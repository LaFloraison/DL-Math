# 代码：把"矩阵的灵魂"算出来——特征值与特征向量

主线里，矩阵 $A = \begin{bmatrix}4&2\\1&3\end{bmatrix}$ 把平面拉成椭圆，两条"只拉伸不旋转"的轴就是它的特征方向。这一节把这条几何直觉变成代码：用 `np.poly` 验证特征多项式，用 `np.linalg.eig` 一次性求出特征值与特征向量，逐列验证 $A\mathbf{v} = \lambda\mathbf{v}$，用谱分解把 $A$ 重新拼回来，再对对称矩阵用 `eigvalsh`/`eigh`，最后亲手实现幂迭代算法求最大特征对。

脚本只依赖 NumPy，约 35 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)   # 打印短小数，不用科学计数

# ---- ① 教材 Figure 2.15 的矩阵 A ----
A = np.array([[4.0, 2.0], [1.0, 3.0]])
print("矩阵 A =\n", A)

# ---- ② 特征多项式 det(A - λI) = λ² - 7λ + 10，用 np.poly 验证 ----
coeff = np.poly(A)                     # 特征多项式系数（从高次到低次）
print("特征多项式系数 =", coeff)       # [1., -7., 10.]

# ---- ③ 一次性求出特征值与特征向量 ----
eigvals, eigvecs = np.linalg.eig(A)    # eigvals: 长度 n；eigvecs: 每列一个特征向量
for j in range(eigvecs.shape[1]):      # 统一符号：每列绝对值最大的分量取正
    if eigvecs[np.argmax(np.abs(eigvecs[:, j])), j] < 0:
        eigvecs[:, j] = -eigvecs[:, j]
print("特征值 λ =", eigvals)           # [5. 2.]
print("特征向量 V =\n", eigvecs)       # 第 i 列对应 eigvals[i]

# ---- ④ 逐列验证 A·v == λ·v ----
for i in range(2):
    v = eigvecs[:, i]
    ok = np.allclose(A @ v, eigvals[i] * v)
    print(f"λ={eigvals[i]:.4f}: |A·v - λ·v| = {np.linalg.norm(A @ v - eigvals[i] * v):.4f}, 验证 = {ok}")

# ---- ⑤ 谱分解重构 A = V·Λ·V⁻¹ ----
Lambda = np.diag(eigvals)
A_rec = eigvecs @ Lambda @ np.linalg.inv(eigvecs)
print("谱分解重构 A ≈ V·Λ·V^-1 ?", np.allclose(A, A_rec))

# ---- ⑥ 对称矩阵：eigvalsh / eigh（特征值升序、特征向量正交）----
S = A @ A.T                            # A·Aᵀ 一定是对称的
lam_s = np.linalg.eigvalsh(S)          # 只返回特征值，升序
_, V_s = np.linalg.eigh(S)
print("对称矩阵 S 的特征值(升序) =", lam_s)
print("V_s^T·V_s =\n", np.round(V_s.T @ V_s, 4) + 0)   # 应为单位阵 → 正交

# ---- ⑦ 幂迭代：大矩阵求最大特征对的正道 ----
rng = np.random.default_rng(0)
v = rng.standard_normal(2)             # 随机起点
for _ in range(60):
    v = A @ v                          # 反复作用矩阵
    v = v / np.linalg.norm(v)          # 每步归一化，防止爆炸
if v[0] < 0: v = -v                    # 特征向量符号不唯一，统一取正
print("幂迭代最大特征向量 ≈", np.round(v, 4))
print("瑞利商 v^T·A·v ≈", np.round(float(v @ A @ v), 4))
```

## 层二：分步逐函数拆解

### 步骤 1：把矩阵 A 装进数组

```python
A = np.array([[4.0, 2.0], [1.0, 3.0]])
```

#### `np.array(嵌套列表)` —— 构造矩阵

**做什么**：把两个列表拼成一个二维数组，形状 $(2, 2)$。
**操作**：`np.array` 扫描嵌套结构，推断出 `float64` 数据类型，按行存储。
**输入**：`[[4.0, 2.0], [1.0, 3.0]]`——外层列表是行，内层列表是列。
**输出**：形状 `(2, 2)` 的 `ndarray`。`A[i, j]` 是第 $i$ 行第 $j$ 列的元素：$A[0,0]=4$、$A[0,1]=2$、$A[1,0]=1$、$A[1,1]=3$。
**可调参数**：
- 换成任意 $n \times n$ 嵌套列表即可；行列数必须相等，因为特征值只对**方阵**有定义——`np.linalg.eig` 传非方阵会直接报错。
- 传 `dtype=np.float32` 可省内存（大模型里常用），代价是精度略降。
**对应数学**：主线里 $A = \begin{bmatrix} 4 & 2 \\ 1 & 3 \end{bmatrix}$——教材 Figure 2.15 用到的矩阵。

---

### 步骤 2：特征多项式 det(A − λI) = 0

```python
coeff = np.poly(A)
```

#### `np.poly(A)` —— 矩阵的特征多项式系数

**做什么**：对 $n \times n$ 矩阵，返回特征多项式 $\det(\lambda I - A)$ 的 $n+1$ 个系数，从最高次到常数项。
**操作**：内部把矩阵约化为上三角并提取对角线，算出特征多项式的系数。
**输入**：形状 `(2, 2)` 的方阵 `A`。
**输出**：长度 `3` 的数组 `[1., -7., 10.]`，代表 $\lambda^2 - 7\lambda + 10 = 0$。
**可调参数**：无。注意 `np.poly` 也能对**根数组**用——传 `[2., 5.]` 会返回 `[1., -7., 10.]`，即"以 2、5 为根的多项式"，用来交叉验证非常方便。
**对应数学**：主线"特征方程 $\det(A-\lambda I)=0$ 得 $\lambda=2,5$"。系数和手算一致，等于把主线里的手算验了一遍。

---

### 步骤 3：一次性求出特征值与特征向量

```python
eigvals, eigvecs = np.linalg.eig(A)
```

#### `np.linalg.eig(A)` —— 特征值与特征向量

**做什么**：解完整的特征值问题 $A\mathbf{v} = \lambda\mathbf{v}$，把 $n$ 个特征值和 $n$ 个特征向量一次全部返回。
**操作**：内部调用 LAPACK 的 `geev`——先把 $A$ 化为上 Hessenberg 形（QR 分解的变体），再迭代求特征值，最后反解特征向量。**它并不依赖** $\det(A-\lambda I)=0$ 那条特征多项式——那条公式只适合手算小矩阵，数值上求多项式的根极不稳定（见文末边界声明）。
**输入**：形状 `(2, 2)` 的方阵 `A`。
**输出**：
- `eigvals`：形状 `(2,)` 的一维数组，`eigvals[i]` 是第 $i$ 个特征值。这里 `[5., 2.]`。
- `eigvecs`：形状 `(2, 2)` 的二维数组，**每一列**是一个特征向量——第 $i$ 列对应 `eigvals[i]`。这里第 0 列 `[0.8944, 0.4472]` 对应 $\lambda=5$（方向 $\approx [2,1]$），第 1 列 `[0.7071, -0.7071]` 对应 $\lambda=2$（方向 $\approx [1,-1]$）。
**可调参数**：
- 输入必须是方阵，非方阵抛 `LinAlgError`。
- 对不对称矩阵，`eigvals` 可能出现**复数**（如旋转矩阵）——此时 `eigvecs` 也是复数矩阵，"验证"步骤仍会通过，但含义变成了复空间里的拉伸（见边界声明）。
- 返回顺序不保证升序或降序（由 LAPACK 决定），需要排序时自己 `np.argsort`；对称矩阵请用 `np.linalg.eigh`，它自带升序。
- 特征向量的**符号是任意的**：LAPACK 可能返回 `[0.7071, -0.7071]`，也可能返回 `[-0.7071, 0.7071]`——它们是同一个方向。脚本里 `for j ...` 的两行"符号归一化"把每列绝对值最大的分量强制取正，只是为了让打印结果可复现，不改动任何数学。
**对应数学**：主线定义块 $A\mathbf{v}=\lambda\mathbf{v}$。注意特征向量被归一化成了单位长度——但方向才是它的灵魂，长度无关紧要。

---

### 步骤 4：逐列验证 A·v == λ·v

```python
v = eigvecs[:, i]
ok = np.allclose(A @ v, eigvals[i] * v)
```

#### `eigvecs[:, i]` —— 取出第 i 列

**做什么**：取特征向量矩阵的第 $i$ 列——一个形状 `(2,)` 的向量 `v`。`:` 表示"取全部行"，`i` 表示"固定第 $i$ 列"。
**输入**：形状 `(2, 2)` 的 `eigvecs` 与整数 `i`。
**输出**：形状 `(2,)` 的向量，即第 $i$ 个特征向量。

#### `A @ v` —— 矩阵乘向量

**操作**：$A$ 的第 $i$ 行与 $v$ 各分量相乘再相加——$(A\mathbf{v})_i = \sum_j A_{ij} v_j$，结果仍是形状 `(2,)` 的向量。这是主线里 $A\mathbf{v}$ 的代码形式。
**输入**：形状 `(2, 2)` 的 `A` 与形状 `(2,)` 的 `v`——矩阵乘向量要求"矩阵的列数 = 向量的长度"，这里都是 2。
**输出**：形状 `(2,)` 的向量 $A\mathbf{v}$。

#### `eigvals[i] * v` —— 标量乘向量

**操作**：把特征值 $\lambda_i$ 乘到向量每个分量上——逐元素缩放，等价于主线右边的 $\lambda\mathbf{v}$。

#### `np.allclose(a, b)` —— 判断两个数组逐元素近似相等

**操作**：逐元素比较 `a` 与 `b`，允许浮点误差：$|a_j - b_j| \le \text{atol} + \text{rtol}\cdot|b_j|$ 全部成立才返回 `True`。
**输入**：两个形状相同的数组 `A @ v` 与 `eigvals[i] * v`。
**输出**：布尔值。这里 `True`——证明 `eig` 返回的东西确实满足定义式 $A\mathbf{v} = \lambda\mathbf{v}$。
**可调参数**：`rtol`（相对容差，默认 `1e-05`）、`atol`（绝对容差，默认 `1e-08`）——验证精度要求越高，把两个容差调得越小；设 `rtol=0, atol=0` 则要求完全相等（浮点下几乎总是失败，不推荐）。
**对应数学**：主线 $A\mathbf{v} = \lambda\mathbf{v}$ 的逐对验证——这是"特征向量"这个称号的唯一判据。

---

### 步骤 5：谱分解重构 A = V·Λ·V⁻¹

```python
Lambda = np.diag(eigvals)
A_rec = eigvecs @ Lambda @ np.linalg.inv(eigvecs)
```

#### `np.diag(eigvals)` —— 向量 → 对角矩阵

**操作**：把一维数组 `[5., 2.]` 放到对角线上，其余位置填 0，得到 $\Lambda = \begin{bmatrix} 5 & 0 \\ 0 & 2 \end{bmatrix}$。
**输入**：形状 `(2,)` 的一维数组。
**输出**：形状 `(2, 2)` 的对角矩阵。
**可调参数**：反过来用——传一个二维矩阵给 `np.diag`，它会返回矩阵主对角线上的元素（提取操作）。同一个函数，双向都能用。

#### `np.linalg.inv(eigvecs)` —— 矩阵求逆

**操作**：对特征向量矩阵 $V$ 求逆 $V^{-1}$，即解 $V X = I$。
**输入**：形状 `(2, 2)` 的可逆方阵 `eigvecs`。
**输出**：形状 `(2, 2)` 的逆矩阵。只要 $A$ 的特征向量线性无关（可对角化），$V$ 就可逆。
**可调参数**：矩阵不可逆（如有一列是零向量或两列成比例）时会抛 `LinAlgError`。

#### `eigvecs @ Lambda @ np.linalg.inv(eigvecs)` —— 矩阵连乘

**操作**：从左到右依次做矩阵乘法：先 $V \Lambda$（每列乘以对应特征值），再乘 $V^{-1}$。结果 `A_rec` 应精确还原 $A$。
**输入**：三个形状都是 `(2, 2)` 的矩阵。矩阵乘法的形状规则：前一个的列数必须等于后一个的行数（都是 2）。
**输出**：形状 `(2, 2)` 的 `A_rec`。`np.allclose(A, A_rec)` 返回 `True`——这是主线"把 $A$ 用特征值对角化"的代码证明。
**对应数学**：主线性质"由特征向量张起空间后，$A$ 被对角化"——$A = V\Lambda V^{-1}$ 就是谱分解（对可对角化矩阵）的通用形式；对称矩阵的特例是 $A = Q\Lambda Q^{\top}$，此时 $V^{-1} = V^{\top}$。

---

### 步骤 6：对称矩阵专用——eigvalsh / eigh

```python
S = A @ A.T
lam_s = np.linalg.eigvalsh(S)
_, V_s = np.linalg.eigh(S)
```

#### `A @ A.T` —— 构造对称矩阵

**操作**：$A$ 乘上它的转置 $A^{\top}$。任何矩阵乘自己的转置，结果必然是对称矩阵（$(A A^{\top})^{\top} = A A^{\top}$）。这里 $S = \begin{bmatrix} 20 & 10 \\ 10 & 10 \end{bmatrix}$。
**对应数学**：这正是 SVD 的入口——$S = A A^{\top}$ 的特征值就是奇异值的平方（教材 Figure 2.16 的 $\Sigma^2$）。PCA 的协方差矩阵 $C = \frac{1}{n}X^{\top}X$ 也是这个形状。

#### `np.linalg.eigvalsh(S)` —— 对称矩阵的特征值（升序）

**操作**：利用对称性，用更快的算法（LAPACK `syevd`）求特征值，并**按升序返回**。
**输入**：形状 `(2, 2)` 的对称矩阵 `S`。
**输出**：形状 `(2,)` 的数组 `[3.8197, 26.1803]`——小的在前。
**可调参数**：第三个参数 `UPLO`，`'L'`/`'U'` 决定只读下三角还是上三角（默认 `'L'`）。**危险提醒**：`eigvalsh` 只读一个三角形，非对称矩阵传给它会**静默地给出错误结果**（它根本不会报错）——所以只在确定矩阵对称时用。

#### `np.linalg.eigh(S)` —— 对称矩阵的特征值与特征向量

**操作**：同 `eigvalsh`，但额外返回特征向量。
**输入**：形状 `(2, 2)` 的对称矩阵。
**输出**：
- 第一个返回值：升序特征值，形状 `(2,)`。
- 第二个返回值 `V_s`：形状 `(2, 2)`，每列是单位特征向量，且列之间互相正交。

`V_s.T @ V_s` 是正交检验：正交矩阵满足 $Q^{\top}Q = I$，所以应该得到单位阵：
```text
[[1. 0.]
 [0. 1.]]
```
**可调参数**：同样有 `UPLO` 参数。对非对称矩阵，`eigh` 和 `eigvalsh` 一样会给出无意义的答案。
**对应数学**：主线性质 3"对称矩阵特征值全为实数、特征向量正交、可谱分解 $A=Q\Lambda Q^{\top}$"。PCA 里的 $Q$ 就是数据主轴。

### 步骤 7：幂迭代——不用求逆，也能抓住最大特征对

```python
rng = np.random.default_rng(0)
v = rng.standard_normal(2)
for _ in range(60):
    v = A @ v
    v = v / np.linalg.norm(v)
if v[0] < 0: v = -v
```

#### `np.random.default_rng(seed)` —— 可复现的随机数生成器

**操作**：创建一个随机数生成器对象，`seed=0` 保证每次运行得到同一串随机数（可复现实验）。
**可调参数**：`seed` 换成别的整数得到不同随机起点。`default_rng` 是 NumPy 1.17+ 推荐用法，替代旧的 `np.random.seed()`。

#### `v = A @ v; v = v / np.linalg.norm(v)` —— 幂迭代的一步

**操作**：这 60 次循环是**完整实现了一个数值算法**，不是调库：每一步先让矩阵作用（$v \leftarrow A v$），再归一化到单位长度。背后的数学：把起点 $v$ 在特征基里展开，$A$ 作用一次，沿 $\lambda=5$ 方向的成分被放大 5 倍、沿 $\lambda=2$ 方向的成分被放大 2 倍；作用 $k$ 次后，相对比例是 $(5/2)^k$——指数级地，小特征值方向被抹平，向量收敛到最大特征值的特征向量。
**输入**：形状 `(2,)` 的向量与形状 `(2, 2)` 的 `A`。
**输出**：收敛到 $\lambda_{\max}=5$ 的特征向量 `[0.8944, 0.4472]`（即方向 $\approx[2,1]$）。
**可调参数**：迭代次数 `60`——次数越多越精确；设成 5 次就还是"半成品"，设成 10000 次会非常精确（但小矩阵没必要）。

#### `v @ A @ v` —— 瑞利商，一步估出特征值

**操作**：当 $v$ 是单位特征向量时，$v^{\top} A v = v^{\top}(\lambda v) = \lambda$。所以一旦迭代收敛，**瑞利商 (Rayleigh quotient) 就是最大特征值本身**——这里是 5.0。
**对应数学**：这是大规模机器学习里求"最大特征对"的标准姿势——因为 $A v$ 一次只要一次矩阵乘向量（稀疏矩阵可低至 $O(\text{非零元素})$），而 `np.linalg.eig` 要 $O(n^3)$。千万维的协方差矩阵不可能完整分解，但幂迭代（及其进阶：Lanczos、ARPACK）照样能抓住前几个最大特征对。主线 DL 桥接里"幂迭代求主方向"就落在这里。

## 边界声明：这套代码能做什么，不能做什么

1. **`np.linalg.eig` 返回的特征值顺序不保证**——本例碰巧是降序 `[5., 2.]`，但 LAPACK 不承诺任何排序。PCA 里要按特征值降序选主轴，必须自己 `np.argsort`；或者直接用 `eigh`/`eigvalsh`（升序）。把"碰巧的降序"当成保证，是初学者最常见的错。
2. **特征向量符号任意、长度单位化**——`[0.8944, 0.4472]` 和 `[-0.8944, -0.4472]` 是同一个特征向量。脚本第 ③ 步、第 ⑦ 步各做了一次符号归一化，就是为了让输出可复现；自己比较两个程序的结果时，也要先对齐符号。
3. **`eigvalsh`/`eigh` 只适用于对称（Hermitian）矩阵**——传入非对称矩阵不会报错，而是静默地只读一个三角形、返回一堆**没有意义**的数字。使用前先确认对称，或用 `np.allclose(A, A.T)` 自检。
4. **`det(A-λI)=0` 是概念公式，不是数值算法**——用它手算 $2\times2$ 很漂亮，但高维下特征多项式系数病态（对扰动极其敏感），`np.poly` 只适合验证小例子。真实的大矩阵靠的是迭代法：幂迭代、Lanczos、ARPACK（`scipy.sparse.linalg.eigs`）。
5. **`np.linalg.eig` 需要完整的 $n \times n$ 矩阵**——神经网络的权重矩阵动辄百万维，不可能完整分解；这时用 SVD（`np.linalg.svd`）或只算前几个奇异值/特征对。特征值分解是概念，迭代与 SVD 才是大规模场景的工程。
