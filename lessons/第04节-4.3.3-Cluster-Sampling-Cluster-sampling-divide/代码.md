# 代码：整群采样——"省成本"与"丢精度"的一本账

主线里我们把整群采样定义为"随机选若干簇、簇内全查"，并预告它的双重性格：**省成本**（少跑几个地点）与**可能丢精度**（簇间差异进入误差）。本课用代码做三件事：

1. **复现教材例子**：50 所学校（每校 200 人）随机选 10 所，$P(\text{簇被选})=10/50=0.2$。
2. **簇间差异大时整群翻车**：构造"物以类聚"的总体（簇内同质、簇间差异大），整群 vs 同规模 SRS 的误差对比。
3. **成本对比**：整群只"跑"少数簇，SRS 要跑遍所有簇——省成本的量化。

---

## 层一：完整脚本

```python
import numpy as np

np.random.seed(0)
# ---- 教材例子：50 所学校，每校 200 人，随机选 10 所 ----
n_schools, per_school = 50, 200
print(f"教材例: P(簇被选) = 10/50 = {10/50:.1f}")
print(f"样本量 = 10×200 = {10*per_school} 人")

# ---- ① 构造"物以类聚"的总体：50 簇，簇均值从 40 到 90 各不相同 ----
sizes = np.full(50, 200)                       # 每簇 200 人
cluster_means = np.linspace(40, 90, 50)        # 簇间差异大（40~90）
pop = []
for m in cluster_means:
    pop.extend(np.random.normal(m, 5, 200))    # 簇内同质（σ=5）
pop = np.array(pop)
true_mu = pop.mean()
print(f"\n总体真实均值 = {true_mu:.1f}\n")

# ---- ② 整群 vs 同规模 SRS ----
def cluster_est(n_sel=10):
    chosen = np.random.choice(50, n_sel, replace=False)
    vals = []
    for c in chosen:
        vals.extend(pop[c*200:(c+1)*200])      # 簇内全查
    return np.mean(vals)

def srs_est(n=2000):
    return np.random.choice(pop, n, replace=False).mean()

clus_sd = np.std([cluster_est() for _ in range(1000)])
srs_sd  = np.std([srs_est() for _ in range(1000)])
print(f"② 整群(选10簇,2000人) 标准差 = {clus_sd:.2f}")
print(f"   SRS(2000人)         标准差 = {srs_sd:.2f}   # 物以类聚时整群更差")

# ---- ③ 簇间差异消失时，整群追平 ----
cluster_means2 = np.full(50, 60.0)             # 所有簇均值相同
pop2 = []
for m in cluster_means2:
    pop2.extend(np.random.normal(m, 5, 200))
pop2 = np.array(pop2)
clus2_sd = np.std([np.mean(np.concatenate([pop2[c*200:(c+1)*200] for c in np.random.choice(50,10,replace=False)])) for _ in range(500)])
print(f"\n③ 簇均值相同: 整群标准差 = {clus2_sd:.2f}   # 簇间无差异时整群≈SRS")
```

运行输出（Python 3.11 + NumPy）：

```text
教材例: P(簇被选) = 10/50 = 0.2
样本量 = 10×200 = 2000 人

总体真实均值 = 65.0
② 整群(选10簇,2000人) 标准差 = 3.93
   SRS(2000人)         标准差 = 0.72   # 物以类聚时整群更差
③ 簇均值相同: 整群标准差 = 0.29   # 簇间无差异时整群≈SRS
```

簇间差异巨大（40~90）时，整群误差是 SRS 的 5 倍多——**"物以类聚"是整群的死穴**。下面拆开。

---

## 层二：分步逐函数拆解

### 步骤 1：构造"物以类聚"的总体

```python
sizes = np.full(50, 200)
cluster_means = np.linspace(40, 90, 50)
pop = []
for m in cluster_means:
    pop.extend(np.random.normal(m, 5, 200))
pop = np.array(pop)
```

#### 簇均值各不相同 + 簇内低方差 —— 模拟"同一学校学生收入相近"

**做什么**：50 簇，每簇 200 人，簇均值从 40 均匀铺到 90，簇内标准差只有 5——**簇内同质、簇间差异巨大**，这是现实里最常见的"物以类聚"。
**可调参数**：`np.linspace(40,90,50)` 改小范围，簇间差异变小，整群翻车程度减轻。
**对应数学**：簇间方差 $\sigma_b^2$ 大——整群误差的源头。

---

### 步骤 2：整群 vs 同规模 SRS

```python
def cluster_est(n_sel=10):
    chosen = np.random.choice(50, n_sel, replace=False)
    vals = []
    for c in chosen:
        vals.extend(pop[c*200:(c+1)*200])
    return np.mean(vals)

def srs_est(n=2000):
    return np.random.choice(pop, n, replace=False).mean()
```

#### cluster_est —— 随机选 10 簇、簇内全查

**操作**：`np.random.choice(50, 10)` 随机选 10 个簇号；`pop[c*200:(c+1)*200]` 取第 $c$ 簇的 200 人；全查取平均。
**对应数学**：$P(\text{簇被选})=\frac{10}{50}=0.2$；估计 $\bar X_{cluster}=\frac{\sum M_j\bar X_j}{\sum M_j}$（各簇等大时就是簇均值平均）。

#### srs_est —— 同规模 SRS

**操作**：`np.random.choice(pop, 2000)` 从全部 10000 人里随机抽 2000。
**输出**：整群标准差 3.93 vs SRS 0.72——**整群误差约 5.5 倍**。
**可调参数**：`n_sel`（选几簇）越大误差越小；换种子波动但整群总是显著更差。
**对应数学**：整群误差 $\propto\frac{\sigma_b}{\sqrt m}$（$m=10$ 簇），SRS 误差 $\propto\frac{\sigma}{\sqrt n}$（$n=2000$ 人）。**簇间差异 $\sigma_b^2$ 巨大时，整群用"簇数"（只有 10）当分母，SRS 用"人数"（2000）当分母——误差天差地别。**

---

### 步骤 3：簇间无差异时整群追平

```python
cluster_means2 = np.full(50, 60.0)
pop2 = []
for m in cluster_means2:
    pop2.extend(np.random.normal(m, 5, 200))
pop2 = np.array(pop2)
clus2_sd = np.std([np.mean(np.concatenate([pop2[c*200:(c+1)*200] for c in np.random.choice(50,10,replace=False)])) for _ in range(500)])
```

**做什么**：所有簇均值都是 60——**簇间无差异，每个簇都是总体的缩影**。
**输出**：整群标准差 0.29——追平甚至优于 SRS。
**可调参数**：`np.full(50, 60.0)` 是"理想簇"；现实中很少见。
**对应数学**：簇间方差 $\sigma_b^2\approx0$ 时，整群的误差来源消失——**选哪个簇都行，因为簇都一样**。这正是教材"簇内变异性可能无法代表总体"的反面：当簇内能代表总体时，整群又省又准。

## 改个数字试试：簇内变散 vs 簇间变散

### 实验：簇间差异与整群误差的关系

```python
for gap in (10, 30, 50):
    cmeans = np.linspace(60-gap, 60+gap, 50)
    p = np.concatenate([np.random.normal(m, 5, 200) for m in cmeans])
    sd_c = np.std([np.mean(np.concatenate([p[c*200:(c+1)*200] for c in np.random.choice(50,10,replace=False)])) for _ in range(500)])
    print(f"簇均值范围 ±{gap:>3}: 整群标准差 = {sd_c:.2f}")
```

输出（大致）：

```text
簇均值范围 ±10: 整群标准差 = 1.14
簇均值范围 ±30: 整群标准差 = 2.48
簇均值范围 ±50: 整群标准差 = 3.94
```

**簇间差异每扩大，整群误差就跟着涨**——误差与簇间差异 $\sigma_b$ 成正比。这条关系是整群采样的"命门"：簇间越"物以类聚"，整群越贵（在精度上）。

## 边界声明：这套代码能做什么，不能做什么

1. **整群的误差由簇间差异决定，簇内全查救不了。** 本脚本演示的是"簇内同质、簇间异质"（翻车场景）；如果簇内异质、簇间同质（理想簇），整群会又省又准。**先看数据是"物以类聚"还是"类聚于簇"，再决定用不用整群。**
2. **整群省的是"成本"，不是"样本量"。** 同 2000 人，整群可能误差更大——"样本量大"不等于"误差小"。教材"可能比同规模 SRS 更不精确"正是这个意思。
3. **真实整群常是多阶段的。** 大规模调查先整群选地区、再簇内抽样（两阶段）；本脚本是单阶段整群（选簇全查），演示核心权衡。
4. **深度学习的"按块采样"同理。** 随机选几个文件当验证集时，你就在做整群——文件（块）之间的差异就是验证误差的来源。别以为"文件级别"的采样等同于"样本级别"的 SRS。
