# 习题：梯度

## 一、概念检验

### 题 1.1（填空）

对 $f(x,y,z)$，梯度定义为 $\nabla f = \left(\dfrac{\partial f}{\partial x}, \underline{\quad}, \underline{\quad}\right)$。梯度指向函数____最快的方向，它的大小等于____；训练时梯度下降沿____方向更新权重。

**解答**：$\dfrac{\partial f}{\partial y}$、$\dfrac{\partial f}{\partial z}$；上升；最大上升速率；负梯度（$-\nabla f$）。
**思路点拨**：前两空是梯度定义的字面复制——每个自变量对应一个偏导分量。后两空是梯度语义的浓缩：上升最快、大小=最大速率、训练走反方向。答错"上升最快"与"下降最快"之分的同学，请记住：**梯度指上升，负梯度指下降。**

### 题 1.2（选择）

在点 $p$ 处，方向导数 $D_{\mathbf{u}} f = \nabla f(p) \cdot \mathbf{u}$ 的最大值出现在（ ）

A. $\mathbf{u}$ 与 $\nabla f(p)$ 垂直时
B. $\mathbf{u}$ 与 $\nabla f(p)$ 同向时
C. $\mathbf{u}$ 与 $\nabla f(p)$ 反向时
D. $\mathbf{u}$ 与坐标轴对齐时

**解答**：B。
**思路点拨**：$D_{\mathbf{u}} f = |\nabla f|\cos\theta$，$\theta$ 是 $\mathbf{u}$ 与梯度夹角。$\cos\theta$ 最大 = $\theta=0$ = 同向。选 A 的同学把"垂直"（方向导数为零）和"最大"搞混了；选 D 的忘了坐标轴只是特例。注意：**$\nabla f(p)$ 通常不是坐标轴方向**——梯度是"所有偏导的合力"，指向斜上方。

### 题 1.3（简答）

证明：梯度 $\nabla f$ 与 $f$ 的等高线（等值线）正交。并解释为什么"最陡方向垂直于等高线"在直觉上合理。

**解答**：沿等高线方向 $\mathbf{u}$，函数值不变，所以方向导数 $D_{\mathbf{u}} f = 0$。又 $D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$，于是 $\nabla f \cdot \mathbf{u} = 0$——两个非零向量点积为零即正交。直觉上：沿等高线走海拔不变（白走），最陡方向必然"垂直于等高线"才能最快改变海拔，正如登山者笔直穿坡而上。
**思路点拨**：这道题把 Toy Model 的登山直觉严格化。关键一步是"沿等高线方向导数为零"——因为等高线就是"函数值不变"的线。能把这个翻译成 $\nabla f \cdot \mathbf{u} = 0$，就完成了直觉到证明的跳跃。

## 二、计算实践

### 题 2.1（手算）

设 $f(x,y) = 3x^2 + 2xy + y^2$。

(a) 求 $\nabla f(x,y)$。
(b) 在点 $(1, 2)$ 处，梯度是什么？上升最快的单位方向是什么？
(c) 朝方向 $\mathbf{u} = (1, 0)$ 的方向导数是多少？它和梯度大小 $|\nabla f(1,2)|$ 谁大？

**解答**：
(a) $\dfrac{\partial f}{\partial x} = 6x + 2y$，$\dfrac{\partial f}{\partial y} = 2x + 2y$，故 $\nabla f = (6x+2y,\; 2x+2y)$。
(b) 代入 $(1,2)$：$\nabla f(1,2) = (6+4,\; 2+4) = (10, 6)$。上升最快单位方向 $\mathbf{u} = \dfrac{(10,6)}{\sqrt{136}} = \dfrac{(10,6)}{2\sqrt{34}}$。
(c) $\mathbf{u}=(1,0)$：$D_{\mathbf{u}} f = (10,6)\cdot(1,0) = 10$。而 $|\nabla f(1,2)| = \sqrt{100+36} = \sqrt{136} \approx 11.66 > 10$。朝梯度方向的方向导数最大。
**思路点拨**：注意"单位方向"要归一化——$\mathbf{u} = \nabla f / |\nabla f|$，不能直接写 $(10,6)$（它的长度是 $\sqrt{136}$ 不是 1）。(c) 的结论"朝梯度 > 朝任何坐标轴"是梯度的定义性特征。算完用《代码.md》的 `directional` 验证：`(10,6)@(1,0)=10`，`(10,6)@(10,6)/√136 = √136`。

### 题 2.2（代码验证）

验证：对 $f(x,y) = x^2 + y^2$，梯度方向 $-\nabla f(1,2)$ 确实是下降最快的方向——从 $(1,2)$ 出发沿它走一小步，比沿 $(-1,0)$ 走同样距离，损失下降得更多。

```python
import numpy as np
def f(x, y): return x**2 + y**2
p = np.array([1.0, 2.0]); L0 = f(*p)
step = 0.1
g = np.array([2.0*p[0], 2.0*p[1]])                  # 梯度 (2,4)
down = -g / np.linalg.norm(g)                       # 负梯度单位方向
east = np.array([-1.0, 0.0])                        # 朝西
d1 = L0 - f(*(p + step*down))                       # 沿负梯度走一步的损失降幅
d2 = L0 - f(*(p + step*east))                       # 沿朝西走一步的损失降幅
print(f"沿负梯度一步损失降 {d1:.4f}，沿朝西一步损失降 {d2:.4f}")
```

**解答**：沿负梯度方向每步下降约 `0.2`（$f(0.9, 1.8)=4.05$，$L_0=5$，降幅 0.95……具体值取决于 `p+step*down` 的取值），沿朝西方向（与梯度不正对）下降更少。负梯度方向是"每走单位距离损失下降最多"的方向。
**思路点拨**：这正是"最速下降 (steepest descent)"的数值验证——同样的步长，方向对了降得多。把 `step` 改成不同值，负梯度方向的优势始终保持（只要步长不太大引起震荡）。这道题把"梯度方向 = 最速下降"从定理变成测量。

## 三、DL 延伸

### 题 3.1

一个网络损失 $L$ 是 5 个权重的函数。在某一步，你算出的梯度向量是 $\nabla L = (0.1, -0.3, 0, 0.5, -0.2)$，$\eta = 0.01$。

(a) 写出所有 5 个权重的更新。
(b) 第 3 个权重 $\partial L/\partial w_3 = 0$，它这一轮会更新吗？这说明它"完美"了吗？

**解答**：(a) 每个权重 $w_i \leftarrow w_i - \eta \cdot g_i$：$w_1$ 减 $0.001$，$w_2$ 加 $0.003$，$w_3$ 不变，$w_4$ 减 $0.005$，$w_5$ 加 $0.002$。(b) 第 3 个权重这一轮不动。但"梯度为零"不代表"完美"——它可能只是这个维度暂时处于平地/鞍点/平坦区，或者它确实已到局部最优；要区分需要二阶信息。梯度为零只是"该方向一阶不动"，不是"最优"。
**思路点拨**：这道题把梯度向量落成逐权重的动作。能写出"$w_3$ 不动但不定论完美"，说明你记住了 §3.2.1 的鞍点警告。真实模型里某个权重梯度为零很常见（稀疏梯度），并不代表它已最佳。

### 题 3.2

教材说梯度可以用解析法（求导规则）或数值法/自动微分计算。工程师在图里发现：解析梯度和数值梯度在某点差出 $10^{-2}$ 量级。请从本节知识列出至少两种可能原因，并说明哪个更危险。

**解答**：① **解析公式错误**：手写链式法则出错，梯度方向或大小错——最危险，因为它"看起来对"却把每一步引向错误方向，模型可能完全训不出来或缓慢漂移。② **数值逼近误差**：$h$ 选得太大（逼近误差）或太小（浮点消减），偏离 U 形曲线黄金地带——数值梯度本身不准，不代表解析错。③ 函数在该点不可微/有折痕（如 ReLU 零点），两条路径在该点本就对不上。判定方法：先减小/增大 $h$ 看数值梯度是否稳定；稳定仍差，则怀疑解析公式，逐层检查链式法则。
**思路点拨**：这是真实工程（autograd 测试）的经典场景。能说出"解析错最危险，因为误差方向可能系统性偏错"就抓住了要害。数值梯度虽慢，却是独立于解析推导的"裁判"——两条独立路径互相印证，正是梯度检查 (gradient check) 的思想。
