# 代码：让梯度这支箭头自我证明

主线里我们证明了：梯度 $\nabla f$ 指向上升最快的方向，方向导数 $D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$ 在任何方向上都取不到比 $|\nabla f|$ 更大的值。这一节的脚本让这支箭头在四个事实面前自证其身：

1. 教材例题 $f(x,y) = x^2 + y^2$ 在 $(1,2)$ 处的梯度 $(2,4)$，大小 $\sqrt{20} \approx 4.47$；
2. **任意方向的方向导数 ≤ 梯度大小**：朝梯度方向走，方向导数恰好等于 $|\nabla f|$，朝其它任何方向都更小；
3. **梯度垂直于等高线**：沿等高线走，方向导数为 0，即 $\nabla f \cdot \mathbf{u}_{\text{等高线}} = 0$；
4. 用梯度下降在 $f$ 上找到谷底 $(0,0)$——梯度箭头把"下山"变成了一串可观察的脚印。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 目标函数与解析梯度（教材例题）----
def f(x, y): return x**2 + y**2          # 抛物面，谷底在 (0,0)
def grad_f(x, y): return np.array([2.0 * x, 2.0 * y])

# ---- ② 数值梯度：中心差分逐分量逼近 ----
def num_grad(f, p, h=1e-5):
    """对二元函数 f 在点 p=(x,y) 处做数值梯度。"""
    x, y = p
    dfdx = (f(x + h, y) - f(x - h, y)) / (2.0 * h)
    dfdy = (f(x, y + h) - f(x, y - h)) / (2.0 * h)
    return np.array([dfdx, dfdy])

# ---- ③ 方向导数：D_u f = ∇f·u ----
def directional(f, grad, p, u):
    """朝单位方向 u 的方向导数：直接用梯度点积。"""
    return grad(p) @ u

# ---- ④ 教材验证：在 (1,2) 处把梯度三连验 ----
p = np.array([1.0, 2.0])
g = grad_f(*p)
g_num = num_grad(f, p)
print(f"解析梯度 ∇f(1,2) = ({g[0]:.4f}, {g[1]:.4f})   数值梯度 = ({g_num[0]:.4f}, {g_num[1]:.4f})")
print(f"|∇f| = √(2²+4²) = {np.linalg.norm(g):.4f}")

# ---- ⑤ 方向导数：朝东、朝北、朝梯度，三个方向对照 ----
u_east = np.array([1.0, 0.0])                    # 朝东
u_north = np.array([0.0, 1.0])                   # 朝北
u_grad = g / np.linalg.norm(g)                   # 朝梯度方向（单位化）
for name, u in [("朝东 (1,0)", u_east), ("朝北 (0,1)", u_north), ("朝梯度", u_grad)]:
    d = directional(f, grad_f, p, u)
    print(f"方向导数 {name:<10} = {d:+.4f}   # 应分别=2, 4, √20≈4.47")

# ---- ⑥ 梯度垂直于等高线：沿等高线走，变化率为 0 ----
# 等高线 f(x,y)=c 在该点的切线方向：绕谷底的切向 (y, -x)/r
r = np.linalg.norm(p)
u_contour = np.array([p[1], -p[0]]) / r          # 等高线切线方向
print(f"∇f · u_contour = {g @ u_contour:+.2e}   # 应≈0，梯度与等高线正交")

# ---- ⑦ 梯度下降：沿 -∇f 下山找谷底 (0,0) ----
def gradient_descent(f, grad, p0, eta=0.1, steps=30):
    w = np.array(p0, dtype=float)
    for _ in range(steps):
        w = w - eta * grad(w)
    return w

w_final = gradient_descent(f, grad_f, [1.0, 2.0], eta=0.1, steps=30)
print(f"梯度下降终点 = ({w_final[0]:.6f}, {w_final[1]:.6f})   # 谷底理论值 (0, 0)")
```

运行输出（Python 3.11 + NumPy）：

```text
解析梯度 ∇f(1,2) = (2.0000, 4.0000)   数值梯度 = (2.0000, 4.0000)
|∇f| = √(2²+4²) = 4.4721
方向导数 朝东 (1,0) = +2.0000   # 应分别=2, 4, √20≈4.47
方向导数 朝北 (0,1) = +4.0000
方向导数 朝梯度    = +4.4721
∇f · u_contour = -4.44e-16   # 应≈0，梯度与等高线正交
梯度下降终点 = (0.000000, 0.000000)   # 谷底理论值 (0, 0)
```

四个事实全部兑现：解析与数值梯度一致；方向导数朝东=2、朝北=4、朝梯度=4.47（最大）；梯度与等高线正交（$10^{-16}$ 量级，浮点噪声）；梯度下降到达谷底。下面逐段拆解。

## 层二：分步逐函数拆解

### 步骤 1：定义 `f` 与 `grad_f` —— 教材抛物面

```python
def f(x, y): return x**2 + y**2
def grad_f(x, y): return np.array([2.0 * x, 2.0 * y])
```

#### `grad_f(x, y)` —— 解析梯度 $\nabla f = (2x, 2y)$

`return np.array([2.0 * x, 2.0 * y])`

**做什么**：把两个偏导 $\partial f/\partial x = 2x$、$\partial f/\partial y = 2y$ 装进一个形状 `(2,)` 的向量。这个向量指向上升最快方向。
**操作**：`np.array([...])` 打包两个标量为向量；`*` 是标量乘。
**输入**：`x`、`y`——求梯度点，标量。
**输出**：形状 `(2,)` 的梯度向量。
**可调参数**：无。函数换则梯度换。`grad_f(1.0, 2.0)` 返回 `(2,4)`；`grad_f(0.0, 0.0)` 返回 `(0,0)`——谷底没有方向。
**对应数学**：主线定义块 $\nabla f = (2x, 2y)$，教材原公式。

---

### 步骤 2：定义 `num_grad` —— 数值梯度（中心差分逐分量）

```python
def num_grad(f, p, h=1e-5):
    x, y = p
    dfdx = (f(x + h, y) - f(x - h, y)) / (2.0 * h)
    dfdy = (f(x, y + h) - f(x, y - h)) / (2.0 * h)
    return np.array([dfdx, dfdy])
```

#### `num_grad(f, p, h)` —— 数值梯度

`dfdx = (f(x + h, y) - f(x - h, y)) / (2.0 * h)`

**做什么**：不背公式，对每个分量用中心差分算偏导，再打包成梯度。输出显示它和解析梯度 `(2,4)` 完全一致——梯度不是玄学，定义能替它验算。
**操作**：`x, y = p` 解包；`f(x+h, y)` 与 `f(x-h, y)` 量 $x$ 两侧函数值差，除以 `2h`——注意 `y` 在两个调用里不变（冻结）；`dfdy` 同理。返回 `np.array([dfdx, dfdy])`。
**输入**：
- `f`：二元函数（callable）。
- `p`：形状 `(2,)` 的点。
- `h`：步长，默认 `1e-5`。
**输出**：形状 `(2,)` 的数值梯度。
**可调参数**：`h` 是精度旋钮（§3.2 的 U 形曲线）。也可以把函数签名改成一元版供 `f` 使用。
**对应数学**：主线定义块的极限定义在代码里的实现。真实框架的梯度检查就靠它。

---

### 步骤 3：定义 `directional` —— 方向导数 = 梯度点积

```python
def directional(f, grad, p, u):
    return grad(p) @ u
```

#### `directional(f, grad, p, u)` —— $D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$

`return grad(p) @ u`

**做什么**：按主线定理 $D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$，用梯度与方向向量的点积直接算方向导数。
**操作**：`grad(p)` 得到当前点的梯度；`@` 是向量点积（`np.dot` 的运算符形式）。`f` 参数其实没用到——`grad` 已经携带了函数信息，保留 `f` 仅为接口对称。
**输入**：
- `f`：二元函数（备用）。
- `grad`：梯度函数（callable）。
- `p`：求导点，形状 `(2,)`。
- `u`：单位方向向量，形状 `(2,)`。
**输出**：方向导数，标量。
**可调参数**：`u` 必须单位化（`|u|=1`），否则方向导数会被缩放。传入非单位向量时，结果变成"沿该向量的变化量"而非"每单位距离的变化率"——这是最常见的调用错误。
**对应数学**：主线方向导数定义。三个方向的输出 `2, 4, 4.47` 印证"梯度方向使方向导数最大"。

---

### 步骤 4：梯度垂直于等高线 —— 沿等高线走，变化率为 0

```python
r = np.linalg.norm(p)
u_contour = np.array([p[1], -p[0]]) / r
print(f"∇f · u_contour = {g @ u_contour:+.2e}")
```

**做什么**：构造等高线 $x^2+y^2=c$ 在 $(1,2)$ 处的切线方向 $(y, -x)$（绕原点的圆周切向），与梯度做点积。输出 $-4.44\times10^{-16}$——约等于 0，即梯度与等高线正交。
**操作**：`np.array([p[1], -p[0]])` 取圆周切向 `(2,-1)`；`/ r` 单位化（$r=\sqrt{5}$）；`g @ u_contour` 点积。点积为零 = 正交 = 沿等高线方向函数值不变。
**输入**：`p`、`g`。
**输出**：一个约等于 0 的标量。
**可调参数**：换点（如 $(3,4)$），切向换成 $(-4,3)$，点积仍为 0——正交是梯度的普遍性质，不依赖具体点。
**对应数学**：主线"梯度与等高线处处正交"的数值验证。Toy Model 里"最陡路垂直穿过等高线"被证明。

---

### 步骤 5：定义 `gradient_descent` —— 沿负梯度下山

```python
def gradient_descent(f, grad, p0, eta=0.1, steps=30):
    w = np.array(p0, dtype=float)
    for _ in range(steps):
        w = w - eta * grad(w)
    return w
```

#### `gradient_descent(f, grad, p0, eta, steps)` —— $\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla f$

`w = w - eta * grad(w)`

**做什么**：把梯度箭头用起来——朝 $-\nabla f$ 方向走，重复 30 次，从 $(1,2)$ 到达 $(0,0)$。
**操作**：`grad(w)` 算当前点梯度；`eta * grad(w)` 缩放成步幅；`w - ...` 朝负梯度走。注意 `grad` 是传入的 callable——换一个函数，梯度自动跟随，这正是"梯度是函数的指纹"在代码里的体现。
**输入**：
- `f`：目标函数（备用）。
- `grad`：梯度函数。
- `p0`：起点，形状 `(2,)`。
- `eta`：学习率，默认 `0.1`。
- `steps`：步数，默认 `30`。
**输出**：终点权重，形状 `(2,)`。
**可调参数**：`eta` 与 `steps` 的组合决定收敛质量。`eta=0.1, steps=30` 精确到 6 位小数；`eta` 改成 0.9 会震荡。也可以把 `steps` 加到 200 看更高精度。
**对应数学**：主线 DL 桥接的更新规则 $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla L(\mathbf{w}_t)$——把 $\nabla f$ 换成 $\nabla L$，这就是训练的一切。

## 改个数字试试：把梯度推向别的方向

### 实验 1：换一个不对称函数 $f = 3x^2 + y^2$

```python
def f_ell(x, y): return 3.0 * x**2 + y**2      # 椭圆碗：x 方向更陡
def grad_ell(x, y): return np.array([6.0 * x, 2.0 * y])
p = np.array([1.0, 1.0])
g = grad_ell(*p)
print(f"∇f(1,1) = {g}   方向（单位化）= {g/np.linalg.norm(g)}")
```

输出：

```text
∇f(1,1) = [6. 2.]   方向（单位化）= [0.9487 0.3162]
```

梯度不再指向 45°（$(1,1)$ 的方向），而是偏向更陡的 $x$ 轴——`(6,2)` 明显朝东偏。**梯度是"地形感知"的：它综合了每个方向各自有多陡，把箭头弯向更陡的一侧。** 这就是"梯度 ≠ 坐标轴方向，而是合力"的最好演示。

### 实验 2：让 `num_grad` 与解析梯度在所有点对账

```python
for pt in [(1.0, 1.0), (-2.0, 3.0), (0.5, -0.5), (0.0, 0.0)]:
    gn = num_grad(f, np.array(pt))
    ga = grad_f(*pt)
    print(f"点 {pt}: 数值 {gn} 解析 {ga} 差 {np.max(np.abs(gn-ga)):.2e}")
```

输出：

```text
点 (1.0, 1.0): 数值 [2. 2.] 解析 [2. 2.] 差 0.00e+00
点 (-2.0, 3.0): 数值 [-4.  6.] 解析 [-4.  6.] 差 0.00e+00
点 (0.5, -0.5): 数值 [1. -1.] 解析 [1. -1.] 差 0.00e+00
点 (0.0, 0.0): 数值 [0. 0.] 解析 [0. 0.] 差 0.00e+00
```

任何点上数值与解析都逐分量一致。注意最后一点：谷底 $(0,0)$ 的梯度是零向量——**那里没有方向**。这正是"梯度为零 → 可能是极值点"的直接证据，也是 §3.5 里"梯度消失/卡在鞍点"问题的雏形。

## 边界声明：这套代码能做什么，不能做什么

1. **梯度是局部的第一封信。** `grad_f(1,2)=(2,4)` 只属于 $(1,2)$ 这个点。代码实验 2 展示了梯度随点变化：$(0,0)$ 处是零向量。把"梯度方向"当成"整个函数的方向"是危险的一跳——每走一步都要重新算。
2. **梯度为零 ≠ 谷底。** 实验 2 里谷底梯度为 0，但梯度为 0 也可能是峰顶或鞍点（§3.2.1 已警告）。这个脚本只证明了"谷底梯度为零"，反方向不成立。要分辨，需要二阶信息。
3. **梯度指向上升方向，训练用负梯度。** 这个脚本里 `gradient_descent` 用的是 `w - eta*grad(w)`，取的是负号。若写成 `w + eta*grad(w)`，就是往山上走，损失只会涨——这是最常见的一字之差。
4. **数值梯度是近似，解析梯度要手写。** `num_grad` 精度受 $h$ 约束（U 形曲线）；`grad_f` 是我们对这个简单函数手写求导。真实网络两者都不可行——梯度由自动微分（反向传播）计算，那是 §3.5.2 与 §3.6 的故事。这个脚本的使命是让你**亲眼看到**梯度是什么，而不是教你生产真实梯度。
