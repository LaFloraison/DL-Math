# §6.2 熵 —— 习题

本节主线把"单条惊讶"聚合成"平均惊讶"：$H(X) = -\sum_x P(x)\log_2 P(x)$。习题分三组：**概念检验** 验证熵的性质与边界，**计算实践** 手算几枚硬币与字母分布、再用代码复核（含 1 亿次模拟），**DL 延伸** 把熵放回交叉熵损失与模型自信度。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：哪个分布熵最小？

以下四个分布，熵**最小**的是（ ）。

- A. $(0.5, 0.5)$
- B. $(0.6, 0.4)$
- C. $(0.99, 0.01)$
- D. $(0.25, 0.25, 0.25, 0.25)$

**解答**：C。

熵越小，分布越"确定"（越偏斜）。C 把 99% 的概率押在一个结果上，几乎确定，熵 ≈ $0.081$ bits。A、B 是两结果分布，熵分别是 1.000、0.971；D 是均匀四等分，熵 $=\log_2 4 = 2$ bits，反而是最大的。**对比时要小心：结果个数不同不能直接比"上界"，但可以直接比熵的值。**

**思路点拨**：陷阱是"看到结果多就以为熵大"。熵不是结果个数，是"结果均匀程度的度量"。C 只有两个结果，却因为极端偏斜而熵最小；D 有四个结果，却因均匀而熵最大。判别思路：先看分布向不向一头偏——偏得越狠，熵越小；均匀得越彻底，熵越大。

### 题 2（判断 + 简答）：熵为零意味着什么？

一枚"硬币"两面的概率是 $(1.0, 0.0)$，熵为 0。有人说："熵为零，说明这个信源完全没有不确定性，也就是没有信息。" 这句话对吗？"熵为零"与"没有信息"是同一个意思吗？

**解答**：分两层。第一层对：熵为零 = 完全没有不确定性，因为 $P(x) = 1$ 的那一面**必然出现**，$\sum_x P(x)\log_2 P(x) = 0$。第二层要小心："没有不确定性"和"没有信息"在信息论的严格语汇里不是同一句话——熵 $H(X)$ 度量的是信源的平均惊讶（不确定性），它是一个信源**属性**；而"信息"常常指"减少的不确定性"（互信息，6.5 节）或"单条消息的惊讶"（自信息，6.1 节）。一个必然事件的自信息 $I = 0$，它的确不携带信息；但"熵为零"这个陈述本身，**就是一条信息**——它告诉你"这个信源完全确定"，这减少了你对信源的不确定性。所以更准确的说法是：熵为零描述的是一个"从不出人意料"的信源，它不产生信息，但它作为一条**关于信源的元信息**是有内容的。

**思路点拨**：这道题考的是"熵 vs 信息"的语汇精确性。最容易犯的错是笼统说"熵就是信息量"——严格说，熵是不确定性，自信息是单条消息的惊讶，互信息是"信息"这个词最贴切的信息论对应。主线边界声明强调"熵衡量不确定性，不是消息内容"，这里再补一刀："熵为零"≠"这句话没有意义"，它是关于信源本身的一条描述。

### 题 3（简答）：为什么熵可以大于 1，但又必须非负？

一个三结果的分布 $(0.33, 0.33, 0.34)$ 熵 ≈ 1.58 bits，大于 1。可教材又说熵"非负"。不矛盾吗？熵能无限大吗？

**解答**：不矛盾。"熵可以大于 1"指的是熵的**数值**可以超过 1 bit——只要信源的不确定性超过"二选一"的尺度：$n$ 个等可能结果的熵是 $\log_2 n$，$n$ 越大熵越大，无上限（均匀时）。"熵非负"指的是熵**永远不小于 0**：每个项 $P(x)\log_b \frac{1}{P(x)} \ge 0$（因为 $P(x) \ge 0$ 且 $\frac{1}{P(x)} \ge 1$ 使对数为非负），总和也非负。两者合起来是 $0 \le H(X) \le \log_2|\mathcal{X}|$——下有界（0）、上有界（均匀分布的对数结果数）。"大于 1"是正常状态，不是错误；0 才是下界，只有完全确定时达到。

**思路点拨**：把"比特"想成一把可以无限加长的尺子就不会困惑——1 bit 是"二选一"的惊讶量，十选一就是 $\log_2 10 \approx 3.32$ bits，尺子读数当然可以超过 1。困惑往往来自"比特 = 一位二进制数"的直觉：那说的是**等长编码**里一位能装 1 bit，而**熵**是信源平均惊讶，可以累积成任意大。6.6 节你会看到：熵多大，压缩就至少要花那么多位。

## 二、计算实践

### 题 1（偏硬币手算 + 代码验证）

一枚偏硬币 $P(H) = 0.75$。

(a) 手算熵 $H(X)$（$\log_2$，保留 3 位）。
(b) 掷 100 万次，用频率估计熵，验证逼近手算值。
(c) 如果这枚硬币被换成公平硬币，熵变化多少？

**解答**：

(a) $H = -(0.75\log_2 0.75 + 0.25\log_2 0.25)$。$\log_2 0.75 = \log_2\frac{3}{4} \approx -0.415$，$\log_2 0.25 = -2$。于是 $H = -(0.75\times(-0.415) + 0.25\times(-2)) = 0.311 + 0.5 = 0.811$ bits。

(b) 代码（§6.2《代码.md》的 `entropy`）：
```python
import numpy as np
def entropy(probs, base=2):
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

n = 1_000_000
flips = np.random.choice([0, 1], size=n, p=[0.75, 0.25])
freq = np.bincount(flips) / n
print(freq)                  # 约 [0.7502, 0.2498]
print(entropy(freq))         # 约 0.811
```
频率逼近 $(0.75, 0.25)$，熵逼近 0.811 bits。

(c) 公平硬币熵 1.000 bits，从偏硬币到公平硬币，熵增加 $1.000 - 0.811 = 0.189$ bits。

**思路点拨**：(a) 是熵公式的直接代入，唯一容易错的是符号——负号在最外层，每一项是"$-P(x)\log P(x)$"的累加。核对方法：把 $\log$ 值代进去时逐项写正负。(c) 提醒一个直觉锚点：**偏得越狠，熵越偏离 $\log_2 n$ 的天花板**。$n=2$ 的天花板是 1 bit，0.75/0.25 离天花板只差 0.189 bits——可见"两结果"时哪怕偏到 75%，熵也没降多少；要熵急剧下降，得偏到 0.9 以上（6.2 节表格里 0.9/0.1 只剩 0.469）。

### 题 2（字母分布：英语的频率不对称）

一段英文文本中五个字母的频率是 "e": 0.28, "a": 0.21, "t": 0.17, "s": 0.19, "z": 0.15（和为 1.0）。

(a) 手算或写代码算熵（3 位小数）。
(b) 如果五个字母**等概率**，熵是多少？谁大？
(c) 这段英文的熵比均匀分布低了多少，说明了什么？

**解答**：

(a) 
$$H = -\big(0.28\log_2 0.28 + 0.21\log_2 0.21 + 0.17\log_2 0.17 + 0.19\log_2 0.19 + 0.15\log_2 0.15\big)$$
逐项：$0.28\times1.836=0.514$，$0.21\times2.252=0.473$，$0.17\times2.556=0.435$，$0.19\times2.396=0.455$，$0.15\times2.737=0.411$。总和 $= 2.288$，即 $H \approx 2.288$ bits。
（代码：`entropy([0.28,0.21,0.17,0.19,0.15])` → `2.288`）

(b) 等概率时 $H = \log_2 5 \approx 2.322$ bits。均匀分布的熵更大。

(c) $2.322 - 2.288 = 0.034$ bits——这段"偏科"的字母分布只比均匀低了 0.034 bits，说明五个字母的频率差得不多，可压缩的空间很小。**频率越不均匀，熵越低，无损压缩能省的平均位数越多**——这正是 6.6 节 Huffman 编码的依据：高频字母给短码、低频给长码，平均码长由熵贴着往下走。

**思路点拨**：(b) 是"均匀分布熵最大"的直接应用。真正有价值的是 (c) 的解读方向：**熵 = 压缩难度的下限**。熵 2.288 bits 意味着五个字母无损编码平均至少要 2.288 位；等概率时 2.322 位。别小看 0.034 bits 的差距——在英语的真实字母分布里（'e' 约 12.7%、'z' 约 0.07%），熵被压到约 4.1 bits/字母（26 个字母等概率是 $\log_2 26 \approx 4.7$），这就是为什么英文文本能压缩、zip 能省空间。

### 题 3（三结果：上界与直觉对照）

分布 $P = (0.5, 0.3, 0.2)$。

(a) 算熵。
(b) 这个分布有三个结果，它的熵比上界 $\log_2 3$ 低多少？换成 $(0.8, 0.1, 0.1)$ 呢？

**解答**：

(a) $H = -(0.5\log_2 0.5 + 0.3\log_2 0.3 + 0.2\log_2 0.2) = 0.5 + 0.3\times1.737 + 0.2\times2.322 = 0.5 + 0.521 + 0.464 = 1.485$ bits。

(b) 上界 $\log_2 3 \approx 1.585$ bits。$(0.5,0.3,0.2)$ 低了 $1.585-1.485 = 0.100$ bits；$(0.8,0.1,0.1)$ 的熵 $= 0.8\times0.322 + 0.1\times3.322 + 0.1\times3.322 = 0.258+0.332+0.332 = 0.922$ bits，低 $1.585-0.922 = 0.663$ bits。

**思路点拨**：上界 $\log_2 3$ 是"完全拿不准三选一"时的惊讶量。分布越向一头倾斜，离上界越远。$(0.8,0.1,0.1)$ 离上界 0.663 bits，而 $(0.5,0.3,0.2)$ 只差 0.100——直观上 0.8/0.1/0.1 你已经很有底（八成押第一个），0.5/0.3/0.2 还相当犹豫。熵把这份"心里的底"标成了数字。

## 三、DL 延伸

### 题 1（交叉熵损失 vs 熵：多花的钱在哪）

训练一个 10 类分类器。某个样本真实标签是第 3 类（独热 $p$：第 3 类为 1，其余 0），模型输出 $q$。试问：

(a) 交叉熵损失 $\mathrm{H}(p, q) = -\sum_x p(x)\log_2 q(x)$ 在这个样本上化简成什么？
(b) 如果模型在正确类别上输出 $q_3 = 0.5$，损失是多少比特？如果 $q_3 = 0.95$ 呢？
(c) 熵 $H(p) = 0$（独热分布没有不确定性）。为什么交叉熵损失不是 0？

**解答**：

(a) 独热分布里只有 $p(3)=1$ 一项非零，求和只剩一项：$\mathrm{H}(p,q) = -\log_2 q(3)$。

(b) $q_3=0.5$ → 损失 $-\log_2 0.5 = 1$ bit；$q_3=0.95$ → $-\log_2 0.95 \approx 0.074$ bits。**模型越押中正确类别，损失越小。**

(c) 熵 $H(p)=0$ 说的是"用**真实**分布编码真实标签的成本是 0"（真实标签毫无不确定性）；但交叉熵用的是**模型分布 $q$** 去编码——模型不确定，就得为这种不确定性额外付费。差价正是 KL 散度：$\mathrm{D}_{\mathrm{KL}}(p\|q) = H(p,q) - H(p) = H(p,q) - 0 = -\log_2 q(3)$。训练就是反复降低这个差价，让 $q$ 逼近 $p$。

**思路点拨**：这道题把熵、交叉熵、KL 散度三兄弟一次摆清。记忆锚点：**熵 = 用真实分布编码真实分布（最优成本）；交叉熵 = 用模型分布编码真实分布（实际成本）；KL = 差价（实际-最优）**。为什么训练用交叉熵不用熵？因为真实分布 $p$ 是固定目标（独热标签），$\mathrm{H}(p,q)$ 里唯一能动的是 $q$——最小化交叉熵就是让 $q$ 逼近 $p$。若误用"熵最小化"当目标就荒谬了：模型永远无法改变标签的熵。

### 题 2（模型的"自信度仪表盘"）

工程师训练一个 100 类分类器，想监控模型是否在"瞎猜"。他想到了熵：记录验证集上每个样本模型输出的熵 $\mathrm{H}(q)$，取平均。

(a) 模型"完全瞎猜"时（输出均匀分布 $q(x)=\frac{1}{100}$），熵是多少比特？
(b) 训练后期，平均熵从 4.3 bits 降到 2.1 bits，说明什么？
(c) 这个监控有什么局限？

**解答**：

(a) 均匀分布 $q(x) = \frac{1}{100}$，熵 $=\log_2 100 \approx 6.64$ bits。这是熵的**上界**——"完全瞎猜"时熵最大。

(b) 熵从 4.3 降到 2.1，说明模型的输出分布越来越尖（越来越集中押在少数类别上）——它正在学会"拿不准时不平均地赌"，预测越来越有底气。但注意：**熵下降不等于正确率上升**，它只反映"自信度"上升。

(c) 局限有三：①熵衡量的是**自信度**，不是**正确率**——一个全错但自信的模型熵也很低（这正是 6.1 节"自信却错误"的信息论版本）；②平均熵抹掉了样本间的差异，两个模型可能有相同平均熵、却一个在 A 类自信、一个在 B 类自信；③小 batch 下熵估计有噪声（见《代码.md》边界声明第三条）。所以熵是"仪表盘"，不是"判决书"——它该和准确率、校准曲线一起看。

**思路点拨**：这道题考的是"熵作为模型属性的解释边界"。最常见的错误是把"熵低"误读为"模型好"。判别句：**熵低 = 模型对它的预测拿得准（或盲目自信），不代表它预测得对。** 更精确的"预测有多对"是校准（calibration），那是另一个量。把熵想成"模型的语气"，而不是"模型的成绩"——语气坚定不等于答案正确。
