# 参考资料：欠拟合与贝叶斯统计

- *Mathematical Foundations for Deep Learning* (Ghayoumi, 2026)，§4.4.2 Underfitting and Bayesian Statistics，PDF 第 129-131 页（教材页码 116-118）。
- 图 4.10：欠拟合的橙色直线（低次多项式）vs 贝叶斯模型的蓝色后验样本带（实线均值 + 不确定性）——真值曲线为绿色虚线，灰色散点为带噪数据。

## 延伸论文

1. **Estimation with Quadratic Loss**（James & Stein, 1961）——詹姆斯-斯坦估计的原始论文："收缩反而更准"的悖论出处，也是"借用强度"的理论根源。读它，你会理解为什么数据少的组向共同中心靠拢不是直觉的妥协，而是数学的必然。
2. **Bayes Estimates for the Linear Model**（Lindley & Smith, 1972）——层级模型的奠基论文：参数的参数、先验的先验。把"借用强度"从悖论升格为一套可构造的建模工具，正是本节"层级模型"的源头。
3. **Simple and Scalable Predictive Uncertainty Estimation using Deep Ensembles**（Lakshminarayanan et al., 2017）——深度学习里画出图 4.10 那条"不确定性带"的廉价方法，把贝叶斯的"后验样本"变成可扩展的工程。

## 代码库/工具

- NumPy：`np.vander` / `np.linalg.solve` / `np.random.default_rng` —— 本课代码的零件（设计矩阵、岭回归、合成数据）。
- scikit-learn：`PolynomialFeatures` + `Ridge`（带 λ 的多项式回归）、`RidgeCV`（自动调 λ）、`MultiTaskLasso`（多任务共享稀疏结构）。
- PyMC / Stan / TensorFlow Probability：真正的层级贝叶斯建模（多组参数 + 超先验）。PyMC 的 `pm.Normal` 嵌套声明、`tfp.distributions` 都是"参数的参数"的直译。
- PyTorch：`optimizer.SGD(weight_decay=λ)` —— λ 就是先验强度旋钮；多任务网络的共享骨干 + 任务头是"上层结构 + 组参数"的工程形态。

## 推荐阅读

- *Statistical Rethinking*（Richard McElreath）第 12-13 章——多层级模型（multilevel models）的教科书级讲解，"借用强度 / 收缩"的直觉与可复现代码并重。
- *Data Analysis Using Regression and Multilevel/Hierarchical Models*（Gelman & Hill, 2006）——层级模型的经典应用读物，覆盖"数据少的组如何借力"的完整处理。
- 3Blue1Brown 的 Bayes 主题视频 或 Distill.pub 的不确定性可视化——把"后验分布"画成一条带子，直击图 4.10 的直观感受。
