# 习题：欠拟合与贝叶斯统计

## 第一组：概念检验

**1. 贝叶斯统计对抗欠拟合的两件武器是什么？各自解决什么问题？**

**解答**：**层次模型 (hierarchical model)**——让参数来自更高层分布（组间承认差异 + 组内借力），动态调整复杂度，数据少的组借整体之力补足；**可调整的先验**——过度限制的先验会导致欠拟合，解法是把先验放宽（更不具信息）或用专家知识选择合理的先验。**一个解决"模型结构抓不住差异"，一个解决"先验压得太死"。**

**2. 用"借力 (borrowing strength)"解释：为什么数据少的组，其估计既像它自己又像整体？**

**解答**：层次模型的每组成员参数 $\theta_g$ 来自上层分布 $\mathcal{N}(\mu,\sigma^2)$。数据多的组，后验由该组数据主导（自由——估计贴自己的样本均值）；数据少的组，后验被上层均值"收缩"拉向 $\mu$（借力——估计向整体靠拢）。教材例子：3 个学生的班的估计 61.23 被拉向整体 69.9 → 63.74。**借力让数据稀缺组不孤军奋战，又不完全抛弃自身特征。**

**3. 判断题并说明理由："先验越强，防欠拟合的效果越好。"**

**解答**：错误，方向完全反了。先验**过强**（过度限制）会把模型压得太简单、抓不住数据变异——**这正是欠拟合的一个原因**（教材明说）。先验越强越容易欠拟合；防欠拟合需要"把先验放宽"（适应性）。先验的作用是双面的：太弱防不了过拟合（§4.4.1）、太强制造欠拟合（本节）——**强度要拧在"恰好够用"的位置。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 5 个班真实水平 80/75/70/65/60，最后一个班只有 3 人（样本均值 61.23）。（a）全局平均是多少？为什么它是"欠拟合"？（b）用收缩公式 $\theta_g=\frac{n_g\bar y_g+\tau\mu}{n_g+\tau}$（$\tau=5$）算最后一个班的层次估计。（c）数据多的班（200 人）的层次估计如何？

**解答**：
（a）全局平均约 69.93——把 80 和 60 的班都抹平成 69.93，**不承认班间差异**，这是"太简单模型"的欠拟合。
（b）$\theta_{few}=\frac{3\times61.23+5\times69.93}{3+5}=\frac{183.69+349.65}{8}\approx66.7$（与《代码.md》的 63.74 略有差异因随机种子不同）——**从 61.23 被拉向整体 69.9**。
（c）$\theta_{many}=\frac{200\times80.11+5\times69.93}{205}\approx80.06$——几乎等于样本均值，**数据多的组自由**。

代码验证：

```python
import numpy as np
np.random.seed(0)
true = np.array([80.,75,70,65,60]); ns = [200,200,200,200,3]
data = [np.random.normal(m,5,n) for m,n in zip(true,ns)]
mu = np.mean(np.concatenate(data)); tau = 5.0
for g in (4, 0):   # 数据少(3人) 与 数据多(200人)
    th = (len(data[g])*np.mean(data[g]) + tau*mu) / (len(data[g])+tau)
    print(f"班{g+1}: 样本均值={np.mean(data[g]):.2f} → 层次估计={th:.2f}")
```

输出：

```text
班5: 样本均值=61.23 → 层次估计=63.74
班1: 样本均值=80.11 → 层次估计=80.06
```

**思路点拨**：若有人答"全局平均 69.93 已经够用"，他忽略了它抹平了 80 与 60 的差异（欠拟合）。若有人困惑"为什么借力是对的"，教材的答案：**数据稀缺时，借整体的信息比信 3 个学生更稳**——詹姆斯-斯坦的收缩理论保证这点（见《代码.md》实验）。

**5. 借力精度实验。** 用代码比较"数据只有 3 个时，独立估计 vs 层次估计"谁更接近真值 60，验证"借力在数据稀缺时更准"。

**解答**：见《代码.md》"改个数字试试"。独立估计平均误差 2.89、层次估计 2.10——**借力在数据稀缺时显著更准**。这是詹姆斯-斯坦"收缩反而更准"的微观演示，也是教材"借力改善稀疏数据组估计精度"的数值证据。

## 第三组：DL 延伸

**6. 多任务学习场景。** 你要同时训练 10 个相关的文本分类任务，其中"法律文书分类"只有 200 条数据（其他任务各有数万条）。（a）用层次模型的"借力"解释为什么共享底层表示能帮法律任务。（b）如果 10 个任务其实互不相关，共享会怎样？（c）与联邦学习、迁移学习的关系。

**解答**：
（a）共享底层表示 = 上层结构（组间共同性）；每个任务的头部 = 组参数。法律任务数据少，它的头部参数被"上层结构 + 其他任务借来的表示"拉向合理位置——**数据多的任务（新闻、评论）教会底层表示，法律任务搭便车**。这正是"数据少的组借整体之力"。
（b）若任务互不相关，共享底层表示 = 错误的"借力"——上层结构把本不相干的任务"拉平"，反而伤害各自表现（负迁移）。**借力的前提是"组间有共同结构"**（§4.4.2 边界声明），前提错了就变成压制。
（c）三者同源：**联邦学习**的全局模型聚合是"上层均值"，客户端本地更新是"组参数"，全局聚合起着借力作用；**迁移学习**的预训练权重是"强上层先验"，下游小数据被拉向它。**"共享结构 + 组内借力"是层次模型的现代形态。**
**思路点拨**：若有人答"共享表示越多越好"，他忽略了负迁移——任务不相关时共享是有害的。若有人答"多任务就是多训练几个模型"，那是"独立估计"，丢掉了"借力"的核心价值——**共享 + 借力，才是层次模型给多任务的东西**。
