# 习题：欠拟合与贝叶斯统计

## 第一组：概念检验

**1. 用"偏差 / 方差"的语言，欠拟合和过拟合各是什么？如何从训练集 / 测试集的误差判断一个模型正在欠拟合？**

**解答**：欠拟合是模型太简单、抓不住数据结构——**偏差大、方差小**：给任何一组数据，它都给出几乎相同、却系统性偏离真相的曲线（直线拟合弧线）。过拟合是模型太复杂、背下了噪声——**方差大、偏差小**：换一组数据，它的形状就大变。判断上：欠拟合时**训练集和测试集都差**（学不进）；过拟合时**训练好、测试差**（学过头）。**思路点拨**：若有人答"欠拟合是训练差、测试好"，那是把欠拟合和过拟合的判据记反了。关键看**训练误差**：欠拟合的训练误差本身就高——因为模型在训练数据上都学不进，这是它和过拟合最本质的差别。

**2. 判断题并说明理由："一个模型欠拟合，说明它参数太少、模型太小。所以解决欠拟合就是不断加大模型复杂度。"**

**解答**：错误，两处都不对。第一，欠拟合不一定是因为参数少——一个 9 阶多项式（10 个参数）在**过度限制的先验**下，照样退化成直线（欠拟合）：模型有没有容量是一回事，**先验允不允许它使用容量**是另一回事。第二，无节制加复杂度立刻滑向过拟合——偏差小了、方差爆了。贝叶斯的答案是"按数据把复杂度调对"，不是"越大越好"。**思路点拨**：若有人选"先验越强越防欠拟合"，方向完全反了——教材明说欠拟合的常见原因是"过度限制的先验"，防欠拟合恰恰要**把先验放宽（适应性）**。

**3. 贝叶斯统计对抗欠拟合给了哪两件工具？各自对应"复杂度旋钮"的哪个方向？**

**解答**：① **层级模型 (hierarchical model)**——"参数的参数"：各组参数共享一个父分布，数据多的组自由、数据少的组被拉向共同中心（借用强度 borrowing strength），复杂度**按数据量动态调节**，不靠拍脑袋定"几次多项式"。② **适应性 (adaptability)**——先验可修订：若初始先验太强导致欠拟合，就把先验改弱（更大方差、less informative）或调整到更能反映数据分布；同时可用**专家知识**选先验，在数据稀缺领域用知识补足样本。**一个管"结构"，一个管"先验强度"，两个方向都指向同一条线：复杂度不该被手工钉死。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 两所学校的成绩数据。学校 B 只有 3 个点：$(1, 3.0),(2, 4.2),(3, 5.5)$；学校 A 有 5 个点：$(1, 2),(2, 4),(3, 6),(4, 8),(5, 10)$（恰好沿直线 $y=2x$）。两组数据的真实斜率都是 2.0。（a）**手算** B 组独立拟合的直线斜率；（b）把两组**合并**成 8 个点再拟合，斜率大约多少？（c）用代码验证，并解释"借用强度"如何把 B 拉回真值附近。

**解答**：
（a）B 组 $\bar x=2,\ \bar y=(3.0+4.2+5.5)/3=4.2333$。斜率
$$b_B=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}
=\frac{(-1)(3.0-4.2333)+(0)(0)+(1)(5.5-4.2333)}{1+0+1}
=\frac{2.5}{2}=1.25$$
B 独立拟合给出斜率 **1.25**——离真值 2.0 差了 0.75，因为 3 个点的噪声把它带偏了。
（b）合并 8 个点（含 A 的 5 个完美点）后，斜率被拉向 A 的方向，约 **1.86**（真值 2.0 只差 0.14）。A 数据多，在合并拟合里话语权大，B 借了 A 的力量。
（c）代码验证：

```python
import numpy as np
xA = np.array([1., 2, 3, 4, 5]); yA = 2*xA          # A组5点，完美 y=2x
xB = np.array([1., 2, 3]); yB = np.array([3.0, 4.2, 5.5])
def slope(x, y):                                     # 最小二乘斜率
    return np.sum((x-x.mean())*(y-y.mean()))/np.sum((x-x.mean())**2)
print(f"B组独立斜率 = {slope(xB, yB):.3f}")
X = np.concatenate([xA, xB]); Y = np.concatenate([yA, yB])
print(f"合并8点斜率 = {slope(X, Y):.3f}")
```

输出：

```text
B组独立斜率 = 1.250
合并8点斜率 = 1.860
```

**思路点拨**：若有人答"B 独立 1.25 已经很准了"，注意真值 2.0——3 个点带噪声时独立估计的**方差**很大，一次碰巧接近、换一组 3 个点就偏很远（《代码.md》演示③ 的 1.39 就是另一个"瞎猜"值）。借用强度（把 B 拉向全组合并趋势）降低的是这种方差——**数据越少，借力越重要**。这是詹姆斯-斯坦"收缩反而更准"的微观形态。若有人把"合并拟合"当成"层级模型"，提醒：合并是借用强度的**方向演示**，完整的层级后验是用精度加权把 B 的估计**收缩**向共同中心（主线公式），B 点越少收缩越狠。

**5. 先验强度实验。** 对同一批 U 形数据（$y_{true}=0.3x^2-0.5$ 加噪声），用 9 阶多项式分别设 $\lambda=10^{-10}, 5, 10^{10}$，打印每个 $\lambda$ 的 MSE（对真值），并标注三档各自对应过拟合 / 恰到好处 / 欠拟合，解释为什么 $\lambda=10^{10}$ 的 MSE 反而比 $\lambda=5$ 高一倍还多。

**解答**：运行《代码.md》层一脚本的演示②，输出：
$$\lambda=10^{-10}\rightarrow 0.107,\quad \lambda=5\rightarrow 0.046,\quad \lambda=10^{10}\rightarrow 0.891$$
$\lambda=10^{-10}$ 是弱先验：9 次多项式追着噪声抖（过拟合），比最优差一倍多；$\lambda=5$ 适中：高次项被温和压向 0，恰好留下真实曲线（恰到好处）；$\lambda=10^{10}$ 是过强先验：全部 10 个系数被按在 0 附近，9 阶模型实际塌成平线 $y\approx0$（欠拟合）。$\lambda=10^{10}$ 的 0.891 比演示① 中"老老实实的直线"的 0.719 还高——**过度限制的先验比本来就简单的模型更糟**：它既不弯，还顶着"我很复杂"的名头。
**思路点拨**：若有人答"λ 越大正则化越强、越防欠拟合"，他把"防过拟合"和"防欠拟合"混成一件事了。正则化（先验）是双刃：太弱防不了过拟合，**太强制造欠拟合**。$\lambda$ 对应的高斯先验 $w\sim\mathcal{N}(0,\frac{1}{2\lambda}I)$（§4.2.6.1）里，λ 大 = 先验方差小 = 信念过强。**先验的强度要配得上证据，不是越大越好。**

## 第三组：DL 延伸

**6. 训练诊断场景。** 你在 CIFAR-10 上训练一个 20 层的 ResNet，观察到的曲线是：训练 loss 和验证 loss 都很高，而且都几乎不下降；loss 没有振荡、没有在训练后期回升。你怀疑模型欠拟合。（a）用贝叶斯的语言，weight_decay 在这里扮演什么角色？把 λ 调大能解决这个问题吗？（b）除了调 λ，还有哪些与本节概念直接相关的排查方向？

**解答**：
（a）weight_decay 就是高斯先验 $w\sim\mathcal{N}(0,\frac{1}{2\lambda}I)$ 的强度（§4.2.6.1）。如果当前 λ 偏大，它会把所有权重按在 0 附近——一个明明够宽的网络"有容量而不敢用"，训练 loss 高居不下，**这正是"过度限制的先验导致欠拟合"**。此时把 λ **调小**（先验改弱、更 less informative）才是教材"适应性"工具的用法——**λ 大不是解药，调对才是**。调整后观察训练 loss 是否开始下降。
（b）按本节概念排查：① 模型容量——若 20 层对任务太小（模型族表达力不足），再调先验也救不了，要加容量（对应边界声明"模型族错了"）；② 训练充分性——欠拟合的"训练也差"也可能是没训够，延长训练或调学习率；③ 数据/标签质量——若训练集本身噪声巨大，模型"学不进"不是因为太简单。**先看模型族对不对，再看先验强不强，最后才怀疑数据。**
**思路点拨**：若有人诊断"训练 loss 高 = 过拟合，赶紧加大 weight_decay"，那是误判——过拟合的标志是"训练好、验证差"，而这里两条曲线都高，是欠拟合（学不进），加 λ 只会更糟。**判别欠拟合 vs 过拟合，第一眼看训练误差。**

**7. 多任务学习场景。** 你同时训练 10 个相关的文本分类任务，其中"法律文书分类"只有 200 条数据，其余任务各有数万条。（a）用层级模型"借用强度"的语言，解释共享底层表示为什么能帮法律任务避免欠拟合；（b）如果这 10 个任务其实互不相关，共享表示会怎样？（c）这套思想和迁移学习、联邦学习是什么关系？

**解答**：
（a）共享底层表示 = 层级模型里的"上层结构"（共同中心 $\mu_w$），每个任务的头部 = 组参数。法律任务数据少（$\tau_g$ 小），它的头部参数被"共享表示 + 其他任务借来的信息"拉向合理位置——**数据多的任务（新闻、评论）教会底层表示，法律任务搭便车**，不至于因为 200 条数据而退化成一条没道理的"直线"（欠拟合）。这正是"数据少的组从数据多的组借力"。
（b）若任务互不相关，共享表示 = 错误的借用——上层先验把本不相干的任务"拉平"，反而伤害各自表现（**负迁移**）。借用强度的前提是"各组共享同一父分布"（主线边界声明），前提错了，借力就变成污染。
（c）三者同源：**迁移学习**的预训练权重是"强先验中心 $\mu_w$"，下游小数据被轻轻拉向它——防下游欠拟合；**联邦学习**的全局聚合 = "上层均值"，客户端本地更新 = "组参数"，全局模型替小数据客户端借力。**"共享结构 + 组内借力"是层次模型在深度学习里的三个名字。**
**思路点拨**：若有人答"共享表示越多越好"，他忽略了负迁移——任务不相关时共享有害，先验的"一家人"假设不成立。若有人答"多任务 = 各任务独立训多个模型"，那是"独立估计"——丢掉了借力的核心价值：**独立估计在数据稀缺时方差巨大，这正是借用强度要补的洞。**
