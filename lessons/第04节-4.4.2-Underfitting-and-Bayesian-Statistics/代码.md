# 代码：欠拟合与贝叶斯统计——三个实验看清"复杂度旋钮"

主线里我们把欠拟合讲成一句话：**模型有多复杂，不该是拍脑袋定的次数，而该是数据更新出来的先验强度。** 本课用代码做三件事：

1. **演示① 欠拟合的现场**：用一条直线（1 阶多项式）去拟合 U 形弧线，量它对真实函数的偏差——直线"错得稳定"。
2. **演示② 先验强度 = 复杂度旋钮**：同一个 9 阶模型，只改正则化强度 λ（= 高斯先验的强弱），误差走过"过拟合 → 恰到好处 → 欠拟合"三档——尤其要看到 **λ 过大把模型压成平线（过度限制的先验导致欠拟合）**。
3. **演示③ 借用强度 (borrowing strength)**：A 组数据多、B 组只有 3 个点，比较"B 独立拟合"与"合并拟合"的斜率——数据少的组从数据多的组借力。

---

## 层一：完整脚本

```python
import numpy as np

def gen_data(seed=0, n=40):
    """合成 U 形真实函数 + 高斯噪声。"""
    rng = np.random.default_rng(seed)
    x = np.linspace(-3, 3, n)
    y_true = 0.3*x**2 - 0.5
    return x, y_true + rng.normal(0, 0.6, n), y_true

def fit_poly(x, y, d, lam):
    """d 阶多项式 + 高斯先验(ridge)的最小二乘。"""
    X = np.vander(x, d+1, increasing=True)
    w = np.linalg.solve(X.T@X + lam*np.eye(d+1), X.T@y)
    return w, X@w

def mse(a, b):
    """均方误差。"""
    return float(np.mean((a-b)**2))

# ① 欠拟合：1 阶直线拟合 U 形弧线
x, y, y_true = gen_data()
_, p_lin = fit_poly(x, y, 1, 0.0)
print(f"① 直线(1阶)拟合弧线: MSE={mse(p_lin, y_true):.3f}")

# ② 先验强度 = 复杂度旋钮：9 阶模型 + 不同 λ
for lam in (1e-10, 5.0, 1e10):
    _, p = fit_poly(x, y, 9, lam)
    print(f"② λ={lam:>8g}  9阶 MSE={mse(p, y_true):.3f}")

# ③ 层级/借用强度：A 组数据多、B 组只有 3 个点
x2 = np.linspace(0, 1.8, 10)
yA = 2.0*x2 + np.random.default_rng(1).normal(0, 0.3, 10)
xB = np.array([0.1, 0.5, 0.9]); yB = 2.0*xB + np.random.default_rng(3).normal(0, 0.3, 3)
wB, _ = fit_poly(xB, yB, 1, 0.0)
wAll, _ = fit_poly(np.concatenate([x2, xB]), np.concatenate([yA, yB]), 1, 0.0)
print(f"③ B独立斜率={wB[1]:.2f}   合并(借用A组)={wAll[1]:.2f}   真值≈2.0")
```

运行输出（Python 3.11 + NumPy 2.3）：

```text
① 直线(1阶)拟合弧线: MSE=0.719
② λ=   1e-10  9阶 MSE=0.107
② λ=       5  9阶 MSE=0.046
② λ=   1e+10  9阶 MSE=0.891
③ B独立斜率=1.39   合并(借用A组)=1.96   真值≈2.0
```

第一眼：① 直线对弧线的 MSE=0.719——一个"只会画直线"的模型被 U 形数据甩开。② 三档 λ 从 0.107 降到 0.046 再飙到 0.891——**同一个模型，只是先验强弱不同，就从过拟合走到恰到好处再跌进欠拟合**；注意 λ=1e10 的 0.891 比演示① 的 0.719 还糟，说明"过度限制的先验"比"老老实实的直线"更僵。③ B 只有 3 个点、独立拟合出斜率 1.39（离真值 2.0 差了 0.6），合并后 1.96（差 0.04）——**借力把它拉回了真相附近**。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入并定义三个工具函数

```python
import numpy as np

def gen_data(seed=0, n=40):
    rng = np.random.default_rng(seed)
    x = np.linspace(-3, 3, n)
    y_true = 0.3*x**2 - 0.5
    return x, y_true + rng.normal(0, 0.6, n), y_true

def fit_poly(x, y, d, lam):
    X = np.vander(x, d+1, increasing=True)
    w = np.linalg.solve(X.T@X + lam*np.eye(d+1), X.T@y)
    return w, X@w

def mse(a, b):
    return float(np.mean((a-b)**2))
```

#### `import numpy as np` —— 工具导入

**操作**：加载 NumPy，绑定别名 `np`。
**对应数学**：为矩阵乘法（`@`）、求解线性方程组（`np.linalg.solve`）、平方求均值（`np.mean`）提供执行者。

#### gen_data —— 合成"上帝视角"的数据

**做什么**：造一条 U 形真实函数，叠上高斯噪声，同时返回无噪声的真值。

```python
rng = np.random.default_rng(seed)
x = np.linspace(-3, 3, n)
y_true = 0.3*x**2 - 0.5
return x, y_true + rng.normal(0, 0.6, n), y_true
```

**操作**：`np.linspace(-3, 3, n)` 在 $[-3,3]$ 上取 n 个等距点；`y_true = 0.3x^2-0.5` 是真实函数（山谷弧线）；`rng.normal(0, 0.6, n)` 造 n 个均值 0、标准差 0.6 的高斯噪声叠上去。
**输入**：`seed`（随机种子，默认 0）、`n`（样本数，默认 40）。
**输出**：三个**形状 `(40,)` 的一维数组**——`x`（采样点）、`y`（带噪观测）、`y_true`（无噪真值）。
**可调参数**：`seed` 换一个数得到另一组噪声；`n` 改大更密。还可以直接改 `0.3`/`-0.5`（真实曲线的弯曲度和高度）或 `0.6`（噪声大小）——这正是后面"模型离真相多远"的参照系。
**对应数学**：这是教材 Figure 4.10 的思路——先造一条已知的真值曲线（图里的绿色虚线），再量"模型离真值有多远"。现实里你看不到真值，这里是"上帝视角"的仿真。

#### fit_poly —— 带高斯先验的最小二乘（岭回归）

**做什么**：对 d 阶多项式做带 L2 惩罚的最小二乘，返回系数和拟合值。

```python
X = np.vander(x, d+1, increasing=True)
w = np.linalg.solve(X.T@X + lam*np.eye(d+1), X.T@y)
return w, X@w
```

**操作**：`np.vander(x, d+1, increasing=True)` 把 x 展开成设计矩阵 X（**形状 `(n, d+1)`**，第 j 列就是 $x^j$，j=0..d）；然后解岭回归的正规方程 $(X^\top X + \lambda I)w = X^\top y$；`np.linalg.solve` 直接求解这个线性方程组，得到系数向量 w；`X@w` 再乘回去得到拟合值。
**输入**：`x`（`(n,)`）、`y`（`(n,)`）、`d`（多项式阶数）、`lam`（正则化强度）。
**输出**：`w`（**形状 `(d+1,)`**，w[0] 是常数项、w[j] 是 $x^j$ 的系数）、预测数组（**`(n,)`**）。
**可调参数**：`d` 和 `lam` 是本课的两个核心旋钮——`d` 是"模型家族的大小"，`lam` 是"先验的强弱"。
**对应数学**：$w\sim\mathcal{N}(0,\frac{1}{2\lambda}I)$ 的高斯先验下，MAP 解就是岭回归（§4.2.6.1 先验 = 正则化的等价式）。**λ 越大 = 先验越强 = 权重越被按向 0。**

#### mse —— 均方误差

**做什么**：两个同形状数组的均方误差，把结果转成 Python 标量。

```python
return float(np.mean((a-b)**2))
```

**操作**：逐元素相减、平方、求平均。
**输入**：两个 `(n,)` 数组。
**输出**：一个 `float` 标量。
**可调参数**：没有参数，但你可以自己再加一个返回 `np.sqrt(mean(...))` 的 `rmse`（均方根误差）——量纲更直观。
**对应数学**：对真值 $y_{true}$ 与预测 $\hat f$ 算 $\frac1n\sum_i(\hat f(x_i)-f(x_i))^2$——这正是主线"偏差-方差分解"里左边那个量。

### 步骤 2：演示① —— 欠拟合的现场（直线对弧线）

```python
x, y, y_true = gen_data()
_, p_lin = fit_poly(x, y, 1, 0.0)
print(f"① 直线(1阶)拟合弧线: MSE={mse(p_lin, y_true):.3f}")
```

**做什么**：用 1 阶多项式（直线，只有 2 个参数）拟合 U 形数据，量它对真值的 MSE。
**操作**：`fit_poly(x, y, 1, 0.0)`——`d=1` 是直线，`lam=0.0` 是无先验（纯最小二乘，让直线尽最大努力）。`p_lin` 是 `(40,)` 的直线预测。
**输出**：`MSE=0.719`。对比步骤 3 的最优 0.046——**直线离真相约 15 倍远**。直线没有"弯"的自由度，无论怎么拧都错得稳定：谷底高悬、谷壁切土。这就是欠拟合：**偏差主导**（噪声那部分 σ²≈0.36 还没算进去，0.719 几乎全是"系统的偏"）。
**可调参数**：把 `d` 改成 `2`，MSE 立刻掉到约 0.02——2 阶多项式正好能表达 U 形；改成 `9`（无先验）则开始追噪声（见步骤 3 第一档）。
**对应数学**：主线"欠拟合 = 偏差大、方差小"——给一百组新数据，直线都给出几乎同样的错误。

### 步骤 3：演示② —— 先验强度 = 复杂度旋钮

```python
for lam in (1e-10, 5.0, 1e10):
    _, p = fit_poly(x, y, 9, lam)
    print(f"② λ={lam:>8g}  9阶 MSE={mse(p, y_true):.3f}")
```

**做什么**：**同一个 9 阶模型**，只改 λ，看 MSE 如何走过三档。
**操作**：λ 从 $10^{-10}$ 到 $10^{10}$，每次 `fit_poly(x, y, 9, lam)`。9 阶模型有 10 个系数，理论上弯得起任何蛇——但 λ 决定它敢不敢弯。
**输出**：
- `λ=1e-10`（弱先验）→ **0.107**：先验几乎不存在，9 次多项式追着每个噪声点抖（过拟合），比最优差一倍多。
- `λ=5`（适中）→ **0.046**：高次项被温和压向 0，恰好留下真实曲线（恰到好处）。
- `λ=1e10`（强先验）→ **0.891**：先验把所有系数死死按在 0 附近，9 阶模型的实际弯曲能力退化成平线 y≈0——**欠拟合**。0.891 比演示① 的 0.719 还高：过度限制的先验，比"老老实实的直线"更僵。
**可调参数**：把循环改成 `(1e-12, 0.1, 1, 5, 50, 1e3, 1e8, 1e10)` 能看见更完整的曲线——λ 从 1e10 往回退时 MSE 先降（不再压平）到最优（约 5）再升（开始追噪声）。
**对应数学**：主线第四节"先验过强 = 欠拟合的开关"。教材那句"欠拟合的常见原因是过度限制的先验"，这里有了数字：**模型的容量是一回事，先验允不允许它使用容量是另一回事。**

### 步骤 4：演示③ —— 借用强度（B 借 A 的力量）

```python
x2 = np.linspace(0, 1.8, 10)
yA = 2.0*x2 + np.random.default_rng(1).normal(0, 0.3, 10)
xB = np.array([0.1, 0.5, 0.9]); yB = 2.0*xB + np.random.default_rng(3).normal(0, 0.3, 3)
wB, _ = fit_poly(xB, yB, 1, 0.0)
wAll, _ = fit_poly(np.concatenate([x2, xB]), np.concatenate([yA, yB]), 1, 0.0)
print(f"③ B独立斜率={wB[1]:.2f}   合并(借用A组)={wAll[1]:.2f}   真值≈2.0")
```

#### `fit_poly` 复用 + `np.concatenate` —— 独立拟合 vs 合并拟合

**做什么**：A 组 10 个点、B 组 3 个点，两者真实斜率都是 2.0。分别用 `fit_poly(xB, yB, 1, 0.0)` 和把两组拼起来后的 `fit_poly(..., 1, 0.0)` 求斜率。
**操作**：`yA`/`yB` 是 `(10,)`/`(3,)` 的带噪数据；`np.concatenate([x2, xB])` 把 x 拼成 `(13,)`、`np.concatenate([yA, yB])` 把 y 拼成 `(13,)`。斜率取 `w[1]`（1 阶模型里第 1 个系数是 x 的斜率，`w[0]` 是截距）。
**输入**：`xB` `(3,)`、`yB` `(3,)`、`x2` `(10,)`、`yA` `(10,)`。
**输出**：两个标量——B 独立斜率、合并斜率。
**结果**：`B独立斜率=1.39`（离真值 2.0 差 0.6）、`合并=1.96`（差 0.04）——**B 只有 3 个点，独立拟合是瞎猜；合并后它"借"了 A 的 10 个点，斜率被拉回真值附近。**
**可调参数**：换 `default_rng(3)` 里的种子，B 会得到另一个"瞎猜"值；把 B 的点从 3 加到 8，独立拟合会越来越可靠、被合并拉动的幅度越来越小——**借用强度随自身数据量衰减**。
**对应数学**：主线第三节层级模型的 **borrowing strength**。注意一个区别：演示③ 用的是"直接合并"（把两组数据当一组拟合），它演示的是借力的**方向**；真正的层级后验是**收缩 (shrinkage)**——B 的估计被"权重 = 数据精度"拉向共同中心（主线公式 $w_g^{\text{post}}$），B 点越少，被拉的越多。两者精神一致，精确的收缩公式留给读者用主线公式手推。

## 改个数字试试：把三个实验推向极限

### 实验 A：把真实函数改成正弦——模型族错了，先验救不了

```python
x, _, _ = gen_data()
y_sin = np.sin(x)                          # 真实函数是正弦，不是多项式
for d, lam in ((1, 0.0), (9, 5.0), (9, 1e10)):
    _, p = fit_poly(x, y_sin, d, lam)
    print(f"d={d} λ={lam:>8g}: 正弦 MSE={mse(p, y_sin):.3f}")
```

输出（大致）：

```text
d=1 λ=       0: 正弦 MSE=0.594
d=9 λ=       5: 正弦 MSE=0.517
d=9 λ=   1e+10: 正弦 MSE=0.594
```

正弦是奇函数、多项式是偶函数与奇函数的组合——但**再调 λ 也无法让多项式族弯出正弦**（MSE 都停在 0.5 上下）。这就是主线第五节边界声明第一句：**先验调节的是"弯曲的程度"，不是"弯曲的形状"；模型族错了，必须换函数形式。**

### 实验 B：把 B 组的点从 3 加到 8

把 `xB = np.array([0.1, 0.5, 0.9])` 换成 `np.linspace(0, 0.9, 8)`（配 8 个带噪点），观察"B 独立斜率 vs 合并斜率"的差距随数据量缩小——**借用强度是"数据越少越重要"的工具**。

## 边界声明：这套代码能做什么，不能做什么

1. **MSE 是对真值 y_true 算的——上帝视角。** 现实里你看不到真值，只能看训练集/验证集的误差。这里的"对真值算"只是为了把"偏差"和"噪声"干净地分开，演示① 的 0.719 才纯是"系统偏"；现实诊断欠拟合要靠训练/验证两条曲线都高。
2. **λ=1e10 连截距一起按到 0。** 演示② 的 $\lambda I$ 惩罚了全部 10 个系数（含常数项），所以强先验下模型塌成 y≈0。真实岭回归通常不惩罚截距——这是 toy 简化，方向不影响结论（过度收缩 → 平线 → 欠拟合）。
3. **演示③ 是"合并"不是完整层级推断。** 真正的层级模型同时估计"共同中心 $\mu_w$"和"组间方差"，用 MCMC/共轭公式做收缩；这里用"两组拼一起拟合"演示借力的方向，牺牲了"自动决定借多少力"。主线公式 $w_g^{\text{post}}=\frac{\tau_g w_g^{\text{own}}+\tau_\mu\mu_w}{\tau_g+\tau_\mu}$ 才是完整版。
4. **欠拟合的根本修复不总是调 λ。** 若模型族本身表达不了现象（实验 A），任何先验都无效；若先验选得比知识更确定（σ 极小），才轮到"调弱先验"出手。**先看模型族对不对，再看先验强不强。**
