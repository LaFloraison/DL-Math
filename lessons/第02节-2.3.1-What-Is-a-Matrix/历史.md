# 历史：一张"没用的表格"，如何成为现代科学的通用语言

## 1858 年，凯莱的一篇"多余"论文

1858 年，阿瑟·凯莱发表《矩阵理论回忆录》，第一次系统地定义了矩阵的加减乘法和逆矩阵。当时的反应我们已经知道（§2.1）：同行觉得这是一套"多余的记法"。

但凯莱自己心里清楚一件重要的事：**矩阵不是一堆数字的随意排列，它有自己的"语法"。** 他把矩阵当作一个**整体对象**来对待——像对待一个数一样，给矩阵定义了"加减乘除"（逆矩阵）。这个"把表格当作单个对象"的跳跃，才是真正革命性的一步。**从"一桌子数字"到"一个对象"**——就像当年"把一组数当作一个向量"一样，是数学抽象史上的一次升维。

## 矩阵的"前半生"：藏在表格里的应用

其实在凯莱之前，矩阵的"内容"早已潜伏在人类的各种表格里。

**两千多年前**，中国的《九章算术》就有"方程术"——解线性方程组时，把系数排列成一张表，用"直除法"（高斯消元的雏形）求解。数学家们早就在用"矩形排列的数字"，只是没有一个统一的名字和代数。

**19 世纪的数学家们**也在各自领域里遇到"表格"：行列式理论（勒让德、柯西、雅可比）研究"由表格算出的一个数"；线性变换的研究者发现"变换的复合"对应着某种"表格的乘法"。这些散落的线索，等凯莱把它们收进"矩阵"这一个名字之下。

## 1880–1950：从"曲线救国"到"线性代数的主角"

凯莱之后，矩阵理论逐渐丰满：弗罗贝尼乌斯（Frobenius）建立矩阵的秩、特征值理论；希伍德、希尔伯特把矩阵用于方程与函数空间。20 世纪上半叶，量子力学登场——海森堡把物理量写成矩阵，矩阵成了描述微观世界的语言。**一张"表格"，成了物理学的语法。**

与此同时，工程与统计也在大规模使用矩阵：线性回归的"正规方程"、主成分分析的协方差矩阵、控制理论的状态空间模型。矩阵从"数学家的抽象玩具"，变成了"工程师的计算工具"。

## 2012 年至今：矩阵，深度学习的地基

而在深度学习里，矩阵走到了它的巅峰：**几乎每一次前向传播、每一次参数更新，都是矩阵运算。** 权重是矩阵，批量数据是矩阵，注意力是矩阵，卷积被重写成矩阵乘法。GPU 为矩阵乘法而生，框架为矩阵优化而生。

从凯莱 1858 年的"没用的表格"，到 2017 年 Transformer 里每秒亿次矩阵乘——矩阵走过了一个半世纪。它从未改变，改变的是世界终于长出了配得上它的规模。

## 留一扇门

凯莱把"表格"升格为"对象"，给了矩阵名字和语法。今天，深度学习把矩阵当成了呼吸的空气。

但一个对象要真正"用"起来，还得回答三个问题：它多大（维度）？它有什么特殊形状（对称等）？它能怎么运算（加减乘、求逆）？——这正是 §2.3.2 到 §2.3.4 的故事。
