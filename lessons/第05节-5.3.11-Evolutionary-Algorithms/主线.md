## 第一步：Toy Model —— 一群体形在飞行的候鸟

想象一群候鸟，要在一条山脉里找一个"食物最丰沛的山谷"过冬。它们有一个残酷的困难：**整条山脉笼罩在浓雾里，没有任何一只鸟能看见全貌**——它们不知道哪个山谷食物最多，甚至不知道远处还有没有更好的谷。

但是这群鸟有一个祖先留下的生存智慧：**进化。** 每一代，它们做四件事：

1. **挑选**：看哪几只鸟住的谷食物最多（适应度最高），让它们成为"明星"；
2. **繁衍**：让明星两两配对，把"更接近好谷的飞行方向"传给孩子（**交叉**）；
3. **偶变**：大多数孩子按父母的方向飞，但**少数孩子故意偏离一点点**（**变异**）——万一父母都错过了某个更好的谷，变异的孩子替全群去发现它；
4. **替换**：新的一代代替老的一代，继续飞、继续挑。

几十代之后，奇迹发生了：**这群鸟的飞行方向越来越集中，最终落在一个食物最丰沛的山谷。** 它们从来没看见过全貌，但靠着"挑选 + 繁衍 + 偶变 + 替换"这个循环，硬是从迷雾里找到了好谷——而且，因为变异的存在，它们**不会被任何一个次好谷永久困住**。

你盯着这群鸟，发现一个惊人的事实：**没有任何一只鸟"聪明"到会计算，但整个群体却在"优化"。** 自然选择，居然是一台优化器。现在问一个"浅到可笑"的问题：**"挑选、交叉、变异"怎么精确成能写进代码的规则？它和梯度下降（§5.3.6）到底差在哪——一个靠坡度，一个靠什么？** 该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：没有梯度，怎么优化？

回顾前面所有方法：梯度下降（§5.3.6）、单纯形法（§5.3.8）、拉格朗日（§5.3.9）——它们全都默认一件事：**你至少能算出某种"方向"或"改进"的线索**。梯度要求函数可微，单纯形要求问题线性，拉格朗日要求约束光滑。

但真实世界大量问题三个都不满足：

- **黑箱函数**：你只有一个"打分器"，给它一组输入，它返回一个数——你碰不到导数，甚至不知道函数长什么样（比如"这个电路布局跑起来多快"）。
- **离散/组合空间**：§5.3.3、§5.3.5 说过，整数空间里没有梯度可借力。
- **崎岖多峰的曲面**：Rastrigin 函数这种全是局部最小的地形，梯度下降十有八九困在第一个坑里。

这时候，进化给出一个完全不同的哲学：**不需要方向，只需要"谁更好"。** 你不需要知道"往哪走会变好"，你只需要能比较"A 和 B 谁更好"——然后让好的多繁衍、差的被淘汰。**比较，比方向更原始、更普适。**

### 二、进化算法的四件套词汇

教材给出的基本概念，是对生物学的一一映射：

- **种群 (population)**：一组候选解的集合——那群候鸟。
- **染色体 (chromosome)**：每一个候选解——每只鸟的"飞行方案"。
- **基因 (gene)**：解的一个组成元素——方案里的一个参数。
- **适应度 (fitness)**：解的好坏程度——每只鸟所在山谷的食物量。在优化里就是目标函数：$\text{Fitness}(x) = f(x)$。

用数学的话说：一个候选解 $\mathbf{x} = (x_1, x_2, \dots, x_n)$ 是一条染色体，$x_i$ 是基因，$f(\mathbf{x})$ 是适应度。**进化算法不碰梯度，只反复执行"评估适应度 → 选择 → 交叉 → 变异 → 替换"。**

### 三、遗传算法的六步循环

教材以最流行的**遗传算法 (genetic algorithm, GA)** 为例，列出六个步骤：

**(1) 初始化 (initialization)**：随机生成初始种群——撒 $N$ 条随机染色体。
**(2) 评估 (fitness)**：用适应度函数给每条染色体打分。$\text{Fitness}(x) = f(x)$。
**(3) 选择 (selection)**：按适应度挑选"父母"。**适应度越高，被选中的概率越大**（"适者生存"）。常用方法：轮盘赌（按比例概率抽）、锦标赛（随机抽几个留最优）。
**(4) 交叉 (crossover / recombination)**：把选中的父母两两配对，交换/混合基因，产生**后代 (offspring)**——模仿有性繁殖。对实数染色体，常用**算术交叉**：孩子 = $\alpha \times$ 父母 A $+ (1-\alpha)\times$ 父母 B。
**(5) 变异 (mutation)**：以一个小概率（**变异率 mutation rate**）随机改动后代的某些基因——给实数染色体加一点高斯噪声。**变异是多样性 (diversity) 的保险丝**：防止种群过早收敛到一个次好解（过早收敛，premature convergence）。
**(6) 替换与终止 (replacement & termination)**：用新种群替换旧种群；重复直到满足终止条件（达到最大代数、或适应度足够好）。

> **遗传算法 (genetic algorithm, GA)**
>
> 物理含义：模拟自然选择——用"选择 + 交叉 + 变异"的循环，在无需梯度、无需连续性的前提下，让一个候选解种群逐代进化逼近最优。
>
> ```
> 初始化: 随机生成 N 条染色体 x1..xN
> 循环 (直到达到最大代数或适应度达标):
>     评估: 计算每条染色体的适应度 f(xi)
>     选择: 依适应度概率挑选父母 (适应度越高越可能被选)
>     交叉: 父母两两配对, 混合基因产生后代
>     变异: 以概率 pm 随机改动后代基因, 维持多样性
>     替换: 新种群 = 后代 (或后代+保留的精英)
> 输出: 历史上适应度最高的染色体
> ```
>
> - **适应度** = 目标函数 $f(x)$（最大化问题直接取 $f$；最小化取 $-f$ 或 $1/f$）
> - **选择**：高适应度个体更可能繁殖——"适者生存"的概率化
> - **交叉**：组合已有优良基因——开发 (exploitation)
> - **变异**：随机探索新基因——勘探 (exploration)，对抗过早收敛
> - **终止**：最大代数、适应度阈值、或收敛停滞

**每个符号的含义逐一解释：** 教材例——优化 $f(x) = -x^2 + 4x$（最大值在 $x=2$，$f(2)=4$）。初始化 10 条随机染色体在 $[0,5]$ 里；每代评估 $f(x)$、选择、交叉、变异；100 代后找到 $x=2$，$f=4$。图 5.13 则演示了更凶险的 Rastrigin 函数 $f(x) = \sum_i (10 + x_i^2 - 10\cos 2\pi x_i)$——它有无穷多个局部最小，像一片长满坑的农田；GA 用 50 代、种群 100、父代 20、变异率 0.1，仍找到了全局最小点。

### 四、进化的家族图谱

遗传算法只是进化算法的老大。教材点名的其他成员：

- **遗传编程 (genetic programming)**：进化的是**计算机程序**本身——把"程序结构"当染色体，交叉变异结构，让程序"长出"正确的逻辑。
- **差分进化 (differential evolution)**：专为**实值函数优化**设计——变异用"随机两个体之差"驱动，在连续空间里极其高效。
- **进化策略 (evolution strategies)**：直接进化**策略参数**——比如把"变异强度"本身也当作被进化的基因，让算法自适应步长（有点像深度学习的自适应学习率）。
- **进化编程 (evolutionary programming)**：重点在**变异**（对有限状态机），不强调交叉。

**一个统一的视角：它们都是"选择 + 变化"的变奏。** 差别只在"变化"的形式——交叉还是变异为主、染色体是实数还是程序还是状态机。

### 五、撞墙加深：进化的优点与软肋

教材把进化算法的**优点**讲得很清楚：
- **灵活 (flexible)**：不要求可微、不要求线性、不要求凸——对黑箱和离散问题照单全收。
- **全局搜索 (global search)**：种群 + 变异让它在多峰地形上比梯度类方法**更可能**找到全局最优——"多个探测头同时探索"。
- **可并行 (parallel)**：每个个体的适应度独立计算，天然适合并行硬件——GPU 上同时评估 N 个候选。

**边界声明——软肋同样扎心：**
1. **计算量大 (computationally intensive)**：每代要评估整个种群，资源随问题规模显著膨胀——比梯度下降贵得多。
2. **不保证最优 (no certainty)**：进化是"大概率好"，**不是"保证最优"**。它像 §5.3.5 的元启发式一样，给出"合理的解"，却无法保证全局最优。面对有精确方法的凸/线性问题，进化是"杀鸡用牛刀"且"牛刀还可能砍偏"。
3. **调参玄学**：种群大小、变异率、交叉概率——每一个都影响收敛，却几乎没有通用规则。

**一句话判断：进化算法是"当梯度不存在、形状不知道、但'好坏'能比较"时的最后一道万能药。** 它用计算量换普适性，用"大概率"换"确定性"。

## 第三步：DL 桥接

**进化算法与深度学习有两个方向的交汇——它既是深度学习的工具，也反过来被深度学习改变。**

**其一：进化做"模型外的优化"。** 深度学习最昂贵的超参数（网络结构、学习率、层数、神经元数）是**离散、不可微**的选择——梯度下降对它们无能为力（§5.3.3 的墙）。进化算法在这里大显身手：**进化神经架构搜索 (evolutionary NAS)**（AmoebaNet、NSGA-Net）把网络结构当染色体，用"在验证集上的精度"当适应度，进化出超越手工设计的架构；**进化超参调优**则把学习率、批大小等编码进染色体一起进化。**"让模型学参数，让进化学超参"——这是当下 AutoML 的两大支柱之一。**

**其二：进化曾想"训练"网络本身。** 1980-90 年代，进化神经网络（NEAT，进化拓扑的神经网络）试图直接用进化代替反向传播训练权重——它一度热闹，但面对大规模网络时，进化的计算量远远追不上梯度下降的速度。**这场"进化 vs 梯度"的竞争，梯度赢了训练，进化赢了几何外的搜索。** 教训：**有梯度的地方梯度更快，没梯度的地方进化才登场。**

**其三：强化学习与进化的融合。** 进化策略在强化学习里"复活"了——**ES（evolution strategies）**不逐样本算 Q 值，而是用"种群扰动 + 梯度估计"探索策略参数空间，在并行机上表现甚至匹敌 PPO。而 OpenAI 2017 年《Evolution Strategies as a Scalable Alternative to Reinforcement Learning》让世界重新意识到：**进化这个古老的算法，在 GPU 集群上依然锋利。**

**一句话收束：进化算法是优化工具箱里"最不挑食"的成员**——不挑可微、不挑线性、不挑凸，只要求"好坏可比"。它在深度学习里不是训练的主力（那是梯度下降），却是模型结构、超参数这些"梯度够不到的地方"的最佳工人。具体如何从零写一个遗传算法、看 $f(x)=-x^2+4x$ 的种群逐代逼近 $x=2$，见《代码.md》。
