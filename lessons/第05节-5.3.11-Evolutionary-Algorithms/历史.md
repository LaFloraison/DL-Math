# 历史：进化算法——把自然选择搬进计算机的人

## 1950 年的曼彻斯特：图灵在论文里埋下了一颗种子

1950 年，艾伦·图灵发表了那篇划时代的《计算机器与智能》。开头那句"机器能思考吗？"引来无数争论，但很少有人注意他藏在第 9 节的一个技术提案。图灵说：**与其手写一个"智能程序"，不如让程序像生物一样进化。** 他设想了一个"基因搜索"过程——随机生成一批候选程序，用测试打分，让好的"繁殖"、差的"淘汰"，一代代改良。

图灵没有实现它——1950 年的计算机跑不动这个疯狂的想法。但这个念头像种子一样埋在土里：**既然自然界能用"自然选择"从无机物里长出眼睛和大脑，为什么计算机不能用同样的循环长出解决难题的程序？**

这颗种子，要等四分之一世纪才发芽。但图灵已经说出了进化计算的全部哲学：**你不是设计答案，你是设计一个"能让答案长出来"的过程。**

## 1960-1975：三条各自独立的进化河流

有趣的是，进化计算不是一个人发明的，而是在 1960 年代被三条互不知晓的河流同时挖出来的。

**第一条河：进化策略（Evolution Strategies）。** 1964 年的柏林，一个研究流体力学的学生英戈·雷申贝格（Ingo Rechenberg）遇到了难题：他要优化一个火箭喷管的形状，但实验只能给出"这个形状好不好"，无法给出导数。他灵光一闪：**为什么不模拟自然选择？** 随机扰动参数，保留好的，丢弃坏的。他和施韦费尔（Hans-Paul Schwefel）把"变异 + 选择"做成了第一个真正的进化算法，还发明了"让变异强度也进化"的自适应机制。

**第二条河：进化编程（Evolutionary Programming）。** 1960 年代，劳伦斯·福格尔（Lawrence Fogel）在圣地亚哥，想的是让有限状态机（一种自动机）自己进化出预测能力——他重点用**变异**，几乎不用交叉。福格尔把他的方法用于模式识别和预测，是最早把进化用于"机器学习"的人之一。

**第三条河，也是最著名的一条：遗传算法（Genetic Algorithm）。** 1960 年代，密歇根大学的约翰·霍兰德（John Holland）在研究自适应系统时，对"自然选择是一种优化过程"这个想法着了迷。1975 年，他出版了《自然与人工系统中的适应性》——这本书第一次系统地给出了遗传算法的完整框架：**种群、染色体、选择、交叉、变异**，以及著名的"模式定理 (schema theorem)"，试图解释"为什么简单的选择+交叉能搜索得这么聪明"。

三条河流，1964-1975，在三个国家，用三种术语，做同一件事：**把达尔文的自然选择，变成可执行的优化算法。** 历史再次证明：当"黑箱 + 无梯度"的需求足够普遍，进化计算会从每个角落同时长出来。

## 1980-1990：进化计算的黄金十年

1980 年代，进化计算进入了爆炸期。它被用于组合优化（旅行商、调度）、机器学习（特征选择、神经网络训练）、工程设计（机翼形状、电路布局）——凡是"黑箱 + 难评价"的问题，进化都去插一脚。

1989 年，戴维·戈德伯格（David Goldberg）出版了《Genetic Algorithms in Search, Optimization, and Machine Learning》，把霍兰德的思想整理成工程师能读懂的教科书——遗传算法从此成为进化计算的门面。1993 年，《进化计算》期刊创刊，这个领域有了自己的舞台。

但这个黄金十年也埋下了一个宿命的伏笔：**进化算法试图训练神经网络，而反向传播 + 梯度下降在同一时期越来越强大。** 两者在"谁更会训练网络"上一较高下——梯度干净利落地赢了。进化被挤回了它真正的主场：**没有梯度的搜索**。

## 2017：进化策略的复活——GPU 上的古老算法

时间快进到 2017 年，OpenAI 发布了一篇标题就带着挑衅的论文：《进化策略是可扩展的强化学习替代方案》。作者用进化策略在 Gym 的连续控制任务上达到了与 PPO 相当的水平——而方法朴素得惊人：随机扰动策略参数、在并行核上评估、用噪声梯度估计更新。

这篇文章之所以轰动，是因为它证明了一件事：**进化这个古老的算法，在 GPU 集群和并行计算面前重获青春。** 过去它"慢"，是因为每代要串行评估整个种群；现在几千个核同时评估——进化算法最被诟病的软肋，被硬件填平了。

同一年，进化神经架构搜索（NAS）也在 ImageNet 上找到了超越人类设计的网络结构。2018 年，谷歌的 AmoebaNet 用进化方法击败了当时最强的强化学习 NAS。**进化算法在深度学习时代不是被淘汰的化石，而是被重新发现的老兵**——它回到了图灵 1950 年设想的位置：当你要搜索的不是参数，而是结构、超参、策略这些"梯度够不到的地方"时，进化依然是那个最不挑食的工人。

## 门，通向主线

从图灵 1950 年的种子，到 1964 年柏林的喷管，到 1975 年霍兰德的模式定理，到 2017 年 OpenAI 的复活——进化计算的历史，是一部"用自然选择替代手写智慧"的漫长尝试史。它不承诺最优，不要求可微，它只相信一件事：**只要"谁更好"可以比较，一代代的挑选与变化，就能把答案长出来。** 现在，轮到你当一个"让答案长出来"的园丁了。
