# 代码：从零写一个遗传算法——看种群逐代逼近最优

**目标**：主线里教材例 $f(x) = -x^2 + 4x$（最大值在 $x=2$，$f(2)=4$）。这里**从零实现遗传算法**：初始化随机种群 → 评估适应度 → 锦标赛选择 → 算术交叉 → 高斯变异 → 替换。你会看到一族"染色体"在 50 代里从随机散布收敛到 $x=2$。**全程不碰任何梯度——这是与梯度下降（§5.3.6）最本质的对照。**

## 层一：完整脚本

```python
import numpy as np
rng = np.random.default_rng(42)

# ---- 1. 适应度 = 目标函数 ----
def fitness(x):
    return -x ** 2 + 4.0 * x            # 教材例: 最大值在 x=2, f=4

# ---- 2. 超参数 ----
POP = 30          # 种群大小
GENS = 50         # 代数
CX_PROB = 0.8     # 交叉概率
MUT_PROB = 0.2    # 变异概率
MUT_STRENGTH = 0.3  # 变异强度 (高斯噪声标准差)

# ---- 3. 初始化: 在 [0,5] 随机撒 30 条染色体 ----
pop = rng.uniform(0.0, 5.0, POP)        # 形状 (30,)

# ---- 4. 进化主循环 ----
for g in range(GENS):
    fit = fitness(pop)                                   # 评估适应度
    # 选择: 锦标赛 (随机抽 2 个, 留更优)
    newpop = np.empty(POP)
    for i in range(POP):
        a, b = rng.integers(0, POP, 2)                   # 两个随机下标
        newpop[i] = pop[a] if fit[a] >= fit[b] else pop[b]
    # 交叉: 两两配对, 算术平均
    for i in range(0, POP - 1, 2):
        if rng.random() < CX_PROB:
            alpha = rng.random()
            newpop[i]     = alpha * newpop[i] + (1 - alpha) * newpop[i + 1]
            newpop[i + 1] = (1 - alpha) * newpop[i + 1] + alpha * newpop[i]
    # 变异: 小概率加高斯噪声
    mask = rng.random(POP) < MUT_PROB
    newpop[mask] += rng.normal(0.0, MUT_STRENGTH, int(mask.sum()))
    # 替换 (并约束在 [0,5] 内)
    pop = np.clip(newpop, 0.0, 5.0)
    # 记录每一代的当前最优 (用替换后的种群重新评估, 保证一致性)
    cur_fit = fitness(pop)
    if g in (0, 9, 49):
        idx = int(np.argmax(cur_fit))
        print(f"第 {g+1:3d} 代: 种群最优 f = {cur_fit[idx]:.4f}, "
              f"最优 x = {pop[idx]:.4f}")

# ---- 5. 结果 ----
final_fit = fitness(pop)
best_x = pop[int(np.argmax(final_fit))]
print(f"\n最终: 最优 x = {best_x:.4f}, 最优 f(x) = {final_fit.max():.4f}")
print(f"解析解: x = 2, f = 4")
```

输出（随机种子固定，可复现）：

```
第   1 代: 种群最优 f = 3.9999, 最优 x = 1.9902
第  10 代: 种群最优 f = 4.0000, 最优 x = 1.9998
第  50 代: 种群最优 f = 4.0000, 最优 x = 2.0000
最终: 最优 x = 2.0000, 最优 f(x) = 4.0000
解析解: x = 2, f = 4
```

**第 1 代就几乎撞上 $f=4$**——因为种群是随机撒的，而 $f(x)=-x^2+4x$ 在 $[0,5]$ 上到处都接近 4（峰很平缓），随机个体 $x\approx1.99$ 的适应度已达 3.9999。把目标换成 Rastrigin（教材 Figure 5.13）再跑，你才会看到进化的真正威力——那个布满局部最小的地形上，随机种子很少直接落在最优附近，种群必须靠"选择 + 变异"一步步爬出来。

## 层二：分步逐函数拆解

### 步骤 1-3：适应度与初始化

```python
def fitness(x):
    return -x ** 2 + 4.0 * x

POP = 30
pop = rng.uniform(0.0, 5.0, POP)
```

#### `fitness` —— 目标函数即适应度

**操作**：返回 $f(x) = -x^2+4x$。**输入**：`x`（标量或数组，逐元素运算）。**输出**：适应度。
**可调参数**：换成 Rastrigin `f(x) = 10 + x² - 10*cos(2πx)`（一维版），你就复制了教材 Figure 5.13 的实验——**同一个 GA，换一个适应度，就是换了一个问题**。

#### `rng.uniform(0.0, 5.0, POP)` —— 初始化随机种群

**操作**：在 $[0,5]$ 上均匀抽 `POP=30` 个数——30 条随机染色体（初始的"候鸟"）。
**输入**：`low=0.0`、`high=5.0`、`size=POP=30`。**输出**：形状 `(30,)` 的数组。
**可调参数**：`POP` 越大，每代的"多样性"越高、搜索越广，但每代评估成本线性上升——**种群大小是"广度 vs 计算量"的旋钮**。初始范围 $[0,5]$ 来自问题定义（教材说变量在 0 到 5）。

**对应数学**：主线六步的 (1) 初始化。

---

### 步骤 4：进化主循环

#### 评估 `fit = fitness(pop)`

**操作**：对整条染色体数组一次算全部适应度（NumPy 向量化）。**输入**：形状 `(30,)`。**输出**：`fit`，形状 `(30,)`，第 $i$ 位是染色体 $i$ 的适应度。

#### 选择 —— 锦标赛

```python
for i in range(POP):
    a, b = rng.integers(0, POP, 2)
    newpop[i] = pop[a] if fit[a] >= fit[b] else pop[b]
```

**操作**：为每个"下一代名额"，随机抽两条染色体，留适应度高的那条——**锦标赛选择 (tournament selection)**。注意`newpop` 允许重复（一条好的染色体可能被选中多次，成为多个后代，这正是"适者生存"）。
**输入**：`pop`、`fit`。**输出**：`newpop`，形状 `(30,)`——"父母池"。
**可调参数**：把"抽 2 个"改成"抽 k 个留最优"（锦标赛规模 $k$）——$k$ 越大，选择压力越大、收敛越快但多样性损失越大。**这是进化里最像"学习率"的旋钮**。

#### 交叉 —— 算术平均

```python
for i in range(0, POP - 1, 2):
    if rng.random() < CX_PROB:
        alpha = rng.random()
        newpop[i]     = alpha * newpop[i] + (1 - alpha) * newpop[i + 1]
        newpop[i + 1] = (1 - alpha) * newpop[i + 1] + alpha * newpop[i]
```

**操作**：相邻两条染色体按概率 `CX_PROB` 配对；`alpha` 是 $[0,1]$ 随机权重，两个后代分别取"父母 A 的 $\alpha$ 份 + 父母 B 的 $(1-\alpha)$ 份"与相反组合——**算术交叉 (arithmetic crossover)**，把两个好解的"优点"混合。
**输入**：`newpop`（父母池）。**输出**：部分交叉后的 `newpop`（含后代）。
**可调参数**：`CX_PROB=0.8` 是交叉频率。调低到 0——种群只剩选择 + 变异，进化退化。调太高——后代过度混合，丢失父代基因。

#### 变异 —— 高斯扰动

```python
mask = rng.random(POP) < MUT_PROB
newpop[mask] += rng.normal(0.0, MUT_STRENGTH, int(mask.sum()))
```

**操作**：以 `MUT_PROB` 概率给染色体加均值为 0、标准差 `MUT_STRENGTH` 的高斯噪声——**小概率的随机探索**。
**输入**：`newpop`。**输出**：部分被扰动后的 `newpop`。
**可调参数**：`MUT_STRENGTH` 是变异强度。太大——种群像醉汉乱走，难以收敛；太小——勘探不足，可能困在局部最优。**这就是"探索 (exploration) vs 开发 (exploitation)"的天平**——变异负责探索，交叉负责开发。

#### 替换 `pop = np.clip(newpop, 0.0, 5.0)`

**操作**：用新种群整体替换旧种群，并用 `np.clip` 把染色体约束回 $[0,5]$（保持可行域）。**输入**：`newpop`。**输出**：下一代的 `pop`。
**可调参数**：这里没有保留"精英"（上一代最优个体）。加一行"精英保留"——把上一代最优直接复制进新种群——可以防止最优解被变异/交叉弄丢。

**对应数学**：主线六步的 (2)-(6)——评估、选择、交叉、变异、替换、终止。

---

### 步骤 5：结果提取

```python
final_fit = fitness(pop)
best_x = pop[int(np.argmax(final_fit))]
```

**操作**：取最终种群适应度最高的染色体作为输出。**对应数学**：主线定义块里"输出历史上适应度最高的染色体"。

---

## 实验台：让进化显灵

1. **换成 Rastrigin**：一维版 $f(x) = 10 + x^2 - 10\cos(2\pi x)$，范围 $[-5.12, 5.12]$。它有无穷多个局部最小——**你会看到普通梯度下降困在坑里，而 GA 靠变异"跳坑"**。
2. **调变异强度**：`MUT_STRENGTH=1.0` 观察种群长期乱晃；`MUT_STRENGTH=0.01` 观察过早收敛到次优——**"探索 vs 开发"的天平当场显形**。
3. **加精英保留**：把上一代 `pop[np.argmax(fit)]` 无条件复制进 `newpop`——收敛更稳（最优不会倒退）。
4. **删掉交叉**：`CX_PROB=0`——只剩选择+变异，看收敛是否变慢。**体会"交叉组合好基因"的贡献**。

**对应数学**：实验 1 复制教材 Figure 5.13（Rastrigin）；实验 2-4 验证主线里"变异防过早收敛""交叉组合优良基因"的每一句话。
