# 习题：叠加

## 第一组：概念检验

### 1.1 叠加给量子计算的"惊人力量"到底是什么？为什么它不等于"免费并行"？

**解答**：叠加的力量是**让 $2^n$ 个基态同时在场，并对它们同时做同一次变换**——用 $n$ 次哈达玛门就能制造 $2^n$ 个可能性的同时在场，一次矩阵乘就能更新全部 $2^n$ 个振幅。但它不等于免费并行，因为**读出（测量）只能让一个基态坍塌，且是概率性的**。所以量子算法真正的工作方式不是"同时算出 $2^n$ 个答案"，而是"让所有可能同时经历变换，再用干涉把正确基态的概率抬起来、其余压下去，最后测量"（Grover 只拿到 $\sqrt{N}$ 而非 $N$，就是证明）。

**思路点拨**：两个关键词——"同时变换"（真的）和"串行读数"（真的）。能把这两句同时说对，才算理解了叠加。只答"同时算很多"是错的。

### 1.2 用双缝实验解释"振幅相加"与"概率相加"的区别。

**解答**：双缝实验里，电子"同时穿过两条缝"。若用经典概率相加：$P = P_A + P_B$，屏上只会出现两条均匀亮带。若用量子振幅相加：穿过缝 A 的振幅 $\alpha_A$ 与穿过缝 B 的振幅 $\alpha_B$ **先相加再平方**：$P = |\alpha_A + \alpha_B|^2 = |\alpha_A|^2 + |\alpha_B|^2 + 2\text{Re}(\alpha_A^*\alpha_B)$——最后那项就是**干涉项**。当两振幅同相时增强（亮纹），反相时抵消（暗纹）。屏幕上明暗相间的条纹，正是振幅相加（干涉）而不是概率相加（无条纹）的证据。

**思路点拨**：公式 $|\alpha_A + \alpha_B|^2$ 里的交叉项 $2\text{Re}(\alpha_A^*\alpha_B)$ 是整道题的钥匙。有交叉项 = 干涉 = 叠加；没有 = 经典。

### 1.3 哈达玛门 $H$ 的本质作用是什么？为什么说 $H$ 是"把确定变成叠加"的操作？

**解答**：$H = \frac{1}{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}$ 的本质作用是把一个基态改写成**等权叠加**：$H|0\rangle = |+\rangle = \frac{1}{\sqrt2}(|0\rangle+|1\rangle)$，$H|1\rangle = |-\rangle = \frac{1}{\sqrt2}(|0\rangle-|1\rangle)$。它"把确定变成叠加"——一个只占据一个基态的状态，被均分成两个基态的叠加（振幅各 $1/\sqrt2$）。$n$ 个 H 同时作用（$H^{\otimes n}$）就把 $|0\rangle^{\otimes n}$ 变成 $2^n$ 个基态的均匀叠加。H 是量子算法"开题第一笔"的标配。

**思路点拨**：注意 $H$ 也保概率（$H^\dagger H = I$），所以它是可逆的、保信息的——这正符合量子门"不破坏信息"的要求。

## 第二组：计算实践

### 2.1 手算：验证 $H|-\rangle = |1\rangle$ 的每一步

把 $|-\rangle = \frac{1}{\sqrt2}(|0\rangle-|1\rangle)$ 代入 $H$，逐步展开。

**解答**：
$$H|-\rangle = H\left(\frac{1}{\sqrt2}(|0\rangle-|1\rangle)\right) = \frac{1}{\sqrt2}(H|0\rangle - H|1\rangle) = \frac{1}{\sqrt2}\left(\frac{1}{\sqrt2}(|0\rangle+|1\rangle) - \frac{1}{\sqrt2}(|0\rangle-|1\rangle)\right)$$
$$= \frac{1}{2}\left(|0\rangle+|1\rangle-|0\rangle+|1\rangle\right) = \frac{1}{2}(2|1\rangle) = |1\rangle$$

$|0\rangle$ 的振幅 $+\frac12$ 与 $-\frac12$ 抵消（相消干涉），$|1\rangle$ 的 $+\frac12$ 与 $+\frac12$ 相加（相长干涉），精确回到 $|1\rangle$。

**思路点拨**：这是"干涉"的最小手算。重点是把每一项的系数当成独立的，各自归类相加——抵掉 0，加上 1。

### 2.2 手算 + 验证：$|+\rangle$ 与 $|-\rangle$ 的 3 比特均匀叠加

写出 $H^{\otimes 3}|000\rangle$ 的完整展开（8 个基态）并验证归一化。

**解答**：$H^{\otimes3}|000\rangle = \frac{1}{\sqrt8}\left(|000\rangle+|001\rangle+|010\rangle+|011\rangle+|100\rangle+|101\rangle+|110\rangle+|111\rangle\right)$。每个振幅 $\frac{1}{\sqrt8} \approx 0.3536$，$8 \times \frac18 = 1$，归一化成立。

```python
import numpy as np
H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)
k0 = np.array([1+0j, 0+0j])
G = np.kron(np.kron(H, H), H)                     # H⊗H⊗H（8×8）
psi = G @ np.kron(np.kron(k0, k0), k0)            # |000⟩
print("振幅:", np.round(psi, 4))
print("概率和:", np.sum(np.abs(psi)**2))
```

输出：

```text
振幅: [0.3536+0.j 0.3536+0.j 0.3536+0.j 0.3536+0.j 0.3536+0.j 0.3536+0.j 0.3536+0.j 0.3536+0.j]
概率和: 1.0
```

**思路点拨**：$\frac{1}{\sqrt8}$ 的每个振幅是 $\sqrt{1/8}$——这是"8 个基态均分概率 1"的唯一合法分法。

### 2.3 验证干涉：测量"五五开"状态的频率

对 $|+\rangle$（单比特）测 20000 次，验证 0/1 大致各半；再对 $H|-\rangle$（应为 $|1\rangle$）测 20000 次，验证几乎全是 1。

```python
import numpy as np
H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)
k0, k1 = np.array([1+0j,0+0j]), np.array([0+0j,1+0j])
np.random.seed(0)
for name, psi in [("|+>", H@k0), ("H|->(=|1>)", H@(H@k1))]:
    draws = np.random.choice(2, size=20000, p=np.abs(psi)**2)
    print(f"{name}: 测到 1 的次数 = {draws.sum()} (理论 {np.abs(psi[1])**2*20000:.0f})")
```

输出：

```text
|+>: 测到 1 的次数 = 9871 (理论 10000)
H|->(=|1>): 测到 1 的次数 = 20000 (理论 20000)
```

**思路点拨**：$|+\rangle$ 五五开（9871/20000 ≈ 0.5），$H|-\rangle$ 几乎永远是 1（20000/20000）——干涉把"五五开"变成了"确定"。频率验证 $\to$ 概率，是量子测量唯一可预测的地方。

## 第三组：DL 延伸

### 3.1 量子 k-means（§12.3.2）用叠加"同时计算到所有聚类中心的距离"。请指出这个方案的实际收益与必须付出的代价。

**解答**：收益：把多个数据点（或多个中心）编码进叠加态，一次量子变换同时算出所有距离——经典是逐对比较（$O(N \times K)$ 次距离），叠加把"同时在场"变成"一次变换"。代价有二：1) **读数**——你得到的不是"每个距离的完整列表"，而是某个距离的统计量（如"最小距离是哪个"），要完整读出全部距离仍需多次测量；2) **编码**——把经典数据点编码成量子振幅本身要成本，数据维度越高越贵（教材"converting regular data into quantum states … can be complicated and time-consuming"）。所以叠加的收益只在"最终只需少数统计量"的任务上能兑现。

**思路点拨**：这题把叠加的力量与 §12.1 的"编码成本"缝合。答"能加速"是半对，加上"读数受限 + 编码贵"才完整。

### 3.2 量子神经网络的"并行"为什么依赖叠加，而经典网络的并行依赖什么？两者本质区别是什么？

**解答**：经典网络的并行是**数据并行/张量并行**——把数据样本或参数分片，分配到多个物理计算单元（GPU）上同时算，每个单元算的是**独立的数据**。量子神经网络的并行是**叠加并行**——$2^n$ 种输入状态同时编码在一个量子态里，一次变换作用于全部 $2^n$ 个振幅，每个单元（量子比特）天然承载多个输入的"影子"。本质区别：经典并行靠"多份硬件 + 通信"扩展，是**显式、可扩展、读得出**的并行；量子叠加并行靠"一个量子态承载所有可能"压缩，是**隐式、指数级、读不出全部**的并行。QNN 的训练必须在"叠加给了多少并行"和"测量限制了读多少"之间找平衡。

**思路点拨**：别把两种并行混为一谈。经典并行 = 多硬件少共享；量子并行 = 单量子态指数压缩。前者读得出、后者读不出——这个区别决定了 QNN 只能做"答案天然是概率"的任务。
