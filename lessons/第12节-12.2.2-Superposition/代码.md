# 代码：叠加与干涉——让 $2^n$ 个状态同时在场，再让答案浮出水面

主线讲了叠加的两重身份：**均匀叠加**让 $2^n$ 个基态同时在场（用 $n$ 次哈达玛门），**干涉**让振幅可以相消相长（$H|-\rangle = |1\rangle$）。这一课把这两件事都用 NumPy 亲手敲出来：定义哈达玛门 $H$，看它把 $|0\rangle, |1\rangle$ 变成什么，把 $n$ 个量子比特拼成 $2^n$ 维向量，最后用数字演示"五五开的叠加，合并后如何精确地只剩一个基态"。

---

## 层一：完整脚本

```python
import sys                               # 让中文 Windows 控制台也能打印 ⊗ 等数学符号
sys.stdout.reconfigure(encoding="utf-8")
import numpy as np                       # 矩阵、张量积、随机数

H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)   # 哈达玛门
KET0 = np.array([1+0j, 0+0j])            # |0⟩
KET1 = np.array([0+0j, 1+0j])            # |1⟩

def tensor(*vecs):                       # ① 张量积：把多个量子比特拼成一个状态
    """n 个 2 维向量 → 一个 2^n 维联合状态。"""
    out = np.array([1+0j])
    for v in vecs:
        out = np.kron(out, v)
    return out

def apply_gate(psi, gate):               # ② 量子门作用：矩阵 × 状态向量
    """gate @ psi：一次作用于全部振幅。"""
    return gate @ psi

# ---- ③ 单比特：H 制造叠加 ----
psi_p = apply_gate(KET0, H)              # H|0⟩ = |+⟩
psi_m = apply_gate(KET1, H)              # H|1⟩ = |−⟩
print("H|0> =", psi_p, " 概率:", np.abs(psi_p)**2)
print("H|1> =", psi_m, " 概率:", np.abs(psi_m)**2)

# ---- ④ 多比特：H⊗H 制造均匀叠加 ----
psi2 = apply_gate(tensor(KET0, KET0), np.kron(H, H))   # H⊗H|00⟩
print("H⊗H|00> =", np.round(psi2, 4))
print("概率总和 =", np.sum(np.abs(psi2)**2))           # 必须 ≈ 1

# ---- ⑤ 干涉：两个五五开合并，精确剩一个基态 ----
back = apply_gate(psi_m, H)              # H|−⟩ = |1⟩（相消相长）
print("H|-> =", np.round(back, 6))

# ---- ⑥ 测量统计：均匀叠加的四态等概率 ----
np.random.seed(11)
draws = np.random.choice(4, size=20_000, p=np.abs(psi2)**2)
counts = np.bincount(draws, minlength=4)
print("测量 20000 次 |00>|01>|10>|11> 计数:", counts)
```

运行输出（Python 3.11 + NumPy）：

```text
H|0> = [0.70710678+0.j 0.70710678+0.j]  概率: [0.5 0.5]
H|1> = [ 0.70710678+0.j -0.70710678+0.j]  概率: [0.5 0.5]
H⊗H|00> = [0.5+0.j 0.5+0.j 0.5+0.j 0.5+0.j]
概率总和 = 1.0
H|-> = [0.+0.j 1.+0.j]
测量 20000 次 |00>|01>|10>|11> 计数: [5080 4990 4912 5018]
```

**H|0⟩ 和 H|1⟩ 概率都是五五开，但振幅一个全正、一个带负号**——这就是 §12.2.1 实验 1 里"概率相同、相位不同"的正式出场。**H|−⟩ 干净地回到 |1⟩**，干涉现场。下面把每一步拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义哈达玛门与基态

```python
H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)
KET0 = np.array([1+0j, 0+0j])
KET1 = np.array([0+0j, 1+0j])
```

#### `np.array([[1, 1], [1, -1]]) / np.sqrt(2)` —— 哈达玛门

**做什么**：把主线的 $H = \frac{1}{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}$ 写进代码。`dtype=complex` 保证复数运算；`/ np.sqrt(2)` 是归一化因子（保证 $H$ 是幺正变换，不改变概率总和）。
**输入**：2×2 的实数矩阵，转复数。
**输出**：形状 `(2, 2)` 的复矩阵。
**可调参数**：`np.sqrt(2)` 固定。哈达玛门是量子计算三大基本门之一（H, X, CNOT），它的归一化是死的——去掉 $\frac{1}{\sqrt2}$ 门就不幺正了，概率会爆。
**对应数学**：主线第二节 $H$ 的定义。$H$ 的作用是"把确定变成叠加"：$H|0\rangle=|+\rangle$、$H|1\rangle=|-\rangle$。

---

### 步骤 2：定义 `tensor` —— 张量积：把多个量子比特拼起来

```python
def tensor(*vecs):
    out = np.array([1+0j])
    for v in vecs:
        out = np.kron(out, v)
    return out
```

#### `tensor` —— n 个 2 维向量 → 一个 2^n 维联合状态

**做什么**：把 $n$ 个单比特向量拼成一个 $n$ 比特联合状态。$n=2$ 时：$|0\rangle \otimes |0\rangle \to |00\rangle$，一个 4 维向量。
**操作**：`np.kron(out, v)` 做**克罗内克积**（张量积的矩阵实现）。从标量 `1+0j` 开始，依次把每个向量乘进去。克罗内克积把两个向量的每个分量两两配对——这正是主线"旋转的硬币乘法"（$2 \times 2 = 4$）的代码版。
**输入**：`*vecs`，任意多个形状 `(2,)` 的向量。
**输出**：形状 `(2**n,)` 的向量，第 $i$ 个分量对应基态 $|i\rangle$ 的振幅。
**可调参数**：
- 传入个数自由。`tensor(KET0, KET1)` 是 $|01\rangle$；`tensor(KET0, KET0, KET0)` 是 3 比特 $|000\rangle$，长度 8。
- 能不能加参数？可以传矩阵做张量积（把门拼起来），但 `np.kron` 直接支持矩阵，这里专门为向量封装。
**对应数学**：主线第一节 $|+\rangle \otimes |+\rangle = \frac12(|00\rangle+|01\rangle+|10\rangle+|11\rangle)$。`np.kron` 就是这个"两两配对"。

---

### 步骤 3：定义 `apply_gate` —— 量子门作用：一次作用于全部振幅

```python
def apply_gate(psi, gate):
    return gate @ psi
```

#### `apply_gate` —— 门 × 状态 = 新状态

**做什么**：把矩阵门作用在状态向量上，得到新状态。
**操作**：`@` 是矩阵乘法。`gate @ psi` 对 $n$ 比特状态 $|\psi\rangle$（长度 $2^n$）和 $2^n \times 2^n$ 的门做一次矩阵乘——**所有 $2^n$ 个振幅同时被更新**。这就是叠加"天然并行"的代码形态：一次矩阵乘，更新全部振幅。
**输入**：`psi`（状态向量）、`gate`（方阵，维度与 psi 匹配）。
**输出**：新状态向量。
**可调参数**：门可以是任意酉矩阵。`np.kron(H, H)` 是"两个哈达玛同时作用"，4×4 矩阵。
**对应数学**：量子变换 $|\psi'\rangle = U|\psi\rangle$。矩阵乘法的一次，就是"同一次变换同时作用于所有振幅"——主线第三节干涉的舞台。

---

### 步骤 4：单比特——H 制造叠加

```python
psi_p = apply_gate(KET0, H)
psi_m = apply_gate(KET1, H)
print("H|0> =", psi_p, " 概率:", np.abs(psi_p)**2)
print("H|1> =", psi_m, " 概率:", np.abs(psi_m)**2)
```

**做什么**：把 H 分别作用在 $|0\rangle$ 和 $|1\rangle$ 上，打印结果。
**操作**：`H @ KET0` 手算就是 $\frac{1}{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}\begin{bmatrix}1\\0\end{bmatrix} = \frac{1}{\sqrt2}\begin{bmatrix}1\\1\end{bmatrix}$。
**输入**：$|0\rangle, |1\rangle$ 两个基态。
**输出**：$|+\rangle = [0.7071, 0.7071]$、$|-\rangle = [0.7071, -0.7071]$，概率都是 `[0.5, 0.5]`。
**可调参数**：这一行没有参数——它就是主线第二节那两个公式的验证。
**对应数学**：$H|0\rangle = |+\rangle$、$H|1\rangle = |-\rangle$。注意输出里 $|1\rangle$ 的第二个振幅是 `-0.7071`——**负振幅**，经典概率里不存在，它是干涉的弹药。

---

### 步骤 5：多比特——H⊗H 制造均匀叠加

```python
psi2 = apply_gate(tensor(KET0, KET0), np.kron(H, H))
```

#### `np.kron(H, H)` —— 两个哈达玛的联合门

**做什么**：把两个单比特 H 门拼成作用在 2 比特上的 4×4 门。
**操作**：`np.kron(H, H)` 做 4×4 克罗内克积——效果等于"第一个比特来一发 H，第二个比特来一发 H"。
**输入**：两个 `(2,2)` 矩阵。
**输出**：`(4,4)` 联合门。
**可调参数**：想作用 $n$ 个比特就 `np.kron` 嵌套 $n$ 次；更简洁的写法是循环 `np.kron`。真实框架（Qiskit）里 `qc.h(range(n))` 内部做的是同样的事。
**对应数学**：主线定义块的 $H^{\otimes n}|0\rangle^{\otimes n} = \frac{1}{\sqrt{2^n}}\sum_{i=0}^{2^n-1}|i\rangle$。$n=2$ 时输出 `[0.5, 0.5, 0.5, 0.5]`——四个基态等振幅，概率各 0.25。

---

### 步骤 6：干涉——H|−⟩ 为什么精确等于 |1⟩

```python
back = apply_gate(psi_m, H)
print("H|-> =", np.round(back, 6))
```

**做什么**：对 $|-\rangle$ 再作用一次 H。直觉上"两个五五开的叠加，再来一发 H 应该还是五五开"？输出打脸：`[0, 1]`，**精确等于 |1⟩**。
**操作**：$H|-\rangle = H\left(\frac{1}{\sqrt2}(|0\rangle-|1\rangle)\right) = \frac{1}{\sqrt2}(|+\rangle - |-\rangle) = \frac{1}{\sqrt2}\left(\frac{1}{\sqrt2}(|0\rangle+|1\rangle) - \frac{1}{\sqrt2}(|0\rangle-|1\rangle)\right) = |1\rangle$。
**输入**：$|-\rangle$。
**输出**：$|1\rangle$。
**可调参数**：`np.round(back, 6)` 里的 6 只是显示精度。真实数值是 `[0, 1]` 的浮点近似——由于 `np.sqrt(2)` 的舍入，会出现 `0.+0.j`（或 $10^{-16}$ 量级的残差），round 后干净。
**对应数学**：主线第三节的相消干涉与相长干涉。$|0\rangle$ 的两个振幅 $+\frac12, -\frac12$ 抵消为 0；$|1\rangle$ 的两个振幅 $+\frac12, +\frac12$ 相加为 1。**这就是"干涉让答案浮出水面"的最小原型**——§12.3.1 的 Grover 把这个技巧放大到 $2^n$ 维。

---

### 步骤 7：测量统计——均匀叠加四态等概率

```python
np.random.seed(11)
draws = np.random.choice(4, size=20_000, p=np.abs(psi2)**2)
counts = np.bincount(draws, minlength=4)
```

**做什么**：对 2 比特均匀叠加测量 20000 次，统计四个基态出现次数。
**操作**：`np.abs(psi2)**2` 得概率数组 `[0.25]*4`；`np.random.choice(4, size=20000, p=...)` 批量抽样；`np.bincount` 统计频次。
**输入**：4 个等概率基态，20000 次。
**输出**：`[5080 4990 4912 5018]`——四个数都在 5000 附近（理论 20000/4 = 5000）。
**可调参数**：`size` 改大，波动收敛到 5000 更紧；`np.random.seed(11)` 保证可复现，删掉则每次结果微变。
**对应数学**：$\frac{1}{2^n}$ 的等概率。均匀叠加"不偏爱任何基态"——这正应了 §12.2 代码里那句"不预设哪个位置更重要"。

## 改个数字试试：把相位与比特数推向极端

### 实验 1：3 个比特——指数在场

```python
psi3 = apply_gate(tensor(KET0, KET0, KET0), np.kron(np.kron(H, H), H))
print("H⊗H⊗H|000> 振幅数:", len(psi3), "  每个振幅:", np.round(psi3[0], 4))
print("概率总和:", np.sum(np.abs(psi3)**2))
```

输出：

```text
H⊗H⊗H|000> 振幅数: 8  每个振幅: 0.3536
概率总和: 1.0
```

**3 个量子比特 = 8 个振幅，每个 $\frac{1}{\sqrt8} \approx 0.3536$。** 每加一个比特，振幅数翻倍、每个振幅除以 $\sqrt2$。你可以一路试到 $n=20$（$10^6$ 个振幅）——见证 §12.2 那本指数账本是怎么由哈达玛门一行一行"发牌"铺开的。

### 实验 2：负振幅制造全抵消

```python
minus = apply_gate(KET0, H) - apply_gate(KET1, H)     # |+⟩ - |−⟩
probs = np.abs(minus)**2
print("|+> - |-> 的振幅:", np.round(minus, 6))
print("概率:", np.round(probs, 6))
```

输出：

```text
|+> - |-> 的振幅: [0.+0.j 1.41421356+0.j]
概率: [0. 2.]
```

**振幅是 `[0, √2]`——第一个基态被完全抵消（概率 0），第二个被增强到概率 2？** 等等，概率 2 不合法。原因：$|+\rangle - |-\rangle$ **没有归一化**——它的模长是 $\sqrt{0 + 2} = \sqrt2$。把它归一化（除以 $\sqrt2$），就得到 $|1\rangle$：概率 `[0, 1]`。这个实验想告诉你：**干涉之前，先检查归一化**。振幅可以随便相加，但只有归一化后的向量才是合法状态——量子力学的概率法，永远在干涉之后复查。

## 边界声明：这套代码能做什么，不能做什么

1. **`apply_gate` 模拟的是"理想量子电路"，没有噪声。** 真实量子硬件上，叠加态的退相干（与环境的接触）会让振幅在计算中途"融化"成经典概率，干涉的精细相位会失真。本脚本的矩阵乘法是精确的、完美的——它演示的是理论逻辑，不是真实硬件的表现。
2. **"均匀叠加"只是起点，不是算法。** 均匀叠加本身不产生任何有用的答案（所有基态等概率，测谁都是随机的）。它的价值在于作为"所有可能同时在场"的初始舞台，供后面的干涉（Grover）、周期提取（Shor）、特征变换（QML）在上面起舞。别把"造出均匀叠加"当成"解决了问题"。
3. **经典模拟在指数处崩溃。** 实验 1 里 n=20 已经有 $10^6$ 个振幅；n=40 就超过 $10^{12}$。用 NumPy 硬算 $H^{\otimes n}$ 的矩阵更是烧内存（$2^n \times 2^n$）。真实量子计算机的意义正在于此：它**不用存**这 $2^n$ 个振幅，它在物理上就是那个叠加。
