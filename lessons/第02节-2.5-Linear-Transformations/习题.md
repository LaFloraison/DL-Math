# 习题：线性变换

## 第一组：概念检验

**1.1（单选）** 下列哪个从 $\mathbb{R}^2$ 到 $\mathbb{R}^2$ 的函数是线性变换？
- A. $T(x, y) = (x+1, y)$
- B. $T(x, y) = (x^2, y)$
- C. $T(x, y) = (2x, 3y)$
- D. $T(x, y) = (xy, x)$

**1.2（判断并说明）** "只要 $T(\mathbf{0}) = \mathbf{0}$，$T$ 就一定是线性变换。" 这句话对吗？如果不对，举一个反例，并指出它违反了哪一条。

**1.3（填空）** 线性变换把平行四边形映成____；它把原点映到____；经过线性变换，网格线的两条性质____和____保持不变。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 设 $A = \begin{bmatrix} 1 & 2 \\ 0 & 3 \end{bmatrix}$，$T(\mathbf{v}) = A\mathbf{v}$。
(a) 手算 $T(1, 2)$；
(b) 取 $u = (1,0)$、$v = (0,1)$，手算并验证 $T(u+v) = T(u) + T(v)$；
(c) 用 `np.allclose` 验证齐次性：$T(cu) = cT(u)$，其中 $c = 3$。

**2.2（代码验证）** 生成一个 $3 \times 2$ 的随机矩阵 $A$，再随机取 100 组向量 $u, v$ 和随机标量 $c$，用一次布尔判断验证：对所有样本都可加性、齐次性同时成立。然后把变换换成 $(x, y) \mapsto (x^2, y)$，观察它在第几个样本处断裂。

**2.3（几何理解）** 设 $A = \begin{bmatrix} 3 & 0 \\ 0 & 2 \end{bmatrix}$。写出 $T(1,0)$、$T(0,1)$，并回答：网格点 $(i,j)$ 的像是怎样的网格？一个单位圆经过 $T$ 变成什么？

## 第三组：DL 延伸

**3.1（场景判断）** 一个全连接层的预激活是 $h = Wx + b$，其中 $W$ 是 $3 \times 4$ 矩阵，$b$ 是 3 维向量。
(a) 从 $x$ 到 $Wx$ 是不是线性变换？
(b) 加上 $b$ 之后还是线性变换吗？为什么？
(c) 如果一个网络只由这种层组成、完全不加激活函数，它最多能表达什么样的输入-输出关系？说出结论并解释。

**3.2（形状判断）** 一批数据 $X$ 的形状是 `(32, 4)`，权重 $W$ 的形状是 `(3, 4)`。无 bias 的前向计算 $Z = X @ W.T$ 的形状是什么？如果不小心写了 `X @ W`，会报什么错？

## 解答与思路点拨

### 第一组

**1.1 答案：C。**
- **思路**：逐一体检。A：$T(0,0) = (1, 0) \neq (0,0)$，违反"原点留原点"——直接判死刑。B：$T(1,0)=(1,0)$、$T(0,1)=(0,1)$，$T(1,1)=(1,1)$，但 $T(1,0)+T(0,1)=(1,1)$——诶，这次碰巧相等？换 $u=(2,0)$、$v=(0,1)$：$T(2,1)=(4,1)$，而 $T(2,0)+T(0,1)=(4,1)$……注意 $x^2$ 只在"两个分量各取一个数相加"时才出问题。取 $u=(1,0)$、$v=(1,0)$：$T(u+v)=T(2,0)=(4,0)$，$T(u)+T(v)=(1,0)+(1,0)=(2,0)$，不等！违反可加性。D：$xy$ 同理违反可加性。C：$T(u+v)=(2(x_1+x_2),3(y_1+y_2))=(2x_1,3y_1)+(2x_2,3y_2)=T(u)+T(v)$；齐次性 $T(cu)=(2cx,3cy)=cT(u)$——两条都过。
- **点拨**：B 很阴险——它的原点、坐标轴都对，很容易漏网。真正的检验不能只看"看着像直线"，必须代两组不同的向量验算可加性。这也是本课反复强调的：**两个点碰巧相等不算数，必须对任意 $u, v$ 成立。**

**1.2 这句话不对。**
- **思路**：$T(\mathbf{0})=\mathbf{0}$ 只是**必要条件**（线性变换必满足），不是**充分条件**。反例：$T(x,y)=(x^2,y)$——它满足 $T(0,0)=(0,0)$，但违反可加性（见 1.1 的 B 选项）。
- **点拨**：这条可以当"一票否决"的快速筛选器，但通过它不等于过关。被它筛掉的（如平移）一定不是线性变换；没被筛掉的，还得继续验可加性与齐次性。把"必要条件"当成"充分条件"，是概念题最常见的失分点。

**1.3 答案：平行四边形 / 原点 / 平行、等距。**
- **思路**：平行四边形的对角线是 $u+v$，可加性保证"对角线的像 = 像的对角线"。原点 $T(\mathbf{0})=\mathbf{0}$ 是齐次性取 $c=0$ 的直接推论。网格点 $(i,j)=ie_1+je_2$ 的像是 $iT(e_1)+jT(e_2)$——还是"以两个基像为边的整数网格"，所以平行、等距。
- **点拨**：这三个空其实是同一个事实的三个视角：**网格的命运被基向量的像完全锁定**。记住这句话，后面的矩阵表示（§2.5.1）就是它的展开。

### 第二组

**2.1**
(a) $T(1,2) = \begin{bmatrix} 1 & 2 \\ 0 & 3 \end{bmatrix}\begin{bmatrix}1\\2\end{bmatrix} = (1\cdot1 + 2\cdot2,\ 0\cdot1 + 3\cdot2) = (5, 6)$。

(b) $T(u) = A(1,0) = (1,0)$，$T(v) = A(0,1) = (2,3)$。$u+v=(1,1)$，$T(u+v) = A(1,1) = (1+2,\ 0+3) = (3,3)$。而 $T(u)+T(v) = (1,0)+(2,3) = (3,3)$。相等 ✓。

(c) $T(cu) = T(3,0) = (3,0)$；$cT(u) = 3(1,0) = (3,0)$。相等 ✓。

```python
import numpy as np
A = np.array([[1.0, 2.0],
              [0.0, 3.0]])
u, v, c = np.array([1.0, 0.0]), np.array([0.0, 1.0]), 3.0
print("T(u+v)=", A @ (u + v), " T(u)+T(v)=", (A @ u) + (A @ v))
print("T(cu)=", A @ (c * u), " c*T(u)=", c * (A @ u))
print(np.allclose(A @ (u + v), (A @ u) + (A @ v)),
      np.allclose(A @ (c * u), c * (A @ u)))
# T(u+v)= [3. 3.]  T(u)+T(v)= [3. 3.]
# T(cu)= [3. 0.]  c*T(u)= [3. 0.]
# True True
```
- **思路**：注意 $A$ 的第一行是 $T$ 对 $e_1=(1,0)$ 的像，第二行是 $T$ 对 $e_2=(0,1)$ 的像——验证可加性时我们其实在验证"两个基像相加"。
- **点拨**：$A$ 是**上三角矩阵**，它的变换效果是把平面"向右上方斜推"。这类"用几组具体向量手算"是唯一能建立直觉的方式——算过一遍，比背十条性质都牢。

**2.2**

```python
import numpy as np
A = np.random.randn(3, 2)                 # 3×2：一个 R² → R³ 的线性变换
ok = True
for _ in range(100):
    u, v = np.random.randn(2), np.random.randn(2)
    c = np.random.randn()
    ok &= np.allclose(A @ (u + v), (A @ u) + (A @ v))
    ok &= np.allclose(A @ (c * u), c * (A @ u))
print("矩阵 A：100 组样本全部通过 →", ok)    # True

def crooked(v):
    return np.array([v[0]**2, v[1]])

for k in range(100):
    u, v = np.random.randn(2), np.random.randn(2)
    if not np.allclose(crooked(u + v), crooked(u) + crooked(v)):
        print("平方机器第", k + 1, "个样本断裂:",
              "T(u+v)=", crooked(u + v), " vs T(u)+T(v)=", crooked(u) + crooked(v))
        break
```
- **思路**：随机矩阵 $A$ 几乎必然"满秩且不特殊"，所以它能代表"绝大多数线性变换"——全部 100 组都通过，这不是巧合，是定理：**任何矩阵乘法都是线性变换**（§2.5.1）。而平方机器几乎必然在第一个样本就断裂，因为可加性对它是恒假命题。
- **点拨**：两个 `ok &=` 里，用 `&=` 累积布尔值，最后只打印一次判断。若写成循环内逐次打印，会刷屏。注意 $A$ 是 $3 \times 2$，输出向量是 3 维——线性变换允许改变空间的维度，这正是"从 $\mathbb{R}^2$ 搬进 $\mathbb{R}^3$"。

**2.3**
$T(1,0) = (3, 0)$，$T(0,1) = (0, 2)$。网格点 $(i,j)$ 的像是 $(3i, 2j)$——一张横间距 3、纵间距 2 的矩形网格，仍然平行、等距，只是每个格子被拉成了 $3 \times 2$ 的矩形。单位圆 $\{(x,y): x^2+y^2=1\}$ 变成 $x'^2/9 + y'^2/4 = 1$——一个长轴 3、短轴 2 的椭圆（以原点为中心）。
- **思路**：对角矩阵只缩放坐标轴方向，不旋转、不倾斜。$(i,j)$ 经过它是"横坐标乘 3、纵坐标乘 2"，所以圆被拉伸成椭圆。
- **点拨**：这是"矩阵的第 $i$ 行 = 第 $i$ 个基像"的最直观例子。圆→椭圆是线性变换的经典名片：**它把圆变成椭圆，但永远不会把圆变成星形**——这就是"不弯曲"。

### 第三组

**3.1**
(a) **是**。$Wx$ 是矩阵乘向量，任何矩阵乘法都满足可加性与齐次性（可加性：$W(u+v)=Wu+Wv$ 是矩阵乘法对向量加法的分配律）。
(b) **不是（当 $b\neq 0$）**。加 $b$ 之后 $T(\mathbf{0}) = W\mathbf{0} + b = b \neq \mathbf{0}$——违反"原点留原点"。它是**仿射变换** (affine)，不是线性变换。这个区别在深度学习里是常态：几乎所有 `nn.Linear` 层都带 bias，所以严格说它们都是仿射层。
(c) **最多能表达一个仿射映射（一条直线或一个超平面）**。理由：线性变换的复合还是线性变换（$T_2(T_1(x)) = T_2T_1(x)$ 仍是矩阵乘），带 bias 的复合仍是仿射。所以无论叠多少层，整体等价于 $y = Wx + b$——一个超平面。它切不开 XOR 这类非线性可分的数据，这就是为什么网络必须在每层之间插入非线性激活（§2.2.3.3、§2.5.3 会深入）。
- **点拨**：这道题的陷阱是"看着层数很多就觉得很强"。**线性层叠多少层都等于一层**，这是深度学习入门最反直觉也最重要的一句话。

**3.2**
$Z = X @ W.T$ 的结果形状是 `(32, 3)`——每行是一个样本，每列对应 $W$ 的一个输出神经元。
如果写 `X @ W`：`(32, 4) @ (3, 4)`，内维 `4` 与 `3` 不匹配，NumPy 会抛 `ValueError: matmul: Input operand 1 has a mismatch in its core dimension`（矩阵乘法要求"左边列数 = 右边行数"）。也就是说，`(32,4)` 的第二个维度 `4` 必须等于 `W` 的第一个维度，而 `W` 的第一个维度是 `3`。
- **思路**：$Z = XW^T$ 的矩阵形状法则：$(32,4)\cdot(4,3) = (32,3)$。为什么转置？因为 `X` 的每行是一个样本向量，要拿它去乘 $W$ 的每一行（每个输出神经元的权重向量），所以输出形状的列数来自 $W$ 的**行**数。
- **点拨**：把"矩阵形状必须匹配"和"$W$ 的行数 = 输出维度"这两条一起记，能避开深度学习里最高频的形状错误。参考 §2.3.2（Dimensions）与 §2.3.4.3（矩阵乘法）。

## 一个"为什么有人会答错"的提醒

- **1.1 的 B 与 1.2 是同一个坑**：$T(x,y)=(x^2,y)$ 原点、坐标轴全对，看起来"很线性"。判断线性变换的**唯一**判据是两条性质对**所有** $u,v,c$ 成立——一组向量碰巧成立不算数，必须换几组再验。
- **1.1 的 A 与平移**：$(x,y)\to(x+1,y)$ 是最常见的"看起来简单其实不线性"的陷阱——直线还是直线，但原点被挪走了。用 $T(\mathbf{0})=\mathbf{0}$ 一票否决。
- **3.1(c) 的直觉偏差**：人们容易觉得"层数 = 复杂度"。对线性层，这个等式是错的——线性复合仍是线性。复杂度必须来自非线性。这是整节课最该带走的一句话。
