## 第一步：Toy Model —— 一台不弯曲的机器

你面前有一张印着标准网格的坐标纸：竖线、横线等间距地铺满纸面，每个点用两个数 $(x, y)$ 定位。现在你造了一台"变换机器"：把整张纸塞进入口，出口吐出一张新纸，纸上每个点都被搬到了一个新位置。

机器有两种性格。

**守规矩的机器。** 你可以把纸横着拉宽（横坐标翻倍）、转一个角度、像拧毛巾一样斜斜地拉长。但无论怎么拉，网格线始终是直的、平行的、等距的。一条直线，进去是直线，出来还是直线。

**不守规矩的机器。** 你把手伸进纸的中央，把纸顶出一个鼓包。网格线弯了。一条直线进去，出来是一条弧线。

你很快发现，"守规矩"的机器有一个奇妙的脾气——**它不在乎你什么时候组装**。取两个点 $u = (2, 1)$ 和 $v = (1, 3)$，它们是平行四边形的两条边；$u + v = (3, 4)$ 是对角线顶点。让它们通过一台"横坐标翻倍"的机器（每个点 $(x,y) \mapsto (2x, y)$）。

先算"先相加，再变换"：$(3,4)$ 进机器 → $(6,4)$。
再算"先变换，再相加"：$(2,1) \to (4,1)$，$(1,3) \to (2,3)$，相加 → $(6,4)$。

一样！

再试倍率。把 $u = (2,1)$ 放大 3 倍成 $(6,3)$，进机器 → $(12,3)$。或者让 $u$ 先进机器得到 $(4,1)$，再放大 3 倍 → $(12,3)$。还是一样！

这台机器不关心你"先组合再变"还是"先变再组合"——加法、数乘，顺序随便怎么安排，殊途同归。这就是"守规矩"的准确含义：**它不弯曲**。

但是等等。是不是所有机器都这么讲道理？你造了一台"平方机器"：$(x, y) \mapsto (x^2, y)$。取 $u = (1, 2)$、$v = (3, 1)$。先相加：$(4,3)$ 进机器 → $(16, 3)$。先变换：$(1,2)\to(1,2)$、$(3,1)\to(9,1)$，相加 → $(10, 3)$。不一样！平方机器在乎顺序——**它弯了**。

直觉到这里开始抓不住。"守规矩"到底是哪种脾气？"弯不弯"是画出来的感觉——可直线经过平移也还是直线，平方机器弯了，平移机器呢？如果不能用一串符号说清楚"什么是守规矩"，我们凭什么断定一台没见过的机器守不守规矩？

——我们需要数学。

## 第二步：正式数学讲解

### 一、撞墙：怎么把"不弯曲"变成一行符号？

你说："守规矩的机器不弯曲。"可"不弯曲"怎么翻译成数学？

先试第一条候选：**直线变直线**。你拿 $(x,y) \mapsto (x^2, y)$ 去检验，直线 $x=1$（一条竖线）被它弯成了一条抛物线——它出局了。可你转念一想：把整张纸**平移**一个单位，$(x,y) \mapsto (x+1, y)$，直线还是直线！它"守规矩"吗？用刚才的检验法：$u=(1,0)$、$v=(0,1)$，$u+v=(1,1)$。先相加：$(1,1) \to (2,1)$。先变换：$(1,0)\to(2,0)$、$(0,1)\to(1,1)$，相加 → $(3,1)$。不一样！平移机器也不守规矩，可它的直线明明是直线。

所以"直线变直线"太粗糙了。真正的判据要更隐蔽、更深刻：**它必须尊重"组装方式"本身。** 你手里有一个点，有两种合法的组装方式——加法（把 $u$ 和 $v$ 拼成 $u+v$）与数乘（把 $u$ 放大成 $cu$）。守规矩的机器要求：**先组装再变换，和先变换再组装，结果必须一模一样。**

这就是把具体数字换成字母的时刻。刚才我们验证的是 $(2,1)$、$(1,3)$、3 倍、横坐标翻倍——可为什么是这两个点，不是别的点？为什么是 3 倍，不是 7 倍？你盯着算出来的那几行数字看：没有任何一个地方依赖"2"或者"3"本身。任何一个点、任何一个倍数，同样的道理都成立。于是，把具体的点换成字母 $u$、$v$，把具体的倍数换成字母 $c$，我们得到两台机器都必须遵守的两条铁律。

### 二、定义块

> **线性变换 (linear transformation / linear map)** $T: V \to W$
>
> 设 $V$、$W$ 是两个向量空间。映射 $T: V \to W$ 称为**线性变换**，如果对任意向量 $\mathbf{u}, \mathbf{v} \in V$ 和任意标量 $c \in \mathbb{R}$，下面两条同时成立：
>
> 1. **可加性 (additivity)**：$T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$——先相加再变换，等于先变换再相加
> 2. **齐次性 (homogeneity)**：$T(c\mathbf{u}) = c\,T(\mathbf{u})$——先缩放再变换，等于先变换再缩放
>
> 两条可以合成一条：$T(a\mathbf{u} + b\mathbf{v}) = a\,T(\mathbf{u}) + b\,T(\mathbf{v})$——**线性变换保持线性组合**。特殊地，取 $c = 0$ 得到 $T(\mathbf{0}) = \mathbf{0}$：线性变换必把零向量映到零向量。
>
> - 每个符号的含义：$V$、$W$ 是两个向量空间（本课的 Toy Model 里都是 $\mathbb{R}^2$）；$T$ 是映射本身（那台机器）；$\mathbf{u}, \mathbf{v}$ 是 $V$ 中任意输入向量；$c$ 是任意实数标量（缩放倍率）；$T(\mathbf{u})$ 是 $\mathbf{u}$ 在 $W$ 中的像。
> - 几何直觉："不弯曲"——直线映成直线，平行线映成平行线，网格保持平行与等距，平行四边形映成平行四边形，原点留在原点。

### 三、展开

**1. 两条其实是一条。** 用可加性套两次：$T(a\mathbf{u}+b\mathbf{v}) = T(a\mathbf{u}) + T(b\mathbf{v}) = aT(\mathbf{u}) + bT(\mathbf{v})$。反过来，这条也蕴含两条——取 $a=b=1$ 得到可加性，取 $b=0$ 得到齐次性。所以"保持线性组合"是线性变换最凝练的表述。

**2. 原点必须留在原点——一票否决的体检。** 取 $c=0$：$T(\mathbf{0}) = T(0\cdot\mathbf{u}) = 0\cdot T(\mathbf{u}) = \mathbf{0}$。这是免费的体检——凡是一眼看到 $T(\mathbf{0}) \neq \mathbf{0}$ 的变换（比如平移 $(x,y)\to(x+1,y)$ 把原点移到了 $(1,0)$），直接判死刑，不用再算。注意这是**必要条件**，不是充分条件：$T(\mathbf{0})=\mathbf{0}$ 的变换（如平方机器 $(x,y)\to(x^2,y)$）照样可能不线性。

**3. 手算一台具体机器。** 矩阵 $A = \begin{bmatrix} 2 & 1 \\ 1 & 3 \end{bmatrix}$，定义 $T(\mathbf{v}) = A\mathbf{v}$。取 $u=(1,2)$、$v=(3,-1)$。先算像：$T(u) = (4, 7)$，$T(v) = (5, 0)$。可加性：$u+v = (4,1)$，$T(u+v) = (9,7)$，而 $T(u)+T(v) = (9,7)$——相等。齐次性：$c=2.5$，$T(2.5u) = (10, 17.5)$，$2.5\,T(u) = (10, 17.5)$——相等。矩阵 $A$ 和线性变换之间这种一一对应，是 §2.5.1 的内容——但你已经看到：**矩阵就是这台机器的说明书**，每一行告诉它把一条基向量搬到哪。

**4. 几何：网格为什么保持平行等距。** 因为网格点本来就是基向量的整数倍线性组合：$(i,j) = i\,(1,0) + j\,(0,1)$。线性性保证组合被逐项保留：$T(i,j) = i\,T(1,0) + j\,T(0,1)$。于是整张网格的像，还是"以 $T(1,0)$、$T(0,1)$ 为两条边的整数网格"——只是两条边换了方向、换了长度。平行没丢、等距没丢。平行四边形为什么还是平行四边形？因为对角线 $u+v$ 的像 $T(u+v)$ 恰等于像的对角线 $T(u)+T(v)$——这正是可加性。**整个网格的命运，被两个基向量的像完全锁定。**

**5. 边界声明：线性变换≠"看起来简单"。** 平移 $(x,y)\to(x+1,y)$ 简单至极，却不线性（原点被搬走了）。平方 $(x,y)\to(x^2,y)$ 简单至极，也不线性（平方破坏可加性）。线性变换实际上极严格：它必须同时尊重加法和数乘这两套组装规则，一条都不能少。更远一点：神经网络里那些"不弯曲"的层（权重矩阵乘法）确实是线性的——而让网络真正有表达力的，恰恰是夹在层与层之间那些**故意的弯曲**（非线性激活函数）。这个张力，正是第三步的入口。

## 第三步：DL 桥接

每一层神经网络的核心，都是一次线性变换。

**具体到符号。** 全连接层的预激活是 $\mathbf{z} = W\mathbf{x} + \mathbf{b}$——其中 $W\mathbf{x}$ 是一次线性变换：权重矩阵 $W$ 把输入向量 $\mathbf{x}$ 线性地搬进一个新的空间。当 $\mathbf{b} = \mathbf{0}$ 时整层就是纯线性变换；$\mathbf{b} \neq \mathbf{0}$ 时它是**仿射** (affine)——多了一次平移，严格地说不是线性（$T(\mathbf{0}) = \mathbf{b} \neq \mathbf{0}$）。这个区别，正是本课"原点必须留在原点"那项体检在深度学习里的直接翻版。

**线性的致命温柔与致命局限。** 两个线性变换的复合仍是线性变换：$T_2\big(T_1(\mathbf{u}+\mathbf{v})\big) = T_2\big(T_1(\mathbf{u}) + T_1(\mathbf{v})\big) = T_2T_1(\mathbf{u}) + T_2T_1(\mathbf{v})$。所以**只有线性层的网络，叠多少层都等价于一个线性变换**——它只能把整个空间像一张刚体网格那样搬动，永远切不开"XOR"这种直线分不了的数据。真正让网络从"搬网格"变成"揉面"的，是每层之后那个非线性激活 $\sigma(\cdot)$（ReLU、sigmoid）：$\mathbf{h} = \sigma(W\mathbf{x} + \mathbf{b})$。**线性变换提供骨架，非线性提供褶皱。**

在 §2.5.3 与教材后续章节你会看到，Transformer 里 Attention 的三次投影 $Q = W_q X$、$K = W_k X$、$V = W_v X$ 正是三台不同的"不弯曲机器"——每个 token 的向量被三台机器搬进三个不同的空间，然后模型在那些空间里比较它们的相似度。"Attention Is All You Need" 里几乎所有的可学习参数，都住在线性变换的矩阵里。你此刻学会的两条规则，就是那些千百亿参数共同遵守的宪法。
