# 历史：一台"不弯曲的机器"，从哥廷根的雨夜到 GPU 集群

## 1903 年，哥廷根，一场"未知是一条曲线"的危机

十九世纪末，欧洲的物理学家们被一类崭新的方程困住了。

过去，解方程是"找出一个数"。小学就会。可新方程要的是**找出整整一条曲线**——一条在每个位置都满足某种约束的曲线。未知量不是几个数，而是无穷多个数。这几乎让当时的数学家失眠：人类的直觉擅长对付一个未知数，谁能对付一整片？

瑞典数学家**弗雷德霍姆 (Ivar Fredholm)** 找到了破局的姿势。他盯着这类方程，忽然意识到：它们可以看成"**无穷多个未知数的线性方程组**"——就是中学那种联立方程，只不过未知数从两个变成无穷多个。他把方程里那台复杂的机器抽象出来，一个更纯粹的形体浮出水面：一台"**吃进一条曲线、吐出一条曲线**"的机器。

然后他注意到了那台机器一个近乎平凡的脾气：把两条曲线一起喂进去，得到的结果，**正好等于分别喂这两条曲线、再把结果相加**。把一条曲线放成两倍大喂进去，得到的结果，**正好是原来结果的翻倍**。

机器不弯曲。

## 为什么"不弯曲"让希尔伯特发狂

1903 年，弗雷德霍姆的论文摆到了**希尔伯特 (David Hilbert)** 的桌上——哥廷根大学那位年轻的数学领袖。

这个"不弯曲"的性质看起来平淡无奇，希尔伯特却嗅到了巨大的力量。他顺着它往下挖，得出一个几乎令人眩晕的结论：**一台不弯曲的机器，行为被"少数几个样板"完全锁死。** 只要知道它对几个基本输入分别做了什么，它对任何输入的响应都能拼出来——因为任何输入都是基本输入的线性组合，而"不弯曲"保证了组合被逐项保留。整片无穷维度的空间，被一张有限的表驯服了。

这是数学史上少有的时刻：一个概念因为"太有用"而被反复发明。希尔伯特在接下来的几年里，把这个想法打磨成一整套理论——算子的理论、谱的理论。量子力学随后赶来，海森堡和薛定谔发现，原子世界的观测本身，就是一台台不弯曲的机器。整个二十世纪物理学的骨架，被这个"不弯曲"的概念撑了起来。

## 从油灯到 GPU：不弯曲的机器成为深度学习的骨骼

时间快进整整一个世纪。

1958 年，**罗森布拉特 (Frank Rosenblatt)** 造出感知机——一台"不弯曲的分类器"。它画的决策边界是一条直线，因为它做的一切只是一次线性变换加上一个阈值。直线分不开的东西，它永远分不开，这让第一代神经网络撞上了天花板。

1980 年代，反向传播普及之后，研究者们才真正想明白那个窍门：**把"不弯曲"和"弯曲"交替堆叠。** 一层线性变换，跟着一个非线性弯曲（激活函数），再来一层线性变换，再弯曲一次……直线被一段段拧弯，越拧越复杂，直到能贴合任何形状。深度学习的"深"，不是线性层叠得深，而是"不弯曲"与"弯曲"交错的次数深。

2017 年，"Attention Is All You Need" 发表。Transformer 里，每一个 token 的向量，都被几台不同的"不弯曲机器"（查询、键、值的投影）同时搬进不同的空间，模型再去比较它们的位置。今天，那些动辄千亿的参数，绝大多数住在这些不弯曲机器的矩阵里。

## 留一扇门

一百二十年前，希尔伯特在哥廷根的雨夜里凝视的那台"不弯曲的机器"，今天有一个朴素的名字——**线性变换 (linear transformation)**。教材只用两条规则就锁死了它的一切行为。可"不弯曲"到底怎么被翻译成精确的符号？两条规则够不够？为什么少了任何一条，机器就会悄悄弯掉？

主线里，我们会亲手拧动这台机器，把它的脾气摸个清楚。
