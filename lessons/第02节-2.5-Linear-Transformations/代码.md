# 代码：用 NumPy 造一台"不弯曲的机器"，并验证它的两条铁律

主线里我们用手算验证了一台矩阵机器满足 $T(u+v)=T(u)+T(v)$ 与 $T(cu)=cT(u)$。这一节把这两条铁律变成代码：用一个 2×2 矩阵实现线性变换，逐条体检可加性与齐次性，再让一台"平方机器"当众被抓包——最后用网格变换演示"网格线保持平行等距"。

脚本只依赖 NumPy，约 40 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                            # NumPy：矩阵与向量运算的家

# ---- ① 线性变换的"身份证"：2×2 矩阵 A ----
A = np.array([[2.0, 1.0],                     # 第 1 行：T(1,0) 的像 = (2,1)
              [1.0, 3.0]])                    # 第 2 行：T(0,1) 的像 = (1,3)

# ---- ② 实现线性变换 T(v) = A @ v ----
def linear_map(A, v):
    return A @ v                              # 矩阵乘向量：逐行点积

# ---- ③ 验证可加性：T(u+v) = T(u) + T(v) ----
u = np.array([1.0, 2.0])
v = np.array([3.0, -1.0])
lhs = linear_map(A, u + v)                    # 先相加，再变换
rhs = linear_map(A, u) + linear_map(A, v)     # 先变换，再相加
print("T(u+v)     =", lhs)
print("T(u)+T(v)  =", rhs)
print("可加性成立?  =", np.allclose(lhs, rhs))  # True

# ---- ④ 验证齐次性：T(cu) = c·T(u) ----
c = 2.5
lhs = linear_map(A, c * u)                    # 先放大，再变换
rhs = c * linear_map(A, u)                    # 先变换，再放大
print("T(cu)      =", lhs)
print("c·T(u)     =", rhs)
print("齐次性成立?  =", np.allclose(lhs, rhs))  # True

# ---- ⑤ 平方机器被抓包：不满足可加性 ----
def crooked(v):
    return np.array([v[0]**2, v[1]])          # 非线性：第一个分量被平方

u2 = np.array([1.0, 2.0])
v2 = np.array([3.0, 1.0])
print("弯 T(u+v)     =", crooked(u2 + v2))
print("弯 T(u)+T(v)  =", crooked(u2) + crooked(v2))
print("可加性成立?    =", np.allclose(crooked(u2+v2), crooked(u2)+crooked(v2)))  # False

# ---- ⑥ 网格保持平行等距：像 = i·T(e1) + j·T(e2) ----
e1, e2 = np.array([1.0, 0.0]), np.array([0.0, 1.0])
Te1, Te2 = linear_map(A, e1), linear_map(A, e2)   # 基向量的像 (2,1)、(1,3)
grid = np.array([[i, j] for i in range(-2, 3) for j in range(-2, 3)], dtype=float)
im   = grid @ A.T                             # 每一行 = 一个网格点的像
d_row = im[5] - im[0]                         # 水平相邻两点像之差
print("T(e1) =", Te1, "  T(e2) =", Te2)
print("(-2,-2) 的像 =", np.round(im[0], 2), "   (2,2) 的像 =", np.round(im[-1], 2))
print("水平相邻像之差 =", d_row, " 应等于 T(e1):", np.allclose(d_row, Te1))
```

运行输出（Python 3.11 + NumPy）：

```text

可加性成立?  = True

齐次性成立?  = True
弯 T(u+v)     = [16.  3.]
弯 T(u)+T(v)  = [10.  3.]
```

## 层二：分步逐函数拆解

### 步骤 1：定义变换矩阵 A

```python
A = np.array([[2.0, 1.0],
              [1.0, 3.0]])
```

#### `np.array(嵌套列表)` —— 造一个 2×2 矩阵

**做什么**：把嵌套列表转成 NumPy 的二维数组——这就是"线性变换在计算机里的存在形式"。
**操作**：`np.array` 按嵌套顺序填入数值，推断出 `float64`，按行存入内存。
**输入**：`[[2.0, 1.0], [1.0, 3.0]]`——外层列表是"行"，内层列表是"这一行的分量"。
**输出**：形状 `(2, 2)` 的 `ndarray`。`A[0]` 是第一行 `[2., 1.]`，`A[1, 1]` 是右下角元素 `3.0`。
**可调参数**：
- 换任何数就是另一台机器。比如 `[[3.0, 0.0], [0.0, 2.0]]` 是"沿 x 轴拉 3 倍、沿 y 轴拉 2 倍"的对角缩放；`[[0.0, -1.0], [1.0, 0.0]]` 是逆时针旋转 90°。
- 传 `dtype`: `np.array([[1, 0], [0, 1]], dtype=float)` 强制转浮点；深度学习里常用 `np.float32` 省显存。
- 行数、列数可不相等：`np.array([[1.0, 2.0], [0.0, 1.0], [1.0, 1.0]])` 是形状 `(3, 2)` 的矩阵——对应一个从 $\mathbb{R}^2$ 到 $\mathbb{R}^3$ 的线性变换。
**对应数学**：主线里 $T(\mathbf{v}) = A\mathbf{v}$ 的手算。矩阵第 $i$ 行正好是 $T$ 对第 $i$ 个基向量 $e_i$ 的像——这个"矩阵=基像拼成的表格"的对应，是 §2.5.1 的正式内容。

### 步骤 2：实现线性变换

```python
def linear_map(A, v):
    return A @ v
```

#### `def linear_map(A, v)` —— 自己写一个"变换机器"

**做什么**：把主线里"矩阵乘向量"这一步封装成一个函数，方便反复调用。
**操作**：函数体只有一行——调用 `@` 运算符。这个函数本身不写字，它只是给 `A @ v` 起了个数学味更浓的名字。
**输入**：`A`（变换矩阵，形状 `(m, n)`）与 `v`（输入向量，形状 `(n,)`）。
**输出**：像向量，形状 `(m,)`。
**可调参数**：这就是我们自己的函数，两个形参都开放。`A` 可以换成任何形状 `(m, n)` 的矩阵（不要求方阵），只要 `v` 的形状是 `(n,)`。注意：这里只接受一个向量；要对一批向量同时变换，直接 `A @ X`（见步骤 6）——这就是深度学习里"一个矩阵乘整个批次"的原型。

#### `@` 运算符 —— 矩阵乘向量

**操作**：$A$ 的每一行与 $v$ 做点积，得到输出的一个分量：$(A \otimes v)_i = \sum_j A_{ij}\, v_j$。行数决定输出维度，列数必须等于 $v$ 的长度。
**输入**：`A` 形状 `(2, 2)`，`v` 形状 `(2,)`——内维 `2` 与 `2` 对齐，才能乘。
**输出**：形状 `(2,)`。`T(u) = A@u = [2·1+1·2, 1·1+3·2] = [4., 7.]`。
**可调参数**：`@` 是运算符，没有参数。若左边是矩阵、右边也是矩阵（形状 `(n, k)`），则结果是形状 `(m, k)` 的矩阵——相当于把 $k$ 个列向量一次性全部变换。深度学习中 `W @ X` 就是这样批量完成的（X 的每一列是一个样本）。
**对应数学**：主线 §2.5 定义块里的 $T(\mathbf{v})$，手算是"逐行点积"，这里一行代码等价。

### 步骤 3：验证可加性

```python
lhs = linear_map(A, u + v)
rhs = linear_map(A, u) + linear_map(A, v)
print("可加性成立?  =", np.allclose(lhs, rhs))
```

#### `u + v` —— 向量加法（逐元素）

**操作**：两个形状相同的数组对应位置相加：$(u+v)_i = u_i + v_i$。`[1,2] + [3,-1] = [4, 1]`。
**输入**：`u`、`v`，形状 `(2,)`。
**输出**：形状 `(2,)` 的和向量。
**可调参数**：无参数。形状不匹配会抛广播错误——`(2,)` 只能和 `(2,)` 或能广播到 `(2,)` 的形状相加。

#### `np.allclose(a, b)` —— 带容差的相等判断

**做什么**：判断两个数组是否"数值上足够接近"。浮点运算有舍入误差，`1.0000000000000002` 与 `1.0` 用 `==` 会判为不等，但数学上它们就是同一个数。
**操作**：对每个位置检查 $|a_i - b_i| \le atol + rtol \cdot |b_i|$，全部通过才返回 `True`。
**输入**：两个形状相同的数组 `lhs`、`rhs`。
**输出**：单个布尔值 `True` 或 `False`。
**可调参数**：
- `rtol=1e-05`：相对容差，按 `b` 的尺度缩放允许误差。训练中比较 loss 时想更宽松，可以调大，如 `rtol=1e-3`。
- `atol=1e-08`：绝对容差，与数值大小无关的底线。比较极小的数（如梯度逼近 0）时要把 `atol` 调小，否则误差会被掩盖。
- 还有第三个用法：`np.allclose` 不接受"部分容差"——要么全真，要么全假，返回一个标量而不是逐位数组。
**对应数学**：可加性 $T(u+v) = T(u) + T(v)$。`lhs` 是"先相加再变换" $(9,7)$，`rhs` 是"先变换再相加" $(9,7)$——两边一致，机器通过体检。

### 步骤 4：验证齐次性

```python
c = 2.5
lhs = linear_map(A, c * u)
rhs = c * linear_map(A, u)
print("齐次性成立?  =", np.allclose(lhs, rhs))
```

#### `c * u` —— 标量乘向量（逐元素缩放）

**操作**：向量的每个分量都乘以同一个标量：$c\,(u_1, u_2) = (cu_1, cu_2)$。`2.5 * [1,2] = [2.5, 5.]`。
**输入**：标量 `c=2.5` 与数组 `u`，形状 `(2,)`。这里用了**广播 (broadcasting)**：NumPy 把标量自动"展开"成与 `u` 同形状后再逐元素相乘。
**输出**：形状 `(2,)`。
**可调参数**：`c` 可以是任意实数——负数会反向，`0` 会把整个向量归零（这就是 $T(\mathbf{0})=\mathbf{0}$ 的由来），小数是压缩。若把 `c` 换成另一个向量，则变成逐元素乘法（Hadamard 积）——那是另一回事，不是齐次性。标量乘向量是"每个分量等比缩放"，这正是线性变换的齐次性来源。
**对应数学**：齐次性 $T(c\mathbf{u}) = cT(\mathbf{u})$。左边 $(10, 17.5)$，右边 $2.5 \cdot (4,7) = (10, 17.5)$——一致。

### 步骤 5：平方机器被抓包

```python
def crooked(v):
    return np.array([v[0]**2, v[1]])
```

#### `v[0]**2` —— 分量平方（非线性的来源）

**做什么**：把向量的第一个分量平方。这个函数就是主线 Toy Model 里那台"平方机器"。
**操作**：`v[0]**2` 计算 $x^2$。平方**不能**写成"某个矩阵乘 $v$"——因为任何矩阵乘法对 $x$ 都是线性的，而 $x^2$ 不是。`np.array([...])` 把两个标量拼回形状 `(2,)` 的向量。
**输入**：`v`，形状 `(2,)`。
**输出**：形状 `(2,)`。
**可调参数**：把 `**2` 换成 `**3`、`np.abs(v[0])`、`np.exp(v[0])`、`np.maximum(0, v[0])`（这就是 ReLU！）——它们都会破坏线性，但各有各的用途。这就是深度学习里"激活函数家族"的数学位置：故意引入不可线性化的弯曲。
**对应数学**：主线"撞墙"里的反例。平方破坏可加性：$T(u+v) = (16, 3)$，而 $T(u)+T(v) = (10, 3)$——`np.allclose` 返回 `False`，机器当场现形。

### 步骤 6：网格保持平行等距

```python
grid = np.array([[i, j] for i in range(-2, 3) for j in range(-2, 3)], dtype=float)
im   = grid @ A.T
d_row = im[5] - im[0]
```

#### `grid @ A.T` —— 每行一个点，一次性变换整张网格

**做什么**：把 25 个网格点 $(-2,-2)$ 到 $(2,2)$ 全部交给矩阵 $A$ 变换。
**操作**：为什么用 `A.T` 而不是 `A`？因为 `grid` 的每一行是"行向量" $v$，而我们想算的是 $Av$（列向量的标准写法）。转置一下：$(v\,A^\top)_i = \sum_j v_j A^\top_{ji} = \sum_j v_j A_{ij} = (Av)_i$——数学上等价，且每行还是"这个点的像"。这是一行代码批量变换整张网格的关键技巧。
**输入**：`grid` 形状 `(25, 2)`，`A.T` 形状 `(2, 2)`。内维 `2` 对齐。
**输出**：`im` 形状 `(25, 2)`，第 $k$ 行是第 $k$ 个网格点的像。
**可调参数**：把列表推导的 `range(-2, 3)` 换成更大范围就是更密的网格；用 `np.meshgrid(np.arange(-2,3), np.arange(-2,3))` 能生成结构化形状 `(5, 5, 2)` 的网格，再 `grid @ A.T` 同样可行——注意 reshape 的顺序别弄反。
**对应数学**：网格点 $(i,j) = i\,e_1 + j\,e_2$，线性性保证像 $= i\,T(e_1) + j\,T(e_2)$。`T(e1)=[2,1]`、`T(e2)=[1,3]` 锁定整张网格：任何相邻两个点的像之差恒定（`d_row == Te1`），说明水平方向间距处处相等——**平行、等距，由线性性自动保证**。

## 边界声明：这套代码能做什么，不能做什么

1. **`A` 是方阵，线性变换不限于此。** 本脚本的 $A$ 是 $2\times 2$，对应 $\mathbb{R}^2 \to \mathbb{R}^2$。线性变换可以在不同维度的空间之间进行：形状 `(m, n)` 的矩阵对应 $\mathbb{R}^n \to \mathbb{R}^m$。§2.5.1 会正式建立"矩阵 ↔ 线性变换"的一一对应。
2. **带偏置的层不是线性变换。** $h = Wx + b$ 在 $b \neq 0$ 时是仿射变换（affine），不是线性变换——体检第一项就过不了：$T(\mathbf{0}) = b \neq \mathbf{0}$。PyTorch 的 `nn.Linear` 默认带 `bias=True`；要一个纯线性映射，必须显式设 `bias=False`。
3. **数值验算 ≠ 数学证明。** `np.allclose` 用容差比较浮点数，它能"抓出错案"，却不能"证明定理"。$T(u+v)=T(u)+T(v)$ 对所有向量成立，靠的是符号推导（可加性证明），不是跑一万组随机数。
4. **"平行等距"在这里是数字证据，不是视觉证据。** 真正"看见"网格保持平行等距，需要把变换前后的网格画出来（matplotlib）——建议配合 3Blue1Brown 的线性变换动画一起看。
5. **线性不是"简单"的同义词。** 平方机器、平移机器看起来都"简单"，却不线性。本课定义的线性是极严格的约束——这也是为什么深度学习必须在每个线性层之间插入非线性激活（步骤 5 的 ReLU 正是这种"故意的弯曲"）。把 `linear_map` 换成 `crooked`，一切验证都会塌。
