# 习题：量子比特

## 第一组：概念检验

### 1.1 经典比特与量子比特的本质区别是什么？用"旋转的硬币"这个比喻回答，并指出比喻的局限。

**解答**：经典比特是"已倒下的硬币"——已经选定 0 或 1，是确定的事实；量子比特是"还在旋转的硬币"——同时处于 $|0\rangle$ 和 $|1\rangle$ 的叠加，直到测量才坍塌。本质区别不是"量子比特有第三态"，而是**经典比特的状态是确定的，量子比特的状态是未定的叠加**。比喻的局限：硬币是宏观物体，它的"旋转"是经典运动（每一瞬间都有确定的方向）；量子比特的"叠加"没有对应的经典图像——它不是"在 0 和 1 之间来回切换"，而是真正同时处于两者。比喻帮你建立直觉，但别把"旋转"当真。

**思路点拨**：两个常犯错误：(1) 说量子比特"既是 0 又是 1 之外还有第三态"——错，它没有第三确定态；(2) 说量子比特"50% 是 0、50% 是 1"——这个说法把"未定"误当成"无知"，对叠加而言，0 和 1 的概率是**真的**，但状态本身不是"某一种等着的确定事实"。

### 1.2 为什么量子比特必须用两个**复数**振幅描述，而不是两个实数概率？

**解答**：因为概率 $|\alpha|^2, |\beta|^2$ 只保留振幅的**大小**，丢掉了**相位**（复数辐角）。而相位是量子干涉的弹药——两个振幅可以因相位差而同相相加（增强）或反相抵消（相消干涉）。若只用概率记账，像 $|+\rangle = \frac{1}{\sqrt2}(|0\rangle+|1\rangle)$ 和 $|-\rangle = \frac{1}{\sqrt2}(|0\rangle-|1\rangle)$ 这样的状态会被错误地当作同一个（概率都是 0.5/0.5），但它们的相位差为 $\pi$，物理行为截然不同。复数振幅是"把大小和方向都留住"的记账方式。

**思路点拨**：代码实验 1 直接验证了这一点——三个状态概率全一样、相位完全不同。这是"墙三"（复数和干涉）的核心。

### 1.3 归一化条件 $|\alpha|^2 + |\beta|^2 = 1$ 的物理意义是什么？如果违反它会怎样？

**解答**：物理意义是"测量总会吐出一个结果"——测到 $|0\rangle$ 或 $|1\rangle$ 的概率之和必须为 1，不可能既不测到 0 也不测到 1。违反归一化的向量不是合法的量子状态（代码实验 2 展示了手动改振幅后概率和变成 1.28 的非法状态）。在代码里，`make_qubit` 通过除以模长强制归一化。

**思路点拨**：归一化是量子状态合法性的唯一法律。任何量子线路、任何算法操作都必须保持它——这让你一眼能识别"这个状态合不合法"。

## 第二组：计算实践

### 2.1 手算：写出 $|+\rangle$ 和 $|-\rangle = \frac{1}{\sqrt2}(|0\rangle - |1\rangle)$ 的概率与 Bloch 球坐标，并验证归一化。

**解答**：$|+\rangle$：$\alpha = \frac{1}{\sqrt2}, \beta = \frac{1}{\sqrt2}$，$P(0)=P(1)=\frac12$，归一化 $\frac12+\frac12=1$；$\theta = 2\arccos\frac{1}{\sqrt2} = \frac{\pi}{2}$，$\phi = 0$（赤道，正 x 方向）。$|-\rangle$：振幅 $[\frac{1}{\sqrt2}, -\frac{1}{\sqrt2}]$，概率同样 $\frac12/\frac12$；$\theta = \frac{\pi}{2}$，$\phi = \pi$（赤道，负 x 方向）。两者在球面上是赤道上相对的两个点。

```python
import numpy as np
for name, beta in [("|+>", 1/np.sqrt(2)), ("|->", -1/np.sqrt(2))]:
    psi = np.array([1/np.sqrt(2)+0j, beta+0j])
    theta = 2*np.arccos(np.abs(psi[0])); phi = np.angle(psi[1]/psi[0])
    print(f"{name} P(0)={np.abs(psi[0])**2:.3f} P(1)={np.abs(psi[1])**2:.3f} θ={theta:.3f} φ={phi:.3f}")
```

输出：

```text
|+> P(0)=0.500 P(1)=0.500 θ=1.571 φ=0.000
|-> P(0)=0.500 P(1)=0.500 θ=1.571 φ=3.142
```

**思路点拨**：这道题证明"概率相同 ≠ 状态相同"。$|+\rangle$ 和 $|-\rangle$ 概率一模一样，但 $\phi$ 相差 $\pi$——它们是两个不同的合法量子比特。经典概率论里它们无法区分，量子力学里它们是硬币旋转方向的两种相反相位。

### 2.2 手算 + 验证：状态 $|\psi\rangle = \sqrt{\frac{2}{3}}|0\rangle + \frac{i}{\sqrt{3}}|1\rangle$ 的测量概率

**解答**：$|\alpha|^2 = \frac{2}{3}$，$|\beta|^2 = \left|\frac{i}{\sqrt3}\right|^2 = \frac13$，和为 1。$P(0) = \frac23 \approx 0.667$，$P(1) = \frac13 \approx 0.333$。Bloch 坐标：$\theta = 2\arccos\sqrt{\frac23} = 2\arccos(0.8165) \approx 1.231$；$\phi = \angle\left(\frac{i/\sqrt3}{\sqrt{2/3}}\right) = \angle(i\cdot\frac{\sqrt3/\sqrt2}{\sqrt3}) = \angle(\frac{i}{\sqrt2}) = \frac{\pi}{2}$。

```python
import numpy as np
psi = np.array([np.sqrt(2/3)+0j, 1j/np.sqrt(3)])
print(f"P(0)={np.abs(psi[0])**2:.3f} P(1)={np.abs(psi[1])**2:.3f}")
theta = 2*np.arccos(np.abs(psi[0])); phi = np.angle(psi[1]/psi[0])
print(f"θ={theta:.3f} φ={phi:.3f}")
```

输出：

```text
P(0)=0.667 P(1)=0.333
θ=1.231 φ=1.571
```

**思路点拨**：这道题练习"模平方"计算与复数相位提取。注意 $|i|^2 = 1$——虚数单位的模是 1，纯虚振幅照样贡献概率。

### 2.3 测量统计验证：对一个 $P(0) = 0.3$ 的状态测量 5000 次，理论命中的 0 的次数是多少？用代码验证频率是否逼近理论值。

**解答**：理论 $P(0) = 0.3$，5000 次期望 $0.3 \times 5000 = 1500$ 次测到 0。代码用 `np.random.choice` 抽样 5000 次，频率应落在 1450–1550 附近。

```python
import numpy as np
np.random.seed(3)
alpha, beta = np.sqrt(0.3), np.sqrt(0.7)     # |α|²=0.3
psi = np.array([alpha+0j, beta+0j])
draws = np.random.choice(2, size=5000, p=[np.abs(alpha)**2, np.abs(beta)**2])
print(f"5000 次中测到 0 的次数 = {draws.sum()} (理论 1500)")
```

输出：

```text
5000 次中测到 0 的次数 = 1509 (理论 1500)
```

**思路点拨**：`np.random.choice(2, p=[0.3, 0.7])` 是批量测量的向量化写法（比循环快）。频率 1509/5000 ≈ 0.3018 逼近 0.3——大数定律又一次兑现。

## 第三组：DL 延伸

### 3.1 经典神经元的激活值是实数 $a \in \mathbb{R}$，量子神经元的单元是量子比特 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$。请说明"单量子神经元信息容量更大"这句话的准确含义与它的限制。

**解答**：准确含义：实数只携带一个自由度（大小）；量子比特携带两个复数（共四个实数自由度），扣除归一化 $|\alpha|^2+|\beta|^2=1$ 和一个全局相位，还剩**两个自由度**——正是 Bloch 球的两个角度 $(\theta, \phi)$。所以单量子比特能表示的"连续状态"比单个实数多（一个球的表面 vs 一条直线）。限制：这些自由度**无法被完整读出**——测量只能吐 $|0\rangle$ 或 $|1\rangle$（一个 bit 的信息），$\phi$ 的相位信息在单次测量中不可见。信息容量是"潜在的"，要借助后续操作（叠加、纠缠）才能转化为计算的收益，而读出仍受 Born 规则约束。

**思路点拨**：别答成"量子神经元能存无限信息"——测量这个唯一出口只给一个比特。容量大在"操作时"，不在"读出时"。

### 3.2 在 §12.4.1 的量子神经网络里，输出是通过"测量"得到的概率。为什么这个输出形式对分类任务反而自然？测量概率与 Softmax 输出的关系是什么？

**解答**：分类任务的经典网络通常以 Softmax 输出概率分布 $[p_1, \ldots, p_c]$。量子测量的输出天然就是概率：测 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ 得到 $P(0) = |\alpha|^2$、$P(1) = |\beta|^2$，且概率和为 1——与 Softmax 的"和为 1 的概率向量"结构一致。区别：Softmax 是确定性映射（同一输入永远给同一概率），量子测量是随机抽样（测 0 或 1 每次都不同，但频率逼近 $|\alpha|^2$）。所以量子网络做分类，要统计多次测量（shots）的频率来估计概率——相当于"用采样估计 Softmax 输出"。这一层的成本是测量次数，收益是量子神经元（§12.4.1）能叠加处理多种输入。

**思路点拨**：要点是"概率形式天然契合分类"与"量子输出是抽样估计而非精确值"这两个互补的面向。训练时损失作用于估计概率，噪声由此进入——这也是 QNN 训练的难点之一。
