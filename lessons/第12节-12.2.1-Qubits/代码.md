# 代码：量子比特——把"旋转的硬币"装进一个长度为 2 的复向量

主线里说：量子比特是 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，$\alpha, \beta$ 是复振幅，$|\alpha|^2$ 是测量得到 0 的概率。这一课不引入任何量子库，只用 NumPy 把量子比特的**状态、概率、Bloch 球坐标、测量**四件事亲手写出来，并用三种典型状态（$|0\rangle$、$|1\rangle$、$|+\rangle$）验证教材图 12.1 里那三条箭头的含义。

---

## 层一：完整脚本

```python
import numpy as np                       # 唯一的工具：复数向量、随机数、三角函数

KET0 = np.array([1+0j, 0+0j])            # 基态 |0⟩ = [1, 0]ᵀ（Bloch 球北极）
KET1 = np.array([0+0j, 1+0j])            # 基态 |1⟩ = [0, 1]ᵀ（Bloch 球南极）

def make_qubit(alpha, beta):             # ① 从两个复振幅构造量子比特
    """把 [alpha, beta] 归一化，保证 |α|²+|β|²=1。"""
    psi = np.array([alpha, beta])
    return psi / np.linalg.norm(psi)     # 除以模长 = 强制归一化

def amplitudes_to_probs(psi):            # ② 振幅 → 概率（Born 规则）
    """逐元素取模平方：|α|² 与 |β|²。"""
    return np.abs(psi) ** 2

def bloch_angles(psi):                   # ③ 振幅 → Bloch 球坐标 (θ, φ)
    """把复振幅翻译成球面坐标：θ=2·arccos|α|，φ=相位差。"""
    theta = 2 * np.arccos(np.clip(np.abs(psi[0]), 0, 1))
    if np.abs(psi[0]) < 1e-12:           # |0⟩ 的振幅为 0 时 φ 无定义，约定为 0
        phi = 0.0
    else:
        phi = np.angle(psi[1] / psi[0])  # β/α 的辐角 = 两个振幅的相位差
    return theta, phi

def measure(psi):                        # ④ 测量：按概率吐出一个 0 或 1
    """P(0)=|α|²，均匀随机数 < P(0) 则测到 0，否则 1。"""
    p0 = np.abs(psi[0]) ** 2
    return 0 if np.random.rand() < p0 else 1

# ---- 三种典型状态 + 一个任意状态 ----
states = {
    "|0>":     make_qubit(1+0j, 0+0j),
    "|1>":     make_qubit(0+0j, 1+0j),
    "|+>":     make_qubit(1/np.sqrt(2), 1/np.sqrt(2)),
    "0.8/0.6": make_qubit(0.8+0j, 0.6+0j),
}
for name, psi in states.items():
    p = amplitudes_to_probs(psi)
    th, ph = bloch_angles(psi)
    print(f"{name:8s} 振幅=({psi[0]:.3f},{psi[1]:.3f})  P(0)={p[0]:.3f}  P(1)={p[1]:.3f}  θ={th:.3f}  φ={ph:.3f}")

# ---- 测量统计：验证 |+⟩ 五五开 ----
np.random.seed(7)
psi = states["|+>"]
counts = [measure(psi) for _ in range(10_000)]
print(f"|+> 测量 10000 次: 0 出现 {counts.count(0)} 次, 1 出现 {counts.count(1)} 次")
```

运行输出（Python 3.11 + NumPy）：

```text
|0>      振幅=(1.000,0.000)  P(0)=1.000  P(1)=0.000  θ=0.000  φ=0.000
|1>      振幅=(0.000,1.000)  P(0)=0.000  P(1)=1.000  θ=3.142  φ=0.000
|+>      振幅=(0.707,0.707)  P(0)=0.500  P(1)=0.500  θ=1.571  φ=0.000
0.8/0.6  振幅=(0.800,0.600)  P(0)=0.640  P(1)=0.360  θ=1.287  φ=0.000
|+> 测量 10000 次: 0 出现 5043 次, 1 出现 4957 次
```

看输出：$|0\rangle$ 是球的北极（$\theta=0$），$|1\rangle$ 是南极（$\theta=\pi \approx 3.142$），$|+\rangle$ 在赤道（$\theta=\pi/2 \approx 1.571$）——教材图 12.1 的三条箭头，被数字逐一兑现。下面把每一步拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义两个基态向量

```python
KET0 = np.array([1+0j, 0+0j])
KET1 = np.array([0+0j, 1+0j])
```

#### `np.array([1+0j, 0+0j])` —— |0⟩ 的向量表示

**做什么**：把数学符号 $|0\rangle = \begin{bmatrix}1\\0\end{bmatrix}$ 写成代码。注意 `+0j`——这是复数，因为振幅必须是复数。
**操作**：`np.array` 构造一维数组；`1+0j` 是实部 1、虚部 0 的复数。
**输入**：两个复数元素。
**输出**：形状 `(2,)` 的 `complex128` 数组。
**可调参数**：`dtype` 可显式指定（如 `dtype=np.complex64` 省内存，代价是精度）。不指定时 NumPy 自动从 `+0j` 推断为复数。
**对应数学**：定义块里的 $|0\rangle = \begin{bmatrix}1\\0\end{bmatrix}$、$|1\rangle = \begin{bmatrix}0\\1\end{bmatrix}$。它们是量子比特向量空间的一组标准基。

---

### 步骤 2：定义 `make_qubit` —— 归一化，量子状态的唯一法律

```python
def make_qubit(alpha, beta):
    psi = np.array([alpha, beta])
    return psi / np.linalg.norm(psi)
```

#### `make_qubit` —— 从两个复振幅构造一个合法量子比特

**做什么**：把 `[alpha, beta]` 组装成向量，然后**归一化**——除以模长，让 $|\alpha|^2 + |\beta|^2 = 1$。
**操作**：`np.linalg.norm(psi)` 算 $\sqrt{|\alpha|^2 + |\beta|^2}$；除法把模长变成 1。这一步是量子力学的硬性法律：任何量子状态必须满足概率总和为 1。
**输入**：`alpha`、`beta`，两个复数（或可转复数的数）。
**输出**：形状 `(2,)` 的归一化复向量。
**可调参数**：
- `alpha`/`beta` 任意给，函数自动归一化。但注意：归一化只保证"概率和为 1"，不保证"这两个振幅物理上可实现"——所有合法量子比特都能被这组参数覆盖，因为球面上每一点都对应某组 $\alpha, \beta$。
- 能不能加参数？可以加第三个参数 `axis` 控制归一化方向——但对单比特（二维向量）没有意义。
**对应数学**：定义块 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$、$\sum|\alpha|^2=1$。归一化正是"旋转的硬币总得倒向某一面"（概率总和恒为 1）的数学。

---

### 步骤 3：定义 `amplitudes_to_probs` —— Born 规则：振幅的平方才是概率

```python
def amplitudes_to_probs(psi):
    return np.abs(psi) ** 2
```

#### `amplitudes_to_probs` —— 复振幅 → 概率

**做什么**：逐元素把复振幅转成概率：$|\alpha|^2$、$|\beta|^2$。
**操作**：`np.abs(psi)` 取模长（$\sqrt{a^2+b^2}$ 对复数 $a+bi$），`** 2` 平方。对归一化向量，输出保证和为 1。
**输入**：`psi`，形状 `(2,)` 的复向量。
**输出**：形状 `(2,)` 的实数组，`[P(0), P(1)]`。
**可调参数**：无——这是量子力学的 Born 规则，没有参数可调。想验证"没归一化时概率和不为 1"，可以传 `[0.5, 0.5]`（未归一化）看看输出 0.5，违反法律。
**对应数学**：主线里"测量得到 $|0\rangle$ 的概率是 $|\alpha|^2$"。`np.abs(...) ** 2` 就是 $\alpha \to |\alpha|^2$ 的代码化身。

---

### 步骤 4：定义 `bloch_angles` —— 从振幅读出球面坐标

```python
def bloch_angles(psi):
    theta = 2 * np.arccos(np.clip(np.abs(psi[0]), 0, 1))
    if np.abs(psi[0]) < 1e-12:
        phi = 0.0
    else:
        phi = np.angle(psi[1] / psi[0])
    return theta, phi
```

#### `bloch_angles` —— 复振幅 → (θ, φ) 球坐标

**做什么**：把量子比特状态翻译成 Bloch 球上的两个角度 $\theta, \phi$——即主线公式 $|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$ 的逆运算。
**操作**：
- `theta = 2 * np.arccos(np.abs(psi[0]))`：因为 $|\alpha| = |\cos\frac{\theta}{2}| = \cos\frac{\theta}{2}$（$\theta \in [0,\pi]$ 时 $\cos \ge 0$），所以 $\theta = 2\arccos|\alpha|$。`np.clip(..., 0, 1)` 防止浮点误差让 $|\alpha|$ 略超 1 导致 `arccos` 出错。
- `phi = np.angle(psi[1] / psi[0])`：两振幅之比 $\beta/\alpha$ 的辐角。因为 $\frac{\beta}{\alpha} = \frac{e^{i\phi}\sin\frac{\theta}{2}}{\cos\frac{\theta}{2}} = e^{i\phi}\tan\frac{\theta}{2}$ 的辐角就是 $\phi$。
**输入**：`psi`，形状 `(2,)` 的复向量。
**输出**：`(theta, phi)`，两个弧度。$\theta$ 决定"离北极多近"（$|0\rangle$ 是 0，$|1\rangle$ 是 $\pi$），$\phi$ 决定"绕 z 轴转了多少"。
**可调参数**：`1e-12` 是判断 $|\alpha|$ 是否为零的阈值——这是数值实现的细节，改小了在极端精度下可能除零，改大了会把接近 $|0\rangle$ 的态误判为 $|0\rangle$。
**对应数学**：主线第二节的 Bloch 球参数化。输出里 $|+\rangle$ 的 $\theta=1.571$（赤道）正是教材图 12.1 那条"位于赤道、与 |0⟩ 和 |1⟩ 等距"的暗蓝箭头。

---

### 步骤 5：定义 `measure` —— 测量：按住硬币的那一下

```python
def measure(psi):
    p0 = np.abs(psi[0]) ** 2
    return 0 if np.random.rand() < p0 else 1
```

#### `measure` —— 按 Born 规则掷一次硬币

**做什么**：模拟一次测量——按 $P(0) = |\alpha|^2$ 的概率吐出一个 0 或 1。
**操作**：`np.random.rand()` 生成 $[0,1)$ 均匀随机数；随机数小于 $P(0)$ 就测到 0，否则测到 1。这精确实现了"测量是概率性的"。
**输入**：`psi`，归一化复向量。
**输出**：整数 0 或 1（坍塌后的基态）。
**可调参数**：
- 测量次数由外层循环控制（本脚本测了 10000 次）。
- 能不能加参数？可以加 `shots` 参数一次测多个——但外层循环更灵活，且能逐个记录，所以保持单次。
**对应数学**：主线第三节 Born 规则 + 坍塌。注意这个函数**不修改 psi**——真实的测量会破坏叠加（psi 变成 |0⟩ 或 |1⟩），这里为了统计方便没有模拟"坍塌后的状态"。想知道坍塌的代码写法，见边界声明第 1 条。

---

### 步骤 6：打印状态表 + 测量统计

```python
for name, psi in states.items():
    p = amplitudes_to_probs(psi)
    th, ph = bloch_angles(psi)
    print(f"{name:8s} 振幅=({psi[0]:.3f},{psi[1]:.3f})  P(0)={p[0]:.3f}  P(1)={p[1]:.3f}  θ={th:.3f}  φ={ph:.3f}")
```

**做什么**：对四个状态逐一打印振幅、概率、球坐标。`{psi[0]:.3f}` 把复数格式化为三位小数。
**操作**：f-string 格式化；`.3f` 控制小数位。
**输入**：`states` 字典（4 个量子比特状态）。
**输出**：4 行表格。
**可调参数**：可以在字典里加任意状态——比如 `make_qubit(1/np.sqrt(2), -1/np.sqrt(2))` 是 $|-\rangle$（赤道另一侧，$\phi=\pi$）。打印输出就是检查"这个状态在球面上哪个点"的最快方式。
**对应数学**：教材图 12.1 的数值版。$|0\rangle(\theta=0)$ 北极、$|1\rangle(\theta=\pi)$ 南极、$|+\rangle(\theta=\pi/2)$ 赤道，一一对应。

## 改个数字试试：把振幅推向极端

### 实验 1：相位改变概率吗？

```python
psi_a = make_qubit(1/np.sqrt(2), 1/np.sqrt(2))      # 相位差 0
psi_b = make_qubit(1/np.sqrt(2), -1/np.sqrt(2))     # 相位差 π（β 取负）
psi_c = make_qubit(1/np.sqrt(2), (0+1j)/np.sqrt(2)) # 相位差 π/2（β 是纯虚数）
for name, psi in [("φ=0", psi_a), ("φ=π", psi_b), ("φ=π/2", psi_c)]:
    p = amplitudes_to_probs(psi)
    th, ph = bloch_angles(psi)
    print(f"{name:5s} P(0)={p[0]:.3f} P(1)={p[1]:.3f}  θ={th:.3f} φ={ph:.3f}")
```

输出：

```text
φ=0    P(0)=0.500 P(1)=0.500  θ=1.571 φ=0.000
φ=π    P(0)=0.500 P(1)=0.500  θ=1.571 φ=3.142
φ=π/2  P(0)=0.500 P(1)=0.500  θ=1.571 φ=1.571
```

**概率完全一样（0.5/0.5），相位完全不同（φ 从 0 到 π 到 π/2）。** 这就是主线"墙二"和"墙三"的代码证明：概率 $|\alpha|^2$ 只看振幅的大小，丢掉相位；而相位是量子干涉的弹药（§12.2.2 的叠加会用到）。如果量子比特只用两个概率描述，这三个截然不同的状态就会被错误地当成同一个——**这正是为什么必须用复数振幅记账。**

### 实验 2：测量频率逼近概率

```python
np.random.seed(0)
for psi_name in ("|+>", "0.8/0.6"):
    psi = states[psi_name]
    for shots in (100, 10_000):
        counts = [measure(psi) for _ in range(shots)]
        print(f"{psi_name:7s} 测 {shots:6d} 次 → P(0)≈{counts.count(0)/shots:.3f} (理论 {np.abs(psi[0])**2:.3f})")
```

输出：

```text
|+>     测    100 次 → P(0)≈0.510 (理论 0.500)
|+>     测  10000 次 → P(0)≈0.507 (理论 0.500)
0.8/0.6 测    100 次 → P(0)≈0.700 (理论 0.640)
0.8/0.6 测  10000 次 → P(0)≈0.644 (理论 0.640)
```

**测量次数越多，频率越逼近理论概率。** 单次测量毫无规律，千次测量开始显形，万次测量基本吻合——这就是量子测量唯一的可预测性：**多次测量的频率，收敛到 $|\alpha|^2$。**

## 边界声明：这套代码能做什么，不能做什么

1. **`measure` 没有模拟"坍塌后的状态"。** 真实测量后，量子比特的状态不再是 $\alpha|0\rangle+\beta|1\rangle$，而是确定地变成 $|0\rangle$ 或 $|1\rangle$。本脚本为了统计方便，只返回测到的结果、不更新 psi。想模拟完整坍塌，写 `psi = KET0 if result == 0 else KET1`——这是真实量子线路模拟器（如 Qiskit）内部做的事。
2. **量子比特状态是连续的，不是离散的。** 主线强调：量子比特是 Bloch 球上的一点（无穷多个合法状态），不是"0/1/第三种状态"三者之一。任何把它当"第三种确定状态"的说法都是错的。叠加是"未确定性本身"，不是"另一个确定值"。
3. **单比特做不了任何有用计算。** 本课演示的是一个量子比特的状态与测量——它本身不产生任何加速。真正的力量要等 §12.2.2（叠加，多个量子比特同时在场）和 §12.2.3（纠缠，量子比特之间的关联）以及后续算法（§12.3）把它们组合起来。单颗珠子只是起点，不是武器。
