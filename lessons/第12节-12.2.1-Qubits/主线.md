# 主线：量子比特——一枚既可以是正面又可以是反面的硬币

## 第一步：Toy Model —— 一枚停在指尖的硬币

把一枚硬币立起来，用指尖让它旋转。

硬币还没有倒下的时候，它是正面还是反面？——都不是，也都可以是。它处于一种"同时既是正面又是反面"的状态。但你一伸手按住它，它就必须二选一：正面，或者反面，绝无第三种可能。而且你**无法预言**它会倒向哪一面——你能说的只是"大约一半概率正面，一半概率反面"。

现在把经典比特和量子比特并排放在一起：

- **经典比特 (bit)**：一枚已经倒在桌上的硬币。它**已经选定**：正面（1）或反面（0），铁板钉钉，翻不出花样。
- **量子比特 (qubit)**：一枚还在指尖旋转的硬币。它**尚未选定**：同时"既是正面又是反面"，直到你测量（按住）它。

教材给量子比特下了一个比喻式的定义："Think of qubits as the quantum version of regular bits." 经典比特只能 0 或 1，量子比特**因为叠加**可以同时是两者。这台机器之所以可能更快，秘密就在"旋转的硬币"里。

但旋转的硬币带来三个必须立刻面对的问题：

1. "既是正面又是反面"到底怎么精确描述？"一半一半"是一个粗糙的说法——能是"七成正面三成反面"吗？能是"正面但带着一点反面的'味道'"吗？
2. 硬币旋转的状态会不会不一样？有的硬币转得快、轴歪一点、像要倒下——这些差异在数学上能被区分吗？
3. 你说"量子计算机可以同时看到很多可能性"——可硬币**最终只能倒向一面**。这个"同时看很多"到底给计算带来了什么？

第一个问题把我们引向精确的数学。旋转的硬币需要一个比"0/1"更丰富的记账方式。

## 第二步：正式数学讲解

### 一、撞墙："半正半反"这个词，太粗糙了

你试着用已有的知识描述旋转的硬币。最自然的是"一半概率正面、一半概率反面"——写成 $50\%$ 和 $50\%$。可你马上撞到三堵墙：

**墙一：概率不是状态。** "50% 正面、50% 反面"描述的是一枚**已经倒下但你没看到**的硬币（你不知道它是正是反，只能押概率）。而旋转的硬币是**真的还没倒下**——它既不正面也不反面，状态本身是第三种东西。概率描述的是"无知"，旋转描述的是"未定"。这两个概念必须分开。

**墙二：只有两个数不够。** 如果你只能写"正面概率、反面概率"两个实数，那旋转的硬币最丰富的可能性（快转、慢转、轴倾斜、相位不同）就被压缩没了。真实量子比特的"旋转状态"远比两个实数丰富——它需要一个能装下"振幅"和"相位"的描述方式。

**墙三：负数、复数和干涉。** 经典概率只能是 $0$ 到 $1$ 之间的实数。可量子世界里，描述硬币的"振幅 (amplitude)"可以是负数、甚至复数。为什么这重要？因为**两个振幅可以互相抵消（干涉，interference）**——就像两列波峰对波谷相遇会互相湮灭。概率世界里没有"负概率"，振幅世界里却有"负振幅"。这一条，是量子计算和经典概率论最深的分界线。

把这三堵墙撞过去，你得到的答案是：量子比特的状态不能用一个"0 或 1"描述，也不能用两个概率描述，而要用**两个复振幅**描述。这就是量子比特的定义：

> **量子比特 (qubit)** $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$
>
> 物理含义：量子比特是量子信息的单位，可同时处于 $|0\rangle$ 和 $|1\rangle$ 两种基本状态的叠加中——就像一枚旋转的硬币同时是正面和反面。
>
> - $|0\rangle = \begin{bmatrix}1\\0\end{bmatrix}$（硬币的反面 / 经典 0）、$|1\rangle = \begin{bmatrix}0\\1\end{bmatrix}$（硬币的正面 / 经典 1）：两个基态（basis states）
> - $\alpha, \beta \in \mathbb{C}$：复振幅。$|\alpha|^2$ 是测量得到 $|0\rangle$ 的概率，$|\beta|^2$ 是测量得到 $|1\rangle$ 的概率
> - 归一化条件：$|\alpha|^2 + |\beta|^2 = 1$——测量总会吐出一个结果，概率总和恒为 1
> - 测量（measurement）：观察量子比特的瞬间，状态**坍塌 (collapse)** 到 $|0\rangle$ 或 $|1\rangle$ 之一，叠加消失

**为什么是两个复数，而不是两个概率？** 因为概率只保留"大小"（$|\alpha|^2$），丢掉了"方向"（$\alpha$ 的相位）。而量子计算的全部威力——干涉、抵消、放大——都藏在相位里。用两个复数，是为了把"大小"和"相位"都留住。

### 二、球的比喻：一个量子比特，是一个球面上的点

三个实数描述一个复数对？其实量子比特的状态空间，直观上是一张**球面**。这个球叫 **Bloch 球 (Bloch sphere)**——教材图 12.1 的主角，§12.3.1 会再见到它。

量子比特 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，加上归一化 $|\alpha|^2 + |\beta|^2 = 1$ 和忽略一个整体相位之后，可以唯一地写成：

$$|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle, \qquad \theta \in [0, \pi],\ \phi \in [0, 2\pi)$$

$\theta$ 和 $\phi$ 正好是两个球坐标——**每个量子比特状态，都对应球面上的一个点**：

- 北极 $(\theta=0)$：$|0\rangle$，纯 0 态（教材图里那条指向正 z 轴的暗红箭头）
- 南极 $(\theta=\pi)$：$|1\rangle$，纯 1 态（教材图里那条指向负 z 轴的暗绿箭头）
- 赤道上 $\phi=0$ 的点：$|+\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$，**均衡叠加**——教材图里那条位于赤道的暗蓝箭头，离 $|0\rangle$ 和 $|1\rangle$ 一样远

你看，教材图 12.1 那三条箭头（北极红、南极绿、赤道蓝）现在有了精确含义：它们就是球面上三个特殊的点。**经典比特只有两个点（南北极），量子比特是整个球面。** 球面是连续的一大片，所以量子比特的状态是连续的无穷多——这正是"比经典比特丰富得多"的几何来源。

### 三、测量：旋转的硬币被按住

说了这么多"状态"，别忘了现实：你迟早要**读**这个量子比特，而读的唯一方式就是测量。测量的法则（Born 规则，Born rule）我们已经见过：

- 测量 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，得到 $|0\rangle$ 的概率是 $|\alpha|^2$，得到 $|1\rangle$ 的概率是 $|\beta|^2$；
- 测量之后，状态**不再是** $\alpha|0\rangle + \beta|1\rangle$，而是**坍塌**为测到的那个基态（$|0\rangle$ 或 $|1\rangle$），叠加被摧毁。

这个"摧毁"是量子计算最痛的一刀，但也是"旋转的硬币"这个比喻最准确的地方：**你按住硬币的那一刻，才决定它是正是反；你测量量子比特的那一刻，才决定它是 0 还是 1。** 在按下去之前，讨论"硬币到底是哪一面"是没有意义的——它真的还没倒下。

边界声明必须在这里下：**"量子比特能同时是 0 和 1"不等于"它既不是 0 也不是 1"**——后一种说法暗示它"等于某个第三种确定状态"，前一种说法才是对的。量子比特不是"第三种确定状态"，而是"未定的、叠加的状态"。这个区分看起来咬文嚼字，但它是整章的地基：**叠加不是某种确定状态，叠加是未确定性本身。** 也因此，测量结果才必然是概率性的——因为叠加态里本来就没有一个"确定答案"等着被读出。

### 四、多个量子比特：从球面到指数空间

单个量子比特是一个球面（连续无穷多个状态）。两个量子比特呢？它们联合的状态空间是 $2^2 = 4$ 维——基态是 $|00\rangle, |01\rangle, |10\rangle, |11\rangle$，状态写作 $|\psi\rangle = \sum_{i=0}^{3}\alpha_i|i\rangle$。$n$ 个量子比特就是 $2^n$ 维，§12.2 那本"指数账本"的细胞，就是单个量子比特这个"球面上的点"。§12.2.2（叠加）将专门讲多个量子比特如何同时存在于这 $2^n$ 个基态上，§12.2.3（纠缠）将讲这些基态之间那种"非经典"的关联。这一节先把单个量子比特这颗最小的珠子看透。

## 第三步：DL 桥接

量子比特是深度学习的"新神经元"。经典神经网络的每个激活值是一个实数 $a \in \mathbb{R}$——它携带"大小"这一个信息。量子神经网络的每个单元是一个量子比特 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$——它携带两个复数，包含"大小"和"相位"。这意味着**单个量子神经元的信息容量，比单个经典神经元更丰富**（§12.4.1 的 QNN 正是建立在这一点上：量子比特 + 量子门 = 神经元）。

具体到公式的桥接：经典神经元 $y = \sigma(Wx + b)$ 里，$x, y$ 是实数，信息沿直线流动；量子神经元里，输入和输出都是量子态 $|\psi\rangle$，信息沿球面上的点流动，层与层之间的"权重"变成了旋转角度 $\theta$（§12.4.1 的 $R_y(\theta)$ 门）。你要把"一个神经元的容量"从"一个实数"升级成"一个球面上的点"——这就是量子比特给深度学习带来的第一次"扩容"。

而硬币那枚"被按住的一刻"——测量——对应到深度学习里就是**读出预测**：量子网络的输出必须测量才能变成经典数字，而测量是概率性的。所以量子神经网络天生的输出形式是概率分布，而不是确定值——这在分类任务里反而是一种自然，因为 Softmax 之后分类器输出的本来就是一个分布。§12.4.1 会看到，如何把"测量概率"当作"类概率"来训练。
