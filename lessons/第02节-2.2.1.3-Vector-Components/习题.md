# 习题：向量的分量

## 第一组：概念检验

**1.1（单选）** 向量 $\vec{A}$ 在 $x$ 轴上的分量 $A_x$ 等于：
- A. $\vec{A}$ 的模长
- B. $\vec{A}$ 与 $x$ 轴单位向量的点积 $\vec{A}\cdot\hat{\imath}$
- C. $\vec{A}$ 与 $y$ 轴单位向量的点积 $\vec{A}\cdot\hat{\jmath}$
- D. $\|\vec{A}\|\sin\theta$（$\theta$ 为 $\vec{A}$ 与 $x$ 轴夹角）

**1.2（判断并说明）** "一个向量的分量是它固有的属性，换任何坐标系分量都不变。" 这句话对吗？

**1.3（填空）** 标准基向量 $\mathbf{e}_2$（5 维空间）是 ____。向量 $\mathbf{x} = [0, 2, 0, 0, 0]$ 可以写成 ____ × $\mathbf{e}_2$。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 已知 $\vec{A} = [5, 12]$。写出它的两个分量 $A_x$、$A_y$，并验证 $A_x\hat{\imath} + A_y\hat{\jmath} = \vec{A}$。用 `np.dot` 和重建代码验证。

**2.2（代码验证）** 把向量 $\mathbf{v} = [2, -1, 4]$ 分解到 3 维标准基上，用分量重建并确认无损。

**2.3（动手理解）** 构造一个非标准基：$\mathbf{b}_1 = [1, 1]$，$\mathbf{b}_2 = [1, -1]$。对 $\vec{A} = [3, 1]$，求出它在 $\mathbf{b}_1$、$\mathbf{b}_2$ 方向上的"分量" $c_1 = \vec{A}\cdot\mathbf{b}_1/\|\mathbf{b}_1\|$、$c_2 = \vec{A}\cdot\mathbf{b}_2/\|\mathbf{b}_2\|$，然后验证 $c_1\frac{\mathbf{b}_1}{\|\mathbf{b}_1\|} + c_2\frac{\mathbf{b}_2}{\|\mathbf{b}_2\|} = \vec{A}$。**思考**：这说明了"分量"依赖坐标系。

## 第三组：DL 延伸

**3.1（场景判断）** one-hot 编码中，词汇表第 5 个单词对应的向量是什么？它属于哪一组特殊向量？在代码里，用哪个 NumPy 函数可以生成这组向量的"全家福"？

**3.2（场景分析）** 词嵌入 (word embedding) 把 one-hot 向量 $\mathbf{e}_i$ 通过矩阵 $E$ 变成新向量 $\mathbf{e}_i E$。有人说"这是把词从标准基换到一组新基"。请解释：为什么"换基"的直觉在这里成立？

---

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：分量定义 $A_x = \vec{A}\cdot\hat{\imath} = \|\vec{A}\|\cos\theta$。C 给的是 $A_y$，D 的 $\sin\theta$ 对应的是 $y$ 分量（$A_y=\|\vec{A}\|\sin\theta$），A 混淆了模长与分量。
- **点拨**：记住口诀"**分量 = 向量与对应轴单位向量的点积 = 该方向的投影**"。$\cos$ 管 $x$、$\sin$ 管 $y$，别记反。

**1.2 不对。**
- **思路**：分量是"向量在特定坐标系下的投影"，换坐标系（换基）分量就变。同一个向量在标准基下是 $[3,4]$，在旋转 45° 的坐标系下会变成另一组数。**不变的是向量本身和它的模长，变的是坐标。**
- **点拨**：这是"对象 vs 表示"的第三节课——前两次在 2.2.1.1（模长不变）和 2.2.1.2（点积投影），这次落在"分量"上。

**1.3 答案：$\mathbf{e}_2 = [0, 1, 0, 0, 0]$；$[0,2,0,0,0] = 2 \times \mathbf{e}_2$。**
- **思路**：标准基向量 $\mathbf{e}_i$ 是"第 $i$ 个分量为 1、其余全 0"。$\mathbf{x}$ 只有一个非零分量 2，所以它是 $2$ 个 $\mathbf{e}_2$。
- **点拨**：one-hot 向量与标准基向量是同一个东西——这打通了"数学里的基"与"深度学习里的编码"。

### 第二组

**2.1**
$A_x = [5,12]\cdot[1,0] = 5$，$A_y = [5,12]\cdot[0,1] = 12$。重建：$5[1,0]+12[0,1] = [5,12] = \vec{A}$。

```python
import numpy as np
A = np.array([5.0, 12.0])
e_x, e_y = np.array([1.0, 0.0]), np.array([0.0, 1.0])
Ax, Ay = np.dot(A, e_x), np.dot(A, e_y)
print(Ax, Ay)                       # 5.0 12.0
print(np.allclose(Ax*e_x + Ay*e_y, A))   # True
```
- **思路**：分量即投影；重建即"分量×基向量求和"。
- **点拨**：模长 $\|\vec{A}\| = \sqrt{25+144} = 13$，而分量 5 和 12 恰好构成勾股数——分量就是"把向量沿两轴拆成的直角边"。

**2.2**
```python
import numpy as np
v = np.array([2.0, -1.0, 4.0])
n = 3
basis = np.eye(n)
comps = [np.dot(v, basis[i]) for i in range(n)]
rebuilt = sum(comps[i]*basis[i] for i in range(n))
print(comps)                       # [2.0, -1.0, 4.0]
print(np.allclose(rebuilt, v))     # True
```
- **思路**：三维与二维同构，每个分量 $v_i = \mathbf{v}\cdot\mathbf{e}_i$ 就是 $\mathbf{v}$ 的第 $i$ 个坐标。
- **点拨**：维数只是分量的个数。从 2 维到 $n$ 维，公式不变——这正是线性代数"以少驭多"的力量。

**2.3**
$\mathbf{b}_1$ 模长 $\sqrt{2}$，$c_1 = [3,1]\cdot[1,1]/\sqrt{2} = 4/\sqrt{2} = 2\sqrt{2}$；$\mathbf{b}_2$ 模长 $\sqrt{2}$，$c_2 = [3,1]\cdot[1,-1]/\sqrt{2} = 2/\sqrt{2} = \sqrt{2}$。
重建：$2\sqrt{2}\cdot\frac{[1,1]}{\sqrt{2}} + \sqrt{2}\cdot\frac{[1,-1]}{\sqrt{2}} = [2,2] + [1,-1] = [3,1] = \vec{A}$。成立。

```python
import numpy as np
A = np.array([3.0, 1.0])
b1 = np.array([1.0, 1.0]); b2 = np.array([1.0, -1.0])
c1 = np.dot(A, b1)/np.linalg.norm(b1)
c2 = np.dot(A, b2)/np.linalg.norm(b2)
rebuilt = c1*b1/np.linalg.norm(b1) + c2*b2/np.linalg.norm(b2)
print(np.allclose(rebuilt, A))      # True
```
- **思路**：即使基向量不是标准基（但要求"垂直+单位"），分解与重建依然成立——只要基是**正交归一的**。
- **点拨**：$\mathbf{b}_1 = [1,1]$、$\mathbf{b}_2 = [1,-1]$ 恰是一组正交基（点积为 0）。换基后，同一个 $[3,1]$ 的分量从 $(3,1)$ 变成了 $(2\sqrt2, \sqrt2)$——**分量确实变了，向量没变**。这就是 1.2 的直观证据。

### 第三组

**3.1 答案：$\mathbf{e}_5 = [0,0,0,0,1,0,\dots,0]$（第 5 位为 1，其余全 0）；它属于标准基向量；生成全家福用 `np.eye(vocab_size)`。**
- **思路**：one-hot 编码把"第 $i$ 个词"映射成"第 $i$ 位为 1 的标准基向量"。`np.eye(V)` 生成 $V\times V$ 单位矩阵，其第 $i$ 行就是第 $i$ 个词的 one-hot 向量。
- **点拨**：这里"词汇表大小 = 维度数"。词嵌入的学习，本质上是学一个映射，把 one-hot 向量搬到新空间——见 3.2。

**3.2 思路**
- one-hot 向量 $\mathbf{e}_i$ 是标准基——它"独热"地指向第 $i$ 个维度，与其它词正交（点积 0）。
- 词嵌入矩阵 $E$（形状 `(vocab, d)`）把 $\mathbf{e}_i$ 映射到 $E$ 的**第 $i$ 行**：$\mathbf{e}_i E = E[i,:]$。这一行是一个 $d$ 维向量——它不再是"只亮一位"的标准基，而是把词放在了一个**低维连续空间**里。
- "换基"的直觉成立，因为：one-hot 用的是"词汇维度"的稀疏标准基；嵌入把它换到"语义维度"的稠密基。换基之后，语义相近的词在新基下**彼此靠近**（夹角小）——这正是 one-hot 做不到的（所有词都互相正交）。
- **点拨**：所以词嵌入 = 一次"换基 + 让语义对齐"。§2.5.3.3 会专门讲嵌入，这里先把"换基"这个数学内核记住。

## 一个"为什么有人会答错"的提醒

1.1 的 D 是高频错项：有人把"$\sin$ 与 $x$ 轴分量"记反。**$\cos\theta$（邻边/斜边）对应 $x$ 分量，$\sin\theta$（对边）对应 $y$ 分量**。2.3 的难点在于记得"非标准基要除以模长"——直接用 $\vec{A}\cdot\mathbf{b}_1$ 不除以 $\|\mathbf{b}_1\|$ 会得到投影×基长，重建就会失败。这正是"单位基"重要性的实战演示。
