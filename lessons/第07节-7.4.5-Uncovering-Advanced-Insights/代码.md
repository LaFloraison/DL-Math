## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 两社区 + 一桥的图：左团 {L1,L2,L3}、右团 {R1,R2,R3}、桥 B 连接两团
names = ["L1", "L2", "L3", "B", "R1", "R2", "R3"]
edges = [("L1","L2"), ("L1","L3"), ("L2","L3"),
         ("R1","R2"), ("R1","R3"), ("R2","R3"),
         ("B","L1"), ("B","R1")]

def adjacency(names, edges):                           # ③ 邻接矩阵
    idx = {n: i for i, n in enumerate(names)}
    A = np.zeros((len(names), len(names)), dtype=float)
    for u, v in edges:
        i, j = idx[u], idx[v]
        A[i, j] = A[j, i] = 1.0
    return A

def degree_centrality(A):                              # ④ 度中心性：连接数
    return A.sum(axis=1)

def betweenness(A):                                    # ⑤ 中介中心性：多少对最短路径经过 v
    n = A.shape[0]
    bc = np.zeros(n)
    for s in range(n):
        for t in range(s + 1, n):
            path = shortest_path(A, s, t)              # 找一条最短路径（BFS 前驱回溯）
            if path is None: continue
            for v in path[1:-1]:                       # 中间节点（不含端点）
                bc[v] += 1.0
    return bc

def shortest_path(A, s, t):                            # ⑥ BFS 找最短路径
    n = A.shape[0]
    prev = {s: None}; queue = [s]; head = 0
    while head < len(queue):
        v = queue[head]; head += 1
        if v == t: break
        for u in range(n):
            if A[v, u] and u not in prev:
                prev[u] = v; queue.append(u)
    if t not in prev: return None
    path = [t]
    while path[-1] != s: path.append(prev[path[-1]])
    return path[::-1]

def pagerank(A, d=0.85, iters=100):                    # ⑦ 手写 PageRank
    n = A.shape[0]
    outdeg = A.sum(axis=1, keepdims=True)
    P = np.ones((n, 1)) / n
    for _ in range(iters):
        teleport = (1 - d) / n
        spread = np.zeros((n, 1))
        for v in range(n):
            if outdeg[v] > 0:
                spread += (A[:, [v]] / outdeg[v]) * P[v]
        P = d * spread + teleport
    return P.ravel()

A = adjacency(names, edges)
print("度中心性：", dict(zip(names, degree_centrality(A))))
print("中介中心性：", dict(zip(names, betweenness(A))))
print("PageRank（×1000 便于比较）：", {n: round(p*1000, 1) for n, p in zip(names, pagerank(A))})
```

输出：

```
度中心性： {'L1': 3.0, 'L2': 2.0, 'L3': 2.0, 'B': 2.0, 'R1': 3.0, 'R2': 2.0, 'R3': 2.0}
中介中心性： {'L1': 6.0, 'L2': 0.0, 'L3': 0.0, 'B': 9.0, 'R1': 6.0, 'R2': 0.0, 'R3': 0.0}
PageRank（×1000 便于比较）： {'L1': 154.0, 'L2': 138.0, 'L3': 138.0, 'B': 199.0, 'R1': 154.0, 'R2': 138.0, 'R3': 138.0}
```

三种度量给出了**三种排序**——这正是本节的核心教训。**度中心性**说 L1 和 R1 最重要（度 3），B 只是普通一员（度 2）；**中介中心性**说 B 才是咽喉——9 对跨社区的节点对（左团 3 个 × 右团 3 个）的最短路径**全部经过 B**，而 L1、R1 各占 6 条（它们各自在跨社区路径的一端附近）。B 度不是最高，却是"必经之路"；**PageRank** 同样把 B 排第一（0.199），因为随机冲浪者从 B 出发能进入两个世界、又从两个世界返回它。**"认识的人多"（度）与"信息的必经之路"（中介/PageRank）是两个不同的"重要"。** 要决定"信发给谁"，中介中心性和 PageRank 都比度更接近真相。

## 层二：分步逐函数拆解

### 步骤 1：定义两个中心性

```python
def degree_centrality(A):
    return A.sum(axis=1)

def betweenness(A):
    n = A.shape[0]
    bc = np.zeros(n)
    for s in range(n):
        for t in range(s + 1, n):
            path = shortest_path(A, s, t)
            if path is None: continue
            for v in path[1:-1]:
                bc[v] += 1.0
    return bc
```

#### degree_centrality / betweenness —— "连接多" vs "必经之路"

**操作**：度中心性 = 每行求和（邻居数）。中介中心性 = 对每对节点 (s, t)，找一条最短路径，把路径上**中间节点**的中介值各 +1——"有多少对节点的最短路径经过 v"。

**输入**：`A`。

**输出**：两个数组。度：L1/R1=3、B=2；中介：B=9、L1/R1=6、其余 0。

**可调参数**：
- 严格的中介中心性应统计**所有**最短路径（若 s–t 有多条，v 落在其中 $\sigma_{st}(v)/\sigma_{st}$ 条上）——这里每对只找一条最短路径，是简化版（对"谁是咽喉"的定性判断足够）。
- 中介中心性也可以归一化（除以 $\binom{n}{2}$），便于跨图比较。

**对应数学**：主线第二节的中介中心性 $b(v) = \sum_{s\neq t} \sigma_{st}(v)/\sigma_{st}$。数一数：左团 3 点 × 右团 3 点 = 9 对跨社区节点对，它们的最短路径**全部**经过 B（必经 B 才能跨团），所以 $b(B)=9$；L1、R1 各被 6 条路径作为中间节点命中（如 L2→R1 的最短路 L2–L1–B–R1 含 L1）；同团内的 6 对路径不经过 B。于是"咽喉" B 的中介中心性一骑绝尘。

### 步骤 2：定义 PageRank

```python
def pagerank(A, d=0.85, iters=100):
    n = A.shape[0]
    outdeg = A.sum(axis=1, keepdims=True)
    P = np.ones((n, 1)) / n
    for _ in range(iters):
        teleport = (1 - d) / n
        spread = np.zeros((n, 1))
        for v in range(n):
            if outdeg[v] > 0:
                spread += (A[:, [v]] / outdeg[v]) * P[v]
        P = d * spread + teleport
    return P.ravel()
```

#### pagerank —— 随机冲浪者的稳态分布

`P = d * spread + teleport`

**操作**：从均匀分布起步，迭代：每个节点 v 把它的 PageRank $P[v]$ 均分给它的邻居（`A[:, [v]] / outdeg[v]`），再按阻尼因子 $d=0.85$ 加权，加上 $1-d$ 的"随机跳转"（teleport）。反复迭代直到收敛——$P[v]$ 就是"随机冲浪者长期落在 v 上的概率"。

**输入**：`A`、`d`（阻尼因子，0.85 是经典值）、`iters`。

**输出**：归一化的概率向量。

**可调参数**：
- `d`：越小越偏向随机跳转（均匀），越大越尊重"沿边传播"。`d=1` 时无随机跳转，孤立节点概率归零（会出问题）——所以必须有 `1-d` 的 teleport 保证收敛。
- `iters`：迭代次数；图越大、谱半径越接近 1 越需要多轮。

**对应数学**：主线的"影响力=被重要者指向"。PageRank 是**特征向量中心性**的随机游走版：$P = d A^T D^{-1} P + (1-d)/n$——"重要"在迭代中互相成就，B 因连接两个团而最高。

```python

print("PageRank：", ...)
```

#### 主流程 —— 三种度量，三种答案

**操作**：并排打印三种度量。

**输入**：图。

**输出**：三个字典。

**可调参数**：把桥 B 再加一条边到右团（连 R2），B 的中介会**下降**（多了冗余路径，B 不再是唯一必经路）——"重要性"随结构改变，是本节洞察的动态性体现。

**对应数学**：主线的"度高 ≠ 有影响力"。三种度量分别回答"连接多"、"必经之路"、"被重要者指向"——同一个 B，三种角色的判定不同。

## 改个数字试试

### 实验 A：给桥加冗余，重要性骤降

把 `("B","R1")` 换成两条 `("B","R1")` 与 `("B","R2")`。重跑看：B 的中介中心性下降（跨社区不再只靠 B 一条路），PageRank 也可能被稀释。**这演示了"影响力是可变的"——结构的微小改变就改写咽喉的位置**，这正是动态演化（§7.6.2）的微观原理。

### 实验 B：换一个"全连接小圈"——没有桥，谁也当不了咽喉

把图改成两个完全孤立的三角形（删掉 B 及它的两条边）。重跑：中介中心性全 0（没有跨社区路径，就没有必经之路）。**没有桥的图，没有"咽喉节点"**——影响力节点是"结构造出来的位置"，不是节点的固有属性。

**呼应主线**：本节用三种度量证明：图能挖出的"谁重要"，比"认识人多"深刻得多——必经之路（中介）、被重要者指向（PageRank）、抱团（社区）才是深层洞察。而这些手工度量，正是 GNN 表示要学的东西的"显式答案"。
