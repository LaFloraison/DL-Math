# §11.2.2.2 偏微分方程 —— 习题

主线把 PDE 讲成"状态是一条线的系统"，用热方程 $\frac{\partial u}{\partial t} = \alpha\frac{\partial^2u}{\partial x^2}$ 讲了金属棒例子的演化，并给出现式有限差分与 CFL 稳定性红线。习题分三组：**概念检验** 验证 PDE/ODE 分界与热方程结构，**计算实践** 手推差分并做代码对照，**DL 延伸** 把热方程放回扩散模型、图像模糊与 PINNs。

---

## 一、概念检验

### 题 1（选择）：为什么热方程是 PDE 而非 ODE？

$\frac{\partial u}{\partial t} = \alpha\frac{\partial^2u}{\partial x^2}$ 被归类为偏微分方程，最根本的理由是：

- A. 它含有二阶导数
- B. 它的未知函数 $u(t,x)$ 同时依赖时间和空间两个自变量，方程里出现偏导数
- C. 它描述的是"热"，而热是复杂的
- D. 它没有闭式解

**解答**：B。

PDE 与 ODE 的分水岭是**自变量个数**：$u(t,x)$ 有两个自变量，所以对 $t$ 求导时要把 $x$ 当常数（偏导数 $\partial$），对 $x$ 求导时把 $t$ 当常数。A 错——二阶 ODE（如摆锤）也有二阶导数但只有一个自变量；C 是错觉；D 与分类无关（很多 ODE 也没有闭式解）。

**思路点拨**：永远数自变量。$u(t)$ 一个 → ODE；$u(t,x)$ 两个 → PDE。这是 §11.2.2 分界口诀的进阶应用。

### 题 2（判断 + 简答）：为什么"中间热、两端凉"会让中间降温？

用热方程的结构解释：金属棒中间 100°C、两端 0°C，为什么中间那格会降温？"曲率"在这里扮演什么角色？

**解答**：因为中间的温度曲线是一个**凸峰（$\cap$ 形）**，其二阶偏导数 $\frac{\partial^2u}{\partial x^2} < 0$（曲率为负）。热方程说 $\frac{\partial u}{\partial t} = \alpha\frac{\partial^2u}{\partial x^2}$——曲率为负，所以 $\frac{\partial u}{\partial t} < 0$，中间温度**下降**。反之，峰两侧的凹区曲率为正，温度上升。**"曲率"就是邻居关系的数学化身：中间格没有自己"做"任何事，它只是被"邻居比它凉"这个事实拖着降温。**

**思路点拨**：把 $\frac{\partial^2u}{\partial x^2}$ 读作"这一格 vs 邻居的温差再差一阶"。尖峰曲率极大 → 变化快（教材 t=0→1 中心 100→60）；峰被抹平后曲率变小 → 变化变慢。这就是"扩散先快后慢"的直觉来源。

### 题 3（简答）：为什么 PDE 需要"两组"条件？

ODE 只要初始条件；热方程却同时要初始条件和边界条件。请解释"边界条件"管什么、缺了它会怎样。

**解答**：PDE 的状态是一条**函数曲线**，不是几个数。**初始条件**决定曲线从什么形状开始（管"过去"）；**边界条件**决定曲线边缘如何与世界互动（管"边界"）。棒两端恒温 0°C（热量可逃出）与两端绝热（热量出不去）是两套完全不同的演化——缺边界条件，演化不唯一：你无法回答"边缘的温度该取什么"。

**思路点拨**：对照 §11.2.1"状态必须充分"——PDE 的"状态"是整条曲线，必须由"初值（曲线起点）+ 边值（曲线端点）"一起钉死才充分。这是 PDE 比 ODE 多一层约束的根源。

## 二、计算实践

### 题 1（手算：一个 5 格微型棒的显式迭代）

设 $M=5$ 格、$dx=0.25$、$\alpha=0.1$、$dt=0.05$（$ratio=0.08$），初始温度分布 $u = [0, 0, 100, 0, 0]$（边界已含两端）。

(a) 写出显式差分更新式。
(b) 手算一步后的中间格温度 $u_2^{\text{new}}$。
(c) 用代码验证。

**解答**：

(a) $u_i^{\text{new}} = u_i + 0.08\,(u_{i+1} - 2u_i + u_{i-1})$。

(b) 中间格 $i=2$：$u_2 = 100$，$u_1 = 0$，$u_3 = 0$，曲率 $= 0 - 2\times100 + 0 = -200$。所以 $u_2^{\text{new}} = 100 + 0.08 \times (-200) = 100 - 16 = 84$。邻居 $u_1^{\text{new}} = 0 + 0.08\times(100 - 0 + 0) = 8$，$u_3^{\text{new}} = 8$。

(c) 代码：
```python
import numpy as np
u = np.array([0.0, 0.0, 100.0, 0.0, 0.0])
un = u.copy(); un[1:-1] = u[1:-1] + 0.08*(u[2:] - 2*u[1:-1] + u[:-2])
print(np.round(un, 2))
```
```
[ 0.    8.   84.    8.    0. ]
```

**思路点拨**：这是"曲率驱动更新"的一次手算。中间格被两个 0 邻居"夹击"，曲率 $-200$，一步掉 16 度；邻居们各涨 8 度——**热量从中间流向两边**。手算一遍，你才真正"看见" $\frac{\partial^2u}{\partial x^2}$ 不是抽象符号。

### 题 2（手算 + 代码：CFL 红线）

显式格式的稳定性条件是 $\alpha\frac{\Delta t}{(\Delta x)^2} \le \frac{1}{2}$。$\alpha=0.1$、$dx=0.25$。

(a) 允许的最大 $dt$ 是多少？
(b) 网格加密到 $dx=0.05$，最大 $dt$ 变成多少？这说明"网格加密"的真实代价是什么？
(c) 用代码演示 $dt$ 取到 $1.0$（ratio=1.6）时的爆炸。

**解答**：

(a) $dt \le \frac{0.5 \times (0.25)^2}{0.1} = 0.3125$ 秒。

(b) $dt \le \frac{0.5 \times (0.05)^2}{0.1} = 0.0125$ 秒——**网格加密 5 倍，时间步要缩 25 倍**（$dt \propto (\Delta x)^2$）。这是显式格式最贵的账：空间分辨率每提升一点，时间上就要多算很多步。

(c) 代码：
```python
import numpy as np
M, alpha, dx = 41, 0.1, 10.0/40
u = np.zeros(M); c = int(M/2); u[c-1:c+2] = 100.0; u[0]=u[-1]=0.0
ratio = alpha*1.0/dx**2                       # dt=1.0 → ratio=1.6
for _ in range(40):
    un = u.copy(); un[1:-1] = u[1:-1] + ratio*(u[2:]-2*u[1:-1]+u[:-2]); un[0]=un[-1]=0.0
    u = un
print("ratio =", round(ratio,2), " 40步后中间温度 =", f"{u[c]:.3e}")
```
```
ratio = 1.6  40步后中间温度 = 1.65e+41
```

**思路点拨**：(b) 是这道题的分量所在——$(\Delta x)^2$ 在分母上，意味着显式方法的网格加密是"平方级"的昂贵。(c) 的 `1.65e+41` 就是教科书那句"数值解会爆炸"的实锤。理解这条线，你就明白为什么工程上会转向无条件稳定的隐式格式。

### 题 3（手算：从具体到字母，PDE 的通用形态）

热方程 $\frac{\partial u}{\partial t} = \alpha\frac{\partial^2u}{\partial x^2}$ 是 PDE 一般形式 $\frac{\partial u}{\partial t} = F(t, x, u, \frac{\partial u}{\partial x}, \frac{\partial^2u}{\partial x^2})$ 的特例。

(a) 对热方程，$F$ 具体长什么样？它显式依赖 $t, x, u$ 吗？
(b) 波动方程 $\frac{\partial^2 u}{\partial t^2} = c^2\frac{\partial^2 u}{\partial x^2}$ 与热方程在"时间导数阶数"上有什么区别？这暗示什么？

**解答**：

(a) $F = \alpha\frac{\partial^2u}{\partial x^2}$——只依赖二阶空间偏导数，**不显式依赖 $t, x, u$**。它是"自治 + 线性 + 常系数"的最简 PDE。

(b) 热方程对时间是一阶（$\partial u/\partial t$），波动方程对时间是二阶（$\partial^2u/\partial t^2$）。**一阶时间 → 系统耗散、向均匀走、不可逆**（热）；**二阶时间 → 系统可振荡、可逆、能量守恒**（波）。阶数决定了"时间之箭"的方向：热方程把信息抹平，波动方程把信息传播。

**思路点拨**：(b) 是"阶数 = 动力学性格"的又一例证（对比 §11.2.2.1 摆锤的二阶 → 振荡）。一阶时间 = 有摩擦/耗散，二阶时间 = 无摩擦/可逆——这个直觉在理解扩散模型（一阶、不可逆加噪）时极有用。

## 三、DL 延伸

### 题 1（扩散模型：生成 = 学会反转热方程）

扩散模型 (DDPM) 的加噪过程把图像 $x$ 逐步变成噪声，写出来是随机 PDE，确定性部分与热方程同族。

(a) 用"扩散 = 信息被抹平"的语言，解释为什么加噪**不可逆**、生成必须靠"学会反转"。
(b) 主线说"CNN 的卷积与热方程是同一个数学骨架"——请说出卷积里的"邻居加权平均"对应热方程里的哪个项。

**解答**：

(a) 热方程的方向只有一个：把尖锐抹平。从清晰图像到纯噪声，是"信息被扩散稀释"的不可逆过程——你不能从噪声里"反解"出原图（信息已经不可逆地丢失，正如你不能从 $t=5$ 的温度反推 $t=0$ 的尖峰）。所以生成不是"解逆方程"，而是**训练一个网络去学这个不可逆过程的逆映射**——每一步预测"上一时刻长什么样"。

(b) 卷积核里的**中心权重减邻居**结构（如 $[-1, 2, -1]$ 或高斯核 $[1, 2, 1]$）对应热方程的差分 $u_{i+1} - 2u_i + u_{i-1}$——都是"自己 vs 邻居"的加权。高斯模糊就是把热方程推一小步；CNN 的卷积层可视为某种扩散型方程的离散化。

**思路点拨**：把主线的三句话（曲率驱动、抹平、不可逆）翻译成扩散模型的三件事（加噪由局部邻居决定、分布趋向纯噪声、生成要学逆映射）。这是 PDE 在现代深度学习里最直接的落点。

### 题 2（PINNs：让神经网络学习 PDE 的解）

PINN (Physics-Informed Neural Network) 的做法是：让网络 $u_\theta(t,x)$ 去近似热方程的解，损失函数包含**方程残差** $\mathcal{L}_{PDE} = \big\|\frac{\partial u_\theta}{\partial t} - \alpha\frac{\partial^2 u_\theta}{\partial x^2}\big\|^2$。

(a) 这个残差项在"惩罚"网络的什么行为？
(b) 与数值差分相比，PINN 的优势和代价各是什么？

**解答**：

(a) 它在惩罚"网络输出不满足热方程"的程度。如果 $u_\theta$ 真是解，残差处处为 0；残差越大，$u_\theta$ 越偏离"变化率约定"。训练就是让 $u_\theta$ 在**连续的意义**上满足方程——不需要网格，只在一个个采样点上要求方程成立。

(b) 优势：无需显式网格（尤其适合高维 PDE，网格会指数爆炸）；给出的是**光滑的解析式近似** $u_\theta(t,x)$，可在任意点求值。代价：训练本身是优化，可能不收敛、精度受网络容量限制；而数值差分有成熟的理论保证（稳定、收敛阶已知）。**PINN 是"让变化语言与学习机器联姻"，但不是银弹。**

**思路点拨**：把"方程残差作为损失"理解成"用梯度下降去满足微分方程"。这题帮你把本章的 PDE 与优化（§5 章）、神经网络（§2 章）三线交汇。PINN 的"残差 = 0"与你之前学的"解 = 满足方程的函数"是同一个判据，只是求解工具从差分换成了网络。
