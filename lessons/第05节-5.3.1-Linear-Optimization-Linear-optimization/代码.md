# 代码：顶点枚举——把"最优在角上"变成一行行可验证的代码

**目标**：主线证明了"线性规划的最优解必在可行域顶点上"。这里把这个定理**直接用代码实现**：枚举出二维可行域的所有候选顶点（任意两条边界线的交点），逐一检验可行性，再比较目标函数值，找出最优解。你会亲眼看到 (4,3)、P=24 是如何被"有限个顶点"锁定的——不靠优化库，全部是裸 NumPy。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 问题定义 ----
# Max P = 3A + 4B
# s.t. A + 2B <= 10 (原材料), 3A + B <= 15 (人工), A >= 0, B >= 0
constraints = [(np.array([1.0, 2.0]), 10.0),   # (系数向量, 上限)
               (np.array([3.0, 1.0]), 15.0)]

def feasible(x):
    for coef, b in constraints:                 # 逐条检查不等式
        if coef @ x > b + 1e-9:                 # 越界即不可行
            return False
    if x[0] < -1e-9 or x[1] < -1e-9:            # 非负约束
        return False
    return True

def objective(x):
    return 3.0 * x[0] + 4.0 * x[1]              # P = 3A + 4B

# ---- 2. 收集所有边界线: (a1, a2, b) 表示 a1*A + a2*B = b ----
lines = [(coef[0], coef[1], b) for coef, b in constraints]
lines.append((1.0, 0.0, 0.0))                   # A = 0  (B 轴)
lines.append((0.0, 1.0, 0.0))                   # B = 0  (A 轴)

# ---- 3. 枚举所有线对交点, 检验可行性, 追踪最优 ----
best_x = None
best_val = -np.inf
for i in range(len(lines)):
    for j in range(i + 1, len(lines)):
        M = np.array([[lines[i][0], lines[i][1]],
                      [lines[j][0], lines[j][1]]])   # 2x2 系数矩阵
        b = np.array([lines[i][2], lines[j][2]])     # 右端向量
        if abs(np.linalg.det(M)) < 1e-12:            # 平行线 -> 无交点
            continue
        x = np.linalg.solve(M, b)                    # 解交点
        if feasible(x) and objective(x) > best_val:  # 可行且更优?
            best_x, best_val = x, objective(x)

print(f"最优解: A = {best_x[0]:.4f}, B = {best_x[1]:.4f}")
print(f"最优利润 P = {best_val:.4f}")
print(f"约束校验: A+2B = {best_x[0]+2*best_x[1]:.4f} (<=10), "
      f"3A+B = {3*best_x[0]+best_x[1]:.4f} (<=15)")
```

输出：

```
最优解: A = 4.0000, B = 3.0000
最优利润 P = 24.0000
约束校验: A+2B = 10.0000 (<=10), 3A+B = 15.0000 (<=15)
```

脚本精确命中主线的手算结果：$(4,3)$，利润 24。注意两条约束在最优解处都取等号——它们同时**绑定**（§5.2 的词），这也是顶点之所以是顶点的原因：**两条线交于一点，才构成角。**

## 层二：分步逐函数拆解

### 步骤 1：问题定义——把 LP 翻译成数据结构

```python
constraints = [(np.array([1.0, 2.0]), 10.0),
               (np.array([3.0, 1.0]), 15.0)]
```

**操作**：把每条不等式约束 $a_1 A + a_2 B \le b$ 存成元组 `(系数向量, 上限)`。第一条对应原材料 $A + 2B \le 10$，第二条对应人工 $3A + B \le 15$。
**输入**：无（硬编码）。**输出**：一个 list，每项是 `(np.ndarray 形状 (2,), float)`。
**可调参数**：
- 增删一个元组就是增删一条约束——比如加一条 `(np.array([1.0, 0.0]), 4.0)` 即 $A \le 4$，可行域被削去一块，最优解会移到 (4,3) 左侧的某个顶点。
- 改上限 `10.0` 为 `20.0`，可行域扩大，最优解可能换成别的顶点。
- 这个结构对应主线定义块里的 $Ax \le b$：`constraints` 就是 $A$ 的行堆叠，上限们就是 $b$。

---

### 步骤 2：两个判断函数——"可行吗"与"值多少"

```python
def feasible(x):
    for coef, b in constraints:
        if coef @ x > b + 1e-9:
            return False
    if x[0] < -1e-9 or x[1] < -1e-9:
        return False
    return True

def objective(x):
    return 3.0 * x[0] + 4.0 * x[1]
```

#### `feasible` —— 可行性检验

**操作**：逐条检查不等式 `coef @ x <= b`。`coef @ x` 是向量的点积：$\begin{pmatrix}1&2\end{pmatrix}\cdot\begin{pmatrix}A\\B\end{pmatrix} = A + 2B$。加 `1e-9` 容差是因为浮点数的解交点可能有 $10^{-17}$ 级误差——没有容差，理论上"恰好在线上"的点会被误判为越界。
**输入**：`x` —— 长度 2 的数组（一个候选顶点）。**输出**：`bool`——满足全部约束返回 `True`。
**可调参数**：
- 容差 `1e-9` 控制判定严苛程度。调大到 `1e-3` 会把"轻微越界"的点也放进来；调小到 `1e-15` 可能让浮点误差误伤合法顶点。
- 若要加入等式约束（如 $A+B=6$），在此函数里加一条 `if abs(A+B-6.0) > tol: return False`——等式要求**恰好**等于，这是 §5.2 三种约束中惩罚法最讨厌、这里最自然的一种。
- **对应数学**：主线里的可行域判定——点落在 $Ax\le b, x\ge 0$ 内即为可行。

#### `objective` —— 线性目标

**操作**：返回 $P = 3A + 4B$。
**输入**：`x`（长度 2 数组）。**输出**：标量 `float`。
**可调参数**：把系数 `3.0`/`4.0` 换成 `c1`/`c2`，最优顶点的选择会变化。**注意**：因为目标是线性的，它不会改变"最优必在顶点"这一事实，只会改变"哪个顶点最优"。

---

### 步骤 3：收集边界线——把顶点候选取出来

```python
lines = [(coef[0], coef[1], b) for coef, b in constraints]
lines.append((1.0, 0.0, 0.0))   # A = 0
lines.append((0.0, 1.0, 0.0))   # B = 0
```

**操作**：把每条约束线（$A+2B=10$、$3A+B=15$）与两根坐标轴（$A=0$、$B=0$）统一记成 `(a1, a2, b)` 表示 $a_1 A + a_2 B = b$。**为什么必须加上轴？** 因为可行域的顶点可能由"一条斜约束 + 一条轴"构成（如 $(5,0)$ 由 $3A+B=15$ 与 $B=0$ 相交）。漏掉轴，你就漏掉了一半顶点。
**输入**：`constraints`。**输出**：形状 `(4, 3)` 的边界线列表。
**可调参数**：新增约束会自动多一条线。若变量数变多（$n>2$），"顶点"由 $n$ 条线交成，枚举逻辑要改成 $n$ 重组合——这正是单纯形法存在的理由（§5.3.8）：它不枚举所有组合，只在相邻顶点间跳跃。

---

### 步骤 4：枚举交点 + 筛选 + 追踪最优

```python
for i in range(len(lines)):
    for j in range(i + 1, len(lines)):
        M = np.array([[lines[i][0], lines[i][1]],
                      [lines[j][0], lines[j][1]]])
        b = np.array([lines[i][2], lines[j][2]])
        if abs(np.linalg.det(M)) < 1e-12:
            continue
        x = np.linalg.solve(M, b)
        if feasible(x) and objective(x) > best_val:
            best_x, best_val = x, objective(x)
```

#### 双重循环 —— 所有线对

**操作**：对 $\binom{4}{2} = 6$ 个线对逐一求交点。每对线的交点是一个候选顶点。
**输入**：`lines` 列表。**输出**：依次处理每个交点。
**可调参数**：线的数量 $L$ 决定循环次数 $O(L^2)$。对二维问题这是秒级；但这是**暴力枚举**，顶点数随维度和约束数组合爆炸——务必记得主线说的"顶点有限≠顶点好找"。

#### `np.linalg.det(M)` —— 平行检测

**操作**：计算 2×2 系数矩阵的行列式。$M = \begin{pmatrix}a_1^{(i)} & a_2^{(i)} \\ a_1^{(j)} & a_2^{(j)}\end{pmatrix}$，行列式 $a_1^{(i)}a_2^{(j)} - a_2^{(i)}a_1^{(j)}$。**若行列式为 0，两条线平行或重合，无唯一交点**——必须跳过，否则下面 `solve` 会报奇异矩阵错误。
**输入**：`M`（形状 `(2,2)`）。**输出**：标量 `float`。
**可调参数**：阈值 `1e-12`。太大（如 `1e-3`）会误杀夹角很小的线对；太小则可能放行浮点导致的"伪平行"。

#### `np.linalg.solve(M, b)` —— 解二元一次方程组

**操作**：求解 $M \begin{pmatrix}A\\B\end{pmatrix} = b$，即联立两条边界线，返回交点坐标。这是主线里手算"$A+2B=10,\;3A+B=15 \Rightarrow (4,3)$"的机器版。
**输入**：`M`（形状 `(2,2)` 系数矩阵）、`b`（形状 `(2,)` 右端向量）。**输出**：形状 `(2,)` 的解向量 $(A,B)$。
**可调参数**：无直接参数。内部用高斯消元/LU 分解求解——线性代数（Ch02）在这里直接上岗。

#### 可行性 + 最优性筛选

**操作**：交点算出来后，先问 `feasible(x)`——不在可行域内的交点（比如落在约束围成区域之外的"假顶点"）直接丢弃；再问 `objective(x) > best_val`——与当前最好值比较，更新 `best_x`、`best_val`。
**输入**：`x`（交点）、`best_val`（当前最优值，初始 `-np.inf`）。**输出**：循环结束时 `best_x` 是最优顶点，`best_val` 是最优利润。
**可调参数**：把 `>` 换成 `<`、初始 `-np.inf` 换成 `+np.inf`，就变成最小化问题。

**对应数学**：这一整块实现主线 LP 基本定理的证明过程——最优解只在顶点候选里出现，所以枚举顶点+逐个比较，就等价于在全体可行点上取极值。

---

### 步骤 5：结果打印与自检

```python
print(f"最优解: A = {best_x[0]:.4f}, B = {best_x[1]:.4f}")
print(f"最优利润 P = {best_val:.4f}")
print(f"约束校验: A+2B = {best_x[0]+2*best_x[1]:.4f} (<=10), "
      f"3A+B = {3*best_x[0]+best_x[1]:.4f} (<=15)")
```

**操作**：输出最优顶点，并回代检验两条约束的取值——`10.0000 (<=10)` 与 `15.0000 (<=15)` 都取等号，证明 $(4,3)$ 是被两条绑定约束同时顶住的那个角。

## 如果想让代码更强

1. **推广到 $n$ 维**：把"线对枚举"换成"$n$ 条边界交成一个点"，可行域就从多边形变成多面体。每多一维，顶点组合指数增长——这正是你该转向单纯形法（§5.3.8）的时刻。
2. **接上 scipy 对照**：用 `scipy.optimize.linprog` 求同一问题，结果应完全一致。黑盒库只作**裁判**，不作拐杖——先理解顶点枚举，再用库加速。
3. **可视化**：用 `matplotlib` 画出两条约束线、阴影可行域，以及红色最优顶点 $(4,3)$——你会第一次"看见"顶点定理。
