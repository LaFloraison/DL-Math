## 解答与思路点拨

### 第一组

**1.1** 线性；线性；凸多面体（convex polyhedron）。**易错点**：有人写"多边形"——二维才是多边形，一般形式是 $n$ 维的多面体（polyhedron/polytope）。

**1.2** 选 B。根本原因是**线性目标 + 凸多面体可行域**这个组合保证极值在极值点取到。A（顶点有限）是结论带来的**好处**，不是原因；C 是必要条件但不是"为什么最优在顶点"的理由——非线性目标在多边形内部也能取极值；D 是错的——线性函数在无约束时没有极值，正因为有可行域这个"壳"，极值才被顶到边界上。

**1.3** 错。线性规划的保证（精确、顶点有限）**只在目标与约束都线性时成立**。非线性问题直接套线性算法，解出来的"最优"可能完全不是真正的最优。工程折中：**线性化 (linearization)**——在某个点附近用切线/切平面近似非线性目标与约束，把局部问题当作 LP 求解。但必须记住主线说的：线性近似只在小邻域可信，非线性太强时会严重失真。

### 第二组

**2.1**
(a) 约束线：$A+B=6$、$4A+B=12$、$A=0$、$B=0$。顶点：$(0,0)$、$(3,0)$（$4A+B=12$ 与 $B=0$ 交点）、$(2,4)$（两线交点：相减得 $3A=6\Rightarrow A=2, B=4$）、$(0,6)$（$A+B=6$ 与 $A=0$ 交点）。
(b) $P$ 在各顶点：$(0,0)\to0$；$(3,0)\to6$；$(2,4)\to4+20=24$；$(0,6)\to30$。**最优解 $(0,6)$，最优值 30。** 注意最优在 $(0,6)$——因为目标 $2A+5B$ 更偏爱 $B$，解被顶到 $B$ 最大的那个角。
(c) 在 $(0,6)$ 处：$A+B=6$ 取等号→**绑定**；$A=0$ 取等号→**绑定**；$4A+B = 6 \le 12$ 严格小于→不绑定；$B=6>0$→不绑定。
**易错点**：别只盯着两条斜线的交点 $(2,4)$——一定要**逐一检验所有顶点**，目标函数的方向决定哪个顶点赢。

**2.2** 可行域是第一象限内、直线 $A+B=4$ 下方的三角形。顶点：$(0,0)$、$(4,0)$、$(0,4)$。这个可行域是**有界**的（被三条边围死）。但关键问题在第 (a) 问之外：如果约束只有 $A \ge 0, B \ge 0$（没有 $A+B\le4$），可行域就是整个第一象限——**无界**。此时 $\max 3A + 4B$ 会随着 $A,B$ 同时增大而无上限地增长，**LP 无界，没有有限最优解**。**易错点**：把"有界"和"有解"混为一谈——无界可行域也可能有最优解（如果目标方向把解压回某个边界），也可能无最优解（如果目标方向与无界方向同向）。

**2.3** 修改：

```python
constraints = [(np.array([1.0, 1.0]), 6.0),
               (np.array([4.0, 1.0]), 12.0)]

def objective(x):
    return 2.0 * x[0] + 5.0 * x[1]
```

运行结果：`最优解 A=0.0000, B=6.0000, P=30.0000`，与手算一致。**要点**：只需改 `constraints` 和 `objective` 两处，顶点枚举逻辑一字不动——这就是"通用算法"的体现：算法骨架与具体问题解耦。

### 第三组

**3.1** 这个网络能表达的仍是**线性函数**。因为 $W_3 W_2 W_1$ 三个矩阵相乘仍是矩阵：$\mathbf{y} = W_{\text{total}} \mathbf{x}$，$W_{\text{total}} = W_3W_2W_1$。输出是输入的线性变换，形状是直线（/超平面），**不能**处理线性不可分数据。用线性优化的话说：这个网络的"表达力"只覆盖线性世界——它连一条弯曲的边界都画不出来。**深度"深"在没有非线性激活时是虚的**——堆多少层线性层，都等价于一层。

**3.2** 关键组件是**非线性激活函数**（ReLU、tanh、sigmoid）。激活让每一层的输出不再是输入的线性函数，破坏了"矩阵相乘仍线性"的链条。从优化角度：激活让整个网络的输入-输出映射从"直线"变成"弯曲"，于是网络能表达的可行域/函数类从线性函数扩张到任意非线性函数（通用逼近定理）。**这正是 §5.3.1 末尾"非线性世界"的入口**——也是为什么深度学习的优化问题不再能用线性规划的顶点保证，而必须转向梯度下降（§5.3.6 起）。
