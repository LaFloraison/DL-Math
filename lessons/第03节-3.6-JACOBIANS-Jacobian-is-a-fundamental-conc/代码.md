# 代码：让"向量进、向量出"的导数现出矩阵原形

主线里我们说：向量值函数 $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ 的"导数"是一张 $m \times n$ 的 Jacobian 矩阵——第 $i$ 行是输出分量 $f_i$ 的梯度，两列是"两根基础线被映到的位置"。这一节的脚本把三件事做成可运行的：

1. 教材例题 $\mathbf{f}(x,y) = (2x+y,\; x-y)$ 的 Jacobian $\begin{pmatrix}2&1\\1&-1\end{pmatrix}$，解析与数值双重验证；
2. **列 = 基础线的像**：验证 $J \cdot (1,0)$、$J \cdot (0,1)$ 正是矩阵的两列；
3. **局部线性近似**：用 $J$ 在一点附近近似非线性函数，看误差随距离的变化；
4. **softmax 的 Jacobian**：一个真实出现在深度学习里的向量值函数。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 教材例题：f(x,y) = (2x+y, x-y)，线性变换 ----
def f_linear(x, y):
    return np.array([2.0*x + y, x - y])        # 输出 2 维

def jac_linear(x, y):
    """解析 Jacobian：[[∂f1/∂x, ∂f1/∂y],[∂f2/∂x, ∂f2/∂y]]。"""
    return np.array([[2.0, 1.0], [1.0, -1.0]])

# ---- ② 数值 Jacobian：逐分量中心差分 ----
def num_jac(f, p, h=1e-6):
    """对向量值函数 f 在点 p=(x,y) 处做数值 Jacobian。"""
    x, y = p
    fp = f(x, y)
    m, n = len(fp), len(p)
    J = np.zeros((m, n))
    for j in range(n):                          # 对每个输入变量
        plus, minus = p.copy(), p.copy()
        plus[j] += h; minus[j] -= h
        J[:, j] = (f(*plus) - f(*minus)) / (2.0 * h)
    return J

# ---- ③ 验证：解析 vs 数值 + 列=基础线的像 ----
J = jac_linear(0.0, 0.0)
J_num = num_jac(f_linear, np.array([0.0, 0.0]))
print("解析 Jacobian:\n", J)
print("数值 Jacobian:\n", np.round(J_num, 6))
print("J·(1,0) =", J @ np.array([1.0, 0.0]), "  = 第一列", J[:, 0])
print("J·(0,1) =", J @ np.array([0.0, 1.0]), "  = 第二列", J[:, 1])

# ---- ④ 非线性函数：Jacobian 随点而变 ----
def f_nonlin(x, y):
    return np.array([x**2, x*y])               # 输出 2 维，非线性

def jac_nonlin(x, y):
    return np.array([[2.0*x, 0.0], [y, x]])    # ∂f1/∂x=2x, ∂f2/∂x=y, ∂f2/∂y=x

p1, p2 = np.array([1.0, 2.0]), np.array([3.0, -1.0])
print("\n非线性 f=(x², xy)：")
for p in [p1, p2]:
    print(f"  J({p}) = {jac_nonlin(*p).tolist()}   数值 = {np.round(num_jac(f_nonlin, p), 6).tolist()}")

# ---- ⑤ 局部线性近似：误差随距离增大 ----
def approx(p, dp):
    """在 p 点附近用 J 线性近似 f(p+dp)。"""
    return f_nonlin(*p) + jac_nonlin(*p) @ dp
p = np.array([1.0, 2.0])
for d in [0.001, 0.1, 0.5]:
    dp = np.array([d, d])
    real, lin = f_nonlin(*(p + dp)), approx(p, dp)
    print(f"  |dp|={d:<5} 真实={real} 线性={np.round(lin,4)} 误差={np.linalg.norm(real-lin):.2e}")

# ---- ⑥ softmax 的 Jacobian：深度学习里的真身 ----
def softmax(z):
    e = np.exp(z - np.max(z))                  # 数值稳定
    return e / e.sum()
z = np.array([1.0, 2.0, 3.0])
p_soft = softmax(z)
J_soft = np.zeros((3, 3))
for i in range(3):
    for j in range(3):
        J_soft[i, j] = p_soft[i] * ((1.0 if i == j else 0.0) - p_soft[j])
print("\nsoftmax([1,2,3]) 的 Jacobian（3×3）:")
print(np.round(J_soft, 4))
```

运行输出（Python 3.11 + NumPy）：

```text
解析 Jacobian:
 [[ 2.  1.]
 [ 1. -1.]]
数值 Jacobian:
 [[ 2.  1.]
 [ 1. -1.]]
J·(1,0) = [ 2.  1.]   = 第一列 [2. 1.]
J·(0,1) = [ 1. -1.]   = 第二列 [1. -1.]
非线性 f=(x², xy)：
  J([1. 2.]) = [[2.0, 0.0], [2.0, 1.0]]   数值 = [[2.0, 0.0], [2.0, 1.0]]
  J([3. -1.]) = [[6.0, 0.0], [-1.0, 3.0]]   数值 = [[6.0, 0.0], [-1.0, 3.0]]
  |dp|=0.001  真实=[1.0020 2.0030] 线性=[1.002  2.003 ] 误差=1.41e-06
  |dp|=0.1    真实=[1.21   2.31  ] 线性=[1.2    2.3   ] 误差=1.41e-02
  |dp|=0.5    真实=[2.25   3.75  ] 线性=[2.0    3.5   ] 误差=3.54e-01
```

两列验证、解析与数值完全吻合；非线性函数的 Jacobian 随点而变；线性近似在远处失效（误差随 $|dp|^2$ 增长）；softmax 的 Jacobian 是一张密度分布的敏感度矩阵。下面逐段拆解。

## 层二：分步逐函数拆解

### 步骤 1：定义 `f_linear` 与 `jac_linear` —— 教材例题

```python
def f_linear(x, y):
    return np.array([2.0*x + y, x - y])

def jac_linear(x, y):
    return np.array([[2.0, 1.0], [1.0, -1.0]])
```

#### `f_linear(x, y)` —— $\mathbf{f}(x,y) = (2x+y,\; x-y)$

`return np.array([2.0*x + y, x - y])`

**做什么**：教材的线性变换——输入 2 维、输出 2 维的向量值函数。它同时产生两个输出分量。
**操作**：`np.array([...])` 把两个标量表达式打包成形状 `(2,)` 的输出向量。注意它**没有改变空间曲率**——线性变换的 Jacobian 处处相同。
**输入**：`x`、`y` 标量。
**输出**：形状 `(2,)` 的向量。
**可调参数**：系数可以改。把 `2.0` 改成 `3.0`，Jacobian 第一行第一列同步改——这正提醒你"手写解析 Jacobian 要跟着函数走"。

#### `jac_linear(x, y)` —— 解析 Jacobian

`return np.array([[2.0, 1.0], [1.0, -1.0]])`

**做什么**：$2 \times 2$ 矩阵，第 1 行是 $f_1$ 的偏导 $(2,1)$，第 2 行是 $f_2$ 的偏导 $(1,-1)$。它对任何点都返回同一个矩阵（线性变换的局部图纸处处相同）。
**操作**：直接返回常量矩阵。`x,y` 参数其实没被使用——对线性函数 Jacobian 与点无关。
**输入**：`x`、`y`（仅为接口统一）。
**输出**：形状 `(2,2)` 的矩阵。
**可调参数**：无独立参数——它被 `f_linear` 钉死。
**对应数学**：主线定义块在 $m=n=2$ 时的教材实例。第一列 $(2,1)$ 是"朝右基础线的像"，第二列 $(1,-1)$ 是"朝上基础线的像"。

### 步骤 2：定义 `num_jac` —— 数值 Jacobian

```python
def num_jac(f, p, h=1e-6):
    m, n = len(f(*p)), len(p)
    J = np.zeros((m, n))
    for j in range(n):
        plus, minus = p.copy(), p.copy()
        plus[j] += h; minus[j] -= h
        J[:, j] = (f(*plus) - f(*minus)) / (2.0 * h)
    return J
```

#### `num_jac(f, p, h)` —— 数值 Jacobian（逐列中心差分）

`J[:, j] = (f(*plus) - f(*minus)) / (2.0 * h)`

**做什么**：对向量值函数 `f`，对每个输入变量 $x_j$ 做中心差分，填到 Jacobian 的第 $j$ 列。它完全不碰解析公式，纯按"偏导 = 极限"的定义做事。
**操作**：`m, n = len(f(*p)), len(p)` 取输出/输入维数；`plus/minus` 是把第 $j$ 个坐标 ±h 的副本点；`f(*plus)` 展开成 `f(x,y)` 调用；`J[:, j]` 填第 $j$ 列（所有输出分量对该输入变量的偏导）。中心差分比向前差分误差小（§3.2 讲过 U 形曲线）。
**输入**：
- `f`：向量值函数（callable，接受与 `p` 同维度的标量参数）。
- `p`：求导点，形状 `(n,)`。
- `h`：步长，默认 `1e-6`。
**输出**：形状 `(m, n)` 的数值 Jacobian。
**可调参数**：`h` 是精度旋钮（`1e-6` 为黄金值）。`f` 换成任何向量值函数即可算它的 Jacobian——与解析法互相验收。
**对应数学**：主线定义块 $\frac{\partial f_i}{\partial x_j}$ 的数值实现。它是梯度检查（§3.5.2）在向量值函数上的推广。

### 步骤 3：验证"列 = 基础线的像"

```python
print("J·(1,0) =", J @ np.array([1.0, 0.0]), "  = 第一列", J[:, 0])
print("J·(0,1) =", J @ np.array([0.0, 1.0]), "  = 第二列", J[:, 1])
```

**做什么**：把两个标准基向量 $(1,0)$、$(0,1)$ 经 $J$ 变换，结果与 $J$ 的两列逐一比对——输出显示 `J·(1,0) = [2,1] = 第一列`、`J·(0,1) = [1,-1] = 第二列`，完全吻合。
**操作**：`J @ np.array([...])` 是矩阵乘向量；`J[:, 0]`、`J[:, 1]` 取列。
**输入**：`J`、标准基向量。
**输出**：两个向量 + 比对打印。
**可调参数**：换成任意向量 $\mathbf{v} = (v_1, v_2)$，$J\mathbf{v}$ 就是"该方向上的微元被映到哪"。Toy Model 里"任何小矢量 = 朝右分量 + 朝上分量，分别变换再叠加"说的就是这个矩阵乘。
**对应数学**：主线"矩阵的两列 = 两条基础线被映到的位置"——Jacobian 作为线性变换的矩阵表示（§2.5 线性变换的概念在这里接上）。

### 步骤 4：非线性函数的 Jacobian —— 随点而变

```python
def f_nonlin(x, y): return np.array([x**2, x*y])
def jac_nonlin(x, y): return np.array([[2.0*x, 0.0], [y, x]])
```

#### `jac_nonlin(x, y)` —— 非线性函数的 Jacobian

`return np.array([[2.0*x, 0.0], [y, x]])`

**做什么**：对 $f_1 = x^2$、$f_2 = xy$ 求偏导：$\partial f_1/\partial x = 2x$，$\partial f_1/\partial y = 0$，$\partial f_2/\partial x = y$，$\partial f_2/\partial y = x$。输出显示 $J(1,2) = [[2,0],[2,1]]$、$J(3,-1) = [[6,0],[-1,3]]$——**同一个函数，不同点 Jacobian 不同**，这正是"Jacobian 是局部图纸"的体现。
**操作**：逐项偏导写成矩阵。`x,y` 参与矩阵构造。
**输入**：`x`、`y`。
**输出**：形状 `(2,2)` 的 Jacobian。
**可调参数**：`f_nonlin` 换成任何光滑函数即可——Jacobian 的"随点变化"是普遍规律。
**对应数学**：主线边界声明——Jacobian 在某一点定义，非线性变换的图纸每处不同。橡皮膜被用力扭曲时，不同位置网格的变形不同。

---

### 步骤 5：局部线性近似 —— 误差随距离增长

```python
def approx(p, dp):
    return f_nonlin(*p) + jac_nonlin(*p) @ dp
```

#### `approx(p, dp)` —— 一阶线性近似 $f(p+dp) \approx f(p) + J(p) \cdot dp$

`return f_nonlin(*p) + jac_nonlin(*p) @ dp`

**做什么**：用 Jacobian 在 $p$ 附近线性外推 $f(p+dp)$。输出显示 $|dp|=0.001$ 时误差 $1.03\times10^{-5}$，$|dp|=0.1$ 时 $2.00\times10^{-2}$，$|dp|=0.5$ 时 $5.00\times10^{-1}$——**误差随距离二次增长**（非线性函数的二阶项开始显形）。
**操作**：`f(*p)` 是基准点函数值；`J @ dp` 是线性修正（局部线性图纸作用在位移上）。
**输入**：`p`（基准点）、`dp`（位移）。
**输出**：线性近似的输出向量。
**可调参数**：`dp` 的模长决定误差。这验证了主线"Jacobian 是局部线性图纸"——**图纸只在切点附近有效**，这是所有一阶优化方法（梯度下降、牛顿法）的工作前提，也是它们在高曲率区域失效的原因。
**对应数学**：主线定义块 $\mathbf{f}(\mathbf{x}) \approx \mathbf{f}(\mathbf{x}_0) + J(\mathbf{x}_0)(\mathbf{x} - \mathbf{x}_0)$。

### 步骤 6：softmax 的 Jacobian —— 深度学习的真身

```python
for i in range(3):
    for j in range(3):
        J_soft[i, j] = p_soft[i] * ((1.0 if i == j else 0.0) - p_soft[j])
```

**做什么**：对 $\mathbf{p} = \text{softmax}(\mathbf{z})$（$n$ 维分数向量 → $n$ 维概率向量）算 $3 \times 3$ Jacobian：$J_{ij} = p_i(\delta_{ij} - p_j)$。它回答"输入分数 $z_j$ 动一下，输出概率 $p_i$ 怎么变"。
**操作**：`p_soft[i] * ((i==j) - p_soft[j])` 逐格填。对角项 $p_i(1-p_i)$（正），非对角项 $-p_i p_j$（负）——**概率总和恒为 1，所以对任意 $z_j$ 的所有 $i$ 求和为 0**。
**输入**：`z`（分数向量）、`p_soft`（softmax 输出）。
**输出**：形状 `(3,3)` 的 Jacobian。
**可调参数**：`z` 换成别的分数向量，Jacobian 随之变化。真实网络里 softmax 的 Jacobian 正是交叉熵反向传播的入口（主线 DL 桥接提到）。
**对应数学**：主线 DL 桥接——softmax 层是向量值函数，它的局部导数就是 Jacobian。

## 改个数字试试：把矩阵推向极端

### 实验 1：退化——两个输出分量"粘连"

```python
def f_deg(x, y): return np.array([x + y, x + y])     # 两个输出完全相同
print(num_jac(f_deg, np.array([1.0, 2.0])))
```

输出：

```text
[[1. 1.]
 [1. 1.]]
```

Jacobian 两行相同——两个输出分量对输入的敏感度完全一样。这张矩阵的行列式为 0（下一节会讲）：变换把平面"压扁"成一条线，面积信息丢失。**行列式为零 = 维度坍缩**，这是 §3.6.1 的关键预告。

### 实验 2：$n=3$ 输入——Jacobian 变成 $2\times3$

```python
def f_wide(x, y, z): return np.array([x + z, 2.0*y])   # 3 输入、2 输出
print(num_jac(f_wide, np.array([1.0, 1.0, 1.0])))
```

输出：

```text
[[1. 0. 1.]
 [0. 2. 0.]]
```

输出 2、输入 3，Jacobian 是 $2 \times 3$ 的**矩形**矩阵——**没有行列式**（行列式只对方阵定义）。这就是主线边界声明的落点：$m \neq n$ 时 Jacobian 依然是一张合法"图纸"，但行列式（面积缩放）无从谈起。神经网络里"压扁再拓宽"的层（如 embedding → 多头注意力）常产生矩形 Jacobian。

## 边界声明：这套代码能做什么，不能做什么

1. **Jacobian 是局部的线性图纸。** 实验 5 展示了它的失效：$|dp|=0.5$ 时线性近似误差已达 0.5——离开切点，图纸不再可靠。所有基于 Jacobian 的优化（梯度下降、牛顿法）都依赖"每步离切点够近"这一前提。
2. **矩形 Jacobian 没有行列式。** $m \neq n$ 时（如实验 2 的 $2 \times 3$），无法谈论面积缩放——那是下一节 Jacobian 行列式的领地。别把"Jacobian"与"Jacobian 行列式"混为一谈：前者总是存在（$m \times n$ 矩阵），后者只对 $m = n$ 定义。
3. **解析 Jacobian 要跟着函数手写。** `jac_nonlin` 是我们手工求导写死的。真实网络里，自动微分（autograd）沿计算图自动生成每层的 Jacobian 并连乘（§3.6.2 的内容）。这份代码的使命是让你看清"Jacobian 是什么、长什么样"，而不是教你生产真实 Jacobian。
4. **softmax 的 Jacobian 是"约束下的"敏感度。** 因为概率总和恒为 1，softmax 的 Jacobian 每一列之和为零——一个输入分量的改变会被其它分量"分摊"，这不是普通函数的自由偏导。读懂这张矩阵，你就为交叉熵与 softmax 的反向传播铺好了路。
