# 代码：用 NumPy 亲手跑一遍张量运算

主线里我们用暗房的一摞照片感受了张量运算的五个动作：逐元素、广播、reshape/transpose、批量矩阵乘法、张量收缩。这一节把它们全部变成 NumPy 代码，并逐函数拆解。每个例子的数字都取自教材 §2.4.4 的原文，跑出来的结果直接印证主线里的手算。

脚本只依赖 NumPy，约 30 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                            # NumPy：张量运算全家桶

# ---- ① 逐元素运算：ReLU —— 教材 (b) 的 Z = [1.1, 2.5] ----
Z = np.array([1.1, 2.5])                      # 形状 (2,)：两个神经元的输出
relu = np.maximum(Z, 0.0)                     # 每个元素与 0 比大小，取大者
print("ReLU([1.1, 2.5]) =", relu)             # [1.1 2.5]

# ---- ② 逐元素运算：MSE 损失 —— 教材 (j) ----
Ypred = np.array([0.8, 0.4])                  # 预测张量，形状 (2,)
Ytrue = np.array([1.0, 0.0])                  # 真实张量，形状 (2,)
loss = np.mean((Ypred - Ytrue) ** 2)          # 逐元素相减 → 逐元素平方 → 取平均
print("MSE loss =", loss)                     # 0.10

# ---- ③ 广播：M + v —— 教材 (h) ----
M = np.array([[3.0, 4.0], [5.0, 6.0]])        # 形状 (2,2) 的矩阵
v = np.array([1.0, 2.0])                      # 形状 (2,) 的向量
Mnew = M + v                                  # v 沿行方向广播 → 每行都加上 v
print("M + v =", Mnew)                        # [[4. 6.] [6. 8.]]

# ---- ④ 批量矩阵乘法：同一个 W 作用整批样本 —— 教材 (e) ----
W = np.array([[0.5, 0.3], [0.7, 0.9]])        # 权重，形状 (2,2)
Xbatch = np.array([[1.0, 2.0], [0.5, 1.5]])   # 两个样本当行，形状 (2,2)
Zbatch = (W @ Xbatch.T).T                     # 每个样本算 W·x，再转回"样本当行"
print("批量输出 Z =", Zbatch)                 # [[1.1 2.5] [0.7 1.7]]

# ---- ⑤ reshape / transpose：特征图摊平给全连接层 ----
fm = np.arange(16).reshape(2, 8)              # 模拟一张特征图，形状 (2,8)
flat = fm.reshape(-1)                         # 摊平成 16 个元素的一维
T = fm.T                                      # 转置：形状 (8,2)
print("flatten =", flat)
print("fm.T    =", T)

# ---- ⑥ 张量收缩：点积 = 沿共享维度相乘求和 —— 教材 (g) ----
a = np.array([1.0, 2.0])                      # 序列 A
b = np.array([3.0, 4.0])                      # 序列 B
score = np.einsum('i,i->', a, b)              # 收缩下标 i：1*3 + 2*4
print("点积 a·b =", score)                    # 11.0
```

## 层二：分步逐函数拆解

### 步骤 1：造张量 `np.array`

```python
Z = np.array([1.1, 2.5])
```

#### `np.array(list)` —— 把 Python 列表变成张量

**做什么**：把列表 `[1.1, 2.5]` 转成 NumPy 的 `ndarray`——这是"张量在计算机里的存在形式"。
**操作**：推断数据类型为 `float64`，把元素按顺序存入内存。
**输入**：一维列表 `[1.1, 2.5]`，两个浮点数。
**输出**：形状 `(2,)` 的数组。`(2,)` 表示"一维、2 个元素"；`Z[0]=1.1`、`Z[1]=2.5` 是两个神经元的输出。
**可调参数**：
- 嵌套列表决定维数：`np.array([[1.0, 2.0], [0.5, 1.5]])` 得到形状 `(2,2)` 的矩阵；再套一层就是 3 阶张量。
- `dtype`：`np.array([1, 2], dtype=np.float32)` 强制单精度，深度学习里省一半显存。
- `ndmin`：`np.array([1, 2], ndmin=2)` 得到形状 `(1,2)`，把一维"升维"——处理形状对齐时有用。
**对应数学**：主线里张量 = 多维数组的定义；`(2,)` 就是一个 1 阶张量。

### 步骤 2：逐元素 ReLU —— `np.maximum`

```python
relu = np.maximum(Z, 0.0)
```

#### `np.maximum(a, b)` —— 逐元素取较大者

**做什么**：对两个张量同一位置的元素，两两取 $\max(a_i, b_i)$，结果形状与输入一致。
**操作**：把 `Z` 的每个元素与标量 `0.0` 比较——标量 `0.0` 靠广播覆盖到 `Z` 的每个位置（这是标量广播，见步骤 4）。
**输入**：`Z` 形状 `(2,)`；`b=0.0` 是标量。
**输出**：形状 `(2,)`：$\max(1.1, 0)=1.1$、$\max(2.5, 0)=2.5$，即 `[1.1 2.5]`。
**可调参数**：
- 两个参数都可以是数组：`np.maximum([1, -2], [3, 1])` 逐位比较得 `[3, 1]`。
- 两个参数形状不同时自动广播——所以 `np.maximum(Z, 0.0)` 能写，`np.maximum(Z, np.array([0.1, 0.2]))` 也能写（逐位置取大者）。
- `out` 参数：`np.maximum(Z, 0.0, out=Z)` 把结果写回 `Z`，省内存。
- 相关函数：`np.clip(Z, 0, None)` 等价于 ReLU；`np.minimum` 是取较小者。
**对应数学**：主线公式 $\text{ReLU}(Z) = \max(0, Z)$——教材 (b) 的逐元素激活。

### 步骤 3：逐元素链 + 归约 —— MSE 损失

```python
loss = np.mean((Ypred - Ytrue) ** 2)
```

#### `ndarray1 - ndarray2` —— 逐元素减法

**做什么**：两个形状相同的张量，同一位置的元素相减。
**操作**：`Ypred - Ytrue = [0.8-1.0, 0.4-0.0] = [-0.2, 0.4]`。
**输入**：`Ypred` 与 `Ytrue`，均形状 `(2,)`。
**输出**：形状 `(2,)` 的 `[-0.2, 0.4]`。
**可调参数**：形状必须相等或可广播；`np.subtract(a, b)` 是同一函数的显式写法。
**对应数学**：教材 (j) 的 $\text{Ypred} - \text{Ytrue}$。

#### `ndarray ** 2` —— 逐元素幂运算

**做什么**：每个元素平方。`[-0.2, 0.4] ** 2 = [0.04, 0.16]`。
**操作**：`** 2` 底层调用 `np.power`，逐元素计算 $x^2$。
**输入**：形状 `(2,)`。
**输出**：形状 `(2,)` 的 `[0.04, 0.16]`。
**可调参数**：指数任意——`** 0.5` 是开方（MSE 里不需要，RMSE 才用）；`np.square(x)` 是平方的等价写法。
**对应数学**：教材 (j) 损失里的 $(0.8-1.0)^2$ 与 $(0.4-0.0)^2$。

#### `np.mean(a)` —— 对所有元素取平均

**做什么**：把 `[0.04, 0.16]` 缩成一个标量 $(0.04+0.16)/2 = 0.10$。
**操作**：对所有元素求和再除以元素个数——这是**归约 (reduction)**：把某个维度的信息"折叠"成一个数。
**输入**：形状 `(2,)`。
**输出**：标量 `0.1`，正好等于教材的 $\tfrac12(0.04+0.16)=0.1$（教材用"二分之一乘以求和"，对两个元素等价于取平均）。
**可调参数**：
- `axis`：`np.mean(a, axis=0)` 沿第 0 维归约，返回形状 `(2,)`——批量训练里对"样本维"求均值得到每个特征的均值，是 BatchNorm 的核心操作。
- `keepdims=True`：保持被归约的维度为 1，方便后续广播（见步骤 4 的语义）。
- `dtype`：控制求和精度。
**对应数学**：主线"逐元素负责每个格子" + 一次归约；MSE 是"逐元素平方后再折叠成单个数字"。

### 步骤 4：广播 —— `M + v`

```python
Mnew = M + v
```

#### `ndarray + ndarray`（带广播）—— 形状不同的逐元素加法

**做什么**：把形状 `(2,)` 的 `v` 加进形状 `(2,2)` 的 `M` 的每一行。
**操作**：按广播规则从右对齐——`(2,)` 对 `(2,2)`，最右维 `2` 对 `2` 相等；`v` 缺失的左侧维度视为 `1`，于是 `v` 被"复用"到两行：第一行加 `[1,2]`、第二行也加 `[1,2]`。
**输入**：`M` 形状 `(2,2)`，`v` 形状 `(2,)`。
**输出**：形状 `(2,2)` 的 `[[4, 6], [6, 8]]`（教材 (h) 的精确结果）。
**可调参数**：
- 换 `v` 的形状为 `(2,1)`（列向量）则沿**列**广播：`M + [[0],[10]]` 让第一行加 0、第二行加 10——同一组数，形状不同，作用方向完全不同。
- 标量：`M + 1.0` 全元素加 1，是广播的极端情形（零维张量）。
- `np.add(M, v)` 是显式写法；两个形状按规则配不上时（如 `(2,2)` 加 `(3,)`）直接抛 `ValueError`。
**对应数学**：主线的广播定义块；教材 (h) 的 $M_{\text{new}}$。

### 步骤 5：批量矩阵乘法 —— `@` 运算符

```python
Zbatch = (W @ Xbatch.T).T
```

#### `a @ b` —— 矩阵乘法（`np.matmul`）

**做什么**：对 `W` 与 `Xbatch` 的转置做矩阵乘，再转回"样本当行"的布局。拆开看：
- `Xbatch.T`：把样本从"行"翻成"列"，形状 `(2,2)`——第 0 列是样本 1 `[1,2]`，第 1 列是样本 2 `[0.5,1.5]`。
- `W @ Xbatch.T`：每个"权重行"与每列做点积，第 $j$ 列就是 $W \cdot \text{样本}_j$——即 $[W\mathbf{x}_1,\ W\mathbf{x}_2]$，形状 `(2,2)`。
- 外层 `.T`：把结果再翻回来，让**第 $i$ 行对应第 $i$ 个样本**（深度学习框架的通行布局）。

**操作**：矩阵乘法 = 张量收缩，对共享维（$W$ 的列、$X^{\mathsf{T}}$ 的行）逐元素相乘再求和。
**输入**：`W` 形状 `(2,2)`，`Xbatch` 形状 `(2,2)`。要求 $W$ 的列数 $=$ `Xbatch.T` 的行数（这里都是 2）。
**输出**：形状 `(2,2)`：`[[1.1, 2.5], [0.7, 1.7]]`——第 0 行是教材 (a) 的单样本结果 $W\mathbf{x}_1=[1.1,2.5]$，第 1 行是 $W\mathbf{x}_2=[0.7,1.7]$。
**可调参数**：
- `np.matmul(a, b)` 支持"批量"：若 `a` 是 `(B,M,K)`、`b` 是 `(K,N)`，结果 `(B,M,N)`——批次维 $B$ 自动不动。这就是 PyTorch 里全连接层真正在跑的东西。
- `@` 与 `np.dot` 的区别：对二维都是矩阵乘；对更高维，`np.dot` 做"后几维收缩"而 `@` 做"按批次广播"，语义不同，别混用。
- `out` 参数：`np.matmul(a, b, out=...)` 可指定输出位置。
**对应数学**：教材 (e) 的批量运算 + 主线"批量矩阵乘法定义块"。

### 步骤 6：reshape 与 transpose

```python
fm = np.arange(16).reshape(2, 8)
flat = fm.reshape(-1)
T = fm.T
```

#### `np.arange(16)` —— 生成 0 到 15 的整数数组

**做什么**：生成形状 `(16,)` 的 `[0 1 2 ... 15]`。
**可调参数**：`np.arange(start, stop, step)`——`np.arange(1, 10, 2)` 得到 `[1 3 5 7 9]`；`dtype` 可指定整数类型。
**对应数学**：为 reshape 准备一串无歧义的"序号"，方便看清元素怎么被重新摆放。

#### `ndarray.reshape(shape)` —— 重塑形状

**做什么**：把 `(16,)` 摆成 `(2,8)`——元素总数必须不变（$2\times8=16$）。
**操作**：按"行优先"（C 顺序）把 `[0..15]` 排成两行：第 0 行 `[0..7]`、第 1 行 `[8..15]`。数据一个没变，变的只是"有几行几列"。
**输入**：形状 `(16,)` 的数组。
**输出**：形状 `(2,8)`。
**可调参数**：
- `-1` 自动推断：`fm.reshape(-1)` 摊平成 `(16,)`——**flatten**，CNN 特征图进全连接层前的标准动作（图 2.11 的 "Flattened Tensor"）。
- `order='F'`：按列优先（Fortran 顺序）重排，同一个数据会摆成不同的矩阵，初学者常在此踩坑。
- `ndarray.flatten()` 返回新数组（总是复制），`reshape` 在多数情况返回**视图**（与原数组共享内存）——改一个会改另一个，见边界声明。
**对应数学**：主线"reshape 换容器不换数据"。

#### `ndarray.T` / `np.transpose(a, axes)` —— 转置

**做什么**：交换第 0 维与第 1 维：`fm` 是 `(2,8)`，`fm.T` 是 `(8,2)`。
**操作**：$(A^{\mathsf{T}})_{ij} = A_{ji}$——把原来的列变成行。看输出：第 0 行 `[0, 8]` 是原矩阵两行的第 0 列拼成的，说明"转置换的是元素之间的相邻关系"，和 reshape 的"只换分组"完全不同。
**输入**：`fm` 形状 `(2,8)`。
**输出**：形状 `(8,2)`。
**可调参数**：
- `np.transpose(a, axes=(1, 0))`：显式给出维度交换顺序；对 3 阶张量 `axes=(2,0,1)` 可做任意的维度重排。
- `.T` 只交换最后两维，高维要交换别的维度就得用 `np.transpose` 或 `.permute`（PyTorch）。
**对应数学**：主线"transpose 换坐标轴"；教材 (e) 里批量矩阵乘法要用到它。

### 步骤 7：张量收缩 —— `np.einsum`

```python
score = np.einsum('i,i->', a, b)
```

#### `np.einsum(subscripts, *operands)` —— 按下标表达式收缩张量

**做什么**：按字符串 `'i,i->'` 指定的方式，把 `a` 和 `b` 沿共享下标 `i` 逐元素相乘再求和。
**操作**：`'i,i->'` 的含义——两个输入都只有下标 `i`，箭头右边什么都没有（表示"求和到标量"）。于是 $\text{score} = \sum_i a_i b_i = 1\times3 + 2\times4 = 11.0$。
**输入**：`a`、`b` 均形状 `(2,)`。
**输出**：标量 `11.0`——教材 (g) 里"两个序列元素之间的点积"，就是注意力里"一个元素对另一个元素的影响程度"。
**可调参数**：
- 下标字符串可写任意收缩模式：矩阵乘 `'ij,jk->ik'`、批量矩阵乘 `'bij,bjk->bik'`、批量点积 `'bd,bd->b'`（$Q$、$K$ 逐样本做点积，正是注意力得分）。
- 一个下标可以"留"（出现在箭头上）也可以"消"（不出现在箭头上）——留=保留维度，消=求和收缩。
- `optimize=True`：自动找最优计算顺序，省下大量乘法；`out`、`dtype` 同前。
**对应数学**：主线"张量收缩定义块"：$(WX)_{ij} = \sum_k W_{ik}X_{kj}$ 与 $\mathbf{a}\cdot\mathbf{b} = \sum_i a_i b_i$。

## 边界声明：这套代码能做什么，不能做什么

1. **广播不是万能的。** 规则是"从右往左，逐维相等或一方为 1"。`M(2,2) + v(3,)` 会抛 `ValueError`——这不是 bug，是 NumPy 在提醒你形状语义对不上。排查形状错误时，先按规则自己对齐一遍再问为什么报错。
2. **reshape 可能返回视图。** `fm.reshape(2,8)` 与原数组共享内存，改视图会改原数组；`transpose` 后内存不再连续，后续运算可能被隐式拷贝。**"看起来一样"不等于"内存里一样"**——需要真正独立的副本时用 `.copy()`。
3. **收缩维度必须匹配。** `(M,K)` 乘 `(K,N)` 要求两个 `K` 相等；不匹配时 `@` 抛错，数学上是"该操作无定义"，不是"算错"。
4. **`@` 与 `np.dot` 对高维张量语义不同。** `@` 把前导维当批次广播，`np.dot` 做另一种收缩；深度学习中几乎只用 `@`（PyTorch 的 `matmul` 同样语义）。
5. **`np.mean` 是"折叠"不是"逐个看"。** 它把一个维度的所有信息压成一个数——BatchNorm 用它算统计量没问题，但**永远不会用它来做"保留每个元素"的逐元素操作**。归约与逐元素是两类不同的张量运算，别混为一谈。
