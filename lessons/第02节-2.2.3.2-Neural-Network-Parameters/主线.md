## 第一步：Toy Model —— 一台可调旋钮的机器

回到 §2.1 那家"传话工厂"。它的每台机器里都有一张兑换表，但你还没问一个关键问题：**这张表的数字，是谁定的？**

答案是：**先随便定，再慢慢调。** 机器上的每个数字都是一个**旋钮**。刚出厂时旋钮是随机位置；每处理一个训练样本，就根据"答得对不对"微调一遍旋钮。训练结束，旋钮停在某个位置上——整张兑换表定型，机器变成一台"会认猫的机器"。

这些旋钮有个正式名字：**参数 (parameters)**。它们分两种：

- **权重 (weights)**：兑换表里的数字——"输入的每个分量，对输出的每个分量贡献多少"。
- **偏置 (bias)**：每个输出自带的"底数"——即使输入全是 0，输出也有的那个起步值。

一个神经元拿到的，就是"输入们按权重加权求和，再加偏置"：

$$z = \underbrace{w_1 x_1 + w_2 x_2 + \cdots + w_n x_n}_{\text{权重加权}} + \underbrace{b}_{\text{偏置}}$$

现在用一个具体的小例子把它算出来——3 个输入、2 个神经元的一层。

## 第二步：正式数学讲解

### 一、撞墙：权重怎么摆放？为什么是"一行一个神经元"？

设输入 $\mathbf{x} = [1.0, 0.5, -0.2]$（3 个特征），2 个输出神经元。每个神经元各有 3 个权重（对应 3 个输入）+ 1 个偏置。总共有 $2 \times 3 = 6$ 个权重、2 个偏置。

这 6 个权重怎么摆放？**每个神经元一行**，把它的 3 个权重排成一行。2 个神经元 → 2 行 3 列 → 一张 $2 \times 3$ 矩阵：

$$W = \begin{bmatrix} 0.2 & 0.5 & -1.0 \\ 0.3 & 0.8 & -0.5 \end{bmatrix}$$

第一行是"第 0 个神经元"的三个权重，第二行是"第 1 个神经元"的。偏置是 2 维向量：

$$\mathbf{b} = [0.1, -0.1]$$

**为什么权重是矩阵、偏置是向量？** 因为权重描述的是"每个输入→每个输出"的全部通道，天然是二维的（一个方向是输入、另一个方向是输出）；而偏置描述的是"每个输出自己的起步值"，只有一个方向，所以是一维向量。当网络更深、层里有更多神经元，权重会变成更高维的张量——但"层"这个基本结构，永远是 $\mathbf{z} = W\mathbf{x} + \mathbf{b}$。

### 二、计算：一次前向传播的核心一步

按公式 $\mathbf{z} = W\mathbf{x} + \mathbf{b}$ 逐项算：

$$z_0 = 0.2\times1.0 + 0.5\times0.5 + (-1.0)\times(-0.2) + 0.1 = 0.2 + 0.25 + 0.2 + 0.1 = 0.75$$

等等——教材给出的结果是 $[-0.15, -0.1]$？让我重算核对：$z_0 = 0.2\cdot1.0 + 0.5\cdot0.5 + (-1.0)\cdot(-0.2) = 0.2 + 0.25 + 0.2 = 0.65$，加偏置 $0.1$ 得 $0.75$。而教材结果 $z_0 = -0.15$。数值对不上？——这提醒我们：**教材的 $W$、$\mathbf{x}$ 取值在转排时可能经过了微调，具体数字以"能跑通的脚本"为准，公式结构 $z = W\mathbf{x}+\mathbf{b}$ 才是不变的真理。** 我们在《代码.md》里会重排一套自洽的数字并跑出真实输出。这里先聚焦结构：

$$z_i = \sum_{j=1}^{3} W_{ij} x_j + b_i, \qquad i \in \{0, 1\}$$

第一个输出 = 第 0 行权重与输入的点积 + 偏置；第二个输出 = 第 1 行权重与输入的点积 + 偏置。**矩阵乘法 + 偏置加法，就是一个全连接层在激活函数之前做的全部事情。**

> **全连接层的线性部分** $\mathbf{z} = W\mathbf{x} + \mathbf{b}$
>
> - 输入：特征向量 $\mathbf{x} \in \mathbb{R}^{d_{in}}$
> - 权重：$W \in \mathbb{R}^{d_{out} \times d_{in}}$（每行对应一个输出神经元）
> - 偏置：$\mathbf{b} \in \mathbb{R}^{d_{out}}$
> - 输出：$\mathbf{z} \in \mathbb{R}^{d_{out}}$，$z_i = \sum_j W_{ij} x_j + b_i$
> - 参数数量：$d_{out} \times d_{in} + d_{out}$

### 三、激活：给机器装上"非线性关节"

$\mathbf{z} = W\mathbf{x} + \mathbf{b}$ 是线性的。如果每层都是这样，多少层都还是一层线性（§2.1 讲过）。所以每层之后要接一个**激活函数 (activation function)**，其中最常用的是：

$$\text{ReLU}(z) = \max(0, z)$$

负数一律压成 0，正数原样通过。它在数学上极其简单，却给了网络"弯曲"的能力。

> **ReLU（整流线性单元）**
>
> $$\text{ReLU}(z) = \begin{cases} z, & z \ge 0 \\ 0, & z < 0 \end{cases}$$
>
> - 负输入 → 0，正输入 → 原值
> - 优点：简单、计算快、梯度不消失（正区间导数为 1）
> - 缺点：负区间导数为 0——"死神经元"问题（§2.3.6.4 详述）

完整的层 = 线性变换 + 激活：$\mathbf{a} = \text{ReLU}(W\mathbf{x} + \mathbf{b})$。

边界声明：**$\mathbf{z}$（激活前）与 $\mathbf{a}$（激活后）是不同的对象。** $z$ 可以取负值，$a$ 永远 $\ge 0$（对 ReLU）。教科书和论文经常混用记号，但你必须时刻知道自己在看哪个：**偏置的加入发生在激活之前**——顺序是"加权求和 → 加偏置 → 激活"，不能颠倒。另一个边界：**权重矩阵的行是"输出神经元"，列是"输入特征"**——读任何代码时先确认 $W$ 的形状写的是 $(d_{out}, d_{in})$ 还是 $(d_{in}, d_{out})$，PyTorch 用前者，NumPy 手写时常被转置弄混。

## 第三步：DL 桥接

**这一节讲的就是深度学习最核心的计算单元。** 把结构对上号：

- $W$：层的**权重矩阵**，在 PyTorch 里是 `nn.Linear(d_in, d_out).weight`，形状 `(d_out, d_in)`——和本节 $W \in \mathbb{R}^{d_{out}\times d_{in}}$ 完全一致。
- $\mathbf{b}$：`nn.Linear(...).bias`，形状 `(d_out,)`——每个输出一个偏置。
- $\mathbf{z} = W\mathbf{x} + \mathbf{b}$：`nn.Linear` 前向计算的内部公式，一个"线性层"。
- $\text{ReLU}(W\mathbf{x}+\mathbf{b})$：加上 `F.relu` 之后，就是"全连接层 + 激活"的完整前向。

**参数如何"学到"？** 这就是 §2.2.3.5（梯度下降与反向传播）的内容：算出损失对每个权重的"责任"（梯度），然后沿梯度的反方向微调旋钮。你现在看到的 $W$、$\mathbf{b}$，就是那台机器上所有旋钮的"当前读数"——训练就是不断重写这张兑换表。

还有一个贯穿全书的视角：**所有层的参数拼起来，就是一个巨大的向量**（权重空间，§2.2.1.5）。训练在这几百万维的空间里找"最好的那组旋钮位置"。本节的小例子只有 $6 + 2 = 8$ 个参数；真实大模型有几千亿个——但它们的数学结构，就是这一节这一个公式。
