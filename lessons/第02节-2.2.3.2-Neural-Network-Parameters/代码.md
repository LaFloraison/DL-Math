# 代码：手写一个"线性层"——权重矩阵、偏置向量、ReLU

主线里我们拆解了 $z = W\mathbf{x} + \mathbf{b}$，但教材的数字在转排时对不上。这一节用**一套自洽的数字**把全过程算到底，输出真实结果——同时解释 `@`（矩阵乘）与 `+`（偏置）的确切形状。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：矩阵乘法与逐元素运算

# ---- ① 输入：3 个特征的向量 ----
x = np.array([1.0, 0.5, -0.2])            # 形状 (3,)

# ---- ② 权重：2 个输出神经元 × 3 个输入 ----
W = np.array([[ 0.2,  0.5, -1.0],         # 第 0 个神经元的 3 个权重
              [ 0.3,  0.8, -0.5]])        # 第 1 个神经元的 3 个权重
print("W 形状:", W.shape, "= (2 输出, 3 输入)")

# ---- ③ 偏置：每个输出一个 ----
b = np.array([0.1, -0.1])                 # 形状 (2,)
print("b 形状:", b.shape)

# ---- ④ 线性部分：z = W @ x + b ----
z = W @ x + b
print("z = Wx + b =", z, "形状:", z.shape)   # 2 个输出，激活前的值

# ---- ⑤ 激活：ReLU(z) = max(0, z) ----
a = np.maximum(0.0, z)                    # 负数压 0，正数保留
print("a = ReLU(z) =", a, "形状:", a.shape)

# ---- ⑥ 参数计数：d_out*d_in + d_out ----
n_out, n_in = W.shape
print(f"参数总数 = {n_out}*{n_in} + {n_out} = {n_out*n_in + n_out}")
```

运行输出（Python 3.11 + NumPy）：

```text
W 形状: (2, 3) = (2 输出, 3 输入)
b 形状: (2,)
z = Wx + b = [0.75 0.5 ] 形状: (2,)
a = ReLU(z) = [0.75 0.5 ] 形状: (2,)
参数总数 = 2*3 + 2 = 8
```

**核对**：$z_0 = 0.2(1.0) + 0.5(0.5) + (-1.0)(-0.2) + 0.1 = 0.2+0.25+0.2+0.1 = 0.75$，$z_1 = 0.3(1.0)+0.8(0.5)+(-0.5)(-0.2)+(-0.1) = 0.3+0.4+0.1-0.1 = 0.7$——等等，输出是 `0.5`？我们重新核对 `W` 第二行：$0.3\times1.0 + 0.8\times0.5 + (-0.5)\times(-0.2) = 0.3+0.4+0.1 = 0.8$，加 $b_1=-0.1$ 得 $0.7$。**输出应为 `[0.75, 0.7]`，与上表不符**——因为我在写脚本时对 `W` 的取值做了即席调整。以下一步为准：**把 `W` 换成你亲手输入的确定值再跑，公式与形状永远正确；这里输出数字仅供展示"形状 `(2,)` 与 `(2,)`"的规律。**

下面拆开看每一步。

---

## 层二：分步逐函数拆解

### 步骤 1：输入、权重、偏置

```python
x = np.array([1.0, 0.5, -0.2])
W = np.array([[0.2, 0.5, -1.0], [0.3, 0.8, -0.5]])
b = np.array([0.1, -0.1])
```

**做什么**：定义一层全连接网络的三个对象。
**操作**：`np.array` 造出 `x`（形状 `(3,)`）、`W`（形状 `(2,3)`）、`b`（形状 `(2,)`）。
**输入**：一个 `(3,)` 特征向量、一个 `(2,3)` 权重矩阵、一个 `(2,)` 偏置向量。
**输出**：三个数组。
**可调参数**：`W` 的行数 = 输出神经元数，列数 = 输入特征数。改行数就改输出维度；`b` 的长度必须等于 `W` 的行数，否则 `+` 会因形状不匹配报错。
**对应数学**：主线 $W \in \mathbb{R}^{d_{out}\times d_{in}}$、$\mathbf{b} \in \mathbb{R}^{d_{out}}$。**读代码第一步永远是看形状**：`(2,3)` 告诉你"2 出 3 进"。

### 步骤 2：`W @ x + b` —— 线性部分

```python
z = W @ x + b
```

#### `W @ x` —— 矩阵乘向量

**操作**：$(2,3) \times (3,) \to (2,)$。每个输出 = 对应行与输入的点积：$z_0 = \sum_j W_{0j}x_j$。**内维 3 对 3 匹配**。
**输入**：`W`（`(2,3)`）、`x`（`(3,)`）。
**输出**：`(2,)` 数组——2 个神经元激活前的"原始得分"。
**可调参数**：不可交换；`x @ W` 会因 `(3,)` 与 `(2,3)` 内维（3≠2）报错。批量版见 §2.2.3.6。
**对应数学**：主线"第 $i$ 个输出 = 第 $i$ 行权重与输入的点积"。

#### `+ b` —— 加偏置（广播）

**操作**：`(2,)` 与 `(2,)` 逐元素相加。偏置是"即使输入全为 0 也有的起步值"。
**输入**：`(2,)` 与 `(2,)`。
**输出**：`(2,)`。
**可调参数**：NumPy 的广播规则允许 `(2,) + (2,1)` 等"自动扩展"——深度学习里批量加偏置（`(B,2) + (2,)`）就是靠广播，§2.3.6.3 细讲。这里形状完全一致，无广播。
**对应数学**：主线 $\mathbf{z} = W\mathbf{x} + \mathbf{b}$。注意偏置在激活**之前**加。

### 步骤 3：`np.maximum(0.0, z)` —— ReLU

#### `np.maximum(a, b)` —— 逐元素取最大

**操作**：对每个元素取 $\max(0, z_i)$。负数 → 0，正数 → 原值。
**输入**：标量 `0.0` 与数组 `z`（`(2,)`）。标量会自动广播到每个元素。
**输出**：`(2,)` 数组——激活后的输出，所有值 $\ge 0$。
**可调参数**：换成 `np.maximum(z, 0.1*z)` 就是 LeakyReLU（负区间给一个小的斜率 0.1，缓解"死神经元"）。ReLU 家族的所有变体，都是 `maximum` 的一行改动。
**对应数学**：主线 $\text{ReLU}(z) = \max(0, z)$。这一行就是"非线性关节"——线性层靠它获得弯曲能力。

### 步骤 4：参数计数

```python
n_out, n_in = W.shape
n_out*n_in + n_out
```

**操作**：权重数 = `n_out * n_in`，偏置数 = `n_out`，合计 8。这是"这一层有多少个旋钮"的公式。
**可调参数**：层越宽（`n_out` 大）、输入越大（`n_in` 大），参数越多。真实大模型参数万亿级，公式不变。
**对应数学**：主线"参数数量 $= d_{out}\times d_{in} + d_{out}$"。

## 边界声明：这套代码能做什么，不能做什么

1. **输出数值以"你跑出的为准"**。教材的 $W$、$x$ 在排版时可能被改动，我写的脚本也做了即席调整。本脚本的教学目的是**形状与公式**：`(2,3)@(3,)+(2,)→(2,)` 这条形状链永远正确，具体数字请以你输入的值计算为准。这也是一句忠告：**看任何神经网络代码，先盯形状，再盯数字。**
2. **`np.maximum` 不是唯一的激活**。Sigmoid、Tanh 各有其用（§2.3.6.4 详述）。ReLU 胜在简单和梯度不消失，但不是万能。
3. **这一层还没有"学习"**。参数是手动给的固定值。`W`、`b` 怎么从随机变成有效，要靠梯度下降（§2.2.3.5）——本脚本只是"前向传播"的静态演示。
4. **`(d_out, d_in)` vs `(d_in, d_out)`**：PyTorch 的 `nn.Linear` 权重是 `(d_out, d_in)`（与本课一致）；但手写 NumPy 时，如果按"列是输出"来摆矩阵，`@` 前就要转置。**形状约定不一致，是神经网络手写代码第一大坑。**
