# 镜鉴：神经网络参数——权重与偏置

## 一、哲学：参数是"被写下的偏好"

权重和偏置，是人类第一次让机器**自己保存判断依据**。一个神经元的权重向量，记录着它"看重输入的哪些方面、忽略哪些"；偏置记录着它的"默认倾向"。训练的每一步，都是在重写这两样东西。

这引出一个惊人的哲学事实：**模型知道的东西，全躺在参数里。** 一个会认猫的模型，没有一行"猫的规则"，它的全部"猫知识"就是那几百万个权重——一份我们读不懂、但模型"理解"的编码。哲学上，这是"知识与表征"的老问题：知识可以不依赖语言而存在吗？神经网络用行动回答：可以——它把理解写进了数字的分布里，而不是句子里。参数，是机器用我们的数学语言写下的"世界观"。

## 二、艺术与科幻：读取一个人的"权重矩阵"

科幻设定：一台设备能读取一个人的"认知参数"——她如何看待世界、偏爱什么、恐惧什么——全部编码成权重和偏置。她的"偏见"是一条偏置向量，她的"关注点"是一组权重。

这个设定之所以震撼，是因为它把"人格"还原成了**可被调参的系统**：换掉一个权重，她的恐惧变了；把偏置清零，她不再有倾向。于是哲学难题浮现——**调整权重，是在"治疗"，还是在"改写人格"？** 现实中我们也在做类似的事：教育、说服、陪伴，都在微妙地调整别人的"权重"。区别在于，机器可以精确指出"哪个参数改了哪份信念"，而人永远说不清。或许这正是人性的神秘之处：我们的"参数"从不允许被彻底读取——被读取的那部分，就不再是人格，而是配置。

## 三、人的映射：偏置，是我们每个人看不见的"起步值"

一个神经元有偏置：即使所有输入为零，它也有一个默认输出。人也一样——我们每个人都有"偏置"：那些不依赖任何具体事件的默认倾向，天性里的底色、习惯性的反应、与生俱来的情绪起点。

有趣的是，偏置常常不被察觉。我们以为自己的反应是"输入决定的"，却忽略了那个默默加在后面的 $\mathbf{b}$。**认识自己的偏置，是这个模型最难的自我调试。** 权重告诉你"你如何加工世界"，偏置告诉你"你默认就是这样的"。心理咨询做的许多事，其实就是"检测偏置、看清偏置、决定要不要调它"。而数学早已说明：没有偏置的模型必须过原点——一个没有"自我底色"的人，也会被所有输入牵着走，失去立场。

## 四、谜镜题

这一节我们学到：$z = W\mathbf{x} + \mathbf{b}$，权重给方向、偏置给位置。

那么，请面对这个谜：

> **一台机器被训练成识别猫。研究者把它最后一层的权重矩阵拿出来，发现：一个神经元的权重向量指向"圆耳朵、胡须、竖瞳"的"特征方向"。请问——这个神经元知道什么是"猫"吗？如果不知道，是谁'知道'？**

这个谜没有答案，只有越来越深的追问。神经元只是权重 + 激活，它不"懂"猫；整个网络的参数联合起来"完成"了识别，但也没有任何单个位置"持有"猫的概念。**"理解"到底住在哪里？** 如果你说"住在参数分布里"，那参数分布和一本字典有什么区别？请写下你的答案——这个问题，深度学习还没有回答完。

## 五、大师耳语

你已看见那台机器的全部构造：一层层的权重、偏置、激活。

> "记住，权重和偏置是机器唯一的'记忆'——它记得的一切，都写在这些数字里。训练的每一秒钟，都是在改写这份记忆。**当有一天你读到某篇论文说'我们让模型学会了 X'，请在心里翻译成：'那几百万个参数，被梯度下降挪到了某个新位置。'** 这是最深也最诚实的翻译。"
