# 习题：神经网络参数——权重与偏置

## 第一组：概念检验

**1.1（单选）** 一个全连接层，输入 4 个特征、输出 3 个神经元。它的权重矩阵形状是：
- A. $(3, 4)$
- B. $(4, 3)$
- C. $(3,)$
- D. $(4, 4)$

**1.2（判断并说明）** "偏置向量 $\mathbf{b}$ 的作用是：即使输入 $\mathbf{x}$ 全为 0，输出 $\mathbf{z}$ 也能不为 0。因此偏置给每个输出提供了一个'起步值'。" 这句话对吗？为什么需要它？

**1.3（填空）** 一个完整全连接层的前向是 $\mathbf{a} = \underline{\qquad}(W\mathbf{x} + \mathbf{b})$，其中 $\underline{\qquad}$ 的作用是引入非线性；$W\mathbf{x}+\mathbf{b}$ 得到的 $\mathbf{z}$ 被称为____（激活前/激活后）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 设 $\mathbf{x} = [2, -1, 1]$，$W = \begin{bmatrix} 1 & 0 & 2 \\ -1 & 1 & 0 \end{bmatrix}$，$\mathbf{b} = [0.5, -0.5]$。手算 $\mathbf{z} = W\mathbf{x}+\mathbf{b}$，再用 NumPy 验证，并指出输出形状。

**2.2（代码验证）** 对 2.1 的 $\mathbf{z}$ 施加 ReLU，手算并验证 $\mathbf{a}$。再换 LeakyReLU（$\max(z, 0.1z)$），对比差异。

**2.3（动手理解）** 用代码把偏置 $\mathbf{b}$ 分别设为全 0 和全 1，观察同一输入下输出的变化，并解释"偏置作为平移量"的含义。

## 第三组：DL 延伸

**3.1（场景判断）** 一个模型层定义写的是 `nn.Linear(512, 256)`。它的权重形状是什么？这层有多少个参数？如果输入是形状 `(32, 512)` 的批量，输出形状是什么？

**3.2（场景分析）** 有人说："没有偏置的网络，任何输入过一层后都必须经过原点——这对分类很不利。" 请用"过原点/平移"的几何语言解释这句话，并说明为什么偏置在几何上等于'把分割超平面移离原点'。

---

## 解答与思路点拨

### 第一组

**1.1 答案：A（$(3,4)$）。**
- **思路**：权重矩阵"一行对应一个输出神经元"。3 个输出 → 3 行；4 个输入 → 4 列。所以 `(3, 4)`。
- **点拨**：记法"**行=输出、列=输入**"。PyTorch `nn.Linear(4, 3)` 的权重就是 `(3, 4)`——名字写的是 `(in, out)`，权重存的是 `(out, in)`，这个反差是高频坑。

**1.2 对。**
- **思路**：$\mathbf{z} = W\mathbf{x}+\mathbf{b}$，当 $\mathbf{x}=\mathbf{0}$ 时 $W\mathbf{0}=\mathbf{0}$，只剩 $\mathbf{z}=\mathbf{b}$。所以偏置是每个输出的"起步值"。没有偏置，输出必须过原点（$\mathbf{x}=\mathbf{0}$ 时输出恒为 0）——决策边界被迫穿过原点，分类能力受限（见 3.2）。
- **点拨**：偏置的价值是**平移**。权重决定"方向/斜率"，偏置决定"位置"。二者配合，才能让分割面放到任意位置。

**1.3 答案：ReLU（或任意激活函数）；激活函数；激活前。**
- **思路**：$\mathbf{z}=W\mathbf{x}+\mathbf{b}$ 是线性部分，激活函数 $\sigma$ 施加后得 $\mathbf{a}=\sigma(\mathbf{z})$。$\mathbf{z}$ 是激活前的原始得分，$\mathbf{a}$ 是激活后的输出。
- **点拨**：区分 $\mathbf{z}$ 与 $\mathbf{a}$ 是读论文的基本功——"pre-activation" vs "post-activation"。偏置加在激活前，顺序不能换。

### 第二组

**2.1**
$z_0 = 1\cdot2 + 0\cdot(-1) + 2\cdot1 + 0.5 = 2 + 0 + 2 + 0.5 = 4.5$；
$z_1 = (-1)\cdot2 + 1\cdot(-1) + 0\cdot1 - 0.5 = -2 - 1 + 0 - 0.5 = -3.5$。
$\mathbf{z} = [4.5, -3.5]$。

```python
import numpy as np
x = np.array([2.0, -1.0, 1.0])
W = np.array([[1.0, 0.0, 2.0], [-1.0, 1.0, 0.0]])
b = np.array([0.5, -0.5])
z = W @ x + b
print(z, z.shape)      # [ 4.5 -3.5] (2,)
```
- **思路**：按"每行点积 + 对应偏置"手算。输出形状 `(2,)` = 输出神经元数。
- **点拨**：手算时用 `z_i = Σ_j W[i,j]*x[j] + b[i]` 逐行算，不容易漏。这与"第 $i$ 行权重与输入点积"是同一件事。

**2.2**
$\mathbf{a}_{\text{ReLU}} = [\max(0,4.5), \max(0,-3.5)] = [4.5, 0]$。
$\mathbf{a}_{\text{Leaky}} = [\max(4.5, 0.45), \max(-3.5, -0.35)] = [4.5, -0.35]$。

```python
print(np.maximum(0.0, z))                # [ 4.5  0. ]
print(np.maximum(z, 0.1*z))              # [ 4.5 -0.35]
```
- **思路**：ReLU 把负的 $z_1=-3.5$ 压成 0；LeakyReLU 给负值保留 10% 的斜率（$-0.35$）。
- **点拨**：区别就在负区间。ReLU 的"死神经元"问题（负梯度恒为 0，神经元再也不更新）用 Leaky 缓解。看到 `maximum` 一行代码，就是整个 ReLU 家族。

**2.3**
```python
for bias in (np.zeros(2), np.ones(2)):
    print(W @ x + bias)
# [4.  -4. ]   （b=0：输出过原点）
# [5.  -3. ]   （b=1：整体平移 +1）
```
- **思路**：$\mathbf{b}=\mathbf{0}$ 时，若输入为 $\mathbf{0}$，输出必为 $\mathbf{0}$——映射"锁死"在过原点。$\mathbf{b}=\mathbf{1}$ 时，整个输出向量平移了 1。
- **点拨**：**偏置是"平移"**。这是 3.2 的数值预演：去掉偏置，一切线性层的分割面都必须过原点，几何自由度少一个。

### 第三组

**3.1 答案：权重形状 `(256, 512)`，参数 $256\times512 + 256 = 131328$，输出形状 `(32, 256)`。**
- **思路**：`nn.Linear(in=512, out=256)` → 权重 `(256, 512)`（行=输出，列=输入）。参数 = 权重 + 偏置 = $256\cdot512 + 256$。批量输入 `(32, 512)` 乘权重转置 → 输出 `(32, 256)`。
- **点拨**：`(32, 512) @ (512, 256) = (32, 256)`——批维保留，内维 512 对齐。这是批处理（§2.2.3.6）的形状规律，这里先混个脸熟。

**3.2 思路**
- 无偏置时，层变换是 $\mathbf{z}=W\mathbf{x}$，这是**过原点的线性变换**：$\mathbf{x}=\mathbf{0}$ 必然映射到 $\mathbf{0}$。分类器的决策边界（超平面）由权重决定，无偏置时该超平面**必过原点**。
- 如果两类数据在原点的同侧（或最佳分割面不过原点），无偏置网络就**切不出**正确的边界——它被迫用"过原点的面"去逼近，分类变差。
- 偏置 $\mathbf{b}$ 在几何上**把超平面平移离原点**：$W\mathbf{x}+\mathbf{b}=0$ 的解集是过 $-\mathbf{b}$ 相关的那个点的超平面，不再受制于原点。这就是"分割面的位置自由度"。
- **点拨**：权重给方向，偏置给位置。深度学习里"为什么 bias 不可省"的答案，就在这里。§2.3.5.3（变换）会从线性变换角度再深化：加偏置后不再是严格意义的"线性变换"，而是"仿射变换"。
