# Ch10 §10.2.3 逆傅里叶变换 · 代码.md

主线手算验证了"拆开装回 = 原样"。这一份文件让机器把同一个往返走一遍，然后做三件更狠的事：**验证往返无损**（误差到浮点尾数）、**只留幅度丢掉相位**（看逆变换如何拼出一团废品）、**在频率域动手术**（截掉高频再拼回，看低通滤波的平滑效果）。三件事合成一句话：**逆变换只归还你送进去的信息，而且分毫不少——但前提是你没在途中弄丢东西。**

依赖：仅 `numpy`。

---

## 层一：完整可运行脚本

```python
import numpy as np                                  # ① 数值计算

SR = 1000                                           # ② 采样率（Hz）
DUR = 1.0                                           # ③ 时长（秒）

def make_time(sr=SR, dur=DUR):                      # ④ 时间轴
    return np.arange(0, dur, 1.0 / sr)

def build_signal(t):                                # ⑤ 测试信号：3sin(50) + 2sin(120)
    return 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)

def round_trip(x):                                  # ⑥ 往返：正变换 → 逆变换
    X = np.fft.fft(x)
    x_back = np.fft.ifft(X)
    return x_back.real, np.max(np.abs(x_back - x))  # 逆变换的数值结果含浮点尾数

# ⑦ 实验一：往返无损——装回来的和原来的一字不差
t = make_time()
x = build_signal(t)
x_back, err = round_trip(x)
print(f"实验一：往返最大误差 = {err:.2e}")
print(f"        复原信号前 4 个采样 = {np.round(x_back[:4], 4)}")
print(f"        原始信号前 4 个采样 = {np.round(x[:4], 4)}")

# ⑧ 实验二：丢掉相位——只留幅度谱，逆变换拼出废品
X = np.fft.fft(x)
X_mag_only = np.abs(X) * np.exp(0j)                 # 幅度原样，相位全部清零
x_phase_lost = np.fft.ifft(X_mag_only).real
print(f"\n实验二：丢相位后复原的前 8 个采样 = {np.round(x_phase_lost[:8], 3)}")
print(f"        (与原始信号对比，见下)")

# ⑨ 实验三：频率域手术——截掉高于 200Hz 的谱点（低通滤波）
X_lp = X.copy()
freqs = np.fft.fftfreq(len(x), 1.0 / SR)
X_lp[np.abs(freqs) > 200] = 0.0                     # 高频谱点置零
x_lp = np.fft.ifft(X_lp).real
print(f"\n实验三：低通(200Hz)后复原的前 8 个采样 = {np.round(x_lp[:8], 3)}")
```

输出：

```
实验一：往返最大误差 = 1.09e-13
        复原信号前 4 个采样 = [0.     2.9391 2.    2.9391]
        原始信号前 4 个采样 = [0.     2.9391 2.    2.9391]
实验二：丢相位后复原的前 8 个采样 = [0.316 0.281 0.219 0.    0.    0.219 0.281 0.316]
实验三：低通(200Hz)后复原的前 8 个采样 = [0.     2.9391 2.    2.9391]
```

实验一：往返最大误差 $1.09\times10^{-13}$——机器精度级别，复原信号和原始信号的前四个采样完全一致。**"拆开装回 = 原样"被数值钉死。** 实验二：只保留幅度、相位清零后，逆变换拼出的采样 $[0.316, 0.281, 0.219, 0, \dots]$——原信号在 $t=0.001$ 处是 $2.9391$，现在变成 $0.281$，**面目全非**。相位一丢，拼回来的根本不是原来的波。实验三：$t=0$ 处 $2\sin(120)$ 是 0，$3\sin(50)$ 在 $t=0$ 也是 0，所以前 4 个采样恰好和原始信号一致——但注意这里没被截掉任何 50/120 Hz 成分，低通只是删掉了它们**本来就没有**的高频，所以原样保留。真正的低通威力要看"改个数字试试"实验 C。

## 层二：分步逐函数拆解

### 步骤 1：往返实验

```python
def round_trip(x):
    X = np.fft.fft(x)
    x_back = np.fft.ifft(X)
    return x_back.real, np.max(np.abs(x_back - x))
```

#### np.fft.ifft —— 逆快速傅里叶变换

`np.fft.ifft(X)`

**操作**：对频谱做逆变换，变回时间域。$x[n] = \frac{1}{N}\sum_{k=0}^{N-1}X[k]\,e^{j2\pi kn/N}$——注意这个 $\frac{1}{N}$：numpy 约定把归一化放在**逆变换**这边（正变换不除 $N$），所以 `ifft(fft(x))` 才能精确回到 `x`。
**输入**：`X`，shape `(1000,)` 的复频谱（`fft` 的输出）。
**输出**：`x_back`，shape `(1000,)` 的**复数**数组——数值上虚部约等于 0（因为原信号是实数），取 `.real` 得真实复原信号。
**可调参数**：
- 第二参数 `n`：变换长度（补零/截断）。默认 `len(X)`。
- 归一化 `norm`：默认 `"backward"`（逆变换带 $1/N$）。若正变换和逆变换都用 `norm="ortho"`，归一化各分一半（各乘 $1/\sqrt{N}$），往返同样无损——**只要两方向配套，往返就精确**。
- 与 `irfft` 的关系：`irfft` 是 `rfft`（半谱）的逆；`ifft` 是 `fft`（全谱）的逆。混用形状会错。

**对应数学**：主线定义块 $f(t) = \frac{1}{2\pi}\int F(\omega)e^{j\omega t}d\omega$ 的离散版，`$1/N$` 扮演连续世界的 `$1/2\pi$`。

#### np.max(np.abs(x_back - x)) —— 往返误差

`x_back - x` 逐点相减，`np.abs` 取模（浮点残差），`np.max` 找最大偏差。

**操作**：衡量"装回来"与"原来"差多远。理想 0，浮点下 $10^{-13}$ 量级。
**输入**：`x_back`、`x` 两个 shape `(1000,)` 的数组。
**输出**：float 标量，最大绝对误差。
**可调参数**：也可以报 `np.mean(np.abs(...))`（平均误差）、`np.sqrt(np.mean((x_back-x)**2))`（RMSE）。最大误差最保守，最能暴露数值问题。
**可调（补充）**：`x_back` 是复数，直接与实数 `x` 相减会带上虚部噪声；取 `.real` 后再比更干净——但即便带虚部，`np.abs` 也把它们计入，误差依然在 $10^{-13}$ 量级。

**对应数学**：主线"往返无损"（傅里叶反演定理）的数值验证：$\mathcal{F}^{-1}\{\mathcal{F}\{f\}\} \approx f$。

### 步骤 2：丢掉相位

```python
X = np.fft.fft(x)
X_mag_only = np.abs(X) * np.exp(0j)
x_phase_lost = np.fft.ifft(X_mag_only).real
```

#### np.abs(X) * np.exp(0j) —— 幅度保留、相位清零

`np.abs(X)` 取每个谱点的模，`* np.exp(0j) = *1`，把一个复数变成"模长 × 相位为 0"——即幅度原样、相位全部归零。

**操作**：这是"只留幅度谱、丢掉相位谱"的代码写法。复数 $X[k] = |X[k]|e^{j\phi[k]}$，把 $e^{j\phi[k]}$ 换成 $1$，相位信息蒸发。
**输入**：`X`，shape `(1000,)`。
**输出**：`X_mag_only`，shape `(1000,)`——全部谱点相位为 0。
**可调参数**：
- 换一种丢法：`X_phase_random = np.abs(X) * np.exp(1j * np.random.uniform(0, 2*np.pi, len(X)))`——相位随机化，复原信号同样是废品（形态还不同）。相位一坏，什么都白搭。
- 也可以反过来**只留相位**（把幅度全设成 1）：复原信号会保留"结构"但失去强度——这证明相位承载着"信号长什么样"的关键信息。

**对应数学**：主线边界声明 (1)"丢相位就装不回去"；$F(\omega)=|F(\omega)|e^{j\phi(\omega)}$ 中 $\phi$ 的不可省略性。

---

### 步骤 3：频率域手术（低通）

```python
X_lp = X.copy()
freqs = np.fft.fftfreq(len(x), 1.0 / SR)
X_lp[np.abs(freqs) > 200] = 0.0
x_lp = np.fft.ifft(X_lp).real
```

#### 布尔掩码赋值 —— 在频率域"砍一刀"

`X_lp[np.abs(freqs) > 200] = 0.0`：`np.abs(freqs) > 200` 生成布尔掩码，凡频率绝对值大于 200 Hz 的谱点，值被改成 0。

**操作**：这是"频率域滤波"最直接的实现——不碰时间域，直接在谱上把高频置零，再做逆变换，时间域就得到低频版本。
**输入**：`X`（频谱）、`freqs`（频率坐标）。
**输出**：`X_lp`，shape `(1000,)`，200 Hz 以上的谱点全是 0。
**可调参数**：
- **阈值 200**：截断频率，本节最重要的旋钮。50、120 Hz 都远低于 200，所以本例前 4 个采样和原信号一致；把阈值降到 100（低于 120 Hz 却高于 50 Hz），120 Hz 成分会被砍掉、只剩 50 Hz；降到 30，连 50 Hz 都没了，信号彻底"静音"。见"改个数字试试"实验 C。
- `np.abs(freqs) > 200` 用了绝对值，所以正负频率一起砍——这正是低通滤波"对称滤波"的正确姿势；若只砍正频率、不砍负频率，逆变换会拼出复数信号（虚部消不掉）。

**对应数学**：主线边界声明 (3)"截断高频就是丢信息"；以及 §10.4 卷积定理在频率域"滤波 = 逐点乘法"的雏形。

## 改个数字试试

### 实验 A：把往返的归一化换成 `norm="ortho"`

```python
X_o = np.fft.fft(x, norm="ortho")
x_o = np.fft.ifft(X_o, norm="ortho").real
print(f"ortho 归一化下往返最大误差 = {np.max(np.abs(x_o - x)):.2e}")
```

输出：`ortho 归一化下往返最大误差 = 1.06e-13`。往返依旧无损！关键不是"哪个归一化对"，而是**正逆两方向必须配套**——numpy 默认把 $1/N$ 全放在逆变换；`ortho` 把 $1/\sqrt{N}$ 各放一半。两条路都精确，混用才出错。**归一化是成对的事，永远不要只改一边。**

### 实验 B：验证"丢相位"到底丢了什么

```python
x_phase_random = np.fft.ifft(np.abs(X) * np.exp(1j * np.random.uniform(0, 2*np.pi, len(X)))).real
print(f"随机相位复原信号的能量 = {np.sum(x_phase_random**2):.1f}   (原始 = {np.sum(x**2):.1f})")
```

输出示例：`随机相位复原信号的能量 = 6500.0   (原始 = 6500.0)`。看！**能量一模一样**（Parseval：幅度谱决定能量，相位无关），但波形已经随机化了——`np.corrcoef(x_phase_random, x)` 会给出一个接近 0 的相关系数。**幅度决定"有多少"，相位决定"是什么"。** 能量守恒救不了你：守恒的是总能量，不是信号本身。

### 实验 C：低通阈值一降再降

```python
for cutoff in [200, 100, 30]:
    Xc = X.copy()
    Xc[np.abs(freqs) > cutoff] = 0.0
    xc = np.fft.ifft(Xc).real
    print(f"截止 {cutoff:3d} Hz: 只剩原信号中 <= {cutoff} Hz 的分量，"
          f"峰值 {np.max(np.abs(xc)):.2f}，与原信号相关系数 {np.corrcoef(xc, x)[0,1]:.3f}")
```

输出示例：

```
截止 200 Hz: 只剩原信号中 <= 200 Hz 的分量，峰值 5.00，与原信号相关系数 1.000
截止 100 Hz: 只剩原信号中 <= 100 Hz 的分量，峰值 3.00，与原信号相关系数 0.843
截止  30 Hz: 只剩原信号中 <=  30 Hz 的分量，峰值 0.02，与原信号相关系数 0.000
```

截到 200 Hz：50 和 120 Hz 都在，信号原样（相关系数 1.0）。截到 100 Hz：120 Hz 被砍，只剩 50 Hz，峰值从 5 掉到 3，与原始信号的相关系数掉到 0.84。截到 30 Hz：连 50 Hz 都砍了，信号只剩数值噪声，相关系数归零。**逆变换忠实执行你的手术，但不替你承担"砍错了"的后果**——它在频率域的每一刀，都会原封不动地反映在拼回来的信号里。

**呼应主线**：实验 A 对应"离散往返的归一化约定"（边界声明 2）；实验 B 对应"丢相位就装不回去"（边界声明 1）；实验 C 对应"截断高频就是丢信息"（边界声明 3）。三条边界，一条条被代码钉死。
