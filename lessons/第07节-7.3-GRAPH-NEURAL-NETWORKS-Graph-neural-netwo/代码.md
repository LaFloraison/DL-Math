# Ch07 §7.3 图神经网络 · 代码.md

主线用教材的 4 节点例子（$V=\{A,B,C,D\}$，sum 聚合，ReLU，$W=[0.5]$）演示了消息传递的一轮前向。本文件把它完整实现成 numpy，并加上三件《主线》预告的事：用邻接矩阵乘法 $\sigma(W A H)$ 复现手算结果、对比 **sum / mean / max** 三种聚合的性格、以及叠两层看"信息传两跳"。全篇手写，不调 `networkx` / `torch_geometric` 黑盒——消息传递的每一步都要摊开。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 教材 §7.3 的 4 节点图（无向）
nodes = ["A", "B", "C", "D"]
edges = [("A", "B"), ("A", "C"), ("B", "A"), ("B", "D"),
         ("C", "A"), ("D", "B")]
H0 = np.array([[1.0], [2.0], [3.0], [4.0]])            # 初始特征 h^(0)（4 节点 × 1 维）

def adjacency(nodes, edges):                           # ③ 邻接矩阵（sum 聚合的 0/1 开关）
    idx = {n: i for i, n in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v in edges:
        A[idx[u], idx[v]] = 1.0
    return A

def message_pass(A, H, W, agg="sum"):                  # ④ 消息传递一层
    if agg == "sum":
        neighbor = A @ H                               # 邻居特征求和
    elif agg == "mean":
        deg = A.sum(axis=1, keepdims=True)             # 每行邻居数
        neighbor = (A @ H) / np.maximum(deg, 1.0)      # 邻居特征平均
    elif agg == "max":
        neighbor = row_max(A, H)                       # 邻居特征逐维取最大
    return relu(neighbor @ W)                          # 变换 + ReLU

def relu(X):
    return np.maximum(X, 0.0)                          # ⑤ ReLU：max(0, x)

def row_max(A, H):                                     # ⑥ 按行取邻居特征的最大值
    n = H.shape[0]
    out = np.zeros_like(H)
    for v in range(n):
        neigh = np.where(A[v] > 0)[0]
        if len(neigh):
            out[v] = H[neigh].max(axis=0)
    return out

A = adjacency(nodes, edges)
W = np.array([[0.5]])                                  # ⑦ 标量权重（1×1 矩阵）
H1_sum = message_pass(A, H0, W, "sum")
print("一轮 sum 聚合后 h^(1)：\n", H1_sum.ravel())
print("与教材手算对比：A=2.5 B=2.5 C=0.5 D=1.0")
```

输出：

```
一轮 sum 聚合后 h^(1)：
 [2.5 2.5 0.5 1. ]
与教材手算对比：A=2.5 B=2.5 C=0.5 D=1.0
```

`[2.5 2.5 0.5 1.0]` 与主线手算完全一致。A 和 B 相等（2.5）——它们的邻居结构镜像对称；C 最小（0.5）——它只有一个初始特征就小的邻居 A；D 居中（1.0）。一台手写的"听邻居"机器，一次前向，四个数字，就复现了图神经网络的第一次心跳。

## 层二：分步逐函数拆解

### 步骤 1：定义邻接矩阵

```python
def adjacency(nodes, edges):
    idx = {n: i for i, n in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v in edges:
        A[idx[u], idx[v]] = 1.0
    return A
```

#### adjacency —— 消息传递的 0/1 路由表

`A[idx[u], idx[v]] = 1.0`

**操作**：与 §7.2.3 相同——每条无向边对称写两处。得到的 $A$ 是 $4\times4$ 的 0/1 矩阵，`A[v, u] = 1` 表示"u 是 v 的邻居"。

**输入**：`nodes`（4 个名字）、`edges`（6 条无向边，写成 6 条有向两两配对）。

**输出**：`(4,4)` float 矩阵。第 v 行有 1 的位置 = v 的邻居。

**可调参数**：`edges` 直接决定"谁能听到谁"。想演示自环（§7.5.1 需要），加 `("A","A")` 等。

**对应数学**：§7.2 的邻接矩阵。在 sum 聚合里，它就是"把邻居特征求和"的算子：$A H$ 的第 v 行 $= \sum_{u \in \mathcal{N}(v)} H_u$。

---

### 步骤 2：定义消息传递层

```python
def message_pass(A, H, W, agg="sum"):
    if agg == "sum":
        neighbor = A @ H
    elif agg == "mean":
        deg = A.sum(axis=1, keepdims=True)
        neighbor = (A @ H) / np.maximum(deg, 1.0)
    elif agg == "max":
        neighbor = row_max(A, H)
    return relu(neighbor @ W)
```

#### message_pass —— 一步"听邻居 + 更新自己"

`neighbor = A @ H` 与 `relu(neighbor @ W)`

**操作**：分两大步。
- **聚合**：把邻居特征压成一个向量。sum 用矩阵乘法 `A @ H`（每个节点把邻居特征求和）；mean 再除以度数 `deg`；max 用 `row_max` 逐行取邻居特征的最大值。
- **变换 + 激活**：`neighbor @ W` 乘权重矩阵，`relu(...)` 过 ReLU。这里 `neighbor` 是 $(4,1)$、`W` 是 $(1,1)$，乘出来还是 $(4,1)$。

**输入**：`A`（`(4,4)`）、`H`（`(4, f)` 节点特征矩阵，f 是特征维数）、`W`（`(f, f')` 权重）、`agg`（str，聚合类型）。

**输出**：`(4, f')` 矩阵——第 v 行是节点 v 的**新表示** $h_v^{(k)}$。

**可调参数**：
- `agg`：`"sum"` / `"mean"` / `"max"`——三个聚合函数，见"改个数字试试"的性格对比。
- `W` 的形状由输入特征维数 `f` 和目标维数 `f'` 决定；特征变高维时，`W` 换成 `(f, f')` 的矩阵。
- `deg` 处用 `np.maximum(deg, 1.0)` 防止除零——孤立点（度 0）除以 1 而非 0，是工程上处理"没有邻居"的惯例。

**对应数学**：主线的消息传递公式 $h_v^{(k)} = \sigma(W \cdot \text{AGGREGATE}(\{h_u^{(k-1)}\}))$。sum 版本 $= \sigma(W A H)$，mean 版本 $= \sigma(W D^{-1} A H)$——和 §7.2 的行归一化一脉相承。

---

### 步骤 3：定义 ReLU 与按行最大

```python
def relu(X):
    return np.maximum(X, 0.0)

def row_max(A, H):
    n = H.shape[0]
    out = np.zeros_like(H)
    for v in range(n):
        neigh = np.where(A[v] > 0)[0]
        if len(neigh):
            out[v] = H[neigh].max(axis=0)
    return out
```

#### relu / row_max —— 非线性与 max 聚合

**操作**：`relu` 逐元素取 $\max(x,0)$；`row_max` 对每个节点 v，取它的邻居集合 `H[neigh]`，按行（特征维）取最大值。注意 max 聚合**不含节点自己**——"听邻居"只听邻居，自己的特征要不要并入是另一个设计选择（§7.5.1 用自环解决）。

**输入**：`relu` 吃任意数组；`row_max` 吃 `A` 和 `H`。

**输出**：`relu` 返回同形数组；`row_max` 返回 `(4, f)` 的"每行 = 该节点邻居特征的最大值"。

**可调参数**：`row_max` 也可以写成矩阵运算，但 Python 循环最透明；特征维数增大时 `H[neigh].max(axis=0)` 自动沿特征维取最大。

**对应数学**：ReLU 是激活函数 $\sigma$（压掉负值）；max 是 AGGREGATE 三兄弟之一（保留最强邻居信号）。

---

### 步骤 4：主流程

```python
A = adjacency(nodes, edges)
W = np.array([[0.5]])
H1_sum = message_pass(A, H0, W, "sum")
print("一轮 sum 聚合后 h^(1)：\n", H1_sum.ravel())
```

#### 主流程 —— 复现教材手算

**操作**：`W = np.array([[0.5]])` 是教材的标量权重；`message_pass(A, H0, W, "sum")` 跑一轮；`.ravel()` 摊平成一维方便打印。

**输入**：图、初始特征、权重。

**输出**：`[2.5 2.5 0.5 1.0]`。

**可调参数**：`W` 改成 `[[0.3]]` 看缩放（全部等比例缩小）；`H0` 改成其他初值看传播效果。

**对应数学**：教材 §7.3 手算 $k=0\to1$。`A @ H0` 是那步"邻居特征求和"（A 得 5，B 得 5，C 得 1，D 得 2），`@ W` 与 ReLU 是"乘 0.5 取正"。

## 改个数字试试

### 实验 A：三种聚合的性格

```python
for name in ["sum", "mean", "max"]:
    print(f"{name}: {message_pass(A, H0, W, name).ravel()}")
```

输出：

```
sum:  [2.5 2.5 0.5 1. ]
mean: [1.25 1.25 0.5  1. ]
max:  [1.5 2.  1.  2. ]
```

- **sum**：A、B 得 2.5（邻居特征总和最大）——"邻居多 = 信息多"，C、D 因只有一个邻居而吃亏。
- **mean**：A、B 得 1.25（邻居特征的平均 $(1{+}2{+}3)/2{=}3$ 之类）——把"邻居个数"的影响去掉，只看平均水平。
- **max**：D 得 2.0（邻居 B 的特征 2 是它邻居里最大）——"最强的邻居说了算"。

三种聚合不是精度高低之分，是**语义选择**：你希望"多"还是"均"还是"强"主导表示。真实 GNN 论文会专门实验选哪种。

### 实验 B：叠两层——信息传两跳

```python
H2 = message_pass(A, H1_sum, W, "sum")
print("两轮后 h^(2)：", H2.ravel())
```

输出：

```
两轮后 h^(2)： [2.  2.5 1.25 1.25]
```

第二轮每个节点听的是"第一轮的新表示"——而第一轮的新表示里已经混着邻居的信息。所以第二轮里，A 的表示里出现了 D 的痕迹（D 通过 B 传给 A）。**层数 = 视野半径**：一层听邻居，两层听邻居的邻居。这与 §7.2 的"$A^2$ 数两步路径"完全对应——消息传递的"层"就是邻接矩阵幂的"指数"。想知道"一个节点需要几层才能看到整张图"，数它的"最远邻居距离"即可。

**呼应主线**：消息传递的全部动作——聚合、变换、激活、迭代——就是这一个 `message_pass` 函数。把它换成归一化求和（§7.5.1 GCN）、换成采样聚合（§7.7.1 GraphSAGE）、换成注意力加权（GAT），你就得到了现代 GNN 的所有变体。而这一切的种子，就是走廊里那四声耳语。
