# §7.3 图神经网络 —— 习题

主线讲了消息传递的三步：聚合邻居、线性变换、非线性激活，以及 sum/mean/max 三种聚合的性格。下面三组习题让你把这台"听邻居"的机器玩熟。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：消息传递里，AGGREGATE（聚合函数）的作用是什么？

- A. 把节点映射到高维空间
- B. 把数量不定的邻居特征"压"成一个固定长度的向量
- C. 计算损失
- D. 给每条边加权重

**解答**：B。

**思路点拨**：图的"不规整"就体现在每个节点邻居数不同——AGGREGATE 负责把"任意多个邻居"压缩成"一个向量"（求和/平均/最大值），这是 GNN 能处理不规整图的根本。A 是 $W$ 的活，D 是注意力/权重的活。常见错选 A，把"变换"和"聚合"混为一谈——聚合发生在变换之前、解决的是"数量不定"问题。

### 题 2（简答）：为什么消息传递对节点的"顺序"不敏感？

**解答**：AGGREGATE（sum/mean/max）是**排列不变**的——交换邻居的先后顺序，求和、平均、最大值都不变。所以无论你给节点怎么编号、邻居怎么排序，聚合结果相同。这保证了：同一个图，不管用哪种方式表示（节点重新编号），GNN 的输出不变。

**思路点拨**：这是 GNN 与普通神经网络的关键区别——普通 MLP 吃固定顺序的向量，打乱顺序输出就变；GNN 靠排列不变的聚合函数，天然对节点乱序免疫。试金石：sum 对 {1,2,3} 和 {3,2,1} 结果一样。常见错误是只回答"因为聚合"，没点明"排列不变性"这个术语和意义。

### 题 3（判断）：GNN 的层数越多越好吗？

**解答**：不是。层数 = 视野半径，但也带来"过度平滑"：层数过多，每个节点的表示都被反复平均，最终所有节点趋于相同，节点失去区分度。此外层数增加参数量与计算量。现实里 2–4 层最常见，超过后性能往往不升反降。

**思路点拨**：这是主线边界声明的考点。答题要答出"过度平滑"这个术语。常见错误是觉得"更深=更强"——那是 CNN 的直觉，GNN 里层数有上限，因为平均化会抹平个体差异。

## 二、计算实践

### 题 1（手算 + NumPy：三节点的消息传递）

图 $V=\{X,Y,Z\}$，$X$ 与 $Y$、$Z$ 相邻，$Y$ 与 $Z$ 相邻（三角形）。初始特征 $h_X^{(0)}=[2], h_Y^{(0)}=[4], h_Z^{(0)}=[6]$。用 sum 聚合、$W=[1.0]$、ReLU，手算一轮 $h^{(1)}$。

**解答**：
- $\text{AGG}_X = h_Y + h_Z = 4 + 6 = 10$，$h_X^{(1)} = \max(0, 1.0 \times 10) = 10$
- $\text{AGG}_Y = h_X + h_Z = 2 + 6 = 8$，$h_Y^{(1)} = 8$
- $\text{AGG}_Z = h_X + h_Y = 2 + 4 = 6$，$h_Z^{(1)} = 6$

**NumPy 验证**：
```python
import numpy as np
A = np.array([[0,1,1],[1,0,1],[1,1,0]], dtype=float)
H0 = np.array([[2.],[4.],[6.]])
H1 = np.maximum((A @ H0) @ np.array([[1.0]]), 0.0)
print("h^(1) =", H1.ravel())      # [10. 8. 6.]
```
```
h^(1) = [10.  8.  6.]
```

**思路点拨**：注意"每个节点的聚合只算邻居、不算自己"——X 的聚合是 4+6，不含自己的 2。这是消息传递的默认约定（要含自己得加自环）。三角形里每个人听到的邻居特征和不同，因为初始特征不同——**聚合忠实传达了邻居的差异**。手算顺序：先各自聚合，再乘 W，再 ReLU。

### 题 2（手算：mean 聚合）

沿用题 1，改用 mean 聚合，手算 $h^{(1)}$。X、Y、Z 各得到什么？与 sum 的结果比，mean 改变了什么？

**解答**：mean 聚合 = 邻居特征的平均。
- $h_X^{(1)} = \max(0, (4+6)/2) = 5$
- $h_Y^{(1)} = \max(0, (2+6)/2) = 4$
- $h_Z^{(1)} = \max(0, (2+4)/2) = 3$

对比 sum 的 [10, 8, 6]：sum 放大总量（X 邻居总和最大），mean 只看平均水平。三角形里大家邻居数相同，mean 只是把 sum 除以 2——但在**度数不等的图**里两者会给出不同排序：一个只有 1 个强邻居的节点，mean 很高、sum 很低。**当"邻居多 ≠ 信息多"时，用 mean 更公平。**

**思路点拨**：这道题的训练价值在"理解聚合语义影响结果"。当图里度数悬殊时，sum 天然偏向大 V（邻居多则和大），mean 保持尺度中性。真实 GNN 的选择依据：任务是否希望"度数越大表示越强"。

## 三、DL 延伸

### 题 1（场景设计）：社交网络节点分类——选哪种聚合？

一个社交网络，要判断每个用户是不是"垃圾账号"（spammer）。已知：spammer 往往关注大量用户（出度高），但被关注很少（入度低）。你打算用 GNN 做节点分类。请问：这里选 sum 还是 mean 聚合更合理？为什么？再考虑：如果不看度数，光看"邻居的平均特征"，能区分 spammer 吗？

**解答**：这取决于"你要什么信息"。若要区分"关注量巨大"这个信号，**sum** 保留总量（出度大 → 聚合总和巨大 → 特征突出）；**mean** 会把大 V 和普通用户拉到同一尺度，spammer 的"关注量巨大"就被平均掉了。但反过来，mean 对"邻居平均质量"更敏感——如果 spammer 的邻居普遍是垃圾号，mean 聚合能捕捉"你身边的人都是什么样"。所以更稳妥的做法是**两者结合**：sum 捕捉数量（关注量）、mean 捕捉质量（邻居平均）。光看 mean 能区分"邻居平均质量"层面的 spammer，但区分不了"纯粹靠数量刷存在"的 spammer。

**思路点拨**：答题核心是"聚合语义 = 你要的信号"。sum 保留度数信号，mean 消除度数偏置。加分点是提出"多聚合拼接"（concat sum & mean）——现代 GNN 常这么做。常见错误是只答"选 sum"或"选 mean"而不说清为什么。

### 题 2（概念连线）：为什么层数对应"视野半径"？

一个 GNN 有 2 层。节点 A 想"听到"距离 3 跳的节点 D 的信息，能听到吗？用消息传递的迭代机制解释，并联系 $A^2$。

**解答**：不能（仅凭 2 层）。第 1 层每个节点聚合直接邻居（1 跳）；第 2 层聚合"第 1 层的邻居表示"，而它们已含各自 1 跳信息——所以第 2 层结束时，节点含 2 跳内信息。D 在 3 跳外，需要至少 3 层。这与 §7.2 的"$A^2$ 数两步路径"对应：$K$ 层消息传递的传播范围 = $A^K$ 覆盖的连接半径。

**思路点拨**：这是把"层"与"跳"接起来的核心。常见错误是答"能听到，因为信息可以传"，漏了层数的上限。用 $A^K$ 类比是加分点。这也预告了 §7.6 的挑战：真实网络直径很大，而 GNN 层数有限——"远处信息传不过来"正是 GNN 的结构性局限之一。
