## 第一步：Toy Model —— 走廊里的四声耳语

一栋楼的四个房间：A、B、C、D。A 与 B、C 相邻；B 与 A、D 相邻；C 只与 A 相邻；D 只与 B 相邻。每间房里住着一个人，每个人心里有一个数：A 的数是 1，B 是 2，C 是 3，D 是 4。

现在响起一阵广播："请每间房的人，把自己房间的数字和所有邻居房间的数字加在一起，再把这个和乘以 0.5，然后……如果结果小于 0，就当作 0。把你得到的数写在门外的白板上。"

你动手算：

- A 的邻居是 B 和 C：$1 + 2 + 3 = 6$，$\times 0.5 = 3$，白板上写 **3**。
- B 的邻居是 A 和 D：$2 + 1 + 4 = 7$，$\times 0.5 = 3.5$，写 **3.5**。
- C 的邻居只有 A：$3 + 1 = 4$，$\times 0.5 = 2$，写 **2**。
- D 的邻居只有 B：$4 + 2 = 6$，$\times 0.5 = 3$，写 **3**。

这一轮做完，你发现一件惊人的事：**每个人白板上的数，已经不再是"自己的数"，而是"自己 + 邻居"的某种浓缩。** A 的 3 里混着 B 和 C 的信息；B 的 3.5 里混着 A 和 D。你从没离开过自己的房间，却知道了邻居的处境——因为你听了他们的耳语。

如果再广播一轮，大家会拿白板上的新数去和邻居的新数相加——第二轮结束后，A 的数里将混进 D 的信息（因为 D 通过 B 传了过来）。**声音每传一轮，就多蔓延一跳。** 传到第三轮，每个房间都能听到整栋楼的动静。

这个"听邻居 + 更新自己"的循环，就是图神经网络 (GNN) 的全部灵魂。它有一个正式名字：**消息传递 (message passing)** 或**邻居聚合 (neighborhood aggregation)**。你刚才在走廊里做的那道算术题，是一台四节点、一轮消息传递的 GNN 前向传播。

## 第二步：正式数学讲解

### 一、撞墙：神经网络怎么"看见"不规整的图？

前几节学的图是数学对象，但深度学习要的是**可微分的函数**——输入张量，输出预测，梯度反传。图有两个地方和"标准输入"作对：

**第一，图没有固定形状。** 图片是 $H \times W \times C$ 的规则网格，序列是 $T \times D$ 的规则序列；图的每个节点邻居数都不同——C 有 1 个邻居，B 有 3 个。你没法把图直接塞进 CNN 的卷积核（核假设邻域形状固定）。

**第二，节点的"顺序"没有意义。** 一张图就是一张图，你把节点重新编号，图没变；可神经网络是吃向量/矩阵的，节点一旦编成矩阵的行，顺序就固化了——换个顺序，同一个图得到不同的表示，这是模型不能接受的。

你撞墙了：**图的结构是"大小不齐、顺序无关"的，而神经网络只会处理"大小齐整、顺序固定"的张量。** 要破墙，需要一种既尊重"邻居各不相同"，又对"节点乱序"不敏感的操作。

### 二、破墙：消息传递——为不规整量身定做的层

走廊实验已经演示了破解思路。每个节点做的事，不依赖任何"全局形状"，只依赖"我的邻居是谁"：

> **图神经网络层 / 消息传递 (Message Passing)** $h_v^{(k)} = \sigma\!\Big(W \cdot \text{AGGREGATE}\big(\{h_u^{(k-1)} : u \in \mathcal{N}(v)\}\big)\Big)$
>
> - $h_v^{(k)}$：节点 $v$ 在第 $k$ 层的表示（特征向量）。
> - $\mathcal{N}(v)$：$v$ 的邻居集合（§7.2 定义的"直接相连"）。
> - $\text{AGGREGATE}$：**聚合函数**，把邻居们 $h_u^{(k-1)}$ 压成一个向量——常用 **sum（求和）/ mean（平均）/ max（取最大）**。
> - $W$：**可学习的权重矩阵**（全节点共享）。
> - $\sigma$：非线性激活函数，如 ReLU：$\sigma(x) = \max(0, x)$。

这个公式把"听邻居 + 更新自己"写成了数学。拆开看三步：
1. **聚合**：$\{h_u^{(k-1)} : u \in \mathcal{N}(v)\}$ 是邻居们上一层的表示，`AGGREGATE` 把它们合并成一个（求和/平均/最大值——因为邻居数不定，必须"压"成固定长度）；
2. **变换**：乘以 $W$（学习缩放与旋转），再经过 $\sigma$（非线性）；
3. **迭代**：$k$ 从 0 到 $K$，重复 $K$ 轮——**第 $k$ 轮之后，节点含 $k$ 跳内的信息**（走廊实验：第 1 轮听到邻居，第 2 轮听到邻居的邻居）。

关键的性质是**排列不变性**：`sum`、`mean`、`max` 对邻居的顺序不敏感——你先把 B 加进来还是先把 C 加进来，结果一样。这一步从数学上解决了"节点乱序"的墙。

### 三、把教材的 4 节点例子走一遍

教材 §7.3 的例子正是走廊实验：$V=\{A,B,C,D\}$，$N(A)=\{B,C\}$、$N(B)=\{A,D\}$、$N(C)=\{A\}$、$N(D)=\{B\}$，初始特征 $h_A^{(0)}=[1], h_B^{(0)}=[2], h_C^{(0)}=[3], h_D^{(0)}=[4]$，AGGREGATE = sum，$\sigma$ = ReLU，$W=[0.5]$（标量）。做 $k=0 \to 1$ 一轮：

**第一步：聚合**（把邻居特征求和）：
- $\text{AGG}_A = h_B + h_C = 2 + 3 = 5$
- $\text{AGG}_B = h_A + h_D = 1 + 4 = 5$
- $\text{AGG}_C = h_A = 1$
- $\text{AGG}_D = h_B = 2$

**第二步：变换 + 激活**（乘 $W$，过 ReLU）：
- $h_A^{(1)} = \max(0, 0.5 \times 5) = 2.5$
- $h_B^{(1)} = \max(0, 0.5 \times 5) = 2.5$
- $h_C^{(1)} = \max(0, 0.5 \times 1) = 0.5$
- $h_D^{(1)} = \max(0, 0.5 \times 2) = 1.0$

注意三个细节，它们全是"结构"在起作用：
- **A 和 B 的新表示相同（都 2.5）**。为什么？它们的邻居结构镜像对称：A 的邻居 {B,C} 特征和 = 5，B 的邻居 {A,D} 特征和 = 5。**结构对称的节点，被图神经网络"看成一样"**——这正是"图即信息"的体现。
- **C 的表示最小（0.5）**。C 只有一个邻居 A，而 A 的初始特征就小。**低连接 + 弱邻居 = 低表示**。
- **D 的表示 1.0**。D 只有邻居 B，但 B 初始特征 2，所以 D 得到了 B 的"恩泽"。

如果把这两轮看成一次学习：这一层的 $W=0.5$ 是"给定的"，真实训练里 $W$ 会由反向传播从数据里学。**$W$ 决定"邻居信息放大还是衰减"**——训练的过程，就是让每个"应该重要"的邻居关系在 $W$ 里获得更大的权重。

### 四、聚合三兄弟：sum / mean / max

AGGREGATE 的选择不是细节，它决定了 GNN 的"性格"：

- **sum（求和）**：保留"总量"——一个节点 10 个微弱邻居与 1 个强烈邻居，求和会偏爱前者。适合"邻居多 = 信息多"的场景。
- **mean（平均）**：保留"平均水平"——对度数不敏感，适合"邻居多少不该影响表示尺度"的场景（社交网络里大 V 和小透明都只代表自己）。
- **max（取最大）**：保留"最强信号"——只留邻居里最突出的那个，适合"某个关键邻居说了算"的场景。

**边界声明**：消息传递不是万能的。第一，**它的"视野"受层数限制**——$K$ 层只能看到 $K$ 跳内的信息，社区级、全局级结构需要更多层或特殊设计（§7.6）；第二，**层数不能无限加深**——层多了所有节点表示趋同（过度平滑 over-smoothing），节点失去区分度；第三，**聚合是"平均化"**——如果邻居信息本来就很杂（§7.2.3.3 习题里"到处是桥"的图），聚合会把节点特征稀释成噪声。GNN 不解决"邻居没有信息"的问题，它只负责把邻居的信息忠实地传进来。

### 五、与经典图算法的关系

消息传递不是凭空发明，它和经典图算法同源：

- **"一步聚合" ≈ 邻接矩阵乘法**。$h^{(k)} = \sigma(W A h^{(k-1)})$（$A$ 为邻接矩阵）——矩阵乘法的每一行，就是"把该节点的邻居特征求和"（§7.2 的"$A$ 的行 = 邻居的 0/1 开关"）。sum 聚合就是 $A h$，mean 聚合就是 $D^{-1}A h$（§7.2 的行归一化）。
- **"迭代传播" ≈ 图上的扩散/随机游走**。信息每传一层沿图扩散一跳，$K$ 层 = $K$ 跳扩散。这与 PageRank、标签传播等经典算法是同一套"沿边传播"的思想，只是把"传播规则"换成了可学习的 $W$。

所以 GNN 是**经典图算法 + 深度学习的融合**——固定的传播骨架（邻域聚合），换成可学习的传播规则（$W$、$\sigma$）。这正是教材那句"GNN 把经典图算法与深度学习无缝融合"的精确含义。

## 第三步：DL 桥接

图神经网络不是"一种网络"，而是一族模型的**总称**，它们共享消息传递骨架，区别在 AGGREGATE 与变换的设计。本章后续会展开几个代表：

- **GCN（图卷积网络，§7.5.1）**：AGGREGATE = 归一化求和，$h_v^{(k+1)} = \sigma\big(\sum_{u \in \mathcal{N}(v) \cup \{v\}} \frac{1}{\sqrt{d_u d_v}} W h_u^{(k)}\big)$——给每个节点加自环、按度归一化，是消息传递最经典的一种。
- **GraphSAGE（§7.7.1）**：不聚合所有邻居，而是**采样**固定个数的邻居再聚合——解决大规模图的扩展性。
- **GAT（图注意力网络）**：AGGREGATE 里每个邻居的权重不是固定的，而是用注意力机制算出来的——每条边"该听谁更多"由数据决定。
- **GNN 的用途**：节点分类（给每个节点打标签）、图分类（给整张图打标签，§7.5.2）、链路预测（预测边）、图生成（生成分子）——全部建立在消息传递之上。

教材 §7.3 的 4 节点例子看起来简单，但它已经展示了 GNN 的全部动作：**聚合邻居、变换、激活、迭代**。把这个动作里的 sum 换成 mean、把 $W$ 从标量换成矩阵、把一层换成多层——你就得到了从 GCN 到 GAT 的所有现代模型。下一节我们回答一个更基本的问题：为什么深度学习要处理图？图的不可替代性在哪？
