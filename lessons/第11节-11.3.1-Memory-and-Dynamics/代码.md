# 代码：一只微型 RNN，从五个数里读出"趋势"

主线说：RNN 的记忆 = 隐藏状态在时间中滚动，$h_t = \tanh(a\,h_{t-1} + b\,x_t)$，而训练就是"雕刻一条动力系统的演化规则"。本节把它变成可运行的代码——**不调用任何深度学习库，手写前向传播与随时间反向传播 (BPTT)**，训练一只 1 个隐藏单元的微型 RNN，让它学会预测序列的下一个值，然后测试教材的例子：从 `[100, 102, 101, 105, 107]` 预测第 6 天。

预期结果：预测 **109.41**——比最后一天 107 更高，**追上了上涨趋势**，与教材的"≈109"一致。

---

## 层一：完整脚本

```python
import numpy as np                                        # np.tanh 与数组运算来自这里

np.random.seed(0)

# ---- ① 训练数据：100 天"上涨趋势 + 小幅波动"的序列 ----
N = 100
x = 100 + 1.5*np.arange(N) + 3.0*np.sin(np.arange(N)/3.0)  # 趋势 + 波动
mu, sd = x.mean(), x.std()                                 # 归一化统计量
xn = (x - mu) / sd                                         # 标准化：均值 0 方差 1

def forward(x, a, b, c):                                   # ② 前向：RNN 的记忆滚动
    """微型 RNN：h_{t+1} = tanh(a h_t + b x_t)，y_t = c h_{t+1} 预测 x_{t+1}。"""
    T = len(x)
    h = np.zeros(T)                                        # 隐藏状态轨道
    z = np.zeros(T)                                        # 激活前值
    y = np.zeros(T-1)                                      # 每一步的预测
    for t in range(T-1):
        z[t+1] = a*h[t] + b*x[t]                           # 旧记忆 × a + 新输入 × b
        h[t+1] = np.tanh(z[t+1])                           # 拧紧 → 新记忆
        y[t] = c*h[t+1]                                    # 读出新记忆 → 预测下一个
    return h, z, y

def bptt(x, a, b, c):                                      # ③ 随时间反向传播
    """手写 BPTT：误差沿时间反向传回，算出 a、b、c 的梯度。"""
    h, z, y = forward(x, a, b, c)
    T = len(x); m = T-1
    e = (y - x[1:]) / m                                    # 预测误差（预测 vs 真实下一个）
    delta = np.zeros(T)                                    # delta[t] = dL/dz_t
    delta[T-1] = 2*e[T-2]*c*(1-h[T-1]**2)                  # 最后一步的梯度
    for t in range(T-2, 0, -1):                            # 沿时间往回传
        delta[t] = (2*e[t-1]*c + a*delta[t+1])*(1-h[t]**2)  # 当前误差 + 未来的回传
    da = np.sum(delta[1:]*h[:-1])                          # dL/da
    db = np.sum(delta[1:]*x[:-1])                          # dL/db
    dc = np.sum(2*e*h[1:])                                 # dL/dc
    return da, db, dc, np.mean(e**2)

# ---- ④ 梯度下降：雕刻演化规则 ----
a, b, c = 0.2, 0.5, 1.0                                    # 权重初始值
lr = 0.05
for it in range(8000):
    da, db, dc, loss = bptt(xn, a, b, c)
    a -= lr*da; b -= lr*db; c -= lr*dc                     # 沿负梯度走一步
    if it % 2000 == 0:
        print(f"iter {it:4d}  loss={loss:.6f}   a={a:+.3f}  b={b:+.3f}  c={c:+.3f}")

# ---- ⑤ 测试：教材的五个股价，预测第 6 天 ----
seq = np.array([100.0, 102.0, 101.0, 105.0, 107.0])
sn = (seq - mu) / sd                                       # 用训练统计量标准化
h = 0.0; hs = []
for t in range(5):                                         # 顺着五个数走五步
    h = np.tanh(a*h + b*sn[t]); hs.append(h)               # 状态一步步滚动
pred = c*h*sd + mu                                         # 把预测换回原始量纲
print(f"\n=== 测试：[100, 102, 101, 105, 107] 预测第 6 天 ===")
print(f"预测值 = {pred:.2f}   （教材 ≈ 109）")
print(f"最后一天 = {seq[-1]}   →   预测 {pred:.2f} > 107，追上了上涨趋势")
print("隐藏状态 h_t:", np.round(hs, 4), "（隐藏单元输出，∈(-1,1)）")
```

运行输出（Python 3.11 + NumPy）：

```text

iter 2000  loss=0.000000   a=-0.331  b=+0.632  c=+2.303
iter 4000  loss=0.000000   a=-0.319  b=+0.581  c=+2.453
iter 6000  loss=0.000000   a=-0.263  b=+0.529  c=+2.566

=== 测试：[100, 102, 101, 105, 107] 预测第 6 天 ===
预测值 = 109.41   （教材 ≈ 109）
最后一天 = 107   →   预测 109.41 > 107，追上了上涨趋势
隐藏状态 h_t: [-0.6844 -0.5831 -0.6046 -0.5721 -0.5616]
```

看测试结果：**预测 109.41，教材说 ≈109——一致。** 网络没有"作弊"（它从不看第 6 天），它只是从 100 天训练序列里学到了"这种序列会沿着趋势继续上涨"的规则，然后顺着五个输入把状态滚到 $h_5$，从记忆里读出 109.41。而隐藏状态 $h_t$ 从 `-0.6844` 缓慢爬向 `-0.5616`——它在平滑地"滚动"：每读一个新数，记忆被更新一点点。

## 层二：分步逐函数拆解

### 步骤 1：造训练数据

```python
N = 100
x = 100 + 1.5*np.arange(N) + 3.0*np.sin(np.arange(N)/3.0)
mu, sd = x.mean(), x.std()
xn = (x - mu) / sd
```

**做什么**：生成 100 天的训练序列——一个"缓慢上涨 + 小幅波动"的信号，然后标准化（减均值除标准差）。
**操作**：`1.5*np.arange(N)` 是线性趋势（每天 +1.5）；`3.0*np.sin(np.arange(N)/3.0)` 是叠加的波动；`(x-mu)/sd` 让序列变成均值 0、标准差 1——**这很重要**，否则数值（100~250）太大，梯度下降会振荡甚至爆炸。
**输入**：无（生成数据）。
**输出**：`x`（原始序列）、`xn`（标准化后的序列）、`mu`、`sd`。
**可调参数**：趋势斜率 1.5、波动幅度 3.0、周期 `N/3`。斜率越大，网络越容易学到"上涨"；波动越大，越难。测试时用同样的 `mu, sd` 做标准化——**统计量必须来自训练集，测试时只用它们转换，不再重算**（§4.3 的防泄漏纪律）。
**对应数学**：这就是动力系统里的"训练轨道"——网络要学的演化规则，是从这条轨道上"反推"出来的。

### 步骤 2：定义 `forward` —— 记忆的滚动

```python
def forward(x, a, b, c):
    T = len(x)
    h = np.zeros(T)
    z = np.zeros(T)
    y = np.zeros(T-1)
    for t in range(T-1):
        z[t+1] = a*h[t] + b*x[t]
        h[t+1] = np.tanh(z[t+1])
        y[t] = c*h[t+1]
    return h, z, y
```

#### forward —— 微型 RNN 前向：$h_{t+1} = \tanh(a h_t + b x_t)$

`z[t+1] = a*h[t] + b*x[t]` 与 `h[t+1] = np.tanh(z[t+1])` 与 `y[t] = c*h[t+1]`

**做什么**：把序列从头到尾走一遍，记录隐藏状态轨道 `h` 和每一步预测 `y`。这是主线定义块里那条递归式的逐行实现。
**操作**：
- `z[t+1] = a*h[t] + b*x[t]`：新消息 = 旧记忆 × a + 当前输入 × b（线性混合）。
- `h[t+1] = np.tanh(z[t+1])`：拧紧（非线性激活），把混合结果压进 $(-1,1)$。
- `y[t] = c*h[t+1]`：把新记忆线性映射成"下一个值的预测"。
**输入**：
- `x`：标准化后的序列，形状 `(N,)`。
- `a`：隐藏到隐藏权重（对标主线 $W_{hh}$）——**旧记忆保留多少**。
- `b`：输入到隐藏权重（对标 $W_{xh}$）——**新消息挤进多少**。
- `c`：隐藏到输出权重（对标 $W_{hy}$）——把记忆翻译成预测。
**输出**：`h`（隐藏状态轨道，形状 `(N,)`）、`z`（激活前值）、`y`（预测序列，形状 `(N-1,)`）。
**可调参数**：
- `a` 是"记忆寿命"旋钮：$|a|$ 接近 1 时旧记忆衰减慢（记得久），接近 0 时记不久。这就是主线说的"记忆保质期写在权重里"。
- `b` 是"反应速度"旋钮：$b$ 越大，当前输入越强势地改写记忆。
- 想加容量，就把隐藏状态从标量换成向量 `h ∈ R^{d_hid}`，`a, b, c` 换成矩阵——§11.1《代码.md》的向量版。这里用 1 个单元，是为了让 BPTT 手写可见。
**对应数学**：主线定义块 $h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t)$ 的标量版。$h_t$ 是"状态"，这条式子是"演化规则"，`h` 数组是整条**轨道**。

### 步骤 3：定义 `bptt` —— 误差沿时间倒流

```python
def bptt(x, a, b, c):
    h, z, y = forward(x, a, b, c)
    T = len(x); m = T-1
    e = (y - x[1:]) / m
    delta = np.zeros(T)
    delta[T-1] = 2*e[T-2]*c*(1-h[T-1]**2)
    for t in range(T-2, 0, -1):
        delta[t] = (2*e[t-1]*c + a*delta[t+1])*(1-h[t]**2)
    da = np.sum(delta[1:]*h[:-1])
    db = np.sum(delta[1:]*x[:-1])
    dc = np.sum(2*e*h[1:])
    return da, db, dc, np.mean(e**2)
```

#### bptt —— 随时间反向传播（Backpropagation Through Time）

`delta[t] = (2*e[t-1]*c + a*delta[t+1])*(1-h[t]**2)`

**做什么**：把"预测误差"沿时间**从后往前**传回，算出 `a, b, c` 各自的梯度。这是 RNN 训练的心脏：因为 $h_t$ 依赖 $h_{t-1}$，误差在第 $t$ 步出现，影响第 $t$ 步之前的每一个权重——**梯度必须沿着记忆链条倒流回去**。
**操作**：
- `e = (y - x[1:]) / m`：每一步的预测误差（预测 vs 真实下一个值），除以样本数归一化。
- `delta[t] = dL/dz_t`（激活前的梯度）。最后一步没有"未来"，只从自己的误差算起：`2*e[T-2]*c*(1-h[T-1]^2)`——`(1-h²)` 是 $\tanh$ 的导数 $\tanh'(z) = 1 - \tanh^2(z)$。
- 从后往前循环：`delta[t] = (当前误差项 + a×未来的回传) × (1-h_t²)`——**`a*delta[t+1]` 这一项，就是误差跨时间的那一跳**，它把梯度沿着 $W_{hh}$ 的链条一步一步传回更早的记忆。
- `da = Σ delta[t+1]·h[t]`：每个时刻的"记忆的梯度 × 旧记忆"之和。
- `db = Σ delta[t+1]·x[t]`：每个时刻的"记忆的梯度 × 新输入"之和。
- `dc = Σ 2e·h`：每个时刻的"预测误差 × 记忆"之和。
**输入**：`x, a, b, c`（同 forward）。
**输出**：`(da, db, dc, loss)`——三个权重的梯度 + 均方误差。
**可调参数**：注意 `(1-h²)` 就是 $\tanh$ 导数——如果 `a` 很大且 `h` 接近 ±1（饱和），`(1-h²)` 接近 0，梯度被"压死"——这就是**梯度消失**的数学机制：误差传不了几步就衰减到零（§11.3.2 的主角）。把 `tanh` 换成 ReLU 则导数恒为 1（消失缓解，但有爆炸风险）。
**对应数学**：链式法则沿时间展开。RNN 展开后就是一条很深的计算链，BPTT 就是在这条链上反向传播——它与 §3.5.2 的普通反向传播是同一件事，只是"深度"变成了"时间"。

### 步骤 4：梯度下降循环 —— 雕刻演化规则

```python
a, b, c = 0.2, 0.5, 1.0
lr = 0.05
for it in range(8000):
    da, db, dc, loss = bptt(xn, a, b, c)
    a -= lr*da; b -= lr*db; c -= lr*dc
    if it % 2000 == 0:
        print(...)
```

**做什么**：重复"算梯度 → 沿负梯度走一步"共 8000 次，把 `a, b, c` 从初始值雕刻成能预测趋势的值。
**操作**：`a -= lr*da` 是梯度下降更新（§5 章）。输出的迭代曲线显示：loss 在 2000 步内就降到 0，权重随后缓慢微调。
**输入**：初始 `(a,b,c)`、学习率 `lr`。
**输出**：每 2000 步打印一次 `(loss, a, b, c)`。
**可调参数**：
- `lr=0.05` 是学习率（= §11.2.1.2 的欧拉步长）。太大 → 发散（§11.2.1.2 习题 2 的教训）；太小 → 收敛慢。这里 loss 很快到 0，说明任务对网络"太简单"——这是刻意为之，让演示干净。
- `it=8000` 是迭代次数。更多迭代 loss 不再降（已经 0），但权重继续沿零梯度区漂移——无伤大雅。
**对应数学**：这就是主线"训练 RNN = 雕刻一条动力系统的演化规则"。学到的 `(a, b, c)` 就是这条规则的具体参数；对测试序列用它们滚动，就是"把学到的动力学施加到新轨道上"。

### 步骤 5：测试教材例子

```python
seq = np.array([100.0, 102.0, 101.0, 105.0, 107.0])
sn = (seq - mu) / sd
h = 0.0; hs = []
for t in range(5):
    h = np.tanh(a*h + b*sn[t]); hs.append(h)
pred = c*h*sd + mu
```

**做什么**：把教材的五个股价标准化后，用**学到的 `(a,b,c)`** 顺着它们走五步，最后用 $c·h_5$ 预测第 6 天，再换回原始量纲。
**操作**：`h` 从 0 出发，对每个输入执行一次 `h = tanh(a*h + b*sn[t])`；预测 `pred = c*h*sd + mu`。
**输入**：`seq`（五个股价）、学到的 `a,b,c`、训练统计量 `mu, sd`。
**输出**：`pred = 109.41`、隐藏状态序列 `[-0.6844, -0.5831, -0.6046, -0.5721, -0.5616]`。
**可调参数**：把 `seq` 换成 `[90, 95, 100, 105, 110]`（更强的上涨），预测会更高（趋势更陡）；换成 `[120, 115, 110, 105, 100]`（下跌），预测会低于 100。**网络从训练数据学到的"趋势规则"被施加到任何新序列上**——这就是"学习演化规则、然后对新轨道做预测"。
**对应数学**：这就是主线"舞台一：时间序列预测"。$h_5$ 是读到第 5 天时的记忆，它背着整条序列的趋势；`pred=109.41 > 107` 说明记忆里确实有"上涨趋势"——**预测不是复制最后一天，是沿趋势外推**。隐藏状态全为负只是因为初始权重的符号——隐藏单元的值是任意编码，关键是它随输入平滑演化。

## 边界声明：这套代码能做什么，不能做什么

1. **1 个隐藏单元，容量极小。** 它只学到了"大体趋势"，抓不住更复杂的模式（转折、周期、长程依赖）。真实 RNN 的 $d_{hid}$ 有几百上千，还要用 LSTM 的门控延长记忆。这里的迷你版是"看得见内部"的教学模型，不是生产模型。
2. **手写 BPTT 只是演示。** 真正的训练用自动微分（PyTorch/TensorFlow 的 `autograd`）完成——它做的事和这里手写的 `delta` 递推**完全一样**，只是自动。理解这 8 行 `bptt`，你就理解了一切 RNN 训练框架在时间维度上做的数学。
3. **这个"趋势"模型在真实股价上会翻车。** 真实股价不是"趋势 + 小波动"——它有噪声、有突变、有市场状态切换。教材的 `≈109` 和本代码的 `109.41` 都是"理想化趋势数据"的结果。**RNN 学的是训练数据的演化规则；训练数据像不像现实，决定预测靠不靠谱**（§4.2.5 过拟合的时序版）。
