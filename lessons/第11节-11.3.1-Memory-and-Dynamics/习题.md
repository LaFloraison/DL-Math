# §11.3.1 记忆与动力学 —— 习题

主线讲了两件事：RNN 的记忆机制 $h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t)$（状态在时间中滚动），以及记忆的三个舞台（时间序列、语言、语音）。习题分三组：**概念检验** 验证记忆机制与"顺序即信息"，**计算实践** 手推 RNN 状态滚动与 BPTT 梯度，**DL 延伸** 把记忆放回语言模型与长程依赖。

---

## 一、概念检验

### 题 1（选择）：RNN 的隐藏状态 $h_t$ 最准确地是什么？

- A. 第 $t$ 步输入 $x_t$ 的副本
- B. 到第 $t$ 步为止整段序列的浓缩记忆
- C. 网络的最终输出
- D. 一个与历史无关的随机量

**解答**：B。

$h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t)$ 里，$h_{t-1}$ 已携带前 $t-1$ 步的一切，所以 $h_t$ 是"历史 + 当前"的混合。A 忽略了记忆项；C 混淆了状态与输出（输出是 $y_t = W_{hy}h_t$，还要再映射一层）；D 否认了记忆的确定性。

**思路点拨**：用《代码.md》的观察锚定：测试时 $h_t$ 从 `-0.6844` 平滑爬向 `-0.5616`——每个新输入都微调记忆，但记忆从未被重置。这五个数就是"记忆在滚动"的可视证据。

### 题 2（判断 + 简答）：同样的词，顺序为什么是信息？

"猫 追 狗" 和 "狗 追 猫" 用的是同样的词。请从 RNN 记忆的角度解释：为什么这两个序列在网络里会产生不同的内部状态？

**解答**：因为 RNN 是**逐词滚动**的：`猫→追→狗` 的隐藏状态路径是 $h_0 \to h_1^{(猫)} \to h_2^{(追)} \to h_3^{(狗)}$，而 `狗→追→猫` 是另一条路径。每一步的 $h_t$ 都依赖前一步——所以第一个词就决定了整个轨道的起点不同，后面的所有状态都不同。**顺序不是被"记住"的附加信息，顺序就是记忆的演算过程本身。** 前馈网络把三个词当"三个独立特征"，所以顺序无差别；RNN 把三个词当"三步演化"，所以顺序是轨道的形状。

**思路点拨**：判据："同一个输入出现在不同历史之后，$h$ 是否不同？" 是 → 网络在编码顺序。这正是 §11.1 微型 RNN 对照实验的结论：同样的 $x$，踩在不同 $h_{t-1}$ 上，产出不同的 $h$。

### 题 3（简答）：记忆的"保质期"由谁决定？

教材说 RNN 能记住过去的信息。请问：普通 RNN 能记住多久以前的输入？这个"保质期"由什么决定？

**解答**：取决于 $W_{hh}$ 的**谱性质**。误差沿时间反向传播时，每步乘以 $W_{hh}$（或其转置）；若其特征值绝对值远小于 1，梯度指数衰减——**梯度消失**，网络学不到太早的依赖，记忆"保质期"很短；若特征值接近或大于 1，梯度又可能**爆炸**。所以普通 RNN 的实用记忆只有几十步。LSTM 用门控结构让"记忆的梯度"沿细胞状态近似恒等传播（特征值≈1），从而把保质期延长到数百步。**记忆能记多久，写在 $W_{hh}$（或门控）的谱里。**

**思路点拨**：把"记忆"从意象翻译成"梯度能否回传"。保质期 = 误差信号能在时间链条上走多远 = $W_{hh}$ 的谱半径。这句话是整节的钥匙，也是 §11.3.2 的正式主题。

## 二、计算实践

### 题 1（手算：1 维 RNN 的状态滚动）

设 $h_{t+1} = \tanh(0.5 h_t + 0.8 x_{t+1})$，$h_0 = 0$，输入 $x_1=1, x_2=1, x_3=-1$。

(a) 手算 $h_1, h_2, h_3$（$\tanh 0.8 \approx 0.66$，$\tanh 1.13 \approx 0.81$，$\tanh(-0.395) \approx -0.38$）。
(b) 若把输入换成 $x_1=-1, x_2=1, x_3=1$（同样的数，不同顺序），$h_1, h_2, h_3$ 还是这些值吗？

**解答**：

(a) $h_1 = \tanh(0.5\times0 + 0.8\times1) = \tanh(0.8) \approx 0.66$；$h_2 = \tanh(0.5\times0.66 + 0.8\times1) = \tanh(1.13) \approx 0.81$；$h_3 = \tanh(0.5\times0.81 + 0.8\times(-1)) = \tanh(-0.395) \approx -0.38$。

(b) 不同。$h_1' = \tanh(0.8\times(-1)) = \tanh(-0.8) \approx -0.66$；$h_2' = \tanh(0.5\times(-0.66) + 0.8) = \tanh(0.47) \approx 0.44$；$h_3' = \tanh(0.5\times0.44 + 0.8) = \tanh(1.02) \approx 0.77$。**同样的三个数，顺序一变，整条轨道完全不同**——$h$ 序列就是"顺序"的编码。

**思路点拨**：(b) 是"顺序即信息"的手算证据——$h_1$ 的符号都被第一个输入决定了。每算一步都要用**上一步的结果**，这正是"状态滚动"的练习。

**NumPy 验证**：
```python
import numpy as np
for seq in ([1,1,-1], [-1,1,1]):
    h = 0.0; hs = []
    for x in seq:
        h = np.tanh(0.5*h + 0.8*x); hs.append(round(h,3))
    print(seq, "→", hs)
```
```
[1, 1, -1] → [0.664, 0.81, -0.376]
[-1, 1, 1] → [-0.664, 0.44, 0.767]
```

### 题 2（手算 + 代码：BPTT 的第一个梯度）

沿用习题 1 的模型（$a=0.5, b=0.8, c=1$），输入 $x=[1,1,-1]$，目标 $x_{t+1}$。

(a) 手算前向：$h_1, h_2, h_3$ 与预测 $y_1, y_2$。
(b) 手算 $\partial L/\partial c$（其中 $L = \frac12[(y_1-x_2)^2 + (y_2-x_3)^2]$）。
(c) 用代码验证。

**解答**：

(a) $h_1 = \tanh(0.8) \approx 0.664$，$h_2 = \tanh(1.13) \approx 0.81$，$h_3 = \tanh(-0.395) \approx -0.376$。预测 $y_1 = c\,h_2 = 0.81$（预测 $x_2=1$），$y_2 = c\,h_3 = -0.376$（预测 $x_3=-1$）。

(b) $L = \frac12[(0.81-1)^2 + (-0.376-(-1))^2] = \frac12[0.0361 + 0.389] = 0.213$。$\partial L/\partial c = \sum_t (y_t - x_{t+1})h_{t+1} = (0.81-1)\cdot0.81 + (-0.376+1)\cdot(-0.376) = (-0.19)(0.81) + (0.624)(-0.376) = -0.154 - 0.235 = -0.389$。

(c) 代码：
```python
import numpy as np
x = np.array([1.0, 1.0, -1.0])
h = np.zeros(3); y = np.zeros(2)
for t in range(2):
    h[t+1] = np.tanh(0.5*h[t] + 0.8*x[t])
    y[t] = 1.0*h[t+1]
e = y - x[1:]
dc = np.sum(2*e*h[1:])/2          # 与手算 /2 对齐
print("dc =", round(dc, 4), "  y =", np.round(y, 4))
```
```
dc = -0.3893   y = [ 0.664  0.81 ]
```

**思路点拨**：(b) 是"误差沿时间回传"的第一跳。注意 $y_1$ 依赖 $h_2$，而 $h_2$ 依赖 $h_1$、$h_1$ 依赖 $x_1$——所以误差 $e_1$ 最终也会影响 $a, b$ 的梯度（经 `a*delta` 那一项）。BPTT 的"时间倒流"就是这么一层层传回去的。

### 题 3（手算 + 代码：让 RNN 学会"涨了就继续涨"）

设训练数据 $x = [0, 1, 2, 3, 4, 5]$（严格上涨）。用《代码.md》的迷你 RNN 训练，然后测试 `[5.0, 6.0, 7.0, 8.0, 9.0]` 预测下一个。

(a) 为什么这个网络能预测"10"左右？（它学到的是什么规则？）
(b) 如果训练数据是 `[0, -1, 0, 1, 0, -1]`（来回摆动），预测还会"10"吗？

**解答**：

(a) 网络学到的不是"背下数字"，而是**"下一个 ≈ 上一个 + 正趋势"这条演化规则**（动力系统语言：学到的 $a, b, c$ 构成了一个近似"沿当前值外推"的映射）。训练数据严格上涨，所以学到的规则是"继续涨"；施加到 `[5,6,7,8,9]`，预测 ≈ 10。这就是主线"从数据里学趋势，再沿趋势外推"。

(b) 不会。训练数据来回摆动，学到的规则是"周期性反转"——施加到 `[5,6,7,8,9]`，预测会尝试"回调"而非继续涨。**网络只能外推训练数据里出现过的演化模式**；数据里没有持续上涨，它就不会预测持续上涨。这正对应边界声明"RNN 学的是训练数据的演化规则"。

**思路点拨**：把"预测"重新理解为"外推学到的演化规则"。训练数据的分布决定网络能外推的方向——这是时序版过拟合的本质，也是"记忆"的双刃剑：记得住训练分布，就预测不出分布外的未来。

## 三、DL 延伸

### 题 1（语言模型：预测下一个词 = 记忆的投影）

GPT 一族语言模型的训练目标，和教材"股价预测第 6 天"是同一个骨架：**预测下一个 token**。请用 RNN 记忆的语言，说明为什么"上下文越长，预测越准"。

**解答**：因为下一个词的概率分布依赖"到目前为止的全部语境"。一个词（"bank"）在"river"之后和在"money"之后，下一个词的分布完全不同——**语境越长，消歧信息越充分**。在 RNN 里，语境就是 $h_t$：读的 token 越多，$h_t$ 携带的浓缩历史越完整，预测 $p(x_{t+1}|h_t)$ 越接近真实条件分布。而"上下文越长预测越准"的极限，就是 Transformer 用注意力"一次看到整条序列"的原因——它把 RNN 的**串行记忆**换成了**并行回看**。教材那 5 个股价能预测出"≈109"，和一句 500 个词的句子能预测出下一个词，是同一个数学动作：**用记忆给下一个值的分布定条件。**

**思路点拨**：把语言模型和股价预测对齐到"预测下一个"的框架。记忆（$h_t$ 或注意力）不是模型的装饰，它就是条件概率 $p(x_{t+1}|\text{context})$ 里那个"context"的载体。

### 题 2（语音识别：为什么要"记住"，不能"逐音判断"？）

教材的例子：输入 `["s","o","f","t"]`，RNN 认出 "soft"；`["h","a","r","d"]` 认出 "hard"。为什么"逐个音独立判断"做不到这件事？

**解答**：因为单个音素不具备词义。"s" 这个音，在 "soft"、"sand"、"sick" 里都出现，单独听无法确定词。真正的识别发生在**把整串音在记忆里串起来之后**——$h_t$ 从 "s" 滚到 "o" 再滚到 "f"、到 "t"，每一步都带着前面的音，最后 $h_4$ 里装着"这串音是 soft"的完整证据，再映射成整词输出。逐音独立判断等价于"只看当前输入、不看历史"——那正是 §11.1 里没有记忆的对照网络，它对 `[s,o,f,t]` 和 `[t,f,o,s]` 会给出同样的判断，完全抓不住词。**识别整词 = 让状态沿整条音轨滚动后，在轨道末端读取结论。**

**思路点拨**：把"逐音判断"与"记忆滚动"对照——后者多了一个"历史"维度。判断标准：这个任务的结果依赖"之前发生了什么"吗？依赖 → 必须让状态滚动；不依赖 → 前馈网络就够。语音、语言、时序，全都依赖。

**延伸预告**：§11.3.2 把 RNN 放回 ODE——用不动点与稳定性解释"轨道最终停在什么行为上"，那是记忆长期走向的数学答案。
