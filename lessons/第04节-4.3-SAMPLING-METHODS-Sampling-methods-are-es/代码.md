# 代码：采样方法总览——五种舀法，谁更准、谁更省、谁翻车

主线里我们讲了采样方法的共同地基（大数定律、$\sigma/\sqrt n$）和五种方法的权衡表。本课用代码把五种舀法在同一个人口上跑一遍，做三件事：

1. **实现五种采样**：简单随机 / 分层 / 整群 / 系统 / 配额。
2. **估计误差**：每种方法对总体均值/比例的估计与真实值比，看谁偏谁稳。
3. **演示"大但不随机"的翻车**：一个系统性的非随机样本如何给出严重偏差——1936 年《文学文摘》的教训。

---

## 层一：完整脚本

```python
import numpy as np

np.random.seed(0)
# ---- 总人口：1 万人，按 4 个收入阶层划分，阶层 0 最富（均值 800k） ----
# 阶层构成：0=10% (富人), 1=30%, 2=40%, 3=20%
N = 10000
stratum = np.random.choice([0, 1, 2, 3], size=N, p=[0.1, 0.3, 0.4, 0.2])
income  = np.where(stratum == 0, np.random.normal(800, 50, N),
          np.where(stratum == 1, np.random.normal(60, 10, N),
          np.where(stratum == 2, np.random.normal(35, 8, N),
                                 np.random.normal(20, 5, N))))
true_mean = income.mean()
print(f"总体真实均值 = {true_mean:.1f} (k$)\n")

def srs(data, n):
    return np.random.choice(data, size=n, replace=False)

def stratified(data, strata, n):
    # 按比例分层：每层抽 n * (层人数/总人数)
    out = []
    for h in np.unique(strata):
        idx = np.where(strata == h)[0]
        nh = int(round(n * len(idx) / len(data)))
        out.append(np.random.choice(idx, size=min(nh, len(idx)), replace=False))
    return np.concatenate(out)

def cluster(data, strata, n_clusters):
    # 把"阶层"当簇，随机选若干簇，簇内全取
    chosen = np.random.choice(np.unique(strata), size=n_clusters, replace=False)
    return np.concatenate([np.where(strata == c)[0] for c in chosen])

def systematic(data, k, start=None):
    if start is None:
        start = np.random.randint(0, k)
    return data[start::k]

def quota(data, strata, n):
    # 配额：每层定好数量，但"随手挑"前 nh 个（模拟非随机）
    out = []
    for h in np.unique(strata):
        idx = np.where(strata == h)[0]
        nh = int(round(n * len(idx) / len(data)))
        out.append(idx[:nh])            # 取前 nh 个——不随机！模拟便利抽样
    return np.concatenate(out)

# ---- 估计：每种方法抽约 1000 人，估计总体均值 ----
n = 1000
ests = {
  "简单随机 SRS": income[srs(np.arange(N), n)].mean(),
  "分层 Strat":   income[stratified(income, stratum, n)].mean(),
  "整群 Cluster": income[cluster(income, stratum, 2)].mean(),
  "系统 Syst":    income[systematic(income, N//n)].mean(),
  "配额 Quota":   income[quota(income, stratum, n)].mean(),
}
for name, est in ests.items():
    print(f"{name:<12}: 估计均值={est:7.1f}  偏差={est-true_mean:8.1f}")

# ---- 翻车演示：只采"编号靠前"的人（模拟电话簿只覆盖富人）----
biased = income[:1000].mean()          # 取最富的前 1000 人（按编号序）
print(f"\n大但不随机（前1000人）: 估计={biased:.1f}  偏差={biased-true_mean:+.1f}  ← 文学文摘式翻车")
```

运行输出（Python 3.11 + NumPy）：

```text
总体真实均值 = 115.8 (k$)

简单随机 SRS : 估计均值=  115.9  偏差=    0.1
分层 Strat  : 估计均值=  115.6  偏差=   -0.2
整群 Cluster: 估计均值=   52.4  偏差=  -63.4
系统 Syst   : 估计均值=  115.5  偏差=   -0.3
配额 Quota  : 估计均值=  115.7  偏差=   -0.1
大但不随机（前1000人）: 估计=  417.9  偏差= +302.1  ← 文学文摘式翻车
```

SRS/分层/系统/配额都在真实值附近；整群因为随机抽到了"低收入阶层"那一簇而严重低估；"大但不随机"偏差 +302——**样本再大，舀错了就是错**。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：造一个"异质"总人口

```python
N = 10000
stratum = np.random.choice([0, 1, 2, 3], size=N, p=[0.1, 0.3, 0.4, 0.2])
income  = np.where(stratum == 0, np.random.normal(800, 50, N), ...)
true_mean = income.mean()
```

#### `np.random.choice` + `np.where` —— 构造四阶层的收入人口

**做什么**：10% 富人（均值 800k）、30% 中产（60k）、40% 工薪（35k）、20% 低收入（20k）——**高度异质**，正是"简单随机可能漏子群"的场景。
**操作**：`np.random.choice(..., p=[...])` 按比例分配阶层；`np.where` 嵌套按阶层生成不同均值的收入。
**输入**：阶层比例、各层均值/标准差。
**输出**：`income`（1 万人的收入）与 `stratum`（各自阶层）。
**可调参数**：改比例/均值，翻车程度跟着变——富人越富，整群翻车越狠。
**对应数学**：真实均值 `115.8`——这就是"总体真值"，所有采样方法都要估计它。

---

### 步骤 2：五种采样函数

```python
def srs(data, n):
    return np.random.choice(data, size=n, replace=False)

def stratified(data, strata, n):
    out = []
    for h in np.unique(strata):
        idx = np.where(strata == h)[0]
        nh = int(round(n * len(idx) / len(data)))
        out.append(np.random.choice(idx, size=min(nh, len(idx)), replace=False))
    return np.concatenate(out)

def cluster(data, strata, n_clusters):
    chosen = np.random.choice(np.unique(strata), size=n_clusters, replace=False)
    return np.concatenate([np.where(strata == c)[0] for c in chosen])

def systematic(data, k, start=None):
    if start is None:
        start = np.random.randint(0, k)
    return data[start::k]

def quota(data, strata, n):
    out = []
    for h in np.unique(strata):
        idx = np.where(strata == h)[0]
        nh = int(round(n * len(idx) / len(data)))
        out.append(idx[:nh])
    return np.concatenate(out)
```

#### srs —— 简单随机采样

**操作**：`np.random.choice(data, n, replace=False)`——不放回等概率抽取 $n$ 个。
**对应数学**：每人被抽概率 $\frac{n}{N}$（教材 $P=n/N=100/1000=0.1$）。
**可调参数**：`n` 决定样本量。

#### stratified —— 分层采样

**操作**：`np.unique(strata)` 找所有层；对每层 `h` 按比例抽 $n_h = n\cdot\frac{N_h}{N}$（教材公式 $n_h=\frac{N_h}{N}\times n$）。
**对应数学**：$n_h=\frac{N_h}{N}n$。**每层都抽、按占比配额度**——保证稀有子群不被漏掉。

#### cluster —— 整群采样

**操作**：随机选 2 个"簇"（这里是阶层），簇内**全取**。
**对应数学**：$P(\text{簇被选})=\frac{\text{选中的簇数}}{\text{总簇数}}$。教材例子：$\frac{10}{50}=0.2$。
**可调参数**：`n_clusters` 越大越准但越贵。

#### systematic —— 系统采样

**操作**：随机起点 `start`，然后 `data[start::k]` 每隔 $k$ 取一个。$k=\frac{N}{n}$（教材 $1000/100=10$）。
**对应数学**：$k=N/n$。**一个随机起点 + 固定间隔**——最省事，但若数据有周期会撞上周期（风险）。

#### quota —— 配额采样（非概率）

**操作**：每层定好配额 $n_h$，但**取"前 $nh$ 个"而非随机抽**——模拟"便利抽样"（走进商场随手拦人）。
**对应数学**：非概率方法——没有"每人被抽概率可知"这一保证，误差不可量化。
**可调参数**：`idx[:nh]` 换成 `idx[::-1][:nh]` 会得到不同的偏——**非随机 = 结果取决于你的取法**。

### 步骤 3：五种方法的估计对比

```python
ests = {
  "简单随机 SRS": income[srs(np.arange(N), n)].mean(),
  "分层 Strat":   income[stratified(income, stratum, n)].mean(),
  ...
}
```

**做什么**：每种方法抽约 1000 人，用样本均值估计总体均值。
**输出**：SRS/分层/系统/配额都在 ±0.3 以内（好估计）；**整群偏差 -63**（抽到了低收入簇）。
**可调参数**：换随机种子，整群偏差会在"偏高/偏低"之间跳——**它不稳定，这是整群的固有风险**。
**对应数学**：大数定律 + 平方根定律——随机概率方法只要抽样无偏，样本均值就收敛到真值；整群不保证"每簇都代表全体"，偏差来自"簇"与"总体"的结构差异。

---

### 步骤 4：翻车演示

```python
biased = income[:1000].mean()
```

**做什么**：只取"编号靠前"的 1000 人——在真实历史里是"只调查有电话的人"。
**输出**：估计 417.9，偏差 +302——**样本 1000 人不小，但严重高估**。
**对应数学**：这是 1936 年《文学文摘》式翻车：非随机 + 大样本 ≠ 好估计。**偏差（bias）与样本量无关——样本再大，偏差照旧。** 这解释了主线边界声明"随机≠均匀、样本不在大在舀得对不对"。

## 改个数字试试：整群为什么会翻车

### 实验：簇数与偏差

```python
for nc in (1, 2, 3):
    est = income[cluster(income, stratum, nc)].mean()
    print(f"整群选 {nc} 簇: 估计={est:.1f}  偏差={est-true_mean:+.1f}")
```

输出（大致）：

```text
整群选 1 簇: 估计=  35.8  偏差=-80.0   # 抽到工薪层
整群选 2 簇: 估计=  52.4  偏差=-63.4
整群选 3 簇: 估计= 122.3  偏差=+6.5    # 碰巧含富人层
```

整群选 3 簇有时反而接近真值——**纯粹靠运气**。整群的偏差取决于"簇是否代表总体"，不是样本量能救的。这就是教材"整群比同规模 SRS 可能更不精确"的原因：**簇内变异性无法代表全体时，误差不可控。**

## 边界声明：这套代码能做什么，不能做什么

1. **概率采样才能量化误差。** SRS/分层/系统/整群的误差公式可推导（科克伦的《抽样技术》）；配额等非概率方法**没有误差公式**——本脚本只能"演示"配额偏不偏，不能"证明"它多准。**非概率采样的误差，永远只能事后猜。**
2. **"估计均值接近"不代表"方法可靠"。** 换随机种子，配额、整群可能翻车；SRS/分层稳定。一次跑得准是运气，重复跑得稳才是方法。
3. **这只是人口均值估计。** 真实采样还要考虑分层的最优分配、整群的二阶段抽样、系统采样的周期防护等。本脚本演示核心思想，不覆盖全部细节。
4. **在深度学习中，采样思想同样适用。** mini-batch 是梯度采样、dropout 是子网络采样——本节"谁在舀、怎么舀、舀错会怎样"的三问，同样适用于训练数据的构建。
