# 习题：采样方法

## 第一组：概念检验

**1. 为什么"随机"是概率采样方法的根基？非概率采样（配额）缺少了什么？**

**解答**：随机让"每个个体被选中的概率"可知可控——于是可以用概率论（大数定律、$\sigma/\sqrt n$）量化估计误差，估计是"有保证"的。配额等非概率方法省了随机，代价是：没有"每人被抽概率"这一保证，误差无法分析、结果可能系统性偏差。**随机采样给你"可分析的误差"，非概率采样把误差藏了起来。**

**2. 判断题并说明理由："样本量越大，估计一定越准，所以大样本一定比小样本好。"**

**解答**：不完整。**样本均值随样本量增大收敛到总体均值（大数定律），但前提是采样无偏**。如果采样过程本身有系统性偏差（比如只调查富人），样本再大，偏差照旧——《文学文摘》240 万样本照样预测错，盖洛普 5 万随机样本预测对。**随机采样 + 足够样本量 = 准；大但不随机 = 大错。**

**3. 为什么采样方法在贝叶斯统计里是"必需品"而不是"可选优化"？**

**解答**：因为贝叶斯后验 $P(w|D)\propto P(D|w)P(w)$ 的分母 $P(D)=\int P(D|w)P(w)dw$ 几乎总不可算——后验通常没有闭式解。**不采样，很多贝叶斯推断根本算不出来**。从后验抽一堆样本、用样本估计均值/方差/预测，这就是蒙特卡洛与 MCMC（§4.3.6、§4.3.9）存在的全部理由。采样在贝叶斯里不是"省成本"，是"能不能做"。

## 第二组：计算实践

**4. 手算 + 代码验证。** 总体 $N=1000$，样本 $n=100$。（a）SRS 每人被选概率？（b）分四层（200/300/250/250 人），按比例分层每层抽多少？（c）系统采样的间隔 $k$ 是多少？

**解答**：
（a）$P=\frac{n}{N}=\frac{100}{1000}=0.1$——每人 10% 被选概率。
（b）$n_h=\frac{N_h}{N}\times n$：$20/30/25/25$（教材例子逐字）。
（c）$k=\frac{N}{n}=\frac{1000}{100}=10$——随机起点后每隔 10 人取一个。

代码验证：

```python
import numpy as np
N, n = 1000, 100
print("SRS 概率 =", n/N)
for Nh in (200, 300, 250, 250):
    print(f"层 N_h={Nh}: 应抽 {Nh/N*n:.0f}")
print("系统间隔 k =", N//n)
```

输出：

```text
SRS 概率 = 0.1
层 N_h=200: 应抽 20
层 N_h=300: 应抽 30
层 N_h=250: 应抽 25
层 N_h=250: 应抽 25
系统间隔 k = 10
```

**思路点拨**：若有人答"分层就是每层抽相同数量"，那是混淆了"按比例分层"与"等量分层"——比例分层 $n_h=\frac{N_h}{N}n$，等量分层则是另一种策略（在层大小悬殊时更公平但可能不省）。教材用的是按比例。

**5. 用代码复现"整群翻车"。** 构造一个"富人占 10%、均值 800"的高异质总体，用整群采样（把阶层当簇）选 1-2 簇估计均值，与真实均值对比，并解释为什么偏差不可控。

**解答**：见《代码.md》"改个数字试试"。典型输出：选 1 簇时估计 35.8（抽到工薪层）、偏差 -80；选 3 簇时碰巧 122（含富人层）。**整群的偏差取决于"抽到的簇是否代表全体"，纯粹看运气**——样本量救不了。这就是教材"整群可能比同规模 SRS 更不精确"的原因：**簇间差异主导误差，簇内全查也补不回来。**

## 第三组：DL 延伸

**6. Mini-batch 场景。** 训练集 10 万样本，batch size=64。（a）一个 batch 估计全量梯度的误差大致与什么成比例？（b）把 batch 翻倍，误差大致变多少？（c）如果训练数据本身是有偏差的（比如全是白天拍的图），加 batch size 能救吗？

**解答**：
（a）梯度估计误差 $\propto \frac{1}{\sqrt{\text{batch}}}$——平方根定律（样本均值方差的根号）。batch=64 时误差约是 batch=1 的 $1/8$。
（b）batch 从 64 翻倍到 128，误差缩到 $1/\sqrt2\approx0.71$ 倍——只降约 29%，不是 50%。**想精确十倍，batch 要百倍**；这就是为什么 SGD 的 batch 收益边际递减。
（c）不能。如果训练数据的**分布本身有偏差**（全是白天图，夜间图缺失），batch 再大也只是"在偏的数据上更精确地估计偏的梯度"——**batch 管的是"梯度估计的方差"，不管"数据的偏差"**。这对应采样理论的核心：方差（样本量）可以减，偏差（采样过程）样本量救不了。白天/夜间不均衡需要的是数据层面的重采样（分层采样思想），不是加大 batch。
**思路点拨**：若有人答"batch 越大越好，那就用全量梯度"——全量梯度无梯度方差但每次更新贵、且易困在尖锐极小值；SGD 的"随机性"本身就是正则化的一部分（§4.2.5）。batch 是"梯度估计精度"与"更新成本/随机性"的权衡，不是越大越好。
