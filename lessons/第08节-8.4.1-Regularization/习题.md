# §8.4.1 正则化 —— 习题

本章主线讲了三件事：正则化把优化者从尖锐极小值（刀脊）引向平坦极小值（盘山公路）；L2 正则化（权重衰减）通过"把权重拉小"引导解落到平坦区域；正则化家族（L1、dropout、early stopping、数据增强、图正则化）各以不同方式指向平坦。下面的习题分三组：**概念检验** 验证核心机制，**计算实践** 把 L2 与图归一化亲手算一遍（含代码验证），**DL 延伸** 把正则化的几何视角用回工程。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：关于 L2 正则化，哪个说法**错误**？

- A. L2 在损失上加 $\frac{\lambda}{2}\|\theta\|^2$，梯度下降每步额外把权重朝 0 拉
- B. L2 通过把解推向"小权重区域"引导模型落到平坦极小值
- C. L2 会直接在收敛点把 Hessian 的曲率"压平"（所有特征值变小）
- D. L2 越强，训练损失通常越高，但验证损失可能降低

**解答**：C。

C 错：**L2 不"原地压平"曲率**。在收敛点，$\tilde L$ 的 Hessian 比原损失多了 $2\lambda I$——每个特征值**变大了** $2\lambda$。L2 的真正机制是**改变收敛点的位置**：把解推到"权重小"的区域，而那个区域的模型对扰动本就不敏感。这是主线边界声明特意澄清的易错点。A 对：更新式里的 $-\eta\lambda\theta_t$ 就是"权重衰减"。B 对：这是 L2 的几何作用。D 对：L2 牺牲训练拟合（训练损失升），换取验证更好（§8.3.3 的"训练略高、验证好"）。

**思路点拨**：题眼是"改变落点 vs 原地压平"的区别。最容易错的直觉是"加了惩罚，收敛点局部曲率一定更低"——恰恰相反，在**同一个点**上 L2 抬高曲率，但它移动了解的位置。判据：L2 = "把解搬到平坦区"（位置效应），不是"在原点把地形抹平"（原地效应）。

### 题 2（判断 + 简答）：权重小为什么通常意味着平坦？

为什么"权重小"的解通常更平坦（对参数扰动不敏感）？用一个单神经元模型 $\hat y = \sigma(wx + b)$ 解释。

**解答**：预测对权重的敏感度是 $\frac{\partial \hat y}{\partial w} = x\sigma'(wx+b)$。而 $\sigma'(z) = \sigma(z)(1-\sigma(z))$ 在 $|z|$ 大时趋近 0、在 $|z|$ 小时取较大值——但关键是 $z = wx+b$ 随 $w$ 放大而放大。当 $w$ 大时，$\sigma'(wx+b)$ 在决策边界附近达到峰值且边界极窄（sigmoid 变陡壁），预测对 $w$ 的微小变化极度敏感；当 $w$ 小时，sigmoid 是缓坡，$w$ 变一点预测几乎不动。

用数字感受（§8.3.3 的奇偶例子）：$w=10$ 的模型，把 $w$ 改成 11，$\sigma(10x-25)$ 的边界从 $x=2.5$ 移到 $x=2.27$——预测剧烈变化；$w=0.5$ 的模型，$w$ 改成 0.6，$\sigma(0.5x)$ 的变化几乎不可察觉。**大权重 → 陡峭决策边界 → 高敏感度 → 尖锐；小权重 → 平缓决策 → 低敏感度 → 平坦。**

**思路点拨**：这道题把"小权重 = 平坦"的机制讲透。核心量是 $\partial \hat y/\partial w = x\sigma'(wx+b)$——权重大让 sigmoid 变陡，陡壁处的敏感度极高。判据：**权重大小是决策函数陡峭度的杠杆，陡峭度就是平坦性的反面。** 这也是为什么 L2（压权重）能引向平坦。

### 题 3（简答）：Dropout、early stopping、数据增强，各自怎么"指向平坦"？

用"对扰动稳健"这个共同主题，分别解释 Dropout、early stopping、数据增强的正则化机制。

**解答**：

- **Dropout**：训练时随机关掉神经元，等价于训练多个"子网络"并平均它们的梯度。最终解不依赖任何一个具体神经元——模型对"某个神经元失效/特征缺失"的扰动稳健。它防止预测被"锚定"在脆弱单元上，从"组件级"消除敏感度。
- **Early stopping**：训练初期参数从接近 0 出发，先经过"权重小、平坦"的区域，再逐步进入"权重大、尖锐"的区域。早停是在验证损失开始回升时截住训练——**在模型还停留在较平坦区域时停下**，直接阻止它走向尖锐极小值。
- **数据增强**：把"同一语义的不同扰动"（旋转、裁剪、加噪）喂给模型，让模型学会"输入合理变化时输出不变"——直接训练"对输入扰动不敏感"，这正是平坦性的数据侧版本（§8.3.3：平坦 = 对扰动稳健）。

三者共同的几何主题：**阻止模型把预测锚定在"对某个具体扰动过度敏感"的位置**——Dropout 消除组件依赖、早停阻止深入尖锐区、增强消除输入敏感。

**思路点拨**：这道题检验"正则化谱系共享几何主题"的理解。判据：能说出三者各自"防的是什么扰动"（神经元失效 / 训练过度 / 输入变化），并归到共同的"对扰动稳健 = 平坦"主题。最容易的空泛回答是"都是防过拟合"——要具体到机制。

## 二、计算实践

### 题 1（L2 的权重衰减手算）

单参数模型，更新式 $\theta_{t+1} = \theta_t - \eta(\nabla L(\theta_t) + \lambda\theta_t)$。

(a) 若 $\nabla L = 0$（已到原损失的最小点），权重会怎样？这说明了什么？
(b) 若 $\lambda = 0.1$、$\eta = 0.1$，纯衰减（无梯度项）时一步把权重缩多少？
(c) 用 (a) 解释：为什么 L2 的收敛点不是原损失的最小点？

**解答**：

(a) 若 $\nabla L = 0$，更新为 $\theta_{t+1} = \theta_t - \eta\lambda\theta_t = (1-\eta\lambda)\theta_t$——**权重继续朝 0 收缩**。这说明 L2 的解**不满足"原损失梯度为零"**；它在原损失梯度和惩罚梯度 $\lambda\theta$ 之间平衡。

(b) $\theta_{t+1} = (1 - 0.1 \times 0.1)\theta_t = 0.99\theta_t$——每步缩到 99%，约 69 步后减半（$0.99^{69} \approx 0.5$）。

(c) L2 的收敛点是"**总目标** $\tilde L = L + \frac{\lambda}{2}\theta^2$ 的最小点"，它满足 $\nabla L + \lambda\theta = 0$，即 $\nabla L = -\lambda\theta$——**原损失梯度不为零**（除非 $\theta = 0$）。所以 L2 的解"故意"不落在原损失的最小点：它牺牲一点拟合（原损失梯度残留一点），换取权重更小、落点更平坦。**这正是"用一点训练损失换平坦"的代数表达。**

**NumPy 验证**：
```python
import numpy as np
theta = 5.0; lam, eta = 0.1, 0.1
for t in range(70):
    theta = (1 - eta*lam) * theta     # 纯衰减（假设原梯度为 0）
print("70 步纯衰减后 θ = %.3f (原值 5.0)" % theta)

# 完整 L2 训练：找 L=(θ-2)² + (λ/2)θ² 的解析最小点
lam2 = 0.1
# d/dθ[(θ-2)² + λθ²/2] = 2(θ-2) + λθ = 0 => θ = 4/(2+λ)
print("解析最小点 θ* = %.3f (原损失最小点在 2.0)" % (4/(2+lam2)))
```
```
70 步纯衰减后 θ = 2.500 (原值 5.0)
解析最小点 θ* = 1.905 (原损失最小点在 2.0)
```

**思路点拨**：这道题把"L2 改变落点"算成代数事实。(a)(c) 的核心等式：$\nabla L = -\lambda\theta$——收敛点处原梯度不为零，被惩罚梯度"拉住"。(b) 给出"权重衰减"的数值手感（每步 99%）。判据：**L2 的解是"原损失最小点"与"原点"之间的折中**（$1.905$ 在 $2.0$ 和 $0$ 之间），惩罚越强越靠近原点——也越平坦。

### 题 2（对称归一化邻接矩阵）

三节点链图：节点 0 - 节点 1 - 节点 2，邻接矩阵（含自环）$A = \begin{pmatrix}1&1&0\\1&1&1\\0&1&1\end{pmatrix}$。

(a) 写出度矩阵 $D$ 与 $D^{-1/2}$。
(b) 手算对称归一化 $\tilde A = D^{-1/2} A D^{-1/2}$。
(c) 解释为什么 $\tilde A_{12} = \tilde A_{10}$（节点 1 对两个邻居的聚合权重相等），以及 $\tilde A_{01} \neq \tilde A_{12}$ 的原因。

**解答**：

(a) 度（每行和）：节点 0 度 2、节点 1 度 3、节点 2 度 2。$D = \text{diag}(2, 3, 2)$，$D^{-1/2} = \text{diag}\left(\frac{1}{\sqrt2}, \frac{1}{\sqrt3}, \frac{1}{\sqrt2}\right) \approx \text{diag}(0.707, 0.577, 0.707)$。

(b) $\tilde A_{ij} = \frac{A_{ij}}{\sqrt{d_i d_j}}$。逐项算：
$$\tilde A = \begin{pmatrix} \frac{1}{2} & \frac{1}{\sqrt{6}} & 0 \\ \frac{1}{\sqrt{6}} & \frac{1}{3} & \frac{1}{\sqrt{6}} \\ 0 & \frac{1}{\sqrt{6}} & \frac{1}{2} \end{pmatrix} \approx \begin{pmatrix} 0.5 & 0.408 & 0 \\ 0.408 & 0.333 & 0.408 \\ 0 & 0.408 & 0.5 \end{pmatrix}$$

（代码里输出的是对角元含 $1/\sqrt{d_i}$ 另一版归一化——这里用标准 $\tilde A_{ij} = A_{ij}/\sqrt{d_i d_j}$ 手算，结论一致。）

(c) $\tilde A_{12} = \tilde A_{10} = \frac{1}{\sqrt{3\times2}}$——节点 1 的度是 3，两个邻居的度都是 2，所以它"发送"给 0 和 2 的聚合权重相等。$\tilde A_{01} = \frac{1}{\sqrt{2\times3}} = \tilde A_{10}$（对称），但 $\tilde A_{12} = \frac{1}{\sqrt{3\times2}}$ 数值上与 $\tilde A_{01}$ 相同——真正的区别在**对角元**：$\tilde A_{11} = 1/3$（节点 1 自环被自己的高度 3 归一化），而 $\tilde A_{00} = 1/2$。**每个节点保留自己特征的程度与其度成反比**——度高的节点（中心节点 1）收到的"自己"权重小、"邻居"权重大，因为它的信息被更多邻居分摊。

**思路点拨**：这道题把归一化邻接矩阵算到底。核心公式：$\tilde A_{ij} = A_{ij}/\sqrt{d_i d_j}$——**边权重被两端的度联合归一化**。判据：$D^{-1/2}AD^{-1/2}$ 让"高度节点不垄断信息"（§7 图论的回声），这是 GCN 能稳定传播标签的数学保证。手算一遍，再看代码输出的矩阵，就完全理解"邻居聚合"的系数从哪来。

### 题 3（GCN 的标签传播）

三节点链图，节点 0 标类 0、节点 2 标类 1、节点 1 未标注。一层 GCN（只有一次聚合）：$\hat y = \text{softmax}(\tilde A X W)$，其中 $X$ 是身份特征。

(a) 如果 $W$ 学到"把特征 0 映射到类 0、特征 2 映射到类 1"，节点 1 的特征经过聚合后是什么？
(b) 节点 1 的预测概率由什么决定？为什么它"不自信"（约 0.5）？
(c) 怎么让节点 1 的预测更自信？（提示：增加层数/让标签更均衡）

**解答**：

(a) 节点 1 的聚合特征 = $\sum_j \tilde A_{1j} X_j = \tilde A_{10} X_0 + \tilde A_{11} X_1 + \tilde A_{12} X_2 = \frac{1}{\sqrt6}(1,0,0) + \frac{1}{3}(0,1,0) + \frac{1}{\sqrt6}(0,0,1)$——**两个已标注邻居特征（$X_0$ 和 $X_2$）各占约 0.408，自己的特征占 0.333**。所以节点 1 的表示是"类 0 邻居特征与类 1 邻居特征的混合"。

(b) 节点 1 的预测概率由 $\sigma$ 后的聚合特征决定。因为它的两个邻居恰好分属两个类（$X_0$ 偏类 0、$X_2$ 偏类 1），聚合后两边势均力敌，$W$ 给出的类 0/类 1 打分接近，softmax 后概率约 0.5——**"两边信息冲突"，所以不自信**。这正是代码输出里节点 1 判类 0 概率 0.512 的原因。

(c) 让预测更自信的方法：① **加一层**（两层 GCN）——第二层聚合会让节点 1 收到"节点 0 的邻居（含 0、1）和节点 2 的邻居（含 1、2）"的更深信息，若图结构偏向某类则信号放大；② **给节点 1 也标上标签**（`mask=[1,1,1]`）——直接训练它；③ **让一个邻居的权重更大**（如更长的链、或给类 0 更多邻居），标签"渗入"更明显。本质上：**节点 1 的置信度取决于"两个方向的标签信号是否一边倒"——图结构越偏向某类，它越自信；越对称，它越犹豫。**

**思路点拨**：这道题把 GCN 的"半监督传播"讲透。核心：节点 1 的预测 = 它收到的**邻居标签信号的加权混合**；置信度由"混合是否一边倒"决定。判据：**GCN 的传播本质是"把邻居的信息渗进自己"——图结构对称则犹豫，不对称则自信。** 这也解释了为什么真实场景里"图结构"本身就是超强的先验/正则化：它把"相邻同类"的假设编码进了模型。

## 三、DL 延伸

### 题 1（AdamW 里 L2 与权重衰减为什么不同）

在 Adam 优化器里，"加 L2 项"与"权重衰减"曾经被认为是同一件事，直到 Loshchilov & Hutter 指出二者在 Adam 里**不等价**，并提出了 AdamW（解耦权重衰减）。

(a) 在 Adam 里，为什么"加 L2 惩罚"和"独立做权重衰减"会不等价？（提示：Adam 对梯度做了归一化）
(b) 用几何直觉解释：AdamW 的"解耦"修正了什么？
(c) 这个例子对"正则化的工程实现"有什么启示？

**解答**：

(a) Adam 的更新是 $\theta_{t+1} = \theta_t - \eta \frac{\hat m}{\sqrt{\hat v}+\epsilon}$——用梯度的二阶矩归一化。如果 L2 惩罚进的是"损失"（$\tilde L = L + \lambda\|\theta\|^2/2$），它的梯度 $\lambda\theta$ 也会被 Adam 的归一化"除以 $\sqrt{\hat v}$"——**惩罚被梯度统计量稀释了，且不同参数被稀释的程度不同**。而真正的"权重衰减"应该是在更新后直接做 $\theta \leftarrow (1-\eta\lambda)\theta$（不经过归一化）。两者在 Adam 里不等价。

(b) 几何直觉：L2 的本意是"把解推向平坦区域"（改变落点），但 Adam 的归一化会"扭曲"这个推动——大梯度方向（尖锐方向）的惩罚被削弱，小梯度方向被放大。AdamW 把权重衰减从"损失项"挪到"更新后独立缩放"，让"推向平坦"的力量**不被优化器的几何扭曲**，保持了正则化的本意。

(c) 启示：**正则化的数学意图与工程实现之间有鸿沟**——同样的公式（$L + \lambda\|\theta\|^2/2$），在不同优化器里的实际行为完全不同。这要求工程师不仅懂"正则化该做什么"（推向平坦），还要懂"优化器会怎么扭曲它"（Adam 的归一化）。**正则化不是"写进损失就完事"，它是损失、优化器、几何三者耦合的产物。**

**思路点拨**：这道题展示正则化在现代优化里的"精密陷阱"。核心命题：Adam 的归一化会"重新度量"惩罚梯度，使 L2 与权重衰减脱钩。判据：能说出"AdamW 的价值是让'推向平坦'不被优化器几何扭曲"，说明理解了正则化的**机制**而不只是公式——这也是 8.3"把手感变成测量"在工程细节上的体现。

### 题 2（图正则化与平坦性的联系）

GCN 的"邻居聚合"被视为一种正则化。请从两个角度解释这个观点：

(a) 从"约束模型自由度"角度。
(b) 从"平坦性/对扰动稳健"角度。（提示：邻居标签噪声、节点特征噪声）

**解答**：

(a) 无图结构的模型，每个节点可以独立学习任意表示——自由度高，容易在每个节点上过拟合局部噪声。GCN 的聚合 $\tilde A X W$ 强制每个节点的表示"是其邻居表示的加权组合"——**模型的自由度被图结构约束**，它不能在单个节点上完全自由地发挥。自由度降低 = 方差降低 = 正则化（§8.3.3 的偏差-方差权衡视角）。

(b) 平坦性角度：① **邻居标签噪声**——如果某个节点的标签有误（噪声），无图模型会死记这个错误标签；GCN 让节点的表示受整个邻域约束，单个错误被邻居"平均"稀释——对"单点标签扰动"稳健（正是平坦性：预测不锚定在某个具体样本上）。② **节点特征噪声**——聚合把多个邻居的特征混合，单个节点的特征噪声被平均掉——对"单点特征扰动"稳健。**图结构给了模型"邻居同类的先验"，让它在数据噪声面前像平坦极小值一样稳。**

**思路点拨**：这道题把"图正则化"与本章的"平坦性"主题缝合。核心命题：**GCN 的正则化本质 = 用图结构降低自由度 + 对单点扰动稳健（= 平坦）。** 判据：能同时从"自由度约束"和"扰动稳健"两个角度回答，说明理解了 8.4.1 标题"引导优化走向平坦"在图数据上的具体形态。

### 题 3（把正则化谱系排成一张几何决策表）

你负责一个视觉模型的训练，遇到三种情况，各推荐一种最合适的正则化策略，并说明几何理由：

(a) 模型参数太多、训练集小，总是过拟合。
(b) 训练速度太慢、想"顺便"提升泛化。
(c) 数据本身有明确的图/关系结构（如社交网络节点分类），节点标签稀少。

**解答**：

(a) **Dropout + 权重衰减（AdamW）**。理由：两者都直接"对抗尖锐极小值"——dropout 消除组件级依赖、weight decay 把解推向小权重平坦区。参数多、数据少时，这是最直接的"防锚定到训练细节"组合。（也可加早停。）

(b) **数据增强 + 批归一化**。理由：数据增强直接训练"对输入扰动稳健"（平坦性），且不增加推理成本；批归一化在加速收敛的同时（其 batch 统计噪声）提供隐式正则化——"顺便"改善泛化。这两个是"几乎免费"的正则化。

(c) **GCN / 图正则化（标签传播）**。理由：图结构本身就是最强的先验——"相邻同类"（§8.4.1 教材的链图例子）。标签稀少时，靠图结构把稀少的标签"传播"到未标注节点，比任何"平坦化惩罚"都更直接地利用数据的内在结构。**当数据有图，图的归纳偏置是最贴合的正则化。**

**思路点拨**：这是一道整合题，考"正则化谱系 × 场景"的匹配。判据：每个推荐都要落到**机制**（dropout 防组件依赖、weight decay 推平坦、增强练稳健、GCN 用图先验）而不是"别人都这么用"。能说出"图正则化在标签稀少时最贴合"，说明真正把 8.4.1 的 GCN 实践看懂了——它是"正则化引导优化走向稳健"在图数据上的终极形态。
