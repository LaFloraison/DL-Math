# 习题：多元微积分导论

本组习题检验你对本章整体图景的把握。§3.1 是一座路标，它不要求你掌握推导细节，但要求你能回答：**这座损失山谷上，每一件工具各自在解决什么问题。**

## 一、概念检验

### 题 1.1（填空）

一个神经网络有 $n$ 个权重，损失函数为 $L(w_1, \ldots, w_n)$。训练时我们要找的是 $L$ 的____点，也就是损失最小的参数组合。它依赖的"脚下信息"是损失函数在每个权重方向上的____导数。

**解答**：极小值（minimum）；偏（partial）。
**思路点拨**：这是本章最核心的比喻：目标 = 谷底，信息 = 脚下坡度。注意不要填"最小值"——最小值是函数值，极小值是那个"点"（参数取值）。损失函数值最小的那个参数点，才对应谷底。

### 题 1.2（选择）

下列关于"偏导数"的说法，**正确的是**（ ）

A. 偏导数描述了函数在**所有**方向上的变化率
B. 对 $f(x,y)$ 求 $\partial f/\partial x$ 时，把 $y$ 视作常数
C. 多元函数的导数只有一个
D. 偏导数一定等于方向导数

**解答**：B。
**思路点拨**：A 是典型陷阱——偏导数只给**坐标轴方向**的变化率，任意方向的变化率属于方向导数（§3.4）。C 的陷阱在于把一元习惯带进多元：多元函数"导数"不是一个数，而是一组偏导数的集合（梯度）。D 只有在方向恰为坐标轴时才成立。B 正是偏导数的定义操作。

### 题 1.3（简答）

梯度下降的更新规则是 $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla L(\mathbf{w}_t)$。解释：为什么是"减"而不是"加"？$\eta$ 起什么作用？

**解答**：梯度 $\nabla L$ 指向函数**上升最快**的方向；要降低损失，必须朝**反方向**走，所以要减。$\eta$（学习率）是每步迈多大——它把梯度这个"方向+陡峭度"缩放成实际的步长。$\eta$ 太大越过谷底，太小走得慢。
**思路点拨**：追问"如果改成加号会怎样"——每一步都往山上走，损失只会涨。这个问题是检验你是否真正理解了"梯度指向上坡"这一句。

## 二、计算实践

### 题 2.1（手算）

设 $L(w_1, w_2) = (w_1 - 3)^2 + 2(w_2 + 2)^2$。

(a) 写出两个偏导数 $\partial L/\partial w_1$、$\partial L/\partial w_2$。
(b) 写出梯度 $\nabla L(1, -1)$，并判断在 $(1,-1)$ 处，$w_1$ 应该增大还是减小来降低损失。

**解答**：(a) $\dfrac{\partial L}{\partial w_1} = 2(w_1 - 3)$，$\dfrac{\partial L}{\partial w_2} = 4(w_2 + 2)$。
(b) 代入 $(1, -1)$：$\nabla L(1,-1) = (2(1-3),\; 4(-1+2)) = (-4,\; 4)$。$w_1$ 方向的偏导是 $-4 < 0$，意味着增大 $w_1$ 会使损失下降——所以 $w_1$ 应**增大**（往 $+w_1$ 方向走）；而 $w_2$ 方向偏导是 $4 > 0$，$w_2$ 应减小。整体下山方向是 $-\nabla L = (4, -4)$。
**思路点拨**：把 $(w_1-3)^2$ 里那个 $3$ 想成谷底位置，$w_1$ 越接近 3 损失越小。若 $w_1 < 3$，偏导为负，往大走就接近谷底；反之往小走。用代码 `grad_loss` 的写法验证：改谷底目标值为 3、系数为 2，复跑《代码.md》的脚本。

### 题 2.2（代码验证）

用 NumPy 验证：$L(w_1, w_2) = (w_1-3)^2 + 2(w_2+2)^2$，从 $(0,0)$ 出发，$\eta = 0.1$，跑 30 步梯度下降，打印终点与终点损失。

```python
import numpy as np
def loss(w): return (w[0]-3.0)**2 + 2.0*(w[1]+2.0)**2
def grad(w):  return np.array([2.0*(w[0]-3.0), 4.0*(w[1]+2.0)])
w = np.array([0.0, 0.0])
for _ in range(30):
    w = w - 0.1 * grad(w)
print(f"终点 w = ({w[0]:.4f}, {w[1]:.4f})  损失 = {loss(w):.8f}")
```

**解答**：终点约 $(2.9829, -1.9857)$，损失约 $2.6 \times 10^{-5}$。谷底理论值 $(3, -2)$，30 步已接近但未精确到达。
**思路点拨**：注意 $w_2$ 方向偏导是 $4$，是 $w_1$ 方向的两倍，所以 $w_2$ 方向每步走得比 $w_1$ 快——这正是系数 2 在梯度里的回声。把 `0.1` 改成 `0.3` 试试震荡，改成 `1.0` 试试发散。如果你改完发现损失涨了，说明你亲手撞上了"学习率过大"的墙。

## 三、DL 延伸

### 题 3.1

一家公司要训练一个 1 亿参数的模型。工程师说"我们每步都要计算梯度"，另一位说"反正就是偏导数，把 1 亿个偏导数算出来填进向量就行"。请指出：这句话对了一半，另一半在哪里会出问题？

**解答**：对的一半——梯度确实是由 1 亿个偏导数组成的向量，方向是上升最陡的方向，训练确实要沿负梯度走。出问题的一半——**怎么算这 1 亿个偏导数**。手写求导不现实；真实框架用**自动微分/反向传播**按链式法则高效地一次性算出全部偏导（§3.5.2、§3.6）。此外，"梯度就是偏导数组装"忽略了梯度在如此高维空间里的**病态行为**：巨大的损失曲面凹凸不平，有鞍点、有局部洼地，光有梯度不等于能走到好的谷底（§3.5）。
**思路点拨**：这道题考的是本章"概念链"——偏导数 → 梯度 → 计算可行性 → 优化困难。能答出"计算效率"和"高维优化困难"两点，就说明你看到了这一章不只是公式，而是一整套工程问题。

### 题 3.2

假设你用《代码.md》里的二维碗训练了一个玩具模型，完美收敛到了谷底。现在把这个模型丢到一个有 100 个真实特征的数据集上，损失曲面不再是一座碗。请从本章导论的视角，预判两个你可能遇到的困难，并各给一句解法方向。

**解答**：① 损失曲面有多个局部极小/鞍点，梯度下降可能卡在浅洼里——解法方向：动量、自适应学习率（Adam/RMSprop）、随机重启。② 参数太多（上百万维），梯度计算昂贵——解法方向：反向传播 + 自动微分、分批（mini-batch）梯度下降。也可以补充：③ 梯度可能消失或爆炸（深层网络）——解法方向：ReLU 激活、归一化、梯度裁剪。
**思路点拨**：这些正是 §3.5 "GRADIENT IN DEEP LEARNING" 要系统讲的挑战。现在你能凭导论的直觉预判出它们，说明你已经建立起了"损失曲面 + 梯度 + 优化"的心智模型——后面每一节都在这张地图上添细节。
