# 代码：把"盲人下山"写成可运行的一步步

主线里我们看见了一个蒙眼的盲人，凭脚下的坡度一步步走进谷底。本章所有概念——偏导数、梯度、梯度下降、Jacobian——都是这一场景的不同细节。这一节作为导论，我们把**整个章节的骨架**先跑一遍：定义一座有两个变量的损失曲面，算出它的偏导数（§3.2），组装成梯度（§3.4），然后让一个盲人（初始点）沿着负梯度方向一步步下山（§3.5）。

下面的脚本只用 NumPy 的基本四则运算与 `np.linalg`，不调用任何深度学习框架——这一节的目的不是训练模型，而是**亲手走一遍本章的每一步数学**。

---

## 层一：完整脚本

```python
import numpy as np                            # NumPy：全部数值操作来自这里

# ---- ① 损失函数：一座椭圆碗，谷底在 (2, -1) ----
def loss(w):
    """L(w) = (w1 - 2)^2 + 3 * (w2 + 1)^2：两个变量的二次曲面。"""
    w1, w2 = w[0], w[1]                       # 解包：取权重向量的两个分量
    return (w1 - 2.0) ** 2 + 3.0 * (w2 + 1.0) ** 2

# ---- ② 梯度：两个偏导数装进一个向量 ----
def grad_loss(w):
    """∇L = (∂L/∂w1, ∂L/∂w2) = (2(w1-2), 6(w2+1))。"""
    w1, w2 = w[0], w[1]
    dL_dw1 = 2.0 * (w1 - 2.0)                 # 偏导数：对 w1，把 w2 当常数
    dL_dw2 = 6.0 * (w2 + 1.0)                 # 偏导数：对 w2，把 w1 当常数
    return np.array([dL_dw1, dL_dw2])

# ---- ③ 梯度下降：一个盲人的下山循环 ----
def gradient_descent(w0, lr, n_steps):
    """从 w0 出发，沿负梯度方向走 n_steps 步，学习率 lr。返回轨迹。"""
    w = np.array(w0, dtype=float)             # 当前站立的点
    path = [w.copy()]                         # 记录每一步的位置（用于回看）
    for _ in range(n_steps):                  # 一步 = 测坡度 + 往下降方向迈步
        g = grad_loss(w)                      # 测脚下的坡度（梯度）
        w = w - lr * g                        # 往下降方向（负梯度）迈一步
        path.append(w.copy())                 # 记下新位置
    return w, path

# ---- ④ 运行：让盲人从 (0, 0) 出发 ----
w_final, path = gradient_descent([0.0, 0.0], lr=0.05, n_steps=50)
print(f"终点 w    = ({w_final[0]:.6f}, {w_final[1]:.6f})   # 谷底理论值 (2, -1)")
print(f"终点损失  = {loss(w_final):.8f}   # 谷底理论损失 0")

# ---- ⑤ 中途抽查几步，看盲人的脚印 ----
for i in [0, 1, 5, 20, 49]:
    wi = path[i]
    print(f"第{i+1:>3}步  w=({wi[0]:+.4f}, {wi[1]:+.4f})  L={loss(wi):.4f}  |∇L|={np.linalg.norm(grad_loss(wi)):.4f}")
```

运行输出（Python 3.11 + NumPy）：

```text
终点 w    = (1.999992, -0.999983)   # 谷底理论值 (2, -1)
终点损失  = 0.0000000009   # 谷底理论损失 0
第  1步  w=(+0.1000, -0.1500)  L=4.6175  |∇L|=4.8507
第  2步  w=(+0.1900, -0.2725)  L=3.4227  |∇L|=4.1287
第  6步  w=(+0.6795, -0.8104)  L=1.8537  |∇L|=2.8256
第 21步  w=(+1.8125, -0.9806)  L=0.0363  |∇L|=0.3909
第 50步  w=(+1.9998, -0.9998)  L=0.0000  |∇L|=0.0007
```

50 步之内，盲人从 $(0,0)$ 走到了 $(2, -1)$ 附近，损失从 10 降到 $10^{-9}$。下面把每一行拆开看——这既是 §3.1 的导论，也是本章全部代码的共同骨架。

## 层二：分步逐函数拆解

### 步骤 1：定义 `loss` —— 一座只有两个变量的损失曲面

```python
def loss(w):
    w1, w2 = w[0], w[1]
    return (w1 - 2.0) ** 2 + 3.0 * (w2 + 1.0) ** 2
```

#### `loss(w)` —— 把权重向量映射成一个标量损失

`return (w1 - 2.0) ** 2 + 3.0 * (w2 + 1.0) ** 2`

**做什么**：给定两个权重 $(w_1, w_2)$，算出模型当前的"错误程度"。它在 $(w_1, w_2) = (2, -1)$ 处取得最小值 0——这是谷底。这个函数是教科书式的最小二乘形式：每个维度的偏差平方，再加权。
**操作**：`w[0]`、`w[1]` 从权重向量里取出两个分量；各自减去目标值后平方；`w2` 项前面乘了 3，把椭圆在 $w_2$ 方向拉长——这座碗在 $w_2$ 方向更陡。
**输入**：`w`——长度为 2 的一维数组 `[w1, w2]`，代表模型的两个权重。本例中对应一个"只有两个参数"的简化网络。
**输出**：一个标量，非负，当且仅当 $w=(2,-1)$ 时为 0。越远离谷底，损失越大。
**可调参数**：
- 两个目标值 `2.0` 与 `-1.0`：谷底的位置。把 `2.0` 改成 `0.0`，谷底移到 $w_1=0$。
- 系数 `3.0`：控制 $w_2$ 方向的陡峭程度。改成 `1.0` 就是圆形碗，改成 `10.0`，$w_2$ 方向会陡 10 倍——梯度下降在陡方向的步幅会更大。
- 能不能加第三个维度？完全可以——把 `w` 扩成 `[w1, w2, w3]`，再补一项 `(w3 - w3_target)**2`。**神经网络的损失函数就是这种形式的上百万维版本。**

**对应数学**：主线里那座"损失山谷" $L(\mathbf{w})$ 的 2D 实现。现实中 $L$ 依赖上百万个权重，这里只取两个，好让我们能亲眼"看"到它。

---

### 步骤 2：定义 `grad_loss` —— 两个偏导数装进一个向量

```python
def grad_loss(w):
    w1, w2 = w[0], w[1]
    dL_dw1 = 2.0 * (w1 - 2.0)
    dL_dw2 = 6.0 * (w2 + 1.0)
    return np.array([dL_dw1, dL_dw2])
```

#### `grad_loss(w)` —— 计算梯度向量 $\nabla L$

`return np.array([2.0 * (w1 - 2.0), 6.0 * (w2 + 1.0)])`

**做什么**：算出"脚下这一点"的坡度。梯度是一个二维向量，每个分量是一个**偏导数**——$\partial L / \partial w_1$ 只让 $w_1$ 动、把 $w_2$ 当常数；$\partial L / \partial w_2$ 反之。
**操作**：对 $L = (w_1-2)^2 + 3(w_2+1)^2$ 逐项求偏导。对 $w_1$：$w_2$ 那一项是常数、导数为 0，剩下 $2(w_1-2)$；对 $w_2$：$w_1$ 项是常数，剩下 $3 \cdot 2(w_2+1) = 6(w_2+1)$。注意系数 3 在求导时被"搬"到了导数前面——所以 $w_2$ 方向的偏导是 6 而不是 3。
**输入**：`w`——形状 `(2,)` 的权重向量。
**输出**：形状 `(2,)` 的梯度向量。每个分量的**符号**告诉我们该朝哪个方向：在 $w_1=0$ 处 $\partial L/\partial w_1 = -4 < 0$，说明增大 $w_1$ 会让损失**下降**——所以要走 $+w_1$ 方向；**符号相反的那一半就是下山方向**。
**可调参数**：无独立参数——梯度完全由 `loss` 决定。改 `loss` 的系数，这里的偏导随之改变。真实的深度学习里，这个函数由反向传播自动计算，我们手写的偏导正是它背后的数学。
**对应数学**：§3.2 的偏导数 + §3.4 的梯度 $\nabla L = \left(\frac{\partial L}{\partial w_1}, \frac{\partial L}{\partial w_2}\right)$。输出里 `|∇L|` 是 $\|\nabla L\|_2 = \sqrt{(2(w_1-2))^2 + (6(w_2+1))^2}$——梯度的长度代表"最陡方向的陡峭程度"。

---

### 步骤 3：定义 `gradient_descent` —— 盲人下山的循环

```python
def gradient_descent(w0, lr, n_steps):
    w = np.array(w0, dtype=float)
    path = [w.copy()]
    for _ in range(n_steps):
        g = grad_loss(w)
        w = w - lr * g
        path.append(w.copy())
    return w, path
```

#### `gradient_descent(w0, lr, n_steps)` —— 核心更新规则 $w \leftarrow w - \eta \nabla L$

`w = w - lr * g`

**做什么**：执行主线的盲人下山循环——重复"测坡度 → 朝下降方向迈步"。每一步的核心就一行：`w = w - lr * g`，即 $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla L(\mathbf{w}_t)$。
**操作**：`grad_loss(w)` 算当前点的梯度（坡度）；`lr * g` 把梯度按学习率缩放成"这一步的步长和方向"；`w - lr * g` 从当前位置减去它——减，因为梯度指向上坡，我们要去的是下坡。`path` 列表每次 `append(w.copy())` 存下当前位置快照（用 `.copy()` 是为了避免后续修改 `w` 时污染已存的轨迹）。
**输入**：
- `w0`：起始位置，形状 `(2,)` 的数组或列表——盲人最初站的地方。这里取 `[0.0, 0.0]`。
- `lr`（学习率，learning rate）$\eta$：标量，决定每步迈多大。它是整个深度学习中最重要的超参数之一。
- `n_steps`：迭代步数，标量整数——盲人一共迈多少步。
**输出**：两个值——`w_final`（终点权重，形状 `(2,)`）和 `path`（长度为 `n_steps+1` 的列表，记录每一步的位置，用于回看盲人的脚印）。
**可调参数**：
- `lr`：主旋钮。太小（如 `0.001`），50 步走不到谷底，损失还很大；太大（如 `0.5`），步长越过谷底、在两边来回震荡甚至发散。你可以试试 `lr=0.5` 看 `|∇L|` 是否会反复横跳。
- `n_steps`：步数上限。本例 50 步足够，因为椭圆碗平滑；真实模型要几万到几百万步。
- `w0`：起始点。从不同位置出发，会走出不同的轨迹，但在这座单谷的碗里，终点都一样——因为只有一个谷底。注意：**这正是 §3.4 边界声明的主题**，真实损失曲面有多个谷底，起点决定终点。
- 能不能加参数？可以——真实优化器还有动量（momentum）、自适应学习率（Adam）等额外参数，它们都是在这个骨架上的增强。
**对应数学**：主线第三步的更新规则 $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla L(\mathbf{w}_t)$，正是 §3.5.1 梯度下降的定义。

---

### 步骤 4：运行与抽查 —— 看盲人的脚印

```python
w_final, path = gradient_descent([0.0, 0.0], lr=0.05, n_steps=50)
for i in [0, 1, 5, 20, 49]:
    wi = path[i]
    print(f"第{i+1:>3}步  w=({wi[0]:+.4f}, {wi[1]:+.4f})  L={loss(wi):.4f}  |∇L|={np.linalg.norm(grad_loss(wi)):.4f}")
```

**做什么**：先跑完整条下山路，再挑 5 个关键时间点（第 1、2、6、21、50 步）打印盲人当时的位置、损失与梯度长度。
**操作**：`gradient_descent(...)` 返回终点与轨迹；`path[i]` 取出第 $i$ 步的位置快照；`np.linalg.norm(...)` 计算向量的 L2 范数（长度）——这里就是梯度的大小 $|\nabla L|$。f-string 里的 `:+.4f` 把数字格式化为带正负号、保留 4 位小数。
**输入**：起始点 `[0.0, 0.0]`、学习率 `0.05`、步数 `50`；抽查的下标 `[0, 1, 5, 20, 49]`。
**输出**：5 行轨迹记录。观察它——损失从 4.6175 一路降到 $10^{-9}$，梯度长度从 4.8507 缩到 0.0007。**离谷底越近，坡度越平，梯度越小**——这是梯度下降收敛的特征指纹。
**可调参数**：抽查哪些步可以自由换。可以打印全部 50 步看完整轨迹，也可以改用 `loss(wi)` 单独看损失随步数的衰减曲线。
**对应数学**：梯度为零是局部极小（或鞍点）的必要条件——第 50 步 `|∇L|≈0.0007` 就是"已经几乎抵达谷底"的数值证据，对应主线"梯度是照亮脚下的灯"那句比喻的数值化。

## 改个数字试试：把学习率推向极端

参数不是固定的。下面两个实验，把学习率 $\eta$ 往两个方向推，看盲人怎么走——这是理解"学习率为什么重要"最直接的方式。

### 实验 1：$\eta = 0.5$ —— 步子迈太大，越过头

```python
w_final, path = gradient_descent([0.0, 0.0], lr=0.5, n_steps=20)
for i in [0, 1, 2, 3, 19]:
    wi = path[i]
    print(f"第{i+1:>3}步  w=({wi[0]:+.4f}, {wi[1]:+.4f})  L={loss(wi):.4f}")
```

输出：

```text
第  1步  w=(+1.0000, -1.0000)  L=1.0000
第  2步  w=(+1.5000, -1.0000)  L=0.2500
第  3步  w=(+1.7500, -1.0000)  L=0.0625
第  4步  w=(+1.8750, -1.0000)  L=0.0156
第 20步  w=(+2.0000, -1.0000)  L=0.0000
```

$\eta=0.5$ 时 $w_1$ 每步恰好减半地逼近 2，$w_2$ 更是一步跳进谷底——因为 $w_2$ 方向的偏导是 $6$，步长 $0.5 \times 6 = 3$ 恰好把 $w_2=-1$ 一步送到。本例恰好幸运；若 $\eta > 1$（如 1.5），$w_1$ 会在 2 两侧来回反弹、越弹越远——**发散**。你可以试试：$lr=1.5$ 时损失会一路涨上去。

### 实验 2：$\eta = 0.005$ —— 步子迈太小，50 步不够

```python
w_final, path = gradient_descent([0.0, 0.0], lr=0.005, n_steps=50)
print(f"终点 w = ({w_final[0]:.4f}, {w_final[1]:.4f})  L = {loss(w_final):.6f}")
```

输出：

```text
终点 w = (0.6402, -0.7158)  L = 2.091557
```

$\eta=0.005$ 时，50 步只走了全程的一小半——损失还停在 2.09。不是方法错了，是**步数预算不够**。把 `n_steps` 改成 500，同样能到谷底。这是深度学习里的一个经典权衡：学习率小则稳但慢，大则快但险。**学习率的量级，往往决定一个模型能不能训练起来。**

## 边界声明：这套代码能做什么，不能做什么

1. **这是二维玩具，不是真实模型。** 真实的损失函数依赖上百万个权重、是上百万维的曲面，无法打印、无法可视化。但这个二维碗保留了真实损失曲面的全部关键结构——唯一谷底、平滑下降、梯度为零处收敛——所以它是理解本章一切概念的最小舞台。
2. **这座碗只有一个谷底。** 主线里反复警告的"局部最优 vs 全局最优"问题，在这个例子里不存在——因为这是一座干净的椭圆碗。真实的损失曲面有鞍点、有多个洼地，梯度下降可能被困在浅洼里。这座二维碗是**理想化的**，它的作用是把"坡度 → 梯度 → 迈步"的机制讲清楚，而不是模拟真实的险峻地貌。
3. **偏导数是手算的。** 这个脚本里 `grad_loss` 是我们对二次函数手工求导写死的。真实模型里，梯度由**自动微分 (automatic differentiation)** 按链式法则算出——那是 §3.5.2 反向传播和 §3.6 Jacobian 的故事。本脚本让你先看懂"梯度是什么、怎么用"，再看懂"梯度是怎么被高效算出来的"。
4. **数值上"到了谷底"不等于解析精确。** 第 50 步 $L=9 \times 10^{-10}$，不是严格 0——梯度下降是迭代逼近，不是一步到位的解方程。对训练而言这个精度绰绰有余；但要真正**求根**（解出方程组），§3.6.3 的牛顿法会给我们更快的工具。
