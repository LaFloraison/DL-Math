# 习题：分层随机采样

## 第一组：概念检验

**1. 写出分层采样的样本量公式，并用教材例（1000 学生：200/300/250/250，$n=100$）算出每层应抽人数。**

**解答**：$n_h=\frac{N_h}{N}\times n$。大一 $\frac{200}{1000}\times100=20$、大二 $\frac{300}{1000}\times100=30$、大三 $\frac{250}{1000}\times100=25$、大四 $25$。**每层按占比分配，保证各年级都被覆盖且占比与全校一致。**

**2. 为什么"层间差异显著时，分层比同规模 SRS 更精确"？给出数学原因。**

**解答**：SRS 的方差 $\mathrm{Var}(\bar X)=\sigma^2/n$ 把"层间差异"混进 $\sigma^2$ 当噪声承担；分层采样的方差 $\mathrm{Var}(\bar X_{strat})=\sum_h(\frac{N_h}{N})^2\frac{\sigma_h^2}{n_h}$ **只含层内方差，层间差异被结构性剔除**。当层间差异显著时，被剔除的部分很大，所以分层误差明显更小——这就是"免费精度"：不花更多样本，只花更聪明的分法。

**3. 判断题并说明理由："分层采样总是比 SRS 精确，所以永远该用分层。"**

**解答**：错误。分层的收益与层间差异成正比：层间差异大才赢，层间相近时打平甚至更差（额外付出分层复杂性、小层样本量小）。而且分层的前提是**层分得准**——如果层内依然高度异质、层间却相近，分层白费功夫。教材明确提醒分层"实现更复杂，需要仔细识别和分离层"。**分得好才赢，分得差白费。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 总体 10000 人，分两层：层 0 占 90%（均值 30）、层 1 占 10%（均值 800）。（a）总体真实均值？（b）抽 100 人按比例分层，每层抽多少？（c）用代码比较分层与 SRS 的估计标准差，说明谁更准、为什么。

**解答**：
（a）$\mu=0.9\times30+0.1\times800=27+80=107$。
（b）层 0 抽 $\frac{9000}{10000}\times100=90$ 人，层 1 抽 10 人。
（c）见《代码.md》步骤 3：SRS 标准差≈12.9、分层≈4.2——**分层误差约为 SRS 的 1/3**。因为层间差异（30 vs 800）巨大，SRS 把这差异当误差，分层把它从误差里剔除了。

代码验证：

```python
import numpy as np
np.random.seed(0)
p0 = np.random.normal(30, 5, 9000); p1 = np.random.normal(800, 50, 1000)
pp = np.concatenate([p0, p1])
srs = np.std([np.random.choice(pp, 100).mean() for _ in range(2000)])
strat = np.std([(0.9*np.random.choice(p0, 90).mean() + 0.1*np.random.choice(p1, 10).mean())
                for _ in range(2000)])
print("SRS 标准差 =", round(srs, 2), " 分层标准差 =", round(strat, 2))
```

输出：

```text
SRS 标准差 = 12.91  分层标准差 = 4.20
```

**思路点拨**：若有人答"分层和 SRS 一样准"，他忽略了"层间差异"这个前提——在层间均值相近时两者才打平；层间差 770 时分层碾压。若有人答"分层标准差应该更小，因为样本量更大"，样本量相同（都 100）——优势来自"结构"，不是"量"。

**5. 分层收益消失实验。** 把两层的均值差从 770 缩到 20，用代码比较 SRS 与分层的标准差，得出结论：分层的价值与什么成正比？

**解答**：见《代码.md》"改个数字试试"。均值差 770 时分层 4.2 vs SRS 12.9；缩到 20 时两者打平（约 5.3 vs 5.4）。**结论：分层收益与层间差异成正比——层越不同，分层越值得。**

## 第三组：DL 延伸

**6. 类别不均衡场景。** 二分类医疗数据，阳性占 2%。你要划分训练/测试集并设计 batch。（a）为什么纯随机划分可能让测试结果不可靠？（b）`train_test_split(stratify=y)` 在做什么？（c）训练时按类分层建 batch 的好处是什么？

**解答**：
（a）阳性只占 2%，纯随机划分（SRS）下测试集里阳性可能极少甚至没有——此时"查全率、查准率"这些指标由极少数样本决定，方差爆炸，结果不可靠。这正是"等概率会漏稀有子群"的深度网络版。
（b）`stratify=y` 按类别标签分层——把"类"当层，$n_h=\frac{N_h}{N}n$ 保证训练集和测试集里阳性都约占 2%。**教材分层公式 $n_h=\frac{N_h}{N}n$ 在 sklearn 的一行调用。**
（c）分层 batch 保证每个 mini-batch 都含约 2% 阳性——梯度估计里稀有类始终有代表，避免某些 batch 全是阴性导致模型对阳性"失忆"。**每个 batch 都是总体的缩小版，训练更稳。**
**思路点拨**：若有人答"随机划分就行，反正大数定律"，大数定律管"平均"，不管"这一次划分"——2% 的稀有类在有限样本里可能恰好失衡。若有人答"分层 batch 就是数据增强"，那是混淆——分层是"分配样本"，增强是"造样本"，两者都是对付类别不均衡，但手段不同。
