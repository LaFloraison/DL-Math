# 习题：反向传播

## 一、概念检验

### 题 1.1（填空）

反向传播的两个阶段是____和____。它计算损失对每个权重偏导所依赖的核心定律是____。梯度计算的顺序是____方向，因为每一层的梯度依赖____层的量。

**解答**：前向传播（forward）；反向传播（backward）；链式法则（chain rule）；输出向输入（往回）；更上（输出）层。
**思路点拨**：第二空是本节灵魂——反向传播没有任何"新"数学，就是链式法则的复用。最后两空连起来回答"为什么不能正向算梯度"：$\partial L/\partial a_\ell$ 依赖 $\partial L/\partial a_{\ell+1}$，那是更上层的量，只能从输出层往回递归。答"从输入算起"就说明没看懂递归结构。

### 题 1.2（选择）

对第 $\ell$ 层的权重，链式法则展开为 $\dfrac{\partial L}{\partial w_\ell} = \dfrac{\partial L}{\partial a_\ell} \cdot \dfrac{\partial a_\ell}{\partial z_\ell} \cdot \dfrac{\partial z_\ell}{\partial w_\ell}$。其中 $\dfrac{\partial a_\ell}{\partial z_\ell}$ 对应（ ）

A. 损失对激活的敏感度
B. 激活函数在 $z_\ell$ 处的导数 $\sigma'(z_\ell)$
C. 预激活对权重的敏感度
D. 激活值本身

**解答**：B。
**思路点拨**：$a_\ell = \sigma(z_\ell)$，所以 $\partial a_\ell/\partial z_\ell = \sigma'(z_\ell)$——激活函数在预激活处的斜率，对应流水线里"这一站对上一站的影响系数"。A 是第一项 $\partial L/\partial a_\ell$；C 是第三项 $\partial z_\ell/\partial w_\ell$（它等于 $a_{\ell-1}$，即输入激活）。三个因子各司其职：**敏感度（上层的）→ 激活斜率 → 权重系数**。

### 题 1.3（简答）

为什么说反向传播"便宜"？它比"对每个权重做数值差分"省了多少？

**解答**：因为中间量复用。反向传播只需要**一次前向 + 一次反向**，总成本约等于两次前向的量级，**与权重数量无关**。而逐权重数值差分每个权重要两次前向——$n$ 个权重要 $2n$ 次前向。对几千亿权重的模型，反向传播便宜几千亿倍：一个把"不可计算"变成"可计算"的差别。省下的根本原因，是中间量 $\partial L/\partial a_\ell$ 被该层所有权重共享（算一次、用多次）。
**思路点拨**：关键词是"复用"与"与权重数无关"。只答"快"不够——要说出**为什么**快：反向传播把每个中间量只算一次，而数值差分把每次前向都重算。这是动态规划思想在微分里的体现，也是反向传播能撑起大模型的根本原因。

## 二、计算实践

### 题 2.1（手算）

三层网络（每层 1 个神经元，$\sigma(z) = z$，无偏置）。$a_0 = 1$，$w_1 = 2$，$w_2 = 3$，$w_3 = 4$，损失 $L = \frac{1}{2}(a_3 - y)^2$，$y = 0$。

(a) 前向算出 $z_1, a_1, z_2, a_2, z_3, a_3$。
(b) 反向算出 $\partial L/\partial w_3$、$\partial L/\partial w_2$、$\partial L/\partial w_1$。
(c) 用直接求导验证 $w_1$ 的梯度。

**解答**：(a) $z_1 = 2, a_1 = 2$；$z_2 = 6, a_2 = 6$；$z_3 = 24, a_3 = 24$；$L = \frac{1}{2} \cdot 24^2 = 288$。
(b) $\partial L/\partial a_3 = a_3 - y = 24$。$\partial L/\partial w_3 = 24 \cdot 1 \cdot a_2 = 24 \cdot 6 = 144$。传回 $\partial L/\partial a_2 = 24 \cdot w_3 = 96$，$\partial L/\partial w_2 = 96 \cdot a_1 = 192$。传回 $\partial L/\partial a_1 = 96 \cdot w_2 = 288$，$\partial L/\partial w_1 = 288 \cdot a_0 = 288$。
(c) $a_3 = w_1 w_2 w_3$，$L = \frac{1}{2}(w_1 w_2 w_3)^2$，$\partial L/\partial w_1 = w_1 w_2^2 w_3^2 = 2 \cdot 9 \cdot 16 = 288$。一致。
**思路点拨**：注意 (b) 中"传回"那一步：$\partial L/\partial a_{\ell} = \partial L/\partial a_{\ell+1} \cdot \sigma'(z_{\ell+1}) \cdot w_{\ell+1}$——每往回一层，要乘上**更上层的权重**。手算一遍你就掌握了两件事：前向的 $a$ 都要记住（反向要用），反向的方向严格从输出往回。想验证，把 $\sigma(z)=z$ 换成 $\sigma=\tanh$，用《代码.md》的 `dL_da1 = W2.T @ dL_dz2` 模式重做。

### 题 2.2（代码验证）

用 NumPy 写一个"梯度检查"：对 $f(w) = \sin(w_1 w_2) + w_2^2$ 在 $(w_1, w_2) = (1, 2)$ 处，用解析导数与中心差分对照。

```python
import numpy as np
w = np.array([1.0, 2.0])
def f(w): return np.sin(w[0]*w[1]) + w[1]**2
# 解析梯度
g = np.array([w[1]*np.cos(w[0]*w[1]), w[0]*np.cos(w[0]*w[1]) + 2*w[1]])
# 数值梯度（中心差分）
h = 1e-6
gn = np.array([
    (f(w + np.array([h,0])) - f(w - np.array([h,0]))) / (2*h),
    (f(w + np.array([0,h])) - f(w - np.array([0,h]))) / (2*h)])
print(f"解析 {g}  数值 {gn}  相对误差 {np.linalg.norm(g-gn)/(np.linalg.norm(g)+1e-12):.2e}")
```

**解答**：解析梯度 $(\cos 2 \cdot 2,\ \cos 2 \cdot 1 + 4) \approx (-0.8323, 3.5839)$；数值梯度与之一致，相对误差约 $10^{-7}$ 量级。
**思路点拨**：这道题把《代码.md》的梯度检查提炼到最小——一个复合函数、两条路径（解析链式 vs 数值定义）互相验收。把 `h` 改成 `1e-3` 和 `1e-10` 各跑一次，观察相对误差先降后升（U 形曲线）——你就完整地复现了"为什么梯度检查用 $h\approx 10^{-6}$"。

## 三、DL 延伸

### 题 3.1

工程师手写了一个反向传播，但梯度检查显示 $\partial L/\partial W_1$ 的相对误差达到 $10^{-2}$，其余参数误差都在 $10^{-7}$。请推断最可能的 bug 位置，并给出排查方向。

**解答**：只有 `W1` 出错而其它正常，说明 bug 大概率在**第 1 层与第 2 层之间的传回**（即 $\partial L/\partial a_1 = W_2^\top \partial L/\partial z_2$ 这一行）或 `dL_dW1 = outer(dL_dz1, x)` 这一行——比如转置写漏（用了 `W2 @` 而不是 `W2.T @`）、`outer` 的参数顺序反了、或 `dL_dz1` 用了缓存错误的 `z1`。排查方向：打印每一行中间量（`dL_dz1`、`dL_da1`），与手算/单独验证对比；确认 `W2.T` 的形状是否匹配（`(2,1)@(1,)`）。
**思路点拨**：**梯度检查的定位价值**在于按参数隔离错误——只有 `W1` 错，就把嫌疑锁定在第 1 层的上游传回。这是真实工程里定位 autograd bug 的标准思路：逐层打中间量，二分定位。能想到"转置方向"这个高频 bug，就说明你理解了 `dL_da1 = W2.T @ dL_dz2` 的形状逻辑。

### 题 3.2

一个 50 层网络的损失函数通过反向传播计算梯度后，发现第 1 层的梯度范数比第 50 层小了 8 个数量级。请解释现象、指出病因，并给出两条缓解手段（结合 §3.5 与本节知识）。

**解答**：现象是**梯度消失**的典型测量——浅层梯度远小于深层。病因是反向传播的链式乘积：$\partial L/\partial W_1$ 要乘以 49 个相邻层的局部导数；若激活在饱和区（如 tanh/sigmoid），$\sigma' < 1$，连乘指数坍缩。缓解：① 换 ReLU（正区导数恒 1，乘积不衰减）；② 加残差连接/直通路径（让梯度不必经过全部连乘，像 LSTM 的记忆线）；③ 配合合适的初始化（如 He）与归一化，避免激活进入饱和区。
**思路点拨**：这道题把 §3.5（消失梯度）与 §3.5.2（链式乘积是载体）缝合起来。能说出"反向传播的连乘是载体、饱和激活是诱因"，就完成了两个小节的连接。真实项目里"浅层梯度远小于深层"就是反向传播现场的直接证据。
