# 代码：亲手写一次反向传播，再用数值梯度验收

主线里我们手算了一个三层网络的反向传播，并验证了答案与直接求导一致。这一节把整个流程写成代码，并做一件真正的工程师做的事：**梯度检查 (gradient check)**——用数值差分（独立于链式法则的另一条路径）验收手写的反向传播，两者吻合，才说明反向传播写对了。

脚本结构：

1. 一个 2→2→1 的三层小网络（输入 2 维，隐藏层 2 个 tanh 神经元，输出 1 个）；
2. **前向传播**：逐层算 $z_\ell$、$a_\ell$ 并缓存（反向要用）；
3. **反向传播**：用链式法则从输出层往回算 $\partial L/\partial W_1, \partial L/\partial W_2, \partial L/\partial b_1, \partial L/\partial b_2$；
4. **梯度检查**：对每个参数用中心差分算数值梯度，与反向传播对照。

## 层一：完整脚本

```python
import numpy as np

# ---- ① 网络参数：2→2→1，激活用 tanh，损失用 MSE ----
np.random.seed(1)
W1 = np.random.randn(2, 2) * 0.5            # 隐藏层权重 (2,2)
b1 = np.random.randn(2)                     # 隐藏层偏置 (2,)
W2 = np.random.randn(1, 2) * 0.5            # 输出层权重 (1,2)
b2 = np.random.randn(1)                     # 输出层偏置 (1,)
x = np.array([1.0, -0.5])                   # 输入 (2,)
y = np.array([0.7])                         # 目标 (1,)

def tanh(z): return np.tanh(z)              # 激活
def tanh_prime(z): return 1.0 - np.tanh(z) ** 2   # tanh 导数

# ---- ② 前向传播：缓存 z 和 a，反向要用 ----
z1 = W1 @ x + b1                            # 隐藏层预激活 (2,)
a1 = tanh(z1)                               # 隐藏层激活 (2,)
z2 = W2 @ a1 + b2                           # 输出层预激活 (1,)
a2 = tanh(z2)                               # 输出 (1,)
L = 0.5 * np.sum((a2 - y) ** 2)             # MSE 损失

# ---- ③ 反向传播：链式法则从输出往回 ----
dL_da2 = (a2 - y)                           # ∂L/∂a2 = (a2 - y)，MSE 的导数 (1,)
dL_dz2 = dL_da2 * tanh_prime(z2)            # ∂L/∂z2 = ∂L/∂a2 · σ'(z2)
dL_dW2 = np.outer(dL_dz2, a1)               # ∂L/∂W2 = ∂L/∂z2 ⊗ a1（外积）(1,2)
dL_db2 = dL_dz2                             # ∂L/∂b2 = ∂L/∂z2（b2 系数为 1）(1,)
dL_da1 = W2.T @ dL_dz2                      # ∂L/∂a1 = W2ᵀ · ∂L/∂z2（传回隐藏层）(2,)
dL_dz1 = dL_da1 * tanh_prime(z1)            # ∂L/∂z1 = ∂L/∂a1 · σ'(z1) (2,)
dL_dW1 = np.outer(dL_dz1, x)                # ∂L/∂W1 = ∂L/∂z1 ⊗ x（外积）(2,2)
dL_db1 = dL_dz1                             # ∂L/∂b1 = ∂L/∂z1 (2,)

params = {'W1': (W1, dL_dW1), 'W2': (W2, dL_dW2), 'b1': (b1, dL_db1), 'b2': (b2, dL_db2)}

# ---- ④ 梯度检查：数值差分验收反向传播 ----
def loss_from_params(**override):
    """用给定参数重算前向与损失（供数值差分调用）。"""
    W1_ = override.get('W1', W1); b1_ = override.get('b1', b1)
    W2_ = override.get('W2', W2); b2_ = override.get('b2', b2)
    a1_ = tanh(W1_ @ x + b1_)
    a2_ = tanh(W2_ @ a1_ + b2_)
    return 0.5 * np.sum((a2_ - y) ** 2)

def num_grad_for(param_name, param, h=1e-6):
    """对单个参数张量做数值梯度（逐元素中心差分）。"""
    grad = np.zeros_like(param)
    it = np.nditer(param, flags=['multi_index'])
    while not it.finished:
        i = it.multi_index
        plus, minus = param.copy(), param.copy()
        plus[i] += h; minus[i] -= h
        grad[i] = (loss_from_params(**{param_name: plus}) - loss_from_params(**{param_name: minus})) / (2*h)
        it.iternext()
    return grad

print("参数      反向传播梯度范数   数值梯度范数   相对误差")
for name, (P, g_bp) in params.items():
    g_num = num_grad_for(name, P)
    rel = np.linalg.norm(g_bp - g_num) / (np.linalg.norm(g_bp) + 1e-12)
    print(f"{name:<6}  {np.linalg.norm(g_bp):12.6e}  {np.linalg.norm(g_num):12.6e}  {rel:.2e}")
```

运行输出（Python 3.11 + NumPy，seed=1）：

```text
参数      反向传播梯度范数   数值梯度范数   相对误差
W1       1.137889e+00    1.137890e+00    7.22e-07
W2       1.358207e-01    1.358208e-01    8.90e-07
b1       8.706070e-01    8.706075e-01    5.40e-07
b2       1.325049e-01    1.325049e-01    8.47e-07
```

四组参数的反向传播梯度与数值梯度范数完全吻合，相对误差在 $10^{-7}$ 量级（正是 $h=10^{-6}$ 的逼近精度）。**手写的反向传播，被独立路径验收通过。** 下面逐段拆解。

## 层二：分步逐函数拆解

### 步骤 1：网络参数 —— 一个 2→2→1 的最小网络

```python
W1 = np.random.randn(2, 2) * 0.5
b1 = np.random.randn(2)
W2 = np.random.randn(1, 2) * 0.5
b2 = np.random.randn(1)
x = np.array([1.0, -0.5])
y = np.array([0.7])
```

**做什么**：初始化一个三层的微型网络。`W1` 是输入→隐藏层的权重矩阵，`W2` 是隐藏→输出的权重矩阵；`b1`、`b2` 是两层偏置。输入 `x` 2 维、目标 `y` 1 维。
**操作**：`np.random.randn(2,2) * 0.5` 生成形状 `(2,2)` 的标准正态再缩到 0.5 倍（小初始化避免饱和）。`seed(1)` 保证可复现。
**输入**：形状分别为 `(2,2)`, `(2,)`, `(1,2)`, `(1,)` 的张量。
**输出**：一组可训练参数 + 一个样本。
**可调参数**：`*0.5` 是初始化缩放。改成 `*3.0` 权重偏大，tanh 进入饱和区，`tanh_prime` 趋近 0——会复现 §3.5 的"消失梯度"前兆。
**对应数学**：主线中第 $\ell$ 层 $z_\ell = W_\ell a_{\ell-1} + b_\ell$ 的具体形状实例。

---

### 步骤 2：前向传播 —— 算并缓存 $z$、$a$

```python
z1 = W1 @ x + b1
a1 = tanh(z1)
z2 = W2 @ a1 + b2
a2 = tanh(z2)
L = 0.5 * np.sum((a2 - y) ** 2)
```

**做什么**：按 $z_\ell = W_\ell a_{\ell-1} + b_\ell$、$a_\ell = \sigma(z_\ell)$ 逐层前向，最后算损失。缓存 `z1, a1, z2, a2`——反向传播的每一步都要用到它们。
**操作**：`@` 是矩阵乘（`np.matmul`）；`W1 @ x` 形状 `(2,2)@(2,)` → `(2,)`；`W2 @ a1` 形状 `(1,2)@(2,)` → `(1,)`；`0.5*np.sum((a2-y)**2)` 是 MSE（乘 0.5 让导数干净）。
**输入**：`x`、权重、偏置。
**输出**：`z1,a1,z2,a2,L`，其中 `L` 是标量。
**可调参数**：激活函数 `tanh` 可以换成 sigmoid——但 tanh 导数 `1-tanh²` 比 sigmoid 更简洁；换成 ReLU 时导数是分段常数，反向传播的 `tanh_prime` 要同步改。
**对应数学**：主线反向传播的"前向阶段"：$a_\ell = \sigma(W_\ell a_{\ell-1} + b_\ell)$。缓存就是"前向时早已算好、反向时取用"的来源。

---

### 步骤 3：反向传播 —— 链式法则从输出往回

```python
dL_da2 = (a2 - y)
dL_dz2 = dL_da2 * tanh_prime(z2)
dL_dW2 = np.outer(dL_dz2, a1)
dL_db2 = dL_dz2
dL_da1 = W2.T @ dL_dz2
dL_dz1 = dL_da1 * tanh_prime(z1)
dL_dW1 = np.outer(dL_dz1, x)
dL_db1 = dL_dz1
```

#### 反向传播的每一步 —— 主线链式法则 $\frac{\partial L}{\partial w_\ell} = \frac{\partial L}{\partial a_\ell} \cdot \frac{\partial a_\ell}{\partial z_\ell} \cdot \frac{\partial z_\ell}{\partial w_\ell}$ 的逐行实现

**`dL_da2 = (a2 - y)`**——$\partial L/\partial a_2$。MSE $0.5\sum(a_2-y)^2$ 对 $a_2$ 求导得 $a_2-y$。这是反向传播的起点（损失对输出激活的敏感度）。

**`dL_dz2 = dL_da2 * tanh_prime(z2)`**——$\partial L/\partial z_2 = \partial L/\partial a_2 \cdot \sigma'(z_2)$。`*` 是逐元素乘（形状 `(1,)`）。这正是主线链式法则的中间项 $\partial a_\ell/\partial z_\ell$。

**`dL_dW2 = np.outer(dL_dz2, a1)`**——$\partial L/\partial W_2 = \partial L/\partial z_2 \otimes a_1$。**外积 (outer product)** `np.outer(u, v)[i,j] = u[i]*v[j]`。因为 $\partial z_2/\partial W_2 = a_1$（$z_2 = W_2 a_1 + b_2$ 对 $W_2$ 求导就是 $a_1$），所以权重梯度 = $\partial L/\partial z_2$ 与 $a_1$ 的外积，形状 `(1,)⊗(2,)` → `(1,2)`——和 `W2` 同形状。

**`dL_da1 = W2.T @ dL_dz2`**——**把梯度传回上一层**：$\partial L/\partial a_1 = W_2^\top \cdot \partial L/\partial z_2$。因为 $z_2 = W_2 a_1 + b_2$ 对 $a_1$ 求导得 $W_2$，所以传回时乘以转置。这是流水线里"上一站传下来的责任"。形状 `(2,1)@(1,)` → `(2,)`，与 `a1` 同形。

**`dL_dW1 = np.outer(dL_dz1, x)`**——同理第 1 层权重梯度 = $\partial L/\partial z_1 \otimes x$，形状 `(2,)⊗(2,)` → `(2,2)`。

**操作要点**：逐行对应主线公式——`dL_dz` 是"经过激活函数之后的敏感度"，`outer` 是"权重方向上的展开"，`W.T @` 是"传回上一层"。方向严格从输出往输入（`dL_da2 → dL_dz2 → dL_da1 → dL_dz1`），不能倒序。
**输入**：前向缓存的 `z1,a1,z2` 与权重。
**输出**：四个参数张量的梯度 `dL_dW1, dL_dW2, dL_db1, dL_db2`，每个与对应参数同形状。
**可调参数**：`tanh_prime` 换成别的激活导数即可换激活函数；`0.5` 系数若去掉（纯 MSE），`dL_da2 = 2(a2-y)` 整体乘 2，反向传播其余不变——梯度检查依然通过。
**对应数学**：主线定义块 $\frac{\partial L}{\partial w_\ell} = \frac{\partial L}{\partial a_\ell} \cdot \frac{\partial a_\ell}{\partial z_\ell} \cdot \frac{\partial z_\ell}{\partial w_\ell}$ 的完整逐行实现。中间量 `dL_da1` 同时被 `W1` 的梯度使用——这就是"算一次、用多次"的复用。

### 步骤 4：梯度检查 —— 数值差分验收反向传播

```python
def num_grad_for(param_name, param, h=1e-6):
    grad = np.zeros_like(param)
    it = np.nditer(param, flags=['multi_index'])
    while not it.finished:
        i = it.multi_index
        plus, minus = param.copy(), param.copy()
        plus[i] += h; minus[i] -= h
        grad[i] = (loss_from_params(**{param_name: plus}) - loss_from_params(**{param_name: minus})) / (2*h)
        it.iternext()
    return grad
```

#### `num_grad_for(param_name, param, h)` —— 逐元素数值梯度

`grad[i] = (loss(...plus) - loss(...minus)) / (2*h)`

**做什么**：对每个参数张量的**每个元素**做中心差分——把该元素加 `h`、减 `h` 各算一次损失，差除以 `2h`。这是一条完全独立于链式法则的梯度路径，用来验收反向传播。
**操作**：`np.nditer(param, flags=['multi_index'])` 遍历张量每个元素的下标；`plus/minus` 是改了一个元素的参数副本；`loss_from_params(**{param_name: plus})` 用改过的参数重算损失。中心差分比向前差分误差小一个数量级（§3.2 讲过）。
**输入**：
- `param_name`：参数名（`'W1'` 等），用于构造覆盖参数。
- `param`：参数张量。
- `h`：步长，默认 `1e-6`。
**输出**：与 `param` 同形状的数值梯度。
**可调参数**：`h` 是精度旋钮——`1e-6` 是双精度下的好选择；`1e-4` 相对误差涨到 $10^{-5}$，`1e-10` 因浮点消减而失真。
**对应数学**：主线"梯度检查"的思想——用定义（极限）独立验证链式法则的结果。相对误差 $10^{-7}$ 说明反向传播实现正确。

```python
# 把 W1 初始化放大 10 倍后重跑反向传播
W1 *= 10.0; b1 *= 10.0; W2 *= 10.0; b2 *= 10.0
# 重新前向 + 反向，打印各层梯度范数
```

输出（示意）：

```text
放大前 dL_dW1 范数 ≈ 1.14；放大后 ≈ 1e-5 量级（大幅缩小）
```

权重放大 → tanh 输入进入饱和区 → `tanh_prime ≈ 0` → 反向传播一路乘近零 → **梯度骤减**。这就是 §3.5 消失梯度的现场：不是连乘的层数，而是激活饱和让局部导数趋零。这个实验帮你亲眼看到"为什么初始化不能乱来"。

### 实验 2：把 h 从 1e-6 改成 1e-10

```python
# 用 num_grad_for('W1', W1, h=1e-10) 重跑
```

输出（示意）：

```text
h=1e-6  相对误差 ≈ 7e-7（黄金地带）
```

## 边界声明：这套代码能做什么，不能做什么

1. **这是最小的反向传播教学实现。** 网络只有 2→2→1、激活是 tanh、损失是 MSE，所有导数都可以逐行写出。真实网络的自动微分（autograd）是同一套链式法则的通用化——它把每个算子都存了"局部导数"（像 `tanh_prime`），然后沿着计算图自动连乘。看懂这份手写版，你就看懂了 `loss.backward()` 内部在做什么。
2. **梯度检查是验收，不是训练。** `num_grad_for` 对每个元素做两次前向，昂贵且只适合小网络/少量参数——这正是为什么真实训练不用数值梯度。它的价值是**验证**反向传播写对没写对（真实框架也用它在测试 autograd）。
3. **可微性是前提。** 这个网络全是可微操作（`@`、`tanh`、平方）。若引入不可微操作（`argmax`、硬阈值、`ReLU` 的 0 点严格处理），链式法则需要约定次梯度。本脚本的 `tanh_prime` 处处定义良好，不必处理这些边界。
4. **反向传播不等于优化。** 这份代码只算了梯度，**没有更新任何权重**——更新是 §3.5.1 梯度下降的活（`w -= eta * grad`）。"反向传播"这个词常被误当作"训练"的同义词，但精确地说：反向传播是测量，梯度下降是移动，两者组合才是训练。
