# 习题：向量空间

## 第一组：概念检验

**1.1（单选）** 下列哪个集合（配上普通向量加法和数乘）**不是**一个向量空间？
- A. $\mathbb{R}^2$（所有二维向量）
- B. 所有形如 $(x, y)$ 且 $x + y = 0$ 的二维向量
- C. 所有"第一分量等于 1"的二维向量，即 $\{(1, y)\}$
- D. 所有三次多项式 $ax^3 + bx^2 + cx + d$

**1.2（判断并说明）** "向量空间里的向量，一定是几何箭头。" 这句话对吗？教材怎么说？

**1.3（填空）** 向量空间的 8 条公理分两组：____（4 条）和 ____（4 条）。其中保证"运算不把结果丢出空间"的隐含性质叫____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 判断 $\mathbf{w} = [1, 1, 1]$ 是否在 $\text{span}\{\mathbf{u}, \mathbf{v}\}$ 中，其中 $\mathbf{u} = [1, 2, 3]$、$\mathbf{v} = [2, 4, 6]$。先手算推理，再用 `np.linalg.lstsq` 验证。

**2.2（代码验证）** 用代码验证 $\mathbb{R}^3$ 中随机选取的三个向量满足"加法结合律"，把公理写成一个断言，换三组随机向量各跑一遍。

**2.3（动手理解）** 在 $\mathbb{R}^2$ 中，直线 $y = x$ 上的所有点构成一个向量空间，而直线 $y = x + 1$ 上的点不构成。请解释原因，并分别给出一组"空间的代表元"和一组"不属于空间的原因"。

## 第三组：DL 延伸

**3.1（场景判断）** 一个全连接网络有 $10^7$ 个参数。训练过程把参数从初始值 $\mathbf{w}_0$ 更新到 $\mathbf{w}^*$。请说明：$\mathbf{w}_0$、$\mathbf{w}^*$、以及每一步更新量 $\Delta \mathbf{w}$ 都"住在"哪个向量空间？这个空间的维数是多少？

**3.2（场景分析）** 深度学习中常说"优化发生在权重空间，分类发生在特征空间"。请解释这两个"空间"分别对应网络结构的哪一部分，并说明为什么它们都是向量空间。

## 解答与思路点拨

### 第一组

**1.1 答案：C。**
- **思路**：C 不封闭——两个 $(1, y)$ 型向量相加得 $(2, y_1+y_2)$，第一分量是 2 不是 1，**结果不在集合里**；且没有零向量 $(0,0)$（第一分量非 1）。A 是经典向量空间；B 满足封闭（$(x_1,y_1)+(x_2,y_2)$ 的和分量仍满足 $x_1+x_2+y_1+y_2=0$）；D 是多项式向量空间（封闭、含零多项式）。
- **点拨**：判断"是不是向量空间"三步走：**① 含零元吗？② 加法封闭吗？③ 数乘封闭吗？** C 同时违反 ①③，是最标准的反例。

**1.2 不对。**
- **思路**：教材明确说：向量空间里的元素"不一定是几何的"，可以是函数、多项式或其他数学对象，只要遵循定义规则。箭头只是最常见的向量。
- **点拨**："向量 = 箭头"是中学直觉；"向量 = 遵守 8 条公理的对象"是线性代数的抽象。深度学习恰好两者都用：直觉画箭头，抽象管函数空间。

**1.3 答案：加法公理；数乘公理；封闭性。**
- **思路**：8 条公理 = 4 条加法（交换、结合、零元、逆元）+ 4 条数乘（两个分配律、结合、单位元）。封闭性未单列但隐含于定义。
- **点拨**：把"封闭性"当第 0 公理记，它是判断空间与否的第一直觉。

### 第二组

**2.1**
**手算推理**：$\mathbf{v} = [2,4,6] = 2\mathbf{u}$，所以 $\text{span}\{\mathbf{u},\mathbf{v}\} = \text{span}\{\mathbf{u}\}$ 是一条过原点的直线（方向 $[1,2,3]$）。$\mathbf{w} = [1,1,1]$ 不在这个方向上（不成比例），所以**不在** $\text{span}$ 中。

```python
import numpy as np
u = np.array([1.0, 2.0, 3.0]); v = np.array([2.0, 4.0, 6.0]); w = np.array([1.0, 1.0, 1.0])
M = np.stack([u, v], axis=1)
sol, *_ = np.linalg.lstsq(M, w, rcond=None)
print(np.allclose(M @ sol, w, atol=1e-8))   # False
```
- **思路**：$\mathbf{v}=2\mathbf{u}$ 线性相关，张成退化成一维直线。$\mathbf{w}$ 与 $\mathbf{u}$ 不成比例，故不在线上。`lstsq` 给出最小二乘解，重建值不精确等于 $\mathbf{w}$，`allclose` 为 `False`。
- **点拨**：**线性相关**的概念从这里登场——两个成比例的向量"拼不出"二维空间。这正是"维数"的数学来源。

**2.2**
```python
import numpy as np
for _ in range(3):
    u, v, w = [np.random.rand(3) for _ in range(3)]
    assert np.allclose((u+v)+w, u+(v+w))
print("3 组随机向量均满足加法结合律")
```
- **思路**：公理对"任意向量"成立，随机抽样是"抽样验证"。`assert` 把公理写成了可测试的断言。
- **点拨**：代码教学的意义正是把"对任意"变成可观察的循环——但这仍是抽样，不是证明。

**2.3**
- 直线 $y=x$：过原点，加法封闭（$(x_1,x_1)+(x_2,x_2)=(x_1+x_2,x_1+x_2)$，仍满足 $y=x$），数乘封闭，含零元 $(0,0)$ → **是向量空间**。
- 直线 $y=x+1$：**不含零元**（$(0,0)$ 不满足 $0=0+1$），且两点的和 $(x_1+x_2, x_1+x_2+2)$ 不在这条线上 → **不是向量空间**。它是"仿射直线"（平移过的子空间）。
- **点拨**：**"过原点"是向量空间的生死线**。过原点的线/面/超平面是空间，偏离原点的是仿射空间。深度学习里线性层的偏置 $\mathbf{b}$ 正是把超平面"平移"出原点——所以含偏置的超平面不是严格意义的向量空间（是仿射子空间）。

### 第三组

**3.1 答案：它们都住在 $\mathbb{R}^{10^7}$——权重空间，维数 $10^7$。**
- **思路**：所有参数排成一列 $\mathbf{w} \in \mathbb{R}^{10^7}$；初始值 $\mathbf{w}_0$ 是空间里的一个点，最优值 $\mathbf{w}^*$ 是另一个点，更新量 $\Delta\mathbf{w}$ 是从 $\mathbf{w}_0$ 到 $\mathbf{w}^*$ 的位移向量。梯度下降 $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta\nabla L$ 就是在这个空间里"点 + 数乘后的向量"。
- **点拨**：**参数总数 = 权重空间的维数**。这就是为什么"模型多大"常以参数量计——一个 7B 模型住在 $\mathbb{R}^{7\times 10^9}$ 里。梯度下降在这个天文维数空间里"盲人摸坡"，还能收敛，全靠空间结构的线性（§3 微积分会讲梯度）。

**3.2 思路**
- **权重空间**：参数 $\{\mathbf{w}^{(1)}, \mathbf{w}^{(2)}, \dots\}$ 所在的空间。**优化**（梯度下降）发生在这里——找参数让损失最小。
- **特征空间**：中间层激活 $\mathbf{h} = \sigma(W\mathbf{x})$ 所在的空间。**分类/识别**发生在这里——最后一层在此找超平面切分类别。
- **为什么都是向量空间**：参数和激活都可以相加、缩放且结果仍在各自空间——满足 8 条公理（严格说激活常被约束在仿射/有界区域，但数学结构仍是向量空间）。
- **点拨**：这串起来的正是"五根柱子"地图：向量（数据）→ 矩阵（参数）→ 变换（层）→ 而优化与分类，是发生在向量空间里的两场"航行"。§2.3.6 会把这些"航行"的具体运算展开。
