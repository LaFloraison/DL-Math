# 代码：用手"摸"到向量空间的八条公理——封闭性、零元、线性组合

主线里定义了向量空间：集合 + 加法 + 数乘 + 8 条公理。这一节用 NumPy **把公理逐条验算一遍**——不是背条文，而是让每条公理在具体数字上"当场兑现"。核心是理解"封闭性"：运算永远不把结果丢出空间。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：向量运算

# ---- ① 取三个"空间里的点"：随机向量 u, v, w ∈ R³ ----
u = np.array([1.0, 2.0, 0.5])
v = np.array([-3.0, 1.0, 2.0])
w = np.array([0.5, -1.0, 4.0])
print("u, v, w 来自 R³")

# ---- ② 加法公理逐条验证 ----
print("交换律  u+v==v+u :", np.allclose(u+v, v+u))
print("结合律  (u+v)+w==u+(v+w) :", np.allclose((u+v)+w, u+(v+w)))
zero = np.zeros(3)
print("零元    u+0==u   :", np.allclose(u+zero, u))
print("逆元    u+(-u)==0:", np.allclose(u+(-u), zero))

# ---- ③ 数乘公理逐条验证 ----
a, b = 2.0, 3.0
print("向量分配 a(u+v)==au+av:", np.allclose(a*(u+v), a*u+a*v))
print("标量分配 (a+b)u==au+bu:", np.allclose((a+b)*u, a*u+b*u))
print("数乘结合 a(bu)==(ab)u :", np.allclose(a*(b*u), (a*b)*u))
print("单位元    1·u==u      :", np.allclose(1.0*u, u))

# ---- ④ 封闭性：线性组合仍在空间里 ----
combo = 0.3*u + 1.5*v - 2.0*w
print("线性组合 0.3u+1.5v-2w =", np.round(combo, 3), "仍在 R³（3 个分量）")

# ---- ⑤ 张成：用两个向量能拼出多少空间 ----
# 判断 w 是否在 span{u, v} 里：解 u*x + v*y = w（即 3×2 线性系统）
M = np.stack([u, v], axis=1)             # (3,2)，列是 u 和 v
sol, *_ = np.linalg.lstsq(M, w, rcond=None)
recon = M @ sol
print("w 在 span{u,v} 中吗?", np.allclose(recon, w, atol=1e-8))
print("     (若为 True：w 是 u、v 的线性组合，三向量共面)")
```

运行输出（Python 3.11 + NumPy）：

```text
u, v, w 来自 R³
交换律  u+v==v+u : True
结合律  (u+v)+w==u+(v+w) : True
零元    u+0==u   : True
逆元    u+(-u)==0: True
向量分配 a(u+v)==au+av: True
标量分配 (a+b)u==au+bu: True
数乘结合 a(bu)==(ab)u : True
单位元    1·u==u      : True
线性组合 0.3u+1.5v-2w = [-5.15  2.9  -6.65] 仍在 R³（3 个分量）
w 在 span{u,v} 中吗? True
```

8 条公理全部 `True`。下面拆开看。

## 层二：分步逐函数拆解

### 步骤 1：造向量

```python
u = np.array([1.0, 2.0, 0.5])
```

**做什么**：从 $\mathbb{R}^3$ 里取三个"点"。它们是否构成向量空间的一部分，取决于 §④ 的封闭性。
**操作**：`np.array` 造三个 `(3,)` 向量。
**输入**：三个三维列表。
**输出**：三个 `(3,)` 数组。
**可调参数**：换任何数字都行；换成 `np.random.rand(3)` 更"随机"，公理照常成立——这就是抽象的力量：规则与具体数值无关。

### 步骤 2：加法公理

```python
print(np.allclose(u+v, v+u))          # 交换律
print(np.allclose((u+v)+w, u+(v+w)))  # 结合律
print(np.allclose(u+zero, u))         # 零元
print(np.allclose(u+(-u), zero))      # 逆元
```

#### `np.allclose(a, b)` —— 容差比较

**操作**：逐元素比较并允许小误差（浮点舍入）。用 `==` 在浮点上会误报，`allclose` 是判断"数学上相等"的正道。
**输入**：两个同形状数组。
**输出**：布尔值。
**可调参数**：`atol`/`rtol` 控制容差；验证公理时默认足够。
**对应数学**：公理 1-4。`-u` 是 NumPy 对"逐元素取负"的重载——它给出的正是加法逆元。`zero = np.zeros(3)` 是零元。

### 步骤 3：数乘公理

```python
print(np.allclose(a*(u+v), a*u+a*v))  # 向量分配律
print(np.allclose((a+b)*u, a*u+b*u))  # 标量分配律
print(np.allclose(a*(b*u), (a*b)*u))  # 结合律
print(np.allclose(1.0*u, u))          # 单位元
```

**做什么**：验证公理 5-8。`a, b = 2.0, 3.0` 是任取的两个标量。
**操作**：`*` 在"标量×数组"时做逐元素数乘——这正是公理里的数乘。四行代码就是四条公理的直接翻译。
**可调参数**：`a`、`b` 换任何实数（含负数、小数）都成立。这是公理的本质：**对所有标量成立**，不是对某个值成立。
**对应数学**：公理 5-8。注意这里 `*` 是数乘（标量×向量），不是向量×向量的逐元素乘。

### 步骤 4：封闭性——线性组合

```python
combo = 0.3*u + 1.5*v - 2.0*w
```

**做什么**：算出 $0.3\mathbf{u} + 1.5\mathbf{v} - 2\mathbf{w}$，结果仍是 3 个分量的向量——仍在 $\mathbb{R}^3$ 里。
**操作**：数乘（`0.3*u`）+ 加法（`+ 1.5*v`）+ 数乘（`-2.0*w`）。这是 §2.2.1.2 的线性组合的代码形式。
**可调参数**：系数任意。**封闭性的含义就是"无论系数怎么选，结果都在空间里"**。
**对应数学**：主线"线性组合仍在 $V$ 里"。$0.3\mathbf{u}+1.5\mathbf{v}-2\mathbf{w}$ 是三个基向量的一种"混合配方"——深度学习里，这是"特征混合"的雏形。

### 步骤 5：张成——`np.linalg.lstsq`

```python
M = np.stack([u, v], axis=1)
sol, *_ = np.linalg.lstsq(M, w, rcond=None)
recon = M @ sol
print(np.allclose(recon, w, atol=1e-8))
```

#### `np.stack([u, v], axis=1)` —— 把向量拼成矩阵列

**操作**：`u`、`v` 两个 `(3,)` 向量沿轴 1 拼成 `(3,2)` 矩阵，两列分别是 $u$、$v$。这就是"以 $u,v$ 为列向量"的矩阵。
**输入**：两个 `(3,)` 数组。
**输出**：`(3,2)` 数组。
**可调参数**：`axis=0` 拼成两行（`(2,3)`）；列向量布局是矩阵×向量的惯例。§2.3 讲矩阵时"列优先"视角会反复出现。

#### `np.linalg.lstsq(A, b, rcond=None)` —— 最小二乘解线性系统

**操作**：求解 $A\mathbf{x} \approx \mathbf{b}$ 的最小二乘解 $\mathbf{x}$。这里解的是 $M\mathbf{x} = \mathbf{w}$（未知数 $\mathbf{x} = [x_1, x_2]$），即找 $x_1\mathbf{u} + x_2\mathbf{v} = \mathbf{w}$ 的系数。
**输入**：`M`（`(3,2)`）、`w`（`(3,)`）、`rcond=None`（推荐，避免奇异值截断警告）。
**输出**：解 `sol`（形状 `(2,)`）——若 $\mathbf{w}$ 确实在 $\text{span}\{\mathbf{u},\mathbf{v}\}$ 里，则 $M\mathbf{x}=\mathbf{w}$ 精确可解。
**可调参数**：`rcond` 控制奇异值截断阈值；系统超定时默认给最小二乘解。
**对应数学**：主线"张成 (span)"与"矩阵的列空间"。`recon = M @ sol` 重建出 $\mathbf{w}$，`allclose(recon, w)` 为 `True` 说明 $\mathbf{w}$ 是 $u,v$ 的线性组合——三向量共面，$\text{span}\{\mathbf{u},\mathbf{v}\}$ 是一张过原点的平面。若用三个随机向量试 `lstsq`，多数情况下 $\mathbf{w}$ 不在 $\text{span}$ 里（因为两个向量只张成平面，装不下三维空间的任意点）——这就是"维数"的直觉来源。

## 边界声明：这套代码能做什么，不能做什么

1. **公理验证只能"抽样"，不能"证明"**。`allclose` 验证的是"我选的这组数字满足公理"，不是"所有数字都满足"。公理的普适性靠数学证明，不靠代码抽样。但代码能把抽象的"对任意 $u,v$"变成看得见的数字——这是教学意义所在。
2. **有限精度陷阱**。浮点误差会让"理论上相等"变成"数值上差一点"，所以全程用 `np.allclose` 而不是 `==`。这是数值计算的第一课。
3. **"空间"不限于数字数组**。函数、多项式也是向量，但 NumPy 无法直接"容纳"无穷维向量空间。本课代码演示的是 $\mathbb{R}^n$ 这个最具体的实例；抽象的公理依然统治着函数空间——只是无法逐条用 `allclose` 验完。
4. **封闭性比"好看"重要**。判断"这是不是向量空间"，第一件事是看运算是否把结果留在集合里。深度学习里，"权重必须留在合法范围内"（如正交约束、非负约束）就是封闭性思想的工程版——违反时模型会崩溃（NaN、发散）。
