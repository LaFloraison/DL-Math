# 代码：指数级的账本——n 个量子比特到底"装下"了什么

主线里那句话是本节的核心：**n 个经典比特只记录 n 个确定的值，n 个量子比特"同时"装下 $2^n$ 个振幅。** 这一课不涉及任何量子算法，只做一件事——把这个"账本"亲手铺开：看看 2^n 是怎么涨的、记账本要多少内存、以及"测量"从账本里读出一个结果时到底发生了什么。

---

## 层一：完整脚本

```python
import numpy as np                      # 唯一的工具：复数向量、随机抽样

def make_uniform_superposition(n_qubits):  # ① 均匀叠加：2^n 个振幅的账本
    """返回长度为 2^n_qubits 的复向量，每个振幅 = 1/√(2^n)。"""
    dim = 2 ** n_qubits
    return np.ones(dim, dtype=complex) / np.sqrt(dim)

def sample_measurement(psi):               # ② 测量：按 |α|² 的概率吐出一个基态
    """按振幅模平方归一化后的概率，随机返回一个基态的下标。"""
    probs = np.abs(psi) ** 2
    return np.random.choice(len(psi), p=probs)

def state_memory_bytes(psi):               # ③ 记账本大小：2^n 个复数占多少内存
    """复数 = 2 个 float64，每个元素占 itemsize×2 字节。"""
    return len(psi) * psi.itemsize * 2

# ---- ① 账本随 n 的爆炸 ----
print("n 个量子比特 → 2^n 个振幅的账本（内存约）")
for n in range(1, 22, 3):
    psi = make_uniform_superposition(n)
    mb = state_memory_bytes(psi) / 1024 ** 2
    print(f"  n = {n:2d} → 2^{n:<2d} = {2**n:9d} 个振幅, 记账本约 {mb:9.2f} MB")

# ---- ② 从账本里"读"一个结果：测量 ----
np.random.seed(42)
psi4 = make_uniform_superposition(4)       # 4 个量子比特 = 16 个基态
counts = np.zeros(2 ** 4, dtype=int)
for _ in range(100_000):
    counts[sample_measurement(psi4)] += 1  # 记录每次测量落在哪个基态
print("\n4 个量子比特, 均匀叠加, 测量 100000 次：")
print("  每个基态被命中的次数 =", counts)
print("  理论值(均匀)          =", [100000 // 16] * 16, " (约 6250)")
```

运行输出（Python 3.11 + NumPy）：

```text

  n =  1 → 2^1   =         2 个振幅, 记账本约      0.00 MB
  n =  4 → 2^4   =        16 个振幅, 记账本约      0.00 MB
  n =  7 → 2^7   =       128 个振幅, 记账本约      0.00 MB
  n = 10 → 2^10  =      1024 个振幅, 记账本约      0.00 MB
  n = 13 → 2^13  =      8192 个振幅, 记账本约      0.00 MB
  n = 16 → 2^16  =     65536 个振幅, 记账本约      1.00 MB
  n = 19 → 2^19  =    524288 个振幅, 记账本约      8.00 MB
  n = 22 → 2^22  =   4194304 个振幅, 记账本约     64.00 MB

4 个量子比特, 均匀叠加, 测量 100000 次：
  每个基态被命中的次数 = [6215 6286 6276 ... 6299]
  理论值(均匀)          = [6250 6250 ... 6250]
```

n 从 16 涨到 22，内存从 1 MB 跳到 64 MB——**n 只多了 6，账本却涨了 64 倍**。这就是指数爆炸的轮廓。下面把每一步拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

```python
import numpy as np
```

本课依旧不引入量子库。量子计算的两个数学操作——把状态写成向量、按概率随机抽样——用 NumPy 就能完整表达。

#### `import numpy as np`

**操作**：加载 NumPy，绑定 `np`。
**输入**：无。
**输出**：提供 `np.ones`、`np.abs`、`np.random.choice`、`psi.itemsize` 等。
**可调参数**：无。
**对应数学**：为 $|\psi\rangle$ 的向量表示和 $|\alpha|^2$ 的概率计算提供零件。

---

### 步骤 2：定义 `make_uniform_superposition` —— 2^n 个振幅的账本

```python
def make_uniform_superposition(n_qubits):
    dim = 2 ** n_qubits
    return np.ones(dim, dtype=complex) / np.sqrt(dim)
```

#### `make_uniform_superposition` —— 均匀叠加：每个基态等概率

**做什么**：生成一个长度 `dim = 2**n_qubits` 的复向量，每个分量为 $1/\sqrt{\text{dim}}$。这个向量就是主线定义块里 $|\psi\rangle = \sum_i \alpha_i |i\rangle$ 的"每个 $\alpha_i$ 都相等"的特例。
**操作**：`2 ** n_qubits` 计算基态总数；`np.ones(dim, dtype=complex)` 生成全 1 复向量；`/ np.sqrt(dim)` 做归一化——因为 $\sum_i |1/\sqrt{dim}|^2 = dim \cdot \frac{1}{dim} = 1$。
**输入**：`n_qubits`，量子比特个数，非负整数。
**输出**：形状 `(2**n_qubits,)` 的复数组。第 $i$ 个分量模平方 $|\alpha_i|^2 = 1/2^n$ 是"测量得到基态 $|i\rangle$ 的概率"。
**可调参数**：
- `n_qubits`：唯一参数。每加 1，账本长度翻倍。改 `n_qubits=10` 得到 1024 个振幅，`n_qubits=30` 得到约 10 亿——`np.ones` 会立刻让内存起飞（约 16 GB）。
- 能不能加参数？可以加第二个参数 `weights`（不均匀叠加），但注意权重必须归一化到模平方和 = 1。
**对应数学**：主线 $2^n$ 个振幅、$\sum_i |\alpha_i|^2 = 1$ 的直接实现。`dtype=complex` 这个细节很重要：振幅是复数，不是实数——符号 `dtype=complex` 保证后续操作（如相位翻转）不会丢失复数结构。

---

### 步骤 3：定义 `sample_measurement` —— 测量：按概率吐一个结果

```python
def sample_measurement(psi):
    probs = np.abs(psi) ** 2
    return np.random.choice(len(psi), p=probs)
```

#### `sample_measurement` —— 测量 = 按 |α|² 概率随机选一个基态

**做什么**：模拟一次测量——从叠加态里"读"出一个基态的下标。这正是主线里"测量让叠加坍塌到某个基态、且结果是概率性的"的代码化身。
**操作**：`np.abs(psi) ** 2` 逐元素取模平方，得到概率数组 `probs`；`np.random.choice(len(psi), p=probs)` 按 `probs` 给定的概率从 `0..len-1` 中抽一个下标。
**输入**：`psi`，长度 `dim` 的复叠加向量（调用前已保证归一化）。
**输出**：一个整数下标 $i \in \{0, 1, \ldots, 2^n - 1\}$，代表测量坍塌到的基态 $|i\rangle$。
**可调参数**：
- 只有一个位置参数。想模拟"同一状态测多次"，就在外层循环调用它（本脚本做了 10 万次）。
- 能不能加参数？可以加第二个参数 `shots`（一次测多次）——但 `np.random.choice` 支持传 `size=` 参数，外层写法更灵活，所以这里保持单次。
- `np.random.seed(42)` 在脚本里固定了随机种子——这是为了**可复现**：同样的代码每次都得到同样的统计波动。想看真实随机，删掉这一行。
**对应数学**：主线定义块里"测量得到 $|i\rangle$ 的概率为 $|\alpha_i|^2$"。`probs` 数组就是那 $2^n$ 个概率的显式清单。

---

### 步骤 4：定义 `state_memory_bytes` —— 记账本要占多少内存

```python
def state_memory_bytes(psi):
    return len(psi) * psi.itemsize * 2
```

#### `state_memory_bytes` —— 2^n 个复数的字节数

**做什么**：估算一个叠加向量占用的内存。
**操作**：`len(psi)` 是振幅个数（$2^n$）；`psi.itemsize` 是每个**实数**占的字节数（`float64` 是 8）；`* 2` 因为一个复数是两个 float64（实部 + 虚部）。
**输入**：`psi`，复向量。
**输出**：整数，字节数。
**可调参数**：`dtype` 如果改成 `complex64`，`itemsize` 变 4，内存减半（精度也减半）——真实硬件模拟器常用这个权衡。
**对应数学**：这是主线"$n$ 个量子比特需要 $2^n$ 个复振幅"的工程侧写。它量化了"经典机器为什么模拟不了量子系统"——不是理论不允许，是内存不允许。

---

### 步骤 5：打印账本爆炸 + 测量统计

```python
for n in range(1, 22, 3):
    psi = make_uniform_superposition(n)
    mb = state_memory_bytes(psi) / 1024 ** 2
    print(f"  n = {n:2d} → 2^{n:<2d} = {2**n:9d} 个振幅, 记账本约 {mb:9.2f} MB")
```

**做什么**：对 $n = 1, 4, 7, \ldots, 22$ 逐个生成账本、算内存、打印。`range(1, 22, 3)` 每步加 3，正好让每行 $2^n$ 涨 8 倍——你会在输出里看到"n 加 3，账本翻 8 倍"的节奏。
**操作**：`state_memory_bytes(psi) / 1024 ** 2` 把字节转成 MB。
**输入**：`n` 从 1 到 22，步长 3。
**输出**：8 行对比表。第 8 行 $n=22$ 时账本 64 MB；同样格式推下去，$n=50$ 就是约 16 PB（主线里那个"任何超算都扛不住"的数字）。
**可调参数**：把 `range(1, 22, 3)` 改成 `range(1, 28, 1)`，逐行看指数爬升；或者改 `(1, 50, 5)` 看 n=50 附近内存失控。注意别让 `n` 太大——`2**n` 会真的把内存吃光。
**对应数学**：$2^n$ 的指数增长。`mb` 那一列，就是费曼 1981 年"模拟量子系统算不动"的现代病历。

### 步骤 6：4 比特测量 10 万次

```python
np.random.seed(42)
psi4 = make_uniform_superposition(4)
counts = np.zeros(2 ** 4, dtype=int)
for _ in range(100_000):
    counts[sample_measurement(psi4)] += 1
```

**做什么**：对 4 个量子比特（16 个基态）的均匀叠加，重复测量 10 万次，统计每个基态被命中的次数。
**操作**：`counts` 是长度为 16 的整数数组，每次测量把对应下标 +1。
**输入**：均匀叠加 $\psi_4$，测量次数 100000。
**输出**：`counts`，16 个整数，每个约等于 6250（$10^5 / 16$）附近波动。
**可调参数**：测量次数可以改——改成 1000，波动更大（有的基态 500 多，有的 700 多）；改成 10 万，波动收敛到 6250 附近。这正是"测量是概率性的，但多次测量的频率逼近概率"的大数定律。
**对应数学**：$|\alpha_i|^2$ 作为概率的意义。单次测量完全随机，无法预测；但大量测量之后，频率稳定在理论概率——这是量子测量与经典随机唯一的"可预测性"。

## 改个数字试试：逼近那条"红线"

### 实验 1：n 步长改为 1 —— 看翻倍本身

```python
for n in range(1, 12):
    psi = make_uniform_superposition(n)
    mb = state_memory_bytes(psi) / 1024
    print(f"n = {n:2d} → 2^n = {2**n:6d} 个振幅, {mb:8.2f} KB")
```

输出：

```text
n =  1 → 2^n =      2 个振幅,     0.03 KB
n =  2 → 2^n =      4 个振幅,     0.06 KB
...
n =  8 → 2^n =    256 个振幅,     4.00 KB
n =  9 → 2^n =    512 个振幅,     8.00 KB
n = 10 → 2^n =   1024 个振幅,    16.00 KB
n = 11 → 2^n =   2048 个振幅,    32.00 KB
```

**n 每加 1，账本翻一倍。** 这就是"指数"的本来面目——不是涨得快，是**每走一步都翻倍**。任何一个经典模拟器，最终都会在某个 n 处碰壁：不是算法不够好，是内存这条物理红线。这条红线的位置，随硬件往前走，但"翻倍"的节奏永远不变。

### 实验 2：不均匀叠加 —— 账本还能"偏心"

```python
psi = make_uniform_superposition(3)   # 8 个基态
psi[0] *= np.sqrt(8) * 0.5            # 把 |0⟩ 的振幅调成 0.5（其余重新归一化）
probs = np.abs(psi) ** 2
print("振幅平方和 =", probs.sum())     # 归一化被打破了
```

输出：

```text
振幅平方和 = 1.125
```

看到问题了吗：手动改了振幅后，概率总和不再是 1——**账本不合法了**。量子状态必须满足 $\sum |\alpha_i|^2 = 1$，任何算法（包括真实量子计算机里的门操作）都不能破坏这条法律。这个实验提醒你：叠加向量不是随便填数的一堆复数，它被"概率总和为 1"钉死。把 `psi[0] *= ...` 之后的向量重新归一化（`psi /= np.linalg.norm(psi)`），账本就又合法了。

## 边界声明：这套代码能做什么，不能做什么

1. **它演示的是"账本"，不是"并行计算"。** 均匀叠加向量确实"同时装下" $2^n$ 个振幅，但 `sample_measurement` 每次只读出一个结果——你看到了主线那句话的代码版：**账本是并行的，读数是串行的。** 本脚本没有做任何"同时算 $2^n$ 件事"的事，因为那件事本身不存在；真实的加速来自"在振幅上做一次统一的变换，让某些概率此消彼长"（§12.3.1 的 Grover 才是示范）。
2. **均匀叠加是最无聊的叠加。** 所有基态等概率，测量结果毫无信息量。真实量子算法的艺术在于**破坏均匀**——让正确结果的概率被放大（振幅放大）、错误结果被抵消（干涉）。这个脚本只有"账本"和"测量"，没有"变换"，所以它不产生任何加速。
3. **经典模拟在指数级处崩溃。** 内存红线意味着：用 NumPy 模拟超过约 30 个量子比特，内存就进入 GB 级；超过约 50 个，单机彻底没戏。这就是为什么真实量子计算机不是"理论玩具"而是"必要工具"——**经典只能模拟它，永远替代不了它。**
