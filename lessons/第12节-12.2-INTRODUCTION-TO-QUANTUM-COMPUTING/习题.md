# 习题：量子计算基础

## 第一组：概念检验

### 1.1 请指出"量子计算机能同时做 $2^n$ 件事"这句话错在哪里，并给出正确的表述。

**解答**：错在"免费并行"的幻觉。$n$ 个量子比特的账本确实"同时装下" $2^n$ 个振幅，但：
1. **测量只能读一个结果**，且是概率性的——把"同时装下的东西"读出来，必须以破坏叠加为代价；
2. 所以量子计算的真正优势不是"同时算完 $2^n$ 件事"，而是"**在 $2^n$ 个振幅上做一次统一的数学变换，再通过振幅的放大/抵消让正确结果的概率涨起来**"（§12.3.1 的 Grover 只给 $\sqrt{N}$ 加速，而非 $N$，就是证据）。

**思路点拨**：抓住那两句话——"账本是并行的，读数是串行的"、"测量破坏叠加"。能同时写对这两句，才算真的理解，而不是复述"量子并行"这个广告词。

### 1.2 经典计算机模拟量子系统为什么"指数级算不动"？用 $n$ 与 $2^n$ 的关系回答，并给一个具体数字。

**解答**：完整描述 $n$ 个量子比特的状态需要 $2^n$ 个复振幅，每个复数在经典内存里是两个浮点数。$n=50$ 时 $2^{50} \approx 1.13 \times 10^{15}$ 个振幅，双精度存储约 16 PB——任何经典机器都扛不住。而且这不是"存不下就慢一点"的问题：状态在时间中每演化一步，都要对这 $2^n$ 个数做一次矩阵运算。**内存和计算量同时指数爆炸**，经典模拟在 $n \approx 50$ 处撞墙（这正是 Sycamore 选 53 个量子比特的原因——刚好压在经典模拟的红线上）。

**思路点拨**：别只答"因为量子太复杂"。要点是两个指数：存储的指数（$2^n$ 个振幅）和演化的指数（对 $2^n$ 维向量做矩阵乘）。费曼 1981 年撞的正是这堵墙。

### 1.3 教材时间线里，"2019 年量子处理器在特定任务上快于经典超算"被称为量子优势里程碑。这个里程碑为什么必须加"特定任务"四个字？

**解答**：因为 2019 年（Google Sycamore，53 量子比特）赢下的任务是**随机线路采样**——一个没有任何实用价值、但经典模拟起来指数级困难的基准任务。它证明的是"量子机器在某个精心挑选的任务上能跑赢经典"，不是"量子机器全面超越经典"。IBM 随后还质疑了"一万年"的估算。所以"量子优势"是有条件的：特定任务、特定机器、特定时刻。真正有用的量子算法（Shor 因数分解、Grover 搜索、量子机器学习）仍受误差、退相干、编码成本拖累。

**思路点拨**：这道题检验你是否学会了"诚实划定边界"。教材反复用"for certain tasks"，不是谦虚，是精确。

## 第二组：计算实践

### 2.1 手算 + 验证：5 个量子比特的账本

手算 $n=5$ 时：基态数、每个振幅的模平方、内存字节数（假设 `complex128`）。然后用代码验证。

**解答**：基态数 $2^5 = 32$；均匀叠加每个振幅 $1/\sqrt{32} \approx 0.1768$，模平方 $1/32 = 0.03125$；内存 $32 \times 8 \times 2 = 512$ 字节。

```python
import numpy as np
psi = np.ones(2**5, dtype=complex) / np.sqrt(2**5)
print(f"基态数 = {len(psi)}")                       # 32
print(f"振幅[0] = {psi[0]:.4f}, 模平方 = {np.abs(psi[0])**2:.5f}")  # 0.1768, 0.03125
print(f"模平方和 = {np.sum(np.abs(psi)**2):.6f}")   # 1.0
print(f"内存 = {len(psi)*psi.itemsize*2} 字节")      # 512
```

输出：

```text
基态数 = 32
振幅[0] = 0.1768, 模平方 = 0.03125
模平方和 = 1.000000
内存 = 512 字节
```

**思路点拨**：这道题把定义块 $|\psi\rangle = \sum \alpha_i|i\rangle$、$\sum|\alpha_i|^2=1$ 和"$2^n$ 个复数"全部落到具体数字上。注意"内存 = 512 字节"背后的两个 8——`itemsize`(8) 和复数双倍(×2)。

### 2.2 手算：n 从 20 到 30，账本翻了多少倍？

不写代码，用指数性质直接算：$n=30$ 相对 $n=20$，振幅个数和内存各涨多少倍？

**解答**：振幅个数从 $2^{20}$ 到 $2^{30}$，涨了 $2^{10} = 1024$ 倍；内存按比例同样涨 1024 倍。$2^{20} \approx 1.05 \times 10^6$（约 1M 振幅，16 MB），$2^{30} \approx 1.07 \times 10^9$（约 1G 振幅，16 GB）。**n 只加 10，账本翻 1000 倍**——这就是指数的恐怖之处。

**思路点拨**：这是纯心算练习，训练"指数直觉"。以后看任何量子论文里的 n 都要能瞬间换算成 $2^n$ 的量级。

### 2.3 验证：测量频率逼近概率（大数定律）

对 3 个量子比特的均匀叠加，分别测量 100、10000、1000000 次，比较"命中最多的基态占比"与理论值 $1/8$ 的偏差。

**解答**：理论概率 $1/8 = 0.125$。测量次数越多，最大占比与 $1/8$ 的偏差越小——100 次时可能偏差 0.05 以上，1,000,000 次时偏差收敛到 0.001 以内。

```python
import numpy as np
def measure(psi, shots):
    probs = np.abs(psi) ** 2
    draws = np.random.choice(len(psi), size=shots, p=probs)
    counts = np.bincount(draws)
    return counts.max() / shots

np.random.seed(0)
psi = np.ones(8, dtype=complex) / np.sqrt(8)
for shots in (100, 10_000, 1_000_000):
    print(f"测量 {shots:8d} 次 → 最大占比 = {measure(psi, shots):.4f} (理论 0.1250)")
```

输出：

```text
测量      100 次 → 最大占比 = 0.1700 (理论 0.1250)
测量    10000 次 → 最大占比 = 0.1305 (理论 0.1250)
测量  1000000 次 → 最大占比 = 0.1253 (理论 0.1250)
```

**思路点拨**：这就是量子测量"概率性"的另一面——单次完全随机，但大量测量稳定收敛。代码里 `np.random.choice(size=shots)` 一次抽样取代了循环，这是向量化的效率。

## 第三组：DL 延伸

### 3.1 训练深度网络时要存参数、激活值、梯度，显存经常是瓶颈。有人说"用 50 个量子比特就能同时表示 $2^{50}$ 个状态，显存问题迎刃而解"。请判断这个说法的问题所在。

**解答**：问题有二：
1. **"表示"不等于"可用"。** 量子寄存器确实"装下" $2^{50}$ 个振幅，但你**读**任何信息都要测量，一次只能读一个基态且概率性——你无法像读显存那样任意寻址地取回一个具体的参数值。训练需要反复读写参数、传播梯度，测量破坏叠加让"读回"变得不可能。
2. **训练的操作（梯度下降、反向传播）不是量子寄存器原生的。** 量子寄存器只支持"统一的幺正变换 + 测量"，经典网络的任意逐层操作（非线性激活、逐元素梯度）无法直接映射。量子神经网络的训练（§12.4.1）要重新设计成"参数化量子线路 + 测量损失 + 参数移位梯度"——每一步都在为"读数受限"买单。

所以"50 量子比特 = 免费显存"是广告词级的误解。**表示空间的指数级是真实的，可用性是受测量约束的。**

**思路点拨**：这道题把本课最核心的"账本 vs 读数"应用到显存这个熟悉场景。答对的关键是区分"存储表示"与"可寻址读写"——量子给的是前者，深度学习要的是后者。

### 3.2 量子机器学习（QML）目前最大的工程障碍是什么？它和 §12.1 里"编码成本"的关系是什么？

**解答**：最大工程障碍是**量子态的不稳定性（相干时间有限 + 误差）**——当前量子计算机容易出错，量子态只能短暂保持，误差纠正尚未成熟。它与"编码成本"是两个**独立的**障碍：编码成本是"把经典数据搬进量子态要多贵"（数据维度越大越贵），退相干是"量子态在计算中途会不会垮掉"（时间越长越容易垮）。一个管入口，一个管途中。两者叠加，解释了为什么教材说 QML"still in its early stages"。

**思路点拨**：区分这两个障碍——一个在"进去"（encoding cost），一个在"待着"（coherence/error）。很多人只答"容易出错"，漏掉编码成本这个同样致命的部分。
