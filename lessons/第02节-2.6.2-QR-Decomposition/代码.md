# 代码：手写 Gram-Schmidt，把矩阵拆成"直框架 × 配方表"

主线里我们把两根歪柱子掰直成 $Q$、并用配方表 $R$ 重建原物。这一节把它变成代码：先用 **NumPy 手写 Gram-Schmidt**，算出 $Q$（正交单位列）与 $R$（上三角），验证 $Q^{\top}Q = I$ 与 $A = QR$ 无损重建；再用 QR 解方程组 $Ax = b$；最后对比条件数，亲眼看到"正规方程为什么不如 QR 稳"。

脚本只依赖 NumPy，约 40 行，输出全部印在下方。

---

## 层一：完整脚本

```python
import numpy as np                          # NumPy：矩阵、内积、范数，全在这里
np.set_printoptions(precision=4, suppress=True)   # 让矩阵打印更整齐（4 位小数）

# ---- ① 原矩阵 A：教材例，3×3 满列秩 ----
A = np.array([[4.0, 2, 1],                  # 第1列 [4,6,5]、第2列 [2,3,7]、第3列 [1,8,10]
              [6.0, 3, 8],
              [5.0, 7, 10]])

# ---- ② 手写 Gram-Schmidt：把列掰成正交单位向量，同时填出 R ----
def gram_schmidt(A):
    m, n = A.shape                          # 取行列数
    Q = np.zeros((m, n))                    # 直框架，先占位
    R = np.zeros((n, n))                    # 配方表，先占位
    for k in range(n):                      # 逐列处理
        v = A[:, k].copy().astype(float)    # 取出第 k 根"柱子"
        for j in range(k):                  # 依次减去沿已掰直方向的投影
            R[j, k] = Q[:, j] @ A[:, k]     # 投影系数：a_k 沿 q_j 走了多远
            v = v - R[j, k] * Q[:, j]       # 减除，剩下的才是新方向
        R[k, k] = np.linalg.norm(v)         # 新方向长度，即对角元
        Q[:, k] = v / R[k, k]               # 归一化成单位方向
    return Q, R

# ---- ③ 回代：解上三角方程 R x = y ----
def back_substitution(R, y):
    n = R.shape[0]
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):          # 从最后一行往上
        x[i] = (y[i] - R[i, i+1:] @ x[i+1:]) / R[i, i]
    return x

# ---- ④ 执行分解并验证 ----
Q, R = gram_schmidt(A)
print("Q  (手写 Gram-Schmidt)：")
print(Q)
print("R  (手写 Gram-Schmidt)：")
print(R)

print("\n--- 验证 ---")
print("Q^T Q =")
print(Q.T @ Q)                             # 应当是单位矩阵
print("重构最大误差 |A - QR| =", np.max(np.abs(A - Q @ R)))

print("\n--- 生产实现 np.linalg.qr 对比 ---")
Q2, R2 = np.linalg.qr(A)                    # 内部用 Householder 反射，数值更稳
print("np.linalg.qr 的 Q^T Q =")
print(Q2.T @ Q2)

print("\n--- 用 QR 解方程组 Ax = b ---")
b = np.array([1.0, -2.0, 3.0])
y = Q.T @ b                                 # 两边左乘 Q^T，得 R x = y
x_qr = back_substitution(R, y)
print("x  (QR 法)      =", np.round(x_qr, 6))
print("x  (np.linalg.solve) =", np.round(np.linalg.solve(A, b), 6))
print("残差 ||Ax - b|| =", np.linalg.norm(A @ x_qr - b))

print("\n--- 条件数对比：正规方程会平方条件数 ---")
print("cond(A)     =", np.round(np.linalg.cond(A), 2))
print("cond(A^T A) =", np.round(np.linalg.cond(A.T @ A), 2))
```

## 层二：分步逐函数拆解

### 步骤 1：造矩阵 A —— `np.array`

```python
A = np.array([[4.0, 2, 1],
              [6.0, 3, 8],
              [5.0, 7, 10]])
```

#### `np.array(嵌套列表)` —— 把二维列表变成矩阵

**做什么**：把 3 个长度 3 的列表叠成一个 $3 \times 3$ 的 `ndarray`——这是我们这个 3×3 例子在计算机里的存在形式。
**操作**：按"行"顺序把元素存入连续内存，推断数据类型为 `float64`。
**输入**：二维列表，形状 `(3, 3)`。
**输出**：形状 `(3, 3)` 的数组。语义：`A[i, j]` 是第 `i` 行第 `j` 列元素；`A[:, k]` 是第 `k` 列（形状 `(3,)`）——在 QR 里，**列**才是主角，每列是一根"柱子"（$\mathbf{a}_k$）。
**可调参数**：任意行列数——行数大于列数就是"高瘦"的最小二乘矩阵（$m > n$），列数大于行数则不能满足本课前提（见边界声明）；第一个列表的元素写 `4` 或 `4.0` 都行，但混入浮点可避免整数除法踩坑。

### 步骤 2：手写 Gram-Schmidt —— `gram_schmidt(A)`

```python
def gram_schmidt(A):
    m, n = A.shape
    Q = np.zeros((m, n))
    R = np.zeros((n, n))
    for k in range(n):
        v = A[:, k].copy().astype(float)
        for j in range(k):
            R[j, k] = Q[:, j] @ A[:, k]
            v = v - R[j, k] * Q[:, j]
        R[k, k] = np.linalg.norm(v)
        Q[:, k] = v / R[k, k]
    return Q, R
```

#### `def gram_schmidt(A)` —— 整个算法的骨架

**做什么**：把 $A$ 的 $n$ 个列向量逐次正交化。外层循环 `for k in range(n)` 每次处理一列；内层循环 `for j in range(k)` 把这一列与前面所有已掰直的 $\mathbf{q}_j$ 逐一对齐。
**操作**：对应主线里的 Gram-Schmidt 单步——量投影、减投影、量剩余长度、归一化。
**输入**：`A`，形状 `(m, n)`，列必须线性无关（满列秩）。
**输出**：元组 `(Q, R)`。`Q` 形状 `(m, n)`，列两两正交且单位长；`R` 形状 `(n, n)`，上三角。
**可调参数**：无——但你可以改里面的判断逻辑：把内层投影系数从 `Q[:, j] @ A[:, k]` 换成 `Q[:, j] @ v`（用"剩余向量"代替"原向量"），就是改进版 **MGS（Modified Gram-Schmidt）**，数值上更稳一点——这是本函数最值得动手实验的变量。

#### `A.shape` —— 取行列数

**做什么**：返回元组 `(m, n)`，决定 Q、R 的占位形状。`m` 是行数（向量维数），`n` 是列数（向量个数）。

#### `np.zeros((m, n))` —— 造全零占位矩阵

**操作**：生成一个所有元素为 0 的矩阵，之后逐列填值。
**输入**：形状元组 `(m, n)`。
**输出**：形状 `(m, n)` 的零矩阵。语义：`Q[:, j]` 是第 `j` 个单位方向（掰直后的柱子），`R[j, k]` 是配方表第 `j` 行第 `k` 列。

#### `A[:, k].copy().astype(float)` —— 取出第 k 列

**操作**：切片 `A[:, k]` 取第 `k` 列（视图），`.copy()` 复制一份（避免后面 `v` 被原地改写波及原矩阵），`.astype(float)` 确保是浮点（防止整数除法）。
**输入**：`A`（形状 `(3,3)`）、整数 `k`。
**输出**：形状 `(3,)` 的一维数组，即 $\mathbf{a}_k$。

#### `Q[:, j] @ A[:, k]` —— 内积，算投影系数

**操作**：`@` 对一维数组做**点积 (dot product)**——对应位置的元素相乘再求和。这就是主线里的 $r_{jk} = \mathbf{q}_j^{\top}\mathbf{a}_k$：量出第 $k$ 根柱子沿第 $j$ 个直方向"走了多远"。
**输入**：`Q[:, j]`（形状 `(3,)`，单位向量）与 `A[:, k]`（形状 `(3,)`，原列向量）。
**输出**：标量 `R[j, k]`。形状语义：`(3,)` 与 `(3,)` 点积得一个数，放进配方表 $R$ 的第 `(j, k)` 格——**这是 R 上三角部分唯一被填值的位置**（`j < k`）。

#### `v = v - R[j, k] * Q[:, j]` —— 减除投影

**操作**：标量 `R[j, k]` 逐元素乘向量 `Q[:, j]`（缩放），再从 `v` 中减去。这正是主线里的 $\mathbf{u}_k \leftarrow \mathbf{a}_k - r_{jk}\mathbf{q}_j$。每做完一次，`v` 里"沿 $\mathbf{q}_j$ 的成分"就少一分。
**输入**：`v`（形状 `(3,)`）、`R[j, k]`（标量）、`Q[:, j]`（形状 `(3,)`）。
**输出**：形状 `(3,)` 的更新后向量。循环结束后，`v` 与所有 `q_j`（$j < k$）都垂直。

#### `np.linalg.norm(v)` —— 剩余部分的长度

**操作**：计算 $\|\mathbf{u}_k\|_2 = \sqrt{\sum_i v_i^2}$。这就是主线里的对角元 $r_{kk}$——"全新方向"的长度，恒为正（列满秩保证）。
**输入**：形状 `(3,)` 的向量。
**输出**：标量（正数）。
**可调参数**：第二参数 `ord` 可选其他范数，但这里必须是默认的 2-范数——它对应欧氏长度，是"方向长度"的正确度量。

#### `v / R[k, k]` —— 归一化成单位方向

**操作**：每个分量除以长度，得到模长为 1 的新方向 $\mathbf{q}_k$。
**输入**：`v`（形状 `(3,)`）、`R[k, k]`（标量）。
**输出**：形状 `(3,)` 的单位向量，写入 `Q[:, k]`。语义：第 `k` 根直柱子就位——两两垂直、长度 1。
**对应数学**：主线 Gram-Schmidt 单步公式 $r_{jk}, u_k, r_{kk}, q_k$ 的完整实现。

### 步骤 3：验证正交性与无损重构

```python
print(Q.T @ Q)
print(np.max(np.abs(A - Q @ R)))
```

#### `Q.T @ Q` —— 验证 $Q^{\top}Q = I$

**操作**：`Q.T` 是转置（形状 `(n, m)`），与 `Q`（形状 `(m, n)`）做矩阵乘法，得形状 `(n, n)`。第 `(i, j)` 元素是 $\mathbf{q}_i \cdot \mathbf{q}_j$——主对角线是各列自内积（应为 1），非对角线是列与列的内积（应为 0）。
**输入**：`Q`（形状 `(3,3)`）。
**输出**：形状 `(3,3)`，数值上应等于单位矩阵。输出里那些 `-0.` 只是 `-2.8e-17` 这种舍入尾数的显示，不是真的负数——这正是"误差只有 $10^{-16}$ 量级"的证据。

#### `np.max(np.abs(A - Q @ R))` —— 重构误差

**操作**：`Q @ R` 重建原矩阵，与 `A` 逐元素相减取绝对值，再取最大值。得到 `8.88e-16`——和计算机浮点精度的机器误差（约 $2.2 \times 10^{-16}$）同一量级，证明 $A = QR$ 在数值上精确成立。
**输入**：两个形状 `(3,3)` 的矩阵。
**输出**：标量（最大绝对误差）。
**对应数学**：主线"无损重构 $A = QR$"。

### 步骤 4：生产实现 `np.linalg.qr`

```python
Q2, R2 = np.linalg.qr(A)
print(Q2.T @ Q2)
```

#### `np.linalg.qr(A)` —— NumPy 的高质量 QR

**做什么**：返回 `(Q2, R2)`，满足 $A = Q_2 R_2$ 且 $Q_2$ 列正交。它内部**不是**经典 Gram-Schmidt，而是 **Householder 反射**——一次消掉一整列的下三角，舍入误差不累积，数值上远更稳。
**输入**：`A`，形状 `(m, n)`。
**输出**：`Q2`（形状 `(m, n)`）、`R2`（形状 `(n, n)` 上三角）。
**可调参数**：第二参数 `mode` 控制返回形状——默认 `'reduced'` 返回"瘦" Q（`(m, n)`）；`mode='complete'` 返回方阵 Q（`(m, m)`）并多出 `(n, m-n)` 个零行；`mode='r'` 只返回 R。深度学习里最常用默认的 `'reduced'`。
**注意对比**：`Q2` 的第一、三列符号与手写版 `Q` **相反**（`Q2[0,0] = -0.4558` vs `Q[0,0] = 0.4558`）。这不是错误——QR 分解的列可以整体翻号（同时翻 $Q$ 的第 $k$ 列与 $R$ 的第 $k$ 行，乘积不变）。我们的手写版取 $r_{kk} > 0$（对角元全为正），`np.linalg.qr` 默认不保证这一点。**无论哪一版，$Q^{\top}Q = I$ 与 $A = QR$ 都精确成立**——输出里两版的 $Q^{\top}Q$ 都是单位阵。

### 步骤 5：用 QR 解方程组 $Ax = b$

```python
b = np.array([1.0, -2.0, 3.0])
y = Q.T @ b
x_qr = back_substitution(R, y)
```

#### `Q.T @ b` —— 两边左乘 $Q^{\top}$

**操作**：把 $QRx = b$ 两边左乘 $Q^{\top}$，利用 $Q^{\top}Q = I$ 得 $Rx = Q^{\top}b$。`Q.T` 形状 `(3,3)` 乘 `b` 形状 `(3,)`，得一维 `y`。语义：把右端项 $b$ "投影"到 $Q$ 的列空间坐标系里。
**输入**：`Q`（`(3,3)`）、`b`（`(3,)`）。
**输出**：`y`，形状 `(3,)`。
**对应数学**：主线第五节 $Rx = Q^{\top}b$。

#### `def back_substitution(R, y)` —— 上三角回代

**做什么**：解上三角方程 $Rx = y$。从最后一行起：$R_{nn} x_n = y_n$ 单独解出 $x_n$；再往上，$R_{n-1,n-1} x_{n-1} + R_{n-1,n} x_n = y_{n-1}$ 中 $x_n$ 已知，解出 $x_{n-1}$……自下而上逐个代出。
**操作**：循环 `for i in range(n-1, -1, -1)` 从最后一行往前；`R[i, i+1:] @ x[i+1:]` 是"第 $i$ 行里那些未知数 $x_{i+1..n-1}$ 的贡献"，从 $y_i$ 里减掉后除以对角元 $R[i,i]$。
**输入**：`R`（形状 `(n,n)` 上三角）、`y`（形状 `(n,)`）。
**输出**：`x`，形状 `(n,)`，即方程组的解。结果 `[-0.3333, 1.4359, -0.5385]` 与 `np.linalg.solve` 完全一致，残差只有 `2.09e-15`——QR 法解方程组是可信的。
**可调参数**：`R` 必须上三角；若传入一般矩阵，本函数会给出错误结果——回代是"只属于三角方程组"的算法。

### 步骤 6：条件数对比

```python
print(np.round(np.linalg.cond(A), 2))
print(np.round(np.linalg.cond(A.T @ A), 2))
```

#### `np.linalg.cond(A)` —— 条件数

**操作**：计算 $\kappa(A) = \|A\|\,\|A^{-1}\|$（默认 2-范数），度量"解对输入扰动的敏感度"。条件数越大，越病态，舍入误差放大得越狠。
**输入**：`A`（形状 `(n,n)` 或任意矩阵）。
**输出**：标量。本例子：$\kappa(A) = 7.96$。
**可调参数**：第二参数 `p` 可选范数类型（`'fro'`、`1`、`'inf'` 等），默认 2-范数。
**关键观察**：$\kappa(A^{\top}A) = 63.41 \approx 7.96^2$——**正规方程把条件数平方了**。QR 直接分解 $A$、不构造 $A^{\top}A$，条件数保持 $7.96$。当 $\kappa(A)$ 上千时，平方后就是百万级，正规方程的解会被噪声淹没，而 QR 依旧稳如磐石。

## 边界声明：这套代码能做什么，不能做什么

1. **手写的经典 Gram-Schmidt 数值不稳**：误差会随列数累积，第 $k$ 步的偏差会让后面的 $\mathbf{q}_k$ 越来越不严格正交。3×3 没问题，几百列时 $Q^{\top}Q$ 会明显偏离 $I$。生产环境一律用 `np.linalg.qr`（Householder）。想感受差距，可把本脚本换成 50×50 的随机矩阵分别跑两版，对比 `Q.T @ Q` 偏离单位阵的程度。
2. **满列秩是硬前提**：`gram_schmidt` 每一步要除以 `R[k, k]`，某列线性相关时该值为 0，直接 `ZeroDivisionError` 或得到 NaN。秩亏矩阵请改用 SVD（§2.6.3）。
3. **`np.linalg.qr` 不保证 $R$ 对角元为正**：同一矩阵可能得到符号不同的列。判别 QR 是否成功的标准不是"数字长得像某本书"，而是 $Q^{\top}Q = I$ 且 $A - QR$ 在机器误差量级——本课手写版特意取了"对角元为正"的唯一版本。
4. **`back_substitution` 只认上三角**：它不检查 $R$ 是否是上三角。若把非三角矩阵传给它，静默产出错误答案。真实框架里，这一步通常由 `np.linalg.solve` / `torch.linalg.solve_triangular` 完成。
5. **矩形矩阵的 Q 只是"列正交"**：$m > n$ 时 $Q^{\top}Q = I_n$ 成立，但 $QQ^{\top} \ne I_m$——正交矩阵（方阵）与列正交矩阵（矩形）不是一回事。本脚本只用方阵演示，最小二乘场景请自行把 `A` 换成高瘦矩阵重跑。
