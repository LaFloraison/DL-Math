# 习题：QR 分解

## 第一组：概念检验

**1.1（单选）** 设 $A$ 是 $3\times 3$ 满秩矩阵，$A = QR$。下列说法**正确**的是：
- A. $Q$ 的列两两垂直且长度为 1
- B. $R$ 的主对角线**以下**的元素都为正
- C. 只要 $A$ 是矩阵，不管列是否线性相关，QR 分解都存在
- D. $Q$ 一定是对称矩阵，即 $Q = Q^{\top}$

**1.2（判断并说明）** "QR 分解把矩阵 $A$ 拆成 $Q$ 和 $R$，其中 $R$ 的每一列都已经归一化，长度都是 1。" 这句话对吗？错在哪里？

**1.3（简答）** 解最小二乘时，为什么用 QR 比用正规方程 $X^{\top}X w = X^{\top}y$ 数值上更稳定？用"条件数"三个字以内的线索回答即可。

## 第二组：计算实践

**2.1（手算）** 对 $A = \begin{bmatrix} 2 & 1 \\ 1 & 1 \end{bmatrix}$ 完整执行一次 Gram-Schmidt：写出 $q_1$、$r_{12}$、$u_2$、$r_{22}$、$q_2$ 与整个 $R$，最后验证 $Q^{\top}Q = I$ 与 $QR = A$。

**2.2（代码验证）** 用代码对教材例 $A = \begin{bmatrix}4&2&1\\6&3&8\\5&7&10\end{bmatrix}$ 验证三件事：$Q^{\top}Q \approx I$（误差在机器精度量级）、$A - QR$ 的重构误差、$\kappa(A^{\top}A) \approx \kappa(A)^2$。

**2.3（手算 + 代码）** 用 $A = \begin{bmatrix}2&1\\1&1\end{bmatrix}$、$b = \begin{bmatrix}3\\2\end{bmatrix}$ 解方程组 $Ax = b$。先把 $R x = Q^{\top}b$ 写成具体数字，再回代求出 $x$；用代码验证。

## 第三组：DL 延伸

**3.1（场景判断）** PyTorch 的 `torch.nn.init.orthogonal_(w)` 让初始权重矩阵 $W$ 的列正交（$W^{\top}W = I$）。为什么深度**线性**网络用正交初始化比随机高斯初始化更容易训练？请从 $\|Wx\|^2 = \|x\|^2$ 这条恒等式出发解释。

**3.2（场景分析）** 线性回归：数据矩阵 $X$ 形状 $(500, 10)$，目标 $y$，要求最小二乘解 $w$。两种实现：(a) $w = (X^{\top}X)^{-1}X^{\top}y$；(b) 对 $X$ 做 $X = QR$，解 $Rw = Q^{\top}y$。哪个数值上更稳？如果 $\kappa(X) = 1000$，两种方案各自的条件数量级是多少？

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：$Q$ 的定义就是"列两两正交且单位长"，即 $Q^{\top}Q = I$。
- **B 为什么错**：$R$ 是上三角，主对角线**以下**全是 0；对角元 $r_{kk} > 0$（取正对角约定下）。"主对角线以下为正"把位置说反了——那是下三角元素的领地。
- **C 为什么错**：QR 的前提是**满列秩**。若某列与前面的列线性相关，Gram-Schmidt 某一步 $\|\mathbf{u}_k\| = 0$，除以 0 崩盘。列不满秩的场合要换 SVD。
- **D 为什么错**：$Q$ 是正交矩阵（$Q^{\top} = Q^{-1}$），正交矩阵**不一定对称**。对称是 $Q = Q^{\top}$，正交是 $Q^{\top}Q = I$——两个不同的性质，把二者混为一谈是经典错误。事实上本课例子的 $Q$ 就不是对称的。
- **点拨**：最容易误选 C——有人觉得"分解嘛，什么矩阵都能拆"。但"拆开"不等于"不崩盘"，满列秩是 QR 的生死线。

**1.2 这句话是错的。**
- **思路**：归一化（长度变为 1）发生在 **$Q$** 的列上——$Q$ 的列才是正交**单位**向量。$R$ 记录的是"原向量在新基下的坐标"：$r_{jk}$ 是投影系数，对角元 $r_{kk}$ 是剩余长度，各列的长度一般**不是** 1。
- **点拨**：把 $Q$ 和 $R$ 的角色对调，是理解 QR 最常见的绊脚石。记忆锚点：**Q 管形状（几何），R 管配方（坐标）**。$Q$ 的列是"掰直后的方向"，$R$ 是"搭出原物的系数"——单位化当然只发生在方向那一侧。

**1.3 答案：正规方程平方条件数。**
- **思路**：$\kappa(X^{\top}X) = \kappa(X)^2$。QR 直接分解 $X$，不构造 $X^{\top}X$，条件数保持 $\kappa(X)$。
- **点拨**：条件数每平方一次，解的误差上限就放大一次。这就是教材说 QR "widely used to solve least square problems" 的根因。

### 第二组

**2.1**
$A$ 的两列：$a_1 = [2,1]$，$a_2 = [1,1]$。
1. $r_{11} = \|a_1\| = \sqrt5$，$q_1 = \frac{a_1}{\sqrt5} = [2/\sqrt5,\; 1/\sqrt5]$。
2. $r_{12} = q_1 \cdot a_2 = \frac{3}{\sqrt5}$。
3. $u_2 = a_2 - r_{12}q_1 = [1,1] - \frac{3}{5}[2,1] = [-1/5,\; 2/5]$。
4. $r_{22} = \|u_2\| = \sqrt5/5$，$q_2 = \frac{u_2}{r_{22}} = [-1/\sqrt5,\; 2/\sqrt5]$。
5. $Q = \begin{bmatrix} 2/\sqrt5 & -1/\sqrt5 \\ 1/\sqrt5 & 2/\sqrt5 \end{bmatrix}$，$R = \begin{bmatrix} \sqrt5 & 3/\sqrt5 \\ 0 & \sqrt5/5 \end{bmatrix}$。

验证：$q_1\cdot q_2 = -\frac{2}{5}+\frac{2}{5}=0$，$\|q_1\|=\|q_2\|=1$；$QR = \begin{bmatrix}2&1\\1&1\end{bmatrix} = A$。
- **思路**：每一步都是"量投影 → 减投影 → 归一化"。$R$ 的对角元 $r_{11}=\sqrt5$、$r_{22}=\sqrt5/5$ 对应两次"剩余长度"。
- **点拨**：注意 $r_{22} = \sqrt5/5$ 是个小于 1 的数——它不代表"柱子变短了"，只代表"新方向是从一个小残量里归一化出来的"。别把对角元误读成原列的长度。

**2.2**
```python
import numpy as np
A = np.array([[4., 2, 1], [6., 3, 8], [5., 7, 10]])
Q, R = np.linalg.qr(A)
print("正交性误差 ||Q^T Q - I||_max =", np.max(np.abs(Q.T @ Q - np.eye(3))))
print("重构误差   ||A - QR||_max    =", np.max(np.abs(A - Q @ R)))
print("cond(A)     =", round(np.linalg.cond(A), 2))
print("cond(A^T A) =", round(np.linalg.cond(A.T @ A), 2))
```
```text
正交性误差 ||Q^T Q - I||_max = 4.44e-16
重构误差   ||A - QR||_max    = 2.89e-15
cond(A)     = 7.96
cond(A^T A) = 63.41
```
- **思路**：两条误差都在 $10^{-15}$ 量级（机器精度），证明 $Q^{\top}Q = I$ 与 $A = QR$ 数值成立。条件数 $63.41 \approx 7.96^2$。
- **点拨**：`np.linalg.qr` 返回的 Q 列符号可能与手写版不同（它不保证 $r_{kk}>0$），但两条验证始终成立——用"误差量级"而不是"数字长相"来判断分解对错。

**2.3**
先算 $y = Q^{\top}b$：$y = \begin{bmatrix} \frac{2}{\sqrt5}\cdot 3 + \frac{1}{\sqrt5}\cdot 2 \\ -\frac{1}{\sqrt5}\cdot 3 + \frac{2}{\sqrt5}\cdot 2 \end{bmatrix} = \begin{bmatrix} 8/\sqrt5 \\ 1/\sqrt5 \end{bmatrix}$。

回代：最后一个方程 $\frac{\sqrt5}{5}x_2 = \frac{1}{\sqrt5}$，得 $x_2 = 1$。再往上 $\sqrt5\, x_1 + \frac{3}{\sqrt5}x_2 = \frac{8}{\sqrt5}$，代入 $x_2 = 1$：$\sqrt5 x_1 = \frac{5}{\sqrt5}$，得 $x_1 = 1$。故 $x = [1, 1]$。

```python
import numpy as np
A = np.array([[2., 1], [1, 1]]); b = np.array([3., 2])
Q, R = np.linalg.qr(A)
x = np.linalg.solve(R, Q.T @ b)
print(x)                 # [1. 1.]
print(np.linalg.solve(A, b))   # [1. 1.] 一致
```
- **思路**：QR 解方程的三部曲——左乘 $Q^{\top}$ 得三角方程，回代求 $x$，残差可验证。
- **点拨**：为什么能"左乘 $Q^{\top}$"？因为 $Q^{\top}Q = I$。正交矩阵是唯一一种"逆就是转置"的矩阵，这让 $Q$ 的"撤销"成本为零——这个性质在 DL 里（正交初始化、白化）到处发光。

### 第三组

**3.1 答案：正交初始化让每层信号的**幅度**不随深度变化。**
- **思路**：对任意向量 $x$，$\|Wx\|^2 = x^{\top}W^{\top}Wx = x^{\top}x = \|x\|^2$。**正交矩阵不改变向量的长度**。于是前向传播中信号既不被放大（梯度爆炸）也不被压缩（梯度消失），深度线性网络在正交初始化下变成了一条"等距管道"。随机高斯初始化的 $W$ 通常有小扰动 $\|Wx\| \approx \|x\|(1+\epsilon)$，几十层后 $\epsilon$ 指数累积成爆炸或消失。
- **点拨**：这正是主线 DL 桥接的核心。容易答偏的地方：有人答"正交让权重正交能减少过拟合"——不对，正交化的收益在**梯度流动**，不在泛化。
- **代码佐证**：`torch.nn.init.orthogonal_` 的实现就是"生成随机矩阵 → QR → 取 $Q$"。

**3.2 答案：方案 (b)（QR）数值上更稳。**
- **思路**：方案 (a) 构造 $X^{\top}X$，条件数从 $\kappa(X)$ 变成 $\kappa(X)^2$。$\kappa(X) = 1000$ 时，方案 (a) 的条件数量级是 $1000^2 = 10^6$，方案 (b) 保持 $1000$。$10^6$ 意味着"输入的 $10^{-16}$ 级舍入误差可能被放大到 $10^{-10}$ 级"——在小目标值场景足以毁掉解。
- **点拨**：条件数的平方是正规方程的原罪。选 (a) 的人常觉得"$(X^{\top}X)^{-1}$ 公式漂亮"，但漂亮的公式在计算机里不等于稳的公式——这是数值线性代数的第一课。
- **补充**：当 $\kappa(X)$ 再大到 $10^6$ 以上、或 $X$ 列相关时，连 QR 也吃力，要升级到 SVD（§2.6.3）加截断。QR 不是病态问题的终点，而是"次病态问题"的稳妥答案。

## 一个"为什么有人会答错"的提醒

1.1 的 D 最具欺骗性——"正交"与"对称"两个词都带"对"字，初学者极易混淆。判据各记一句：正交 = 转置即逆（$Q^{\top}Q = I$）；对称 = 转置即自身（$A^{\top} = A$）。1.2 的角色错位（把单位化安到 R 头上）同样高频，务必用"Q 管几何、R 管配方"的锚点钉死。3.1 则要警惕"顺手写成防过拟合"——看到正交，第一反应永远是"长度不变 / 梯度流动"，而不是"正则化"。
