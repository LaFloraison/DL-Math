# 代码：在凸碗上下山——从零手写梯度下降

**目标**：主线用 $f(x) = x^2 + 4x + 4$（碗底 $-2$）讲了凸函数。这里把图 5.5 的演示做成代码：**从零手写梯度下降**，在凸函数 $f(x) = x^2 + 4x + 4$ 上从 $x=2$ 出发，一步步收敛到碗底 $x=-2$。你还会看到凸性的签名——**越接近碗底，梯度越小，步幅自动收窄**。全部裸 NumPy，不碰优化库。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 凸目标及其导数 ----
# f(x) = x^2 + 4x + 4 = (x+2)^2, 解析最小值在 x=-2, f(-2)=0
def f(x):
    return x ** 2 + 4.0 * x + 4.0

def df(x):
    return 2.0 * x + 4.0            # f'(x) = 2x + 4

# ---- 2. 梯度下降主循环 ----
x = 2.0          # 起点（图 5.5 右侧的绿点）
lr = 0.1         # 学习率
iters = 50       # 迭代步数
traj = []        # 记录轨迹 (x, f(x))
for t in range(iters):
    traj.append((x, f(x)))
    x = x - lr * df(x)              # 核心更新: x <- x - lr * f'(x)

# ---- 3. 结果与轨迹检查 ----
print(f"最终 x = {x:.6f}  (解析解 -2.0)")
print(f"最终 f(x) = {f(x):.6f}  (解析值 0.0)")
print("前 6 步轨迹 (x, f(x)):")
for a, b in traj[:6]:
    print(f"  x = {a:8.4f}   f(x) = {b:8.4f}")
```

输出：

```
最终 x = -1.999943  (解析解 -2.0)
最终 f(x) = 0.000000  (解析值 0.0)
前 6 步轨迹 (x, f(x)):
  x =   2.0000   f(x) =  16.0000
  x =   1.2000   f(x) =  10.2400
  x =   0.5600   f(x) =   6.5536
  x =   0.0480   f(x) =   4.1943
  x =  -0.3616   f(x) =   2.6844
  x =  -0.6893   f(x) =   1.7180
```

看轨迹：$x$ 从 2 一路向 $-2$ 逼近，$f(x)$ 从 16 一路掉到 0。注意每步的 $x$ 变化量——从 $2\to1.2\to0.56\to0.048$——**步幅在逐次缩小**。原因正是凸函数的签名：离碗底越近，$f'(x)=2x+4$ 越接近 0，$-\eta f'(x)$ 的步幅越小。碗的几何，被梯度自动翻译成了收敛的节奏。

## 层二：分步逐函数拆解

### 步骤 1：目标函数与导数——碗的方程

```python
def f(x):
    return x ** 2 + 4.0 * x + 4.0

def df(x):
    return 2.0 * x + 4.0
```

#### `f` —— 凸目标函数

**操作**：计算 $f(x) = x^2 + 4x + 4 = (x+2)^2$。注意配方后的形式直接暴露碗底：$(x+2)^2 \ge 0$，等号在 $x=-2$。
**输入**：标量 `float`（或 NumPy 数组，运算逐元素）。**输出**：标量 `float`。
**可调参数**：把常数改成 `(x - 3) ** 2`，碗底挪到 3。改成 `x ** 4`，碗底仍是 0 但底部更平（梯度更缓，收敛更慢）——**你会直观看到"平底凸函数"收敛变慢**，这是凸优化"容易但可能慢"的一个缩影。

#### `df` —— 导数（梯度）

**操作**：计算 $f'(x) = 2x + 4$。在凸函数上，导数单调递增——这是凸性的微分签名（一维：凸 ⟺ 导数非减）。
**输入**：标量 `float`。**输出**：标量 `float`。
**可调参数**：无直接参数。若目标是 $x^2$（图 5.5），则 `df` 应为 `2.0 * x`。**注意**：导数从 0 到 $|x|$ 处处存在——$f$ 是**光滑**凸函数。若换成 $|x|$（在 0 处不可微），`df` 无从定义，那就要动用主线的第三套武器——次梯度/近端方法。

**对应数学**：主线的定义块——凸函数 $f$ 与其导数。对凸函数，负梯度方向 $-\nabla f$ 是**最陡下降方向**，且保证不升。

---

### 步骤 2：梯度下降主循环——下山的每一步

```python
x = 2.0
lr = 0.1
iters = 50
traj = []
for t in range(iters):
    traj.append((x, f(x)))
    x = x - lr * df(x)
```

#### 更新规则 `x = x - lr * df(x)`

**操作**：这就是梯度下降的全部核心——$x_{t+1} = x_t - \eta f'(x_t)$。读法：**当前点沿着负梯度方向迈出一步，步长 = 学习率 × 梯度。** 梯度的方向告诉你"碗壁往哪边塌"，负梯度就是"下降"的方向；梯度的大小告诉你"塌得多陡"，陡就迈大步，缓就迈小步。
**输入**：`x`（当前位置）、`lr`（学习率）、`df(x)`（当前梯度）。**输出**：更新后的 `x`。
**可调参数**：
- `lr = 0.1`：学习率，下山步子的缩放。改小到 `0.01`——收敛变慢，50 步到不了 $-2$；改大到 `0.9`——在碗底两侧**震荡**（$x$ 在 $-2$ 附近反复横跳）；改成 `1.5` 以上——**发散**，$x$ 越走越远（梯度爆炸）。试试这三个值，你会亲眼看到学习率的全部脾气。
- `iters = 50`：迭代次数。凸函数上，越多步越接近碗底，但收益递减——因为越接近底部步幅越小。
- `traj.append(...)`：记录每步位置，供打印轨迹。删掉它不影响收敛，只影响观察。

**对应数学**：主线的求解武器 (a)——梯度下降。图 5.5 的蓝点就是 `traj` 里这些 $(x, f(x))$。

### 步骤 3：结果与轨迹检查

```python
print(f"最终 x = {x:.6f}  (解析解 -2.0)")
print(f"最终 f(x) = {f(x):.6f}  (解析值 0.0)")
```

**操作**：打印收敛结果，与解析解（配方得到的 $-2$ 和 0）对照。
**输出**：`x ≈ -1.999943`、`f(x) ≈ 0.0`——误差来自 50 步之后 $0.8^{50}\approx1.4\times10^{-5}$ 的剩余项（每步因子 $1-\alpha\cdot2=0.8$），不是算法错误；多跑几步误差会更小。
**可调参数**：把 `iters` 提到 500，误差会小到 $10^{-11}$ 量级。

**对应数学**：这里在验证主线的核心保证——**凸函数上，任意起点的梯度下降都收敛到同一个全局最优**。换起点（`x = -10.0`）重跑，你会得到同一个 $-2$——这就是"局部最优=全局最优"在数值上的直接体现。

## 实验台：亲手触碰凸性的边界

1. **换起点**：`x = -10.0` 从左边下山，仍收敛到 $-2$——凸性保证"从哪来都到同一个底"。
2. **调学习率**：`lr = 1.2` 观察发散，`lr = 0.5` 观察震荡，`lr = 0.01` 观察龟速。你会懂得"学习率是凸优化里唯一真正要紧的超参数"。
3. **换成非凸函数**：把 `f` 改成 $g(x) = x^4 - 8x^2 + 16$（双碗），`df` 改为 $4x^3 - 16x$。从 `x = 0` 出发——梯度为 0，**原地不动**，停在一个局部极大（鞍顶）；从 `x = 2` 出发——滑进右边的碗。**同一个函数，不同的起点，不同的归宿**——非凸的丘陵困境，你亲手重现了。
4. **接上带约束版本**：主线教材例 $f(x) = x^2+4x+4$，约束 $x \ge -1$。给更新加一行 `x = max(x, -1.0)`（投影回可行域），观察解被顶到边界 $x=-1$——这就是"最优解在碗底或边界"的凸直觉。

**对应数学**：实验 3 与主线"丘陵 vs 碗"的 Toy Model 直接对应——非凸函数让"起点决定命运"。理解这个，你就理解了深度学习为什么如此在意初始化与优化器设计（§5.6）。
