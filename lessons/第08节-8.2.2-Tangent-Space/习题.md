# §8.2.2 切空间与梯度 —— 习题

本章主线讲了三件事：切空间是流形在某点的"方向集合"（局部线性化）；梯度 $\nabla L(\theta_t)$ 是切空间里指向最陡上升的向量；梯度下降 $\theta_{t+1} = \theta_t - \eta\nabla L(\theta_t)$ 每次只在脚下重新测量切空间。下面的习题分三组：**概念检验** 验证核心定义，**计算实践** 把切平面与梯度下降亲手算一遍（含代码验证），**DL 延伸** 把切空间放回优化器的真实场景。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：关于切空间 $T_pM$，哪个说法**错误**？

- A. $T_pM$ 是一个向量空间，维数与流形 $M$ 的维数相同
- B. $T_pM$ 包含从 $p$ 出发、贴着流形的所有移动方向
- C. 把切向量沿流形延伸很远，它仍然精确贴在切平面上
- D. $T_pM$ 是流形在 $p$ 点的线性近似

**解答**：C。

C 错：切平面是**一阶**近似，只在 $p$ 附近精确。把切向量沿流形"延伸"时，流形的弯曲会让真实路径偏离切平面——离 $p$ 越远，偏离越大（代码输出里切平面高度 2.40 vs 真实 2.65 就是这个偏离）。A 对：切空间是向量空间（方向可相加、可缩放），维数 = 流形维数。B 对：切空间精确地装着"从 $p$ 能往哪些方向走"。D 对：这是切空间的定义性描述。

**思路点拨**：题眼是"切空间是局部的"。最容易错的是 C——把"方向属于切空间"误当成"延长后的路径也属于切平面"。方向是**瞬间**的量，延长是**有限**的量，两者之间隔着曲率。判据：切空间只回答"从 $p$ 出发朝哪个方向"，不回答"沿这个方向走很远到哪里"。

### 题 2（判断 + 简答）：梯度一定在切空间里吗？

一个训练中的网络，损失景观 $L(\theta)$ 在参数点 $\theta_t$ 处有切空间 $T_{\theta_t}$。梯度 $\nabla L(\theta_t)$ 属于 $T_{\theta_t}$ 吗？为什么？这对"梯度下降的方向选择"意味着什么？

**解答**：**属于。** 梯度由偏导数 $\partial L/\partial \theta_i$ 组成，而偏导数正是"沿第 $i$ 个参数方向（切空间的一个方向）的瞬时变化率"。由切空间的定义（由坐标方向偏导张成），$\nabla L(\theta_t)$ 就是这个张成空间里的一个向量——它天然属于 $T_{\theta_t}$。

这意味着梯度下降从不需要"跳出"参数空间去决定方向：它只在当前点的切空间内部做选择。**参数更新 $\theta_{t+1} = \theta_t - \eta\nabla L(\theta_t)$ 的每一步，都在切空间里挑一个向量、乘以步长、迈出去。** 方向的选择被切空间完全封装了。

**思路点拨**：这道题把主线最关键的断言——"梯度住在切空间里"——变成判断题。它考的是偏导数的定义与切空间定义的一致性。若你理解了这一点，就理解了为什么梯度下降每步都"重算梯度"（因为参数点变了，切空间换了，脚下的坡度也换了）。

### 题 3（简答）：为什么梯度下降每次都要"重新测量梯度"？

梯度下降的更新式每步都要求重新计算 $\nabla L(\theta_t)$。为什么不能在一开始算一次梯度，之后一直沿着同一个方向走？用切空间的观念解释。

**解答**：因为**切空间是随点而变的**。流形（损失景观）在弯曲，每个参数点 $\theta_t$ 脚下的切平面都不同——在 $\theta_t$ 处算出的梯度，只精确描述"从 $\theta_t$ 出发瞬间"的最陡方向。一旦你迈出一步到 $\theta_{t+1}$，地形变了，原来的梯度已经过时：它描述的是 $\theta_t$ 的坡度，不是 $\theta_{t+1}$ 的。

用切空间的观念说：每一步之后，你进入了一个**新的切空间** $T_{\theta_{t+1}}$。优化器必须在新切空间里重新测量梯度，否则等于用旧地图走新地形。

**思路点拨**：这是"切空间是局部近似"直接推导出的操作纪律。最容易的反直觉点：对凸二次函数（抛物面），其实可以解析地一步到位（牛顿法），但真实神经网络的损失景观远非二次，切空间只在脚下可信。这也为 8.3.1 的鞍点困境埋下伏笔——在鞍点附近梯度接近零，重新测量多次也几乎为零，所以优化会卡住。

## 二、计算实践

### 题 1（切平面的方程与一阶近似）

设损失函数 $L(\theta_1, \theta_2) = \theta_1^2 + 3\theta_2^2$（椭圆抛物面），考虑点 $p = (1, 2)$。

(a) 写出 $L$ 在 $p$ 处的值、梯度、以及切平面方程。
(b) 在 $p$ 处沿方向 $v = (1, 1)$ 的方向导数是多少？沿单位化的梯度方向呢？两者哪个大？
(c) 用切平面近似计算 $L(1.1, 2.1)$，并与真实值比较，解释误差来源。

**解答**：

(a) $L(1,2) = 1^2 + 3\cdot 2^2 = 1 + 12 = 13$。梯度 $\nabla L = (2\theta_1, 6\theta_2)$，在 $(1,2)$ 处为 $(2, 12)$。切平面（一阶泰勒展开）：

$$L \approx 13 + 2(\theta_1 - 1) + 12(\theta_2 - 2)$$

(b) 方向导数 $D_v L = \nabla L \cdot v = 2 \cdot 1 + 12 \cdot 1 = 14$。梯度方向单位化：$\hat g = \frac{(2,12)}{\|(2,12)\|} = \frac{(2,12)}{\sqrt{148}} \approx (0.164, 0.986)$，方向导数 $= \|\nabla L\| \cdot 1 = \sqrt{148} \approx 12.166$。

**比较**：$14$ 和 $12.166$——看起来 $v = (1,1)$ 的方向导数更大？不对，这里有个陷阱：$v = (1,1)$ 不是单位向量，它的模长是 $\sqrt{2} \approx 1.414$。方向导数 $D_v L = \nabla L \cdot v$ 随 $v$ 的模长线性放大。单位化后 $(1,1)$ 变成 $(0.707, 0.707)$，方向导数 $= 2 \cdot 0.707 + 12 \cdot 0.707 = 14/\sqrt{2} \approx 9.9 < 12.166$。**对单位方向而言，梯度方向的方向导数最大（$= \|\nabla L\|$），任何其他单位方向都更小。** 这就是"梯度 = 最陡上升方向"的数值证据。

(c) 切平面近似：$L \approx 13 + 2(0.1) + 12(0.1) = 13 + 0.2 + 1.2 = 14.4$。真实值：$L(1.1, 2.1) = 1.21 + 3 \times 4.41 = 1.21 + 13.23 = 14.44$。误差 $0.04$——来自二阶项（曲率）：$\frac{1}{2}\Delta\theta^\top H \Delta\theta$，其中 Hessian $H = \text{diag}(2, 6)$，$\frac{1}{2}(2 \times 0.01 + 6 \times 0.01) = 0.04$。**切平面差掉的正是曲率那部分。**

**NumPy 验证**：
```python
import numpy as np

def L(x, y): return x**2 + 3*y**2
def grad(x, y): return np.array([2*x, 6*y])

p = np.array([1.0, 2.0])
v = np.array([1.0, 1.0]); v_hat = v / np.linalg.norm(v)
g = grad(*p)
print("切平面近似 L(1.1,2.1) =", L(*p) + g @ np.array([0.1, 0.1]))
print("真实值              =", L(1.1, 2.1))
print("梯度方向单位化方向导数 =", g @ (g / np.linalg.norm(g)))
print("任意单位方向 v_hat 方向导数 =", g @ v_hat, "（应小于前者）")
```
```
切平面近似 L(1.1,2.1) = 14.4
真实值              = 14.44
梯度方向单位化方向导数 = 12.165525060596439
任意单位方向 v_hat 方向导数 = 9.899494936611665
```

**思路点拨**：(b) 是最容易错的——方向导数 $D_v L = \nabla L \cdot v$ 的"最陡"结论只对**单位方向**成立。忘了归一化，任何向量都可以靠拉长来"超过"梯度。判据：比较方向时先把它们都单位化。(c) 展示了切平面是"一阶工具"：它与真实值的差正好是二阶（Hessian）项——这正是 8.2.4 曲率要补上的信息。

### 题 2（梯度下降的步长与收敛）

对 $L(\theta) = \theta^2$（一元），从 $\theta_0 = 3$ 出发，梯度下降 $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$。

(a) 写出 $\nabla L$，并用 $a = 1 - 2\eta$ 把更新写成 $\theta_{t+1} = a\,\theta_t$ 的形式。
(b) 对 $\eta = 0.4$，迭代 5 步，看 $\theta_t$ 与 $L_t$ 的变化。
(c) 对 $\eta = 1.1$（> 1），迭代几步，发生了什么？用 $a$ 解释收敛/发散的判据。

**解答**：

(a) $\nabla L = 2\theta$。更新：$\theta_{t+1} = \theta_t - \eta \cdot 2\theta_t = (1 - 2\eta)\theta_t$。记 $a = 1 - 2\eta$。

(b) $\eta = 0.4 \Rightarrow a = 1 - 0.8 = 0.2$。$\theta_t = 3 \cdot (0.2)^t$：

| t | $\theta_t$ | $L_t = \theta_t^2$ |
|---|---|---|
| 0 | 3.0000 | 9.0000 |
| 1 | 0.6000 | 0.3600 |
| 2 | 0.1200 | 0.0144 |
| 3 | 0.0240 | 0.0006 |
| 4 | 0.0048 | 0.0000 |

收敛很快——每一步把 $\theta$ 乘 0.2，损失按 $0.04$ 倍衰减。

(c) $\eta = 1.1 \Rightarrow a = 1 - 2.2 = -1.2$，$|a| = 1.2 > 1$。$\theta_t = 3(-1.2)^t$：$3 \to -3.6 \to 4.32 \to -5.184 \to \dots$——**振幅逐格放大，发散**。判据：收敛当且仅当 $|a| = |1 - 2\eta| < 1$，即 $0 < \eta < 1$。$L(\theta) = \theta^2$ 的曲率是 $2$（Hessian = 2），所以临界学习率 $\eta_{\max} = 2/\text{曲率} = 1$。$a = -1.2$ 还意味着参数**振荡**（符号交替）——这正是"过大学习率导致震荡甚至爆炸"的代数来源。

**思路点拨**：这道题把梯度下降的收敛性化成几何级数 $a^t$。关键洞察：**收敛判据 $|a| < 1$ 直接由曲率（二阶导数）决定**——这就是为什么一阶方法的学习率要参考二阶信息（曲率）来设定。牛顿法（8.3.1）用 $\theta_{t+1} = \theta_t - H^{-1}\nabla L$ 一步到达谷底，正是因为它显式使用了曲率。你的代码练习：把代码.md 的 `ETA` 改成 1.1，看抛物面二维版本是否同样发散。

### 题 3（从二维抛物面到任意二次函数）

代码.md 的抛物面 $L = x^2 + y^2$ 各向对称，梯度下降沿对角线直冲谷底。现在换成 $L = x^2 + 10y^2$（扁碗）。

(a) 预测：梯度下降路径还会是直线吗？$y$ 方向比 $x$ 方向陡多少倍？
(b) 运行代码，观察路径在 $y$ 方向是否有振荡或"S 形"蛇行，解释原因。

**解答**：

(a) 不再是直线。梯度 $\nabla L = (2x, 20y)$——$y$ 方向的坡度是 $x$ 方向的 10 倍。每次更新，$y$ 分量被放大了 10 倍地移动，但都用同一个学习率 $\eta$。$\eta$ 必须小到 $y$ 方向不爆炸，这导致 $x$ 方向（平缓方向）走得极慢——**路径会先冲 $y$、再沿 $x$ 缓慢爬行，呈现"S 形"蛇行或锯齿状振荡**。

(b) 代码：

```python
import numpy as np

def L(x, y): return x**2 + 10*y**2
def grad(x, y): return np.array([2*x, 20*y])

def gd(start, eta, steps):
    p = np.array(start, dtype=float); path = [p.copy()]
    for _ in range(steps):
        p = p - eta * grad(*p)
        path.append(p.copy())
    return np.array(path)

for eta in (0.05, 0.09, 0.12):
    path = gd((1.0, 1.0), eta, 20)
    y_vals = path[:, 1]
    print("eta=%.2f  y 轨迹前6格: %s" % (eta, np.round(y_vals[:6], 4)))
    print("        最终 L = %.5f" % L(*path[-1]))
```
```
eta=0.05  y 轨迹前6格: [1.    0.    0.   -0.   -0.    0.   ]
        最终 L = 1.00000
eta=0.09  y 轨迹前6格: [1.     -0.8     0.64   -0.512   0.4096 -0.3277]
        最终 L = 0.28053
eta=0.12  y 轨迹前6格: [1.     -1.4     1.96   -2.744   3.8416 -5.3782]
        最终 L = 29.65085
```

看 `eta=0.09`：$y$ 在 $1 \to -0.8 \to 0.64 \to -0.512 \dots$ **左右振荡、缓慢衰减**（对应 $a_y = 1 - 20\times0.09 = -0.8$），而 $x$ 方向几乎没动（$a_x = 1 - 0.18 = 0.82$）。`eta=0.12` 时 $y$ 方向已经发散（$|1-20\times0.12| = 1.4 > 1$）。**一个学习率要同时伺候两个方向曲率差 10 倍的坐标——这是用一阶切空间走非各向同性地形的典型痛苦**，也是 Adam 这类自适应方法存在的理由（它在切空间里按方向单独缩放步长）。

**思路点拨**：这道题预告了"曲率异质性"问题。判据藏在 $a_i = 1 - 2\eta\cdot\lambda_i$（$\lambda_i$ 是第 $i$ 方向曲率）里：任何方向 $|a_i| \ge 1$ 就发散。所以 $\eta$ 被最陡方向的曲率锁死，而最缓方向又因此走不动——**Hessian 特征值跨度越大，普通梯度下降越慢**。8.3.1 会用 Hessian 特征值精确刻画这个困境。

## 三、DL 延伸

### 题 1（梯度裁剪与切空间的安全步长）

训练 RNN 时损失可能剧烈震荡，常见做法是**梯度裁剪 (gradient clipping)**：如果 $\|\nabla L\| > c$，就把它缩放到 $\|\nabla L\| = c$ 再更新。

(a) 用切空间的语言，梯度裁剪做了什么？它改变了梯度的什么、不改变什么？
(b) 为什么"只改长度不改方向"能缓解训练的不稳定？

**解答**：

(a) 梯度裁剪把切空间里的向量 $\nabla L$ 缩放到最大模长 $c$：$\tilde g = \nabla L \cdot \min(1, c/\|\nabla L\|)$。它**改变了梯度向量的长度（步长）**，**不改变方向**——裁剪后的向量仍然指向切空间里的同一个最陡方向。也就是说：方向选择（切空间里指向哪）完全不变，只是把"迈多远"限制在安全范围内。

(b) 训练不稳定的来源之一，是某个参数点的切空间里出现"异常陡峭"的梯度（数值上可能来自长程依赖的梯度爆炸）。此时方向可能还是对的，但步长过大——用切空间的语言说，**一阶近似的有效范围是有限的，步长超过曲率决定的临界值，切平面就不可信了**。梯度裁剪保证步长不越过这个安全区，于是训练稳定。它本质上是"在切空间里限速"。

**思路点拨**：这道题考"梯度向量的两个属性（方向与长度）哪个承载几何信息"。方向由切空间的坡度结构决定（几何），长度由优化步长决定（策略）。裁剪动策略、不动几何——所以它能稳定训练而不改收敛目标。最容易的错答案是"裁剪会改变下降方向"——不会，方向是 $\nabla L$ 的归一化信息。

### 题 2（在约束流形上优化：球形参数）

假设你要训练一个参数**约束在球面 $\|\theta\| = 1$ 上**的模型（例如一些归一化方法把权重钉在单位球上）。

(a) 在约束下，梯度 $\nabla L(\theta)$ 还能直接用来更新参数吗？为什么？
(b) 正确的做法是什么？（提示：把梯度投影到切空间 $T_\theta S^{n-1}$ 上再更新，更新后重新归一化）

**解答**：

(a) **不能直接用。** 普通的 $\nabla L(\theta)$ 在欧氏参数空间里指向最陡上升，但它可能有一个"径向分量"（指向改变 $\|\theta\|$ 的方向）——而约束要求 $\|\theta\| = 1$ 恒定，径向移动会违反约束。**约束流形把参数限制在曲面上，梯度下降到中途会"飞离"球面。**

(b) 正确做法是**黎曼梯度下降 (Riemannian gradient descent)**：先把欧氏梯度投影到球面在 $\theta$ 点的切空间 $T_\theta S^{n-1}$（去掉径向分量，保留切向分量），在切空间里迈步，再用"指数映射"或重新归一化把参数放回球面。即：

$$\theta_{t+1} = \mathrm{Proj}\big(\theta_t - \eta\, \mathrm{Proj}_{T_{\theta_t}S}(\nabla L(\theta_t))\big)$$

两步：投影到切空间（方向合法）→ 更新后投影回流形（位置合法）。这正是一般黎曼优化在流形上的范式：**方向活在切空间里，位置活流形上，两步之间靠投影/映射搭桥。**

**思路点拨**：这是切空间思想在**带约束优化**里的直接应用——比主线更严格地展示了"为什么梯度必须活在切空间里"。判据：约束流形上，合法移动方向 = 切空间里的方向；欧氏梯度会越界。自然梯度下降（8.3.4）也是这个范式的延伸：它用 Fisher 信息矩阵做度量的"黎曼梯度"，本质上也是在非欧几何下重新定义"切空间里的一步有多远"。想透彻理解优化器在弯曲空间里的运作，这道题是一个很好的枢纽。
