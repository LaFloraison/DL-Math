# §8.2.2 切空间与梯度 · 代码

主线里我们看见：梯度就是切空间里指向"最陡上升"的向量，梯度下降每次都在脚下的切平面里挑方向、迈一步，再重新测量。这节代码，把这句话落到教材 Figure 8.1 的抛物面 $z = x^2 + y^2$ 上，亲手验证三件事：① 抛物面上一点 $(1,1,2)$ 处的切平面方程长什么样；② 梯度向量是不是真的躺在切平面上、并指向最陡方向；③ 梯度下降沿切平面里的负梯度方向走，路径是否真的逼近谷底 $(0,0)$。

需要的环境：Python 3.8+ 与 `numpy`、`matplotlib`。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方。

```python
"""
§8.2.2 切空间与梯度 · 代码.md
用抛物面 z = x^2 + y^2 演示切空间与梯度下降：
切平面方程 + 梯度向量验证 + 梯度下降路径。

运行：python 代码.py    （依赖 matplotlib）
"""

import numpy as np
import matplotlib.pyplot as plt

ETA = 0.1        # 学习率
X0, Y0 = 1.0, 1.0   # 起始点 (抛物面上的 (1,1,2))
N_STEPS = 10     # 梯度下降步数


def paraboloid(x, y):
    """损失函数 L = x^2 + y^2。返回形状与输入相同的函数值。"""
    return x**2 + y**2


def gradient(x, y):
    """损失函数的梯度 (dL/dx, dL/dy) = (2x, 2y)。"""
    return 2.0 * x, 2.0 * y


def tangent_plane(x0, y0, X, Y):
    """在 (x0, y0) 处构造切平面: z = f0 + fx*(X-x0) + fy*(Y-y0)。"""
    f0 = paraboloid(x0, y0)
    fx, fy = gradient(x0, y0)
    return f0 + fx * (X - x0) + fy * (Y - y0)


def gradient_descent(grad_fn, start, eta=ETA, n_steps=N_STEPS):
    """从 start 出发沿负梯度方向迭代 n_steps 步，返回路径 (list of 2-tuples)。"""
    x, y = start
    path = [(x, y)]
    for _ in range(n_steps):
        gx, gy = grad_fn(x, y)          # 重新测量脚下的切空间（梯度）
        x, y = x - eta * gx, y - eta * gy   # 沿负梯度迈一小步
        path.append((x, y))
    return path


def verify_tangent_vector(x0, y0, vx, vy):
    """验证向量 (vx,vy) 沿切平面方向移动时，与平面精确贴合（一阶条件）。"""
    # 沿向量方向移动小步 d，比较切平面预测的增量与实际函数增量的一阶项
    fx, fy = gradient(x0, y0)
    dir_gain = fx * vx + fy * vy          # 函数沿该方向的方向导数
    return float(dir_gain)


def plot_tangent_plane_and_descent(path):
    """画抛物面 + (1,1) 处切平面 + 梯度下降路径。"""
    xs = np.linspace(-1.5, 1.5, 40)
    X, Y = np.meshgrid(xs, xs)
    Z = paraboloid(X, Y)
    Zt = tangent_plane(X0, Y0, X, Y)      # 切平面：在 (1,1,2) 处贴着抛物面

    fig = plt.figure(figsize=(8, 6))
    ax = fig.add_subplot(111, projection="3d")
    ax.plot_surface(X, Y, Z, alpha=0.5, cmap="viridis")
    ax.plot_surface(X, Y, Zt, alpha=0.5, color="yellow")  # 切平面

    px = [p[0] for p in path]
    py = [p[1] for p in path]
    pz = [paraboloid(p[0], p[1]) for p in path]
    ax.plot(px, py, pz, "r-o", label="梯度下降路径")

    gx, gy = gradient(X0, Y0)
    ax.quiver(X0, Y0, paraboloid(X0, Y0),
              -gx * 0.3, -gy * 0.3, -(gx**2 + gy**2) * 0.3,
              color="red", label="负梯度方向 (在切平面内)")
    ax.set_xlabel("θ1"); ax.set_ylabel("θ2"); ax.set_zlabel("L")
    ax.legend()
    plt.title("抛物面 z=x²+y² 的切平面与梯度下降路径")
    plt.show()


# ---------------- 主流程 ----------------
path = gradient_descent(gradient, (X0, Y0))

print("切平面在 (1,1,2) 处的方程:")
print("  L = 2 + 2*(x-1) + 2*(y-1)   （因为 f=2, df/dx=2, df/dy=2）")
print("  验证: 切平面上点 (1.2, 1.1) 处平面高度 =", round(tangent_plane(1.0, 1.0, 1.2, 1.1), 4))
print("        真实函数高度            =", round(paraboloid(1.2, 1.1), 4))

print("\n梯度向量与方向导数 (梯度 = 切空间中最陡上升方向):")
gx, gy = gradient(X0, Y0)
print("  梯度 ∇L(1,1) = (%.1f, %.1f)" % (gx, gy))
print("  沿任意方向 v 的方向导数 = ∇L·v；梯度方向使这个数最大")

print("\n梯度下降路径 (学习率 η = %.2f):" % ETA)
for i, (x, y) in enumerate(path):
    print("  t=%d   θ=(%.4f, %.4f)   L=%.6f" % (i, x, y, paraboloid(x, y)))

plot_tangent_plane_and_descent(path)
```

## 层二：分步逐函数拆解

### 步骤 1：损失函数与梯度 —— `paraboloid(x, y)`、`gradient(x, y)`

```python
def paraboloid(x, y):
    return x**2 + y**2

def gradient(x, y):
    return 2.0 * x, 2.0 * y
```

#### `paraboloid(x, y)` —— 一只能装下一切的碗

**操作**：返回 $L = x^2 + y^2$。`x`、`y` 可以是标量、一维数组或二维网格——`**` 与 `+` 对 numpy 数组逐元素生效，所以这个函数既能算单个点的损失，也能算整片网格（用于绘图）。

**对应数学**：这就是教材 Figure 8.1 的抛物面，也是主线四的数值例子的函数。它是最简单的**凸**损失：唯一的最小值在谷底 $(0,0)$，梯度下降从任何起点都能到达。

**输入**：`x`、`y` —— 标量或 `numpy.ndarray`，参数坐标 $\theta_1, \theta_2$。

**输出**：与输入同形状的数组/标量，损失值 $L$。

**可调参数**：没有参数可调——但如果你把函数体换成 `x**2 + 10*y**2`，碗就被压成"长条碗"（椭圆抛物面），梯度下降会沿陡峭的 $y$ 方向振荡——这是后面可调参数里最有启发性的实验。

#### `gradient(x, y)` —— 脚下滑坡的仪表盘

**操作**：返回 $(\partial L/\partial x, \partial L/\partial y) = (2x, 2y)$。对抛物面来说，梯度是一个**解析**已知的式子；对真实神经网络，这个结果由反向传播（链式法则）算出来——但它的数学含义完全相同：每个方向上的瞬时变化率。

**对应数学**：这就是主线里 $\nabla L(\theta_t)$ 的具体实现。$\nabla L = (2x, 2y)$ 在 $(1,1)$ 处是 $(2,2)$——它指向"损失增长最快"的方向（右上），梯度下降走它的反方向。

**输入**：`x`、`y` —— 标量或数组，当前参数点。

**输出**：`(gx, gy)` 两个数/数组，梯度两个分量。

**可调参数**：`gradient` 是 `paraboloid` 的配套函数——换损失函数必须同步换梯度，否则梯度下降走的根本不是这座山的坡度（这正是"梯度与函数必须一致"的陷阱，见验证环节）。

### 步骤 2：切平面方程 —— `tangent_plane(x0, y0, X, Y)`

```python
def tangent_plane(x0, y0, X, Y):
    f0 = paraboloid(x0, y0)
    fx, fy = gradient(x0, y0)
    return f0 + fx * (X - x0) + fy * (Y - y0)
```

#### `tangent_plane(x0, y0, X, Y)` —— 把切空间画出来

**操作**：在 $(x_0, y_0)$ 处，用泰勒展开的一阶项构造平面：$L \approx f_0 + f_x (X - x_0) + f_y (Y - y_0)$。其中 $f_0 = x_0^2 + y_0^2$ 是切点高度，$f_x = 2x_0$、$f_y = 2y_0$ 是切点处沿两个坐标方向的坡度。`X, Y` 是网格坐标，返回网格上每个点的"切平面高度"。

**对应数学**：这就是主线定义块里"切空间是流形在 $p$ 点的线性化"的显式公式。一阶泰勒展开
$$f(x_0+\Delta x, y_0+\Delta y) \approx f(x_0,y_0) + \frac{\partial f}{\partial x}\Delta x + \frac{\partial f}{\partial y}\Delta y$$
正是切平面。它贴合曲面的精度是**一阶**：差一个 $O(\Delta^2)$ 的误差（由曲率决定），所以离切点越远，平面与曲面分得越开——代码输出里 2.40 vs 2.65 的差异就是这个二阶误差。

**输入**：
- `x0, y0`：标量，切点坐标。
- `X, Y`：`numpy.ndarray`（同形状网格），要求解切平面高度的点。

**输出**：`numpy.ndarray`，**形状与 `X` 相同**——每个网格点的切平面高度 $L$。

**可调参数**：
- `x0, y0`：换成 $(0,0)$，切平面变成水平面 $L=0$（谷底处坡度为零——梯度为零，梯度下降停在这里，这正是收敛点）；换成 $(1.5, 0)$，切平面朝 $x$ 方向陡峭倾斜。
- 还能不能有第三个参数？可以加一个 `order=2`，返回二阶泰勒展开（加上 Hessian 项）——那就是曲率近似的开始，8.2.4 的方向。

### 步骤 3：梯度下降 —— `gradient_descent(grad_fn, start, eta, n_steps)`

```python
def gradient_descent(grad_fn, start, eta=ETA, n_steps=N_STEPS):
    x, y = start
    path = [(x, y)]
    for _ in range(n_steps):
        gx, gy = grad_fn(x, y)          # 重新测量脚下的切空间（梯度）
        x, y = x - eta * gx, y - eta * gy   # 沿负梯度迈一小步
        path.append((x, y))
    return path
```

#### `gradient_descent(grad_fn, start, eta, n_steps)` —— 每一步只信脚下

**操作**：把 $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$ 迭代 `n_steps` 次。循环体只有两行：`grad_fn(x, y)` 测量当前点的梯度（重新建立切空间），`x - eta * gx, y - eta * gy` 沿负梯度方向走一步。`path` 记录每一站的坐标。

**对应数学**：这就是主线第三步那个更新式的逐行实现。它是整门深度学习的训练循环的雏形——真实的 PyTorch `optimizer.step()` 做的正是这同一件事，只是梯度来自反向传播、参数有成千上万个。

**输入**：
- `grad_fn`：函数，输入 $(x, y)$ 返回梯度 $(gx, gy)$。
- `start`：二元组，起点 $(\theta_1, \theta_2)$。
- `eta`：浮点数（可省略，默认 0.1），学习率。
- `n_steps`：整数（可省略，默认 10），迭代步数。

**输出**：`list`，长度 `n_steps + 1`，每项是 `(x, y)` 二元组——完整的梯度下降路径。

**可调参数**：
- `eta`（学习率）：最关键的旋钮。`eta=0.01` 时 10 步只走到 0.9 附近，收敛极慢；`eta=0.49` 时路径在谷底附近振荡但单调；`eta=1.0` 时每一格都在 $(1,1)$ 与 $(-1,-1)$ 之间横跳，永远不收敛——**学习率超过某个阈值，梯度下降从收敛变发散**（这个阈值与函数的光滑度/曲率有关，是二阶分析的对象）。
- `start`：从 $(10, 10)$ 出发，路径还是沿对角线直冲谷底（抛物面各向对称）；从 $(3, -2)$ 出发，路径走一条斜线。
- `n_steps`：加大到 100，损失会降到 $10^{-20}$ 量级——但打印时会溢出吗？不会，只是很小。
- 还能不能有第四个参数？可以加一个 `momentum=0.9`，实现动量法——它把历史速度并入更新，路径不再直线冲底，而是带一点"惯性"，这在鞍点附近（8.3.1）能帮模型冲过去。

### 步骤 4：方向导数验证 —— `verify_tangent_vector(x0, y0, vx, vy)`

```python
def verify_tangent_vector(x0, y0, vx, vy):
    fx, fy = gradient(x0, y0)
    dir_gain = fx * vx + fy * vy          # 函数沿该方向的方向导数
    return float(dir_gain)
```

#### `verify_tangent_vector(x0, y0, vx, vy)` —— 梯度是"最陡"的数学证明

**操作**：计算函数沿向量 $(v_x, v_y)$ 的方向导数 $\nabla L \cdot v = f_x v_x + f_y v_y$。它是一个标量——沿该方向每单位长度，函数增长多少。

**对应数学**：方向导数的定义 $D_v f = \nabla f \cdot v$。由柯西-施瓦茨不等式 $|\nabla f \cdot v| \le \|\nabla f\| \cdot \|v\|$，当 $v$ 与 $\nabla f$ 同向时取等号——**这就是"梯度指向最陡上升方向"的严格证明**。梯度不是"一个方向"，它是"所有方向中增长最快的那个方向"，其他任何方向的方向导数都更小。

**输入**：
- `x0, y0`：切点坐标。
- `vx, vy`：要检验的方向向量。

**输出**：`float`——方向导数。若要验证"梯度最陡"，比较 $v = \nabla f/\|\nabla f\|$ 与任意其他单位方向 $w$ 的方向导数，前者最大。

**可调参数**：
- `vx, vy`：换成 `(1, 0)` 得到"沿 $x$ 方向"的方向导数 2；换成单位化的梯度 $(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})$ 得到 $2\sqrt{2} \approx 2.828$，是最大的——试试其他单位方向，都不会超过它。

**操作**：`meshgrid` 生成 40×40 网格，`paraboloid` 算抛物面高度、`tangent_plane` 算切平面高度，两个 `plot_surface` 分别绘制；`path` 的每一站 `(x,y)` 用 `paraboloid` 换算高度后连成红色折线；`quiver` 在起点画出负梯度方向箭头（三轴分量 = 负梯度乘以小系数）。

## 一步验证：把学习率拧到"爆炸"

主线边界声明说，切空间是局部近似，走远了会偏离。把 `ETA` 调到 1.0 跑一遍：

```
  t=0   θ=(1.0000, 1.0000)   L=2.000000
  t=1   θ=(-1.0000, -1.0000)   L=2.000000
  t=2   θ=(1.0000, 1.0000)   L=2.000000
  ...
```

参数在 $(1,1)$ 和 $(-1,-1)$ 之间横跳，损失永远停在 2.0——不收敛也不发散。原因正在于切空间的一阶本性：在 $(1,1)$ 处，切平面说"往反方向走 $1\times$ 梯度就能到谷底"——但抛物面是弯的，一步迈了 2 个单位，已经冲过了谷底 $O(\Delta^2)$ 的曲率误差。**切空间只在脚下几步内可信；迈大步，一阶近似的谎言就暴露了。** 这也解释了为什么深度学习中过大的学习率会让训练发散——那不是数字问题，是你在试图用一阶的切空间走二阶级别的远路。
