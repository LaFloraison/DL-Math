# 代码：惩罚法——让越界付出代价

**目标**：主线里的面包店问题——最大化 $3x_1 + 2x_2$，约束为 $x_1+x_2 \le 10,\; x_1 \le 6,\; x_1 \ge 0,\; x_2 \ge 0$，已知解析最优解是 $(6,4)$，最优值 26。这里亲手实现**惩罚法**：把约束变成罚款，把约束问题改写成无约束问题，再用网格搜索求解。你会看到：罚得够重，优化器自己就学会了守规矩。

## 层一：完整脚本

```python
import numpy as np

# 1. 原始目标：最大化 3*x1 + 2*x2  => 最小化 -(3*x1 + 2*x2)
def objective(x):
    return -(3.0 * x[0] + 2.0 * x[1])

# 2. 惩罚法：把违反约束的量折算成罚款加进目标
def penalized(x, P=1000.0):
    x1, x2 = x
    viol = 0.0
    viol += max(0.0, (x1 + x2) - 10.0)   # 预算 x1+x2<=10 的越界量
    viol += max(0.0, x1 - 6.0)           # 产能 x1<=6 的越界量
    viol += max(0.0, -x1) + max(0.0, -x2)  # 非负约束的越界量
    return objective(x) + P * viol       # 总成本 = 目标 + 罚金

# 3. 在二维网格上扫描，找 penalized 的最小值
g1 = np.linspace(0.0, 8.0, 401)     # x1 的候选值
g2 = np.linspace(0.0, 12.0, 401)    # x2 的候选值
G1, G2 = np.meshgrid(g1, g2)        # 形状 (401, 401)
stack = np.stack([G1, G2], axis=-1) # 形状 (401, 401, 2)：每个格点一个 (x1,x2)

pen = np.zeros_like(G1)             # 形状 (401, 401)
for i in range(len(g1)):
    for j in range(len(g2)):
        pen[i, j] = penalized(stack[i, j], P=1000.0)

# 4. 挑出罚后总成本最小的格点
flat = pen.ravel()                  # 摊平成 (160801,)
idx = int(np.argmin(flat))          # 最小值的扁平下标
i, j = np.unravel_index(idx, pen.shape)  # 还原成二维下标
best = stack[i, j]                  # 最优点 (x1, x2)

print(f"惩罚法最优解: x1={best[0]:.4f}, x2={best[1]:.4f}")
print(f"原始目标值 3*x1+2*x2 = {-objective(best):.4f}  (解析最优 26.0)")
print(f"约束检验: x1+x2={best[0]+best[1]:.4f}(<=10), x1={best[0]:.4f}(<=6)")
```

输出：

```
惩罚法最优解: x1=6.0000, x2=4.0000
原始目标值 3*x1+2*x2 = 26.0000  (解析最优 26.0)
约束检验: x1+x2=10.0000(<=10), x1=6.0000(<=6)
```

网格搜索精确命中 $(6,4)$，因为 $(6,4)$ 恰好落在网格点上。现在做两个实验：把 `P=1000.0` 改成 `P=1.0`，观察解如何"越界"；把两个 `max(0.0, ...)` 中任何一个删掉，观察优化器如何光明正大地走进禁区。**惩罚法的一切性格，都藏在那个 $P$ 里。**

## 层二：分步逐函数拆解

### 步骤 1：原始目标——把最大化翻成最小化

```python
def objective(x):
    return -(3.0 * x[0] + 2.0 * x[1])
```

#### `objective` —— 原始利润的负号版

**操作**：输入决策变量 $(x_1, x_2)$，返回 $-3x_1 - 2x_2$。最大化利润 $3x_1+2x_2$ 与最小化它的相反数等价（主线学过）。
**输入**：`x` —— 长度 2 的序列（`list` 或 NumPy 数组），`x[0]=x1`、`x[1]=x2`。
**输出**：标量 `float`——负利润，即待最小化的"成本"。
**可调参数**：把系数 `3.0`/`2.0` 换成别的数，最优解的位置随之移动。注意这里**没有**约束逻辑——`objective` 根本不管点可不可行，它只负责算"不看围栏时的利润"。

**对应数学**：主线里的目标函数 $f(x) = -3x_1 - 2x_2$（最小化形式）。

---

### 步骤 2：惩罚法——越界的每一寸都要标价

```python
def penalized(x, P=1000.0):
    x1, x2 = x
    viol = 0.0
    viol += max(0.0, (x1 + x2) - 10.0)
    viol += max(0.0, x1 - 6.0)
    viol += max(0.0, -x1) + max(0.0, -x2)
    return objective(x) + P * viol
```

#### `penalized` —— 被罚款过的总成本

**操作**：先逐条检查三条约束的**违反量**，全部累加进 `viol`，再乘以惩罚系数 $P$ 加回目标。任何一条约束被违反，`max(0.0, ...)` 都会返回正的越界量；全部守规矩时 `viol=0`，函数退化成 `objective(x)`。
**输入**：`x`（决策变量）、`P=1000.0`（惩罚系数，默认 1000）。
**输出**：标量 `float`——"目标值 + 罚金"。这个值越小越好。
**可调参数**：
- `P`：整个方法的灵魂。`P=1` 时罚款太便宜，解会大幅越界（例如 $x_1+x_2=14$ 也"划算"）；`P=1e6` 时罚款贵得离谱，解几乎严格守规矩，但数值上梯度会变得极陡（主线说的"悬崖"）。教材和工程里常**递增 $P$**（先粗后细）。
- 三条约束行各有含义：`(x1+x2)-10.0` 对应预算不等式 $x_1+x_2\le 10$；`x1-6.0` 对应产能不等式 $x_1\le 6$；`-x1`、`-x2` 对应非负约束。**增删一行，就是增删一条约束**——这是惩罚法最方便的地方：约束越多，只是多累加几项罚款。

**对应数学**：主线定义块里的 $f(x) + P\sum_i \big(\max\{0,h_i(x)\}\big)^2$。教材用的惩罚项常带平方（$\max\{0,\cdot\}^2$），这里为了简单用了线性惩罚——结论一致，收敛行为略有差异，值得你试试把 `max(0.0, v)` 改成 `max(0.0, v)**2` 观察最优解如何变化。

---

### 步骤 3：二维网格——把可行域/禁区一起扫一遍

```python
g1 = np.linspace(0.0, 8.0, 401)
g2 = np.linspace(0.0, 12.0, 401)
G1, G2 = np.meshgrid(g1, g2)
stack = np.stack([G1, G2], axis=-1)
```

#### `np.linspace` —— 生成一维候选序列

**操作**：`g1` 在 $[0,8]$ 取 401 个等距点（$x_1$ 的候选），`g2` 在 $[0,12]$ 取 401 个等距点（$x_2$ 的候选）。间距分别为 $8/400=0.02$ 和 $12/400=0.03$。
**输入**：起点、终点、点数。
**输出**：两个形状 `(401,)` 的一维数组。
**可调参数**：点数越多越精确，但下面的双重循环代价按 $N^2$ 增长——**暴力网格的维度诅咒**，§5.3.6 梯度下降的出场理由。

#### `np.meshgrid` —— 把两条轴织成一张网

**操作**：`G1` 的每行都等于 `g1`，`G2` 的每列都等于 `g2`。于是 `(G1[i,j], G2[i,j])` 就是网格上第 $i$ 行第 $j$ 列那个点的坐标。
**输入**：`g1`、`g2` 两个一维数组。
**输出**：两个形状 `(401, 401)` 的二维数组——坐标矩阵。
**可调参数**：`indexing='ij'` 或默认的 `'xy'` 会影响输出的行列含义，对对称网格无差别，但做图像类数据时务必查文档。

#### `np.stack(..., axis=-1)` —— 把坐标合成一个点堆

**操作**：把 `G1`、`G2` 沿新开的最后一维拼起来，使得 `stack[i,j]` 是一个长度为 2 的向量 `(x1, x2)`。
**输入**：`[G1, G2]` 两个同形状数组，`axis=-1` 表示在最后追加一维。
**输出**：形状 `(401, 401, 2)` 的三维数组——每个格点一个坐标向量。
**可调参数**：`axis` 取 `0` 时得到 `(2, 401, 401)`，语义是"先坐标再格点"，访问方式随之改变。**注意**：这个三维结构正好喂给下面的 `penalized`，因为 `stack[i,j]` 就是一个 `(2,)` 向量。

---

### 步骤 4：逐格点评估 + 挑最小值

```python
pen = np.zeros_like(G1)
for i in range(len(g1)):
    for j in range(len(g2)):
        pen[i, j] = penalized(stack[i, j], P=1000.0)

flat = pen.ravel()
idx = int(np.argmin(flat))
i, j = np.unravel_index(idx, pen.shape)
best = stack[i, j]
```

#### `np.zeros_like(G1)` —— 准备存放罚后成本的画布

**操作**：生成一个与 `G1` 形状相同（`(401,401)`）、初值为 0 的浮点数组，用来逐格存放罚后总成本。
**输入**：模板数组 `G1`。
**输出**：同形状全零数组。
**可调参数**：无直接参数（`dtype` 默认沿用模板）。

#### `for` 双重循环 —— 显式网格评估

**操作**：对 401×401 = 160801 个格点逐一调用 `penalized`，把结果写入 `pen` 的对应位置。这里没有向量化（为了逐点讲透），实际工程会用 `np.vectorize` 或批量评估提速——但数学完全等价。
**输入**：`stack[i,j]` 每个格点的坐标向量。
**输出**：填满的 `pen` 数组，`pen[i,j]` 是格点 `(G1[i,j], G2[i,j])` 的罚后成本。

#### `np.ravel()` + `np.argmin` + `np.unravel_index` —— 找到全局最小格点

**操作**：`pen.ravel()` 把 `(401,401)` 摊平成 `(160801,)` 一维；`np.argmin` 找到最小值的**扁平下标**；`np.unravel_index(idx, pen.shape)` 把这个扁平下标还原成 `(i, j)` 二维坐标；最后 `stack[i,j]` 取出那个最优格点的坐标向量。
**输入**：`pen`（罚后成本矩阵）、`idx`（扁平下标）、`pen.shape`（原始形状）。
**输出**：`best` —— 长度为 2 的数组，即罚后总成本最小的点。
**可调参数**：想找最大值换 `np.argmax`。注意 `np.argmin` 只返回**第一个**最小值——如果有多个格点并列最小，它取行优先的第一个。

**对应数学**：这一整块在执行 $\arg\min_x \big[\text{objective}(x) + P \cdot \text{violation}(x)\big]$——主线里惩罚法的离散版。

---

### 步骤 5：打印与约束自检

```python
print(f"惩罚法最优解: x1={best[0]:.4f}, x2={best[1]:.4f}")
print(f"原始目标值 3*x1+2*x2 = {-objective(best):.4f}  (解析最优 26.0)")
print(f"约束检验: x1+x2={best[0]+best[1]:.4f}(<=10), x1={best[0]:.4f}(<=6)")
```

**操作**：输出最优点，用 `-objective(best)` 还原出原始利润（因为 `objective` 存的是负号版），并逐条打印约束的取值做自检——`x1+x2=10.0000<=10` 说明预算约束绑定，`x1=6.0000<=6` 说明产能约束绑定，与主线的分析完全一致。

---

## 实验台：亲手感受惩罚法的脾气

1. **把 `P` 改小**（如 `1.0`）：最优解会"越界"——因为罚款便宜，越界多赚的那点利润超过了罚款。
2. **把平方惩罚项** `max(0.0, ...)**2` 代替线性项：解会更平滑地靠近边界，但罚得越狠越接近严格可行。
3. **删掉 `x1 - 6.0` 那行**：解立刻变成 $(6.99, ...)$ 之类的越界值——你亲眼看到"少一条约束，世界就大了一圈"。

**对应数学**：这些都对应主线中"惩罚法把约束变成目标函数里的罚款"——约束不再是被硬性禁止的墙，而是标了价的选项。
