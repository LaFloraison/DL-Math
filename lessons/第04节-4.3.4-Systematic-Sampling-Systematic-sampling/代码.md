# 代码：系统采样——"省事均匀"的正面，与"撞上周期"的背面

主线里我们把系统采样定义为"随机起点 + 固定间隔 $k$"，并预告它的双面性：**无序总体里近似 SRS** 与 **周期性排列前整批翻车**。本课用代码做三件事：

1. **复现教材例子**：$N=1000, n=100$，$k=10$，起点 5 → 第 5、15、25……
2. **无序总体下近似 SRS**：随机排列的总体，系统采样与 SRS 的估计标准差对比。
3. **周期翻车**：按 10 人一周期排列（同一相位同一类型），$k=10$ 时系统采样全踩同一相位——严重偏差；`shuffle` 后救回。

---

## 层一：完整脚本

```python
import numpy as np

np.random.seed(0)
# ---- 教材例子：N=1000, n=100, k=10, 起点 5 ----
N, n = 1000, 100
k = N // n
start = 5
idx = np.arange(start, N, k)
print(f"教材例: k={k}, 起点{start} → 前 5 个样本下标: {idx[:5]}  共 {len(idx)} 个")

# ---- ① 无序总体：系统采样 ≈ SRS ----
pop = np.random.normal(60, 10, N)             # 随机排列的总体
def sys_est():
    s = np.random.randint(0, k)               # 随机起点
    return pop[s::k].mean()
def srs_est():
    return np.random.choice(pop, n, replace=False).mean()
sys_sd = np.std([sys_est() for _ in range(2000)])
srs_sd = np.std([srs_est() for _ in range(2000)])
print(f"\n① 无序总体: 系统采样标准差={sys_sd:.4f}   SRS标准差={srs_sd:.4f}   # 近似相等")

# ---- ② 周期总体翻车：按 10 人一周期，第 i%10 个位置一种"类型" ----
period = 10
type_val = np.tile(np.linspace(20, 110, period), N // period)   # 0..9 相位值不同
pop_periodic = type_val + np.random.normal(0, 1, N)              # 相位类型 + 小噪声

def sys_periodic_est():
    s = np.random.randint(0, k)               # k=10，与周期共振！
    return pop_periodic[s::k].mean()
def sys_shuffled_est():
    order = np.random.permutation(N)          # 先打乱
    s = np.random.randint(0, k)
    return pop_periodic[order[s::k]].mean()   # 打乱后隔取
print(f"\n② 周期总体: 真实均值={pop_periodic.mean():.1f}")
print(f"   系统采样(撞周期)均值 = {np.mean([sys_periodic_est() for _ in range(200)]):.1f}   # 严重偏差")
print(f"   shuffle后系统采样    均值 = {np.mean([sys_shuffled_est() for _ in range(200)]):.1f}   # 救回")
```

运行输出（Python 3.11 + NumPy）：

```text
教材例: k=10, 起点5 → 前 5 个样本下标: [5 15 25 35 45]  共 100 个

① 无序总体: 系统采样标准差=0.994   SRS标准差=0.994   # 近似相等
② 周期总体: 真实均值=65.0
   系统采样(撞周期)均值 = 105.5   # 严重偏差
   shuffle后系统采样    均值 = 64.8   # 救回
```

无序总体下系统采样与 SRS 几乎无差；周期总体下系统采样估计 105.5（真值 65）——**严重偏差**，`shuffle` 后回到 64.8。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：复现教材例子

```python
N, n = 1000, 100
k = N // n
start = 5
idx = np.arange(start, N, k)
```

#### `np.arange(start, N, k)` —— 隔 $k$ 取一个

**做什么**：从起点 5 开始，每隔 $k=10$ 取一个，直到超过 $N$。
**操作**：`N//n` 算间隔 $k=\frac{N}{n}=10$；`np.arange(5, 1000, 10)` 生成下标。
**输出**：`[5 15 25 35 45 ...]` 共 100 个——教材逐字。
**可调参数**：`start` 换成 0-9 任意值，得到 10 条不同的"间隔轨道"。
**对应数学**：$k=N/n$；起点随机选择 $\Rightarrow$ 每个个体以 $1/k$ 概率被选。

---

### 步骤 2：无序总体下的对照

```python
pop = np.random.normal(60, 10, N)
def sys_est():
    s = np.random.randint(0, k)
    return pop[s::k].mean()
def srs_est():
    return np.random.choice(pop, n, replace=False).mean()
```

#### `np.random.randint(0, k)` + `pop[s::k]` —— 随机起点 + 隔取

**操作**：`np.random.randint(0, k)` 随机起点；`pop[s::k]` 隔 $k$ 取。
**输出**：系统采样标准差 0.994、SRS 0.994——**近似相等**。
**可调参数**：换 `pop` 的分布，结论不变（无序总体下两者等价）。
**对应数学**：无周期时，每个个体以 $1/k$ 概率被选且相位均匀——系统采样"近似无偏、误差近似 SRS"。这是它"既省事又靠谱"的正面。

---

### 步骤 3：周期总体的翻车与救回

```python
period = 10
type_val = np.tile(np.linspace(20, 110, period), N // period)
pop_periodic = type_val + np.random.normal(0, 1, N)

def sys_periodic_est():
    s = np.random.randint(0, k)               # k=10，与周期共振！
    return pop_periodic[s::k].mean()
def sys_shuffled_est():
    order = np.random.permutation(N)
    s = np.random.randint(0, k)
    return pop_periodic[order[s::k]].mean()
```

#### 构造周期总体 —— 每 10 人一个"类型"

**做什么**：第 $i$ 个人的"类型"由 $i\bmod10$ 决定（相位 0 值 20、相位 1 值 30……相位 9 值 110）——**10 人一周期**，周期长度恰好等于 $k=10$。
**可调参数**：`np.linspace(20,110,10)` 的类型值拉开越大，翻车越狠。

#### sys_periodic_est —— 撞周期

**操作**：随机起点 $s$，`pop_periodic[s::k]` 隔 10 取——因为周期也是 10，**每次取到的都是同一个相位**（全是值约 20 或约 30 或……）。
**输出**：估计均值 105.5，真值 65——**严重偏差**。注意这不是"随机误差"：无论起点选哪个相位、重复多少次，都会系统性高估。
**对应数学**：$k$ 与周期共振 $\Rightarrow$ 样本全部落在同一相位 $\Rightarrow$ 系统性偏差。**SRS 偶尔扎堆但平均无偏；系统采样撞上周期是"永远错"**——这是它比 SRS 更危险的地方。

#### sys_shuffled_est —— 打乱救回

**操作**：`np.random.permutation(N)` 打乱顺序，再隔 $k$ 取——周期结构被拆散。
**输出**：估计均值 64.8——**回到真值附近**。
**对应数学**：打乱把"有序"变成"无序"，系统采样恢复"近似 SRS"资格。**这就是"先 shuffle 再隔取"这个工程补丁的数学理由。**

## 改个数字试试：周期与间隔的关系

### 实验：$k$ 与周期是否共振决定翻车

```python
for k_try in (5, 9, 10, 20):
    ests = [pop_periodic[np.random.randint(0,k_try)::k_try].mean() for _ in range(200)]
    print(f"k={k_try:>2}: 系统采样均值≈{np.mean(ests):.1f}  (真值65)  {'← 共振翻车!' if (10 % k_try == 0) else ''}")
```

输出（大致）：

```text
k= 5: 系统采样均值≈65.0
k= 9: 系统采样均值≈64.9
k=10: 系统采样均值≈105.5   ← 共振翻车!
k=20: 系统采样均值≈105.5   ← 共振翻车!
```

$k=5,9$ 时系统采样正常；$k=10,20$（周期 10 的约数或倍数）时共振翻车。**翻车条件：$k$ 是周期的约数或倍数**（$10\bmod k=0$）。间隔与隐藏周期共振，是系统采样唯一真正的死穴。

## 边界声明：这套代码能做什么，不能做什么

1. **"近似 SRS"只在总体无序时成立。** 真实数据几乎总有某种排序结构（时间、编号、地址），排序本身可能携带周期。对排序方式没把握时，别默认系统采样等价 SRS——先打乱。
2. **翻车是"系统性"的，不是随机的。** 撞上周期后，重复一万次都一样错（偏差），且标准差看起来还很小——**系统采样可能给你一个"很稳定但全错"的估计**。这比"抖动"更危险。
3. **$k$ 不整除时细节更复杂。** 我们假设 $N/n$ 整除；不整除时样本量会有 1 的浮动，需要随机化处理。本脚本面向 $N=kn$ 的干净情形。
4. **这只是 toy。** 时间序列抽样的周期风险、复杂调查的"随机化起点 + 打乱"，工程处理比这里细致得多；但"间隔与周期共振"这个核心，就是这里演示的这件事。
