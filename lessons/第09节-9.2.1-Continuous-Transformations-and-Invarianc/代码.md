# 代码：用 Betti 数给形状按指纹——圆和椭圆，真的同胚吗？

主线里我们断言：圆与椭圆同胚，因为存在一个不撕不粘的映射；环面（甜甜圈）与圆不同胚，因为环面有一个洞、圆没有。本节代码把这两个断言**算出来**。

工具是**拓扑不变量 (topological invariant)**——$(\beta_0, \beta_1)$：$\beta_0$ 是连通分量数（几块），$\beta_1$ 是 1 维环的个数（几个洞）。我们从点云出发，用**Vietoris–Rips 复形 (Vietoris–Rips complex)** 在给定尺度 $\varepsilon$ 下把点连成边、边连成三角形，再用线性代数（模 2 的高斯消元）算出同调数。脚本只依赖 Python 标准库的 `math`。

**剧本**：采样圆、椭圆、双圆、实心盘四组点云，分别算出 $(\beta_0, \beta_1)$，再看一条**度量性质**（平均边长）在圆与椭圆之间怎么变。

---

## 层一：完整脚本

```python
import math

def dist(a, b):
    """欧氏距离（唯一用到的度量——用来决定谁连谁）。"""
    return math.hypot(a[0]-b[0], a[1]-b[1])

def sample_curve(kind, k=40, **kw):
    """按角度采样闭合曲线：'circle' 圆 / 'ellipse' 椭圆 / 'disk' 实心盘。"""
    pts = []
    for t in range(k):
        ang = 2*math.pi*t/k
        if kind == "circle":
            pts.append((math.cos(ang), math.sin(ang)))
        elif kind == "ellipse":
            a, b = kw.get("a", 2.0), kw.get("b", 1.0)
            pts.append((a*math.cos(ang), b*math.sin(ang)))
        elif kind == "disk":            # 圆 + 内部填充，构成实心盘
            pts.append((math.cos(ang), math.sin(ang)))
            for r in (0.4, 0.75):
                pts.append((r*math.cos(ang), r*math.sin(ang)))
    return pts

def vrp_complex(points, eps):
    """在尺度 eps 下建 Vietoris–Rips 复形（顶点/边/三角形），返回三个列表。"""
    n = len(points)
    edges = [(i,j) for i in range(n) for j in range(i+1,n)
             if dist(points[i], points[j]) <= eps]
    eset = set(edges)
    tris = [(i,j,k) for (i,j) in edges for k in range(j+1,n)
            if (i,k) in eset and (j,k) in eset]
    return n, edges, tris

def betti_numbers(points, eps):
    """算出 (β0, β1)：连通分量数 + 1维洞数。"""
    V, edges, tris = vrp_complex(points, eps)
    parent = list(range(V))
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]; a = parent[a]
        return a
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[ra] = rb
    for i, j in edges: union(i, j)
    beta0 = len({find(i) for i in range(V)})
    E = len(edges)
    # rank(∂2)：三角形→边的关联矩阵（模2），高斯消元求秩
    M = [[0]*len(tris) for _ in range(E)]
    col_of = {e: c for c, e in enumerate(edges)}
    for c, (i, j, k) in enumerate(tris):
        for e in ((i,j),(i,k),(j,k)):
            M[col_of[e]][c] ^= 1
    pivot_row = 0
    for col in range(len(tris)):
        r = next((rr for rr in range(pivot_row, E) if M[rr][col]), None)
        if r is None: continue
        M[r], M[pivot_row] = M[pivot_row], M[r]
        for rr in range(pivot_row+1, E):
            if M[rr][col]:
                for cc in range(col, len(tris)):
                    M[rr][cc] ^= M[pivot_row][cc]
        pivot_row += 1
    rank_d2 = pivot_row
    beta1 = E - V + beta0 - rank_d2
    return beta0, beta1

def avg_edge_length(points, eps):
    """度量性质：尺度 eps 下的平均边长——一拉就变，不是拓扑的。"""
    ls = [dist(points[i], points[j])
          for i in range(len(points)) for j in range(i+1, len(points))
          if dist(points[i], points[j]) <= eps]
    return sum(ls)/len(ls) if ls else 0.0

# ---- 四组实验 ----
circle   = sample_curve("circle")
ellipse  = sample_curve("ellipse", a=2.0, b=1.0)
disc     = sample_curve("disk")
two_circ = sample_curve("circle") + [ (x+3.0, y) for x, y in sample_curve("circle") ]

print(f"圆        : β0={betti_numbers(circle, 0.25)[0]}, "
      f"β1={betti_numbers(circle, 0.25)[1]}  | 平均边长={avg_edge_length(circle,0.25):.3f}")
print(f"椭圆      : β0={betti_numbers(ellipse, 0.45)[0]}, "
      f"β1={betti_numbers(ellipse, 0.45)[1]}  | 平均边长={avg_edge_length(ellipse,0.45):.3f}")
print(f"实心盘    : β0={betti_numbers(disc, 0.45)[0]}, "
      f"β1={betti_numbers(disc, 0.45)[1]}")
print(f"双圆      : β0={betti_numbers(two_circ, 0.25)[0]}, "
      f"β1={betti_numbers(two_circ, 0.25)[1]}")
```

运行输出（Python 3.11）：

```text
圆        : β0=1, β1=1  | 平均边长=0.157
椭圆      : β0=1, β1=1  | 平均边长=0.225
实心盘    : β0=1, β1=0  | 平均边长=0.104
双圆      : β0=2, β1=2  | 平均边长=0.157
```

读这几行输出：**圆与椭圆，$(\beta_0,\beta_1)$ 完全一样 = (1,1)——它们同胚**，而平均边长从 0.157 涨到 0.225（度量性质变了）。实心盘 $= (1,0)$——洞被填掉了。双圆 $=(2,2)$——两块、两个环。下面逐行拆解。

## 层二：分步逐函数拆解

### 步骤 1：`sample_curve` —— 采样形状

```python
def sample_curve(kind, k=40, **kw):
    pts = []
    for t in range(k):
        ang = 2*math.pi*t/k
        if kind == "circle":
            pts.append((math.cos(ang), math.sin(ang)))
        elif kind == "ellipse":
            a, b = kw.get("a", 2.0), kw.get("b", 1.0)
            pts.append((a*math.cos(ang), b*math.sin(ang)))
        elif kind == "disk":
            pts.append((math.cos(ang), math.sin(ang)))
            for r in (0.4, 0.75):
                pts.append((r*math.cos(ang), r*math.sin(ang)))
    return pts
```

**做什么**：把闭合曲线/曲面采样成有限点云。角度 `ang = 2πt/k` 把圆周均匀切成 k 份。
**输入**：`kind`（形状名）、`k`（圆周切分数）、`**kw`（椭圆的半轴 `a, b`）。
**输出**：坐标元组列表，如圆得到 40 个点在单位圆上。
**可调参数**：
- `k` 是精度旋钮：越大点越密，下面 `eps` 的取值空间越大；过小（如 8）会丢失"环"的形状。
- `a, b`：椭圆的半轴，默认 2.0 与 1.0——**注意椭圆与圆同胚，与你把 a, b 拉成多少无关**，这正是本节要验证的。
- `kind="disk"` 额外生成两圈内点（r=0.4, 0.75），把圆"填实"成盘。
**对应数学**：圆 $(\cos\theta,\sin\theta)$、椭圆 $(a\cos\theta,b\sin\theta)$ 的极角参数化——正是主线里那个显式同胚 $\mathbb{R}^2$ 里的 $(x,y)\mapsto(x/a, y/b)$ 的采样版。

### 步骤 2：`vrp_complex` —— 建 Vietoris–Rips 复形

```python
def vrp_complex(points, eps):
    n = len(points)
    edges = [(i,j) for i in range(n) for j in range(i+1,n)
             if dist(points[i], points[j]) <= eps]
    eset = set(edges)
    tris = [(i,j,k) for (i,j) in edges for k in range(j+1,n)
            if (i,k) in eset and (j,k) in eset]
    return n, edges, tris
```

#### `vrp_complex` —— 在尺度 eps 下决定"谁连谁"

**做什么**：给定阈值 $\varepsilon$，把距离 $\le \varepsilon$ 的点对连成**边 (edge)**；把三条边互相闭合的三元组连成**三角形 (triangle)**。
**操作**：
- 边的规则：**Vietoris–Rips 条件**——两点距离不超过 $\varepsilon$ 就连边。
- 三角形的规则：三元组任意两两之间都有边（即每对距离都 $\le \varepsilon$）就补上三角形。`(i,j)` 遍历边、`k` 从 `j+1` 起，用 `eset` 的 O(1) 查表保证 `(i,k)`、`(j,k)` 都是边。
**输入**：`points` 点云、`eps` 阈值（正数）。
**输出**：`(n, edges, tris)`——顶点数、边表（下标对列表）、三角形表（三元组列表）。
**可调参数**：`eps` 是本脚本的灵魂旋钮。
- 对圆取 `eps=0.25`：仅相邻点相连，40 点连成一圈，**没有**三角形（相邻三点中首尾相距约 0.314 > 0.25）——于是留下一个"环"。
- 若 `eps` 大到 0.314 以上，相邻三点两两相连，三角形出现，环被填掉，$\beta_1$ 变 0——**洞消失了**。试一试就知道这个阈值有多敏感。
**对应数学**：这就是 §9.4.1 持久同调里的"过滤 (filtration)"在单个固定尺度下的切片；$\varepsilon$ 就是那个"尺度参数"。

### 步骤 3：`betti_numbers` —— 高斯消元算同调

```python
    parent = list(range(V))
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]; a = parent[a]
        return a
    def union(a, b):

        if ra != rb: parent[ra] = rb
    for i, j in edges: union(i, j)
    beta0 = len({find(i) for i in range(V)})
    E = len(edges)
    M = [[0]*len(tris) for _ in range(E)]
    col_of = {e: c for c, e in enumerate(edges)}
    for c, (i, j, k) in enumerate(tris):
        for e in ((i,j),(i,k),(j,k)):
            M[col_of[e]][c] ^= 1
    pivot_row = 0
    for col in range(len(tris)):
        r = next((rr for rr in range(pivot_row, E) if M[rr][col]), None)
        if r is None: continue
        M[r], M[pivot_row] = M[pivot_row], M[r]
        for rr in range(pivot_row+1, E):
            if M[rr][col]:
                for cc in range(col, len(tris)):
                    M[rr][cc] ^= M[pivot_row][cc]
        pivot_row += 1
    rank_d2 = pivot_row
    beta1 = E - V + beta0 - rank_d2
    return beta0, beta1
```

#### `find` / `union` —— 并查集，合并连通分量

**做什么**：维护"谁属于哪一块"。`find(a)` 找到 a 的块代表，`union(a,b)` 把两块并起来。
**操作**：路径压缩（`parent[a] = parent[parent[a]]`）让查找接近 O(1)。
**输入**：节点下标。
**输出**：`find` 返回块根，`union` 无返回值（副作用改 `parent`）。
**可调参数**：无——标准模板。对每个点云调用前先对边逐条 `union`，最后 `β0 = len({find(i) for i in range(V)})`——数出几个不同的块根。
**对应数学**：$\beta_0$（连通分量数）的直接计算。

#### `M` 矩阵与高斯消元 —— 算 rank(∂2)

**做什么**：构造"三角形→边"的关联矩阵 $M$（行=边，列=三角形，$M_{e,T}=1$ 当边 $e$ 属于三角形 $T$），模 2 高斯消元求其**秩 (rank)**，记 `rank_d2`。
**操作**：`col_of` 把每条边映射到矩阵列；每个三角形 `(i,j,k)` 把它三条边的对应位置 `^= 1`（模 2 加法）。消元：逐列找主元行，交换到 `pivot_row`，消去下方同列 1 的行。最后 `rank_d2 = pivot_row` 即主元个数。
**输入**：`V, edges, tris`。
**输出**：`(beta0, beta1)`。`beta1 = E - V + beta0 - rank_d2`——这正是公式"$\beta_1 = \dim\ker\partial_1 - \dim\operatorname{im}\partial_2$"：$E - V + \beta_0$ 是一维闭链空间的维数（图的环秩），减去三角形填充掉的 $\partial_2$ 的秩，剩下真正**没被填掉**的环。
**可调参数**：无。模 2 意味着我们只看"奇偶"——每个环要么存在、要么被填，这正是"有没有洞"的离散本性。
**对应数学**：$(\beta_0,\beta_1)$ 是教材 §9.2.1 说的"洞的个数"的精确版，也是 §9.4.1 持久同调的固定尺度特例。`rank_d2` 的角色很关键：没有三角形时（如圆），$rank=0$，环原样保留（$\beta_1=1$）；有三角形填充时（如盘），$rank$ 足够大把环杀掉（$\beta_1=0$）。

### 步骤 4：`avg_edge_length` —— 对照实验：度量不是拓扑

```python
def avg_edge_length(points, eps):
    ls = [dist(points[i], points[j])
          for i in range(len(points)) for j in range(i+1, len(points))
          if dist(points[i], points[j]) <= eps]
    return sum(ls)/len(ls) if ls else 0.0
```

**做什么**：尺度 $\varepsilon$ 内所有边的平均长度——一个纯**度量**量。
**操作**：遍历所有点对，把距离 $\le \varepsilon$ 的边长收集起来求平均。
**输入**：`points`、`eps`。
**输出**：一个浮点数（无边长时返回 0）。
**可调参数**：`eps` 与主实验一致即可。注意它是度量量：拉长椭圆、或者换单位制，这个数立刻变——而 $(\beta_0,\beta_1)$ 纹丝不动。
**对应数学**：主线里"距离、角度、面积是细枝末节，同胚不管它们"的量化证据。输出里圆 0.157 vs 椭圆 0.225，就是"形状被拉扁后度量的反应"，而两者 $\beta$ 恒等。

```python
flat = sample_curve("ellipse", a=10.0, b=0.2)   # 极扁的椭圆
print(f"扁椭圆    : β0={betti_numbers(flat, 1.2)[0]}, β1={betti_numbers(flat, 1.2)[1]}")
```

```text

```

把椭圆压成接近一条缝的薄片，$(\beta_0,\beta_1)$ 依然是 (1,1)——**与圆同胚**。这是"同胚不管胖瘦"最极端的一次演示：无论 a, b 怎么拉，闭曲线就是闭曲线，一个环永远是一个环。（注意：`eps` 必须随 a 放大，否则点数过密导致点之间过近——这就是"采样精度 vs 尺度"的联动，是 §9.4.1 持久同调的伏笔。）

## 边界声明：这套代码能做什么，不能做什么

1. **它验证的是必要不充分条件**。$(\beta_0,\beta_1)$ 相同是两个形状同胚的**必要条件**，不是充分条件。同胚还要求存在具体的双向连续映射——本脚本没有构造、也不保证存在。两个 $\beta$ 完全一致却不同胚的形状在更高维存在（§9.4.1 的 $\beta_2$ 只是又多一道指纹）。
2. **离散化会偷走精度**。点云是连续形状的有限采样；`eps` 取得不好，环会被误填（$\beta_1$ 变 0）或漏连（$\beta_0$ 虚高）。真实数据没有"正确答案的阈值"——这正是持久同调（§9.4.1）用"所有尺度一起看"来治的病。
3. **这只算到 1 维洞**。$\beta_2$（空腔）不在本脚本射程；环面内部的"空腔"需要二维单形与 $\partial_3$。完整的 Betti 序列留给 §9.4.1 的持久同调。
