# 习题：不撕、不粘、不破皮

## 第一组：概念检验

**1. 判断题并说明理由**："一个正方形压扁成一条线段的过程是连续的，所以线段与正方形同胚。"

**2. 单选题**：下面哪一对图形**同胚**？
- (A) 圆环（两个同心圆之间的区域）与实心圆盘
- (B) 环面（甜甜圈）与一个圆圈
- (C) 数字"6"与数字"9"（视为平面上的图形）
- (D) 一个圆圈与两个不相交的圆圈

**3. 简答**：同胚定义里"逆映射也连续"这一条，防止的是什么错误？举一个"连续双射但逆不连续"的例子。

### 解答与思路点拨

**1. 错误。** 压扁是连续的，但**只有正向**连续；从线段还原正方形需要"长出"高度，还原过程不连续。同胚要求正向与逆向都连续（"不破皮"），所以正方形与线段**不同胚**。这道题的陷阱在"单向"与"双向"——很多人只检查"能变过去"，忘了"能变回来且不撕"。回想主线：$(0,1)$ 与 $\mathbb{R}$ 同胚，但 $[0,1]$ 与 $(0,1)$ 不同胚，正是同一个原因。

**2. (C)。** 把"6"旋转 180° 就是"9"（或者把 6 的上环挪下来）——不撕不粘即可互变。而 (A) 圆环中间有个洞、实心盘没有，$\beta_1$ 不同（1 vs 0），不同胚；(B) 环面有一个洞、圆圈有一个洞——**等等**，它们 $\beta_1$ 都是 1，为什么不同胚？因为环面是 2 维曲面（内部是空的、要穿过管孔），圆圈是 1 维曲线，**维数不同**。同胚保持维数，所以不同胚——选 (B) 的读者只看了洞数，漏了维数这道更基本的指纹。(D) 一个环 vs 两个环，$\beta_1$ 是 1 vs 2，不同胚。

**3.** "逆连续"防止的是**把有端点的空间错认成无端点的空间**。经典例子：$f:(0,2\pi)\to$ 单位圆，$t\mapsto e^{it}$。这是连续双射（开区间卷成去掉一点的圆），但逆映射在 $t$ 逼近 $2\pi$ 处必须"撕开"才能回到 0——所以逆不连续，$(0,2\pi)$ 与单位圆**不同胚**（一个有"末端"、一个没有）。"逆连续"是防止假等价的哨兵，也是 §9.2 里"开集的原像是开集"的正逆双向运用。

## 第二组：计算实践

**4. 手算**：一个正五边形，一个正十七边形，一个圆——三者是否两两同胚？说出你的判定依据。

**5. 代码验证**：用本节的 `betti_numbers`，分别算（a）一个圆、（b）一个圆 + 在圆心放一个孤立点（两段互不相连的形状）的 $(\beta_0,\beta_1)$，解释每组数字的含义。

### 解答与思路点拨

**4.** 三者两两**同胚**。正五边形、正十七边形、圆都是**闭合的一维曲线**，各自恰好围出一个洞：$\beta_0=1, \beta_1=1$，维数都是 1——同胚。边数（5、17、无穷）是度量/组合细节，与拓扑无关。这与教材"圆和椭圆同胚"是同一件事，只是更激进：连"多边形"和"圆"都同胚。常见错误：以为边数不同的多边形"长得不同所以不同胚"——同胚不看边数。

**5.** 验证脚本：

```python
import math
def circle(k): return [(math.cos(2*math.pi*t/k), math.sin(2*math.pi*t/k)) for t in range(k)]
# 复用主线的 betti_numbers（此处略，直接导入或复制）
from importlib import util
spec = util.spec_from_file_location("b", "代码.py")   # 若把本节脚本存为 代码.py
```

直接补一个实验更简单：`two = circle(40) + [(5.0, 5.0)]`（圆 + 一个孤立点）。预期输出 `β0=2, β1=1`：两块（圆一块、孤立点一块），一个环（只有圆贡献）。孤立点的加入没有改变环的数量——**它只是多了一个连通分量**。这就是 $\beta_0$ 与 $\beta_1$ 独立性的体现：孤立点只抬 $\beta_0$，只有闭合结构才抬 $\beta_1$。

## 第三组：DL 延伸

**6. 场景判断**：你发现一个分类网络对"同一类别的两个流形"学得很好——A 流形是环形（像一个甜甜圈的表面），B 流形是实心盘。网络把两者都正确分类。后来你把网络改成**纯线性**（去掉所有非线性激活），发现分类彻底失败。请用拓扑学解释：为什么纯线性网络必败？

**7. 思考题**：数据增强里常用的"旋转""翻转""拉伸"各对应克莱因分类（§9.2.1 历史）中的哪一级"变换下的不变性"？一个模型希望"拉伸后的猫还是猫"，这要求模型在什么意义下保持猫的"同胚类"？

### 解答与思路点拨

**6.** 环形（甜甜圈表面）与实心盘在拓扑上**不同胚**：环形有 1 个环（$\beta_1=1$），实心盘没有（$\beta_1=0$）。一个**线性**映射是连续映射，连续映射**保持拓扑**——所以任何线性映射都无法把这两个不同胚的流形"分开放到不同区域"，线性分类必败。非线性激活打破了"纯线性=连续保持拓扑"的束缚（具体说，ReLU 等把空间折叠、拉升，允许拓扑不同的结构被分离）。这就是主线 DL 桥接里的核心论点：**非线性是拓扑的解绑器**。

**7.** 开放题。旋转 → 刚体变换（欧氏几何级不变性）；翻转 → 刚体/等距；拉伸 → 仿射或连续变换（拓扑级容忍）。一个模型若希望"拉伸后的猫还是猫"，它必须学到的不是猫的**度量**（具体像素、尺寸），而是猫的**同胚类**（那个'猫的样子'的骨架/拓扑不变量）。§9.4 的持久同调之所以成为分析工具，正是因为它能显式提取这种"变形下不变"的特征。
