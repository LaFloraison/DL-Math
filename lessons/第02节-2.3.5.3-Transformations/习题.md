# 习题：变换——矩阵作为几何动作

## 第一组：概念检验

**1.1（单选）** 旋转矩阵 $R_\theta = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$ 对向量 $\mathbf{v} = (1, 0)$ 作用的结果是：
- A. $(\cos\theta, \sin\theta)$
- B. $(-\sin\theta, \cos\theta)$
- C. $(1, 1)$
- D. $(\cos\theta, -\sin\theta)$

**1.2（判断并说明）** "平移是线性变换，所以可以用 2×2 矩阵表示。" 这句话对吗？为什么需要用齐次坐标？

**1.3（填空）** 缩放矩阵 $S = \begin{bmatrix} s_x & 0 \\ 0 & s_y \end{bmatrix}$；旋转矩阵是 $R_\theta = \_\_\_$；平移用齐次坐标，把点 $(x,y)$ 写成 $\_\_\_$，用 $\_\_\_$ 维矩阵实现。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算缩放矩阵 $S=\text{diag}(3, 1)$ 与旋转矩阵 $R_{90°}$ 分别作用在 $(2, 1)$ 上的结果，用 NumPy 验证。

**2.2（代码验证）** 验证旋转矩阵保长度：对 5 个随机向量，检查 $\|R_\theta \mathbf{v}\| = \|\mathbf{v}\|$。解释为什么旋转不拉伸。

**2.3（动手理解）** 用齐次坐标实现"先平移 $(2,1)$、再绕原点转 $90°$"与"先转 $90°$、再平移 $(2,1)$"两种复合，比较结果是否相同，并解释顺序为何重要。

## 第三组：DL 延伸

**3.1（场景判断）** 图像数据增强要把一张图"随机旋转 $\theta$、随机缩放 $s$、随机平移 $(t_x,t_y)$"。这三个动作应该怎么组织？最终是几个矩阵的复合？

**3.2（场景分析）** 神经网络的一层 $z = W\mathbf{x}+\mathbf{b}$，为什么说它是"线性变换 + 平移"？从"原点是否被保持"的角度说明 $\mathbf{b}$ 的角色，并类比"齐次坐标里平移需要升维"。

---

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：$R_\theta(1,0) = (\cos\theta\cdot1 - \sin\theta\cdot0,\ \sin\theta\cdot1+\cos\theta\cdot0) = (\cos\theta, \sin\theta)$——$x$ 轴基向量被送到角度 $\theta$ 处，逆时针旋转 $\theta$。
- **点拨**：B（$(-\sin\theta,\cos\theta)$）是 $R_\theta$ 作用在 $y$ 轴基向量 $(0,1)$ 上的结果。**旋转矩阵的列 = 基向量的落点**——记住这一点，旋转矩阵怎么来的就通了。

**1.2 不对。**
- **思路**：线性变换必须保持原点（$A\mathbf{0}=\mathbf{0}$），而平移把原点挪走，所以平移不是线性变换，2×2 矩阵表示不了（矩阵乘法定死原点）。用齐次坐标把点升成 $(x,y,1)$，用 3×3 矩阵把平移"藏"进第 3 列——这样平移就统一进矩阵乘法，可以与其他变换复合。
- **点拨**：**"升一维装下非线性"是核心方法**。这也是"为什么有时候要多维护一个恒为 1 的维度"的原因。

**1.3 答案：$\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$；$(x,y,1)$；$3\times3$。**
- **思路**：旋转矩阵公式、齐次坐标表示、3×3 平移矩阵。
- **点拨**：三个答案连起来就是本节的"三板斧"。

### 第二组

**2.1**
缩放：$S(2,1) = (3\cdot2, 1\cdot1) = (6,1)$。旋转：$R_{90°}(2,1) = (0\cdot2-1\cdot1,\ 1\cdot2+0\cdot1) = (-1, 2)$。
```python
import numpy as np
S = np.diag([3.0, 1.0])
th = np.radians(90)
R = np.array([[np.cos(th), -np.sin(th)],[np.sin(th), np.cos(th)]])
print(S @ np.array([2.,1.]))    # [6. 1.]
print(R @ np.array([2.,1.]))    # [-1.  2.]
```
- **思路**：缩放逐分量；旋转按公式算。
- **点拨**：$R_{90°}$ 把 $(x,y)$ 变 $(-y, x)$（逆时针 90° 的公式，值得记）。

**2.2**
```python
for _ in range(5):
    v = np.random.rand(2)
    print(np.isclose(np.linalg.norm(R@v), np.linalg.norm(v)))   # 全 True
```
- **思路**：$\|R\mathbf{v}\|^2 = (R\mathbf{v})^\top(R\mathbf{v}) = \mathbf{v}^\top R^\top R \mathbf{v} = \mathbf{v}^\top\mathbf{v} = \|\mathbf{v}\|^2$，因为 $R^\top R=I$（正交）。
- **点拨**：**旋转是正交矩阵，正交矩阵保长度**。这也解释了为什么旋转不改变图形大小。缩放则改变长度（除非 $s=1$）。

**2.3**
```python
T = np.array([[1.,0.,2.],[0.,1.,1.],[0.,0.,1.]])   # 平移 (2,1)
R3 = np.array([[0.,-1.,0.],[1.,0.,0.],[0.,0.,1.]]) # 90° 旋转
p = np.array([1.,0.,1.])
print("先平移再旋转:", (R3 @ T @ p)[:2])    # T 后 R3：先平移再旋转
print("先旋转再平移:", (T @ R3 @ p)[:2])    # R3 后 T：先旋转再平移
```
- **思路**：复合矩阵的乘法顺序决定动作顺序（列向量，先作用在最右）。先平移后旋转 ≠ 先旋转后平移——结果不同。
- **点拨**：**矩阵乘法不可交换（§2.3.4.3）在这里有了具体几何**。写增强代码、渲染管线，顺序错了画面就错。**"先做哪个动作"决定了矩阵怎么排。**

### 第三组

**3.1 答案：应该把缩放、旋转、平移写成齐次坐标矩阵，再按"先缩放、再旋转、再平移"（或任务指定顺序）复合成一个 3×3 矩阵 $M = T \cdot R \cdot S$，一次作用到所有顶点。**
- **思路**：缩放 $S$、旋转 $R$、平移 $T$ 各写成齐次 3×3，复合 $M=T\cdot R\cdot S$。所有像素/顶点乘以同一个 $M$——一次矩阵乘法完成全部变换。常用顺序"缩放→旋转→平移"（避免先平移把中心挪走导致缩放/旋转绕错点）。
- **点拨**：**复合一个矩阵、作用到所有点**，是图形学与数据增强的标准工程化。3.2 的"升维"在这里兑现为"3×3 统一矩阵"。

**3.2 思路**
- $z = W\mathbf{x}+\mathbf{b}$：$W\mathbf{x}$ 是线性变换（把原点钉在原点，§2.5 会讲），加 $\mathbf{b}$ 是平移（把原点挪到 $\mathbf{b}$）。所以一层 = 线性变换 + 仿射平移。
- 从"原点"角度：无偏置时 $W\mathbf{0}=\mathbf{0}$，原点被保持（严格线性）；有偏置时 $W\mathbf{0}+\mathbf{b}=\mathbf{b}\neq\mathbf{0}$，原点被挪走——**所以含偏置的层是"仿射变换"，不是严格线性变换**。
- 类比齐次坐标：纯平移不是线性变换，齐次坐标靠升维把它装进矩阵；神经网络层靠"显式加 $\mathbf{b}$"实现平移。两者都在"线性之外加一个偏移"。
- **点拨**：**"权重给方向，偏置给位置"**（§2.2.3.2）的几何版。线性层 = 缩放/旋转/剪切 + 平移的组合——这正是 §2.5 的主线。
