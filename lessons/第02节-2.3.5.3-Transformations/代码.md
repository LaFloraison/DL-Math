# 代码：缩放、旋转、平移——把矩阵当作"动作"来用

主线里我们认识了三种变换矩阵。这一节用 NumPy 把它们实际作用到点集上，并演示**齐次坐标平移**与"平移-旋转-平移"的复合。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：矩阵运算

# ---- ① 缩放矩阵 ----
S = np.array([[2.0, 0.0],                # x 方向 2 倍
              [0.0, 0.5]])               # y 方向 0.5 倍
p = np.array([3.0, 4.0])
print("缩放 2x,0.5y: S@p =", S @ p)      # [6. 2.]

# ---- ② 旋转矩阵（90°）----
theta = np.radians(90)
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print("旋转90°: R@(1,0) =", R @ np.array([1.0, 0.0]))   # 约 [0, 1]
print("R@R.T =", R @ R.T, "| R 保长度:", np.allclose(np.linalg.norm(R@np.array([1.,2.])), np.linalg.norm(np.array([1.,2.]))))

# ---- ③ 平移：用齐次坐标（3x3 矩阵）----
T = np.array([[1.0, 0.0, 3.0],           # tx = 3
              [0.0, 1.0, 2.0],           # ty = 2
              [0.0, 0.0, 1.0]])
ph = np.array([1.0, 1.0, 1.0])           # 点 (1,1) 的齐次坐标
print("平移 (3,2): T@ph =", T @ ph)       # [4. 3. 1.] -> (4,3)

# ---- ④ 复合：绕点 (1,1) 旋转 90°（平移-旋转-平移）----
p_center = np.array([1.0, 1.0])
T1 = np.array([[1.,0.,-p_center[0]],[0.,1.,-p_center[1]],[0.,0.,1.]])  # 平移到原点
T2 = np.array([[1.,0.,p_center[0]],[0.,1.,p_center[1]],[0.,0.,1.]])     # 平移回来
R3 = np.array([[0.,-1.,0.],[1.,0.,0.],[0.,0.,1.]])                      # 90° 旋转(齐次)
M  = T2 @ R3 @ T1                                                       # 复合矩阵
pt = np.array([2.0, 1.0, 1.0])
print("绕(1,1)旋转90°: (2,1) ->", (M @ pt)[:2])   # (2,1) 绕(1,1)转90° -> (1,2)
```

运行输出（Python 3.11 + NumPy）：

```text

旋转90°: R@(1,0) = [6.123233e-17 1.000000e+00]   # 约 (0,1)
R@R.T = [[1. 0.] [0. 1.]] | R 保长度: True
平移 (3,2): T@ph = [4. 3. 1.] -> (4,3)
绕(1,1)旋转90°: (2,1) -> [1. 2.]
```

## 层二：分步逐函数拆解

### 步骤 1：缩放矩阵

```python
S = np.array([[2.0, 0.0], [0.0, 0.5]])
S @ p   # [6. 2.]
```

**做什么**：$S=\text{diag}(2, 0.5)$，把 $x$ 拉伸 2 倍、$y$ 压缩一半。$(3,4) \mapsto (6,2)$。
**操作**：对角矩阵数乘各分量：$x'=s_xx$、$y'=s_yy$。
**可调参数**：$s_x=s_y$ 是均匀缩放（保持形状）；$s_x\neq s_y$ 是各向异性（变形）。$s<0$ 会翻转。
**对应数学**：主线 $S=\begin{bmatrix}s_x&0\\0&s_y\end{bmatrix}$。

### 步骤 2：旋转矩阵

```python
theta = np.radians(90)
R = np.array([[np.cos(theta), -np.sin(theta)], [np.sin(theta), np.cos(theta)]])
```

#### `np.radians(90)` —— 角度转弧度

**操作**：$90° \to \pi/2$ 弧度。NumPy 三角函数默认用弧度。
**可调参数**：`np.degrees` 反向转换。工程里角度常用度数，三角函数用弧度——别忘转换。

#### `R @ np.array([1.,0.])` —— 旋转基向量

**操作**：$R(1,0) = (\cos90°, \sin90°) = (0,1)$——$x$ 轴单位向量被送到 $y$ 轴，逆时针转 90°。
**可调参数**：$\theta$ 换任意角；$-\theta$ 顺时针。**旋转矩阵的列 = 基向量的落点**（§2.5 的核心思想）。
**对应数学**：主线 $R_\theta=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$。`R @ R.T = I` 验证它是正交矩阵；`norm` 验证保长度——旋转不拉伸。

### 步骤 3：齐次坐标平移

```python
T = np.array([[1., 0., 3.], [0., 1., 2.], [0., 0., 1.]])
ph = np.array([1., 1., 1.])
T @ ph   # [4. 3. 1.]
```

**做什么**：点 $(1,1)$ 写成 $(1,1,1)$，用 $3\times3$ 矩阵平移 $(3,2)$ → $(4,3,1)$，即 $(4,3)$。
**操作**：$x'=x+t_x$、$y'=y+t_y$、最后一维保持 1。**多出的第 3 维恒为 1，是齐次坐标的记号。**
**可调参数**：$t_x,t_y$ 任意；缩放/旋转也能放进齐次矩阵（左上 $2\times2$ 块）。**所有变换统一成 $3\times3$ 矩阵，才能复合。**
**对应数学**：主线齐次坐标平移矩阵。**"升一维，装下平移"是本节的方法论。**

### 步骤 4：复合变换——绕任意点旋转

```python
T1 = 平移到原点; R3 = 90°旋转; T2 = 平移回来
M = T2 @ R3 @ T1
(M @ pt)[:2]   # (2,1) 绕 (1,1) 转90° → (1,2)
```

**做什么**：绕 $(1,1)$ 旋转 90°：先把中心平移到原点（$T_1$），旋转（$R_3$），再平移回来（$T_2$）。复合矩阵 $M = T_2R_3T_1$。
**操作**：`(2,1)` 绕 `(1,1)` 逆时针 90°：相对中心是 $(1,0)$，旋转后 $(0,1)$，加回中心得 $(1,2)$。输出 `[1., 2.]` ✓。
**可调参数**：改变 $T_1,T_2$ 的中心、$R_3$ 的角度，得到任意"绕任意点旋转"。**注意复合顺序**：$M=T_2R_3T_1$，先作用的矩阵在最右（对列向量）。**顺序错了，变换就错**——这正是 §2.3.4.3 不可交换性的实践。
**对应数学**：主线"平移-变换-平移"套路。**这是计算机图形学与数据增强的核心操作。**

## 边界声明：这套代码能做什么，不能做什么

1. **二维变换矩阵对二维点 `(x,y)` 用 2×2 是线性变换**；要平移必须用齐次坐标（3×3）。**不要用 2×2 矩阵"硬做"平移**——那是错误的（它会同时缩放/旋转）。
2. **复合顺序不能换**：$M=T_2R_3T_1$（先右后左）。`R3 @ T1` 与 `T1 @ R3` 是不同动作。深度学习里"先归一化再过层"与"先过层再归一化"同理——顺序即语义。
3. **旋转保长度、保角度，但缩放不保**。缩放 $s_x\neq s_y$ 会改变角度（把圆压成椭圆）——别把"缩放"当"旋转"用。
4. **齐次坐标最后一维恒为 1**（对"点"而言）。如果混入了"向量"（方向，最后一维 0），平移不会作用在向量上——这是图形学的"点 vs 方向"之分，深度学习里少数场景（如光流）会用到。本节默认都是"点"。
