# 代码：贝叶斯统计——把"先验 × 似然"更新成"后验"

主线里我们把贝叶斯定理写成 $P(A|B)=\frac{P(B|A)P(A)}{P(B)}$，并用教材的抛硬币例展示了共轭更新。本课用代码做三件事：

1. **贝叶斯定理四件套**：把医疗检测的四个数字（发病率、灵敏度、假阳性率）代进公式，算出"测出阳性后真正得病的概率"。
2. **共轭更新**：复现教材 Figure 4.8——先验 $\text{Beta}(2,2)$，50 次抛掷 35 正 15 反，后验 $\text{Beta}(37,17)$，均值 ≈ 0.69。
3. **顺序更新**：让信念随数据"一步一步"移动——从 0.5 走向真实概率 0.7。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 医疗检测：贝叶斯定理四件套 ----
def bayes_rule(p_b_given_a, p_a, p_b_given_not_a):
    """后验 P(A|B)，由先验 P(A)、似然 P(B|A)、假阳性率 P(B|¬A) 直接算出。"""
    p_not_a = 1 - p_a
    p_b = p_b_given_a * p_a + p_b_given_not_a * p_not_a   # 证据 P(B) = 全概率公式
    return p_b_given_a * p_a / p_b                          # P(A|B) = P(B|A)P(A)/P(B)

post = bayes_rule(0.99, 0.001, 0.05)   # 灵敏度 99%，发病率 0.1%，假阳性率 5%
print(f"P(得病|阳性) = {post:.4f}   # ≈ 1.9%，不是 99%")

# ---- ② 抛硬币：Beta 先验 × 二项似然 = Beta 后验（共轭） ----
def beta_update(a_prior, b_prior, heads, tails):
    """共轭更新：后验参数 = 先验参数 + 观测计数。"""
    return a_prior + heads, b_prior + tails

a0, b0 = 2, 2                                     # 先验 Beta(2,2)：对称、均值 0.5、相信公平
a1, b1 = beta_update(a0, b0, heads=35, tails=15)  # 教材：50 次抛掷，35 正 15 反
print(f"后验参数 α={a1}, β={b1}   # 均值 = {a1/(a1+b1):.4f}，众数 = {(a1-1)/(a1+b1-2):.4f}（教材 ≈0.69）")

# ---- ③ 顺序更新：信念随数据一步步移动 ----
np.random.seed(0)
flips = np.random.binomial(1, 0.7, 50)    # 真实概率 0.7 的 50 次抛掷
a, b = a0, b0
for i, head in enumerate(flips, 1):       # 每次抛掷后立即更新一次
    a, b = beta_update(a, b, int(head), 1 - int(head))
    if i % 10 == 0:
        print(f"前 {i:>2} 次后: 后验均值 = {a/(a+b):.3f}   # 从 0.5 走向 0.7")
```

运行输出（Python 3.11 + NumPy）：

```text
P(得病|阳性) = 0.0194   # ≈ 1.9%，不是 99%
后验参数 α=37, β=17   # 均值 = 0.6852，众数 = 0.6923（教材 ≈0.69）
前 10 次后: 后验均值 = 0.643   # 从 0.5 走向 0.7
前 20 次后: 后验均值 = 0.583
前 30 次后: 后验均值 = 0.588
前 40 次后: 后验均值 = 0.636
前 50 次后: 后验均值 = 0.704
```

三段分别对应：① 灵敏度 99% 的检测，真正得病概率只有 1.9%——"测出阳性"和"得了病"隔着 50 倍的差距；② 共轭更新退化成两次加法，后验均值 0.685 ≈ 0.69，与教材 Figure 4.8 一致；③ 后验均值从 0.5 出发，**一路摇摆**（0.64→0.58→0.59→0.64→0.70）——信念不是直线逼近真实值，而是在噪声数据里蹒跚前行，趋势却没错。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：`bayes_rule` —— 贝叶斯定理四件套

```python
def bayes_rule(p_b_given_a, p_a, p_b_given_not_a):
    p_not_a = 1 - p_a
    p_b = p_b_given_a * p_a + p_b_given_not_a * p_not_a
    return p_b_given_a * p_a / p_b
```

#### bayes_rule —— 把四个数字合成为后验

**做什么**：给定先验 $P(A)$、似然 $P(B|A)$、假阳性率 $P(B|\neg A)$，算出后验 $P(A|B)$。
**操作**：先求证据 $P(B)=P(B|A)P(A)+P(B|\neg A)P(\neg A)$——**全概率公式**，把"得病"和"不得病"两种原因都算进去；再代进 $P(A|B)=P(B|A)P(A)/P(B)$。
**输入**：
- `p_b_given_a`：似然，标量——"如果 A 真，测出 B 的概率"（这里是灵敏度 0.99）
- `p_a`：先验，标量——"看到证据前 A 的概率"（这里是发病率 0.001）
- `p_b_given_not_a`：标量——"如果 A 假，仍测出 B 的概率"（假阳性率 0.05）
**输出**：后验概率，标量。`bayes_rule(0.99, 0.001, 0.05)` → `0.0194`。
**可调参数**：三个参数各改一个数字都合法，但含义不同——`p_a` 是证据之外的信息（来自流行病学），`p_b_given_a` 与 `p_b_given_not_a` 是检测自身的两个"方向"的出错率。**还可以传第四个参数吗？** 可以——若想显式处理"漏诊"（得病却没测出）那半边，把证据展开成三项甚至更多项的列表，`bayes_rule` 就扩展成"多原因求和"的通用版。
**对应数学**：主线"手算验证"里那一步——$P(\text{得病}|\text{阳性})\approx0.0194$。

---

### 步骤 2：`beta_update` —— 共轭更新退化成加法

```python
def beta_update(a_prior, b_prior, heads, tails):
    return a_prior + heads, b_prior + tails
```

#### beta_update —— 后验参数 = 先验参数 + 数据计数

**做什么**：把先验 Beta 的参数与观测计数相加，返回后验 Beta 的参数。
**操作**：$\text{Beta}(a_0,b_0)+\text{(heads 次正面, tails 次反面)}\to\text{Beta}(a_0+\text{heads}, b_0+\text{tails})$。
**输入**：`a_prior`、`b_prior`（先验两个参数，均 > 0），`heads`、`tails`（非负整数计数）。
**输出**：`(a1, b1)` 两个数——后验参数。`beta_update(2, 2, 35, 15)` → `(37, 17)`。
**可调参数**：`heads`/`tails` 换成任何计数，后验跟着变；`a_prior`/`b_prior` 换大一点（如 `(10,10)`）就是更强的先验——后验会更贴近 0.5（见习题第 5 题）。
**对应数学**：Beta 是二项似然的**共轭先验**——先验和似然同族，后验还是同族，所以"算积分"降级成"做加法"。这正是教材 Figure 4.8 那张图背后的闭式解。

### 步骤 3：顺序更新——信念随数据一步步移动

```python
np.random.seed(0)
flips = np.random.binomial(1, 0.7, 50)
a, b = a0, b0
for i, head in enumerate(flips, 1):
    a, b = beta_update(a, b, int(head), 1 - int(head))
    if i % 10 == 0:
        print(f"前 {i:>2} 次后: 后验均值 = {a/(a+b):.3f}")
```

#### `np.random.binomial` —— 按真实概率抛 50 次

**做什么**：生成 50 个 0/1 的抛掷结果，正面（1）概率 0.7。
**输入**：`n=1`（每次一抛）、`p=0.7`（真实概率）、`size=50`。**可调参数**：把 `p` 改成 0.5 就是公平硬币，改成 0.3 就是偏向反面。
**输出**：形状 `(50,)` 的整数数组，第 $i$ 个元素是第 $i$ 次抛掷的结果（1=正，0=反）。

#### 循环更新 —— 每一步都重算一次后验

**做什么**：每次抛掷后立刻调用一次 `beta_update`，把当前后验当成下一步的先验——**这是贝叶斯"顺序学习"的现场：今天的后验，就是明天的先验。**
**操作**：`int(head)` 把布尔/整数转成 0 或 1；正面则 `a+1`，反面则 `b+1`。
**输出**：每 10 次打印一次后验均值。从 0.643 摇摆到 0.704——**注意它不单调**：前 20 次曾跌回 0.583。这不是 bug，是噪声数据的正常波动；50 次后均值贴住 0.7，方向始终没偏。
**可调参数**：`np.random.seed(0)` 换成别的整数，得到另一组抛掷序列、另一条摇摆路径；`p` 和 `size` 决定数据本身的真实性与总量。
**对应数学**：$P(\theta|\text{data}_{1:n})\propto P(\theta)\prod_i P(\text{data}_i|\theta)$——顺序更新等价于一次性吃进全部数据，**更新顺序不影响终局**（贝叶斯更新满足交换律）。

## 改个数字试试：两个反直觉的实验

### 实验一：发病率翻十倍、翻一百倍，后验怎么变

```python
for prev in (0.001, 0.01, 0.10):
    print(f"发病率={prev*100:.1f}%: P(得病|阳性)={bayes_rule(0.99, prev, 0.05):.4f}")
```

输出（大致）：

```text
发病率= 0.1%: P(得病|阳性)=0.0194
发病率= 1.0%: P(得病|阳性)=0.1667
发病率=10.0%: P(得病|阳性)=0.6875
```

发病率从 0.1% 涨到 10%（一百倍），真正的患病概率从 1.9% 飙到 69%——**先验（发病率）对后验的决定性**肉眼可见。同样是"阳性"，在罕见病里几乎无意义，在常见病里高度可疑。

### 实验二：灵敏度从 99% 降到 80%，后验几乎不动

```python
for se in (0.99, 0.90, 0.80):
    print(f"灵敏度={se*100:.0f}%: P(得病|阳性)={bayes_rule(se, 0.001, 0.05):.4f}")
```

输出（大致）：

```text
灵敏度=99%: P(得病|阳性)=0.0194
灵敏度=90%: P(得病|阳性)=0.0177
灵敏度=80%: P(得病|阳性)=0.0158
```

灵敏度从 99% 掉到 80%，后验只从 1.9% 移到 1.6%——**在罕见病里，把"逮住真病人"做得再好，也救不回被"假阳性洪水"淹没的后验。** 真正要紧的是假阳性率：把它从 5% 降到 0.5%，后验才会显著抬升。**这不只是数字游戏——它告诉我们，一个工具的关键短板，往往藏在它最不起眼的那个参数里。**

## 边界声明：这套代码能做什么，不能做什么

1. **共轭只在特殊组合成立。** 我们用了 Beta × 二项这一对共轭，后验闭式可算（两次加法）。真实模型的先验 × 似然几乎从不共轭——**后验不可闭式，必须用 MCMC（§4.3.9）或变分推断近似**。本脚本是"心脏"，不是"全身"。
2. **`np.random.binomial` 只是玩具数据。** 它假装"真实概率已知为 0.7"，好让读者看清后验走向。现实中你**永远不知道**真实概率——你只有观测和信念，而这恰恰是贝叶斯要处理的处境。别把"模拟的真实值"当成"后验的目标"。
3. **顺序更新不是越跑越准。** 第 20 次时的均值（0.583）比第 10 次（0.643）更差，因为噪声数据会让信念暂时走偏。**贝叶斯保证的是"数据的逻辑正确性"，不是"每一步都比上一步更接近真相"。**
4. **后验均值 ≠ 唯一的答案。** 我们只打印了均值与众数。完整的后验是一条分布曲线，均值、众数、可信区间各自回答不同问题；在深度学习的 BNN 里，这条分布被 MCMC / VI 采样，才能给出"不确定性"。
