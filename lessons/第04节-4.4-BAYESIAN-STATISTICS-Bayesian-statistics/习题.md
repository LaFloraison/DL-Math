# 习题：贝叶斯统计

## 第一组：概念检验

**1. 写出贝叶斯定理，并解释先验、似然、证据、后验各是什么。为什么证据 $P(B)$ 被称为"归一化常数"？**

**解答**：$P(A|B)=\frac{P(B|A)\,P(A)}{P(B)}$。$P(A)$ 是**先验 (prior)**——看到证据前对 $A$ 的信念；$P(B|A)$ 是**似然 (likelihood)**——若 $A$ 为真，观测到 $B$ 的概率；$P(B)$ 是**证据 (evidence)**——在所有可能的 $A$ 上把 $P(B|A)P(A)$ 求和（离散）或积分（连续）的结果；$P(A|B)$ 是**后验 (posterior)**——看到证据后的新信念。$P(B)$ 归一化，是因为对 $A$ 的所有可能取值求和/积分时 $\sum_A P(B|A)P(A)=P(B)$，正好让 $\sum_A P(A|B)=\frac{1}{P(B)}\sum_A P(B|A)P(A)=1$——**它保证后验加起来等于 1，是合法的概率分布。**

**2. 判断题并说明理由："某检测灵敏度 99%，所以我测出阳性后，得病的概率就是 99%。"**

**解答**：错误，这正是"逆概率谬误 (base rate fallacy)"——把 $P(\text{阳性}|\text{得病})$（若得病则测出阳性的概率）当成了 $P(\text{得病}|\text{阳性})$（若测出阳性则得病的概率）。两者隔着先验：若发病率 0.1%、假阳性率 5%，则 $P(\text{得病}|\text{阳性})\approx1.9\%$。**灵敏度只描述'检测逮住真病人的能力'，不描述'阳性报告里有多少是真病人'——后者还必须算上假阳性洪水。**
**思路点拨**：若有人答"对，99% 很准"，他忽略了三件事之一：发病率太低（先验小）、假阳性率不为零、以及条件概率方向不能随便翻。**用 1000 人排队的画面（999 个没病的里会冒 50 个假阳性）可以立刻破除这个错误。**

**3. 贝叶斯统计的三大优势是什么？频率学派与贝叶斯学派对"参数"的理解有何不同？**

**解答**：三大优势——**灵活性**（同时整合新数据与先验知识，数据不足时先验垫底、充足时数据主导）、**可解释性**（结果直接是概率，天然是人的语言）、**完整分布**（给出参数的完整概率描述而非点估计）。对参数的理解：频率学派认为参数是"固定但未知"的数，只能给点估计 + 置信区间（重复试验的频率含义），不引入先验；贝叶斯学派认为参数是不确定量，用后验分布描述，先验是核心组成部分。**频率学派问"重做无数次试验会怎样"，贝叶斯学派问"基于我的信念和数据，我该信什么"。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 发病率 0.1%，灵敏度 99%，假阳性率 5%。（a）手算 $P(\text{阳性})$ 与 $P(\text{得病}|\text{阳性})$。（b）若灵敏度降到 90%，后验变成多少？这说明了什么？

**解答**：
（a）$P(\text{阳性})=0.99\times0.001+0.05\times0.999=0.00099+0.04995=0.05094$；$P(\text{得病}|\text{阳性})=\frac{0.00099}{0.05094}\approx0.0194\approx1.9\%$。
（b）灵敏度 90%：$P(\text{阳性})=0.90\times0.001+0.05\times0.999=0.05085$；后验 $\frac{0.0009}{0.05085}\approx0.0177\approx1.8\%$。灵敏度从 99% 掉到 90%，后验只从 1.9% 移到 1.8%——**罕见病场景里，假阳性洪水把后验压得很低，改善灵敏度也救不回来；真正要紧的是降低假阳性率。**

代码验证：

```python
def bayes_rule(se, prev, fp):
    """后验 P(得病|阳性)，se=灵敏度, prev=发病率, fp=假阳性率。"""
    return se*prev / (se*prev + fp*(1-prev))

print(f"P(阳性)         = {0.99*0.001 + 0.05*0.999:.4f}")
for se in (0.99, 0.90):
    print(f"灵敏度{se*100:.0f}%: P(得病|阳性) = {bayes_rule(se, 0.001, 0.05):.4f}")
```

输出：

```text
P(阳性)         = 0.0509
灵敏度99%: P(得病|阳性) = 0.0194
灵敏度90%: P(得病|阳性) = 0.0177
```

**思路点拨**：若有人答"灵敏度降到 90%，后验也会从 1.9% 大幅下跌到接近 0"，他高估了灵敏度在罕见病里的权重——后验的分子是 $0.90\times0.001$，本来就小；分母里 $0.05\times0.999$ 的假阳性几乎不受灵敏度影响。**当先验极小、假阳性率不低时，后验被'假阳性基数'主导，灵敏度只是边缘角色。**

**5. 手算 + 代码验证（共轭更新）。** 先验 $\text{Beta}(2,2)$，50 次抛掷 35 正 15 反。（a）后验参数？（b）后验均值与众数？（c）若把先验换成 $\text{Beta}(10,10)$，后验又变成什么？两种先验下均值有何差异、为什么？

**解答**：
（a）共轭更新：后验 $\text{Beta}(2+35,\ 2+15)=\text{Beta}(37,17)$。
（b）均值 $\frac{37}{54}\approx0.685$，众数 $\frac{37-1}{37+17-2}=\frac{36}{52}\approx0.692$。
（c）$\text{Beta}(10,10)$：后验 $\text{Beta}(45,25)$，均值 $\frac{45}{70}\approx0.643$。**更强的先验（10+10 的假想数据）把后验均值拉回 0.5 方向**——先验的"分量"越大，数据越难独自决定结论。

代码验证：

```python
a, b = 2+35, 2+15
print(f"Beta(2,2)  : 后验 Beta({a},{b}), 均值={a/(a+b):.4f}, 众数={(a-1)/(a+b-2):.4f}")
a, b = 10+35, 10+15
print(f"Beta(10,10): 后验 Beta({a},{b}), 均值={a/(a+b):.4f}")
```

输出：

```text
Beta(2,2)  : 后验 Beta(37,17), 均值=0.6852, 众数=0.6923
Beta(10,10): 后验 Beta(45,25), 均值=0.6429
```

**思路点拨**：若有人答"两种先验结果一样，因为数据都是 35 正 15 反"，他漏掉了共轭更新的本质——**后验 = 先验参数 + 数据计数，先验不是摆设，它是一笔'假想数据'，与真实数据等权相加。** 先验假想数据越多（10+10 vs 2+2），它在后验里的投票权越大。

**6. 顺序更新实验。** 用 `np.random.seed(0)` 模拟真实概率 0.7 的 50 次抛掷，每 10 次打印一次后验均值（先验 $\text{Beta}(2,2)$），并观察：后验均值是单调逼近 0.7 吗？这个"摇摆"说明什么？

**解答**：见《代码.md》层一步骤 3 的输出——均值路径为 0.643 → 0.583 → 0.588 → 0.636 → 0.704，**并不单调**：前 30 次曾跌到 0.58 附近，直到 50 次才贴住 0.7。这既不是 bug 也不是"贝叶斯失灵"，而是**数据本身带噪声**：这段模拟序列恰好前 30 次正面偏少。贝叶斯保证的是"更新逻辑正确"，不保证"每一步都比上一步更接近真相"。**对短序列，后验会被局部的运气牵着走；数据越多，趋势越稳。**

## 第三组：DL 延伸

**7. 正则化场景。** 贝叶斯神经网络 (BNN) 的权重后验 $P(w|D)\propto P(D|w)P(w)$。（a）推导：若先验取高斯 $w\sim\mathcal{N}(0,\sigma^2)$，MAP 目标函数 $-\log P(w|D)$ 长什么样？（b）这个式子和你训练神经网络时加的东西有什么关系？（c）如果换成拉普拉斯先验（$\propto e^{-|w|/b}$），会诱导出什么结构？

**解答**：
（a）$\arg\max_w\log P(w|D)=\arg\max_w\big[\log P(D|w)+\log P(w)\big]$。高斯先验 $\log P(w)=-\frac{w^2}{2\sigma^2}+C$，于是最小化负对后验等价于**最小化 $-\log P(D|w)+\frac{1}{2\sigma^2}\|w\|^2$**——第一项是负对数似然（训练损失），第二项正是 L2 正则项，$\lambda=\frac{1}{2\sigma^2}$。
（b）这就是你每天训练的损失 + `weight_decay`。**你在 PyTorch 里设 `weight_decay=λ`，就是在声明"我事先相信权重服从一个方差 $1/2\lambda$ 的高斯先验"。**
（c）拉普拉斯先验 $\log P(w)\propto-|w|$，MAP 等价于损失 + $\lambda\|w\|_1$——**L1 正则化，诱导稀疏**（许多权重精确为零，对应特征选择）。**先验的形状 = 你对权重的偏好结构。**
**思路点拨**：若有人答"正则化只是工程技巧，和概率无关"，让他写下 $-\log P(w|D)$ 展开式——**正则化就是先验的对数，两者是同一件事的两种语言**。若有人答"MAP 就是完整的贝叶斯"，提醒他 MAP 只取后验的众数（一个点），放弃了后验的宽度——那是 BNN 与确定性网络的分水岭。

**8. 不确定性场景。** 你部署一个疾病诊断模型到临床。方案 A：输出单个概率"得病可能性 0.73"（点估计）；方案 B：输出后验分布"得病概率以 90% 落在 [0.62, 0.84]"（完整分布）。（a）为什么方案 B 在临床上更安全？（b）MC-dropout 是如何从一次普通的 dropout 网络里得到"不确定性"的？（c）这条思路对应教材说的贝叶斯哪一条优势？

**解答**：
（a）方案 B 让你看到**模型自己有多确定**：区间窄且高说明证据充分，区间宽说明数据还不足以判断。一个把 [0.62, 0.84] 报成"0.73"的模型，在区间其实极宽时（比如 [0.1, 0.95]）会给出一个**虚假的精确**——临床上"我不知道"比"错误地很确定"安全得多。
（b）训练时 dropout 遮罩神经元，等价于对权重施加乘性噪声。**预测时也开着 dropout，做多次前向传播，每次得到略不同的输出**——这些输出的方差就是对不确定性的估计（MC-dropout，Gal & Ghahramani 2016）。它在贝叶斯眼里等价于从权重后验做蒙特卡洛采样。
（c）对应"**完整分布 (full distribution)**"——贝叶斯不只给点估计，还给出参数的完整概率描述。**"模型学会了说'我不知道'"，是贝叶斯统计送给深度学习最珍贵的东西。**
