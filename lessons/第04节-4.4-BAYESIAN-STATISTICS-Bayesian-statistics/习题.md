# 习题：贝叶斯统计

## 第一组：概念检验

**1. 写出贝叶斯定理，并解释四个部分各是什么。**

**解答**：$P(A|B)=\frac{P(B|A)P(A)}{P(B)}$。$P(A)$ 先验——看到证据前对 $A$ 的信念；$P(B|A)$ 似然——给定 $A$，数据有多可能；$P(B)$ 证据——归一化常数（对所有参数值积分）；$P(A|B)$ 后验——看到证据后的信念。**先验是起点，似然是燃料，后验是到达点，证据让一切合法化。**

**2. 教材的硬币例：先验 $\text{Beta}(2,2)$，50 次抛掷 35 正 15 反，后验是什么？均值从多少移到多少？**

**解答**：后验 $\text{Beta}(2+35,\ 2+15)=\text{Beta}(37,17)$。均值从 $\frac{2}{4}=0.5$ 移到 $\frac{37}{54}\approx0.69$——**先验的"公平假设"被数据推向 0.7**。因为 Beta 是二项似然的共轭先验，后验参数 = 先验参数 + 数据计数。

**3. 判断题并说明理由："贝叶斯统计比频率统计更准确，因为它用了先验。"**

**解答**：错误。两者是不同的问题与承诺：频率学派给"点估计 + 频率置信区间"（参数固定未知），贝叶斯给"后验分布 + 信念更新"（参数有分布）。先验是双刃剑——**先验对（或数据稀缺）时是知识，先验错时是偏差**（教材明确警告）。贝叶斯的"更好"在"不确定性量化、整合先验知识"，不在"数字更准"。

## 第二组：计算实践

**4. 手算 + 代码验证。** （a）先验 $\text{Beta}(2,2)$ 的均值？（b）50 次 35 正 15 反后，手写后验参数与均值。（c）代码复现，并给出后验 95% 可信区间。

**解答**：
（a）$\frac{2}{2+2}=0.5$——对称、假设公平。
（b）后验 $\text{Beta}(37,17)$，均值 $\frac{37}{54}\approx0.685$。
（c）见《代码.md》层一：先验均值 0.5 → 后验均值 0.685，95% 可信区间 $[0.555,0.802]$。

代码验证：

```python
import numpy as np
from math import gamma as g
def beta_pdf(x, a, b):
    B = g(a)*g(b)/g(a+b)
    return x**(a-1)*(1-x)**(b-1)/B
a, b = 2+35, 2+15
print("后验均值 =", round(a/(a+b), 3))
xs = np.linspace(1e-6, 1-1e-6, 100000)
cdf = np.cumsum(beta_pdf(xs, a, b)) * (xs[1]-xs[0])
print("95% 区间 =", [round(xs[np.argmin(abs(cdf-q))], 3) for q in (0.025, 0.975)])
```

输出：

```text
后验均值 = 0.685
95% 区间 = [0.555, 0.802]
```

**思路点拨**：若有人答"后验均值应该是 0.7（因为数据是 70%）"，他忽略了先验——后验是"先验×数据"的合成，数据 50 次的信息量很大但还没大到完全吞掉先验，所以是 0.685 而非 0.7。**共轭更新"参数相加"的本质，是"先验的知识（2+2）与数据的证据（35+15）各按信息量加进来"。**

**5. 数据量扫描实验。** 固定先验 $\text{Beta}(2,2)$，让数据量从 10 涨到 5000（真实 70% 正面），观察后验均值与标准差，验证"数据越多，后验越被数据主导"。

**解答**：见《代码.md》"改个数字试试"。数据 10 次时后验均值 0.571（先验还拽着）、5000 次时 0.699（贴数据 0.7）；标准差从 0.134 缩到 0.006（更确定）。**后验的"折中"由数据量决定——数据越多，先验越退居幕后**（§4.2.6.2 的结论重演）。

## 第三组：DL 延伸

**6. 正则化场景。** 你的神经网络训练在小数据集上过拟合。（a）用贝叶斯语言描述 weight decay 的作用。（b）如果先验设得太强（weight decay 太大），会发生什么？（c）如何在贝叶斯框架下判断"先验强度"该多大？

**解答**：
（a）weight decay 的 $\lambda\|w\|^2$ 等价于高斯先验 $w\sim\mathcal{N}(0,\frac{1}{2\lambda})$（§4.2.5）——**先验说"权重应该小"，把后验估计拉向 0，防止模型在小数据上把噪声背下来**。这就是"先验作为正则化"（教材 §4.4.1 的核心）。
（b）先验太强（$\lambda$ 太大）→ 后验被先验主导 → 权重被压得太小，模型失去表达能力 → **欠拟合**。**先验是双刃剑：太弱防不了过拟合，太强制造欠拟合**——教材 §4.4.2 说的"过度限制的先验导致欠拟合"。
（c）**贝叶斯模型比较**：用边缘似然（证据）$P(D)=\int P(D|w)P(w)dw$ 比较不同 $\lambda$——**证据自动平衡"拟合度"与"复杂度惩罚"**（教材提到的 BIC/DIC 正是这类准则的近似）。工程上更实用的是**交叉验证**：在验证集上选 $\lambda$，让"泛化表现"而非"训练拟合"裁决先验强度。**"先验该多强"的答案，藏在"模型在没见过的数据上多好"里。**
**思路点拨**：若有人答"weight decay 越大越好，正则化越强越防过拟合"，他忽略了强正则化的欠拟合代价。若有人答"先验强度靠感觉调"，贝叶斯给出更系统的答案——证据/交叉验证**自动**在复杂度与拟合之间找平衡，这正是贝叶斯模型选择的威力。
