# §6.3.2 条件熵 —— 习题

本节主线把"给定 $X$ 后 $Y$ 还剩多少不确定"精确成条件熵 $H(Y\mid X)=\sum_x P(x)\,H(Y\mid X=x)$，并用教材天气例子手算出 0.646 bits。习题分三组：**概念检验** 验证条件熵的性质与方向陷阱，**计算实践** 手算教材例子并代码复核、加一个自创场景，**DL 延伸** 把条件熵放回语言模型与条件生成。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：哪个量随"方向"改变？

以下哪个量**不对称**（一般 $A \ne B$）？

- A. $H(Y \mid X)$ 与 $H(X \mid Y)$
- B. $H(X, Y)$ 与 $H(Y, X)$
- C. $H(X) + H(Y)$ 与 $H(Y) + H(X)$
- D. 独立时 $H(Y\mid X)$ 与 $H(Y)$

**解答**：A。

A 是方向不对称的：条件熵没有对称性，$H(Y\mid X)$ 几乎总不等于 $H(X\mid Y)$（教材例：0.646 vs 0.722）。B 的联合熵对变量顺序不敏感（配对集合一样，二重求和顺序无关）；C 是加法交换律，恒等；D 在独立时 $H(Y\mid X)=H(Y)$ 是恒等式。

**思路点拨**：考点是"什么量带方向"。联合熵、熵之和都不带方向（交换变量无影响）；条件熵带方向。判别锚点：**条件熵回答"知道 A 后 B 还剩多少"，A 与 B 互换，问题就变了**——"知道天气后带伞剩多少"和"知道带伞后天气剩多少"是两个不同的问题。做题时第一件事：确认谁是条件、谁是被条件。

### 题 2（判断 + 简答）：$H(Y\mid X)=H(Y)$ 说明什么？$H(Y\mid X)=0$ 呢？

小明算出 $H(Y\mid X)=H(Y)$，说："这不可能，知道 $X$ 总该有点帮助。" 又算出另一个场景 $H(Y\mid X)=0$，说："这下条件熵最小了，$X$ 和 $Y$ 完全无关吧？" 两句话各对错如何？

**解答**：第一句错，第二句错。

- $H(Y\mid X)=H(Y)$ **完全可能**，它恰恰是**独立**的标志：知道 $X$ 不改变对 $Y$ 的了解（条件熵取上界）。"知道总有帮助"是直觉的错觉——若 $X,Y$ 本来无关，知道等于不知道。
- $H(Y\mid X)=0$ 表示**给定 $X$ 后 $Y$ 被完全确定**（条件熵取下界）——这是**完全依赖**，不是"完全无关"。说"完全无关"恰好说反了：完全无关时条件熵该等于 $H(Y)$ 而不是 0。

**思路点拨**：条件熵的两端对应关系的两个极端：**下界 0 = 完全依赖**，**上界 $H(Y)$ = 完全独立**。这是整章最容易被记反的一对。记忆锚点：条件熵越小，$X$ 对 $Y$ 帮助越大——所以 0 是"帮助最大"（完全决定），$H(Y)$ 是"毫无帮助"（独立）。把"条件熵小"和"关系强"绑定，就不会记反。

### 题 3（简答）：为什么要"按 $P(x)$ 加权"，而不是取平均？

条件熵的定义是 $H(Y\mid X)=\sum_x P(x)\,H(Y\mid X=x)$，而不是 $H(Y\mid X)=\frac{1}{|\mathcal{X}|}\sum_x H(Y\mid X=x)$。解释为什么加权是必须的。

**解答**：因为 $X$ 的取值**不是等可能出现的**。教材天气例子里，晴天占 70%、雨天占 30%——"晴天时的带伞不确定 0.722 bits"在你的人生里出现的频率是"雨天时的不确定 0.469 bits"的 $\frac{0.7}{0.3}\approx2.3$ 倍。简单平均会错误地给两者相同的权重，算出 $\frac{0.722+0.469}{2}=0.596$——而这个数描述的是"一个晴天雨天各半的虚构世界"，不是你真实的世界。**条件熵要回答的是"在我的世界里，看了天之后平均还剩多少不确定"**，所以必须按 $X$ 的真实出现频率 $P(x)$ 加权。$P(x)$ 是世界的真实比例，不是均匀的。

**思路点拨**：这是理解条件熵"平均"语义的关键。加权平均 vs 简单平均的区别，本质是"按真实世界加权"vs"按假设的均匀世界加权"。日常直觉里的"平均"往往是简单平均，但概率论里的平均几乎总是加权平均——权就是概率。判别句：**哪个值在你的世界里出现得更频繁，它在平均值里的分量就该更大。**

## 二、计算实践

### 题 1（教材天气例子：完整手算）

数据：$P(S)=0.7, P(R)=0.3$；晴时带伞 $0.2$、不带 $0.8$；雨时带伞 $0.9$、不带 $0.1$。

(a) 手算 $H(Y\mid X=S)$ 与 $H(Y\mid X=R)$。
(b) 手算 $H(Y\mid X)$，并核对 $0 < H(Y\mid X) < H(Y)$。
(c) 验证链式法则：$H(X,Y)=H(X)+H(Y\mid X)$。

**解答**：

(a) $H(Y\mid S) = -(0.2\log_2 0.2 + 0.8\log_2 0.8) = 0.2\times2.322 + 0.8\times0.322 = 0.464+0.258 = 0.722$ bits。$H(Y\mid R) = -(0.9\log_2 0.9 + 0.1\log_2 0.1) = 0.9\times0.152 + 0.1\times3.322 = 0.137+0.332 = 0.469$ bits。

(b) $H(Y\mid X) = 0.7\times0.722 + 0.3\times0.469 = 0.505+0.141 = 0.646$ bits。$H(Y)=-(0.41\log_2 0.41+0.59\log_2 0.59)\approx0.977$ bits。所以 $0 < 0.646 < 0.977$：天气有帮助（小于 $H(Y)$），但没完全决定（大于 0）。

(c) $H(X) = -(0.7\log_2 0.7 + 0.3\log_2 0.3) = 0.7\times0.515+0.3\times1.737 = 0.360+0.521 = 0.881$ bits。联合表四格 $(0.14, 0.56, 0.27, 0.03)$，$H(X,Y) = -(0.14\log_2 0.14 + 0.56\log_2 0.56 + 0.27\log_2 0.27 + 0.03\log_2 0.03) \approx 0.397+0.469+0.510+0.152 = 1.528$ bits。链式法则：$H(X)+H(Y\mid X) = 0.881+0.646 = 1.527 \approx 1.528$（舍入误差内）——成立。

**思路点拨**：(a)(b) 是教材手算的完整复现，务必亲手走一遍。三个易错点：①$H(Y\mid S)$ 用条件分布 $(0.2,0.8)$，不是联合概率 $(0.14,0.56)$——条件分布已经归一化，别再把 $0.14, 0.56$ 代进熵公式；②加权用 $P(x)=(0.7,0.3)$，别用简单平均；③最后用 $0<0.646<0.977$ 核对结果是否落在合法区间——这是个免费的正确性检查。

**代码验证**：
```python
import numpy as np
def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -np.sum(p * np.log(p) / np.log(2))
pxy = np.array([[0.14, 0.56], [0.27, 0.03]])
px = pxy.sum(axis=1); py = pxy.sum(axis=0)
H_y_given_s = entropy([0.2, 0.8]); H_y_given_r = entropy([0.9, 0.1])
print(0.7 * H_y_given_s + 0.3 * H_y_given_r)      # 0.646
print(entropy(pxy) - entropy(px))                  # 0.646，链式法则版
print(entropy(py))                                 # 0.977 = H(Y)
```

### 题 2（自创场景：广告 × 购买）

电商数据：$X$ 表示用户是否看了广告（看 60%、不看 40%）；$Y$ 表示是否购买（买/不买）。看广告者买 30%、不看者买 5%。

(a) 算 $H(Y)$。
(b) 算 $H(Y\mid X)$。
(c) "广告提供了多少关于购买的信息"——用条件熵回答。

**解答**：

(a) $P(\text{买}) = 0.6\times0.3 + 0.4\times0.05 = 0.18+0.02 = 0.20$。$P(\text{不买}) = 0.80$。$H(Y) = -(0.2\log_2 0.2 + 0.8\log_2 0.8) = 0.2\times2.322 + 0.8\times0.322 = 0.464+0.258 = 0.722$ bits。

(b) $H(Y\mid X=\text{看}) = -(0.3\log_2 0.3 + 0.7\log_2 0.7) = 0.3\times1.737 + 0.7\times0.515 = 0.521+0.360 = 0.881$ bits。$H(Y\mid X=\text{不看}) = -(0.05\log_2 0.05 + 0.95\log_2 0.95) = 0.05\times4.322 + 0.95\times0.074 = 0.216+0.070 = 0.286$ bits。加权：$H(Y\mid X) = 0.6\times0.881 + 0.4\times0.286 = 0.529+0.114 = 0.643$ bits。

(c) 知道是否看广告后，购买的不确定从 0.722 降到 0.643——广告提供了 $0.722-0.643 = 0.079$ bits 的信息。**很少**（不到 0.1 bits）：看广告者买 30%、不看者买 5%，差别虽明显，但"买"的边缘概率本身很低（20%），这个变量整体很偏、不确定性本就不高，所以广告能削掉的部分有限。

**思路点拨**：这道题是条件熵在真实场景的完整走位。注意 (b) 里的加权细节：看广告的占 60%，它的条件熵 0.881 在平均值里权重更大。最反直觉的是 (c)：广告把购买概率从 5% 提到 30%（6 倍），信息增益却只有 0.079 bits——因为 $H(Y)$ 本身只有 0.722（$Y$ 太偏了，本来就不太确定）。**信息增益小不代表"没关系"**，只代表"能削掉的不确定绝对值少"——这是个值得记住的反直觉，也是信息论与"直觉重要性"的分野。

### 题 3（条件熵上界：独立时取等）

$P(X)=(0.7, 0.3)$，$Y$ 与 $X$ 完全独立，$P(Y)=(0.5, 0.5)$。求 $H(Y\mid X)$ 并解释它为什么等于 $H(Y)$。

**解答**：独立时 $P(y\mid x)=P(y)$ 对任意 $x$ 成立。于是 $H(Y\mid X=x) = H(Y)$ 对所有 $x$ 相同，加权后不变：$H(Y\mid X) = \sum_x P(x)\,H(Y) = H(Y)$。具体地，$H(Y) = -(0.5\log_2 0.5 + 0.5\log_2 0.5) = 1$ bit，所以 $H(Y\mid X) = 1$ bit。**独立时条件熵取上界 $H(Y)$**——知道 $X$ 对 $Y$ 毫无帮助，因为条件分布与边缘分布处处相同。

**思路点拨**：这道题考条件熵的上界语义。关键洞察：**"独立"意味着 $P(y\mid x) = P(y)$——条件分布退化成边缘分布**，于是每个条件熵都等于边缘熵，加权平均当然等于边缘熵。反之，只要条件分布与边缘分布有偏差，条件熵就严格小于 $H(Y)$。这个"偏差"正是下一节信息增益要量的东西。记不住方向就记这条：**独立 → 条件熵最大 → 信息增益为 0**。

## 三、DL 延伸

### 题 1（语言模型：条件熵为什么必须逐环递减）

一个自回归模型生成句子。训练时每一环的交叉熵损失 $\mathcal{L}_t = -\log_2 q(w_t \mid w_{<t})$，对应的条件熵 $H(w_t \mid w_{<t})$ 随 $t$ 增大而递减。

(a) 用条件熵的语言解释"递减"意味着什么。
(b) 如果在某个长位置 $t$ 条件熵突然**上升**，可能发生了什么？
(c) 整句的熵与逐环条件熵的关系（写出公式）。

**解答**：

(a) $H(w_t \mid w_{<t})$ 递减，说明**上下文越长，下一个词的剩余不确定越小**——模型学会用越来越多的历史去"锁定"下一个词。这就是语言"强预测性"的数值形态：开头几个词还比较自由（条件熵高），越往后越被前面约束。

(b) 条件熵突然上升，说明模型在长上下文处"更拿不准"了。常见原因：①该位置出现了罕见表达或从未见过的搭配（模型没见过，条件分布接近均匀）；②上下文窗口截断了关键信息（长距离依赖丢失）；③数值不稳定/训练不足。它不等于"模型出错"——它只是如实报告"这里我不确定"。

(c) 由链式法则：$H(w_1,\ldots,w_n) = H(w_1) + H(w_2\mid w_1) + \cdots + H(w_n\mid w_{<n})$——整句熵是逐环条件熵之和。

**思路点拨**：语言模型是条件熵的**逐环工厂**。训练中监控 $H(w_t\mid w_{<t})$ 随 $t$ 的曲线，比只看平均损失更精细：它告诉你模型在哪个位置"心里没底"。条件熵上升点的模式，往往能暴露数据分布的薄弱区。注意 (a) 与 (c) 要连起来想：递减的条件熵加起来，就是整句的总不确定——语言之所以可压缩（6.6 节），正因为这些条件熵远小于"无上下文的熵"。

### 题 2（条件生成：条件给得好，输出才确定）

一个"文本 → 图像"生成模型，输入 prompt $c$ 生成图像 $x$，目标是压低 $H(X \mid C)$。某工程师观察到：模型在长 prompt 下生成的图像比短 prompt 下更"一致"。

(a) 用条件熵解释这个现象。
(b) "更一致"是否必然意味着"更好"？条件熵能回答这个吗？

**解答**：

(a) 长 prompt 携带更多关于目标图像的信息，所以 $H(X \mid C=\text{长 prompt})$ 比 $H(X \mid C=\text{短 prompt})$ 小——给定更多条件，输出的剩余不确定更少，模型"发挥空间"更小，生成的图像自然更一致。条件生成模型的核心能力，就是**把"输出"的条件熵压到尽量低**（条件给够时，图像几乎确定）。

(b) **不一定**。$H(X\mid C)$ 小只说明"给定 $c$，输出很确定"——但可能是"错误地确定"（模型无视 prompt 细节，总是输出同一类图）。条件熵衡量的是**确定性**，不是**正确性**——这和 6.2 节的边界一致：熵低 ≠ 答案对。要判断"更好"，还得看生成图像与 prompt 的语义吻合度。条件熵说"模型不再犹豫"，但它不说"模型答对了"。

**思路点拨**：这道题把条件熵从"度量的确定性"推回"不等于正确性"。最重要的迁移：**$H(X\mid C)$ 小 = 输出一致 = 模型"不再犹豫"；但一致的方向对不对，是另一个问题。** 这正是为什么生成模型的评估不能只看"多样性/一致性"，还要看"对齐度"。条件熵是所有"不确定"量具的共同弱点——它们诚实，但不评判对错。把"条件熵下降"当作"模型进步"的唯一指标，是常见误区。
