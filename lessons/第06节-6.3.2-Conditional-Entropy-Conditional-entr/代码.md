# 代码：条件熵——把"加权平均"的每一步摊开

主线把条件熵定义为"先对每个 $x$ 算一个条件熵 $H(Y\mid X=x)$，再按 $P(x)$ 加权平均"。本脚本**严格按照这个定义**实现 `conditional_entropy_by_value`——它会把每个天气值下的条件熵算出来、打出来、再加权求和，让加权平均的过程一目了然；同时给出链式法则版 `conditional_entropy` 做交叉验证。最后验证教材天气例子的 **0.646 bits**，并亲眼看 $H(Y\mid X) \ne H(X\mid Y)$ 的方向不对称。

---

## 层一：完整脚本

```python
import numpy as np                                   # 二维数组 = 联合分布表

def entropy(probs, base=2):                          # ① 一维熵（6.2 复用）
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def marginal(pxy, axis):                             # ② 边缘化
    return pxy.sum(axis=axis)

def conditional_entropy_by_value(pxy, base=2):       # ③ 按定义：先逐值算，再加权
    """H(Y|X) = Σ_x P(x)·H(Y|X=x)。返回 (总条件熵, 每个 x 的条件熵表)。"""
    px = marginal(pxy, axis=1)                       # P(x)：沿列求和
    cond = np.zeros_like(px)                         # 每个 x 一个条件熵
    for i in range(pxy.shape[0]):                    # 遍历每个 x 值
        py_given_x = pxy[i] / px[i]                  # P(Y|X=x)：该行除以 P(x)
        cond[i] = entropy(py_given_x, base)          # H(Y|X=x)
    return np.sum(px * cond), cond                   # 加权求和 + 逐值表

def conditional_entropy(pxy, base=2):                # ④ 链式法则快捷版
    """H(Y|X) = H(X,Y) - H(X)。与 ③ 结果一致。"""
    return entropy(pxy, base) - entropy(marginal(pxy, axis=1), base)

# ---- 教材天气 × 带伞：行=X{晴,雨}，列=Y{带,不带} ----
pxy_weather = np.array([[0.7 * 0.2, 0.7 * 0.8],      # P(晴,带)=0.14, P(晴,不带)=0.56
                        [0.3 * 0.9, 0.3 * 0.1]])     # P(雨,带)=0.27, P(雨,不带)=0.03
print("== 教材天气 × 带伞 ==")
print(f"H(Y)                = {entropy(marginal(pxy_weather, axis=0)):.3f}   # 知道前的不确定")
Hc, cond_table = conditional_entropy_by_value(pxy_weather)
print("每个天气值下的条件熵 H(Y|X=x):")
for name, val in zip(["晴", "雨"], cond_table):
    print(f"  X={name}: H(Y|X={name}) = {val:.3f}")
print(f"H(Y|X) 按定义加权     = {Hc:.3f}   # 期望 0.646")
print(f"H(Y|X) 用链式法则     = {conditional_entropy(pxy_weather):.3f}   # 交叉验证")

# ---- 方向不对称：H(Y|X) vs H(X|Y) ----
print("\n== 方向不对称 ==")
print(f"H(Y|X) = {conditional_entropy(pxy_weather):.3f}")
print(f"H(X|Y) = {conditional_entropy(pxy_weather.T):.3f}   # 转置表：X,Y 互换")

# ---- 边界实验：从完全决定到完全独立 ----
print("\n-- 边界实验：雨天带伞概率从 0.5 扫到 1.0 --")
for p_umbrella_rain in [0.5, 0.9, 1.0]:
    tab = np.array([[0.7*0.2, 0.7*0.8], [0.3*p_umbrella_rain, 0.3*(1-p_umbrella_rain)]])
    print(f"雨天带伞={p_umbrella_rain} -> H(Y|X)={conditional_entropy(tab):.3f}   H(Y)={entropy(marginal(tab,axis=0)):.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
== 教材天气 × 带伞 ==
H(Y)                = 0.977   # 知道前的不确定
每个天气值下的条件熵 H(Y|X=x):
  X=晴: H(Y|X=晴) = 0.722
  X=雨: H(Y|X=雨) = 0.469
H(Y|X) 按定义加权     = 0.646   # 期望 0.646
H(Y|X) 用链式法则     = 0.646   # 交叉验证

== 方向不对称 ==
H(Y|X) = 0.646
H(X|Y) = 0.551   # 转置表：X,Y 互换

-- 边界实验：雨天带伞概率从 0.5 扫到 1.0 --
雨天带伞=0.5 -> H(Y|X)=0.805   H(Y)=0.869
雨天带伞=0.9 -> H(Y|X)=0.646   H(Y)=0.977
雨天带伞=1.0 -> H(Y|X)=0.505   H(Y)=0.990
```

三个关键画面：①"加权平均"的结构被逐值打印——晴 0.722、雨 0.469，加权 $0.7\times0.722+0.3\times0.469=0.646$；②$H(Y\mid X)=0.646 \ne H(X\mid Y)=0.551$——方向不对称；③雨天带伞越接近必带，条件熵越低（同时注意 $H(Y)$ 也在变——改"雨天带伞概率"会同时改边缘分布）。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：`entropy` 与 `marginal` —— 复用零件

```python
def entropy(probs, base=2):
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def marginal(pxy, axis):
    return pxy.sum(axis=axis)
```

#### `entropy` —— 一维熵

**操作**：与 6.2/6.3 节一致。**注意它被用在条件分布上**——`entropy(py_given_x)` 算的就是"给定某个 $x$ 后 $Y$ 的熵"。
**输入**：一维分布。
**输出**：标量。
**对应数学**：$H(Y\mid X=x) = -\sum_y P(y\mid x)\log P(y\mid x)$ 的实现。

#### `marginal` —— 边缘化

**操作**：`pxy.sum(axis=axis)`。`axis=1` → $P(x)$；`axis=0` → $P(y)$。
**对应数学**：$P(x)=\sum_y P(x,y)$，是加权平均里的"权"。

---

### 步骤 2：定义 `conditional_entropy_by_value` —— 按定义，一步一步

```python
def conditional_entropy_by_value(pxy, base=2):
    """H(Y|X) = Σ_x P(x)·H(Y|X=x)。返回 (总条件熵, 每个 x 的条件熵表)。"""
    px = marginal(pxy, axis=1)                       # P(x)：沿列求和
    cond = np.zeros_like(px)                         # 每个 x 一个条件熵
    for i in range(pxy.shape[0]):                    # 遍历每个 x 值
        py_given_x = pxy[i] / px[i]                  # P(Y|X=x)：该行除以 P(x)
        cond[i] = entropy(py_given_x, base)          # H(Y|X=x)
    return np.sum(px * cond), cond                   # 加权求和 + 逐值表
```

#### `conditional_entropy_by_value(pxy, base)` —— 按定义逐步计算

**做什么**：严格按主线定义实现条件熵——**先对每个 $x$ 值算一个条件熵 $H(Y\mid X=x)$，再按 $P(x)$ 加权平均**。同时把"每个 $x$ 的条件熵"作为第二返回值吐出来，方便逐值检视。
**操作**：
1. `px = marginal(pxy, axis=1)`：沿列求和得到 $P(x)$（天气分布 $(0.7, 0.3)$）。
2. `cond = np.zeros_like(px)`：开一个与 $P(x)$ 同形状的数组，存每个 $x$ 的条件熵。
3. 循环 `for i in range(pxy.shape[0])`：遍历每一行（每个 $x$ 值）。`pxy[i] / px[i]` 把该行联合概率除以 $P(x_i)$——得到**条件分布** $P(Y \mid X = x_i)$（晴天行 $(0.14, 0.56)$ 除以 0.7 得 $(0.2, 0.8)$）。`entropy(py_given_x)` 对这个条件分布算熵，存进 `cond[i]`。
4. `np.sum(px * cond)`：`px * cond` 逐元素乘（每个 $x$ 的权重 × 它的条件熵），求和即加权平均。
**输入**：
- `pxy`：联合分布表，形状 `(n_x, n_y)`，行 = X 的取值、列 = Y 的取值。
- `base`：对数底，默认 2。
**输出**：元组 `(总条件熵, 逐值条件熵数组)`。第一项是标量 $H(Y\mid X)$；第二项形状 `(n_x,)`，第 $i$ 项是 $H(Y\mid X=x_i)$。
**可调参数**：
- `base` 同前。
- `pxy.shape[0]` 决定循环次数（X 有几个取值就循环几次）——这个函数自动适应任意行数，不是写死的天气例子。
- 能不能加参数？`pxy, base` 已完备。它返回逐值表是为了教学透明；工程上通常只要总熵，用下面的 `conditional_entropy` 更简洁。
**对应数学**：主线定义块 $H(Y\mid X) = \sum_x P(x)\,H(Y\mid X=x)$ 的逐行翻译。`pxy[i] / px[i]` 就是 $P(y\mid x) = P(x,y)/P(x)$ 的条件化操作；`entropy(py_given_x)` 是 $H(Y\mid X=x)$；`np.sum(px * cond)` 是加权平均。

---

### 步骤 3：定义 `conditional_entropy` —— 链式法则的快捷版

```python
def conditional_entropy(pxy, base=2):
    """H(Y|X) = H(X,Y) - H(X)。与 ③ 结果一致。"""
    return entropy(pxy, base) - entropy(marginal(pxy, axis=1), base)
```

#### `conditional_entropy(pxy, base)` —— $H(Y\mid X) = H(X,Y) - H(X)$

**做什么**：条件熵的**快捷实现**——不逐值算条件熵，而是用 6.3 节的链式法则移项：$H(Y\mid X) = H(X,Y) - H(X)$。
**操作**：`entropy(pxy)` 是联合熵 $H(X,Y)$；`entropy(marginal(pxy, axis=1))` 是 $H(X)$；相减即得。
**输入**：联合表 `pxy`；`base`。
**输出**：标量条件熵 $H(Y \mid X)$。
**可调参数**：想算 $H(X \mid Y)$，用链式法则另一头 $H(X,Y)-H(Y)$：把 `axis=1` 换成 `axis=0`——或者直接 `conditional_entropy(pxy.T)`（转置表让 X、Y 互换）。两个方向数值不同，方向由 `axis` 决定。
**对应数学**：链式法则 $H(X,Y)=H(X)+H(Y\mid X)$ 的移项。脚本里 0.646 与 `conditional_entropy_by_value` 的 0.646 完全一致——**两条路线殊途同归**，交叉验证了定义的正确性。

---

### 步骤 4：教材例子 —— 逐值条件熵 + 加权平均

```python
Hc, cond_table = conditional_entropy_by_value(pxy_weather)
for name, val in zip(["晴", "雨"], cond_table):
    print(f"  X={name}: H(Y|X={name}) = {val:.3f}")
print(f"H(Y|X) 按定义加权     = {Hc:.3f}   # 期望 0.646")
print(f"H(Y|X) 用链式法则     = {conditional_entropy(pxy_weather):.3f}   # 交叉验证")
```

**做什么**：把教材天气例子的加权平均过程完整摊开。
**操作**：`conditional_entropy_by_value` 返回逐值表 `[0.722, 0.469]` 与加权和 0.646；`conditional_entropy` 给出同值的交叉验证。
**对应数学**：主线第二节的完整手算——$0.7\times0.722 + 0.3\times0.469 = 0.646$。注意**逐值条件熵 (0.722, 0.469) 是"给定具体天气后的剩余不确定"**，加权后的 0.646 才是"整体知道天气后的剩余不确定"。前者是中间产物，后者是答案。

---

### 步骤 5：方向不对称 —— $H(Y\mid X) \ne H(X\mid Y)$

```python
print(f"H(Y|X) = {conditional_entropy(pxy_weather):.3f}")
print(f"H(X|Y) = {conditional_entropy(pxy_weather.T):.3f}   # 转置表：X,Y 互换")
```

**做什么**：用转置表算另一个方向的条件熵。
**操作**：`pxy_weather.T` 是转置——原来"行=天气、列=带伞"变成"行=带伞、列=天气"。`conditional_entropy(pxy_weather.T)` 算的正是 $H(X \mid Y)$（把转置后的"行"当作条件变量）。
**对应数学**：主线边界声明——条件熵**不对称**。$H(Y\mid X)=0.646$（天气帮带伞消掉 $0.977-0.646=0.331$），$H(X\mid Y)=0.551$（带伞帮天气只消掉 $0.881-0.551=0.331$——等等，两个差其实**相等**！）。没错：$0.331 = 0.331$，因为 $H(Y)-H(Y\mid X) = H(X)-H(X\mid Y) = I(X;Y)$（互信息，6.5 节）。条件熵 $H(Y\mid X)$ 与 $H(X\mid Y)$ **数值不同**（0.646 vs 0.551），但它们各自与边缘熵的差是同一个数——这正是"互信息对称"的来历。方向不对称的是条件熵本身，对称的是被消掉的共享量。

### 步骤 6：边界实验 —— 关系越强，条件熵越低

```python
for p_umbrella_rain in [0.5, 0.9, 1.0]:
    tab = np.array([[0.7*0.2, 0.7*0.8], [0.3*p_umbrella_rain, 0.3*(1-p_umbrella_rain)]])
    print(f"雨天带伞={p_umbrella_rain} -> H(Y|X)={conditional_entropy(tab):.3f}   H(Y)={entropy(marginal(tab,axis=0)):.3f}")
```

**做什么**：把"雨天带伞概率"从 0.5（雨天带伞与晴天带伞相同 → 天气与带伞无关）扫到 1.0（雨天必带 → 天气完全决定带伞），观察条件熵。
**操作**：循环里手动改联合表的雨天行，`conditional_entropy` 与 `H(Y)` 一起打印。
**对应数学**：主线"两个极端"的现场验证。`p_umbrella_rain=0.5` 时雨天与晴天的条件分布相同（都 0.2/0.8），天气对带伞毫无帮助 → 条件熵 0.805（接近但略小于同表的 $H(Y)=0.869$，因为"雨天带伞 0.5"把边缘分布改变了）；`=1.0` 时雨天必带 → 条件熵降到 0.505。**注意 $H(Y)$ 也在变（0.869 → 0.977 → 0.990）：改"雨天带伞概率"会同时改变边缘 $P(Y)$。** 所以正确的对比是"同一张表内 $H(Y\mid X) \le H(Y)$"（每一行都满足：0.805<0.869、0.646<0.977、0.505<0.990）——条件熵永远不会超过同表的边缘熵。

## 改个数字试试：把方向与边界推向极端

### 实验 1：完全决定（晴天必不带、雨天必带）

```python
tab = np.array([[0.7*0.0, 0.7*1.0], [0.3*1.0, 0.3*0.0]])   # 晴不带、雨必带
print(f"H(Y|X) = {conditional_entropy(tab):.3f}   # 期望 0：天气完全决定带伞")
print(f"H(X|Y) = {conditional_entropy(tab.T):.3f}")
```

输出：

```text
H(Y|X) = 0.000   # 期望 0：天气完全决定带伞
H(X|Y) = 0.000
```

晴天必不带、雨天必带——知道天气就完全知道带伞，$H(Y\mid X)=0$（条件熵下界）。有趣的是 $H(X\mid Y)$ 也是 0：因为这种"双射"关系下，知道带伞也完全知道天气（不带→晴，带→雨）。**当关系是"一一对应"时，两个方向的条件熵同时为零**——完全可逆的依赖。

### 实验 2：单向决定（天气完全决定带伞，但带伞不决定天气）

```python
tab = np.array([[0.2*1.0, 0.2*0.0], [0.3*1.0, 0.3*0.0], [0.5*0.0, 0.5*1.0]])
# 三个天气：X1→必带、X2→必带、X3→必不带（带伞只分两列）
print(f"H(Y|X) = {conditional_entropy(tab):.3f}   # 0：给定天气，带伞完全确定")
print(f"H(X|Y) = {conditional_entropy(tab.T):.3f}   # >0：给定带伞，还有三个天气的不确定")
```

输出：

```text
H(Y|X) = 0.000   # 0：给定天气，带伞完全确定
H(X|Y) = 0.485   # >0：给定带伞，还有三个天气的不确定
```

这是方向不对称的**终极形态**：$X$ 完全决定 $Y$（$H(Y\mid X)=0$），但 $Y$ 不能完全决定 $X$（知道"必带"，仍分不清是 X1 还是 X2 导致的必带——$P(X\mid Y=Yes)$ 在 X1/X2 间还有 0.971 bits 的不确定，加权后剩 0.485）。**"完全决定"是单向的**——$H(Y\mid X)=0$ 只说明"知道 $X$ 就够"，不说明"知道 $Y$ 就够"。这正是主线边界声明"方向不能混"的最强例证，也是很多信息论误读的来源。

## 边界声明：这套代码能做什么，不能做什么

1. **方向是函数的第一参数。** `conditional_entropy(pxy)` 按"行 = 条件变量"计算——`pxy` 的行是 $X$ 时返回 $H(Y\mid X)$，转置后返回 $H(X\mid Y)$。两个值一般不等（天气例 0.646 vs 0.551）。**用错方向是最常见的错误**：写代码时确认"谁是条件"，写论文时确认"箭头指向哪"。
2. **条件熵依赖整张联合表，不依赖"看起来像不像相关"。** `conditional_entropy` 只认 `pxy` 里的数字。两张边缘相同但条件结构不同的表会给出不同的条件熵——条件熵量的是"表内的条件关系"，不是任何外部的直观。若表没归一化（格子之和 ≠ 1），`marginal` 得到的 $P(x)$ 不是概率，加权平均就错了。
3. **"给定一个值"与"给定整个变量"的区别，代码里清晰可见。** `conditional_entropy_by_value` 打印的逐值表（0.722、0.469）是"给定某一天天气"的条件熵——它们是中间产物；加权后的 0.646 才是"给定整个天气变量"的条件熵——这是答案。别把逐值表当成答案，也别以为"知道了晴天的条件熵"就是"知道了条件熵"。方向、加权、归一化，是这把尺子赖以成立的三根支柱。
