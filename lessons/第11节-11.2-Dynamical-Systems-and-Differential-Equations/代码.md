# 代码：同一个世界，两种量法

主线说：离散与连续，是同一种变化的两副刻度。这句话不能被"感觉"接受，要用数字证明。

设定一个具体场景：一笔 100 元的存款，年利率 5%。**离散的记法**说：每年末连本带利翻一次，$x_{n+1} = 1.05\,x_n$。**连续的记法**说：利率每时每刻都在复利，变化率恒等于 $0.05x$，$x(t) = 100e^{0.05t}$。

矛盾来了：同样十年，离散版复利 10 次，连续版复利了无穷多次——它们会给出**不同的答案**。这差距从哪来？答案是：**离散版本藏在"每隔多久结一次息"这个隐藏旋钮上。** 如果一年结息 $N$ 次，十年结 $10N$ 次，你会得到 $x = 100(1 + 0.05/N)^{10N}$。$N=1$ 是离散，$N \to \infty$ 就是连续——中间每一个有限的 $N$，都是同一副刻度下的格子。欧拉 (Euler) 把这事做成了一条定理：$(1 + r/N)^N \to e^r$。

下面的脚本把这个旋钮拨到底：从 $N=1$（一年结一次息，等于离散动力系统）开始，逐级拨大 $N$，看十年后的金额如何一路逼近 $100e^{0.5}$——亲眼看见"一口跳一步的钟"和"一口时时流的钟"在极限处合体。

---

## 层一：完整脚本

```python
import numpy as np                                 # np.exp 提供自然指数 e^{...}

def discrete_growth(x0, r, n):                     # ① 离散动力系统：x_{k+1} = (1+r) x_k
    """按步跳：每步复利一次，返回走完 n 步后的状态。"""
    x = x0
    for _ in range(n):                             # 规则被反复施加 n 次
        x = (1.0 + r) * x                          # 一步更新
    return x

def continuous_growth(x0, r, t):                   # ② 连续动力系统：dx/dt = r x
    """时时流：直接给出解析解 x(t) = x0 * e^{rt}。"""
    return x0 * np.exp(r * t)                      # 这就是"无限复利"的终点

x0, r, T = 100.0, 0.05, 10.0                       # 本金 100，利率 5%，十年

print("=== 拨动'每年结息次数'N 这个旋钮 ===")
for N in [1, 4, 12, 365, 100000]:                  # 1=一年一次(离散)，∞ 的极限=连续
    xN = x0 * (1.0 + r / N) ** (N * T)             # 十年结 N*T 次息，复利公式
    print(f"N = {N:>7d}   十年后 = {xN:10.4f}")

print("\n=== 两端对照 ===")
print(f"离散版  N=1       十年后 = {discrete_growth(x0, r, 10):.4f}")
print(f"连续版  e^{{rT}}   十年后 = {continuous_growth(x0, r, T):.4f}")
```

运行输出（Python 3.11 + NumPy）：

```text
=== 拨动'每年结息次数'N 这个旋钮 ===
N =       1   十年后 =   162.8895
N =       4   十年后 =   164.3620
N =      12   十年后 =   164.7010
N =     365   十年后 =   164.8660
N =  100000   十年后 =   164.8721

=== 两端对照 ===
离散版  N=1       十年后 = 162.8895
连续版  e^{rT}   十年后 = 164.8721
```

看那串数字：$162.89 \to 164.87$，一格一格地往上爬，最后稳稳落在 $164.8721$。十年结息 10 万次的结果，与解析解 $100e^{0.5} = 164.8721$ **在小数点后 4 位完全相同**。离散的钟和连续的钟，在极限处合体了。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy —— 只需要一个函数

```python
import numpy as np
```

**做什么**：加载 NumPy。整段脚本只用它一个函数：`np.exp`（自然指数 $e^{(\cdot)}$）。复利公式里 $e^{rT}$ 由它给出；连续解 $x_0 e^{rt}$ 也靠它。

#### `import numpy as np` —— 引入数值工具箱

**操作**：加载 NumPy 并绑定简写 `np`。
**输入**：无。
**输出**：`np` 句柄，这里只用 `np.exp`。
**可调参数**：无。
**对应数学**：$e^{rT}$ 是"无限复利"的极限值，`np.exp` 就是计算它的引擎。

### 步骤 2：定义 `discrete_growth` —— 离散动力系统的样板

```python
def discrete_growth(x0, r, n):
    x = x0
    for _ in range(n):
        x = (1.0 + r) * x
    return x
```

#### discrete_growth —— 按步跳：反复施加演化规则 $x_{k+1}=(1+r)x_k$

`x = (1.0 + r) * x`

**做什么**：从初始状态 `x0` 出发，把演化规则 $x_{k+1} = (1+r)x_k$ 连续施加 `n` 次，返回最终状态。这是主线定义块里离散动力系统的**代码模板**——状态、规则、反复作用，一个不缺。
**操作**：`for` 循环执行 `n` 次，每次把当前 `x` 替换成 `(1+r) * x`。每循环一次，就是动力系统走一步。
**输入**：
- `x0`：初始状态，标量。对应动力系统的**初始条件**。
- `r`：增长率，标量。这里是 0.05（5%）。它和 1 相加，构成演化规则 $f(x) = (1+r)x$ 里的乘子。
- `n`：步数，正整数。规则被施加的次数。
**输出**：一个标量——走完 `n` 步后的状态 $x_n = x_0(1+r)^n$。
**可调参数**：
- `r` 是这个系统的灵魂。$r > 0$ 指数增长（本金长大），$r < 0$ 指数衰减（放射性衰变），$|r|$ 越大变化越猛。把 `r` 改成 $-0.02$，你会看到十年后只剩 100×(0.98)¹⁰ ≈ 81.7——衰减与增长，同一个规则的两个方向。
- `n` 是"时间刻度"：每步代表多久。同样十年，`n=10` 表示一年一步，`n=3650` 表示一天一步。
- 能不能加第四个参数？这个函数已经完整——更一般的形式是把 `(1+r)` 整个换成任意演化函数 $f(x)$（比如逻辑斯蒂映射 $x(1-x)$），那会让它从"线性增长"升级成"能产生混沌"的通用模拟器，但那已属于 §11.2.2.2 的故事。
**对应数学**：主线支柱一的离散写法 $x_{n+1} = f(x_n)$。这里 $f(x) = (1+r)x$ 是最简单的一种演化规则——一个线性乘子。别小看它：上一节 §11.1 的 RNN 状态更新，本质就是"$\sigma$ 包裹着的、带外部输入的线性乘子"。

### 步骤 3：定义 `continuous_growth` —— 连续动力系统的解析解

```python
def continuous_growth(x0, r, t):
    return x0 * np.exp(r * t)
```

#### continuous_growth —— 时时流：$x(t) = x_0 e^{rt}$

`return x0 * np.exp(r * t)`

**做什么**：直接给出连续动力系统 $\frac{dx}{dt} = rx$ 的解析解。不迭代，一锤定音。
**操作**：`np.exp(r * t)` 计算 $e^{rt}$，再乘 `x0`。这一步背后其实藏着一个推导：$\frac{dx}{dt} = rx$ 的解是 $x(t) = x_0 e^{rt}$——因为 $e^{rt}$ 的导数正是 $r e^{rt}$，代回方程两边相等。主线的"推导优于宣告"在这里兑现：不是背公式，是验证公式。
**输入**：
- `x0`：初始状态，标量。
- `r`：变化率常数，标量。对应微分方程右端的系数。
- `t`：连续时间，标量（或任意形状数组——传数组时一次返回所有时刻的状态）。
**输出**：$x(t)$——任意时刻的状态。传标量返回标量，传数组返回数组。
**可调参数**：
- `t` 可以是一个数组 `np.linspace(0, 10, 1000)`——一次算出整条连续轨道，直接画图。这是连续版比离散版"省事"的地方：离散版要循环 1000 步，这里一次 `np.exp` 全给。
- `r` 为负时 $e^{rt}$ 指数衰减——同一公式管增长也管衰减，这正体现了 $e$ 作为"最自然的增长函数"的普适性。
- 能不能加参数？真正的通用版本应该接受**任意**右端函数 $f(x)$（如 $f(x) = x(1-x)$），此时没有解析解，要靠数值积分——那是 §11.2.1.2 的 Euler 方法。这里的 `continuous_growth` 是"恰有解析解"的特例。
**对应数学**：主线里连续版本 $\frac{dx(t)}{dt} = f(x(t))$ 中取 $f(x)=rx$ 的特例，及其解析解。教材 §11.2.1.2 的指数增长 $x(t) = x(0)e^{0.5t}$ 正是它的翻版。

### 步骤 4：拨动"结息次数"旋钮 —— 从离散走向连续

```python
for N in [1, 4, 12, 365, 100000]:
    xN = x0 * (1.0 + r / N) ** (N * T)
    print(f"N = {N:>7d}   十年后 = {xN:10.4f}")
```

**做什么**：把"每年结息 $N$ 次"从 1 一路拨到 10 万，每次算十年后的总金额，打印成表格。这一行的数学：
$$x_N(T) = x_0\left(1 + \frac{r}{N}\right)^{NT}$$

#### `(1.0 + r / N) ** (N * T)` —— 复利公式的代码形态

**操作**：先把年利率 $r$ 除以 $N$，得到"每次结息期"的利率；`**` 是幂运算，共复利 $N \times T$ 次。`N=1` 时退化为 $x_0(1+r)^T$——正是 `discrete_growth`；`N` 越大越接近连续。
**输入**：`x0`（本金）、`r`（年利率）、`T`（年数）、`N`（每年结息次数）。
**输出**：十年后的总金额，标量。
**可调参数**：`N` 是这里唯一的旋钮。`N=1` 是纯离散；`N=4` 是季度复利；`N=12` 是月复利；`N=365` 是日复利；`N=100000` 几乎等于连续。你甚至可以试 `N=10**9`——结果停在 164.8721 不再变化，那就是 $e^{rT}$ 的极限。
**对应数学**：欧拉极限 $(1 + r/N)^N \to e^r$ 的数值演示。输出的那串单调递增的数字，就是"离散刻度和连续刻度之间的每一格"。

### 步骤 5：两端对照 —— 收敛到同一个数

```python
print(f"离散版  N=1       十年后 = {discrete_growth(x0, r, 10):.4f}")
print(f"连续版  e^{{rT}}   十年后 = {continuous_growth(x0, r, T):.4f}")
```

**做什么**：把离散版（`N=1`）和连续版（`e^{rT}`）并排打印。输出的对比就是本节主题的证据：162.8895 与 164.8721 不同——**离散与连续在同一种刻度下给出不同答案，因为它们藏在"每次复利间隔"这个旋钮上**；而随着 `N` 增大，中间版本的数值一路逼近连续版，最终在小数点后 4 位完全重合。

#### `discrete_growth(x0, r, 10)` vs `continuous_growth(x0, r, T)` —— 两副刻度，同一个世界

**操作**：分别调用两个函数。前者循环 10 次（一年一步），后者一次 `np.exp` 完成。
**输入**：相同的 `x0=100, r=0.05`；步数 `10` vs 时间 `T=10`。
**输出**：两个标量——`162.8895` 和 `164.8721`。
**可调参数**：把 `T` 换成 50 年，离散版 100×1.05⁵⁰ ≈ 1146.7，连续版 100e²·⁵ ≈ 1218.3——差距被时间放大，但**相对结构不变**：连续版永远比离散版多那么一点，因为多复利了无穷次。换成负利率，离散版（$0.98^{10} \approx 0.817$）和连续版（$e^{-0.2} \approx 0.819$）依然趋同。
**对应数学**：这就是主线"同一种变化的两副刻度"的数值证词——$\{x_n\}$ 是离散轨道，$x(t)$ 是连续轨道，它们在同一时刻的值只在"格子有多粗"上分道扬镳。

## 边界声明：这套代码能做什么，不能做什么

1. **这个例子有解析解，是特例中的特例。** $\frac{dx}{dt}=rx$ 是最简单的一阶线性常微分方程，恰有闭式解 $x_0e^{rt}$。绝大多数动力系统（摆锤、洛伦兹方程、RNN 的连续版本）**没有**解析解——那时不能用 `np.exp` 一锤定音，必须用 Euler 方法或 `scipy.integrate.solve_ivp` 做数值积分（§11.2.1.2、§11.2.2.1 会做这件事）。这里的"简单"是为让你先看见离散与连续之间的**关系**，不是世界普遍的样子。
2. **"连续版"在这里只是一个极限。** `continuous_growth` 返回的是解析值，它代表"复利间隔无限细"的极限。真实的连续系统不是"每隔极小时间跳一次"，而是**每时每刻都在变**——但两者的数值几乎不可分辨，这正是 Euler 方法能工作的原因：把连续流切成足够细的离散步，误差小到可接受。
3. **这只是一个确定性的线性系统。** 没有随机、没有非线性、没有相互作用。真实的动力系统——三体问题、逻辑斯蒂映射、RNN——都有非线性项，会产生震荡、分岔、混沌。$e^{rt}$ 的优雅曲线是线性世界的专利；非线性世界的轨道，常常丑得多，也迷人得多。
