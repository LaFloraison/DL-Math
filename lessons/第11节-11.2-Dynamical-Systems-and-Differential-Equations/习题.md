# §11.2 动力系统与微分方程的理论 —— 习题

主线立起两根支柱：动力系统（状态 + 规则）与微分方程（变化的语言），并划出离散/连续、ODE/PDE 两条分界线。下面的习题分三组：**概念检验** 验证你接住了两根支柱的骨架，**计算实践** 亲手算复利的离散与连续版本，**DL 延伸** 把两根支柱放回 RNN 与扩散模型。

---

## 一、概念检验

### 题 1（选择）：哪个是"状态"，哪个是"演化规则"？

一个保温杯里的咖啡在慢慢凉下去。以下是动力系统的视角，哪项说法**正确**？

- A. 咖啡温度是演化规则，凉下去的速度是状态
- B. 咖啡温度是状态，描述"温度如何随时间和环境变化"的规律是演化规则
- C. 环境温度是状态，咖啡温度是演化规则
- D. 咖啡温度和时间都是演化规则

**解答**：B。

动力系统的两件套：**状态** = 系统在某一时刻的完整信息（这里就是咖啡温度），**演化规则** = 把当前状态变成下一个状态的法则（这里就是冷却定律——牛顿冷却定律 $\frac{dT}{dt} = -k(T - T_{\text{env}})$）。A 把两者倒置；C 混淆了外部环境（边界条件）与系统内部状态；D 把自变量时间误当成了规则。

**思路点拨**：判据是"哪一个是**此刻的值**，哪一个是**如何变**"。温度是此刻的值，冷却规律是如何变。抓住这个"值 vs 变"的分工，动力系统的骨架就立住了。

### 题 2（判断 + 简答）："连续 = 无限精细的离散"吗？

有人说："连续动力系统就是把离散动力系统的步长取到无穷小，两者本质相同。" 判断并解释。

**解答**：方向对，但要补一个关键的精确化。连续系统确实可以看作"离散化的步长 $\to 0$"的极限——§11.2 代码里 $(1+r/N)^{NT} \to e^{rT}$ 就是这个意思；反过来，数值求解连续系统也靠"切成足够细的步长"（Euler 方法）。但**两者不是一回事**：离散系统的状态**只在一串时刻上被定义**，连续系统的状态在**每一瞬间都被定义**；离散的演化规则是"位置 → 位置"，连续的是"位置 → 变化率"。它们的关系是"极限与逼近"，不是"本质相同"——就像圆是多边形的极限，但圆周率的严格定义并不靠画多边形。

**思路点拨**：这道题考"极限 ≠ 等同"。最严谨的说法是：连续系统是离散系统在步长趋于零时的极限对象，而离散系统是连续系统的一种**离散化近似**。教材里图 11.1 正是画这对关系的：两条轨迹在变化平缓处几乎重合，在变化剧烈处分开——近似的裂缝在那里现形。

### 题 3（简答）：ODE 和 PDE 的分界线在哪？

请用自己的话解释：为什么秋千用 ODE、而金属棒里的热扩散用 PDE？

**解答**：分界线在**有几个自变量**。ODE（常微分方程）只有一个自变量（通常是时间 $t$），函数 $y(t)$ 的导数 $dy/dt$ 是普通导数。秋千的位置 $y(t)$ 只随时间变化——一个时间轴就够描述它，所以是 ODE（$\frac{d^2y}{dt^2} + \omega^2 y = 0$）。PDE（偏微分方程）有多个自变量（如时间 $t$ 与空间 $x$ 同时出现），导数变成**偏导数**。金属棒的温度 $u(t,x)$ 既随时间变、又在空间每个位置都不同——要同时描述"时间上的变化"和"空间上的分布"，必须用偏导数 $\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$。

**思路点拨**：判断口诀："一个自变量 → ODE，多个自变量 → PDE；普通导数 → ODE，偏导数 → PDE。" 记住温度函数 $u(t,x)$ 的两个参数——时间一个、空间一个——你就知道为什么热方程离不开偏导数。

## 二、计算实践

### 题 1（手算：离散复利）

100 元本金，年利率 10%（$r = 0.10$），每年复利一次。

(a) 写出离散动力系统的演化规则，并手算第 1、2、3 年的金额。
(b) 手算第 10 年的金额（可用计算器）。

**解答**：

(a) 演化规则 $x_{n+1} = (1 + 0.1) x_n = 1.1 x_n$。于是
$$x_1 = 1.1 \times 100 = 110,\quad x_2 = 1.1 \times 110 = 121,\quad x_3 = 1.1 \times 121 = 133.1$$

(b) $x_{10} = 100 \times 1.1^{10} \approx 100 \times 2.5937 = 259.37$。

**思路点拨**：这就是教材 §11.2.1.1 里种群增长 $x_{n+1} = 1.2x_n$ 的翻版——同一个模板，换个增长率。手算的关键是"一步一个脚印"，不要把 (a) 和 (b) 的记法弄混：$x_n$ 是第 $n$ 步的状态。

**NumPy 验证**：
```python
import numpy as np

x = 100.0
for n in range(1, 11):
    x = 1.1 * x
print("第10年:", round(x, 2), "  解析: 100*1.1^10 =", round(100 * 1.1**10, 2))
```
```
第10年: 259.37   解析: 100*1.1^10 = 259.37
```

### 题 2（手算 + 代码：连续版本与极限）

对同样的 100 元、年利率 10%、十年期，计算连续复利的结果。

(a) 连续动力系统 $\frac{dx}{dt} = 0.1x$ 的解析解是什么？十年后是多少？
(b) 若每年复利 $N$ 次，$N=12$ 时十年后是多少？与连续版差多少？（可用计算器或代码）

**解答**：

(a) 解为 $x(t) = 100 e^{0.1t}$，十年后 $x(10) = 100 e^{1} \approx 271.83$。

(b) 复利公式 $x = 100(1 + 0.1/12)^{120}$。$1 + 0.1/12 = 1.008333$，$1.008333^{120} \approx 2.70704$，故约 $270.70$。与连续版 $271.83$ 差约 $1.13$。

**NumPy 验证**：
```python
import numpy as np

print("连续版 e^{rT}      :", round(100 * np.exp(0.1 * 10), 4))
for N in [1, 12, 100000]:
    print(f"N = {N:>6d}   :", round(100 * (1 + 0.1 / N) ** (N * 10), 4))
```
```
连续版 e^{rT}      : 271.8282
N =      1   : 259.3742
N =     12   : 270.7041
N = 100000   : 271.8282
```

**思路点拨**：(a) 是"连续版的答案"——它比任何有限复利次数都高，因为多复利了无穷次。(b) 的表格是主线那台"拨旋钮"机器的复现：$N$ 从 1 到 10 万，金额一路逼近 $271.8282 = 100e$。记牢这个数字：**$e$ 是"复利间隔趋于零"的自然归宿**，它在动力系统和深度学习中反复现身（指数衰减、softmax、Neural ODE）。

### 题 3（手算：把 RNN 状态更新对号入座）

设隐藏状态 $h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t)$。请指出：状态空间、演化规则、初始条件、外部输入分别是什么？并用一句话说明它属于"离散"还是"连续"家族。

**解答**：状态空间 = $\mathbb{R}^{d_{hid}}$（所有可能的隐藏状态）；演化规则 = 整条递归式（给定 $h_{t-1}$ 与 $x_t$ 确定 $h_t$）；初始条件 = $h_0$；外部输入 = $x_t$。它属于**离散**动力系统家族——时间步 $t$ 是一格一格的，状态只在离散时刻被更新。

**思路点拨**：把主线的两根支柱"认领"到 RNN 上——这是 §11.3 的预习。判据很简单：时间轴是一格一格（$t$ 是整数下标）→ 离散。如果有人说"RNN 是连续的"，那是指它的**连续化极限**（CTRNN / Neural ODE），不是默认形态。

## 三、DL 延伸

### 题 1（Neural ODE：网络层是"流"还是"跳"？）

Neural ODE 把网络前向传播写成"解一个微分方程"：$\frac{dh}{d\tau} = f_\theta(h, \tau)$，输出是 $h(1) = h(0) + \int_0^1 f_\theta\, d\tau$。

(a) 和普通残差网络 $h_{k+1} = h_k + f_\theta(h_k)$ 相比，Neural ODE 的"演化规则"和"时间"各是什么？
(b) 为什么可以说"Neural ODE 是普通网络的一个连续化极限"？

**解答**：

(a) Neural ODE 的演化规则是微分方程本身：状态 $h(\tau)$ 的变化率由 $f_\theta$ 决定；"时间"是连续变量 $\tau$（从 0 到 1），它不再对应"第几层"，而是对应"网络的深度连续化了"。普通残差网络是它的离散近似：把 $\tau$ 切成单位步，$\frac{dh}{d\tau} \approx h_{k+1} - h_k$，就得到 $h_{k+1} = h_k + f_\theta(h_k)$。

(b) 残差网络每层推进一个"深度单位"，正是 Euler 方法以步长 1 去积分那条连续轨道。把步长改小、层数增多，就越来越接近真正的积分；Neural ODE 干脆直接用专业求解器积分，把"层数"从超参数变成求解器的容差。所以说：普通残差网络是步长取 1 的离散化，Neural ODE 是它的连续化极限——这是主线"离散与连续是同一变化的两副刻度"在模型结构上的复现。

**思路点拨**：这道题把 §11.2 的数学直接搬到 §11.1 提到的 Neural ODE 上。核心对应：**残差 = Euler 一步，层数 = 步数，Neural ODE = 精确积分**。如果你看懂了《代码.md》里 $N \to \infty$ 逼近 $e^{rT}$ 的过程，就明白 Neural ODE 在做什么——它把"网络的深度"从格子里解放了出来。

### 题 2（扩散模型：哪根支柱在幕后？）

扩散模型的加噪过程可以写成随机微分方程，其确定性部分形如 $\frac{\partial p}{\partial t} = \dots$，与热方程 $\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$ 同族。请判断：扩散模型的核心数学是 ODE 还是 PDE 的世界？为什么一个"图像生成"模型会和"热量扩散"共用同一个方程家族？

**解答**：**PDE 的世界**。扩散模型处理的不是单一数值随时间的演化，而是**整个概率分布在时间和"样本空间"上的演化**——$p(x, t)$ 既是时间的函数、又是所有可能样本 $x$ 上的函数，至少两个自变量，必然涉及偏导数。至于"为什么图像生成和热量扩散同族"：热方程描述的是"物质浓度/温度随时间向均匀扩散"，而扩散模型的加噪过程正是"把图像分布逐步向纯噪声稀释"——**扩散是"信息被抹平"的通用数学**。浓度被抹平是热传导，图像被抹平成噪声是扩散模型的加噪，同一族方程在两端站岗。

**思路点拨**：这道题考"判断 ODE 还是 PDE"的进阶应用。关键不是记模型名字，而是数自变量：$p(x,t)$ 有两个自变量（样本空间 + 时间），所以是 PDE 的地盘。这个判断法你在 §11.2.2.2 会反复用到——那节的热方程，就是这里扩散模型方程的"亲戚原版"。

**延伸预告**：§11.2.1.1 给离散动力系统完整的定义与轨道分析；§11.2.2.2 会把热方程亲手数值解出来——那时你回头看扩散模型，会认出它的血缘。
