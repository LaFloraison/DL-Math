## 第一步：Toy Model —— 两封电报

深夜，前线指挥所。通讯员小跑进来，递上两封电报，你说：念。

第一封："报告，今晚太阳将从东方升起。"

第二封："报告，敌军将于今夜发动总攻。"

同样是电报，同样花了一个字一个字的油墨，可你的心跳只被第二封拽动。第一封你听完就想把它揉掉——"这算什么情报？"第二封你却连夜调兵。

现在问一个"浅到可笑"的问题：**为什么同样长度的一条消息，一条没有分量，另一条却重得压手？**

你大概会说：因为第二件事实在"太意外了"。太阳照常升起，你早就知道，它不让你惊讶，也就不携带什么信息；敌军夜里偷袭，你之前一无所知，它让你猛地坐直——这一惊，就是信息的全部秘密。

闭上眼，把"信息"这个词从"电报""信件""话语"里剥离出来，它剩下的内核就是一句话：**信息，是事件带给你的惊讶程度。** 越不可能发生的事，一旦发生，带来的信息就越大。必然的事，信息为零——它不会改变你头脑里任何一笔账。

可是"惊讶程度"是个模糊的感觉。你能说"第二封电报的惊讶是第一封的十倍"吗？能说"敌军偷袭的惊讶是 6.3 个单位"吗？你拿起笔，想把"信息"量化成一个可以写进公式、可以加加减减的数——这才发现，手里什么工具都没有。

"信息"这个词人类用了几千年，从来没有人想过要给它一个单位、一把尺子。但这一章我们要做这件事。而这件事，将通往深度学习的每一个角落。

## 第二步：正式数学讲解

### 一、撞墙：信息需要一个单位，而直觉给不出

先问清楚：要给"信息"定一把尺子，这把尺子必须量出哪些东西？

你的直觉已经给出三个要求，现在把它们摆到桌上：

**要求一：必然的事，信息为零。** "太阳从东方升起"从不让你惊讶，它必须计 0。

**要求二：越不可能的事，信息越大。** 敌军偷袭（概率极小）比下雨（概率中等）携带的信息多。信息是概率的**减函数**。

**要求三：两件独立的事同时发生，信息要能相加。** 如果"敌军夜袭"和"敌军在北方突破"是两件独立的消息，那么"敌军夜袭且在北方突破"这一条合起来的消息，携带的信息应当等于两条分开的信息**加起来**。你想拆开几条就拆开几条，账不能乱——这是把"信息"当成可以度量的量的最低要求。

三个要求，听起来天经地义。现在请你用数学把它们写下来。

你翻遍已有的工具箱：线性函数？$I(p) = c(1-p)$ 满足要求二，但两个独立事件 $p_1, p_2$ 联合发生的概率是 $p_1 p_2$，信息要等于 $I(p_1) + I(p_2)$——于是必须有 $I(p_1 p_2) = I(p_1) + I(p_2)$。一个函数，输入相乘、输出相加——**只有对数函数**有这个性质：$\log(a b) = \log a + \log b$。再加一个负号让"越不可能越大"（$p$ 越小，$-\log p$ 越大），并且必然事件 $p=1$ 时 $-\log 1 = 0$——三个要求同时命中。

你甚至没有"设计"这个公式，你是被三条要求**逼**到它面前的。只要承认"信息可以度量、可以相加"，就逃不开对数。这就像当年有人发现"圆周长与直径的比值是个常数"——不是人规定的，是圆的几何**逼**出来的。

> **自信息 (self-information / surprisal)** $I(x)$
>
> 物理含义：观测到事件 $x$ 时收获的"惊讶量"——一条消息携带的信息，等于它的概率的负对数。
>
> $$I(x) = \log_b \frac{1}{P(x)} = -\log_b P(x)$$
>
> - $P(x)$：事件 $x$ 发生的概率，$0 < P(x) \le 1$
> - $b$：对数的底，决定"信息"的单位。$b = 2$ → 单位是**比特 (bit)**；$b = e$ → **纳特 (nat)**；$b = 10$ → **哈特利 (hartley / dit)**
> - 三条性质正是我们撞墙时的三句直觉：必然事件 $I = 0$；越不可能，$I$ 越大；独立事件联合，$I$ 相加

### 二、用具体数字试这把尺子

把教材掷硬币的例子搬进来，让这把尺子第一次量出真实的数。

**公平硬币**：$P(H) = P(T) = 0.5$。掷出正面带给你的信息：

$$I(H) = -\log_2 0.5 = -\log_2 2^{-1} = 1 \text{ bit}$$

掷出反面同样是 1 bit。一枚公平硬币的每一次结果，都值 1 比特。

**偏硬币**：$P(H) = 0.9, P(T) = 0.1$。掷出正面（意料之中）的信息：

$$I(H) = -\log_2 0.9 = -\log_2 \frac{9}{10} \approx 0.152 \text{ bits}$$

掷出反面（小概率）的信息：

$$I(T) = -\log_2 0.1 = \log_2 10 \approx 3.322 \text{ bits}$$

看这两个数字：正面才 0.152 比特，反面高达 3.322 比特——同样的硬币，不同的面，信息的价值差出二十多倍。这正是教材那段话的意思：**偏硬币大多数时候掷出正面，所以"又是正面"几乎不让你惊讶；而罕见的那次反面，让你真正抬头。** 用 bits 当单位，世界第一次把"惊讶"标上了刻度。

现在你试着回答下一个问题："那这枚**偏硬币整体**，平均每次掷出能给我多少信息？"你打算算一个平均值——可你立刻发现不对劲：0.152 和 3.322 哪个该当"平均"？正面出现的次数多，平均理该更靠近 0.152，可反面单次的信息大得多。要算出"平均每次掷币的信息"，得先想清楚用什么加权。这个问题暂时悬在这里——它是下一节"熵"要回答的。

### 三、边界声明：这把尺子量不了什么

自信息是个好起点，但它有明确的边界，先画清楚，免得后面翻车。

**第一，自信息是"这一次"的，不是"这个信源"的。** $I(H) = 0.152$ bits 说的是"某一次掷出正面收获多少信息"，它不能代表整枚硬币的性状。要衡量"这个信源平均多不确定"，必须把信源的所有可能结果按概率加权平均——那是熵 (entropy) 的定义，下一节的事。单条消息的惊讶，和整个信源的平均惊讶，是两把不同的尺子。

**第二，"信息量"不等于"意义"。** 自信息只依赖概率 $P(x)$，与消息的内容毫无关系。"敌军夜袭"和"明天会下雨"如果概率相同，信息量就相同——尽管一个关乎生死、一个只关乎晾衣。信息论刻意把"语义"扔到一边，只管"意外程度"。这让它强大（能统一处理电报、DNA、像素），也让它在面对"这句话重不重要"时沉默。语义不是信息论的领域。

**第三，单位随底数而变。** $\log_2$ 给出 bits，$\log_e$ 给出 nats——同一个事件，数值不同（$I = -\ln 0.1 = 2.303$ nats，而 $- \log_2 0.1 = 3.322$ bits）。写公式、看论文时必须先确认底数，否则数字对不上。比特是信息论里的默认单位，本章如无特别说明，一律 $\log_2$。

## 第三步：DL 桥接

这一节没有任何公式直接出现在神经网络里——但整个第六章铺的这条路，会在深度学习里掀起风暴。先用三句话把地图铺开，后面的每一节都会走到这张地图上：

**熵 (entropy) → 交叉熵损失。** 分类神经网络训练时的标准损失函数是交叉熵 (cross-entropy)。它衡量"模型输出的分布 $q$ 去编码真实标签分布 $p$ 需要的平均比特数"。当你看见 `loss = -log(model_output[correct_class])` 那一行代码时，你看见的就是 $-\log_2 q(\hat y)$——自信息的表亲。下一节讲完熵，你会立刻认出它。

**互信息 (mutual information) → 特征选择与表示学习。** 第六章后半会引入互信息，它告诉你两个变量共享多少信息。在深度学习中它是特征选择的铁律——选出与目标变量互信息最大的特征；也是 InfoGAN 等模型的设计动机。

**数据压缩 → 表示压缩。** 第六章末尾的数据压缩告诉你熵是压缩的下界。而现代表示学习的深层动机正是：神经网络把高维、冗余的原始数据（图像、文本）压成低维、信息浓密的潜表示 (latent representation)——模型是一台"语义压缩机"。
