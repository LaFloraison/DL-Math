# 代码：自信息——让 Python 替我们称量"惊讶"

主线里我们撞出了一把尺子：$I(x) = -\log_b P(x)$。这把尺子把"这条消息多让人惊讶"变成了一串可以计算的数字。现在把它写成函数，让 Python 替我们称量。

下面的脚本只做三件事：实现 `self_information`，在主线提到的几枚硬币上量出具体的信息量，然后验证"独立事件的信息相加"这条性质。全部只依赖标准库 `math`——信息论的一切起点，不需要任何第三方库。

---

## 层一：完整脚本

```python
import math                                   # math.log2 / math.log：对数的家

def self_information(p, base=2):              # ① 自信息：I = -log_base(p)
    """一条概率为 p 的消息携带的信息量（单位随 base 而定）。"""
    assert 0 < p <= 1.0, "概率必须在 (0, 1] 之间"
    return -math.log(p, base)

def joint_information(p1, p2, base=2):        # ② 两个独立事件同时发生的信息
    """独立事件 x、y 一起发生的信息 = 各自信息之和。"""
    return self_information(p1 * p2, base)    # P(x且y) = P(x)·P(y)，再取 -log

# ---- ① 主线里的那几枚硬币 ----
print(f"公平硬币 正面 I(H) = {self_information(0.5):.3f} bit")   # 期望 1 bit
print(f"偏硬币   正面 I(H) = {self_information(0.9):.3f} bits")  # 期望约 0.152
print(f"偏硬币   反面 I(T) = {self_information(0.1):.3f} bits")  # 期望约 3.322
print(f"必然事件      I   = {self_information(1.0) + 0.0:.3f} bit")  # 必然 = 0（+0.0 消掉 -0.0 的显示）

# ---- ② 换底：同一个事件，单位不同，数值不同 ----
print(f"反面(底10) I(T) = {self_information(0.1, base=10):.3f} hartley")  # 0.1 → 1 hartley
print(f"反面(底 e) I(T) = {self_information(0.1, base=math.e):.3f} nats")  # 0.1 → 约 2.303

# ---- ③ 独立事件的加法性：掷硬币且掷骰子掷出6 ----
I_h = self_information(0.5)                   # "硬币正面"的信息
I_6 = self_information(1 / 6)                 # "骰子掷出6"的信息
I_both = joint_information(0.5, 1 / 6)        # "正面 且 6"的信息
print(f"I(H) + I(6)   = {I_h + I_6:.3f} bits")
print(f"I(H且6)       = {I_both:.3f} bits")    # 应完全相等：信息相加

# ---- ④ 信息量随概率变化的曲线：p 越小，I 越大 ----
for p in [0.5, 0.1, 0.01, 0.001]:
    print(f"p = {p:<6} -> I = {self_information(p):.3f} bits")
```

运行输出（Python 3.11，标准库）：

```text
公平硬币 正面 I(H) = 1.000 bit   # 期望 1 bit
偏硬币   正面 I(H) = 0.152 bits  # 期望约 0.152
偏硬币   反面 I(T) = 3.322 bits  # 期望约 3.322
必然事件      I   = 0.000 bit    # 必然 = 0
反面(底10) I(T) = 1.000 hartley  # 0.1 → 1 hartley
反面(底 e) I(T) = 2.303 nats     # 0.1 → 约 2.303
I(H) + I(6)   = 3.585 bits
I(H且6)       = 3.585 bits       # 应完全相等：信息相加
p = 0.5    -> I = 1.000 bits
p = 0.1    -> I = 3.322 bits
p = 0.01   -> I = 6.644 bits
p = 0.001  -> I = 9.966 bits
```

主线里那几枚硬币，被 Python 一五一十地称了出来。下面把每一行拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 `math` —— 对数的家

```python
import math
```

#### `import math` —— 引入标准库的数学函数

**操作**：把 Python 标准库 `math` 加载进来，之后可以调用 `math.log`、`math.log2`、`math.e`。
**输入**：无。
**输出**：`math` 模块句柄。
**可调参数**：无。也可以用 `from math import log` 直接导入函数（少打几个字，代价是把 `log` 的名字占掉）；用 `math.log` 全限定写法更清晰，本脚本采用后者。
**对应数学**：这一行不直接对应公式，它提供公式的原料——对数 $\log_b$。

---

### 步骤 2：定义 `self_information` —— 那把称量惊讶的尺子

```python
def self_information(p, base=2):
    """一条概率为 p 的消息携带的信息量（单位随 base 而定）。"""
    assert 0 < p <= 1.0, "概率必须在 (0, 1] 之间"
    return -math.log(p, base)
```

#### `self_information(p, base)` —— 自信息：$I = -\log_b p$

**做什么**：给定事件的概率 $p$ 和对数底 `base`，返回该事件的自信息 $-\log_b p$。
**操作**：`-math.log(p, base)` 计算 $-\log_{\text{base}}(p)$。`assert` 先拦下非法输入——$p$ 必须落在 $(0, 1]$，概率为 0 的事件取对数会炸（$\log 0$ 无定义，负无穷），概率大于 1 是荒谬的。这就是主线边界声明"$0 < P(x) \le 1$"在代码里的化身。
**输入**：
- `p`：事件概率，标量（float）。例如公平硬币正面 `0.5`，偏硬币反面 `0.1`，必然事件 `1.0`。
- `base`：对数底，标量（int 或 float），**默认 2**。决定信息量的单位。
**输出**：一个标量，该事件的自信息。$p$ 越接近 0，输出越大；$p = 1$ 时输出恰好 0。
**可调参数**：
- `base=2` → 单位是**比特 (bit)**，信息论默认单位。教材和本章如无特别说明都用它。
- `base=math.e`（自然对数）→ 单位是**纳特 (nat)**。深度学习文献（如变分推断、信息瓶颈）里经常用 nats，因为自然对数的导数里没有 $\ln 2$ 这个因子，数学上更顺。
- `base=10` → 单位是**哈特利 (hartley / dit)**。香农早期的合作者 Ralph Hartley 1928 年就用底 10 的对数度量信息。
- 能不能加第四个参数？`p, base` 已完备——自信息就两个自由度：事件概率和对数底。可以再包一层 `def bits(p): return self_information(p, 2)` 之类的语法糖，但那是调用约定，不是新参数。
**对应数学**：主线定义块里的 $I(x) = -\log_b P(x)$，逐符号翻译。注意 Python 的 `math.log(x, base)` 两个参数就是 $\log_{\text{base}} x$，与数学记法 $\log_b x$ 的顺序相同。

---

### 步骤 3：定义 `joint_information` —— 独立事件的加法性

```python
def joint_information(p1, p2, base=2):
    """独立事件 x、y 一起发生的信息 = 各自信息之和。"""
    return self_information(p1 * p2, base)    # P(x且y) = P(x)·P(y)，再取 -log
```

#### `joint_information(p1, p2, base)` —— 两独立事件同时发生的信息

**做什么**：给定两个独立事件的概率 $p_1, p_2$，返回"两件事同时发生"的自信息。
**操作**：**没有调用两次 `self_information` 再相加**——而是先算联合概率 $p_1 \times p_2$，再对联合概率取一次 $-\log$。为什么？因为对数有魔法性质：$-\log(p_1 p_2) = -\log p_1 - \log p_2$。所以 `self_information(p1 * p2)` **数学上恒等于** `self_information(p1) + self_information(p2)`。脚本第 ③ 段打印两行数字，就是为了让这个恒等式在输出里亲眼对上。
**输入**：
- `p1`：事件 1 的概率，标量。
- `p2`：事件 2 的概率，标量。
- `base`：对数底，默认 2。
**输出**：标量，"两件事同时发生"的自信息。
**可调参数**：`base` 与 `self_information` 一致。能不能有第三个概率？能——联合概率连乘 $p_1 p_2 p_3$，对数组化或多事件版本，可以把 `*p_list` 展开（`self_information(math.prod(p_list))`）。本脚本只需两个，够验证性质即可。
**对应数学**：主线里的要求三——"两件独立的事同时发生，信息要相加"。这里的关键是**独立**：只有独立事件才满足 $P(x \cap y) = P(x)P(y)$。如果事件不独立（比如"下雨"和"带伞"），联合概率就不是简单相乘，这条性质不成立——这正是第 6.3 节"联合熵"的伏笔。

---

### 步骤 4：打印那几枚硬币的信息量

```python
print(f"公平硬币 正面 I(H) = {self_information(0.5):.3f} bit")
```

**做什么**：把主线里手算的数字交给函数复核。`.3f` 把结果格式化为保留 3 位小数。
**操作**：f-string（`f"..."`）里 `{self_information(0.5):.3f}` 先调用函数，再把返回值格式化成字符串嵌入文本。
**输入**：一串 `self_information` 调用，各传一个代表某个硬币面的概率。
**输出**：四行文本，例如 `公平硬币 正面 I(H) = 1.000 bit`。
**可调参数**：想称量别的概率，直接改实参——比如 `self_information(0.99)`（几乎必然的消息，信息只有 0.014 bits）或 `self_information(0.0001)`（万分之一的消息，约 13.29 bits）。
**对应数学**：每次打印就是一次 $I(x) = -\log_2 p$ 的代入。0.152 和 3.322 这两个数字与主线手算完全一致——偏硬币正面 0.152 bits、反面 3.322 bits，差出二十多倍，正是"越不可能信息越大"在具体数字上的体现。

---

### 步骤 5：换底数 —— 单位不同，数值不同

```python
print(f"反面(底10) I(T) = {self_information(0.1, base=10):.3f} hartley")
print(f"反面(底 e) I(T) = {self_information(0.1, base=math.e):.3f} nats")
```

**做什么**：对**同一个事件**（$p = 0.1$）用三个不同的底数称量，看数值如何随单位变化。
**操作**：传 `base` 关键字参数改变对数底；`math.e` 就是自然常数 $e$。
**输入**：同一个概率 `0.1`，两个不同的 `base`。
**输出**：两行。底 10 → `1.000 hartley`（因为 $0.1 = 10^{-1}$，$-\log_{10} 0.1 = 1$）；底 $e$ → `2.303 nats`（$-\ln 0.1 = 2.303$）。
**可调参数**：把 `0.1` 换成任何概率，三个底数的输出随之变化，但**彼此恒成固定比例**——$\text{bits} = \text{nats} / \ln 2 \approx \text{nats} \times 1.443$。这是因为换底公式 $\log_b p = \frac{\ln p}{\ln b}$ 只差一个常数因子。所以你从一篇用 nats 的论文换算成比特时，心里要有一个 $\times 1.443$。
**对应数学**：主线边界声明第三条——"单位随底数而变"。同一个事件的信息是同一个物理量，只是用不同刻度的尺子量，读数不同。比特、纳特、哈特利，是同一把尺子的三种刻度。

### 步骤 6：验证加法性 —— 信息真的能相加

```python
I_h = self_information(0.5)
I_6 = self_information(1 / 6)
I_both = joint_information(0.5, 1 / 6)
print(f"I(H) + I(6)   = {I_h + I_6:.3f} bits")
print(f"I(H且6)       = {I_both:.3f} bits")
```

**做什么**：掷硬币且掷骰子掷出 6——两个独立事件。比较"分别称量再相加"与"对联合事件直接称量"。
**操作**：`I_h + I_6` 是各自自信息相加；`joint_information(0.5, 1/6)` 是对联合概率 $0.5 \times \frac{1}{6} = \frac{1}{12}$ 取一次 $-\log_2$。
**输入**：`0.5`（硬币正面概率）、`1/6`（骰子掷出 6 的概率）。
**输出**：两行都打印 `3.585 bits`——因为 $-\log_2 \frac{1}{12} = \log_2 12 \approx 3.585$，而 $-\log_2 0.5 + (-\log_2 \frac{1}{6}) = 1 + 2.585 = 3.585$。两条路线，殊途同归。
**可调参数**：换任何一对独立概率都可以验证。但注意：**如果你换成的两个事件不独立**（比如"下雨"概率 0.3 和"带伞"概率 0.5，而两者强相关），`joint_information` 里的 `p1 * p2` 就不是真的联合概率，两条路线就对不上了——这正好预示了 6.3 节的联合熵。
**对应数学**：主线要求三——$\log(ab) = \log a + \log b$，两个独立事件的信息可加。这是"信息可以度量"的最低要求，也是 6.2 节熵的定义里"加权平均"能成立的根基。

## 改个数字试试：把概率推向极端

这把尺子的"性格"，在极端概率下最清晰。

### 实验 1：几乎必然的消息，几乎为零

```python
print(f"p = 0.999  -> I = {self_information(0.999):.3f} bits")   # 几乎必然，几乎没信息
print(f"p = 0.5    -> I = {self_information(0.5):.3f} bits")
print(f"p = 0.001  -> I = {self_information(0.001):.3f} bits")   # 千分之一，近 10 bits
```

输出：

```text
p = 0.999  -> I = 0.001 bits
p = 0.5    -> I = 1.000 bits
p = 0.001  -> I = 9.966 bits
```

$p$ 从 0.999 到 0.001，信息量从 0.001 到 9.966——横跨四个数量级。**概率每缩小 10 倍，信息量增加约 3.32 bits**（因为 $-\log_2 10 \approx 3.322$）。这条"每除以 10 加 3.32 bits"的规律，就是比特的自然标尺：一位二进制数恰好能区分两种等可能情况（1 bit），四位能区分 16 种（4 bits）。

### 实验 2：一条消息值多少比特，取决于你把世界切成几份

```python
print(f"四选一    I = {self_information(0.25):.3f} bits")   # 1/4 → 2 bits
print(f"八选一    I = {self_information(1/8):.3f} bits")    # 1/8 → 3 bits
print(f"1024选一  I = {self_information(1/1024):.3f} bits") # 1/1024 → 10 bits
```

输出：

```text
四选一    I = 2.000 bits
八选一    I = 3.000 bits
1024选一  I = 10.000 bits
```

等可能的 $n$ 选一，信息恰好 $\log_2 n$ bits。这给了比特一个更具体的画面：**一条"从 1024 种等可能情况里指出了 1 种"的消息，等价于 10 个二进制的 0/1 提问。** 信息量 = 把不确定性消掉的难度。这个视角，下一节熵的定义里会用得更狠。

## 边界声明：这套代码能做什么，不能做什么

1. **`p` 必须严格大于 0**。概率为 0 的事件 $-\log 0 = +\infty$——它真的发生时携带"无穷大"的信息。数学上可以这么写（震惊世界的事件），代码里必须拦下来：`assert 0 < p <= 1.0` 会在你误传 0 时直接报错，而不是算出个 `inf` 悄悄溜过去。这条边界也呼应主线：信息论研究概率非零的事件，必然事件信息为零，不可能事件信息无穷。
2. **自信息是"单条消息"的读数，不是信源的平均。** 脚本里 `self_information(0.9) = 0.152` 是"某次掷出正面"的信息，它**不能**用来回答"这枚偏硬币平均每次掷出多少信息"。要回答后者，必须把 0.152 和 3.322 按各自出现概率加权平均——那是熵，下一节的函数 `entropy()` 的事。别把单条惊讶当成信源性状。
3. **"信息量"与"重要性"是两回事。** 这把尺子量的是概率，不量意义。`self_information(0.001)` 会把"明天太阳从西边升起"（概率极小）称出近 10 bits，也会把"敌军夜袭"（同样概率极小）称出同样的 10 bits——尽管一个荒诞、一个攸关生死。信息论故意对此沉默，这是它的边界，也是它的力量：不看内容，只看意外。
