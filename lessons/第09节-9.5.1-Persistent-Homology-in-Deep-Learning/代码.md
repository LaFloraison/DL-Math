# 代码：把"圆形 vs 方形"做成持久同调特征，再数一数损失地形的坑

本节代码是第 09 章的收官实验——把教材 §9.5.1 的两个应用亲手做出来：

**应用一：五步管线（圆形 vs 方形）**。数据集 A 是单位圆上 8 个等距点（有环形结构），数据集 B 是单位方内 8 个随机点（无结构）。走完教材五步：距离矩阵 → Vietoris–Rips 复形 → Betti 数 → 持久图 → 特征向量（环的持久性）。**结论：圆 ≈ 1.08，方 ≈ 0.14——一个数字分开两类。**

**应用二：损失地形数坑**。把"损失函数有几个局部极小（坑）"算出来——光滑地形 1 个坑，崎岖地形 6 个坑。这就是"损失地形分析"的雏形：**坑越多，优化越难。**

脚本复用 §9.4.1 的持久同调实现，只依赖标准库 `math` + NumPy。

## 层一：完整脚本

```python
import numpy as np, math

def dist(a, b): return math.hypot(a[0]-b[0], a[1]-b[1])

# ---- 复用 §9.4.1：持久 H1（此处略去完整实现，见 §9.4.1 代码.md）----
def ph1(points): ...        # 返回 (出生, 死亡) 对列表（环）

def loop_persistence(points):
    """特征向量第 1 维：环的最大持久性 = max(death - birth)。"""
    h1 = ph1(points)
    return max((d - b for b, d in h1 if d != float('inf')), default=0.0)

def betti_at(points, eps):
    """Step 2-3：在单个阈值 eps 下，数 (β0, β1)。"""
    n = len(points)
    edges = [(i,j) for i in range(n) for j in range(i+1,n)
             if dist(points[i], points[j]) <= eps]
    eset = set(edges)
    tris = [(i,j,k) for (i,j) in edges for k in range(j+1,n)
            if (i,k) in eset and (j,k) in eset]
    parent = list(range(n))
    def find(a):
        while parent[a] != a: parent[a] = parent[parent[a]]; a = parent[a]
        return a
    for i, j in edges:
        ra, rb = find(i), find(j)
        if ra != rb: parent[ra] = rb
    beta0 = len({find(i) for i in range(n)})
    E = len(edges)
    M = [[0]*len(tris) for _ in range(E)]
    col = {e: c for c, e in enumerate(edges)}
    for c, (i,j,k) in enumerate(tris):
        for e in ((i,j),(i,k),(j,k)): M[col[e]][c] ^= 1
    pr = 0
    for cc in range(len(tris)):
        r = next((rr for rr in range(pr, E) if M[rr][cc]), None)
        if r is None: continue
        M[r], M[pr] = M[pr], M[r]
        for rr in range(pr+1, E):
            if M[rr][cc]:
                for c2 in range(cc, len(tris)): M[rr][c2] ^= M[pr][c2]
        pr += 1
    return beta0, E - n + beta0 - pr

# ---- 数据集 A（圆）与 B（方）----
s2 = math.sqrt(2)/2
A = [(1,0),(s2,s2),(0,1),(-s2,s2),(-1,0),(-s2,-s2),(0,-1),(s2,-s2)]
B = [(0.1,0.9),(0.4,0.7),(0.6,0.2),(0.9,0.4),(0.3,0.5),(0.7,0.8),(0.5,0.1),(0.2,0.6)]

print("=== Step 2-3：Betti 数随阈值 ε 的变化 ===")
for name, P in (("圆 A", A), ("方 B", B)):
    print(f"{name}: ε=0.5→{betti_at(P,0.5)}  ε=0.8→{betti_at(P,0.8)}  "
          f"ε=1.0→{betti_at(P,1.0)}  ε=1.5→{betti_at(P,1.5)}  ε=1.9→{betti_at(P,1.9)}")

print("\n=== Step 4-5：环的持久性（拓扑特征向量）===")
print(f"圆 A 环的持久性 = {loop_persistence(A):.3f}")
print(f"方 B 环的持久性 = {loop_persistence(B):.3f}")

print("\n=== 应用二：损失地形数坑 ===")
def count_pits(loss_fn, N=100, lo=-4, hi=4):
    xs = np.linspace(lo, hi, N)
    X, Y = np.meshgrid(xs, xs)
    L = loss_fn(X, Y)
    pits = 0
    for r in range(1, N-1):
        for c in range(1, N-1):
            v = L[r,c]
            if v <= L[r-1,c] and v <= L[r+1,c] and v <= L[r,c-1] and v <= L[r,c+1]:
                pits += 1
    return pits

smooth = lambda x, y: x*x + y*y
rugged = lambda x, y: (x*x+y*y)/10 + 0.5*np.cos(2*x) + 0.5*np.sin(2*y)
print(f"光滑地形（碗状）：{count_pits(smooth)} 个局部极小（好优化）")
print(f"崎岖地形（多坑）：{count_pits(rugged)} 个局部极小（难优化）")
```

读这组输出，教材 §9.5.1 的五步管线全部落地：

- **Step 2-3（Betti 变化）**：圆 A 在 ε=0.5 时 8 点全孤立（8,0），ε=0.8 时连成 1 块带 1 环（1,1），这个环一直活到 ε=1.5 仍然存在（1,1），到 ε=1.9 才被填实（1,0）——**环在 0.8 到 1.9 之间都活着**。方 B 在 ε=0.5 时有一个环（1,1），但 ε=0.8 就死了（1,0）——**出生即死的噪声环**。
- **Step 4-5（特征向量）**：圆 A 环持久性 **1.082**，方 B **0.136**——设阈值 0.5，两类零误差分离。这就是能喂给分类器的拓扑特征。
- **应用二（数坑）**：光滑地形 1 个坑、崎岖地形 6 个坑——**坑数就是优化难度的拓扑签名**。

## 层二：分步逐函数拆解

### 步骤 1：`loop_persistence` —— 特征向量的核心维度

```python
def loop_persistence(points):
    h1 = ph1(points)
    return max((d - b for b, d in h1 if d != float('inf')), default=0.0)
```

#### `loop_persistence` —— 环的最大持久性

**做什么**：对 `ph1` 返回的每个环 `(birth, death)`，取 `death - birth` 的最大值——即"最持久的环活过多少尺度"。
**操作**：`max(...)` 遍历所有环；`d != float('inf')` 排除永远不会死的环；`default=0.0` 处理"一个环都没有"的情形。
**输入**：`points` 点云。
**输出**：一个浮点数——该点云的"环形结构强度"。
**可调参数**：把 `max` 换成"前 k 个持久性的和"或"持久性分布的平均/方差"，可得到更丰富的特征向量——但本实验 `max` 一个数字就足够分离圆与方，说明**核心判别信号极其干净**。
**对应数学**：教材 Step 5 的"拓扑特征向量"。圆 = 1.082（有一个长命环）、方 = 0.136（只有短命环）——**这个数字是分类器可以直接消费的结构信号**。

### 步骤 2：`betti_at` —— Step 2-3 的单阈值快照

```python
def betti_at(points, eps):
    n = len(points)
    edges = [(i,j) for i in range(n) for j in range(i+1,n)
             if dist(points[i], points[j]) <= eps]
    ...
    return beta0, E - n + beta0 - pr
```

**做什么**：在给定阈值 `eps` 下，构造 Vietoris–Rips 复形并返回 $(\beta_0, \beta_1)$。这是 §9.2.1 同调机器在"一个尺度"下的快照——`ph1` 把它在"所有尺度"下跑一遍才得到持久性。
**操作**：`edges` 取距离 $\le$ eps 的点对、`tris` 补三角形；并查集算 $\beta_0$；模 2 高斯消元算 $\mathrm{rank}(\partial_2)$；$\beta_1 = E - V + \beta_0 - \mathrm{rank}(\partial_2)$。
**输入**：`points`、`eps`。
**输出**：`(β0, β1)` 元组。
**可调参数**：`eps` 的取值序列（0.5/0.8/1.0/1.5/1.9）就是过滤的"抽样"——这正是教材 Step 2 的"选取几个 ε 值观察变化"。
**对应数学**：教材 Step 3 的 Betti 数轨迹。圆 A 的 `(8,0)→(1,1)→(1,1)→(1,0)` 就是"环出生 → 活着 → 被填实"的完整生命史；方 B 的 `(1,1)→(1,0)` 是"环出生即死"。

**操作**：A 用极坐标 $(\cos 2\pi k/8, \sin 2\pi k/8)$ 精确生成（`s2 = √2/2`）；B 用教材给定的 8 个坐标。
**输入**：无。

**可调参数**：A 的采样数改成 16，环形特征更精确；B 换一组随机点（保持单位方内），噪声环的持久性仍在 0.2 以下——**"方无持久环"是稳健规律**。
**对应数学**：教材 Step 1 的距离矩阵 $D_A, D_B$ 的来源（§9.4.1 代码已印过 $D_A$ 的 8×8 矩阵：主对角 0、相邻 0.765、对角 1.414、跨度 3 步 1.848、直径 2.0）。

### 步骤 4：`count_pits` —— 损失地形数坑

```python
def count_pits(loss_fn, N=100, lo=-4, hi=4):
    xs = np.linspace(lo, hi, N)
    X, Y = np.meshgrid(xs, xs)
    L = loss_fn(X, Y)
    pits = 0
    for r in range(1, N-1):
        for c in range(1, N-1):
            v = L[r,c]
            if v <= L[r-1,c] and v <= L[r+1,c] and v <= L[r,c-1] and v <= L[r,c+1]:
                pits += 1
    return pits
```

#### `count_pits` —— 网格上的局部极小计数

**做什么**：把损失函数在二维网格上求值，数出"比上下左右四个邻居都小"的格子——每个这样的格子是一个**局部极小（坑）**。
**操作**：`meshgrid` 铺网格、`loss_fn` 逐点求值；双循环对每个内部格子检查 `v <= L[r±1,c]` 与 `v <= L[r,c±1]` 四个条件。
**输入**：`loss_fn`（损失函数）、`N`（网格密度）、`lo/hi`（采样范围）。
**输出**：整数——局部极小的个数。
**可调参数**：`N` 越大坑数越精确（但要小心噪声尖峰）；`loss_fn` 换成真实网络的损失采样（在参数空间随机取点算损失）就得到"真实损失地形的坑数"——本实验用合成函数演示机制。
**对应数学**：这就是"损失地形分析"的雏形——教材说"持久同调数损失函数有多少低点与鞍点"。坑数 = $\beta_0$ 在"低水平集"上的持久分量数（这里用网格差分近似）；**坑越多，优化越容易困住**。

## 边界声明：这套代码能做什么，不能做什么

1. **它算的是玩具规模，不是真实网络的损失地形**。真实损失函数定义在几十万维的参数空间，无法网格化——需要随机采样 + 子水平集持久同调（更重的计算），且"坑数"要与随机性做统计检验。本节的 `count_pits` 演示机制，不是生产级工具。
2. **"环的持久性 1.08 vs 0.14"是特定数据集的数值**。换噪声幅度、点数、尺度范围，数值会漂移；但"圆形有持久环、随机点没有"的**定性结论**稳健（§9.5 代码已用 4 个随机种子验证）。**特征提取的数值需要结合任务验证，不能直接搬用。**
3. **"环的持久性"不是"分类的唯一依据"**。真实任务里它只是众多特征之一；且计算持久同调仍昂贵、尺度参数仍敏感（教材 §9.5.1 的工程顾虑全部适用）。本节是第 09 章的"收官演示"——**证明结构之眼值得装，但安装它要付计算与调参的代价。**
