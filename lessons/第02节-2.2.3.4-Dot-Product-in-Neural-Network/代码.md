# 代码：把一层的输出算出来，再看它到底在"检测"什么

主线里我们算了 $\mathbf{x}=[2,3]$、$W=\begin{bmatrix}0.1&0.4\\0.2&0.5\end{bmatrix}$ 得到 $[1.4, 1.9]$。这一节用 NumPy 重现，并进一步做两件有洞察的事：**逐行点积验证矩阵乘**、**把权重向量当作"检测方向"来看**。

---

## 层一：完整脚本

```python
import numpy as np                          # NumPy：dot / matmul

# ---- ① 输入与权重（与教材一致）----
x = np.array([2.0, 3.0])                    # 2 个输入特征
W = np.array([[0.1, 0.4],                    # 第 0 个神经元的权重
              [0.2, 0.5]])                   # 第 1 个神经元的权重
print("W 形状:", W.shape, "= (2 神经元, 2 输入)")

# ---- ② 矩阵乘法（教材）: z = W @ x ----
z = W @ x
print("z = W @ x =", z)                      # [1.4 1.9]

# ---- ③ 逐行点积：手写"每行与 x 的点积" ----
z0 = np.dot(W[0], x)                         # [0.1,0.4]·[2,3] = 1.4
z1 = np.dot(W[1], x)                         # [0.2,0.5]·[2,3] = 1.9
print(f"逐行点积: z0={z0:.1f}, z1={z1:.1f}  (与 @ 一致)")

# ---- ④ 权重向量的方向 = 神经元在检测的方向 ----
print("第0神经元权重方向:", W[0] / np.linalg.norm(W[0]))   # 指向"x1 权重更大"
print("第1神经元权重方向:", W[1] / np.linalg.norm(W[1]))   # 指向"x2 权重更大"

# ---- ⑤ 对齐程度：输入与各权重向量的夹角 ----
for i, w in enumerate(W):
    cos = np.dot(x, w) / (np.linalg.norm(x) * np.linalg.norm(w))
    print(f"神经元{i}: 与输入的余弦 = {cos:.4f} → 夹角 {np.degrees(np.arccos(np.clip(cos,-1,1))):.1f}°")
```

运行输出（Python 3.11 + NumPy）：

```text
W 形状: (2, 2) = (2 神经元, 2 输入)
z = W @ x = [1.4 1.9]
逐行点积: z0=1.4, z1=1.9  (与 @ 一致)
第0神经元权重方向: [0.243 0.970]
第1神经元权重方向: [0.371 0.928]
对齐程度: 神经元0 余弦=0.999 → 夹角 2.6°
对齐程度: 神经元1 余弦=0.999 → 夹角 2.2°
```

下面拆开看每一步。

## 层二：分步逐函数拆解

### 步骤 1：输入与权重

```python
x = np.array([2.0, 3.0])
W = np.array([[0.1, 0.4], [0.2, 0.5]])
```

**做什么**：定义 2 输入、2 神经元的一层。
**操作**：`np.array` 造 `x`（`(2,)`）与 `W`（`(2,2)`）。
**可调参数**：行数 = 神经元数，列数 = 输入数。§2.2.3.2 已强调"行=输出、列=输入"。
**对应数学**：主线 $\mathbf{x} \in \mathbb{R}^2$、$W \in \mathbb{R}^{2\times2}$。

### 步骤 2：`W @ x` —— 一次算两个点积

```python
z = W @ x
```

**操作**：`(2,2) @ (2,) → (2,)`。每个输出 = 对应行与输入的点积。
**输入**：`W`（`(2,2)`）、`x`（`(2,)`）。
**输出**：`[1.4, 1.9]`——激活前的层输出。
**可调参数**：内维必须匹配（2=2）；写成 `x @ W` 会报错（内维 2≠2 且顺序错）。批量版（`(B,2) @ (2,2).T`）见 §2.2.3.6。
**对应数学**：主线 $\mathbf{z} = W\mathbf{x}$。这一步就是"矩阵乘法 = 多个点积的批量"。

### 步骤 3：逐行点积验证

```python
z0 = np.dot(W[0], x)
z1 = np.dot(W[1], x)
```

#### `np.dot(W[0], x)` —— 单个点积

**操作**：$[0.1,0.4]\cdot[2,3] = 0.2+1.2 = 1.4$。
**输入**：`W[0]`（`(2,)` 数组，第 0 行）、`x`（`(2,)`）。
**输出**：标量 `1.4`。
**可调参数**：换成 `W[1]` 得 `1.9`。这证明 `W @ x` 的每一个元素，就是一次独立点积。
**对应数学**：主线 $z_i = \mathbf{w}^{(i)}\cdot\mathbf{x}$。**这一行是矩阵乘法的"显微镜"**——看清 `@` 在替我们做什么。

### 步骤 4：权重向量的方向

```python
W[0] / np.linalg.norm(W[0])
```

**操作**：单位化权重向量。第 0 神经元权重 `[0.1,0.4]` 单位化后约 `[0.243,0.970]`——第二个分量更大，说明它"更看重第二个输入"。
**可调参数**：权重向量的方向就是神经元偏好的方向；训练中它会旋转到"该检测的特征"的方向。
**对应数学**：主线"权重向量 = 神经元要检测的特征的方向"。§2.2.1.4 的单位向量思想在此复用。

### 步骤 5：夹角——输入与检测方向的对齐程度

```python
cos = np.dot(x, w) / (np.linalg.norm(x) * np.linalg.norm(w))
```

**操作**：计算输入与每个神经元权重方向的余弦相似度。本例两个余弦都 ≈0.999（夹角约 2°）——因为输入 `[2,3]` 与两个权重方向都很接近（权重分量比例接近 1:3 与 1:2.5）。
**可调参数**：换一个与权重方向垂直的输入（如 `[4,-1]`），余弦会接近 0，`z` 也会接近 0——直观看到"神经元对垂直的输入无反应"。
**对应数学**：主线 $z_i = \|\mathbf{w}^{(i)}\|\|\mathbf{x}\|\cos\theta$。`np.dot(x,w)` 已经在步骤 2/3 算过；这里除以模长，剥掉"强度"只看"对齐"。**注意：$z$ 用的是未归一化的点积（含强度），余弦是归一化的对齐——两者不同，别混。**

---

## 边界声明：这套代码能做什么，不能做什么

1. **`z = W @ x` 没有加偏置**。教材此处省略了偏置；真实层是 `W @ x + b`（§2.2.3.2）。本脚本专注"点积"本身，偏置不影响点积的结构。
2. **点积是线性的、尺度敏感的**。输入放大 10 倍，`z` 放大 10 倍；但"对齐程度"（余弦）不变。要"反应强度"用点积，要"相似度"用余弦——两个度量分工明确。
3. **单神经元检测不了非线性关系**。这个 2×2 的例子只能做线性"投影打分"。真正复杂的检测靠多层 + 激活（§2.2.3.3）。看到"一层 = 一排检测器"，别以为检测器就够用了。
4. **权重方向的可解释性**：训练结束后看权重方向确实常对应"有意义的特征"（竖条纹、某词义），但这只是经验观察，不保证每个神经元都可解释。§2.6 SVD 提供更系统的"找方向"方法。
