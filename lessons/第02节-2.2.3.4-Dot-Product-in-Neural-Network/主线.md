## 第一步：Toy Model —— 一个裁判打分的秘密

一场体操比赛，裁判给选手打综合分。不是直接给一个数，而是先给 5 个小分（难度、完成度、艺术性、落地、编排），再按"权重"加权求和。假如选手小分是 $[2, 3]$，两个项目权重是 $0.4$ 和 $0.5$，那么综合分：

$$2 \times 0.4 + 3 \times 0.5 = 0.8 + 1.5 = 2.3$$

这个"对应相乘、再加总"的动作，就是**点积 (dot product)**——它的含义是"两列数字的加权融合"。裁判把"选手的表现"和"自己的重视程度"点积在一起，得到"总分"。

现在把镜头切到神经网络。一个神经元在做的事，和裁判一模一样：**输入向量是"选手的表现"，权重向量是"这个神经元的重视程度"，点积就是"这个神经元对输入的反应分"。** 一个神经元 = 一个有自己的"评分权重"的裁判；一层神经元 = 一排持有不同"评分标准"的裁判，各自对同一份输入打出自己的分。

这节要回答的问题是：为什么"点积"恰好是神经网络的核心运算？它凭什么同时完成了"打分"和"信息融合"两件事？

## 第二步：正式数学讲解

### 一、撞墙：一层网络的两个输出，怎么同时算？

教材例子：输入 $\mathbf{x} = [2, 3]$，一层有两个神经元，权重矩阵：

$$W = \begin{bmatrix} 0.1 & 0.4 \\ 0.2 & 0.5 \end{bmatrix}$$

（第 0 行是第 0 个神经元的权重，第 1 行是第 1 个神经元的权重。）

第一个神经元：$z_0 = 0.1\times2 + 0.4\times3 = 0.2 + 1.2 = 1.4$。
第二个神经元：$z_1 = 0.2\times2 + 0.5\times3 = 0.4 + 1.5 = 1.9$。

合并写成：$\mathbf{z} = W\mathbf{x} = [1.4, 1.9]$。

**你看到了什么？** 两个输出，分别就是**输入 $\mathbf{x}$ 与 $W$ 的第 0 行、第 1 行的点积**。矩阵乘法的"一行 × 向量"就是在算一次点积。**矩阵乘法不是新的运算——它是一次性算多个点积。**

> **神经网络中的点积**
>
> $\mathbf{z} = W\mathbf{x}$，其中第 $i$ 个输出：$z_i = \mathbf{w}^{(i)} \cdot \mathbf{x} = \sum_j W_{ij} x_j$
>
> - $\mathbf{w}^{(i)}$：$W$ 的第 $i$ 行——第 $i$ 个神经元的权重向量
> - $z_i$：第 $i$ 个神经元对输入 $\mathbf{x}$ 的"反应分"
> - 物理含义：**输入与权重越"对齐"，$z_i$ 越大**——神经元在检测"输入里有没有它想要的那种模式"

### 二、展开：点积到底在检测什么？

把 $z_i = \mathbf{w}^{(i)}\cdot\mathbf{x}$ 用 §2.2.1.4 的几何语言打开：

$$z_i = \|\mathbf{w}^{(i)}\|\,\|\mathbf{x}\|\cos\theta$$

- 当输入 $\mathbf{x}$ 与权重 $\mathbf{w}^{(i)}$ **同向**（$\theta \approx 0$）：$z_i$ 取到最大值——神经元强烈激活，因为输入"正中它下怀"。
- 当两者**垂直**（$\theta \approx 90°$）：$z_i \approx 0$——神经元无反应。
- 当两者**相反**：$z_i$ 为负——神经元被抑制。

所以**权重向量就是"这个神经元要检测的特征的方向"**。训练一个神经元，本质就是反复调整 $\mathbf{w}^{(i)}$，让它指向"该响应的那种输入模式"。训练结束后，你去看某个神经元的权重向量，会发现它指向了数据里一个有意义的方向（比如"检测竖条纹"）——**点积，就是那个"指向性检测器"。**

### 三、信息融合的另一种读法：加权求和

点积还有一层更朴素的读法。$z_i = \sum_j W_{ij}x_j$ 是"把输入的每个分量，按它对应权重加权求和"。这层读法的意义在于：**它把高维输入压成一个标量**，压缩的过程保留了"与权重对齐"的信息、丢弃了"与权重垂直"的信息。

这正是"投影"（§2.2.1.3）：$z_i$ 是 $\mathbf{x}$ 在 $\mathbf{w}^{(i)}$ 方向上的投影长度。**神经网络的一层 = 把输入向量，投影到这一层所有神经元的权重方向上**。$W$ 的每一行是一个"关注方向"，输出 $\mathbf{z}$ 记录的是"输入在这每个方向上有多少分量"。信息没有被删掉，而是被**重写成"在哪些关注方向上"的表达**——这就是"表征变换 (representation)"的数学本质。

边界声明：**点积是线性的，所以"检测器"也是线性的。** 一个神经元只能检测"与它权重线性对齐"的模式——XOR 这类非线性可分问题，单神经元永远检测不了（1969 年明斯基的结论）。神经元能做的，是检测"某个方向上的投影"；要检测更复杂的关系，必须靠多层叠加（每层之间插入非线性激活，§2.2.3.3）。另外注意：点积对**输入的尺度敏感**——输入向量整体放大 10 倍，$z_i$ 也放大 10 倍。所以"对齐程度"最好用余弦相似度（归一化后）衡量，而"反应强度"用点积。两者用途不同，别混。

## 第三步：DL 桥接

点积是神经网络里**出现频率最高的运算**，没有之一。三处最有代表性的落点：

1. **全连接层**：$z = W\mathbf{x} + \mathbf{b}$——每个输出神经元就是一个点积检测器。你每看到一个 `nn.Linear`，它的前向就是一层点积。这在本节已完全展开。

2. **卷积**（§2.2.3.7、§2.5.3.2）：卷积核在图像上滑动，每个位置的输出 = 核与"图像局部块"的点积。卷积核就是一个"滑动的小检测器"，扫过整张图找同一种特征。

3. **注意力机制 (Attention)**：$QK^\top$ 计算"查询向量与每个键向量的点积"——就是"这个 token 与那个 token 有多对齐"。点积大 = 相关 = 注意力权重高。**Transformer 里"注意力"的数学内核，正是点积的"对齐检测"。**（Transformer 用缩放点积 $\frac{QK^\top}{\sqrt{d_k}}$，其中 $1/\sqrt{d_k}$ 是为了防点积随维度变大而膨胀。）

你还会在损失函数（$\mathbf{w}\cdot\mathbf{x}$ 形式的线性预测）、PCA（投影方向上的点积）、特征相似度里反复见到它。**把"点积 = 对齐检测"这个画面刻进脑子里，深度学习的每一个角落都认得出来。**
