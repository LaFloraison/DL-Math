# 习题：神经网络中的点积

## 第一组：概念检验

**1.1（单选）** 输入 $\mathbf{x} = [2, 3]$，权重矩阵 $W = \begin{bmatrix} 0.1 & 0.4 \\ 0.2 & 0.5 \end{bmatrix}$，则 $W\mathbf{x}$ 等于：
- A. $[0.2, 1.2]$
- B. $[1.4, 1.9]$
- C. $[0.5, 1.0]$
- D. $[1.9, 1.4]$

**1.2（判断并说明）** "矩阵乘法 $\mathbf{z} = W\mathbf{x}$ 本质上是一次性计算多个点积——每个输出神经元对应 $W$ 的一行与输入的逐个点积。" 这句话对吗？

**1.3（填空）** 若输入 $\mathbf{x}$ 与某神经元权重 $\mathbf{w}$ 的夹角为 $90°$，则该神经元的输出 $z = \mathbf{w}\cdot\mathbf{x}$ 约等于____；若二者同向，$z$ 取到____（最大/最小/零）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 设 $\mathbf{x} = [1, 4, 2]$，$W = \begin{bmatrix} 1 & 0 & 2 \\ -1 & 1 & 3 \\ 0 & 2 & 1 \end{bmatrix}$。手算 $W\mathbf{x}$，再用 NumPy 验证，指出每个输出对应哪个神经元的"点积"。

**2.2（代码验证）** 用余弦相似度计算"输入 $\mathbf{x}=[1,4,2]$ 与 $W$ 三个行向量的对齐程度"，按对齐程度排序，解释"对齐越大，$z$ 越大"（注意 $z$ 还受权重长度影响）。

**2.3（动手理解）** 构造一个与 $\mathbf{x}=[1,4,2]$ 几乎垂直的向量 $\mathbf{x}_\perp$（提示：在 $\mathbb{R}^3$ 中找 $\mathbf{x}\cdot\mathbf{x}_\perp\approx0$），计算其与某个行向量的 $z$，验证"垂直 → 点积≈0"。

## 第三组：DL 延伸

**3.1（场景判断）** 注意力机制里 $QK^\top$ 计算的是"查询与所有键的点积"。如果两个 token 的查询向量与键向量夹角很小，注意力权重会偏____（高/低）；这一步点积的物理含义是什么？

**3.2（场景分析）** 有人把卷积层称为"滑动窗口点积"。请解释：为什么卷积核在每个位置的计算可以看作一次点积？这个视角与"卷积核是特征检测器"如何联系起来？

## 解答与思路点拨

### 第一组

**1.1 答案：B（$[1.4, 1.9]$）。**
- **思路**：$z_0 = 0.1\times2 + 0.4\times3 = 1.4$，$z_1 = 0.2\times2 + 0.5\times3 = 1.9$。
- **点拨**：逐行点积。D 是顺序写反（$[1.9,1.4]$），A 是只算了"某一行的一部分"（$0.2, 1.2$ 是逐项积不是求和）。

**1.2 对。**
- **思路**：矩阵乘法的定义 $z_i = \sum_j W_{ij}x_j$ 逐行展开，每一行就是一个点积。矩阵乘法 = "批量点积"。
- **点拨**：这是"矩阵乘法"与"点积"的统一视角——理解它，§2.3.4.3 会轻松很多。

**1.3 答案：约 0；最大。**
- **思路**：$z = \|\mathbf{w}\|\|\mathbf{x}\|\cos\theta$，$\theta=90°$ 时 $\cos\theta=0$ → $z=0$；同向 $\cos\theta=1$ → $z$ 取最大值。
- **点拨**："垂直 → 零反应，同向 → 最大反应"，这是神经元作为"方向检测器"的核心。

### 第二组

**2.1**
$z_0 = 1\cdot1 + 0\cdot4 + 2\cdot2 = 5$；
$z_1 = (-1)\cdot1 + 1\cdot4 + 3\cdot2 = 9$；
$z_2 = 0\cdot1 + 2\cdot4 + 1\cdot2 = 10$。
$\mathbf{z} = [5, 9, 10]$。

```python
import numpy as np
x = np.array([1.0, 4.0, 2.0])
W = np.array([[1.,0.,2.],[-1.,1.,3.],[0.,2.,1.]])
print(W @ x)                       # [ 5.  9. 10.]
for i in range(3):
    print(np.dot(W[i], x))         # 5.0 9.0 10.0 逐行点积一致
```
- **思路**：每行与 $\mathbf{x}$ 点积，三个输出分别对应三个神经元。
- **点拨**：手算矩阵乘 = 逐行点积，这是最不易错的计算方式。

**2.2**
```python
x = np.array([1.0, 4.0, 2.0])
W = np.array([[1.,0.,2.],[-1.,1.,3.],[0.,2.,1.]])
for i, w in enumerate(W):
    cos = np.dot(x, w)/(np.linalg.norm(x)*np.linalg.norm(w))
    print(i, f"cos={cos:.4f}", f"z={np.dot(x,w):.1f}")
# 行0: cos=0.757 z=5.0
# 行1: cos=0.889 z=9.0
# 行2: cos=0.943 z=10.0
```
- **思路**：对齐度排序 行2 > 行1 > 行0，$z$ 也同序——**对齐越大，$z$ 越大**。但注意 $z$ 还乘了权重模长，所以严格说 $z \propto \cos\theta \times \|\mathbf{w}\|$。
- **点拨**：余弦（纯对齐）与 $z$（含强度）通常同趋势，但不恒等——两个权重同方向、长度不同，$z$ 不同。这是"点积 vs 余弦"的经典差异。

**2.3**
```python
x = np.array([1.0, 4.0, 2.0])
x_perp = np.array([4.0, -1.0, 0.0])      # x·x_perp = 4-4+0 = 0
print(np.dot(x, x_perp))                  # 0.0
print(np.dot(x_perp, W[0]))               # 4.0 (与行0 不垂直)
# 找一个与行0 也接近垂直的:
w0 = W[0]; import numpy.linalg as la
# 用叉积构造同时垂直 x 与 w0 的方向:
v = np.cross(x, w0)
print(np.dot(x, v), np.dot(w0, v))        # ≈0 ≈0
```
- **思路**：$\mathbf{x}_\perp$ 与 $\mathbf{x}$ 点积为 0（垂直）；再用叉积构造同时垂直 $\mathbf{x}$ 与某行的向量，验证两个点积都≈0。
- **点拨**：**垂直 = 点积为 0 = 神经元无反应**。叉积（§2.2.1.2）在这里派上用场：它造出的向量天然与两者垂直。这在特征去相关（让特征相互正交）里有实际应用。

### 第三组

**3.1 答案：夹角小 → 点积大 → 注意力权重偏高。点积的物理含义是"两个 token 的对齐/相关程度"。**
- **思路**：$QK^\top$ 中每个元素是查询向量与键向量的点积。点积大 = 语义相关 = Softmax 后权重高 = 该 token 被重点关注。夹角小意味着"方向几乎一致"，对应"高度相关"。
- **点拨**：**注意力权重就是一组"点积对齐度的归一化"。** 这就是"点积是注意力心脏"的原因。缩放因子 $1/\sqrt{d_k}$ 防止点积随维数膨胀、Softmax 退化（§2.3.6.4 会讲 Softmax）。

**3.2 思路**
- 卷积核是一个小矩阵（如 3×3），在每个图像位置上，把核的 9 个数与图像该位置邻域的 9 个像素**对应相乘再求和**——这正是"点积"（把 3×3 块拉平成 9 维向量，再与核拉平的点积）。
- 卷积核滑过整张图，本质是**同一个"检测器"（核）在每一处都做一次点积**——它检测"这个局部块里有没有核想找的图案"。核的权重向量指向它检测的特征（如横边、竖边）。
- **联系**：卷积 = "平移不变的点积检测器"。全连接层的权重是全局的（每个神经元看整个输入），卷积核是局部的（只看一个小窗口）——但底层的数学都是点积。
- **点拨**：这个视角把"卷积"拉回本节的统一语言：**深度学习的一切特征检测，都是点积**——只是"检测器"作用的范围不同（全连接=全局，卷积=局部窗口，注意力=按相关度动态选择）。
