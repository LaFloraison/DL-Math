# 代码：用 NumPy 亲手拆开一个矩阵，看它的拉伸方向与拉伸倍数

主线里我们用一颗球感受了 SVD：任何矩阵都是一次"旋转、拉伸、再旋转"。这一节把这句话变成代码——用 `np.linalg.svd` 把矩阵拆成 $U,\Sigma,V^\top$ 三件套，重构验证精确复原，再截断到前 $k$ 个奇异值，亲眼验证 Eckart–Young 定理的误差公式。

脚本只依赖 NumPy，约 30 行，全部输出印在下方（数字是真实运行结果）。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：线性代数的瑞士军刀

# ---- ① 教材例：A = diag(1, 4, 0)，对角阵，奇异值一目了然 ----
A = np.array([[1., 0., 0.],
              [0., 4., 0.],
              [0., 0., 0.]])
print("A =\n", A)

# ---- ② 完整 SVD（默认 full_matrices=True）----
U, S, Vh = np.linalg.svd(A)
print("U:", U.shape, "| S:", S.shape, "| Vh:", Vh.shape)
print("U =\n", U)
print("奇异值 S =", S)
print("Vh =\n", Vh)

# ---- ③ 重构验证：A = U Σ Vᵀ，把一维 S 填进 m×n 对角块 ----
S_fill = np.zeros(A.shape)
np.fill_diagonal(S_fill, S)
recon = U @ S_fill @ Vh
print("重构最大误差:", np.abs(recon - A).max())

# ---- ④ 经济型 SVD：只算 min(m,n) 个，形状更小 ----
Ue, Se, Vhe = np.linalg.svd(A, full_matrices=False)
print("经济型:", Ue.shape, Se.shape, Vhe.shape)
print("经济型重构误差:", np.abs(Ue @ np.diag(Se) @ Vhe - A).max())

# ---- ⑤ 非方阵 + 截断：3×5 随机数据，保留 k 个奇异值 ----
rng = np.random.default_rng(0)
X = rng.standard_normal((3, 5))
U, S, Vh = np.linalg.svd(X, full_matrices=False)
print("X 形状:", X.shape, "| 经济型 U,S,Vh:", U.shape, S.shape, Vh.shape)
print("X 的奇异值 S =", np.round(S, 4))
for k in (1, 2, 3):
    Xk = U[:, :k] @ np.diag(S[:k]) @ Vh[:k, :]
    err = np.linalg.norm(X - Xk)                    # Frobenius 范数
    theory = np.sqrt(np.sum(S[k:]**2))              # Eckart-Young 预言
    print(f"k={k}: 实际误差 {err:.4f} | 理论误差 {theory:.4f} | 秩={np.linalg.matrix_rank(Xk)}")

# ---- ⑥ 奇异值谱：各方向携带的能量占比 ----
print("能量占比:", np.round(S**2 / np.sum(S**2), 4))
print("累计能量占比:", np.round(np.cumsum(S**2) / np.sum(S**2), 4))
```

## 层二：分步逐函数拆解

### 步骤 1：造矩阵 `np.array`

```python
A = np.array([[1., 0., 0.],
              [0., 4., 0.],
              [0., 0., 0.]])
```

#### `np.array(嵌套列表)` —— 把列表变成二维数组

**做什么**：把教材里的矩阵 $A = \text{diag}(1,4,0)$ 变成 NumPy 数组——三个行列表拼成一个二维数组。
**操作**：`np.array` 从嵌套列表推断形状 `(3, 3)`（3 行、3 列），推断数据类型为 `float64`（因为写了 `1.` 而非 `1`）。
**输入**：一个嵌套列表，外层长度 = 行数 3，每个内层列表长度 = 列数 3。
**输出**：形状 `(3, 3)` 的 `ndarray`。`A[i, j]` 是第 $i$ 行第 $j$ 列的元素。
**可调参数**：
- 内层列表长度不必相等吗？——相等才构成矩阵；不等会报错或变成"参差数组"（NumPy 2 默认禁止）。
- 传 `dtype`：`np.array([[1,0,0],[0,4,0],[0,0,0]], dtype=float)` 强制浮点；深度学习常用 `np.float32` 省一半内存。
- 想造任意形状的全零/全一矩阵，用 `np.zeros(shape)` / `np.ones(shape)`（步骤 3 会用到 `np.zeros`）。
**对应数学**：主线第二步的教材例 $A = \text{diag}(1,4,0)$。

### 步骤 2：完整 SVD `np.linalg.svd` —— 本节的主角

```python
U, S, Vh = np.linalg.svd(A)
```

#### `np.linalg.svd(a, full_matrices=True, compute_uv=True, hermitian=False)` —— 计算奇异值分解

**做什么**：把矩阵 $A$ 分解成 $A = U\Sigma V^\top$。这是本节的灵魂一行——从任何矩阵里挖出它的"拉伸方向"（$U$、$V$ 的列）和"拉伸倍数"（$S$ 的元素）。
**操作**：数值上，numpy 不会傻傻地"先算 $A^\top A$ 的特征值再开方"（那会放大浮点误差），而是用双对角化 + 隐式 QR 迭代（Golub–Kahan 一脉的算法），对任意形状、任意秩的矩阵都数值稳定。
**输入**：`a`——形状 `(m, n)` 的二维数组。本步 `A` 是 `(3, 3)`。
**输出**：按顺序返回**三个**对象：
- `U`——**左奇异向量矩阵**，形状 `(m, m)`（默认完整型）= `(3, 3)`。列向量 $\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3$ 是 $AA^\top$ 的特征向量，两两正交。
- `S`——**奇异值的一维数组**，形状 `(min(m,n),)` = `(3,)`。元素非负、降序：`[4., 1., 0.]`。注意！numpy 把 $\Sigma$ 的**对角元素**单独拿出来装进一维数组，**它不是一个对角矩阵**——这是 numpy 的设计决策，步骤 3 会解释怎么补回对角阵。
- `Vh`——**$V$ 的转置**（实矩阵就是 $V^\top$），形状 `(n, n)` = `(3, 3)`。行向量是右奇异向量。numpy 直接返回 $V^\top$ 而不是 $V$，方便直接做矩阵乘法 `U @ ... @ Vh`。

验证一下输出：$U$ 和 $Vh$ 都是同一个置换矩阵（交换第 1、2 行/列的那个），$S = [4, 1, 0]$ 正是主线上手算的奇异值——降序、非负、秩为 2（两个非零）。
**可调参数**（`np.linalg.svd` 一共就这几个公开参数）：
- `full_matrices`：默认 `True`。`True` → `U` 是 `(m,m)` 的完整正交方阵、`Vh` 是 `(n,n)`；`False` → 经济型：`U` 是 `(m, k)`、`S` 是 `(k,)`、`Vh` 是 `(k, n)`，其中 `k = min(m, n)`。改成 `False` 能省内存、略快，因为完整型的 `U` 在 `m > n` 时有 `m-n` 列是"多余的"（对应零奇异值，不携带信息）。
- `compute_uv`：默认 `True`。设成 `False` 时**只返回 `S`**（一个值，不是三个）——当你只需要奇异值谱、不需要 $U$、$V$ 时用这个，快很多。比如只想看"数据塌缩得有多快"时。
- `hermitian`：默认 `False`。如果**确定**输入是实对称或复 Hermitian 矩阵，设 `True` 会走更快的特征分解路径；但若输入其实不对称，会返回**错误**的结果——不知道就别设。
- 还能传第 5 个参数吗？——numpy 2.x 里还有 `out`（把结果写进预分配数组，极少数场景用）。日常写代码，前两个参数就够。
**对应数学**：主线定义块 $A = U\Sigma V^\top$。`S` 就是奇异值 $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$，`U`、`Vh` 分别装着左、右奇异向量。

### 步骤 3：重构验证——把一维 `S` 填回对角矩阵

```python
S_fill = np.zeros(A.shape)
np.fill_diagonal(S_fill, S)
recon = U @ S_fill @ Vh
print("重构最大误差:", np.abs(recon - A).max())
```

因为 numpy 把 $\Sigma$ 的对角元素拆成了 `S` 一维数组，重构前要先把它"填回"对角矩阵 `S_fill`，再做三次矩阵乘法。

#### `np.zeros(shape)` —— 造全零数组

**做什么**：生成一个形状为 `shape` 的数组，所有元素为 0。`A.shape` 是 `(3, 3)`，所以 `S_fill` 是 `(3, 3)` 的全零矩阵——它将是空的 $\Sigma$。
**可调参数**：`dtype` 指定类型（默认 `float64`）；`shape` 可以是整数或元组，`np.zeros(5)` 是一维，`np.zeros((3, 5))` 是二维。

#### `np.fill_diagonal(a, val)` —— 原地填充主对角线

**做什么**：把 `val` 写进二维数组 `a` 的主对角线，就地修改，不返回新数组。`val` 可以是标量（全填同一个数）或一维数组（逐个填）——这里 `S` 是 `(3,)`，正好把 `[4., 1., 0.]` 依次放到主对角线位置，其余位置保持 0。
**输入**：`a`——形状 `(m, n)` 的数组；`val`——标量或长度 `min(m, n)` 的一维数组。
**输出**：无返回值（原地修改）。对非方阵（如 `(3, 5)`），它只填 `min(m, n) = 3` 个对角位置。
**可调参数**：`val` 换成标量 `1` 就把整条对角线设为 1（得到单位阵的雏形）。

#### `U @ S_fill @ Vh` —— 矩阵乘法（`@` 运算符）

**做什么**：做两次矩阵乘法：`(3,3) @ (3,3) @ (3,3)` → `(3,3)`。这就是 $U\Sigma V^\top$ 的数值版本。
**操作**：`@` 是 `np.matmul` 的运算符写法，按"行 × 列"规则计算：结果第 $i$ 行第 $j$ 列 = 左矩阵第 $i$ 行与右矩阵第 $j$ 列的内积。
**输入/输出**：`(m, k) @ (k, n)` 才合法，中间维 `k` 必须对齐；结果是 `(m, n)`。这里 `(3,3)@(3,3)` → `(3,3)`。
**可调参数**：`@` 没有参数，但它对**高维数组**（三维以上）按"批量矩阵乘法"处理，对一维数组也有特殊语义（向量内积/外积）。本课全是二维，规则最干净。
**对应数学**：主线 $A = U\Sigma V^\top$。输出 `重构最大误差: 0.0`——逐元素最大误差是 0，说明精确复原。

#### `np.abs(x).max()` —— 逐元素绝对值再取最大

**做什么**：`np.abs(recon - A)` 先逐元素算差值的绝对值（一个 `(3,3)` 数组），`.max()` 取其中最大值——这是"重构到底差多少"的标量度量。
**可调参数**：`.max()` 可传 `axis`（沿某轴取最大，如 `.max(axis=0)` 按列取）；想算平均误差就用 `.mean()`，想看最坏位置用 `.argmax()`。
**对应数学**：这里是逐元素最大误差，主线里更常用的整体误差是 Frobenius 范数（步骤 6 的 `np.linalg.norm`）。

### 步骤 4：经济型 SVD `full_matrices=False`

```python
Ue, Se, Vhe = np.linalg.svd(A, full_matrices=False)
print("经济型重构误差:", np.abs(Ue @ np.diag(Se) @ Vhe - A).max())
```

**做什么**：用经济型（reduced / thin）SVD 重做一次，演示 `full_matrices=False` 的形状语义，并验证重构依旧精确。
**形状对比**（`A` 是 `(3,3)`，`k = min(3,3) = 3`）：经济型的 `Ue:(3,3)`、`Se:(3,)`、`Vhe:(3,3)` 和完整型一模一样——因为方阵的 `min(m,n) = m = n`，经济型没有省略任何东西。**要看到经济型的差别，得用非方阵**——步骤 5 的 `(3,5)` 就不同了。
**为什么需要 `np.diag(Se)`**：`Se` 是一维数组，不能直接和矩阵相乘；`np.diag(Se)` 把它变成 `(3,3)` 对角阵。
**对应数学**：同一分解的两种输出形态。工程里处理"行数远大于列数"的数据时（如 1000 个样本 × 5 个特征），`full_matrices=False` 让 `U` 从 `(1000, 1000)` 缩到 `(1000, 5)`——省下的内存非常可观。

#### `np.diag(v)` —— 一维数组 ↔ 对角矩阵

**做什么**：两个方向都能用——`np.diag([4,1,0])` 得到 `(3,3)` 对角矩阵；`np.diag(M)`（传二维）提取 `M` 的主对角线成一维数组。
**输入**：一维数组（长度 $k$）→ 输出 $k\times k$ 对角阵；二维数组 → 输出主对角线。
**可调参数**：`k`（偏移量，默认 `0` 主对角线）：`np.diag(S, 1)` 把 `S` 放到主对角线上方一条的位置，主对角线补零——这是构造"偏移对角阵"的少见用法。

### 步骤 5：非方阵随机数据 + 截断切片

```python
rng = np.random.default_rng(0)
X = rng.standard_normal((3, 5))
U, S, Vh = np.linalg.svd(X, full_matrices=False)
for k in (1, 2, 3):
    Xk = U[:, :k] @ np.diag(S[:k]) @ Vh[:k, :]
```

这一步换成**非方阵** `X` 形状 `(3, 5)`（3 个样本、5 个特征——深度学习里最常见的数据形状）。经济型下 `k = min(3,5) = 3`：`U:(3,3)`、`S:(3,)`、`Vh:(3,5)`。**看，`Vh` 从 `(5,5)` 变成了 `(3,5)`**——这才是经济型真正发挥作用的场景。

`for k in (1, 2, 3)` 循环里做**截断 SVD**：只保留前 $k$ 个奇异值重构 $X_k$，用三个切片：

- `U[:, :k]`：取 `U` 的**前 $k$ 列**（形状 `(3, k)`）——保留前 $k$ 个左奇异向量；
- `np.diag(S[:k])`：取 `S` 的**前 $k$ 个**奇异值（长度 `k`），扩成 $k\times k$ 对角阵；
- `Vh[:k, :]`：取 `Vh` 的**前 $k$ 行**（形状 `(k, 5)`）——保留前 $k$ 个右奇异向量。

三块相乘 `(3,k) @ (k,k) @ (k,5)` → `(3,5)`，得到 $X_k$。

#### `np.random.default_rng(seed)` / `rng.standard_normal(shape)` —— 可复现的随机数

**做什么**：`default_rng(0)` 用种子 0 生成一个随机数生成器（RNG）；`rng.standard_normal((3,5))` 从标准正态分布 $N(0,1)$ 逐元素采样，填出一个 `(3,5)` 数组。
**可调参数**：
- `seed`：固定为同一个整数，每次运行得到**完全相同**的 `X`——实验可复现的关键。不传种子，每次结果都不同。
- `standard_normal` 还可传 `dtype`、`out`。想要均匀分布 `[0,1)` 用 `rng.random(shape)`；想要整数用 `rng.integers`。
- 这是 NumPy 2.x 的现代写法，取代旧的 `np.random.seed(0) + np.random.randn(...)` 全局状态。
**对应数学**：构造一个"真实世界"的满秩随机矩阵——它的奇异值一般都不为 0，截断才会真正丢信息。

#### 切片 `U[:, :k]`、`S[:k]`、`Vh[:k, :]` —— 取前 $k$ 个成分

**做什么**：NumPy 切片。`U[:, :k]` 逗号前是行（`:` 全取）、逗号后是列（`0..k-1`）；`Vh[:k, :]` 反之；`S[:k]` 是一维数组取前 `k` 个。
**输出**：`U[:, :k]` 形状 `(3, k)`，`S[:k]` 长度 `k`，`Vh[:k, :]` 形状 `(k, 5)`。
**可调参数**：`k` 是整数，`k=0` 得到空矩阵（误差 = $\|X\|_F$），`k=3` 是满秩（误差 0）。切片是**视图**不是拷贝（共享内存，改原数组切片也会变），需要独立副本时用 `.copy()`。
**对应数学**：主线第五节"截断 SVD 只保留前 $k$ 个奇异值"。$X_k$ 就是 Eckart–Young 定理里的最优秩 $k$ 近似。

### 步骤 6：Eckart–Young 检验——实际误差 vs 理论误差

```python
err = np.linalg.norm(X - Xk)
theory = np.sqrt(np.sum(S[k:]**2))
```

#### `np.linalg.norm(x, ord=None, axis=None)` —— 计算范数

**做什么**：对二维数组 `X - Xk` 默认 `ord=None`，算的是 **Frobenius 范数** $\|X - X_k\|_F = \sqrt{\sum_{i,j}(X-X_k)_{ij}^2}$——所有元素平方和再开方。
**操作**：这正是主线里"矩阵总能量 = $\sqrt{\sigma_1^2 + \cdots + \sigma_r^2}$"的定义。
**输入**：`X - Xk`，形状 `(3,5)`；输出标量。
**可调参数**：
- `ord`：换成 `'nuc'` 得核范数（奇异值之和）；`2` 得谱范数（最大奇异值）；`1`、`'inf'`、`'fro'` 等各不同。默认对二维就是 Frobenius。
- `axis`：`np.linalg.norm(X, axis=1)` 对每一行求范数，返回长度 3 的数组——批量归一化时常用。

#### `np.sqrt(np.sum(S[k:]**2))` —— 被丢弃奇异值的能量

**做什么**：`S[k:]` 切片取**被丢掉**的奇异值（索引 `k` 及以后）；`**2` 逐个平方；`np.sum` 求和；`np.sqrt` 开方。这就是主线里的理论误差 $\sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}$。
**输出对比**：`k=1` 时实际 `2.2843` = 理论 `2.2843`；`k=2` 时 `0.6248` = `0.6248`；`k=3` 时 `0.0000`。**实际误差与 Eckart–Young 预言逐位吻合**——这不是巧合，是定理在替你打工。`秩=1/2/3` 用 `np.linalg.matrix_rank(Xk)` 确认每个 $X_k$ 的秩确实不超过 $k$。
**对应数学**：Eckart–Young 定理的误差公式（主线第五节）。`S[0]=2.7828, S[1]=2.1972, S[2]=0.6248`，所以 `k=1` 时理论值 = $\sqrt{2.1972^2 + 0.6248^2} = 2.2843$。

### 步骤 7：奇异值谱与累计能量

```python
print("能量占比:", np.round(S**2 / np.sum(S**2), 4))
print("累计能量占比:", np.round(np.cumsum(S**2) / np.sum(S**2), 4))
```

**做什么**：回答"这个矩阵的信息集中在哪几个方向"。
- `S**2 / np.sum(S**2)`：每个奇异值的平方占**总能量**（所有平方和）的比例。输出 `[0.5974 0.3724 0.0301]`——第一个方向扛走 59.7% 的能量。
- `np.cumsum(S**2)`：**累计和**（cumulative sum），再除以总能量，得到"保留前 $i$ 个方向能保住多少能量"。输出 `[0.5974 0.9699 1.]`——只留前 2 个方向，就保住了 96.99% 的能量；第 3 个方向几乎可以忽略。

#### `np.cumsum(a)` —— 累计和

**做什么**：`np.cumsum([2,3,4])` → `[2, 5, 9]`。把数组从头到尾累加。
**可调参数**：`axis`（沿哪一维累加）、`dtype`。
**对应数学**：主线"奇异值掉得越快，数据越瘦地躺在一个低维子空间里"。累计能量占比是选择截断 $k$ 的通行判据——"想保住 95% 的能量，就保留前多少个奇异值"。

## 边界声明：这套代码能做什么，不能做什么

1. **`S` 是一维数组，不是对角矩阵**。`U @ S @ Vh` 会直接报错（形状对不上）或行为诡异。必须先 `np.diag(S)`（或 `np.fill_diagonal`）把它扩成对角阵，这是 numpy SVD 最经典的坑。
2. **`U`、`Vh` 的形状随 `full_matrices` 变化**。默认完整型：`(m,m)` 和 `(n,n)`；经济型：`(m,k)` 和 `(k,n)`，`k=min(m,n)`。写通用代码时**永远不要硬编码形状**，用 `.shape` 推断。方阵上两者看不出差别，非方阵上差别巨大（`(1000, 5)` 的数据，完整型 `U` 是 `1000×1000`）。
3. **SVD 的 `U`、`V` 不唯一**：任意一列同时翻转符号、或存在相等奇异值时子空间内任意旋转，重构结果都一样。所以不同库、不同版本算出的 `U`、`V` 可能不同——**奇异值 `S` 才是唯一确定的**。别把某个 `U` 的符号当圣旨。
4. **`hermitian=True` 是个危险的加速开关**：只有输入**确实**是实对称/复 Hermitian 矩阵时才正确；乱设会得到错误分解。不确定就保持默认 `False`。
5. **`np.linalg.matrix_rank` 是数值秩**：它用奇异值相对容差判断"算不算 0"。对接近奇异的矩阵（如某奇异值 $10^{-14}$），秩的判定受浮点误差影响，别把它当精确的代数秩。
6. **Eckart–Young 的误差公式只在 Frobenius / 谱范数下成立**。换成别的误差度量（如逐元素 1-范数、最大绝对值误差），截断 SVD 不一定最优。以及本脚本只处理**实矩阵**；复数矩阵 numpy 用共轭转置，`Vh` 的语义和这里略有不同，超出本课范围。
7. **这一节只"拆解"，不"应用"**：主成分分析、矩阵补全、低秩微调（LoRA）都是 SVD 的**下游应用**——工具已经握在手里，用在哪里是后面章节的事。
