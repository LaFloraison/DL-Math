## 第三组：DL 延伸

**3.1（场景判断）** 一个推荐系统把"用户 × 物品"的评分矩阵 $R \in \mathbb{R}^{10000 \times 5000}$ 做 SVD 后只保留前 $k=200$ 个奇异值，用 $R_k$ 预测用户对没看过的物品的评分。请你解释：**为什么丢弃后 4800 个奇异值方向，不仅省了存储，反而让预测变好（去噪），而不是单纯地"丢信息"？** 提示：评分矩阵里充满了缺失项和噪声，$R_k$ 里被丢弃的方向对应什么样的奇异值？

## 解答与思路点拨

### 第一组

**1.1 答案：B（4）。**
- **思路**：奇异值个数最多是 $\min(m, n) = \min(4, 7) = 4$。事实上非零奇异值的个数 $= \text{rank}(A) \le \min(m, n)$。一个 $4 \times 7$ 的矩阵，行空间最多 4 维，所以它"拉伸"方向最多 4 个。
- **点拨**：选 A（7）的常见错因是把"列数"当成了"奇异值个数"。$\Sigma$ 的形状是 $(m, n)$，主对角线上只有 $\min(m, n)$ 个位置——在 $4 \times 7$ 的例子里，超过 4 行的"对角线"全是 0。选 C（11）是把 $m + n$ 误当成了分解结果的规模。这道题的教训：**奇异值个数看 $\min(m,n)$，非零奇异值个数看秩。**

**1.2 这句话只在特定条件下成立。**
- **思路**：奇异值来自 $\sigma_i = \sqrt{\lambda_i(A^\top A)}$。当 $A$ 对称半正定时，$A^\top A = A^2$，其特征值是 $\lambda_i^2$，开方回来 $\sigma_i = \lambda_i$，且 $U = V$——这时"奇异值就是特征值"成立。当 $A$ 只是普通对称矩阵时，奇异值等于 $|\lambda_i|$（特征值的绝对值）。当 $A$ 非方阵时，它根本没有特征值，这句话无从谈起。
- **点拨**：最容易答错的地方是把"对称"误当充分条件。$A$ 对称但**不正定**时（如 $A = \text{diag}(-2, 1)$），特征值是 $-2, 1$，奇异值是 $2, 1$——**绝对值**，不是相等。记住：对称半正定（所有特征值 $\ge 0$）才是相等。

**1.3 答案：非负；降序排列；一共 $\min(m, n)$ 个（非零的只有 $\text{rank}(A)$ 个）。$\text{rank}(A)$ = 非零奇异值的个数。**
- **思路**：这是定义块里直接列出的三条性质。第三个空格要特别小心——奇异值**总共**有 $\min(m,n)$ 个，但**非零**的只有 $\text{rank}(A)$ 个，两者不是一回事（满秩时相等）。
- **点拨**：填"个数 = 秩"其实也对，但那是"非零奇异值"的个数；"总个数 = $\min(m,n)$"是另一个事实。写答案时把这两个数分开说，是区分"真的懂了"和"背下来了"的试金石。

### 第二组

**2.1 手算：**
$A^\top A = \begin{bmatrix} 0 & 0 \\ 0 & 9 \end{bmatrix}$，特征值 $9, 0$，开方得**奇异值 $\sigma = 3, 0$**。
$A^\top A$ 特征值 9 对应特征向量 $[0, 1]^\top$，特征值 0 对应 $[1, 0]^\top$，所以 $V = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}$（列按奇异值降序排）。
$AA^\top = \begin{bmatrix} 9 & 0 \\ 0 & 0 \end{bmatrix}$，特征值 9 对应 $[1,0]^\top$、特征值 0 对应 $[0,1]^\top$，所以 $U = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} = I$。
验证：$A = U\Sigma V^\top = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\begin{bmatrix} 3 & 0 \\ 0 & 0 \end{bmatrix}\begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix} = \begin{bmatrix} 0 & 3 \\ 0 & 0 \end{bmatrix}$ ✓

```python
import numpy as np
A = np.array([[0., 3.], [0., 0.]])
U, S, Vh = np.linalg.svd(A)
print("U =\n", U)   # [[1. 0.],[0. 1.]]
print("S =", S)     # [3. 0.]
print("Vh =\n", Vh) # [[ 0.  1.],[-1.  0.]]
```

注意！numpy 返回的 `Vh = [[0, 1], [-1, 0]]`，而手算的 $V = [[0,1],[1,0]]$。**两者都对**：$V$ 的第二列差了 $-1$（符号翻转）。因为对应的奇异值 $\sigma_2 = 0$，$u_2$ 的符号无所谓，乘积 $U\Sigma V^\top$ 完全不变。这就是主线边界声明里说的"SVD 不唯一，符号翻转不影响重构"的活例子。
- **思路**：手算 SVD 的固定流程——先算 $A^\top A$ 和 $AA^\top$ 的特征分解，奇异值 = $A^\top A$ 特征值开方，$V$ 列是 $A^\top A$ 特征向量，$U$ 列是 $AA^\top$ 特征向量。
- **点拨**：看到 numpy 输出和手算"不一样"先别慌——先用 `np.allclose(U @ np.diag(S) @ Vh, A)` 验证乘积，符号差异是常态，不是错误。

**2.2 答案：奇异值 $5, 3, 1$（降序）；$\|A\|_F = \sqrt{25+9+1} = \sqrt{35} \approx 5.916$；截断到 $k=2$ 的误差 $= \sqrt{1^2} = 1$。**
- **思路**：对角阵的奇异值就是主对角线元素（按降序排）；Frobenius 范数是奇异值平方和的平方根（主线"总能量"）；截断到 $k=2$ 丢掉的是 $\sigma_3 = 1$，误差就是 $\sqrt{\sigma_3^2} = 1$。
- **点拨**：容易算错的地方是把 $k=2$ 的误差算成 $\sqrt{3^2+1^2}$——那是"丢掉最大两个"的错误理解。截断是**丢最小的**（$\sigma_{k+1}$ 到 $\sigma_r$），不是丢最大的。这也呼应了 3.2 的"该保留谁"。

```python
import numpy as np
A = np.diag([5., 3., 1.])
U, S, Vh = np.linalg.svd(A)
A2 = U[:, :2] @ np.diag(S[:2]) @ Vh[:2, :]
print(np.linalg.norm(A - A2))      # 1.0
print(np.sqrt(np.sum(S[2:]**2)))   # 1.0
```

**2.3 参考代码：**
```python
import numpy as np
rng = np.random.default_rng(7)
R = rng.standard_normal((5, 8))          # 5 行 8 列，非方阵
U, S, Vh = np.linalg.svd(R, full_matrices=False)
print("奇异值 =", np.round(S, 4))        # [4.3263 2.5264 2.2642 1.1632 0.9692]
k = 2
Rk = U[:, :k] @ np.diag(S[:k]) @ Vh[:k, :]
err    = np.linalg.norm(R - Rk)          # 实际误差
theory = np.sqrt(np.sum(S[k:]**2))       # Eckart-Young 理论
print("实际 =", err, "| 理论 =", theory)  # 2.7238 == 2.7238
```
- **思路**：注意 $5 \times 8$ 矩阵有 $\min(5,8)=5$ 个奇异值（降序），截断到 $k=2$ 丢掉的是后 3 个；实际误差与理论逐位一致。
- **点拨**：把 `k` 改成 0 试试——误差变成 $\|R\|_F$；改成 5——误差是 0。观察误差如何随 `k` 平滑下降，是理解"奇异值能量"最快的方式。

### 第三组

**3.1 思路：**
- 评分矩阵 $R$ 中大多数位置是**缺失**的（用户只看过极少数物品），能观测到的评分还混着噪声（手滑、心情、评分偏差）。
- SVD 把 $R$ 拆成 $U\Sigma V^\top$ 后，前 $k$ 个奇异值对应的是 $R$ 里**最强的结构**——"喜欢科幻的用户倾向喜欢《银翼杀手》"这类稳定的协同模式；后 4800 个奇异值大多是**小奇异值**，对应的是噪声、个别用户的怪癖、以及缺失项带来的随机波动。
- 截断丢掉它们，$R_k$ 就只保留了"真正的结构"而滤掉了噪声——这正是主线 DL 桥接里"去噪"的含义。保留全部奇异值反而把噪声也当作真相学进去，预测未见评分时**过拟合**。
- **点拨**：容易答错的方向是"截断=丢信息，越少越差"。关键区分：**丢掉的是噪声方向还是信号方向？** 截断 SVD 丢的是小奇异值方向（噪声主导），所以是"去噪"；如果错误地保留全部分量，反而会把噪声固化进模型。这个直觉和 3.2 共享同一个原理。

**3.2 至少两条理由：**
1. **存储与计算**：保留全部 512 个奇异值要存 $512 \times 512$ 的 $U$、$\Sigma$、$V$，共约 78 万个数；只存前 40 个，只需 $512 \times 40 + 40 + 40 \times 512 \approx 4.1$ 万个数——**压缩比接近 20 倍**，重构仍保住 99% 能量。
2. **去噪**：第 41 到 512 个奇异值对应的是图像里的高频噪声（传感器误差、压缩伪影）。丢掉它们，$A_k$ 更干净；全保留则噪声原样保留。
3. **泛化**：在很多下游任务里，低秩近似 $A_k$ 泛化更好——用完整 $A$ 训练会过拟合噪声，用 $A_{40}$ 训练抓住的是图像的主体结构。
- **点拨**：问"为什么不保留全部"的诱惑是"误差为 0 最完美"。Eckart–Young 给出的"最优"是针对**给定 k** 的最小误差；但 k 本身是权衡，不是越大越好。这是主线边界声明"k 是人的决定，不是数学的结论"的直接应用。

## 一个"为什么有人会答错"的提醒

三组题共享一个深层陷阱：**把"分解"当成"分类"**。SVD 不会替你做决定——它只把能量按奇异值排好队；**保留几个奇异值（k）永远要人来定**。1.1 的错误（把列数当奇异值个数）来自没记住"个数看 $\min(m,n)$、非零个数看秩"；2.2 的错误（截断丢最大的）来自没记住"丢最小"；3.1/3.2 的错误（越多越好）来自没记住"k 是权衡，不是免费"。
