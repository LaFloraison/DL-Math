# 习题：正则化技术

## 第一组：概念检验

**1.1（单选）** 两个矩阵 $\mathbf{A} = \begin{bmatrix} 3 & 0 \\ 0 & 0 \end{bmatrix}$ 与 $\mathbf{B} = \begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix}$，它们的 Frobenius 范数关系是：
- A. $\|\mathbf{A}\|_F > \|\mathbf{B}\|_F$
- B. $\|\mathbf{A}\|_F < \|\mathbf{B}\|_F$
- C. $\|\mathbf{A}\|_F = \|\mathbf{B}\|_F$
- D. 无法比较（一个是稀疏的一个是满的）

**1.2（简答）** 同样是"把权重压小"，为什么 L1 正则化能把权重**精确地压成 0**，而 L2 正则化只能让权重**趋近于 0**？请从两者的梯度入手解释。

**1.3（判断并说明）** "在 NumPy 里，`np.linalg.norm(W, ord=1)` 计算的就是 L1 正则化里的那个惩罚项 $\sum_{ij}|w_{ij}|$。" 这句话对吗？提示：考虑它返回的是"最大列绝对和"。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 对 $\mathbf{W} = \begin{bmatrix} 3 & -4 \\ 0 & 5 \end{bmatrix}$，分别手算 Frobenius 范数 $\|\mathbf{W}\|_F$ 与元素 L1 范数 $\sum|w_{ij}|$，再用 NumPy 验证（注意 `np.linalg.norm(W, ord=1)` 的结果与元素 L1 的关系）。

**2.2（代码验证）** 取初始权重 $\mathbf{W} = \begin{bmatrix} 1 & 0.5 \\ -1 & 0.5 \end{bmatrix}$，$\lambda = 0.1$、学习率 $\text{lr} = 0.1$。分别执行 100 步"只按 L2 惩罚更新"（$W \leftarrow W - \text{lr}\cdot 2\lambda W$）和"只按 L1 惩罚更新"（$W \leftarrow W - \text{lr}\cdot \lambda\operatorname{sign}(W)$）。观察并解释：为什么 L1 最终把 $0.5$ 变成精确的 $0$，而 L2 只让它无限趋近？

**2.3（手算 + 代码验证）** 一批数据 $\mathbf{X} = \begin{bmatrix} 1 & 2 \\ 2 & 3 \\ 3 & 4 \end{bmatrix}$（3 个样本、2 个特征）。手算每个特征的均值 $\mu$、方差 $\sigma^2$、归一化结果 $\hat{X}$，再套用可学习参数 $\gamma = [2, 1]$、$\beta = [0.5, -0.5]$ 计算 $Y = \gamma\hat{X} + \beta$，用 NumPy 验证。

## 第三组：DL 延伸

**3.1（场景分析）** 一个全连接层，输入 256 维、输出 512 个神经元，权重矩阵 $\mathbf{W}$ 形状 $(512, 256)$。优化器里设 `weight_decay = 0.01`。请写出这一项精确惩罚的是什么量（公式），并说明在 SVD 视角（$\|\mathbf{W}\|_F^2 = \sum_k \sigma_k^2$）下，它实际上在鼓励 $\mathbf{W}$ 变成什么样的线性变换。

**3.2（场景判断）** 在 BatchNorm 层里，$\gamma$ 和 $\beta$ 在训练开始时通常被初始化为 $1$ 和 $0$。为什么要这么初始化？如果把 $\gamma$、$\beta$ 永远冻结在 $1$ 和 $0$（即只归一化、不做任何缩放平移），网络会失去什么？

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：$\|\mathbf{A}\|_F = \sqrt{3^2+0+0+0} = 3$；$\|\mathbf{B}\|_F = \sqrt{1+1+1+1} = 2$。所以 $3 > 2$。
- **点拨**：这是个经典陷阱——有人看见 $\mathbf{A}$ "大部分是 0"、$\mathbf{B}$ "四个方向都有力量"，凭直觉选 B。但 Frobenius 范数度量的是**总能量**：$\mathbf{A}$ 有一个元素是 3，能量 $9$ 远超 $\mathbf{B}$ 的 $4$。"矩阵大小"≠"元素数量"——一个巨大的元素就足以让范数很大。这也解释了为什么正则化用范数而非"非零元素个数"来度量大小。

**1.2 思路：** 看两者的梯度。
- L2：惩罚 $\lambda\sum w^2$ 的梯度是 $2\lambda w$——**与 $w$ 成正比**。权重越接近 0，拉力也越接近 0，像一根被拉长后越来越没劲的弹簧，永远差最后一口气：$w$ 趋近 0 但达不到 0。
- L1：惩罚 $\lambda\sum|w|$ 的梯度是 $\lambda\operatorname{sign}(w) = \pm\lambda$——**恒定**。哪怕 $w = 0.0001$，拉力仍是满格 $\lambda$，把最后一步走完：$w$ 被精确压成 0，而且一旦为 0，梯度也为 0，它就"死"在那里不再回来。
- **点拨**：判据是"梯度是否随权重变小而变小"。L2 是弹簧，L1 是恒力。这直接解释了为什么 L1 得到**稀疏**矩阵、L2 得到**小而满**的矩阵。

**1.3 这句话是错的。**
- **思路**：对**二维矩阵**，`np.linalg.norm(W, ord=1)` 返回的是**各列绝对值之和的最大值**（诱导 1 范数），不是所有元素绝对值之和。例如 $\begin{bmatrix} 2 & -1 \\ 0.5 & 1 \end{bmatrix}$：列和分别是 $2.5$ 和 $2.0$，`ord=1` 取最大值 $2.5$；而 L1 正则化用的 $\sum|w| = 4.5$。两者恰好在这个例子里数值相同纯属巧合。
- **点拨**：L1 正则化惩罚项的正确 NumPy 写法是 `np.sum(np.abs(W))`。诱导范数（最大列和）是另一类范数，用在条件数分析里。这个错误在面试/作业里极常见——因为 `ord=1` 这个参数名太像"元素 1 范数"了。

### 第二组

**2.1**
$$\|\mathbf{W}\|_F = \sqrt{3^2 + (-4)^2 + 0^2 + 5^2} = \sqrt{50} \approx 7.071, \qquad \sum|w_{ij}| = 3 + 4 + 0 + 5 = 12$$

```python
import numpy as np
W = np.array([[3.0, -4.0], [0.0, 5.0]])
print(np.linalg.norm(W))            # 7.0710678118654755
print(np.sum(np.abs(W)))            # 12.0
print(np.linalg.norm(W, ord=1))     # 9.0  —— 最大列和：max(|3|+0, |-4|+5) = max(3, 9) = 9
```
- **思路**：Frobenius = 元素平方和开方；元素 L1 = 绝对值之和。`ord=1` 是另一回事（这里 = 9）。
- **点拨**：三行输出三个不同的数（7.07 / 12 / 9），正好演示"矩阵的'大小'有不止一种定义"——正则化选哪种，取决于你想要"总能量"还是"稀疏程度"。

**2.2**
```python
import numpy as np
lam, lr = 0.1, 0.1
Wl2 = np.array([[1.0, 0.5], [-1.0, 0.5]])
Wl1 = Wl2.copy()
for _ in range(100):
    Wl2 = Wl2 - lr * (2 * lam * Wl2)      # L2：弹簧力
    Wl1 = Wl1 - lr * (lam * np.sign(Wl1)) # L1：恒力
print("L2 100 步后:\n", np.round(Wl2, 6))
print("L1 100 步后:\n", np.round(Wl1, 6))
# L2:  [[0.0675 0.0337]  [-0.0675 0.0337]]   —— 全不为 0，且趋近 0
# L1:  [[0. 0.]  [0. 0.]]                    —— 0.5 在第 50 步精确归零
```
- **思路**：L1 每步每个非零权重减少 $\text{lr}\cdot\lambda = 0.01$，$0.5$ 恰好第 50 步归零、$1.0$ 第 100 步归零；L2 的减少量 $2\lambda\text{lr}\,w = 0.02w$ 随 $w$ 变小而变小，永远只"逼近"。
- **点拨**：把循环步数加到很大（如 10 万），L2 仍然不会精确为 0（只会越来越小）；L1 则会早早把元素钉在 0 上。这就是"稀疏 vs 小满"的代码证据。

**2.3**
$\mu = [2, 3]$（每列均值）；$\sigma^2 = [\tfrac{(1-2)^2+(2-2)^2+(3-2)^2}{3},\ \tfrac{(2-3)^2+(3-3)^2+(4-3)^2}{3}] = [\tfrac23, \tfrac23]$。
$\hat{X} = \dfrac{X-\mu}{\sqrt{\sigma^2+\epsilon}} = \begin{bmatrix} -1.2247 & -1.2247 \\ 0 & 0 \\ 1.2247 & 1.2247 \end{bmatrix}$（$\tfrac{1}{\sqrt{2/3}}\approx 1.2247$）。
$Y = \gamma\hat{X}+\beta$：第 1 列 $\times 2$ 再 $+0.5$，第 2 列 $\times 1$ 再 $-0.5$：
$$Y = \begin{bmatrix} 2(-1.2247)+0.5 & 1(-1.2247)-0.5 \\ 0+0.5 & 0-0.5 \\ 2(1.2247)+0.5 & 1(1.2247)-0.5 \end{bmatrix} = \begin{bmatrix} -1.949 & -1.725 \\ 0.5 & -0.5 \\ 2.949 & 0.725 \end{bmatrix}$$

```python
import numpy as np
X = np.array([[1.0, 2.0], [2.0, 3.0], [3.0, 4.0]])
mu = X.mean(axis=0); var = X.var(axis=0)
Xhat = (X - mu) / np.sqrt(var + 1e-5)
gamma = np.array([2.0, 1.0]); beta = np.array([0.5, -0.5])
print(np.round(Xhat, 4))          # [[-1.2247 -1.2247] [ 0.  0. ] [ 1.2247 1.2247]]
print(np.round(gamma * Xhat + beta, 4))  # [[-1.9494 -1.7247] [ 0.5 -0.5 ] [ 2.9494 0.7247]]
```
- **思路**：归一化把每个特征拉到均值 0、方差 1；$\gamma,\beta$ 再各自缩放/平移。注意广播：`gamma`、`beta` 都是形状 `(2,)`，与 `(3,2)` 的 `Xhat` 沿列对齐。
- **点拨**：如果 $\gamma = [1,1]$、$\beta = [0,0]$，$Y$ 就等于 $\hat{X}$——这就是"冻结"的纯归一化。

### 第三组

**3.1 答案：** `weight_decay = 0.01` 惩罚的是 $\lambda\|\mathbf{W}\|_F^2 = 0.01 \sum_{i=1}^{512}\sum_{j=1}^{256} w_{ij}^2$（对全部 $512\times 256$ 个元素求和）。由于 $\|\mathbf{W}\|_F^2 = \sum_k \sigma_k^2$（$\sigma_k$ 是奇异值），惩罚大奇异值、鼓励小奇异值——**在 SVD 视角下，它鼓励 $\mathbf{W}$ 成为"低秩"的变换**：在若干方向上几乎不拉伸，整体表现为一个简单、平滑的线性映射。
- **思路**：$512\times 256$ 权重全被同一个 $\lambda$ 拽小；但因为平方，贡献大的是**大的元素**，也就是大的奇异值方向。
- **点拨**：常见的错误是写成 $\lambda\sum w$（没有平方）或者只对一行求——都不对。`weight_decay` 在优化器里默认作用于**所有**参数张量，一项不落地惩罚整个矩阵的"大小"。

**3.2 答案：** 初始化为 $\gamma = 1$、$\beta = 0$，表示训练开始时网络**不干预归一化**——先让归一化发挥全部稳定作用（均值 0、方差 1），让网络在稳定环境下起步，再让梯度决定要不要恢复尺度与位置。若永远冻结在 $1/0$，归一化就把每层输出**锁死在均值 0、方差 1**——网络失去了自己决定"数据放在哪、以多大规模分布"的能力（教材说的"representational power"），深层网络会表达不足；且经过归一化后梯度传播的尺度也会被固定，无法自调节。
- **思路**：归一化是"为了稳定而削足适履"，$\gamma,\beta$ 是"削完之后把鞋还给你"。冻结 $\gamma,\beta$ = 只削足、不还鞋。
- **点拨**：有人会答"冻结了更稳定所以更好"——不对。稳定是手段，表达是目的；$\gamma,\beta$ 可学习正是 BatchNorm 兼顾两者的关键设计（教材 §2.5.3.4 的原句）。

## 一个"为什么有人会答错"的提醒

1.1 的陷阱是"稀疏 vs 能量"：一个巨大的元素比一堆小元素贡献更大的范数。1.3 与 2.1 的陷阱是 `ord=1` 的名字——它像"元素 1 范数"，实则是"最大列和"；写 L1 正则化时记得用 `np.sum(np.abs(W))`。2.2 的陷阱在直觉层面：很多人以为"L1 和 L2 都会把权重压到 0"——但看梯度就明白，L2 是弹簧力、L1 是恒力，只有恒力能把最后一步走完。
