# 习题：重采样方法（自助法）

## 第一组：概念检验

**1. 用你自己的话解释自助法：它从哪采样、采样多少次、得到什么？**

**解答**：从**原始数据**（一份样本）**有放回**地反复抽样，每次抽同样数量，重复 $B$ 次（教材例 1000）。对每个重采样本算一个统计量（如均值），得到 $B$ 个 $\hat\theta^*$。**这 $B$ 个统计量的分布 = "估计有多准"的答案**——标准差是标准误，分位数是置信区间。不需要第二个总体，数据自己当总体的替身。

**2. 为什么"从数据里有放回抽样"能替代"从总体重复抽样"？**

**解答**：因为样本的**经验分布**（观测值各以 $\frac1n$ 出现）是总体分布的良好近似——样本量足够大时，经验分布收敛到真实分布。自助法就是"从经验分布里重复抽样"，它是"从总体重复抽样"的合法替身。**唯一的风险是：样本本身有偏时，经验分布偏离真实分布，自助法把偏差原样放大。**

**3. 判断题并说明理由："自助法的置信区间适用于任何统计量，不需要它服从正态分布。"**

**解答**：正确。解析置信区间往往要求统计量近似正态（如均值）；自助法的分位数区间只依赖"重采样统计量的经验分布"——中位数、相关系数、分位数、甚至复杂模型的性能指标，都可以用自助法直接给出置信区间。**这是自助法相对解析公式最大的普适优势。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 教材例：500 观测，重采 1000 次估计总体均值。（a）写出每次重采样的做法。（b）代码实现，得到 1000 个均值。（c）计算标准误与 95% 置信区间，与解析 $\sigma/\sqrt n$ 对照。

**解答**：
（a）从 500 个观测**有放回**抽 500 个（`replace=True`），算均值；重复 1000 次。
（b）（c）见《代码.md》层一：自助标准误 0.4469、解析 0.4472、置信区间 $[49.116,50.865]$——几乎一致。

代码验证：

```python
import numpy as np
np.random.seed(0)
data = np.random.normal(50, 10, 500)
bm = [np.random.choice(data, 500, replace=True).mean() for _ in range(1000)]
print("标准误 =", round(np.std(bm), 4), "  95%区间 =", np.percentile(bm, [2.5, 97.5]).round(3))
```

输出：

```text
标准误 = 0.4469  95%区间 = [49.116 50.865]
```

**思路点拨**：若有人忘写 `replace=True`，得到的是"重排后的原数据"，均值恒定——**有放回是自助法的灵魂**：没有它就没有"新的样本"，也就没有分布。

**5. 小样本实验。** 用代码比较 $n=30,200,5000$ 时自助法标准误与解析值，说明"样本量足够大"为什么是前提。

**解答**：见《代码.md》"改个数字试试"。$n=30$ 时自助 1.783 vs 解析 1.826（差约 2%，经验分布太稀疏）；$n=200$ 时几乎相等；$n=5000$ 完全一致。**样本越小，经验分布离真实分布越远，自助法偏差越大**——"样本要足够大"是自助法合法性的前提。

## 第三组：DL 延伸

**6. Bagging 场景。** 你要训练一个集成模型提升稳定性。（a）解释 bagging 与自助法的关系。（b）写出 bagging 的流程。（c）Deep ensemble（训练多个不同种子的神经网络取平均）与严格 bagging 的异同。

**解答**：
（a）**Bagging (bootstrap aggregating) 就是自助法的机器学习版**——用自助采样生成 $B$ 份训练数据、每份训练一个模型、预测取平均。自助法贡献了"重采样生成多份数据"这一核心动作。
（b）对训练集自助采样 $B$ 次 → 得到 $B$ 个自助训练集 → 每个训练一个模型 → 预测时平均 $B$ 个模型的输出。随机森林 = bagging + 随机特征。
（c）Deep ensemble 训练多个**不同初始化种子**的神经网络取平均——与严格 bagging 的异同：相同点是"多个模型 + 平均 = 方差下降 + 不确定性估计"；不同点是 bagging 靠**重采样数据**制造多样性，deep ensemble 靠**不同初始化/数据顺序**制造多样性。**但两者继承的是同一个思想：用多个模型的差异，估计单个模型的不确定。**
**思路点拨**：若有人答"bagging 就是多训练几个模型"，他漏了"重采样数据"这一关键——bagging 的多样性来自数据，不是来自随机初始化。若有人答"deep ensemble 就是 bagging"，严格说不同——但思想上同源，都可以用本节"重采样→多模型→分布"的骨架理解。
