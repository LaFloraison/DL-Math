# 代码：给数据提取"结构指纹"——TDA 送给深度学习的礼物

主线里说，TDA + 深度学习的核心姿势之一是**特征提取**：把数据的拓扑结构（环的持久性、组件的存活长度）变成向量，喂给网络。本节代码把这个承诺做出来——从 §9.4.1 的 `ph0`/`ph1` 里提炼一个**拓扑特征向量**，用它区分"圆环分布"和"随机分布"。

实验剧本：**坐标上很难区分的两类数据，靠一个拓扑特征（最长 H1 持久性）就能干净地分开。** 这就是"结构信息是免费的判别信号"——也是 §9.5.1 圆形 vs 方形分类的微缩版。脚本复用 §9.4.1 的持久同调实现（只依赖标准库 `math` + NumPy 生成噪声）。

---

## 层一：完整脚本

```python
import numpy as np, math

# ---- 复用 §9.4.1：持久 H0 与 H1（此处略去完整实现，见 §9.4.1 代码.md）----
def ph0(points): ...      # 返回 (出生, 死亡) 对的列表（连通分量）
def ph1(points): ...      # 返回 (出生, 死亡) 对的列表（环）

def topological_feature_vector(points):
    """把点云变成 2 维拓扑特征向量：[最长 H0 持久性, 最长 H1 持久性]。"""
    h0 = ph0(points)
    h1 = ph1(points)
    max_h0 = max(d - b for b, d in h0 if d != float('inf'))    # 最长有限 H0 存活
    max_h1 = max(d - b for b, d in h1 if d != float('inf')) if h1 else 0.0
    return round(max_h0, 3), round(max_h1, 3)

circ = [(math.cos(2*math.pi*k/8), math.sin(2*math.pi*k/8)) for k in range(8)]
print("=== 结构指纹：圆环 vs 随机分布（不同种子）===")
print(f"圆       : {topological_feature_vector(circ)}")
for seed in (0, 1, 2, 3):
    rng = np.random.default_rng(seed)
    noise = [(float(a), float(b)) for a, b in rng.uniform(-1, 1, (8, 2))]
    print(f"噪声 seed{seed}: {topological_feature_vector(noise)}")
```

运行输出（Python 3.11 + NumPy）：

```text
=== 结构指纹：圆环 vs 随机分布（不同种子）===
圆       : (0.765, 1.082)
噪声 seed0: (1.295, 0.0)
噪声 seed1: (0.923, 0.088)
噪声 seed2: (0.718, 0.0)
噪声 seed3: (0.759, 0.113)
```

读这组输出——看**第二列（最长 H1 持久性）**：

- **圆**：H1 持久性 **1.082**——它有一个活过 1.082 个尺度的环；
- **噪声（4 个种子）**：H1 持久性 **0.0 ~ 0.113**——没有一个超过 0.12，全是没有持久环的随机排列。

**一个数字就把两类分开了**：设定阈值 0.5，圆（1.08 > 0.5）与噪声（< 0.12）零误差分离。第一列（H0 持久性）在两类之间没有清晰的规律（噪声甚至更高）——**只有 H1 那列是"结构指纹"里的判别特征**。这就是教材说的"用数据的自然形状与结构，改进学习方法"的微观演示。

## 层二：分步逐函数拆解

### 步骤 1：`topological_feature_vector` —— 把持久图压缩成向量

```python
def topological_feature_vector(points):
    h0 = ph0(points)
    h1 = ph1(points)
    max_h0 = max(d - b for b, d in h0 if d != float('inf'))
    max_h1 = max(d - b for b, d in h1 if d != float('inf')) if h1 else 0.0
    return round(max_h0, 3), round(max_h1, 3)
```

#### `topological_feature_vector` —— 持久图 → 特征向量

**做什么**：把 §9.4.1 的持久数据（一列"出生/死亡"对）压缩成 2 个数字——最长 H0 持久性、最长 H1 持久性。
**操作**：对 H0，取所有**有限**死亡的分量的 `death - birth` 最大值；对 H1，若存在环则取最长持久，没有环则返回 0。
**输入**：`points`（n×2 点云）。
**输出**：`(最长H0持久, 最长H1持久)` 元组。
**可调参数**：把"取最大"换成"取前 k 个持久性的和"或"持久图全向量的归一化版本"（如 persistence landscape 的采样），可以让特征更丰富——但本脚本用"最长 H1 持久"这一个数字就足以区分圆与噪声，说明**结构特征可以极简**。
**对应数学**：这是从持久图到固定维度向量的"压缩"——深度学习的输入必须是固定形状，持久图（变长的点列）不能直接喂，所以压缩成向量是 TDA→DL 的关键一步。

---

### 步骤 2：数据与对比输出

```python
circ = [(math.cos(2*math.pi*k/8), math.sin(2*math.pi*k/8)) for k in range(8)]
for seed in (0, 1, 2, 3):
    rng = np.random.default_rng(seed)
    noise = [(float(a), float(b)) for a, b in rng.uniform(-1, 1, (8, 2))]
    print(f"噪声 seed{seed}: {topological_feature_vector(noise)}")
```

**做什么**：一组圆、四组随机噪声（不同种子），各算特征向量。
**操作**：`rng.uniform(-1,1,(8,2))` 生成 [-1,1]² 上的 8 个随机点；`default_rng(seed)` 保证可复现。
**输入**：无。
**输出**：五组特征向量。
**可调参数**：`seed` 控制噪声样本——四种噪声 H1 都在 0.12 以下，说明"噪声没有持久环"是**稳健规律**，不是某个种子的侥幸。也可以把噪声点数从 8 改成 50——H1 持久性会略升（更多点更容易偶然围出环），但依然远低于圆的 ~1.08。
**对应数学**：这正是 §9.5.1 那个"圆形 vs 方形"例子的准备——那里的核心同样是"圆的持久环 vs 方形的无持久环"。

## 改个数字试试：给圆加噪声，结构指纹还灵吗？

```python
circ_noisy = circ + [(0.3, 0.4), (-0.4, -0.2)]
print(f"圆+2噪声   : {topological_feature_vector(circ_noisy)}")
```

```text
圆+2噪声   : (0.765, 0.452)
```

加两个噪声点后，H1 持久性从 1.082 掉到 **0.452**——环还在（> 0.3），但被削弱了（噪声点连出的弦提前填实三角形）。**结论：结构指纹对轻微噪声仍能识别（圆 > 噪声），但对明显污染会变弱**——这呼应教材 §9.5.1 的工程提醒：**提取拓扑特征时，尺度参数与噪声控制必须细心设置**，否则特征会被污染。

## 边界声明：这套代码能做什么，不能做什么

1. **它演示了"特征提取"的雏形，不是完整的 TDA 分类管线**。真正的 TDA+DL 会：对每个样本构造更丰富的拓扑特征（多维度持久性、persistence landscape）、用网络处理、并做统计显著性检验。本节只展示"结构信息确实能判别数据"。
2. **"最长 H1 持久"是启发式特征，不是最优点**。它在此例中判别力强，但换数据集（如噪声点特别多）会退化；真实实践用整个持久图/条形码的变换特征（landscape、持久熵）更稳健。**特征选择本身就是 TDA+DL 的开放问题。**
3. **计算代价与参数敏感没有消失**。§9.5.1 会列出持久同调的全部工程顾虑（计算量、预处理、尺度参数、可解释性）——本节是"证明值得做"，§9.5.1 是"教你做好"。
