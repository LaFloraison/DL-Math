## 第一步：Toy Model —— 给一支箭"验明正身"

一支箭从原点射向 $(3, 4)$。它有两件事是"箭自己的"——不依赖你站在哪看：**它有多长**，和**它朝哪个方向**。

长度好办：勾股定理，$\sqrt{3^2+4^2} = 5$。

方向怎么精确地说？你也许会说"朝右偏上"。可"偏上"多上？工程师要的是一个数字，能写进公式、能比较大小。

量角器量出来是：这条箭与 $x$ 轴的夹角约 $53.13°$。这个数不是靠猜的——它是从两个分量**算**出来的：向上 4、向右 3，$\tan\theta = \frac{4}{3}$，所以 $\theta = \arctan\frac{4}{3} \approx 53.13°$。

于是这支箭被彻底"验明正身"：**长 5，方向 53.13°**。模长和方向，这两个量合起来，唯一地确定了一个向量——就像一个人的身高和籍贯，合起来让你大致认出他是谁。

现在的问题是：这套"用长度和角度描述向量"的方法，在深度学习里有用吗？——答案是：长度和方向有，但**角度**，几乎从来不用。为什么？这一节会给你一个意想不到的答案。

## 第二步：正式数学讲解

### 一、撞墙：用"角度"描述方向，在高维会塌

二维里，方向用一个角度 $\theta$ 就够了。但三维呢？一个方向需要两个角度（像地球的经纬度：经度 + 纬度）。四维？需要三个。**$n$ 维空间里描述一个方向，需要 $n-1$ 个角度**——而且这些角度之间的换算越来越复杂，$\arctan$ 的象限问题（正负号）让人抓狂。

更糟的是：一个角度是"圆的"——$53.13°$ 和 $413.13°$ 是同一个方向（转了一圈）。这种"循环"的数值，在求导、做优化时是灾难：梯度不知道该往哪走（$360°$ 和 $0°$ 明明一样，梯度却不同）。

所以数学家做了一个干脆的决定：**方向不用角度描述，用"单位向量"描述。** $\vec{A}$ 的方向，就是"把 $\vec{A}$ 拉成单位长度"后的那个向量：

$$\hat{\mathbf{A}} = \frac{\vec{A}}{\|\vec{A}\|}$$

它保留了"朝哪"，丢掉了"多长"——一个向量，装下整个方向。这就是我们之前用过的"单位向量"，这一节给它正名：**它是方向的正式数学形式。** 而模长与方向的关系，也在此刻合拢：

> **大小 (magnitude / norm)** $\|\vec{A}\|$
>
> $$\|\vec{A}\| = \sqrt{A_x^2 + A_y^2} \quad (\text{一般地 } \sqrt{\sum_i A_i^2})$$
>
> 向量到原点的距离，衡量"多强、多大"。
>
> **方向 (direction)**
>
> $$\theta = \arctan\frac{A_y}{A_x} \quad (\text{二维，相对 } x \text{ 轴})$$
>
> 或等价地用单位向量 $\hat{\mathbf{A}} = \vec{A}/\|\vec{A}\|$ 表示（任意维数都行）。

### 二、手算 [3,4]：一支箭的完整档案

按教材例子：

$$\|\vec{A}\| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = 5$$

$$\theta = \arctan\frac{4}{3} \approx 53.13°$$

注意 $\arctan$ 的两个**陷阱**：

1. **象限问题**。$[3,4]$ 在第一象限，$\arctan(4/3) \approx 53.13°$ 没问题。但 $[-3,4]$ 呢？$\arctan(4/(-3))$ 会给出负角，而真实的 $\theta$ 应该在第二象限（约 $126.87°$）。所以工程上不用裸的 $\arctan$，而用**四象限反正切** $\text{atan2}(A_y, A_x)$，它根据 $A_x$、$A_y$ 的符号自动判断象限。
2. **零分量**。若 $A_x = 0$（纯竖直的向量），$\frac{A_y}{A_x}$ 除以零，$\arctan$ 直接失效。$\text{atan2}$ 同样处理了这个情况。

### 三、为什么"方向=单位向量"才是正道

把方向装进单位向量，有三个压倒性的好处：

1. **任意维数通用**。$n$ 维里 $\hat{\mathbf{A}}$ 还是那一个公式，而角度需要 $n-1$ 个。
2. **没有循环歧义**。$53.13°$ 和 $413.13°$ 是同一个方向，但 $\frac{[3,4]}{5}$ 和 $\frac{[3,4]}{5}$ 是同一个向量——单位向量不含糊。
3. **可直接参与计算**。$\cos\theta = \frac{\vec{A}\cdot\vec{B}}{\|\vec{A}\|\|\vec{B}\|} = \hat{\mathbf{A}}\cdot\hat{\mathbf{B}}$——**两向量夹角的余弦，就是它们单位向量的点积**。相似度、余弦相似度、注意力权重，全靠这条公式，而不需要真的求出角度。

边界声明：角度 $\theta$ 仍然在二维几何、旋转、正弦/余弦表达式中活跃（§2.5.2.1 缩放、旋转会用到），但它作为"方向的载体"在高维世界被单位向量取代了。记住分工：**模长回答"多大"，单位向量回答"朝哪"，角度只是二维时的辅助工具。**

## 第三步：DL 桥接

**余弦相似度 (cosine similarity)** 是深度学习里衡量"两个向量有多像"的第一工具，它的定义就是本节公式的直接应用：

$$\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|} = \hat{\mathbf{a}}\cdot\hat{\mathbf{b}}$$

它最漂亮的性质是**尺度无关**：$\mathbf{a}$ 和 $10\mathbf{a}$ 的余弦相似度完全相同（方向一样）。这在检索里至关重要——搜"猫"的嵌入和文档中"猫"的嵌入可能长度不同（一个模型长、一个文本长），但方向一致，余弦相似度就是 1。

**模长在哪里出现？** 处处是正则化与约束：

- **L2 正则化（权重衰减）**：在损失里加 $\lambda\|\mathbf{w}\|^2$，惩罚权重向量的"长度"——让模型不依赖"巨大的权重"，而是用"方向正确的权重"。§2.3.6.6 会专门讲。
- **梯度裁剪 (gradient clipping)**：训练时若梯度 $\nabla L$ 的模长超过阈值，就把它**等比例缩小**到阈值以内——只改变梯度的"大小"，不改"方向"。这正是"模长与方向分离"思想在训练里的直接应用。
- **归一化**：特征向量除以模长（单位化），让"方向"成为唯一信号——softmax 前的 logits 缩放、对比学习的温度参数，都围绕"模长是否被正确归一"打转。

一句话：**深度学习几乎从不关心"方向是几度"，它只关心"两个方向有多一致"（余弦相似度）和"这个向量有多大"（模长）**。而这两者，正是本节"大小与方向"的两种数学化身。
