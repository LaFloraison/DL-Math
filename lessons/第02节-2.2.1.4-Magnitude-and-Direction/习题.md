# 习题：大小与方向

## 第一组：概念检验

**1.1（单选）** 向量 $\vec{A} = [6, 8]$ 的模长和与 $x$ 轴的夹角（约）分别是：
- A. 10 与 53.13°
- B. 14 与 36.87°
- C. 10 与 36.87°
- D. 100 与 53.13°

**1.2（判断并说明）** "`np.arctan2(y, x)` 和 `np.arctan(y/x)` 永远给出相同的结果。" 这句话对吗？

**1.3（填空）** 在深度学习里，"方向"的标准数学表示是____，而不是角度；衡量两个向量相似度常用____，它等于两个____向量的点积。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 向量 $\vec{A} = [1, \sqrt{3}]$。手算模长与方向角（用 $\arctan$），再用 `np.linalg.norm` 与 `np.arctan2` 验证。

**2.2（代码验证）** 对四个向量 $[3,4]$、$[-3,4]$、$[-3,-4]$、$[3,-4]$，分别用 `np.arctan2` 求方向角，观察结果覆盖 $(-180°,180°]$ 的哪些范围，验证四象限处理。

**2.3（动手理解）** 验证余弦相似度的尺度无关性：构造 $\mathbf{a}$，计算 $\cos(\mathbf{a}, 2\mathbf{a})$、$\cos(\mathbf{a}, 5\mathbf{a})$、$\cos(\mathbf{a}, -2\mathbf{a})$，解释各结果。

## 第三组：DL 延伸

**3.1（场景判断）** 一个向量检索系统用余弦相似度排序。两个文档的嵌入 $\mathbf{d}_1$、$\mathbf{d}_2$ 与查询 $\mathbf{q}$ 的夹角分别是 $10°$ 和 $10°$，但 $\|\mathbf{d}_1\| = 100$、$\|\mathbf{d}_2\| = 1$。系统会认为哪个文档更相关？这个结果反映了余弦相似度的什么特性？

**3.2（场景分析）** 训练中梯度 $\nabla L$ 的模长突然从 $0.1$ 涨到 $1000$，训练开始震荡。工程上常用"梯度裁剪"把模长压回 $1.0$。请说明：裁剪操作改变了梯度的什么、不改变什么？为什么这样能稳定训练？

## 解答与思路点拨

### 第一组

**1.1 答案：A（10 与 53.13°）。**
- **思路**：$\|\vec{A}\| = \sqrt{6^2+8^2} = \sqrt{36+64} = 10$。方向角 $\tan\theta = \frac{A_y}{A_x} = \frac{8}{6} = \frac{4}{3}$，$\theta = \arctan\frac{4}{3} \approx 53.13°$。
- **点拨**：这里的坑是把 $\frac{A_y}{A_x}$ 记成 $\frac{A_x}{A_y}$——那是 $36.87°$（选项 C 的诱饵），因为 $\arctan(3/4) \approx 36.87°$。**分子是 $y$ 分量，分母是 $x$ 分量**（$\tan\theta = \frac{\text{对边}}{\text{邻边}}$）。$[6,8]$ 是 $[3,4]$ 的两倍，方向角应与 $[3,4]$ 相同（都是 $53.13°$）——这本身就是个快速自检：**倍数不改变方向角。**

**1.2 不对。**
- **思路**：两者只在 $x>0$（第一、四象限）且 $x\neq0$ 时一致。当 $x<0$，`arctan(y/x)` 把角度落在 $(-90°,90°)$，丢失象限信息；`atan2` 则返回正确的 $(-180°,180°]$ 角度。例：`arctan2(4,-3) ≈ 126.87°`，而 `arctan(4/(-3)) ≈ -53.13°`。
- **点拨**：**工程代码永远用 `atan2`**。看到 `arctan` 处理向量方向，先怀疑象限 bug。

**1.3 答案：单位向量；余弦相似度；单位向量。**
- **思路**：方向 $\to$ 单位向量 $\hat{\mathbf{A}}$；相似度 $\to$ 余弦相似度 $\cos\theta = \hat{\mathbf{a}}\cdot\hat{\mathbf{b}}$（单位向量点积）。
- **点拨**：这是"角度在高维退役、单位向量登基"的浓缩版。

### 第二组

**2.1**
$\|\vec{A}\| = \sqrt{1 + 3} = 2$。$\tan\theta = \frac{\sqrt{3}}{1} = \sqrt{3}$，$\theta = \arctan\sqrt{3} = 60°$。

```python
import numpy as np
A = np.array([1.0, np.sqrt(3)])
print(np.linalg.norm(A))                                # 2.0
print(np.degrees(np.arctan2(A[1], A[0])))               # 60.0
```
- **思路**：这是特殊角 $\sqrt{3}$ 与 $60°$——熟悉常用角的三角函数值能大大提速。
- **点拨**：单位圆上，$\cos60°=1/2$、$\sin60°=\sqrt{3}/2$，恰好对应这个向量的单位化结果 $[0.5, \sqrt{3}/2]$。

**2.2**
```python
import numpy as np
pts = [[3.,4.], [-3.,4.], [-3.,-4.], [3.,-4.]]
for p in pts:
    print(np.degrees(np.arctan2(p[1], p[0])))
# 53.13  126.87  -126.87  -53.13
```
- **思路**：一、二象限给正角，三、四象限给负角（或 $180°+\theta$），覆盖范围 $(-180°, 180°]$，四个象限各归其位。
- **点拨**：这就是 `atan2` 相对 `arctan` 的全部价值——**自动判断象限**。写一次循环观察它，比背十遍文档都记得牢。

**2.3**
```python
import numpy as np
a = np.array([1.0, 2.0])
def cos(u, v): return np.dot(u, v)/(np.linalg.norm(u)*np.linalg.norm(v))
print(cos(a, 2*a), cos(a, 5*a), cos(a, -2*a))
# 1.0  1.0  -1.0
```
- **思路**：正倍数不改变方向 → 相似度 1；负倍数反转方向 → 相似度 $-1$。尺度（模长）被完全抵消。
- **点拨**：`-1.0` 的含义是"方向完全相反"——这在语义上就是"彻底不相关/相对"。注意力机制里负的点积对应"忽略"。

### 第三组

**3.1 答案：系统认为两个文档**同样相关**（相似度都是 $\cos 10°$，与模长无关）。**
- **思路**：余弦相似度只比较方向，不看长度。$\mathbf{d}_1$、$\mathbf{d}_2$ 与 $\mathbf{q}$ 夹角相同 → 相似度相同 → 排序并列。即使 $\|\mathbf{d}_1\|=100$、$\|\mathbf{d}_2\|=1$。
- **点拨**：这是余弦相似度的**双刃剑**——优点：长度不影响（长短文本可比）；缺点：如果"长度"本身承载信息（如文档篇幅重要），余弦会丢。需要长度时用欧氏距离或"点积相似度"（未归一化）。
- **为什么有人答错**：直觉上"模长大 = 更相关"。余弦相似度的设计恰恰是**消除**这个直觉依赖——它是"方向"的度量，不是"强度"的度量。

**3.2 思路**
- 梯度裁剪 $\nabla L \leftarrow \min(1, \frac{1.0}{\|\nabla L\|})\nabla L$：当模长超过阈值 $1.0$，把**整个梯度向量按同一比例缩小**，使模长回到 $1.0$。
- 改变的是：**大小（模长）**。不改变的是：**方向（单位向量 $\nabla L/\|\nabla L\|$）**。
- 为什么能稳定训练：梯度方向才是"该往哪个方向走"的信息；模长只是"走多快"。模长暴涨（爆炸梯度，exploding gradient）会让一步迈出十万八千里，直接越过最优解甚至产生 NaN。裁剪把"步长"限制住，但保留"正确的方向"——这正是"模长与方向分离"思想的工程应用：**大小可牺牲，方向不可牺牲。**
- **点拨**：梯度裁剪是 RNN/Transformer 训练的标配。它与 L2 正则化（惩罚权重模长）形成对照：一个管"梯度的步长"，一个管"权重的长度"。
