# 代码：量出向量的"身高"与"籍贯"——模长、方向角、单位向量

主线里我们学了：模长用勾股定理，方向角用 $\arctan$，但真正在深度学习里常用的是单位向量（方向）与余弦相似度。这一节用 NumPy 把这些全部算出，并**演示 `atan2` 比 `arctan` 高明在哪**——这是最容易踩坑的地方。

---

## 层一：完整脚本

```python
import numpy as np                               # NumPy：norm / arctan2 / arccos

# ---- ① 教材例子：向量 (3, 4) ----
A = np.array([3.0, 4.0])
mag = np.linalg.norm(A)                          # 模长 = 5
theta = np.degrees(np.arctan2(A[1], A[0]))       # 方向角 = 53.13°
print(f"A = {A} | 模长 = {mag:.2f} | 方向角 = {theta:.2f}°")

# ---- ② atan2 vs arctan：象限陷阱 ----
B = np.array([-3.0, 4.0])                        # 第二象限
print(f"B = {B}")
print(f"  裸 arctan: {np.degrees(np.arctan(B[1]/B[0])):.2f}°  (错!)")
print(f"  atan2:     {np.degrees(np.arctan2(B[1], B[0])):.2f}°  (对)")

# ---- ③ 方向 = 单位向量 ----
A_hat = A / np.linalg.norm(A)
print(f"单位向量 Â = {np.round(A_hat, 4)} | 模长 = {np.linalg.norm(A_hat):.2f}")

# ---- ④ 余弦相似度：不用求角度，直接用单位向量点积 ----
C = np.array([6.0, 8.0])                         # 与 A 同向、长度 10
cos_sim = np.dot(A_hat, C / np.linalg.norm(C))
print(f"cos(A, C) = {cos_sim:.4f}  → 夹角 = {np.degrees(np.arccos(np.clip(cos_sim, -1, 1))):.2f}°")

# ---- ⑤ 尺度无关性：把 A 放大 10 倍，余弦相似度不变 ----
A_big = 10.0 * A
cos2 = np.dot(A_big / np.linalg.norm(A_big), C / np.linalg.norm(C))
print(f"cos(10A, C) = {cos2:.4f}  (与 cos(A,C) 相同：尺度无关)")
```

运行输出（Python 3.11 + NumPy）：

```text
A = [3. 4.] | 模长 = 5.00 | 方向角 = 53.13°
B = [-3.  4.]
  裸 arctan: -53.13°  (错!)
  atan2:     126.87°  (对)
单位向量 Â = [0.6 0.8] | 模长 = 1.00
cos(A, C) = 1.0000  → 夹角 = 0.00°
cos(10A, C) = 1.0000  (与 cos(A,C) 相同：尺度无关)
```

下面拆开看每一步。

## 层二：分步逐函数拆解

### 步骤 1：模长与方向角

```python
mag = np.linalg.norm(A)
theta = np.degrees(np.arctan2(A[1], A[0]))
```

#### `np.linalg.norm(A)` —— 模长

**操作**：$\sqrt{3^2+4^2}=5$。上节课已拆解，这里直接使用。
**输入**：`A`（形状 `(2,)`）。
**输出**：标量 `5.00`。
**可调参数**：同 §2.2.1.1（`ord`、`axis`）。

#### `np.arctan2(y, x)` —— 四象限反正切

**操作**：给定 $y$ 和 $x$，返回从 $x$ 轴正方向逆时针到 $(x,y)$ 的夹角（弧度），范围 $(-180°, 180°]$。它同时看两个分量的**符号**来判断象限。
**输入**：`A[1]=4.0`（$y$）、`A[0]=3.0$（$x$）。
**输出**：`0.9273` 弧度，`np.degrees` 转成 `53.13°`。
**可调参数**：**顺序是 (y, x)，不是 (x, y)**——写反是最高频的错误，结果直接变成角的余角。`np.arctan`（单参数）没有象限判断，工程与数学代码一律用 `atan2`。
**对应数学**：主线 $\theta = \arctan\frac{A_y}{A_x}$ 的工程版——`atan2` 自动处理象限与除零。

### 步骤 2：`atan2` vs `arctan` 的象限陷阱

```python
print(np.degrees(np.arctan(B[1]/B[0])))    # -53.13° (错)
print(np.degrees(np.arctan2(B[1], B[0])))  # 126.87° (对)
```

**做什么**：对第二象限的 $[-3,4]$，演示两种函数的差异。
**操作**：`B[1]/B[0] = 4/(-3) ≈ -1.333`，`arctan(-1.333) = -53.13°`——因为 $\arctan$ 的值域只有 $(-90°,90°)$，它"不知道" $x$ 为负。而 `atan2(4, -3)` 看符号：$x<0, y>0$ → 第二象限 → `126.87°`。
**可调参数**：把 `B` 换成 `[3,-4]`（第四象限），`arctan` 仍错、`atan2` 仍对（`-53.13°`）。四个象限各试一遍，`atan2` 永远正确。
**对应数学**：主线"$\arctan$ 的象限问题"。这正是历史里"一维反函数装不下二维方向"的教训在代码里的回声。

### 步骤 3：单位向量

```python
A_hat = A / np.linalg.norm(A)
```

**操作**：每个分量除以模长：`[3,4]/5 = [0.6, 0.8]`，模长恒为 1。
**输入**：`A` 与标量 `5`。
**输出**：`[0.6, 0.8]`。
**可调参数**：任何非零向量都可单位化；零向量会得 `[nan, nan]`，务必先判断。
**对应数学**：主线"方向 = 单位向量"——$\hat{\mathbf{A}} = \vec{A}/\|\vec{A}\|$。

### 步骤 4：余弦相似度

```python
cos_sim = np.dot(A_hat, C / np.linalg.norm(C))
```

**操作**：先单位化 `C`，再与 `Â` 点积。`C=[6,8]` 与 `A` 同向，单位化后都是 `[0.6,0.8]`，点积 `1.0`，夹角 `0°`。
**输入**：`A_hat`（`(2,)`）、`C`（`(2,)`）。
**输出**：标量 `1.0`。
**可调参数**：改成 `np.dot(A/np.linalg.norm(A), B/np.linalg.norm(B))` 一行完成；如果想算夹角再补 `arccos`。
**对应数学**：主线 $\cos\theta = \hat{\mathbf{a}}\cdot\hat{\mathbf{b}}$。这是深度学习里衡量相似度的标准操作——**不需要真的算角度**。

### 步骤 5：尺度无关性

```python
A_big = 10.0 * A
cos2 = np.dot(A_big / np.linalg.norm(A_big), C / np.linalg.norm(C))
```

**操作**：`10*A` 单位化后还是 `[0.6,0.8]`——因为模长也被放大 10 倍，比例抵消。`cos2 = 1.0`，与 `cos(A,C)` 相同。
**可调参数**：任意正常数 $k$，`cos(kA, C) = cos(A, C)`。这就是余弦相似度的**尺度无关性 (scale invariance)**。
**对应数学**：主线"模长只回答多大，单位向量装方向"——放大不改变方向，所以不改变余弦相似度。检索系统依赖这条性质：文本长短不一（模长不同），只要方向一致就相似。

## 边界声明：这套代码能做什么，不能做什么

1. **`atan2` 的参数顺序是 (y, x)**。无数 bug 源于此。看到 `np.arctan2(a, b)` 先确认第一个是 $y$（纵坐标）。可以加注释防呆。
2. **角度只在二维"亲切"**。到了 3 维要 2 个角，$n$ 维要 $n-1$ 个，工程上几乎不可用。所以深度学习的"方向"一律用单位向量，余弦相似度用点积。看到模型代码里出现"角度"超参（如旋转增强的 $\theta$），那通常只是二维视觉任务里的特例。
3. **余弦相似度不等于"向量距离"**。它衡量方向一致性，对"长度"失明：一个向量及其 100 倍版本相似度为 1。如果应用需要"大小也重要"（如权重正则化），要结合模长（如 L2 距离 $\|\mathbf{a}-\mathbf{b}\|$）一起用。
4. **`np.linalg.norm` 对大批量逐行算模长要传 `axis`**：`np.linalg.norm(X, axis=1)` 对一个 `(B, d)` 的批量返回 `B` 个模长。不传 `axis` 会把整个矩阵拍成一个数——§2.4 张量里会专门讲。
