# 代码：记一本只增的账本——Adagrad 的自适应与学习率衰减

**目标**：主线里教材例 $f(x,y)=x^2+2y^2$，$\alpha=0.1$，$x_0=y_0=2$，第 2 步 $x_2\approx1.831$。这里复现这个例子，并用两个诚实的实验看清 Adagrad 的性格：**(a)** 虽然 $y$ 的梯度是 $x$ 的两倍，归一化步长却相等（自适应"拉平尺度"）；**(b)** 账本只增不减会让步长持续收缩——在同一问题上 Adagrad 比 GD **慢得多**，在"梯度不消失"的问题上步长一路衰减到趋近零（"学习率死亡"的现场）。全部裸 NumPy。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 教材例: f(x,y) = x^2 + 2y^2, alpha=0.1, eps=1e-8 ----
alpha, eps = 0.1, 1e-8
x, y = 2.0, 2.0
Gx, Gy = 0.0, 0.0                       # 账本: 历史梯度平方和

print("--- 教材例: 前 2 步 (对照教材 x2≈1.831) ---")
for t in range(1, 3):
    gx, gy = 2.0 * x, 4.0 * y            # 梯度: df/dx=2x, df/dy=4y
    Gx += gx ** 2; Gy += gy ** 2         # 记账 (只增不减)
    x = x - alpha * gx / (np.sqrt(Gx) + eps)
    y = y - alpha * gy / (np.sqrt(Gy) + eps)
    print(f"iter{t}: gx={gx:.2f} gy={gy:.2f}  x={x:.4f} y={y:.4f}")

# ---- 2. 诚实对照: f(x)=x^2 上 Adagrad vs GD 谁先到 x<0.01 ----
def steps_to(use_ada):
    x, G = 2.0, 0.0
    for t in range(1, 20000):
        g = 2.0 * x
        if use_ada:
            G += g ** 2
            x = x - alpha * g / (np.sqrt(G) + eps)
        else:
            x = x - alpha * g
        if abs(x) < 0.01: return t
    return 20000

print(f"\n--- f(x)=x^2 上到达 x<0.01 所需步数 ---")
print(f"Adagrad: {steps_to(True)} 步  |  GD: {steps_to(False)} 步")

# ---- 3. 学习率死亡: f(x)=x (梯度恒=1), 看步长一路衰减 ----
print(f"\n--- f(x)=x (梯度恒为 1), 步长随时间单调衰减 ---")
x, G = 0.0, 0.0
for t in range(1, 10001):
    G += 1.0                             # 梯度恒=1, 账本= t
    x = x - alpha / (np.sqrt(G) + eps)   # 步长 = alpha/sqrt(t)
    if t in (1, 10, 100, 1000, 10000):
        print(f"t={t:5d}: 步长={alpha/(np.sqrt(G)+eps):.2e}  x={x:.4f}")
```

输出（可复现）：

```

iter1: gx=4.00 gy=8.00  x=1.9000 y=1.9000

--- f(x)=x^2 上到达 x<0.01 所需步数 ---
Adagrad: 551 步  |  GD: 24 步

--- f(x)=x (梯度恒为 1), 步长随时间单调衰减 ---

t=   10: 步长=3.16e-02  x=-0.5021
t=  100: 步长=1.00e-02  x=-1.8590
t= 1000: 步长=3.16e-03  x=-6.1801
t=10000: 步长=1.00e-03  x=-19.8545
```

**三个现象，Adagrad 的全部性格**：(1) 教材例里 $y$ 的梯度（8）是 $x$（4）的两倍，归一化后 $x_1=y_1=1.9$——**账本拉平尺度**；(2) 同一问题上 Adagrad 要 551 步到 $x<0.01$，GD 只要 24 步——**Adagrad 慢 23 倍**，因为步长在收缩；(3) 恒定梯度下步长从 0.1 一路衰减到 0.001，$x$ 只走了 $\sqrt{t}$ 级距离（10000 步才到 -19.85）——**"学习率死亡"：梯度还在，进步却越来越慢，最终趋近停滞。**

## 层二：分步逐函数拆解

### 步骤 1：教材例——前 2 步

```python
gx, gy = 2.0 * x, 4.0 * y
Gx += gx ** 2; Gy += gy ** 2         # 记账 (只增不减)
x = x - alpha * gx / (np.sqrt(Gx) + eps)
```

#### 记账 `Gx += gx**2`

**操作**：$g_{t,i}=g_{t-1,i}+g_{t,i}^2$——**账本 = 历史梯度平方的累加**。**关键**：`+=` 是累加，**只增不减**——Adagrad 全部性格的源头。
**输入**：`Gx`（旧账本）、`gx`（当前梯度）。**输出**：新账本。
**可调参数**：无。**注意**：$y$ 的账本（64）是 $x$（16）的四倍，因为 $y$ 梯度大。

#### 更新 `x = x - alpha * gx / (np.sqrt(Gx) + eps)`

**操作**：$\theta_{t+1,i}=\theta_{t,i}-\frac{\alpha}{\sqrt{g_{t,i}}+\varepsilon}\nabla f$——**逐参数学习率**是 $\frac{\alpha}{\sqrt{G}+\varepsilon}$。
**输入**：`x`、`alpha`、`Gx`、`gx`、`eps`。**输出**：更新后的 `x`。
**可调参数**：`eps=1e-8` 防除零；`alpha` 是全局基准。
**为什么 $x_1=y_1$？** $x$ 更新量 $=\frac{0.1}{\sqrt{16}}\times4=0.1$；$y$ 更新量 $=\frac{0.1}{\sqrt{64}}\times8=0.1$——**梯度大两倍、账本平方根后也大两倍，恰好抵消**。归一化"拉平"了尺度差异。

**对应数学**：主线定义块的 Adagrad 更新规则。

---

### 步骤 2：诚实对照——Adagrad 在光滑问题上反而慢

```python
def steps_to(use_ada):
    x, G = 2.0, 0.0
    for t in range(1, 20000):
        g = 2.0 * x
        if use_ada:
            G += g ** 2
            x = x - alpha * g / (np.sqrt(G) + eps)
        else:
            x = x - alpha * g
        if abs(x) < 0.01: return t
    return 20000
```

#### `steps_to` —— 数到收敛的步数

**操作**：在 $f(x)=x^2$ 上从 $x=2$ 出发，数两种方法各需多少步把 $|x|$ 压到 0.01 以下。
**输入**：`use_ada`（bool）。**输出**：步数。
**可调参数**：阈值 `0.01`、`alpha`。
**结果**：Adagrad 551 步 vs GD 24 步。**为什么 Adagrad 慢？** GD 步长恒为 $\alpha$，按几何级数收敛（$x_t=2\times0.8^t$）；Adagrad 的账本不断累积，步长 $\alpha/\sqrt{G}$ 持续收缩——**前几步尚可，越走越慢**。

**对应数学**：主线"学习率随时间显著下降、阻碍进展"——在光滑凸问题上，Adagrad 的"自适应"反而拖慢收敛。

---

### 步骤 3：学习率死亡——梯度不消失时的慢性衰减

```python
for t in range(1, 10001):
    G += 1.0
    x = x - alpha / (np.sqrt(G) + eps)
```

**操作**：用 $f(x)=x$（梯度恒为 1）作为"极端但清晰"的演示——**梯度永不消失，账本 $G=t$ 永远增长，步长 $\alpha/\sqrt{t}$ 永远衰减**。
**输入**：无。**输出**：每千步打印步长与位置。
**看点**：步长从 0.1 → 0.001（100 倍收缩），而 $x$ 只移动到 -19.85（$\sqrt{t}$ 级增长）——**如果梯度一直存在（比如深度网络的漫长训练），Adagrad 的步长会一路缩到趋近零，训练"名存实亡"。**

**对应数学**：主线"有效学习率不断减小、阻碍非凸问题或长训练下的进展"——Adagrad 的致命伤。

## 实验台：让账本现出原形

1. **换频繁 vs 稀疏**：目标改成 $f(x,y)=x^2+0.01y^2$（$y$ 是"稀疏特征"）——Adagrad 给 $y$ 相对更大的步长（账本小）。**"不频繁但重要的特征获得大更新"的现场**——这正是它在稀疏数据（词向量）上的价值。
2. **对比 RMSprop（§5.6.6 预告）**：把 `G += g**2` 改成 `0.9*G + 0.1*g**2`（滑动平均）——步长不再归零，在 $f(x)=x$ 上也能持续前进。**"只增账本" vs "滑动账本"一字之差，生死之别。**
3. **画收敛曲线**：$f(x)=x^2$ 上画 Adagrad 与 GD 的 loss-epoch 曲线——Adagrad 先快后慢，GD 匀速——"自适应"在光滑问题上的代价一目了然。
4. **用 torch.optim.Adagrad**：`torch.optim.Adagrad([x], lr=0.1)` 解同一问题，结果与裸核一致——**本脚本就是它的"说明书"**。

**对应数学**：实验 2 直接预告 §5.6.6 的 RMSprop——它是 Adagrad 的"换账本"版本，也是 Adam 二阶矩的来源。
