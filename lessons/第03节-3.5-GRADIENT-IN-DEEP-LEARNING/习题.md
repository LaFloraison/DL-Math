# 习题：深度学习中的梯度

## 一、概念检验

### 题 1.1（填空）

反向传播中，浅层权重的梯度是各层局部导数的____（运算）。当这些局部导数都小于 1 时，梯度随层数____衰减，称为____梯度；当都大于 1 时，梯度____，称为____梯度。应对后者的常用手段是____。

**解答**：连乘（乘积）；指数（几何）；消失（vanishing）；爆炸（exploding）；梯度裁剪（gradient clipping）。
**思路点拨**：三个关键词连成一条因果链——连乘 → 指数衰减/放大 → 消失/爆炸。答错"求和"的同学要记住：**链式法则让梯度沿层相乘**（§3.6.2 的 Jacobian 连乘），乘积才是病根。梯度裁剪是"只改大小不改方向"的刹车，不要和"正则化"（惩罚大权重）混为一谈。

### 题 1.2（选择）

以下能**直接缓解梯度消失**的是（ ）

A. 增大学习率
B. 使用 ReLU 激活
C. 梯度裁剪
D. 增大 batch size

**解答**：B。
**思路点拨**：ReLU 正区导数恒为 1，放进连乘不衰减——这是治消失的直接手段。梯度裁剪（C）治的是**爆炸**；增大学习率（A）会加剧震荡甚至爆炸；增大 batch size（D）影响的是梯度估计的噪声，与消失无关。选 C 的同学混淆了消失与爆炸这对孪生病的解药——**消失用"放行"（ReLU、LSTM、归一化），爆炸用"刹车"（裁剪）**。

### 题 1.3（简答）

在鞍点处，梯度为零但既不是极大也不是极小。请用 $f(x,y) = x^2 - y^2$ 解释"为什么梯度下降会在这里卡住"，并说明自适应优化器（Adam）为何能部分应对。

**解答**：在原点，$\nabla f = (2x, -2y) = (0,0)$，梯度为零意味着"没有前进信号"——沿 $x$ 方向是谷（二阶偏导 +2），沿 $y$ 方向是峰（二阶偏导 $-2$），所以它不是极值点。朴素的梯度下降在梯度为零处直接停摆（更新量为 $\eta \cdot 0 = 0$）。Adam 等自适应优化器带着**动量**（梯度历史的方向惯性）和**自适应步幅**（每个参数按历史梯度大小单独缩放），即使某一步梯度为零，动量仍可能把它"带出"鞍部继续前进，且不会因为在鞍点附近梯度极小就完全冻住。
**思路点拨**：能说出"梯度为零 → 更新量为零 → 卡住"以及"动量提供穿出鞍部的惯性"，就掌握了鞍点问题的机制。注意：Adam 能**穿过**鞍点，但不保证**到达全局最优**——它依然受困于局部最优（§3.5 边界声明）。

## 二、计算实践

### 题 2.1（手算）

一个 30 层网络，假设每层局部导数都是 0.8（不现实但便于计算）。初始梯度为 1.0。

(a) 梯度穿过 30 层后大约是多少（用指数近似）？
(b) 如果改用每层导数 1.2，梯度穿过 30 层后是多少？
(c) 两种情况下训练会分别出现什么现象？

**解答**：(a) $0.8^{30} = e^{30 \ln 0.8} = e^{30 \times (-0.223)} = e^{-6.69} \approx 1.24 \times 10^{-3}$。(b) $1.2^{30} = e^{30 \ln 1.2} = e^{30 \times 0.182} = e^{5.47} \approx 2.37 \times 10^{2}$。(c) (a) 梯度消失——浅层权重的偏导趋近于 0，前几层几乎学不动，整体欠拟合且训练极慢；(b) 梯度爆炸——权重更新量巨大，损失剧烈震荡、可能跳成 NaN。
**思路点拨**：用 $a^b = e^{b\ln a}$ 把指数算清楚。注意 0.8 和 1.2 离 1 都不远，但 30 层连乘后一个缩到千分之一、一个放大到两百倍——**连乘的指数威力**正是本节的核心直觉。真实网络中局部导数不恒定，但同样的定性规律成立。

### 题 2.2（代码验证）

验证梯度裁剪"只改大小、不改方向"：对 $\mathbf{g} = (300, -400)$ 用阈值 $c=1$ 裁剪，计算裁剪前后的方向余弦。

```python
import numpy as np
g = np.array([300.0, -400.0])
c = 1.0
norm = np.linalg.norm(g)
g_clip = g * (c / norm) if norm > c else g
cos = g @ g_clip / (np.linalg.norm(g) * np.linalg.norm(g_clip))
print(f"裁剪后范数 = {np.linalg.norm(g_clip):.2f}，方向余弦 = {cos:.6f}")
```

**解答**：裁剪后范数 = 1.00，方向余弦 = 1.000000——范数从 500 压到 1，方向完全不变（余弦 1 = 夹角 0°）。
**思路点拨**：方向余弦 = 1 意味着两向量同向。裁剪缩放的是**整条**向量（乘一个标量），所有分量等比例，方向天然不变。这正是裁剪"保留方向信息、只限制步幅"的数学根据。把 `g` 换成 $(0.1, 0.2)$（范数小于 1），`if` 分支不触发，原样返回——验证裁剪的"有条件"特性。

## 三、DL 延伸

### 题 3.1

你训练一个 50 层网络，发现：前 10 层的权重在训练 1000 步后**几乎没变**，而损失曲线缓慢下降。请用本节知识判断最可能的病因，并给出两种解决方向。

**解答**：最可能病因是**梯度消失**——浅层权重梯度经 50 层连乘后趋近于零，更新量 $\eta \cdot \partial L/\partial W^{(1)} \approx 0$，所以前 10 层"睡了"。解决方向：① 换成 ReLU（或 Leaky ReLU）——正区导数恒为 1，连乘不衰减；② 加残差连接（ResNet 式跳跃连接）——给梯度一条绕过连乘的直通线，与 LSTM 记忆直通线同理；③ 用 BatchNorm 等归一化，避免激活进入饱和区（若用的是 sigmoid/tanh 则首当其冲）。也可辅以更合理的初始化。
**思路点拨**：判断"浅层不动"这一症状要立刻联想到"浅层梯度 → 消失"。注意这不是爆炸——爆炸的症状是震荡/NaN，而这里是**缓慢不动**。能区分消失与爆炸的症状，就抓住了本节的主线。

### 题 3.2

工程师报告：训练 2000 步后 loss 突然变成 `NaN`，且检查梯度发现范数达到 $10^6$。请给出诊断和至少两种处理手段，并说明每种手段分别针对"现象"还是"病根"。

**解答**：诊断：**梯度爆炸**——梯度范数 $10^6$ 导致一步权重更新量巨大，溢出或跳到损失曲面远处，loss 变 NaN。处理：① 梯度裁剪（$c$ 设成 1–10）——把范数压回阈值，直接针对**现象**（爆炸的当次更新）；② 降低学习率 $\eta$——减小每步步幅，从源头缓解"一步迈太大"，针对**病根之一**；③ 检查初始化/架构是否合理（如权重方差过大），换更合理的初始化，针对**病根之二**。裁剪是急救，降学习率与初始化是治疗。
**思路点拨**：能分清"急救（裁剪）vs 治疗（降学习率、初始化）"就掌握了工程处理的分层。真实工程里常说"loss=NaN 先查梯度是否爆炸，再查学习率"——正是这道题的流程。注意梯度裁剪的方向不变性（题 2.2）意味着急救不破坏正确的方向信息。
