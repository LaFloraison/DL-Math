# 代码：把消失、爆炸与鞍点做成可观测的实验

主线里我们说，梯度穿层会"连乘"，因子都小于 1 就消失、都大于 1 就爆炸。这一节的脚本把这些话变成数字：

1. **传话队列模拟**：梯度穿过 $L$ 层，每层乘一个局部导数因子 $r$——观察 $r<1$（消失）、$r>1$（爆炸）、$r=1$（ReLU，稳定）三种命运；
2. **ReLU vs sigmoid**：比较两种激活的导数峰值对梯度放缩的影响；
3. **梯度裁剪**：把一个爆炸的大梯度压回阈值，验证"只改大小、不改方向"；
4. **鞍点解剖**：$f(x,y) = x^2 - y^2$ 在原点梯度为零，但一个方向是谷、一个方向是峰——看它为何"像极值点却不是"。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 传话队列：梯度连乘模拟 ----
def pass_through_layers(L, r):
    """梯度穿过 L 层，每层乘局部导数因子 r，返回最终梯度大小。"""
    g = 1.0
    for _ in range(L):
        g *= r
    return g

print("=== 连乘的三种命运（起始梯度 = 1.0）===")
for r, name in [(0.5, "r=0.5  <1（消失）"), (1.0, "r=1.0  =1（ReLU）"), (1.1, "r=1.1  >1（爆炸）")]:
    for L in [10, 50, 100]:
        print(f"{name}  穿过 {L:>3} 层 → 梯度 = {pass_through_layers(L, r):.3e}")

# ---- ② 激活导数对比：sigmoid 峰值 0.25 vs ReLU 正区导数 1 ----
def sigmoid_deriv(z): return 1.0 / (1.0 + np.exp(-z)) * (1.0 - 1.0 / (1.0 + np.exp(-z)))
def relu_deriv(z): return 1.0 if z > 0 else 0.0
z = 5.0                                   # 一个饱和的输入
print(f"\n在 z=5 处：sigmoid 导数 = {sigmoid_deriv(z):.6f}  ReLU 导数 = {relu_deriv(z):.1f}")

# ---- ③ 梯度裁剪：只改大小，不改方向 ----
def clip_grad(g, c):
    """若 ||g|| > c，缩放为 g * c/||g||；否则原样返回。"""
    norm = np.linalg.norm(g)
    return g if norm <= c else g * (c / norm)

g_big = np.array([300.0, -400.0])         # 爆炸梯度：范数 500
g_clip = clip_grad(g_big, c=1.0)
print(f"\n裁剪前 ||g||={np.linalg.norm(g_big):.1f}  裁剪后 ||g||={np.linalg.norm(g_clip):.2f}")
print(f"方向保持：裁剪前后夹角余弦 = {g_big @ g_clip / (np.linalg.norm(g_big)*np.linalg.norm(g_clip)):.4f}")

# ---- ④ 鞍点解剖：f(x,y) = x^2 - y^2，原点梯度为零 ----
def saddle_grad(x, y): return np.array([2.0 * x, -2.0 * y])
p = np.array([0.0, 0.0])
print(f"\n鞍点梯度 ∇f(0,0) = {saddle_grad(*p)}")
# 沿 x 轴走一步：损失升（谷）；沿 y 轴走一步：损失降（峰）
gx = (0.1**2) - 0**2                       # f(0.1,0) - f(0,0)
gy = 0**2 - (0.1**2)                       # f(0,0.1) - f(0,0)
print(f"沿 +x 走 0.1：函数升 {gx:+.2f}（谷底方向）  沿 +y 走 0.1：函数降 {-gy:+.2f}（峰顶方向）")
```

运行输出（Python 3.11 + NumPy）：

```text
=== 连乘的三种命运（起始梯度 = 1.0）===
r=0.5  <1（消失）  穿过  10 层 → 梯度 = 9.766e-04
r=0.5  <1（消失）  穿过  50 层 → 梯度 = 8.882e-16
r=0.5  <1（消失）  穿过 100 层 → 梯度 = 7.889e-31
r=1.0  =1（ReLU）  穿过  10 层 → 梯度 = 1.000e+00
r=1.0  =1（ReLU）  穿过  50 层 → 梯度 = 1.000e+00
r=1.0  =1（ReLU）  穿过 100 层 → 梯度 = 1.000e+00
r=1.1  >1（爆炸）  穿过  10 层 → 梯度 = 2.594e+00
r=1.1  >1（爆炸）  穿过  50 层 → 梯度 = 1.172e+02
r=1.1  >1（爆炸）  穿过 100 层 → 梯度 = 1.378e+04
在 z=5 处：sigmoid 导数 = 0.006648  ReLU 导数 = 1.0
裁剪前 ||g||=500.0  裁剪后 ||g||=1.00
方向保持：裁剪前后夹角余弦 = 1.0000
鞍点梯度 ∇f(0,0) = [0. 0.]

```

输出里最震撼的是第一组：$r=0.5$ 时，穿过 100 层的梯度是 $7.9 \times 10^{-31}$——**彻底消失**；$r=1.1$ 时变成 $1.4 \times 10^4$——**爆炸**；$r=1.0$ 时纹丝不动。而 sigmoid 在饱和区导数只有 0.0066（远小于 1），ReLU 恒为 1。下面逐段拆解。

## 层二：分步逐函数拆解

### 步骤 1：定义 `pass_through_layers` —— 传话队列的数学版

```python
def pass_through_layers(L, r):
    g = 1.0
    for _ in range(L):
        g *= r
    return g
```

#### `pass_through_layers(L, r)` —— 梯度连乘模拟

`g *= r`

**做什么**：模拟"梯度穿过 $L$ 层、每层乘因子 $r$"。$g$ 从 1 开始，循环里连乘 $r$ 共 $L$ 次。这正是反向传播中浅层梯度 $\prod_{k=1}^{L-1}\frac{\partial a^{(k+1)}}{\partial a^{(k)}}$ 的数值缩影。
**操作**：`for _ in range(L)` 循环 $L$ 次；`g *= r` 每次把 $g$ 乘上 $r$。$r$ 是每层的"局部导数大小"。
**输入**：
- `L`：层数（深度），整数。
- `r`：每层的局部导数因子，标量。
**输出**：穿过 $L$ 层后的梯度大小，标量。
**可调参数**：`L` 与 `r` 是两个自由旋钮。`r=0.5, L=100` → $7.9\times10^{-31}$；`r=0.9, L=100` → $2.7\times10^{-5}$。**任何小于 1 的因子，只要层数够多，梯度必归零**——这就是"深"的数学诅咒。
**对应数学**：主线"梯度消失"公式的连乘部分。真实梯度是矩阵连乘（Jacobian 乘积），这里简化为标量以看清指数衰减的本质。

---

### 步骤 2：对比激活导数 —— sigmoid 的 0.0066 vs ReLU 的 1

```python
def sigmoid_deriv(z):
    return 1.0/(1.0+np.exp(-z)) * (1.0 - 1.0/(1.0+np.exp(-z)))
def relu_deriv(z): return 1.0 if z > 0 else 0.0
```

#### `sigmoid_deriv(z)` —— sigmoid 导数 $\sigma'(z) = \sigma(z)(1-\sigma(z))$

`return 1.0/(1.0+np.exp(-z)) * (1.0 - 1.0/(1.0+np.exp(-z)))`

**做什么**：算出 sigmoid 函数在 $z$ 处的导数。sigmoid 的导数等于 $\sigma(z)(1-\sigma(z))$，峰值只有 $0.25$，在饱和区（$z$ 远离 0）趋近 0。
**操作**：`1.0/(1.0+np.exp(-z))` 是 $\sigma(z)$；再乘 `(1 - σ(z))`。两行合起来正是 $0.006648$——这是 $z=5$（饱和区）的导数。
**输入**：`z`，标量（前向激活值）。
**输出**：该点的 sigmoid 导数。
**可调参数**：`z` 是主旋钮。$z=0$ 时导数取峰值 $0.25$；$z=5$ 时只剩 $0.0066$；$z=10$ 时几乎为 0。**饱和区 = 导数趋零 = 梯度消失的温床。**
**对应数学**：主线"消失"病根——sigmoid 导数峰值 $<1$，且在大激活处进一步坍缩。

#### `relu_deriv(z)` —— ReLU 导数：正区恒为 1

`return 1.0 if z > 0 else 0.0`

**做什么**：ReLU 在 $z>0$ 时导数恒为 1，$z\le0$ 时为 0。正区导数 1 意味着放进连乘不会衰减梯度——这是 ReLU 成为默认激活的数学理由。
**操作**：`if z > 0` 分支。注意它对标量是逐点判断；对数组要用 `np.where` 向量化（此处为演示用标量版）。
**输入**：`z`。
**输出**：0 或 1。
**可调参数**：无。ReLU 的负区导数为 0 是它的双刃剑——可能造成"死亡神经元"（§3.5 边界声明）。
**对应数学**：主线"ReLU 在正区导数恒为 1，稳住连乘"。对比 $z=5$ 处 sigmoid 的 0.0066 与 ReLU 的 1.0——**一个因子让梯度几乎归零，另一个让梯度纹丝不动。**

### 步骤 3：定义 `clip_grad` —— 梯度裁剪

```python
def clip_grad(g, c):
    norm = np.linalg.norm(g)
    return g if norm <= c else g * (c / norm)
```

#### `clip_grad(g, c)` —— 梯度裁剪

`return g if norm <= c else g * (c / norm)`

**做什么**：若梯度范数超过阈值 $c$，把整个梯度缩放 $c/\|g\|$ 倍——范数被压到 $c$，方向不变。这是爆炸梯度的急救刹车。
**操作**：`np.linalg.norm(g)` 算范数；`g * (c / norm)` 是标量缩放。裁剪后 `(300, -400)` 范数 500 → 范数 1，但方向余弦为 1.0000——**方向分毫未动**。
**输入**：
- `g`：梯度向量，形状任意。
- `c`：阈值（clip value），正标量。
**输出**：裁剪后的梯度，与 `g` 同形状。
**可调参数**：`c` 是刹车力度。`c=1.0` 严格限制；`c=100` 只挡巨幅爆炸。`c` 太小时方向信息被"均摊"成小额步幅，太大会失去保护作用。
**对应数学**：主线"梯度裁剪"定义块：$\mathbf{g} \leftarrow \frac{c}{\|\mathbf{g}\|}\mathbf{g}$（当 $\|\mathbf{g}\|>c$）。"只改大小不改方向"是它的灵魂——它尊重梯度指出的方向，只限制步幅。

### 步骤 4：解剖鞍点 —— $f(x,y)=x^2-y^2$

```python
def saddle_grad(x, y): return np.array([2.0 * x, -2.0 * y])
print(f"鞍点梯度 ∇f(0,0) = {saddle_grad(*p)}")
```

#### `saddle_grad(x, y)` —— 鞍面梯度 $\nabla f = (2x, -2y)$

`return np.array([2.0 * x, -2.0 * y])`

**做什么**：算鞍面 $f = x^2 - y^2$ 的梯度。**注意 $y$ 分量前面的负号**——它在 $y$ 方向是"倒着的谷"。
**操作**：`np.array([2x, -2y])`。在原点 $(0,0)$ 处返回 $(0,0)$——梯度为零，看起来像极值点。
**输入**：`x`、`y`。
**输出**：梯度向量。
**可调参数**：`p` 换成任意点都能算。但关键是 $(0,0)$——那里梯度为零，却不是极值。
**对应数学**：主线"鞍点"病的标准例子。沿 $x$ 方向走 0.1，函数升 0.01（谷）；沿 $y$ 方向走 0.1，函数降 0.01（峰）。**梯度为零，但一个方向是谷、一个方向是峰**——这就是鞍点：梯度下降在此无信号，容易被困。$f=x^2-y^2$ 是教材与深度学习文献中最经典的鞍点画像。

## 改个数字试试：把深度推向极限

### 实验 1：r=0.9 的"温和消失"——深层的隐形杀手

```python
for L in [20, 100, 500]:
    print(f"r=0.9 穿过 {L:>3} 层 → 梯度 = {pass_through_layers(L, 0.9):.3e}")
```

输出：

```text
r=0.9 穿过  20 层 → 梯度 = 1.216e-01
r=0.9 穿过 100 层 → 梯度 = 2.656e-05
r=0.9 穿过 500 层 → 梯度 = 1.330e-23
```

$r=0.9$ 每个因子只比 1 小一点，前 20 层还活着（0.12），但 500 层后就到 $10^{-23}$。**这就是为什么"深度消失"是慢性的**：不是突然归零，而是随着层数积累、无声地窒息。真实网络中这样的慢性衰减极难察觉——训练前几层永远缓慢，你却不知道病根在连乘。

### 实验 2：不同裁剪阈值

```python
for c in [0.5, 5.0, 1000.0]:
    g2 = clip_grad(np.array([300.0, -400.0]), c)
    print(f"c={c:<6} 裁剪后 ||g||={np.linalg.norm(g2):.2f}")
```

输出：

```text
c=0.5    裁剪后 ||g||=0.50
c=5.0    裁剪后 ||g||=5.00
c=1000.0 裁剪后 ||g||=500.00
```

注意第三行：`c=1000` 时范数**不是** 1000——`clip_grad` 只在范数**超过**阈值时缩放；原范数 500 < 1000，所以**原样返回**，范数保持 500。裁剪是"有条件"的：它只负责把超标的压回来，从不主动放大。如果你把第三行误写成 1000，说明实现里丢了 `if norm <= c` 这个分支——这是实现裁剪函数时最常见的 bug。

## 边界声明：这套代码能做什么，不能做什么

1. **这是标量化的玩具模拟，不是真实梯度。** 真实反向传播里每层乘的是**矩阵**（Jacobian），不是标量 $r$；矩阵连乘的衰减/放大规律更复杂（取决于谱半径）。`pass_through_layers` 用标量 $r$ 只为了让你看清"连乘"这个本质，它的量级不能直接搬到真实网络。
2. **ReLU 不是万能解药。** `relu_deriv` 的正区导数恒 1 确实稳住了连乘，但负区导数恒 0 会造成"神经元死亡"（dying ReLU）——那些神经元对任何输入都输出 0，梯度永远为 0，永久死亡。Leaky ReLU、ELU 等变体正是为此而生。本脚本没有覆盖这个副作用。
3. **梯度裁剪治标不治本。** 如果梯度**反复**被裁剪，说明学习率或架构本身有问题——裁剪只是急救包，不是治疗。它把爆炸压回安全区，但保留了"这个方向本来就该慢走"的信号吗？不——它一刀切地把整条梯度按比例压小，细节方向的相对大小被扭曲（虽然方向不偏）。
4. **鞍点只展示了"梯度为零却不是极值"。** 真实的困境比这更复杂：高维损失曲面上鞍点大量存在，且梯度下降在鞍点附近可能极慢（因为那里的梯度虽然不为零却很小）。$f=x^2-y^2$ 是理解鞍点的最小例子，但不要把它当真实损失曲面的全貌。
