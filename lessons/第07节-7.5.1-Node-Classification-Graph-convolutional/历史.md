# 历史：几个标签，怎样在网络上"传染"开

## 2003 年，一个"把标签借出去"的念头

想象一张图：几千个节点，只有几十个有标签，其余全是空白。这是 2000 年代初机器学习最常见的困局——**标注昂贵**。给一个用户标"垃圾/正常"，给一篇论文标"图论/优化"，都要专家人工，成本极高。标注 10% 的节点或许勉强可行，剩下的 90% 怎么办？

加州大学伯克利分校的朱（Xiaojin Zhu）等研究者，在 2003 年提出一个大胆的玩法：**让标签自己沿着边爬。** 他们把每个有标签的节点当"信源"，让标签沿着图中的边一点点"渗"出去——一个无标签节点，从它所有邻居那里"听"标签，反复迭代，直到整个图的标签分布稳定。这个算法叫"标签传播"（label propagation）。

它背后是一个朴素到几乎像信仰的假设：**相连的节点，倾向于同一种标签。** 物以类聚——你的朋友是垃圾号，你多半也是；你的论文引用的都是图论文献，你多半也是图论。标签像墨水滴进水里，沿着连接扩散，把"少数标注"变成"全图推断"。

## 一条既古老又常青的思想

标签传播在数学上不是新东西——它和扩散过程、随机游走、热传导共享同一套方程：**信息沿边流动，直到平衡。** 你把它看成"热的传播"也好、"舆论的扩散"也罢，本质都是同一个过程。但它在机器学习里打开了一扇门：**半监督学习 (semi-supervised learning)**——只靠少量标签 + 大量无标签数据的结构，就能做分类。

这个思想在后来的十几年里不断升级。2006 年前后，研究者开始用"图的拉普拉斯正则化"把"相连者相似"写进损失函数——让模型在拟合标签的同时，惩罚"相邻节点表示差异过大"。这等于把"物以类聚"从启发式变成了训练目标的一部分。

## 2017 年，标签传播住进了神经网络

2017 年，基普夫和韦林发表的 GCN，把这个古老思想做了一次彻底的"神经网络化"。

关键在 GCN 层的公式：

$$H^{(k+1)} = \sigma\big(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2} H^{(k)} W^{(k)}\big)$$

表面看它只是"聚合邻居 + 线性变换"。但深一层看，那个 $\tilde{A}$（加自环的邻接矩阵）乘上 $H$，做的正是**标签传播的"一步"**——把每个节点的表示换成"自己和邻居的加权平均"。GCN 的每一层 = 标签传播的一轮 + 一个可学习的变换 $W$。**标签传播的"扩散"骨架没有变，变的是"扩散规则"从手工设定的固定系数，变成了从数据里学出来的权重。**

更妙的是，GCN 论文的实验正是半监督节点分类：引用网络上，每类只标注 20 篇论文，GCN 用"谁引用谁"的结构，把标签扩散到全部 2708 篇论文，准确率一举刷新纪录——**几十个标签，借图的结构，猜对了整个领域。** 这正是朱教授"标签传播"的神经网络版，也是"物以类聚"最漂亮的一次现代证明。

## 从"渗标签"到"学怎么渗"

回看这条线：标签传播（固定规则，渗）→ 图拉普拉斯正则化（把相似写进损失）→ GCN（学习扩散规则）。每一次升级，都是把"物以类聚"这个直觉往"可学习"的方向推进一步。GCN 没有发明"标签会传染"，它只是让模型学会了"该听谁的、该信多少、该在哪一步停"。

而今天，这个思想已经长成图深度学习的基本盘：社交平台的垃圾账号检测、论文的领域分类、蛋白质的功能预测——几乎所有"给节点贴标签"的任务，都在用"让标签沿边扩散，并让模型学习如何扩散"。

## 留一扇门

老师只批了两份作业，模型却猜对了五个人的类型——这不是魔术，是"标签沿边传染"这个半监督思想的胜利。

但这个思想要变成能亲手算的公式——加自环、归一化、矩阵乘法——还需要主线把 GCN 的那一行公式，一个符号一个符号地拆开。更重要的是，要看清"物以类聚"什么时候会失效：当标签不再与连接同质，整个方法的假设就塌了。
