## 第一步：Toy Model —— 老师只批了两份作业

一份 5 人小班的作业。老师时间有限，只亲笔批了其中两人的作业，在上面写了评语：

- **A 同学的作业上写着："普通用户"**
- **D 同学的作业上写着："大V"**

剩下三个人——B、C、E 的作业，老师没批。但老师知道一件额外的事：**这几个人互相认识**。关系是：A 认识 B 和 C，B 认识 A、C、D，C 认识 A、B、E，D 只认识 B，E 只认识 C。

现在要让一个模型猜：**B、C、E 各是什么类型？**

如果只给每个人"属性"（活动量、内容质量），模型只能瞎猜。但关系图给出了一个有力的线索——**"物以类聚"：你的类型，大概率和你认识的人一致。** A 是"普通用户"，而 A 认识 B 和 C；那么 B 和 C 很可能是"普通用户"（物以类聚）。D 是"大V"，B 认识 D——但这只是 B 的一个邻居。综合所有邻居的"类型倾向"，模型能比瞎猜准得多地给 B、C、E 贴标签。

这个"利用已知标签 + 连接关系，预测未标注节点标签"的任务，就叫**节点分类 (node classification)**。本节要做的事，是把"物以类聚"这个直觉，变成 GCN（图卷积网络）里可以算、可以训练、可以预测的公式。

## 第二步：正式数学讲解

### 一、撞墙：普通神经网络为什么做不了"物以类聚"？

给每人建一行特征（活动量、内容质量），塞进 MLP——MLP 只能学到"属性 → 标签"的映射，即"内容质量高的人更像大V"。但节点的标签还由**邻居**决定：B 的标签应该参考 A（普通）和 C、D。MLP 的每一行是独立样本，它"看不见"B 的邻居是谁，更别提把邻居的信息加权进 B 的预测。

另一个更隐蔽的墙：**标签只有两个（A、D 有标签），大部分节点没标签。** 传统监督学习假设"每个样本都有标签"；这里 5 个里只有 2 个有。普通 MLP 面对"大量无标签样本"基本无计可施——它没法把 A 的标签"借"给 B。你撞墙了：**既需要"邻居信息进入预测"，又需要"少数标签扩散到全图"。**

### 二、破墙：GCN 层——把"物以类聚"写进矩阵

§7.3 的消息传递已经在聚合邻居了。GCN 把它改造成标准矩阵形式，并加上两个工程细节（自环 + 归一化）：

> **图卷积层 (GCN Layer)** $H^{(k+1)} = \sigma\big(\hat{A} H^{(k)} W^{(k)}\big)$
>
> - $H^{(k)}$：第 $k$ 层的节点特征矩阵，第 $i$ 行是节点 $i$ 的表示，形状 $(n, f)$。
> - $\hat{A}$：**归一化邻接矩阵**。从 $\tilde{A} = A + I$（加自环）出发，$\hat{A} = \tilde{D}^{-1/2} \tilde{A} \tilde{D}^{-1/2}$，其中 $\tilde{D}$ 是 $\tilde{A}$ 的度矩阵。
> - $W^{(k)}$：第 $k$ 层的可学习权重矩阵，形状 $(f, f')$。
> - $\sigma$：激活函数（ReLU 等）。

拆开这个公式，每一步都有明确的"为什么"：

**为什么加自环（$A + I$）？** §7.2 习题里说过：没有自环，孤立/低度节点的聚合是空集。加 $I$ 让每个节点聚合时**永远包含自己**——这一层结束时，节点的表示 = "自己的旧表示 + 邻居的旧表示"的线性组合。物以类聚的第一步：**我是谁，加上我的邻居是谁。**

**为什么归一化（$\tilde{D}^{-1/2}\cdot\tilde{D}^{-1/2}$）？** 不归一化的话，度大的节点（B 有 4 个邻居）聚合的总和天然比度小的节点大——"认识人多"会让特征暴涨。§7.2.4 我们见过这个问题的原型。对称归一化让每个节点除以 $\sqrt{\text{度}}$，把"度大小"的影响摊平：**聚合结果是"平均化的邻居信息"，而不是"被度数扭曲的总和"。**

**为什么乘 $W^{(k)}$？** 这是神经网络的学习部分——从数据里学"怎么组合邻居信息才有判别力"。

### 三、把教材的 5 人例子完整走一遍

教材的例子正是 Toy Model：$V=\{A,B,C,D,E\}$，邻接表 $N(A)=\{B,C\}$、$N(B)=\{A,C,D\}$、$N(C)=\{A,B,E\}$、$N(D)=\{B\}$、$N(E)=\{C\}$。初始特征（活动度, 内容质量）：$h_A=[0.9,0.1]$、$h_B=[0.8,0.2]$、$h_C=[0.3,0.7]$、$h_D=[0.2,0.8]$、$h_E=[0.1,0.9]$。

**第一步：加自环、算归一化邻接 $\hat{A}$。**
邻接矩阵 $A$ 对角线加 1 得 $\tilde{A}$。每个节点度（含自环）：$\tilde{d}(A)=3$、$\tilde{d}(B)=4$、$\tilde{d}(C)=4$、$\tilde{d}(D)=2$、$\tilde{d}(E)=2$。行归一化（教材的简化版用均值聚合）：$\hat{A}$ 的第 $i$ 行除以 $\tilde{d}(i)$。

**第二步：先做线性变换 $H^{(0)}W$。** 设 $W = \begin{pmatrix}0.5&0.1\\0.3&0.7\end{pmatrix}$，每个节点特征乘 $W$：
- $h_A W = [0.9,0.1]\cdot W = [0.48, 0.16]$
- $h_B W = [0.8,0.2]\cdot W = [0.44, 0.22]$
- $h_C W = [0.3,0.7]\cdot W = [0.36, 0.52]$
- $h_D W = [0.2,0.8]\cdot W = [0.34, 0.58]$
- $h_E W = [0.1,0.9]\cdot W = [0.32, 0.64]$

**第三步：归一化聚合（$\hat{A} \cdot (H^{(0)}W)$）。** 每个节点聚合"自己 + 邻居"的 $HW$，按度平均。以 A 为例（自己 + B + C，各 $\frac{1}{3}$）：
$$h_A^{(1)} = \sigma\Big(\frac{1}{3}[0.48,0.16] + \frac{1}{3}[0.44,0.22] + \frac{1}{3}[0.36,0.52]\Big) = \sigma([0.427, 0.30])$$
ReLU 下 $\sigma(x)=\max(0,x)$，结果不变：$h_A^{(1)} = [0.427, 0.30]$。同理可算 B、C、D、E。**注意发生了什么：A 的表示里混进了 B、C 的特征；而无标签节点 B 的表示里，也混进了有标签节点 A、D 的信息。** 一层之后，每个节点的表示都是"自己 + 邻居"的浓缩——物以类聚开始生效。

**第四步：分类。** 把 $H^{(1)}$ 乘一个分类权重 $W_c$ 得 logits，再过 softmax 得"普通用户/大V"的概率。教材的最终预测：
- B：普通用户（~51.8%）
- C：普通用户（~50.8%）
- E：大V（~61.8%）

**直觉检验**：B 和 C 被预测为"普通用户"，因为它们的邻居里 A 是普通用户（B 认识 A，C 也认识 A）；E 被预测为"大V"，因为它的特征"内容质量高"（$[0.1,0.9]$）本身就是大V画像，且连接它的 C 虽然被预测普通，但 E 自己的特征主导了判断。**物以类聚 + 自身特征，两个信号一起投票。**

### 四、边界：GCN 的诚实声明

- **同质性假设是前提**。GCN 的"物以类聚"假设标签与连接正相关。若标签**反同质**（如"敌人"互相连接），GCN 的聚合会传播错误标签——这时需要方向反转或特殊设计。
- **层数有限**。$K$ 层 GCN 只看 $K$ 跳。层太多会过度平滑（所有节点表示趋同）。教材例子里一层就够——真实任务常 2–4 层。
- **归一化不是万能的**。$\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$ 摊平了度数偏置，但若"度数本身"是任务信号（比如"连接越多越可能是大V"），归一化反而抹掉了这个信号——**用哪种归一化，取决于度是不是信息**。
- **转导式 vs 归纳式**：GCN 在**固定图**上转导学习（训练时看到整张图的结构，包括测试节点）；若要处理"从未见过的新节点/新图"，需要 §7.7.1 GraphSAGE 的归纳式设计。

## 第三步：DL 桥接

节点分类是图深度学习最成熟的应用，GCN 是它的招牌模型：

- **社交平台**：用户是节点、关注/互动是边，预测"是否是垃圾账号 / 是否会流失 / 兴趣标签"——正是教材的 5 人例子的工业版（百万级节点）。
- **引用网络**：论文是节点、引用是边，半监督分类"论文属于哪个领域"——GCN 的经典实验（Cora、PubMed 数据集，§7.4.2 参考资料）。训练时只需少量标注，GCN 借"引用结构"把标签扩散到未标注论文。
- **分子/生物**：原子/蛋白是节点、键/相互作用是边，预测"毒性/功能"。
- **推荐**：用户与物品是节点，节点分类可做"用户兴趣分组"。

节点分类与 §7.5.2 图分类的区别：**节点分类给每个节点一个标签，图分类给整张图一个标签**——一个管"点"，一个管"整幅画"。前者我们已经走通了（聚合邻居 + softmax），后者需要在整图上做"全局池化"（§7.5.2）。
