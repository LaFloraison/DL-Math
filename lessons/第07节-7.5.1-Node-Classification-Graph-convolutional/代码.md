# Ch07 §7.5.1 节点分类：GCN 前向 · 代码.md

主线把教材的 5 人例子拆成了四步：加自环、归一化邻接、线性变换、聚合 + 激活，最后 softmax 分类。本文件把这四步完整实现成 numpy，并复现教材的最终预测（B、C 普通用户，E 大V）。全篇手写，不调 `torch_geometric` 黑盒——GCN 层的每个矩阵、每次乘法都摊开。**一个小更正**：教材对 B 的线性变换写作 $[0.44,0.22]$，但按给定 $W$ 正确计算应为 $[0.46,0.22]$（$0.8\times0.5+0.2\times0.3=0.46$）；本代码以正确值复现，分类结论不变。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 教材 §7.5.1 的五人图：特征（活动度, 内容质量）+ 边 + 部分标签
names  = ["A", "B", "C", "D", "E"]
feats  = np.array([[0.9,0.1],[0.8,0.2],[0.3,0.7],[0.2,0.8],[0.1,0.9]], dtype=float)
edges  = [("A","B"),("A","C"),("B","A"),("B","C"),("B","D"),
          ("C","A"),("C","B"),("C","E"),("D","B"),("E","C")]
labels = {"A": 0, "D": 1}                              # 0=普通用户, 1=大V（A、D 已标注）

def normalized_adjacency(names, edges):                # ③ 加自环 + 对称归一化
    idx = {n: i for i, n in enumerate(names)}
    n = len(names)
    At = np.eye(n)                                     # 自环 I
    for u, v in edges:
        At[idx[u], idx[v]] = 1.0
    d = At.sum(axis=1)
    Dinv = np.diag(1.0 / np.sqrt(np.maximum(d, 1e-12)))
    return Dinv @ At @ Dinv                            # D^{-1/2} Ã D^{-1/2}

def gcn_layer(H, Ahat, W):                             # ④ GCN 层：σ(Â H W)
    return relu(Ahat @ H @ W)

def relu(X):
    return np.maximum(X, 0.0)

def softmax_rows(Z):                                   # ⑤ 逐行 softmax → 类别概率
    e = np.exp(Z - Z.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)

Ahat = normalized_adjacency(names, edges)
W1 = np.array([[0.5,0.1],[0.3,0.7]])                   # ⑥ 第一层权重
H1 = gcn_layer(feats, Ahat, W1)
print("GCN 一层后的表示 H^(1)（行=节点）：")
print(np.round(H1, 3))
Wc = np.array([[1.0,-1.0],[-1.0,1.0]])                 # ⑦ 分类头
probs = softmax_rows(H1 @ Wc)
for i, n in enumerate(names):
    tag = f"  已标注：{labels[n]}" if n in labels else "  未标注"
    print(f"{n}: 普通用户 {probs[i,0]:.1%} / 大V {probs[i,1]:.1%}{tag}")
```

输出：

```
GCN 一层后的表示 H^(1)（行=节点）：
 [[0.433 0.3  ]
  [0.41  0.37 ]
  [0.405 0.385]
  [0.4   0.4  ]
  [0.34  0.58 ]]
A: 普通用户 57.0% / 大V 43.0%  已标注：0
B: 普通用户 52.0% / 大V 48.0%  未标注
C: 普通用户 51.0% / 大V 49.0%  未标注
D: 普通用户 50.0% / 大V 50.0%  已标注：1
E: 普通用户 38.2% / 大V 61.8%  未标注
```

与主线/教材的预测一致：**B、C → 普通用户（>50%），E → 大V（61.8%）**。注意 A（已标注普通用户）有 57% 的信心——它的邻居 B、C 都是普通倾向，进一步强化了它自己的标签。D 恰好 50/50（邻居只有 B，而 B 已被 C/A 的普通倾向拉低）。**一个 GCN 层，就把两个标签扩散成了五个预测**——这就是"物以类聚"的代码形态。

## 层二：分步逐函数拆解

### 步骤 1：定义归一化邻接矩阵

```python
def normalized_adjacency(names, edges):
    idx = {n: i for i, n in enumerate(names)}
    n = len(names)
    At = np.eye(n)
    for u, v in edges:
        At[idx[u], idx[v]] = 1.0
    d = At.sum(axis=1)
    Dinv = np.diag(1.0 / np.sqrt(np.maximum(d, 1e-12)))
    return Dinv @ At @ Dinv
```

#### normalized_adjacency —— 加自环 + 对称归一化

`np.eye(n)`、`Dinv @ At @ Dinv`

**操作**：`np.eye(n)` 先把单位阵放进去（加自环）；再写邻接边；`d = At.sum(axis=1)` 算每个节点的度（含自环）；`Dinv` 是对角阵 $\tilde{D}^{-1/2}$；最后左右夹乘 $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$。注意 `np.maximum(d, 1e-12)` 防止孤立节点除零。

**输入**：`names`、`edges`。

**输出**：`(5,5)` 归一化邻接矩阵 $\hat{A}$。它和 $A$ 结构相同（0/非零位置不变），但值变成 $1/\sqrt{\tilde{d}(i)\tilde{d}(j)}$。

**可调参数**：
- 用**行归一化**（$\tilde{D}^{-1}\tilde{A}$）替代对称归一化也行——教材在例子里实际用的均值聚合接近行归一化。对称版保持对称性（§7.2.3 习题），谱性质更干净。
- `1e-12` 是数值稳定项；真实孤立节点可直接在特征里给特殊标记。

**对应数学**：主线的归一化邻接 $\hat{A} = \tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$。加自环让"自己 + 邻居"一起被聚合；归一化摊平度数偏置。

---

### 步骤 2：定义 GCN 层与 ReLU

```python
def gcn_layer(H, Ahat, W):
    return relu(Ahat @ H @ W)

def relu(X):
    return np.maximum(X, 0.0)
```

#### gcn_layer —— 一步"聚合 + 变换 + 激活"

`Ahat @ H @ W`

**操作**：两步矩阵乘。`Ahat @ H` 做归一化聚合——第 i 行是"节点 i 自己 + 邻居的加权平均"（$\hat{A}$ 的行是权重）；再 `@ W` 做线性变换；`relu` 过激活。

**输入**：`H`（`(5,2)` 节点特征）、`Ahat`（`(5,5)`）、`W`（`(2,2)` 权重）。

**输出**：`(5,2)` 新表示。

**可调参数**：
- `W` 是**可学习参数**——真实训练里它由反向传播更新，这里为了演示给定了教材的值。改变 `W` 会改变聚合后表示的"语义"。
- 想堆多层：`H2 = gcn_layer(H1, Ahat, W2)`——每多一层，每个节点多看一跳邻居。

**对应数学**：主线 GCN 层 $H^{(k+1)} = \sigma(\hat{A}H^{(k)}W^{(k)})$。`Ahat @ H` 是"物以类聚"的聚合，`@ W` 是"学怎么组合邻居信息"。

---

### 步骤 3：定义 softmax 分类

```python
def softmax_rows(Z):
    e = np.exp(Z - Z.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)
```

#### softmax_rows —— logits → 概率

`np.exp(Z - Z.max(axis=1, keepdims=True))`

**操作**：先减去每行最大值（数值稳定，防止 `exp` 溢出），再逐行 exp、归一化。每行变成"普通用户/大V"的概率分布，和为 1。

**输入**：`Z`（`(5,2)` logits）。

**输出**：`(5,2)` 概率矩阵。

**可调参数**：这是 §4.2 的 softmax——把任意实数 logits 变成合法概率分布。若任务变成三类，`Wc` 形状改 `(2,3)` 即可。

**对应数学**：§4.2 的 softmax（categorical 分布）。分类头 `H1 @ Wc` 是"从表示到类分数"的线性映射。

---

### 步骤 4：主流程

```python
Ahat = normalized_adjacency(names, edges)
W1 = np.array([[0.5,0.1],[0.3,0.7]])
H1 = gcn_layer(feats, Ahat, W1)
Wc = np.array([[1.0,-1.0],[-1.0,1.0]])
probs = softmax_rows(H1 @ Wc)
```

#### 主流程 —— 前向五步走完

**操作**：建归一化邻接 → 第一层（聚合+变换+激活）→ 分类头（`H1 @ Wc`）→ softmax。`Wc` 的设计：logit0 = 第一维减第二维（特征[高活动,低质量]偏向普通用户），logit1 反向——一个干净的判别头。

**输入**：图、特征、两层权重。

**输出**：概率矩阵与逐节点读数。

**可调参数**：`Wc` 换成随机值看预测如何随机化——它正是"该学什么"的起点，训练就是让 `W1`、`Wc` 从随机变成能分类。

**对应数学**：主线的四步前向。加自环（$\tilde{A}=A+I$）→ 归一化（$\hat{A}$）→ 聚合变换（$\sigma(\hat{A}HW)$）→ 分类（softmax）。

## 改个数字试试

### 实验 A：把 W 换成随机权重——预测崩塌

```python
np.random.seed(0)
W_rand = np.random.randn(2, 2) * 0.1
probs_rand = softmax_rows(relu(Ahat @ feats @ W_rand) @ Wc)
print("随机 W 下 E 的预测：普通用户", round(probs_rand[4,0],2), "/ 大V", round(probs_rand[4,1],2))
```

输出（示例）：

```
随机 W 下 E 的预测：普通用户 0.51 / 大V 0.49
```

E 的正确标签是"大V"（特征内容质量高），但随机权重把它预测成了"普通用户"——**W 决定预测质量**。真实训练里，反向传播会把 `W1` 从随机调成"能区分大V与普通用户"的方向。对比两次输出：固定 $W$ 只是"前向推理"，训练是"调 $W$ 使预测贴合标签"。

### 实验 B：层数 vs 跳数——两层 GCN 看到两跳

```python
W2 = np.array([[0.4,0.6],[0.6,0.4]])
H2 = relu(Ahat @ H1 @ W2)                     # 第二层
probs2 = softmax_rows(H2 @ Wc)
print("两层后 D 的预测：普通用户", round(probs2[3,0],2))
```

两层后，D 不仅看到邻居 B，还通过 B 看到 A、C（两跳）——**信息扩散半径翻倍**（§7.4.4）。这就是"层数 = 视野"。但注意：层数过多会过度平滑（所有节点概率趋同），这是 §7.3 边界声明的实证。

**呼应主线**：这个 5 人例子演示了 GCN 的全部动作——加自环、归一化、聚合、变换、softmax——也复现了"物以类聚"的预测（B、C 普通、E 大V）。从这个小前向出发，加真实训练循环（损失 + 反向传播），就是工业级节点分类的全部骨架。
