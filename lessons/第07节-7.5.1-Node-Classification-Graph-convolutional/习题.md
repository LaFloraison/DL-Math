# §7.5.1 节点分类：GCN —— 习题

主线讲了 GCN 的四步（自环、归一化、聚合、softmax）与"物以类聚"的假设。下面三组习题检验你是否真的会算、会设计一个 GCN。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：GCN 层里"加自环"（$A+I$）的作用是什么？

- A. 让矩阵变成可逆的
- B. 让每个节点在聚合时包含自己，防止孤立/低度节点被清零
- C. 让邻接矩阵变成稠密矩阵
- D. 引入二阶邻居

**解答**：B。

**思路点拨**：自环让"自己 + 邻居"一起被聚合——否则度 0 的节点聚合到空集，表示丢失。这也让特征在每层至少保留一部分自身信息。A、C 是无关的矩阵性质；D 错——自环不是二阶邻居，层数才决定跳数。常见错选 D，混淆"自环"与"多层"。

### 题 2（简答）：为什么 GCN 要做归一化？不归一化会怎样？

**解答**：因为**度大的节点聚合总和天然更大**——不归一化，一个认识 100 人的节点的表示会因"邻居多"而数值暴涨，扭曲节点间的可比性。归一化（$\tilde{D}^{-1/2}\cdot\tilde{D}^{-1/2}$）把"连接数量"的影响摊平，让聚合变成"平均化的邻居信息"。**代价**：如果"度数本身"是任务信号（连接越多越可能是大V），归一化会抹掉它——是否归一化取决于度是不是信息。

**思路点拨**：答题要点是"度数偏置"。能说出"归一化摊平度数、但也可能抹掉度数信号"就得满分——这体现了边界意识。常见错误是只说"防止过大"，没提"可能丢失信号"。

### 题 3（判断）：GCN 在"标签与连接不相关"的图上会怎样？

**解答**：会失败（或显著变差）。GCN 的"物以类聚"假设**同质性**——相连节点倾向同标签。若图是**反同质**的（如"对立双方"互相连接）、或标签与连接无关，GCN 聚合传播的是错误/无关信息。此时需换方向、用异质处理、或引入额外特征。

**思路点拨**：这是主线边界声明的直考。答题要给"失效场景 + 对策"。常见错误是默认 GCN 对任何图都有效。记忆锚点：GCN 是"同质性假设 + 邻域聚合"的乘积，假设塌了乘积就塌。

## 二、计算实践

### 题 1（手算 + NumPy：两节点 GCN）

两个节点 X、Y，一条边 X–Y。特征 $h_X=[1,0]$、$h_Y=[0,1]$。$W=\begin{pmatrix}1&0\\0&1\end{pmatrix}$（恒等），无激活。

(a) 写 $\tilde{A} = A+I$ 及其度。
(b) 用行归一化 $\tilde{D}^{-1}\tilde{A}$，算一层后的 $h_X^{(1)}$、$h_Y^{(1)}$。
(c) 说明归一化前后 $h_X$ 发生了什么变化。

**解答**：

(a) $\tilde{A} = \begin{pmatrix}1&1\\1&1\end{pmatrix}$（X、Y 各有自环 + 对方，度都为 2）。

(b) 行归一化：每行除以 2。$h_X^{(1)} = \frac{1}{2}h_X + \frac{1}{2}h_Y = [0.5, 0.5]$；$h_Y^{(1)} = [0.5, 0.5]$。**两个节点表示完全相同**——互相平均。

(c) 归一化前：$h_X$ 若只看邻居（不含自环）是 $h_Y=[0,1]$；含自环求和是 $[1,1]$。归一化让"自己+邻居"各占一半，$h_X$ 从"只有自己"变成"自己和邻居的平均"——**这就是"物以类聚"在表示上的效果：相连节点互相拉近。**

**NumPy 验证**：
```python
import numpy as np
A = np.array([[1,1],[1,1]], dtype=float)   # 已含自环
Dinv = np.diag(1/A.sum(1))
H = np.array([[1.,0.],[0.,1.]])
print("行归一化后：\n", Dinv @ A @ H)       # [[0.5,0.5],[0.5,0.5]]
```
```
行归一化后：
 [[0.5 0.5]
  [0.5 0.5]]
```

**思路点拨**：(c) 的洞察是关键——GCN 的本质是"让相连节点在表示空间里互相靠近"。两节点的图把这件事放大到肉眼可见。常见错误是算成 $A H$ 忘了除以度，或把自环忘了。

### 题 2（手算：分类 logits 与 softmax）

承接主线，$h_B^{(1)} = [0.41, 0.37]$，分类头 $W_c = \begin{pmatrix}1&-1\\-1&1\end{pmatrix}$。手算 B 的 logits 与 softmax 概率。

**解答**：$z = h_B W_c = [0.41\times1 + 0.37\times(-1),\ 0.41\times(-1)+0.37\times1] = [0.04, -0.04]$。softmax：$e^{0.04} \approx 1.0408$、$e^{-0.04} \approx 0.9608$，和 $2.0016$，$P(\text{普通用户}) = 1.0408/2.0016 \approx 0.520$，$P(\text{大V}) \approx 0.480$。B 被判为普通用户（52%）。

**思路点拨**：这道题把"表示 → logits → 概率"的最后一环走一遍。$W_c$ 的设计让"第一维 - 第二维 > 0"偏向普通用户（高活动低质量）。常见错误：softmax 直接对 logits 做 $e^z/\sum$ 忘了减 max（数值上会溢出）；或把行/列方向算反。注意概率总和必须为 1（$0.52+0.48=1$），这是 §4.2 归一化公理的检查点。

## 三、DL 延伸

### 题 1（场景设计）：垃圾账号检测——GCN 的设计选择

一个平台要检测"垃圾账号"。已知：垃圾号大量关注他人（出度高），但被关注少；普通号被关注多。你打算用 GCN 做节点分类。请回答：(a) 用 sum 聚合还是归一化聚合？(b) 如果你认为"连接数本身就是垃圾信号"，归一化是否合适？

**解答**：(a) 若认为"关注量巨大"是垃圾号的判别信号，**sum 聚合**保留它（出度大 → 聚合总和巨大 → 特征突出）；归一化会把它抹平。(b) 若"连接数量"是核心信号，**不应归一化**——归一化把大 V 和垃圾号拉到同一尺度，恰恰抹掉了你要的信号。但要注意"被关注少"这个信号在**入方向**上——垃圾号入度低，这在对称聚合里会被"被关注多"的邻居稀释。更合适的设计可能是"出边/入边分开聚合"（方向感知 GCN）——出度大 + 入度小两个信号同时捕捉。

**思路点拨**：这道题把"归一化 vs 保留度数信号"的权衡落到具体任务。核心：**归一化不是免费午餐**——它保护可比性，但也可能抹掉"度数本身是特征"的信号。加分点：提出"分方向聚合"。常见错误是"一律用归一化"。

### 题 2（概念连线）：半监督是怎么发生的？

GCN 训练时，只有 A、D 有标签（2/5）。为什么训练后 B、C、E 也能被分类？用 GCN 的前向机制解释，并说明这属于转导式还是归纳式学习。

**解答**：训练时，损失只算在有标签节点（A、D）上，但梯度反传通过 GCN 层时，**每个节点的表示都依赖邻居**——A 的表示含 B、C 的信息，A 的损失梯度会调整"如何聚合 B、C 的信息"这一权重。训练后，未标注节点 B、C、E 走同样前向，它们的表示由"训练好的聚合权重 + 它们自己的邻居"算出，于是被正确分类。**标签通过结构扩散到未标注节点**——这是半监督。且因为训练时模型见过整张图的结构（包括测试节点），这属于**转导式**（transductive）；若要对"从未见过的新节点"分类，需 GraphSAGE 的归纳式设计（§7.7.1）。

**思路点拨**：答题锚点是"标签梯度经聚合流向邻居"。能把"半监督"和"转导 vs 归纳"两个概念都答出是满分。常见错误是只说"能分类"不说机制，或分不清转导/归纳。
