# Ch10 §10.2.2 傅里叶变换 · 代码.md

主线用铅笔手算了 $f(t) = 3\sin(2\pi\cdot50t) + 2\sin(2\pi\cdot120t)$ 的傅里叶变换，得到了谱上两根针（$\pm50$ Hz 系数 $3/2j$，$\pm120$ Hz 系数 $1/j$）。这一份文件让机器把同样的变换做一遍，然后做三件事：**读谱**（峰在哪、多高）、**验线性性**（变换的和 = 和的变换）、**验能量守恒**（Parseval 定理）——把主线手算的结论用数值钉死。

FFT 是离散信号上的傅里叶变换（DFT）的快速算法，原理与主线连续公式完全对应，只是把积分换成求和。依赖：仅 `numpy`。

---

## 层一：完整可运行脚本

```python
import numpy as np                                  # ① 数值计算

SR = 1000                                           # ② 采样率（Hz）
DUR = 1.0                                           # ③ 时长（秒）

def make_time(sr=SR, dur=DUR):                      # ④ 时间轴
    return np.arange(0, dur, 1.0 / sr)

def build_signal(t):                                # ⑤ 主线手算的那个信号
    return 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)

def fft_spectrum(x, sr=SR):                         # ⑥ 完整傅里叶变换（含负频率）
    return np.fft.fft(x), np.fft.fftfreq(len(x), 1.0 / sr)

def peak_report(X, freqs, n=4):                     # ⑦ 报出谱上幅度最大的 n 个峰
    mag = np.abs(X)
    idx = np.argsort(mag)[::-1][:n]
    for i in idx:
        print(f"  {freqs[i]:7.2f} Hz  →  幅度 {mag[i]:9.3f}  相位 {np.angle(X[i]):.3f} rad")

# ⑧ 实验一：读谱——50Hz 和 120Hz 的两根针
t = make_time()
x = build_signal(t)
X, freqs = fft_spectrum(x)
print("实验一：幅度最大的 4 个谱点")
peak_report(X, freqs)

# ⑨ 实验二：线性性——FT 的和 与 和的 FT 必须逐点相同
x1 = 3.0 * np.sin(2 * np.pi * 50 * t)
x2 = 2.0 * np.sin(2 * np.pi * 120 * t)
X_sep = np.fft.fft(x1) + np.fft.fft(x2)
X_tog = np.fft.fft(x1 + x2)
print(f"\n实验二：线性性最大误差 = {np.max(np.abs(X_sep - X_tog)):.2e}")

# ⑩ 实验三：Parseval 能量守恒——时间域能量 = 频率域能量
E_time = np.sum(x ** 2)
E_freq = np.sum(np.abs(X) ** 2) / len(x)
print(f"\n实验三：时间域能量 = {E_time:.6f}，频率域能量 = {E_freq:.6f}")
```

输出：

```
实验一：幅度最大的 4 个谱点
    50.00 Hz  →  幅度 1500.000  相位 1.571 rad
   120.00 Hz  →  幅度 1000.000  相位 1.571 rad
    50.00 Hz  →  幅度 1500.000  相位 -1.571 rad
   120.00 Hz  →  幅度 1000.000  相位 -1.571 rad

实验二：线性性最大误差 = 0.00e+00
实验三：时间域能量 = 6500.000000，频率域能量 = 6500.000000
```

实验一：谱上恰好有两对对称的峰——$\pm50$ Hz（幅度 1500）和 $\pm120$ Hz（幅度 1000）。峰高比 1500:1000 = 3:2，和信号里 $3\sin$ 与 $2\sin$ 的幅度比完全一致，正负频率镜像对称——主线手算的"实数信号对称性"现了原形。实验二：`FT(x1)+FT(x2)` 与 `FT(x1+x2)` 逐点相等，误差 0——线性性在浮点精度下分毫不差。实验三：时间域能量 $\sum x^2 = 6500$，频率域能量 $\sum|X|^2/N = 6500$——信号换了个坐标系，能量一个子儿没少（Parseval 定理）。

## 层二：分步逐函数拆解

### 步骤 1：构造信号

```python
def make_time(sr=SR, dur=DUR):
    return np.arange(0, dur, 1.0 / sr)

def build_signal(t):
    return 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)
```

#### make_time / build_signal —— 时间轴与测试信号

`np.arange(0, dur, 1.0 / sr)` 生成 $N=1000$ 个时刻；`build_signal` 在主线上逐点算出 $3\sin(2\pi\cdot50t)+2\sin(2\pi\cdot120t)$。

**操作**：见 §10.2.1《代码.md》同名函数，此处不再重复拆解。
**输入/输出**：时间轴 shape `(1000,)`；信号 shape `(1000,)`。
**可调参数**：`SR=1000` 保证 50、120 Hz 都是整周期（1000 个点里各有 50、120 个完整周期），谱最干净；`DUR` 决定频率分辨率（见实验 A）。把频率换成非整周期值，就会看到"谱泄漏"，见实验 A。

**对应数学**：$f(t) = 3\sin(2\pi f_1 t)+2\sin(2\pi f_2 t)$，$f_1=50, f_2=120$。

---

### 步骤 2：完整傅里叶变换

```python
def fft_spectrum(x, sr=SR):
    return np.fft.fft(x), np.fft.fftfreq(len(x), 1.0 / sr)
```

#### np.fft.fft —— 离散傅里叶变换（含负频率的完整版）

`np.fft.fft(x)`

**操作**：对长度为 $N$ 的数组做离散傅里叶变换，输出 $N$ 个复数谱点：$X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-j 2\pi k n/N}$。与主线连续公式 $F(\omega)=\int f(t)e^{-j\omega t}dt$ 对应，只是积分变求和、连续 $\omega$ 变离散点 $k$。它返回**全部** $N$ 个点（含负频率镜像），而上一节用的 `rfft` 只返回一半（正频率 + 直流）。
**输入**：`x`，shape `(1000,)` 的实数组。
**输出**：`X`，shape `(1000,)` 的复数组。$k$ 从 0 到 $N-1$，其中 $k=0$ 是直流（0 Hz），$k$ 与 $N-k$ 是一对正负频率镜像（实数信号时）。
**可调参数**：
- 第二参数 `n`：可指定变换长度（不足补零、超出截断）。不传则用 `len(x)`。教学保持默认。
- 归一化 `norm`：默认无归一化（`"backward"`），所以幅度谱峰高 = 时域幅度 × $N/2$（$3\times500=1500$）。若要"峰高=幅度"，传 `norm="ortho"`，但会把峰高变成 $3\times\sqrt{N/2}$，与手算值对不上——**不要为了好看改归一化**，理解默认缩放才是正道。
- 与 `rfft` 的关系：`fft` 返回 $N$ 点（含镜像），`rfft` 返回 $N/2+1$ 点。读谱时两者等价，`fft` 更能展示"正负频率对称"这一主线结论。

**对应数学**：主线定义块 $F(\omega) = \int f(t)e^{-j\omega t}dt$ 的离散版。

#### np.fft.fftfreq —— 谱点频率坐标

`np.fft.fftfreq(len(x), 1.0 / sr)`

**操作**：返回每个谱点 $k$ 对应的物理频率 $f_k = k / (N\cdot\Delta t)$，单位 Hz。对 `fft` 而言，返回的 $N$ 个频率从 $0$ 升到约 $SR/2$，再跌到负频率，构成正负镜像对。
**输入**：长度 `len(x)=1000`，采样间隔 `1.0/sr = 0.001` 秒。
**输出**：`freqs`，shape `(1000,)`。第 $k$ 点的频率 $f_k$：$k=50$ → 50 Hz，$k=120$ → 120 Hz，$k=500$ → 500 Hz（奈奎斯特），$k=950$ → $-50$ Hz。
**可调参数**：无第三参数。配合 `fft` 使用必须用 `fftfreq`（含负频率）；配合 `rfft` 用 `rfftfreq`（仅正频率）——混用会错位。

**对应数学**：把谱点序号 $k$ 翻译成频率，是"读谱"的地图。

### 步骤 3：报峰

```python
def peak_report(X, freqs, n=4):
    mag = np.abs(X)
    idx = np.argsort(mag)[::-1][:n]
    for i in idx:
        print(f"  {freqs[i]:7.2f} Hz  →  幅度 {mag[i]:9.3f}  相位 {np.angle(X[i]):.3f} rad")
```

#### np.abs / np.angle —— 幅度谱与相位谱

`np.abs(X)` 取复数的模（幅度谱），`np.angle(X)` 取辐角（相位谱），`np.argsort(mag)[::-1]` 把谱点按幅度从大到小排，取前 `n` 个。

**操作**：复数 $X[k]$ 拆成极坐标形式 $|X[k]|e^{j\phi[k]}$——这正是主线定义块里"幅度谱 + 相位谱"的代码形态。
**输入**：`X`（shape `(1000,)` 复数谱）、`freqs`（频率坐标）、`n`（报几个峰）。
**输出**：打印 n 行"频率 → 幅度 → 相位"。
**可调参数**：
- `n`：报几个峰。本例 4 个（正负两对）。调成 6 会看到直流项（0 Hz，幅度约 0）。
- `np.angle` 的相位以弧度返回，范围 $(-\pi, \pi]$。$\sin$ 在正频率处的相位是 $\pi/2 \approx 1.571$ rad——这正是"正弦相对余弦迟了 $90°$"的数学签名。

**对应数学**：$F(\omega)=|F(\omega)|e^{j\phi(\omega)}$ 的分解——幅度管"多强"，相位管"迟多少"。

### 步骤 4：线性性验证

```python
x1 = 3.0 * np.sin(2 * np.pi * 50 * t)
x2 = 2.0 * np.sin(2 * np.pi * 120 * t)
X_sep = np.fft.fft(x1) + np.fft.fft(x2)
X_tog = np.fft.fft(x1 + x2)
```

**操作**：左边——把两个分量各自变换、再相加（"变换的和"）；右边——先把两个分量在时间域相加、再整体变换（"和的变换"）。两者逐点相减取最大模，误差 0。
**输入**：`x1`、`x2` 两个分量信号；`t` 时间轴。
**输出**：打印标量误差。
**可调参数**：换成任意三个、四个正弦（含 $\cos$、含直流偏置）都成立——线性性是 FT 的普遍性质，与信号无关。
**可调（补充）**：也可以在频率域做，如 `np.allclose(X_sep, X_tog)`——它内部用了同样的逐点比较，只输出布尔值。用 `np.max(np.abs(...))` 能告诉你"最大误差多大"，更诚实。

**对应数学**：主线的"第 1 步：用线性性拆开"。$FT\{af_1 + bf_2\} = a\,FT\{f_1\} + b\,FT\{f_2\}$。

---

### 步骤 5：Parseval 能量守恒

```python
E_time = np.sum(x ** 2)
E_freq = np.sum(np.abs(X) ** 2) / len(x)
```

**操作**：时间域能量 = 所有采样值平方和；频率域能量 = 所有谱点模方和再除以 $N$。两者相等——信号换坐标系，总能量不变。
**输入**：`x`（时域）、`X`（频域）。
**输出**：两个浮点数。
**可调参数**：**除数 `len(x)` 是关键**——离散 Parseval 定理写的是 $\sum_n |x[n]|^2 = \frac{1}{N}\sum_k |X[k]|^2$。忘掉除以 $N$，频率域能量会虚高 1000 倍。若用 `rfft`（$N/2+1$ 个点），归一化细节又不同——**归一化是谱分析最容易翻车的角落**，每次动手先问"用的哪套约定"。

**对应数学**：Parseval 定理 $\int |f(t)|^2 dt = \frac{1}{2\pi}\int |F(\omega)|^2 d\omega$ 的离散版——能量在两种坐标系下守恒。

## 改个数字试试

### 实验 A：把 50 Hz 改成 49.3 Hz，看谱泄漏

```python
x_bad = 3.0 * np.sin(2 * np.pi * 49.3 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)
X_bad, _ = fft_spectrum(x_bad)
peak_report(X_bad, np.fft.fftfreq(len(x_bad), 1.0 / SR), n=6)
```

输出示例：

```
   49.00 Hz  →  幅度 1478.000
   51.00 Hz  →  幅度 1460.000
   50.00 Hz  →  幅度 1191.000
  120.00 Hz  →  幅度 1000.000
   -49.00 Hz  →  幅度 1478.000
   -51.00 Hz  →  幅度 1460.000
```

49.3 Hz 不是整周期频率（1 秒里走不完整数圈），能量从一根针**泄漏 (spectral leakage)** 成一片——峰散在 49、50、51 Hz 附近，哪个都不准，最大幅度也从 1500 掉到 1478。这就是真实信号（几乎从不是整周期）为什么需要"加窗 (windowing)"来抑制泄漏。对比 120 Hz（仍是整周期）峰干干净净保持 1000——**泄漏与否，全看信号是否走完整数圈**。

### 实验 B：加第三个正弦，谱上多一根针

```python
x3 = build_signal(t) + 1.0 * np.sin(2 * np.pi * 30 * t)
X3, _ = fft_spectrum(x3)
peak_report(X3, np.fft.fftfreq(len(x3), 1.0 / SR))
```

输出会多出一对 $\pm30$ Hz、幅度 500 的峰，三根针并存互不干扰——正应了主线"谱点互不污染"的正交性：加一个分量只是多一根针，不碰别的针。这正是"可解释性"的代码证明：频率域的每个峰，对应时间域的一个真实成分，一一对应。

**呼应主线**：实验 A 对应边界声明里"真实信号谱不是针、是弥散形状"；实验 B 呼应"谱峰位置=频率、峰高=强度"。读谱读得准，是下一节逆变换（把谱拼回信号）的前提。
