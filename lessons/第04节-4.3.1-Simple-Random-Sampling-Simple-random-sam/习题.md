# 习题：简单随机采样（SRS）

## 第一组：概念检验

**1. 写出 SRS 下每人被选中的概率公式。教材例：$N=1000, n=100$ 时是多少？**

**解答**：$P(\text{selection})=\frac{n}{N}=\frac{100}{1000}=0.1$——每人 10% 被选概率，人人平等。

**2. 为什么说"等概率"是 SRS 误差可分析的支点？如果概率不等会怎样？**

**解答**：等概率 → 样本均值无偏：$\mathbb{E}[\bar X]=\mu$。这是所有误差公式（方差 $\frac{\sigma^2}{n}$、$\frac{\sigma}{\sqrt n}$）的出发点。如果概率不等（富人更容易被选），$\mathbb{E}[\bar X]\ne\mu$——**偏差出现，误差公式被污染**，估计的"平均"都不对了。等概率不是道德要求，是"无偏"的数学前提。

**3. 判断题并说明理由："SRS 人人等概率，所以任何子群都一定被公平覆盖。"**

**解答**：错误。等概率 ≠ 保证覆盖。稀有子群（占 1%）在 $n=100$ 时整体漏掉的概率高达 $(0.99)^{100}\approx37\%$——**等概率让每次抽取都不看子群，稀有子群全靠运气**。这就是教材"SRS 在异质总体中可能不高效、导致某些子群代表性不足"的根源。要保证覆盖，用分层采样（§4.3.2）。

## 第二组：计算实践

**4. 手算 + 代码验证。** 总体 $N=10000$、均值 50、标准差 10。（a）$n=100$ 时样本均值的标准差是多少？（b）$n=400$ 呢？（c）样本量翻 4 倍，误差怎么变？为什么？

**解答**：
（a）$\sigma/\sqrt n=10/\sqrt{100}=1.0$。
（b）$10/\sqrt{400}=0.5$。
（c）样本量翻 4 倍（$\sqrt4=2$），误差减半——**平方根定律**。想精确十倍（误差缩到 $1/10$），样本要百倍（$n$ 乘 100）。这就是深度学习里 batch 大小收益递减的根源。

代码验证：见《代码.md》步骤 3——$n=25/100/400$ 的样本均值标准差实测 $1.999/1.000/0.500$，与理论完全吻合。

**5. 用代码验证无偏性。** 重复 1 万次 $n=100$ 的 SRS，算样本均值的均值，确认它收敛到总体均值；再对比"只取编号靠前 100 人"的估计，看偏差从哪来。

**解答**：

```python
import numpy as np
np.random.seed(0)
pop = np.random.normal(50, 10, 10000)
reps = [np.random.choice(pop, 100, replace=False).mean() for _ in range(10000)]
print("SRS 样本均值均值 =", round(np.mean(reps), 3), " 总体均值 =", round(pop.mean(), 3))
print("取前 100 人（非随机）=", round(pop[:100].mean(), 3))
```

输出（大致）：

```text
SRS 样本均值均值 = 50.002  总体均值 = 50.000
取前 100 人（非随机）= 49.712
```

SRS 的样本均值平均下来贴总体均值（无偏）；"取前 100 人"因编号序与分布相关而有偏差。**思路点拨**：单次 SRS 也可能偏（50.5 或 49.8），但"平均起来"回到 50——无偏是"平均"性质，不是"每次都准"。若有人把"一次 SRS 估计偏了"当成"SRS 有偏"，那是混淆了无偏（bias=0）与方差（单次误差）。

## 第三组：DL 延伸

**6. 训练/测试划分场景。** 你要划分训练集与测试集。方案 A：纯随机划分（SRS）；方案 B：按类别分层划分。数据里"癌症阳性"只占 2%。（a）方案 A 的风险是什么？（b）为什么医疗场景几乎必须用方案 B？（c）`train_test_split` 的 `random_state` 参数在做什么？

**解答**：
（a）阳性只占 2%，随机划分时阳性可能大部分挤进训练集或测试集——若测试集里阳性样本太少，模型"是否检测到癌症"的测试误差会方差爆炸（少数样本决定结论）。**SRS 的"等概率"不保证稀有类在训练/测试两侧都均匀。**
（b）方案 B（分层）按类别比例分配训练/测试——保证两侧都含有约 2% 的阳性，稀有类的评估才稳定。医疗、欺诈检测、罕见事件里，稀有类是研究重点，纯随机划分等于让关键子群听天由命。
（c）`random_state` 固定随机种子——让"随机划分"可复现。**SRS 是随机的，但随机需要能被重现**（同一实验换机器重跑、论文可复现、调试可定位），这正是"受控随机"的工程体现。不设 `random_state`，每次跑训练集不同，实验结果无法比较。
**思路点拨**：若有人答"random_state 让划分更随机"，方向反了——它让随机**固定**（可复现），不是更随机。若有人答"方案 A 就行，反正测试集也代表分布"，那是忽略了稀有类在小测试集里代表不了——**SRS 的"无偏"是平均意义的，具体到这一次划分，稀有类可能失衡**。
