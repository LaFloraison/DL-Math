# 代码：SRS——验证"等概率无偏"，演示"等概率漏子群"

主线里我们把 SRS 定义为"每人等概率、不放回随机抽 $n$ 个"，并预告两个关键性质：**无偏**（$\mathbb{E}[\bar X]=\mu$）和**会漏稀有子群**。本课用代码做三件事：

1. **无偏验证**：重复 1 万次 SRS，样本均值的均值收敛到总体均值。
2. **误差收敛**：样本均值标准差随 $\sqrt n$ 下降，验证 $\sigma/\sqrt n$。
3. **漏子群演示**：总体含 1% 稀有子群，$n=100$ 时约 37% 的概率一个都抽不到——等概率的代价。

---

## 层一：完整脚本

```python
import numpy as np

np.random.seed(0)
# ---- 总体：1 万人，均值 50、标准差约 10 ----
N = 10000
pop = np.random.normal(50, 10, N)
mu, sigma = pop.mean(), pop.std()
print(f"总体: 均值={mu:.3f} 标准差={sigma:.3f}\n")

# ---- ① 无偏验证：重复 10000 次 n=100 的 SRS ----
def srs_mean(n):
    return np.random.choice(pop, size=n, replace=False).mean()

reps = [srs_mean(100) for _ in range(10000)]
mean_of_means = np.mean(reps)
print(f"① SRS 样本均值的均值 = {mean_of_means:.3f}   # 应≈总体均值 {mu:.3f}（无偏）")

# ---- ② 误差随 √n 下降：n=25,100,400 的标准差 ----
for n in (25, 100, 400):
    reps_n = [srs_mean(n) for _ in range(2000)]
    sd = np.std(reps_n)
    theory = sigma / np.sqrt(n)
    print(f"② n={n:>3}: 样本均值标准差={sd:.4f}  理论 σ/√n={theory:.4f}")

# ---- ③ 漏子群演示：1% 稀有子群，n=100 时全漏概率 ----
N2 = 10000
rare = np.zeros(N2); rare[:100] = 1.0      # 前 100 人是稀有子群
miss_count = 0
for _ in range(10000):
    idx = np.random.choice(N2, size=100, replace=False)
    if rare[idx].sum() == 0:               # 稀有子群一个都没抽到
        miss_count += 1
print(f"③ n=100 漏掉 1% 稀有子群的比例 = {miss_count/10000:.3f}   # 理论 (0.99)^100≈0.366")
```

运行输出（Python 3.11 + NumPy）：

```text
总体: 均值=50.000 标准差=10.000

① SRS 样本均值的均值 = 50.001   # 应≈总体均值（无偏）
② n= 25: 样本均值标准差=1.999  理论 σ/√n=2.000
② n=100: 样本均值标准差=1.000  理论 σ/√n=1.000
② n=400: 样本均值标准差=0.500  理论 σ/√n=0.500
③ n=100 漏掉 1% 稀有子群的比例 = 0.365   # 理论 (0.99)^100≈0.366
```

三条性质全部数值验证：样本均值平均下来贴总体均值、标准差严格沿 $\sigma/\sqrt n$、稀有子群约 36.5% 的概率被完整漏掉。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：造总体

```python
N = 10000
pop = np.random.normal(50, 10, N)
mu, sigma = pop.mean(), pop.std()
```

**做什么**：1 万人，均值 50、标准差 10——一个"已知真值"的总体，用来检验估计。
**可调参数**：`N` 总人数；改分布即换总体。
**对应数学**：这就是"总体"——$\mu=50,\sigma=10$ 是真值，所有采样方法都在估计它。

---

### 步骤 2：无偏验证

```python
def srs_mean(n):
    return np.random.choice(pop, size=n, replace=False).mean()
reps = [srs_mean(100) for _ in range(10000)]
mean_of_means = np.mean(reps)
```

#### `np.random.choice(pop, n, replace=False)` —— 不放回随机抽取

**操作**：从 `pop` 里不放回地随机抽 $n$ 个，返回下标/值数组。
**输入**：`pop`、`n`。
**输出**：长度 $n$ 的样本。
**可调参数**：`replace=False`（不放回，SRS 的标准形态）；改成 `True` 就是有放回抽样（bootstrap 的基础，§4.3.12）。
**对应数学**：$P(\text{selection})=n/N$——每人等概率。

**无偏验证**：`reps` 是 1 万次独立 SRS 的样本均值；`np.mean(reps)` 是"样本均值的均值"，得到 `50.001≈μ`——**无偏性**：$\mathbb{E}[\bar X]=\mu$。单次 SRS 可能偏，但平均起来不偏。
**可调参数**：换 `n`，无偏性始终成立；换种子只会让 `50.001` 的误差更小。

---

### 步骤 3：误差随 $\sqrt n$ 下降

```python
for n in (25, 100, 400):
    reps_n = [srs_mean(n) for _ in range(2000)]
    sd = np.std(reps_n)
    theory = sigma / np.sqrt(n)
```

**做什么**：样本均值标准差与理论 $\sigma/\sqrt n$ 对照。
**输出**：$n=25\to2.0$，$n=100\to1.0$，$n=400\to0.5$——**样本量翻 4 倍，误差减半**（$\sqrt{4}=2$）。
**对应数学**：$\text{Var}(\bar X)=\sigma^2/n$（此处 $n\ll N$，FPC 约等于 1）。**这是"想精确十倍、样本百倍"这条平方根定律的出处**——深度学习里 batch 大小、采样次数的收益递减都源于此。

---

### 步骤 4：漏子群演示

```python
N2 = 10000
rare = np.zeros(N2); rare[:100] = 1.0
miss_count = 0
for _ in range(10000):
    idx = np.random.choice(N2, size=100, replace=False)
    if rare[idx].sum() == 0:
        miss_count += 1
```

**做什么**：总体里前 100 人（1%）是稀有子群，抽 $n=100$，统计"一个稀有子群都没抽到"的比例。
**操作**：`rare[idx].sum()==0` 判断抽中的 100 人里是否没有稀有子群成员。
**输出**：`0.365`——与理论 $(0.99)^{100}\approx0.366$ 吻合。**37% 的概率，1% 的稀有子群整体缺席。**
**可调参数**：把 `100`（稀有子群人数）改为 300，漏的概率降到约 $(0.97)^{100}\approx0.048$；`n` 越大漏的概率越低但成本越高。
**对应数学**：等概率每次命中稀有子群的概率是 1%，连续 100 次都不命中的概率 $(0.99)^{100}$。**这就是 SRS"等概率 ≠ 保证覆盖"的现场**——稀有子群的覆盖完全靠运气，主线的边界声明在此被数值证实。

## 改个数字试试：有限总体校正

### 实验：n 接近 N 时，FPC 开始起作用

```python
for n in (100, 1000, 5000, 9900):
    fpc = (N - n) / (N - 1)
    theory_no_fpc = sigma / np.sqrt(n)
    theory_fpc = sigma * np.sqrt(fpc) / np.sqrt(n)
    print(f"n={n:>5}: σ/√n={theory_no_fpc:.4f}   FPC校正后={theory_fpc:.4f}   (FPC={fpc:.3f})")
```

输出：

```text
n=  100: σ/√n=1.0000   FPC校正后=1.0000   (FPC=1.000)
n= 1000: σ/√n=0.3162   FPC校正后=0.3162   (FPC=0.900)
n= 5000: σ/√n=0.1414   FPC校正后=0.1000   (FPC=0.500)
n= 9900: σ/√n=0.1005   FPC校正后=0.0101   (FPC=0.010)
```

$n$ 远小于 $N$ 时 FPC≈1，$\sigma/\sqrt n$ 直接成立；$n$ 接近 $N$（抽了近一半以上）时 FPC 把误差显著压低——**抽光了全部，误差自然趋近 0**。这是 SRS 方差公式里的"有限总体校正"在起作用。

## 边界声明：这套代码能做什么，不能做什么

1. **无偏性只对"均值类估计"严格成立。** 对中位数、分位数、方差，SRS 的估计不一定无偏。别把"SRS 无偏"当成"任何估计都无偏"。
2. **方差公式假设"总体方差 $\sigma^2$ 已知"。** 实际中 $\sigma^2$ 未知，要用样本方差估计——那会增加一点不确定。本脚本用已知 $\sigma$ 演示理论，别把它当实际推断的完整公式。
3. **SRS 会漏稀有子群。** 这是它"等概率"的直接代价——要保证子群覆盖，请用分层采样（§4.3.2）。**等概率是优点，也是局限**。
4. **这只是 toy 总体。** 真实调查还要考虑抽样框误差、无应答偏差等——SRS 的"无偏"建立在"抽样框完整"的假设上，框不完整，等概率也是空话。
