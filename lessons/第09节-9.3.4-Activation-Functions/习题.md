# 习题：四道门的选择题

## 第一组：概念检验

**1. 判断题并说明理由**："ReLU 的导数在正半轴恒为 1，所以 ReLU 网络绝不会出现梯度消失或训练失败。"

**2. 单选题**：一个二分类任务，网络的输出层应该用哪个激活函数最合适？
- (A) ReLU
- (B) Tanh
- (C) Sigmoid
- (D) LeakyReLU

**3. 简答**：什么是"死亡 ReLU (dying ReLU)"？它为什么几乎不可逆？LeakyReLU 和 PReLU 分别怎么解决它？

### 解答与思路点拨

**1. 错误。** ReLU 正半轴导数恒 1 解决了"激活函数饱和导致的梯度消失"，但训练失败还有别的来源：(a) **负半轴导数恒 0**——死掉的神经元梯度为 0；(b) **无上界输出**——激活值可无限增长，深网络仍可能爆炸；(c) 梯度消失也可能来自**权重矩阵谱**而非激活（§9.3.3 的时间链）；(d) 还有局部极小、过拟合等。ReLU 是"消除了某一类消失"，不是"消灭了所有失败"。

**2. (C)。** Sigmoid 输出在 (0,1)，天然是"概率"——二分类（是/否）输出层的标准选择。Tanh 范围 (-1,1) 适合隐藏层；ReLU/LeakyReLU 输出无上界，不能直接当概率。**陷阱**：不要因为"sigmoid 会梯度消失"就回避它——那说的是**深层隐藏层**；输出层只有一层，不构成深链，sigmoid 的概率语义才是关键。

**3.** 死亡 ReLU：神经元的输入 $z=wx+b$ 长期落在负半轴时，导数恒为 0 → 梯度为 0 → 权重永不更新 → 该神经元"永不激活"。**几乎不可逆**是因为更新量为 0，没有外力把 $z$ 推回正半轴。LeakyReLU 把负半轴换成 $\alpha z$（$\alpha$ 固定如 0.01），梯度非 0，神经元能"爬"回来；PReLU 让 $\alpha$ 成为**可学习参数**，由训练自动确定坡度——两者都在"复活"与"非线性"之间取平衡。

## 第二组：计算实践

**4. 手算**：$z=3.0$ 处，sigmoid 的导数是多少（保留 3 位小数）？$z=3.0$ 处，tanh 的导数呢？哪个"通道更宽"？

**5. 代码验证**：用本节的 `dsigmoid`/`dtanh` 验证 4 的结果；再算 $z=-3.0$ 处两者的导数，对比正负两端的导数，说明"sigmoid/tanh 为什么在输入很大时梯度消失"。

### 解答与思路点拨

**4.** $\sigma(3)=\frac{1}{1+e^{-3}}\approx 0.953$，$\sigma'(3)=0.953\times(1-0.953)\approx 0.045$。$\tanh'(3)=1-\tanh^2(3)$，$\tanh(3)\approx 0.995$，所以 $\tanh'(3)=1-0.995^2\approx 0.010$。**tanh 在 $z=3$ 处的通道（0.010）比 sigmoid（0.045）更窄**——但两者都已经趋近 0，都是"饱和"。

**5.** 验证：`dsigmoid(3.0)` ≈ 0.045、`dtanh(3.0)` ≈ 0.010；`dsigmoid(-3.0)` = 0.953×(1-0.953) ≈ 0.045、`dtanh(-3.0)` ≈ 0.010。正负两端对称。**共同点**：离 0 越远，导数越接近 0（$z=\pm3$ 都只剩 0.01~0.04）——这就是"饱和区"，梯度在这里被闷死。对照 ReLU 在 $z=3$ 处导数恒 1，差距一目了然。

## 第三组：DL 延伸

**6. 场景判断**：你的深层网络训练时损失不再下降，检查发现隐藏层激活值大量为 0（很多神经元死了）。请诊断：这是哪种激活函数的典型症状？该换什么？除了换激活，还有哪些缓解手段？

**7. 思考题**：教材 Figure 9.4 比较了 深度 1/3/5 × relu/tanh 六组训练曲线。为什么**同样的深度**下，ReLU 与 tanh 的收敛曲线会有明显差异（比如 ReLU 初始损失下降更陡）？请用"导数通道宽度"解释。

### 解答与思路点拨

**6.** 大量激活值恒为 0 = **死亡 ReLU 的典型症状**（ReLU 负半轴导数恒 0）。修复方向：(a) 换 LeakyReLU/PReLU（给负半轴坡度）；(b) **调整学习率与初始化**——学习率过大常把权重推入"全负"区域，改用更小的学习率或更合适的初始化（He init）；(c) 用 BatchNorm 把输入分布拉回激活函数的不饱和区。注意：死神经元有时是"暂时的"（某批数据把 $z$ 推到负区），需结合激活分布直方图判断。

**7.** ReLU 正半轴导数恒 1，误差穿过每个活跃层**不衰减**——所以 ReLU 网络初始阶段损失下降陡（梯度畅通，底层学得动）；tanh 导数在饱和区趋近 0，误差穿层被反复缩放，初始收敛平缓（教材输出里 tanh "更渐进的曲线"）。但注意：**深度越深，tanh 的劣势越放大**（$0.25^{20}$ 与 $1^{20}$ 的差距随层数指数拉开）——所以 深度 5 时两者的曲线差异比深度 1 时明显得多。这就是"激活函数与深度强耦合"（主线边界声明）的数值原因。
