# 代码：激活函数的"通道宽度"——数值解剖四道门

主线里说：激活函数是"梯度的搬运工"，它的**导数**决定了梯度每层能通过多少。本节代码把四个激活函数**逐一解剖**：

1. **动物园**：在 $z=-2, 0, 2$ 三个点分别打印 sigmoid/tanh/ReLU/LeakyReLU 的**值**与**导数**——导数就是"通道宽度"；
2. **恒等式验证**：用差分法证明 $\sigma'(z) = \sigma(z)(1-\sigma(z))$；
3. **死亡 ReLU**：构造一个输入恒为负的神经元，看 ReLU 的梯度如何永远为 0（神经元死亡），而 LeakyReLU 如何靠 $\alpha$ 小坡复活。

脚本只依赖 NumPy。

---

## 层一：完整脚本

```python
import numpy as np

def sigmoid(z):  return 1.0/(1.0+np.exp(-z))
def tanh(z):     return np.tanh(z)
def relu(z):     return np.maximum(z, 0)
def lrelu(z, alpha=0.01): return np.where(z > 0, z, alpha*z)

def dsigmoid(z): return sigmoid(z)*(1-sigmoid(z))    # σ(1-σ)
def dtanh(z):    return 1.0-tanh(z)**2               # 1-tanh²
def drelu(z):    return (z > 0).astype(float)        # 正半轴 1，负半轴 0
def dlrelu(z, alpha=0.01): return np.where(z > 0, 1.0, alpha)

print("=== 四个激活函数：值 与 导数（z = -2, 0, 2）===")
z = np.array([-2.0, 0.0, 2.0])
for name, f, df in [("sigmoid",sigmoid,dsigmoid), ("tanh",tanh,dtanh),
                    ("relu",relu,drelu), ("leakyrelu",lrelu,dlrelu)]:
    print(f"{name:10s} 值={np.round(f(z),3)}  导数={np.round(df(z),3)}")

print("\n=== 验证 σ'(z) = σ(z)(1-σ(z))（取 z=0.7，用差分法）===")
z0, eps = 0.7, 1e-6
num = (sigmoid(z0+eps) - sigmoid(z0-eps)) / (2*eps)
print(f"σ(0.7)={sigmoid(z0):.5f},  差分法 σ'(0.7)={num:.5f},  公式 σ(1-σ)={dsigmoid(z0):.5f}")

print("\n=== 死亡 ReLU：一个输入恒为负的神经元 ===")
x = np.array([-2.0, -1.0, 0.0])    # 训练输入
w, b = 1.0, -2.0                   # 权重使 z = w*x+b 恒 ≤ 0
z = w*x + b
print(f"z 值 = {z}")
print(f"ReLU 导数     = {drelu(z)}   → 梯度全 0，权重永不更新（神经元死了）")
print(f"LeakyReLU 导数(α=0.01) = {dlrelu(z)}   → 梯度非 0，能复活")
```

运行输出（Python 3.11 + NumPy）：

```text
=== 四个激活函数：值 与 导数（z = -2, 0, 2）===
sigmoid    值=[0.119 0.5   0.881]  导数=[0.105 0.25  0.105]
tanh       值=[-0.964 0.    0.964]  导数=[0.071 1.    0.071]
relu       值=[0. 0. 2.]           导数=[0. 0. 1.]
leakyrelu  值=[-0.02  0.    2.  ]  导数=[0.01 0.01 1.  ]
=== 验证 σ'(z) = σ(z)(1-σ(z))（取 z=0.7，用差分法）===
σ(0.7)=0.66819,  差分法 σ'(0.7)=0.22171,  公式 σ(1-σ)=0.22171
=== 死亡 ReLU：一个输入恒为负的神经元 ===
z 值 = [-4. -3. -2.]
ReLU 导数     = [0. 0. 0.]   → 梯度全 0，权重永不更新（神经元死了）
LeakyReLU 导数(α=0.01) = [0.01 0.01 0.01]   → 梯度非 0，能复活
```

读这组输出：

- **通道宽度一目了然**：sigmoid 的导数最大 **0.25**（在 $z=0$），两端 0.105——$z$ 一偏离 0 就"卡"；tanh 导数最大 **1**，两端 0.071——比 sigmoid 好但同样饱和；ReLU 正半轴**恒 1**、负半轴恒 0；LeakyReLU 正半轴 1、负半轴 **0.01**。
- **恒等式坐实**：差分法算出的 $\sigma'(0.7)=0.22171$ 与公式 $\sigma(1-\sigma)=0.22171$ **完全相等**。
- **死亡 ReLU 现场**：`z=[-4,-3,-2]` 全在负半轴，ReLU 导数全是 0——这个神经元的梯度永远为 0，权重永不更新；LeakyReLU 给每个负值配了 0.01 的坡度，梯度能顺着爬回来。

## 层二：分步逐函数拆解

### 步骤 1：四个激活函数与其导数

```python
def sigmoid(z):  return 1.0/(1.0+np.exp(-z))
def tanh(z):     return np.tanh(z)
def relu(z):     return np.maximum(z, 0)
def lrelu(z, alpha=0.01): return np.where(z > 0, z, alpha*z)

def dsigmoid(z): return sigmoid(z)*(1-sigmoid(z))
def dtanh(z):    return 1.0-tanh(z)**2
def drelu(z):    return (z > 0).astype(float)
def dlrelu(z, alpha=0.01): return np.where(z > 0, 1.0, alpha)
```

#### `sigmoid` / `tanh` / `relu` / `lrelu` —— 四道门

**做什么**：在任意点 $z$ 上求四个激活函数的值。
**操作**：sigmoid 用 `np.exp` 算 $1/(1+e^{-z})$；tanh 直接用 NumPy 内置；relu 用 `np.maximum(z,0)`；lrelu 用 `np.where(z>0, z, alpha*z)` 把负半轴改成缓坡。
**输入**：`z`（标量或数组）、`alpha`（仅 leakyrelu，负半轴坡度）。
**输出**：同形状数组，每个点的函数值。
**可调参数**：
- `alpha`（LeakyReLU）是坡度旋钮：`0.01` 是常规值；`0` 退化为 ReLU（死墙）；`0.2` 坡度更陡（复活更快但更接近线性）；`1` 就变成恒等函数（失去非线性）。**PReLU 的 $\alpha$ 是训练中学出来的，LeakyReLU 的 $\alpha$ 是写死的——这就是两者的唯一区别。**

#### `dsigmoid` / `dtanh` / `drelu` / `dlrelu` —— 通道宽度

**做什么**：求四个激活函数的**导数**——即"梯度每穿过这个神经元还剩多少"。
**操作**：
- `dsigmoid = σ(z)(1-σ(z))`——这是 sigmoid 导数的**解析公式**，靠"算过的值"直接得到（见步骤 2 的差分验证）。
- `dtanh = 1-tanh(z)²`——类似地，tanh 的导数用其自身表示。
- `drelu = (z>0).astype(float)`——布尔比较转 0/1：正半轴 1、负半轴 0。
- `dlrelu = np.where(z>0, 1.0, alpha)`——正半轴 1、负半轴 `alpha`。
**输入**：`z`、`alpha`。
**输出**：同形状数组，每个点的导数值。
**可调参数**：同函数本体。导数与函数一一对应——**选激活函数就是选导数曲线**。
**对应数学**：主线定义块里四个函数的导数。sigmoid 的"最大 0.25"、tanh 的"最大 1"、ReLU 的"恒 1/恒 0"、LeakyReLU 的"1/α"——这些数字就是"通道宽度"的量化。

### 步骤 2：差分法验证 σ'(z) = σ(z)(1-σ(z))

```python
z0, eps = 0.7, 1e-6
num = (sigmoid(z0+eps) - sigmoid(z0-eps)) / (2*eps)
print(f"σ(0.7)={sigmoid(z0):.5f},  差分法 σ'(0.7)={num:.5f},  公式 σ(1-σ)={dsigmoid(z0):.5f}")
```

**做什么**：不背公式，用导数的定义式（中心差分）算出 $\sigma'(0.7)$，与解析公式 $\sigma(1-\sigma)$ 对照。
**操作**：$\frac{\sigma(0.7+\epsilon)-\sigma(0.7-\epsilon)}{2\epsilon}$ 是 $d\sigma/dz$ 在 0.7 处的数值近似。$\epsilon=10^{-6}$ 精度足够。
**输入**：`z0`（求导点）、`eps`（差分步长）。
**输出**：三个小数——函数值、差分导数、公式导数。
**可调参数**：`eps`——太大失真、太小浮点误差。可换 `z0`（如 3.0）验证"两端导数趋近 0"。
**对应数学**：验证主线"$\sigma'(z) = \sigma(z)(1-\sigma(z))$"。这个恒等式之所以重要，是因为它允许"算一次 σ 就同时拿到它的导数"——反向传播里极其高效。

### 步骤 3：死亡 ReLU 现场演示

```python
x = np.array([-2.0, -1.0, 0.0])
w, b = 1.0, -2.0
z = w*x + b
print(f"ReLU 导数     = {drelu(z)}   → 梯度全 0，权重永不更新（神经元死了）")
print(f"LeakyReLU 导数(α=0.01) = {dlrelu(z)}   → 梯度非 0，能复活")
```

**做什么**：构造一个"命中注定死亡"的神经元——它的权重使所有输入的 $z=wx+b$ 都落在负半轴。
**操作**：`w=1, b=-2`，对输入 `x∈{-2,-1,0}`，$z$ 恒 ≤ 0。ReLU 导数在这些点全为 0；LeakyReLU 导数全为 0.01。
**输入**：`x`（训练样本）、`w`、`b`。
**输出**：两行导数数组。
**可调参数**：改 `w`/`b` 让 $z$ 有一部分落在正半轴，那个神经元就没死。**"死亡"不是永久属性，是"当前权重把输入全推到负半轴"的状态**——但 ReLU 一旦进入这个状态，梯度为 0、权重不动、永远出不来，所以"死亡"在 ReLU 里是**不可逆的**；LeakyReLU 的 0.01 坡度让梯度非 0，权重会被缓缓推回正半轴——**复活**。
**对应数学**：死 ReLU 的机制 = §9.3.4 教材"ReLU 会让一些神经元停止工作（永不激活）"。参数 `alpha` 越大复活越快，但网络越接近线性（非线性减弱）——教材引出的 LeakyReLU/PReLU 就是在"复活速度"与"非线性强度"之间取平衡。

## 改个数字试试：α 从 0.01 改到 0.3

```python
z_neg = np.array([-3.0, -1.0])
for alpha in (0.01, 0.1, 0.3):
    print(f"α={alpha}: 负半轴导数 = {dlrelu(z_neg, alpha)}")
```

```text
α=0.01: 负半轴导数 = [0.01 0.01]
α=0.1 : 负半轴导数 = [0.1  0.1 ]
α=0.3 : 负半轴导数 = [0.3  0.3 ]
```

坡度越大，死去的神经元"复活"得越快（梯度越大），但负半轴不再是墙——$\alpha$ 越接近 1，LeakyReLU 越像恒等函数，非线性越弱。**这就是教材提到的 LeakyReLU/PReLU 的设计张力：复活 vs 非线性，一个 α 全兜着。** PReLU 让网络自己在训练中学这个 α，正是把这个旋钮交给数据。

## 边界声明：这套代码能做什么，不能做什么

1. **它看的是"单点导数"，不是"整个网络的收敛"**。单个神经元导数 0.25 vs 1 是"通道宽度"，但真实收敛还依赖权重谱、深度、归一化、优化器。§9.3 的梯度链实验（$0.25^{20}\approx10^{-12}$）是把"单点导数"放大到深层的视图——两者要合起来读。
2. **"导数恒 1"不保证训练成功**。ReLU 解决了梯度消失，却带来无上界输出（激活值可无限增长 → 后续层爆炸）与死神经元；现代深度网络几乎总要在 ReLU 之外搭配归一化（BatchNorm/LayerNorm）来兜底。**没有哪个激活函数是万能的。**
3. **数值实现与教材公式的边界**：本脚本用 NumPy 直接实现；真实框架（PyTorch）把激活与导数合并进自动微分，但**背后正是这些公式**——看懂数值实现，才能看懂框架在替你做什么。
