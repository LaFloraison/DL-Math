# 代码：统计与概率中的矩——四个形容词，四道算术，一张现场

主线把矩定义为"绕某个中心 $c$ 的 n 次幂期望"，并强调 $E[X^n]$ 是理论量、`np.mean(x**n)` 只是它的样本估计。本课用代码做四件事：

1. **教材例子验证**：对 $N(50, 5^2)$ 抽样，算一阶/二阶原始矩与中心矩，核对教材数字。
2. **第三矩的方向**：用右尾的伽马分布看 $\mu_3 > 0$——Toy Model 的"偏斜"。
3. **矩不存在的现场**：柯西分布的样本均值永不收敛——"存在且有限"不是套话。
4. **离群点冲击**：一个点如何让四阶矩跳两个数量级。

---

## 层一：完整脚本

```python
import numpy as np

def raw_moment(x, n):
    """n 阶原始矩：E[X^n]，绕原点 0 转。"""
    return np.mean(x ** n)

def central_moment(x, n):
    """n 阶中心矩：E[(X-E[X])^n]，绕均值转。"""
    mu = np.mean(x)
    return np.mean((x - mu) ** n)

np.random.seed(7)

# ---- ① 教材例子：N(50, 5^2)，抽样 10000 个 ----
x = np.random.normal(50, 5, 10000)
print(f"μ1' = E[X]      = {raw_moment(x, 1):8.3f}    # 一阶原始矩 = 均值 ≈ 50")
print(f"μ2' = E[X^2]    = {raw_moment(x, 2):8.3f}    # 二阶原始矩 ≈ 50^2+5^2 = 2525")
print(f"μ1  = E[X-mu]   = {central_moment(x, 1):8.4f}    # 一阶中心矩恒 ≈ 0")
print(f"μ2  = E[(X-mu)^2]= {central_moment(x, 2):8.3f}    # 二阶中心矩 = 方差 ≈ 25")

# ---- ② 第三矩带方向：右尾分布 μ3 > 0（Toy Model 的"偏斜"）----
z = np.random.gamma(2.0, 1.0, 20000)
print(f"伽马(2,1) μ3 = {central_moment(z, 3):8.3f}    # > 0：右尾偏斜")

# ---- ③ 矩不总是存在：柯西分布一阶矩不存在，样本均值不收敛 ----
c = np.random.standard_cauchy(20000)
for k in (100, 1000, 20000):
    print(f"柯西前 {k:>6} 个样本均值 = {np.mean(c[:k]):8.3f}    # 越取越多越乱 → 期望不存在")

# ---- ④ 一个离群点对高阶矩的冲击 ----
y = np.random.normal(0, 1, 1000)
y_out = y.copy(); y_out[0] = 20.0
print(f"干净数据   μ2 = {central_moment(y, 2):.3f}, μ4 = {central_moment(y, 4):.2f}")
print(f"加离群点   μ2 = {central_moment(y_out, 2):.3f}, μ4 = {central_moment(y_out, 4):.2f}")
```

运行输出（Python 3.11 + NumPy 2.x）：

```text
μ1' = E[X]      =   49.955    # 一阶原始矩 = 均值 ≈ 50
μ2' = E[X^2]    = 2520.080    # 二阶原始矩 ≈ 50^2+5^2 = 2525
μ1  = E[X-mu]   =   0.0000    # 一阶中心矩恒 ≈ 0
μ2  = E[(X-mu)^2]=   24.614    # 二阶中心矩 = 方差 ≈ 25
伽马(2,1) μ3 =    3.877    # > 0：右尾偏斜
柯西前    100 个样本均值 =   -0.750    # 越取越多越乱 → 期望不存在
柯西前   1000 个样本均值 =   -1.320    # 越取越多越乱 → 期望不存在
柯西前  20000 个样本均值 =   -1.474    # 越取越多越乱 → 期望不存在
干净数据   μ2 = 0.997, μ4 = 2.84
加离群点   μ2 = 1.397, μ4 = 162.90
```

四行核心结论：**一阶中心矩恒为 0（什么都不测）；二阶中心矩 ≈ 25 就是方差；三阶中心矩带正负号描述偏斜；四阶中心矩被一个离群点从 2.84 炸到 162.90。** 下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义两个矩函数

```python
import numpy as np

def raw_moment(x, n):
    """n 阶原始矩：E[X^n]，绕原点 0 转。"""
    return np.mean(x ** n)

def central_moment(x, n):
    """n 阶中心矩：E[(X-E[X])^n]，绕均值转。"""
    mu = np.mean(x)
    return np.mean((x - mu) ** n)
```

#### `import numpy as np` —— 工具导入

**操作**：加载 NumPy 并绑定为 `np`。
**对应数学**：为 $\sum$（`np.mean`）、$(\cdot)^n$（`**`）提供执行者。

#### raw_moment —— n 阶原始矩

**做什么**：算 $E[X^n]$——把每个样本取 n 次幂，再求平均。
**输入**：`x`——一维样本数组，形状 `(N,)`，N 个观测值，每个位置是一个样本；`n`——阶数，正整数（1、2、3、…）。
**输出**：一个标量（形状 `()`），n 阶原始矩的样本估计。
**操作**：`x ** n` 先对数组逐元素求 n 次幂（结果仍是 `(N,)`），`np.mean` 再对所有元素求算术平均。
**可调参数**：`n` 就是阶数旋钮——`n=1` 得均值，`n=2` 得 $E[X^2]$，`n=3,4` 得更高阶。n 不能为 0（0 次幂恒为 1，矩退化无信息）；n 很大时对大数值样本会溢出（见边界声明）。
**对应数学**：教材的原始矩公式 $\mu_n' = E[X^n]$。

#### central_moment —— n 阶中心矩

**做什么**：算 $E[(X-E[X])^n]$——先减去均值，再取 n 次幂平均。
**输入**：同 `raw_moment`；`x` 形状 `(N,)`，`n` 正整数。
**输出**：一个标量（形状 `()`），n 阶中心矩的样本估计。
**操作**：`np.mean(x)` 先算出均值 $\mu$（一阶原始矩），`(x - mu) ** n` 逐元素减均值再取幂（结果 `(N,)`），再 `np.mean` 平均。
**可调参数**：`n=2` 得方差（胖瘦），`n=3` 得带符号的偏斜信息，`n=4` 得尖峰信息。
**对应数学**：教材的中心矩公式 $\mu_n = E[(X-E[X])^n]$。

### 步骤 2：教材例子 $N(50, 5^2)$ 的对账

```python
np.random.seed(7)
x = np.random.normal(50, 5, 10000)
print(f"μ1' = E[X]      = {raw_moment(x, 1):8.3f}    # 一阶原始矩 = 均值 ≈ 50")
print(f"μ2' = E[X^2]    = {raw_moment(x, 2):8.3f}    # 二阶原始矩 ≈ 50^2+5^2 = 2525")
print(f"μ1  = E[X-mu]   = {central_moment(x, 1):8.4f}    # 一阶中心矩恒 ≈ 0")
print(f"μ2  = E[(X-mu)^2]= {central_moment(x, 2):8.3f}    # 二阶中心矩 = 方差 ≈ 25")
```

#### `np.random.seed(7)` —— 固定随机数种子

**做什么**：把随机数发生器钉在同一个起点，保证"你跑出来的数字和我一样"。
**操作**：重置伪随机序列。
**可调参数**：数字 `7` 可换成任意整数——换一个种子，抽样不同，输出在小数点后几位有差异（这正是"样本矩会波动"的现场）。
**对应数学**：没有任何数学角色，纯粹为了复现。

#### `np.random.normal(50, 5, 10000)` —— 从正态分布抽样

**做什么**：从 $N(\mu=50, \sigma=5)$ 抽出 10000 个样本，当作教材分布的"替身"。
**输入**：`50` 是均值 $\mu$；`5` 是标准差 $\sigma$（不是方差！）；`10000` 是样本量。
**输出**：形状 `(10000,)` 的一维数组。
**可调参数**：`loc`/`scale`（这里按位置传 50/5）、`size` 是第三个可传参数——`size` 传 `(3, 4)` 可得到二维样本，本课只需要一维。样本量越大，样本矩越贴近理论值（大数定律）。
**对应数学**：教材例子 $N(50, 5^2)$——理论上一阶原始矩 $E[X]=50$、二阶中心矩 $\mu_2=25$。

**为什么输出对不上教材的"精确"数字？** 教材写的是理论矩（分布决定的数），这里算的是样本矩。$E[X]$ 理论上是 50，抽样 10000 个算出来 49.955；$\mu_2$ 理论上 25，算出来 24.614——**样本永远只是近似**，这就是主线"标靶 vs 箭簇"的区分。

### 步骤 3：第三矩的方向信息

```python
z = np.random.gamma(2.0, 1.0, 20000)
print(f"伽马(2,1) μ3 = {central_moment(z, 3):8.3f}    # > 0：右尾偏斜")
```

#### `np.random.gamma(2.0, 1.0, 20000)` —— 抽一个右尾分布

**做什么**：从形状参数 2.0、尺度参数 1.0 的伽马分布抽 20000 个样本——它天然右尾偏斜。
**输入**：前两个参数是分布参数，第三个是样本量。
**输出**：形状 `(20000,)` 的一维数组。
**可调参数**：形状参数越小（如 0.5），分布越歪，$\mu_3$ 越大；形状参数越大，分布越接近对称，$\mu_3$ 越接近 0。这也是"能不能再传参数"的答案——伽马有形状、尺度、样本量三个参数。
**对应数学**：三阶中心矩 $\mu_3 = E[(X-\mu)^3]$。右尾长 → 正的三次方偏差占上风 → $\mu_3 > 0$。**这就是 Toy Model 里"偏斜"形容词的数值签名。**

### 步骤 4：柯西——矩不存在的现场

```python
c = np.random.standard_cauchy(20000)
for k in (100, 1000, 20000):
    print(f"柯西前 {k:>6} 个样本均值 = {np.mean(c[:k]):8.3f}    # 越取越多越乱 → 期望不存在")
```

#### `np.random.standard_cauchy(20000)` —— 抽柯西分布

**做什么**：从标准柯西分布抽 20000 个样本——它的尾巴极厚，一阶矩（期望）**不存在**。
**输入**：样本量 20000。
**输出**：形状 `(20000,)` 的一维数组。注意柯西样本会时不时蹦出一个几百上千的"疯子值"。
**可调参数**：只有样本量一个位置参数；`np.random.standard_cauchy` 不支持直接传定位/尺度，想换中心得用 `np.random.cauchy(loc, scale, size)`。
**对应数学**：教材说"若 $E[X^n]$ 存在且有限，则称 n 阶矩存在"。柯西分布的期望积分不收敛，**一阶矩都不存在**。大数定律对柯西失效——样本越多，均值不是越稳，而是越乱（-0.750 → -1.320 → -1.474，再来一轮又是另一组数）。
**警告**：`np.mean` 不会报错，它只会给你一个"看起来很权威的假数字"。代码层面你完全看不出"矩不存在"——这正是它危险的地方。

### 步骤 5：一个离群点如何打爆四阶矩

```python
y = np.random.normal(0, 1, 1000)
y_out = y.copy(); y_out[0] = 20.0
print(f"干净数据   μ2 = {central_moment(y, 2):.3f}, μ4 = {central_moment(y, 4):.2f}")
print(f"加离群点   μ2 = {central_moment(y_out, 2):.3f}, μ4 = {central_moment(y_out, 4):.2f}")
```

#### `np.random.normal(0, 1, 1000)` + `y_out[0] = 20.0` —— 造一个"污染样本"

**做什么**：先抽 1000 个标准正态样本（$\mu_2 \approx 1$、$\mu_4 \approx 3$，正态的理论四阶矩正是 3），再把第 0 个样本改成 20——模拟数据里混进一个异常点。
**输入**：`y` 形状 `(1000,)`。
**操作**：`y.copy()` 复制一份（不污染原数组），`y_out[0] = 20.0` 单点替换。
**可调参数**：离群点位置 `20.0` 和改哪个样本都可调——值越大、越靠"头"的位置，冲击越猛。
**对应数学**：$\mu_4 = E[(X-\mu)^4]$——四阶幂对"大偏差"极度放大。$20^4 = 160000$，一个点就把均值拉飞：$\mu_2$ 从 0.997 微涨到 1.397，$\mu_4$ 从 2.84 炸到 162.90。**二阶矩扛得住一个离群点，四阶矩扛不住。** 这就是"样本高阶矩不稳"的边界：偏度、峰度在小样本上不可信。

## 改个数字试试：把整个分布平移 100，看哪个矩会被骗

```python
x2 = x + 100.0
print(f"平移前   μ1' = {raw_moment(x, 1):9.4f},  μ2 = {central_moment(x, 2):8.3f},  μ3 = {central_moment(x, 3):9.3f}")
print(f"平移+100 μ1' = {raw_moment(x2, 1):9.4f},  μ2 = {central_moment(x2, 2):8.3f},  μ3 = {central_moment(x2, 3):9.3f}")
```

输出（大致）：

```text
平移前   μ1' =   49.9546,  μ2 =   24.614,  μ3 =   -4.643
平移+100 μ1' =  149.9546,  μ2 =   24.614,  μ3 =   -4.643
```

把 $N(50,5^2)$ 整体加 100：**一阶原始矩跟着涨了整整 100（49.95 → 149.95），二阶、三阶中心矩纹丝不动（24.614、-4.643）**。原因：原始矩绕原点 0 转，原点被平移了，它当然被骗；中心矩先减掉均值（平移量也被减掉），只关心"形状"。这正是主线"原始矩混着位置、中心矩只留形状"的数值证据。

顺带观察：正态分布理论三阶中心矩是 0，但这里样本估计出 -4.643——**理论为 0，样本却晃到 -4.6**。高阶矩的样本估计就是这样又慢又抖。

## 边界声明：这套代码能做什么，不能做什么

1. **样本矩 ≠ 理论矩。** 代码里全是 `np.mean(x ** n)` 这类样本估计。只有当样本量很大、且分布"良态"时，它们才贴近理论的 $E[X^n]$。样本小、或分布厚尾时，算出来的矩可能和真实值差十万八千里。
2. **矩不总是存在。** 柯西分布的期望不存在，`np.mean` 照样给你一个数——**"能算出一个数"和"矩存在"是两回事**。代码检测不了这一点，数学的定义才行。
3. **高阶矩对离群点极敏感。** 一个异常点能把 $\mu_4$ 的估计从 2.84 炸到 162.90。实践铁律：小样本上别信偏度、峰度；要估四阶矩，先清洗离群点、再要极大的样本。
4. **矩不能锁死分布。** 存在两个不同分布拥有相同的所有阶矩（矩问题）。这里算出来的矩是"摘要"，不是"身份证"——同样的矩可以对应不同的分布。
