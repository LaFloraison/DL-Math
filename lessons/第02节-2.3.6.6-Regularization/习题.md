# 习题：正则化——L2 与 Dropout

## 第一组：概念检验

**1.1（单选）** 原损失 1.0，权重 $[0.5, 0.8]$，$\lambda=0.1$，L2 正则化损失是：
- A. $1.089$
- B. $1.0445$
- C. $1.0895$
- D. $0.9555$

**1.2（判断并说明）** "Dropout 在训练和测试时都随机丢弃神经元。" 这句话对吗？测试时应该怎么做？

**1.3（填空）** L2 正则化在损失上加 $\frac{\lambda}{2}\sum \_\_\_$，目的是惩罚____权重；Dropout 以概率 $p$ 随机____神经元，防止神经元____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算 L2 惩罚：$w=[1.0, -2.0, 0.5]$、$\lambda=0.5$，算出惩罚项与正则化损失（原损失 2.0），用 NumPy 验证。

**2.2（代码验证）** 用 `np.random.default_rng(0)` 实现一次 $p=0.5$ 的 Dropout（激活 `[0.5,0.8,0.3,0.9]`），打印掩码与结果；再算测试期缩放 `a*(1-p)`。

**2.3（动手理解）** 在 $L=(w-5)^2$ 的梯度下降里加 L2 项（$\lambda=0.5$），跑 10 步，对比"有/无 L2"时 $w$ 收敛到的位置，解释差异。

## 第三组：DL 延伸

**3.1（场景判断）** PyTorch 里 `Adam(..., weight_decay=0.01)` 的 `weight_decay` 对应 L2 正则化的哪个参数？`nn.Dropout(0.5)` 里的 `0.5` 是什么？`model.eval()` 对 Dropout 做什么？

**3.2（场景分析）** 一个模型在训练集上准确率 99%、验证集上 80%——典型的过拟合。你会建议哪些正则化手段？分别对应 L2、Dropout、数据增强中的哪个思路？

## 解答与思路点拨

### 第一组

**1.1 答案：B（$1.0445$）。**
- **思路**：$\frac{0.1}{2}(0.5^2+0.8^2) = 0.05\times0.89 = 0.0445$；$1.0+0.0445 = 1.0445$。
- **点拨**：A（$1.089$）是漏了 $\frac12$（$0.1\times0.89=0.089$）；C 是把 $0.5^2$ 算成 $0.25$ 又多加一次。**注意 $\frac{\lambda}{2}$ 的 $\frac12$ 是公式的一部分。**

**1.2 不对。**
- **思路**：Dropout 只在**训练**时随机丢弃神经元（制造"子网络集成"）；**测试时关闭 Dropout**，并（教材版本）把输出乘以 $1-p$ 对齐期望。
- **点拨**：**"训练随机、测试确定 + 缩放"**是 Dropout 的完整约定。PyTorch 用 `model.eval()` 自动切换。

**1.3 答案：$w_i^2$；大；置零（丢弃）；过度共适应。**
- **思路**：L2 惩罚 $\frac{\lambda}{2}\sum w_i^2$ 惩罚大权重；Dropout 随机置零神经元，防共适应。
- **点拨**："L2 罚大权重、Dropout 破共谋"是本节的记忆锚点。

### 第二组

**2.1**
$\frac{\lambda}{2}\sum w^2 = \frac{0.5}{2}(1+4+0.25) = 0.25\times5.25 = 1.3125$；正则化损失 $= 2.0 + 1.3125 = 3.3125$。
```python
import numpy as np
w = np.array([1.0,-2.0,0.5])
pen = (0.5/2)*np.sum(w**2)
print(pen, 2.0 + pen)    # 1.3125 3.3125
```
- **思路**：先平方和、再乘 $\lambda/2$。注意负数平方后变正——L2 惩罚对负权重也有效。
- **点拨**：**L2 是"权重的平方和"**，符号无所谓，大小才是关键。

**2.2**
```python
rng = np.random.default_rng(0)
a = np.array([0.5,0.8,0.3,0.9])
mask = rng.random(4) > 0.5
print(mask.astype(int), a*mask)      # 每次运行结果由 seed 决定
print(a*(1-0.5))                     # 测试期缩放
```
- **思路**：掩码随机、激活乘掩码；测试缩放 $a(1-p)$。
- **点拨**：**`seed` 决定"谁消失"**——可复现是工程要求。换 seed，消失的神经元不同——这正是"每次不同的子网络"。

**2.3**
```python
w_no, w_l2 = 1.0, 1.0
alpha, lam = 0.1, 0.5
for _ in range(10):
    w_no = w_no - alpha * 2*(w_no-5)
    w_l2 = w_l2 - alpha * (2*(w_l2-5) + lam*w_l2)
print(w_no, w_l2)    # 无L2更接近5；有L2停在更小处
```
- **思路**：L2 项 $\lambda w$ 把 $w$ 往 0 拉——所以 L2 版的 $w$ 收敛到小于无 L2 版的位置。
- **点拨**：**"正则化让最优解偏离纯拟合"**——L2 版"牺牲一点拟合，换取权重小"。这就是 §2.3.6.6 的边界声明：$\lambda$ 太大，模型欠拟合（停在很接近 0 的地方）。

### 第三组

**3.1 答案：`weight_decay` 对应 L2 正则化的 $\lambda$；`nn.Dropout(0.5)` 的 `0.5` 是丢弃概率 $p$；`model.eval()` 关闭 Dropout（不丢弃），并做测试期缩放（PyTorch 用 inverted dropout，训练时已缩放）。**
- **思路**：三个"数字"各对应一个超参数/行为。`weight_decay` = $\lambda$，`Dropout(p)` 的 $p$ = 丢弃概率，`eval()` = 切换训练/测试模式。
- **点拨**：**读训练脚本时，`weight_decay`、`p`、`train()/eval()` 就是本节的三个落点。**

**3.2 思路**
- **过拟合判断**：训练 99% vs 验证 80% = 模型"记住了训练集"，泛化差。
- **建议**：(1) **L2/weight_decay**——让权重小而均衡，别依赖少数特征；(2) **Dropout**——随机丢神经元，破"共适应"；(3) **数据增强**——旋转/翻转/裁剪，制造更多"训练经验"（§2.3.5.3 的变换矩阵）；(4) **早停**——验证集不降就停；或减小模型/降学习率。
- **点拨**：**过拟合的对策 = 让模型"简单 + 见多识广"**。L2 管"简单"（权重小），Dropout 管"独立"（破共谋），数据增强管"见多识广"（更多样本）。三管齐下是标准做法。
