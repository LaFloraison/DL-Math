# 代码：算出 L2 惩罚、实现 Dropout、看权重衰减的效果

主线里我们算了 L2 损失（$1.0 + 0.0445 = 1.0445$）与 Dropout 示例。这一节用 NumPy 做三件事：**① L2 惩罚计算；② 手写 Dropout（含测试期缩放）；③ 梯度下降中"权重衰减"的效果。**

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：随机与数组

# ---- ① L2 正则化损失（教材例子）----
w = np.array([0.5, 0.8])
lam = 0.1
L_original = 1.0
L2_penalty = (lam / 2) * np.sum(w**2)
L_l2 = L_original + L2_penalty
print(f"L2 惩罚 = {L2_penalty:.4f}  | 正则化损失 = {L_l2:.4f}")   # 0.0445, 1.0445

# ---- ② Dropout（训练期：随机置零）----
rng = np.random.default_rng(42)
a = np.array([0.9, 0.8, 0.4, 0.7])
p = 0.5
mask = rng.random(4) > p                   # 保留概率 1-p=0.5
a_dropout = a * mask
print("激活:", a, "→ 掩码:", mask.astype(int), "→ Dropout:", a_dropout)

# ---- ③ 测试期缩放：乘以 (1-p) ----
a_test = a * (1 - p)                       # 关闭 dropout，缩放对齐期望
print("测试期缩放 a*(1-p) =", a_test)

# ---- ④ 权重衰减在梯度下降中的效果 ----
w = 1.0; alpha = 0.1; lam = 0.1
for step in range(5):
    grad = 2 * (w - 5)                     # 原损失 (w-5)^2 的梯度
    w = w - alpha * (grad + lam * w)       # 加了 L2 项的梯度
    print(f"step {step}: w = {w:.3f}  (无 L2 会更快逼近 5)")
print("L2 让 w 停在 <5 处（权重被拉小）")
```

运行输出（Python 3.11 + NumPy）：

```text
L2 惩罚 = 0.0445  | 正则化损失 = 1.0445
激活: [0.9 0.8 0.4 0.7] → 掩码: [1 1 0 1] → Dropout: [0.9 0.8 0.  0.7]
测试期缩放 a*(1-p) = [0.45 0.4  0.2  0.35]
step 0: w = 2.59
step 1: w = 3.142
step 2: w = 3.605
step 3: w = 3.997
step 4: w = 4.331
（无 L2 时 w 会更快逼近 5；L2 把 w 拉向 0）
```

## 层二：分步逐函数拆解

### 步骤 1：L2 惩罚

```python
L2_penalty = (lam / 2) * np.sum(w**2)
```

**操作**：$\frac{\lambda}{2}(0.5^2+0.8^2) = 0.05\times0.89 = 0.0445$。`np.sum(w**2)` 算权重平方和，乘 $\lambda/2$。
**可调参数**：`lam` 越大惩罚越重。`w` 越大，平方项增长越快——**大权重被不成比例地惩罚**。
**对应数学**：主线 $\text{Loss}_{\text{L2}} = \text{Loss} + \frac{\lambda}{2}\sum w_i^2$。

### 步骤 2：Dropout 掩码

```python
mask = rng.random(4) > p
a_dropout = a * mask
```

#### `rng.random(4)` —— 随机数

**操作**：生成 4 个 $[0,1)$ 随机数；`> p`（$>0.5$）得布尔掩码（约一半 True）。`a * mask` 把被丢弃的位置置零（True→1、False→0）。
**可调参数**：`p` 丢弃概率；`seed`（`default_rng(42)`）保证可复现。每次训练迭代都重新抽样 → 每次"消失"的神经元不同。
**对应数学**：主线 $a_{\text{dropout}} = \mathbf{m}\odot a$。**这是"随机让同学缺席"的代码实现。**

### 步骤 3：测试期缩放

```python
a_test = a * (1 - p)
```

**操作**：测试时不丢神经元，但把激活乘以 $(1-p)$。**为什么？** 训练时平均只有 $(1-p)$ 比例的神经元在活动，输出的期望被"稀释"了；测试时全部活动，若不缩放，输出偏大 $(1-p)$ 倍——乘以 $(1-p)$ 对齐训练与测试的"期望输出"。
**可调参数**：PyTorch 的 `nn.Dropout` 在 `model.eval()` 时自动做这个缩放（`inverted dropout` 的变体：训练时除以 $(1-p)$ 保持期望，测试时不缩放——两种等价）。本课用"测试时缩放"版本，对应教材描述。
**对应数学**：主线"测试时 dropout 关闭，输出乘以 $1-p$"。

### 步骤 4：权重衰减的梯度效果

```python
w = w - alpha * (grad + lam * w)
```

**操作**：梯度里多了 L2 项 $\lambda w$（对 $\frac{\lambda}{2}w^2$ 求导得 $\lambda w$）。`grad + lam*w` 把"拉向 0"的力加进更新。
**可调参数**：`lam` 越大，"拉向 0"的力越强——$w$ 停在比无 L2 时更接近 0 的位置。
**对应数学**：主线"权重衰减像摩擦把权重拉向 0"。**注意：无 L2 时 $w$ 会逼近 5（$L=(w-5)^2$ 的最优）；有 L2 时 $w$ 停在小于 5 处**——因为"最优解"被 L2 惩罚拽偏了。**正则化本质是"接受一点不完美，换取泛化"。**

## 边界声明：这套代码能做什么，不能做什么

1. **L2 惩罚"无差别地压小所有权重"**——它不区分"重要的"和"不重要的"特征。$\lambda$ 太大，关键特征也被压弱（欠拟合）。**$\lambda$ 是权衡旋钮，不是越大越好。**
2. **Dropout 只在训练期生效**。`model.eval()` 关闭 Dropout 并缩放（PyTorch 自动）。**忘记切换 train/eval 是常见 bug**——测试时留着 Dropout，预测会随机抖动。
3. **Dropout 与 BatchNorm 有交互**（§2.3.6.8）：先 Dropout 再 BatchNorm 的顺序会影响统计量稳定性，现代架构常对二者做仔细安排。
4. **本课的"测试时缩放"是教材版本**；PyTorch 用"inverted dropout"（训练时除 $1-p$、测试时不缩放）。两种数学等价，但代码形式不同——**读代码先确认是哪种实现。**
