## 第一步：Toy Model —— 两个"防止死记硬背"的老师

一个学生背课文，有两种"死记硬背"的危险：一是**背得太死**——只记住训练时见过的句子，换一种说法就不会了（过拟合）；二是**依赖某个"好学生"**——总是抄同桌的答案，同桌一走就完蛋。

两个老师各出一招：

**老师一（L2 正则化）**：订一条规则——"你的'背诵笔记'里，任何一条记太多（权重太大），就扣你的分。" 于是学生不敢把全部希望押在几个特别大的笔记上，而是平均用力、保持笔记小而均衡——**防止过度依赖任何单个特征**。

**老师二（Dropout）**：考试时**随机抽掉一半的学生**（不许抄），逼每个人独立会做。平时大家一起学，但每次练习都随机让一半人"消失"——于是没有谁能依赖谁，每个人都学会了独立解题。**防止神经元之间过度"共谋"。**

这两个老师，就是深度学习里最常用的两种正则化：**L2 正则化（权重衰减）** 与 **Dropout**。它们都是为了对付同一个敌人——**过拟合 (overfitting)**：模型在训练数据上完美、在没见过的新数据上崩盘。

## 第二步：正式数学讲解

### 一、撞墙：为什么"损失函数"要额外加惩罚？

训练的损失函数原本是"预测错多少"（如 MSE）。但只优化这个，模型会走上一条危险的路：**为了把训练误差压到 0，它把某些权重调得特别大**——用"巨大权重的极端反应"去精确匹配每一个训练点。结果是：它在训练集上过拟合，泛化崩盘。

你撞的墙是：**"预测越准"这个目标本身，会把模型推向"记得太死"。** 所以要在损失函数里加一条"惩罚条款"，把目标改写成"既要准，又要权重小"。这就是正则化的全部思想：**在"拟合数据"与"保持简单"之间找平衡。**

### 二、L2 正则化（权重衰减）

> **L2 正则化 / 权重衰减 (weight decay)**
> $$\text{Loss}_{\text{L2}} = \text{Loss}_{\text{original}} + \frac{\lambda}{2}\sum_i w_i^2$$
>
> - $\frac{\lambda}{2}\sum w_i^2$：L2 惩罚项——权重的平方和
> - $\lambda$（正则化系数）：惩罚强度。$\lambda$ 越大，大权重的代价越高
> - 作用：惩罚大权重，鼓励模型用"小而均衡"的权重——更简单、更泛化
>
> 例：$w_1=0.5$、$w_2=0.8$、原损失 1.0、$\lambda=0.1$：
> $$\text{Loss}_{\text{L2}} = 1.0 + \frac{0.1}{2}(0.5^2 + 0.8^2) = 1.0 + 0.05\times0.89 = 1.0 + 0.0445 = 1.0445$$

**为什么是"权重平方和"？** 平方让"大的更大"——$0.8^2=0.64$ 比 $0.5^2=0.25$ 大一倍多，所以惩罚**不成比例地打击大权重**。这逼着模型把大权重压下来、把"功劳"分摊给多个小权重。

直觉检验：$\lambda$ 的含义是"大权重的税率"。$\lambda=0$：不惩罚，模型自由过拟合；$\lambda$ 增大：惩罚加重，权重被压向 0，模型变"简单"。**权重衰减 (weight decay) 这个名字**来自优化视角：梯度更新里，L2 项让权重每步额外"衰减"一点（$w \leftarrow w(1-\eta\lambda)$），像摩擦一样把权重慢慢拉向 0。

### 三、Dropout：随机让神经元"消失"

> **Dropout**
>
> 训练时，每层激活以概率 $p$ **随机置零**（丢弃）一部分神经元。
> $$a_{\text{dropout}} = \mathbf{m} \odot a, \qquad m_i \sim \text{Bernoulli}(1-p)$$
>
> - 例：$a = [0.9, 0.8, 0.4, 0.7]$，$p=0.5$ → 随机得 $a_{\text{dropout}} = [0.9, 0, 0.4, 0]$
> - 训练：每个批次用不同的随机丢弃 → 网络每次"看到"不同的子网络
> - 测试：**关闭 dropout**，但输出乘以 $(1-p)$——因为训练时平均只有 $(1-p)$ 的神经元在活动，测试时要"对齐期望值"

**为什么 Dropout 有效？** 它打破了神经元之间的"共适应 (co-adaptation)"：如果没有 Dropout，神经元会学会"依赖彼此的正确性"（同桌抄答案）；有 Dropout，每次随机一批"同学缺席"，每个神经元必须独立学会解题。**结果：网络变成一个"多个子网络的集成"，泛化更强。**

边界声明：**正则化不是万能的，两种方法各有代价。** L2 惩罚大权重，但**不能区分"重要的特征"与"不重要的特征"**——它一律压小，可能把关键特征也压弱（所以 $\lambda$ 不能太大）。Dropout 训练时神经元随机消失，会让**训练更慢、收敛噪声更大**；且对某些架构（如 BatchNorm 之后，§2.3.6.8）需要小心使用。**正则化是"防过拟合"的工具箱之一，不是唯一答案**——数据增强、早停、更小的模型也是常用手段。

## 第三步：DL 桥接

**两种正则化都是深度学习训练的"标准配置"。**

1. **L2 → weight decay**：PyTorch 的 `optimizer = Adam(..., weight_decay=0.01)`——`weight_decay` 参数就是 $\lambda$（实现上常直接衰减权重而非加惩罚项）。**几乎每个训练脚本都会设置它**，是"防过拟合"的第一道防线。它让模型的权重保持"小而均衡"（§2.6 SVD 视角下 = 保持模型"低秩、简单"）。

2. **Dropout → `nn.Dropout(p)`**：在隐藏层之间插入 `nn.Dropout(0.5)`，训练时自动随机置零，`model.eval()` 时自动关闭并缩放。**Transformer 里每个子层之后都有 Dropout**（$p$ 通常 0.1–0.3）——它是现代模型的标配部件。

3. **"正则化 = 归纳偏置"**：L2 假设"小权重更好"（简单假设），Dropout 假设"独立特征更好"（鲁棒假设）。**正则化本质是把"先验"注进训练**——这不是玄学，是对"什么样的模型能泛化"的工程信念。

一句话：**L2 用"罚大权重"逼模型简单，Dropout 用"随机消失"逼神经元独立**——两者都为了对抗过拟合、提高泛化。你在每个训练脚本里看到的 `weight_decay` 和 `nn.Dropout`，就是这两个老师。
