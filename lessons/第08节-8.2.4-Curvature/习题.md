# §8.2.4 曲率 —— 习题

本章主线讲了三件事：高斯曲率 $K = k_1 k_2$ 用主曲率的乘积判定局部形状（正/零/负）；曲率与参数敏感度、泛化的关系（高曲率区域敏感且易过拟合，平坦区域稳健且泛化好）；深度学习里曲率由 Hessian 特征值读出（凸谷全正、穹顶全负、鞍点有正有负）。下面的习题分三组：**概念检验** 验证核心定义，**计算实践** 把曲率亲手算一遍（含代码验证），**DL 延伸** 把曲率放回损失景观与泛化的场景。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：圆柱的高斯曲率为什么是零？

一个半径为 $R$ 的圆柱面。它的高斯曲率 $K$ 是多少？

- A. $K = 1/R^2$，因为它是弯的
- B. $K = 0$，因为它的两个主曲率一正一负
- C. $K = 0$，因为它的一个主曲率为零（母线方向是直的）
- D. $K = -1/R^2$，因为它像马鞍

**解答**：C。

圆柱面两个主方向：圆周方向弯成半径为 $R$ 的圆弧，$k_1 = 1/R$；母线方向完全平直，$k_2 = 0$。乘积 $K = k_1 \cdot k_2 = 0$。这就是"弯却可展"：圆柱能沿母线剪开摊平，因为它的弯曲只在圆周方向，母线方向给了它"展开的出路"。A 错——$1/R^2$ 是球的曲率（两个方向都弯）。B 错——圆柱的两个主曲率不是一正一负，而是一正一零。D 错——马鞍的特征是异号，圆柱是含零。

**思路点拨**：题眼是"可展面 $K = 0$"。最容易错的直觉是"圆柱看起来弯，所以 $K \neq 0$"——这正是主线边界声明警告的地方：$K = 0$ 不代表"看起来平"，只代表"可以摊平"。判据：想清楚两个主方向各自的曲率，再相乘。

### 题 2（判断 + 简答）：鞍点、局部最大值、局部最小值，怎么用曲率区分？

在损失景观上，梯度为零的点有三种可能：局部最小值、局部最大值、鞍点。如何用 Hessian 特征值的符号区分它们？为什么"梯度为零"不足以判断是哪一种？

**解答**：设 Hessian 特征值为 $\lambda_1 \le \lambda_2 \le \dots \le \lambda_n$：

- **局部最小值（凸谷）**：所有 $\lambda_i > 0$（Hessian 正定）——每个方向的曲率都为正，往哪个方向走，损失都上升；
- **局部最大值（穹顶）**：所有 $\lambda_i < 0$（Hessian 负定）——每个方向都向下弯；
- **鞍点**：特征值有正有负——至少一个方向是谷（正曲率）、至少一个方向是岭（负曲率）。

"梯度为零"只说明一阶条件是临界点（stationary point），但它不区分是谷、峰还是马鞍——一阶信息（梯度）看不见弯曲，二阶信息（Hessian/曲率）才看见。这就是为什么"梯度为零"不是"最小值"的充分条件：你可能站在一个两边高中间低的马鞍背上。

**思路点拨**：这是主线"最小值判据不只是梯度为零，还要曲率全正"的展开。记忆锚点：**一阶条件找候选，二阶条件（曲率）定身份**。高维里鞍点远比最小值常见（随机临界点有正有负特征值的概率极高）——这是 8.3.1 的核心，这里先建立判据。

### 题 3（简答）：为什么"平坦的极小值"泛化更好？

两个模型收敛到两个损失极小值：模型 A 落在平坦极小（Hessian 特征值都很小），模型 B 落在尖锐极小（Hessian 特征值很大）。为什么 A 在新数据上通常表现更好？从"参数敏感度"角度回答。

**解答**：平坦极小意味着**低曲率**——Hessian 特征值小，参数在极小值附近小幅变化时，损失的上升非常缓慢、预测几乎不变。于是模型 A 对参数的精确取值不敏感：稍微扰动权重、输入或数据分布，输出保持稳定——它对训练数据的"记忆"是宽泛的（抓住了普遍模式），所以对未见数据也稳定（泛化好）。

尖锐极小（高曲率）则相反：参数稍微一动，损失剧烈上升、预测大幅改变——模型把训练集的**具体细节**刻进了权重的精确位置（过拟合）。这些细节在新数据上不成立，所以验证表现差。曲率在这里充当"参数敏感度"的计表：**曲率低 = 稳健 = 泛化好；曲率高 = 脆弱 = 过拟合。** 8.3.3 会把"平坦 vs 尖锐"用 $\lambda_{\max}(H)$ 精确量化。

**思路点拨**：这道题把主线第四节"曲率与泛化"变成因果链。核心链条：低曲率 → 参数不敏感 → 预测稳健 → 泛化好。易错点是只说"平坦好"而不解释"为什么好"——必须落到"低曲率 = 对参数扰动不敏感"这个机制上。

## 二、计算实践

### 题 1（高斯曲率的解析计算）

对曲面 $z = f(x,y) = x^2 - 2y^2$（马鞍），计算它在点 $(1, 1)$ 处的高斯曲率 $K$，并说明符号。再用 $z = x^2 + 2y^2$（碗）在 $(1,1)$ 处算一遍对比。

**解答**：

对图 $z = f(x,y)$，高斯曲率 $K = \frac{f_{xx}f_{yy} - f_{xy}^2}{(1 + f_x^2 + f_y^2)^2}$。

**马鞍 $f = x^2 - 2y^2$**：$f_x = 2x$，$f_y = -4y$，$f_{xx} = 2$，$f_{yy} = -4$，$f_{xy} = 0$。在 $(1,1)$：$f_x = 2, f_y = -4$，分母 $= (1 + 4 + 16)^2 = 21^2 = 441$，分子 $= 2 \times (-4) - 0 = -8$。所以
$$K = \frac{-8}{441} \approx -0.0181$$
负号 → 鞍型，符合预期（$x$ 方向向上、$y$ 方向向下）。

**碗 $f = x^2 + 2y^2$**：$f_{xx} = 2, f_{yy} = 4, f_{xy} = 0$，分子 $= 2 \times 4 = 8$，分母相同 $441$，$K = \frac{8}{441} \approx 0.0181$。正号 → 鼓型。

**NumPy 验证**（用代码.md 的函数）：
```python
import numpy as np

def gaussian_curvature_graph(f, x, y, h=1e-5):
    fx = (f(x+h, y) - f(x-h, y)) / (2*h)
    fy = (f(x, y+h) - f(x, y-h)) / (2*h)
    fxx = (f(x+h, y) - 2*f(x, y) + f(x-h, y)) / h**2
    fyy = (f(x, y+h) - 2*f(x, y) + f(x, y-h)) / h**2
    fxy = (f(x+h, y+h) - f(x+h, y-h) - f(x-h, y+h) + f(x-h, y-h)) / (4*h**2)
    return (fxx*fyy - fxy**2) / (1 + fx**2 + fy**2)**2

saddle = lambda x, y: x**2 - 2*y**2
bowl2  = lambda x, y: x**2 + 2*y**2
print("马鞍 (x²-2y²) 在 (1,1): K = %.4f" % gaussian_curvature_graph(saddle, 1, 1))
print("碗   (x²+2y²) 在 (1,1): K = %.4f" % gaussian_curvature_graph(bowl2, 1, 1))
```
```
马鞍 (x²-2y²) 在 (1,1): K = -0.0181
碗   (x²+2y²) 在 (1,1): K =  0.0181
```

**思路点拨**：核心是分子 $f_{xx}f_{yy} - f_{xy}^2$ 的符号——它决定 $K$ 的符号（分母恒正）。最容易错的地方：忘记分母 $(1+f_x^2+f_y^2)^2$（在陡峭处分母显著大于 1，$|K|$ 被压小）。另一个易错点：$f_{xy} \ne 0$ 时分子不是简单的 $f_{xx}f_{yy}$——交叉项会改变主曲率的方向。判据：分子 $>0$ 鼓、$<0$ 鞍、$=0$ 平/可展。

### 题 2（Hessian 特征值分类）

对损失函数 $L(\theta_1, \theta_2) = \theta_1^3 - 3\theta_1 + \theta_2^2$：

(a) 求所有梯度为零的点（临界点）。
(b) 对每个临界点算 Hessian，分类（凸谷/穹顶/鞍点）。
(c) 哪些是全局最小值候选？

**解答**：

(a) $\nabla L = (3\theta_1^2 - 3, 2\theta_2) = (0, 0)$。由 $2\theta_2 = 0$ 得 $\theta_2 = 0$；由 $3\theta_1^2 - 3 = 0$ 得 $\theta_1 = \pm 1$。临界点：$(-1, 0)$ 和 $(1, 0)$。

(b) Hessian $H = \begin{pmatrix} 6\theta_1 & 0 \\ 0 & 2 \end{pmatrix}$。在 $(-1, 0)$：$H = \text{diag}(-6, 2)$，特征值 $-6, 2$——**鞍点**（一正一负）。在 $(1, 0)$：$H = \text{diag}(6, 2)$，特征值 $6, 2$——**凸谷**（全正，局部最小值）。

(c) $L(-1, 0) = (-1)^3 - 3(-1) + 0 = -1 + 3 = 2$；$L(1, 0) = 1 - 3 = -2$。局部最小值在 $(1, 0)$，值为 $-2$。但 $L$ 在 $\theta_1 \to -\infty$ 时趋于 $-\infty$（三次项主导），所以 $(1, 0)$ 只是**局部**最小值，**不是全局**最小值——全局不存在（无界）。

**NumPy 验证**：
```python
import numpy as np

def grad(t1, t2): return np.array([3*t1**2 - 3, 2*t2])
def hess(t1, t2):
    H = np.array([[6*t1, 0.0], [0.0, 2.0]])
    return np.linalg.eigvalsh(H)

for p in [(-1.0, 0.0), (1.0, 0.0)]:
    w = hess(*p)
    sign = "凸谷" if w[0] > 0 else ("穹顶" if w[1] < 0 else "鞍点")
    print("临界点 %s: λ=%s -> %s, L=%.2f" % (p, np.round(w,2), sign,
                                              p[0]**3 - 3*p[0] + p[1]**2))
```
```
临界点 (-1.0, 0.0): λ=[-6. 2.] -> 鞍点, L=2.00
临界点 (1.0, 0.0): λ=[ 6. 2.] -> 凸谷, L=-2.00
```

**思路点拨**：这是一道完整的"临界点分类"题。步骤：一阶条件找候选 → 二阶条件（Hessian 特征值符号）定身份。最容易错的两处：① 漏解 $\theta_1 = -1$（很多人只解 $\theta_1 = 1$）；② 把鞍点 $(-1,0)$ 也当极小值——它的 Hessian 含负特征值 $-6$，往 $\theta_1$ 增大方向走损失会降，所以不是谷底。**(c) 提醒：深度学习里"局部最小值"不保证是全局最优，这本身就是损失景观研究要面对的残酷现实。**

### 题 3（曲率与学习率的关系）

一维损失 $L(\theta) = \frac{1}{2}a\theta^2$（曲率 $= a$），梯度下降 $\theta_{t+1} = \theta_t - \eta a\theta_t = (1 - \eta a)\theta_t$。

(a) 收敛条件是什么？给出临界学习率 $\eta_{\max}$ 与 $a$ 的关系。
(b) 把 $\eta$ 设成 $1.5/a$ 会怎样？
(c) 这条规律怎么解释"高曲率区域要降低学习率"？

**解答**：

(a) 收敛当且仅当 $|1 - \eta a| < 1$，即 $0 < \eta a < 2$，$\eta_{\max} = 2/a$。**临界学习率与曲率成反比**：曲率越大，能用的学习率越小。

(b) $\eta = 1.5/a$ 则 $1 - \eta a = -0.5$，$|−0.5| < 1$——**收敛但振荡**：参数每一步都换方向，但振幅逐格减半，最终收敛。若 $\eta > 2/a$，$|1-\eta a| > 1$，发散。

(c) 高曲率区域 $a$ 大 → $\eta_{\max} = 2/a$ 小 → 必须用小学习率。这正是 8.2.4 主线说的"高曲率区域里参数微小变化造成损失剧烈变化，实践上要降低学习率防止不稳定"的代数解释。多参数情形下，$a$ 换成 Hessian 特征值 $\lambda_i$，临界条件变为 $\eta < 2/\lambda_{\max}$——**最大特征值（最尖方向）锁死学习率**。

**思路点拨**：这道题把"曲率高 = 小心步长"变成可算的公式。核心关系：$\eta_{\max} = 2/\lambda_{\max}$。最容易错的地方是以为"学习率是拍脑袋定的"——它其实被曲率（Hessian 最大特征值）硬性约束。这也解释了自适应优化器（Adam）存在的意义：它们逐方向缩放步长，等于在"不知道曲率的情况下隐式回应曲率"。

## 三、DL 延伸

### 题 1（用曲率判断"该不该降学习率"）

训练中，你在参数点 $\theta_t$ 处用近似方法算得 Hessian 的最大特征值 $\lambda_{\max} \approx 100$，当前学习率 $\eta = 0.05$。

(a) 用 $\eta < 2/\lambda_{\max}$ 判据判断：这个学习率安全吗？
(b) 如果训练开始振荡（损失上下跳动），从曲率角度该做什么，为什么？

**解答**：

(a) $2/\lambda_{\max} = 2/100 = 0.02$，当前 $\eta = 0.05 > 0.02$——**不安全**。至少在 $\lambda_{\max}$ 对应的方向上，迭代的 $|1 - \eta\lambda_{\max}| = |1 - 5| = 4 > 1$，该方向发散。这是一个"曲率诊断学习率"的实例：不用试错，用曲率直接算。

(b) 振荡意味着在某些方向 $|1 - \eta\lambda_i|$ 过大甚至超过 1。对策：**降低学习率**（让 $\eta < 2/\lambda_{\max}$），或采用自适应方法（Adam/RMSprop 对高曲率方向自动减小有效步长）。更高明的做法是二阶方法（牛顿法 $\theta_{t+1} = \theta_t - H^{-1}\nabla L$），它对所有方向归一化步长，不再受 $\lambda_{\max}$ 束缚——但代价是要算/近似 $H$。

**思路点拨**：这道题让曲率判据直接上岗。核心公式：$\eta < 2/\lambda_{\max}$。陷阱：初学者常把学习率当成"运气参数"，其实它是被曲率**上限约束**的——超过临界值，训练必然发散。记忆锚点：**曲率是地形的陡度，学习率是脚步的大小；陡坡上必须小步，这是几何，不是调参技巧。**

### 题 2（鞍点 vs 局部最小值：为什么高维优化那么难）

一个 $n$ 参数网络，在某临界点，Hessian 的特征值大致各一半正一半负（随机神经网络的典型情况）。

(a) 这个临界点是鞍点还是最小值？概率上哪个更常见？
(b) 梯度下降在鞍点附近会遇到什么困难？（结合曲率与梯度大小）
(c) 为什么自适应方法（Adam）能缓解？（提示：对平坦方向放大步长）

**解答**：

(a) 有正有负 = **鞍点**。在随机 Hessian 下，特征值全为正的概率是 $2^{-n}$——随参数数 $n$ 指数衰减。**高维里，梯度为零的点几乎都是鞍点**，局部最小值在概率上罕见。这是 8.3.1 的核心观察。

(b) 鞍点附近梯度接近零（一阶条件），梯度下降每一步的步长 $\eta\|\nabla L\|$ 也接近零——**参数更新极小，训练停滞**。同时，鞍点沿负曲率方向（特征值为负）是"下坡"、沿正曲率方向是"上坡"，若初始方向没对准负曲率方向，参数会先在"谷脊"上缓慢徘徊。

(c) Adam 用梯度的一阶/二阶矩估计逐参数归一化步长：在梯度小（平坦）的方向，它把有效步长放大；在梯度大（陡峭）的方向压缩。鞍点附近，负曲率方向的梯度最终会显现出来，Adam 沿该方向大步逃离；普通 SGD 则在所有方向上都"等比例小步"，容易被鞍点冻住。动量（momentum）也起类似作用——沿历史速度方向继续冲，帮助穿越平坦区。

**思路点拨**：这道题把"鞍点"与"曲率"绑定。核心公式：鞍点概率 $\approx 1 - 2^{-n}$（特征值随机正负）。最容易的空泛回答是"高维优化难"——要落到机制：梯度接近零（一阶）但曲率符号混合（二阶），一阶方法信息不足。记忆锚点：**鞍点是高维的常态，最小值是偶然；自适应优化器之所以流行，一部分原因就是它们更擅长逃离鞍点。**

### 题 3（平坦极小值 = 好泛化的工程判断）

训练完一个模型，你想快速判断它落在平坦极小还是尖锐极小，从而预估其泛化能力。给出两种不需要精确 Hessian 的近似判断方法，并说明理由。

**解答**：

方法一：**扰动-稳定测试**。对训练好的权重加微小随机扰动 $\theta + \epsilon$（$\epsilon \sim \mathcal{N}(0, \sigma^2 I)$，$\sigma$ 很小），重新计算验证集准确率。平坦极小下，准确率几乎不变（参数不敏感）；尖锐极小下，准确率骤降。这直接测"参数敏感度"——曲率高的实际后果。

方法二：**锐度度量 (sharpness-aware) 近似**。计算 $\lambda_{\max}(H)$ 的近似：用梯度差 $\frac{1}{h}\|\nabla L(\theta + h\epsilon) - \nabla L(\theta)\|$（幂迭代法的有限差分版）估计最大特征方向上的曲率。$\lambda_{\max}$ 小 → 平坦 → 泛化好的信号（这正是 §8.3.3 与 Sharpness-Aware Minimization (SAM) 的思想）。

两种方法都避开"精确求 Hessian"（$O(n^2)$ 存储、$O(n^3)$ 求逆不可行），用"小扰动 + 观察响应"来间接测量曲率。本质上它们都在回答同一个问题：**"这个极小值，参数动一下，损失和预测会不会大变？"** 不会变 → 平坦 → 好泛化。

**思路点拨**：这道题把"平坦 vs 尖锐"变成可操作诊断。核心逻辑链：曲率（Hessian 特征值）→ 参数敏感度 → 泛化。方法一、二都是"通过响应测曲率"的代理。这预告了 8.3.3 泛化一节与 SAM 的动机。判据：任何方法只要能区分"参数对扰动敏不敏感"，就是在区分平坦与尖锐。
