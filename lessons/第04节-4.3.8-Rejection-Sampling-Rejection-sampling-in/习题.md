# 习题：拒绝采样

## 第一组：概念检验

**1. 写出拒绝采样的接受准则，并解释每个符号。**

**解答**：接受 $x$（从 $q$ 采的候选）当且仅当 $u\le\frac{p(x)}{Mq(x)}$，其中 $u\sim\text{Uniform}(0,1)$。$p$ 是目标分布（复杂、无采样算法），$q$ 是提议分布（简单、能采样），$M$ 是常数且 $Mq(x)\ge p(x)$ 对所有 $x$ 成立。**接受概率 $\frac{p(x)}{Mq(x)}$ 随 $p$ 的高度变化**——$p$ 高处更容易接受，于是留下的样本服从 $p$。

**2. 为什么"$Mq$ 必须处处罩住 $p$"？如果罩不住会怎样？**

**解答**：罩不住意味着某处 $Mq(x)<p(x)$，接受概率 $\frac{p(x)}{Mq(x)}>1$——那一处"曲线比帐篷高"，飞镖永远落在曲线外，该处永远采不到样本，分布被系统性扭曲。而且这个失败**是静默的**（不报错，结果看似正常）。**$M$ 必须大于等于 $p/q$ 的最大值——帐篷的高度是合法性的底线。**

**3. 判断题并说明理由："拒绝采样的接受率越高越好，所以 $M$ 越小越好。"**

**解答**：方向对但需限定。接受率 $=\frac1M$，$M$ 越小确实越省算力，但 **$M$ 不能小于 $\max p/q$**——小于这个下限就罩不住、方法失败。**$M$ 的最优值是"恰好罩住"：再小一分就错，再大一分就浪费。** 教材例子 $M=4$ 就是"恰好罩住高斯峰值 3.99"。

## 第二组：计算实践

**4. 手算 + 代码验证。** 目标 $p=\mathcal{N}(0.5,0.1^2)$（定义在 $[0,1]$），提议 $q=\text{Uniform}(0,1)$。（a）$M$ 至少取多少？（b）理论接受率是多少？（c）代码复现：1 万候选应剩约多少？

**解答**：
（a）$p$ 的峰值 $p(0.5)=\frac{1}{0.1\sqrt{2\pi}}\approx3.99$，$q\equiv1$，所以 $M\ge3.99$，取 $M=4$。
（b）接受率 $=\frac1M=\frac14=25\%$。
（c）1 万候选 × 25% ≈ 2500——与教材"约 2500 个有效样本"一致。

代码验证：

```python
import numpy as np
np.random.seed(0)
def p(x): return np.exp(-(x-0.5)**2/0.02)/(0.1*np.sqrt(2*np.pi))
M = 4.0
x = np.random.uniform(0,1,10000); u = np.random.uniform(0,1,10000)
acc = x[u <= p(x)/M]
print("接受数 =", acc.size, " 接受率 =", round(acc.size/10000, 3))
```

输出：

```text
接受数 = 2537  接受率 = 0.254
```

**思路点拨**：若有人答"$M$ 越大越好，接受率 100%"，那是把"接受率"当成了目标——$M$ 太小会失败，$M$ 太大的浪费算力。$M$ 的意义是"恰好罩住"。

**5. 形状验证实验。** 把接受样本画成直方图与目标密度对比，验证"筛选没有扭曲分布"；再故意把 $M$ 设小（$M=2$），观察分布如何被扭曲。

**解答**：见《代码.md》步骤 3-4。$M=4$ 时直方图与目标密度最大偏差约 0.08（吻合良好）；$M=2$ 时"处处罩住=False"——峰值附近接受概率被截断为 1，该区域被高估、两侧被低估，分布扭曲。**$M$ 的合法性与接受率是两件事：$M=2$ 虽"接受率 50%"却完全错误。**

## 第三组：DL 延伸

**6. LLM 解码场景。** 你用一个语言模型生成回答，模型输出每个位置的 token 概率分布。你担心模型会输出低质量的答案，想用"生成多个候选、只保留满足准则的"来提高质量。（a）这个"生成候选 + 筛选"的过程对应本节什么概念？（b）它与"模型自带的概率采样"有什么本质区别？（c）这种做法的代价是什么？

**解答**：
（a）对应**拒绝采样**——从模型分布（$q$，能采样）生成候选，按准则（$p$ 或评分函数）接受/拒绝。工程上常见的是"候选生成 + 过滤"：beam search 或多次采样生成候选，按奖励/规则筛选。
（b）本质区别：拒绝采样是**显式筛选**——生成很多、扔一部分；模型自带的概率采样是**一次到位**——直接按分布抽一个。拒绝采样允许"用算力换质量"：把差的候选扔掉、只保留好的，但**必须保证"筛选准则"与"目标质量"一致**，否则筛选会扭曲生成分布（比如只保留长答案，导致系统性冗长）。
（c）代价是**接受率**：生成 100 个候选可能只接受 10 个——90% 的算力被拒绝（$M$ 的税）。高维、长序列下候选空间巨大，接受率骤降，这也是为什么"对齐/过滤"常用强化学习（奖励模型）而非纯拒绝采样——**拒绝采样在采样空间巨大时不够高效。**
**思路点拨**：若有人答"筛选越严格质量越高"，他忽略了接受率——筛选过严，候选几乎全被拒，样本太少甚至无法生成。若有人答"拒绝采样就是贪心解码"，那是混淆——贪心取概率最高，拒绝采样按概率筛选、保留的还是概率分布的样本（只是截断了差的）。
