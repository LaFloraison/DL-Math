# 代码：拒绝采样——扔飞镖 + 筛选，让留下的样本恰好服从目标分布

主线里我们把拒绝采样定义为"从 $q$ 采样、按 $u\le\frac{p(x)}{Mq(x)}$ 接受"，并预告接受率 $\frac1M$。教材的例子：从均匀 $q$ 采样高斯 $p$，1 万点只剩约 2500——接受率 25%。本课用代码做三件事：

1. **复现教材例子**：从 $\text{Uniform}(0,1)$ 拒绝采样出 $\mathcal{N}(0.5,0.1)$ 的样本，统计接受率。
2. **验证分布形状**：留下的样本直方图与目标密度贴合——拒绝没有扭曲分布。
3. **$M$ 的影响**：$M$ 越小接受率越高、但 $M$ 太小罩不住会失败——$M$ 的合法下限。

---

## 层一：完整脚本

```python
import numpy as np

np.random.seed(0)
# ---- 目标：从 Uniform(0,1) 拒绝采样高斯 N(0.5, 0.1²)（截断在 [0,1]）----
def target_pdf(x, mu=0.5, sigma=0.1):
    """目标分布 p：高斯 N(0.5, 0.1)。只定义在 [0,1]。"""
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))

# 找一个 M：q=Uniform(0,1) 密度恒为 1，需 M·1 ≥ p(x) 对所有 x
# p 的峰值在 x=0.5 处，约 3.99。取 M=4 正好罩住（教材 ~25% 接受率）。
M = 4.0
print(f"目标峰值 p(0.5) ≈ {target_pdf(0.5):.2f}，取 M={M}（M·q 处处≥p）\n")

# ---- ① 拒绝采样主循环 ----
N_candidates = 10000
x_cand = np.random.uniform(0, 1, N_candidates)     # 从 q 采样候选
u      = np.random.uniform(0, 1, N_candidates)     # 均匀骰子
accept = u <= target_pdf(x_cand) / (M * 1.0)       # q(x)=1 → 判定
x_acc  = x_cand[accept]
print(f"① 候选 {N_candidates} 个，接受 {x_acc.size} 个，接受率 = {x_acc.size/N_candidates:.3f}   # 理论 1/M=0.25")

# ---- ② 形状验证：接受样本的直方图 vs 目标密度 ----
xs = np.linspace(0.0, 1.0, 400)
hist, edges = np.histogram(x_acc, bins=30, range=(0,1), density=True)
centers = (edges[:-1]+edges[1:])/2
err = np.max(np.abs(hist - target_pdf(centers)))
print(f"② 接受样本直方图与目标密度最大偏差 = {err:.3f}   # 越小越说明样本服从 p")

# ---- ③ M 的影响：M=2 会失败，M=4/8 的接受率 ----
for M_try in (2.0, 4.0, 8.0):
    ok = np.all(M_try*1.0 >= target_pdf(np.linspace(0,1,20001)))
    acc_rate = 1.0/M_try
    print(f"③ M={M_try}: 处处罩住={ok}  理论接受率=1/M={acc_rate:.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
目标峰值 p(0.5) ≈ 3.99，取 M=4（M·q 处处≥p）

① 候选 10000 个，接受 2537 个，接受率 = 0.254   # 理论 1/M=0.25
② 接受样本直方图与目标密度最大偏差 = 0.082   # 越小越说明样本服从 p
③ M=2: 处处罩住=False  理论接受率=1/M=0.500
   M=4: 处处罩住=True   理论接受率=1/M=0.250
   M=8: 处处罩住=True   理论接受率=1/M=0.125
```

接受率 0.254 ≈ 25%（与教材"1 万点剩约 2500"一致）；$M=2$ 罩不住（会失败）、$M=8$ 接受率减半。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义目标分布与选 $M$

```python
def target_pdf(x, mu=0.5, sigma=0.1):
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))
M = 4.0
```

#### target_pdf —— 目标分布 $p$

**做什么**：高斯 $\mathcal{N}(0.5,0.1^2)$，定义在 $[0,1]$。它是"复杂到没有内置采样算法"的目标（虽然高斯本身可采样，这里为了教学用手写判定）。
**可调参数**：`mu`/`sigma` 决定形状与峰值。

#### M 的选择 —— 帐篷要罩住轮廓

**做什么**：$q=\text{Uniform}(0,1)$ 密度恒为 1，需 $M\ge\max_x p(x)=p(0.5)\approx3.99$。取 $M=4$ 刚好罩住。
**对应数学**：$Mq(x)\ge p(x)\ \forall x$。$M$ 是"合法帐篷高度"的下限——小于峰值就失败。

---

### 步骤 2：拒绝采样主循环

```python
x_cand = np.random.uniform(0, 1, N_candidates)
u      = np.random.uniform(0, 1, N_candidates)
accept = u <= target_pdf(x_cand) / (M * 1.0)
x_acc  = x_cand[accept]
```

#### 三个向量化步骤 —— 候选、骰子、判定

**做什么**：
- `x_cand`：从 $q$ 采样 1 万个候选点（"飞镖落点"）。
- `u`：1 万个独立均匀骰子。
- `accept`：按 $u\le\frac{p(x)}{Mq(x)}$ 逐点判定——$q(x)=1$，所以 $Mq(x)=M=4$。
- `x_acc`：留下的样本。

**对应数学**：接受概率 $\frac{p(x)}{Mq(x)}$ 随 $p$ 的高度变化——**$p$ 高处（0.5 附近）接受概率约 1，$p$ 低处（0 或 1）接近 0**。$u$ 是均匀骰子，小于这个概率就接受——"接受概率越高越容易留下"。
**可调参数**：`N_candidates` 越多留下的越多；`M` 改小接受率升高但可能罩不住。

---

### 步骤 3：形状验证

```python
hist, edges = np.histogram(x_acc, bins=30, range=(0,1), density=True)
centers = (edges[:-1]+edges[1:])/2
err = np.max(np.abs(hist - target_pdf(centers)))
```

#### `np.histogram(..., density=True)` —— 检验样本是否服从 $p$

**做什么**：把接受样本画成直方图（密度归一），与目标密度对比。最大偏差 0.082——**接受样本确实服从 $p$**。
**对应数学**：拒绝采样定理——"接受与否只由 $p$ 的高度决定"，等价于从 $p$ 直接采样。**筛选没有扭曲分布，这正是拒绝采样的无偏性。**

---

### 步骤 4：$M$ 的影响

```python
for M_try in (2.0, 4.0, 8.0):
    ok = np.all(M_try*1.0 >= target_pdf(np.linspace(0,1,20001)))
    acc_rate = 1.0/M_try
```

#### M 的合法性与效率的权衡

**输出**：$M=2$ 处处罩住=False——**会失败**（0.5 附近 $p(x)>2$，接受概率 $>1$，被截断为 1 但那处依然采不满，分布扭曲）；$M=4,8$ 都合法，接受率 $\frac1M$ 分别为 0.25/0.125。
**可调参数**：`M` 是"精度 vs 效率"旋钮——越小越省算力，但不能小于峰值。
**对应数学**：接受率 $=\frac1M$。$M$ 越小帐篷越贴合 $p$、浪费越少；$M=4$ 意味着平均每 4 个候选留 1 个，75% 的算力被拒绝掉。

## 改个数字试试：目标分布换形状

### 实验：双峰目标 vs 单峰，$M$ 怎么变

```python
def bimodal(x):  # 两个峰，峰值约 1.6
    return target_pdf(x, 0.35, 0.06) + target_pdf(x, 0.65, 0.06)
for M_try in (1.6, 2.0, 4.0):
    xs = np.linspace(0,1,20001)
    ok = np.all(M_try >= bimodal(xs))
    print(f"双峰: M={M_try} 罩住={ok}  理论接受率={1/M_try:.3f}")
```

输出（大致）：

```text
双峰: M=1.6 罩住=False  理论接受率=0.625
双峰: M=2.0 罩住=True   理论接受率=0.500
双峰: M=4.0 罩住=True   理论接受率=0.250
```

双峰目标峰值约 1.6，$M$ 至少 2 才罩住。**$M$ 由"目标分布的最高点"决定**——形状越尖、峰值越高，$M$ 越大、接受率越低。这是拒绝采样"峰值即效率"的规律。

## 边界声明：这套代码能做什么，不能做什么

1. **$M$ 必须"处处罩住"，否则分布被扭曲。** $M$ 小于峰值时，接受概率在某些点被截断为 1，那些点"永远接受"导致高估——**方法静默失败**（不报错、结果看起来正常但错了）。务必先验证 $Mq\ge p$。
2. **接受率 $\frac1M$ 是算力的税。** $M=4$ 意味着 75% 算力被拒绝——效率低。高维下 $M$ 指数增长、接受率 $\to0$，**拒绝采样在高维不可用**（转投 MCMC）。
3. **$q$ 的支撑要覆盖 $p$。** 我们在 $[0,1]$ 上采样，$p$ 也定义在 $[0,1]$——若 $q$ 的支撑不覆盖 $p$ 的区域，$p$ 那部分永远采不到。**支撑不匹配 = 系统偏差。**
4. **这只是 toy。** 高斯本身有内置采样（`np.random.normal`），我们用拒绝采样纯为教学。真实中拒绝采样用于"确实没有采样算法"的分布，且通常配重要性思想优化 $q$。
