# 代码：手写 ReLU 与 Sigmoid，看它们如何"掰弯"一条直线

主线里我们用 $x=1.0, w=0.5, b=0.2$ 算出 $z=0.7$，然后看 ReLU 输出 0.7、Sigmoid 输出 0.668。这一节把这几个激活函数写成函数、画出它们的形状，并演示**为什么没有激活的网络等于一层线性**。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：exp / maximum

# ---- ① 教材例子：单个神经元 ----
x, w, b = 1.0, 0.5, 0.2
z = w * x + b                            # z = 0.7
print(f"z = wx + b = {z:.1f}")

def relu(z):                             # ReLU：负归零、正保留
    return np.maximum(0.0, z)
def sigmoid(z):                          # Sigmoid：压进 (0,1)
    return 1.0 / (1.0 + np.exp(-z))

print(f"ReLU(z)   = {relu(z):.4f}")      # 0.7000
print(f"Sigmoid(z) = {sigmoid(z):.4f}")  # 0.6682

# ---- ② 激活函数的"形状"：在 z 轴上采样 ----
z_axis = np.linspace(-6.0, 6.0, 1001)
r = relu(z_axis)                         # 形状 (1001,)
s = sigmoid(z_axis)                      # 形状 (1001,)
print("ReLU 在 z=-3 处:", r[z_axis<=-3][-1], "| 在 z=3 处:", r[z_axis>=3][0])
print("Sigmoid 范围: [%.3f, %.3f]" % (s.min(), s.max()))

# ---- ③ 关键演示：没有激活的两层 = 一层线性 ----
W1 = np.array([[1.0, 2.0], [3.0, 4.0]])
W2 = np.array([[0.5, -1.0]])
x_vec = np.array([1.0, 2.0])
identity = lambda v: v                   # 恒等"激活"
out_no_act = W2 @ (W1 @ x_vec)           # 两层线性复合
W_merged = W2 @ W1                       # 合并成单层
print("两层复合 =", out_no_act, "| 合并单层 =", W_merged @ x_vec)
```

运行输出（Python 3.11 + NumPy）：

```text
z = wx + b = 0.7
ReLU(z)   = 0.7000
Sigmoid(z) = 0.6682
ReLU 在 z=-3 处: 0.0 | 在 z=3 处: 3.0
Sigmoid 范围: [0.002, 0.998]
两层复合 = [-2.5] | 合并单层 = [-2.5]
```

下面拆开看每一步。

---

## 层二：分步逐函数拆解

### 步骤 1：教材的单个神经元

```python
z = w * x + b
```

**做什么**：计算线性部分 $z = 0.5\times1.0 + 0.2 = 0.7$。
**操作**：`*` 逐元素乘，`+` 加偏置。单神经元是"标量版"的 $W\mathbf{x}+\mathbf{b}$。
**可调参数**：`x, w, b` 任意。负的 `z` 会凸显 ReLU 与 Sigmoid 的差别。
**对应数学**：主线 $\mathbf{z} = W\mathbf{x}+\mathbf{b}$ 的标量版本。

### 步骤 2：两个激活函数

```python
def relu(z):    return np.maximum(0.0, z)
def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
```

#### `relu` —— 整流线性单元

**操作**：`np.maximum(0.0, z)` 逐元素取 $\max(0, z)$。
**输入**：标量 `z`（或数组）。
**输出**：$z\ge0$ 时原值，否则 0。`relu(0.7)=0.7`。
**可调参数**：`0.0` 改成 `0.1*z` 即 LeakyReLU（负值保留 10%）。
**对应数学**：主线 $\text{ReLU}(z)=\max(0,z)$。

#### `sigmoid` —— 逻辑斯蒂函数

**操作**：`np.exp(-z)` 算 $e^{-z}$，套进 $1/(1+e^{-z})$。
**输入**：标量 `z`。
**输出**：$(0,1)$ 内。`sigmoid(0.7)≈0.6682`。
**可调参数**：若要"负值对称"版，用 `np.tanh(z)`（范围 $(-1,1)$）。
**对应数学**：主线 $\sigma(z)=\frac{1}{1+e^{-z}}$。注意 `np.exp(-z)` 对 `z` 很大时会下溢为 0，`1/(1+0)=1`——数值稳定版本是 `scipy.special.expit`。

### 步骤 3：形状采样

```python
z_axis = np.linspace(-6.0, 6.0, 1001)
r = relu(z_axis)
```

#### `np.linspace(-6, 6, 1001)` —— 在 $z$ 轴上均匀采样

**操作**：生成 1001 个点，从 $-6$ 到 $6$。把数组传给 `relu`/`sigmoid`，一次算出所有点的值（向量化）。
**可调参数**：范围、点数任意。采样越密，画出的曲线越光滑。
**对应数学**：观察激活函数的"形状"——ReLU 是一条在原点折断的线，Sigmoid 是一条 S 形坡。`r[z_axis>=3][0]=3.0` 说明 ReLU 在正区间"原样放行"；`s.min()≈0.002` 说明 Sigmoid 输出恒在 $(0,1)$。

### 步骤 4：没有激活的两层 = 一层线性

```python
out_no_act = W2 @ (W1 @ x_vec)
W_merged = W2 @ W1
```

**做什么**：两层权重矩阵（无激活）对输入的作用，等于"合并矩阵" $W_2W_1$ 对输入的作用——**两层塌缩成一层**。
**操作**：`W2 @ (W1 @ x_vec)` 先 $W_1$ 后 $W_2$；`W2 @ W1` 把两个线性映射复合成一个，`(W_merged @ x_vec)` 结果与前者完全相同（都是 `-2.5`）。
**可调参数**：把其中一个换成 `relu(W1 @ x_vec)`，两式结果就不相等了——**非线性打断了"合并"**。
**对应数学**：主线"全线性网络退化为一层线性"。$W_2(W_1\mathbf{x}) = (W_2W_1)\mathbf{x}$——矩阵乘法结合律的直观结果。**这就是深度网络必须有激活函数的代数证明。**

## 边界声明：这套代码能做什么，不能做什么

1. **`relu`/`sigmoid` 是本课手写版**。工程上用 `torch.nn.functional.relu`、`F.sigmoid`（内部有数值稳定处理）。手写版的价值是看清"关节"的数学形状。
2. **激活函数的选择是任务相关的**。不是"Sigmoid 一定错、ReLU 一定对"。输出层做二分类用 Sigmoid（出概率），隐藏层用 ReLU 家族（保梯度），回归输出层可能不用激活。判断标准是"任务需要什么范围 + 梯度好不好传"。
3. **ReLU 的"死神经元"风险**。负区间梯度恒为 0，若神经元长期落在负区，它再也不更新。工程上用 LeakyReLU/ELU 或较小学习率缓解。这不是 ReLU 的 bug，是它的性格——§2.3.6.4 会展开。
4. **"没有激活 = 一层"只在全连接层之间严格成立**。卷积、归一化等其他运算会引入不同的结构，但"线性复合仍是线性"这条代数事实不变。看到"深度网络为什么需要非线性"的论证，核心就是这一步 `W2 @ W1` 的合并。
