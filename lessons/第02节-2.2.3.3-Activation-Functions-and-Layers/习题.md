# 习题：激活函数与层

## 第一组：概念检验

**1.1（单选）** 对 $z = -2$，ReLU 与 Sigmoid 的输出分别是：
- A. 0 与 0.12
- B. -2 与 0.12
- C. 0 与 0.88
- D. -2 与 0.88

**1.2（判断并说明）** "如果一个网络的所有层都不加激活函数，那么多层网络和单层网络在表达能力上是等价的。" 这句话对吗？用代数说明。

**1.3（填空）** 一个完整层的两个步骤是：先做____（$W\mathbf{x}+\mathbf{b}$），再施加____引入非线性；第 $l$ 层的____向量会成为第 $l+1$ 层的输入。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 设 $z = [2.0, -1.0, 0.5]$。手算 $\text{ReLU}(\mathbf{z})$ 与 $\sigma(\mathbf{z})$（保留 3 位小数），再用 NumPy 验证。

**2.2（代码验证）** 验证"两层线性复合可合并"：取 $W_1 = \begin{bmatrix} 1&2\\3&4\end{bmatrix}$、$W_2 = \begin{bmatrix} 0.5&-1\\2&0\end{bmatrix}$、$\mathbf{x}=[1,2]$，比较 $W_2(W_1\mathbf{x})$ 与 $(W_2W_1)\mathbf{x}$。再在中间插入 ReLU，比较是否还相等。

**2.3（动手理解）** 分别画出（或采样）ReLU、Sigmoid、Tanh 在 $[-5,5]$ 上的输出，记录各自的值域。思考：哪个适合"输出当概率"？哪个适合"隐藏层保梯度"？

## 第三组：DL 延伸

**3.1（场景判断）** 一个二分类网络，输出层的原始得分 $z = -1.8$。用 Sigmoid 激活后，模型认为"属于正类"的概率是多少？这个数该怎么解读？

**3.2（场景分析）** 某工程师把隐藏层激活全部换成 Sigmoid，网络训不动（loss 不降）。最可能的原因是什么？请用"梯度消失"和"Sigmoid 两端导数趋近 0"解释，并给出改法。

## 解答与思路点拨

### 第一组

**1.1 答案：A（0 与 0.12）。**
- **思路**：$\text{ReLU}(-2)=\max(0,-2)=0$；$\sigma(-2) = \frac{1}{1+e^{2}} = \frac{1}{1+7.389} \approx 0.12$。
- **点拨**：Sigmoid 对负的 `z` 输出接近 0 但不为 0（永远在 $(0,1)$）。C 的 0.88 是 $\sigma(2)$（正 2），记反了符号就是 0.88 vs 0.12 的差别。

**1.2 对。**
- **思路**：$\mathbf{z}^{(2)} = W^{(2)}(W^{(1)}\mathbf{x}+\mathbf{b}^{(1)})+\mathbf{b}^{(2)}$。若无激活，复合后仍是"一个线性变换 + 一个偏置"：$W^{(2)}W^{(1)}\mathbf{x} + (W^{(2)}\mathbf{b}^{(1)}+\mathbf{b}^{(2)})$——形式上就是单层 $\tilde{W}\mathbf{x}+\tilde{\mathbf{b}}$。**多层的线性复合，等价于某一层线性**，表达能力不增。
- **点拨**：这是"深度"的必要性论证。表达能力的跃升来自每层之间的非线性——正是激活函数。

**1.3 答案：线性变换（矩阵乘加偏置）；激活函数；激活。**
- **思路**：层 = 线性部分 + 非线性激活。$\mathbf{a}^{(l)}=\sigma(W^{(l)}\mathbf{a}^{(l-1)}+\mathbf{b}^{(l)})$，前一层的激活就是后一层的输入。
- **点拨**："激活向量接力"是理解"深度"的钥匙——每层都在前一层表达的基础上重新表达。

### 第二组

**2.1**
$\text{ReLU}([2,-1,0.5]) = [2, 0, 0.5]$。
$\sigma(2)=\frac{1}{1+e^{-2}}\approx0.881$，$\sigma(-1)=\frac{1}{1+e^{1}}\approx0.269$，$\sigma(0.5)=\frac{1}{1+e^{-0.5}}\approx0.622$。

```python
import numpy as np
z = np.array([2.0, -1.0, 0.5])
print(np.maximum(0, z))            # [2.  0.  0.5]
print(1/(1+np.exp(-z)))            # [0.881 0.269 0.622]
```
- **思路**：ReLU 逐元素取 max；Sigmoid 逐元素套 $1/(1+e^{-z})$。
- **点拨**：两个函数都是"逐元素"的——对向量来说就是对每个分量独立弯。`np.exp(-z)` 对负数 `z` 返回 $>1$，输出自然 $<0.5$。

**2.2**
```python
import numpy as np
W1 = np.array([[1.,2.],[3.,4.]])
W2 = np.array([[0.5,-1.],[2.,0.]])
x = np.array([1.,2.])
print(W2 @ (W1 @ x))        # [-2.5 -4. ]
print((W2 @ W1) @ x)        # [-2.5 -4. ] 相同
# 中间插 ReLU：
h = np.maximum(0, W1 @ x)   # [5. 11.]
print(W2 @ h)               # [-8.5 10. ] 与上面不同了
```
- **思路**：无激活时两层可合并（矩阵结合律）；插入 ReLU 后 $W_2\,\text{ReLU}(W_1\mathbf{x})$ 无法写成"某单矩阵 × $\mathbf{x}$"，因为 ReLU 破坏了线性。
- **点拨**：这就是"没有激活=一层"的数值证明。合并与否的分水岭，正是非线性。

**2.3**
```python
import numpy as np
z = np.linspace(-5, 5, 1001)
relu = np.maximum(0, z)
sigmoid = 1/(1+np.exp(-z))
tanh = np.tanh(z)
print("ReLU 值域:", relu.min(), relu.max())      # 0.0 5.0
print("Sigmoid 值域:", sigmoid.min(), sigmoid.max())  # ≈0.007 0.993
print("Tanh 值域:", tanh.min(), tanh.max())      # ≈-1 1
```
- **思路**：ReLU $[0,\infty)$、Sigmoid $(0,1)$、Tanh $(-1,1)$。Sigmoid 输出可当概率；ReLU 正区间导数 1 保梯度适合隐藏层。
- **点拨**：三个值域是三种"弯腰哲学"。选激活的第一步就是看值域是否匹配任务（概率→Sigmoid/Softmax，隐藏层→ReLU 族）。

### 第三组

**3.1 答案：概率 $= \sigma(-1.8) = \frac{1}{1+e^{1.8}} \approx 0.14$，即约 14%。**
- **思路**：$\sigma(-1.8)\approx0.1419$。模型认为正类概率约 14%，反类约 86%。决策阈值默认 0.5，低于它判为反类。
- **点拨**：**Sigmoid 把"得分"翻译成"概率"**。得分为负不意味着概率为 0，只是小于 50%。这就是"分数 vs 概率"的区别——§4 概率论会严格处理。

**3.2 思路**
- 最可能原因：**梯度消失 (vanishing gradient)**。Sigmoid 两端导数 $\sigma'(z)=\sigma(z)(1-\sigma(z))$ 趋近 0。深层网络反向传播时，每层都乘一个接近 0 的导数，梯度逐层衰减，浅层参数几乎学不到 → loss 不降。
- 若还叠加"零均值问题"：Sigmoid 输出全为正（均值 0.5），后层梯度会"同号振荡"，收敛更慢。
- **改法**：隐藏层换 ReLU 家族（正区间导数 1，梯度不衰减）；或用 ResNet 残差连接、BatchNorm（§2.3.6.8）缓解。
- **点拨**：这就是 2012 年 ReLU 取代 Sigmoid 的工程原因。选激活 = 在"表达力"与"梯度传播"之间权衡。§2.3.6.4 会有更系统的对比表。
