# 历史：让直线学会弯曲的"关节"——激活函数的故事

## 1943–1958：神经元有"阈值"，但世界是线性可分的

从麦卡洛克-皮茨的人工神经元到罗森布拉特的感知机，最早的"激活函数"其实是一个**硬阈值**：加权和超过某个值，输出 1；否则输出 0。像一扇门，要么开、要么关。

这套"阶跃函数"在逻辑上强大，在训练上却致命：**阶跃处不可导**——没有斜率，就没有梯度，就没有学习信号。更糟的是，1969 年明斯基证明了感知机连异或都学不会，因为单层 + 硬阈值的模型只能划一条直线。**神经网络需要一个"光滑的关节"：既能弯曲，又能求导。**

## 1986 年，一个 S 形曲线登上舞台

反向传播（1986）需要处处可导的激活函数。于是那个被统计学使用了上百年的 S 形曲线被请了出来：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**Sigmoid**——光滑、可导、把任意实数压进 $(0,1)$。它在生物学上也有说服力：神经元不会"要么全开要么全关"，而是渐进地饱和。整个 80、90 年代，Sigmoid 就是神经网络的默认激活。深层网络的第一次大规模训练，靠的都是这条 S 曲线。

## 世纪之交：Sigmoid 的黑暗面——"梯度消失"

可随着网络越来越深，一个幽灵出现了。

Sigmoid 在两端（$z$ 很大或很小时）导函数趋近于 0——曲线变得平坦。而反向传播要一层层把梯度乘回去：每一层都乘上一个"接近 0 的导数"，几十层乘下来，梯度像被稀释的水，到最底层时已经趋近于 0。**深层的权重几乎学不到东西。** 这个问题叫**梯度消失 (vanishing gradient)**。1990 年代，人们尝试各种补救——更好的初始化、逐层预训练——但"深度"始终卡在"层数一多就训不动"的天花板上。

## 2011–2012：ReLU——那个"用一句话解决梯度消失"的函数

破局者简单得近乎荒谬。2011 年前后，研究者们（尤其是 Glorot、Bordes、Bengio 的论文）开始推广一个在视觉皮层研究中早有来头的函数：

$$\text{ReLU}(z) = \max(0, z)$$

负数归零，正数原样。它为什么能救"梯度消失"？因为在**正区间，导数是 1**——不管这层的 $z$ 多大，梯度都原封不动地穿过去，不再被"稀释"。ReLU 的计算只是一个 `max(0, z)`，比指数运算快一个数量级。

2012 年，AlexNet 用 ReLU 在 ImageNet 上大杀四方，错误率几乎减半。从那以后，ReLU 取代 Sigmoid，成了深度学习的默认激活函数。**深度学习第一次真正"深"下去，靠的是一个连光滑都不要的分段线性函数。** 讽刺的是，当年人们以为激活必须光滑（为了可导），ReLU 用事实证明：分段线性不仅可导（除原点外），还更好训。

## ReLU 之后：一个繁荣的家族

ReLU 也非完美——负区间导数为 0，产生"死神经元"。于是家族开枝散叶：LeakyReLU 给负值一个微小的斜率，ELU 让负区间平滑衰减，GELU 用误差函数加权，SiLU 用 $\sigma(z)z$……每一次改进，都是对同一个问题的回答：**怎么弯曲，既保梯度、又保表达？**

而这一切的背后，是那条 1943 年就存在的分界线：**线性部分负责"搬"，激活函数负责"弯"。** 从硬阈值到 Sigmoid 再到 ReLU 家族，变的只是"弯的方式"，不变的是"必须弯"。

## 留一扇门

一根竹竿做不成圆；装上关节，折线就能逼近任何形状。激活函数，就是深度学习的那批关节。

从 1943 年的开关，到 1986 年的 S 曲线，再到 2012 年的 ReLU——每次激活的换代，都伴随一次深度的跃迁。而"该用哪种关节"的答案，始终在"表达力"与"可训练性"的天平上摇摆。下一节，我们去看那个把一切连起来的运算——**点积**——它是每个关节转动时脚下的那条轨道。
