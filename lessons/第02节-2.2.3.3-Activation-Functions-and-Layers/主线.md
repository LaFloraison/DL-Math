## 第一步：Toy Model —— 一根只能造直线的竹竿

一根竹竿，只能做成直线——你可以让它朝任何方向，但它永远是直的。一段高铁轨道，也只能是直线（夸张一点说）。现在给你一个任务：**用直线，拼出一个圆。** 你做不到——无论把多少条直线首尾相接，得到的还是一根"折了很多次但每一段都是直的"的折线，永远不是真正的圆。

但如果你被允许在每两段之间**装一个关节**——一个能把方向"掰弯"的关节——情况就不同了。每装一个关节，折线就多一次"弯腰"的机会；装足够多的关节，折线就逼近圆。

深度学习就是这趟折线游戏：**每一层是一条直线段（$W\mathbf{x} + \mathbf{b}$），激活函数是那个关节。** 没有激活函数，整个网络就是"一根更长的直线"（线性函数的复合还是线性）；有了激活函数，网络就有了"弯腰"的能力——它可以把数据掰成任意复杂的形状。

现在看一台机器的具体动作：一个值 $x = 1.0$ 进来，乘上权重 $w = 0.5$，加偏置 $b = 0.2$，得 $z = 0.7$。这就是"直线段"的长度。接下来，**关节**要决定怎么处理这个 0.7。

## 第二步：正式数学讲解

### 一、撞墙：$0.7$ 之后，到底该做什么？

$z = wx + b = 0.5 \times 1.0 + 0.2 = 0.7$。问题：把这个 $0.7$ 原样传给下一层，还是加工一下？

**先试"原样传"**——这等价于没有激活函数。§2.1 我们说过，全线性网络退化为一层线性，永远画不出曲线。所以"原样传"不行。

**再试"直接截断"**：如果 $z$ 是负数就归零，正数就保留——这就是 ReLU：

$$\text{ReLU}(0.7) = \max(0, 0.7) = 0.7$$

**换一种：压成 0 到 1 之间**——这就是 Sigmoid：

$$\sigma(0.7) = \frac{1}{1 + e^{-0.7}} \approx \frac{1}{1 + 0.4966} \approx 0.668$$

两个不同的"关节"，对同一个 0.7 给出不同的"弯腰"结果（0.7 vs 0.668）。**激活函数就是在选择"该怎么弯"**。你撞到的墙是：弯的方式有无数种，选哪个？答案没有唯一——这取决于任务（二分类喜欢 Sigmoid，深层网络喜欢 ReLU）。

### 二、定义块

> **激活函数 (activation function)** $\sigma$
>
> 施加在层输出上的非线性函数，让网络能建模复杂关系。
>
> **ReLU（整流线性单元）**
> $$\text{ReLU}(z) = \max(0, z) = \begin{cases} z & z > 0 \\ 0 & z \le 0 \end{cases}$$
>
> - 输出范围：$[0, \infty)$
> - 正区间导数恒为 1（梯度不衰减），负区间导数恒为 0
> - 现代网络默认选择；计算极快
>
> **Sigmoid（逻辑斯蒂函数）**
> $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
>
> - 输出范围：$(0, 1)$——可解释为概率
> - $z \to +\infty$ 时趋近 1，$z \to -\infty$ 时趋近 0
> - 两端导数趋近 0（梯度饱和问题，§2.3.6.4）
>
> 完整的层：$\mathbf{a}^{(l)} = \sigma(W^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)})$
> 其中 $\mathbf{a}^{(l)}$ 是第 $l$ 层的激活向量，也是下一层的输入。

### 三、层与层：激活向量如何接力

现在看清"层"的完整结构。每个"层"做两件事：

1. **线性变换**：$\mathbf{z}^{(l)} = W^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$——把上一层的激活向量搬到新空间（§2.3.5.3 会讲这是"线性变换"）。
2. **非线性激活**：$\mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)})$——掰弯。

**$l$ 层的激活向量，是 $l+1$ 层的输入。** 于是信息像接力棒一样逐层传递，每一层都在前一层的基础上"重新表达"数据。这就是为什么"层"这个字如此贴切：数据像穿过楼层一样，每上一层，表达就抽象一层——第一层看像素边缘，中间层看纹理，深层看"猫脸"。

直觉检验：Sigmoid 把任意 $z$ 压进 $(0,1)$，天然适合"概率"；ReLU 不压缩范围，保留正值大小，天然适合深层网络（梯度不消失）。**不同激活 = 不同的"弯腰哲学"**：有的想让输出保持在有界范围（Sigmoid），有的想保留幅度差异（ReLU），有的想对称（Tanh，负值也保留）。

边界声明：**激活函数必须是非线性的，但非线性不是"越多越好"。** ReLU 在负区间把梯度直接归零——负输入的网络参数得不到更新，"死神经元"问题（§2.3.6.4 详述）。Sigmoid 在两端饱和，深层网络里梯度逐层衰减（梯度消失）。没有免费的弯腰——每个激活函数都在"表达力"和"可训练性"之间做权衡。此外，"层"不一定全是全连接层；卷积层、池化层、归一化层各司其职（§2.2.3.7、§2.3.6.8），但"线性 + 激活"是所有层共享的骨架。

## 第三步：DL 桥接

**激活函数是"深度学习能深下去"的关键。** 三个落点：

1. **没有激活，深等于浅。** 如果所有层都线性（$\sigma$ 是恒等），那么 $W^{(2)}(W^{(1)}\mathbf{x}) = (W^{(2)}W^{(1)})\mathbf{x}$——两层并成一层。**深度失去意义。** 激活函数让"深"真正变"深"：每一层都贡献一次"掰弯"，网络才能拟合复杂的决策边界。这是"深度网络为什么必须有非线性"的数学答案。

2. **选择与任务绑定。** 二分类输出层用 Sigmoid（输出可当概率），多分类用 Softmax（§2.3.6.4 介绍），隐藏层默认 ReLU 及变体。**同一个网络内部，激活可以不同**：中间层 ReLU 保梯度，输出层 Sigmoid 出概率。

3. **激活与几何。** 激活函数的输入是"特征空间里的位置"（$z$），输出是"弯过之后的位置"（$a$）。整条"特征流"——从输入向量到最终概率——就是数据被一层层线性搬动、非线性掰弯的过程。你在注意力里看到的 Softmax、在 GAN 里看到的 LeakyReLU、在扩散模型里看到的 SiLU，全都是"该怎样弯腰"这个问题的不同答案。

一句话：**没有激活函数，神经网络只是"更长的直线"；有了它，直线才能弯曲成能装下整个世界的形状。** 每一种激活，都是人类为"如何弯曲"找到的一个答案。
