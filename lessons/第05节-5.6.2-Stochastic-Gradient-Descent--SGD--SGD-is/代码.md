# 代码：三档下山——SGD、小批量、BGD 的速度与噪声对照

**目标**：主线讲了 SGD（单样本）与 mini-batch（小批）。这里在**同一份数据**上跑三档梯度——**BGD**（每步全部样本）、**mini-batch**（每步 64 样本）、**SGD**（每步 1 样本）——记录两个指标：**收敛速度**（达到 loss 0.30 需要几个 epoch）与**噪声水平**（末 epoch 内逐更新 loss 的抖动 std）。你会看到教材那句"SGD 快但震荡"的完整证据：**SGD 用 4 个 epoch 就够好，但它最抖；BGD 平滑却要 300 个 epoch；mini-batch 是两者之王。**

## 层一：完整脚本

```python
import numpy as np
rng = np.random.default_rng(42)

# ---- 1. 数据: 与 §5.6.1 相同 ----
X = np.linspace(0.0, 10.0, 1000)
y = 2.5 + 1.5 * X + rng.normal(0, 0.5, len(X))
N = len(X)

# ---- 2. 梯度函数 ----
def full_grad(theta):                                  # BGD: 全部样本
    pred = theta[0] + theta[1] * X
    return np.array([np.sum(pred - y), np.sum((pred - y) * X)]) / N

def sub_grad(theta, idx):                              # mini/SGD: 只看 idx
    pred = theta[0] + theta[1] * X[idx]
    return np.array([np.sum(pred - y[idx]),
                     np.sum((pred - y[idx]) * X[idx])]) / len(idx)

def loss(theta):
    return np.mean((theta[0] + theta[1] * X - y) ** 2)   # MSE

# ---- 3. 训练: 记录每 epoch 的 loss 与末 epoch 的抖动 ----
def train(method, epochs, lr, bs=1):
    theta = np.array([0.0, 0.0])
    losses = []
    for _ in range(epochs):
        if method == 'BGD':                            # 1 epoch = 1 次全量更新
            theta = theta - lr * full_grad(theta)
        else:                                          # 1 epoch = N/bs 次批更新
            for _ in range(N // bs):
                idx = rng.integers(0, N, size=bs)      # 随机抽样 (stochastic!)
                theta = theta - lr * sub_grad(theta, idx)
        losses.append(loss(theta))
    # 末 epoch 内逐更新 loss, 量"噪声"
    t2 = theta.copy(); last_noise = []
    if method != 'BGD':
        for _ in range(N // bs):
            idx = rng.integers(0, N, size=bs)
            t2 = t2 - lr * sub_grad(t2, idx)
            last_noise.append(loss(t2))
    else:
        last_noise = [losses[-1]]
    return theta, losses, last_noise

def epochs_to(losses, thr):                            # 达到阈值的 epoch 数
    for i, l in enumerate(losses):
        if l < thr: return i + 1
    return len(losses)

# ---- 4. 三档训练 ----
th_b, lb, nb = train('BGD', 300, 0.02)                 # BGD: 每 epoch 只 1 次更新
th_m, lm, nm = train('MB',  50, 0.02, bs=64)           # mini-batch: 每 epoch 16 次
th_s, ls, ns = train('SGD', 50, 0.002, bs=1)           # SGD: 每 epoch 1000 次

print(f"BGD: theta=[{th_b[0]:.3f},{th_b[1]:.3f}]  loss={lb[-1]:.4f}  达0.30需 {epochs_to(lb,0.30)} epoch")
print(f"MB : theta=[{th_m[0]:.3f},{th_m[1]:.3f}]  loss={lm[-1]:.4f}  达0.30需 {epochs_to(lm,0.30)} epoch")
print(f"SGD: theta=[{th_s[0]:.3f},{th_s[1]:.3f}]  loss={ls[-1]:.4f}  达0.30需 {epochs_to(ls,0.30)} epoch")
print(f"末epoch内loss抖动(std): BGD={np.std(nb):.2e}  MB={np.std(nm):.4f}  SGD={np.std(ns):.4f}")
print(f"前3个epoch的loss: SGD {[round(float(l),3) for l in ls[:3]]}  |  BGD {[round(float(l),3) for l in lb[:3]]}")
```

输出（可复现，固定种子）：

```
BGD: theta=[1.98,1.58]  loss=0.3086  达0.30需 300 epoch
MB : theta=[2.43,1.49]  loss=0.2529  达0.30需 22 epoch
SGD: theta=[2.48,1.52]  loss=0.2632  达0.30需 4 epoch
末epoch内loss抖动(std): BGD=0.00e+00  MB=0.0009  SGD=0.0123
前3个epoch的loss: SGD [0.699, 0.443, 0.347]  |  BGD [13.306, 2.64, 1.552]
```

**一行数据，整个 §5.6.2 的结论全在里面：**
- **收敛速度**：SGD 用 **4 个 epoch** 就达到 loss 0.30（它每 epoch 做 1000 次更新，走得最频）；mini-batch 用 22 个；BGD 跑了 300 个 epoch 还没到（它每 epoch 只 1 次更新，走得最稀）。**"SGD 收敛更快"——因为在同样"看一遍数据"的时间里，它更新参数的次数多出几百上千倍。**
- **噪声水平**：末 epoch 内逐更新 loss 的抖动，SGD（0.0123）是 mini-batch（0.0009）的 **13 倍**，BGD 完全平滑（0）。**SGD 冲到谷底附近后一直"抖"着落不稳**——它的 theta1=1.52 也比 mini-batch 的 1.49 偏离真值 1.5 更远。
- **mini-batch 是折中**：收敛快（22 epoch）、噪声小（0.0009），几乎兼得 SGD 的速度与 BGD 的稳定——**这就是它成为深度学习事实标准的原因。**

## 层二：分步逐函数拆解

### 步骤 1-2：数据与梯度

```python
def full_grad(theta):
    pred = theta[0] + theta[1] * X
    return np.array([np.sum(pred - y), np.sum((pred - y) * X)]) / N

def sub_grad(theta, idx):
    pred = theta[0] + theta[1] * X[idx]
    return np.array([np.sum(pred - y[idx]),
                     np.sum((pred - y[idx]) * X[idx])]) / len(idx)
```

#### `full_grad` 与 `sub_grad` —— 全量 vs 局部梯度

**操作**：两者算的都是 MSE 梯度 $\big(\frac{1}{K}\sum(\text{pred}-y),\ \frac{1}{K}\sum(\text{pred}-y)x\big)$，区别只在用多少样本：
- `full_grad`：用全部 `X`、`y`（`N=1000`）——BGD 的全量梯度，`/N` 平均。
- `sub_grad`：用 `X[idx]`、`y[idx]`（`idx` 随机下标数组）——mini-batch/SGD 的局部梯度，`/len(idx)` 平均。

**输入**：`theta`（形状 `(2,)`）、可选 `idx`（下标数组）。**输出**：形状 `(2,)` 的梯度。
**可调参数**：`idx` 的长度就是**批大小**——1 是 SGD，64 是 mini-batch，1000 是 BGD。**同一个公式，靠抽样规模切换档位。**

**对应数学**：主线的 SGD 更新 $\theta\leftarrow\theta-\alpha\nabla J(\theta;x_i,y_i)$ 与 mini-batch 更新 $\theta\leftarrow\theta-\alpha\frac{1}{m}\sum_{i\in\mathcal{B}}\nabla J(\theta;x_i,y_i)$。

---

### 步骤 3：训练与两个指标

```python
def train(method, epochs, lr, bs=1):
    theta = np.array([0.0, 0.0])
    losses = []
    for _ in range(epochs):
        if method == 'BGD':
            theta = theta - lr * full_grad(theta)      # 1 epoch = 1 次更新
        else:
            for _ in range(N // bs):                    # 1 epoch = N/bs 次更新
                idx = rng.integers(0, N, size=bs)
                theta = theta - lr * sub_grad(theta, idx)
        losses.append(loss(theta))
    ...
```

#### `rng.integers(0, N, size=bs)` —— 随机抽样

**操作**：从 `[0, N)` 均匀抽 `bs` 个下标——**"stochastic" 的注入点**：每步换一批随机样本。**输入**：`low=0`、`high=1000`、`size=bs`。**输出**：形状 `(bs,)` 的下标数组。
**可调参数**：`bs` 是批大小——深度学习最关键的超参数之一。

#### 1 epoch 的定义（关键）

**操作**：三种方法"1 个 epoch"（过完一遍数据）内部的更新次数不同：
- BGD：`1` 次全量更新。
- mini-batch/SGD：`N // bs` 次批更新（bs=64 → 16 次；bs=1 → 1000 次）。

**这就是"SGD 收敛更快"的根源**：在同样"看一遍数据"的时间（1 epoch）里，SGD 更新参数 1000 次，BGD 只更新 1 次。**走得更频，自然更快到达好解。**

#### 末 epoch 噪声测量

```python
t2 = theta.copy(); last_noise = []
for _ in range(N // bs):
    idx = rng.integers(0, N, size=bs)
    t2 = t2 - lr * sub_grad(t2, idx)
    last_noise.append(loss(t2))
```

**操作**：训练结束后，用最终 $\theta$ 再跑一个 epoch，记录每步的 loss——**这一串 loss 的抖动（std）就是"噪声水平"**。BGD 没有噪声（`last_noise` 只有 1 个点，std=0）。
**可调参数**：无。**意义**：SGD 的 std=0.0123 表示它在谷底附近"抖"的幅度——这就是教材说的"高方差导致震荡，难以精确落点"。


## 实验台：让三档的脾气现出原形

1. **画 loss 曲线**：把 `lb`、`lm`、`ls` 画成"loss vs epoch"曲线——SGD 急坠（前 5 epoch 就到 0.3 以下），BGD 缓降（300 epoch 还在 0.3 以上），mini-batch 居中。**一张图看懂"频率换速度"。**
2. **调批大小**：`bs` 从 1 → 16 → 64 → 256：看"达阈值 epoch 数"变多、但"噪声 std"变小。**批大小是噪声-稳定-算力的三向旋钮。**
3. **加学习率衰减**：SGD 的 `lr` 每 epoch 乘 `0.9`——后期步长收窄，SGD 终于能"落稳"，末 epoch 抖动 std 明显下降。**这就是主线"学习率衰减"解药的代码验证。**
4. **换非凸地形**：把目标换成 §5.4 的双谷函数——BGD 从浅谷盆地出发会困住，SGD 的噪声能帮它翻出来。**"噪声帮助逃离局部最优"的现场。**

**对应数学**：实验 3 对应主线"缓解震荡的三味解药"（衰减/动量/批）；实验 4 对应"SGD 噪声在非凸问题上的额外好处"。
