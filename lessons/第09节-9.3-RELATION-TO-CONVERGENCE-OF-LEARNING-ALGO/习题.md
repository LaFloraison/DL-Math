# 习题：收敛的五个支点

## 第一组：概念检验

**1. 多选题**：下面哪些属于 §9.3 列出的"决定收敛效果"的拓扑/配置支点？
- (A) 层数（深度）
- (B) 每层节点数（宽度）
- (C) 学习率的大小
- (D) 连接方式（跳连/循环）
- (E) 激活函数的选择
- (F) 训练数据的具体分布

**2. 判断题并说明理由**："只要把学习率调到最优，任何拓扑的网络都能顺利收敛。"

**3. 简答**：为什么"梯度消失"会让深度网络训不动？它影响的到底是哪个环节？

### 解答与思路点拨

**1. (A)(B)(D)(E)(F)。** (C) 学习率不属于 §9.3 的"拓扑/配置"支点——教材明确列的是：深度、宽度、连接方式、激活函数，加上数据与任务、初始化、正则化。学习率是**优化器超参数**，与拓扑不在同一个抽屉。注意 (F) 数据也算一个支点——教材说"数据与任务，与拓扑一起决定收敛"，别漏掉它。

**2. 错误。** 收敛是拓扑+配置+优化的合力。如果梯度因深度而消失（如 tanh 20 层，梯度到 $10^{-4}$ 量级），学习率调得再准，底层权重收到的更新信号也微乎其微——优化器"看不见"底层的错误，无从调整。学习率只能调整"在看得见的梯度上走多远"，不能凭空造出消失的梯度。**学习率管步长，拓扑管梯度有没有。**

**3.** 梯度消失发生在**反向传播的信号传输**环节：误差从输出逐层传回，每层乘一次"激活导数 × 权重"，乘积项数等于层数。当每层增益 < 1（如 sigmoid 的 0.25），乘积指数衰减——底层接收到的 $\delta$ 趋近 0。后果是底层的权重更新量 $\Delta W \propto \delta \approx 0$——底层**永远学不到东西**，整个深层网络实际只有顶部几层在学。这正是 §9.3.1.1"深度带来的挑战"的核心。

## 第二组：计算实践

**4. 手算**：一条 10 层标量链，每层增益为 0.5。输出层梯度幅值设为 1。请计算输入层（第 0 层）的梯度幅值（保留科学计数法），并说出它意味着什么。

**5. 代码验证**：用本节的 `grad_chain` 验证：`grad_chain(10, 0.5, 1.0)` 的最后一个元素；再把增益换成 2.0（`grad_chain(10, 2.0, 1.0)`），观察梯度如何变化，说明这种现象叫什么。

### 解答与思路点拨

**4.** 每层乘 0.5，10 层就是 $0.5^{10} = \frac{1}{1024} \approx 9.77 \times 10^{-4}$。输入层的梯度只有输出层的千分之一——**梯度消失**。含义：如果这是网络底层，它收到的更新信号微弱到几乎无法学习，深层网络"训不动"的病根就在这。

**5.** 验证：

```python
import math
def grad_chain(L, w, fprime, skip=False):
    grads=[1.0]; d=1.0
    for _ in range(L):
        d=d*w*fprime
        if skip: d=d+1.0
        grads.append(d)
    return grads

print(f"增益0.5 → 输入层梯度 = {grad_chain(10,0.5,1.0)[0]:.2e}")
print(f"增益2.0 → 输入层梯度 = {grad_chain(10,2.0,1.0)[0]:.2e}")
print(f"增益2.0 的 log10 = {math.log10(grad_chain(10,2.0,1.0)[0]):.1f}")
```

```text
增益0.5 → 输入层梯度 = 9.77e-04
增益2.0 → 输入层梯度 = 1.02e+03
```

增益 0.5 → 消失（千分之一）；增益 2.0 → **爆炸**（涨到 1000 倍以上）。同一套乘积机制，增益小于 1 就消失、大于 1 就爆炸——这就是 §9.3"深度带来的收敛挑战"的数值根源，也是为什么初始化要精心设计（He/Glorot 正是让增益≈1 的初始化）。

## 第三组：DL 延伸

**6. 场景判断**：你训练一个 100 层的纯 tanh 网络，发现损失在某个值上"卡死"，不再下降。你怀疑梯度消失了。请设计一个最小验证实验：应该观察什么信号、在哪里观察、对比什么，来确认"梯度消失"确实是元凶（而不是学习率太小或数据问题）。

**7. 思考题**：§9.3 说"结构能极大地影响学习算法找到最优解的成功率"。结合 ResNet 的历史（§9.3 历史），请说明：为什么"深度导致训不动"被诊断为结构问题而非调参问题？这个诊断靠什么证据？

### 解答与思路点拨

**6.** 一个直接验证：在训练中**打印每一层权重的梯度范数**（§9.3 代码的 `grad_chain` 就是标量版）。如果发现：靠输出层的梯度范数正常（如 0.1~1 量级），而靠输入层的梯度范数小到 $10^{-6}$ 以下，且随层数单调衰减——那就是梯度消失。对照实验：把激活换成 ReLU（或加跳连），同样的深度梯度范数恢复正常，则坐实了"激活函数/结构导致梯度消失"这一结论，而非学习率或数据问题。

**7.** 关键证据是**训练误差**（不是测试误差）也随深度升高——何恺明 2015 年的观察：56 层比 20 层在训练集上的误差**更高**。若是过拟合（数据/正则问题），训练误差应该更低；训练误差反而更高，说明网络**没学会**，是优化（收敛）失败。再配合"加跳连后同深度能收敛"这一对照，证明问题出在结构（梯度传播通道），而非学习率等调参。这就是"结构影响收敛成功率"的实证链条。
