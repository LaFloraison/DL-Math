# §6.3 联合熵与条件熵 —— 习题

本节主线建立了从单变量到两变量的两把尺子：联合熵 $H(X,Y)$ 量系统总不确定，条件熵 $H(Y\mid X)$ 量"知道 $X$ 后 $Y$ 还剩多少"，以及贯穿一切的链式法则 $H(X,Y)=H(X)+H(Y\mid X)$。习题分三组：**概念检验** 验证两把尺子的性质与边界，**计算实践** 用联合分布表手算并代码验证链式法则，**DL 延伸** 把条件熵放回语言模型的逐词预测与 VAE。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：哪个关系恒成立？

设 $X, Y$ 为任意两个离散随机变量（不一定独立）。以下关系**恒成立**的是（ ）。

- A. $H(X,Y) = H(X) + H(Y)$
- B. $H(Y \mid X) = H(X \mid Y)$
- C. $H(X,Y) \le H(X) + H(Y)$
- D. $H(Y \mid X) \ge H(Y)$

**解答**：C。

C 是链式法则 $H(X,Y) = H(X) + H(Y\mid X)$ 与 $H(Y\mid X) \le H(Y)$（已知只会减少不确定）合并的直接推论：$H(X,Y) = H(X)+H(Y\mid X) \le H(X)+H(Y)$，等号当且仅当独立。A 只在独立时成立；B 两个条件熵一般不等（天气×带伞就是反例）；D 方向反了——条件熵不会大于边缘熵。

**思路点拨**：这类题的关键是"恒成立"vs"特定情形成立"。A、D 都披着"直觉合理"的外衣（A 像"加总"、D 像"知道了还更拿不准"），但都被链式法则证伪。判别锚点：**"知道只会帮倒忙"在信息论里永不成立——$H(Y\mid X) \le H(Y)$ 是铁的**。拿不准时把链式法则写出来推一遍。

### 题 2（判断 + 简答）：$H(Y\mid X)$ 能等于 $H(Y)$ 吗？

小明算出一个条件熵 $H(Y\mid X)$ 恰好等于 $H(Y)$。他说："这不可能，知道 $X$ 总该让 $Y$ 的不确定变小一点。" 判断并解释。

**解答**：可能，而且**完全独立**时就会发生。$H(Y\mid X)=H(Y)$ 恰恰刻画了 $X$ 与 $Y$ 独立：知道 $X$ 不改变对 $Y$ 的了解。链式法则 $H(X,Y)=H(X)+H(Y\mid X)$ 在独立时变成 $H(X,Y)=H(X)+H(Y)$——回到 §6.3.1 硬币×骰子的情形：$H(Y\mid X)=H(Y)=2.585$。所以"条件熵等于边缘熵"不是错误，它是在说"这两个变量互不相干"。

**思路点拨**：这题考的是条件熵的**两端**：$H(Y\mid X)=0$（$X$ 完全决定 $Y$）与 $H(Y\mid X)=H(Y)$（$X$ 与 $Y$ 无关）。直觉总把"知道之后"想象成"总会变小"，但信息论说：如果两者本来就不相关，知道等于不知道，条件熵不变。记住 $0 \le H(Y\mid X) \le H(Y)$ 的**下界与上界各自对应一种极端关系**，条件熵在两端的取值就是关系的指纹。

### 题 3（简答）：链式法则为什么叫"链式"？

写出两变量的链式法则，并解释：如果把系统扩到三个变量 $X, Y, Z$，这条"链"会怎样延伸？

**解答**：两变量的链式法则 $H(X,Y) = H(X) + H(Y\mid X)$。扩展到三个变量：

$$H(X,Y,Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y)$$

一般地，对 $n$ 个变量：

$$H(X_1,\ldots,X_n) = H(X_1) + H(X_2\mid X_1) + \cdots + H(X_n\mid X_1,\ldots,X_{n-1})$$

"链式"的名字来自它的结构：总不确定被拆成**一环扣一环**——先记第一个变量的不确定，再加"知道第一个后第二个还剩的"，再加"知道前两个后第三个还剩的"，如此递推。每一步的"条件"都比上一步多一个变量，像链条一节节扣上。语言模型预测一句含 $n$ 个词的话，用的正是这条 $n$ 环链。

**思路点拨**：这题的价值在"看到递推结构"。链式法则不是两条凑巧的恒等式，而是一族可任意延长的等式——它的每一项都是"给定前面所有，这一环还剩多少"。理解了这个结构，你就同时理解了：为什么条件熵的定义是"加权平均"，以及为什么自回归模型能天然地用信息论表述。

## 二、计算实践

### 题 1（抛硬币 + 掷骰子：验证链式法则）

$X$：公平硬币（正/反），$P(X=H)=P(X=T)=0.5$。$Y$：公平六面骰子。$X, Y$ 独立。

(a) 手算 $H(X)$、$H(Y)$。
(b) 构造联合分布表 $P(x,y)$，手算 $H(X,Y)$。
(c) 用链式法则验证 $H(X,Y) = H(X) + H(Y\mid X)$，并直接给出 $H(Y\mid X)$。

**解答**：

(a) $H(X) = -\big(0.5\log_2 0.5 \times 2\big) = 1$ bit；$H(Y) = -\sum_{y=1}^{6}\frac{1}{6}\log_2\frac{1}{6} = \log_2 6 \approx 2.585$ bits。

(b) 独立时 $P(x,y) = P(x)P(y) = 0.5 \times \frac{1}{6} = \frac{1}{12}$，共 $2\times6=12$ 格。联合熵
$$H(X,Y) = -\sum_{x,y}\frac{1}{12}\log_2\frac{1}{12} = \log_2 12 = 2 + \log_2 3 \approx 3.585 \text{ bits}$$

(c) 独立时 $H(Y\mid X) = H(Y) = 2.585$ bits。链式法则：
$$H(X,Y) = 1 + 2.585 = 3.585 \text{ bits}$$
与 (b) 完全一致。

**思路点拨**：(b) 的关键是"独立 → 联合表每个格子概率相等 $\frac{1}{12}$"——12 个等概率配对，联合熵就是 $\log_2 12$。教材 §6.3.1 的数字 3.585 bits 就是这么来的。最容易错的地方是把 $H(X,Y)$ 错算成 $H(X)\times H(Y)$（乘法）——熵之间是**相加**不是相乘；"配对概率相乘"（$\frac{1}{12}$）与"熵相加"（1+2.585）是两个层次的事，别混。

**代码验证**：
```python
import numpy as np
def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -np.sum(p * np.log(p) / np.log(2))
pxy = np.full((2, 6), 0.5 * 1/6)
print(entropy(pxy))            # 3.584962500721156
print(entropy([0.5, 0.5]) + entropy([1/6]*6))   # 3.584962500721156
```

### 题 2（天气 × 带伞：把条件熵算到底）

教材数据：$P(X=S)=0.7$（晴），$P(X=R)=0.3$（雨）；晴时带伞 $P(Y=\text{Yes}\mid S)=0.2$，雨时带伞 $P(Y=\text{Yes}\mid R)=0.9$。

(a) 填出联合分布表 $P(x,y)$（4 格）。
(b) 算边缘 $P(Y=\text{Yes})$、$P(Y=\text{No})$，以及 $H(Y)$。
(c) 用"先算两个条件熵再加权"的方式手算 $H(Y\mid X)$。
(d) 用链式法则核对 $H(X,Y) = H(X) + H(Y\mid X)$。

**解答**：

(a) $P(S,\text{Yes})=0.7\times0.2=0.14$；$P(S,\text{No})=0.7\times0.8=0.56$；$P(R,\text{Yes})=0.3\times0.9=0.27$；$P(R,\text{No})=0.3\times0.1=0.03$。表：
| | Yes | No |
|---|---|---|
| S | 0.14 | 0.56 |
| R | 0.27 | 0.03 |

(b) $P(Y=\text{Yes}) = 0.14+0.27 = 0.41$，$P(Y=\text{No}) = 0.56+0.03 = 0.59$。
$$H(Y) = -(0.41\log_2 0.41 + 0.59\log_2 0.59) \approx 0.41\times1.287 + 0.59\times0.761 \approx 0.528 + 0.449 = 0.977 \text{ bits}$$

(c) 晴天条件分布 $(0.2, 0.8)$：$H(Y\mid S) = -(0.2\log_2 0.2 + 0.8\log_2 0.8) = 0.2\times2.322 + 0.8\times0.322 = 0.464 + 0.258 = 0.722$ bits。雨天条件分布 $(0.9, 0.1)$：$H(Y\mid R) = -(0.9\log_2 0.9 + 0.1\log_2 0.1) = 0.9\times0.152 + 0.1\times3.322 = 0.137 + 0.332 = 0.469$ bits。加权：
$$H(Y\mid X) = 0.7\times0.722 + 0.3\times0.469 = 0.505 + 0.141 = 0.646 \text{ bits}$$

(d) $H(X) = -(0.7\log_2 0.7 + 0.3\log_2 0.3) = 0.7\times0.515 + 0.3\times1.737 = 0.360+0.521 = 0.881$ bits。$H(X,Y) = -(0.14\log_2 0.14 + 0.56\log_2 0.56 + 0.27\log_2 0.27 + 0.03\log_2 0.03)$。$0.14\times2.837=0.397$，$0.56\times0.837=0.469$，$0.27\times1.889=0.510$，$0.03\times5.059=0.152$，和 $=1.528$。于是 $H(X)+H(Y\mid X) = 0.881 + 0.646 = 1.527 \approx 1.528$（舍入误差内）——链式法则成立。

**思路点拨**：(c) 是条件熵定义的完整演练：**先对每个 $X$ 取值算一个条件熵，再按 $P(x)$ 加权**。这一步是 6.3.2 节的核心，务必亲手走一遍。容易错的两处：①$H(Y\mid S)$ 用的是**条件分布** $(0.2,0.8)$ 而不是联合概率，分母已经是 1，别把 $0.14, 0.56$ 代进去；②加权用的是 $P(x)$（$0.7, 0.3$），不是别的权重。核对：$0.646 < 0.977 = H(Y)$，条件熵确实小于边缘熵——知道天气让带伞的不确定下降了。

### 题 3（独立 vs 相关：一表看穿）

用同一组边缘分布 $P(X)=(0.7,0.3)$、$P(Y)=(0.41,0.59)$，分别构造**独立**联合分布（外积）和**相关**联合分布（教材场景 B 的表），比较两者 $H(X,Y)$ 与 $H(Y\mid X)$。

**解答**：

独立联合表（外积）：$P(x,y)=P(x)P(y)$，即 $(0.7\times0.41, 0.7\times0.59, 0.3\times0.41, 0.3\times0.59) = (0.287, 0.413, 0.123, 0.177)$。它的联合熵
$$H(X,Y)_{\text{ind}} = H(X)+H(Y) = 0.881 + 0.977 = 1.858 \text{ bits}$$
$H(Y\mid X)_{\text{ind}} = H(Y) = 0.977$ bits。

相关联合表（场景 B）：$H(X,Y)_{\text{dep}} = 1.528$ bits，$H(Y\mid X)_{\text{dep}} = 0.646$ bits。

**两表边缘分布完全相同，只是格子里概率的"摆放"不同**——独立时 $P(x,y)=P(x)P(y)$，相关时偏离外积。结果：$H(X,Y)$ 从 1.858 降到 1.528，$H(Y\mid X)$ 从 0.977 降到 0.646。**边缘分布一样，关系不一样，联合熵和条件熵就跟着变**——这两把尺子量的不是"各自的不确定"，而是"放在一起之后的不确定"。

**思路点拨**：这题最考验理解：**同样的边缘，不同的联合**。$H(X)$、$H(Y)$ 由边缘分布决定，两边完全相同；但联合熵和条件熵对"表里概率怎么摆"极其敏感。这是为什么联合熵/条件熵能"看到"关系，而单变量熵看不到。答这类题的关键：先固定边缘，再比较联合，差异即关系的指纹。6.5 节会把这个"差异"正式命名为互信息。

## 三、DL 延伸

### 题 1（语言模型 = 一串条件熵）

一个自回归语言模型把句子 $s = (w_1, w_2, w_3)$ 建模为 $P(w_1, w_2, w_3) = P(w_1)P(w_2\mid w_1)P(w_3\mid w_1, w_2)$。

(a) 写出"整句话的熵"按链式法则的分解。
(b) 已知 $H(w_1) = 4.0$ bits，$H(w_2\mid w_1) = 2.5$ bits，$H(w_3\mid w_1, w_2) = 1.0$ bits，整句话的熵是多少？
(c) 三环熵递减说明了语言的什么性质？如果每一环的条件熵都和 $H(w_1)$ 一样大，说明模型学到了什么（没学到什么）？

**解答**：

(a) $H(w_1, w_2, w_3) = H(w_1) + H(w_2 \mid w_1) + H(w_3 \mid w_1, w_2)$。

(b) $H = 4.0 + 2.5 + 1.0 = 7.5$ bits。

(c) 三环熵递减（4.0 → 2.5 → 1.0）说明**语言的强预测性**：看到前一个词后，下一个词的不确定大幅下降；上下文越长，越能预测后续——这正是语言高冗余的表现（可压缩的原因）。如果每一环的条件熵都等于 $H(w_1)=4.0$，说明模型（或语言本身在这个设定下）**没有利用任何上下文**：$w_t$ 与前面的词完全无关，每个词都是独立等随机——模型什么依赖都没学到。条件熵的降幅，就是"上下文帮了多少忙"的度量。

**思路点拨**：这道题把链式法则直接翻译成语言模型的训练目标。要点：**条件熵递减小 = 预测成功**。训练语言模型，就是在压低每一环的 $H(w_t\mid w_{<t})$。如果条件熵不降反升，说明模型在"更会预测之前"先学会了"更会吃惊"——通常意味着过拟合或数值问题。这个"条件熵递减"的曲线，是判断模型是否真学到语言的可靠仪表。

### 题 2（VAE 里的联合分布：$H(Y\mid X)$ 的另一面）

变分自编码器的证据下界 (ELBO) 里，编码器输出 $q(z\mid x)$——给定数据 $x$ 后隐变量 $z$ 的条件分布。从信息论看，训练 VAE 在做什么？把 $H(Z\mid X)$ 与 $H(Z)$ 的关系讲清楚。

**解答**：编码器 $q(z\mid x)$ 是"给定 $x$ 后 $z$ 的条件分布"，信息论里对应的正是条件熵 $H(Z\mid X)$——已知数据 $x$ 后，隐变量 $z$ 还剩多少不确定。训练 VAE 的目标之一，是让 $q(z\mid x)$ 足够尖锐（$H(Z\mid X)$ 小）——给定图片 $x$，隐码 $z$ 应被确定下来（编码器"看懂了"这张图）；但同时 $H(Z)$（先验 $p(z)$ 的熵）应保持"可控"（隐码空间别塌缩）。两者对比：$H(Z\mid X) < H(Z)$ 说明数据 $x$ 携带了关于 $z$ 的信息（编码器不是瞎猜）；而 $I(X;Z) = H(Z) - H(Z\mid X)$ 正是"数据告诉了我们多少关于隐码的事"——ELBO 里的 KL 项与重建项，本质是在这场"信息到底放哪"的博弈里找平衡。

**思路点拨**：VAE 常被说成"很难理解"，但如果把它翻译成条件熵的语言，它就不难了：**编码器在压条件熵（给定 $x$ 就确定 $z$），解码器在压重建误差（给定 $z$ 就还原 $x$）**，而 KL 项约束着"$z$ 别把自己变成独立于 $x$ 的噪声"。$H(Z\mid X)$ 与 $H(Z)$ 的差，就是隐空间"装了多少关于输入的信息"——信息论给生成模型提供了一把清晰的尺子。这也是 6.5 节互信息在生成模型里的真正位置。
