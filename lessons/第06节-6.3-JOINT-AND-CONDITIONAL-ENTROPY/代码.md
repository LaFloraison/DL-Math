# 代码：联合熵与条件熵——把整张配对概率表装进函数

主线里我们把熵推向两个变量：联合熵 $H(X,Y)$ 量整个系统的总不确定，条件熵 $H(Y\mid X)$ 量"知道 $X$ 后 $Y$ 还剩多少"。它们共同的原料是**联合分布 $P(x,y)$**——一张二维概率表。

本脚本的核心约定：**联合分布用 NumPy 的二维数组表示**，行对应 $X$ 的取值、列对应 $Y$ 的取值，每个格子是 $P(x, y)$。从这张表出发，可以派生出一切：边缘分布 $P(x)$、$P(y)$、条件分布 $P(y \mid x)$、以及所有熵。脚本会验证主线最要紧的那条链式法则 $H(X,Y) = H(X) + H(Y\mid X)$——用独立场景和教材的天气×带伞场景各验一次。

---

## 层一：完整脚本

```python
import numpy as np                                   # 二维数组 = 联合分布表

def marginal(pxy, axis):                             # ① 边缘分布：沿某轴求和
    """从联合分布 pxy 压出 P(x)（axis=0）或 P(y)（axis=1）。"""
    return pxy.sum(axis=axis)

def entropy(probs, base=2):                          # ② 一维熵（复习 6.2）
    """给定一维概率分布，返回熵。"""
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def joint_entropy(pxy, base=2):                      # ③ 联合熵 H(X, Y)
    """把二维表展平成一维，套用熵公式。"""
    return entropy(pxy, base)

def conditional_entropy(pxy, base=2):                # ④ 条件熵 H(Y | X)
    """用链式法则 H(Y|X) = H(X,Y) - H(X) 计算。"""
    hxy = joint_entropy(pxy, base)                   # H(X, Y)
    hx  = entropy(marginal(pxy, axis=1), base)       # H(X)：对列求和 → P(x)
    return hxy - hx

# ---- 场景 A：独立 —— 硬币 × 骰子（6.3.1 的主线例子） ----
# 行 = 硬币{H,T}，列 = 骰子{1..6}，12 格每个 1/12
px, py = np.array([0.5, 0.5]), np.full(6, 1/6)
pxy_indep = np.outer(px, py)                         # 独立 → P(x,y) = P(x)·P(y)
print("== 场景 A：硬币 × 骰子（独立）==")
print(f"H(X)      = {entropy(px):.3f}")
print(f"H(Y)      = {entropy(py):.3f}")
print(f"H(X,Y)    = {joint_entropy(pxy_indep):.3f}   # 期望 log2(12)=3.585")
print(f"H(Y|X)    = {conditional_entropy(pxy_indep):.3f}   # 独立时 = H(Y)")
print(f"链式法则  H(X)+H(Y|X) = {entropy(px) + conditional_entropy(pxy_indep):.3f}")

# ---- 场景 B：相关 —— 天气 × 带伞（教材 6.3.2 的数据） ----
# 行 = X 天气{S晴, R雨}，列 = Y 带伞{Yes, No}
# P(X=S)=0.7, P(X=R)=0.3；晴时带伞0.2，雨时带伞0.9
pxy_dep = np.array([[0.7 * 0.2, 0.7 * 0.8],          # P(S,Yes), P(S,No)
                    [0.3 * 0.9, 0.3 * 0.1]])         # P(R,Yes), P(R,No)
print("\n== 场景 B：天气 × 带伞（相关）==")
print(f"H(X)      = {entropy(marginal(pxy_dep, axis=1)):.3f}")
print(f"H(Y)      = {entropy(marginal(pxy_dep, axis=0)):.3f}")
print(f"H(X,Y)    = {joint_entropy(pxy_dep):.3f}")
print(f"H(Y|X)    = {conditional_entropy(pxy_dep):.3f}   # 期望 0.646")
print(f"H(X)+H(Y) = {entropy(marginal(pxy_dep, axis=1)) + entropy(marginal(pxy_dep, axis=0)):.3f}   # 比 H(X,Y) 大：相关让联合更确定")
print(f"链式法则  H(X)+H(Y|X) = {entropy(marginal(pxy_dep, axis=1)) + conditional_entropy(pxy_dep):.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
== 场景 A：硬币 × 骰子（独立）==
H(X)      = 1.000
H(Y)      = 2.585
H(X,Y)    = 3.585   # 期望 log2(12)=3.585
H(Y|X)    = 2.585   # 独立时 = H(Y)
链式法则  H(X)+H(Y|X) = 3.585

== 场景 B：天气 × 带伞（相关）==
H(X)      = 0.881
H(Y)      = 0.977
H(X,Y)    = 1.527
H(Y|X)    = 0.646   # 期望 0.646
H(X)+H(Y) = 1.858   # 比 H(X,Y) 大：相关让联合更确定
链式法则  H(X)+H(Y|X) = 1.527
```

两个场景，同一条恒等式：**链式法则 $H(X,Y) = H(X) + H(Y\mid X)$ 每次都精确成立**——第一个场景独立（3.585 = 3.585），第二个场景相关（1.527 = 1.527）。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy —— 二维数组就是联合分布表

```python
import numpy as np
```

#### `import numpy as np`

**操作**：加载 NumPy 并绑定 `np`。
**输入**：无。
**输出**：`np` 句柄，本脚本用到 `np.outer`、`np.array`、`np.sum`、`np.log`、`np.log` 的向量化。
**可调参数**：无。
**对应数学**：联合分布天然是二维数组——这正是主线"配对概率表"的代码形态。一维熵在 6.2 节已实现，这里要处理的是二维表。

---

### 步骤 2：定义 `marginal` —— 从联合分布压出单变量分布

```python
def marginal(pxy, axis):
    """从联合分布 pxy 压出 P(x)（axis=0）或 P(y)（axis=1）。"""
    return pxy.sum(axis=axis)
```

#### `marginal(pxy, axis)` —— 边缘化：$P(x) = \sum_y P(x,y)$

**做什么**：对二维联合分布表沿指定轴求和，得到一维边缘分布。
**操作**：`pxy.sum(axis=axis)`。关键在 `axis` 的语义：`axis=1` 沿**列**求和（固定行 $x$，把该行所有 $P(x,y)$ 加起来）→ 得到 $P(x)$，长度 = 行数；`axis=0` 沿**行**求和（固定列 $y$，把该列所有 $P(x,y)$ 加起来）→ 得到 $P(y)$，长度 = 列数。注意：为了和教材记号对齐，脚本里 `axis=1 → P(x)`、`axis=0 → P(y)`，与我们"行是 X、列是 Y"的约定一致。
**输入**：
- `pxy`：二维数组，形状 `(n_x, n_y)`，联合分布表。每个格子 $\ge 0$，全部格子之和为 1。
- `axis`：`0` 或 `1`。`axis=1` 压出 $P(x)$（形状 `(n_x,)`）；`axis=0` 压出 $P(y)$（形状 `(n_y,)`）。
**输出**：一维数组，边缘分布。
**可调参数**：`axis` 是唯一的旋钮，它的选择决定你压出哪个变量的边缘分布。把表格转置（`pxy.T`）再传 `axis=1`，效果等价于传 `axis=0`。
**对应数学**：边缘化 $P(x) = \sum_y P(x, y)$——"不管 Y 取什么，把 X 取 $x$ 的所有路都加起来"。这是从联合分布回收单变量分布的唯一途径，也是条件熵计算里绕不开的一步。

---

### 步骤 3：定义 `entropy` —— 一维熵（复用 6.2）

```python
def entropy(probs, base=2):
    """给定一维概率分布，返回熵。"""
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))
```

#### `entropy(probs, base)` —— $H = -\sum p\log p$

**做什么**：一维分布的熵，与 6.2 节完全一致。**输入一个一维数组，返回标量熵。**
**操作**：`np.asarray` 规范化 → `probs > 0` 过滤零概率（$0\cdot\log 0 = 0$ 约定）→ `-np.sum(p·log(p)/log(base))`。
**输入**：一维概率分布 `probs`（形状 `(n,)`）；`base` 默认 2。
**输出**：标量熵。
**可调参数**：`base` 同 6.2 节。注意本函数只吃一维——如果传入二维联合表，`probs > 0` 会按元素过滤后**展平成一维**，语义就错了。联合熵专门交给下面的 `joint_entropy` 处理。
**对应数学**：主线的单变量熵，联合熵的"零件"。

---

### 步骤 4：定义 `joint_entropy` —— 把二维表展平，套用熵公式

```python
def joint_entropy(pxy, base=2):
    """把二维表展平成一维，套用熵公式。"""
    return entropy(pxy, base)
```

#### `joint_entropy(pxy, base)` —— $H(X,Y) = -\sum_x\sum_y P(x,y)\log P(x,y)$

**做什么**：联合熵。**关键技巧：把二维联合表按行拼接展平成一维，直接喂给一维 `entropy`。**
**操作**：`entropy(pxy, base)` 内部 `np.asarray(pxy)` 后 `probs[probs > 0]` 会自动把二维表展平（NumPy 布尔索引返回一维）再求和。所以二重求和 $\sum_x\sum_y$ 被展平后的单重求和代替——数学上完全等价，因为 $H(X,Y)$ 就是把**每一个配对** $(x,y)$ 的自信息按概率加权平均，顺序无关紧要。
**输入**：二维数组 `pxy`（形状 `(n_x, n_y)`），联合分布表。
**输出**：标量，联合熵。
**可调参数**：`base` 同上。能不能不用展平、显式双重循环？能，但没必要——向量化更快也更接近"整个分布一起算"的直觉。
**对应数学**：主线定义块 $H(X,Y) = -\sum_x\sum_y P(x,y)\log_b P(x,y)$。注意这里不需要先算任何边缘分布——联合熵直接消费整张配对概率表。

---

### 步骤 5：定义 `conditional_entropy` —— 用链式法则反推

```python
def conditional_entropy(pxy, base=2):
    """用链式法则 H(Y|X) = H(X,Y) - H(X) 计算。"""
    hxy = joint_entropy(pxy, base)                   # H(X, Y)
    hx  = entropy(marginal(pxy, axis=1), base)       # H(X)：对列求和 → P(x)
    return hxy - hx
```

#### `conditional_entropy(pxy, base)` —— $H(Y\mid X) = H(X,Y) - H(X)$

**做什么**：条件熵 $H(Y \mid X)$。**不直接算条件分布，而是用链式法则反推**：$H(Y\mid X) = H(X,Y) - H(X)$。
**操作**：两步。① `joint_entropy(pxy)` 得 $H(X,Y)$；② `marginal(pxy, axis=1)` 沿列求和得 $P(x)$，再 `entropy(...)` 得 $H(X)$。两者相减即得 $H(Y\mid X)$。为什么能这样算？因为主线链式法则 $H(X,Y) = H(X) + H(Y\mid X)$ 移项即得——**先用正确的事实避免直接构造条件分布表的麻烦**。
**输入**：二维数组 `pxy`；`base`。
**输出**：标量，条件熵 $H(Y \mid X)$。
**可调参数**：
- `base` 同上。
- 注意方向：这个函数算的是 $H(Y \mid X)$。想算 $H(X \mid Y)$？用链式法则另一头：$H(X\mid Y) = H(X,Y) - H(Y)$，也就是把 `marginal(pxy, axis=1)` 换成 `marginal(pxy, axis=0)`——或者把表转置 `pxy.T` 再调用本函数。两个条件熵一般不相等，这正是主线边界声明第二条。
- 能不能直接按定义算（不用链式法则）？能——先算条件分布 $P(y\mid x) = P(x,y)/P(x)$（二维表每行除以该行的边缘和），再对每一行算一个条件熵 $H(Y\mid X=x)$，最后按 $P(x)$ 加权平均。两种算法结果完全一致，链式法则版代码更短。
**对应数学**：主线定义块 $H(Y\mid X) = \sum_x P(x) H(Y\mid X=x)$ 与链式法则 $H(X,Y)=H(X)+H(Y\mid X)$。这个函数本身就是链式法则的一次现场使用。

### 步骤 6：场景 A —— 硬币 × 骰子，独立

```python
px, py = np.array([0.5, 0.5]), np.full(6, 1/6)
pxy_indep = np.outer(px, py)
```

#### `np.outer(px, py)` —— 独立联合分布 = 两个边缘分布的外积

**操作**：`np.outer(a, b)` 返回 `a[i] * b[j]` 组成的二维数组，形状 `(len(a), len(b))`。这里 `pxy_indep[i][j] = px[i]*py[j]`——正是独立时 $P(x,y) = P(x)P(y)$ 的矩阵形式。
**输入**：`px`（硬币概率，形状 `(2,)`）、`py`（骰子概率，形状 `(6,)`）。
**输出**：`pxy_indep`，形状 `(2, 6)`，12 个格子每个 $= 0.5\times\frac{1}{6} = \frac{1}{12}$。
**可调参数**：`np.outer` 只做外积，没有别的参数。想模拟**相关**的联合分布，就不能用外积——得手动填表（像场景 B 那样）。
**对应数学**：独立性 $P(x,y) = P(x)P(y)$。这是"两变量独立时联合分布长什么样"的构造方法。

#### 打印与解读

```python
print(f"H(X,Y)    = {joint_entropy(pxy_indep):.3f}   # 期望 log2(12)=3.585")
print(f"H(Y|X)    = {conditional_entropy(pxy_indep):.3f}   # 独立时 = H(Y)")
print(f"链式法则  H(X)+H(Y|X) = {entropy(px) + conditional_entropy(pxy_indep):.3f}")
```

**做什么**：独立场景的四项指标。`H(X,Y) = 3.585 = \log_2 12`；`H(Y|X) = 2.585 = H(Y)`（独立时知道 $X$ 不改变对 $Y$ 的了解）；链式法则 `1.000 + 2.585 = 3.585` 精确闭合。
**操作**：四次函数调用加两行 print。
**对应数学**：独立时 $H(X,Y) = H(X)+H(Y)$、$H(Y\mid X) = H(Y)$——这是主线 6.3.1 节手算 3.585 bits 的场景在代码里的复现，也是"独立 → 联合熵相加"的现场验证。

### 步骤 7：场景 B —— 天气 × 带伞，相关

```python
pxy_dep = np.array([[0.7 * 0.2, 0.7 * 0.8],
                    [0.3 * 0.9, 0.3 * 0.1]])
```

**做什么**：手动填写**相关**的联合分布表。行 = X 天气 {晴, 雨}，列 = Y 带伞 {Yes, No}。用教材数据：$P(S)=0.7, P(R)=0.3$；晴时带伞 $P(Y=\text{Yes}\mid S)=0.2$，雨时带伞 $P(Y=\text{Yes}\mid R)=0.9$。联合概率由 $P(x,y) = P(x)P(y\mid x)$ 算出：`[0.7*0.2, 0.7*0.8]` 是晴天行（带伞 0.14、不带 0.56），`[0.3*0.9, 0.3*0.1]` 是雨天行（带伞 0.27、不带 0.03）。
**操作**：纯手动填表——`np.array` 直接列出四个联合概率，每行每列之和都验证了边缘概率。
**输入**：四个 $P(x,y)$。
**输出**：`pxy_dep`，形状 `(2, 2)`。全表之和 $0.14+0.56+0.27+0.03 = 1.0$。
**可调参数**：改任意格子的数字就得到一个新的相关场景。比如把"雨时带伞"从 0.9 改成 1.0（下雨必带伞），$H(Y\mid X)$ 会更小——这是"关系越强、条件熵越低"的现场实验。
**对应数学**：相关联合分布 $P(x,y) = P(x)P(y\mid x)$——和独立时用外积不同，这里因为 $P(y\mid x) \ne P(y)$，联合表里藏着"关系"。

#### 打印与解读

```python
print(f"H(Y|X)    = {conditional_entropy(pxy_dep):.3f}   # 期望 0.646")
print(f"H(X)+H(Y) = {entropy(marginal(pxy_dep, axis=1)) + entropy(marginal(pxy_dep, axis=0)):.3f}   # 比 H(X,Y) 大")
print(f"链式法则  H(X)+H(Y|X) = {entropy(marginal(pxy_dep, axis=1)) + conditional_entropy(pxy_dep):.3f}")
```

**做什么**：相关场景的四项指标。`H(X,Y) = 1.527`，而 `H(X)+H(Y) = 1.858`——**联合熵比两者之和少了 0.331 bits**，这正是"相关让系统比'各自相加'更确定"的数值证据；`H(Y|X) = 0.646` 是 6.3.2 节手算的结果；链式法则 `0.881 + 0.646 = 1.527` 再次精确闭合。
**操作**：`marginal(pxy_dep, axis=1)` 得 $P(x) = (0.7, 0.3)$，`entropy` 得 $H(X)=0.881$；`axis=0` 得 $P(y) = (0.41, 0.59)$，$H(Y)=0.977$（天气与带伞两个变量的信息含量并不相同——这正是"条件熵不对称"的根源）。
**对应数学**：链式法则 $H(X,Y) = H(X)+H(Y\mid X)$ 在**相关**场景下依然成立——这正是主线反复强调的"链式法则不分独立还是相关，总是成立"。而 $H(X,Y) < H(X)+H(Y)$ 是相关性的指纹，将在 6.5 节变成互信息：$I(X;Y) = H(X)+H(Y)-H(X,Y) = 1.762 - 1.527 = 0.235$ bits。

## 改个数字试试：把"关系"拧紧

### 实验 1：从独立到完全依赖，条件熵一路滑到 0

```python
for p_umbrella_rain in [0.5, 0.7, 0.9, 1.0]:
    tab = np.array([[0.7*0.2, 0.7*0.8], [0.3*p_umbrella_rain, 0.3*(1-p_umbrella_rain)]])
    print(f"雨时带伞={p_umbrella_rain}  ->  H(Y|X) = {conditional_entropy(tab):.3f}   I(X;Y) = {entropy(marginal(tab,axis=1))+entropy(marginal(tab,axis=0))-joint_entropy(tab):.3f}")
```

输出：

```text
雨时带伞=0.5  ->  H(Y|X) = 0.805   I(X;Y) = 0.063
雨时带伞=0.7  ->  H(Y|X) = 0.770   I(X;Y) = 0.164
雨时带伞=0.9  ->  H(Y|X) = 0.646   I(X;Y) = 0.330
雨时带伞=1.0  ->  H(Y|X) = 0.505   I(X;Y) = 0.484
```

随着"雨天带伞"的概率从 0.5 升到 1.0，天气对带伞的"约束力"越来越强：条件熵 $H(Y\mid X)$ 从 0.805 滑到 0.505，而互信息 $I(X;Y)$（还没正式登场，先用 $H(X)+H(Y)-H(X,Y)$ 预演）从 0.063 涨到 0.484。**关系越铁，剩余不确定越少，共享信息越多。** 这条单调性就是整章后半段的地基。

### 实验 2：完全独立时，条件熵恰好等于边缘熵

```python
pxy = np.outer([0.7, 0.3], [0.2, 0.8])
print(f"H(Y|X) = {conditional_entropy(pxy):.3f}   H(Y) = {entropy(marginal(pxy, axis=0)):.3f}")
```

输出：

```text
H(Y|X) = 0.722   H(Y) = 0.722
```

把场景 B 的两行概率**改成完全独立**（外积构造，`P(y\mid x)=P(y)` 处处成立），条件熵 0.722 与边缘熵 0.722 完全相等——知道天气对带伞毫无帮助。独立是"条件熵 = 边缘熵"的极限情形；相关度越高，两者差得越远，那个差正是"信息"。

## 边界声明：这套代码能做什么，不能做什么

1. **`conditional_entropy` 算的是 $H(Y\mid X)$，方向不能搞反。** 它用链式法则 $H(Y\mid X)=H(X,Y)-H(X)$ 计算，其中 `axis=1` 压出 $P(x)$。想算 $H(X\mid Y)$ 必须换轴（`axis=0` 压出 $P(y)$）。两值一般不等——主线边界声明第二条，在这个函数里就是"轴选错，全盘皆错"。
2. **二维表的归一化假设。** `joint_entropy` 和 `conditional_entropy` 都默认 `pxy` 的格子之和为 1（合法联合分布），函数不校验。若传非归一化表（和不是 1），算出的熵没有意义。这和 6.2 节 `entropy` 的边界一致。
3. **联合熵不是"关系的度量"。** 脚本里场景 B 的 `H(X,Y)=1.527` 只说明"系统总不确定 1.527 bits"，它**不**告诉你天气和带伞有多相关。相关度要靠 `H(X)+H(Y)-H(X,Y)`（互信息）来量——两个独立但取值很多的变量，联合熵照样很大，可它们毫无关系。判断关系强弱，等 6.5 节的 `mutual_information` 登场。
