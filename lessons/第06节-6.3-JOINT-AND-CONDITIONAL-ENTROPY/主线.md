## 第一步：Toy Model —— 两个人各出一张牌

一场小赌局。规则：A 在"红、黑"两张牌里抽一张；B 在"1、2、3"三张牌里抽一张。两人各自把牌背对着你——你只知道他们各自会抽，却不知道结果。

先单看 A。他抽"红"还是"黑"，五五开，你拿不准——A 的熵是 1 bit。

再单看 B。他抽 1、2、3，三选一，你也拿不准——B 的熵约 1.585 bits。

现在问一个"浅到可笑"的问题：**把 A 和 B 当做一个整体——"这一对牌"——你心里总共有多少不确定？**

你本能地想：那就加起来呗，1 + 1.585 = 2.585 bits。可再一想，你犹豫了：这个"加起来"成立的前提，是 A 和 B **互不相干**。可如果这场赌局的规则改一下——**B 的抽牌和 A 的抽牌有关系**（比如：A 抽到红，B 有八成概率抽 1）——那么"这对牌"的不确定，还能简单相加吗？

你闭上眼试想那个相关的规则：知道 A 抽了红，你对 B 的猜就已经不是三选一的"完全拿不准"了，而是"八成是 1"——你心里对 B 的不确定**变小了**。整个系统的不确定，因此也变小了。**两个变量如果相关，它们的"联合不确定"一定小于各自不确定的简单相加**——因为一个变量的信息，泄漏了另一个变量的底。

现在你的面前有两把尺子：一把量"整个系统的总不确定"——这叫**联合熵**；一把量"知道了一个，另一个还剩多少不确定"——这叫**条件熵**。这两把尺子，是本章从"单个变量"迈向"变量之间的关系"的第一步，也是通往互信息的必经之路。直觉已经看到了它们的形状，接下来把形状精确成数学。

## 第二步：正式数学讲解

### 一、撞墙：单变量的记账本，装不下两个变量

上一节我们学会了给一个变量写"不确定性账本"：$H(X) = -\sum_x P(x)\log P(x)$。现在系统里有两个变量 $X, Y$，我们要问两个新问题：

**问题一：整个系统的总不确定是多少？**
**问题二：知道 $X$ 之后，$Y$ 还剩多少不确定？**

先试问题一。你打算沿用单变量的办法：把 $(X, Y)$ 当一个"超变量"，它的取值是所有的**配对** $(x, y)$。A 和 B 各出一张牌，配对就有 $2 \times 3 = 6$ 种：$(红,1), (红,2), (红,3), (黑,1), (黑,2), (黑,3)$。每一种配对有一个概率 $P(x, y)$——注意，这不是 $P(x)$ 和 $P(y)$ 的简单相乘，除非 A 和 B 独立。这一大张"配对的概率表"，就是**联合分布 (joint distribution)** $P(X, Y)$。

有了联合分布，把单变量的熵公式原样搬过来：对每一个配对 $(x, y)$ 取 $-\log P(x, y)$，再按概率加权平均——只是把单个求和换成**对所有配对的二重求和**：

$$H(X, Y) = -\sum_{x \in \mathcal{X}}\sum_{y \in \mathcal{Y}} P(x, y)\log P(x, y)$$

这就是**联合熵 (joint entropy)**。它的画面就是上面那张配对概率表：表里每格一个概率，把每格的自信息按概率加权平均，得到"整个系统平均每对取值的不确定"。

现在撞墙的地方来了。直觉说"相关的系统，联合熵小于各自熵的和"——**为什么？** 因为 $-\log P(x, y) = -\log\big(P(x)\cdot P(y \mid x)\big) = -\log P(x) - \log P(y\mid x)$：一个配对的自信息，拆成"$X$ 取这个值的惊讶"加上"知道 $X$ 之后 $Y$ 取这个值的惊讶"。如果 $X$ 和 $Y$ 独立，$P(y\mid x) = P(y)$，第二项就退化成单变量的惊讶，加权平均后联合熵恰好等于 $H(X)+H(Y)$；可如果 $Y$ 依赖 $X$，第二项的"惊讶"会被 $X$ 的已知信息**削弱**，联合熵就掉到和以下。

于是问题二浮出水面：**"知道 $X$ 之后 $Y$ 还剩多少不确定"** ——它正是上面拆出来的那个第二项的平均：

> **联合熵 (joint entropy)** $H(X, Y)$
>
> 物理含义：随机变量对 $(X, Y)$ 作为一个整体，平均每产生一对取值所携带的惊讶——整个系统的不确定总量。
>
> $$H(X, Y) = -\sum_{x \in \mathcal{X}}\sum_{y \in \mathcal{Y}} P(x, y)\log_b P(x, y)$$
>
> - $P(x, y)$：$X = x$ 且 $Y = y$ 的联合概率，$\sum_x \sum_y P(x,y) = 1$
> - 二重求和遍历所有配对 $(x, y)$
> - 性质：$H(X,Y) \ge H(X)$ 且 $H(X,Y) \ge H(Y)$（联合永远不会比单个更确定）；$H(X,Y) \le H(X) + H(Y)$（等号当且仅当 $X, Y$ 独立）

> **条件熵 (conditional entropy)** $H(Y \mid X)$
>
> 物理含义：已知 $X$ 的取值之后，$Y$ 平均还剩多少不确定。
>
> $$H(Y \mid X) = \sum_{x \in \mathcal{X}} P(x)\, H(Y \mid X = x)$$
>
> 等价形式（用联合分布与条件概率）：
>
> $$H(Y \mid X) = -\sum_{x \in \mathcal{X}}\sum_{y \in \mathcal{Y}} P(x, y)\log_b P(y \mid x)$$
>
> - $H(Y \mid X = x)$：固定 $X=x$ 后，$Y$ 在条件分布 $P(y\mid x)$ 下的熵
> - 性质：$0 \le H(Y \mid X) \le H(Y)$（已知只会让不确定减少或不变，不会增加）
> - 注意：$H(Y \mid X) \ne H(X \mid Y)$，两个条件熵一般不相等

### 二、链式法则：联合熵、两个条件熵、一条恒等式

把刚才拆开的那步写整齐，就得到信息论最重要的一条恒等式：

$$H(X, Y) = H(X) + H(Y \mid X)$$

读法：**整个系统的总不确定 = $X$ 自己的不确定 + 知道 $X$ 之后 $Y$ 还剩的不确定。** 对称地也成立：$H(X, Y) = H(Y) + H(X \mid Y)$。这两条合起来叫**链式法则 (chain rule)**——它把"两变量的联合熵"拆成"单变量的熵加条件熵"两步走。你可以把它想成下棋记账：先记第一个棋子的不确定，再记"看到第一个棋子后，第二个还剩多少不确定"，两笔账加起来就是整盘棋的总不确定。

链式法则给了联合熵和条件熵一张**地图**。把 $H(X)$、$H(Y)$、$H(X,Y)$ 画成面积：$H(X)$ 是一块区域，$H(Y)$ 是另一块区域，两者**交叠的部分**正是 $X$ 和 $Y$ 共享的信息（下一节 6.5 的互信息 $I(X;Y)$），而联合熵 $H(X,Y)$ 是**两块区域并起来的总面积**。这张文氏图（信息图）是整章反复使用的地图：

- $H(X, Y) = H(X) + H(Y \mid X)$：总面积 = 一块 + 另一块扣掉交叠后的部分
- $H(Y \mid X) = H(Y) - I(X; Y)$：知道 $X$ 后 $Y$ 的不确定 = $Y$ 自己的不确定 - 共享的信息

如果 $X, Y$ 独立，两块区域不交叠：$I=0$，$H(X,Y) = H(X)+H(Y)$，$H(Y\mid X) = H(Y)$。

### 三、边界声明：这两把尺子的三条底线

**第一，联合熵和条件熵，都不是互信息。** 联合熵量的是"系统总不确定"（总面积），条件熵量的是"知道一个后剩下的不确定"（扣掉交叠后的部分），而"两个变量**共享**的信息"是它们之间的差：$I(X;Y) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X)$。别把"联合熵"当成"两个变量的关系度量"——联合熵本身不告诉你 X、Y 有多相关，它只告诉你整个系统多不确定。关系的强弱，要等 6.5 节的互信息来回答。

**第二，$H(Y \mid X) \ne H(X \mid Y)$。** 条件熵没有对称性。"知道天气后，带伞还剩多少不确定"几乎总是不同于"知道带伞后，天气还剩多少不确定"。常见错误是把两者混为一谈。方向错了，数值就错了——这正是 6.3.2 节要亲手算清楚的地方。

**第三，条件熵不会让不确定"变负"。** $0 \le H(Y \mid X)$ 永远成立——知道 $X$ 最多把 $Y$ 的不确定消到零（$X$ 完全决定 $Y$），绝不可能"过度消除"出负数。若你在某处算出 $H(Y\mid X) < 0$，那一定是公式用错或分布算错，不可能是信息论本身的结论。

## 第三步：DL 桥接

这一节没有直接进入某个模型的公式，但"联合分布 + 条件分布"是深度学习表示世界的两套语法，先把位置标出来：

**联合分布 → 生成模型。** 变分自编码器 (VAE) 建模的是隐变量 $z$ 与数据 $x$ 的**联合分布** $p(x, z)$，它的证据下界 (ELBO) 里写着联合熵与条件熵的家族成员：$\log p(x) \ge \mathbb{E}_{q(z\mid x)}[\log p(x \mid z)] - \mathrm{D}_{\mathrm{KL}}(q(z\mid x)\|p(z))$。右边第一项是"条件概率的对数"，第二项是两个分布间的距离（KL 散度，6.2 节预告过）。联合熵 $H(X,Z)$ 与条件熵 $H(X \mid Z)$ 是这个框架的信息论底色。

**条件分布 → 自回归模型。** 语言模型（如 Transformer）每一步在算的就是条件熵的极小化：给定前面所有 token，预测下一个 token 的分布 $q(\text{token}_t \mid \text{token}_{<t})$。整个句子的"总不确定"按链式法则拆成一串条件熵：

$$H(\text{sentence}) = H(t_1) + H(t_2 \mid t_1) + H(t_3 \mid t_1, t_2) + \cdots$$

你训练语言模型时看到的每一行损失，都是在压低这些条件熵。链式法则不是练习题，它是语言模型把"一句话"拆成"一步步预测"的数学依据。
