# 历史：当一条消息不再孤单——联合熵与条件熵的诞生

## 1948 年，一篇论文里的"下一行"

香农把《通信的数学理论》写完初稿后，回头读自己的手稿。第 2 节定义完熵，他已经掌握了"一个信源平均每次发出多少信息"。可翻到下一页，他停住了。

通信从来不是一个人的事。

电话线的那头有人说话，这头有人听。发报机发出摩尔斯码，收报机收到的却是混着噪声的电流。**发的人是一个信源，收的人是另一个"变量"**——而通信的全部意义，恰恰在这两个变量之间的纠缠里：收到的信号，能在多大程度上告诉你发出的是什么？如果噪声太大，收到 1 的你根本分不清对方发的是 1 还是 0——两个变量近乎独立，通信近乎失败；如果线路干净，收到什么几乎就决定了发出什么——两个变量强烈相关，通信近乎完美。

香农需要回答的正是这个问题：**两个变量放到一起，不确定性会怎么变？** 一个变量的信息，能减少对另一个变量的不确定吗？这已经不是单变量熵能回答的了——他必须让熵"长出第二个变量"。

于是他在论文里，几乎是顺着自然的节奏，写下了下一行。

## 从"一个信源的账本"到"两个变量的关系"

单变量的熵，香农是这样想的：信源 $X$ 有若干可能结果，每个结果概率 $P(x)$，对整个分布求"平均惊讶"。现在有两个信源 $X$ 和 $Y$——发报机里待发的消息 $X$，收报机里收到的信号 $Y$。它们一起构成一个"联合系统"：$(X, Y)$ 的每一种配对 $(x, y)$ 有一个联合概率 $P(x, y)$。

香农做了一件很自然的事：**把单变量的熵公式原样搬到配对上去。** 对每一个配对 $(x, y)$，算它携带的惊讶 $-\log P(x, y)$，再按联合概率加权平均：

$$H(X, Y) = -\sum_{x,y} P(x, y)\log P(x, y)$$

他叫它**联合熵**——整个系统的总不确定。然后他问第二个问题：如果我已经知道了 $X$（收到的信号），$Y$（待发的消息）还剩多少不确定？他把"给定 $x$ 后的条件熵 $H(Y \mid X = x)$"按 $P(x)$ 加权平均：

$$H(Y \mid X) = \sum_x P(x)\, H(Y \mid X = x)$$

**条件熵**——知道一个之后，另一个剩下的不确定。

香农在这两个定义之间，写下了一条今天被称为"链式法则"的恒等式：

$$H(X, Y) = H(X) + H(Y \mid X)$$

这句话的朴素程度，让后来的人几乎忘了它曾是里程碑：**整个系统的总不确定 = 第一个变量自己的不确定 + 知道第一个后第二个还剩的不确定。** 它把"两个变量的世界"还原成"一步步的世界"——先看第一个，再看"知道第一个之后的第二个"。这条法则将贯穿整个信息论：互信息、信道容量、以及半个多世纪后深度学习里的自回归语言模型，全都建立在它的结构上。

## 一张交叠的圆圈：信息图

香农可能没有画过我们今天常见的那张文氏图——把 $H(X)$ 和 $H(Y)$ 画成两个交叠的圆圈，中间的重叠区标着"共享的信息"。但信息论的后来者们（尤其是 Raymond Yeung 及其"信息图"系统研究）把它画了出来，从此这张图成了每个学信息论的人脑中第一幅画面：

两个圆圈，一个写着 $H(X)$，一个写着 $H(Y)$。它们交叠的部分，是 $X$ 和 $Y$ **共享**的信息；左圈独属的部分，是"只有 $X$ 自己知道"的；右圈独属的部分，是"只有 $Y$ 自己知道"的；两圈并起来的总面积，是联合熵 $H(X,Y)$。交叠区越大，两个变量越"纠缠"。

这张图第一次让"关系"有了几何。工程师们看着它，忽然明白了一件事：**噪声通道里的通信，本质上是一场"让两个圆圈尽量重叠"的工程**——你设计编码、加强信号，最终目的都是让收到的信号圈与发出的消息圈尽可能重合。两个变量的纠缠度，从此可以测量、可以优化。

## 从电报到神经网络：同一句恒等式

香农大概不会想到，七十年后，他这条"把两个变量拆成一步一步"的链式法则，会住进一类叫 Transformer 的神经网络里。

语言模型的训练目标，是把一句话拆成一连串条件概率：先预测第一个词，再给定第一个词预测第二个，再给定前两个词预测第三个……而这一切的数学依据，正是香农当年的链式法则 $H(X, Y) = H(X) + H(Y \mid X)$ 的 n 变量推广。**预测即条件化**——今天每一个 token 生成式模型的推理，都是这句话在硅片上的复读。

而当研究者想理解"神经网络学到了什么"，他们又回到了那两张交叠的圆圈：输入数据圈和模型表示圈之间的重叠区，成了"深度学习到底学走了多少信息"的标尺——这将在 6.5 节互信息那里再次登场。

## 留一扇门

香农把熵从"一个信源"推向"两个变量"，留下了两把尺子：联合熵量整个系统的总不确定，条件熵量"知道一个后另一个还剩多少"。而那张交叠圆圈里，最耐人寻味的不是两个圈，是它们**交叠的那一小块**——两个变量共享的信息。那块区域，还没有名字。

下一节，我们把联合熵算到具体的数字里：一枚硬币和一颗骰子凑成一对时，12 种配对，总共装着多少不确定？再下一节，条件熵会告诉我们：看了天气预报，带伞这件事还剩多少不确定？
