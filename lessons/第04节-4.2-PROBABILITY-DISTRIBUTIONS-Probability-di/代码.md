# §4.2 概率分布 · 代码

主线里，我们认识了那面墙——分布就是墙上的楦：一整套预先塑好形状的模型，每一个为特定种类的数据量身定做。这节代码，就把"楦"和"脚"请进 Python：从骰子（一个均匀离散分布）里采样，反推经验的形状，把经验 PMF 和理论 PMF 画在同一张图上，最后用**大数定律**确认——样本越多，反推出来的形状越贴近那只预先塑好的楦。

§4.1 的代码用的是纯 Python 手工循环；这一节换一个更"向量化"的武器：**numpy**。整条形状不再是一个一个点地处理，而是一整个数组一次算完。

需要的环境：Python 3.8+、`numpy` 与 `matplotlib`（`pip install numpy matplotlib`）。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方（`SEED = 42` 固定，你的结果与这里**逐位一致**）。

```python
"""
§4.2 概率分布 · 代码.md
把"分布的形状"请进 numpy：
1) 从均匀离散分布（骰子）采样   —— 得到样本（脚）
2) 统计经验概率 PMF             —— 从脚反推形状
3) 绘制 PMF 柱状图              —— 把形状画出来
4) 验证大数定律                 —— 样本越多，经验形状越贴理论形状

运行：python 代码.py   （绘图依赖 matplotlib）
"""

import numpy as np                  # 向量化数值计算库
import matplotlib.pyplot as plt

N_FACES = 6                          # 骰子面数：支撑 {1,2,3,4,5,6}
N_SAMPLES = 1000                     # 采样量 N
SEED = 42                            # 随机种子：让"随机"实验可复现


def theoretical_pmf(n_faces=N_FACES):
    """理论 PMF：公平骰子的均匀离散分布 p(k) = 1/n。"""
    return np.full(n_faces, 1.0 / n_faces)


def sample_dice(n, n_faces=N_FACES, seed=SEED):
    """从均匀离散分布独立采样 n 次，返回形状 (n,) 的面值数组。"""
    rng = np.random.default_rng(seed)     # 现代 numpy 的随机数发生器
    return rng.integers(1, n_faces + 1, size=n)   # 左闭右开 [1, n_faces+1)


def empirical_pmf(samples, n_faces=N_FACES):
    """把样本数成每张面的经验概率 Phat(k) = N_k / N。"""
    counts = np.bincount(samples - 1, minlength=n_faces)   # 面 k -> 槽 k-1
    return counts / samples.size


def plot_pmf(empirical, theoretical, title):
    """画 PMF 柱状图：经验概率（柱子）上叠理论概率（红点）。"""
    x = np.arange(1, len(empirical) + 1)
    plt.bar(x, empirical, width=0.55, color="steelblue", alpha=0.85,
            label="经验 PMF Phat(k)")
    plt.plot(x, theoretical, "ro-", label="理论 PMF p(k) = 1/6")
    plt.xlabel("骰子面数 k")
    plt.ylabel("概率")
    plt.xticks(x)
    plt.ylim(0, 0.45)
    plt.legend()
    plt.grid(axis="y", linestyle="--", alpha=0.3)
    plt.title(title)
    plt.show()


def tv_distance(a, b):
    """总变差距离：衡量两个分布形状差异的规范度量。"""
    return 0.5 * np.sum(np.abs(a - b))


# ---------------- 主流程 ----------------
th = theoretical_pmf()                          # 1. 理论分布（模型 / 楦）
samples = sample_dice(N_SAMPLES)                # 2. 采样（数据 / 脚）
emp = empirical_pmf(samples)                    # 3. 经验 PMF（反推的形状）

print("前 24 次掷骰:", samples[:24])
print("经验 PMF Phat(k) =", np.round(emp, 4))
print("理论 PMF p(k)    =", np.round(th, 4))
plot_pmf(emp, th, "经验 PMF vs 理论 PMF（N = %d 次掷骰）" % N_SAMPLES)

# 大数定律：样本越多，经验形状越贴理论形状（整条曲线一起收敛）
print("\n大数定律：经验 PMF 与理论 PMF 的距离随样本量收敛")
print("  最大偏差 = max_k |Phat(k) - p(k)|，TV 距离 = (1/2) * sum_k |Phat(k) - p(k)|")
for n in (10, 100, 1000, 10000, 100000):
    emp_n = empirical_pmf(sample_dice(n))
    dev = np.max(np.abs(emp_n - th))
    tv = tv_distance(emp_n, th)
    print("  N = %6d  -> 最大偏差 = %.4f   TV 距离 = %.4f   Phat(6) = %.4f"
          % (n, dev, tv, emp_n[5]))
```

## 层二：分步逐函数拆解

### 步骤 1：设置实验参数与随机源

```python
import numpy as np                  # 向量化数值计算库
import matplotlib.pyplot as plt

N_FACES = 6                          # 骰子面数：支撑 {1,2,3,4,5,6}
N_SAMPLES = 1000                     # 采样量 N
SEED = 42                            # 随机种子：让"随机"实验可复现
```

这一块没有函数，它是**实验的参数表**——对应主线里"支撑"与"旋钮"的具身。

`import numpy as np` 引入 numpy：整个脚本的所有计算都发生在数组层面，一个操作作用于一整条数组，不再逐点循环。`import matplotlib.pyplot as plt` 引入绘图工具。

三个模块级常量：

- `N_FACES = 6` —— 骰子面数。这正是主线里的**支撑**（support）$\{1, 2, 3, 4, 5, 6\}$。改成 8，整台机器变成八面骰；改成 2，就是抛硬币。**注意**：它被 `theoretical_pmf`、`sample_dice`、`empirical_pmf` 三个函数共同读取——改一个常量，全链路跟着变，这就是"支撑决定分布的形状"。
- `N_SAMPLES = 1000` —— 采样量 $N$。主线里"量多少只脚"的脚数。改成 10 会看到经验形状乱跳，改成 100000 会看到形状几乎趴在理论上——这正是步骤 7 大数定律要演示的。
- `SEED = 42` —— 随机种子。numpy 的随机不是真随机：它是确定性递归，种子决定这条递归从哪个状态起步。固定种子 = 每次运行得到**逐位相同**的结果。改种子（如 `SEED = 7`），骰子序列换一套，但统计形状不变。

**可调参数**：三个常量都是"实验的旋钮"——`N_FACES` 换骰子种类，`N_SAMPLES` 换样本量，`SEED` 换随机流的起点。还能不能有第四个？当然可以——比如加一个 `LABELS` 常量把面值换成文字，或者加一个 `SAVE_PATH` 让图存成文件。但这里为了透明，只留三个。

### 步骤 2：理论分布 —— `theoretical_pmf(n_faces)`

```python
def theoretical_pmf(n_faces=N_FACES):
    """理论 PMF：公平骰子的均匀离散分布 p(k) = 1/n。"""
    return np.full(n_faces, 1.0 / n_faces)
```

#### `theoretical_pmf(n_faces)` —— 雕好那只楦

**操作**：`np.full(n_faces, 1.0 / n_faces)` 创建一个长度为 `n_faces` 的数组，每一个元素都填同一个值 `1.0 / n_faces`。对 `n_faces=6`，就是 `[1/6, 1/6, 1/6, 1/6, 1/6, 1/6]`。注意 `1.0` 是浮点数——保证 `1.0 / 6 = 0.1666...` 而不是整数除法的 0。

**对应数学**：这就是主线里概率质量函数 (PMF) 的第一个实例——**均匀离散分布 (uniform discrete distribution)**：

$$p(k) = \frac{1}{n}, \quad k \in \{1, 2, \dots, n\}$$

它满足 PMF 的两条纪律：$p(k) \ge 0$ 且 $\sum_{k=1}^{n} p(k) = 1$。它从何而来？不是靠掷骰测出来的，而是从"公平"这个**对称性假设**推出的：六个面没有任何一个该被偏爱，于是每面分到同样的 $1/6$。这就是理论值 vs 经验值的分野——**理论值来自假设与推导，经验值来自观察与计数**。

**输入**：`n_faces` —— 整数（可省略，默认 6），面数。

**输出**：numpy 数组，**形状 `(n_faces,)`**，每个元素都是 `1.0 / n_faces`，六个元素之和为 1。

**可调参数**：
- `n_faces`：传 8 得到 $p(k) = 1/8$；传 2 得到抛硬币分布 $p = 1/2$。
- 还能不能有第二个参数？可以加一个 `weights` 数组（如 `[1, 1, 1, 1, 1, 2]`），归一化后返回——这就把公平楦扩展成**任意离散分布**，即主线"每种分布都量身定做于特定数据"的极简预览。但公平骰子用不到。

### 步骤 3：采样 —— `sample_dice(n, n_faces, seed)`

```python
def sample_dice(n, n_faces=N_FACES, seed=SEED):
    """从均匀离散分布独立采样 n 次，返回形状 (n,) 的面值数组。"""
    rng = np.random.default_rng(seed)     # 现代 numpy 的随机数发生器
    return rng.integers(1, n_faces + 1, size=n)   # 左闭右开 [1, n_faces+1)
```

#### `sample_dice(n, n_faces, seed)` —— 从楦里倒出 n 只脚

**操作**：
1. `rng = np.random.default_rng(seed)` —— 用种子初始化一个**随机数发生器 (Generator)**。现代 numpy 推荐用它替代旧版 `np.random.randint` 这类全局接口。它底层跑的是 PCG64 算法，比 Mersenne Twister 更快、统计性质更好。
2. `rng.integers(1, n_faces + 1, size=n)` —— 从 $[1, n_faces)$ **左闭右开**区间里抽取整数。写成 `[1, n_faces + 1)` 是为了让高边界把 6 包含进来：合法的输出是 $1, 2, 3, 4, 5, 6$ 各等概率。

**对应数学**：这一步是主线"楦对脚的预言"的逆过程——**让模型生成数据**。随机变量 $X \sim \text{Uniform}\{1,\dots,6\}$ 的一次实现 (realization)，就是这里返回数组里的一个元素。`size=n` 表示做 $n$ 次**独立同分布 (i.i.d.)** 采样：上一次掷出 6 不影响这一次。这 $n$ 个实现合起来，就是主线里"量到的 n 只脚"——**一个样本 (sample)**。

**输入**：
- `n`：整数，采样次数（样本量 $N$）。
- `n_faces`：整数（可省略，默认 6），面数。
- `seed`：整数（可省略，默认 42），随机种子。

**输出**：numpy 整数数组，**形状 `(n,)`**——一维，长度 $N$，第 $i$ 个元素是第 $i$ 次掷骰的面值。

**可调参数**：
- `n`：任意非负整数。给 0 返回空数组；给 10 得到 10 个结果，经验形状会与 $1/6$ 偏差很大；给 100000 会非常贴近。
- `n_faces`：改成 8，输出范围变为 $\{1,\dots,8\}$，每面概率 $1/8$。
- `seed`：保持默认 42 → 可复现；改成任意整数 → 换一套序列；传 `None` → 用系统熵自动播种，每次运行结果都不同，没法复现。
- 还能不能有第四个参数？可以加 `dtype` 指定输出整数类型（默认是平台相关的 `int64`），内存敏感时有用。
- **陷阱**：如果手滑把 `rng.integers(1, n_faces + 1)` 写成 `rng.integers(0, n_faces)`，输出范围变成 $\{0,1,\dots,5\}$——面 6 变成面 0，整个支撑平移了一格。更隐蔽的错误是把高边界写成 `n_faces` 又想包含 6，结果面 6 永远不会出现——**左闭右开是 numpy 统一的纪律，高边界必须 +1**。

### 步骤 4：经验 PMF —— `empirical_pmf(samples, n_faces)`

```python
def empirical_pmf(samples, n_faces=N_FACES):
    """把样本数成每张面的经验概率 Phat(k) = N_k / N。"""
    counts = np.bincount(samples - 1, minlength=n_faces)   # 面 k -> 槽 k-1
    return counts / samples.size
```

#### `empirical_pmf(samples, n_faces)` —— 从脚反推形状

**操作**：
1. `samples - 1` —— 把面值数组整体平移一格：面 $k$ 变成 $k-1$。为什么？因为 numpy 数组的下标从 0 开始，面 1 要落进下标 0 的槽。
2. `np.bincount(samples - 1, minlength=n_faces)` —— 统计每个整数出现的次数。`np.bincount` 是 numpy 的**向量化直方图**：给定一个非负整数数组，它数出 0 出现了几次、1 出现了几次……返回一个长度等于"最大值+1"的计数数组。`minlength=n_faces` 强制输出至少有 6 个槽——否则如果这一批样本恰好没掷出某个面，输出就会比 6 短。
3. `counts / samples.size` —— 每个计数除以总样本数 $N$，归一化成频率。`samples.size` 是数组的元素个数，即 $N$。

**对应数学**：这就是主线里"可能性的频率解释"的代码形式——**经验概率 (empirical probability)**：

$$\hat{p}(k) = \frac{N_k}{N}, \qquad N_k = \text{面 } k \text{ 在样本中出现的次数}$$

$\hat{p}(k)$（读作 p-hat）是**从有限样本里"看到"的概率**——对应主线边界声明里那句"楦不是脚"：$\hat{p}(k)$ 是随机量（换一批样本就变），而 $p(k) = 1/6$ 是确定的理论值。因为每个样本恰好属于一个面，所以 $\sum_k \hat{p}(k) = 1$ 恒成立——归一化纪律的现场版。

**输入**：
- `samples`：numpy 整数数组，**形状 `(N,)`**——步骤 3 的输出。每个元素是 $\{1,\dots,6\}$ 中的一个面值。
- `n_faces`：整数（可省略，默认 6），面数。

**输出**：numpy 浮点数组，**形状 `(n_faces,)`**。第 $k-1$ 个元素是面 $k$ 的经验概率，每个值在 $[0,1]$ 内，六个值之和恒为 1。

**可调参数**：
- `n_faces`：若你在步骤 3 把骰子换成了 8 面，这里也必须传 `n_faces=8`，否则计数槽还是 6 格，面 7、面 8 的下标（6、7）超过槽数而被**静默丢弃**——不报错，但形状缺了两格。参数不一致是这类代码最常见的 bug 来源。
- 还能不能有第三个参数？可以加一个 `normalize=True` 开关：传 `False` 就只返回原始计数 `counts` 而不除以 $N$。当你想同时看"次数"和"频率"时有用。
- **对比**：§4.1 的代码用手工循环 `for face in rolls` 逐格累加；这里 `np.bincount` 一次调用完成同样的事。结果相同，但后者是**向量化**的——对百万级样本，速度差几个数量级。这正是 numpy 的核心哲学：把"对一个点做的事"写成"对整条数组做的事"。

### 步骤 5：绘图 —— `plot_pmf(empirical, theoretical, title)`

```python
def plot_pmf(empirical, theoretical, title):

    plt.ylabel("概率")
```

#### `plot_pmf(empirical, theoretical, title)` —— 把楦和脚画在同一面墙上

**操作**：
1. `x = np.arange(1, len(empirical) + 1)` —— 横轴坐标：面 1 到面 6。
2. `plt.bar(...)` —— 画经验 PMF 的**柱状图**：柱高就是 $\hat{p}(k)$，这是离散分布的标准画法。
3. `plt.plot(x, theoretical, "ro-")` —— 在同样位置叠一条理论 PMF 的**红色折线**（"ro-" 表示红色圆点加连线）。$\hat{p}(k)$ 是柱子，$p(k)$ 是折线，一目了然。
4. `plt.ylim(0, 0.45)` —— 把纵轴定在 $[0, 0.45]$，让 $1/6 \approx 0.167$ 恰好在中部偏下，柱顶高低尽收眼底。
5. 其余是图例、网格、标题等排版。

**对应数学**：这幅图就是主线 Toy Model 的复刻——**经验形状 vs 理论楦**。柱顶距红色折线越近，说明经验频率越贴近理论概率，即"从脚反推的形状"越贴"预先塑好的楦"。当 `N_SAMPLES` 变大，柱子会越来越整齐地趴在红线上。

**输入**：
- `empirical`：numpy 数组，**形状 `(n_faces,)`**——步骤 4 的输出。
- `theoretical`：numpy 数组，**形状 `(n_faces,)`**——步骤 2 的输出。
- `title`：字符串，图标题。

**输出**：无返回值（返回 `None`）。把图渲染到窗口（Jupyter 中则内嵌），`plt.show()` 展示。

**可调参数**：
- `empirical` / `theoretical`：两个数组必须等长（都是 `(6,)`），否则柱子和折线对不上横轴。
- 函数体内还有一批**样式旋钮**：`width`（柱宽，默认 0.55）、`color`（柱色）、`alpha`（透明度）、`ylim`（纵轴范围）。想从外部控制，把它们升级成函数参数即可。
- 还能不能有第四个参数？可以加 `save_path`：传入路径（如 `"pmf.png"`）后用 `plt.savefig(save_path)` 把图存成文件而不是弹窗口——无图形环境里非常有用。

### 步骤 6：距离 —— `tv_distance(a, b)`

```python
def tv_distance(a, b):
    """总变差距离：衡量两个分布形状差异的规范度量。"""
    return 0.5 * np.sum(np.abs(a - b))
```

#### `tv_distance(a, b)` —— 给"楦与脚差多少"一把尺子

**操作**：
1. `np.abs(a - b)` —— 逐点求差的绝对值：$|\hat{p}(k) - p(k)|$，得到形状 `(6,)` 的数组。
2. `np.sum(...)` —— 把六个点的绝对差加总。
3. `0.5 * ...` —— 乘 $\tfrac12$ 归一化。

**对应数学**：这就是概率论里衡量"两个分布相差多少"的**总变差距离 (total variation distance)**：

$$d_{\mathrm{TV}}(p, \hat{p}) = \frac{1}{2} \sum_{k} \big|\, p(k) - \hat{p}(k) \,\big|$$

系数 $\tfrac12$ 让距离永远落在 $[0, 1]$：两个分布完全相同 → 距离 0；支撑互不相交 → 距离 1。它比"看某一个面"更诚实——它衡量的是**整条形状的差异**。主线里"楦对脚贴不贴"，用的正是这把尺子。

**输入**：`a`、`b` —— 两个 numpy 数组，**形状相同**（这里都是 `(6,)`），代表两个分布的概率向量。

**输出**：一个标量浮点数，$d_{\mathrm{TV}} \in [0, 1]$。

**可调参数**：
- `a` / `b`：两个向量必须等长，否则 `np.abs(a - b)` 报形状错误。它们也不必非得是分布——任何等长数值向量都能算，但只有"和为 1 的非负向量"算出来的才有概率意义。
- 还能不能有第三个参数？可以加 `axis=None`：传 `axis=1` 就能一次算多行样本和理论分布之间的距离矩阵。但单条形状用不到。
- **前瞻**：总变差距离是"形状差距"最朴素的一把尺子。在深度学习里，衡量两个分布更常用的尺子是 **KL 散度**（softmax 交叉熵损失的本质就是 KL 散度的另一半）。那把尺子会在线性代数与信息论相关的章节登场——但骨架你已经摸到了：两个形状，逐点比差，再按某种规则加总。

### 步骤 7：主流程 —— 采样、反推、画图，最后验证大数定律

```python
th = theoretical_pmf()                          # 1. 理论分布（模型 / 楦）
samples = sample_dice(N_SAMPLES)                # 2. 采样（数据 / 脚）
emp = empirical_pmf(samples)                    # 3. 经验 PMF（反推的形状）

print("前 24 次掷骰:", samples[:24])
print("经验 PMF Phat(k) =", np.round(emp, 4))
print("理论 PMF p(k)    =", np.round(th, 4))
plot_pmf(emp, th, "经验 PMF vs 理论 PMF（N = %d 次掷骰）" % N_SAMPLES)

# 大数定律：样本越多，经验形状越贴理论形状（整条曲线一起收敛）
print("\n大数定律：经验 PMF 与理论 PMF 的距离随样本量收敛")
print("  最大偏差 = max_k |Phat(k) - p(k)|，TV 距离 = (1/2) * sum_k |Phat(k) - p(k)|")
for n in (10, 100, 1000, 10000, 100000):
    emp_n = empirical_pmf(sample_dice(n))
    dev = np.max(np.abs(emp_n - th))
    tv = tv_distance(emp_n, th)
    print("  N = %6d  -> 最大偏差 = %.4f   TV 距离 = %.4f   Phat(6) = %.4f"
          % (n, dev, tv, emp_n[5]))
```

#### 主流程 —— 把三个函数串成"量脚配楦"的流水线

**操作**：这是脚本的"执行部分"（顶层代码，不是函数）。它把步骤 2–6 串成一条链：

1. `th = theoretical_pmf()` —— 雕好楦，得到形状 `(6,)` 的理论 PMF。
2. `samples = sample_dice(N_SAMPLES)` —— 从楦里倒出 1000 只脚，得到形状 `(1000,)` 的样本。
3. `emp = empirical_pmf(samples)` —— 反推形状，得到形状 `(6,)` 的经验 PMF。
4. 打印前 24 次掷骰、经验 PMF、理论 PMF，再 `plot_pmf(...)` 画图。
5. **大数定律循环**：对 $N = 10, 100, 1000, 10000, 100000$ 各采样一次、反推一次，算两个量：
   - `dev = np.max(np.abs(emp_n - th))` —— **最大偏差**，六个点上经验与理论差距最大的那个；
   - `tv = tv_distance(emp_n, th)` —— **总变差距离**，整条形状的差距。
   - 顺便打印 `emp_n[5]` —— 面 6 的经验概率（下标 5 对应面 6）。

**对应数学**：最后的循环是主线全文的缩影。看输出里那两列数——最大偏差从 0.1333 一路塌缩到 0.0015，TV 距离从 0.2000 塌缩到 0.0023。它们在**围绕 0 收缩**，且收缩的幅度越来越小。这就是**大数定律 (Law of Large Numbers)**：当 $N \to \infty$，经验频率逐点逼近理论概率，也就是整条经验形状逼近理论楦。单支脚是混沌，几千只脚显秩序——现在这秩序有了精确的数学表达。

**输入**：无显式输入，读三个模块常量。

**输出**：控制台文本（一段经验/理论 PMF + 五行收敛表）+ 一张柱状图。

**可调参数**：
- 修改 `N_SAMPLES`：主流程的柱状图随之变化。设成 `100`，柱子高矮明显参差；设成 `100000`，柱子几乎齐平，趴在那条红线上。
- 修改大数定律循环里的元组 `(10, 100, 1000, 10000, 100000)`：换成别的样本量序列。加一个 `1000000`，最大偏差会塌缩到小数点后四位。
- 还能不能有更多参数？这层不是函数，没有"参数"——想更灵活，可以把打印与循环封装成 `run_experiment(sample_sizes, n_faces)`。但作为一节导论的演示，顶层直写更透明。

## 一步验证：把楦换成"灌铅的骰子"

想亲手撞一次主线里的边界声明（"选错分布，比没有分布更危险"）吗？把 `sample_dice` 换成一只不诚实的骰子——用 `rng.choice` 直接从"带权重"的分布采样：

```python
def sample_loaded_dice(n, seed=SEED):
    """灌铅骰子：面 6 概率 1/3，其余五面各 2/15。"""
    rng = np.random.default_rng(seed)
    support = np.arange(1, 7)                    # 支撑 {1,...,6}
    weights = np.full(6, 2.0 / 15)               # 其余五面各 2/15
    weights[5] = 1.0 / 3                         # 面 6 独享 1/3
    return rng.choice(support, size=n, p=weights)
```

把主流程里的 `sample_dice(N_SAMPLES)` 换成 `sample_loaded_dice(N_SAMPLES)`，其余不动。你会看到：柱子们不再趴在 $p(k) = 1/6$ 的红线上——面 6 高高突起。**经验频率忠实反映的，是生成数据的真实机制，而不是我们一厢情愿的假设。** 这正是主线里"楦不是脚"的现场演示：$\hat{p}(k)$ 不会说谎，但它只会告诉你骰子实际怎么掷的；至于你用哪只楦去套它——那取决于你的模型假设。选错了楦，再多的数据也只会喂出一个自信的错误。
