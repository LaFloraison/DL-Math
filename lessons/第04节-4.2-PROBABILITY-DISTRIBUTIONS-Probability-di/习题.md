# 习题：概率分布

## 第一组：概念检验

**1. 什么是概率分布？用"支撑 (support)、身体 (body)、参数 (parameters)"三要素，给一张分布画一幅完整肖像。**

**解答**：概率分布 (probability distribution) 是把随机变量 $X$ 的一切可能取值与它们各自的可能性联系起来的完整规则，由两样东西构成：

- **支撑**：$X$ 可能取到的一切值的集合——离散时是可数个点（骰子的 $\{1,\dots,6\}$），连续时是实数轴上的一段区间（身高的整条轴）。它回答"这只楦能覆盖多大的脚"。
- **身体**：把可能性分给支撑的规则——离散时是概率质量函数 $p(k)=\mathrm{P}(X=k)$，连续时是概率密度函数 $f(x)$。它回答"轮廓长什么样"。
- **参数**：重塑身体形状的旋钮——家族决定形状的种类，参数决定形状的细节。它回答"把足弓调高一点是指什么"。

再加一条归一化纪律作为身体的体检标准：离散 $\sum_k p(k)=1$，连续 $\int_{-\infty}^{+\infty} f(x)\,dx=1$。三要素齐了，这张分布才是完整的。

**思路点拨**：若有人答"概率分布就是那个钟形曲线（正态分布）"——只答对了一半。钟形只是墙上的一只楦；分布是**这面墙本身**，即"支撑 + 身体 + 参数"这个总框架。把"一只楦"当成"整面墙"，是本节最常见的混淆。

---

**2. 判断题并说明理由："概率密度函数 (PDF) 的取值 $f(x)$，就是随机变量 $X$ 等于 $x$ 的概率。"**

**解答**：错误，而且踩中了本节最大的陷阱。$f(x)$ 是**单位长度上的概率浓度（密度）**，不是概率。原因在主线第二节那面墙：连续支撑有不可数无穷多个点，若逐点分配正概率，总和立刻爆掉 1——所以连续世界"按点记账"失效，改用"按区间积分"记账：

$$\mathrm{P}(a \le X \le b) = \int_a^b f(x)\,dx$$

概率是密度曲线下那一小段的**面积**。一个直接后果：$f(x)$ 完全可以大于 1（密度高不等于概率大），但任何**单个点**的概率严格为 0。

**思路点拨**：为什么有人会选错？因为离散世界里 PMF 的值 $p(k)$ 就是概率，"$f(x)$ 也是概率"这个类比看起来天经地义——可两类楦的记账方式根本不同：离散按点记**质量**，连续按区间记**浓度**。记住那条分界线：骰子是点，身高是轴。

---

**3. 主线边界声明说"选错分布，比没有分布更危险"。用鞋铺的语言解释这句话，并指出它通往 §4.2.5 的哪个话题。**

**解答**：分布是模型假设——**楦不是脚**。楦再精致，也刻不进脚上的每一道纹路。当师傅硬用胖楦去套瘦脚，做出来的鞋会比不做的还难受：这只楦会给出**自信的、却完全是错的预言**——比承认"我不知道"更糟。真实数据可能同时带一点这个家族、一点那个家族，甚至根本不属于墙上任何一只楦。

它通往 §4.2.5 的过拟合与欠拟合：把一个太复杂的真实形状硬塞进太简单的楦（欠拟合），和把一个简单的真实形状塞进太复杂的楦（过拟合），是两种对称的"楦与脚错配"。

**思路点拨**：若有人答"选错分布最多就是不准确，总比没有模型好"——方向反了。错配的楦有确定性输出（所以"自信"），但它输出的是**假设的形状**而非数据的形状，会让后续一切基于它的决策（估计、正则化）建立在不真实的地基上。模型的危险不在"准不准"，而在"信誓旦旦地错"。

## 第二组：计算实践

**4. 手算 + NumPy 验证。** 教材《代码.md》步骤 7 里，$N=1000$ 的经验 PMF 输出为（已四舍五入到 4 位）：

$$\hat{p}(k) = [0.182,\ 0.152,\ 0.157,\ 0.173,\ 0.177,\ 0.159]$$

（a）手算验证六值之和为 1——归一化纪律。（b）估算面 1 在 1000 个样本中出现的次数 $N_1$。（c）手算最大偏差 $\max_k |\hat{p}(k) - \frac16|$ 与总变差距离 $d_{\mathrm{TV}} = \frac12 \sum_k |\hat{p}(k) - \frac16|$，再用 NumPy 验证（见《代码.md》步骤 6 的 `tv_distance`）。

**解答**：

（a）逐项相加：$0.182+0.152=0.334$，$+0.157=0.491$，$+0.173=0.664$，$+0.177=0.841$，$+0.159=1.000$。六只脚分完了唯一的一坨质量，总和恰好 1。

（b）$N_1 \approx \hat{p}(1) \times N = 0.182 \times 1000 = 182$ 次。

（c）理论值 $\frac16 \approx 0.1667$。逐点偏差：

| 面 | $\hat{p}(k)$ | $|\hat{p}(k)-\frac16|$ |
|---|---|---|
| 1 | 0.182 | 0.0153 |
| 2 | 0.152 | 0.0147 |
| 3 | 0.157 | 0.0097 |
| 4 | 0.173 | 0.0063 |
| 5 | 0.177 | 0.0103 |
| 6 | 0.159 | 0.0077 |

最大偏差 $= 0.0153$；总变差距离 $= \frac12 (0.0153+0.0147+0.0097+0.0063+0.0103+0.0077) = \frac12 \times 0.0640 = 0.0320$。**注意：这恰好与《代码.md》步骤 7 里 $N=1000$ 那一行的输出逐位一致**——说明对 4 位舍入后的 $\hat{p}(k)$ 做手算，就能复现机器算出的两个指标。

代码验证：

```python
import numpy as np
phat = np.array([0.182, 0.152, 0.157, 0.173, 0.177, 0.159])
p = np.full(6, 1/6)
print("归一化检查：sum(Phat) =", round(phat.sum(), 4))
print("面 1 出现次数 ≈", phat[0] * 1000)
print("最大偏差 =", round(np.max(np.abs(phat - p)), 4))
print("TV 距离   =", round(0.5 * np.sum(np.abs(phat - p)), 4))
```

输出：

```text
归一化检查：sum(Phat) = 1.0
面 1 出现次数 ≈ 182.0
最大偏差 = 0.0153
TV 距离   = 0.032
```

**思路点拨**：两个常见错误。第一，把 $\hat{p}(1)=0.182$ 当成"面 1 的真实概率"——不，真实概率是理论值 $\frac16 \approx 0.1667$，$\hat{p}$ 只是 1000 只脚反推的经验形状，是**随机量**，换一批样本就变；这正是主线"楦不是脚"的字面含义。第二，算总变差距离时忘了乘 $\frac12$——系数 $\frac12$ 让距离落在 $[0,1]$：形状完全相同是 0，支撑互不相交是 1。少了这个系数，你量出来的就不是教材《代码.md》里那把尺子。

**5. 大数定律手算。** 教材《代码.md》步骤 7 的收敛表给出不同样本量下 $P_{hat}(6)$ 的值：

| $N$ | 10 | 100 | 1000 | 10000 | 100000 |
|---|---|---|---|---|---|
| $\hat{p}(6)$ | 0.1000 | 0.1400 | 0.1590 | 0.1625 | 0.1659 |

（a）手算每个 $N$ 下 $\hat{p}(6)$ 与 $\frac16$ 的偏差，并描述偏差序列的性质。（b）用主线的一句话总结你看到的现象。

**解答**：

（a）$\frac16 \approx 0.1667$：

| $N$ | $|\hat{p}(6)-\frac16|$ |
|---|---|
| 10 | $\lvert 0.1000-0.1667 \rvert = 0.0667$ |
| 100 | $\lvert 0.1400-0.1667 \rvert = 0.0267$ |
| 1000 | $\lvert 0.1590-0.1667 \rvert = 0.0077$ |
| 10000 | $\lvert 0.1625-0.1667 \rvert = 0.0042$ |
| 100000 | $\lvert 0.1659-0.1667 \rvert = 0.0008$ |

偏差序列单调收缩、整体向 0 塌缩。

（b）**大数定律 (Law of Large Numbers)**：当 $N \to \infty$，经验频率逐点逼近理论概率——单支脚是混沌，几千只脚显秩序。反推出来的经验形状，贴着预先塑好的楦长出来了。这正是《代码.md》步骤 7 里"最大偏差 0.1333 → 0.0015"那两列数的本质。

**思路点拨**：若有人以为"$\hat{p}(6)$ 应该单调逼近 $\frac16$"——不对。大数定律保证的是**收敛到理论值**（偏差绝对值整体收缩），不是"每一步都比上一步更近"；$N=10$ 到 $N=100$ 时 $\hat{p}(6)$ 从 0.1000 涨到 0.1400，路径是曲折的，但误差的"上限"在稳步收窄。

**6. 归一化的另一边：连续密度。** 设 $f(x) = c \cdot x$ 定义在支撑 $[0, 1]$ 上，其余地方为 0。求常数 $c$，使 $f$ 成为合法的概率密度函数 (PDF)，并说明你用了哪条纪律。再算 $\mathrm{P}(X \le 0.5)$。

**解答**：用连续身体的归一化纪律 $\int f = 1$：

$$\int_0^1 c\,x\,dx = c \cdot \frac{x^2}{2}\bigg|_0^1 = \frac{c}{2} = 1 \quad\Longrightarrow\quad c = 2$$

于是 $f(x) = 2x$ 是 $[0,1]$ 上的合法密度。注意 $f(1) = 2 > 1$ 完全合法——PDF 的值不是概率，只有曲线下的**面积**才是。概率：

$$\mathrm{P}(X \le 0.5) = \int_0^{0.5} 2x\,dx = x^2\Big|_0^{0.5} = 0.25$$

**思路点拨**：若有人条件反射地"让 $c$ 满足最大值不超过 1"或"让 $f(0.5)$ 等于概率 $0.25$"——两处都踩了习题 2 的坑。PDF 只要求**非负 + 总积分 1**，$f(x) > 1$ 并不违规；而 $\mathrm{P}(X=0.5)$ 严格为 0，概率只活在区间上。这道题就是习题 2 判断题的"身体力行"版。

数值验证（用 `np.trapezoid` 数值积分，对应主线"概率是密度曲线下的面积"）：

```python
import numpy as np
x = np.linspace(0, 1, 1001)
f = 2 * x
print("int_0^1 2x dx =", np.trapezoid(f, x))          # 总面积 = 1
print("P(X<=0.5)     =", np.trapezoid(f[x <= 0.5], x[x <= 0.5]))  # 左段面积 = 0.25
```

输出：

```text
int_0^1 2x dx = 1.0
P(X<=0.5)     = 0.25
```

## 第三组：DL 延伸

**7. softmax 归一化手算。** 主线 DL 桥接里，softmax 把 $K$ 个原始分数（logits）变成定义在支撑 $\{1,\dots,K\}$ 上的离散分布：

$$p(y=k \mid x) = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

给定三个类的分数 $\mathbf{z} = (2, 1, 0)$：（a）手算三个 softmax 输出值并验证和为 1。（b）解释为什么网络**不能**直接用原始分数 $z$ 当概率输出，而必须落在合法分布上。（c）附 NumPy 验证。

**解答**：

（a）$e^2 \approx 7.389,\ e^1 \approx 2.718,\ e^0 = 1$，分母 $= 7.389 + 2.718 + 1 = 11.107$：

$$p_1 = \frac{7.389}{11.107} \approx 0.665, \qquad p_2 = \frac{2.718}{11.107} \approx 0.245, \qquad p_3 = \frac{1}{11.107} \approx 0.090$$

三值之和 $\approx 1.000$ —— 这条离散分布合法地落在支撑 $\{1,2,3\}$ 上。

（b）原始分数 $z_k$ 可以是任何实数，可以是负数，加起来也不等于 1——它不是概率，违反了"身体的总质量必须恰好等于 1"这条纪律。而训练目标是最大化似然 $p(y \mid x, \theta)$，损失取负对数 $\mathcal{L}(\theta) = -\log p(y \mid x, \theta)$（交叉熵）——$\log$ 的定义域要求输入必须是个真概率。所以 softmax 不是锦上添花，它是让模型输出"合法楦的身体"的必要一步。

（c）验证：

```python
import numpy as np
z = np.array([2.0, 1.0, 0.0])
p = np.exp(z) / np.exp(z).sum()
print(np.round(p, 4), "sum =", round(p.sum(), 4))
```

输出：

```text
[0.6652 0.2447 0.09  ] sum = 1.0
```

**思路点拨**：若有人答"softmax 就是把分数按比例缩放"——它确实是，但**指数 $e^z$ 不是白加的**：第一，它保证输出恒为正（原始分数可能为负）；第二，它放大分数差距（$z_1 - z_2 = 1$，softmax 后 $p_1 - p_2 \approx 0.42$）。若去掉指数只做线性归一化 $z_k/\sum z_j$，一旦出现负数，输出就成了伪分布——习题 2 的"浓度不是概率"在 DL 里的翻版。

**8. 选楦：任务种类决定输出分布。** 主线说"任务的'数据种类'决定了该用哪只楦"（§4.2 主题句在 DL 里的回响）。对以下四个深度学习场景，各选一只输出分布（并注明对应的输出变换），再回答：为什么"选楦"的错配（比如对房价用 softmax）会给出自信而荒谬的预言？

（a）二分类：判断一封邮件是否垃圾邮件。
（b）多分类：识别 10 类手写数字。
（c）连续回归：预测一套房的售价（实数）。
（d）计数：预测某网站在一小时内收到的点击次数（非负整数）。

**解答**：

（a）**伯努利分布 (Bernoulli)**——$\sigma$（sigmoid）变换，网络输出单个成功概率 $p$。
（b）**类别分布 (categorical)**——softmax 变换，输出支撑 $\{1,\dots,K\}$ 上的离散分布。
（c）**正态分布 (Normal)**——网络输出 $\hat\mu$ 与 $\hat\sigma$（实践里常输出 $\log\hat\sigma$ 再指数化保证正），损失里会多出 $\log\hat\sigma$ 一项。
（d）**泊松分布 (Poisson)**——网络输出 $\lambda$（单位时间的平均发生次数），损失用泊松负对数似然。

主题句"量身定做"的字面含义：输出的楦必须匹配数据的脚的种类。二选一的结果用伯努利，固定 $K$ 类的离散标签用类别分布，连续实数用正态，稀有事件计数用泊松。若对房价（连续）用 softmax：你把连续支撑硬切成有限格，同一售价永远拿不到概率质量，模型只能给出"最像的几个格子"——它自信，因为 softmax 输出恒是合法分布；它荒谬，因为那只楦根本不是为这条连续轴雕刻的。

**思路点拨**：若有人把（c）答成 softmax 或伯努利——那是把"回归"和"分类"混为一谈，连续数据没有有限类别可以切。若有人把（d）答成正态——点击次数是非负整数且常偏斜，泊松的支撑 $\{0,1,2,\dots\}$ 才匹配；硬用正态，模型输出的概率密度在负数处也非零，等于给"不可能的事"发了票。**选楦的错误，不是"精度差一点"，而是"支撑都放错了地方"。**
