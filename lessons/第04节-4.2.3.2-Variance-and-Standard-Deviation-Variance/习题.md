# 习题：方差与标准差

## 第一组：概念检验

**1. 为什么"平均偏离" $\mathbb{E}[X-\mu]$ 恒等于 0，不能用来衡量离散度？为什么平方能解决问题？**

**解答**：$\mathbb{E}[X-\mu]=\mathbb{E}[X]-\mu=0$——均值就是正负偏离的平衡点，正负永远抵消。平方把负偏离翻正，$\mathbb{E}[(X-\mu)^2]$ 不再抵消；同时平方在代数上顺滑（展开、求导、线性运算都友好）。代价是单位平方化（"环²"），取根号回到原单位得到标准差。

**2. 判断题并说明理由："方差为 0 说明这个分布没有随机性。"**

**解答**：正确。$\mathrm{Var}[X]=0 \Leftrightarrow \mathbb{E}[(X-\mu)^2]=0$。因为 $(X-\mu)^2\ge0$，其期望为 0 当且仅当 $X-\mu$ 恒为 0，即 $X$ 恒等于 $\mu$——一个常数的确"没有随机性"。反之只要 $X$ 有任意一点波动，那个非零的偏离平方就会让方差为正。

**3. 用一句话解释 $\mathrm{Var}[X]=\mathbb{E}[X^2]-(\mathbb{E}[X])^2$ 为什么成立，以及它的一个数值上的风险。**

**解答**：展开定义式并利用期望的线性性：$\mathbb{E}[(X-\mu)^2]=\mathbb{E}[X^2]-2\mu\mathbb{E}[X]+\mu^2=\mathbb{E}[X^2]-\mu^2$，交叉项 $-2\mu^2+\mu^2$ 恰好消成一个 $-\mu^2$。风险是"两个大数相减"：如果 $\mathbb{E}[X^2]$ 和 $\mu^2$ 都很大且接近（数据聚集在远处），浮点相减会丢失有效数字——数值计算里常用定义式而非快捷公式。

## 第二组：计算实践

**4. 手算 + 代码验证。** 三次考试：甲班成绩均值 70、标准差 5；乙班均值 70、标准差 15。（a）哪个班"更平均"？为什么？（b）把两个班合并后，均值还是 70 吗？方差大概怎么变？（c）如果老师给全班每人加 10 分，均值、方差、标准差各怎么变？

**解答**：
（a）甲班更平均——标准差 5 意味着"平均偏离均值约 5 分"，乙班约 15 分。均值相同，方差不同，这就是主线两位射手的故事。
（b）合并后均值仍是 70（都是 70 的班级合起来还是 70）。但方差**变大**：除了班内散布，还引入了班际差异——乙班的低分和高分把合并分布的两端拉开。具体：合并方差不等于两班方差之和，但会显著大于 25。这正是"分组数据的方差分解"（组内 + 组间）的雏形，§4.5 会再遇。
（c）每人加 10：均值从 70 变 80，标准差**不变**（仍是 5 和 15），方差也不变。因为加常数只是平移，偏离 $X-\mu$ 完全不变。$\mathrm{Var}[aX+b]=a^2\mathrm{Var}[X]$ 里 $b$ 不出现。

代码验证：

```python
import numpy as np
a = np.random.normal(70, 5, 2000)
b = np.random.normal(70, 15, 2000)
merged = np.concatenate([a, b])
print("合并均值 =", round(merged.mean(), 2), " 合并标准差 =", round(merged.std(), 2))
print("加 10 分后标准差 =", round((merged + 10).std(), 2))
```

输出（大致）：

```text
合并均值 = 69.99  合并标准差 = 11.63
加 10 分后标准差 = 11.63
```

**思路点拨**：若有人答"合并方差 = 25 + 225"，那是想当然了——合并方差还包括两班均值之间的差（组间方差）。若有人答"加 10 分标准差也变大"，那是把"平移"当成了"缩放"：平移只动位置不动散布。

**5. 用抽样验证"样本均值的方差 $=\sigma^2/N$"。** 从 $\mathcal{N}(0,1)$ 反复抽 $N$ 个样本算均值，重复 10000 次，看这些均值的标准差是否约为 $1/\sqrt{N}$。

**解答**：

```python
import numpy as np
np.random.seed(0)
for N in (10, 100, 1000):
    means = [np.random.normal(0, 1, N).mean() for _ in range(10000)]
    print(f"N={N:>4}: 样本均值们的标准差 = {np.std(means):.4f}  理论 1/√N = {1/np.sqrt(N):.4f}")
```

输出：

```text
N=  10: 样本均值们的标准差 = 0.3151  理论 1/√N = 0.3162
N= 100: 样本均值们的标准差 = 0.0998  理论 1/√N = 0.1000
N=1000: 样本均值们的标准差 = 0.0314  理论 1/√N = 0.0316
```

样本量从 10 到 1000（100 倍），均值的标准差从 0.32 掉到 0.03——只缩小了约 10 倍。**平方根定律：误差随 $N$ 的平方根下降。** 想精确十倍，样本要百倍。**思路点拨**：这条 $\frac{\sigma}{\sqrt N}$ 是深度学习一切蒙特卡洛估计（§4.3.6）的底层账本——MC-dropout 的重复次数、随机梯度的 batch 大小，都在这条曲线上定价。

## 第三组：DL 延伸

**6. 初始化场景。** 一个神经元接收 $n$ 个输入 $z=\sum_{i=1}^n w_i x_i$。设 $w_i$ 独立、方差 $\sigma_w^2$，$x_i$ 独立、均值 0、方差 $\sigma_x^2$。（a）写出 $\mathrm{Var}[z]$ 的表达式。（b）解释为什么需要"让方差不随 $n$ 增长"的初始化（如 He 初始化 $\sigma_w^2=\frac{2}{n}$），以及如果方差逐层爆炸/消失会怎样。

**解答**：
（a）利用"独立随机量之和的方差等于方差之和"（这是 $\mathrm{Var}[X+Y]=\mathrm{Var}[X]+\mathrm{Var}[Y]$ 对独立的延伸）：$\mathrm{Var}[z]=\sum_i\mathrm{Var}[w_ix_i]$。而 $\mathrm{Var}[w_ix_i]=\mathbb{E}[w_i^2]\mathbb{E}[x_i^2]-(\mathbb{E}[w_ix_i])^2$，当 $w_i,x_i$ 独立且均值 0 时为 $\sigma_w^2\sigma_x^2$。于是 $\mathrm{Var}[z]=n\sigma_w^2\sigma_x^2$——**方差随 $n$ 线性增长**。
（b）如果不做约束，层数加深时 $\mathrm{Var}[z]$ 被 $n$ 逐层放大：$n=256$ 的一层就把方差放大 256 倍，几十层下来信号爆炸（梯度消失/爆炸的方差视角）。He 初始化取 $\sigma_w^2=\frac{2}{n}$，代入得 $\mathrm{Var}[z]=\frac{2}{n}\cdot n\cdot\sigma_x^2=2\sigma_x^2$——**方差被钉住，不随 $n$ 变**。这就是初始化器里那个 $\frac{1}{\sqrt{n}}$（或 $\sqrt{2/n}$）的由来：它不是经验值，是"方差守恒方程"的解。
**思路点拨**：若有人直接答"$z$ 的方差是 $n\sigma_w^2$"，漏了 $x$ 的方差 $\sigma_x^2$——二者都要写。若有人困惑"为什么不是让方差变小而是守恒"，可以想：太小信号逐层衰减成无声（梯度消失），太大逐层爆炸（梯度爆炸），"不涨不灭"才是目标。方差，是梯度流的血压。
