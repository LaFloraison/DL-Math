# 代码：方差与标准差——让"散不散"被两个数字抓住，让平方放大效应现身

主线里我们把方差定义为"偏离平方的平均"：$\mathrm{Var}[X]=\mathbb{E}[(X-\mu)^2]=\mathbb{E}[X^2]-\mu^2$，标准差是它的根号。本课用代码做四件事：

1. **两位射手的对照**：平均环数相同，方差天差地别——"均值相等"如何骗人。
2. **连续版验算**：对 $\mathcal{N}(50,25)$ 用梯形积分算 $\int(x-\mu)^2f(x)dx$，应得 25。
3. **快捷公式验证**：$\mathrm{Var}=\mathbb{E}[X^2]-\mu^2$ 与定义式结果一致。
4. **离群点实验**：加一个离谱样本，看方差如何被平方放大。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：mean / var / std / trapz

# ---- ① 两位射手：平均都是 8 环，散布不同 ----
archer_a = np.array([8.0, 7.9, 8.1, 8.0, 8.2, 7.8, 8.1, 7.9, 8.0, 8.0])
archer_b = np.array([5.0, 10.0, 6.0, 9.0, 8.0, 7.0, 11.0, 4.0, 10.0, 10.0])
print(f"A: 均值={archer_a.mean():.2f}  方差={archer_a.var():.4f}  标准差={archer_a.std():.4f}")
print(f"B: 均值={archer_b.mean():.2f}  方差={archer_b.var():.4f}  标准差={archer_b.std():.4f}")

# ---- ② 手动实现定义式（不用 np.var），再看快捷公式 ----
def var_manual(x):
    mu = x.mean()
    return np.mean((x - mu)**2)           # E[(X-μ)²]
def var_shortcut(x):
    return np.mean(x**2) - x.mean()**2    # E[X²] - μ²
print(f"B 定义式方差 = {var_manual(archer_b):.4f}   快捷公式 = {var_shortcut(archer_b):.4f}")

# ---- ③ 连续版：N(50,25) 的方差用梯形积分 ----
x = np.linspace(20.0, 80.0, 100001)
pdf = 1.0/(5.0*np.sqrt(2.0*np.pi))*np.exp(-(x-50.0)**2/(2.0*25.0))
mu = np.trapz(x * pdf, x)                 # E[X]
var_cont = np.trapz((x - mu)**2 * pdf, x) # E[(X-μ)²] = ∫ (x-μ)² f(x) dx
print(f"N(50,25) 积分方差 ≈ {var_cont:.4f}   标准差 ≈ {np.sqrt(var_cont):.4f}   # 理论 25 / 5")

# ---- ④ 离群点实验：B 的成绩加一个 3 环，看方差怎么变 ----
archer_b2 = np.append(archer_b, 3.0)
print(f"B 加离群点 3 环后：均值={archer_b2.mean():.2f}  方差={archer_b2.var():.4f}（原来 {archer_b.var():.4f}）")
```

运行输出（Python 3.11 + NumPy）：

```text
A: 均值=8.00  方差=0.0100  标准差=0.1000
B: 均值=8.00  方差=4.6000  标准差=2.1448
B 定义式方差 = 4.6000   快捷公式 = 4.6000
N(50,25) 积分方差 ≈ 25.0000   标准差 ≈ 5.0000   # 理论 25 / 5
B 加离群点 3 环后：均值=7.55  方差=6.4479（原来 4.6000）
```

均值同为 8.00，方差却从 0.01 到 4.6——"平均"骗人的证据。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

```python
import numpy as np
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 $\mathbb{E}$（`np.mean`）、$\int$（`np.trapz`）提供执行者。

---

### 步骤 2：两位射手对照

```python
archer_a = np.array([8.0, 7.9, 8.1, 8.0, 8.2, 7.8, 8.1, 7.9, 8.0, 8.0])
archer_b = np.array([5.0, 10.0, 6.0, 9.0, 8.0, 7.0, 11.0, 4.0, 10.0, 10.0])
```

#### `np.array(...)` 与 `.mean()` `.var()` `.std()` —— 创建数组并算三个量

**做什么**：把两位射手的十环造出来，然后各算均值、方差、标准差。
**操作**：`np.array` 把列表变成数组；`.mean()` 求平均；`.var()` 求方差（默认 `ddof=0`，即除以 $N$，对应"总体方差"）；`.std()` 是 `np.sqrt(var)`。
**输入**：长度 10 的两个一维数组。
**输出**：两组三连数字。A 方差 0.01，B 方差 4.6——差 460 倍。
**可调参数**：`.var(ddof=1)` 改用 $N-1$ 作分母（样本方差的无偏估计，§4.3.12 重采样会再遇到）；`.var(axis=...)` 可对多维数组沿某轴算。**注意** `.var()` 内部用的就是"平方的期望减期望的平方"，与 `var_manual` 殊途同归，但数值上对极端数据可能丢精度。
**对应数学**：$\mathrm{Var}[X]=\mathbb{E}[(X-\mu)^2]$。两个分布均值相同、方差不同——方差补上了均值漏掉的"散"。

---

### 步骤 3：手动实现两种方差公式

```python
def var_manual(x):
    mu = x.mean()
    return np.mean((x - mu)**2)           # E[(X-μ)²]
def var_shortcut(x):
    return np.mean(x**2) - x.mean()**2    # E[X²] - μ²
print(f"B 定义式方差 = {var_manual(archer_b):.4f}   快捷公式 = {var_shortcut(archer_b):.4f}")
```

#### var_manual 与 var_shortcut —— 定义式 vs 快捷公式

**做什么**：前者照抄定义"偏离平方的平均"，后者用"平方的期望减期望的平方"。输出 `4.6000` 对 `4.6000`——两个公式数学上恒等。
**操作**：`(x - mu)**2` 逐元素偏离平方；`np.mean(...)` 取平均。`x**2` 逐元素平方后取平均得 $\mathbb{E}[X^2]$；`x.mean()**2` 得 $\mu^2$。
**输入**：一维数组。
**输出**：两个标量。
**可调参数**：把 `x` 换成任意数据，两个函数永远给出相同结果（浮点误差内）。想复现教材 $\mathcal{N}(50,5)$：用 N(50,25) 抽样数组，两种算都应约等于 25。
**对应数学**：$\mathrm{Var}[X]=\mathbb{E}[X^2]-(\mathbb{E}[X])^2$。为什么两个式子相等？展开定义式：$\mathbb{E}[(X-\mu)^2]=\mathbb{E}[X^2-2\mu X+\mu^2]=\mathbb{E}[X^2]-2\mu^2+\mu^2=\mathbb{E}[X^2]-\mu^2$——期望的线性性让中间的交叉项消失。

---

### 步骤 4：连续版方差——梯形积分

```python
x = np.linspace(20.0, 80.0, 100001)
pdf = 1.0/(5.0*np.sqrt(2.0*np.pi))*np.exp(-(x-50.0)**2/(2.0*25.0))
mu = np.trapz(x * pdf, x)
var_cont = np.trapz((x - mu)**2 * pdf, x)
print(f"N(50,25) 积分方差 ≈ {var_cont:.4f}   标准差 ≈ {np.sqrt(var_cont):.4f}")
```

**做什么**：对正态密度算 $\mu=\int x f(x)dx$ 与 $\mathrm{Var}=\int(x-\mu)^2 f(x)dx$，应得 50 与 25。
**操作**：`pdf` 是手写正态密度（§4.2.2.2）；`np.trapz(x*pdf, x)` 积出均值；`np.trapz((x-mu)**2*pdf, x)` 积出方差——注意**先算 $\mu$，再用 $\mu$ 去积方差**，这是定义式的顺序。
**输入**：网格、密度。
**输出**：`25.0000` 与 `5.0000`，与教材 $\sigma^2=25,\ \sigma=5$ 完全吻合。
**可调参数**：把 `pdf` 换成均匀/指数等其他分布，积分会自动给出该分布的方差——比如 $\text{Uniform}(a,b)$ 的 $\frac{(b-a)^2}{12}$（§4.2.2.1）。这是验证"每个分布自带方差公式"的万能钥匙。
**对应数学**：$\mathrm{Var}[X]=\int_{-\infty}^{\infty}(x-\mu)^2 f(x)dx$。积分是对"每个位置的偏离平方 × 该位置的密度"做加权平均——这正是"平方的平均"在连续世界的翻译。

### 步骤 5：离群点实验

```python
archer_b2 = np.append(archer_b, 3.0)
print(f"B 加离群点 3 环后：均值={archer_b2.mean():.2f}  方差={archer_b2.var():.4f}（原来 {archer_b.var():.4f}）")
```

#### `np.append(arr, val)` —— 给数组追加一个元素

**做什么**：给 B 射手的成绩追加一发离谱的 3 环，看方差被撑大多少。
**操作**：`np.append` 返回新数组（原数组不变）。
**输入**：原数组与追加值。
**输出**：长度 11 的数组。
**可调参数**：追加值换成不同大小的离群点，观察方差变化——3 环让方差从 4.6 涨到 6.45（涨约 40%），而均值只从 8.00 掉到 7.55。**均值被拖了一点点，方差被拖了一大截。**
**对应数学**：$(x-\mu)^2$ 的平方放大——3 环那个点离均值 4.5 环，平方贡献约 20，是正常点（偏离约 2）的四五倍。这就是主线边界声明里"方差对离群点敏感"的现场演示。

## 改个数字试试：标准差与方差的关系

### 实验：σ 翻倍时方差翻四倍

```python
x = np.linspace(20.0, 80.0, 100001)
for sig in (2.5, 5.0, 10.0):
    pdf = 1.0/(sig*np.sqrt(2.0*np.pi))*np.exp(-(x-50.0)**2/(2.0*sig**2))
    var = np.trapz((x-50.0)**2*pdf, x)
    print(f"σ={sig:>5}: 方差={var:8.2f}   (σ₁ 的平方 {sig**2:7.2f})")
```

输出：

```text
σ=  2.5: 方差=    6.25   (σ₁ 的平方    6.25)
σ=  5.0: 方差=   25.00   (σ₁ 的平方   25.00)
σ= 10.0: 方差=  100.00   (σ₁ 的平方  100.00)
```

标准差从 5 翻到 10，方差从 25 翻到 100——**方差按 σ 的平方增长**（$\mathrm{Var}[aX]=a^2\mathrm{Var}[X]$）。这就是为什么说"方差用于数学推导，标准差用于人话"：$\sigma=10$ 比 $\sigma=5$ 只"宽了两倍"，方差却大四倍。

## 边界声明：这套代码能做什么，不能做什么

1. **方差被离群点牵着走。** 平方放大极端偏离——一个离谱样本就能撑大方差。对含大量离群点的数据（长尾收入、点击日志），方差可能严重失真；想更鲁棒用四分位距 (IQR) 或绝对偏差。别拿方差当"散度"的唯一答案。
2. **`.var()` 默认除 $N$（总体方差），`.var(ddof=1)` 才是无偏的样本方差。** 对一小批样本（比如 10 个），两者差异不小。深度学习里常用 `ddof=1` 或框架的相应选项（如 PyTorch 的 `torch.var(unbiased=True)` 默认）来估计方差。
3. **这只是在验算方差的定义。** 真实模型里方差由框架计算（BN 统计量、优化器的二阶矩估计如 Adam 的 $v_t$——Adam 的 $v_t$ 正是"梯度的方差"的指数移动平均）。但看懂"$\sigma^2=\mathbb{E}[(X-\mu)^2]$"，你就看懂了 Adam 的第二动量、BN 的分母、MC 估计的误差公式 $\frac{\sigma}{\sqrt N}$ 从哪里来。
