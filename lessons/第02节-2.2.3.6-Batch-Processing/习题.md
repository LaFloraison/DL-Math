# 习题：批处理

## 第一组：概念检验

**1.1（单选）** 批大小 $B=32$、每个样本 $d_{in}=784$ 特征、一层输出 $d_{out}=10$ 个神经元。这一层的权重矩阵形状、批量输入形状、批量输出形状分别是：
- A. $(784, 10)$、$(32, 784)$、$(32, 10)$
- B. $(10, 784)$、$(32, 784)$、$(32, 10)$
- C. $(10, 784)$、$(784, 32)$、$(10, 32)$
- D. $(32, 10)$、$(32, 784)$、$(32, 784)$

**1.2（判断并说明）** "批量训练比逐样本训练更稳，是因为批量梯度是一批样本梯度的平均，单样本的噪声被稀释了。" 这句话对吗？

**1.3（填空）** 把 $B$ 个样本摞成的矩阵 $X$ 形状是 $(B, d_{in})$；每层输出 $Z = X \_\_\_ + \mathbf{b}$（填矩阵乘），其中 $\_\_\_$ 的作用是让权重矩阵与批量对齐；偏置 $\mathbf{b}$ 通过____自动加到每一行。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 设批量 $X = \begin{bmatrix} 1 & 2 \\ 3 & 4 \\ 5 & 6 \end{bmatrix}$（3 样本、2 特征），$W = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$（2 输出、2 输入），$\mathbf{b} = [0, 0]$。手算 $Z = XW^\top + \mathbf{b}$，再用 NumPy 验证。

**2.2（代码验证）** 用 `np.stack` 造一批 4 个随机 3 维向量，验证"批量前向 `X @ W.T` 与逐样本 `W @ x + b` 摞起来"的结果完全一致（用 `np.allclose`）。

**2.3（动手理解）** 模拟"平均稀释噪声"：造 10 个"梯度样本"（含几个极端值），分别算"单个样本梯度"与"10 样本平均梯度"的方向，比较谁的噪声更大（可比较与"真实方向"的夹角）。

## 第三组：DL 延伸

**3.1（场景判断）** PyTorch 里 `DataLoader(dataset, batch_size=64)` 把数据集切成 64 个一批。如果数据集有 1000 个样本，最后一个批次通常只有 36 个。请问：这会影响模型吗？框架通常怎么处理？（提示：`drop_last` 参数）

**3.2（场景分析）** 有工程师把 `batch_size` 从 32 改到 512，发现 loss 下降曲线"更平滑了但最终准确率略降"。请用"平均噪声 vs 泛化"解释这两个现象，并说明为什么这不是 bug。

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：权重"行=输出、列=输入"→ $(10, 784)$；批量输入 $(32, 784)$；前向 $XW^\top$：$(32,784)@(784,10) = (32,10)$。
- **点拨**：A 把权重转置方向记反（$(784,10)$ 是"列=输出"的另一种约定，PyTorch 不用）。读代码先确认权重存放约定，是本课反复强调的。

**1.2 对。**
- **思路**：批量梯度 $\frac{1}{B}\sum_b \nabla L_b$。单个样本的梯度可能被该样本的极端特征"带偏"；平均后，几个极端样本被大多数正常样本的梯度"拽回"，方向更接近整体最陡方向，噪声被稀释。
- **点拨**：这是批量训练"稳"的来源。反过来也说明为什么 $B=1$ 的纯 SGD 振荡剧烈。

**1.3 答案：`@ W.T`（矩阵乘）；`W.T`（转置）；广播。**
- **思路**：批量前向 $Z = XW^\top + \mathbf{b}$。$W^\top$ 让内维对齐；$\mathbf{b}$ 通过广播加到每行。
- **点拨**：`W.T` 是"批量前向的标准姿势"——忘了转置是最常见的形状报错。

### 第二组

**2.1**
$W^\top = \begin{bmatrix}1&0\\0&1\end{bmatrix}$（对称，转置不变）。$Z = \begin{bmatrix}1&2\\3&4\\5&6\end{bmatrix}\begin{bmatrix}1&0\\0&1\end{bmatrix} = \begin{bmatrix}1&2\\3&4\\5&6\end{bmatrix}$（单位阵不改变数据），加 $\mathbf{b}=[0,0]$ 不变。

```python
import numpy as np
X = np.array([[1.,2.],[3.,4.],[5.,6.]])
W = np.array([[1.,0.],[0.,1.]])
b = np.array([0.,0.])
print(X @ W.T + b)   # [[1. 2.] [3. 4.] [5. 6.]]
```
- **思路**：$W$ 是单位阵，任何输入过它都不变——**这是调试矩阵代码的第一招**（用单位阵验证形状与结构）。
- **点拨**：把 $W$ 换成 $\begin{bmatrix}1&1\\0&1\end{bmatrix}$ 再算，就能看到"批量同时被变换"。

**2.2**
```python
import numpy as np
X = np.random.rand(4, 3)          # 4 样本、3 特征
W = np.random.rand(2, 3)          # 2 输出
b = np.random.rand(2)
Z_batch = X @ W.T + b
Z_loop = np.stack([W @ x + b for x in X])
print(np.allclose(Z_batch, Z_loop))   # True
```
- **思路**：批量与循环等价——矩阵乘是"打包的循环"。
- **点拨**：这是"向量化"的定义性验证：**结果相同、写法不同、速度差几个量级**。

**2.3**
```python
import numpy as np
true_dir = np.array([1.0, 1.0]) / np.sqrt(2)          # "真实"下坡方向
grads = np.random.randn(10, 2)                        # 10 个样本梯度
grads[0] *= 50; grads[5] *= 50                        # 加两个极端值
def angle(g, t=true_dir):
    return np.degrees(np.arccos(np.clip(np.dot(g,t)/(np.linalg.norm(g)*np.linalg.norm(t)), -1, 1)))
print("单个极端样本与真实方向夹角:", round(angle(grads[0]), 1))
print("平均梯度与真实方向夹角   :", round(angle(grads.mean(axis=0)), 1))
```
- **思路**：极端样本的梯度方向可能严重偏离"真实方向"；平均后，10 个样本相互抵消，方向更接近真实。
- **点拨**：这就是"平均稀释噪声"的数值实证。注意方向与模长分开看——平均主要改善**方向**。

### 第三组

**3.1 思路**
- 最后一批只有 36 个样本，仍能正常前向/反向——批量运算不要求每批大小相等（框架会自动处理最后一小批）。
- 但 BatchNorm（§2.3.6.8）会受影响：批大小 36 时统计量噪声大（"batch too small"问题）。此外梯度平均时 $1/B$ 的 $B$ 不同，方向略有差异。
- `drop_last=True` 丢弃最后的 36 个样本，保证每批等大（稳定 BatchNorm/训练）；`drop_last=False`（默认）保留。取舍：丢弃损失部分数据，保留则末批统计不稳定。
- **点拨**：`drop_last` 是"等批次大小 vs 用尽数据"的工程权衡。

**3.2 思路**
- **更平滑**：$B$ 从 32 到 512，平均梯度用了 16 倍多的样本，单样本噪声大幅稀释，loss 曲线振荡更小——"更稳"。
- **准确率略降**：经验上大批次收敛到更"尖锐"的极值，泛化较差；小批次的噪声反而起到"随机探索"作用，帮助跳出不好的极值区（§5 优化深入）。这不是 bug，是"稳定性 vs 泛化"的权衡。
- **改法**：若要大批次 + 好泛化，可加大学习率并按批大小缩放、或用 warmup 等技巧（§2.3.6.7 优化器）。
- **点拨**：**"更平滑"不总是"更好"**——训练曲线的平滑度不是目标，泛化才是。这是把"批大小"当纯工程参数时最常犯的观念错误。
