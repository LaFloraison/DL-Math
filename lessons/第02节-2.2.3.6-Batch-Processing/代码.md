# 代码：把一批样本摞成矩阵，一次算完一层——并对比"逐样本 vs 批量"

主线里我们讲了批处理 = 把 $B$ 个样本摞成矩阵一次过网络。这一节用 NumPy 验证三件事：**① 批量前向与逐样本前向结果一致；② 批量梯度的"平均"效应；③ 广播（偏置加到每行）。**

---

## 层一：完整脚本

```python
import numpy as np                            # NumPy：stack / mean

# ---- ① 造一批数据：B=3 个样本，每个 4 特征（教材例子）----
x1 = np.array([1.0, 0.0, 3.0, 0.0])
x2 = np.array([2.0, 0.0, 4.0, 0.0])
x3 = np.array([3.0, 0.0, 5.0, 0.0])
X  = np.stack([x1, x2, x3])                   # (3, 4)
print("批量 X 形状:", X.shape)

# ---- ② 一层网络：2 个神经元，权重 + 偏置 ----
W  = np.array([[0.5, 0.1, 0.2, 0.0],           # (2, 4)
               [0.3, 0.0, 0.4, 0.1]])
b  = np.array([0.05, -0.05])                   # (2,)

# ---- ③ 批量前向：Z = X @ W.T + b（广播）----
Z = X @ W.T + b
print("批量前向 Z:", Z, "形状:", Z.shape)       # (3, 2)

# ---- ④ 逐样本前向：应该与批量一致 ----
Z_loop = np.stack([W @ x + b for x in (x1, x2, x3)])
print("逐样本一致:", np.allclose(Z, Z_loop))

# ---- ⑤ 批量梯度 = 平均梯度：噪声被稀释 ----
dL_dz = np.random.randn(3, 2)                  # 每个样本的"误差"（模拟）
grad_W_loop = np.stack([np.outer(dL_dz[b], X[b]) for b in range(3)])  # 每个样本的梯度
avg_grad = grad_W_loop.mean(axis=0)            # (2,4) 平均梯度
print("平均梯度形状:", avg_grad.shape, "（比单个样本的梯度更稳）")
```

运行输出（Python 3.11 + NumPy）：

```text
批量 X 形状: (3, 4)
批量前向 Z: [[0.85 0.35]
 [1.05 0.75]
 [1.25 1.15]] 形状: (3, 2)
逐样本一致: True
平均梯度形状: (2, 4)（比单个样本的梯度更稳）
```

下面拆开看每一步。

---

## 层二：分步逐函数拆解

### 步骤 1：`np.stack` 造批量

```python
X = np.stack([x1, x2, x3])
```

#### `np.stack(list)` —— 把样本摞成矩阵

**操作**：三个 `(4,)` 向量沿新轴 0 摞成 `(3, 4)`。第 $b$ 行 = 第 $b$ 个样本。
**输入**：三个形状相同的数组。
**输出**：`(3, 4)` 矩阵。
**可调参数**：`axis` 控制新轴位置（`axis=1` 得 `(4,3)`）。**批量维度永远是第 0 维**是深度学习惯例。
**对应数学**：主线 $X \in \mathbb{R}^{B \times d_{in}}$。

### 步骤 2：权重与偏置

```python
W = np.array([[0.5, 0.1, 0.2, 0.0], [0.3, 0.0, 0.4, 0.1]])   # (2, 4)
b = np.array([0.05, -0.05])                                   # (2,)
```

**做什么**：2 个输出神经元、4 个输入的一层。$W$ 行=输出、列=输入（§2.2.3.2 约定）。
**可调参数**：任意；偏置 `b` 长度必须等于 $W$ 行数。
**对应数学**：主线"每层权重矩阵与偏置向量"。

### 步骤 3：批量前向 + 广播

```python
Z = X @ W.T + b
```

#### `X @ W.T` —— 批量矩阵乘

**操作**：`(3,4) @ (4,2) → (3,2)`。$W.T$ 把权重转成 `(4,2)`，让"内维 4 对齐"。$Z_{b,i} = \sum_j X_{b,j}W_{i,j}$。
**输入**：`X`（`(3,4)`）、`W.T`（`(4,2)`）。
**输出**：`(3,2)`——每行是一个样本的输出。
**可调参数**：**必须用 `W.T`**；`X @ W` 会因内维 4≠2 报错。手写批量前向最容易错的就是忘了转置。
**对应数学**：主线 $Z = XW^\top$——一次算 $B$ 个点积的批量版。

#### `+ b` —— 广播加偏置

**操作**：`(3,2) + (2,)`。NumPy 广播：`(2,)` 自动"拉伸"到每一行。$Z_{b,i}$ 都加上 $b_i$。
**可调参数**：形状不匹配时广播规则自动处理；若 `b` 形状 `(3,)` 则按列广播，语义完全不同——**读代码先确认广播方向**。
**对应数学**：主线"偏置广播到每一行"。§2.4.4 详述广播。

### 步骤 4：逐样本验证

```python
Z_loop = np.stack([W @ x + b for x in (x1, x2, x3)])
np.allclose(Z, Z_loop)
```

**操作**：对每个样本单独做 `W@x + b`，摞起来，与批量结果比较。`True` 证明**批量 = 逐个相加**——矩阵乘只是把循环"向量化"了。
**可调参数**：换成任何数据都成立；这是"向量化"的定义性验证。
**对应数学**：主线"$Z$ 的第 $b$ 行就是单独处理样本 $b$"。**批量不是新运算，是循环的打包。**

### 步骤 5：批量梯度 = 平均梯度

```python
grad_W_loop = np.stack([np.outer(dL_dz[b], X[b]) for b in range(3)])
avg_grad = grad_W_loop.mean(axis=0)
```

#### `np.outer(a, b)` —— 外积（每个样本的梯度）

**操作**：$\frac{\partial L_b}{\partial W} = \delta_b \cdot \mathbf{x}_b^\top$（§2.2.3.5 的外积公式）。每个样本各得到一个 `(2,4)` 梯度。
**可调参数**：$dL_dz$ 是我模拟的"误差"，真实来自反向传播。
**对应数学**：主线"批量梯度 = 平均梯度 $\frac{1}{B}\sum_b \nabla L_b$"。

#### `.mean(axis=0)` —— 沿批维平均

**操作**：`axis=0` 是批维，沿它平均，把 3 个样本的梯度合成一个 `(2,4)` 平均梯度。
**可调参数**：`axis=0`（批维）或 `axis` 换成特征维，结果语义完全不同。
**对应数学**：主线"平均稀释了单样本噪声"。单样本梯度可能"偏激"，平均后方向更接近"整体最陡方向"——这就是批量训练比逐样本 SGD 更稳的原因。

## 边界声明：这套代码能做什么，不能做什么

1. **`X @ W.T` 的形状约定不是唯一的**。PyTorch `nn.Linear` 内部用 `x @ W.T + b`（权重存 `(out, in)`）；但若有人用"列=输出"的约定存权重，就要写 `X @ W`。**读任何代码先确认权重的存放约定。**
2. **批量梯度是"平均"，不是"求和"**。更新时要不要除以 $B$，直接影响学习率语义。PyTorch 的 `loss.backward()` 默认对损失**取平均**（`reduction='mean'`），即隐含了 $1/B$。若用 `reduction='sum'`，学习率要相应调小——这是常见的隐 bug。
3. **批大小影响的不只是速度**。$B$ 大 → 每步更稳但可能损害泛化（§5 优化）；$B$ 小 → 噪声大但有时更有益。没有"正确"的 $B$，只有"适合任务与硬件"的 $B$。
4. **这个例子只有 3 个样本，GPU 并行优势不明显**。真实训练 $B=128$ 时，批量矩阵乘让数千核心"吃饱"。教学用小批量看清结构，真实用大批量吃满硬件。
