# 代码：滑动账本 vs 只增账本——RMSprop 与 Adagrad 的生死对照

**目标**：主线里教材例 $f(x)=(x-2)^2$，$\alpha=0.01$，$\beta=0.9$，$x_0=4$。这里复现 RMSprop 的迭代，并用一个**决定性的对照**演示"为什么滑动平均救活了学习率"：在梯度恒为 1 的问题上，Adagrad 的步长从 0.1 一路衰减到 0.001，而 RMSprop 的步长稳定在 0.1——**一个字之差（累加 vs 滑动平均），一个走向死亡，一个持续前进。** 全部裸 NumPy。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 教材例: f(x) = (x-2)^2, alpha=0.01, beta=0.9 ----
alpha, beta, eps = 0.01, 0.9, 1e-8
x, E = 4.0, 0.0                          # 位置与滑动平均账本

print("--- RMSprop f(x)=(x-2)^2, 前 2 步 ---")
for t in range(1, 3):
    g = 2.0 * (x - 2.0)                  # 梯度
    E = beta * E + (1 - beta) * g ** 2   # 滑动平均账本
    x = x - alpha * g / (np.sqrt(E) + eps)  # 更新
    print(f"iter{t}: g={g:.2f} E={E:.4f} x={x:.4f}")

# ---- 2. 决定性对照: f(x)=x (梯度恒=1), 看步长走向 ----
print("\n--- f(x)=x (梯度恒=1): Adagrad vs RMSprop 步长 ---")
xa, Ga = 0.0, 0.0                        # Adagrad 的状态
xr, Er = 0.0, 0.0                        # RMSprop 的状态
for t in range(1, 10001):
    Ga += 1.0                            # Adagrad: 累加 (只增)
    xa = xa - 0.1 / (np.sqrt(Ga) + 1e-8)
    Er = beta * Er + (1 - beta) * 1.0    # RMSprop: 滑动平均
    xr = xr - 0.1 / (np.sqrt(Er) + 1e-8)
    if t in (1, 10, 100, 1000, 10000):
        print(f"t={t:5d}: Adagrad 步长={0.1/np.sqrt(Ga):.2e} x={xa:8.2f}"
              f" | RMSprop 步长={0.1/np.sqrt(Er):.3f} x={xr:9.2f}")
```

输出（可复现）：

```

iter2: g=3.94 E=2.9898 x=3.9456

--- f(x)=x (梯度恒=1): Adagrad vs RMSprop 步长 ---
t=    1: Adagrad 步长=1.00e-01 x=    -0.10 | RMSprop 步长=0.316 x=    -0.32

t=10000: Adagrad 步长=1.00e-03 x=   -19.85 | RMSprop 步长=0.100 x= -1000.91
```

**两个现象，RMSprop 的全部价值**：(1) 教材例里账本 $E$ 从 1.6 到 2.99，平滑更新——**RMSprop 正常学习**；(2) 决定性对照里，梯度恒为 1：**Adagrad 的步长从 $10^{-1}$ 衰减到 $10^{-3}$（100 倍收缩，$x$ 只走到 -19.85），RMSprop 的步长稳定在 0.100（$x$ 匀速走到 -1000.91）**——因为 RMSprop 的滑动平均账本收敛到稳态（$\sqrt{1}=1$），步长不再死亡。**"累加"让学习率衰亡，"滑动平均"让学习率永生。**

## 层二：分步逐函数拆解

### 步骤 1：教材例——滑动账本

```python
E = beta * E + (1 - beta) * g ** 2   # 滑动平均账本
x = x - alpha * g / (np.sqrt(E) + eps)  # 更新
```

#### 滑动平均账本 `E = beta*E + (1-beta)*g**2`

**操作**：$E[g^2]_t = \beta E[g^2]_{t-1} + (1-\beta)g_t^2$——旧账保留 `beta=0.9` 份，新账混入 `0.1` 份。
**输入**：`E`（旧账本）、`g`（当前梯度）。**输出**：新账本。
**可调参数**：`beta=0.9` 是记忆长度。调 `0.99`——记忆更长、更平滑、反应更慢；调 `0.5`——几乎只记当下、波动大。
**与 Adagrad 的唯一区别**：Adagrad 是 `E += g**2`（累加，账本无限增长），RMSprop 是 `E = beta*E + (1-beta)*g**2`（滑动平均，账本收敛到稳态）——**一个 `beta*` 和一个 `(1-beta)*`，就是"永生"与"死亡"的差别。**

#### 更新 `x = x - alpha*g/(np.sqrt(E)+eps)`

**操作**：$\theta \leftarrow \theta - \frac{\alpha}{\sqrt{E}+\varepsilon}g$——和 Adagrad 的更新**一模一样**，唯一的区别在上面的账本更新。
**输入**：`x`、`alpha`、`E`、`g`、`eps`。**输出**：更新后的 `x`。
**可调参数**：`alpha=0.01` 是全局学习率。**关键**：`E` 稳定 → 步长 $\alpha/\sqrt{E}$ 稳定。

**对应数学**：主线定义块的 RMSprop 更新规则。

---

### 步骤 2：决定性对照——梯度恒为 1

```python
Ga += 1.0                            # Adagrad: 累加
xa = xa - 0.1 / (np.sqrt(Ga) + 1e-8)
Er = beta * Er + (1 - beta) * 1.0    # RMSprop: 滑动平均
xr = xr - 0.1 / (np.sqrt(Er) + 1e-8)
```

#### Adagrad 账本 `Ga += 1.0`

**操作**：梯度恒为 1，账本 `Ga` 每步加 1，于是 `Ga = t`——**线性增长，永不停止**。步长 $0.1/\sqrt{t}$ 单调衰减。
**输入**：`Ga`。**输出**：新账本。
**看点**：$t=10000$ 时 `Ga=10000`，步长 $0.1/100=0.001$——比最初缩小 100 倍。

#### RMSprop 账本 `Er = beta*Er + (1-beta)*1.0`

**操作**：梯度恒为 1，滑动平均 $E_r = 0.9E_r + 0.1$——**这是几何级数，收敛到 $E_r = 1$**（稳态）。步长 $0.1/\sqrt{1}=0.1$ 稳定不变。
**输入**：`Er`。**输出**：新账本。
**看点**：$t=100$ 后 `Er≈1`，步长稳定在 0.100——**账本有稳态，学习率不会死**。

**对应数学**：主线"RMSprop 解决 Adagrad 的学习率衰减"——用"账本是否收敛到稳态"一图说清。

---

### 步骤 3：打印对照

```python
print(f"t={t:5d}: Adagrad 步长={0.1/np.sqrt(Ga):.2e} x={xa:8.2f}"
      f" | RMSprop 步长={0.1/np.sqrt(Er):.3f} x={xr:9.2f}")
```

**操作**：并排打印两种方法的步长与位置。**看点**：Adagrad 步长从 $10^{-1}$ 衰减到 $10^{-3}$（x 龟速），RMSprop 步长恒为 0.100（x 匀速）——**"衰减"与"稳定"的对照，就是 Adagrad 与 RMSprop 的全部区别。**

## 实验台：让滑动账本现出真身

1. **换 β**：`beta=0.99`——账本记忆更长、更平滑，但步长收敛更慢；`beta=0.5`——账本更"敏感"，步长波动更大。**β 是"稳定 vs 响应"的旋钮。**
2. **对照真实收敛**：$f(x)=(x-2)^2$ 上跑 100 步，RMSprop 能精确收敛到 2 吗？对比 Adagrad（步长衰减，收敛慢）。**"滑动账本"在真实问题上的胜利。**
3. **换成病态 2D**：$J=\theta_1^2+100\theta_2^2$ 上比较 RMSprop 与 Momentum——RMSprop 自适应步长（每参数），Momentum 平滑方向。**两个"单招"各自擅长什么。**
4. **用 torch.optim.RMSprop**：`torch.optim.RMSprop([x], lr=0.01, alpha=0.9)` 验证教材例——**注意 PyTorch 里衰减率参数叫 `alpha`，别和全局学习率 `lr` 搞混。**

**对应数学**：实验 3 预告 §5.6.7——Adam 把 RMSprop 的滑动账本（二阶矩）和 Momentum 的惯性（一阶矩）合二为一。
