# 历史：RMSprop——一段课堂上改变世界的幻灯片

## 2012 年，Coursera：辛顿没有投稿，只讲了六页讲义

深度学习历史上最奇特的算法之一，RMSprop，**从来没有发表过论文。** 它的"出生证明"，是 2012 年杰弗里·辛顿在 Coursera 开设的《Neural Networks for Machine Learning》课程里的一段课堂讲义。

那一年，辛顿在给神经网络初学者讲优化。他提到 Adagrad 有个致命问题：**账本只增不减，学习率持续衰减，训练后期"学不动了"。** 然后他在讲义里写了三行公式，建议把 Adagrad 的"累加账本"换成"滑动平均账本"：

$$E[g^2]_t = \beta E[g^2]_{t-1} + (1-\beta) g_t^2$$
$$\theta_{t+1} = \theta_t - \frac{\alpha}{\sqrt{E[g^2]_t}+\epsilon}\, g_t$$

没有华丽的论文标题，没有严格的收敛证明——只是一段课堂建议，和一个名字：**RMSprop**。学生记下公式，各奔东西。**一个改变了深度学习优化格局的算法，最初只是讲课人的一段即兴。**

## 为什么"滑动平均"是那年的关键一步

要理解 RMSprop 的重要性，得回到 2011-2012 年的困境。

Adagrad（2011）刚给世界带来"逐参数自适应学习率"，却被自己的"累加账本"困住：只要梯度不消失，账本无限增长，学习率无限衰减。对凸问题这还勉强可以接受（后期小步更精确）；但对**非凸的深度网络**（§5.4），训练后期常常还需要大步调整——Adagrad 却已经"死了"。

辛顿的滑动平均账本，是一记精确的手术：**不再记住全部历史，只记住"近期梯度平方的加权平均"**（旧账按 $\beta$ 衰减、新账按 $1-\beta$ 混入）。这样账本会**收敛到一个稳态**——当梯度稳定时，$E[g^2]$ 稳定在 $g^2$ 的平均附近，学习率不再衰减到零。**一个从"无限增长"到"稳态收敛"的改动，让自适应优化器从"短命"变成了"可长期训练"。**

2012 年正是深度学习大爆发的前夜——AlexNet 在 ImageNet 上震惊世界，深度网络的训练需要能长期跑下去的自适应优化器。RMSprop 的"学习率不会死"让它顺理成章地成为深度训练的重要工具，尤其适合梯度尺度剧烈变化的 **RNN/LSTM**。

## 2013-2014：从课堂讲义到 Adam 的"另一半"

RMSprop 虽然没发表论文，却在 2013-2014 年迅速传播。Graves 等人在 RNN 训练里独立地用到了类似的"均方根"归一化；深度学习的实践者们在论坛、代码库里互相传阅辛顿的讲义——**一个没发表的算法，靠"效果好"完成了传播。**

2014 年，Kingma 与 Ba 发表 Adam 时，他们的论文里明确把 RMSprop 的滑动平均账本当作二阶矩的来源——**Adam = 动量（§5.6.4）+ RMSprop 的滑动平均账本 + 偏差校正**。RMSprop 从"课堂讲义"变成了"Adam 的半壁江山"。

有趣的历史注脚：因为 RMSprop 从未正式发表，它的"出生证明"一直存在争议——不同人引用不同的讲义版本，公式里的符号（$\beta$ 还是 $\gamma$）也不统一。**但这不妨碍它成为深度学习最重要的算法之一。** 它提醒我们：在深度学习这个领域，**"被写进论文"与"改变世界"并不总是一回事——一段课堂讲义，也可以托起一个时代。**

## 2014 至今：被 Adam 覆盖，但从未消失

2014 年后，Adam 因为"免调参 + 快 + 稳"几乎全面覆盖了 RMSprop 的使用场景。今天你打开 PyTorch，很少单独用 `torch.optim.RMSprop`——但它从未消失：

- **Adam 的二阶矩**：你每天调的 `betas=(0.9, 0.999)`，其中 `0.999` 就是 RMSprop 的滑动平均账本。
- **RNN 训练**：某些非平稳任务上，RMSprop 依然有它的位置。
- **思想遗产**："用滑动平均代替累加"——从 BatchNorm 的 running statistics 到 EMA 权重平均，这个模式遍布深度学习的每个角落。

**一个从未发表论文的课堂讲义，成了 Adam 的骨头、深度学习的标配。** 这是优化史（乃至整个深度学习史）里最反"学术等级"的故事之一：有时候，真正改变世界的，不是顶会论文，而是一个老师愿意在课堂上分享的"三行公式"。

## 门，通向主线

从 2012 年辛顿的六页讲义，到 2014 年 Adam 的登基——RMSprop 用"把累加换成滑动平均"这一字之差，治愈了 Adagrad 的学习率死亡，也把自己写进了 Adam 的基因。它教会我们：**进步不总是来自更复杂的公式，有时只是来自"该记多久"这个朴素问题的答案。** 现在，该亲手滑动一次账本了——看那个稳定的步长，如何让训练一路走下去，不死亡、不枯竭。
