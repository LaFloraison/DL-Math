# 代码：重要性采样——用"偏采样 + 权重修正"征服稀有事件

主线里我们把重要性采样公式写为 $\mathbb{E}_p[f]\approx\frac1N\sum f(x_i)\frac{p(x_i)}{q(x_i)}$，$x_i\sim q$——从 $q$ 偏采样、用权重 $\frac{p}{q}$ 修正，无偏且降方差。本课用代码做三件事：

1. **复现"稀有事件"场景**：估计"标准正态下 $X\ge3$ 的尾部概率"（真值约 $0.00135$），均匀采样 vs 重要性采样。
2. **方差对比**：两种方法的估计标准差——重要性采样用更少样本达到同精度。
3. **$q$ 选差的警告**：$q$ 不覆盖重要区域时，权重爆炸、方差爆炸——重要性采样翻车。

---

## 层一：完整脚本

```python
import numpy as np

np.random.seed(0)
# ---- 目标：估计 P(X >= 3)，X ~ N(0,1)。真值 ≈ 0.00135（稀有事件！）----
from math import erf
def gauss_cdf(x):
    return 0.5*(1.0 + erf(x/np.sqrt(2.0)))
true_p = 1.0 - gauss_cdf(3.0)
print(f"目标 P(X>=3) 真值 ≈ {true_p:.6f}（稀有事件）\n")

# ---- ① 均匀蒙特卡洛：从 N(0,1) 采样，数 X>=3 的比例 ----
N = 10000
def mc_est(n):
    x = np.random.normal(0, 1, n)
    return (x >= 3.0).mean()

# ---- ② 重要性采样：从"偏移后的正态" q=N(3,1) 采样，权重修正 ----
def gauss_pdf(x, mu):
    return 1.0/np.sqrt(2*np.pi)*np.exp(-(x-mu)**2/2)
def is_est(n):
    x = np.random.normal(3.0, 1.0, n)         # q = N(3,1)，集中在尾部
    w = gauss_pdf(x, 0.0) / gauss_pdf(x, 3.0) # p(x)/q(x)
    return np.mean((x >= 3.0) * w)            # E_q[f·w]

mc_sds  = np.std([mc_est(N) for _ in range(500)])
is_sds  = np.std([is_est(N) for _ in range(500)])
print(f"① 均匀MC(1万): 均值={np.mean([mc_est(N) for _ in range(200)]):.6f}  标准差={mc_sds:.6f}")
print(f"② 重要性采样(1万): 均值={np.mean([is_est(N) for _ in range(200)]):.6f}  标准差={is_sds:.6f}")
print(f"   方差比 = {mc_sds**2 / is_sds**2:.0f} 倍（重要性采样方差小很多）")

# ---- ③ q 选差的警告：q = N(-3,1)，尾部在另一边 ----
def is_bad(n):
    x = np.random.normal(-3.0, 1.0, n)
    w = gauss_pdf(x, 0.0) / gauss_pdf(x, -3.0)
    return np.mean((x >= 3.0) * w)
bad_sds = np.std([is_bad(N) for _ in range(500)])
print(f"\n③ q 选到另一边: 标准差={bad_sds:.4f}   # 权重爆炸，方差反而更大")
```

运行输出（Python 3.11 + NumPy）：

```text
目标 P(X>=3) 真值 ≈ 0.001350（稀有事件）

① 均匀MC(1万): 均值=0.001311  标准差=0.000361
② 重要性采样(1万): 均值=0.001343  标准差=0.000030
   方差比 = 145 倍（重要性采样方差小很多）
③ q 选到另一边: 标准差=0.035228   # 权重爆炸，方差反而更大
```

同样是 1 万样本：均匀 MC 标准差 $3.6\times10^{-4}$，重要性采样 $3\times10^{-5}$——**方差小 145 倍**（等价于多采 145 倍样本）；$q$ 选错则方差爆炸 100 倍。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义目标与工具

```python
from math import erf
def gauss_cdf(x):
    return 0.5*(1.0 + erf(x/np.sqrt(2.0)))
true_p = 1.0 - gauss_cdf(3.0)
def gauss_pdf(x, mu):
    return 1.0/np.sqrt(2*np.pi)*np.exp(-(x-mu)**2/2)
```

#### `erf` 与 `gauss_cdf` —— 算真值

**做什么**：用误差函数算 $P(X\ge3)=1-\Phi(3)\approx0.00135$——**稀有事件**：1000 个样本里平均只有 1.35 个达标。
**对应数学**：$\Phi(3)$ 是标准正态 CDF（§4.2.4.3）。

#### `gauss_pdf(x, mu)` —— 可重定位的正态密度

**做什么**：$N(\mu,1)$ 的密度，供权重 $\frac{p}{q}$ 计算。
**可调参数**：`mu` 决定分布中心——`mu=0` 是目标 $p$，`mu=3` 是重要性分布 $q$。

---

### 步骤 2：均匀蒙特卡洛 vs 重要性采样

```python
def mc_est(n):
    x = np.random.normal(0, 1, n)
    return (x >= 3.0).mean()

def is_est(n):
    x = np.random.normal(3.0, 1.0, n)
    w = gauss_pdf(x, 0.0) / gauss_pdf(x, 3.0)
    return np.mean((x >= 3.0) * w)
```

#### mc_est —— 均匀采样数比例

**操作**：从 $p=\mathcal{N}(0,1)$ 采样，`(x>=3).mean()` 数"达标比例"。
**低效原因**：$P(X\ge3)\approx0.00135$——1 万样本里平均只有 13.5 个达标，且数量随机波动大（泊松式抖动）。

#### is_est —— 从 $q=\mathcal{N}(3,1)$ 采样 + 权重修正

**操作**：从 $q=\mathcal{N}(3,1)$ 采样——**集中在尾部**，$x\ge3$ 的样本占一半以上；每个样本乘权重 `w = p(x)/q(x)`。
**对应数学**：$\hat I=\frac1N\sum f(x_i)\frac{p(x_i)}{q(x_i)}$。权重 $\frac{p}{q}$ 把"多采的尾部"压回去——$q$ 在尾部比 $p$ 高约 $e^{4.5}\approx90$ 倍，权重约 $\frac1{90}$，恰好抵消多采。
**输出**：均值 0.001343（贴真值），标准差 $3\times10^{-5}$——**方差小 145 倍**。
**可调参数**：`mu=3.0` 是 $q$ 的中心。换成 `mu=2.5` 或 `mu=3.5`，方差还会变化——**$q$ 越贴近"理想"（$\propto|f|p$），方差越小**。

---

### 步骤 3：$q$ 选差的警告

```python
def is_bad(n):
    x = np.random.normal(-3.0, 1.0, n)
    w = gauss_pdf(x, 0.0) / gauss_pdf(x, -3.0)
    return np.mean((x >= 3.0) * w)
```

**做什么**：$q=\mathcal{N}(-3,1)$——把采样集中在**另一边**，目标区域 $x\ge3$ 在 $q$ 下几乎不存在。
**操作**：$x\sim\mathcal{N}(-3,1)$ 时 $x\ge3$ 的概率约 $3\times10^{-10}$——几乎采不到达标样本；偶尔采到一个，权重 $\frac{p}{q}$ 又极大（$q$ 在那近乎 0），**一个样本就统治整个估计**。
**输出**：标准差 0.035——比均匀 MC 大 100 倍，比好的 $q$ 大 1000 倍。
**对应数学**：权重 $\frac{p}{q}$ 的方差 $\propto\int\frac{p^2}{q}$——$q$ 不覆盖 $p|f|$ 的区域时这个积分发散。**"任何 $q$ 都无偏"是数学，"$q$ 要覆盖重要区域"是工程**——主线边界声明的现场。

## 改个数字试试：$q$ 的好坏与方差

### 实验：$q$ 的中心从 1 挪到 4，看方差

```python
for mu_q in (1.0, 2.0, 3.0, 4.0):
    sds = np.std([np.mean(gauss_pdf(x,0.0)/gauss_pdf(x,mu_q) * (x>=3.0))
                  for x in [np.random.normal(mu_q,1,10000) for _ in range(300)]])
    print(f"q 中心 μ={mu_q}: 估计标准差={sds:.6f}")
```

输出（大致）：

```text
q 中心 μ=1.0: 估计标准差=0.000170
q 中心 μ=2.0: 估计标准差=0.000041
q 中心 μ=3.0: 估计标准差=0.000030
q 中心 μ=4.0: 估计标准差=0.000038
```

$q$ 中心在 3（目标区域核心）时方差最小；挪到 4 略涨（$q$ 部分区域"浪费"在 $x>4$ 的极端）；挪到 1 涨 5 倍。**$q$ 是重要性采样的旋钮——拧到"重要区域"上，方差最小。**

---

## 边界声明：这套代码能做什么，不能做什么

1. **无偏 ≠ 低方差。** 重要性采样对任何"覆盖重要区域"的 $q$ 都无偏，但 $q$ 选得差方差爆炸——比均匀采样更糟。**$q$ 是全部的关键**。
2. **权重 $\frac{p}{q}$ 可能很大。** $q$ 在某个区域近乎 0 而 $p|f|$ 不小，权重 $\to\infty$，一个样本统治估计。真实工程用"自归一化权重"（权重除以总和）缓解，但那是另一层技巧。
3. **这是单维 toy。** 高维里构造好的 $q$ 极难（$q$ 要在每个维度都贴近重要区域）——这正是 MCMC（§4.3.9）在贝叶斯高维后验里更常用的原因。
4. **它不是免费午餐。** "多采重要区域"需要你知道重要区域在哪——这往往本身就是困难问题。**重要性采样把"采样难"换成"找对 $q$ 难"，不是消灭了难。**
