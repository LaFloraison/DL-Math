# 习题：重要性采样

## 第一组：概念检验

**1. 写出重要性采样的估计公式，并解释每一项的作用。**

**解答**：$\mathbb{E}_p[f]\approx\frac1N\sum_{i=1}^N f(x_i)\frac{p(x_i)}{q(x_i)}$，$x_i\sim q$。$p$ 是原分布，$q$ 是重要性分布（实际采样的），$f$ 是被估函数，$\frac{p(x_i)}{q(x_i)}$ 是重要性权重。**$q$ 负责"从重要区域多采样"，权重负责"把多采的压回去、少采的补回来"。**

**2. 为什么"从 $q$ 偏采样"不会引入偏差？用"乘一个 1"的推导说明。**

**解答**：$\mathbb{E}_p[f]=\int f(x)p(x)dx=\int f(x)\frac{p(x)}{q(x)}q(x)dx=\mathbb{E}_q[f(X)\frac{p(X)}{q(X)}]$。**同一个积分，只是把期望的"视角"从 $p$ 换成 $q$**——这是恒等式，不是近似。权重 $\frac{p}{q}$ 是杠杆：$q$ 多采的区域（$q>p$）权重 $<1$ 压回去，$q$ 少采的区域（$q<p$）权重 $>1$ 补回来。**采样集中在哪不重要，权重会把账拉平。**

**3. 判断题并说明理由："重要性采样从任何 $q$ 采样都是无偏的，所以 $q$ 怎么选都行。"**

**解答**：前半句对（数学），后半句错（工程）。任何"在 $f$ 非零区域也非零"的 $q$ 都保证无偏，但 **$q$ 选得差时方差爆炸**：如果 $q$ 在某个 $p|f|$ 非零的区域近乎为 0，权重 $\frac{p}{q}\to\infty$，一个样本就能统治估计——比均匀采样更糟。**"任何 $q$ 都无偏"是数学的优雅，"$q$ 要贴近重要区域"是实用的前提。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 目标：估计 $P(X\ge3)$，$X\sim\mathcal{N}(0,1)$（真值约 0.00135）。（a）为什么均匀采样低效？（b）取 $q=\mathcal{N}(3,1)$ 做重要性采样，写出每个样本的权重公式。（c）代码对比两种方法的估计标准差。

**解答**：
（a）$P(X\ge3)\approx0.00135$——1 万样本里平均只有 13.5 个达标，达标数本身随机抖动大，估计方差大。
（b）权重 $w(x)=\frac{p(x)}{q(x)}=\frac{\exp(-x^2/2)}{\exp(-(x-3)^2/2)}$——$q$ 集中在尾部，权重把多采压回去。
（c）见《代码.md》步骤 2：均匀 MC 标准差 $3.6\times10^{-4}$，重要性采样 $3\times10^{-5}$——**方差小 145 倍**。

代码验证：

```python
import numpy as np
np.random.seed(0)
def pdf(x, mu): return np.exp(-(x-mu)**2/2)/np.sqrt(2*np.pi)
N = 10000
mc = np.std([(np.random.normal(0,1,N)>=3).mean() for _ in range(300)])
is_ = np.std([np.mean(pdf(x,0)/pdf(x,3)*(x>=3)) for x in [np.random.normal(3,1,N) for _ in range(300)]])
print("均匀MC 标准差 =", round(mc, 6), " 重要性采样标准差 =", round(is_, 6))
```

输出：

```text
均匀MC 标准差 = 0.000360  重要性采样标准差 = 0.000030
```

**思路点拨**：若有人答"重要性采样均值更准所以更好"，均值两者都贴真值（无偏）——**优势在方差**：同样的样本量，重要性采样的估计波动小 145 倍，等价于"多采了 145 倍样本"。

**5. $q$ 好坏实验。** 把 $q$ 的中心从 1 挪到 4，观察估计标准差，找出最优点并解释为什么 $q$ 太大也不行。

**解答**：见《代码.md》"改个数字试试"。$q$ 中心 1→4 的标准差 $1.7\times10^{-4}\to3\times10^{-5}\to3.8\times10^{-5}$——**$q$ 中心在目标区域核心（3）时方差最小**；挪到 4 略涨（部分采样"浪费"在更极端的 $x>4$）；挪到 1 涨 5 倍。**$q$ 是重要性采样的旋钮，理想 $q\propto|f|p$——"重要区域"就是"$f$ 大且 $p$ 也不小"的地方。**

## 第三组：DL 延伸

**6. 强化学习 off-policy 场景。** 你用旧策略 $\pi_{\text{old}}$ 收集的经验数据，想估计新策略 $\pi_{\text{new}}$ 的价值。（a）用重要性采样的语言描述这个问题。（b）写出权重公式。（c）为什么 $q$（行为策略）和 $p$（目标策略）差太远会出问题？

**解答**：
（a）数据由行为策略 $q=\pi_{\text{old}}$ 生成，但你想估目标策略 $p=\pi_{\text{new}}$ 的期望回报——**从 $q$ 采样的数据，估计 $p$ 下的量**，正是重要性采样的场景。
（b）权重 $w=\frac{p(x)}{q(x)}=\frac{\pi_{\text{new}}(a|s)}{\pi_{\text{old}}(a|s)}$——**新策略与旧策略在该状态-动作下的概率比**。off-policy 的价值估计 $\approx\frac1N\sum w_i\cdot G_i$（$G_i$ 是回报）。
（c）如果 $\pi_{\text{new}}$ 与 $\pi_{\text{old}}$ 差异巨大（比如旧策略很少做新策略常做的动作），权重 $\frac{p}{q}$ 在某些点上极大——少数"新策略偏爱、旧策略几乎不做"的动作获得天文权重，方差爆炸。**这正是重要性采样"$q$ 选差方差爆炸"在 RL 里的形态**，也是 off-policy 方法要用"重要性采样截断 (importance clipping)"、PPO 限幅权重的原因。
**思路点拨**：若有人答"off-policy 就是拿旧数据继续训练"，他漏了"分布不匹配"这个核心问题——行为分布 $q$ 与目标分布 $p$ 不同，必须权重修正。若有人答"权重可以无限大"，工程上必须裁剪（clip）——正是 PPO 的核心技巧，数学根源就在本节"权重爆炸"。
