# 代码：梯度矩阵的更新——`W - αG`，并手算一个小损失的真实梯度

主线里我们看了"更新公式" $W_{\text{new}}=W-\alpha G$。这一节用 NumPy 做两件事：**① 按教材更新权重；② 手写一个最小二乘损失的梯度，看梯度矩阵是怎么从损失"长"出来的。**

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：梯度与更新

# ========== ① 教材：W - αG ==========
W = np.array([[0.5, 0.1], [0.3, 0.7]])
G = np.array([[0.02, 0.01], [0.03, 0.04]])   # 梯度矩阵
alpha = 0.1
W_new = W - alpha * G
print("W_new = W - αG =\n", W_new)
# [[0.498 0.099] [0.297 0.696]]

# ========== ② 手算一个真实梯度：最小二乘损失 ==========
# 模型: z = w·x，损失 L = 0.5*(z - y)^2，数据点 (x, y) = (2, 4)
w = np.array([0.5])                        # 单个权重
x, y = 2.0, 4.0
z = w * x
L = 0.5 * (z - y)**2
grad = (z - y) * x                         # dL/dw = (z-y)*x  （链式法则）
print(f"z={z}, L={L}, dL/dw={grad}")       # z=1.0, L=4.5, dL/dw=-6.0
w_new = w - 0.1 * grad
print(f"w_new = {w_new}  (更新后损失 L={0.5*(w_new*x - y)**2:.3f})")

# ========== ③ 多参数：梯度是"逐参数的责任表" ==========
w2 = np.array([0.5, 0.3])                  # 两个权重
x2 = np.array([2.0, -1.0])
z2 = w2 @ x2
L2 = 0.5 * (z2 - 4.0)**2
grad2 = (z2 - 4.0) * x2                    # 每个参数各得一个梯度（形状同 w2）
print(f"z2={z2}, L2={L2}, 梯度矩阵 grad2={grad2}")
w2_new = w2 - 0.1 * grad2
print(f"w2_new = {w2_new}")
```

运行输出（Python 3.11 + NumPy）：

```text

  [0.297 0.696]]

z2=0.7, L2=5.445, 梯度矩阵 grad2=[-6.6  3.3]
w2_new = [1.16 0.03]
```

## 层二：分步逐函数拆解

### 步骤 1：教材更新

```python
W_new = W - alpha * G
```

**做什么**：按公式 $W-\alpha G$ 更新权重矩阵。每个权重独立朝损失下降方向挪一点。
**操作**：`alpha * G` 数乘梯度矩阵；`W - ...` 逐元素相减（矩阵减法，§2.3.4.1）。
**可调参数**：`alpha` 是学习率——调大更新猛（可能发散）、调小更新缓（可能停滞）。`G` 是"责任表"，由反向传播算出。
**对应数学**：主线 $W_{\text{new}}=W-\alpha G$。**注意是"减"——梯度指向上升方向，更新反向。**

### 步骤 2：手算单个权重的梯度

```python
z = w * x
grad = (z - y) * x
```

**操作**：模型 $z=wx$，损失 $L=\frac12(z-y)^2$。链式法则：$\frac{dL}{dw}=\frac{dL}{dz}\frac{dz}{dw}=(z-y)\cdot x$。代入 $z=1.0,y=4,x=2$：$(1-4)\times2=-6$。
**可调参数**：换数据点，梯度变。梯度为负（$w$ 太小，该增大）——更新后 $w=1.1$，损失从 4.5 降到 3.61。
**对应数学**：主线"梯度 = $\frac{\partial L}{\partial w}$"。**这一步展示了梯度不是凭空给的，是从损失链式法则算出来的。**

### 步骤 3：多参数梯度矩阵

```python
grad2 = (z2 - 4.0) * x2
```

**操作**：两个参数的梯度各为 $(z-y)\cdot x_i$：$(0.7-4)\times2=-6.6$、$(0.7-4)\times(-1)=3.3$。**形状与 $w2$ 相同**——每个参数一格"责任"。
**可调参数**：参数越多，梯度矩阵越大；形状永远与参数一致。
**对应数学**：主线"梯度矩阵 $G_{ij}=\partial L/\partial W_{ij}$"。**注意梯度符号相反：$w_1$ 该增大（负梯度）、$w_2$ 该减小（正梯度）——这正是"不能整体更新"的原因（§2.3.6.5 撞墙）。**

## 边界声明：这套代码能做什么，不能做什么

1. **这里的梯度是我手写的链式法则**。真实网络用 `loss.backward()` 自动求导（§2.2.3.5），自动算每一层参数的梯度矩阵。手写版是为了"看懂梯度从哪来"。
2. **梯度矩阵是"一阶信息"，不含二阶曲率**。它只告诉"往哪走"，不告诉"走多远最优"——所以学习率才重要，优化器（§2.3.6.7）才存在。
3. **更新方向永远是"减梯度"**。看到 `W - alpha*G` 就想起"梯度指向上升，反向下降"（§2.2.3.5 习题 1.2）。写成 `W + alpha*G` 就是梯度上升（找最大值），别混。
4. **学习率是全局标量，但梯度逐格不同**。§2.3.6.7 的优化器会让"每格的步长"也自适应——"一张梯度矩阵 + 逐维步长"是现代训练配方。
