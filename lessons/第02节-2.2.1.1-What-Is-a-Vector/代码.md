# 代码：用 NumPy 亲手"捏"一个向量，量出它的大小与方向

主线里我们用游戏手柄感受了向量：一组数同时携带"大小"和"方向"。这一节把这句话变成代码——用 `np.array` 造向量，用 `np.linalg.norm` 量大小，用"单位化"隔离方向，再验证几个分量相同的向量的模长关系。

脚本只依赖 NumPy，约 30 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                      # NumPy：造向量、算模长，全在这里

# ---- ① 造向量：游戏里的移动指令 [右3, 上4] ----
v = np.array([3.0, 4.0])                # 二维向量，形状 (2,)
print("向量 v        =", v)
print("v 的形状      =", v.shape)

# ---- ② 用公式算模长：‖v‖ = sqrt(3² + 4²) = 5 ----
len_manual = np.sqrt(v[0]**2 + v[1]**2)
len_norm   = np.linalg.norm(v)          # 库函数：等价，更通用
print(f"手算模长      = {len_manual:.4f}")
print(f"np.linalg.norm = {len_norm:.4f}")

# ---- ③ 单位向量：把方向单独拎出来 ----
u = v / np.linalg.norm(v)               # 除以模长，得到"只有方向"的单位向量
print("单位向量 u    =", np.round(u, 4), "模长 =", np.round(np.linalg.norm(u), 4))

# ---- ④ 验证：方向相同、长度翻倍的向量 ----
w = np.array([6.0, 8.0])                # [6,8] = 2 * [3,4]
print("w =", w, "模长 =", np.linalg.norm(w))          # 应为 10 = 2*5
print("u 与 w 方向是否一致: w / ‖w‖ =", np.round(w / np.linalg.norm(w), 4))

# ---- ⑤ 高维：一张 28×28 的图片摊平成 784 维向量 ----
img_flat = np.random.rand(784)          # 784 个像素亮度 ∈ [0,1]
print("图片向量形状 =", img_flat.shape, "| 模长 ≈", np.round(np.linalg.norm(img_flat), 4))
```

运行输出（Python 3.11 + NumPy）：

```text
向量 v        = [3. 4.]
v 的形状      = (2,)
手算模长      = 5.0000
np.linalg.norm = 5.0000
单位向量 u    = [0.6 0.8] 模长 = 1.0
w = [6. 8.] 模长 = 10.0
u 与 w 方向是否一致: w / ‖w‖ = [0.6 0.8]
图片向量形状 = (784,) 主| 模长 ≈ 14.4376
```

## 层二：分步逐函数拆解

### 步骤 1：造向量 `np.array`

```python
v = np.array([3.0, 4.0])
print("v 的形状      =", v.shape)
```

#### `np.array(list)` —— 把列表变成数组

**做什么**：把 Python 列表 `[3.0, 4.0]` 转成 NumPy 的 `ndarray`——这是"向量在计算机里的存在形式"。
**操作**：`np.array` 接收列表，推断出数据类型为 `float64`，按顺序存入内存。
**输入**：一维列表 `[3.0, 4.0]`——两个浮点数。
**输出**：形状 `(2,)` 的 `ndarray`。`(2,)` 表示"一维、2 个元素"；`v[0]=3.0`、`v[1]=4.0` 就是向量的两个分量。
**可调参数**：
- 长度可变：`np.array([1.0, 2.0, 3.0])` 是三维向量。
- 传 `dtype`：`np.array([3, 4], dtype=float)` 强制转浮点；深度学习里常用 `np.float32` 省内存。
- 传嵌套列表 `np.array([[1.0],[2.0]])` 得到形状 `(2,1)` 的"列向量"——它其实是二维数组，和 `(2,)` 的语义不同（§2.3.4.3 细讲）。本课统一用 `(n,)` 的一维表示。
**对应数学**：主线里向量 $\mathbf{v} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}$ 的定义。

### 步骤 2：量模长——手算 + `np.linalg.norm`

```python
len_manual = np.sqrt(v[0]**2 + v[1]**2)
len_norm   = np.linalg.norm(v)
```

#### `np.sqrt(x)` —— 开平方根

**操作**：逐元素计算 $\sqrt{x}$。`v[0]**2` 是第一个分量的平方（`3.0**2=9.0`），两者相加后开方。
**输入**：标量或数组。
**输出**：相同形状的平方根。`np.sqrt(9.0+16.0)=np.sqrt(25.0)=5.0`。
**可调参数**：无特殊参数；`x**0.5` 效果相同。

#### `np.linalg.norm(v)` —— 计算向量模长（二范数）

**操作**：对向量 $\mathbf{v}$ 计算 $\|\mathbf{v}\|_2 = \sqrt{\sum_i v_i^2}$——与手写公式完全一致，但自动处理任意维数。
**输入**：形状 `(2,)` 的数组 `v`。
**输出**：标量 `5.0`。
**可调参数**：
- 第二参数 `ord` 控制范数类型：默认 `None`（即 2-范数）；`ord=1` 是曼哈顿距离 $\sum|v_i|$；`ord=np.inf` 是最大值范数。深度学习里最常见的还是默认的 2-范数，它对应欧氏距离。
- `axis` 参数可对矩阵的某一行/列批量求范数——§2.3 之后会用到。
**对应数学**：主线公式 $\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2}$。手算与库函数结果一致（都是 5.0），证明库函数做的就是这条公式。

### 步骤 3：单位向量——把方向单独拎出来

```python
u = v / np.linalg.norm(v)
```

#### `ndarray / 标量` —— 逐元素除法

**操作**：向量的每个分量都除以同一个数——这是**缩放 (scaling)** 的代码形式。`v / 5.0 = [3.0/5, 4.0/5] = [0.6, 0.8]`。
**输入**：`v`（形状 `(2,)`）与标量 `5.0`。
**输出**：`[0.6, 0.8]`，模长恰好为 1。
**可调参数**：除数是任何非零标量；除以 0 会得到 `inf/nan`——所以对零向量求单位向量会报错或产生 NaN，这是必须提防的边界情况。
**对应数学**：主线"模长只回答多大，方向由分量的比例决定"。单位向量 $\mathbf{u} = \mathbf{v}/\|\mathbf{v}\|$ 把所有大小信息剥掉，只留"朝哪"——它在深度学习里无处不在：归一化特征、余弦相似度的分母、神经网络权重的正交初始化。

### 步骤 4：验证"方向相同、长度翻倍"

```python
w = np.array([6.0, 8.0])
print(w / np.linalg.norm(w))
```

**操作**：`[6,8]` 是 `[3,4]` 的两倍，模长应为 $2 \times 5 = 10$；而单位化后 `w/‖w‖ = [0.6, 0.8]` 与 `u` 完全一致——**方向相同的两个向量，单位化后得到同一个向量**。
**可调参数**：换成任意倍数 `k*[3,4]`，单位化结果都一样。这正是"方向是分量的比例、与模长无关"的验证。
**对应数学**：主线"$[3,4]$ 与 $[6,8]$ 方向相同，大小差一倍"。

### 步骤 5：高维向量——784 维的图片

```python
img_flat = np.random.rand(784)
```

#### `np.random.rand(n)` —— 生成 $n$ 个 $[0,1)$ 均匀随机数

**操作**：生成一个长度 `784` 的数组，每个元素在 $[0,1)$ 内均匀随机——模拟 784 个像素的亮度。
**输入**：`n`，数组长度（也可传多个维度，如 `np.random.rand(28, 28)` 得到二维随机矩阵）。
**输出**：形状 `(784,)` 的数组。
**可调参数**：`n` 决定维数；想要正态随机用 `np.random.randn`；想要可复现，先 `np.random.seed(0)`。
**对应数学**：主线"28×28 的图片摊平成 784 维向量"——深度学习里图像进网络前的标准姿势。784 维空间里，每个点是一张图。

## 边界声明：这套代码能做什么，不能做什么

1. **`np.linalg.norm` 默认是 2-范数**，也就是欧氏长度。但"大小"不是只有这一种定义——曼哈顿范数、无穷范数各有各的几何。深度学习里大多数场景用 2-范数，但正则化（§2.3.6.6）会用 1-范数惩罚稀疏性，看到 `norm(v, ord=1)` 别慌，它量的是"分量绝对值之和"。
2. **`(n,)` 与 `(n,1)` 的坑**：`np.array([3.,4.])` 形状 `(2,)`，`np.array([[3.],[4.]])` 形状 `(2,1)`。数值一样，但一个是"向量"、一个是"矩阵"，广播与矩阵乘法行为不同。本课统一用 `(n,)`；真实框架（PyTorch）里 `(n,)` 和 `(n,1)` 同样是初学者最容易踩的形状陷阱。
3. **单位化对零向量无效**：`[0,0]` 除以 0 得 `[nan, nan]`。训练中若出现 NaN，先查是不是某一步对零向量做了归一化。
4. **这一节只"度量"，不"运算"**：向量相加、数乘、点积这些真正的"运算"是下一节（2.2.1.2）的内容。本脚本是认识向量的"体检报告"——先知道它长什么样，再学怎么用它。
