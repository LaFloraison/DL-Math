# 习题：什么是向量

## 第一组：概念检验

**1.1（单选）** 两个向量 $\mathbf{a} = [3, 4]$ 与 $\mathbf{b} = [6, 8]$ 的关系是：
- A. 方向相同、大小相同
- B. 方向相同、大小不同
- C. 方向不同、大小相同
- D. 方向不同、大小不同

**1.2（判断并说明）** "一个向量的坐标一旦写出来，就完全确定了这个向量，不会再有歧义。" 这句话对吗？提示：考虑同一个箭头在不同坐标系下的表示。

**1.3（填空）** 向量 $\mathbf{v} = [-6, 8]$ 的模长 $\|\mathbf{v}\| =$ ____；它的"方向"与 $[3, -4]$ 是否相同？____（是/否）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 分别计算 $\mathbf{a} = [1, 2, 2]$ 与 $\mathbf{b} = [3, 4, 12]$ 的模长，并求出 $\mathbf{a}$、$\mathbf{b}$ 各自对应的单位向量。用 `np.linalg.norm` 验证。

**2.2（代码验证）** 生成一个长度为 10 的向量，验证"向量除以它的模长后，新向量的模长恒为 1"这一性质——无论原向量多大或多小。

**2.3（动手理解方向）** 令 $\mathbf{v} = [\cos 30^\circ, \sin 30^\circ]$。它的模长是多少？这个向量的几何意义是什么？

## 第三组：DL 延伸

**3.1（场景判断）** 一个全连接层有 512 个输入神经元。这一层里"每个神经元的权重"在代码中应该用什么形状的数组表示？一个批次 32 个样本、每个样本 512 个特征，数据用什么形状表示？

**3.2（场景分析）** 为什么深度学习里几乎从不显式计算每个向量的"方向角"（比如用角度 $\theta$ 表示方向），而是直接用分量来表示向量？说出至少两条理由。

---

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：$\mathbf{b} = 2\mathbf{a}$，分量成比例，所以方向相同；模长 $\|\mathbf{a}\|=5$、$\|\mathbf{b}\|=10$，大小不同。
- **点拨**：判断方向是否相同，看**分量的比例**是否一致，而不是数值是否相等。

**1.2 这句话有问题。**
- **思路**：坐标是"向量在某个坐标系下的表示"，不是向量本身。同一个箭头，在旋转后的坐标系里会得到一组不同的坐标。所以"写了坐标就没有歧义"只对**固定坐标系**成立；对象（向量）本身，是独立于坐标系而存在的。
- **点拨**：这是"对象 vs 表示"分离的第一课，§2.5 线性变换会把这个区分彻底展开。

**1.3 答案：$\|\mathbf{v}\| = \sqrt{36+64} = 10$；方向与 $[3,-4]$ 相同（是）。**
- **思路**：$[-6,8] = -2 \times [3,-4]$。负的倍数只是把方向反转吗？注意：$[-6,8]$ 与 $[3,-4]$ 分量成比例（比例因子 $-2$），比例可以是负的——负数代表"反向同线"，几何上仍在同一条直线上，只是指向相反。若题目要求"完全相同"的方向，可说"在同一直线上、指向相反"。
- **点拨**：这个题考的是"比例决定方向"的精确版本：比例为正同向，为负反向。

### 第二组

**2.1**
$\|\mathbf{a}\| = \sqrt{1+4+4} = \sqrt{9} = 3$，$\mathbf{a}$ 的单位向量 $= [\tfrac13, \tfrac23, \tfrac23]$。
$\|\mathbf{b}\| = \sqrt{9+16+144} = \sqrt{169} = 13$，$\mathbf{b}$ 的单位向量 $= [\tfrac{3}{13}, \tfrac{4}{13}, \tfrac{12}{13}]$。

```python
import numpy as np
for v in ([1.0, 2.0, 2.0], [3.0, 4.0, 12.0]):
    a = np.array(v)
    print(np.linalg.norm(a), np.round(a / np.linalg.norm(a), 4))
# 3.0        [0.3333 0.6667 0.6667]
# 13.0       [0.2308 0.3077 0.9231]
```
- **思路**：模长是各分量平方和再开方；单位向量就是"分量除以模长"。
- **点拨**：注意三维公式与二维完全同构——维数增加只是多几项平方。

**2.2**
```python
import numpy as np
for _ in range(3):
    v = np.random.rand(10) * np.random.randint(1, 100)   # 随机大小
    print(np.linalg.norm(v / np.linalg.norm(v)))         # 恒为 1.0
```
- **思路**：$\left\|\frac{\mathbf{v}}{\|\mathbf{v}\|}\right\| = \frac{\|\mathbf{v}\|}{\|\mathbf{v}\|} = 1$。因为模长是"齐次的"：$\|c\mathbf{v}\| = |c|\,\|\mathbf{v}\|$。
- **点拨**：单位化是深度学习里的常用操作（如特征归一化、权重归一化），它的数学根基就是这条恒等式。

**2.3**
$\|\mathbf{v}\| = \sqrt{\cos^2 30^\circ + \sin^2 30^\circ} = 1$。几何意义：$(\cos\theta, \sin\theta)$ 是单位圆上角度 $\theta$ 处的点——它是"指向 $\theta$ 方向的单位向量"。
```python
import numpy as np
v = np.array([np.cos(np.radians(30)), np.sin(np.radians(30))])
print(np.linalg.norm(v))   # 1.0
```
- **思路**：三角恒等式 $\cos^2\theta+\sin^2\theta=1$ 正是"模长恒为 1"的另一种写法。
- **点拨**：这解释了为什么单位向量常写作 $(\cos\theta, \sin\theta)$——它把"方向"这个几何概念和三角函数连接起来。

### 第三组

**3.1 答案：每个神经元的权重是一个形状 `(512,)` 的向量；一批数据是形状 `(32, 512)` 的二维数组（张量）。**
- **思路**：一个神经元连 512 个输入，所以它身上有 512 个权重，正好一个 `(512,)` 向量。32 个样本、每样本 512 个特征，摞起来是 `(32, 512)`。
- **点拨**：这正呼应主线"权重是向量、数据是向量（批量后是张量）"。注意第 0 维放"样本数"是通行惯例。

**3.2 思路（至少两条）**
1. **分量可以计算**：方向角需要反三角函数 $\theta = \arctan(v_2/v_1)$，还要处理象限；而分量直接参与加法、点积、神经网络的前向传播。计算上用分量，几何上才"可算"。
2. **高维失效**：方向角只对二维直观（极角），到 3 维要两个角（经纬度），到 $n$ 维需要 $n-1$ 个角度——而分量表示只需 $n$ 个数，形式始终如一。
3. **与数据天然匹配**：图像、文本、特征的原始数据就是数字（像素值、词频），直接装进分量，无需先转成角度。
- **点拨**：这道题帮你看清"向量的分量表示"为什么是深度学习的事实标准——它让高维计算变得机械、统一、可批量。

## 一个"为什么有人会答错"的提醒

1.1 的 C 选项很常见——有人把"分量数字不同"当成"方向不同"，忽略了比例关系。记住判据：**方向相同 $\Leftrightarrow$ 分量成比例（同号）**。2.3 是另一个陷阱：$\cos^2+\sin^2=1$ 乍看像"某个数加另一个数等于 1"，容易被误认为 $\|\mathbf{v}\|=1$ 是巧合——它不是巧合，它就是单位圆的定义。
