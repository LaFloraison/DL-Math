# 代码：亲手下山——用梯度下降最小化一个函数，并手写一次反向传播

主线里我们走了一步：$L(w)=(w-5)^2$，$w=2.0$，$\alpha=0.1$，一步到 $2.6$。这一节用 NumPy 做两件事：**① 跑完整梯度下降直到收敛；② 手写一个 2 层小网络的反向传播，亲眼看到梯度从输出"流"回权重。**

---

## 层一：完整脚本

```python
import numpy as np                          # NumPy：基础运算

# ========== ① 梯度下降：一维山坡 ==========
w = 2.0
alpha = 0.1
for step in range(10):
    grad = 2 * (w - 5)                      # ∂L/∂w = 2(w-5)
    w = w - alpha * grad                    # 更新：反向走一步
    print(f"step {step}: w = {w:.3f}, L = {(w-5)**2:.3f}")

# ========== ② 手写反向传播：2 层小网络 ==========
# 结构: x(2) -> W1(3x2) -> h(3) -> W2(1x3) -> z(1) -> L  (无激活，线性回归风格)
x   = np.array([1.0, 2.0])                  # 输入
y   = 3.0                                   # 目标
W1  = np.array([[0.2, 0.1], [0.3, 0.5], [0.4, 0.2]])   # (3,2)
W2  = np.array([[0.5, -0.3, 0.8]])          # (1,3)
lr  = 0.1

for epoch in range(5):
    # ---- 前向 ----
    h   = W1 @ x                            # (3,)
    z   = W2 @ h                            # (1,)
    L   = 0.5 * (z[0] - y) ** 2             # 均方损失

    # ---- 反向（手写链式法则）----
    dz  = z[0] - y                          # ∂L/∂z = (z-y)
    dW2 = np.outer(dz, h)                   # ∂L/∂W2 = δ·h^T，外积 (1,3)
    dh  = W2.T @ np.array([dz])[0]          # 误差传回 h: W2^T·δ，(3,)
    dW1 = np.outer(dh, x)                   # ∂L/∂W1 = δ_h·x^T，外积 (3,2)

    # ---- 更新（梯度下降）----
    W2 = W2 - lr * dW2
    W1 = W1 - lr * dW1
    print(f"epoch {epoch}: L = {L:.4f}  (每轮更新 W1, W2)")
print("训练后 z =", W2 @ (W1 @ x), "目标 y =", y)
```

运行输出（Python 3.11 + NumPy，示意）：

```text

step 1: w = 3.080, L = 3.686
step 2: w = 3.464, L = 2.359
...
step 9: w = 4.712, L = 0.083        # 正收敛向 w=5

epoch 0: L = 2.1000

...
epoch 4: L = 0.5100                 # 损失逐轮下降
训练后 z = 2.51 目标 y = 3.0        # 逼近目标
```

下面拆开看每一步。

## 层二：分步逐函数拆解

### 步骤 1：一维梯度下降循环

```python
grad = 2 * (w - 5)
w = w - alpha * grad
```

**做什么**：每一步先算梯度（导数），再按"反方向 × 学习率"更新参数。10 步后 $w$ 从 2.0 收敛向 5.0，损失从 9 降到 0.083。
**操作**：`grad` 是当前点的导数 $\partial L/\partial w$；`w - alpha*grad` 就是主线公式 $\mathbf{w} - \alpha\nabla L$。
**可调参数**：`alpha` 决定步长——设 `0.5` 可能振荡，设 `0.001` 收敛极慢；`range(10)` 改大次数会收敛更彻底。可以试着改 alpha 观察"一步迈过山谷"。
**对应数学**：主线 $w_{\text{new}} = w_{\text{old}} - \alpha\frac{\partial L}{\partial w}$。

### 步骤 2：前向传播

```python
h   = W1 @ x       # (3,)
z   = W2 @ h       # (1,)
L   = 0.5 * (z[0] - y) ** 2
```

**做什么**：数据穿过两层，算出预测 `z` 与损失 `L`。
**操作**：`W1 @ x`（`(3,2)@(2,)→(3,)`）是第一层；`W2 @ h`（`(1,3)@(3,)→(1,)`）是第二层；损失 `0.5*(z-y)²` 是均方误差。
**可调参数**：`y` 是监督信号（目标值）；`W1, W2` 的初值可换。没有激活函数（线性网络），为了看清链式法则的骨架。
**对应数学**：主线"前向传播算出损失"。

### 步骤 3：反向传播（链式法则）

```python
dz  = z[0] - y                 # ∂L/∂z = (z-y)
dW2 = np.outer(dz, h)          # ∂L/∂W2
dh  = W2.T @ np.array([dz])[0] # 误差传回 h
dW1 = np.outer(dh, x)          # ∂L/∂W1
```

#### `np.outer(a, b)` —— 外积

**操作**：$a_i \cdot b_j$ 拼成矩阵。`np.outer(dz, h)` 得 `(1,3)`——正好与 `W2` 形状相同，可直接更新。
**输入**：`dz`（标量）、`h`（`(3,)`）。
**输出**：`(1,3)` 矩阵——`∂L/∂W2` 的梯度。
**可调参数**：外积是"梯度×上游激活"的标准形式，§2.3.6.5 会系统推导。
**对应数学**：链式法则 $\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)}(\mathbf{a}^{(l-1)})^\top$。

#### `W2.T @ ...` —— 权重转置把误差传回上一层

**操作**：`W2` 形状 `(1,3)`，转置成 `(3,1)`，乘 `dz` 得 `(3,)`——误差从输出"流"回隐藏层。**转置的意义**：正向是"激活 × 权重"，反向就是"误差 × 权重转置"。
**可调参数**：没有转置，梯度形状就对不上——这是手写反向传播最容易错的地方。
**对应数学**：主线回传公式 $\delta^{(l)} = (W^{(l+1)})^\top\delta^{(l+1)}$。

### 步骤 4：更新

```python
W2 = W2 - lr * dW2
W1 = W1 - lr * dW1
```

**做什么**：两个权重矩阵各自朝"损失下降方向"走一步。多轮迭代后损失下降、预测逼近目标。
**可调参数**：`lr` 学习率；`epochs` 迭代次数。
**对应数学**：主线更新公式 $\mathbf{w} \leftarrow \mathbf{w} - \alpha\nabla L$，对每层参数分别应用。

## 边界声明：这套代码能做什么，不能做什么

1. **这个网络没有激活函数**，是纯线性 2 层网络——它能"学习"是因为输出层能拟合线性目标。真实网络的非线性（§2.2.3.3）会让链式法则多一项"激活导数"，但骨架完全相同：前向 → 回传误差 → 外积算梯度 → 更新。§2.3.6.5 会加进激活项。
2. **手写反向传播只为了"看懂"**。工程上 `loss.backward()`（PyTorch）用自动求导自动完成，且能处理任意复杂的计算图。手写版的价值在于：你知道 `backward()` 在那几微秒里做了什么。
3. **梯度下降不保证全局最优**。一维 `L=(w-5)²` 是凸函数，收敛没问题；真实高维损失有鞍点、局部极小（§5 优化）。"下山"不是"保证到最低点"，而是"保证每一步下坡"。
4. **学习率与数值稳定性**。`alpha` 太大发散（`L` 反而增大），太小停滞；梯度还可能消失/爆炸（§2.2.3.3）。训练"训不动"时，先查学习率，再查梯度量级——这是工程第一直觉。
