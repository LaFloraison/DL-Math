# 习题：梯度下降与反向传播

## 第一组：概念检验

**1.1（单选）** 损失 $L(w) = (w-5)^2$ 在 $w = 2.0$ 处的梯度 $\frac{\partial L}{\partial w}$ 是：
- A. $-6$
- B. $6$
- C. $-3$
- D. $9$

**1.2（判断并说明）** "梯度指向损失下降最快的方向，所以我们应该沿着梯度方向更新参数。" 这句话哪里有问题？

**1.3（填空）** 反向传播的核心数学工具是微积分的____；它把输出端的误差从____往前逐层传回，从而高效计算每个参数的梯度。梯度下降的更新公式是 $\mathbf{w}_{\text{new}} = \mathbf{w}_{\text{old}} - \underline{\qquad}$。

**2.2（代码验证）** 把学习率分别设为 $0.1$、$0.5$、$1.5$，各跑 20 步，记录 $w$ 的轨迹。哪个学习率收敛最快？哪个发散？解释原因。

## 解答与思路点拨

### 第一组

**1.1 答案：A（$-6$）。**
- **思路**：$\frac{\partial L}{\partial w} = 2(w-5)$，代入 $w=2$：$2(2-5) = -6$。导数为负，说明 $w$ 增大时损失减小——所以要"反向"更新（增大 $w$）。
- **点拨**：梯度符号很关键。负数梯度 + 更新公式 $w - \alpha\nabla L$ = $w +$ 正值 → $w$ 变大 → 靠近 5。B（+6）是只算了 $2(w-5)$ 忘了代入时的符号思维。

**1.2 梯度指向的是损失**上升**最快的方向，不是下降。**
- **思路**：梯度 $\nabla L$ 定义就是"各方向偏导组成的向量"，它指向函数值增长最快的方向。要下降，必须朝梯度的**反方向**：$\mathbf{w} - \alpha\nabla L$。
- **点拨**：这是"梯度下降"名字里"下降"的含义——先算出上升方向，再反向走。说"沿梯度方向更新"的人，把方向搞反了。

**1.3 答案：链式法则；输出（最后一层/损失端）；$\alpha \nabla L$。**
- **思路**：反向传播 = 链式法则把误差从输出端逐层传回；更新公式 $\mathbf{w} - \alpha\nabla L$。
- **点拨**：把"链式法则"与"反向传播"绑在一起记：**反向传播就是链式法则在多层网络上的高效实现。**

### 第二组

**2.1**
第 1 步：$\nabla = 2(2-5)=-6$，$w_1 = 2 - 0.1(-6) = 2.6$，$L=(2.6-5)^2=5.76$。
第 2 步：$\nabla = 2(2.6-5)=-4.8$，$w_2 = 2.6 - 0.1(-4.8) = 3.08$，$L=(3.08-5)^2=3.686$。
第 3 步：$\nabla = 2(3.08-5)=-3.84$，$w_3 = 3.08 - 0.1(-3.84) = 3.464$，$L=(3.464-5)^2=2.359$。

```python
import numpy as np
w, alpha = 2.0, 0.1
for _ in range(3):
    grad = 2*(w-5); w -= alpha*grad
    print(w, (w-5)**2)
```
- **思路**：每步"梯度 → 反向更新 → 重算损失"。梯度绝对值逐步变小（$6→4.8→3.84$），因为 $w$ 越来越接近 5——**越靠近谷底，坡越缓**。
- **点拨**：这正是梯度下降的收敛模式：开始大步、接近时小步。$L$ 从 9 单调降到 2.36。

**2.2**
```python
w0 = 2.0
for alpha in (0.1, 0.5, 1.5):
    w = w0; traj = []
    for _ in range(20):
        w -= alpha * 2*(w-5); traj.append(w)
    print(alpha, np.round(traj[-1], 3))
# 0.1 → 4.972（慢速逼近 5）
# 0.5 → 5.000（几步就收敛）
# 1.5 → 振荡：w 在 5 两侧反复横跳（发散或振荡）
```
- **思路**：$\alpha=0.1$ 太保守；$\alpha=0.5$ 恰好一步半程（最优的"冷静"步长）；$\alpha=1.5 > $ 最优步长 1，$w$ 越过 5 跑到另一侧，来回振荡。
- **点拨**：对二次函数 $L=(w-5)^2$，最优步长是 $1/\text{二阶导} = 1/2 = 0.5$。$\alpha > 2\times0.5$ 就发散。**学习率过大 → 振荡/发散，过小 → 收敛慢**——这是调参的第一课。

**2.3**
$L = \frac12(z-y)^2$，$z = W_2 \cdot h$，故 $\frac{\partial L}{\partial W_{2,0j}} = \frac{\partial L}{\partial z}\frac{\partial z}{\partial W_{2,0j}} = (z-y)h_j$。这正等于 `np.outer(dz, h)[0,j]`。

```python
dz = z[0]-y; h = W1 @ x
for j in range(3):
    print(dz * h[j], np.outer(dz, h)[0, j])   # 两列相等
```
- **思路**：链式法则逐项展开，$\frac{\partial z}{\partial W_{2,0j}} = h_j$（因为 $z = \sum_j W_{2,0j}h_j$）。
- **点拨**：这就是"外积 = 梯度×激活"的来历。看懂这一行，§2.3.6.5 的梯度矩阵公式就不神秘了。

### 第三组

**3.1 思路**
- `.grad` 里存的是**损失对该参数的梯度** $\frac{\partial L}{\partial w_i}$——即"这个旋钮往哪转、损失降得快"。它是反向传播（链式法则）算出来的。
- `optimizer.step()` 执行**梯度下降更新**：$w_i \leftarrow w_i - \alpha \cdot \text{grad}_i$（不同优化器还有动量、自适应步长，§2.3.6.7）。之后 `optimizer.zero_grad()` 把 `.grad` 清零，为下一轮重新累积。
- **点拨**：前向（算损失）→ backward（填 .grad）→ step（更新）→ zero_grad（清空）——这是 PyTorch 训练循环的"四步舞"，对应本节的"算梯度 → 更新"两件事。

**3.2 思路**
- 最可能：**梯度消失 (vanishing gradient)**。反向传播逐层乘链式因子，每层含 Sigmoid 导数 $\sigma'(z) = \sigma(z)(1-\sigma(z)) \le 0.25$。20 层连乘，梯度 $\le 0.25^{20} \approx 9\times10^{-13}$——浅层梯度趋近 0，参数几乎不更新，loss 不降。
- **改法**：(1) 激活换 ReLU 家族（正区间导数 1，不衰减）；(2) 用更好的初始化（He/Xavier，§2.5.3.5）让信号起始不消失；(3) 加 BatchNorm（§2.3.6.8）稳定每层分布；(4) 用残差连接（ResNet，§9 拓扑）提供"梯度高速公路"。
- **点拨**：**"训不动"先怀疑梯度流**——梯度消失（太小）或爆炸（太大）。这是深度学习工程师的诊断第一课。§2.3.6.5 会从矩阵角度再解释为什么链式连乘会这样。
