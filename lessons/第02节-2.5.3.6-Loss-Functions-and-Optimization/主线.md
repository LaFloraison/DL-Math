## 第一步：Toy Model —— 盲人下山

你是一个盲人，站在一片大雾里。脚下是山坡。你要做的只有一件事：走到山谷的最低处。

你看不见整座山，连脚下两米之外都看不见。你能获得的全部信息只有一处——脚底那一点地面：朝哪个方向踩下去，路是升还是降？坡有多陡？

你的办法很笨但很可靠：摸到脚下的坡度，朝"下坡"方向迈一小步；到了新位置，再摸，再迈。只要每一步都朝下走，你的海拔就只降不升。重复几百次，你自然停在谷底。

给你一个具体数字。假设你此刻站在 $w = 3$ 的位置，脚底传来的坡度是 $+4$——意思是：如果把 $w$ 调大一点，地面会上升，每增大 1 单位海拔升高约 4；把 $w$ 调小一点，地面会下降。于是你朝 $w$ 减小的方向迈了 0.1 步，来到 $w = 2.9$，海拔降了一些。

这就是"优化 (optimization)"。给这套画面换个名字：

- 山的形状，由**损失函数 (loss function)** 画出来——它是"当前位置有多糟"的地形图
- 你脚下的海拔，是**损失 (loss)**——一个数字，衡量此刻你离目标有多远
- 脚底那一点的坡度，是**梯度 (gradient)**——它告诉你朝哪个方向走海拔会降、降多快

现在把镜头拉到神经网络门口。那座"山"住在**参数空间**里：每个坐标轴是一根权重，几百万个轴；山脚（损失最小处）是那组"让预测最准"的权重。数据不变，山就不变；你训练，就是在山里摸黑下山。

直觉到这里完全够用——但请你立刻认真问自己三个问题：

1. 脚下的"坡度"到底怎么**算**出来？它不是摸出来的，得从损失函数的解析式里精确算出来。怎么算？
2. 每一步该迈多大？0.1 吗？如果谷底又窄又陡，迈大了会不会直接迈过头，冲到对面山坡上？
3. 神经网络里有几百万个轴，你只能知道其中一个轴的坡度，却要同时决定几百万个轴各自朝哪动。一只脚，怎么顾得过来？

直觉在这里撞墙了。我们需要的，是精确的语言。

## 第二步：正式数学讲解

### 一、撞墙：怎么把"预测得好不好"变成一把尺子

你的模型输出预测值 $\hat{\mathbf{y}}$，手里有真实值 $\mathbf{y}$。要衡量"差多少"，最直接的想法是相减：$\hat{y}_i - y_i$。

这个想法立刻撞墙。看一个具体例子——教材给的：预测值 $\hat{\mathbf{y}} = [2, 3]$，真实值 $\mathbf{y} = [1, 4]$。两个样本的误差分别是：

$$2 - 1 = 1, \qquad 3 - 4 = -1$$

如果你直接把误差加起来取平均：$\frac{1 + (-1)}{2} = 0$。荒谬！两个样本明明各偏了 1，平均误差却是 0——你的模型看起来"完美无缺"。一正一负，互相抵消了。

平方能救你。$1^2 = 1$，$(-1)^2 = 1$——不管偏多还是偏少，偏差都变成正的，只会叠加、永不抵消。于是：

$$\frac{1^2 + (-1)^2}{2} = \frac{1 + 1}{2} = 1$$

这个 1，才是诚实的总偏差：平均而言，每个样本的预测偏了约 1。

现在停下来追问一句：如果下个任务有 100 个样本，你是不是要从头再写一遍这个式子？再下个任务有 1000 个呢？——你盯着 $1^2 + (-1)^2$ 看。这个 1 和 −1 有什么特殊之处吗？没有。它们不过是"第 $i$ 个样本的误差"，写成 $\hat{y}_i - y_i$ 就行。**把具体数字换成字母**：

> **均方误差 (Mean Squared Error, MSE)** $\mathcal{L}(\hat{\mathbf{y}}, \mathbf{y})$
>
> 预测值向量 $\hat{\mathbf{y}}$ 与真实值向量 $\mathbf{y}$ 的平均平方偏差——一个非负的标量 (scalar)，越小代表预测越准。
>
> $$\mathcal{L} = \frac{1}{n}\sum_{i=1}^{n}\big(\hat{y}_i - y_i\big)^2$$
>
> - $n$：样本个数
> - $y_i$：第 $i$ 个样本的真实值 (actual value)
> - $\hat{y}_i$：第 $i$ 个样本的预测值 (predicted value)
> - $\frac{1}{n}$：平均——把"总误差"变成"平均误差"，不随样本量膨胀
> - 平方：把负偏差翻正、永不相消，且对大误差加重惩罚
> - 重要性质：$\mathcal{L} \ge 0$，且 $\mathcal{L} = 0$ 当且仅当全部 $\hat{y}_i = y_i$（预测完全命中）

检验教材的例子：$n=2$，$\mathcal{L} = \tfrac{1}{2}\big[(2-1)^2 + (3-4)^2\big] = \tfrac{1}{2}[1 + 1] = 1$。与手算一致。

### 二、损失是权重空间的标量函数——一座山被"标量化"了

MSE 里的预测值不是天上掉下来的——它来自模型。最朴素的模型就是上一节见过的 dense layer：$\hat{\mathbf{y}} = \mathbf{W}\mathbf{x} + \mathbf{b}$，输入 $\mathbf{x}$ 经过权重矩阵 $\mathbf{W}$ 与偏置 $\mathbf{b}$ 的线性变换（教材图 2.13 画的正是这件事：蓝色输入向量被权重与偏置变换成红色输出向量）。把 $\hat{y}_i = \mathbf{W}\mathbf{x}_i + \mathbf{b}$ 代进 MSE：

$$\mathcal{L}(\mathbf{W}, \mathbf{b}) = \frac{1}{n}\sum_{i=1}^{n}\big(\mathbf{W}\mathbf{x}_i + \mathbf{b} - y_i\big)^2$$

看这个式子本身。左边是 $\mathbf{W}$ 和 $\mathbf{b}$ 的函数，右边是一个数。**损失函数把整个参数空间压成了一个标量**——$d$ 个权重，决定一个数。这是个深刻的收缩：$\mathcal{L} : \mathbb{R}^d \to \mathbb{R}$。两个权重，它是一张曲面；几百万个权重，它就是几百万维空间里的一座地形。**你要找的，就是这座地形的最低点。**

### 三、撞墙 again：怎么"找到最低点"？

你已经有了尺子（损失），也有了地形（损失是权重的函数）。接下来的问题是残酷的：怎么找到最低点？

你可能会说：把每个 $\mathbf{W}$ 都试一遍，看哪个损失最小。马上撞墙——$\mathbf{W}$ 的每个元素是连续实数，取值无穷多；一个 7 亿参数的模型，穷举等于把宇宙的所有原子都用完都不够。**在连续空间里，"试遍"是物理上不可能的。**

但盲人给了我们答案：不用试遍，只需要**每一步朝下坡走**。而"下坡方向"正是那个"算出来的坡度"——梯度。

回到具体数字。在 $w = 3$ 处，$\frac{d\mathcal{L}}{dw} = +4$。含义：$w$ 每增大 1，损失约上升 4；每减小 1，损失约下降 4。为了让损失下降，$w$ 应该朝梯度的**反方向**走：

$$w \leftarrow 3 - 0.1 \times 4 = 2.9$$

那个 0.1，是你为自己设的步长——学习率 (learning rate)。走完一步，到 $w = 2.9$ 再算新坡度，再走一步。这就是**梯度下降 (gradient descent)** 的全部。

再追问一次：这个式子里的 3、4、0.1 有特殊之处吗？没有。$3$ 只是"当前在哪"，换成任何 $\mathbf{W}^{(t)}$；$4$ 只是"脚下的坡度"，换成 $\nabla_{\mathbf{W}}\mathcal{L}$；$0.1$ 只是步长，换成 $\eta$。**换字母**：

> **梯度下降 (Gradient Descent)**
>
> 从任意初始权重 $\mathbf{W}^{(0)}$ 出发，反复沿损失函数梯度的反方向更新权重：
>
> $$\mathbf{W}^{(t+1)} = \mathbf{W}^{(t)} - \eta\, \nabla_{\mathbf{W}}\mathcal{L}\big(\mathbf{W}^{(t)}\big)$$
>
> - $\mathbf{W}^{(t)}$：第 $t$ 步迭代时的权重矩阵/向量，形状与模型真实参数完全一致
> - $\nabla_{\mathbf{W}}\mathcal{L}$：损失对权重的梯度——**与 $\mathbf{W}$ 形状相同的矩阵**，其第 $(i,j)$ 个元素是 $\mathcal{L}$ 对 $W_{ij}$ 的偏导数 $\partial\mathcal{L}/\partial W_{ij}$
> - $\eta$：学习率，正数，控制每一步迈多大（常用 $10^{-3} \sim 10^{-1}$）
> - 直觉：梯度指向"损失上升最快"的方向，取负号即"下降最快"；这一步把权重往谷底方向挪动 $\eta$ 倍的坡度
> - 学习率的双刃：$\eta$ 太大——一步跨过谷底，在谷两侧来回震荡甚至发散 (diverge)；$\eta$ 太小——蚂蚁爬，几千步才挪一点

### 四、梯度怎么算？教材那句"权重更新是误差的线性变换"

梯度不是黑盒。对 MSE 加线性模型，它可以一步步推出来——这是本节最值得亲手做一遍的推导。

设模型输出 $\hat{y}_i = \mathbf{W}\mathbf{x}_i$（暂时略去偏置，原理不变）。链式法则一层层剥开：

$$\mathcal{L} = \frac{1}{n}\sum_i (\hat{y}_i - y_i)^2 \quad\Longrightarrow\quad \nabla_{\mathbf{W}}\mathcal{L} = \frac{2}{n}\sum_i \big(\hat{y}_i - y_i\big)\,\mathbf{x}_i^\top = \frac{2}{n}\,\mathbf{X}^\top \mathbf{e}$$

其中 $\mathbf{e} = \hat{\mathbf{y}} - \mathbf{y}$ 是**误差向量**，$\mathbf{X}$ 是数据矩阵。看右边：**梯度 $\nabla_{\mathbf{W}}\mathcal{L}$ 是误差向量 $\mathbf{e}$ 的一个线性变换**（先乘数据矩阵的转置 $\mathbf{X}^\top$，再乘常数 $\tfrac{2}{n}$）。教材原话正是这句："对权重的梯度导致的权重更新，是误差的一个线性变换。" 它把误差从输出端一路搬回权重端。

拿一个可以手算的数字验证。数据矩阵 $\mathbf{X} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix}$，目标 $\mathbf{y} = [1, 2, 3]$，初始权重 $\mathbf{W}^{(0)} = [0, 0]$，学习率 $\eta = 0.1$。

第 0 步：$\hat{\mathbf{y}} = \mathbf{X}\mathbf{W}^{(0)} = [0, 0, 0]$，误差 $\mathbf{e} = [0-1,\ 0-2,\ 0-3] = [-1, -2, -3]$。梯度：

$$\nabla_{\mathbf{W}}\mathcal{L} = \frac{2}{3}\,\mathbf{X}^\top \mathbf{e} = \frac{2}{3}\begin{bmatrix} -4 \\ -5 \end{bmatrix} = \begin{bmatrix} -2.667 \\ -3.333 \end{bmatrix}$$

更新：$\mathbf{W}^{(1)} = [0, 0] - 0.1\,[-2.667, -3.333] = [0.267, 0.333]$。重复 30 步，权重逼近真值 $[1, 2]$，损失从 4.667 一路掉到 0.005 以下——完整运行与逐函数拆解见《代码.md》。

### 五、边界声明：这座山，不是处处只有一座谷底

1. **梯度下降是"近视"的**：它每一步只依赖脚下那一点的局部坡度，保证走到一个**局部极小点 (local minimum)**，不保证全局最小。对线性模型 + MSE，损失是凸函数 (convex)——只有一座谷底，局部就是全局；但深度网络的损失地形布满山脊与坑洞，不同的随机起点会走进不同的坑。这就是"随机初始化 + 多次试验"在深度学习里如此重要的数学根源。
2. **MSE 怕离群点，也不擅长分类**：平方项让一个大误差（离群点，outlier）的惩罚被急剧放大，一个坏数据就能把整条拟合线拽偏。分类任务的输出是概率，MSE 对"接近 0 或 1 的概率"梯度会消失，训练停滞——所以分类的标准损失是**交叉熵 (cross-entropy)**：把真实标签 $\mathbf{y}$（one-hot）与预测概率 $\hat{\mathbf{p}}$ 对齐，$\mathcal{L} = -\sum_k y_k \log \hat{p}_k$，真实类别对应的 $\hat{p}$ 越接近 1，损失越接近 0。
3. **$\eta$ 没有万能值**：太大发散、太小蜗牛。工程上用"学习率调度"让它随训练逐步减小，并用损失曲线实时诊断。
4. **梯度必须"算得出来"**：这里我们手推了解析梯度；真实深度网络靠反向传播 (backpropagation) 自动完成——但那只是同一套链式法则的自动化，数学本质与本节无二。

## 第三步：DL 桥接

现在，把整个深度学习放回这一节的镜头里——它的全部动作，就是两件事：**定义一个标量，然后沿它的梯度地形下山。**

**回归任务**：模型前向传播，$\hat{\mathbf{y}}$ 由层层 dense layer（图 2.13 的 $\mathbf{W}\mathbf{x} + \mathbf{b}$）与激活函数组成；损失 $\mathcal{L} = \tfrac{1}{n}\sum(\hat{y}_i - y_i)^2$ 把"预测与真实之差"压成一个数。

**分类任务（包括大语言模型）**：最后一层输出的是"概率分布" $\hat{\mathbf{p}}$，损失换成交叉熵 $\mathcal{L} = -\sum_k y_k \log \hat{p}_k$。在 Transformer 里，每个 token 处模型对整个词表输出概率，损失取真实下一个 token 对应那一类的 $-\log \hat{p}_{\text{target}}$——整个"预测下一个词"的训练，就是最小化这个标量。

**梯度的形状**：反向传播用链式法则算出 $\nabla_{\mathbf{W}}\mathcal{L}$，它与 $\mathbf{W}$ 形状相同——**每一个权重，都收到一条"你该往哪动、动多少"的指令**。§2.5 的线性变换在这里彻底闭环：误差向量从最后一层出发，穿过每一层的 $\mathbf{W}^\top$（线性变换的转置），把坡度信息搬回所有参数。

**更新**：$\mathbf{W} \leftarrow \mathbf{W} - \eta\,\nabla_{\mathbf{W}}\mathcal{L}$。Attention 的 $QK^\top$、FFN 的矩阵乘法、损失、梯度、更新——这条链上，数学的一头是线性代数（本章），另一头是这座山的形状与走向。你看到的每一次"训练 loss 下降"，都是那个盲人，在参数空间里，又稳稳地朝谷底迈了一步。
