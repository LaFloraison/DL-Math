# 习题：损失函数与优化

## 第一组：概念检验

**1.1（单选）** 预测值 $\hat{\mathbf{y}} = [2, 3]$，真实值 $\mathbf{y} = [1, 4]$，MSE $\mathcal{L}$ 等于：
- A. 0
- B. 0.5
- C. 1
- D. 2

**1.2（判断并说明）** "梯度下降每一步的损失一定下降，只要一直跑下去，就一定能找到全局最小的权重。" 这句话对吗？错在哪里？

**1.3（填空）** 梯度下降更新公式 $\mathbf{W}^{(t+1)} = \mathbf{W}^{(t)} - \eta\,\nabla_{\mathbf{W}}\mathcal{L}$ 中：
- (a) $\eta$ 的中文名称是____，它的作用是把梯度（坡度）缩放成____；
- (b) $\nabla_{\mathbf{W}}\mathcal{L}$ 的形状与____一致，其第 $(i,j)$ 个元素是____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** (a) 计算教材例的 MSE：$\hat{\mathbf{y}} = [2, 3]$，$\mathbf{y} = [1, 4]$。
(b) 再算：预测 $[0.5, 1.5, 2.5]$，真实 $[1, 2, 3]$ 的 MSE，并用 NumPy 验证。

**2.2（手算 + 代码验证）** 单权重线性模型 $\hat{y} = w\,x$，数据 $x = [1, 2, 3]$，$y = [2, 4, 6]$（真值 $y = 2x$），MSE 损失，初始 $w = 0$，$\eta = 0.1$：
(a) 手算在 $w=0$ 处的梯度 $\frac{d\mathcal{L}}{dw}$；(b) 手算更新后的 $w^{(1)}$；(c) 用代码验证 $w$ 随梯度下降逼近 2。

**2.3（代码实验：学习率）** 把梯度下降的学习率 $\eta$ 分别设为 0.01、0.1、0.5、1.5，各跑 30 步，观察损失曲线。哪个太慢？哪个会震荡或发散？

## 第三组：DL 延伸

**3.1（场景判断）** 线性回归的梯度可以解析写出 $\nabla_{\mathbf{W}}\mathcal{L} = \frac{2}{n}\mathbf{X}^\top(\hat{\mathbf{y}} - \mathbf{y})$。请说明：为什么教材说"权重更新是误差的线性变换"？这对反向传播意味着什么？

**3.2（场景分析）** 一个图像二分类模型，最后一层输出一个概率 $\hat{p} \in (0,1)$。为什么用它做分类损失时，交叉熵 $\mathcal{L} = -\big[y\log\hat{p} + (1-y)\log(1-\hat{p})\big]$ 通常比 MSE 更合适？说出至少两条理由。

---

## 解答与思路点拨

### 第一组

**1.1 答案：C。**
- **思路**：$\mathcal{L} = \frac{1}{2}\big[(2-1)^2 + (3-4)^2\big] = \frac{1}{2}[1 + 1] = 1$。
- **点拨**：三个陷阱选项各有来历。选 D（=2）的人算对了平方和 $1+1=2$ 却忘了除以 $n=2$——**MSE 是"平均"平方误差，不是"总"平方误差**。选 A（=0）的人犯了主线第一节的那个错误：直接用 $1 + (-1) = 0$，正负误差抵消了——**平方的意义就是把偏差翻正、永不抵消**。选 B 的人可能拿错了 $n$ 或算错平方。记住节奏：**先逐样本平方，再求和，最后除以样本数**。

**1.2 这句话有两处不对。**
- **思路**：(1) 梯度下降每步**不一定**让损失下降——学习率 $\eta$ 太大时，一步可能跨过谷底，在谷两侧震荡，损失甚至回升（见 2.3 的 $\eta=1.5$）；(2) 就算损失稳步下降，也只能保证到达**局部极小点 (local minimum)**——深度网络的损失地形布满坑洞，不同起点会进不同的坑，不保证是全局最小。
- **点拨**：这道题考的是主线边界声明的两条。选"对"的人往往把"损失下降"等同于"到达全局最优"，忽略了**步长**和**非凸性**两个变量。

**1.3 答案**：(a) 学习率 (learning rate)；把梯度（坡度）缩放成"这一步迈多大"（步长）；(b) $\nabla_{\mathbf{W}}\mathcal{L}$ 的形状与 $\mathbf{W}$（权重矩阵/向量）一致；第 $(i,j)$ 个元素是偏导数 $\partial\mathcal{L}/\partial W_{ij}$。
- **点拨**：$\nabla_{\mathbf{W}}\mathcal{L}$ 与 $\mathbf{W}$ **同形**是梯度下降能逐元素执行的前提——每根权重拿到属于自己的坡度，这正是盲人同时顾到几百万个轴的数学根基。

### 第二组

**2.1**
- (a) $\mathcal{L} = \frac{1}{2}\big[(2-1)^2 + (3-4)^2\big] = 1$。
- (b) $\mathcal{L} = \frac{1}{3}\big[(0.5-1)^2 + (1.5-2)^2 + (2.5-3)^2\big] = \frac{1}{3}\big[0.25 + 0.25 + 0.25\big] = \frac{1}{3} \times 0.75 = 0.25$。

```python
import numpy as np
def mse(yhat, y):
    return (1.0 / y.size) * np.sum((yhat - y) ** 2)

print(mse(np.array([2.0, 3.0]), np.array([1.0, 4.0])))                 # 1.0
print(mse(np.array([0.5, 1.5, 2.5]), np.array([1.0, 2.0, 3.0])))       # 0.25
```

- **思路**：每步都是"相减 → 平方 → 求和 → 除以 n"。注意 (b) 里三个误差绝对值都是 0.5，平方后都是 0.25——三个"等幅偏差"得到 0.25。
- **点拨**：这个函数 `mse` 就是《代码.md》里内联公式的抽取版。可以试着把 `** 2` 换成 `** 1`（绝对值平均）对比——那就是 MAE，它不再"重罚大误差"。

**2.2**
- (a) 梯度：$\frac{d\mathcal{L}}{dw} = \frac{2}{n}\sum_i x_i(\hat{y}_i - y_i) = \frac{2}{3}\sum_i x_i (w x_i - y_i)$。在 $w=0$ 处：$\frac{2}{3}\big[1(-2) + 2(-4) + 3(-6)\big] = \frac{2}{3}(-28) = -\frac{56}{3} \approx -18.67$。
- (b) $w^{(1)} = 0 - 0.1 \times (-18.67) = 1.867$。
- (c) 验证：梯度指向 $+$ 方向（损失随 $w$ 增大而下降），一步就跳到 1.867，继续迭代逼近真值 $w=2$。

```python
import numpy as np
x = np.array([1.0, 2.0, 3.0]); y = np.array([2.0, 4.0, 6.0])
w, eta = 0.0, 0.1
for step in range(50):
    diff = w * x - y
    grad = (2.0 / x.size) * np.sum(x * diff)
    w = w - eta * grad
    if step in (0, 1, 2, 9, 49):
        print(step, round(w, 4))
# 0 1.8667
# 1 1.9733
# 2 1.9947
# 9 2.0
# 49 2.0
```

- **思路**：注意这里的梯度是标量（单权重）。它 $\approx -18.67$，即 $w$ 每增大 1，损失约下降 18.67——方向是"增大 $w$"，更新公式自动转向。
- **点拨**：$-18.67$ 看着很大，但这是"坡度"，步长由 $\eta=0.1$ 缩放成 $\approx 1.87$ 的实跳。**梯度的大小 ≠ 该迈的步长**——这是初学者最容易搞混的一处：步长是 $\eta$，不是 $\|\nabla\mathcal{L}\|$。

**2.3 思路**：用 2.2 的数据把 `eta` 换成四个值观察。

```python
import numpy as np
x = np.array([1.0, 2.0, 3.0]); y = np.array([2.0, 4.0, 6.0])
for eta in (0.01, 0.1, 0.5, 1.5):
    w = 0.0; hist = []
    for _ in range(30):
        diff = w * x - y
        w = w - eta * (2.0 / x.size) * np.sum(x * diff)
        hist.append(round((1.0 / x.size) * np.sum((w * x - y) ** 2), 3))
    print(f"eta={eta}: 末步损失 {hist[-1]}, 最后几步 {hist[-4:]}")
```

- **结果预期**：$\eta=0.01$ 收敛慢（30 步后损失还停在 0.3 左右）；$\eta=0.1$ 干净收敛到 0；$\eta=0.5$ 大步但仍在收敛；$\eta=1.5$ 损失震荡、完全不收敛。
- **点拨**：对单个权重，收敛性由 $\eta$ 与损失曲率共同决定；$\eta$ 超出一条临界值就发散。**发散不是"模型坏了"，而是"步长越界"**——先调小 $\eta$ 再谈其他。这也是主线边界声明里"$\eta$ 没有万能值"的实证。

### 第三组

**3.1 思路**：
- 误差向量 $\mathbf{e} = \hat{\mathbf{y}} - \mathbf{y}$ 已经"编码"了每个样本预测偏了多少。梯度 $\nabla_{\mathbf{W}}\mathcal{L} = \frac{2}{n}\mathbf{X}^\top \mathbf{e}$ 是 $\mathbf{e}$ 的线性变换：先乘数据矩阵的转置 $\mathbf{X}^\top$（把误差按特征加权汇总），再乘常数 $\frac{2}{n}$——**不含任何非线性**。因此权重更新 $\mathbf{W}\leftarrow\mathbf{W} - \eta\cdot\frac{2}{n}\mathbf{X}^\top\mathbf{e}$ 本质是把"误差"这一列数经过固定线性变换后，从权重里减掉。
- 对反向传播的含义：误差从输出端逐层向回传时，每一层只做线性操作（乘转置权重矩阵）与逐元素求导（激活的导数）。**只要前向是"线性变换 + 可导激活"的组合，误差就能被线性地搬回每一个权重**——这正是教材那句话放在 §2.5（线性变换）里的原因，也是反向传播能机械化的数学前提。
- **点拨**：常见的错误是以为梯度是"算出来的某种神秘数字"。看清 $\nabla = \frac{2}{n}\mathbf{X}^\top\mathbf{e}$ 之后你会发现：**梯度就是误差的线性影子**，形状和权重一样大，内容由误差决定。

**3.2 思路（至少两条）**：
1. **MSE 对饱和概率梯度消失**：当 $\hat{p}$ 接近 0 或 1 时（模型已经很自信但判错了），$(\hat{p}-y)^2$ 对 $\hat{p}$ 的导数 $2(\hat{p}-y)$ 并不大，导致更新极慢；而交叉熵的梯度正比于 $\hat{p}-y$ 之外还带 $\frac{1}{\hat{p}(1-\hat{p})}$ 的因子，在错误且自信的地方给出大梯度，把模型更快拉回来。
2. **概率对齐更自然**：分类输出是概率分布，交叉熵 $-\sum_k y_k \log \hat{p}_k$ 直接衡量"预测分布与真实分布的信息距离"，与概率的语义吻合；MSE 是为连续回归（数值预测）设计的，把概率当普通数字比平方，语义不匹配。
3. （加分）MSE 在概率接近 0/1 时梯度趋近于一个常数差 $2(\hat p-y)$，但被 $\hat{p}$ 饱和区域压住；且分类的 softmax + 交叉熵组合在数学上正好给出简洁的梯度形式 $\hat{p}-\mathbf{y}$（预测减真值）。
- **点拨**：这道题对应主线边界声明第 2 条。选 MSE 的人往往觉得"越接近越准，平方正合适"——忽略了概率的特殊结构。**损失函数要与输出的语义匹配**：回归选 MSE，分类选交叉熵。

## 一个"为什么有人会答错"的提醒

1.1 的 D 选项（=2）是最常见的陷阱——**漏掉 $\frac{1}{n}$**。把 MSE 的四个动作连成一个口诀记牢：**相减 → 平方 → 求和 → 平均**，四步缺一不可。2.2 里把梯度大小（$-18.67$）误当成"该迈的步长"是第二个高频错误——**坡度再陡，迈多大由 $\eta$ 决定**，梯度只指方向。3.2 则是概念层：以为 MSE 是"唯一正确的损失"，忘了它怕离群点、怕概率饱和。损失函数的世界不是一把尺子量到底——**选尺子，先看你要量什么**。
