# 代码：手写 MSE 与梯度下降——把"下山"写成一行更新公式

主线里我们跟着一个盲人走下山：脚下的坡度是梯度，每一步 $\mathbf{W} \leftarrow \mathbf{W} - \eta\nabla_{\mathbf{W}}\mathcal{L}$。这一节把这句话变成代码——**不调用任何自动求导、不调用任何优化器**，用一个 2 权重的线性模型，亲手算 MSE、亲手算梯度、亲手执行更新公式。你看到的每一步，都是数学公式的逐字翻译。

脚本只依赖 NumPy，约 30 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 教材例子：MSE = 误差平方的平均 ----
yhat = np.array([2.0, 3.0])             # 预测值 ŷ，形状 (2,)
y    = np.array([1.0, 4.0])             # 真实值 y，形状 (2,)
n    = y.size                           # 样本数 n = 2
mse  = (1.0 / n) * np.sum((yhat - y) ** 2)
print("① MSE(ŷ, y) =", mse)             # = ½[(2-1)²+(3-4)²] = 1.0

# ---- ② 线性层前向：pred = X @ w，损失是权重 w 的标量函数 ----
X    = np.array([[1., 0.], [0., 1.], [1., 1.]])   # 数据，形状 (3, 2)
Y    = np.array([1., 2., 3.])                      # 目标，形状 (3,)；真权重是 [1, 2]
w    = np.array([0., 0.])                          # 初始权重，形状 (2,)
pred = X @ w                                       # 前向，形状 (3,)
L0   = (1.0 / Y.size) * np.sum((pred - Y) ** 2)
print("② 初始损失 L(w) =", np.round(L0, 4))       # 4.6667

# ---- ③ 手动梯度：∇_w L = (2/n) · Xᵀ (pred − y) ----
def grad_loss(w):
    diff = X @ w - Y                          # 误差向量 e，形状 (3,)
    return (2.0 / Y.size) * (X.T @ diff)      # 形状 (2,)——与 w 同形

# ---- ④ 梯度下降：w ← w − η ∇_w L，训练 30 步 ----
eta = 0.1                                     # 学习率 η（步长）
for step in range(30):
    g = grad_loss(w)                          # 当前梯度
    w = w - eta * g                           # ← 本节核心更新公式
    if step % 5 == 0:
        L = (1.0 / Y.size) * np.sum((X @ w - Y) ** 2)
        print(f"④ step {step:2d}: w = {np.round(w, 4)}, L = {L:.6f}, ‖∇L‖ = {np.linalg.norm(g):.4f}")
```

## 层二：分步逐函数拆解

### 步骤 1：教材例子——把 MSE 公式一字一字敲进去

```python
yhat = np.array([2.0, 3.0])                 # ŷ，形状 (2,)
y    = np.array([1.0, 4.0])                 # y，形状 (2,)
n    = y.size                               # n = 2
mse  = (1.0 / n) * np.sum((yhat - y) ** 2)
print("① MSE(ŷ, y) =", mse)                 # 1.0
```

#### `np.array([...])` —— 造向量

**做什么**：把列表变成 NumPy 数组，这就是"预测向量 $\hat{\mathbf{y}}$ / 真实向量 $\mathbf{y}$ 在计算机里的存在形式"。
**输入**：Python 列表，两个浮点数。
**输出**：形状 `(2,)` 的一维数组；`yhat[0]=2.0` 是第一个样本的预测值，`y[0]=1.0` 是第一个样本的真实值。
**可调参数**：长度任意——`np.array([2.,3.,4.])` 就是 3 样本的向量；传 `dtype=np.float32` 可省内存。**对应数学**：主线里 $\hat{\mathbf{y}}$ 与 $\mathbf{y}$ 的定义。

#### `(yhat - y)` 与 `** 2` —— 逐元素相减与逐元素平方

**做什么**：`(yhat - y)` 对两个向量按位置相减，得到误差向量 $\mathbf{e} = \hat{\mathbf{y}} - \mathbf{y} = [2-1,\ 3-4] = [1, -1]$；`** 2` 把每个误差翻平方，$[1, 1]$——负偏差被翻正、永不抵消，这正是主线里"平方救了你"的那一步。
**操作**：NumPy 对形状相同的数组做**逐元素 (elementwise)** 运算，不写循环。
**输入**：两个形状 `(2,)` 的数组。
**输出**：形状 `(2,)` 的数组。
**可调参数**：`** 2` 可换 `** 3`（不同损失，如 Huber 损失用分段）；把平方换绝对值就是 MAE。**对应数学**：主线"$(\hat{y}_i - y_i)^2$"。

#### `np.sum(...)` —— 求和

**做什么**：把数组所有元素加起来。$\text{sum} = 1 + 1 = 2$，这正是教材里的"求和是线性操作"。
**输入**：形状 `(2,)` 的数组。
**输出**：标量 `2.0`。
**可调参数**：`axis` 参数可沿指定维度求和（如对 `(n,d)` 的矩阵沿样本轴加总）——后面训练循环会用到。**对应数学**：MSE 公式里的 $\sum_{i=1}^{n}$。

#### `(1.0 / n) * ...` —— 除以样本数取平均

**做什么**：把"总误差"变成"平均误差"。$n = y.size = 2$，所以 `mse = (1/2) * 2 = 1.0`，与教材结果一致。
**可调参数**：`n` 是样本数，由 `y.size` 自动取到——换成任意长度，公式一字不改。**对应数学**：MSE 的 $\tfrac{1}{n}$。

### 步骤 2：前向传播——`X @ w`

```python
X    = np.array([[1., 0.], [0., 1.], [1., 1.]])   # (3, 2)
Y    = np.array([1., 2., 3.])                      # (3,)
w    = np.array([0., 0.])                          # (2,)
pred = X @ w                                       # (3,)
L0   = (1.0 / Y.size) * np.sum((pred - Y) ** 2)
print("② 初始损失 L(w) =", np.round(L0, 4))       # 4.6667
```

#### `X @ w` —— 矩阵乘向量（线性层前向）

**做什么**：数据矩阵 $\mathbf{X}$（形状 `(3, 2)`，第 $i$ 行是第 $i$ 个样本的两个特征）乘权重向量 $\mathbf{w}$（形状 `(2,)`），得到预测向量 `pred`（形状 `(3,)`）。这是主线里 dense layer $\hat{\mathbf{y}} = \mathbf{W}\mathbf{x}$ 的批量版：**一次前向，算出所有样本的预测**。
**操作**：`@` 是矩阵乘法。结果第 $i$ 个元素 $= \mathbf{X}[i,:]$ 与 $\mathbf{w}$ 的点积：第 0 个样本 $1\times 0 + 0\times 0 = 0$，第 2 个样本 $1\times 0 + 1\times 0 = 0$。形状对齐规则：`(3,2) @ (2,) → (3,)`——中间维 2 必须相等，结果去掉被乘的维。
**输入**：`X` 形状 `(3, 2)`（3 样本、2 特征）；`w` 形状 `(2,)`。
**输出**：`pred` 形状 `(3,)`，第 $i$ 个元素是第 $i$ 个样本的预测值 $\hat{y}_i$。
**可调参数**：`X` 行数随意（更多样本）、列数随意（更多特征）；权重列数决定输出维数——`w` 若是 `(2, 5)`，`pred` 就是 `(3, 5)`（5 个输出神经元），这就在向真正的全连接层进化了。
**对应数学**：教材图 2.13 的线性变换 $\mathbf{W}\mathbf{x}$。

#### `np.round(L0, 4)` —— 四舍五入显示

**做什么**：把 `L0 = 4.6667` 保留 4 位小数。**可调参数**：第二个参数是小数位数，`np.round(L0)` 默认取整。
**对应数学**：`L0 = (1/3)[(0−1)²+(0−2)²+(0−3)²] = 14/3 ≈ 4.667`——初始权重全 0 时，损失等于目标平方的平均。

### 步骤 3：手动梯度 `grad_loss(w)`

```python
def grad_loss(w):
    diff = X @ w - Y                          # 误差向量 e，形状 (3,)
    return (2.0 / Y.size) * (X.T @ diff)      # 形状 (2,)
```

#### `diff = X @ w - Y` —— 误差向量

**做什么**：前向预测减去真实目标，$\mathbf{e} = \hat{\mathbf{y}} - \mathbf{y}$。第 $i$ 个元素是第 $i$ 个样本"偏了多少、朝哪偏"。这是整段代码里最重要的一列数——**梯度是它的线性变换**。
**输入**：`pred`（`(3,)`）与 `Y`（`(3,)`），形状相同，逐元素相减。
**输出**：`diff`，形状 `(3,)`。

#### `X.T` 与 `X.T @ diff` —— 转置后乘误差（梯度公式）

**做什么**：`X.T` 把数据矩阵转置（形状 `(3,2) → (2,3)`）；`X.T @ diff` 是 `(2,3) @ (3,) → (2,)`——结果的第 $j$ 个元素 $= \sum_i \mathbf{X}[i,j]\cdot \text{diff}[i]$，即"第 $j$ 个特征在所有样本上的加权和"。再乘 `2.0 / Y.size`，就得到梯度向量，形状 `(2,)`——**与 `w` 完全同形，每一根权重拿到自己的坡度**。
**操作**：这正是主线推导的 $\nabla_{\mathbf{W}}\mathcal{L} = \frac{2}{n}\mathbf{X}^\top \mathbf{e}$ 的逐字翻译。注意 `@` 是矩阵乘、`*` 是逐元素乘，两者绝不能互换。
**输入**：`X.T` 形状 `(2, 3)`，`diff` 形状 `(3,)`。
**输出**：`grad_loss(w)` 返回形状 `(2,)` 的梯度——与 `w` 同形，是"权重更新"能逐元素执行的前提。
**可调参数**：`X` 的维度任意变化，函数自动适配——换成 `(100, 10)` 的数据，照样返回 `(10,)` 的梯度。这就是矩阵形式"一个公式管所有维度"的力量。

### 步骤 4：梯度下降循环——`w = w - eta * g`

```python
eta = 0.1
for step in range(30):
    g = grad_loss(w)                          # 当前梯度
    w = w - eta * g                           # ← 本节核心更新公式
    if step % 5 == 0:
        L = (1.0 / Y.size) * np.sum((X @ w - Y) ** 2)
        print(f"④ step {step:2d}: w = {np.round(w, 4)}, L = {L:.6f}, ‖∇L‖ = {np.linalg.norm(g):.4f}")
```

#### `w = w - eta * g` —— 更新公式（主线核心）

**做什么**：`eta * g` 用学习率缩放梯度（步长 = 坡度 × 步长系数），`w - eta * g` 沿梯度的反方向挪动权重——**这一行就是 $\mathbf{W} \leftarrow \mathbf{W} - \eta\nabla_{\mathbf{W}}\mathcal{L}$ 本身**。
**操作**：逐元素执行：`w[0] = w[0] - 0.1 * g[0]`、`w[1] = w[1] - 0.1 * g[1]`。两个权重同时更新——盲人同时照顾到了几百万个轴，靠的就是这行逐元素算术。
**输入**：`w`（`(2,)`）、`g`（`(2,)`）、`eta`（标量）。
**输出**：更新后的 `w`，形状不变 `(2,)`。
**可调参数**：`eta` 是本节唯一的超参数——改成 `1.5` 试试，损失会在谷底两侧震荡甚至发散；改成 `0.01`，收敛慢十倍。**对应数学**：主线"梯度下降"定义块。

#### `np.linalg.norm(g)` —— 梯度模长（收敛哨兵）

**做什么**：量"这步坡有多陡"。梯度模长 `‖∇L‖` 从 4.27 一路掉到 0.09——**越接近 0，说明脚下越平，越接近谷底**。看它收敛，就是"盲人终于踩到了平地"。
**可调参数**：换 `ord=1` 或 `ord=np.inf` 可量其他范数（见 2.2.1.1 节）。**对应数学**：梯度消失即 $\|\nabla_{\mathbf{W}}\mathcal{L}\| \to 0$，是"到达极小点"的一阶必要条件。

## 边界声明：这套代码能做什么，不能做什么

1. **梯度的解析式只对"线性模型 + MSE"成立**：`grad_loss` 里那句 `(2/n) * X.T @ diff` 是我们手推出来的闭合公式。换成带激活函数的深度网络，梯度不再有这种简单的矩阵写法——真实框架靠**反向传播 (backpropagation)** 自动计算，它本质是链式法则的机械化。本节的数学（更新公式、梯度形状、误差的线性变换）完全不变，变的只是"梯度怎么拿到"。
2. **学习率 $\eta$ 没有万能值**：它是手调的超参数。本例取了 0.1 恰好收敛漂亮；改大可能发散（损失在 step 0 后反而上升），改小则慢如蜗牛。工程里靠损失曲线诊断——曲线震荡，调小 $\eta$。
3. **这里是全批量梯度下降**：每一步用**全部**样本算梯度。样本量大时每步算得很贵，深度学习常用随机梯度下降 (SGD) / 小批量版——每步只用一个/一小撮样本，方向更吵但每步更便宜。数学思想相同，只是 $\mathbf{e}$ 取自子集。
4. **数据是"完美线性"的**：$\mathbf{Y}$ 恰好由真权重 $[1, 2]$ 生成，所以损失能收敛到接近 0。真实数据带噪声甚至离群点时，MSE 的平方项会被大误差拽偏，损失停在一个正的谷底——那正是主线边界声明里"MSE 怕离群点"的代码形态。
5. **`@` 与 `*` 不能混**：`X.T @ diff` 是矩阵乘法；若误写成 `X.T * diff`，形状 `(2,3)` 与 `(3,)` 无法广播，直接报错或得到语义全错的结果。
