# 代码：把矩阵乘法的每一格"手工算出来"——并撞两次经典错误

主线里我们算了 $C = AB$。这一节用 NumPy 做四件事：**① `@` 一步算完；② 手写三重循环复现定义；③ 验证不可交换；④ 撞"内维不匹配"的报错。**

---

## 层一：完整脚本

```python
import numpy as np                          # NumPy：matmul

# ---- ① 教材的两个矩阵 ----
A = np.array([[1, 2], [3, 4]])
B = np.array([[2, 0], [1, 3]])
print("A @ B =\n", A @ B)                    # [[ 4  6] [10 12]]

# ---- ② 手写三重循环：复现定义 C_ij = Σ_k A_ik B_kj ----
m, k = A.shape            # 2, 2
n = B.shape[1]            # 2
C = np.zeros((m, n))
for i in range(m):
    for j in range(n):
        for r in range(k):
            C[i, j] += A[i, r] * B[r, j]
print("手写 C =\n", C.astype(int))           # 与 @ 一致

# ---- ③ 验证不可交换：AB ≠ BA ----
print("AB == BA ?", np.allclose(A @ B, B @ A))      # False
print("A @ B =\n", A @ B, "\nB @ A =\n", B @ A)

# ---- ④ 内维不匹配：报错 ----
M = np.ones((3, 2))
N = np.ones((3, 2))        # M 的列 2 ≠ N 的行 3
try:
    _ = M @ N
except ValueError as e:
    print("内维不匹配报错:", e)

# ---- ⑤ 形状规则：内维 k 匹配 ----
X = np.ones((3, 4))        # (3,4)
W = np.ones((4, 2))        # (4,2)  内维 4 匹配
print("(3,4) @ (4,2) =", (X @ W).shape)      # (3,2) 左行右列
```

运行输出（Python 3.11 + NumPy）：

## 层二：分步逐函数拆解

### 步骤 1：`A @ B`

#### `ndarray @ ndarray` —— 矩阵乘法

**操作**：$(2,2)@(2,2)\to(2,2)$。每个元素 = 行×列点积：$C_{11} = 1\cdot2+2\cdot1 = 4$。
**输入**：`A`（`(2,2)`）、`B`（`(2,2)`）。
**输出**：`(2,2)` 数组。
**可调参数**：`np.matmul(A, B)` 与 `@` 等价；`np.dot` 对二维也是矩阵乘（但对高维行为不同）。**注意 `A * B` 是逐元素乘，不是矩阵乘。**
**对应数学**：主线 $C_{ij}=\sum_r A_{ir}B_{rj}$。**`@` 是深度学习的命脉运算。**

### 步骤 2：手写三重循环

```python
for i in range(m):
    for j in range(n):
        for r in range(k):
            C[i, j] += A[i, r] * B[r, j]
```

**做什么**：按定义逐格累加。`C[i,j]` 累加 $\sum_r A_{ir}B_{rj}$。
**操作**：`i` 遍历左矩阵行、`j` 遍历右矩阵列、`r` 遍历内维求和。三重循环是定义的"慢速复读机"。
**可调参数**：`m,k,n` 由形状决定；任何符合内维规则的矩阵都适用。
**对应数学**：主线定义公式的逐行翻译。**看懂这个三重循环，`@` 就不再是黑盒。**（工程上用 im2col 或 BLAS 优化，但数学就是这三层循环。）

### 步骤 3：`np.allclose(A @ B, B @ A)` → False

**做什么**：验证不可交换。$AB = \begin{bmatrix}4&6\\10&12\end{bmatrix}$，$BA = \begin{bmatrix}2&4\\10&14\end{bmatrix}$，不相等。
**可调参数**：换成"可交换的特殊对"（如 $A$ 为对角矩阵）可能相等——但那要碰运气。
**对应数学**：主线"矩阵乘法不可交换"。**几何上：先缩放再旋转 ≠ 先旋转再缩放。** 这是深度学习里"矩阵顺序不可乱换"的根据。

### 步骤 4：内维不匹配报错

```python
M = np.ones((3, 2)); N = np.ones((3, 2))
_ = M @ N   # ValueError
```

**做什么**：$M$ 的列数 2 ≠ $N$ 的行数 3，无法相乘。报错信息提到 "core dimension mismatch"——即内维不匹配。
**可调参数**：把 `N` 换成 `np.ones((2, 5))` 就能乘，得 `(3, 5)`。
**对应数学**：主线"内维必须匹配"。**写 `@` 前先心算内维**——这是矩阵代码的第一纪律。

### 步骤 5：`(3,4) @ (4,2) = (3,2)`

**做什么**：演示形状规则。左 `(3,4)`、右 `(4,2)`，内维 4 匹配，输出 `(3,2)`——**左行右列**。
**可调参数**：任意形状，规则不变：$(m,k)(k,n)\to(m,n)$。
**对应数学**：主线"输出形状 = 左行 × 右列"。批量前向 $XW^\top$：$(B,d_{in})(d_{in},d_{out})\to(B,d_{out})$——**这个形状链是深度学习前向的标准。**
