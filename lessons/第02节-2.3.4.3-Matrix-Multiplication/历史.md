# 历史：一场关于"矩阵该怎么乘"的世纪之争

## 1858 年，凯莱的"一个奇怪的决定"

凯莱建立矩阵理论时，面临一个开放问题：**矩阵该不该有乘法？如果有，怎么乘？**

他完全可以像加法一样定义"逐元素相乘"——那最自然、最好算。但凯莱做了当时看来很奇怪的决定：**他不定义逐元素乘法，而是定义了一种"行×列点积"的乘法。** 为什么？因为他心里装的不是"两个表格"，而是"线性变换的复合"：两个变换先后作用，它们的矩阵如何表示？答案是行×列点积——凯莱从**变换的需求**里推出了矩阵乘法，而不是从"表格"里。

这个决定在当时令人费解。逐元素乘法多自然啊！为什么要定义一种这么别扭的规则？凯莱坚持己见：矩阵的意义在于"表示变换"，而变换的复合就是这个规则。**一百多年后回头看，这个"别扭的选择"成了整个现代科学的基石。**

## 1905 年前后：两个"矩阵乘法"，一场暗战

其实在凯莱之后，"逐元素相乘"（哈达玛积）也有它的支持者。法国数学家雅克·哈达玛（Jacques Hadamard）系统研究过"对应元素相乘"的运算——今天的 Hadamard 积、深度学习里的 `*`，就是它。

于是 19 世纪末到 20 世纪初，数学界有两套"乘法"并行：凯莱的行×列乘法（强调变换），与哈达玛的逐元素乘法（强调表格）。**前者用于物理学和线性代数，后者用于概率论和调和分析。** 两套工具各有战场，没有谁取代谁。

但历史的裁判已经偏向凯莱：**只要一门学科的核心是"变换"——物理、工程、计算——凯莱乘法就是主力。** 矩阵乘法不是"两个表格怎么乘"，而是"两个变换怎么复合"；这个定义让矩阵成了变换的语言。

## 1970s–2000s：让矩阵乘法更快——一场持续半个世纪的竞赛

当矩阵乘法成为计算机的核心运算，一个新的问题出现：**怎么让它最快？**

1969 年，施特拉森（Volker Strassen）发明了 $O(n^{2.807})$ 的矩阵乘法算法——用 7 次乘法代替 8 次，第一次打破"必须 $n^3$"的直觉。此后竞赛持续：Coppersmith–Winograd 算法（1987）、激光法、以及近年来的新突破。每次把指数压低一点点，都是数值计算界的盛事。

而在工程界，真正让矩阵乘法"快"的是硬件：**GPU 专门为矩阵乘法优化**——分块、流水线、张量核心。2017 年英伟达推出的张量核心，就是"一块专吃矩阵乘法的芯片"。深度学习为什么能用 GPU？因为它的核心运算是矩阵乘法，而 GPU 为矩阵乘法而生。

## 2012–2017：矩阵乘法登上王座

2012 年，AlexNet 用 GPU 做卷积（im2col 后是矩阵乘法），ImageNet 夺冠。2017 年，Transformer 把注意力写成 $QK^\top$——又是矩阵乘法。深度学习从输入到输出，几乎每一步都是矩阵乘法。

**凯莱 1858 年那个"别扭的选择"，在两个世纪后成为万亿参数模型的命脉。** 他当年想的"变换的复合"，今天在每一块 GPU 上，以每秒千万亿次的速度执行着。
