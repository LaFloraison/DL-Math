# 代码：把数据装进量子比特，以及那位把 $175 预测成 $140 的交易员

主线讲了量子机器学习的两个核心动作和两个拦路虎：**振幅编码**把数据装进量子比特，**内积/距离**让 k-means 能"同时算距离"；而**编码成本**和**退相干噪声**让那位交易员把 $175 预测成 $140。这一课把四件事全部写成代码：振幅编码（10 个股价）、量子距离（10 个苹果到中心）、量子 k-means 的"同时比较"，以及噪声如何把上涨的趋势读成下跌。

---

## 层一：完整脚本

```python
import sys                               # 让中文 Windows 控制台也能打印 ≈、→ 等符号
sys.stdout.reconfigure(encoding="utf-8")
import numpy as np                       # 向量、内积、随机噪声

def amplitude_encode(data):              # ① 振幅编码：把经典数据装进量子振幅
    """返回 (归一化振幅, 数据模长)。数据被压进长度 1 的复向量——量子状态。"""
    data = np.asarray(data, dtype=complex)
    norm = np.linalg.norm(data)          # ||x||，归一化因子
    return data / norm, norm

def quantum_distance(x, y):              # ② 量子距离：用内积算欧几里得距离
    """||x-y||² = ||x||² + ||y||² − 2·||x||·||y||·√|<ψx|ψy>|²。"""
    sx, nx = amplitude_encode(x)
    sy, ny = amplitude_encode(y)
    overlap = np.abs(np.vdot(sx, sy)) ** 2   # |⟨ψx|ψy⟩|²：两个量子态的重叠
    return nx ** 2 + ny ** 2 - 2 * nx * ny * np.sqrt(overlap)

# ---- ③ 振幅编码：教材的 10 天股价 ----
prices = [150, 152, 148, 155, 160, 158, 162, 165, 167, 170]
psi, norm = amplitude_encode(prices)
print("归一化振幅 psi(前5个):", np.round(psi[:5], 4))
print("振幅平方和 =", np.round(np.sum(np.abs(psi)**2), 6), " (必须 = 1)")
print("数据模长 ||x|| =", round(norm, 2), " (编码要除以它)")

# ---- ④ 量子 k-means：10 个苹果的重量同时算到两个中心的距离 ----
weights = np.array([80, 78, 82, 79, 81, 120, 122, 118, 121, 119])
for c in (80.0, 120.0):
    dists = np.array([quantum_distance(w, c) for w in weights])
    print(f"到中心 {c:.0f}g 的距离:", np.round(dists, 1))

# ---- ⑤ 那位交易员：无噪声 vs 退相干噪声 ----
def lin_fit(xs, ys):                     # 最小二乘线性拟合, 预测下一时刻
    xs, ys = np.asarray(xs, float), np.asarray(ys, float)   # 兼容列表输入
    xm, ym = xs.mean(), ys.mean()
    slope = np.sum((xs - xm) * (ys - ym)) / np.sum((xs - xm) ** 2)
    return slope, ym + slope * (len(xs) + 1 - xm)

xs = np.arange(1, 11)
_, clean = lin_fit(xs, prices)           # 无噪声: 编码后读出, 干净
np.random.seed(169)
measured = np.array(prices) + np.random.normal(0, 25, size=10)   # 退相干污染读数
slope, noisy = lin_fit(xs, measured)
print(f"无噪声量子预测 ≈ {clean:.0f}")
print(f"有噪声量子预测 ≈ {noisy:.0f}  (斜率 {slope:.2f}, 趋势被读反了)")
```

运行输出（Python 3.11 + NumPy）：

```text
归一化振幅 psi(前5个): [0.2986 0.3026 0.2946 0.3086 0.3185]
振幅平方和 = 1.0  (必须 = 1)
数据模长 ||x|| = 502.35  (编码要除以它)
到中心 80.0g 的距离: [0.0 4.0 4.0 1.0 1.0 1600.0 1764.0 1444.0 1681.0 1521.0]
到中心 120.0g 的距离: [1600.0 1764.0 1444.0 1681.0 1521.0 0.0 4.0 4.0 1.0 1.0]
无噪声量子预测 ≈ 172
有噪声量子预测 ≈ 139  (斜率 -2.95, 趋势被读反了)
```

看最后两行：**同一个量子模型，无噪声预测 172（上涨），有噪声预测 139（下跌）**——教材那位交易员把 $175 预测成 $140 的悲剧，在代码里重演了。下面把每一步拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义 `amplitude_encode` —— 编码，量子机器学习的入场费

```python
def amplitude_encode(data):
    data = np.asarray(data, dtype=complex)
    norm = np.linalg.norm(data)
    return data / norm, norm
```

#### `amplitude_encode` —— 把经典数据压进长度 1 的复向量

**做什么**：把 $m$ 个实数的数据 $\mathbf{x}$ 变成归一化的复振幅向量 $|\psi_{\mathbf{x}}\rangle$，满足 $\sum|\alpha_i|^2 = 1$。
**操作**：`np.linalg.norm(data)` 算 $\|\mathbf{x}\| = \sqrt{\sum x_i^2}$；`data / norm` 逐元素除以模长——这正是主线定义块里"$\alpha_i = x_i/\|\mathbf{x}\|$"的代码。
**输入**：`data`，任意长度的一维数组（实数或复数）。
**输出**：`(psi, norm)`——归一化振幅向量 + 原模长。返回 `norm` 是因为后面算距离要用它。
**可调参数**：
- 编码方式有三种（主线第五节）：振幅编码（本函数）、角度编码（把 $x_i$ 变成旋转门角度 $\theta_i$）、基编码（把实数展开成二进制）。本函数实现振幅编码——它最直观，也是教材例子隐含的编码。
- 能不能加参数？真实振幅编码还要考虑"凑 $2^n$ 个振幅"（$n$ 个量子比特只能装 $2^n$ 个数）。本函数不检查 $2^n$ 对齐——10 个数据理论上需要 $2^4=16$ 个振幅（空 6 个），真实实现要补零。这是个"看起来小事、实现起来烦"的细节，正是教材说编码"tricky"的一部分。
**对应数学**：主线定义块的振幅编码。**归一化是量子状态的合法性要求**——`norm` 就是那条"入场费"：数据模长越大，编码越贵（量子门越多）。

### 步骤 2：定义 `quantum_distance` —— 距离 = 内积的量子版本

```python
def quantum_distance(x, y):
    sx, nx = amplitude_encode(x)
    sy, ny = amplitude_encode(y)
    overlap = np.abs(np.vdot(sx, sy)) ** 2
    return nx ** 2 + ny ** 2 - 2 * nx * ny * np.sqrt(overlap)
```

#### `quantum_distance` —— 用两个量子态的重叠算欧几里得距离

**做什么**：算 $\|\mathbf{x} - \mathbf{y}\|^2$——但通过量子态的"重叠" $\langle\psi_{\mathbf{x}}|\psi_{\mathbf{y}}\rangle$ 实现。这正是量子 k-means 的"距离原语"。
**操作**：
- `np.vdot(sx, sy)` 算复内积 $\langle\psi_{\mathbf{x}}|\psi_{\mathbf{y}}\rangle = \sum_i \alpha_i^* \beta_i$；
- `np.abs(...)**2` 取模平方 $|\langle\psi_x|\psi_y\rangle|^2$（量子核的样子）；
- 套用主线第二节的恒等式：$\|\mathbf{x}-\mathbf{y}\|^2 = \|\mathbf{x}\|^2 + \|\mathbf{y}\|^2 - 2\sqrt{\|\mathbf{x}\|^2\|\mathbf{y}\|^2\,|\langle\cdot\rangle|^2}$，其中 $|\langle\psi_x|\psi_y\rangle| = \frac{\langle\mathbf{x},\mathbf{y}\rangle}{\|\mathbf{x}\|\|\mathbf{y}\|}$。
**输入**：`x, y`，两个数据点。
**输出**：标量，欧几里得距离。
**可调参数**：无——距离定义是死的。但**真实量子实现**会用 swap test（交换检验）估算 $|\langle\psi_x|\psi_y\rangle|^2$，本函数用 `np.vdot` 精确计算——演示的是数学，不是硬件电路。
**对应数学**：主线第二节 $\|\mathbf{x} - \mathbf{y}\|^2 = \|\mathbf{x}\|^2 + \|\mathbf{y}\|^2 - 2\langle\mathbf{x}, \mathbf{y}\rangle$。`overlap` 就是内积的量子化——**"两个数据点像不像"被翻译成"两个量子态重不重叠"**。

### 步骤 3：振幅编码实战——10 天股价

```python
psi, norm = amplitude_encode(prices)
print("归一化振幅 psi(前5个):", np.round(psi[:5], 4))
print("振幅平方和 =", np.round(np.sum(np.abs(psi)**2), 6), " (必须 = 1)")
```

**做什么**：把教材的 10 天股价装进量子振幅，验证归一化。
**操作**：`amplitude_encode(prices)` 一次完成；`np.abs(psi)**2` 求概率。
**输入**：`prices = [150,152,...,170]`。
**输出**：归一化振幅（前 5 个 `[0.2986 0.3026 ...]`）与振幅平方和 1.0。
**可调参数**：换任意数据都能编码——这是"装进量子比特"的通用入口。注意振幅平方和必须精确等于 1，这是量子状态的合法性法律。
**对应数学**：主线定义块 $\sum_i|\alpha_i|^2 = 1$。输出的 0.2986 就是 $150/502.35 \approx 0.2986$——**每个振幅 = 数据值 / 模长**，一眼可见。

### 步骤 4：量子 k-means——10 个苹果同时算距离

```python
for c in (80.0, 120.0):
    dists = np.array([quantum_distance(w, c) for w in weights])
```

**做什么**：对 10 个苹果的重量，各算到中心 80g 和 120g 的距离。教材的"compare all the apples simultaneously"——在代码里，`np.array([...])` 的向量化 + `quantum_distance` 的内积计算，让 10 个距离一次算完（真实量子版则是叠加态一次变换）。
**操作**：`weights = [80,78,82,79,81,120,122,118,121,119]`（10 个苹果：前 5 个约 80g，后 5 个约 120g）。
**输入**：苹果重量数组 + 中心。
**输出**：到 80g 的距离 `[0,4,4,1,1,1600,1764,...]`（前 5 个近、后 5 个远），到 120g 相反。**聚类结果一目了然：前 5 个苹果归 80g 中心，后 5 个归 120g 中心。**
**可调参数**：换中心、换数据都行。把中心改成 90g，距离分布会改变——k-means 的"重新计算中心"迭代就是这样反复跑的。
**对应数学**：主线第二节的"距离同时在场"。**注意距离的语义：距离小 = 量子态重叠大 = 该归这一类**——这就是聚类在量子表示下的运作方式。

### 步骤 5：那位交易员——噪声如何读反趋势

```python
np.random.seed(169)
measured = np.array(prices) + np.random.normal(0, 25, size=10)
slope, noisy = lin_fit(xs, measured)
```

**做什么**：模拟教材的悲剧——编码成功后，量子系统因不稳定（退相干）在读数时给每个数据叠加噪声（$\sigma=25$），然后量子线性回归读出的趋势从上涨变成下跌。
**操作**：
- `np.random.normal(0, 25, size=10)`：给 10 个读数各加一个均值为 0、标准差 25 的随机误差——模拟"量子系统 struggle to maintain its state"导致的读数污染。
- `lin_fit`：最小二乘线性拟合（真实量子回归用量子线性代数解，本函数用经典最小二乘演示"读出的趋势"）。
**输入**：10 天股价 + 噪声。
**输出**：无噪声预测 172、有噪声预测 139，斜率从正变负。
**可调参数**：
- `np.random.seed(169)`：固定噪声，保证复现出 139 这个"接近教材的 $140$"。改 seed，噪声不同，预测在 130–210 间波动——有时碰巧仍接近 172，有时更糟。想看清"不稳定系统的预测有多不可靠"，可以试 `seed=0,1,2` 看每次结果差多远。
- `25` 是噪声强度：调小（如 5），预测仍接近 172（系统还算稳）；调大（如 50），预测可能崩到 100 以下。
**对应数学**：主线第五节。**这不是算法错，是硬件噪声把趋势"读反了"**——$175 \to 140$ 不是统计离群值，是"读出的斜率从 +2.4 变成 -2.9"的结构性错误。

## 改个数字试试：把编码与噪声推向极端

### 实验 1：固定噪声强度，换随机种子——趋势被随机读反

```python
for seed in (0, 3, 6, 9, 12):
    np.random.seed(seed)
    measured = np.array(prices) + np.random.normal(0, 25, size=10)
    slope, pred = lin_fit(xs, measured)
    print(f"seed={seed:2d} → 预测 {pred:5.0f}, 斜率 {slope:+.2f}")
```

输出：

```text
seed= 0 → 预测   167, 斜率 -1.90
seed= 3 → 预测   150, 斜率 -0.99
seed= 6 → 预测   174, 斜率 +3.29
seed= 9 → 预测   153, 斜率 +1.30
seed=12 → 预测   189, 斜率 +5.65
```

**同样的噪声强度（$\sigma=25$），只是换了随机种子，预测从 150 漂到 189，斜率从 +5.65 变成 -1.90。** 种子 0 和 3 的趋势被读反了（斜率变负，预测低于真实趋势），种子 6 和 12 又被读得过高。这就是教材"quantum computer may struggle to maintain its state, potentially leading to incorrect predictions"的完整数值图景：**误差纠正不成熟时，量子系统的输出不是"略不准"，是"随机漂移"——漂移的方向和幅度都由运气决定。**

### 实验 2：编码的成本——数据翻倍，振幅翻倍

```python
for m in (4, 8, 16, 32):
    data = np.ones(m)
    psi, norm = amplitude_encode(data)
    print(f"{m:3d} 个数据 → 需要 {int(np.ceil(np.log2(m))):2d} 个量子比特 → 编码向量长度 {2**int(np.ceil(np.log2(m)))}")
```

输出：

```text
  4 个数据 → 需要  2 个量子比特 → 编码向量长度 4
  8 个数据 → 需要  3 个量子比特 → 编码向量长度 8
 16 个数据 → 需要  4 个量子比特 → 编码向量长度 16
 32 个数据 → 需要  5 个量子比特 → 编码向量长度 32
```

**数据翻倍，只多一个量子比特**（$m$ 与 $2^n$ 的指数关系）——这是振幅编码的"容量红利"。但主线提醒过：构造这个态的**门数**通常随 $n$ 指数增长，所以容量是免费的、构造是昂贵的。**容量大 ≠ 编码便宜**——这是 QML 所有"看起来美好"的算法的共同陷阱。

## 边界声明：这套代码能做什么，不能做什么

1. **`quantum_distance` 用的是精确内积，不是真实量子估计。** 真实量子 k-means 用 swap test 等电路**估算** $|\langle\psi_x|\psi_y\rangle|^2$，结果是带噪声的估计值（测量次数越多越准）。本函数用 `np.vdot` 精确计算——它演示"距离 = 内积"的数学结构，不含测量统计噪声。
2. **"同时算距离"的收益是条件性的。** 叠加确实让 10 个距离"一次变换"在场，但完整读出 10 个距离仍要测量（读数串行，§12.2.2）。量子 k-means 的真实收益取决于"最终只需要少数统计量（如哪个最近）"，而不是"需要完整距离列表"。别把向量化 `np.array([...])` 误当成"免费的量子并行"。
3. **噪声模型是简化的。** 真实的退相干是量子态的相位/振幅被环境扰动，其数学比"给读数加高斯噪声"复杂得多（需要噪声信道、密度矩阵）。本脚本用高斯噪声**演示后果**（趋势被读反），不是为了精确建模退相干。**它的教学目标是"噪声能让涨跌反转"，不是"精确预测 140"。** 教材的 $175 \to 140$ 同样是示意性的——它要你记住的是：不稳定系统的输出不可靠。
