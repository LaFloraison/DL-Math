# 习题：量子机器学习算法

## 第一组：概念检验

### 1.1 为什么"把经典数据编码进量子态"是量子机器学习最关键的瓶颈？用"入场费"与"奖金"的比喻回答。

**解答**：量子算法的加速（$O(\sqrt{N})$、指数级）都是在"编码完成后"才兑现的。而编码本身——构造承载数据的量子态——的门数通常随数据维度**指数增长**（$O(2^n)$）。如果编码花 $O(2^n)$、经典算法处理同样数据只花 $O(n)$，那么"入场费已经超过奖金"，加速变成净亏损。教材"converting regular data into quantum states … can be complicated and time-consuming, sometimes canceling out the speed advantages"说的正是这个。所以判断一个 QML 算法值不值，必须算总账：**编码成本 + 测量读数成本 + 硬件噪声，三项一起和理论加速结账。**

**思路点拨**：别只答"编码难"。要点是**编码成本与计算加速的赛跑**——当编码成本吃掉加速时，QML 就是"表面快"。2014 年一批 QML 论文被批评"假设数据已编码"，正是这个问题的学术史。

### 1.2 量子 k-means 凭什么能"同时比较所有苹果"？它的收益为什么是有条件的？

**解答**：因为振幅编码把所有苹果的重量装进一个叠加态 $|\psi\rangle$，而距离计算被翻译成内积/量子态重叠（$\|\mathbf{x}-\mathbf{y}\|^2 = \|\mathbf{x}\|^2+\|\mathbf{y}\|^2 - 2\langle\mathbf{x},\mathbf{y}\rangle$）——一次量子变换可同时作用于全部数据点的振幅，所以"所有距离同时在场"。收益有条件的原因：**读数串行**——测量只能让一个基态坍塌，要完整读出 N 个距离仍需多次测量。所以量子 k-means 的真正收益只在"最终只需少数统计量"（如最近的中心是哪个）时兑现；若要完整距离列表，测量次数可能吞掉加速。

**思路点拨**：分两层答——叠加给"同时计算"（真），测量限制"同时读出"（真），所以净收益取决于"要读多少"。这也是 §12.2.2"账本并行、读数串行"在聚类上的落地。

### 1.3 那位把 $175 预测成 $140 的交易员，预测错误的原因是什么？是算法算错了吗？

**解答**：不是算法逻辑错，是**硬件噪声（退相干）**：量子系统无法稳定保持量子态，计算中途叠加被环境扰动，读数被污染，导致"读出的趋势"从上涨变成下跌。教材的原话："errors might occur because the quantum computer may struggle to maintain its state"。这体现了 NISQ 时代的核心现实：**理论加速是干净的，硬件输出是带噪的。** 误差纠正尚未成熟，量子机器学习"still in its early stages"。

**思路点拨**：注意区分两个独立障碍——**编码成本**（数据进不去）与**退相干噪声**（数据进去了但途中崩坏）。很多人混为一谈；教材的交易员例子专门讲的是后者。

## 第二组：计算实践

### 2.1 手算 + 验证：振幅编码 10 个股价

手算 $150/502.35$ 与 $170/502.35$（数据模长 $\|\mathbf{x}\| \approx 502.35$），验证归一化；再用代码核对。

**解答**：$150/502.35 \approx 0.2986$，$170/502.35 \approx 0.3384$。验证 $\sum_i (x_i/502.35)^2 = \frac{1}{502.35^2}\sum x_i^2 = \frac{\|\mathbf{x}\|^2}{\|\mathbf{x}\|^2} = 1$——归一化自动成立。

```python
import numpy as np
prices = np.array([150,152,148,155,160,158,162,165,167,170])
psi, norm = prices / np.linalg.norm(prices), np.linalg.norm(prices)
print(f"模长 = {norm:.2f}, 振幅[0] = {psi[0]:.4f}, 振幅平方和 = {np.sum(psi**2):.6f}")
```

输出：

```text
模长 = 502.35, 振幅[0] = 0.2986, 振幅平方和 = 1.000000
```

**思路点拨**：振幅编码的本质就是"除以模长"。验证归一化只需证明 $\sum(x_i/\|\mathbf{x}\|)^2 = 1$——一个代数恒等式，不是近似。

### 2.2 手算：量子距离的两个特例

对一维数据 $x=3, y=3$ 和 $x=3, y=7$，手算 $\|\mathbf{x}-\mathbf{y}\|^2$ 并验证量子距离公式（含内积项）。

**解答**：
- $x=y=3$：$\|x-y\|^2 = 0$。量子公式：$n_x=n_y=3$，$\langle\psi_x|\psi_y\rangle = 1$，$3^2+3^2-2\cdot3\cdot3\cdot1 = 18-18 = 0$。
- $x=3, y=7$：$\|x-y\|^2 = 16$。$n_x=3, n_y=7$，$\langle\psi_x|\psi_y\rangle = \frac{3\cdot7}{3\cdot7} = 1$（一维内积/模长之积 = 1），$9+49-2\cdot3\cdot7\cdot1 = 58-42 = 16$。✓

```python
import numpy as np
def qd(x, y):
    sx, nx = x/np.linalg.norm(x), np.linalg.norm(x)
    sy, ny = y/np.linalg.norm(y), np.linalg.norm(y)
    return nx**2 + ny**2 - 2*nx*ny*np.abs(np.vdot(sx, sy))**2
print(qd(np.array([3.]), np.array([3.])), qd(np.array([3.]), np.array([7.])))
```

输出：

```text
0.0 16.0
```

**思路点拨**：一维情形内积项正好抵消 $\|\mathbf{x}\|^2+\|\mathbf{y}\|^2$ 里多算的部分，返回经典距离。注意这里 `**2` 直接放在 `np.abs` 外面（与代码文件里的 `**2` 写法一致）——对一维实数二者相等。

### 2.3 验证噪声：同一个模型，不同噪声种子给出天差地别的预测

用《代码.md》的模型，对 10 个不同随机种子跑有噪声预测，统计预测值的分布，说明"噪声让输出随机漂移"。

```python
import numpy as np
prices = np.array([150,152,148,155,160,158,162,165,167,170]); xs = np.arange(1,11)
def lin_fit(xs, ys):
    xm, ym = xs.mean(), ys.mean()
    s = np.sum((xs-xm)*(ys-ym))/np.sum((xs-xm)**2)
    return ym + s*(len(xs)+1-xm)
preds = []
for seed in range(20):
    np.random.seed(seed)
    preds.append(lin_fit(xs, prices + np.random.normal(0, 25, size=10)))
preds = np.array(preds)
print("20 个种子下的预测:", np.round(preds))
print(f"均值 = {preds.mean():.0f}, 标准差 = {preds.std():.0f}, 范围 = [{preds.min():.0f}, {preds.max():.0f}]")
```

输出：

```text
20 个种子下的预测: [167. 164. 148. 150. 157. 162. 174. 166. 215. 153. 164. 156. 189. 191. 161. 147. 166. 177. 165. 167.]
均值 = 167, 标准差 = 16, 范围 = [147, 215]
```

**思路点拨**：真实值约 172 附近，但范围 [147, 215]——同一天数据、同一模型，只因随机噪声不同，预测能差近 70。这就是教材交易员场景的统计版：**不稳定系统的输出是"随机漂移"，不是"略不准"。** 这也是为什么 QML 落地前，误差纠正是不可回避的前提。

## 第三组：DL 延伸

### 3.1 量子核方法（QSVM）与经典核技巧（如 RBF 核）的本质区别是什么？量子核的"高维空间"为什么可能是优势？

**解答**：经典核技巧手工选择核函数 $K(\mathbf{x},\mathbf{y})$（RBF、多项式核），把数据隐式映射到某个经典特征空间。量子核方法用参数化量子线路定义特征映射 $|\phi(\mathbf{x})\rangle$，核 $K(\mathbf{x},\mathbf{y}) = |\langle\phi(\mathbf{x})|\phi(\mathbf{y})\rangle|^2$——特征空间是**量子比特的状态空间**（维度 $2^n$，指数级）。潜在优势：量子核对应的特征空间维度远高于经典手工核，可能分离经典核无法分离的数据（教材"uncovering patterns that regular methods might miss"）。但同样受编码成本与噪声约束——量子核在硬件上算出的 $\langle\phi|\phi\rangle$ 是带噪估计。

**思路点拨**：核心对比是"手工设计核 vs 电路定义核"。高维空间是量子电路的"免费赠品"，但它的利用受编码与噪声限制——优势是潜在的，不是自动的。

### 3.2 深度学习管道里，k-means、SVM、回归分别被 QML 翻译成什么？这三种翻译共享的数学内核是什么？

**解答**：k-means 聚类 → 量子 k-means（距离 = 量子态重叠/内积，叠加同时算距离）；SVM 分类 → QSVM（特征映射到量子空间，量子核做相似度）；回归 → 量子线性回归（求解线性方程组用量子线性代数，如 HHL）。共享内核是**线性代数操作的量子化**：**内积**（距离与核）、**矩阵求逆/特征分解**（回归、PCA）都被翻译成量子态上的操作——数据被编码成量子态，线性代数变成量子线路，测量读出统计量。一句话：**QML 把深度学习的"矩阵运算内核"换成了量子线性代数。**

**思路点拨**：三个算法看似不同，数学内核都是"线性代数（内积、求逆、分解）"。抓到这个内核，就能理解为什么 QML 论文的加速声明几乎都针对矩阵运算——以及为什么"完整读出矩阵"类任务不划算（读数串行）。
