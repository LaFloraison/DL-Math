# 历史：当一台还在纸面上的机器，开始改写机器学习的账本

## 1995 年，一间办公室，一篇没人当真的论文

苏布拉曼扬·卡克（Subhash Kak）写下了一篇论文的标题：《论量子神经网络》。那一年距离 Shor 的算法问世刚一年，量子计算还只是一堆纸面定理。卡克，一位印度裔的计算科学家，在论文里做了一件超前得几乎荒唐的事：他把人工神经网络和量子比特拼在一起，想象了一种"量子神经元"——用量子态做神经元的激活，用叠加做并行。

论文发表后，几乎没有波澜。没有实验室能实现它，没有公司愿意投资它，同行们礼貌地翻过去。卡克自己后来也说，那是"一篇概念性的文章"。量子神经网络——在 1995 年——是一个没有硬件、没有数据、没有应用场景的纯思想实验。它像一颗埋得很深的种子，在无人看见的土壤里躺了整整二十年。

## 从"没人要"到"抢着做"：2013–2014 年的那场井喷

种子发芽的年份是 2013–2014。麻省理工的赛斯·劳埃德（Seth Lloyd）和帕特里克·雷本特罗斯特（Patrick Rebentrost）、以及后来的马里奥·莫塞尼（Mario Mohseni），在短短一年里连续发表了数篇论文，把"量子机器学习"从概念变成了算法蓝图。

他们的核心想法，值得用一句话说清：**机器学习的瓶颈不是"算法不够聪明"，是"线性代数算得太慢"**——k-means 要算无数个距离、SVM 要算核矩阵、回归要求逆矩阵。而量子计算正好有一批新工具（§12.3.1 的振幅放大、量子内积估计、量子线性方程组求解），能把这些矩阵运算从 $O(N)$ 压到 $O(\log N)$——**只要把数据矩阵本身"装进"量子态。**

于是 2014 年迎来了 QML 的井喷：

- 2013 年，劳埃德等人发表《量子主成分分析》——把大数据矩阵的谱分解变成量子操作；
- 2014 年，雷本特罗斯特等人发表《量子支持向量机》——核矩阵的求逆在量子里变成了内积估计；
- 2014 年，劳埃德、莫塞尼、雷本特罗斯特发表《用于监督和无监督机器学习的量子算法》——k-means、最近邻、谱聚类全部拿到量子版本。

一夜之间，"量子 + 机器学习"从卡克笔下无人问津的幻想，变成了最热的研究方向。美国国防高级研究计划局（DARPA）、Google、IBM、微软纷纷入场。**一个二十年前的概念，在硬件还不存在的时候，先被算法抢跑了。**

## 泼冷水的时刻：快是快了，装不进去

但 2014 年的热情里，已经有人注意到了裂缝。雷本特罗斯特等人在论文里反复强调一个词：**encoding**（编码）——把经典数据装进量子态。

2014 年的一批算法，几乎都建立在同一个假设上：**"假设数据已经被编码成量子态，可以直接作为输入。"** 可这个假设是 QML 最大的暗礁。把 $N$ 个数据点装进 $N$ 个振幅，理想情况只花 $O(\log N)$ 次操作；但构造那个"能装数据的量子态"的**具体线路**，常常要 $O(N)$ 甚至 $O(N \log N)$ 次门——**入场费比比赛奖金还高。**

这个裂缝在 2014–2020 年间不断被学界反复敲打。2018 年，有论文明确指出：很多 QML 论文的"量子加速"在算上编码成本后烟消云散；2021 年，雷本特罗斯特等人自己也更新了观点，强调"编码成本必须被诚实计入"。教材 §12.3.2 那句"encoding … can be complicated and time-consuming, sometimes canceling out the speed advantages"，正是这场十年争论沉淀下来的共识。**QML 从"狂热"走向"诚实"的转折点，就是人们开始认真算"装数据的账"。**

## 硬件登场：NISQ 时代和那台"会算错"的机器

2016 年之后，故事有了第三幕：硬件终于来了，但它不配合。

IBM 在 2016 年把第一台 5 量子比特的量子计算机放上了云端；2019 年，Google 的 Sycamore（§12.2 历史）证明了量子优势。但所有研究者都撞上同一堵墙：**退相干（decoherence）**。量子态活不过足够长的时间——一次计算中途，叠加就被环境"测量"掉，噪声窜入结果。教材那个交易员的例子——10 天股价明明在涨，量子系统却预测成 $140 而不是 $175——不是虚构的寓言，是 NISQ（有噪声中等规模量子，Noisy Intermediate-Scale Quantum）时代的日常。

于是 QML 的叙事从"指数加速"回落成"诚实评估"：当前没有一台机器能跑出 2014 年论文承诺的指数加速；真正在实验室里跑起来的是另一批更务实的东西——**量子核方法、变分量子分类器、混合量子-经典训练**——它们不大规模但真实，不在量子端做完整训练、而在量子端做特征映射和统计量估计，其余交给经典。

## 留一扇门

从卡克 1995 年的概念论文，到 2014 年的算法井喷，再到 NISQ 时代的诚实评估——量子机器学习走完了一个完整的"愿景 → 蓝图 → 现实"循环。它没有失败，它只是学会了算账：**叠加承诺"同时比较"，编码收取"入场费"，硬件制造"中途噪声"，三者必须一起结账。**

而这一切的尽头，指向一个更具体的构想：如果神经网络的"神经元"本身就是量子比特呢？如果权重变成旋转角度、激活变成测量概率、特征关联变成纠缠呢？那不是算法层面的 QML，那是结构层面的——**量子神经网络**。卡克 1995 年那篇没人当真的论文，正在这个方向被重新翻开。下一节，量子神经网络的开幕。
