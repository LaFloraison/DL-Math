# 代码：带噪声的下山——用 NumPy 手写 SGD

**目标**：主线用图 5.8 讲了 $f(x)=x^2+\text{noise}$ 上的 SGD。这里亲手实现：在带噪声的目标上跑**随机梯度下降**，并和**全批量梯度下降**对照。你还会实现教材的**库存例子**——用随机 mini-batch 估计梯度，迭代更新再订货点。核心看点：**SGD 的轨迹是抖的，但它照样收敛到最优点——噪声没有阻止下山，反而让它更稳地穿过了随机世界。**

## 层一：完整脚本

```python
import numpy as np
rng = np.random.default_rng(42)

# ---- 1. 库存例子的数据: 每日需求 X 与当日成本 y (随机需求, 共 400 天) ----
true_theta = 2.0                                  # 假想的"真实最优再订货点"
X = np.linspace(0.5, 3.0, 400)                    # 面积/需求 400 个样本
y = true_theta * X + rng.normal(0, 0.5, len(X))   # 含噪声: y = 2x + eps

def grad_batch(theta):                            # 全数据梯度 (平均归一化)
    return np.sum((theta * X - y) * X) / len(X)

def grad_sample(theta, idx):                      # 单个样本梯度
    return (theta * X[idx] - y[idx]) * X[idx]

# ---- 2. 全批量梯度下降 (基准) ----
theta_bg = 0.5
lr = 0.01
for _ in range(200):
    theta_bg -= lr * grad_batch(theta_bg)

# ---- 3. SGD: 每步随机取 1 个样本估计梯度 ----
theta_sg = 0.5
for t in range(200):
    i = rng.integers(0, len(X))                   # 随机下标
    g = grad_sample(theta_sg, i)                  # 单样本梯度 (带噪声)
    theta_sg -= lr * g                            # theta <- theta - lr * g

print(f"全批量: theta = {theta_bg:.4f}")
print(f"SGD   : theta = {theta_sg:.4f}")
print(f"真实最优 (true_theta) = {true_theta}")
```

输出（随机种子固定，可复现）：

```
全批量: theta = 2.0012
SGD   : theta = 1.9570
真实最优 (true_theta) = 2.0
```

两种方法都收敛到真实最优 $\theta \approx 2.0$ 附近。**但注意差异**：全批量的 2.0012 干净利落，SGD 的 1.9570 带明显偏差——因为最后几步还在被单样本噪声推着抖。**SGD 不是更准，是更快更省**：每步只算 1 个样本的梯度，成本是批量的 1/400，而 200 步照样逼近最优。把 `lr` 改成 0.005 或把步数加到 1000，SGD 会抖得更小、更接近 2.0。

（**注意 `grad_batch` 除以了 `len(X)`**——全批量的梯度是"平均"的，与单样本梯度量级相当，这样两者能用同一个学习率。若不归一化，批梯度是单样本的 400 倍，同样的 `lr=0.01` 会让 BGD 直接发散——这是"批大小影响梯度尺度、需要调学习率"的活教材。）

## 层二：分步逐函数拆解

### 步骤 1：数据与两个梯度函数

```python
true_theta = 2.0
X = np.linspace(0.5, 3.0, 400)
y = true_theta * X + rng.normal(0, 0.5, len(X))

def grad_batch(theta):
    return np.sum((theta * X - y) * X) / len(X)

def grad_sample(theta, idx):
    return (theta * X[idx] - y[idx]) * X[idx]
```

#### `rng.normal(0, 0.5, len(X))` —— 生成随机噪声

**操作**：从均值为 0、标准差 0.5 的正态分布里抽 400 个数，叠加到 `true_theta * X` 上——**这是"随机世界"的制造厂**。`y` 不再是 $2x$ 的精确值，而是 $2x + \varepsilon$。
**输入**：`loc=0`（均值）、`scale=0.5`（标准差）、`size=len(X)=400`（样本数）。**输出**：形状 `(400,)` 的噪声数组。
**可调参数**：
- `scale=0.5`：噪声强度。调到 `2.0`——噪声变大，SGD 轨迹更抖、更难收敛；调到 `0.0`——数据变干净，问题退化成确定性回归。**噪声强度就是"世界的不确定性"的大小。**

#### `grad_batch` —— 全数据梯度（§5.3.6 的梯度）

**操作**：$\sum_i (\theta x_i - y_i)x_i$——用全部 400 个样本算一次梯度。**输入**：`theta`（标量）。**输出**：标量——"干净"的梯度，无噪声。
**可调参数**：无。**它是 SGD 的"裁判"**——用来对照"SGD 每步的噪声梯度最终平均到什么"。

#### `grad_sample` —— 单样本梯度（噪声梯度）

**操作**：只用一个样本 `idx` 算 $\frac{\partial}{\partial\theta}\frac{1}{2}(\theta x_i - y_i)^2 = (\theta x_i - y_i)x_i$。**输入**：`theta`（标量）、`idx`（整数下标）。**输出**：标量——**带噪声的梯度估计**。
**可调参数**：换 `idx`，梯度就换一个方向——这就是"随机性"的注入点。**单个样本的梯度与真实梯度可能相差很远**（有的样本推大 $\theta$，有的推小），但**期望**等于真实梯度（无偏估计）——这是 SGD 能收敛的数学根基（Robbins-Monro）。

**对应数学**：主线里 $\min_x \mathbb{E}_\xi[f(x,\xi)]$ 的离散化——`grad_sample` 是对期望梯度的蒙特卡洛估计，`grad_batch` 是精确期望（在数据分布下的）。

---

### 步骤 2：全批量基线

```python
theta_bg = 0.5
lr = 0.01
for _ in range(200):
    theta_bg -= lr * grad_batch(theta_bg)
```

**操作**：200 步全批量梯度下降，作为"精确但贵"的基准。**输入**：`theta_bg=0.5`、`lr=0.01`。**输出**：收敛后的 `theta_bg`。
**可调参数**：`lr`、`200`（迭代数）。全批量每步 $O(400)$ 次运算——**400 个样本全用上**。

---

### 步骤 3：SGD 主循环——每步一个随机样本

```python
theta_sg = 0.5
for t in range(200):
    i = rng.integers(0, len(X))
    g = grad_sample(theta_sg, i)
    theta_sg -= lr * g
```

#### `rng.integers(0, len(X))` —— 掷骰子选样本

**操作**：从 `[0, 400)` 里均匀抽一个整数下标——**每次迭代都换一个随机样本**，这就是"随机 (stochastic)"的来历。
**输入**：`low=0`、`high=400`。**输出**：整数 `i`。
**可调参数**：把单样本换成 **mini-batch**——一次抽 `b` 个下标（如 `rng.integers(0, 400, size=16)`），用它们的平均梯度更新。**batch 越大越接近全批量（稳但慢），越小越接近单样本 SGD（快但抖）**——这是 §5.6.2 的核心旋钮。

#### `theta_sg -= lr * g` —— 带噪声的更新

**操作**：$\theta \leftarrow \theta - \alpha \hat g$，其中 $\hat g$ 是单样本梯度。**与 §5.3.6 的公式一字不差**——唯一的区别是梯度从"精确"变成"随机估计"。每步都抖，但 `-= lr * g` 保证"平均方向朝下"。
**可调参数**：`lr=0.01`。SGD 的学习率通常要**小于或等于**批量版本（因为单样本梯度噪声大）；也可用**递减步长**（Robbins-Monro 条件：步长总和→∞、平方和有限），越到后期越小步，收敛更稳。

**对应数学**：主线的工具二（SGD）与图 5.8——轨迹带噪声但收敛。

---

### 步骤 4：对照打印

```python
print(f"全批量: theta = {theta_bg:.4f}")
print(f"SGD   : theta = {theta_sg:.4f}")
print(f"真实最优 (true_theta) = {true_theta}")
```

**操作**：三行打印——全批量（精确）、SGD（带噪但够好）、真实最优（真值）。**看点**：SGD 用了 1/400 的每步成本，达到了和全批量几乎一样的收敛水平。

---

## 实验台：让随机性现出真身

1. **换种子**：`rng = np.random.default_rng(7)`——SGD 最终值会变，全批量不变。**SGD 的结果带随机性**，这就是为什么深度学习训练要设 `seed` 保证可复现（reproducible-ml 技能的核心）。
2. **加大噪声**：`scale=2.0`——SGD 轨迹更抖、更难收敛；你看到"世界越不确定，随机优化越艰难"。
3. **换 mini-batch**：把 `rng.integers(0, len(X))` 改成一次取 16 个样本取平均——轨迹明显变稳。**从"单样本"到"mini-batch"到"全批量"，是稳定性和速度的一次次交换**。
4. **递减步长**：`lr` 每步除以 `(t+1)**0.5`——后期步长收窄，SGD 收敛更精确。这正是 Robbins-Monro 条件的实践版。

**对应数学**：实验 1 体现随机优化的"结果分布"性质；实验 3 正是 §5.6.1/5.6.2 里 BGD/SGD/mini-batch 三兄弟的代码原型。
