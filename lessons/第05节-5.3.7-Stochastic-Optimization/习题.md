## 第三组：DL 延伸

**3.1** 深度学习的训练损失 $\mathcal{L}(\theta) = \frac{1}{N}\sum_{i=1}^N \ell(f(x_i;\theta), y_i)$ 在结构上是什么方法的直接应用？为什么说"训练集只是数据分布的一个样本"？这和泛化有什么关系？

**3.2** 为什么 mini-batch SGD 的随机噪声被认为是"隐式正则化"——它可能帮助模型找到更好的局部最优？结合随机优化的"在平均意义上最优"思想解释。

## 解答与思路点拨

### 第一组

**1.1** $\mathbb{E}_\xi[f(x,\xi)]$；随机变量（不确定性）；平均成本（一个标量）；平均（期望/高概率）。**易错点**：把"期望最优"理解成"对最可能场景最优"——错，期望是**所有**场景的加权平均，不是单一场景。

**1.2** 选 B。SAA 的机制就是"用样本均值近似期望"：抽 $N$ 个样本，把 $\mathbb{E}_\xi[f(x,\xi)]$ 替换成 $\frac{1}{N}\sum f(x,\xi_k)$，解替代问题。A 错——SAA 恰恰是"算不出解析期望"时的替代；C 是"鲁棒优化"（最坏情况）的思路，不是 SAA；D 错——样本再多也只是近似期望，无法"消除随机性"（随机性在 $\xi$ 里，不在样本数里）。

**1.3** 错。Robbins-Monro（1951）证明：即使每步梯度带噪声，只要迭代步长满足两个条件（$\sum \alpha_t = \infty$：走得动；$\sum \alpha_t^2 < \infty$：别乱跳），序列**几乎必然收敛**到最优点。关键直觉：单个噪声梯度有偏，但**期望**是真实梯度（无偏估计）——平均起来方向朝下，加上递减步长消除累积抖动，SGD 就能收敛。**判断要点**：把"带噪声"和"不收敛"划等号是最大误区——噪声使收敛"有抖动"，不使收敛"不可能"。

### 第二组

**2.1** $\theta_{\text{new}} = 2.0 - 0.05 \times 0.6 = 2.0 - 0.03 = 1.97$。注意：这是**一步**更新——SGD 会连续做很多步，每步都用新的随机 mini-batch 重新估计梯度。

**2.2**
(a) $\mathbb{E}[Y] = 0.5\times 1 + 0.5\times 3 = 2$。
(b) $\nabla J(\theta) = \mathbb{E}[(\theta - Y)] = \theta - \mathbb{E}[Y] = \theta - 2$。
(c) 令 $\nabla J = 0 \Rightarrow \theta^* = \mathbb{E}[Y] = 2$。**结论：最优预测就是均值**——对平方损失，期望意义下最优的点是均值（这不是巧合，是"最小二乘 = 条件均值"的原理）。
(d) SAA：用样本 $\{1, 3\}$ 平均代替期望，$\hat{\mathbb{E}}[Y] = 2$，替代问题最优解仍是 $\theta = 2$。
**易错点**：(b) 里别忘记期望可以"线性穿透"——$\mathbb{E}[\theta - Y] = \theta - \mathbb{E}[Y]$，$\theta$ 是确定量，$\mathbb{E}[\theta] = \theta$。

**2.3**
(a) `scale=2.0` 时噪声增大，SGD 轨迹更抖，200 步后的 $\theta$ 偏差明显变大（可能停在 1.9–2.1 之外），需要更多步或更小步长才收敛——**世界越不确定，随机优化越难**。
(b) mini-batch（16 样本平均）使梯度估计方差缩小 $\sqrt{16}=4$ 倍，轨迹明显更稳，最终 $\theta$ 更贴近 2.0——**批大小是"速度 vs 稳定"的旋钮**。
**要点**：这两个实验分别对应主线"数据依赖"与"SGD 用 mini-batch"两点。

### 第三组

**3.1** 是 **SAA（样本均值近似）** 的直接应用——用训练集样本平均 $\frac{1}{N}\sum \ell(f(x_i;\theta),y_i)$ 近似对真实分布 $\mathbb{E}_{(x,y)}[\ell]$。说"训练集只是分布的一个样本"是因为：训练集是从真实分布里随机抽出的有限个点，它只能**估计**分布的期望，不能等于分布的期望。泛化因此产生：模型在训练集上最小化的，只是一个**样本均值**，它可能偏离真实分布——所以测试损失会高于训练损失（过拟合的本质），而数据越多、越有代表性，SAA 的近似越接近真实期望。

**3.2** mini-batch SGD 的噪声是梯度估计的随机抖动。为什么是"隐式正则化"：(a) 噪声给参数"随机试探"的能力，能**逃离尖锐的局部极小**（它们对扰动敏感），从而落在更平坦、更宽泛的谷底——而平坦谷底在测试集上更鲁棒（参数微小变化不剧烈影响输出）；(b) 从"平均意义最优"看，噪声下的 SGD 相当于在期望意义下优化，同时被噪声"约束"远离病态尖谷。**要点**：随机优化不再只是"容忍噪声"，而是"利用噪声"——噪声的随机性本身成了一种正则化力量，这正是 §5.3.7 与 §5.6.2 的连接点。
