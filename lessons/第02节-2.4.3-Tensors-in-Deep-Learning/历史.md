# 历史：一群不愿按"人的方式"思考的机器，发明了数字的帝国

## 2012 年的夏天，多伦多的一间实验室

机器爱数字。但要让它爱到什么程度，才有资格谈"理解"？2012 年，在多伦多大学的实验室里，亚历克斯·克里热夫斯基（Alex Krizhevsky）正在和一块 GPU 较劲。

GPU 是个奇怪的仆人——它的心算能力惊人，可它**只听得懂"长方形"**。你给它一排整齐的数字，它能一口气算上亿次；你给它一张乱糟糟的、每个角落大小不一的表格，它当场罢工。

可他要处理的是照片。照片是长方形的吗？一张 224×224 的彩色照片，可以看作一个规整的方阵——高 224 格、宽 224 格，每个格子里压着三个数：红、绿、蓝。这确实是个"长方形"，但它是个**厚的**长方形：每一个位置，都叠着三层数字。

更麻烦的是，他想要的不是一个"对照片的描述"，而是 96 个**同时工作的小探测器**——有的找竖边，有的找横边，有的找圆角。每个探测器都是一个小方块，要在整张照片上滑来滑去。96 个小方块 × 每个小方块的厚度 × 小方块的高和宽——这已经不是"长方形"了，这是**长方形的长方形**。

2012 年以前，没有几个程序员愿意这么想。他们会写一堆特殊代码：图像一个数组、卷积核一个结构体、滤波器组一个对象，每样东西各有各的存放方式，每个运算符都要为每种数据结构单独写一遍。

克里热夫斯基做了个在那个年代显得很笨的决定：**他不管这些数据"本来"是什么，只把它们统统塞进一种东西里——整齐的、有层级的数字方格。**

图像，塞进去。卷积核，塞进去。96 个滤波器的集合，也塞进去。一块 GPU 只要遇到这种"数字的长方形"，就能发挥全部威力。

2012 年 9 月，一个叫 AlexNet 的网络，在这套笨办法上跑通了 ImageNet 的识别比赛——把错误率从 26% 砍到 15%。后来的叙述总把功劳记在 GPU 上。但真正革命的，不是硬件，是那个决定：**把世界上的每一种数据，都翻译成同一种、机器最擅长处理的结构。**

## 五年后：一张"世界上最大的表格"

那个结构后来有了名字——张量。但光有名字还不够。2012 年的 AlexNet 只是把**图像**翻译成了张量。文本呢？语音呢？在 2017 年之前，处理一句话，用的是另一套逻辑：一句话是一个词的序列，序列要**一个词一个词地**喂进网络，像一个人站在传送带前，逐个捡起零件。这很符合人的直觉——话就是一句一句说的呀。

直到 2017 年，一篇叫《Attention Is All You Need》的论文，做了一个更决绝的选择。

它的作者们盯着"一句话"看了很久。那句话有 50 个词。如果每个词被翻译成 300 个数字，那么**整句话**不就是一个 50 行、300 列的表格吗？谁规定语言必须一个词一个词地处理？机器不是人，机器只听得懂"长方形"——那就把一句话，摊成一张大表格，一次性地喂进去。

于是文本、图像、声音、权重、中间结果……2017 年的 Transformer 把所有数据统统压进了同一种结构：张量。不是张量"能装下"这些数据，而是**这个决定本身**让一批新的运算成为可能——整句话同时做相似度计算、整句话并行流动。RNN 靠"逐个词循环"走过的路，Transformer 靠"一张大表格一次算完"走完了。那一年，语言模型的时代开始了。

从 2012 年一摞照片大小的方格，到 2017 年一句完整的自然语言变成一张表格——**数据的外形千变万化，底下的结构只有一个：张量。** 你此刻正在读的这些字，如果被送进模型，也会被翻译成一张张量的表格，在层与层之间流动。

## 留一扇门

可这里藏着一个反直觉的地方：**机器一视同仁地把一切都装进张量，但每一格数字的含义，机器并不自动知道。** 同样是 32，有的位置代表"图有多高"，有的位置代表"有几张图"，有的位置代表"第几个词"。如果没人告诉机器每一维叫什么，那张量就是一团失明的数字——它知道自己在哪个抽屉，却不知道这个抽屉叫什么。

那么，一个张量，到底要怎样才算"被说清楚了"？我们走进主线，看那套被称为"形状"的语言。
