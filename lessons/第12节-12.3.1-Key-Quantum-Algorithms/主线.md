# 主线：关键量子算法——一招绝杀（Shor）与一记普适（Grover）

## 第一步：Toy Model —— 两位不同风格的侦探

两位侦探要破解同一桩案子。

**侦探 A（经典侦探）**，风格严谨。案子涉及一把保险箱密码，密码是一串很大的数字。他拿到数学老师的线索：这个数字可以拆成两个质数的乘积——而保险箱锁匠 RSA 声称，只要拆不出来，箱子就永远是安全的。侦探 A 开始拆：一个个试质数，2 不行、3 不行、5 不行……他拆了几十年，拆到头发花白，还是没拆出来。因为数字每多一位，要试的质数就爆炸式地变多。

**侦探 B（量子侦探）**，风格诡异。他接手同一把锁，却用了一招所有锁匠都没想到的偷梁换柱：他不直接拆数字，而是先让那把锁"自己报出节奏"——锁芯内部有一个齿轮结构，转动它有固定的**周期**：每转 4 圈，锁芯回到同样的状态。B 侦探只需读出这个"4"，套进一个简单的算术公式，两秒钟就把密码拆成了两个质数。锁匠 RSA 震惊了：他赌的是"拆数字很难"，没想到有人能绕过拆数字，直接偷走节奏。

现在换一桩别的案子。一个书库里有一百万本书，其中一本藏着暗号。**侦探 C（经典侦探）**一本一本翻，最坏翻一百万本。**侦探 D（量子侦探）**不翻书，他把一百万本书"同时摊在桌上"看了一遍，然后做了一个奇怪的动作：反复地"更用力地看暗号那本书"——每看一次，暗号那本书就"更亮"一点，其余书"更暗"一点。他大约看了 $\sqrt{1000000} = 1000$ 次，那本书亮得像灯塔，翻开来，正是暗号。

两个故事，两种风格：

- **Shor 算法**——侦探 B：把"分解大数"翻译成"找周期"，再用叠加一次性读出周期。**指数级加速**（把 RSA 的命门连根拔起）。
- **Grover 算法**——侦探 D：无结构搜索，用"振幅放大"让答案概率像聚光灯一样越来越亮。**平方根加速**（一万次变一千次）。

两个故事都该让你问同一个问题：**"读出周期"和"让暗号变亮"，靠的是什么？** 侦探 B 靠的是叠加 + 量子傅里叶变换（§12.2.2 的干涉放大镜）；侦探 D 靠的是叠加 + 振幅放大（还是干涉）。你会发现：量子算法没有魔法，它的全部招式，都是 §12.2 那三根支柱的组合拳——叠加制造"同时在场"，干涉制造"此消彼长"。这一节，我们看这两记组合拳如何打出去。

## 第二步：正式数学讲解

### 一、撞墙：为什么分解大数会"指数级"难？

先认真对待侦探 A 的绝望。你要分解一个 $n$ 位数字 $N$（$N$ 大约 $10^{n-1}$ 到 $10^n$ 之间）。最简单的方法：从 $2$ 开始逐个试质数，看谁整除 $N$。最坏情况要试到 $\sqrt{N}$——因为因子成对出现，超过 $\sqrt{N}$ 的因子必然配一个小因子。

$\sqrt{N} \approx \sqrt{10^n} = 10^{n/2}$。**数字每多 1 位，试除的次数乘以 $\sqrt{10} \approx 3.16$。** 听起来不算恐怖？但把视角拉长：$n = 100$ 位，$10^{50}$ 次试除；$n = 300$ 位（现代 RSA 的典型长度），$10^{150}$ 次——宇宙中原子总数只有约 $10^{80}$ 个，$10^{150}$ 次试除，把全宇宙的原子当计数器都用不完。**这就是"指数级"的真实体重。**

而更精巧的经典算法（数域筛法，GNFS）也没能改变本质：它的耗时随 $n$ 以**次指数**（亚指数）增长，仍然在 $n$ 变大时迅速失控。这就是为什么 RSA 敢把安全赌在"分解大数很难"上——**经典世界里，这条赌注一直是安全的。**

### 二、Shor：把"拆"换成"找周期"

侦探 B 的偷梁换柱，是 Shor 算法的灵魂。核心思想一句话：**找一个数 $a$，观察函数 $f(x) = a^x \bmod N$ 的周期 $r$，然后用 $r$ 反推因子。**

为什么周期能反推因子？以教材反复提到的经典例子 $N = 15$ 为例。取 $a = 2$，看 $f(x) = 2^x \bmod 15$ 的序列：

$$x = 0, 1, 2, 3, 4, 5, 6, 7, \ldots$$
$$f(x) = 1, 2, 4, 8, 1, 2, 4, 8, \ldots$$

$f(x)$ 在 $x = 0, 4, 8, \ldots$ 处都等于 1——**周期 $r = 4$**。这个 4 就是侦探 B 偷走的"节奏"。怎么用？

$$a^{r/2} = 2^{2} = 4, \qquad a^{r/2} + 1 = 5, \qquad a^{r/2} - 1 = 3$$

而 $\gcd(5, 15) = 5$，$\gcd(3, 15) = 3$——**因子自己跳出来了**。这就是 Shor 的精妙：只要读出周期 $r$，再算两个最大公约数 $\gcd(a^{r/2} \pm 1, N)$，因子就到手。数学上 $a^r \equiv 1 \pmod N$（因为 $f(r) = f(0) = 1$），于是 $a^{r/2}$ 和 $\pm 1$ 之间藏着 $N$ 的因子。

**周期从哪来？——量子傅里叶变换 (quantum Fourier transform, QFT)。** 这是 Shor 的量子心脏：把 $f(x)$ 的周期"一次叠加"成频谱。经典找周期要试很多个 $x$（每个都算一次 $f(x)$，再看重复）；量子把所有 $x$ 叠加起来、一次变换、读出周期。**经典要 $O(n^2)$ 到指数次，Shor 只要 $O(n^2)$ 次——从"拆数字"换成"找节奏"，指数级的大山变成了多项式级的山坡。**

> **Shor 算法（因数分解）**
>
> 输入：合数 $N$（$n$ 位）。
> 输出：$N$ 的一个非平凡因子。
>
> 1. 选随机 $a$，计算 $g = \gcd(a, N)$；若 $g > 1$，直接得因子
> 2. 用 QFT 求 $f(x) = a^x \bmod N$ 的周期 $r$（量子步骤，$O(n^2)$ 次操作）
> 3. 若 $r$ 为偶数，计算 $p, q = \gcd(a^{r/2} \pm 1, N)$；若得非平凡因子，成功
> 4. 否则换一个 $a$ 重试
>
> 加速：经典 GNFS 为 $O(e^{c\,n^{1/3}})$（次指数）；Shor 为 $O(n^2 \log n \log\log n)$（多项式）。**指数级 vs 多项式级——这是量子算法史上最著名的一刀。** 它直接威胁 RSA：RSA 的安全赌注"分解大数很难"被改写为"分解大数不难（在量子机器上）"，推动了量子安全密码学 (quantum-safe cryptography) 的诞生。

### 三、Grover：把"翻书"变成"让暗号变亮"

侦探 D 的故事，是 Grover 算法的骨架。$N$ 条无结构数据库，经典最坏翻 $N$ 次，Grover 只要约 $\sqrt{N}$ 次。

Grover 的两步核心，我们在 §12.1 代码里已经见过了——**相位标记 (phase oracle)** 和 **绕平均翻转 (inversion about the mean)**：

1. **叠加入场**：$H^{\otimes n}$ 让 $N = 2^n$ 个状态同时在场（§12.2.2 的均匀叠加）。
2. **相位标记**：一个"判断器"（oracle）识别出目标——但**不读出它**，只在目标的振幅上翻一个负号。这一步不改变任何概率（$|\alpha|^2$ 不变），只埋下"目标与别人不同"的记号。
3. **绕平均翻转**：所有振幅绕平均值翻转。目标（现在最负）被抬到最高，其余被压低。一轮之后，目标的概率涨了一点。
4. **重复**：约 $\frac{\pi}{4}\sqrt{N}$ 轮之后，目标概率接近 1，测量即命中。

用 §12.1 的数字再感受一次：$N = 10^6$，经典最坏 $10^6$ 次，Grover 约 $\lceil \frac{\pi}{4}\sqrt{10^6}\rceil = 786$ 次——**快约 1272 倍**。$N = 10^{12}$，经典 $10^{12}$ 次，Grover 约 $\lceil \frac{\pi}{4}\times10^6\rceil = 785{,}398$ 次——快约 127 万倍。数据库越大，优势越恐怖。

> **Grover 算法（无结构搜索）**
>
> 输入：可判断"是否目标"的黑盒 oracle，$N$ 个条目。
> 输出：目标条目（以高概率）。
>
> $$T_{\text{iterations}} = \left\lceil \frac{\pi}{4}\sqrt{N} \right\rceil$$
>
> - 经典最坏：$O(N)$ 次查询；Grover：$O(\sqrt{N})$ 次
> - 每轮 = 相位标记 + 绕平均翻转（振幅放大，amplitude amplification）
> - 边界：轮数是精确值不是越多越好（§12.1 实验 1：翻倍轮数反而跌回 0.5）；且无结构搜索的最优性有严格证明——$\sqrt{N}$ 是量子搜索的下限

**Grover 的普适性**：它不挑问题结构。数据库搜索、SAT 求解、最短路、以及——深度学习里最诱人的——**优化问题**：任何"在解空间里找最优"的任务，只要能写出"是不是最优"的判断器，就能套上 Grover 的放大。这就是教材说它"especially useful for tasks like database searches and optimization problems"的原因。

### 四、Bloch 球：给算法的对象一张地图

教材在 §12.3.1 处放进了图 12.1——Bloch 球。我们已经见过它的数学（§12.2.1），现在把教材的描述完整对位：

- **北极**：$|0\rangle$ 态（暗红箭头，沿正 z 轴）。对应经典 0，是"纯 0 状态"。
- **南极**：$|1\rangle$ 态（暗绿箭头，沿负 z 轴）。对应经典 1，是"纯 1 状态"。这两个点，就是经典比特的全部地盘。
- **赤道**：$|+\rangle$ 态（暗蓝箭头）。$|+\rangle = \frac{1}{\sqrt2}(|0\rangle+|1\rangle)$，与 $|0\rangle$、$|1\rangle$ 等距的**均衡叠加**——"同时是 0 和 1"的几何落点。

为什么图 12.1 放在算法这一节？因为 $H|0\rangle = |+\rangle$（赤道）、Grover 的绕平均翻转（在球面上把状态点从赤道推高）、Shor 的 QFT（在球面上转相位）——**所有算法动作，都是球面上的点在做运动**。Bloch 球是量子算法的"地图"：经典比特只有南北极两个点，量子算法在整个球面上盘旋，靠叠加（赤道）起手、靠干涉（相位）转向。

### 五、边界声明：两记必杀技各自的短板

诚实划定两条边界，缺一不可：

**Shor 的边界**：它只威胁"基于因数分解/离散对数"的加密（RSA、ECC）。对称加密（AES）、哈希函数（SHA）受 Grover 影响是平方根级的（$2^{128}$ 变 $2^{64}$，仍不可行）。而且 Shor 需要**大规模、容错的量子计算机**——目前最好的实验也只分解了 $15 = 3\times5$ 这样的玩具数字（2017 年 IBM 在 7 量子比特上）。"能跑"和"能威胁 RSA"之间，隔着几十年的工程。

**Grover 的边界**：$\sqrt{N}$ 是"无结构"搜索的最优。有结构的问题（排序、索引）经典本来就是 $O(\log N)$ 甚至 $O(1)$，Grover 反而更慢。而且 §12.1 已强调：轮数必须算准，翻过头会失效。Grover 是"普适但不极端"的加速——它不挑问题，但只给平方根。

一句话记住两者的分工：**Shor 是绝杀（针对性、指数级、威胁加密），Grover 是普适（通用性、平方根、服务搜索与优化）。**

## 第三步：DL 桥接

两个算法给深度学习的启发，是两种不同的"加速哲学"。

**Shor → "换一个数学表示"的加速。** Shor 没有更快地"试除"，它**换了一个问题**——把"拆数字"翻译成"找周期"，周期在叠加里被一次读出。深度学习里的对等物：**换表示 (reparametrization) 与特征变换**。PCA 把数据换到方差最大的方向、傅里叶把信号换到频率域、注意力把 token 换到内积空间——都是"换一个问题，让原本难算的东西变易算"。Shor 是这一哲学最极端的证明：**有时候最快的算法，不是更快地做原题，是改写原题。**

**Grover → "答案概率放大"的优化观。** 深度学习的训练本质是优化——在巨大的参数空间里找损失最低点。Grover 提供一种非经典的优化视角：**不用逐个评估候选，而是让"好候选"的概率被放大**。量子优化（如量子退火、QAOA）正是这一思路的工程化。当然，§12.3.2 会立刻泼冷水：把损失函数编码进量子态（"是不是最优"的判断器）本身要成本，且测量读数受限——Grover 式加速要在"编码成本 vs 放大收益"的赛跑里兑现。

**两记必杀技的共同底座**：叠加 + 干涉。这提醒我们——深度学习里几乎所有"加速"（批量处理、注意力、稀疏化）都能追到某个数学结构，而量子算法的全部结构，都长在 §12.2 那三根支柱上。下一节，我们看这两记必杀技怎么被接进机器学习的管道：量子 k-means、QSVM、量子回归——量子机器学习的开幕。
