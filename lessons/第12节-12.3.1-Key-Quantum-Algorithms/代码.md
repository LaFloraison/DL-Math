# 代码：两记必杀技的实战——Grover 放大，与 Shor 的周期偷梁换柱

主线讲了两件事：**Grover 用"相位标记 + 绕平均翻转"把目标概率放大到接近 1**，**Shor 用"找周期 + 最大公约数"绕过分解大数**。这一课把两者都写成可运行的代码：先用 §12.1 的振幅放大函数跑通 Grover（$N=4$ 一轮命中、$N=16$ 三轮命中），再用纯 Python 复刻 Shor 的周期-因子链路（$15 = 3 \times 5$）。

---

## 层一：完整脚本

```python
import sys                               # 让中文 Windows 控制台也能打印 →、⇒ 等符号
sys.stdout.reconfigure(encoding="utf-8")
import numpy as np
from math import gcd                     # gcd：Shor 反推因子的工具

def grover(N, target, rounds):           # ① Grover 振幅放大
    """N 条无结构数据找 target：每轮=相位标记+绕平均翻转，目标概率逐轮抬升。"""
    psi = np.ones(N, dtype=complex) / np.sqrt(N)   # 均匀叠加入场
    for _ in range(rounds):
        psi[target] *= -1                # 相位标记：只翻目标，概率不变
        psi = 2 * np.mean(psi) - psi     # 绕平均翻转：目标被抬、其余被压
    return psi

# ---- ② Grover 实战 ----
for N, target, rounds in [(4, 3, 1), (16, 7, 3)]:
    probs = np.abs(grover(N, target, rounds)) ** 2
    print(f"Grover N={N:2d}, {rounds} 轮: P(目标)={probs[target]:.4f}, 其余最高={probs[np.argmax(np.delete(probs,target))]:.4f}")

# ---- ③ Shor 的周期-因子链路（N=15） ----
def find_period(a, Nval):                # 找 f(x)=a^x mod N 的周期 r
    seq, x = [], 1
    for _ in range(20):
        seq.append(x)
        x = (x * a) % Nval
    for i in range(1, len(seq)):
        if seq[i] == seq[0]:
            return i, seq                 # 第一次回到 f(0) 的下标 = 周期
    return None, seq

Nval, a = 15, 2
r, seq = find_period(a, Nval)
print(f"2^x mod 15 的前 12 项: {seq[:12]}")
print(f"周期 r = {r}")
half = a ** (r // 2)
f1, f2 = gcd(half + 1, Nval), gcd(half - 1, Nval)
print(f"a^(r/2) = {half} → gcd(a^(r/2)+1,15) = {f1}, gcd(a^(r/2)-1,15) = {f2}  ⇒  15 = {f1} × {f2}")
```

运行输出（Python 3.11 + NumPy）：

```text
Grover N= 4, 1 轮: P(目标)=1.0000, 其余最高=0.0000
Grover N=16, 3 轮: P(目标)=0.9613, 其余最高=0.0033
2^x mod 15 的前 12 项: [1, 2, 4, 8, 1, 2, 4, 8, 1, 2, 4, 8]
周期 r = 4
a^(r/2) = 4 → gcd(a^(r/2)+1,15) = 5, gcd(a^(r/2)-1,15) = 3  ⇒  15 = 5 × 3
```

Grover 用 1 轮和 3 轮分别把 $N=4$ 和 $N=16$ 的目标概率抬到 1.0 和 0.96；Shor 用周期 4 反推出了因子 3 和 5。两记必杀技都落地了。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入

```python
import numpy as np
from math import gcd
```

#### `from math import gcd` —— 最大公约数

**做什么**：引入 `gcd`（最大公约数），Shor 第三步"用 $a^{r/2}\pm1$ 反推因子"的算术工具。
**操作**：标准库导入。`gcd(a, b)` 用欧几里得算法算最大公约数。
**输入**：两个整数。
**输出**：它们的最大公约数。
**可调参数**：无（标准库函数）。
**对应数学**：主线 Shor 算法步骤 3 的 $\gcd(a^{r/2} \pm 1, N)$。

---

### 步骤 2：定义 `grover` —— 相位标记 + 绕平均翻转

```python
def grover(N, target, rounds):
    psi = np.ones(N, dtype=complex) / np.sqrt(N)
    for _ in range(rounds):
        psi[target] *= -1
        psi = 2 * np.mean(psi) - psi
    return psi
```

#### `grover` —— 一轮 = 标记 + 放大

**做什么**：从均匀叠加出发，做 `rounds` 轮"相位标记 + 绕平均翻转"，把目标振幅抬到接近 1。这个函数和 §12.1 的 `grover_like_amplify` 逻辑一致，只是名字更正式——它就是 Grover 的"振幅放大 (amplitude amplification)"引擎。
**操作**：
- 第 1 行：均匀叠加（§12.2.2 的 $H^{\otimes n}$ 入场）。
- 每轮两步：
  - `psi[target] *= -1`：**相位标记 (phase oracle)**——只翻目标的振幅符号，概率（模平方）不变，仅埋下"目标与众不同"的记号。
  - `psi = 2 * np.mean(psi) - psi`：**绕平均翻转**——所有振幅绕均值翻转，目标（现在最负）被抬得最高。
**输入**：`N`（条目数，$2^n$）、`target`（目标下标）、`rounds`（轮数）。
**输出**：叠加向量，目标概率接近 1。
**可调参数**：
- `rounds` 是最关键的旋钮。最优轮数约 $\frac{\pi}{4}\sqrt{N}$ 的最近整数：$N=4$ 取 1（输出 1.0），$N=16$ 取 3（输出 0.9613）。**注意不是越多越好**——$N=16$ 取 4 轮，概率反而跌到 0.58（"聚过头"）。真实实现必须精确计算轮数，这正是 §12.1 实验 1 讲的陷阱。
- 能不能加参数？真实 Grover 需要 oracle 参数（判断"是不是目标"），本脚本直接把 `target` 传进去——它假设 oracle 就是"目标下标"这个黑盒。想模拟真实的 oracle，改成传一个函数 `f(i)` 返回布尔。
**对应数学**：主线 Grover 算法的定义块。$T = \lceil \frac{\pi}{4}\sqrt{N}\rceil$ 轮、$O(\sqrt{N})$ 次查询。

---

### 步骤 3：Grover 实战——两个规模

```python
for N, target, rounds in [(4, 3, 1), (16, 7, 3)]:
    probs = np.abs(grover(N, target, rounds)) ** 2
    print(f"Grover N={N:2d}, {rounds} 轮: P(目标)={probs[target]:.4f}, 其余最高={probs[np.argmax(np.delete(probs,target))]:.4f}")
```

**做什么**：跑两个规模，打印目标概率与"其余条目里的最高概率"。
**操作**：`np.abs(...) ** 2` 求测量概率；`np.delete(probs, target)` 去掉目标后 `np.argmax` 找其余最高的。
**输入**：`(N=4, 目标3, 1轮)` 与 `(N=16, 目标7, 3轮)`。
**输出**：两行。$N=4$：目标概率 1.0、其余 0——一轮就把概率**全部**聚到目标。$N=16$：目标 0.9613、其余最高 0.0033——测量一次，96% 概率命中。
**可调参数**：换目标下标、换 N，都能跑。把 `rounds` 改成比最优多 1，能看到概率回落——亲手验证"轮数必须算准"。
**对应数学**：Grover 的 $\sqrt{N}$ 轮收敛。$N=4 \to 1$ 轮、$N=16 \to 3$ 轮、$N=64 \to 5\text{–}7$ 轮——轮数与 $\sqrt{N}$ 成正比，这就是"平方根加速"在代码里的形状。

### 步骤 4：定义 `find_period` —— Shor 的"找周期"链路

```python
def find_period(a, Nval):
    seq, x = [], 1
    for _ in range(20):
        seq.append(x)
        x = (x * a) % Nval
    for i in range(1, len(seq)):
        if seq[i] == seq[0]:
            return i, seq
    return None, seq
```

#### `find_period` —— 生成 a^x mod N 并找到周期 r

**做什么**：枚举 $f(x) = a^x \bmod N$ 的序列，找到第一次回到 $f(0)$ 的下标——那正是周期 $r$。**这是 Shor 里 QFT 干的活的"经典演示版"**：量子用 QFT 一次读出周期，这里用枚举演示"周期存在"。
**操作**：`x = (x * a) % Nval` 迭代计算 $a^x \bmod N$（模幂）；`seq[i] == seq[0]` 找第一次重复。
**输入**：`a`（底数）、`Nval`（模数）。
**输出**：`(r, seq)`——周期与完整序列。
**可调参数**：
- `a` 换别的底数试试：$a=4, N=15$ 的序列是 $1, 4, 1, 4, \ldots$，周期 2，同样能分解。$a=7, N=15$：$1,7,4,13,1,\ldots$ 周期 4。
- `20` 是枚举上限——对演示足够，真实 Shor 不枚举，用 QFT。
**对应数学**：主线第二节 $f(x) = a^x \bmod 15$ 的序列 $1,2,4,8,1,2,4,8,\ldots$，周期 $r=4$。注意 $a^r \equiv 1 \pmod N$——这是周期定义，也是"因子藏在 $a^{r/2}\pm1$ 里"的根源。

---

### 步骤 5：Shor 反推因子

```python
half = a ** (r // 2)
f1, f2 = gcd(half + 1, Nval), gcd(half - 1, Nval)
```

**做什么**：用周期 $r$ 计算 $a^{r/2}$，再算 $\gcd(a^{r/2}+1, N)$ 和 $\gcd(a^{r/2}-1, N)$——因子从这里跳出来。
**操作**：`a ** (r // 2)` 算 $2^{4/2} = 4$；`gcd(5, 15) = 5`、`gcd(3, 15) = 3`。
**输入**：`half = a^{r/2}`、`Nval`。
**输出**：两个最大公约数，输出 `15 = 5 × 3`。
**可调参数**：`//` 是整除——要求 $r$ 为偶数（$r$ 为奇数时换 `a` 重试，这正是 Shor 步骤 4 的回退）。
**对应数学**：主线第二节的 $\gcd(a^{r/2}\pm1, N)$。数学依据：$a^r \equiv 1$ 意味着 $a^{r/2}$ 的平方 $\equiv 1$，于是 $a^{r/2} \pm 1$ 分别与 $N$ 共享因子。

## 改个数字试试：把参数推向极端

### 实验 1：Grover 轮数敏感性——多一轮，概率就崩

```python
for r in (2, 3, 4, 5):
    p = np.abs(grover(16, 7, r)[7]) ** 2
    print(f"N=16, rounds={r} → P(目标)={p:.4f}")
```

输出：

```text
N=16, rounds=2 → P(目标)=0.9084
N=16, rounds=3 → P(目标)=0.9613
N=16, rounds=4 → P(目标)=0.5817
N=16, rounds=5 → P(目标)=0.0526
```

**最优是 3 轮（0.9613），4 轮就掉到 0.58，5 轮只剩 0.05。** 绕平均翻转是周期运动——目标概率像钟摆，荡过最高点就回落。这就是为什么 Grover 在真实实现里必须精确计算轮数：**它不是"多试几次更保险"的算法，是"剂量精确的算法"。** 这个"剂量"概念，是量子算法与经典直觉最尖锐的冲突。

### 实验 2：Shor 换底数——a=4 也能分解

```python
r2, seq2 = find_period(4, 15)
half2 = 4 ** (r2 // 2)
print(f"4^x mod 15 周期 = {r2}, 序列前 8 项 = {seq2[:8]}")
print(f"gcd(4^(r/2)+1,15) = {gcd(half2+1,15)}, gcd(4^(r/2)-1,15) = {gcd(half2-1,15)}")
```

输出：

```text
4^x mod 15 周期 = 2, 序列前 8 项 = [1, 4, 1, 4, 1, 4, 1, 4]
gcd(4^(r/2)+1,15) = 5, gcd(4^(r/2)-1,15) = 3
```

**换底数 4，周期变成 2，照样分解出 3 和 5。** Shor 的"换 a 重试"机制（步骤 4）正是为了应对不同底数得到不同周期的情况——只要 $r$ 为偶数且 $a^{r/2} \not\equiv \pm 1$，分解就能成功。

## 边界声明：这套代码能做什么，不能做什么

1. **Grover 的 `grover` 是"状态级"演示，不是量子电路。** 真实 Grover 要把 oracle（判断"是不是目标"）实现成量子线路、用多量子比特编码 $N$ 个条目、经过测量读取。本脚本直接对目标下标操作，跳过编码——它演示**振幅放大的数学**，不是可上硬件的电路。把 $N$ 换大一点（如 64），你会看到经典枚举 $N$ 次 vs Grover $\sqrt{N}$ 轮的差距，但脚本本身的复杂度仍是经典（`np.ones(N)` 要真实占用 $N$ 内存）——**这正是经典模拟量子算法的天花板**。
2. **Shor 的 `find_period` 用枚举代替了 QFT，** 所以它展示的是"周期能反推因子"这条**数学链路**，不是量子加速。真实的量子优势在 QFT 一次读出周期，那一步在本脚本里被 `seq` 的线性扫描替代了。想看 QFT 的真身，可以读参考资料的 Nielsen–Chuang 第 5 章。
3. **`N=15` 是玩具规模。** 教材与 2017 年 IBM 实验都分解的是 15——它是"每一步都真、但远不足以威胁 RSA"的示范。真实 RSA 用 300+ 位数字，需要容错量子计算机。**"算法成立"与"能破解加密"之间，隔着几十年工程。** 这条边界务必守住，不要从演示推理出"RSA 已被破解"。
