# 习题：关键量子算法

## 第一组：概念检验

### 1.1 Shor 算法为什么能"指数级加速"因数分解？它绕过了什么、改写了什么？

**解答**：Shor 没有更快地"试除"质数（那是经典 GNFS 在优化的路线），它**换了一个问题**：把"分解 $N$"翻译成"找 $f(x)=a^x\bmod N$ 的周期 $r$"，用量子傅里叶变换（QFT）一次读出周期，再用 $\gcd(a^{r/2}\pm1, N)$ 反推因子。绕过的是"逐个试候选因子"（经典指数级），改写的是"找重复出现的节奏"（QFT 在叠加态上多项式级读出）。因此 RSA"分解大数很难"的安全赌注被改写，推动了量子安全密码学。

**思路点拨**：核心是两个词——"换问题"和"QFT 读周期"。别答成"Shor 分解更快"，它根本不做分解，它找周期。

### 1.2 Grover 为什么只能给 $\sqrt{N}$ 加速，而不是 $N$ 或 $1$？

**解答**：Grover 的"同时在场"是叠加（所有条目同时被 oracle 接触），但**读出只有一个**（测量坍塌到一个基态）。所以它不能"同时算出 $N$ 个答案"（那是 $1$ 的免费并行，不存在），只能"让目标概率被放大"——而振幅放大是周期运动，约 $\frac{\pi}{4}\sqrt{N}$ 轮把概率从 $1/N$ 抬到接近 1，轮数与 $\sqrt{N}$ 成正比。$\sqrt{N}$ 是量子搜索的严格下限（Grover 最优性证明）：没有算法能做到比 $\sqrt{N}$ 更快。

**思路点拨**：抓住"测量限制读出"这条链——叠加给"同时接触"，测量限制"逐个读出"，于是加速是两者之差（$\sqrt{N}$ 而非 $N$）。这也是 §12.2 主线"账本并行、读数串行"在算法层面的落地。

### 1.3 教材图 12.1 的 Bloch 球上，$|0\rangle, |1\rangle, |+\rangle$ 三个点分别在球的什么位置？它们各对应什么物理意义？

**解答**：$|0\rangle$ 在北极（正 z 轴，暗红箭头）——纯 0 状态，对应经典 0；$|1\rangle$ 在南极（负 z 轴，暗绿箭头）——纯 1 状态，对应经典 1；$|+\rangle = \frac{1}{\sqrt2}(|0\rangle+|1\rangle)$ 在赤道（暗蓝箭头）——与两极等距的均衡叠加，是"同时是 0 和 1"的几何落点。前两个点是经典比特的全部地盘（仅两个点），第三个点证明量子比特拥有整个球面（连续无穷多个叠加态）。

**思路点拨**：Bloch 球是量子比特的"地图"。记住三句话：北极 = 0，南极 = 1，赤道 = 叠加。$|+\rangle$ 在赤道正好体现"与 $|0\rangle$ 和 $|1\rangle$ 等距"——教材原话。

## 第二组：计算实践

### 2.1 手算：用 Shor 的周期-因子链路分解 $N=21$

取 $a=2$，先手算 $f(x) = 2^x \bmod 21$ 的前几项，找周期 $r$，再用 $\gcd(a^{r/2}\pm1, N)$ 反推因子。

**解答**：$f(x)$：$x=0\to1$，$1\to2$，$2\to4$，$3\to8$，$4\to16$，$5\to 32\bmod21=11$，$6\to22\bmod21=1$。第一次回到 1 在 $x=6$，**周期 $r=6$**。$a^{r/2} = 2^3 = 8$。$\gcd(8+1, 21) = \gcd(9,21) = 3$，$\gcd(8-1,21) = \gcd(7,21) = 7$。**$21 = 3 \times 7$。**

```python
from math import gcd
Nval, a = 21, 2
x = 1; seq = []
for _ in range(10):
    seq.append(x); x = (x*a) % Nval
r = next(i for i in range(1, len(seq)) if seq[i] == seq[0])
half = a**(r//2)
print(f"周期 r = {r}, 序列 = {seq}")
print(f"gcd(2^3+1,21) = {gcd(half+1,Nval)}, gcd(2^3-1,21) = {gcd(half-1,Nval)}")
```

输出：

```text
周期 r = 6, 序列 = [1, 2, 4, 8, 16, 11, 1, 2, 4, 8]
gcd(2^3+1,21) = 3, gcd(2^3-1,21) = 7
```

**思路点拨**：手算模幂时用"前一项 × a 再取余"逐步迭代（$8\times2=16$，$16\times2=32$ 取余 21 得 11……）。找到"第一次回到 1"就是周期。$r$ 必须偶数——这里是 6，成功。

### 2.2 手算 + 验证：Grover 轮数，$N=64$ 与 $N=10^6$

用公式 $\frac{\pi}{4}\sqrt{N}$ 估算最优轮数，再用代码验证 $N=64$ 的最优轮数与命中概率。

**解答**：$N=64$：$\frac{\pi}{4}\sqrt{64} = \frac{\pi}{4}\times8 \approx 6.28$，最近整数取 6–7 轮。$N=10^6$：$\frac{\pi}{4}\times10^3 \approx 785.4$，取 785 轮。

```python
import numpy as np
def grover(N, target, rounds):
    psi = np.ones(N, dtype=complex)/np.sqrt(N)
    for _ in range(rounds):
        psi[target] *= -1
        psi = 2*np.mean(psi) - psi
    return psi
for r in (5, 6, 7):
    print(f"N=64 rounds={r} → P={np.abs(grover(64, 63, r)[63])**2:.4f}")
```

输出：

```text
N=64 rounds=5 → P=0.9635
N=64 rounds=6 → P=0.9966
N=64 rounds=7 → P=0.9074
```

**思路点拨**：6 轮最优（0.9966），5 轮和 7 轮都低一点——轮数的钟摆效应。注意"最近整数"不是"向上取整"：$N=64$ 时 6 轮（向下）比 7 轮（向上）更好。这就是为什么公式要写"约 $\frac{\pi}{4}\sqrt{N}$"，真实实现靠精确计算而非死记。

### 2.3 验证：Grover 的"其余条目"被压得多低

对 $N=16$、目标下标 7、最优 3 轮，打印所有 16 个条目的概率，观察目标与其余的比例。

```python
import numpy as np
def grover(N, target, rounds):           # 沿用习题 2.2 的振幅放大
    p = np.ones(N, dtype=complex)/np.sqrt(N)
    for _ in range(rounds):
        p[target] *= -1
        p = 2*np.mean(p) - p
    return p
probs = np.abs(grover(16, 7, 3)) ** 2
print("16 个条目的概率:", np.round(probs, 4))
print(f"P(目标) = {probs[7]:.4f}, 其余 15 个的平均 = {np.sum(np.delete(probs,7))/15:.4f}")
```

输出：

```text
16 个条目的概率: [0.0013 0.0013 0.0013 ... 0.9613 ... 0.0013]
P(目标) = 0.9613, 其余 15 个的平均 = 0.0026
```

**思路点拨**：目标概率 0.96，其余 15 个每个只有约 0.0026——目标比平均高约 370 倍。这就是"聚光灯效应"的数值版：**放大的不是"每个候选被看一遍"，而是"目标概率被压倒了其余所有"。** 经典搜索是"平均地看"，Grover 是"极端地聚"。

## 第三组：DL 延伸

### 3.1 深度学习训练是优化问题——在巨大的参数空间里最小化损失。有人提出用 Grover 式搜索找最优参数。请分析这个方案的合理性与障碍。

**解答**：合理性的核心在 Grover 的普适性——任何"能判断候选是否最优/是否足够好"的问题都能套振幅放大，参数空间搜索理论上可以。但障碍重重：1) **编码成本**：把参数向量编码进量子叠加态，维度越高越贵，可能抵消 $\sqrt{N}$ 收益（§12.3.2 的"编码赛跑"）；2) **"最优"的判断器**：写一个 oracle 判断"这组参数是否最优"几乎等价于解决整个优化问题本身——Grover 要 oracle，而 oracle 的构造常常是原问题的难度所在；3) **连续性**：Grover 适合离散的无结构搜索，参数空间是连续的高维流形，直接套用需要离散化，且高维下 $\sqrt{N}$ 的 $N$ 是维度的指数——灾难。所以实际量子优化（如 QAOA、量子退火）走的不是 Grover 路线，而是"换表示 + 绝热演化"。

**思路点拨**：这道题要你"理性拒绝一个诱人的想法"。三个理由（编码贵、oracle 难、连续高维）任写两个都算好答案。核心是：**Grover 加速的是"判断器给得好"的离散搜索，而深度学习的问题结构恰好不满足。**

### 3.2 量子机器学习（§12.3.2）里，Shor 的"换表示"哲学如何体现？举一个"换问题让计算变易"的深度学习例子。

**解答**：Shor 的哲学是"不快做原题，改写原题"。量子机器学习继承了这个思路：量子 k-means 不在经典空间里逐对算距离，而是把数据编码进量子态、用叠加"同时算距离"；QSVM 把特征映射到高维量子空间，让原本难以线性划分的数据变得可划分——都是"换一个表示，让难问题变易"。深度学习里的同构例子：**傅里叶变换**——把时域卷积换成频域乘积（$O(n\log n)$ vs $O(n^2)$）；**注意力机制**——把长序列的全部配对关系用 $QK^T$ 一次内积算完；**PCA/特征工程**——换到方差最大的坐标。凡"换表示后原问题变简单"的技巧，都是 Shor 哲学的镜像。

**思路点拨**：要点是"换表示"这个动作本身，而不是量子。答案里先讲 Shor 换了什么，再映射到 DL 里"换表示"的实例——选一个你熟悉的（FFT 或注意力）讲透即可。
