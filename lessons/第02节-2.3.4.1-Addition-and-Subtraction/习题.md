# 习题：矩阵的加法与减法

## 第一组：概念检验

**1.1（单选）** $A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$、$B = \begin{bmatrix} 2 & 0 \\ 1 & 3 \end{bmatrix}$，则 $A + B$ 等于：
- A. $\begin{bmatrix} 3 & 2 \\ 4 & 7 \end{bmatrix}$
- B. $\begin{bmatrix} 2 & 0 \\ 3 & 12 \end{bmatrix}$
- C. $\begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$
- D. $\begin{bmatrix} 2 & 0 \\ 1 & 3 \end{bmatrix}$

**1.2（判断并说明）** "只要两个矩阵的元素个数一样，就可以相加。" 这句话对吗？

**1.3（填空）** 矩阵加法要求两个矩阵____（形状条件）；减法可以看作加法与____的组合（写成一个式子）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算 $A - B$（$A, B$ 同上），用 NumPy 验证，并与"$A + (-1)\cdot B$"比较。

**2.2（代码验证）** 用 `np.random.rand` 生成两个 `(3,3)` 矩阵，验证加法交换律 $A+B = B+A$ 与结合律 $(A+B)+C = A+(B+C)$。

**2.3（动手理解）** 用代码演示"形状不匹配"：`(2,3)` 矩阵与 `(3,2)` 相加，观察报错；再演示"广播"：`(3,2)` 矩阵与 `(2,)` 向量相加，观察广播沿哪条轴。

## 第三组：DL 延伸

**3.1（场景判断）** 一批输入过线性层后得到 $Z \in \mathbb{R}^{64\times128}$（64 样本、128 输出），现在要加偏置 $\mathbf{b} \in \mathbb{R}^{128}$。这个加法是"矩阵+向量"的广播，还是严格矩阵加法？为什么形状 `(64,128)+(128,)` 能成功？

**3.2（场景分析）** ResNet 的残差连接写成 `y = F(x) + x`（`F` 是卷积等层）。为什么这个"逐元素加法"对训练超深网络至关重要？（提示：梯度传播，§2.2.3.5 的链式法则）

---

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：逐元素相加：$1+2=3$、$2+0=2$、$3+1=4$、$4+3=7$。
- **点拨**：B 是"对应位置相乘"（$1\times2=2$、$3\times1=3$...）——把 `+` 当成 `*` 是高频错。C/D 是原矩阵。

**1.2 不对。**
- **思路**：元素个数相同（如 $2\times3$ 与 $3\times2$ 都是 6 个）不代表形状相同。矩阵加法要求**行数和列数都相同**——$2\times3$ 与 $3\times2$ 不能相加，因为"位置对不上"。
- **点拨**："形状"是矩阵加法的硬条件。这也解释了为什么深度学习的形状约定（$B,d$）那么重要。

**1.3 答案：形状完全相同（同为 $m\times n$）；数乘 $-1$；$A-B = A+(-1)B$。**
- **思路**：加法要求同形状；减法 = 加法 + 数乘 $-1$。
- **点拨**：减法不独立，它是"加逆元"。这在向量空间公理（§2.2.1.5）里是第 4 条加法逆元的直接应用。

### 第二组

**2.1**
$A-B = \begin{bmatrix} 1-2 & 2-0 \\ 3-1 & 4-3 \end{bmatrix} = \begin{bmatrix} -1 & 2 \\ 2 & 1 \end{bmatrix}$。
```python
import numpy as np
A = np.array([[1.,2.],[3.,4.]])
B = np.array([[2.,0.],[1.,3.]])
print(A - B)                 # [[-1.  2.] [ 2.  1.]]
print(np.allclose(A - B, A + (-1)*B))   # True
```
- **思路**：逐元素相减；`A + (-1)*B` 完全等价。
- **点拨**：这就是"减法 = 加法 + 数乘 -1"的验证。写代码时看到 `A - B`，心里翻译成 `A + (-B)`。

**2.2**
```python
A = np.random.rand(3,3); B = np.random.rand(3,3); C = np.random.rand(3,3)
print(np.allclose(A+B, B+A))              # True 交换律
print(np.allclose((A+B)+C, A+(B+C)))      # True 结合律
```
- **思路**：逐元素相加，交换/结合自然成立——因为标量加法满足这两条。
- **点拨**：矩阵加法的性质继承自标量加法，验证只是"抽样确认"。**这与矩阵乘法（不可交换）形成鲜明对比**——记住这个反差，§2.3.4.3 会用。

**2.3**
```python
import numpy as np
M23 = np.ones((2,3)); M32 = np.ones((3,2))
# M23 + M32 -> ValueError (形状不匹配)
b2 = np.array([1.0, 2.0])
print(M32 + b2)    # (3,2) + (2,) -> 广播沿列轴，每列加 1 或 2
```
- **思路**：`(2,3)+(3,2)` 报错；`(3,2)+(2,)` 广播——后对齐，`(2,)` 与第 1 维 2 匹配，所以按"列"加（每行分别加 `[1,2]`）。
- **点拨**：**广播是"对齐末尾维"**。`(3,2)+(2,)` 对齐的是 `2`。若想"加偏置到每行"，`(3,2)+(2,)` 恰好是"每行加一个 2 维向量"——这是深度学习里最常见的广播模式。

### 第三组

**3.1 答案：这是广播加法（工程实现），数学上"矩阵+向量"不是严格矩阵加法。`(64,128)+(128,)` 能成功，因为广播规则把 `(128,)` 对齐到 `(64,128)` 的末维 128，自动"复制"到每一行。**
- **思路**：严格数学中，矩阵加法要求同形状——`(64,128)` 与 `(128,)` 形状不同，数学上不能加。但 NumPy/PyTorch 的广播允许"末维匹配"的加法：`(128,)` 被隐式扩展成 `(64,128)`（复制 64 份）。
- **点拨**：**这是"数学定义"与"工程实现"的分界**。理解广播规则，才能看懂"加偏置"为什么是一行代码。§2.4.4 会把广播讲透。

**3.2 思路**
- 残差连接 $y = F(x) + x$：梯度通过加法时，$\frac{\partial y}{\partial x} = \frac{\partial F}{\partial x} + I$（单位阵来自 `+x` 那条直连）。**直连路径的梯度恒为 1**，不随层数衰减。
- 没有残差时，深网络的反向传播（§2.2.3.5 链式法则）逐层连乘，梯度消失/爆炸；有了 `+x`，梯度多了一条"高速公路"，即使深层梯度被乘小，也能从直连路径原样传回浅层。
- **点拨**：**一次"逐元素加法"，买来了训练超深网络的能力。** ResNet 靠它训练到 152 层（此前深到 20 层就训不动）。矩阵加法的"平凡"，在这里成就了"非凡"。

## 一个"为什么有人会答错"的提醒

1.1 的 B（对应位置相乘）是经典陷阱——很多人把矩阵加法和"哈达玛积"搞混，或者看到 `A*B` 就以为那是矩阵乘法。**记住三条：`+` 逐元素加、`*` 逐元素乘、`@` 矩阵乘。** 三者各不相同。1.2 的"元素个数相同"陷阱也值得警惕——形状（行×列）才是判据，不是总数。
