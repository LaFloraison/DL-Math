## 第一步：Toy Model —— 谷底里的球，山顶上的球

一颗玻璃珠，放在一只碗里。你松手。

珠子顺着碗壁滚下去，在谷底来回晃几下，最终**停在最低点**。现在换一颗珠子，放在一座圆滑的山顶上。你手一松——它立刻滚下山坡，而且**再也回不来了**。

两幕画面，同样是"松手"，结局天差地别。差别不在珠子，而在**那个平衡位置的性质**：

- 谷底：把珠子**轻轻推偏一点**，它自己会滚回来——这个平衡点**稳定 (stable)**。
- 山顶：把珠子推偏一点，它滚得**更远**——这个平衡点**不稳定 (unstable)**。

现在做一件关键的事：**把"碗"和"山"翻译成数学。** 你猜这两幕对应两个完全不同的符号——谷底对应的方程，它的解最终**钉死在一个数上**；山顶对应的方程，解**逃离那个数**。而"钉死"和"逃离"，就是这一节要交给你的两把钥匙。

然后，把眼光从珠子移开。上一节（§11.3.1）我们学了：RNN 的隐藏状态 $h_t$ 是一条在状态空间里滚动的轨道。现在问那个等了整整一章的问题：**这条轨道，最终会停在哪儿？** 是会像谷底的珠子那样"钉死在一个状态"，还是会绕圈、乱掉？——答案，就在"稳定"与"不稳定"这两把钥匙里。

## 第二步：正式数学讲解

### 一、撞墙：轨道会滚，可它会"停"吗？

RNN 的状态 $h_t$ 每步都在更新。但你盯着一条训练好的 RNN 的轨道，会注意到一个现象：**有些轨道，滚着滚着，就不动了。** 输入消失了（比如句子读完了），状态停在某个值上，不再变化。

这个"不再变化"的状态，数学上叫什么？回忆 §11.2.1.2：连续系统的状态演化由 $\frac{dx}{dt} = f(x)$ 决定。**"不再变化" = 变化率为零 = $\frac{dx}{dt} = 0$。** 于是定义降临：

> **不动点 (fixed point / stationary state)** $x^*$
>
> $$f(x^*) = 0, \qquad \frac{dx}{dt}\Big|_{x^*} = 0$$
>
> 物理含义：系统一旦到达 $x^*$，变化率为零，状态从此不再随时间改变——"停住的地方"。
>
> 对 RNN：若连续化状态的演化由 $\frac{dh}{d\tau} = f(h)$ 决定，那么不动点 $h^*$ 就是"网络长期稳定下来的内部状态"。一个 RNN 落在稳定的不动点上，就会对序列给出**一致的输出**——这就是教材说的"long-term behavior of the network"。

但"有不动点"只回答了"有没有停住的地方"，还没回答"轨道**会不会**停在那里"。谷底和山顶都是"停住的地方"（$f=0$），可珠子只会被谷底接住。所以下一件必须问的事是：**不动点，稳吗？**

### 二、稳定性：轻轻推一下，会回来还是离开？

定义稳定性，用一个"扰动实验"。假设系统在不远处：$x = x^* + \delta$，其中 $\delta$ 是很小的偏离。问：$\delta$ 会缩回 0（稳定），还是被放大（不稳定）？

把 $f$ 在不动点附近展开（线性化）：

$$f(x^* + \delta) \approx f(x^*) + f'(x^*)\,\delta = f'(x^*)\,\delta$$

代入演化方程 $\frac{d\delta}{dt} = f(x^* + \delta) \approx f'(x^*)\,\delta$——这是一个线性 ODE，解是

$$\delta(t) \approx \delta(0)\,e^{\,f'(x^*)\,t}$$

于是判据从天而降：

- **$f'(x^*) < 0$：$\delta(t)$ 指数衰减 → 稳定**（谷底，推偏了就滚回来）
- **$f'(x^*) > 0$：$\delta(t)$ 指数增长 → 不稳定**（山顶，推偏了就滚走）

> **稳定性判据（一维）**
>
> $$f'(x^*) < 0 \ \Rightarrow\ \text{稳定不动点（吸引子）}, \qquad f'(x^*) > 0 \ \Rightarrow\ \text{不稳定不动点（排斥子）}$$
>
> - 推导：线性化 $f(x^*+\delta) \approx f'(x^*)\delta$，解 $\delta(t) = \delta(0)e^{f'(x^*)t}$
> - $f'(x^*)$ 的符号决定 $\delta$ 是衰减（稳定）还是放大（不稳定）
> - 多变量推广：把 $f'$ 换成**雅可比矩阵 (Jacobian)** $J$，判据变成"$J$ 的特征值实部是否 < 0"
> - 这个推导完美呼应 §11.2.1.1 的离散判据 $|f'(x^*)| < 1$——只是连续版用"特征值实部 < 0"

这几乎是整章最漂亮的一步：**你不需要知道轨道长什么样，只需要在不动点处求一阶导数，就能判断它稳不稳。** 求导，代替了看球。

### 三、一个完整的手算例子：逻辑斯蒂 ODE

教材这一节的数值例子被截断了，我们用标准的逻辑斯蒂方程把它补完。设状态 $x(t)$ 满足

$$\frac{dx}{dt} = f(x) = x\,(1 - x)$$

**第一步，找不动点：** 解 $f(x^*) = 0$，即 $x^*(1-x^*) = 0$，得 $x^* = 0$ 和 $x^* = 1$。

**第二步，判稳定性：** $f'(x) = 1 - 2x$。于是 $f'(0) = 1 > 0$ → **$x^*=0$ 不稳定**（排斥子）；$f'(1) = -1 < 0$ → **$x^*=1$ 稳定**（吸引子）。

**第三步，验证轨道：** 从 $x(0) = 0.2$ 出发，轨道单调上升，逼近 1；从 $x(0) = 0.8$ 出发，同样逼近 1；从 $x(0) = -0.5$ 出发，轨道一路逃向 $-\infty$（因为它掉进了 0 这个不稳定点的"外推区"）；从 $x(0) = 1.1$ 出发，下降回到 1。**凡是 $x > 0$ 的起点，都被吸向 1；而 0 像一个不稳定的分水岭，从哪一侧靠近它，都会被弹开。**

三句话总结：**不动点 1 是吸引子（谷底），不动点 0 是排斥子（山顶）。** 这就是"长期行为 (long-term behavior)"的全部——轨道最终会"住"在哪个不动点，由稳定性判据一锤定音。

### 四、回到 RNN：不动点就是记忆

现在把镜子转向 RNN。连续时间 RNN (CTRNN) 的隐藏状态演化是

$$\frac{dh}{d\tau} = -h + \sigma(W_{hh}h + W_{xh}x(\tau))$$

看它的不动点方程（输入为 0 的"自由演化"下）：$-h^* + \sigma(W_{hh}h^*) = 0$。满足它的 $h^*$ 就是网络的**长期记忆状态**。这个框架解释了三件大事：

1. **稳定的不动点 = 可靠的记忆。** 如果 RNN 落在稳定不动点上，网络对序列给出**一致、可复现**的输出——教材说的 "consistent outputs for sequences, making its performance reliable"。一个语言模型"记住"了一个确定性的语境，就是状态被吸向一个稳定不动点。
2. **梯度消失 = 被不动点"吸死"。** 上一节说普通 RNN 记不住太久；用稳定性语言说：当 $W_{hh}$ 的谱半径 $< 1$，误差回传时被反复压缩（类似 $\delta(t) = \delta(0)e^{f' t}$ 的指数衰减），轨道**被稳定不动点吸引得太过彻底**，历史信息像扰动一样被抹掉。梯度消失与"状态被吸向不动点"，是同一枚硬币的两面。
3. **吸引子 = 联想记忆。** 霍普菲尔德网络（§11.1 历史的主角）把"存储的记忆"直接设计成稳定不动点：网络从残缺输入出发，轨道滑向最近的那个不动点——这就是"联想记忆"的动力学解释。

> **RNN 的不动点视角**
>
> 自由演化 $\frac{dh}{d\tau} = -h + \sigma(W_{hh}h)$ 的不动点 $h^*$ 满足 $h^* = \sigma(W_{hh}h^*)$。
>
> - 稳定不动点：长期记忆 / 吸引子（联想记忆、一致输出）
> - 不稳定不动点：分水岭（决定轨道会滑向哪个吸引子）
> - 判据：雅可比 $J = -I + W_{hh}\,\text{diag}(\sigma')$ 的特征值实部
> - 梯度消失 ↔ 吸引子吸得太紧；LSTM 的门控 = 给记忆装上"不那么容易滑向不动点"的机制

### 五、边界声明：稳定性分析的三条边界

1. **稳定性是局部的。** 判据 $f'(x^*) < 0$ 只保证"**在不动点附近**"稳定——它基于线性化，是大范围内的近似。一个局部稳定点，可能只是"碗底的小洼"，轨道在更大尺度上另有去处。要判全局，得靠更深的工具（李雅普诺夫函数）。
2. **不动点不是轨道的全部结局。** 稳定不动点是"停住"，但轨道还可能**绕圈**（极限环，对应振荡序列）或**混沌**（§11.2.2.2 的逻辑斯蒂映射）。教材和本节的 RNN 分析聚焦"停住"这一档，是理解更复杂结局的起点，不是终点。
3. **标量判据管不住高维网络。** 真实的 RNN 隐藏状态有几百上千维，判据变成"雅可比矩阵特征值实部"——计算量大、还依赖当前状态。$f'(x^*)$ 只对一维系统是"一锤定音"，对高维系统只是理论骨架。别把 1 维的漂亮判据，误当成高维 RNN 的免检证明。

## 第三步：DL 桥接

这一节的"桥"就是它自己——ODE 与不动点，是解释 RNN 长期行为的语法。三句落点：

- **语言模型与一致性：** 一个训练好的语言模型对同一段上下文反复生成，为什么稳定？因为它的状态被吸向稳定不动点/吸引子——生成过程是"顺着吸引子附近的轨道走"。
- **记忆的保质期：** §11.3.1 的"梯度消失 = 记不住太久"，这里有了精确的机制：误差像扰动 $\delta(t)e^{f't}$ 一样沿时间指数衰减，被稳定不动点"吸死"。LSTM 的门控，就是给这条指数衰减装上"变速器"。
- **Neural ODE 与深度：** §11.2.2.1 的 Neural ODE 把网络写成 $\frac{dh}{d\tau} = f_\theta(h)$，它的"层数"是连续量——而它学到的东西，正是这套不动点/稳定性理论所描述的动力学。

至此，第 11 章的地图全部合拢：**动力系统给了 RNN 状态与轨道，微分方程给了演化规则，不动点与稳定性给了长期行为。** RNN，从此不再是"一个神经网络"，而是一台有数学族谱的时间机器。
