# §11.3.2 用 ODE 解释 RNN —— 习题

主线把 RNN 的长期行为交给 ODE：不动点 $f(x^*)=0$ 是"停住的地方"，判据 $f'(x^*)<0$ 稳定 / $>0$ 不稳定，并用逻辑斯蒂方程 $x'=x(1-x)$ 做完了完整手算。习题分三组：**概念检验** 验证不动点与稳定性判据，**计算实践** 手算判据并做代码对照，**DL 延伸** 把不动点放回 RNN 记忆、梯度消失与联想记忆。

---

## 一、概念检验

### 题 1（选择）：哪个判断**最准确**地描述了稳定不动点？

- A. 系统恰好停在那里，永远不会动
- B. 系统被轻轻推离后，扰动会衰减、最终回到它附近
- C. 系统永远绕着它转圈
- D. 系统的变化率在该点取最大值

**解答**：B。

稳定不动点的定义是**对扰动的反应**：$f'(x^*)<0$ 时，小扰动 $\delta(t)=\delta(0)e^{f' t}$ 指数衰减，系统被拉回。A 只描述了"停住"（不动点的共性），没区分稳定/不稳定；C 是极限环（振荡），不是不动点；D 与稳定性无关。

**思路点拨**：判据是"推一下，回不回来"。A 是常见的陷阱——不动点（$f=0$）和稳定不动点（$f=0$ 且 $f'<0$）不是一回事：山顶也是 $f=0$，但不稳定。**"停住的地方" ≠ "停得稳的地方"。**

### 题 2（判断 + 简答）：为什么 $f'(x^*)$ 的**符号**决定稳定性？

从 $f'(x^*)$ 出发，推导扰动 $\delta(t)$ 的行为，并解释为什么正号 = 增长、负号 = 衰减。

**解答**：在不动点附近设 $x = x^* + \delta$，把 $f$ 线性化：$f(x^*+\delta) \approx f(x^*) + f'(x^*)\delta = f'(x^*)\delta$。代入演化方程得 $\frac{d\delta}{dt} = f'(x^*)\,\delta$——这是一个一阶线性 ODE，解是 $\delta(t) = \delta(0)\,e^{f'(x^*)t}$。**$f'(x^*)<0$ 时指数 $<0$，$\delta$ 指数衰减到 0（稳定）；$f'(x^*)>0$ 时指数 $>0$，$\delta$ 指数放大（不稳定）。** 符号，就是"衰减"与"放大"的分界。

**思路点拨**：把判据**推出来**而不是背下来。$e$ 的指数上挂着 $f'(x^*)$——正负号直接决定扰动是缩回还是飞走。这一行推导，就是 §11.2.1.2"指数增长/衰减"在不动点附近的复现。

### 题 3（简答）：不动点如何解释 RNN 的"长期行为"？

教材说 RNN 的固定点代表网络的长期行为。请用一句话说明：一个 RNN 落在稳定不动点上，对序列输出会有什么性质？不稳定不动点扮演什么角色？

**解答**：RNN 落在稳定不动点上，会给出**一致、可复现**的输出——同一语境反复输入，状态总被吸向同一 $h^*$，所以输出稳定（这正是教材说的 "consistent outputs ... making its performance reliable"）。不稳定不动点则充当**分水岭**：它决定"从不同的起点出发，轨道会滑向哪个稳定不动点"——联想记忆（霍普菲尔德网络）正是把"要记住的图案"设为稳定不动点、让残缺输入滑向最近的它。

**思路点拨**：把"稳定 = 记忆可靠"、"不稳定 = 分水岭"两个意象焊死。稳定不动点是"住的地方"，不稳定不动点是"分界的地方"——RNN 的长期行为，就是这两类点共同编排的剧本。

## 二、计算实践

### 题 1（手算：逻辑斯蒂方程的完整分析）

$\frac{dx}{dt} = x(1-x)$。

(a) 求所有不动点。
(b) 求 $f'(x)$，并判断每个不动点的稳定性。
(c) 不用算轨道，预测：从 $x(0)=0.5$ 出发，长期会停在哪儿？从 $x(0)=1.2$ 呢？从 $x(0)=-0.1$ 呢？

**解答**：

(a) $x^*(1-x^*)=0 \Rightarrow x^*=0$ 或 $x^*=1$。

(b) $f'(x) = 1-2x$。$f'(0)=1>0$ → **0 不稳定**；$f'(1)=-1<0$ → **1 稳定**。

(c) $x(0)=0.5$：落在 $(0,1)$ 内，$f>0$，轨道上升逼近 **1**。$x(0)=1.2$：$x>1$，$f<0$，轨道下降逼近 **1**。$x(0)=-0.1$：$x<0$，$f<0$ 且越来越负，轨道**逃离向 $-\infty$**（0 是排斥子，把负侧的轨道弹走）。长期停在 1，只有 1 是稳定不动点。

**思路点拨**：判据在手，连轨道都不用跑就能预测长期行为——这正是"稳定性分析"存在的意义。别漏 $x(0)=-0.1$ 的情形：它提醒你"稳定不动点"只吸得住它吸引盆里的轨道，0 这个排斥子把负侧弹向深渊。

**NumPy 验证**：
```python
def euler(x0, dt=0.05, steps=200):
    x = x0
    for _ in range(steps):
        x = x + x*(1-x)*dt
    return x
for x0 in [0.5, 1.2, -0.1]:
    print(f"x0={x0} → 末态 = {euler(x0):.4f}")
```
```
x0=0.5 → 末态 = 1.0000
x0=1.2 → 末态 = 1.0000
x0=-0.1 → 末态 = -inf
```

### 题 2（手算 + 代码：另一条 ODE 的判据）

$\frac{dx}{dt} = x^2 - 1$。

(a) 求不动点。
(b) 求 $f'(x)$ 并判稳定性。
(c) 用代码跑轨道，验证 (b)。

**解答**：

(a) $x^{*2} - 1 = 0 \Rightarrow x^* = -1$ 或 $x^* = 1$。

(b) $f'(x) = 2x$。$f'(-1) = -2 < 0$ → **$x^*=-1$ 稳定**；$f'(1) = 2 > 0$ → **$x^*=1$ 不稳定**。

(c) 代码：
```python
def euler(x0, steps=200, dt=0.02):
    x = x0
    for _ in range(steps):
        x = x + (x*x - 1)*dt
    return x
for x0 in [-0.5, 1.5, 3.0, -3.0]:
    print(f"x0={x0} → {euler(x0):+.4f}")
```
```
x0=-0.5 → -1.0000
x0=1.5  → 1.0000      ← 见下方点拨
x0=3.0  → 1.0000
x0=-3.0 → -1.0000
```

**思路点拨**：观察结果有个"反直觉"点：从 1.5 出发末态是 1.0000——但 1 不是被"吸"过去的，它是**被"逼"过去的**：$x>1$ 时 $f=x^2-1>0$，轨道应当**上升逃离**……但数值上它停在 1。原因：$x=1$ 是不稳定不动点，轨道确实在"离开"1，只是 $f$ 在 1 附近很小（$f(1)=0$），且 200 步内离开得极慢，末态恰好显示 1.0000。**把起点改成 1.0001 并跑 2000 步，你会看到它真正逃离**——这就是"局部稳定"的教训：判据只管"附近"，慢速逃逸容易被数值假象掩盖。

### 题 3（手算：把判据接到离散世界）

§11.2.1.1 的离散判据是 $|f'(x^*)|<1$ 稳定；本节连续判据是 $f'(x^*)<0$ 稳定。这两个判据为什么长得不一样？它们各自在判断什么？

**解答**：因为**更新方式不同**。离散系统 $x_{n+1}=f(x_n)$ 的扰动演化是 $\delta_{n+1} = f'(x^*)\delta_n$——每步乘一个数，所以判据是"乘子绝对值 $|f'|<1$"（乘子绝对值小于 1 才收缩）。连续系统 $\frac{dx}{dt}=f(x)$ 的扰动演化是 $\frac{d\delta}{dt}=f'(x^*)\delta$——解 $\delta(t)=\delta(0)e^{f' t}$，所以判据是"指数符号 $f'<0$"。**离散看乘子的绝对值，连续看指数的符号——$|f'|<1$ 与 $f'<0$ 是同一个稳定性直觉（扰动收缩 vs 发散）在两套语言里的各自翻译。**

**思路点拨**：把两个判据并排背一次就永远记住了：离散 → 乘数 $|·|<1$；连续 → 指数 $·<0$。都是"扰动能缩回去吗"。这一题帮你把 §11.2.1.1 与 §11.3.2 焊接成一块完整的地图。

## 三、DL 延伸

### 题 1（梯度消失 = 被稳定不动点"吸死"）

普通 RNN 的误差沿时间回传时指数衰减（梯度消失）。请用本节的不动点/稳定性语言解释：为什么"状态被稳定不动点强烈吸引"和"梯度消失"是同一件事？

**解答**：梯度消失的本质是误差信号 $\delta$ 沿时间反向传播时，每一步被乘一个 $|$谱半径$|<1$ 的因子——指数衰减。而"状态被稳定不动点吸引"的数学也是同一个指数衰减：$\delta(t)=\delta(0)e^{f' t}$，$f'<0$ 时扰动（历史信息）被不动点"吸掉"。**历史信息与误差信号是同一条指数衰减的河**：吸引子吸得越紧（$f'$ 越负 / 谱半径越小），网络"记得越牢的同时"也"忘得越快"——稳定不动点是记忆的终点，也是历史信息被抹平的地方。LSTM 的门控，正是给这条指数衰减装上"先经过一个几乎为 1 的系数"的缓冲（细胞状态梯度近似恒等），让信号能在时间链上走得更远。

**思路点拨**：把"梯度消失"和"吸引子"翻译成同一个指数衰减。这是整章最深刻的连接之一：**记忆的稳定，与记忆的流失，共用同一个数学机制**——你只能在"吸引"与"遗忘"之间找平衡，LSTM 就是在调这个平衡。

### 题 2（联想记忆：为什么网络能从残缺输入"回忆"出完整图案）

霍普菲尔德网络把"要记住的图案"设计成稳定不动点。请解释：为什么网络从**残缺的输入**出发，能恢复出完整图案？"不完整的起点"对应动力系统的什么概念？

**解答**：因为残缺输入只是一个"靠近某个稳定不动点、但不在其上"的初始状态。动力系统说：落在稳定不动点吸引盆里的任何起点，轨道最终都被吸向那个不动点。所以残缺图案 $\to$ 初始状态 $\to$ 轨道滚向最近的稳定不动点 $\to$ 输出完整图案。**"回忆"就是"滑向吸引子"**；"不完整的起点"就是"吸引盆里的一个初始条件"。而能否正确回忆，取决于残缺程度是否还在该不动点的吸引盆内——扰动太大（残缺太多），可能被吸向另一个不动点（记错成另一个图案）。

**思路点拨**：把"联想记忆"翻译成"初始条件被吸引子捕获"。稳定不动点不只是数学对象——它就是记忆本身；吸引盆就是"多残缺仍能回忆起来"的容错范围。这也解释了 §11.1 历史里霍普菲尔德为什么需要李雅普诺夫能量函数：他要证明"网络必然滚向某个不动点"。

**本章延伸预告**：第 11 章到此合拢——动力系统给了 RNN 状态与轨道（11.2），微分方程给了演化规则（11.2.2），不动点与稳定性给了长期行为（11.3.2）。想继续往下走，§10 的傅里叶分析（周期序列的频域视角）与本章的振荡/极限环互为镜像；而 Stochastic Differential Equations（随机版 ODE）是理解扩散模型加噪的下一站。
