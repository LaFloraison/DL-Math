# 代码：谷底与山顶——不动点的稳定性验证

主线说：RNN 的长期行为可以用 ODE 的不动点解释——$f(x^*) = 0$ 是"停住的地方"，$f'(x^*) < 0$ 是谷底（稳定）、$f'(x^*) > 0$ 是山顶（不稳定）。本节用一个完整例子把这条判据变成代码：**逻辑斯蒂 ODE** $\frac{dx}{dt} = x(1-x)$。

脚本做三件事：(1) 求不动点（解 $x(1-x)=0$）；(2) 求导数在不动点处的值，判稳定/不稳定；(3) 从不同初始条件跑轨道（欧拉法），**亲眼验证**轨道被稳定点 1 吸住、被不稳定点 0 弹开。

---

## 层一：完整脚本

```python
import numpy as np                                        # 数组与算术运算

def f(x):                                                 # ① 演化规则右端：dx/dt = f(x)
    """逻辑斯蒂 ODE：x(1-x)。"""
    return x * (1.0 - x)

def fp(x):                                                # ② f 的导数：线性化系数
    """f'(x) = 1 - 2x。"""
    return 1.0 - 2.0 * x

# ---- ③ 求不动点：f(x*) = 0 ----
print("=== 不动点：f(x*) = x*(1-x*) = 0 ===")
print("解析解：x* = 0  或  x* = 1")
print(f"f'(0) = {fp(0):+.1f}  →  {'稳定' if fp(0) < 0 else '不稳定'}")
print(f"f'(1) = {fp(1):+.1f}  →  {'稳定' if fp(1) < 0 else '不稳定'}")

# ---- ④ 欧拉法跑轨道：从不同初始条件出发 ----
def euler(x0, dt, steps):                                 # 数值积分 dx/dt = f(x)
    """从 x0 出发，欧拉法跑 steps 步，返回轨道。"""
    x, traj = x0, [x0]
    for _ in range(steps):
        x = x + f(x) * dt
        traj.append(x)
    return traj

print("\n=== 从不同初始条件出发（dt=0.05, 300 步）===")
for x0 in [0.2, 0.8, -0.5, 0.0, 1.0]:
    tr = euler(x0, 0.05, 300)
    print(f"x0={x0:+.1f}   末态 = {tr[-1]:+.4f}")

# ---- ⑤ 扰动实验：验证稳定性判据 ----
print("\n=== 扰动实验（20 步）===")
tr = euler(1.0 + 0.1, 0.05, 20)                           # 在稳定点 1 附近推偏 0.1
print(f"从 1.1 出发 → {tr[-1]:.4f}   （回到 1 附近 = 稳定）")
tr = euler(0.0 + 0.1, 0.05, 20)                           # 在不稳定点 0 附近推偏 0.1
print(f"从 0.1 出发 → {tr[-1]:.4f}   （远离 0 = 不稳定）")
```

运行输出（Python 3.11 + NumPy）：

```text
=== 不动点：f(x*) = x*(1-x*) = 0 ===
解析解：x* = 0  或  x* = 1
f'(0) = +1.0  →  不稳定
f'(1) = -1.0  →  稳定
=== 从不同初始条件出发（dt=0.05, 300 步）===
x0=+0.2   末态 = +1.0000
x0=+0.8   末态 = +1.0000
x0=-0.5   末态 =     -inf
x0=+0.0   末态 = +0.0000
x0=+0.1   末态 = +1.0000
=== 扰动实验（20 步）===
从 1.1 出发 → 1.0336   （回到 1 附近 = 稳定）
从 0.1 出发 → 0.2290   （远离 0 = 不稳定）
```

看判据与轨道如何互相印证：**$f'(1) = -1 < 0$ → 稳定 → 凡从 $x>0$ 出发的轨道都被吸向 1**（0.2、0.8 都落在 1.0000，1.1 被拉回 1.03）；**$f'(0) = +1 > 0$ → 不稳定 → 从 0.1 出发 20 步就长到 0.229，正在远离 0**；而 $x_0 = -0.5$ 一路逃向 $-\infty$——它掉进了 0 这个排斥子的"外推区"。0 是分水岭：从哪一侧靠近它，都会被弹开。这就是主线判据 $f'(x^*)<0$ 稳定 / $>0$ 不稳定的全部证据。

下面把每段拆开看。

## 层二：分步逐函数拆解

### 步骤 1：定义 `f` 与 `fp` —— 规则与它的导数

```python
def f(x):
    return x * (1.0 - x)

def fp(x):
    return 1.0 - 2.0 * x
```

#### f —— 演化规则右端 $f(x) = x(1-x)$

**做什么**：给定当前状态，返回"此刻的变化率"。这是 ODE $\frac{dx}{dt} = f(x)$ 的右端函数——主线里连续动力系统定义块的 `f` 本身。
**操作**：`x * (1.0 - x)` 一次乘法。$x$ 在 $[0,1]$ 内时 $f>0$（增长）；$x>1$ 时 $f<0$（回落）；$x<0$ 时 $f<0$（逃离）。**这个"承载力"结构正是逻辑斯蒂的名字来源**（§11.2.2.2 的亲戚）。
**输入**：`x`——状态，标量。
**输出**：$f(x)$——变化率，标量。
**可调参数**：这是"逻辑斯蒂"版本。换成 $f(x) = x$（无承载力）就是 §11.2.1.2 的指数增长，不动点只剩 $x^*=0$（不稳定）——轨道要么涨到 $\infty$ 要么缩到 0，没有吸引子。**换右端 = 换整套长期行为**。
**对应数学**：主线定义块 $f(x^*)=0$ 里的 $f$。它是"停在哪、稳不稳"判定的数据源。

#### fp —— 导数 $f'(x) = 1-2x$

**做什么**：返回 $f$ 在 `x` 处的导数——主线稳定性判据 $f'(x^*)$ 的那个数。
**操作**：`1.0 - 2.0*x`。在 $x=0$ 处是 $+1$，在 $x=1$ 处是 $-1$。
**输入**：`x`，标量。
**输出**：$f'(x)$，标量。
**可调参数**：这是解析求导（$\frac{d}{dx}x(1-x) = 1-2x$）。也可以**数值求导**：`(f(x+h)-f(x))/h`——对没有解析导数的 $f$（如含 $\sigma$ 的 RNN 右端）这是通用做法。**判据不依赖你如何求导数，只依赖导数的值。**
**对应数学**：主线判据 $f'(x^*)<0$ 稳定 / $>0$ 不稳定。它是线性化 $f(x^*+\delta)\approx f'(x^*)\delta$ 的系数，直接决定扰动 $\delta(t)=\delta(0)e^{f'(x^*)t}$ 是衰减还是增长。

### 步骤 2：解析求不动点 + 打印判据

```python
print("=== 不动点：f(x*) = x*(1-x*) = 0 ===")
print("解析解：x* = 0  或  x* = 1")
print(f"f'(0) = {fp(0):+.1f}  →  {'稳定' if fp(0) < 0 else '不稳定'}")
print(f"f'(1) = {fp(1):+.1f}  →  {'稳定' if fp(1) < 0 else '不稳定'}")
```

**做什么**：先手解方程 $x(1-x)=0$ 得两个不动点，再分别算 $f'$ 判稳定性。
**操作**：`fp(0)`、`fp(1)` 各算一次；`'稳定' if fp(x) < 0 else '不稳定'` 把判据直接翻译成文字。
**输入**：无（固定调用）。
**输出**：四行文字——不动点列表 + 两个稳定性结论。
**可调参数**：这是"解析法"。一般系统没有解析解，要**数值求根**：`scipy.optimize.fsolve(f, x0)`（从初值 $x_0$ 出发找 $f(x)=0$）——对高维 RNN 的 $h^* - \sigma(W_{hh}h^*)=0$，这就是标准做法。
**对应数学**：主线定义块 + 稳定性判据。`f'(0)=+1` 对应"山顶"（排斥子），`f'(1)=-1` 对应"谷底"（吸引子）。

---

### 步骤 3：定义 `euler` —— 数值积分轨道

```python
def euler(x0, dt, steps):
    x, traj = x0, [x0]
    for _ in range(steps):
        x = x + f(x) * dt
        traj.append(x)
    return traj
```

#### euler —— 欧拉法解 $dx/dt = f(x)$

`x = x + f(x) * dt`

**做什么**：从 `x0` 出发，用欧拉法（§11.2.1.2）把 ODE 积分 `steps` 步，返回整条轨道。这是验证"轨道会不会被吸向不动点"的工具。
**操作**：每步 $x \leftarrow x + f(x)\cdot dt$——"新状态 = 旧状态 + 变化率 × 时间步"。循环 `steps` 次，收集每个状态。
**输入**：`x0`（初始条件）、`dt`（步长）、`steps`（步数）。
**输出**：长度为 `steps+1` 的轨道列表。
**可调参数**：
- `dt` 越小越准（§11.2.1.2 的教训）。这里 `dt=0.05` 对光滑的逻辑斯蒂足够。
- 换成 `scipy.integrate.solve_ivp`（§11.2.2.1）可自适应步长，更准。
- 把 `f(x)` 换成任意右端，`euler` 就是通用积分器——它不知道也不关心规则是谁。
**对应数学**：主线验证"从不同起点跑轨道"的数值手段。轨道被吸向 1（稳定）或被 0 弹开（不稳定），在这里变成可打印的数字。

---

### 步骤 4：从不同初始条件出发——看轨道落点

```python
for x0 in [0.2, 0.8, -0.5, 0.0, 1.0]:
    tr = euler(x0, 0.05, 300)
    print(f"x0={x0:+.1f}   末态 = {tr[-1]:+.4f}")
```

**做什么**：五个起点，各跑 300 步，打印末态——看轨道被谁吸走。
**操作**：`tr[-1]` 取轨道最后一点（$t=15$ 秒）。
**输入**：`x0 ∈ {0.2, 0.8, -0.5, 0.0, 1.0}`。
**输出**：五行的 `(起点, 末态)`：`0.2→1.0000`、`0.8→1.0000`、`-0.5→-inf`、`0.0→0.0000`、`1.0→1.0000`。
**可调参数**：把起点加密成 `np.arange(-0.5, 1.6, 0.1)`，你会看清分水岭：**所有 $x>0$ 的起点都汇向 1，0 自己是不动点，$x<0$ 的起点坠向 $-\infty$**。这就是"吸引子的吸引盆 (basin of attraction)"。
**对应数学**：主线第三节的手算验证。`-inf` 尤其值得玩味：它不是数值错误，是**真的**逃逸——$x<0$ 时 $f(x)<0$ 且越来越负，轨道加速逃离，这正是"不稳定不动点把轨道弹开"的极端形式。

### 步骤 5：扰动实验——直接检验稳定性定义

```python
tr = euler(1.0 + 0.1, 0.05, 20)
print(f"从 1.1 出发 → {tr[-1]:.4f}   （回到 1 附近 = 稳定）")
tr = euler(0.0 + 0.1, 0.05, 20)
print(f"从 0.1 出发 → {tr[-1]:.4f}   （远离 0 = 不稳定）")
```

**做什么**：把稳定性定义本身变成实验——在不动点附近"推偏" 0.1，看轨道被拉回还是被推走。
**操作**：`euler(1.0 + 0.1, 0.05, 20)` 从 1.1 出发跑 20 步；`euler(0.0 + 0.1, 0.05, 20)` 从 0.1 出发跑 20 步。
**输入**：起点 1.1 与 0.1。
**输出**：`1.0336`（回到 1 附近）与 `0.2290`（远离 0）。
**可调参数**：把扰动加大到 0.5：从 1.5 出发仍回到 1（稳定盆大）；从 0.5 出发长到接近 1（它不在 0 的吸引盆，而是 1 的）。把扰动取负（如 `-0.1` 对 0）：轨道更负，逃离更猛。
**对应数学**：主线第二节的扰动实验 $\delta(t) = \delta(0)e^{f'(x^*)t}$。从 1.1 出发 $\delta_0 = 0.1$、$f'(1) = -1$ → $\delta(t) \approx 0.1 e^{-t}$，20 步后 $\approx 0.0336$——与输出 `1.0336` 吻合到小数点后四位；从 0.1 出发 $\delta_0 = 0.1$、$f'(0)=+1$ → $\delta(t) \approx 0.1e^{t}$，指数增长，20 步后远大于 0.229（因为超过线性化区，真实轨道开始向 1 弯曲）。**判据预测了扰动实验，扰动实验印证了判据。**

## 边界声明：这套代码能做什么，不能做什么

1. **判据是局部的。** $f'(x^*)<0$ 只保证**不动点附近**稳定。这个例子是全局吸向 1（逻辑斯蒂幸运地单调），但一般系统里，$f'<0$ 的"谷底"可能只是大尺度地形上的一个小洼——轨道在远处另有去处。要判全局稳定，得靠李雅普诺夫函数（§11.3.2 历史里第二方法）。
2. **`-inf` 是真实逃逸，不是 bug。** 从 $x_0=-0.5$ 出发轨道坠向 $-\infty$，说明 $x^*=0$ 的"吸引盆"里只含它自己一点——0 是排斥子。但注意：**真实系统常在 $x=0$ 处有物理边界**（种群不能为负），此时"逃向 $-\infty$"在物理上不会发生，模型需要截断。数学的无界逃逸 ≠ 物理的无界逃逸。
3. **一维判据 ≠ 高维 RNN。** 这条 $f'(x^*)$ 的漂亮判据只对一维 ODE 成立。真实 RNN 的隐藏状态有几百上千维，判据升级为"雅可比矩阵特征值实部"，而且 $W_{hh}$、激活函数都让"不动点在哪"本身难求。本节的一维逻辑斯蒂是**教学显微镜**——它让你看清机制，但把结论直接搬到高维 RNN 前，请先算雅可比（§11.3.2 主线的边界声明）。
