# 代码：用 NumPy 亲手"捏"出 0 到 4 阶张量

主线里我们把标量、向量、矩阵、彩色照片统一成了"张量"这个家族：靠"阶"和"形状"区分彼此。这一节把这句话变成代码——用 `np.array` 捏出 0/1/2 阶张量，用 `np.zeros` 造一张 $100\times100\times3$ 的彩色照片（3 阶张量），再用 `.ndim` / `.shape` / `.size` 读它的"体检报告"，最后用 `np.prod` 验证"元素总数 = 形状各维之积"。

脚本只依赖 NumPy，约 25 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：张量的造、查、取，全在这里

# ---- ① 0 阶张量：标量，单个数字 ----
c = np.array(5.0)                        # 标量 c = 5，不需要下标就能定位
print("标量 c =", c, "| ndim =", c.ndim, "| shape =", c.shape)

# ---- ② 1 阶张量：向量，一列数 ----
v = np.array([1.0, 2.0, 3.0])            # 向量，形状 (3,)，一个下标 v[i]
print("向量 v =", v, "| ndim =", v.ndim, "| shape =", v.shape)
print("v[1] =", v[1])                    # 一个下标，取第 2 个元素

# ---- ③ 2 阶张量：矩阵，一张数表 ----
M = np.array([[1.0, 2.0], [3.0, 4.0]])   # 矩阵，形状 (2, 2)，两个下标 M[i, j]
print("矩阵 M =", M, "| ndim =", M.ndim, "| shape =", M.shape)
print("M[1, 0] =", M[1, 0])              # 两个下标：第 2 行第 1 列

# ---- ④ 3 阶张量：一张 100×100×3 的 RGB 彩色图片 ----
T = np.zeros((100, 100, 3))              # 图片张量：宽100 × 高100 × 3通道
print("图片 T 形状 =", T.shape, "| ndim =", T.ndim)
T[50, 30, :] = [0.9, 0.2, 0.1]           # 三个下标：第51行、第31列像素设为"偏红"
print("T[50, 30, :] =", T[50, 30, :])    # 该像素三通道：红0.9 绿0.2 蓝0.1

# ---- ⑤ 元素总数：形状各维之积 ----
total = np.prod(T.shape)                 # 100*100*3 = 30000
print("T 的元素总数 =", total)

# ---- ⑥ 4 阶张量：一批 32 张图，多一个"第几张"维 ----
batch = np.zeros((32, 100, 100, 3))      # 批次张量：(32, 高, 宽, 通道)
print("批次形状 =", batch.shape, "| ndim =", batch.ndim,
      "| 元素数 =", np.prod(batch.shape))
```

运行输出（Python 3.11 + NumPy）：

```text
标量 c = 5.0 | ndim = 0 | shape = ()
向量 v = [1. 2. 3.] | ndim = 1 | shape = (3,)
v[1] = 2.0
矩阵 M = [[1. 2.]
          [3. 4.]] | ndim = 2 | shape = (2, 2)
M[1, 0] = 3.0
图片 T 形状 = (100, 100, 3) | ndim = 3
T[50, 30, :] = [0.9 0.2 0.1]
T 的元素总数 = 30000
批次形状 = (32, 100, 100, 3) | ndim = 4 | 元素数 = 960000
```

下面拆开看每一步。

## 层二：分步逐函数拆解

### 步骤 1：造 0 阶张量 `np.array`

```python
c = np.array(5.0)
print("c.ndim =", c.ndim, "| c.shape =", c.shape)
```

#### `np.array(数值)` —— 把单个数字变成 0 阶张量

**做什么**：把标量 `5.0` 包装成一个 0 维的 NumPy 数组——这就是"标量 (scalar)"在计算机里的存在形式。
**操作**：`np.array` 接收一个数值，生成一个 `ndim = 0` 的 `ndarray`。
**输入**：单个浮点数 `5.0`。
**输出**：0 阶张量。`ndim = 0` 表示"0 个维度"，`shape = ()` 表示"形状是空元组"。注意它**不是**长度为 1 的数组——它比向量还"小"，没有轴。
**可调参数**：
- 传整数 `np.array(5)` 得到整型标量；深度学习里建议显式 `dtype=float`（`np.array(5.0)` 已是浮点）。
- 传 `dtype=np.float32` 可省内存——真实框架（PyTorch 的 `torch.tensor`）默认 `float32`。
**对应数学**：主线里 0 阶张量 $c = 5$ 的定义——不需要任何下标就能定位它自己。

### 步骤 2：造 1 阶张量 `np.array`

```python
v = np.array([1.0, 2.0, 3.0])
print("v[1] =", v[1])
```

#### `np.array(列表)` —— 把一列数变成 1 阶张量

**做什么**：把 Python 列表 `[1.0, 2.0, 3.0]` 转成 1 维数组——"向量 (vector)"在计算机里的存在形式。
**操作**：`np.array` 推断出这是一维数据，按顺序存入连续内存。
**输入**：一维列表，3 个浮点数。
**输出**：形状 `(3,)` 的数组。`shape = (3,)` 表示"一维、3 个元素"；`ndim = 1` 表示"需要 1 个下标"。
**可调参数**：
- 列表长度任意：`np.array([1.0, 2.0])` 是 $(2,)$ 的向量，`np.array([1.0])` 是 $(1,)$——**形状 `(1,)` 不是标量**，它是长度为 1 的向量，`ndim` 仍是 1。
- 传嵌套列表会产生更高阶张量（见步骤 3）；`dtype` 参数同上。

#### `v[1]` —— 用一个下标取元素

**做什么**：索引取值。`v[1]` 取第 2 个元素（下标从 0 数起），返回 `2.0`。**一个下标 → 1 阶张量**，这正是主线的判据。
**可调参数**：Python 切片 `v[0:2]` 返回子向量 `[1., 2.]`，不会报错——但注意切片的 `ndim` 仍是 1，只是元素变少。
**对应数学**：主线"1 阶张量需要一个索引 $v_i$ 定位元素"。

### 步骤 3：造 2 阶张量 `np.array`

```python
M = np.array([[1.0, 2.0], [3.0, 4.0]])
print("M[1, 0] =", M[1, 0])
```

#### `np.array(嵌套列表)` —— 把一张数表变成 2 阶张量

**做什么**：嵌套列表 `[[1.0, 2.0], [3.0, 4.0]]`（两个小列表，每个 2 个数）转成 2 维数组——"矩阵 (matrix)"的存在形式。
**操作**：`np.array` 把外层当成第 0 维（行）、内层当成第 1 维（列），要求所有内层等长。
**输入**：形状为"2 个行、每行 2 个数"的嵌套列表。
**输出**：形状 `(2, 2)` 的数组，`ndim = 2`。`M[0]` 是第 1 行 `[1., 2.]`，`M[0, 1]` 是第 1 行第 2 列 `2.0`。
**可调参数**：
- 行列数任意：`np.array([[1.,2.,3.],[4.,5.,6.]])` 形状 `(2, 3)`——行数由外层列表长度决定，列数由内层列表长度决定。
- **内层必须等长**：`[[1., 2.], [3.]]` 会抛 `ValueError`，因为每行的长度不一致，构不成规则的矩形。矩阵（以及所有张量）要求每个维度整齐划一，这是张量的铁律。
- 用 `np.array([...], dtype=float)` 强制浮点。

#### `M[1, 0]` —— 用两个下标取元素

**做什么**：`M[1, 0]` 用逗号分隔的两个下标定位——第 1 个下标选行（`M[1]` → 第 2 行 `[3., 4.]`），第 2 个下标选列（→ `3.0`）。**两个下标 → 2 阶张量**。
**可调参数**：`M[1, :]` 取整行（`[3., 4.]`，仍是 1 维数组）；`M[:, 0]` 取整列（`[1., 3.]`）。下标个数必须 ≤ `ndim`，多给一个会抛 `IndexError`——这正好反证了"阶数 = 需要的下标个数"。
**对应数学**：主线"2 阶张量需要两个索引 $i, j$"与矩阵元素 $M_{ij}$。

### 步骤 4：造 3 阶张量 `np.zeros`

```python
T = np.zeros((100, 100, 3))
T[50, 30, :] = [0.9, 0.2, 0.1]
```

#### `np.zeros(形状元组)` —— 用零填满一块任意形状的张量

**做什么**：按给定形状造一块张量，每个元素初始化为 0——这里是"先圈出一块 $100\times100\times3$ 的空地，再往里面放像素"。
**操作**：`np.zeros` 分配一块连续内存，把所有元素写成 `0.0`。
**输入**：形状元组 `(100, 100, 3)`——三个维度的名字分别是（高, 宽, 颜色通道）。
**输出**：形状 `(100, 100, 3)`、`ndim = 3` 的全零数组。这就是教材里那张 RGB 图片张量 $T_{ijk}$ 的代码形态。
**可调参数**：
- **形状元组完全自由**：`np.zeros((10, 20, 5))` 任意三维，`np.zeros((3, 3))` 是零矩阵，`np.zeros((4,))` 是零向量。
- `dtype` 默认 `float64`；图片常用 `dtype=np.uint8`（0–255 整数亮度）省 8 倍内存。
- 想要初始化为别的值，用 `np.ones(shape)`（全 1）、`np.full(shape, 7.0)`（全 7）或 `np.random.rand(*shape)`（随机）。
- **不传形状参数会怎样**：`np.zeros()` 直接报错——形状是张量的"身份证明"，必须有。

#### `T[50, 30, :]` —— 用三个下标取一个像素的颜色

**做什么**：**三个下标 → 3 阶张量**。`T[50, 30, :]` 定位到"第 51 行、第 31 列"，冒号 `:` 表示"这一维全取"——于是取回那 3 个颜色通道 `[红, 绿, 蓝]`。赋值 `= [0.9, 0.2, 0.1]` 把这个像素涂成"红色多、蓝绿少"的偏红色。
**操作**：NumPy 的高级索引：前两个下标压到具体位置，冒号展开第 3 维。
**输入**：`T`（形状 `(100, 100, 3)`）加下标 `[50, 30, :]`。
**输出**：形状 `(3,)` 的数组 `[0.9, 0.2, 0.1]`——一个像素的 RGB 三通道。
**可调参数**：下标可写全（`T[50, 30, 2]` 单取蓝色分量，返回标量）；冒号位置可换（`T[50, :, 1]` 取"第 51 行的整行绿色分量"，形状 `(100,)`）。下标越界（如 `T[100, 0, 0]`）抛 `IndexError`。
**对应数学**：主线手算 $T_{50, 30, 2}$——第 50 行、第 30 列、第 2 个通道（绿色）的那个数。3 个下标，正好 3 阶。

### 步骤 5：元素总数 `np.prod`

```python
total = np.prod(T.shape)
```

#### `np.prod(数组)` —— 把所有元素相乘（求形状各维之积）

**做什么**：把形状元组 `(100, 100, 3)` 的每一项相乘，得到元素总数 $100 \times 100 \times 3 = 30000$——这是主线"元素总数 = 各维度大小之积"的代码实现。
**操作**：`np.prod` 默认把整个数组的元素逐一相乘。`T.shape` 返回 `(100, 100, 3)`，`np.prod((100, 100, 3)) = 30000`。
**输入**：`T.shape`——形状元组。
**输出**：标量整数 `30000`。
**可调参数**：
- 传任意数组均可：`np.prod([2, 2, 3])` 得 12。
- 参数 `axis`：如 `np.prod(M, axis=0)` 对矩阵按列相乘（结果每列是一个乘积），得到形状 `(2,)`。
- **`np.prod(()) = 1`**：空元组之积约定为 1——这正对应标量 $c = 5$ 的"元素总数就是它自己"（1 个元素）。
**对应数学**：主线"元素总数 = 各维度大小之积，$100 \times 100 \times 3 = 30000$"。同时注意它验证了"形状是张量的身份证明"——元素总数完全由形状决定，与里面的数值无关。

### 步骤 6：4 阶张量——一批图片

```python
batch = np.zeros((32, 100, 100, 3))
```

#### `np.zeros((32, 100, 100, 3))` —— 用 4 维形状造一批图片

**做什么**：32 张 $100\times100\times3$ 的彩色照片摞起来，多出一个"第几张"的维度——`ndim = 4`。
**操作**：同步骤 4 的 `np.zeros`，只是形状元组多了一维。
**输入**：形状 `(32, 100, 100, 3)`——第 0 维 32 是批大小 (batch size)，后三维是单张图（高、宽、通道）。
**输出**：4 阶张量，元素数 $32 \times 100 \times 100 \times 3 = 960000$（约百万）。
**可调参数**：第 0 维即批大小，训练时可改成 64、128；想要视频再多一维时间轴 `np.zeros((32, 30, 100, 100, 3))` 就是 5 阶。**阶数上不封顶，规则一条不变**——n 阶张量 = n 维形状 + 一个 `ndim`。
**对应数学**：主线"一批 32 张照片就是 4 阶张量 $(32, 100, 100, 3)$"，以及"大脑画不出 4 维以上，但数学不在乎"——`np.zeros` 不在乎，它按形状分配内存就行。

## 边界声明：这套代码能做什么，不能做什么

1. **这里没有任何"运算"**：本课只做"造张量 + 读形状 + 取元素"。张量的加减、转置、矩阵乘法、广播 (broadcasting) 是下一节（§2.4.2）的内容。现在看到的 `ndim`、`shape` 只是张量的"出生证明"，不是它的"生活能力"。
2. **深度学习里的"张量"只是多维数组**：`np.array` / `np.zeros` 造出的东西，数学上完全等价于主线里的"张量"——它们都是"数值的多维数组"。但请记住主线里的边界声明：爱因斯坦物理张量的"坐标变换律"在这里**没有**，PyTorch 的 `torch.Tensor` 同样没有。`ndim` 是阶数，与线性代数里矩阵的"秩 (rank)"是两回事。
3. **形状一旦定下就锁死**：`(100, 100, 3)` 的张量**不能**原地变成 `(100, 300)` 或 `(99, 100, 3)`——要改形状只能用 `reshape` / `transpose`（也是下一节的内容），而且改变的元素总数必须一致。企图直接赋一个形状不匹配的值，NumPy 会报 `ValueError`。这正是张量的纪律：形状是身份，不能随意篡改。
4. **维度顺序是约定，不是数学**：`(100, 100, 3)`（高宽通道，HWC）和 `(3, 100, 100)`（通道在前，CHW）数字内容可以完全相同，但第 0 维的语义不同。PyTorch 图像数据惯用 CHW、`PIL`/OpenCV 图像惯用 HWC——跨库搬运数据时先查清楚顺序，这是初学者最常见的 bug 之一。
