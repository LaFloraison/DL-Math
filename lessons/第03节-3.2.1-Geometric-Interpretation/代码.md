# 代码：切一刀，看看切线——并验算二阶偏导

主线里我们用一把刀切开了曲面：沿 $y$ 常数切一刀，剖面上切线的斜率就是 $\partial f/\partial x$；再往下切一层，"斜率的变化率"就是二阶偏导。这一节的脚本把这三件事都做成可运行的：

1. 对抛物面 $z = x^2 + y^2$，在 $(1,2)$ 处算出两个偏导（解析 + 数值对照），并**显式构造**那条切线；
2. 把切片剖面与切线画出来——让"切线斜率 = 偏导"这个几何事实肉眼可见；
3. 对教材高阶偏导例题 $f = x^2y + 3xy^2$，算出一阶、二阶、混合偏导，并**从两个方向**算混合偏导验证 Clairaut 定理。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 抛物面与偏导（教材例题：z = x^2 + y^2，点 (1,2)）----
def f(x, y):
    """抛物面 z = x^2 + y^2：原点最低，向四方张开。"""
    return x**2 + y**2

def dz_dx(x, y): return 2.0 * x        # 解析 ∂z/∂x：冻结 y
def dz_dy(x, y): return 2.0 * y        # 解析 ∂z/∂y：冻结 x

def num_partial(g, p, h=1e-5):
    """对一元函数 g 在点 p 用中心差分求导。"""
    return (g(p + h) - g(p - h)) / (2.0 * h)

# ---- ② 在 y=2 的切片里构造切线：z = f(1,2) + 2*(x-1) ----
x0, y0 = 1.0, 2.0
slope_x = dz_dx(x0, y0)                 # 2x = 2
slope_y = dz_dy(x0, y0)                 # 2y = 4
# 数值验证：沿 y=y0 冻结的切片 g(x)=f(x,2)，在 x=1 处求导
g_slice_x = lambda x: f(x, y0)          # 冻结 y 的一元剖面
g_slice_y = lambda y: f(x0, y)          # 冻结 x 的一元剖面
num_x = num_partial(g_slice_x, x0)
num_y = num_partial(g_slice_y, y0)
print(f"∂z/∂x(1,2) = 解析 {slope_x:.4f}  数值 {num_x:.4f}   # 东西方向坡度")
print(f"∂z/∂y(1,2) = 解析 {slope_y:.4f}  数值 {num_y:.4f}   # 南北方向坡度")

# ---- ③ 教材高阶偏导例题：f(x,y) = x^2*y + 3*x*y^2 ----
def g(x, y): return x**2 * y + 3.0 * x * y**2

def dg_dx(x, y): return 2.0 * x * y + 3.0 * y**2      # ∂f/∂x
def dg_dy(x, y): return x**2 + 6.0 * x * y            # ∂f/∂y
def d2g_dx2(x, y): return 2.0 * y                     # ∂²f/∂x²
def d2g_dy2(x, y): return 6.0 * x                     # ∂²f/∂y²
def d2g_dydx(x, y): return 2.0 * x + 6.0 * y          # 先 x 后 y
def d2g_dxdy(x, y): return 2.0 * x + 6.0 * y          # 先 y 后 x（应相同）

px, py = 2.0, 3.0
print(f"∂f/∂x({px},{py})  = {dg_dx(px, py):.2f}   ∂f/∂y({px},{py})  = {dg_dy(px, py):.2f}")
print(f"∂²f/∂x²  = {d2g_dx2(px, py):.2f}   ∂²f/∂y²  = {d2g_dy2(px, py):.2f}")
print(f"先x后y ∂²f/∂y∂x = {d2g_dydx(px, py):.2f}   先y后x ∂²f/∂x∂y = {d2g_dxdy(px, py):.2f}")

# ---- ④ 画图：切片剖面 + 切线（保存为 png）----
try:
    import matplotlib.pyplot as plt
    xs = np.linspace(-1.0, 3.0, 200)
    z_slice = f(xs, y0)                              # 剖面曲线 z = x^2 + 4
    tangent = f(x0, y0) + slope_x * (xs - x0)        # 切线：过 (1, f(1,2))，斜率 2
    plt.figure(figsize=(6, 4))
    plt.plot(xs, z_slice, label="剖面 z=f(x, 2)=x²+4")
    plt.plot(xs, tangent, "--", label=f"切线：斜率 ∂z/∂x={slope_x:.0f}")
    plt.plot([x0], [f(x0, y0)], "ro", label=f"切点 ({x0:.0f}, {f(x0,y0):.0f})")
    plt.legend(); plt.xlabel("x"); plt.ylabel("z"); plt.grid(alpha=0.3)
    plt.savefig("tangent_slice.png", dpi=120)
    print("已保存 tangent_slice.png：剖面上的切线与偏导数斜率")
except ImportError:
    print("matplotlib 未安装，跳过画图（数值计算不受影响）")
```

运行输出（Python 3.11 + NumPy）：

```text
∂z/∂x(1,2) = 解析 2.0000  数值 2.0000   # 东西方向坡度
∂z/∂y(1,2) = 解析 4.0000  数值 4.0000   # 南北方向坡度
∂f/∂x(2,3) = 39.00   ∂f/∂y(2,3)  = 40.00
∂²f/∂x²  = 6.00   ∂²f/∂y²  = 12.00
先x后y ∂²f/∂y∂x = 22.00   先y后x ∂²f/∂x∂y = 22.00
已保存 tangent_slice.png：剖面上的切线与偏导数斜率
```

注意最后一行：**两条路径算出的混合偏导都是 22.00**——Clairaut 定理在数字面前现形。下面逐段拆解。

## 层二：分步逐函数拆解

### 步骤 1：定义 `f` 与解析偏导 —— 抛物面与它的坡度

```python
def f(x, y): return x**2 + y**2
def dz_dx(x, y): return 2.0 * x
def dz_dy(x, y): return 2.0 * y
```

#### `f(x, y)` —— 抛物面 $z = x^2 + y^2$

`return x**2 + y**2`

**做什么**：教材的抛物面——在原点取最小值 0，向四个方向张开成碗状。它是主线的"丘陵"。
**操作**：逐项平方求和。对每个点 $(x,y)$ 返回高度 $z$。
**输入**：`x`、`y`——可标量或同形状数组。
**输出**：高度值（或数组）。
**可调参数**：无。但可以把系数改大（如 `2*x**2`）让碗在 $x$ 方向更陡，对应偏导 $4x$ 而不是 $2x$。

#### `dz_dx` / `dz_dy` —— 解析偏导

`return 2.0 * x`

**做什么**：对 $x$ 求偏导（冻结 $y$）得到 $2x$；对 $y$ 求偏导得到 $2y$。在 $(1,2)$ 处分别给出 2 与 4——**东西慢、南北陡**，教材原话"在 (1,2) 处 x 方向斜率为 2，y 方向斜率为 4"。
**操作**：直接代入公式。注意 `dz_dx` 不接收也不使用 `y`——这正是"冻结 $y$"在代码里的诚实体现。
**输入**：`x`（和 `dz_dy` 的 `y`）。
**输出**：该方向上的偏导值。
**可调参数**：无。它们由 `f` 的系数唯一决定。
**对应数学**：主线第一步 $\frac{\partial z}{\partial x} = 2x$ 在 $(1,2)$ 处为 2，$\frac{\partial z}{\partial y} = 2y$ 在 $(1,2)$ 处为 4。

---

### 步骤 2：定义 `num_partial` 与切片 —— 数值验证"冻结变量"

```python
def num_partial(g, p, h=1e-5):
    return (g(p + h) - g(p - h)) / (2.0 * h)

g_slice_x = lambda x: f(x, y0)
num_x = num_partial(g_slice_x, x0)
```

#### `num_partial(g, p, h)` —— 中心差分求一元函数导数

`return (g(p + h) - g(p - h)) / (2.0 * h)`

**做什么**：对任意一元函数 `g` 在点 `p` 用中心差分逼近导数。它不知道求导公式，只按定义做事。
**操作**：`g(p+h) - g(p-h)` 量函数在点两侧的高度差，除以跨度 `2h`。`g` 是传入的可调用对象。
**输入**：
- `g`：一元函数（callable）。
- `p`：求导点，标量。
- `h`：步长，默认 `1e-5`。
**输出**：`g'(p)` 的数值近似。
**可调参数**：`h` 是精度旋钮，§3.2 的 U 形曲线在这里同样适用。可以试试 `h=1e-12` 看误差反弹。

#### `lambda x: f(x, y0)` —— 冻结 $y$ 的一元剖面

**做什么**：把二元函数 `f` 的第 2 个参数**钉死**在 `y0`，返回一个只接受 `x` 的一元函数——这就是几何上"沿 $y=y_0$ 平面切一刀"得到的剖面曲线 $g(x) = f(x, 2) = x^2+4$。
**操作**：lambda 闭包捕获 `y0`。传入 `num_partial` 后，数值结果 `2.0` 与解析值 `2x=2` 完全咬合——**"冻结变量"的操作与"切剖面"的几何是同义词**。
**输入**：`x`。
**输出**：剖面高度 $f(x, y_0)$。
**可调参数**：`y0` 换成别的常数，就切在别处。比如切 $y=0$，剖面是 $x^2$，偏导在 $x=0$ 处为 0——那是谷底的"平地"。
**对应数学**：主线"切蛋糕"的第一个动作——用平面 $y=y_0$ 切开曲面。`lambda` 冻结变量，就是定义块里"冻结其余变量"的代码化身。

---

### 步骤 3：定义高阶偏导函数 —— 导数的导数

```python
def g(x, y): return x**2 * y + 3.0 * x * y**2
def dg_dx(x, y): return 2.0 * x * y + 3.0 * y**2
def d2g_dx2(x, y): return 2.0 * y
def d2g_dydx(x, y): return 2.0 * x + 6.0 * y
```

#### `g(x, y)` —— 教材高阶偏导例题 $f = x^2y + 3xy^2$

`return x**2 * y + 3.0 * x * y**2`

**做什么**：选它是因为两个一阶偏导都"有料"——$2xy + 3y^2$ 和 $x^2 + 6xy$，二阶偏导不再是常数，混合偏导有真正的结构。
**操作**：逐项计算。`**` 幂、`*` 乘法。
**输入**：`x`、`y`。
**输出**：函数值。
**可调参数**：系数 3 可以换成任意 $a$。换成 $a=0$，函数变成 $x^2y$，混合偏导变成 $2x$——结构仍在。

#### `d2g_dx2(x, y)` —— $\partial^2 f/\partial x^2 = 2y$

`return 2.0 * y`

**做什么**：对一阶偏导 $2xy + 3y^2$ 再对 $x$ 求导：$2xy \to 2y$，$3y^2$（对 $x$ 是常数）归零。结果 $2y$——**在 $(2,3)$ 处等于 6**，且它还依赖 $y$，说明曲率随位置变化。
**操作**：直接写出二阶导公式。同理 `d2g_dy2` 给出 $6x$。
**输入**：`x`、`y`。
**输出**：二阶偏导值。
**可调参数**：无。换函数就换公式——这正是手写解析法的弱点，数值法没有。
**对应数学**：主线定义块 $\frac{\partial^2 f}{\partial x^2} = \frac{\partial}{\partial x}\left(\frac{\partial f}{\partial x}\right)$。

#### `d2g_dydx` / `d2g_dxdy` —— 混合偏导的两个方向

`return 2.0 * x + 6.0 * y`

**做什么**：`d2g_dydx` 是"先对 $x$ 求、再对 $y$ 求"，`d2g_dxdy` 是"先对 $y$ 求、再对 $x$ 求"。两个函数**写的是同一个公式**——这不是偷懒，而是 Clairaut 定理的预告：混合偏导与求导顺序无关。输出里两条路径都算出 `22.00`，就是定理的数值证据。
**操作**：`dg_dx = 2xy + 3y^2` 对 $y$ 求导得 $2x + 6y$；`dg_dy = x^2 + 6xy` 对 $x$ 求导得 $2x + 6y$。殊途同归。
**输入**：`x`、`y`。
**输出**：混合偏导值。
**可调参数**：无。但你可以故意写错一个（比如把 $6y$ 写成 $6$），数值对照立刻会报警——这正是深度学习里手写 autograd 容易踩的坑，Clairaut 是天然的检验器。
**对应数学**：主线 Clairaut 定理：$\dfrac{\partial^2 f}{\partial y\partial x} = \dfrac{\partial^2 f}{\partial x\partial y}$（二阶偏导连续时）。

### 步骤 4：画图 —— 让切线可见

```python
xs = np.linspace(-1.0, 3.0, 200)
z_slice = f(xs, y0)
tangent = f(x0, y0) + slope_x * (xs - x0)
plt.plot(xs, z_slice, label="剖面 z=f(x, 2)=x²+4")
plt.plot(xs, tangent, "--", label=f"切线：斜率 ∂z/∂x={slope_x:.0f}")
```

**做什么**：画出 $y=2$ 剖面曲线 $z = x^2+4$，以及过切点 $(1, f(1,2)) = (1,5)$、斜率为 2 的切线 $z = 5 + 2(x-1)$。
**操作**：`np.linspace` 生成 $x$ 网格；`f(xs, y0)` 用向量化算整条剖面；`f(x0, y0) + slope_x*(xs - x0)` 用点斜式构造切线（斜率 $2x$ 在切点处等于 2）。`try/except` 包裹，matplotlib 缺失时数值部分不受影响。
**输入**：`xs`（横轴网格）、`y0`、`x0`、`slope_x`。
**输出**：`tangent_slice.png` 图片文件——剖面上切线贴着曲线、又只在切点与曲线重合。
**可调参数**：`xs` 的范围决定看得多远。切点 $x_0$ 换成 $0$，切线斜率变成 0——那是谷底的"平地切线"。
**对应数学**：主线"切线撑起切平面"的第一条边。切平面本身需要两条切线（$x$ 方向与 $y$ 方向）张成——它们是下一节 §3.4 梯度里"上升最陡方向"的前奏。

## 改个数字试试：把切点推向谷底

### 实验 1：切在谷底 $(0,0)$

```python
x0, y0 = 0.0, 0.0
print(f"∂z/∂x(0,0) = {dz_dx(x0, y0):.4f}   ∂z/∂y(0,0) = {dz_dy(x0, y0):.4f}")
```

输出：

```text
∂z/∂x(0,0) = 0.0000   ∂z/∂y(0,0) = 0.0000
```

谷底的坡度是 0——两个偏导同时为零。这正是"梯度为零 → 可能是极值点"的第一印象，也是 §3.4 里"梯度为零的点是局部极值或鞍点"这句话在抛物面上的验证。**谷底是平地**，这个朴素的事实，是梯度下降停止的判据。

### 实验 2：把抛物线 $z = x^2 + y^2$ 换成 $z = x^2 - y^2$

```python
def saddle(x, y): return x**2 - y**2          # 鞍面：x 方向是谷，y 方向是峰
print(f"∂z/∂x(1,1) = {2*x:+.1f}  ∂z/∂y(1,1) = {2*y:+.1f}")  # 设 x=1, y=1
```

输出：

```text
∂z/∂x(1,1) = +2.0  ∂z/∂y(1,1) = +2.0
```

但注意这个函数的**二阶偏导**：$\partial^2 z/\partial x^2 = 2 > 0$（$x$ 方向是谷），$\partial^2 z/\partial y^2 = -2 < 0$（$y$ 方向是峰）。在原点处两个**一阶**偏导都是 0（看起来像极值点），但**二阶**偏导符号相反——这是一个**鞍点 (saddle point)**，不是极值。只靠一阶信息会被骗，二阶偏导揭穿了真相。这就是为什么 §3.2.1 的二阶偏导不是书斋趣味：**它决定一个"平地"到底是不是谷底。**

## 边界声明：这套代码能做什么，不能做什么

1. **切线是局部的，切平面也是。** 代码里那条切线只在切点附近贴着剖面曲线，离远了就分道扬镳。曲面是弯曲的，切线是直的——切平面是曲面在**一个点**上的最佳线性近似，离开这个点，误差迅速累积。这正是"局部线性化"的含义，也是所有牛顿型优化方法（§3.6.3）工作的前提与失效的边界。
2. **二阶偏导是"局部曲率"，不是全局形状。** `∂²f/∂x²` 在某个点告诉你的只是那一处的弯曲程度，换个点数值就变（$f = x^2y + 3xy^2$ 的 $\partial^2 f/\partial x^2 = 2y$ 依赖 $y$）。把全部二阶偏导拼成海森矩阵（Hessian），得到的也只是**那一个点**的完整曲率信息，不描述整座曲面。
3. **Clairaut 交换律有前提。** 代码里两条路径相等，是因为这个多项式处处光滑。函数在"折痕"处（如 ReLU 的零点）二阶偏导不存在，交换律自然失效。深度学习里很多二阶信息（曲率估计）在非光滑激活下是"名义上"的——明白这一点，你就不会在梯度对不上时惊慌。
4. **数值差分是近似。** `num_partial` 的精度受 $h$ 约束（U 形曲线），它验证了解析结果，但它本身不是解析值。手写解析偏导虽然"脆"（改公式就要改代码），但它提供了精确的基准——真实框架正是靠解析求导 + 数值梯度检查互相印证的。
