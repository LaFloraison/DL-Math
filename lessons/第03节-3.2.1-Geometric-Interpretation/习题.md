# 习题：偏导数的几何解释

## 一、概念检验

### 题 1.1（填空）

对曲面 $z = f(x,y)$，$\dfrac{\partial f}{\partial x}$ 在点 $(x_0, y_0)$ 的几何意义是：用平面 ____ 切开曲面，剖面上在 $x = x_0$ 处____的斜率。同理 $\dfrac{\partial f}{\partial y}$ 对应平面 ____ 处的剖面。

**解答**：$y = y_0$；切线；$x = x_0$。
**思路点拨**：关键词是"冻结"。"$y = y_0$"就是冻结 $y$，"$x = x_0$"就是冻结 $x$。答错者常把两个方向搞混——记牢：**对谁求导，谁就在剖面线上动；另一个方向被刀冻住。** 画出"切蛋糕"的图，这条就不会错。

### 题 1.2（选择）

下列关于二阶偏导的说法，**错误**的是（ ）

A. $\dfrac{\partial^2 f}{\partial x^2}$ 描述的是"沿 $x$ 方向的坡度变化得多快"
B. 混合偏导 $\dfrac{\partial^2 f}{\partial y\partial x}$ 读作"先对 $x$ 求、再对 $y$ 求"
C. Clairaut 定理保证混合偏导在**任意**函数上都与求导顺序无关
D. 把函数所有二阶偏导排成矩阵，称为海森矩阵

**解答**：C。
**思路点拨**：A 正确——二阶偏导就是"坡度（一阶）的变化率"，即曲率。B 正确——记号从右往左读。D 正确——Hessian 矩阵 $H_{ij} = \partial^2 f/\partial x_i\partial x_j$。C 是陷阱：Clairaut 交换律的前提是**二阶偏导连续**。函数在"折痕"处（如 ReLU 零点）二阶偏导不存在，交换律无从谈起。选 C 的同学往往把定理当成无条件成立的公理——它是一条有条件的**安全网**，不是免检章。

### 题 1.3（简答）

在点 $(x_0, y_0)$ 处，$\partial f/\partial x$ 与 $\partial f/\partial y$ 两条切线，能完整描述曲面在这一点的陡峭度吗？还缺什么？

**解答**：不能。两条切线只给出 $x$、$y$ 两个坐标轴方向的信息，而曲面上从该点出发有**无穷多个方向**（东北、西北、东南……每个方向都有各自的坡度）。两条切线张成的切平面只是曲面局部的"最佳平板近似"，但"朝任意方向有多陡"需要把所有偏导数组装成**梯度**、再用方向导数去量——那是 §3.4 的内容。
**思路点拨**：这道题考的是主线边界声明——切线不等于曲面，偏导只是两个方向的切片。能答出"还差所有其他方向的坡度"，说明你已经看到 §3.4 梯度的必要性。

## 二、计算实践

### 题 2.1（手算）

设 $f(x,y) = x^3y + 2x^2y^2$。

(a) 求一阶偏导 $\partial f/\partial x$、$\partial f/\partial y$。
(b) 求二阶偏导 $\partial^2 f/\partial x^2$、$\partial^2 f/\partial y^2$ 和两个混合偏导。
(c) 验证：在 $(1, 2)$ 处，$\partial^2 f/\partial y\partial x = \partial^2 f/\partial x\partial y$。

**解答**：
(a) $\dfrac{\partial f}{\partial x} = 3x^2y + 4xy^2$，$\dfrac{\partial f}{\partial y} = x^3 + 4x^2y$。
(b) $\dfrac{\partial^2 f}{\partial x^2} = 6xy + 4y^2$；$\dfrac{\partial^2 f}{\partial y^2} = 4x^2$；混合偏导 $\dfrac{\partial^2 f}{\partial y\partial x} = 3x^2 + 8xy$（对 $\partial f/\partial x$ 再对 $y$ 求），$\dfrac{\partial^2 f}{\partial x\partial y} = 3x^2 + 8xy$（对 $\partial f/\partial y$ 再对 $x$ 求）。
(c) 代入 $(1,2)$：两者都等于 $3 \cdot 1 + 8 \cdot 1 \cdot 2 = 19$。
**思路点拨**：混合偏导**两条路都要算**——这不仅验证 Clairaut，也是发现手算错误的习惯。代入点之前先写成一般式，再代数字，减少出错。算完用《代码.md》的 `d2g_dydx` 风格函数验证。

### 题 2.2（代码验证）

验证 $f(x,y) = x^2 + 2xy + y^2$ 在 $(1, 1)$ 处的两个混合偏导相等，并计算 $\partial^2 f/\partial x^2$ 的数值。

```python
import numpy as np
def f(x, y): return x**2 + 2.0*x*y + y**2
h = 1e-5
# 混合偏导 ∂²f/∂y∂x：对 f 先让 x 动、再让 y 动
mixed = (f(1+h, 1+h) - f(1+h, 1-h) - f(1-h, 1+h) + f(1-h, 1-h)) / (4*h*h)
# 二阶 ∂²f/∂x²：f(x+h,y)-2f(x,y)+f(x-h,y) 除以 h²
second_x = (f(1+h, 1) - 2*f(1, 1) + f(1-h, 1)) / (h*h)
print(f"混合偏导 ≈ {mixed:.4f}   二阶 ∂²f/∂x² ≈ {second_x:.4f}")
```

**解答**：混合偏导 $\approx 2.0000$（解析：$f$ 的 $2xy$ 项贡献 2，$x^2$、$y^2$ 贡献 0）。二阶 $\partial^2 f/\partial x^2 \approx 2.0000$（解析：$x^2$ 项二阶导为 2）。
**思路点拨**：二阶导数的标准数值格式是**二阶差分** $\dfrac{f(x+h)-2f(x)+f(x-h)}{h^2}$，混合偏导则是"先差 $x$、再差 $y$"的四点组合。把 `h` 改成 `1e-10` 看看浮点消减怎么破坏结果——呼应《代码.md》实验 1 的 U 形曲线。

## 三、DL 延伸

### 题 3.1

训练时损失曲面 $L(w)$ 在某个权重方向的一阶偏导 $\partial L/\partial w$ 接近 0，工程师说"到极值点了，可以停"。请指出这个判断为什么可能出错，并说明二阶偏导如何帮助修正。

**解答**：一阶偏导为零只能说明这是"平地"，不能区分谷底、峰顶还是鞍点——三种情况都满足 $\partial L/\partial w = 0$。要看二阶偏导：$\partial^2 L/\partial w^2 > 0$ 是谷底（局部极小），$< 0$ 是峰顶（局部极大），$\partial^2 L/\partial w^2$ 为 0 或正负交叉需要继续判断。在多维情形下，需要看海森矩阵的特征值——全正才是局部极小，有正有负是鞍点。所以"一阶为零就停"在鞍点处会停在错误的地方，二阶信息（曲率）才是裁决者。
**思路点拨**：这是 §3.2.1 代码实验 2 的理论化——鞍面 $z = x^2 - y^2$ 在原点一阶偏导全为零、二阶偏导符号相反。深度学习里鞍点远比局部极小常见（高维空间的鞍点密度很高），理解"一阶零 ≠ 极值"能帮你看懂为什么训练会在某个损失值"卡住"。

### 题 3.2

现代优化器 Adam 在更新每个权重 $w_i$ 时，用一阶偏导的历史平方来缩放学习率：更新的分母是 $\sqrt{\hat{v}_t} + \epsilon$，其中 $\hat{v}_t$ 是一阶偏导平方的指数加权平均。请用 §3.2.1 的语言解释：Adam 是在用什么"信息"来给每个方向定步幅？它和"二阶偏导 = 曲率"有什么关系（直觉层面即可）？

**解答**：$\hat{v}_t$ 统计的是"这个方向上一阶偏导最近有多大"。如果某个方向的偏导一直很大（损失曲面在那里陡峭、起伏剧烈），$\hat{v}_t$ 就大，分母就大，实际步幅被压缩；反之偏导小（曲面平缓），步幅放宽。**大的偏导平方 ≈ 该方向地形起伏剧烈 ≈ 高曲率**，Adam 用一阶偏导的历史量作为曲率（二阶信息）的廉价估计，给"弯曲剧烈"的方向分配更小的步幅——这正是主线 DL 桥接里"Adam 用一阶历史平方估计有效曲率"那句话的具体化。
**思路点拨**：严格说，真曲率是 $\partial^2 L/\partial w^2$，Adam 用的是它的**近似代理**——不需要算二阶导（太贵），用一阶的历史统计顶替。能说出"代理曲率"这层，就说明你看穿了 Adam 和本节的连接。这是深度学习中"用便宜的东西逼近昂贵的东西"的经典范例。
