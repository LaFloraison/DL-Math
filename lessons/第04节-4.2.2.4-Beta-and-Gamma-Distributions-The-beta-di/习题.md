# 习题：Beta 与 Gamma 分布

## 第一组：概念检验

**1. 用一句话回答：Beta 分布和 Gamma 分布各自"专治"什么问题？**

**解答**：Beta 专治"定义在 $[0,1]$ 上的概率或比例"——它给"一个概率本身"建模，形状由 $\alpha,\beta$ 拧出来；Gamma 专治"等到第 $\alpha$ 个事件发生"的等待时间——当 $\alpha$ 为正整数时，它正是 $\alpha$ 个独立指数变量之和。一个管"比例的世界"，一个管"等待的世界"。

**2. 为什么说 Beta 分布是"贝叶斯的第一块砖"？$\alpha$ 和 $\beta$ 可以理解成什么？**

**解答**：因为对"抛硬币得到正面概率 $p$"这件事，Beta 分布提供了"先给 $p$ 一个信念分布、看到数据后更新它"的完整语言。$\alpha$ 可以理解成"（成功的次数 $+1$）"，$\beta$ 理解成"（失败的次数 $+1$）"：抛 9 正 1 反 → $\text{Beta}(10,2)$，均值 $\frac{10}{12}\approx0.83$ 恰好贴合直觉。看到的数据越多，$\alpha+\beta$ 越大，曲线越尖——信念越确定。这个"用计数更新分布"的机制，就是 §4.4 贝叶斯统计的雏形。

**3. 判断题并解释："$\text{Gamma}(2, \lambda)$ 的均值是 $\text{Exp}(\lambda)$ 的两倍，因为它要等两次。"**

**解答**：正确。$\text{Gamma}(2,\lambda)$ 是两个独立 $\text{Exp}(\lambda)$ 之和，期望可加：$\mathbb{E}[X_1+X_2]=\frac1\lambda+\frac1\lambda=\frac2\lambda$。但注意这只是**均值**：分布的形状完全不同——单指数从 $x=0$ 直接下坠，Gamma(2) 从 0 爬起、中途隆起再下降。"等两个事件"几乎不可能立刻全部完成。

## 第二组：计算实践

**4. 手算 + 代码验证。** 你观察一个新上线的功能，100 个用户里 70 个点击。用 $\text{Beta}(71, 31)$ 作为点击率的信念分布。（a）均值是多少？（b）用代码画出 $x=0.7$ 附近的密度，与 $x=0.3$ 处比较。（c）$\text{Beta}(71,31)$ 和 $\text{Beta}(7,3)$（只看 10 个用户、7 个点击）谁更"尖"？为什么？

**解答**：
（a）$\mathbb{E}[X]=\frac{\alpha}{\alpha+\beta}=\frac{71}{102}\approx0.696$。
（b）$\frac{f(0.7)}{f(0.3)}=\frac{0.7^{70}\cdot0.3^{30}}{0.3^{70}\cdot0.7^{30}}=(\frac{0.7}{0.3})^{40}\approx7.5\times10^6$——$0.7$ 处的密度比 $0.3$ 处高约 **750 万倍**。100 个样本已经让曲线在 0.70 附近高高隆起、远端几乎为零。
（c）$\text{Beta}(71,31)$ 更尖。$\alpha+\beta=102$ 远大于 $7+3=10$，均值相同（都约 0.7），但 $\mathrm{Var}=\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ 与 $(\alpha+\beta)$ 成反比——样本越多，方差越小，曲线越集中。直觉：70/100 比 7/10 的"把握"大得多。

代码验证（用主线脚本的 `beta_pdf`）：

```python
import numpy as np
def beta_norm(alpha, beta):
    t = np.linspace(1e-6, 1-1e-6, 200000)
    return np.trapz(t**(alpha-1)*(1-t)**(beta-1), t)
def beta_pdf(x, alpha, beta):
    return x**(alpha-1)*(1-x)**(beta-1)/beta_norm(alpha, beta)
print("Beta(71,31) 在 0.7 处密度 =", round(beta_pdf(0.7, 71, 31), 3))
print("Beta(71,31) 在 0.3 处密度 =", format(beta_pdf(0.3, 71, 31), '.3e'))
print("Beta(71,31) 方差 =", round(71*31/(102**2*103), 5))
print("Beta(7,3)   方差 =", round(7*3/(10**2*11), 5))
```

输出（大致）：

```text
Beta(71,31) 在 0.7 处密度 = 6.423
Beta(71,31) 在 0.3 处密度 = 8.5e-07
Beta(71,31) 方差 = 0.00206
Beta(7,3)   方差 = 0.01909
```

**思路点拨**：方差约缩小 9 倍，因为分母里 $(\alpha+\beta)^2$ 把样本量的平方引了进来——**样本多 10 倍，不确定性的数量级要小两个量级**。这是 Beta 分布替"数据越多越有把握"提供的精确账本。

**5. 用代码验证特例。** 证明 $\text{Gamma}(1,\lambda)$ 的密度与 $\lambda e^{-\lambda x}$ 重合；证明 $\text{Beta}(1,1)$ 的密度恒等于 1。

**解答**：

```python
import numpy as np
# 用上一题的 gamma_norm 与 gamma_pdf（略写），直接对点验证
def gamma_pdf(x, alpha, lam):
    t = np.linspace(1e-6, 30.0, 200000)
    g = np.trapz(t**(alpha-1)*np.exp(-t), t)
    return lam**alpha*x**(alpha-1)*np.exp(-lam*x)/g
x = np.linspace(0.1, 10.0, 5)
manual = np.array([0.5*np.exp(-0.5*v) for v in x])          # λe^{-λx}, λ=0.5
from_gamma = gamma_pdf(x, 1.0, 0.5)
print("最大偏差 =", np.max(np.abs(manual - from_gamma)))
```

输出：

```text
最大偏差 = 6.9e-13
```

两个版本逐点重合（误差在浮点精度内）。$\alpha=1$ 时 $\Gamma(1)=1$、$x^0=1$，Gamma 公式退化成指数公式——不是近似，是**恒等**。**思路点拨**：若有人问"为什么 Gamma 的 $\alpha$ 一定要是整数才叫等几个事件"，此处可以答：$\alpha=1$ 已经说明问题——退化成指数，就是"等 1 个事件"。

## 第三组：DL 延伸

**6. Bandit / Thompson 采样场景。** 你做 A/B 测试推荐两个广告（两个"臂"）。臂 A 显示 50 次、被点 30 次；臂 B 显示 30 次、被点 10 次。Thompson 采样每次从 $\text{Beta}(1+\text{点}, 1+\text{未点})$ 里抽一个"真实点击率"$p$，取 $p$ 大的臂展示。请给出两臂的后验分布，并解释为什么"只看点率 0.6 vs 0.33"还不够，还要看分布的形状。

**解答**：臂 A：$\text{Beta}(31, 21)$，均值 $\frac{31}{52}\approx0.596$；臂 B：$\text{Beta}(11, 21)$，均值 $\frac{11}{32}\approx0.344$。只看点率，A 显然更好——但 Thompson 采样不直接取均值，而是**从后验里抽样**。臂 A 的样本量多（50），后验尖；臂 B 样本量少（30），后验宽。偶尔 B 会抽出一个比 A 更高的 $p$ 而获得展示机会——**这正是探索 (exploration)**：样本少、不确定的臂，靠"宽尾巴"偶尔被选中，从而有机会积累更多数据。若只看点率直接选 A，B 永远没机会被完善评估，这就是"探索 vs 利用"的困境。$\alpha,\beta$ 正是把"多少证据"编码进决策的工具：不是"A 点率更高"，而是"A 的后验又高又尖，B 的后验虽矮但还宽着"。
**思路点拨**：若有人只答"A 好，选 A"，那是掉进了"只看点估计、不看分布宽度"的陷阱。Thompson 采样的灵魂是"不确定的臂保留机会"——Beta 分布的方差公式 $\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ 精确地告诉你，样本少的一方有多"宽"。
