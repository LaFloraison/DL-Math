## 解答与思路点拨

### 第一组

**1.1 答案：C（SVD）。**
- **思路**：教材原文点名 SVD "是 PCA、数据压缩、信号处理等应用的基础"。LU 管解方程组与求逆，QR 管数值稳定的最小二乘与特征值算法；特征分解只认方阵。
- **点拨**：选 D（特征分解）很常见——因为 PCA 也常表述为"对协方差矩阵做特征分解"。但协方差矩阵恰好是方阵，对它做特征分解等价于对数据矩阵做 SVD；而 SVD 对**任何形状**的矩阵都成立，是特征分解的"万能推广"，所以教材把 PCA 归给 SVD。

**1.2 答案：$1.5 = 6/4$，它是消元倍数。**
- **思路**：要消掉 $(2,1)$ 位置的元素 $6$，做法是"第二行减去 $1.5$ 倍第一行"：$6 - 1.5 \times 4 = 0$。这个倍数正是 $6$ 除以主元 $4$。所有消元倍数收集起来，就拼成了下三角矩阵 $L$。
- **点拨**：有人会把 $L$ 的 $(2,1)$ 元当成"消元前的元素值（6）"或"消元后剩下的元素（0）"。都不是——它是**把 6 变成 0 所乘的那个倍数**。读 $L$ 时要想起它记录的是"高斯消元的每一步做了什么"。

**1.3 这句话错。**
- **思路**：两条理由：(1) 只有**方阵**才有特征值，矩形矩阵没有特征分解；(2) 即使方阵，也可能没有 $n$ 个线性无关的特征向量（如剪切矩阵 $\begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}$ 只有一个独立特征向量），此时**不能对角化**。另外实矩阵的特征值还可能不是实数。
- **点拨**：对比 SVD——SVD 对任何矩阵都存在、奇异值恒为实数非负。把"特征分解只适用于可对角化方阵"和"SVD 适用于一切矩阵"这两个边界混为一谈，是本节最典型的错误。

### 第二组

**2.1**
特征多项式：$\det(A - \lambda I) = (4-\lambda)(3-\lambda) - 2 = \lambda^2 - 7\lambda + 10 = (\lambda-5)(\lambda-2)$，故 $\lambda_1 = 5$、$\lambda_2 = 2$。
- $\lambda = 5$：解 $(A - 5I)\mathbf{v} = 0$，即 $\begin{bmatrix} -1 & 2 \\ 1 & -2 \end{bmatrix}\mathbf{v} = 0$，得 $-x + 2y = 0$，取 $\mathbf{v}_1 = [2, 1]^T$。验证：$A[2,1]^T = [10, 5]^T = 5[2,1]^T$。
- $\lambda = 2$：解 $(A - 2I)\mathbf{v} = 0$，即 $\begin{bmatrix} 2 & 2 \\ 1 & 1 \end{bmatrix}\mathbf{v} = 0$，得 $x + y = 0$，取 $\mathbf{v}_2 = [1, -1]^T$。验证：$A[1,-1]^T = [2,-2]^T = 2[1,-1]^T$。

```python
import numpy as np
A = np.array([[4.0, 2.0],
              [1.0, 3.0]])
w, v = np.linalg.eig(A)
print(w)               # [5. 2.]
print(v)               # 每列一个特征向量
print(v[:, 0] / v[1, 0])   # [2. 1.] → 与手算 [2,1] 同方向（归一化了）
print(np.allclose(A @ v[:, 0], w[0] * v[:, 0]))   # True
```
```text
[5. 2.]
[[ 0.8944 -0.7071]
 [ 0.4472  0.7071]]
[2. 1.]
True
```
- **思路**：numpy 返回的是**归一化**的特征向量（单位长度），所以 `v[:, 0] = [0.8944, 0.4472]` 是 $[2,1]$ 除以自身长度 $\sqrt{5}$ 的结果，两者**同方向**。验证用 `A @ v[:, i] == w[i] * v[:, i]` 最直接。
- **点拨**：特征向量乘以任意非零常数仍是特征向量——所以手算答案与 numpy 答案"长得不一样"**不代表算错**。有人看到 `[0.8944, 0.4472]` 就以为自己错了，其实只是归一化约定不同。

**2.2**
```python
import numpy as np
A = np.array([[1.0, 0.0],
              [0.0, 4.0]])
U, S, Vt = np.linalg.svd(A)
print("U =\n", U, "\nS =", S, "\nVt =\n", Vt)
print("U^T U == I ?", np.allclose(U.T @ U, np.eye(2)))
print("非负且降序 ?", np.all(S >= 0) and np.all(np.diff(S) <= 0))
print("U diag(S) Vt == A ?", np.allclose(U @ np.diag(S) @ Vt, A))
```
```text
U =
 [[0. 1.]
 [1. 0.]]
S = [4. 1.]
Vt =
 [[0. 1.]
 [1. 0.]]
U^T U == I ? True
非负且降序 ? True
U diag(S) Vt == A ? True
```
- **思路**：奇异值 $[4, 1]$ 恰好是 $A$ 对角元的绝对值——因为对角矩阵的奇异值就是对角元的绝对值。性质 (b) 用 `S >= 0`（非负）和 `np.diff(S) <= 0`（相邻差非正 = 降序）两条并起来检验。
- **点拨**：有人会误以为"奇异值 = 特征值"。对一般矩阵并不成立（特征值可能复数或负）；但对**对称矩阵**，特征值确实是奇异值的带符号版本。可以顺手验证：换一个非对称矩阵，比较 `np.linalg.svd(A)[1]` 与 `np.abs(np.linalg.eig(A)[0])`。

**2.3**
```python
import numpy as np
rng = np.random.default_rng(7)
M = rng.normal(size=(40, 3)) @ rng.normal(size=(3, 25))   # 真实秩 = 3
M = M + 0.05 * rng.normal(size=(40, 25))                  # 加 5% 噪声
U, S, Vt = np.linalg.svd(M)
print("奇异值:", np.round(S, 2))
for k in (1, 2, 3, 5, 10):
    Mk = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
    print(f"k={k}: 相对误差 = {np.linalg.norm(M - Mk) / np.linalg.norm(M):.4f}")

N = rng.normal(size=(40, 25))                              # 纯随机
Un, Sn, Vtn = np.linalg.svd(N)
print("随机矩阵前5奇异值:", np.round(Sn[:5], 2))
N3 = Un[:, :3] @ np.diag(Sn[:3]) @ Vtn[:3, :]
print("随机矩阵秩-3相对误差 =",
      f"{np.linalg.norm(N - N3) / np.linalg.norm(N):.4f}")
```
```text
奇异值: [31.11 20.33 19.24  0.48  0.46  0.42 ...]
k=1: 相对误差 = 0.6694
k=2: 相对误差 = 0.4607
k=3: 相对误差 = 0.0329
k=5: 相对误差 = 0.0288
k=10: 相对误差 = 0.0201
随机矩阵前5奇异值: [11.29 10.53  9.86  9.07  8.42]
随机矩阵秩-3相对误差 = 0.8244
```
- **思路**：结构化矩阵的奇异值前 3 个（31、20、19）远大于后面的（0.5 以下）——出现"断崖"。因此 $k=3$ 时相对误差骤降到 3.3%，再往上几乎不再下降。纯随机矩阵的奇异值从 11.3 到 8.4 **缓慢衰减、没有断崖**，秩-3 近似误差高达 0.82。
- **点拨**：低秩近似是否有效，看的是**奇异值衰减的陡峭程度**。有人只看"误差在下降"就以为 SVD 压缩永远有效——真正的教训是"断崖决定压缩上限"。深度学习的权重矩阵奇异值通常近似指数衰减（近似低秩），这正是低秩压缩和低秩参数化的依据。

### 第三组

**3.1**
(a) **右奇异向量 $V$ 的列**是主成分方向。因为 $X^T X = V \Sigma^T \Sigma V^T$（$U$ 正交消掉），$V$ 的列正是协方差矩阵（正比于 $X^T X$）的特征向量。
(b) 降维坐标 $Z = X V_{[:, :100]}$（$X$ 在 $V$ 前 100 列上的投影；等价地取 $U\Sigma$ 的前 100 列）。
(c) 数据在第 $i$ 个方向上的方差正比于 $\sigma_i^2$（因为 $\|X \mathbf{v}_i\|^2 = \sigma_i^2$，$\mathbf{v}_i$ 是 $V$ 的第 $i$ 列）。奇异值降序 ⟹ 方差降序 ⟹ 保留前 100 个奇异值对应的方向，就是保留方差最大的 100 个方向。**"特征脸"（eigenfaces）就是这些方向的列，可视化出来是一张张脸的变体。**
- **点拨**：有人会选 $U$ 当主成分方向——错。$U$ 是**样本方向**（左奇异向量对应行/样本空间），$V$ 才是**特征方向**（右奇异向量对应列/特征空间）。投影作用发生在 $V$ 一侧：$X V$ 才是"把样本投到主成分轴上"。

**3.2**
(a) $W \approx W_k = U_k \Sigma_k V_k^T$，其中 $U_k$ 是 $U$ 的前 100 列（$1024 \times 100$），$\Sigma_k$ 是奇异值矩阵的前 $100 \times 100$ 对角块，$V_k^T$ 是 $V^T$ 的前 100 行（$100 \times 1024$）。
(b) 替换前存储 $1024^2 = 1{,}048{,}576$ 个数；替换后 $1024 \times 100 + 100 + 100 \times 1024 = 204{,}900$ 个数——压缩约 **5 倍**。
(c) 当 $W$ 的奇异值**衰减缓慢**（稳定秩高、近似满秩）时，丢掉 100 个方向会丢掉大量能量，重建误差大；若前 100 个奇异值已占绝大部分能量则几乎无损。快速判据：看比值 $\sigma_{101} / \sigma_1$ 是否足够小（比如 $< 0.05$）。
- **点拨**：这是"先训练后压缩"经常失真的原因——训练得到的权重未必低秩。反过来，**在训练时就把权重参数化成低秩分解**，约束权重本身低秩，压缩就水到渠成。注意有人会以为"保留 100/1024 ≈ 10% 的方向就是保留 10% 信息"——**信息量按 $\sigma_i^2$（能量）算，不按方向个数算**。若 $\sum_{i=1}^{100}\sigma_i^2 / \sum_{i=1}^{1024}\sigma_i^2$ 只有 60%，那就真的丢了 40% 的信息。

## 一个"为什么有人会答错"的提醒

1.1 的 D 很常见——PCA 与特征分解的关联让人误以为教材把 PCA 归给特征分解；记住判据 **SVD 对任何形状成立，是特征分解的万能推广**。1.2 考的是"$L$ 记的是倍数，不是元素值"——读 $L$ 时把它读成"消元档案"。2.1 考的是**特征向量的归一化自由**：方向一致就是正确答案，数值不同不代表错。2.3 与 3.2 是同一条神经：**压缩有效与否，取决于奇异值的"断崖"与能量占比，而不是方向个数**。这是本节最值得带走的直觉。
