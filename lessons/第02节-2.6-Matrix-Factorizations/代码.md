# 代码：用 NumPy 亲手拆开一台矩阵机器

主线里我们把矩阵分解讲成"把复杂机器拆成简单零件"。这一节把它变成代码：手写 LU（其实就是高斯消元），再用 `np.linalg.qr` / `np.linalg.svd` / `np.linalg.eig` 拆出 QR、SVD、特征分解，最后用 SVD 做一次低秩压缩，看"扔掉小奇异值"到底损失多少。

脚本只依赖 NumPy，约 40 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                                # NumPy：分解的机器都住在 np.linalg 里
np.set_printoptions(precision=4, suppress=True)   # 打印保留 4 位小数、去掉科学计数法

# ---- ① 造一台"机器"：教材 LU 例子的矩阵 A ----
A = np.array([[4.0, 3.0],                         # 2×2 方阵
              [6.0, 3.0]])
print("A.shape  =", A.shape)                      # (2, 2)

# ---- ② LU：手写高斯消元，这就是 LU 的全部秘密 ----
U = A.copy()                                      # 拷贝一份，因为消元会改写它
L = np.eye(2)                                     # L 起手是单位阵（对角全 1）
l21 = U[1, 0] / U[0, 0]                           # 消元倍数 = 6/4 = 1.5
L[1, 0] = l21                                     # 把倍数记进 L 的下三角
U[1, :] = U[1, :] - l21 * U[0, :]                 # 第2行减 1.5×第1行 → (2,1) 清零
print("L =\n", L)
print("U =\n", U)
print("L@U 还原 A ? ", np.allclose(L @ U, A))     # 应该输出 True

# ---- ③ QR：正交因子 Q × 上三角 R ----
Q, R = np.linalg.qr(A)
print("\nQ =\n", Q)
print("R =\n", R)
print("Q^T Q == I ? ", np.allclose(Q.T @ Q, np.eye(2)))
print("Q@R 还原 A ? ", np.allclose(Q @ R, A))

# ---- ④ SVD：任何矩阵都能拆成 U Σ V^T ----
U, S, Vt = np.linalg.svd(A)
print("\nU  =\n", U, "  形状", U.shape)
print("奇异值 S =", S)
print("Vt =\n", Vt, "  形状", Vt.shape)
print("U@diag(S)@Vt 还原 A ? ", np.allclose(U @ np.diag(S) @ Vt, A))

# ---- ⑤ 特征分解：找"方向不变、只被拉伸"的轴 ----
w, v = np.linalg.eig(A)
print("\n特征值 w =", w)
print("特征向量 v（每列一个） =\n", v)
for i in range(2):
    print(f"A@v[:,{i}] == w[{i}]·v[:,{i}] ? ",
          np.allclose(A @ v[:, i], w[i] * v[:, i]))

# ---- ⑥ SVD 压缩：奇异值按大小排列，小尾巴可以扔掉 ----
X = np.random.default_rng(0).normal(size=(20, 8))
Ux, Sx, Vtx = np.linalg.svd(X, full_matrices=False)
energy = Sx**2 / (Sx**2).sum()                    # 每个奇异值的"能量占比"
print("\n奇异值        =", np.round(Sx, 3))
print("能量占比累计  =", np.round(np.cumsum(energy), 3))
X2 = Ux[:, :2] @ np.diag(Sx[:2]) @ Vtx[:2, :]     # 只留前 2 个奇异值
err = np.linalg.norm(X - X2) / np.linalg.norm(X)
print("秩-2 近似相对误差 =", round(err, 4))
```

## 层二：分步逐函数拆解

### 步骤 1：造矩阵，并设置打印格式

```python
A = np.array([[4.0, 3.0],
              [6.0, 3.0]])
print("A.shape  =", A.shape)
```

#### `np.array(嵌套列表)` —— 把列表变成二维数组

**做什么**：把两层列表 `[[4.0, 3.0], [6.0, 3.0]]` 转成形状 `(2, 2)` 的 `ndarray`。
**操作**：NumPy 按"列表的嵌套层数"推断维数——两层列表 → 二维矩阵。`A[i, j]` 是第 $i$ 行第 $j$ 列元素。
**输入**：嵌套 Python 列表；内层每一项长度必须一致，否则报 `ValueError`。
**输出**：形状 `(2, 2)` 的浮点矩阵。`(2, 2)` 的含义：第 0 维是行数 2，第 1 维是列数 2。
**可调参数**：
- 换成 `[[4.0, 3.0, 6.0, 3.0]]` 得到形状 `(1, 4)`（一行四列）；`[4.0, 3.0]` 是形状 `(2,)` 的一维数组（不是矩阵！）。
- 传 `dtype=np.float32` 强制单精度，省内存；深度学习里权重常用 `float32`。
- 更大：`np.zeros((n, n))`、`np.random.randn(n, n)` 也能造矩阵。
**对应数学**：主线里 $A = \begin{bmatrix} 4 & 3 \\ 6 & 3 \end{bmatrix}$ 这台"机器"。

#### `np.set_printoptions(precision=4, suppress=True)` —— 控制打印

**操作**：设置全局打印规则：浮点保留 4 位小数（`precision`），并在数值小时关闭科学计数法（`suppress=True`）。只影响打印，不影响计算。
**可调参数**：`threshold` 控制数组太长时是否折叠；`linewidth` 控制每行宽度。不改也行，纯为输出可读。

### 步骤 2：手写 LU —— 高斯消元就是 LU

```python
U = A.copy()                                      # 拷贝一份，因为消元会改写它
L = np.eye(2)                                     # L 起手是单位阵
l21 = U[1, 0] / U[0, 0]                           # 消元倍数 = 6/4 = 1.5
L[1, 0] = l21                                     # 记进 L 的下三角
U[1, :] = U[1, :] - l21 * U[0, :]                 # 第2行减 1.5×第1行
print("L@U 还原 A ? ", np.allclose(L @ U, A))
```

#### `A.copy()` —— 深拷贝，避免改写原矩阵

**操作**：在内存里复制一份 $A$ 给 `U`。如果不拷贝直接 `U = A`，后面的 `U[1, :] = ...` 会**同时**改写 `A`——因为它们指向同一块内存。
**输入**：任意数组。**输出**：数值相同、内存独立的数组。
**对应数学**：消元必须"原地磨掉原矩阵"，但我们还想保留原始 $A$ 做验证，所以先拷贝。

#### `np.eye(2)` —— 单位矩阵

**操作**：生成 $2 \times 2$ 单位阵 $I = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$——对角线全 1、其余全 0。它是 $L$ 的"胚子"：下三角 $L$ 的对角元本来就必须是 1。
**可调参数**：`np.eye(n)` 的 `n` 是阶数；`np.eye(2, 3)` 可生成非方单位阵。

#### `U[1, 0] / U[0, 0]` —— 消元倍数

**操作**：取 `U` 第 1 行第 0 列元素 $6$ 除以第 0 行第 0 列元素 $4$，得 $1.5$。这就是"第二行要减掉第一行的几倍才能把 (1,0) 清零"——$6 - 1.5 \times 4 = 0$。
**输入**：两个标量元素。**输出**：标量 `1.5`。
**对应数学**：主线里 $L$ 的 $(2,1)$ 元 $1.5 = 6/4$，消元倍数。

#### `U[1, :] = U[1, :] - l21 * U[0, :]` —— 一次行变换

**操作**：`U[1, :]` 是第 2 行（形状 `(2,)`），`l21 * U[0, :]` 是"第 1 行乘 1.5"（广播 (broadcasting)：标量乘数组，逐元素），两者相减得第 2 行的新值 `[6-6, 3-4.5] = [0, -1.5]`，写回 `U` 的第 2 行。
**输入**：`U`（(2,2)）、标量 `1.5`。**输出**：改写后的 `U`，`(2,1)` 位置变成 0。
**可调参数**：这是"行操作"，还可以有列操作 `U[:, 1]`；倍数 `l21` 一旦等于某值就固定——**这就是 LU 唯一要做的事**。
**对应数学**：主线里"第二行减去 1.5 倍第一行"的消元；消元完成后 $U$ 是上三角，倍数们组成的 $L$ 是下三角，$L \cdot U = A$。

#### `np.allclose(x, y)` —— 近似相等验证

**操作**：逐元素比较 $L@U$ 与 $A$，允许微小浮点误差（默认相对容差 1e-5），全部在容差内才返回 `True`。**绝不**用 `==` 比较浮点。
**对应数学**：验证分解的正确性——"乘回去等于原矩阵"就是主线里每种分解的验收标准。

### 步骤 3：QR 分解 `np.linalg.qr`

```python
Q, R = np.linalg.qr(A)
print("Q^T Q == I ? ", np.allclose(Q.T @ Q, np.eye(2)))
print("Q@R 还原 A ? ", np.allclose(Q @ R, A))
```

#### `np.linalg.qr(A)` —— 正交-上三角分解

**做什么**：把 $A$ 分解成 $A = QR$。
**操作**：默认用 Householder 反射，把 $A$ 一列一列地"反射"成上三角，反射矩阵的乘积就是 $Q$。
**输入**：`A`，形状 `(m, n)`（任意矩形都行）。
**输出**：两个数组。
- `Q`：形状 `(m, k)`，其中 `k = min(m, n)`。它的每一列是一个**单位长度**向量，且任意两列**内积为 0**——标准正交列。验证 `Q.T @ Q` 得 `(k,k)` 单位阵（我们的 `A` 是方阵，所以得 `(2,2)` 单位阵，输出 `True`）。
- `R`：形状 `(k, n)`，上三角矩阵（`(2,1)` 位置是 0）。
**可调参数**：
- `mode='complete'`：让 `Q` 变完整方阵——`Q` 形状 `(m, m)`，`R` 形状 `(m, n)`（多出的列补成正交基）。矩形矩阵 `(5,3)` 时，默认 `Q` 是 `(5,3)`、`complete` 是 `(5,5)`。
- `mode='r'`：只返回 `R`；`mode='raw'`：返回 Householder 反射器 `h` 与系数 `tau`（给需要手搓特征值算法的人）。
- 还能传第三个参数？`np.linalg.qr` 只接受 `a` 和 `mode` 两个参数。
**对应数学**：主线 QR 分解定义块——$Q$ 正交、$R$ 上三角、$QR=A$。教材 3×3 例子里的 $Q$ 就是这种"只旋转不拉伸"的矩阵。

### 步骤 4：SVD 分解 `np.linalg.svd`

```python
U, S, Vt = np.linalg.svd(A)
print("U@diag(S)@Vt 还原 A ? ", np.allclose(U @ np.diag(S) @ Vt, A))
```

#### `np.linalg.svd(A)` —— 奇异值分解

**做什么**：把 $A$ 分解成 $A = U \Sigma V^T$。
**操作**：先算 $A^T A$ 的特征分解得到 $V$ 与奇异值，再由 $U = A V \Sigma^{-1}$ 求出左奇异向量（实际实现用更稳定的双对角化算法）。
**输入**：`A`，形状 `(m, n)`（**任何形状**都行，矩形更是家常便饭）。
**输出**：三个数组。
- `U`：形状 `(m, m)`（默认）或 `(m, k)`——**左奇异向量**，列正交归一。在输出里 `U = [[-0.5958, -0.8031], [-0.8031, 0.5958]]`。
- `S`：形状 `(k,)` 的**一维数组**，`k = min(m, n)`——**奇异值**，保证非负且**从大到小排列**：`[8.3356, 0.7198]`。它不是一个矩阵，只是对角线上的那串数。
- `Vt`：形状 `(n, n)`（默认）或 `(k, n)`——**右奇异向量 $V$ 的转置**，行正交归一。
**重建**：`U @ np.diag(S) @ Vt` 把 $S$ 从一维数组"摊回"对角矩阵 $\Sigma$，再乘起来，恰好还原 $A$（输出 `True`）。
**可调参数**：
- `full_matrices`：默认 `True`，`U` 取 `(m,m)` 大方阵、`Vt` 取 `(n,n)`；改 `False` 得到精简版 `U (m,k)`、`Vt (k,n)`，省内存。矩形矩阵（如 `(6,4)`）用默认模式时 `U` 是 `(6,6)`、`S` 只有 4 个奇异值，重建必须写 `U[:, :4] @ diag(S) @ Vt`——这是最常见的形状陷阱。
- `compute_uv=False`：只返回奇异值 `S`，不计算 `U`、`Vt`，更快（求"这个矩阵多大"时用）。NumPy 2.0 还有专门的 `np.linalg.svdvals`。
**对应数学**：主线 SVD 定义块——$U$ 旋转、$\Sigma$ 拉伸、$V^T$ 旋转。教材例子里奇异值 `4` 和 `1` 正对应 $\Sigma$ 的对角。

### 步骤 5：特征分解 `np.linalg.eig`

```python
w, v = np.linalg.eig(A)
for i in range(2):
    print(f"A@v[:,{i}] == w[{i}]·v[:,{i}] ? ",
          np.allclose(A @ v[:, i], w[i] * v[:, i]))
```

#### `np.linalg.eig(A)` —— 特征值与特征向量

**做什么**：对方阵 $A$，解 $A\mathbf{v} = \lambda \mathbf{v}$。
**操作**：数值上先做 Hessenberg 化再用 QR 迭代，逼近所有特征值，再回代求特征向量。
**输入**：`A`，**必须方阵**形状 `(n, n)`；传矩形会直接报 `LinAlgError`。
**输出**：两个数组。
- `w`：形状 `(n,)` 的**一维数组**——特征值。输出 `[7.772, -0.772]`（注意第二个是负的——这台机器沿某个方向是**压缩**而不是拉伸）。
- `v`：形状 `(n, n)`，**每一列**是一个特征向量，`v[:, i]` 对应特征值 `w[i]`。输出里 `v[:, 0] = [0.6225, 0.7826]`、`v[:, 1] = [-0.5322, 0.8466]`。
**验证**：`A @ v[:, i]` 应等于 `w[i] * v[:, i]`——两行全部输出 `True`，正是定义 $A\mathbf{v} = \lambda\mathbf{v}$ 的直接检验。
**可调参数**：`np.linalg.eig` 只有 `a` 一个参数。**对称矩阵请用 `np.linalg.eigh(a)`**——它利用对称性跑更快、数值更稳，且保证返回实数特征值。
**对应数学**：主线特征值定义块与教材例子 $A = \begin{bmatrix} 4 & 2 \\ 1 & 3 \end{bmatrix}$（特征值 $5$ 和 $2$）。本脚本的 $A$ 特征值 $7.772$ 与 $-0.772$，几何上是一台"沿某轴拉长 7.77 倍、沿另一轴压缩 0.77 倍（反向）"的机器。

### 步骤 6：SVD 压缩 —— 扔掉小奇异值

```python
Ux, Sx, Vtx = np.linalg.svd(X, full_matrices=False)
energy = Sx**2 / (Sx**2).sum()
X2 = Ux[:, :2] @ np.diag(Sx[:2]) @ Vtx[:2, :]
err = np.linalg.norm(X - X2) / np.linalg.norm(X)
```

#### `np.random.default_rng(0).normal(size=(20, 8))` —— 可复现的随机矩阵

**操作**：用种子 `0` 的随机数生成器造一个 `(20, 8)` 的矩阵，每个元素独立同分布、服从标准正态 $N(0,1)$——模拟"一批 20 个样本、8 个特征"的数据矩阵。给固定种子，运行结果可复现。
**可调参数**：把 `0` 换成别的整数得到不同数据；`normal` 换成 `uniform` 得到均匀分布；`size=(20, 8)` 决定形状。

#### `Sx**2 / (Sx**2).sum()` —— 能量占比

**操作**：奇异值平方称为该方向的"能量"。把每个奇异值平方除以总和，得到"第 $i$ 个方向占总能量的比例"。Frobenius 范数满足 $\|X\|_F^2 = \sigma_1^2 + \cdots + \sigma_r^2$，所以奇异值平方之和就是矩阵的"总能量"。
**输出**：`cumsum` 累计到 1 时的占比数组。本脚本里前 2 个奇异值占约 46.8%，前 5 个占 86.6%。

#### 低秩近似 `Ux[:, :2] @ np.diag(Sx[:2]) @ Vtx[:2, :]`

**操作**：只保留前 2 个奇异值及其对应的 $U$、$V^T$ 列/行——`Ux[:, :2]` 是 $U$ 的前 2 列 `(20,2)`，`np.diag(Sx[:2])` 是 $2 \times 2$ 对角阵，`Vtx[:2, :]` 是 $V^T$ 的前 2 行 `(2,8)`。三者相乘得 $X$ 的**秩-2 近似** $X_2$，形状仍是 `(20, 8)`。
**相对误差**：`np.linalg.norm(X - X2) / np.linalg.norm(X)` 是相对误差，输出 `0.7291`——意味着"随机矩阵用 2 个方向只能保住约 27% 的信息"。

#### `np.linalg.norm(M)` —— 矩阵的 Frobenius 范数

**操作**：默认对矩阵求 Frobenius 范数 $\sqrt{\sum_{ij} M_{ij}^2}$——所有元素的平方和开方，衡量"这个矩阵多大"。
**可调参数**：`ord='nuc'` 是核范数（奇异值之和），`ord=2` 是谱范数（最大奇异值）；`axis` 可沿某轴批量求。

**对应数学**：主线第四部分——SVD 压缩与低秩近似。**这个实验的关键读法**：奇异值衰减得**慢**（`[6.65, 5.06, 4.89, ...]`），能量累计到第 5 个才到 86.6%——因为 $X$ 是**纯随机**的，随机矩阵的奇异值天生缓慢衰减，低秩压缩对它几乎无效（误差 0.73）。这正是要对比的对照组：**SVD 只"压缩"本来就近似低秩的结构**。真实的深度学习权重矩阵近似低秩，所以低秩近似能奏效；而纯噪声不可压缩。详见下方边界声明。

## 边界声明：这套代码能做什么，不能做什么

1. **手写的 LU 没有行置换。** 若 $A$ 的左上角是 0（比如 `[[0,1],[1,1]]`），`U[1,0]/U[0,0]` 会**除零**。真实生产用 `scipy.linalg.lu`，它返回三件套 `(P, L, U)` 满足 $PA = LU$，自动处理主元问题。教材只给无置换情形，但要知道完整版本的存在。
2. **`np.linalg.eig` 会返回复数。** 非对称实矩阵的特征值不一定是实数；`w` 里可能出现 `1+2j`。若特征值必须是实数且 $A$ 对称，请用 `np.linalg.eigh`。而奇异值**永远是实数且非负**——这是 SVD 相对特征分解的稳定性优势。
3. **`full_matrices` 的形状陷阱。** 对矩形矩阵，`np.linalg.svd` 默认给 `(m,m)` 的 `U`，重建时**必须**切片 `U[:, :k]`（`k = min(m,n)`），否则矩阵乘法直接维度不匹配。数据大时设 `full_matrices=False` 更省内存、也更贴近"只保留有用的列"。
4. **SVD 不能压缩噪声。** 纯随机矩阵奇异值衰减缓慢、稳定秩高，低秩近似的误差几乎不下降（本脚本误差 0.73）。SVD 压的是"本来就有结构"的矩阵——这也解释了为什么模型压缩里的低秩近似要配合训练（约束权重本身低秩），而不是事后对任意权重硬拆。
5. **分解不便宜。** LU/QR/SVD 对 $n \times n$ 矩阵都是 $O(n^3)$。对超大权重矩阵用完整 SVD 不现实，工业上会用随机化 SVD (randomized SVD) 或只算前 $k$ 个奇异值的截断版本。
