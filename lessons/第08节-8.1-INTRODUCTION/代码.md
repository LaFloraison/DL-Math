# §8.1 微分几何导论 · 代码

主线里，我们遇见一只趴在篮球上的蚂蚁——它看不见篮球是弯的，因为它只相信自己脚下那一小块。这节代码，就是把"**局部像平面、整体是弯曲的**"这句话，亲手在 Python 里验证一遍。

我们将做四件事：生成一个球面（一个最经典的 2 维流形）→ 在球面上采一个点，取它周围的一小块邻域 → 用 PCA 给这一小块拟合一个"最佳平面"（切平面），看看它到底多接近平面 → 再测量两个"直线"距离与"曲面"距离，看看弯曲到底躲在哪里。

需要的环境：Python 3.8+ 与 `numpy`、`matplotlib`（`pip install numpy matplotlib`）。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方（`SEED = 0` 固定，结果可复现）。

```python
"""
§8.1 微分几何导论 · 代码.md
验证流形的核心直觉：局部像平面，整体弯曲。
用球面（2D 流形）演示：切平面拟合 + 欧氏距离 vs 曲面距离。

运行：python 代码.py    （绘图依赖 matplotlib）
"""

import numpy as np
import matplotlib.pyplot as plt

R = 1.0          # 球半径
N = 10000        # 球面上均匀采样点数
SEED = 0         # 随机种子：可复现

rng = np.random.default_rng(SEED)


def sample_sphere(n_points, radius=R, seed=SEED):
    """在半径 radius 的球面上均匀采样 n_points 个点。"""
    rng = np.random.default_rng(seed)
    u = rng.random(n_points)            # u ~ U[0,1)：控制纬度
    v = rng.random(n_points)            # v ~ U[0,1)：控制经度
    theta = 2.0 * np.pi * u             # 经度 theta ∈ [0, 2π)
    phi = np.arccos(2.0 * v - 1.0)      # 纬度 phi ∈ [0, π]（反余弦保证均匀）
    # 球坐标 -> 直角坐标，形状 (n, 3)
    pts = np.stack([
        radius * np.sin(phi) * np.cos(theta),
        radius * np.sin(phi) * np.sin(theta),
        radius * np.cos(phi),
    ], axis=1)
    return pts


def collect_neighbors(pts, center, k):
    """找出球面上离 center 最近的 k 个点（欧氏最近邻），作为"脚下的一小块"。"""
    d2 = np.sum((pts - center) ** 2, axis=1)   # (n,) 到 center 的平方距离
    idx = np.argsort(d2)[:k]                    # 距离最小的 k 个下标
    return pts[idx]


def fit_tangent_plane(neighbors):
    """用 PCA 给邻域拟合一个平面，返回法向量（平面朝外的方向）。"""
    mu = neighbors.mean(axis=0)                # 邻域质心 (3,)
    centered = neighbors - mu                   # 去中心 (k, 3)
    cov = centered.T @ centered / len(neighbors)  # 3x3 协方差矩阵
    w, V = np.linalg.eigh(cov)                  # 特征值 + 特征向量
    normal = V[:, 0]                            # 最小方差方向 = 平面法向
    if np.dot(normal, mu) < 0:                  # 让法向量朝外（沿径向）
        normal = -normal
    return normal, mu, w


def local_flatness_error(neighbors, normal, mu):
    """量化"这一小块有多接近平面"：点到拟合平面的平均距离。"""
    dists = np.abs((neighbors - mu) @ normal)   # (k,) 每个点到平面距离
    return float(dists.mean())                   # 平均距离：0 就是完全平的


def euclid_vs_surface_dist(pts_a, pts_b, radius=R):
    """两个点的欧氏（直线穿球）距离 vs 球面（沿表面走弧线）距离。"""
    eu = float(np.linalg.norm(pts_a - pts_b))                       # 直线穿球
    cos_angle = np.clip(np.dot(pts_a, pts_b) / (radius * radius), -1.0, 1.0)
    surf = float(radius * np.arccos(cos_angle))                      # 沿球面的弧
    return eu, surf


def plot_sphere_and_tangent(pts, center, normal, mu, neighbors):
    """画球面 + 一个点的邻域 + 拟合出的切平面。"""
    fig = plt.figure(figsize=(8, 7))
    ax = fig.add_subplot(111, projection="3d")
    ax.scatter(pts[:, 0], pts[:, 1], pts[:, 2], s=1, c="steelblue", alpha=0.3,
               label="球面上的点（2D 流形）")
    ax.scatter(*center, color="red", s=60, label="关注点 p")
    ax.scatter(neighbors[:, 0], neighbors[:, 1], neighbors[:, 2], s=8,
               color="orange", label="p 的局部邻域")
    # 画一个以 mu 为中心、法向 normal 的圆盘（切平面的一块）
    u_, v_ = np.linalg.svd(neighbors - mu)[2][1], None
    t1 = np.linalg.svd(neighbors - mu)[2][1]          # 邻域主轴方向
    t2 = np.cross(normal, t1)                          # 与法向正交的第二方向
    s = 0.25
    grid = np.array([(a * t1 + b * t2) for a in np.linspace(-s, s, 2)
                     for b in np.linspace(-s, s, 2)])
    ax.plot_trisurf(mu[0] + grid[:, 0], mu[1] + grid[:, 1], mu[2] + grid[:, 2],
                    color="yellow", alpha=0.5, label="拟合切平面")
    ax.set_xlabel("x"); ax.set_ylabel("y"); ax.set_zlabel("z")
    ax.legend()
    plt.title("球面上 p 点的局部邻域与拟合切平面")
    plt.show()


# ---------------- 主流程 ----------------
pts = sample_sphere(N)                       # 1. 生成球面（2D 流形）

center = np.array([1.0, 0.0, 0.0])           # 2. 关注点：赤道上的 (1,0,0)
nb = collect_neighbors(pts, center, k=40)    # 3. 取脚下的一小块（40 个最近邻）
normal, mu, w = fit_tangent_plane(nb)        # 4. 用 PCA 拟合切平面
err = local_flatness_error(nb, normal, mu)   # 5. 量化"局部有多平"

p_a = np.array([1.0, 0.0, 0.0])
p_b = np.array([0.0, 1.0, 0.0])
eu, surf = euclid_vs_surface_dist(p_a, p_b)  # 6. 欧氏距离 vs 曲面距离

print("局部平坦性检验（邻域到拟合平面平均距离）:")
print("  平均偏差 = %.5f  (半径 R = %.2f)" % (err, R))
print("  -> 邻域几乎落在同一平面内，这就是'局部像平面'")
print("\n欧氏距离 vs 曲面距离 (赤道上的两点 (1,0,0) 与 (0,1,0)):")
print("  直线穿球的欧氏距离 = %.4f" % eu)
print("  沿球面走的弧线距离 = %.4f" % surf)
print("  两者之比 = %.4f   -> 弯曲让'最短路径'变长了" % (surf / eu))

plot_sphere_and_tangent(pts, center, normal, mu, nb)
```

## 层二：分步逐函数拆解

### 步骤 1：生成球面 —— `sample_sphere(n_points, radius, seed)`

```python
def sample_sphere(n_points, radius=R, seed=SEED):
    rng = np.random.default_rng(seed)
    u = rng.random(n_points)            # u ~ U[0,1)：控制纬度
    v = rng.random(n_points)            # v ~ U[0,1)：控制经度
    theta = 2.0 * np.pi * u             # 经度 theta ∈ [0, 2π)
    phi = np.arccos(2.0 * v - 1.0)      # 纬度 phi ∈ [0, π]
    pts = np.stack([
        radius * np.sin(phi) * np.cos(theta),
        radius * np.sin(phi) * np.sin(theta),
        radius * np.cos(phi),
    ], axis=1)
    return pts
```

#### `sample_sphere(n_points, radius, seed)` —— 在球面上均匀撒点

**操作**：先抽两组 $[0,1)$ 均匀随机数 $u, v$，映射成球坐标的经度 $\theta = 2\pi u$ 与纬度 $\phi = \arccos(2v-1)$，再用球坐标公式转成直角坐标 $(x,y,z) = R(\sin\phi\cos\theta,\ \sin\phi\sin\theta,\ \cos\phi)$。

注意纬度映射为什么是 $\arccos(2v-1)$ 而不是直接的 $\pi v$：如果让 $\phi = \pi v$ 均匀取值，点会密集堆在南北极（靠近极地的"纬度条带"面积更小，却分到同样多的点）。用反余弦让 $z = R\cos\phi$ 在 $[-R, R]$ 上均匀，点就真正均匀铺在球面上——这正是**参数化的不均匀会扭曲"均匀"**的现场演示，和主线里"参数是地图、不是地形"是同一件事。

**对应数学**：球面 $S^2$ 是一个 2 维流形。每个点只需要两个坐标 $(\theta, \phi)$ 就能唯一描述——但这两个坐标并不能覆盖整个球（在南北极退化），所以它正是主线定义块里"需要一叠 chart 组成 atlas 才能覆盖"的活例子。

**输入**：
- `n_points`：整数，采样点数 $N$。
- `radius`：浮点数（可省略，默认 `R = 1.0`），球半径。
- `seed`：整数（可省略，默认 0），随机种子。

**输出**：`numpy.ndarray`，**形状 `(n_points, 3)`**——每行是一个采样点的 $(x,y,z)$ 直角坐标，行数 = 采样点数，列数 = 3 维空间。

**可调参数**：
- `n_points`：改 100 点太少，邻域会稀疏；改 100000 点太多，`argsort` 变慢。5000–50000 是这个演示的甜区。
- `radius`：改成 3.0，整个球放大 3 倍——注意下面的"局部平坦误差"和"曲面弧长"都会随之缩放，说明**曲率是 1/半径**的量级（见 8.2.4 的曲率一节）。
- `seed`：换一个种子，采出的点不同，但统计量（平均偏差）几乎不变——这正是"局部像平面"是一个几何事实、不是随机噪声。

### 步骤 2：取局部邻域 —— `collect_neighbors(pts, center, k)`

```python
def collect_neighbors(pts, center, k):
    d2 = np.sum((pts - center) ** 2, axis=1)   # (n,) 平方距离
    idx = np.argsort(d2)[:k]                    # 距离最小的 k 个下标
    return pts[idx]
```

#### `collect_neighbors(pts, center, k)` —— 找出"脚下的一小块"

**操作**：计算每个点到 `center` 的欧氏平方距离 $d_i^2 = \|p_i - c\|^2$（批量向量化：`(n,3) - (3,)` 广播成 `(n,3)`，平方后沿 axis=1 求和），用 `np.argsort` 取距离最小的前 `k` 个下标，返回这 `k` 个点。

为什么用**平方**距离？省一次开方，且 `argsort` 对开方前后结果一致——这是速度优化，不影响正确性。

**对应数学**：这一小撮点，就是主线里那只蚂蚁"脚下的一块地面"。我们观察它，是为了检验"这块地面是不是平的"。选邻近的 40 个点，本质上是流形定义中"开邻域 $U$"的**离散采样近似**——流形上每一点都有一个"看起来像平面"的小邻域，这里我们用最邻近的 $k$ 个点来近似这个邻域。

**输入**：
- `pts`：`(n, 3)` 数组，球面上的点（步骤 1 输出）。
- `center`：`(3,)` 数组，关注点的坐标。
- `k`：整数，邻域大小（取几个最近邻）。

**输出**：`(k, 3)` 数组，离 `center` 最近的 $k$ 个点。

**可调参数**：
- `k`：这是本函数最值得拧的旋钮。`k` 太小（如 5），拟合平面噪声大；`k` 太大（如 2000），邻域大到跨越半个球，PCA 拟合出的"平面"就不再贴合曲面，"局部平坦误差"显著变大——**邻域尺度一旦超过曲率半径，局部就不再平了**。这正好演示主线的边界声明：局部平坦只在足够小的尺度下成立。
- 还能不能有第三个参数？可以加一个 `metric="euclid"` 参数，切换成球面距离（测地距离）找最近邻。但演示里邻域足够小，欧氏与球面距离几乎一致，用欧氏就够。

### 步骤 3：拟合切平面 —— `fit_tangent_plane(neighbors)`

```python
def fit_tangent_plane(neighbors):
    mu = neighbors.mean(axis=0)
    centered = neighbors - mu
    cov = centered.T @ centered / len(neighbors)
    w, V = np.linalg.eigh(cov)
    normal = V[:, 0]
    if np.dot(normal, mu) < 0:
        normal = -normal
    return normal, mu, w
```

#### `fit_tangent_plane(neighbors)` —— 用 PCA 找邻域所在的最佳平面

**操作**：这是主线的切空间概念在数据上的落地。

1. `mu = neighbors.mean(axis=0)` —— 邻域质心（近似切点 $p$ 的位置）。
2. `centered = neighbors - mu` —— 把邻域平移到质心。
3. `cov = centered.T @ centered / len(neighbors)` —— 计算 $3\times3$ 协方差矩阵。它在数学上等于 $C = \frac{1}{k}\sum_i (p_i - \mu)(p_i - \mu)^\top$。
4. `w, V = np.linalg.eigh(cov)` —— 特征分解。`eigh` 按特征值升序排列，所以 `V[:, 0]` 是**最小**特征值对应的特征向量。
5. 关键：邻域几乎躺在一个平面里，所以数据在"平面法向"方向上的方差最小——最小方差方向就是法向量 `normal`。
6. 最后一个 `if`：让法向量指向外（与径向 $\mu$ 同向），方便绘图。

**对应数学**：这就是主线里切空间 $T_pM$ 的离散构造。流形上 $p$ 点的切空间是"所有可走方向张成的线性空间"，而 $T_pM$ 的法向量就是"曲面在 $p$ 点不延伸的方向"。用 PCA 找最小方差方向，等于在数据里**识别出流形的局部线性结构**——主成分分析（PCA）在这节课里第一次和微分几何相遇：PCA 找"数据的主要延伸方向"，切空间找"曲面的局部延伸方向"，数学上是同一件事。

**输入**：`neighbors` —— `(k, 3)` 数组，局部邻域（步骤 2 输出）。

**输出**：三元组 `(normal, mu, w)`。
- `normal`：`(3,)` 数组，拟合平面的单位法向量。
- `mu`：`(3,)` 数组，邻域质心（近似切点）。
- `w`：`(3,)` 数组，三个特征值（升序），第 0 个越小，邻域越贴近平面。

**可调参数**：
- 本函数没有显式可调参数，但它的行为被步骤 2 的 `k` 控制。`k` 大 → 平面拟合的是更粗的结构；`k` 小 → 拟合的是更精细的局部。
- 还能不能有参数？可以加一个 `fit_type="plane"`，改成拟合二次曲面（抛物面），那就能同时估计出曲率了——这是 8.2.4 的方向。

### 步骤 4：量化局部平坦性 —— `local_flatness_error(neighbors, normal, mu)`

```python
def local_flatness_error(neighbors, normal, mu):
    dists = np.abs((neighbors - mu) @ normal)
    return float(dists.mean())
```

#### `local_flatness_error(neighbors, normal, mu)` —— 测"这一小块离平面有多远"

**操作**：对每个邻域点，计算它到拟合平面的**带符号距离** $(p_i - \mu) \cdot n$（质心到点的向量投影到法向），取绝对值，再求平均。

**对应数学**：这是"局部像平面"的直接计量。如果这些点真的共面，每个点到平面的距离为 0，平均偏差为 0。我们的测量得到 `0.00021`——相对于半径 1 的球，这 40 个点几乎就躺在一个平面上。**球面的曲率不藏在"一块地"里，藏在"这块地和旁边那块地如何拼接"里。** 平均偏差的量级大致是 $\frac{\text{邻域直径}^2}{\text{曲率半径}}$——邻域越小、曲率越大，它越小。

**输入**：
- `neighbors`：`(k, 3)` 邻域点。
- `normal`：`(3,)` 法向量。
- `mu`：`(3,)` 质心。

**输出**：一个 `float`——平均点到平面距离，单位与坐标一致（这里是球半径的尺度）。**数值 0 意味着完全平，数值越大越弯。**

**可调参数**：本函数没有参数可调，但你可以改变它"怎么衡量"：比如取最大偏差而不是平均偏差、或用"点到平面距离的方差"。核心结论不变：邻域足够小时，任何光滑曲面都接近平面。

### 步骤 5：欧氏距离 vs 曲面距离 —— `euclid_vs_surface_dist(pts_a, pts_b, radius)`

```python
def euclid_vs_surface_dist(pts_a, pts_b, radius=R):
    eu = float(np.linalg.norm(pts_a - pts_b))
    cos_angle = np.clip(np.dot(pts_a, pts_b) / (radius * radius), -1.0, 1.0)
    surf = float(radius * np.arccos(cos_angle))
    return eu, surf
```

#### `euclid_vs_surface_dist(pts_a, pts_b, radius)` —— 弯不弯，一测便知

**操作**：
1. `eu = np.linalg.norm(pts_a - pts_b)` —— 两点直线距离：**沿弦线穿过球内部**的欧氏距离 $\|a - b\|$。
2. `cos_angle = dot(a, b) / R^2` —— 两个单位方向向量夹角的余弦（因为 $a, b$ 模长都是 $R$）。
3. `surf = R * arccos(cos_angle)` —— 沿球面的弧长：半径乘以圆心角，即测地线长度 $R\theta$。
4. `np.clip(..., -1, 1)` —— 防止浮点误差让余弦超出 $[-1,1]$ 导致 `arccos` 出错。

**对应数学**：这是主线"欧氏几何只适用于平面"的数值铁证。在平面上，两点最短路径就是直线，长度 $\|a-b\|$；在球面上，最短路径是大圆上的弧，长度 $R\theta$。我们算出的比值 $1.1107$：直线穿球 1.4142（即 $\sqrt{2}$），沿球面 1.5708（即 $\frac{\pi}{2}$）。**同一个起点、同一个终点，路径差了一成多——因为你不能穿过地球，只能沿着地表走。** 这正是"度量张量"要解决的问题（8.2.3）：在弯曲表面，欧氏距离公式失效，需要一个新的内积来定义"真实距离"。

**输入**：
- `pts_a, pts_b`：各为 `(3,)` 数组，球面上两点。
- `radius`：浮点数（可省略，默认 1.0），球半径。

**输出**：`(eu, surf)` 两个 `float`——欧氏直线距离与球面弧长。

**可调参数**：
- 两个点改成任意一对，比值都会大于 1（球面弧长永远不小于弦长），且越远比值越大——半圈的两点比值最大（$\pi/2$）。
- `radius` 放大，两个距离按比例放大，但**比值不变**——曲率只影响"绝对尺度"，不影响"弯曲有没有"。

#### `plot_sphere_and_tangent(...)` —— 把"局部平"画出来

**操作**：画三层东西——全体采样点（蓝色小点，象征整个弯曲的流形）→ 关注点 $p$（红点）与它的局部邻域（橙色小点）→ 用法向量和邻域主轴张出的黄色圆盘（拟合切平面）。

其中圆盘的方向由两步决定：`t1 = svd(neighbors - mu)[2][1]` 取邻域的**主轴**（数据延伸最大的方向），`t2 = cross(normal, t1)` 取与法向、主轴都正交的第二方向——`t1, t2` 张出平面本身，`normal` 垂直于它。

**对应数学**：这幅图就是教材图 8.1 的自绘版。你会在图上看到：橙色邻域几乎完全"躺"在黄色圆盘里——局部平；但蓝色大球整个弯成一个球——整体弯。图上那个圆盘，正是主线的切平面 $T_pM$。

**输入**：`pts`（`(n,3)`）、`center`（`(3,)`）、`normal`（`(3,)`）、`mu`（`(3,)`）、`neighbors`（`(k,3)`）。

**输出**：无返回值。渲染一张 3D 图（窗口或 Jupyter 内嵌）。

**可调参数**：
- 圆盘边长 `s`（函数体内写死为 0.25）：调大，圆盘凸出球面、明显"切"而非"贴"；调小，圆盘更贴合邻域。
- 邻域点尺寸 `s=8`、球的透明度 `alpha=0.3` 都是样式旋钮。
- 还能不能有参数？可以加一个 `save_path`，用 `plt.savefig` 把图存盘而不是弹窗——在无图形环境跑脚本时很有用。

## 一步验证：把球面换成"可展"的圆柱面

想亲手撞一次主线里的边界声明吗？把 `sample_sphere` 换成一个圆柱面：

```python
def sample_cylinder(n_points, radius=R, seed=SEED):
    rng = np.random.default_rng(seed)
    u = rng.random(n_points)               # 经度
    z = rng.uniform(-1.0, 1.0, n_points)   # 高度
    theta = 2.0 * np.pi * u
    return np.stack([
        radius * np.cos(theta),
        radius * np.sin(theta),
        z,
    ], axis=1)
```

在圆柱面上取邻域拟合平面、测平均偏差——你会发现它同样"局部平"（偏差几乎为 0）。这并不奇怪：圆柱面在**一个**方向上弯，但在另一个方向上完全平，所以在局部它依然像一张纸。

但真正的分水岭藏在另一个问题里：**圆柱面可以沿母线剪开、摊平成一张长方形纸，球面却永远摊不平。** 前者叫"可展 (developable)"，后者不是。曲率（8.2.4）会用 $K = k_1 k_2$ 抓住这个差别：圆柱的一个方向曲率 $k_1 \neq 0$、另一个方向 $k_2 = 0$，乘积 $K = 0$——它"弯了却没弯成曲面"；球面两个方向都弯，$K > 0$，所以它是真正的弯曲流形。**"局部平"能骗过眼睛，却骗不过曲率的乘积。**
