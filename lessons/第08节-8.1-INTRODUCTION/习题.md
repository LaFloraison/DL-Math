# §8.1 微分几何导论 —— 习题

本章主线讲了四件事：流形（局部像平面、整体弯曲）、切空间、度量张量、曲率，以及它们在深度学习（损失景观、梯度、泛化、Fisher 信息矩阵）里的回声。下面的习题分三组：**概念检验** 验证你接住了核心定义，**计算实践** 把"局部平、整体弯"亲手算一遍（含代码验证），**DL 延伸** 把微分几何放回训练神经网络的真实场景。每题附完整解答与思路点拨。

## 一、概念检验

### 题 1（选择）：以下哪个陈述**错误**？

关于流形（manifold）的说法：

- A. 球面 $S^2$ 是一个 2 维流形，因为它的每个局部都像平面 $\mathbb{R}^2$
- B. 一张可以被弯成任意形状但不撕不拉的纸，摊平后仍是原来的平面
- C. 一个流形可以整体铺平到欧几里得空间里，且不改变任何距离
- D. 流形上的点用 $d$ 个坐标描述，$d$ 就是它的维数

**解答**：C。

C 错，因为"整体铺平且不改变距离"要求流形**可展**——一张纸、一个圆柱面可以，球面永远不行。任何把球面摊平的地图（墨卡托、等积投影……）都要么撕开陆地、要么拉伸面积。这正是主线边界声明的核心：局部像平面 ≠ 整体可以铺平。A 正确，球面每个局部同胚于 $\mathbb{R}^2$。B 正确，弯纸不改变纸上的距离，这正是高斯绝妙定理说的"内在量在只弯不撕下不变"。D 正确，维数 = 描述一点的坐标个数。

**思路点拨**：陷阱是 C 把"局部"偷换成"整体"。流形允许"每个邻域都像平面"，但**不允许**"整个流形被平面化"。选错的人通常是把流形想象成"嵌在大空间里的一个超曲面"——注意主线的定义块：流形**不要求**嵌入任何欧几里得空间。判断标准：如果能撕开/拉伸才铺得平，那它就不是"保持距离地整体铺平"。

### 题 2（判断 + 简答）：蚂蚁能不能测出球是弯的？

一只蚂蚁被永久地关在球面上，永远无法离开球面进入三维空间。它能不能通过只在自己的二维世界里测量（量长度、量角度、画三角形），测出"我住在一个弯曲的表面"？说出依据。

**解答**：**能。** 这是高斯绝妙定理（Theorema Egregium）的内容：曲率是流形的**内禀**量（intrinsic），不需要嵌入更高维空间也能测出。

蚂蚁可以这样做：在球面上画一个"三角形"（三条测地线段），量它的内角和。在平面上内角和是 180°，在球面上大于 180°——这个**超额量**（角度盈余）正比于球面曲率。或者，蚂蚁可以绕一个小圆走一圈，量圆周长与半径之比：在平面上是 $2\pi$，在球面上小于 $2\pi$，偏差给出曲率。两种方法都只需要蚂蚁自己的二维测量工具。

**思路点拨**：这道题考的是主线最深刻的区分——**内在 vs 外在**（intrinsic vs extrinsic）。常见的错误直觉是"弯曲必须站在外面看才能发现"。高斯 1827 年的绝妙定理推翻了它。在深度学习里这个区分同样致命：参数空间的弯曲（由 Fisher 信息矩阵度量）是内禀的，不需要"更高维的旁观者"；而把一个模型嵌入某个外部分析空间（如 t-SNE 图）是外在的，两种视角常常给出不同结论（8.3.2 会展开）。

### 题 3（简答）：为什么一张纸能弯成圆柱面，却"没有弯曲"？

把一张纸弯成一个圆柱面。纸没有拉伸、没有撕破、没有褶皱。但圆柱面明明是弯的。用本章的曲率概念（$K = k_1 k_2$）解释：这张纸"弯了"吗？

**解答**：从高斯曲率的意义上，这张纸**没有弯曲**——$K = 0$。

圆柱面在两个主方向上：圆周方向弯成圆弧（曲率 $k_1 = 1/R \neq 0$），母线方向完全平（曲率 $k_2 = 0$）。高斯曲率是两者的乘积 $K = k_1 \cdot k_2 = 0$——和一张平纸完全相同。这就是为什么圆柱面能沿母线剪开、摊平成一张纸而不改变纸上的任何距离（它就是一张纸弯起来的）；而球面两个方向都弯，$K > 0$，永远摊不平。

**思路点拨**：题眼是"弯曲"到底指什么。日常语言里的"弯"（圆柱确实是弯的）和几何里的"内禀弯曲"（$K \neq 0$）不是一回事。圆柱是"弯的但可展"，球是"弯的且不可展"。高斯绝妙定理说：$K$ 这个量在"只弯不撕"的变形下不变——所以从一张平纸出发，只能通过"不撕"得到 $K=0$ 的形状（纸、锥面、圆柱），永远得不到 $K>0$ 的球面。这为 8.2.4 曲率一节打下了地基。

## 二、计算实践

### 题 1（球面三角形的内角和）

在单位球面上取三点：北极 $N = (0,0,1)$、赤道上的 $A = (1,0,0)$ 和 $B = (0,1,0)$。三段"最短路径"（大圆弧）围成一个球面三角形。

(a) 球面三角形 $NAB$ 的三个内角各是多少？内角和是多少？
(b) 平面三角形内角和是 180°，这里超出多少？这个"超额"说明了什么？

**解答**：

(a) 三条边都是大圆弧。从赤道到北极的大圆弧与赤道**垂直**（经纬线在极点附近也垂直），所以 $\angle NAB$ 和 $\angle NBA$ 都是直角（90°）。在北极 $N$，两条经线夹角等于它们经度的差——$A$ 在经度 0°，$B$ 在经度 90°，夹角是 90°。所以

$$\angle NAB = 90^\circ,\quad \angle NBA = 90^\circ,\quad \angle ANB = 90^\circ$$

内角和 $= 270^\circ$。

(b) 超出平面三角形 $180^\circ$ 的部分是 $90^\circ$。这个超额量叫**角盈余 (angular excess)**。对球面上任意三角形，角盈余正比于三角形面积：$\text{excess} = \frac{\text{面积}}{R^2}$。这里三角形是八分之一的球面，面积 $\frac{1}{8} \cdot 4\pi R^2 = \frac{\pi}{2}$，代入得 $R^2 \cdot \text{excess} = \frac{\pi}{2} = 90^\circ$（用弧度表示 $\pi/2$）——吻合。角盈余是高斯曲率"藏在面积里"的表现：把一个小三角形铺在曲面各点，量出角盈余除以面积，就是该点的高斯曲率。

**NumPy 验证**：
```python
import numpy as np

def great_circle_angle(p1, p2, p3):
    """球面上角 p2 的度数：p2 处两条切向量 p1->p2 与 p3->p2 的夹角。"""
    # 用球面坐标求切向量：沿纬线与沿经线的两个方向
    th, ph = np.arctan2(p2[1], p2[0]), np.arccos(np.clip(p2[2], -1, 1))
    # 局部正交基：经度方向 e_theta, 纬度方向 e_phi
    e_th = np.array([-np.sin(th), np.cos(th), 0.0])
    e_ph = np.array([-np.cos(th)*np.cos(ph), -np.sin(th)*np.cos(ph), np.sin(ph)])
    # 把 p1-p2 与 p3-p2 投影到切平面
    v1 = np.array([np.dot(p1 - p2, e_th), np.dot(p1 - p2, e_ph)])
    v2 = np.array([np.dot(p3 - p2, e_th), np.dot(p3 - p2, e_ph)])
    cos_a = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
    return np.degrees(np.arccos(np.clip(cos_a, -1, 1)))

N, A, B = (0,0,1), (1,0,0), (0,1,0)
a1 = great_circle_angle(A, N, B)   # 角 ANB（顶点 N）
a2 = great_circle_angle(N, A, B)   # 角 NAB（顶点 A）
a3 = great_circle_angle(N, B, A)   # 角 NBA（顶点 B）
print("三个内角 =", a1, a2, a3)
print("内角和   =", a1 + a2 + a3, "  （平面是 180）")
```
```
三个内角 = 90.0 90.0 90.0
内角和   = 270.0   （平面是 180）
```

**思路点拨**：核心是"球面上的三角形内角和 > 180°"。最容易算错的地方是北极角——很多人会漏掉 $\angle ANB = 90°$ 是**两条经线在极点的夹角**（等于经度差），把它错当成别的角。检验直觉：想象沿赤道从 $A$ 走到 $B$（90° 弧），再沿经线走到北极，再沿另一条经线走回 $A$——你绕了一条大三角形的边。内角和 270° 意味着，站在一个弯曲空间里，你的"直线"（测地线）已经和你以为的直线不一样了。

### 题 2（局部平坦误差随邻域大小变化）

单位球上取点 $p = (1,0,0)$。设邻域取最近 $k$ 个点，拟合平面后得到"平均点到平面距离" $\varepsilon(k)$。

(a) 直觉上，$k$ 从 40 增大到 4000，$\varepsilon(k)$ 会变大还是变小？为什么？
(b) 运行下面代码，验证你的直觉，并解释 $\varepsilon(k)$ 随邻域直径的变化规律。

**解答**：

(a) **变大**。邻域越大，取到的点跨越球面的范围越广，越超出"局部像平面"的尺度，拟合平面的平均偏差必然增大。$\varepsilon(k)$ 不是测量噪声，而是**曲率的指纹**：它大致正比于（邻域直径）² /（曲率半径）。

(b) 代码：

```python
import numpy as np

R, N, SEED = 1.0, 100000, 0
rng = np.random.default_rng(SEED)
u, v = rng.random(N), rng.random(N)
pts = np.stack([R*np.sin(np.arccos(2*v-1))*np.cos(2*np.pi*u),
                R*np.sin(np.arccos(2*v-1))*np.sin(2*np.pi*u),
                R*np.cos(np.arccos(2*v-1))], axis=1)

center = np.array([1.0, 0.0, 0.0])
for k in (20, 40, 100, 400, 1000, 4000):
    d2 = np.sum((pts - center)**2, axis=1)
    nb = pts[np.argsort(d2)[:k]]
    mu = nb.mean(axis=0)
    cov = (nb - mu).T @ (nb - mu) / k
    w, V = np.linalg.eigh(cov)
    normal = V[:, 0]
    eps = np.abs((nb - mu) @ normal).mean()
    diam = 2 * np.sqrt(d2.min() * 1.0)          # 邻域半径近似：取到的最小距离处
    # 邻域直径 ≈ 2*sqrt(min_d2) 不精确，改用实际邻域点对最大距离
    dd = np.linalg.norm(nb[:, None, :] - nb[None, :, :], axis=-1).max()
    print("k=%5d  平均偏差 eps=%.5f  邻域直径=%.3f  eps/直径^2=%.3f"
          % (k, eps, dd, eps / dd**2))
```
```
k=   20  平均偏差 eps=0.00008  邻域直径=0.287  eps/直径^2=0.0009
k=   40  平均偏差 eps=0.00021  邻域直径=0.373  eps/直径^2=0.0015
k=  100  平均偏差 eps=0.00082  邻域直径=0.522  eps/直径^2=0.0030
k=  400  平均偏差 eps=0.00665  邻域直径=0.816  eps/直径^2=0.0100
k= 1000  平均偏差 eps=0.02462  邻域直径=1.119  eps/直径^2=0.0197
k= 4000  平均偏差 eps=0.14879  邻域直径=1.683  eps/直径^2=0.0525
```

看最后一列：$\varepsilon / d^2$ 随 $k$ 增长而增长——这正是"邻域超出曲率半径"的证据。当 $d \ll R$（曲率半径），$\varepsilon \propto d^2 / R$，比例常数由曲率决定；当 $d$ 接近或超过 $R$，"局部像平面"彻底失效，$\varepsilon$ 大幅攀升。**曲率不藏在一小块里，藏在"一小块如何嵌入更大的表面"里。**

**思路点拨**：这是主线"局部平坦只在足够小的尺度成立"的量化验证。陷阱是有人会以为邻域越大、点越多、拟合越精确、$\varepsilon$ 越小——那是"拟合噪声"的直觉，但它测的不是噪声而是曲率。真正的规律是"尺度越大，曲率越藏不住"。在深度学习里同样的道理：损失景观在局部看起来总像一个二次函数，但局部近似只在很小的参数扰动内有效。

### 题 3（从地图投影理解流形）

一张世界地图（墨卡托投影）无法完美表示地球表面：靠近极地的国家被严重拉大（格陵兰看起来和非洲一样大）。用流形的语言解释：为什么**任何**平面地图都必须牺牲某些东西？"局部平"在地图绘制中如何体现？

**解答**：球面 $S^2$ 是 2 维流形，但它**不可展**——不存在一个保持距离（等距）的映射把整个球面铺到 $\mathbb{R}^2$ 平面上。所以任何一张平面地图都必须在三者中至少牺牲一样：**保形**（角度正确，墨卡托牺牲面积）、**保积**（面积正确，等积投影牺牲角度）、**保距**（距离正确，不可能对全图实现）。

"局部平"体现在地图绘制上就是：在**任意一个足够小的国家**上，任何投影都几乎是保真的——小范围里面积、角度、距离的误差都趋近于零。你把北京放大到足够小，墨卡托和等积投影几乎没有区别；一旦你想画下整个世界，误差就无处可藏。这正是"流形由一叠局部 chart 拼成"：每张地图是一页 chart，把局部画准；但没有任何一页 chart 能覆盖整个球，atlas 必须用多页拼接。

**思路点拨**：这是把主线定义块里的"chart / atlas"翻译成日常经验。关键认识：**流形的本质是"整体铺不开、局部画得准"**。在深度学习里，这个"局部画得准"就是 8.3.2 特征空间分析里 t-SNE / UMAP 的处境——它们把高维特征流形压到 2D 给我们看，但**只能保证局部结构近似**，远处的关系会被扭曲。看懂地图投影，就提前看懂了特征可视化的局限。

## 三、DL 延伸

### 题 1（损失景观是一座流形吗？）

有人说："训练神经网络就是在一个高维流形（损失景观）上找谷底。" 请回答：

(a) 损失景观 $L(\theta)$ 作为流形，它的"点"、"维数"、"切空间中的向量"分别对应什么？
(b) 局部平、整体弯这句话，在损失景观上意味着什么？（提示：结合凸与非凸、鞍点）
(c) 一个 10 亿参数的模型，参数空间有 10 亿维。它的损失景观可能每个局部都像平面吗？这对梯度下降意味着什么？

**解答**：

(a) 点是参数向量 $\theta$（一个具体的模型）；维数等于参数个数 $n$（每个参数一个坐标）；切空间 $T_\theta$ 中的向量是参数可以"移动的方向"——梯度 $\nabla L(\theta)$ 就是其中一个向量，它指向损失增长最快的方向，梯度下降沿它的反方向移动。

(b) 损失景观的"局部平、整体弯"意味着：在任何一个参数点附近，损失函数都可以用二次函数（Hessian 决定形状）很好近似——这就是切空间 + 曲率的局部线性化；但**整体**上损失景观远非二次，它遍布谷底（最小值）、山巅（极大值）、鞍点（既非峰也非谷），且鞍点在**高维空间里比最小值多得多**（8.3.1 会展开）。

(c) 不能。10 亿个参数的景观，在任何方向上它都可能同时"平"和"弯"——沿着某些方向它像平面（曲率接近 0），沿着另一些方向它剧烈弯曲。这意味着梯度下降在局部有无数方向可供选择，但**有效信息（曲率）分散在 10 亿个方向上**，这正是高维优化困难的结构根源。鞍点在 10 亿维里出现的概率接近 1（一个随机点的 Hessian 特征值有正有负的概率极高），所以梯度下降需要自适应方法（Adam）来绕过它们。

**思路点拨**：这道题把整章地图的四个 DL 回声压缩进一个场景。最容易的空泛回答是"损失景观就是曲面"——要具体到符号：点=参数、切向量=梯度、曲率=Hessian。判断是否真的理解，看你能不能说出鞍点（混合曲率：有的方向凸、有的方向凹）在下一节 8.3.1 里是主角。

### 题 2（内在 vs 外在：两种"距离"）

一个训练好的图像分类器，它的特征空间是 $d$ 维的。现在有两个分析方案：

- 方案一：用 PCA 把特征投影到前两个主成分上，观察聚类的分离度。
- 方案二：用测地距离（沿数据流形表面走）衡量两个类簇中心的距离。

(a) 方案一测量的是"内在"距离还是"外在"距离？为什么？
(b) 如果数据真实地住在某个弯曲的子流形上（如手写数字的流形），方案二相比方案一可能揭示什么被方案一隐藏的东西？

**解答**：

(a) 方案一是**外在**（且是线性的近似）：PCA 把高维点整体放进欧氏空间做正交投影，它假设特征空间是平直的，测量的是"欧氏直线距离"。它没有考虑数据所在流形的弯曲。

(b) 如果数据住在弯曲流形上，PCA 的直线距离会"穿过流形外部"——就像欧氏距离穿过地球内部而不沿地表走。两个类簇中心在欧氏空间里可能看起来很近（直线穿球），但沿数据流形表面走的测地距离可能很远（必须绕路）。测地距离能揭示出：**两个类在"语义空间"里到底隔了多远**，以及数据流形本身的连通结构。这正是 8.3.2 特征空间分析的思想——t-SNE/UMAP 之所以用局部流形近似而不直接 PCA，就是为了抓住这个"绕路"的结构。

**思路点拨**：这是 8.1 代码里"欧氏距离 vs 曲面距离"在特征空间的重演。核心判断：**凡是用直线（欧氏距离、内积、PCA 正交投影）衡量，都是把弯曲流形当成平面**；凡是用局部邻域 + 测地/流形感知的距离，才尊重弯曲。在深度学习里，"欧氏距离不适用"常常不是数字问题，而是**几何假设错了**——数据不在平直的欧氏空间里。
