# 习题：均值（期望值）

## 第一组：概念检验

**1. 掷一枚均匀骰子，$X$ 为点数。$\mathbb{E}[X]$ 是多少？这个值是不是骰子可能出现的结果？它告诉你什么、不告诉你什么？**

**解答**：$\mathbb{E}[X]=\frac{1}{6}(1+2+3+4+5+6)=3.5$。3.5 不是骰子面，但它正确回答了"长期反复掷骰子的平均点数"。它告诉你"平均中心"在 3.5；它**不**告诉你分布多散、偏不偏、最可能是什么。$\mathbb{E}[X]=3.5$ 与"每面都是 $\frac16$"这个对称结构绑定——换个不对称的分布，均值就不再等于"中点"。

**2. 判断题并说明理由："如果 $\mathbb{E}[X]$ 很大，说明 $X$ 大概率取很大的值。"**

**解答**：错误。期望是加权平均，可能被少量极大值拉高。典型例子是收入分布：均值被极少数富人拉高，而**最可能**的收入（众数）很低。$\mathbb{E}[X]$ 大只说明"总体平均水平高"，不代表"单个样本大概率大"。

**3. 为什么 $\mathbb{E}[X+Y]=\mathbb{E}[X]+\mathbb{E}[Y]$ 不需要 $X$ 和 $Y$ 独立，而 $\mathbb{E}[XY]=\mathbb{E}[X]\mathbb{E}[Y]$ 通常需要？**

**解答**：期望是线性算子——求和可以拆开，这来自期望的定义（每项的线性叠加），与独立无关。而乘积的期望等于期望的乘积，是因为"联合分布是否等于边缘分布的乘积"——只有独立时联合密度才分解，$XY$ 的期望才等于各自期望的乘积。记住这个不对称，是理解协方差与相关性（后续内容）的关键。

## 第二组：计算实践

**4. 手算 + 代码验证。** 一档保险：每月保费 200 元。若出险（概率 2%）理赔 5000 元，若不出险（98%）无理赔。对保险公司而言，每月每单的期望利润是多少？

**解答**：理赔的期望成本 $=5000\times0.02=100$ 元。利润 $=\text{保费}-\text{期望成本}=200-100=100$ 元/单/月。更正式地：令 $Y$ 为净利润，$Y=200$（不出险，概率 0.98）或 $Y=200-5000=-4800$（出险，概率 0.02），$\mathbb{E}[Y]=200\times0.98+(-4800)\times0.02=196-96=100$ 元。

代码验证：

```python
import numpy as np
vals = [200.0, -4800.0]
probs = [0.98, 0.02]
print("期望利润 =", np.sum(np.array(vals) * np.array(probs)), "元")
```

输出：

```text
期望利润 = 100.0 元
```

**思路点拨**：若有人算成"$200-5000=-4800$"，那是忘了乘概率——理赔不是必然发生。保险业的全部生意，就是"期望利润 > 0"这门算术。注意单笔可能亏损 4800 元，但长期平均每单赚 100——期望值看的是"长期平均"。

**5. 用抽样验证大数定律。** 从"99 个 0 元 + 1 个 500 元"的转盘抽 $N$ 次，画样本均值随 $N$ 的收敛（打印几个节点值）。

**解答**：

```python
import numpy as np
np.random.seed(0)
vals, probs = [0.0]*99+[500.0], [0.99]*99+[0.01]
samples = np.random.choice(vals, size=200000, p=probs)
for N in (10, 100, 1000, 10000, 200000):
    print(f"N={N:>6}: 样本均值 = {samples[:N].mean():.3f}")
```

输出（每次略有不同）：

```text
N=    10: 样本均值 = 0.000
N=   100: 样本均值 = 5.000
N=  1000: 样本均值 = 4.500
N= 10000: 样本均值 = 4.800
N=200000: 样本均值 = 4.997
```

$N=10$ 时可能是 0（一次大奖都没抽中），$N$ 越大均值越贴近 5。**思路点拨**：前几个样本的均值剧烈抖动，这是小样本的随机性；大数定律保证抖动随 $N$ 收缩，但不是"单调逼近"——中间可能忽高忽低。

## 第三组：DL 延伸

**6. 损失函数场景。** 训练一个分类器，损失函数是交叉熵 $\ell(f_\theta(x),y)$。训练目标写为 $\min_\theta \frac{1}{N}\sum_{i=1}^{N}\ell(f_\theta(x_i),y_i)$。请解释：这个"经验均值"和"真实期望" $\mathbb{E}_{(x,y)\sim p}[\ell(f_\theta(x),y)]$ 的关系是什么？为什么样本多、模型学得越好？

**解答**：真实期望是对数据分布 $p$ 的积分——但它不可计算（我们不知道 $p$）。我们用 $N$ 个样本的均值去**估计**它，这就是经验风险最小化。两者的差距随 $N$ 增大而缩小（大数定律）：样本均值 $\to$ 期望。训练集是"从 $p$ 里抽的有限样本"，所以训练损失只是真实损失的近似——这直接通向过拟合与泛化（§4.2.5）：样本越少，经验均值离真实期望越远，模型"以为学到的东西"与"真实规律"偏离越大。**你每次看训练曲线上的 loss 下降，看的就是一个样本均值在朝它的期望移动。**
**思路点拨**：若有人把"训练集损失降为 0"当成"真实损失也降为 0"，那是混淆了经验均值与期望——这正是过拟合的数学根源。样本越少，均值作为期望的估计越不可靠，模型越容易把噪声当真信号。
