# 代码：期望值——把"加权平均"写进函数，让离散与连续在同一把尺子上对账

主线里我们把期望值定义为"值 × 概率（密度）"的加权平均：离散求和 $\mathbb{E}[X]=\sum_i x_i P(X=x_i)$，连续积分 $\mathbb{E}[X]=\int x f(x)dx$。本课用代码做三件事：

1. **离散验算**：转盘"99 个 0 元 + 1 个 500 元"，期望回报应为 5 元。
2. **连续验算**：对正态 $\mathcal{N}(50,25)$ 用梯形积分算 $\int x f(x)dx$，应得 50。
3. **函数期望**：算 $\mathbb{E}[X^2]$，为下一节方差做铺垫。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：linspace / trapz / mean

def expected_discrete(values, probs):     # ① 离散期望：值 × 概率，求和
    """E[X] = Σ x_i P(X=x_i)"""
    return np.sum(np.asarray(values) * np.asarray(probs))

def expected_continuous(x, pdf):          # ② 连续期望：x * f(x) 做梯形积分
    """E[X] = ∫ x f(x) dx，x 是网格，pdf 是网格上的密度值。"""
    return np.trapz(x * pdf, x)

# ---- ① 转盘：99 个格子 0 元，1 个格子 500 元 ----
vals = [0.0] * 99 + [500.0]               # 100 个可能值
probs = [0.99] * 99 + [0.01]              # 对应概率（99% 的 0 元 + 1% 的 500 元）
mean_lottery = expected_discrete(vals, probs)
print(f"转盘期望回报 = {mean_lottery:.2f} 元   # 理论 500×1% = 5 元")

# ---- ② 连续：N(50, 25)，即 mu=50, sigma=5 ----
x = np.linspace(20.0, 80.0, 100001)       # μ±6σ，覆盖几乎全部质量
pdf = 1.0 / (5.0 * np.sqrt(2.0 * np.pi)) * np.exp(-(x - 50.0)**2 / (2.0 * 25.0))
mean_normal = expected_continuous(x, pdf)
print(f"N(50,25) 的期望 ≈ {mean_normal:.6f}   # 理论 μ = 50")

# ---- ③ 函数的期望：E[X^2]（为方差铺垫）----
ex2 = np.trapz(x * x * pdf, x)            # E[X^2] = ∫ x² f(x) dx
print(f"N(50,25) 的 E[X^2] ≈ {ex2:.2f}   # 理论 μ²+σ² = 2500+25 = 2525")

# ---- ④ 抽样验证：抽 100 万次转盘，样本均值应逼近 5 ----
np.random.seed(0)
spins = np.random.choice(vals, size=1000000, p=probs)
print(f"转盘抽样 100 万次的均值 = {spins.mean():.4f}   # 理论 5，大数定律")
```

运行输出（Python 3.11 + NumPy）：

```text
转盘期望回报 = 5.00 元   # 理论 500×1% = 5 元
N(50,25) 的期望 ≈ 50.000000   # 理论 μ = 50
N(50,25) 的 E[X^2] ≈ 2525.00   # 理论 μ²+σ² = 2500+25 = 2525
转盘抽样 100 万次的均值 = 5.0044   # 理论 5，大数定律
```

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

```python
import numpy as np
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 $\sum$（`np.sum`）、$\int$（`np.trapz`）提供执行者。

---

### 步骤 2：定义 `expected_discrete` —— 求和版期望

```python
def expected_discrete(values, probs):
    """E[X] = Σ x_i P(X=x_i)"""
    return np.sum(np.asarray(values) * np.asarray(probs))
```

#### expected_discrete —— 离散期望：值 × 概率，逐项相乘再求和

**做什么**：把"每个可能值"和"对应概率"逐位相乘，再把所有乘积加起来。
**操作**：`np.asarray` 把列表转成 NumPy 数组；`*` 逐元素相乘（长度相同的两个数组）；`np.sum` 求和。
**输入**：
- `values`：所有可能取值 $x_i$，长度 $n$。
- `probs`：对应概率 $P(X=x_i)$，长度 $n$，要求 $\sum=1$。
**输出**：一个标量，期望值。
**可调参数**：列表长度可任意（只要 `values` 和 `probs` 等长）。注意**必须** $\sum p_i=1$，否则算出的不是期望——比如漏了某个概率，结果会系统性偏小。可以加一行 `assert abs(probs.sum()-1) < 1e-9` 做防御。
**对应数学**：$\mathbb{E}[X]=\sum_i x_iP(X=x_i)$。

---

### 步骤 3：定义 `expected_continuous` —— 积分版期望

```python
def expected_continuous(x, pdf):
    """E[X] = ∫ x f(x) dx，x 是网格，pdf 是网格上的密度值。"""
    return np.trapz(x * pdf, x)
```

#### expected_continuous —— 连续期望：把 x·f(x) 沿网格梯形积分

**做什么**：把"值 × 密度"这条曲线 $\mathbb{E}[X]=\int x f(x)dx$ 用梯形法则数值积分。
**操作**：`x * pdf` 逐元素算"每个位置的值 × 该位置的密度"；`np.trapz(曲线, x)` 沿网格积分。
**输入**：
- `x`：横坐标网格，形状 `(N,)`。
- `pdf`：与 `x` 对应的密度值，形状 `(N,)`。
**输出**：标量，期望值。
**可调参数**：网格越宽越密越准。对正态取 $\mu\pm6\sigma$ 已覆盖近乎全部质量；对尾巴更重的分布要更宽。
**对应数学**：$\mathbb{E}[X]=\int_{-\infty}^{\infty}x f(x)dx$。`x` 的跨度模拟"整个实数轴"，`N` 越大越接近真积分。

---

### 步骤 4：转盘的期望回报

```python
vals = [0.0] * 99 + [500.0]
probs = [0.99] * 99 + [0.01]
mean_lottery = expected_discrete(vals, probs)
print(f"转盘期望回报 = {mean_lottery:.2f} 元   # 理论 500×1% = 5 元")
```

**做什么**：构造"99 个 0 元 + 1 个 500 元"的转盘，算期望。
**操作**：`[0.0]*99 + [500.0]` 造出 100 个值的列表；`[0.99]*99 + [0.01]` 是 99 个 0.99 加一个 0.01——和为 1。
**输入**：100 个值 + 100 个概率。
**输出**：`5.00`。
**可调参数**：把 `500.0` 换成别的奖金、`0.01` 换成别的概率，期望随之变。直观检查：奖金 × 概率，正是"期望 = 结果 × 机会"。
**对应数学**：$5 = 0\times0.99 + 500\times0.01$。注意期望 5 元**不是**最可能结果（0 元）——它是一次"加权平均"。

---

### 步骤 5：连续正态的期望与 $\mathbb{E}[X^2]$

```python
x = np.linspace(20.0, 80.0, 100001)
pdf = 1.0 / (5.0 * np.sqrt(2.0 * np.pi)) * np.exp(-(x - 50.0)**2 / (2.0 * 25.0))
mean_normal = expected_continuous(x, pdf)
ex2 = np.trapz(x * x * pdf, x)
print(f"N(50,25) 的期望 ≈ {mean_normal:.6f}   # 理论 μ = 50")
print(f"N(50,25) 的 E[X^2] ≈ {ex2:.2f}   # 理论 μ²+σ² = 2500+25 = 2525")
```

**做什么**：在 $\mu=50,\sigma=5$ 的正态上算 $\mathbb{E}[X]$ 和 $\mathbb{E}[X^2]$。
**操作**：`pdf` 是手写的正态密度（见 §4.2.2.2）；`np.trapz(x * pdf, x)` 积分得 $\mathbb{E}[X]$；`np.trapz(x * x * pdf, x)` 积分得 $\mathbb{E}[X^2]$。
**输入**：网格与密度。
**输出**：`50.000000` 与 `2525.00`。
**可调参数**：`pdf` 换成任意分布的密度都能算。`ex2` 的公式 $\mathbb{E}[X^2]=\mu^2+\sigma^2=2500+25=2525$——这是下一节方差 $\mathrm{Var}[X]=\mathbb{E}[X^2]-\mu^2$ 的原料。
**对应数学**：$\mathbb{E}[X]=\int x f(x)dx$ 与 $\mathbb{E}[g(X)]=\int g(x)f(x)dx$。对称分布里 $\int (x-\mu)f(x)dx=0$，所以均值落在对称轴上。

---

### 步骤 6：抽样验证——大数定律

```python
np.random.seed(0)
spins = np.random.choice(vals, size=1000000, p=probs)
print(f"转盘抽样 100 万次的均值 = {spins.mean():.4f}   # 理论 5，大数定律")
```

#### `np.random.choice(a, size, p)` —— 按给定概率抽样

**操作**：从 `vals` 里按概率 `probs` 抽 `size` 个样本。
**输入**：
- `a`：候选值列表（这里 100 个）。
- `size`：样本数。
- `p`：与 `a` 等长的概率（和为 1）。
**输出**：形状 `(size,)` 的样本数组。
**可调参数**：第三个参数 `replace=True` 默认放回抽样；不传 `p` 则均匀抽取。换 `size` 可观察收敛——`size=1000` 时均值在 5 附近抖，`size=1000000` 时贴近 5.00。
**对应数学**：`spins.mean()` 是样本均值，大数定律保证它收敛到期望 5。理论给精确，抽样给验证——这是蒙特卡洛方法（§4.3.6）的第一次握手。

## 改个数字试试：期望不是最可能

### 实验：把"偶尔大奖"改成"稳定小奖"

```python
# 方案一：99% 中 5 元，1% 中 0 元 → 期望 4.95
print("期望(稳定小奖) =", expected_discrete([5.0, 0.0], [0.99, 0.01]))
# 方案二：50% 中 100 元，50% 中 0 元 → 期望 50
print("期望(抛硬币大奖) =", expected_discrete([100.0, 0.0], [0.5, 0.5]))
```

输出：

```text
期望(稳定小奖) = 4.95
期望(抛硬币大奖) = 50.00
```

方案二期望 50 元，比方案一高得多——可它有一半概率一无所获。期望值只回答"平均"，不回答"风险"。**这正是下一节方差要补的账**：两个分布可以有相同的期望，却有着完全不同的风险。别只看期望选方案。

## 边界声明：这套代码能做什么，不能做什么

1. **期望值可能不存在。** 对柯西分布 $f(x)\propto\frac{1}{1+x^2}$，$\int x f(x)dx$ 发散——均值根本不存在。对这类重尾分布，用 `np.trapz` 积分会得到一个随网格范围漂移的假数。**有分布，就未必有均值。**
2. **期望不是"最可能"。** 转盘的期望 5 元，最可能却是 0 元。用均值描述"典型"用户、典型收入、典型损失都会误导——收入分布就是均值被富人拉高的经典例子。
3. **这只是在"验算期望的定义"。** 真实训练里没人手写 $\int x f(x)dx$——损失、梯度、价值函数都由框架/采样器隐式计算。但看懂"$\frac1N\sum\ell(\cdot)$ 是期望的样本近似"，你就看懂了整个训练过程在最小化什么。
