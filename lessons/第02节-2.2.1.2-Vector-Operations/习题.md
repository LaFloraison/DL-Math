# 习题：向量运算

## 第一组：概念检验

**1.1（单选）** 点积 $\mathbf{a} \cdot \mathbf{b}$ 的结果是：
- A. 一个与 $\mathbf{a}$、$\mathbf{b}$ 都垂直的向量
- B. 一个标量，衡量两向量方向的"对齐程度"
- C. 一个向量，长度等于 $\mathbf{a}$、$\mathbf{b}$ 张成的平行四边形面积
- D. 一个标量，等于 $\|\mathbf{a}\| + \|\mathbf{b}\|$

**1.2（判断并说明）** "两个向量模长分别为 3 和 4，那么它们的和（向量加法）模长一定是 7。" 这句话对吗？什么时候成立，什么时候不成立？

**1.3（填空）** 若 $\mathbf{a} \cdot \mathbf{b} = 0$ 且 $\mathbf{a}$、$\mathbf{b}$ 都是非零向量，则两向量____（几何关系）。$\mathbf{a} \times \mathbf{b} = \mathbf{0}$ 当且仅当 $\mathbf{a}$、$\mathbf{b}$ ____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 给定 $\mathbf{a} = [2, -1]$，$\mathbf{b} = [1, 3]$。手算：$\mathbf{a}+\mathbf{b}$、$3\mathbf{a}$、$\mathbf{a}\cdot\mathbf{b}$，并用 NumPy 验证，指出每个结果的"形状"（向量还是标量）。

**2.2（代码验证）** 验证 $\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}$：对 $\mathbf{a}=[1,0]$，$\mathbf{b}=[\cos 60^\circ, \sin 60^\circ]$，算出夹角并确认是 $60°$。

**2.3（动手理解）** 用代码验证 $\mathbf{a} \times \mathbf{b} = -(\mathbf{b} \times \mathbf{a})$（反交换律），并解释几何含义。

## 第三组：DL 延伸

**3.1（场景判断）** 神经网络里一个神经元的输出是 $z = \mathbf{w}\cdot\mathbf{x} + b$。为什么研究者常说"这个神经元在检测输入与权重是否对齐"？请用点积的几何意义解释。

**3.2（场景分析）** Transformer 的注意力计算 $QK^\top$ 被称为"点积注意力"。如果两个 token 的向量 $\mathbf{q}$ 与 $\mathbf{k}$ 的夹角接近 $180°$，注意力权重会偏高还是偏低？为什么？这对模型的"关注什么"意味着什么？

---

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：点积的定义是"对应分量相乘再求和"，结果必然是标量；而 $\mathbf{a}\cdot\mathbf{b} = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$ 揭示它衡量的是"方向对齐程度"。A 描述的是叉积，C 描述的也是叉积（长度=面积），D 完全错误。
- **点拨**：把四个选项当"概念对照表"：A/C 是叉积的属性，B 才是点积。**点积→标量→对齐；叉积→向量→垂直。**

**1.2 这句话只在"两向量同向"时成立。**
- **思路**：模长公式 $\|\mathbf{a}+\mathbf{b}\|$ 不能直接等于 $\|\mathbf{a}\|+\|\mathbf{b}\|$。更准确的关系是三角不等式 $\|\mathbf{a}+\mathbf{b}\| \le \|\mathbf{a}\|+\|\mathbf{b}\|$，等号当且仅当 $\mathbf{a}$、$\mathbf{b}$ **同向**。同向时 $\|3+4\| = 7$；垂直时 $\|\mathbf{a}+\mathbf{b}\| = \sqrt{3^2+4^2} = 5$；反向时 $\|\mathbf{a}+\mathbf{b}\| = |3-4| = 1$。
- **点拨**：用勾股/三角不等式思考。把"加法"与"模长相加"分开——**加法是分量相加，模长是算出来的**，二者不是一回事。

**1.3 答案：垂直（正交）；平行（夹角 0° 或 180°）。**
- **思路**：$\mathbf{a}\cdot\mathbf{b}=0$ 且非零 → $\cos\theta=0$ → $\theta=90°$。叉积模长 $\|\mathbf{a}\|\|\mathbf{b}\|\sin\theta=0$ 且非零向量 → $\sin\theta=0$ → $\theta\in\{0°,180°\}$。
- **点拨**：这两条"判据"是本节最常用的结论——"点积零 ⟺ 垂直"在深度学习里用来检测特征是否独立；"叉积零 ⟺ 平行"在几何里检测共线。

### 第二组

**2.1**
$\mathbf{a}+\mathbf{b} = [3, 2]$（向量）；$3\mathbf{a} = [6, -3]$（向量）；$\mathbf{a}\cdot\mathbf{b} = 2\cdot1 + (-1)\cdot3 = 2 - 3 = -1$（标量）。

```python
import numpy as np
a = np.array([2.0, -1.0]); b = np.array([1.0, 3.0])
print(a + b, (a + b).shape)     # [3. 2.] (2,)
print(3 * a, (3 * a).shape)     # [ 6. -3.] (2,)
print(np.dot(a, b))             # -1.0
```
- **思路**：加法和数乘保持向量形状 `(2,)`；点积坍缩成标量 `-1.0`。
- **点拨**：观察 `.shape` 是理解"谁得向量、谁得标量"的最直接方法。负的点积表示夹角 $>90°$——$\mathbf{a}$ 与 $\mathbf{b}$ 大致相反。

**2.2**
$\mathbf{a}\cdot\mathbf{b} = 1\cdot\cos60° + 0\cdot\sin60° = \cos60° = 0.5$，$\|\mathbf{a}\|=1$，$\|\mathbf{b}\|=1$，故 $\cos\theta = 0.5$，$\theta=60°$。

```python
import numpy as np
a = np.array([1.0, 0.0]); th = np.radians(60)
b = np.array([np.cos(th), np.sin(th)])
cos = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(np.degrees(np.arccos(np.clip(cos, -1, 1))))   # 60.0
```
- **思路**：这题直接体现公式——点积给出的正是"一个向量在另一个方向上的投影比例"。
- **点拨**：注意到 $\mathbf{a}\cdot\mathbf{b}$ 恰好等于 $\cos60°$，因为 $\mathbf{a}$、$\mathbf{b}$ 都是单位向量。**单位向量之间的点积就是夹角余弦**——这是后面相似度计算最常用的捷径。

**2.3**
```python
import numpy as np
a = np.array([1.0, 2.0, 3.0]); b = np.array([4.0, 5.0, 6.0])
print(np.cross(a, b))                    # [-3.  6. -3.]
print(np.cross(b, a))                    # [ 3. -6.  3.]
```
**输出**：两结果互为相反数。几何含义：右手定则决定了 $\mathbf{a}\times\mathbf{b}$ 的方向；交换顺序后，右手的手指方向反转，大拇指指向相反方向，向量取负。
- **思路**：这正是主线"$\mathbf{a}\times\mathbf{b} = -(\mathbf{b}\times\mathbf{a})$"。反交换律是叉积与点积最大的行为差异之一——点积可交换（$\mathbf{a}\cdot\mathbf{b}=\mathbf{b}\cdot\mathbf{a}$），叉积反交换。
- **点拨**：记住"点积对称、叉积反对称"，在几何和物理推导中能省大量排查时间。

### 第三组

**3.1 思路**
- 神经元计算 $z = \mathbf{w}\cdot\mathbf{x} + b$，其中点积 $\mathbf{w}\cdot\mathbf{x} = \|\mathbf{w}\|\|\mathbf{x}\|\cos\theta$ 衡量输入 $\mathbf{x}$ 与权重 $\mathbf{w}$ 的"对齐程度"。
- 当输入向量与权重向量方向一致（夹角小），点积大，神经元被强烈激活；当方向相反或垂直，点积小甚至为负，神经元沉默。
- 所以训练过程，本质上是**让每个神经元的权重向量指向它"应该响应"的输入模式**——权重学习了"要检测的特征长什么样"，点积就是那个"检测器"。
- **点拨**：把"点积=对齐"这个几何画面带进深度学习，很多直觉就通了：权重向量是指向特征的方向，激活是输入在该方向的投影强度。

**3.2 思路**
- 夹角接近 $180°$ 时，$\cos\theta \approx -1$，点积 $QK^\top$ 为**大负数**。
- 注意力权重来自点积经过 Softmax 归一化，大负数对应的权重会**接近 0**——即该 token 对另一个 token "几乎不关注"。
- 这意味着：**注意力机制天然排斥方向相反的向量**——模型会把"关注"集中在方向一致（语义相关）的 token 上，忽略方向相反的。这就是"注意力"这个名字的数学内涵：它用点积决定把目光投向谁。
- **点拨**：注意点积未归一化时，$\cos\theta$ 还要乘以两向量的模长——所以"向量的长度"也影响注意力强弱。这就是为什么有时研究者会对 $Q$、$K$ 做归一化（$\frac{QK^\top}{\sqrt{d_k}}$），避免模长主导注意力。
