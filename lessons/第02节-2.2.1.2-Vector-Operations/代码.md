# 代码：把四种向量运算亲手按出来——加法、数乘、点积、叉积

主线里我们认识了四种运算：加法（对应分量相加）、数乘（每个分量乘 $k$）、点积（乘后求和，得标量）、叉积（三维专用，得垂直向量）。这一节用 NumPy 全部实现，重点观察：**谁得向量，谁得标量**——这是最容易在代码里分不清的地方。

---

## 层一：完整脚本

```python
import numpy as np                                  # NumPy：向量运算全家桶

# ---- ① 造两个向量（与教材一致）----
a = np.array([1.0, 2.0])
b = np.array([3.0, 4.0])
print("a =", a, "| b =", b)

# ---- ② 加法：对应分量相加，结果仍是向量 ----
c = a + b
print("a + b =", c, "形状:", c.shape)               # [4. 6.]

# ---- ③ 数乘：每个分量乘同一个数；负数反向 ----
v   = np.array([2.0, 1.0])
print("3*v     =", 3 * v, "形状:", (3 * v).shape)   # [6. 3.]
print("-2*v    =", -2 * v)                          # [-4. -2.]

# ---- ④ 点积：对应分量相乘再求和，结果是标量 ----
dot1 = np.dot(a, b)                                 # 1*3 + 2*4 = 11
dot2 = a @ b                                        # @ 对两个向量就是点积
print("np.dot(a,b) =", dot1, "| a @ b =", dot2)     # 都是 11，都是标量

# ---- ⑤ 点积的几何：夹角 ----
norm_a, norm_b = np.linalg.norm(a), np.linalg.norm(b)
cos_theta = dot1 / (norm_a * norm_b)
theta_deg = np.degrees(np.arccos(np.clip(cos_theta, -1, 1)))
print(f"cosθ = {cos_theta:.4f} → θ = {theta_deg:.2f}°")

# ---- ⑥ 叉积：三维专用，结果是垂直于 a、b 的向量 ----
a3 = np.array([1.0, 0.0, 0.0])                      # x 轴单位向量
b3 = np.array([0.0, 1.0, 0.0])                      # y 轴单位向量
cross = np.cross(a3, b3)
print("a3 × b3 =", cross)                           # [0. 0. 1.] → z 轴
print("垂直检验: a3·(a3×b3) =", np.dot(a3, cross), "| b3·(a3×b3) =", np.dot(b3, cross))
```

运行输出（Python 3.11 + NumPy）：

```text
a = [1. 2.] | b = [3. 4.]
a + b = [4. 6.] 形状: (2,)
3*v     = [6. 3.] 形状: (2,)
-2*v    = [-4. -2.]
np.dot(a,b) = 11 | a @ b = 11
cosθ = 0.9822 → θ = 10.80°
a3 × b3 = [0. 0. 1.]
垂直检验: a3·(a3×b3) = 0.0 | b3·(a3×b3) = 0.0
```

四种运算，一条条验证了主线。下面拆开看。

## 层二：分步逐函数拆解

### 步骤 1：造向量

```python
a = np.array([1.0, 2.0])
b = np.array([3.0, 4.0])
```

**做什么**：构造两个二维向量，与教材例子一致。
**操作**：`np.array` 把列表转成 `ndarray`，形状 `(2,)`。
**输入**：两个一维列表。
**输出**：`a=[1.,2.]`、`b=[3.,4.]`。
**可调参数**：维数随列表长度变化；换任何数字都可以，本脚本的数值结构不变。

### 步骤 2：加法 `a + b`

```python
c = a + b
```

#### `ndarray + ndarray` —— 逐元素加法

**做什么**：两个同形状数组**对应位置相加**，结果仍是数组。
**操作**：$c_i = a_i + b_i$：`[1+3, 2+4] = [4, 6]`。NumPy 对"+"运算符做了逐元素重载。
**输入**：两个形状 `(2,)` 的数组。**形状必须相同**——不同形状会触发广播规则（§2.4.4 讲）或报错。
**输出**：形状 `(2,)` 的数组 `[4., 6.]`。
**可调参数**：无多余参数；"+"固定做逐元素加。
**对应数学**：主线 $\mathbf{a} + \mathbf{b} = [a_1+b_1, a_2+b_2]$。

### 步骤 3：数乘 `3 * v`

```python
print("3*v     =", 3 * v)
print("-2*v    =", -2 * v)
```

#### `标量 * ndarray` —— 逐元素缩放

**做什么**：每个分量乘以同一个标量。
**操作**：`3 * [2., 1.] = [6., 3.]`；`-2 * [2., 1.] = [-4., -2.]`。
**输入**：标量 `3`（或 `-2`）与数组 `v`。
**输出**：同形状数组，模长变为原来的 `|k|` 倍，`k<0` 时方向反转。
**可调参数**：`k` 可以是任何实数；`k=0` 得全零数组。
**对应数学**：主线数乘定义 $(k\mathbf{v})_i = k v_i$。这里也体现了"线性"的第一个性质：向量对缩放是"齐次"的。

### 步骤 4：点积——两个写法，一个结果

```python
dot1 = np.dot(a, b)
dot2 = a @ b
```

#### `np.dot(a, b)` —— 点积 / 内积

**操作**：$\sum_i a_i b_i = 1\cdot3 + 2\cdot4 = 11$。对一维数组，`np.dot` 就是点积。
**输入**：两个形状 `(n,)` 的数组。
**输出**：**标量** `11`——注意是 `11`，不是 `[11.]`。向量运算里唯一"降维到数"的操作之一。
**可调参数**：`np.dot` 对更高维数组会退化为矩阵乘法（§2.3.4.3）；对二维来说它和 `@` 等价。

#### `a @ b` —— `@` 运算符

**操作**：Python 3.5+ 引入的矩阵乘法运算符。两个一维数组用 `@`，结果与 `np.dot` 相同——都是标量。
**输入**：两个形状 `(n,)` 的数组。
**输出**：标量 `11`。
**可调参数**：无；注意 `@` 与逐元素的 `*` 完全不同——`a * b = [3, 8]`（逐元素相乘得数组），`a @ b = 11`（求和得标量）。**这是初学者最常踩的坑。**
**对应数学**：主线 $\mathbf{a}\cdot\mathbf{b} = \sum_i a_i b_i$。点积是深度学习里最重要的运算，它的结果"对齐程度"由下一步的夹角揭示。

### 步骤 5：夹角——点积的几何解读

```python
cos_theta = dot1 / (norm_a * norm_b)
theta_deg = np.degrees(np.arccos(np.clip(cos_theta, -1, 1)))
```

#### `np.arccos(x)` —— 反余弦

**操作**：给定 $\cos\theta$ 的值，返回角度 $\theta$（弧度）。`np.degrees` 把弧度转成角度。
**输入**：`cos_theta ≈ 0.9822`。
**输出**：`10.80°`——两向量夹角约 10.8°，非常接近同向。
**可调参数**：`np.clip(cos_theta, -1, 1)` 把值夹在 $[-1,1]$ 内——**重要**：由于浮点误差，`cos_theta` 偶尔会算出 `1.0000001`，超出 $\arccos$ 的定义域导致 `NaN`。`clip` 是防 NaN 的保险。
**对应数学**：主线公式 $\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}$。`dot1 / (norm_a * norm_b)` 就是这条公式的直接翻译。

### 步骤 6：叉积——垂直向量的制造

```python
a3 = np.array([1.0, 0.0, 0.0])
b3 = np.array([0.0, 1.0, 0.0])
cross = np.cross(a3, b3)
print("垂直检验:", np.dot(a3, cross), np.dot(b3, cross))
```

#### `np.cross(a, b)` —— 三维叉积

**操作**：计算 $\mathbf{a}\times\mathbf{b}$。这里 `[1,0,0] × [0,1,0] = [0,0,1]`（$x$ 轴叉 $y$ 轴得 $z$ 轴）。
**输入**：两个形状 `(3,)` 的数组。
**输出**：形状 `(3,)` 的数组——同时垂直于 $\mathbf{a}$ 与 $\mathbf{b}$ 的向量。
**可调参数**：`np.cross` 也接受形状 `(..., 3)` 的批量数组（如一批顶点坐标算法向量）；对非 3 维输入会报错——**叉积天生限定在 3 维**。
**对应数学**：主线叉积定义。`np.dot(a3, cross)=0` 与 `np.dot(b3, cross)=0` 是两个"垂直检验"：一个向量与垂直它的向量点积为零——点积为 0 即正交，这正是主线"点积 = 0 ⟺ 垂直"的应用。

## 改个数字试试：把向量推向极端

### 实验 1：垂直向量——点积真的会归零

```python
u = np.array([1.0, 0.0])
v = np.array([0.0, 1.0])
print("u·v =", np.dot(u, v))            # 0.0
```

**输出**：`u·v = 0.0`。垂直的向量点积为 0，这是主线"正交 ⟺ 点积为零"的直接验证。深度学习里"正交性"是热门话题——正交权重、正交初始化、去相关特征，都是想让分量"互不干扰"（点积为 0）。

### 实验 2：反向向量——点积变负

```python
print("u·(-v) =", np.dot(u, -v))        # -0.0 → 实际上是 0，因 u、v 已垂直
print("[1,0]·[-1,0] =", np.dot(np.array([1.,0.]), np.array([-1.,0.])))   # -1.0
```

**输出**：`[1,0]·[-1,0] = -1.0`。方向相反时点积为负。这正是"反向的相似度"——在注意力机制里，负点积对应"不相关/排斥"的关系。

## 边界声明：这套代码能做什么，不能做什么

1. **`*` 与 `@` 是两种完全不同的运算**：`a * b` 逐元素乘（得数组 `[3., 8.]`），`a @ b` 点积/矩阵乘（得标量 `11`）。写错符号是 NumPy 初学者第一大事故源。深度学习框架里同样严格区分——PyTorch 里是 `*` vs `torch.matmul`/`@`。
2. **点积得标量，叉积得向量，二者永不可混**。点积衡量对齐，叉积制造垂直；一个负责"有多像"，一个负责"造新方向"。神经网络只需要前者，几何任务才需要后者。
3. **`np.cross` 只接受三维**。处理二维向量时想算"垂直方向"，得手工构造 $[-v_2, v_1]$。在 §2.4 张量里你会看到，高维深度学习根本没有叉积的位置。
4. **夹角计算要防浮点误差**：`cos_theta` 因舍入可能略超出 $[-1,1]$，务必 `np.clip` 后再 `arccos`，否则得到 `NaN`。这是一类隐蔽 bug——查错时先怀疑数值边界。
