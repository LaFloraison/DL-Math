# 习题：量子神经网络（QNN）

## 第一组：概念检验

### 1.1 QNN 里"量子门作为神经元"是什么意思？为什么说 QNN 的"激活函数"是测量？

**解答**：经典神经元的操作是 $Wx+b$（线性）+ $\sigma$（非线性激活）。QNN 里每个量子神经元的行为是一扇**量子门**——幺正变换 $R_y(\theta)$ 作用在输入量子比特上，保留量子信息（幺正变换不丢失信息）。而"激活函数"的角色由**测量**承担：Born 规则 $P = |\alpha|^2$ 是平方操作（非线性），测量把叠加态压成确定分类概率。所以 QNN 不需要手工设计 sigmoid/ReLU——**"非线性激活"是测量免费赠送的**。

**思路点拨**：两个对比要分清——"门 = 神经元的线性变换（但保信息）"，"测量 = 神经元的非线性激活（Born 规则）"。很多初学者误以为门是激活函数——门是权重那一侧，测量才是激活那一侧。

### 1.2 教材的单比特 QNN 为什么在 $\theta = \pi/2$ 时分不清两个类别？用"赤道盲区"解释。

**解答**：$\theta = \pi/2$ 时，$R_y(\pi/2)$ 把输入 $|0\rangle$ 变成 $|+\rangle$、把输入 $|1\rangle$ 变成 $|-\rangle$——两者都落在 Bloch 球**赤道**上。而赤道上的状态测量 0/1 的概率都是 $\frac12$：$P(0) = (\frac{\sqrt2}{2})^2 = \frac12$，$P(1) = \frac12$，对两个输入完全相同。虽然 $|+\rangle$ 和 $|-\rangle$ 是相位不同的两个状态，但测量概率 $|\alpha|^2$ 只保留振幅大小、抹掉相位——**赤道是"测量盲区"：相位信息在单次测量里读不出来**。

**思路点拨**：要点是"相位不同但概率相同"（§12.2.1 实验 1 的延伸）。$|+\rangle$ 和 $|-\rangle$ 在数学上是不同状态，但在"只测 0/1"的测量下无法区分——这就是为什么 $\theta=\pi/2$ 是失败参数。

### 1.3 参数移位规则为什么是 QNN"可训练"的关键？它和经典反向传播的区别是什么？

**解答**：QNN 由不可逆的幺正门 + 测量组成，无法直接"沿层反向传播"梯度。参数移位规则提供了一条替代路径：对 $R_y(\theta)$ 这类旋转门，梯度精确等于 $[L(\theta+\frac{\pi}{2}) - L(\theta-\frac{\pi}{2})]/2$——只要把参数平移 $\pm\pi/2$、各跑一次前向、相减除以 2。区别：经典反向传播用链式法则在**计算图上**传播梯度（一次反向就能拿到全部参数梯度）；参数移位是**按参数逐个求梯度**（每个参数要两次前向），且梯度依赖测量（在硬件上带噪）。它让 QNN 从"手拧参数"变成"可梯度训练"——2018 年解锁 QNN 训练的关键。

**思路点拨**：对比的核心是"计算图反向传播" vs "参数平移差分"。前者一次全传、后者逐参两次前向。这也是 QNN 训练比经典贵的一个原因。

## 第二组：计算实践

### 2.1 手算：$R_y(\theta)$ 对 $|0\rangle$ 和 $|1\rangle$ 的作用，以及 $\theta=\pi/2$ 与 $\theta=0$ 的测量概率

用 $R_y(\theta) = \begin{bmatrix}\cos\frac{\theta}{2} & -\sin\frac{\theta}{2} \\ \sin\frac{\theta}{2} & \cos\frac{\theta}{2}\end{bmatrix}$ 逐步手算。

**解答**：$R_y(\theta)|0\rangle = \cos\frac{\theta}{2}|0\rangle + \sin\frac{\theta}{2}|1\rangle$；$R_y(\theta)|1\rangle = -\sin\frac{\theta}{2}|0\rangle + \cos\frac{\theta}{2}|1\rangle$。
- $\theta=\pi/2$：$\cos\frac{\pi}{4}=\sin\frac{\pi}{4}=\frac{\sqrt2}{2}$。输入 0 → $P(0)=\frac12, P(1)=\frac12$；输入 1 → $P(0)=\frac12, P(1)=\frac12$。分不清。
- $\theta=0$：$R_y(0)=I$。输入 0 → $P(0)=1, P(1)=0$（类 0）；输入 1 → $P(0)=0, P(1)=1$（类 1）。正确。

```python
import numpy as np
def ry(t):
    return np.array([[np.cos(t/2), -np.sin(t/2)],[np.sin(t/2), np.cos(t/2)]])
def prob(bit, t):
    e = np.array([1.,0.]) if bit==0 else np.array([0.,1.])
    return np.abs(ry(t) @ e)**2
for t in (np.pi/2, 0.0):
    print(f"θ={t:.3f}: 输入0 P={np.round(prob(0,t),4)}, 输入1 P={np.round(prob(1,t),4)}")
```

输出：

```text
θ=1.571: 输入0 P=[0.5 0.5], 输入1 P=[0.5 0.5]
θ=0.000: 输入0 P=[1. 0.], 输入1 P=[0. 1.]
```

**思路点拨**：$R_y(\theta)$ 的作用本质是"按 $\theta$ 把基态旋转"。记牢两行手算结论——这是整节的核心操作。

### 2.2 手算 + 验证：从 $\theta=\pi/2$ 用参数移位做一步梯度下降

手动计算第一步梯度 $g = [L(\frac{\pi}{2}+\frac{\pi}{2}) - L(\frac{\pi}{2}-\frac{\pi}{2})]/2$（$L(\theta) = -(P_0(0)+P_1(1))$），并验证与代码一致。

**解答**：$L(\pi) = -(P_0^{\pi}(0) + P_1^{\pi}(1))$。$\theta=\pi$ 时 $\cos\frac{\pi}{2}=0, \sin\frac{\pi}{2}=1$，$R_y(\pi) = \begin{bmatrix}0&-1\\1&0\end{bmatrix}$。输入 0 → $|1\rangle$，$P_0(0)=0$；输入 1 → $-|0\rangle$，$P_1(1)=0$。$L(\pi) = 0$。$L(0) = -(1+1) = -2$。$g = \frac{L(\pi)-L(0)}{2} = \frac{0-(-2)}{2} = 1$。一步：$\theta' = \frac{\pi}{2} - 0.3 \times 1 = 1.5708 - 0.3 = 1.2708$——与代码 `step 0: θ=1.2708` 完全一致。

**思路点拨**：参数移位规则的计算就是"两次前向 + 平均差"。手算 $\theta=0$ 和 $\theta=\pi$ 两个极端很干净（$L(0)=-2$、$L(\pi)=0$），一步梯度 = 1，推下去就是代码里的训练轨迹。

### 2.3 验证：损失随 θ 的形状

扫描 $\theta \in [0, 2\pi]$，画出/打印 $L(\theta) = -(P_0(0)+P_1(1))$，找到最小值位置，说明梯度下降为什么从 $\pi/2$ 出发能到 0 而不是别处。

```python
import numpy as np
def ry(t): return np.array([[np.cos(t/2), -np.sin(t/2)],[np.sin(t/2), np.cos(t/2)]])
def P0(bit, t):
    e = np.array([1.,0.]) if bit==0 else np.array([0.,1.])
    return np.abs(ry(t) @ e)[0]**2
for t in np.linspace(0, 2*np.pi, 9):
    L = -(P0(0,t) + P0(1,t))
    print(f"θ={t:6.3f}  L={L:+.4f}")
```

输出：

```text
θ= 0.000  L=-2.0000
θ= 0.785  L=-1.7071
θ= 1.571  L=-1.0000
θ= 2.356  L=-0.2929
θ= 3.142  L=-0.0000
θ= 3.927  L=-0.2929
θ= 4.712  L=-1.0000
θ= 5.498  L=-1.7071
θ= 6.283  L=-2.0000
```

**思路点拨**：$L(\theta)$ 在 $\theta=0$ 和 $\theta=2\pi$（同一物理位置）处最小（-2），在 $\theta=\pi$ 处最大（0）。从 $\pi/2$ 出发，梯度为正（$\theta$ 增加则损失增），所以往 $\theta$ 减小的方向走，自然滑向 0。**损失地形的形状决定了梯度下降的路径**——这一点量子与经典毫无差别。

## 第三组：DL 延伸

### 3.1 经典神经元 $y = \sigma(Wx+b)$ 与量子神经元 $R_y(\theta)|b\rangle$ 的结构对应关系是什么？"激活 = 测量"对 QNN 的训练意味着什么？

**解答**：对应关系：权重 $W$ → 角度 $\theta$；偏置 $b$ → （单比特无偏置，多比特线路里有类似角色）；输入 $x$ → 量子态 $|b\rangle$；线性变换 $Wx$ → 幺正变换 $R_y(\theta)$；激活 $\sigma$ → 测量（Born 规则 $P=|\alpha|^2$）；输出 $y$ → 测量概率。对训练的意义：因为激活是测量，QNN 的输出天然是概率（分类任务友好），但梯度必须"测量出来"——用参数移位规则（或多次测量估计），且硬件噪声会污染梯度。**QNN 不是"换了一个激活函数"，是"激活函数变成了物理测量"**——非线性来自平方，随机性来自 Born 规则。

**思路点拨**：把主线那张对照表记熟是本题的基础。加分的点在"训练含义"——激活 = 测量导致梯度依赖测量（参数移位 + 噪声）。

### 3.2 混合量子-经典架构（hybrid quantum-classical）为什么是当前 QNN 的主流？量子端和经典端各干什么？

**解答**：当前 NISQ 硬件不稳、量子比特有限，纯量子训练不可行。混合架构的分工：**量子端**做参数化线路（PQC）——编码输入 + 一串可训练旋转门/纠缠门 + 测量，输出概率（相当于特征变换 + 非线性激活）；**经典端**做优化——计算损失、用参数移位规则（或自动微分接口）求梯度、更新 $\theta$，循环回量子端。经典端还负责数据预处理、编码选择、误差缓解。**它是 §12.4.1 单比特 QNN 的自然放大**——量子做"能做的变换"，经典做"擅长的最优化"，各取所长。PyTorch + Pennylane 的集成就是这一范式的工程落地。

**思路点拨**：核心是"量子算前向、经典算梯度"。为什么不能纯量子？因为测量破坏叠加、硬件带噪、参数移位逐参求梯度在经典端组织更自然。这是理解现代 QNN 论文架构的关键。
