# 代码：一台单比特 QNN——从"90° 分不清"到"梯度下降自己找到 0°"

主线完整走了一遍教材的单比特 QNN：编码 → $R_y(\theta)$ → 测量 → 概率。这一课把这条链路全部写成代码，并多走一步——**用参数移位规则做梯度下降，让网络自己从 $\theta = \pi/2$（分不清）训练到 $\theta \approx 0$（完美分类）**。你将亲眼看到：$\theta=\pi/2$ 时两个输入的概率完全相同（失败），$\theta=0$ 时完美分类（成功），以及训练过程如何自动找到那个角度。

---

## 层一：完整脚本

```python
import sys                               # 让中文 Windows 控制台也能打印 θ、⇒ 等符号
sys.stdout.reconfigure(encoding="utf-8")
import numpy as np                       # 矩阵、三角、随机

def ry(theta):                           # ① 旋转门 Ry(θ)：QNN 的"神经元"
    """绕 y 轴旋转 θ 的量子门：把量子比特在 Bloch 球上转一个角度。"""
    return np.array([[np.cos(theta/2), -np.sin(theta/2)],
                     [np.sin(theta/2),  np.cos(theta/2)]], dtype=complex)

def encode(bit):                         # ② 编码：经典 0/1 → 量子态
    """输入 0 → |0⟩ = [1,0]ᵀ；输入 1 → |1⟩ = [0,1]ᵀ（即 X|0⟩）。"""
    return np.array([1+0j, 0+0j]) if bit == 0 else np.array([0+0j, 1+0j])

def qnn_forward(bit, theta):             # ③ 前向：编码 → 旋转 → 测量概率
    """QNN 前向：Ry(θ) 作用在编码后的量子态上，返回 [P(0), P(1)]。"""
    psi = ry(theta) @ encode(bit)
    return np.abs(psi) ** 2

# ---- ④ 教材 Step 4：θ = π/2 —— 失败 ----
print("θ=π/2:  Input0 P =", np.round(qnn_forward(0, np.pi/2), 4))
print("        Input1 P =", np.round(qnn_forward(1, np.pi/2), 4))
print("  → 两个输入的 P(0),P(1) 完全相同, 无法区分类别!")

# ---- ⑤ 教材 Step 5：θ = 0 —— 成功 ----
print("θ=0:    Input0 P =", qnn_forward(0, 0.0))
print("        Input1 P =", qnn_forward(1, 0.0))
print("  → Input0 高概率 0 ⇒ 类0 (正确); Input1 高概率 1 ⇒ 类1 (正确)")

# ---- ⑥ 训练：参数移位梯度下降, 从 θ=π/2 学到 θ≈0 ----
def loss(theta):                         # 损失: 想让 Input0 的 P(0) 和 Input1 的 P(1) 都大
    return -(qnn_forward(0, theta)[0] + qnn_forward(1, theta)[1])

def param_shift_grad(theta, shift=np.pi/2):   # 参数移位规则: 量子版的"梯度"
    """∂L/∂θ = [L(θ+s) − L(θ−s)] / 2, 不用反向传播。"""
    return (loss(theta + shift) - loss(theta - shift)) / 2.0

theta = np.pi / 2                        # 从失败的角度出发
lr = 0.3
for step in range(12):
    g = param_shift_grad(theta)
    theta = theta - lr * g                # 梯度下降, 和经典神经网络一模一样
    if step in (0, 3, 6, 9, 11):
        p = qnn_forward(0, theta)[0]
        print(f"step {step:2d}: θ={theta:.4f}  loss={loss(theta):+.4f}  P0(0)={p:.3f}")

print(f"训练后 θ = {theta:.4f}  (应收敛到 0)")
c0 = "类0" if qnn_forward(0, theta)[0] > qnn_forward(0, theta)[1] else "类1"
c1 = "类0" if qnn_forward(1, theta)[0] > qnn_forward(1, theta)[1] else "类1"
print(f"分类: Input0 → {c0} (正确), Input1 → {c1} (正确)")
```

运行输出（Python 3.11 + NumPy）：

```text
θ=π/2:  Input0 P = [0.5 0.5]
        Input1 P = [0.5 0.5]
  → 两个输入的 P(0),P(1) 完全相同, 无法区分类别!
θ=0:    Input0 P = [1. 0.]
        Input1 P = [0. 1.]
  → Input0 高概率 0 ⇒ 类0 (正确); Input1 高概率 1 ⇒ 类1 (正确)
step  0: θ=1.2708  loss=-1.2955  P0(0)=0.648
step  3: θ=0.5333  loss=-1.8611  P0(0)=0.931
step  6: θ=0.1895  loss=-1.9821  P0(0)=0.991
step  9: θ=0.0653  loss=-1.9979  P0(0)=0.999
step 11: θ=0.0320  loss=-1.9995  P0(0)=1.000
训练后 θ = 0.0320  (应收敛到 0)
分类: Input0 → 类0 (正确), Input1 → 类1 (正确)
```

从 $\theta = \pi/2$ 出发，12 步梯度下降就把 $\theta$ 推到了 0.032——**网络自己找到了你手动拧到的那个 0°**。下面把每个齿轮拆开。

## 层二：分步逐函数拆解

### 步骤 1：定义 `ry` —— 旋转门，QNN 的神经元

```python
def ry(theta):
    return np.array([[np.cos(theta/2), -np.sin(theta/2)],
                     [np.sin(theta/2),  np.cos(theta/2)]], dtype=complex)
```

#### `ry` —— 绕 y 轴的旋转门

**做什么**：返回 $R_y(\theta)$ 矩阵——主线定义块里那个量子神经元。它把量子态在 Bloch 球上绕 y 轴旋转 $\theta$ 弧度。
**操作**：`np.array` 按公式填 2×2 矩阵；`dtype=complex` 保证复数运算。注意 $-\sin(\theta/2)$ 在右上角、$+\sin(\theta/2)$ 在左下角——这个符号结构是干涉的来源（主线第三节"赤道盲区"的解释）。
**输入**：`theta`，旋转角度（弧度）。
**输出**：形状 `(2, 2)` 的幺正矩阵。
**可调参数**：
- `theta` 是唯一参数，也是**训练对象**——类比经典网络的权重 $W$。$\theta=0$ 是恒等门，$\theta=\pi$ 是"翻转一半"，$\theta=2\pi$ 转一圈回到原状。
- 能不能加参数？真实的参数化线路里有多个旋转门（$R_x, R_y, R_z$）和不同量子比特上的不同角度——但单比特 QNN 只需要一个 $R_y$。
**对应数学**：主线定义块 $R_y(\theta) = \begin{bmatrix}\cos\frac{\theta}{2} & -\sin\frac{\theta}{2} \\ \sin\frac{\theta}{2} & \cos\frac{\theta}{2}\end{bmatrix}$。**这是 QNN 里"权重"的量子形态——一个角度。**

---

### 步骤 2：定义 `encode` —— 编码，输入 0/1 变成量子态

```python
def encode(bit):
    return np.array([1+0j, 0+0j]) if bit == 0 else np.array([0+0j, 1+0j])
```

#### `encode` —— 经典比特 → 基态

**做什么**：把经典输入 0 编码为 $|0\rangle$、输入 1 编码为 $|1\rangle$。教材 Step 1 说 $|1\rangle = X|0\rangle$（Pauli-X 门翻 NOT）——这里直接用 $|1\rangle = [0,1]^T$ 等价实现。
**操作**：条件表达式选向量。
**输入**：`bit`，0 或 1。
**输出**：形状 `(2,)` 的基态向量。
**可调参数**：只接受 0/1。想处理更多输入（如 $[0,1]$ 二维特征）需要更多量子比特和更复杂的编码——那是 §12.4.1 三根支柱里"叠加与并行"的地盘。
**对应数学**：教材 Step 1。$|0\rangle = \begin{bmatrix}1\\0\end{bmatrix}$、$|1\rangle = \begin{bmatrix}0\\1\end{bmatrix}$。

---

### 步骤 3：定义 `qnn_forward` —— 前向：编码 → 旋转 → 测量

```python
def qnn_forward(bit, theta):
    psi = ry(theta) @ encode(bit)
    return np.abs(psi) ** 2
```

#### `qnn_forward` —— QNN 的完整前向传播

**做什么**：一台 QNN 的一次推理——输入经过编码、旋转门作用、测量，输出概率。
**操作**：`ry(theta) @ encode(bit)` 是矩阵乘（门作用在态上）；`np.abs(psi) ** 2` 是 Born 规则（模平方得概率）。
**输入**：`bit`（0/1）、`theta`（角度）。
**输出**：`[P(0), P(1)]`——测量到 0 和 1 的概率。
**可调参数**：无额外参数。真实 QNN 的前向会把这一步放大：多量子比特的叠加编码 + 多层参数化门 + CNOT 纠缠——但"编码 → 旋转 → 测量"的骨架不变。
**对应数学**：主线定义块 $|\psi_{\text{output}}\rangle = R_y(\theta)|b\rangle$、$P(0)=|\alpha|^2$。**"激活函数"就是这里的 `np.abs(psi)**2`——Born 规则的平方非线性。**

---

### 步骤 4：教材 Step 4——θ = π/2 的失败

```python
print("θ=π/2:  Input0 P =", np.round(qnn_forward(0, np.pi/2), 4))
print("        Input1 P =", np.round(qnn_forward(1, np.pi/2), 4))
```

**做什么**：验证教材的"分不清"时刻。`np.round(..., 4)` 格式化显示。
**操作**：把 $\theta = \pi/2$ 代入 `qnn_forward`，对两个输入各跑一次。
**输入**：两个输入（0 和 1），$\theta = \pi/2$。
**输出**：两行都是 `[0.5 0.5]`。
**可调参数**：`np.round` 的第 4 位是显示精度。$\theta=\pi/2$ 是精确的 $\cos^2(\pi/4) = 0.5$，round 后干净。
**对应数学**：主线第三节的推导——输入 0 得 $|+\rangle$、输入 1 得 $|-\rangle$，但 $P(0)=P(1)=\frac12$ 对两者相同。**赤道上不同相位的状态，测量概率完全一样——这就是"测量盲区"。**

---

### 步骤 5：教材 Step 5——θ = 0 的成功

```python
print("θ=0:    Input0 P =", qnn_forward(0, 0.0))
print("        Input1 P =", qnn_forward(1, 0.0))
```

**做什么**：验证教材的"成功"时刻。
**操作**：$\theta = 0$ 时 $R_y(0) = I$（恒等门），输入原样通过。
**输入**：两个输入，$\theta = 0$。
**输出**：Input0 → `[1. 0.]`（$P(0)=1$，判类 0），Input1 → `[0. 1.]`（$P(1)=1$，判类 1）。
**可调参数**：无。这行演示的是"角度 = 0 让输入与测量基对齐"——一种"碰巧正确"的解。
**对应数学**：主线第三节 $\theta=0$ 的推导。$R_y(0) = I$ 保持 $|0\rangle$、$|1\rangle$ 不变，于是 $P(0)=1$、$P(1)=1$ 分别命中两个类别。

---

### 步骤 6：定义 `loss` 与 `param_shift_grad` —— 损失与量子梯度

```python
def loss(theta):
    return -(qnn_forward(0, theta)[0] + qnn_forward(1, theta)[1])

def param_shift_grad(theta, shift=np.pi/2):
    return (loss(theta + shift) - loss(theta - shift)) / 2.0
```

#### `loss` —— QNN 的损失函数

**做什么**：输入 0 时希望 $P(0)$ 大（判类 0），输入 1 时希望 $P(1)$ 大（判类 1）——所以损失定义为两者之和的负数：$L(\theta) = -(P_0(0) + P_1(1))$。$L$ 越小越好，$\theta=0$ 时 $L = -2$ 最小。
**操作**：`qnn_forward(0, theta)[0]` 取输入 0 的 $P(0)$；`qnn_forward(1, theta)[1]` 取输入 1 的 $P(1)$；取负。
**输入**：`theta`。
**输出**：标量损失。
**可调参数**：真实 QNN 常用交叉熵损失——这里用最简损失演示思想。加权重、加正则化都可以，但演示不需要。
**对应数学**：主线第四节。经典网络用 MSE/交叉熵，QNN 用"测量概率"构造损失——**输出是概率，损失作用在概率上**。

#### `param_shift_grad` —— 参数移位规则：不需要反向传播的梯度

**做什么**：计算 $\partial L/\partial \theta$——通过把参数平移 $\pm\frac{\pi}{2}$、各算一次损失、相减除以 2。这是量子线路训练的关键工具（§历史 2018 年解锁训练的那两个公式）。
**操作**：`loss(theta + shift)` 与 `loss(theta - shift)` 各跑一次前向，差除以 `2.0`。
**输入**：`theta`，`shift = np.pi/2`（参数移位规则的固定平移量）。
**输出**：梯度估计（对 $R_y$ 这类旋转门，这是**精确**梯度，不是近似）。
**可调参数**：`shift` 默认为 $\pi/2$——参数移位规则的魔法值。对 $R_y(\theta) = e^{-i\theta Y/2}$，导数等于"平移 $\pi/2$ 后的相位版"，所以 $s=\frac{\pi}{2}$ 给出精确梯度。换成别的值就是有限差分近似（更不精确）。
**对应数学**：主线第四节 $\frac{\partial L}{\partial \theta} = \frac{L(\theta+\frac{\pi}{2}) - L(\theta-\frac{\pi}{2})}{2}$。**这就是"QNN 的梯度是测量出来的"——每个损失值都是一次（理想化的）测量。**

---

### 步骤 7：训练循环——梯度下降自己找到 0°

```python
theta = np.pi / 2
lr = 0.3
for step in range(12):
    g = param_shift_grad(theta)
    theta = theta - lr * g
```

**做什么**：从失败的角度 $\theta = \pi/2$ 出发，做 12 步梯度下降——每步算梯度、沿负梯度方向更新 $\theta$。这和经典神经网络的 `theta -= lr * grad` 完全同构。
**操作**：`theta - lr * g` 沿负梯度更新；`lr = 0.3` 是学习率。
**输入**：$\theta_0 = \pi/2$，`lr = 0.3`，12 步。
**输出**：$\theta$ 从 1.5708 → 0.0320，`loss` 从 -1.30 → -2.00（最小），`P0(0)` 从 0.648 → 1.000。
**可调参数**：
- `lr`：学习率。调大（如 1.0）收敛快但可能震荡；调小（如 0.05）收敛慢但稳。梯度下降的经典权衡，在 QNN 里原样存在。
- `range(12)`：迭代轮数。改成 30，$\theta$ 会收敛到更接近 0；这个玩具问题几轮就够。
- `theta` 初始值：从别的角度出发也能收敛——梯度下降的魅力就是"不用知道答案在哪"。试试 $\theta_0 = 1.2$、$\theta_0 = -0.5$，网络都能找到 0°（或 0° 的等价位置）。
**对应数学**：主线第四节的训练。**教材手拧旋钮找到 0°，参数移位规则让机器自动找到 0°**——这就是"可训练"的全部意义。

### 实验 2：多输入视角——如果只有输入 0 呢？

```python
def loss2(theta):
    return -(qnn_forward(0, theta)[0])     # 只关心输入 0 判对
theta = np.pi/2
for step in range(15):
    g = (loss2(theta+np.pi/2) - loss2(theta-np.pi/2)) / 2.0
    theta = theta - 0.5*g
print(f"只训练输入0: θ={theta:.4f}, P0(0)={qnn_forward(0,theta)[0]:.3f}")
```

输出：


## 边界声明：这套代码能做什么，不能做什么

1. **这是一台最小的玩具 QNN，不是真实的力量展示。** 1 比特 + 1 门，没有叠加并行、没有纠缠。它的"分类能力"（$\theta=0$）本质上靠"输入恰好与测量基对齐"。**别把本节的成功误读为"QNN 已经超越经典"**——真实 QNN 的力量来自 §12.4.1 三根支柱（多比特叠加、纠缠关联），那需要更多量子比特和更深的线路。
2. **`param_shift_grad` 在理想量子模拟下精确，在真实硬件上带噪。** 参数移位规则假设测量无噪声；真实 NISQ 硬件上，退相干（§12.3.2）会污染每个 `loss(theta±shift)` 的读数，让梯度估计偏移。**QNN 的梯度是"测量出来的"，不是"算出来的"**——硬件越不稳，梯度越不准，这是 QNN 训练比经典难的核心原因。
3. **"测量概率"是期望值，单次测量是随机的。** `qnn_forward` 返回的是精确概率 $|\alpha|^2$（理想化）。真实量子硬件上，你要用多次测量的频率估计概率——测量次数越多越准，但成本越高。**QNN 的输出天然是"概率的估计"，这一层的随机性要始终记在心里。**
