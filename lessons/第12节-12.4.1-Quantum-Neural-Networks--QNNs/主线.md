# 主线：量子神经网络——当"权重"变成一个角度

## 第一步：Toy Model —— 一台只有一个旋钮的分类机

想象一台很简单的机器，它是你的第一个"神经网络"。机器上只有一个旋钮，旋钮刻度用角度 $\theta$ 表示。你要用它做一个极简单的分类任务：**喂给它一个数，它吐出一个概率——告诉你这应该归第 0 类还是第 1 类。**

任务只有两条规则：
- 喂 **0** → 机器应该高概率说"第 0 类"；
- 喂 **1** → 机器应该高概率说"第 1 类"。

你拧旋钮。旋钮拧到某个位置，机器运转起来——但它内部不是算加法和乘法，而是在**旋转**某种东西：它把输入的 0 或 1 变成一个"旋转的硬币"（一个量子比特），旋钮的角度 $\theta$ 决定这枚硬币旋转多少度，最后"按住硬币"（测量），看它落在"正面（类 1）"还是"反面（类 0）"的概率。

你试了一个位置：$\theta = 90^\circ$（$\pi/2$ 弧度）。喂 0，机器吐出"50% 类 0、50% 类 1"；喂 1，机器**也**吐出"50% 类 0、50% 类 1"。两个完全不同的输入，机器给出完全相同的回答——**它分不清 0 和 1。**

你再拧旋钮，试 $\theta = 0$。喂 0，机器吐出"100% 类 0"；喂 1，机器吐出"100% 类 1"。**完美分类。**

现在三个问题浮现了：

1. **为什么 90° 分不清、0° 分得清？** 旋钮角度和"分类能力"之间到底是什么关系？
2. 这台机器不是用权重 $w$ 加权求和，而是用一个**角度** $\theta$ 旋转状态——"权重变角度"意味着什么？
3. 单旋钮机器很弱。真正的"量子神经网络"怎么靠**叠加**（多路并行）和**纠缠**（特征关联）变强？

这三个问题，就是 §12.4.1 的全部。而教材给出的，恰好是这台单旋钮机器的完整说明书——一台"一个量子比特 + 一个旋转门"的量子神经网络（QNN），以及它如何学会分类。

## 第二步：正式数学讲解

### 一、撞墙：神经网络的"权重"，在量子世界里变成了"角度"

经典神经网络的神经元，是这样一个函数：

$$y = \sigma(W x + b)$$

$W$ 是**权重**（实数），$x$ 是输入，$\sigma$ 是激活函数，$y$ 是输出。训练 = 找一组合适的 $W, b$，让 $y$ 逼近目标。

现在把神经元搬到量子世界。输入不再是实数 $x$，而是**量子态** $|\psi\rangle$（量子比特）；"神经元的操作"不再是加权求和，而是**量子门**（一个幺正矩阵，作用在量子态上）；"权重"不再是实数 $W$，而是**门里的角度参数** $\theta$。教材说的第一句话：**"Each quantum neuron acts like a quantum gate, performing operations on input qubits while preserving quantum information."**——每个量子神经元的行为像一扇量子门，对输入量子比特做操作，同时**保留量子信息**（幺正变换不丢失信息）。

这个"权重→角度"的跳跃，是 QNN 的第一个撞墙点。你会困惑：**一个只做旋转的门，怎么可能是神经元？** 旋转只是把量子态在 Bloch 球上转一个角度，它既不做加权、也不做非线性激活——凭什么能分类？答案在后面：分类的能力来自"旋转 + 测量"的组合——旋转改变量子态，测量把它压成一个概率，概率的高低位，就是分类。**QNN 的"激活函数"是测量（Born 规则），不是 sigmoid。**

### 二、量子神经元：一个旋转门 + 一次测量

QNN 的最小单元（教材的二进制分类例子）：

> **量子神经元（quantum neuron）**
>
> 输入：经典比特 $b \in \{0, 1\}$，编码成量子态 $|b\rangle$。
> 参数：角度 $\theta$（类比经典权重 $w$）。
> 操作：旋转门 $R_y(\theta)$ 作用在输入上，再测量。
>
> $$R_y(\theta) = \begin{bmatrix} \cos\frac{\theta}{2} & -\sin\frac{\theta}{2} \\ \sin\frac{\theta}{2} & \cos\frac{\theta}{2} \end{bmatrix}$$
>
> 对输入 $|0\rangle$：$R_y(\theta)|0\rangle = \cos\frac{\theta}{2}|0\rangle + \sin\frac{\theta}{2}|1\rangle$
> 对输入 $|1\rangle$：$R_y(\theta)|1\rangle = -\sin\frac{\theta}{2}|0\rangle + \cos\frac{\theta}{2}|1\rangle$
>
> 测量概率（Born 规则）：$P(0) = |\alpha|^2$，$P(1) = |\beta|^2$。
> 分类规则：$P(0) > P(1)$ 判第 0 类，否则判第 1 类。

注意 $R_y(\theta)$ 的第一列第二行是 $+\sin\frac{\theta}{2}$、第二列第一行是 $-\sin\frac{\theta}{2}$——这个负号藏在矩阵里，是干涉的种子，等一下会让"90° 分不清"显得顺理成章。

### 三、走一遍教材的完整步骤：从编码到失败

**Step 1：编码。** 把经典输入装进量子态。输入 0 编码为 $|0\rangle = \begin{bmatrix}1\\0\end{bmatrix}$；输入 1 编码为 $|1\rangle$，而 $|1\rangle = X|0\rangle$（**Pauli-X 门**，量子 NOT，把 $|0\rangle$ 翻成 $|1\rangle$）：

$$X = \begin{bmatrix}0 & 1 \\ 1 & 0\end{bmatrix}, \qquad |1\rangle = X|0\rangle$$

**Step 2：搭网络。** 一台 QNN = 1 个量子比特（存状态）+ 1 个带可训练参数的量子门 $R_y(\theta)$（充当神经元）。

**Step 3：前向。** 把旋转门作用到输入上：$|\psi_{\text{output}}\rangle = R_y(\theta)|b\rangle$。

**Step 4：测量——θ = π/2 的失败。** 取 $\theta = \frac{\pi}{2}$（教材演示值）。$\cos\frac{\pi}{4} = \sin\frac{\pi}{4} = \frac{\sqrt2}{2}$，于是：

- 输入 0：$R_y(\tfrac{\pi}{2})|0\rangle = \frac{\sqrt2}{2}|0\rangle + \frac{\sqrt2}{2}|1\rangle$，$P(0) = (\frac{\sqrt2}{2})^2 = \frac12$，$P(1) = \frac12$
- 输入 1：$R_y(\tfrac{\pi}{2})|1\rangle = -\frac{\sqrt2}{2}|0\rangle + \frac{\sqrt2}{2}|1\rangle$，$P(0) = \frac12$，$P(1) = \frac12$

**两个输入的概率完全相同（各 $\frac12$），QNN 无法区分两个类别。** 这就是 Toy Model 里"90° 分不清"的数学真相：$\theta = \frac{\pi}{2}$ 把两个输入都转到了赤道上（$|+\rangle$ 和 $|-\rangle$），而赤道上的点在测量 $0/1$ 时概率都是对半——**赤道是"测量盲区"**。看那个负号：$-\frac{\sqrt2}{2}$ 的相位让 $|-\rangle$ 和 $|+\rangle$ 是两个不同的状态，但测量概率把它们抹平了。

**Step 5：找 θ——θ = 0 的成功。** 目标：输入 0 最大化 $P(0)$（判类 0），输入 1 最大化 $P(1)$（判类 1）。试 $\theta = 0$：

$$R_y(0) = \begin{bmatrix}\cos 0 & -\sin 0 \\ \sin 0 & \cos 0\end{bmatrix} = \begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix} = I$$

- 输入 0：$R_y(0)|0\rangle = |0\rangle$：$P(0) = 1$，$P(1) = 0$ → **高概率类 0（正确）**
- 输入 1：$R_y(0)|1\rangle = |1\rangle$：$P(0) = 0$，$P(1) = 1$ → **高概率类 1（正确）**

$\theta = 0$ 就是恒等门——它不旋转，让输入原样通过，于是 $|0\rangle$ 保持 $|0\rangle$（类 0）、$|1\rangle$ 保持 $|1\rangle$（类 1）。**分类成功。** 教材的结论：$P(0)$ 高 ⇒ 类 0，$P(1)$ 高 ⇒ 类 1，两者都正确。

### 四、训练：怎么找到那个对的角度？

教材直接试出了 $\theta = 0$。但真实的 QNN 不能靠试——它要像经典网络一样，用**梯度下降**自动找 $\theta$。

QNN 的"损失"定义和经典类似：输入 0 时我们希望 $P(0)$ 大、输入 1 时我们希望 $P(1)$ 大。可以定义损失 $L(\theta) = -(P_0(0) + P_1(1))$（$P_0(0)$ 是输入 0 的 $P(0)$，$P_1(1)$ 是输入 1 的 $P(1)$）——$L$ 越小越好，$\theta = 0$ 时 $L = -2$ 最小。

梯度怎么算？经典网络用反向传播（链式法则）。量子网络用**参数移位规则 (parameter-shift rule)**——一个美丽的事实：对于 $R_y(\theta)$ 这种旋转门，梯度可以精确地写成"两个平移点的差"：

$$\frac{\partial L}{\partial \theta} = \frac{L(\theta + \frac{\pi}{2}) - L(\theta - \frac{\pi}{2})}{2}$$

**不需要反向传播，不需要拆开量子线路——只要把参数平移 $\pm\frac{\pi}{2}$、各跑一次前向、相减除以 2。** 这是因为 $R_y(\theta)$ 的导数是它自己的平移（$\frac{d}{d\theta}R_y(\theta) = R_y(\theta + \frac{\pi}{2})$ 的一个相位版本）。从 $\theta = \frac{\pi}{2}$ 出发，梯度为正（损失随 $\theta$ 增大而增大，所以应减小 $\theta$），梯度下降把 $\theta$ 一路推向 0——**QNN 自己"学会"了 Toy Model 里你手动拧到 0° 的那个位置。** 《代码.md》会完整演示这个过程。

### 五、三根支柱，三种力量：从单比特到真 QNN

单旋钮机器太弱了——它只有 1 个量子比特、1 个角度，只能做玩具分类。教材告诉我们，真正的 QNN 靠三根支柱获得力量：

1. **量子门作为神经元 (Quantum Gates as Neurons)**：每个量子神经元是一扇幺正门，保留量子信息地变换输入。这是"神经元"的量子形态。
2. **叠加与并行 (Superposition and Parallelism)**：叠加让量子神经元一次处理多个计算——$n$ 个量子比特同时在场 $2^n$ 个状态（§12.2.2），网络不用逐一遍历输入，而是让它们"同时被处理"。这是 QNN 的"并行引擎"。
3. **纠缠做特征关联 (Entanglement for Feature Correlation)**：纠缠把量子神经元"拴"成整体（§12.2.3），让网络能检测和关联复杂的跨特征模式——"helping QNNs detect and relate complex data patterns more effectively than classical networks"。经典网络要靠很多层、很多权重去逼近"特征之间的联合结构"，纠缠把这个结构直接内建在量子态里。

### 六、边界声明：单比特 QNN 只是一个旋转，力量在别处

必须诚实划两条边界：

- **本节的 QNN 是最小的玩具**：1 比特 + 1 门，它等价于"根据 $\theta$ 决定是否翻转输入"——没有任何并行、没有纠缠。它的分类能力（$\theta=0$ 时）不过是因为输入 $\{0,1\}$ 恰好与测量基对齐。**它演示的是"量子神经元"的概念，不是 QNN 的力量。** 真正的力量来自 §12.4.1 三根支柱的组合：多比特的叠加（同时处理多路输入）与纠缠（跨特征关联）——那需要更多量子比特、更深的参数化线路。
- **测量的随机性必须统计处理**：QNN 的输出是测量概率，单次测量是随机的。训练时要么用期望值（如 $P(0)$ 的精确值），要么多次测量取平均——真实硬件上，测量噪声（§12.3.2 的退相干）会污染这些概率，导致梯度估计偏移。**QNN 的梯度是"测量出来的"，不是"算出来的"**——这让它在 NISQ 硬件上比经典网络更难训练。

## 第三步：DL 桥接

QNN 是本章对深度学习最直接的一次"换装"。经典神经元与量子神经元并排看：

| | 经典神经元 | 量子神经元 |
|---|---|---|
| 单元 | 激活值 $a \in \mathbb{R}$ | 量子比特 $|\psi\rangle$ |
| 参数 | 权重 $W$、偏置 $b$（实数） | 旋转角 $\theta$（$R_y(\theta)$ 门） |
| 变换 | $Wx + b$（线性）+ $\sigma$（非线性） | 幺正变换 $R_y(\theta)$（保持信息） |
| 激活 | sigmoid / ReLU | **测量（Born 规则）** |
| 关联 | 权重矩阵 $W$（逐层局部） | 纠缠（内建于量子态的整体关联） |

**最深的一课在"激活 = 测量"**：经典网络的非线性激活（sigmoid、ReLU）是手工设计的；量子网络的"非线性"来自测量——Born 规则 $P = |\alpha|^2$ 本身是非线性的（平方），而测量把叠加压成确定分类。**QNN 的激活函数是量子力学免费赠送的。**

而 §12.3.2 那本"编码 + 读数 + 噪声"的账，在 QNN 这里同样适用：把经典输入编码成量子态要收费；输出是概率、要统计处理；NISQ 硬件的退相干污染梯度。所以今天真正在跑的 QNN 大多是**混合量子-经典 (hybrid quantum-classical)** 架构——量子端做参数化线路（特征变换）、经典端做优化（梯度下降）、两者循环协作。教材用一台单比特 QNN 教给你的，正是这个混合范式的最小原型：**你手拧旋钮（或梯度下降自动拧），机器旋转、测量、报概率——量子与经典的第一次握手，就是这个样子。**
