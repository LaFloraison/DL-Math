# 代码：贝叶斯神经网络 (BNN)——把图 4.11 的那条带子亲手造出来

主线里我们建立了两个公式：后验 $P(w\mid D)\propto P(D\mid w)P(w)$，和预测分布 $P(y^*\mid x^*,D)=\int P(y^*\mid x^*,w)P(w\mid D)\,dw$，并声明"真实深度网络上这两个积分算不出来"。那有没有能算出来的地方，让我们**亲眼看看这条带子是从哪来的**？

有——**线性模型**。高斯先验 × 高斯似然 → 后验仍是高斯，积分有闭式解。本课用线性回归搭一个教材图 4.11 的迷你版：

1. **灰点**：多项式 + 噪声的合成数据；
2. **红线（传统 NN）**：最小二乘钉死一组权重，每个输入只给一个点；
3. **蓝线（BNN 均值）+ 浅蓝带（不确定度）**：贝叶斯后验给出的均值与方差。

## 层一：完整脚本

```python
import numpy as np

# ---- ① 生成合成数据：多项式 + 噪声（图中灰点） ----
np.random.seed(42)
x = np.concatenate([np.random.uniform(-1.2, 1.2, 24),   # 数据密集在中间
                    np.random.uniform(-3, -1.2, 3),     # 左端数据稀疏
                    np.random.uniform(1.2, 3, 3)])      # 右端数据稀疏
y = 0.9*x - 0.2*x**2 + np.random.normal(0, 0.3, len(x))

def design(X, deg=2):
    return np.vander(X, deg + 1, increasing=True)       # 设计矩阵 [1, x, x²]

# ---- ② 传统 NN（单点估计）：最小二乘，钉死一组权重 ----
X = design(x)
w_ols = np.linalg.solve(X.T @ X, X.T @ y)               # 图中红虚线：只给一个答案

# ---- ③ BNN：高斯先验 + 高斯似然 → 后验仍是高斯（闭式解） ----
sig_n, sig_p = 0.3, 1.5                                 # 观测噪声 σ / 先验 σ₀
S_N = np.linalg.inv(X.T @ X / sig_n**2 + np.eye(3) / sig_p**2)
w_N = S_N @ (X.T @ y) / sig_n**2                        # 后验均值（一片云的中心）

# ---- ④ 预测分布：BNN 均值 + 不确定度带（图中蓝线 + 浅蓝阴影） ----
xs = np.linspace(-3, 3, 101)
Xs = design(xs)
y_trad = Xs @ w_ols                                     # 传统 NN 单点预测
y_mean = Xs @ w_N                                       # BNN 预测均值
y_var = sig_n**2 + np.sum((Xs @ S_N) * Xs, axis=1)      # 预测方差（含观测噪声）
y_std = np.sqrt(np.clip(y_var, 0, None))                # 带的半宽

# ---- ⑤ 从后验采样：多组权重 → 多条候选预测 → 输出分布 ----
W_samp = np.random.multivariate_normal(w_N, S_N, size=200)  # 抽 200 组权重
Y_samp = Xs @ W_samp.T                                  # 200 条候选预测线

print("传统NN权重 w_ols =", np.round(w_ols, 3), "   # 单点，没有不确定度")
print("BNN 后验均值 w_N =", np.round(w_N, 3), "    # 一片云的中心")
i0 = int(np.argmin(np.abs(xs)))                        # 定位 x=0
i2 = int(np.argmin(np.abs(xs - 2.5)))                  # 定位 x=2.5
print(f"预测带 x=0（数据密集）   : ±{y_std[i0]:.3f}")
print(f"预测带 x=2.5（数据稀疏） : ±{y_std[i2]:.3f}")
print("后验采样 200 组权重 →", Y_samp.shape, "条候选预测线 → 每个 x 处一个分布")
```

运行输出（Python 3.13 + NumPy 2.3）：

```text
传统NN权重 w_ols = [-0.096  0.901 -0.166]    # 单点，没有不确定度
BNN 后验均值 w_N = [-0.096  0.9   -0.166]     # 一片云的中心
预测带 x=0（数据密集）   : ±0.307
预测带 x=2.5（数据稀疏） : ±0.376
后验采样 200 组权重 → (101, 200) 条候选预测线 → 每个 x 处一个分布
```

第一段：传统 NN 与 BNN 的**均值几乎一样**（都贴着数据真值 $0.9x-0.2x^2$）——贝叶斯不是让你换一条更好的线，而是**给同一条线配上一条带子**。第二段：**数据密集处（$x=0$）带窄（±0.307），数据稀疏处（$x=2.5$）带张（±0.376）**——带子不是画上去的装饰，是数据密度照出来的影子。第三段：从后验抽 200 组权重，200 条候选线叠起来，每个 $x$ 处摊开成一个分布——这就是 MC 近似的现场。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：生成合成数据

```python
np.random.seed(42)
x = np.concatenate([np.random.uniform(-1.2, 1.2, 24),
                    np.random.uniform(-3, -1.2, 3),
                    np.random.uniform(1.2, 3, 3)])
y = 0.9*x - 0.2*x**2 + np.random.normal(0, 0.3, len(x))
```

**做什么**：造出图 4.11 里的灰点——一条二次曲线 $y=0.9x-0.2x^2$ 加上噪声。故意让数据**中间密、两端稀**，这样"带子在数据稀疏处张开"的效果一眼可见。

#### `np.random.seed(42)` —— 固定随机种子

**操作**：把随机数发生器的状态重置为 42。
**可调参数**：`42` 可以换成任何整数——换一个数，数据点换一批，但"数据密集处带窄"的结论不变。不设种子，每次运行数据都不同。
**对应数学**：保证实验可复现——后验是数据的函数，数据变了后验就变。

#### `np.random.uniform(low, high, size)` —— 均匀采样

**做什么**：在区间 `[low, high]` 内独立均匀地抽 `size` 个数。
**输入**：`(-1.2, 1.2, 24)`——左边 24 个点集中在 $[-1.2,1.2]$；`(-3, -1.2, 3)` 和 `(1.2, 3, 3)`——两端各只有 3 个点。三段拼成整个 $[-3,3]$。
**输出**：一维数组，长度分别为 24 / 3 / 3。
**可调参数**：第三个数字是采样数量——把 `24` 改成 `24, 40` 只加中段密度；也可以不用 `np.concatenate`，直接 `np.random.uniform(-3, 3, 30)` 均匀撒点，但那样"稀疏处带宽"就不明显了。
**对应数学**：观测位置（自变量）的分布——数据密度决定认知不确定度 (epistemic uncertainty) 的收缩快慢。

#### `np.concatenate([a, b, c])` —— 沿默认轴拼接数组

**做什么**：把三段一维数组首尾相接成一根长数组。
**输入**：三个一维数组（列表里）。
**输出**：一个长度为 $24+3+3=30$ 的一维数组。

#### `np.random.normal(loc, scale, size)` —— 高斯噪声

**做什么**：从均值 `loc`、标准差 `scale` 的高斯分布抽 `size` 个噪声。
**输入**：`(0, 0.3, len(x))`——噪声中心 0、标准差 0.3、数量跟 `x` 一样多（30 个）。
**可调参数**：`0.3` 是观测噪声强度——调大到 `0.8`，数据更"毛躁"，带的**噪声部分**（偶然不确定度 aleatoric）也变宽，但"稀疏处更宽"的趋势仍在。
**对应数学**：观测噪声 $\sigma$——预测分布里那一个独立的 $\sigma^2$ 项，就是它。

### 步骤 2：传统 NN 单点估计

```python
def design(X, deg=2):
    return np.vander(X, deg + 1, increasing=True)

X = design(x)
w_ols = np.linalg.solve(X.T @ X, X.T @ y)
```

**做什么**：用普通最小二乘钉死一组权重——这就是"传统神经网络"的替身（图 4.11 里那条红虚线，教材说它用多项式回归当传统 NN 的代理）。

#### `design(X, deg=2)` —— 造设计矩阵

**做什么**：把自变量 $X$ 的每个值展开成多项式特征 $[1, x, x^2]$。
**操作**：`np.vander(X, deg+1, increasing=True)` 生成范德蒙德矩阵——第 $j$ 列是 $x^{j}$，`increasing=True` 让幂次从低到高排（第 0 列全 1，第 1 列是 $x$，第 2 列是 $x^2$）。
**输入**：`X`（一维数组 $(30,)$）、`deg=2`。
**输出**：设计矩阵，形状 $(30, 3)$——行对应数据点，列对应多项式系数 $[w_0, w_1, w_2]$。
**可调参数**：`deg` 可改成 `3`、`5`——次数越高拟合能力越强，但权重数变多、后验协方差变大、带子也更容易张开（过拟合的贝叶斯镜像）。**要不要第三个参数**：`np.vander` 本身只收两个核心参数；想控制更高阶就直接改 `deg`。
**对应数学**：特征映射 $\phi(x)=[1,x,x^2]^\top$——把"输入→输出"的映射问题变成"线性回归于特征"的问题，这样后验才有闭式解。

#### `np.linalg.solve(A, b)` —— 解线性方程组

**做什么**：解 $Aw=b$，这里解的是最小二乘正规方程 $(X^\top X)w = X^\top y$。
**输入**：`A = X.T @ X`（$(3,3)$ 格拉姆矩阵）、`b = X.T @ y`（$(3,)$）。
**输出**：`w_ols`，形状 $(3,)$——三个系数 $[w_0, w_1, w_2]$，一组**固定的数**。
**可调参数**：`X.T @ X` 里没有可调参数——但换成 `np.linalg.lstsq` 也能得到同一个解（数值更稳）。
**对应数学**：无先验（等价于均匀先验）的 MAP 估计——**单点权重的源头**，也是贝叶斯视角下"最弱先验"的后验峰值。

### 步骤 3：BNN 后验（闭式解）

```python
sig_n, sig_p = 0.3, 1.5
S_N = np.linalg.inv(X.T @ X / sig_n**2 + np.eye(3) / sig_p**2)
w_N = S_N @ (X.T @ y) / sig_n**2
```

**做什么**：这是本课的心脏——把"一片权重云"用解析公式算出来。高斯似然 $y\mid x,w\sim\mathcal{N}(w^\top\phi(x),\sigma_n^2)$ 配高斯先验 $w\sim\mathcal{N}(0,\sigma_p^2 I)$，后验仍是高斯：$w\mid D\sim\mathcal{N}(w_N, S_N)$，其中

$$S_N=\left(\frac{1}{\sigma_n^2}X^\top X + \frac{1}{\sigma_p^2}I\right)^{-1}, \qquad w_N=\frac{1}{\sigma_n^2}S_N X^\top y$$

#### `np.eye(3)` —— 单位矩阵

**做什么**：生成 $3\times3$ 单位阵，把先验精度放在对角线上——相当于给每个权重一个独立的先验方差 $\sigma_p^2$。
**输入**：`3` = 权重个数（与 `X` 的列数一致）。
**输出**：$(3,3)$ 对角全 1 的矩阵。
**可调参数**：`3` 必须等于权重数——`deg=3` 时就要 `np.eye(4)`，忘了改会直接报维度错误。

#### `np.linalg.inv(M)` —— 矩阵求逆

**操作**：对括号里那个 $3\times3$ 对称矩阵求逆，得到后验协方差 $S_N$。
**对应数学**：后验协方差的闭式解——**这个矩阵的非零之处，就是"权重云"的形状**。`X.T @ X / sig_n**2` 是数据的贡献（越多数据贡献越大），`np.eye(3) / sig_p**2` 是先验的贡献（$\sigma_p$ 越小先验越强、越把云压向零）。

#### `w_N = S_N @ (X.T @ y) / sig_n**2` —— 后验均值

**操作**：后验协方差 $S_N$ 乘上数据加权和 $X^\top y$，再除以噪声方差，得到后验均值向量。
**输出**：`w_N`，形状 $(3,)$——与 `w_ols` 几乎一样（弱先验让数据说了算），但它的身份变了：**它是"一片云"的中心，不是一个唯一的答案**。
**对应数学**：贝叶斯定理在"共轭高斯"情形下的落地——$\propto P(D\mid w)P(w)$ 的两个高斯相乘，还是一个高斯，只是均值和方差被更新了。

---

### 步骤 4：预测分布（均值 + 带子）

```python
xs = np.linspace(-3, 3, 101)
Xs = design(xs)
y_trad = Xs @ w_ols
y_mean = Xs @ w_N
y_var = sig_n**2 + np.sum((Xs @ S_N) * Xs, axis=1)
y_std = np.sqrt(np.clip(y_var, 0, None))
```

**做什么**：沿整条 $x$ 轴算出——传统 NN 的单点线、BNN 的均值线、以及每个位置的不确定度带。

#### `np.linspace(-3, 3, 101)` —— 生成网格

**输入**：`(-3, 3, 101)`——起点、终点、点数。
**输出**：101 个从 -3 到 3 均匀取的点。
**可调参数**：`101` 是曲线的分辨率——改成 `1001` 曲线更光滑，改成 `11` 就只有 11 个采样点（太粗）。**要不要更多参数**：可以传 `endpoint=False` 去掉右端点，一般用不到。

#### `np.sum((Xs @ S_N) * Xs, axis=1)` —— 二次型 $\phi(x)^\top S_N\, \phi(x)$

**操作**：`Xs @ S_N` 是 $(101,3)\times(3,3)=(101,3)$；与 `Xs` 逐元素相乘后按 `axis=1`（每一行）求和，得到 101 个标量——正是 $\phi(x_i)^\top S_N\,\phi(x_i)$。
**输出**：形状 $(101,)$ 的一维数组，每个位置是"该点的函数方差"（权重云被投影到 $x$ 处后的晃动程度）。
**可调参数**：`axis=1` 不能动（按行求和），但括号里可以换成 `np.einsum('ij,jk,ik->i', Xs, S_N, Xs)`——同一个二次型，写法不同。

#### `y_var = sig_n**2 + ...` —— 预测方差

**做什么**：在函数方差上**加回观测噪声方差** $\sigma_n^2$——预测分布 $P(y^*\mid x^*,D)$ 的方差有两部分：函数不确定度 + 噪声。`np.clip(y_var, 0, None)` 保证不出现负方差（数值误差兜底），`np.sqrt` 得到标准差，即"带的半宽"。
**对应数学**：$y^*$ 的方差 $=\sigma_n^2 + \phi(x^*)^\top S_N\,\phi(x^*)$——前半是偶然不确定度（数据噪声），后半是认知不确定度（模型没见过的区域）。**这就是图 4.11 浅蓝带的精确来历。**

---

### 步骤 5：从后验采样，把"积分"换成"求和"

```python
W_samp = np.random.multivariate_normal(w_N, S_N, size=200)
Y_samp = Xs @ W_samp.T
```

#### `np.random.multivariate_normal(mean, cov, size)` —— 从多元高斯采样

**做什么**：从后验 $\mathcal{N}(w_N, S_N)$ 抽出 200 组"可能的权重"——**每抽一次，就是去一个"可能的世界"看一眼**。
**输入**：`w_N`（$(3,)$ 均值）、`S_N`（$(3,3)$ 协方差）、`size=200`（采样数）。
**输出**：`W_samp`，形状 $(200, 3)$——200 行，每行是一组候选权重 $w_t$。
**可调参数**：`size` 就是主线里的 $T$——越大，MC 近似越贴近那个"不可行的积分"（验证见《习题.md》第 5 题）；但内存和计算线性上涨。

#### `Y_samp = Xs @ W_samp.T` —— 200 条候选预测线

**操作**：$(101,3)\times(3,200)\to(101,200)$——每条候选权重 $w_t$ 与设计矩阵相乘，得到 200 条预测线。
**输出**：`(101, 200)` 矩阵——**第 $t$ 列就是"第 $t$ 个世界对 101 个 $x$ 的预测"**。每行（固定一个 $x$）的 200 个数值摊开，就是那个 $x$ 处的输出分布。
**对应数学**：预测分布的 MC 近似 $P(y^*\mid x^*,D)\approx\frac{1}{T}\sum_t P(y^*\mid x^*,w_t)$——均值和方差（步骤 4 的解析结果）就是这 200 条线在每处的平均与散布。

## 改个数字试试：带子听谁的？

### 实验一：数据量从 30 → 200，带子怎么缩

```python
np.random.seed(7)
x2 = np.random.uniform(-3, 3, 200)                     # 200 个数据点
y2 = 0.9*x2 - 0.2*x2**2 + np.random.normal(0, 0.3, 200)
X2 = design(x2)
S2 = np.linalg.inv(X2.T @ X2 / sig_n**2 + np.eye(3) / sig_p**2)
w2 = S2 @ (X2.T @ y2) / sig_n**2
var2 = sig_n**2 + np.sum((Xs @ S2) * Xs, axis=1)
print(f"n=30 : 带@x=0=±{y_std[i0]:.3f}  @x=2.5=±{y_std[i2]:.3f}")
print(f"n=200: 带@x=0=±{np.sqrt(var2[i0]):.3f}  @x=2.5=±{np.sqrt(var2[i2]):.3f}")
```

输出：

```text
n=30 : 带@x=0=±0.307  @x=2.5=±0.376
n=200: 带@x=0=±0.302  @x=2.5=±0.304
```

数据从 30 涨到 200：**带子整体收窄，而且"稀疏处（2.5）与密集处（0）的差距"被抹平**——数据把认知不确定度压下去了。这正是教材说的数据效率：**BNN 用更少的数据做更诚实的估计，数据越多带子越诚实。**

### 实验二：先验强度 $\sigma_p$ 从 0.3 → 100

```python
for sig_p2 in (0.3, 1.5, 100.0):
    SN = np.linalg.inv(X.T @ X / sig_n**2 + np.eye(3) / sig_p2**2)
    wN = SN @ (X.T @ y) / sig_n**2
    print(f"σ_p={sig_p2:>6}: 斜率权重 w_N[1]={wN[1]:+.3f}   # 越小=越强=越被拉向 0")
```

输出：

```text
σ_p=  0.3: 斜率权重 w_N[1]=+0.877   # 越小=越强=越被拉向 0
σ_p=  1.5: 斜率权重 w_N[1]=+0.900
σ_p=100.0: 斜率权重 w_N[1]=+0.901
```

先验从强到弱，斜率权重从 0.877 爬回 0.901（真值 0.9）——**强先验把权重拉向 0**。这就是"先验 = 正则化"在本课现场：先验 $\sigma_p$ 越小，后验越不敢离零太远。教材说的"先验惩罚偏离零太远的权重，如同 L1/L2 正则化"，被这一个数字之差钉在屏幕上。

## 边界声明：这套代码能做什么，不能做什么

1. **这里能做"精确"积分，只因为它是一条直线。** 本课所有闭式解都依赖"线性特征 + 高斯先验 + 高斯似然"的共轭结构。**换成真实的深度网络（非线性、百万权重），后验 $P(w\mid D)$ 和预测分布都没有闭式解**——那两个积分公式只存在于黑板和教科书上。真实 BNN 必须走变分推断或采样，而它们都是**近似**：变分近似会偏差（$q$ 族选窄了、选偏了，后验就跟着偏），采样近似有噪声（$T$ 有限，均值就抖）。
2. **带子不全是"模型不确定"。** `y_var` 里那个独立的 $\sigma_n^2$（噪声）是偶然不确定度，加再多数据也消不掉；能随数据收缩的只有 $\phi^\top S_N\phi$（认知部分）。**别把带子的全部宽度都归功于"贝叶斯的智能"**——其中一部分只是世界本身的噪声。
3. **这条带子不能保证真值落进去。** 它编码的是**模型的信念**。先验选错了、似然设定错了（比如噪声其实不是高斯），后验再"精确"也是精确地错。贝叶斯给你的是"在假设之下的最优"，不是"绝对的正确"。
4. **这只是回归 toy。** 分类的 BNN（权重是分布、输出是概率分布而非一条带）、深度 BNN（变分参数翻倍）在本课只是概念——它们的数学骨架与这里完全一致（后验 → 预测分布 → MC/变分近似），但工程细节远超一个脚本。
