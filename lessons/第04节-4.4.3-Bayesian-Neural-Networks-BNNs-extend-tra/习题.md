# 习题：贝叶斯神经网络 (BNN)

## 第一组：概念检验

**1. 传统神经网络与贝叶斯神经网络在"输出"上的本质区别是什么？为什么这个区别在医学诊断里是生死攸关的？**

**解答**：传统 NN 对每个输入只输出**一个单点估计**——一组权重被钉死，前向传播给出唯一的答案（如"85% 肺炎"）。BNN 让权重服从后验分布 $P(w\mid D)$，对每个输入输出**一个分布**——对同样的输入，一组"可能的世界"各给一个答案，摊开成一团（如"80%~88% 之间，峰值 85%"）。在医学诊断里，医生需要知道"这个判断有多可信"：病灶清晰、数据密集处，带子窄，诊断可以果断；病灶模糊、罕见病例处，带子宽，说明模型没有依据去自信——**单点估计把这种关键信号压缩成了一个数字**，而"量化诊断决策的信心"正是教材点名 BNN 在医学中的价值。

**思路点拨**：若有人答"区别是 BNN 更准"，方向错了——BNN 的主要卖点不是精度，而是**不确定性量化**（均值往往与传统 NN 几乎相同，见代码输出）。"更准"是数据效率的副产品，不是定义本身。

**2. 写出 BNN 的核心公式：后验 $P(w\mid D)$ 和预测分布 $P(y^*\mid x^*,D)$。并解释：为什么在真实深度网络上这两个公式"对但算不出"？**

**解答**：

$$P(w\mid D)=\frac{P(D\mid w)P(w)}{P(D)}\propto P(D\mid w)P(w), \qquad P(y^*\mid x^*,D)=\int P(y^*\mid x^*,w)P(w\mid D)\,dw$$

算不出的原因：$P(D)=\int P(D\mid w)P(w)\,dw$ 是对**所有权重配置**的积分，而深度网络的权重有百万个——这个积分在计算上不可行；预测分布又是权重空间上的第二个积分。所以真实 BNN 必须用**变分推断**（选一个分布族 $q(w;\theta)$，最小化它与后验的 KL 散度）或**蒙特卡洛采样**（$w_t\sim P(w\mid D)$，$\frac{1}{T}\sum_t$ 近似积分）——**两者都是近似，不是精确解**。

**思路点拨**：若有人答"因为数据不够多"——不，无关数据量，是**权重维度爆炸**让积分不可行；即使数据无限多，那俩积分照样算不出来（变分/采样照样是近似）。

**3. 判断题并说明理由："BNN 的预测带宽度只由模型对数据的不确定决定，数据越多带子越窄、最终能窄到消失。"**

**解答**：错误。预测方差分两层（见代码 `y_var = sig_n**2 + ...`）：**偶然不确定度 (aleatoric)** $\sigma_n^2$ 来自观测噪声本身，加再多数据也消不掉；**认知不确定度 (epistemic)** $\phi^\top S_N\phi$ 来自"模型没见过的区域"，数据增多会收缩，但最终收敛到 $\sigma_n^2$ 而不会消失。数据稀疏处（如 $x=\pm3$）带子最宽；数据极多时带子窄到"只剩下世界的噪声"。

**思路点拨**：若有人答"能窄到消失"，是把"模型不确定"和"世界不确定"混为一谈——**带子永远至少等于世界的噪声宽度**。

## 第二组：计算实践

**4. 手算 + 代码验证。** 在《代码.md》的数据上（$X$ 为 $(30,3)$ 设计矩阵，$\sigma_n=0.3$，先验 $\sigma_p=1.5$）：
（a）推导 $\sigma_p\to\infty$ 时后验均值 $w_N$ 的极限；
（b）用 $\sigma_p=0.3,\ 1.5,\ 10^6$ 分别计算 $w_N$ 与 $w_{\text{ols}}$ 的距离，验证你的推导，并解释先验强度如何充当正则化。

**解答**：
（a）后验均值与协方差为

$$S_N=\left(\frac{1}{\sigma_n^2}X^\top X+\frac{1}{\sigma_p^2}I\right)^{-1},\qquad w_N=\frac{1}{\sigma_n^2}S_N X^\top y$$

当 $\sigma_p\to\infty$ 时 $\frac{1}{\sigma_p^2}I\to 0$，于是 $S_N\to\sigma_n^2(X^\top X)^{-1}$，$w_N\to (X^\top X)^{-1}X^\top y=w_{\text{ols}}$——**先验消失，后验均值退化为最小二乘解**（均匀先验的 MAP）。
（b）验证代码：

```python
import numpy as np
np.random.seed(42)
x = np.concatenate([np.random.uniform(-1.2,1.2,24),
                    np.random.uniform(-3,-1.2,3),
                    np.random.uniform(1.2,3,3)])
y = 0.9*x - 0.2*x**2 + np.random.normal(0, 0.3, len(x))
X = np.vander(x, 3, increasing=True)
w_ols = np.linalg.solve(X.T @ X, X.T @ y)               # 无先验基线
for sp in (0.3, 1.5, 1e6):                             # 强 → 弱先验
    S = np.linalg.inv(X.T @ X / 0.3**2 + np.eye(3)/sp**2)
    w = S @ (X.T @ y) / 0.3**2
    print(f"σ_p={sp:>6}: w_N={np.round(w,3)}   ||w_N - w_ols||={np.linalg.norm(w-w_ols):.2e}")
```

输出：

```text
σ_p=  0.3: w_N=[-0.095  0.877 -0.167]   ||w_N - w_ols||=2.38e-02
σ_p=  1.5: w_N=[-0.096  0.9   -0.166]   ||w_N - w_ols||=9.76e-04
σ_p=1000000.0: w_N=[-0.096  0.901 -0.166]   ||w_N - w_ols||=2.24e-15
```

$\sigma_p=0.3$（强先验）把斜率从 0.901 拉到 0.877，距离 $2.4\times10^{-2}$；$\sigma_p=10^6$ 时距离是 $2.2\times10^{-15}$——机器精度级别，即**完全重合**。先验强度 = 把权重拉向零的力度 = 正则化强度。

**思路点拨**：若有人答"$\sigma_p$ 越小 $w_N$ 越准"——在真值斜率 0.9 附近强先验反而把权重拉偏了（0.877 比 0.901 更远离真值）。**正则化不是"让权重更准"，是"抑制过拟合、用小权重换泛化"**——数据足够时它拖后腿，数据稀缺时它救命。

**5. 代码验证 MC 近似收敛。** 从后验 $\mathcal{N}(w_N,S_N)$ 采样 $T=200$ 和 $T=5000$ 组权重，对每个 $x$ 计算样本预测的均值，与解析预测均值 $\bar y = X_s w_N$ 比较（均方误差），并报告 $x=1.5$ 处两个均值。

**解答**：MC 把预测分布的积分换成求和：$\frac{1}{T}\sum_{t=1}^T X_s w_t$。验证代码：

```python
import numpy as np
np.random.seed(42)
x = np.concatenate([np.random.uniform(-1.2,1.2,24),
                    np.random.uniform(-3,-1.2,3),
                    np.random.uniform(1.2,3,3)])
y = 0.9*x - 0.2*x**2 + np.random.normal(0, 0.3, len(x))
X = np.vander(x, 3, increasing=True)
sig_n, sig_p = 0.3, 1.5
S_N = np.linalg.inv(X.T @ X / sig_n**2 + np.eye(3)/sig_p**2)
w_N = S_N @ (X.T @ y) / sig_n**2
xs = np.linspace(-3, 3, 101); Xs = np.vander(xs, 3, increasing=True)
anal = Xs @ w_N                                       # 解析预测均值（蓝线）
np.random.seed(0)
for T in (200, 5000):
    Ws = np.random.multivariate_normal(w_N, S_N, size=T)   # 抽 T 组权重
    mc = (Xs @ Ws.T).mean(axis=1)                         # MC 预测均值
    ix = int(np.argmin(np.abs(xs - 1.5)))
    print(f"T={T:>5}: 均方误差={np.mean((mc-anal)**2):.6f}  "
          f"x=1.5处 MC={mc[ix]:.3f} vs 解析={anal[ix]:.3f}")
```

输出：

```text
T=  200: 均方误差=0.000324  x=1.5处 MC=0.885 vs 解析=0.879
T= 5000: 均方误差=0.000007  x=1.5处 MC=0.878 vs 解析=0.879
```

$T=200$ 时 MC 均值有 $3\times10^{-4}$ 的抖动；$T=5000$ 时降到 $7\times10^{-6}$，$x=1.5$ 处 0.878 贴着解析值 0.879——**采样数 $T$ 就是"无穷积分"的近似旋钮**：$T$ 越大越接近闭式解，但代价是 $T$ 倍前向传播。

**思路点拨**：若有人只跑 $T=200$ 就断言 MC 不可靠——MC 的误差以 $\sim1/\sqrt{T}$ 的速度收缩，$T=5000$ 就够用；这正是工程上"$T$ 次前向传播换取不确定性"的底气。也别把"MC 均值接近解析均值"误当成"MC 就是精确"——**接近的是均值，带宽（方差）的估计收敛得更慢**。

**6. 手算 + 代码验证。** 在《代码.md》的数据分布（中间密、两端稀）下，预测带在哪个 $x$ 处最宽？哪个最窄？用解析公式解释原因，并用代码验证带半宽的极值位置。

**解答**：带半宽 $=\sqrt{\sigma_n^2 + \phi(x)^\top S_N\,\phi(x)}$。$\phi(x)^\top S_N\phi(x)$ 是**函数方差**——$x$ 离数据越远，这个二次型越大（认知不确定度越大），因为后验对这儿的函数值了解最少。所以带子在**两端数据稀疏处（$x=\pm3$）最宽**，在**中间数据密集处（$x=0$）最窄**。验证代码：

```python
# 沿用第 5 题的 w_N、S_N、xs、Xs
y_var = sig_n**2 + np.sum((Xs @ S_N) * Xs, axis=1)     # 预测方差
y_std = np.sqrt(np.clip(y_var, 0, None))               # 带半宽
print("最宽处 x =", xs[np.argmax(y_std)], " 半宽 = ±", round(y_std.max(), 3))
print("x=0  处半宽 = ±", round(y_std[int(np.argmin(np.abs(xs)))], 3))
print("x=-3 处半宽 = ±", round(y_std[int(np.argmin(np.abs(xs + 3)))], 3))
```

输出：

```text
最宽处 x = 3.0  半宽 = ±0.431
x=0  处半宽 = ±0.307
x=-3 处半宽 = ±0.408
```

**思路点拨**：若有人答"带子均匀的"——那正是把"噪声部分"当成全部。忽略 $\phi^\top S_N\phi$ 这一项，就会漏掉"数据稀疏处更不确定"这个 BNN 最有用的信号。**这也是教材图 4.11 中"数据边缘带子张开"的精确解释。**

## 第三组：DL 延伸

**7. 医学诊断场景。** 你给一位呼吸科医生部署模型。传统 NN 在某个罕见病例上输出"85% 肺炎"；BNN 在同样输入上给出预测分布：均值 0.85，但带子很宽（0.4~0.97 都有不可忽视的概率）。
（a）用 BNN 的术语，这个"宽带子"对应哪个量？它告诉医生什么？
（b）传统 NN 的"85%"在这个病例上隐瞒了什么？如果医生只按">80% 就治疗"的规则行事，会出什么问题？
（c）如果带子很宽，医生该怎么用这个输出？

**解答**：
（a）宽带子对应预测分布 $P(y^*\mid x^*,D)$ 的大方差——具体说是大的函数方差 $\phi(x^*)^\top S_N\phi(x^*)$（认知不确定度）：这个病例落在模型没见过（或极少见）的输入区域，**模型对"自己该信多少"没有把握**。
（b）"85%"是一个单点估计，**把所有不确定性压缩成一个数字**。它隐瞒了"这个 85% 是建立在大量见过的类似病例上，还是建立在一个几乎空白的区域上"。若医生按"超过 80% 即治疗"行事，在带子宽的病例上，0.85 只是均值，真实概率可能低至 0.4——**按单点做阈值决策，等于把模型的赌博当成事实**。
（c）带子宽时，医生应把决策从"机器说了算"改为"机器提醒、人补证据"：加做检查、咨询会诊、把风险沟通给患者。**BNN 的价值不是给一个更准的数字，而是把"该何时相信机器"这个判断权还给医生**——这正是教材所说"量化诊断决策的信心"。

**思路点拨**：若有人答"带子宽就说明模型错了，应该重训"——不，宽带子不是 bug，是模型在**诚实报告自己的无知**。重训之前该先问：是不是训练数据没覆盖这类病例？**带子是诊断信号，不是故障代码。**

**8. MC-dropout 场景。** 你手上有一个已训练好的、训练时开了 dropout 的神经网络（`p=0.5`）。你想在不重训、不换架构的前提下得到预测的不确定性。
（a）写出 MC-dropout 的做法，并说明它为什么是"从后验附近的采样"。
（b）为什么它比真正训练一个 BNN（如 Bayes by Backprop）便宜？
（c）它会在什么情况下**低估**不确定性？给出一个边界声明。

**解答**：
（a）做法：把模型设为训练模式（dropout 保持开启），对同一个输入 $x^*$ 前向传播 $T$ 次，得到 $T$ 个输出 $\hat{y}_1,\dots,\hat{y}_T$；均值 $\frac{1}{T}\sum_t \hat{y}_t$ 是预测，方差是其不确定性。它的贝叶斯身份（Gal & Ghahramani, 2016）：**随机遮罩把"哪一个神经元被关掉"当成一组隐变量，dropout 的前向传播等价于从这些隐变量的变分分布采样**——每一次前向传播都是一次后验近似采样，$T$ 次就是 MC 积分。
（b）它不增加任何训练成本、不修改任何参数：$T$ 次前向传播是推理阶段的一次性开销，而真正的 BNN 需要让权重参数翻倍（每根权重一套均值 + 方差）并改写训练目标（ELBO/变分损失）。**工程上 $T$ 次前向比一次复杂的变分训练便宜得多。**
（c）边界：MC-dropout 是对后验的一个**特定变分近似**，采样空间局限在"dropout 能表达的不确定性"里。如果模型的架构本身把不确定性藏得很深（如批归一化统计了训练分布），或者 dropout 概率被调得很小，近似会**系统性低估**不确定性；它也不能表达训练数据覆盖范围之外的认知不确定度（那需要先验本身的结构）。**"免费"是有代价的——近似永远可能低估真实的不确定。**

**思路点拨**：若有人答"dropout 只在训练时有用，预测时当然关掉"——这是传统用法；MC-dropout 恰恰反其道而行：**把"预测时关 dropout"这个工程习惯改掉，就免费换来了不确定性**。但若有人把 MC-dropout 当"真正的后验"，要提醒它仍是变分近似，有低估风险——这正是教材"BNN 计算代价大、只能近似"那句话的另一面。
