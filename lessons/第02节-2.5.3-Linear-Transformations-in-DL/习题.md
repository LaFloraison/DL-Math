## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：线性变换必须同时满足 $f(\mathbf{u}+\mathbf{v})=f(\mathbf{u})+f(\mathbf{v})$ 和 $f(c\mathbf{u})=cf(\mathbf{u})$。$\mathbf{W}\mathbf{x}$ 两者都满足。A 的常数项 $+3$ 使 $f(\mathbf{0})=3\ne\mathbf{0}$，是仿射变换；C 的绝对值 $|\cdot|$ 不满足加法保持（$|x+y|\ne|x|+|y|$）；D 的 ReLU 在负区压成 0，同样破坏加法保持。
- **点拨**：有人选 A，是因为初中"一次函数 $y=kx+b$"也叫"线性函数"。但数学上"线性变换"要求**过原点**（$f(\mathbf{0})=\mathbf{0}$），凡带常数项的都不是线性变换——它属于仿射。

**1.2 这句话有两个错误。**
- **思路**：
  1. **名字错了**：$\mathbf{h}=\mathbf{W}\mathbf{x}+\mathbf{b}$ 是仿射变换，不是线性变换（$f(\mathbf{0})=\mathbf{b}\ne\mathbf{0}$）。
  2. **表达能力的推断错了**：即便只堆 $\mathbf{W}\mathbf{x}$ 这种纯线性变换，复合仍是线性变换（$\mathbf{W}_2\mathbf{W}_1\mathbf{x}$），一层矩阵就能吃掉所有层——深度增加不带来任何新表达能力。更一般地，仿射的复合仍是仿射（见 2.3），无激活的堆叠等价于**一层仿射**。
- **点拨**：判断"堆叠是否有用"，关键是看"复合是否产生结构上的新东西"。线性复合不产生新结构，所以必须有非线性打断它。

**1.3 答案：$f(\mathbf{0})=\mathbf{b}$；当且仅当 $\mathbf{b}=\mathbf{0}$；$\mathbf{x}$ 形状 $(2,)$；输入维 $2$，输出维 $3$。**
- **思路**：$f(\mathbf{0})=\mathbf{A}\mathbf{0}+\mathbf{b}=\mathbf{b}$，所以 $\mathbf{b}$ 是"原点的新地址"。$\mathbf{A}$ 是 $n\times m$，则 $\mathbf{x}\in\mathbb{R}^m$（输入维 $m$）、结果 $\in\mathbb{R}^n$（输出维 $n$）。这里 $n=3$、$m=2$。
- **点拨**：矩阵"行数 = 输出维、列数 = 输入维"是全连接层形状判断的万能钥匙——反了必错。

### 第二组

**2.1**
(1) $\mathbf{W}\mathbf{x}_1 = \begin{bmatrix}2\\-1\end{bmatrix}$，$\mathbf{W}\mathbf{x}_2 = \begin{bmatrix}4\\2\end{bmatrix}$，$\mathbf{x}_1+\mathbf{x}_2 = \begin{bmatrix}3\\-1\end{bmatrix}$，$\mathbf{W}(\mathbf{x}_1+\mathbf{x}_2) = \begin{bmatrix}6\\1\end{bmatrix}$。$\mathbf{W}\mathbf{x}_1+\mathbf{W}\mathbf{x}_2 = \begin{bmatrix}2+4\\-1+2\end{bmatrix} = \begin{bmatrix}6\\1\end{bmatrix}$ ✓，加法保持。

(2) $f(\mathbf{x}_1) = \begin{bmatrix}2\\-1\end{bmatrix}+\begin{bmatrix}1\\1\end{bmatrix} = \begin{bmatrix}3\\0\end{bmatrix}$，$f(\mathbf{x}_2) = \begin{bmatrix}4\\2\end{bmatrix}+\begin{bmatrix}1\\1\end{bmatrix} = \begin{bmatrix}5\\3\end{bmatrix}$。$f(\mathbf{x}_1)+f(\mathbf{x}_2) = \begin{bmatrix}8\\3\end{bmatrix}$。而 $f(\mathbf{x}_1+\mathbf{x}_2) = \begin{bmatrix}6\\1\end{bmatrix}+\begin{bmatrix}1\\1\end{bmatrix} = \begin{bmatrix}7\\2\end{bmatrix}$。$\begin{bmatrix}8\\3\end{bmatrix}\ne\begin{bmatrix}7\\2\end{bmatrix}$，加法保持被破坏。

```python
import numpy as np
W = np.array([[2., 0.], [0., -1.]])
b = np.array([1., 1.])
x1, x2 = np.array([1., 1.]), np.array([2., -2.])
print("Wx1+Wx2  ==", W@x1 + W@x2, "  W(x1+x2) ==", W@(x1+x2))
print("f(x1)+f(x2) ==", (W@x1+b) + (W@x2+b))
print("f(x1+x2)    ==", W@(x1+x2) + b)
# W(x1+x2)==Wx1+Wx2 -> True; f(x1)+f(x2)==f(x1+x2) -> False
```

- **点拨**：差的不是"手算失误"，而是结构性差异——两边差一个 $\mathbf{b}$。看到"加偏置后等式不成立"不要怀疑算错，这正是仿射的本质特征。

**2.2**
```python
import numpy as np
rng = np.random.default_rng(0)          # 固定种子，可复现
W = rng.normal(size=(3, 2))
u, v = rng.normal(size=(2,)), rng.normal(size=(2,))
c = 2.5
b = rng.normal(size=(3,))
# 线性公理：应均为 True
print(np.allclose(W @ (u + v), W @ u + W @ v))   # True
print(np.allclose(W @ (c * u), c * (W @ u)))     # True
# 仿射：加法保持被破坏，应为 False
f = lambda z: W @ z + b
print(np.allclose(f(u) + f(v), f(u + v)))        # False
```
- **思路**：`np.allclose` 用容差比较浮点结果，是验证数学恒等式的正确姿势（`==` 会因浮点误差误报）。只要 $\mathbf{b}\ne\mathbf{0}$，第三条恒为 `False`。
- **点拨**：这个实验证明"加偏置破坏线性"不是某个例子的巧合，而是**结构性的、对任意矩阵都成立**。

**2.3**
$$f_2(f_1(\mathbf{x})) = \mathbf{W}_2(\mathbf{W}_1\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2 = (\mathbf{W}_2\mathbf{W}_1)\mathbf{x} + (\mathbf{W}_2\mathbf{b}_1 + \mathbf{b}_2)$$

它仍是仿射变换，等效权重 $\mathbf{W}_2\mathbf{W}_1$、等效偏置 $\mathbf{W}_2\mathbf{b}_1+\mathbf{b}_2$。**结论**：不含激活的任意多层网络，整体等价于一层仿射变换——这就是"深层塌缩"。

```python
import numpy as np
rng = np.random.default_rng(1)
W1, W2 = rng.normal(size=(2,2)), rng.normal(size=(2,2))
b1, b2 = rng.normal(size=(2,)), rng.normal(size=(2,))
x = rng.normal(size=(2,))
left  = W2 @ (W1 @ x + b1) + b2          # 两层直接算
right = (W2 @ W1) @ x + (W2 @ b1 + b2)   # 合并成单层
print(np.allclose(left, right))          # True
```
- **点拨**：`np.allclose` 对随机权重也成立——塌缩是一条**数学定理**，不是特定权重的巧合。这正是为什么工程里每一层仿射后面都必接激活。

### 第三组

**3.1 答案：权重形状 `(512, 784)`，偏置形状 `(512,)`；这一层做的是仿射变换；叠 100 层无激活，整体等价于一层仿射变换。**
- **思路**：行数 = 输出维（512）、列数 = 输入维（784）。因为有 $\mathbf{b}$，是仿射不是线性。由 2.3 的复合公式，任意多层仿射复合仍是仿射，等效为一层。
- **点拨**：有人会答"线性变换"——记住判据：**带 $\mathbf{b}$ 的"线性层"在数学上是仿射变换**。形状陷阱则是把行列写反：`(784, 512)` 会把输入维输出维搞颠倒，`@` 立刻报维度不匹配。

**3.2 思路（至少两条）**
1. **深层塌缩**：去掉激活后，该层与其相邻层都是仿射变换，复合仍是一层仿射。整个网络的深度"名义上没变、实质上被砍掉一层"，表达能力锐减——更极端地，若所有层都去掉激活，整个网络退化为一条直线决策边界（单层感知机），连 XOR 都分不开。
2. **丢失非线性表达能力**：激活函数负责"弯折"决策边界。删掉它，网络只能画超平面（直线/平面），无法拟合曲线、曲面等复杂非线性模式——与教材"线性变换单个建模能力有限"直接呼应。
- **点拨**：工程师发现"训练仍能跑"不奇怪——线性变换一样能降低损失，只是永远学不会真正的非线性结构。要验证是否误删激活，可以打印中间层输出的直方图：如果所有值只在一段区间内线性分布、从无负值被截断的痕迹，就怀疑激活被删了。

## 一个"为什么有人会答错"的提醒

1.1 选 A 的人是掉进了"初中一次函数也叫线性函数"的坑——数学意义的线性变换必须把原点钉住。1.2 是本节最重要的陷阱：**"线性层"名字带"线性"，但它是仿射变换**；且仿射复合仍仿射，所以"堆得越多越强"在无激活时纯属幻觉。2.1(2) 算出的不等式不相等，很多人会反复重算怀疑自己——那不是失误，**差的那一个 $\mathbf{b}$ 就是仿射与线性的分界线**。
