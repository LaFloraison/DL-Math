# 历史：从一台只会画直线的机器，到把直线叠成世界的网络

## 1958 年夏天，康奈尔，一台"会学习"的机器

纽约州伊萨卡，康奈尔航空实验室。一台连着摄像头的机器立在桌子中央，样子笨拙得像个消防栓。它的发明者，心理学家**弗兰克·罗森布拉特（Frank Rosenblatt）**，正兴奋地向记者演示。

规则简单得近乎天真：摄像头的每个像素都乘上一个数字——有的像素被放大，有的被缩小，有的被倒过来算——然后把所有结果加起来，跟一个门槛比一比。超过门槛，机器喊"是"；没超过，喊"不是"。

这就是感知机 (perceptron)。罗森布拉特管它叫"会学习的机器"：每次答错，就自动调一调那些数字，直到答对。媒体沸腾了——《纽约时报》登出头版：*"海军期待电子计算机将能走路、说话、看见、书写、繁殖……"* 罗森布拉特甚至预言，感知机终将学会识别人类。

没有人注意到一件事。这台机器的数学内核，其实是几百年前就存在的旧家具：**每个输入乘一个权重、加总、平移、过一道门槛**——一次"缩放、加总、再整体挪一挪"的操作。它画不出任何弯曲的线。

## 1969 年，那一道岔开两条路的"异或"

罗森布拉特的野心在十年后撞上一堵铁墙。**马文·明斯基（Marvin Minsky）和西摩·帕佩特（Seymour Papert）**合写了一本书，题目温柔——《感知机》。

书里只用了几个小例子，就把感知机打趴下了。最著名的一个叫"异或"：两个开关，要么同时关、要么同时开，机器要答"是"；一个开一个关，要答"不是"。四个点，画在纸上：两个"是"在对角，两个"不是"在对角。

要用一条直线把这两对对角点分开，办不到。可感知机只会画直线——它只有一层，那一层把输入推过去、平移、判门槛，再怎么调权重，输出的边界永远是一条直线。直线分不开四个交叉的对角点。**感知机连这么一道小门都推不开。**

寒冬降临。媒体收回了预言，经费撤走了，神经网络的研究沉睡了将近二十年。教训刻在每一个后来者心里：**单层的"缩放、加总、平移"是一个死胡同——它不懂弯曲。**

## 1986 年，那一记"把直线叠起来"的醒悟

让神经网络复活的关键，不是更聪明，而是更"笨"：既然一层直线画不出弯曲，那就**把直线一段一段接起来，接成折线**。

1986 年，**鲁梅尔哈特（David Rumelhart）、辛顿（Geoffrey Hinton）和威廉姆斯（Ronald Williams）**重新激活了"反向传播 (backpropagation)"：误差从输出一层一层倒着传回去，每一层根据自己的"责任"微调权重。更重要的是，人们终于接受了一件反直觉的事：**在每一层"缩放、加总、平移"之后，接一个"踩刹车"的步骤**——超过零的留下，没超过的归零。这个叫"非线性"的小动作，让折线有了拐点。

1989 年，数学家们把这件事钉死在定理上：**只要直线叠得够多、拐点够多，这样一个网络就能逼近几乎任何连续的形状**——弯的、曲的、歪七扭八的，都能被一段段直线拼接出来。直线的"死胡同"，在"叠加"面前变成了"任意曲面的积木"。

## 2012 年，显卡上的一场狂欢

但叠得多，算得就多。几百万个权重、几亿次"缩放、加总、平移"，靠 CPU 一颗一颗地算，等到头发白也训练不完。

救星是打游戏的人。显卡 (GPU) 为了每秒渲染几千万个三角形，被游戏产业逼着把一种运算磨到了极致——**大量一模一样的、并行的乘法累加**。工程师们突然醒悟：神经网络里那个"每个输入乘权重、加总"的操作，不正是显卡最擅长的事吗？它的形状，就是一张大表（矩阵）乘以一列数。

2012 年，**亚历克斯·克里热夫斯基（Alex Krizhevsky）等人在 ImageNet 竞赛上，用两块显卡把网络的深度一口气推到八层**，错误率几乎砍半，震惊学界。2017 年，Transformer 论文《Attention Is All You Need》更是把整个模型变成了一条巨大的矩阵运算流水线——那些古老的"缩放、加总、平移"，在显卡上以每秒数十万亿次的速度狂奔。

## 留一扇门

从 1958 年那台只会画直线的感知机，到 2012 年让世界为之一震的深度学习——中间隔着的，恰恰是同一个问题：**"缩放、加总、平移"这一步，到底是什么数学？**

它有个名字。一次旋转、拉伸的"缩放加总"，叫线性变换；再补上一次"整体搬家"，叫仿射变换。理解了这两个词，你才真正知道每一层全连接层在做什么，才明白为什么一条直线要叠成百上千层，又为什么那一记"踩刹车"的非线性，是它唯一不能丢的东西。这正是我们接下来要亲手验证的事。
