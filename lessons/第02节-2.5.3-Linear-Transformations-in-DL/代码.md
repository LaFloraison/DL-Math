# 代码：用 NumPy 拆开"线性层"，亲手看见线性与仿射

主线里我们用橡皮膜感受了线性变换，又证明了网络的"线性层"其实是仿射变换。这一节把这些全部变成代码：构造 $\mathbf{h} = \mathbf{W}\mathbf{x} + \mathbf{b}$，验证 $\mathbf{W}\mathbf{x}$ 满足两条线性公理、加上 $\mathbf{b}$ 后不满足，再看无激活的堆叠如何塌缩成一层，最后用两层 + ReLU 学会单层学不会的异或（XOR）。

脚本只依赖 NumPy，约 45 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：矩阵、乘法、逐元素操作全在这里

# ---- ① 构造仿射层 h = Wx + b ----
W = np.array([[1.0, -1.0],               # 2×2 权重矩阵：2 输入 → 2 输出
              [2.0,  1.0]])
b = np.array([1.0, 1.0])                 # 偏置：负责"整体平移"
x = np.array([1.0, 2.0])                 # 输入向量

h = W @ x + b                            # 仿射变换：线性部分 + 平移
print("① h = Wx + b     =", h)           # [0. 5.]

# ---- ② 验证 Wx 是线性变换：缩放保持 + 加法保持 ----
print("② 缩放保持: W(2x) =", W @ np.array([2.0, 4.0]), " 2Wx =", 2 * (W @ x))
u = np.array([1.0, 2.0]); v = np.array([1.0, 0.0])
print("   加法保持: W(u+v) =", W @ (u + v), " Wu+Wv =", W @ u + W @ v)

# ---- ③ 验证 Wx + b 破坏加法保持：仿射 ≠ 线性 ----
print("③ h(u)+h(v) =", (W @ u + b) + (W @ v + b))
print("   h(u+v)    =", W @ (u + v) + b)     # 两边不相等 → 不是线性变换

# ---- ④ 列组合视角：Wx 是 W 各列的加权和 ----
col_combo = x[0] * W[:, 0] + x[1] * W[:, 1]  # 组合系数是 x 的分量
print("④ 列组合 =", col_combo, " Wx =", W @ x)   # 两边相等

# ---- ⑤ 无激活堆叠塌缩：两层线性 = 一层线性 ----
W2 = np.array([[0.5, 0.0], [0.0, 2.0]])
two = W2 @ (W @ x)                       # 先 W 再 W2
one = (W2 @ W) @ x                       # 合并成单矩阵再作用
print("⑤ 堆叠两层 =", two, " 合并后 =", one)     # 两边相等

# ---- ⑥ ReLU 打破塌缩：非线性后无法合并 ----
def relu(z): return np.maximum(z, 0.0)   # 激活：负的归零，正的保留
print("⑥ relu(W@x) =", relu(W @ x))
print("   W2@relu(W@x) =", W2 @ relu(W @ x))

# ---- ⑦ XOR：单层仿射学不会，两层 + ReLU 学会 ----
X  = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])  # 4 个输入样本
y  = np.array([0., 1., 1., 0.])                           # 异或目标
Wh = np.array([[1., 1.], [1., 1.]])                       # 隐层权重
bh = np.array([0., -1.])                                  # 隐层偏置
Wo = np.array([[1.], [-3.]])                              # 输出层权重
bo = np.array([0.])                                       # 输出层偏置
hidden = relu(X @ Wh + bh)                                # 隐层：仿射 + ReLU
out    = hidden @ Wo + bo                                 # 输出：仿射
print("⑦ hidden =", hidden.tolist())
print("   输出 =", np.round(out, 4).flatten().tolist())
print("   预测 =", (out.flatten() > 0).astype(int).tolist(), " 目标 =", y.astype(int).tolist())
```

## 层二：分步逐函数拆解

### 步骤 1：构造权重矩阵、偏置、输入

```python
W = np.array([[1.0, -1.0], [2.0, 1.0]])
b = np.array([1.0, 1.0])
x = np.array([1.0, 2.0])
```

#### `np.array(嵌套列表)` —— 把列表变成数组

**做什么**：把 Python 数据转成 NumPy 数组，这是"向量和矩阵在计算机里的存在形式"。
**操作**：传入列表，NumPy 推断形状与数据类型，按顺序存入连续内存。
**输入**：
- `W`：嵌套列表 `[[1.0,-1.0],[2.0,1.0]]`，外层 2 个元素、每个内层 2 个元素 → 形状 `(2, 2)`。
- `b`：`[1.0, 1.0]` → 形状 `(2,)`。
- `x`：`[1.0, 2.0]` → 形状 `(2,)`。

**输出**：对应形状的 `ndarray`。形状语义：`(2, 2)` 的 `W` 第 0 维是输出维（行、2 个神经元）、第 1 维是输入维（列、2 个输入）；`x` 的 `(2,)` 是输入向量；`b` 的 `(2,)` 是每个输出神经元的平移量。
**可调参数**：
- 尺寸随便改：`W` 换成 `(3, 2)`，就把 2 个输入映射到 3 个输出——行数 = 输出维，列数 = 输入维，这是全连接层形状的规律。
- `dtype`：`np.array(..., dtype=np.float32)` 强制单精度，省内存；深度学习训练默认 `float32`。
- 必须保证 `W` 的**列数 = x 的元素数**，否则 `@` 会报错（形状不匹配，见步骤 2）。
**对应数学**：主线里仿射变换 $f(\mathbf{x}) = \mathbf{A}\mathbf{x} + \mathbf{b}$ 的三个零件：$\mathbf{W}$、$\mathbf{b}$、$\mathbf{x}$。

### 步骤 2：仿射变换 `W @ x + b`

```python
h = W @ x + b
```

#### `ndarray @ ndarray` —— 矩阵乘法（Python 3.5+ 的 `@` 运算符）

**做什么**：真正的线性变换 $\mathbf{W}\mathbf{x}$，再 `+ b` 完成平移——合起来就是网络的"线性层"。
**操作**：`@` 调用 `np.matmul`。`W`（形状 `(2,2)`）乘 `x`（形状 `(2,)`）：对 `W` 每一行与 `x` 做点积。第 0 行 `[1.0,-1.0] · [1.0,2.0] = 1 - 2 = -1`，第 1 行 `[2.0,1.0] · [1.0,2.0] = 2 + 2 = 4` → `[-1, 4]`。然后逐元素加 `b` → `[0, 5]`。
**输入**：`W` 形状 `(2,2)`，`x` 形状 `(2,)`。形状规则：`(2,2) @ (2,)` → 内维（`2`）必须相等。
**输出**：形状 `(2,)` 的向量 `[0. 5.]`。每个分量是一个神经元的输出。
**可调参数**：
- 加法顺序：`W @ x + b` 与 `b + W @ x` 结果相同（逐元素加法交换）；但 `W @ x` 绝不能写成 `x @ W`——后者要求 `x` 的元素数等于 `W` 的行数，几何含义完全不同。
- 批量：想让 32 个样本一起算，把 `x` 换成形状 `(2, 32)` 的矩阵，`W @ X` 一次算出所有样本——这正对应 GPU 上高效的矩阵乘法。
- `+ b` 依赖 NumPy 的**广播 (broadcasting)**：`(2,)` 的 `b` 逐元素加到 `(2,)` 的结果上；若结果是 `(32, 2)`，`b` 会自动广播到每一行。
**对应数学**：主线公式 $\mathbf{h} = \mathbf{W}\mathbf{x} + \mathbf{b}$，$f(\mathbf{0}) = \mathbf{b}$——输入全零时输出恰好是 `b`（试 `W @ np.zeros(2) + b` 得 `[1. 1.]`）。

### 步骤 3：验证 $\mathbf{W}\mathbf{x}$ 是线性变换

```python
print(W @ np.array([2.0, 4.0]), 2 * (W @ x))
print(W @ (u + v), W @ u + W @ v)
```

**做什么**：用两组相等性检查两条公理。
**操作**：
- 缩放保持：`W @ [2.0,4.0]`（即 $2\mathbf{x}$）算得 `[-2. 8.]`，与 `2 * (W @ x) = [-2. 8.]` 相等。
- 加法保持：`W @ (u + v) = [0. 6.]`，与 `W @ u + W @ v = [0. 6.]` 相等。
**输入**：都是形状 `(2,)` 的向量。
**输出**：两个布尔意义上的"相等"（数值完全一致），证明 $\mathbf{W}\mathbf{x}$ 满足两条公理——它是线性变换。
**可调参数**：换任意向量、任意 `W`，两条等式都成立——这正是"线性"不依赖具体数字的证明。想用程序判断相等，用 `np.allclose(W @ (u + v), W @ u + W @ v)`（浮点比较别用 `==`）。
**对应数学**：主线定义块里线性变换的两条公理 $T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})$、$T(c\mathbf{u})=cT(\mathbf{u})$。

### 步骤 4：验证 $\mathbf{W}\mathbf{x} + \mathbf{b}$ 不是线性变换

```python
print((W @ u + b) + (W @ v + b))   # h(u) + h(v)
print(W @ (u + v) + b)             # h(u + v)
```

**做什么**：检验仿射变换是否还满足加法保持——结果应该**不相等**。
**操作**：`h(u)+h(v) = [2. 8.]`，而 `h(u+v) = [1. 7.]`，两边差 `[1. 1.]`——差的部分恰好是 `b` 被算了两遍 vs 一遍。所以 $\mathbf{W}\mathbf{x}+\mathbf{b}$ 破坏加法保持，不是线性变换，是仿射变换。
**输入**：两个形状 `(2,)` 的向量及其求和结果。
**输出**：`[2. 8.]` 与 `[1. 7.]`，不相等。
**可调参数**：把 `b` 换成 `np.zeros(2)`，两边就相等了——这就是定义里"当且仅当 $\mathbf{b}=\mathbf{0}$ 时是线性变换"的代码验证。
**对应数学**：主线"网络的'线性层'根本不是线性变换"——名字里的"线性"只指 $\mathbf{W}$ 那部分。

### 步骤 5：列组合视角

```python
col_combo = x[0] * W[:, 0] + x[1] * W[:, 1]
```

**做什么**：用"各列加权和"重新算一遍 $\mathbf{W}\mathbf{x}$。
**操作**：`x[0]`（`1.0`）乘 `W[:, 0]`（`W` 的第 0 列 `[1.,2.]`）得 `[1.,2.]`；`x[1]`（`2.0`）乘 `W[:, 1]`（`[-1.,1.]`）得 `[-2.,2.]`；相加得 `[-1.,4.]`——与 `W @ x` 一致。
**输入**：`W[:, 0]` 形状 `(2,)`，`W[:, 1]` 形状 `(2,)`，`x[0]`、`x[1]` 是标量。
**输出**：形状 `(2,)` 的 `[-1. 4.]`。
**可调参数**：对任意 `n` 列，`W @ x` 都等于 `sum(x[j] * W[:, j] for j in range(n))`——列数等于输入维。这个视角揭示"输出是权重各列的线性组合，系数是输入分量"。
**对应数学**：主线"看列，不看行"——可解释性的数学根源。

### 步骤 6：无激活堆叠塌缩

```python
two = W2 @ (W @ x)
one = (W2 @ W) @ x
```

**做什么**：两层线性变换，一层层算 vs 合并成单矩阵，结果应该一致。
**操作**：`W2 @ W` 先做矩阵乘法 `(2,2)@(2,2) → (2,2)`，得到 `[[0.5,-0.5],[4.0,2.0]]`，再作用到 `x`；`two` 与 `one` 都是 `[-0.5 8.]`。结合律证明：堆多少层线性层，都等价于一张矩阵。
**输入**：`W2` 形状 `(2,2)`，`W @ x` 形状 `(2,)`。
**输出**：`[-0.5 8. ]`，两者相等。
**可调参数**：多堆几层也一样——`A3 @ (A2 @ (A1 @ x))` 等于 `(A3 @ A2 @ A1) @ x`。这就是"不加激活，深层网络塌缩成浅层"的代码铁证。
**对应数学**：主线"复合仍是线性变换，矩阵乘法就是复合"——教材"单个线性变换建模能力有限"的直接证据。

### 步骤 7：ReLU 打破塌缩

```python
def relu(z): return np.maximum(z, 0.0)
print(W2 @ relu(W @ x))
```

#### `np.maximum(a, b)` —— 逐元素取较大者

**做什么**：ReLU 激活 $\text{ReLU}(z)=\max(0,z)$ 的代码形式。
**操作**：对输入的每个元素，与 `0.0` 比较取大者。`W @ x = [-1., 4.]` → `[0., 4.]`：负的 `-1` 被压成 `0`，正的 `4` 保留。
**输入**：`z` 形状 `(2,)` 的数组，`b` 标量 `0.0`（会被广播到每个元素）。
**输出**：同形状 `[0. 4.]`。
**可调参数**：
- 第二参数换成负数（如 `-1.0`）就得到 LeakyReLU 的雏形：负区不再是 0 而是一段斜率。
- `np.maximum` 还可以两个数组对位取大：`np.maximum(z1, z2)` 逐元素返回两者中较大者。
- ReLU 之后 `W2 @ relu(W @ x) = [0. 8.]`，它**不能**再写成某个单矩阵作用在 `x` 上——因为"先砍掉负数再乘"无法用一次矩阵乘法表达。非线性让塌缩失效。
**对应数学**：主线边界声明"激活函数负责弯折"——非线性是网络表达复杂模式的关键。

### 步骤 8：XOR——单层学不会，两层学会

```python
hidden = relu(X @ Wh + bh)
out    = hidden @ Wo + bo
```

**做什么**：构造一个完整的两层小网络，验证它学会异或。
**操作**：`X` 是 4 个输入样本（形状 `(4,2)`）。`X @ Wh + bh`：每行样本与隐层权重做仿射，再逐行 ReLU，得到隐层 `hidden`（形状 `(4,2)`）——对四个样本分别是 `[0,0]`、`[1,0]`、`[1,0]`、`[2,1]`。`hidden @ Wo + bo`：形状 `(4,2) @ (2,1) → (4,1)`，得到输出 `[0., 1., 1., -1.]`。阈值判断 `> 0` 得预测 `[0,1,1,0]`，与目标 `[0,1,1,0]` 完全一致。
**输入**：`X` 形状 `(4,2)`（4 个样本 × 2 个特征），`Wh` 形状 `(2,2)`，`bh` 形状 `(2,)`，`Wo` 形状 `(2,1)`，`bo` 形状 `(1,)`。
**输出**：`hidden` 形状 `(4,2)`，`out` 形状 `(4,1)`，预测形状 `(4,)`。
**可调参数**：
- 换掉 `Wo = [[1.],[-3.]]` 的数值，只要保持 `Wo[0,0] > 0` 且 `Wo[0,0]*2 + Wo[1,0] < 0`，依然正确——决定对错的不是某一组数，而是"隐层把四个点映射到能线性分开的位置"这个结构。
- 若把 `relu` 去掉，`hidden` 退化为线性，两层合并成一层，XOR 立刻学不会——这正是步骤 6/7 的因果闭环。
**对应数学**：主线"堆叠 + 非线性 → 建模复杂非线性模式"的最小演示。

## 边界声明：这套代码能做什么，不能做什么

1. **验证"是否线性"必须同时测两条公理。** 只测缩放保持（步骤 3 前半）会漏掉平移的破坏；必须连加法保持一起测，才能区分线性与仿射。`h(u)+h(v)` 与 `h(u+v)` 差一个 `b`，就是"平移"背叛线性的全部罪证。
2. **浮点相等用 `np.allclose`。** 真实网络里数值带误差，`==` 几乎永远返回 `False`。本脚本的小数恰好能精确相等是侥幸；工程里一律用容差比较。
3. **`@` 的形状规则是硬约束。** `(2,2) @ (2,)` 合法、`(2,) @ (2,2)` 报错。全连接层的 `W` 形状必须满足"列数 = 输入维、行数 = 输出维"，写错就是维度不匹配异常（真实框架里的 `nn.Linear(in, out)` 底层就是这张矩阵）。
4. **这里的手写两层网络没有"学习"。** 权重 `Wh`、`Wo` 是我们直接填好的，模型不会自己调参。真正的训练（梯度下降更新权重）是后续章节的内容——本课只负责证明"结构上"两层非线性能表达 XOR，不负责"学会"它。
