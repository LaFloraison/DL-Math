# 代码：均匀分布——把"处处平等"写成一个常数，让积分替我们裁决

主线里我们得出一条结论：均匀分布是"任何位置机会均等"的数学化身，其密度是区间 $[a,b]$ 内的一个常数 $\frac{1}{b-a}$，区间外是 0。但这只是一个声明。本课我们要亲手把这句话变成代码，并且用两把尺子量它：

1. **区间概率**：$\mathrm{P}(c \le X \le d) = \dfrac{d-c}{b-a}$——Toy Model 里"机会正比于长度"的精确公式。
2. **归一化裁决**：整个区间上密度与 $x$ 轴围出的面积必须等于 1——这是"够不够格当概率密度"的唯一裁判。

我们不调用任何现成的分布类，只用手写的公式 + NumPy 的 `np.trapz` 梯形积分。这样你才能看见：那个常数不是魔法，是被面积守恒逼出来的。

## 层一：完整脚本

```python
import numpy as np                        # NumPy：where / linspace / trapz 全部来自这里

def uniform_pdf(x, a, b):                 # ① 密度函数：区间内常数 1/(b-a)，区间外 0
    """连续均匀分布的密度：区间内处处相等，区间外为 0。"""
    return np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)

def uniform_cdf(x, a, b):                 # ② 累积分布函数：到 x 为止累计了多少概率
    """P(X <= x)：x 落在 a 之前是 0，落在 b 之后是 1，中间线性爬升。"""
    return np.where(x < a, 0.0,
           np.where(x > b, 1.0,
           (x - a) / (b - a)))

# ---- ① 教材的数字：公交 6:00-7:00，即 Uniform(0, 60)（单位：分钟）----
a, b = 0.0, 60.0
print(f"密度 f(30)             = {uniform_pdf(30.0, a, b):.6f}   # 区间内处处 = 1/60")
print(f"密度 f(70)             = {uniform_pdf(70.0, a, b):.6f}   # 区间外 = 0")
print(f"P(15 <= X <= 45)       = {uniform_cdf(45.0, a, b) - uniform_cdf(15.0, a, b):.6f}   # 理论 (45-15)/60 = 0.5")

# ---- ② 归一化裁决：∫ f(x) dx ≈ 1 ----
x = np.linspace(-10.0, 70.0, 10001)       # 从区间外一点铺到区间外一点，把整座矩形包住
area = np.trapz(uniform_pdf(x, a, b), x)
print(f"∫ Uniform(0,60) ≈ {area:.6f}   # 理论值 1，完全吻合")

# ---- ③ 抽样：用 np.random.uniform 直接抽 20 万次，统计落入 [15,45] 的比例 ----
np.random.seed(0)                         # 固定随机种子，让结果可复现
samples = np.random.uniform(low=a, high=b, size=200000)
empirical = np.mean((samples >= 15.0) & (samples <= 45.0))
print(f"抽样 200000 次，落在 [15,45] 的比例 = {empirical:.6f}   # 理论 0.5，大数定律把它拉回来")
```

运行输出（Python 3.11 + NumPy）：

```text
密度 f(30)             = 0.016667   # 区间内处处 = 1/60
密度 f(70)             = 0.000000   # 区间外 = 0
P(15 <= X <= 45)       = 0.500000   # 理论 (45-15)/60 = 0.5
∫ Uniform(0,60) ≈ 1.000000   # 理论值 1，完全吻合
抽样 200000 次，落在 [15,45] 的比例 = 0.500000   # 理论 0.5，大数定律把它拉回来
```

公式被数字当场验算：密度恒定、区间概率正比于长度、总面积恰好 1、抽样比例收敛到 0.5。下面把每一行拆开。

### 步骤 2：定义 `uniform_pdf` —— 区间内取常数，区间外归零

```python
def uniform_pdf(x, a, b):
    """连续均匀分布的密度：区间内处处相等，区间外为 0。"""
    return np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)
```

#### uniform_pdf —— 均匀分布的密度：区间内常数，区间外零

`return np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)`

**做什么**：对传入的每个点，判断是否落在 $[a,b]$ 内——落在区间内的输出常数密度 $\frac{1}{b-a}$，落在区间外的输出 $0$。
**操作**：`(x >= a) & (x <= b)` 逐元素比较，产生与 `x` 同形状的布尔数组（区间内 `True`，区间外 `False`）；`np.where(条件, 值1, 值2)` 是向量化的三目运算——条件为真的位置取 `1.0 / (b - a)`，为假的位置取 `0.0`。这就是"区间外密度为 0"这个限定在代码里的化身。
**输入**：
- `x`：标量或任意形状数组，待求密度的点。可以一次传入整个网格（如 10001 个点），NumPy 逐元素应用——**向量化 (vectorization)**，是后面 `np.trapz` 一次算完的前提。
- `a`：区间下界，标量，对应教材的 $a$。
- `b`：区间上界，标量，对应教材的 $b$。
**输出**：与 `x` 同形状的数组，每个位置是该点的密度。区间内恒为 $\frac{1}{b-a}$，区间外恒为 0。
**可调参数**：
- 参数 `a`、`b`：区间两端，也是这个分布仅有的两个自由度。区间越窄，$\frac{1}{b-a}$ 越大——因为总面积必须恒为 1，宽度压短了高度就得抬高。想模拟"从 0 到 1 随机取数"取 $a=0,b=1$（密度 1）；想模拟"公交车一小时一班"取 $a=0,b=60$（密度 $\frac{1}{60}\approx0.0167$）。
- 能不能加第四个参数？`np.where` 还能用简写 `np.where(条件)`（只返回满足条件的下标），但那是别的用途；对密度函数，`x, a, b` 已完备。
**对应数学**：主线里的 $f(x)=\frac{1}{b-a},\ a\le x\le b$。`np.where` 的第三个分支正是公式里"for $a\le x\le b$"这个限定——没有它，$x=70$ 就会错误地得到 $\frac{1}{60}$ 而不是 0。

### 步骤 3：定义 `uniform_cdf` —— 从左边累计概率

```python
def uniform_cdf(x, a, b):
    """P(X <= x)：x 落在 a 之前是 0，落在 b 之后是 1，中间线性爬升。"""
    return np.where(x < a, 0.0,
           np.where(x > b, 1.0,
           (x - a) / (b - a)))
```

#### uniform_cdf —— 均匀分布的累积分布函数：区间内线性爬升

`np.where(x < a, 0.0, np.where(x > b, 1.0, (x - a) / (b - a)))`

**做什么**：回答"$X$ 不超过 $x$ 的概率是多少"。在 $a$ 的左边，这个概率是 0（还没进区间）；在 $b$ 的右边，是 1（已经越过了整个区间）；在中间，从 0 线性爬到 1。
**操作**：外层 `np.where(x < a, 0.0, ...)` 处理左支；内层 `np.where(x > b, 1.0, ...)` 处理右支；最后的 `(x - a) / (b - a)` 是中间支——**从 $a$ 到 $x$ 的区间长度占总长度的比例**。
**输入**：
- `x`：标量或数组，求"不超过多少"的那个数。
- `a`、`b`：与 `uniform_pdf` 相同的区间参数。
**输出**：与 `x` 同形状的数组，值是 $[0,1]$ 之间的累积概率。`uniform_cdf(45.0,a,b) - uniform_cdf(15.0,a,b)` 就是 $\mathrm{P}(15\le X\le 45)$。
**可调参数**：
- 参数与 `uniform_pdf` 一致。可以换任意区间验证：$a=0,b=1$ 时 `uniform_cdf(0.8,0,1)=0.8`——"从 0 到 1 随机取数，取到 0.8 以下"的概率正好 80%。
- 能不能加参数？`x, a, b` 已完备。教科书有 `scipy.stats.uniform.cdf(x, loc=a, scale=b-a)` 的等价写法，`scale` 就是区间长度 $b-a$。
**对应数学**：主线里 $\mathrm{P}(c\le X\le d)=\frac{d-c}{b-a}$ 的"单侧版"——先累计到 $d$，再减掉累计到 $c$。累积分布函数的通式 $\mathrm{P}(X\le x)=\int_{-\infty}^{x} f(t)\,dt$，对均匀分布积分出来就是这条直线。

### 步骤 4：打印特定点的密度与区间概率

```python
a, b = 0.0, 60.0
print(f"密度 f(30)             = {uniform_pdf(30.0, a, b):.6f}   # 区间内处处 = 1/60")
print(f"P(15 <= X <= 45)       = {uniform_cdf(45.0, a, b) - uniform_cdf(15.0, a, b):.6f}   # 理论 (45-15)/60 = 0.5")
```

**做什么**：在几个"有故事"的点上把公式算成具体的数。`.6f` 把结果格式化为保留 6 位小数。
**操作**：f-string（`f"..."`）把 `{}` 里的表达式求值并格式化嵌入字符串；`uniform_pdf(30.0, 0.0, 60.0)` 就是把 $x=30, a=0, b=60$ 代入。
**输入**：函数调用，各自传入代表性横坐标。
**输出**：文本行，如 `密度 f(30) = 0.016667`。
**可调参数**：可以换成任何点——比如 `uniform_pdf(0.0, 0.0, 1.0)`（$[0,1]$ 上密度恰为 1），或 `uniform_pdf(-1.0, 0.0, 60.0)`（区间外，应得 0）。
**对应数学**：$f(30)=\frac{1}{60}$ 证明"处处相等"；`cdf 差`证明"机会正比于长度"。注意打印出来的 $f(30)=0.0167$ **不是概率**——它是密度，概率要乘区间宽度。

### 步骤 5：`np.trapz` 梯形法则验证归一化

```python
x = np.linspace(-10.0, 70.0, 10001)
area = np.trapz(uniform_pdf(x, a, b), x)
```

#### `np.linspace(start, stop, N)` —— 生成等距网格

**操作**：在 $[start, stop]$ 上生成 $N$ 个等间距点，首尾都包含。
**输入**：`start`（起点）、`stop`（终点）、`N`（点的个数）。
**输出**：长度 $N$ 的一维数组。`np.linspace(-10.0, 70.0, 10001)` 得到 10001 个点，间距 $dx = (70-(-10))/(10001-1)=0.008$。
**可调参数**：`N` 越大网格越密，梯形近似越准。还可以传第四个参数 `endpoint=False` 去掉末点，或 `retstep=True` 同时返回间距——本脚本不需要。
**为什么起点取 $-10$ 而不是 $0$？** 因为我们要验证的是"整个 $x$ 轴上的总面积"。从区间外一点的 $-10$ 铺到区间外一点的 $70$，把整座矩形完整包住，积分才算完整——这正是"归一化"要证明的：哪怕把区间外也算进来，总面积依然是 1。

#### `np.trapz(y, x)` —— 用梯形法则求数值积分

**操作**：把曲线下方切成 $N-1$ 个细长梯形，每个梯形以相邻两点 $x_i,x_{i+1}$ 上的函数值 $y_i,y_{i+1}$ 为上下底，面积 $\frac{y_i+y_{i+1}}{2}\cdot dx$，全部相加。这就是梯形法则：把"连续"近似成"一段段直线"。
**输入**：
- `y`：函数值数组，形状 `(N,)`——这里是每个网格点上的密度。
- `x`：网格点数组，形状 `(N,)`——与 `y` 一一对应的横坐标。
**输出**：一个标量，$\int f(x)\,dx$ 的近似值。这里输出 `1.000000`。
**可调参数**：
- 第二个参数也可传标量间距 `dx`（如 `np.trapz(y, 0.008)`），等价。
- 均匀分布是平的，梯形法则对它近乎零误差；把 `10001` 改成 `11` 依然分毫不差。换成钟形曲线就不行了——那是 §4.2.2.2 的故事。
- 新版 NumPy（≥2.0）把 `np.trapz` 更名为 `np.trapezoid`，结果一致。为对齐教材保留 `np.trapz`。
**对应数学**：对 $\int_{-\infty}^{\infty} f(x)\,dx = 1$ 这条合法性条件的直接验算。

### 步骤 6：用 `np.random.uniform` 抽样，让大数定律说话

```python
np.random.seed(0)
samples = np.random.uniform(low=a, high=b, size=200000)
empirical = np.mean((samples >= 15.0) & (samples <= 45.0))
```

#### `np.random.seed(seed)` —— 固定随机序列，让结果可复现

**操作**：把伪随机数生成器的初始状态设为 `0`，此后每一次 `np.random.*` 调用产生的"随机"序列都是固定的。
**输入**：`seed`，任意整数。
**输出**：无返回值，只重置内部状态。
**可调参数**：任意整数都行。换一个种子，抽样结果会有微小差异，但都会收敛到同一个理论值——这就是随机性的本质：单次看是"随机"，整体看是"规律"。

#### `np.random.uniform(low, high, size)` —— 从均匀分布里抽样本

**操作**：在 $[low, high)$ 上按密度 $\frac{1}{high-low}$ 抽取 `size` 个独立样本。底层是一个线性同余/梅森旋转伪随机数发生器，再经过一个缩放——输出的分布精确服从均匀。
**输入**：
- `low`：区间下界，对应 $a$。
- `high`：区间上界，对应 $b$。
- `size`：抽多少样本。这里 `200000`。
**输出**：形状 `(200000,)` 的一维数组，每个元素都在 $[0,60)$ 内，且密度处处相同。
**可调参数**：还有第四个位置参数 `dtype`（返回的数组类型，默认 `float64`）；`size` 可以是元组 `(100, 100)` 返回二维数组。`low`/`high` 决定区间。想模拟"从 0 到 1 随机取数"就传 `low=0, high=1`。

#### `(samples >= 15.0) & (samples <= 45.0)` 与 `np.mean` —— 数比例

**操作**：布尔数组（落在区间内为 `True`），`np.mean` 把 `True` 当 1、`False` 当 0 求平均——平均一个布尔数组，就是在算"为真的比例"。
**输入**：`samples` 数组和区间端点。
**输出**：一个标量 `0.500000`（近似）。
**可调参数**：换区间端点即换比例；换 `size` 可看收敛——`size=100` 时比例可能在 0.45 到 0.55 之间晃，`size=200000` 时被拉回 0.500 附近。这就是**大数定律 (law of large numbers)**：样本越多，频率越逼近真实概率。
**对应数学**：$P(15\le X\le45)=0.5$ 的抽样验证——公式算的是"上帝视角"，抽样算的是"统计视角"，两者在大数定律下合流。

## 改个数字试试：把区间推向极端

### 实验 1：区间变窄，密度升高

```python
print(f"Uniform(0,1) 的密度     = {uniform_pdf(0.5, 0.0, 1.0):.6f}   # 1/(1-0) = 1")
print(f"Uniform(0,0.5) 的密度   = {uniform_pdf(0.25, 0.0, 0.5):.6f}   # 1/(0.5-0) = 2，密度 > 1！")
x2 = np.linspace(-0.2, 0.7, 10001)
print(f"Uniform(0,0.5) 的面积   = {np.trapz(uniform_pdf(x2, 0.0, 0.5), x2):.6f}   # 依然是 1")
```

输出：

```text
Uniform(0,1) 的密度     = 1.000000   # 1/(1-0) = 1
Uniform(0,0.5) 的密度   = 2.000000   # 1/(0.5-0) = 2，密度 > 1！
Uniform(0,0.5) 的面积   = 1.000000   # 依然是 1
```

密度是 **2**——比"最大概率 1"还大！面积却依然是 1。这就是主线里那句边界声明的现场演示：**密度可以大于 1，概率不能。** 面积守恒逼着它把"变窄的底"折算成"变高的墙"。

### 实验 2：区间平移，只改位置不改形状

```python
print(f"Uniform(5,15) 的密度    = {uniform_pdf(10.0, 5.0, 15.0):.6f}   # 1/(15-5) = 0.1")
print(f"P(6 <= X <= 9)          = {uniform_cdf(9.0,5.0,15.0)-uniform_cdf(6.0,5.0,15.0):.6f}   # (9-6)/10 = 0.3")
```

输出：

```text
Uniform(5,15) 的密度    = 0.100000   # 1/(15-5) = 0.1
P(6 <= X <= 9)          = 0.300000   # (9-6)/10 = 0.3
```

区间从 $[0,60]$ 换成 $[5,15]$，密度、概率全部自动跟上——你只改了 `a` 和 `b` 两个数，其余全部由公式接管。这就是参数化的意义：**形状的灵魂是那一条法律（总面积=1），数字只是它的奴隶。**

## 边界声明：这套代码能做什么，不能做什么

1. **打印出来的密度不是概率。** $f(30)=0.0167$ 的意思是"30 分钟那一瞬间的单位长度上有约 1.7% 的浓度"，不是"恰好 30 分钟的概率是 1.7%"（连续分布单点概率恒为 0）。要概率必须积分——CDF 的差、梯形法则的积分，都是干这个的。
2. **均匀分布只能表达"无差别"。** 如果你的数据在区间中部隆起、两端稀疏，均匀分布会给出荒谬的答案——它根本不知道"隆起"是什么。它是"我什么都不知道"的先验，不是"我知道形状"的模型。对隆起的数据，请去找 §4.2.2.2 的正态分布。
3. **这只是验算工具。** 真实建模不会手写 PDF 再数值积分——NumPy 有 `np.random.uniform` 直接抽样，SciPy 有 `scipy.stats.uniform` 的完整分布对象。但那些封装背后，正是这两行公式在做同一件事。先把公式亲手写出来，再跳进封装——你才能看懂封装在替你做哪一步。
