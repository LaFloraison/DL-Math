# 习题：均匀分布（连续）

## 第一组：概念检验

**1. 判断正误并说明理由："均匀分布里，区间内任何一点的概率都相等。"**

**解答**：错误。这句话混淆了"密度"和"概率"。连续均匀分布里，区间内任何一点的**概率**都是 0（单点没有宽度，装不下概率），它们"永远相等"；相等的是**概率密度** $f(x)=\frac{1}{b-a}$。正确答案是"区间内任何一点的密度都相等"。这是连续分布世界最容易犯的一个错——把密度当概率。

**2. 为什么 $[a,b]$ 上的均匀分布，密度必须是 $\frac{1}{b-a}$，而不是随便一个常数 $c$？**

**解答**：因为总概率必须等于 1。密度恒为 $c$ 时，整段区间上的"面积"是底 $\times$ 高 $=(b-a)\cdot c$，令它等于 1，就唯一地解出 $c=\frac{1}{b-a}$。这不是约定，是被"总面积恒为 1"这条法律逼出来的。如果你试图用别的常数，面积要么大于 1（多出来的概率无处安放），要么小于 1（概率凭空消失）。

**3. 若 $X \sim \text{Uniform}(0, 0.5)$，则 $f(x)$ 的取值是什么？这个值超过 1 了吗？它违反什么没有？**

**解答**：$f(x) = \frac{1}{0.5-0} = 2$，区间内处处为 2，区间外为 0。它超过了"1"，但没有违反任何规则——因为 $f(x)$ 是**密度**不是概率，密度可以大于 1。面积 $0.5 \times 2 = 1$，归一化依然成立。超过 1 的直觉在这里必须让位给"密度是每单位长度的浓度"这个定义。

## 第二组：计算实践

**4. 手算 + 代码验证。** 公交车在 $[0, 60]$ 分钟上均匀到达。（a）车在 $[20, 50]$ 之间来的概率？（b）车在**恰好** $30$ 分钟来的概率？（c）求均值 $\mathbb{E}[X]$ 与方差 $\mathrm{Var}[X]$。

**解答**：
（a）$\mathrm{P}(20\le X\le 50) = \frac{50-20}{60-0} = \frac{30}{60} = 0.5$。50%——Toy Model 里"机会正比于长度"的精确版。
（b）$\mathrm{P}(X=30)=0$。单点没有宽度，概率恒为 0。这不是"车绝不会在 30 分钟到"，而是"连续世界里概率不放在点上"。
（c）$\mathbb{E}[X]=\frac{a+b}{2}=\frac{0+60}{2}=30$ 分钟；$\mathrm{Var}[X]=\frac{(b-a)^2}{12}=\frac{3600}{12}=300$（单位：分钟²）。

代码验证：

```python
import numpy as np
a, b = 0.0, 60.0
x = np.linspace(0.0, 60.0, 10001)
pdf = np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)
# (a) 区间概率：用 CDF 差
cdf = lambda t: np.where(t < a, 0.0, np.where(t > b, 1.0, (t - a) / (b - a)))
print("P(20<=X<=50) =", cdf(50.0) - cdf(20.0))
# (c) 均值与方差：直接按定义积分
mean = np.trapz(x * pdf, x)
var  = np.trapz((x - mean)**2 * pdf, x)
print("E[X] =", mean, " Var[X] =", var)
```

输出：

```text
P(20<=X<=50) = 0.5
E[X] = 30.0  Var[X] = 300.0
```

**思路点拨**：若有人把 (b) 答成"$\frac{1}{60}$"，那是把离散均匀的 $P(X=k)=\frac{1}{n}$ 错误搬进了连续世界。区分标志只有一个：随机变量取的是**可数的值**（骰子面）还是**连续的值**（时间、长度）。后者一律不谈单点概率。

**5. 用抽样估计 $\mathrm{P}(X \le 12)$，其中 $X\sim\text{Uniform}(0,60)$，抽 10 万次。理论值是多少？抽样结果为什么总在理论值附近抖，而不是严格等于？**

**解答**：理论值 $\frac{12-0}{60}=0.2$。代码：

```python
import numpy as np
np.random.seed(42)
samples = np.random.uniform(0.0, 60.0, 100000)
print("抽样比例 =", np.mean(samples <= 12.0))
```

输出（每次略有不同）：

```text
抽样比例 = 0.19922
```

抽样比例 $0.19922$ 在理论值 $0.2$ 附近抖动，是因为样本只是有限次观测，频率围绕概率波动；样本数越大，波动越小——这就是大数定律。若换了 seed 或 size，你会得到 $0.2007$、$0.1990$ 之类"还是差不多 $0.2$"的数。**理论值给精确，抽样给验证，两者靠大数定律握手。**

## 第三组：DL 延伸

**6. 初始化场景。** 你想给一层全连接网络做权重初始化。两个方案：方案 A，权重从 $\text{Uniform}(-\frac{1}{\sqrt{n}}, \frac{1}{\sqrt{n}})$ 抽取；方案 B，权重从 $\text{Uniform}(-1, 1)$ 抽取（$n$ 是输入神经元数）。哪个更合理？为什么方差公式 $\mathrm{Var}[X]=\frac{(b-a)^2}{12}$ 在这里是决策工具？

**解答**：方案 A 更合理。关键看方差如何随 $n$ 变化。一个神经元收到 $n$ 个输入加权求和 $z=\sum_i w_i x_i$。若每个 $w_i$ 的方差都是 $\sigma^2$，且输入彼此独立、方差 $\text{Var}[x]$，则 $\text{Var}[z] = n\cdot\sigma^2\cdot\text{Var}[x]$——方差随 $n$ 线性增长。如果 $n$ 很大（比如 1024）而 $\sigma^2$ 固定，$z$ 的散布随层数逐层爆炸，信号失真。
方案 B 的 $\sigma^2 = \frac{(1-(-1))^2}{12} = \frac{4}{12}=\frac13$ 与 $n$ 无关；方案 A 的 $\sigma^2 = \frac{(2/\sqrt{n})^2}{12} = \frac{1}{3n}$，代入 $\text{Var}[z] = n\cdot\frac{1}{3n}\cdot\text{Var}[x] = \frac13\text{Var}[x]$——**方差被钉住了，不随层数爆炸也不衰减**。你看到的那个 $\frac{1}{\sqrt{n}}$，正是用 $\mathrm{Var}[X]=\frac{(b-a)^2}{12}$ 反解出来的。
**思路点拨**：这题的核心是"参数不是拍脑袋定的，是被约束条件解出来的"。若有人选 B，往往是因为"$(-1,1)$ 看着对称好看"——但对称不是目标，**方差守恒**才是。均匀分布在这里的价值就是：它的方差有闭式公式 $\frac{(b-a)^2}{12}$，于是"区间宽度"和"方差"之间可以精确互算。
