## 解答与思路点拨

### 第一组

**1.1** 最小化；模型预测；实际值（真实标签）；未见数据（新数据）。**易错点**：把"最小化损失"和"泛化"混为一谈——最小化是手段，泛化是目的。损失在训练集上掉到 0，未必泛化好（过拟合）。

**1.2** 选 B。Momentum 用历史速度 $v=\beta v+g$ 纳入当前更新——惯性让平缓方向攒速、陡峭方向缓冲，抑制震荡、加速收敛。A 是 Adagrad/RMSprop/Adam 的思想；C 是 SGD；D 与动量无关。

**1.3** 错。两点：(a) 自适应方法在**平滑、坐标尺度适中**的问题上并不比 Momentum/GD 快（代码回合一已证明）——它的优势是鲁棒而非绝对速度；(b) 文献（Wilson 2017）发现自适应方法在训练损失上收敛快，但**泛化常不如带冲量的 SGD**——因为自适应方法倾向收敛到"更尖"的局部最优（§5.4），对测试数据不鲁棒。**判断要点**：把"收敛快"与"效果好"划等号是常见误区——收敛速度和泛化是两个维度。

### 第二组

**2.1**
(a) $\nabla J = (2\theta_1, 200\theta_2) = (6, 100)$。
(b) GD：$\theta_1 = 3 - 0.01\times6 = 2.94$；$\theta_2 = 0.5 - 0.01\times100 = -0.5$——**$\theta_2$ 一步跨过谷底到 -0.5，震荡**（步长 1.0 > 距离 0.5）。
(c) Adagrad：一步后 $E = g^2 = (36, 10000)$。$\theta_1 = 3 - 0.01\times 6/\sqrt{36} = 3 - 0.01\times1 = 2.99$；$\theta_2 = 0.5 - 0.01\times 100/\sqrt{10000} = 0.5 - 0.01\times1 = 0.49$——**两个方向都只挪 0.01**，不会踩空。
**易错点**：对比两者的 $\theta_2$ 方向——GD 一步挪 1.0（踩过头），Adagrad 一步挪 0.01（稳健）。这就是"逐坐标归一化"的威力。

**2.2**
(a) $v_{\text{new}} = \beta v + g = 0.9(0.1,0.2) + (0.3,0.4) = (0.09+0.3,\ 0.18+0.4) = (0.39, 0.58)$。
(b) 参数更新量 = $\alpha v_{\text{new}} = 0.1 \times (0.39, 0.58) = (0.039, 0.058)$。
**易错点**：Momentum 的更新用的是"新速度"，不是"当前梯度"——别把 `g` 直接乘 $\alpha$。

**2.3**
(a) `iters=2000`：GD 沿 $\theta_1$ 以因子 $1-0.005\times2=0.99$ 衰减，2000 步后 $\approx 5\times0.99^{2000}\approx5\times1.9\times10^{-9}\approx0$，距离趋于 0；Adagrad 的 $E$ 持续累加，步长 $\propto 1/\sqrt{t}$ 递减，2000 步后仍在 4-5 附近——**账本只增不死的"学习率死亡"现场**。
(b) `lr=0.2`：自适应方法仍幸存（归一化把每步压到 $\approx \text{lr}/\|g\|$ 量级），但 GD/Momentum 早已发散。
(c) `torch.optim.Adam` 结果与裸核一致——默认超参 `betas=(0.9, 0.999), eps=1e-8`。
**要点**：实验 (a) 揭示 Adagrad 的软肋（§5.6.5），(b) 揭示自适应的核心价值（鲁棒性）。

### 第三组

**3.1** 三点：(a) **数据量**——现代数据集百万级以上，BGD 每步要扫全部数据，一次迭代成本天文数字；mini-batch 每步只看几十到几百样本，快几个数量级。(b) **每步成本**——SGD/mini-batch 的每步计算与批大小成正比，批越小越省（配合 GPU 并行有个最优批大小区间）。(c) **噪声帮助**——mini-batch 的梯度噪声（§5.3.7）让优化器能"晃出"尖锐的局部最优（§5.4），BGD 的精确梯度反而容易卡住。**所以深度学习默认 mini-batch + 自适应优化器，BGD 只在理论分析里当基准。**

**3.2** 解释：自适应方法归一化步长后，倾向收敛到**更尖锐 (sharp)** 的局部最优——它们快速钻进"低训练损失"的窄谷；而带冲量的 SGD 更常落在**更宽 (wide)** 的谷底。窄谷对参数扰动敏感，测试时（参数微小变化、数据噪声）性能雪崩；宽谷对扰动鲁棒，泛化更好（§5.4 详细）。**实践建议**：两步走——先用 Adam 快速探索、获得一个不错的解；再用带冲量的 SGD 精修（或用 AdamW、余弦退火等改进），以获得更好的泛化。这也是很多 SOTA 训练的标配配方。
