# 代码：五款优化器同台竞技——一个诚实的下山锦标赛

**目标**：主线用"五个下山者"讲了优化器家族。这里把五款优化器**全部从零实现**，放在**病态二次函数** $J(\theta)=\theta_1^2 + 100\theta_2^2$（椭圆等高线，最优在 $(0,0)$）上比赛。但这场比赛有两个回合，结论比"自适应方法永远最好"**更真实、更有价值**：

- **回合一（稳妥学习率）**：你会看到 Momentum 反而最快，自适应方法并不神奇——这是真实文献（Wilson et al. 2017）承认的事实。
- **回合二（偏大学习率）**：GD 和 Momentum 直接**发散**，而 Adagrad/RMSprop/Adam 靠逐参数归一化**幸存**——这正是它们成为深度学习默认优化器的真正原因：**对学习率鲁棒**。

全部裸 NumPy，每个优化器就是 3-6 行更新公式——读一遍代码，就同时读懂了 §5.6.4 到 §5.6.7 的四套公式。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 病态二次函数: J = theta1^2 + 100*theta2^2 ----
def grad(theta):
    return np.array([2.0 * theta[0], 200.0 * theta[1]])

def dist(theta):
    return np.hypot(theta[0], theta[1])            # 到谷底 (0,0) 的距离

# ---- 2. 五款优化器 ----
def run(name, lr, iters):
    theta = np.array([5.0, 1.0])                   # 共同起点
    v, beta = np.zeros(2), 0.9                     # Momentum 状态
    E = np.zeros(2); m = np.zeros(2); t = 0        # 自适应方法状态
    b1, b2, eps = 0.9, 0.999, 1e-8
    for _ in range(iters):
        g = grad(theta)
        if name == 'GD':
            theta = theta - lr * g
        elif name == 'Momentum':
            v = beta * v + g
            theta = theta - lr * v
        elif name == 'Adagrad':
            E = E + g**2
            theta = theta - lr * g / (np.sqrt(E) + eps)
        elif name == 'RMSprop':
            E = 0.9 * E + 0.1 * g**2
            theta = theta - lr * g / (np.sqrt(E) + eps)
        elif name == 'Adam':
            t += 1
            m = b1 * m + (1 - b1) * g
            E = b2 * E + (1 - b2) * g**2
            theta = theta - lr * (m / (1 - b1**t)) / (np.sqrt(E / (1 - b2**t)) + eps)
        if np.abs(theta).max() > 1e8:
            return float('inf')                    # 发散检测
    return dist(theta)

# ---- 3. 两个回合 ----
print("回合一: lr=0.005 (稳妥小学习率), 200 步")
for name in ['GD', 'Momentum', 'Adagrad', 'RMSprop', 'Adam']:
    print(f"  {name:9s} 距谷底 = {run(name, 0.005, 200):.4f}")

print("回合二: lr=0.05 (偏大学习率), 60 步")
for name in ['GD', 'Momentum', 'Adagrad', 'RMSprop', 'Adam']:
    d = run(name, 0.05, 60)
    print(f"  {name:9s} 距谷底 = {'发散!' if d == float('inf') else f'{d:.4f}'}")
```

输出（可复现，无随机）：

```

  Adagrad   距谷底 = 4.9434
  RMSprop   距谷底 = 3.9644
  Adam      距谷底 = 4.0500

回合二: lr=0.05 (偏大学习率), 60 步
  GD        距谷底 = 发散!
  Momentum  距谷底 = 发散!
  Adagrad   距谷底 = 4.3339

```

**两个回合，两个诚实而深刻的结论：**
- **回合一**：Momentum 用 200 步精确到谷底（0.0000），GD 慢（0.67），自适应方法反而落后（3-5）。**在平滑的、坐标尺度适中的二次函数上，自适应方法并不神奇**——动量（加速梯度）才是最快的。这是真实的数学事实，也是 2017 年"自适应方法的价值"之争的由来。
- **回合二**：学习率放大 10 倍，GD 和 Momentum 直接**发散**，三个自适应方法却靠"逐坐标归一化"稳稳幸存。**自适应方法的真正王牌不是"更快"，而是"更鲁棒"**——它把每个参数的步长除以它的历史梯度尺度，所以不会一步踩空。这正是深度学习训练里 `Adam` 成为默认的原因：**你不需要把学习率调得那么精细，Adam 自己会兜底。**

## 层二：分步逐函数拆解

### 步骤 1：目标与距离

```python
def grad(theta):
    return np.array([2.0 * theta[0], 200.0 * theta[1]])

def dist(theta):
    return np.hypot(theta[0], theta[1])
```

#### `grad` —— 病态函数的梯度

**操作**：$J = \theta_1^2 + 100\theta_2^2$ 的梯度 $\nabla J = (2\theta_1, 200\theta_2)$。**输入**：`theta`（形状 `(2,)`）。**输出**：形状 `(2,)` 的梯度。
**可调参数**：第二个分量系数 `200` 决定病态程度。改大到 `2000`，椭圆更扁——GD 的之字更惨，自适应方法的鲁棒优势更明显。

#### `dist` —— 到谷底的距离

**操作**：$\sqrt{\theta_1^2+\theta_2^2}$，衡量离最优 $(0,0)$ 还有多远。**输入**：`theta`。**输出**：标量，比赛记分牌。

---

### 步骤 2：五款优化器

#### GD（朴素梯度下降）

```python
theta = theta - lr * g
```

**操作**：$\theta \leftarrow \theta - \alpha g$——§5.3.6 的原始公式，一把尺子量所有方向。**可调参数**：`lr`。在病态地形上，它对 $\theta_2$（梯度 200 倍大）极易冲过头（回合二直接发散），对 $\theta_1$（梯度小）挪不动——走之字。

#### Momentum（动量）

```python
v = beta * v + g
theta = theta - lr * v
```

**操作**：维护速度 `v`（历史梯度的指数滑动平均，$\beta=0.9$），更新用 `v` 而非 `g`——**惯性在平缓方向攒速、陡峭方向缓冲**。这就是为什么回合一它 200 步精确到谷底：Nesterov/加速梯度的力量。
**可调参数**：`beta=0.9` 惯性大小。调 `0.99`——记忆更长、更冲；调 `0.5`——几乎无惯性。

#### Adagrad（自适应梯度）

```python
E = E + g**2
theta = theta - lr * g / (np.sqrt(E) + eps)
```

**操作**：`E` **累加**每个参数历史梯度的平方；更新用 $g/(\sqrt{E}+\epsilon)$——**梯度平方大的参数步长被压小，小的被放大**（逐坐标自适应）。
**可调参数**：`eps` 防除零。**软肋**：`E` 只增不减，步长随时间趋近 0——两个回合里它都落后，正是这个"账本只增"的毛病。

#### RMSprop（滑动平均账本）

```python
E = 0.9 * E + 0.1 * g**2
theta = theta - lr * g / (np.sqrt(E) + eps)
```

**操作**：和 Adagrad 唯一区别是 `E` 从"累加"改成"滑动平均"（$0.9$ 旧 + $0.1$ 新）——**账本不再只增不减，步长不会死**。
**可调参数**：`0.9` 是衰减系数（§5.6.6 的 $\beta$）。这是辛顿 2012 年课堂讲义里的算法——没发论文，却改变了世界。

#### Adam（自适应矩估计）

```python
m = b1 * m + (1 - b1) * g                       # 一阶矩 (动量)
E = b2 * E + (1 - b2) * g**2                    # 二阶矩 (滑动账本)
theta = theta - lr * (m / (1 - b1**t)) / (np.sqrt(E / (1 - b2**t)) + eps)
```

**操作**：Adam = Momentum 的 `m`（一阶矩）+ RMSprop 的 `E`（二阶矩）+ **偏差校正**（`1 - b1**t`、`1 - b2**t` 修正训练初期矩估计偏零）。
**可调参数**：`b1=0.9`、`b2=0.999`、`eps=1e-8`——**这就是 `torch.optim.Adam` 的默认超参**。回合二它和 RMSprop 一起幸存于大学习率，正是鲁棒性的体现。

## 实验台：让锦标赛更有层次

1. **看"之"字**：画 $J$ 的等高线 + 各优化器轨迹——回合一里 GD 在椭圆上走锯齿，Momentum 斜着滑下去，自适应方法在早期大步后期钝化。**一次可视化，看懂全部 §5.6。**
2. **改病态程度**：系数改 `2000`——GD 的之字更惨，自适应方法的鲁棒优势更大。
3. **加梯度噪声（模拟 SGD/mini-batch）**：给 `g` 加 `rng.normal(0, 0.5, 2)`——自适应方法在有噪声下依然稳，GD 更难收敛。**这预告了 §5.6.2 的 SGD。**
4. **对照 torch.optim**：用 `torch.optim.Adam/RMSprop/SGD(momentum=0.9)` 解同一问题，结果一致——**本脚本就是 PyTorch 优化器的裸核**。

**对应数学**：这张锦标赛表，就是主线 §5.6 家族谱系表的数值版——**数据轴（GD/SGD/mini-batch）决定梯度质量，步长轴（Momentum/Adagrad/RMSprop/Adam）决定步长智慧**；而两个回合合起来，是对"自适应方法为什么成为默认"最诚实的回答：**不是因为它更快，而是因为它更稳、更不用你操心学习率。**
