## 第一步：Toy Model —— 五个下山者的全家福

你已经是一个经验丰富的下山者了（§5.3.6 那节学的）。但这一次，山有脾性：**它在两个方向上"胖瘦不一"**——沿 $x_1$ 方向平缓如原野，沿 $x_2$ 方向陡峭如悬崖。这样的地形叫**病态 (ill-conditioned)**，等高线是一族被压扁的椭圆，而不是圆。

你站在山腰，面前站着五个同行，各自有一套下山策略：

1. **朴素者（GD）**：每一步都朝最陡方向走固定的一步。结果——它在悬崖方向上冲过头、在原野方向上挪不动，**走成一条锯齿状的"之"字**，半天到不了谷底。
2. **惯性者（Momentum）**：不仅看现在的坡度，还记得**上一步的方向**，像滚雪球一样攒起惯性。它不再那么摇摆，斜着滑下坡，快多了。
3. **记账者（Adagrad）**：给每个方向单独记一笔"以前走过多陡"的账——**走得多陡的方向，自动迈小步；走得少的方向，自动迈大步**。它开始懂得"因地制宜"。
4. **滑动平均者（RMSprop）**：记账者有个毛病——账越记越大，步子越迈越小，最后几乎走不动（学习率衰减到零）。RMSprop 换成**滑动平均的账本**（记最近的，忘掉远古的），步子不会死。
5. **全能者（Adam）**：把惯性者（动量的"速度"）和滑动平均者（RMSprop 的"步长"）**合二为一**，还加了偏差校正。它快、稳、几乎不用调参——**今天深度学习里 `optimizer.step()` 的默认名字，就是它。**

你看着这五个同行下山，发现一个惊人的规律：**它们做的是同一件事（朝低处走），区别全在"每一步怎么决定步长和方向"。** 深度学习训练的本质，就是选一个下山者，让它在损失面的丘陵上走到够低的谷底。现在问一个"浅到可笑"的问题：**这五种策略各自的更新公式长什么样？为什么自适应方法（Adagrad/RMSprop/Adam）能驯服病态地形？** 该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：深度学习的优化，为什么需要"专门"的方法

先把基调定住。教材 §5.6 的开篇只有三句话，但句句是地基：

**"优化在深度学习中至关重要，因为目标是最小化（有时最大化）损失函数；损失函数衡量预测与实际值的差距；通过优化它，我们确保模型对新数据泛化良好。"**

三句话三层意思：
1. **目标**：最小化损失 $L(\theta)$——衡量模型预测与真实值的差距（均方误差、交叉熵）。
2. **手段**：用优化方法把 $L$ 压下去。
3. **目的**：**泛化 (generalization)**——$L$ 在训练集上下降，是为了让模型在**未见数据**上也表现好。

**撞墙点**：为什么深度学习的优化不能直接用 §5.3-5.4 那些经典方法？三个理由：
- **非凸**（§5.4）：损失面是深不见底的丘陵，任何"保证全局最优"的经典方法都不适用。
- **大规模**（§5.5）：十亿参数、万亿次计算，每步都要"贵且快"。
- **数据是随机样本**（§5.3.7）：真实梯度算不起，只能用 mini-batch 估计。

所以深度学习需要一整套**专属优化器**——它们全都是"梯度下降 + 针对上述三个难题的修补"。§5.6.1 到 §5.6.7 就是这套修补的七件套：**BGD → SGD → Momentum → Adagrad → RMSprop → Adam**。

### 二、一张优化器家族谱系表

把七个成员放进一张表，先看全景，后面每节逐个拆解：

| 优化器 | 更新核心 | 解决什么 | 主要问题 |
|---|---|---|---|
| BGD（§5.6.1） | 全部数据的精确梯度 | 精确稳定 | 大数据下太慢、每步全扫 |
| SGD（§5.6.2） | 单个样本梯度 | 快、能跳出局部 | 噪声大、震荡 |
| mini-batch | 小批梯度 | 速度与稳定折中 | 深度学习事实标准 |
| Momentum（§5.6.4） | 加惯性 $v=\beta v+g$ | 抑制震荡、加速 | 惯性可能冲过头 |
| Adagrad（§5.6.5） | 历史梯度平方累加 | 给陡峭方向自动小步 | 学习率衰减到零 |
| RMSprop（§5.6.6） | 梯度平方滑动平均 | 修复 Adagrad 的死亡 | 需要调 $\beta$ |
| Adam（§5.6.7） | 动量 + 自适应 + 校正 | 快、稳、免调参 | 理论收敛性存疑 |

> **深度学习优化器家族**
>
> 物理含义：全部是"沿负梯度下降"的变奏——区别在于每步如何利用"历史梯度"来改进方向与步长，以应对非凸、大规模、随机数据三个难题。
>
> **统一骨架**：$\theta_{t+1} = \theta_t - \alpha \cdot \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}$
>
> - BGD/SGD/mini-batch：决定"梯度怎么估"（全量 / 单样本 / 小批）
> - Momentum：$\hat{m}_t$ 加入"惯性"（历史梯度的指数滑动平均）
> - Adagrad/RMSprop/Adam：$\hat{v}_t$ 是"自适应步长"（历史梯度平方的累加或滑动平均）
> - Adam = Momentum 的 $\hat{m}_t$ + RMSprop 的 $\hat{v}_t$ + 偏差校正
>
> **统一目标**：$\min_\theta L(\theta)$，$L$ 为损失函数，$\theta$ 为全部参数——优化保证 $L$ 下降，泛化保证下降有意义。

**每个符号的含义逐一解释：** $\theta_t$ 是第 $t$ 步参数；$\alpha$ 是学习率；$m_t$ 是动量项（一阶矩估计）；$v_t$ 是自适应项（二阶矩估计，梯度平方的滑动平均）。**注意：这个统一骨架里，SGD 对应 $m=g$、$v=1$；Momentum 对应 $m$ 有惯性、$v=1$；RMSprop 对应 $m=g$、$v$ 滑动平均；Adam 是两者兼有。**

### 三、为什么"自适应步长"是这节的主角

整个 §5.6 的进化主线只有一条：**怎么让每一步的步长更聪明。**

- **BGD/SGD**：所有方向共用**同一个**学习率 $\alpha$——在病态地形（椭圆等高线）上，这对陡峭方向太大、对平缓方向太小，于是走"之"字。
- **Momentum**：用"历史速度"平滑方向，让之字变直——但它仍用统一的步长。
- **Adagrad/RMSprop/Adam**：**每个参数单独配一个学习率**——历史梯度平方大的参数（陡峭方向）自动小步，历史梯度平方小的参数（平缓方向）自动大步。这直接治好了病态地形的"之"字病。

这个"逐参数自适应步长"的思想，是深度学习优化器最伟大的工程贡献之一——**Adam 之所以成为默认，就是因为它把"动量"（管方向）与"自适应"（管步长）都做到了最好。**

### 四、一张地图：从 BGD 到 Adam 的进化逻辑

```text
GD（§5.3.6，一把尺子量所有方向）
 ├─ 数据维度：BGD（全数据）→ mini-batch → SGD（单样本）【§5.6.1-5.6.2】
 └─ 步长维度：固定 α → Momentum（加惯性）【§5.6.4】
                → Adagrad（累加账本）【§5.6.5】
                → RMSprop（滑动账本）【§5.6.6】
                → Adam（惯性 + 账本 + 校正）【§5.6.7】
```

两条进化轴：**数据轴**（用多少数据算梯度）与**步长轴**（怎么决定每步多大）。每一个新优化器，都是在某一轴上更聪明一点。**你读懂了这张地图，就读懂了整个深度学习训练优化的全部脉络。**

## 第三步：DL 桥接

**§5.6 就是深度学习训练的"控制面板"——这一节本身和 DL 是同一个东西。** 你在训练任何 PyTorch 模型时写的：

```python
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
```

那一行，就是 §5.6.7 的公式。换成 `SGD` 就是 §5.6.2，换 `RMSprop` 就是 §5.6.6。**"优化方法"不是深度学习的附属品，它就是训练本身。** 而这三句话——"最小化损失""衡量差距""泛化"——正是你在 Ch04 学损失函数、在 Ch01-02 学模型结构时，所有数学最终汇聚的地方。

**对后续各节的地图**：§5.6.1（BGD）给你"全量"的基准；§5.6.2（SGD）给你"随机"的威力；§5.6.4-5.6.7（Momentum/Adagrad/RMSprop/Adam）给你"自适应"的进化。**学完这一节，你就拥有了把任何训练代码里的 `optimizer.step()` 翻译成数学公式的能力。** 具体如何用一段代码让五款优化器同台竞技、看它们在病态地形上的收敛差距，见《代码.md》。
