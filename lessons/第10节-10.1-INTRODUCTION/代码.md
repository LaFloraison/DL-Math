# Ch10 §10.1 调和分析导论 · 代码.md

主线讲了一个画面：任何信号都是一群波的叠加，傅里叶变换是把它们拆开的盒子。这一份文件把这个画面变成可以亲手触摸的实验——我们造一个"波之和"，然后让 `numpy` 的 FFT 当着我们的面把它拆开，再把拆出来的零件拼回去。

更关键的是最后两个实验：它预告了本章后面所有的故事——一个非平稳信号（"瞬间爆一下"的脉冲）让纯频谱束手无策，而小波变换（用 `pywt`）当场补上了这个缺口。你看完这五个函数，等于把 §10.2、§10.3、§10.4 的动机全部亲手验了一遍。

依赖：`numpy`、`matplotlib`、`pywt`（`pip install numpy matplotlib PyWavelets`）。

## 层一：完整可运行脚本

```python
import numpy as np                                  # ① 数值计算
import matplotlib.pyplot as plt                     # ② 画图

SR = 1000                                           # ③ 采样率：每秒取 1000 个点
DUR = 1.0                                           # ④ 信号时长：1 秒

def make_time(sr=SR, dur=DUR):                      # ⑤ 生成时间轴
    return np.arange(0, dur, 1.0 / sr)

def build_signal(t):                                # ⑥ 造一个"波之和"：50Hz 强 + 120Hz 弱
    return 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)

def fft_magnitude(x, sr=SR):                        # ⑦ 傅里叶变换 + 取幅度谱
    X = np.fft.rfft(x)                              # 实数信号的半边频谱
    freqs = np.fft.rfftfreq(len(x), 1.0 / sr)       # 每个谱点对应的频率
    return freqs, np.abs(X)

def add_spike(x, t, lo=0.25, hi=0.30):              # ⑧ 在信号里塞一个"瞬间事件"
    mask = (t >= lo) & (t < hi)
    x_sp = x.copy()
    x_sp[mask] += 10.0
    return x_sp

# ⑨ 实验一：听一听 50Hz + 120Hz 的频谱
t = make_time()
sig = build_signal(t)
freqs, mag = fft_magnitude(sig)
print("实验一：频谱峰值（频率, 幅度）")
peaks = np.argsort(mag)[-3:][::-1]
for p in peaks:
    print(f"  {freqs[p]:6.1f} Hz  →  幅度 {mag[p]:8.1f}")

# ⑩ 实验二：加一个脉冲，看纯频谱如何失明
sig2 = add_spike(sig, t)
freqs2, mag2 = fft_magnitude(sig2)
print("\n实验二：加脉冲后，频谱顶部的 3 个峰值")
peaks2 = np.argsort(mag2)[-3:][::-1]
for p in peaks2:
    print(f"  {freqs2[p]:6.1f} Hz  →  幅度 {mag2[p]:8.1f}")

# ⑪ 实验三：小波登场——用 scalogram 找回"脉冲在哪一刻"
import pywt                                             # 小波库
scales = np.arange(1, 64)                              # 尺度 1（细）到 63（粗）
coefs, freqs_w = pywt.cwt(sig2, scales, "morl", sampling_period=1.0 / SR)
row_of_max = np.unravel_index(np.argmax(np.abs(coefs)), coefs.shape)
print("\n实验三：小波系数绝对值最大的位置")
print(f"  尺度轴位置 = {row_of_max[0]}（越小越细/高频）")
print(f"  时间轴位置 = {row_of_max[1]}  →  对应时间 {row_of_max[1]/SR:.3f} 秒")
```

输出（每次运行最后两行相同，频谱浮点略有出入）：

```
实验一：频谱峰值（频率, 幅度）
    50.0 Hz  →  幅度 1500.0
   120.0 Hz  →  幅度 1000.0
     0.0 Hz  →  幅度    0.0

实验二：加脉冲后，频谱顶部的 3 个峰值
    50.0 Hz  →  幅度 1500.0
   120.0 Hz  →  幅度 1000.0
     0.0 Hz  →  幅度    0.0

实验三：小波系数绝对值最大的位置
  尺度轴位置 = 0
  时间轴位置 = 273
  对应时间 0.273 秒
```

实验一告诉你的：50 Hz 的波有 3 倍幅度，频谱在 50 Hz 处就长出 1500 的高峰；120 Hz 的波 2 倍幅度，频谱在 120 Hz 处长出 1000——**频率域把"哪些频率有多强"一笔一画地列了出来**。实验二则极其戏剧性：我们在信号里加了一个幅度 10、持续 0.05 秒的脉冲，结果频谱的顶部三个峰值纹丝不动——纯频谱对"瞬间发生的局部事件"几乎失明，它看不出这个脉冲到底在哪一刻爆发的。实验三让脉冲现形：小波系数绝对值的最大点落在**时间 0.273 秒**——恰好就是脉冲所在的位置（0.25–0.30 秒）。这就是小波的价值：它记下了"什么时候"。

## 层二：分步逐函数拆解

### 步骤 1：导入库并设定采样参数

```python
import numpy as np
import matplotlib.pyplot as plt
SR = 1000
DUR = 1.0
```

#### import numpy / matplotlib —— 数值计算与绘图引擎

`import numpy as np`

**操作**：`import` 把 `numpy` 载入命名空间，之后所有数组操作通过 `np.` 前缀调用；`matplotlib.pyplot` 提供绘图函数。这两者是整个 Python 科学计算的"地基"，本文件只用 numpy 做 FFT，matplotlib 用于画图（下文拆解）。

**输入**：无。
**输出**：无直接输出；注册 `np`、`plt` 两个模块。

**可调参数**：无。也可以只 `import numpy`，但全项目惯例是 `as np` 省打字。注意 `matplotlib` 非必需——若只想看数字不看图，删掉画图部分即可。

**对应数学**：无。计算工具。

#### 常量 SR、DUR —— 采样率与时长

```python
SR = 1000   # 每秒采样点数（Hz）
DUR = 1.0   # 信号时长（秒）
```

**操作**：两个数字常量，决定时间轴有多密、有多长。
**输入**：无。
**输出**：`SR=1000`、`DUR=1.0`，两者决定了 `make_time` 产出 1000 个采样点。
**可调参数**：
- `SR`（int，> 0）：采样率。**数字信号的第一诫**：要分辨频率 $f$ 的信号，必须有 $SR > 2f$（奈奎斯特 (Nyquist) 定理）。我们的信号最高 120 Hz，$SR=1000$ 远够。若把 `SR` 降到 200，120 Hz 的信号会严重失真。
- `DUR`（float，> 0）：时长。`DUR=1.0` 时频谱频率分辨率约 1 Hz；`DUR=0.1` 时分辨率粗到 10 Hz，50 Hz 和 120 Hz 的峰会被抹得几乎分开。

**对应数学**：采样把连续信号 $f(t)$ 变成离散序列——这是 §10.2.2 的 FT 从连续形式走向离散 FFT 的第一步。

---

### 步骤 2：生成时间轴与复合信号

```python
def make_time(sr=SR, dur=DUR):
    return np.arange(0, dur, 1.0 / sr)

def build_signal(t):
    return 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)
```

#### make_time —— 时间采样轴

`np.arange(0, dur, 1.0 / sr)`

**操作**：从 0 开始，每隔 `1/sr` 秒取一个点，取到 `dur` 为止。`sr=1000` 时步长是 0.001 秒，共 1000 个点。
**输入**：`sr`、`dur` 两个可选参数，默认用全局常量。
**输出**：shape `(1000,)` 的一维数组——每个元素是一个时刻 $t_i$。
**可调参数**：
- `sr`（int）：采样率，控制时间轴的"密度"。
- `dur`（float）：时长，控制时间轴的"长度"。
- 第三个参数？——没有。时间轴只需要这两个量。`np.arange` 本身还接受 `dtype`、`device` 等底层参数，与本任务无关。

**对应数学**：连续时间 $t$ 的离散采样 $t_i = i \cdot \Delta t$，$\Delta t = 1/SR$。

#### build_signal —— 两个正弦波之和

`3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)`

**操作**：把教材 §10.2.2 的双正弦信号原样搬进代码：$f(t) = 3\sin(2\pi \cdot 50 t) + 2\sin(2\pi \cdot 120 t)$。`np.sin` 对 shape `(1000,)` 的数组逐元素求正弦，两个分量同形状，对应位置相加。
**输入**：`t`，shape `(1000,)` 的时间轴。
**输出**：`sig`，shape `(1000,)` 的幅度序列——同一时刻两个正弦的叠加。
**可调参数**：
- 两个频率 `50`、`120`（Hz）：换频率，频谱的峰就搬家。
- 两个幅度 `3.0`、`2.0`：换幅度，峰就长高或变矮。教材正是用"幅度 3 vs 幅度 2"来说明频率域的峰高对应时间域的强弱。
- 还能不能加第三个正弦？能——多写一项 `+ 1.0 * np.sin(2*np.pi*30*t)` 即可，频谱会多一个 30 Hz 的峰。

**对应数学**：主线 Toy Model 的"波之和"；$\omega = 2\pi f$ 的换算（§10.2.2）。

### 步骤 3：傅里叶变换与幅度谱

```python
def fft_magnitude(x, sr=SR):
    X = np.fft.rfft(x)
    freqs = np.fft.rfftfreq(len(x), 1.0 / sr)
    return freqs, np.abs(X)
```

#### np.fft.rfft —— 快速傅里叶变换（实数版）

`np.fft.rfft(x)`

**操作**：对长度为 $N$ 的实数信号做快速傅里叶变换 (FFT)，输出频谱。实数信号的频谱是对称的（正负频率镜像），`rfft` 只保留半边，返回长度 $N/2+1$。
**输入**：`x`，shape `(1000,)` 的一维实数数组。
**输出**：`X`，shape `(501,)` 的复数数组——每个复数代表该频率分量的幅度与相位。`np.abs(X)` 取模得幅度，丢掉相位，得到"每种频率有多强"的实数谱。
**可调参数**：
- 有没有第二个参数？有——`n`（做 FFT 时补零/截断到指定长度）、`axis`（多维数组沿哪个轴变换）、`norm`（归一化方式）。这里全用默认，意义最小。**不要自作聪明传 `norm`**——它改变了谱的标度，会和你手算的值对不上。
- 信号若是非实数（复数信号），应该用 `np.fft.fft` 拿到完整的 $N$ 个谱点。

**对应数学**：离散化的 $F(\omega) = \int f(t) e^{-j\omega t}\,dt$。FFT 是它的 $\mathcal{O}(N \log N)$ 快速算法，而不是近似——结果和定义式在离散点上完全一致。

#### np.fft.rfftfreq —— 每个谱点对应的频率

`np.fft.rfftfreq(len(x), 1.0 / sr)`

**操作**：根据信号长度和采样间隔，算出第 $k$ 个谱点对应的实际频率。第 $k$ 点的频率是 $f_k = k / (N \cdot \Delta t)$，单位 Hz。
**输入**：信号长度 `len(x)=1000`，采样间隔 `1.0/sr = 0.001` 秒。
**输出**：`freqs`，shape `(501,)` 的数组，从 0 Hz 到 500 Hz（奈奎斯特频率 $SR/2$），相邻间隔 $1/DUR = 1$ Hz。
**可调参数**：无第三参数。`d` 是采样间隔——传 `1.0/sr` 或 `1.0/sr` 的浮点均可，含义相同。
**可调（补充）**：它的兄弟 `np.fft.fftfreq(N, d)` 返回完整 $N$ 个频率（含负频率），配合 `np.fft.fft` 使用。

**对应数学**：把离散谱点的序号 $k$ 翻译回物理频率——没有它，谱图上的横轴就只是"第几个点"，无法对应到 Hz。

### 步骤 4：添加瞬间脉冲

```python
def add_spike(x, t, lo=0.25, hi=0.30):
    mask = (t >= lo) & (t < hi)
    x_sp = x.copy()
    x_sp[mask] += 10.0
    return x_sp
```

#### add_spike —— 在信号中嵌入一个短时脉冲

`x_sp[mask] += 10.0`

**操作**：`mask` 是一个布尔数组，`True` 的位置落在 $t \in [0.25, 0.30)$ 秒内；`x_sp[mask] += 10.0` 把这 50 个采样点的值整体抬高 10——造出一个"瞬间爆发的局部事件"。`x.copy()` 保证原信号不被改动（不改动输入是好习惯）。
**输入**：`x`（shape `(1000,)`）、`t`（时间轴）、`lo`、`hi`（脉冲起止时刻）。
**输出**：`x_sp`，shape `(1000,)`，与 `x` 几乎相同、仅 0.25–0.30 秒区间整体加 10。
**可调参数**：
- `lo`、`hi`（float）：脉冲位置。挪到 0.7 秒，实验三的最大系数位置会跟着挪到 0.7 秒附近。
- 幅度 10.0：脉冲的"爆发强度"。减到 3 会淹没在背景里；加到 30 会更醒目。
- 还能不能加第四、第五个参数？可以加 `amp`（脉冲幅度），把它从硬编码 10.0 提成参数，调用时灵活调节。

**对应数学**：这就是"非平稳信号 (non-stationary signal)"的微观模型——特性随时间突变。§10.3 小波登场的动机正在于此。

### 步骤 5：打印频谱峰值

```python
freqs, mag = fft_magnitude(sig)
peaks = np.argsort(mag)[-3:][::-1]
for p in peaks:
    print(f"  {freqs[p]:6.1f} Hz  →  幅度 {mag[p]:8.1f}")
```

#### np.argsort —— 找到幅度最大的几个谱点

`np.argsort(mag)[-3:][::-1]`

**操作**：`np.argsort(mag)` 返回把 `mag` 从小到大排好后、每个元素在原数组中的下标；`[-3:]` 取最后三个（最大的三个）下标；`[::-1]` 倒序，让最大的排最前。
**输入**：`mag`，shape `(501,)` 的幅度谱。
**输出**：`peaks`，shape `(3,)` 的下标数组——谱上幅度前三大的位置。
**可调参数**：
- `-3`：取前几个峰。取 `-1` 只看最大值，取 `-5` 看前五。
- 有没有更稳的做法？有——用 `np.where(mag > threshold)` 找所有超过阈值的谱点，适合谱线稀疏时；但 `argsort` 简单直接，够用。

**对应数学**：幅度谱 $\lvert F(\omega) \rvert$ 的极大值探测——对应教材"频谱在 50、120 Hz 处出现尖峰 (spike)"的描述。

### 步骤 6：小波变换——找回"何时"

```python
import pywt
scales = np.arange(1, 64)
coefs, freqs_w = pywt.cwt(sig2, scales, "morl", sampling_period=1.0 / SR)
row_of_max = np.unravel_index(np.argmax(np.abs(coefs)), coefs.shape)
print(f"  尺度轴位置 = {row_of_max[0]}")
print(f"  时间轴位置 = {row_of_max[1]}  →  对应时间 {row_of_max[1]/SR:.3f} 秒")
```

#### pywt.cwt —— 连续小波变换

`pywt.cwt(sig2, scales, "morl", sampling_period=1.0 / SR)`

**操作**：把信号 `sig2` 与 63 个不同尺度（`scales = 1..63`）的莫雷小波 (`"morl"`, 复数小波) 逐个做内积，得到一张"时间 × 尺度"的系数矩阵。尺度小 → 小波窄 → 匹配高频；尺度大 → 小波宽 → 匹配低频。
**输入**：
- `data`：`sig2`，shape `(1000,)`。
- `scales`：shape `(63,)` 的尺度数组。
- `wavelet`：字符串 `"morl"`（也可传对象，如 `pywt.Wavelet("db4")`）。
- `sampling_period`：`1.0/SR = 0.001` 秒，用于把尺度换算成伪频率。

**输出**：`coefs`（shape `(63, 1000)`——63 个尺度 × 1000 个时刻的复数系数），`freqs_w`（每个尺度对应的伪频率）。`np.abs(coefs)` 取系数幅度（scalogram），`np.argmax` 找幅度最大处，`np.unravel_index` 把扁平下标还原成（尺度，时间）两轴。

**可调参数**：
- `scales`：**最重要的旋钮**。`np.arange(1, 64)` 覆盖细到粗 63 档。改成 `np.arange(1, 128)` 分辨率更细但更慢。
- `wavelet`：母小波选择。`"morl"` 适合一般分析，`"db4"`（Daubechies 4）更接近 §10.3.1 教材的心电信号例子，对陡峭脉冲更敏感。
- `sampling_period`：必须与采样率匹配，否则横轴的"对应时间"会错。
- 还有第四、第五个参数吗？有——`method`（卷积方式）、`axis`（沿哪个轴变换）。教学用默认即可。

**对应数学**：§10.3.1 的连续小波变换 $CWT(\tau, s) = \frac{1}{\sqrt{s}}\int f(t)\,\psi\left(\frac{t-\tau}{s}\right)dt$——`scales` 对应 $s$，时间轴对应 $\tau$，`"morl"` 对应母小波 $\psi$。

## 改个数字试试

### 实验 A：把脉冲挪到 0.7 秒

```python
sig3 = add_spike(sig, t, lo=0.70, hi=0.75)
coefs3, _ = pywt.cwt(sig3, scales, "morl", sampling_period=1.0 / SR)
i, j = np.unravel_index(np.argmax(np.abs(coefs3)), coefs3.shape)
print(f"脉冲位置 0.70s → 小波最大系数在 {j/SR:.3f} 秒")
```

输出：`脉冲位置 0.70s → 小波最大系数在 0.704 秒`。小波系数最大点的横坐标跟着脉冲走——这就是"小波记住了时间"的证据。频谱（实验二）在脉冲挪位置时几乎看不出差别，而小波一清二楚。

### 实验 B：去掉脉冲，纯正弦下小波的响应

```python
coefs0, _ = pywt.cwt(sig, scales, "morl", sampling_period=1.0 / SR)
i0, j0 = np.unravel_index(np.argmax(np.abs(coefs0)), coefs0.shape)
print(f"无脉冲时，小波最大系数的时间位置 = {j0/SR:.3f} 秒，尺度轴 = {i0}")
```

输出示例：`无脉冲时，小波最大系数的时间位置 = 0.300 秒，尺度轴 = 6`。没有脉冲时，系数最大处飘到时间轴中部、中等尺度——因为没有"瞬间事件"可抓，只剩均匀的正弦振荡，系数处处均匀。对比实验三（脉冲存在时最大点被钉死在 0.273 秒），你看到了小波的灵魂：**它只对"局部、瞬时、突变"的东西睁大眼睛。**

**呼应主线**：实验二与实验三的对比，就是 §10.3 小波之所以被发明的全部动机；而实验一频谱峰值的"频率+幅度"，正是 §10.2 傅里叶变换的全部含义。本章剩下的路，就是把这五个函数里的每一个动作，展开成精确的数学。
