## 第一组：概念检验

### 题 1：填一填

把下面的空格填上正确的术语（中英文均可）：

> 任何一个"正常"的连续信号，都可以被拆成一组不同频率的 ______ 的加权和。把信号从时间域翻译到频率域的工具叫 ______；它不仅告诉你"有哪些频率"，还告诉你"每个频率在什么时候出现"的工具叫 ______。时间域的卷积在频率域里等价于 ______。

**解答**：正弦波（$\sin$/$\cos$，即谐波/harmonic）；傅里叶变换 (Fourier transform, FT)；小波变换 (wavelet transform, WT)；逐点乘法。

**思路点拨**：这三句话就是 §10.1 的骨架。第二空与第三空的区别是本题的陷阱：很多人把"拆频率"笼统归给"傅里叶"，忘了"加上了时间定位"的小波才是专门为"频率在何时出现"而生的。关键词是**时间定位**。

### 题 2：判断并说明理由

> 一个信号的频谱在 50 Hz 处有一个 3 倍高的峰。小明据此断言：这个信号一定只包含 50 Hz 一种成分。

小明对吗？为什么？

**解答**：不对。频谱（幅度谱）只回答了"有哪些频率、每种多强"，它**不回答"这些频率什么时候出现"**。信号可能是一段 50 Hz + 一段 120 Hz 的拼接（非平稳），也可能是一个在 0.25 秒处爆发的脉冲叠加在 50 Hz 上——这两种情况下频谱的峰依然是 50 Hz 最高，但信号都"不止一种成分"。而且幅度谱丢掉了相位信息，两个频谱相同、波形完全不同的信号也可能存在。

**思路点拨**：答错的常见理由有两种：(a) 只记得"频谱=频率清单"，忘掉"非平稳"的可能；(b) 误以为幅度谱已经包含了全部信息——实际上谱有幅度和相位两半，幅度谱只是其一。本题提示了 §10.3 小波登场的必要性。

### 题 3：简答

> 为什么说"CNN 最底层的卷积核本质上在做调和分析"？用一句话说清这个论断的根据。

**解答**：卷积核在图像局部计算核与像素的乘积和，等价于探测该局部区域的频率成分——核本身的纹理（粗细、方向）决定了它对哪种频率最敏感，所以一组卷积核就是在探测一组不同频率、不同方向的"成分"，这正是调和分析"把复杂信号拆成频率成分"的动作。

**思路点拨**：注意本题要求**根据**而非记忆。根据是"卷积核的模式决定它敏感的频率"——这是主线 DL 桥接里 AlexNet 第一层学出伽柏状滤波器的结构原因，不是巧合。

## 第二组：计算实践

### 题 4：手算频率换算

一个信号包含 $f(t) = 5\sin(2\pi \cdot 100\, t) + 1.5 \sin(2\pi \cdot 350\, t)$。

1. 写出两个分量的角频率 $\omega$（rad/s）。
2. 若以 $SR = 800$ Hz 采样，哪个分量会出问题？为什么？

**解答**：
1. $\omega = 2\pi f$：100 Hz → $\omega = 200\pi$ rad/s；350 Hz → $\omega = 700\pi$ rad/s。
2. 350 Hz 的分量会出问题。奈奎斯特频率 (Nyquist frequency) 是 $SR/2 = 400$ Hz，350 Hz 尚未超过它，**理论上**还能采样；但 350 Hz 已经非常接近 400 Hz，在 $SR=800$ 下每个周期只采到约 2.3 个点，波形严重失真。若把频率提高到 450 Hz（超过 $SR/2$），就会发生**混叠 (aliasing)**——450 Hz 会被伪装成一个 350 Hz 的虚假分量。所以更稳妥的说法是：以 800 Hz 采样时，350 Hz 分量虽然合法但分辨率很差，最好提高采样率。

**思路点拨**：很多人答"350 Hz 超了奈奎斯特所以不能采"——不对，$350 < 800/2$，还在合法范围内。真正的边界是"频率 < SR/2"。本题考点是奈奎斯特判据 $f_{max} < SR/2$，以及"接近边界时质量变差"的工程直觉。

### 题 5：读谱（对应《代码.md》实验一）

你运行《代码.md》的脚本，`fft_magnitude` 输出了三行"频率 → 幅度"：

```
 50.0 Hz  →  幅度 1500.0
120.0 Hz  →  幅度 1000.0
  0.0 Hz  →  幅度    0.0
```

1. 为什么 50 Hz 的幅度（1500）恰好是 120 Hz（1000）的 1.5 倍？
2. 为什么谱上还有 0 Hz 这一项，且幅度为 0？
3. 若把 120 Hz 的幅度从 2.0 改成 4.0，谱会变成什么？重新跑一遍逻辑，给出预期输出。

**解答**：
1. 因为时间域的幅度就是频率域峰高的来源：$3\sin(2\pi\cdot50t)$ 的幅度 3 对应谱峰 1500，$2\sin(2\pi\cdot120t)$ 的幅度 2 对应谱峰 1000，$1500/1000 = 3/2$。`rfft` 的默认缩放让峰高 = 幅度 × $N/2$（$N=1000$，故 $3\times500=1500$、$2\times500=1000$）。
2. 0 Hz 对应直流 (DC) 分量——信号在一个周期内的平均值。$3\sin$ 和 $2\sin$ 的平均值都是 0，所以直流分量为 0。若信号整体抬高（如全部加 2），0 Hz 的峰就会长高。
3. 预期输出：50 Hz → 1500 不变；120 Hz → 2000（$4\times500$）；0 Hz → 0。频谱里只有这两个峰，其余位置接近 0。

**思路点拨**：题 1 考"峰高与幅度的正比关系"；题 2 考直流分量。常见错误是把幅度谱误读成"有多少个分量就有多少个峰"——其实**谱峰对应频率分量，而分量数量取决于信号的构成**，两个正弦就是两个峰（外加它们频谱上各自的正负频率镜像，`rfft` 只显示正频半边）。

### 题 6：脉冲定位（对应《代码.md》实验三）

```python
coefs, _ = pywt.cwt(sig2, np.arange(1, 64), "morl", sampling_period=0.001)
i, j = np.unravel_index(np.argmax(np.abs(coefs)), coefs.shape)
```

`coefs` 的形状是 `(63, 1000)`。运行后 `j` 打印出 273。

1. `j = 273` 这个数字代表什么？对应多少秒？
2. 若脉冲在信号里的位置是 0.25–0.30 秒，为什么最大系数落在 0.273 秒而不是恰好在 0.25 秒？
3. 为什么 `np.argmax(np.abs(coefs))` 不用 `np.max`？

**解答**：
1. `j` 是系数矩阵的列下标（时间轴位置），对应时刻 $j \times \Delta t = 273 \times 0.001 = 0.273$ 秒。
2. 脉冲是 0.25–0.30 秒的一段，小波系数对整段都有响应，而脉冲的"能量中心"约在区间中段（0.275 秒附近）；加上采样离散与母小波的时宽，峰值落在 0.273 秒是合理近似——它不会"恰好"钉在区间起点。
3. `np.argmax` 返回最大值的**位置**（下标），`np.max` 返回最大值的**数值**。我们要找的是"脉冲在哪"——位置，不是数值。二者经常被混淆。

**思路点拨**：题 1、2 考"小波系数矩阵的轴代表什么"；题 3 考 numpy 基本功。这里最容易犯错的是把 `argmax` 当 `max` 用——"我明明要最大的数，为什么输出 273？"因为你要的是那个数在哪。

## 第三组：DL 延伸

### 题 7：诊断一个 CNN 实验

研究员训练了一个 CNN，第一层卷积核学到的是：12 个只对**水平方向边缘**敏感、但频率从细到粗覆盖的核；其余核全是低频平滑核。他用小波变换分析了几个输入图片的局部区域，发现这些图片里几乎没有水平高频结构。

1. 用调和分析的眼光判断：这个第一层的设计有什么问题？
2. 他应该怎么调整？

**解答**：
1. 问题在于**覆盖不均**：12 个核挤在"水平 + 高频"这一小片频率-方向区域，而输入里根本缺少水平高频——这 12 个核近乎冗余（都在探测一种不存在的成分）；同时"垂直方向"和"低频"区域几乎无人值守，卷积层没有学会探测这些真正存在的成分。
2. 调整方向：让第一层的核在频率-方向平面上铺开——高频、中频、低频都要有，水平/垂直/对角方向都要覆盖；或者先用小波分析一批输入图片，统计它们真实的频率-方向分布，再据此初始化或引导卷积核的数量分配（这就是"让调和分析指导 CNN 设计"的现代思路，如谱池化、小波卷积的出发点）。

**思路点拨**：本题考的是主线 DL 桥接的核心论断——**卷积核=频率探测器，一组好核应该在频率平面上均匀布点**。答错的方向是"核学错了"或"分辨率不够"——真正的病灶是**探测频率和输入频率错位**。把"频率成分的分布"换成"该听哪些乐器"，就好理解了：乐队没有低音，你却派了 12 个低音提琴手，何不派几个去吹号？

### 题 8：选工具

给下面三个任务各选一个本章的工具（FT / WT / 卷积定理 + FFT），并一句话说明理由：

- (a) 判断一段纯音频里是否混入了某个 3 kHz 的干扰音。
- (b) 在心电图上定位一次"早搏"发生的精确时间。
- (c) 让一个 512×512 的卷积层在大卷积核下算得快一些。

**解答**：
- (a) **FT**：音频平稳、频率固定，谱上一个 3 kHz 的峰就足够确认干扰。
- (b) **WT**：早搏是非平稳的瞬间事件，需要"何时"的定位，频谱做不到。
- (c) **卷积定理 + FFT**：时间域卷积换成频率域逐点相乘再逆变换，大核时显著更快。

**思路点拨**：三题的判据分别是"信号平稳→FT""瞬间局部→WT""卷积→FFT 换域"。常见混淆是把 (b) 选成 FT——纯频谱在实验二里已经演示过：瞬间事件几乎不改变频谱峰值的位置。记住那个判据：**要"何时"就找小波。**
