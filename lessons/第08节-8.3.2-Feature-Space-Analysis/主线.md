# §8.3.2 特征空间分析 —— 看网络心里在想什么

## 第一步：Toy Model —— 一间被自动整理的艺术品仓库

想象一间巨大的仓库，地上堆着几百万件艺术品——油画、素描、雕塑、陶器……乱七八糟地堆在一起。这时来了一位神奇的**仓库管理员**，他有一个癖好：每收到一件艺术品，都把它放到一个特定的货架上，而且摆放有严格规律——**越相似的东西，放得越近；越不同的东西，放得越远。**

几个月后，奇迹出现了。仓库不再是乱堆的：所有猫的画像聚在一个角落，所有风景画聚在另一个角落，不同风格的陶器各自成区。你走进仓库，甚至不用看标签，光看"什么东西和什么东西挨在一起"，就能判断这位管理员对艺术品的理解有多深——如果他把所有"忧郁"的作品放在一起、把"欢快"的放在另一边，说明他理解了超越题材的风格；如果他把猫和狗混在一起，说明他的分类能力有限。

现在把仓库管理员换成一个神经网络。网络的前向传播，就是一件艺术品（一张输入图片）被逐层搬运、最终放到某个"货架"上的过程。而这个"货架"，就是**特征空间 (feature space)**。

具体地说：网络的第一层看见的是"边缘"（一张图最原始的特征），中间层看见的是"形状"（边缘组合成轮廓），最后一层看见的是"对象"（轮廓组合成猫、狗、车）。每一层的输出，都是把输入重排成一个"更接近本质"的表示。到最后一层，每个输入都被放在高维特征空间里的一个点——**这个点之间的距离，就是网络对"这些输入有多相似"的判断。**

直觉已经到位：**特征空间的距离结构，是网络内心世界的直接投影——同类聚团、异类分离，就是网络"学会了分类"的物理证据。** 但"距离"和"聚类"要怎样精确成能检查的数学？我们如何既看整体分布、又抓单个错误样本？该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：像素里的相似，不是语义里的相似

先做一个思想实验，让你撞上特征空间的"必要性"。

给你一张猫的图片和一张狗的图片，它们在像素层面差别巨大——像素值的分布几乎没有任何重叠。再给你两张同一只猫的图片：一张是它在阳光下的照片，一张是它在黑暗里的照片。这两张"同一只猫"的图片，在**像素层面**的差异，甚至可能比"猫 vs 狗"的差异还要大（光照变了，每个像素都变了）。

现在问：分类器该拿什么做依据？如果它直接在像素空间里用欧氏距离判断"谁和谁像"，它会被光照骗得团团转——把"暗处的猫"错认成"暗处的狗"。**像素空间里的距离，根本承载不了"语义上的相似"。**

所以网络必须做一件事：把像素空间**重新组织**成一个新空间——特征空间——在这个空间里，"相似"由语义定义而不是由像素定义。同一个对象的不同照片（不同光照、不同角度、不同遮挡）应该被映射到特征空间里的**邻近位置**，而不同对象即使像素相似也该被拉开。这个"重排"，正是神经网络逐层学习做的事情：**每一层都在把输入改写成一个更接近"语义几何"的表示。**

### 二、定义：特征映射与特征空间

把"重排"精确化。

> **特征映射与特征空间**
>
> 物理含义：神经网络把高维输入 $x$ 逐层变换成低维特征向量 $z$，$z$ 所在的空间即特征空间——其中点与点的距离反映"语义相似度"。
>
> $$z = f_\theta(x), \qquad x \in \mathbb{R}^n,\ \ z \in \mathbb{R}^d,\ \ d \ll n$$
>
> - $x$：输入（如 $28\times28$ 图像展平为 $n = 784$ 维向量）
> - $f_\theta$：网络（前 $k$ 层）学到的非线性映射，$\theta$ 是权重
> - $z$：特征向量——输入在特征空间中的坐标
> - $d$：特征维度（通常几十到几千），远小于输入维度 $n$
>
> **特征空间距离（欧氏）**：
> $$\|z_1 - z_2\| = \sqrt{\sum_{i=1}^{d} (z_{1,i} - z_{2,i})^2}$$
> 语义越相似的输入，$z$ 距离越小；语义越不同，距离越大

每个符号逐一解释。$x$ 是原始输入——一张图、一句话、一条基因序列，高维且充满与语义无关的噪声（光照、角度、笔迹）。$f_\theta$ 是网络的前若干层，它的每一次矩阵乘法和非线性激活，都是在"拧"这个空间：把无关的变化方向压扁、把语义相关的方向拉开。$z$ 是重排后的坐标——网络认为的"本质位置"。$d \ll n$ 是流形假说（§8.2.1）在特征端的体现：网络把 $n$ 维输入压缩到 $d$ 维"本质"表示。

那条距离公式，就是"判断相似性"的尺子。注意它在数学上是最朴素的欧氏距离——而这正是我们撞墙后要警惕的地方：**欧氏距离只在特征空间被学得"好"时才对应语义**。如果网络没学好，$z$ 空间的邻近邻居可能毫无语义；如果网络学得好，$z$ 空间的距离才真的等于"语义距离"。**特征空间的分析，分析的不是那个 $d$ 维几何，而是网络在 $d$ 维几何里刻下的语义结构。**

边界声明：**欧氏距离是"平直"的尺子，而特征空间未必平直。** 数据的流形可能是弯曲的（§8.2.3 度量张量正是为弯曲空间准备的尺子）；真实语义距离可能应该用测地距离或学到的度量来衡量，而不是直线。欧氏距离是工程上最常用的**默认尺子**，但当你看到"特征空间聚类"结论时，记住它默认了平直假设——这在流形明显弯曲时可能误导。

### 三、展开：一个完整的前向计算，看特征怎么被"摆"到正确位置

用教材的 2-2-1 小网络，把一个具体数字算到底。任务：把两类点分开——类 A 聚集在 $[2,2]$ 附近，类 B 聚集在 $[-2,-2]$ 附近。

网络结构：输入层 2 神经元（$x_1, x_2$），隐藏层 2 神经元 + ReLU，输出层 1 神经元 + sigmoid。权重：$W_1 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$（恒等），$b_1 = 0$，$W_2 = [1, 1]$，$b_2 = 0$。

取类 A 的一个点 $x = [2, 2]$ 走前向：

**隐藏层**（特征空间！）：
$$z_1 = W_1 x + b_1 = \begin{pmatrix}1&0\\0&1\end{pmatrix}\begin{pmatrix}2\\2\end{pmatrix} = \begin{pmatrix}2\\2\end{pmatrix}$$
$$h = \mathrm{ReLU}(z_1) = [2, 2] \quad (\text{正值，原样通过})$$

**输出层**：
$$\hat y = \sigma(W_2 h + b_2) = \sigma(1\cdot 2 + 1\cdot 2) = \sigma(4) = \frac{1}{1 + e^{-4}} \approx 0.982$$

$\hat y \approx 0.982$ 表明"几乎确定是类 A"。注意那个 $h = [2,2]$：它就是 $x$ 在**隐藏层特征空间**里的坐标。类 A 的点都在 $[2,2]$ 附近，映射后也在特征空间 $(2,2)$ 附近——**同类聚团**；类 B 的点在 $[-2,-2]$，映射后特征空间距离
$$\|h_A - h_B\| \approx \|[2,2] - [-2,-2]\| = \|[4,4]\| = 4\sqrt{2} \approx 5.66$$
足够大——**异类分离**。而这个网络为什么能分离？因为 $W_1 = I$ 把"坐标位置"直接保留成特征，输出层用"特征和"（$1\cdot h_1 + 1\cdot h_2$）决定类别：类 A 的和是 $4$（sigmoid 后 0.982），类 B 的和是 $-4$（sigmoid 后 0.018）。**整个分类，就是特征空间里一个线性分类器的"读心术"。**

### 四、展开：看特征空间的四件事

有了"特征空间 = 语义坐标"这个框架，分析网络就有了四件标准动作（具体实现见《代码.md》）：

**看整体聚类——t-SNE / UMAP。** 特征空间是几十维的，人眼看不见。t-SNE、UMAP 把高维特征压到 2D/3D，尽量保持局部邻接关系，让我们"看"到聚类：同类是否聚团、异类是否分离、类别之间是清晰边界还是交叠。

**量类间分离。** 计算不同类簇中心的距离（§8.2.1 习题的 $\rho = d_{AB}/(s_A+s_B)$）。分离大 → 网络能区分；重叠 → 模型在这些类上必然出错。

**找错误样本。** 把**错分样本**在特征空间里标出来——它们通常落在类簇的边界或两个类重叠的区域。看"错误的点长什么样"，就知道模型在哪些输入上判断力弱（例如把"潦草的 7"认成"1"）。

**测对抗鲁棒性。** 对抗样本（精心构造的、人眼几乎不变却让模型错判的输入）在特征空间里往往**远离真实样本**——它们钻了"模型判断边界"的漏洞。一个稳健的模型，真实样本与对抗样本在特征空间里应该离得远；分析两者距离，能评估模型面对攻击的脆弱性。

这四件事，就是特征空间分析在工程里的全部日常。它们共同回答一个问题：**网络心里的"语义地图"长什么样、哪里画对了、哪里画错了。**

## 第三步：DL 桥接

特征空间分析在真实深度学习里无处不在，最经典的应用：

- **可视化诊断**：训练分类器后把验证集投影到 t-SNE/UMAP——如果两个类严重重叠，说明网络没学会区分它们的特征，需要更深的层或更强的正则化。这是每个工程师都做过的日常检查。
- **迁移学习判断**：如果预训练模型的特征空间把同类聚得极紧、异类分得极开，说明学到的特征是"可迁移的"——可以冻结这些层、只训练最后一层完成新任务（fine-tuning 的理由）。
- **对抗防御**：分析真实样本与对抗样本在特征空间的距离，指导防御策略——例如"输入在特征空间的邻域里做平滑/去噪"（对抗训练的原理）。
- **度量学习**：对比学习、三元组损失直接把"特征空间的距离结构"当训练目标——让同类距离小、异类距离大。特征空间分析从"检查工具"变成了"训练目标"。

一句话串起整节：**特征空间是网络内心的投影——同类聚团、异类分离，就是它"懂了"的证据；而 t-SNE 的距离、聚类的重叠、错分的落点，就是我们在读它的心。** 下一节，我们把镜头从"网络看到什么"转向"网络记住什么"——为什么平坦的落点意味着更稳健的记忆（泛化）。
