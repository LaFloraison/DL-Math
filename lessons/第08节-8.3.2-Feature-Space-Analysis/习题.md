# §8.3.2 特征空间分析 —— 习题

本章主线讲了三件事：特征空间是网络内心世界的投影（同类聚团、异类分离）；特征映射 $z = f_\theta(x)$ 把高维输入重排成语义坐标；特征空间分析的四件标准动作（t-SNE 看聚类、量类间分离、找错分点、测对抗鲁棒性）。下面的习题分三组：**概念检验** 验证核心定义，**计算实践** 把特征距离与分离度亲手算一遍（含代码验证），**DL 延伸** 把特征空间分析用回真实工程。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：关于特征空间，哪个说法**错误**？

- A. 特征空间是网络把输入映射成的低维表示所在的坐标空间
- B. 同类输入在特征空间里通常比异类输入更接近
- C. 特征空间里的欧氏距离一定等于"语义相似度"
- D. t-SNE / UMAP 可以把高维特征投影到 2D 便于观察

**解答**：C。

C 错：欧氏距离**只有在网络学得好、且特征流形接近平直时才近似等于语义相似度**。特征空间可能弯曲（真实语义距离应是测地距离），网络也可能没学好（$z$ 空间距离承载不了语义）——这正是主线边界声明警告的地方。A 对：特征空间是 $z = f_\theta(x)$ 的值域。B 对：这是分类器能工作的前提。D 对：t-SNE/UMAP 的用途。

**思路点拨**：题眼是"欧氏距离 ≠ 语义距离"的默认平直假设。最容易错的直觉是"特征空间距离就是语义"。判据：看到"特征空间聚类"结论时，先问——这个空间是平直的吗？网络学好了吗？这两问都通过，欧氏距离才可信。

### 题 2（判断 + 简答）：为什么说"越相似放得越近"是网络"学会分类"的证据？

用特征空间的语言解释：为什么"同类聚团、异类分离"这个观察，能说明网络学到了分类能力？

**解答**：因为网络从**没有被直接告知**"哪些输入同类"（监督学习只给标签，不给"相似度"），却在自己的特征空间里自发地把同类放在邻近位置、异类分开——这说明网络从数据里**学到了能区分类别的特征结构**。如果网络只是死记硬背输入（记住每个训练样本），它不会形成"聚团"——它会把所有点随机铺开或原样保留；只有真正理解了"同类共享某些特征、异类特征不同"，才会产生聚类结构。**聚团是"理解"的结构性证据**：它证明了网络学到的是特征（可泛化的属性），而不是样例（不可泛化的记忆）。

**思路点拨**：这道题考"为什么聚类有意义"。核心对比：记忆（无结构）vs 理解（有结构）。判据：聚类意味着"网络找到了同类共享的特征维度"——这也是为什么聚团紧、分离大的特征空间通常泛化好（学的是模式不是样本）。

### 题 3（简答）：错分样本为什么通常落在类边界？

观察特征空间发现，模型的错分样本几乎都落在两个类的簇之间的**交界地带**。为什么？这对调试模型有什么提示？

**解答**：分类器在特征空间里本质上画了一条（或一组）决策边界，把空间划分给各个类。错分发生在"决策边界附近的点"——这些点离两个类的簇中心都较远、位于边界两侧的模糊地带。它们可能：① 特征本身模糊（一个潦草到极点的"7"在特征空间里确实更接近"1"的簇）；② 边界附近特征不足（模型在该区域的判别信息不够）。

调试提示：错分点集中分布在边界 → 问题在**边界附近区域的判别力**，而不是整体。对策包括：① 给边界附近的训练样本加权（难例挖掘，hard example mining）；② 增加特征维度/容量，让边界更平滑；③ 检查错分点是否呈现某类系统性特征（如都来自某种光照/角度），若是，说明数据流形在该区域有缺失。

**思路点拨**：这道题把"错分点"与"决策边界"联系起来。核心：**错分 = 点在边界模糊区**。判据：看错分点在特征空间的**位置分布**（集中在边界 vs 散落各处）能区分"边界判别力不足"与"数据本身噪声"两种病因。这也是主线"找错误样本看落点"这一动作的价值所在。

## 二、计算实践

### 题 1（教材 2-2-1 网络的完整前向）

网络结构：输入 2 神经元，隐藏层 2 神经元 + ReLU，输出 1 神经元 + sigmoid。权重：$W_1 = I$、$b_1 = 0$、$W_2 = [1,1]$、$b_2 = 0$。

(a) 对 $x = [2,2]$（类 A），手算 $h$ 与 $\hat y$。
(b) 对 $x = [-2,-2]$（类 B），手算 $h$ 与 $\hat y$。为什么 $h$ 会变成 $[0,0]$？
(c) 用类 A 中心 $[2,2]$ 与类 B 中心 $[-2,-2]$，算特征空间距离 $\|h_A - h_B\|$，并解释这个网络为什么能分类。

**解答**：

(a) $z_1 = I\cdot[2,2] + 0 = [2,2]$，$h = \mathrm{ReLU}([2,2]) = [2,2]$。$z_2 = [1,1]\cdot[2,2] = 4$，$\hat y = \sigma(4) = \frac{1}{1+e^{-4}} \approx 0.982$。输出接近 1，判为类 A。

(b) $z_1 = [-2,-2]$，$h = \mathrm{ReLU}([-2,-2]) = [0,0]$——负值被 ReLU 截断为 0。$z_2 = 0$，$\hat y = \sigma(0) = 0.5$。输出 0.5——"无法判断"？这其实揭示了一个微妙点：这个网络对类 B 的判别**不如对类 A 强**。因为 $W_2 = [1,1]$ 只累加正值特征；类 B 的特征全被 ReLU 压成 0，贡献为零。一个更对称的网络（如 $W_1 = I, W_2 = [1,-1]$）会给出对称的判别。

(c) $\|h_A - h_B\| = \|[2,2] - [0,0]\| = \sqrt{8} \approx 2.83$。这个网络能分类的原因是：$W_1 = I$ 保留坐标位置，ReLU 把"位于第一象限的类 A"完整保留、把"位于第三象限的类 B"压到原点，$W_2 = [1,1]$ 依据"特征之和"做判别。**分类能力来自"特征空间里类 A 与类 B 被映射到不同区域"**。

**NumPy 验证**：
```python
import numpy as np

def relu(x): return np.maximum(x, 0)
def sigmoid(x): return 1/(1+np.exp(-x))
W1, b1, W2, b2 = np.eye(2), np.zeros(2), np.array([[1.,1.]]), np.array([0.])

for name, x in [("A [2,2]", np.array([2.,2.])), ("B [-2,-2]", np.array([-2.,-2.]))]:
    h = relu(W1 @ x + b1)
    y = sigmoid(W2 @ h + b2)[0]
    print("%s: h=%s yhat=%.3f" % (name, h, y))
```
```
A [2,2]: h=[2. 2.] yhat=0.982
B [-2,-2]: h=[0. 0.] yhat=0.500
```

**思路点拨**：核心是 ReLU 的"截断"如何塑造特征空间——它把负半空间压到原点，让特征空间不再是整个 $\mathbb{R}^2$ 而是"第一象限"。这正是非线性激活的几何作用：**特征空间是由激活函数"拧"出来的**。值得注意 (b) 暴露的不对称性：$W_2 = [1,1]$ 对类 B 判 0.5（无信息）——如果这是个真实模型，需要调整权重才能对两类对称判别。

### 题 2（分离度的手算）

两类点在特征空间里：类 A 中心 $[3, 1]$，类 B 中心 $[-1, 3]$，类内平均散布 $s_A = 0.5$、$s_B = 0.4$。

(a) 算类间距离与分离度 $\rho$。
(b) 如果类 A 散布增大到 $s_A = 1.5$，$\rho$ 变成多少？这说明什么？
(c) 分离度 $\rho$ 这个指标，和"分类准确率"是什么关系？

**解答**：

(a) 类间距离 $d_{AB} = \|[3,1] - [-1,3]\| = \|[4,-2]\| = \sqrt{16+4} = \sqrt{20} \approx 4.47$。$\rho = \frac{4.47}{0.5+0.4} = \frac{4.47}{0.9} \approx 4.97$——类间距是散布的近 5 倍，高度可分。

(b) $s_A$ 变 1.5：$\rho = \frac{4.47}{1.5+0.4} = \frac{4.47}{1.9} \approx 2.35$——分离度下降一半多。类 A 的点扩散得更开，部分点可能越过分界线进入类 B 区域，分类准确率预期下降。**分离度 $\rho$ 度量"重叠程度"，而重叠程度决定错误率。**

(c) 两者高度相关但不等价：$\rho$ 是特征空间的**几何量**（在分类之前就能算），准确率是分类的**结果量**。$\rho \gg 1$ → 准确率通常很高（决策边界远离类中心）；$\rho$ 小 → 边界穿过类内，错误率上升。但准确率还受决策边界的形状、类的分布形态（非高斯、多模态）影响——$\rho$ 是"近似预估器"，不是准确率的函数式。**分离度用于快速体检，准确率用于最终验收。**

**思路点拨**：这道题把"特征空间分离度"算成具体数字。(a) 练 $\rho = d/(s_A+s_B)$。(b) 揭示"类内散布"的杀伤力——两个类不够"紧"时，即使中心分得远，也挡不住重叠。(c) 是概念辨析：几何量 vs 结果量。判据：**在特征空间里先量 $\rho$（几何），再去验证集测准确率（结果），两者互相印证。**

### 题 3（t-SNE 的尺度陷阱）

两个分类器在同样的验证集上有相同准确率 95%。你分别对它们的特征空间跑 t-SNE，图 A 中两类被一条大裂缝分开，图 B 中两类紧贴但也被分开。你能据此说"图 A 的模型更好"吗？

**解答**：**不能。** t-SNE 保持的是**局部邻接关系**，全局距离被扭曲（§8.1 边界声明）。图 A 中"大裂缝"可能是 t-SNE 的**伪影**——它把"局部密度低"的区域拉伸成视觉上的大空隙，并不意味着特征空间里两类真的离得很远。图 B 中"紧贴但分开"也不代表模型差——只要局部邻接正确，边界附近本来就是模糊区。**t-SNE 图上"离多远"不可信，"是否分开"才可信。** 要比较真正的分离度，应该回到欧氏/度量的类间距离（题 2 的 $\rho$）或在验证集上测准确率。

**思路点拨**：这是 t-SNE 最常见的误用——把"可视化的裂缝"当"几何的分离"。判据一句话：**t-SNE 的横纵坐标没有绝对意义，只有相对聚散有意义。** 想要可比较的分离度，用 PCA 保持的全局距离或直接算类间距离；想要看"能不能分开"，用 t-SNE。两者各回答一个问题。

## 三、DL 延伸

### 题 1（迁移学习：用特征空间判断能不能复用）

你想把在 ImageNet 上预训练的分类网络迁移到"识别医学 X 光片"的新任务。在动手微调之前，你决定先看一眼预训练模型的特征空间。

(a) 你会看什么，来判断"这个特征空间对新任务有用"？
(b) 如果特征空间显示：新任务的各类别在预训练特征空间里**已经聚团**，你会怎么做？如果**严重重叠**呢？

**解答**：

(a) 做两件事：① 把新任务的数据过一遍预训练网络，取倒数第二层的特征，跑 t-SNE 看各类是否聚团；② 计算类间分离度 $\rho$。聚团 + 分离大 → 预训练特征已经能区分新任务类别；重叠 → 特征空间与新任务不匹配。

(b) **已聚团**：预训练特征空间对新任务足够好——只需冻结特征提取层，训练一个线性分类头（甚至 KNN）即可，省时省力。**严重重叠**：预训练特征与新任务"错位"——需要微调更深层（解冻更多层让特征空间适应新数据），或重新训练，或换一个更接近的预训练模型。**特征空间的聚类结构，是迁移学习"该冻几层、该微调几层"的直接判据。**

**思路点拨**：这是特征空间分析最实用的应用。核心命题：**迁移的深浅，由新任务在预训练特征空间的"自然聚团程度"决定。** 判据：聚团好 → 只训头；聚团差 → 微调深/重训。这解释了为什么 ImageNet 特征对"自然图像任务"迁移极好（聚团好）而对"医学影像、卫星图"迁移差（分布偏移，聚团差）。

### 题 2（对抗样本与特征空间的距离）

攻击者生成对抗样本：给一张"熊猫"图 $x$ 加极小扰动 $\delta$，使 $x' = x + \delta$ 被模型错认为"长臂猿"，但人眼看不出区别。

(a) 在特征空间里，$x$ 与 $x'$ 的位置关系通常是什么样的？
(b) 为什么"真实样本与对抗样本在特征空间里离得远"能帮助防御？
(c) 给出一种利用特征空间距离的防御思路。

**解答**：

(a) 通常 $x' = x + \delta$ 在**像素空间**里离 $x$ 极近，但在**特征空间**里被推到远离真实样本的位置——因为 $\delta$ 被精心构造，专门沿着"特征空间里最敏感的方向"（垂直于真实流形的方向，或决策边界附近的方向）推动。$x'$ 往往落在"模型自以为可靠、实则远离真实数据分布"的区域。

(b) 因为"真实样本都住在数据流形附近"（§8.2.1），而对抗样本偏离流形。如果模型在特征空间里把"离真实流形过远的点"当作可疑（降低置信、拒绝、或拉回流形），就能挡住大量对抗攻击。**特征空间的流形结构 = 判断"这个输入是否合理"的依据。**

(c) 典型思路：**对抗训练**——训练时把对抗样本也放进训练集，让模型学会把 $x'$ 也映射到与 $x$ 邻近的特征位置（拉近对抗与真实样本的距离），从而削弱攻击。另一种：**输入去噪/防御性净化**——在特征空间里把可疑点"投影回流形"（如自编码器重建），去除对抗扰动。两者都利用了"对抗样本偏离特征空间流形"这一几何事实。

**思路点拨**：这道题把特征空间分析接到对抗鲁棒性。核心命题：**真实 vs 对抗在特征空间里的距离，是鲁棒性的几何度量。** 判据：距离大 = 模型能区分真实与恶意输入 = 鲁棒；距离小 = 攻击能把点推近真实簇 = 脆弱。这也衔接 8.3.3：泛化好的模型（平坦极小值）对输入扰动更不敏感，本身就减少了对攻击的脆弱性。

### 题 3（度量学习：把特征空间当训练目标）

对比学习（如 SimCLR）的损失是"拉近同图两个增强版本的距离、推远不同图的距离"。

(a) 用特征空间的语言，对比学习在训练什么？
(b) 它和"用特征空间分析做检查"是什么关系？
(c) 对比学习学到的特征空间，为什么往往比监督学习学的更适合"特征空间可视化"？

**解答**：

(a) 对比学习在**直接优化特征空间的距离结构**：让 $z = f_\theta(x)$ 满足"同一张图的增强版本 $x, x'$ 距离小，不同图的增强版本距离大"。它把"特征空间该长什么样"从隐式的（监督学习靠分类损失间接塑造）变成显式的（直接对距离结构做损失）。

(b) 关系是"检查 vs 目标"的升级：特征空间分析（t-SNE、分离度、错分点）是**检查**工具——训练后看网络学到了什么；对比学习把"距离结构"变成**训练目标**——直接让网络学到好的距离结构。分析提供诊断，目标提供约束；两者共享同一套几何语言（§8.3 的度量透镜）。

(c) 因为对比学习的损失**显式地要求**"同类近、异类远"，它学到的特征空间天然具有清晰的聚类结构（不依赖任何类别标签的引导，而是数据增强定义的语义邻近）。监督学习用交叉熵只约束"决策边界正确"，特征空间内部结构是"副产品"；对比学习直接雕刻特征空间本身，所以其可视化通常更"干净"（聚团更紧、分离更明显）。

**思路点拨**：这道题把"特征空间分析"和"特征空间学习"连起来。核心：**分析是检查、度量学习是目标，它们用同一把尺子。** 判据：能说出"监督学习间接塑造特征空间、度量学习直接雕刻特征空间"，说明你理解了"特征空间"既是诊断对象也是设计对象——这正是 §8.3 主线"特征空间从被观察对象变成被优化目标"的完整落点。
