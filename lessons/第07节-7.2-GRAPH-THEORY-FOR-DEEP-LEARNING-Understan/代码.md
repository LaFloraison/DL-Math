# Ch07 §7.2 图的正式定义 · 代码.md

主线用一栋五层小楼讲了图的三个正式对象：邻接矩阵、度、以及"图 → 矩阵"的翻译。本文件把这些定义全部实现成 Python：从边列表构建邻接矩阵、验证它的对称性、构造度矩阵、然后推出两种常用的归一化邻接矩阵——它们是 §7.5.1 GCN 公式 $\hat{A} = D^{-1/2} \tilde{A} D^{-1/2}$ 的雏形。全篇只用 `numpy`，每个矩阵长什么样、每项怎么算，全部摊开。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy：矩阵的构建与运算

# ② 五间房 + 四条走廊（边），对应主线 Toy Model
nodes = ["301", "302", "401", "402", "502"]
edges = [("301", "302"), ("302", "401"), ("401", "402"), ("402", "502")]

def adjacency_matrix(nodes, edges):                    # ③ 图 → 邻接矩阵 A
    idx = {name: i for i, name in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v in edges:
        i, j = idx[u], idx[v]
        A[i, j] = 1.0
        A[j, i] = 1.0                                  # 无向：对称
    return A

def degree_matrix(A):                                  # ④ 度矩阵 D：对角线放度，其余 0
    d = A.sum(axis=1)
    return np.diag(d)

def symmetric_normalize(A, D):                         # ⑤ 对称归一化：D^{-1/2} A D^{-1/2}
    Dinv = np.diag(1.0 / np.sqrt(np.diag(D)))
    return Dinv @ A @ Dinv

def row_normalize(A, D):                               # ⑥ 行归一化：每行除以自己的度
    return np.linalg.inv(D) @ A

A = adjacency_matrix(nodes, edges)                     # ⑦ 主流程：建图、验证、归一化
D = degree_matrix(A)
print("邻接矩阵 A：\n", A)
print("对称？", np.allclose(A, A.T))
print("握手引理：Σ度 =", D.sum(), "，2|E| =", 2 * len(edges))
print("度矩阵 D：\n", D)
print("对称归一化 Â = D^{-1/2} A D^{-1/2}：\n", np.round(symmetric_normalize(A, D), 3))
print("行归一化 Â_row：\n", np.round(row_normalize(A, D), 3))
```

看几处值得驻足的细节。**度矩阵不是全 2**：链的两端 301、502 各只有 1 个邻居，度是 1；中间三个节点度是 2。这正是邻接矩阵每行 1 的个数，一数便知。**握手引理** $\sum_v d(v) = 1+2+2+2+1 = 8 = 2|E|$——四条边，各贡献两个端点，守恒成立。**对称归一化**里，301–302 那条边的值是 $1/\sqrt{1\times2} \approx 0.707$，而 302–401 是 $1/\sqrt{2\times2} = 0.5$——端点的边被"放大"了一些，因为端点度低、分摊的强度大。**行归一化**则是每行除以自己的度：301 那行是 $[0,1,0,0,0]$（它只有 1 个邻居，全部分给 302），302 那行是 $[0,0.5,0.5,0,0]$（两个邻居各分一半）。同样一张图，三种写法，三种强度分配。

## 层二：分步逐函数拆解

### 步骤 1：导入 numpy 与定义图数据

```python
import numpy as np
nodes = ["301", "302", "401", "402", "502"]
edges = [("301", "302"), ("302", "401"), ("401", "402"), ("402", "502")]
```

#### import numpy / nodes / edges —— 数据准备

**操作**：`nodes` 用字符串列表给节点起名字（比编号可读）；`edges` 用"节点名对"描述四条走廊。名字和编号之间需要一个索引表——这正是 `adjacency_matrix` 里 `idx` 字典的职责。

**输入**：无。

**输出**：`nodes`（list of str，5 个元素）；`edges`（list of (str, str)，4 条边）。

**可调参数**：增删 `edges` 的元素会直接改变图结构；调换 `nodes` 的**顺序**会改变矩阵的行列顺序（矩阵还是同一个图，只是编号变了——再次印证"表示与对象分离"）。

**对应数学**：§7.2 定义里的**节点集 $V$** 和**边集 $E$**。

---

### 步骤 2：定义邻接矩阵构建函数

```python
def adjacency_matrix(nodes, edges):
    idx = {name: i for i, name in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v in edges:
        i, j = idx[u], idx[v]
        A[i, j] = 1.0
        A[j, i] = 1.0
    return A
```

#### adjacency_matrix —— 节点名 ↔ 编号 ↔ 矩阵

`idx = {name: i for i, name in enumerate(nodes)}`

**操作**：分三步。(1) 建一个字典，把节点名映射到它在 `nodes` 里的下标（"301"→0, "302"→1, …）；(2) 用 `np.zeros` 造一个全零方阵；(3) 遍历每条边，取出两端的下标 `i, j`，在 `A[i, j]` 和 `A[j, i]` 各写 1.0。

**输入**：
- `nodes`：list of str，节点名列表。
- `edges`：list of (str, str)，边的列表。

**输出**：`np.ndarray`，形状 `(len(nodes), len(nodes))`，`dtype=float`（用浮点是为了后面能除以度数、开根号；纯 0/1 时用 int 也行）。

**可调参数**：
- `dtype=float` vs `dtype=int`：这里选 float，因为 `symmetric_normalize` 要算平方根和倒数，int 矩阵会被截断。
- 若建**有向图**，删掉 `A[j, i] = 1.0`；若建**加权图**，把 `1.0` 换成 `w`。

**对应数学**：§7.2 的**邻接矩阵定义** $A_{ij} = 1 \iff \{v_i, v_j\} \in E$。`idx` 字典把"节点名"和"矩阵下标"对接，正是定义里"按 $V$ 的节点顺序排列"的实现。

---

### 步骤 3：定义度矩阵函数

```python
def degree_matrix(A):
    d = A.sum(axis=1)
    return np.diag(d)
```

#### degree_matrix —— 对角线放度

`np.diag(d)`

**操作**：`A.sum(axis=1)` 求每行的和（每个节点的度），得到一维数组 `d`；`np.diag(d)` 把它放到一个方阵的对角线上，其余位置补 0。

**输入**：`A`：`np.ndarray`，形状 `(n, n)`，邻接矩阵。

**输出**：`np.ndarray`，形状 `(n, n)`，对角阵：`D[i, i] = d(v_i)`，非对角全 0。

**可调参数**：无额外参数。注意 `np.diag` 有两个重载——传入一维数组得到对角阵，传入二维数组则提取对角线。这里传一维数组，是前者。

**对应数学**：§7.2 的**度矩阵** $D = \mathrm{diag}(d(v_1), \dots, d(v_n))$。它是把"每个节点的邻居个数"从一行数字摊成一个矩阵，好让后面能用矩阵乘法做归一化。

---

### 步骤 4：定义对称归一化函数

```python
def symmetric_normalize(A, D):
    Dinv = np.diag(1.0 / np.sqrt(np.diag(D)))
    return Dinv @ A @ Dinv
```

#### symmetric_normalize —— GCN 的归一化邻接矩阵雏形

`Dinv @ A @ Dinv`

**操作**：先取 $D$ 的对角线（每个度），开平方、取倒数，做成对角阵 $D^{-1/2}$；然后做三次矩阵乘法：$D^{-1/2} \times A \times D^{-1/2}$。

**输入**：
- `A`：`(n, n)` 邻接矩阵。
- `D`：`(n, n)` 度矩阵。

**输出**：`(n, n)` 归一化邻接矩阵 $\hat{A}$。它和 $A$ 结构相同（0 还是 0，非零位置还是非零），但**非零位置的值**变成了 $1/\sqrt{d(v_i) d(v_j)}$。

**可调参数**：
- 这条 `Dinv @ A @ Dinv` 就是 §7.5.1 GCN 层里 $\hat{A} = D^{-1/2}\tilde{A}D^{-1/2}$ 的全部秘密（$\tilde{A}$ 是加自环后的邻接矩阵）。它为什么这样设计？——为了让**度大的节点不被放大**：如果你只做 $D^{-1}A$，一个度 100 的节点会把邻居信息放大 100 倍；对称地除以 $\sqrt{度}$，让每个方向各摊一半，尺度稳定。
- 矩阵乘法顺序不能换：$D^{-1}A$ 和 $A D^{-1}$ 结果不同，必须两边夹乘。

**对应数学**：§7.2 主线的预告——"归一化邻接矩阵 $\hat{A}$ 的操作，是针对**表示**做的，图本身没有变"。$A$ 里写的是"连不连"，$\hat{A}$ 里写的是"以多大强度传"，图的结构信息一分没丢。

---

### 步骤 5：定义行归一化函数

```python
def row_normalize(A, D):
    return np.linalg.inv(D) @ A
```

#### row_normalize —— 每行除以自己的度

`np.linalg.inv(D) @ A`

**操作**：`np.linalg.inv(D)` 求 $D$ 的逆。因为 $D$ 是对角阵，它的逆就是对角线取倒数。`inv(D) @ A` 把 $A$ 的第 $i$ 行整体乘以 $1/d(v_i)$——**每一行被自己的度归一化**，行和变成 1（除非某行度是 0）。

**输入**：`A`：`(n, n)` 邻接矩阵；`D`：`(n, n)` 度矩阵。

**输出**：`(n, n)` 行归一化矩阵。第 $i$ 行是"从 $v_i$ 出发，把信息平均分给它的 $d(v_i)$ 个邻居，每个邻居得 $1/d(v_i)$"。

**可调参数**：
- 若某节点度是 0（孤立点），`inv(D)` 的对应对角元素是无穷，结果里出现 NaN。真实代码里要先处理孤立点（比如给度加个小常数），这是 §7.6 可扩展性的一个角落。
- 对比 `symmetric_normalize`：行归一化是对称归一化去掉"除以目标节点度"那半边。前者在 GCN 里更常见，因为它还能保持 $\hat{A}$ 的特征值结构。

**对应数学**：**均值聚合 (mean aggregation)**——§7.3 消息传递里"取邻居的平均"就是行归一化的一种实现。主线 Toy Model 里"纸条沿着边传播"的强度版本：强连接多传，弱连接少传。

### 步骤 6：主流程

```python
A = adjacency_matrix(nodes, edges)
D = degree_matrix(A)
print("邻接矩阵 A：\n", A)
print("对称？", np.allclose(A, A.T))
print("握手引理：Σ度 =", D.sum(), "，2|E| =", 2 * len(edges))
print("对称归一化 Â：\n", np.round(symmetric_normalize(A, D), 3))
print("行归一化 Â_row：\n", np.round(row_normalize(A, D), 3))
```

#### np.allclose / np.round —— 验证与美化输出

**操作**：`np.allclose(A, A.T)` 判断 $A$ 和它的转置逐元素相等（无向图必须成立）；`D.sum()` 求 $D$ 全体元素之和 = 所有节点度之和；`np.round(..., 3)` 把归一化矩阵四舍五入到 3 位小数，方便阅读。

**输入**：矩阵。

**输出**：布尔值（对称性）、标量（度之和）、以及两个矩阵的打印。

**可调参数**：`np.allclose` 还有 `rtol`、`atol` 两个容差参数，用于浮点比较——这里矩阵是精确的 0/1，用默认值即可。

**对应数学**：**握手引理 (handshake lemma)**：$\sum_v d(v) = 2|E|$——每条边贡献 2 个度端点，所以度之和恒等于边数两倍。这个引理是图论里最基础的一条守恒律，也是检验你的邻接矩阵建得对不对的免费检测器。

## 改个数字试试

### 实验 A：把链改成环——度全部相等

把 `edges` 改成五条边构成一个环（最后一间房连回第一间）：`[("301","302"), ("302","401"), ("401","402"), ("402","502"), ("502","301")]`。重跑脚本，观察：邻接矩阵的主对角线、对角线两侧各出现一个 1，形成"带状 + 角落"的形状；每个节点度都是 2，度矩阵全部是 2——握手引理依然成立（$10 = 2\times5$）。

这说明什么？**图的结构变了，但"度之和 = 2|E|"这条定律纹丝不动。** 它是所有图共享的守恒律，与拓扑无关。

### 实验 B：给图加自环（为 §7.5.1 铺路）

GCN 里用的 $\tilde{A} = A + I$（给每个节点加一条指向自己的边）。手动构造：

```python
Atilde = A + np.eye(5)
print("加自环后行归一化（均值聚合）：\n", np.round(row_normalize(Atilde, degree_matrix(Atilde)), 3))
```

输出每一行是"自己 + 邻居的平均"：比如 301 有自己和 302 两个"邻居"，各分 1/2——这正是 §7.5.1 里"包含自环的均值聚合"的代码形态。自环的存在让每个节点在聚合时**永远算上自己**，防止"没有邻居的节点"在消息传递里被清零。

**呼应主线**：本节的所有矩阵对象——$A$、$D$、$\hat{A}$、$A+I$——都是同一种"表示与对象分离"的练习：图没有变，只是换着方式写。等到 §7.5.1，它们会联手成为 GCN 层的前向公式。
