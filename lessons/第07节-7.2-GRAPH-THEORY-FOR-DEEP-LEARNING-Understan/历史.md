# 历史：一张被随手画下的图，怎样变成了矩阵

## 1736 年之后的两百年：图是"画"出来的

哥尼斯堡之后，欧拉留下的"点与线"，长成了一个越来越庞大的家族。到了十九世纪末，人们用图来解决的已经不只是走桥：运输调度用图，电路分析用图，化学家发现，分子式本身就是一张图——碳原子是点，化学键是线。

但有一个尴尬始终挥之不去：**这个家族没有一个正经的户口。** 数学家们可以画图、讲图，可当有人问"图的精确定义是什么？"，答案却是含糊的——"就是……那些点和线啊。" 图像是数学家桌子上的涂鸦，而没有像函数、集合那样，拥有一套被写进教科书的严谨身份。

对一个只能靠眼睛理解的对象，你可以直觉地讨论它。但你不能给它建公式，不能交给机器，不能严格地证明关于它的定理。图论悬在数学和工程之间，像一座没有打地基的房子。

## 1936，柏林：一本给图"上户口"的书

德尼斯·柯尼希（Dénes Kőnig）是个匈牙利人，一辈子几乎只做一件事：把"图"从涂鸦变成一门正规的数学。他写的那本书名字朴实无华——《有限与无限图的理论》。

柯尼希做了一件和欧拉相反的事。欧拉是从具体问题里"抽象"出图；柯尼希是要给这个抽象**立规矩**。他在书里写下的定义，今天任何一个学生都能背出来：一张图就是两个集合——一堆**节点**，和一堆把节点两两连起来的**边**。除此以外，什么也不需要了。

这个定义看起来平淡，却是决定性的。它意味着：图不再是"画得像不像"的东西，而是一个**可以用集合论严格描述、可以推理、可以证明定理**的数学对象。柯尼希的书给图论打了地基，从此图论从"工程师的便利画法"升格成了数学的一个正经分支。后世把这一天当作图论作为独立学科的生日。

但还有一个问题悬着。柯尼希的图，长得再规矩，还是**画在纸上的**。你可以用眼睛看它，可以用手数它，但你没法"算"它——没法把一张图扔进一台机器里，让机器替你做关于这张图的任何计算。

## 一群看着"格子表"的人

转折悄悄发生在二十世纪中叶。当数学家们开始研究图的各种性质时，有人发现了一个不起眼的搬法：把图里的节点排成一列，然后画一张**方格子表**——每个格子代表"这一行的点"和"这一列的点"之间有没有一条边。有，就写 1；没有，就写 0。

这张表没有任何新信息，它只是把图画里的"有没有线"翻译成了"格子里的 0 或 1"。可是这个翻译是致命的：**图画只能被眼睛看，格子表可以被手算。** 当"图中两点之间隔几步"这种问题被写成"对这张格子表做乘法"时，图的全部性质——谁连谁、走几步能到、哪块密哪块疏——忽然变成了一串可以执行、可以程序化的数字运算。

这张格子表，后人叫它**邻接矩阵**。它一出现，图就不再只是眼睛的领地。从此"研究一张图"和"研究一张写着 0 和 1 的方表"，变成了同一件事的两种说法。

## 从格子表到神经网络

此后又一个意想不到的转弯。邻接矩阵安静地待在谱理论的著作里几十年，然后，深度学习来了。

2017 年前后，一批研究者意识到：神经网络的看家本领——矩阵乘法——和邻接矩阵是天作之合。如果给每个节点配一串特征数字，再让"写着 0 和 1 的格子表"和这串数字做乘法，结果恰好就是"每个节点把自己邻居的信息收拢到自己身上"——这正是神经网络最擅长学习的操作。那张两百年前为走桥问题发明的图，与那个为柯尼希的集合定义服务的格子表，联手变成了图神经网络里每一次前向传播都要执行的核心动作。

图的全部旅程浓缩在这条线上：**欧拉为一座城画的线 → 柯尼希为它立的规矩 → 邻接矩阵把它变成数字 → 神经网络把它变成学习。** 从眼睛到集合，从集合到矩阵，从矩阵到梯度——一个概念走了三百年，终于在深度学习中找到了它最彻底的一次变身。

## 留一扇门

现在我们手里有了图的两个标准零件：节点和边。有了把它们装进数字世界的那张格子表——邻接矩阵。

但一个紧迫的问题等着我们：**现实里的关系不总是"连不连"这么简单。** 一张论文引用图，A 引用 B 和 B 引用 A 是两回事；一张交通图，两城之间的距离有远近。当"方向"和"强度"被加进图里，那张格子表会怎样改变？

这正是主线要回答的：有向图、无向图、加权图——三种变形，三种穿在同一个骨架上、分别为了回答不同问题的外衣。
