**1.2（判断并说明）** "展平图像时，像素之间的空间位置信息完全丢失了，所以展平后的向量无法反映图像的任何结构。" 这句话对吗？

## 第三组：DL 延伸

**3.1（场景判断）** 一个文本检索系统，查询 $\mathbf{q}$ 与两篇文档的嵌入 $\mathbf{d}_1$、$\mathbf{d}_2$ 的余弦相似度分别为 0.9 和 0.5。系统返回哪篇文档？为什么用余弦相似度而不是点积？

**3.2（场景分析）** 为什么全连接网络直接吃 784 维展平向量时，对"平移不变"的任务表现差？CNN 是如何用"卷积核在图像上滑动"来解决这一点的（概念层面，不写代码）？

## 解答与思路点拨

### 第一组

**1.1 答案：C（16）。**
- **思路**：展平把每个像素变成一个分量，$4\times4 = 16$。
- **点拨**：维数 = 像素数 = 宽 × 高。MNIST 是 $28\times28=784$。这是"特征向量维度"的最直接计算。

**1.2 这句话不完全对。**
- **思路**：展平是**信息无损**的——9 个像素全进来了，只是"位置"被编码成了"维度序号"。空间关系（相邻、上下）没有被抹掉，而是被**压进了顺序里**，需要模型去重新发现。所以说"完全丢失"不对；说"没有直接暴露、要靠模型学习"才对。
- **点拨**：这是理解"为什么需要 CNN"的钥匙。展平不丢信息，但丢"结构便捷性"——模型得自己学，CNN 则把结构直接编进运算（卷积）。

**1.3 答案：彼此靠近（夹角小/距离近）；余弦相似度。**
- **思路**：嵌入的哲学是"语义几何化"——语义相近 ⇔ 向量距离近 ⇔ 夹角小 ⇔ 余弦相似度高。
- **点拨**："距离即语义"要记牢。这也是检索、推荐、注意力都用的度量。

### 第二组

**2.1**
分子 $= 0.8\times0.75 + 0.2\times0.3 + 0.7\times0.65 = 0.6 + 0.06 + 0.455 = 1.115$。
$\|\mathbf{a}\| = \sqrt{0.64+0.04+0.49} = \sqrt{1.17} \approx 1.0817$；$\|\mathbf{b}\| = \sqrt{0.5625+0.09+0.4225} = \sqrt{1.075} \approx 1.0368$。
$\text{sim} = \frac{1.115}{1.0817 \times 1.0368} \approx \frac{1.115}{1.1215} \approx 0.9942$。

```python
import numpy as np
a = np.array([0.8, 0.2, 0.7]); b = np.array([0.75, 0.3, 0.65])
print(np.dot(a, b)/(np.linalg.norm(a)*np.linalg.norm(b)))   # 0.9942
```
- **思路**：按"分子 → 模长 → 比值"三步走，手算与代码一致。
- **点拨**：0.994 非常接近 1，说明夹角极小——"king"、"queen" 语义几乎同向。这就是教材那句"strong similarity"的数值证据。

**2.2**
```python
import numpy as np
img = np.array([[1, 2], [3, 4]])
print(img.flatten())             # [1 2 3 4]（行优先：先读第 0 行，再第 1 行）
print(img.flatten(order='F'))    # [1 3 2 4]（列优先：先读第 0 列，再第 1 列）
```
注意：同一个 2×2 图，行优先得到 `[1,2,3,4]`，列优先得到 `[1,3,2,4]`——**两个向量完全不同**。若改用对称的棋盘图 `[[0,255],[255,0]]`，两种顺序恰好相同（图案对称掩盖了差异），更容易误以为顺序无所谓。
- **思路**：**展平顺序决定"每个维度代表哪个像素"**。同一张图，顺序不同，向量完全不同——模型读到的就是两张图。所以训练时展平顺序必须固定且一致。
- **点拨**："特征向量每个维度语义固定"不是自动的，是**约定出来的**。跨库、跨脚本顺序不一致，是数据管线里很隐蔽的 bug。

**2.3**
```python
import numpy as np
pairs = [([1.,0.],[np.cos(np.pi/3), np.sin(np.pi/3)]),
         ([1.,0.],[-1.,0.]),
         ([1.,0.],[0.,1.])]
for u, v in pairs:
    print(np.dot(u,v)/(np.linalg.norm(u)*np.linalg.norm(v)))
# 0.5  -1.0  0.0
```
- **思路**：单位向量间的余弦相似度就是夹角余弦：$60°\to0.5$、$180°\to-1$、$90°\to0$。取值范围恒在 $[-1,1]$。
- **点拨**：这是余弦相似度的"取值地图"：$1$ 同向、$0$ 垂直、$-1$ 反向。看到相似度 0.9 就知道"几乎同向"，看到负值就知道"方向相反"。

### 第三组

**3.1 答案：返回 $\mathbf{d}_1$（相似度 0.9 更高）。用余弦相似度是因为它只比方向、不比长度，长短文档可比。**
- **思路**：余弦相似度越大，语义越接近，优先返回。用余弦而非点积，是因为点积会被模长主导：一篇很长的文档模长大，点积天然大，但这不代表语义更接近查询。归一化后只保留"方向"信息，检索更公平。
- **点拨**：检索/推荐的标配就是余弦相似度（或其变形）。注意点积注意力（Transformer）里没有归一化，是因为它对"模长"另有安排（缩放因子 $1/\sqrt{d_k}$）——两种用法各有道理。

**3.2 思路**
- **全连接吃展平向量**：784 个像素被当成 784 个独立特征，模型**不知道**第 100 位和第 101 位在空间上是相邻的。数字"6"平移一格，784 个分量的值几乎全变，但模型没有"平移不变"的机制，等于要重新学一遍。
- **CNN 的解法**：卷积核（一个小矩阵，如 3×3）在图像上**滑动**，同一套权重扫过所有位置。核在"左邻"提取的某种模式，和"右邻"提取的是同一个核→同一套权重→**同一个特征，不管出现在哪**。平移不靠模型"发现"，而是被卷积的滑窗结构直接编码进来。
- **点拨**：这就是"展平有损结构，卷积保留结构"的落点。§2.2.3.7 会讲 CNN 的向量视角，§2.5.3.2 讲它的线性变换视角。这里先建立概念：**特征向量是扁平入场券，结构要靠运算结构来补。**
