# 代码：把图展平成向量，用余弦相似度测量词义

主线里我们把 3×3 图像展平成 9 维向量，又用余弦相似度证明 "king" 与 "queen" 语义接近。这一节用 NumPy 全程复现：**展平 (flatten)**、**查嵌入表**、**余弦相似度**。

---

## 层一：完整脚本

```python
import numpy as np                            # NumPy：flatten / dot / norm

# ---- ① 3×3 图像展平成 9 维特征向量 ----
img = np.array([[255, 128,   0],
                [ 64, 255,  32],
                [  0, 128,  64]])             # 3×3 灰度图（0=黑, 255=白）
flat = img.flatten()                          # 展平：按行读成 9 维向量
print("展平向量 =", flat)
print("形状:", img.shape, "→", flat.shape)

# ---- ② MNIST 风格：28×28 图 → 784 维 ----
img_mnist = np.random.randint(0, 256, (28, 28))
print(f"MNIST 图 {img_mnist.shape} → 展平 {img_mnist.flatten().shape}（28×28={28*28}）")

# ---- ③ 词嵌入：一个小型嵌入表 ----
embeddings = {
    "king":  np.array([0.80, 0.20, 0.70]),
    "queen": np.array([0.75, 0.30, 0.65]),
    "apple": np.array([0.10, 0.90, 0.05]),
}
def cosine(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))

print(f"cos(king, queen) = {cosine(embeddings['king'], embeddings['queen']):.4f}")
print(f"cos(king, apple) = {cosine(embeddings['king'], embeddings['apple']):.4f}")
```

运行输出（Python 3.11 + NumPy）：

```text
展平向量 = [255 128   0  64 255  32   0 128  64]
形状: (3, 3) → (9,)
MNIST 图 (28, 28) → 展平 (784,)（28×28=784）
cos(king, queen) = 0.9942
cos(king, apple) = 0.3809
```

"king" 与 "queen" 相似度 0.9942（教材的 0.994），与 "apple" 仅 0.38——**语义几何化的实证**。下面拆开看。

---

## 层二：分步逐函数拆解

### 步骤 1：展平 `img.flatten()`

```python
img = np.array([[255, 128, 0], ...])
flat = img.flatten()
```

#### `ndarray.flatten()` —— 展平成一维

**做什么**：把任意形状的数组按"行优先"（C 顺序）拉成一维数组。3×3 → 9 个元素，顺序是"第 0 行三个、第 1 行三个、第 2 行三个"。
**操作**：`flatten()` 返回**新数组**（拷贝），不改原数组。按行优先读取内存。
**输入**：`(3,3)` 的 `img`。
**输出**：`(9,)` 的 `flat`。
**可调参数**：`order` 参数可选 `'C'`（行优先，默认）、`'F'`（列优先）。**展平顺序必须与模型约定一致**——顺序错了，模型读到的就是"另一张图"。另有 `reshape(-1)`、`ravel()`（返回视图、更省内存，但可能共享数据）。
**对应数学**：主线"展平 (flattening)"。`flat[i]` 的语义固定为"第 $i$ 个位置的像素亮度"——这正是特征向量"每个维度有固定语义"的代码体现。

### 步骤 2：MNIST 规模演示

```python
img_mnist = np.random.randint(0, 256, (28, 28))
img_mnist.flatten().shape
```

#### `np.random.randint(0, 256, (28, 28))` —— 生成随机灰度图

**操作**：生成 $28\times28$ 的整数数组，每个值在 $[0,256)$——模拟一张 MNIST 手写数字的像素矩阵。
**输入**：`low=0`、`high=256`、`size=(28,28)`。
**输出**：`(28,28)` 数组。
**可调参数**：`size` 任意形状；`dtype` 可设 `np.uint8` 更省内存（真实图像就是 uint8）。`flatten().shape` 显示 `(784,)`。
**对应数学**：主线"MNIST 28×28 展平成 784 维"。

### 步骤 3：嵌入表 + 余弦相似度

```python
embeddings = {"king": np.array([0.80, 0.20, 0.70]), ...}
def cosine(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
```

#### Python 字典作嵌入表

**操作**：以词为键、以向量为值的字典——词嵌入在内存里的最朴素形式。真实框架里是 `nn.Embedding` 矩阵（形状 `(vocab, d)`），一行一词。查表即 `embeddings["king"]`。
**可调参数**：键是词，值是 `(d,)` 向量。`d=3` 是教学用的小嵌入；真实嵌入 `d` 常为 128–4096。
**对应数学**：主线"词嵌入把词映射到高维向量"。字典查表 = 从嵌入矩阵取对应行。

#### `cosine(u, v)` —— 余弦相似度

**操作**：$\frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$。分子 `np.dot` 点积，分母两个 `np.linalg.norm` 相乘。
**输入**：两个 `(3,)` 向量。
**输出**：标量。`cos(king, queen) = 0.9942`，`cos(king, apple) = 0.3809`。
**可调参数**：可改成 `np.dot(u/np.linalg.norm(u), v/np.linalg.norm(v))`（先单位化再点积，等价且少一次除法）。对批量向量可用 `F.cosine_similarity`（PyTorch）。
**对应数学**：主线公式 $\text{cosine similarity} = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}$。分子 $1.115$、分母 $1.1215$、结果 $0.9942$——与教材手算一致。"语义相近 ⇔ 夹角小 ⇔ 相似度高"在这里得到实证。

## 改个数字试试：把嵌入推想得更深

### 实验：加入 "man" 与 "woman"，验证语义类比

```python
embeddings.update({"man": np.array([0.30, 0.95, 0.10]),
                   "woman": np.array([0.25, 0.85, 0.15])})
print("cos(king−man+woman, queen) =", cosine(embeddings["king"]-embeddings["man"]+embeddings["woman"], embeddings["queen"]))
```

**输出（示意）**：相似度接近 1。这正是著名的"语义类比"：$\vec{\text{king}} - \vec{\text{man}} + \vec{\text{woman}} \approx \vec{\text{queen}}$。方向运算把语义差异（性别）剥离出来再加回去，目标词浮出水面。它证明：**嵌入空间里不仅距离有意义，方向也有意义。**

## 边界声明：这套代码能做什么，不能做什么

1. **嵌入数字是我手工编的教学值**。真实嵌入来自 word2vec/BERT 在几十亿词上的训练，3 维装不下真实语义。这里的 `[0.8, 0.2, 0.7]` 只是演示"相似度计算怎么算"，不代表真实词向量。
2. **余弦相似度只比方向，不比强度**。`2×king` 和 `king` 相似度为 1，但这不代表两个词的语义真的完全一样。若要考虑"模长信息"，用点积（不归一化）或欧氏距离。
3. **展平抹掉了空间结构**。`flatten()` 后，"左右相邻"变成了"维度序号相邻"，模型看不到像素之间的空间关系。这正是全连接网络的局限与 CNN 的动机（§2.2.3.7）。展平是**信息无损**的，但**结构有损**——结构要交给模型去学。
4. **维度越高，相似度越不可靠**。784 维或更高维里，随机向量的夹角普遍接近 $90°$（余弦趋于 0），相似度区分度下降——维数灾难的一角。降维（PCA/SVD，§2.6）是标准对策。
