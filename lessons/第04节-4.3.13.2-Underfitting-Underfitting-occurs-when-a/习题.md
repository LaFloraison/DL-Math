# 习题：欠拟合

## 第一组：概念检验

**1. 从采样视角看，欠拟合的两类成因是什么？它们与"模型太简单"是什么关系？**

**解答**：**采样不足**（样本太少/太稀，规律没显形）与**采样太稀/间隔太大**（系统采样 $k$ 过大，波峰波谷被跳过）。它们与"模型太简单"（容量不足）是**两个独立旋钮**：容量不足是模型表达不了规律，采样不足是规律压根没被喂给模型。教材 Figure 4.7b 是两者叠加：稀疏蓝点 + 线性模型 → 双重欠拟合。区分方法：**加数据是否改善**——加了明显改善是采样问题，加了纹丝不动是容量问题。

**2. 为什么系统采样的大步长会导致欠拟合？**

**解答**：系统采样（§4.3.4）间隔 $k$ 太大时，$k$ 与数据的变化周期（波的起伏）相仿甚至更大，**波峰波谷被系统性跳过**——采样点看似"均匀覆盖"全范围，其实每次落点都处在相近相位，连成一条"假直线"的点阵。模型用这条假直线拟合，以为数据是平的，其实数据在剧烈波动（混叠）。《代码.md》⑤ 的数字：间隔 $\pi$ 只采 4 个点，样本内误差 0.086（看着几乎完美）但对真函数偏差 0.967（完全错误）——**"均匀"的假象比"稀疏"更危险**。

**3. 判断题并说明理由："欠拟合都是模型太简单造成的，加数据没有用。"**

**解答**：错误。欠拟合是两个独立旋钮——采样密度与模型容量。《代码.md》的 2×2 矩阵：稀疏+线性 1.031、密集+线性 1.067（加数据几乎无改善——容量缺）、稀疏+deg5 1.017、密集+deg5 0.210（加数据改善近 5 倍——采样缺）。模型容量够但样本不足时，加数据明显改善。**正确诊断用"加数据改善"**：训练误差随样本量下降 → 采样问题；恒定不降 → 容量问题。

## 第二组：计算实践

**4. 手算 + 代码验证。** 复现教材 Figure 4.7b：真函数 $f(x)=\sin(x)\cdot x\cdot 0.2+0.5$，稀疏 15 个点 + 线性拟合。（a）对真函数偏差是多少？（b）只加密采样到 60 点，线性模型改善吗？（c）换成容量足够的 deg5，稀疏/密集各是多少？（d）结论是什么？

**解答**：
（a）1.031——欠拟合基准。
（b）1.067——**几乎不改善，甚至略高**。直线模型把数据加满 4 倍也学不会曲线（容量天花板）。
（c）稀疏 1.017、密集 0.210——同一 deg5，补数据改善近 5 倍。
（d）**欠拟合是两个独立旋钮**：光加数据救不了容量不足（b），光加容量救不了采样不足（c 的稀疏 1.017 依然差），两者都给足才学会（c 的密集 0.210）。

代码验证：

```python
import numpy as np
np.random.seed(0)
def f(x): return np.sin(x)*x*0.2 + 0.5
xs = np.random.uniform(0.3, 12.0, 15); ys = f(xs) + np.random.normal(0, 0.05, 15)
xd = np.random.uniform(0.3, 12.0, 60); yd = f(xd) + np.random.normal(0, 0.05, 60)
xx = np.linspace(0.3, 12.0, 300)
def err(x, y, d): return np.mean((np.polyval(np.polyfit(x, y, d), xx) - f(xx))**2)
print("稀疏+线性", round(err(xs, ys, 1), 3), " 密集+线性", round(err(xd, yd, 1), 3))
print("稀疏+deg5", round(err(xs, ys, 5), 3), " 密集+deg5", round(err(xd, yd, 5), 3))
```

输出：

```text
稀疏+线性 1.031  密集+线性 1.067
稀疏+deg5 1.017  密集+deg5 0.21
```

**思路点拨**：若有人答"加数据一定能改善欠拟合"，他忽略了"容量缺"这一半——密集+线性 1.067 反而略高（更多点被强制压上直线）。若有人答"加容量一定能治好"，稀疏+deg5 仍是 1.017——样本太稀，高次模型约束不住。**两个旋钮缺一不可，先诊断再下手。**

**5. 系统采样陷阱实验。** 用 `np.arange(0.3, 12.0, np.pi)` 做系统采样（间隔 $\pi$），线性拟合。（a）样本内误差是多少？（b）对真函数偏差是多少？（c）这两个数字为什么差 11 倍？把间隔改小到 0.8 作对照。

**解答**：
（a）0.086——样本内几乎完美。
（b）0.967——对真函数完全错误。
（c）间隔 $\pi$ 接近正弦半周期，每次落点处于相近相位，波峰波谷被系统性跳过——采样点连成"假直线"，线性拟合在采样点上贴合完美，却完全没抓住起伏（混叠，见历史.md 的奈奎斯特-香农）。间隔 0.8（15 点）：样本内 0.928、对真函数 0.934——两数几乎相等，样本诚实。**判断陷阱的判据：样本内误差远小于对真函数偏差时，样本在骗你。**

代码验证：

```python
import numpy as np
def f(x): return np.sin(x)*x*0.2 + 0.5
xx = np.linspace(0.3, 12.0, 300)
for step in (0.8, np.pi):
    x = np.arange(0.3, 12.0, step)
    np.random.seed(8)
    y = f(x) + np.random.normal(0, 0.05, len(x))
    c = np.polyfit(x, y, 1)
    e_in = np.mean((np.polyval(c, x) - y)**2)
    e_tu = np.mean((np.polyval(c, xx) - f(xx))**2)
    print(f"间隔{step:.2f}({len(x)}点): 样本内={e_in:.3f} 对真函数={e_tu:.3f}")
```

输出：

```text
间隔0.80(15点): 样本内=0.928 对真函数=0.934
间隔3.14( 4点): 样本内=0.086 对真函数=0.967
```

**思路点拨**：若有人只报"样本内 0.086，模型很好"，他正被采样陷阱骗了——**在样本上完美与在真相上全错可以同时发生**。这也是 §4.2.5"别用训练误差选模型"在采样视角下的回响：训练误差衡量的是"模型在采样点上多乖"，采样点本身可能骗人。

## 第三组：DL 延伸

**6. 低资源语言场景。** 你想训练一个小语种的语言模型，但该语言的文本数据极少。（a）用采样视角解释为什么模型表现差。（b）三类缓解措施各自的数学身份。（c）如果换一个更大的模型（加容量），为什么可能依然欠拟合？如何用"加数据改善"判据诊断？

**解答**：
（a）**采样不足**——语料太少/太稀，语法规律（词序、搭配、长距离依赖）没被足够样本暴露给模型。模型容量可能足够，但"数据喂不够"，它学不到真实语言分布——稀疏采样导致的欠拟合（对应《代码.md》① 的 1.031：数据稀，规律没显形）。
（b）**加数据**：数据增强、回译（文本翻译再翻回来）——本质是**加密采样**，在稀疏语料上造出更多"虚拟样本"（对应 15 点→60 点的改善）；**借数据**：迁移学习（从大数据语言借先验，§4.2.6.1 的"预训练权重当先验中心"）——用别的语言的结构补足样本；**降容量/强正则**：数据极稀时大模型没东西可学，缩小模型或加强正则反而更稳。
（c）换更大模型可能依然欠拟合——这正是《代码.md》③ 的核心：同一条稀疏样本上 deg1→deg5 只从 1.031 降到 1.017，**光加容量不补数据照样欠拟合**。诊断用"加数据改善"：训练误差随语料量增加而下降 → 采样不足，值得继续找数据/增强；训练误差恒高不降 → 容量不足，才考虑换模型。**"看曲线，别猜"是欠拟合诊断的第一原则。**

**思路点拨**：若有人答"换更大的模型"，在数据极稀缺时是错误方向——大模型没数据可学（加容量救不了采样）。若有人答"加更多数据就行"，对低资源语言往往根本做不到——**这就是数据增强、迁移学习存在的意义：真数据加不了时，用虚拟数据或借来的先验补足采样。**
