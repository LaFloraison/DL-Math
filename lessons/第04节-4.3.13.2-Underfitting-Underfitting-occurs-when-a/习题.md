# 习题：欠拟合（采样视角）

## 第一组：概念检验

**1. 从采样视角看，欠拟合的两个原因是什么？它们与"模型太简单"是什么关系？**

**解答**：**采样不足**（样本太少/太稀，规律没显形）和**采样太稀/间隔太大**（系统采样 $k$ 过大跳过起伏）。它们与"模型太简单"是**两个独立旋钮**：容量不足是模型表达不了规律，采样不足是规律压根没被喂给模型。教材 Figure 4.7b 演示了两者叠加：稀疏点 + 线性模型 → 双重欠拟合。

**2. 为什么系统采样的大步长会导致欠拟合？**

**解答**：系统采样间隔 $k$ 太大时，$k$ 大于数据变化周期（波的起伏），**波峰波谷被跳过**——采样点看似均匀覆盖，其实恰好错过所有起伏，连成一条"假直线"的点阵。模型用这条假直线拟合，以为数据是平的，其实数据在剧烈波动。**"均匀"的假象让你以为覆盖了全范围，其实规律全被采丢了。**

**3. 判断题并说明理由："欠拟合都是模型太简单造成的，加数据没有用。"**

**解答**：错误。欠拟合是两个旋钮——**采样密度**与**模型容量**。若模型容量够但样本不足（比如稀疏采样），加数据（加密采样）明显改善；只有容量不足时（直线学不了二次+正弦），加数据才没用。**正确诊断用学习曲线**：训练误差随 $n$ 下降 → 采样问题；不下降 → 容量问题。

## 第二组：计算实践

**4. 手算 + 代码验证。** 复现教材 Figure 4.7b：真函数 $y=0.3x^2+1.5\sin(2.5x)$，稀疏 12 点。（a）线性拟合的误差？（b）只加密采样到 200 点，误差改善吗？（c）稀疏+二次、加密+二次各是多少？结论是什么？

**解答**：见《代码.md》层一。典型输出：稀疏+直线 5.861、加密+直线 5.910（**几乎不改善**）、稀疏+二次 0.241、加密+二次 0.021。**结论：欠拟合是两个独立旋钮**——只加样本没用（容量缺）、只加容量有限（样本稀）、两者都给足才治好。

代码验证：

```python
import numpy as np
np.random.seed(0)
def f(x): return 0.3*x**2 + 1.5*np.sin(2.5*x)
xs = np.random.uniform(0.5, 10, 12); ys = f(xs) + np.random.normal(0, 0.3, 12)
xd = np.random.uniform(0.5, 10, 200); yd = f(xd) + np.random.normal(0, 0.3, 200)
xx = np.linspace(0, 10.5, 300)
def err(x, y, d): return np.mean((np.polyval(np.polyfit(x, y, d), xx) - f(xx))**2)
print("稀疏+直线", round(err(xs, ys, 1), 3), " 加密+直线", round(err(xd, yd, 1), 3))
print("稀疏+二次", round(err(xs, ys, 2), 3), " 加密+二次", round(err(xd, yd, 2), 3))
```

输出：

```text
稀疏+直线 5.861  加密+直线 5.910
稀疏+二次 0.241  加密+二次 0.021
```

**思路点拨**：若有人答"加数据一定能改善欠拟合"，他忽略了"容量缺"这一半——加密+直线误差 5.910 反而略高（噪声更多）。若有人答"加容量一定能治好"，稀疏+二次仍残留 0.241（样本没把起伏采全）。**两个旋钮缺一不可。**

**5. 系统采样大步长实验。** 用 `np.arange(0.5, 10.0, 1.5)` 做系统采样（间隔 1.5），即使用二次模型，误差为什么仍大？把间隔改小到 0.3 试试。

**解答**：见《代码.md》步骤 3。间隔 1.5 → 只有 7 点，误差 5.152（严重欠拟合）——**间隔大于起伏周期，波峰波谷被跳过**。把 `1.5` 改成 `0.3`（约 32 点），误差应骤降到 0.05 以下——**采样间隔小于起伏周期，规律显形**。这就是"采样密度决定你能看见什么规律"的直接演示。

## 第三组：DL 延伸

**6. 低资源语言场景。** 你想训练一个小语种的语言模型，但该语言的文本数据极少。（a）用采样视角解释为什么模型表现差。（b）三类缓解措施各自的数学身份。（c）如何用学习曲线判断"该加数据还是该换模型"？

**解答**：
（a）**采样不足**——语料太少/太稀，语法规律（词序、搭配、长距离依赖）没有被足够多的样本暴露给模型。模型"容量"可能足够，但"数据喂不够"，它学不到真实的语言分布——这是稀疏采样导致的欠拟合。
（b）**加数据**：数据增强、回译（把文本翻译再翻回来）——本质是**加密采样**，在稀疏的语料上造出更多"虚拟样本"；**借数据**：迁移学习（从大数据语言借先验，§4.2.6.1 的"预训练权重当先验中心"）——用别的语言的结构补足；**降容量**：用更小的模型/更强的正则——当数据稀缺时，大容量模型反而"没东西可学"，收敛到欠拟合与过拟合之间的灰色地带。
（c）**学习曲线**：训练误差随语料量增加而下降 → 采样不足，值得继续找数据/增强；训练误差恒高不降 → 容量不足，换更大模型或换表达。**"看曲线，别猜"是欠拟合诊断的第一原则。**
**思路点拨**：若有人答"换更大的模型"，在数据极稀缺时这是错误方向——大模型没数据可学。若有人答"加更多数据就行"，对低资源语言这可能根本做不到——**这就是迁移学习、数据增强存在的意义：在"真数据加不了"时，用"虚拟数据"或"借来的先验"补足采样**。
