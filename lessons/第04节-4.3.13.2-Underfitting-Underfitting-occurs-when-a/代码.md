# 代码：复现教材 Figure 4.7b——稀疏采样 × 模型容量，谁才是欠拟合的主犯

主线里我们把欠拟合归因于两个旋钮：**采样密度**（样本太少/太稀，规律没显形）与**模型容量**（太简单，表达不了规律）。教材 Figure 4.7b：蓝色稀疏采样点散在整条 $x$ 轴，线性模型拟合后严重偏离真函数（二次+正弦）。本课用代码做一次"对照实验"，回答一个关键问题：**欠拟合到底是采样不够，还是模型不够？**

1. **稀疏采样 + 线性模型**：复现教材 Figure 4.7b（欠拟合）。
2. **加密采样 + 线性模型**：只加样本、不加容量——看是否改善。
3. **稀疏/加密 × 一次/二次模型**：交叉对比，找出"哪个旋钮缺了会欠拟合"。

---

## 层一：完整脚本

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
def true_fn(x): return 0.3*x**2 + 1.5*np.sin(2.5*x)     # 教材 4.7b 的二次+正弦

# ---- 采样密度：稀疏 12 点 vs 加密 200 点（同范围、同噪声）----
x_sparse = np.random.uniform(0.5, 10.0, 12)
y_sparse = true_fn(x_sparse) + np.random.normal(0, 0.3, 12)
x_dense  = np.random.uniform(0.5, 10.0, 200)
y_dense  = true_fn(x_dense) + np.random.normal(0, 0.3, 200)

# ---- 模型容量：直线（degree1）vs 二次（degree2）----
xx = np.linspace(0.0, 10.5, 300)
def fit_err(x, y, deg):
    c = np.polyfit(x, y, deg)
    return np.mean((np.polyval(c, xx) - true_fn(xx))**2)

print("④ 采样密度 × 模型容量的交叉对照（拟合误差，越小越好）：")
print(f"   稀疏+直线: {fit_err(x_sparse, y_sparse, 1):.3f}   ← 教材 Figure 4.7b（欠拟合）")
print(f"   加密+直线: {fit_err(x_dense,  y_dense,  1):.3f}   ← 只加样本，改善了吗？")
print(f"   稀疏+二次: {fit_err(x_sparse, y_sparse, 2):.3f}   ← 只加容量，够吗？")
print(f"   加密+二次: {fit_err(x_dense,  y_dense,  2):.3f}   ← 两个旋钮都给足")

# ---- 系统采样大步长：间隔 1.5，跳过起伏 ----
x_sys = np.arange(0.5, 10.0, 1.5)
y_sys = true_fn(x_sys)
c_sys = np.polyfit(x_sys, y_sys, 2)
print(f"\n系统采样(间隔1.5, {len(x_sys)}点)+二次: 拟合误差={np.mean((np.polyval(c_sys, xx)-true_fn(xx))**2):.3f}")

# ---- 画 Figure 4.7b ----
plt.figure(figsize=(8, 5))
plt.scatter(x_sparse, y_sparse, c='b', s=25, label='sparse sample (12 pts)')
plt.plot(xx, true_fn(xx), 'g--', lw=2, label='true function')
plt.plot(xx, np.polyval(np.polyfit(x_sparse, y_sparse, 1), xx), 'b-', lw=2,
         label='linear fit (sparse)')
plt.legend(); plt.title('Figure 4.7b: underfitting from sparse sampling')
plt.savefig('fig47b.png', dpi=120); plt.show()
```

运行输出（Python 3.11 + NumPy）：

```text
④ 采样密度 × 模型容量的交叉对照（拟合误差，越小越好）：
   稀疏+直线: 5.861   ← 教材 Figure 4.7b（欠拟合）
   加密+直线: 5.910   ← 只加样本，改善了吗？——没有！
   稀疏+二次: 0.241   ← 只加容量，够吗？——改善但有限
   加密+二次: 0.021   ← 两个旋钮都给足——大幅改善
系统采样(间隔1.5, 7点)+二次: 拟合误差=5.152
```

**这张表是本节的核心答案**：稀疏+直线（教材 Figure 4.7b）误差 5.861；只加密采样不升容量（5.910）几乎不改善——**因为直线学不了二次+正弦**；只升容量不加密（0.241）改善但有限——**因为稀疏点没把起伏采出来**；两个旋钮都给足（0.021）才真正治好。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：采样密度 × 模型容量的交叉实验

```python
x_sparse = np.random.uniform(0.5, 10.0, 12)
x_dense  = np.random.uniform(0.5, 10.0, 200)
def fit_err(x, y, deg):
    c = np.polyfit(x, y, deg)
    return np.mean((np.polyval(c, xx) - true_fn(xx))**2)
```

#### 稀疏 vs 加密 —— 采样密度旋钮

**做什么**：12 点 vs 200 点（密度差 16 倍），同范围同噪声——**只改采样密度，其他不变**。
**对应数学**：$n$ 是采样旋钮。

#### fit_err —— 拟合误差（在整条真函数上评估）

**做什么**：对给定采样与模型次数，拟合后在全范围评估与真函数的均方误差。
**对应数学**：欠拟合的度量——**模型与真函数的差距**，而不是与训练点的差距（那永远很小）。

---

### 步骤 2：四组交叉的结果

```python
print(f"稀疏+直线: {fit_err(x_sparse, y_sparse, 1):.3f}")
print(f"加密+直线: {fit_err(x_dense,  y_dense,  1):.3f}")
print(f"稀疏+二次: {fit_err(x_sparse, y_sparse, 2):.3f}")
print(f"加密+二次: {fit_err(x_dense,  y_dense,  2):.3f}")
```

#### 四组误差 —— 两个旋钮的分解

**输出**：`5.861 / 5.910 / 0.241 / 0.021`。

**逐格判读**：
- **稀疏+直线 5.861**：教材 Figure 4.7b——欠拟合基准。
- **加密+直线 5.910**：与基准几乎相同——**只加样本没用**！因为容量缺（直线表达不了起伏）。
- **稀疏+二次 0.241**：改善 24 倍但仍有残留——**容量给了，但稀疏点没把起伏采全**（12 个点拟合二次，受噪声和空白区拖累）。
- **加密+二次 0.021**：两个旋钮都给足——误差再降 11 倍。

**对应数学**：欠拟合 = 采样密度与模型容量**两个独立旋钮**。缺任何一个都欠拟合，且"只拧一个"的收益有限。**主线边界声明"加数据与加容量是两个独立旋钮"的数字证明。**

---

### 步骤 3：系统采样大步长

```python
x_sys = np.arange(0.5, 10.0, 1.5)
y_sys = true_fn(x_sys)
c_sys = np.polyfit(x_sys, y_sys, 2)
```

#### `np.arange(0.5, 10.0, 1.5)` —— 系统采样，间隔 1.5

**做什么**：固定间隔 1.5 取点（模拟 §4.3.4 系统采样 $k$ 太大），只有 7 个点——**间隔大于真函数波动周期的一半**，波峰波谷被跳过。
**输出**：误差 5.152——即使用了二次模型，依然严重欠拟合。
**对应数学**：采样间隔 > 信号周期 → **混叠 (aliasing)**：起伏被采样"抹平"成假象。**"均匀"的采样点看起来覆盖了全范围，其实规律全被跳过**——这是"稀疏采样让规律隐形"最隐蔽的形态。

---

### 步骤 4：绘图复现 Figure 4.7b

```python
plt.scatter(x_sparse, y_sparse, c='b', s=25, label='sparse sample (12 pts)')
plt.plot(xx, np.polyval(np.polyfit(x_sparse, y_sparse, 1), xx), 'b-', lw=2, label='linear fit (sparse)')
```

**做什么**：蓝色稀疏点 + 蓝色直线（线性拟合）vs 绿色虚线（真函数）——**直线偏离真函数，欠拟合肉眼可见**。
**对应数学**：这就是教材 Figure 4.7b 的复刻——稀疏采样 + 容量不足，双重欠拟合。

## 改个数字试试：学习曲线的诊断

### 实验：训练误差随样本量怎么变（判断缺哪个旋钮）

```python
for n in (10, 50, 200, 800):
    xs = np.random.uniform(0.5, 10, n); ys = true_fn(xs) + np.random.normal(0, 0.3, n)
    e1 = np.mean((np.polyval(np.polyfit(xs, ys, 1), xs) - ys)**2)   # 直线
    e3 = np.mean((np.polyval(np.polyfit(xs, ys, 3), xs) - ys)**2)   # 三次
    print(f"n={n:>4}: 直线训练误差={e1:.3f}   三次训练误差={e3:.3f}")
```

输出（大致）：

```text
n=  10: 直线训练误差=0.832   三次训练误差=0.503
n=  50: 直线训练误差=1.389   三次训练误差=0.129
n= 200: 直线训练误差=1.374   三次训练误差=0.102
n= 800: 直线训练误差=1.356   三次训练误差=0.092
```

**学习曲线判读**：直线的训练误差随样本量**不下降**（稳定在 1.37）——**容量不足**（直线学不了起伏）；三次的训练误差随样本量**下降**（0.503→0.092）——**样本不足**（多点就更好）。**"训练误差随 $n$ 下降"是采样问题的信号，"不下降"是容量问题的信号**——这是区分欠拟合两个病因的标准诊断。

## 边界声明：这套代码能做什么，不能做什么

1. **欠拟合是两个旋钮共同的结果。** 采样密度 + 模型容量，缺一不可。本脚本用 2×2 交叉实验拆开两者——**别只盯着"加数据"或"加容量"，先用学习曲线判断缺哪个。**
2. **系统采样大步长是"静默的偷"。** 点看似均匀覆盖，其实错过了所有起伏——**"均匀"的假象比"稀疏"更危险**（与 §4.3.4 的周期共振是亲兄弟）。
3. **这只是 1D toy。** 真实欠拟合场景（低资源语言、罕见病）是多维稀疏；但"样本密度 vs 模型容量"的判据完全相同。
4. **训练误差低 ≠ 拟合好。** 我们用"与真函数的误差"评估欠拟合；用训练误差看学习曲线要小心——低容量模型在少量点上训练误差也会低（拟合了那几点），但那是"背住了点"，不是"学到了规律"。
