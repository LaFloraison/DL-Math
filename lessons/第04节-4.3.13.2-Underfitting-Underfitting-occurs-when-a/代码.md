# 代码：欠拟合——稀疏采样让"规律隐形"（复现教材 Figure 4.7b）

主线里我们把欠拟合拆成两个独立的原因：**容量不足**（模型表达不了规律）与**采样不足**（样本太稀、规律没显形）。教材 Figure 4.7b 画的是采样视角：蓝色稀疏点散在整条 $x$ 轴，线性模型（深蓝直线）对不上真实函数的二次与正弦起伏。本课用代码复现并量化，做四件事：

1. **复现 Figure 4.7b**：15 个稀疏蓝点 + 线性拟合 → 深蓝直线严重欠拟合真函数。
2. **区分两个旋钮**：密集采样 + 线性（容量天花板）vs 稀疏/密集 + 高次模型（采样决定一切）。
3. **诊断矩阵**：加数据能否改善——一表区分"采样不足"与"容量不足"。
4. **系统采样陷阱**：间隔 $\pi$ 的系统采样，样本内误差极小（看着对）但对真函数偏差巨大（完全错）。

## 层一：完整脚本

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
def true_fn(x): return np.sin(x)*x*0.2 + 0.5     # 二次+正弦的起伏（教材 Figure 4.7）
xx = np.linspace(0.3, 12.0, 300)                 # 评估/画图用的 x 网格

def fit_error(x, y, deg):
    """拟合 deg 次多项式，返回对真函数的平均平方偏差。"""
    c = np.polyfit(x, y, deg)
    return np.mean((np.polyval(c, xx) - true_fn(xx))**2)

# ---- ① Figure 4.7b：稀疏蓝点 + 线性 = 欠拟合 ----
xs = np.random.uniform(0.3, 12.0, 15)            # 稀疏：整条 x 轴只撒 15 个蓝点
ys = true_fn(xs) + np.random.normal(0, 0.05, 15) # 加观测噪声
print(f"① 稀疏(15点)+线性: 对真函数偏差={fit_error(xs, ys, 1):.4f}   # 欠拟合")

# ---- ② 密集 + 线性：容量天花板 ----
xd = np.random.uniform(0.3, 12.0, 60)            # 密集：同样的全范围采 60 个点
yd = true_fn(xd) + np.random.normal(0, 0.05, 60)
print(f"② 密集(60点)+线性: 对真函数偏差={fit_error(xd, yd, 1):.4f}   # 仍欠拟合→容量问题")

# ---- ③ 容量足够(deg5)：稀疏 vs 密集 = 采样是旋钮 ----
print(f"③ 容量足够(deg5): 稀疏={fit_error(xs, ys, 5):.4f} 密集={fit_error(xd, yd, 5):.4f}   # 光加容量不补数据→照样欠拟合")

# ---- ④ 诊断矩阵：加数据改善多少 ----
print("④ 加数据改善了多少（稀疏→密集）：")
for deg in (1, 5):
    a = fit_error(xs, ys, deg); b = fit_error(xd, yd, deg)
    print(f"   deg{deg}: 稀疏={a:.3f} 密集={b:.3f} 改善={a-b:+.3f}")

# ---- ⑤ 系统采样陷阱：间隔 π 跳过起伏 ----
xsys = np.arange(0.3, 12.0, np.pi)               # 4 个点，间隔接近正弦半周期
np.random.seed(8)
ysys = true_fn(xsys) + np.random.normal(0, 0.05, len(xsys))
c_sys = np.polyfit(xsys, ysys, 1)
e_in = np.mean((np.polyval(c_sys, xsys) - ysys)**2)      # 样本内误差
e_tu = np.mean((np.polyval(c_sys, xx) - true_fn(xx))**2) # 对真函数偏差
print(f"⑤ 系统采样(间隔π,{len(xsys)}点)+线性: 样本内={e_in:.3f} 对真函数={e_tu:.3f}")

# ---- ⑥ 画 Figure 4.7b ----
c1 = np.polyfit(xs, ys, 1)
plt.figure(figsize=(8, 5))
plt.scatter(xs, ys, c='b', s=22, label='sparse sample')
plt.plot(xx, true_fn(xx), 'g--', lw=2, label='true function')
plt.plot(xx, np.polyval(c1, xx), 'b-', lw=2, label='linear fit (underfit)')
plt.legend(); plt.title('Figure 4.7b: underfitting from sparse sampling')
plt.savefig('fig47b.png', dpi=120); plt.show()
```

运行输出（Python 3.11 + NumPy）：

```text
① 稀疏(15点)+线性: 对真函数偏差=1.0305   # 欠拟合
② 密集(60点)+线性: 对真函数偏差=1.0671   # 仍欠拟合→容量问题
③ 容量足够(deg5): 稀疏=1.0174 密集=0.2095   # 光加容量不补数据→照样欠拟合
④ 加数据改善了多少（稀疏→密集）：
   deg1: 稀疏=1.031 密集=1.067 改善=-0.037
   deg5: 稀疏=1.017 密集=0.210 改善=+0.808
⑤ 系统采样(间隔π,4点)+线性: 样本内=0.086 对真函数=0.967
```

五个信息逐条读出：**①** 稀疏样本 + 线性 = 欠拟合（偏差 1.03）；**②** 同一线性模型数据加满到 60 点，偏差 1.07 纹丝不动——**线性模型学不了曲线，这是容量天花板**；**③** 换成容量足够的 deg5，稀疏时 1.02 依然差、密集时 0.21 立刻好——**光加容量不补数据照样欠拟合，补了数据立刻学会**；**④** 一表见分晓：deg1 加数据改善 -0.04（没用），deg5 加数据改善 +0.81（巨大）——**"加数据是否改善"就是采样与容量的验钞机**；**⑤** 系统采样间隔 $\pi$ 只采 4 个点，样本内误差 0.086（看着几乎完美）但对真函数偏差 0.967（完全错误）——**采样点把起伏"混叠"成了直线，样本在骗你**。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入并定义工具函数

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
def true_fn(x): return np.sin(x)*x*0.2 + 0.5
xx = np.linspace(0.3, 12.0, 300)

def fit_error(x, y, deg):
    c = np.polyfit(x, y, deg)
    return np.mean((np.polyval(c, xx) - true_fn(xx))**2)
```

#### `import numpy as np` / `import matplotlib.pyplot as plt` —— 工具导入

**操作**：加载 NumPy（数值计算）与 Matplotlib（绘图）。
**对应数学**：为最小二乘、多项式求值、可视化提供执行者。

#### `true_fn` —— 真函数

**做什么**：真函数 $f(x)=\sin(x)\cdot x\cdot 0.2+0.5$——同时含正弦起伏（$\sin x$）与随 $x$ 增长的包络（$x$ 项），整体在"上升与波动"之间摆动，正是教材说的"二次与正弦 (quadratic and sinusoidal) 的形态"。
**输入**：x（标量或数组）。
**输出**：形状与输入相同的 y 数组。
**可调参数**：改成别的函数会改变欠拟合的具体形态，但原理不变。
**对应数学**：**与姊妹课 §4.3.13.1（Figure 4.7a）共用同一条真函数**——Figure 4.7a 与 4.7b 画的是同一条绿虚线，只是采样方式不同：一次采偏（过拟合），一次采稀（欠拟合）。

#### `xx = np.linspace(0.3, 12.0, 300)` —— 评估网格

**做什么**：在 $[0.3,12.0]$ 上均匀取 300 个点，作为"对整个数据范围逐点评估模型"的网格。
**输入**：起点 0.3、终点 12.0、个数 300。
**输出**：形状 `(300,)` 的一维数组。
**可调参数**：第三参数 300 是网格密度——更密更精确，300 点已足够光滑。
**对应数学**：toy 里我们"知道真函数"，于是能对整个定义域逐一打分——这正是现实中只能用验证集替代的那件事。

#### `fit_error` —— 泛化误差的替身

**做什么**：拟合 deg 次多项式后，返回它在整条 $x$ 轴上"对真函数 $f$ 的平均平方偏差" $\frac{1}{300}\sum_{j}(\hat f(x_j)-f(x_j))^2$。
**操作**：`np.polyfit` 最小二乘拟合 → `np.polyval` 在 300 个网格点上求值 → 逐点与 `true_fn` 平方差取平均。
**输入**：`x`（样本 x，形状 `(n,)`）、`y`（样本 y，形状 `(n,)`）、`deg`（多项式次数）。
**输出**：标量 float——"模型离真相平均多远"，越大越欠拟合/越错。
**可调参数**：`deg` 是容量旋钮——`1` 是直线（容量最小），`5` 是五次多项式（足以表达二次+正弦）。`np.polyfit` 还可以传第 4 个参数 `w`（每个点的权重）与第 5 个 `rcond`（病态阈值），本课不用。
**对应数学**：主线学习曲线诊断的量化工具——用真函数当"上帝视角的验证集"，量的是泛化误差本身。

### 步骤 2：① 稀疏采样 + 线性拟合（Figure 4.7b）

```python
xs = np.random.uniform(0.3, 12.0, 15)
ys = true_fn(xs) + np.random.normal(0, 0.05, 15)
```

#### `np.random.uniform(0.3, 12.0, 15)` —— 稀疏采样

**做什么**：在 $[0.3,12]$ 上均匀采 15 个 x——**样本少且随机散落**，正是 Figure 4.7b 的蓝色稀疏点。
**操作**：独立同分布抽样 $x\sim U(0.3,12)$（简单随机采样 SRS）。
**输入**：下界 0.3、上界 12.0、个数 15。
**输出**：形状 `(15,)` 的 x 数组。
**可调参数**：第三参数 15 是**样本量旋钮**——改成 5 是极端稀疏（更欠拟合），改成 60 就是下面的密集对照组。还能传 `size=(...)` 生成多维样本。
**对应数学**：主线"采样不足：数据量太少，不足以支撑规律学习"。

#### `np.random.normal(0, 0.05, 15)` —— 观测噪声

**做什么**：给每个真值加零均值高斯噪声 $N(0,0.05^2)$——把确定性函数变成"带噪声的观测"（现实数据都是这样的）。
**操作**：逐点独立加噪。
**输出**：形状 `(15,)` 的噪声数组，加到 `true_fn(xs)` 上得 `ys`。
**可调参数**：`0.05` 是噪声标准差——改到 0 是纯函数（欠拟合更"教科书"），改到 0.3 则噪声主导、任何模型都难学。
**对应数学**：观测误差项 $\varepsilon$——教材图中散点落在绿虚线附近的"抖动"，就是它。

#### `np.polyfit(xs, ys, 1)` —— 线性最小二乘

**做什么**：对 15 个点做一阶（直线）最小二乘拟合。
**操作**：解 $\min_{a,b}\sum_i(y_i-(a x_i+b))^2$ 的正规方程。
**输入**：`xs` 形状 `(15,)`、`ys` 形状 `(15,)`、次数 1。
**输出**：形状 `(2,)` 的系数数组（`np.polyfit` 按降幂返回，即 `[b, a]`）。
**可调参数**：次数 `1` 是容量旋钮最低档。还可传 `w`（样本权重）、`rcond`。
**对应数学**：§4.2.5 的线性拟合——**它只会画直线，表达不了二次与正弦**。`fit_error(xs, ys, 1)=1.0305`：稀疏样本 + 直线模型，双重欠拟合。

### 步骤 3：②③④ 两个旋钮与诊断矩阵

```python
print(f"② 密集(60点)+线性: 对真函数偏差={fit_error(xd, yd, 1):.4f}")
print(f"③ 容量足够(deg5): 稀疏={fit_error(xs, ys, 5):.4f} 密集={fit_error(xd, yd, 5):.4f}")
print("④ 加数据改善了多少（稀疏→密集）：")
for deg in (1, 5):
    a = fit_error(xs, ys, deg); b = fit_error(xd, yd, deg)
    print(f"   deg{deg}: 稀疏={a:.3f} 密集={b:.3f} 改善={a-b:+.3f}")
```

**做什么**：把"数据密度"与"模型容量"两个旋钮交叉，量出四格偏差，再读"加数据改善"。

#### ② 密集 + 线性 —— 容量天花板

`fit_error(xd, yd, 1)=1.0671`，与稀疏的 1.0305 几乎相同（甚至略高）——**线性模型把数据加满 4 倍也学不会曲线**。这证明容量是一根独立的天花板：样本管够、直线模型照样欠拟合。**不能怪数据——是模型没有那个形状。**

#### ③ 容量足够（deg5）—— 采样才是真瓶颈

同一条稀疏样本，deg1→deg5：1.0305→1.0174，**几乎没改善**——"光加容量不补数据，照样欠拟合"；同一 deg5，稀疏→密集：1.0174→0.2095，**改善近 5 倍**——"补了数据立刻学会"。容量与数据是两个正交的旋钮，**转动哪一个都救不了另一个造成的欠拟合**。

#### ④ 诊断矩阵 —— 加数据是验钞机

| | 稀疏(15点) | 密集(60点) | 加数据改善 |
|---|---|---|---|
| deg1（容量不足） | 1.031 | 1.067 | **-0.037（没用）** |
| deg5（容量足够） | 1.017 | 0.210 | **+0.808（巨大）** |

读法：**加数据后误差明显下降 → 你的模型缺的是数据（采样不足）；加数据后纹丝不动 → 缺的是容量。** 这正是主线"加数据是否改善"诊断的数值版。注意 deg1 那格改善为负——加数据对容量不足的模型不仅无益，还会因更多点被强制压上直线而略差。

### 步骤 4：⑤ 系统采样陷阱

```python
xsys = np.arange(0.3, 12.0, np.pi)
np.random.seed(8)
ysys = true_fn(xsys) + np.random.normal(0, 0.05, len(xsys))
c_sys = np.polyfit(xsys, ysys, 1)
e_in = np.mean((np.polyval(c_sys, xsys) - ysys)**2)
e_tu = np.mean((np.polyval(c_sys, xx) - true_fn(xx))**2)
```

#### `np.arange(0.3, 12.0, np.pi)` —— 系统采样（§4.3.4）

**做什么**：从 0.3 出发，每隔 $\pi$ 取一个点——固定间隔的系统采样，共 4 个点（x ≈ 0.30, 3.44, 6.58, 9.72）。
**操作**：`np.arange(起点, 终点, 步长)` 等差数列。
**可调参数**：**第三个参数 `step` 是本课的主角**——间隔 $\pi$ 接近正弦的半周期，使每次落点都处在相近的相位，波峰波谷被系统性跳过。
**对应数学**：教材点名的机制——**系统采样的间隔 $k$ 太大，跳过重要变化**。

#### 样本内误差 vs 对真函数偏差 —— 陷阱的两面

`e_in = 0.086`（模型在采样点上表现如何），`e_tu = 0.967`（模型在整个 $x$ 轴上实际多错）。

**做什么**：同一个线性模型，量它"在样本上看多好"与"对真相差多远"。
**输出**：样本内 0.086（看着几乎完美！）对真函数 0.967（完全错误）——**中间差了 11 倍**。
**对应数学**：这 4 个点恰好落在正弦的"上升段中点"附近，连起来几乎是一条直线——线性拟合在采样点上贴合完美，却完全没抓住起伏。这正是历史.md 里奈奎斯特-香农的"混叠 (aliasing)"：**采样间隔与信号周期相仿时，高频起伏被伪装成低频直线**。若只盯着训练误差（0.086），你会以为模型极好——这是采样陷阱最阴险的地方。

## 改个数字试试：系统采样的间隔 $k$ 多大才安全

### 实验：扫间隔，看样本内误差何时开始骗人

```python
for step in (0.8, 1.5, 2.0, np.pi):
    x = np.arange(0.3, 12.0, step)
    np.random.seed(8)
    y = true_fn(x) + np.random.normal(0, 0.05, len(x))
    c = np.polyfit(x, y, 1)
    e_in = np.mean((np.polyval(c, x) - y)**2)        # 样本内误差
    e_tu = np.mean((np.polyval(c, xx) - true_fn(xx))**2)  # 对真函数偏差
    print(f"间隔{step:.2f}({len(x):2d}点): 样本内={e_in:.3f} 对真函数={e_tu:.3f}")
```

输出：

```text
间隔0.80(15点): 样本内=0.928 对真函数=0.934
间隔1.50( 8点): 样本内=0.966 对真函数=0.952
间隔2.00( 6点): 样本内=0.791 对真函数=0.966
间隔3.14( 4点): 样本内=0.086 对真函数=0.967
```

读这张表：**间隔 ≤ 1.5 时，样本内误差与对真函数偏差几乎相等**（0.93~0.97）——样本诚实，欠拟合一眼可见（这是容量天花板的代价）；**间隔 ≥ 2.0 起，样本内误差开始"虚低"**（0.79），到间隔 $\pi$ 时跌到 0.086——**样本开始骗人，说"模型极好"，其实完全错了**。系统采样的陷阱不在"点太少"（间隔 1.5 只有 8 个点也没骗人），而在**间隔与起伏周期相仿**——那才是混叠发生的地方。真实工程里，随机化采样间隔（§4.3.13.2 主线 DL 桥接）就是在回避这条临界线。

## 边界声明：这套代码能做什么，不能做什么

1. **"对真函数偏差"是上帝视角，现实中没有。** toy 里我们捏造了真函数才能逐点打分；真实问题只能用验证集误差近似。但"加数据是否改善"的判断逻辑在真实里同样成立——只是验证集噪声会让改善线不再这么平滑。
2. **欠拟合不全是采样问题，容量是独立的一维。** ② 的 1.0671 证明：数据再密，直线也学不了曲线。**"加数据"与"加容量"是两个独立的旋钮**，本脚本的核心结论是"各救各的"——诊断顺序永远是先问加数据是否改善。
3. **稀疏样本 + 高容量模型的数字要小心读。** deg5 在 15 个稀疏点上偏差 1.0174，接近线性模型的 1.0305——这不完全是"欠拟合"的优雅失败，也包含高次多项式在小样本上**振荡**的成分（样本太少，约束不住高维模型）。定性的结论（稀疏→差，密集→好）是稳健的，具体数值对样本敏感。
4. **系统采样陷阱的前提是数据本身有起伏。** 对单调递增、无周期的数据，大步长采样不会骗人（没有"波峰波谷"可跳）。混叠只在"间隔 ≈ 变化周期"时发生——教材强调的"跳过重要起伏"，针对的正是周期性数据。
5. **这只是 1D toy。** 真实欠拟合是多维的：稀疏采样在哪个特征维度上发生、样本在高维空间里多稀疏，决定模型在哪些"角落"欠拟合。原理相同，维度更高。
