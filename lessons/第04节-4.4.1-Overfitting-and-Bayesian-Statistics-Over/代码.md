# 代码：过拟合与贝叶斯统计——让模型承认自己不知道

主线把贝叶斯抗过拟合讲成三件工具：**先验 = 正则化**、**模型比较为复杂度计费（BIC）**、**完整分布暴露过度自信**。本课代码复现教材 Figure 4.9 的场景（15 个含噪正弦点），并量化这三件工具：

1. **过拟合 vs 强先验**：15 次多项式（弱先验）与一次线性（强先验）在训练/测试误差上的对照——先验牺牲训练拟合，换来泛化。
2. **不确定性对照**：两者 95% 预测区间在训练点处与数据外（外推）的宽度——完整分布暴露"过度自信"。
3. **BIC 记账**：线性真值数据上比较 1 次与 15 次模型——复杂度惩罚如何起作用。

---

## 层一：完整脚本

```python
import numpy as np

def poly_basis(x, d):                     # 构造 0..d 次多项式基，输入 x:(n,)
    X = np.empty((len(x), d+1))
    for j in range(d+1):
        X[:, j] = x**j                    # 第 j 列 = x^j
    return X                              # 输出 X:(n, d+1)

def bayes_lr(X, y, s2, sig_w):            # 高斯先验 w~N(0,sig_w²I) 的贝叶斯线性回归
    lam = s2/sig_w**2                     # 先验强度 → 岭系数 λ = s²/σw²
    A = X.T@X + lam*np.eye(X.shape[1])
    mu = np.linalg.solve(A, X.T@y)        # 后验均值（=MAP 解）
    cov = s2*np.linalg.inv(A)             # 后验协方差（参数不确定性）
    return mu, cov

def predict(xs, mu, cov, s2):             # 后验预测均值与方差（含观测噪声）
    Phi = poly_basis(xs, len(mu)-1)
    m = Phi@mu                            # 预测均值
    v = np.sum((Phi@cov)*Phi, axis=1) + s2  # 预测方差
    return m, v

def bic(X, y, mu, s2):                    # BIC = k·ln n − 2·ln L
    n, k = X.shape
    rss = float(np.sum((y - X@mu)**2))
    lnL = -n/2*np.log(2*np.pi*s2) - rss/(2*s2)
    return k*np.log(n) - 2*lnL

# ---- 数据：15 个含噪正弦点（教材 Figure 4.9 的场景）----
np.random.seed(3)
n = 15
x = np.linspace(0, 2*np.pi, n);  xs = np.linspace(0, 2*np.pi, 400)
xn = (x-np.pi)/np.pi;  xsn = (xs-np.pi)/np.pi   # 归一化到 [-1,1]，防高次基数值爆炸
s2 = 0.05**2
y = np.sin(x) + np.random.normal(0, 0.05, n)   # 真值 sin 加高斯噪声

# ---- ① 过拟合：15 次多项式 + 极弱先验（几乎 = 最小二乘）----
mu_o, cov_o = bayes_lr(poly_basis(xn,15), y, s2, 1e6)
m_o, v_o = predict(xsn, mu_o, cov_o, s2)
# ---- ② 贝叶斯强先验：一次多项式 ----
mu_b, cov_b = bayes_lr(poly_basis(xn,1), y, s2, 0.1)
m_b, v_b = predict(xsn, mu_b, cov_b, s2)

# ---- ③ 训练 vs 测试误差（"测试"=无噪声真值 sin，即泛化能力）----
tr_o = ((poly_basis(xn,15)@mu_o - y)**2).mean();  te_o = ((m_o - np.sin(xs))**2).mean()
tr_b = ((poly_basis(xn,1)@mu_b - y)**2).mean();   te_b = ((m_b - np.sin(xs))**2).mean()
print(f"①过拟合  训练MSE={tr_o:.4f}  测试MSE={te_o:.4f}")
print(f"②贝叶斯  训练MSE={tr_b:.4f}  测试MSE={te_b:.4f}")

# ---- ④ 不确定性：训练点处 vs 数据外(外推)的平均 95% 区间宽度 ----
_, v_o_tr = predict(xn, mu_o, cov_o, s2);  _, v_b_tr = predict(xn, mu_b, cov_b, s2)
xo = np.linspace(2*np.pi, 3.2*np.pi, 200);  xon = (xo-np.pi)/np.pi
_, v_o_x = predict(xon, mu_o, cov_o, s2);   _, v_b_x = predict(xon, mu_b, cov_b, s2)
print(f"①过拟合 95%区间均宽：训练点={1.96*np.sqrt(v_o_tr).mean():.3f} 外推={1.96*np.sqrt(v_o_x).mean():.2e}")
print(f"②贝叶斯 95%区间均宽：训练点={1.96*np.sqrt(v_b_tr).mean():.3f} 外推={1.96*np.sqrt(v_b_x).mean():.3f}")

# ---- ⑤ BIC：给复杂度记账（线性真值数据上比较 1 次 vs 15 次）----
np.random.seed(2)
x2 = np.linspace(-1, 1, 30);  y2 = 0.5*x2 + 0.8 + np.random.normal(0, 0.2, 30)
s2e = 0.2**2
mu1, _ = bayes_lr(poly_basis(x2,1), y2, s2e, 1e6)
mu15, _ = bayes_lr(poly_basis(x2,15), y2, s2e, 1e6)
print(f"⑤BIC(1次)={bic(poly_basis(x2,1), y2, mu1, s2e):.2f}  BIC(15次)={bic(poly_basis(x2,15), y2, mu15, s2e):.2f}")
```

运行输出（Python 3.13 + NumPy 2.3）：

```text
①过拟合  训练MSE=0.0000  测试MSE=0.3193
②贝叶斯  训练MSE=0.2322  测试MSE=0.2143
①过拟合 95%区间均宽：训练点=0.139 外推=2.93e+09
②贝叶斯 95%区间均宽：训练点=0.104 外推=0.120
⑤BIC(1次)=-7.61  BIC(15次)=32.97
```

第一组数字：过拟合模型训练误差归零、测试误差 0.3193（背下了噪声）；贝叶斯模型训练误差 0.2322（不追求完美）、测试误差 0.2143（泛化好约 1.5 倍）。第二组：过拟合模型的区间在训练点处只有 0.139——**窄，但它声称的"95% 范围"连自己真实误差（测试 RMSE≈0.57）的零头都盖不住**；一旦外推，区间爆炸到 $2.9\times10^9$（Runge 现象）。贝叶斯模型从训练点的 0.104 平滑放宽到外推的 0.120——**证据不足处，诚实地张开嘴**。第三组：BIC 判定 1 次模型更优（-7.61 < 32.97），尽管 15 次拟合得更好。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：`poly_basis` —— 多项式基

```python
def poly_basis(x, d):
    X = np.empty((len(x), d+1))
    for j in range(d+1):
        X[:, j] = x**j
    return X
```

#### poly_basis —— 把标量 x 升维成 d+1 个特征

**做什么**：对每个输入 $x_i$ 构造 $[1, x_i, x_i^2, \ldots, x_i^d]$。
**操作**：第 `j` 列填 `x**j`。
**输入**：`x`，形状 `(n,)`，n 个样本点；`d`，最高次数。
**输出**：`X`，形状 `(n, d+1)`——第 `i` 行是第 `i` 个样本的 0..d 次幂特征。
**可调参数**：`d` 是唯一自由度——`d=1` 是直线（2 个参数），`d=15` 是 15 次曲线（16 个参数）。**`d` 越大，模型越能弯曲去贴合数据，也越容易过拟合。** 还可以传第 3 个参数控制"是否含偏置列"，这里用 0 次项 `x**0` 当偏置。
**对应数学**：把"用多项式拟合"翻译成线性回归——对特征 $X$ 线性，对 $x$ 非线性。

---

### 步骤 2：`bayes_lr` —— 贝叶斯线性回归（后验）

```python
def bayes_lr(X, y, s2, sig_w):
    lam = s2/sig_w**2
    A = X.T@X + lam*np.eye(X.shape[1])
    mu = np.linalg.solve(A, X.T@y)
    cov = s2*np.linalg.inv(A)
    return mu, cov
```

#### bayes_lr —— 高斯先验下的后验均值与协方差

**做什么**：求解带高斯先验 $w\sim\mathcal{N}(0,\sigma_w^2 I)$、观测噪声 $s^2$ 的线性回归后验。
**操作**：解析解。后验均值 $w_{MAP}=(X^\top X+\lambda I)^{-1}X^\top y$，后验协方差 $\Sigma=s^2(X^\top X+\lambda I)^{-1}$，其中 $\lambda=s^2/\sigma_w^2$。
**输入**：`X` 形状 `(n, d+1)`；`y` 形状 `(n,)`；`s2` 观测噪声方差；`sig_w` 先验标准差。
**输出**：`mu` 形状 `(d+1,)`（后验均值 = MAP 权重）；`cov` 形状 `(d+1, d+1)`（后验协方差 = 参数不确定性）。
**可调参数**：`sig_w` 是先验强度旋钮——极大（`1e6`）时 `lam≈0`，退化为普通最小二乘（无先验 = 过拟合极限）；越小先验越强，权重越被拉向 0。还可以传一个非对角先验协方差，控制"哪些权重组合该小"，这里用最简单的各向同性。
**对应数学**：`lam*np.eye(...)` 这一项就是主线第二节的 $\log P(w)$——**先验 = 正则化**。`sig_w=1e6` 是"几乎不约束"的弱先验，`sig_w=0.1` 是强先验。

---

### 步骤 3：`predict` —— 后验预测分布

```python
def predict(xs, mu, cov, s2):
    Phi = poly_basis(xs, len(mu)-1)
    m = Phi@mu
    v = np.sum((Phi@cov)*Phi, axis=1) + s2
    return m, v
```

#### predict —— 后验预测均值与方差

**做什么**：在新位置 `xs` 上给出预测分布的均值与方差。
**操作**：均值 $\phi(x)^\top\mu$；方差 $\phi(x)^\top\Sigma\phi(x)+s^2$——第一项是参数不确定性（数据证据不足处变大），第二项是观测噪声。
**输入**：`xs` 形状 `(m,)` 预测位置；`mu`/`cov` 后验参数；`s2` 观测噪声。
**输出**：`m` 形状 `(m,)` 预测均值；`v` 形状 `(m,)` 预测方差。
**可调参数**：`s2` 传入时控制观测噪声项；`xs` 可以取训练范围内（插值）或范围外（外推）——**外推时 `v` 会变大，这就是"数据不给证据处区间变宽"的机制**。
**对应数学**：主线第四节的 $P(y^*|x^*,D)=\int P(y^*|x^*,w)P(w|D)\,dw$——对高斯模型这个积分是闭式解。

---

### 步骤 4：`bic` —— 模型比较准则

```python
def bic(X, y, mu, s2):
    n, k = X.shape
    rss = float(np.sum((y - X@mu)**2))
    lnL = -n/2*np.log(2*np.pi*s2) - rss/(2*s2)
    return k*np.log(n) - 2*lnL
```

#### bic —— 给复杂度记账

**做什么**：计算 $\text{BIC}=k\ln n-2\ln\hat{L}$。
**操作**：`rss` 是残差平方和；`lnL` 是高斯噪声模型的对数似然；返回 `k*np.log(n) - 2*lnL`。
**输入**：`X` 形状 `(n, k)`；`y` 形状 `(n,)`；`mu` 模型权重；`s2` 观测噪声。
**输出**：一个标量——**BIC 越小，模型越好**。
**可调参数**：`k` 由 `X` 的列数自动决定，不能直接传——但你可以换 `X`（1 次基 vs 15 次基），`k` 就跟着变。**多雇一个参数，第二项就多付 $\ln n$。**
**对应数学**：主线第三节。第一项奖励拟合，第二项惩罚复杂度——"每个参数必须带来超过 $\ln n$ 的拟合提升"。

### 步骤 5：数据生成与两个模型

```python
np.random.seed(3)
x = np.linspace(0, 2*np.pi, n);  xs = np.linspace(0, 2*np.pi, 400)
xn = (x-np.pi)/np.pi;  xsn = (xs-np.pi)/np.pi
s2 = 0.05**2
y = np.sin(x) + np.random.normal(0, 0.05, n)
mu_o, cov_o = bayes_lr(poly_basis(xn,15), y, s2, 1e6)
mu_b, cov_b = bayes_lr(poly_basis(xn,1), y, s2, 0.1)
```

**做什么**：造出教材 Figure 4.9 的数据——15 个落在正弦曲线上的点，加标准差 0.05 的高斯噪声。
**关键细节**：`xn = (x-π)/π` 把数据归一化到 $[-1,1]$。**不归一化，$x^{15}$ 在 $x=2\pi$ 处高达约 $10^{12}$，设计矩阵会病态，数值就爆炸了。**
**模型 ①**：15 次多项式、弱先验 `sig_w=1e6`——16 个参数去贴合 15 个点，这是"复杂度超过数据能支撑的程度"的过拟合设定。
**模型 ②**：一次多项式、强先验 `sig_w=0.1`——2 个参数 + 强收缩，这是教材的"简单线性 + 高斯噪声模拟不确定性"的贝叶斯模型。
**对应数学**：教材 Figure 4.9 的红线与蓝线。

### 步骤 6：训练 vs 测试误差，与区间宽度

```python
tr_o = ((poly_basis(xn,15)@mu_o - y)**2).mean();  te_o = ((m_o - np.sin(xs))**2).mean()
print(f"①过拟合  训练MSE={tr_o:.4f}  测试MSE={te_o:.4f}")
...
print(f"①过拟合 95%区间均宽：训练点={1.96*np.sqrt(v_o_tr).mean():.3f} 外推={1.96*np.sqrt(v_o_x).mean():.2e}")
```

**做什么**：① 训练误差在训练点上评估；**"测试误差"用无噪声的真值 $\sin(x)$ 在密集网格上评估——新数据没有噪声，测的就是泛化能力**。② 95% 区间宽度 = $1.96\times$ 预测标准差，在训练点处与数据外（$x\in[2\pi,3.2\pi]$）各取平均。
**解读**：
- 过拟合：训练 0.0000、测试 0.3193——**训练完美，泛化最差**。
- 贝叶斯：训练 0.2322、测试 0.2143——**牺牲一点训练拟合，泛化好约 1.5 倍**。
- 过拟合区间：训练点处 0.139（窄且自信），外推 2.93e+09（Runge 爆炸）——**它在背下的噪声之间极度自信，一离开数据就崩溃**。
- 贝叶斯区间：0.104 → 0.120——**平滑、诚实地在证据不足处放宽**。
**对应数学**：主线第二、四节——先验=正则化、完整分布暴露过度自信。

### 步骤 7：BIC 记账

```python
np.random.seed(2)
x2 = np.linspace(-1, 1, 30);  y2 = 0.5*x2 + 0.8 + np.random.normal(0, 0.2, 30)
s2e = 0.2**2
mu1, _ = bayes_lr(poly_basis(x2,1), y2, s2e, 1e6)
mu15, _ = bayes_lr(poly_basis(x2,15), y2, s2e, 1e6)
print(f"⑤BIC(1次)={bic(poly_basis(x2,1), y2, mu1, s2e):.2f}  BIC(15次)={bic(poly_basis(x2,15), y2, mu15, s2e):.2f}")
```

**做什么**：换一组**真实就是直线**的数据（$y=0.5x+0.8$ + 噪声），让 1 次与 15 次模型都跑一遍 BIC。为什么换数据？因为正弦数据的真实函数不是直线——15 次多项式在那里"真的拟合得更好"，BIC 判定它更优是合理的。**BIC 惩罚的是"只买到噪声"的复杂度**，所以演示它必须用"简单模型就是对的"的数据。
**解读**：1 次 BIC=−7.61，15 次 BIC=32.97。15 次拟合确实更好（残差 0.80 < 1.08），但复杂度账单 $14\ln30\approx47.6$ 远超拟合收益——**净亏约 40 分，被记账**。
**对应数学**：主线第三节——"每个多出来的参数都要收费"。

## 改个数字试试：先验强度从强到弱

### 实验：固定 15 次模型，把先验 $\sigma_w$ 从 0.01 拧到 1e6

```python
for sw in (0.01, 0.1, 1.0, 1e6):
    mu_s, _ = bayes_lr(poly_basis(xn,15), y, s2, sw)
    rss_s = float(np.sum((poly_basis(xn,15)@mu_s - y)**2))
    print(f"σw={sw:>7}: 训练残差={rss_s:.4f}  最大|w|={np.abs(mu_s).max():.3f}")
```

输出（同批正弦数据）：

```text
σw=   0.01: 训练残差=5.5770  最大|w|=0.136
σw=    0.1: 训练残差=0.7860  最大|w|=1.546
σw=    1.0: 训练残差=0.0228  最大|w|=3.480
σw=1000000.0: 训练残差=0.0000  最大|w|=2760.780
```

先验从强到弱：最大权重从 0.136 涨到 2760——**先验把权重"收缩"得越小，模型越不敢弯曲；先验一松开，权重就疯狂膨胀去贴合噪声，训练残差一路压到 0。** 这正是主线第二节"先验 = 正则化（shrinkage）"的现场。强先验（0.01）此时把模型压得太狠（残差 5.58，欠拟合）——**先验不是越强越好，教材 Figure 4.9 里的强先验是"强得刚好"。**

## 边界声明：这套代码能做什么，不能做什么

1. **贝叶斯不能凭空消灭过拟合。** 先验太弱（`sig_w` 大）照样过拟合；先验太强（`sig_w=0.01`）会欠拟合，把真实信号也压掉。"先验防过拟合"与"先验制造欠拟合"是同一把刀的两面。
2. **BIC 演示特意用了"真实是直线"的数据。** 在正弦数据上，15 次多项式确实拟合得更好，BIC 判它更优是*合理*的——**BIC 惩罚的是"只买到噪声"的复杂度，不是"拟合得好"。** 如果你把本节代码套到真实世界，先问一句"简单模型是否真的接近真相"。
3. **`s2` 是写死的。** 这里假设观测噪声已知（0.05²）；若真实噪声被严重低估，贝叶斯同样给出窄而不准的区间——**贝叶斯保证"在给定模型类与噪声下诚实地量化不确定性"，不保证模型类正确**（呼应主线边界声明）。
4. **这只是单维的 toy。** 真实深度网络有百万权重、高维特征，weight decay 的原理相同（高斯先验 → L2），但"区间宽度"的直观远没有这个一维例子这么清楚。
