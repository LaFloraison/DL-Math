# 习题：过拟合与贝叶斯统计

## 第一组：概念检验

**1. 什么是过拟合？教材给出的成因是什么？为什么"训练误差接近零"不但不是好消息，反而是可疑的信号？**

**解答**：过拟合 (overfitting) 是统计模型捕获了数据中的噪声或随机波动、而非真实潜在模式。成因是**模型复杂度超过数据能支撑的程度**——参数太多、样本太少、或噪声太大。训练误差接近零意味着模型把噪声也"背"了下来：数据把信号与噪声混在一起递给你，一个自由度足够的模型可以同时拟合两者，于是它在训练集上无懈可击、在新数据上崩溃。**"训练误差最小"不是好模型的标准，因为噪声是能被背下来的。**

**2. 贝叶斯统计给了哪三件对抗过拟合的工具？用一句话概括每一件。**

**解答**：① **先验 = 正则化**——给参数一个偏好合理值的先验 $w\sim\mathcal{N}(0,\sigma_w^2)$，MAP 求解等价于 L2 正则化，把估计拉向 0（收缩, shrinkage），防止模型钻入噪声；② **模型比较为复杂度计费**——BIC/DIC 在拟合度与复杂度之间平衡，每多一个参数多付 $k\ln n$，惩罚不必要的复杂度；③ **完整分布暴露过度自信**——贝叶斯给出后验预测分布而非点估计，过拟合模型会显示窄到不可信的置信区间，良好贝叶斯模型在数据证据不足处显示更宽的区间。

**3. 判断题并说明理由："贝叶斯统计永远不会过拟合，因为它有先验。"**

**解答**：错误。先验只是降低过拟合的风险，不是保证——先验太弱（$\sigma_w$ 大、数据少、噪声大）时照样过拟合；先验太强或选错（中心错）时会**欠拟合**，把真实信号也压掉。"先验防过拟合"与"先验制造欠拟合"是同一把刀的两面。贝叶斯的承诺是"让不确定性可见、让先验有分量"，不是"永远不犯错"。

**思路点拨**：若有人选"贝叶斯永远不会过拟合"，他混淆了"降低风险"与"消灭风险"。教材明确说的是先验"可以"收缩估计、防止过度贴合噪声——它是有条件的好工具，不是免死金牌。

## 第二组：计算实践

**4. 手算 + 代码验证。** 在 15 个含噪正弦点上，比较 15 次多项式（弱先验 $\sigma_w=10^6$）与一次线性（强先验 $\sigma_w=0.1$）的**训练 MSE** 与**测试 MSE**（测试用无噪声真值 $\sin$）。分别回答：（a）两者的训练误差各是多少？哪个"拟合得更好"？（b）两者的测试误差各是多少？哪个"泛化更好"？（c）结论是什么？

**解答**：（a）过拟合模型训练 MSE≈0.0000（完美背下 15 个含噪点），贝叶斯模型训练 MSE≈0.2322——只看训练，过拟合"完胜"。（b）过拟合模型测试 MSE≈0.3193，贝叶斯模型测试 MSE≈0.2143——泛化上贝叶斯好约 1.5 倍。（c）**训练误差归零不说明泛化好；先验牺牲一点训练拟合，换来更好的泛化。**

代码验证：

```python
import numpy as np
def poly(x, d): return np.vander(x, d+1, increasing=True)
def bayes(X, y, s2, sw):
    lam = s2/sw**2; A = X.T@X + lam*np.eye(X.shape[1])
    return np.linalg.solve(A, X.T@y), s2*np.linalg.inv(A)
np.random.seed(3)
x = np.linspace(0, 2*np.pi, 15); xs = np.linspace(0, 2*np.pi, 400)
xn = (x-np.pi)/np.pi; xsn = (xs-np.pi)/np.pi
y = np.sin(x) + np.random.normal(0, 0.05, 15)
mu_o, _ = bayes(poly(xn,15), y, 0.05**2, 1e6)
mu_b, _ = bayes(poly(xn,1),  y, 0.05**2, 0.1)
m_o = poly(xsn,15)@mu_o;  m_b = poly(xsn,1)@mu_b
print(f"过拟合15次 训练MSE={((poly(xn,15)@mu_o-y)**2).mean():.4f}  测试MSE={((m_o-np.sin(xs))**2).mean():.4f}")
print(f"贝叶斯一次 训练MSE={((poly(xn,1)@mu_b-y)**2).mean():.4f}  测试MSE={((m_b-np.sin(xs))**2).mean():.4f}")
```

输出：

```text
过拟合15次 训练MSE=0.0000  测试MSE=0.3193
贝叶斯一次 训练MSE=0.2322  测试MSE=0.2143
```

**思路点拨**：若有人答"训练误差为 0 所以 15 次模型更好"，他正重复教材要纠正的错觉——**训练误差为 0 意味着把噪声背了下来**。评估模型必须用没参与训练的数据（这里用无噪声的真值 $\sin$ 充当"测试集"）。另外注意 `xn=(x-np.pi)/np.pi` 的归一化：不做这一步，$x^{15}$ 会在 $x=2\pi$ 处爆炸成 $10^{12}$，矩阵病态，数值全错。

**5. 手算 + 代码验证。** 在线性真值数据（$y=0.5x+0.8+$ 噪声，30 点）上，比较 1 次模型与 15 次模型的 BIC。（a）分别写出 BIC 的两项——拟合项 $-2\ln\hat{L}$ 与复杂度项 $k\ln n$——并手算它们的值；（b）为什么 15 次拟合更好，BIC 却判它更差？（c）这个例子说明 BIC 惩罚的是什么？

**解答**：噪声 $s_e^2=0.2^2$，$n=30$，$\ln n\approx3.40$。1 次模型：$k=2$，复杂度项 $k\ln n\approx6.80$，残差平方和 1.0807，拟合项 $-2\ln\hat{L}\approx-14.41$，BIC $\approx-7.61$。15 次模型：$k=16$，复杂度项 $16\times3.40\approx54.4$，残差平方和 0.7991，拟合项 $\approx-21.46$，BIC $\approx32.97$。（b）15 次模型确实拟合得更好（残差从 1.08 降到 0.80），但这 14 个额外参数总共只买来约 7 分的拟合提升（$-2\Delta\ln\hat{L}\approx7$），却要付约 47.6 分的复杂度账单——**净亏约 40 分**，所以 BIC 判它更差。（c）BIC 惩罚的是"**只买到噪声**的复杂度"——在真实就是直线的数据上，15 次模型的高次项只是在追噪声。

代码验证：

```python
import numpy as np
def poly(x, d): return np.vander(x, d+1, increasing=True)
def bayes(X, y, s2, sw):
    lam = s2/sw**2; A = X.T@X + lam*np.eye(X.shape[1])
    return np.linalg.solve(A, X.T@y), None
def bic(X, y, mu, s2):
    n, k = X.shape
    rss = float(np.sum((y-X@mu)**2))
    lnL = -n/2*np.log(2*np.pi*s2) - rss/(2*s2)
    return k*np.log(n) - 2*lnL
np.random.seed(2)
x2 = np.linspace(-1, 1, 30);  y2 = 0.5*x2 + 0.8 + np.random.normal(0, 0.2, 30)
mu1, _  = bayes(poly(x2,1),  y2, 0.2**2, 1e6)
mu15, _ = bayes(poly(x2,15), y2, 0.2**2, 1e6)
print("BIC(1次) =", round(bic(poly(x2,1), y2, mu1, 0.2**2), 2))
print("BIC(15次) =", round(bic(poly(x2,15), y2, mu15, 0.2**2), 2))
```

输出：

```text
BIC(1次) = -7.61
BIC(15次) = 32.97
```

**思路点拨**：若有人问"为什么 BIC 不用正弦数据演示"，那正是要小心的地方——**正弦数据的真实函数不是直线**，15 次多项式在那里"真的拟合得更好"，BIC 判它更优是合理的。BIC 惩罚的是"只买到噪声的复杂度"；只有当简单模型接近真相时，复杂度账单才真正生效。**BIC 是相对比较，不是验证模型类是否正确。**

**6. 先验强度实验。** 固定 15 次模型，把先验 $\sigma_w$ 从 0.01 拧到 1e6，观察训练残差平方和与最大权重 $|w|_{max}$ 如何变化，并解释：哪个设置最像教材 Figure 4.9 的红线（过拟合）？哪个设置会造成欠拟合？

**解答**：见《代码.md》"改个数字试试"。$\sigma_w=0.01$（极强先验）时最大权重仅 0.136、训练 RSS 高达 5.577（曲线被压平，连正弦趋势都没抓住——**欠拟合**）；$\sigma_w=1e6$（极弱先验）时最大权重暴涨到 2760、训练 RSS 归零（曲线钻进每个噪声点——**过拟合**，即红线）；教材蓝线对应的强先验在两者之间（$\sigma_w\approx0.1$ 附近，RSS 0.786，能抓趋势、不钻噪声）。**先验不是越强越好，"强得刚好"才正确。**

**思路点拨**：若有人答"$\sigma_w$ 越小模型越准"，他只看了"收缩防过拟合"这一面，忽略了收缩过头会把真实信号也压掉。**先验的强弱是一个需要权衡的旋钮，不是越大/越小越好**——这正是贝叶斯模型选择（BIC/交叉验证）要解决的问题。

## 第三组：DL 延伸

**7. 医学影像的 OOD 场景。** 一个肺结节诊断模型在训练分布内的影像上准确率很高，但在一种未见过的新型扫描设备产生的影像上，它给出的**置信度几乎全是 99%**。（a）用本节概念解释：这个"高置信度"为什么值得警惕？（b）你会用哪种贝叶斯工具来诊断它？它会给出什么信号？（c）如果改用 MC-dropout，在新型设备影像上你会期望它的不确定性表现如何？

**解答**：（a）这是教材说的"不可信的窄置信区间"——**过拟合/分布偏移下的过度自信**。模型在没见过的情况下照样笃定，恰恰是"把训练分布里的相关性当成了规律"的征兆；置信度窄到与真实误差不相称，是过度自信的信号。（b）改用贝叶斯方法（BNN / MC-dropout），让模型输出完整预测分布。在新型设备影像（数据证据不足）上，**后验预测分布应当自动变宽**——如果变宽了，说明模型诚实地"知道自己不知道"；如果仍然窄，说明模型类或噪声假设本身有问题。（c）MC-dropout 通过多次随机前向取方差：在 OOD 影像上，不同 dropout 遮罩下的预测会剧烈分歧，**不确定性方差应当显著变大**——这是"数据不给证据处区间变宽"的深度网络版本。

**思路点拨**：若有人答"置信度 99% 说明模型很可靠"，他中了过度自信的陷阱——**高置信度本身不能证明模型正确**，尤其当它出现在训练分布之外。贝叶斯视角的反问是：你的不确定性来自哪里？数据给过证据吗？

**8. 架构选择场景。** 你在选一个图像分类网络的宽度（参数个数）。验证集损失曲线显示：网络 A 参数少、验证损失 0.30；网络 B 参数多、验证损失 0.29。（a）用 BIC 的精神解释：为什么不能只看验证损失选 B？（b）早停、weight decay、dropout 在贝叶斯框架下分别扮演什么角色？（c）double descent 现象为什么提醒我们"复杂度一定坏"的直觉需要修正？

**解答**：（a）BIC 的精神是"每个参数都要收费"：B 只比 A 好 0.01 的验证损失，但付出了多得多的参数——**好的拟合要扣掉复杂度的账单**。选模型不能只看拟合，还要看它"花多少钱买到了这 0.01"。（b）**weight decay = 高斯先验的 MAP**（把权重拉向 0，即先验=正则化）；**dropout = 对权重施加随机遮罩的先验结构，训练时的贝叶斯/变分近似**；**早停 = 限制后验离先验（初始化附近）太远的隐式正则化**——三者是"别让模型离开先验太远"这一主题的三个乐器。（c）double descent 显示：当参数多到远超数据（超参数化）时，模型反而可能恢复泛化——**"复杂度一定坏"在超参数化区域不成立**。这意味着 BIC 式的"复杂度罚分"不是普适定律，而是一个需要和具体区域（欠参数化 vs 超参数化）一起看待的启发。

**思路点拨**：若有人答"验证损失 0.29 < 0.30，所以选 B"，他忽略了模型选择的记账视角——**单看拟合最优会永远走向最复杂的模型**，这正是过拟合的源头。BIC 的复杂度项就是把这个直觉公式化。
