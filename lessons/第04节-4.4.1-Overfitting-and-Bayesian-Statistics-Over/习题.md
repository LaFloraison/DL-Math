# 习题：过拟合与贝叶斯统计

## 第一组：概念检验

**1. 贝叶斯统计抗过拟合的机制有哪些？用一句话概括每一条。**

**解答**：① **先验 = 正则化**——高斯先验对应 L2 收缩，把参数拉向合理值，防小数据/噪声主导；② **模型比较带复杂度惩罚**——BIC/DIC 在拟合度与复杂度间平衡，惩罚不必要的复杂度；③ **完整分布暴露过度自信**——过拟合模型给离谱窄的置信区间，贝叶斯模型在数据不足处给诚实的宽区间。

**2. 为什么"先验偏好简单"能防过拟合，但前提是什么？**

**解答**：后验对数 $\log P(\theta|D)=\log P(D|\theta)+\log P(\theta)$——似然项被噪声主导时，先验项把估计拉向合理值（收缩），防模型拟合噪声。**前提是"简单确实接近真相"**——教材 Figure 4.9 里真实是平滑的 $\sin$，所以直线先验是对的；若真实规律剧烈弯曲，强先验会把模型带偏（欠拟合）。**先验防过拟合与先验制造欠拟合是同一把刀的两面。**

**3. 判断题并说明理由："贝叶斯统计永远不会过拟合，因为它有先验。"**

**解答**：错误。先验降低过拟合的风险，但不是保证——先验太弱（数据少、噪声大）时照样过拟合；先验选错（与真相不符）时会欠拟合。**贝叶斯的承诺是"让不确定性可见、让先验有分量"，不是"永远不犯错"。** 教材明确列出"先验选择的主观性可能导致偏差"这一挑战。

## 第二组：计算实践

**4. 手算 + 代码验证。** 给带噪声的 $\sin$ 数据（30 点）分别拟合 15 次多项式与岭回归（$\lambda=2$）。（a）两者的训练点误差？（b）对真函数的误差？（c）结论。

**解答**：见《代码.md》层一。15 次多项式训练点误差 0.000（完美背下噪声）、真函数误差 0.313；岭回归训练点误差 0.040（不追求完美）、真函数误差 0.055（泛化好近 6 倍）。**结论：贝叶斯正则化的"不完美"换来更好的泛化——训练误差小不说明泛化好。**

代码验证：

```python
import numpy as np
np.random.seed(0)
x = np.random.uniform(0, 6, 30); y = np.sin(x) + np.random.normal(0, 0.2, 30)
c15 = np.polyfit(x, y, 15)
print("15次 训练点误差 =", round(np.mean((np.polyval(c15, x) - y)**2), 5))
X = np.vander(x, 2, increasing=True)
cb = np.linalg.solve(X.T@X + 2*np.eye(2), X.T@y)
print("岭回归 训练点误差 =", round(np.mean((X@cb - y)**2), 4))
```

输出：

```text
15次 训练点误差 = 0.00000
岭回归 训练点误差 = 0.0402
```

**思路点拨**：若有人答"15 次多项式训练误差为 0 所以模型更好"，他正是教材要纠正的错觉——**训练误差 0 意味着把噪声背了下来**。岭回归"牺牲"一点训练拟合，是为了不拟合噪声。

**5. λ 扫描实验。** 把岭回归的 $\lambda$ 从 0 改到 50，观察对真函数的误差，找出最优 λ，解释"太弱/太强"各自对应什么。

**解答**：见《代码.md》"改个数字试试"。$\lambda=0$（无先验）误差 0.109，$\lambda=2$ 时 0.055（最佳平衡），$\lambda=50$ 时 0.164（先验太强，把直线压成近乎平线——欠拟合）。**λ 太弱防不了过拟合，太强制造欠拟合；最优点在中间**——这正是贝叶斯模型选择（BIC/交叉验证）要解决的问题。

## 第三组：DL 延伸

**6. 早停场景。** 训练 CNN，训练损失持续下降、验证损失在第 20 epoch 触底。（a）用贝叶斯语言解释早停为什么是隐式正则化。（b）为什么"训练损失继续降"不代表"后验更好"？（c）早停、weight decay、dropout 在贝叶斯框架下是什么关系？

**解答**：
（a）贝叶斯后验 $\log P(w|D)=\log P(D|w)+\log P(w)$——训练从先验（初始化附近）出发，逐步走向数据；早停在验证损失上升前截断，**让最终权重停在"离先验不太远"的地方**——相当于"别让后验被似然带太远"，是隐式正则化。
（b）训练损失继续降 = 似然项 $\log P(D|w)$ 继续涨——但模型开始把噪声背下来，**"对训练数据的似然"与"对新数据的表现"脱节**。后验的"更好"要看验证数据（没被训练过的那部分），不是训练数据。
（c）三者都是贝叶斯"别让模型离开先验太远"的不同实现：**早停**限制"走了多远"（路径截断）、**weight decay** 惩罚"离 0 多远"（高斯先验）、**dropout** 施加"随机遮罩的先验结构"（变分推断）——**同一个贝叶斯正则化主题的三个乐器**。
**思路点拨**：若有人答"早停只是省时间"，他漏了它的统计身份——它是隐式正则化，限制模型走向先验（简单）的偏离。若有人答"训练损失降到最低就是最好的模型"，他重复了教材要纠正的错觉——**训练似然最大化过头 = 过拟合**。
