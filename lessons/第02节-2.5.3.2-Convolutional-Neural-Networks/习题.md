# 习题：卷积神经网络

## 第一组：概念检验

**1.1（单选）** 卷积层与全连接层最本质的区别是：
- A. 卷积层是非线性的，全连接层是线性的
- B. 卷积层在每个局部邻域上应用**同一个**可学习小矩阵（核），全连接层用一个大矩阵作用在整个输入上
- C. 卷积层处理二维数据，全连接层只能处理一维数据
- D. 卷积层每个位置用不同的模板，全连接层所有位置共用同一组权重

**1.2（判断并说明）** "卷积层是线性运算，所以即便堆叠 100 层且每层之间都不接激活函数，整个网络依然等价于一个线性变换。" 这句话对吗？为什么？

**1.3（填空）** 一张 $6\times6$ 的图像，用 $3\times3$ 核、stride=1：
- 无 padding 时输出尺寸 = ____×____；
- padding=1 时输出尺寸 = ____×____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 图像 $I = \begin{bmatrix} 1 & 0 & 0 \\ 1 & 0 & 0 \\ 1 & 0 & 0 \end{bmatrix}$（左列白、右两列黑——一条垂直边界），核 $F = \begin{bmatrix} 1 & -1 \\ 1 & -1 \end{bmatrix}$。手算出 $2\times2$ 特征图的每个值，再用 NumPy 验证。

**2.2（代码验证）** 卷积的**线性**：用代码验证叠加原理——对任意图像 $I_1, I_2$ 和标量 $a$，核 $K$ 满足 $K\star(I_1+I_2)=K\star I_1+K\star I_2$ 且 $K\star(aI_1)=a\,(K\star I_1)$。写出验证代码并解释输出。

**2.3（计算）** 一张 $32\times32$ 的图，用 $5\times5$ 核：
- stride=1、padding=2 时输出尺寸？
- stride=2、padding=0 时输出尺寸？（公式 $\lfloor (H+2p-k)/s \rfloor + 1$）

## 第三组：DL 延伸

**3.1（场景判断）** 一个卷积层的输入是形状 `(B=8, C_in=3, H=32, W=32)` 的彩色图像批次，层内 $C_{\text{out}}=16$ 个 $3\times3$ 核，stride=1、padding=1。
- 输出形状是什么？每一维分别代表什么？
- 这一层有多少个可学习参数（权重 + 偏置）？写出计算式。

**3.2（场景分析）** 平移不变性（translation invariance）是 CNN 的招牌性质：把图像里的猫整体平移 3 个像素，卷积特征图跟着平移，分类结果基本不变——这对"图片里有没有猫"是好事。但请指出：在什么任务里，这种"不管物体在哪都同样对待"反而有害？说出你的理由。

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：主线核心——卷积核是一个被**共享**的小线性变换，在所有局部邻域复用；全连接层则是一次性的大矩阵线性变换。A 错：卷积层本身是线性的；C 错：全连接层照样能吃展平后的二维数据，只是丢掉空间结构；D 的表述正好说反（卷积才是"到处用同一组模板"）。
- **点拨**：这道题考的不是"卷积在视觉上更酷"，而是主线的一句话——**参数共享 + 局部性**是卷积与全连接在数学结构上的分野。选 A 的人把"CNN 里卷积后有 ReLU"误当成"卷积本身非线性"了。

**1.2 这句话对。**
- **思路**：卷积是线性组合（点积求和）；线性映射的复合仍是线性映射。所以 100 层纯卷积（无激活）等价于一层大线性变换，表达能力不会随深度增长。CNN 必须在卷积之间插入 ReLU 等非线性，深度才有意义。
- **点拨**：这是"卷积是线性运算"的推论，也是边界声明 1 要你记住的事。容易答反的人，是把"网络里用了非线性激活"与"卷积层自带非线性"混为一谈了。

**1.3 答案：无 padding 时 $4\times4$；padding=1 时 $6\times6$。**
- **思路**：无 padding：$(6+0-3)/1+1=4$。padding=1 相当于高宽各加 2：$(6+2-3)/1+1=6$——尺寸完全保住。
- **点拨**：padding 的作用就是"把图像外围补零，防止尺寸萎缩"。记住公式 $\lfloor (H+2p-k)/s\rfloor+1$，它就是主线定义块里"输出尺寸"的完整版。

### 第二组

**2.1**
核 $F$ 有 $2\times2=4$ 个权重。核能放的位置：横 $(3-2+1)=2$、竖 $2$，共 4 个。

- 位置 $(0,0)$：盖住 $I[0:2, 0:2]=\begin{bmatrix}1&0\\1&0\end{bmatrix}$，得 $1\cdot1+(-1)\cdot0+1\cdot1+(-1)\cdot0=2$
- 位置 $(0,1)$：盖住 $I[0:2, 1:3]=\begin{bmatrix}0&0\\0&0\end{bmatrix}$，得 $0$
- 位置 $(1,0)$：盖住 $I[1:3, 0:2]=\begin{bmatrix}1&0\\1&0\end{bmatrix}$，得 $2$
- 位置 $(1,1)$：盖住 $I[1:3, 1:3]=\begin{bmatrix}0&0\\0&0\end{bmatrix}$，得 $0$

特征图 $\begin{bmatrix} 2 & 0 \\ 2 & 0 \end{bmatrix}$。核在左列"嗅"到白黑突变（左白右黑），输出 2；一进到全黑区域就哑火。它是一台**垂直边探测器**。

```python
import numpy as np
I = np.array([[1,0,0],[1,0,0],[1,0,0]], dtype=float)
F = np.array([[1,-1],[1,-1]], dtype=float)
oh = I.shape[0] - F.shape[0] + 1
ow = I.shape[1] - F.shape[1] + 1
fm = np.zeros((oh, ow))
for i in range(oh):
    for j in range(ow):
        fm[i, j] = np.sum(I[i:i+F.shape[0], j:j+F.shape[1]] * F)
print(fm)
# [[2. 0.]
#  [2. 0.]]
```
- **思路**：每个输出值 = 核与对应 $2\times2$ 邻域的点积。手算的意义在于亲眼看"同一个核、四个位置、四个点积"。
- **点拨**：容易漏掉的是"核要放得下"——$3\times3$ 图配 $2\times2$ 核只有 4 个位置，不是 9 个。位置数永远由 $(H-k+1)(W-k+1)$ 决定。

**2.2**
```python
import numpy as np

def conv2d(img, ker):
    oh = img.shape[0] - ker.shape[0] + 1
    ow = img.shape[1] - ker.shape[1] + 1
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            out[i, j] = np.sum(img[i:i+ker.shape[0], j:j+ker.shape[1]] * ker)
    return out

rng = np.random.default_rng(0)
I1, I2, K = rng.random((6,6)), rng.random((6,6)), rng.random((3,3))
a = 2.5
print("叠加性:", np.allclose(conv2d(I1+I2, K), conv2d(I1,K) + conv2d(I2,K)))  # True
print("齐次性:", np.allclose(conv2d(a*I1, K), a * conv2d(I1,K)))              # True
```
- **思路**：`conv2d` 是我们手写卷积的复刻；`np.allclose` 判断两次计算逐元素相等。两个 True 表明卷积对加法和数乘都封闭——这正是**线性变换**的定义（叠加原理）。
- **点拨**：这个性质解释了为什么卷积能被当"线性变换"分析，也预告了它必须配非线性激活才有深度价值。

**2.3**
- stride=1、padding=2：$\lfloor (32+2\cdot2-5)/1 \rfloor+1 = 32$ → $32\times32$（尺寸完全保住）。
- stride=2、padding=0：$\lfloor (32-5)/2 \rfloor+1 = \lfloor 13.5 \rfloor+1 = 14$ → $14\times14$（近似减半）。
- **思路**：padding 补尺寸、stride 省计算，两者互相拮抗。$s=2$ 时特征图立刻缩小一半，是深层 CNN 常用的"下采样"手段。
- **点拨**：$13.5$ 要**向下取整**——核放不下的最后半个位置被丢弃。有人会算出 15，那是忘了取整。

### 第三组

**3.1**
- **输出形状：`(8, 16, 32, 32)`**。第 0 维 B=8（8 张图）；第 1 维 C_out=16（16 个核 → 16 张特征图/通道）；后两维 32×32 由 $p=1$ 保住尺寸。**第 1 维就是"用了几个核"**（对应代码.md 步骤 6 的 `(2,3,3)` 雏形）。
- **参数数**：每个 $3\times3$ 核有 $3\times3\times C_{\text{in}}=9\times3=27$ 个权重 + 1 个偏置，共 28；16 个核 → $16\times28=448$。注意**参数与图像大小 32×32 无关**——这就是"共享"的红利：同样输出 16 通道，全连接层需要 $(32\times32\times3)\times 16 \approx 49{,}000$ 个参数。
- **点拨**：参数公式 $C_{\text{out}}\times(k^2\times C_{\text{in}}+1)$ 值得背下来。有人把 $C_{\text{in}}=3$ 漏掉，算出 $16\times10=160$——错在忘了核要同时看 RGB 三个通道。

**3.2**
- **反例：位置本身是信息的任务。** 例 1，医疗影像：同一个肺结节，长在肺尖和长在肺门，临床意义完全不同——你既想要"有没有结节"，也想要"结节在哪"。卷积特征图会跟着平移，分类器可能只学了"有猫"，而"在哪"的信息被结构性地丢弃。例 2，自动驾驶：一辆车在左车道还是右车道，直接决定下一步怎么打方向盘；"平移不变"在这里是致命的。
- **修正思路**：这类任务要么在特征图上保留位置（用坐标回归头、或融合位置编码），要么对平移敏感的那层不做全局池化。
- **点拨**：CNN 的"平移不变"是把双刃剑——它来自"核到处复用"，这正是本节的结构核心。能指出"共享带来不变、不变在有些任务里有害"，才算真正吃透了参数共享的含义。

## 一个"为什么有人会答错"的提醒

1.1 的 A 是高频错选：人们看到"CNN"就想到 ReLU，误以为卷积自带非线性——**卷积层本身是线性变换，非线性来自它后面的激活函数。** 1.2 若把"网络线性"答成"不对"，也是栽在同一个误会。2.1 的另一处坑：有人会把 $2\times2$ 核当成 $3\times3$ 去对齐，手算时把图像里不存在的像素也算进去——**邻域大小永远等于核的大小**。3.1 的参数题漏乘 $C_{\text{in}}$，是"形状语义没吃透"的典型信号：多一个通道，核就多一组平面权重。
