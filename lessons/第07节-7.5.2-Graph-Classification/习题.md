# §7.5.2 图分类 —— 习题

主线讲了图分类的三件套：GCN 聚合 → 全局池化 → 分类器。下面三组习题检验你是否理解"怎么把整张图压成一个向量"。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：全局池化要满足的最关键性质是什么？

- A. 保持节点的顺序
- B. 排列不变——节点编号改变，池化结果不变
- C. 让图表示越短越好
- D. 保留所有节点信息无损

**解答**：B。

**思路点拨**：图没有天然顺序，节点怎么编号都不该改变"整张图"的判断，所以池化必须排列不变（sum/mean/max 都满足）。A 恰恰相反。D 错——池化是有损的（这也是边界声明）。常见错选 D，把"压缩"误当"无损编码"。

### 题 2（简答）：sum、mean、max 三种池化的语义差别是什么？各在什么场景合适？

**解答**：sum 保留"总量"（节点多 → 图向量大），适合"规模是信号"的场景（反洗钱里转账账户多可能是团伙信号）；mean 消除规模（只看平均面貌），适合"规模无关"的场景（分子性质：原子数多少不该决定"是否有毒"）；max 只看最强信号（逐维取最大），适合"某个关键特征说了算"的场景（图里有一个特别突出的可疑信号）。

**思路点拨**：答题锚点是"每种池化选什么当图的特征"。能把"规模是否信息"作为 sum vs mean 的分界就说透了。常见错误是以为三种池化只是实现细节。

### 题 3（判断）：图分类和节点分类，哪种更难"看见局部结构"？为什么？

**解答**：图分类更难。节点分类给每个节点贴标签，每个节点的表示保留了自己的局部邻域；图分类要把整张图压成一个向量（全局池化），**这个压缩是有损的**——图里某个关键的局部结构（比如"中心藏着一个可疑账户"）可能在池化里被稀释/抹掉。现代方法用层级池化（先局部后全局）缓解。

**思路点拨**：这是主线边界声明的直考。答题要点是"池化有损、局部被稀释"。加分点：提到层级池化或 GIN（更强的图表示）。常见错误是答"一样容易"。

## 二、计算实践

### 题 1（手算 + NumPy：sum 池化的图表示）

一张图有 3 个节点，GCN 后节点表示 $h_1=[1,2]$、$h_2=[3,4]$、$h_3=[5,6]$。

(a) sum 池化的图表示？
(b) mean 池化的图表示？
(c) max 池化的图表示？

**解答**：(a) $[1+3+5, 2+4+6] = [9, 12]$。(b) $[9/3, 12/3] = [3, 4]$。(c) 逐维最大：第一维 $\max(1,3,5)=5$，第二维 $\max(2,4,6)=6$，$[5,6]$。

**NumPy 验证**：
```python
import numpy as np
H = np.array([[1,2],[3,4],[5,6]], dtype=float)
print("sum :", H.sum(0))      # [9. 12.]
print("mean:", H.mean(0))     # [3. 4.]
print("max :", H.max(0))      # [5. 6.]
```
```
sum : [9. 12.]
mean: [3. 4.]
max : [5. 6.]
```

**思路点拨**：三种池化给出三个不同的"图的签名"——sum 数值最大（含节点数信息）、mean 是平均、max 只留最强。手算时别把 `axis` 搞反：沿**节点维**（axis=0）求和。这道题的训练价值：同一堆节点表示，池化选择不同，后续分类结果完全不同——**池化是建模决策，不是实现细节**。

### 题 2（手算：图分类全流程）

网络：两个账户，1 连 2；特征 $h_1=[1,0]$（普通）、$h_2=[0,1]$（可疑）。$W=I$（恒等），sum 池化，分类头 $W_c=[-1,1]$，sigmoid。

(a) 图表示 $g$？
(b) logit 与欺诈概率？
(c) 这个网络"该判"欺诈吗？（按模型的逻辑）

**解答**：(a) 线性变换后仍 $[1,0]$、$[0,1]$，sum 池化 $g=[1,1]$。(b) logit $= 1\times(-1)+1\times1 = 0$，$\sigma(0)=0.5$——"完全不确定"。(c) 模型给 50/50：一个普通账户 + 一个可疑账户，sum 后两个维度相等，"可疑度"和"普通度"打平——模型说"无法判断"。这提醒：**sum 池化对"混合成分"的图给出中性判断**，若任务要求"只要含可疑账户就判欺诈"，需要 max 池化或更细的结构特征。

**思路点拨**：(c) 的教训关键：池化会"平均掉"关键信号。一个可疑账户藏在一堆普通账户里，sum/mean 都会稀释它，只有 max（或专门的池化）能抓住"最强信号"。这正是图分类"局部结构易丢失"的微观示例。

## 三、DL 延伸

### 题 1（场景设计）：分子毒性预测——选池化

一个任务：用图分类判断分子是否有毒。分子图里，毒性往往由**一小撮特定官能团**（几个原子的特定排列）决定。请论证：sum 池化在此任务有什么风险？什么做法更合理？

**解答**：sum 池化把整张图的表示求和——**毒性官能团（少数原子）的信号会被大量普通原子稀释**：一个 50 原子的大分子，其毒性信号在 sum 后只占 1/50 的分量。更合理的做法：(1) **max 池化**——抓住"最强的官能团信号"；(2) **层级/注意力池化**——先识别"哪些原子/区域是活性位点"再聚焦池化；(3) 结合子结构特征（如 GIN、WL 核）让"官能团"这类局部模式被显式表示。关键是：**毒性是"局部决定性"的，池化必须能保住局部信号，而不是均匀摊平。**

**思路点拨**：答题锚点是"毒性=局部信号，池化不能摊平它"。能把 sum 的风险（稀释）与对策（max/注意力/子结构）都说清是满分。常见错误是"一律 sum"。

### 题 2（概念连线）：WL 算法为什么是 GNN 图分类的"天花板"？

§7.5.2 历史里说"GNN 的表达能力上限是 WL 算法"。请解释：为什么 WL 颜色细化（节点聚合邻居颜色）与 GNN 消息传递是同构的？这对图分类意味着什么？

**解答**：WL 的每一轮：节点的**新颜色 = 旧颜色 + 邻居旧颜色的多重集**；GNN 的每一层：节点的**新表示 = σ(聚合(自己 + 邻居表示))**——结构完全同构（聚合邻居 + 更新自己）。因此一个 GNN 能区分的图，不超过 WL 算法能区分的图；**如果两张图 WL 都分不出（颜色分布收敛相同），任何消息传递型 GNN 也分不出**。对图分类意味着：**池化 + 聚合的表达能力有明确上限**——想突破（区分同分异构体这类精细差异），需要 WL 更强的设计（如 GIN 用 sum 聚合，被证明等价于 WL 且是消息传递型最强的）。

**思路点拨**：答题锚点是"聚合邻居+更新自己"的同构性。能说出"表达能力上限=WL"和"GIN 是消息传递型的天花板"就非常到位。常见错误是把 WL 当"另一种 GNN"而非"理论基准"。这道题把历史、§7.3 消息传递、图分类串成一条线。
