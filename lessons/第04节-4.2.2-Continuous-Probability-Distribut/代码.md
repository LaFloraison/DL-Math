# 代码：连续概率分布——把密度写进函数，让积分替我们验算

主线里我们看见了三个连续分布的形状：均匀分布是一条平线，正态分布是一座钟，指数分布是一条贴着纵轴滑下去的坡。但"密度函数长这样"是一回事，"它到底合法不合法"是另一回事。

连续分布合法性的唯一裁决者是**归一化**：整条曲线与 $x$ 轴围出的面积必须恰好是 1。离散分布靠把概率逐点相加，连续分布只能靠积分。而积分——我们不必手算。梯形法则（trapezoidal rule）可以把曲线切成千上万个小梯形，把它们的面积加总，得到一个近似值。如果这个近似值非常接近 1，就说明这三个函数确实够格被称为概率密度。

下面的脚本用手写的方式把三个 PDF 敲出来（只依赖 `np.sqrt`、`np.pi`、`np.exp` 三个基本操作，不调用任何现成的分布类），然后在特定点上量出它们的密度，最后用 `np.trapz` 做梯形积分验证归一化。

## 层一：完整脚本

```python
import numpy as np                        # NumPy：sqrt / pi / exp / trapz 全部来自这里

def uniform_pdf(x, a, b):                 # ① 连续均匀分布：区间 [a,b] 内取常数 1/(b-a)
    """密度：区间内处处相等，区间外为 0。"""
    return np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)

def normal_pdf(x, mu, sigma):             # ② 正态分布：均值 mu、标准差 sigma 的钟形曲线
    """密度：以 mu 为中心、sigma 决定胖瘦的钟形。"""
    return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))

def exponential_pdf(x, lam):              # ③ 指数分布：率参数 lam 的衰减，只活在 x>=0
    """密度：从 x=0 处 lam 起，按 e^{-lam*x} 衰减。"""
    return lam * np.exp(-lam * x) * (x >= 0)

# ---- ① 在特定点上量密度（教材的数字：均匀 [0,1]、正态 170/10、指数 λ=0.5）----
print(f"uniform(0.5)    = {uniform_pdf(0.5, 0.0, 1.0):.6f}   # 区间内密度恒为 1/(1-0)=1")
print(f"uniform(1.5)    = {uniform_pdf(1.5, 0.0, 1.0):.6f}   # 区间外密度为 0")
print(f"normal(170)     = {normal_pdf(170.0, 170.0, 10.0):.6f}   # 峰顶密度 = 1/(σ√(2π))")
print(f"normal(180)     = {normal_pdf(180.0, 170.0, 10.0):.6f}   # 距均值 1σ，密度降了约 40%")
print(f"exponential(0)  = {exponential_pdf(0.0, 0.5):.6f}   # x=0 处密度 = λ")
print(f"exponential(2)  = {exponential_pdf(2.0, 0.5):.6f}   # 2 分钟后，密度只剩 e^{-1} 倍")

# ---- ② 梯形法则验证归一化：∫ f(x) dx ≈ 1 ----
x = np.linspace(0.0, 1.0, 10001)          # uniform 的定义域网格（b-a 全长）
I_u = np.trapz(uniform_pdf(x, 0.0, 1.0), x)
x = np.linspace(120.0, 220.0, 10001)      # normal 取 μ±5σ，把钟的裙边都包进来
I_n = np.trapz(normal_pdf(x, 170.0, 10.0), x)
x = np.linspace(0.0, 20.0, 10001)         # exponential 只取 [0, 20]，尾巴留给了无限远处
I_e = np.trapz(exponential_pdf(x, 0.5), x)
print(f"∫ uniform     ≈ {I_u:.6f}   # 理论值 1，完全吻合")
print(f"∫ normal      ≈ {I_n:.6f}   # 理论值 1，μ±5σ 已覆盖 99.99994%")
print(f"∫ exponential ≈ {I_e:.6f}   # 理论值 1，有限区间丢了一点尾巴")
```

运行输出（Python 3.11 + NumPy）：

```text

uniform(1.5)    = 0.000000   # 区间外密度为 0

normal(180)     = 0.024197   # 距均值 1σ，密度降了约 40%
```

### 步骤 1：导入 NumPy —— sqrt / pi / exp / trapz 全部来自这里

```python
import numpy as np
```

这一节课我们不会用到任何深度学习的库。需要的三样基本数学工具——$\sqrt{\cdot}$、$\pi$、$e^{(\cdot)}$——以及最后的数值积分，全部由 NumPy 提供。

#### `import numpy as np` —— 引入数值计算的工具箱

**操作**：把 NumPy 库加载进内存，并绑定简写 `np`（此后 `np.sqrt` 即 `numpy.sqrt`）。

**可调参数**：无（`import numpy as np` 是最常规写法；`import numpy` 也能用，只是每次都要敲全名 `numpy.sqrt`，累）。
**对应数学**：这一行不直接对应任何公式，它是为公式服务的——$\sqrt{2\pi}$ 里的 $\pi$ 从 `np.pi` 来，$e^{x}$ 从 `np.exp` 来。

### 步骤 2：定义 `uniform_pdf` —— 区间内取常数，区间外归零

```python
def uniform_pdf(x, a, b):
    """密度：区间内处处相等，区间外为 0。"""
    return np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)
```

#### uniform_pdf —— 连续均匀分布的密度：区间内取常数，区间外归零

`return np.where((x >= a) & (x <= b), 1.0 / (b - a), 0.0)`

**做什么**：对传入的每一个点，判断它是否落在 $[a, b]$ 内——落在区间内的点输出常数密度 $1/(b-a)$，落在区间外的点输出 $0$。
**操作**：`(x >= a) & (x <= b)` 逐元素比较，产生一个与 `x` 同形状的布尔数组（区间内为 `True`，区间外为 `False`）；`np.where(条件, 值1, 值2)` 是向量化的三目运算——条件为真的位置取 `1.0 / (b - a)`，为假的位置取 `0.0`。布尔数组 `True/False` 在参与乘法、条件选择时被当作 `1/0` 使用。
**输入**：
- `x`：标量或任意形状的数组，待求密度的点。可以一次传入整个区间网格（如 10001 个点），NumPy 会把公式应用到每个元素上——这就是**向量化 (vectorization)**，是后面 `np.trapz` 一次算完的前提。
- `a`：区间下界，标量。教材里的变量就是 $a$。
- `b`：区间上界，标量。对应教材的 $b$。
**输出**：与 `x` 同形状的数组，每个位置是该点的概率密度值。区间内恒为 $1/(b-a)$，区间外恒为 0。
**可调参数**：
- 参数 `a`、`b`：区间的两端，也是这个分布仅有的两个自由度。区间越窄，$1/(b-a)$ 就越大——因为总面积必须恒为 1，把宽度压短了，高度就得抬高。想模拟"从 0 到 1 随机取数"，取 $a=0, b=1$（密度 $=1$）；想模拟"从 5 到 15 随机取数"，取 $a=5, b=15$（密度 $=0.1$）。也可以试试 $a=0, b=2$：密度变成 0.5，而 $\int_0^2 0.5\,dx = 1$ 依然成立——无论怎么改，归一化都自动满足。
- 能不能加第四个参数？`np.where` 本身还支持 `np.where(条件, x, y)` 之外的 `np.where(条件)` 简写（只返回满足条件的下标），但那是别的用途；对密度函数来说，`x, a, b` 三个参数已经完整了。
**对应数学**：主线里的 $f(x) = \dfrac{1}{b-a},\quad a \le x \le b$。`np.where` 的第三个分支（区间外取 0）正是公式里"for $a \le x \le b$"这个限定在代码里的化身——如果没有这一支，$x=1.5$ 就会错误地得到 $1/(b-a)$ 而不是 0。

### 步骤 3：定义 `normal_pdf` —— 钟形曲线的两个因子

```python
def normal_pdf(x, mu, sigma):
    """密度：以 mu 为中心、sigma 决定胖瘦的钟形。"""
    return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))
```

#### normal_pdf —— 正态分布的密度：归一化因子 × 钟形内核

`return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))`

**做什么**：对每个点算出该点的正态密度——把"离均值多远"翻译成"密度多高"。公式分成相乘的两块：前面的 $1/(\sigma\sqrt{2\pi})$ 是**归一化因子 (normalization factor)**，只管把总面积压到 1；后面的 $\exp\!\big(-\frac{(x-\mu)^2}{2\sigma^2}\big)$ 是**钟形内核**，决定曲线的形状。
**操作**：`(x - mu)**2` 逐元素算每个点到均值的**平方距离**；除以 `2.0 * sigma**2` 后取 `np.exp`（自然指数 $e^{(\cdot)}$），得到内核；再乘上归一化因子。`x` 可以是数组，四则运算全部逐元素完成。
**输入**：
- `x`：标量或任意形状数组，待求密度的点。
- `mu`（均值，mean）：钟形的对称中心，也是密度的最高点所在。教材例子里是身高 $\mu = 170$ cm。
- `sigma`（标准差，standard deviation）：钟形的胖瘦。教材例子 $\sigma = 10$ cm。
**输出**：与 `x` 同形状的数组，每个位置是该点的概率密度，恒为正且面积和为 1。
**可调参数**：
- `mu`：平移整座钟。$\mu=170$ 时峰值在 170；改成 $\mu=0$ 就是标准位置；它在 $\frac{(x-\mu)^2}{2\sigma^2}$ 里只影响"哪里是中心"，不影响形状。可以把 `mu` 想成旋钮上刻着"平均值"的那个刻度。
- `sigma`：决定胖瘦和峰高。$\sigma$ 越大钟越矮胖，$\sigma$ 越小钟越高瘦——因为峰高 $1/(\sigma\sqrt{2\pi})$ 与 $\sigma$ 成反比，而总面积必须保持 1，摊得越开就得压得越矮。
- 还能不能加参数？`x, mu, sigma` 三个已完备。有人把 $\sigma^2$（方差）单独提出来当参数，写成 `normal_pdf(x, mu, var)`——如果你这么写，记得函数内部要 `np.sqrt(var)` 转回 $\sigma$。教材直接给 $\mu, \sigma$，我们就照教材来。

**为什么要 `np.sqrt(2.0 * np.pi)`？——这里是最值得停下来看清的地方。** 内核 $\exp\!\big(-\frac{(x-\mu)^2}{2\sigma^2}\big)$ 是一个不会自己归一的函数：它在整个实数轴上积分出来不是 1，而是 $\sigma\sqrt{2\pi}$（这是高斯积分 $\int_{-\infty}^{\infty} e^{-t^2}dt=\sqrt{\pi}$ 的伸缩版本）。要让总面积变成 1，唯一的办法就是**除以它自己积出来的面积**——于是归一化因子 $1/(\sigma\sqrt{2\pi})$ 就这样被迫诞生。它不是为了好看，它是一场除法。`np.sqrt(2.0 * np.pi)` 里的 $\pi$ 不是圆的周长公式闯进来的，而是高斯积分 $\sqrt{\pi}$ 的余音。验证就在脚本输出里：当 $\sigma=10$ 时峰顶密度 $1/(10\sqrt{2\pi}) \approx 0.039894$，乘上整个曲线扫过的宽度，面积恰好回到 1。

**`np.exp(-(x - mu)**2 / (2.0 * sigma**2))` 在说什么？** 指数里是**标准化的平方距离** $(x-\mu)^2/(2\sigma^2)$。当 $x=\mu$ 时指数为 0，$e^0=1$，密度取到峰值；当 $x=\mu\pm\sigma$ 时指数为 $-1/2$，密度降到峰值的 $e^{-1/2}\approx 0.6065$——这就是输出里 180（距均值 1σ）处 0.024197 ≈ 0.039894 × 0.6065 的原因，"降了约 40%"。平方把"偏离"放大成"偏离²"，所以离得越远密度掉得越狠——这正是教材那句"距离均值越远，密度越低"的精确版本。
**对应数学**：$f(x) = \dfrac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac{(x-\mu)^2}{2\sigma^2}}$，正是主线 §4.2.2.2 的公式逐符号翻译。

### 步骤 4：定义 `exponential_pdf` —— 只活在半条数轴上的衰减

```python
def exponential_pdf(x, lam):
    """密度：从 x=0 处 lam 起，按 e^{-lam*x} 衰减。"""
    return lam * np.exp(-lam * x) * (x >= 0)
```

#### exponential_pdf —— 指数分布的密度：率参数驱动的衰减，x≥0 之外归零

`return lam * np.exp(-lam * x) * (x >= 0)`

**做什么**：对每个点算出指数密度——从 $x=0$ 处的高度 $\lambda$ 出发，按 $e^{-\lambda x}$ 指数式下坠。`(x >= 0)` 把负数轴整个按下归零。
**操作**：`-lam * x` 逐元素取负率乘时间；`np.exp(...)` 取 $e^{(\cdot)}$；再乘 `lam` 与布尔掩码 `(x >= 0)`。布尔数组乘数值数组时 `True→1, False→0`，于是 $x<0$ 的点密度归零，$x\ge 0$ 的点正常计算。
**输入**：
- `x`：标量或任意形状数组，待求密度的"等待时间"。
- `lam`（率参数，rate parameter，写做希腊字母 $\lambda$）：事件发生的平均速率，即**单位时间事件数的期望**。教材例子里平均 2 分钟来一通电话，速率就是 $\lambda = 1/2 = 0.5$ 通/分钟。
**输出**：与 `x` 同形状的数组，每个位置是该点的概率密度。$x<0$ 处全为 0。
**可调参数**：
- `lam`：唯一的参数，同时控制起点高度与衰减快慢。$x=0$ 处密度恰好等于 $\lambda$（所以输出里 `exponential(0)=0.5`），而衰减速率也由 $\lambda$ 决定——$\lambda$ 越大，$e^{-\lambda x}$ 掉得越快。$\lambda$ 的倒数 $1/\lambda$ 是平均等待时间：$\lambda=0.5$ 时平均等 2 分钟，$\lambda=2$ 时平均等 0.5 分钟。
- 能不能加参数？`x, lam` 已完备。有的库写成 `exponential_pdf(x, scale)`，其中 `scale = 1/lam`（平均等待时间）——两种写法说的是同一个分布，只是参数化方向相反。教材用 $\lambda$，我们跟着用 $\lambda$。
**对应数学**：$f(x) = \lambda e^{-\lambda x},\quad x \ge 0$，正是主线 §4.2.2.3 的公式。`(x >= 0)` 是公式里"$x\ge0$"条件的代码化身。值得留意：指数分布只有 $x\ge0$ 这一侧有意义——等待时间不可能为负，这就是为什么教材特意写"for $x \ge 0$"。

### 步骤 5：打印特定点的密度值 —— 用具体数字检验三个公式

```python
print(f"uniform(0.5)    = {uniform_pdf(0.5, 0.0, 1.0):.6f}   # 区间内密度恒为 1/(1-0)=1")
print(f"normal(170)     = {normal_pdf(170.0, 170.0, 10.0):.6f}   # 峰顶密度 = 1/(σ√(2π))")
print(f"exponential(0)  = {exponential_pdf(0.0, 0.5):.6f}   # x=0 处密度 = λ")
```

**做什么**：在几个"有故事"的点上，把三个公式算成具体的数。`.6f` 把结果格式化为保留 6 位小数的字符串。
**操作**：f-string（`f"..."`）把 `{}` 里的 Python 表达式求值并格式化后嵌入字符串；`uniform_pdf(0.5, 0.0, 1.0)` 就是调用函数、把 `x=0.5, a=0, b=1` 代入。
**输入**：三个函数调用，各自传入该分布的一个代表性横坐标。
**输出**：六行文本，如 `uniform(0.5)    = 1.000000`。
**可调参数**：这里的参数是"选哪些点来量"。可以自由换成任何 x——比如 `normal_pdf(160.0, 170.0, 10.0)`（离均值 1σ 的另一侧，应得到与 180 相同的 0.024197，因为正态对称），或 `exponential_pdf(1.0, 0.5)`（恰好等 1 分钟时的密度）。
**对应数学**：每个打印行都是一次具体的函数代入。离散分布教材用 $P(X=k)$ 一个点一个点地写概率；连续分布没有"点的概率"，只有"点的密度"——这些打印出来的数不是概率，是密度，是 $\int f$ 的"被积函数在那些点上的高度"。

### 步骤 6：`np.trapz` 梯形法则验证归一化 —— ∫f(x)dx ≈ 1

```python
x = np.linspace(120.0, 220.0, 10001)
I_n = np.trapz(normal_pdf(x, 170.0, 10.0), x)
```

#### `np.linspace(start, stop, N)` —— 生成等距网格

**操作**：在 $[start, stop]$ 上生成 $N$ 个等间距的点，首尾都包含。
**输入**：`start`（起点）、`stop`（终点）、`N`（点的个数）。
**输出**：长度 $N$ 的一维数组。`np.linspace(120.0, 220.0, 10001)` 得到 10001 个点，间距 $dx = (220-120)/(10001-1) = 0.01$。
**可调参数**：`N` 越大，网格越密，梯形近似越准；教材均匀分布区间 [0,1]、正态取 μ±5σ=[120,220]、指数取 [0,20]，每个区间都铺了 10001 个点。还可以加第四个参数 `endpoint=False` 去掉最后一个点，以及 `retstep=True` 同时返回间距——本脚本不需要。

#### `np.trapz(y, x)` —— 用梯形法则求数值积分

**操作**：把曲线下方切成 $N-1$ 个细长梯形，每个梯形用相邻两点 $x_i, x_{i+1}$ 上的函数值 $y_i, y_{i+1}$ 作为上下底，面积 $\frac{y_i+y_{i+1}}{2}\cdot dx$，全部相加。这就是梯形法则 (trapezoidal rule)：线性地"想象"每小段之间函数按直线过渡，于是积分退化成大量梯形面积之和。
**输入**：
- `y`：函数值数组，形状 `(N,)`——这里就是 `uniform_pdf(x, 0.0, 1.0)` 等，每个网格点上的密度。
- `x`：网格点数组，形状 `(N,)`——与 `y` 一一对应的横坐标。
**输出**：一个标量，$\int f(x)\,dx$ 的近似值。三组输出分别是 `1.000000`、`0.999999`、`0.999955`。
**可调参数**：
- 第二个参数也可以传标量间距 `dx`（如 `np.trapz(y, 0.01)`），效果等价；传数组的好处是网格不必等距。
- `x` 的网格密度是主旋钮：把 `10001` 改成 `101`，均匀分布仍准（它是平的，少几个梯形也分毫不差），但正态和指数会明显偏差——因为钟顶和陡坡段缺了采样点。试试就知道，梯形法则的精度取决于"函数在多大程度上像直线"与"网格有多密"的赛跑。
- 注意：新版 NumPy（≥2.0）把 `np.trapz` 更名为 `np.trapezoid`，`np.trapz` 会打出一条 DeprecationWarning，但结果完全一致。为对齐教材与通行写法，这里保留 `np.trapz`。
**对应数学**：这是对主线里"总面积等于 1"这一合法性条件的直接验算——$\int_a^b f(x)\,dx = 1$。三行输出就是三个分布各自面积的值。

## 改个数字试试：把参数推向极端

参数不是固定的。下面两个实验，把教材里的参数往极端推，看看曲线怎么响应——这是理解"参数控制形状"最直接的方式。

### 实验 1：σ 从 10 改到 3 —— 正态峰变尖

```python
x = np.linspace(155.0, 185.0, 10001)               # μ±5σ，对新 σ 重新取网格
print(f"sigma=3 峰顶密度 = {normal_pdf(170.0, 170.0, 3.0):.6f}")   # 原 σ=10 时是 0.039894
print(f"sigma=3 归一化   = {np.trapz(normal_pdf(x, 170.0, 3.0), x):.6f}")
```

输出：

```text
sigma=3 峰顶密度 = 0.132981   # 原 σ=10 时是 0.039894
sigma=3 归一化   = 0.999999
```

σ 从 10 缩到 3，峰顶密度 0.039894 → 0.132981，**涨了约 3.3 倍**。为什么？峰高 $1/(\sigma\sqrt{2\pi})$ 与 σ 成反比——σ 缩到 3/10，峰高就涨到 10/3 倍。面积守恒逼着曲线把变矮的宽度"还"回高度：钟变尖、变瘦、变高。而 `归一化 = 0.999999` 依然成立——参数怎么改，面积永远守约 1。你在模型里看到"方差小的预测，置信区间的钟又尖又窄"时，看到的就是这座被捏紧的钟。

### 实验 2：λ 从 0.5 改到 2 —— 指数衰减变快

```python
print(f"lam=2 在 x=0 处 = {exponential_pdf(0.0, 2.0):.6f}")   # 原 λ=0.5 时是 0.5
print(f"lam=2 在 x=2 处 = {exponential_pdf(2.0, 2.0):.6f}")   # 原 λ=0.5 时是 0.183940
x = np.linspace(0.0, 20.0, 10001)
print(f"lam=2 归一化    = {np.trapz(exponential_pdf(x, 2.0), x):.6f}")
```

输出：

```text
lam=2 在 x=0 处 = 2.000000   # 原 λ=0.5 时是 0.5
lam=2 在 x=2 处 = 0.036631   # 原 λ=0.5 时是 0.183940
lam=2 归一化    = 1.000001
```

λ 从 0.5 改到 2（即平均等待时间从 2 分钟缩到 0.5 分钟）：起点高度 $\lambda$ 从 0.5 跳到 2（4 倍），而 $x=2$ 处的密度从 0.183940 骤降到 0.036631（只剩约 1/5）——事件来得越密，曲线趴得越低、收得越快。归一化仍守约 1。这就是教材里那个呼叫中心：λ 越大，下一通电话来得越快，等不到 2 分钟的概率也越高。

## 边界声明：这套代码能做什么，不能做什么

1. **打印出来的数不是概率**。$f(180) = 0.024197$ 的意思是"在 180 cm 附近单位长度内聚着约 2.4% 的密度"，而不是"恰好 180 cm 的概率是 2.4%"（连续分布里单点概率恒为 0）。要算"170 到 180 之间的概率"，必须对这一段积分 $\int_{170}^{180} f\,dx$——梯形法则正是干这个的，但它算的是积分，不是点值。
2. **梯形法则对"无限尾巴"只能近似**。指数分布的积分域是 $[0,\infty)$，而我们只铺到 20——所以输出 0.999955 略小于 1，差的那 0.000045 是 $[20,\infty)$ 漏掉的尾巴。正态理论上积分域是 $(-\infty,\infty)$，我们用 μ±5σ=[120,220] 截断，已经盖住 99.99994%，仍有约 $6\times10^{-7}$ 的微小误差。想要更精，就把网格区间加宽、点数加密——但永远拿不到"无穷"本身。
3. **这只是一个"验算工具"**。真实建模不会手写密度再数值积分——NumPy 有 `np.random.uniform`、`np.random.normal`、`np.random.exponential` 直接抽样，SciPy 有 `scipy.stats.*` 的完整分布对象。但那些封装背后，正是这三条公式在做同一件事。先把公式亲手写出来、让积分替你验算，再跳进封装——你才能看懂封装在替你做哪一步。
