# §4.2.2 连续概率分布 — 代码验证

> 三个连续分布的 PDF 全部手写。改 $\mu$、$\sigma$、$\lambda$，看曲线怎么变。积分归一化用梯形法则——不是黑盒，是你可以手算的方法。

## 完整代码

```python
import numpy as np

# ═══ 1. 连续均匀分布 Uniform(a, b) ═══
def uniform_pdf(x, a, b):
    """f(x) = 1/(b-a)  for a <= x <= b,  0 otherwise"""
    if x < a or x > b:
        return 0.0
    return 1.0 / (b - a)

# ═══ 2. 正态分布 N(mu, sigma^2) ═══
def normal_pdf(x, mu, sigma):
    """f(x) = 1/sqrt(2π)/σ * exp(-(x-μ)²/(2σ²))"""
    coeff = 1.0 / (np.sqrt(2 * np.pi) * sigma)
    exponent = -((x - mu) ** 2) / (2 * sigma ** 2)
    return coeff * np.exp(exponent)

# ═══ 3. 指数分布 Exp(lambda) ═══
def exponential_pdf(x, lam):
    """f(x) = λ * exp(-λx)  for x >= 0,  0 for x < 0"""
    if x < 0:
        return 0.0
    return lam * np.exp(-lam * x)

# ═══ 验证：计算特定点的密度 ═══
print("=== 连续均匀分布: Uniform(0, 1), x=0.5 ===")
print(f"f(0.5) = {uniform_pdf(0.5, 0, 1):.4f}  (期望 1.0)")
print(f"f(1.5) = {uniform_pdf(1.5, 0, 1):.4f}  (区间外，期望 0.0)")

print("\n=== 正态分布: N(170, 10^2), x=170, 180, 200 ===")
print(f"f(170) = {normal_pdf(170, 170, 10):.4f}  (峰顶，期望约 0.04)")
print(f"f(180) = {normal_pdf(180, 170, 10):.4f}  (μ+1σ)")
print(f"f(200) = {normal_pdf(200, 170, 10):.4f}  (μ+3σ，期望接近 0)")

print("\n=== 指数分布: Exp(λ=0.5), x=0, 1, 5 ===")
print(f"f(0)  = {exponential_pdf(0, 0.5):.4f}  (期望 λ=0.5)")
print(f"f(1)  = {exponential_pdf(1, 0.5):.4f}")
print(f"f(5)  = {exponential_pdf(5, 0.5):.4f}  (接近 0)")

# ═══ 验证归一化：梯形法则近似积分 ∫f(x)dx ≈ 1 ═══
def integrate_trapezoid(f, a, b, n=1000):
    """梯形法则：把曲线切成 n 个梯形，面积求和"""
    xs = np.linspace(a, b, n)
    dx = (b - a) / (n - 1)
    ys = np.array([f(x) for x in xs])
    return np.trapz(ys, xs)  # NumPy 内置梯形积分

# 均匀：∫_{0}^{1} 1 dx = 1
uniform_area = integrate_trapezoid(lambda x: uniform_pdf(x, 0, 1), 0, 1)
# 正态：∫_{-∞}^{∞} 用 μ±5σ 近似
normal_area = integrate_trapezoid(lambda x: normal_pdf(x, 170, 10), 120, 220, 2000)
# 指数：∫_{0}^{∞} 用 [0, 10/λ] 近似
exp_area = integrate_trapezoid(lambda x: exponential_pdf(x, 0.5), 0, 20, 2000)

print(f"\n=== PDF 归一化检查（应≈1） ===")
print(f"Uniform(0,1),  ∫f = {uniform_area:.6f}")
print(f"N(170,10^2), ∫f = {normal_area:.6f}")
print(f"Exp(0.5),    ∫f = {exp_area:.6f}")
```

运行输出：

```

f(1.5) = 0.0000  (区间外，期望 0.0)

=== 正态分布: N(170, 10^2), x=170, 180, 200 ===
f(170) = 0.0399  (峰顶，期望约 0.04)
f(180) = 0.0242  (μ+1σ)
f(200) = 0.0004  (μ+3σ，期望接近 0)

=== 指数分布: Exp(λ=0.5), x=0, 1, 5 ===

f(1)  = 0.3033
f(5)  = 0.0410  (接近 0)
```

## 分步讲解


### 步骤 1：连续均匀分布 PDF —— `uniform_pdf(x, a, b)`

```python
def uniform_pdf(x, a, b):
    if x < a or x > b:
        return 0.0
    return 1.0 / (b - a)
```

**做什么**：计算 $x$ 点在区间 $[a, b]$ 上的均匀分布概率密度。


**区间判断 —— `if x < a or x > b`**

```python
if x < a or x > b:
    return 0.0
```

**操作**：检查 $x$ 是否在 $[a, b]$ 之外。如果是，密度为 0——在这个区间之外没有概率质量。

**输入**：`x`（要查询的点），`a`（下界），`b`（上界）。

**输出**：0.0 或继续往下算。


**`1.0 / (b - a)` —— 矩形高度**

```python
return 1.0 / (b - a)
```

**操作**：区间宽度 $b-a$，总概率 1 均匀分布在整个区间上 → 密度 = $1/(b-a)$。

**可调参数**：
- **`a`（下界）**：区间左端点。$a$ 越大 → 区间右移
- **`b`（上界）**：$b > a$，区间右端点。$b-a$ 越大 → 区间越宽 → 密度越低（概率 1 要分摊到更宽的范围）。极端情况：$b-a \to 0$ 时密度 $\to \infty$（但在实际中 $b-a$ 不可能为零）
- **`x`（查询点）**：标量，在 $[a, b]$ 内任意值返回相同密度——这就是"均匀"的代码体现

**对应数学**：主线第二节的 $f(x) = 1/(b-a), a \le x \le b$。矩形面积 = 宽 × 高 = $(b-a) \cdot 1/(b-a) = 1$。

### 步骤 2：正态分布 PDF —— `normal_pdf(x, mu, sigma)`

```python
def normal_pdf(x, mu, sigma):
    coeff = 1.0 / (np.sqrt(2 * np.pi) * sigma)
    exponent = -((x - mu) ** 2) / (2 * sigma ** 2)
    return coeff * np.exp(exponent)
```

**做什么**：计算 $x$ 点在正态分布 $\mathcal{N}(\mu, \sigma^2)$ 上的概率密度。


**`1.0 / (np.sqrt(2 * np.pi) * sigma)` —— 归一化系数**

```python
coeff = 1.0 / (np.sqrt(2 * np.pi) * sigma)
```

**操作**：计算 $\frac{1}{\sqrt{2\pi}\,\sigma}$。`np.sqrt(2 * np.pi)` = $\sqrt{2\pi} \approx 2.507$。乘以 $\sigma$ 再取倒数。

**为什么有 $\sqrt{2\pi}$？** 因为 $\int_{-\infty}^{\infty} e^{-x^2/2}\,dx = \sqrt{2\pi}$——这个积分是高斯积分，结果里有 $\sqrt{2\pi}$。没有这个系数，PDF 的面积不是 1。

**输入**：`sigma`（标准差），正数。

**输出**：标量。$\sigma=10$ → 系数约 $1/(2.507 \times 10) \approx 0.04$——这就是峰顶密度。$\sigma$ 越大 → 分布越宽 → 峰越低（总面积为 1 分摊到更宽的范围）。


**`-((x - mu) ** 2) / (2 * sigma ** 2)` —— 指数部分**

```python
exponent = -((x - mu) ** 2) / (2 * sigma ** 2)
```

**操作**：计算 $-\frac{(x-\mu)^2}{2\sigma^2}$。

分解：
1. `(x - mu)`：$x$ 离中心的**距离**（有正负）
2. `** 2`：距离的平方——正负对称，只关心"多远"不关心"往哪边偏"
3. `/(2 * sigma ** 2)`：除以 $2\sigma^2$ 缩放——$\sigma$ 越大 → 分母越大 → 指数衰减越慢 → 分布越"胖"
4. 前面的 `-`：把平方距离映射为负指数——越远指数越小，密度越低

**可调参数**：
- **`mu`（均值 $\mu$）**：分布的中心。$\mu=170$ → 峰在 170 处。$\mu$ 可以是任意实数。改变 $\mu$ 相当于把整条曲线水平平移
- **`sigma`（标准差 $\sigma$）**：$\sigma > 0$。控制"胖瘦"——$\sigma$ 翻倍 → 峰高减半（系数里的 $1/\sigma$），衰减变慢（指数里的 $1/\sigma^2$）→ 分布扩散到更宽的范围
- **`x`（查询点）**：可以是任意实数。$x = \mu$ 时指数为 0 → $f(\mu) = 1/(\sqrt{2\pi}\sigma)$ 是最大值。$x$ 离 $\mu$ 越远 → 指数部分越接近 0 → 密度越低


**`np.exp(exponent)` —— 把指数拉回正数**

```python
return coeff * np.exp(exponent)
```

**操作**：`np.exp(y)` = $e^y$。指数部分 $-\frac{(x-\mu)^2}{2\sigma^2}$ 是负数或零，$e^{\text{负数}}$ 在 $(0, 1]$ 之间。

**对应数学**：主线第三节的正态分布 PDF。$e^{-(x-\mu)^2/(2\sigma^2)}$ 是正态的"灵魂形状"——系数 $1/(\sqrt{2\pi}\sigma)$ 是"让它积分等于 1"的修正因子。

### 步骤 3：指数分布 PDF —— `exponential_pdf(x, lam)`

```python
def exponential_pdf(x, lam):
    if x < 0:
        return 0.0
    return lam * np.exp(-lam * x)
```

**做什么**：计算等待时间 $x$ 的指数分布密度。


**`if x < 0` —— 等待时间不能为负**

```python
if x < 0:
    return 0.0
```

**操作**：指数分布只定义在 $x \ge 0$ 上——你不能等负分钟。$x < 0$ 时密度为 0。


**`lam * np.exp(-lam * x)` —— 指数衰减**

```python
return lam * np.exp(-lam * x)
```

**操作**：$\lambda e^{-\lambda x}$。`np.exp(-lam * x)` = $e^{-\lambda x}$——纯指数衰减。乘以 $\lambda$ 是归一化——$\int_0^\infty \lambda e^{-\lambda x}\,dx = 1$。

**可调参数**：
- **`lam`（速率 $\lambda$）**：$\lambda > 0$。$\lambda$ 大 → 事件频繁 → 等待时间短 → $e^{-\lambda x}$ 衰减极快 → 密度集中在 0 附近。$\lambda$ 小 → 事件稀少 → 等待时间长 → 衰减慢 → 长尾。均值 $1/\lambda$——$\lambda=0.5$ 时平均等 2 分钟
- **`x`（等待时间）**：$x \ge 0$。$x=0$ 时密度为 $\lambda$（最大值）。$x$ 越大 → $e^{-\lambda x}$ 越小 → 密度越低，但永远不会降到 0——理论上你可以等无限久（尽管概率趋近于 0）

**对应数学**：主线第四节的 $f(x) = \lambda e^{-\lambda x}$。从泊松分布推导——"$x$ 分钟内 0 次事件"的概率是 $e^{-\lambda x}$，求导得到密度。

### 步骤 4：梯形法则积分 —— `integrate_trapezoid`

```python
def integrate_trapezoid(f, a, b, n=1000):
    xs = np.linspace(a, b, n)
    dx = (b - a) / (n - 1)
    ys = np.array([f(x) for x in xs])
    return np.trapz(ys, xs)
```

**做什么**：用数值方法近似 $\int_a^b f(x)\,dx$。不是黑盒——是你可以手算的梯形面积求和。


**`np.linspace(a, b, n)` —— 切分区间**

```python
xs = np.linspace(a, b, n)
```

**操作**：从 $a$ 到 $b$ 均匀切 $n$ 个点。$n=1000$ 表示 1000 个采样点。$n$ 越大 → 近似越精确，但计算越慢。

**可调参数**：
- **`a, b`**：积分上下限。正态分布理论上从 $-\infty$ 到 $\infty$，但实践中 $\mu \pm 5\sigma$ 覆盖了 99.9999% 的概率质量，截断误差可忽略
- **`n`**：采样点数。$n=1000$ 对光滑函数足够。$n$ 太小 → 梯形近似粗糙；$n$ 太大 → 不必要


**`np.trapz(ys, xs)` —— 梯形面积求和**

```python
return np.trapz(ys, xs)
```

**操作**：把相邻两点之间的曲线段近似为梯形，计算每个小梯形的面积，全部加起来。这就是黎曼积分的数值实现——你在微积分课上学过的 $\int_a^b f(x)\,dx \approx \sum f(x_i) \Delta x$。

**为什么不直接用解析积分？** 因为这节课教的不是"scipy 帮你积分"——而是让你亲手看到：PDF 归一化不是魔法，就是面积求和。


### 改个数字试试

把正态的 $\sigma$ 从 10 改成 3：

```python
print("N(170, 3^2):")
print(f"  f(170) = {normal_pdf(170, 170, 3):.4f}  (峰更高了)")
print(f"  f(173) = {normal_pdf(173, 170, 3):.4f}  (μ+1σ，降到峰的 0.607)")
print(f"  f(180) = {normal_pdf(180, 170, 3):.4f}  (μ+3.3σ，几乎为 0)")
```

输出：

```
N(170, 3^2):
  f(170) = 0.1330  (峰更高了)
  f(173) = 0.0807  (μ+1σ，降到峰的 0.607)
  f(180) = 0.0005  (μ+3.3σ，几乎为 0)
```

$\sigma$ 从 10 缩到 3 → 峰高从 0.04 跳到 0.13（高了 3 倍多）。但总面积还是 1——峰高了，坡陡了，概率质量更集中在 $\mu$ 周围。$\mu+3\sigma$ 从 200（还很远）变成了 179（已经近得多，密度几乎为 0）。

再把指数的 $\lambda$ 从 0.5 改成 2：

```python
print("Exp(2.0):")
for x in [0, 0.5, 1, 3]:
    print(f"  f({x}) = {exponential_pdf(x, 2.0):.4f}")
```

输出：

```
Exp(2.0):
  f(0) = 2.0000  (起始密度翻了 4 倍)
  f(0.5) = 0.7358
  f(1) = 0.2707
  f(3) = 0.0050  (几乎衰减完了)
```

$\lambda=2$ 时平均等待 0.5 分钟。密度从 2 开始急剧衰减——到 3 分钟时几乎为零。和 $\lambda=0.5$（平均等 2 分钟，衰减慢）对比——$\lambda$ 直接控制了"事件间隔的典型尺度"。
