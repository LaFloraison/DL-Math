## 第一步：Toy Model —— 一面身高墙

想象一面白墙，像老式门框边量身高画的那道刻度。一千个人依次站上去，量完身高，在墙上的对应高度画一道小小的记号。你退后几步看那面墙——记号不再均匀散布，而是聚成一团：170 cm 附近密密麻麻，向两端越来越稀，160 cm 以下、180 cm 以上，只剩零星几道。

现在问一个"浅到可笑"的问题：**随机拉来一个人，他的身高恰好等于 170.000 cm 的概率是多少？**

你盯着墙上那一团记号。有人是 169.8，有人是 170.3，有人在 170.1 和 170.2 之间。**没有一个人恰好是 170.000**——就算真有，你换个更细的尺子去量，170.0000？170.00000？这个"恰好"永远追不上。你把墙分成无穷多个"点"，每个点宽为零——而零宽度的东西，什么也装不下。

于是你学会了一件事：**对连续的身高，不能问"等于多少"，只能问"落在哪一段"**。"他身高在 160 到 170 cm 之间"——这是一个有宽度的区间，区间有长度，记号才挤得进去。

怎么把"落在哪一段"算出来？你把墙分成等宽的条，像把一段城墙切成很多格。每格宽 5 cm，数一数里面有几道记号，把数字画成一根根竖起的柱子——这就是**直方图 (histogram)**。柱子越高，说明那一段被击中的可能性越大。

现在做一件关键的事：把格子切得更细。宽 5 cm 的格子换成 1 cm，每根柱子变矮了，但整面墙的形状**没有变**——中间依然隆起，两端依然低平。你再细，柱子矮下去，但那道"山形"还在。真正稳定的不是某根柱子有多高，而是**每厘米分布着多少人**——记号在墙上的浓密程度。这个"每单位长度的浓密程度"，就是**概率密度 (probability density)**。

你的直觉已经看到了答案：连续世界里，可能性不在"点"上，而在"段"上；计量它靠的不是"这一段有几个人"，而是"这一段平均每厘米有几个人"。但直觉到此为止——"每厘米几个人"这句话，要怎样精确成能放进公式里的数学？一厘米对应多少概率？整面墙的面积为什么加起来是 1？该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：离散的记账本，在连续世界里破账

上一节我们认识了**概率质量函数 (probability mass function, PMF)**。掷骰子，$p(k) = \mathrm{P}(X = k) = \frac{1}{6}$，$k \in \{1,2,3,4,5,6\}$。它的记账方式是：**把概率存在一个个孤立的点上**，所有点上的概率加起来等于 1：

$$\sum_{k} p(k) = 1$$

这套记账本在骰子上用得顺手极了。现在把它搬到身高墙上，试着回答"恰好等于 170.000 的概率"。

你打算给每个具体身高 $x$ 都配一个正的概率 $p(x)$。但身高在 $[150, 190]$ 里能取**无穷多个**值——169.999, 170.001, 170.0001……它们不是可数的一串，而是连成一条线的**不可数无穷**。如果你给每一个都分哪怕一丁点正概率，无穷多个正数加起来，必然爆掉 1。可是概率总和必须等于 1。**账对不上。**

你不是算错了，是**记账方式用错了**。在连续世界里，可能性不存放在"点"上——点没有宽度，装不下概率。它只存放在**区间**上。所以账本必须重写：

- 离散：概率**质量**存在点上，求和 $\sum$
- 连续：概率**浓度**铺在区间上，求积分 $\int$

$\sum$ 换成了 $\int$，这就是从 PMF 到 PDF 的那一步翻译。而 $f(x)$ 不再是"概率"，而是**概率密度函数 (probability density function, PDF)**——它给出的是"单位长度上的概率浓度"，真正的概率要从区间里积出来：

$$\mathrm{P}(a \le X \le b) = \int_a^b f(x)\,dx$$

把整条数轴积起来，一个人总要有个身高：

$$\int_{-\infty}^{\infty} f(x)\,dx = 1$$

现在你必须撞一面更硬的墙，否则后面会翻车。$f(x)$ **本身不是概率**——它是密度，密度可以大于 1。下一节马上会看到，均匀分布 $\mathrm{Uniform}(0, 0.5)$ 的密度是 $f(x) = 2$，比"最大概率 1"还大。密度是"每单位长度的概率"，只要它乘以区间的宽度之后积出来不超过 1，就完全合法。就像人口密度可以是每平方公里 2000 人，虽然"人"不是"概率"。**密度不是概率，积分才是。**

### 二、连续均匀分布：一张铺平的墙

回到墙面。如果那面墙上的记号**完全铺平**——从 $a$ 到 $b$ 每一厘米都一样浓密，没有任何隆起——这样的墙长什么样？

先看最简单的：在 $[0, 1]$ 里随机取一个数。密度处处相等，记为常数 $c$。墙的面积必须等于 1，而这块墙是个矩形：底是 $1 - 0 = 1$，高是 $c$，面积 $1 \cdot c = 1$，所以 $c = 1$。于是

$$f(x) = 1, \quad 0 \le x \le 1$$

"取到 $0.2$ 到 $0.8$ 之间的数"的概率，就是这块矩形的面积：底 $0.8 - 0.2 = 0.6$，高 $1$，得 $\mathrm{P}(0.2 \le X \le 0.8) = 0.6$。60%，跟你的直觉完全一致——区间占了整个墙的六成，可能性就是六成。

现在问："如果是 $[0, 2]$ 呢？" 底变成 2，面积要为 1，高只能是 $\frac{1}{2}$。"如果是任意 $[a, b]$ 呢？" 底是 $b - a$，高被唯一地钉死为 $\frac{1}{b-a}$。你看到了吗——把具体的 $0, 1$ 换成字母 $a, b$，那个常数就不是拍脑袋定的，而是**被"总面积必须等于 1"这条法律逼出来的**。

> **连续均匀分布** $X \sim \text{Uniform}(a, b)$
>
> 物理含义：在 $[a, b]$ 内任何一点的概率密度相等——没有哪个位置更受偏爱。
>
> $$f(x) = \frac{1}{b-a}, \quad a \le x \le b$$
>
> - 参数：$a$（下界）、$b$（上界），要求 $a < b$
> - 定义域：$x \in [a, b]$，之外 $f(x) = 0$
> - 均值：$\mathbb{E}[X] = \dfrac{a+b}{2}$
> - 方差：$\mathrm{Var}[X] = \dfrac{(b-a)^2}{12}$

直觉检验：均值取区间中点，天经地义——两边对称，重心必在中点。方差随区间长度平方增长，也很自然：区间越长，取值越散。

边界声明：注意"任何一点密度相等"**不等于**"任何一点的**概率**相等"——每个点的概率都是 0，它们永远相等。Uniform 相等的是**密度**，不是概率。这句话看似绕口令，却是整节课的钥匙：**连续分布的世界里，我们只谈论区间。**

### 三、正态分布：那面墙终于隆起来了

均匀分布的墙太平了。可真实的身高墙是隆起的——170 cm 附近记号浓密，向两边变稀。你需要的是一面**中间高、两边低、左右对称**的墙。这样的形状在自然界里出现得如此频繁——身高、测量误差、人群的血压——以至于它成了统计学里最重要的一条曲线：**正态分布 (normal / Gaussian distribution)**。

别急着背公式。先用具体数字感受它的"性格"。设身高的均值 $\mu = 170$ cm，标准差 $\sigma = 10$ cm。在均值那一厘米上，密度有多大？代入公式（马上给）：

$$f(170) = \frac{1}{10\sqrt{2\pi}}\,e^{0} = \frac{1}{10 \times 2.5066} \approx 0.04$$

170 cm 附近的密度大约是每厘米 0.04。往右挪 10 厘米，到 180 cm：

$$f(180) = \frac{1}{10\sqrt{2\pi}}\,e^{-\frac{100}{200}} = 0.0399 \times e^{-0.5} \approx 0.0399 \times 0.6065 \approx 0.024$$

密度从 0.04 掉到 0.024——离均值越远，墙越矮。曲线在 $\mu$ 处最高，向两边指数式地塌下去，永远碰不到零。这就是"钟形曲线 (bell-shaped curve)"：中间一座峰，两侧两条永不落地的大尾巴。

"这个身高分布落在 $\mu$ 两侧各一个 $\sigma$ 之内的概率是多少？"答案是约 68%：

$$\mathrm{P}(\mu - \sigma \le X \le \mu + \sigma) \approx 0.68$$

对身高而言就是：160 到 180 cm 之间大约住了 68% 的人。剩下的 32% 散落在两条尾巴里。

现在把具体的 $170, 10$ 换成字母 $\mu, \sigma$。为什么峰一定要在 $\mu$？因为曲线对称，均值就是对称轴。为什么胖瘦由 $\sigma$ 决定？因为 $\sigma$ 越大，曲线摊得越宽、压得越低——**总面积恒为 1，宽了就必须矮**。墙的形状，被这两个字母完全锁定：

> **正态分布** $X \sim \mathcal{N}(\mu, \sigma^2)$
>
> 物理含义：取值集中在 $\mu$ 附近，离 $\mu$ 越远密度越小，曲线对称、钟形。
>
> $$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \quad x \in \mathbb{R}$$
>
> - 参数：$\mu$（均值，曲线的对称轴）、$\sigma$（标准差，曲线的胖瘦），$\sigma > 0$。记 $\sigma^2$ 为方差
> - 定义域：整条实数轴 $(-\infty, +\infty)$——两端尾巴延伸到无穷，但密度趋近 0
> - 均值：$\mathbb{E}[X] = \mu$
> - 方差：$\mathrm{Var}[X] = \sigma^2$
> - 经验法则 (empirical rule)：约 68% 落在 $\mu \pm \sigma$，约 95% 落在 $\mu \pm 2\sigma$，约 99.7% 落在 $\mu \pm 3\sigma$

注意括号里写的是 $\sigma^2$ 还是 $\sigma$——记号 $\mathcal{N}(\mu, \sigma^2)$ 里的第二个量是**方差**，不是标准差。教科书习惯如此，无数人在这里栽跟头：看到 $\mathcal{N}(0, 4)$，标准差是 2，不是 4。

边界声明：**"长得像钟"不等于正态。** 任何对称单峰的曲线都长得像钟，但只有满足上面这个精确公式的才是正态。经验法则 68/95/99.7 是这条曲线专属的数值——换成别的分布，同样的区间概率完全两样。要判断数据是否正态，不能靠眼睛看形状，要靠假设检验——那是 §4.4 的故事。

### 四、指数分布：等待时间的墙

现在换一种墙。你不是在量身高，而是在**等**——等电话亭里下一个电话进来。时间流过去了，电话始终没响。你盯着秒针，心里发毛：已经等了 3 分钟了，下一通电话还要等多久？

先看一个自然的直觉：**如果平均每 2 分钟来一通电话，那么"从现在起还要等多久"会不会和"已经等了多久"有关？** 你可能会觉得：等了 3 分钟还没响，那"应该快响了吧"，概率应该变大。对吗？

这个直觉**错了**——而且错得非常有价值。电话的到达是彼此独立、以恒定平均速率发生的。数学上说，等待时间服从**指数分布 (exponential distribution)**，而它有一条震惊所有人的性质：**无记忆性 (memoryless)**——已经等了 3 分钟，与下一通电话何时到来**没有任何关系**。未来就像从未等过一样，从零重新开始。电话亭不记得你等了多久。

代入具体数字感受一下。平均每 2 分钟一通电话，则速率 $\lambda = \frac{1}{2} = 0.5$（每分钟）。"等一通电话的时间小于 1 分钟"的概率：

$$\mathrm{P}(X < 1) = 1 - e^{-\lambda \cdot 1} = 1 - e^{-0.5} \approx 1 - 0.6065 \approx 0.393$$

39.3%——还不到四成。直觉上"平均 2 分钟一通，等 1 分钟应该五五开"？不是。因为**等待时间从 0 起就被 $\lambda$ 反复地"消耗"**：密度函数 $\lambda e^{-\lambda x}$ 在 $x=0$ 处最高，越往后越小——等得越久，密度越低。时间没有站在你这边。

把 $\lambda = 0.5$ 换成字母 $\lambda$，得到通用公式：

> **指数分布** $X \sim \text{Exp}(\lambda)$
>
> 物理含义：建模"到下一次独立事件"的等待时间——事件以恒定平均速率 $\lambda$ 连续独立地发生。
>
> $$f(x) = \lambda e^{-\lambda x}, \quad x \ge 0$$
>
> - 参数：$\lambda$（速率参数，单位时间内事件发生的平均次数），$\lambda > 0$
> - 定义域：$x \ge 0$——等待时间不会是负数
> - 均值：$\mathbb{E}[X] = \dfrac{1}{\lambda}$（平均等待时间就是速率的倒数）
> - 方差：$\mathrm{Var}[X] = \dfrac{1}{\lambda^2}$
> - 无记忆性：$\mathrm{P}(X > s + t \mid X > s) = \mathrm{P}(X > t)$——"已经等了 $s$ 还没来"这个信息，完全不改变还要再等 $t$ 的概率

边界声明：指数分布的无记忆性既成就它、也限制它。它只适合**恒定速率**的过程——电话到达、放射性衰变、顾客进店。如果等的是"人的寿命"或"机械零件的寿命"，无记忆性就是灾难：零件会老化，用旧了坏的概率明明更大。老化的等待时间不属于指数分布——那是韦布尔 (Weibull) 分布的领地。

### 五、一张翻译表

四节撞墙之后，把连续世界的新语言和离散世界对照着收进一张表——你之后在深度学习里翻来覆去用的就是这张表：

| | 离散世界 | 连续世界 |
|---|---|---|
| 随机变量取值 | 可数的点 $k$ | 连续的区间 |
| 描述函数 | PMF $p(k)$ | PDF $f(x)$ |
| 函数本身的意义 | 是概率 | **不是**概率，是密度 |
| 总概率 | $\sum_k p(k) = 1$ | $\int_{-\infty}^{\infty} f(x)\,dx = 1$ |
| 算区间概率 | $\sum_{k \in A} p(k)$ | $\int_a^b f(x)\,dx$ |
| 记法的灵魂 | 求和 $\sum$ | 积分 $\int$ |

一句话记住它：**$\sum$ 换成 $\int$，概率换成密度**——这就是离散到连续的全部秘密。

## 第三步：DL 桥接

三个分布，三扇通往深度学习的门。

**正态分布 → 权重初始化。** 神经网络初始化时，每个权重 $w$ 从一个正态分布里抽样。为什么要正态？因为一个神经元接到的输入是很多项的和——而独立随机量的和，无论每个分量长什么样，都收敛到正态（**中心极限定理 (central limit theorem)**）。正态是"大量微小随机叠加"的天然归宿。为什么方差不能随便取？如果 $\sigma$ 太小，权重全挤在 0 附近，信号经过一层就衰减成无声；如果 $\sigma$ 太大，信号逐层爆炸。**He 初始化**对 ReLU 网络取 $w \sim \mathcal{N}(0, \tfrac{2}{n_{\text{in}}})$（$n_{\text{in}}$ 是输入神经元数），正是为了让激活值的方差在层与层之间**不涨不灭**。你看到的那个 $\tfrac{2}{n_{\text{in}}}$，就是"保持方差守恒"解出来的答案。

**指数分布 → 强化学习的折扣因子。** 在强化学习里，一个智能体要最大化**折扣回报 (discounted return)** $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$，其中 $0 < \gamma < 1$。看那一项 $\gamma^k$——它正是指数衰减：$\gamma^k = e^{k \ln \gamma} = e^{-\lambda k}$，速率 $\lambda = \ln\frac{1}{\gamma}$。越遥远的奖励，权重按指数塌下去。这和指数分布的无记忆性是同一种气质：$\gamma^k$ 相邻两项的比值恒为 $\gamma$，与距离多远无关——未来被一视同仁地、机械地打折。$\gamma$ 越大（越接近 1），智能体越"有耐心"；$\gamma$ 越小，它越只盯着眼前。一个超参数，背后立着一座概率分布的雕塑。

**均匀分布 → 数据增强。** 训练图像分类器时，我们把每张图随机旋转一个角度再喂给网络，让模型学会"旋转了还是同一只猫"。旋转角从哪来？$\theta \sim \text{Uniform}(-\theta_{\max}, \theta_{\max})$——**均匀**，意味着没有任何一个角度被偏爱。如果旋转角偏向某个方向，模型就会偷偷学会"朝某个角度的猫才算猫"。均匀分布是"没有任何先验偏好"的数学声明，它和 dropout 里随机遮罩神经元、随机裁剪的偏移量一样，处处在替模型说同一句话：**我不预设哪个位置更重要。**

这三种分布——正态管"叠加出来的自然"，指数管"衰减与等待"，均匀管"绝对公平"——是深度学习里出场频率最高的三个连续概率分布。它们的具体采样、PDF/CDF 计算、以及"为什么 $f(170) \approx 0.04$"的数值验证，见《代码.md》。
