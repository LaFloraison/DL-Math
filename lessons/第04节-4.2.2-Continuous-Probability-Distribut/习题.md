# 习题：连续概率分布

## 第一组：概念检验

**1. "密度不是概率，积分才是。"** 均匀分布 $\mathrm{Uniform}(0, 0.5)$ 的密度是 $f(x)=2$，比"最大概率 1"还大。这违反概率公理吗？$f(x)=2$ 到底是什么意思？

**解答**：不违反。$f(x)$ 是"单位长度上的概率浓度"，不是概率——真正的概率必须乘上区间宽度（积分）才得到。$\mathrm{Uniform}(0,0.5)$ 里底为 $0.5$，要让面积 $\int_0^{0.5} f\,dx = 0.5\times 2=1$，高只能被钉死在 $2$。"$f(x)=2$"的意思是"每单位长度里聚着 2 份概率浓度"；它乘以任意小区间宽度 $dx$ 得到概率 $2\,dx$，只要 $dx<0.5$，这个概率就小于 1。就像人口密度可以是每平方公里 2000 人，但"人"不是"概率"。

**思路点拨**：有人一看到 $f(x)=2>1$ 就以为违背了"概率不超过 1"。这是把"密度"和"概率"当成一个东西。连续世界里只有区间扛得起概率，单点概率恒为 0。对应《代码.md》边界声明 1："打印出来的数不是概率"。

**2. 记号陷阱。** 一个随机变量 $X\sim\mathcal{N}(0, 4)$。括号里的 $4$ 是标准差还是方差？请估算 $P(-2\le X\le 2)$ 与 $P(-4\le X\le 4)$ 各约等于多少，并说出依据。

**解答**：$\mathcal{N}(\mu,\sigma^2)$ 里第二个量是**方差**，标准差是它的平方根——所以 $\mathcal{N}(0,4)$ 里 $\sigma=2$。经验法则 (empirical rule) 说约 68% 落在 $\mu\pm\sigma$、约 95% 落在 $\mu\pm2\sigma$。于是：
- $P(-2\le X\le 2)=P(\mu-\sigma\le X\le \mu+\sigma)\approx 0.68$
- $P(-4\le X\le 4)=P(\mu-2\sigma\le X\le \mu+2\sigma)\approx 0.95$

**思路点拨**：这是《主线.md》明说的"无数人在这里栽跟头"的陷阱——若有人把 $4$ 当成标准差 $\sigma$，就会把 68% 区间错算成 $(-4,4)$，把 95% 区间错算成 $(-8,8)$。看到 $\mathcal{N}(a,b)$ 先问一句"$b$ 是 $\sigma^2$ 还是 $\sigma$"再动手，永远不亏。

**3. 判断正误："在呼叫中心已经等了 3 分钟电话还没响，那么接下来 1 分钟内响的概率，比刚开始等的时候大——等得越久越该来了。"**

**解答**：错误。电话到达是恒定速率 $\lambda=0.5$/分钟的独立事件，等待时间服从指数分布，而指数分布**无记忆 (memoryless)**：$P(X>s+t \mid X>s)=P(X>t)$。已经等了 $s=3$ 分钟这个信息，完全不改变"还要再等 $t=1$ 分钟"的概率——未来就像从未等过一样，从零重新开始。$P(X<1)=1-e^{-0.5}\approx 0.393$，无论你已等了多久都是这个数。电话亭不记得你等了多久。

**思路点拨**：这是赌徒谬误的连续版。但要小心指数分布的边界：无记忆性只适合**恒定速率**的过程（电话到达、放射性衰变）。若等的是"机械零件寿命"，零件会老化，用旧了坏的概率更大——无记忆性就是灾难，那是韦布尔 (Weibull) 分布的领地。对应《主线.md》指数分布的边界声明。

## 第二组：计算实践

**4. 手算 + 代码验证。**
（a）手算：$X\sim\mathrm{Uniform}(0,1)$，$P(0.2\le X\le 0.8)$（教材 §4.2.2.1 的例子）；
（b）手算：$X\sim\mathrm{Exp}(0.5)$，$P(X<1)$（教材 §4.2.2.3 的例子）；
（c）用《代码.md》步骤 2–4 的三个 PDF 函数，量出 $f(170)$（正态 $\mu=170,\sigma=10$）与 $f(0)$（指数 $\lambda=0.5$），并解释这两个数是什么、不是什么。

**解答**：
（a）面积法：$P(0.2\le X\le 0.8)=(0.8-0.2)\times 1=0.6$。
（b）$P(X<1)=\int_0^1 0.5\,e^{-0.5x}dx=1-e^{-0.5}\approx 1-0.6065=0.3935$。
（c）代码：

```python
import numpy as np
def normal_pdf(x, mu, sigma):
    return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))
def exponential_pdf(x, lam):
    return lam * np.exp(-lam * x) * (x >= 0)
print(f"f(170) = {normal_pdf(170.0, 170.0, 10.0):.6f}   峰顶密度 = 1/(σ√(2π))")
print(f"f(0)   = {exponential_pdf(0.0, 0.5):.6f}    x=0 处密度 = λ")
```

输出（与《代码.md》步骤 5 一致）：

```
f(170) = 0.039894   峰顶密度 = 1/(σ√(2π))
f(0)   = 0.500000    x=0 处密度 = λ
```

$f(170)=0.039894$ 的意思是"170 cm 附近每单位长度聚着约 0.04 的密度"，$f(0)=0.5$ 的意思是"等待时间为 0 处每单位时间聚着 0.5 的密度"——它们都是**密度**，**不是**"恰好 170 cm 的概率是 3.99%"或"恰好等 0 分钟的概率是 50%"。

**思路点拨**：（b）若有人用"密度×宽度"近似：$f(0)\times 1=0.5$，会高估 $P(X<1)=0.3935$——因为密度在 $[0,1]$ 内不恒定（指数在 0 处最陡），矩形近似天然高估。这再次印证"密度不是概率，积分才是"。（a）里均匀分布密度恒定，所以"密度×宽度"恰好精确——均匀是唯一没有这个陷阱的分布。

**5. 身高区间概率。** 身高 $X\sim\mathcal{N}(170, 10^2)$（单位 cm）。用数值积分求 $P(160\le X\le 180)$，并与"拿峰顶密度乘宽度"的近似比较。这验证了《主线.md》的哪一条结论？

**解答**：梯形法则数值积分（沿用《代码.md》步骤 6 的做法）：

```python
import numpy as np
def normal_pdf(x, mu, sigma):
    return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))
x = np.linspace(160.0, 180.0, 10001)
I = np.trapz(normal_pdf(x, 170.0, 10.0), x)
approx = normal_pdf(170.0, 170.0, 10.0) * 20.0
print(f"积分 ∫160^180 f(x) dx = {I:.4f}")
print(f"峰顶密度 × 宽度(近似) = {approx:.4f}")
```

输出：

```
积分 ∫160^180 f(x) dx = 0.6827
峰顶密度 × 宽度(近似) = 0.7979
```

积分给出 $0.6827$——正是经验法则第一条"约 68% 落在 $\mu\pm\sigma$"（160 和 180 恰好是 $170\pm10=\mu\pm\sigma$）。而"峰顶密度 $\times$ 宽度"给出 $0.7979$，严重高估：正态的钟在顶部是凸的，密度从峰顶向两边迅速跌落，用峰顶的密度乘以整个 20 cm 宽度，等于把两边矮下去的部分全按最高密度算了。

**思路点拨**：若有人直接拿 $f(170)\times 20\approx 0.80$ 当答案，就是再次踩了"密度当概率"的坑——密度在区间内不恒定，矩形近似必须对"形状"诚实。经验法则 68/95/99.7 不是"长得像钟"就能用的，它是正态曲线这个精确公式的专属数值（换均匀分布，$\mu\pm\sigma$ 区间只有约 57.7%）。对应《代码.md》步骤 6 与《主线.md》的边界声明。

**6. 无记忆性的数值验证。** 用代码验证指数分布的无记忆性：$\lambda=0.5$ 时，证明 $P(X>4\mid X>3)=P(X>1)$。（提示：$P(X>t)=e^{-\lambda t}$。）

**解答**：代码：

```python
import numpy as np
lam = 0.5
def P_gt(t):                 # P(X > t) = e^{-λt}
    return np.exp(-lam * t)
s, t = 3.0, 1.0
lhs = P_gt(s + t) / P_gt(s)  # P(X > 4) / P(X > 3) = P(X>4 | X>3)
rhs = P_gt(t)                # P(X > 1)
print(f"P(X>4 | X>3) = {lhs:.4f}")
print(f"P(X>1)       = {rhs:.4f}")
```

输出：

```
P(X>4 | X>3) = 0.6065
P(X>1)       = 0.6065
```

两边都是 $e^{-0.5}=0.6065$：$\dfrac{e^{-2}}{e^{-1.5}}=e^{-0.5}$。已经等了 3 分钟（$X>3$）条件下还要再等 1 分钟以上的概率，与从零开始直接等 1 分钟以上**完全相同**——等待没有记忆。对应《代码.md》步骤 4 的 `exponential_pdf` 与《主线.md》的无记忆性公式 $P(X>s+t\mid X>s)=P(X>t)$。

**思路点拨**：若有人把 $P(X>4\mid X>3)$ 算成 $P(X>4)=e^{-2}\approx 0.135$，那是忘了条件概率要除以 $P(X>3)$——"已知已等 3 分钟"这个条件把概率空间缩小了。无记忆性的本质，正是"这个条件不改变任何东西"。

## 第三组：DL 延伸

**7. He 初始化。** 一个 ReLU 网络，权重用正态分布初始化。（a）为什么初始化用正态而不是别的分布？（b）如果 $\sigma$ 太大或太小会怎样？（c）He 初始化取 $w\sim\mathcal{N}(0,\tfrac{2}{n_{\text{in}}})$，那个 $\tfrac{2}{n_{\text{in}}}$ 是怎么来的？

**解答**：
（a）一个神经元接收的输入是很多独立随机量的和——无论每个分量是什么分布，和的极限都收敛到正态（中心极限定理，central limit theorem）。正态是"大量微小随机叠加"的天然归宿。
（b）$\sigma$ 太小，权重全挤在 0 附近，信号经过一层就衰减成无声；$\sigma$ 太大，激活值逐层爆炸。两者都会让网络训不动。
（c）He 初始化让激活值的方差在层与层之间**不涨不灭**。ReLU 会把一半的激活砍成 0（方差拦腰斩断），所以要补偿 2 倍——$\tfrac{2}{n_{\text{in}}}$ 正是"保持方差守恒"解出来的答案。你看到的那条 $\mathcal{N}(0,\tfrac{2}{n_{\text{in}}})$，就是连续概率分布和深度学习的第一次握手。

**思路点拨**：若有人只记得"用正态初始化"而忽略 $\sigma$ 的取值，会踩到"方差爆炸/消失"的坑——分布选对了，参数配错了，同样完蛋。若有人把 $\tfrac{2}{n_{\text{in}}}$ 当成拍脑袋的常数，那是没看见"方差守恒"这条约束：它不是 magic number，是一个方程的解。延伸见《参考资料.md》He et al. (2015)。

**8. 数据增强的均匀声明。** 训练图像分类器时，每张图随机旋转一个角度再喂给网络，旋转角 $\theta\sim\mathrm{Uniform}(-\theta_{\max},\theta_{\max})$。（a）为什么必须是**均匀**而不是"任意随机"？（b）如果旋转角偏向某个方向，模型会学到什么不该学到的东西？（c）这和其他哪个 DL 技巧共享"不预设哪个位置更重要"的哲学？

**解答**：
（a）"随机"有无数种分布，均匀是其中"每个角度等可能"的那一种。用正态或其他分布做旋转角，意味着某些角度被系统性地偏爱，数据增强就会偷偷灌输偏好。（b）若偏向某个方向，模型会学到"朝某个角度的猫才算猫"——学到的特征带上了位置偏差，泛化反而变差。（c）dropout 的随机遮罩、随机裁剪的偏移量、随机擦除，都是同一个声明：**我不预设哪个位置更重要**。均匀分布是"没有任何先验偏好"的数学真名（《主线.md》第三步桥接）。

**思路点拨**：若有人把"随机"当作"均匀"的同义词，就错过了重点——均匀分布的 $1/(b-a)$ 是一份**精确到每个角度的、非常强的规则**，它的平坦正是它的严格。真实工程里若发现某类图像旋转后性能暴跌，首先要怀疑的正是：旋转角分布是否偷偷带上了非均匀的偏向。这与《镜鉴》"均匀管绝对公平"一脉相承。
