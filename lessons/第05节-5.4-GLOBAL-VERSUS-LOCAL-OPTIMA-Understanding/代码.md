# 代码：双谷丘陵——起点决定命运，退火逃出困境

**目标**：主线里 $f(x) = x^4 - 3x^2 + x$ 有两个谷：全局最小在 $x\approx-1.3$（$f\approx-3.51$），局部最小在 $x\approx1.13$（$f\approx-1.07$）。这里实现三种策略并对照：**朴素梯度下降**（从两个不同起点出发，看它停在哪）、**随机重启**（多次随机起步取最好）、**模拟退火**（允许偶尔变差，慢慢冷却）。一个脚本，把"起点决定命运"和"怎么逃出命运"都演给你看。

## 层一：完整脚本

```python
import numpy as np
rng = np.random.default_rng(42)

# ---- 1. 非凸目标及其梯度 ----
def f(x):
    return x**4 - 3.0*x**2 + x          # 全局最小 x≈-1.3, 局部最小 x≈1.13

def df(x):
    return 4.0*x**3 - 6.0*x + 1.0

# ---- 2. 朴素梯度下降 (从起点开始, 一路向下) ----
def gd(start, lr=0.01, iters=2000):
    x = start
    for _ in range(iters):
        x = x - lr * df(x)              # 只往下走, 绝不回头
    return x, f(x)

# ---- 3. 随机重启: N 次随机起步, 取最好的 ----
def random_restarts(n=30, lo=-2.0, hi=2.0):
    best = None
    for _ in range(n):
        x, fx = gd(rng.uniform(lo, hi))
        if best is None or fx < best[1]:
            best = (x, fx)
    return best

# ---- 4. 模拟退火: 温度高时接受变差, 慢慢冷却 ----
def anneal(start=2.0, T0=5.0, steps=5000):
    x = start
    best_x, best_f = x, f(x)
    for t in range(steps):
        T = T0 * (1.0 - t / steps)          # 温度线性降到 0
        x_new = x + rng.normal(0, 0.5)       # 随机试探
        delta = f(x_new) - f(x)
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-9)):
            x = x_new                        # 变好就接受; 变差按概率接受
        if f(x) < best_f:
            best_x, best_f = x, f(x)
    return best_x, best_f

# ---- 5. 对照实验 ----
x_a, fa = gd(1.0)          # 起点 1.0 (靠近浅谷)
x_b, fb = gd(-1.5)         # 起点 -1.5 (靠近深谷)
print(f"朴素 GD 起点 1.0 : x={x_a:.4f}, f={fa:.4f}  → 困在局部最优!")
print(f"朴素 GD 起点 -1.5: x={x_b:.4f}, f={fb:.4f}  → 到达全局最优")
rx, rf = random_restarts()
print(f"随机重启(30次)  : x={rx:.4f}, f={rf:.4f}")
ax, af = anneal()
print(f"模拟退火         : x={ax:.4f}, f={af:.4f}  (解析全局最优 -3.51)")
```

输出（随机种子固定，可复现）：

```
朴素 GD 起点 1.0 : x=1.1309, f=-1.0702  → 困在局部最优!
朴素 GD 起点 -1.5: x=-1.3008, f=-3.5139  → 到达全局最优
随机重启(30次)  : x=-1.3008, f=-3.5139
模拟退火         : x=-1.3009, f=-3.5139
```

**同一个函数，两条截然不同的命运**：从 1.0 出发，梯度下降停在浅谷 $f\approx-1.07$；从 -1.5 出发，它到达深谷 $f\approx-3.51$。这就是"起点决定命运"。而随机重启（多试几次总有命中的）和模拟退火（允许乱跳再慢慢收网）都逃出了浅谷，抵达全局最优。**四行输出，就是 §5.4 的全部教学。**

## 层二：分步逐函数拆解

### 步骤 1-2：目标、梯度、朴素梯度下降

```python
def f(x):
    return x**4 - 3.0*x**2 + x

def df(x):
    return 4.0*x**3 - 6.0*x + 1.0

def gd(start, lr=0.01, iters=2000):
    x = start
    for _ in range(iters):
        x = x - lr * df(x)
    return x, f(x)
```

#### `f` / `df` —— 双谷函数及其导数

**操作**：$f(x) = x^4 - 3x^2 + x$；导数 $f'(x) = 4x^3 - 6x + 1$。令 $f'=0$ 得三个驻点（两个谷、一个峰）。**输入**：标量 `x`。**输出**：函数值 / 梯度。
**可调参数**：换系数就是换地形——把 `+x` 改成 `+2*x`，深谷变浅、浅谷变深，两个谷的"王位"互换。

#### `gd` —— 只会向下的笨下山者

**操作**：从 `start` 出发，反复 $x \leftarrow x - \text{lr}\cdot f'(x)$——**只往下走，绝不回头**。2000 步后停下的点，完全取决于起始点落在了哪个"盆地"。
**输入**：`start`（起点）、`lr=0.01`（步长）、`iters=2000`。**输出**：`(x, f(x))`。
**可调参数**：`lr`、`iters` 控制精度。**关键**：`gd` 没有任何"越山"能力——这是它与下面两种策略的本质区别。

**对应数学**：主线的朴素梯度下降——§5.3.6 的公式，在非凸地形上的"天真版本"。

---

### 步骤 3：随机重启——多试几次，总有命中的

```python
def random_restarts(n=30, lo=-2.0, hi=2.0):
    best = None
    for _ in range(n):
        x, fx = gd(rng.uniform(lo, hi))
        if best is None or fx < best[1]:
            best = (x, fx)
    return best
```

#### `random_restarts` —— 用多次试错对冲起点运气

**操作**：在 $[-2,2]$ 均匀抽 30 个随机起点，每个跑一遍 `gd`，保留全局最好的结果。**命中深谷盆地即赢**——深谷的"吸引范围"越大，命中概率越高。
**输入**：`n=30`（重启次数）、`lo/hi`（采样范围）。**输出**：`(x, fx)` 全局最好。
**可调参数**：`n` 越大命中概率越高，但成本线性增长。**这是主线武器一"随机重启"的直白实现**——也是深度学习"多换几个随机种子训练"的数学理由。

### 步骤 4：模拟退火——允许倒退，换取全局

```python
def anneal(start=2.0, T0=5.0, steps=5000):
    x = start
    best_x, best_f = x, f(x)
    for t in range(steps):
        T = T0 * (1.0 - t / steps)
        x_new = x + rng.normal(0, 0.5)
        delta = f(x_new) - f(x)
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-9)):
            x = x_new
        if f(x) < best_f:
            best_x, best_f = x, f(x)
    return best_x, best_f
```

#### `T = T0 * (1.0 - t / steps)` —— 冷却计划

**操作**：温度从 `T0=5.0` 线性降到 0。**输入**：`t`（当前步）、`steps`（总步数）。**输出**：标量 `T`。
**可调参数**：`T0` 决定"初始乱跳幅度"。太小——一开始就冻结，逃不出浅谷；太大——前期纯乱走，浪费步数。**这是退火最像"学习率"的超参数。**

#### 接受准则 `delta < 0 or rng.random() < exp(-delta / T)`

**操作**：试探新点 `x_new`。若变好（`delta < 0`）必然接受；若变差，以概率 $\exp(-\delta/T)$ 接受——**差得越多、温度越低，接受概率越小**。这就是"偶尔接受更差解"的精确公式（Metropolis 准则，蒙特卡洛的血脉，§4.3）。
**输入**：`delta`（变差量）、`T`（温度）。**输出**：`bool` 决定是否接受。
**可调参数**：`0.5` 是试探步长。太大——乱跳；太小——探索不足。

**对应数学**：主线武器二"模拟退火"——用冶金学的"高温乱跳 + 缓慢冷却"，让搜索获得翻山能力。

## 实验台：让丘陵现出全貌

1. **换起点**：`gd(0.0)`、`gd(1.3)`、`gd(-2.0)`——观察"起点落在哪个盆地就停在哪个谷"。
2. **调退火温度**：`T0=0.5`（过早冻结，可能困在浅谷）、`T0=50`（前期纯乱走）——体会"冷却太快 vs 太慢"。
3. **换地形**：把 `f` 改成 Rastrigin 或 $f(x)=\sin(x)+0.1x$——局部最优更多，朴素 GD 几乎必困，退火/重启的价值更明显。
4. **画损失面**：用 `matplotlib` 画 $f(x)$ 曲线，标出两个谷、起点与三种策略的落点——"看见"全局 vs 局部。

**对应数学**：这些实验验证主线的一句话——**非凸世界里，起点决定命运，而随机性决定你能不能改命。**
