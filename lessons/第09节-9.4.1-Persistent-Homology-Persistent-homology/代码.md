# 代码：记录特征的出生与死亡——从零实现持久同调

主线里我们说：持久同调 = 追踪拓扑特征（块、环、空腔）在过滤中的**出生 (birth)** 与**死亡 (death)**，持久性 = 死亡 − 出生。本节代码**从零实现**这套流程：

- **持久 H0**（连通分量的生死）：并查集按距离合并，每次合并"杀死"较年轻的分量——记录它的死亡尺度；
- **持久 H1**（环的生死）：遍历所有出现的半径，跟踪 $\beta_1$ 的增减——$\beta_1$ 增加表示有环出生，减少表示有环死亡。

两个实验：**教材的 6 点例子**（应该有一个环），以及**圆上 8 点 vs 8 个随机点**（圆有持久的环、噪声没有）——这正是教材 Figure 9.5/9.6 的故事。脚本只依赖标准库 `math`（随机噪声用 NumPy 生成）。

## 层一：完整脚本

```python
import numpy as np, math

def dist(a, b):
    """欧氏距离（决定'谁在尺度 r 内相连'）。"""
    return math.hypot(a[0]-b[0], a[1]-b[1])

def ph0(points):
    """持久 H0：并查集按距离合并，记录每个分量的 (出生, 死亡)。"""
    n = len(points)
    edges = sorted((dist(points[i], points[j]), i, j)
                   for i in range(n) for j in range(i+1, n))
    parent = list(range(n)); born = [0.0]*n; pairs = []
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]; a = parent[a]
        return a
    for d, i, j in edges:
        ri, rj = find(i), find(j)
        if ri != rj:                              # 合并两个分量
            if born[ri] >= born[rj]:              # 较年轻的分量死亡
                pairs.append((born[ri], d)); parent[rj] = ri
            else:
                pairs.append((born[rj], d)); parent[ri] = rj
    pairs.append((born[find(0)], float('inf')))   # 最后一个分量永远存活
    return pairs

def betti1(points, eps):
    """固定尺度 eps 下，Vietoris–Rips 复形的 β1（环数）。"""
    n = len(points)
    edges = [(i,j) for i in range(n) for j in range(i+1,n)
             if dist(points[i], points[j]) <= eps]
    eset = set(edges)
    tris = [(i,j,k) for (i,j) in edges for k in range(j+1,n)
            if (i,k) in eset and (j,k) in eset]
    parent = list(range(n))
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]; a = parent[a]
        return a
    for i, j in edges:
        ra, rb = find(i), find(j)
        if ra != rb: parent[ra] = rb
    beta0 = len({find(i) for i in range(n)})
    E = len(edges)
    M = [[0]*len(tris) for _ in range(E)]          # ∂2 矩阵：三角形→边
    col = {e: c for c, e in enumerate(edges)}
    for c, (i,j,k) in enumerate(tris):
        for e in ((i,j),(i,k),(j,k)): M[col[e]][c] ^= 1
    pr = 0
    for cc in range(len(tris)):                    # 模2高斯消元求 rank(∂2)
        r = next((rr for rr in range(pr, E) if M[rr][cc]), None)
        if r is None: continue
        M[r], M[pr] = M[pr], M[r]
        for rr in range(pr+1, E):
            if M[rr][cc]:
                for c2 in range(cc, len(tris)): M[rr][c2] ^= M[pr][c2]
        pr += 1
    return E - n + beta0 - pr                       # β1 = E - V + β0 - rank(∂2)

def ph1(points):
    """持久 H1：遍历所有半径，β1 增→环出生，β1 减→环死亡。"""
    n = len(points)
    radii = sorted(set(dist(points[i], points[j])
                       for i in range(n) for j in range(i+1, n)))
    prev, born, pairs = 0, [], []
    for r in radii:
        b = betti1(points, r)
        if b > prev:
            for _ in range(b - prev): born.append(r)
        elif b < prev:
            for _ in range(prev - b):
                if born: pairs.append((born.pop(), r))
        prev = b
    while born: pairs.append((born.pop(), float('inf')))
    return pairs

fmt = lambda p: [(round(b,3), '∞' if d==float('inf') else round(d,3)) for b, d in p]

print("=== 实验 1：教材的 6 个点 (0,0)(1,0)(0,1)(1,1)(2,1)(3,1) ===")
six = [(0,0),(1,0),(0,1),(1,1),(2,1),(3,1)]
print(f"H0（块）：{fmt(ph0(six))}")
print(f"H1（环）：{fmt(ph1(six))}")

print("\n=== 实验 2：圆上 8 点 vs 8 个随机点 ===")
circ = [(math.cos(2*math.pi*k/8), math.sin(2*math.pi*k/8)) for k in range(8)]
rng = np.random.default_rng(0)
noise = [(float(a), float(b)) for a, b in rng.uniform(-1, 1, (8, 2))]
print(f"圆   H1：{fmt(ph1(circ))}")
print(f"噪声 H1：{fmt(ph1(noise))}")
print(f"噪声 H0（块）：{fmt(ph0(noise))}")
```

运行输出（Python 3.11）：

```text

=== 实验 2：圆上 8 点 vs 8 个随机点 ===

噪声 H1：[]
噪声 H0（块）：[(0.0, 0.103), (0.0, 0.264), (0.0, 0.382), (0.0, 0.43), (0.0, 0.541), (0.0, 0.921), (0.0, 1.295), (0.0, ∞)]
```

读这三组输出：

- **6 点 H0**：5 个分量出生在 0、在 $\varepsilon=1.0$ 时全部合并（该尺度的边长都是 1.0）；最后一个分量存活到 ∞。
- **6 点 H1**：**一个环 (1.0, 1.414)**——出生在 $\varepsilon=1.0$（左边四点的方框闭合）、死亡在 $\varepsilon=1.414$（方框对角线出现、三角形把环填实），持久性 = 0.414。**教材说"环在 r=1.0 出生、r=2.0 死亡"是示意性叙述；代码给出精确值：1.414（=√2，方框对角线长）。**
- **圆 vs 噪声 H1**：圆有一个环 **(0.765, 1.848)**（持久性 1.083）；噪声**一个环都没有**。**一个数字就分开了"有环形结构"和"没有结构"的数据。** 噪声的 H0 全部短命（<1.3 就合并），没有任何持久特征。

## 层二：分步逐函数拆解

### 步骤 1：`ph0` —— 持久 H0（块的生死）

```python
def ph0(points):
    n = len(points)
    edges = sorted((dist(points[i], points[j]), i, j)
                   for i in range(n) for j in range(i+1, n))
    parent = list(range(n)); born = [0.0]*n; pairs = []
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]; a = parent[a]
        return a
    for d, i, j in edges:
        ri, rj = find(i), find(j)
        if ri != rj:
            if born[ri] >= born[rj]:
                pairs.append((born[ri], d)); parent[rj] = ri
            else:
                pairs.append((born[rj], d)); parent[ri] = rj
    pairs.append((born[find(0)], float('inf')))
    return pairs
```

#### `ph0` —— 并查集实现"块"的持久性

**做什么**：模拟 $\varepsilon$ 从 0 增大、点对按距离依次相连；每当两个连通分量合并，**较年轻的那个死亡**（记录它的出生与本次合并尺度）。
**操作**：所有点对距离排序后从小到大处理。`find` 找分量代表，`born[x]` 记分量 x 的出生尺度（初始 0）。合并时比较两个分量的 `born`——出生晚的（较年轻）是"被并掉的"，记录 `(born, 合并距离)`；出生早的（较老）继续活着。最后剩下一个分量存活到 ∞。
**输入**：`points`（n×2 点云）。
**输出**：`(birth, death)` 列表，长度 n（n-1 个死亡 + 1 个 ∞）。
**可调参数**：无（工具函数）。它是持久同调 H0 的**标准精确算法**——教材说"$r=0$ 时 6 个分量、$r$ 增大逐渐合并"，这里就是它的自动化。
**对应数学**：$\beta_0$ 的持久性。输出里 `(0.0, 1.0)` 表示"这个块从 0 出生、在 1.0 被并掉"——所有块在 1.0 一起合并，因为 6 点里最近的"跨块距离"都是 1.0。

### 步骤 2：`betti1` —— 固定尺度的环数

```python
def betti1(points, eps):
    n = len(points)
    edges = [(i,j) for i in range(n) for j in range(i+1,n)
             if dist(points[i], points[j]) <= eps]
    eset = set(edges)
    tris = [(i,j,k) for (i,j) in edges for k in range(j+1,n)
            if (i,k) in eset and (j,k) in eset]
    parent = list(range(n))
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]; a = parent[a]
        return a
    for i, j in edges:
        ra, rb = find(i), find(j)
        if ra != rb: parent[ra] = rb
    beta0 = len({find(i) for i in range(n)})
    E = len(edges)
    M = [[0]*len(tris) for _ in range(E)]
    col = {e: c for c, e in enumerate(edges)}
    for c, (i,j,k) in enumerate(tris):
        for e in ((i,j),(i,k),(j,k)): M[col[e]][c] ^= 1
    pr = 0
    for cc in range(len(tris)):
        r = next((rr for rr in range(pr, E) if M[rr][cc]), None)
        if r is None: continue
        M[r], M[pr] = M[pr], M[r]
        for rr in range(pr+1, E):
            if M[rr][cc]:
                for c2 in range(cc, len(tris)): M[rr][c2] ^= M[pr][c2]
        pr += 1
    return E - n + beta0 - pr
```

#### `betti1` —— §9.2.1 同调机器在单个尺度下的切片

**做什么**：在固定阈值 `eps` 下，构造 Vietoris–Rips 复形（边 + 三角形），算环数 $\beta_1$。
**操作**：
- `edges`：距离 $\le$ eps 的点对；`tris`：三边两两闭合的三元组（$k$ 从 `j+1` 起、用 `eset` 查 `(i,k),(j,k)` 是否都是边）。
- 并查集算 $\beta_0$；`M` 是"三角形→边"的关联矩阵（模 2），高斯消元求秩 `rank(∂2)`。
- `E - n + beta0 - pr` 是公式 $\beta_1 = E - V + \beta_0 - \mathrm{rank}(\partial_2)$。
**输入**：`points`、`eps`（阈值）。
**输出**：整数，$\beta_1$。
**可调参数**：`eps` 是唯一旋钮——**这正是 §9.4.1 主线说的"固定尺度 Betti 数的尴尬"：取 1.0 环未闭合（β1=0）、取 1.414 环已填实（β1=0）、取 1.2 才有环（β1=1）**。持久同调（`ph1`）正是为了摆脱"这个 eps 怎么选"的尴尬而存在的。
**对应数学**：§9.2.1 代码的 `betti_numbers` 的 $\beta_1$ 部分，原样复用。

### 步骤 3：`ph1` —— 持久 H1（环的生死）

```python
def ph1(points):
    n = len(points)
    radii = sorted(set(dist(points[i], points[j])
                       for i in range(n) for j in range(i+1, n)))
    prev, born, pairs = 0, [], []
    for r in radii:
        b = betti1(points, r)
        if b > prev:
            for _ in range(b - prev): born.append(r)
        elif b < prev:
            for _ in range(prev - b):
                if born: pairs.append((born.pop(), r))
        prev = b
    while born: pairs.append((born.pop(), float('inf')))
    return pairs
```

#### `ph1` —— 用 β1 的增减追踪环的生死

**做什么**：遍历所有出现的半径（从小到大），跟踪 $\beta_1$：**增加了几个环 → 记录这几个环在此半径出生；减少了几个环 → 最近的环在此半径死亡**（LIFO 配对）。
**操作**：`radii` 是所有点对距离的集合（排序去重）。在每一个半径上重算 `betti1`。`b > prev` 时把多出的环的出生压栈；`b < prev` 时弹栈配对死亡。最后栈里剩下的环存活到 ∞。
**输入**：`points`。
**输出**：`(birth, death)` 列表（环的持久性数据）。
**可调参数**：无。注意：这个"跟踪 β1 增减"的实现对"环一次只生/死一个"的小例子精确；处理大量同时生死的环需要标准边界矩阵约简（对 n 个点 O(n³)），本实现保持教学透明。
**对应数学**：这就是教材定义的持久性——圆环 $(0.765, 1.848)$ 表示"环在尺度 0.765 出现、1.848 消失，活过 1.083 个尺度单位"。**离"出生即死"越远，越接近真实结构。**

这里有两层信息：**主环 (0.765, 1.218)** 还在——圆环结构没有被噪声摧毁，但它的死亡从 1.848 提前到 1.218（环内部的噪声点连出的弦更早填实了三角形，把环"闷"死了）。**次环 (0.922, 1.053)** 是噪声点造出的短命环（持久性仅 0.131），贴在对角线附近——**它正是教材说的"出现又很快消失、视为噪声"的特征**。这个实验教会我们两件事：持久同调能区分"长命结构"与"短命噪声"；但**噪声放的位置会改变持久性的数值**——这就是教材 §9.5.1 提醒的"过滤参数要细心设置"的缘由。

## 边界声明：这套代码能做什么，不能做什么

1. **它算的是持久性，不是"这个环有没有用"**。圆环持久 1.083、6 点方框持久 0.414——数字告诉我们"结构有多强"，不告诉我们"对分类/回归重不重要"。结构特征与任务语义对齐是 §9.5.1 的事。
2. **"跟踪 β1 增减"对小例子精确，对大规模并不标准**。真正的持久同调用边界矩阵约简（复杂度 O(n³) 最坏），并返回 H0/H1/H2 全维度；本脚本教学优先、保持透明，适合 n ≤ 几十的点云。
3. **结果依赖距离度量**。欧氏距离下"环出生 0.765、死亡 1.848"；换度量（如曼哈顿）数值会变，但"圆有持久环、噪声没有"的**定性结论**不变——持久同调对度量有一定鲁棒性，但对尺度范围（filtration 的起止）仍然敏感。真实应用（§9.5.1）需要细心设置参数并做统计检验。
