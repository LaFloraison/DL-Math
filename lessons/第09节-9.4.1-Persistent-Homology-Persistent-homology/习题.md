# 习题：活得久的才是结构

## 第一组：概念检验

**1. 判断题并说明理由**："持久图（persistence diagram）上离对角线越近的点，代表越重要的结构。"

**2. 单选题**：Betti 数 $\beta_1$ 统计的是？
- (A) 连通分量（独立的块）的个数
- (B) 环（1 维洞）的个数
- (C) 空腔（2 维洞）的个数
- (D) 数据点的个数

**3. 简答**：什么是过滤 (filtration)？为什么持久同调要通过"在所有尺度上建单纯复形"来摆脱"选一个阈值"的困境？

### 解答与思路点拨

**1. 错误。** 离对角线越近的点，持久性（death−birth）越小——那是**转瞬即逝的噪声**（教材："出生后很快死亡的特征通常被视为噪声"）；离对角线越远的点，持久性越大、越重要。选"正确"的读者把"距离对角线"的方向搞反了。记住口诀：**远离对角线 = 长寿 = 结构；贴在对角线 = 短命 = 噪声。**

**2. (B)。** $\beta_0$ 数连通分量（A），$\beta_1$ 数环/1 维洞（B），$\beta_2$ 数空腔（C）。(D) 是点数，与 Betti 数无关。三兄弟的"维度"依次升高：点→线→面。

**3.** 过滤是一串**嵌套**的单纯复形 $\mathcal{K}_{\varepsilon_1}\subset\mathcal{K}_{\varepsilon_2}\subset\cdots$——尺度参数 $\varepsilon$ 从 0 增长，复形不断"长胖"（点连成边、边围成三角形）。持久同调在**每一个** $\varepsilon$ 下数 Betti 数并追踪特征的生死，于是"该用哪个阈值"这个问题被消解了——**不选一个尺度，而是在所有尺度下同时观察**，让"活多久"自己回答。这正是教材"在不同尺度下看特征如何存留或变化"的意思。

## 第二组：计算实践

**4. 手算**：四个点构成一个正方形：$(0,0),(1,0),(1,1),(0,1)$。写出该点集持久同调的：
   - (a) H0 的持久性数据（几个块？分别在什么尺度合并？）；
   - (b) H1 的持久性数据（有没有环？出生/死亡尺度？持久性？）。
   提示：正方形边长 1，对角线长 √2≈1.414。

**5. 代码验证**：用本节的 `ph0`/`ph1` 验证 4 的结果；再把正方形整体放大 2 倍（顶点变 $(0,0),(2,0),(2,2),(0,2)$），重算，观察环的出生/死亡如何变化。

### 解答与思路点拨

**4.** (a) 四个块：出生 0，分别在 $\varepsilon=1.0$（四条边合并成一块）全部死亡——4 个分量 → 1 个分量，所以是 3 个 `(0, 1.0)` 对 + 1 个 `(0, ∞)`。(b) 一个环：四条边在 $\varepsilon=1.0$ 闭合（出生 1.0），对角线在 $\varepsilon=\sqrt2\approx1.414$ 出现并填实三角形（死亡 1.414），持久性 = 0.414。**手算要点**：先列所有点对距离（4 边 = 1，2 对角线 = 1.414），再按"谁先连上、谁先填实"推出生/死亡。

**5.** 验证（用本节函数）：

```python
square = [(0,0),(1,0),(1,1),(0,1)]
print(f"H0：{fmt(ph0(square))}")
print(f"H1：{fmt(ph1(square))}")
big = [(0,0),(2,0),(2,2),(0,2)]     # 正方形放大 2 倍
print(f"放大2倍 H1：{fmt(ph1(big))}")
```

```text
H0：[(0.0, 1.0), (0.0, 1.0), (0.0, 1.0), (0.0, ∞)]
H1：[(1.0, 1.414)]
放大2倍 H1：[(2.0, 2.828)]
```

正方形 H1 = (1.0, 1.414)（持久 0.414）；放大 2 倍后 = (2.0, 2.828)（持久 0.828）——**出生与死亡同步放大、环依然存在**。这正是拓扑 vs 度量的分界：**"有没有环"是拓扑性质（不变），持久性的具体数值是度量性质（随比例缩放）**。注意：如果**单方面**拉长某条边（比如把 (0,0) 拉到 (1.5,0.5)），Rips 持久性可能让环消失——因为填实环的三角形可能先于闭合边出现。这是 Rips 构造"度量敏感"的一面（§9.4.1 边界声明的现实注脚），值得自己动手验证。

## 第三组：DL 延伸

**6. 场景判断**：你提取了一批数据的持久同调特征（每个样本一个"环的持久性"），想作为额外特征喂给分类网络。请指出：持久性向量怎么作为输入？它可能给网络带来哪些普通坐标特征没有的信息？又有什么风险？

**7. 思考题**：§9.4.1 教材说持久同调可用于"分析网络"（social/biological/communication）。请设计：如何用持久同调分析一个社交网络（比如谁是"核心群"、有没有"环状结构"），并把结果和普通指标（度中心性、聚类系数）做个对比。

### 解答与思路点拨

**6.** 做法：对每个样本（或每类数据）算持久图，把持久性较大的特征（如 top-k 环的 birth/death/persistence）拼接成固定长度向量，作为网络的额外输入。**新增信息**：普通坐标特征只反映"点的位置"，持久性特征反映"结构"——比如"这两类数据一个有环、一个没环"，坐标上看不出，拓扑特征直接给出判别信号（§9.5.1 的圆形 vs 方形正是这个例子）。**风险**：(a) 计算成本高；(b) 持久性对过滤参数敏感，参数没调好会引入噪声特征；(c) 拓扑特征可能与任务无关，白加维度；(d) 不同样本的持久图对齐需要技巧。

**7.** 把社交网络当成"点 = 用户、边 = 关系"的图，构造过滤（比如按边的权重/交互强度增大的顺序建图），用持久同调提取：$\beta_0$（图何时从"多社区"连成"整体"——社区结构的分离强度）、$\beta_1$（何时出现环——冗余连接/反馈回路）。对比：度中心性只告诉你"谁连接多"，聚类系数只告诉你"局部三角密度"；持久同调告诉你"**全局的连通性结构如何随尺度演化**"——比如一个高度冗余的网络（很多环）与一个树状网络（无环）在持久图上截然不同。这正是教材"揭示网络如何连接、如何聚类、整体结构如何"的意思。
