# 习题：Jacobian 与链式法则的关系

## 一、概念检验

### 题 1.1（填空）

设 $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^p$、$\mathbf{g}: \mathbb{R}^p \to \mathbb{R}^m$，复合 $\mathbf{h} = \mathbf{g}\circ\mathbf{f}$ 的 Jacobian 是 $J_{\mathbf{h}}(\mathbf{x}) = J_{\mathbf{g}}(\underline{\quad})\cdot J_{\mathbf{f}}(\mathbf{x})$。其中 $J_{\mathbf{g}}$ 的求值点是____，它的形状是____；$J_{\mathbf{f}}$ 的形状是____；乘积形状是____。

**解答**：$\mathbf{f}(\mathbf{x})$（中间变量）；$\mathbf{f}(\mathbf{x})$；$m \times p$；$p \times n$；$m \times n$。
**思路点拨**：三处关键——求值点（中间变量 $\mathbf{f}(\mathbf{x})$，不是 $\mathbf{x}$）、维度咬合（$p$ 是 $f$ 的输出维 = $g$ 的输入维）、乘积形状（$m\times n$ 与 $h$ 的输出/输入维一致）。最常见的错误是漏写"$\mathbf{f}(\mathbf{x})$"这个求值点，或把 $J_g$ 的形状写成 $m\times n$。**"先内层、外层在中间值上求导"**——这个结构在多元与一元里完全一致。

### 题 1.2（选择）

对复合 $J_{\mathbf{g}\circ\mathbf{f}} = J_{\mathbf{g}} \cdot J_{\mathbf{f}}$，下列**错误**的是（ ）

A. $J_{\mathbf{g}}$ 与 $J_{\mathbf{f}}$ 的乘法顺序不能交换
B. 结合律允许改变连乘的分组方式
C. 若 $m = p = n$，$\det J_{\mathbf{h}} = \det J_{\mathbf{g}} \cdot \det J_{\mathbf{f}}$
D. 改变复合顺序（$\mathbf{f}\circ\mathbf{g}$）时，乘积仍是 $J_{\mathbf{g}} \cdot J_{\mathbf{f}}$

**解答**：D。
**思路点拨**：A 正确——矩阵乘法不可交换。B 正确——$(J_g J_f) J_h = J_g (J_f J_h)$，这是前向/反向模式成本分析的基础。C 正确——$\det(AB) = \det A \det B$，这正是 §3.6.1 习题 3.2 用过的"梯度体积缩放"。D 错误——$\mathbf{f}\circ\mathbf{g}$（先 $g$ 后 $f$）的 Jacobian 是 $J_{\mathbf{f}} \cdot J_{\mathbf{g}}$，顺序完全反转。选 D 的同学把"复合顺序"和"矩阵顺序"脱钩了：**先作用的后写，乘积也后乘。**

### 题 1.3（简答）

为什么反向传播"从输出往输入"（反向模式）比"从输入往输出"（前向模式）便宜？结合结合律解释。

**解答**：Jacobian 连乘满足结合律，所以两种分组的**答案相同**，但成本不同。前向模式从左往右，中间产生 $n\times n$ 的"胖"矩阵，每一步成本 $n^3$；反向模式从右往左，从标量损失出发，始终保持 $1\times n$ 的行向量，每步成本 $n^2$。对 $L$ 层网络，总成本分别是 $O(Ln^3)$ 与 $O(Ln^2)$——差一个 $n$ 因子。反向传播选反向模式，正是选了"便宜的分组"。
**思路点拨**：关键是把"结合律"和"成本"两个概念接起来——**结合律保证答案一致，成本决定选哪个分组**。能说出"保持 1×n 行向量、避开 n×n 胖矩阵"就抓住了本质。这也就是为什么真实框架的 `loss.backward()` 从损失往回走。

## 二、计算实践

### 题 2.1（手算）

设 $\mathbf{f}(x, y) = (x + 2y,\; 3x - y)$，$\mathbf{g}(u, v) = (u^2,\; v)$。

(a) 求 $J_{\mathbf{f}}$。
(b) 求 $J_{\mathbf{g}}(\mathbf{f}(x,y))$。
(c) 用链式法则求 $J_{\mathbf{g}\circ\mathbf{f}}$。
(d) 直接展开 $\mathbf{g}(\mathbf{f}(x,y))$ 验证。

**解答**：
(a) $J_{\mathbf{f}} = \begin{pmatrix}1&2\\3&-1\end{pmatrix}$。
(b) $J_{\mathbf{g}} = \begin{pmatrix}2u&0\\0&1\end{pmatrix}$，在 $\mathbf{f}(x,y) = (x+2y,\ 3x-y)$ 处：$\begin{pmatrix}2(x+2y)&0\\0&1\end{pmatrix}$。
(c) $J_{\mathbf{h}} = J_{\mathbf{g}} J_{\mathbf{f}} = \begin{pmatrix}2(x+2y)&0\\0&1\end{pmatrix}\begin{pmatrix}1&2\\3&-1\end{pmatrix} = \begin{pmatrix}2(x+2y)&4(x+2y)\\3&-1\end{pmatrix}$。
(d) $\mathbf{h}(x,y) = ((x+2y)^2,\ 3x-y)$。直接求导：$\partial h_1/\partial x = 2(x+2y)$，$\partial h_1/\partial y = 4(x+2y)$；$\partial h_2/\partial x = 3$，$\partial h_2/\partial y = -1$。一致。
**思路点拨**：注意 (c) 里 $J_g$ 的第一行是 $\begin{pmatrix}2(x+2y)&0\end{pmatrix}$——因为 $g_1 = u^2$ 只依赖 $u$，$\partial g_1/\partial v = 0$。链式法则的矩阵乘自动处理了"$g$ 的第一个输出只依赖 $u$"这个稀疏性。手算一遍，再用《代码.md》的三条路径（链式/直接/数值）复核，你会更信任这个矩阵乘法。

### 题 2.2（代码验证）

验证 $\det J_{\mathbf{h}} = \det J_{\mathbf{g}} \cdot \det J_{\mathbf{f}}$ 对题 2.1 成立。

```python
import numpy as np
Jf = np.array([[1.0, 2.0], [3.0, -1.0]])
x, y = 1.0, 2.0
Jg = np.array([[2.0*(x+2*y), 0.0], [0.0, 1.0]])
Jh = Jg @ Jf
print(f"det(Jg)·det(Jf) = {np.linalg.det(Jg)*np.linalg.det(Jf):.4f}")
print(f"det(Jh)         = {np.linalg.det(Jh):.4f}")
```

**解答**：$\det J_f = 1\times(-1)-2\times3 = -7$；$\det J_g = 2(x+2y)\times1 = 10$；$\det J_h = -70$。两者一致（$(-7)\times10 = -70$）。
**思路点拨**：这是 $\det(AB)=\det A\det B$ 的直接验证。有趣的是：$|\det J_h| = 70$ 是复合变换整体的面积放大倍数，它**同时**是 $J_f$（7 倍）与 $J_g$（10 倍）的乘积——两层膜的体积缩放相乘，正是 Toy Model"叠两张膜"的数学版。这个"缩放的乘法"也是 §3.6.1 习题 3.2 里"梯度体积指数缩放"的来源。

## 三、DL 延伸

### 题 3.1

一个 3 层网络，输入 2 维、第 2 层 3 维、输出 1 维。三层（含线性部分）的 Jacobian 形状分别为 $J_3: 1\times3$、$J_2: 3\times2$、$J_1: 2\times2$。写出梯度 $\frac{\partial L}{\partial a_1}$ 的 Jacobian 连乘表达式，并指出：反向传播从哪里开始、每步保持什么形状的中间量。

**解答**：$\frac{\partial L}{\partial a_1} = \frac{\partial L}{\partial a_3} \cdot J_3 \cdot J_2 \cdot J_1$（$a_3$ 是输出）。反向传播从 $\frac{\partial L}{\partial a_3}$（$1\times1$ 标量，即 $\partial L/\partial a_3$）开始，先乘 $J_3$（$1\times3$）得 $1\times3$，再乘 $J_2$（$3\times2$）得 $1\times2$，最后乘 $J_1$（$2\times2$）得 $1\times2$——**全程保持行向量（$1\times$ 开头）**，从不产生 $3\times3$ 之类的胖矩阵。
**思路点拨**：这道题把 §3.5.2 的 `dL_da1 = W2.T @ dL_dz2` 与本节链式法则的形状分析合一。能回答"全程 $1\times k$ 行向量"就复述了反向模式的成本优势。注意维度：中间维度（2→3→1）必须逐层咬合，否则矩阵乘不合法——这也是定义网络时"相邻层单元数匹配"的数学根源。

### 题 3.2

工程师给自动微分写了一个"前向模式"版本：从输入开始，一路用 Jacobian 乘过去，最后得到梯度。他发现训练极慢。请用本节知识解释为什么，并说明为什么 `loss.backward()`（反向模式）会快。

**解答**：前向模式从输入 $a_0$（$1\times n_0$ 或向量）开始，把 Jacobian 从左往右连乘——对多输出、高维中间层，中间会累积出 $n\times n$ 的大矩阵（或需要同时追踪 $n_0$ 个方向的 Jacobian），每步成本 $O(n^3)$；对 $L$ 层总成本 $O(Ln^3)$。而损失是**标量**（1 维），`loss.backward()` 从它出发反向乘——每步保持 $1\times k$ 行向量，成本 $O(Ln^2)$。当 $n$ 是百万量级，这就是"不可计算"与"可计算"的差别。**标量损失的场景下，反向模式是唯一可行的选择。**
**思路点拨**：能说出"前向模式在中间产生胖矩阵、反向模式保持瘦行向量"就抓住了本质。补充一句：如果输出**也是高维向量**（如某些生成任务要输出 $10^5$ 维），反向模式会从 $10^5$ 个标量分别出发、也变贵——此时前向模式反而可能更优。**没有绝对最优，只有"对着输出维数选方向"**——这个判断力正是理解 autodiff 两种模式的钥匙。
