# 习题：梯度下降

## 第一组：概念检验

**1.1（填空）** 梯度 $\nabla J(\theta)$ 指向函数\_\_\_\_\_\_最快的方向；梯度下降沿其\_\_\_\_\_\_方向移动。更新规则是 $\theta_{\text{new}} = $ \_\_\_\_\_\_。

**1.2（选择）** 学习率 $\alpha$ 设得过大，最可能出现的后果是：
- A. 收敛变慢
- B. 参数在最优附近震荡或直接发散
- C. 卡在局部最优
- D. 梯度变为零

**1.3（判断+理由）** "梯度下降一定能找到函数的全局最小值。" 对还是错？在什么条件下它保证找到全局最小？在非凸情况下它可能停在哪里？

## 第二组：计算实践

**2.1（手算）** 教材例：$\theta = 0.5$，$\nabla J(\theta) = 1.2$，$\alpha = 0.01$。计算 $\theta_{\text{new}}$。如果 $\alpha$ 改成 0.1，$\theta_{\text{new}}$ 是多少？两次结果说明学习率对一步更新的影响是什么？

**2.2（手算）** 考虑 $J(\theta) = \theta^2$（即 $f(x) = x^2$）。从 $\theta = 3$ 出发，$\alpha = 0.2$，手算前 3 步的 $\theta$ 值（梯度为 $\nabla J = 2\theta$）。你能看出它在向哪个值收敛吗？如果 $\alpha = 1.1$，前 3 步会怎样？

**2.3（代码验证）** 运行《代码.md》脚本：(a) 把 `alpha` 改成 `0.001`，200 步后 $\theta$ 是多少？离解析解 2.8095 差多远？(b) 把 `alpha` 改成 `0.1`，发生了什么？(c) 把 `X` 改成 `[0.0005, 0.001, 0.002]`（面积单位放大 1000 倍），`alpha=0.01` 下 200 步后 $\theta$ 是多少？这验证了什么？

## 第三组：DL 延伸

**3.1** 深度网络中 `loss.backward()` 和 `optimizer.step()` 各对应主线公式的哪一部分？为什么说"反向传播是梯度下降的梯度工厂"？

**3.2** 你在训练一个模型，loss 在第 5 轮变成 NaN。请列举至少三种可能原因，并说明如何排查（结合学习率、梯度爆炸、特征尺度）。

---

## 解答与思路点拨

### 第一组

**1.1** 上升（steepest increase）；相反（负梯度，即最陡下降）；$\theta_{\text{old}} - \alpha \nabla J(\theta_{\text{old}})$。**易错点**：梯度指向上**升**最快——所以更新要**减**梯度，方向别搞反。

**1.2** 选 B。$\alpha$ 太大 → 一步跨过谷底、来回震荡，极端则发散（cost 变 NaN）。A（收敛变慢）是 $\alpha$ **太小**的症状；C（卡局部最优）常因 $\alpha$ 太小跨不过洼沿；D 是梯度为零的结果，与 $\alpha$ 无关。

**1.3** 错。梯度下降只保证"下降"，不保证"降到全局最小"。保证全局最小需要条件：**函数凸（且学习率合适）**——此时任何局部最小都是全局最小（§5.3.4）。在非凸情况下，它可能停在**局部最小 (local minimum)** 或**鞍点 (saddle point)**（§5.4 详讲）。**判断要点**：把"梯度下降"与"全局最优"划等号，是这道题最大的坑——它只在凸世界里成立。

### 第二组

**2.1** $\theta_{\text{new}} = 0.5 - 0.01\times 1.2 = 0.5 - 0.012 = 0.488$。若 $\alpha = 0.1$：$\theta_{\text{new}} = 0.5 - 0.1\times 1.2 = 0.38$。**说明**：$\alpha$ 从 0.01 变 0.1，一步的改动量从 0.012 变 0.12——整整放大 10 倍。学习率决定"每步移动多少"，同样一个梯度，步长不同，走出的距离天差地别。

**2.2** $J = \theta^2$，$\nabla J = 2\theta$。
- $\theta_0 = 3$ → $\theta_1 = 3 - 0.2\times 6 = 1.8$ → $\theta_2 = 1.8 - 0.2\times 3.6 = 1.08$ → $\theta_3 = 1.08 - 0.2\times 2.16 = 0.648$。收敛方向：向 $\theta=0$（最小值）。
- $\alpha = 1.1$：$\theta_1 = 3 - 1.1\times 6 = 3 - 6.6 = -3.6$ → $\theta_2 = -3.6 - 1.1\times(-7.2) = -3.6+7.92 = 4.32$ → $\theta_3 = 4.32 - 1.1\times 8.64 = 4.32-9.504 = -5.184$。**越跳越大——发散！**
**易错点**：$\alpha=1.1$ 时注意梯度会**改变符号**（从负到正），每一步都被推到更远的一侧——这比"震荡"更危险，是真正的发散。

**2.3**
(a) `alpha=0.001`：200 步后 $\theta$ 大约在 2.2–2.4 之间，离 2.8095 差 0.4–0.6——**龟速，200 步不够**（需要几千步）。
(b) `alpha=0.1`：cost 变 NaN，$\theta$ 爆炸——**发散**。
(c) `X` 放大 1000 倍后梯度也放大，同样的 $\alpha$ 下 $\theta$ 几乎不动（仍在 0.5 附近）——**特征尺度敏感**。归一化后（如 `X/np.max(X)`）恢复。
**要点**：这三个实验对应主线"$\alpha$ 太大发散 / 太小龟速 / 特征缩放敏感"三个撞墙点，一个脚本全部复现。

### 第三组

**3.1** `loss.backward()` 对应**计算梯度 $\nabla J(\theta)$**——反向传播用链式法则（Ch03）从输出端逐层把误差传回，高效算出每一层权重上的偏导，这就是"梯度工厂"的含义：没有它，几亿维的梯度算不出来，梯度下降就无从迈步。`optimizer.step()` 对应**执行更新 $\theta \leftarrow \theta - \alpha \nabla J$**——把梯度工厂产出的方向翻译成一步移动。**两者合起来，才是完整的一步梯度下降。**

**3.2** 至少三种：(a) **学习率太大**——更新跨过谷底甚至冲出有效域，梯度爆炸。排查：把 `alpha` 调小一个数量级看是否恢复。(b) **梯度爆炸（深层网络）**——链式法则连乘导致梯度指数级放大。排查：加梯度裁剪（`clip_grad_norm_`）、换自适应优化器（Adam/RMSprop）、检查是否该用更稳定的初始化。(c) **特征/输入尺度失当**——某特征量级过大让损失面病态。排查：标准化输入、检查是否混入了异常值（NaN 输入）。此外还有 loss 函数本身在数值上不稳定（如 log 里出现 0）的可能。**要点**：NaN 是"训练崩溃"的告警灯，按"学习率 → 梯度 → 数据"顺序排查是标准流程。
