# 代码：从零训练一个线性回归——梯度下降的第一场实战

**目标**：主线用教材的数值例子（$\theta=0.5$，$\nabla J=1.2$，$\alpha=0.01 \Rightarrow \theta=0.488$）演示了一步更新。这里把它**升级成完整的训练循环**：用 NumPy 从零实现单变量线性回归 $h(x) = \theta x$，成本 $J(\theta) = \frac{1}{2}\sum(h(x_i)-y_i)^2$，用梯度下降把 $\theta$ 从 0.5 一路训练到最小二乘最优解。**你写的这段代码，就是 PyTorch 里 `optimizer.step()` 的裸核。**

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 数据: 房子面积 x(百平尺) 与价格 y(万元) ----
X = np.array([0.5, 1.0, 2.0])
y = np.array([1.5, 3.0, 5.5])
n = len(X)

# ---- 2. 模型/成本/梯度 ----
def predict(theta, x):
    return theta * x                       # h(x) = theta*x

def cost(theta):
    pred = predict(theta, X)               # 批量预测, 形状 (3,)
    return 0.5 * np.sum((pred - y) ** 2)   # J = 1/2 * sum((h-y)^2)

def grad(theta):
    pred = predict(theta, X)
    return np.sum((pred - y) * X)          # dJ/dtheta = sum((h-y)*x)

# ---- 3. 梯度下降训练 ----
theta = 0.5          # 起点 (教材例子)
alpha = 0.01         # 学习率
epochs = 200
history = []
for t in range(epochs):
    g = grad(theta)                        # 量坡度
    theta = theta - alpha * g              # 迈一步: theta <- theta - alpha * grad
    history.append((t + 1, theta, cost(theta)))

# ---- 4. 打印结果 ----
print(f"训练完成: theta = {theta:.4f}")
print(f"解析最优(最小二乘) = {np.sum(X*y)/np.sum(X*X):.4f}")
print("前 3 步 (epoch, theta, cost):")
for t, th, c in history[:3]:
    print(f"  epoch {t:3d}  theta={th:.4f}  cost={c:.4f}")
print(f"最后一步: epoch {history[-1][0]}  theta={theta:.4f}  cost={history[-1][2]:.6f}")
```

输出：

```
训练完成: theta = 2.8083
解析最优(最小二乘) = 2.8095
前 3 步 (epoch, theta, cost):
  epoch   1  theta=0.6213  cost=18.6317
  epoch   2  theta=0.7399  cost=15.9818
  epoch   3  theta=0.8558  cost=13.6191
  epoch 200  theta=2.8083  cost=0.0007
```

200 步后，$\theta$ 从 0.5 训练到 2.8083，逼近解析最优 2.8095，成本从 18.6 掉到 0.0007。**第一步的 $\theta=0.6213$**——你把教材的"$\theta: 0.5 \to 0.488$"换成了自己的数据，但机制一模一样：位置减去（学习率 × 坡度）。这个"位置 -= 学习率 × 坡度"的循环，就是整个机器学习训练的心脏。

## 层二：分步逐函数拆解

### 步骤 1：数据——一次"预测房价"的最小原型

```python
X = np.array([0.5, 1.0, 2.0])
y = np.array([1.5, 3.0, 5.5])
n = len(X)
```

**操作**：三套房子的面积与价格：0.5 百平尺卖 1.5 万元、1.0 卖 3.0、2.0 卖 5.5。`X`、`y` 都是形状 `(3,)` 的一维数组，`n=3`。
**可调参数**：加数据点、改价格，最优 $\theta$ 会变。**注意**：这些数据本身就近似线性（价格 ≈ 2.75×面积），所以线性模型能拟合得很好——选数据时别选"明显非线性"的，否则误差项会让训练讲解失焦。

---

### 步骤 2：模型、成本、梯度——三件套

```python
def predict(theta, x):
    return theta * x

def cost(theta):
    pred = predict(theta, X)
    return 0.5 * np.sum((pred - y) ** 2)

def grad(theta):
    pred = predict(theta, X)
    return np.sum((pred - y) * X)
```

#### `predict` —— 模型假设函数

**操作**：$h(x) = \theta x$。输入标量 `theta` 与标量 `x`，返回 $\theta x$。**输入**：`theta`（float）、`x`（float）。**输出**：float。
**可调参数**：把 `theta * x` 改成 `theta[0] + theta[1] * x` 就变成带截距的双参数回归——`theta` 变成长度 2 的向量，梯度也变成向量。**这是从"单参数"迈向"多参数"的最短一步**，深度学习的"参数向量"概念由此开始。

#### `cost` —— 损失函数

**操作**：计算 $J(\theta) = \frac{1}{2}\sum_i (h(x_i) - y_i)^2$。`predict(theta, X)` 因 NumPy 广播返回形状 `(3,)` 的预测数组；`(pred - y) ** 2` 逐元素平方；`np.sum` 求和；`0.5` 是教材公式的系数（求导时约掉 2）。
**输入**：`theta`（float）。**输出**：标量 `float`——当前模型的误差。
**可调参数**：把 `0.5 *` 去掉、或换成绝对值 $|pred - y|$（MAE），最优解不变但收敛行为变化——**损失函数的形状决定"山的形状"**。

#### `grad` —— 梯度（这里的"拐杖"）

**操作**：计算 $\frac{dJ}{d\theta} = \sum_i (h(x_i) - y_i) \cdot x_i$。推导：$\frac{\partial}{\partial\theta}\frac{1}{2}(\theta x_i - y_i)^2 = (\theta x_i - y_i) x_i$，逐样本求和。**这就是链式法则在最小二乘里的化身**——Ch03 的产物，此刻直接上岗。
**输入**：`theta`（float）。**输出**：标量 `float`——当前坡度的方向与陡度。
**可调参数**：无直接参数。**验证**：手动算 `grad(0.5)`：$h=[0.25,0.5,1.0]$，$h-y=[-1.25,-2.5,-4.5]$，×$X$ 得 $[-0.625,-2.5,-9.0]$，和 $=-12.125$——梯度为负，说明 $\theta$ 需要**增大**（0.5 偏小了）。这与教材例子方向相反，只是因为数据不同——机制完全一致。

**对应数学**：`cost` 和 `grad` 分别是主线定义块里的 $J(\theta)$ 与 $\nabla J(\theta)$。

---

### 步骤 3：训练循环——下山 200 步

```python
theta = 0.5
alpha = 0.01
epochs = 200
history = []
for t in range(epochs):
    g = grad(theta)
    theta = theta - alpha * g
    history.append((t + 1, theta, cost(theta)))
```

#### 核心更新 `theta = theta - alpha * g`

**操作**：这就是梯度下降的全部：$\theta \leftarrow \theta - \alpha \nabla J(\theta)$。`alpha` 是学习率（步长），`g` 是梯度（方向+陡度）。**每次迭代 = 插一次拐杖 + 迈一步**。
**可调参数**：
- `alpha = 0.01`：调大到 `0.05`——震荡（$\theta$ 在最优附近横跳）；调到 `0.1` 以上——**发散**（cost 爆炸成 NaN）。**学习率的全部脾气，就在这一个数字上**。
- `epochs = 200`：迭代次数。多跑几步更接近最优，但收益递减。
- `history.append(...)`：记录每步的 (epoch, theta, cost) 供打印，删掉不影响训练。

#### `g = grad(theta)` —— 每次迭代重新量坡度

**操作**：**每步都用当前位置重算梯度**——这是梯度下降的关键纪律。山势随位置变化，你每迈一步都要重新插拐杖，不能拿旧坡度走新路。

**对应数学**：这是主线更新规则的完整循环版——图 5.7 的"红点逐步下移"。

### 步骤 4：结果与对照

```python
print(f"训练完成: theta = {theta:.4f}")
print(f"解析最优(最小二乘) = {np.sum(X*y)/np.sum(X*X):.4f}")
print("前 3 步 (epoch, theta, cost):")
for t, th, c in history[:3]:
    print(f"  epoch {t:3d}  theta={th:.4f}  cost={c:.4f}")
```

**操作**：打印训练结果与解析解对照。解析最小二乘解：$\theta^* = \frac{\sum X_i y_i}{\sum X_i^2} = \frac{0.75+3+11}{5.25} \approx 2.8095$（Ch02 最小二乘 / 正规方程）。
**输出**：训练 $\theta=2.8083$ 与解析解 $2.8095$ 之差约 $0.001$——200 步的数值解已经逼近精确解。**要点**：这个"数值逼近解析"的对照，正是"为什么需要梯度下降"的答案——解析解只在有公式时可用，深度网络没有公式，只能靠这 200 步。

## 实验台：让下山显出真章

1. **换学习率**：`alpha = 0.001`（龟速，200 步到不了最优）、`alpha = 0.05`（震荡）、`alpha = 0.15`（发散，cost → NaN）。你会看到学习率的"三档命运"。
2. **看轨迹**：把 `history` 画成 `cost vs epoch` 曲线——理想的下降曲线是"快速坠落后平缓收尾"（凸函数的签名）。
3. **换损失**：`cost` 改成绝对值误差（去掉平方），梯度变成符号函数——收敛变慢、在最优附近抖，直观体会"损失形状决定收敛性格"。
4. **不归一化**：把 `X` 改成 `[0.0005, 0.001, 0.002]`（面积单位换成万平尺），同样的 $\alpha$ 下训练几乎不动——**亲手撞上"特征尺度敏感"这堵墙**，然后归一化 `X` 再看恢复如初。

**对应数学**：实验 4 正是主线的撞墙点——特征缩放。你用代码证明了一件事：**归一化不是锦上添花，是梯度下降的必需品**。
