# 历史：梯度下降——一条从牛顿到 GPU 的漫长下坡路

## 1847 年的巴黎：一个数学家把"下山"写成了公式

奥古斯丁-路易·柯西，复变函数的奠基人，1847 年发表了一篇论文。他研究的问题朴素得惊人：**给定一个函数，怎么找到它的最小值？** 在那个没有计算机的年代，这个问题的答案通常是"求导、令导数为零、解方程"。但柯西意识到：很多函数根本解不出那个方程——你连它的解析解都写不出来，怎么求最小值？

于是他提出一个笨办法：**别指望一步到位，一步步往山下走。** 在当前位置，看函数往哪个方向最陡地上升，然后朝相反的方向走一小步。重复。柯西把它称作"梯度法 (la méthode de la descente)"——**把"找极值"从"解方程"变成了"重复地看脚下"**。这是梯度下降在数学史上的第一次现身。

有意思的是，柯西本人对这个方法并不十分看重——当时的数学更迷恋优雅的解析解，对这种"土办法"兴趣寥寥。梯度下降被搁置了几十年，像一个被提前发明、却没人需要的工具。**它需要一个真正解不开方程的时代，才能发光。**

## 1948-1970：当"解不开方程"成为常态

时间快进到二十世纪中叶。第二次世界大战后，统计学、经济学、工程学里的优化问题越来越多——而它们的函数一个比一个难解。1948 年，统计学家提出了一个此前无人在意的更新规则：沿着"最速下降方向"迭代修正参数。到 1950 年代，Robbins 与 Monro 的随机逼近（§5.1 历史提过）让"用带噪声的梯度也能收敛"成为可能——梯度下降开始被认真当作数值方法使用。

但真正把梯度下降推上王座的，是机器学习的觉醒。1960 年代，弗拉基米尔·瓦普尼克（Vapnik）和切尔沃宁基斯在苏联研究模式识别，罗森布拉特在美国推广感知机（§5.3.1 提过）。到 1980 年代，一个叫**反向传播 (backpropagation)** 的算法横空出世——它用链式法则，把网络输出端的误差逐层传回，高效地算出每一层的梯度。**梯度下降第一次有了能喂饱它的"梯度工厂"。**

1986 年，鲁梅尔哈特、辛顿和威廉姆斯发表了那篇奠定现代深度学习的论文，把反向传播 + 梯度下降写成完整的训练范式。从这一刻起，**"训练一个网络"就和"用梯度下降最小化损失"画上了等号**——直到今天，这个等号依然成立。

## 1990-2010：梯度下降的自我进化

反向传播解决了"梯度从哪来"，下一个问题是"步子迈多大"。整整一代研究者在这上面花光了头发。

- **1992 年，Yurii Nesterov 提出 Nesterov 动量**——不是简单沿当前梯度走，而是"先顺着惯性张望一下再迈步"，收敛更快。
- **2011 年，John Duchi 等提出 Adagrad**——给每个参数单独配一个学习率，历史梯度大的参数自动迈小步。
- **2012 年，Tieleman 与 Hinton 在 Coursera 课程里提出 RMSprop**——用滑动平均代替历史累加，解决了 Adagrad 学习率衰减过猛的问题。
- **2014 年，Kingma 与 Ba 提出 Adam**——把动量与自适应学习率合二为一，还加上了偏差校正。它好用到近乎"免调参"，从此统治了整个深度学习世界的 `optimizer` 列表。

**每一步进化，都是同一个公式的同一个伤口：$\theta \leftarrow \theta - \alpha \nabla J$。** 变的是 $\alpha$ 怎么定、$\nabla$ 怎么估、要不要加惯性。那个"1.75 张桌子"的问题（§5.3.3）不曾困扰过梯度下降，但"该迈多大步"的问题，困扰了它一个半世纪。

## 2012 至今：GPU 上的万马下山

2012 年，AlexNet 用两块 GTX 580 显卡完成了 ImageNet 上的惊天一战。从此，梯度下降有了它梦寐以求的硬件：**GPU**。几千个并行核心同时计算梯度——不再是柯西笔下那个一步一停的独行者，而是铺天盖地的万马下山。

今天，GPT 们用数万块 GPU、数月时间、数万亿次梯度更新，把 $\theta$ 从随机初始化一路推到能写诗、能推理、能编程。回望 1847 年，柯西在纸上写下"朝最陡下降方向走一小步"的那个下午，他绝不会想到——这句话将成为人类历史上被最多次执行的数学操作之一。

## 门，通向主线

从柯西的"土办法"，到反传来的"梯度工厂"，到 Adam 的"自适应步长"，再到 GPU 上的万马下山——梯度下降的历史，就是"只凭脚下坡度走天下"这一信念的一百八十年进化史。它简单得近乎天真，却托起了整个深度学习。现在，该亲手量一次坡度、迈一步了。
