# Ch07 §7.4.3 灵活与多才 · 代码.md

主线讲图的三种"多才"：权重装强度、方向装单向、异质装类型。本文件用一个**加权有向异质图**（迷你知识图谱：地点、人物、机构三种节点；"位于""任职""距离"三种边）把三种多样性同时装进代码，并演示"**按边类型分路聚合**"的消息传递——异质图 GNN 的核心动作。全篇手写 numpy。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 迷你知识图谱：三种节点、三种有向边、部分带权重
#    节点类型：人(P)、地点(L)、机构(O)；边：位于(L)∈L, 任职(W), 距离(D)∈带权重
nodes = [("北京", "L"), ("上海", "L"), ("张伟", "P"),
         ("李娜", "P"), ("清大", "O"), ("复大", "O")]
triples = [("北京", "位于", "中国"), ("上海", "位于", "中国"),
           ("张伟", "任职", "清大"), ("李娜", "任职", "复大"),
           ("北京", "距离", "上海")]                     # 注意"中国"不在 nodes 里，见下
# 为完整性，把"中国"补进去
nodes += [("中国", "L")]
edge_types = {"位于": 0, "任职": 1, "距离": 2}

def build_hetero(nodes, triples, edge_types):           # ③ 三类边分开存：每类一张邻接矩阵
    idx = {n: i for i, (n, _) in enumerate(nodes)}
    n = len(nodes)
    mats = {t: np.zeros((n, n), dtype=float) for t in edge_types}
    for s, rel, o in triples:
        mats[rel][idx[s], idx[o]] = 1.0                 # 有向：只写 s→o
    return mats

def aggregate_by_type(mats, H, order):                  # ④ 分边类型聚合：每类边各自的 A @ H
    outs = []
    for t in order:                                     # order 固定类型顺序，保证输出可读
        outs.append(mats[t] @ H)                        # 每类边贡献一份"邻居聚合"
    return np.hstack(outs)                              # 拼起来：异质表示

mats = build_hetero(nodes, triples, edge_types)
ORDER = ["位于", "任职", "距离"]                        # ⑤ 固定类型的输出顺序
H = np.eye(len(nodes))                                  # ⑥ 初始特征 = 独热（每节点自己一类）
print("边类型数：", len(mats), "，每类邻接矩阵形状：", mats["位于"].shape)
agg = aggregate_by_type(mats, H, ORDER)
print("异质聚合后表示形状（n × 边类型数）：", agg.shape)
print("'北京'的表示（按 位于/任职/距离 分类型聚合）：\n", agg[nodes.index(("北京","L"))])
```

输出：

```
边类型数： 3 ，每类邻接矩阵形状： (7, 7)
异质聚合后表示形状（n × 边类型数）： (7, 3)
'北京'的表示（分类型聚合）：
 [1. 0. 1.]
```

北京的表示 `[1, 0, 1]` 的三个分量对应三种关系类型："位于"这一类里，北京指向中国（得 1 分）；"任职"这一类里北京没有出边（0）；"距离"这一类里北京指向上海（1）。**同一张图、同一个节点，不同类型的边被分开记账**——这就是异质图的"分路聚合"：每类关系有自己的通道，最后拼成一个更丰富的表示。若把所有类型混成一个矩阵，北京的表示会被压扁成 `[2, 0]`（丢失"是什么类型的关系"），异质信息就没了。

## 层二：分步逐函数拆解

### 步骤 1：定义异质图的构建

```python
def build_hetero(nodes, triples, edge_types):
    idx = {n: i for i, (n, _) in enumerate(nodes)}
    n = len(nodes)
    mats = {t: np.zeros((n, n), dtype=float) for t in edge_types}
    for s, rel, o in triples:
        mats[rel][idx[s], idx[o]] = 1.0
    return mats
```

#### build_hetero —— 每类边一张邻接矩阵

`mats[rel][idx[s], idx[o]] = 1.0`

**操作**：不是一张大矩阵，而是**每种关系类型一张 $n\times n$ 邻接矩阵**（有向：只写 $s \to o$）。`mats["位于"]` 存所有"位于"关系，`mats["任职"]` 存所有"任职"关系，互不混叠。

**输入**：`nodes`（list of (名字, 类型)）、`triples`（list of (主语, 关系, 宾语)）、`edge_types`（关系名 → 编号的映射）。

**输出**：dict，键是关系类型，值是 `(n, n)` 有向邻接矩阵。

**可调参数**：
- 权重：把 `1.0` 换成三元组里的权重值，就得到"加权异质图"（如"距离"边直接带公里数）。
- 类型数量可扩展：再加一种关系（"合作""竞争"），只需在 `edge_types` 里加一行，`mats` 自动多一张矩阵。

**对应数学**：§7.4.3 的**异质图**——边按类型分组。每类边对应一个关系子图，异质图 = 多个同质子图的叠加。

---

### 步骤 2：定义分类型聚合

```python
def aggregate_by_type(mats, H):
    outs = []
    for t in sorted(mats):
        outs.append(mats[t] @ H)
    return np.hstack(outs)
```

#### aggregate_by_type —— 每种关系各聚合一份，再拼接

`mats[t] @ H` 与 `np.hstack(outs)`

**操作**：对每种边类型 t，算 `mats[t] @ H`（该类型下的邻居聚合，§7.3 的 sum 聚合）；把各类结果**横向拼接**（`hstack`）成一个更长的向量。这样节点的表示 = "位于邻居给的表示 | 任职邻居给的表示 | 距离邻居给的表示"——**类型信息被保留**。

**输入**：`mats`（dict of 矩阵）、`H`（`(n, f)` 特征矩阵）。

**输出**：`(n, k·f)` 矩阵，k 是边类型数——每个节点 k 段，各段对应一种关系类型。

**可调参数**：
- 真实异质 GNN 里，每类边会先过**各自的变换矩阵 $W_t$**（再拼接或求和）——这就是 HetGNN（§7.6.3）的核心。
- 可以只取某几类边（`mats` 过滤），观察哪类关系对任务最有用。

**对应数学**：主线 DL 桥接的"不同类型用不同变换"。这里是"分类型聚合"的最简形态——每类关系独立贡献，再拼装。

---

### 步骤 3：主流程

```python
H = np.eye(len(nodes))
agg = aggregate_by_type(mats, H)
print("'北京'的表示：", agg[nodes.index(("北京","L"))])
```

#### 主流程 —— 异质表示的读数

**操作**：`H = np.eye(n)` 用独热当初始特征（每个节点只"认识"自己），这样聚合后的表示直接反映"每类边把信息传到哪"。看"北京"一行：`[1, 0, 1]` = 位于(1 个宾语) + 任职(0) + 距离(1 个宾语)。

**输入**：矩阵与节点。

**输出**：每类聚合的拼接。

**可调参数**：换节点看不同表示；把 `H` 换成真实特征（如"张伟"的属性向量），聚合就会混入属性信息——这就是真实 GNN 的前向。

**对应数学**：异质消息传递的一次前向。`[1,0,1]` 直观展示"三类关系分账"。

## 改个数字试试

### 实验 A：把三类边混成一张矩阵——信息丢失

```python
mega = sum(mats.values())                     # 三种关系叠加成一张"混合"矩阵
print("混合聚合 '北京'：", (mega @ H)[nodes.index(("北京","L"))])
```

输出：

```
混合聚合 '北京'： [2. 0. 1.]
```

混成一张矩阵后，北京的表示变成 `[2, 0, 1]`——**"位于中国"和"距离上海"两个事实被加在一起**，你再也分不清"北京与中国的关系"和"北京与上海的关系"类型。分类型聚合（`[1,0,1]`）保留了"这是两种不同的关系"，混合聚合把它们压成一个总数。**这就是异质图 GNN 坚持分类型的根本原因**：类型是语义，不能混。

### 实验 B：给"距离"边加权重

把 `("北京","距离","上海")` 换成带权三元组（200 公里），`build_hetero` 里 `1.0` 换成 `200.0`。北京的"距离"分量从 1 变 200——**权重把"有连接"升级成"连接多强"**。这就是"加权异质图"的三种多样性叠加：有方向、有类型、有强度。

**呼应主线**：本实验用三张邻接矩阵证明"图的灵活"——权重、方向、异质三种多样性可以同时装进同一个 $G=(V,E)$ 骨架，分类型聚合让"关系类型"成为可学习的信号。灵活性不是口号，是 `mats` 这个 dict 里的三张矩阵。
