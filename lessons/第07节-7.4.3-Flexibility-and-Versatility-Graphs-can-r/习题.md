# §7.4.3 灵活与多才 —— 习题

主线讲了图的三种"多才"：权重（强度）、方向（单向）、异质（类型），以及它们可以组合。下面三组习题检验你是否能为不同的数据选对"图的穿法"。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：以下哪种关系**用不着**方向？

- A. 网页 A 链接到网页 B
- B. 城市之间的双向公路
- C. 论文 A 引用论文 B
- D. 用户 A 关注用户 B

**解答**：B。

**思路点拨**：双向公路，A 到 B 能走、B 到 A 也能走，方向是冗余信息（无向边即可）。A、C、D 都是天然单向（链接、引用、关注）。判别法还是那句：交换两端，关系变不变。常见错选是 D——关注恰恰是单向的典型。

### 题 2（判断）：异质图"异质"在什么意义上？一张图可以同时是"加权+有向+异质"吗？

**解答**：异质指**节点和边有不同类型**（如"人/地点/机构"节点、"位于/任职/距离"边）。可以同时是加权+有向+异质——例如"张伟 →（权重 0.8，任职）→ 清大"既带方向、又带权重、又属于"任职"类型。三种多样性是**正交的装法**，可以任意组合。

**思路点拨**：关键是"正交"——方向、权重、类型是三个独立维度，互不排斥。常见错误是以为异质图只指"节点类型不同"，忽略了"边类型不同"也是异质。加分点：指出"每类边可以有自己的权重"。

### 题 3（简答）：图很灵活，是不是所有数据都该建模成图？为什么？

**解答**：不是。图擅长表达"关系多样性"（强度、方向、类型），但不擅长表达"连续场"（流体、电磁）或"高维格点"（完整图像语义）。而且"装成什么样的图"（加权吗？有向吗？异质吗？）本身就是建模决策——选错了算法再强也没用。**灵活性是"关系类型的多样性"，不是"所有数据类型"。**

**思路点拨**：这是主线边界声明的直考。答题要点：区分"关系的灵活性"与"数据的万能性"。常见错误是"图很灵活 → 图适合一切"。记忆锚点：图装关系，不装连续场。

## 二、计算实践

### 题 1（手算：为三类数据选"穿法"）

对以下三类数据，分别回答：需要方向吗？需要权重吗？需要异质吗？

(a) 城市公路网（有里程，双向）
(b) 论文引用网（引用单向，无强度）
(c) 电商推荐（用户、商品两类节点，边是"购买"）

**解答**：

(a) 方向：不需要（双向）。权重：需要（里程/耗时）。异质：不需要（全是城市）。
(b) 方向：需要（引用单向）。权重：可选（一般不加）。异质：不需要。
(c) 方向：需要（用户→商品是单向的"购买"，商品不"购买"用户）。权重：可选（购买次数/金额）。异质：需要（用户 vs 商品是两类节点）。

**思路点拨**：这是"为数据选图穿法"的实战。判别方向用"交换两端变不变"，判别权重用"强度是不是信息"，判别异质用"节点/边是不是有多类"。常见错误是(c)里说"不需要方向"——其实购买关系是单向的，二部图的边天生有方向性（除非你只关心"有无交互"）。

### 题 2（手算 + NumPy：混合矩阵 vs 分类型矩阵）

图：节点 北京、上海、中国；边："位于"北京→中国、"距离"北京→上海（权重 200）。

(a) 分类型聚合后，北京的表示是什么（位于/距离 两段）？
(b) 若把两类边混成一张矩阵再聚合，北京的表示是什么？丢失了什么？

**解答**：

(a) 独热初始特征下：位于段 = [0,0,1]（北京→中国），距离段 = [0,200,0]（北京→上海）。分类型表示 = 两段拼接，语义清晰：一段是"位于关系"，一段是"距离关系"。

(b) 混合矩阵 = 位于矩阵 + 距离矩阵，北京行 = [0, 200, 1]——"中国(位于)"和"上海(距离200)"被加在一起，**丢失了"这是两种不同类型的关系"**。你无法再区分"北京位于中国"和"北京距上海 200km"这两件不同性质的事。

**NumPy 验证**：
```python
import numpy as np
idx = {"北京":0, "上海":1, "中国":2}
m_locate = np.zeros((3,3)); m_locate[idx["北京"], idx["中国"]] = 1
m_dist   = np.zeros((3,3)); m_dist[idx["北京"], idx["上海"]] = 200
H = np.eye(3)
print("位于段：", (m_locate @ H)[0])   # [0. 0. 1.]
print("距离段：", (m_dist @ H)[0])     # [0. 200. 0.]
print("混合：  ", ((m_locate+m_dist) @ H)[0])  # [0. 200. 1.]
```
```
位于段： [0. 0. 1.]
距离段： [0. 200. 0.]
混合：   [0. 200. 1.]
```

**思路点拨**：这是《代码.md》实验 A 的手算版。核心教训：**混类型 = 把"关系种类"这个语义加没了**。异质 GNN 坚持分类型的根本原因就在这里。常见错误是觉得"反正是求和，混起来也无妨"——混起来的是数字，丢的是类型语义。

## 三、DL 延伸

### 题 1（场景设计）：给推荐系统设计异质图

一个电商推荐系统，要同时利用"用户–商品–商家"三类节点和"购买/收藏/评价/隶属"四类边。请设计：(a) 哪些边是有向的？(b) 哪些边该加权？(c) 为什么异质 GNN 比"把边全混起来"更合理？

**解答**：(a) 用户→商品（购买/收藏）是单向的；商品→商家（隶属）也单向；评价可视为用户→商品带权。若只关心"有无交互"也可无向化，但"购买"的语义方向是用户到商品。(b) 购买次数、收藏时长、评价星级都可以做权重——"买了 1 次"与"买了 30 次"强度不同。(c) 异质 GNN 每类边单独变换（$W_{购买} \neq W_{收藏} \neq W_{隶属}$），因为"购买"与"收藏"携带完全不同的语义——混成一张矩阵会让"购买"和"收藏"被当成同一种关系，损失区分度。

**思路点拨**：答题锚点是"**每类边 = 独立语义 = 独立参数**"。加分点：指出"用户–商品二部图"与"商品–商家隶属图"是两个同质子图，异质图把它们缝合在一起。常见错误是把所有边混成一个无类型矩阵。

### 题 2（概念连线）：R-GCN 为什么为每种关系准备一个矩阵？

教材提到关系图卷积（R-GCN）处理知识图谱。请解释：知识图谱的三元组（主语, 关系, 宾语）如何对应 §7.3 的消息传递，为什么"关系类型"要进参数而不进数据？

**解答**：知识图谱每条三元组 (s, r, o) 就是一条有向边 s →(r)→ o，关系 r 是边的"类型"。R-GCN 的更新式 $h_v^{(k+1)} = \sigma\big(\sum_{r}\sum_{u\in\mathcal{N}_r(v)} W_r h_u^{(k)}\big)$ 按关系 r **各用一张权重矩阵 $W_r$**——"位于"关系的变换和"任职"关系的变换是两套参数。关系类型进参数（$W_r$）而非进数据，是因为：类型是**语义通道**，不同语义需要不同的"如何从邻居取信息"的方式；若把类型当作普通特征混进数据，模型无法区分"北京位于中国"与"张伟任职清大"是不同性质的证据。

**思路点拨**：这道题把 §7.4.3 的异质、§7.3 的消息传递、§7.6.3 的 HetGNN 串成一条线。核心一句：**关系类型 = 语义 = 独立的变换参数**。常见错误是只说"类型不同要分开"，没点出"分开的方式是每类一套 $W_r$"。
