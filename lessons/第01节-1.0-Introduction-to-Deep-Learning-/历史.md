# 历史：地图先于城市——深度学习的数学从何而来

## 2012 年秋天，多伦多，一间塞满显卡的实验室

深夜。机器在响——不是服务器那种温和的风扇声，而是一台塞进桌下的游戏显卡，被拽着超频运转，发出像是小型空调的轰鸣。

三个年轻人守在它旁边。房间里堆着泡面盒，墙上是手写的进度表。他们是多伦多大学 Hinton 实验室的学生：Alex Krizhevsky、Ilya Sutskever，以及他们的导师 Geoffrey Hinton。

他们做了一件当时整个领域都觉得徒劳的事：参加 ImageNet——一百多万张照片，一千个类别，全世界最权威的图像识别比赛。而他们想用的工具，是被主流冷落了二十年的"神经网络"。

主流早就判了它死刑。上世纪八十年代它还风光过，九十年代就衰落了：网络一深就失灵，学不动，还慢。学界转向了"支持向量机"这种漂亮而浅薄的工具，神经网络被放进了学术的仓库。你很难说服任何一个顶刊审稿人：这东西值得再试一次。

这三个年轻人偏偏要试。而且他们要试的方向更疯狂——不是把网络做大一点点，是把它做得**深**。八层。这在当时几乎等于异端：越深的网络越难训练，这是人人皆知的常识。

## 撞墙

把网络加深，遇到的第一堵墙，是**计算**。八层网络里埋着几千万个可调的数字，每一张图从输入走到输出，要经过几千亿次乘加运算。光一个前向，就能把一台普通电脑拖到崩溃。

第二堵墙更狠，叫**训练不动**。网络不是摆设，它得"学"。学意味着：每一轮，要算出"哪几个数字该往哪个方向调、调多少"。这在浅层网络里是小事，在深层网络里，误差信号要一层一层往回传——传过八层，传到第一层时，信号已经弱到几乎听不见了。人人知道要调，可没人知道在这么深的地方怎么调。

第三堵墙，是**勇气**。整个领域都说过"此路不通"。你要证明的不是一个技术细节，而是把一块被埋了二十年的招牌重新挂起来。

你几乎能看见那个深夜的实验室。屏幕上，损失曲线趴着不动，像一条死蛇。泡面凉了。机器还在响。三个年轻人盯着那条不动的曲线——所有现成的工具都试过了，都不行。差的那一点，深藏在"网络如何学习"这件事的本质里，藏在没有人愿意重新翻出来的古老文献里。

## 翻旧书的人

然后他们做了一件在今天看来理所当然、在当时却几乎是考古学的事：**回头去翻数学的旧书。**

他们翻到的第一样东西，是"一步一步往山谷最深处走"的老法子——向着脚下最陡的坡迈步，重复千万次。这个念头最早要追溯到 1847 年，法国数学家柯西（Cauchy）写的一篇论文，距今一百六十多年，那时候还没有"计算机"这个词。

他们翻到的第二样东西，是"把误差一层层传回去"的规则——每一层都知道自己该为错误负多少责，把它传给自己下面的层。这个想法在 1986 年就有人系统地写过，被埋进故纸堆里，同样没人再提起。

他们翻到的第三样东西，是整个工具箱里最基础的：**用"数阵"表示数据、用"数阵的乘法"表示变换**。这是 19 世纪就建好的语言，比神经网络这个词早了一百多年。

没有一件是新的。没有一件是"为深度学习发明的"。它们全是数学里搁置多年的存货——柯西在下坡，高斯在给误差称重，十九世纪的一群数学家在建一座语言的城。这座城市不是为了神经网络而建的，它甚至不知道神经网络会来。

但这一刻，它等到了它的住客。

Alex 把游戏显卡用了起来——几千万次乘加运算被并排丢进显卡的数百个计算核心，一块显卡顶几十块 CPU。机器轰鸣。损失曲线开始下降。先是一条死蛇，然后活过来，然后以近乎垂直的角度往下扎。

2012 年，这个叫 AlexNet 的网络，以巨大优势碾压了 ImageNet 的所有对手。神经网络复活了。深度学习这个名称，从这一天开始被整个世界使用。

## 五年后：一切变成数阵的乘法

城市建成了地基，但还只是一小片城区。真正让整座城市——十二个数学街区——全部亮起灯的时刻，在五年之后。

2017 年，一篇标题朴素得近乎挑衅的论文在谷歌发表：《Attention Is All You Need》，注意力机制就是你所需要的一切。它的作者给它起名 Transformer，并且说了一件石破天惊的事：

我们不再需要一层层"加工图像"的专门结构。序列里任意两个词之间的关系，可以用一个极其朴素的数学动作捕捉——**把两个数阵相乘，看看它们多像**。你想知道"我"和"你"在句子里谁该注意谁，就把它们各自的数字棒拉出来，算一个内积。所有词两两之间都算一遍，就得到了"谁在注意谁"的完整关系图。

一个模型，被简化到只剩"数阵乘法"这一种动作。复杂得令人叹为观止的机器翻译、文本生成、对话，全部从这一种动作里长出来。

柯西的陡坡、高斯的大数阵、19 世纪的线性语言、二十世纪的误差回传——那些从未见过神经网络的数学家，他们的工具被一座城市全部征用，在 2017 年的某个 GPU 集群上，合奏成同一个乐章。

## 留一扇门

故事讲到这里，你大概已经知道我们要做什么了。

2012 年的深夜，三个年轻人靠翻旧书闯过了那堵墙。但他们靠的是拼凑——知道这里要用哪个工具、那里要用哪个工具，却没有人把整座城市的地图画下来。2017 年之后，深度学习变成了真正的大城市，迷失在其中的人越来越多。

这本书就是那张地图。它不是发明任何一件工具的，它是把所有工具——线性代数的数阵、微积分的陡坡、概率的噪声、优化的步伐、信息论的尺度——画进同一张图里，标好它们的街区，标好它们之间的路。

而现在，我们要从城市的正门走进去。第一站是那座最古老、最坚硬、被整个城市踩在脚下的地基。它的名字，叫线性代数。
