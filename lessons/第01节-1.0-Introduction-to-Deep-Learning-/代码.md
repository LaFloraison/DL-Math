# 第01节 · 深度学习数学导论 — 代码验证

> 把这个脚本复制到任意 Python 环境，`python run.py`。没有一行黑盒——每个操作都是数学的直接翻译。试着改学习率从 0.5 到 100，看 loss 是收敛还是爆炸。

---

## 完整代码

```python
import numpy as np

# ═══ 准备数据 ═══
X   = np.random.randn(64, 10)          # 输入：64个样本，每个10维向量
y   = np.random.randint(0, 3, (64,))   # 真实标签：0、1、2 之一

# ═══ 准备参数 ═══
W1  = np.random.randn(10, 20) * 0.01   # 第1层权重：10→20
b1  = np.zeros(20)                      # 第1层偏置
W2  = np.random.randn(20, 3)  * 0.01   # 第2层权重：20→3
b2  = np.zeros(3)                       # 第2层偏置

# ═══ 正向传播 ═══
Z1  = X @ W1 + b1                       # 线性变换
A1  = np.maximum(0, Z1)                 # ReLU 激活
Z2  = A1 @ W2 + b2                      # 线性变换 → logits

# ═══ Softmax：logits → 概率 ═══
expZ   = np.exp(Z2 - Z2.max(axis=1, keepdims=True))
probs  = expZ / expZ.sum(axis=1, keepdims=True)

# ═══ 交叉熵损失 ═══
loss = -np.mean(np.log(probs[np.arange(64), y] + 1e-8))

# ═══ 一步梯度下降 ═══
probs[np.arange(64), y] -= 1            # softmax+交叉熵的联合梯度
grad_W2 = A1.T @ probs / 64             # ∂loss/∂W2（链式法则）
grad_b2 = probs.mean(axis=0)            # ∂loss/∂b2

lr = 0.5                                # 学习率
W2 -= lr * grad_W2                      # 沿负梯度方向更新 W2
b2 -= lr * grad_b2                      # 沿负梯度方向更新 b2

print(f"Loss: {loss:.4f}")
```

运行输出示例：

```
Loss: 1.1028
```

## 分步讲解

---

### 步骤 1：准备数据 —— $X$ 和 $y$

```python
X   = np.random.randn(64, 10)          # 输入：64个样本，每个10维向量
y   = np.random.randint(0, 3, (64,))   # 真实标签：0、1、2 之一
```

**做什么**：生成模拟的初始数据。输入特征 $X$，真实标签 $y$。

---

#### `np.random.randn(64, 10)` —— 生成输入特征矩阵 $X$

```python
X   = np.random.randn(64, 10)
```

**操作**：从标准正态分布 $\mathcal{N}(0, 1)$ 中随机采样，填满一个形状为 $(64, 10)$ 的数组。每个位置的数字是独立抽取的——均值 0，标准差 1，大约 68% 的数字落在 $[-1, 1]$ 之间。

**输入**：无——这一步是创造数据，不从别处接收数据。

**输出**：形状 $(64, 10)$ 的二维数组（矩阵）。64 行 = 64 个样本，10 列 = 每个样本有 10 个特征。$X[0, 3]$ 是第 0 个样本的第 3 个特征值。

**可调参数**：

- **第 1 个参数 `64`**：行数，即样本数量。深度学习中叫 batch size。改成 128 就是 128 个样本，改成 1 就是单样本。样本越多 → 梯度估计越稳定，但计算越慢。

- **第 2 个参数 `10`**：列数，即每个样本的特征维度。这是由你的数据决定的——手头有多少个特征就是多少。在真实场景中，一张 $224 \times 224$ 的 RGB 图像展开成一维就是 $224 \times 224 \times 3 = 150528$ 维，而不是 10。

- **第 3 个参数**：可以有。`np.random.randn(64, 10, 3)` 会生成形状 $(64, 10, 3)$ 的**三维数组**（张量）。64 个样本，每个样本是 $10 \times 3$ 的矩阵。可以继续加——`randn(32, 3, 224, 224)` 生成四维数组，正是图像数据的标准形状：batch × 通道 × 高 × 宽。理论上可以加到任意维度。

---

#### `np.random.randint(0, 3, (64,))` —— 生成标签 $y$

```python
y   = np.random.randint(0, 3, (64,))
```

**操作**：从区间 $[0, 3)$（即 $\{0, 1, 2\}$）中均匀随机抽取整数，填满形状为 $(64,)$ 的数组。每个标签独立抽取，0、1、2 出现的概率大致相等（各约 1/3）。

**输入**：无。

**输出**：形状 $(64,)$ 的**一维数组**（向量）。长度为 64，每个元素是 0、1、2 之一。`y[5]` 是第 5 个样本的真实类别——比如 `y[5] = 2` 表示"第 5 个样本属于类别 2"。

**可调参数**：

- **第 1 个参数 `0`（`low`）**：随机整数的最小值（包含）。改成 1 就是从 1 开始抽取。

- **第 2 个参数 `3`（`high`）**：随机整数的最大值（**不包含**）。所以 `randint(0, 3)` 只抽取 $\{0, 1, 2\}$。二分类问题时写成 `(0, 2)`——只抽 0 和 1。100 分类问题时写成 `(0, 100)`。

- **第 3 个参数 `(64,)`（`size`）**：输出数组的**形状 (shape)**。

  | 写法 | 含义 | 举例 |
  |------|------|------|
  | `(64,)` | 一维数组，长度 64 | `[2, 0, 1, 0, ...]` |
  | `(64, 1)` | 二维数组，64 行 1 列 | `[[2], [0], [1], ...]` |
  | `(64, 10)` | 二维数组，64 行 10 列 | 每行 10 个标签 |
  | `(2, 64, 10)` | 三维数组，2 × 64 × 10 | 两个 batch，每 batch 64 样本，每样本 10 标签 |

  关键区分：`(64,)` 和 `(64, 1)` 在 NumPy 里是**不同形状**。前者是一维向量（rank-1），后者是二维矩阵（rank-2）。神经网络中 batch 的标签一般用 `(64,)` 而不用 `(64, 1)`，因为交叉熵函数期望一维的标签向量。

- **第 4 个参数**：`randint` 还有一个 `dtype` 参数（如 `dtype=np.int64`），控制输出整数的精度。一般不传，默认 `np.int64` 足够用。

---

**对应数学**：$X$ 是**矩阵**——线性代数中最基本的对象。$X$ 的第 $i$ 行第 $j$ 列是第 $i$ 个样本的第 $j$ 个特征。$y$ 是**标签向量**——概率论中交叉熵公式里的 $y_{i,j}$（one-hot 形式）可以用单个整数 $y_i$ 等价表示。

---

### 步骤 2：准备参数 —— $W_1, \mathbf{b}_1, W_2, \mathbf{b}_2$

```python
W1  = np.random.randn(10, 20) * 0.01   # 第1层权重：10→20
b1  = np.zeros(20)                      # 第1层偏置
W2  = np.random.randn(20, 3)  * 0.01   # 第2层权重：20→3
b2  = np.zeros(3)                       # 第2层偏置
```

**做什么**：初始化网络的权重矩阵和偏置向量。这些就是模型要通过训练来"学习"的东西。初始时随机生成——训练过程中，每一步梯度下降都会更新它们。

---

#### `np.random.randn(10, 20) * 0.01` —— 权重初始化

```python
W1  = np.random.randn(10, 20) * 0.01
W2  = np.random.randn(20, 3)  * 0.01
```

**操作**：先和步骤 1 一样从 $\mathcal{N}(0, 1)$ 采样填满一个矩阵，然后每个元素乘以 0.01。效果：把标准差从 1.0 缩小到 0.01——值集中在 $[-0.03, 0.03]$ 之间。

**输入**：无。

**输出**：
- $W_1$：形状 $(10, 20)$。10 行 = 10 个输入特征，20 列 = 20 个输出特征。$W_1[2, 5]$ 表示"第 2 个输入特征对第 5 个隐藏单元的贡献权重"。
- $W_2$：形状 $(20, 3)$。20 个隐藏单元 → 3 个输出类别。

**可调参数**：

- **`randn` 的前两个参数**：和步骤 1 完全相同——先传行数再传列数，可以有第三、第四参数变成高维张量。

- **`* 0.01`（缩放因子 / scale）**：控制初始权重的幅度。这是深度学习中最关键的初始化细节之一：
  - 太小（`* 0.0001`）→ 信号在层间传递时迅速衰减到零 → **梯度消失**
  - 太大（`* 1.0`）→ 信号爆炸 → **梯度爆炸**
  - 0.01 是一个经验安全值，适合浅层网络。实际中常用 Xavier 初始化或 He 初始化——它们根据输入/输出维度自动计算缩放因子，比固定 0.01 更科学

---

#### `np.zeros(20)` —— 偏置初始化

```python
b1  = np.zeros(20)
b2  = np.zeros(3)
```

**操作**：生成全是 0 的数组，形状由传入的参数决定。

**输入**：无。

**输出**：
- $\mathbf{b}_1$：形状 $(20,)$。给隐藏层 20 个维度各自一个偏置（初始为 0，训练中会被更新）。
- $\mathbf{b}_2$：形状 $(3,)$。给 3 个类别各自一个偏置。

**可调参数**：

- **第 1 个参数**：数组的形状。可以传一个整数 `20`（=`(20,)` 一维），也可以传元组 `(2, 3)` 得到全零的 $2 \times 3$ 矩阵。`np.zeros((64, 10))` 生成全零的 $64 \times 10$ 矩阵——形状规则和 `randn` 完全一致。

- **为什么偏置初始化为 0 没问题？** 因为权重 $W$ 是随机初始化的——每个隐藏单元收到的输入信号已经不同了。偏置只是给这个已经不同的信号加一个统一偏移，初始为 0 不影响对称性破坏。如果权重也是全零初始化——那每个隐藏单元算出来的值完全一样，反向传播时梯度也完全一样，所有单元学到的特征一模一样——等于只学了一个单元。

---

**对应数学**：$W_1$ 是从向量空间 $\mathbb{R}^{10}$ 到 $\mathbb{R}^{20}$ 的**线性映射**在标准基下的矩阵表示。它不是"一段代码"——它是一个线性变换，把每个 10 维输入向量旋转、缩放、投影到 20 维空间。

---

### 步骤 3：第一层线性变换 —— $Z_1 = X W_1 + \mathbf{b}_1$

```python
Z1  = X @ W1 + b1
```

**做什么**：把 64 个样本各自从 10 维空间映射到 20 维空间。这是网络对输入做的第一次"理解"。

---

#### `X @ W1` —— 矩阵乘法

```python
X @ W1
```

**操作**：`@` 是 NumPy 的矩阵乘法运算符。计算规则：$X$ 的第 $i$ 行与 $W_1$ 的第 $j$ 列做内积（对应元素相乘后求和），结果放在第 $i$ 行第 $j$ 列。做完 $64 \times 20 = 1280$ 次内积。

**输入**：
- $X$：形状 $(64, 10)$——64 个样本，10 个特征
- $W_1$：形状 $(10, 20)$——10 个输入特征，20 个输出特征

**形状对齐规则**：$X$ 的列数（10）必须等于 $W_1$ 的行数（10）。对齐后，结果形状 = $(X\text{的行数}, W_1\text{的列数}) = (64, 20)$。如果列数不匹配——比如 $X$ 是 $(64, 10)$ 而 $W_1$ 是 $(12, 20)$——NumPy 会直接报错 `matmul: dimension mismatch`。

**输出**：形状 $(64, 20)$ 的矩阵。第 $i$ 行第 $j$ 列的值 = 第 $i$ 个样本的 10 个特征与第 $j$ 个输出维度的权重做内积的结果。每个值衡量了"输入样本在该输出维度上的投影强度"。

**可调参数**：无——`@` 是一个运算符，不接受额外参数。矩阵乘法的行为完全由两个输入的形状决定。

---

#### `+ b1` —— 广播加法

```python
+ b1
```

**操作**：$\mathbf{b}_1$ 的形状是 $(20,)$，$XW_1$ 的形状是 $(64, 20)$。NumPy 的**广播 (broadcasting)** 机制自动把 $(20,)$ 扩展为 $(64, 20)$——相当于把同一个长度为 20 的向量加到 64 行的每一行上。

**输入**：
- 左操作数：形状 $(64, 20)$ 的矩阵
- 右操作数 $\mathbf{b}_1$：形状 $(20,)$ 的向量

**广播规则**：从最后一维往前对齐。$(64, 20)$ 和 $(20,)$ 的最后一维都是 20——匹配。缺少的维度（64）自动复制。如果形状是 $(20,)$ 和 $(64, 10)$——最后一维 20 ≠ 10，报错。

**输出**：形状 $(64, 20)$。每一行的 20 个数字各自加上了同样的偏置。

**可调参数**：无——这是一个逐元素加法。

---

**对应数学**：$Z_1 = XW_1 + \mathbf{b}_1$ 是**仿射变换**——线性变换加平移。$W_1$ 负责旋转和缩放，$\mathbf{b}_1$ 负责把整个变换后的空间平行移动。

---

### 步骤 4：ReLU 激活 —— $A_1 = \max(0, Z_1)$

```python
A1  = np.maximum(0, Z1)
```

**做什么**：把 $Z_1$ 中所有负数变成 0。这是引入**非线性**的关键步骤。

---

#### `np.maximum(0, Z1)` —— 逐元素取最大值

```python
np.maximum(0, Z1)
```

**操作**：`np.maximum(a, b)` 逐元素比较两个数组，每个位置取较大的那个数。这里 `a=0`（标量）被广播到和 $Z_1$ 同样的形状 $(64, 20)$，然后每个位置比较：大于 0 的值原样保留，小于 0 的值变成 0。

**输入**：
- 第一个参数 `0`：标量，广播到 $(64, 20)$
- 第二个参数 $Z_1$：形状 $(64, 20)$，值是任意实数

**输出**：形状 $(64, 20)$。正值原样保留，负值截断为 0。形状和输入完全一致——ReLU 不改变维度，只改变值。

**可调参数**：无——`np.maximum` 只接受两个要比较的数组。

**注意**：`np.maximum`（逐元素）和 `np.max`（沿某个轴取最大值，返回标量或降维数组）是不同的函数。这里必须用 `maximum`（五个字母），用 `max`（三个字母）会把整个矩阵压缩成一个标量。

---

**对应数学**：$\max(0, x)$ 是深度学习中最常用的非线性激活函数。**为什么非线性不可或缺？** 因为两层线性变换的复合依然是线性变换——$W_2(W_1 X) = (W_2 W_1)X$，两层等价于一层。ReLU 打破了这条链——让 100 层网络和 1 层网络有了本质区别。

---

### 步骤 5：第二层线性变换 —— $Z_2 = A_1 W_2 + \mathbf{b}_2$

```python
Z2  = A1 @ W2 + b2
```

**做什么**：把 20 维的隐藏表示映射到 3 维——每个类别一个原始分数。

**操作**：和步骤 3 完全一样的数学操作——矩阵乘法 + 广播加法。

**输入**：
- $A_1$：$(64, 20)$——ReLU 处理后的隐藏表示（没有负数）
- $W_2$：$(20, 3)$，$\mathbf{b}_2$：$(3,)$

**输出**：$Z_2$，形状 $(64, 3)$。每行 3 个数字叫 **logits**（原始分数）——它们还不是概率。logit 可以大于 1，可以是负数。logit 的大小只表示"这个类别的相对证据强度"——logit 越大，该类别越可能。但 3 个 logit 的和不需要等于 1。把 logit 变成概率需要下一步的 Softmax。

**对应数学**：仿射变换，输出维度 = 类别数。$Z_2$ 的第 $j$ 列是"模型认为样本属于类别 $j$ 的原始证据"。

---

### 步骤 6：Softmax —— logits → 概率

```python
expZ   = np.exp(Z2 - Z2.max(axis=1, keepdims=True))
probs  = expZ / expZ.sum(axis=1, keepdims=True)
```

**做什么**：把没有约束的 logit 变成 3 个正数，且和为 1——一个合法的概率分布。

---

#### `Z2.max(axis=1, keepdims=True)` —— 每行取最大值

```python
Z2.max(axis=1, keepdims=True)
```

**操作**：沿 `axis=1`（列方向）取每行的最大值。`keepdims=True` 保持维度——输出形状 $(64, 1)$ 而不是 $(64,)$，方便后续广播减法。

**输入**：$Z_2$，$(64, 3)$。

**输出**：形状 $(64, 1)$。每行是这一行 3 个 logit 中的最大值。

**意义**：这是**数值稳定性技巧**——防止 $e^{100}$ 溢出成 `inf`。因为 softmax 的分子分母同时除以 $e^{\max}$，数学结果不变。

---

#### `np.exp(Z2 - Z2.max(...))` —— 取指数

```python
np.exp(Z2 - Z2.max(axis=1, keepdims=True))
```

**操作**：$Z_2$ 每行减去该行最大值（让最大 logit 变成 0，其他变成负数），然后取 $e^x$。结果所有值在 $(0, 1]$ 之间。

**输入**：$Z_2$ 减去行最大值的结果，$(64, 3)$。

**输出**：`expZ`，$(64, 3)$。全是正数——$e^{-\infty} \to 0$，$e^0 = 1$。

---

#### `expZ.sum(axis=1, keepdims=True)` —— 每行求和

```python
expZ.sum(axis=1, keepdims=True)
```

**操作**：沿 `axis=1` 对每行的 3 个值求和。`keepdims=True` 使输出形状为 $(64, 1)$。

**输出**：形状 $(64, 1)$。每行是"该样本 3 个指数的总和"。

---

#### `expZ / expZ.sum(...)` —— 逐元素除法

```python
probs  = expZ / expZ.sum(axis=1, keepdims=True)
```

**操作**：$(64, 3) \div (64, 1)$——广播除法。每行的 3 个指数各自除以该行的指数总和。

**输出**：`probs`，形状 $(64, 3)$。每行 3 个正数，和为 1。现在可以读了——第 0 行第 1 列的 0.72 表示"模型认为第 0 个样本有 72% 的概率属于类别 1"。

---

**对应数学**：Softmax 函数 $\hat{y}_j = e^{z_j} / \sum_k e^{z_k}$。来自**概率论**中的玻尔兹曼分布——logit 越大的类别分到的概率越多。Softmax 不是唯一把实数映射到概率的方法，但它是梯度形式最简洁的方法。

---

### 步骤 7：交叉熵损失

```python
loss = -np.mean(np.log(probs[np.arange(64), y] + 1e-8))
```

**做什么**：用一个数字衡量"模型猜得有多不准"。

---

#### `probs[np.arange(64), y]` —— 花式索引取真实类别的概率

```python
probs[np.arange(64), y]
```

**操作**：`np.arange(64)` 生成 `[0, 1, 2, ..., 63]`。和 $y$ 配对——`(0, y[0]), (1, y[1]), ...`——从 `probs` 中取出每个样本在**真实类别**上的预测概率。

**输入**：`probs` $(64, 3)$，$y$ $(64,)$。

**输出**：形状 $(64,)$ 的向量。第 $i$ 个值 = 模型对第 $i$ 个样本的**真实类别**给出的概率。如果 `y[0] = 2`，那 `probs[0, 2]` 就被取出来——正是模型认为"第 0 个样本属于类别 2"的概率。

---

#### `np.log(...)` —— 取对数

```python
np.log(...)
```

**操作**：对取出的概率逐元素取自然对数 $\ln$。

**为什么取对数？** 信息论告诉我们——一个概率为 $p$ 的事件的"意外程度"是 $-\log p$。$p=1$ → 毫不意外 → $-\log(1) = 0$。$p=0.001$ → 极度意外 → $-\log(0.001) \approx 6.9$。

---

#### `np.mean(...)` —— 求平均

```python
-np.mean(...)
```

**操作**：把 64 个 $-\log(p)$ 加起来取平均。得到一个正数——交叉熵损失。

**输出**：一个标量（0 维）。值越小 → 模型对真实类别的预测概率越高 → 模型越好。

**`+ 1e-8`**：防止 $\log(0)$ 出现——当某个样本的真实类别概率恰好为 0 时，$\log(0) = -\infty$ 会导致整个程序崩溃。加上 $10^{-8}$ 把 0 变成 0.00000001，$\log(10^{-8}) \approx -18.4$——很大但不会崩溃。

---

**对应数学**：**信息论**中的交叉熵 $H(y, \hat{y}) = -\frac{1}{n}\sum_i \sum_j y_{i,j} \log \hat{y}_{i,j}$ 在 one-hot 标签下退化为 $-\frac{1}{n}\sum_i \log \hat{y}_{i, \text{true}}$。等价于**概率论**中的负对数似然——最小化交叉熵 = 最大化模型在给定数据下的似然。

---

### 步骤 8：一步梯度下降

```python
probs[np.arange(64), y] -= 1            # softmax+交叉熵的联合梯度
grad_W2 = A1.T @ probs / 64             # ∂loss/∂W2（链式法则）
grad_b2 = probs.mean(axis=0)            # ∂loss/∂b2

lr = 0.5                                # 学习率
W2 -= lr * grad_W2                      # 沿负梯度方向更新 W2
b2 -= lr * grad_b2                      # 沿负梯度方向更新 b2
```

**做什么**：计算 loss 对参数的梯度，然后沿负梯度方向更新参数。更新后再做正向传播，loss 会变小。

---

#### `probs[np.arange(64), y] -= 1` —— Softmax + 交叉熵的联合梯度

```python
probs[np.arange(64), y] -= 1
```

**操作**：对真实类别的预测概率减 1。这是 Softmax + 交叉熵在数学上联合求导的结果——梯度 = 预测概率分布 - one-hot 真实分布。推导在本书第三章（多元微积分）会详细展开。这里的操作等价于 `probs - y_onehot` 但更省内存——只修改真实类别位置的值。

**输入**：`probs`，$(64, 3)$。

**输出**：修改后的 `probs`，$(64, 3)$。真实类别位置的值变成了 $p-1$（负数），其他位置的值不变（仍为正数 $p$）。

---

#### `A1.T @ probs / 64` —— 链式法则计算 $\partial \text{loss} / \partial W_2$

```python
grad_W2 = A1.T @ probs / 64
```

**操作**：$A_1$ 的形状是 $(64, 20)$。`.T` 是转置——把 $(64, 20)$ 翻成 $(20, 64)$。然后矩阵乘法 $(20, 64) \times (64, 3) \to (20, 3)$，最后除以 64（样本数）取平均。

**链式法则在这里**：$\frac{\partial \text{loss}}{\partial W_2} = \frac{\partial \text{loss}}{\partial Z_2} \cdot \frac{\partial Z_2}{\partial W_2} = A_1^T \cdot (\text{预测} - \text{真实}) / n$。$A_1^T$ 来自"$Z_2 = A_1 W_2$ 对 $W_2$ 求导"这一步。

**输出**：`grad_W2`，形状 $(20, 3)$。和 $W_2$ 的形状完全一致——每个元素是 loss 对 $W_2$ 对应位置的偏导数。

---

#### `probs.mean(axis=0)` —— $\partial \text{loss} / \partial \mathbf{b}_2$

```python
grad_b2 = probs.mean(axis=0)
```

**操作**：沿 `axis=0`（行方向）对 64 个样本取平均。$(64, 3) \to (3,)$。

**输出**：`grad_b2`，形状 $(3,)$。和 $\mathbf{b}_2$ 形状一致。

---

#### `W2 -= lr * grad_W2` —— 梯度下降更新

```python
lr = 0.5                                # 学习率
W2 -= lr * grad_W2                      # 沿负梯度方向更新 W2
b2 -= lr * grad_b2                      # 沿负梯度方向更新 b2
```

**操作**：沿负梯度方向迈 `lr` 那么大的步长。`-=` 是减等——`W2 = W2 - lr * grad_W2`。

**可调参数**：

- **`lr`（学习率，learning rate）**：控制每一步更新多大。这是整个训练过程中**最重要的超参数**：
  - `lr = 0.001`：极小步，收敛慢但稳定
  - `lr = 0.5`：中等步，收敛较快
  - `lr = 100`：巨大步 → 参数疯狂震荡 → loss 爆炸
  - 试试改成 `lr = 100` 然后重新运行——看看 loss 是不是从一个正常值（~1.1）跳到了天文数字

- **为什么只更新 $W_2$ 和 $\mathbf{b}_2$，不更新 $W_1$ 和 $\mathbf{b}_1$？** 这个脚本只演示了一步梯度下降——为了代码简洁，只反向传播了最后一层。真实训练中梯度会通过链式法则继续传到第一层：$\frac{\partial \text{loss}}{\partial W_1} = \frac{\partial \text{loss}}{\partial Z_2} \cdot \frac{\partial Z_2}{\partial A_1} \cdot \frac{\partial A_1}{\partial Z_1} \cdot \frac{\partial Z_1}{\partial W_1}$。这将在第三章（多元微积分）和第四章（优化理论）中深入展开。

---

**对应数学**：**优化理论**中的梯度下降 $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$，其中 $\nabla L$ 由**多元微积分**的链式法则计算。梯度告诉你"往哪走 loss 升最快"（微积分），负号让你往反方向走（优化），学习率控制步长（优化）。

---

### 改个数字试试

把 `lr = 0.5` 改成 `lr = 100`，重新运行。你会看到类似：

```
Loss: 8347129472.3156
```

loss 从 1.1 跳到了 83 亿。这是因为步长太大——梯度下降"跨过了"最优解，反而冲到了参数空间里 loss 极高的区域。这不是代码 bug——这是**优化理论在直接对你说话**：步长选择决定了收敛还是发散。

现在改回来 `lr = 0.001`：

```
Loss: 1.0988
```

收敛了，但因为步长太小，loss 下降很慢——同样走一步，0.5 比 0.001 多降了 500 倍。

**这就是学数学的意义。** 你不是在"调参"——你是在和梯度下降的数学行为对话。
