# §1.0 深度学习数学导论 · 代码

主线里我们看见了那幅最核心的画面：一个训练步骤（前向 → 损失 → 反向 → 更新）里，全书的数学同时呼吸。这节代码，就是把那"三拍"亲手写一遍——用一个纯 NumPy 实现的两层小网络，跑完一个完整的训练步骤，并在每一拍上标出它属于哪一章的数学。

这不是教你写网络（那是后面每一章代码.md 的累积任务）。这是**全景图**：用十几行代码，让你亲眼看穿整本书的骨架。

需要的环境：Python 3.8+ 与 NumPy（`pip install numpy`）。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方（`SEED = 42` 固定，所以你的结果与这里**逐位一致**）。

```python
"""
第01节 代码.md：一次训练步骤里的整本书。
前向 -> 损失 -> 反向 -> 更新，全部用纯 NumPy 手写，每一步标注所属章节。
"""

import sys
try:
    sys.stdout.reconfigure(encoding="utf-8")   # 让 Windows 控制台正常显示中文
except Exception:
    pass

import numpy as np

D_IN = 3      # 输入特征数（第 2 章：数据表示）
D_HIDDEN = 4  # 隐藏层宽度
D_OUT = 2     # 输出类别数
B = 4         # 批量大小（一次喂进几个样本）
LR = 0.1      # 学习率（第 5 章：优化的步长）
SEED = 42     # 随机种子


def init_parameters(d_in, d_hidden, d_out, seed=SEED):
    """初始化两组参数 W1,b1,W2,b2：权重服从 N(0, 0.1^2) 的小随机数。"""
    rng = np.random.default_rng(seed)
    W1 = rng.normal(0.0, 0.1, size=(d_hidden, d_in))
    b1 = np.zeros(d_hidden)
    W2 = rng.normal(0.0, 0.1, size=(d_out, d_hidden))
    b2 = np.zeros(d_out)
    return {"W1": W1, "b1": b1, "W2": W2, "b2": b2}


def relu(z):
    """逐元素激活：max(0, z)，保留正值、清零负值。"""
    return np.maximum(z, 0.0)


def forward(X, params):
    """前向：两层线性变换 + 一次 ReLU 激活，返回 logits 与中间缓存。"""
    W1, b1, W2, b2 = params["W1"], params["b1"], params["W2"], params["b2"]
    Z1 = X @ W1.T + b1          # (B, D_HIDDEN)
    A1 = relu(Z1)               # (B, D_HIDDEN)
    Z2 = A1 @ W2.T + b2         # (B, D_OUT)
    cache = {"Z1": Z1, "A1": A1}
    return Z2, cache


def softmax(logits):
    """把任意 logits 归一化成和为 1 的概率分布（沿最后一维）。"""
    shifted = logits - logits.max(axis=-1, keepdims=True)
    exp = np.exp(shifted)
    return exp / exp.sum(axis=-1, keepdims=True)


def cross_entropy(logits, y):
    """交叉熵损失：-log P(y | x) 在批量上取平均。"""
    probs = softmax(logits)
    p_true = probs[np.arange(len(y)), y]
    return float(-np.log(p_true).mean())


def backward(X, y, params, cache):
    """反向：链式法则逐层回传梯度。"""
    W2 = params["W2"]
    Z1, A1 = cache["Z1"], cache["A1"]
    logits, _ = forward(X, params)
    probs = softmax(logits)
    one_hot = np.zeros_like(probs)
    one_hot[np.arange(len(y)), y] = 1.0
    dZ2 = (probs - one_hot) / len(y)          # (B, D_OUT)  softmax+CE 的梯度（含 1/B）
    dW2 = dZ2.T @ A1                          # (D_OUT, D_HIDDEN)
    db2 = dZ2.sum(axis=0)                     # (D_OUT,)
    dA1 = dZ2 @ W2                            # (B, D_HIDDEN)
    dZ1 = dA1 * (A1 > 0)                      # ReLU 导数
    dW1 = dZ1.T @ X                           # (D_HIDDEN, D_IN)
    db1 = dZ1.sum(axis=0)                     # (D_HIDDEN,)
    return {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}


def update(params, grads, lr=LR):
    """参数更新：theta <- theta - lr * grad。"""
    return {k: params[k] - lr * grads[k] for k in params}


def train_one_step(X, y, params, lr=LR):
    """编排一次完整训练步骤：前向 -> 损失 -> 反向 -> 更新，返回新旧损失。"""
    logits, cache = forward(X, params)
    loss_before = cross_entropy(logits, y)
    grads = backward(X, y, params, cache)
    new_params = update(params, grads, lr)
    logits_new, _ = forward(X, new_params)
    loss_after = cross_entropy(logits_new, y)
    return new_params, loss_before, loss_after


# ---------------- 主流程 ----------------
X = np.array([[0.5, -1.2, 0.3],
              [1.0, 0.4, -0.8],
              [-0.3, 0.7, 0.9],
              [0.8, -0.5, 0.2]])          # 形状 (4, 3)：4 个样本、3 个特征
y = np.array([0, 1, 1, 0])                 # 形状 (4,)：每个样本的类别

params = init_parameters(D_IN, D_HIDDEN, D_OUT)
logits, cache = forward(X, params)

print("logits 形状 (B, D_OUT) =", logits.shape)
print("W1 形状 (D_HIDDEN, D_IN) =", params["W1"].shape)
print("W2 形状 (D_OUT, D_HIDDEN) =", params["W2"].shape)

loss0 = cross_entropy(logits, y)
print("更新前 loss = %.8f" % loss0)

params, loss_before, loss_after = train_one_step(X, y, params)
print("train_one_step 报告的更新前 loss = %.8f" % loss_before)
print("更新后 loss = %.8f" % loss_after)
print("loss 下降量 = %.8f" % (loss_before - loss_after))
```

运行输出（`SEED=42`，结果完全可复现）：

```
logits 形状 (B, D_OUT) = (4, 2)
W1 形状 (D_HIDDEN, D_IN) = (4, 3)
W2 形状 (D_OUT, D_HIDDEN) = (2, 4)
更新前 loss = 0.68596922
train_one_step 报告的更新前 loss = 0.68596922
更新后 loss = 0.68492860
loss 下降量 = 0.00104062
```

看到了吗：一次更新之后，loss 从 0.68596922 降到了 0.68492860——这台随机初始化、什么都不会的小机器，**往正确的方向挪了一点**。就这一步里，线性代数（第 2 章）、多元微积分（第 3 章）、概率论（第 4 章）、优化理论（第 5 章）、信息论（第 6 章）全部在场。接下来逐函数拆开看。

## 层二：分步逐函数拆解

### 步骤 1：环境与参数表

```python
import sys
try:
    sys.stdout.reconfigure(encoding="utf-8")   # 让 Windows 控制台正常显示中文
except Exception:
    pass

import numpy as np

D_IN = 3      # 输入特征数（第 2 章：数据表示）
D_HIDDEN = 4  # 隐藏层宽度
D_OUT = 2     # 输出类别数
B = 4         # 批量大小（一次喂进几个样本）
LR = 0.1      # 学习率（第 5 章：优化的步长）
SEED = 42     # 随机种子
```

#### `sys.stdout.reconfigure(encoding="utf-8")` —— 让中文输出不被乱码

**操作**：把标准输出的编码改成 UTF-8。Windows 的 cmd/PowerShell 默认用 GBK 解码字节，而 Python 写中文时按 UTF-8 编码，两者错位就会出现乱码。这一行强制两边对齐。`try/except` 是因为某些环境（如旧的 Python 版本）没有 `reconfigure` 方法——没有就跳过，不影响数学。

**输入**：无输入。**输出**：无返回值，只改变后续 `print` 的编码行为。

**可调参数**：没有参数。这是纯环境配置，不是核心数学，你可以删掉它——只是 Windows 下中文可能显示成乱码。

#### 五个模块级常量 —— 实验的参数表

- `D_IN = 3`：每个样本有几个数字特征。对应主线里"猫的照片被翻译成一大堆数字"——这里是 3 个特征（你可以想象是"毛色深浅、耳朵长短、体重"三个数）。改成 5，整台机器就吃 5 维输入。
- `D_HIDDEN = 4`：隐藏层宽度——中间那层放多少个"神经元"。这是第 2 章矩阵的形状来源之一。改成 100，网络变宽、参数变多。
- `D_OUT = 2`：输出类别数——这里是二分类（0 和 1）。softmax 会输出 2 个分数。
- `B = 4`：批量大小，一次喂进几个样本。它决定了所有中间矩阵的第一维。
- `LR = 0.1`：学习率，第 5 章优化理论的步长 $\eta$。改大（如 1.0）步子太大可能震荡、损失不降反升；改小（如 0.001）步子太慢，一步之后 loss 几乎不动。
- `SEED = 42`：随机种子。决定 `init_parameters` 里那一串"随机"权重是哪个序列。固定它，每次运行结果逐位一致。

**对应数学**：这一步把主线定义块里的符号落到常量上：$\theta$（权重）← 权重张量，$N$（样本数）← 这里用批量 $B=4$，$\eta$（学习率）← `LR`。

### 步骤 2：初始化参数 —— `init_parameters(d_in, d_hidden, d_out, seed)`

```python
def init_parameters(d_in, d_hidden, d_out, seed=SEED):
    rng = np.random.default_rng(seed)
    W1 = rng.normal(0.0, 0.1, size=(d_hidden, d_in))
    b1 = np.zeros(d_hidden)
    W2 = rng.normal(0.0, 0.1, size=(d_out, d_hidden))
    b2 = np.zeros(d_out)
    return {"W1": W1, "b1": b1, "W2": W2, "b2": b2}
```

#### `init_parameters(d_in, d_hidden, d_out, seed)` —— 造一组"什么都不会"的初始参数

**操作**：用 `np.random.default_rng(seed)` 造一个随机数发生器，然后从正态分布 $N(0, 0.1^2)$ 里抽两组权重，把两组偏置初始化为全零。权重取小随机数是为了"打破对称"——如果所有权重都相等，反向传播会算出相同的梯度，网络就永远学不出区分度；取很小的幅度（标准差 0.1）是为了让初期的 logits 落在 softmax 的敏感区（见步骤 5）。返回值是一个字典，键是名字，值是 NumPy 数组。

**对应数学**：这是主线定义块里那个 $\theta$（参数）的**初始化**。训练从 $\theta$ 出发，最后停在 $\theta^{*}$。初始点怎么选是第 2 章 §2.5.3.5（Initialization）的正式课题——现在只需知道"小随机数 + 零偏置"是一套极简的默认配方。

**输入**：
- `d_in`：整数，输入特征数（就是 `D_IN`）。
- `d_hidden`：整数，隐藏层宽度。
- `d_out`：整数，输出类别数。
- `seed`：整数（可省略，默认 `SEED = 42`），随机种子。

**输出**：一个字典，含四个数组：
- `W1`：**形状 `(d_hidden, d_in)` = `(4, 3)`**——二维矩阵。第 $j$ 行是第 $j$ 个隐藏神经元对 3 个输入特征各自乘以的权重。
- `b1`：**形状 `(d_hidden,)` = `(4,)`**——一维数组，每个隐藏神经元的偏置。
- `W2`：**形状 `(d_out, d_hidden)` = `(2, 4)`**——二维矩阵。第 $c$ 行是第 $c$ 个输出类对 4 个隐藏激活各自乘以的权重。
- `b2`：**形状 `(d_out,)` = `(2,)`**——一维数组，每个输出类的偏置。

**可调参数**：
- `seed`：改成别的整数（如 7），会得到另一套随机权重，但统计性质（均值 0、标准差 0.1）不变；传 `None` 则每次运行都不同（用系统熵播种），无法复现。
- 还能不能有第五个参数？可以——比如 `std`：把 `rng.normal(0.0, 0.1, ...)` 里的 `0.1` 提成参数 `std`。传 `0.5`，初始权重更大，初期 loss 会更接近 $\ln D_{OUT}$（随机猜的水平）；传 `0.01`，初始权重很小，初期 loss 贴近均匀分布的交叉熵。更高级的初始化（Xavier、He）会按输入维度调整这个标准差，那是第 2 章的内容。

### 步骤 3：激活 —— `relu(z)`

```python
def relu(z):
    return np.maximum(z, 0.0)
```

#### `relu(z)` —— 把负值压成零的非线性门

**操作**：`np.maximum(z, 0.0)` 逐元素比较，每个元素取 $\max(z_i, 0)$。负值全部变成 0，正值原样保留。

**对应数学**：这就是激活函数 (activation function) 的极简实现。它是神经网络**必须有非线性**的原因：如果每层都只做线性变换，那么"两层线性变换"本质上还是一层线性变换（矩阵乘法对矩阵乘法仍是矩阵乘法），网络再深也学不出弯折的决策边界。ReLU 那个"一压"是非线性的——它让网络真的"深"了。这是第 2 章 §2.2.3.3（Activation Functions）的前奏。

**输入**：`z`——任意形状的 NumPy 数组（这里是 `(4, 4)`，即 `Z1`）。

**输出**：与输入**形状完全相同**的数组，每个元素 $\ge 0$。元素语义：原值的截断保留。

**可调参数**：只有一个位置参数 `z`。还能不能有第二个？可以——比如 `slope=0.1`，把负半轴变成 `slope * z` 而不是 0，那就是 Leaky ReLU，专治"神经元死亡"（负值区域梯度恒 0，参数再也学不动）。现在用不着。

### 步骤 4：前向 —— `forward(X, params)`

```python
def forward(X, params):
    W1, b1, W2, b2 = params["W1"], params["b1"], params["W2"], params["b2"]
    Z1 = X @ W1.T + b1          # (B, D_HIDDEN)
    A1 = relu(Z1)               # (B, D_HIDDEN)
    Z2 = A1 @ W2.T + b2         # (B, D_OUT)
    cache = {"Z1": Z1, "A1": A1}
    return Z2, cache
```

#### `forward(X, params)` —— 把数据送过两层变换，算出 logits

**操作**：四步：
1. `Z1 = X @ W1.T + b1`——输入 $X$（`(4, 3)`）右乘 `W1.T`（`(3, 4)`），得到 `(4, 4)`；再加 `b1`（`(4,)`，NumPy 广播成 `(4, 4)` 每一行都加同一组偏置）。$Z_{1} = X W_1^{\top} + b_1$。
2. `A1 = relu(Z1)`——把 `Z1` 的负值压成 0，得到隐藏激活 `(4, 4)`。
3. `Z2 = A1 @ W2.T + b2`——`(4, 4)` 右乘 `W2.T`（`(4, 2)`），得到 `(4, 2)`，加 `b2`。$Z_{2} = A_1 W_2^{\top} + b_2$。
4. `cache = {"Z1": Z1, "A1": A1}`——把中间结果存进缓存字典，留给反向传播用（见步骤 6）。

**对应数学**：这是主线 DL 桥接里"前向 (forward)"那一拍的代码实现，也是全书第 2 章的心脏：**线性变换就是矩阵乘法**。注意 `W1.T` 这个转置——我们约定权重行是"神经元 × 特征"，所以要用 `W1.T`（`(3, 4)`）来和 `X`（`(4, 3)`）对齐：内维 3 = 3 对上，形状 `(4, 3) @ (3, 4) = (4, 4)`。矩阵乘法要求"左矩阵列数 = 右矩阵行数"，这一条规则是第 2 章一切形状推导的起点。

**输入**：
- `X`：NumPy 数组，**形状 `(B, D_IN)` = `(4, 3)`**——`B` 行是批量里 `B` 个样本，`D_IN` 列是每个样本的 3 个特征。这里第一行 `[0.5, -1.2, 0.3]` 就是"第一只猫"的特征向量。
- `params`：`init_parameters` 返回的字典（四个数组）。

**输出**：一个元组 `(Z2, cache)`：
- `Z2`：**形状 `(B, D_OUT)` = `(4, 2)`**——每个样本的 2 个"未归一化分数"（logits）。它还不是概率，可能为负、和不为 1（这正是第 4 章"分数 vs 概率"的起点）。
- `cache`：字典，含 `Z1`（`(4, 4)`）和 `A1`（`(4, 4)`），供反向使用。

**可调参数**：只有 `X` 和 `params` 两个参数。还能不能有第三个？可以——比如 `dropout_p=0.0`：在 `A1` 上加一个随机置零的开关（训练时把 `dropout_p` 比例的神经元随机冻结），那是正则化的一种。现在不需要。

### 步骤 5：损失 —— `softmax(logits)` 与 `cross_entropy(logits, y)`

```python
def softmax(logits):
    shifted = logits - logits.max(axis=-1, keepdims=True)
    exp = np.exp(shifted)
    return exp / exp.sum(axis=-1, keepdims=True)


def cross_entropy(logits, y):
    probs = softmax(logits)
    p_true = probs[np.arange(len(y)), y]
    return float(-np.log(p_true).mean())
```

#### `softmax(logits)` —— 把分数变成合法的概率分布

**操作**：
1. `shifted = logits - logits.max(...)`——对每个样本，把 logits 减去它自己的最大值。这是数值稳定技巧：直接算 `np.exp(logits)` 时，若 logits 很大，`exp` 会上溢成无穷；减去最大值后所有指数都落在 $(-\infty, 0]$，不会爆。数学上，softmax 对整体平移不变（分子分母同乘 $e^{-m}$），所以减去最大值**不改变结果**。
2. `exp = np.exp(shifted)`——逐元素取指数。
3. `return exp / exp.sum(axis=-1, keepdims=True)`——每个元素除以该样本所有元素之和，把结果归一化到 [0,1] 且每行和为 1。

**对应数学**：主线第二步的"撞墙"在这里得到解答——logits 是"分数"（可为负、和不为 1），softmax 把分数翻译成**合法的概率分布**：非负、和为 1，正好满足第 4 章 Kolmogorov 公理的前两条。$p_c = \dfrac{e^{z_c}}{\sum_{c'} e^{z_{c'}}}$。它是分类模型里"分布语法"的入口。

**输入**：`logits`——**形状 `(B, D_OUT)` = `(4, 2)`** 的数组。

**输出**：**形状与输入相同 `(4, 2)`**，每行是非负且和为 1 的概率分布。第 $i$ 行第 $c$ 列 = "第 $i$ 个样本属于类别 $c$"的模型信念。

**可调参数**：只有 `logits`。还能不能有第二个？可以——比如 `temperature=1.0`：先在指数前除以温度。温度 > 1 让分布更"平"（更不确定），温度 < 1 让分布更"尖"（更自信）。这是知识蒸馏 (knowledge distillation) 的核心旋钮，现在不需要。

#### `cross_entropy(logits, y)` —— 度量模型有多不自信

**操作**：
1. `probs = softmax(logits)`——先归一化。
2. `p_true = probs[np.arange(len(y)), y]`——`np.arange(len(y))` 是样本下标 `[0,1,2,3]`，`y` 是每个样本的真实类别 `[0,1,1,0]`。用"行下标 + 列下标"联合索引，取出每个样本"真实类别"那一格的概率——这就是 $P(y^{(i)} \mid x^{(i)})$。
3. `return float(-np.log(p_true).mean())`——对每个样本取 $-\ln P(y\mid x)$，再求均值。模型给真实类别分配的概率越低，$-\ln$ 越大，损失越高。

**对应数学**：交叉熵 (cross-entropy) 损失——信息论（第 6 章）的核心量，它的数学前提（概率非负、归一、类别互斥）来自概率论（第 4 章）。$L = -\frac{1}{B}\sum_i \ln p_{y^{(i)}}$。当模型完全随机（二分类里两个类各 0.5）时，loss ≈ $-\ln 0.5 = 0.6931$——而我们随机初始化的 loss 是 0.68596922，已经很接近这个"什么都不会"的基准，说明初始权重确实很小。

**输入**：
- `logits`：**形状 `(B, D_OUT)`**——`forward` 的输出。
- `y`：**形状 `(B,)`** 的整数数组，每个元素 ∈ {0, 1, ..., D_OUT-1}，是第 $i$ 个样本的真实类别。注意：它是**类别下标**，不是 one-hot 向量。

**输出**：一个 Python `float`（标量）——整个批量的平均损失。数值范围是 $[0, \infty)$；越小越好。

**可调参数**：只有 `logits`、`y`。还能不能有第三个？可以——比如 `reduction="sum"`：把 `.mean()` 换成 `.sum()`，返回总损失而非平均损失。深度学习中默认用均值（与批量大小解耦，改 `B` 不改变损失尺度）。

### 步骤 6：反向 —— `backward(X, y, params, cache)`

```python
def backward(X, y, params, cache):
    W2 = params["W2"]
    Z1, A1 = cache["Z1"], cache["A1"]
    logits, _ = forward(X, params)
    probs = softmax(logits)
    one_hot = np.zeros_like(probs)
    one_hot[np.arange(len(y)), y] = 1.0
    dZ2 = (probs - one_hot) / len(y)          # (B, D_OUT)  softmax+CE 的梯度（含 1/B）
    dW2 = dZ2.T @ A1                          # (D_OUT, D_HIDDEN)
    db2 = dZ2.sum(axis=0)                     # (D_OUT,)
    dA1 = dZ2 @ W2                            # (B, D_HIDDEN)
    dZ1 = dA1 * (A1 > 0)                      # ReLU 导数
    dW1 = dZ1.T @ X                           # (D_HIDDEN, D_IN)
    db1 = dZ1.sum(axis=0)                     # (D_HIDDEN,)
    return {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}
```

#### `backward(X, y, params, cache)` —— 用链式法则算每个参数的梯度

**操作**：反向传播是一串链式法则，从损失往参数方向逐层求导。每一行的形状注释都标出了结果形状，逐个看：

1. `probs = softmax(logits)`；`one_hot`：把真实类别 `y` 编码成 one-hot 矩阵——每个样本在自己的真实类别那格是 1，其余是 0。
2. `dZ2 = (probs - one_hot) / len(y)`——**softmax + 交叉熵的联合梯度**。这是整个反向里最漂亮的一个事实：损失对 logits 的偏导，恰好就是"预测概率减真实 one-hot"。除以 `len(y)` 是因为损失用了均值（见步骤 5 的 `reduction` 讨论）。
3. `dW2 = dZ2.T @ A1`——损失对 $W_2$ 的偏导：$\partial L/\partial W_2 = dZ_2^{\top} A_1$，形状 `(2, 4)`，与 `W2` 同形。
4. `db2 = dZ2.sum(axis=0)`——对批量求和，消掉样本维，得到 `(2,)`。
5. `dA1 = dZ2 @ W2`——把梯度从输出层传回激活层：`(4, 2) @ (2, 4) = (4, 4)`。
6. `dZ1 = dA1 * (A1 > 0)`——ReLU 的导数：`A1 > 0` 是一张布尔掩码（正值为 True=1，非正为 False=0），逐元素相乘后，只有前向里"活着"（>0）的神经元才收到梯度。这就是"ReLU 死了就死了"的由来——负值区梯度恒 0。
7. `dW1 = dZ1.T @ X`、`db1 = dZ1.sum(axis=0)`——重复 3、4 的逻辑，算出第一层参数的梯度，形状分别是 `(4, 3)` 与 `(4,)`。

**对应数学**：这是主线 DL 桥接里"反向 (backward)"那一拍，也是第 3 章多元微积分的灵魂：**链式法则 (chain rule)**。$\dfrac{\partial L}{\partial W_1} = \dfrac{\partial L}{\partial Z_2}\cdot\dfrac{\partial Z_2}{\partial A_1}\cdot\dfrac{\partial A_1}{\partial Z_1}\cdot\dfrac{\partial Z_1}{\partial W_1}$——每一步的"导数矩阵"在这里就是一行矩阵乘法。梯度从输出一路传回输入，每一步的形状都对齐、都被算出来，这就是"反向传播 = 链式法则的合唱"。

**输入**：
- `X`：**形状 `(B, D_IN)`**，前向的输入（步骤 4 原样传入）。
- `y`：**形状 `(B,)`**，真实类别。
- `params`：参数字典（用于读 `W2`）。
- `cache`：`forward` 返回的缓存字典（用于读 `Z1`、`A1`）。**注意**：`A1` 是梯度计算的关键——ReLU 导数需要知道前向时哪些神经元是正的，这正是我们要在前向里缓存 `A1` 的原因。

**输出**：一个字典，四个键与 `params` 完全对应，每个值是"损失对那个参数全体的偏导"：
- `dW1`：**形状 `(4, 3)`**；`db1`：**形状 `(4,)`**；`dW2`：**形状 `(2, 4)`**；`db2`：**形状 `(2,)`**。
每个梯度的形状都和对应参数完全一致——这是反向传播必须满足的不变量（否则 `params[k] - lr * grads[k]` 无法相减）。

**可调参数**：只有四个位置参数。还能不能有第五个？可以——比如 `lambda_l2=0.0`：往梯度里加一项 $2\lambda W$（L2 正则化的梯度），把权重往 0 拖，抑制过拟合（第 2 章 §2.5.3.4 的正式主题）。现在不需要。

### 步骤 7：更新与编排 —— `update(params, grads, lr)` 与 `train_one_step(...)`

```python
def update(params, grads, lr=LR):
    return {k: params[k] - lr * grads[k] for k in params}


def train_one_step(X, y, params, lr=LR):
    logits, cache = forward(X, params)
    loss_before = cross_entropy(logits, y)
    grads = backward(X, y, params, cache)
    new_params = update(params, grads, lr)
    logits_new, _ = forward(X, new_params)
    loss_after = cross_entropy(logits_new, y)
    return new_params, loss_before, loss_after
```

#### `update(params, grads, lr)` —— 参数迈一步

**操作**：字典推导式对每个键 `k` 做 `params[k] - lr * grads[k]`。这就是梯度下降更新：$\theta \leftarrow \theta - \eta \nabla L(\theta)$。梯度指向损失增长最快的方向，所以朝**反方向**走 `lr` 步，损失就减小。

**对应数学**：这是主线 DL 桥接里"更新 (update)"那一拍，也是第 5 章优化理论的母式。整个第 5 章（动量、Adagrad、RMSprop、Adam）都是在这一个减法上添加策略：动量记下速度，Adam 调整每个参数各自的步长——但骨架永远是 `θ - η·∇L`。

**输入**：
- `params`：参数字典。
- `grads`：`backward` 返回的梯度字典。
- `lr`：浮点数（可省略，默认 `LR = 0.1`），步长 $\eta$。

**输出**：一个新字典，键与 `params` 相同，值是更新后的参数。**注意**：它不改动原 `params`（返回新字典），这是刻意为之——先算完梯度再统一更新，避免"前一层已经更新、后一层还用旧参数"的串扰。

**可调参数**：
- `lr`：核心旋钮。`0.1` 在这里让 loss 下降 0.00104；改 `0.001`，一步几乎看不出变化；改 `1.0`，单步下降更大（约 0.011）。但注意：**单步下降大 ≠ 多步收敛好**——离谷底远时梯度方向始终是对的，大步单步也降；可一旦靠近谷底，大步会跨过头、在谷底两侧震荡（30 步实验里 `lr = 10.0` 最终发散，见《习题.md》计算实践题 3）。判断学习率好不好，要看整条轨迹，不能只看一步。
- 还能不能有第二个参数？可以——比如 `momentum=0.9`：维护一个速度变量 $v \leftarrow \mu v - \eta g$，用 $v$ 更新。它让参数在平坦区域滚得更快、在震荡方向自我抵消。这是第 5 章 §5.6.4 的主题。

#### `train_one_step(X, y, params, lr)` —— 三拍交响乐的总指挥

**操作**：按主线 DL 桥接的顺序，把四个函数串成一步：
1. `forward` → 算 `logits` 和 `cache`。
2. `cross_entropy` → 记录更新前的 `loss_before`。
3. `backward` → 用 `cache` 算梯度。
4. `update` → 得到 `new_params`。
5. 用 `new_params` **再前向一次**，算 `loss_after`——这样调用者才能看到"这一步到底降了多少"。返回 `(new_params, loss_before, loss_after)`。

**对应数学**：这就是主线里那句"前向、反向、更新，三拍而已，第 2、3、4、5、6 章的数学全都在场"的可执行版本。把 `train_one_step` 放进一个 `for` 循环里跑几百遍，你就亲手造出了一个正在训练的网络——那正是后续各章逐步替换、升级的起点。

**输入**：`X`（`(B, D_IN)`）、`y`（`(B,)`）、`params`（字典）、`lr`（浮点，可省略）。

**输出**：三元组 `(new_params, loss_before, loss_after)`——新参数 + 更新前后的损失。

**可调参数**：
- `lr`：透传给 `update`。改大/改小，效果与步骤 7 一致。
- 还能不能有第四个参数？可以——比如 `n_steps=1`：内部循环 `n_steps` 次再返回，一次调用就跑多步。主流程里演示一步，已经足够看清全貌。

### 步骤 8：主流程 —— 把一切串起来

```python
X = np.array([[0.5, -1.2, 0.3],
              [1.0, 0.4, -0.8],
              [-0.3, 0.7, 0.9],
              [0.8, -0.5, 0.2]])          # 形状 (4, 3)：4 个样本、3 个特征
y = np.array([0, 1, 1, 0])                 # 形状 (4,)：每个样本的类别

params = init_parameters(D_IN, D_HIDDEN, D_OUT)
logits, cache = forward(X, params)
print("logits 形状 (B, D_OUT) =", logits.shape)
print("W1 形状 (D_HIDDEN, D_IN) =", params["W1"].shape)
print("W2 形状 (D_OUT, D_HIDDEN) =", params["W2"].shape)

loss0 = cross_entropy(logits, y)
print("更新前 loss = %.8f" % loss0)

params, loss_before, loss_after = train_one_step(X, y, params)
print("train_one_step 报告的更新前 loss = %.8f" % loss_before)
print("更新后 loss = %.8f" % loss_after)
print("loss 下降量 = %.8f" % (loss_before - loss_after))
```

#### 主流程 —— 数据、初始化、观察一次更新

**操作**：这是脚本的"执行部分"（顶层代码，不是函数）。
1. 手写 4 个样本的输入 `X`（形状 `(4, 3)`）与真实类别 `y`（`(4,)`）。你完全可以把这些数字理解成"4 只猫/狗，每只 3 个特征，标签是 0/1"。
2. `init_parameters` 初始化参数，`forward` 跑一次前向，打印三行形状——让你看见每一层张量的维度。
3. `loss0`：更新前的损失。
4. `train_one_step`：跑完整的一步，打印更新前、更新后与下降量。

**对应数学**：这一步是主线的具身。那一串形状 `(4, 3)`、`(4, 4)`、`(4, 2)` 就是数据穿过网络时"数阵"的体型变化——线性代数（第 2 章）里"矩阵乘法要求内维对齐"的活教材；`loss` 的数字是信息论（第 6 章）与概率论（第 4 章）的合体；`loss 下降量 = 0.00104062 > 0` 是优化理论（第 5 章）那句"沿梯度反方向走步长 $\eta$ 损失必降"的第一次实证。

**输入**：无显式输入，读模块级常量与手写数据。

**输出**：控制台文本，共 7 行（三行形状 + 四行损失）。

**可调参数**：
- 改 `X`、`y`：换一批样本。比如把第二行 `[1.0, 0.4, -0.8]` 的标签从 1 改成 0，梯度方向随之改变，loss 下降量不同。
- 改 `LR`：观察更新幅度。`0.5` 时下降量明显变大；`5.0` 时可能看到"更新后 loss 反而变大"——一步迈过头了。
- 改 `D_HIDDEN`：把 4 改成 64，`W1` 变成 `(64, 3)`、`W2` 变成 `(2, 64)`，参数变多、计算变多——模型容量变大，这是第 9 章"宽度"主题的伏笔。
- 还能不能有更多参数？这层不是函数，没有"参数"。想让它更灵活，可以把数据与循环封装成一个 `run_training(X, y, n_steps, lr)` 函数——但在导论里，顶层直写最透明。

## 一步验证：把"三拍"变成"三十拍"

想亲手看见主线那台"什么都不会的机器"真正学会吗？把主流程的最后一段换成循环：

```python
params = init_parameters(D_IN, D_HIDDEN, D_OUT)
for step in range(30):
    params, before, after = train_one_step(X, y, params, lr=0.5)
    if step % 5 == 0:
        print("step %2d  loss = %.6f" % (step, after))
```

你会看到 loss 一路往下走（大约从 0.68 降到 0.07 上下），网络真的在"学"。把这个循环、这几行代码，和主线第三步那幅"前向、反向、更新"的画面对照——**你刚刚亲手执行了整本书的总纲**。后面的每一节，都是在往这三拍里填入更精密的数学。
