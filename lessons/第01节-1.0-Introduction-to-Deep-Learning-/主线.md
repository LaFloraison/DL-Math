### 第二步：数学讲解 (15-20 min)

#### 1. 深度学习的数学地图

深度学习模型本质上做一件事：**学习一个函数映射**。给定输入 $x \in \mathbb{R}^n$，我们希望学到一个函数 $f_\theta(x)$ 尽可能逼近真实的映射 $y = f^*(x)$。

这个函数 $f_\theta$ 由**参数** $\theta$ 控制（权重和偏置），学习过程就是寻找最优参数：

$$\theta^* = \arg\min_\theta \mathcal{L}(f_\theta(x), y)$$

其中 $\mathcal{L}$ 是损失函数 (loss function)，衡量预测与真实值的差距。

这个看似简单的优化问题，需要四块数学基石：

| 数学领域 | 在 DL 中的角色 | 教材章节 |
|---------|---------------|---------|
| 线性代数 (Linear Algebra) | 数据表示（张量）、权重矩阵、特征分解 | Ch02 |
| 多元微积分 (Multivariate Calculus) | 反向传播、梯度计算、链式法则 | Ch03 |
| 概率论与统计 (Probability & Statistics) | 损失函数的概率解释、不确定性建模 | Ch04 |
| 优化理论 (Optimization) | 梯度下降及其变体、收敛性分析 | Ch05 |

**核心洞察**：神经网络不是"黑箱"。它是一个**数学结构**——由矩阵乘法、非线性激活、和概率解释组成的分层函数。

#### 2. 关键定义：神经网络作为函数

**定义 1.1（前馈神经网络, Feedforward Neural Network）**

一个 $L$ 层前馈神经网络是一个复合函数：

$$f_\theta(x) = f^{(L)} \circ f^{(L-1)} \circ \cdots \circ f^{(1)}(x)$$

其中每一层 $f^{(l)}(z) = \sigma^{(l)}(W^{(l)} z + b^{(l)})$，$W^{(l)}$ 是权重矩阵 (weight matrix)，$b^{(l)}$ 是偏置向量 (bias vector)，$\sigma^{(l)}$ 是逐元素的非线性激活函数 (activation function)。

**直观理解**：每一层做的事是"先线性变换，再非线性扭曲"。线性变换（矩阵乘法）负责旋转、缩放、平移数据；非线性激活负责"折叠"空间，让模型能表达复杂函数。

**为什么需要非线性？** 如果去掉激活函数，多层线性变换还是线性变换：

$$W_2(W_1 x + b_1) + b_2 = (W_2 W_1)x + (W_2 b_1 + b_2)$$

这仍然是一个线性函数。无论堆多少层，表达能力都不超过单层。**非线性是深度网络表达能力的来源**。

> ⚠️ **不能做什么**：不是所有非线性都能用。比如 $\sigma(z) = z^2$ 虽然是非线性，但它的梯度可能爆炸。激活函数的选择有数学约束（单调性、梯度范围等），这是 Ch03 和 Ch05 的内容。

#### 3. 学习 = 优化

**定义 1.2（损失函数, Loss Function）**

给定训练集 $\{(x_i, y_i)\}_{i=1}^N$，经验损失 (empirical loss) 为：

$$\mathcal{L}(\theta) = \frac{1}{N} \sum_{i=1}^N \ell(f_\theta(x_i), y_i)$$

其中 $\ell$ 是单个样本的损失，如均方误差 (MSE) 或交叉熵 (cross-entropy)。

**学习问题**：找到 $\theta^* = \arg\min_\theta \mathcal{L}(\theta)$。

**关键挑战**：$\mathcal{L}$ 是高维非凸函数（通常有数十万甚至数十亿维参数）。没有解析解，只能迭代逼近。

**最常用的迭代方法**：梯度下降 (gradient descent)

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t)$$

其中 $\eta$ 是学习率 (learning rate)，$\nabla_\theta \mathcal{L}$ 是损失对参数的梯度 (gradient)。

**为什么梯度下降能收敛？** 直觉：在 $\theta_t$ 附近对 $\mathcal{L}$ 做一阶泰勒展开 (Taylor expansion)：

$$\mathcal{L}(\theta_t + \Delta\theta) \approx \mathcal{L}(\theta_t) + \nabla\mathcal{L}(\theta_t)^T \Delta\theta$$

要让 $\mathcal{L}$ 下降，即让 $\nabla\mathcal{L}^T \Delta\theta < 0$，最速下降方向就是 $-\nabla\mathcal{L}$。这就是梯度下降的几何直觉。

> ⚠️ **不能做什么**：梯度下降只保证找到**局部极小值** (local minimum)，不保证全局最优。非凸优化的这一困境是整个深度学习理论的核心难题之一。实践中靠随机初始化 + 大量数据 + 精心调参来逼近好的解。

#### 4. 为什么需要这四门数学？

**线性代数**：数据是矩阵，模型是矩阵运算。张量 (tensor) 是多维数组的推广，Transformer 的注意力机制本质是一系列矩阵乘法。

**多元微积分**：反向传播 (backpropagation) 就是链式法则 (chain rule) 的工程实现。每个参数的梯度都要通过复合函数的链式求导来计算。

**概率论**：交叉熵损失源自最大似然估计 (maximum likelihood estimation)。Dropout 是贝叶斯推断的近似。生成模型（VAE、GAN）的整个理论基础是概率分布。

**优化理论**：从 SGD 到 Adam，所有优化器都是梯度下降的变体。理解它们的数学原理才能正确选择和使用。

### 第三步：DL 桥接 + 代码 (5-8 min)

#### 最小神经网络：从数学定义到代码

我们用一个 3 行代码的神经网络验证刚才的数学定义：

```python
import numpy as np

# 定义 1.1 的数学结构：f(x) = σ(Wx + b)
def forward(W, b, x, activation):
    """一层神经网络的前向传播"""
    return activation(W @ x + b)  # @ 是矩阵乘法

# 验证：没有激活函数的"深度"网络仍是线性函数
np.random.seed(42)
W1, b1 = np.random.randn(4, 2), np.random.randn(4)
W2, b2 = np.random.randn(1, 4), np.random.randn(1)

x = np.array([1.0, 2.0])
linear_stack = W2 @ (W1 @ x + b1) + b2  # 两层纯线性

# 合并为单层：W_combo = W2 @ W1
W_combo = W2 @ W1
b_combo = W2 @ b1 + b2
single_layer = W_combo @ x + b_combo

print(f"两层线性: {linear_stack[0]:.6f}")
print(f"合并单层: {single_layer[0]:.6f}")
print(f"完全相等: {np.allclose(linear_stack, single_layer)}")
# 输出: 完全相等: True
```

**这段代码验证了什么？** 正是第 2 节的数学结论：多层线性变换可以合并为单层。这就是为什么深度学习**必须**有非线性激活函数。

#### 梯度下降的最小实现

```python
import numpy as np

# 目标：拟合 y = 2x + 1（但我们假装不知道）
x_data = np.array([0, 1, 2, 3, 4], dtype=float)
y_data = np.array([1, 3, 5, 7, 9], dtype=float)

# 模型：y_pred = w * x + b
w, b = 0.0, 0.0  # 从零开始
learning_rate = 0.1

for step in range(50):
    # 前向：计算预测
    y_pred = w * x_data + b
    
    # 损失：MSE = mean((y_pred - y_true)^2)
    loss = np.mean((y_pred - y_data) ** 2)
    
    # 梯度（解析推导）：
    # dLoss/dw = mean(2 * (y_pred - y_true) * x)
    # dLoss/db = mean(2 * (y_pred - y_true))
    grad_w = np.mean(2 * (y_pred - y_data) * x_data)
    grad_b = np.mean(2 * (y_pred - y_data))
    
    # 梯度下降更新：θ ← θ - η * ∇L(θ)
    w -= learning_rate * grad_w
    b -= learning_rate * grad_b

print(f"学到的参数: w={w:.2f}, b={b:.2f}")
print(f"真实参数:   w=2.00, b=1.00")
# 输出: 学到的参数: w≈2.00, b≈1.00
```

**这段代码展示了什么？** 整个深度学习的核心循环：**前向传播 → 计算损失 → 反向传播（算梯度）→ 参数更新**。所有深度学习框架（PyTorch、TensorFlow）只是在规模化地自动化这个过程。
