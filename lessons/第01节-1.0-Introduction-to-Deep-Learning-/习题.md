## 一、概念检验

### 题 1（选择）：哪个"不"属于深度学习问题的三件套？

主线把深度学习问题定义成三件套 $\big(\mathcal{D},\ f_\theta,\ L\big)$——数据集、模型、损失。以下哪个选项**不**属于这三件套，而是独立于它们存在的另一个要素？

- A. 数据集 $\mathcal{D} = \{(x^{(i)}, y^{(i)})\}$
- B. 模型 $f_\theta$（由参数 $\theta$ 决定）
- C. 优化算法（如梯度下降、Adam）
- D. 损失函数 $L(\theta)$

**解答**：C。

数据集（A）、模型（B）、损失（D）正是三件套本身。而**优化算法**不是三件套之一——它是求解那个最小化问题的手段：给定 $L(\theta)$ 之后，"如何找到 $\arg\min_\theta L(\theta)$"是第 5 章优化理论的事。可以这样分：三件套描述"问题是什么"，优化算法描述"怎么解"。

**思路点拨**：陷阱在于——深度学习里我们总是同时提起"损失"和"优化器"，容易把它们当成一对。但它们的分工不同：损失是**目标**（第 6 章信息论定义它该长什么样），优化是**方法**（第 5 章决定怎么走到谷底）。主线里那个定义块刻意只放了三件套，就是为了把"问题的定义"和"解法"分开——正如把"线性映射"和"它的矩阵表示"分开是全书反复出现的纪律。选 C 之外的选项，多半是把"优化的东西"误认成了"优化本身"。

### 题 2（匹配）：把"功能"对到"章节"

主线把 12 章分成五层。请把下列"功能描述"对到正确的数学分支（线性代数 / 多元微积分 / 概率论与统计 / 优化理论 / 信息论 / 图论）：

(a) 数据如何被表示和变换（数阵乘法）。
(b) "误差"要往哪一层回传，用链式法则逐层求梯度。
(c) 损失函数用交叉熵，它度量"模型有多不自信"。
(d) 一批样本是从数据分布里抽出来的，且模型输出要归一化成概率分布。
(e) 如何沿梯度的反方向迈步，找到让损失最小的参数。

**解答**：(a) 线性代数（第 2 章）。(b) 多元微积分（第 3 章）。(c) 信息论（第 6 章）。(d) 概率论与统计（第 4 章）。(e) 优化理论（第 5 章）。

**思路点拨**：这是主线"地图"那一节的直接复述，但值得你多停一停：(c) 与 (d) 最容易混——"输出要归一化成概率"是概率论的纪律（softmax 满足非负与归一），而"用什么样的量来度量错误"是信息论的发明（交叉熵 $-\log p$）。一个决定"数长什么样"，一个决定"错误怎么称重"。记不住时，回主线那个训练步骤的比喻：前向是线性代数，回传是微积分，数据与归一化是概率，迈步是优化，称错是信息论。

### 题 3（判断 + 简答）："数学是深度学习的全部"

有人说："有了这本书，把每一章都吃透，深度学习就再没有难题了。"判断这句话是否成立，并用主线的**边界声明**解释。

**解答**：不成立。

主线在"地图不是地形"里划了三条边界：真实世界的深度学习还至少包含**工程**（数据清洗、GPU 调度、调试）、**经验直觉**（哪些超参数组合通常好使，往往没有数学证明）、**计算现实**（亿级参数的 $\arg\min_\theta$ 只能逼近，求不到精确解）。数学告诉你"梯度是指向最陡上升的方向"，但没说走几步、会不会掉进泥坑。

**思路点拨**：这句判断的陷阱是把"必要条件"当成了"充分条件"。数学是深度学习的**语言**——没有它，你只能照别人的配方做；有了它，你才能自己配方、读懂论文、在新场景里判断该用哪个工具。但语言不等于全部生活：工程与直觉同样决定成败。主线的立场是"没有数学不能创造，有数学才能自由"——注意这里的关键词是"才能"，不是"就一定"。

## 二、计算实践

### 题 1（手算一次两层前向的每个形状与数字）

给定单个样本的特征向量 $x = (0.5,\ -1.2,\ 0.3)$，以及参数：

$$
W_1 = \begin{bmatrix} 0.2 & -0.1 & 0.4 \\ 0.3 & 0.5 & -0.2 \end{bmatrix},\quad
b_1 = (0.1,\ -0.1),\quad
W_2 = \begin{bmatrix} 0.5 & -0.4 \\ -0.2 & 0.3 \end{bmatrix},\quad
b_2 = (0,\ 0.05)
$$

(a) 写出 $Z_1 = x W_1^{\top} + b_1$ 的每个分量，并说明为什么要用 $W_1^{\top}$。
(b) 过 ReLU 得到 $A_1$，写出 $Z_2 = A_1 W_2^{\top} + b_2$。
(c) 对 $Z_2$ 做 softmax，得到 $p_0, p_1$；若真实类别 $y=0$，求交叉熵损失。

**解答**：

(a) $x$ 是 $1\times3$ 行向量，$W_1^{\top}$ 是 $3\times2$。矩阵乘法要求"左矩阵列数 = 右矩阵行数"：$1\times3$ 乘 $3\times2$，内维 3 对齐，结果是 $1\times2$。因此

$$
Z_1 = (0.5,\ -1.2,\ 0.3) \begin{bmatrix} 0.2 & 0.3 \\ -0.1 & 0.5 \\ 0.4 & -0.2 \end{bmatrix} + (0.1,\ -0.1)
$$

逐分量算：第一个输出神经元收到 $x$ 各分量乘 $W_1$ 第一行再求和：

$$
Z_{1,1} = 0.5(0.2) + (-1.2)(-0.1) + 0.3(0.4) + 0.1 = 0.10 + 0.12 + 0.12 + 0.10 = 0.44
$$
$$
Z_{1,2} = 0.5(0.3) + (-1.2)(0.5) + 0.3(-0.2) - 0.1 = 0.15 - 0.60 - 0.06 - 0.10 = -0.61
$$

所以 $Z_1 = (0.44,\ -0.61)$。

(b) ReLU 保留正值、清零负值：$A_1 = (0.44,\ 0)$。于是

$$
Z_2 = (0.44,\ 0) \begin{bmatrix} 0.5 & -0.2 \\ -0.4 & 0.3 \end{bmatrix} + (0,\ 0.05)
$$

$$
Z_{2,1} = 0.44(0.5) + 0(-0.4) + 0 = 0.22,\qquad
Z_{2,2} = 0.44(-0.2) + 0(0.3) + 0.05 = -0.088 + 0.05 = -0.038
$$

$Z_2 = (0.22,\ -0.038)$。

(c) softmax：

$$
e^{0.22} = 1.2461,\quad e^{-0.038} = 0.9627,\quad \text{和} = 2.2088
$$
$$
p_0 = \frac{1.2461}{2.2088} = 0.5641,\qquad p_1 = \frac{0.9627}{2.2088} = 0.4359
$$

真实类别 $y=0$ 对应 $p_0 = 0.5641$，交叉熵：

$$
L = -\ln(0.5641) = 0.5724
$$

**NumPy 验证**：
```python
import numpy as np
x = np.array([[0.5, -1.2, 0.3]])
W1 = np.array([[0.2, -0.1, 0.4], [0.3, 0.5, -0.2]])
b1 = np.array([0.1, -0.1])
W2 = np.array([[0.5, -0.4], [-0.2, 0.3]])
b2 = np.array([0.0, 0.05])

Z1 = x @ W1.T + b1
A1 = np.maximum(Z1, 0)
Z2 = A1 @ W2.T + b2
e = np.exp(Z2 - Z2.max(axis=-1, keepdims=True))   # 数值稳定的 softmax
P = e / e.sum(axis=-1, keepdims=True)
loss = -np.log(P[0, 0])                            # y = 0
print("Z1 =", Z1)     # [[ 0.44 -0.61]]
print("A1 =", A1)     # [[0.44 0.  ]]
print("Z2 =", Z2)     # [[ 0.22  -0.038]]
print("P  =", P)      # [[0.56414458 0.43585542]]
print("CE =", loss)   # 0.5724447055447239
```

**思路点拨**：这道题把主线 DL 桥接里"前向"那一拍落了地。三个最常见的错：

1. **转置搞反**——有人写成 $W_1 x$ 或 $x W_1$。我们约定权重行是"神经元 × 特征"，所以 $x$（特征维在右）必须右乘 $W_1^{\top}$（特征维在左），才能让内维对齐。拿不准就数维度：$(1\times3)(3\times2) = (1\times2)$。
2. **ReLU 作用于 $Z_1$ 而非直接作用于输入**——激活在每层线性变换之后，$A_1 = \text{ReLU}(Z_1)$ 而不是 $\text{ReLU}(x)$。
3. **偏置位置**——偏置在求和之后才加，且逐神经元加。第 (b) 问里 $Z_{2,2} = 0.44(-0.2) + 0 + 0.05$，把偏置算进被 $A_1$ 乘的项里是错的。

选错 softmax 的常见原因：忘了先对所有 $Z_2$ 分量取指数再归一化，或直接拿 $Z_2$ 当概率用——logits 可为负、和不为 1，它只是"分数"，不是概率（这正是第 4 章"分数 vs 概率"的分界线）。

### 题 2（形状推导：三张数阵穿过网络的"体型"）

批量大小 $B=4$，输入特征 $D_{in}=3$，隐藏宽度 $D_{hidden}=4$，输出类别 $D_{out}=2$。填空：

(a) 输入 $X$ 的形状是 ______；权重 $W_1$ 的形状是 ______；则 $Z_1 = X W_1^{\top} + b_1$ 的形状是 ______，$b_1$ 的形状必须是 ______。
(b) $A_1$ 与 $Z_1$ 形状相同，为 ______；$W_2$ 的形状是 ______；则 $Z_2 = A_1 W_2^{\top} + b_2$ 的形状是 ______。
(c) 交叉熵损失 $L$ 是一个标量（一个数）。$L$ 对 $W_1$ 的梯度 $\partial L/\partial W_1$ 的形状必须与 ______ 相同。

**解答**：
(a) $X$：`(4, 3)`；$W_1$：`(4, 3)`；$Z_1$：`(4, 4)`（因为 `(4,3)@(3,4)=(4,4)`）；$b_1$：`(4,)`（广播到 `(4,4)` 每行加同一组）。
(b) $A_1$：`(4, 4)`；$W_2$：`(2, 4)`；$Z_2$：`(4, 2)`（`(4,4)@(4,2)=(4,2)`）。
(c) 与 $W_1$ 相同，即 `(4, 3)`。

**思路点拨**：这是主线里"矩阵乘法要求内维对齐"的形状版，也是阅读一切深度学习代码的基础技能。记三条铁律：
1. **内维对齐**：`(B, d1) @ (d1, d2) = (B, d2)`——中间的 `d1` 必须相等，结果只留首尾两维。
2. **形状贯穿全链**：`X (B,3) → Z1 (B,4) → A1 (B,4) → Z2 (B,2)`，每一层的输出宽度就是下一层矩阵的行数来源。
3. **梯度同形不变式**：$\partial L/\partial W$ 的形状永远等于 $W$ 的形状——否则 `θ - η·∇L` 无法相减。这是检查反向传播写没写错的第一道安检。第 (c) 问最容易错的是写成 `(3,4)`（把 `W1.T` 的形状记成了 `W1` 的形状）。

### 题 3（代码验证：学习率如何决定命运）

用《代码.md》里的 `train_one_step`，把它放进循环里跑 30 步，分别试 `lr = 0.1`、`1.0`、`10.0`（`SEED=42` 不变）。每次记录 loss：

```python
# 在代码.md 基础上补一个训练循环
def train(X, y, lr, n_steps=30):
    params = init_parameters(D_IN, D_HIDDEN, D_OUT)
    losses = []
    for _ in range(n_steps):
        params, before, after = train_one_step(X, y, params, lr=lr)
        losses.append(after)
    return losses

for lr in (0.1, 1.0, 10.0):
    L = train(X, y, lr)
    print("lr = %-4s -> 最终 loss = %.6f" % (lr, L[-1]))
```
```
lr = 0.1  -> 最终 loss = 0.588403
lr = 1.0  -> 最终 loss = 0.027577
lr = 10.0 -> 最终 loss = 2.460670
```

(a) 三条曲线分别是什么走势？哪个收敛最快？
(b) `lr = 10.0` 时发生了什么？为什么它没有像直觉预期的那样"走得快所以更早到谷底"？
(c) 这三条曲线合起来，说明优化理论里"步长"起什么作用？

**解答**：

(a) `lr = 0.1` 稳步但缓慢地下降（30 步后 0.685 → 0.588，还在半路）；`lr = 1.0` 陡降并收敛（0.675 → 0.028）；`lr = 10.0` **发散**——第一步先降到 0.49，随后不降反升、在 2.4~3.0 之间高频震荡，30 步后 2.46，比起点 0.69 还差得多。收敛最快的是 `lr = 1.0`。

(b) 步长太大，参数每一步都**跨过了谷底**、反弹到另一侧的斜坡上，下一大步又跨回来——于是 loss 在谷底两侧来回弹跳，永远无法落脚，甚至越弹越远。注意一个反直觉的点：第一步 `lr = 10.0` 时 loss 是从 0.686 降到 0.491 的（离谷底远，梯度的方向是对的、大步也在往好处走）；但之后每次都被推过谷底，累积起来就发散。**只看一步，甚至会误以为"大学习率更好"——这正是必须看整条轨迹的原因。**

(c) 步长 $\eta$ 是"沿梯度反方向走多远"。太小：迈不动，收敛极慢；太大：跨过谷底，震荡甚至发散；适中：稳步下降。而"适中"本身依赖地形——离谷底远时可以走大步（这是"学习率调度"learning rate schedule 的直觉来源），靠近谷底必须收步。优化理论（第 5 章）整章都在回答同一个问题：这个 $\eta$ 该怎么定、该不该每个参数不同（Adam 就给了每个参数各自的步长）。

**思路点拨**：这道题让你亲手撞一次"优化步长"的墙。最常见的错误直觉是"走大步 = 更快到谷底"——它只在**梯度方向一致性保持**的早期成立；一旦靠近谷底，大步就是反弹。请把这条经验刻下来：**梯度只告诉你"最陡的方向"，步长决定你能不能停在谷底**。这正是主线边界声明里"数学没说走几步、会不会掉进泥坑"的现场版。另一个易错点：用**单步**的下降量来判断学习率好坏——单步下降多不等于 30 步后收敛得好，轨迹比单步更诚实。

## 三、DL 延伸

### 题 1（场景→章节：拿到一个任务，你知道该翻哪本书吗）

你接到三个深度学习任务，请为每个任务指出：**它最依赖哪一章的数学**，以及那一章里你**具体**会用到的工具（不必展开，点名即可）。

- 任务 A：把 224×224 的 RGB 图像识别成 1000 类物体。
- 任务 B：预测一句话里相邻词之间的相互关注关系。
- 任务 C：给一张稀疏的社会网络图预测两个用户会不会成为朋友。

**解答**：

- 任务 A → **线性代数（第 2 章）**与**调和分析（第 10 章）**：图像是 `(224, 224, 3)` 的数阵，卷积神经网络把卷积操作写成数阵运算；而"卷积在频域是乘法"的卷积定理（第 10 章）是理解 CNN 谱系的关键。若只选一章，选第 2 章——卷积神经网络的每一层都是矩阵运算。
- 任务 B → **线性代数（第 2 章）**与**信息论（第 6 章）**：Transformer 的注意力 $QK^{\top}$ 是矩阵乘法，算的是任意两个词的内积相似度（第 2 章）；而它预测词时用的是交叉熵损失（第 6 章），softmax 归一化来自概率论（第 4 章）。
- 任务 C → **图论（第 7 章）**：用户是节点、关注关系是边，预测"会不会成为朋友"就是**边预测/链接预测**，图神经网络（GNN）在图上做消息传递——这是第 7 章的核心应用。

**思路点拨**：这道题考的是"地图感"——拿到问题先定位，而不是一头扎进代码。判别的试金石：
- 数据长得像"棋盘数阵"（图像、批量特征）→ 线性代数。
- 数据是"序列/词与词的关系"→ 注意：是"谁注意谁"的相似度结构 → 线性代数（内积）+ 信息论（损失）。
- 数据是"节点 + 边"→ 图论。
容易混的地方：任务 B 很多人第一反应是"这是 NLP，该用第 3 章微积分"——不，微积分管的是**训练机制**（怎么学），不决定**数据建模**该用哪个结构。先分清"数据长什么样"（建模层），再谈"怎么学"（训练层）。

### 题 2（训练日志解读：loss 的三种走法各归哪一章）

你训练同一个网络三次，得到三条 loss 曲线：

- 曲线 1：loss 从 0.69 一路降到 0.07，平稳收敛。
- 曲线 2：loss 前 20 步降到 0.2，之后**反复震荡**，降不下去。
- 曲线 3：训练 loss 一直很低，但换到没见过的测试数据上，错误率高得惊人。

(a) 曲线 2 的"震荡"最可能由什么参数引起？它属于哪一章的课题？
(b) 曲线 3 的现象叫什么？它最可能由哪种数学工具来缓解？属于哪一章？

**解答**：

(a) **学习率 $\eta$ 偏大**（或优化策略不合适）。步长太大，参数在谷底附近来回跨越、无法稳定落脚，表现为 loss 高频震荡、平台期。这是**优化理论（第 5 章）**的课题——动量、Adam、学习率调度（learning rate schedule）都是为此而生。

(b) 这叫**过拟合 (overfitting)**：模型把训练集背了下来，没学到可泛化的规律。缓解它的工具很多——**正则化 (regularization)**（L2 惩罚、dropout）、交叉验证、更多数据。在本书里，正则化的数学出现在第 2 章 §2.5.3.4 与 §2.3.6.6；"为什么模型会在分布外数据上失灵"的深入讨论则在第 4 章（过拟合与欠拟合、贝叶斯观点）与第 9 章（拓扑与泛化）。

**思路点拨**：这道题把"损失曲线"这个深度学习里最常见的一张图，拆成两章的分工：**震荡**是优化问题（第 5 章）——机制没调好；**训练好但测试差**是泛化问题（第 2 章正则化、第 4 章过拟合、第 9 章拓扑）——目标本身没对准。最容易犯的错是把"测试差"也归咎于优化："再加大学习率多训几轮"——这通常只会让过拟合更严重。判断口诀：**训练 loss 高 → 欠拟合/机制问题，去找优化与容量；训练 loss 低但测试差 → 过拟合/泛化问题，去找正则化与数据**。主线边界声明"数学不解决全部工程问题"，在这里有了最具体的形状。
