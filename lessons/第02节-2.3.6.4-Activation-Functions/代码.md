# 代码：把三兄弟"验明正身"——值域、导数、逐元素行为

主线里我们对比了 ReLU、Sigmoid、Tanh。这一节用 NumPy 做三件事：**① 三个函数作用于同一组数；② 数值验证各自的导数；③ 演示"逐元素、不改变形状"。**

---

## 层一：完整脚本

```python
import numpy as np                     # NumPy：exp / maximum / tanh

# ---- ① 三兄弟作用于同一组数 ----
z = np.array([-3.0, -1.0, 0.0, 1.0, 3.0])
relu    = np.maximum(0.0, z)           # ReLU：负归零、正保留
sigmoid = 1.0 / (1.0 + np.exp(-z))     # Sigmoid：压进 (0,1)
tanh    = np.tanh(z)                   # Tanh：压进 (-1,1)
print("z      =", z)
print("ReLU   =", relu)
print("Sig    =", np.round(sigmoid, 3))
print("Tanh   =", np.round(tanh, 3))

# ---- ② 数值导数（中心差分）----
def num_deriv(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

x = 1.0
print("\n--- 导数在 z=1 处 ---")
print("ReLU 数值导数:", num_deriv(np.maximum, 0.0, x), "理论 1")
print("Sigmoid 导数:", num_deriv(lambda t: 1/(1+np.exp(-t)), x), "理论", sigmoid[3]*(1-sigmoid[3]))
print("Tanh 导数:", num_deriv(np.tanh, x), "理论", 1 - np.tanh(x)**2)

# ---- ③ 逐元素、不改变形状 ----
M = np.array([[1.0, -2.0], [3.0, -4.0]])
A = np.maximum(0.0, M)
print("\n输入形状:", M.shape, "→ ReLU 输出形状:", A.shape)
print("ReLU(M) =\n", A)
```

## 层二：分步逐函数拆解

### 步骤 1：三兄弟的"体检表"

```python
relu    = np.maximum(0.0, z)
sigmoid = 1.0 / (1.0 + np.exp(-z))
tanh    = np.tanh(z)
```

**做什么**：对同一组 $z=[-3,-1,0,1,3]$ 施加三个函数，观察值域差异。
**操作**：`np.maximum`（ReLU）、`np.exp`（Sigmoid）、`np.tanh`（Tanh）。`-z` 对负数取反 → $e^{-z}$ 放大。
**可调参数**：换成任意数组。注意观察：ReLU 只归零负数；Sigmoid 把 $-3$ 压到 0.047、$3$ 压到 0.953；Tanh 把 $-3$ 压到 $-0.995$、$3$ 压到 0.995。
**对应数学**：主线三兄弟的值域。**Sigmoid 是"非零中心"（0.5 居中），Tanh 是"零中心"（0 居中）**——这是 Tanh 优于 Sigmoid 的关键点。

### 步骤 2：数值导数

```python
def num_deriv(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)
```

#### 中心差分 —— 数值求导

**操作**：$\frac{f(x+h)-f(x-h)}{2h}$ 近似导数。$h=10^{-6}$ 时精度高。
**可调参数**：`h` 太小会浮点误差，太大不准确；$10^{-6}$ 是好默认。
**对应数学**：主线各函数导数公式的数值验证：ReLU 导数 $=1$（正区间）、Sigmoid 导数 $=\sigma(1-\sigma)\approx0.197$（$\le 0.25$）、Tanh 导数 $=1-\tanh^2\approx0.420$（$\le 1$）。**数值与理论吻合。**

### 步骤 3：逐元素 + 形状不变

```python
M = np.array([[1.0, -2.0], [3.0, -4.0]])
A = np.maximum(0.0, M)
```

**操作**：`(2,2)` 矩阵每个元素独立过 ReLU，输出 `(2,2)`——**形状不变、逐元素**。负的 $-2,-4$ 归零，正的 $1,3$ 保留。
**可调参数**：任意形状张量均可。**这正是激活能"无缝插入"任何层之后的原因。**
**对应数学**：主线"激活是逐元素的，不改变形状"。**卷积/全连接的输出过激活，形状完全一致。**

## 边界声明：这套代码能做什么，不能做什么

1. **数值导数 ≠ 自动求导**。这里手写中心差分是为了"看导数长什么样"；深度学习用 `loss.backward()`（自动求导，§2.2.3.5）——数值求导太慢，只作验证。
2. **`np.maximum(0.0, z)` 是"整块" ReLU**。PyTorch 的 `F.relu` 内部有更精细的梯度处理（原点处取 0）。手写版展示数学，框架版更工程。
3. **选择激活要看任务**：隐藏层默认 ReLU 家族（保梯度），输出层看任务（二分类 Sigmoid、多分类 Softmax、回归无激活/Tanh）。**没有"最好"的激活，只有"匹配"的激活。**
4. **Sigmoid/Tanh 的饱和问题依然存在**：即使隐藏层用 ReLU 避开梯度消失，输出层的 Sigmoid 仍可能饱和（概率接近 0/1 时梯度趋 0）。这是"最后一层"的固有代价。
