# 习题：激活函数——ReLU、Sigmoid、Tanh

## 第一组：概念检验

**1.1（单选）** 对 $z = -5$，ReLU、Sigmoid、Tanh 的输出分别是（约）：
- A. $0$、$0.007$、$-0.9999$
- B. $-5$、$0.993$、$0.9999$
- C. $0$、$0.993$、$-0.9999$
- D. $-5$、$0.007$、$0.9999$

**1.2（判断并说明）** "Sigmoid 和 Tanh 都有两端饱和的问题，导致梯度消失，所以现代深度学习完全不用它们。" 这句话对吗？

**1.3（填空）** ReLU 的定义是 $\max(0, z)$，它的值域是 $\_\_\_$，正区间导数为 $\_\_\_$；Sigmoid 值域是 $\_\_\_$，Tanh 值域是 $\_\_\_$ 且是____中心（零/非零）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算 $\text{ReLU}([2,-1,0])$、$\sigma(1)$、$\tanh(0)$，用 NumPy 验证。

**2.2（代码验证）** 验证 Sigmoid 与 Tanh 的关系 $\tanh(z) = 2\sigma(2z) - 1$：取 5 个 $z$ 值，比较两边。

**2.3（动手理解）** 用数值差分验证 $\sigma'(z) = \sigma(z)(1-\sigma(z))$ 在 $z=2$ 处成立；再验证 ReLU 在正区间的导数为 1。

## 第三组：DL 延伸

**3.1（场景判断）** 一个二分类模型，输出层之前得到一个 logit $z = -2.5$。用 Sigmoid 后，模型预测"正类"概率是多少？这个数该怎么解读？

**3.2（场景分析）** 工程师把隐藏层的 Sigmoid 全部换成 ReLU 后，深层网络训练明显变快、loss 下降更顺。请用"梯度消失"与"ReLU 正区间导数为 1"解释为什么。

---

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：$\text{ReLU}(-5)=\max(0,-5)=0$；$\sigma(-5)=\frac{1}{1+e^5}\approx0.0067$；$\tanh(-5)\approx-0.9999$（负数 → 接近 -1）。
- **点拨**：C 的 $\sigma(-5)=0.993$ 是 $\sigma(5)$（符号记反）；B/D 的 ReLU 输出 $-5$ 是把"归零"记成"原样"。**ReLU 对负数是 0，Tanh 对负数输出负数（对称）。**

**1.2 不对。**
- **思路**：Sigmoid/Tanh 确实有饱和问题，但"完全不用"是错的。(1) Sigmoid 仍是**二分类输出层**的标准（出概率）；(2) **门控机制**（LSTM 的门、注意力里的门控）用 Sigmoid；(3) Tanh 用于**对称输出**（生成模型、RNN 候选状态）。它们只是"退出隐藏层"，不是"退出深度学习"。
- **点拨**：**"退出舞台中央 ≠ 退场"。** 选择激活 = 值域匹配 + 梯度行为权衡——隐藏层要梯度（ReLU），输出层要值域（Sigmoid）。

**1.3 答案：$[0,\infty)$；$1$；$(0,1)$；$(-1,1)$；零。**
- **思路**：ReLU 值域非负、正区间导数为 1；Sigmoid 值域 $(0,1)$；Tanh 值域 $(-1,1)$ 且零中心。
- **点拨**：**"Tanh 是零中心的 Sigmoid"**（$\tanh(z)=2\sigma(2z)-1$）——零中心缓解了后层梯度同号振荡。

### 第二组

**2.1**
$\text{ReLU}([2,-1,0]) = [2, 0, 0]$；$\sigma(1)=\frac{1}{1+e^{-1}}\approx0.731$；$\tanh(0)=0$。
```python
import numpy as np
z = np.array([2.,-1.,0.])
print(np.maximum(0,z))            # [2. 0. 0.]
print(1/(1+np.exp(-1)))           # 0.731
print(np.tanh(0.))                # 0.0
```
- **思路**：逐函数代入。
- **点拨**：$\tanh(0)=0$、$\sigma(0)=0.5$——**"零中心"的差别在 0 处可见**。

**2.2**
```python
z = np.array([-2.,-1.,0.,1.,2.])
lhs = np.tanh(z)
rhs = 2*(1/(1+np.exp(-2*z))) - 1
print(np.allclose(lhs, rhs))    # True
```
- **思路**：$\tanh(z) = \frac{e^z-e^{-z}}{e^z+e^{-z}} = 2\sigma(2z)-1$——Tanh 是 Sigmoid 的"拉伸+平移"。
- **点拨**：这个恒等式说明两者同族：**Tanh = 2×Sigmoid(2z) − 1**。记住它，三个函数只记两个公式即可。

**2.3**
```python
z = 2.0
sig = lambda t: 1/(1+np.exp(-t))
num = (sig(z+1e-6) - sig(z-1e-6)) / (2e-6)
theory = sig(z)*(1-sig(z))
print(np.isclose(num, theory))   # True
# ReLU 在正区间的导数是 1
relu = lambda t: max(0.0, t)
print(np.isclose((relu(1+1e-6)-relu(1-1e-6))/2e-6, 1.0))   # True
```
- **思路**：数值差分验证导数公式。Sigmoid 导数 $\le0.25$（衰减），ReLU 正区间导数恒 1（不衰减）。
- **点拨**：**这就是 ReLU 胜出的数值证据：Sigmoid 把梯度乘上 $\le0.25$，深层连乘迅速消失；ReLU 乘 1，原样通过。**

### 第三组

**3.1 答案：概率 $\approx \sigma(-2.5) = \frac{1}{1+e^{2.5}} \approx 0.076$，即约 7.6%。模型认为"正类"概率很低，判为负类（阈值 0.5）。**
- **思路**：$\sigma(-2.5)\approx0.0759$。Sigmoid 把负 logit 压成小于 0.5 的概率。
- **点拨**：**Sigmoid 把"得分"翻译成"概率"**。$z<0$ 不代表概率为 0，只是小于 50%。这是"分数 vs 概率"的经典区分（§4 概率论严格化）。

**3.2 思路**
- 换成 ReLU 前（Sigmoid 隐藏层）：每层反向传播乘 $\sigma'(z)\le0.25$，深层网络梯度逐层衰减 → **梯度消失**，浅层学不到 → loss 难降。
- 换成 ReLU 后：正区间导数为 1，梯度**原样穿过每一层**，不再衰减 → 深层可训，loss 顺畅下降。
- **点拨**：这就是 2012 年 ReLU 取代 Sigmoid 的工程原因（§2.2.3.3/§2.3.6.4 历史）。**"训不动"先怀疑激活的梯度行为**——这是深度学习工程师的诊断第一课。
