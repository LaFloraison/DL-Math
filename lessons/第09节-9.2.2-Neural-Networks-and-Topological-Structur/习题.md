# 习题：接线图是可能性，权重是现实性

## 第一组：概念检验

**1. 判断题并说明理由**："神经网络训练完成后，它的拓扑（接线图）发生了显著改变——因为权重都被更新了。"

**2. 多选题**：下面哪些属于"网络拓扑"的组成成分？
- (A) 神经元的个数
- (B) 节点如何排列成层
- (C) 权重矩阵的具体数值
- (D) 层与层之间的连接方式

**3. 简答**：教材说"网络的形状决定它能解决哪类问题"。请用自己的话解释：为什么"结构"比"权重数值"更能划出能力边界？

### 解答与思路点拨

**1. 错误。** 训练改变的是**权重**（每条接线的数值），不是**拓扑**（谁连着谁、几层、每层多宽）。接线图在训练全程不变——这正是本节代码现场验证的结论（`adj0 == adj1` 为 True）。选"正确"的读者把"权重在变"错当成了"结构在变"——两个概念在 §9.2.2 被严格分开：权重是度量（可变形），拓扑是结构（不变量）。

**2. (A)(B)(D)。** (C) 权重矩阵是"列车"不是"铁轨"——它是训练中变化的量，不属于拓扑。教材定义的三元组是：节点数量、层次布局、连接模式。

**3.** 权重只能在"接线图允许的范围"内调节。一个单隐藏层、每层 1 个神经元的网络（`[2,1,1]`），无论权重怎么调，都表达不出需要弯曲边界的函数（如 XOR）——因为接线图里根本没有足够的节点/层来组成那样的形状。结构划定了"可能表达的函数空间"，权重只是在这个空间里挑一个具体的函数。所以"接线图 = 可能性边界，权重 = 现实性"。

## 第二组：计算实践

**4. 手算**：两个网络拓扑：(i) `[2, 3, 1]`，(ii) `[2, 2, 2, 1]`。分别计算它们的节点总数与连接总数（全连接）。哪一个"表达能力"潜力更大？为什么？

**5. 代码验证**：把两个拓扑喂给本节的 `build_adjacency`，核对你的手算；再打印两个网络的接线图，比较它们是否相同（注意：不同拓扑的邻接表**一定**不同——这正是"拓扑指纹"）。

### 解答与思路点拨

**4.** (i) 节点数 `2+3+1=6`，连接数 `2×3 + 3×1 = 9`。(ii) 节点数 `2+2+2+1=7`，连接数 `2×2 + 2×2 + 2×1 = 10`。潜力更大的是 (ii)——它有三层变换，可以逐级组合特征（层级式特征学习），能表达更复杂的决策边界。**陷阱**：别只看连接数 10 > 9 就下结论——深度带来的"逐级抽象"能力，是单纯加宽度难以替代的（这正是 §9.3.1.1 与 §9.3.1.2 的分工）。

**5.** 验证脚本（复用 9.2.2 的 `build_adjacency`）：

```python
def build_adjacency(layers):
    offsets, acc = [], 0
    for w in layers:
        offsets.append(acc); acc += w
    adj = {i: set() for i in range(acc)}
    for L in range(len(layers)-1):
        for u in range(layers[L]):
            for v in range(layers[L+1]):
                a, b = offsets[L]+u, offsets[L+1]+v
                adj[a].add(b); adj[b].add(a)
    return adj, acc

for ls in ([2,3,1],[2,2,2,1]):
    adj, n = build_adjacency(ls)
    edges = sum(len(v) for v in adj.values())//2
    print(f"{ls}: 节点={n}, 连接={edges}")
```

```text
[2, 3, 1]: 节点=6, 连接=9
[2, 2, 2, 1]: 节点=7, 连接=10
```

思路点拨：两个邻接表完全不同——`[2,3,1]` 的邻接表规模小、结构简单；`[2,2,2,1]` 有四个层次。邻接表就是网络拓扑的精确指纹，两个不同拓扑绝不产生相同邻接表。

## 第三组：DL 延伸

**6. 场景判断**：一个团队要解决一个问题：把两个交缠在一起的螺旋类别分开。他们先在 `[2, 4, 1]` 上训练，失败了；然后把隐藏层加宽到 `[2, 400, 1]`，仍然失败。工程师打算继续加宽。请用拓扑观点指出：只加宽、不加层，这条路很可能走不通——为什么？

**7. 思考题**：结合 §9.2.1 的"连续映射保持拓扑"，解释为什么一个**纯线性**网络（权重任意调）无法把"环形分布"和"实心盘分布"两类数据分开；并说说引入非线性激活后，这个限制是如何被"解绑"的。

### 解答与思路点拨

**6.** 螺旋类别之间的分界需要"卷曲"的决策边界。宽度（节点数）只能增加边界的**精细程度**，难以根本改变边界所需的**卷曲结构**——那需要多层逐级弯曲（深度）来达成。§9.3.1.1 的 Figure 9.2 正演示了这一点：从 1 层到 3 层，边界从"简单"到"精细复杂"，靠的是层数而非每层的节点数。只加宽不加层，是在同一层"可能性边界"内反复调参，难以突破结构极限。

**7.** 环形分布与实心盘分布不同胚（环形有环、盘没有）。线性映射是连续映射，连续映射保持拓扑——因此任何线性组合都无法把这两个不同胚的分布"分离到不同输出区域"，线性分类必败。非线性激活（如 ReLU）使映射不再是"纯线性连续"，它允许把特征空间折叠、拉升、切开——从而打破"连续映射保持拓扑"的束缚，让不同胚的类别可以被分开。这就是深度网络"非线性 + 深度"双重拓扑改写的意义。
