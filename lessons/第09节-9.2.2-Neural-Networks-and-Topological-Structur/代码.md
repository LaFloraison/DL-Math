# 代码：训练是变形，接线图是不变量

主线里我们把训练翻译成了拓扑语言：**权重是"被连续变形"的东西，接线图是"不变"的东西。** 本节代码把这个断言做成一个可运行实验——训练一个 2-2-1 的小网络解决异或 (XOR) 问题，然后当场检查两件事：

1. **权重**：训练前后是否变化？（应该：变，而且变了才有学习。）
2. **接线图（拓扑）**：训练前后是否一致？（应该：纹丝不动——这是"拓扑不变量"。）

脚本依赖 NumPy 的矩阵乘法、逐元素运算和随机数。所有结构量（层宽、连接数、邻接表）由我们自己手写构建，不调黑盒。

---

## 层一：完整脚本

```python
import numpy as np

def build_adjacency(layers):
    """拓扑指纹之接线图：层宽表 → 邻接表（每层节点全连到下一层）。"""
    offsets, acc = [], 0
    for w in layers:
        offsets.append(acc); acc += w
    adj = {i: set() for i in range(acc)}
    for L in range(len(layers)-1):
        for u in range(layers[L]):
            for v in range(layers[L+1]):
                a, b = offsets[L]+u, offsets[L+1]+v
                adj[a].add(b); adj[b].add(a)
    return adj, acc

def sigmoid(z):
    """激活函数：把实数压进 (0,1)。"""
    return 1.0/(1.0+np.exp(-z))

def forward(W1, b1, W2, b2, X):
    """前向：X(4×2) → 隐藏(4×2) → 输出(4×1)。"""
    h = sigmoid(X @ W1 + b1)
    y = sigmoid(h @ W2 + b2)
    return h, y

def train_step(W1, b1, W2, b2, X, Y, eta=1.0):
    """一步全批量梯度下降：反向传播更新四个参数。"""
    h, y = forward(W1, b1, W2, b2, X)
    dy = (y - Y) * y * (1 - y)                 # 输出层误差（MSE 的梯度）
    dh = (dy @ W2.T) * h * (1 - h)             # 经 W2 传回隐藏层
    W2 -= eta * h.T @ dy
    b2 -= eta * np.sum(dy, axis=0, keepdims=True)
    W1 -= eta * X.T @ dh
    b1 -= eta * np.sum(dh, axis=0, keepdims=True)
    return W1, b1, W2, b2

# ---- 数据：异或 XOR 的四个样本 ----
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
Y = np.array([[0],[1],[1],[0]], dtype=float)

layers = [2, 2, 1]                            # 拓扑：输入2 → 隐藏2 → 输出1
adj0, n0 = build_adjacency(layers)            # 训练前的接线图
n_conn = sum(len(v) for v in adj0.values()) // 2
np.random.seed(0)
W1 = np.random.randn(2,2)*0.5                 # 权重随机初始化
b1 = np.random.randn(1,2)*0.1                 # 偏置也取小的随机值（打破对称）
W2 = np.random.randn(2,1)*0.5
b2 = np.random.randn(1,1)*0.1

print(f"拓扑：层宽={layers}, 节点数={n0}, 连接数={n_conn}")
print(f"训练前权重 W1 = {np.round(W1,3).tolist()}")
W1_before = W1.copy()                         # 留一份"变形前"的权重快照
for step in range(1, 2001):
    W1, b1, W2, b2 = train_step(W1, b1, W2, b2, X, Y)
    if step in (1, 1000, 2000):
        _, y = forward(W1, b1, W2, b2, X)
        print(f"第{step:4d}步后预测 = {np.round(y.ravel(),3)}")

adj1, n1 = build_adjacency(layers)            # 训练后的接线图
print(f"权重是否变化    : {not np.allclose(W1, W1_before)}   # 是——所以才在学")
print(f"接线图是否不变  : {adj0 == adj1}，节点数 {n0}->{n1}，连接数不变")
print(f"连接数（训练前后一致）= {n_conn}")
```

运行输出（Python 3.11 + NumPy）：

```text
拓扑：层宽=[2, 2, 1], 节点数=5, 连接数=6
训练前权重 W1 = [[0.882, 0.2], [0.489, 1.12]]
第   1步后预测 = [0.54  0.546 0.561 0.564]
第1000步后预测 = [0.116 0.88  0.879 0.139]
第2000步后预测 = [0.054 0.951 0.95  0.053]
权重是否变化    : True   # 是——所以才在学
接线图是否不变  : True，节点数 5->5，连接数不变
```

看懂这组输出：预测从第 1 步的"四堆 0.5"（什么都不懂）慢慢收敛到第 2000 步的"0.05, 0.95, 0.95, 0.05"（把异或的四个样本分对了）——**权重变了，所以在学习**；但接线图 `adj0 == adj1` 为 `True`，5 个节点、6 条连接一根没动——**拓扑没变**。这就是"训练是变形，接线图是不变量"的现场证据。

## 层二：分步逐函数拆解

### 步骤 1：`build_adjacency` —— 接线图的指纹

```python
def build_adjacency(layers):
    offsets, acc = [], 0
    for w in layers:
        offsets.append(acc); acc += w
    adj = {i: set() for i in range(acc)}
    for L in range(len(layers)-1):
        for u in range(layers[L]):
            for v in range(layers[L+1]):
                a, b = offsets[L]+u, offsets[L+1]+v
                adj[a].add(b); adj[b].add(a)
    return adj, acc
```

**做什么**：把层宽表 `[2,2,1]` 转成邻接表 `adj`——键是全局节点编号，值是该节点的邻居集合。这是网络"接线图"的精确数据结构。
**操作**：`offsets` 给每层第一个节点分配全局编号（层 0 从 0 起，层 1 从 2 起，层 2 从 4 起）；双层循环把第 L 层的每个节点与第 L+1 层的每个节点两两相连（全连接），无向图双向登记。
**输入**：`layers`——每层的节点数列表。
**输出**：`(adj, acc)`——邻接表字典、总节点数。
**可调参数**：`layers` 就是拓扑本身。改成 `[2,4,1]` 或 `[2,2,2,1]`，接线图立即变化——但注意：**训练过程中这个函数不会被再调用改结构**，所以它的输出天然是一个"不变量"。
**对应数学**：主线定义块里的"节点 + 分层 + 连接"三元组。训练前后各调用一次，`adj0 == adj1` 就是在验证拓扑不变。

---

### 步骤 2：`sigmoid` 与 `forward` —— 前向传播

```python
def sigmoid(z):
    return 1.0/(1.0+np.exp(-z))

def forward(W1, b1, W2, b2, X):
    h = sigmoid(X @ W1 + b1)
    y = sigmoid(h @ W2 + b2)
    return h, y
```

#### `sigmoid` —— 挤压激活函数

**操作**：`np.exp(-z)` 逐元素算指数，再逐元素做 $1/(1+e^{-z})$。输出恒在 (0,1)。
**输入**：任意形状数组 `z`。
**输出**：同形状数组，每个元素在 (0,1)。
**可调参数**：无——固定公式。想用 ReLU 只需替换这行（那是 §9.3.4 的内容）。
**对应数学**：激活函数的非线性是"连续但非线性的变形"——它让网络能表达数学拓扑之外更丰富的内容（§9.2.1 桥接段讲过，非线性是拓扑的解绑器）。

#### `forward` —— 把输入推过两层

**操作**：`X @ W1 + b1` 是矩阵乘法加偏置（线性变换），`sigmoid(...)` 加非线性，得到隐藏层 `h`；再对 `h` 重复一次得到输出 `y`。
**输入**：`W1`(2×2)、`b1`(1×2)、`W2`(2×1)、`b2`(1×1)、`X`(4×2)。
**输出**：`h`(4×2)、`y`(4×1)。
**可调参数**：无（四个参数都是"被训练"的对象，不是可调开关）。
**对应数学**：$h=\sigma(W_1 x+b_1)$，$y=\sigma(W_2 h+b_2)$——一个 2-2-1 网络的全过程。§9.3.1.1 会把它推广到任意层数。

---

### 步骤 3：`train_step` —— 一步梯度下降

```python
def train_step(W1, b1, W2, b2, X, Y, eta=1.0):
    h, y = forward(W1, b1, W2, b2, X)
    dy = (y - Y) * y * (1 - y)
    dh = (dy @ W2.T) * h * (1 - h)
    W2 -= eta * h.T @ dy
    b2 -= eta * np.sum(dy, axis=0, keepdims=True)
    W1 -= eta * X.T @ dh
    b1 -= eta * np.sum(dh, axis=0, keepdims=True)
    return W1, b1, W2, b2
```

#### `train_step` —— 反向传播 + 参数更新

**做什么**：用全部 4 个样本（全批量）算梯度，把四个参数各挪一步——这就是"训练这个变形"的最小单元。
**操作**：
- `dy`：输出层误差。MSE 损失对输出的导数乘上 sigmoid 的导数 $y(1-y)$（链式法则的一环）。
- `dh`：把误差经 `W2.T` 传回隐藏层，再乘隐藏层 sigmoid 导数——**这一步就是"反向传播"**，误差从输出一路传回隐藏。
- 更新：`W2 -= eta * h.T @ dy` 等四行，用"输入×误差"的梯度下降。
**输入**：四个参数、数据 `X`(4×2)、标签 `Y`(4×1)、学习率 `eta`。
**输出**：更新后的四个参数。
**可调参数**：`eta`（学习率）是唯一旋钮——取太大网络震荡不收敛，取太小收敛极慢。改成 `0.3` 试试：第 100 步的预测会差得多，因为还没收敛——**权重更新的幅度变了，但接线图依旧不变**。
**对应数学**：梯度下降 $\theta \leftarrow \theta - \eta\nabla_\theta L$。这个"θ"只含权重——拓扑不在优化变量里，所以训练天然不动拓扑。

### 步骤 4：训练循环与验证

```python
for step in range(1, 101):
    W1, b1, W2, b2 = train_step(W1, b1, W2, b2, X, Y)
    if step in (1, 100):
        _, y = forward(W1, b1, W2, b2, X)
        print(f"第{step:3d}步后预测 = {np.round(y.ravel(),3)}")
adj1, n1 = build_adjacency(layers)
```

**做什么**：2000 步梯度下降后重新构建接线图，与前对比。
**操作**：`build_adjacency(layers)` 用**同一个** `layers` 重算——只要结构参数没被改动，输出必然相同；`adj0 == adj1` 直接比较两个字典。
**输入**：无新参数（复用前面的全局状态）。
**输出**：打印的预测序列 + 布尔结果。
**可调参数**：训练步数 2000 可改——但无论改成多少，只要 `layers` 不动，拓扑结论永远不变。
**对应数学**：$(\beta_0, \beta_1)$ 那种"不变量"在网络的对应物——这里的不变量就是接线图本身。**2000 步训练改写了所有权重的数值，接线图一个比特都没变。**

## 边界声明：这套代码能做什么，不能做什么

1. **它只演示了"训练不动拓扑"，没有说"拓扑决定一切"**。这里 2000 步就学会 XOR，是因为 2-2-1 的接线图恰好允许表达 XOR；换一个拓扑（如 `[2,1,1]`——隐藏层只有 1 个神经元），无论训多少步都学不会——因为接线图里根本装不下 XOR 所需的弯曲边界。这就是"拓扑设定可能性边界"的下一站实验，值得你自己跑一遍。
2. **反向传播这里是最简形式**。只处理 2-2-1、sigmoid、全批量 MSE，无动量、无批次、无正则。真实网络（§9.3.1.x）要处理任意层宽与这些工程细节——但那不改变"权重变、拓扑不变"的结论。
3. **"接线图不变"不意味"结构完全没变"**。若训练过程用了 dropout、剪枝、或动态添加神经元，结构会变——那是另一种"拓扑学习"（§9.3 的边界之外）。本脚本假定最标准的固定拓扑训练。
