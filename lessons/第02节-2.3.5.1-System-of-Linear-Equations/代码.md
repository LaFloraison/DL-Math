# 代码：三种方法解同一个方程组——并体验"不可逆时"的报错

主线里我们用 $X = A^{-1}B$ 解了 $\begin{cases}x+2y=5\\3x+4y=6\end{cases}$，得 $(-4, 4.5)$。这一节用 NumPy 演示**三种解法**（`solve`、`inv`、`lstsq`），并演示"奇异方程组"的报错与"超定方程组"的最小二乘解。

---

## 层一：完整脚本

```python
import numpy as np                         # NumPy：linalg

# ---- ① 系数矩阵与常数向量（教材例子）----
A = np.array([[1.0, 2.0], [3.0, 4.0]])
b = np.array([5.0, 6.0])

# ---- ② 解法一：np.linalg.solve（推荐）----
x1 = np.linalg.solve(A, b)
print("solve:", x1)                        # [-4.   4.5]

# ---- ③ 解法二：显式求逆 A⁻¹ b ----
Ainv = np.linalg.inv(A)
x2 = Ainv @ b
print("inv 法:", x2, "| 与 solve 一致:", np.allclose(x1, x2))

# ---- ④ 解法三：最小二乘（超定/不可逆也能用）----
x3, *_ = np.linalg.lstsq(A, b, rcond=None)
print("lstsq:", x3, "| 一致:", np.allclose(x1, x3))

# ---- ⑤ 验证解：Ax = b ----
print("A@x 应等于 b:", np.allclose(A @ x1, b))      # True

# ---- ⑥ 奇异方程组：det=0 ----
S = np.array([[1.0, 1.0], [2.0, 2.0]])     # 两个方程成比例
try:
    np.linalg.solve(S, np.array([2.0, 3.0]))   # 无解（x+y=2 与 2x+2y=3）
except np.linalg.LinAlgError as e:
    print("奇异方程组报错:", e)
```

运行输出（Python 3.11 + NumPy）：

```text
solve: [-4.   4.5]
inv 法: [-4.   4.5] | 与 solve 一致: True
lstsq: [-4.   4.5] | 一致: True
A@x 应等于 b: True
奇异方程组报错: Matrix is singular to working precision.
```

下面拆开看。

## 层二：分步逐函数拆解

### 步骤 1：定义方程组

```python
A = np.array([[1.0, 2.0], [3.0, 4.0]])
b = np.array([5.0, 6.0])
```

**做什么**：把 $x+2y=5$、$3x+4y=6$ 翻译成 $A\mathbf{x}=\mathbf{b}$。$A$ 是系数矩阵、$b$ 是常数向量。
**可调参数**：任何方程组都这样翻译；$A$ 的行数 = 方程数，列数 = 未知数个数。
**对应数学**：主线 $A\mathbf{x}=\mathbf{b}$ 的矩阵表示。

### 步骤 2：`np.linalg.solve(A, b)` —— 推荐解法

#### `np.linalg.solve(A, b)` —— 解方阵方程组

**操作**：用 LU 分解（§2.6.1）求解 $A\mathbf{x}=\mathbf{b}$。内部**不显式求逆**，更快更稳。
**输入**：`A`（`(n,n)`）、`b`（`(n,)`）。
**输出**：`(n,)` 解向量 `[-4., 4.5]`。
**可调参数**：$A$ 必须方阵且可逆，否则 `LinAlgError`。$b$ 可以是 `(n, k)` 矩阵（同时解多个右端）。
**对应数学**：主线 $X=A^{-1}B$ 的"数值实现"。**工程上解方程组永远用 `solve`，不用 `inv`。** 这是本节最重要的工程习惯。

### 步骤 3：`np.linalg.inv(A) @ b` —— 教科书解法

**操作**：显式求逆再乘 $b$：$x = A^{-1}\mathbf{b}$。结果与 `solve` 一致。
**可调参数**：理论上等价，数值上更慢更不稳定（病态时误差放大）。
**对应数学**：主线 $X = A^{-1}B$——教材的方法。**看得懂，但别在工程里用。** 这正是"逆矩阵是概念、`solve` 是工具"的实例。

### 步骤 4：`np.linalg.lstsq(A, b, rcond=None)` —— 最通用的解法

**操作**：最小二乘解 $\min\|A\mathbf{x}-\mathbf{b}\|$。对可逆方阵，它返回精确解；对奇异/超定方程组，它返回"最接近"的解。
**输入**：`A`（任意形状）、`b`、`rcond=None`（推荐）。
**输出**：`x`（解）、残差等（用 `*_` 丢弃）。
**可调参数**：`rcond` 控制奇异值截断；对病态矩阵，`rcond` 大一点更稳。
**对应数学**：主线"超定方程组的最小二乘"（§2.3.4.6 的伪逆思想）。**它不要求 $A$ 可逆——是"退化情形"的兜底解法。**

### 步骤 5：验证解

```python
np.allclose(A @ x1, b)    # True
```

**操作**：把解代回原方程，验证 $A\mathbf{x}=\mathbf{b}$。**这是"解对了没有"的唯一判据。**
**可调参数**：浮点下有舍入，用 `allclose` 而非 `==`。
**对应数学**：主线"验证答案"——粮仓管理员拿到 $(-4, 4.5)$ 后，也要代回账本核对。

### 步骤 6：奇异方程组的报错

```python
S = np.array([[1.,1.],[2.,2.]])
np.linalg.solve(S, [2.,3.])    # LinAlgError
```

**操作**：$S$ 两行成比例，$\det=0$——方程组 $x+y=2$、$2x+2y=3$ **无解**（矛盾方程）。`solve` 报 "Matrix is singular"。
**可调参数**：把右端改成 `[2.,4.]`（相容，$2x+2y=4$ 是同一方程），则**无穷多解**——`solve` 仍会因奇异而报错（数值上无法唯一确定）。
**对应数学**：主线"$\det=0$：无解或无穷多解"。**`solve` 报错，正是"无法唯一反推"的代码语言。**

## 边界声明：这套代码能做什么，不能做什么

1. **`solve` 只处理"方阵且可逆"**。现实中大量方程组是超定（样本>特征）或欠定（特征>样本）——用 `lstsq`（最小二乘）或 `pinv`（§2.6.3 SVD）。看到"不可逆"，别慌，那是"转最小二乘"的信号。
2. **病态矩阵（$\det$ 接近 0）时，`solve` 能跑但结果不可信**。查 `np.linalg.cond(A)`：条件数巨大说明解对输入误差极其敏感。**先查条件数，再信解。**
3. **"无解"和"无穷多解"都触发奇异**——`LinAlgError` 不区分两者。要看情况用秩（`matrix_rank`）与相容性判断：增广矩阵秩 < 系数矩阵秩 ⇒ 无解；两秩相等且 < n ⇒ 无穷多解。
4. **深度学习几乎不"解方程组"**——它用梯度下降（§2.2.3.5）逼近最优参数，而不是解 $A\mathbf{x}=\mathbf{b}$。但"从结果反推原因"的思想、最小二乘、伪逆，处处沿用这套矩阵语言。
