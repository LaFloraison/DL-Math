# 习题：线性方程组

## 第一组：概念检验

**1.1（单选）** 方程组 $\begin{cases} x + 2y = 5 \\ 3x + 4y = 6 \end{cases}$ 的矩阵形式是 $A\mathbf{x} = \mathbf{b}$，其中 $\mathbf{x}$ 是：
- A. $\begin{bmatrix} 1 \\ 2 \end{bmatrix}$
- B. $\begin{bmatrix} x \\ y \end{bmatrix}$
- C. $\begin{bmatrix} 5 \\ 6 \end{bmatrix}$
- D. $\begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$

**1.2（判断并说明）** "只要 $\det(A) = 0$，方程组 $A\mathbf{x}=\mathbf{b}$ 就一定无解。" 这句话对吗？

**1.3（填空）** 方阵 $A$ 可逆时，$A\mathbf{x}=\mathbf{b}$ 的唯一解是 $\mathbf{x} = \_\_\_$；实际数值求解应优先用 `np.linalg.____` 而非显式求逆。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算并验证方程组 $\begin{cases} 2x - y = 1 \\ x + 3y = 11 \end{cases}$ 的解（可用代入法或矩阵法），再用 `np.linalg.solve` 验证。

**2.2（代码验证）** 验证"可逆矩阵必有唯一解"：随机生成一个 $3\times3$ 可逆矩阵 $A$ 和向量 $\mathbf{b}$，解 $A\mathbf{x}=\mathbf{b}$，代回验证 $A\mathbf{x}=\mathbf{b}$。

**2.3（动手理解）** 构造"无穷多解"的方程组（如 $x+y=2$ 与 $2x+2y=4$），用 `lstsq` 求最小二乘解，观察它给的是哪种"代表解"，并解释为什么 `solve` 会报错。

## 第三组：DL 延伸

**3.1（场景判断）** 线性回归想解 $X\mathbf{w}=\mathbf{y}$，但 $X$ 是 $1000\times10$（样本远多于特征，超定）。能否用 `np.linalg.solve`？应该用什么？为什么？

**3.2（场景分析）** 正规方程 $\mathbf{w} = (X^\top X)^{-1}X^\top\mathbf{y}$ 里，$(X^\top X)^{-1}$ 存在的前提是什么？若 $X^\top X$ 不可逆（如特征完全重复），现实中怎么办？

---

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：$\mathbf{x} = \begin{bmatrix}x\\y\end{bmatrix}$ 是未知数向量。A 是 $A$ 的某列，C 是 $\mathbf{b}$，D 是 $A$。
- **点拨**：$A\mathbf{x}=\mathbf{b}$ 里三个角色的分工：系数矩阵、未知向量、常数向量。记住"$A$ 是机器、$\mathbf{x}$ 是输入、$\mathbf{b}$ 是输出"。

**1.2 不对。**
- **思路**：$\det(A)=0$ 意味着"无唯一解"——可能是**无解**，也可能是**无穷多解**。例：$x+y=2$、$2x+2y=4$（$\det=0$）有无数解；$x+y=2$、$x+y=3$（$\det=0$）无解。
- **点拨**：$\det=0$ ⟺ "解不唯一"（无解或无穷多解）；$\det\neq0$ ⟺ 唯一解。区分"无解"与"无穷多解"要看方程组是否相容（常数向量是否在 $A$ 的列空间里）。

**1.3 答案：$A^{-1}\mathbf{b}$；`solve`。**
- **思路**：唯一解 $\mathbf{x}=A^{-1}\mathbf{b}$；数值上用 `np.linalg.solve`（LU 分解）更快更稳。
- **点拨**："理论用逆、工程用 solve"是本节的核心工程智慧。

### 第二组

**2.1**
由 $2x-y=1$ 得 $y=2x-1$，代入 $x+3(2x-1)=11$：$x+6x-3=11$，$7x=14$，$x=2$，$y=3$。
```python
import numpy as np
A = np.array([[2.,-1.],[1.,3.]])
b = np.array([1.,11.])
print(np.linalg.solve(A, b))    # [2. 3.]
```
- **思路**：代入消元或矩阵法都可；`solve` 验证。
- **点拨**：解出来**代回验证**——$2(2)-3=1$、$2+3(3)=11$ 都成立。永远验证。

**2.2**
```python
A = np.random.rand(3,3) + 4*np.eye(3)   # 加 4I 保证可逆
b = np.random.rand(3)
x = np.linalg.solve(A, b)
print(np.allclose(A @ x, b))            # True
```
- **思路**：随机矩阵几乎必然可逆（为保险加 $4I$ 增大 $\det$）；解出后代回验证。
- **点拨**：**"解正确 ⟺ 代回成立"**——这是线性方程组的唯一判据。

**2.3**
```python
S = np.array([[1.,1.],[2.,2.]])
x, *_ = np.linalg.lstsq(S, np.array([2.,4.]), rcond=None)
print(x)   # 例如 [0.4 1.6] 之类，满足 x+y=2 的某个代表解
```
- **思路**：$2x+2y=4$ 与 $x+y=2$ 是同一方程——无穷多解（$y=2-x$ 的所有点）。`lstsq` 给出其中"范数最小"的一个代表解。`solve` 会因奇异报错（数值上无法选唯一解）。
- **点拨**：**"无穷多解"不是 bug，是"信息不足"**。`lstsq` 用"范数最小"这个额外标准挑一个代表——这正是"不可逆时退而求其次"的哲学。§2.6.3 SVD/伪逆给出一般理论。

### 第三组

**3.1 思路**
- 不能直接用 `solve`——它要求方阵，$X$ 是 $1000\times10$（非方阵）。
- 应该用 `np.linalg.lstsq(X, y)`（最小二乘）或正规方程 $\mathbf{w}=(X^\top X)^{-1}X^\top\mathbf{y}$（先变成 $10\times10$ 方阵）。超定方程组"严格无解"，最小二乘找"误差最小"的近似解——这正是线性回归的本质。
- **点拨**：**"样本多于未知数"是常态，"精确解"是理想**。机器学习的"拟合"= 解一个超定方程组的"近似解"。$1000$ 个样本、$10$ 个特征，就是 $1000$ 个方程去"逼近"一个 $10$ 维的解。

**3.2 思路**
- $(X^\top X)^{-1}$ 存在的前提：$X^\top X$ 可逆（$\det\neq0$），即 $X$ 的**列线性无关**（特征不重复、样本数 $\ge$ 特征数）。若特征完全重复（一列是另一列的倍数），$X^\top X$ 奇异。
- 不可逆时的做法：**岭回归**加 $\lambda I$：$\mathbf{w}=(X^\top X+\lambda I)^{-1}X^\top\mathbf{y}$（$\lambda>0$ 保证可逆）；或**伪逆** $\mathbf{w}=X^{+}\mathbf{y}$（SVD，§2.6.3）。两者都能在退化时给出稳定解。
- **点拨**：**"不可逆"在真实数据里频繁发生**（共线性），正则化/伪逆是标准对策。这也预告了 §2.6.3 SVD 与 §2.3.6.6 正则化的价值。
