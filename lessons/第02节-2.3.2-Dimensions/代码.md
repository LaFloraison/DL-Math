# 代码：学会"读形状"——shape、ndim、size 与 reshape

主线里我们把"维度"拆成三个含义：矩阵维度（$m\times n$）、空间维数、数组 ndim。这一节用 NumPy 把形状语言练熟：`shape`、`ndim`、`size`、`reshape`，并演示"形状 = 语义"。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：形状三件套

# ---- ① 教材例子：3x2 矩阵 ----
B = np.array([[1, 2], [3, 4], [5, 6]])
print("B.shape =", B.shape, "| ndim =", B.ndim, "| size =", B.size)
# (3, 2)  |  2  |  6

# ---- ② 形状 vs 元素数：3x2 与 2x3 元素一样多、形状不同 ----
C = np.array([[1, 2, 3], [4, 5, 6]])
print("B: shape", B.shape, "size", B.size, "| C: shape", C.shape, "size", C.size)

# ---- ③ reshape：改形状不改元素 ----
D = B.reshape(2, 3)                      # (3,2) -> (2,3)
print("B.reshape(2,3) =", D, "形状:", D.shape)
print("元素顺序没变（行优先读取）:", D.flatten())

# ---- ④ 广播前的形状检查：矩阵乘要求内维匹配 ----
W = np.array([[1.0, 2.0, 3.0],           # (2,3)
              [4.0, 5.0, 6.0]])
# B(3,2) @ W(2,3) -> (3,3)，内维 2 对齐
print("B @ W 形状:", (B @ W).shape)      # (3, 3)
```

运行输出（Python 3.11 + NumPy）：

```text
B.shape = (3, 2) | ndim = 2 | size = 6
B: shape (3, 2) size 6 | C: shape (2, 3) size 6
B.reshape(2,3) = [[1 2 3]
 [4 5 6]] 形状: (2, 3)
元素顺序没变（行优先读取）: [1 2 3 4 5 6]
B @ W 形状: (3, 3)
```

## 层二：分步逐函数拆解

### 步骤 1：`B.shape` / `.ndim` / `.size`

```python
B.shape   # (3, 2)
B.ndim    # 2
B.size    # 6
```

#### `ndarray.shape` —— 形状元组

**操作**：返回 `(行数, 列数)` 的元组。`B.shape == (3, 2)`——**"3 by 2"**。
**可调参数**：无。这是数组最核心的属性。
**对应数学**：主线 $B \in \mathbb{R}^{3\times2}$。

#### `ndarray.ndim` —— 轴的个数

**操作**：返回数组是几维：标量 0、向量 1、矩阵 2、张量 3+。`B.ndim == 2`。
**可调参数**：无。
**对应数学**：主线"数组的 ndim"。**注意 `ndim` 与"空间维数"不同**——$3\times2$ 矩阵是 ndim=2 的数组，但它活在 $\mathbb{R}^6$ 里。

#### `ndarray.size` —— 元素总数

**操作**：`size = 行数 × 列数 = 3×2 = 6`。
**可调参数**：无。
**对应数学**：主线"元素总数"。`size` 与 `shape` 的关系：`size = prod(shape)`。

### 步骤 2：形状 vs 元素数

```python
B.shape  (3,2),  size 6
C.shape  (2,3),  size 6
```

**做什么**：$3\times2$ 与 $2\times3$ 元素数相同（都是 6），但形状不同——它们是**不同的矩阵**。
**可调参数**：无。
**对应数学**：主线"形状比大小重要"。**6 个元素可能是 3×2、2×3、1×6、6×1**——同一堆数字，不同形状 = 不同身份。

### 步骤 3：`B.reshape(2, 3)`

#### `ndarray.reshape(rows, cols)` —— 重塑形状

**操作**：把 `(3,2)` 的元素按**行优先**顺序重新排成 `(2,3)`。元素没变、顺序没变（`[1,2,3,4,5,6]`），只是"切法"变了。
**输入**：新形状（元素总数必须不变）。
**输出**：新形状的数组（视图或拷贝，视内存是否连续而定）。
**可调参数**：可用 `-1` 让 NumPy 自动推断（如 `B.reshape(-1)` 拉成一维）。`reshape` 改变"读法"，不改变"数据"。
**对应数学**：主线"形状即语义"的灵活面——同一份数据可以按不同形状组织（展平、加批维等）。

### 步骤 4：矩阵乘的形状检查

```python
W = np.array([[1.,2.,3.],[4.,5.,6.]])    # (2,3)
B @ W    # (3,2) @ (2,3) = (3,3)
```

**做什么**：`B(3,2) @ W(2,3) → (3,3)`。内维 2 对齐。
**可调参数**：若内维不匹配（如 `(3,2) @ (3,3)`），NumPy 直接报 `ValueError: matmul`。**先查 shape 再乘**，是矩阵代码第一纪律。
**对应数学**：主线"形状决定能不能运算"。输出形状 = 左行 × 右列：`(3,2)@(2,3)` 取左的 3、右的 3 → `(3,3)`。

## 边界声明：这套代码能做什么，不能做什么

1. **`reshape` 不改数据顺序，但可能产生"副本"或"视图"**。`reshape` 若内存不连续会返回拷贝；`view`（PyTorch）只允许连续内存。改形状前用 `np.ascontiguousarray` 可以强制连续。这是性能相关的细节。
2. **`shape` 与 `ndim` 不是"空间维数"**。一个 `(512, 768)` 的权重矩阵是 ndim=2 的数组，但它活在 512×768=393216 维的空间里。**"几行几列" ≠ "几维空间"**——这个区分在 §2.2.1.5 和 §2.6 会反复出现。
3. **`size` 大 ≠ 参数多**。矩阵 `size` 是元素总数；"参数数"在深度学习里是所有权重元素之和。一个 `(512,512)` 矩阵有 262144 个参数——shape 决定 size，size 决定显存。
4. **这一节只"读"形状，不"算"运算**。真正的形状推导（广播、矩阵乘的维数规则）在 §2.3.4.3 与 §2.4.4 系统展开。现在先练"读"，马上就能"算"。
