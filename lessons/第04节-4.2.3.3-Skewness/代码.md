# 代码：偏度——让"歪向哪边"变成一个带符号的数字

主线里我们把偏度定义为"标准化三阶矩"：$\text{Skewness}=\mathbb{E}\!\left[\left(\frac{X-\mu}{\sigma}\right)^3\right]$——3 次方保留符号，除以 $\sigma^3$ 消掉量纲，0 表示对称。本课用代码做四件事：

1. **三座山对照**：对称钟、右偏山、左偏山，算各自的偏度，确认符号与方向对应。
2. **收入分布演示**：造一个"穷人很多、富人极少"的右偏样本，看均值 > 中位数 > 众数。
3. **取对数的魔法**：对右偏数据做 $\log(1+x)$，看偏度被拉回 0 附近——为什么深度学习常先取对数。
4. **离群点实验**：给对称数据加一个极端值，看偏度被立方放大成什么样。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：random / mean / std / log1p

def skewness(x):
    """样本偏度：E[((X-μ)/σ)³]。除以 N，与 scipy 的 fisher 偏度一致。"""
    mu = x.mean()
    sigma = x.std()
    return np.mean(((x - mu) / sigma)**3)

np.random.seed(0)

# ---- ① 三座山：正态（对称）、指数（右偏）、正态取负（左偏）----
sym   = np.random.normal(0, 1, 100000)
right = np.random.exponential(1.0, 100000)
left  = -np.random.exponential(1.0, 100000)
print(f"对称分布   偏度 = {skewness(sym):.3f}   # 应接近 0")
print(f"右偏分布   偏度 = {skewness(right):.3f}   # 应为正（≈2 对指数分布）")
print(f"左偏分布   偏度 = {skewness(left):.3f}   # 应为负")

# ---- ② 收入分布：右偏，均值 > 中位数 > 众数 ----
income = np.random.lognormal(mean=3.0, sigma=0.8, size=100000)
mean, median = income.mean(), np.median(income)
hist, edges = np.histogram(income, bins=100)
mode = edges[np.argmax(hist)]             # 直方图最高柱的左边界≈众数
print(f"收入分布: 均值={mean:.1f} 中位数={median:.1f} 众数≈{mode:.1f} 偏度={skewness(income):.3f}")

# ---- ③ 取对数的魔法：log1p 把右偏拉回近似对称 ----
log_income = np.log1p(income)
print(f"log1p 后: 偏度 = {skewness(log_income):.3f}   # 从 {skewness(income):.2f} 拉回接近 0")

# ---- ④ 离群点实验：给对称数据塞一个 100 值 ----
outlier = np.append(sym, 100.0)
print(f"对称数据加一个 100 后: 偏度 = {skewness(outlier):.3f}   # 原 {skewness(sym):.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
对称分布   偏度 = 0.002   # 应接近 0
右偏分布   偏度 = 1.999   # 应为正（≈2 对指数分布）
左偏分布   偏度 = -2.000   # 应为负
收入分布: 均值=26.7 中位数=22.7 众数≈11.0 偏度=2.163
log1p 后: 偏度 = 0.033   # 从 2.16 拉回接近 0
对称数据加一个 100 后: 偏度 = 2.116   # 原 0.002
```

一个极端值把偏度从 0.002 炸到 2.116——立方放大的现场。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy 并定义 `skewness`

```python
import numpy as np

def skewness(x):
    """样本偏度：E[((X-μ)/σ)³]。除以 N，与 scipy 的 fisher 偏度一致。"""
    mu = x.mean()
    sigma = x.std()
    return np.mean(((x - mu) / sigma)**3)
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 $\mathbb{E}$、$\mu$、$\sigma$ 提供执行者。

#### skewness —— 偏度：把每个样本标准化后取立方，再平均

**做什么**：直接翻译 $\mathbb{E}[((X-\mu)/\sigma)^3]$。
**操作**：`(x - mu)` 逐元素去中心；`/ sigma` 标准化（除以标准差）；`**3` 取立方（保留符号）；`np.mean` 平均。
**输入**：一维样本数组。
**输出**：一个标量偏度。
**可调参数**：这个版本除以 $N$（总体/矩定义）。若想与 `scipy.stats.skew` 默认（除以 $N$）一致就不用改；与某些库的"调整偏度"（除以 $N-1$ 的修正）会略有差异，但不改变符号与量级。
**对应数学**：$\text{Skewness}=\frac{\mathbb{E}[(X-\mu)^3]}{\sigma^3}$。注意 `(x-mu)**3` 的符号：正值在右尾，三次方保持正。

---

### 步骤 2：三座山的对照

```python
sym   = np.random.normal(0, 1, 100000)
right = np.random.exponential(1.0, 100000)
left  = -np.random.exponential(1.0, 100000)
print(f"对称分布   偏度 = {skewness(sym):.3f}   # 应接近 0")
print(f"右偏分布   偏度 = {skewness(right):.3f}   # 应为正（≈2 对指数分布）")
print(f"左偏分布   偏度 = {skewness(left):.3f}   # 应为负")
```

#### `np.random.normal` / `np.random.exponential` —— 生成三种形状的样本

**做什么**：正态（对称）、指数（右偏）、负指数（左偏）各抽 10 万个样本。
**操作**：`np.random.normal(0,1,100000)` 抽标准正态；`np.random.exponential(1.0,100000)` 抽标准指数（右偏）；`-np.random.exponential(...)` 把指数镜像到负半轴（左偏）。
**输入**：分布参数与样本数。
**输出**：三个长度 100000 的数组。
**可调参数**：样本数越多，偏度估计越稳。指数分布的**理论偏度是 2**——抽样得到的 1.999 正是大数定律的证明。
**对应数学**：对称分布的三阶中心矩为 0；指数分布的理论偏度恒为 2（不管 $\lambda$ 取多少）——你可以换 `np.random.exponential(0.5,...)` 验证，偏度仍是 2 左右。**偏度无量纲，所以不随缩放变。**

### 步骤 3：收入分布——均值 > 中位数 > 众数

```python
income = np.random.lognormal(mean=3.0, sigma=0.8, size=100000)
mean, median = income.mean(), np.median(income)
hist, edges = np.histogram(income, bins=100)
mode = edges[np.argmax(hist)]
print(f"收入分布: 均值={mean:.1f} 中位数={median:.1f} 众数≈{mode:.1f} 偏度={skewness(income):.3f}")
```

#### `np.random.lognormal(mean, sigma, size)` —— 生成对数正态（右偏收入）

**操作**：先生成 $\ln X\sim\mathcal{N}(3,0.8^2)$ 的正态样本，再取 $X=e^{(\cdot)}$——得到的 $X$ 一定是正数且右偏。
**输入**：`mean`（对数域的均值）、`sigma`（对数域的标准差）、`size`。
**输出**：右偏的正值数组。
**可调参数**：`sigma` 越大右尾越胖、偏度越大。`mean` 决定量级（约 $e^3\approx20$）。
**对应数学**：对数正态是"下界为 0、上界无限"的典型右偏分布——主线里"为什么真实数据老往一边歪"的数学答案之一。

#### `np.median`、`np.histogram`、`np.argmax` —— 找中位数与众数

**操作**：`np.median` 排序取中；`np.histogram(income, bins=100)` 分 100 柱统计；`np.argmax(hist)` 找最高柱的下标；`edges[...]` 取该柱左边界近似众数。
**输入**：`income` 数组。
**输出**：`mean=26.7 > median=22.7 > mode≈11.0`——**均值 > 中位数 > 众数**，右偏的标准不等式。
**可调参数**：`bins` 越大众数越准但越抖；`range` 可限定直方图区间。
**对应数学**：右偏时均值被长尾拉得最右、众数留在峰值（最左）、中位数居中。这条不等式是判断"尾巴拖向哪边"的速记口诀——教材里"收入分布有一群极高值"正是这个形状。

---

### 步骤 4：取对数的魔法

```python
log_income = np.log1p(income)
print(f"log1p 后: 偏度 = {skewness(log_income):.3f}   # 从 {skewness(income):.2f} 拉回接近 0")
```

#### `np.log1p(x)` —— 计算 $\ln(1+x)$，把右偏拉回对称

**做什么**：对每个收入取 $\log(1+x)$，压缩右尾。
**操作**：`np.log1p` 精确计算 $\ln(1+x)$（对 $x$ 很大时比 `np.log(1+x)` 稳定）。
**输入**：`income` 数组。
**输出**：近似对称的数组，偏度从 2.16 掉到 0.03。
**可调参数**：`np.log1p` 只接受一个数组；想更强压缩可先除以大常数再取对数。
**对应数学**：$\ln X$ 服从正态 ⇒ $X$ 右偏。反过来取对数，就把"乘法式的右偏"还原成"加法式的对称"。这就是为什么 NLP 对词频、推荐对计数做 $\log$ 变换——**它在拉平偏度**。

### 步骤 5：离群点实验

```python
outlier = np.append(sym, 100.0)
print(f"对称数据加一个 100 后: 偏度 = {skewness(outlier):.3f}   # 原 {skewness(sym):.3f}")
```

#### `np.append(arr, val)` —— 追加一个极端值

**做什么**：往 10 万对称样本里塞一个 100，观察偏度变化。
**操作**：`np.append` 返回新数组。
**输入**：`sym` 与值 `100.0`。
**输出**：长度 100001 的数组。
**可调参数**：换不同的离群值大小，看偏度如何被立方放大——塞 `10` 时偏度约 0.1，塞 `100` 时约 2.1。
**对应数学**：$(X-\mu)^3$ 的立方放大——一个偏离 $\sigma$ 数百倍的样本，立方贡献是天文数字。这是主线边界声明"偏度对离群点极其敏感"的数值证明。

## 改个数字试试：取对数的边界

### 实验：负值或零值数据不能直接取对数

```python
data_with_zero = np.append(right, 0.0)
try:
    np.log(data_with_zero)                # log(0) = -inf
except Warning:
    pass
print(f"log(0) 得到 {np.log(np.maximum(data_with_zero, 1e-300)).min():.1f}   # 趋近 -inf")
print(f"log1p(0) 得到 {np.log1p(0.0):.1f}   # ln(1+0)=0，安全")
```

输出：

```text
log(0) 得到 -inf   # 趋近 -inf
log1p(0) 得到 0.0   # ln(1+0)=0，安全
```

对含 0 的数据，`np.log` 会给出 $-\infty$；`np.log1p`（$\ln(1+x)$）则安全。这就是推荐系统里默认用 $\log(1+x)$ 的工程原因——**既拉平偏度，又不会撞上 0 的对数奇点**。

## 边界声明：这套代码能做什么，不能做什么

1. **偏度为 0 不代表对称。** 我们的 `skewness` 用三阶矩，它是"不对称"的必要不充分度量——存在对称偏 0 但不对称的病态分布。若要检测对称性，三阶矩只是起点，不是终点。
2. **偏度对离群点病态敏感。** 立方放大让一个极端值就能改写符号。对含离群点的数据，偏度的绝对值意义有限——它告诉你"哪边尾巴长"，但"长多少"可能被单个点扭曲。
3. **标准化的局限。** 本脚本的 `np.log1p` 只对"正值、右偏"数据有效。左偏数据、或含负值的数据，需要别的变换（如取平方、Box-Cox）。别把"取对数"当成万能的偏度药。
4. **这是样本偏度，不是分布的理论偏度。** 对指数分布，理论偏度是 2；但我们算出的是抽样估计 1.999——样本越大越接近。分清"分布的性质"与"数据的估计"，是后续所有统计推断的前提。
