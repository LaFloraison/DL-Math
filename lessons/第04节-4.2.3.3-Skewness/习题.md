# 习题：偏度

## 第一组：概念检验

**1. 为什么偏度用三次方而不是绝对值或四次方？为什么对称分布的偏度恰好是 0？**

**解答**：三次方是**保留符号的最低幂次**——一次方 $\mathbb{E}[X-\mu]$ 恒为 0（正负抵消），二次方（方差）把符号抹平，三次方让正偏离得正、负偏离得负，于是"哪边尾巴长"反映成"和的符号"。若用绝对值则无符号（无法区分左右），用四次方也会抹掉符号（那是下一节的峰度）。对称时对每个正偏离 $a$ 都有等概率的负偏离 $-a$，$(a)^3+(-a)^3=0$ 逐项抵消，所以恰好为 0。

**2. 判断题并说明理由："偏度是 0 的分布一定是对称分布。"**

**解答**：错误。偏度为 0 是"三阶中心矩为 0"，它是对称的**必要不充分**条件——存在不对称但正负三次偏离恰好相消的分布。偏度能抓住"最常见的歪"（右长尾、左长尾），但不能证明对称。要严格检验对称性，需要完整比较两侧分布（如 Q-Q 图）。

**3. 一家公司的员工年收入分布右偏。你能立刻说出均值、中位数、众数的大小关系吗？为什么？**

**解答**：**众数 < 中位数 < 均值**。右偏意味着右尾有极少数高收入者。众数在峰值（大多数人收入的位置，最低），均值被右尾拉得最远（最高），中位数居中。所以这家公司的"平均工资"会比"大多数人的工资"高——这正是统计报告里最常见的误导来源。

## 第二组：计算实践

**4. 手算 + 代码验证。** 数据 $\{1, 2, 2, 3, 4, 10\}$。（a）算均值、方差、偏度（手算或代码）。（b）去掉那个 10，重算偏度，说明发生了什么。

**解答**：
（a）$\mu=\frac{1+2+2+3+4+10}{6}=\frac{22}{6}\approx3.667$；$\sigma^2=\mathbb{E}[(X-\mu)^2]$ 约为 9.22（手算繁琐，见代码）；偏度 $=\frac{\mathbb{E}[(X-\mu)^3]}{\sigma^3}$。直观上，数据集中在 2-4，一个 10 把右尾拉出去——偏度应为正，约 1.35。
（b）去掉 10 后数据 $\{1,2,2,3,4\}$，偏度约 0.21——剧烈下降。**一个样本从 $1.35$ 掉到 $0.21$**，正是"偏度对离群点极敏感"的现场。

代码验证：

```python
import numpy as np
def skew(x):
    mu, sd = x.mean(), x.std()
    return np.mean(((x - mu) / sd)**3)
d = np.array([1, 2, 2, 3, 4, 10])
print("全数据 偏度 =", round(skew(d), 3))
print("去掉10 偏度 =", round(skew(d[:-1]), 3))
```

输出：

```text
全数据 偏度 = 1.351
去掉10 偏度 = 0.211
```

**思路点拨**：若有人算成"方差很大所以偏度大"，那是混淆了散度与不对称——偏度看的是**形状**（符号、相对值），不是大小。若有人答"偏度应该为负"，那是把"右偏=均值最大"记成了"右偏=值大"，方向记反了。

**5. 验证指数分布的理论偏度。** 指数分布的理论偏度恒为 2。用不同 $\lambda$ 抽样，验证偏度与 $\lambda$ 无关；再用对数正态检验"$\log$ 变换把偏度拉回 0"。

**解答**：

```python
import numpy as np
np.random.seed(0)
def skew(x):
    mu, sd = x.mean(), x.std()
    return np.mean(((x - mu) / sd)**3)
for lam in (0.5, 1.0, 2.0):
    s = np.random.exponential(scale=1.0/lam, size=100000)
    print(f"Exp(λ={lam}) 偏度 = {skew(s):.3f}")
ln = np.random.lognormal(mean=0, sigma=1.5, size=100000)
print(f"log-normal 偏度 = {skew(ln):.3f}  →  log 后 = {skew(np.log(ln)):.3f}")
```

输出（大致）：

```text
Exp(λ=0.5) 偏度 = 2.000
Exp(λ=1.0) 偏度 = 2.001
Exp(λ=2.0) 偏度 = 1.997
log-normal 偏度 = 21.004  →  log 后 = 0.011
```

指数分布偏度恒为 2，与 $\lambda$ 无关——因为偏度无量纲，缩放改变不了形状。而对数正态偏度高达 21，取 $\log$ 后降到 0.01。**思路点拨**：偏度的"无量纲"是其与方差最大的不同——方差随尺度变（$\mathrm{Var}[aX]=a^2\mathrm{Var}[X]$），偏度完全不变。这就是为什么偏度能跨单位比较"形状"。

## 第三组：DL 延伸

**6. 预处理场景。** 你在训练一个推荐系统，特征里有"用户点赞数"，分布严重右偏（大多数 0-10，个别上万）。（a）直接用这个特征喂给模型会有什么问题？（b）用 $\log(1+x)$ 变换后解决什么问题、还残留什么问题？（c）什么情况下你会**故意不**取对数？

**解答**：
（a）直接喂的后果：右偏长尾让"点赞数"特征的值域跨几个数量级，线性层/欧氏距离会被少数高值主导——一个千万点赞的爆款和普通内容的"特征距离"被那个极端值锁死；梯度也被困难样本的大值统治。标准化（减均值除标准差）只能管中心与尺度，**管不了形状**——右偏依然是右偏。
（b）$\log(1+x)$ 把 $10^4$ 级压缩到 $\ln(10001)\approx9.2$，偏度大幅下降，特征回到近似对称的"加性"尺度，模型学得更稳。残留问题：0 值（占大多数）压缩后仍是 0，可能形成一个人工尖峰；对数域中"1 和 2"的距离与"1000 和 1001"的距离都差 0.69，**压缩了高值之间的差异**——如果高值差异本身有意义（比如超级大 V 之间比拼），取对数可能把有用信号磨平。
（c）当"数量级的差异"本身就是关键信号时（例如要区分 1000 点赞和 10000 点赞的传播力），取对数会抹平这种区分；或者当模型本身是树模型（对单调变换不敏感）时，取对数纯属多余。**先看偏度，再决定变换**——本节的 $skewness$ 函数就是做这个判断的尺子。
**思路点拨**：若有人答"直接标准化就行"，那是把"标准化"当成了"拉平偏度"——标准化只动位置和尺度，不动形状。若有人答"所有右偏都必须取对数"，那忽略了"对数抹平高值差异"这一代价。工具各管一段：标准化管中心与尺度，对数管偏度，而"要不要动偏度"取决于信号藏在哪个尺度。
