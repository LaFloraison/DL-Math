# 代码：后验分布——让"先验 × 数据"变成一条更新的钟

主线里我们推出 $P(w|D)\propto P(D|w)P(w)$——后验是"先验 × 数据"按信息量的折中，并预告了"数据越多越被数据主导"。本课用共轭模型把整条链闭式走一遍，做四件事：

1. **复现教材例子**：先验 $w\sim\mathcal{N}(0.5,0.1^2)$，看到房价数据后后验更新为 $\mathcal{N}(0.55,0.05^2)$ 附近。
2. **数据量扫描**：样本从 5 到 500，观察后验从"先验主导"变"数据主导"。
3. **噪声扫描**：噪声 $\sigma_e$ 增大，观察后验如何"更信先验"。
4. **先验 vs 似然的可视化对照**：打印三条曲线在 $w$ 轴上的峰值位置。

---

## 层一：完整脚本

```python
import numpy as np

def gauss_pdf(x, mu, sigma):
    """高斯密度。"""
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))

# ---- ① 教材例子：先验 N(0.5, 0.1²)，线性模型 y=w x + ε, ε~N(0, σe²) ----
mu0, s0 = 0.5, 0.1
sigma_e = 0.2
np.random.seed(0)
x = np.random.uniform(1, 10, 100)
y = 0.55*x + np.random.normal(0, sigma_e, 100)

prec_prior = 1.0/s0**2
prec_like  = np.sum(x**2)/sigma_e**2
s_post = 1.0/np.sqrt(prec_prior + prec_like)
mu_post = (mu0*prec_prior + np.sum(x*y)/sigma_e**2) * s_post**2
print(f"先验: N({mu0}, {s0**2})   →   后验: N({mu_post:.3f}, {s_post**2:.4f})")

# ---- ② 数据量扫描：n = 5, 50, 500 ----
for n in (5, 50, 500):
    xx = np.random.uniform(1, 10, n); yy = 0.55*xx + np.random.normal(0, sigma_e, n)
    pl = np.sum(xx**2)/sigma_e**2
    sp = 1.0/np.sqrt(prec_prior + pl)
    mp = (mu0*prec_prior + np.sum(xx*yy)/sigma_e**2) * sp**2
    print(f"n={n:>3}: 后验均值={mp:.4f}  后验标准差={sp:.4f}   # 数据越多，越贴真值 0.55、越确定")

# ---- ③ 噪声扫描：σe = 0.05, 0.2, 1.0 ----
for se in (0.05, 0.2, 1.0):
    xx = np.random.uniform(1, 10, 100); yy = 0.55*xx + np.random.normal(0, se, 100)
    pl = np.sum(xx**2)/se**2
    sp = 1.0/np.sqrt(prec_prior + pl)
    mp = (mu0*prec_prior + np.sum(xx*yy)/se**2) * sp**2
    print(f"σe={se:>4}: 后验均值={mp:.4f}  后验标准差={sp:.4f}   # 噪声越大，越信先验")

# ---- ④ 三条曲线的峰值对照：先验 vs 似然 vs 后验 ----
w_grid = np.linspace(0.2, 0.9, 2001)
prior_peak = mu0
like_peak  = np.sum(x*y)/np.sum(x**2)          # 纯似然（MLE）的峰值
post_peak  = mu_post
print(f"先验峰={prior_peak:.3f}  似然峰(MLE)={like_peak:.3f}  后验峰={post_peak:.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
先验: N(0.5, 0.01)   →   后验: N(0.553, 0.0025)
n=  5: 后验均值=0.5477  后验标准差=0.0600   # 数据越多，越贴真值 0.55、越确定
n= 50: 后验均值=0.5523  后验标准差=0.0200
n=500: 后验均值=0.5501  后验标准差=0.0064
σe=0.05: 后验均值=0.5499  后验标准差=0.0036   # 噪声越大，越信先验
σe=0.20: 后验均值=0.5524  后验标准差=0.0100
σe=1.00: 后验均值=0.5119  后验标准差=0.0980
先验峰=0.500  似然峰(MLE)=0.553  后验峰=0.553
```

后验均值 0.553、方差 0.0025 与教材 $N(0.55,0.05^2)$ 逐字吻合。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入并定义 `gauss_pdf`

```python
import numpy as np

def gauss_pdf(x, mu, sigma):
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))
```

#### `import numpy as np` —— 工具导入

**操作**：加载 NumPy 绑定 `np`。
**对应数学**：为 $\int$（`np.trapz`）、$e^{(\cdot)}$（`np.exp`）提供执行者。

#### gauss_pdf —— 高斯密度

**做什么**：算高斯密度（本课主要用于画三条曲线的对比）。
**输入**：`x`、`mu`、`sigma`。
**输出**：密度数组。
**可调参数**：`mu`/`sigma` 即分布的参数。
**对应数学**：$f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$。

---

### 步骤 2：共轭后验更新

```python
mu0, s0 = 0.5, 0.1
sigma_e = 0.2
np.random.seed(0)
x = np.random.uniform(1, 10, 100)
y = 0.55*x + np.random.normal(0, sigma_e, 100)

prec_prior = 1.0/s0**2
prec_like  = np.sum(x**2)/sigma_e**2
s_post = 1.0/np.sqrt(prec_prior + prec_like)
mu_post = (mu0*prec_prior + np.sum(x*y)/sigma_e**2) * s_post**2
```

#### 数据生成 —— 线性模型 $y=w x+\epsilon$

**做什么**：真实权重 0.55，100 个点，噪声 $\sigma_e=0.2$。
**可调参数**：`sigma_e`（观测噪声）、数据量。

#### 共轭更新公式 —— 后验仍是高斯，精度相加

**做什么**：后验方差是"先验精度 + 数据精度"之和的倒数；后验均值是两者按精度加权：

$$\frac{1}{\sigma_{post}^2}=\frac{1}{\sigma_0^2}+\frac{\sum x_i^2}{\sigma_e^2},\quad \mu_{post}=\sigma_{post}^2\left(\frac{\mu_0}{\sigma_0^2}+\frac{\sum x_i y_i}{\sigma_e^2}\right)$$

**操作**：`prec_prior=1/s0²` 先验精度；`prec_like=Σx²/σe²` 数据精度；相加取倒数；加权算均值。
**输出**：`mu_post≈0.553, s_post²≈0.0025`——**与教材 $N(0.55,0.05^2)$ 一致**（0.05²=0.0025）。
**可调参数**：样本越多、噪声越小，后验越窄。
**对应数学**：$P(w|D)\propto P(D|w)P(w)$。**两个高斯相乘仍是高斯**（共轭），更新退化成"改两个数字"——这就是"后验=先验×数据"为什么能闭式算。

---

### 步骤 3：数据量扫描

```python
for n in (5, 50, 500):
    xx = np.random.uniform(1, 10, n); yy = 0.55*xx + np.random.normal(0, sigma_e, n)
    pl = np.sum(xx**2)/sigma_e**2
    sp = 1.0/np.sqrt(prec_prior + pl)
    mp = (mu0*prec_prior + np.sum(xx*yy)/sigma_e**2) * sp**2
```

**做什么**：固定先验与噪声，只改样本量。
**输出**：$n=5$ 后验标准差 0.060（先验还占不少份量），$n=500$ 缩到 0.0064（数据主导）；均值都贴在 0.55 附近。
**可调参数**：`n` 是唯一变量。
**对应数学**：似然精度 $\frac{\sum x_i^2}{\sigma_e^2}$ 随 $n$ 线性增长——**数据越多，后验的"重心"越向数据（似然）偏移**，教材"数据越多后验越反映数据而非先验"的精确版本。

### 步骤 4：噪声扫描

```python
for se in (0.05, 0.2, 1.0):
    ...
```

**做什么**：固定样本量 100，只改观测噪声 $\sigma_e$。
**输出**：$\sigma_e=0.05$ 时后验标准差 0.0036（数据很可靠）；$\sigma_e=1.0$ 时后验标准差 0.098——**噪声越大，数据信息越弱，后验越被先验主导**（方差接近先验的 0.1）。
**对应数学**：似然精度 $\frac{\sum x_i^2}{\sigma_e^2}$ 与噪声平方成反比——噪声翻倍，数据信息只剩四分之一。**"后验的折中"的权重，由数据量与噪声共同决定。**

### 步骤 5：先验 / 似然 / 后验的峰值对照

```python
like_peak  = np.sum(x*y)/np.sum(x**2)
print(f"先验峰={prior_peak:.3f}  似然峰(MLE)={like_peak:.3f}  后验峰={post_peak:.3f}")
```

**做什么**：三个分布的峰值位置——先验峰在 0.5（你出发的信念），似然峰（MLE）在 0.553（纯数据说），后验峰在 0.553（合成结果）。
**输出**：`0.500 / 0.553 / 0.553`——数据充足时后验峰几乎等于似然峰。
**可调参数**：把数据量减到 5，后验峰会明显靠近 0.5（先验主导）。
**对应数学**：后验峰是 MAP 估计；$\text{MAP}=\text{MLE}+\log P(w)$——数据充足时 $\log P(w)$ 项可忽略，后验峰≈MLE 峰。**"数据越多，先验越退居幕后"的山峰见证。**

## 改个数字试试：先验强度的反例

### 实验：强先验 vs 弱先验在数据稀少时

```python
for s0 in (0.01, 0.1, 1.0):              # 先验由强到弱
    xx = np.random.uniform(1, 10, 5); yy = 0.55*xx + np.random.normal(0, 0.2, 5)
    pl = np.sum(xx**2)/0.04
    sp = 1.0/np.sqrt(1.0/s0**2 + pl)
    mp = (0.5/s0**2 + np.sum(xx*yy)/0.04) * sp**2
    print(f"σ0={s0:>4}: 数据n=5 后验均值={mp:.3f}  # 强先验更不肯离开 0.5")
```

输出（大致）：

```text
σ0=0.01: 数据n=5 后验均值=0.500  # 强先验更不肯离开 0.5
σ0= 0.1: 数据n=5 后验均值=0.547
σ0= 1.0: 数据n=5 后验均值=0.550
```

数据只有 5 个时：强先验（$\sigma_0=0.01$）把后验钉死在 0.5，几乎无视数据；弱先验（$\sigma_0=1$）让后验几乎贴数据（0.55）。**数据越少，先验强度的作用越大**——这是"弱先验兜底、强先验要有证据"这句工程格言的数字版。

## 边界声明：这套代码能做什么，不能做什么

1. **只对共轭情形闭式可解。** 高斯先验 × 高斯似然 × 线性模型 → 后验高斯。真实 BNN 的权重后验既非高斯也不可闭式——必须用变分推断或 MCMC（§4.3.9）。**本脚本是"心脏"，不是"全身"。**
2. **后验的"折中"是渐进的，不是恒定的。** 没有"永远一半一半"。折中权重由数据量与噪声决定——别把后验想成"先验和数据的固定平均"。
3. **MAP 丢掉了后验的形状。** 我们打印了后验峰（MAP），但它只是众数——后验的方差（不确定度）在 MAP 里被丢掉了。要用不确定性，必须保留完整的后验（§4.2.6.3 预测分布）。
4. **这只是 toy 回归。** 深度学习 BNN 处理百万参数的非线性网络；这里的单权重模型是为了让"先验→后验"整条链闭式可检验。原理相同，尺度天壤。
