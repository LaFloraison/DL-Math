# 习题：后验分布

## 第一组：概念检验

**1. 写出贝叶斯公式的四个零件，并分别用一句话说明它们是什么。**

**解答**：$P(w|D)=\frac{P(D|w)P(w)}{P(D)}$。$P(w)$ 先验——看到数据前对权重的信念；$P(D|w)$ 似然——给定权重，数据有多可能；$P(w|D)$ 后验——看到数据后的更新信念；$P(D)=\int P(D|w)P(w)dw$ 证据——归一化常数，保证后验积分等于 1。**先验是你出发的地方，数据是路上的证据，后验是你到达的地方，证据是让一切合法化的分母。**

**2. 为什么说"后验是先验与数据的折中"？"折中"的权重由什么决定？**

**解答**：因为去掉常数分母后 $P(w|D)\propto P(w)P(D|w)$——后验是"先验 × 数据"。用对数看是加法：$\log P(w|D)=\log P(w)+\log P(D|w)$。折中的权重由**数据量与噪声**共同决定：数据越多、噪声越小，后验越被数据（似然）主导；数据越少、噪声越大，后验越被先验主导。**没有"永远一半一半"，只有"谁的信息更多，谁说了算"。**

**3. 判断题并说明理由："MAP 估计就是后验分布的完整信息。"**

**解答**：错误。MAP 只取后验的**众数**（峰的位置）——它是"后验的点版本"，丢掉后验的形状（方差/不确定度）。两个后验可以有相同的 MAP 峰、完全不同的宽度，它们的预测不确定性天差地别。要用不确定性，必须保留完整后验（§4.2.6.3 的预测分布要积分权重）。**MAP 给你"最可能的参数"，不给"参数有多确定"。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 先验 $w\sim\mathcal{N}(0.5,0.1^2)$，线性模型 $y=wx+\epsilon$（$\sigma_e=0.2$），100 个点真实 $w=0.55$。（a）写出后验方差与均值的闭式公式。（b）代码算出后验，与教材 $N(0.55,0.05^2)$ 对比。（c）用"先验峰/似然峰/后验峰"说明数据充足时先验退居幕后。

**解答**：
（a）$\frac{1}{\sigma_{post}^2}=\frac{1}{\sigma_0^2}+\frac{\sum x_i^2}{\sigma_e^2}$；$\mu_{post}=\sigma_{post}^2\left(\frac{\mu_0}{\sigma_0^2}+\frac{\sum x_i y_i}{\sigma_e^2}\right)$。
（b）见《代码.md》：`mu_post≈0.553, s_post²≈0.0025`——与教材 $N(0.55,0.05^2)$ 一致（$0.05^2=0.0025$）。
（c）先验峰 0.500、似然峰（MLE）0.553、后验峰 0.553——数据充足时后验峰几乎等于似然峰，先验只在数据稀疏时显形。

代码验证：

```python
import numpy as np
np.random.seed(0)
x = np.random.uniform(1, 10, 100); y = 0.55*x + np.random.normal(0, 0.2, 100)
sp2 = 1.0/(1.0/0.01 + np.sum(x**2)/0.04)
mp  = (0.5/0.01 + np.sum(x*y)/0.04)*sp2
print("后验: mu =", round(mp, 4), " var =", round(sp2, 5))
```

输出：

```text
后验: mu = 0.553  var = 0.0025
```

**思路点拨**：若有人困惑"为什么后验均值不是 0.5 和 0.55 的平均 0.525"——因为"折中"不是算术平均，是**按精度（信息量）加权**：先验精度 $\frac{1}{0.01}=100$，数据精度 $\frac{\sum x^2}{0.04}$ 是几百的量级，数据占大头，所以后验均值几乎贴 0.55。

**5. 数据量与噪声扫描。** 固定先验，分别扫描（a）样本量 $n=5,50,500$ 和（b）噪声 $\sigma_e=0.05,0.2,1.0$，打印后验标准差，说明"谁主导后验"由什么决定。

**解答**：见《代码.md》步骤 3-4。典型输出：$n$ 从 5 到 500，后验标准差从 0.060 缩到 0.0064——数据越多越确定；$\sigma_e$ 从 0.05 到 1.0，后验标准差从 0.0036 涨到 0.098——噪声越大越不确定、越被先验主导。**结论：后验的"折中"由数据量（正比于信息）与噪声（反比于信息）共同决定。**

## 第三组：DL 延伸

**6. 持续学习场景。** 一个 BNN 在线上不断接收新数据。用后验的"对数加法"形式解释为什么它天然适合在线学习；并说明传统网络（固定权重）在此场景下的两个劣势。

**解答**：对数后验 $\log P(w|D)=\log P(w)+\sum_i\log P(D_i|w)$——每看到一批新数据，只需往和式里加一项 $\log P(D_{\text{new}}|w)$，后验就完成了更新。**BNN 的"动态更新机制"是结构自带的**：它是加法，不是重训。传统网络的劣势：第一，固定权重 $\theta^*$ 训完即停，新数据要么被忽略、要么需要整体重训（昂贵且丢失旧知识）；第二，它无法表达"我对这个权重有多确定"，无法在概念漂移时自动调整信念的置信度。**"训练"在贝叶斯世界里就是"算后验"，而后验的加法结构天然支持数据流。**
**思路点拨**：若有人答"传统网络也能增量更新（SGD 继续训练）"，那确实可以，但那是在**旧后验的位置上继续跑梯度**，不是结构化的贝叶斯更新——遇到分布漂移时，SGD 会被新数据牵着走、灾难性遗忘旧知识；BNN 的后验框架则明确地在"先验（旧信念）"与"新数据"之间做信息量加权。**加法结构，是贝叶斯在线学习的护城河。**
