# §7.6 挑战 —— 习题

主线立了三道坎：太大（可扩展性）、在动（动态图）、太杂（异质图）。下面三组习题检验你是否理解"为什么教科书 GNN 一到现实就失效"。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：教科书 GCN 在亿级图上失效的最直接原因是？

- A. 准确率不够
- B. 邻域聚合的计算与内存随图规模爆炸，整图装不进内存
- C. 图没有标签
- D. 激活函数选错

**解答**：B。

**思路点拨**：GCN 的"每层聚合所有邻居"在亿级图上计算与内存爆炸（稠密邻接矩阵 $n^2$ 内存，§7.6《代码.md》坎 1）。A 是"效果"问题不是"可行性"问题；C、D 与规模无关。常见错选 A——混淆"模型不够准"与"模型跑不起来"。

### 题 2（简答）：三道坎各自对应的"模型假设 vs 现实"冲突是什么？

**解答**：可扩展性——GCN 假设"图能整体处理"，现实是图大到装不下；动态图——GCN 假设"图是静止的"（静态结构），现实是图时刻在变；异质图——GCN 假设"所有节点/边同类型可一视同仁"，现实是类型多样需分别处理。

**思路点拨**：答题锚点是"每个假设被现实击穿"。把三道坎各对应一个"假设 vs 现实"就说透了。常见错误是只列现象（太大/在动/太杂）不说出背后的模型假设。

### 题 3（判断）：三道坎有"完美解"吗？

**解答**：没有，只有工程权衡。采样丢信息、增量忘旧事、异质增参数——每个对策都在某维度让步。理解"没有免费午餐"，是评估任何图系统"在真实世界是否可用"的前提。

**思路点拨**：这是主线边界声明的直考。答题要点是"每个对策的代价"。常见错误是以为"采样/增量/异质"是完美方案。记忆锚点：对策 ≈ 有损近似，方向不同而已。

## 二、计算实践

### 题 1（手算 + NumPy：内存对比）

比较两种图表示在 100 万节点、平均每节点 10 条边（共约 $10^7$ 条边）下的内存（float64，8 字节）：(a) 稠密邻接矩阵；(b) 稀疏存储（只存边）。

**解答**：(a) $10^{12}$ 元素 × 8 字节 = $8\times10^{12}$ 字节 = **8000 GB**。(b) $10^7$ 条边（无向存两次约 $2\times10^7$）≈ 2×$10^7$×16 字节（两个端点索引 + 值）≈ **0.32 GB**。差约 2.5 万倍。

**NumPy/SciPy 验证**：
```python
import scipy.sparse as sp
S = sp.random(1_000_000, 1_000_000, density=1e-5)   # 约 10^7 非零元
print("稀疏矩阵内存 GB ≈", S.data.nbytes / 1e9)
```
```
稀疏矩阵内存 GB ≈ 0.08
```

**思路点拨**：核心是"稠密 $n^2$ vs 稀疏 $|E|$"。真实图平均度小（稀疏），稀疏存储让亿级图从"不可能"变"可行"。常见错误是忘了稀疏矩阵还要存索引。这也是 §7.4.4"局部化"的存储侧。

### 题 2（手算：静态模型的失真）

一张 3 节点链 1–2–3。模型（行归一化 GCN，恒等 W）在**旧图**上训练。之后边 {2,3} 被删，图变成 1–2 与孤立 3。手算节点 3 的表示在旧图 vs 新图下的值，并说明为什么"静态模型"失真。

**解答**：旧图节点 3 的邻居 {2,3}（含自环？——不含自环的简化版：邻居 {2}）。用行归一化（含自环）更标准：旧图 $\tilde{A}$ 对角线 +1，节点 3 的度 2（自环 + 节点 2），$h_3^{(1)} = (h_3 + h_2)/2$。设 $h_2=[0,1]$、$h_3=[1,0]$，则旧图 $h_3^{(1)} = [0.5, 0.5]$。新图节点 3 孤立（只有自环），$h_3^{(1)} = h_3 = [1,0]$。**同一节点、同一模型，因图变化，表示从"混入邻居信息"变成"只有自己"**——模型输出的预测也随之失真，而静态模型没有更新机制。

**思路点拨**：这道题把"图变 → 表示变 → 预测失真"这条链走一遍。核心：**GCN 表示依赖结构，结构变了表示必然变**，静态模型只能"假装"结构没变。常见错误是以为训练好的 $W$ 能让表示对新图"自动适应"——不会，$W$ 是静态的。

## 三、DL 延伸

### 题 1（场景设计）：实时反欺诈——三道坎全撞上

一个实时反欺诈系统：每笔转账触发"这笔交易可疑吗"的判断，交易图每秒变化。请指出这个系统撞上了三道坎的哪几道，并分别给出应对思路。

**解答**：(1) **可扩展性**——交易图巨大，全图 GCN 跑不实时。应对：采样 + mini-batch，只对"当前交易附近的子图"算局部表示（§7.6.1）。(2) **动态图**——图每秒变化，静态模型预测失真。应对：增量学习（只更新受影响子图）+ 流式处理（实时跟随新交易，§7.6.2）。(3) **异质图**——转账涉及账户、商户、卡、设备多种实体与"转账/登录/绑卡"多种边。应对：异质 GNN/元路径，分类型处理（§7.6.3）。**实时反欺诈是三道坎的合流**——这解释了为什么它至今仍是图 AI 最难、也最值得攻克的战场之一。

**思路点拨**：答题要把三道坎与三个应对一一对应。加分点：指出"实时性"是三道坎共同的放大器——不仅图大、在动、太杂，还要求毫秒级响应。常见错误是只答一道坎。

### 题 2（概念连线）：为什么"对策都是近似"？

采样（§7.6.1）丢信息、增量（§7.6.2）忘旧事、异质分参（§7.6.3）增参数——请用"近似"这个词统一解释：为什么这三道坎没有完美解？

**解答**：三道坎的本质都是"模型假设（完整、静态、同质）与真实图（巨大、动态、异质）不匹配"，而任何"让模型适配真实图"的努力，都要在某个维度放松精确性：采样是**空间近似**（只算部分邻居，丢远端信息）；增量是**时间近似**（只更新局部，旧变化被淡忘）；异质分参是**表示空间近似**（每类一套参数，牺牲共享与简化）。**三者都是"用有损近似换可行性"**——没有哪个方案能同时做到"完整、实时、简单"，这正是"没有免费午餐"的图版本。

**思路点拨**：答题锚点是"三种近似对应三个维度（空间/时间/类型）"。能用"近似"统一三对策就是满分。常见错误是把采样/增量/异质当"完美解法"，忽略了各自的代价。
