# Ch07 §7.6 挑战 · 代码.md

主线立了三道坎：太大、在动、太杂。本文件用三个小实验把三道坎**量化**出来：(1) 稠密邻接矩阵在亿级节点下的内存爆炸；(2) 为静态图训练的模型，图一变就失效；(3) 异质边混处理的语义损失（用 §7.4.3 的"分类型 vs 混合"对比）。每个实验十几行，全篇手写 numpy。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ===== 坎 1：太大——稠密邻接矩阵的内存爆炸 =====
def memory_of_dense(n):
    return n * n * 8 / 1e9                             # n×n 个 float64（8 字节）→ GB

for n in [1_000, 1_000_000, 1_000_000_000]:
    print(f"  稠密邻接矩阵 {n} 节点 ≈ {memory_of_dense(n):.1f} GB")

# ===== 坎 2：在动——静态模型的失效 =====
def static_gcn_predict(A, H, W):                       # 用固定权重做一次聚合预测
    Dinv = np.diag(1.0 / np.maximum(A.sum(1), 1e-12))
    return np.maximum(Dinv @ A @ H @ W, 0.0)           # 行归一化 + 变换

A_old = np.array([[0,1,0],[1,0,1],[0,1,0]], dtype=float)   # 旧图：1-2-3 链
A_new = np.array([[0,1,0],[1,0,0],[0,0,0]], dtype=float)   # 新图：1-2 边被删，3 孤立
H = np.array([[1.,0.],[0.,1.],[1.,0.]])
W = np.array([[1.,0.],[0.,1.]])
pred_old = static_gcn_predict(A_old, H, W)
pred_new = static_gcn_predict(A_new, H, W)
print("\n  旧图下节点3的表示：", np.round(pred_old[2], 2))
print("  新图下节点3的表示：", np.round(pred_new[2], 2), "（孤立了）")

# ===== 坎 3：太杂——异质混处理的语义损失 =====
idx = {"北京":0, "上海":1, "中国":2}
m_locate = np.zeros((3,3)); m_locate[idx["北京"], idx["中国"]] = 1   # 位于
m_dist   = np.zeros((3,3)); m_dist[idx["北京"], idx["上海"]] = 200   # 距离
I = np.eye(3)
print("\n  分类型聚合 '北京'：", np.round((m_locate @ I)[0], 1), "|", np.round((m_dist @ I)[0], 1))
print("  混合聚合 '北京'：", np.round(((m_locate + m_dist) @ I)[0], 1))
```

输出：

```
  稠密邻接矩阵 1000 节点 ≈ 0.0 GB
  稠密邻接矩阵 1000000 节点 ≈ 8000.0 GB
  稠密邻接矩阵 1000000000 节点 ≈ 8.0e+15 GB
  旧图下节点3的表示： [0.5 0. ]
  新图下节点3的表示： [1. 0.]
  （孤立了）
  分类型聚合 '北京'： [0. 0. 1.] | [0. 200. 0.]
  混合聚合 '北京'： [0. 200. 1.]
```

三个数字各说一件事。**坎 1**：100 万节点稠密矩阵就要 8000 GB——存不下；只有用稀疏存储 + 采样（§7.6.1）才能活。**坎 2**：旧图里节点 3 的表示是"自己 + 邻居 2 的平均"（`[0.5,0]`），边被删后它变成纯自己（`[1,0]`）——**静态模型的表示因图变化而失真**，且没有机制更新。**坎 3**：分类型聚合保留"位于中国"（第三维）与"距上海 200"（第二维 200）的**类型区分**；混合聚合把两个不同语义的事实加进同一个向量——**类型信息被抹掉**。

## 层二：分步逐函数拆解

### 步骤 1：量化内存爆炸

```python
def memory_of_dense(n):
    return n * n * 8 / 1e9
```

#### memory_of_dense —— 稠密矩阵的内存代价

`n * n * 8`

**操作**：邻接矩阵有 $n^2$ 个元素，每个 float64 占 8 字节，除以 $10^9$ 换成 GB。

**输入**：`n`（节点数）。

**输出**：GB 数。

**可调参数**：换成稀疏存储（非零元 ≈ 边数 $|E|$），内存从 $n^2$ 降到 $|E|$——这是 §7.4.4"局部化"的存储版。`n=10^9$` 时稠密 8×$10^{15}$ GB，稀疏只需千亿条边的量级——**稀疏 + 采样是亿级图的唯一活路**。

**对应数学**：§7.4.4 的"运算量随 $n^2$ 爆炸"的内存版。坎 1 的量化。

---

### 步骤 2：演示静态模型失效

```python
def static_gcn_predict(A, H, W):
    Dinv = np.diag(1.0 / np.maximum(A.sum(1), 1e-12))
    return np.maximum(Dinv @ A @ H @ W, 0.0)
```

#### static_gcn_predict —— 固定权重的静态 GCN

`Dinv @ A @ H @ W`

**操作**：行归一化邻接 × 特征 × 权重——一个"训练好但不会更新"的模型。旧图/新图喂同一个函数，输出不同。

**输入**：`A`、`H`、`W`。

**输出**：节点表示矩阵。

**可调参数**：`W` 是训练好的固定权重（没有学习步）——这正是"静态模型"的代码形态：**模型参数不变，图的输入变了**。真实的动态图挑战就是：图每分钟都在变，静态 `W` 越来越失真，而重训成本高得离谱。

**对应数学**：§7.5.1 的 GCN 前向，但冻结权重。坎 2 的量化：同一 `W`，不同 `A`，输出不同——**结构变了，表示失真**。

---

### 步骤 3：对比异质分类型与混合

```python
m_locate = np.zeros((3,3)); m_locate[idx["北京"], idx["中国"]] = 1
m_dist   = np.zeros((3,3)); m_dist[idx["北京"], idx["上海"]] = 200
```

#### 分类型 vs 混合 —— 类型语义的保留

**操作**：`m_locate` 存"位于"（1），`m_dist` 存"距离"（200），各自聚合再**拼接**（分类型）或**相加**（混合）。

**输入**：两个边类型矩阵。

**输出**：北京的表示。分类型：`[0,0,1] | [0,200,0]`（位于段 + 距离段）；混合：`[0,200,1]`。

**可调参数**：若把"位于"权重也设为 200，混合后你根本分不清"北京位于中国"还是"北京距上海 200km"——**类型被数字掩盖**。分类型（拼接）保住了"这是两种关系"的事实。

**对应数学**：§7.4.3 与 §7.6.3 的异质处理。坎 3 的量化：类型混在一起，语义丢失。

## 改个数字试试

### 实验 A：稀疏矩阵的内存拯救

```python
import scipy.sparse as sp
S = sp.random(1_000_000, 1_000_000, density=1e-6)     # 稀疏：平均每节点 1 条边
print(f"  100 万节点稀疏矩阵内存 ≈ {S.data.nbytes / 1e9:.3f} GB（vs 稠密 8000 GB）")
```

稀疏矩阵只存非零元（≈ 边数），100 万节点的稀疏邻接只需几 MB——**稀疏性 + 局部采样，是坎 1 的工程解**。

### 实验 B：增量更新——只改受影响的局部

删边后，只有节点 2、3 的表示需要重算（节点 1 的邻居没变）。增量学习的思想：**图变化时只更新受影响子图**，而不是全图重算——这是 §7.6.2 的核心。你可以在 `static_gcn_predict` 里只重算 `pred_new[[1,2]]` 来体会这个"局部重算"。

**呼应主线**：三道坎——太大（内存爆炸）、在动（静态模型失真）、太杂（类型混损失）——各有其工程对策：采样稀疏、增量流式、异质分参。本实验把"挑战"从形容词变成了数字，也预告了 §7.6.1–§7.6.3 的具体解法。
