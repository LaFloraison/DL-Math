# 代码：从零手写 LU 分解，再用它解方程组

主线里我们把 $A$ 拆成了 $A = LU$：$L$ 装着消元时记下的乘数（单位下三角），$U$ 装着消元后的成品（上三角）。这一节把这句话变成可运行的 Python——**不调 `scipy.linalg.lu`，不调 `np.linalg.solve`**，用手写的双重循环把分解、前代、回代逐个做出来，再验证"分解正确、解方程正确"。你会看到 LAPACK 里那些库函数，本质上就是这几行循环。

脚本只依赖 NumPy，约 50 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np

def lu_decompose(A):
    """Doolittle LU 分解：L 单位下三角、U 上三角，返回 (L, U)。"""
    n = A.shape[0]                  # 矩阵阶数
    U = A.astype(float).copy()      # U 从 A 的副本开始，逐步消元
    L = np.eye(n)                   # L 初始为单位阵，逐格填入乘数
    for k in range(n):              # 第 k 列（也是第 k 行）
        if U[k, k] == 0.0:          # 主元为零：numpy 除零不报错、只给 NaN，必须显式拦下
            raise ValueError(f"主元 U[{k},{k}] 为零：需要行置换 PA=LU")
        for i in range(k + 1, n):   # 消掉第 k 列里、主元下方的所有元素
            m = U[i, k] / U[k, k]   # 乘数 = 被消元素 / 主元
            L[i, k] = m             # 记入 L（第 i 行第 k 列）
            U[i, k:] -= m * U[k, k:]  # 第 i 行第 k 列及以后，减去 m 倍第 k 行
    return L, U

def lu_decompose_pp(A):
    """部分选主元的 LU 分解：返回 (P, L, U)，满足 P@A = L@U。"""
    n = A.shape[0]
    P = np.eye(n)                   # 置换矩阵，初始为单位阵
    U = A.astype(float).copy()
    L = np.eye(n)
    for k in range(n):
        pivot = np.argmax(np.abs(U[k:, k])) + k   # 第 k 列下半段绝对值最大的行号
        if pivot != k:                            # 主元不够"大"就换行
            U[[k, pivot], :] = U[[pivot, k], :]   # 交换 U 的两行
            P[[k, pivot], :] = P[[pivot, k], :]   # 在 P 里记录这次交换
            if k > 0:
                L[[k, pivot], :k] = L[[pivot, k], :k]  # L 已填的列同步交换
        for i in range(k + 1, n):                 # 之后与朴素版完全相同
            m = U[i, k] / U[k, k]
            L[i, k] = m
            U[i, k:] -= m * U[k, k:]
    return P, L, U

def forward_substitute(L, b):
    """前代：解 L c = b（L 是单位下三角，从第 0 行往最后一行算）。"""
    n = L.shape[0]
    c = b.astype(float).copy()
    for i in range(n):
        c[i] -= L[i, :i] @ c[:i]    # 减去左边所有已知项对第 i 行的贡献
    return c

def back_substitute(U, c):
    """回代：解 U x = c（U 是上三角，从最后一行往第 0 行算）。"""
    n = U.shape[0]
    x = c.astype(float).copy()
    for i in range(n - 1, -1, -1):
        x[i] = (x[i] - U[i, i+1:] @ x[i+1:]) / U[i, i]  # 主元在分母上
    return x

# ============ 主流程：分解 → 回代 → 验证 ============
A = np.array([[2., 1., 1.],        # 与主线手算同一个 A
              [4., 3., 3.],
              [8., 7., 9.]])
b = np.array([4., 10., 22.])

L, U = lu_decompose(A)
print("L =", L, sep="\n")
print("U =", U, sep="\n")
print("重构误差 max|A - L@U| =", np.max(np.abs(A - L @ U)))
c = forward_substitute(L, b)      # 第一步：解 L c = b
x = back_substitute(U, c)         # 第二步：解 U x = c
print("解 x =", x)
print("残差 max|A@x - b| =", np.max(np.abs(A @ x - b)))

# ============ 主元为零：需要行置换 PA = LU ============
B = np.array([[0., 2., 1.],        # 左上角是 0，朴素分解必炸
              [2., 1., 1.],
              [4., 3., 1.]])
try:
    lu_decompose(B)
except ValueError as e:
    print("普通分解失败：", e)
P, Lp, Up = lu_decompose_pp(B)
print("P@B  =", P @ B, sep="\n")
print("Lp@Up =", Lp @ Up, sep="\n")
print("两者一致？", np.allclose(P @ B, Lp @ Up))
```

## 层二：分步逐函数拆解

### 步骤 1：造数据——`np.array` 矩阵与向量

```python
A = np.array([[2., 1., 1.], [4., 3., 3.], [8., 7., 9.]])
b = np.array([4., 10., 22.])
```

#### `np.array(嵌套列表)` —— 把嵌套列表变成矩阵 / 向量

**做什么**：`A` 是一个 3 行 3 列的二维数组（矩阵），`b` 是一维数组（向量），数值与主线 §2.6.1 手算完全一致。
**操作**：`np.array` 扫描传入的列表，推断形状与数据类型（这里都是 `float64`），按行主序存进内存。
**输入**：`A` 的输入是一个"列表的列表" `[[2.,1.,1.],...]`——内层 3 个列表，每个长 3。
**输出**：`A` 形状 `(3, 3)`，`A[i, j]` 是第 $i$ 行第 $j$ 列；`b` 形状 `(3,)`。
**可调参数**：
- 矩阵大小：改成 `np.array([[1., 2.], [3., 4.]])` 就是 2×2，分解代码一行不用改——循环按 `n = A.shape[0]` 自适应。
- `dtype`：`np.array(..., dtype=np.float32)` 可省内存，但数值精度略降，分解误差会从 `0.0` 变成 `1e-7` 量级。
**对应数学**：主线定义块里的矩阵 $A$ 与右边 $b$。

### 步骤 2：`lu_decompose(A)` —— Doolittle 分解核心

```python
n = A.shape[0]
U = A.astype(float).copy()
L = np.eye(n)
for k in range(n):
    if U[k, k] == 0.0:
        raise ValueError(f"主元 U[{k},{k}] 为零：需要行置换 PA=LU")
    for i in range(k + 1, n):
        m = U[i, k] / U[k, k]
        L[i, k] = m
        U[i, k:] -= m * U[k, k:]
return L, U
```

#### `A.shape[0]` —— 取行数

**做什么**：`A.shape` 是 `(3, 3)` 的元组，`[0]` 取第一个元素 `3`，即矩阵阶数。
**输入**：形状 `(n, n)` 的二维数组。**输出**：标量整数 `n`。
**可调参数**：无。换成任意方阵都返回对应阶数。

#### `A.astype(float).copy()` —— 复制并转浮点

**做什么**：`U` 必须是一份**独立副本**——后面要原地修改 `U`，若直接写 `U = A`，会悄悄改掉用户的 `A`。`astype(float)` 保证即便输入是整数矩阵也能做除法。
**输入**：形状 `(3, 3)` 的 `A`。**输出**：形状 `(3, 3)` 的新数组。
**可调参数**：`astype` 的 `dtype` 可传 `np.float64`（默认双精度）或 `np.float32`（省内存、精度略降）。

#### `np.eye(n)` —— 生成单位矩阵

**做什么**：对角线全 1、其余全 0 的 $n\times n$ 矩阵。$L$ 从单位阵出发，只填主对角线以下的乘数——这样 $L$ 的对角线天然全 1，正是 Doolittle 约定。
**输入**：整数 `n=3`。**输出**：形状 `(3, 3)` 的单位矩阵。
**可调参数**：
- 第二参数 `k` 控制对角线偏移：`np.eye(3, k=1)` 把 1 放到主对角线**上方**一条，其余全 0。
- `dtype`：`np.eye(3, dtype=float)` 默认就是浮点。

#### 双层循环 `for k ... for i ...` + 切片消元 —— 全脚本的心脏

**做什么**：外层 `k` 遍历主元位置（主对角线上的 `(k,k)`）；内层 `i` 消掉第 `k` 列中主元下方的元素。
**操作**：对每一格 `(i,k)`，算乘数 `m = U[i,k]/U[k,k]`，把 `m` 记进 `L[i,k]`，再把第 `i` 行**从第 `k` 列往后**整体减去 `m` 倍第 `k` 行。`U[i, k:]` 是"第 `i` 行从第 `k` 列到末尾"的切片，`U[k, k:]` 同理；`-=` 是逐元素就地减法，一次处理整段切片（向量化，比 `for j` 内层循环快得多）。
**输入**：`U` 形状 `(3, 3)`，`k`、`i` 为行号。**输出**：`L` 填上乘数、`U` 逐列清零左下角。
**可调参数**：无独立参数。但注意切片 `U[i, k:]` 与 `U[i, k:] -= ...` 只更新第 `k` 列及以后——第 `k` 列左边已经是 0，无需再碰，这是教科书式的高斯消元的代码形态。
**对应数学**：主线"$l_{ij}$ 就是消元乘数、$U$ 就是消元后的成品"。第 1 步手算的 `m = 4/2 = 2`、`8/2 = 4`、`3/1 = 3` 恰好就落在输出的 `L` 里。

### 步骤 3：`forward_substitute(L, b)` —— 前代，解 $Lc = b$

```python
n = L.shape[0]
c = b.astype(float).copy()
for i in range(n):
    c[i] -= L[i, :i] @ c[:i]
return c
```

**做什么**：$L$ 是单位下三角，第一行只有一个未知数 $c_1 = b_1$；算出 $c_1$ 后，第二行的未知数只剩 $c_2$。从第 0 行往最后一行，每一行只有一个新未知数——这就是"前代 (forward substitution)"。
**操作**：`L[i, :i]` 是 $L$ 第 $i$ 行第 0 列到第 $i-1$ 列（即主元左边的已知乘数），`c[:i]` 是已经算出的前 $i$ 个未知数；两者做**点积 (dot product)**，就是"左边所有已知项对第 $i$ 行的贡献"。用 $b_i$（存在 `c[i]` 里）减去这个贡献，就得到 $c_i$。
**输入**：`L` 形状 `(3, 3)` 下三角；`b` 形状 `(3,)`。**输出**：`c` 形状 `(3,)`。
**可调参数**：无显式参数。行列数由 `n = L.shape[0]` 自适应；`b` 可以是任何长度为 `n` 的向量。**还可以传更多参数**——NumPy 允许 `b` 是形状 `(n, m)` 的矩阵（$m$ 个右边同时前代），把一维点积推广为矩阵乘即可，这正是 LAPACK `dgetrs` 批处理多个右边的方式。
**对应数学**：主线"前代 $Lc=b$：$c_2 = 10 - 2\times4 = 2$"。运行结果 `c` 没打印，但 `x = [1., 2., 0.]` 就是它往下喂给回代的结果。

### 步骤 4：`back_substitute(U, c)` —— 回代，解 $Ux = c$

```python
n = U.shape[0]
x = c.astype(float).copy()
for i in range(n - 1, -1, -1):
    x[i] = (x[i] - U[i, i+1:] @ x[i+1:]) / U[i, i]
return x
```

**做什么**：$U$ 是上三角，最后一行只有一个未知数 $x_3 = c_3/u_{33}$；算完再从倒数第二行往上。方向与前代相反（`range(n-1, -1, -1)` 从最后一行走到第 0 行），所以叫"回代 (back substitution)"。
**操作**：`U[i, i+1:]` 是第 $i$ 行主元**右侧**的元素，`x[i+1:]` 是已算出的下方未知数，点积得右侧已知项的贡献；`x[i]`（此刻存着 $c_i$）减去它，**再除以主元 `U[i, i]`**——主元在分母上，所以主元为零时这里必然除零。
**输入**：`U` 形状 `(3, 3)` 上三角；`c` 形状 `(3,)`。**输出**：`x` 形状 `(3,)`，方程组的解。
**可调参数**：无显式参数。与 `forward_substitute` 一样，`c` 换成形状 `(n, m)` 的矩阵即可一次回代 $m$ 个右边。
**对应数学**：主线"回代 $Ux=c$：$x_3=0/2=0,\ x_2=2/1=2,\ x_1=(4-2)/2=1$"，输出 `x = [1. 2. 0.]` 与手算一致。

### 步骤 5：验证——`L @ U` 重构与残差

```python
print("重构误差 max|A - L@U| =", np.max(np.abs(A - L @ U)))
print("残差 max|A@x - b| =", np.max(np.abs(A @ x - b)))
```

#### `L @ U` —— 矩阵乘法

**操作**：$L\cdot U$，结果应是原矩阵 $A$。$L@U$ 的第 $(i,j)$ 格是 $L$ 第 $i$ 行与 $U$ 第 $j$ 列的点积——即主线手算里的"第 $i$ 行 = $L$ 的系数加权 $U$ 的各行"。
**输入**：`L`、`U` 均形状 `(3, 3)`。**输出**：`(3, 3)`。**可调参数**：`@` 是运算符没有参数；等价写法 `np.matmul(L, U)`，二者对 2 维数组行为一致。

#### `np.max(np.abs(...))` —— 最大绝对误差

**做什么**：`np.abs` 逐元素取绝对值，`np.max` 取所有元素的最大值。`A - L@U` 逐元素相减，若分解精确，每格都是 0，最大值 `0.0`。
**输入**：`(3, 3)` 数组。**输出**：标量。
**可调参数**：`np.max` 的 `axis` 参数可沿某轴取最大（如 `axis=0` 按列取）；想取绝对值之和小一些的度量，可换成 `np.linalg.norm(A - L@U)`。
**对应数学**：主线"验证 $L\cdot U = A$ 分毫不差"。残差同理：`A@x - b` 应全为 0，证明解正确。

### 步骤 6：`lu_decompose_pp(B)` —— 部分选主元，$PA = LU$

```python
pivot = np.argmax(np.abs(U[k:, k])) + k
if pivot != k:
    U[[k, pivot], :] = U[[pivot, k], :]
    P[[k, pivot], :] = P[[pivot, k], :]
    if k > 0:
        L[[k, pivot], :k] = L[[pivot, k], :k]
```

**做什么**：`B` 的左上角是 0，朴素版在第 0 步就撞上"主元为零"。带选主元的版本每步先**在 $U$ 的第 $k$ 列、主元以下找绝对值最大的行**，把它换到主元位置，再做同样的消元。行交换的记录写进置换矩阵 `P`，所以最终 `P@A = L@U`。
**操作**：
- `U[k:, k]` 是第 $k$ 列从第 $k$ 行到末尾的切片；`np.abs` 逐元素取绝对值；`np.argmax` 返回**这个切片里**最大值的下标（0 基）；再加回 `k`，得到在整个矩阵里的行号 `pivot`。
- `U[[k, pivot], :]` 是"取第 `k` 行和第 `pivot` 行"组成的小矩阵（花式索引 fancy indexing），`=` 赋值把它换位——一次交换两行。
- `L[[k, pivot], :k]` 同理交换 $L$ 已填好的左半列——因为消元顺序已经变过，$L$ 里已填的乘数也必须跟着换行，否则乘积对不上。
**输入**：`B` 形状 `(3, 3)`，`P`、`L`、`U` 都是形状 `(3, 3)`。**输出**：`P` 置换矩阵、`L` 单位下三角、`U` 上三角，满足 `P@A = L@U`。
**可调参数**：无独立参数；`np.argmax` 的 `axis` 参数可改变求最大值的方向（这里默认展平整个切片求全局最大）。`np.allclose(P @ B, Lp @ Up)` 判断两个矩阵是否"数值上相等"——`rtol`、`atol` 两个参数控制容差，默认 `rtol=1e-5`、`atol=1e-8`，对精确浮点运算足够。
**对应数学**：主线"主元为零 → 需要置换 $PA=LU$"。输出 `P@B` 与 `Lp@Up` 完全一致（都是 `[[4,3,1],[0,2,1],[2,1,1]]`），`两者一致？ True` 就是这条恒等式的机器证明。

## 边界声明：这套代码能做什么，不能做什么

1. **朴素 `lu_decompose` 遇零主元直接抛异常**——这是**刻意为之**。原生 NumPy 里 `U[i,k]/U[k,k]` 除零**不会报错**，只会悄悄产生 `inf`/`nan` 并打印一行 `RuntimeWarning`，分解结果全是无效值。真实工程里"静默的 NaN"比"响亮的报错"危险一万倍——所以这里用 `if U[k,k] == 0.0` 显式拦截，让失败看得见。
2. **`lu_decompose_pp` 仍然不是万能**：它只处理"行交换"（部分选主元）。若矩阵本身奇异（$\det A = 0$），无论怎么换行，某一步主元必然还是 0——选主元只是保证"理论上可解的都解出来"，不是把无解变成有解。
3. **这套循环是教学版，不是生产版**：手写双重循环对 $n\times n$ 矩阵是 $O(n^3)$，$n$ 到几百没问题，$n$ 上万就慢到不可用。生产代码请用 `np.linalg.solve`（内部就是 LAPACK 的 LU + 回代，且带选主元、针对高速缓存优化过）。本课手写它，是为了让每个乘数、每次换行都**可见**——这正是"函数是数学说明书"的意义。
4. **误差不会永远恰好是 0.0**：这里所有数字都能精确表示，所以重构误差是 `0.0`。换成 `dtype=np.float32` 或病态矩阵，误差会变成 `1e-7` 量级——此时就靠选主元压住误差的膨胀（Wilkinson 的稳定性结论）。
