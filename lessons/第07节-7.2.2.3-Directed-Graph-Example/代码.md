# Ch07 §7.2.2.3 有向图例：三篇论文的引用网络 · 代码.md

主线把教材的三论文引用网络（$V=\{A,B,C\}$，$E=\{(A,B),(A,C),(B,C)\}$）读成了三个量：出度、入度、流向。本文件用 numpy 把这个微型例子完整实现，并加一个"间接影响"的检查——$A$ 虽然只直接引用 $B$、$C$，但通过 $B$，$A$ 与 $C$ 之间还隔着一条 2 步的引用链。所有结果都能手算核对，公式与直觉面对面。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

V = ["A", "B", "C"]                                    # ② 三篇论文
E = [("A", "B"), ("A", "C"), ("B", "C")]               #    引用：A引B, A引C, B引C

def build_adjacency(nodes, edges):                     # ③ 有向邻接矩阵
    idx = {n: i for i, n in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=int)
    for u, v in edges:
        A[idx[u], idx[v]] = 1
    return A

def degrees(A):                                        # ④ 出度=行和，入度=列和
    return A.sum(axis=1), A.sum(axis=0)

A = build_adjacency(V, E)                              # ⑤ 主流程
out_d, in_d = degrees(A)
print("邻接矩阵（行=引用方 列=被引方）：\n", A)
print("出度（每篇引用了几篇）:", dict(zip(V, out_d)))
print("入度（每篇被引了几次）:", dict(zip(V, in_d)))
print("B→A 存在边吗？", A[1, 0] == 1)                  # A引用B，但B未必引用A
print("间接影响：A→B→C 是否构成 2 步路径？", (A @ A)[0, 2] == 1)
```

输出：

```
邻接矩阵（行=引用方 列=被引方）：
 [[0 1 1]
  [0 0 1]
  [0 0 0]]
出度（每篇引用了几篇）: {'A': 2, 'B': 1, 'C': 0}
入度（每篇被引了几次）: {'A': 0, 'B': 1, 'C': 2}
B→A 存在边吗？ False
间接影响：A→B→C 是否构成 2 步路径？ True
```

四个数字把主线读图的三句话全部验证：A 出度最高（视野最广，引了 2 篇）、C 入度最高（被引 2 次，是源头）、B→A 反向不存在（方向不可逆）、$A \to B \to C$ 是一条真实的 2 步引用链（$A$ 间接受 $C$ 影响）。一张 3 节点的图，信息量已经不小。

## 层二：分步逐函数拆解

### 步骤 1：定义有向邻接矩阵

```python
def build_adjacency(nodes, edges):
    idx = {n: i for i, n in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=int)
    for u, v in edges:
        A[idx[u], idx[v]] = 1
    return A
```

#### build_adjacency —— 从引用对到非对称矩阵

`A[idx[u], idx[v]] = 1`

**操作**：建名字→下标映射；造全零方阵；对每条引用 `(u, v)`，在"u 行 v 列"写 1。**只写一处**（不写对称位置），所以矩阵是非对称的——这正是方向性的编码。

**输入**：`nodes`（list of str）、`edges`（list of (str, str)）。注意 `dtype=int`：这里只关心 0/1，用整数省内存。

**输出**：`np.ndarray`，形状 `(3, 3)`，`dtype=int`。`A[i, j] = 1` ⟺ 存在引用 $i \to j$。

**可调参数**：
- 想表达"引用强度"（顺手一提 vs 深度依赖），把 `1` 换成权重——升级为 §7.2.4 的加权有向图。
- 若论文数量增多，`nodes` 顺序改变会改变矩阵行列——图没变，只是表示变了（表示与对象分离的又一次提醒）。

**对应数学**：§7.2.2 定义 $E \subseteq V\times V$。三篇论文的引用对 $(A,B),(A,C),(B,C)$ 逐条落进矩阵。

---

### 步骤 2：定义出入度函数

```python
def degrees(A):
    return A.sum(axis=1), A.sum(axis=0)
```

#### degrees —— 行和与列和

`A.sum(axis=1)` 与 `A.sum(axis=0)`

**操作**：`axis=1` 每行求和 → 每个节点的出度（该行有 1 的列数 = 引用了几篇）；`axis=0` 每列求和 → 每个节点的入度（该列有 1 的行数 = 被引了几次）。

**输入**：`A`：`(n, n)` 有向邻接矩阵。

**输出**：两个 `np.ndarray`，形状 `(n,)`。出度 `[2, 1, 0]`（A、B、C），入度 `[0, 1, 2]`。

**可调参数**：无额外参数。可验证恒等式 `out_d.sum() == in_d.sum() == len(E)`（3）——每条引用边同时贡献一个出度和一个入度。

**对应数学**：§7.2.2 的出度 $d^+(v)$ 与入度 $d^-(v)$。这里的 `dict(zip(V, out_d))` 把数字映射回论文名，可读性更好——这就是"表示"层的小技巧。

---

### 步骤 3：主流程——验证方向不可逆与间接影响

```python
print("B→A 存在边吗？", A[1, 0] == 1)
print("间接影响：A→B→C 是否构成 2 步路径？", (A @ A)[0, 2] == 1)
```

#### 矩阵索引与矩阵乘 —— 反向不存在、2 步路径存在

`A[1, 0]` 与 `(A @ A)[0, 2]`

**操作**：`A[1, 0]` 直接查"B 行、A 列"——因为 `build_adjacency` 只在 `A[0,1]`（A引B）写 1，`A[1,0]` 是 0。`A @ A` 是矩阵平方，`(A@A)[0, 2]` 是"从 A 走两步到 C 的路数"——路径只有一条：A→B→C，所以是 1。

**输入**：`A`：`(3,3)` 矩阵；下标 `[1,0]`、`[0,2]`。

**输出**：两个布尔值/整数。

**可调参数**：矩阵索引用 `[行, 列]`，别和 Python 的 `A[行][列]` 记混。`A @ A` 的幂次可以继续叠——`(A @ A @ A)` 数 3 步路径，这里 A 的出度结构使 3 步路径不存在（C 无出边）。

**对应数学**：主线第四节"方向的反问"与矩阵的幂。$A^2_{02} = 1$ 把"间接影响"这个直觉翻译成了精确的代数事实。

## 改个数字试试

### 实验 A：加一篇"综合综述"D，看入度分布怎么变

假设出现一篇综述论文 D，同时引用 A、B、C 三篇。加 `("D","A"),("D","B"),("D","C")`，重跑。你会看到：D 出度 3、入度 0（谁也不引用它，至少现在）；C 的入度从 2 变 3。这个 4 节点的网络已经能看出**入度分布的不均**——这正是普赖斯在百万节点网络上发现的"富者愈富"的种子：C 已经领先，新论文越晚出现，越倾向于指向已有的高入度节点。

### 实验 B：预测"谁下一个被引用"

用链路预测的直觉想一下：$A \to B \to C$ 这条链，下一步最可能出现的引用边是哪条？——很可能是 $A \to D$（如果 D 出现在 A 之后）或"顺着链往下"，即某篇被引用者再去引用更新文献。图没有给你答案，但图给了你**候选集**：沿着箭头方向，比逆着方向更可能发生新引用。这就是 §7.4.2 链接预测在图上的朴素形态——**方向性大幅压缩了"谁可能引用谁"的搜索空间**。
