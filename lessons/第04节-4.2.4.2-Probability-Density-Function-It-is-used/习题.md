# 习题：概率密度函数（PDF）

## 第一组：概念检验

**1. 用你自己的话解释"密度不是概率"，并举一个密度大于 1 的例子。**

**解答**：密度是"每单位长度的概率浓度"，不是"某个点的概率"。把密度想象成人口密度：每平方公里 2000 人，不是"某平方公里恰好 2000 人"而是"平均浓度"。例子：$\text{Uniform}(0,0.5)$ 的密度处处是 $f(x)=\frac{1}{0.5}=2>1$——但 $P(0\le X\le 0.5)=2\times0.5=1$，完全合法。密度可以超 1，概率永远不能；概率要靠密度乘宽度（积分）。

**2. 为什么 $P(X=x)=0$ 对连续变量恒成立？这是否意味着"$X=x$ 不可能发生"？**

**解答**：因为单点没有宽度——概率 $P(x\le X\le x+dx)\approx f(x)dx$，令 $dx\to0$ 得 0。但这**不等于**"不可能发生"：概率 0 的事件可以发生（连续世界里每个具体点发生的概率都是 0，可总会发生某一个点）。"概率为 0"≠"不可能"，这是连续概率与日常直觉的最大裂缝。

**3. 判断题："$f(x)$ 曲线越高，说明 $x$ 处取值越可能。" 这句话哪里对、哪里不对？**

**解答**：对的部分：$f(x)$ 高说明"$x$ 附近单位长度的概率浓度高"，取值落在"$x$ 附近的一个小窗"比落在"低密度处的同宽小窗"更可能。不对的部分：$f(x)$ 本身不是概率，"$x$ 处单点的可能性"恒为 0——你不能拿 $f(x)$ 的值说"取到 $x$ 的概率是 $f(x)$"。**密度高是"附近可能"，不是"这个点可能"。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 设 $X\sim\mathcal{N}(0,1)$。（a）$f(0)$ 是多少？它是概率吗？（b）$P(-0.5\le X\le0.5)$ 约多少？（c）"$P(X=0)$"是多少？

**解答**：
（a）$f(0)=\frac{1}{\sqrt{2\pi}}e^0\approx0.399$。它是**密度**，不是概率——"0 附近单位长度的浓度约 40%"。
（b）$\int_{-0.5}^{0.5}\frac{1}{\sqrt{2\pi}}e^{-x^2/2}dx\approx0.383$（用误差函数 $\text{erf}$ 或数值积分：$\text{erf}(0.5/\sqrt2)\approx0.383$）。
（c）$P(X=0)=0$——单点概率恒为 0。

代码验证：

```python
import numpy as np
def pdf(x): return 1.0/np.sqrt(2*np.pi)*np.exp(-x**2/2)
x = np.linspace(-0.5, 0.5, 10001)
print("f(0) =", round(pdf(0.0), 4))
print("P(-0.5<=X<=0.5) =", round(np.trapz(pdf(x), x), 4))
```

输出：

```text
f(0) = 0.3989
P(-0.5<=X<=0.5) = 0.3829
```

**思路点拨**：若有人答"$P(-0.5\le X\le0.5)=f(0)$"，那是把密度当概率的经典错误——$0.399$ 是"浓度"，真正的面积是 $0.383$。两个数看着接近，但一个是点值、一个是积分，数学地位完全不同。

**5. 用"频率/窗宽"估计密度。** 从 $\mathcal{N}(0,1)$ 抽 20 万样本，把 $[-2,2]$ 分成 40 箱，用"每箱频率 ÷ 箱宽"估计密度，与理论 $f(x)$ 对比；样本量从 1000 涨到 20 万，误差如何变化？

**解答**：

```python
import numpy as np
np.random.seed(0)
def pdf(x): return 1.0/np.sqrt(2*np.pi)*np.exp(-x**2/2)
for size in (1000, 20000, 200000):
    s = np.random.normal(0, 1, size)
    counts, edges = np.histogram(s, bins=40, range=(-2, 2))
    width = 4.0/40
    centers = (edges[:-1]+edges[1:])/2
    err = np.max(np.abs(counts/(size*width) - pdf(centers)))
    print(f"size={size:>7}: 最大密度估计误差 = {err:.4f}")
```

输出（大致）：

```text
size=   1000: 最大密度估计误差 = 0.0712
size=  20000: 最大密度估计误差 = 0.0149
size= 200000: 最大密度估计误差 = 0.0041
```

样本每涨约 10 倍，误差缩约 3-4 倍——"频率/窗宽"作为密度估计在收敛（平方根定律）。**思路点拨**：这就是主线"直方图除以窗宽就是密度估计"的证明——也是 §4.3.6 蒙特卡洛与 §4.3.12 重采样的共同地基。若有人问"为什么不直接数频率当概率"，提醒他：那得到的是"每箱的概率"，要变成密度必须除以箱宽。

## 第三组：DL 延伸

**6. 回归与不确定性场景。** 一个深度回归模型输出 $\hat y=f_\theta(x)$ 和方差 $\sigma_\theta^2(x)$，假设 $y|x\sim\mathcal{N}(f_\theta(x),\sigma_\theta^2(x))$。（a）写出给定输入 $x$、标签 $y$ 时这条高斯 PDF 的值。（b）解释为什么"最大化这条 PDF"等价于"最小化 $\frac{(y-\hat y)^2}{2\sigma^2}+\log\sigma$"。（c）为什么模型学会输出大的 $\sigma$ 会"偷懒"——这个损失如何惩罚它？

**解答**：
（a）$p(y|x)=\frac{1}{\sigma_\theta(x)\sqrt{2\pi}}\exp\!\left(-\frac{(y-f_\theta(x))^2}{2\sigma_\theta^2(x)}\right)$。
（b）取负对数：$-\log p(y|x)=\frac{(y-\hat y)^2}{2\sigma^2}+\log\sigma+\frac12\log(2\pi)$。常数项 $\frac12\log(2\pi)$ 不影响优化，于是最小化 MSE 的"高斯加权版"——**这个式子就是高斯 PDF 的负对数似然**。当 $\sigma$ 固定时它就是 $\frac{(y-\hat y)^2}{2\sigma^2}$（MSE 的缩放版）；当 $\sigma$ 也学习时，网络在"拟合 $\hat y$"和"汇报多大不确定性"之间权衡。
（c）如果模型对每个样本都输出巨大 $\sigma$，第一项 $\frac{(y-\hat y)^2}{2\sigma^2}$ 会被压到接近 0——损失几乎只看 $\log\sigma$。而 $\log\sigma$ 随 $\sigma$ 增大而增大，所以**输出超大的 $\sigma$ 反而抬高损失**——$\log\sigma$ 项就是"不准偷懒"的惩罚。模型被逼着只在确实不确定的地方放大 $\sigma$。这就是异方差不确定性回归（heteroscedastic regression）的全部数学。
**思路点拨**：若有人答"模型输出大 $\sigma$ 会让损失变小所以是好的"，那是只看了第一项——$+\log\sigma$ 的惩罚项正是为对抗这种偷懒设计的。若有人问"为什么不是 $-\log\sigma$"，提醒他：$\sigma$ 越小 PDF 峰值越高（越确定），负对数似然应该惩罚"假装确定但实际错"，这正是第二项存在的原因。
