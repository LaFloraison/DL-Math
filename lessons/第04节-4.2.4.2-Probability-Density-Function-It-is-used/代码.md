# 代码：PDF——让"浓度"被极限定义、被积分验证、被直方图逼近

主线里我们把 PDF 定义为"每单位长度的概率浓度"：$f(x)=\lim_{\Delta x\to0}\frac{P(x\le X\le x+\Delta x)}{\Delta x}$，并且强调——**它本身不是概率，概率要靠积分**。本课用代码做四件事：

1. **极限定义**：把 $\Delta x$ 不断缩小，看"窗内概率 / 窗宽"收敛到正态密度的峰值 $\frac{1}{\sqrt{2\pi}}\approx0.399$。
2. **密度 vs 概率**：打印 $f(0)=0.399$ 与 $P(0\le X\le 0.01)\approx0.004$——密度可以比概率"看着大"，但概率才是可读的数。
3. **归一化裁决**：$\int_{-\infty}^\infty f(x)dx$ 应约等于 1。
4. **直方图逼近**：用抽样频率除以窗宽，让直方图逼近理论密度曲线。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：linspace / trapz / exp / sqrt

def normal_pdf(x, mu=0.0, sigma=1.0):
    """标准正态密度：N(0,1) 的 f(x)=1/(√(2π))·e^{-x²/2}。"""
    return 1.0/(sigma*np.sqrt(2.0*np.pi))*np.exp(-(x-mu)**2/(2.0*sigma**2))

# ---- ① 极限定义：把 Δx 从 0.1 缩到 1e-5，看比值是否收敛到 0.399 ----
for dx in (0.1, 0.01, 0.001, 1e-5):
    # 用梯形积分算 P(-dx/2 <= X <= dx/2)（小窗内概率）
    xs = np.linspace(-dx/2, dx/2, 10001)
    p_in_window = np.trapz(normal_pdf(xs), xs)
    print(f"Δx={dx:>8}: P(窗内)/Δx = {p_in_window/dx:.6f}   # 极限应≈0.399")

# ---- ② 密度 vs 概率：f(0) 与 P(0<=X<=0.01) ----
f0 = normal_pdf(0.0)
p_tiny = np.trapz(normal_pdf(np.linspace(0.0, 0.01, 1001)), np.linspace(0.0, 0.01, 1001))
print(f"f(0)={f0:.4f}   但 P(0<=X<=0.01)={p_tiny:.5f}   # 密度不是概率！")

# ---- ③ 归一化：∫ f(x) dx ≈ 1 ----
x = np.linspace(-6.0, 6.0, 10001)         # μ±6σ，几乎盖住全部质量
area = np.trapz(normal_pdf(x), x)
print(f"∫ f(x) dx ≈ {area:.6f}   # 理论 1")

# ---- ④ 直方图逼近：抽样频率/窗宽 ≈ 理论密度 ----
np.random.seed(0)
samples = np.random.normal(0, 1, 200000)
counts, edges = np.histogram(samples, bins=40, range=(-4, 4))
width = (4.0 - (-4.0)) / 40
centers = (edges[:-1] + edges[1:]) / 2
approx = counts / (200000 * width)        # 频率 / 窗宽 → 密度估计
peak_err = np.max(np.abs(approx - normal_pdf(centers)))
print(f"直方图与理论密度的最大偏差 = {peak_err:.4f}   # 样本越多越小")
```

运行输出（Python 3.11 + NumPy）：

```text
Δx=     0.1: P(窗内)/Δx = 0.399184   # 极限应≈0.399
Δx=    0.01: P(窗内)/Δx = 0.399077   # 极限应≈0.399
Δx=   0.001: P(窗内)/Δx = 0.398942   # 极限应≈0.399
Δx=   1e-05: P(窗内)/Δx = 0.398942   # 极限应≈0.399
f(0)=0.3989   但 P(0<=X<=0.01)=0.00399   # 密度不是概率！
∫ f(x) dx ≈ 1.000000   # 理论 1
直方图与理论密度的最大偏差 = 0.0026   # 样本越多越小
```

$\Delta x$ 缩小，比值稳定收敛到 $0.398942=\frac{1}{\sqrt{2\pi}}$；密度 0.399 与"0.01 窗的概率 0.004"反差鲜明。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy 并定义 `normal_pdf`

```python
import numpy as np

def normal_pdf(x, mu=0.0, sigma=1.0):
    """标准正态密度：N(0,1) 的 f(x)=1/(√(2π))·e^{-x²/2}。"""
    return 1.0/(sigma*np.sqrt(2.0*np.pi))*np.exp(-(x-mu)**2/(2.0*sigma**2))
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 $\int$（`np.trapz`）、$e^{(\cdot)}$（`np.exp`）、$\sqrt{2\pi}$（`np.sqrt`、`np.pi`）提供执行者。

#### normal_pdf —— 正态密度的直接翻译

**做什么**：对每个点算出该点的密度 $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$。
**操作**：`(x-mu)**2/(2*sigma**2)` 标准化平方距离；`np.exp` 取指数；乘归一化因子。
**输入**：`x`（标量或数组）、`mu`（默认 0）、`sigma`（默认 1）。
**输出**：与 `x` 同形状的密度数组。
**可调参数**：`mu`/`sigma` 可改（默认就是标准正态）；`x` 可传任意网格。
**对应数学**：教材 $\mathcal{N}(0,1)$ 的公式。峰值 $\frac{1}{\sqrt{2\pi}}\approx0.399$——正是脚本要验证的极限值。

---

### 步骤 2：验证极限定义

```python
for dx in (0.1, 0.01, 0.001, 1e-5):
    xs = np.linspace(-dx/2, dx/2, 10001)
    p_in_window = np.trapz(normal_pdf(xs), xs)
    print(f"Δx={dx:>8}: P(窗内)/Δx = {p_in_window/dx:.6f}")
```

#### `np.linspace(-dx/2, dx/2, N)` 与 `np.trapz` —— 算小窗内概率

**做什么**：对每个窗宽 $\Delta x$，算"落在 $[-\Delta x/2, \Delta x/2]$ 内的概率"除以窗宽——即主线定义 $\frac{P(x\le X\le x+\Delta x)}{\Delta x}$ 在 $x=0$ 处的取值。
**操作**：`np.trapz` 在窗内对密度积分得 $P(\text{窗内})$；除以 `dx`。
**输入**：窗宽 `dx`。
**输出**：比值序列 `0.399184 → 0.398942`——随 $\Delta x\to0$ 收敛到 $\frac{1}{\sqrt{2\pi}}$。
**可调参数**：把窗的中心从 0 移到 1，比值收敛到 $f(1)$（正态在 $x=1$ 的密度，约 0.242）——**这个极限在每个点上都等于那个点的密度**。
**对应数学**：$f(x)=\lim_{\Delta x\to0}\frac{P(x\le X\le x+\Delta x)}{\Delta x}$。收敛序列证明了"密度是概率对位置的导数"。

---

### 步骤 3：密度 vs 概率

```python
f0 = normal_pdf(0.0)
p_tiny = np.trapz(normal_pdf(np.linspace(0.0, 0.01, 1001)), np.linspace(0.0, 0.01, 1001))
print(f"f(0)={f0:.4f}   但 P(0<=X<=0.01)={p_tiny:.5f}")
```

#### 两个数字的对照 —— "密度不是概率"的现场

**做什么**：打印 $f(0)=0.399$ 和"落在 $[0,0.01]$ 的概率 $\approx0.004$"。窗宽只有 0.01，所以概率（面积）是密度乘以窗宽的近似（$0.399\times0.01\approx0.004$）。
**操作**：`normal_pdf(0.0)` 直接取点值；`np.trapz` 在 $[0,0.01]$ 上积分。
**输入**：$x=0$ 与小区间 $[0,0.01]$。
**输出**：`0.3989` vs `0.00399`——一个"看着大"，一个才是可读的概率。
**可调参数**：换任意点，对照始终成立。想演示"密度超 1"，可换 $\text{Uniform}(0,0.5)$：密度 2、窗内概率却仍小。
**对应数学**：$P(a\le X\le b)=\int_a^b f(x)dx\approx f(x_0)\cdot(b-a)$——**概率 ≈ 密度 × 宽度**，这就是"密度可以大于 1 而概率不能"的算术根源。

---

### 步骤 4：归一化裁决

```python
x = np.linspace(-6.0, 6.0, 10001)
area = np.trapz(normal_pdf(x), x)
print(f"∫ f(x) dx ≈ {area:.6f}   # 理论 1")
```

#### `np.trapz` —— 全轴积分

**做什么**：把整条数轴（用 $\mu\pm6\sigma$ 近似）的密度积起来，确认面积 1。
**操作**：`np.linspace(-6,6,10001)` 铺满 6σ；`np.trapz` 梯形积分。
**输入**：网格与密度。
**输出**：`1.000000`。
**可调参数**：网格范围改小（如 ±2σ）面积会明显小于 1——因为钟的裙边被切掉了。**范围必须包住几乎全部质量。**
**对应数学**：$\int_{-\infty}^{\infty}f(x)dx=1$。这是"够不够格当密度"的唯一裁决。

---

### 步骤 5：直方图逼近密度

```python
samples = np.random.normal(0, 1, 200000)
counts, edges = np.histogram(samples, bins=40, range=(-4, 4))
width = (4.0 - (-4.0)) / 40
centers = (edges[:-1] + edges[1:]) / 2
approx = counts / (200000 * width)
peak_err = np.max(np.abs(approx - normal_pdf(centers)))
```

#### `np.histogram` 与归一化 —— 频率/窗宽 ≈ 密度

**做什么**：抽 20 万样本分 40 箱，用"频率 ÷ 窗宽"估计每箱的密度，与理论密度比。
**操作**：`np.histogram(samples, bins=40, range=(-4,4))` 数每箱个数；`width` 是箱宽；`approx = counts/(N*width)` 把频率变成"每单位宽度的频率"——这正是密度的统计版。
**输入**：样本、箱数、范围。
**输出**：最大偏差 `0.0026`。
**可调参数**：`bins` 越多曲线越细但每箱样本越少（偏差会先降后升）；样本越多偏差越小——大数定律的现场。
**对应数学**：$P(x\le X\le x+dx)/dx$ 的频率估计——**直方图除以窗宽，就是密度的无偏估计**。这和主线定义的极限是同一条路，只是从"统计"方向逼近。

## 改个数字试试：换一个密度再看

### 实验：Uniform(0, 0.5) 的密度是 2——密度真的可以超 1

```python
def uniform_pdf(x, a=0.0, b=0.5):
    return np.where((x >= a) & (x <= b), 1.0/(b-a), 0.0)
xs = np.linspace(0.0, 0.5, 10001)
print(f"f(0.25) = {uniform_pdf(0.25):.2f}   # 密度=2，超过 1！")
print(f"P(0<=X<=0.5) = {np.trapz(uniform_pdf(xs), xs):.4f}   # 面积仍=1")
```

输出：

```text
f(0.25) = 2.00   # 密度=2，超过 1！
P(0<=X<=0.5) = 1.0000   # 面积仍=1
```

密度 2 > 1，面积却仍是 1——**"密度不是概率"最锋利的证据**。若有人问"2 怎么可能是概率"，答案是：它不是概率，是"每单位长度的浓度"；概率 $=2\times0.5=1$。

## 边界声明：这套代码能做什么，不能做什么

1. **打印出来的 $f(x)$ 不是概率。** $f(0)=0.399$ 是"0 附近单位长度的浓度"，不是"恰好 0 的概率 39.9%"（单点概率恒 0）。要概率必须积分——`np.trapz` 干的正是这个。
2. **无限尾巴只能近似。** 正态的积分域是 $(-\infty,\infty)$，我们用 ±6σ 截断——已盖住 99.9999998%，仍有微小的截断误差。想要更精确，把网格放宽即可，但"无穷"本身拿不到。
3. **直方图逼近有取舍。** `bins` 太少曲线粗、太多每箱噪声大——密度估计的"偏差-方差权衡"在后续课程（§4.3.12 重采样）会系统展开。本脚本只演示原理。
4. **这只是验算工具。** 真实建模用 `scipy.stats.norm.pdf`、`np.random.normal` 直接工作。但"密度=概率对位置的导数"这个定义，是所有封装的地基。
