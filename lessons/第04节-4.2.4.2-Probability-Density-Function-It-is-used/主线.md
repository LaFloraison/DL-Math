## 第一步：Toy Model —— 一面密度墙

上一节你学会了给骰子、硬币画"柱子账本"（PMF）。现在把场景换成身高：你给一千个人量身高，把结果画成直方图——中间隆起，两端低平。

一个"浅到可笑"的问题又来了：**随机拉一个人，他身高恰好等于 170.000000 cm 的概率是多少？**

你盯着直方图想：如果把身高精确到 0.000001 cm，那一个点能装几个人？答案是一个都没有——直方图的每根柱子都有**宽度**，170.000 这个点宽度为 0，装不进任何概率。可你换个方式问："身高在 170 到 171 之间"——有宽度了，就能数出柱子里有多少人。

于是你明白：**对连续的量，可能性不放在"点"上，放在"段"上。** 而"段"的大小怎么描述？你把直方图的柱子越切越细：5 cm 一格、1 cm 一格、0.1 cm 一格——柱子越切越矮（因为每格人更少），但整面墙的**轮廓**不变。真正稳定的，是"每单位高度分布了多少人"——墙在某个位置有多"浓密"。这个"每单位长度的浓密程度"，就是**概率密度 (probability density)**。

现在问题变成：**"浓密程度"在哪个瞬间被定义？** 你直觉到它和"格子的宽度"有关——格子越小，它越精确。可格子小到 0 会怎样？以及，"密度"和"概率"到底差在哪——为什么墙可以高出"1"，而概率永远超不过 1？该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：把"浓密程度"精确化，撞上一个极限

上一节 PMF 直接给"恰好等于 $x$"的概率——那是因为离散点有"质量"。连续世界，$P(X=x)=0$——单点宽度为零。怎么定义"每单位长度的浓密程度"？

自然的做法：看一个**小窗** $[x, x+\Delta x]$。这个窗内的概率 $\mathrm{P}(x \le X \le x+\Delta x)$ 除以窗的宽度 $\Delta x$，得到"每单位宽度的概率"——窗内的平均浓度。窗越小，这个比值越接近"在 $x$ 这个点上的瞬间浓度"。把窗无限缩小：

$$f(x) = \lim_{\Delta x \to 0} \frac{\mathrm{P}(x \le X \le x+\Delta x)}{\Delta x}$$

**这个极限就是概率密度函数 (probability density function, PDF)。** 它把上一节 PMF 的"点质量"换成"瞬间浓度"——一个由导数定义的函数。注意：$f(x)$ 是"每单位长度的概率浓度"，**它本身不是概率**。

### 二、密度的三条性格

**性格一：$f(x)$ 不是概率，可以大于 1。** 拿 $\text{Uniform}(0,0.5)$ 来说，密度处处是 $f(x)=2$。2 > 1，却完全合法——因为密度乘上宽度才是概率，窗越窄概率越小。**"密度 = 概率 / 宽度"，这个除法让密度可以超 1。**

**性格二：概率要靠积分。** 想知道"身高落在 $[a,b]$"，把这段区间内每一点的浓度积起来：

$$\mathrm{P}(a \le X \le b) = \int_a^b f(x)\, dx$$

**性格三：总面积恒为 1。** 一个人总要有身高，所以把整条数轴积起来：

$$\int_{-\infty}^{\infty} f(x)\, dx = 1$$

> **概率密度函数 (PDF)** $f(x) = \lim_{\Delta x\to 0}\dfrac{\mathrm{P}(x\le X\le x+\Delta x)}{\Delta x}$
>
> 物理含义：连续随机变量在 $x$ 处的"概率浓度"——每单位长度的概率。它不是概率，概率要积分。
>
> $$f(x) \ge 0, \qquad \int_{-\infty}^{\infty} f(x)\,dx = 1$$
>
> - 区间概率：$\mathrm{P}(a \le X \le b) = \int_a^b f(x)\,dx$——概率 = 曲线下的面积
> - 单点概率恒为 0：$\mathrm{P}(X=x)=0$
> - 与 PMF 的翻译表：**$\sum$ 换成 $\int$，质量换成浓度**
> - 例子（教材）：标准正态 $\mathcal{N}(0,1)$，$f(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$——峰值在 0，向 ±1 递减

**直觉检验：正态的密度曲线。** $\mathcal{N}(0,1)$ 的密度在 $x=0$ 处最高（$\approx0.399$），向两端指数式下降——"越靠近均值，浓度越高"。教材说"$f(x)$ 在均值处最高，随 $x$ 远离对称下降"，这正是钟形的文字版。

### 三、一张翻译表，锁住离散与连续的全部秘密

上一节 PMF 与本节 PDF 是同一枚硬币的两面。用一张表把它们的关系钉死：

| | 离散（PMF） | 连续（PDF） |
|---|---|---|
| 描述的量 | 点质量 $p(x)$ | 浓度 $f(x)$ |
| 函数值本身 | **是**概率 | **不是**概率，是密度 |
| 单点概率 | $p(x)$ 可正 | 恒为 0 |
| 总概率 | $\sum_x p(x)=1$ | $\int_{-\infty}^\infty f(x)dx=1$ |
| 区间概率 | $\sum_{x\in[a,b]}p(x)$ | $\int_a^b f(x)dx$ |
| 记号灵魂 | 求和 $\sum$ | 积分 $\int$ |

一句话：**$f(x)$ 有多高，说的是"$x$ 附近每单位长度的概率浓度"；要想真正拿到概率，必须用积分去量它下方的面积。**

边界声明：**"长得像概率"不等于"是概率"。** 新手最常犯的错是拿 $f(x)$ 的值直接当概率（"$f(170)=0.04$，所以 170 cm 的概率是 4%"）。不是——$f(170)=0.04$ 的意思是"170 cm 附近单位长度内聚着约 4% 的浓度"，单点概率依然是 0。**看曲线高度只给直觉，给概率必须积分。**

## 第三步：DL 桥接

**PDF 是连续概率建模的语言——VAE、扩散模型、正态假设全用它。**

**VAE 的隐变量先验与后验。** 变分自编码器的隐空间假设 $z$ 服从标准正态 $p(z)=\frac{1}{\sqrt{2\pi}}e^{-z^2/2}$，编码器输出的后验 $q(z|x)$ 也用正态 PDF 建模。VAE 的全部训练目标——ELBO——建立在"两个 PDF 的距离"（KL 散度）上。**每个 VAE 训练循环里的 $\mu,\sigma$，都是正态 PDF 的两个参数。**

**扩散模型的正向加噪。** 扩散模型每一步 $x_t=\sqrt{1-\beta_t}x_{t-1}+\sqrt{\beta_t}\epsilon$ 中的 $\epsilon$ 从 $\mathcal{N}(0,I)$ 抽取——高斯 PDF 的"加自己仍是高斯"性质，让多步加噪有闭式解。**去噪网络学的，就是在给定噪声 PDF 下如何反推干净的 $x_0$。**

**回归与条件密度。** 深度回归模型的输出 $\hat{y}=f_\theta(x)$ 通常被解释为"条件均值"，配合高斯误差假设 $\epsilon\sim\mathcal{N}(0,\sigma^2)$：$p(y|x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-(y-f_\theta(x))^2/2\sigma^2}$。**MSE 损失正是这条 PDF 的负对数似然**——最小化 MSE，就是最大化高斯 PDF 在真实标签处的取值。

**为什么"PDF 不是概率"在 DL 里要命？** 当模型预测的不确定性用 $\sigma(x)$ 表示时，医生/自动驾驶看的"置信区间"来自 PDF 的积分——单看 PDF 高度会误判。**PDF 是供积分使用的对象，不是供直读的概率。**

它的"$\lim_{\Delta x\to0}$"怎么在数值上验证、为什么 $\mathcal{N}(0,1)$ 峰值是 $\frac{1}{\sqrt{2\pi}}\approx0.399$，见《代码.md》。
