# 历史：两种机床的世纪——全连接与卷积如何各据一方

## 1943–1958：第一种机床——全连接，从神经元到感知机

神经网络的第一种"机床"（全连接）几乎与神经元同步诞生。1943 年麦卡洛克-皮茨的神经元是"全连接"的雏形：每个输入都连到输出。1958 年罗森布拉特的感知机，是第一个可学习的全连接层：输入向量 × 权重向量 + 阈值。

整个 50–80 年代，神经网络几乎只有这一种机床。它在表格数据、逻辑函数上表现不错，但处理图像时有个致命短板：**一张 28×28 的图要压成 784 维向量，每个像素都被独立对待，"相邻"信息被丢弃**（§2.2.3.1）。人们需要第二种机床。

## 1980–1998：第二种机床——卷积，从大脑到 LeNet

第二种机床（卷积）的灵感来自生物：1959 年，休伯尔和维塞尔发现猫的视觉皮层用"局部感受野"检测图像（§2.2.3.7）。1980 年，福岛邦彦的 Neocognitron 把这一发现变成"局部滑动的核"。1998 年，LeCun 的 LeNet-5 把卷积 + 反向传播结合，成为第一个实用的 CNN——**第二种机床正式量产。**

有趣的是，LeNet 论文里有一个关键工程细节：**他把卷积实现成了矩阵乘法**（im2col）——把每个滑动块拉平成向量，堆成矩阵，一次 `@` 完成。**两种机床的底层运算，从 LeNet 起就统一了。** 全连接用矩阵乘，卷积"其实也是矩阵乘"。

## 2012–2015：两种机床的合奏，登顶世界

2012 年 AlexNet 的架构，是两种机床的经典合奏：**多层卷积提取局部特征（边、纹理），展平后接全连接层做全局分类。** "局部扫描 → 全局融合"成了视觉任务的黄金配方。VGG、GoogLeNet、ResNet 都是这个配方的规模化。

为什么需要"先卷积后全连接"？因为图像的特征是"局部重复 + 全局整合"：边缘在到处出现（卷积擅长），但"这些边缘组合起来是不是一只猫"需要全局判断（全连接擅长）。**两种机床各司其职。**

## 2017 年至今：第三机床（注意力）与"局部/全局"的重新洗牌

2017 年 Transformer 引入注意力机制——一种"全局关系"运算（每个 token 关注全部 token）。它的出现让"全局融合"有了新实现，甚至在某些任务上取代了卷积。

但卷积并未退场：现代架构常是"卷积做局部、注意力做全局"的混合（如 ConvNeXt、混合视觉 Transformer）。**"全连接、卷积、注意力"三种机床共存**——每一种都在回答"如何让信息流动"的不同层次：局部窗口、全局逐对、以及"每个输出综合所有输入"的线性融合。

## 留一扇门

从 1943 年的全连接神经元，到 1998 年的卷积 LeNet，再到 2017 年的注意力——三种"机床"走过八十年，从独占到合奏。

而这一节的要点是：**无论哪种机床，底层都是线性运算（矩阵乘、滑动点积）**——真正让它们"聪明"起来的，是下一节的主角：**激活函数**。它给每台机床装上"非线性关节"。
