# 习题：层中的运算——矩阵乘法与卷积

## 第一组：概念检验

**1.1（单选）** 全连接层与卷积层最本质的区别是：
- A. 全连接用矩阵乘法，卷积不用
- B. 全连接看全局输入，卷积看局部邻域（且共享参数）
- C. 全连接不能加偏置，卷积能
- D. 卷积只能处理灰度图，全连接能处理彩色图

**1.2（判断并说明）** "卷积在工程上经常被实现成矩阵乘法（im2col），所以'全连接用矩阵乘、卷积用滑窗'并不是绝对的。" 这句话对吗？

**1.3（填空）** 全连接层公式 $\mathbf{z} = W\mathbf{x} + \mathbf{b}$，其中每个输出 $z_i = \sum_j \_\_\_ + \_\_\_$；卷积输出特征图尺寸 = 输入 $H\times W$、核 $k\times k$ 时 = $\_\_\_$（无 padding、stride=1）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算 $\mathbf{x}=[1,2]$、$W=\begin{bmatrix}0.5&0.1\\0.3&0.7\end{bmatrix}$、$\mathbf{b}=[0.2,0.3]$ 的全连接输出，用 NumPy 验证。

**2.2（代码验证）** 用 §2.2.3.7 的教材核 $F=\begin{bmatrix}1&0&-1\\1&0&-1\\1&0&-1\end{bmatrix}$ 对 $I=\begin{bmatrix}10&20&30\\10&20&30\\10&20&30\end{bmatrix}$ 卷积，手算左上角输出，用代码验证。

**2.3（动手理解）** 用 im2col 实现一个 $5\times5$ 图与 $3\times3$ 核的卷积，验证与双循环滑窗结果一致，并观察"块矩阵"的形状（$(3\times3,\ 9)$）。

## 第三组：DL 延伸

**3.1（场景判断）** 一个 CNN 模型末尾是 `Flatten()` 接 `nn.Linear(256, 10)`。为什么需要先展平再接全连接？全连接在这个位置扮演什么角色？

**3.2（场景分析）** 为什么"先多层卷积、再接全连接"是图像分类的经典配方？从"局部→全局"的信息流角度分析两种层的分工。

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：全连接每个输出综合全部输入（全局）；卷积每个输出只看 $k\times k$ 邻域且核共享（局部 + 参数共享）。A 错（卷积也可实现为矩阵乘）；C 错（两者都能加偏置）；D 错（卷积处理彩色图用多通道张量）。
- **点拨**：**"全局 vs 局部 + 共享"是两种机床的分水岭。** 这也是为什么图像用卷积、表格数据用全连接。

**1.2 对。**
- **思路**：im2col 把每个滑动块拉平成向量、堆成矩阵，一次 `@` 完成所有位置的点积——卷积的底层就是矩阵乘法。所以"全连接矩阵乘、卷积滑窗"是**概念**层面，工程实现可以统一。
- **点拨**：**矩阵乘法是深度学习的通用底层**——§2.3.4.3 说过"一切核心运算最终都是矩阵乘法"。卷积也不例外。

**1.3 答案：$W_{ij}x_j$；$b_i$；$(H-k+1)\times(W-k+1)$。**
- **思路**：全连接 $z_i=\sum_j W_{ij}x_j+b_i$；卷积输出 $(H-k+1)\times(W-k+1)$。
- **点拨**：这两个公式（一个全局、一个局部）是本节的两根柱子。

### 第二组

**2.1**
$z_0 = 0.5\cdot1+0.1\cdot2+0.2 = 0.9$；$z_1 = 0.3\cdot1+0.7\cdot2+0.3 = 2.0$。
```python
import numpy as np
W = np.array([[0.5,0.1],[0.3,0.7]]); x = np.array([1.,2.]); b = np.array([0.2,0.3])
print(W @ x + b)    # [0.9 2. ]
```
- **思路**：逐输出加权和 + 偏置。
- **点拨**：**"每个输出 = 所有输入加权和"**——全连接的全局性在此。

**2.2**
$(0,0)$ 位置：$10(1)+20(0)+30(-1)+10(1)+20(0)+30(-1)+10(1)+20(0)+30(-1) = 10-30+10-30+10-30 = -60$。
```python
I = np.array([[10.,20.,30.],[10.,20.,30.],[10.,20.,30.]])
F = np.array([[1.,0.,-1.],[1.,0.,-1.],[1.,0.,-1.]])
print(np.sum(I[:3,:3]*F))    # -60.0
```
- **思路**：核检测"左白右黑"的横向差异；这里每行 10→30（左小右大），方向与核偏好相反 → 负值。
- **点拨**：**负值也是正常检测**——核找的是"变化"，方向相反就是负。§2.2.3.7 习题 2.1 同款。

**2.3**
```python
I = np.random.rand(5,5); F = np.random.rand(3,3)
# 双循环
out = np.zeros((3,3))
for i in range(3):
    for j in range(3):
        out[i,j] = np.sum(I[i:i+3,j:j+3]*F)
# im2col
patches = np.stack([I[i:i+3,j:j+3].reshape(-1) for i in range(3) for j in range(3)])  # (9,9)
out2 = (patches @ F.reshape(-1)).reshape(3,3)
print(patches.shape)                     # (9, 9)：9 个位置 × 9 个块元素
print(np.allclose(out, out2))            # True
```
- **思路**：im2col 把"9 个位置 × 每个块 9 元素"组织成 `(9,9)` 矩阵，一次矩阵乘得到 9 个点积。
- **点拨**：**"块矩阵"的形状 = (位置数, 块大小)**。看懂这个形状，卷积的矩阵乘法实现就通了。

### 第三组

**3.1 答案：因为卷积层输出是 $(B, C, H, W)$（带空间/通道结构），而 `nn.Linear` 需要二维输入 $(B, d)$。`Flatten()` 把每张特征图 `reshape(B, -1)`（$B, C\times H\times W$），喂给全连接做全局分类。全连接在这个位置扮演"分类头"——把卷积提取的局部特征综合成最终的类别得分。**
- **思路**：卷积负责"特征提取"（局部），全连接负责"分类决策"（全局）。`Flatten` 是两者的桥梁（§2.3.2 习题 3.2 同款）。
- **点拨**：**"局部特征 → 全局决策"**是 CNN 的设计哲学。展平不是丢信息，是换"吃法"。

**3.2 思路**
- 多层卷积：从像素 → 边缘 → 纹理 → 部件 → 对象，逐层提取越来越抽象的**局部特征**（§2.2.3.7 的层次化特征图）。
- 全连接：把"提取到的特征"做**全局组合**——判断"这些特征组合起来是不是一只猫"。
- 分工逻辑：图像信息"局部重复、全局整合"——局部模式（边）到处复用（卷积擅长、参数少、平移不变），而"像不像猫"是全局判断（全连接擅长）。两者配合 = 高效且可泛化。
- **点拨**：**"先局部后全局"是图像建模的黄金配方**。现代架构（混合 Transformer）沿用此逻辑，只是"全局融合"的实现从全连接换成注意力。
