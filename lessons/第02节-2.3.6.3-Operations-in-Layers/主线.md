## 第一步：Toy Model —— 一台工厂里的两种机床

回到 §2.1 那家传话工厂。工厂里其实有**两种机床**，处理不同形状的盒子：

- **全连接机床 (fully connected / dense)**：进来一列盒子（向量），它对照"每个输入×每个输出"的兑换表（权重矩阵），把所有输入都揉进每个输出——**它看的是整列盒子，全局融合**。
- **卷积机床 (convolutional)**：进来一摞带"空间位置"的盒子（矩阵），它拿一个小模板（卷积核）在盒子上滑动，逐格点积——**它只看局部窗口，滑动扫描**。

一台机床是"全局融合"，一台是"局部扫描"——这就是深度学习里两类最基本的"层运算"。这一节把它们的公式与直觉并排摆好，你会看到：**一个网络就是这两种机床（再加激活、池化等）按顺序装配起来的流水线。**

## 第二步：正式数学讲解

### 一、全连接层：全局融合的公式

**全连接层 (fully connected layer / dense layer)** 的核心运算就是矩阵乘法 + 偏置。教材例子：$\mathbf{x}=[1,2]$、$W = \begin{bmatrix} 0.5 & 0.1 \\ 0.3 & 0.7 \end{bmatrix}$、$\mathbf{b} = [0.2, 0.3]$：

$$\mathbf{z} = W\mathbf{x} + \mathbf{b} = \begin{bmatrix} 0.5(1) + 0.1(2) \\ 0.3(1) + 0.7(2) \end{bmatrix} + \begin{bmatrix} 0.2 \\ 0.3 \end{bmatrix} = \begin{bmatrix} 0.7 \\ 1.7 \end{bmatrix} + \begin{bmatrix} 0.2 \\ 0.3 \end{bmatrix} = \begin{bmatrix} 0.9 \\ 2.0 \end{bmatrix}$$

注意：**每个输出都是"所有输入"的加权和**——第一个输出 $0.9$ 同时用了 $x_1, x_2$ 与第 1 行权重、第 1 个偏置。这就是"全连接"的名字来源：**每个输出连接全部输入。**

> **全连接层**
> $$\mathbf{z} = W\mathbf{x} + \mathbf{b}, \qquad z_i = \sum_j W_{ij}x_j + b_i$$
>
> - 每个输出 $z_i$ = 所有权重的加权和 + 自己的偏置
> - "全连接" = 输入与输出之间**全部相连**
> - 作用：把输入特征按学习到的权重**全局组合**，传递给下一层

### 二、卷积层：局部扫描的公式

**卷积层 (convolutional layer)** 用核在输入上滑动。教材例子：$4\times4$ 输入 $I$、$3\times3$ 核 $F$。核在左上角盖住 $3\times3$ 块，做点积：

$$(1)(1) + (0)(0) + (2)(1) + (0)(0) + (1)(1) + (0)(2) + (1)(1) + (1)(0) + (0)(1) = \dots$$

（逐格相乘求和，得到该位置的输出）。核滑完全部 $2\times2$ 个位置，得到 $2\times2$ 特征图。

> **卷积层**
> $$F_{\text{map}}(i,j) = \sum_{u=0}^{k-1}\sum_{v=0}^{k-1} I(i+u,\,j+v)\, F(u,v)$$
>
> - 每个输出 = 核与**局部 $k\times k$ 块**的点积
> - 核滑动共享权重（参数共享）
> - 作用：检测局部模式（边、纹理、角），平移不变

### 三、展开：两种机床的对比

| | 全连接层 | 卷积层 |
|---|---|---|
| 看的范围 | **全局**（全部输入） | **局部**（$k\times k$ 邻域） |
| 参数 | 每个输出一组权重（$m\times n$） | 一个核（$k\times k$）全图共享 |
| 输入形态 | 向量/矩阵 | 矩阵/张量（保留空间） |
| 运算 | 矩阵乘法 $W\mathbf{x}$ | 滑动点积（滑窗矩阵乘） |
| 擅长 | 特征组合、表格数据 | 图像、局部结构 |
| 平移不变 | 无 | 有 |

**为什么全连接是"全局"而卷积是"局部"？** 这是设计选择：全连接假设"每个输出都要综合全部输入"（适合特征少的表格数据）；卷积假设"局部相关的模式应该在空间各处复用"（适合图像）。**两种机床针对不同的数据本性。**

边界声明：**卷积在工程上常被实现为矩阵乘法**（im2col：把每个滑动块拉平成向量，堆成矩阵，一次 `@`）——所以"全连接用矩阵乘、卷积用滑窗"不是绝对的，卷积的底层往往是矩阵乘法。另外，**两种层都只做"线性运算"**，都需要激活函数（§2.3.6.4）引入非线性，否则深了等于没深。

## 第三步：DL 桥接

**这一节是"架构的零件图"。** 三处落点：

1. **`nn.Linear` vs `nn.Conv2d`**：PyTorch 里这两个模块就是本节两种机床。`nn.Linear(m, n)` 做全连接矩阵乘；`nn.Conv2d(in, out, kernel_size)` 做滑窗卷积。**读模型代码，就是看这两种层怎么交替装配。**

2. **CNN 的经典装配**：`Conv → ReLU → Pool → Conv → ReLU → Pool → Flatten → Linear → Softmax`——先卷积提局部特征，再全连接做全局分类。**LeNet、AlexNet、ResNet 的骨架都是这条"局部→全局"的流水线。**

3. **Transformer 的"全局卷积"**：注意力（§2.2.3.4 的点积）让每个 token 关注全部 token——它是"全连接式"的关系融合，却用点积实现。**现代架构其实是"局部（卷积）+ 全局（注意力）+ 线性（全连接）"的混合。**

一句话：**全连接层"全局融合"，卷积层"局部扫描"**——深度学习网络的每一次前向，就是这两种机床交替作业的流水线。公式你已经全会了：$W\mathbf{x}+\mathbf{b}$ 与滑动点积，一个都不神秘。
