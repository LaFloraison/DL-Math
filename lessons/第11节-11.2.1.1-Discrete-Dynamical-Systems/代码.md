# 代码：一池鱼，一代一代地迭代

主线说：离散动力系统就是 $x_{n+1} = f(x_n)$——一条规则，反复施加。本节用两个例子把它变成代码：先复现教材的**种群增长**（$f(x) = 1.2x$，从 100 长到 249），再敲开边界声明提到的那扇门——**逻辑斯蒂映射**（$x_{n+1} = r x_n(1-x_n)$），看同一台"反复施加规则"的机器，如何从驯服的线性增长，走向完全不可预测的混沌。

---

## 层一：完整脚本

```python
import numpy as np                                        # 只用到标量运算与打印

def iter_map(f, x0, n):                                   # ① 通用离散动力系统推进器
    """从 x0 出发，把规则 f 反复施加 n 次，返回轨道 x0, x1, ..., xn。"""
    traj = [x0]                                           # 轨道的第一点 = 初始条件
    x = x0
    for _ in range(n):
        x = f(x)                                          # 应用一次演化规则
        traj.append(x)
    return traj                                           # 长度 n+1

def growth(x):                                            # ② 线性增长规则 f(x) = 1.2 x
    return 1.2 * x

# ---- ③ 复现教材：五代种群增长 ----
traj = iter_map(growth, 100.0, 5)
print("=== 线性增长 x_{n+1} = 1.2 x_n（教材 §11.2.1.1）===")
for n, x in enumerate(traj):
    print(f"Generation {n}: x_{n} = {x:8.2f}")

# ---- ④ 验证闭式解：迭代结果 vs x_0 (1+r)^n ----
print("\n=== 迭代 vs 闭式解（第 10 代）===")
x_iter = iter_map(growth, 100.0, 10)[-1]
x_closed = 100.0 * (1.2 ** 10)
print(f"迭代 10 代 = {x_iter:10.4f}")
print(f"闭式解     = {x_closed:10.4f}  差 = {abs(x_iter - x_closed):.2e}")

# ---- ⑤ 逻辑斯蒂映射：同一个机器，另一条规则 ----
def logistic(r):                                          # 返回一个"规则工厂"
    def step(x):
        return r * x * (1.0 - x)
    return step

print("\n=== 逻辑斯蒂映射 x_{n+1} = r x_n (1 - x_n) ===")
for r in [2.8, 3.4, 3.9]:                                 # 三档参数：稳定 / 振荡 / 混沌
    traj = iter_map(logistic(r), 0.2, 100)                # 迭代 100 步，丢掉前 90 步（暂态）
    steady = traj[90:]                                    # 看第 91~101 步的"长期行为"
    print(f"r={r}: 长期轨道 = {np.round(steady[:6], 4)} ...")
```

运行输出（Python 3.11 + NumPy）：

看那三行逻辑斯蒂输出：$r=2.8$ 时长期轨道在 0.63–0.65 附近游荡（被吸向一个不动点，还没完全收敛）；$r=3.4$ 时在 0.45 和 0.84 之间**来回跳**（周期 2，稳定振荡）；$r=3.9$ 时数字毫无规律（**混沌**）。同一台迭代机器，只是换了一个参数 $r$，命运从稳定、到振荡、到疯狂——这就是主线边界声明那句"有规则不等于可预测"的血淋淋证据。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy —— 只需要标量算术

```python
import numpy as np
```

**做什么**：加载 NumPy。本节脚本只用标量运算和 `np.round` 格式化——`np` 在这里更像是一个"格式化工具箱"。真正的引擎是纯 Python 的 `for` 循环。

#### `import numpy as np` —— 引入数值工具箱

**操作**：加载 NumPy，绑定简写 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：无直接公式——数值操作的后勤。

### 步骤 2：定义 `iter_map` —— 通用推进器

```python
def iter_map(f, x0, n):
    traj = [x0]
    x = x0
    for _ in range(n):
        x = f(x)
        traj.append(x)
    return traj
```

#### iter_map —— 从初始条件出发，反复施加规则，返回整条轨道

`x = f(x)` 与 `traj.append(x)`

**做什么**：把任意演化规则 `f` 从初始条件 `x0` 反复施加 `n` 次，收集途中每个状态，返回轨道。这是主线定义块 $x_{n+1} = f(x_n)$ 的**通用模板**——`f` 可以是任何函数，`iter_map` 不管它长什么样。
**操作**：`traj` 列表以 `x0` 开头；循环体内"先推进、再记录"——`x = f(x)` 执行一次规则，`traj.append(x)` 把新状态收进轨道。循环 $n$ 次，轨道长度 $n+1$。
**输入**：
- `f`：演化规则，一个**单参数函数**（输入一个状态，输出下一个状态）。
- `x0`：初始条件，标量。轨道的第一点。
- `n`：步数，正整数。规则被施加的次数。
**输出**：长度为 $n+1$ 的列表 `[x0, x1, ..., xn]`——整条离散轨道。
**可调参数**：
- `f` 是核心旋钮：传 `growth`（线性增长）得到指数轨道；传 `logistic(r)`（逻辑斯蒂）得到稳定/振荡/混沌轨道；传 `lambda x: x - eta*grad(x)` 就变成梯度下降的迭代器。**`iter_map` 不认识规则，它只负责反复施加。**
- `x0` 是命运起点：逻辑斯蒂映射从 0.2 出发和从 0.9 出发，长期行为相同（都被吸向同一批不动点/吸引子），但途中的轨迹不同——§11.2.1 习题里的"起点不同、循环相同"在这里重现。
- `n` 是"跑多久"。看长期行为时，`n` 要大（如 100），并且要把前面的**暂态 (transient)**丢掉，只看尾部。
- 能不能加参数？可以把 `n` 改成 `stop`（收敛判据），比如"当相邻状态差小于 $\epsilon$ 就停"——这就是不动点迭代的停机标准。`iter_map` 是最简形态，需要时你自己加。
**对应数学**：轨道 $\{x_n\}$ 的代码形态。`traj[k]` 就是 $x_k$。

### 步骤 3：定义 `growth` —— 教材的线性增长规则

```python
def growth(x):
    return 1.2 * x
```

#### growth —— $f(x) = 1.2x$：每次增长 20%

`return 1.2 * x`

**做什么**：给定当前状态（鱼数），返回下一代状态——乘 1.2。这就是教材里"20% 增长/代"的代码写法。
**操作**：单个乘法。输入状态，输出状态 × 1.2。
**输入**：`x`——当前代的鱼数，标量。
**输出**：`1.2 * x`——下一代的鱼数。
**可调参数**：
- 把 1.2 换成 0.9（负增长），轨道一路缩向 0——衰减方向；换成 1.0，轨道钉死不动（不动点）；换成 -0.8，轨道正负振荡。**乘子的大小和符号，决定整条轨道的性格**——这正是主线第三节"为什么 1.2 决定了这一切"。
- 能不能加参数？`growth` 是写死的。想要"任意增长率"，改成 `def growth(r): return lambda x: (1+r)*x`，返回一个规则工厂——`iter_map(growth(0.2), 100.0, 5)` 与教材例子等价。更一般地，`lambda x: (1+r)*x` 本身就是 $f$。
**对应数学**：$f(x) = (1+r)x$，主线定义块里的线性特例。它的闭式解 $x_n = x_0(1+r)^n$ 在步骤 4 验证。

---

### 步骤 4：验证闭式解 —— 迭代结果 vs 公式

```python
x_iter = iter_map(growth, 100.0, 10)[-1]
x_closed = 100.0 * (1.2 ** 10)
print(f"迭代 10 代 = {x_iter:10.4f}")
print(f"闭式解     = {x_closed:10.4f}  差 = {abs(x_iter - x_closed):.2e}")
```

**做什么**：把"迭代 10 次"的结果和闭式解 $100 \times 1.2^{10}$ 并排打印，验证两者完全一致。
**操作**：`iter_map(growth, 100.0, 10)` 跑出一条 11 点轨道，`[-1]` 取最后一点（第 10 代）；`(1.2 ** 10)` 是幂运算，算出公式值。
**输入**：初始 100、乘子 1.2、10 步。
**输出**：两个标量——`619.1736` 和 `619.1736`，差 0.00e+00。
**可调参数**：把 10 换成 100，迭代 100 次和 $1.2^{100}$ 依然分毫不差——线性规则下，迭代与公式是**完全同一件事**。这正是"闭式解"的意义：把 $n$ 次迭代压缩成一个表达式。但记住主线的边界声明：只有 $f$ 是这种"齐次线性"时才有闭式解；换成逻辑斯蒂，这个验证会立刻失效（没有公式可对照）。
**对应数学**：$x_n = x_0(1+r)^n$。这是"从具体数字到字母"（主线第二步）的数值收官——$x_n$ 的封闭形式被当场验证。

### 步骤 5：逻辑斯蒂映射 —— 同一个机器，另一条规则

```python
def logistic(r):
    def step(x):
        return r * x * (1.0 - x)
    return step

for r in [2.8, 3.4, 3.9]:
    traj = iter_map(logistic(r), 0.2, 100)
    steady = traj[90:]
    print(f"r={r}: 长期轨道 = {np.round(steady[:6], 4)} ...")
```

#### logistic —— 规则工厂：返回 $f(x) = rx(1-x)$

`def step(x): return r * x * (1.0 - x); return step`

**做什么**：`logistic(r)` 不是一个规则，是一个**造规则的工厂**——传入参数 $r$，返回对应的演化规则。这是"把规则当作一等公民"的惯用写法：参数被闭包 (closure) 捕获，返回的函数可以用。
**操作**：内层 `step` 实现 $x \mapsto r x (1-x)$；外层 `logistic` 返回它。`r` 被闭包记住。
**输入**：`r`——控制非线性强度的参数。
**输出**：一个单参数函数 `step`，可直接传给 `iter_map`。
**可调参数**：`r` 是这条映射的灵魂。$r \in (1,3)$ 轨道收敛到不动点；$r=3.4$ 附近进入周期 2 振荡；$r \approx 3.57$ 之后进入混沌。**同一个函数形状，只改一个数，命运天翻地覆。**
**对应数学**：逻辑斯蒂映射 $x_{n+1} = r x_n(1 - x_n)$。$x$ 被归一化到 $[0,1]$（归一化种群比例），$(1-x)$ 是"承载力"项——种群太多时把它压回去，这与 $1.2x$ 的无限增长形成对照。

#### `steady = traj[90:]` —— 丢掉暂态，只看长期行为

**操作**：`traj[90:]` 取轨道第 91 到 101 个点。前 90 步是**暂态 (transient)**——从初始条件 $x_0=0.2$ 出发、还没"安定"下来的那一段；丢掉它，剩下的才是长期行为。
**输入**：`traj`（长度 101 的列表）、切片起点。
**输出**：长度 11 的列表——长期轨道。
**可调参数**：切片点 90 越大，丢弃的暂态越多。对混沌系统（$r=3.9$），暂态和长期本来就不可区分——混沌是"永不安定"的暂态。
**对应数学**：这就是动力系统里"长期行为 (long-term behavior)"的概念：轨道扔掉暂态后剩下的形状——可能是不动点、周期轨道、或混沌吸引子。§11.3.2 的固定点分析正是研究它。

## 边界声明：这套代码能做什么，不能做什么

1. **线性增长不是真实种群。** $1.2x$ 的轨道指数爆炸——第 100 代是 $100 \times 1.2^{100} \approx 8.3 \times 10^9$，池塘早装不下了。真实种群受承载力约束，要用逻辑斯蒂映射（含 $(1-x)$ 项）。教材的 $1.2x$ 只负责讲清"迭代机制"，不要把它当成生态模型。
2. **混沌 ≠ 随机。** $r=3.9$ 的轨道看起来"随机"，但它**完全确定**：同一种子，同一条轨道。混沌的"乱"来自对初始条件的指数级敏感（$x_0$ 差 $10^{-16}$，几十步后轨道完全不同），不是抛硬币。这是"确定性系统能产生不可预测行为"的严格意义。
3. **数值误差在混沌区会被放大。** 混沌轨道对任何舍入误差都敏感——你用 float64 算，误差在第 40 步左右就开始"张牙舞爪"。这不是 bug，这是混沌的物理性质：**可预测的保质期是有限的**。对混沌系统，做长期精确预测在原则上不可能——这正是"有规则不等于可预测"最硬的一条。
