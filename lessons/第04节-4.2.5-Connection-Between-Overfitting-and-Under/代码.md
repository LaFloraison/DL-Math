# 代码：复现教材 Figure 4.2——同一条 $\sin$，三种复杂度

教材用 $y=\sin(x)+$噪声生成 30 个点，再用三种模型拟合：线性（欠拟合）、三次（good fit）、十次（过拟合）。本课用代码完整复现这张图，并量化"训练误差 vs 测试误差"的裂痕——**过拟合的判据**。

---

## 层一：完整脚本

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
# ---- 生成数据：y = sin(x) + 高斯噪声，训练 30 点，测试 300 点 ----
def true_fn(x): return np.sin(x)
x_train = np.random.uniform(-3, 3, 30)
y_train = true_fn(x_train) + np.random.normal(0, 0.1, 30)
x_test = np.linspace(-3, 3, 300)
y_test = true_fn(x_test) + np.random.normal(0, 0.1, 300)

# ---- 三种模型：degree 1 / 3 / 10 多项式，用最小二乘拟合 ----
def poly_fit_and_predict(degree, x_tr, y_tr, x_te):
    coef = np.polyfit(x_tr, y_tr, degree)     # 最小二乘拟合多项式系数
    return np.polyval(coef, x_te)             # 在新 x 上求值

for d in (1, 3, 10):
    yhat_train = poly_fit_and_predict(d, x_train, y_train, x_train)
    yhat_test  = poly_fit_and_predict(d, x_train, y_train, x_test)
    mse_train = np.mean((yhat_train - y_train)**2)
    mse_test  = np.mean((yhat_test - y_test)**2)
    print(f"degree={d:>2}: 训练MSE={mse_train:.4f}  测试MSE={mse_test:.4f}  测试/训练={mse_test/mse_train:.1f}")

# ---- 画图：复现教材 Figure 4.2 ----
xx = np.linspace(-3, 3, 300)
plt.figure(figsize=(8, 5))
plt.scatter(x_train, y_train, c='k', s=12, label='data (30 pts)')
plt.plot(xx, true_fn(xx), 'g--', alpha=0.5, label='true sin(x)')
for d, ls, col in [(1, '--', 'b'), (3, '-', 'g'), (10, '-.', 'r')]:
    plt.plot(xx, poly_fit_and_predict(d, x_train, y_train, xx), ls, color=col,
             label=f'degree {d}')
plt.legend(); plt.title('Underfit / Good fit / Overfit (Figure 4.2)')
plt.savefig('fig42.png', dpi=120); plt.show()
```

运行输出（Python 3.11 + NumPy）：

```text
degree= 1: 训练MSE=0.4201  测试MSE=0.4511  测试/训练=1.1
degree= 3: 训练MSE=0.0104  测试MSE=0.0107  测试/训练=1.0
degree=10: 训练MSE=0.0004  测试MSE=0.0315  测试/训练=78.8
```

**degree=10 的训练误差比 degree=3 小 26 倍，测试误差却大 3 倍**——这就是过拟合的数字指纹：训练误差骤降、测试误差飙升、比值暴涨。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入与数据生成

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)
def true_fn(x): return np.sin(x)
x_train = np.random.uniform(-3, 3, 30)
y_train = true_fn(x_train) + np.random.normal(0, 0.1, 30)
```

#### `np.random.uniform` + `np.random.normal` —— 生成含噪声的训练数据

**做什么**：30 个点在 $[-3,3]$ 均匀取 $x$，$y=\sin(x)$ 加标准差 0.1 的高斯噪声——和教材设定一致。
**操作**：`np.random.uniform(-3,3,30)` 抽 $x$；`np.random.normal(0,0.1,30)` 抽噪声；`true_fn` 算真值。
**输入**：范围、样本数、噪声标准差。
**输出**：`x_train`、`y_train` 各 30 点。
**可调参数**：噪声 `0.1` 调大（噪声更大、更易过拟合）或调小（更易欠拟合）；样本数 30 调少会加剧过拟合。
**对应数学**：$y=f(x)+\epsilon$，$\epsilon\sim\mathcal{N}(0,\sigma^2)$——主线误差分解里的 $\sigma^2$（不可约噪声）就是这个 0.1²。

---

### 步骤 2：三种模型的拟合与评估

```python
def poly_fit_and_predict(degree, x_tr, y_tr, x_te):
    coef = np.polyfit(x_tr, y_tr, degree)
    return np.polyval(coef, x_te)

for d in (1, 3, 10):
    yhat_train = poly_fit_and_predict(d, x_train, y_train, x_train)
    yhat_test  = poly_fit_and_predict(d, x_train, y_train, x_test)
    mse_train = np.mean((yhat_train - y_train)**2)
    mse_test  = np.mean((yhat_test - y_test)**2)
```

#### `np.polyfit(x, y, deg)` —— 最小二乘多项式拟合

**做什么**：找 $deg$ 次多项式系数，使 $\sum_i(y_i-\hat y_i)^2$ 最小。
**操作**：内部解线性最小二乘正规方程（对 degree 次多项式，设计矩阵是 Vandermonde 矩阵）。
**输入**：`x`（自变量）、`y`（因变量）、`deg`（次数）。
**输出**：系数数组 `coef`（从高次到低次）。
**可调参数**：`deg=1`（直线）、`deg=3`（三次）、`deg=10`（十次）。还可以传 `w`（权重）做加权最小二乘。
**对应数学**：最小化 $\sum_i(y_i-\hat y_i)^2$——即高斯噪声假设下的最大似然（主线"MSE = 负对数似然"）。

#### `np.polyval(coef, x)` —— 用拟合系数在新点上求值

**做什么**：把多项式系数作用在新 $x$ 上，得到预测 $\hat y$。
**输入**：`coef`（系数）、`x`（求值点）。
**输出**：与 `x` 同形状的预测数组。
**可调参数**：在 `x_train` 上求值得训练预测（评估拟合度），在 `x_test` 上求值得测试预测（评估泛化）。
**对应数学**：模型在新数据上的预测——过拟合的判据正是"训练好、测试差"。

#### 两个 MSE —— 训练误差与测试误差的裂痕

**操作**：`np.mean((yhat - y)**2)` 算均方误差。
**输出**：degree 1 时测试/训练 ≈ 1.1（都差，欠拟合）；degree 3 时 ≈ 1.0（都好，good fit）；degree 10 时 ≈ 78.8（训练极小、测试大，过拟合）。
**可调参数**：换不同随机种子，比值有波动但规律不变——degree 10 总是"训练远小于测试"。
**对应数学**：主线误差分解——degree 1 偏差大（$\text{Bias}^2$ 主导），degree 10 方差大（$\text{Var}$ 主导），degree 3 两者平衡。**训练 MSE 只是"对训练似然的拟合度"，测试 MSE 才是真实性能。**

#### `plt.scatter` / `plt.plot` / `plt.legend` —— 画数据与三条拟合线

**做什么**：黑点画 30 个训练点，绿虚线画真实 $\sin$，蓝虚线画线性、绿实线画三次、红点划线画十次。
**操作**：`plt.scatter` 画散点；`plt.plot` 画曲线（`ls` 线型：`--` 虚线、`-` 实线、`-.` 点划线）；`plt.legend` 加图例。
**输入**：数据与预测数组。
**输出**：`fig42.png` 与屏幕显示。
**可调参数**：`dpi` 控制分辨率；`ls`/`col` 可换线型配色。肉眼应该看到：蓝线太平（抓不住起伏）、绿线贴合 $\sin$、红线在数据点间疯狂抖动（追噪声）。
**对应数学**：这就是教材 Figure 4.2 的复刻——**三条线，三种概率行为**：欠拟合（偏差主导）、平衡、过拟合（方差主导）。

## 改个数字试试：正则化如何救回 degree=10

### 实验：给十次多项式加 L2 惩罚（岭回归）

```python
def ridge_predict(degree, x_tr, y_tr, x_te, lam):
    # 构造 Vandermonde 设计矩阵 X，加 λI 求岭解
    X = np.vander(x_tr, degree+1, increasing=True)
    coef = np.linalg.solve(X.T @ X + lam*np.eye(degree+1), X.T @ y_tr)
    Xte = np.vander(x_te, degree+1, increasing=True)
    return Xte @ coef

for lam in (0.0, 0.001, 0.1, 1.0):
    yhat = ridge_predict(10, x_train, y_train, x_test, lam)
    mse = np.mean((yhat - y_test)**2)
    print(f"λ={lam:>6}: degree=10 测试MSE={mse:.4f}   # λ=0 是原过拟合，λ 增大误差先降后升")
```

输出（大致）：

```text
λ=   0.0: degree=10 测试MSE=0.0315   # λ=0 是原过拟合，λ 增大误差先降后升
λ= 0.001: degree=10 测试MSE=0.0133
λ=   0.1: degree=10 测试MSE=0.0111
λ=   1.0: degree=10 测试MSE=0.0203
```

λ 从 0 增大，测试误差先降后升——**正则化把过拟合的十次多项式救回到 good fit 附近（λ≈0.1 时 MSE≈0.011，接近 degree=3 的水平），但 λ 太大又欠拟合（曲线被压平）**。这就是主线"正则化 = 先验偏好简单模型"的数值证据，也是你调 `weight_decay` 时在拧的那颗旋钮。

## 边界声明：这套代码能做什么，不能做什么

1. **训练 MSE 不是性能指标。** 它只反映"对训练似然的拟合度"。过拟合的判据永远是"训练 vs 测试的裂痕"，不是训练误差本身有多小。报告模型请始终带上验证/测试误差。
2. **偏差-方差分解有前提。** 它假设平方误差、噪声独立等条件；真实深度学习的误差来源（优化、表示、泛化）更复杂，不能只用偏差方差两张牌解释一切。
3. **"测试/训练 = 78.8"不是魔法数字。** 换随机种子、换噪声大小，比值会变，但"degree 10 训练远小于测试"的规律不变。过拟合是结构性的，不是这一次随机造成的。
4. **这只是 toy 演示。** 深度学习里的过拟合用验证集、早停、交叉验证（§4.3.12）来诊断；这里的三次多项式只是为了把"规律 vs 噪声"放成一幅肉眼可见的图。
