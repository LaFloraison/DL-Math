# 习题：过拟合与欠拟合的概率视角

## 第一组：概念检验

**1. 用"乐器"的比喻解释过拟合，并说出它的偏差-方差特征。**

**解答**：教材的比喻——把琴调得完美贴合某一间音乐厅，搬到任何其他厅都会走音。过拟合就是把模型调到"完美贴合训练集的所有细节"，包括噪声——在训练集上 $P(D|\theta)$ 极大，在新数据上 $P(D'|\theta)$ 极差。特征是**低偏差、高方差**：对训练集完美，对任何数据扰动崩溃。对应教材十次多项式那条剧烈抖动的红曲线。

**2. 偏差和方差各是什么？为什么它们通常此消彼长（tradeoff）？**

**解答**：偏差是"模型系统性偏离真值的程度"——线性拟合 $\sin$ 的偏差巨大，因为模型族里根本没有 $\sin$ 的形状。方差是"模型对数据集改变的敏感度"——十次多项式换一批数据曲线大变。它们此消彼长是因为：增加模型复杂度时，模型更能表达真值（降偏差），但自由度多了、更容易追噪声毛刺（升方差）。误差分解 $\mathbb{E}[(y-\hat y)^2]=\text{Bias}^2+\text{Var}+\sigma^2$ 显示，最优复杂度在两者交叉处。

**3. 判断题并说明理由："L2 正则化的惩罚项 $\lambda\|w\|^2$ 在贝叶斯看来，等价于给权重一个高斯先验。"**

**解答**：正确。若先验取 $w\sim\mathcal{N}(0,\frac{1}{2\lambda})$，则先验的负对数似然是 $-\log p(w)=\lambda\|w\|^2+$常数——最大化后验（MAP）就是最小化"负对数似然 + $\lambda\|w\|^2$"，正是 L2 正则化。**正则化不是工程补丁，是贝叶斯"偏好简单模型"这一信念的数学物化。** 同理 L1 对应拉普拉斯先验（更喜欢权重恰为 0，故诱导稀疏）。

## 第二组：计算实践

**4. 手算 + 代码验证。** 用代码拟合 degree 1/3/10 三种多项式，打印各自的训练 MSE、测试 MSE 与比值，指出哪个是欠拟合、哪个是过拟合。

**解答**：见《代码.md》层一。典型输出：degree 1 训练 MSE≈0.42、测试≈0.45、比值≈1.1（都差，欠拟合）；degree 3 训练≈0.010、测试≈0.011、比值≈1.0（都好，good fit）；degree 10 训练≈0.0004、测试≈0.032、比值≈79（训练完美、测试崩溃，过拟合）。

代码验证（换 seed 复跑，规律不变）：

```python
import numpy as np
np.random.seed(0)
x = np.random.uniform(-3, 3, 30); y = np.sin(x) + np.random.normal(0, 0.1, 30)
for d in (1, 3, 10):
    c = np.polyfit(x, y, d)
    yh = np.polyval(c, x)
    print(f"degree={d}: 训练MSE={np.mean((yh-y)**2):.4f}")
```

**思路点拨**：若有人用"训练 MSE 最小"选模型，他会在 degree=10 上栽跟头——训练误差 0.0004 最小，却是最差模型。**永远用测试（或验证）误差选模型**，这是过拟合给新手的第一课。

**5. 正则化救场实验。** 对 degree=10 多项式加 L2 惩罚（岭回归），画出测试误差随 $\lambda$ 的变化，找出最优 $\lambda$ 并解释"λ 太小/太大的后果"。

**解答**：见《代码.md》"改个数字试试"。典型输出：$\lambda=0$ 时测试 MSE≈0.032（过拟合），$\lambda=0.1$ 时降到 ≈0.011（接近 degree=3 的水平），$\lambda=1$ 时回升到 ≈0.02（欠拟合）。**λ 太小惩罚不足（还过拟合），λ 太大把曲线压平（欠拟合），中间有个最优点。** 这正是主线"正则化 = 先验强度旋钮"的数值版。

## 第三组：DL 延伸

**6. 深度学习场景。** 你在训练一个 CNN 分类器：训练损失持续下降逼近 0，验证损失在第 20 个 epoch 触底后开始上升。（a）用概率语言描述发生了什么。（b）列出并解释三种对策的贝叶斯身份。（c）为什么"early stopping"也是一种正则化？

**解答**：
（a）模型把训练集里的噪声也"学会"了——训练似然 $P(D|\theta)$ 被最大化过头，新数据（验证集）的 $P(D'|\theta)$ 恶化。这就是"过拟合 = 把噪声当规律"的深度网络版：训练损失逼近 0，说明模型已经把随机毛刺背成了规律。
（b）**L2 weight decay**：给权重高斯先验，惩罚大权重；**dropout**：以概率遮罩神经元，在贝叶斯里近似变分推断（MC-dropout 被解释为后验的蒙特卡洛采样）；**数据增强**：把"变换不变性"作为先验加进训练——同一只猫旋转后还是猫，这个信念降低了对单一样本的过度拟合。
（c）早停是在验证损失上升前**截断训练**——它阻止模型继续在"最大化训练似然"的方向上走太远，本质上是在"拟合训练数据"与"保持先验偏好（简单模型）"之间提前踩刹车。从贝叶斯看，未训练的模型更接近先验，早停让最终权重停在"离先验不太远"的地方——因此它被归为隐式正则化。
**思路点拨**：若有人答"换更大的网络"，那是加重过拟合而不是对抗它——复杂度更高，方差更大。若有人把早停说成"省时间"，那是只看到表象；它的统计身份是"把训练过程当作正则化参数的路径截断"。
