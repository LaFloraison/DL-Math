# 习题：线性变换的矩阵表示

## 第一组：概念检验

**1.1（单选）** 线性变换 $T:\mathbb{R}^2\to\mathbb{R}^2$ 在标准基下满足 $T(\mathbf{e}_1)=(3,1)$、$T(\mathbf{e}_2)=(2,4)$。则 $T$ 的矩阵 $\mathbf{A}$ 是：
- A. $\begin{bmatrix}3&2\\1&4\end{bmatrix}$
- B. $\begin{bmatrix}3&1\\2&4\end{bmatrix}$
- C. $\begin{bmatrix}1&3\\4&2\end{bmatrix}$
- D. $\begin{bmatrix}3&4\\1&2\end{bmatrix}$

**1.2（判断并说明）** "给出一个矩阵 $\mathbf{A}$，就完全确定了一个线性变换 $T$，与基的选择无关。" 这句话对吗？为什么？

**1.3（填空）** 把平面逆时针旋转 $90^\circ$ 的变换满足 $T(\mathbf{e}_1)=(0,1)$、$T(\mathbf{e}_2)=(-1,0)$，所以它的矩阵 $\mathbf{A}=$ ____。$\mathbf{A}$ 的第一列是 ____，它表示 $T(\mathbf{e}_1)$ 的像。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 变换 $T(x,y)=(2x+3y,\; x-y)$。写出它在标准基下的矩阵 $\mathbf{A}$，手算 $T(3,4)$，再用 NumPy 验证。

**2.2（代码验证）** 任取一个 $3\times2$ 随机矩阵 $\mathbf{A}$、两个向量 $\mathbf{u},\mathbf{v}\in\mathbb{R}^2$ 和一个标量 $c$，验证 $\mathbf{A}(\mathbf{u}+\mathbf{v})=\mathbf{A}\mathbf{u}+\mathbf{A}\mathbf{v}$ 与 $\mathbf{A}(c\mathbf{u})=c\mathbf{A}\mathbf{u}$ 恒成立。这说明了什么？

**2.3（构造矩阵）** $T:\mathbb{R}^2\to\mathbb{R}^3$，已知 $T(\mathbf{e}_1)=(1,2,3)$、$T(\mathbf{e}_2)=(4,5,6)$。写出 $\mathbf{A}$（注意形状），手算 $T(1,1)$，再用代码验证。

## 第三组：DL 延伸

**3.1（场景判断）** 一个全连接层把 784 维输入映射到 512 维：$\mathbf{z}=\mathbf{W}\mathbf{x}+\mathbf{b}$。$\mathbf{W}$ 的形状是什么？$\mathbf{W}$ 的第 143 列在数学上是什么？在这个场景里代表什么含义？

**3.2（场景分析）** 假设一个网络只由线性层组成、没有任何激活函数：$\mathbf{z}=\mathbf{W}_2(\mathbf{W}_1\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2$。请用"矩阵表示线性变换"的视角解释：为什么这样的网络表达能力有限？它与激活函数的必要性有何关系？

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：矩阵的列 = 基向量的像。$T(\mathbf{e}_1)=(3,1)$ 放进第 1 列，$T(\mathbf{e}_2)=(2,4)$ 放进第 2 列，所以 $\mathbf{A}=\begin{bmatrix}3&2\\1&4\end{bmatrix}$。
- **验证**：$\mathbf{A}\mathbf{e}_1=$ 第 1 列 $=(3,1)$ ✓；$\mathbf{A}\mathbf{e}_2=$ 第 2 列 $=(2,4)$ ✓。
- **为什么有人选错**：选项 B 是"把像写成行"——读起来从左到右恰好是 $(3,1)$、$(2,4)$，很"顺口"，于是被当成正确答案。但约定是**列**。任何时候不确定，就用万能检验：**矩阵作用在 $\mathbf{e}_j$ 上必须取出第 $j$ 列**。B 作用在 $\mathbf{e}_1$ 上得 $(3,2)\neq(3,1)$，立刻露馅。

**1.2 这句话不对。**
- **思路**：矩阵是变换在**特定基**下的描述，不是变换本身。同一台变换 $T$，在标准基下是 $\begin{bmatrix}2&0\\0&1\end{bmatrix}$，在基 $\{(1,1),(1,-1)\}$ 下变成 $\begin{bmatrix}1.5&0.5\\0.5&1.5\end{bmatrix}$——变换没变，矩阵变了（§2.5.1 主线第四节）。反过来，同一张矩阵配不同基，定义的是不同变换。
- **点拨**：这是"对象 vs 表示"分离的完整形态。矩阵自己不会说话，必须带着"在哪个基下"这个上下文才成其为"某个变换的矩阵"。

**1.3 答案：$\mathbf{A}=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$；第一列是 $(0,1)$，它表示 $\mathbf{e}_1=(1,0)$ 逆时针旋转后到达 $(0,1)$。**
- **思路**：第 1 列填 $T(\mathbf{e}_1)=(0,1)$，第 2 列填 $T(\mathbf{e}_2)=(-1,0)$。
- **点拨**：可用"旋转两次 = 旋转 180°"检验：$\mathbf{A}^2=\begin{bmatrix}0&-1\\1&0\end{bmatrix}^2=\begin{bmatrix}-1&0\\0&-1\end{bmatrix}=-\mathbf{I}$，确实是 180°（每个点反向）。这也顺带预习了"矩阵乘法 = 变换的复合"。

### 第二组

**2.1**
先由基向量的像建矩阵：$T(\mathbf{e}_1)=T(1,0)=(2,1)$，$T(\mathbf{e}_2)=T(0,1)=(3,-1)$，所以

$$\mathbf{A}=\begin{bmatrix}2&3\\1&-1\end{bmatrix}$$

$$T(3,4)=\mathbf{A}\begin{bmatrix}3\\4\end{bmatrix}=\begin{bmatrix}2\cdot3+3\cdot4\\1\cdot3+(-1)\cdot4\end{bmatrix}=\begin{bmatrix}6+12\\3-4\end{bmatrix}=\begin{bmatrix}18\\-1\end{bmatrix}$$

```python
import numpy as np
A = np.array([[2.0, 3.0],
              [1.0, -1.0]])
v = np.array([3.0, 4.0])
print(A @ v)          # [18. -1.]
```
- **思路**：两步走——先"列 = 像"得矩阵，再矩阵乘列向量。
- **点拨**：直接代入公式 $T(3,4)=(2\cdot3+3\cdot4,\;3-4)=(18,-1)$ 可以交叉验证。矩阵乘法的答案必须和"代入公式"的答案一致，这是最廉价的自检。

**2.2**
```python
import numpy as np
rng = np.random.default_rng(0)      # 固定随机种子，可复现
A = rng.normal(size=(3, 2))         # 3×2 随机矩阵
u, v, c = rng.normal(size=2), rng.normal(size=2), 2.5
print(np.allclose(A @ (u + v), (A @ u) + (A @ v)))   # True
print(np.allclose(A @ (c * u), c * (A @ u)))         # True
```
- **思路**：**任何**矩阵都自动满足这两条——因为矩阵乘法是"行点积"，而点积对加法、数乘天然分配且齐次。这不是巧合，是构造使然：我们按"第 $j$ 列 = $T(\mathbf{e}_j)$"建矩阵，这一构造本身就保证了线性。
- **点拨**：这个结论反过来才是真正的武器——**判断一个函数 $T$ 能不能用矩阵表示，就检查它是否同时满足可加性与齐次性**。任何违反这两条的（比如 $T(\mathbf{x})=(\sqrt{x_1},x_2)$）都没有矩阵。

**2.3**
列 = 像，所以 $\mathbf{A}=\begin{bmatrix}1&4\\2&5\\3&6\end{bmatrix}$（$3\times2$）。
$$T(1,1)=T(\mathbf{e}_1)+T(\mathbf{e}_2)=(1,2,3)+(4,5,6)=(5,7,9)$$
```python
import numpy as np
A = np.array([[1.0, 4.0],
              [2.0, 5.0],
              [3.0, 6.0]])
print(A @ np.array([1.0, 1.0]))     # [5. 7. 9.]
```
- **思路**：行数 = 输出维 $m=3$，列数 = 输入维 $n=2$。
- **点拨**：形状是最好的纠错工具——$3\times2$ 乘 $(2,)$ 得 $(3,)$，维度自洽。若有人把列写反成 $2\times3$，$2\times3$ 乘 $(2,)$ 会直接报维度错误，或者（若改写成别的输入）结果形状 $ (2,)$ 立刻暴露。看见"矩阵形状和维度对不上"，先怀疑"列放反了"。

### 第三组

**3.1 答案：$\mathbf{W}\in\mathbb{R}^{512\times784}$；第 143 列是第 143 个输入基向量 $\mathbf{e}_{143}$ 在线性变换下的像——一个 512 维向量，代表"输入的第 143 个特征对 512 个输出神经元的贡献模式"。**
- **思路**：在标准基下 $\mathbf{z}=\mathbf{W}\mathbf{x}+\mathbf{b}$ 的线性部分是 $\mathbf{W}\mathbf{x}$，$\mathbf{x}$ 是 $\mathbb{R}^{784}$ 的点（坐标即分量），所以 $\mathbf{W}$ 的列就是标准基向量的像（§2.5.1 核心）。第 $j$ 列回答："输入第 $j$ 个坐标动一下，输出全体怎么变。"
- **点拨**：这正是 §2.5.3 说的**可解释性**来源——读列，就是读特征如何影响后续层。注意 $\mathbf{b}$ 使整层是**仿射 (affine)** 而非线性：$\mathbf{b}$ 不在矩阵里，因为只有 $\mathbf{W}\mathbf{x}$ 是线性部分；偏置是"平移"，线性变换没有平移。

**3.2 思路**
- **代数上塌缩**：把括号展开，$\mathbf{z}=\mathbf{W}_2\mathbf{W}_1\mathbf{x}+\mathbf{W}_2\mathbf{b}_1+\mathbf{b}_2=\mathbf{W}_{\text{eff}}\,\mathbf{x}+\mathbf{b}_{\text{eff}}$。两个矩阵相乘还是一个矩阵——**两层塌缩成一层**。再多的线性层，效果都等价于单张矩阵。
- **能力受限**：一张矩阵只能表达线性变换，而线性变换表达不了 XOR 这类非线性关系（§2.5 的定义——它"不弯折空间"）。所以"全线性"网络对非线性可分的数据无能为力。
- **激活函数的必要性**：ReLU 等激活恰好是**矩阵表达不了的增量**。深度学习靠"线性（矩阵）+ 非线性（激活）"逐层交替（§2.5.3），正是为了在"矩阵能高效批量算"的同时，补上矩阵表达不了的那部分。
- **点拨**：这是主线边界声明的直接推论——矩阵能表示的世界是线性的，非线性的部分必须另请激活函数。

## 一个"为什么有人会答错"的提醒

1.1 是典型的**行/列陷阱**——把基向量的像写成了行。记住锚点：**$\mathbf{A}\mathbf{e}_j$ 必须等于第 $j$ 列**，任何犹豫都用这条检验。1.2 是**对象/描述混淆**——矩阵看起来"就是"变换，但它只是描述；记住换基的例子：同一台机器两张表。2.2 看起来"太显然"了，有人会跳过它——但它其实是本节最锋利的结论：**"可加 + 齐次"才是"有矩阵表示"的判据**，这一条将来判断某个自定义操作能否并入矩阵运算时天天要用。
