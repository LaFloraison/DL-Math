# 代码：把"空间机器"装进矩阵，再用矩阵乘列向量驱动它

主线里我们把线性变换翻译成矩阵：**矩阵的列 = 基向量的像**。这一节把它变成代码——用 `np.array` 把"机器的规格表"写成矩阵，用 `A @ v` 让变换作用到点上，验证"任意矩阵都满足线性"两条性质，再换一组基看同一台机器如何换一张表，最后把规模抬到神经网络的一层。脚本只依赖 NumPy，约 35 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                      # NumPy：矩阵、向量、求逆都在这里

# ---- ① 把"水平拉伸2倍"这台机器写成矩阵：列 = 基向量的像 ----
#    T(e1) = (2,0)，T(e2) = (0,1)，所以第1列填(2,0)，第2列填(0,1)
A = np.array([[2.0, 0.0],               # 行0：两个像的 x 分量
              [0.0, 1.0]])              # 行1：两个像的 y 分量

# ---- ② 矩阵乘列向量 = 把变换作用到点上 ----
v = np.array([3.0, 4.0])                # 输入点 (3,4)，形状 (2,)
w = A @ v                               # A@v：矩阵乘列向量
print("A      =", A)
print("v      =", v, "-> T(v) =", w)    # 期望 [6. 4.]

# ---- ③ 手算对照：w[i] = 第 i 行与 v 的点积 ----
manual = np.array([A[0,0]*v[0] + A[0,1]*v[1],   # w0 = 2*3 + 0*4
                   A[1,0]*v[0] + A[1,1]*v[1]])  # w1 = 0*3 + 1*4
print("手算对照 =", manual)

# ---- ④ 验证线性性质：任意矩阵都满足加性 + 齐次性 ----
u = np.array([1.0, 2.0])                # 第二个输入点 (1,2)
print("加性 T(u+v)==T(u)+T(v):", np.allclose(A @ (u + v), (A @ u) + (A @ v)))
print("齐性 T(3u)==3T(u)     :", np.allclose(A @ (3.0*u), 3.0*(A @ u)))

# ---- ⑤ 同一台机器，换一组基：列 = 新基向量(1,1)、(1,-1) ----
P = np.array([[1.0,  1.0],              # 新基向量 b1=(1,1) 作第1列、b2=(1,-1) 作第2列
              [1.0, -1.0]])
Ap = np.linalg.inv(P) @ A @ P           # 换基公式：新基下的矩阵
print("换基后矩阵 =", Ap)                # 期望 [[1.5, 0.5], [0.5, 1.5]]

# ---- ⑥ 高维推广：784 个输入 -> 512 个神经元 的层矩阵 ----
W = np.random.randn(512, 784)           # 每列 = 一个输入坐标分发到 512 个输出的权重
x = np.random.randn(784)                # 一张 28×28 图摊平的 784 维向量
h = W @ x                               # 一次矩阵乘列向量 = 一次线性层前向
print("W.shape =", W.shape, "| x =", x.shape, "-> h =", h.shape)
```

运行输出（Python 3.11 + NumPy）：

```text
A      = [[2. 0.]
 [0. 1.]]
v      = [3. 4.] -> T(v) = [6. 4.]
手算对照 = [6. 4.]
加性 T(u+v)==T(u)+T(v): True
齐性 T(3u)==3T(u)     : True
换基后矩阵 = [[1.5 0.5]
 [0.5 1.5]]
W.shape = (512, 784) | x = (784,) -> h = (512,)
```

## 层二：分步逐函数拆解

### 步骤 1：把"机器"装进表格 —— `np.array` 造二维数组

```python
A = np.array([[2.0, 0.0],
              [0.0, 1.0]])
```

#### `np.array(list_of_lists)` —— 把嵌套列表变成矩阵

**做什么**：把"列表的列表"转成 NumPy 的二维数组（`ndarray`）——这就是"矩阵在计算机里的存在形式"。
**操作**：`np.array` 检查所有内层列表等长，推断形状 `(2, 2)`，数据类型 `float64`，按行存入内存。
**输入**：`[[2.0, 0.0], [0.0, 1.0]]`——外层列表 2 个元素（行），每个内层列表 2 个元素（列）。
**输出**：形状 `(2, 2)` 的二维数组。`A[i, j]` 是第 `i` 行第 `j` 列的元素；`A[:, j]` 取第 `j` 列，`A[i, :]` 取第 `i` 行。形状 `(2, 2)` 就是主线定义里的 $m\times n = 2\times2$ 矩阵。
**可调参数**：
- 形状任意：`np.array([[1.,2.,3.],[4.,5.,6.]])` 得到 `(2, 3)`。
- 传 `dtype`：`np.array([[...]], dtype=float)` 或 `np.float32` 控制精度与内存——深度学习里矩阵常用 `float32` 以省显存。
- 全零/全一矩阵可用 `np.zeros((m, n))`、`np.ones((m, n))`；随机矩阵用 `np.random.randn(m, n)`（第 6 步会用到）。
**对应数学**：主线定义块——第 $j$ 列 = 基向量 $\mathbf{v}_j$ 的像。这里第 0 列 `[2, 0]` 是 $T(\mathbf{e}_1)$，第 1 列 `[0, 1]` 是 $T(\mathbf{e}_2)$。

### 步骤 2：应用变换 —— `A @ v`

```python
w = A @ v
```

#### `ndarray @ ndarray` —— 矩阵乘向量（`@` 运算符）

**做什么**：执行主线里的 $T(\mathbf{v}) = \mathbf{A}\mathbf{v}$——把变换作用到点 $\mathbf{v}$ 上。
**操作**：矩阵乘法的"行视角"：结果的第 $i$ 个分量 = 矩阵第 $i$ 行与向量逐元素相乘再求和（点积）。`w[0] = A[0,0]*v[0] + A[0,1]*v[1] = 2*3+0*4 = 6`，`w[1] = 0*3+1*4 = 4`。也可以从"列视角"读：$\mathbf{w} = v_0\times$第0列 $+\,v_1\times$第1列——这正是"按坐标线性组合基向量的像"。
**输入**：`A`（形状 `(2, 2)`）与 `v`（形状 `(2,)`）。形状必须满足"内维对齐"：矩阵列数（2）等于向量长度（2）。
**输出**：形状 `(2,)` 的向量 `[6., 4.]`——点 `(3,4)` 的像。
**可调参数**：
- `np.dot(A, v)` 完全等价于 `A @ v`；`@` 是 Python 3.5+ 引入的矩阵乘运算符，语义更明确。
- 换向量：`A @ np.array([5., -1.])` 得 `[10., -1.]`，验证"换一个点，结构一样"。
- 形状陷阱：若 `v` 是 `(2, 1)`（列向量），`A @ v` 得 `(2, 1)`——数值相同但多了一个轴。`(2,)` 是"向量"，`(2, 1)` 是"矩阵"，广播与后续运算行为不同。
**对应数学**：主线定义块的核心等式 $[T(\mathbf{v})]_{\mathcal{C}} = \mathbf{A}[\mathbf{v}]_{\mathcal{B}}$ 在标准基下的形态。

### 步骤 3：手算对照 —— 用索引 `A[i, j]` 显式写公式

```python
manual = np.array([A[0,0]*v[0] + A[0,1]*v[1],
                   A[1,0]*v[0] + A[1,1]*v[1]])
```

**做什么**：把第 2 步黑箱里发生的事摊开，逐元素手写一遍，证明 `@` 做的就是这样一次"行点积"。
**操作**：`A[i, j]` 取出单个元素；`*` 是逐元素标量乘，`+` 是逐元素加法。
**输入**：`A`（`(2, 2)`）与 `v`（`(2,)`）的各分量。
**输出**：`[6., 4.]`——与 `A @ v` 完全一致。
**可调参数**：NumPy 索引玩法很多——负索引 `A[-1, -1]` 取右下角；切片 `A[:, 0]` 取第 0 列、`A[1, :]` 取第 1 行；`A[0, 0]` 是单个标量。本步只用最朴素的"取单个元素"。
**对应数学**：主线第三节手算 $\begin{bmatrix}2&0\\0&1\end{bmatrix}\begin{bmatrix}3\\4\end{bmatrix}$ 的完整展开。

### 步骤 4：验证线性性质 —— `np.allclose`

```python
print("加性 T(u+v)==T(u)+T(v):", np.allclose(A @ (u + v), (A @ u) + (A @ v)))
print("齐性 T(3u)==3T(u)     :", np.allclose(A @ (3.0*u), 3.0*(A @ u)))
```

#### `np.allclose(a, b)` —— 逐元素"近似相等"比较

**做什么**：判断两个数组是否在容差内逐元素相等——返回一个布尔值（True/False），用于验证"两边相等"。
**操作**：比较每个对应元素 $|a_i - b_i|$ 是否同时小于 `atol + rtol*|b_i|`。
**输入**：两个同形状的数组 `a`、`b`（这里是 `A @ (u+v)` 与 `(A @ u)+(A @ v)`，都是 `(2,)`）。
**输出**：单个 `bool`。这里两个都输出 `True`。
**可调参数**：
- `rtol`：相对容差，默认 `1e-05`；`atol`：绝对容差，默认 `1e-08`。浮点运算有舍入误差，所以"严格相等"用 `==` 会得到 False 的假警报，`allclose` 是标准做法。
- 还有第三个可选参数 `equal_nan`：默认 `False`，设为 `True` 时把 NaN 视作相等（排查训练中 NaN 时有用）。
**对应数学**：主线第一节的**可加性** $T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})$ 与**齐次性** $T(c\mathbf{u})=cT(\mathbf{u})$。这里验证的不是"某台特殊机器"，而是**任意矩阵**都自动满足这两条——因为矩阵乘法就是"行点积"，点积对加法和数乘天然分配、齐次。这正面回应主线"矩阵表示存在的地基"。

### 步骤 5：换一组基 —— `np.linalg.inv`

```python
P = np.array([[1.0,  1.0],
              [1.0, -1.0]])
Ap = np.linalg.inv(P) @ A @ P
```

**做什么**：把同一台机器（水平拉伸 2 倍）从标准基的描述，换算到新基 $\{(1,1),(1,-1)\}$ 的描述——主线第四节手算过，这里用公式复算。
**操作**：新基向量 $\mathbf{b}_1=(1,1)$、$\mathbf{b}_2=(1,-1)$ 作为 `P` 的列。换基公式 $\mathbf{A}' = \mathbf{P}^{-1}\mathbf{A}\mathbf{P}$ 的读法：先把"新基坐标"变回"标准坐标"（乘 $\mathbf{P}$），再作用原矩阵（乘 $\mathbf{A}$），最后把"标准坐标"变回"新基坐标"（乘 $\mathbf{P}^{-1}$）。
**输入**：`P`（`(2, 2)`，可逆方阵）与 `A`（`(2, 2)`）。
**输出**：`Ap`（`(2, 2)`）= $\begin{bmatrix}1.5&0.5\\0.5&1.5\end{bmatrix}$——与主线第四节手算一致，**和原矩阵 `[[2,0],[0,1]]` 不同，但描述的是同一台机器**。
**可调参数**：
- `np.linalg.inv(P)` 只接收**方阵**；`P` 不可逆（行列式为 0）会抛 `LinAlgError`。大规模/数值敏感场景不要直接用 `inv`，改用 `np.linalg.solve(P, b)` 或 `np.linalg.lstsq` 更稳。
- 换个基再试：把 `P` 改成其他两列线性无关的向量，`Ap` 又是一张新表——同一变换，无穷多种写法。
**对应数学**：主线第四节"变换（对象）vs 矩阵（描述）"——换基公式 $\mathbf{P}^{-1}\mathbf{A}\mathbf{P}$ 是 §2.6 特征分解里反复出现的核心结构。

### 步骤 6：高维推广 —— 一层神经网络的矩阵

```python
W = np.random.randn(512, 784)
x = np.random.randn(784)
h = W @ x
```

#### `np.random.randn(m, n)` —— 生成 $m\times n$ 标准正态随机矩阵

**做什么**：生成一个形状 `(512, 784)` 的矩阵，每个元素独立抽样自标准正态分布 $N(0,1)$——模拟一个随机初始化的全连接层权重。
**操作**：`randn` 按 `dtype=float64` 逐元素填充。`W` 的**第 $j$ 列**就是这个"层变换"下第 $j$ 个输入基向量 $\mathbf{e}_j$ 的像。
**输入**：两个整数 `512, 784`——先写行数（输出维 $m$），再写列数（输入维 $n$）。
**输出**：`(512, 784)` 的二维数组。
**可调参数**：维数任意（`np.random.randn(28, 28)` 得方形随机图）；想要均匀分布用 `np.random.rand`；**想要可复现**，先 `np.random.seed(0)`（或 `default_rng`）。
**操作（`W @ x`）**：`(512, 784)` 乘 `(784,)` → `(512,)`。内维 784 对齐，结果形状 = 矩阵行数。
**输出**：`h`（`(512,)`）——784 维输入被"分发"到 512 个神经元后的激活向量，即 $T(\mathbf{x})$ 的像。
**可调参数**：这一步也可以用 `np.dot(W, x)`；若用 `x.reshape(784, 1)` 做成 `(784,1)` 列向量，`h` 变 `(512,1)`——又是那个轴数陷阱。
**对应数学**：主线 DL 桥接——全连接层的 $\mathbf{W}\mathbf{x}$ 正是"矩阵的列 = 输入基向量的像"在 512 维输出空间的形态。

## 边界声明：这套代码能做什么，不能做什么

1. **矩阵是描述，不是变换本身。** 第 5 步已经实证：同一台机器在标准基下是 `[[2,0],[0,1]]`，在新基下是 `[[1.5,0.5],[0.5,1.5]]`。因此"给定一张矩阵"不等于"给定一个变换"——你还需要知道基。反过来，同一张矩阵在代码里可以当不同的变换用，全看基怎么选。
2. **只有线性变换才有矩阵表示。** 第 4 步验证的是"任意矩阵都满足线性"，但这只对**矩阵乘**成立。ReLU、sigmoid、softmax 都不是线性的——没有任何 `A @ x` 能表达它们。所以本脚本的 `A @ v` 只能驱动线性层；激活函数必须另写，无法并入矩阵乘法。
3. **`(2,)` 与 `(2,1)` 的轴数陷阱。** `np.array([3., 4.])` 是形状 `(2,)` 的向量，`np.array([[3.],[4.]])` 是形状 `(2,1)` 的矩阵。两者数值相同，但 `A @ v` 的结果形状一个是 `(2,)` 一个是 `(2,1)`。PyTorch 里 `(n,)` 与 `(n,1)` 同样是初学者最容易踩的形状坑。
4. **数值要"近似"比较，不要 `==`。** 第 4 步必须用 `np.allclose`，因为浮点乘法有舍入误差；用 `==` 偶尔会得到意外的 `False`。训练脚本里 `loss` 是否下降、梯度是否为零的判断，同样要用 `allclose`/`isclose` 或相对误差。
5. **`np.linalg.inv` 只对方阵、只在矩阵可逆时有效，且数值上不是首选。** 大规模线性系统请用 `np.linalg.solve`；奇异矩阵（行列式为 0）求逆会直接报错——这不是 bug，是在提醒你"这台变换把空间压扁了，不可逆"。
