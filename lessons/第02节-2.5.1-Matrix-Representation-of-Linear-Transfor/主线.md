## 第一步：Toy Model —— 一台"空间机器"和一张四格的表

假设你是一家自动化工厂的工程师。传送带送来一块块透明玻璃板，每块板上点着一个点：$(3,4)$、$(5,-1)$、$(2,8)$……每块板依次穿过一台机器。这台机器不弯折、不撕裂玻璃，它做一件事：**把整块玻璃沿横向拉长一倍**——每个点的 $x$ 坐标翻倍，$y$ 坐标不动。于是 $(3,4)$ 变成 $(6,4)$，$(5,-1)$ 变成 $(10,-1)$，$(2,8)$ 变成 $(4,8)$。

有一天老板说：另外那家工厂要复刻这台机器，但我们不运实物，你写一张**规格说明书**——要让对方只看文字，就能算出"任意一个点进去，会从哪个点出来"。

你一开始觉得这不可能：点有**无穷多个**，难道要列无穷多个"输入—输出对"？这说明书没法写。

但你停下来想。机器对两个特殊的点做了什么？

- 点 $(1,0)$——"只向右 1 格"——进去后变成 $(2,0)$。
- 点 $(0,1)$——"只向上 1 格"——进去后变成 $(0,1)$。

就记这两个就够了。因为**每个点都是这两个点的组合**：$(3,4) = 3\times(1,0) + 4\times(0,1)$——"向右 3、向上 4"。而机器不弯不折、对整个玻璃一视同仁，它**尊重这个组合**：像 $(3,4)$ 是怎么被拼出来的，它的像就怎么拼出来。

$$\text{像}(3,4) = 3\times\text{像}(1,0) + 4\times\text{像}(0,1) = 3\times(2,0) + 4\times(0,1) = (6,4)$$

于是说明书只需四格数字。按惯例写成一张表，列上写"基点的像"：

|         | $(1,0)$ 的像 | $(0,1)$ 的像 |
| ------- | ------------ | ------------ |
| $x$ 分量 | $2$          | $0$          |
| $y$ 分量 | $0$          | $1$          |

拿到这张表的人，对任何点都能算：$x$ 分量 = $2\cdot(\text{点的}x) + 0\cdot(\text{点的}y)$，$y$ 分量 = $0\cdot(\text{点的}x) + 1\cdot(\text{点的}y)$。看似需要无穷多数据的机器，被四格数字完全捕获。

但这里藏着一个让你直觉不安的问题：**为什么偏偏选 $(1,0)$ 和 $(0,1)$ 当"基点"？** 如果说明书用别的两个点当参照——比如 $(1,1)$ 和 $(1,-1)$——表格会不会变？机器明明还是同一台。表格变了，机器没变——那这张表到底**是**这台机器，还是只是对它的某种**描述**？直觉回答不了，我们需要精确的语言。

## 第二步：正式数学讲解

### 一、撞墙：一台空间机器，到底要记多少个"输入—输出"对？

Toy Model 里你发现：记两个基点就够了。但这是碰巧，还是必然？得先把"机器"说精确。上一节（§2.5）的定义：一个函数 $T:V \to W$ 叫**线性变换 (linear transformation / linear map)**，如果它保持两种运算：

$$T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}) \qquad\text{（可加性 additivity）}$$
$$T(c\mathbf{u}) = c\,T(\mathbf{u}) \qquad\text{（齐次性 homogeneity）}$$

"不弯折、不撕裂、一视同仁"翻译成数学，就是这两条。

现在撞墙的问题来了：**要完全描述这样一台机器，我需要记多少个"输入—输出"对？** 你直觉说"无穷多个"——毕竟每个点都可能单独作怪。好，那我们把任意一个输入 $\mathbf{v}$ 拆开。设 $\{\mathbf{v}_1,\dots,\mathbf{v}_n\}$ 是 $V$ 的一组**基 (basis)**，那么任何 $\mathbf{v}$ 都能写成 $\mathbf{v} = c_1\mathbf{v}_1 + \cdots + c_n\mathbf{v}_n$——就像任何玻璃板上的点都能写成"向右、向上"的组合。反复用上面那两条性质：

$$T(\mathbf{v}) = T(c_1\mathbf{v}_1 + \cdots + c_n\mathbf{v}_n) = c_1T(\mathbf{v}_1) + \cdots + c_nT(\mathbf{v}_n)$$

你盯着这个式子。先看具体：Toy Model 里 $T(3,4) = 3\,T(\mathbf{e}_1) + 4\,T(\mathbf{e}_2) = (6,4)$，算出来了。可如果下个点不是 $(3,4)$，而是 $(5,-1)$、$(2,8)$、$(-7,0)$ 呢？你要一个个重算吗？

不。你发现了：**每次算 $T(\mathbf{v})$，结构一模一样——"$\sum$（坐标 × 基向量的像）"**。$3$、$4$、$5$、$-7$ 这些坐标没有任何特殊之处，换成任意 $c_1,\dots,c_n$ 公式照转。于是把字母提出来：

> **只要知道 $n$ 个基向量的像 $T(\mathbf{v}_1),\dots,T(\mathbf{v}_n)$，任意输入的像都被它们的线性组合唯一决定。**

无穷多个"输入—输出"对，被线性性压缩成 $n$ 个。这就是矩阵表示存在的地基——我们不得不把这些像按顺序收进一张表，而那张表，就是矩阵。

### 二、定义块

> **线性变换的矩阵表示** —— $T$ 在基 $\mathcal{B},\mathcal{C}$ 下的矩阵 $\mathbf{A}$
>
> 设 $V$ 有基 $\mathcal{B}=\{\mathbf{v}_1,\dots,\mathbf{v}_n\}$，$W$ 有基 $\mathcal{C}=\{\mathbf{w}_1,\dots,\mathbf{w}_m\}$。线性变换 $T:V\to W$ 在（基 $\mathcal{B}$，基 $\mathcal{C}$）下的矩阵 $\mathbf{A}\in\mathbb{R}^{m\times n}$ 是这样一张 $m\times n$ 的表：**第 $j$ 列恰是第 $j$ 个基向量 $\mathbf{v}_j$ 的像 $T(\mathbf{v}_j)$ 在基 $\mathcal{C}$ 下的坐标**：
>
> $$\mathbf{A} = \Big[\,[T(\mathbf{v}_1)]_{\mathcal{C}} \;\; [T(\mathbf{v}_2)]_{\mathcal{C}} \;\; \cdots \;\; [T(\mathbf{v}_n)]_{\mathcal{C}}\,\Big]$$
>
> 而"把变换作用到 $\mathbf{v}$ 上"就是一次矩阵乘列向量：
>
> $$[T(\mathbf{v})]_{\mathcal{C}} = \mathbf{A}\, [\mathbf{v}]_{\mathcal{B}}$$
>
> 符号逐一解释：
> - $\mathcal{B},\mathcal{C}$：输入空间 $V$ 与输出空间 $W$ 的基。基就是"坐标系"——把抽象向量翻译成坐标数字所需的参照物。
> - $\mathbf{v}_j$：$V$ 的第 $j$ 个基向量；$n$ 是 $V$ 的维数（矩阵的列数）。
> - $T(\mathbf{v}_j)$：第 $j$ 个基向量的**像**——变换作用在它身上得到的结果（一个 $W$ 中的对象）。
> - $[\,\cdot\,]_{\mathcal{C}}$：把对象写成它在基 $\mathcal{C}$ 下的坐标（描述）。所以每一列是"一个对象，用 $\mathcal{C}$ 的语言写下的签名"。
> - $\mathbf{A}$ 的形状 $m\times n$：$m$ 是 $W$ 的维数（行数），$n$ 是 $V$ 的维数（列数）。
> - 等式 $[T(\mathbf{v})]_{\mathcal{C}} = \mathbf{A}[\mathbf{v}]_{\mathcal{B}}$：矩阵乘列向量，得到的就是像的坐标。

最常用的情形是标准基。当 $V=\mathbb{R}^n$、$W=\mathbb{R}^m$ 都取标准基（$\mathbf{e}_1,\dots$），坐标就是分量本身，于是上式退化成最干净的样子：

$$T(\mathbf{v}) = \mathbf{A}\mathbf{v},\qquad \mathbf{A}\text{ 的第 }j\text{ 列} = T(\mathbf{e}_j)$$

**矩阵的列，就是标准基向量的像。** 记住这一句，你就握住了这一节。

### 三、展开：为什么"列是像"，以及怎么读一张矩阵

回到 Toy Model。水平拉伸 2 倍：$T(\mathbf{e}_1)=(2,0)$、$T(\mathbf{e}_2)=(0,1)$，所以

$$\mathbf{A} = \begin{bmatrix}2&0\\0&1\end{bmatrix}$$

手算一次矩阵乘列向量，对 $\mathbf{v}=\begin{bmatrix}3\\4\end{bmatrix}$：

$$\mathbf{A}\mathbf{v} = \begin{bmatrix}2&0\\0&1\end{bmatrix}\begin{bmatrix}3\\4\end{bmatrix} = \begin{bmatrix}2\cdot3 + 0\cdot4\\ 0\cdot3 + 1\cdot4\end{bmatrix} = \begin{bmatrix}6\\4\end{bmatrix}$$

与 Toy Model 亲眼看到的一致。但注意这个乘法的另一种读法（§2.3.4.3 的列视角）：

$$\mathbf{A}\mathbf{v} = 3\times(\text{第}1\text{列}) + 4\times(\text{第}2\text{列})$$

右边恰好是 $3\,T(\mathbf{e}_1) + 4\,T(\mathbf{e}_2)$。**矩阵乘法不是别的，就是把"按坐标线性组合基向量的像"这条规则机械化。** 所以列的位置有讲究：第 $j$ 列坐在第 $j$ 个基向量的座位上。这就是为什么"列是像、不是行"。

读矩阵 = 依次看每一列，问"这一列告诉我哪个基向量去了哪"：
- **恒等变换** $T(\mathbf{v})=\mathbf{v}$：$T(\mathbf{e}_1)=(1,0)$、$T(\mathbf{e}_2)=(0,1)$，矩阵是单位阵 $\mathbf{I}$——每个基向量原地不动。
- **关于 $y$ 轴的反射**：$T(\mathbf{e}_1)=(-1,0)$、$T(\mathbf{e}_2)=(0,1)$，矩阵 $\begin{bmatrix}-1&0\\0&1\end{bmatrix}$——第一列把 $\mathbf{e}_1$ 掉头。
- **逆时针旋转 $90^\circ$**：$T(\mathbf{e}_1)=(0,1)$、$T(\mathbf{e}_2)=(-1,0)$，矩阵 $\begin{bmatrix}0&-1\\1&0\end{bmatrix}$。

这种"读列法"比死背公式可靠得多——看见一张陌生矩阵，先问：每一列把对应的基向量送到哪？

### 四、变换（对象）与矩阵（描述）的分离

回到 Toy Model 结尾那个悬着的问题：换一组"基点"，表格会变吗？会。

还是水平拉伸 2 倍那台机器。选新基 $\mathcal{B}'=\{\mathbf{b}_1,\mathbf{b}_2\}$，其中 $\mathbf{b}_1=(1,1)$、$\mathbf{b}_2=(1,-1)$。看机器对两个新基向量的像：

- $T(\mathbf{b}_1)=T(1,1)=(2,1)$。把 $(2,1)$ 在新基下展开：$(2,1)=1.5\,\mathbf{b}_1 + 0.5\,\mathbf{b}_2$，所以像的坐标是 $\begin{bmatrix}1.5\\0.5\end{bmatrix}$。
- $T(\mathbf{b}_2)=T(1,-1)=(2,-1)=0.5\,\mathbf{b}_1 + 1.5\,\mathbf{b}_2$，坐标为 $\begin{bmatrix}0.5\\1.5\end{bmatrix}$。

新基下的矩阵：

$$\mathbf{A}' = \begin{bmatrix}1.5&0.5\\0.5&1.5\end{bmatrix}$$

**机器没变，表变了。** $\begin{bmatrix}2&0\\0&1\end{bmatrix}$ 与 $\begin{bmatrix}1.5&0.5\\0.5&1.5\end{bmatrix}$ 描述的是同一台机器，只是用了两种不同的"语言"。变换是**对象**，矩阵是它在某个基下的**描述**——这正是 §2.2.1.1"向量 vs 坐标表示"的升级版：对象从"点"变成了"把整个空间搬来搬去的动作"。

### 五、边界声明

1. **矩阵不是变换本身。** 一张 $\mathbf{A}$ 只有配上"在哪个基下"才有意义；同一张矩阵在不同基下定义的是不同变换。反过来，同一变换在不同基下有不同矩阵（第四节）。所以"给一个矩阵" ≠ "给一个变换"。
2. **只有线性变换才有矩阵表示。** 可加性、齐次性缺一不可。神经网络里的激活函数 ReLU、sigmoid **不是**线性的——没有任何矩阵能表示它们。这正是深度学习必须"线性层 + 非线性激活"交替的原因（§2.5.3）。
3. **矩阵不保证可逆、形状也不必是方阵。** $\mathbb{R}^n\to\mathbb{R}^m$ 的矩阵是 $m\times n$，行列可以不等；压缩、扩张、不可逆都合法。可逆性、行列式是下一章（§2.6）的话题。

## 第三步：DL 桥接

一个全连接层做的是 $\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$。剥掉偏置 $\mathbf{b}$，$\mathbf{W}\mathbf{x}$ 就是一次矩阵乘列向量：$\mathbf{W}\in\mathbb{R}^{512\times784}$ 表示从 $\mathbb{R}^{784}$（输入像素空间）到 $\mathbb{R}^{512}$（神经元激活空间）的线性变换，用的正是**标准基**。于是本节学到的读法直接可用——**$\mathbf{W}$ 的第 $j$ 列，就是第 $j$ 个输入坐标 $\mathbf{e}_j$ 在这一层"分发"到 512 个输出神经元上的权重**：它回答"输入的第 $j$ 个特征，如何影响这一层的每一个神经元"。

$\mathbf{W}$ 是"描述"，它背后的"对象"是这一层学到的特征变换。同一个特征变换，若给输入换一套坐标系（比如对输入做 PCA 白化），$\mathbf{W}$ 会变成另一张表——正是第四节的换基现象；但变换的几何本质——它把哪个方向拉伸、哪个方向旋转——不变。所以训练时你更新的只是"描述"（$\mathbf{W}$ 的分量），而真正有解释价值的是它背后的"对象"。这也回应了 §2.5.3 说的**可解释性**：读列，就是读特征如何流动。

还有边界声明的回响：GPU 之所以能把层间运算做得极快（§2.5.3 强调的效率），正因为线性部分可以**压缩进一张矩阵**批量运算；而矩阵表达不了的非线性（ReLU），只能逐神经元逐个做、无法合并成一次矩阵乘法。于是整个网络是"矩阵能表达的一切"与"矩阵表达不了的增量"的交替——这是深度学习最基本的节律，而它的源头，就是"线性变换可以装进一张矩阵"这一句。
