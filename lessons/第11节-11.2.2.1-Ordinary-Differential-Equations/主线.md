## 第一步：Toy Model —— 一只秋千，和人人都忽略的"第二件事"

一只秋千，被你推到最高处，松手。

它荡下来，荡到最低点，速度最快，呼地冲上另一边——然后慢下来，停住，再荡回来。周而复始。如果没有摩擦，它会永远这样荡下去。

现在问你一个朴素的问题：**要预测秋千的下一步，你需要知道什么？**

你大概会说：它的位置。可你试一下——告诉你"秋千现在在最低点"，然后让你说它一秒后在哪。**说不出来。** 因为最低点有两种可能：它可能正从左边荡到右边（速度向右），也可能正从右边荡回左边（速度向左）。**同一个位置，两种未来。**

§11.2.1 你已经见过这堵墙：位置，不是一个充分的状态。要预测秋千，你还需要**第二件事**——它此刻的速度。位置 + 速度，这才够。

但秋千比鱼（§11.2.1.1）和菌落（§11.2.1.2）多了一层复杂性：**描述"位置如何变"（速度）的方程，本身又依赖"速度如何变"（加速度），而加速度又依赖位置。** 这是一个二层的套娃：位置 → 速度 → 加速度，一环咬一环。写成方程，你会看见二阶导数——$y$ 对时间变化率的**变化率**。

你盯着荡着的秋千，心里浮起本节的问题：**为什么"预测"需要位置和速度两件事？这个"两层"的结构，数学上长什么样？**

## 第二步：正式数学讲解

### 一、撞墙：一阶方程，装不下秋千

先回到熟悉的形状。§11.2.2 的方程是 $\frac{dy}{dt} = f(t, y)$——一阶常微分方程，它说"位置的变化率只依赖位置"。菌落、热茶，都归它管。

现在试着用这个形状写秋千。秋千的"位置变化率"是速度 $v$。你说 $v = f(y)$？——"速度只依赖位置"。秋千在最低点 $y=0$ 时速度应该最大，在最高点 $y=y_{\max}$ 时速度为零……似乎能写。但问题来了：**最高点的速度是零——秋千停住了吗？没有！** 它马上要荡回来。位置 $y=y_{\max}$ 处速度为零，可这不是静止，只是**转向**。你的方程 $v=f(y)$ 根本分不清"停在最高点"和"荡到最高点正要回头"——这两件事位置相同、速度相同，却一个是永恒的静止、一个是运动的转折点。

为什么分不清？因为**描述秋千需要的是加速度，不是速度。** 加速度由**位置**决定（越偏离平衡点，往回拉的力越大——这是物理），而位置的变化率（速度）由**速度自己**决定。你不可能用一条只含 $y$ 和 $y'$ 的式子同时锁死这两层。于是你被逼着写出**二阶**方程：

$$\frac{d^2 y}{dt^2} + \omega^2 y = 0$$

这里 $\frac{d^2y}{dt^2}$ 是加速度（$y$ 对 $t$ 的二阶导数），$\omega$ 是**角频率 (angular frequency)**——每秒钟荡多少个弧度的"快慢参数"。这个方程的物理来源是牛顿第二定律：$ma = F$，而恢复力 $F = -ky$ 与位移成正比、方向相反（弹簧、摆的线性近似），所以 $a = -(\frac{k}{m})y$，记 $\omega^2 = \frac{k}{m}$，就得到上式。

### 二、二阶方程：解族需要两枚常数

一阶方程 $\frac{dy}{dt} = -0.5y$ 的解族 $Ce^{-0.5t}$ 只有一个常数 $C$。二阶方程需要**两个**常数——因为要对"加速度"连续求两次积分。我们来看解长什么样。

教材给的通用解是：

$$y(t) = A\cos(\omega t) + B\sin(\omega t)$$

验证它确实满足方程。逐项求导：

$$\frac{dy}{dt} = -A\omega\sin(\omega t) + B\omega\cos(\omega t)$$
$$\frac{d^2y}{dt^2} = -A\omega^2\cos(\omega t) - B\omega^2\sin(\omega t) = -\omega^2\big(A\cos(\omega t) + B\sin(\omega t)\big) = -\omega^2 y$$

把 $\frac{d^2y}{dt^2} = -\omega^2 y$ 移项，就是 $\frac{d^2y}{dt^2} + \omega^2 y = 0$ $\checkmark$。**为什么会是正弦和余弦？** 因为正弦/余弦的导数是余弦/负正弦——求两次导数回到自身但带负号，正好与"加速度反比于位移"咬合。$\cos$ 和 $\sin$ 是"二阶导数等于自身的负"这对需求的答案。

> **简谐振动 (simple harmonic oscillator)** $\frac{d^2y}{dt^2} + \omega^2 y = 0$
>
> 物理含义：受"与位移成正比、方向相反"的恢复力作用的系统——弹簧、摆（小角度）、秋千。位置 $y(t)$ 随时间正弦/余弦式地来回摆动。
>
> $$y(t) = A\cos(\omega t) + B\sin(\omega t)$$
>
> - $y(t)$：t 时刻的位置（位移）
> - $\omega$：角频率 (angular frequency)，单位 rad/s——控制摆动的快慢
> - $A, B$：待定常数，由**初始条件**确定——初始位置 $y(0)$ 和初始速度 $y'(0)$ 各钉死一个
> - 等价写法：$y(t) = R\cos(\omega t + \phi)$，其中 $R = \sqrt{A^2+B^2}$ 是振幅，$\phi$ 是相位
> - 周期 $T = \frac{2\pi}{\omega}$：摆动一圈的时间；频率 $f = \frac{1}{T} = \frac{\omega}{2\pi}$
> - 一个二阶方程的状态需要**两个**数（位置 + 速度）——这正是 §11.2.1 "状态必须充分"的又一次印证

注意定义块里的 "$R\cos(\omega t+\phi)$"：$A\cos + B\sin$ 可以用一个余弦（带振幅 $R$ 和相位 $\phi$）重写——**这是同一个解的两种写法**，表示的是同一条曲线，只是记账方式不同。

### 三、初始条件：两枚常数怎么被钉死

通解 $y(t) = A\cos(\omega t) + B\sin(\omega t)$ 里有 $A, B$ 两个自由常数——系统有无数种可能的摆动（不同振幅、不同相位）。谁把它们钉死？**初始条件**：开始那一刻的位置 $y(0)$ 和速度 $y'(0)$。

教材的例子：$\omega = 2$，$y(0) = 1$，初速度为零。

- 代入位置：$y(0) = A\cos(0) + B\sin(0) = A = 1$。得 $A = 1$。
- 代入速度：$y'(t) = -2A\sin(2t) + 2B\cos(2t)$，所以 $y'(0) = 2B = 0$，得 $B = 0$。

于是特解：

$$y(t) = \cos(2t)$$

一个干净到发亮的答案：**从位置 1、静止出发，以 2 rad/s 的频率来回摆，曲线就是 $\cos(2t)$。** 它在 $+1$ 和 $-1$ 之间平滑往返，永不衰减——因为这是个理想的无摩擦系统。

这套"代入初值 → 解出 $A, B$"的动作，与 §11.2.2 的"通解 + 初值 = 特解"完全同构，只是这次要解两枚常数。**初位置钉死 $A$，初速度钉死 $B$**——它们各管一项，井水不犯河水，这是 $\cos$ / $\sin$ 在 $t=0$ 处取值的"正交"特性带来的礼物。

### 四、边界声明：真实的世界，没有这么乖

1. **简谐振动是线性近似。** 真实摆锤满足 $\frac{d^2y}{dt^2} + \omega^2\sin y = 0$（含 $\sin y$，非线性）。只有当摆动很小（$y$ 接近 0）时 $\sin y \approx y$，才退化成我们解的 $\frac{d^2y}{dt^2} + \omega^2 y = 0$。大角度摆动下，解不是干净的 $\cos$，周期也会拉长。**教材的摆是理想化的摆。**
2. **没有摩擦。** 真实秋千会衰减——那要加阻尼项 $+c\frac{dy}{dt}$，解里会多出指数因子 $e^{-ct}$。$\cos(2t)$ 永不衰减是"无摩擦宇宙"的产物。
3. **二阶 ODE 是"一类"，不是"全部"。** 一个系统是几阶，看它的状态需要几个量。位置+速度 → 二阶；位置+速度+加速度 → 三阶。RNN 的隐藏状态更新是一阶（只需 $h_{t-1}$ 一个量）——但它的**记忆**，要用高阶/更复杂的结构去延长（§11.3.2 会看到为什么）。

## 第三步：DL 桥接

ODE 在 RNN 身上有三层姻缘。

**第一层：RNN 就是离散化的 ODE。** 连续时间 RNN (CTRNN) 的隐藏状态 $\frac{dh}{d\tau} = -h + \sigma(W_{hh}h + W_{xh}x(\tau))$ 是一个一阶 ODE；普通 RNN 的 $h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t)$ 是它的欧拉离散化。摆锤那个"二阶"结构提醒我们：**一个状态要"充分"，得装下决定下一步的全部信息**——而普通 RNN 的 $h_t$ 往往装不下"很久以前的输入"，这正是 §11.3.2 会用 ODE 的**不动点与稳定性**解释的梯度消失问题。

**第二层：Neural ODE 是"解 ODE 代替堆层"。** 它学一个右端 $f_\theta$，前向传播 = 求解器积分 $\int_0^1 f_\theta\,d\tau$。这里没有"层数"超参数——深度是连续量。你在这节学的"解 = 顺着变化率走出来的函数"，就是 Neural ODE 前向的全部。

**第三层：谐振子藏在表征里。** 振荡系统的解是 $\cos(\omega t)$、$\sin(\omega t)$——这与你 §10 章学的傅里叶分析一脉相承（傅里叶级数就是把信号展开成各种频率的正弦/余弦）。而循环网络处理**周期序列**时，其隐藏状态常常学会"绕着圈走"——像一只在状态空间里荡的秋千。理解振荡，就是理解序列模型的一半。
