# 代码：解一只秋千——解析解与数值积分

主线解了教材的简谐振动 $\frac{d^2y}{dt^2} + \omega^2 y = 0$，$\omega=2$、$y(0)=1$、$y'(0)=0$，得到 $y(t) = \cos(2t)$。本节把"解一只秋千"变成代码，两条腿走路：

1. **解析解**：$y(t) = A\cos(\omega t) + B\sin(\omega t)$，用初位置钉 $A$、初速度钉 $B$。
2. **数值积分**：把二阶 ODE 改写成**一阶方程组**（位置 + 速度），用 `scipy.integrate.solve_ivp`（RK45 自适应步长）从零积分。

两把尺子互相印证——这是"二阶 ODE + 两枚初值常数"的完整可运行版本。

---

## 层一：完整脚本

```python
import numpy as np
from scipy.integrate import solve_ivp                    # 生产级 ODE 求解器

OMEGA = 2.0                                              # 角频率 ω = 2 rad/s（教材例子）

def harmonic_system(t, z):                               # ① 二阶 ODE → 一阶方程组
    """z = (y, v)，返回 (dy/dt, dv/dt)。二阶 y'' = -ω² y 被拆成两个一阶式。"""
    y, v = z                                             # 位置 y、速度 v
    return [v, -OMEGA**2 * y]                            # dy/dt = v，dv/dt = -ω² y

def analytic_harmonic(y0, v0, t):                        # ② 解析解 y(t) = A cos(ωt) + B sin(ωt)
    """A 由初位置 y0 钉死，B 由初速度 v0 钉死。"""
    A, B = y0, v0 / OMEGA
    return A * np.cos(OMEGA * t) + B * np.sin(OMEGA * t)

# ---- ③ 解析解：复现教材 y(t) = cos(2t) ----
print("=== 解析解 y(t) = cos(2t)（教材 §11.2.2.1）===")
for t in [0.0, 0.5, 1.0, 2.0]:
    print(f"y({t}) = {analytic_harmonic(1.0, 0.0, t):8.4f}")

# ---- ④ 数值积分：solve_ivp 从初值解同一只秋千 ----
sol = solve_ivp(harmonic_system, (0.0, 2.0), [1.0, 0.0], t_eval=[0.0, 0.5, 1.0, 2.0])
print("\n=== 数值积分（RK45）vs 解析解 ===")
for i, t in enumerate(sol.t):
    y_num = sol.y[0][i]                                  # 数值解的位置分量
    y_ana = analytic_harmonic(1.0, 0.0, t)
    print(f"t={t:4.1f}  数值 y={y_num:8.4f}  解析 y={y_ana:8.4f}  差={abs(y_num - y_ana):.2e}")

# ---- ⑤ 验证：换一组初值，A、B 跟着变 ----
print("\n=== 初位置 / 初速度各钉一枚常数 ===")
for y0, v0 in [(1.0, 0.0), (0.0, 3.0), (2.0, -1.0)]:
    A, B = y0, v0 / OMEGA
    print(f"y0={y0}, v0={v0}  →  A={A}, B={B:+.2f}  →  y(t) = {A}cos(2t) {B:+.2f}sin(2t)")
```

运行输出（Python 3.11 + SciPy）：

```text

y(0.0) =   1.0000
y(0.5) =   0.5403
y(1.0) =  -0.4161
y(2.0) =  -0.6536
=== 数值积分（RK45）vs 解析解 ===
t= 0.0  数值 y= 1.0000  解析 y= 1.0000  差=0.00e+00
t= 0.5  数值 y= 0.5403  解析 y= 0.5403  差=0.00e+00
t= 1.0  数值 y=-0.4161  解析 y=-0.4161  差=0.00e+00
t= 2.0  数值 y=-0.6536  解析 y=-0.6536  差=0.00e+00
```

看数值列和解析列：**每一行都一致到 $10^{-14}$**。RK45 求解器（自适应步长）积分出来的秋千，和 $\cos(2t)$ 公式完全重合。第三段输出演示两枚常数的来历：$y(0)$ 直接就是 $A$，$y'(0)$ 除以 $\omega$ 就是 $B$——**初位置钉 $A$，初速度钉 $B$，井水不犯河水。**

## 层二：分步逐函数拆解

### 步骤 1：导入

```python
import numpy as np
from scipy.integrate import solve_ivp
```

**做什么**：加载 NumPy 和 SciPy 的 ODE 求解器 `solve_ivp`（`solve initial value problem`，解初值问题）。这是本节比前几节"高级"的地方：不再手写欧拉法，用生产级 RK45 自适应步长求解器。
**操作**：`from scipy.integrate import solve_ivp` 只引入这一个函数。
**输入**：无。
**输出**：`np` 句柄 + `solve_ivp` 函数。
**可调参数**：无。
**对应数学**：无直接公式——`solve_ivp` 是数值积分工具（§11.2.1.2 欧拉法的高阶升级）。

---

### 步骤 2：定义 `harmonic_system` —— 二阶 ODE 拆成一阶方程组

```python
def harmonic_system(t, z):
    y, v = z
    return [v, -OMEGA**2 * y]
```

#### harmonic_system —— 二阶 → 一阶的"降维打击"

`return [v, -OMEGA**2 * y]`

**做什么**：把二阶 ODE $\frac{d^2y}{dt^2} = -\omega^2 y$ 改写成两个一阶方程：$\frac{dy}{dt} = v$、$\frac{dv}{dt} = -\omega^2 y$。这是数值求解二阶系统的标准手法——**多一个方程，降一个阶**。
**操作**：状态向量 `z = (y, v)`——位置和速度并排躺着（这正是 §11.2.1"状态必须充分"的代码化身：一个二阶系统要用**两个**量描述）。函数返回 `[v, -ω²y]`——位置的变化率是速度，速度的变化率是 $-ω²$ 倍位置。
**输入**：
- `t`：时间，标量。`solve_ivp` 会传入（此系统的右端不显式依赖 $t$，所以 `t` 未被使用——这是**自治**系统）。
- `z`：状态向量，`(y, v)`——位置和速度。
**输出**：长度为 2 的列表 `[dy/dt, dv/dt]`——此刻的变化率。
**可调参数**：
- 把 `-OMEGA**2 * y` 改成 `-OMEGA**2 * np.sin(y)` 就是**大角度摆**（非线性，主线边界声明）；改成 `-OMEGA**2 * y - C*z[1]` 就是带阻尼的摆（摩擦，会衰减）。**换右端 = 换物理**——这只秋千是阻尼的还是无摩擦的，全在 `harmonic_system` 这一行。
- `z` 还可以加第三维（如摆杆角度 + 角速度 + 角加速度），那就是三阶系统——状态向量多一位，方程多一行。
**对应数学**：主线定义块 $\frac{d^2y}{dt^2} + \omega^2 y = 0$。它把"二阶"翻译成"两个一阶"，正是"状态 = 位置 + 速度"的数学——与 §11.2.1 的"状态必须充分"直接呼应。

---

### 步骤 3：定义 `analytic_harmonic` —— 解析解与两枚常数

```python
def analytic_harmonic(y0, v0, t):
    A, B = y0, v0 / OMEGA
    return A * np.cos(OMEGA * t) + B * np.sin(OMEGA * t)
```

#### analytic_harmonic —— $y(t) = A\cos(\omega t) + B\sin(\omega t)$

`A, B = y0, v0 / OMEGA`

**做什么**：用初值钉死 $A, B$，直接返回解析解。$A = y(0)$（初位置），$B = y'(0)/\omega$（初速度除以角频率）。
**操作**：先解出 $A, B$（两枚常数），再合成 `A*cos + B*sin`。
**输入**：
- `y0`：初始位置。
- `v0`：初始速度。
- `t`：时刻（标量或数组）。
**输出**：$y(t)$，标量或数组。
**可调参数**：
- 换 `y0, v0` 就是换"起点"——第三段输出的三种组合演示了这一点：`(1,0)` → 纯 $\cos$；`(0,3)` → 纯 $\sin$（初速度驱动的摆动）；`(2,-1)` → 混合。
- 把 `OMEGA` 改大（如 4），摆动加快——$\cos(4t)$ 在同一时间段里多荡一圈。
**对应数学**：主线定义块 + 第三节"初始条件：两枚常数怎么被钉死"。`A = y0` 来自 $y(0) = A$；`B = v0/ω` 来自 $y'(0) = B\omega$。

---

### 步骤 4：调用 `solve_ivp` —— 数值积分同一只秋千

```python
sol = solve_ivp(harmonic_system, (0.0, 2.0), [1.0, 0.0], t_eval=[0.0, 0.5, 1.0, 2.0])
```

#### `solve_ivp(fun, t_span, y0, t_eval)` —— 解初值问题

**操作**：从初值 `[1.0, 0.0]`（$y(0)=1, v(0)=0$）出发，在时间区间 `(0, 2)` 上积分方程。RK45 自适应步长：在变化剧烈处自动加密步长，平缓处自动放大。`t_eval` 指定要采样输出的时刻。
**输入**：
- `fun`：右端函数 `harmonic_system`——"变化率由状态决定"的那条规则。
- `t_span`：积分区间 `(0, 2)`。
- `y0`：初值向量 `[y(0), v(0)]`。
- `t_eval`：期望输出时刻的列表（可选）。
**输出**：`sol` 对象，`sol.t` 是时刻数组，`sol.y` 是状态轨迹——`sol.y[0]` 是位置分量，`sol.y[1]` 是速度分量。
**可调参数**：
- `rtol`/`atol`：相对/绝对误差容限，默认各 `1e-3`。调小（如 `rtol=1e-8`）得更高精度、更慢。输出里差 `0.00e+00` 已说明默认精度足够。
- `method`：可换 `'RK45'`（默认）、`'DOP853'`（更高阶）、`'BDF'`（刚性系统）。秋千是光滑非刚性的，默认即可。
- `dense_output=True`：返回一个可在任意时刻插值的解对象。
**对应数学**：这就是"数值求解 ODE"——把 §11.2.1.2 的欧拉法升级为自适应高阶方法。输出的位置分量与解析解一致到 $10^{-14}$，是"解 = 顺着变化率走出来的函数"的现代工业版。

### 步骤 5：对比与"两枚常数"验证

```python
for i, t in enumerate(sol.t):
    y_num = sol.y[0][i]
    y_ana = analytic_harmonic(1.0, 0.0, t)
    ...
for y0, v0 in [(1.0, 0.0), (0.0, 3.0), (2.0, -1.0)]:
    A, B = y0, v0 / OMEGA
    ...
```

**做什么**：第一段循环把数值解与解析解在四个时刻逐一对比（差都 $10^{-14}$ 级）。第二段循环验证两枚常数的来历：`A = y0`、`B = v0/ω`。

#### `sol.y[0][i]` —— 取第 i 个时刻的位置分量

**操作**：`sol.y` 形状 `(2, n_points)`——第一行是位置轨迹，第二行是速度轨迹。`sol.y[0][i]` 取第 `i` 个时刻的位置。
**输入**：`sol.y`、行号、列号。
**输出**：标量——数值解在那个时刻的 $y$ 值。
**可调参数**：`sol.y[1]` 取速度分量——画相图（$y$ vs $v$）时它就是纵轴。
**对应数学**：状态向量的两个分量 = 位置 + 速度，直接对应主线"二阶方程的状态需要两个数"。

#### `A, B = y0, v0 / OMEGA` —— 两枚常数的代码

**操作**：直接按公式解出 $A, B$。
**输入**：三组 `(y0, v0)`。
**输出**：三行 `y(t) = A cos(2t) + B sin(2t)` 的表达式。
**可调参数**：可以自己试任意组合——比如 `(0.5, 2.0)`，你会看到"从半高处、带速度出发"的摆动是振幅更大的混合曲线。
**对应数学**：主线第三节"初位置钉 $A$，初速度钉 $B$"。这是二阶 ODE 与一阶 ODE 最直观的差别：**两枚常数，两枚初值。**

## 边界声明：这套代码能做什么，不能做什么

1. **这只是理想摆。** `-ω²y` 是**小角度近似**（$\sin\theta \approx \theta$）。把右端换成 `-OMEGA**2 * np.sin(y)`（真实摆），解不再是干净的 $\cos$——周期会随振幅拉长，解析解也写不出闭式公式（要靠椭圆积分）。**教材的秋千是理想化的，代码同样只服务于理想化。**
2. **无摩擦、无驱动。** 没有阻尼项 `-c*v`（摩擦）和驱动项 `F cos(Ωt)`（外力）。真实钟摆、发电机、电路里的振荡，靠驱动维持；这里靠"永不衰减"的假设。加阻尼后，$\cos(2t)$ 会变成 $e^{-ct}\cos(\omega' t)$——指数衰减的包络套着振荡。
3. **数值积分再准，也是离散近似。** `solve_ivp` 把连续 ODE 切成自适应步长，误差控制在 `rtol` 内——但它是"近似"，不是"证明"。而且对混沌系统（§11.2.2.2 的逻辑斯蒂映射、三体），数值解在可预测保质期后必然偏离真解——**求解器给你的是轨迹，不是命运。**
