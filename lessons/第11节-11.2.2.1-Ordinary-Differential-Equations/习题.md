# §11.2.2.1 常微分方程 —— 习题

主线解了简谐振动 $\frac{d^2y}{dt^2} + \omega^2 y = 0$：通解 $A\cos(\omega t)+B\sin(\omega t)$、两枚初值常数、以及"二阶状态需要位置 + 速度"。习题分三组：**概念检验** 验证二阶结构与解的语法，**计算实践** 手算特解并做数值对照，**DL 延伸** 把 ODE 放回 RNN 连续化与周期序列。

---

## 一、概念检验

### 题 1（选择）：为什么简谐振动是"二阶"方程？

以下哪句**最准确**地解释了 $\frac{d^2y}{dt^2} + \omega^2 y = 0$ 是二阶的？

- A. 因为它的解里有 $\cos$ 和 $\sin$ 两个函数
- B. 因为"位置的未来"需要位置和速度两个信息，而加速度（二阶导数）反比于位置
- C. 因为它有两个常数 $A, B$
- D. 因为它含有 $\omega^2$

**解答**：B。

"阶"是方程里**最高导数的阶数**。方程里有 $\frac{d^2y}{dt^2}$（二阶导数），所以是二阶。而二阶导数的出现，物理原因是：加速度（$y$ 对 $t$ 的二阶导）由位置决定（$a \propto -y$），位置的变化率（速度）由速度决定——要预测未来，必须同时知道位置和速度两个量。A、D 是把"解的形状"或"记号"误当成阶数判据；C 是二阶的一个**后果**（两枚积分常数），不是阶数的定义。

**思路点拨**：阶数 = 最高导数阶数，永远看方程本身，不看解。而"为什么会出现二阶导数"要回到牛顿第二定律与"状态必须充分"（§11.2.1）——二阶，是"两个量决定未来"的数学签名。

### 题 2（判断 + 简答）：$A$ 和 $B$ 各管什么？

有人说："简谐振动的解 $y(t)=A\cos(\omega t)+B\sin(\omega t)$ 里，$A$ 由初位置定，$B$ 由初速度定。" 验证这句话，并说明 $\cos$ / $\sin$ 在 $t=0$ 处如何"各司其职"。

**解答**：正确。$y(0) = A\cos 0 + B\sin 0 = A$——初位置直接就是 $A$（因为 $\cos 0 = 1,\ \sin 0 = 0$）。$y'(t) = -A\omega\sin(\omega t) + B\omega\cos(\omega t)$，所以 $y'(0) = B\omega$——初速度除以 $\omega$ 才是 $B$。**$\cos$ 和 $\sin$ 在 $t=0$ 处取值正交（一个取 1、一个取 0），这保证了两枚初值各钉一枚常数、互不干扰。** 这就是"井水不犯河水"的数学本质。

**思路点拨**：把"代入初值"做到底——$A = y(0)$ 是一行，$B = y'(0)/\omega$ 是一行。理解了 $t=0$ 处 $\cos$ 取 1、$\sin$ 取 0 的"正交"特性，你就不会再混 $A$ 和 $B$ 的来历。

### 题 3（简答）：把二阶 ODE 变成两个一阶——为什么能这么做？

代码里把 $y'' = -\omega^2 y$ 改写成 $\frac{dy}{dt} = v$、$\frac{dv}{dt} = -\omega^2 y$。请说明这个改写为什么合法，以及它的状态是什么。

**解答**：合法，因为二阶 ODE 的状态本来就是**两个量**——位置 $y$ 和速度 $v$。设 $v = y'$（定义速度），则 $y'' = v'$，原方程变成 $v' = -\omega^2 y$；加上 $y' = v$，就得到两个一阶方程。新状态向量是 $z = (y, v)$。**"降阶"的本质不是丢掉信息，而是把"二阶"显式地拆成"两个一阶"**——代价是多一个方程，收益是标准的数值方法（RK45）都吃一阶方程组。

**思路点拨**：判据：一阶系统需要状态里有几个量，就是"几维"。$z=(y,v)$ 两维 = 二阶。这直接对应主线第三节"二阶系统的状态需要两个数"——代码里 `solve_ivp` 的 `y0=[1.0, 0.0]` 就是同时给出位置和速度两个初值。

## 二、计算实践

### 题 1（手算：教材特解的完整推导）

$\omega = 2$，$y(0) = 1$，$y'(0) = 0$。

(a) 写出通解，代入初值解出 $A, B$。
(b) 手算 $y(0.5)$、$y(1)$、$y(\pi/2)$（$\cos 1 \approx 0.540$，$\cos 2 \approx -0.416$，$\cos \pi = -1$）。
(c) 周期是多少？

**解答**：

(a) 通解 $y(t) = A\cos(2t) + B\sin(2t)$。$y(0) = A = 1$。$y'(t) = -2A\sin(2t) + 2B\cos(2t)$，$y'(0) = 2B = 0$，$B = 0$。特解 $y(t) = \cos(2t)$。

(b) $y(0.5) = \cos 1 \approx 0.540$；$y(1) = \cos 2 \approx -0.416$；$y(\pi/2) = \cos \pi = -1$（最低点）。

(c) 周期 $T = \frac{2\pi}{\omega} = \frac{2\pi}{2} = \pi \approx 3.14$ 秒——每 $\pi$ 秒荡一个完整来回。

**思路点拨**：(a) 把主线的推导亲手走一遍；(b) 用 $t$ 的具体值感受 $\cos$ 的来回；(c) 周期公式 $T=2\pi/\omega$ 是"频率旋钮" $\omega$ 与"快慢"之间的兑换表。

**NumPy 验证**：
```python
import numpy as np
for t in [0.0, 0.5, 1.0, np.pi/2]:
    print(f"y({t:.3f}) = {np.cos(2*t):.4f}")
print("周期 =", round(2*np.pi/2, 4))
```
```
y(0.000) = 1.0000
y(0.500) = 0.5403
y(1.000) = -0.4161
y(1.571) = -1.0000
周期 = 3.1416
```

### 题 2（手算 + 代码：第二组初值）

$\omega = 2$，$y(0) = 0$，$y'(0) = 4$。

(a) 求 $A, B$，写出特解。
(b) 这个解与 $y=\cos(2t)$ 有什么相位关系？
(c) 用代码（解析或数值）验证 $y(0.5)$。

**解答**：

(a) $A = y(0) = 0$；$B = y'(0)/\omega = 4/2 = 2$。特解 $y(t) = 2\sin(2t)$。

(b) $\sin(2t) = \cos(2t - \pi/2)$——纯 $\sin$ 解是纯 $\cos$ 解**滞后四分之一周期**（$\pi/2$ 相位）。同样振幅为 2（`2sin` 的范围是 $[-2, 2]$），只是"从平衡点带速度出发"而非"从最高点静止出发"。

(c) $y(0.5) = 2\sin(1) \approx 2 \times 0.8415 = 1.683$。代码：
```python
import numpy as np
print("y(0.5) =", round(2 * np.sin(2 * 0.5), 4))
```
```
y(0.5) = 1.6830
```

**思路点拨**：(b) 是这道题的灵魂——$A\cos + B\sin$ 与 $R\cos(\omega t + \phi)$ 是同一枚硬币（主线定义块的等价写法）。$\phi$ 就是"从哪一相位开始摆"的旋钮，由初位置和初速度联合决定。**初值不改变摆的频率，只改变摆的振幅和相位**——记住这句，就抓住了二阶 ODE 的骨架。

### 题 3（手算 + 代码：二阶 ODE 的数值验证）

用 `scipy.integrate.solve_ivp` 解 $y'' + 4y = 0$、$y(0)=1$、$y'(0)=0$。

(a) 写出方程组形式的 `harmonic_system`。
(b) 跑代码，对比 $t \in \{0, 0.5, 1, 2\}$ 的数值解与 $\cos(2t)$。
(c) 把初值改成 $y(0)=0, y'(0)=3$，验证解变为 $\frac{3}{2}\sin(2t)$。

**解答**：

(a) `def f(t, z): y, v = z; return [v, -4*y]`——$\omega^2 = 4$，故 $v' = -4y$。

(b)(c) 代码：
```python
from scipy.integrate import solve_ivp
import numpy as np

def f(t, z):
    y, v = z
    return [v, -4.0 * y]

for y0, v0 in [(1.0, 0.0), (0.0, 3.0)]:
    sol = solve_ivp(f, (0, 2), [y0, v0], t_eval=[0, 0.5, 1, 2])
    ana = (lambda t: y0*np.cos(2*t) + v0/2*np.sin(2*t))
    print(f"y0={y0}, v0={v0}: 数值 {[round(v,4) for v in sol.y[0]]} vs 解析 {[round(ana(t),4) for t in sol.t]}")
```
```
y0=1.0, v0=0.0: 数值 [1.0, 0.5403, -0.4161, -0.6536] vs 解析 [1.0, 0.5403, -0.4161, -0.6536]
y0=0.0, v0=3.0: 数值 [0.0, 1.3412, 1.2484, 0.5440] vs 解析 [0.0, 1.3412, 1.2484, 0.5440]
```

**思路点拨**：这题验证"降阶 + 数值积分"的完整流程。注意 `v0/2`——$\omega=2$，所以 $B = v_0/\omega = v_0/2$。两组初值都完全吻合，说明 `solve_ivp` 与解析解是同一只秋千的两种算法。

## 三、DL 延伸

### 题 1（连续时间 RNN：隐藏状态是 ODE 的解）

连续时间 RNN (CTRNN) 的隐藏状态演化是 $\frac{dh}{d\tau} = -h + \sigma(W_{hh}h + W_{xh}x(\tau))$。

(a) 这是几阶 ODE？它的"状态"需要几个量？
(b) 与简谐振动对照：二阶系统需要位置 + 速度，CTRNN 是一阶——这个"少一阶"对记忆意味着什么？

**解答**：

(a) 一阶——方程里的最高导数是 $\frac{dh}{d\tau}$。状态是 $h(\tau)$，一个量就够描述"此刻"，因为右端完全由 $h$ 和输入 $x(\tau)$ 决定。

(b) 一阶意味着**状态里没有"速度"这类第二维**——记忆的"动量"不存在。简谐振动靠位置 + 速度两枚常数把摆动维持下去；一阶 CTRNN 的 $h$ 一旦停止接收"外力"（输入和 $W_{hh}$ 的驱动），它要么被吸向不动点、要么按 $W_{hh}$ 的谱指数衰减——**这就是普通 RNN"记不住很久以前"的结构根源**（§11.3.2 的梯度消失）。LSTM 之所以能拖住长程记忆，正是因为它给一阶系统**偷偷加了"第二维"**（细胞状态 $c_t$）——给记忆补上了它缺的"动量"。

**思路点拨**：把"阶数 = 状态维数 = 记忆容量"这条线连起来。二阶系统能振荡、能维持，一阶系统只能单调收敛或衰减——这是理解 RNN 记忆为何脆弱的数学钥匙。

### 题 2（周期序列：RNN 学会了在状态空间里荡秋千）

一个 RNN 被训练去预测正弦波 $x_t = \sin(0.5t)$ 的下一个值。训练后，它的隐藏状态 $h_t$ 常会呈现**绕圈**的轨迹。

(a) 用 ODE 的语言解释：为什么"预测周期序列"会让隐藏状态学会振荡式轨道？
(b) 这个振荡对应的 $\omega$ 是什么？如果序列周期是 $2\pi/0.5 = 4\pi$，状态绕一圈的"频率"应接近多少？

**解答**：

(a) 因为要持续预测一个永不停止的周期信号，$h_t$ 不能停在某个不动点上（否则输出会恒定）——它必须在状态空间里**持续运动**。最简单的持续运动就是绕圈（振荡），正如摆锤在相空间里转圈。RNN 学到的 $W_{hh}$ 会形成一个"带旋转的动力学"，让 $h_t$ 绕着某个吸引子（极限环）转——这正是简谐振动在状态空间的几何：$y$-$v$ 相图里的一个圆。

(b) 序列频率 $f = \frac{0.5}{2\pi}$，角频率 $\omega = 0.5$。RNN 若要"跟上"这个信号，其隐藏状态的旋转频率应接近 $\omega = 0.5$ rad/s——绕一圈约 $\frac{2\pi}{0.5} \approx 12.57$ 个时间步。**你在这节学的 $\omega$（角频率），就是 RNN 状态轨迹的"转速"。**

**思路点拨**：把主线的"摆锤"和 RNN 的"状态轨迹"连通：振荡的数学（$\cos/\sin$）是理解周期序列模型的通用语言，也是 §11.3.2 极限环 (limit cycle) 吸引子的预告。而傅里叶（§10 章）是它的频域兄弟。

**延伸预告**：§11.2.2.2 讲 PDE——自变量不止一个时的"变化语言"；§11.3.2 用 ODE 的不动点与稳定性正式解释 RNN 的记忆与梯度消失。
