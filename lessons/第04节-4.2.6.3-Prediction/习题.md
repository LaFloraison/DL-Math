# 习题：贝叶斯预测

## 第一组：概念检验

**1. 写出后验预测分布的公式，并解释每一个部分在干什么。**

**解答**：$P(y|x,D)=\int P(y|x,w)\,P(w|D)\,dw$。$P(w|D)$ 是后验——"权重 $w$ 有多可信"；$P(y|x,w)$ 是给定权重下的预测——"在 $w$ 下模型认为 $y$ 多可能"；积分把所有权重 $w$ 的预测按可信度加权平均。**它不是选一个权重，而是让所有权重按后验投票。** 传统网络的 $f_{\theta^*}(x)$ 是单次预测；预测分布是一个分布——均值 + 宽度。

**2. 预测分布里的方差由哪两块组成？分别叫什么？哪块能随数据增加而减小？**

**解答**：预测方差 = **权重不确定**（认知不确定 epistemic，$\sigma_{post}^2$ 的投影 $x^2\sigma_{post}^2$）+ **观测噪声**（偶然不确定 aleatoric，$\sigma_e^2$）。权重不确定随数据增加而减小（数据削减后验的宽度）；观测噪声即使数据无限多也消不掉（$y$ 本身有随机性）。**分清两者，是主动学习（标哪些样本）与安全决策（能不能信这个预测）的关键。**

**3. 判断题并说明理由："预测分布比只用 MAP 权重预测更好，因为前者的均值更接近真实值。"**

**解答**：错误。预测分布的"更好"不在均值更准（均值往往和 MAP 预测接近），而在它**保留的不确定信息**：预测分布给均值 + 宽度，MAP 点估计给一个自信的数。在数据稀疏处，预测分布的宽度明显变大（"我知道我不确定"），MAP 照样自信。**价值在诚实，不在更准**——对安全关键决策，"知道自己不知道"本身比"均值更准"重要。

## 第二组：计算实践

**4. 手算 + 代码验证。** 贝叶斯线性回归后验 $w\sim\mathcal{N}(0.55,0.05^2)$，噪声 $\sigma_e=0.2$。（a）在 $x=4$ 处给出预测分布（均值与标准差）。（b）95% 预测区间。（c）如果 $x=4$ 处数据稀疏（后验方差更大，比如 $w\sim\mathcal{N}(0.55,0.1^2)$），区间怎么变？

**解答**：
（a）均值 $\mu_{post}x=0.55\times4=2.2$；标准差 $\sqrt{x^2\sigma_{post}^2+\sigma_e^2}=\sqrt{16\times0.0025+0.04}=\sqrt{0.08}\approx0.283$。
（b）$[2.2-1.96\times0.283,\ 2.2+1.96\times0.283]=[2.2-0.555,\ 2.2+0.555]=[1.65,\ 2.76]$。
（c）若 $\sigma_{post}=0.1$：标准差 $\sqrt{16\times0.01+0.04}=\sqrt{0.2}\approx0.447$，区间 $[2.2-0.876,\ 2.2+0.876]=[1.32,\ 3.08]$——**更宽**。

代码验证：

```python
import numpy as np
def pred(x, sp, se):
    sd = np.sqrt(x**2*sp**2 + se**2)
    return 0.55*x, sd
for sp in (0.05, 0.1):
    m, sd = pred(4.0, sp, 0.2)
    print(f"σ_post={sp}: 均值={m:.2f}  95%区间=[{m-1.96*sd:.2f}, {m+1.96*sd:.2f}]")
```

输出：

```text
σ_post=0.05: 均值=2.20  95%区间=[1.65, 2.76]
σ_post=0.10: 均值=2.20  95%区间=[1.32, 3.08]
```

**思路点拨**：均值不变、区间变宽——**权重不确定只影响宽度，不影响中心**。若有人把"预测分布更宽"误读成"预测更不准"，提醒他：宽度是"诚实"的度量，不是"错误"的度量。

## 第三组：DL 延伸

**6. 主动学习场景。** 你的标注预算只够再标 100 个样本，要从 1 万个未标注样本里挑。用预测分布设计一个采样策略，并解释为什么它优于"随机挑"和"挑模型最自信的"。

**解答**：**不确定性采样（uncertainty sampling）**：对每个未标注样本 $x_i$，用 MC-dropout 或深度集成估计预测分布的方差 $\text{Var}(\hat y_i)$，优先标方差最大的。理由：方差大 = 模型对"这个区域的结果"最不确定——标它带来的信息增益最大，能最有效地削减该区域的权重不确定（$\sigma_{post}^2$）。随机挑浪费预算在模型已确定的区域；挑"模型最自信的"（方差最小）则是在已经学会的地方反复确认——两者都不划算。**主动学习的地图，就是预测分布方差的地图。**
**思路点拨**：若有人答"挑预测置信度最高的"，那是反向的——主动学习要标"最不确定"的。若有人困惑"为什么标不确定的能加速训练"，因为数据削减的是"认知不确定"（权重不确定），而认知不确定只在该区域有数据时才会减小——**标方差最大的样本，就是在最缺数据的区域补数据**。
