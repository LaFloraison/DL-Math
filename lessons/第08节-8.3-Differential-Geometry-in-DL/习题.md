# §8.3 微分几何在深度学习中的应用 —— 习题

本章主线把微分几何四件工具映射到深度学习的四个主题（数据流形、损失景观、泛化、信息几何），并强调这套框架的核心价值是"把工程直觉翻译成可计算的几何命题"。下面的习题分三组：**概念检验** 验证翻译表，**计算实践** 亲手做一次"几何体检"（含代码验证），**DL 延伸** 把几何语言用回真实的工程决策。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（连线题）：把几何对象与它的 DL 对应连起来

| 几何对象 | DL 对应 |
|---|---|
| (a) 流形 | (1) Hessian 矩阵 |
| (b) 切空间 | (2) 特征空间的低维结构 / 聚类 |
| (c) 度量张量 | (3) 梯度所在的方向空间 |
| (d) 曲率 | (4) Fisher 信息矩阵 |

**解答**：(a)-(2)、(b)-(3)、(c)-(4)、(d)-(1)。

- 流形 → 特征空间低维结构（§8.3.2）：数据"住"在低维流形上，类别的分离/重叠由流形结构决定。
- 切空间 → 梯度方向空间（§8.3.1）：梯度是切空间里的向量，指向最陡上升。
- 度量张量 → Fisher 信息矩阵（§8.3.4）：给参数空间装尺子，量"一步踏出影响多大"。
- 曲率 → Hessian 矩阵（§8.3.1/§8.3.3）：二阶导，特征值决定极小值平/尖与优化稳定性。

**思路点拨**：这是主线翻译表的直接检验。最容易搞混的是 (c) 与 (d)——度量张量（Fisher）量"一步的影响大小"，曲率（Hessian）量"地形弯得多厉害"。判据：**Fisher 管"走多远合适"，Hessian 管"站得稳不稳"。**

### 题 2（判断 + 简答）：几何翻译的意义

为什么把"训练卡住"翻译成"鞍点问题"、把"过拟合"翻译成"尖锐极小值"、把"模型不自信"翻译成"Fisher 几何"是有价值的？给出一个"翻译带来的实际好处"的例子。

**解答**：翻译的价值在于**把现象描述升级为机制解释，从而获得可操作的诊断工具**。

例子：如果只知道"训练卡住"，对策是瞎试（调学习率、换优化器、重新初始化……）；但如果诊断为"鞍点问题"，你就知道：① 梯度接近零是暂时的（鞍点沿某些方向有负曲率，有路可走）；② 自适应优化器（Adam）沿平坦方向放大步长，能更快逃离；③ 可以加动量或噪声扰动帮助脱离；④ 可以沿 Hessian 负特征值方向显式推动。**同一个"卡住"，翻译前后，对策从碰运气变成了有依据的设计。** 这就是 8.3 主线"让手感变成测量"的核心主张。

**思路点拨**：这道题考的是"为什么这章值得学"，不是考一个公式。回答的骨架：现象（卡住）→ 机制（鞍点：梯度≈0、曲率混合）→ 对策（自适应方法/动量/扰动）。若只会背翻译表而说不出一句"翻译带来什么"，说明还没接住这章的方法论价值。

### 题 3（简答）：四片透镜如何描述同一个训练周期

用流形、切空间、度量、曲率四个概念，各用一句话描述"训练一个分类器"的四个阶段：数据进入、参数移动、参数落点、泛化预估。

**解答**：

- **数据进入**（流形）：输入数据住在低维流形上，网络在学的正是这个流形的结构，使同类聚团、异类分离（§8.3.2）。
- **参数移动**（切空间）：每一步，梯度在参数点的切空间里给出最陡上升方向，优化器沿负方向更新（§8.3.1）。
- **参数移动的步幅**（度量）：Fisher 信息矩阵定义参数空间的真实尺度——在哪一步踏出影响大、在哪一步影响小（§8.3.4）。
- **参数落点**（曲率）：优化停在某个极小值，其曲率（Hessian 特征值）决定它是平坦盆地还是尖锐尖峰（§8.3.1）。
- **泛化预估**（曲率）：平坦极小值对扰动不敏感 → 泛化好；尖锐极小值对扰动敏感 → 过拟合（§8.3.3）。

**思路点拨**：这是把主线的"四片透镜"变成对训练过程的完整描述。核心是每个几何对象对应一个**阶段性问题**：在哪（流形）、往哪走（切空间）、走多远（度量）、稳不稳（曲率）。若你还能说出这些对象之间的衔接（如"曲率来自度量"、"切空间上的内积由度量给出"），说明已经把它们织成一张网。

## 二、计算实践

### 题 1（用曲率判断一个极小值平不平）

训练完代码.md 的 MLP，收敛点 Hessian 特征值为：λ = [0.04, 0.31, 0.42, 0.87, 1.21, ..., 2.65]（17 个，最小 0.04、最大 2.65，全为正）。

(a) 这个收敛点是凸谷还是鞍点？判据是什么？
(b) λ_max = 2.65 意味着什么？它对你预测"这个模型泛化如何"有什么提示？
(c) 如果改用更强的 L2 正则化，λ_max 预计会怎样变化？为什么？

**解答**：

(a) **凸谷（局部最小值）**。判据：所有特征值 $\lambda > 0$（Hessian 正定）。这里 $\lambda_{\min} = 0.04 > 0$，所以是真正的极小值，不是鞍点（鞍点要求至少一个负特征值）。

(b) $\lambda_{\max} = 2.65$ 是**最尖锐方向**的曲率。它提示：沿这个方向，参数轻微扰动会显著改变损失——模型在这个方向上对扰动比较敏感。不过 $2.65$ 相对不算大（平坦极小值的典型信号），整体落在宽盆地中，可以预期泛化较好。更严格地说，$\lambda_{\max}$ 越小，泛化越有保障——这正是 §8.3.3 的量化判据 $\lambda_{\max}(H)$ 小 → 平坦 → 泛化好。

(c) **预计 $\lambda_{\max}$ 变小**。L2 正则化在损失里加 $\frac{\lambda}{2}\|\theta\|^2$，对 Hessian 的作用相当于所有特征值统一加 $\lambda$（二阶导加常数），同时它改变收敛点位置，偏向"权重小、曲率低"的区域。净效果是让模型停在更平坦、更不敏感的极小值——曲率谱被"压平"。这就是"正则化引导优化走向平坦区域"的几何机制。

**思路点拨**：这道题把代码.md 的透镜四输出变成解释练习。(a) 用 $\lambda_{\min} > 0$ 判凸谷；(b) 用 $\lambda_{\max}$ 估泛化；(c) 理解正则化对曲率谱的压平效应。核心判据记三句话：**全正 = 谷、有负 = 鞍、$\lambda_{\max}$ 小 = 平 = 泛化好。**

### 题 2（损失景观切片：识别盆地与马鞍）

你在某收敛点 $\theta^*$ 附近做损失景观切片（像代码.md 的 `loss_slice`），得到两个正交方向的切面数据：

- 沿方向 $d_1$：$L(\theta^* \pm 0.5 d_1) = 0.09, 0.35$（对称升高）
- 沿方向 $d_2$：$L(\theta^* \pm 0.5 d_2) = 0.09, 0.09$（几乎不变）

(a) 从这个切面判断：$\theta^*$ 是凸谷、马鞍，还是两者都不是？说出依据。
(b) 沿 $d_2$ 方向损失几乎不变，说明 $d_2$ 是哪个曲率特征的方向？

**解答**：

(a) **是凸谷，但接近"退化"的凸谷**。沿 $d_1$ 两个方向损失都升高（谷的特征：四周高于中心）；沿 $d_2$ 损失几乎不变（平坦方向）。$d_2$ 方向没有升也没有降——它是**零曲率（近似）方向**。一个方向曲率正、一个方向曲率≈0，按 8.2.4 的判据这是 $K \approx 0$ 的可展/平坦型；在 Hessian 语言里，$\lambda_{d_1} > 0$、$\lambda_{d_2} \approx 0$，仍有 $\lambda_{\min} \approx 0$，所以是"几乎平坦方向的凸谷"。

(b) $d_2$ 是**近似零特征值方向**（Hessian 的近似零本征方向）。沿这个方向，参数可以大幅移动而不改变损失——它对应模型中的"冗余参数方向"或"对称方向"。这种方向的存在，正是"参数空间维度远大于有效自由度"的表现（呼应 §8.2.1 的流形假说：数据/模型的有效结构维度低）。

**思路点拨**：这道题教你"读切片"。判据：**切片四周都升 = 谷；一边升一边降 = 马鞍；某方向几乎不变 = 零曲率/冗余方向。** 最容易错的是把"某方向不变"当成"整体是平面"——不，其他方向可能还是谷。零曲率方向在真实网络中常见（ReLU 网络的尺度对称性、冗余神经元），这也是 Hessian 特征值谱常含大量近似零的原因。

### 题 3（特征空间分离度：类间 vs 类内距离）

代码.md 的透镜一给出：A 类中心在 $c_A$、B 类中心在 $c_B$，类间距离 $d_{AB} = 2.29$。设 A 类特征点的标准差（类内散布半径）约 $s_A = 0.3$、B 类约 $s_B = 0.3$。

(a) 计算"分离度比" $\rho = \frac{d_{AB}}{s_A + s_B}$，这个比值说明类的可分性如何？
(b) 如果 $\rho < 1$，说明什么？工程上你会怎么处理？
(c) 从度量张量的角度，"类间距离"应该用什么尺子量才更有语义？

**解答**：

(a) $\rho = \frac{2.29}{0.3 + 0.3} = \frac{2.29}{0.6} \approx 3.8$。类间距是类内散布的近 4 倍——**高度可分**。这正是一个"网络学到了好特征"的量化信号（呼应 §8.3.2 特征空间分析：同类聚紧、异类分离）。

(b) 如果 $\rho < 1$，类间距离小于类内散布——**两类在特征空间里重叠**。这预示分类器在该特征下必然出错。工程处理：① 检查是不是模型没收敛/欠拟合；② 加大模型容量或换架构；③ 用度量学习（对比学习）显式拉近同类、推开异类；④ 检查数据标签是否本身有噪声（流形重叠的真实原因）。

(c) 欧氏类间距离假设特征空间平直。更"语义"的尺子是**沿数据流形的测地距离**（§8.3.2 讨论过：欧氏直线可能穿出流形），或按 Fisher/协方差加权的**马氏距离**（对每个方向的散布尺度归一化）。用马氏距离：$d^2_{AB} = (c_A - c_B)^\top \Sigma^{-1} (c_A - c_B)$，其中 $\Sigma$ 是类内协方差——它自动把"散布大的方向"的距离压低，避免了"欧氏距离被噪声方向主导"的问题。

**思路点拨**：这道题把特征空间分析变成定量判据。核心比值：$\rho = d_{AB}/(s_A + s_B)$。判据：$\rho \gg 1$ 可分、$\rho < 1$ 重叠。这部分还预告了 8.3.2 的"用度量量距离"主题——欧氏只是度量张量为单位矩阵的特例，真实语义需要流形/协方差感知的尺子。

## 三、DL 延伸

### 题 1（几何诊断帮你在两个模型里选）

你训练了两个模型：模型 X 收敛点 Hessian 最大特征值 $\lambda_{\max}(H_X) = 0.5$，模型 Y 的 $\lambda_{\max}(H_Y) = 50$。两者训练集损失几乎相同（$0.09$ vs $0.08$）。

(a) 不跑测试集，你更看好哪个模型的泛化？为什么？
(b) 这个判断的局限是什么？（提示：$\lambda_{\max}$ 是充分条件还是必要条件？）

**解答**：

(a) **更看好 X**。两者训练损失相同，但 X 落在平坦极小（$\lambda_{\max}$ 小、对扰动不敏感），Y 落在尖锐极小（$\lambda_{\max}$ 大、对扰动极敏感）。按 §8.3.3 与平坦极小值理论，X 更可能泛化好——因为它的解对参数/输入的微小扰动稳健，学到的是"宽泛模式"而非"训练集细节"。

(b) 局限：$\lambda_{\max}$ 是一个**启发式指标，不是保证**。① 它只刻画局部曲率，不保证全局结构；② 泛化还受数据、架构、初始化、训练过程中的随机性影响；③ 在测试集上验证仍是金标准——$\lambda_{\max}$ 用于"在验证之前快速筛掉明显危险的解"，或用于设计（SAM 把 $\lambda_{\max}$ 当优化目标）。**"平"是泛化好的强烈信号，但不是充分条件，更不是必要条件**（也有平坦但泛化差的边界情形）。

**思路点拨**：这道题把 $\lambda_{\max}$ 用进选型决策。核心：$\lambda_{\max}$ 小 → 对扰动不敏感 → 更可能泛化好，但它是启发式。判据一句话：**用 $\lambda_{\max}$ 做预筛与设计（SAM），用测试集做最终裁决。** 这也衔接了 8.3.3 与 8.4.1（正则化把 $\lambda_{\max}$ 压低）。

### 题 2（信息几何翻译"不确定性"）

一个分类器输出 $p(y|x) = 0.9$。两种解读：解读一"0.9 就是 90% 把握"；解读二"需要看参数空间里 Fisher 度量给出的置信几何"。用 §8.3.4 的框架解释解读二，并给出一个解读一可能误导你的场景。

**解答**：解读二认为，预测的"把握"不只是输出数值，而是参数空间里的几何对象。在贝叶斯/信息几何框架下，权重的后验分布在参数流形上摊开，Fisher 信息矩阵定义该流形的度量——预测的不确定性（epistemic）由后验在这个度量下的"宽度/曲率"决定。两个点预测都输出 0.9，但一个的后验尖锐集中（真正确定），另一个的后验平坦宽阔（只是碰巧在这一点输出 0.9，实际毫无把握）——它们的"0.9"含义完全不同。

解读一误导的场景：模型只在分布内数据上训练过。来了一张训练分布外的输入（比如手机拍摄的雾天交通牌，训练数据只有晴天街拍），模型可能仍输出 0.9——但它的后验在这片输入上极宽、Fisher 度量给出的置信区间极大。解读一会让你误信 0.9；解读二会让你知道"这个 0.9 是虚张声势"。这正是贝叶斯深度学习（§4.2.6 提到过）要解决的问题，而信息几何给它提供了几何语言。

**思路点拨**：这道题把"不确定性"翻译成几何。核心命题：**单点预测不携带置信度，置信度活在参数/预测分布的几何里（后验宽度 × Fisher 度量）。** 判据：看到 0.9 时问——"这个 0.9 的后验是尖的还是平的？" 呼应主线 8.3.4"Fisher 度量计量把握"的主题，也把第 4 章 BNN 的内容用几何重新串了一遍。

### 题 3（把四个透镜整合成一个决策）

你是一个模型调试工程师，遇到如下问题：训练 loss 停在 0.35 不动，验证 loss 一直升高，测试集准确率远低于训练集。用四个几何概念各给出一个"可能的诊断 + 对应的检查手段"。

**解答**：

- **流形（数据结构）**：诊断——训练与验证数据的特征空间可能不一致（分布漂移，或训练数据本身的流形结构过窄）；检查——把训练/验证点一起投影到 PCA/t-SNE 看是否重叠，类间分离度 $\rho$ 是否够大。
- **切空间（优化）**：诊断——可能踩上鞍点或卡在高曲率窄谷，梯度接近零但没到谷底；检查——看梯度范数曲线是否长期停滞，损失景观切片在收敛点附近是盆地还是马鞍，必要时调学习率/换 Adam。
- **度量（Fisher/敏感度）**：诊断——某些参数方向对预测极敏感（Fisher 特征值大），训练对这些方向的噪声极不稳定；检查——算 Fisher 对角或 Hessian 特征值，找"雷区"方向，考虑梯度裁剪或归一化。
- **曲率（泛化）**：诊断——模型落进尖锐极小值（过拟合训练细节）；检查——$\lambda_{\max}(H)$ 是否异常大，加正则化/用 SAM 找平坦解，对比扰动权重后验证集是否骤降。

**思路点拨**：这是一道整合题，考四片透镜能否协同工作。好的回答让四个诊断互相印证（如"曲率尖锐"可能源于"数据流形过窄"）。判据：每个诊断都要落到一个**可检查的量**（PCA 投影、梯度范数、Fisher/Hessian 特征值、扰动响应），而不是空泛的"可能过拟合"。这也正是 8.3 主线"把手感变成测量"的最终演练。
