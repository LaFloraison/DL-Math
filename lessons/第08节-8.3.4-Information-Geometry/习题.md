# §8.3.4 信息几何 —— 习题

本章主线讲了三件事：概率分布构成统计流形，Fisher 信息矩阵是其黎曼度量（"参数动一步，预测分布改变多少"的尺子）；自然梯度用 $I^{-1}$ 把欧氏梯度翻译成真实几何方向，在病态 Fisher 下更快更稳；贝叶斯深度学习用 Fisher 几何计量不确定性与引导更新。下面的习题分三组：**概念检验** 验证核心定义，**计算实践** 把 Fisher 与自然梯度亲手算一遍（含代码验证），**DL 延伸** 把信息几何用回真实工程。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：关于 Fisher 信息矩阵，哪个说法**错误**？

- A. $F(\theta)$ 度量"参数微扰 $\delta\theta$ 在多大程度上改变预测分布"
- B. $F(\theta)$ 是统计流形上的黎曼度量（度量张量）
- C. 在逻辑回归的"饱和区"（概率接近 0 或 1），$F$ 通常很大
- D. 自然梯度用 $F^{-1}$ 把欧氏梯度翻译成内在几何下的方向

**解答**：C。

C 错：饱和区（预测确定）里，参数怎么动预测分布几乎不变，**$F$ 趋近 0 而不是很大**。$F$ 大的是"预测最不确定"的区域（如决策边界附近、概率 0.5 处）——那里参数一动，预测分布剧烈变化（§8.2.3 习题的 $\sigma(1-\sigma)$ 在 $\theta=0$ 处取最大值 0.25）。A 对：这是 $F$ 的 DL 角色。B 对：信息几何的核心命题。D 对：自然梯度更新的机制。

**思路点拨**：题眼是"$F$ 大 = 敏感，而敏感区域是"不确定"区不是"确定"区"。最容易错的直觉是"预测确定说明参数重要，所以 $F$ 大"——恰恰相反，确定区的参数是"迟钝"的。判据：**$F$ 度量的是"参数移动对预测的搅动能力"，不是"参数的绝对重要性"。**

### 题 2（判断 + 简答）：为什么欧氏距离在参数空间里会"骗人"？

两个模型的参数 $\theta_A, \theta_B$ 欧氏距离很小。为什么这不能保证"两个模型的预测行为相近"？Fisher 信息矩阵怎么解释这个现象？

**解答**：因为"预测行为"由概率分布 $p(y|x,\theta)$ 决定，而"参数差 → 分布差"的换算率**随位置与方向变化**，由 Fisher 信息矩阵给出。欧氏距离 $\|\theta_A - \theta_B\|$ 把每个方向的"一步"当成等价，但 Fisher 度量告诉我：在敏感方向（$F$ 特征值大），参数差 0.01 就能让预测分布天翻地覆；在迟钝方向（$F$ 特征值小），参数差 1.0 预测也纹丝不动。

所以两个欧氏距离小的参数点，如果它们之差恰好落在 $F$ 的大特征值方向上，预测行为可能迥异。**欧氏尺子假设参数空间处处等比例；Fisher 尺子承认"一步的真实代价"逐点逐方向变化。** 正确的"参数距离"应该是 Fisher 度量下的距离（沿路径积分），而不是坐标差。

**思路点拨**：这是主线撞墙"参数差 0.01 行为天差地别"的解释。核心：**坐标差是标签，Fisher 度量才是真实代价。** 判据：能说出"欧氏距离默认 $F \propto I$，而真实 $F$ 各向异性"，说明理解了为什么需要信息几何。

### 题 3（简答）：贝叶斯深度学习里的"不确定性"怎么用几何表达？

在贝叶斯深度学习中，权重是随机变量，后验 $p(\theta|\mathcal{D})$ 代表对最优权重的信念。用信息几何的语言回答：什么决定了"模型有多确定"？Fisher 度量在这里起什么作用？

**解答**：模型的"确定性"由**后验分布在统计流形上的形状**决定——更精确地说，由后验在 Fisher 度量下的"宽度"决定。后验 $p(\theta|\mathcal{D})$ 在 Fisher 度量意义下"宽"，说明多个参数区域都能解释数据，模型不确定；"窄"说明参数被数据钉死，模型确定。

Fisher 度量起两个作用：① **定义"宽度"的尺子**——后验的展开程度必须用 Fisher 度量（真实分布改变量）来量，而不是欧氏坐标差（一个方向在 Fisher 度量下可能"一步顶十步"）；② **引导更新**——贝叶斯训练沿 Fisher 几何的方向更新权重分布，让每一步在"分布改变量"的意义下合理，这就是自然梯度在贝叶斯框架里的角色。**简单说：不确定性 = 后验在 Fisher 几何里的摊开程度；Fisher 度量是计量与导航它的尺子。**

**思路点拨**：这道题把"不确定性"翻译成几何。核心命题：**置信不在单点输出里，在后验分布在 Fisher 几何中的形状里。** 判据：能说出"后验宽 = 不确定、窄 = 确定"且"宽度用 Fisher 度量量"，说明理解了主线四与 8.3.2 习题里"0.9 可能是虚张声势"的几何本质。

## 二、计算实践

### 题 1（伯努利 Fisher 的手算）

单参数伯努利模型 $p = \sigma(\theta)$。

(a) 对 $\theta = 0$，$\sigma(0) = 0.5$，手算 $F = \sigma(1-\sigma)$。
(b) 对 $\theta = -3$（$\sigma \approx 0.047$），手算 $F$。
(c) 用"得分方差"的角度解释：为什么 $\theta = 0$ 处 $F$ 最大、两端趋零？

**解答**：

(a) $\sigma(0) = \frac{1}{1+e^0} = 0.5$，$F = 0.5 \times 0.5 = 0.25$。

(b) $\sigma(-3) = \frac{1}{1+e^{3}} \approx \frac{1}{21.085} \approx 0.0474$，$F = 0.0474 \times 0.9526 \approx 0.0452$。

(c) 得分 $s = x - p$（$x$ 是伯努利样本），$F = \mathrm{Var}(s) = \mathrm{Var}(x) = p(1-p)$。在 $\theta=0$，$p = 0.5$，样本围绕期望波动最大（$\mathrm{Var} = 0.25$）——**数据对参数最"有话说"**，所以 $F$ 最大；在 $\theta = -3$，$p \approx 0$，样本几乎恒为 0（波动趋零），数据对参数几乎"无话可说"，$F$ 趋零。**Fisher 信息 = 数据携带的参数信息量 = 预测对参数的敏感度**，三者在这里是同一个量。

**思路点拨**：这道题把 Fisher 算成具体数字，并揭示其统计含义。核心恒等式：**伯努利得分 $= x - p$，$F = p(1-p)$**。判据：$F$ 大 ↔ 数据对参数信息多 ↔ 预测对参数敏感——这三个说法在 $F$ 的定义下是同一件事的不同面孔。这也呼应 Cramér–Rao 下界：参数估计的方差 ≥ $1/F$，$F$ 越大估计越准。

### 题 2（自然梯度 vs 普通梯度：一维数字对比）

单参数模型，损失 $L(\theta) = \frac{1}{2}a\theta^2$（曲率 $a$），Fisher 信息 $F(\theta) = f$（常数）。

(a) 普通梯度更新：$\theta_{t+1} = \theta_t - \eta a\theta_t$。写出收敛条件与临界学习率。
(b) 自然梯度更新：$\theta_{t+1} = \theta_t - \eta \frac{a}{f}\theta_t$。若 $f$ 很大（参数敏感），自然梯度的有效步长如何变化？
(c) 用这两个式子解释：为什么"敏感方向"（$F$ 大）上自然梯度会自动放慢、普通梯度可能爆炸？

**解答**：

(a) 普通梯度：$\theta_{t+1} = (1 - \eta a)\theta_t$，收敛条件 $|1-\eta a| < 1$，临界学习率 $\eta_{\max} = 2/a$。**临界学习率由损失曲率 $a$ 决定**（§8.2.4 的老判据）。

(b) 自然梯度：$\theta_{t+1} = (1 - \eta\frac{a}{f})\theta_t$，临界学习率 $\eta_{\max} = 2f/a$。若 $f$ 大（$F$ 大，参数对预测敏感），临界学习率**被放大**——同样的 $\eta$ 更安全；反之若 $f$ 小（参数迟钝），自然梯度反而会放大步长（$a/f$ 大），补偿"欧氏一步没效果"的问题。

(c) 关键：普通梯度的步长只受损失曲率 $a$ 约束，完全无视 Fisher $f$——如果"敏感方向"（$f$ 大）恰好与"损失陡峭方向"（$a$ 大）重合，普通梯度会走很大的欧氏步，预测分布剧变甚至发散。自然梯度用 $f$ 做分母：$f$ 越大（敏感）步长越小——**它把"对预测分布的搅动"控制在恒定水平**，不会在敏感方向迈过头。这就是"自然梯度在敏感方向自动收步"的代数机制。

**思路点拨**：这道题用一维代数把自然梯度的"自动收步"讲透。核心：普通梯度受 $a$（损失曲率）约束，自然梯度受 $a/f$（"损失曲率/预测敏感度"之比）约束。判据：**自然梯度 = 用 Fisher 归一化的梯度 = 在"分布改变量"意义下等长的一步。** 记住"$f$ 在分母"：敏感方向自动放慢。

### 题 3（Fisher 矩阵的数值计算）

给定数据 $X = [x_1, x_2]$（两特征），标签 $y \in \{\pm1\}$，逻辑回归模型。在参数点 $w$ 处，经验 Fisher 为：

$$F = \frac{1}{N}\sum_{i=1}^{N} \text{score}_i \text{score}_i^\top, \quad \text{score}_i = (1 - \sigma(y_i w^\top x_i))\, y_i x_i$$

设数据只有两个样本：$x_1 = (1, 0)$、$y_1 = 1$；$x_2 = (0, 1)$、$y_2 = -1$。当前 $w = (0, 0)$。

(a) 算两个样本的 $p_i = \sigma(y_i w^\top x_i)$ 与 score。
(b) 写出 $F$ 矩阵并求特征值。
(c) 特征值告诉了我们关于两个参数方向的什么？

**解答**：

(a) $w = (0,0)$ 时 $w^\top x_1 = w^\top x_2 = 0$，$\sigma(0) = 0.5$，所以 $p_1 = p_2 = 0.5$。$\text{score}_1 = (1-0.5) \cdot 1 \cdot (1, 0) = (0.5, 0)$；$\text{score}_2 = (1-0.5) \cdot (-1) \cdot (0, 1) = (0, -0.5)$。

(b) $F = \frac{1}{2}\left[\begin{pmatrix}0.5\\0\end{pmatrix}(0.5, 0) + \begin{pmatrix}0\\-0.5\end{pmatrix}(0, -0.5)\right] = \frac{1}{2}\left[\begin{pmatrix}0.25 & 0\\0 & 0\end{pmatrix} + \begin{pmatrix}0 & 0\\0 & 0.25\end{pmatrix}\right] = \begin{pmatrix}0.125 & 0\\0 & 0.125\end{pmatrix}$。特征值 $\lambda_1 = \lambda_2 = 0.125$。

(c) 两个特征值相等——在这个 $w$ 点，两个参数方向**同样敏感**（各向同性）。直观解释：$x_1$ 只激活 $w_1$、$x_2$ 只激活 $w_2$，两个方向被数据"一视同仁"，所以 Fisher 是各向同性的 $\frac18 I$。注意这是**当前点 $w$** 的 Fisher——换到别处（如 $w$ 偏离 0），$p_i$ 不再都等于 0.5，$F$ 就不再各向同性，而会偏向"数据覆盖多的方向"。

**NumPy 验证**：
```python
import numpy as np
def sigmoid(z): return 1/(1+np.exp(-z))
X = np.array([[1.,0.],[0.,1.]]); y = np.array([1.,-1.]); w = np.zeros(2)
z = X @ w; p = sigmoid(y * z)
score = (1-p)[:,None] * (y[:,None] * X)
F = score.T @ score / len(X)
print("F =", np.round(F, 4))
print("特征值 =", np.round(np.linalg.eigvalsh(F), 4))
```
```
F = [[0.125 0.   ]
     [0.    0.125]]
特征值 = [0.125 0.125]
```

**思路点拨**：这道题手算一个 2×2 的 Fisher 矩阵。核心是"得分外积平均"的操作流程：算 $p_i$ → 算 score → 外积 → 平均。判据：**$F$ 的特征值 = 各方向的敏感度；特征值相等 = 各向同性（自然梯度无优势），差异悬殊 = 病态（自然梯度价值大）。** 这也解释了代码.md 里"各向同性时自然梯度退化成普通梯度"的实验。

## 三、DL 延伸

### 题 1（Fisher 信息矩阵与参数缩放）

训练一个逻辑回归时，你把特征 $x_2$ 整体放大 10 倍，重新训练。其他不变。

(a) 从信息几何角度，$F$ 的哪个方向会改变？为什么？
(b) 普通梯度的行为会怎么变？自然梯度呢？
(c) 这解释了工程里的什么经验？

**解答**：

(a) 特征放大 10 倍意味着"同样数值的 $w_2$ 步长"在输入上产生 10 倍效果，所以 $w_2$ 方向的敏感度（$F_{22}$）增大——$F$ 在 $w_2$ 方向"更陡"。本质上，特征缩放改变了数据在参数空间里定义的度量。

(b) 普通梯度的行为被改变：$w_2$ 方向更敏感，临界学习率被该方向锁死，步长必须缩小，否则发散——同一份模型，换一个特征尺度，训练表现就不同（这正是普通梯度对"参数化方式"敏感的体现）。自然梯度用 $F^{-1}$ 归一化，把 $w_2$ 方向的步长自动压低——**它对特征缩放不敏感**，训练行为基本不变。

(c) 这解释了特征工程的一条经验：**训练前要归一化特征（标准化、白化）**——因为普通梯度对"特征尺度→参数敏感度"的耦合极敏感，归一化让 $F$ 更接近各向同性、训练更稳更快。自然梯度/二阶方法对缩放不敏感，这正是它们在很多场景"免调参"的原因之一。

**思路点拨**：这道题把"特征归一化"翻译成几何。核心命题：**特征缩放改变 $F$ 的形状，普通梯度被它牵着走，自然梯度对它免疫。** 判据：能说出"归一化 = 让 Fisher 更各向同性"这个几何理由，比背"特征要标准化"更有穿透力。这也揭示了普通梯度的一个深层弱点：**它不变量（reparametrization-dependent）**——同样的模型，换个坐标写法，收敛行为就变。

### 题 2（EWC：用 Fisher 度量做"知识地图"）

持续学习中，模型先学任务 A、再学任务 B，学 B 时往往会"灾难性遗忘"A。EWC（弹性权重巩固）的做法：在学 B 的损失上加一项 $\frac{\lambda}{2}\sum_i F_i(\theta_i - \theta_A^*)^2$，其中 $F_i$ 是任务 A 训练结束时 Fisher 信息矩阵的对角元，$\theta_A^*$ 是任务 A 学好的参数。

(a) 用信息几何的语言解释：$F_i$ 在这里代表什么？
(b) 为什么"$F_i$ 大的参数在学 B 时被重罚"能保护旧知识？
(c) 如果用均匀权重（所有参数同罚）代替 $F_i$，会有什么问题？

**解答**：

(a) $F_i$ 是任务 A 结束时第 $i$ 个参数的 Fisher 信息——它度量"任务 A 的预测分布对该参数有多敏感"。$F_i$ 大 = 这个参数轻微移动，任务 A 的预测就大改 = **这个参数承载了任务 A 的关键知识**。

(b) EWC 用 $F_i$ 给每个参数加"知识权重"：$F_i$ 大的参数（承载旧知识）在学 B 时被重罚偏离 $\theta_A^*$，于是被"钉"在旧位置，保护任务 A 的能力；$F_i$ 小的参数（对任务 A 不敏感）可以自由移动去适配任务 B。**Fisher 度量在这里充当"哪些参数别动"的知识地图**——它是 8.2.3"Fisher = 参数空间内在度量"在持续学习里的直接应用。

(c) 均匀权重的问题：所有参数同等惩罚，会① 过度限制那些可以自由适配 B 的参数（$F_i$ 小），导致学 B 太慢；② 不足以保护真正重要的参数（$F_i$ 大），仍然遗忘 A。均匀惩罚"该管的没管住、不该管的管死了"——而 $F_i$ 加权恰好按"知识重要度"分配保护预算。

**思路点拨**：这道题把 Fisher 度量用进持续学习。核心命题：**Fisher 信息 = 参数承载的知识量 = 该保护的优先级。** 判据：能说出"$F_i$ 度量'这个参数动一点，旧任务变多少'"——这就是 Fisher 定义的直接应用。EWC 也是"Fisher 度量从优化尺子变成知识地图"的代表。

### 题 3（自然梯度与不确定性的衔接）

一个训练好的模型，其预测输出 0.9。为了判断这个 0.9 有多可信，你想"看看它的后验在参数流形上摊得多宽"。

(a) 用什么量来"测宽度"？它和 Fisher 信息矩阵什么关系？
(b) 后验窄（模型确定）与后验宽（模型不确定）对部署意味着什么？
(c) 如果只能算 Fisher 矩阵的对角元，你能获得关于不确定性的什么信息？局限是什么？

**解答**：

(a) 用后验 $p(\theta|\mathcal{D})$ 在**Fisher 度量下**的宽度（如 Fisher 度量意义下的协方差、或对数后验的曲率）。近似关系：后验的协方差 $\approx F^{-1}$（拉普拉斯近似）——**后验越宽（$F^{-1}$ 大 = $F$ 小），不确定越大；后验越窄（$F^{-1}$ 小 = $F$ 大），越确定**。这与"$F$ 大 = 参数被数据钉得牢"的直觉完全一致。

(b) 后验窄（确定）：预测可靠，可以放心部署到自动化流程；后验宽（不确定）：预测不可信，应该交给人工复核、拒绝作答、或采集更多数据。这正是"分布外检测（OOD detection）"的思想：当输入落在后验宽的区域（训练覆盖不足），模型应主动"说不"。

(c) 对角元 $F_{ii}$ 只给出**每个参数单独**的敏感度，丢失了参数之间的相关（$F_{ij}, i\neq j$）。所以对角近似只能估计"总体不确定性"的一个粗略标量（如 $\sum 1/F_{ii}$ 或特征值下界），无法给出联合置信区域，也无法捕获"几个参数组合起来才敏感"的方向。局限：可能高估或低估真实不确定性（忽略相关性时，联合不确定性与对角之和不同）。完整版本需要完整的 $F$ 或采样。

**思路点拨**：这道题把"0.9 可不可信"落地成"后验宽度"。核心链条：**后验宽度 ≈ $F^{-1}$ 的某种度量 → $F$ 大 = 确定 → 后验窄 = 可信的 0.9。** 判据：能说出"对角近似丢相关性"这个局限，说明理解了 Fisher 矩阵是完整的二次信息、对角是降级近似。这也在 §8.3 结尾把"不确定性"与"几何"牢牢焊在了一起——而 §8.4.1 的正则化，正是这套几何语言的又一次实践。
