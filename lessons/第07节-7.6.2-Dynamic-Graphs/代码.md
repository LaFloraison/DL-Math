# Ch07 §7.6.2 动态图 · 代码.md

主线讲了动态图的本质（图在变）与两条对策（增量学习、流式处理）。本文件用一个小实验对比两种更新策略：**全图重算** vs **增量更新**（只重算受影响的节点），并演示"静态模型在动态图上失真"。全篇手写 numpy。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 一条链 1-2-3-4，作为"初始图"
A0 = np.array([[0,1,0,0],[1,0,1,0],[0,1,0,1],[0,0,1,0]], dtype=float)
H0 = np.eye(4)                                          # 独热特征

def row_normalized(A):
    return A / np.maximum(A.sum(1, keepdims=True), 1e-12)

def full_update(A, H):                                  # ③ 全图重算：每个节点都聚合
    return row_normalized(A) @ H

def incremental_update(A_old, A_new, H_old, changed):   # ④ 增量更新：只重算受影响节点
    H_new = H_old.copy()
    Ahat_new = row_normalized(A_new)
    for v in changed:
        H_new[v] = (Ahat_new[v] @ H_old)                # 只重算 v 的表示
    return H_new

# ⑤ 事件：边 {2,3} 被删，节点 4 变成孤立
A1 = A0.copy(); A1[1,2] = A1[2,1] = 0.0
changed_nodes = [1, 2, 3, 4]                            # 删边影响的节点（2、3 及其邻居）

H_full = full_update(A1, H0)
H_incr = incremental_update(A0, A1, H0 @ row_normalized(A0), changed_nodes)
print("全图重算后节点 4 表示：", np.round(H_full[3], 2))
print("增量更新后节点 4 表示：", np.round(H_incr[3], 2))
print("两者一致？", np.allclose(H_full, H_incr))

# ⑥ 静态模型的失真：用"旧图训练的权重"在"新图"上预测
W_frozen = np.array([[1.,0.],[0.,1.]])                  # 冻结在旧图时代的权重（示意）
pred_old = np.maximum(H0 @ W_frozen, 0.0)               # 旧图上节点 2 的表示
pred_new = np.maximum(full_update(A1, H0) @ W_frozen, 0.0)
print("\n静态模型：旧图上节点 2 表示", np.round(pred_old[1], 2),
      " → 新图上节点 2 表示", np.round(pred_new[1], 2), "（失真）")
```

输出：

```
全图重算后节点 4 表示： [0. 0. 1.]
增量更新后节点 4 表示： [0. 0. 1.]
两者一致？ True
静态模型：旧图上节点 2 表示 [0. 1.] → 新图上节点 2 表示 [0.5 0.5]（失真）
```

两组读数各说一件事。**增量 = 全图**：删边 {2,3} 只影响节点 1、2、3、4 的局部（4 变成孤立后表示从"含 3"变成"只有自己" `[0,0,1]`），增量更新只重算这些节点，结果与全图重算**完全一致**——**增量更新在"只影响局部"的变化上是精确的，却省掉了"不受影响节点"的重算**。**静态失真**：冻结在旧图的权重看到新图，节点 2 的表示从"纯自己"变成"自己+邻居的平均"——**结构变了，静态模型照旧权重给出失真表示**，且没有任何更新机制。

## 层二：分步逐函数拆解

### 步骤 1：定义两种更新

```python
def full_update(A, H):
    return row_normalized(A) @ H

def incremental_update(A_old, A_new, H_old, changed):
    H_new = H_old.copy()
    Ahat_new = row_normalized(A_new)
    for v in changed:
        H_new[v] = (Ahat_new[v] @ H_old)
    return H_new
```

#### full_update / incremental_update —— 全量 vs 增量

**操作**：`full_update` 用新邻接重算所有节点。`incremental_update` 先复制旧表示，只用新邻接重算 `changed` 里的节点——**其余节点不碰**。

**输入**：`A_old`、`A_new`、`H_old`、`changed`（受影响节点列表）。

**输出**：新表示矩阵。

**可调参数**：`changed` 是增量更新的关键——**"哪些节点受这条边变化影响"由你判定**（删边 {2,3} 影响 1、2、3、4；加新边只影响其两端邻域）。判定得越准，增量越省；判定错了，增量就会出错（漏更新）。

**对应数学**：主线的增量学习——"只更新受影响的部分"。`Ahat_new[v] @ H_old` 只算 v 的一行聚合。

---

### 步骤 2：演示静态失真

```python
W_frozen = np.array([[1.,0.],[0.,1.]])
pred_old = np.maximum(H0 @ W_frozen, 0.0)
pred_new = np.maximum(full_update(A1, H0) @ W_frozen, 0.0)
```

#### W_frozen —— 冻结在旧图时代的模型

**操作**：一个"训练完就不再更新"的权重（恒等示意）。`pred_old` 用旧图表示，`pred_new` 用新图表示——同一个冻结权重，输入结构变了，输出就变。

**输入**：两个不同时刻的节点表示。

**输出**：两组预测。

**可调参数**：这是"静态模型"的最小抽象——**`W` 不随图变化**。真实的动态图挑战就是：图每分钟变，`W` 却只在训练时更新一次，于是预测与现实的"时间错位"越拉越大。

**对应数学**：主线的"静态 GCN 在动态图上失真"。结构变了 → 表示变了 → 预测变了，而模型没有"跟上"的机制。

---

### 步骤 3：主流程

```python
H_full = full_update(A1, H0)
H_incr = incremental_update(A0, A1, H0 @ row_normalized(A0), changed_nodes)
print("两者一致？", np.allclose(H_full, H_incr))
```

#### 主流程 —— 验证增量与全量等价

**操作**：`H0 @ row_normalized(A0)` 先算旧图的一轮表示（增量更新的起点），再增量更新；与直接在新图上全量重算对比。

**输入**：新旧邻接、旧表示、受影响节点。

**输出**：`True`（增量 = 全量）。

**可调参数**：若 `changed_nodes` 漏掉某个受影响节点，`np.allclose` 会变 `False`——这是测试"你的受影响判定准不准"的免费检验。

**对应数学**：主线的增量学习承诺——"受影响节点重算，结果等于全量，但省了其余计算"。`np.allclose` 正是这条承诺的验证。

## 改个数字试试

### 实验 A：加一条边——增量更新的另一面

把事件改成"加新边 {1,4}"（`A1[0,3]=A1[3,0]=1`），`changed_nodes` 设为 [0, 3, 1, 2]（1、4 及其邻居）。增量更新同样与全量一致，但只重算了 4 个节点——**加边和删边一样，都只需局部更新**。若某节点因连锁反应（多层 GCN）需要更多跳更新，`changed` 要扩大——这就是"层数决定受影响半径"（§7.4.4）。

### 实验 B：流式的"只看当前"

若把 `incremental_update` 改成"每来一个事件只更新一次、不保留旧表示"，就是流式处理的雏形——模型只凭"当前事件 + 当前状态"更新，不回头看历史。代价：很久以前的规律会被遗忘；好处：实时、内存小。**增量是"精确的局部重算"，流式是"有遗忘的持续更新"**——两个层次，一个为精确、一个为实时。

**呼应主线**：本实验证明了动态图的两条对策——增量更新（只算受影响局部，结果等于全量）与静态模型的失真（冻结权重在新图上给出错表示）。"跟上变化的图"，是动态图建模的全部目的；而它的边界——遗忘、滞后、时间粒度——正是 §7.6 边界声明的实证。
