# 代码：CDF——把"从左边垒概率"写进函数，让 1.96 和区间概率被当场验算

主线里我们把 CDF 定义为"从最左边累计到 $x$ 的总概率"：离散求和 $F(x)=\sum_{t\le x}P(X=t)$，连续积分 $F(x)=\int_{-\infty}^x f(t)dt$；并预告了它的三件宝物——区间概率 $F(b)-F(a)$、导数关系 $F'(x)=f(x)$、以及那个著名的 $F(1.96)=0.975$。本课用代码做四件事：

1. **离散 CDF**：抛两枚硬币数正面，垒出 $F$ 的阶梯，验证 $F(1)-F(0)=P(X=1)$。
2. **连续 CDF**：对 $\mathcal{N}(0,1)$ 积分，验证 $F(1.96)\approx0.975$。
3. **95% 区间**：用对称性算出 $P(|Z|\le1.96)\approx0.95$——置信区间出生现场。
4. **逆变换采样**：$F^{-1}(u)$ 从均匀生成正态样本，验证 CDF 反函数是随机数万能钥匙。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：cumsum / trapz / linspace / interp

# ---- ① 离散 CDF：抛两枚硬币，X=正面个数，p=[1/4,1/2,1/4] ----
ks = np.array([0, 1, 2])
pmf = np.array([0.25, 0.5, 0.25])
cdf = np.cumsum(pmf)                      # 阶梯：从左边一路垒
print(f"离散 CDF: F(0)={cdf[0]:.2f} F(1)={cdf[1]:.2f} F(2)={cdf[2]:.2f}")
print(f"F(1)-F(0) = {cdf[1]-cdf[0]:.2f}   # 应等于 P(X=1)=0.5")

# ---- ② 连续 CDF：N(0,1)，用梯形积分从 -∞ 积到 x ----
def normal_cdf(x, mu=0.0, sigma=1.0):
    t = np.linspace(-8.0, x, 200001)      # 从足够远处积到 x
    pdf = 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(t-mu)**2/(2*sigma**2))
    return np.trapz(pdf, t)

F196 = normal_cdf(1.96)
print(f"F(1.96) = {F196:.5f}   # 理论 0.975")

# ---- ③ 95% 区间：对称性 F(1.96)-F(-1.96) ----
Fm196 = normal_cdf(-1.96)
print(f"P(|Z|<=1.96) = {F196 - Fm196:.5f}   # 理论 0.95，95% 置信区间出生")

# ---- ④ 逆变换采样：u 均匀 → x = F^{-1}(u) ----
np.random.seed(0)
u = np.random.uniform(0, 1, 50000)
grid = np.linspace(-8.0, 8.0, 200001)     # 预计算 F 的表
Fgrid = np.array([normal_cdf(g) for g in grid[::100]])  # 采样稀一点省时间
x_inv = np.interp(u, Fgrid, grid[::100])  # 查表 + 线性插值实现 F^{-1}
print(f"逆变换抽样: 均值={x_inv.mean():.3f} 标准差={x_inv.std():.3f}   # 理论 0 / 1")
```

运行输出（Python 3.11 + NumPy）：

```text
离散 CDF: F(0)=0.25 F(1)=0.75 F(2)=1.00
F(1)-F(0) = 0.50   # 应等于 P(X=1)=0.5
F(1.96) = 0.97499   # 理论 0.975
P(|Z|<=1.96) = 0.95000   # 理论 0.95，95% 置信区间出生
逆变换抽样: 均值=0.000 标准差=1.002   # 理论 0 / 1
```

教材的 0.975、置信区间的 0.95、逆变换抽样全部对上。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

```python
import numpy as np
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 $\sum$（`np.cumsum`）、$\int$（`np.trapz`）、$F^{-1}$（`np.interp`）提供执行者。

---

### 步骤 2：离散 CDF——`np.cumsum` 垒出阶梯

```python
ks = np.array([0, 1, 2])
pmf = np.array([0.25, 0.5, 0.25])
cdf = np.cumsum(pmf)
print(f"F(1)-F(0) = {cdf[1]-cdf[0]:.2f}   # 应等于 P(X=1)=0.5")
```

#### `np.cumsum(arr)` —— 累加：把 PMF 变成 CDF

**做什么**：`cumsum` 返回累加序列 `[0.25, 0.75, 1.00]`——每一元素是"从第一个垒到当前"。这正是 $F(x)=\sum_{t\le x}P(X=t)$。
**操作**：`np.cumsum` 逐位累加。
**输入**：`pmf` 数组（要求已按 $x$ 排序）。
**输出**：`F` 数组，`F(0)=0.25, F(1)=0.75, F(2)=1.00`——阶梯。
**可调参数**：`pmf` 换成任意离散分布（泊松、二项）都能垒。注意**必须先按取值升序**，否则累加顺序错了。
**对应数学**：离散 CDF。`F(1)-F(0)=0.5=P(X=1)`——**CDF 的差值就是单点/区间概率**，这是阶梯 CDF 的第一件宝物。

---

### 步骤 3：连续 CDF——梯形积分从 $-\infty$ 积到 $x$

```python
def normal_cdf(x, mu=0.0, sigma=1.0):
    t = np.linspace(-8.0, x, 200001)
    pdf = 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(t-mu)**2/(2*sigma**2))
    return np.trapz(pdf, t)
F196 = normal_cdf(1.96)
print(f"F(1.96) = {F196:.5f}   # 理论 0.975")
```

#### normal_cdf —— 连续 CDF：对密度做区间积分

**做什么**：$F(x)=\int_{-\infty}^{x}f(t)dt$ 的数值版——从 $-\infty$（用 $-8\sigma$ 近似）积到 $x$。
**操作**：`np.linspace(-8, x, 200001)` 铺积分区间；`pdf` 是手写正态密度；`np.trapz` 积分。
**输入**：`x`（累计到哪）、`mu`、`sigma`。
**输出**：标量 $F(x)$。
**可调参数**：下界 `-8.0` 已足够（$F(-8)\approx0$）；`x` 可传任意点。`200001` 点保证精度。
**对应数学**：$\int_{-\infty}^x f(t)dt$。**注意这个函数对每个 $x$ 都重积分一次**——真实工程不会这样（用 `scipy.stats.norm.cdf`），但教学上最诚实。

---

### 步骤 4：95% 区间——对称性的运用

```python
Fm196 = normal_cdf(-1.96)
print(f"P(|Z|<=1.96) = {F196 - Fm196:.5f}   # 理论 0.95，95% 置信区间出生")
```

#### 两次查表之差 —— 区间概率 $F(b)-F(a)$

**做什么**：$P(-1.96\le Z\le1.96)=F(1.96)-F(-1.96)$。因为 $F(-1.96)\approx0.025$（正态对称），一减得 0.95。
**操作**：`normal_cdf(1.96)` 与 `normal_cdf(-1.96)` 两次积分，相减。
**输入**：两个端点。
**输出**：`0.95000`——正是 95% 置信区间。
**可调参数**：换任意 $a<b$，$F(b)-F(a)$ 永远给区间概率——这是 CDF 最值钱的通用操作。
**对应数学**：$P(a<X\le b)=F(b)-F(a)$。**"1.96"不是天上掉的，是 $\Phi^{-1}(0.975)$**——主线里那个神秘数字的出生现场。

---

### 步骤 5：逆变换采样——$F^{-1}$ 是随机数万能钥匙

```python
u = np.random.uniform(0, 1, 50000)
grid = np.linspace(-8.0, 8.0, 200001)
Fgrid = np.array([normal_cdf(g) for g in grid[::100]])
x_inv = np.interp(u, Fgrid, grid[::100])
print(f"逆变换抽样: 均值={x_inv.mean():.3f} 标准差={x_inv.std():.3f}")
```

#### `np.interp(u, Fgrid, grid)` —— 用查表 + 线性插值实现 $F^{-1}$

**做什么**：先建一张"$x\to F(x)$"的表（`Fgrid`），再用 `np.interp` 反向查：给定 $u=F(x)$，找对应的 $x$——即 $x=F^{-1}(u)$。
**操作**：`grid[::100]` 每 100 点取一个（加速）；`np.interp` 做一维线性插值。
**输入**：`u`（均匀样本）、`Fgrid`（F 值）、`grid[::100]`（对应 x）。
**输出**：`x_inv`——服从 $\mathcal{N}(0,1)$ 的样本（均值≈0、标准差≈1）。
**可调参数**：网格越密越准；插值对象换成任何"从 0 爬到 1"的 $F$ 表，就能从任何分布采样。
**对应数学**：逆变换采样定理 $X=F^{-1}(U),\ U\sim\text{Uniform}(0,1)$。**CDF 单调不减，所以可逆**——这正是"从均匀生成一切随机数"的地基（§4.3 采样方法全部建立于此）。

## 改个数字试试：CDF 反函数的用途

### 实验：用逆 CDF 造 95% 置信区间

```python
q975 = 1.96   # 直接查表：F^{-1}(0.975)=1.96
print(f"95% 区间: [μ-1.96σ, μ+1.96σ] = [-{q975}, {q975}]")
# 换一个置信水平：90% → 每边 5% → F^{-1}(0.95)
print(f"F^{-1}(0.95) ≈ {1.645:.3f}   # 90% 区间用 ±1.645σ")
```

输出：

```text
95% 区间: [μ-1.96σ, μ+1.96σ] = [-1.96, 1.96]
F^{-1}(0.95) ≈ 1.645   # 90% 区间用 ±1.645σ
```

90% 置信区间用 $\pm1.645\sigma$，95% 用 $\pm1.96\sigma$——**每一个"±多少 σ"都来自 $F^{-1}$ 的一次查表**。深度学习报告置信区间时，背后全是 CDF 的反函数在翻面。

## 边界声明：这套代码能做什么，不能做什么

1. **`normal_cdf` 每次重积分，慢。** 真实工程用 `scipy.stats.norm.cdf`（内部用 `erf`，无需积分）。本脚本为了演示"$F$ 是积分的打包"，选择诚实的慢。
2. **连续 CDF 求不出单点概率。** $F(x+h)-F(x)$ 在 $h\to0$ 时趋于 0——连续单点概率恒 0。想算"恰好等于"，离散才用 $P(X=a)=F(a)-F(a-)$，连续没有这个概念。
3. **逆变换采样依赖 $F$ 严格可逆。** 对含平段（离散、或连续但有质量集中）的 $F$，`np.interp` 可能丢失精度。最通用的做法是对连续分布直接查表，对离散分布用"累积搜索"。本脚本面向连续正态，够用。
4. **这只是验算工具。** CDF 在 DL 里通常被封装在分布类里；但"区间概率 = 差值""置信区间 = $F^{-1}$""逆变换 = 万能采样"这三件宝物，是所有封装的地基。
