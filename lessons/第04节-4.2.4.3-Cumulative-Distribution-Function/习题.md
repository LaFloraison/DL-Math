# 习题：累积分布函数（CDF）

## 第一组：概念检验

**1. 用一句话回答：为什么"区间概率 = $F(b)-F(a)$"是 CDF 最值钱的性质？**

**解答**：因为想算任何"落在某区间"的概率，只需两次查表（$F(b)$ 和 $F(a)$）再相减，不用重新求和或积分。$F$ 把"从左边垒起来的总概率"一次性打包好，区间概率就从"重复累加"退化成"两次查表减一次"。这是 CDF 作为"概率查询接口"的威力。

**2. 判断题并说明理由："CDF 只适用于连续随机变量。"**

**解答**：错误。CDF 同时适用于离散与连续。离散的 $F(x)=\sum_{t\le x}P(X=t)$ 是一条**阶梯**（每根柱子处跳一截）；连续的 $F(x)=\int_{-\infty}^x f(t)dt$ 是一条**平滑曲线**（从 0 爬到 1）。CDF 是少数"两个世界共用同一套规则"的工具——单调不减、从 0 到 1、差值即区间概率，对两者都成立。

**3. 为什么 $F'(x)=f(x)$？这个关系说明了 PDF 和 CDF 是什么关系？**

**解答**：因为 $F(x)=\int_{-\infty}^x f(t)dt$，由微积分基本定理，对 $x$ 求导得 $F'(x)=f(x)$。**PDF 和 CDF 是同一枚硬币的两面**：$f$ 是曲线的斜率（浓度），$F$ 是曲线下的累计面积（总概率）。看到 $f$ 看形状，问"不超过多少"看 $F$，两者由求导/积分互锁。

## 第二组：计算实践

**4. 手算 + 代码验证。** 设 $X\sim\mathcal{N}(0,1)$。（a）$F(0)$ 是多少？（b）$P(-1\le X\le1)$ 约多少？（c）$P(X\ge1.645)$ 约多少？（d）用 CDF 的语言解释"95% 置信区间 $\mu\pm1.96\sigma$"。

**解答**：
（a）$F(0)=0.5$——正态在均值处对称，一半质量在左边。
（b）$P(-1\le X\le1)=F(1)-F(-1)=0.8413-0.1587=0.6826$（约 68%，经验法则 1σ）。
（c）$P(X\ge1.645)=1-F(1.645)=1-0.95=0.05$——右侧 5% 尾巴。
（d）$P(-1.96\le X\le1.96)=F(1.96)-F(-1.96)=0.975-0.025=0.95$。所以"$\mu\pm1.96\sigma$"恰好框住中间 95%——置信区间的标准定义。

代码验证：

```python
import numpy as np
def F(x):
    t = np.linspace(-8, x, 200001)
    pdf = np.exp(-t**2/2)/np.sqrt(2*np.pi)
    return np.trapz(pdf, t)
print("F(0) =", round(F(0), 4))
print("P(-1<=Z<=1) =", round(F(1)-F(-1), 4))
print("P(Z>=1.645) =", round(1-F(1.645), 4))
```

输出：

```text
F(0) = 0.5000
P(-1<=Z<=1) = 0.6827
P(Z>=1.645) = 0.0500
```

**思路点拨**：若有人答"$P(Z\ge1.645)=F(1.645)$"，方向反了——"$Z\ge x$"是右侧尾巴，$=1-F(x)$。若有人把 0.6827 记成 0.68，提醒他经验法则 68% 正是 $F(1)-F(-1)$ 的精确值。

**5. 验证 CDF 的单调性与极限。** 用代码检查 $F$ 单调不减、$F(-\infty)\to0$、$F(+\infty)\to1$；再验证"密度是 CDF 的导数"（数值微分 $F(x+h)-F(x-h)\approx2hf(x)$）。

**解答**：

```python
import numpy as np
def F(x):
    t = np.linspace(-8, x, 200001)
    return np.trapz(np.exp(-t**2/2)/np.sqrt(2*np.pi), t)
xs = np.linspace(-3, 3, 30)
vals = [F(x) for x in xs]
print("单调不减:", all(vals[i] <= vals[i+1] for i in range(len(vals)-1)))
print("F(-8)≈", round(F(-8), 6), " F(8)≈", round(F(8), 6))
x0, h = 0.0, 1e-4
fdiff = (F(x0+h) - F(x0-h)) / (2*h)
pdf0 = np.exp(0)/np.sqrt(2*np.pi)
print(f"(F(0+h)-F(0-h))/2h = {fdiff:.4f}   f(0) = {pdf0:.4f}")
```

输出（大致）：

```text
单调不减: True
F(-8)≈ 0.000000  F(8)≈ 1.000000
(F(0+h)-F(0-h))/2h = 0.3989   f(0) = 0.3989
```

$F$ 从 0 爬到 1、永不下降；数值微分 $F'(0)$ 恰好等于 $f(0)=0.3989$——**导数关系的数值证明**。**思路点拨**：这段代码把 CDF 的三条性格（单调、极限、导数）一次性验完。若有人问"为什么用 $(F(x+h)-F(x-h))/2h$ 而不用 $(F(x+h)-F(x))/h$"，因为中心差分误差更小——$O(h^2)$ 而非 $O(h)$。

## 第三组：DL 延伸

**6. 置信区间场景。** 一个深度回归模型在某个输入 $x$ 处输出预测 $\hat y=3.2$ 和方差 $\sigma^2=0.25$（即 $\sigma=0.5$）。（a）报告 95% 置信区间。（b）解释 1.96 从哪里来。（c）如果你要的是 99% 置信区间，$\pm$ 号后面应该是什么？它和 95% 相比说明什么？

**解答**：
（a）$[\hat y-1.96\sigma,\ \hat y+1.96\sigma]=[3.2-0.98,\ 3.2+0.98]=[2.22,\ 4.18]$。
（b）1.96 来自标准正态 CDF 的反函数 $\Phi^{-1}(0.975)$：$F(1.96)=0.975$，又 $F(-1.96)=0.025$，中间 95%。它不是"经验值"，是 $\Phi^{-1}$ 的一次查表。
（c）99% 区间两侧各留 0.5%，即 $F(x)=0.995$，查表得 $\Phi^{-1}(0.995)\approx2.576$。所以区间 $[3.2-1.288,\ 3.2+1.288]=[1.91,\ 4.49]$。**99% 比 95% 更宽**——要更高的置信，必须接受更大的区间；这是"置信水平 ↔ 区间宽度"的永恒权衡。
**思路点拨**：若有人答"$\pm2\sigma$ 就是 99%"，那是把经验法则（95%≈2σ）错误外推——99% 的精确乘子是 2.576。若有人问"为什么不直接用 $\pm2.576\sigma$"，因为那只是 99% 的乘子，95% 是 1.96、90% 是 1.645——**每一个都来自 $F^{-1}$ 在不同置信水平下的取值**。深度学习报告不确定性时，这段"查反函数"的算术就是全部。
