## 第一步：Toy Model —— 电梯里的倒计时

你在一栋办公楼里等电梯。电梯到达时间 $X$ 是一个随机变量（分钟）。你不想知道"电梯恰好 2 分钟到"的概率（那是 0），你想知道的是更实际的问题：**"电梯在 2 分钟内到"的概率是多少？** ——因为你赶时间，只要它在 2 分钟内到，你就不会迟到。

于是你换了一种记账方式：不再问"电梯**恰好**几点到"，而是问"**最迟到**几点到"。把"不超过某个时刻"的概率全都累积起来：

- $P(X \le 1) = 20\%$：1 分钟内到的概率
- $P(X \le 2) = 45\%$：2 分钟内到的概率
- $P(X \le 3) = 65\%$：3 分钟内到的概率
- $P(X \le 4) = 80\%$：4 分钟内到的概率
- $P(X \le 5) = 90\%$：5 分钟内到的概率

这些数字**只增不减**：等的时间越长，"最迟到这之前"的概率当然越大，最后必然趋向 1（电梯总会来）。这就是一条 **累积分布函数 (CDF)** 的手感——**从左边把概率一路垒上去**。

现在问一个"浅到可笑"的问题：**"不超过某个时刻"这个累计，和上一节"恰好某个时刻的密度"，是什么关系？** 你盯着数字看：$P(X\le2)=45\%$、$P(X\le1)=20\%$，两者相减 $45\%-20\%=25\%$——这正是"电梯在 1 到 2 分钟之间到"的概率！也就是说，**累计函数的差值，就是区间概率；而区间概率除以宽度，又回到密度。** 三者像环一样扣在一起。

你的直觉已经看到 CDF 的骨架：它是"从左边垒起来的概率"，会告诉我们任何区间概率。但还留着两个问题：这个累计函数在数学上长什么样、对离散和连续各怎么定义？以及——那个神秘的"1.96"，为什么成了深度学习和统计里人尽皆知的数字？该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：想算"不超过"，PMF/PDF 都要从头数

上一节我们有了 PMF（离散的柱子）和 PDF（连续的曲线）。现在你想回答"$X$ 不超过 $x$ 的概率"。怎么办？

用 PMF：你得从定义域的最左边一根柱子一根柱子地加过来——$p(x_{min}) + p(x_1) + \dots + p(x)$。用 PDF：你得从 $-\infty$ 一路积分到 $x$——$\int_{-\infty}^{x} f(t)dt$。

每次要算"不超过"，都要重复一遍求和/积分——太累了。于是你定义一个新函数，把"从最左边垒到 $x$ 的总概率"**一次性**打包：

$$F(x) = \mathrm{P}(X \le x)$$

离散时它是求和，连续时它是积分：

> **累积分布函数 (CDF)** $F(x) = \mathrm{P}(X \le x)$
>
> 物理含义：随机变量"不超过 $x$"的总概率——从最左边一路累计到 $x$。
>
> **离散**：$$F(x) = \sum_{t \le x} \mathrm{P}(X = t)$$
> **连续**：$$F(x) = \int_{-\infty}^{x} f(t)\, dt$$
>
> - 单调不减：$a < b \Rightarrow F(a) \le F(b)$——概率只增不减
> - 极限：$F(-\infty)=0,\quad F(+\infty)=1$——从 0 垒到 1
> - 区间概率：$\mathrm{P}(a < X \le b) = F(b) - F(a)$——**CDF 的差值就是区间概率**
> - 与 PDF 互逆：$f(x) = F'(x)$——密度是 CDF 的导数
> - 对离散：$F$ 是"阶梯"（每根柱子处跳一截）；对连续：$F$ 是"平滑曲线"（从 0 爬到 1）

### 二、CDF 的三个性格

**性格一：CDF 的差值 = 区间概率。** 这是 CDF 最值钱的性质。$P(a<X\le b)=F(b)-F(a)$——想算任何区间概率，只需两次查表（查 $F$），不用重新积分。你 Toy Model 里那个 $25\%$，正是 $F(2)-F(1)$。

**性格二：密度是 CDF 的导数。** 把 $F(x)=\int_{-\infty}^x f(t)dt$ 对 $x$ 求导：$F'(x)=f(x)$。**PDF 和 CDF 是同一枚硬币的两面**——微积分基本定理把它们互锁：$f$ 是斜率，$F$ 是面积。看曲线形状看 $f$，问"不超过多少"看 $F$。

**性格三：CDF 永远在 $[0,1]$ 之间、单调不减。** $F$ 从 0 爬到 1，永不下降。这条单调性让 CDF 成为所有随机变量统一的"形状签名"——**离散的阶梯和连续的平滑曲线共用同一套规则**，这也是 CDF 能同时服务两个世界的原因。

### 三、那个神秘的 1.96：95% 置信区间从哪来

教材例：标准正态 $\mathcal{N}(0,1)$，$F(1.96)=P(X\le1.96)\approx0.975$。

这句话有两层意思。第一层，字面：97.5% 的值不超过 1.96。第二层，惊天动地：由于对称，$P(X\le-1.96)\approx0.025$，于是**中间那一段**的概率是 $0.975-0.025=0.95$：

$$P(-1.96 \le X \le 1.96) \approx 0.95$$

**这就是 95% 置信区间 (confidence interval) 的数学出身。** 深度的"约 95% 落在 $\mu\pm2\sigma$"（经验法则的精确版），以及统计学里"$\pm1.96$ 倍标准差"的全部答案，都是先由 CDF 算出 $F(1.96)=0.975$，再借对称性切成中间 95%。**1.96 不是天上掉的，是 $F$ 的反函数在 0.975 处的取值**——"$\Phi^{-1}(0.975)\approx1.96$"。

边界声明：CDF 的"差值 = 区间概率"只对**同一边**的累计成立——$F(b)-F(a)$ 用的是"不超过 $b$"减"不超过 $a$"，跨过中间那段。如果你想算"恰好等于 $a$"（离散）或"恰好等于 $a$"（连续），离散用 $P(X=a)=F(a)-F(a-)$（$F$ 在 $a$ 处跳一截），连续则恒为 0——**别用连续 CDF 的连续性去求单点概率**。

## 第三步：DL 桥接

**CDF 是"概率查询"的通用接口——置信区间、p 值、概率解释全靠它。**

**置信区间与预测带。** 深度学习里模型输出 $\mu(x),\sigma(x)$ 后，工程师要报告"预测的 95% 置信区间"。它怎么算？$[\mu-1.96\sigma,\ \mu+1.96\sigma]$——这里的 1.96 正是 $\Phi^{-1}(0.975)$，是标准正态 CDF 的反函数。**你看到 ±1.96，看到 ±2σ，看到 95%，看到的都是 CDF 在背后翻了个面。**

**p 值与假设检验。** 经典统计里"这个特征显著吗"的 p 值，定义是 $P(Z\ge z_{\text{obs}})=1-F(z_{\text{obs}})$——正态 CDF 的尾部。深度学习实验报告里的"置信区间宽度"、"显著差异"，都是 CDF 的查表应用。

**概率校准（calibration）。** 分类器的置信度 $\hat p$ 是否可信？校准曲线把"预测概率 $\hat p$"与"真实频率"对照——若置信度输出是 $F$（CDF）形状的单调映射，说明校准良好。**CDF 的单调性，正是"校准"这个概念的数学骨架。**

**逆变换采样（inverse transform sampling）。** 从任意连续分布抽样的最通用方法：先抽均匀 $u\sim\text{Uniform}(0,1)$，再算 $x=F^{-1}(u)$。为什么？因为 $F$ 从 0 爬到 1，$F^{-1}$ 把"均匀的量"映射成"该分布的样本"。**CDF 的反函数，是生成一切随机数的万能钥匙**——§4.3 采样方法的地基。
