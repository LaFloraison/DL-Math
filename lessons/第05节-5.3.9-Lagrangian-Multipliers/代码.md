# 代码：验证拉格朗日——(5,5)、λ=5 与影子价格的数值实验

**目标**：主线里教材例 $\max f(x,y)=xy$ 约束 $x+y=10$ 的解是 $x=y=5$、$f=25$、$\lambda=5$。这里用三种方式交叉验证：**沿约束线枚举**、**检查梯度平行条件 $\nabla f = -\lambda\nabla g$**、**验证影子价格 $\lambda = \frac{\partial f^*}{\partial c}$**。一个脚本，把拉格朗日乘子的几何、代数、经济学三层含义全部"钉死"。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 沿约束线枚举: 参数化 y = 10 - x ----
xs = np.linspace(0.0, 10.0, 10001)
ys = 10.0 - xs
fs = xs * ys                                    # f = x*y 沿路取值
i = int(np.argmax(fs))
print(f"枚举最优: x={xs[i]:.4f}, y={ys[i]:.4f}, f={fs[i]:.4f}  (解析: 5,5,25)")

# ---- 2. 梯度平行条件: ∇f = -λ∇g ----
x0, y0 = 5.0, 5.0
grad_f = np.array([y0, x0])                     # ∇f = (y, x) = (5,5)
grad_g = np.array([-1.0, -1.0])                 # ∇g = (-1,-1)  (g = 10-x-y, 约束写成 g=0)
lam = -grad_f[0] / grad_g[0]                    # 从第一个分量解 λ
print(f"λ = {lam:.4f}  (解析: 5)")
print(f"∇f      = {grad_f}")
print(f"-λ·∇g   = {-lam * grad_g}   ← 两者应相等 (梯度平行)")

# ---- 3. 影子价格: λ ≈ (f*(c+Δc) - f*(c)) / Δc ----
def f_star(c):
    return (c / 2.0) ** 2                        # max xy s.t. x+y=c 的最优值 c²/4
c0, dc = 10.0, 0.1
rate = (f_star(c0 + dc) - f_star(c0)) / dc       # 数值导数
print(f"影子价格数值 = {rate:.4f}  (解析 λ=5, 误差 {abs(rate-5.0):.2e})")
```

输出：

```
枚举最优: x=5.0000, y=5.0000, f=25.0000  (解析: 5,5,25)
λ = 5.0000  (解析: 5)
∇f      = [5. 5.]
-λ·∇g   = [5. 5.]   ← 两者应相等 (梯度平行)
影子价格数值 = 5.0250  (解析 λ=5, 误差 2.50e-02)
```

三行输出，拉格朗日乘子的三个身份全部兑现：**解**（$(5,5),f=25$）、**几何**（$\nabla f$ 与 $\nabla g$ 平行，比例为 $|\lambda|=5$）、**经济学**（约束放宽 0.1，最优值涨 $0.5025 \approx \lambda\times0.1=0.5$）。影子价格数值 5.025 ≈ 5，误差来自 $\Delta c=0.1$ 的有限差分——把 `dc` 改小到 `0.001`，误差会掉到 $10^{-6}$ 级。

## 层二：分步逐函数拆解

### 步骤 1：沿约束线枚举——参数化消元

```python
xs = np.linspace(0.0, 10.0, 10001)
ys = 10.0 - xs
fs = xs * ys
i = int(np.argmax(fs))
```

**操作**：把约束 $x+y=10$ 参数化成 $y = 10-x$，代入 $f$ 得到一元函数 $f = x(10-x)$；在 $[0,10]$ 上取 10001 个点，`np.argmax` 找最大点。
**输入**：无。**输出**：`i`（最大值的下标）。
**可调参数**：点数 10001 越大越精确（间距 $10/10000=0.001$）。**注意**：这个方法利用了"约束能显式消元"——但 $x^2+y^2=1$ 之类约束不能简单消元，这就是需要拉格朗日法的原因。**枚举是"偷懒的验证"，拉格朗日是"普适的方法"。**

**对应数学**：主线的约束极值问题——它先沿约束曲线降维（$f=x(10-x)$），再求一元极值。

---

### 步骤 2：梯度平行条件——拉格朗日的几何签名

```python
x0, y0 = 5.0, 5.0
grad_f = np.array([y0, x0])
grad_g = np.array([1.0, 1.0])
lam = -grad_f[0] / grad_g[0]
```

**操作**：算出 $\nabla f = (y,x)$ 与 $\nabla g = (1,1)$，用第一个分量解出 $\lambda = -\frac{\nabla f_1}{\nabla g_1}$，打印 $\nabla f$ 与 $-\lambda\nabla g$。
**输入**：最优解 `(x0,y0)=(5,5)`。**输出**：`lam=5.0`、两个向量。
**可调参数**：换约束（如 $2x+y=10$）→ $\nabla g=(2,1)$ → $\lambda$ 不同。**要点**：$\nabla f$ 与 $-\lambda\nabla g$ 相等，正是主线里"梯度平行"（$\nabla f = -\lambda\nabla g$）的数值证据——这是拉格朗日方法成立的核心，也是"为什么最优在切线相切处"的代数表达。

**对应数学**：主线定义块的核心方程 $\nabla \mathcal{L} = \nabla f + \lambda\nabla g = 0$。

---

### 步骤 3：影子价格——λ 的经济学身份

```python
def f_star(c):
    return (c / 2.0) ** 2

c0, dc = 10.0, 0.1
rate = (f_star(c0 + dc) - f_star(c0)) / dc
```

#### `f_star` —— 参数化最优值函数

**操作**：对一般约束 $x+y=c$，拉格朗日法给出 $x=y=c/2$、$f^* = c^2/4$。`f_star(c)` 返回约束量为 $c$ 时的最优值。
**输入**：`c`（约束量）。**输出**：最优值 $f^*(c)$。
**可调参数**：无直接参数。这是"把最优值写成约束量的函数"——正是"影子价格"的定义域。

#### 有限差分求 `rate`

**操作**：$\frac{f^*(c_0+\Delta c)-f^*(c_0)}{\Delta c}$——约束放宽 $0.1$ 时最优值的增量除以 $0.1$，是 $\frac{\partial f^*}{\partial c}$ 的数值近似（Ch03 的数值微分）。
**输入**：`c0=10.0`、`dc=0.1`。**输出**：`rate=5.025`。
**可调参数**：`dc` 越小越精确（但过小会触发浮点消减误差）。`f_star` 换成别的目标函数，`rate` 就是那个问题的影子价格——**这是经济学"多一单位资源值多少钱"的通用算法**。

**对应数学**：主线里 $\lambda = \frac{\partial f^*}{\partial c}$ 的数值验证——拉格朗日乘子的经济学解释（SVM 里对应"样本对边界的影响力"）。

## 实验台：让乘子显灵

1. **换约束到单位圆**：把约束改成 $x^2+y^2=1$（教材 Figure 5.10）。手写拉格朗日解出 $x=y=\pm 1/\sqrt2$，然后枚举圆上参数点 $(\cos\theta,\sin\theta)$，验证 $f=xy$ 的极大（$0.5$，在 $45°/225°$）与极小（$-0.5$，在 $135°/315°$）。**同一个乘子方法，同时找到极大和极小**。
2. **看影子价格的随 $c$ 变化**：对 $f^*(c)=c^2/4$，$\lambda = c/2$ 随 $c$ 增长——说明"资源越充裕，每单位资源越值钱"（对这个具体问题）。换一个目标（如 $f^* = 10c - c^2$），影子价格会随 $c$ **递减**——体会"影子价格不一定是常数"。
3. **把 $f(x,y)=xy$ 换成 $f = x^2+y^2$**（凸函数），约束 $x+y=10$：拉格朗日给出 $x=y=5$，$f=50$——注意这时它是最小值还是最大值？$x^2+y^2$ 沿直线在端点最大、中点最小——**$\nabla\mathcal{L}=0$ 的点可能是极小，需要二阶条件确认**。
4. **接上 scipy**：`scipy.optimize.minimize` 用 `method='SLSQP'` 直接解约束问题，结果与拉格朗日一致——库只作裁判。

**对应数学**：实验 3 呼应主线的边界声明——**拉格朗日只保证"驻点"，不保证"极大"**，这正是它与凸优化"全局最优保证"的差别。
