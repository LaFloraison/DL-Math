## 解答与思路点拨

### 第一组

**1.1** 目标函数 (objective function)；决策变量 (decision variables)；可行域 (feasible region)。这是主线的定义块，三要素缺一不可——漏掉任何一个，"优化"这个词都没有意义。

**1.2** 对。最大化 $g$ 与最小化 $-g$ 在数学上是同一个问题：若 $x^*$ 使 $g$ 取到最大值 $g(x^*)$，则对任意 $x$ 有 $g(x) \le g(x^*)$，两边取负得 $-g(x) \ge -g(x^*)$，所以 $x^*$ 使 $-g$ 取到最小值。反之亦然。**常见错误**：有人会说"因为最大值加个负号就是最小值"——方向对，但严格的理由是**不等式两边同时取负会反转不等号**。

**1.3** 选 B。维度高（A）确实让计算变难，但它不是"无法保证最优"的**根本原因**——即使是一个 2 维的非凸函数，局部最小也照样存在；梯度无法计算（C）是错的，链式法则能算；最优解不存在（D）通常不成立，损失函数有下界。**根本原因是非凸性**：一个凸函数只有一个碗，局部最小天然是全局最小（§5.3.4 会证明）；神经网络的损失不是凸的，所以下山可能停在任何一个洼地（§5.4 会讲）。

### 第二组

**2.1** 配方：$f(x) = (x-2)^2 + 3$。因为 $(x-2)^2 \ge 0$，最小值在 $x=2$ 取到，最小值是 $3$。或用微积分：$f'(x) = 2x - 4 = 0 \Rightarrow x = 2$。这是**无约束**优化——$x$ 可以取任意实数，没有围栏。**易错点**：最小值是 $3$（函数值），不是 $2$（变量的取值）——问"最小值"时，先分清问的是 $x^*$ 还是 $f(x^*)$。

**2.2** $g(x) = e^{-x^2}$ 在 $x=0$ 取到最大值 1（因为 $-x^2 \le 0$，$e^0 = 1$ 是 $e$ 的幂的最大值）。改写为标准最小化形式：$\arg\max_x g(x) = \arg\min_x (-g(x)) = \arg\min_x \left(-e^{-x^2}\right)$，答案仍是 $x = 0$。**易错点**：很多人写成 $\arg\max_x e^{-x^2}$ 就交卷——题目要的是"改写成最小化形式"，关键在于那个负号。

**2.3** 验证代码：

```python
import numpy as np
def f(x):
    return (x - np.pi) ** 2 + 2.0

for n in (1001, 10001):
    grid = np.linspace(0.0, 6.0, n)
    idx = np.argmin(f(grid))
    print(f"n={n}: 最优点={grid[idx]:.6f}, 误差={abs(grid[idx]-np.pi):.2e}")
```

输出大致为：

```
n=1001: 最优点=3.138000, 误差=3.59e-03
n=10001: 最优点=3.141600, 误差=7.35e-06
```

网格间距分别为 $\frac{6}{1000} = 0.006$ 和 $\frac{6}{10000} = 0.0006$，所以误差也随点数线性缩小两个数量级。**要点**：$\pi$ 是无理数，永远不落在任何有限网格点上，所以误差**不可能为零**——这就是暴力搜索的天花板，也正是梯度下降这种"朝坡度走"的方法存在的理由（它不依赖撒点密度，直接朝最陡方向迈步）。

### 第三组

**3.1** 目标函数：交叉熵损失 $L(\theta)$；决策变量：网络的全部权重和偏置，统称 $\theta$；可行域：整个参数空间（无约束）。加正则项 $\lambda\|\theta\|^2$ 后，被最小化的函数从 $L(\theta)$ 变成 $L(\theta) + \lambda\|\theta\|^2$——**改变的是目标函数**。正则化不限制 $\theta$ 的取值范围（可行域没变），而是通过惩罚大的权重，把解往"小权重"方向推。**常见错误**：有人把正则化当成"加了约束"——严格说，它改变的是目标，不是约束。真正的约束（如 $\|\theta\|_2 \le C$）改变的是可行域。

**3.2** 错。Adam 是深度学习常用的优化器（§5.6.7），它很擅长快速找到"够好"的解，但**无法保证全局最优**。理由：神经网络的损失函数非凸（见 1.3），优化只能靠局部信息迭代逼近，可能停在局部极小或鞍点。任何宣称"保证找到全局最优"的深度学习优化器都是营销话术。**能保证全局最优的，只有特定结构的问题——线性规划（单纯形法）、凸优化——这正是本章后半部分分类学的用处。**
