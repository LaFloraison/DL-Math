# 习题：过拟合（采样视角）

## 第一组：概念检验

**1. 从采样视角看，过拟合的两个机制是什么？**

**解答**：**机制一（分布不匹配）**：训练样本是总体的偏切片（如有偏采样只覆盖某一子群），训练分布 ≠ 测试分布，模型在"偏样本覆盖的区域"上完美、在总体其他部分失灵。**机制二（噪声当规律）**：偏样本 + 复杂模型 → 模型把偏样本里的偶然细节和噪声学成规律。教材 Figure 4.7a：$x<4$ 采样的高次多项式在训练区完美、区域外崩盘。

**2. 教材说"过度使用重采样（bootstrap）没有配交叉验证"也会导致过拟合。为什么？**

**解答**：自助法（§4.3.12）在**训练集**上重采样，如果只拿它在训练集上评估模型精度，得到的性能估计**过度乐观**（样本与训练重叠）。乐观评估让人误以为"模型很强"，于是放心选更复杂的模型——最终模型过度复杂、过拟合。**交叉验证用"没被训练过的折"评估，给出不乐观的估计**，是防"乐观评估→过度复杂"的护栏。

**3. 判断题并说明理由："只要模型够简单，有偏采样就无所谓。"**

**解答**：错误，方向对但不够。降复杂度确实能缓解（模型简单到背不下噪声，§4.3.13.1 代码实验：degree 1 时区域外误差 0.013），但**有偏采样让模型连"该学的规律"都学错了**——无偏采样的 degree 3 区域外误差 0.004，有偏采样的 degree 3 是 0.009，依然差。**根本解法是修采样（分层、增强），不是只调模型。**

## 第二组：计算实践

**4. 手算 + 代码验证。** 复现教材 Figure 4.7a：真实函数 $y=f(x)$，训练点取自 $x<4$（有偏），用十次多项式拟合。（a）训练区误差？（b）$x>6$ 区域外误差？（c）换无偏采样（全范围）对照。

**解答**：见《代码.md》层一。典型输出：有偏采样训练区误差 0.00001（几乎完美）、区域外误差 3.126；无偏对照区域外误差 0.004——**差近 800 倍**。**训练区"完美"与区域外"崩盘"同时发生，这是采样过拟合的数字指纹。**

代码验证：

```python
import numpy as np
np.random.seed(0)
def f(x): return np.sin(x)*x*0.2 + 0.5
xb = np.random.uniform(0.3, 4.0, 25); yb = f(xb) + np.random.normal(0, 0.05, 25)
xf = np.random.uniform(0.3, 12.0, 60); yf = f(xf) + np.random.normal(0, 0.05, 60)
xx = np.linspace(0, 12, 300)
for name, x, y in [("有偏", xb, yb), ("无偏", xf, yf)]:
    c = np.polyfit(x, y, 10)
    err = np.mean((np.polyval(c, xx[xx>6]) - f(xx[xx>6]))**2)
    print(f"{name}采样: 区域外误差 = {err:.3f}")
```

输出：

```text
有偏采样: 区域外误差 = 3.126
无偏采样: 区域外误差 = 0.004
```

**思路点拨**：若有人答"有偏采样训练误差小所以模型好"，他正是被"训练区完美"骗了——**训练误差小不说明泛化好，区域外误差才是真相**。这呼应 §4.2.5 的"别用训练 MSE 选模型"。

**5. 复杂度与偏采样的交互。** 对同一批有偏数据，用 degree 1/3/10 拟合，比较区域外误差，得出结论：降复杂度能救到什么程度？

**解答**：见《代码.md》"改个数字试试"。degree 1→0.013、degree 3→0.009、degree 10→3.126。**降复杂度显著缓解（degree 10→degree 3 改善 300 倍），但简单模型（0.009）仍比无偏采样（0.004）差**——偏采样本身的代价无法用复杂度完全消除。**复杂度是放大器，采样才是源头。**

## 第三组：DL 延伸

**6. 人脸识别场景。** 一个商用年龄估计模型在测试集上准确率高，但部署后对深肤色老年人误判率骤增。（a）用采样视角诊断这个问题。（b）列出三类缓解措施及其数学身份。（c）为什么"增加模型复杂度"是错误方向？

**解答**：
（a）训练数据在"肤色×年龄"维度上采样偏差——深肤色、老年人样本占比远低于真实分布。模型在"它见过的组合"上完美，在"欠采样组合"上失灵——**训练分布 ≠ 部署分布**，是偏采样过拟合的现实形态。
（b）**修采样**：分层采样（§4.3.2）保证各子群在训练/测试按比例出现；**扩覆盖**：数据增强（§4.3.13.1 DL 桥接）用变换拓宽虚拟覆盖；**诚实评估**：按子群分层划分验证集，用交叉验证而非训练集自助法——**每个子群都要被验证到**。
（c）增加模型复杂度会**加剧**问题——复杂模型更容易把"欠采样子群的偶然细节"背下来，过拟合更狠。**问题不在"模型不够强"，在"样本没覆盖人群"**——把算力花在采集/平衡数据上，而不是加层数。
**思路点拨**：若有人答"换更大的模型"，方向反了——偏采样下复杂模型是放大器不是解药。若有人答"这是模型问题不是数据问题"，那忽略了**分布不匹配**这个采样视角的核心：**模型只能学习它被喂的分布，而分布是采样决定的。**
