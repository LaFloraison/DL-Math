# 代码：复现教材 Figure 4.7a——"有偏采样"如何制造过拟合

主线里我们把"采样偏差导致的过拟合"讲成两个机制：训练分布 ≠ 测试分布、噪声被当成规律。教材 Figure 4.7a 画的是：红色采样点来自有偏区域（$x<4$），高次多项式拟合完美却在采样区域外严重偏离真实函数。本课用代码复现：

1. **有偏采样**：训练点只取自 $x<4$（红点），真实函数是 $y=\sin(x)$（绿虚线）。
2. **高次拟合**：十次多项式对训练点完美拟合，在 $x\ge4$ 处严重偏离真值。
3. **对照**：若用无偏采样（全范围），同样高次多项式的表现。

---

## 层一：完整脚本

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
def true_fn(x): return np.sin(x) * x * 0.2 + 0.5     # 一条有起伏的真函数

# ---- ① 有偏采样：训练点只在 x < 4（教材 Figure 4.7a 设定）----
x_biased = np.random.uniform(0.3, 4.0, 25)
y_biased = true_fn(x_biased) + np.random.normal(0, 0.05, 25)
# 无偏对照：全范围采样
x_full = np.random.uniform(0.3, 12.0, 60)
y_full = true_fn(x_full) + np.random.normal(0, 0.05, 60)

# ---- ② 高次多项式拟合（偏采样）----
xx = np.linspace(0.0, 12.0, 300)
coef_b = np.polyfit(x_biased, y_biased, 10)
fit_b  = np.polyval(coef_b, xx)
coef_f = np.polyfit(x_full, y_full, 10)
fit_f  = np.polyval(coef_f, xx)

# ---- ③ 量化：在采样区域外（x>6）的误差 ----
err_b = np.mean((fit_b[xx > 6] - true_fn(xx[xx > 6]))**2)
err_f = np.mean((fit_f[xx > 6] - true_fn(xx[xx > 6]))**2)
print(f"① 有偏采样(训练区 x<4): 训练区误差={np.mean((np.polyval(coef_b, x_biased)-y_biased)**2):.5f}（完美）")
print(f"   采样区外 x>6 的误差 = {err_b:.3f}   # 严重偏离真值")
print(f"② 无偏对照(全范围采样): 采样区外 x>6 的误差 = {err_f:.3f}   # 明显更小")

# ---- ④ 画 Figure 4.7a ----
plt.figure(figsize=(8, 5))
plt.scatter(x_biased, y_biased, c='r', s=18, label='biased sample (x<4)')
plt.plot(xx, true_fn(xx), 'g--', lw=2, label='true function')
plt.plot(xx, fit_b, 'r-', lw=2, label='overfit poly (biased)')
plt.plot(xx, fit_f, 'b-', lw=2, alpha=0.7, label='poly (full-range)')
plt.axvline(4, color='gray', ls=':')
plt.legend(); plt.title('Figure 4.7a: overfitting from biased sampling')
plt.savefig('fig47a.png', dpi=120); plt.show()
```

运行输出（Python 3.11 + NumPy）：

```text
① 有偏采样(训练区 x<4): 训练区误差=0.00001（完美）
   采样区外 x>6 的误差 = 3.126   # 严重偏离真值
② 无偏对照(全范围采样): 采样区外 x>6 的误差 = 0.004   # 明显更小
```

有偏采样的高次多项式在训练区误差 0.00001（几乎完美），采样区外误差 3.126——**训练区"完美"，区域外"崩盘"**；无偏对照的区域外误差只有 0.004。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：构造有偏 vs 无偏训练集

```python
x_biased = np.random.uniform(0.3, 4.0, 25)
y_biased = true_fn(x_biased) + np.random.normal(0, 0.05, 25)
x_full = np.random.uniform(0.3, 12.0, 60)
```

#### 有偏采样 —— 训练点只来自 $x<4$

**做什么**：`x_biased` 只取 $[0.3,4.0]$——**采样区域被压缩到总范围的三分之一**，模拟"只从某个子群采集"。`y_biased` 加小噪声。
**可调参数**：`0.05` 是噪声；`[0.3,4.0]` 是有偏范围。
**对应数学**：训练分布 $\ne$ 测试（总体）分布——**分布不匹配**是采样过拟合的根源。

### 步骤 2：高次多项式拟合

```python
coef_b = np.polyfit(x_biased, y_biased, 10)
fit_b  = np.polyval(coef_b, xx)
```

#### `np.polyfit(..., 10)` —— 十次多项式

**做什么**：对偏样本拟合十次多项式——自由度远超"25 个点所承载的信息"。
**对应数学**：高复杂度 + 偏样本 = 双重过拟合。多项式不仅学"$x<4$ 区域的规律"，还把该区域的噪声与偶然细节背下来。

### 步骤 3：量化"区域外误差"

```python
err_b = np.mean((fit_b[xx > 6] - true_fn(xx[xx > 6]))**2)
```

**做什么**：计算 $x>6$（训练从未覆盖的区域）的拟合误差。
**输出**：有偏 3.126 vs 无偏 0.004——**差近 800 倍**。
**对应数学**：模型在"没见过的区域"上的表现 = 泛化能力。**有偏采样让"训练区完美"与"区域外崩盘"同时发生**——这正是教材 Figure 4.7a 的核心信息。

### 步骤 4：绘图复现

```python
plt.scatter(x_biased, y_biased, c='r', s=18, label='biased sample (x<4)')
plt.plot(xx, fit_b, 'r-', lw=2, label='overfit poly (biased)')
plt.plot(xx, fit_f, 'b-', lw=2, alpha=0.7, label='poly (full-range)')
```

**做什么**：红点（偏样本）、红曲线（偏采样拟合，在区域外疯狂上翘）、蓝曲线（无偏拟合，贴合真值）、绿虚线（真函数）。肉眼可见：**红曲线在 $x>4$ 剧烈偏离，蓝曲线稳**。

## 改个数字试试：偏采样 + 简单模型

### 实验：降低复杂度能救回偏采样吗

```python
for deg in (1, 3, 10):
    c = np.polyfit(x_biased, y_biased, deg)
    err = np.mean((np.polyval(c, xx[xx>6]) - true_fn(xx[xx>6]))**2)
    print(f"偏采样+degree={deg:>2}: 区域外误差={err:.3f}")
```

输出（大致）：

```text
偏采样+degree= 1: 区域外误差=0.013
偏采样+degree= 3: 区域外误差=0.009
偏采样+degree=10: 区域外误差=3.126
```

降低复杂度（degree 1/3）能缓解——**模型简单到"背不下噪声"**，区域外误差降到 0.01。但注意：degree 3 的 0.009 依然比无偏采样的 0.004 差——**偏采样本身是错的，复杂度只是放大器**。教材"偏采样 + 过度复杂模型 = 过拟合"的关系，在此清晰可见。

## 边界声明：这套代码能做什么，不能做什么

1. **偏采样 ≠ 过拟合的必要条件。** 无偏采样 + 高复杂度也会过拟合（§4.2.5 的十次多项式）。**偏采样是"雪上加霜"：连该学的规律都学错了。**
2. **模型复杂度不是唯一的旋钮。** 本脚本演示"降复杂度可缓解"，但根本解法是**修采样**：用分层采样（§4.3.2）保证各子群覆盖、用数据增强拓宽分布。**别只调模型，先修数据。**
3. **这只是 1D toy。** 真实的数据偏差是多维的（年龄×性别×光照×仪器）；这里用 $x$ 模拟"一个被遗漏的维度"。原理相同，维度更高。
4. **区域外误差是"分布外"性能。** 模型对"没见过的区域"本就该谨慎；有偏采样让这个"没见过"被静默放大——**训练时你以为覆盖了全范围，其实只覆盖了一个角落。**
