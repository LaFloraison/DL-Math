# 代码：验证对称与反对称——转置、`allclose`、以及"从数据造对称矩阵"

主线里我们定义了对称矩阵（$A^\top=A$）与反对称矩阵（$A^\top=-A$）。这一节用 NumPy 验证定义、检查随机矩阵是否为对称，并演示"协方差矩阵为什么天然对称"。

---

## 层一：完整脚本

```python
import numpy as np                          # NumPy：转置与比较

# ---- ① 教材的对称矩阵 ----
A = np.array([[1, 2, 3],
              [2, 4, 5],
              [3, 5, 6]])
print("A =\n", A)
print("A.T =\n", A.T)
print("A 是否对称 (A.T == A):", np.allclose(A, A.T))       # True

# ---- ② 教材的反对称矩阵 ----
S = np.array([[ 0,  2,  3],
              [-2,  0,  5],
              [-3, -5,  0]])
print("S 是否反对称 (S.T == -S):", np.allclose(S, -S))     # True
print("S 对角线全 0:", np.allclose(np.diag(S), 0))         # True

# ---- ③ 随机矩阵一般不对称 ----
R = np.random.randn(3, 3)
print("随机矩阵是否对称:", np.allclose(R, R.T))            # 几乎必然 False

# ---- ④ 任何矩阵 M，M+M.T 是对称的、M-M.T 是反对称的 ----
M = np.random.randn(3, 3)
sym  = M + M.T
skew = M - M.T
print("M+M.T 对称:", np.allclose(sym, sym.T))              # True
print("M-M.T 反对称:", np.allclose(skew, -skew.T))         # True

# ---- ⑤ 协方差矩阵天然对称 ----
X = np.random.randn(50, 4)                  # 50 个样本、4 个特征
Xc = X - X.mean(axis=0)                     # 中心化（减每列均值）
C = (Xc.T @ Xc) / (50 - 1)                  # 协方差 (4,4)
print("协方差形状:", C.shape)
print("协方差是否对称:", np.allclose(C, C.T))              # True
```

## 层二：分步逐函数拆解

### 步骤 1：`A.T` 与 `np.allclose`

```python
A.T          # 转置
np.allclose(A, A.T)
```

#### `ndarray.T` —— 转置

**操作**：交换行与列：$(A^\top)_{ij} = A_{ji}$。对 `(3,3)` 转置仍是 `(3,3)`，元素关于对角线镜像。
**可调参数**：二维数组 `.T` 简单交换两维；更高维用 `np.transpose(a, axes)`。
**对应数学**：主线转置定义。

#### `np.allclose(A, A.T)` —— 对称性判断

**操作**：逐元素比较（容差），全等返回 `True`。这就是"$A^\top=A$"的代码翻译。
**可调参数**：`atol`/`rtol` 控制容差；对整数精确比较也可用 `np.array_equal`。
**对应数学**：主线对称定义。**对称性的判断在代码里就是"转置后是否相等"这一句。**

### 步骤 2：反对称验证

```python
np.allclose(S, -S)
np.allclose(np.diag(S), 0)
```

#### `np.diag(S)` —— 取对角线

**操作**：提取主对角线元素 `[0, 0, 0]`。`np.allclose(..., 0)` 验证全为 0。
**可调参数**：`np.diag` 也可以"构造"对角矩阵（传一维数组）。
**对应数学**：主线反对称定义 $A^\top=-A$、$A_{ii}=0$。**对角线必须为 0**是反对称的强制要求（$A_{ii}=-A_{ii}\Rightarrow A_{ii}=0$）。

### 步骤 3：随机矩阵一般不对称

```python
R = np.random.randn(3, 3)
np.allclose(R, R.T)   # False
```

**操作**：随机矩阵满足 $R_{ij}=R_{ji}$ 的概率为 0（除非恰巧相等），所以返回 `False`。
**可调参数**：换 `np.random.rand` 也一样。**对称是"特殊的结构"，不是"随机的常态"。**
**对应数学**：主线"对称需要特殊的关系结构"——随机两两关系几乎从不双向相等。

### 步骤 4：对称/反对称的"拆分"

```python
sym  = M + M.T     # 对称
skew = M - M.T     # 反对称
```

**操作**：任意矩阵 $M$ 都能拆成"对称部分 + 反对称部分"：$M = \frac{M+M^\top}{2} + \frac{M-M^\top}{2}$。代码验证 $M+M^\top$ 对称、$M-M^\top$ 反对称。
**可调参数**：除以 2 得到"对称化/反对称化"的标准形式。这个分解在分析任意矩阵时很有用（如矩阵的对称化处理）。
**对应数学**：主线对称/反对称定义的直接推论。**"任何矩阵可拆成对称 + 反对称"是线性代数里优雅的通用分解。**

### 步骤 5：协方差矩阵天然对称

```python
Xc = X - X.mean(axis=0)          # 中心化
C = (Xc.T @ Xc) / (50 - 1)       # 协方差
```

#### `X.mean(axis=0)` —— 按列求均值

**操作**：`axis=0` 沿"样本轴"求均值，得到每列（每个特征）的平均值，形状 `(4,)`。中心化 = 每个样本减列均值。
**可调参数**：`axis` 指定沿哪轴。中心化是 PCA/协方差分析的前提。
**对应数学**：主线"数据矩阵（中心化）的协方差"。

#### `Xc.T @ Xc` —— 特征两两内积

**操作**：`Xc.T` 是 `(4,50)`，`Xc` 是 `(50,4)`，相乘得 `(4,4)`——第 $(i,j)$ 个元素是特征 $i$ 与特征 $j$ 的（未归一化）内积。除以 $N-1$ 得无偏协方差。
**可调参数**：除以 $N$ 或 $N-1$ 得到总体/样本协方差；`np.cov(Xc, rowvar=False)` 一步到位。
**对应数学**：主线"协方差矩阵天然对称"——$X^\top X$ 的转置是 $(X^\top X)^\top = X^\top X$，所以必然对称。**这就是为什么 PCA 的前提是协方差矩阵可正交对角化（§2.6）。**

## 边界声明：这套代码能做什么，不能做什么

1. **`np.allclose` 是"近似相等"**。浮点运算下 $A^\top$ 与 $A$ 可能差 $10^{-16}$，`allclose` 容差吸收它。判断对称性永远用 `allclose` 而非 `==`。
2. **对称性只对方阵有意义**。`np.allclose(A, A.T)` 对非方阵会在形状上就不同（`(3,2)` vs `(2,3)`），比较直接报错或返回 False。**对称 = 方阵 + 转置不变。**
3. **对称 ≠ 正定 ≠ 元素非负**。对称只管"镜像相等"。特征值全为正才是"正定"（§2.6.4）。看到"对称矩阵"别自动脑补"好的性质都成立"——正定性要单独验证。
4. **协方差对称是"定义使然"**：因为 $\text{Cov}(X_i,X_j)=\text{Cov}(X_j,X_i)$。若数据经过非线性变换，新特征间的"协方差"可能不再对称——对称性是"两两关系"假设下的产物，不是普遍真理。
