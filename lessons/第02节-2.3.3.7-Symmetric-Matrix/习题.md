# 习题：对称矩阵

## 第一组：概念检验

**1.1（单选）** 下列哪个矩阵是对称矩阵？
- A. $\begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$
- B. $\begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}$
- C. $\begin{bmatrix} 0 & 2 \\ -2 & 0 \end{bmatrix}$
- D. $\begin{bmatrix} 1 & 2 & 3 \end{bmatrix}$

**1.2（判断并说明）** "一个反对称矩阵（$A^\top = -A$）的对角线元素必须全为 0。" 这句话对吗？为什么？

**1.3（填空）** 对称矩阵满足 $A^\top = \_\_\_$；任意矩阵 $M$ 都可以分解为对称部分 $\_\_\_$ 与反对称部分 $\_\_\_$ 之和（写表达式）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算 $A = \begin{bmatrix} 1 & 4 \\ 4 & 9 \end{bmatrix}$ 的转置并验证对称；对 $B = \begin{bmatrix} 0 & 3 \\ -3 & 0 \end{bmatrix}$ 验证反对称。用 NumPy 确认。

**2.2（代码验证）** 对任意随机矩阵 $M$（如 3×3），验证 $M = \frac{M+M^\top}{2} + \frac{M-M^\top}{2}$（即"对称部分 + 反对称部分"精确重组原矩阵）。

**2.3（动手理解）** 用 NumPy 生成一个对称矩阵的"另一半"：构造 $A = B^\top B$（$B$ 是随机矩阵），验证 $A$ 必为对称矩阵，并解释为什么（提示：$(B^\top B)^\top = ?$）。

## 第三组：DL 延伸

**3.1（场景判断）** 一段文本的 4 个 token，两两之间的"共现次数"填进 4×4 矩阵。这个矩阵天然对称吗？为什么？这种矩阵在 NLP 里叫什么？

**3.2（场景分析）** PCA 需要把数据的协方差矩阵做特征分解。协方差矩阵为什么必然是对称的？对称性对 PCA 的成功（特征值实数、特征向量正交）起了什么作用？

## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：B 中 $A_{12}=2=A_{21}$ → 对称。A 中 $2\neq3$ 不对称；C 是反对称（$A^\top=-A$）；D 不是方阵（$1\times3$），谈不上对称。
- **点拨**：**对称前提是方阵 + $A_{ij}=A_{ji}$**。C 是经典的"反对称"陷阱——它"看起来整齐"但不是对称。

**1.2 对。**
- **思路**：反对称要求 $A^\top=-A$，逐元素即 $A_{ij}=-A_{ji}$。取 $i=j$：$A_{ii}=-A_{ii}$，只有 $A_{ii}=0$ 才能成立。所以对角线必为 0。
- **点拨**：这是"从定义推出结构"的小推导。对称矩阵对角线**可以**非零；反对称矩阵对角线**必须**为 0——两者的关键区别。

**1.3 答案：$A$；$\frac{M+M^\top}{2}$；$\frac{M-M^\top}{2}$。**
- **思路**：对称 $A^\top=A$；任意 $M$ 拆成 $\frac{M+M^\top}{2}$（对称）+ $\frac{M-M^\top}{2}$（反对称），两者相加得 $M$。
- **点拨**：这个分解是"对称/反对称"章节的万能工具——任何矩阵都能"对称化处理"。

### 第二组

**2.1**
$A^\top = \begin{bmatrix} 1&4\\4&9\end{bmatrix} = A$ → 对称；$B^\top = \begin{bmatrix} 0&-3\\3&0\end{bmatrix} = -B$ → 反对称。
```python
import numpy as np
A = np.array([[1.,4.],[4.,9.]])
B = np.array([[0.,3.],[-3.,0.]])
print(np.allclose(A, A.T))     # True
print(np.allclose(B, -B.T))    # True
```
- **思路**：逐元素对照定义。注意反对称判定是 `B.T == -B`，别写成 `B.T == B`。
- **点拨**：**对称判 `A.T==A`，反对称判 `A.T==-A`**——差一个负号，是高频笔误点。

**2.2**
```python
M = np.random.randn(3, 3)
sym_part  = (M + M.T) / 2
skew_part = (M - M.T) / 2
print(np.allclose(M, sym_part + skew_part))     # True
print(np.allclose(sym_part, sym_part.T))        # True
print(np.allclose(skew_part, -skew_part.T))     # True
```
- **思路**：$\frac{M+M^\top}{2}$ 对称、$\frac{M-M^\top}{2}$ 反对称，相加精确还原 $M$。
- **点拨**：这是"任何矩阵都能拆成对称+反对称"的数值证明。工程上它用于矩阵的对称化（如把非对称相似度矩阵投影到对称空间）。

**2.3**
```python
B = np.random.randn(4, 4)
A = B.T @ B
print(np.allclose(A, A.T))     # True，永远成立
```
- **思路**：$(B^\top B)^\top = B^\top (B^\top)^\top = B^\top B = A$——转置两次还原，所以 $A$ 对称。这是"构造对称矩阵"最常用的方法。
- **点拨**：$B^\top B$ 型矩阵还有更强的性质（半正定，特征值 $\ge 0$，§2.6.4 相关）。**协方差矩阵、Gram 矩阵都属于这一类。** 记住"$B^\top B$ 必对称半正定"这一句，后面很多章节会用。

### 第三组

**3.1 答案：天然对称；因为"共现"不分方向（token $i$ 与 $j$ 共现 = token $j$ 与 $i$ 共现）。这种矩阵叫"共现矩阵"（co-occurrence matrix），是词嵌入（§2.2.3.1）的经典前身。**
- **思路**：共现计数 $C_{ij}=C_{ji}$（同一对词的出现次数相同），所以矩阵对称。word2vec 之前，词嵌入就用共现矩阵 + SVD 得到。
- **点拨**：**"不分方向的两两关系"= 对称矩阵**——这一条贯穿 NLP 与图论。无向图的邻接矩阵同样如此。

**3.2 思路**
- 协方差 $C = \frac{1}{N}X^\top X$（中心化），$(X^\top X)^\top = X^\top X$，所以对称。
- 对称性对 PCA 的意义：谱定理保证对称矩阵的特征值全为实数、特征向量可正交归一化。这意味 PCA 一定能找到"一组互相垂直的主方向"，且按特征值（方差）大小排序——降维才不会歪斜、方向才正交清晰。若协方差非对称，特征值可能是复数、特征向量不正交，PCA 就失去几何意义。
- **点拨**：**PCA 能用，先决条件是协方差对称**。这解释了为什么"对称矩阵"这一小节是通向 §2.6 SVD/特征分解的必要铺垫。

## 一个"为什么有人会答错"的提醒

1.1 的 C（反对称）是经典陷阱——它满足 $A^\top=-A$，很多人在"对称"的选项里被它的整齐迷惑。**判据只有一条：转置后等于自己（对称）还是等于负自己（反对称）。** 2.1 的另一个坑是反对称判定符号——`A.T == -A` 写错成 `A.T == A` 就会把反对称误判为不对称。动手写一遍，这两个坑就填平了。
