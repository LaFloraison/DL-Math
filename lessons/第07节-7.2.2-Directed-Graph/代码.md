# Ch07 §7.2.2 有向图 · 代码.md

主线讲了有向图的定义：边是有序对 $(u,v)$，从 $u$ 指向 $v$，因此矩阵不对称、度分裂成出度与入度、可达性也带上了方向。本文件用一个三篇论文的引用网络（教材 §7.2.2 的 V={A,B,C}, E={(A,B),(A,C),(B,C)}）把这些全部实现成 numpy：构造有向邻接矩阵、验证不对称、算出度入度、再验证"引用不可逆"与"矩阵幂数有向路径"。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy：矩阵与运算

papers = ["A", "B", "C"]                               # ② 三篇论文
citations = [("A", "B"), ("A", "C"), ("B", "C")]       #    A 引 B、A 引 C、B 引 C

def directed_adjacency(nodes, edges):                  # ③ 有向邻接矩阵：只写一个方向
    idx = {name: i for i, name in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v in edges:
        A[idx[u], idx[v]] = 1.0                        # 只写 u→v，不写 v→u
    return A

def in_out_degree(A):                                  # ④ 出度=行和，入度=列和
    return A.sum(axis=1), A.sum(axis=0)

def reachable(A, start):                               # ⑤ 有向可达：沿箭头走
    visited = {start}
    frontier = [start]
    while frontier:
        nxt = []
        for v in frontier:
            for u in range(A.shape[0]):
                if A[v, u] == 1.0 and u not in visited:
                    visited.add(u)
                    nxt.append(u)
        frontier = nxt
    return sorted(visited)

A = directed_adjacency(papers, citations)              # ⑥ 主流程
out_d, in_d = in_out_degree(A)
print("有向邻接矩阵（行=引用方，列=被引方）：\n", A)
print("对称吗？", np.allclose(A, A.T))
print("出度（引用了几篇）:", out_d)
print("入度（被引了几次）:", in_d)
print("A→B 存在边吗？", A[0, 1] == 1.0, "  B→A 存在边吗？", A[1, 0] == 1.0)
print("从 A 出发能走到：", reachable(A, 0))
print("从 C 出发能走到：", reachable(A, 2))
```

输出：

```
有向邻接矩阵（行=引用方，列=被引方）：
 [[0. 1. 1.]
  [0. 0. 1.]
  [0. 0. 0.]]
对称吗？ False
出度（引用了几篇）: [2. 1. 0.]
入度（被引了几次）: [0. 1. 2.]
A→B 存在边吗？ True   B→A 存在边吗？ False
从 A 出发能走到： [0, 1, 2]
从 C 出发能走到： [2]
```

矩阵是个严格上三角——这是"引用只能向后"的自然形态（按发表顺序编号时）。A 引用了 B 和 C，出度 2、入度 0；C 被 A 和 B 引用，入度 2、出度 0。**一个方向流到底**：从 A 出发能到任何论文，从 C 出发只能原地踏步——单向关系的全部不平等，都在这几个数字里。

## 层二：分步逐函数拆解

### 步骤 1：定义有向邻接矩阵

```python
def directed_adjacency(nodes, edges):
    idx = {name: i for i, name in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v in edges:
        A[idx[u], idx[v]] = 1.0
    return A
```

#### directed_adjacency —— 只写一个方向的邻接矩阵

`A[idx[u], idx[v]] = 1.0`

**操作**：和无向版唯一的区别是**少了一行**——无向版写 `A[i,j]` 和 `A[j,i]` 两处，这里只写 `A[idx[u], idx[v]]` 一处，表示"从 u 指向 v"。方向被编码进矩阵的"行/列"分工：**第 i 行 = 从节点 i 出发的边，第 j 列 = 指向节点 j 的边。**

**输入**：`nodes`（list of str）、`edges`（list of (str, str)，每个二元组是有序的——顺序就是方向）。

**输出**：`np.ndarray`，形状 `(n, n)`。`A[i, j] == 1` 表示存在边 $i \to j$；注意 $A[j, i]$ 不受影响，可以仍是 0。

**可调参数**：
- `edges` 里二元组的**顺序即方向**：`("A","B")` 和 `("B","A")` 是两条完全不同的边，想建双向就得两条都写。
- `dtype=float`：若只想当 0/1 开关看，用 `dtype=int` 更省内存；要跟度、归一化配合就保留 float。
- 若要**加权有向图**（§7.2.4），把 `1.0` 换成权重 `w`——方向与强度同时进入矩阵。

**对应数学**：§7.2.2 定义 $E \subseteq V \times V$，每条边 $(u,v)$ 是有序对。矩阵的非对称性 $\neg(A_{ij} = A_{ji})$ 就是"方向性/不对称性"的直接体现。

---

### 步骤 2：定义出入度函数

```python
def in_out_degree(A):
    return A.sum(axis=1), A.sum(axis=0)
```

#### in_out_degree —— 出度行和、入度列和

`A.sum(axis=1)` 与 `A.sum(axis=0)`

**操作**：`axis=1` 沿行求和 → 第 i 个元素是"从 i 出发的边数"（出度）；`axis=0` 沿列求和 → 第 j 个元素是"指向 j 的边数"（入度）。无向图里这两个结果相同（对称），有向图里分道扬镳。

**输入**：`A`：`(n, n)` 有向邻接矩阵。

**输出**：两个 `np.ndarray`，形状 `(n,)`：出度数组、入度数组。对引用网络：出度 = "引用了几篇"，入度 = "被引了几次"。

**可调参数**：无额外参数。验证恒等式 $\sum d^+ = \sum d^- = |E|$：`out_d.sum()` 和 `in_d.sum()` 都应等于 `len(citations)` = 3。

**对应数学**：§7.2.2 的出度 $d^+(v)$ 与入度 $d^-(v)$。入度是加菲尔德"被引次数"的数学形态——影响力计量的起点。

### 步骤 3：定义有向可达函数

```python
def reachable(A, start):
    visited = {start}
    frontier = [start]
    while frontier:
        nxt = []
        for v in frontier:
            for u in range(A.shape[0]):
                if A[v, u] == 1.0 and u not in visited:
                    visited.add(u)
                    nxt.append(u)
        frontier = nxt
    return sorted(visited)
```

#### reachable —— 只沿箭头方向走的 BFS

`if A[v, u] == 1.0 and u not in visited`

**操作**：和 §7.2 的 `reach` 完全相同的 BFS 骨架，唯一的差别是查询条件 `A[v, u] == 1.0` 只认"v→u 这条有向边存在"。所以扩散只能顺着箭头走——u 认识 v 不再自动意味着 v 能到 u。

**输入**：`A`：`(n, n)` 有向邻接矩阵；`start`：int，出发节点。

**输出**：`list[int]`，从 `start` 沿箭头方向能到达的所有节点。

**可调参数**：
- 想算**强连通分量**（互相可达的节点团），可以两两比较"从 u 能否到 v"和"从 v 能否到 u"——都是这个函数的组合。
- 想限制跳数（K 跳可达），在 `while` 加计数器——这与 §7.7.1 GraphSAGE 的采样深度是同一概念。

**对应数学**：§7.2.2 的"可达性不再对称"。`reachable(A, 0) == [0,1,2]` 而 `reachable(A, 2) == [2]`——从引用源头能顺流而下，从末流不能逆流而上。

### 步骤 4：主流程

```python
A = directed_adjacency(papers, citations)
out_d, in_d = in_out_degree(A)
print("有向邻接矩阵：\n", A)
print("对称吗？", np.allclose(A, A.T))
...
```

#### 主流程 —— 验证不对称的三个证据

**操作**：`np.allclose(A, A.T)` 判不对称；`A[0,1]` 与 `A[1,0]` 直接对比 A→B 与 B→A；`reachable` 对比正反方向可达性。三个证据分别对应定义的三句话——方向性、不对称性、方向化可达。

**输入**：矩阵与下标。

**输出**：布尔值与列表的打印。

**可调参数**：`A[0, 1]` 里的下标随图变。想看"谁直接引用了 C"，就是 `A[:, 2]`（第 2 列的非零行）。

**对应数学**：无新概念，这是把 §7.2.2 的每条性质逐一落到数字上。

## 改个数字试试

### 实验 A：把图"翻转"——方向反过来，角色互换

```python
rev = directed_adjacency(papers, [ (v, u) for u, v in citations ])
print("反转后的出度/入度：", in_out_degree(rev))
print("反转后从 C 出发能走到：", reachable(rev, 2))
```

输出：

```
反转后的出度/入度： (array([0., 1., 2.]), array([2., 1., 0.]))
反转后从 C 出发能走到： [0, 1, 2]
```

方向一翻，A 从"引用者"变成"被引者"（入度 2），C 从"被引者"变成"引用者"（出度 2）。可达性也从"从 A 出发全通"翻转成"从 C 出发全通"。**有向图里，方向不是装饰，是整套角色分配的开关。** 这解释了为什么建模时必须想清楚箭头的语义——同一个结构，方向不同，读出的故事完全不同。

### 实验 B：矩阵的幂数有向路径

无向图里 $A^2$ 数"走两步的路数"，有向图同理，只是每一步都只能沿箭头：

```python
A2 = A @ A
print("A² 第 0 行（从 A 出发走 2 步有向路径的目标）：", np.where(A2[0] > 0)[0])
```

输出：

```
A² 第 0 行（从 A 出发走 2 步有向路径的目标）： [2]
```

从 A 走两步只能到 C（A→B→C；A→C 后 C 没有出边）。注意这里**没有**"回到自己"的 2 步路径（A→B 后 B 不能回 A），而无向版本会有——因为箭头禁止了反向。$A^k$ 依然数步数，但有向图里它数的，是"只能顺流而下的步数"。

**呼应主线**：Transformer 的注意力、知识图谱的关系，全是这种"只认一个方向"的图。理解了 `directed_adjacency` 里那"少写的一行"，你就理解了有向性的全部数学本质——以及为什么它能把"影响力""流量""依赖"这些单向世界装进深度学习。
