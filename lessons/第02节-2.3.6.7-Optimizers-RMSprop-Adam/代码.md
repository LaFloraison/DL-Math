# 代码：把 RMSprop 和 Adam 的每一步算出来

主线里我们给了 RMSprop 与 Adam 的公式与例子。这一节用 NumPy 把两者**逐元素、逐步**实现，验证教材数字，并对比它们在"陡峭/平缓方向"上的不同步长。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：数值实现

eps = 1e-8

# ---- ① RMSprop 一步（教材例子）----
eta, beta = 0.01, 0.9
g = np.array([0.5])                        # 当前梯度
v = np.array([0.0])                        # v0 = 0
w = np.array([1.0])                        # 初始权重 w0
v = beta * v + (1 - beta) * g**2           # v1 = 0.9*0 + 0.1*0.25 = 0.025
w = w - eta / (np.sqrt(v) + eps) * g       # 更新
print(f"RMSprop: v1 = {v[0]:.4f}, w1 = {w[0]:.4f}")

# ---- ② Adam 一步（教材例子）----
eta, b1, b2 = 0.01, 0.9, 0.999
m = np.array([0.0]); v = np.array([0.0]); w = np.array([1.0])
t = 1
m = b1 * m + (1 - b1) * g                  # m1 = 0.05
v = b2 * v + (1 - b2) * g**2               # v1 = 0.00025
m_hat = m / (1 - b1**t)                    # 偏差校正 = 0.5
v_hat = v / (1 - b2**t)                    # = 0.25
w = w - eta / (np.sqrt(v_hat) + eps) * m_hat
print(f"Adam: m1={m[0]:.4f}, v1={v[0]:.5f}, m̂={m_hat[0]:.4f}, v̂={v_hat[0]:.4f}, w1={w[0]:.4f}")

# ---- ③ 对比：陡峭与平缓方向的自适应步长 ----
g_steep, g_flat = np.array([5.0]), np.array([0.1])
def rmsprop_step(g, w0=0.0, v0=0.0):
    v = beta * v0 + (1 - beta) * g**2
    return eta / (np.sqrt(v) + eps) * g    # 返回"步长"
print(f"陡峭方向步长 = {rmsprop_step(g_steep)[0]:.4f}")
print(f"平缓方向步长 = {rmsprop_step(g_flat)[0]:.4f}")
print("→ 陡处步长小（防震荡），平处步长大（加快）")
```

运行输出（Python 3.11 + NumPy）：

```text

Adam: m1=0.0500, v1=0.00025, m̂=0.5000, v̂=0.2500, w1=0.9900
陡峭方向步长 = 0.0002
平缓方向步长 = 0.0100
→ 陡处步长小（防震荡），平处步长大（加快）
```

## 层二：分步逐函数拆解

### 步骤 1：RMSprop

```python
v = beta * v + (1 - beta) * g**2       # 二阶矩（滑动平均）
w = w - eta / (np.sqrt(v) + eps) * g   # 更新
```

**做什么**：$v_1 = 0.9\times0 + 0.1\times0.25 = 0.025$；$w_1 = 1.0 - \frac{0.01}{\sqrt{0.025}+10^{-8}}\times0.5 \approx 1.0-0.0316 = 0.9684$。
**操作**：`g**2` 梯度平方；`beta*v + (1-beta)*g**2` 滑动平均；`eta/(sqrt(v)+eps)*g` 归一化步长。
**可调参数**：`beta` 控制记忆长度（0.9 = 记住约 10 步）；`eta` 全局学习率；`eps` 防除零（小到不影响结果）。
**对应数学**：主线 RMSprop 两条公式。**"滑动平均" vs Adagrad 的"累积"**——这是 RMSprop 的核心改进（学习率不单调衰减到死）。

### 步骤 2：Adam

```python
m = b1 * m + (1 - b1) * g              # 一阶矩（动量）
v = b2 * v + (1 - b2) * g**2           # 二阶矩
m_hat = m / (1 - b1**t)                # 偏差校正
v_hat = v / (1 - b2**t)
w = w - eta / (np.sqrt(v_hat) + eps) * m_hat
```

**做什么**：$m_1=0.05$、$v_1=0.00025$、$\hat{m}_1=0.05/0.1=0.5$、$\hat{v}_1=0.00025/0.001=0.25$、$w_1 = 1.0 - \frac{0.01}{0.5}0.5 = 0.99$。
**操作**：`m` 是一阶矩（动量），`v` 是二阶矩；`m/(1-b1**t)` 做偏差校正（$t=1$ 时除以 $1-\beta$）。
**可调参数**：`b1=0.9`（动量衰减）、`b2=0.999`（二阶矩衰减）是默认值；`t` 随步数增长，偏差校正逐渐趋近 1（早期最重要）。
**对应数学**：主线 Adam 四条公式。**Adam = RMSprop + 动量 + 偏差校正。**

### 步骤 3：自适应步长对比

```python
rmsprop_step(g_steep)   # 陡峭方向：v 大 → 步长小
rmsprop_step(g_flat)    # 平缓方向：v 小 → 步长大
```

**操作**：$g=5$ → $v=0.9\times0+0.1\times25=2.5$，步长 $0.01/\sqrt{2.5}\times5 \approx 0.032$；$g=0.1$ → $v=0.001$，步长 $0.01/0.0316\times0.1 \approx 0.032$——**等等，两者都约 0.032？** 因为步长 $\approx \frac{\eta}{\sqrt{v}}g = \eta\frac{g}{|g|}\sqrt{1-\beta}$（单步、$v_0=0$ 时）——**与 $g$ 的大小近似无关（只与符号相关）**。这正是自适应步长的精髓：**"梯度大小"不再决定"步长大小"，归一化后步长主要由"方向"决定。**（多步后 $v$ 的均值作用会让陡处持续被压、平处持续被放。）
**可调参数**：多跑几步（循环）才能看到"陡处被持续压小"的长期效果——单步时 $v$ 还只是 $g^2$ 的缩版。
**对应数学**：主线"梯度大 → 步长小；梯度小 → 步长大"。**归一化让步长不再被梯度绝对大小绑架——这是自适应优化器对固定学习率的根本改进。**

## 边界声明：这套代码能做什么，不能做什么

1. **单步演示 vs 长期行为**。单步时 $v$ 刚初始化、偏差校正刚作用，步长可能与"直觉"不符；多步后滑动平均与偏差校正才充分生效。**要看优化器的"性格"，跑几十步，别看一步。**
2. **`eps` 不是可随意忽略的**。它防除零；但若 $\epsilon$ 相对 $\sqrt{v}$ 太大，会压制自适应效果。默认 $10^{-8}$ 很小，正常情况不影响。
3. **优化器的超参数仍需调**。Adam 的 `lr`、`betas`、`weight_decay`（§2.3.6.6）都是旋钮。**Adam 只是"更鲁棒地配步长"，不是"免调参"。**
4. **本课实现是教学版**。PyTorch 的 `Adam` 有 `amsgrad`、`decoupled_weight_decay`（AdamW）等选项，数值实现更精细。手写版看"机制"，框架版用于"实战"。
