# 习题：优化器——RMSprop 与 Adam

## 第一组：概念检验

**1.1（单选）** RMSprop 的 $v_t$ 更新是 $v_t = \beta v_{t-1} + (1-\beta)g_t^2$。当某参数最近梯度一直很大时，$\sqrt{v_t}$ 会____，导致该参数的步长____：
- A. 变大；变小
- B. 变大；变大
- C. 变小；变小
- D. 变小；变大

**1.2（判断并说明）** "Adam 比 RMSprop 多维护一个梯度的一阶矩（动量），并用偏差校正修正训练初期的估计。" 这句话对吗？Adam 的两个矩各管什么？

**1.3（填空）** RMSprop 用____的滑动平均归一化步长（解决 Adagrad 的____问题）；Adam 的更新是 $w_t = w_{t-1} - \frac{\eta}{\sqrt{\hat{v}_t}+\epsilon}\hat{m}_t$，其中 $\hat{m}$ 是____、$\hat{v}$ 是____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 手算 RMSprop 一步：$\eta=0.01,\ \beta=0.9,\ g=0.5,\ v_0=0,\ w_0=1.0$，用 NumPy 验证。

**2.2（代码验证）** 手算 Adam 一步：$\eta=0.01,\ \beta_1=0.9,\ \beta_2=0.999,\ g=0.5,\ m_0=v_0=0,\ w_0=1.0$，含偏差校正，用 NumPy 验证。

**2.3（动手理解）** 对"陡峭"（$g=5$）与"平缓"（$g=0.1$）两个参数各跑 10 步 RMSprop（$\beta=0.9,\ \eta=0.01$），记录每步步长，观察"陡处持续被压、平处保持较大"的长期效果。

## 第三组：DL 延伸

**3.1（场景判断）** PyTorch 里 `torch.optim.Adam(model.parameters(), lr=1e-3)` 与 `RMSprop(model.parameters(), lr=1e-3)` 的核心差别是什么？什么任务常选 RMSprop、什么选 Adam？

**3.2（场景分析）** 一个训练脚本从 SGD 换成 Adam 后，loss 收敛明显变快。请用"每参数自适应步长 + 动量"解释为什么 Adam 通常比朴素 SGD 收敛快，并指出 Adam 可能的缺点（泛化/超参）。

---

## 解答与思路点拨

### 第一组

**1.1 答案：A（变大；变小）。**
- **思路**：梯度大 → $g^2$ 大 → 滑动平均 $v_t$ 大 → $\sqrt{v_t}$ 大 → 步长 $\eta/(\sqrt{v}+\epsilon)\cdot g$ 的分母大 → 步长小。**陡处自动减速，防震荡。**
- **点拨**：这是 RMSprop 的核心直觉：**"步幅随陡峭程度自适应"**。B（变大变大）是把分母关系记反。

**1.2 对。**
- **思路**：Adam 比 RMSprop 多维护一阶矩 $m$（梯度本身的滑动平均 = 动量，管"方向惯性"）；二阶矩 $v$（梯度平方的滑动平均，管"幅度归一化"，同 RMSprop）。偏差校正 $\hat{m}=m/(1-\beta_1^t)$、$\hat{v}=v/(1-\beta_2^t)$ 修正"从 0 起步"的早期偏差。
- **点拨**：**"一阶管方向、二阶管幅度"**是 Adam 的记忆锚点。偏差校正在训练初期最重要（$t$ 小时 $1-\beta^t$ 远小于 1）。

**1.3 答案：梯度平方；学习率早衰（单调衰减）；一阶矩（动量）；二阶矩（梯度平方均值）。**
- **思路**：RMSprop 用"梯度平方滑动平均"替代 Adagrad 的"累积"；Adam 用 $\hat{m}$（动量）、$\hat{v}$（二阶矩）。
- **点拨**：三空对应"RMSprop 改进 Adagrad、Adam 加动量 + 偏差校正"的完整链条。

### 第二组

**2.1**
$v_1 = 0.9\times0 + 0.1\times0.25 = 0.025$；$w_1 = 1.0 - \frac{0.01}{\sqrt{0.025}+10^{-8}}\times0.5 \approx 1.0 - 0.0316 = 0.9684$。
```python
import numpy as np
eps=1e-8
v = 0.9*0 + 0.1*0.5**2          # 0.025
w = 1.0 - 0.01/(np.sqrt(v)+eps)*0.5
print(v, w)                     # 0.025 0.9684
```
- **思路**：先算 $v_1$（滑动平均），再算步长（归一化）。
- **点拨**：**步长 = $\eta\times\frac{g}{\sqrt{v}}$**——梯度被 $v$ 归一化，不再是 $g$ 的裸值。

**2.2**
$m_1 = 0.9\times0+0.1\times0.5 = 0.05$；$v_1 = 0.999\times0+0.001\times0.25 = 0.00025$；$\hat{m}_1 = 0.05/0.1 = 0.5$；$\hat{v}_1 = 0.00025/0.001 = 0.25$；$w_1 = 1.0 - \frac{0.01}{\sqrt{0.25}}0.5 = 1.0 - 0.01 = 0.99$。
```python
m = 0.9*0 + 0.1*0.5          # 0.05
v = 0.999*0 + 0.001*0.5**2   # 0.00025
mh = m/(1-0.9); vh = v/(1-0.999)
w = 1.0 - 0.01/(np.sqrt(vh)+1e-8)*mh
print(mh, vh, w)             # 0.5 0.25 0.99
```
- **思路**：先算矩，再偏差校正，最后更新。偏差校正让 $m_1=0.05$ 变回 $\hat{m}_1=0.5$（$g$ 本身）——**早期不被"从 0 起步"拖小。**
- **点拨**：**偏差校正在 $t=1$ 时最重要**（$1-\beta_1^1=0.1$，把 0.05 放大 10 倍回 0.5）。$t$ 大后校正系数趋近 1，不再起作用。

**2.3**
```python
def rmsprop(g, steps=10, beta=0.9, eta=0.01, eps=1e-8):
    v, w = 0.0, 0.0; stepsize = []
    for _ in range(steps):
        v = beta*v + (1-beta)*g*g
        step = eta/(np.sqrt(v)+eps)*g
        stepsize.append(step); w -= step
    return stepsize, w
s_steep, _ = rmsprop(5.0)
s_flat,  _ = rmsprop(0.1)
print("陡峭方向各步步长:", [round(s,5) for s in s_steep])
print("平缓方向各步步长:", [round(s,5) for s in s_flat])
```
- **思路**：多步后 $v$ 收敛到 $g^2$（$\beta\to$ 记忆的稳态），步长 $\to \eta/\sqrt{g^2}\cdot g = \eta\cdot\text{sign}(g)$——**每步大小趋近 $\eta$，与 $g$ 的绝对值无关**。陡处不再"一步跨很大"，平处不再"一步挪很小"。
- **点拨**：**RMSprop 让"步长"与"梯度大小"解耦**——这才是自适应学习率的精髓。单步看不出，多步才显。

### 第三组

**3.1 答案：核心差别是 Adam 多维护一阶矩（动量）+ 偏差校正；RMSprop 只有二阶矩。RMSprop 在 RNN、简单稳定训练中常用；Adam（及其 AdamW）是绝大多数现代任务（CNN/Transformer/大模型）的默认。**
- **思路**：RMSprop = 自适应步长；Adam = 自适应步长 + 动量 + 偏差校正。动量让 Adam 在平缓长坡加速、方向平滑；偏差校正修正早期。
- **点拨**：**"默认用 Adam，特殊情况用 SGD/RMSprop"**是工程惯例。R Adam 的"每参数步长"也带来泛化争议——某些任务上精心调优的 SGD 更好。

**3.2 思路**
- **自适应步长**：Adam 给每个参数独立配步长——陡的（梯度大）自动减速、平的（梯度小）自动加速，不像 SGD 用同一个 $\eta$ 在崎岖曲面上震荡或停滞。
- **动量**：一阶矩 $m$ 携带"前进方向"的惯性——在平缓长坡上沿一致方向加速，在噪声中平滑方向。两者叠加让 Adam 走得更快更稳。
- **缺点**：(1) 每参数自适应可能放大噪声、在某些任务收敛到泛化更差的点；(2) 超参（$\eta,\beta_1,\beta_2$）仍敏感；(3) 与权重衰减交互需用 AdamW（§2.3.6.6）。
- **点拨**：**Adam 的"快"来自自适应 + 动量，它的"争议"来自"自适应不一定泛化最好"。** 选优化器 = 在"收敛速度"与"最终泛化"之间权衡。
