# 代码：指数分布——把"无记忆"写进函数，让抽样证明它真的无记忆

主线里我们由"失效率恒定"这个无记忆性的精确翻译，逼出了指数分布的公式 $f(x)=\lambda e^{-\lambda x}$，CDF $F(x)=1-e^{-\lambda x}$，并算得"平均 2 分钟一通、1 分钟之内来"的概率约 39.3%。本课用代码做四件事：

1. **量密度**：在教材的呼叫中心例（$\lambda=0.5$）上量出 $x=0$、$x=1$ 等点的密度。
2. **验 CDF**：验证 $\mathrm{P}(X<1)\approx0.393$。
3. **验无记忆性**：数值上证明"已等 3 分钟再等 1 分钟以内"等于"从零开始等 1 分钟以内"。
4. **抽样验证**：用 `np.random.exponential` 抽样，统计等待时间直方图与理论密度是否吻合。

不调用现成的分布类，公式全部手写。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：exp / trapz / linspace / random

def exp_pdf(x, lam):                      # ① 密度：从 x=0 处的 lam 按 e^{-lam x} 衰减
    """指数密度：只活在 x>=0，速率参数 lam。"""
    return lam * np.exp(-lam * x) * (x >= 0)

def exp_cdf(x, lam):                      # ② 累积分布函数：1 - e^{-lam x}
    """P(X <= x)：x<0 为 0，之后按 1-e^{-lam x} 爬升。"""
    return np.where(x >= 0, 1.0 - np.exp(-lam * x), 0.0)

# ---- ① 教材的数字：平均 2 分钟一通，lam = 1/2 = 0.5 ----
lam = 0.5
print(f"f(0) = {exp_pdf(0.0, lam):.6f}   # 起点密度 = λ = 0.5")
print(f"f(1) = {exp_pdf(1.0, lam):.6f}   # 1 分钟后密度 = 0.5 * e^{-0.5}")
print(f"P(X<1) = {exp_cdf(1.0, lam):.6f}   # 理论 1 - e^{-0.5} ≈ 0.393")

# ---- ② 无记忆性：P(3<X<4) / P(X>3) 应该还是 P(X<1) ----
numerator   = exp_cdf(4.0, lam) - exp_cdf(3.0, lam)
denominator = 1.0 - exp_cdf(3.0, lam)
print(f"P(3<X<4 | X>3) = {numerator / denominator:.6f}   # 理论仍是 0.393！")

# ---- ③ 归一化裁决：∫ f(x) dx ≈ 1 ----
x = np.linspace(0.0, 30.0, 10001)         # [0,30] 覆盖 15 个平均等待时间，尾巴足够长
print(f"∫ Exp(0.5) ≈ {np.trapz(exp_pdf(x, lam), x):.6f}   # 理论值 1，有限区间丢了一点点尾巴")

# ---- ④ 抽样验证：抽 20 万次，看样本均值与区间占比 ----
np.random.seed(0)
samples = np.random.exponential(scale=1.0/lam, size=200000)   # scale = 1/λ = 平均等待时间
print(f"样本均值 = {samples.mean():.4f}   # 理论 E[X]=1/λ=2")
print(f"样本 P(X<1) = {np.mean(samples < 1.0):.4f}   # 理论 0.393")
```

运行输出（Python 3.11 + NumPy）：

```text
f(0) = 0.500000   # 起点密度 = λ = 0.5
f(1) = 0.303265   # 1 分钟后密度 = 0.5 * e^{-0.5}
P(X<1) = 0.393469   # 理论 1 - e^{-0.5} ≈ 0.393
P(3<X<4 | X>3) = 0.393469   # 理论仍是 0.393！
∫ Exp(0.5) ≈ 0.999959   # 理论值 1，有限区间丢了一点点尾巴
样本均值 = 2.0011   # 理论 E[X]=1/λ=2
样本 P(X<1) = 0.3937   # 理论 0.393
```

无记忆性在数字上被当场证明：`P(3<X<4 | X>3)` 和 `P(X<1)` 输出同一个数 `0.393469`。下面拆开每一行。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

```python
import numpy as np
```

本课需要 `np.exp`、`np.where`、`np.linspace`、`np.trapz`、`np.random.exponential`、`np.mean`。

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定简写 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：$e^{(\cdot)}$ 从 `np.exp` 来，$\lambda e^{-\lambda x}$ 的两个 $\lambda$ 由我们显式传入。

---

### 步骤 2：定义 `exp_pdf` —— 只活在半条数轴上的衰减

```python
def exp_pdf(x, lam):
    """指数密度：只活在 x>=0，速率参数 lam。"""
    return lam * np.exp(-lam * x) * (x >= 0)
```

#### exp_pdf —— 指数分布的密度：率参数驱动的衰减，x≥0 之外归零

`return lam * np.exp(-lam * x) * (x >= 0)`

**做什么**：对每个点算出指数密度——从 $x=0$ 处的高度 $\lambda$ 出发，按 $e^{-\lambda x}$ 指数式下坠。
**操作**：`-lam * x` 逐元素取负率乘时间；`np.exp(...)` 取 $e^{(\cdot)}$；再乘 `lam` 与布尔掩码 `(x >= 0)`。布尔数组乘数值数组时 `True→1, False→0`，于是 $x<0$ 的密度归零。
**输入**：
- `x`：标量或任意形状数组，待求密度的"等待时间"。
- `lam`（率参数，rate parameter，写做希腊字母 $\lambda$）：事件发生的平均速率，即单位时间事件数的期望。教材里平均 2 分钟一通电话，$\lambda=1/2=0.5$ 通/分钟。
**输出**：与 `x` 同形状的数组，每个位置是该点的密度。$x<0$ 处全为 0。
**可调参数**：
- `lam`：唯一参数，同时控制起点高度与衰减快慢。$x=0$ 处密度恰好等于 $\lambda$（所以 `f(0)=0.5`）；$\lambda$ 越大，$e^{-\lambda x}$ 掉得越快。$\lambda$ 的倒数 $1/\lambda$ 是平均等待时间。
- 能不能加参数？`x, lam` 已完备。有的库写成 `exp_pdf(x, scale)`，其中 `scale=1/lam`——同一分布，参数化方向相反。教材用 $\lambda$，我们跟着用。
**对应数学**：$f(x)=\lambda e^{-\lambda x},\ x\ge0$。`(x >= 0)` 是公式里"for $x\ge0$"的代码化身——等待时间不可能为负。

---

### 步骤 3：定义 `exp_cdf` —— 累积概率的闭式解

```python
def exp_cdf(x, lam):
    """P(X <= x)：x<0 为 0，之后按 1-e^{-lam x} 爬升。"""
    return np.where(x >= 0, 1.0 - np.exp(-lam * x), 0.0)
```

#### exp_cdf —— 指数分布的累积分布函数：$1-e^{-\lambda x}$

`np.where(x >= 0, 1.0 - np.exp(-lam * x), 0.0)`

**做什么**：回答"下一通电话在 $x$ 之内来"的概率。指数分布很幸运：它的 CDF 有闭式解 $1-e^{-\lambda x}$，不用做积分。
**操作**：`np.where` 处理负半轴（等待时间不能为负，$x<0$ 处概率为 0）；非负处直接套闭式公式。
**输入**：`x`（等待时间）、`lam`（速率），同 `exp_pdf`。
**输出**：与 `x` 同形状的数组，值在 $[0,1)$ 内。
**可调参数**：同 `exp_pdf`。想验证"2 分钟内来"的概率就用 `exp_cdf(2.0, 0.5) = 1-e^{-1} ≈ 0.632`。
**对应数学**：$F(x)=\int_0^x \lambda e^{-\lambda t}dt = 1-e^{-\lambda x}$。CDF 是 PDF 的积分，而指数分布的积分恰好能闭式完成。

---

### 步骤 4：验证无记忆性

```python
numerator   = exp_cdf(4.0, lam) - exp_cdf(3.0, lam)
denominator = 1.0 - exp_cdf(3.0, lam)
print(f"P(3<X<4 | X>3) = {numerator / denominator:.6f}   # 理论仍是 0.393！")
```

**做什么**：计算条件概率 $\mathrm{P}(3<X<4 \mid X>3)=\frac{\mathrm{P}(3<X<4)}{\mathrm{P}(X>3)}$，然后与 $\mathrm{P}(X<1)$ 对照。
**操作**：分子 `exp_cdf(4)-exp_cdf(3)` 是"4 分钟内减去 3 分钟内"的区间概率；分母 `1 - exp_cdf(3)` 是"等待超过 3 分钟"的概率；两者相除即条件概率。
**输入**：两个端点与 `lam`。
**输出**：`0.393469`——和 `P(X<1)` 完全相等。
**可调参数**：把 3 换成任何数，结果不变！这是无记忆性的直接演示——你甚至可以写个循环，对 $s=0,1,2,5,10$ 分别打印条件概率，它们全都是 $1-e^{-0.5}$。
**对应数学**：$\mathrm{P}(X>s+t\mid X>s)=\mathrm{P}(X>t)$。指数分布是唯一连续无记忆分布——这段代码证明的不是"某个数值巧合"，而是"已等待时间不进入最终概率"这个数学性质。

### 步骤 5：`np.trapz` 验证归一化

```python
x = np.linspace(0.0, 30.0, 10001)
print(f"∫ Exp(0.5) ≈ {np.trapz(exp_pdf(x, lam), x):.6f}   # 理论值 1，有限区间丢了一点点尾巴")
```

#### `np.linspace(0.0, 30.0, 10001)` 与 `np.trapz` —— 梯形积分验证总面积

**操作**：指数分布的积分域是 $[0,\infty)$，我们只铺到 30（15 个平均等待时间），所以输出 `0.999959` 略小于 1——差的那 $4\times10^{-5}$ 是 $[30,\infty)$ 漏掉的尾巴。注意这和均匀分布的 `1.000000` 不同：均匀的支撑是有限区间，指数的是无限区间。
**输入/输出/可调参数**：与前一节 `np.trapz` 完全一致。想提高精度就把网格放宽（如 `0, 60`）或加密。
**对应数学**：$\int_0^\infty\lambda e^{-\lambda x}dx=1$ 的近似。永远拿不到"无穷"本身，但可以无限逼近。

### 步骤 6：抽样验证 —— 大数定律把样本拉回理论

```python
np.random.seed(0)
samples = np.random.exponential(scale=1.0/lam, size=200000)
print(f"样本均值 = {samples.mean():.4f}   # 理论 E[X]=1/λ=2")
print(f"样本 P(X<1) = {np.mean(samples < 1.0):.4f}   # 理论 0.393")
```

#### `np.random.exponential(scale, size)` —— 从指数分布抽样

**操作**：抽取 `size` 个服从指数分布的独立样本。底层用逆变换采样 (inverse transform sampling)：先抽均匀样本 $u\sim\text{Uniform}(0,1)$，再算 $x=-\text{scale}\cdot\ln(1-u)$——把均匀"随机数"翻译成指数"等待时间"。这是因为 $F(x)=1-e^{-x/\text{scale}}$ 的反函数正好是 $-\text{scale}\cdot\ln(1-u)$。
**输入**：
- `scale`：**平均等待时间**，$1/\lambda$。教材里 $\lambda=0.5$，所以 `scale=2.0`。
- `size`：样本数。
**输出**：形状 `(200000,)` 的数组，近似服从 $\text{Exp}(\lambda)$。
**可调参数**：`scale` 也可写成 `scale=2.0` 直接传（就是平均等待时间）；注意它和 $f(x)=\lambda e^{-\lambda x}$ 的参数方向相反——传 $\lambda$ 时要记得取倒数。
**对应数学**：样本均值 `2.0011 ≈ 1/λ = 2`；样本 `P(X<1)=0.3937 ≈ 0.393`。理论给精确，抽样给验证。

## 改个数字试试：把速率推向极端

### 实验 1：λ 改到 2，平均等待缩到 0.5 分钟

```python
lam2 = 2.0
print(f"f(0) = {exp_pdf(0.0, lam2):.6f}   # 原 λ=0.5 时是 0.5")
print(f"f(1) = {exp_pdf(1.0, lam2):.6f}   # 原 λ=0.5 时是 0.303265")
print(f"P(X<0.5) = {exp_cdf(0.5, lam2):.6f}   # 平均 0.5 分钟内，来一半？1-e^{-1}=0.632")
```

输出：

```text
f(0) = 2.000000   # 原 λ=0.5 时是 0.5
f(1) = 0.270671   # 原 λ=0.5 时是 0.303265
P(X<0.5) = 0.632121   # 平均 0.5 分钟内，来一半？1-e^{-1}=0.632
```

λ 从 0.5 改到 2（平均等待从 2 分钟缩到 0.5 分钟）：起点密度跳到 2，$x=1$ 处掉得只剩 0.27——事件来得越密，曲线趴得越低、收得越快。而 $\mathrm{P}(X<\frac{1}{\lambda})$ 恒等于 $1-e^{-1}\approx0.632$，**不管 $\lambda$ 取多少**——"等待时间小于平均值"的概率永远是 63.2%。这是一个不容易想到的恒等式：平均等待时间之内，只有约 63% 的机会等到；剩下 37% 的人要等超过"平均"。

### 实验 2：可视化直方图 vs 理论密度

```python
hist, edges = np.histogram(samples, bins=60, range=(0.0, 10.0), density=True)
centers = (edges[:-1] + edges[1:]) / 2
err = np.max(np.abs(hist - exp_pdf(centers, lam)))
print(f"直方图与理论密度的最大偏差 = {err:.4f}")
```

输出（大致）：

```text
直方图与理论密度的最大偏差 = 0.0140
```

`density=True` 让直方图归一成"概率密度"，与理论密度在同一把尺子上可比。样本越多、分箱越细，偏差越小——这是大数定律与中心极限定理在直方图上的又一次握手。

## 边界声明：这套代码能做什么，不能做什么

1. **指数分布只认"恒定速率"。** 如果事件的发生速率随时间变化——比如晚高峰的电话量、会老化的机械零件——指数分布就失效了。老化的等待时间属于韦布尔 (Weibull) 分布。本脚本验算的公式只在"速率恒为 $\lambda$"的前提下成立。
2. **无记忆性是"数学事实"，不是"生活建议"。** "已经等了 3 分钟所以快来了"这个直觉对无记忆过程是错的；但如果你等的是公交车（它有固定时刻表，有记忆），"快来了"就是对的。用错分布，结论完全相反。
3. **有限区间积分永远差一点尾巴。** $\int_0^{30}$ 是 `0.999959` 而不是 `1.000000`——这是无限支撑分布数值积分的固有代价。对有限支撑的分布（均匀、Beta）则没有这个问题。
4. **这只是验算工具。** 真实建模用 `np.random.exponential` 或 `scipy.stats.expon` 直接工作；但逆变换采样 `-scale*ln(1-u)` 这条底层逻辑，正是本脚本 `exp_cdf` 的逆，看懂它才看得懂封装。
