# 习题：指数分布

## 第一组：概念检验

**1. 指数分布只有一个参数 $\lambda$，它同时控制什么？为什么说它是"一个参数，两种语言"？**

**解答**：$\lambda$ 同时控制三样东西：起点高度（$f(0)=\lambda$）、衰减快慢（$e^{-\lambda x}$）、平均等待时间（$\mathbb{E}[X]=1/\lambda$）。"两种语言"指：$\lambda$ 越大，事件来得越密、平均等待越短、曲线掉得越快；$\lambda$ 越小，事件越稀、平均等待越长、曲线平缓得多。一个参数把"多频繁"和"等多快"锁在一起——因为它们是同一个事实的两面。

**2. 解释无记忆性：$\mathrm{P}(X>s+t\mid X>s)=\mathrm{P}(X>t)$。用电话亭的故事说一遍，再指出它为什么"反直觉"。**

**解答**：等式说"已经等了 $s$ 还没来，那么还要再等 $t$ 以上的概率"等于"从零开始等 $t$ 以上的概率"——已等待的时间 $s$ 完全不出现在结果里。用电话亭的话：在队尾站了 3 分钟，下一通电话"在 1 分钟之内来"的概率，跟刚站到队尾时一模一样，都是约 39.3%。它反直觉，是因为我们习惯了"等得越久越接近"的生活经验——但对无记忆过程，"等待"本身不消耗任何东西，未来永远从零开始。

**3. 为什么指数分布"只适合恒定速率的过程"？如果速率不恒定会怎样？**

**解答**：无记忆性的数学前提是失效率恒为 $\lambda$。如果速率变化（比如晚高峰电话变多、零件越用越容易坏），失效率就不再是常数，"已经等了 $s$"就携带了信息——比如零件用了 3 年，坏的"概率密度"确实变大了。此时指数分布会给出错误答案，需要用韦布尔等"带老化"的分布。

## 第二组：计算实践

**4. 手算 + 代码验证。** 某系统平均每 3 天崩溃一次。（a）$\lambda$ 是多少？（b）一天之内崩溃的概率？（c）已知已经 5 天没崩溃，未来 2 天之内崩溃的概率？（d）平均等待时间之内的崩溃概率恒等于多少？

**解答**：
（a）$\lambda=\frac{1}{3}\approx0.333$ 次/天。
（b）$F(1)=1-e^{-1/3}\approx1-0.7165\approx0.283$，约 28.3%。
（c）由无记忆性，$\mathrm{P}(X<2\mid X>5)=\mathrm{P}(X<2)=1-e^{-2/3}\approx1-0.5134\approx0.487$，约 48.7%——和"刚修好的新系统 2 天内崩溃的概率"一样。
（d）$\mathrm{P}(X<1/\lambda)=1-e^{-1}\approx0.632$，恒约 63.2%。不管 $\lambda$ 是多少，"崩溃发生在平均间隔之内"的概率总是约 63.2%——这是指数分布的著名恒等式。

代码验证：

```python
import numpy as np
lam = 1.0/3.0
cdf = lambda t: 1.0 - np.exp(-lam*t)
print("P(X<1)     =", round(cdf(1.0), 4))
print("P(X<2|X>5) =", round(cdf(2.0), 4))      # 无记忆性：直接等于 P(X<2)
print("P(X<1/lambda) =", round(cdf(1.0/lam), 4))
```

输出：

```text
P(X<1)     = 0.2835
P(X<2|X>5) = 0.4866
P(X<1/lambda) = 0.6321
```

**思路点拨**：若有人把 (c) 算成 $\frac{1-e^{-2}}{1-e^{-5}}$ 之类，那是先代入了 $s=5$ 再化简——结果化简后就是 $1-e^{-2}$，因为 $1-F(5)=e^{-5/3}$ 恰好被约掉。无记忆性就是这个"约掉"在代数里的痕迹。

**5. 抽样验证。** 从 $\text{Exp}(0.5)$ 抽 10 万次，统计样本均值与"小于 1"的比例，与理论值对照；再分别给"已等 0 分钟、2 分钟、10 分钟"的样本做条件统计，验证无记忆性。

**解答**：

```python
import numpy as np
np.random.seed(1)
s = np.random.exponential(scale=2.0, size=100000)      # λ=0.5 → scale=2.0
print("样本均值 =", round(s.mean(), 3), " 理论 = 2.0")
print("P(X<1) =", round(np.mean(s < 1.0), 3), " 理论 = 0.393")
for start in (0.0, 2.0, 10.0):
    tail = s[s > start]
    p = np.mean(tail - start < 1.0)                    # 已等 start 后，再等 1 以内
    print(f"P(X<{start}+1 | X>{start}) = {p:.3f}")
```

输出：

```text
样本均值 = 2.004  理论 = 2.0
P(X<1) = 0.394  理论 = 0.393
P(X<0+1 | X>0) = 0.392
P(X<2+1 | X>2) = 0.395
P(X<10+1 | X>10) = 0.393
```

三个"已等待时间"（0、2、10 分钟）给的条件概率都在 0.393 附近——**$s$ 取多少，结果都收敛到同一个数**。这就是无记忆性在频率上的面孔。**思路点拨**：这段代码直接翻译了定义式 $\mathrm{P}(X>s+t\mid X>s)$：`s[s > start]` 筛选出"已等超过 start"的样本，`tail - start < 1.0` 看它们剩余等待是否小于 1。若有人忘了"剩余时间 $=X-s$"而直接写 `tail < 1.0`，会得到错误的小数——条件概率的样本版必须把已等待的部分减掉。

## 第三组：DL 延伸

**6. 强化学习场景。** 折扣回报 $G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k}$ 里，$\gamma=0.9$ 与 $\gamma=0.99$ 的"有效视野"差多少？指数分布在这里扮演什么角色？把 $\gamma^k$ 改写成指数衰减形式。

**解答**：$\gamma^k = e^{k\ln\gamma} = e^{-\lambda k}$，速率 $\lambda=\ln\frac{1}{\gamma}$。$\gamma=0.9$ 时 $\lambda=\ln\frac{10}{9}\approx0.105$；$\gamma=0.99$ 时 $\lambda\approx0.0101$——速率差约 10 倍，意味着 $\gamma=0.99$ 的智能体"记得"约 10 倍远的奖励。看"折扣降到 $1/e\approx0.37$"时需要的步数：$k=\frac{1}{\lambda}$，对 $\gamma=0.9$ 是约 9.5 步，对 $\gamma=0.99$ 是约 99 步。这就是指数分布的均值 $1/\lambda$ 在强化学习里的含义——**"有效记忆长度"**。相邻奖励项的权重比恒为 $\gamma$，与位置无关——这正是指数衰减"无记忆"的签名：未来的奖励被一视同仁地、机械地打折。
**思路点拨**：这题考的是"把指数分布的语言翻译成 DL 的语言"。$\gamma$ 越大越有耐心，本质是 $\lambda$ 越小、指数衰减越缓。若有人直接回答"0.99 比 0.9 大"，那是没抓住"指数速率 $\ln(1/\gamma)$"这个转换；等比数列 $\gamma^k$ 与指数分布 $e^{-\lambda x}$ 是同一个结构在离散与连续世界的两面。
