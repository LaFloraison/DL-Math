## 第一步：Toy Model —— 1.75 张桌子？

一间小木工作坊，做两种家具：小桌（A）和木椅（B）。每张小桌净赚 2 元，每把木椅净赚 3 元。原料和时间都有限：

- **木料**：每张小桌耗 1 单位木料，每把木椅耗 3 单位，你只有 7 单位。于是 $A + 3B \le 7$。
- **工时**：每张小桌耗 3 工时，每把木椅耗 1 工时，你只有 7 个工时。于是 $3A + B \le 7$。

你拿起上一节学到的线性规划，画出两条线，找到顶点。联立 $A + 3B = 7$ 与 $3A + B = 7$，解得 $A = 1.75, B = 1.75$。代入利润：$P = 2\times 1.75 + 3\times 1.75 = 8.75$。

你盯着这个答案，忽然愣住了。**1.75 张桌子？** 你环顾作坊——锯子、刨子、散落的木料。没有哪把锯子能把一张桌子锯成 1.75 张。你的产品必须是**整数**：0 张、1 张、2 张……而不是 1.75 张。

于是你试着"四舍五入"：$A=1.75 \to 2$，$B=1.75 \to 2$，做 2 张桌子 2 把椅子？一验算：木料 $2 + 3\times 2 = 8 > 7$——**超了**！工时 $3\times 2 + 2 = 8 > 7$——也超了！四舍五入的结果根本不可行。你退回去试 (1,2)：木料 $1+6=7\le7$ ✓，工时 $3+2=5\le7$ ✓，利润 $2+6=8$。再试 (2,1)：利润 $4+3=7$。**(1,2) 的 8 元，比 (2,1) 的 7 元好——但它是 1 张桌子 2 把椅子，跟"四舍五入"出来的 (2,2) 毫无关系。**

你撞上了一个全新的问题：**线性规划把最优解放在 (1.75, 1.75)，可现实只接受整数格点。四舍五入是陷阱，不是答案。** 在无穷多个整数格点里，怎么不靠一个个试，找到那个真正的最优？该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：为什么"四舍五入"会翻车

先把你刚才的遭遇讲精确。线性规划（§5.3.1）把变量当连续实数，算出最优解 $x^* = (1.75, 1.75)$。整数优化要求 $x \in \mathbb{Z}^n$——变量必须取整数。直觉上你会想：LP 最优解就在旁边，四舍五入一下不就行了？

**错，而且错得深刻。** 四舍五入有两个致命问题：

1. **舍入可能不可行。** $(1.75,1.75)$ 舍入成 $(2,2)$，走出可行域——违反了两条约束。整数格点不像连续解那样"挨着边界就有邻居"，离散点之间是**跳跃**的，一跳就可能跳过可行域。
2. **即使可行，也可能远非最优。** 就算舍入出可行解 $(2,1)$（利润 7），真正的整数最优 $(1,2)$（利润 8）躲在另一个方向——它和 LP 最优解**不在同一象限**。LP 最优点周围"最近的整数点"根本不是整数最优。

这说明一个残酷的事实：**整数优化的困难，不是"连续解改整数"的技术细节，而是问题结构本身的剧变。** 可行域从"连成一片的多面体"变成"撒在一张网上的孤立格点"——那张网（图 5.4 里的网格）上，相邻格点之间没有任何"连续性"可借力。你没法从 (1,1) 平滑地滑向 (1,2)，只能一个个跳。

### 二、整数优化的三种形态

教材把整数优化 (integer optimization, IO / integer programming, IP) 分成三种：

**(a) 纯整数规划 (Pure Integer Programming, PIP)**——所有变量都是整数。木工作坊：$A, B \in \mathbb{Z}_{\ge 0}$。

**(b) 混合整数规划 (Mixed Integer Programming, MIP)**——部分变量整数、部分变量连续。最接近现实：比如"建多少座仓库"是整数（整数座），"每座仓库备货多少"是连续的（吨数可以带小数）。

**(c) 二进制整数规划 (Binary Integer Programming, BIP)**——变量只能是 0 或 1。用于"开关式"决策：开还是关、上马还是放弃、选还是不选。上一节的"生产 A 还是 B"如果变成"生产还是不生产 A"，就是 BIP。

> **整数规划 (integer programming)**
>
> 物理含义：在要求部分或全部决策变量取整数的前提下，最大化或最小化目标函数——现实世界"没有半个产品""没有 2.7 个人"的硬性要求。
>
> $$\max_{x} \; c^T x \quad \text{s.t.} \quad Ax \le b,\; x \ge 0,\; x_i \in \mathbb{Z}\ \forall i \in \mathcal{I}$$
>
> - $c^T x$：目标函数（可为线性或非线性，线性时称 **线性整数规划**）
> - $Ax \le b$：约束（可为线性或非线性）
> - $\mathcal{I}$：整数变量的下标集合。若 $\mathcal{I}$ 含所有变量 → **PIP**；含部分 → **MIP**；若变量取值只能 0/1 → **BIP**
> - 去掉 $x_i \in \mathbb{Z}$ 的版本称为**连续松弛 (continuous relaxation)**——它是 LP，解是整数问题的"宽松上界"

**每个符号的含义逐一解释：** 教材的例子——桌子 T、椅子 C，利润 $Z = 20T + 15C$，总产量 $T + C \le 100$，且 $T, C \in \mathbb{Z}$。注意这里的 LP 松弛解是 $(100, 0)$（纯整数，恰好不用舍入）——但换一组约束，松弛解立刻就不是整数，陷阱就会出现（Toy Model 的木工坊就是反面教材）。

### 三、为什么整数优化是 NP-hard 的：困难有数学证据

这是必须诚实面对的一堵墙。教材直说了：**IO 问题被归类为 NP-hard——计算困难会随问题规模指数级增长。**

NP-hard 的含义：目前人类不知道存在多项式时间算法能保证求解任意整数优化问题。这意味着什么？——**求解一个 100 变量的整数问题，可能比求解一个 50 变量的同类问题难上不可想象的倍数**，而且没有任何已知算法能避免这个"墙"。这不是我们不够聪明，而是这类问题的内在结构：**离散的组合爆炸**。

对比一下就懂了。连续 LP 为什么容易？因为目标线性 + 可行域凸，最优必在有限个顶点上（§5.3.1），顶点可以高效遍历。整数问题为什么难？因为可行格点虽然也有限（在有限区域里），但**格点数量可以多到指数级**，且它们之间没有"连续梯度"可以借力——**梯度下降在离散空间里根本没有梯度**。§5.3.6 之后你会看到，梯度是深度学习优化的命根子；而整数问题恰恰把梯度拔掉了，逼你走完全不同的路。

**边界声明：** "NP-hard"说的是**最坏情况**。现实中大量整数问题有专门结构（比如纯 0/1 背包、指派问题），可以用多项式算法解决；现代求解器（CPLEX、Gurobi、HiGHS）也在几十上百亿变量的工业问题上战功赫赫。**"NP-hard"是数学上最坏情况的宣言，不是"这题永远解不出"的丧钟。**

### 四、整数优化的三件武器

既然整数问题是硬骨头，数学给出一套成套工具。教材点名三个：

**武器一：分支定界 (branch and bound, B&B)。** 思路是"先放松，再切割"。先把整数约束扔掉，解连续松弛（LP）——得到一个"太乐观"的解（上界）。如果松弛解已经全是整数，太好了，它就是最优；如果有变量是分数（比如 $B = 1.75$），就在这个变量上**分支**：分别强制 $B \le 1$ 和 $B \ge 2$，把原问题劈成两个子问题，递归求解。用各子问题的上界剪掉"不可能超过当前最好整数解"的分支。**用"聪明的剪枝"把指数搜索砍成可承受的规模。**（§5.3.10 专讲。）

**武器二：割平面法 (cutting plane method)。** 不从解上动手，而是从**可行域**上动手：给原来的多面体不断加新的线性约束（割平面），一刀一刀把"不含任何整数点的角落"切掉，让松弛 LP 的顶点逐渐逼向整数点。**用"切掉无用的空间"代替"搜索所有格点"。**（§5.3.10 一并展开。）

**武器三：启发式 (heuristics)。** 放弃"保证最优"，只求"够快够好"。教材点名的有**舍入 (rounding)**——把连续解四舍五入到最近整数（小心，Toy Model 已经证明了它是陷阱）；还有**diving** 之类技巧。启发式可能找不到最优，但能在瞬间给出一个可接受的可行解——在必须立刻决策的场合（比如调度），"够好"远比"最优"实用。

### 五、Toy Model 收束：格点上的最优点

回到木工坊。$A + 3B \le 7$、$3A + B \le 7$、$A,B \in \mathbb{Z}_{\ge 0}$。可行整数格点只有几个：(0,0) 到 (2,2) 之间的那些点。逐一检验：$(1,2)$ 利润 8 是最高。**整数最优不是"LP 最优的舍入"，它是格点世界里自己的王。**

这条教训值得刻在墙上：**整数优化里，"最优"要重新定义——它是在离散格点上的最优，而不是在连续空间里的最优。** 连续世界说"往那边走一点更赚"；离散世界说"你只能站在格子上，格子之间没有路"。

## 第三步：DL 桥接

**整数优化在深度学习里有两个角色：一个是"敌人"，一个是"工具"。**

**敌人：梯度是连续世界的通行证，离散空间没有梯度。** 深度学习训练靠梯度下降，而梯度要求变量连续可导。一切把网络结构变成"离散选择"的做法（网络层数、神经元数量、激活函数选哪个、神经元要不要剪掉）都撞上整数优化的墙——它们本质上是离散决策，不能直接求导。这就是为什么**神经架构搜索 (neural architecture search, NAS)** 早期用强化学习/进化算法（§5.3.11）这类无梯度工具，直到 DARTS 提出**连续松弛 (continuous relaxation)** 技巧：把"选 A 还是选 B"的 0/1 选择，软化成"A 的权重 0.3、B 的权重 0.7"的连续混合——**先松弛成连续问题求梯度，再在结束时做硬选择**。这和 IP 的"先解松弛 LP 再处理整数"是同一个哲学，只是用在两个完全不同的年代。

**工具：二进制决策在模型里开枝散叶。** BIP 的 0/1 变量，正是 **dropout** 的数学模型——每个神经元以概率保留（1）或丢弃（0），mask 是一个二进制向量。**随机掩码 = 对网络做一次二进制采样**。类似地，**模型剪枝 (pruning)** 决定"这个权重要不要保留"，**混合专家 (Mixture of Experts)** 决定"这个 token 路由到哪几个专家"——全是整数/二进制的开关。

**最痛的隐喻：量化 (quantization) 就是深度学习里的"取整陷阱"。** 为了把模型压到手机上，权重从 float32 舍入到 int8——**直接舍入**会让精度雪崩，正像 Toy Model 里把 (1.75,1.75) 舍入成不可行的 (2,2)。工程上必须用更聪明的策略（量化感知训练、渐进量化）来对付"取整的毒性"。**你在量化模型时犯的错，和木工师傅面对 1.75 张桌子时犯的错，是同一个错。**

离散与连续的对抗，贯穿了从 1954 年的旅行商问题到 2018 年的 DARTS。而理解这条分界线，就是理解"哪些优化问题能用梯度解决、哪些不能"的钥匙。具体如何枚举整数格点、验证 (1,2) 是最优，见《代码.md》。
