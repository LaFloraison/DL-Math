# 代码：整数枚举——在格点上找王

**目标**：主线里木工坊的问题——$\max P = 2A + 3B$，约束 $A + 3B \le 7,\; 3A + B \le 7,\; A,B \in \mathbb{Z}_{\ge 0}$。这里用**暴力整数枚举**：把可行整数格点全部扫一遍，找出真正的最优 $(1,2)=8$。同时代码直接演示主线的核心教训——**连续松弛的最优 $(1.75,1.75)=8.75$ 与四舍五入的陷阱 $(2,2)$**，三者并排打印，让你亲眼看到"离散世界的王不认连续世界的路"。

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 约束 ----
# 木料: A + 3B <= 7 ; 工时: 3A + B <= 7 ; A, B 为非负整数
def feasible(A, B):
    return (A + 3.0 * B <= 7.0 + 1e-9
            and 3.0 * A + B <= 7.0 + 1e-9
            and A >= 0 and B >= 0)

# ---- 2. 暴力枚举整数格点 ----
best_A, best_B, best_P = -1, -1, -np.inf
grid_pts = 0
for A in range(0, 8):                # A 从 0 到 7
    for B in range(0, 8):            # B 从 0 到 7
        if feasible(A, B):
            grid_pts += 1
            P = 2.0 * A + 3.0 * B
            if P > best_P:
                best_A, best_B, best_P = A, B, P

# ---- 3. 对照：连续松弛与四舍五入 ----
# LP 松弛顶点: 联立 A+3B=7, 3A+B=7 => A=B=1.75, P=8.75
relax_A, relax_B, relax_P = 1.75, 1.75, 8.75
round_A, round_B = 2, 2                       # 四舍五入 (1.75->2)
round_feasible = feasible(round_A, round_B)   # 验证: 违反约束吗?

print(f"整数枚举: 可行格点 {grid_pts} 个")
print(f"整数最优解: A={best_A}, B={best_B}, P={best_P}")
print(f"连续松弛解: A={relax_A}, B={relax_B}, P={relax_P}  (只是个幻想)")
print(f"四舍五入  : A={round_A}, B={round_B}, 可行? {round_feasible}")
if not round_feasible:
    print(f"  -> (2,2) 违反约束: A+3B={round_A+3*round_B}>7")
```

输出：

```
整数枚举: 可行格点 10 个
整数最优解: A=1, B=2, P=8
连续松弛解: A=1.75, B=1.75, P=8.75  (只是个幻想)
四舍五入  : A=2, B=2, 可行? False
  -> (2,2) 违反约束: A+3B=8>7
```

三行输出，三个世界：连续松弛给出的 8.75 是**幻想**（造不出 1.75 张桌子）；四舍五入的 (2,2) 是**陷阱**（超木料）；真正能兑现的是整数格点里的 (1,2)=8。**离散世界的最优，和连续世界的最优，住在两个不同的星球。**

## 层二：分步逐函数拆解

### 步骤 1：约束函数——整数的可行性检验

```python
def feasible(A, B):
    return (A + 3.0 * B <= 7.0 + 1e-9
            and 3.0 * A + B <= 7.0 + 1e-9
            and A >= 0 and B >= 0)
```

#### `feasible` —— 整数点可行性

**操作**：对给定整数对 $(A,B)$ 逐条检查两条不等式约束与非负约束，全部满足返回 `True`。`1e-9` 是浮点容差（整数运算理论上不需要，但统一写法能防后续改成浮点时的边界误判）。
**输入**：`A`、`B` —— 两个整数（或浮点）。**输出**：`bool`。
**可调参数**：
- 增删一个 `and` 条件就是增删一条约束。比如加 `and 2.0*A + 2.0*B <= 10.0`，可行格点变少，最优解可能换人。
- 把 `<= 7.0` 改成 `<= 6.0`，可行域缩小，整数最优会随之变化——你可以亲眼看到"约束松一寸，最优挪一步"。

**对应数学**：主线里整数问题的约束集 $Ax \le b, x \ge 0$，这里只额外要求 $A,B$ 是整数。

---

### 步骤 2：暴力枚举——把整张格子网扫一遍

```python
best_A, best_B, best_P = -1, -1, -np.inf
grid_pts = 0
for A in range(0, 8):
    for B in range(0, 8):
        if feasible(A, B):
            grid_pts += 1
            P = 2.0 * A + 3.0 * B
            if P > best_P:
                best_A, best_B, best_P = A, B, P
```

#### `range(0, 8)` 双重循环 —— 扫描 8×8 格点网

**操作**：让 $A, B$ 各自遍历 $0,1,\dots,7$，共 64 个候选格点（图 5.4 里那种网格）。为什么到 7 就够？因为 $A \ge 8$ 时 $3A + B \ge 24 > 7$ 必违反工时约束——**搜索上界可以从约束里推出来**。
**输入**：无。**输出**：依次访问每个 $(A,B)$。
**可调参数**：把上界 `8` 改成 `20`，扫描范围扩大但不会找到更好的解（8 以上必不可行）——这是"用约束剪掉搜索空间"的朴素版，正是主线说的启发式/剪枝思想的最早形态。

#### `grid_pts += 1` —— 统计可行格点数

**操作**：每发现一个可行格点计数加一。输出显示共 10 个可行格点——其中 (1,2)=8 是冠军。
**可调参数**：无。**意义**：让你直观感受到"格点有限但必须逐个看"。

#### 更新最优

**操作**：`P = 2.0*A + 3.0*B` 计算目标值；`if P > best_P` 保留历史最优。`best_P` 初始为 `-np.inf`，保证第一个可行格点必然胜出。
**可调参数**：把 `>` 换 `<`、`-np.inf` 换 `+np.inf` 即变最小化。目标系数 `2.0, 3.0` 决定"更偏爱谁"——系数越大，解越偏向对应变量。

**对应数学**：这是主线里"逐一检验整数格点"的机器版。对 2 变量小问题，枚举可行；对 100 变量——格点数指数爆炸，枚举就是灾难。这正是分支定界/割平面（§5.3.10）存在的原因。

---

### 步骤 3：对照——松弛、舍入、真相

```python
relax_A, relax_B, relax_P = 1.75, 1.75, 8.75
round_A, round_B = 2, 2
round_feasible = feasible(round_A, round_B)
```

**操作**：写死连续松弛解 $(1.75,1.75)=8.75$（由联立两条约束线得出），把四舍五入结果 $(2,2)$ 送进 `feasible` 检验。
**输入**：无（硬编码）。**输出**：`round_feasible = False`——(2,2) 违反木料约束。
**可调参数**：把舍入策略从"四舍五入"换成"向下取整"$(1,1)$，可行但利润只有 5，远逊 (1,2)=8——**说明"离 LP 解近"≠"整数最优"**。

**对应数学**：连续松弛是主线定义块里"去掉整数约束的宽松上界"；四舍五入是主线武器三里点名的启发式之一，而这里证明了它为什么是陷阱。

---

### 步骤 4：打印三个世界

```python
print(f"整数枚举: 可行格点 {grid_pts} 个")
print(f"整数最优解: A={best_A}, B={best_B}, P={best_P}")
print(f"连续松弛解: A={relax_A}, B={relax_B}, P={relax_P}  (只是个幻想)")
print(f"四舍五入  : A={round_A}, B={round_B}, 可行? {round_feasible}")
```

**操作**：并排打印三行结果，让"连续松弛 8.75 > 整数最优 8 > 舍入 7"的落差一目了然。**注意连续松弛的 8.75 甚至高于整数最优的 8**——因为松弛允许了造不出来的分数解，它给出的是**上界**，而整数最优永远不可能超过这个上界。分支定界正是用"松弛解当上界"来剪枝的。

## 实验台：让整数问题长出牙齿

1. **把第二条约束改成 $2A + 3B \le 7$**：整数最优会变吗？先心算，再跑代码验证。
2. **加一条 $A + B \le 4$**：可行格点变少，最优解如何漂移？
3. **把目标改成 $P = 5A + 2B$**（更偏爱桌子）：最优解会从 (1,2) 挪到哪个格点？——体会"目标方向改变王位"。
4. **把变量扩展到 3 个（加一个 $C$）**：枚举变成三重循环，格点数从 64 涨到 512——**维度诅咒的暴力版本**，为你理解为什么需要分支定界埋下引线。

**对应数学**：这一切都在验证主线的一句话——**整数最优是格点世界的王，连续最优是连续世界的王，两者之间没有梯子。**
