## 解答与思路点拨

### 第一组

**1.1** 纯整数规划 (PIP)；混合整数规划 (MIP)；二进制整数规划 (BIP)。**易错点**：MIP 不是"介于两者之间"的模糊地带，而是"同时含整数和连续变量"的精确类别——比如"建几座仓库"（整数）+"每座库存多少吨"（连续）。

**1.2** 选 B。四舍五入的两宗罪正是主线撞墙的核心：舍入后可能跳出可行域（不可行），而且即便落在可行域内，也可能与真正的整数最优相去甚远（(2,1)=7 vs 真正最优 (1,2)=8）。A 错——四舍五入的结果当然是整数；C 错——舍入是 O(1) 的计算；D 错——整数问题通常有可行解（比如全零解）。

**1.3** 前半句对（IO 被归类为 NP-hard），后半句错。**"NP-hard"描述的是最坏情况**：存在整数问题实例，其计算难度随规模指数增长，且目前没有已知的多项式算法能保证所有实例都快。但实践中大量整数问题有特殊结构（背包、指派、网络流），用分支定界/割平面/专用算法在巨大规模上解得很好；现代求解器解决数十亿变量的工业问题并不罕见。**判断要点**：把"最坏情况困难"误当成"所有情况都无解"，是这道题最常见的陷阱。

### 第二组

**2.1**
(a) 连续松弛：约束 $A+2B\le6$、$2A+B\le6$。顶点：$(0,0)$、$(3,0)$（$2A+B=6$ 与 $B=0$）、$(2,2)$（联立：$A+2B=6,\;2A+B=6 \Rightarrow A=2,B=2$）、$(0,3)$（$A+2B=6$ 与 $A=0$）。目标 $3A+2B$：$(0,0)\to0$；$(3,0)\to9$；$(2,2)\to6+4=10$；$(0,3)\to6$。**连续松弛最优 $(2,2)$，值 10**——恰好是整数，所以 (a) 与 (b) 相同！这是一个"松弛解碰巧整数"的例子。
(b) 可行整数格点：$(0,0)$…$(2,2)$ 内的点。逐一算 $3A+2B$，最大的是 $(2,2)=10$。**整数最优 $(2,2)$，值 10。**
(c) 两者**无差**——因为松弛最优本来就是整数。**要点**：这提醒你，"整数问题难"只在松弛解是分数时显现。**别把"整数优化"想成永远难——很多实例松弛解碰巧整数，解起来和 LP 一样快。**
**易错点**：这道题若直接把 (b) 当"舍入"处理，你会误以为舍入成功；但它的真正教学点是：**要判断舍入可不可靠，先看松弛解是不是分数。**

**2.2** 枚举所有 $x_i\in\{0,1\}^4$（16 种组合，剔除超重的）：总重量 $\le 5$。最优是装物品 4（重 4 值 7）+ 物品 1（重 1 值 3），总重 5，总值 **10**。检验其他：物品 2+3（重 5 值 9）次之；物品 3+1（重 4 值 8）。**最优装法 {1,4}，价值 10。**
**易错点**：直觉会选"价值密度最高"的贪心——物品 1 密度 3、物品 2 密度 2、物品 3 密度 1.67、物品 4 密度 1.75。按密度贪心先选 1、2（重 3 值 7），再想选密度次高的 4 但超重（3+4=7>5），最后得 7——**贪心只拿到 7，全局最优 10**。这正是"离散不可借连续梯度"的又一个写照，也是背包问题需要精确枚举/动态规划的原因。

**2.3** 修改：

```python
def feasible(A, B):
    return (A + 2.0 * B <= 6.0 + 1e-9
            and 2.0 * A + B <= 6.0 + 1e-9
            and A >= 0 and B >= 0)
# P = 5.0 * A + 2.0 * B
```

运行结果：`整数最优解 A=3, B=0, P=15`。（更偏爱桌子后，解从偏向 B 的位置挪到 $(3,0)$。）**要点**：只改约束和目标两处，枚举逻辑不动——与手算 2.1 的松弛最优 $(3,0)=15$ 一致（碰巧仍是整数）。

### 第三组

**3.1** 量化是"把连续权重舍入到离散整数"的过程，和 Toy Model 把 $(1.75,1.75)$ 舍入成 $(2,2)$ 是同一个动作。直接舍入的雪崩来自取整陷阱：(a) **舍入后参数可能越界**——某个权重舍入后让激活值爆炸（类比 (2,2) 违反约束）；(b) **即使不越界，舍入方向也是局部的**——单独看每个权重的"最近整数"是对的，但它们叠加在网络上就累积成大的精度损失，正如 (2,2) 离真正最优 (1,2) 很远。所以工程上用**量化感知训练**（让网络在量化误差下训练，学着容忍离散）而不是事后舍入——相当于"在离散世界里训练，而不是在连续世界里算完再搬"。

**3.2** DARTS 把"操作 A 还是操作 B"的 0/1 选择，替换成"操作 A 权重 $\alpha_A$、操作 B 权重 $\alpha_B$"的连续混合（$\alpha$ 连续可导），在训练中优化连续权重，最后按权重大小做硬选择。这与整数优化的**连续松弛**完全同构：把整数约束 $x\in\{0,1\}$ 放松成 $x\in[0,1]$，先解连续问题，再在结束时恢复整数。松弛后容易的根本原因是：**连续变量有梯度，梯度可以指引优化器平滑地朝最优移动；而 0/1 离散空间没有梯度，只能枚举或启发式。** DARTS 的全部巧妙，就是把一个"没有梯度的离散选择"翻译成"有梯度的连续优化"——这正是整数优化六十年来反复使用的策略。
