# 代码：让"记忆"流进隐藏状态——从零手写一个 RNN

主线里我们把 RNN 写成了两条公式：$h_t = f(W_h h_{t-1} + W_x x_t + b)$ 与 $y_t = f_y(W_y h_t + c)$。本节代码**从零实现**这两条公式，用教材的例句"The cat is on the mat"做实验：

1. 把前 5 个词（The cat is on the）逐字喂进 RNN，观察隐藏状态 $h_1\to h_5$ 如何**逐字累积记忆**；
2. 看第 5 步的输出 $y_5$ 给 6 个候选词打的分数——"mat" 是否得分最高；
3. 最后，用一条标量链证明 RNN 的**硬伤**：反向传播穿过时间（BPTT），梯度随序列长度指数衰减（$0.5^L$）——这就是"长序列记不住"的数学根源。

脚本只依赖 NumPy。权重是随机初始化的（种子固定），我们演示的是**机制**——"记忆如何流动"；训练（§9.3.3 之外的课程）只是把分数往正确方向拧。

## 层一：完整脚本

```python
import numpy as np, math

VOCAB = ['The','cat','is','on','the','mat']     # 6 个词的词典
SEQUENCE = ['The','cat','is','on','the']        # 前 5 词，目标预测 'mat'
idx = {w:i for i,w in enumerate(VOCAB)}

def onehot(w):
    """把词变成 one-hot 向量（词典大小 6）。"""
    v = np.zeros(len(VOCAB)); v[idx[w]] = 1.0
    return v

def rnn_forward(X, Wx, Wh, b, Wy, c, hidden=8):
    """按教材公式逐字前向：返回每步隐藏状态与输出分数。"""
    hs = [np.zeros((1, hidden))]                 # h_0 = 0（初始无记忆）
    ys = []
    for t in range(len(X)):
        h = np.tanh(X[t:t+1] @ Wx + hs[-1] @ Wh + b)   # h_t = f(Wh h_{t-1} + Wx x_t + b)
        hs.append(h)
        ys.append(h @ Wy + c)                    # y_t = f_y(Wy h_t + c)（这里 f_y 线性）
    return hs, ys

# ---- 实验 1：逐字前向，看记忆累积 ----
np.random.seed(3)
hidden = 8
Wx = np.random.randn(len(VOCAB), hidden) * 0.5   # 输入权重
Wh = np.random.randn(hidden, hidden) * 0.5       # 循环权重（记忆怎么传）
b  = np.zeros((1, hidden))
Wy = np.random.randn(hidden, len(VOCAB)) * 0.5   # 输出权重
c  = np.zeros((1, len(VOCAB)))

X = np.stack([onehot(w) for w in SEQUENCE])      # (5, 6)
hs, ys = rnn_forward(X, Wx, Wh, b, Wy, c)
print("每步隐藏状态范数 |h_t|：",
      [round(float(np.linalg.norm(h)), 3) for h in hs[1:]])
y5 = ys[-1].ravel()
print("y5 给 6 个词的分数：",
      {w: round(float(y5[idx[w]]), 3) for w in VOCAB})
print("第 5 步 top-1 预测：", VOCAB[int(np.argmax(y5))])

# ---- 实验 2：记忆真的在流动吗？篡改 h_4 再看 h_5 ----
h4_orig = hs[4]
h5_orig = hs[5]
hs[4] = np.zeros_like(h4_orig)                   # 把第 4 步的记忆清零
h5_new = np.tanh(X[4:5] @ Wx + hs[4] @ Wh + b)   # 用空记忆重算第 5 步
print(f"记忆清零前后 h5 的变化量 ||h5新 - h5原|| = {np.linalg.norm(h5_new - h5_orig):.3f}")

# ---- 实验 3：BPTT 梯度随序列长度指数衰减 ----
print("反向传播穿过 L 个时间步的梯度幅值（每步增益 0.5）：")
for L in (1, 5, 10, 20):
    g = 0.5 ** L
    print(f"  L={L:2d}: 梯度≈{g:.2e}  log10={math.log10(g):6.2f}")
```

运行输出（Python 3.11 + NumPy）：

```text
每步隐藏状态范数 |h_t|： [1.112, 1.846, 1.884, 2.047, 1.702]
y5 给 6 个词的分数： {'The': 0.051, 'cat': 0.379, 'is': -1.478, 'on': 0.268, 'the': -0.8, 'mat': 0.389}
第 5 步 top-1 预测： mat
记忆清零前后 h5 的变化量 ||h5新 - h5原|| = 2.135
反向传播穿过 L 个时间步的梯度幅值（每步增益 0.5）：
  L= 1: 梯度≈5.00e-01  log10= -0.30
  L= 5: 梯度≈3.12e-02  log10= -1.51
  L=10: 梯度≈9.77e-04  log10= -3.01
  L=20: 梯度≈9.54e-07  log10= -6.02
```

读这组输出：

- **记忆在累积**：$|h_t|$ 从 1.112 一路波动到 2.047——每一步的隐藏状态都在"重写"，且**每一步都依赖上一步**（这正是循环边干的事）。
- **预测"mat"**：$y_5$ 给 "mat" 打了 0.389 的最高分——虽然权重是随机的，但**机制跑通了**：读到第 5 个词时，网络基于前 5 个词的语境输出下一个词的候选分数。
- **记忆真的流动**：把 $h_4$ 清零后重算 $h_5$，$h_5$ 变化了 2.135——**第 4 步的记忆直接影响第 5 步**，不是摆设。
- **BPTT 的硬伤**：梯度随序列长度按 $0.5^L$ 指数衰减，L=20 时只剩 $10^{-6}$ 量级——**序列越长，早先的信息越传不回来**。这就是教材说的"长序列中梯度消失/爆炸"。

## 层二：分步逐函数拆解

### 步骤 1：`onehot` —— 把词变成向量

```python
def onehot(w):
    v = np.zeros(len(VOCAB)); v[idx[w]] = 1.0
    return v
```

**做什么**：把词 "The" 变成 6 维向量，只有它对应的位置是 1。
**操作**：`idx[w]` 查出词在词典里的下标，把那个位置的 0 改成 1.0。
**输入**：`w`（词）。
**输出**：`(6,)` 的 one-hot 向量。
**可调参数**：无。真实模型用**词嵌入 (embedding)** 代替 one-hot（把 6 维变成几百维稠密向量，且"语义相近的词向量相近"）——one-hot 是理解机制的最小形式。
**对应数学**：$x_t$ 的编码。每个词是输入空间的一个标准基向量。

---

### 步骤 2：`rnn_forward` —— 教材两条公式的逐字实现

```python
def rnn_forward(X, Wx, Wh, b, Wy, c, hidden=8):
    hs = [np.zeros((1, hidden))]
    ys = []
    for t in range(len(X)):
        h = np.tanh(X[t:t+1] @ Wx + hs[-1] @ Wh + b)
        hs.append(h)
        ys.append(h @ Wy + c)
    return hs, ys
```

#### `rnn_forward` —— 循环边把时间串起来

**做什么**：按时间步 $t=1,\dots,T$ 依次处理输入。每一步用"当前词 + 上一步隐藏状态"更新 $h_t$，再从 $h_t$ 产生输出。
**操作**：
- `hs = [np.zeros((1,hidden))]`——$h_0$ 初始化为零（开头没有记忆）。
- 循环体 `h = np.tanh(X[t:t+1] @ Wx + hs[-1] @ Wh + b)` 是教材公式 $h_t = f(W_h h_{t-1} + W_x x_t + b)$ 的直接翻译：`X[t:t+1] @ Wx` 是"当前词的贡献"，`hs[-1] @ Wh` 是"上一步记忆的贡献"，两者相加过 tanh。
- `ys.append(h @ Wy + c)` 是 $y_t = f_y(W_y h_t + c)$（这里 $f_y$ 取线性，因为我们要的是分数）。
**输入**：`X`(T×6) 序列、`Wx`(6×8)、`Wh`(8×8)、`b`(1×8)、`Wy`(8×6)、`c`(1×6)、`hidden`。
**输出**：`(hs, ys)`——`hs` 是长度 T+1 的隐藏状态列表（`hs[0]` 是 $h_0$=0），`ys` 是长度 T 的分数列表。
**可调参数**：
- `Wh` 的规模是"记忆的持久性"旋钮：`Wh` 乘以 0.5（`np.random.randn(hidden,hidden)*0.25`）让记忆衰减更快；乘以 2.0 让记忆过于"顽固"甚至爆炸。**$W_h$ 的谱半径（最大特征值）决定了记忆能传多远**——这正是实验 3 的微观机制。
- `hidden` 是隐藏维度：越大装的记忆越"宽"；8 是小玩具值。
- `np.tanh` 换成 `np.maximum(z,0)`（ReLU）会改变衰减行为——ReLU 没有 tanh 的饱和，但容易爆炸（§9.3.4 会讲）。
**对应数学**：教材 $h_t = f(W_h h_{t-1} + W_x x_t + b)$ 与 $y_t = f_y(W_y h_t + c)$ 的逐符号翻译。**注意 $W_h, W_x, W_y$ 在每一步复用**——"the" 在第 1 位和第 5 位用的是同一套权重（权重共享，主线里三堵墙的答案）。

### 步骤 3：实验 2 —— 篡改 $h_4$，验证记忆真的在流动

```python
h4_orig = hs[4]
h5_orig = hs[5]
hs[4] = np.zeros_like(h4_orig)
h5_new = np.tanh(X[4:5] @ Wx + hs[4] @ Wh + b)
print(f"记忆清零前后 h5 的变化量 = {np.linalg.norm(h5_new - h5_orig):.3f}")
```

**做什么**：把第 4 步的隐藏状态清零，用同一个公式重算 $h_5$，比较 $h_5$ 变没变。
**操作**：`np.zeros_like(h4_orig)` 造一个同形状的零向量替换 `hs[4]`；重跑第 5 步的前向；`np.linalg.norm(...)` 量两个 $h_5$ 的欧氏距离。
**输入**：`hs`、`X`、`Wx`、`Wh`、`b`。
**输出**：一个标量距离。
**可调参数**：篡改方式可换——把 `hs[4]` 改成随机值、或者只清一半维度，观察 $h_5$ 变化程度。**篡改越"靠近"第 5 步，影响越大**——这也是"记忆随距离衰减"的直接证据。
**对应数学**：$\partial h_5 / \partial h_4 = W_h^\top \cdot \mathrm{diag}(f'(z_5))$ 的实验验证——$h_5$ 对 $h_4$ 的依赖不为零，正是循环边在传"梯度/信息"。

### 步骤 4：实验 3 —— BPTT 梯度衰减

```python
for L in (1, 5, 10, 20):
    g = 0.5 ** L
    print(f"  L={L:2d}: 梯度≈{g:.2e}  log10={math.log10(g):6.2f}")
```

**做什么**：算出反向传播穿过 L 个时间步后，$h_0$ 收到的梯度幅值——用标量近似：每回传一步，梯度乘一次"时间增益"（这里取 0.5）。
**操作**：`0.5 ** L` 就是 $g^L$。$g<1$ 时指数衰减；$g>1$ 时指数爆炸。
**输入**：`L`（时间步数）。
**输出**：每行一个梯度幅值与它的 log10。
**可调参数**：把底数 0.5 换成 1.5——梯度从"消失"翻转为"爆炸"（$1.5^{20}\approx 3325$）。**RNN 的 $W_h$ 恰好处在临界点上：谱半径 <1 消失、>1 爆炸**——这就是"vanishing/exploding gradient"的一体两面，也是为什么 LSTM 需要专门的恒等通道（§9.3.2 历史的传送带）。
**对应数学**：BPTT 的核心：$\partial L / \partial h_0 = \partial L / \partial h_T \cdot \prod_{t} (W_h^\top \mathrm{diag}(f'(z_t)))$。乘积项数 = 序列长度——**循环网络的时间深度，就是 §9.3.1.1 深度问题的重演**。

## 改个数字试试：记忆到底能传多远？

```python
# 篡改灵敏度：循环权重大 → 记忆影响强；循环权重小 → 记忆"憋死"
for scale in (0.1, 1.0):
    hs_t, _ = rnn_forward(X, Wx, Wh*scale, b, Wy, c)
    h4, h5 = hs_t[4], hs_t[5]
    hs_t[4] = np.zeros_like(h4)                 # 清零第 4 步记忆
    h5_new = np.tanh(X[4:5] @ Wx + hs_t[4] @ (Wh*scale) + b)
    print(f"Wh×{scale}: 清零 h4 后 h5 变化量 = {np.linalg.norm(h5_new - h5):.3f}")
```

```text
Wh×0.1: 清零 h4 后 h5 变化量 = 0.131
Wh×1.0: 清零 h4 后 h5 变化量 = 2.135
```

循环权重 $W_h$ 缩小 10 倍，$h_4$ 的记忆对 $h_5$ 的影响从 2.135 跌到 0.131——**记忆几乎传不动了**。这就是"记忆能传多远"的控制旋钮：$W_h$ 的规模（更准确说是它的谱半径）决定过去对现在的影响强度。**$W_h$ 太小 → 记忆立即遗忘（梯度消失）；太大 → 记忆失控（梯度爆炸）**——RNN 的整个设计史（LSTM 门控、初始化、归一化）都是在刀尖上平衡这个量。注意：前向的 tanh 会把激活压在有界范围（所以这里 h 没有爆炸），但**反向传播的梯度**不受 tanh 保护——爆炸发生在 BPTT 的乘积里（实验 3 已见）。

## 边界声明：这套代码能做什么，不能做什么

1. **它演示的是"前向机制"，不是"训练好的模型"**。权重是随机的，所以 "mat" 得分最高只是凑巧（种子 3）——机制正确不代表学会了。真正的"预测 mat"需要 BPTT 训练（把 $y_t$ 与真实下一个词做损失，反传更新权重），那是本节的边界之外。
2. **BPTT 衰减用的是标量近似**。真实 RNN 的每步增益是 $W_h^\top \mathrm{diag}(f')$ 的谱行为，随输入而变，不总等于固定常数。但"乘积项数=序列长度→指数行为"的定性结论，在真实 RNN 中成立——这正是长程依赖问题的公认诊断。
3. **它没实现门控**。LSTM/GRU 通过门（§9.3.2 历史的传送带）给记忆加恒等通道，缓解 BPTT 衰减；本节的朴素 RNN 是它们的"未加门"基线。**先看懂朴素 RNN 为什么衰减，才能看懂门为什么能救它。**
