# 代码：让"面积缩放几倍"当场被量出来

主线里我们说：Jacobian 行列式的绝对值是局部面积缩放系数，符号表示翻没翻面。这一节的脚本把这些话从"抽象定义"变成"可测量的实验"：

1. 教材例题 $u = 2x + y$，$v = x - y$：算 $\det J = -3$，然后用**真实的点**验证——把一个微小的正方形变换成平行四边形，量它的面积，看是否恰好是原来的 3 倍；
2. **翻面检测**：量变换后平行四边形的"有向面积"符号，验证 $\det J < 0$ 对应翻转；
3. **一维回声**：$f(x) = x^2$ 的"行列式"就是 $f'(x)$，验证换元法的长度缩放；
4. **极坐标**：算 $|\det J| = r$，验证"二重积分换极坐标乘 $r$"。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 教材变换：u = 2x + y, v = x - y ----
def T(x, y):
    return np.array([2.0*x + y, x - y])

J = np.array([[2.0, 1.0], [1.0, -1.0]])
detJ = np.linalg.det(J)
print(f"det J = {detJ:.2f}   绝对值 = {abs(detJ):.2f}（面积放大倍数）  符号 = {'翻转' if detJ < 0 else '保持'}")

# ---- ② 数值验证：把小正方形变换成平行四边形，量面积 ----
# 取以原点为中心、边长为 eps 的小正方形，四个角点变换后围成平行四边形
eps = 0.01
corners = np.array([[-1,-1],[1,-1],[1,1],[-1,1]]) * eps      # 小正方形四角
transformed = np.array([T(*c) for c in corners])             # 变换后四角
# 面积 = |(b-a) × (d-a)| / 2（平行四边形两邻边叉积），这里取四边形的两条对角线法
area_sq = (2*eps) * (2*eps)                                  # 原正方形面积
def polygon_area(pts):
    x, y = pts[:,0], pts[:,1]
    return 0.5 * abs(np.sum(x * np.roll(y, -1) - np.roll(x, -1) * y))   # 鞋带公式
area_tr = polygon_area(transformed)
print(f"原正方形面积 = {area_sq:.4f}   变换后面积 = {area_tr:.6f}   比值 = {area_tr/area_sq:.2f}")

# ---- ③ 翻面检测：用叉积符号看方向 ----
v1 = transformed[1] - transformed[0]      # 边 1
v2 = transformed[3] - transformed[0]      # 边 2
signed = np.cross(v1, v2)                 # 叉积（z 分量）
print(f"变换后叉积符号 = {signed:+.4f}   （负 = 翻面，与 det J<0 一致）")

# ---- ④ 一维回声：f(x) = x^2，'行列式' = f'(x) ----
def f1(x): return x**2
x0 = 2.0
dx = 0.001
len_scale = (f1(x0 + dx) - f1(x0)) / dx   # 数值 f'(x) = 2x
print(f"\n一维：f(x)=x² 在 x=2 处 '|det J|'≈{len_scale:.3f}  解析 f'(2)={2*x0:.1f}")

# ---- ⑤ 极坐标：x = r cosθ, y = r sinθ，|det J| = r ----
def polar_jac(r, theta):
    return np.array([[np.cos(theta), -r*np.sin(theta)],
                     [np.sin(theta),  r*np.cos(theta)]])
for (r, th) in [(2.0, 0.5), (3.0, 1.0)]:
    print(f"极坐标 r={r}：|det J| = {abs(np.linalg.det(polar_jac(r, th))):.4f}   （应 = r）")
```

运行输出（Python 3.11 + NumPy）：

```text
det J = -3.00   绝对值 = 3.00（面积放大倍数）  符号 = 翻转
原正方形面积 = 0.0004   变换后面积 = 0.001200   比值 = 3.00
变换后叉积符号 = -0.002400   （负 = 翻面，与 det J<0 一致）
一维：f(x)=x² 在 x=2 处 '|det J|'≈4.000   解析 f'(2)=4.0
极坐标 r=2：|det J| = 2.0000   （应 = r）
极坐标 r=3：|det J| = 3.0000   （应 = r）
```

四个实验全部兑现：$\det J = -3$，小正方形面积恰好放大 3 倍；叉积符号为负（翻面）；一维 $f'(2)=4$；极坐标 $|\det J|=r$。下面逐段拆解。

## 层二：分步逐函数拆解

### 步骤 1：算 det J —— 教材例题

```python
J = np.array([[2.0, 1.0], [1.0, -1.0]])
detJ = np.linalg.det(J)
```

#### `np.linalg.det(J)` —— 计算行列式

`detJ = np.linalg.det(J)`

**做什么**：对 $2 \times 2$ 矩阵算行列式 $ad - bc = 2\times(-1) - 1\times1 = -3$。`np.linalg.det` 对任意方阵都能算（内部用 LU 分解等数值方法）。
**操作**：`np.linalg.det(J)` 返回标量 $-3$。绝对值 3 是面积缩放，符号负表示翻面。
**输入**：`J`，形状 `(2,2)` 的方阵。
**输出**：行列式，标量。
**可调参数**：`J` 换成任意方阵。换 $J = [[2,0],[0,3]]$ 得 $\det = 6$（拉伸不翻面）；换 $J = [[-1,0],[0,1]]$ 得 $-1$（镜像）。可以随意试验。
**对应数学**：主线定义块 $\det J$ 与教材算例 $2\times(-1)-1\times1 = -3$。

---

### 步骤 2：数值面积验证 —— 用真实的点量"放大倍数"

```python
corners = np.array([[-1,-1],[1,-1],[1,1],[-1,1]]) * eps
transformed = np.array([T(*c) for c in corners])
def polygon_area(pts):
    x, y = pts[:,0], pts[:,1]
    return 0.5 * abs(np.sum(x * np.roll(y, -1) - np.roll(x, -1) * y))
```

#### `polygon_area(pts)` —— 鞋带公式量多边形面积

`return 0.5 * abs(np.sum(x * np.roll(y, -1) - np.roll(x, -1) * y))`

**做什么**：用**鞋带公式 (shoelace formula)** 计算变换后四边形的面积。输出 `0.0012 / 0.0004 = 3.00`——和 $|\det J| = 3$ 完全一致。
**操作**：`np.roll(y, -1)` 把数组循环右移一位（$y_{i+1}$）；`x * roll(y,-1) - roll(x,-1) * y` 是鞋带公式的交叉项；求和取 0.5 倍、取绝对值。
**输入**：`pts`，形状 `(4,2)` 的顶点数组（按环绕顺序）。
**输出**：多边形面积，标量。
**可调参数**：`eps` 越小越接近"微元"（线性近似越准）。把 `eps` 改成 `0.5`，比值会偏离 3.00（因为线性变换对任意大小都精确放大 3 倍——这个变换本身是线性的，所以其实始终精确 3 倍；换成非线性变换，`eps` 越小越接近 $|\det J|$）。
**对应数学**：主线"$|\det J|$ = 面积缩放倍数"。这里用"真实面积测量"验证了"行列式 = 缩放系数"——不是定义自证，而是独立测量对照。

---

### 步骤 3：翻面检测 —— 叉积符号

```python
v1 = transformed[1] - transformed[0]
v2 = transformed[3] - transformed[0]
signed = np.cross(v1, v2)
```

#### `np.cross(v1, v2)` —— 叉积测"有向面积"

`signed = np.cross(v1, v2)`

**做什么**：计算变换后两邻边的二维叉积（有向面积）。输出 `-0.0024`——负号对应"翻面"，与 $\det J = -3 < 0$ 一致。**有向面积的符号 = 行列式的符号**。
**操作**：`np.cross` 对二维向量返回标量（$v_{1x}v_{2y} - v_{1y}v_{2x}$）。符号为正 = 逆时针（未翻面），负 = 顺时针（翻面）。
**输入**：`v1`、`v2`，形状 `(2,)` 的边向量。
**输出**：有向面积，标量（带符号）。
**可调参数**：把变换换成 $u = 2x, v = 3y$（只拉伸），叉积为正——与 $\det J = 6 > 0$ 一致。这是"符号 = 定向"的独立验证。
**对应数学**：主线"$\det J > 0$ 保持定向、$< 0$ 反转定向"。叉积（有向面积）正是二维行列式的几何别名。

---

### 步骤 4：一维回声 —— $f(x) = x^2$ 的"行列式"

```python
def f1(x): return x**2
len_scale = (f1(x0 + dx) - f1(x0)) / dx
```

#### 一维换元的长度缩放

`len_scale = (f1(x0 + dx) - f1(x0)) / dx`

**做什么**：在 $x=2$ 处量 $x^2$ 的局部长度缩放系数。输出 `4.000`，解析 $f'(2) = 4$。**一维的 Jacobian 行列式就是导数本身**——$du = f'(x)dx$ 里那个 $f'(x)$。
**操作**：向前差分 $(f(2+0.001) - f(2))/0.001 \approx f'(2)$。这是"换元积分乘修正因子"在 $n=1$ 时的数值实现。
**输入**：`x0`（求导点）、`dx`（步长）。
**输出**：数值导数（一维"行列式"）。
**可调参数**：`x0` 换成 $-1$，$f'(x) = -2$——长度为负？不，换元用的是 $|f'(x)|$；符号仍表示方向是否翻转（$x \to x^2$ 在负半轴是"折叠"）。这提醒你：**一维里"翻面"就是"方向反转"。**
**对应数学**：主线"一维的回声"——$du = f'(x)dx$，$f'(x)$ 是 1 维 Jacobian 行列式。

---

### 步骤 5：极坐标 —— $|\det J| = r$

```python
def polar_jac(r, theta):
    return np.array([[np.cos(theta), -r*np.sin(theta)],
                     [np.sin(theta),  r*np.cos(theta)]])
```

#### `polar_jac(r, theta)` —— 极坐标变换的 Jacobian

`return np.array([[cosθ, -r sinθ], [sinθ, r cosθ]])`

**做什么**：$x = r\cos\theta$、$y = r\sin\theta$，对 $(r, \theta)$ 求偏导。行列式：$\cos\theta \cdot r\cos\theta - (-r\sin\theta)\sin\theta = r(\cos^2\theta + \sin^2\theta) = r$。输出 `|det J| = r`。
**操作**：第 1 列是 $\partial(x,y)/\partial r = (\cos\theta, \sin\theta)$，第 2 列是 $\partial(x,y)/\partial\theta = (-r\sin\theta, r\cos\theta)$；`np.linalg.det` 算出 $r$。
**输入**：`r`、`theta`（极坐标）。
**输出**：$2 \times 2$ Jacobian。
**可调参数**：`theta` 不影响行列式（$\cos^2+\sin^2$ 恒 1）；`r` 直接决定缩放。$r=0$ 时行列式为 0——极点在极坐标下"退化"（无数个 $\theta$ 对应同一个点）。
**对应数学**：主线"极坐标 $|\det J| = r$，所以二重积分换极坐标乘 $r$"。这是 Jacobian 行列式最经典的教科书应用。

## 改个数字试试：把行列式推向零

### 实验 1：退化变换——$\det J = 0$

```python
J0 = np.array([[1.0, 2.0], [2.0, 4.0]])   # 第二行 = 2×第一行，秩 1
print(f"det = {np.linalg.det(J0):.2e}   变换把小正方形压成面积 0 的图形")
```

输出：

```text
det = 0.00e+00   变换把小正方形压成面积 0 的图形
```

两行成比例 → 行列式为零 → 变换把整个平面压成一条线 → 面积信息彻底丢失。这就是主线警告的"$\det J = 0$ 坍缩"。在深度学习语境里，如果一个变换层在某个区域 $\det J = 0$，说明它在那里**不可逆**——归一化流（主线 DL 桥接）设计网络层时最忌讳的就是这一点。

### 实验 2：拉伸 vs 剪切——同样面积，不同形状

```python
A_stretch = np.array([[2.0, 0.0], [0.0, 3.0]])   # 拉伸
A_shear   = np.array([[2.0, 1.0], [0.0, 3.0]])   # 拉伸 + 剪切
print(f"纯拉伸 det = {np.linalg.det(A_stretch):.1f}   拉伸+剪切 det = {np.linalg.det(A_shear):.1f}")
```

输出：

```text
纯拉伸 det = 6.0   拉伸+剪切 det = 6.0
```

两个矩阵行列式都是 6——**剪切不改面积**（斜着推平行四边形的顶角，底乘高不变）。这解释了"为什么行列式公式里有那个交叉项"：$ad - bc$ 里的 $bc$ 正是剪切造成的"倾斜修正"。面积缩放只取决于"两个方向的拉伸量"（对角元的乘积），与剪切无关——但方向（特征向量）完全不同。

## 边界声明：这套代码能做什么，不能做什么

1. **行列式只对方阵有意义。** `np.linalg.det` 对非方阵会直接报错（或行为未定义）。§3.6 已强调：$m \neq n$ 的矩形 Jacobian 没有行列式，也就没有"面积缩放"。"Jacobian" 与 "Jacobian 行列式"是两个对象——前者总存在（$m\times n$ 矩阵），后者只对 $n=m$ 定义。
2. **$\det J$ 是局部的。** 它对非线性变换只在"点附近"描述缩放；把 `eps` 放大，面积比值会偏离 $|\det J|$（除非变换本身线性）。代码实验 2 里的拉伸/剪切都是线性变换，所以处处精确；真实网络层是非线性的，$\det J$ 必须逐点计算。
3. **符号与坐标系约定绑定。** "正 = 保持定向"依赖于你用的是右手系。反手系会让所有符号翻转，但"翻不翻面"这个事实本身不变。别把"符号为正/负"当成绝对事实——那是约定下的相对判断。
4. **$\det J = 0$ 是危险信号，不是错误。** 它标出变换退化（不可逆）的位置。在优化里，$\nabla f = 0$（梯度为零）与"局部雅可比行列式退化"是同族现象；在归一化流里，$\det J = 0$ 的区域会导致密度公式分母爆炸（除以零）。读懂这个信号，比躲开它更重要。
