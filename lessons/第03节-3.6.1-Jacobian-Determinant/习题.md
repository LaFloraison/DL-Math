# 习题：Jacobian 行列式

## 一、概念检验

### 题 1.1（填空）

Jacobian 行列式 $|\det J|$ 表示变换在一点附近的____缩放倍数；$\det J$ 的符号为正表示____定向，为负表示____定向；$\det J = 0$ 表示变换在这一点____。

**解答**：面积/体积；保持；反转；坍缩（退化、不可逆）。
**思路点拨**：三个信号各司其职——绝对值管"放大几倍"，符号管"翻没翻面"，零管"压扁/不可逆"。注意"翻面"与"负号"的对应依赖坐标系约定（§3.6.1 边界声明），但"面积缩放"是无条件的。答错"符号管面积大小"的同学混淆了 $|\det J|$ 与 $\det J$——**大小看绝对值，方向看符号**。

### 题 1.2（选择）

教材例题变换 $u = 2x + y$，$v = x - y$ 的 Jacobian 行列式是（ ），它说明变换（ ）

A. $3$，保持定向且面积放大 3 倍
B. $-3$，反转定向且面积放大 3 倍
C. $-3$，反转定向且面积缩小 3 倍
D. $-5$，保持定向且面积放大 5 倍

**解答**：B。
**思路点拨**：$\det J = 2\times(-1) - 1\times1 = -3$。符号负 → 翻面；绝对值 3 → 放大 3 倍。选 C 的同学把"负号"误读成"缩小"——**负号只代表方向翻转，缩放倍数永远看绝对值 $|−3|=3$**。选 D 的十字相乘算错（$ad - bc$ 是 $-2-1$，不是 $2-1$ 或其它）。手算一遍教材原题，这个符号问题就不会再错。

### 题 1.3（简答）

为什么 Jacobian 行列式只在 $m = n$ 时存在？矩形 Jacobian（$m \neq n$）还能不能谈"面积缩放"？

**解答**：行列式按定义只对方阵（$n \times n$）存在——它度量"$n$ 个列向量张成的 $n$ 维超平行体的有向体积"，这要求恰好有 $n$ 个 $n$ 维列向量。$m \neq n$ 时（如 $2 \times 3$），"体积"没有明确定义：输入 3 维、输出 2 维的变换把体积压到 2 维，缩放系数不是一个数能描述的。此时 Jacobian 依然存在（它是合法的线性图纸），但"面积缩放"与"翻面"这两个行列式承载的信息不再有定义。
**思路点拨**：这道题考主线边界声明。能说出"行列式需要 $n$ 个 $n$ 维向量张成有向体积"就抓到了本质。这也是为什么归一化流等需要"体积缩放"的场景**强制要求变换是方阵（可逆、同维）**——不是设计偏好，是行列式的定义前提。

## 二、计算实践

### 题 2.1（手算）

设变换 $(u,v) = (x^2 + y,\; y^2)$。

(a) 写出 Jacobian 矩阵。
(b) 在点 $(1, 2)$ 处，$\det J$ 是多少？说明它在该点的几何含义。
(c) 在点 $(0, 1)$ 处，$\det J$ 是多少？这个点发生了什么？

**解答**：
(a) $J = \begin{pmatrix} 2x & 1 \\ 0 & 2y \end{pmatrix}$。
(b) 代入 $(1,2)$：$J = \begin{pmatrix}2&1\\0&4\end{pmatrix}$，$\det J = 8 > 0$——在该点保持定向，微小面积放大 8 倍。
(c) 代入 $(0,1)$：$J = \begin{pmatrix}0&1\\0&2\end{pmatrix}$，$\det J = 0$——**变换在此点退化**：$\partial u/\partial x = 0$ 且 $\partial v/\partial x = 0$，说明 $x$ 方向的变化被完全吞掉，平面被压成线，局部不可逆。
**思路点拨**：(c) 是最有价值的观察——同一个变换，不同点行列式不同（$(1,2)$ 处 8、$(0,1)$ 处 0），这正是"$\det J$ 是局部的"的体现。$x=0$ 时 $u = x^2 + y$ 对 $x$ 的导数恰好为零（抛物线在顶点处水平），两个输出都不依赖 $x$——"一个输入维度被消灭"。可以把这个结论与 §3.5 梯度消失的直觉对照。

### 题 2.2（代码验证）

验证"$|\det J|$ = 面积缩放倍数"：对变换 $(u,v) = (3x + y,\; x + 2y)$，用小正方形数值量面积，与 $|\det J|$ 对比。

```python
import numpy as np
J = np.array([[3.0, 1.0], [1.0, 2.0]])
detJ = np.linalg.det(J)
eps = 0.01
corners = np.array([[-1,-1],[1,-1],[1,1],[-1,1]]) * eps
T = lambda x, y: np.array([3.0*x + y, x + 2.0*y])
pts = np.array([T(*c) for c in corners])
def area(p):
    x, y = p[:,0], p[:,1]
    return 0.5*abs(np.sum(x*np.roll(y,-1) - np.roll(x,-1)*y))
print(f"|det J| = {abs(detJ):.2f}   数值面积比值 = {area(pts)/((2*eps)**2):.2f}")
```

**解答**：$\det J = 3\times2 - 1\times1 = 5$，$|\det J| = 5$；数值面积比值 $= 5.00$。两者完全一致。
**思路点拨**：这是《代码.md》实验的直接复用——用真实点量面积，独立验证行列式。把变换改成非线性的（如 $(x^2+y, xy)$），把 `eps` 改小（`0.01` → `0.001`），比值会逼近该点的 $|\det J|$——因为非线性变换的缩放随位置变化，微元越小越接近局部值。

## 三、DL 延伸

### 题 3.1

归一化流用可逆变换 $\mathbf{x} = \mathbf{f}(\mathbf{z})$ 把标准正态变成复杂分布，密度公式为 $p_x(\mathbf{x}) = p_z(\mathbf{f}^{-1}(\mathbf{x})) \cdot |\det J_{\mathbf{f}^{-1}}|$。请解释：为什么密度公式里必须出现 $|\det J|$？如果某层的 $|\det J|$ 恰好在某区域为 0，会发生什么？

**解答**：因为变换会**重新分配概率体积**。标准正态在 $\mathbf{z}$ 空间均匀铺开；经过 $\mathbf{f}$，某些区域的体积被压缩（$\det J$ 大）、某些被摊开（$\det J$ 小），但总概率必须守恒——所以密度要乘一个"体积补偿因子" $|\det J|$：体积缩小处密度变浓，体积放大处密度变稀。若某区域 $|\det J| = 0$，该处变换把体积压成零、密度公式除以零/趋于无穷——模型在该区域退化且不可逆，反向（从 $\mathbf{x}$ 回到 $\mathbf{z}$）也无法进行。因此归一化流设计层时会**强制所有地方 $|\det J| \neq 0$**。
**思路点拨**：这道题把"$|\det J|$ = 面积缩放"落到概率守恒。能说出"体积缩小处密度变浓"这个补偿逻辑，就真正理解了为什么生成模型需要行列式。这也是为什么归一化流偏爱三角 Jacobian 的层——$\det J$ 好算（主对角元之积），且容易控制不为零。

### 题 3.2

梯度沿网络反向传播的连乘是 $\frac{\partial L}{\partial a_1} = \frac{\partial L}{\partial a_L} \prod_{\ell=2}^{L} J_\ell$。已知 $\det(AB) = \det A \cdot \det B$（行列式乘法定理）。请用本节知识说明：如何用各层 Jacobian 的行列式判断"梯度体积"是放大还是缩小？

**解答**：取连乘的行列式：$\det\left(\prod J_\ell\right) = \prod |\det J_\ell|$（对非奇异 Jacobian）。若各层 $|\det J_\ell| > 1$，连乘的"梯度体积"指数放大 → 对应梯度爆炸；若 $< 1$，指数缩小 → 对应梯度消失。这个"乘积行列式"是各层 Jacobian 谱效应的一个标量指标——它不捕捉方向（特征向量）信息，但给出了"梯度整体缩放"的粗略判断。
**思路点拨**：严格说，梯度消失/爆炸由 Jacobian 的**谱半径**（最大特征值）而非行列式决定，行列式是"体积平均缩放"，可能掩盖方向差异。但理解"$\det$ 的乘法 = 缩放的乘法"这个结构，能让你一眼看懂为什么深度网络梯度会呈指数级放大/缩小。能指出"行列式是标量近似、谱半径才是严格判据"，就说明你读懂了本节与 §3.5 的连接层次。
