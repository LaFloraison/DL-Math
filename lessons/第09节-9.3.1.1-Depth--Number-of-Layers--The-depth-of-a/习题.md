# 习题：深度的三座山

## 第一组：概念检验

**1. 排序题**：把下面的特征按"深度网络学到的层级"从低到高排序：
- (A) 完整的猫脸（物体级）
- (B) 图像中某条特定朝向的边缘
- (C) 由纹理组合而成的"毛发感"区域
- (D) 眼睛与耳朵之间的相对位置（部件级）

**2. 多选题**：教材指出深度带来的挑战有哪些？
- (A) 更易过拟合
- (B) 训练困难（梯度消失/爆炸）
- (C) 计算开销更大
- (D) 一定让准确率更高

**3. 简答**：为什么"深层网络在训练集上的误差比浅层还高"是可能的？它说明问题出在哪个环节，而不是什么环节？

### 解答与思路点拨

**1. 正确顺序：B → C → D → A。** 初始层学边缘（B），中间层把边缘组合成纹理/部件群（C），再组合成部件间的结构（D），最后到物体级整体（A）。这正是教材"初始层→中间层→深层"的三级抽象，也是 §9.3.1.1 历史中休伯尔-维泽尔的"简单细胞→复杂细胞→超复杂细胞"在人工网络里的对应。

**2. (A)(B)(C)。** (D) 是误区——深度不保证更高准确率，收益有上限、甚至超过临界点会退化（§9.3 历史的 56 层问题）。教材明确列的三大挑战是：过拟合、训练困难、计算开销。

**3.** 训练误差高 = 网络在训练集上都没学好 = **优化（收敛）失败**，不是泛化/过拟合问题（过拟合的特征是训练误差低、测试误差高）。它说明问题出在"梯度能否传到底层"（深度导致梯度消失），而非"数据不够"或"学习率没调好"。§9.3 历史里何恺明 2015 年正是凭"训练误差随深度反升"这条证据，把退化问题诊断成结构/收敛问题。

## 第二组：计算实践

**4. 手算**：一个深度网络各隐藏层宽度为 [784, 256, 128, 64, 10]（不含输入输出）。计算：总隐藏层数、第 1→2 层（784→256）的连接数、第 3→4 层（128→64）的连接数。

**5. 代码验证**：用本节的 `train_mlp`，在 XOR 簇数据上分别训练 深度 1（宽 5）、深度 2（宽 10），打印准确率与边界翻转数，验证"深度 1 分不开、深度 2 分得开"的结论；再把深度 2 的宽度改成 3，看看发生了什么。

### 解答与思路点拨

**4.** 隐藏层数 = 4（784, 256, 128, 64 四层）。784→256：`784×256 = 200,704` 个连接（+256 个偏置）。128→64：`128×64 = 8,192` 个连接。注意连接数随"宽度乘积"爆炸——这为 §9.3.1.2"宽度决定参数量"埋下伏笔。

**5.** 代码（直接复用本节脚本）：

```python
X, y = make_xor_clusters()
for depth, width in ((1,5),(2,10),(2,3)):
    Ws, bs, acc = train_mlp(X, y, depth, width)
    print(f"深度{depth} 宽{width}: 准确率={acc:.3f}, 翻转={boundary_crossings(Ws, bs)}")
```

```text
深度1 宽5 : 准确率=0.726, 翻转=31
深度2 宽10: 准确率=1.000, 翻转=67
深度2 宽3 : 准确率=0.463, 翻转=0
```

三行并排：深度 1 分不开（简单边界）；深度 2 宽 10 分得开（精细边界）；深度 2 但宽 3 又分不开了——**深度够了但宽度不足**。这就同时验证了"深度提升表达力"与"宽度也卡能力"两个命题。

## 第三组：DL 延伸

**6. 场景判断**：你用一个 20 层网络在图像分类上只得了 70% 准确率，同事建议"再加 20 层"来提升。请用 §9.3.1.1 的框架指出：这个建议在什么前提下才可能有效？它忽略了哪些"深度挑战"？

**7. 思考题**：§9.3.1.1 说深层网络"先学边缘、再学形状、最后学物体"。请猜测：如果用随机的、从未见过的图像训练同样的网络，它还能学到"边缘→形状→物体"的层级吗？这个观察对"层级式特征学习到底学的是什么"有何启发？

### 解答与思路点拨

**6.** 加层要有效，需要同时满足：数据量足够（否则过拟合）、有跳连或合适的激活（否则梯度消失训不动）、硬件算力够（否则训练时间不可接受）。同事的建议只考虑了"深度收益"的一半，漏掉了教材的三座山。现实做法：先确认 70% 是"没训好"（训练误差高→加层无益，先解决优化）还是"泛化差"（测试误差高→加正则/数据），再决定是否加深。

**7.** 如果训练数据是随机的，网络学不到有意义的"物体"层级——因为"物体"这个概念存在于数据的统计结构里，不在网络结构里。这个观察说明：**层级式特征学习学的是数据里真实存在的层级结构，网络只提供了"逐级组合"的模板。** 结构与数据配合，层级才成立——这也呼应了 §9.3"拓扑与数据共同决定性能"。随机数据 + 深层结构 = 网络依然能"过拟合"随机图案，但学不到可迁移的层级——一个关于深度局限性的清醒认识。
