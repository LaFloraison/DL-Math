# 代码：用深度重演 Figure 9.2——决策边界怎么随层数变精细

主线里我们说：深度决定**层级式特征学习**，Figure 9.2 用三幅决策边界图证明了它——浅层边界简单粗糙，深层边界精细复杂。本节代码把这个实验**亲手做一遍**：

- 数据集：**XOR 簇**——四堆点云分布在四个角（左上/右下是一类，右上/左下是另一类），需要一条**弯曲**的决策边界才能分开；
- 网络：手写的通用多层感知机（ReLU 激活、全批量梯度下降、MSE），唯一变化的是**隐藏层数**；
- 度量：训练准确率 + **决策边界复杂度**（在一张 60×60 网格上数"类别翻转次数"）。

三组深度，对照着看——这就是 Figure 9.2 的数据版。

---

## 层一：完整脚本

```python
import numpy as np

def make_xor_clusters(n=1000, seed=0):
    """四角簇：(-1,-1)/(1,1) 是类0，(-1,1)/(1,-1) 是类1——需要弯曲边界。"""
    rng = np.random.default_rng(seed)
    centers = np.array([[-1,-1],[1,1],[-1,1],[1,-1]])
    idx = rng.integers(0, 4, n)
    X = centers[idx] + rng.standard_normal((n,2))*0.3
    y = (idx>=2).astype(float).reshape(-1,1)
    return X, y

def relu(z):
    return np.maximum(z, 0)

def train_mlp(X, y, depth, width, eta=0.2, steps=15000, seed=4):
    """通用 MLP：depth 个隐藏层、每层 width 个 ReLU 单元。返回权重与准确率。"""
    n = len(X)
    rng = np.random.default_rng(seed)
    sizes = [2] + [width]*depth + [1]
    Ws = [rng.standard_normal((sizes[i],sizes[i+1]))*np.sqrt(2.0/sizes[i])
          for i in range(len(sizes)-1)]                  # He 初始化
    bs = [np.zeros((1,sizes[i+1])) for i in range(len(sizes)-1)]
    for _ in range(steps):                               # 全批量梯度下降
        zs, hs = [], [X]
        for W, b in zip(Ws, bs):
            z = hs[-1]@W + b; zs.append(z); hs.append(relu(z))
        yh = hs[-1]; dy = yh - y
        deltas = [None]*len(Ws)
        deltas[-1] = dy*(zs[-1]>0).astype(float)         # 输出层误差
        for l in range(len(Ws)-2,-1,-1):                 # 逐层反向传播
            deltas[l] = (deltas[l+1]@Ws[l+1].T)*(zs[l]>0).astype(float)
        for l in range(len(Ws)):                         # 梯度下降更新
            Ws[l] -= eta/n*hs[l].T@deltas[l]
            bs[l] -= eta/n*np.sum(deltas[l], axis=0, keepdims=True)
    return Ws, bs, ((yh>0.5)==(y>0.5)).mean()

def boundary_crossings(Ws, bs):
    """决策边界复杂度：60×60 网格上水平相邻格子类别翻转的次数。"""
    gx, gy = np.meshgrid(np.linspace(-2.5,2.5,60), np.linspace(-2.5,2.5,60))
    pts = np.column_stack([gx.ravel(), gy.ravel()])
    h = pts
    for W, b in zip(Ws, bs): h = relu(h@W + b)
    lab = (h.ravel()>0.5).reshape(60,60)
    return sum(1 for r in range(60) for c in range(59) if lab[r,c]!=lab[r,c+1])

X, y = make_xor_clusters()
for depth, width in ((1,5),(2,10),(3,10)):               # 三组深度（对应 Figure 9.2）
    Ws, bs, acc = train_mlp(X, y, depth, width)
    print(f"深度 {depth} 隐藏层 x 宽 {width}: "
          f"准确率={acc:.3f}, 边界翻转={boundary_crossings(Ws, bs)}")
```

运行输出（Python 3.11 + NumPy）：

```text
深度 1 隐藏层 x 宽 5 : 准确率=0.726, 边界翻转=31
深度 2 隐藏层 x 宽 10: 准确率=1.000, 边界翻转=67
深度 3 隐藏层 x 宽 10: 准确率=1.000, 边界翻转=65
```

读这组输出，Figure 9.2 的三层图在你眼前复活：

- **深度 1（浅层）**：准确率只有 **0.726**——单层隐藏层画不出一条足够弯曲的边界，XOR 簇分不干净；边界翻转只有 31 次，**边界简单**。
- **深度 2（中层）**：准确率跳到 **1.000**——两层逐级组合，画出了能把四角簇完全分开的边界；翻转涨到 67，**边界精细了一倍**。
- **深度 3（深层）**：准确率 **1.000**，翻转 65——与深度 2 能力相当，说明这个任务两三层就到顶了（深度收益递减）。

**深度改变了决策边界的表达能力**：不是权重更聪明了，是层数给了网络"逐级组合"的级数。下面逐行拆解。

## 层二：分步逐函数拆解

### 步骤 1：`make_xor_clusters` —— 需要弯曲边界的四角簇

```python
def make_xor_clusters(n=1000, seed=0):
    rng = np.random.default_rng(seed)
    centers = np.array([[-1,-1],[1,1],[-1,1],[1,-1]])
    idx = rng.integers(0, 4, n)
    X = centers[idx] + rng.standard_normal((n,2))*0.3
    y = (idx>=2).astype(float).reshape(-1,1)
    return X, y
```

**做什么**：生成四堆二维点云。`(-1,-1)` 和 `(1,1)` 是类 0，`(-1,1)` 和 `(1,-1)` 是类 1。
**操作**：`rng.integers(0,4,n)` 随机给每点挑一个簇心，`standard_normal*0.3` 加高斯噪声（簇的半径）。`(idx>=2)` 把簇下标 0,1 标成 0，2,3 标成 1。
**输入**：`n`（样本数）、`seed`（随机种子）。
**输出**：`X`(n×2) 坐标、`y`(n×1) 标签。
**可调参数**：`n` 越大数据越密；`0.3` 是簇的噪声——改成 `0.05` 让四簇几乎不相交（任何深度都好分），改成 `0.8` 让簇混在一起（谁都难分）。噪声正是"任务难度"旋钮。
**对应数学**：异或 (XOR) 逻辑在二维平面的几何实现——**没有一条直线能分开四角簇**，必须用弯曲边界。这保证了"浅层 vs 深层"的差异能被显出来。

---

### 步骤 2：`relu` —— 激活函数

```python
def relu(z):
    return np.maximum(z, 0)
```

**做什么**：ReLU——负值归零，正值原样。
**操作**：`np.maximum(z, 0)` 逐元素取 `max(z, 0)`。导数在 `z>0` 时为 1、`z<=0` 时为 0（弱导数）。
**输入**：任意形状数组 `z`。
**输出**：同形状数组。
**可调参数**：无。换成 `tanh`/`sigmoid` 会导致梯度消失（§9.3 代码已演示），所以深度实验用 ReLU——这也是教材 Figure 9.2 用 ReLU 的原因。
**对应数学**：非线性的来源。深度网络"逐级组合"的能力，全靠每层之间的非线性把线性变换叠出弯曲。

### 步骤 3：`train_mlp` —— 通用深度的 MLP 训练

```python
def train_mlp(X, y, depth, width, eta=0.2, steps=15000, seed=4):
    n = len(X)
    rng = np.random.default_rng(seed)
    sizes = [2] + [width]*depth + [1]
    Ws = [rng.standard_normal((sizes[i],sizes[i+1]))*np.sqrt(2.0/sizes[i])
          for i in range(len(sizes)-1)]
    bs = [np.zeros((1,sizes[i+1])) for i in range(len(sizes)-1)]
    for _ in range(steps):
        zs, hs = [], [X]
        for W, b in zip(Ws, bs):
            z = hs[-1]@W + b; zs.append(z); hs.append(relu(z))
        yh = hs[-1]; dy = yh - y
        deltas = [None]*len(Ws)
        deltas[-1] = dy*(zs[-1]>0).astype(float)
        for l in range(len(Ws)-2,-1,-1):
            deltas[l] = (deltas[l+1]@Ws[l+1].T)*(zs[l]>0).astype(float)
        for l in range(len(Ws)):
            Ws[l] -= eta/n*hs[l].T@deltas[l]
            bs[l] -= eta/n*np.sum(deltas[l], axis=0, keepdims=True)
    return Ws, bs, ((yh>0.5)==(y>0.5)).mean()
```

#### `train_mlp` —— 任意深度的前向 + 反向 + 更新

**做什么**：用全批量梯度下降训练一个 `depth` 层隐藏的 MLP。`sizes = [2, width, ..., width, 1]`——输入 2 维、`depth` 个隐藏层、输出 1 维。
**操作**：
- **初始化**：`Ws[l]` 用 He 初始化 `randn*sqrt(2/fan_in)`——让信号方差在层间守恒（§9.3 代码的"增益≈1"）。`bs[l]` 全零。
- **前向**：`zs` 存每层的线性输出 `z`，`hs` 存每层的激活 `h`（`hs[0]=X`，`hs[l+1]=relu(zs[l])`）。
- **反向**：`deltas[-1] = dy*(zs[-1]>0)` 是输出层误差乘 ReLU 导数；`deltas[l] = (deltas[l+1]@Ws[l+1].T)*(zs[l]>0)` 把误差逐层传回——**这就是反向传播**。
- **更新**：`Ws[l] -= eta/n * hs[l].T @ deltas[l]`——除以 `n` 是因为全批量梯度是 1000 个样本的**和**，除以 n 转成**平均**，梯度下降才稳定。
**输入**：`X`(n×2)、`y`(n×1)、`depth`（隐藏层数）、`width`（每层宽度）、`eta`、`steps`、`seed`。
**输出**：`(Ws, bs, acc)`——权重列表、偏置列表、训练准确率。
**可调参数**：
- `depth` 是本实验的主角：1/2/3 对应 Figure 9.2 的三层图。每加一层，`sizes` 就多一段 `[width]`，反向传播就多一次矩阵乘——梯度传播的距离加一。
- `width` 是每层的宽度：实验里浅层 5、深层 10。**注意**：`width` 和 `depth` 都能加参数，但加的"东西"不同——加宽是一次性提高单层容量，加深是增加"逐级组合"的级数（§9.3.1.2 会单独讲宽度）。
- `eta` 学习率：0.2 是调试出来的稳定值；太大会发散（NaN），太小收敛慢。
- `steps` 训练步数、`seed` 初始化种子——固定 `seed=4` 保证结果可复现。
**对应数学**：$h_l = \mathrm{ReLU}(W_l h_{l-1}+b_l)$ 的叠乘；`depth` 每加一，函数类的复杂度上限就高一档。**层数——即函数的嵌套层数——是表达复杂度的直接控制旋钮。**

### 步骤 4：`boundary_crossings` —— 量化决策边界的复杂度

```python
def boundary_crossings(Ws, bs):
    gx, gy = np.meshgrid(np.linspace(-2.5,2.5,60), np.linspace(-2.5,2.5,60))
    pts = np.column_stack([gx.ravel(), gy.ravel()])
    h = pts
    for W, b in zip(Ws, bs): h = relu(h@W + b)
    lab = (h.ravel()>0.5).reshape(60,60)
    return sum(1 for r in range(60) for c in range(59) if lab[r,c]!=lab[r,c+1])
```

#### `boundary_crossings` —— 数一数边界"弯了几次"

**做什么**：在整个输入平面铺一张 60×60 的网格，把每个格子喂进网络看它预测哪一类，然后数水平相邻格子之间**类别翻转**的次数——翻转越多，决策边界越精细、越弯曲。
**操作**：`meshgrid` 生成网格坐标，`column_stack` 展平成点列，前向传播得到每点输出，`(h>0.5)` 变成 0/1 标签矩阵，双循环数相邻翻转。
**输入**：`Ws, bs`（训练好的权重）。
**输出**：整数，边界翻转次数。
**可调参数**：网格密度 60 可改——越密翻转数越大（因为采样更细），所以它衡量的是**相对复杂度**：同密度下浅层 31 vs 深层 67，才是有效对比。`[-2.5,2.5]` 是采样范围，要盖住四簇。
**对应数学**：这是"决策边界复杂程度"的数值代理——对应 Figure 9.2 里"简单粗糙 vs 精细复杂"的视觉差异。深度网络能画出更弯曲的边界，正是它层级式特征组合能力的直接体现。

## 改个数字试试：宽度也会卡住能力

### 实验：同是深度 2，宽度 3 vs 宽度 10

```python
for depth, width in ((2,3),(2,10)):
    Ws, bs, acc = train_mlp(X, y, depth, width)
    print(f"深度 {depth} 隐藏层 x 宽 {width}: 准确率={acc:.3f}, 边界翻转={boundary_crossings(Ws, bs)}")
```

```text
深度 2 隐藏层 x 宽 3 : 准确率=0.463, 边界翻转=0
深度 2 隐藏层 x 宽 10: 准确率=1.000, 边界翻转=67
```

同一份深度 2，宽度 3 的网络**连 XOR 簇都分不开**（0.463 = 预测全给多数类），宽度 10 却轻松 100%。这说明：**深度提供"组合的级数"，宽度提供"每一级组合的资源"——两者缺一不可**。窄到极点的层，即便深度足够，也画不出需要多单元协同的弯曲边界。这个"宽度旋钮"是 §9.3.1.2 的主角，在这里先感受它的威力。

## 边界声明：这套代码能做什么，不能做什么

1. **它证明了"深度提升边界表达力"，不是"深度永远更好"**。任务简单到深度 2 就饱和，深度 6 毫无收益；而在现实任务里，深度超过某点甚至会**退化**（§9.3 历史的 56 层问题）。深度的收益，是被任务复杂度和正则化共同圈定的。
2. **它用的优化器是最朴素的**（全批量 GD）。真实世界的深层网络用 mini-batch + Adam + 归一化才能训得动。特别地，宽度很大的深层网络（如 3×50）用本脚本的朴素优化器会收敛失败——这本身就是"深度挑战"（§9.3 三座山）的活标本，而 §9.3.2 的跳连正是为治它而生的。
3. **准确率 1.000 是训练集上的**。深网络参数多，更容易**过拟合**训练集而在测试集上退化——教材提醒的"深层网络更易过拟合，尤其数据不足时"。要测泛化，必须划出验证集。
