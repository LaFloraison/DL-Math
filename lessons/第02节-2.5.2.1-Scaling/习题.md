# 习题：缩放

## 第一组：概念检验

**1.1（单选）** 缩放矩阵 $S = \begin{bmatrix} 3 & 0 \\ 0 & 3 \end{bmatrix}$，向量 $\mathbf{v} = \begin{bmatrix} 2 \\ 1 \end{bmatrix}$。$S\mathbf{v}$ 等于：
- A. $\begin{bmatrix} 6 \\ 3 \end{bmatrix}$
- B. $\begin{bmatrix} 3 \\ 1 \end{bmatrix}$
- C. $\begin{bmatrix} 6 \\ 1 \end{bmatrix}$
- D. $\begin{bmatrix} 2 \\ 3 \end{bmatrix}$

**1.2（判断并说明）** "如果 $\det(S) < 0$，那么经过 $S$ 作用后，图形的面积变成了负数。" 这句话对吗？

**1.3（填空）** $S = \begin{bmatrix} 2 & 0 \\ 0 & 4 \end{bmatrix}$，则 $\det(S) =$ ____；一个边长为 3 的正方形经过 $S$ 后面积变为 ____；若把 $S$ 改成 $\begin{bmatrix} 2 & 0 \\ 0 & 0 \end{bmatrix}$，则 $\det(S) =$ ____，这个变换 ____（可逆 / 不可逆）。

## 第二组：计算实践

**2.1（手算）** 令 $\mathbf{v} = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$，$S = \begin{bmatrix} 2 & 0 \\ 0 & 4 \end{bmatrix}$。求 $S\mathbf{v}$、$\|\mathbf{v}\|$、$\|S\mathbf{v}\|$，并指出：模长缩放倍数是否恰好等于 $\det(S)$？为什么？

**2.2（手算 + 代码验证）** 单位正方形四个角为 $(0,0), (1,0), (1,1), (0,1)$。分别用均匀缩放 $c = 2$ 与非均匀缩放 $S = \begin{bmatrix} 2 & 0 \\ 0 & 0.5 \end{bmatrix}$ 作用它。用 NumPy 计算两种情况下"变形后面积 ÷ 原面积"，验证它分别等于 $c^2$ 与 $|\det(S)|$。

**2.3（代码 + 分析）** 对 $S = \begin{bmatrix} 2 & 0 \\ 0 & 3 \end{bmatrix}$，取 $\mathbf{v} = [1, 0]$、$[0, 1]$、$[1, 1]$，分别计算"模长缩放倍数"（$\|S\mathbf{v}\| / \|\mathbf{v}\|$）。比较三个倍数，说明：非均匀缩放下，长度缩放倍数为什么依赖于方向？

## 第三组：DL 延伸

**3.1（场景判断）** 批归一化里，对激活向量 $\mathbf{x} \in \mathbb{R}^d$ 做 $\hat{x}_i = (x_i - \mu_i)/\sqrt{\sigma_i^2 + \epsilon}$ 之后还要乘 $\gamma_i$。为什么必须用逐维缩放（对角矩阵），而不能用一个标量同时缩放所有通道？写出这个逐维缩放的对角矩阵形式。

**3.2（场景分析）** 梯度爆炸时常用梯度裁剪：若 $\|\mathbf{g}\| > c$，令 $\mathbf{g} \leftarrow \mathbf{g} \cdot \frac{c}{\|\mathbf{g}\|}$。这是一个均匀缩放。**为什么这里用均匀缩放，而不是把某个特别大的分量单独压小（逐维缩放）？** 提示：想想梯度向量的"方向"在优化里意味着什么。

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：$s_x = s_y = 3$ 是均匀缩放，$S\mathbf{v} = 3\begin{bmatrix}2\\1\end{bmatrix} = \begin{bmatrix}6\\3\end{bmatrix}$。
- **点拨**：这是"均匀缩放 = 标量乘法"的直球。**为什么有人会选 C 或 D**：他们记住了"横坐标乘第一个对角元、纵坐标乘第二个对角元"，却忘了两个对角元相等时它就是标量乘法——把两个分量错位相乘（`[3*2, 1*3]` 之类）源于没把矩阵乘法写成"行乘列"。

**1.2 这句话是错的。**
- **思路**：面积是 $\det$ 的**绝对值**倍数 $|\det(S)|$，永远非负。$\det(S) < 0$（比如 $s_x$、$s_y$ 一正一负）只表示**取向翻转**——图形像从镜子背面看，面积数值仍乘 $|\det(S)|$。
- **点拨**：行列式的符号给"方向（取向）"，行列式的绝对值给"面积（体积）"。两者是不同信息。**为什么有人会答对错参半**：他们把"$\det < 0$"直接理解成"面积变小/变负"，而忽略了取绝对值。

**1.3 答案：$\det(S) = 2 \times 4 = 8$；面积变为 $3^2 \times 8 = 72$；$\det = 0$；不可逆。**
- **思路**：正方形边长 3、面积 9；$S$ 使面积 ×$\det = 8$，得 72。改成 `diag(2, 0)` 后 $\det = 0$——纵轴被压扁成一条线，两个不同点可被送到同一个点，不可逆。
- **点拨**：$\det = 0$ 是"信息销毁"的代数指纹。记住三个判据：$\det \ne 0$ 可逆、$|\det|$ 是面积倍数、$\det < 0$ 是镜像。

### 第二组

**2.1**
$S\mathbf{v} = \begin{bmatrix}2 \times 2 \\ 4 \times 3\end{bmatrix} = \begin{bmatrix}4 \\ 12\end{bmatrix}$。
$\|\mathbf{v}\| = \sqrt{2^2 + 3^2} = \sqrt{13}$，$\|S\mathbf{v}\| = \sqrt{4^2 + 12^2} = \sqrt{160} = 4\sqrt{10}$。
模长倍数 $= \|S\mathbf{v}\|/\|\mathbf{v}\| = \sqrt{160/13} \approx 3.51$，而 $\det(S) = 8$。**两者不等。**

```python
import numpy as np
v = np.array([2.0, 3.0])
S = np.array([[2.0, 0.0], [0.0, 4.0]])
print(np.linalg.norm(v), np.linalg.norm(S @ v))           # 3.6055  12.6491
print(np.linalg.norm(S @ v) / np.linalg.norm(v))          # 3.5082
print(np.linalg.det(S))                                    # 8.0
```

- **思路**：$\det$ 量的是**面积（二维体积）**的倍数，不是**长度**的倍数。非均匀缩放下，长度缩放倍数甚至依赖方向（见 2.3）。只有当 $s_x = s_y = s$（均匀）时，长度倍数 $=|s|$、面积倍数 $= s^2$，两者才都简单。
- **点拨**：**为什么有人会觉得模长倍数应等于 8**：他们把"$\det$ 是面积倍数"误推广成"对任何几何量都乘 8"。行列式只承诺"体积"这一件事。

**2.2**
均匀 $c=2$：角变为 $(0,0),(2,0),(2,2),(0,2)$，面积 $4$，倍数 $4 = 2^2$。
非均匀 `diag(2, 0.5)`：角变为 $(0,0),(2,0),(1,0.5),(0,0.5)$，面积 $1$，倍数 $1 = |2 \times 0.5|$。

```python
import numpy as np
sq = np.array([[0., 0.], [1., 0.], [1., 1.], [0., 1.]])
def area(poly):                       # 鞋带公式：多边形面积
    x, y = poly[:, 0], poly[:, 1]
    return 0.5 * abs(np.dot(x, np.roll(y, 1)) - np.dot(y, np.roll(x, 1)))

Su = np.array([[2., 0.], [0., 2.]])
Sn = np.array([[2., 0.], [0., 0.5]])
print(area(sq @ Su.T) / area(sq))     # 4.0 = det(Su) = 2*2
print(area(sq @ Sn.T) / area(sq))     # 1.0 = |det(Sn)| = |2*0.5|
```

- **思路**：`sq @ Sn.T` 把矩阵同时作用到每一行（一个角）。鞋带公式量面积，比值即面积倍数。均匀缩放面积倍数 $= c^2$；非均匀 $= |s_x s_y|$。
- **点拨**：非均匀缩放面积倍数可以是 1（拉伸与压扁互相"抵销"），但形状已经被扭曲了——面积不变 ≠ 形状不变，这是这道题想让你看见的。

**2.3**
- $\mathbf{v} = [1, 0]$：$\|v\|=1$，$Sv = [2, 0]$，倍数 $2$。
- $\mathbf{v} = [0, 1]$：$\|v\|=1$，$Sv = [0, 3]$，倍数 $3$。
- $\mathbf{v} = [1, 1]$：$\|v\|=\sqrt2$，$Sv = [2, 3]$，$\|Sv\|=\sqrt{13}$，倍数 $\sqrt{13}/\sqrt2 \approx 2.55$。

```python
import numpy as np
S = np.array([[2.0, 0.0], [0.0, 3.0]])
for v in ([1., 0.], [0., 1.], [1., 1.]):
    v = np.array(v)
    print(np.linalg.norm(S @ v) / np.linalg.norm(v))
# 2.0  3.0  2.5495...
```

- **思路**：非均匀缩放下，每个方向被拉伸的程度不同——沿横轴的向量被乘 2，沿纵轴的乘 3，斜着的向量介于两者之间。长度缩放倍数不是一个常数，它随方向在 $2$ 与 $3$ 之间变化。均匀缩放没有这个现象：所有方向倍数恒为 $|c|$。
- **点拨**：这解释了为什么"缩放一个向量到目标长度"在非均匀变换下没有单一答案——方向必须先被确定。这也预告了特征值（§2.5.3）：那些"长度倍数恰为一个定值"的特殊方向，就是特征向量。

### 第三组

**3.1**
- **答案**：因为各通道的方差 $\sigma_i^2$ 不同。归一化目标是把**每个**通道都调到单位方差——若用一个标量 $c$，所有通道都乘同一个 $c$，各通道的方差保持原有比例，无法同时变为 1。必须逐维缩放，对角矩阵为
$$\Gamma = \begin{bmatrix} \gamma_1 & & \\ & \ddots & \\ & & \gamma_d \end{bmatrix} = \operatorname{diag}(\gamma_1, \ldots, \gamma_d), \qquad x_i^{\text{out}} = \gamma_i \hat{x}_i + \beta_i$$
- **点拨**：**为什么有人会想用标量**：均匀缩放太顺手了，忘了"方差不同"这个事实。非均匀缩放的必要性正来自数据本身的异质性——每个通道是独立的物理量，量纲和尺度都不同。

**3.2**
- **答案**：梯度向量 $\mathbf{g}$ 的**方向**决定参数往哪个方向走（最速下降方向），大小只决定走多远。逐维缩放会改变各分量的相对比例，从而改变梯度的方向——你会"往错的方向走一小步"，优化路径被搅乱。均匀缩放只改大小、不改方向，所以安全。
- **点拨**：这是"均匀缩放保方向、非均匀缩放改方向"在优化里的直接后果。**为什么有人会想逐维缩放**：觉得"哪个分量大就压哪个"很自然，却忽略了梯度下降依赖方向。顺带一提：这正是 $\eta$（学习率）必须是标量的原因——它也只能是均匀缩放。

## 一个"为什么有人会答错"的提醒

最容易错的三处：一是把"面积倍数"误推广成"任何量的倍数"（$\det$ 只承诺体积）；二是忘记 $\det < 0$ 时面积仍取绝对值，符号只表示镜像；三是用均匀缩放的直觉去处理非均匀缩放——均匀缩放是"一个数管所有方向"，非均匀缩放是"每个方向各管各的"，长度倍数因此依赖于方向。
