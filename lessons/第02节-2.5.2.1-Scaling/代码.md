# 代码：用 NumPy 亲手拖动相片的一角

主线里我们用手和眼睛感受了缩放：向量乘标量是均匀缩放，对角矩阵是逐维缩放，行列式是面积倍数。这一节把这三句话变成代码——用 `ndarray * 标量` 做均匀缩放，用 `S @ v` 做非均匀缩放，用 `square @ S.T` 让一组点整体变形，再用 `np.linalg.det` 验证"面积倍数 = 行列式"。

脚本只依赖 NumPy，约 40 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：向量、矩阵、行列式全在这里

# ---- ① 均匀缩放：向量 × 标量 ----
v = np.array([3.0, 4.0])                 # 原向量，形状 (2,)
c = 2.0                                  # 缩放因子
vc = c * v                               # 每个分量乘 c：方向不变，长度 ×c
print("v          =", v)
print(f"{c} * v   = {vc}  模长 = {np.linalg.norm(vc):.1f}")

# ---- ② 负标量：方向掉头 ----
vn = (-1.0) * v                          # 乘以 -1：长度不变，方向反转
print("-1 * v    =", vn, "  模长 =", np.linalg.norm(vn))

# ---- ③ 缩放矩阵：非均匀缩放 ----
S = np.array([[3.0, 0.0],                # 横轴 ×3
              [0.0, 2.0]])               # 纵轴 ×2，形状 (2, 2)
print("S          =\n", S)
print("S @ v      =", S @ v)             # 逐维缩放：[3*3, 4*2] = [9, 8]

# ---- ④ 作用在一组点上：正方形 → 矩形 ----
square = np.array([[0., 0.], [2., 0.], [2., 2.], [0., 2.]])  # 4 个角，形状 (4, 2)
rect = square @ S.T                      # 每行是一个点，被 S 左乘：x×3, y×2
print("square     =\n", square)
print("square @ S.T =\n", rect)

# ---- ⑤ 面积验证：det(S) = 面积缩放因子 ----
det_S = np.linalg.det(S)                 # 行列式：3*2 = 6
ratio = (6.0 * 4.0) / (2.0 * 2.0)        # 缩放后面积 / 原面积
print(f"det(S)  = {det_S:.1f}   面积倍数 = {ratio:.1f}")

# ---- ⑥ 退化：某个缩放因子为 0 → 行列式为 0，不可逆 ----
S0 = np.array([[0.0, 0.0], [0.0, 1.0]])  # 横轴被压扁：x 分量一律变成 0
print(f"det(S0) = {np.linalg.det(S0):.1f}   S0 @ v = {S0 @ v}")
```

## 层二：分步逐函数拆解

### 步骤 1：向量 × 标量——均匀缩放

```python
v  = np.array([3.0, 4.0])
vc = 2.0 * v
```

#### `np.array(list)` —— 把列表变成向量

**做什么**：把 Python 列表 `[3.0, 4.0]` 转成 NumPy 的 `ndarray`。
**操作**：按顺序把元素存入连续内存，推断出类型 `float64`。
**输入**：一维列表 `[3.0, 4.0]`——两个浮点数。
**输出**：形状 `(2,)` 的数组。`(2,)` 表示"一维、2 个元素"；`v[0]=3.0`、`v[1]=4.0` 是向量的两个分量。
**可调参数**：
- 长度任意：`np.array([1.0, 2.0, 3.0])` 是三维向量。
- 传 `dtype`：`np.array([3, 4], dtype=np.float32)` 强制单精度，省一半内存——深度学习里常用。
- 嵌套列表 `np.array([[1.0],[2.0]])` 得到形状 `(2, 1)` 的"列向量"——它是二维数组，语义与 `(2,)` 不同（§2.3.4.3 细讲）。本课统一用 `(n,)`。

#### `ndarray * 标量` —— 逐元素缩放（广播）

**做什么**：把向量的每个分量乘以同一个标量——这就是主线里的标量缩放 $c\mathbf{v}$。
**操作**：NumPy 的广播 (broadcasting) 机制把标量 `2.0` 自动"铺开"到每个元素：`[3*2, 4*2] = [6., 8.]`。
**输入**：`v`（形状 `(2,)`）与标量 `2.0`。
**输出**：`[6., 8.]`，形状 `(2,)`。
**可调参数**：`c` 可以是任意实数——
- `c > 1`：拉伸，长度变为原来的 $c$ 倍（`2.0 * v` 模长从 5 变成 10）
- `0 < c < 1`：压缩（如 `0.5 * v` 模长变 2.5）
- `c = 1`：原样不动
- `c < 0`：反向（见步骤 2）
- `c = 0`：全部压到原点（零向量），信息全部丢失
- 标量还能与任意形状的数组相乘：`2.0 * np.ones((2, 2))` 对矩阵每个元素×2，`c * batch` 对一批 `(32, 784)` 的数据整体缩放。这就是"均匀缩放"的代码形态——一个数，作用到所有地方。
**对应数学**：主线公式 $c\begin{bmatrix}x\\y\end{bmatrix}=\begin{bmatrix}cx\\cy\end{bmatrix}$。

#### `np.linalg.norm(vc)` —— 向量模长（复习）

**做什么**：算 $\|\mathbf{v}\|_2 = \sqrt{\sum_i v_i^2}$。
**输入**：形状 `(2,)` 的数组。
**输出**：标量。`norm([6.,8.]) = 10.0`，正好是原模长 5 的两倍——**均匀缩放把模长也乘了 $c$**，这是它"均匀"的证据。
**可调参数**：第二参数 `ord` 换范数类型（`ord=1` 曼哈顿、`ord=np.inf` 最大值范数），本节用默认的 2-范数。

### 步骤 2：负标量——方向掉头

```python
vn = (-1.0) * v
```

#### `ndarray * 标量(-1)` —— 缩放因子为负

**做什么**：主线的关键边界——**标量为负时，方向改变**。
**操作**：`(-1.0) * [3., 4.] = [-3., -4.]`。
**输入**：`v`（`(2,)`）与 `-1.0`。
**输出**：`[-3., -4.]`，形状 `(2,)`，模长仍是 5——长度没变，方向反转了 180°。
**可调参数**：任意负数都行。`-2.0 * v = [-6., -8.]`：长度翻倍且方向反转——"反向 + 缩放"两件事合在一起。若只要反转方向不改变长度，就用 `-1.0`。
**对应数学**：教材"不改变方向，除非标量为负"。负缩放 = 关于原点的镜像 + 缩放。

### 步骤 3：缩放矩阵 × 向量——非均匀缩放

```python
S = np.array([[3.0, 0.0],
              [0.0, 2.0]])
S @ v
```

#### `np.array(嵌套列表)` —— 构造 2×2 矩阵

**做什么**：把嵌套列表转成二维数组。
**输入**：`[[3.0, 0.0], [0.0, 2.0]]`——外层 2 个"行"，每行 2 个"列"。
**输出**：形状 `(2, 2)` 的数组：`S[0,0]=3.0`（横轴因子 $s_x$）、`S[1,1]=2.0`（纵轴因子 $s_y$）、其余为 0。**形状 `(2, 2)` 的含义：第一维是行（输出维度），第二维是列（输入维度）**——`S` 把 2 维输入映射到 2 维输出。
**可调参数**：把某个对角元改成 0 就是退化（步骤 6）；改成负数是反向；改非对角元（如 `S[0,1]`）就不再是缩放，变成别的变换了——那是 §2.5.2 后面的内容。

#### `@`（矩阵乘法）—— `S @ v`

**做什么**：矩阵乘向量，一次算完两个维度的缩放。
**操作**：`@` 做"行 × 列"内积求和：
$$(S\mathbf{v})_1 = 3.0 \times 3 + 0.0 \times 4 = 9, \qquad (S\mathbf{v})_2 = 0.0 \times 3 + 2.0 \times 4 = 8$$
非对角元全是 0，所以每个输出分量只被**自己的**对角元决定——这就是缩放矩阵"不混合维度"的代数形式。
**输入**：`S` 形状 `(2, 2)`，`v` 形状 `(2,)`。**形状对齐规则**：`(2, 2) @ (2,)` 合法的条件是左边的列数 = 右边的元素数，结果形状是 `(2,)`。
**输出**：`[9., 8.]`，形状 `(2,)`。对比 `2.0 * v = [6., 8.]`——均匀缩放两边乘同一个数，非均匀缩放两边乘不同的数。
**可调参数**：`@` 是通用矩阵乘法，能接更高维：`(2, 2) @ (2, 5)` 会把 5 个向量一起缩放（每一列一个向量）；`S @ (3, 2, 4)` 张量乘法规则更复杂，初学先掌握 `(n,n) @ (n,)` 与 `(m,n) @ (n,)`。
**对应数学**：主线定义块 $S\mathbf{v} = \begin{bmatrix}s_x x \\ s_y y\end{bmatrix}$。

### 步骤 4：让一组点整体变形——正方形 → 矩形

```python
square = np.array([[0., 0.], [2., 0.], [2., 2.], [0., 2.]])
rect   = square @ S.T
```

#### `ndarray @ ndarray` —— `square @ S.T`（行向量约定）

**做什么**：把 `S` 同时作用到 4 个点（正方形的 4 个角）上，一次性得到变形后的 4 个角。
**操作**：`square` 的**每一行是一个点** `(x, y)`。要让每个点被 `S` 左乘（$S\mathbf{r}$），需要把它写成**列**再乘——对整块数组来说，公式是：
$$\text{rect} = \text{square} \cdot S^{\top} \quad\Longleftrightarrow\quad (\text{rect})^{\top} = S \cdot (\text{square})^{\top}$$
`S.T` 是转置。本例 `S` 是对角矩阵，`S.T == S`，所以数值上 `square @ S` 结果一样；写 `S.T` 是为了坚持正确的通用约定——**"对每一行应用矩阵 $M$"，右乘的是 $M^\top$**。换成非对称矩阵（§2.5.2 后续）时这个约定就派上用场了。
**输入**：`square` 形状 `(4, 2)`（4 个点、每点 2 个坐标），`S.T` 形状 `(2, 2)`。形状对齐：`(4, 2) @ (2, 2)` 合法，结果 `(4, 2)`。
**输出**：`[[0,0],[6,0],[6,4],[0,4]]`，形状 `(4, 2)`——4 个新点，正是主线里那个 $6 \times 4$ 矩形的 4 个角。
**可调参数**：行数任意。`(1000, 2) @ S.T` 一次变形 1000 个点——这是把缩放"批量"应用到数据集的标准姿势，深度学习里每批样本 `(batch, d)` 就是这么被处理的。
**对应数学**：主线第三步"正方形 $(0,0),(2,0),(2,2),(0,2)$ 被 $S$ 作用变成矩形 $(0,0),(6,0),(6,4),(0,4)$"。

### 步骤 5：行列式 = 面积倍数

```python
det_S = np.linalg.det(S)
ratio = (6.0 * 4.0) / (2.0 * 2.0)
```

#### `np.linalg.det(S)` —— 矩阵的行列式

**做什么**：算 $2 \times 2$ 矩阵的行列式。
**操作**：内部做 $\det = a d - b c$（对 `[[a,b],[c,d]]`）。缩放矩阵 `[[3,0],[0,2]]`：$3 \times 2 - 0 \times 0 = 6$。
**输入**：形状 `(2, 2)` 的方阵。
**输出**：标量 `6.0`。
**可调参数**：
- 对任意 `(n, n)` 方阵都适用，不必是缩放矩阵——它度量"这个变换把体积放大了多少倍"。
- 大数据集算行列式数值不稳时，可换 `np.linalg.slogdet`（返回符号 + 对数行列式，避免上溢/下溢）。
**对应数学**：主线公式 $\det(S) = s_x s_y$，$|\det|$ 是面积倍数。代码里 `det_S = 6.0` 与手算面积倍数 `ratio = 24/4 = 6.0` 完全一致——**面积倍数就是行列式**，一次验证坐实。

### 步骤 6：退化——某个缩放因子为 0

```python
S0 = np.array([[0.0, 0.0], [0.0, 1.0]])
```

#### `np.array` 造退化矩阵

**做什么**：演示主线的边界声明——**$s_x = 0$ 时面积消失、变换不可逆**。
**操作**：`S0 @ v = [0*3 + 0*4, 0*3 + 1*4] = [0., 4.]`：任何点的横坐标都被压成 0，整个平面塌到纵轴上的一条线。
**输出**：`det(S0) = 0.0`——面积倍数 0；`S0 @ v = [0., 4.]`。
**为什么不可逆**：点 `(1, 2)` 和点 `(3, 2)` 都被送到 `(0, 2)`——两个不同的点变成同一个点，从结果无法判断原点是哪一个。信息在 $s_x = 0$ 这一步被永久销毁了。
**对应数学**：主线"$\det(S) = 0$，二维图形塌成一条线，变换不可逆"。

## 边界声明：这套代码能做什么，不能做什么

1. **只演示了"沿坐标轴"的缩放。** 这里所有矩阵都是对角矩阵——它们只在 $x$、$y$ 轴方向动手。如果你把非对角元设为非零（比如让 `S[0,1] = 1`），得到的是剪切 (shear) 之类的变换，不再是我们这节定义的缩放。想沿任意方向拉伸，需要"旋转 × 缩放 × 旋转回来"，那是 §2.5.2 后续变换（以及 §2.5.3 特征分解）的内容。
2. **`(n,)` 与 `(n, 1)` 的坑。** `S @ np.array([3., 4.])`（形状 `(2,)`）得到 `[9., 8.]`；`S @ np.array([[3.],[4.]])`（形状 `(2, 1)`）得到形状 `(2, 1)` 的结果。数值一样，形状不同，后续广播、拼接行为全不一样。PyTorch 里 `(n,)` 与 `(n, 1)` 同样是初学者最常踩的形状陷阱。
3. **行列式为 0 的变换没有"撤销"按钮。** 只要某个缩放因子是 0，信息就永久丢失；反推回原图是不可能的。训练中若发现某层输出"退化"（所有样本输出相同），大概率是有某个维度被压成了 0。
4. **`np.linalg.det` 度量的是面积倍数，不是方向信息。** 当 `det < 0` 时（$s_x$、$s_y$ 一正一负），面积倍数取绝对值，负号表示取向翻转（镜像）。这个脚本里没有演示镜像，因为它不改变面积的数值——留给你在习题里亲手验证。
