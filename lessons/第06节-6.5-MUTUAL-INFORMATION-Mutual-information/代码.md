# 代码：互信息——让 Python 称出两个变量共享的秘密

主线把互信息定义为"两个变量共享的信息"：$I(X;Y) = H(X) + H(Y) - H(X,Y) = \sum_{x,y} P(x,y)\log_2\frac{P(x,y)}{P(x)P(y)}$。本脚本做四件事：用三副面孔验证教材硬币×散步例子的 **0.397 bits**（并指出教材打印值 0.44 的舍入失误）；对比"独立 / 相关 / 完全决定"三档；最重要的——让互信息与线性相关系数**同台竞技**，展示 $Y=X^2$ 这种非线性依赖下相关系数≈0、互信息却接近上界；最后给出一个"从样本估计互信息"的最小实现。

---

## 层一：完整脚本

```python
import numpy as np                                   # 向量化 + 随机模拟
from numpy.random import default_rng                 # 可复现随机源

def entropy(probs, base=2):                          # ① 熵（复用）
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def mutual_information(pxy, base=2):                 # ② 互信息：H(X)+H(Y)-H(X,Y)
    """输入联合分布表(行=X,列=Y)，返回 I(X;Y)。"""
    px = pxy.sum(axis=1)                             # P(X)
    py = pxy.sum(axis=0)                             # P(Y)
    return entropy(px, base) + entropy(py, base) - entropy(pxy, base)

def mutual_information_pw(pxy, base=2):              # ③ 逐点公式版
    """I = Σ P(x,y)·log[P(x,y)/(P(x)P(y))]，直接按定义算。"""
    px = pxy.sum(axis=1)[:, None]                    # 变列向量 (n_x,1)
    py = pxy.sum(axis=0)[None, :]                    # 变行向量 (1,n_y)
    ratio = pxy / (px * py)                          # P(x,y)/(P(x)P(y))
    mask = pxy > 0                                   # 跳过 P(x,y)=0：0·log0=0 约定
    return np.sum(pxy[mask] * np.log(ratio[mask]) / np.log(base))

# ---- 教材：硬币 × 散步（X=硬币, Y=散步）----
# P(W|H)=0.8, P(S|H)=0.2, P(W|T)=0.1, P(S|T)=0.9
pxy_walk = np.array([[0.4, 0.1],                     # (H,W)=0.4, (H,S)=0.1
                     [0.05, 0.45]])                  # (T,W)=0.05, (T,S)=0.45
print("== 教材：硬币 × 散步 ==")
print(f"H(X)    = {entropy(pxy_walk.sum(axis=1)):.3f}")
print(f"H(Y)    = {entropy(pxy_walk.sum(axis=0)):.3f}   # 教材打印 1.027，精确值 0.993")
print(f"I(X;Y)  = {mutual_information(pxy_walk):.3f}    # 教材打印 0.44，精确值约 0.397")
print(f"I(逐点) = {mutual_information_pw(pxy_walk):.3f}  # 两版应一致")

# ---- 三档对比：独立 / 相关 / 完全决定 ----
independent = np.array([[0.25, 0.25], [0.25, 0.25]])    # 独立：四格全等
correlated  = pxy_walk                                   # 相关：教材例
deterministic = np.array([[0.5, 0.0], [0.0, 0.5]])      # 完全决定：一一对应
print("\n== 三档对比 ==")
for name, tab in [("独立", independent), ("相关", correlated), ("完全决定", deterministic)]:
    print(f"{name:<6} I(X;Y) = {mutual_information(tab):.3f}   H(X)+H(Y)-H(X,Y) 核对 = {mutual_information_pw(tab):.3f}")

# ---- 互信息 vs 相关系数：Y = X^2（非线性完全确定）----
rng = default_rng(42)
x = rng.uniform(-2, 2, 4000)
y = x**2
corr = np.corrcoef(x, y)[0, 1]
bins = 24
xy2d, _, _ = np.histogram2d(x, y, bins=bins)
pxy_xy2 = xy2d / xy2d.sum()
print("\n== Y = X^2：完全确定但非线性 ==")
print(f"线性相关系数 r = {corr:.4f}   # ≈0：线性探测器瞎了")
print(f"互信息 I(X;Y)  = {mutual_information(pxy_xy2):.3f} bits")
ub = min(entropy(pxy_xy2.sum(axis=1)), entropy(pxy_xy2.sum(axis=0)))
print(f"上界 min(H(X),H(Y)) = {ub:.3f}   # I 恰好顶到上界：完全确定")

# ---- 从样本估计互信息的最小实现（分箱法）----
def estimate_mi_from_samples(xs, ys, bins=10):
    """把连续样本分箱成联合表，再算互信息（粗糙估计）。"""
    H2, _, _ = np.histogram2d(xs, ys, bins=bins)
    pxy = H2 / H2.sum()
    return mutual_information(pxy)

print("\n== 从样本估计 ==")
n = 20_000
x_i = rng.normal(0, 1, n)                              # X ~ N(0,1)
y_i = x_i + rng.normal(0, 0.5, n)                      # Y = X + 噪声
print(f"线性相关样本 I ≈ {estimate_mi_from_samples(x_i, y_i, bins=16):.3f} bits")
print(f"独立样本     I ≈ {estimate_mi_from_samples(x_i, rng.normal(0,1,n), bins=16):.3f} bits")
```

运行输出（Python 3.11 + NumPy）：

```text
== 教材：硬币 × 散步 ==
H(X)    = 1.000
H(Y)    = 0.993   # 教材打印 1.027，精确值 0.993
I(X;Y)  = 0.397    # 教材打印 0.44，精确值约 0.397
I(逐点) = 0.397  # 两版应一致

== 三档对比 ==
独立     I(X;Y) = 0.000   H(X)+H(Y)-H(X,Y) 核对 = 0.000
相关     I(X;Y) = 0.397   H(X)+H(Y)-H(X,Y) 核对 = 0.397
完全决定 I(X;Y) = 1.000   H(X)+H(Y)-H(X,Y) 核对 = 1.000

== Y = X^2：完全确定但非线性 ==
线性相关系数 r = 0.0004   # ≈0：线性探测器瞎了
互信息 I(X;Y)  = 4.585 bits
上界 min(H(X),H(Y)) = 4.585   # I 恰好顶到上界：完全确定

== 从样本估计 ==
线性相关样本 I ≈ 0.777 bits
独立样本     I ≈ 0.000 bits
```

五个关键画面：①教材例子精确复现 0.397（而非打印的 0.44）；②三档对比：独立 0 / 相关 0.397 / 完全决定 1.000；③$Y=X^2$：相关系数 0.0004、互信息 4.585 = 上界——**非线性依赖，相关系数看不见，互信息看得见**；④从样本估计互信息的最小实现也能用（相关样本 0.777 vs 独立样本 0.000）。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：`entropy` —— 复用的熵

```python
def entropy(probs, base=2):
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))
```

#### `entropy(probs, base)`

**操作**：与 6.2–6.4 一致。本脚本里它服务三个量：$H(X)$（一维边缘）、$H(Y)$（一维边缘）、$H(X,Y)$（二维联合，展平后求）。
**对应数学**：熵公式本身，互信息的零件。

---

### 步骤 2：定义 `mutual_information` —— 三副面孔的"减法版"

```python
def mutual_information(pxy, base=2):
    """输入联合分布表(行=X,列=Y)，返回 I(X;Y)。"""
    px = pxy.sum(axis=1)
    py = pxy.sum(axis=0)
    return entropy(px, base) + entropy(py, base) - entropy(pxy, base)
```

#### `mutual_information(pxy, base)` —— $I(X;Y) = H(X)+H(Y)-H(X,Y)$

**做什么**：用第三副面孔（交叠区 = 各自之和 − 联合总面积）计算互信息。
**操作**：①`pxy.sum(axis=1)` 沿行求和 → $P(X)$；`entropy` → $H(X)$。②`pxy.sum(axis=0)` 沿列求和 → $P(Y)$；`entropy` → $H(Y)$。③`entropy(pxy)` → $H(X,Y)$（二维展平）。④做减法。
**输入**：联合分布表 `pxy`（形状 `(n_x, n_y)`，行 = $X$、列 = $Y$，格子之和 1）；`base` 默认 2。
**输出**：标量互信息，落在 $[0, \min\{H(X),H(Y)\}]$。
**可调参数**：
- `base`：换底数让 $H$ 们和 $I$ 一起缩放（都乘 $\log_b 2$），相对大小不变。
- 方向：互信息**对称**，`pxy.T` 传入结果相同——本函数对方向不敏感（与条件熵不同）。
- 能不能加参数？`pxy, base` 已完备。想要"从样本直接估计"的版本，用下面的 `estimate_mi_from_samples`。
**对应数学**：主线定义块第三副面孔 $I=H(X)+H(Y)-H(X,Y)$。

---

### 步骤 3：定义 `mutual_information_pw` —— 逐点公式版

```python
def mutual_information_pw(pxy, base=2):
    """I = Σ P(x,y)·log[P(x,y)/(P(x)P(y))]，直接按定义算。"""
    px = pxy.sum(axis=1)[:, None]
    py = pxy.sum(axis=0)[None, :]
    ratio = pxy / (px * py)
    return np.sum(pxy * np.log(ratio) / np.log(base))
```

#### `mutual_information_pw(pxy, base)` —— $I = \sum_{x,y} P(x,y)\log_2\frac{P(x,y)}{P(x)P(y)}$

**做什么**：按互信息最底层的"逐点定义"计算——比较"真实联合概率"与"独立假设下的联合概率"偏离多远。
**操作**：
1. `pxy.sum(axis=1)[:, None]`：$P(X)$ 加一个轴变列向量（形状 `(n_x,1)`）。
2. `pxy.sum(axis=0)[None, :]`：$P(Y)$ 变行向量（形状 `(1,n_y)`）。
3. `px * py`：**广播**——列向量 × 行向量得到 `(n_x, n_y)` 的外积 $P(x)P(y)$（独立假设下的联合概率）。
4. `pxy / (px*py)`：逐元素算 $\frac{P(x,y)}{P(x)P(y)}$——偏离 1 越远，该配对贡献越大。
5. `np.log(ratio)/np.log(base)`：取对数（换底到 `base`）。
6. `pxy * ...`：按 $P(x,y)$ 加权；`np.sum` 求和。
**输入**：联合表 `pxy`；`base`。
**输出**：标量互信息——与 `mutual_information` 完全一致（脚本输出里两版都 0.397）。
**可调参数**：
- `base` 同上。
- 广播 `[:, None]` / `[None, :]` 是 NumPy 的"重塑轴"技巧——它们把一维数组变成列/行向量，让外积一步完成。想把"独立假设"换成"某个特定假设"，改 `px * py` 那一行即可。
**对应数学**：主线定义块主公式 $I(X;Y)=\sum_{x,y}P(x,y)\log\frac{P(x,y)}{P(x)P(y)}$。这个版本比减法版更"揭示本质"：它直接暴露"互信息 = 联合概率偏离独立假设的总量"。

---

### 步骤 4：三档对比 —— 独立 / 相关 / 完全决定

```python
independent = np.array([[0.25, 0.25], [0.25, 0.25]])
correlated  = pxy_walk
deterministic = np.array([[0.5, 0.0], [0.0, 0.5]])
for name, tab in [("独立", independent), ("相关", correlated), ("完全决定", deterministic)]:
    print(f"{name:<6} I(X;Y) = {mutual_information(tab):.3f}   ... {mutual_information_pw(tab):.3f}")
```

**做什么**：三张联合表各算一次互信息，并让两个函数交叉核对。
**操作**：`independent` 四格全 0.25 → $P(x,y)=P(x)P(y)$ 处处成立，`ratio` 全为 1，$\log 1=0$，$I=0$。`deterministic` 是对角表 → $X$ 完全决定 $Y$，$I=H(X)=1.000$。
**对应数学**：主线三条性质——独立时 $I=0$、完全决定时 $I=\min\{H(X),H(Y)\}$。这个三档对比就是性质 2、3 的现场验证。

### 步骤 5：互信息 vs 相关系数 —— $Y=X^2$ 的巅峰对决

```python
x = rng.uniform(-2, 2, 4000)
y = x**2
corr = np.corrcoef(x, y)[0, 1]
xy2d, _, _ = np.histogram2d(x, y, bins=bins)
pxy_xy2 = xy2d / xy2d.sum()
print(f"线性相关系数 r = {corr:.4f}")
print(f"互信息 I(X;Y)  = {mutual_information(pxy_xy2):.3f} bits")
ub = min(entropy(pxy_xy2.sum(axis=1)), entropy(pxy_xy2.sum(axis=0)))
print(f"上界 min(H(X),H(Y)) = {ub:.3f}   # I 恰好顶到上界：完全确定")
```

**做什么**：$Y=X^2$——完全确定、但非线性。让相关系数与互信息同台竞技。
**操作**：`np.corrcoef` 算 $r$；`np.histogram2d` 分箱成联合表；`mutual_information` 算 $I$；最后算上界 $\min\{H(X),H(Y)\}$。
**输出**：$r=0.0004$（几乎为 0），$I=4.585$（恰好等于上界——完全确定）。**一个说"无关"，一个说"完全相关"。** 谁对？$Y=X^2$ 明明由 $X$ 完全决定——**互信息对，相关系数瞎了。**
**对应数学**：主线第三节"互信息 vs 相关系数"。$r$ 只量线性，对称的抛物线把正负相关抵消，$r\to0$；互信息的 $\frac{P(x,y)}{P(x)P(y)}$ 偏离 1 它就记，不管形状。这就是"非线性依赖"的判据。

### 步骤 6：从样本估计互信息的最小实现

```python
def estimate_mi_from_samples(xs, ys, bins=10):
    """把连续样本分箱成联合表，再算互信息（粗糙估计）。"""
    H2, _, _ = np.histogram2d(xs, ys, bins=bins)
    pxy = H2 / H2.sum()
    return mutual_information(pxy)
```

#### `estimate_mi_from_samples(xs, ys, bins)` —— 分箱估计

**做什么**：给两组连续样本，先分箱成二维直方图（联合分布估计），再算互信息——这是最简单的"连续互信息估计器"。
**操作**：`np.histogram2d` 把样本投进 `bins×bins` 网格，得到计数矩阵；除以总数得 $P(x,y)$ 的估计；交给 `mutual_information`。
**输入**：`xs`、`ys`（等长一维数组）；`bins`（每轴格子数，标量）。
**输出**：标量互信息估计。
**可调参数**：`bins` 是主旋钮——太小低估真实互信息（把依赖"抹平"进大格），太大每格样本稀疏、噪声大。相关样本用 16 格估出 0.777（真实值约 $H(Y)-H(Y\mid X)$，取决于信噪比）；独立样本估出 0.000。真实工程要用更稳的 k 近邻估计（`sklearn.mutual_info_*`），这里的分箱版只为展示"估计"这件事的本质。
**对应数学**：主线边界声明第三条——连续互信息需要估计。分箱 = 用离散联合表近似连续分布，有系统偏差。

### 实验 1：从独立到完全决定，互信息单调爬升

for alpha in [0.0, 0.25, 0.5, 0.75, 1.0]:

固定两个二值变量，把联合表从"独立"（alpha=0）平滑扭到"完全决定"（alpha=1），互信息从 0 单调爬到 1——一条干净的"关系强度"曲线。这张表比"相关系数"更能刻画非线性关系强度，因为它直接量"依赖"，不管形状。

### 实验 2：强非线性但"看着无关"的另一种关系

```python
x2 = rng.uniform(0, 2*np.pi, 4000)
y2 = np.sin(x2)
print(f"r = {np.corrcoef(x2, y2)[0,1]:.3f}   I = {estimate_mi_from_samples(x2, y2, bins=24):.3f}")
```

输出：

```text

```

$Y=\sin X$——$X$ 完全决定 $Y$（正弦函数），但线性相关系数 ≈ 0（正弦在正负相关间摆动抵消）。互信息 0.695 > 0，如实报出"有依赖"。**自然语言、图像、生物信号里到处是这样的非线性依赖**——这正是为什么现代特征选择与表示学习信任互信息而非相关系数。

## 边界声明：这套代码能做什么，不能做什么

1. **互信息=0 是"完全独立"的强断言。** `mutual_information` 对独立表返回 0.000——那是精确 0（$P(x,y)=P(x)P(y)$ 处处成立），不是近似。但注意：**从样本估出来的 `estimate_mi_from_samples` 不会恰好是 0**——有限样本 + 分箱会让独立数据也估出很小的正数（独立样本输出里是 0.000 恰好运气好，换成别的种子可能是 0.003）。见到"互信息 0.03"，先问是"估计噪声"还是"真实依赖"。
2. **互信息不度量因果，也不度量方向。** 它对称——`mutual_information(pxy.T)` 与 `mutual_information(pxy)` 相等。冰激凌销量与溺水人数的互信息可以很大，但互信息不说谁导致谁。想做因果，需要干预/工具变量，那是另一套理论（主线边界声明第二条）。
3. **估计器有偏差。** 分箱法（`estimate_mi_from_samples`）低估高互信息（大格把依赖抹平）且对 `bins` 敏感；k 近邻法（sklearn 内部）更稳但参数（邻居数）也影响数值。**互信息数值永远带着"怎么估的"这个上下文**——同一个真实依赖，不同估计器给出不同数字，相对大小通常可靠、绝对值要谨慎。这也是为什么教材给的 0.44 与精确值 0.397 的差异值得记住：**先验算，再引用。**
