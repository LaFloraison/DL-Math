# §6.5 互信息 —— 习题

本节主线把"两个变量共享的信息"精确成互信息 $I(X;Y) = H(X)+H(Y)-H(X,Y) = \sum_{x,y}P(x,y)\log_2\frac{P(x,y)}{P(x)P(y)}$，并确立三条性质（对称、非负、范围）。习题分三组：**概念检验** 验证互信息的性质与它和相关系数的分野，**计算实践** 手算教材硬币×散步例子并代码复核、加一个自创场景，**DL 延伸** 把互信息放回 InfoGAN 与信息瓶颈。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：哪个关于互信息的说法正确？

以下说法**正确**的是（ ）。

- A. $I(X;Y)$ 越大，$X$ 越"导致" $Y$
- B. $I(X;Y) = I(Y;X)$ 恒成立
- C. 线性相关系数为 0 的两个变量，$I(X;Y)$ 一定为 0
- D. $I(X;Y)$ 可以大于 $H(X)$ 也可以大于 $H(Y)$

**解答**：B。

B 是对称性，恒成立。A 错——互信息量"依赖"，不量"因果"（冰激凌与溺水反例）；C 错——$Y=X^2$ 时相关系数≈0 但 $I \approx H(Y)$（非线性依赖，互信息看得见）；D 错——$I(X;Y) \le \min\{H(X),H(Y)\}$，不可能同时大于两者。

**思路点拨**：四个选项恰好覆盖互信息的三条性质加一个常见误区。C 是"相关系数 0 ≠ 独立"的翻版——线性探测器和依赖探测器是两回事；D 考范围上界——互信息的天花板是"较弱那个变量的熵"，因为它最多把较弱变量的不确定全部共享掉。记忆锚点：**对称、非负、上界 $\min\{H(X),H(Y)\}$、独立时取 0。**

### 题 2（判断 + 简答）：$I(X;Y)=H(X)$ 意味着什么？

算得 $I(X;Y) = H(X)$。据此能推出什么？它和 $I(X;Y)=0$ 分别对应关系的哪一端？

**解答**：$I(X;Y)=H(X)$ 意味着 $Y$ **完全决定 $X$**——互信息取到上界（$H(X) \le H(Y)$ 时）。因为 $I(X;Y)=H(X)-H(X\mid Y)$，取到 $H(X)$ 当且仅当 $H(X\mid Y)=0$：知道 $Y$ 就完全知道 $X$。这与 $I=0$（完全独立）恰好是关系的两端：**$I=0$ 是"毫无关系"（知道一个对另一个没帮助），$I=\min\{H(X),H(Y)\}$ 是"一个完全决定另一个"。** 中间的任何值对应不同程度的依赖。

**思路点拨**：互信息的两端就是关系的两端。最容易记反的是"上界对应什么"——$I$ 达到上界不是"两个一样复杂"，而是"一个能完全预测另一个"。判别句：**互信息量的是"共享"，达到上界意味着"全部共享"（一个含另一个的信息），达到 0 意味着"毫不共享"。** 这比记公式更本质。

### 题 3（简答）：互信息与条件熵、联合熵的"家族关系"

用 $I(X;Y)$、$H(X)$、$H(Y)$、$H(X,Y)$、$H(X\mid Y)$、$H(Y\mid X)$ 六个量，画出它们之间的等式关系（信息图），并用一句话解释"交叠区"。

**解答**：信息图上，$H(X)$、$H(Y)$ 是两个圆圈，交叠区是 $I(X;Y)$。它们满足：
- $H(X,Y) = H(X) + H(Y) - I(X;Y)$（并集 = 两者之和 − 交叠）
- $H(X) = I(X;Y) + H(X\mid Y)$（左圈 = 交叠 + 左圈独有）
- $H(Y) = I(X;Y) + H(Y\mid X)$（右圈 = 交叠 + 右圈独有）
- $H(X,Y) = I(X;Y) + H(X\mid Y) + H(Y\mid X)$（并集 = 交叠 + 两片独有）

"交叠区" $I(X;Y)$ 就是"共享的信息"：它同时属于 $X$ 的了解也属于 $Y$ 的了解——观测任意一方，都能获得这部分信息。三个量（$H(X)$、$H(Y)$、$H(X,Y)$）两两相减，把整个信息图拼完整。

**思路点拨**：这张"信息图"是整章的地图，务必画进脑子里。六变量只有一个自由度（给定 $I$、$H(X)$、$H(Y)$，其余全部确定）。这个"家族表"也是 6.4→6.5 过渡的关键：信息增益 $\mathrm{IG}(Y;X)$ 就是 $I(X;Y)$——同一件事，决策树视角叫"增益"，图视角叫"交叠"。

## 二、计算实践

### 题 1（教材：硬币 × 散步，完整手算）

$X$：公平硬币（$P(H)=P(T)=0.5$）。$Y$：散步/待着，$P(W\mid H)=0.8$、$P(S\mid H)=0.2$、$P(W\mid T)=0.1$、$P(S\mid T)=0.9$。

(a) 求 $P(Y=W)$、$P(Y=S)$，以及 $H(Y)$。
(b) 求联合熵 $H(X,Y)$ 与 $H(X\mid Y)$。
(c) 求 $I(X;Y)$，用至少两副面孔核对。

**解答**：

(a) $P(W)=0.8\times0.5+0.1\times0.5=0.45$，$P(S)=0.55$。$H(Y)=-(0.45\log_2 0.45+0.55\log_2 0.55)\approx0.45\times1.152+0.55\times0.862=0.518+0.474=0.993$ bits。

(b) 联合表：$P(H,W)=0.4$、$P(H,S)=0.1$、$P(T,W)=0.05$、$P(T,S)=0.45$。$H(X,Y)=-(0.4\log_2 0.4+0.1\log_2 0.1+0.05\log_2 0.05+0.45\log_2 0.45)\approx0.529+0.332+0.216+0.518=1.595$ bits。$H(X\mid Y)=H(X,Y)-H(Y)=1.595-0.993=0.603$ bits。

(c) 面孔一：$I(X;Y)=H(X)-H(X\mid Y)=1-0.603=0.397$ bits。面孔二：$I(X;Y)=H(X)+H(Y)-H(X,Y)=1+0.993-1.595=0.397$ bits。两副面孔一致，$I\approx0.397$ bits。

**思路点拨**：(c) 的双面孔核对是本节最重要的习惯——**互信息必须能用多种方式算出同一个数**，对不上就说明哪步错了。注意教材打印值（0.44）是舍入失误，精确值约 0.397（主线有专门的诚实交代）。$0.397$ 落在 $[0, \min\{1, 0.993\}]$ 里：硬币对散步有依赖，但非完全决定——正面也可能待着、反面也可能散步。

**代码验证**：
```python
import numpy as np
def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -np.sum(p * np.log(p) / np.log(2))
pxy = np.array([[0.4, 0.1], [0.05, 0.45]])
hx = entropy(pxy.sum(axis=1)); hy = entropy(pxy.sum(axis=0)); hxy = entropy(pxy)
print(hx + hy - hxy)          # 0.397
print(hx - (hxy - hy))        # 0.397，另一副面孔
```

### 题 2（自创场景：广告 × 购买，用互信息说话）

$X$：是否看广告（看 60%、不看 40%）；$Y$：是否购买（买/不买）。看广告者买 30%、不看者买 5%。

(a) 求 $I(X;Y)$。
(b) 把这个互信息与"广告的因果效果"区分开——如果 5% 的不看者也买了，可能是"广告起了作用"还是"买的人本来就爱买"？互信息能回答吗？

**解答**：

(a) 联合表：$P(\text{看,买})=0.6\times0.3=0.18$、$P(\text{看,不买})=0.42$、$P(\text{不看,买})=0.4\times0.05=0.02$、$P(\text{不看,不买})=0.38$。$P(\text{买})=0.18+0.02=0.20$，$P(\text{不买})=0.80$。$H(Y)=-(0.2\log_2 0.2+0.8\log_2 0.8)\approx0.464+0.258=0.722$ bits。$H(X)=-(0.6\log_2 0.6+0.4\log_2 0.4)\approx0.6\times0.737+0.4\times1.322=0.442+0.529=0.971$ bits。$H(X,Y)=-(0.18\log_2 0.18+0.42\log_2 0.42+0.02\log_2 0.02+0.38\log_2 0.38)\approx0.446+0.526+0.113+0.531=1.616$ bits。$I=H(X)+H(Y)-H(X,Y)=0.971+0.722-1.616=0.077$ bits。

(b) 互信息 0.077 bits 只说明"看广告与购买共享 0.077 bits 信息"，它**不能**回答"广告是否**导致**购买"。要回答因果，需要知道：如果不看广告，这些人本来会买多少（反事实）——那需要随机对照实验（A/B 测试），把"看广告"当作干预随机分配，才能隔离因果效应。互信息混在一起：它把"广告真的起作用"和"爱买东西的人恰好也爱看广告"两个来源的共享信息都算进去了。**相关性（互信息）≠ 因果，因果需要干预。**

**思路点拨**：(a) 是一次完整的互信息手算演练——注意 $H(X)$ 也要算（互信息和 $H(X)$、$H(Y)$ 三者缺一不可）。(b) 是互信息最常被误用的地方：广告分析师用互信息/相关系数证明"看广告和购买相关"，就宣称"广告有效"——逻辑跳跃。判别句：**互信息描述"现状的依赖"，不描述"干预后的变化"。** 同一个数字，观测研究里是"相关"，随机实验里才能谈"因果"。

### 题 3（从样本估计：为什么估计值不是精确 0？）

生成 1000 个 $X \sim \text{Bernoulli}(0.5)$ 样本，$Y$ 与 $X$ 完全独立（$Y\sim\text{Bernoulli}(0.5)$ 独立抽样）。用分箱法从样本估计 $I(X;Y)$。

(a) 理论上 $I(X;Y)$ 是多少？
(b) 估计值会是精确 0 吗？为什么？

**解答**：

(a) 理论上 $I(X;Y)=0$——两个独立变量，$P(x,y)=P(x)P(y)$ 处处成立，$\log\frac{P(x,y)}{P(x)P(y)}=0$。

(b) **通常不是精确 0。** 有限样本（1000 个）让估计的联合表 $\hat P(x,y)$ 偏离真实 $P(x,y)$：某个格子可能多几个样本、少几个样本，$\hat P(x,y) \ne \hat P(x)\hat P(y)$ 就出现，估计的互信息就是个小正数（如 0.01）。样本越多，估计越接近 0；样本无限，才精确为 0。这是"统计估计误差"，不是"真有依赖"——所以见到 0.03 的互信息，必须先判断它是不是估计噪声（可以多次重采样看波动，或用置换检验给 p 值）。

**思路点拨**：这道题把主线边界声明第三条落到具体。关键区分：**"真实的 $I=0$"（数学事实）与"估计的 $I\approx0.001$"（统计事实）不是一回事。** 判别句：**互信息估计值有一个"噪声底"**——它由样本量、分箱粒度共同决定；低于噪声底的数值不可信。这也是为什么特征选择里常用"排序"而非"绝对阈值"：相对大小可靠，绝对数值要谨慎。

## 三、DL 延伸

### 题 1（InfoGAN：为什么用互信息当"隐码有用吗"的判据）

InfoGAN 在 GAN 损失上加一项 $I(c; G(z,c))$——隐码 $c$ 与生成图像 $G(z,c)$ 的互信息。

(a) 为什么这个量能度量"隐码 $c$ 是否真的控制了生成"？
(b) 如果训练后 $I(c;G(z,c))$ 趋近 0，说明什么？

**解答**：

(a) 如果隐码 $c$（比如"数字类别"）真的决定了生成图像的某个属性，那么**从生成的图像应该能反推出 $c$**——给定 $G(z,c)$，$c$ 的剩余不确定小，$H(c\mid G(z,c))$ 小，$I(c;G(z,c))=H(c)-H(c\mid G(z,c))$ 大。反之，如果 $c$ 只是被生成器无视了（输入不同 $c$，输出几乎一样），那么从图像推不出 $c$，互信息趋近 0。**互信息是"从输出能否恢复隐码"的精确度量**——它是隐码"真的起作用"的判据。

(b) $I(c;G(z,c))\to0$ 说明隐码 $c$ 与生成图像几乎共享不了信息——生成器把 $c$ 当作噪声忽略了，训练出的"可解释隐码"失败了。InfoGAN 通过在训练中最大化这个互信息（用辅助网络 $Q$ 估计 $q(c\mid x)$），强行逼着生成器"承认" $c$ 的控制权，从而让 $c$ 真正有意义。

**思路点拨**：这道题把互信息的"共享"语义翻译成生成模型的"可解释性"。判别句：**隐码可解释 ⇔ 从输出能推断隐码 ⇔ $I(c;\text{输出})$ 大。** 互信息在这里不是算着玩的，它是训练目标的一部分——InfoGAN 用梯度上升直接最大化它。这是"信息论量进损失函数"的经典示范。

### 题 2（信息瓶颈：神经网络在调什么账）

信息瓶颈理论把深度网络的第 $l$ 层表示记为 $T_l$，用互信息刻画训练过程。

(a) 写出信息瓶颈的核心目标（用 $I(T;Y)$ 和 $I(X;T)$），并解释两项各代表什么。
(b) 为什么"最大化 $I(T;Y)$、最小化 $I(X;T)$"对应"挤冗余、留相关"？

**解答**：

(a) 信息瓶颈目标：最大化 $I(T;Y)$（表示 $T$ 与目标 $Y$ 共享的信息）同时最小化 $I(X;T)$（表示 $T$ 与输入 $X$ 共享的信息）。第一项大 = 表示保留了与任务相关的信息；第二项小 = 表示丢弃了与任务无关的输入冗余。

(b) 冗余（irrelevant details）会抬高 $I(X;T)$——表示"记下了"不该记的输入细节；相关性（relevant structure）体现为 $I(T;Y)$——表示"抓住了"决定目标的东西。一个理想的表示：对 $Y$ 有足够信息（$I(T;Y)$ 大）、对 $X$ 不再冗余地大（$I(X;T)$ 小）——这正是"压缩到只剩任务所需信息"。Tishby 的论断"压缩有助于泛化"说：丢掉冗余（压 $I(X;T)$）能防止网络死记训练集，从而泛化得更好。

**思路点拨**：信息瓶颈是互信息进入深度学习的最深刻入口。要点：**网络每层都是一个"互信息调账师"**——既不能把 $I(X;T)$ 压得太狠（会丢掉 $Y$ 所需的信息），也不能留着冗余（会过拟合）。这两个互信息的平衡，就是"表示学习"的信息论表述。注意这是研究前沿，Tishby 的"压缩必泛化"仍有争议——但用互信息看网络，这个视角本身已经深刻地改变了我们描述深度学习的方式。
