# §7.4.1 图直观表示复杂关系 —— 习题

主线论证了"图让结构可见"，《代码.md》把"核心/圈内/桥"三个角色数字化。下面三组习题检验你是否能识别这些结构角色。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：一个节点的"桥"角色最准确的判断依据是？

- A. 度最高
- B. 聚类系数最高
- C. 删掉它后图的连通分量变多
- D. 特征向量数值最大

**解答**：C。

**思路点拨**：桥的定义是"连接多个分量的唯一咽喉"——删掉它图会破碎（分量变多）。A 错：度最高可能是"圈内大 V"，删掉圈内人图未必碎。B 错：聚类最高恰恰说明它深处圈子内部，是"圈内人"而非"桥"。D 与结构无关。常见错选 A——"认识人多"不等于"桥"，冗余度高的节点删掉也不影响连通。

### 题 2（判断）：聚类系数为 0 的节点一定是桥吗？

**解答**：不一定。聚类系数为 0 只说明"朋友之间互不相识"，表示它**可能**在跨界——但一个"只认识一个人"的叶子节点聚类系数也是 0，删掉它对连通性毫无影响，不是桥。桥还要满足"删掉会破碎"。聚类 0 是桥的**必要条件之一**，不是充分条件。

**思路点拨**：这是"必要条件 vs 充分条件"的经典陷阱。判别：桥 = 聚类低（不在圈内）+ 删点破碎（连接不同分量）。常见错误是把"聚类低"直接当成"桥"。

### 题 3（简答）：为什么"特征表"这种表示天然表达不了"谁是核心圈子的灵魂人物"？

**解答**：特征表的每一行是独立实体的属性，行与行之间没有"关系"通道。"灵魂人物"是一个**位置概念**——它依赖"这个人连接着什么、处在什么结构中"，而不是"他有什么属性"。特征表能回答"他最活跃"（按发帖数排序），但回答不了"他最不可或缺"（结构位置）——后者必须从关系结构里读。

**思路点拨**：答题锚点是"位置 vs 属性"。位置概念（核心、桥、边缘）全部依赖连接结构，特征表没有连接维度。加分点：指出"活动量高"和"结构关键"是两种独立性质量。

## 二、计算实践

### 题 1（手算 + NumPy：一条线上的桥）

图 $V=\{1,2,3,4\}$，边 $\{1,2\},\{2,3\},\{3,4\}$（一条链）。

(a) 每个节点的度。
(b) 每个节点的聚类系数。
(c) 谁是桥？删掉它图会碎成几块？

**解答**：

(a) $d(1)=d(4)=1$，$d(2)=d(3)=2$。

(b) 所有节点聚类系数都是 0——没有任何节点有"两个互相认识的朋友"（2 的邻居 1、3 互不相识，等等）。**一条链没有任何三角形。**

(c) 全是桥：删 2，图碎成 {1} 与 {3,4} 两块；删 3 同理。链上的每个中间节点都是"唯一连接两端"的咽喉；端点 1、4 删除也会让剩下的不连通（但只减少一个点，分量从 1 变 2——严格说端点删掉分量也变多，因为 {2,3,4} 仍连通，分量还是 1……等等，删 1 后图是 {2,3,4}，仍连通，分量不变。所以端点不是桥）。

**NumPy 验证**：
```python
import numpy as np
A = np.array([[0,1,0,0],[1,0,1,0],[0,1,0,1],[0,0,1,0]], dtype=float)
# 桥检测：删 v 后分量变多
def ncomp(B):
    n=B.shape[0]; seen=set(); c=0
    for s in range(n):
        if s in seen: continue
        c+=1; st=[s]; seen.add(s)
        while st:
            v=st.pop()
            for u in range(n):
                if B[v,u] and u not in seen: seen.add(u); st.append(u)
    return c
for v in range(4):
    B=A.copy(); B[v,:]=B[:,v]=0
    print(f"删 {v+1} 后分量: {ncomp(B)}")
```
```
删 1 后分量: 1
删 2 后分量: 2
删 3 后分量: 2
删 4 后分量: 1
```

**思路点拨**：这道题的关键是**端点不是桥**——删掉端点，剩下的图仍连通（分量不变）。中间节点 2、3 是桥。常见错误是把端点也算成桥。聚类系数全 0 也提醒你：链没有任何"圈子"，它的全部价值在"传递"，这正是桥的极端形态。

### 题 2（手算：两团一桥的度与聚类）

沿用《代码.md》的图（左团 L1-L2-L3、右团 R1-R2-R3、桥 B 连 L1 和 R1）。手算 B 和 L1 的聚类系数，并解释为什么度相同的节点聚类系数可以天差地别。

**解答**：B 的邻居 {L1, R1}，它们之间无连边 → 聚类 0。L1 的邻居 {L2, L3, B}：L2 与 L3 有边，L2-B、L3-B 无边 → 朋友间边数 1，$\binom{3}{2}=3$，聚类 $=1/3 \approx 0.33$。度上 B=2、L1=3 不同；若换成度相同的例子（如 B 与某个度 2 的 L2）：L2 的邻居 {L1, L3} 有边，聚类 1；B 的邻居 {L1, R1} 无连边，聚类 0——**度相同（都 2），聚类天差地别（1 vs 0）**。因为聚类度量的是"朋友之间是否成圈"，与连接数量无关。

**思路点拨**：聚类与度是**两个正交的结构量**：度数"连多少"，聚类数"连成圈没有"。桥的识别必须同时看两者（以及删点测试）。常见错误是只用一个量下结论。

## 三、DL 延伸

### 题 1（场景设计）：用图做"谁值得重点维护"的用户分析

一个社区平台想找出"最值得运营维护的用户"。请设计：用哪些图结构量（度、聚类、桥）区分三类用户——"圈内大 V""跨界桥""边缘潜水者"，并说明各自对平台的营销价值。

**解答**：**圈内大 V**：度高 + 聚类高（在密集圈子里是核心）——价值是"影响一个紧密社区"，适合社区运营激励。**跨界桥**：聚类低 + 删点破碎（连接不同圈子）——价值是"信息传播的枢纽"，一个桥能把活动从一个圈带到另一个圈，是传播最优投放点，价值常被低估。**边缘潜水者**：度低 + 聚类低（几乎不连接）——短期价值低，但可能是"潜力股"（新用户）或"流失风险"信号。三者对应三种运营策略：激励大 V 维持活跃、定向服务桥节点做传播杠杆、对潜水者做激活。

**思路点拨**：答题锚点是"**三类角色 = 三种价值**"。加分点：指出"桥节点的价值常被属性指标低估"（表格模型只看得见大 V，看不见桥）——这正是"图直观表示"的落地价值。常见错误是只给角色分类，不连到运营决策。

### 题 2（概念连线）：GNN 如何把"直观结构"变成"表示向量"？

主线的直觉（大 V、桥、潜水者）怎么进入 GNN 的学习？请用"邻居聚合"解释：为什么经过几轮消息传递，结构相似的节点会获得相似的表示？

**解答**：GNN 的每轮聚合，让节点的表示 = 自己的特征 + 邻居特征的重组（§7.3）。经过 $K$ 轮，节点的表示包含 $K$ 跳内的"结构邻居画像"。两个**结构角色相似**的节点（比如两个都在密集圈内的节点），它们 $K$ 跳内的邻居特征分布相似 → 聚合后的表示相似；而桥与圈内人 $K$ 跳内的邻居结构截然不同 → 表示不同。**消息传递把"结构相似性"翻译成"表示相似性"，这就是 GNN 从直观结构里学到的东西。**

**思路点拨**：答题锚点是"**聚合 → 表示相似性 = 结构相似性**"。这是"直观表示"到"可学习表示"的桥。常见错误是只说"GNN 能处理图"，没落到"为什么结构相似导致表示相似"的机制（邻居画像相似）。
