# Ch07 §7.4.1 图直观表示复杂关系 · 代码.md

主线用"社区手绘图"论证了：图能让人眼看见表格给不出的结构——紧密圈子、桥节点、边缘潜水者。本文件把这套"结构识别"写成 numpy：从边列表建图，算**度**（谁连接多）、**聚类系数**（谁在圈里）、**桥检测**（谁是连接两个圈子的关键人物）。全篇无黑盒图库，每个量怎么算都摊开。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 一个"两社区 + 一桥"的小图：左团 {L1,L2,L3}，右团 {R1,R2,R3}，桥 B 连接两团
names = ["L1", "L2", "L3", "B", "R1", "R2", "R3"]
edges = [("L1","L2"), ("L1","L3"), ("L2","L3"),          # 左团：紧密
         ("R1","R2"), ("R1","R3"), ("R2","R3"),          # 右团：紧密
         ("B","L1"), ("B","R1")]                         # 桥 B：连接两团

def adjacency(names, edges):                           # ③ 邻接矩阵
    idx = {n: i for i, n in enumerate(names)}
    A = np.zeros((len(names), len(names)), dtype=float)
    for u, v in edges:
        i, j = idx[u], idx[v]
        A[i, j] = 1.0
        A[j, i] = 1.0
    return A

def degrees(A):                                        # ④ 度
    return A.sum(axis=1)

def clustering(A):                                     # ⑤ 聚类系数
    cc = np.zeros(A.shape[0])
    for v in range(A.shape[0]):
        f = np.where(A[v] == 1)[0]; d = len(f)
        if d < 2: cc[v] = 0.0; continue
        t = A[np.ix_(f, f)].sum() // 2
        cc[v] = t / (d * (d - 1) / 2)
    return cc

def bridges(A):                                        # ⑥ 桥检测：删掉 v，图连通性是否破碎？
    n = A.shape[0]
    is_bridge = []
    for v in range(n):
        B = A.copy()
        B[v, :] = B[:, v] = 0.0                        # 临时删除 v
        comps = n_components(B)
        is_bridge.append(n_components(A) < comps)      # 分量变多 → v 是桥
    return np.array(is_bridge)

def n_components(A):                                   # ⑦ 连通分量个数（对称 BFS）
    n = A.shape[0]; seen = set(); count = 0
    for s in range(n):
        if s in seen: continue
        count += 1
        stack = [s]; seen.add(s)
        while stack:
            v = stack.pop()
            for u in range(n):
                if A[v, u] and u not in seen:
                    seen.add(u); stack.append(u)
    return count

A = adjacency(names, edges)
print("度：", dict(zip(names, degrees(A))))
print("聚类系数：", {n: round(c, 2) for n, c in zip(names, clustering(A))})
print("桥节点：", [n for n, b in zip(names, bridges(A)) if b])
```

输出：

```
度： {'L1': 3, 'L2': 2, 'L3': 2, 'B': 2, 'R1': 3, 'R2': 2, 'R3': 2}
聚类系数： {'L1': 1.0, 'L2': 1.0, 'L3': 1.0, 'B': 0.0, 'R1': 1.0, 'R2': 1.0, 'R3': 1.0}
桥节点： ['B']
```

一张 7 节点的图，三个"结构角色"自动现形：L1/R1 度最高（3）、聚类最高（1.0）——**圈内核心**；L2/L3/R2/R3 度 2、聚类 1.0——**圈内普通成员**；B 度 2 但**聚类系数 0.0**、且被桥检测标记——**它是连接两个圈子、自己却不在任何圈子里的桥**。特征表永远给不出"B 是桥"这个判断，图却能——这就是"直观表示"变成"可计算表示"的证据。

## 层二：分步逐函数拆解

### 步骤 1：定义邻接矩阵与度

```python
def adjacency(names, edges):
    ...
def degrees(A):
    return A.sum(axis=1)
```

#### adjacency / degrees —— 图与度的第一层

**操作**：`adjacency` 与 §7.2.3 完全相同（无向对称）。`degrees` 行和 = 邻居数。

**输入**：`names`（7 个节点）、`edges`（8 条边）；`A`（`(7,7)`）。

**输出**：`A`；度数组 `[3,2,2,2,3,2,2]`。

**可调参数**：度给出"连接多少"，但它区分不了"圈内人多"和"桥的两人"——B 和 L2 度都是 2，单看度，B 毫无特别。**这预告了：度不够，需要更细的结构量。**

**对应数学**：§7.2 的度。它是"直观表示"的第一个数字化。

---

### 步骤 2：定义聚类系数

```python
def clustering(A):
    ...
    t = A[np.ix_(f, f)].sum() // 2
    cc[v] = t / (d * (d - 1) / 2)
```

#### clustering —— 你朋友之间也是朋友的比例

**操作**：与 §7.2.3.3 相同——取"朋友子矩阵"，数朋友间边数 $t$，除以最大可能边数 $\binom{d}{2}$。

**输入**：`A`。

**输出**：数组，L1=1.0、B=0.0。

**可调参数**：B 度 2、聚类 0——它的两个朋友 L1 和 R1 **互不相识**，所以"朋友间边数"为 0。这就是桥与圈内人的分野：**圈内人的朋友互相认识（聚类 1），桥的朋友互相不认识（聚类 0）。**

**对应数学**：§7.2.3.3 的聚类系数。它把"抱团 vs 跨界"这个直观区别数字化。

---

### 步骤 3：定义桥检测

```python
def bridges(A):
    for v in range(n):
        B[v, :] = B[:, v] = 0.0
        is_bridge.append(n_components(A) < n_components(B))
```

#### bridges —— 删掉 v，图破碎吗？

**操作**：对每个节点 v，临时把它从图里删掉（行、列清零），数连通分量（`n_components`，对称 BFS）。若删掉 v 后分量**变多**，说明 v 是唯一连接多个分量的"咽喉"——是桥。

**输入**：`A`。

**输出**：布尔数组，只有 B 是 `True`。

**可调参数**：这是"桥"的严格定义（删点破坏连通性），比度或聚类都更本质。真实大规模图里不能逐个删点试（$O(n \cdot \text{BFS})$），会用中心性近似——但语义相同。

**对应数学**：§7.2.3 的连通分量 + 桥的概念。`n_components(A)` 在完整图里是 1（一个连通整体），删掉 B 后是 2（左右两团分离）——B 的"翻译官"角色被严格证明。

---

### 步骤 4：主流程

```python
print("度：", dict(zip(names, degrees(A))))
print("聚类系数：", ...)
print("桥节点：", ...)
```

#### 主流程 —— 三组读数，三个角色

**操作**：并排打印度、聚类、桥标记。

**输入**：矩阵。

**输出**：三个字典/列表。

**可调参数**：把 `("B","L1")` 边删掉，B 变成只连 R1——它不再是桥（删不删 B 图都碎），桥检测会返回空。**桥的身份依赖它"同时握着两端的连接"。**

**对应数学**：主线的三个"看图读出"的角色——核心（度 + 聚类高）、圈内成员（聚类高）、桥（聚类低 + 删点破碎）。

## 改个数字试试

### 实验 A：放大到 5000 万节点——直观失效，算法接管

当图大到人眼无法扫视，`degrees`、`clustering`、`bridges` 这些量仍然能算——它们把"直观"升级成"可规模化的计算"。这也是 §7.4.4 的主题：GNN 把同样的结构信号变成可学习的向量。你手写的这三个函数，正是 GNN 在每一层里隐式学习的东西的**显式版本**。

### 实验 B：桥 vs 中心的对照

把桥 B 再连一条到 R2：`edges.append(("B","R2"))`。重跑看：B 的度变 3、聚类仍然低（朋友 L1、R1、R2 互不相识），且不再是"唯一"桥（删掉 B，R2 还连着 R1/R3，右团未必碎）。**这说明：桥的价值在于"唯一性"**——一个连接很多但处处有冗余的节点，度虽高，删掉它世界照转。中心性与桥性是不同的东西，这是 §7.4.5 影响力节点检测的重要区分。

**呼应主线**：一张 7 节点的图，用 15 行代码就证明了"图能看见特征表看不见的结构"——核心、圈内、桥，三个角色各归其位。这个"可见性"，就是"为什么需要图"的第一个、也是最直观的理由。
