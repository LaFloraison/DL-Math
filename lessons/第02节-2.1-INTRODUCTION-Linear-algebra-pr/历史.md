# 历史：一张纸上的表格，如何变成整个世界的地基

## 1858 年，剑桥，一个被当作"多余"的发明

那年，剑桥的一位数学家阿瑟·凯莱（Arthur Cayley）写下了一篇不到十页的短文。文章里他提出了一种奇怪的"表格"——一排排数字整整齐齐地码成方块，他还给这些方块规定了乘法的规则。

当时几乎没人认真对待它。同行们觉得，这不过是把一堆数字排列成矩形，再发明一套算它的规则——一种"多余的记法"。凯莱自己也只是轻描淡写地把它称为 "the general theory of matrices"——矩阵理论。他说，这或许有趣，但"我看不出它有什么用"。

他看不到用途，是因为还不到时候。他面对的世界，是三维的物理、是一元二次方程的求根，一个人穷尽一生也碰不到需要同时操纵几百万个数字的问题。那个问题，要等一个多世纪之后才会出现。

## 一百多年里，矩阵在暗处生长

凯莱抛下的这个"没用的发明"，在之后的岁月里却处处发芽。

**物理学家**先捡起了它：量子力学要同时描述粒子的许多状态，海森堡把观测写成了矩阵，波恩从中认出"动量"；工程师用它求解桥梁受力、电网电流——一个复杂的系统，拆成一张表，再解这张表。

**计算机科学家**再捡起它：上世纪中叶，计算理论兴起，人们发现矩阵乘法是许多计算的核心。但计算机还不够快，矩阵运算在大众眼里仍是学者书房里的冷门工具。

到 1990 年代，神经网络的第一波浪潮来而复去。那时也有人尝试训练深度网络，但连"在合理时间内把一层 1000×1000 的矩阵乘完"都费劲——机器太慢，数据太少，数学躺在纸上，等着一台真正为它而生的机器。

## 2012 年，一间 GPU 机房——矩阵第一次站上世界舞台

转折点在一间普通的机房里。多伦多大学，Alex Krizhevsky 和同事们在几块游戏显卡（GPU）上训练一个叫 AlexNet 的卷积神经网络。

GPU 是什么？它最初是给游戏画面做渲染的——每一帧画面里有上百万个像素，每个像素的颜色都要同时算出来。游戏逼着芯片制造商学会了**把成千上万个核心塞进一块芯片**，让它们并行地做同一种运算。

而图像分类这件事，一旦用矩阵写出来，就变成了一长串几乎一模一样的乘法——**和游戏渲染的需求，惊人地一致**。Alex 他们做了一个当时略显离经叛道的决定：不去用"正经的"CPU 集群，而是把神经网络的矩阵乘法搬上为游戏而生的 GPU。

效果是戏剧性的。训练时间从"以月计"缩到"以天计"。2012 年 ImageNet 竞赛，AlexNet 以碾压性的优势夺冠，错误率几乎比第二名低了一半。整个机器学习界被震住了——不是因为他们发明了新的数学，而是因为他们**让已有的数学第一次跑得足够快**。

一夜之间，矩阵不再是学者书房里的表格。它是每一块 GPU 里最核心的那道指令。

## 2017 年，"Attention Is All You Need"——一切都被写成了矩阵

矩阵在深度学习里的登基，在五年后完成。

2017 年，一篇名为《Attention Is All You Need》的论文提出了 Transformer。它做了一件堪称激进的事：把自然语言处理里的每一步——词与词的关系、位置信息、加权求和——**全部改写成了矩阵运算**。

输入的一句话被变成一个矩阵：每一行是一个词的向量。词与词之间的关联被算成两个矩阵的乘法 $QK^T$，注意力权重由 Softmax 得出来。整个模型没有一行"规则"，只有一连串矩阵乘法、加法和逐元素运算，全部喂给 GPU。

从此，深度学习的一切——语言、图像、语音、代码——都被装进了同一种盒子里：**矩阵运算**。GPU 是为它造的，框架是为它写的，一个模型几万亿个参数，全部躺在矩阵里。

## 留一扇门

从凯莱写下那张"没用的表格"，到 Transformer 里每秒几十亿次的矩阵乘法，中间隔了一个半世纪。那张表格本身从没变过——变的，是世界终于长出了配得上它的规模。

凯莱会说，矩阵就是"一列装数字的盒子，和一张分发数字的兑换表"。今天你会看到，这一列盒子叫向量，兑换表叫矩阵，盒子里套盒子叫张量；而整台 Transformer、整台神经网络，不过是把这三样东西按特定方式组织起来、让它们一层层传递数据——一台你完全能看懂的工厂。

要认懂这台工厂，我们从最基础的那列盒子开始：向量。
