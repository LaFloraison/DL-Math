# 第02节 · 线性代数导论

## 第一步：动机 —— 你正在实现一个神经网络

假设你正在从零实现一个最简单的神经网络——**单层感知机 (Perceptron)**。这个网络做的事情极其简单：接收输入数据，乘以权重，加上偏置，然后通过激活函数输出结果。

你写下代码：

```python
import numpy as np

# 输入：3个特征，4个样本
X = np.random.randn(4, 3)
# 权重：3个输入 → 2个输出
W = np.random.randn(3, 2)
# 偏置
b = np.random.randn(2)

# 前向传播
output = X @ W + b
```

这行代码 `X @ W + b` 在 PyTorch 里也就是 `nn.Linear(3, 2)` 的全部内容。

**问题来了**：为什么是"矩阵乘法"而不是别的什么运算？为什么权重是一个矩阵而不是一个数？为什么神经网络的学习本质上是在调整矩阵里的数字？

如果你答不上来，别急——这一章就是答案。线性代数不是神经网络的一个"工具"，**它就是神经网络的语言**。

## 第二步：数学讲解

### 2.1.1 什么是线性代数？

**线性代数 (Linear Algebra)** 是研究**向量空间 (vector spaces)** 以及**向量空间之间的线性映射 (linear mappings)** 的数学分支。

这个定义包含两个核心对象：

| 对象 | 通俗理解 | 深度学习中的对应 |
|------|---------|----------------|
| 向量 (vector) | 一组有序的数字 | 一个样本的特征、一层网络的输出 |
| 线性映射 (linear map) | 保持"直线"和"平行"的变换 | 权重矩阵 $W$ 的作用：$x \mapsto Wx$ |

**线性映射的严格定义**：一个映射 $T: V \to W$（$V$、$W$ 是向量空间）称为线性的，当且仅当对任意 $u, v \in V$ 和标量 $c$，满足：

$$T(u + v) = T(u) + T(v) \quad \text{(可加性)}$$
$$T(cu) = cT(u) \quad \text{(齐次性)}$$

这两个条件合称为**叠加原理 (superposition principle)**。

> **直觉**：线性映射不会弯曲空间。直线进去还是直线出来，平行线保持平行。就像一块玻璃板上的影子——你移动物体，影子跟着移动，但不会扭曲变形。

### 2.1.2 为什么深度学习需要线性代数？

教材指出，线性代数是"贯穿深度学习织物的线" (the thread weaving through the fabric of deep learning)。具体而言，它提供三大能力：

**能力一：表示 (Representation)**

数据必须以某种结构存储。一张 $224 \times 224$ 的 RGB 图像在计算机里是什么？是一个 $224 \times 224 \times 3$ 的张量 (tensor)——三维数组。一个句子呢？是一串 token 的嵌入向量 (embedding vectors)。

没有向量和矩阵的语言，我们根本无法描述"数据长什么样"。

**能力二：变换 (Transformation)**

神经网络每一层做的事情，本质上就是一个线性变换接一个非线性激活：

$$\mathbf{h} = \sigma(W\mathbf{x} + \mathbf{b})$$

其中 $W\mathbf{x} + \mathbf{b}$ 是**仿射变换 (affine transformation)**——线性变换加平移。整个深度网络就是一系列这样的变换的复合。

**能力三：优化 (Optimization)**

训练网络意味着调整 $W$ 和 $\mathbf{b}$ 使得损失函数最小。梯度下降的核心运算是计算损失对每个参数的偏导数——这本身就是矩阵微积分 (matrix calculus)。而反向传播算法 (backpropagation) 的本质，就是**链式法则在多变量函数上的系统性应用**，其底层运算是矩阵乘法。

### 2.1.3 关键的张量操作

教材强调，神经网络计算的"核心"是**张量运算 (tensor operations)**。以下是四种最基本的：

**① 逐元素运算 (element-wise operations)**

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
c = a + b        # 逐元素加法 → [5, 7, 9]
d = a * b        # 逐元素乘法 → [4, 10, 18]
```

**② 点积 (dot product)**

$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i$$

```python
dot = np.dot(a, b)   # → 32
```

**③ 矩阵乘法 (matrix multiplication)**

$$(AB)_{ij} = \sum_{k} A_{ik} B_{kj}$$

```python
A = np.random.randn(3, 4)
B = np.random.randn(4, 2)
C = A @ B            # 形状: (3, 2)
```

**④ 转置 (transpose)**

$$(A^T)_{ij} = A_{ji}$$

```python
A_T = A.T            # 形状: (4, 3)
```

> **⚠️ 不能做什么（局限性）**：
> - 矩阵乘法**不满足交换律**：$AB \neq BA$（通常）。这就是为什么在神经网络中，输入 $X$ 和权重 $W$ 的顺序不能随意调换——`X @ W` 和 `W @ X` 是完全不同的运算，甚至可能因为形状不匹配而根本无法执行。
> - 逐元素乘法与矩阵乘法是**两种完全不同的运算**。在代码中，`*` 和 `@` 不可互换。初学者常犯的错误之一就是混淆 `np.multiply`（逐元素）和 `np.dot`（矩阵乘法）。

### 2.1.4 为什么这些概念"既理论又实用"？

教材说这些概念"不仅是理论基础，也是让深度学习模型活起来的实用工具" (not only theoretical foundations but also practical instruments)。

这不是修辞。请看：

- **批量训练 (mini-batch training)** 之所以高效，是因为我们可以把整个 batch 的数据堆叠成一个矩阵，一次矩阵乘法完成所有样本的前向传播——**而不是写 for 循环逐个样本计算**。
- **GPU 加速**之所以可能，是因为矩阵乘法可以被分解成大量并行的乘加运算，这正是 GPU 擅长的。
- **模型压缩**（如低秩分解）之所以可行，是因为我们理解了矩阵的秩 (rank) 和奇异值分解 (SVD)——这是本章后面要讲的内容。

## 第三步：DL 桥接 + 代码验证

### 桥接：矩阵乘法就是"批量特征变换"

一个全连接层做的事情可以拆解为：

$$\mathbf{h} = W\mathbf{x} + \mathbf{b}$$

- $W$ 的每一行是一个"特征检测器"——它衡量输入 $\mathbf{x}$ 在某个方向上的投影强度
- $W$ 的每一列对应输入的一个特征如何贡献到各个输出神经元
- 矩阵乘法 $\mathbf{h} = W\mathbf{x}$ 同时计算了所有输出神经元的值——**一次运算，全部完成**

### 代码验证：亲手感受"批量"的力量

```python
import numpy as np
import time

# 模拟：1000个样本，每个样本784维（像MNIST），输出10类
X = np.random.randn(1000, 784)
W = np.random.randn(784, 10)
b = np.random.randn(10)

# 方法1：循环逐个样本（慢）
def loop_forward(X, W, b):
    outputs = []
    for x in X:
        outputs.append(W.T @ x + b)
    return np.array(outputs)

# 方法2：批量矩阵乘法（快）
def batch_forward(X, W, b):
    return X @ W + b

# 验证结果一致
assert np.allclose(loop_forward(X, W, b), batch_forward(X, W, b))

# 对比速度
t0 = time.time()
loop_forward(X, W, b)
t1 = time.time()
batch_forward(X, W, b)
t2 = time.time()

print(f"循环方式: {t1-t0:.4f} 秒")
print(f"矩阵方式: {t2-t1:.4f} 秒")
print(f"加速比: {(t1-t0)/(t2-t1):.1f} 倍")
```

**预期输出**（数值因机器而异）：

```
循环方式: 0.0281 秒
矩阵方式: 0.0010 秒
加速比: 28.1 倍
```

这就是线性代数"让模型活起来"的直接体验——**同样的数学运算，用矩阵形式表达，快了近 30 倍**。这还只是 CPU 上的 1000 个样本。在 GPU 上处理百万级数据时，差距是数量级的。
