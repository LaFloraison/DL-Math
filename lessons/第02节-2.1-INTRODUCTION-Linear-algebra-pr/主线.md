## 第一步：Toy Model —— 一家传话工厂

想象一家工厂，只做一件事：把一种"盒子"变成另一种"盒子"。

入口处，工人们推着一种装满数字的长条盒子进来——盒子像一列火车车厢，每节车厢里放一个数：`[2, 7, 3, 1]`。这是**数据**。一张照片、一段语音、一句话，进了这家工厂，都被拆成这种装满数字的长条盒子。

工厂里摆着一排机器。每台机器的内部是一张巨大的"兑换表"——一张表格，竖列是进来的盒子里的每一个数，横排是出去的时候每一个数该拿多少份。进来的每个数，照着表分发到出去的各个数位上，加起来，就成了一个新的盒子。

`[2, 7, 3, 1]` 从第一台机器里出来，变成了 `[5, 9]`；再进第二台，变成 `[13]`。一层接一层，长盒子越变越短。最后一台机器吐出一个只有一个数的盒子——一个答案：`0.98`。工厂门口的标牌写着：这个数代表"图片里有猫"。

现在退后一步看整家工厂。你不需要看懂每一台机器内部的具体数字——你只需要认得出**三种东西**：

- 那列装数字的长条盒子，叫**向量 (vector)**
- 机器内部那张巨大的兑换表，叫**矩阵 (matrix)**
- 一批盒子摞在一起、或者每节车厢里又套着小盒子的那种"盒子里有盒子"，叫**张量 (tensor)**

整家工厂——从上百万个盒子到最终那一个数——就是一台**神经网络 (neural network)**。而线性代数，就是描述这家工厂的**全套语言**：它告诉你怎么描述盒子、怎么描述兑换表、怎么算"一列盒子过一台机器"这件事、怎么把一张巨大的兑换表拆成几张小表看懂它在干什么。

你或许已经隐约感到：这家工厂的每一个动作，都是**线性的**——进来的数乘上表里的数，再加起来。没有开方，没有超越函数（那要等"激活函数"那一节才会登场）。一台完全由"乘和加"堆起来的工厂，为什么能学会识别猫、翻译语言、下赢围棋？这就是这一整章要回答的问题。

## 第二步：正式数学讲解

### 一、撞墙：没有这门语言，深度学习就无话可说

你打开任何一篇深度学习论文，会撞见这样的段落：

> "我们把输入 $X \in \mathbb{R}^{B \times C \times H \times W}$ 送入网络，经过 $W^{(l)} \in \mathbb{R}^{d_{l} \times d_{l-1}}$ 的线性层……"

看不懂，不是因为论文写得差，而是因为**你还没有这门语言**。$X$、$W$、$\mathbb{R}^{B \times C \times H \times W}$ 这些符号，就是工厂里那些盒子、兑换表、盒子里套盒子的**速记**。没有这门语言，深度学习的每一句话都是天书；有了这门语言，上面这句论文开头就变成：

- $X$：进来的数据，装在"批×通道×高×宽"的四层盒子里（一张图：一批 32 张、每张 3 个颜色通道、高宽各 224）
- $W^{(l)}$：第 $l$ 层机器里的兑换表，$d_{l} \times d_{l-1}$ 意味着"$d_{l-1}$ 个进、$d_l$ 个出"
- $\in \mathbb{R}^{\cdots}$：盒子里装的是实数

但"语言"这个词还太轻了。线性代数给深度学习的不只是一套符号——它给的是**一套算得动的数学**。为什么工厂里全是"乘和加"？因为乘和加有两大美德：

1. **可预测的几何**。一个盒子过一台机器，方向会被拉伸或旋转，但直线永远保持直线，原点永远不动——这是**线性变换 (linear transformation)**。深度学习里的每一层，本质上都在重复这件几何动作。
2. **可计算的效率**。几百亿个数字的乘法，可以交给 GPU 成千上万个核心同时算——GPU 天生就是为矩阵乘法造的。2012 年 AlexNet 之所以能赢，一半功劳要记在"把卷积写成矩阵运算、用 GPU 做"这个决定上。

### 二、五根柱子：本章的地图

一本 12 章的书，为什么第二章、而且是在概率论与微积分**之前**就讲线性代数？因为在深度学习中，线性代数是那个"一切运算的舞台"——概率要在这上面写，梯度要在这上面走。本章给你竖五根柱子，每一根都通向深度学习的一个零件：

**柱子一：向量 (vector)——数据的最小单位。** §2.2 讲向量、向量运算、向量空间。深度学习里，一张图的特征、一句话的词嵌入 (embedding)、一个样本的所有属性，都是向量。向量之间怎么加、怎么比较长短、怎么衡量相似——就是数据之间怎么交互的第一课。

**柱子二：矩阵 (matrix)——参数的存放与运算。** §2.3 讲矩阵、矩阵乘法、逆矩阵、线性方程组。神经网络里千百万个可学习参数，全部存在矩阵里；前向传播 (forward pass) 的每一次 $W \cdot x$，都是矩阵乘法。

**柱子三：张量 (tensor)——批量数据的形状。** §2.4 讲张量与张量运算。真实训练时数据不是单个样本，而是"一批"样本、还带通道和空间维度——这种多维数组就是张量，Transformer 里的 token 序列、CNN 里的特征图，都是张量。

**柱子四：线性变换 (linear transformation)——层在做什么。** §2.5 讲线性变换的几何与矩阵表示。缩放、旋转、剪切、投影——每一层的权重矩阵，几何上就是这几种动作的组合。看清了变换的几何，就看清了神经网络"在空间中挪动数据"的本质。

**柱子五：矩阵分解 (matrix factorization)——把大象拆开看。** §2.6 讲 LU、QR、SVD 与特征值分解。一张巨大的兑换表可能无法理解，但把它拆成几张小表——"旋转一下、伸缩一下、再转回去"——就露出了它真正的结构。主成分分析 (PCA)、词嵌入降维、谱聚类，全站在 SVD 和特征值的肩上。

五根柱子合成一句话：**向量是数据的语言，矩阵是参数的语言，张量是批量的语言，变换是层的行为，分解是理解复杂变换的手术刀。**

### 三、一个贯穿始终的对比：线性 vs 非线性

在看具体章节之前，先埋下全章最重要的一条分界线，否则你会在第三章（微积分）和后面的激活函数处反复迷路。

本章所有机器——向量加法、矩阵乘法、线性变换——都是**线性的**。线性有什么特征？两个盒子叠加后过机器，等于分别过机器再叠加：

$$T(\alpha \mathbf{u} + \beta \mathbf{v}) = \alpha T(\mathbf{u}) + \beta T(\mathbf{v})$$

这就是**叠加原理 (superposition principle)**。如果神经网络全由线性运算组成，那么无论多少层，串起来**还是一层线性**——因为线性映射的复合仍是线性映射，一堆直线叠不出曲线。而识别猫、翻译语言这种事，恰恰需要**曲线**——需要把直线掰弯的能力。这个"掰弯"由激活函数（如 ReLU）提供，那属于 §2.2.3.3 与 §2.3.6.4 的内容。

所以本章你会反复看到同一句话的两半：**线性代数造出那台线性的机器，激活函数在机器之间插入非线性**。二者缺一，深度学习都不成立。

### 四、本章的内部路线图

如果你把整章当作一次旅行，路线是这样的：

1. **§2.2 向量**：数据如何被描述（§2.2.1），以及向量如何直接长在深度学习骨架上（§2.2.3）——特征向量、网络参数、点积、梯度下降、批处理、卷积的向量视角。
2. **§2.3 矩阵**：数据如何被变换（§2.3.1–2.3.5），以及矩阵运算如何长在神经网络的每一次前向与反向传播上（§2.3.6）。
3. **§2.4 张量**：从单个向量、矩阵，推广到任意维度的数组——深度学习数据流的真实形状。
4. **§2.5 线性变换**：从代数的"算"到几何的"看"——每层的矩阵到底把空间怎么挪。
5. **§2.6 矩阵分解**：把复杂变换拆解成可理解的基本件——SVD、特征值，深度学习的许多"隐藏结构"（PCA、词向量、卷积核分析）都在这里。

边界声明：本章每一节的"正式数学"都建立在这个前提上——向量、矩阵、张量里的元素都是**实数**，运算都是标准的加法和乘法。这套体系在实数域上完美，但请不要以为它是万能的：一旦你需要处理"不是向量该表达的东西"（比如一张图的结构性关系、事件之间的因果），或者需要"非线性"的度量（那是第三章微积分与第四章概率的领地），线性的工具箱就会不够用。线性代数是一切的地基，但**地基不等于整栋楼**。

## 第三步：DL 桥接

这一节本身就是一张桥图。把五根柱子一一接到具体的深度学习组件上：

| 线性代数对象 | 深度学习的落点 | 具体到符号 |
|---|---|---|
| 向量 | 一个样本的特征、词嵌入 | 一张 224×224 的图压成一维向量 $\mathbf{x} \in \mathbb{R}^{50176}$ |
| 向量运算（点积） | 相似度度量 | Attention 里的 $Q \cdot K^T$ 计算 token 间相似度 |
| 矩阵 | 层参数 | 全连接层权重 $W \in \mathbb{R}^{d_{out} \times d_{in}}$ |
| 矩阵乘法 | 前向传播 | $\mathbf{h} = W\mathbf{x} + \mathbf{b}$，一次乘加对全层同时生效 |
| 张量 | 批数据 / 特征图 | 输入批量 $X \in \mathbb{R}^{B \times C \times H \times W}$ |
| 线性变换 | 层的几何行为 | 权重矩阵 $W$ 是对输入空间的一次线性变换 |
| SVD / 特征值 | 降维与结构分析 | PCA 取协方差矩阵最大特征值方向作主成分 |

你会在 §2.2 到 §2.6 一处处遇到这张表里的每一项。这一章的最终目标，就是让你看到：**深度学习里几乎没有一步不是线性代数。** 当你学完本章回头再看这篇论文的开头——"我们把输入 $X \in \mathbb{R}^{B \times C \times H \times W}$ 送入网络"——它就不再是天书，而是一句你完全读得懂的工厂说明书。每一处具体运算的 Python 实现，见《代码.md》。
