## 解答与思路点拨

### 第一组

**1.1 答案：B。**
- **思路**：全设常数 $c$ 的核心问题不是"数太大或太小"，而是**同一层所有神经元完全对称**——输入相同、加权和相同、激活输出相同、收到的梯度相同、更新后仍相同，永远无法分化。这就是主线的对称性问题 (symmetry problem)。
- **为什么有人会选错**：选 A 或 C 的同学，把"常数"误解成"特别大的数或特别小的数"。常数的大小不是关键——即使 $c$ 恰好是个合适的量级，对称性依然杀死这一层。选 D 的同学混淆了初始化与正则化/过拟合的范畴。

**1.2 这句话不对。**
- **思路**：Xavier 的方差推导假设激活函数在零点附近**近似线性**、输入**零均值**。$\tanh$、sigmoid 近似满足；而 ReLU 会把约一半神经元输出置零，使二阶矩减半，Xavier 的平衡被打破——信号每层衰减一半，深层照样消失。ReLU 网络要用 He 初始化（$\sigma_w^2 = 2/n_{in}$），多出的因子 2 恰好补偿被砍掉的能量。
- **点拨**：判断一个初始化方案，永远问三个问题：激活在原点附近线性吗？输入零均值吗？前后向方差条件都满足吗？

**1.3 答案：$\sigma_w^2 = \dfrac{2}{100} = \dfrac{1}{50}$；$\sigma_w = \sqrt{\dfrac{2}{100}} = \sqrt{0.02} \approx 0.141$。**
- **思路**：He 只依赖 $n_{in}$（输入神经元数），不依赖 $n_{out}$。注意 $n_{out}=50$ 是干扰项，不入公式。
- **点拨**：对比 Xavier 要用 $n_{in}+n_{out}$，He 只认 $n_{in}$——这个区别正是很多人记混的地方。

### 第二组

**2.1**
(a) $a = \sqrt{\frac{6}{16}} = \sqrt{0.375} \approx 0.612$。
(b) $\sigma_w^2 = a^2/3 = 0.375/3 = 0.125 = \frac18$；$\text{Var}(y_i) = 8 \times \frac18 \times 1 = 1$——输出方差等于输入方差，信号穿过一层不缩放。这就是 Xavier 的核心：$a$ 的取值正是为了凑出这个"恰好等于 1"。

**2.2**
(a) $\sigma_w = \sqrt{\dfrac{2}{n_{in}}} = \sqrt{\dfrac{2}{16}} = \sqrt{0.125} \approx 0.354$。
(b) 验证代码：

```python
import numpy as np
rng = np.random.default_rng(0)
N, n = 10000, 16
x = rng.normal(0.0, 1.0, (N, n))            # 能量 E[x²] ≈ 1
xr = np.maximum(x, 0.0)                     # ReLU：能量减半 ≈ 0.5
W_he = rng.normal(0.0, np.sqrt(2.0 / n), (n, n))       # He
a    = np.sqrt(6.0 / (n + n))               # Xavier 边界
W_xa = rng.uniform(-a, a, (n, n))           # Xavier
print("输入能量      =", round((x**2).mean(), 4))     # ≈ 1.0037
print("ReLU 后能量   =", round((xr**2).mean(), 4))    # ≈ 0.5010
print("He    层后 E[y²] =", round(((xr @ W_he.T)**2).mean(), 4))   # ≈ 1.0707
print("Xavier 层后 E[y²] =", round(((xr @ W_xa.T)**2).mean(), 4))  # ≈ 0.4458
```

- **思路**：ReLU 把能量从 1 砍到 0.5。He 的权重方差 $2/16$ 正好把它"补"回 1（$E[y^2] = n\sigma_w^2 E[x^2] = 16 \times \frac{2}{16} \times 0.5 = 1$），实测 1.07 贴合理论；Xavier 的 $1/16$ 没有补偿，$E[y^2] = 16 \times \frac{1}{16} \times 0.5 = 0.5$，实测 0.45——每层丢一半，深层必死。
- **点拨**：用二阶矩 $E[y^2]$ 而不是"方差"去验证 He——因为 ReLU 后分布不再零均值，$E[y^2]$ 才是 He 真正校准的量。

**2.3**
```python
import numpy as np
rng = np.random.default_rng(42)
def propagate(Ws, x, use_relu=False):
    stds = []
    for i, W in enumerate(Ws):
        x = x @ W.T
        if use_relu and i < len(Ws) - 1:
            x = np.maximum(x, 0.0)
        stds.append(np.std(x))
    return np.array(stds)
L, n = 50, 256
x0 = rng.normal(0.0, 1.0, (64, n))
Ws_n = [rng.normal(0.0, 1.0, (n, n)) for _ in range(L)]          # naive σ=1
Ws_x = [rng.uniform(-np.sqrt(6/(2*n)), np.sqrt(6/(2*n)), (n, n)) for _ in range(L)]
for name, Ws in [("naive", Ws_n), ("xavier", Ws_x)]:
    s = propagate(Ws, x0.copy())
    print(name, "第10层σ=%.3e  第30层σ=%.3e  第50层σ=%.3e" % (s[9], s[29], s[49]))
# naive  : 第10层σ=1.128e+12  第30层σ=1.320e+36  第50层σ=1.621e+60
# xavier : 第10层σ=1.001e+00  第30层σ=9.166e-01  第50层σ=1.007e+00
```

- **思路**：naive（$\sigma_w=1$、$n=256$）每层放大 $\sqrt{256}=16$ 倍，所以 $\sigma \approx 16^{\text{层数}}$——第 10 层 $16^{10}\approx 10^{12}$，第 50 层 $16^{50}\approx 10^{60}$，一路冲向溢出。xavier 每层缩放因子约 1，第 10、30、50 层都稳定在 $1$ 附近——"纹丝不动"正是初始化设计的全部意义。
- **点拨**：注意横轴是"层数"、纵轴是"σ"，naive 在**对数**尺度上近似直线上升——这正是指数定律 $r^L$ 的几何签名。

### 第三组

**3.1 答案：必须用 He。**
- **思路**：152 层全是 ReLU，Xavier 每层丢一半能量，$152$ 层后 $0.5^{152}\approx 10^{-46}$——信号根本走不到输出端。He 的因子 2 恰好补回 ReLU 砍掉的一半，让能量逐层守恒，152 层的梯度才不至于在中途耗尽（这正是 He 2015 论文里"深 ReLU 网络首次真正训得动"的工程背景）。
- **为什么有人会选错**：选 Xavier 的同学记住了"Xavier 很有名"，却忘了它的假设是"激活在 0 附近近似线性"。**选初始化方案永远先问激活函数**：$\tanh$/sigmoid → Xavier，ReLU → He。
- **全零的后果**：对称性问题。152 层每一层都退化成"一个有效神经元"，网络退化成一个近乎线性的浅通道，完全丧失表达能力——而且这种对称性一旦建立，训练永远无法打破。

**3.2 梯度方差大约被乘 $\sigma_w^2 \times n_{out} = \frac{2}{10001} \times 1 \approx 0.0002$ 倍，即标准差缩到约 $\sqrt{0.0002}\approx 0.014$——穿过一个瓶颈，梯度就缩到原来的约 1/70。**
- **思路**：反向传播 $\frac{\partial L}{\partial x_j} = \sum_{i=1}^{n_{out}} w_{ij}\frac{\partial L}{\partial y_i}$ 只有 $n_{out}=1$ 项求和，方差条件 $\sigma_w^2 = 1/n_{out} = 1$ 被 Xavier 的折中严重违反。单个窄瓶颈只让梯度缩 70 倍，还勉强能扛；但网络里若一连串这样的窄层，梯度被逐层压缩，指数级走向消失——"窄瓶颈"是梯度消失的一个隐藏温床。
- **点拨**：这就是为什么深度学习实践偏爱**宽层**（前后向方差条件都好满足），并用 ResNet 的**恒等捷径**（identity shortcut）给梯度开一条不经过瓶颈的直达通道——让梯度"绕路"而不必硬穿每个窄层。这个思想在 §4 概率与优化、ResNet 相关章节会继续展开。

## 一个"为什么有人会答错"的提醒

1.1 的最大陷阱是把"常数初始化"当"太大/太小"，而真正的杀手是**对称性**——判断初始化问题，先看对称，再看尺度。2.3 的曲线要会读：naive 在对数尺度上近似直线，那是指数定律的签名；xavier 平得像一条直线地平线，那是"每层缩放因子等于 1"的签名。3.2 容易误以为"梯度爆炸只来自权重太大"，其实**窄层（$n_{out}$ 很小）同样能压缩梯度**——前向看 $n_{in}$，反向看 $n_{out}$，两边都要盯住。
