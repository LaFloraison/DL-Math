# 代码：用 NumPy 亲手"称"四种初始化的斤两

主线推导出：信号穿过一层不被缩放，权重标准差要取 $\frac{1}{\sqrt{n_{in}}}$（Xavier 折中到 $\sqrt{\frac{2}{n_{in}+n_{out}}}$，ReLU 再修正到 $\sqrt{\frac{2}{n_{in}}}$）。这一节把这三条公式变成代码——构造四种初始化，让同一份输入穿过 50 层，量出每层输出的标准差，亲眼看到"消失"和"爆炸"是两位数的指数灾难，而 Xavier / He 是数量级稳定的。

脚本只依赖 NumPy，约 40 行，输出印在下方。这里的数字全部真实运行所得（Python 3.11 + NumPy 2.3）。

## 层一：完整脚本

```python
import numpy as np                      # 唯一依赖：NumPy

rng = np.random.default_rng(42)         # 固定随机种子，结果可复现

def propagate(Ws, x, use_relu=False):
    """让输入 x 依次穿过每一层权重，返回每层输出的标准差"""
    stds = []
    for i, W in enumerate(Ws):
        x = x @ W.T                     # 前向传播：y = x @ W^T
        if use_relu and i < len(Ws) - 1:
            x = np.maximum(x, 0.0)      # 除最后一层外，加一道 ReLU
        stds.append(np.std(x))
    return np.array(stds)

def naive_init(n_in, n_out):
    """朴素初始化：标准正态 σ=1，权重太大"""
    return rng.normal(0.0, 1.0, (n_out, n_in))

def small_init(n_in, n_out):
    """朴素初始化：均匀小值 ±0.05，权重太小"""
    return rng.uniform(-0.05, 0.05, (n_out, n_in))

def xavier_init(n_in, n_out):
    """Xavier：均匀分布，边界 a = sqrt(6 / (n_in + n_out))"""
    a = np.sqrt(6.0 / (n_in + n_out))
    return rng.uniform(-a, a, (n_out, n_in))

def he_init(n_in, n_out):
    """He：正态分布，标准差 σ = sqrt(2 / n_in)"""
    return rng.normal(0.0, np.sqrt(2.0 / n_in), (n_out, n_in))

L = 50                                  # 网络深度：50 层
n = 256                                 # 每层 256 个神经元
x0 = rng.normal(0.0, 1.0, (64, n))      # 输入：64 个样本、256 维，σ=1

# ---- ① 纯线性链：不同初始化下，信号穿过 50 层后还剩多大 ----
for name, init in [("naive(σ=1)", naive_init),
                   ("small(±0.05)", small_init),
                   ("xavier", xavier_init)]:
    stds = propagate([init(n, n) for _ in range(L)], x0.copy())
    print(f"{name}: 首层 σ={stds[0]:.3f}   第50层 σ={stds[-1]:.3e}")

# ---- ② 加 ReLU：Xavier 会消失，He 能稳住 ----
for name, init in [("xavier", xavier_init), ("he", he_init)]:
    stds = propagate([init(n, n) for _ in range(L)], x0.copy(), use_relu=True)
    print(f"{name}: 首层 σ={stds[0]:.3f}   第50层 σ={stds[-1]:.3e}")

# ---- ③ 单层验证：n_in=4 的 Xavier，对 500 次随机初始化取平均 ----
mean_var = 0.0
for _ in range(500):
    W4 = xavier_init(4, 4)
    x4 = rng.normal(0.0, 1.0, (1000, 4))
    mean_var += ((x4 @ W4.T) ** 2).mean()
print(f"n_in=4: a={np.sqrt(6/8):.4f}   500 次初始化的平均 E[Var(y)] = {mean_var/500:.4f}（理论值 1）")
```

运行输出（Python 3.11 + NumPy 2.3，种子 42）：

```text
naive(σ=1): 首层 σ=16.129   第50层 σ=1.621e+60
small(±0.05): 首层 σ=0.468   第50层 σ=1.696e-17
xavier: 首层 σ=1.006   第50层 σ=1.027e+00
xavier: 首层 σ=0.591   第50层 σ=4.094e-08
he: 首层 σ=0.826   第50层 σ=3.767e-01
n_in=4: a=0.8660   500 次初始化的平均 E[Var(y)] = 0.9988（理论值 1）
```

先看三行就够你记一辈子：**σ=1 的随机权重 50 层后是 1.6 的 60 次方（爆炸）；±0.05 的小权重 50 层后是 1.7 的负 17 次方（消失）；Xavier 是 1.03（纹丝不动）。** 下面把每一步拆开看。

## 层二：分步逐函数拆解

### 步骤 1：固定随机种子 `np.random.default_rng`

```python
rng = np.random.default_rng(42)
```

#### `np.random.default_rng(seed)` —— 造一个可复现的随机数生成器

**做什么**：生成一个 NumPy 随机数生成器对象 `Generator`。本课所有"随机初始化"都从它身上取数。
**操作**：以 `42` 为种子初始化底层伪随机算法（PCG64）。种子相同，生成器产出的整条随机序列完全相同。
**输入**：`seed`——一个整数（`42`）。传 `None` 时用系统熵，每次运行序列都不同。
**输出**：`Generator` 对象。之后所有 `rng.normal(...)`、`rng.uniform(...)` 都由它产生。
**可调参数**：
- `seed` 可以是任意整数、整数数组或 `None`。深度学习里"固定种子"是复现实验的第一行代码——同一份脚本、同一个种子，才能跑出同一份结果。
- 对比旧接口 `np.random.seed(0)`：旧接口修改的是**全局**随机状态，影响程序里所有 `np.random` 调用；`default_rng` 是**独立**生成器，互不污染，是现代 NumPy 的推荐用法。

### 步骤 2：前向传播函数 `propagate`

```python
def propagate(Ws, x, use_relu=False):
    stds = []
    for i, W in enumerate(Ws):
        x = x @ W.T
        if use_relu and i < len(Ws) - 1:
            x = np.maximum(x, 0.0)
        stds.append(np.std(x))
    return np.array(stds)
```

**做什么**：模拟 $L$ 层前向传播，返回**每一层输出标准差**组成的序列——这就是"信号走到第几层还剩多大"的体检报告。
**操作**：对列表里每个权重矩阵 `W`，执行一次 `x = x @ W.T`（前向），记录 `np.std(x)`，可选在最后一层之前加一道 ReLU。
**输入**：`Ws`——权重矩阵的列表，每个元素形状 `(n, n)`（本课各层同宽）；`x`——形状 `(64, n)` 的输入。
**输出**：`stds`——形状 `(L,)` 的一维数组，`stds[k]` 是第 $k$ 层输出的标准差。
**可调参数**：
- `use_relu`：`True/False`，是否在每层之间插入 ReLU。`True` 时可以看到"Xavier 在 ReLU 下失效、He 生效"的对照。
- 若网络各层宽度不同，只要传入的 `W` 形状与 `x` 的维度匹配即可——`@` 会自动对齐内维。
**对应数学**：主线公式 $\mathbf{y} = \mathbf{W}\mathbf{x}$ 的逐层执行，以及"每层缩放因子"的度量。

#### `x @ W.T` —— 矩阵乘法（前向传播）

**做什么**：把批次数据 `x` 与权重矩阵 `W` 做矩阵乘法，得到本层输出。
**操作**：形状 `(64, n)` 的 `x` 右乘形状 `(n, n)` 的 `W.T`，内维 `n` 对齐，结果形状 `(64, n)`。第 $i$ 行第 $j$ 列元素 = $\sum_k x[i,k] \cdot W[j,k]$——正是主线的 $y_j = \sum_k w_{jk} x_k$。
**输入**：`x` `(64, n)`（64 个样本、每样本 $n$ 维）、`W` `(n, n)`。
**输出**：`(64, n)`。第 0 维仍是"样本数"，第 1 维仍是"特征数"——形状语义在传播前后保持一致。
**可调参数**：左乘 `W @ x` 也合法，但那要求 `W` 形状 `(n, 64)`，语义完全不同；本课统一用 `x @ W.T` 的"行向量视角"约定。
**对应数学**：主线 $\text{Var}(y_i) = n_{in}\sigma_w^2\sigma_x^2$ 中"$n_{in}$ 个独立乘积求和"这一步的批量实现。

#### `np.maximum(x, 0.0)` —— ReLU 激活

**做什么**：逐元素取 $\max(x, 0)$——负值全部置零，正值原样保留。
**操作**：对形状 `(64, n)` 的数组逐元素比较。约一半元素被置 `0`，这正是主线说的"ReLU 砍掉一半能量"。
**输入**：任意形状数组 + 标量 `0.0`。
**输出**：与输入形状相同的数组。
**可调参数**：第二参数可以是任意标量（如 `np.maximum(x, 0.1)` 就是 Leaky ReLU 的雏形），也可以是数组（逐元素阈值）。
**对应数学**：主线撞墙三——ReLU 把二阶矩减半，逼出了 He 的因子 2。

#### `np.std(x)` —— 标准差

**做什么**：计算数组所有元素的标准差：$\sqrt{\frac{1}{N}\sum (x_i - \bar{x})^2}$，$N$ 是元素总数。
**输入**：形状 `(64, n)` 的数组。
**输出**：标量。
**可调参数**：
- `axis`：沿某一维求（如 `np.std(x, axis=0)` 得到每列的标准差，形状 `(n,)`）。
- `ddof`：默认 `0`（除以 $N$，总体标准差）；`ddof=1` 是样本标准差（除以 $N-1$）。本课 64×256 个样本，两者差别可忽略。
**对应数学**：主线"每层缩放因子"的数字化身——首层 σ 与第 50 层 σ 的比值，就是 50 次"接力"的总缩放。

### 步骤 3：四个初始化函数

```python
def naive_init(n_in, n_out):
    return rng.normal(0.0, 1.0, (n_out, n_in))

def small_init(n_in, n_out):
    return rng.uniform(-0.05, 0.05, (n_out, n_in))

def xavier_init(n_in, n_out):
    a = np.sqrt(6.0 / (n_in + n_out))
    return rng.uniform(-a, a, (n_out, n_in))

def he_init(n_in, n_out):
    return rng.normal(0.0, np.sqrt(2.0 / n_in), (n_out, n_in))
```

#### `rng.normal(loc, scale, size)` —— 正态分布随机权重

**做什么**：从正态分布 $\mathcal{N}(\text{loc}, \text{scale}^2)$ 抽取一个形状为 `size` 的随机数组——权重矩阵的"原料"。
**操作**：每个元素独立抽取。`naive_init` 取 `scale=1`（标准差 1），`he_init` 取 `scale=np.sqrt(2.0/n_in)`。
**输入**：`loc=0.0`（均值）、`scale`（标准差）、`size=(n_out, n_in)`。
**输出**：形状 `(n_out, n_in)` 的数组——这就是一个权重矩阵 $\mathbf{W}$：**每一行是一个神经元的 $n_{in}$ 个权重**（$n_{out}$ 行 = $n_{out}$ 个神经元）。
**可调参数**：
- `scale` 就是主线里的 $\sigma_w$——本课所有"初始化选多大"都归结为这个数。
- `size` 可以是任意形状（如 `(4,4,3)` 得到三维张量，卷积核初始化会用到）。
- 想用均匀分布初始化，见下面的 `rng.uniform`。
**对应数学**：主线 $\sigma_w = \sqrt{2/n_{in}}$（He）的具体填充。

#### `rng.uniform(low, high, size)` —— 均匀分布随机权重

**做什么**：从区间 $[\text{low}, \text{high})$ 的均匀分布抽取形状为 `size` 的随机数组。
**操作**：每个元素独立抽取。`small_init` 取 `low=-0.05, high=0.05`；`xavier_init` 取 `low=-a, high=a`，其中 $a=\sqrt{6/(n_{in}+n_{out})}$。
**输入**：`low`、`high`（区间端点）、`size=(n_out, n_in)`。
**输出**：形状 `(n_out, n_in)` 的数组。
**可调参数**：
- 区间端点决定权重范围；均匀分布 $\mathcal{U}[-a,a]$ 的**方差是 $a^2/3$**——这就是主线里 $a=\sqrt{6/(n_{in}+n_{out})}$ 的来历（令 $a^2/3 = 2/(n_{in}+n_{out})$）。
- `size` 同样可以是任意形状。
**对应数学**：主线 Xavier 定义块中的 $\mathcal{U}\left[-\sqrt{6/(n_{in}+n_{out})},\,\sqrt{6/(n_{in}+n_{out})}\right]$。

### 步骤 4：主流程 ① 纯线性链对比

```python
for name, init in [("naive(σ=1)", naive_init),
                   ("small(±0.05)", small_init),
                   ("xavier", xavier_init)]:
    stds = propagate([init(n, n) for _ in range(L)], x0.copy())
    print(f"{name}: 首层 σ={stds[0]:.3f}   第50层 σ={stds[-1]:.3e}")
```

**做什么**：用三种初始化各生成 50 个权重矩阵，让同一份输入依次穿过，打印首层与末层的输出标准差。
**操作**：`[init(n, n) for _ in range(L)]` 生成 50 个独立的 `(256, 256)` 权重矩阵——`n_in=n_out=256`，所以 Xavier 的均匀边界 $a=\sqrt{6/512}\approx 0.108$。
**输出**（真实运行）：
- `naive(σ=1)`：首层 σ=16.13（每层放大 $\sqrt{256}\approx 16$ 倍），50 层后 $16^{50} \approx 1.6 \times 10^{60}$。
- `small(±0.05)`：首层 σ=0.468（每层缩到约 0.47 倍），50 层后 $0.47^{50} \approx 1.7\times 10^{-17}$。
- `xavier`：首层 σ=1.006，50 层后 σ=1.027——**纹丝不动**。这正是主线手算 $\text{Var}(y_i)=n_{in}\sigma_w^2\sigma_x^2=1$ 的实证。
**可调参数**：把 `L` 改成 10 或 100，可以直观看到"灾难随深度呈指数累积"——10 层时 naive 还是 $\sim 10^{12}$，100 层就爆成 $\sim 10^{120}$。

### 步骤 5：主流程 ② ReLU 链对比

```python
for name, init in [("xavier", xavier_init), ("he", he_init)]:
    stds = propagate([init(n, n) for _ in range(L)], x0.copy(), use_relu=True)
    print(f"{name}: 首层 σ={stds[0]:.3f}   第50层 σ={stds[-1]:.3e}")
```

**做什么**：同一场景，但每层之间插入 ReLU，比较 Xavier 与 He。
**输出**（真实运行）：
- `xavier` + ReLU：首层 σ=0.591，50 层后 σ=4.09e-08——**消失**。原因：ReLU 每层砍掉约一半能量，Xavier 没有预留补偿。
- `he` + ReLU：首层 σ=0.826，50 层后 σ=0.377——**数量级稳定**。因子 2 的补偿让能量逐层守恒。
**对应数学**：主线撞墙三——ReLU 的二阶矩减半，逼出 He 的 $\sigma_w^2=2/n_{in}$。
**可调参数**：把 `np.maximum(x, 0.0)` 换成 `np.maximum(x, 0.01*x)`（Leaky ReLU），可以看到 He 的稳定区间变宽——这正是主线边界声明里"Leaky ReLU 的最佳系数介于 1 与 2 之间"的出处。

### 步骤 6：主流程 ③ 单层期望验证

```python
mean_var = 0.0
for _ in range(500):
    W4 = xavier_init(4, 4)
    x4 = rng.normal(0.0, 1.0, (1000, 4))
    mean_var += ((x4 @ W4.T) ** 2).mean()
print(f"n_in=4: a={np.sqrt(6/8):.4f}   500 次初始化的平均 E[Var(y)] = {mean_var/500:.4f}（理论值 1）")
```

**做什么**：回到主线的 $n_{in}=4$ 手算，验证"方差保持"是**期望意义**上的。
**操作**：500 次独立随机初始化，每次让 $4\times 4$ 的 Xavier 权重作用在 1000 个随机输入上，计算输出二阶矩 $E[y^2]$。因为输入零均值、权重零均值，$E[y^2]=\text{Var}(y)$，正好对主线公式 $\text{Var}(y_i)=n_{in}\sigma_w^2\sigma_x^2$ 求期望。
**输出**（真实运行）：`a=0.8660`，500 次平均 `E[Var(y)]=0.9988`，逼近理论值 1。
**可调参数**：
- 把循环次数从 500 改成 10，会看到单次结果在 0.7–1.4 之间波动——**单次随机初始化有抽样误差，期望才等于理论值**。这解释了为什么 4×4 的一次性手算会偏离 1。
- 把 `xavier_init(4,4)` 换成 `naive_init(4,4)`，平均 `E[Var(y)]` 会变成 4——每层放大 2 倍，正是爆炸的起点。
**对应数学**：主线手算验证 $\text{Var}(y_i)=4\times 0.25\times 1=1$。

## 边界声明：这套代码能做什么，不能做什么

1. **这里没有训练。** 脚本只跑前向传播、量标准差，没有损失、没有梯度、没有反向传播。它演示的是"梯度消失/爆炸的**前向根源**"——信号本身的尺度。梯度的反向会穿过同一套闸门，结论方向一致（这也是历史里 Glorot 分析的完整图景），但要真正看到梯度，需要搭一个带 `backward` 的训练循环（§2.5 之后的课程）。
2. **方差保持是期望意义，不是单次保证。** 一次随机初始化，哪怕公式完全正确，抽样误差也会让输出方差在理论值附近晃动；只有对多次独立初始化取平均，才精确收敛（步骤③）。别因为"一次跑出来不是正好 1"而怀疑公式。
3. **He 校准的是"能量"而非严格"方差"。** ReLU 之后分布不再零均值，所以 He 的推导用的是二阶矩 $E[y^2]$；如果你用 `np.var` 去量 ReLU 后的输出，数值会偏低（约 0.34 倍），这是分布偏斜造成的，不是初始化错了。
4. **本课只初始化权重矩阵，没有碰偏置。** 真实框架里 bias 单独初始化为 0，不随权重一起随机——因为偏置的"对称性"影响与权重不同，乱设反而添乱。
5. **别在生产里手写这些循环。** PyTorch 的 `torch.nn.init.xavier_uniform_` / `kaiming_normal_` 和 Keras 的 `GlorotUniform` / `HeNormal` 就是本课公式的现成实现。本脚本的意义是**看清公式内部在做什么**，而不是替代框架。
