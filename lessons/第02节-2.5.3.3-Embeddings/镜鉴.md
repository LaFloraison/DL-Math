# 镜鉴：词嵌入

## 一、数学之美

一个离散的符号，被放进连续空间，语义结构竟然原样保留——这是嵌入矩阵最动人的地方。$\mathbf{E} \in \mathbb{R}^{V \times d}$ 只是一张表，却拥有线性代数全部的力量：行是词，行与行的夹角是语义的亲疏，整个词表是 $\mathbb{R}^d$ 里的一个星座。one-hot 把词推成十万个互相垂直的孤岛；embedding 把它们放进同一片可以度量、可以求导、可以加减的海。而这一切的起点，是一次朴素到极致的"取行"——因为写成 $\mathbf{e}_i^{\top}\mathbf{E}$，查表就从字典变成了变换。美在于：**最朴素的操作，只要被写成线性运算，就变得可训练、可批量、可组合。**

## 二、DL 中的意义

嵌入是深度学习"让符号可计算"的总开关。没有它，语言进不了梯度下降；有了它，词的语义第一次成为可以被优化的目标。在 Transformer 里，$\mathbf{E}$ 是每一行 token 的起点，$\mathbf{Q} = \mathbf{X}\mathbf{W}_Q$ 的一切都从它出发——整个注意力机制，建立在"词能放进向量空间"这个前提上。embedding 还重塑了学习观：**语义不是被定义出来的，是被数据长出来的。** 没有人告诉机器"猫和狗是同类"，它只是反复看到它们出现在相似的上下文，便自己靠拢了。

## 三、人的映射

嵌入矩阵告诉我们一件近乎残忍又温柔的事：**一个东西的意义不在它自身，而在它与所有其他东西的关系网络。** cat 和 dog 靠近，不是因为谁标注了它们同义，而是因为它们总出现在相同的位置。人也一样——一个词被上下文定义，一个人被与他人的关系定义。而 $\mathbf{E}$ 的任何一行都不可逐维解释：第 3 个分量不代表任何东西，意义是整体几何的涌现。这提醒我们：有时你无法指着某个人说"他的本质是这个"，本质或许藏在他与所有他人的距离之和里。

## 四、开放问题

如果有一天我们能画出全部人类概念的嵌入空间，它的形状会透露什么？我们或许会发现机器学到的"距离"与直觉惊人一致——但也可能发现，它编码的是共现与统计，而不是我们自以为的"意义"。那么问题来了：**当机器说 cat 和 dog 很相似，而人类说它们都是宠物时，两套相似性谁更接近"真实"？** 或者说，"真实"这个词，本身就只存在于某一种嵌入里？
