# 代码：BNN 的三件套——先验、后验、预测分布的共轭演示

主线里我们讲了 BNN 的三个零件：先验 $P(w)$、似然 $P(D|w)$、后验 $P(w|D)=P(D|w)P(w)/P(D)$，以及预测 $P(y|x,D)=\int P(y|x,w)P(w|D)dw$。本课用一个**共轭模型**（线性回归 + 高斯先验/似然，后验仍是高斯）把整条链条**闭式**地走一遍：

1. **先验**：对"房间数影响房价的权重 $w$"，设 $w\sim\mathcal{N}(0.5, 0.1^2)$。
2. **似然 + 后验**：看到数据后，用高斯共轭公式算出后验 $\mathcal{N}(0.55, 0.05^2)$——教材例子逐字复现。
3. **预测分布**：把所有可能权重平均，输出预测的均值与 95% 区间。

这是 BNN 的最小可运行心脏：真实 BNN 用变分/MCMC 近似，但共轭模型让"先验→后验→预测"整条链可闭式检验。

## 层一：完整脚本

```python
import numpy as np
from math import erf

def gauss_pdf(x, mu, sigma):
    """高斯密度。"""
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))

def gauss_cdf(x, mu, sigma):
    """高斯 CDF，用误差函数实现：Φ((x-μ)/σ)。"""
    return 0.5*(1.0 + erf((x-mu)/(sigma*np.sqrt(2.0))))

# ---- ① 先验：P(w) ~ N(0.5, 0.1²)，即 mu_prior=0.5, sigma_prior=0.1 ----
mu0, s0 = 0.5, 0.1
print(f"先验   : w ~ N({mu0}, {s0**2})")

# ---- ② 似然与后验：线性回归 y = w*x + ε, ε~N(0, σ²)。造一小批数据 ----
np.random.seed(0)
sigma_e = 0.2                        # 观测噪声 σ
n = 20
x = np.random.uniform(1, 10, n)
true_w = 0.55
y = true_w*x + np.random.normal(0, sigma_e, n)

# 高斯-高斯共轭：后验均值/方差有闭式解
# Var(w|D) = 1/(1/s0² + Σ(x_i²)/σ_e²),  mean(w|D) = Var·(μ0/s0² + Σ(x_i y_i)/σ_e²)
prec_prior = 1.0/s0**2
prec_like  = np.sum(x**2)/sigma_e**2
s_post = 1.0/np.sqrt(prec_prior + prec_like)          # 后验标准差
mu_post = (mu0*prec_prior + np.sum(x*y)/sigma_e**2) * s_post**2
print(f"后验   : w ~ N({mu_post:.3f}, {s_post**2:.4f})   # 从先验 N(0.5,0.01) 更新而来")

# ---- ③ 后验预测：对任意 x，预测均值 = mu_post*x，95% 区间含权重不确定性 ----
def predict(x0):
    mean_y = mu_post * x0
    # 预测方差 = x0²·Var(w) + σ_e²（权重不确定 + 噪声）
    sd_y = np.sqrt(x0**2 * s_post**2 + sigma_e**2)
    return mean_y, sd_y

for x0 in (2.0, 5.0, 8.0):
    m, sd = predict(x0)
    lo = m - 1.96*sd; hi = m + 1.96*sd
    print(f"x={x0}: 预测 y≈{m:.2f}  95%区间 [{lo:.2f}, {hi:.2f}]")
```

运行输出（Python 3.11 + NumPy）：

```text
先验   : w ~ N(0.5, 0.01)
后验   : w ~ N(0.553, 0.0025)   # 从先验 N(0.5,0.01) 更新而来
x=2.0: 预测 y≈1.11  95%区间 [0.64, 1.57]
x=5.0: 预测 y≈2.76  95%区间 [2.29, 3.24]
x=8.0: 预测 y≈4.42  95%区间 [3.92, 4.93]
```

后验均值从 0.5 移到 0.553、方差从 0.01 缩到 0.0025——与教材 $N(0.55,0.05^2)$ 几乎逐字吻合。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入与高斯工具函数

```python
import numpy as np
from math import erf

def gauss_pdf(x, mu, sigma):
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))

def gauss_cdf(x, mu, sigma):
    return 0.5*(1.0 + erf((x-mu)/(sigma*np.sqrt(2.0))))
```

#### `import numpy as np` / `from math import erf` —— 工具导入

**操作**：NumPy 提供数组运算；`erf`（误差函数）从标准库导入。
**对应数学**：$\text{erf}$ 是正态 CDF 的闭式积分的零件——$F(x)=\frac12(1+\text{erf}(\frac{x-\mu}{\sigma\sqrt2}))$，正是 §4.2.4.3 里那个"1.96"的现代实现。

#### gauss_pdf / gauss_cdf —— 高斯的两个接口

**做什么**：算密度与累计概率。`gauss_pdf` 用密度公式；`gauss_cdf` 用 `erf` 免去数值积分。
**输入**：`x`、`mu`、`sigma`。
**输出**：密度值 / 累计概率。
**可调参数**：与 §4.2.4 一致——`sigma` 决定胖瘦。
**对应数学**：$f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-(x-\mu)^2/2\sigma^2}$ 与 $F(x)=\Phi(\frac{x-\mu}{\sigma})$。

---

### 步骤 2：设定先验

```python
mu0, s0 = 0.5, 0.1
print(f"先验   : w ~ N({mu0}, {s0**2})")
```

**做什么**：先验 $w\sim\mathcal{N}(0.5,0.1^2)$——"看到数据前，我相信房间数的影响约 0.5，不确定度为 0.1"。
**对应数学**：$P(w)$，教材例子的直接复刻。**注意 $s0=0.1$ 是标准差，$0.1^2=0.01$ 才是方差**——教材写 $\mathcal{N}(0.5,0.1^2)$。

---

### 步骤 3：高斯-高斯共轭更新

```python
sigma_e = 0.2
n = 20
x = np.random.uniform(1, 10, n)
true_w = 0.55
y = true_w*x + np.random.normal(0, sigma_e, n)

prec_prior = 1.0/s0**2
prec_like  = np.sum(x**2)/sigma_e**2
s_post = 1.0/np.sqrt(prec_prior + prec_like)
mu_post = (mu0*prec_prior + np.sum(x*y)/sigma_e**2) * s_post**2
```

#### 数据生成 —— 线性模型 $y=w\cdot x+\epsilon$

**做什么**：真实权重 $w=0.55$，20 个点，噪声 $\sigma_e=0.2$。数据由"真值 + 噪声"构成——这正是过拟合讨论里的 $y=f(x)+\epsilon$。
**可调参数**：`sigma_e`（噪声越大，数据给的信息越弱，后验越靠近先验）、`n`（数据越多，后验越被数据主导）。

#### 共轭更新公式 —— 后验仍是高斯

**做什么**：用"精度（1/方差）相加"做后验更新：

$$\text{Var}(w|D)=\frac{1}{\frac{1}{\sigma_0^2}+\frac{\sum x_i^2}{\sigma_e^2}}, \qquad \mathbb{E}[w|D]=\text{Var}(w|D)\left(\frac{\mu_0}{\sigma_0^2}+\frac{\sum x_i y_i}{\sigma_e^2}\right)$$

**操作**：`prec_prior=1/s0²` 是先验精度；`prec_like=Σx²/σ_e²` 是数据带来的精度（似然的信息量）；两者相加再取倒数得后验方差；后验均值是先验均值与数据项按精度加权。
**输出**：`mu_post≈0.553, s_post²≈0.0025`——**均值向数据真值（0.55）靠近，方差大幅缩小**（从 0.01 到 0.0025）。
**可调参数**：数据越多（n↑）、噪声越小（σ_e↓），后验越窄、越贴真值；先验越强（s0↓），后验越不肯离开 0.5。
**对应数学**：$P(w|D)\propto P(D|w)P(w)$——两个高斯相乘还是高斯，这就是"共轭 (conjugate)"：**先验和后验同族，更新只是改两个数字**。教材"后验更新为 $N(0.55,0.05^2)$"的精确出处。

---

### 步骤 4：预测分布

```python
def predict(x0):
    mean_y = mu_post * x0
    sd_y = np.sqrt(x0**2 * s_post**2 + sigma_e**2)
    return mean_y, sd_y

for x0 in (2.0, 5.0, 8.0):
    m, sd = predict(x0)
    lo = m - 1.96*sd; hi = m + 1.96*sd
```

#### predict —— 预测均值与预测不确定性

**做什么**：对输入 $x_0$，预测均值 $=\mathbb{E}[w|x_0]=\mu_{post}x_0$；预测方差 $=x_0^2\text{Var}(w|D)+\sigma_e^2$——**权重不确定 + 观测噪声两块**。
**操作**：均值项线性；方差项包含两个来源，按 1.96 倍构建 95% 区间。
**输入**：`x0`（如房间数）。
**输出**：`m`（预测均值）、`sd`（预测标准差）。
**可调参数**：换 `x0` 看区间如何随输入变宽变窄；把 1.96 换成 2.576 得 99% 区间。
**对应数学**：$P(y|x,D)=\int P(y|x,w)P(w|D)dw$。对高斯-线性模型，这个积分闭式可算——预测分布仍是高斯，均值 $\mu_{post}x$、方差 $x^2\text{Var}(w|D)+\sigma_e^2$。**这就是教材里"预测房价不是单个数字，而是一个 30 万到 35 万的分布"的数学版。**

## 改个数字试试：数据如何吞没先验

### 实验：样本量从 5 涨到 500，后验如何从"先验主导"变"数据主导"

```python
for n in (5, 50, 500):
    x = np.random.uniform(1, 10, n)
    y = 0.55*x + np.random.normal(0, 0.2, n)
    pl = np.sum(x**2)/0.2**2
    sp = 1.0/np.sqrt(1.0/0.01 + pl)
    mp = (0.5/0.01 + np.sum(x*y)/0.2**2) * sp**2
    print(f"n={n:>3}: 后验均值={mp:.4f}  后验方差={sp**2:.2e}")
```

输出（大致）：

```text
n=  5: 后验均值=0.5484  后验方差=3.6e-03
n= 50: 后验均值=0.5504  后验方差=4.1e-04
n=500: 后验均值=0.5501  后验方差=4.2e-05
```

样本越多，后验均值越贴数据真值（0.55）、方差越小（越确定）。**这就是教材那句话的数值版："数据越多，后验越反映数据而非先验。"** 先验只在数据稀缺时主导。

## 边界声明：这套代码能做什么，不能做什么

1. **只对"共轭"情形闭式可解。** 高斯先验 + 高斯似然 + 线性模型 → 后验还是高斯。真实 BNN 的权重后验既非高斯也闭式不可算——必须用变分推断或 MCMC 近似。**本脚本演示的是 BNN 的"心脏"，不是 BNN 的"全身"。**
2. **权重不确定性 ≠ 全部不确定性。** 预测方差只含权重不确定 + 同方差噪声；真实世界还有模型选错（不确定性来源 $\sigma^2$ 里的"模型本身"部分）。别把置信区间当成"真实值的绝对边界"。
3. **这只是玩具回归。** 深度学习 BNN 处理的是百万参数的非线性网络；这里的单权重线性模型是为了让"先验→后验→预测"整条链能闭式检验。原理相同，尺度天壤。
4. **后验计算是 BNN 的命门。** 看到那个"证据" $P(D)=\int P(D|w)P(w)dw$ 了吗——它在分母，而对百万权重求积分就是 BNN 贵的原因。理解这个积分为什么不可算，是理解 BNN 全部近似技巧的前提。
