## 第一步：Toy Model —— 找不到的整数最优

你是一家小作坊的老板，做两种家具。利润：小桌（$x_1$）每件赚 3 元，木椅（$x_2$）每件赚 2 元。约束：

- **木料**：$2x_1 + 3x_2 \le 12$
- **工时**：$2x_1 + x_2 \le 9$
- **产量必须是整数**：$x_1, x_2 \in \mathbb{Z}_{\ge 0}$

（这是 §5.3.3 那个"整数世界"的延续——你不能做半张桌子。）

你先把整数约束扔掉，解 LP 松弛（§5.3.3 教过）：最优解是 $x_1 = 3.75, x_2 = 1.5$，利润 $Z = 14.25$。**但 3.75 张小桌是造不出来的。** 这是整数问题的"宽松上界"——任何整数解都不可能超过 14.25。

现在你有两条路，代表整数优化的两大家族：

**路线一：把问题劈开。** 松弛解里 $x_1 = 3.75$ 不是整数——那真正的整数解，$x_1$ 要么 $\le 3$，要么 $\ge 4$（没有中间地带）。你把这个分支当灵感，把原问题**劈成两个子问题**：一个强制 $x_1 \le 3$，一个强制 $x_1 \ge 4$。分别求解：
- 分支 $x_1 \le 3$：最优在 $(3,2)$，利润 $3\times3 + 2\times2 = 13$。
- 分支 $x_1 \ge 4$：最优在 $(4,1)$，利润 $3\times4 + 2\times1 = 14$。

取两者更好者：**$(4,1)$，14 元**。而 14 元 vs 松弛的 14.25——**那个 0.25 的差距，就是"必须整数"的代价。**

**路线二：把墙往里推。** 你盯着松弛最优 $(3.75, 1.5)$——它不在整数格点上。你问：能不能**加一条新的约束线**，把 $(3.75,1.5)$ 这个"非整数角落"切掉，同时不伤害任何整数可行点？你试了 $x_1 + x_2 \le 5$：所有整数可行点都满足（最大的 $x_1+x_2$ 正好是 $(4,1)$ 和 $(3,2)$ 的 5），而 $(3.75,1.5)$ 的 $3.75+1.5 = 5.25 > 5$——**被切掉了！** 加完这条"割平面"，重新解 LP，最优立刻变成 $(4,1)$，14 元。

**两条路线，同一个答案。** 劈开（分支）和切墙（割平面），是整数优化对抗指数爆炸的两把刀。现在问一个"浅到可笑"的问题：**"分支"该往哪劈？"割平面"该切哪一刀？怎么判断一个分支或一条切法"没希望"就扔掉，从而避免把整个格点网搜一遍？** 该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：整数问题的"上界"是免费的礼物

整数优化的敌人是 §5.3.5 的组合爆炸。但敌人有个弱点：**LP 松弛的解，是整数问题的一个"免费上界"。** 因为整数问题是"在更小的集合（格点）上优化"，它的最优值不可能超过"在更大的集合（连续区域）上优化"的 LP 松弛值。

$$Z_{\text{IP}} \le Z_{\text{LP 松弛}}$$

这个上界值钱在哪里？**它让"剪枝"成为可能**：如果某个子问题的 LP 松弛值已经比不上"目前已找到的最好整数解"，那这个子问题里的**所有**整数点都不可能反超——它可以直接被扔掉，连看都不用看。

这就是**分支定界 (branch and bound, B&B)** 的全部引擎。教材把它的三个动作讲得很清楚：

**(a) 分支 (branching)**：把当前问题劈成子问题，形成一棵"解树"。劈法通常是：松弛解中某个分数变量 $x_j$ 取分数值 $v$，则分成"$x_j \le \lfloor v \rfloor$"和"$x_j \ge \lceil v \rceil$"两个分支。**因为整数在 $v$ 的两侧，只能落在这两个范围里**——分支没有漏掉任何整数解。

**(b) 定界 (bounding)**：对每个子问题算 LP 松弛，得到它的上界。如果某子问题的上界**优于**当前最好整数解，才值得继续挖；否则放弃。

**(c) 剪枝 (pruning)**：把"上界已无法超过当前最优"的子问题整棵剪掉，**砍掉指数级的无用搜索**。

> **分支定界 (branch and bound, B&B)**
>
> 物理含义：用"LP 松弛提供上界 + 分数变量分裂 + 剪枝砍掉无望分支"，在指数级整数解空间里系统地逼近最优。
>
> 伪代码：
> ```
> 初始化: best = -∞; 待解集合 Q = {原问题}
> while Q 非空:
>     取出一个子问题 P
>     解 P 的 LP 松弛, 得上界 U 与松弛解 x̃
>     if U <= best: 剪枝 (不可能反超)
>     elif x̃ 全为整数: best = max(best, Z(x̃))  # 更新可行最优
>     else: 取一个分数变量 x_j, 分支成 x_j<=⌊v⌋ 与 x_j>=⌈v⌉, 都放入 Q
> 输出 best
> ```
>
> - 上界来自 LP 松弛（整数问题最优值的免费天花板）
> - 分支分裂不遗漏任何整数解（分数两侧全覆盖）
> - 剪枝是效率的灵魂：每砍掉一个分支，指数搜索就少一块

**每个符号的含义逐一解释：** Toy Model 里，根问题松弛 $Z=14.25$；分支 $x_1\ge4$ 直接解出整数解 $(4,1)$，$best=14$；分支 $x_1\le3$ 的松弛 $Z=13 \le 14$——**虽然它的解碰巧也是整数，但就算不是，它也会因为 $13 < 14$ 被剪掉**。教材 Figure 5.11 的背包树演示了同一过程：从根节点"value=0, weight=0"逐层分"装/不装"两枝，超重的节点标记为"剪枝/不可行"，最终停在"value=190, weight=10"的最优叶。

### 二、割平面法：切墙，而不是劈树

B&B 从"解"上劈。割平面法 (cutting plane method) 从"可行域"上切。教材给出三步：

**(a) 起点**：先解 LP 松弛（忽略整数约束）。
**(b) 检查与切 (Check & Cut)**：看松弛解是不是整数。如果不是，**加一条割平面 (cut)——一条线性不等式，把当前的分数解排除，同时保留所有整数可行点**。
**(c) 迭代**：反复解 + 切，直到得到整数解，或证明整数解不存在。

割平面的精妙在于那条"不伤整数"的约束。Toy Model 的 $x_1 + x_2 \le 5$ 就是一个完美割平面：它砍掉了 $(3.75,1.5)$，却让 $(4,1)$、$(3,2)$ 等所有整数可行点安然无恙。一刀下去，可行域从"含有分数角落"变成"贴着整数格点"。

> **割平面法 (cutting plane method)**
>
> 物理含义：通过不断添加"排除分数解、保留整数点"的线性约束，把 LP 松弛的可行域"修整"成整数问题的可行包络，从而让 LP 解自然落在整数点上。
>
> 迭代：
> 1. 解 LP 松弛 $\max c^Tx$ s.t. $Ax\le b, x\ge0$，得 $x^{(t)}$
> 2. 若 $x^{(t)}$ 全为整数 → 停止，输出
> 3. 否则构造一条**有效割平面** $\alpha^T x \le \beta$：$\alpha^T x^{(t)} > \beta$（切掉分数解）且对所有整数可行点 $\alpha^T x \le \beta$（不误伤）
> 4. 加入约束，回到 1
>
> - 每一步都"收紧"可行域，却不触碰任何整数解
> - Gomory 割平面保证有限步收敛（对纯整数线性规划）
> - 与 B&B 常组合成 **B&C (branch-and-cut)**——现代整数求解器的标配

**每个符号的含义逐一解释：** "有效割平面 (valid inequality)"的两个条件——$\alpha^T x^{(t)} > \beta$ 把当前分数解隔出去，$\alpha^Tx\le\beta$ 对所有整数可行点成立。教材 Figure 5.12 展示了三条约束线围出的可行域上，红色、橙色两条割平面依次切掉非整数区域，最终露出黄色整数最优解。

### 三、撞墙加深：两把刀各自的软肋

**边界声明一：B&B 的快慢，取决于"上界有多紧"。** 如果 LP 松弛的上界很松（离整数最优很远），剪枝就无力，树会爆炸。玩具例子里上界 14.25 只比 14 高一点，所以两刀就砍完；真实问题里上界松的时候，B&B 也要遍历巨大的一棵树。

**边界声明二：割平面不一定好找。** 构造一条"切掉分数解、不伤整数点"的不等式，本身就是一门手艺。Gomory 割平面保证有限收敛（对纯整数 LP），但实践中切得慢；真实求解器大多用更强的"lift-and-project""Chvátal-Gomory"割平面，并且把 B&B 和割平面**组合成 branch-and-cut**——先切几刀让上界变紧，再分支。**现代整数求解器（CPLEX、Gurobi）的默认引擎，就是 B&C 的工程实现。**

**一个诚实的收束：两把刀都不是魔法。** 它们把指数搜索压缩成"可承受的搜索"，但最坏情况仍是 NP-hard（§5.3.3）。**B&B 与割平面是"让指数墙在大多数现实问题上变得可以翻越"的工程艺术**——不是推翻那堵墙，而是把它变成一道能翻的矮墙。

## 第三步：DL 桥接

**分支定界与割平面法在深度学习中不出现在训练循环里，但它们的"搜索 + 剪枝"思想，渗透进了深度学习的推理与离散优化。**

**其一：beam search 是 B&B 的近亲。** §5.3.5 提过，Transformer 解码时用束宽 K 的 beam search 选最优序列。beam search 和 B&B 共享同一种"树搜索 + 剪枝"骨架：树是生成的 token 序列树，剪枝是"每步只保留分数最高的 K 个节点"——**束宽 K 就是"剪枝强度"**。K=1 是纯贪心（剪到极致），K=∞ 是暴力（不剪枝）。深度学习的推理，每天都在做 B&B 式的搜索。

**其二：神经架构搜索 (NAS) 的离散搜索。** NAS 要在指数级的网络结构空间里搜最优结构——早期的进化算法 NAS、强化学习 NAS 都是"元启发式"的树搜索；而 DARTS 用连续松弛绕开离散（§5.3.3 讲过），正是因为在离散空间里"分支 + 剪枝"的精确方法面对神经网络这种巨大解空间也无能为力。**理解 B&B 的"上界剪枝"，你就理解了为什么 NAS 要换思路。**

**其三：AlphaGo 的 MCTS 是一棵"概率版 B&B"。** 蒙特卡洛树搜索在博弈树上做搜索，用"胜率估计"当上界来剪枝——它不保证最优（下棋无法枚举），但用"近似上界"把搜索导向最有希望的子树。**MCTS 的思想血脉里，流淌着 B&B"用上界砍掉无望分支"的基因。**

**一句话收束：分支定界与割平面，是整数优化对抗指数爆炸的两把刀**——一把劈开解空间，一把切掉可行域。它们不在深度学习训练的循环里，却以 beam search、MCTS、NAS 的形态，活在深度学习推理与搜索的每一个角落。具体如何用代码加一条割平面、劈两个分支，验证 $(4,1)$ 与 14，见《代码.md》。
