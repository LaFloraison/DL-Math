# §11.2.1.2 连续动力系统 —— 习题

主线把连续动力系统 $\frac{dx}{dt}=f(x)$ 讲成"没有下一步、只有此刻的变化率"，用指数增长 $\frac{dx}{dt}=0.5x$ 解出 $100e^{0.5t}$，并给出欧拉法这座"连续↔离散"的桥。习题分三组：**概念检验** 验证连续与离散的区别及解的结构，**计算实践** 手算指数增长并做欧拉法代码对照，**DL 延伸** 把梯度流与 Neural ODE 放回连续视角。

---

## 一、概念检验

### 题 1（选择）：连续动力系统给出的"解"是什么？

解微分方程 $\frac{dx}{dt} = 0.5x$，得到的"解"是以下哪一项？

- A. 一个数字，比如 $x = 448.17$
- B. 一个函数 $x(t) = x_0 e^{0.5t}$，满足方程的每一点
- C. 一个常数，$x = 0.5$
- D. 一条直线 $x = 0.5t$

**解答**：B。

微分方程的解是一个**函数**——它在每个时刻的值代入方程都成立。$x(t) = x_0e^{0.5t}$ 就是解族：取不同的 $x_0$（初始条件），得到不同的具体解。A 是"某个时刻的值"（解在一点上的值，不是解本身）；C 是方程右端的系数；D 是一条匀速直线——但它不满足方程（$x'=0.5 \ne 0.5x$）。

**思路点拨**：抓住"微分方程的解是函数不是数字"。这是 §11.2 定义块里"解：一个函数（不是数字）"的考点。判断方法：把候选代进方程，两边相等吗？D 不相等，B 相等。

### 题 2（判断 + 简答）：连续和离散，是"差不多"还是"差很多"？

有人说："把离散动力系统的步长取小一点，就变成连续动力系统了，所以两者就是精度问题。" 判断并解释。

**解答**：方向对，但要精确。**离散系统可以"逼近"连续系统**（欧拉法就是例子），连续系统也可以被离散化近似；但两者不是"精度差"那么简单。离散系统的状态**只在一串离散时刻上存在**，演化规则是"位置→位置"；连续系统的状态**在每一瞬间都存在**，演化规则是"位置→变化率"。它们的区别是**描述方式的不同**，不是"粗还是细"。$\lim_{n\to\infty}(1+1/n)^n = e$ 说明离散复利在极限处等于连续复利——但极限本身是一个**新的对象**，不是"更细的离散"。

**思路点拨**：这道题考"极限 ≠ 等同"。最强的一击是教材图 11.1：两条轨迹在平缓处几乎重合、在陡峭处分开——如果只是"精度问题"，分开就不会系统性出现。正确说法：离散是连续的一种**近似/抽样**，连续是离散的**极限对象**。

### 题 3（简答）：为什么初始条件 $x(0)=100$ 这么重要？

$\frac{dx}{dt} = 0.5x$ 有无穷多个解 $x(t) = C e^{0.5t}$。为什么加上 $x(0)=100$ 之后，解就唯一了？

**解答**：因为初始条件把常数 $C$ 钉死了。代入 $x(0) = C e^{0} = C$，所以 $C = 100$，解唯一化为 $100e^{0.5t}$。**微分方程描述的是"怎么变"，初始条件描述的是"从哪开始变"**——两者缺一不可，合起来才唯一确定整条轨道。这正是主线定义块里"初始条件决定整条连续轨道"的含义，也是动力系统里"轨道由初值唯一确定"的连续版本。

**思路点拨**：这是"推导优于宣告"的考点——不背"初始条件重要"，而是亲手推出 $C=100$。§11.2.2.1 的简谐振动 $y(t)=A\cos(\omega t)+B\sin(\omega t)$ 里，$A, B$ 同样靠初值（初始位置和速度）钉死——同一个机制。

## 二、计算实践

### 题 1（手算：指数增长的三个时刻）

$\frac{dx}{dt} = 0.5x$，$x(0) = 100$。

(a) 写出解的表达式。
(b) 手算 $x(1)$、$x(2)$、$x(4)$（用 $e \approx 2.718$）。
(c) 如果换成 $\frac{dx}{dt} = -0.5x$（衰减），$x(2)$ 是多少？趋势如何？

**解答**：

(a) $x(t) = 100 e^{0.5t}$。

(b) $x(1) = 100e^{0.5} \approx 100 \times 1.648 = 164.8$；$x(2) = 100e^1 \approx 271.8$；$x(4) = 100e^2 \approx 100 \times 7.389 = 738.9$。

(c) 换 $r = -0.5$：$x(2) = 100 e^{-1} \approx 36.8$。趋势是**指数衰减**——总量减半所需时间恒定（半衰期 = $\ln 2 / 0.5 \approx 1.39$ 单位时间）。同一公式，$r$ 的符号决定涨跌。

**思路点拨**：核心是"指数滑下来变系数"：$\frac{d}{dt}e^{rt} = re^{rt}$。衰减方向用 $e^{-1}$，等于约 0.368——记住这个数，它反复出现（半衰期、softmax 的尾部、RNN 的记忆衰减）。

**NumPy 验证**：
```python
import numpy as np

def ana(x0, r, t): return x0 * np.exp(r * t)
for t in [1, 2, 4]:
    print(f"x({t}) =", round(ana(100, 0.5, t), 2))
print("衰减 x(2) =", round(ana(100, -0.5, 2), 2))
```
```
x(1) = 164.87
x(2) = 271.83
x(4) = 738.91
衰减 x(2) = 36.79
```

### 题 2（手算 + 代码：欧拉法的一步）

用欧拉法近似 $\frac{dx}{dt} = 0.5x$、$x(0)=100$。

(a) 手算：$dt = 1.0$，求 $x(1)$ 的欧拉近似（一步）。
(b) 与解析值 $164.87$ 比，误差多少？为什么欧拉法**低估**？
(c) 用代码把 $dt$ 取 0.5 和 0.1 各积到 $t=3$，对比误差。

**解答**：

(a) 欧拉更新：$x(1) \approx x(0) + f(x(0))\cdot dt = 100 + (0.5 \times 100) \times 1 = 150$。

(b) 解析值 164.87，误差约 14.87。**低估**是因为 $e^{0.5t}$ 是凸函数：欧拉法沿**切线**走，而切线在凸函数下方。$x(t)$ 的增长率在每一步都在变大，欧拉法却用"起步时的增长率"一算到底，于是落后。

(c) 代码：
```python
import numpy as np

def euler(x0, r, t_end, dt):
    n = int(round(t_end / dt)); x = x0
    for _ in range(n):
        x = x + (r * x) * dt
    return x

truth = 100 * np.exp(0.5 * 3)
for dt in [1.0, 0.5, 0.1]:
    val = euler(100.0, 0.5, 3, dt)
    print(f"dt={dt}: 欧拉={val:.4f} 误差={abs(val-truth):.4f}")
```
```
dt=1.0: 欧拉=406.2500 误差=41.9189
dt=0.5: 欧拉=431.6227 误差=16.5462
dt=0.1: 欧拉=446.0776 误差=2.0913
```
步长每缩 10 倍，误差约缩 8–10 倍——**一阶收敛**的实感。

**思路点拨**：(b) 是这道题的灵魂——理解"为什么低估"比记住"欧拉有误差"值钱得多。画一条凸曲线和它的切线，你就会永远记住：欧拉法用每段起点的斜率，而真实斜率一直在变。(c) 的误差表让你"看见"收敛阶。

### 题 3（手算 + 代码：从具体数字到一般公式）

设 $\frac{dx}{dt} = r x$，$x(0) = x_0$。教材用 $r=0.5, x_0=100$ 算了一个例子。

(a) 把具体数字换成字母，写出通解。
(b) 验证：$x(t) = x_0 e^{rt}$ 确实满足方程（求导代回）。
(c) 用代码画 $r=0.5$ 和 $r=-0.3$ 两条轨道在 $t \in [0,5]$ 的形状，描述差异。

**解答**：

(a) $x(t) = x_0 e^{rt}$。这是"从具体到字母"的收官——§11.2 定义块里 $f(x)=rx$ 的完整解族。

(b) $\frac{d}{dt}(x_0 e^{rt}) = x_0 \cdot r e^{rt} = r(x_0 e^{rt}) = r x(t)$，等于方程右端 $\checkmark$。

(c) $r=0.5$ 从 100 指数涨到 $100e^{2.5}\approx 1218$；$r=-0.3$ 从 100 衰减到 $100e^{-1.5}\approx 22.3$。前者单调上升且越来越陡（复利加速），后者单调下降且越来越平（趋向 0 但不抵达）。

**思路点拨**：把教材的具体数换成字母，正是主线"从 3 到 $k$ 的跳跃"在连续世界的版本。$e^{rt}$ 是整章最常用的函数——RNN 的记忆衰减（$|W_{hh}|<1$ 时隐藏状态按类似指数衰减）、softmax、Neural ODE 里全是它。

## 三、DL 延伸

### 题 1（梯度流：训练 = 一条流向谷底的河）

连续化的梯度下降是**梯度流**：$\frac{dw}{d\tau} = -\nabla L(w)$。

(a) 解释负号：为什么是 $-\nabla L$ 而不是 $+\nabla L$？
(b) 普通 SGD $w_{k+1} = w_k - \eta\nabla L(w_k)$ 和梯度流是什么关系？

**解答**：

(a) $\nabla L(w)$ 指向损失**增大**最快的方向；我们想让损失**减小**，所以取负号——参数沿"损失下降最快"的方向流动。这是"沿梯度负方向走"的连续化：不是跳一大步，而是每时每刻都朝最陡下坡方向"流"。

(b) SGD 是梯度流的**欧拉离散化**：令 $\frac{dw}{d\tau} \approx \frac{w_{k+1}-w_k}{\eta}$（学习率 $\eta$ 当步长），代入 $\frac{dw}{d\tau} = -\nabla L(w)$，就得到 $w_{k+1} = w_k - \eta\nabla L(w_k)$。**你每天写的 `w -= lr * grad`，就是把这条连续河流切回离散格子的欧拉一步**——§11.2.1.2 的欧拉法在这里以最日常的形式现身。

**思路点拨**：这道题把本节数学直接接到训练循环上。学习率 $\eta$ 在连续视角里就是欧拉步长 $dt$——这解释了为什么"学习率太大不稳定"：欧拉法步长太大也会 overshoot 发散（§11.2.1.2 习题 2 的教训）。看懂这个，优化器不再是黑盒。

### 题 2（Neural ODE：层数去哪儿了？）

Neural ODE 的前向传播是 $\frac{dh}{d\tau} = f_\theta(h(\tau), \tau)$，输出 $h(1) = h(0) + \int_0^1 f_\theta d\tau$。

(a) 和普通残差网络 $h_{k+1} = h_k + f_\theta(h_k)$ 相比，'层数'和'步长'发生了什么变化？
(b) 为什么说 Neural ODE 的"深度"是连续量？

**解答**：

(a) 残差网络把 $\tau$ 切成单位步（步长 1），每层就是一步：$h_{k+1} = h_k + f_\theta(h_k)$ 正是欧拉法。Neural ODE 放弃固定步长，把"切格"交给专业求解器——步长可以自适应、可以在梯度陡的地方加密。**层数不再是整数超参数，而是积分求解器选出来的格点数量。**

(b) "深度"变成了连续变量 $\tau \in [0,1]$。$h(\tau)$ 在每个 $\tau$ 都有定义——不仅在第 0、1、2…层。网络的"层"被重新解释为"这条连续轨道上的采样点"。这就是主线"连续是离散的极限"在模型结构上的精确兑现。

**思路点拨**：抓住一个等式：**残差 = 欧拉一步，层数 = 步数，Neural ODE = 精确积分。** §11.2.1.2 的误差表（dt 越细越准）在这里变成工程决策：`scipy.integrate.solve_ivp` 的容差参数控制"层数"，和欧拉法的 dt 是同一个旋钮的升级版。

**延伸预告**：§11.2.2 把"变化的语言"微分方程正式立起来；§11.2.2.1 用 ODE 解摆锤；§11.3.2 用 ODE 解释 RNN 的记忆与稳定性。
