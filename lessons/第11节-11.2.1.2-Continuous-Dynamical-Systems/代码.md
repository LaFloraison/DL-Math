# 代码：连续世界的两把尺——解析解与欧拉法

主线里解了教材的指数增长 $\frac{dx}{dt} = 0.5x$、$x(0)=100$，得到解析解 $x(t) = 100e^{0.5t}$，并在 $t=1,2,3$ 处手算得 $164.87, 271.83, 448.17$。本节把这套验证与延伸变成代码：先用 `np.exp` 一锤定音复现那三个数，再用**欧拉法 (Euler method)** 从零数值积分这条方程，最后做一个实验——把步长 $\Delta t$ 从 1.0 一路切细到 0.001，看数值解如何逼近解析解。**这是"连续世界"与"离散世界"（§11.2.1.1）之间的那座桥。**

---

## 层一：完整脚本

```python
import numpy as np                                       # np.exp 与 np.linspace 来自这里

def analytic_growth(x0, r, t):                           # ① 解析解：x(t) = x0 e^{rt}
    """连续动力系统 dx/dt = rx 的闭式解。"""
    return x0 * np.exp(r * t)

def euler_growth(x0, r, t_end, dt):                      # ② 欧拉法：数值积分 dx/dt = rx
    """从 t=0 积分到 t_end，步长 dt，返回 (终值, 整条轨迹)。"""
    n_steps = int(round(t_end / dt))                     # 步数
    traj = np.zeros(n_steps + 1)
    traj[0] = x0                                         # 初始条件
    t = 0.0
    for k in range(n_steps):
        traj[k+1] = traj[k] + (r * traj[k]) * dt         # x += f(x) * dt，f(x) = r x
        t += dt
    return traj[-1], traj                                 # 终值与轨迹

# ---- ③ 复现教材的三个时刻 ----
print("=== 解析解 x(t) = 100 e^{0.5t}（教材 §11.2.1.2）===")
for t in [1, 2, 3]:
    print(f"x({t}) = {analytic_growth(100.0, 0.5, t):10.4f}")

# ---- ④ 欧拉法 vs 解析解：把 dt 切细 ----
print("\n=== 欧拉法逼近解析解（t = 3，解析值 448.17）===")
truth = analytic_growth(100.0, 0.5, 3)
for dt in [1.0, 0.5, 0.1, 0.001]:
    val, _ = euler_growth(100.0, 0.5, 3, dt)
    print(f"dt = {dt:<7g}  欧拉值 = {val:10.4f}  误差 = {abs(val - truth):10.4f}")

# ---- ⑤ 看一眼整条轨迹（前 5 个欧拉点，dt=1）----
_, traj = euler_growth(100.0, 0.5, 3, 1.0)
print("\n=== 欧拉法 dt=1 的轨迹（每步记录）===")
print(np.round(traj, 4))
```

运行输出（Python 3.11 + NumPy）：

```text
=== 解析解 x(t) = 100 e^{0.5t}（教材 §11.2.1.2）===
x(1) =   164.8721
x(2) =   271.8282
x(3) =   448.1689
=== 欧拉法逼近解析解（t = 3，解析值 448.17）===
dt = 1      欧拉值 =   406.2500  误差 =    41.9189
dt = 0.5    欧拉值 =   431.6227  误差 =    16.5462
dt = 0.1    欧拉值 =   446.0776  误差 =     2.0913
dt = 0.001  欧拉值 =   448.1476  误差 =     0.0213
```

看那四行误差：`41.92 → 16.55 → 2.09 → 0.021`。步长 $\Delta t$ 每缩小一个数量级，误差跟着缩大约一个数量级——这是**一阶方法**的标志（欧拉法线性收敛）。这就是"连续世界 + 足够细的步长 ≈ 离散世界"的数值证词：把连续流切成细格，就是离散动力系统，而切得越细，越接近真实。

下面把每段拆开看。

### 步骤 2：定义 `analytic_growth` —— 解析解的一锤定音

```python
def analytic_growth(x0, r, t):
    return x0 * np.exp(r * t)
```

#### analytic_growth —— $x(t) = x_0 e^{rt}$

`return x0 * np.exp(r * t)`

**做什么**：直接返回连续动力系统 $\frac{dx}{dt} = rx$ 的解 $x_0 e^{rt}$。不迭代，一次算完任意时刻。
**操作**：`np.exp(r * t)` 算 $e^{rt}$，乘 `x0`。这背后是主线那个验证：$\frac{d}{dt}e^{rt} = r e^{rt}$，所以 $e^{rt}$ 的导数是它自己的 $r$ 倍——正好是方程右端。
**输入**：
- `x0`：初始条件，标量。教材里是 100。
- `r`：增长率，标量。教材里是 0.5。
- `t`：时刻，标量或数组。传数组 `np.linspace(0, 3, 100)` 时一次算出整条曲线。
**输出**：$x(t)$——标量或与 `t` 同形状的数组。
**可调参数**：
- `t` 传数组 = 免费拿到整条连续轨道，画图直接用。这是解析解的福利：离散版要循环 100 次，这里一次 `np.exp`。
- `r` 是性格开关：`r > 0` 指数增长（菌落、复利），`r < 0` 指数衰减（镭的衰变、热水变凉）。$r=0$ 静止。教材 §11.2.1.2 只用了增长，但同一公式管两个方向。
- 能不能加参数？这是"恰有解析解"的特例。任意右端 $f(x)$（如逻辑斯蒂 $x(1-x)$）没有闭式解，`analytic_growth` 就失效，必须靠 `euler_growth` 或更专业的求解器。
**对应数学**：主线定义块 + 第二节的完整解。`x(1)≈164.87`、`x(2)≈271.83`、`x(3)≈448.17` 与教材手算完全一致。

### 步骤 3：定义 `euler_growth` —— 欧拉法数值积分

```python
def euler_growth(x0, r, t_end, dt):
    n_steps = int(round(t_end / dt))
    traj = np.zeros(n_steps + 1)
    traj[0] = x0
    t = 0.0
    for k in range(n_steps):
        traj[k+1] = traj[k] + (r * traj[k]) * dt
        t += dt
    return traj[-1], traj
```

#### euler_growth —— 把连续流切成细格，一步步推进

`traj[k+1] = traj[k] + (r * traj[k]) * dt`

**做什么**：用欧拉法把 $\frac{dx}{dt} = rx$ 从 $t=0$ 积分到 `t_end`。这是主线"连续系统 + 细步长 ≈ 离散系统"的代码实现——它把一个连续方程变成一条离散轨道。
**操作**：先算步数 `n_steps = t_end / dt`；`traj[0] = x0` 存初始条件；循环里每步做**欧拉更新**：$x_{k+1} = x_k + f(x_k)\cdot dt$，其中 $f(x) = rx$。这个式子正是 $x_{k+1} = x_k + \frac{dx}{dt}\cdot dt$——"新状态 = 旧状态 + 变化率 × 时间步"。
**输入**：
- `x0`：初始条件，标量。
- `r`：增长率，标量。
- `t_end`：积分终点，标量。跑多久。
- `dt`：步长，标量正数。连续流被切多细。
**输出**：元组 `(traj[-1], traj)`——终值（$x(t_{end})$ 的近似）+ 整条轨迹数组（形状 `(n_steps+1,)`）。
**可调参数**：
- `dt` 是精度旋钮。`dt=1.0` 时只走 3 步、误差 41.9（粗！）；`dt=0.001` 时走 3000 步、误差 0.02。**`dt` 越小越准、越贵**——精度与步数是一桩交易。这正是主线边界声明的第二点：欧拉法是一阶的，$\Delta t$ 减半误差也约减半。
- `r` 换成负值（衰减），欧拉法依然工作：$x_{k+1} = x_k - 0.5x_k dt$，数值解逼近 $100e^{-0.5t}$。
- 能不能加参数？可以换成任意右端函数 `f`（签名 `euler(f, x0, t_end, dt)`），那就成了通用 ODE 积分器——`scipy.integrate.solve_ivp` 就是这么做的（只是阶数更高、步长自适应）。
**对应数学**：主线第四节的欧拉法公式 $x(t+\Delta t) \approx x(t) + f(x(t))\,\Delta t$。它是"从离散到连续"那座桥的桥面。

**输出**：`164.8721`、`271.8282`、`448.1689`——与教材 $164.87, 271.83, 448.17$ 一致（教材四舍五入到两位）。

### 步骤 5：欧拉法 vs 解析解——把 dt 切细

```python
truth = analytic_growth(100.0, 0.5, 3)
for dt in [1.0, 0.5, 0.1, 0.001]:
    val, _ = euler_growth(100.0, 0.5, 3, dt)
    print(f"dt = {dt:<7g}  欧拉值 = {val:10.4f}  误差 = {abs(val - truth):10.4f}")
```

**做什么**：用四个不同的 `dt` 做欧拉积分，每次与解析解比误差。误差列从 `41.92 → 0.021` 单调下降——这就是主线"数值积分以步长为代价逼近真解"的完整证据。
**操作**：`truth` 是解析真值 448.17；`euler_growth(100.0, 0.5, 3, dt)` 依次用粗到细的步长积分；`abs(...)` 取误差。
**输入**：`dt ∈ {1.0, 0.5, 0.1, 0.001}`。
**输出**：四行 `(dt, 欧拉值, 误差)`。
**可调参数**：把列表换成 `[2.0]`——步长太大时欧拉值会明显"overshoot"（跳过头），因为指数增长对粗步长不友好；换成 `[0.0001]`——误差降到 0.002，但要走 3 万步。
**对应数学**：主线第四、五节的边界声明——欧拉法是一阶方法、$dt$ 控制精度。这张误差表就是"切得越细越接近连续"的数字证词。

### 步骤 6：看整条轨迹

```python
_, traj = euler_growth(100.0, 0.5, 3, 1.0)
print(np.round(traj, 4))
```

**做什么**：用 `dt=1.0` 的粗步长跑一次，打印整条轨迹。输出 `[100, 150, 225, 337.5]`——每步都在解析曲线下方，这就是**欧拉法系统性的低估**（指数函数是凸的，切线永远在曲线下方）。
**操作**：`_` 丢弃终值，取轨迹数组，`np.round` 四位小数。
**输入**：`euler_growth(100.0, 0.5, 3, 1.0)`。
**输出**：`[100.  150.  225.  337.5]`——4 个欧拉点（$t=0,1,2,3$）。
**可调参数**：`dt` 换 `0.5` 会得到 7 个点，逐次逼近 $100e^{0.5t}$ 的曲线。画出来（`plt.plot`）就能看到：粗步长是折线，细步长几乎与解析曲线重合——教材图 11.1 里"离散红点 vs 连续蓝线"的动态版。
**对应数学**：离散轨道与连续轨道的直观对照。欧拉法的低估（$337.5 < 448.17$）正是教材图 11.1 里"变化剧烈处离散与连续分开"的机制。

## 边界声明：这套代码能做什么，不能做什么

1. **`analytic_growth` 只对 $\frac{dx}{dt}=rx$ 有效。** 它是教材挑的特例——线性、齐次、有闭式解。真实系统（摆锤、流体、三体、逻辑斯蒂）没有闭式解，`analytic_growth` 无从谈起，一切靠数值积分。**解析解是奢侈品，数值积分是常态。**
2. **欧拉法会系统性地低估凸曲线。** 指数增长是凸的，切线永远在曲线下方，所以欧拉法每步都"落后"一点——这是方法的**偏置 (bias)**，不是随机误差。想要更准，用 RK4 或 `scipy.integrate.solve_ivp`（自适应步长），§11.2.2.1 会用到。
3. **数值积分在混沌区会崩。** §11.2.1.1 说过，对混沌系统，任何步长、任何精度的数值解，都会在"可预测保质期"之后与真解分道扬镳——因为舍入误差被指数放大。连续系统的"数值可解"不等于"长期可预测"。
