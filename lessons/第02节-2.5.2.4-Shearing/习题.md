# 习题：剪切

## 第一组：概念检验

**1.1（单选）** 水平剪切 $S(k) = \begin{bmatrix}1&k\\0&1\end{bmatrix}$ 作用在点 $(x,y)$ 上，结果正确的是：
- A. $(x + ky,\ y)$
- B. $(x,\ kx + y)$
- C. $(kx + y,\ y)$
- D. $(x + k,\ y)$

**1.2（判断并说明）** "$\det S(k) = 1$，所以剪切不改变图形的任何属性。" 这句话对吗？提示：想想角度和长度会不会变，哪条线上的点不受影响。

**1.3（填空）** 水平剪切 $S(k)$ 的固定线是 ____（哪条直线？）。先做剪切因子 $k_1$，再做剪切因子 $k_2$，等价于一次剪切因子为 ____ 的剪切。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 取 $k = 3$，手算单位正方形四个顶点 $(0,0),(1,0),(1,1),(0,1)$ 被水平剪切后的像，画出结果并验证面积仍为 1。用 NumPy 验证。

**2.2（代码验证）** 验证"剪切可以撤销"：证明 $S(2)\,S(-2) = I$（单位矩阵）。手算一次，代码验证一次。

**2.3（代码实践，体会不可交换性）** 令点 $p = (1,2)$。先做水平剪切 $k=2$，再做竖直剪切 $k=3$；然后换顺序（先竖直后水平）。两次结果相同吗？用 NumPy 验证并解释。

## 第三组：DL 延伸

**3.1（场景判断）** 一个货架图片分类任务，训练图全是"横平竖直"的正视图。你给每张图加随机水平剪切（剪切因子 $k$ 在 $[-0.1, 0.1]$ 均匀随机）。请回答：这个操作改的是像素坐标 $(x,y)$ 的哪个量？它模拟的现实世界的哪种变形？$\det = 1$ 意味着图像的信息量如何变化？

**3.2（场景分析）** 数据增强里，随机剪切常与随机旋转、随机缩放组合使用。旋转保面积也保形状，缩放改变面积（$\det = s_x s_y$）但保角度，剪切保面积却歪形状。为什么把三者组合，能让模型对"视角变化"更鲁棒？提示：想想一张照片在现实中会因为什么同时发生倾斜、缩放和推歪。

## 解答与思路点拨

### 第一组

**1.1 答案：A。**
- **思路**：直接算矩阵乘法：$x' = 1\cdot x + k\cdot y = x + ky$，$y' = 0\cdot x + 1\cdot y = y$。所以 $(x,y)\to(x+ky,\ y)$。
- **点拨**：选项 B 是**竖直**剪切 $V(k)$ 的作用（$y$ 坐标加上 $kx$）；C 把 $k$ 放错了位置（那对应矩阵 $\begin{bmatrix}k&1\\0&1\end{bmatrix}$，左下角借了一个多余的数）；D 是**平移**——加一个常数，那根本不是线性变换（原点都动了，而线性变换必须把原点留在原点）。记住判据：剪切是"乘一个坐标"（$ky$），不是"加一个常数"（$+k$）。

**1.2 这句话不对。**
- **思路**：$\det=1$ 只保证**面积**不变。角度会被推成斜角（直角变非直角），非固定线上点的模长一般会变。剪切是"保面积、不保形状"的变换；旋转才保角度与长度，反射只是镜像。唯一完全不受影响的是固定线（$y=0$）上的点。
- **点拨**：这是"行列式只告诉你面积倍数"这一课——行列式是个非常"吝啬"的量，它不告诉你任何关于形状的信息。

**1.3 答案：固定线是 $x$ 轴（$y=0$）；等价于剪切因子 $k_1+k_2$ 的一次剪切。**
- **思路**：$y=0$ 的点横向位移 $ky=0$，所以不动。叠加规则：$S(k_1)S(k_2)=S(k_1+k_2)$，两个剪切矩阵相乘，右上角相加。
- **点拨**：注意这个"相加"只发生在同一个方向（都是水平）的剪切之间；水平和竖直混着用没有这么简单的加法——2.3 会撞见这一点。

### 第二组

**2.1**
$S(3)$ 作用四个顶点：
$(0,0)\to(0,0)$，$(1,0)\to(1,0)$，$(1,1)\to(1+3,1)=(4,1)$，$(0,1)\to(0+3,1)=(3,1)$。

结果是一个底边仍长 1、高仍为 1、顶边右移了 3 格的平行四边形，面积 $=1$。

```python
import numpy as np
k = 3.0
S = np.array([[1.0, k], [0.0, 1.0]])
sq = np.array([[0.,0.],[1.,0.],[1.,1.],[0.,1.]])
def shoelace(P):
    x, y = P[:,0], P[:,1]
    return 0.5*abs(np.dot(x, np.roll(y,-1)) - np.dot(np.roll(x,-1), y))
print(shoelace(sq @ S.T))   # 1.0
```
- **思路**：平行四边形面积 = 底 × 高。剪切不改变高度（$y$ 不变），只平移了顶边，所以底 × 高仍为 $1\times1$。
- **点拨**：这比背公式更直观——**剪切保住面积的本质是"高不变"**。任何只沿一个方向滑动、不改变垂直距离的变换，都天然等积。

**2.2**
$$S(2)\,S(-2) = \begin{bmatrix}1&2\\0&1\end{bmatrix}\begin{bmatrix}1&-2\\0&1\end{bmatrix} = \begin{bmatrix}1&2-2\\0&1\end{bmatrix} = \begin{bmatrix}1&0\\0&1\end{bmatrix} = I$$

```python
import numpy as np
S2  = np.array([[1., 2.],[0., 1.]])
Sm2 = np.array([[1.,-2.],[0., 1.]])
print(S2 @ Sm2)     # [[1. 0.] [0. 1.]]
```
- **思路**：右上角 $2 + (-2) = 0$，其余位置是标准的单位阵元素，结果恰为 $I$。先往右推 2 再往左推 2，一切复位。
- **点拨**：这同时验证了"等积变换的逆仍是等积变换"——$\det(S(-2))=\det(S(2))=1$。

**2.3 两次结果不同。**
先水平后竖直：$H:(1,2)\to(1+2\cdot2,\ 2)=(5,2)$；再 $V:(5,2)\to(5,\ 3\cdot5+2)=(5,17)$。
先竖直后水平：$V:(1,2)\to(1,\ 3\cdot1+2)=(1,5)$；再 $H:(1,5)\to(1+2\cdot5,\ 5)=(11,5)$。

```python
import numpy as np
H = np.array([[1.,2.],[0.,1.]])
V = np.array([[1.,0.],[3.,1.]])
p = np.array([1.,2.])
print(V @ (H @ p))   # [ 5. 17.]
print(H @ (V @ p))   # [11.  5.]
```
- **思路**：矩阵乘法 $VH \neq HV$。用矩阵写：$VH = \begin{bmatrix}1&2\\3&7\end{bmatrix}$，而 $HV = \begin{bmatrix}7&2\\3&1\end{bmatrix}$，完全不同。
- **点拨**：这正是"矩阵乘法不可交换"的鲜活例子——顺序很重要。它意味着：如果要对数据做"水平 + 竖直"剪切，必须先定死先后顺序，否则会得到两套不同的结果。

### 第三组

**3.1 答案：改的是像素的横坐标**——每个像素 $(x,y)$ 变成 $(x+ky, y)$，横向位移正比于纵向位置 $y$。它模拟的是相机绕竖直轴转动（视角侧倾）造成的视差：画面越高（越靠上）的部分横向偏得越多。$\det = 1$ 意味着**信息量（图像的"面积体积"）不放大也不压缩**，只是被重新摆放。
- **思路**：把每个像素当向量，整张图就是一堆向量被同一个矩阵同时作用。$k$ 随机，模型每次见到略微不同的歪斜版本。
- **点拨**：别误以为这是"平移"——平移对每个像素加同一个常数，剪切是按坐标的比例滑动。这正是"视角歪斜"和"整体挪动"的数学区别。

**3.2 思路**
相机在三维空间里移动，对照片同时产生三类效应：绕光轴的自转 → **旋转**；离物体远近变化 → 透视导致整体**缩放**；视线相对物体倾斜 → **剪切**。真实世界对物体的"视角变形"是这三者的复合，不是任何单独一个。

因此：
- 旋转让模型认识"转着看"；
- 缩放让模型认识"近看远看"（大小变化）；
- 剪切让模型认识"斜着看"（形状歪斜但总量不变）。

三者组合，覆盖的是"仿射变形"这个大家族——它正好是真实相机能造成的全部线性失真。模型在训练时见过这个家族里的各种成员，测试时面对任意一个视角，都不再是"没见过"。
- **点拨**：常见的错误是只加剪切就以为够——但现实中相机的移动同时产生三种效应，只练一种，另两种来了照样懵。这正是"数据增强 = 教模型对真实世界的不变方向免疫"的完整画面。

## 一个"为什么有人会答错"的提醒

1.1 的 D 选项很诱人——"推一格"听起来像"加一格"，于是有人写成 $(x+k, y)$。但剪切乘的是**坐标**（$ky$）而不是**常数**（$k$），因为每层滑多少取决于它离固定线多远，这正是"固定线"存在的意义。1.3 则是另一个陷阱：两个同向剪切能简单相加，但一旦混入竖直方向（2.3），"相加"立刻失效——有人把"$k_1+k_2$"的规则泛化到不同方向，就错了。记住：**同向剪切可加，异向剪切不可交换**。
