# 代码：把正方形推成平行四边形，再当面量它的面积

主线里我们用手推一摞扑克牌，感受到"推歪一格、面积不变"。这一节把这句话变成代码：构造剪切矩阵，用它推一个点、推一个正方形，用鞋带公式量面积，再验证固定线上的点一动不动。

脚本只依赖 NumPy，约 30 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np                      # NumPy：造矩阵、做乘法、求行列式

# ---- ① 构造水平剪切矩阵：沿 x 方向推，剪切因子 k=2 ----
k = 2.0
S = np.array([[1.0, k],
              [0.0, 1.0]])              # 形状 (2,2)，右上角是剪切因子
print("剪切矩阵 S =\n", S)
print("行列式 det(S) =", np.linalg.det(S))        # 1.0 → 面积不变

# ---- ② 单个点被剪切：矩阵左乘向量 ----
p = np.array([1.0, 2.0])                # 一个点，形状 (2,)
q = S @ p                               # 左乘：x' = x + ky, y' = y
print("p =", p, "→ 剪切后 q =", q)      # [5.0, 2.0] = [1+2*2, 2]

# ---- ③ 单位正方形 → 平行四边形，鞋带公式量面积 ----
square   = np.array([[0.,0.], [1.,0.], [1.,1.], [0.,1.]])   # 顶点，形状 (4,2)
sheared  = square @ S.T                 # 每行一个点，右乘 S 的转置

def shoelace(P):                        # 鞋带公式：任意多边形面积
    x, y = P[:, 0], P[:, 1]
    return 0.5 * abs(np.dot(x, np.roll(y, -1)) - np.dot(np.roll(x, -1), y))

print("原始正方形面积 =", shoelace(square))
print("剪切后面积     =", shoelace(sheared))    # 都是 1.0

# ---- ④ 固定线：y=0 上的点一动不动 ----
on_axis = np.array([3.0, 0.0])
print("y=0 上的点", on_axis, "→", S @ on_axis)  # 不变，仍是 [3.0, 0.0]

# ---- ⑤ 竖直剪切：同一个 k，滑动方向换成 y ----
V = np.array([[1.0, 0.0],
              [k, 1.0]])                # k 放在左下角
print("竖直剪切 V =\n", V, "\ndet(V) =", np.linalg.det(V))   # 还是 1.0
```

## 层二：分步逐函数拆解

### 步骤 1：造剪切矩阵，验证面积守恒

```python
k = 2.0
S = np.array([[1.0, k], [0.0, 1.0]])
print(np.linalg.det(S))     # 1.0
```

#### `np.array([[1.0, k], [0.0, 1.0]])` —— 把嵌套列表变成 2×2 矩阵

**做什么**：把"两行、每行两个数"的嵌套列表转成 NumPy 的 `ndarray`，这就是剪切矩阵在计算机里的存在形式。
**操作**：外层列表长度 2 = 行数，内层列表长度 2 = 列数，推断数据类型为 `float64`，按行存入内存。
**输入**：嵌套列表 `[[1.0, k], [0.0, 1.0]]`。
**输出**：形状 `(2, 2)` 的矩阵。索引：`S[0,0]=1.0`、`S[0,1]=k`（右上角，剪切因子）、`S[1,0]=0.0`、`S[1,1]=1.0`。
**可调参数**：
- `k`：剪切因子。`k>0` 向右推、`k<0` 向左推、`|k|` 越大推得越歪、`k=0` 时退化为单位矩阵。改成 `k=-2.0` 试试，点会被推向左。
- 挪位置：把 `k` 从右上角挪到左下角 `[[1.0,0.0],[k,1.0]]`，就是竖直剪切。
- 加一维：`np.array([[1.,0.,k],[0.,1.,0.],[0.,0.,1.]])` 是三维里"沿 x-y 平面滑动、z 不动"的剪切矩阵。
- 还可以传 `dtype`：`np.array([...], dtype=np.float32)` 强制单精度，省内存。
**对应数学**：主线定义块中的水平剪切矩阵 $S(k) = \begin{bmatrix}1&k\\0&1\end{bmatrix}$。

#### `np.linalg.det(S)` —— 行列式，面积放大倍数

**做什么**：计算方阵的行列式——对 $2\times2$ 矩阵，它恰好是"变换前后面积之比"。
**操作**：对 $S = \begin{bmatrix}a&b\\c&d\end{bmatrix}$ 计算 $ad - bc = 1 \times 1 - k \times 0 = 1$。
**输入**：形状 `(2,2)` 的方阵 `S`。
**输出**：标量 `1.0`——与 `k` 无关，对任意 `k` 都是 1，这就是"面积不变"的代数证明。
**可调参数**：对任意 $n\times n$ 方阵有效；非方阵会报错（行列式只定义在方阵上）。它算的是精确值，不受点数、坐标选择影响。
**对应数学**：主线"面积放大倍数 = $|\det|$"。

### 步骤 2：推一个点——矩阵左乘向量

```python
p = np.array([1.0, 2.0])
q = S @ p
```

#### `ndarray @ ndarray` —— 矩阵乘法（这里是矩阵×向量）

**做什么**：用剪切矩阵 `S` 去作用向量 `p`，得到剪切后的点。
**操作**：对 $i$ 行：$q_i = \sum_j S_{ij}\, p_j$。这里 $q_0 = 1\times1 + 2\times2 = 5$，$q_1 = 0\times1 + 1\times2 = 2$。
**输入**：左侧 `S` 形状 `(2,2)`，右侧 `p` 形状 `(2,)`。形状对齐规则：左矩阵的列数 2 = 右向量的长度 2。
**输出**：形状 `(2,)` 的向量 `[5.0, 2.0]`——横坐标多了 $ky=4$，纵坐标原样。
**可调参数**：`@` 是通用矩阵乘法运算符（Python 3.5+）。右边可以换成矩阵（`S @ B` 要求 `S` 的列数 = `B` 的行数）；等价写法 `np.matmul(S, p)`、`np.dot(S, p)`。注意形状错了（比如 `p @ S`）会报错或给出完全不同的结果。
**对应数学**：主线 $\begin{bmatrix}x'\\y'\end{bmatrix} = S(k)\begin{bmatrix}x\\y\end{bmatrix}$——单个点被剪切。

### 步骤 3：推整块图形——批量右乘 + 鞋带公式量面积

```python
square  = np.array([[0.,0.],[1.,0.],[1.,1.],[0.,1.]])
sheared = square @ S.T

def shoelace(P):
    x, y = P[:, 0], P[:, 1]
    return 0.5 * abs(np.dot(x, np.roll(y, -1)) - np.dot(np.roll(x, -1), y))
```

#### `S.T` —— 转置，让"每行一个点"能一次性乘上剪切矩阵

**做什么**：把 `S` 的行和列对调。为什么这里要右乘 `S.T` 而不是左乘 `S`？因为 `square` 的形状是 `(4,2)`——**每一行是一个点**。矩阵乘法要求"左矩阵的列数 = 右矩阵的行数"，`(4,2)` 要乘 `(2,2)`，但矩阵乘法不交换：`square @ S` 是 `(4,2)@(2,2)`，行的对齐是 `S` 的行（不是我们想要的列向量作用）。转置后 `S.T` 仍是 `(2,2)`，但 `square @ S.T` 的每一行 = 该行的点被 `S` 作用，语义正确。
**操作**：`S.T` 把右上角的 `k` 换到左下角：`[[1,2],[0,1]]` → `[[1,0],[2,1]]`。
**输入**：形状 `(2,2)` 的 `S`。
**输出**：形状 `(2,2)` 的 `S.T`。
**可调参数**：任何矩阵都能 `.T`；对 `(n,m)` 得到 `(m,n)`。等效写法：把点放在列上，用 `S @ square.T` 得到 `(2,4)`，再 `.T` 回来。
**对应数学**：主线"单位正方形四个顶点批量手算"——四个点一次性全算完。

#### `shoelace(P)` —— 鞋带公式求多边形面积

**做什么**：给定按顺序环绕一圈的顶点，算多边形面积。
**操作**：对顶点按环绕顺序，面积 $= \frac12\left|\sum_i x_i y_{i+1} - x_{i+1} y_i\right|$（下标循环回起点）。`np.roll(y, -1)` 把数组整体左移一位，实现下标 $i+1$ 的循环；`np.dot(x, roll(y,-1))$ 计算 $\sum_i x_i y_{i+1}$。
**输入**：`P` 形状 `(n,2)`——`n` 个顶点，`P[:,0]` 取全部 x 坐标、`P[:,1]` 取全部 y 坐标。
**输出**：标量面积。原始正方形 `1.0`，剪切后平行四边形也是 `1.0`——"面积不变"的数值证据。
**可调参数**：顶点必须按环绕多边形一圈的顺序排列（顺、逆时针皆可，公式取绝对值）；乱序会得到错误面积。`n` 可以是任意多边形边数，不限于四边形。
**对应数学**：主线的平行四边形手算——底边仍长 1、高仍为 1，面积 $=1$。

### 步骤 4：固定线上的点

```python
on_axis = np.array([3.0, 0.0])
print(S @ on_axis)     # [3.0, 0.0]，纹丝不动
```

#### `S @ on_axis` —— 同一句矩阵乘法，验证不动点

**操作**：$q_0 = 3 + 2\times0 = 3$，$q_1 = 0\times3 + 1\times0 = 0$。点 `(3,0)` 的纵坐标是 0，横向位移 $k\times y = 2\times0 = 0$，所以原地不动。
**对应数学**：主线的**固定线 (fixed line)**——$y=0$（$x$ 轴）上的所有点都被剪切矩阵锚定。换个角度看：矩阵第一列 $(1,0)^\top$ 是 $x$ 轴方向，$S\cdot(1,0)^\top = (1,0)^\top$，方向完全不变。

### 步骤 5：竖直剪切

```python
V = np.array([[1.0, 0.0], [k, 1.0]])
print(np.linalg.det(V))     # 1.0
```

#### `np.array([[1.0, 0.0], [k, 1.0]])` —— 竖直剪切矩阵

**做什么**：把剪切因子 `k` 放在左下角，作用 $(x,y) \mapsto (x,\ kx + y)$——这次滑动的是纵坐标，正比于横坐标。
**操作**：`V[1,0]=k`，第一列 $(1,k)^\top$ 说"新的 y 坐标 = 原 y + k 倍的原 x"。
**输入**：嵌套列表，形状 `(2,2)`。
**输出**：竖直剪切矩阵，`det(V)=1.0`——面积同样守恒。
**可调参数**：`k` 语义与水平剪切相同。把水平、竖直两个剪切连用（矩阵相乘），能得到更一般的"斜向"滑动。
**对应数学**：主线定义块中的竖直剪切 $V(k) = \begin{bmatrix}1&0\\k&1\end{bmatrix}$。

## 边界声明：这套代码能做什么，不能做什么

1. **剪切保面积、不保形状**。`shoelace` 验证的是面积守恒；但剪切后任意两点的距离、任意角的角度一般都会变——用 `np.linalg.norm` 量一个点剪切前后的模长，你会发现它变了。想保持距离和角度，要用旋转或正交变换，不是剪切。别被"面积不变"误导成"什么都不变"。
2. **`S @ p` 与 `square @ S.T` 的分工**：左乘 `S @ p` 是"矩阵作用在列向量上"（数学课本惯例）；右乘 `square @ S.T` 是"每个点放在一行、批量处理"（数据科学惯例）。数值一样，但形状方向相反，初学最容易混。想通了，第 ② 步和第 ③ 步其实是同一个动作的两种排版。
3. **行列式为 1 不等于可对角化**。剪切矩阵（$k\neq0$）两个特征值都是 1，却只有一个特征方向——它是"不可对角化"矩阵的经典例子。如果你用 `np.linalg.eig(S)` 去看，会得到两个相同的特征值 1，却凑不出两个线性无关的特征向量。这是 §2.6.4 的伏笔，现在知道"特征分解不是万能的"就够。
4. **`np.linalg.det` 只对方阵有效**，且它回答的是"面积/体积的缩放"，不回答"形状怎么变"。对非方阵（比如一张图片的批量张量形状 `(N,3,64,64)`）它不适用——但那也不是"变换矩阵"，语义不同。
