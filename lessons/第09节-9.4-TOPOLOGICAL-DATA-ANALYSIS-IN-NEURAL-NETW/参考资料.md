# 参考资料：给数据装上结构之眼

## 1. 教材出处

- **Mathematical Foundations for Deep Learning** (Ghayoumi, 2026), **§9.4 TOPOLOGICAL DATA ANALYSIS IN NEURAL NETWORKS**. 教材概述 TDA 与神经网络的结合：TDA 提供考察数据形状与结构的工具，与深度学习的网络结合时，为理解数据组织方式、各部分关系以及网络行为提供独特视角；§9.4.1 将引入核心工具持久同调。

## 2. 延伸论文

- **Topological persistence and simplification** (Edelsbrunner, Letscher & Zomorodian, 2002) —— 持久同调的奠基论文："让尺度自己说话"的原始定义。
- **Topology and Data** (Carlsson, 2009) —— TDA 的宣言式综述，提出"数据有形状，形状有结构"，是理解 TDA 全局思想的最佳入口。
- **Topological Data Analysis and its applications** / **Persistent homology: theory and practice** —— 面向应用的 TDA 综述，覆盖 Mapper、持久图在数据科学中的落地。

## 3. 代码库/工具

- **scikit-tda**（`ripser`, `persim`）—— Python 生态的 TDA 工具箱：`ripser` 一行算持久同调，`persim` 画持久图/条形码（§9.4.1 的主角）。
- **gudhi** —— 更底层的 TDA 库（C++ 核心 + Python 绑定），支持 Vietoris-Rips、持久图等。
- **Topology ToolKit (TTK)** —— 面向科学可视化的拓扑工具。

## 4. 推荐阅读

- **A roadmap for the computation of persistent homology** (Otter et al., 2017) —— 中文圈常译"持久同调计算路线图"，算法层面的最佳地图。
- **Distill.pub / 科普文章 "What is Persistent Homology?"** —— 把持久图、条形码画成可交互的可视化，是 §9.4 Toy Model（星图）的完整动态版。
