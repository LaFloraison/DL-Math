# 习题：让尺度自己说话

## 第一组：概念检验

**1. 判断题并说明理由**："TDA 的核心是把数据在'一个最合适的尺度'下分析，所以首先要精心挑选聚类半径。"

**2. 单选题**：TDA 判断一个拓扑特征（如一个环）是"真结构"还是"噪声"，主要依据是？
- (A) 这个环的形状是否圆
- (B) 这个环跨越了多少个尺度（存活长度）
- (C) 这个环包含多少个点
- (D) 这个环离坐标系原点多远

**3. 简答**：为什么"数据有形状，而形状有结构"这句话对深度学习特别有意义？请结合"特征空间不可见"这一点回答。

### 解答与思路点拨

**1. 错误。** TDA 恰恰**拒绝**选择单一尺度——它的核心是"把所有的尺度一起看"，让每个特征用"存活长度"自己说话。选"正确"的读者把 TDA 和传统聚类（必须选半径）搞混了。这正是 §9.4 代码的核心：$\beta_0=3$ 存活长度 3.028 是数据自己暴露的，不需要任何人指定"半径取多少"。

**2. (B)。** TDA 的哲学：**活得久的特征是结构，一闪而过的特征是噪声**（§9.4 代码里，数据集 A 的 β0=3 活了 3.028，噪声数据集最长才 0.157）。环的形状（A）、点数（C）、位置（D）都是"度量细节"，TDA 恰恰不看重它们——这正是 §9.2"忽略细枝末节"的延续。

**3.** 深度学习的特征空间是几千维的，人眼无法直接"看"到数据在其中的形状。但 TDA 的 Betti 数不依赖"看"——它只依赖"谁和谁近"，高维空间里的环、洞、连通性全都可以计算。于是"数据被网络映射成什么形状""两类数据分开没有"这类原本只能靠降维猜的问题，变成了可计算的拓扑量。**看不见的形状，可以被数出来**——这就是 TDA 对深度学习的独特价值。

## 第二组：计算实践

**4. 手算**：一个数据集包含 2 个清晰簇，簇间距离很大。给出它的 $\beta_0$ 随 $\varepsilon$ 变化的"存活区间"示意（只写关键的 2-3 个状态与长度），并判断哪个状态是结构、哪个是噪声。

**5. 代码验证**：用本节的 `components_curve` + `state_intervals`，生成一个"2 个清晰簇"的数据集（如簇心 `[0,0]` 与 `[5,0]`，各 20 点、噪声 0.2），打印各状态的存活长度，验证"$\beta_0=2$ 活得最长"。

### 解答与思路点拨

**4.** 示意：$\beta_0=40$（每个点孤立）存活 $[0, 0.05)$ 长 0.05（噪声）；$\beta_0=2$（两个簇各自成块）存活 $[0.3, 3.5)$ 长 3.2（**结构**——最长的中间状态）；$\beta_0=1$ 存活 $[3.5, \infty)$。关键判断：**$\beta_0=2$ 的长度远超其他中间状态，它就是数据的真实结构**（两个簇）；簇内合并（40→2）的过渡是噪声。手算要点：不要纠结精确数字，抓住"哪个状态活得最久"。

**5.** 验证（复用本节函数）：

```python
rng = np.random.default_rng(1)
C = np.vstack([np.array([0,0]) + rng.standard_normal((20,2))*0.2,
               np.array([5,0]) + rng.standard_normal((20,2))*0.2])
for c, birth, death, length in sorted(state_intervals(components_curve(C)),
                                      key=lambda t: -t[3])[:4]:
    print(f"β0={c:2d}: 存活 ε∈[{birth:.3f}, {death:.3f})  长度={length:.3f}")
```

```text
β0= 1: 存活 ε∈[4.255, inf)  长度=999.000
β0= 2: 存活 ε∈[0.442, 4.255)  长度=3.813
β0= 3: 存活 ε∈[0.360, 0.442)  长度=0.082
β0= 5: 存活 ε∈[0.203, 0.284)  长度=0.081
```

$\beta_0=2$ 存活 **3.813**，其余状态 < 0.1——两个簇的结构清晰得不能再清晰。对照 §9.4 代码里 3 簇的 3.028，你会看到：**簇数就是那个"活得最久的 β0 值"，存活长度就是簇的"分离强度"。**

## 第三组：DL 延伸

**6. 场景判断**：你想用 TDA 监控训练过程——看看"两个类别的数据在网络中间层是否越分越开"。请设计：在每个训练 epoch 后，对某一隐藏层激活（两类数据各取一批）算 $\beta_0$ 的存活区间，说明你该观察什么指标、怎么解读"分开了""没分开""崩溃了"。

**7. 思考题**：§9.4 说 TDA 能"同时理解数据与网络行为"。请分别举一个"TDA 用于理解数据"和"TDA 用于理解网络"的具体场景，并说明各自的输入是什么。

### 解答与思路点拨

**6.** 指标：两类数据混合点云的 $\beta_0$ 存活曲线。**解读**：如果训练有效，随着 epoch 增加，$\beta_0=2$（两类各成一簇）的存活长度应**不断变长**——两类在特征空间里被"拉开"了；如果 $\beta_0=2$ 长度变短甚至消失（变成 $\beta_0=1$ 存活长），说明两类缠在一起，**没分开**；如果训练后期突然坍缩（所有点挤成一团，$\beta_0$ 极快降到 1），可能是**表征崩溃 (representation collapse)**——网络把所有样本映射到了同一个点。这个指标比"准确率"更早、更结构性地暴露问题。

**7.** **理解数据**：对原始输入点云（如分子结构、基因表达）算持久同调，提取"环/洞/空腔的存活长度"作为数据的结构特征——输入是原始数据，输出是拓扑特征向量。**理解网络**：对隐藏层激活（把一批输入喂进网络，取某层输出）算持久同调，看网络把数据变成了什么拓扑形状——输入是"网络+数据"，输出是"特征空间的拓扑"。两者的差别：前者回答"数据本来长什么样"，后者回答"网络把数据变成了什么样"。
