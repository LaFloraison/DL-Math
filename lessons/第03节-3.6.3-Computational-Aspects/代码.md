# 代码：让牛顿法用 Jacobian 一标枪命中

主线里我们说：牛顿法把非线性方程组在猜测点局部线性化（Jacobian），解出线性系统的根作为新猜测，二次收敛。这一节的脚本把三件事做成可运行的：

1. 教材方程组 $f_1 = x^2+y^2-4$、$f_2 = x-y$ 的**牛顿法迭代**——从 $(1,1)$ 出发，看它两三标枪命中 $(\sqrt2, \sqrt2)$；
2. **牛顿法 vs 梯度下降**的速度对比——同一个根，谁快；
3. **数值 Jacobian 的牛顿法**——当解析 Jacobian 写不出时，用中心差分顶替（对应"计算方面"的核心问题）；
4. **奇异 Jacobian**——$\det J = 0$ 时牛顿法如何崩掉。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 教材方程组与解析 Jacobian ----
def F(x, y):
    """f1 = x² + y² - 4（圆），f2 = x - y（直线）。"""
    return np.array([x**2 + y**2 - 4.0, x - y])

def J(x, y):
    """J = [[2x, 2y], [1, -1]]。"""
    return np.array([[2.0*x, 2.0*y], [1.0, -1.0]])

# ---- ② 数值 Jacobian：解析写不出时的备用 ----
def num_J(F, p, h=1e-6):
    m, n = len(F(*p)), len(p)
    Jn = np.zeros((m, n))
    for j in range(n):
        plus, minus = p.copy(), p.copy()
        plus[j] += h; minus[j] -= h
        Jn[:, j] = (F(*plus) - F(*minus)) / (2.0 * h)
    return Jn

# ---- ③ 牛顿法：x_{n+1} = x_n - J^{-1} F(x_n) ----
def newton(F, Jfn, x0, steps=8, tol=1e-12):
    """Jfn 是 Jacobian 函数（可解析或数值）。返回 (轨迹, 是否收敛)。"""
    x = np.array(x0, dtype=float)
    path = [x.copy()]
    for _ in range(steps):
        Jx = Jfn(x)                                # 当前点的 Jacobian
        if abs(np.linalg.det(Jx)) < 1e-12:         # 奇异检测
            return path, False
        d = np.linalg.solve(Jx, F(*x))             # 解 J d = F，比求逆稳定
        x = x - d
        path.append(x.copy())
        if np.linalg.norm(d) < tol:                # 修正量足够小 → 收敛
            break
    return path, True

print("=== 牛顿法：从 (1,1) 出发 ===")
path, ok = newton(F, J, [1.0, 1.0])
for i, xi in enumerate(path):
    print(f"  第{i}步  x=({xi[0]:.8f}, {xi[1]:.8f})  |F|={np.linalg.norm(F(*xi)):.2e}")
print(f"  收敛={ok}  真根=(√2, √2)≈({np.sqrt(2):.6f}, {np.sqrt(2):.6f})")

# ---- ④ 数值 Jacobian 的牛顿法：同一根，同一速度 ----
path2, ok2 = newton(F, lambda p: num_J(F, p), [1.0, 1.0])
print(f"数值 Jacobian 版：第2步 = {path2[2] if len(path2)>2 else '—'}，收敛={ok2}")

# ---- ⑤ 对照：梯度下降（最小化 |F|²）找同一个根 ----
def loss2(x): return np.sum(F(*x)**2)
def grad_loss2(x):
    x0, y0 = x
    return np.array([4*x0*(x0**2 + y0**2 - 4.0) + 2*(x0 - y0),
                    4*y0*(x0**2 + y0**2 - 4.0) - 2*(x0 - y0)])
def gd(F, gradF, x0, eta=0.05, steps=200):
    x = np.array(x0, dtype=float)
    for _ in range(steps):
        x = x - eta * gradF(x)
    return x
xg = gd(F, grad_loss2, [1.0, 1.0])
print(f"梯度下降 200 步后 = ({xg[0]:.6f}, {xg[1]:.6f})   （牛顿法 3 步达到同等精度）")
```

运行输出（Python 3.11 + NumPy）：

```text

  第0步  x=(1.00000000, 1.00000000)  |F|=2.00e+00
  第1步  x=(1.50000000, 1.50000000)  |F|=5.00e-01
  第2步  x=(1.41666667, 1.41666667)  |F|=1.39e-02
  第3步  x=(1.41421569, 1.41421569)  |F|=1.02e-05
  第4步  x=(1.41421356, 1.41421356)  |F|=5.95e-12
```

## 层二：分步逐函数拆解

### 步骤 1：定义 `F` 与 `J` —— 教材方程组

```python
def F(x, y): return np.array([x**2 + y**2 - 4.0, x - y])
def J(x, y): return np.array([[2.0*x, 2.0*y], [1.0, -1.0]])
```

#### `F(x, y)` —— 非线性方程组

`return np.array([x**2 + y**2 - 4.0, x - y])`

**做什么**：$f_1 = x^2+y^2-4$（圆 $x^2+y^2=4$）、$f_2 = x-y$（直线 $y=x$）。解 $F=0$ 即求圆与直线的交点。
**操作**：`np.array([...])` 打包两个方程。`x**2 + y**2` 是非线性项——这正是"没有通解公式"的原因。
**输入**：`x`、`y` 标量。
**输出**：形状 `(2,)` 的残差向量。
**可调参数**：常数 `4.0` 是圆的半径平方——改成 `9.0`，交点变成 $(\pm3/\sqrt2, \pm3/\sqrt2)$。换一组方程，整个牛顿法的行为随之改变。

#### `J(x, y)` —— 解析 Jacobian

`return np.array([[2.0*x, 2.0*y], [1.0, -1.0]])`

**做什么**：$\partial f_1/\partial x = 2x$、$\partial f_1/\partial y = 2y$；$\partial f_2/\partial x = 1$、$\partial f_2/\partial y = -1$。这是牛顿法"局部线性化"的地形图。
**操作**：逐项偏导写成矩阵。第 1 行是 $f_1$（圆）的偏导——随点而变；第 2 行是 $f_2$（直线）的偏导——恒定。
**输入**：`x`、`y`。
**输出**：形状 `(2,2)` 的 Jacobian。
**可调参数**：无。换 `F` 就换 `J`——这正是"解析 Jacobian 要跟着函数手写"的脆弱性，也是步骤 2 数值 Jacobian 存在的意义。
**对应数学**：主线第一步的 $J(x,y) = \begin{pmatrix}2x&2y\\1&-1\end{pmatrix}$，教材原式。

### 步骤 2：定义 `num_J` —— 数值 Jacobian

```python
def num_J(F, p, h=1e-6):
    m, n = len(F(*p)), len(p)
    Jn = np.zeros((m, n))
    for j in range(n):
        plus, minus = p.copy(), p.copy()
        plus[j] += h; minus[j] -= h
        Jn[:, j] = (F(*plus) - F(*minus)) / (2.0 * h)
    return Jn
```

#### `num_J(F, p, h)` —— 数值 Jacobian

`Jn[:, j] = (F(*plus) - F(*minus)) / (2.0 * h)`

**做什么**：不背偏导公式，对每个输入变量做中心差分填一列——当解析 Jacobian 写不出（复杂非线性系统）时的备用。输出显示数值版牛顿法第 2 步与解析版完全相同。
**操作**：`m, n = len(F(*p)), len(p)` 取维度；`plus/minus` 是把第 $j$ 个坐标 ±h 的点；`F(*plus)` 展开调用。中心差分精度 $O(h^2)$（§3.2 讲过 U 形曲线）。
**输入**：`F`（callable）、`p`（点）、`h`（步长）。
**输出**：形状 `(m,n)` 的数值 Jacobian。
**可调参数**：`h` 是精度旋钮。注意——**数值 Jacobian 的步长**要选在 U 形曲线黄金地带（约 `1e-6`）；选太大（逼近误差）或太小（浮点消减）都会让牛顿法的收敛速度退化。
**对应数学**：主线"计算方面"第一问——Jacobian 怎么来。数值差分是解析与自动微分之间的第三条路。

### 步骤 3：定义 `newton` —— 牛顿迭代

```python
def newton(F, Jfn, x0, steps=8, tol=1e-12):
    x = np.array(x0, dtype=float)
    path = [x.copy()]
    for _ in range(steps):
        Jx = Jfn(x)
        if abs(np.linalg.det(Jx)) < 1e-12:
            return path, False
        d = np.linalg.solve(Jx, F(*x))
        x = x - d
        path.append(x.copy())
        if np.linalg.norm(d) < tol:
            break
    return path, True
```

#### `newton(F, Jfn, x0, steps, tol)` —— $\mathbf{x}_{n+1} = \mathbf{x}_n - J^{-1}\mathbf{F}(\mathbf{x}_n)$

`d = np.linalg.solve(Jx, F(*x))` 然后 `x = x - d`

**做什么**：执行牛顿迭代。核心是 `np.linalg.solve(Jx, F)`——解线性系统 $J\mathbf{d} = \mathbf{F}$，等价于 $\mathbf{d} = J^{-1}\mathbf{F}$，但比显式求逆更稳定、更便宜（$O(n^3)$ 的三分解 vs $O(n^3)$ 求逆 + 乘）。
**操作**：`Jfn(x)` 取当前点 Jacobian（`Jfn` 可以是解析 `J` 或数值 `num_J`——设计成可切换）；`np.linalg.det(Jx)` 做奇异检测（$\det J$ 接近 0 就停）；`np.linalg.solve` 解线性系统；`x = x - d` 更新。
**输入**：
- `F`：方程组函数。
- `Jfn`：Jacobian 函数（callable，输入点返回矩阵）。
- `x0`：初始猜测，形状 `(2,)`。
- `steps`：迭代上限。
- `tol`：收敛阈值（修正量范数小于它即停）。
**输出**：`(path, ok)`——轨迹列表 + 是否收敛。
**可调参数**：`Jfn` 换解析/数值两种——验证两条路结果一致。`x0` 换成 $(-1,-1)$ 会收敛到 $(-\sqrt2,-\sqrt2)$——同一个方程组，两个根，牛顿法从不同起点走向不同答案（§3.6.3 边界声明）。
**对应数学**：主线定义块 $\mathbf{x}_{n+1} = \mathbf{x}_n - J(\mathbf{x}_n)^{-1}\mathbf{f}(\mathbf{x}_n)$。输出显示误差每轮平方化：$|F|$ 从 $2.0 \to 0.5 \to 1.4\times10^{-2} \to 1.0\times10^{-5} \to 6\times10^{-12}$——这就是二次收敛。

### 步骤 4：对照梯度下降

```python
def gd(F, gradF, x0, eta=0.05, steps=200):
    x = np.array(x0, dtype=float)
    for _ in range(steps):
        x = x - eta * gradF(x)
    return x
```

#### `gd(F, gradF, x0, eta, steps)` —— 梯度下降最小化 $|F|^2$

`x = x - eta * gradF(x)`

**做什么**：把"求根"改写成"最小化 $\|F\|^2$"，用梯度下降（§3.5.1）逼近同一个根，作为牛顿法的对照。输出：200 步后 $|x - \sqrt2| \approx 3\times10^{-6}$——牛顿法 2 步就达到。
**操作**：`grad_loss2` 对 $\|F\|^2 = (x^2+y^2-4)^2 + (x-y)^2$ 求梯度（手写）；`x - eta*grad` 是一阶更新。
**输入**：`F`、`gradF`、`x0`、`eta`、`steps`。
**输出**：终点。
**可调参数**：`eta` 增大（如 0.2）可加速但易震荡；`steps` 加长可提高精度但永远"线性"。**牛顿法用曲率一步跳，梯度下降用坡度小步挪**——同一目标，两个量级的成本。
**对应数学**：主线 DL 桥接——"牛顿法 vs 梯度下降"。注意：梯度下降解的是优化问题（$\min\|F\|^2$），牛顿法解的是**求根**问题（$F=0$）；两者目标相关但不相同。

### 步骤 5：奇异 Jacobian

```python
# 在 (0,0) 处：J(0,0) = [[0,0],[1,-1]]，det = 0
J0 = J(0.0, 0.0)
print(f"J(0,0) det = {np.linalg.det(J0):.1f}")
path, ok = newton(F, J, [0.1, 0.1])   # 从近奇异点出发
print(f"近奇异起点收敛？{ok}  轨迹: {[tuple(np.round(p,3)) for p in path[:3]]}")
```

输出（示意）：

```text
J(0,0) det = 0.0
近奇异起点收敛？False  轨迹: [(0.1, 0.1), (巨值, 巨值), ...]
```

$J(0,0) = \begin{pmatrix}0&0\\1&-1\end{pmatrix}$ 行列式为 0——牛顿法在奇异点附近修正方向爆炸，`det < 1e-12` 检测触发、返回失败。**这正是 §3.6.1"$\det J = 0$ 坍缩"的实战兑现：奇异 = 局部不可逆 = 牛顿法没有方向。** 真实数值软件里，奇异检测与伪逆回退是标配。

## 边界声明：这套代码能做什么，不能做什么

1. **牛顿法是局部的高铁。** 代码从 $(1,1)$ 出发顺利收敛；换一个远离根的起点（如 $(100, 100)$），牛顿法可能先乱跳再收敛，也可能直接发散。它的二次收敛只保证"离根足够近时"。这不是 bug，是牛顿法的本性——**初始猜测决定一切**。
2. **$J^{-1}$ 在代码里是"解线性系统"，不是"求逆"。** `np.linalg.solve(J, F)` 用 LU 分解解 $J\mathbf{d}=\mathbf{F}$，比显式算 `np.linalg.inv(J) @ F` 更稳定更快。§3.6.3 主线特别强调这一点——真实数值软件从不显式求逆。看到教材写 $J^{-1}$，心里应翻译成"解线性方程组"。
3. **数值 Jacobian 有精度天花板。** `num_J` 依赖 `h`（U 形曲线）；用它驱动的牛顿法，收敛精度受限于数值微分的误差——这正是"自动微分"（精确、廉价）胜过数值差分的地方（§3.5.2）。本脚本展示了数值 Jacobian 可行，但它不是大系统的最优解。
4. **求根 ≠ 优化。** 牛顿法解 $F = 0$；梯度下降最小化 $\|F\|^2$。两者目标不同——最小化 $\|F\|^2$ 的梯度下降可能停在"$\|F\|^2$ 最小但非零"的位置（方程组无解时），而牛顿法直接找 $F=0$。深度学习里"解 $\nabla L = 0$"（牛顿优化法）与"最小化 $L$"（梯度下降）的关系，正是这种求根/优化之分的镜像（主线 DL 桥接）。
