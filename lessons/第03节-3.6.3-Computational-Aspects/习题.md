# 习题：Jacobian 的计算方面

## 一、概念检验

### 题 1.1（填空）

多元牛顿法的迭代公式是 $\mathbf{x}_{n+1} = \mathbf{x}_n - J(\mathbf{x}_n)^{-1}\,\mathbf{f}(\mathbf{x}_n)$。其中 $J(\mathbf{x}_n)$ 是____；$J^{-1}$ 存在要求____；该方法在离根足够近时____收敛（误差大致平方化）。

**解答**：$\mathbf{f}$ 在 $\mathbf{x}_n$ 处的 Jacobian 矩阵；$\det J \neq 0$（$J$ 可逆）；二次（quadratic）。
**思路点拨**：三个关键词——Jacobian（线性化地形图）、可逆（奇异检测）、二次收敛（位数翻倍）。注意教材写法里的 $J^{-1}$ 在实现时通常翻译成"解线性方程组 $J\mathbf{d} = \mathbf{f}$"（`np.linalg.solve`），比显式求逆更稳定（§3.6.3 代码边界声明）。答错"线性收敛"的同学把牛顿法和梯度下降搞混了——**梯度下降线性、牛顿二次**。

### 题 1.2（选择）

下列关于牛顿法**正确**的是（ ）

A. 从任何起点都能收敛到根
B. 每步都要构造并分解 Jacobian，成本 $O(n^3)$
C. 数值 Jacobian（中心差分）总是优于解析 Jacobian
D. $\det J = 0$ 时牛顿法依然照常工作

**解答**：B。
**思路点拨**：A 错误——牛顿法是**局部**的，起点离根太远会发散或跳到别的根（教材方程组有两个根，起点决定落点）。B 正确——每步构造并分解 $J$（LU 分解）是 $O(n^3)$，比梯度下降每步 $O(n)$ 贵得多，这是它快却不普及的原因。C 错误——数值 Jacobian 有 $h$ 精度天花板（U 形曲线），解析/自动微分更精确；数值只是"写不出解析时的备用"。D 错误——$\det J = 0$ 时 $J^{-1}$ 不存在，牛顿法崩掉（§3.6.1 的坍缩警告）。

### 题 1.3（简答）

教材把这一节叫"计算方面 (Computational Aspects)"。请列出 Jacobian 在计算上的三个关键问题，并各给一句简短答案。

**解答**：① **Jacobian 怎么来？**——解析（手写偏导）、数值（中心差分）或自动微分（反向传播）；大系统首选自动微分。② **Jacobian 怎么用？**——不显式求逆，而是解线性系统 $J\mathbf{d} = \mathbf{f}$（`np.linalg.solve`），更便宜更稳定。③ **Jacobian 何时失效？**——$\det J = 0$（奇异）时 $J^{-1}$ 不存在，需奇异检测与回退；$\det J$ 近零时修正方向病态。
**思路点拨**：这三个问题串起来就是牛顿法的"工程观"——知道怎么算、怎么用、何时崩。能回答出"解线性系统而非求逆"与"自动微分优先"，说明你读懂了 §3.6.3 的计算视角，也提前理解了框架内部的工程选择。

## 二、计算实践

### 题 2.1（手算）

教材方程组 $f_1 = x^2 + y^2 - 4$，$f_2 = x - y$，Jacobian $J = \begin{pmatrix}2x&2y\\1&-1\end{pmatrix}$。

(a) 从 $(x_0, y_0) = (1, 1)$ 出发，计算第一轮牛顿迭代的结果。
(b) 计算第二轮的 $J$ 和结果。
(c) 与真根 $(\sqrt2, \sqrt2)$ 比较，说明收敛速度。

**解答**：
(a) $f(1,1) = (-2, 0)$，$J(1,1) = \begin{pmatrix}2&2\\1&-1\end{pmatrix}$，$\det = -4$。解 $J\mathbf{d} = \mathbf{f}$：$\begin{pmatrix}2&2\\1&-1\end{pmatrix}\begin{pmatrix}d_1\\d_2\end{pmatrix} = \begin{pmatrix}-2\\0\end{pmatrix}$。解得 $d_1 = -0.5$，$d_2 = -0.5$。$(x_1,y_1) = (1,1) - (-0.5,-0.5) = (1.5, 1.5)$。
(b) $f(1.5,1.5) = (0.5, 0)$，$J = \begin{pmatrix}3&3\\1&-1\end{pmatrix}$，$\det = -6$。解 $\begin{pmatrix}3&3\\1&-1\end{pmatrix}\mathbf{d} = \begin{pmatrix}0.5\\0\end{pmatrix}$：得 $d = (1/12, 1/12) \approx (0.0833, 0.0833)$。$(x_2,y_2) = (1.5,1.5) - (0.0833,0.0833) = (1.4167, 1.4167)$。
(c) $\sqrt2 \approx 1.4142$。第二轮已到 $1.4167$（误差 $\approx 2.5\times10^{-3}$）；第三轮 $\approx 1.4142$（误差 $\approx 2\times10^{-6}$）。**误差从 $10^{-3}$ 跳到 $10^{-6}$——位数约翻倍，二次收敛。**
**思路点拨**：注意求逆/解方程这一步——$J\mathbf{d}=\mathbf{f}$ 比手写逆矩阵更稳。手算一次，体会"每步要重算 $J$、重解线性系统"的成本。对照《代码.md》的 `newton` 输出，$(1.5,1.5) \to (1.4167,1.4167) \to (1.4142,1.4142)$ 逐行吻合。

### 题 2.2（代码验证）

用 NumPy 验证：从 $(x_0,y_0) = (-1,-1)$ 出发，牛顿法收敛到另一个根 $(-\sqrt2, -\sqrt2)$。

```python
import numpy as np
def F(x, y): return np.array([x**2 + y**2 - 4.0, x - y])
def J(x, y): return np.array([[2.0*x, 2.0*y], [1.0, -1.0]])
x = np.array([-1.0, -1.0])
for _ in range(5):
    d = np.linalg.solve(J(*x), F(*x))
    x = x - d
    print(f"x = ({x[0]:.6f}, {x[1]:.6f})")
print(f"真根 = ({-np.sqrt(2):.6f}, {-np.sqrt(2):.6f})")
```

**解答**：牛顿法从 $(-1,-1)$ 出发收敛到 $(-\sqrt2, -\sqrt2) \approx (-1.4142, -1.4142)$，约 4-5 步达到 6 位小数精度。
**思路点拨**：同一个方程组、同一个方法，**起点不同落点不同**——教材方程组有两个根，牛顿法"最近的局部根"由起点决定。这是牛顿法"局部收敛"的直接证据：它不保证找到"所有根"，只保证"起点附近的那个根"。换起点 $(-1,1)$ 试试——它可能发散或飞向 $(-\sqrt2,-\sqrt2)$，因为 $(-1,1)$ 不是任何根的邻域。

## 三、DL 延伸

### 题 3.1

深度学习优化里，牛顿法推广为 $\theta \leftarrow \theta - H^{-1}\nabla L$，其中 $H$ 是海森矩阵（$\nabla L$ 的 Jacobian）。请解释：为什么几千亿参数的模型**不用**这个牛顿法，而用 Adam、L-BFGS 这类近似？

**解答**：因为 $H$ 是 $n \times n$ 的矩阵（$n$ = 参数量），构造它要算 $O(n^2)$ 个二阶偏导、求逆要 $O(n^3)$——几千亿参数下这两步都是天文数字（$n^3$ 是 $10^{27}$ 量级的运算）。于是工程退而求其次：**用一阶信息近似二阶信息**——Adam 用一阶梯度历史的平方（二阶矩）估计每维曲率，L-BFGS 用有限的梯度历史逼近 $H^{-1}$。它们用"近似曲率"换来了"每步 $O(n)$ 的成本"，保住了牛顿法的方向直觉、甩掉了它的矩阵成本。
**思路点拨**：这道题把"$O(n^3)$ 求逆"与"深度学习为什么用一阶近似"接起来。能说出"牛顿法要 $H$ 与求逆、太贵，所以用一阶近似曲率"就抓住了 §3.6.3 DL 桥接的核心。这也是为什么"二次收敛"在深度学习中永远是个传说——**它快，但它贵到没人付得起。**

### 题 3.2

隐式神经网络（如 Deep Equilibrium Model）的解是"不动点" $z^* = f_\theta(z^*, x)$ 的解，训练时要用**隐式求导**，其核心是解一个含 Jacobian 的线性系统 $\left(I - \frac{\partial f}{\partial z}\right)\mathbf{d} = \mathbf{g}$。请用本节知识说明：这个线性系统与牛顿法的哪个环节同构？为什么它能避免"显式算整张 Jacobian"？

**解答**：这与牛顿法的"解线性系统 $J\mathbf{d} = \mathbf{f}$"环节同构——两者都是"通过解一个含 Jacobian 的线性系统来得到修正量 $\mathbf{d}$"，且都用 `np.linalg.solve` 类的分解方法而非显式求逆。它避免显式算整张 $J$ 的方式是：把"矩阵乘 $J\mathbf{d}$"实现为一次**向量-Jacobian 积（vector-Jacobian product）**——用自动微分按方向作用，而不是物化 $n\times n$ 矩阵；配合迭代法（如共轭梯度）解这个线性系统，成本由"矩阵分解"降为"多次向量-矩阵积"。本质上和牛顿法"不显式求逆、解线性系统"是同一个思想的更彻底版本：**只按需要的方向使用 Jacobian，从不把它当矩阵存下来。**
**思路点拨**：这道题把 §3.6.3 的"解线性系统而非求逆"推演到极限——连"构造矩阵"都省了，只用 vector-Jacobian product。能说出"矩阵乘被替换成向量-Jacobian 积"就抓住了现代数值微分（隐式求导、JAX 生态）与本节计算思想的传承。这是 Jacobian"计算方面"在当前深度学习前沿最犀利的落点。
