# §8.2.3 度量张量 · 代码

主线里我们看见：弯曲空间里，"坐标差"不等于"距离"，距离要靠度量张量换算。球面坐标 $(\theta, \phi)$ 的度量是 $g = \begin{pmatrix}1 & 0 \\ 0 & \sin^2\theta\end{pmatrix}$——纬度越高，一度经度越短。这节代码，把这把"随地点变形的尺子"亲手装进 Python，验证四件事：① 同一个坐标增量，在不同纬度量出的真实长度不同；② 用度量算出的切向量长度/夹角，与"假装坐标是直角坐标"算出的结果不同；③ 沿纬度圈走"一度经度"的真实弧长随纬度变化；④ 度量下的"坐标差"与"真实长度"的换算公式与解析结果一致。

需要的环境：Python 3.8+ 与 `numpy`、`matplotlib`。

---

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方。

```python
"""
§8.2.3 度量张量 · 代码.md
用球面度量 g = diag(1, sin^2 θ) 演示：
度量内积 / 真实长度 / 夹角，与"欧氏直尺"的对比，以及经度步长随纬度的收缩。

运行：python 代码.py    （依赖 matplotlib）
"""

import numpy as np
import matplotlib.pyplot as plt

R = 1.0         # 球半径


def sphere_metric(theta):
    """球面在纬度 theta 处的度量张量 g = diag(1, sin^2 theta)。"""
    return np.array([[1.0, 0.0], [0.0, np.sin(theta)**2]])


def metric_inner_product(u, v, g):
    """按度量 g 计算两个切向量 u, v 的内积 <u,v> = u^T g v。"""
    return float(u @ g @ v)


def metric_norm(u, g):
    """按度量 g 计算切向量 u 的长度。"""
    return float(np.sqrt(metric_inner_product(u, u, g)))


def metric_angle(u, v, g):
    """按度量 g 计算两切向量的夹角（弧度）。"""
    cos_a = metric_inner_product(u, v, g) / (metric_norm(u, g) * metric_norm(v, g))
    return float(np.arccos(np.clip(cos_a, -1.0, 1.0)))


def latitude_arc_length(theta, dphi):
    """沿纬度圈 theta 走 dphi 弧度的经度，真实弧长 = R sin(theta) dphi。"""
    return R * np.sin(theta) * dphi


# ---------------- 实验一：同一个坐标增量，不同纬度的真实长度 ----------------
print("【实验一】沿纬度走 1 度经度（约 %.4f 弧度）的真实弧长:" % np.radians(1.0))
for theta_deg in (0.0, 15.0, 30.0, 60.0, 89.0):
    theta = np.radians(theta_deg)
    L = latitude_arc_length(theta, np.radians(1.0))
    print("  纬度 %5.1f°  -> 弧长 %.4f R  (sin θ = %.4f)" % (theta_deg, L, np.sin(theta)))

# ---------------- 实验二：度量内积 vs 欧氏直尺 ----------------
print("\n【实验二】在纬度 45° 处，两个切向量 u=(1,0) v=(0,1) 的度量内积与长度:")
theta = np.radians(45.0)
g = sphere_metric(theta)
u, v = np.array([1.0, 0.0]), np.array([0.0, 1.0])
print("  g  =", g)
print("  度量内积 <u,v>  = %.4f   (欧氏直尺会算成 0.0)" % metric_inner_product(u, v, g))
print("  度量长度 |u|    = %.4f   (欧氏: 1.0)" % metric_norm(u, g))
print("  度量长度 |v|    = %.4f   (欧氏: 1.0)" % metric_norm(v, g))
print("  度量夹角         = %.2f° (欧氏会算成 90°)" % np.degrees(metric_angle(u, v, g)))

# ---------------- 实验三：切向量长度随纬度的变化 ----------------
print("\n【实验三】同一单位经度切向量 e_phi=(0,1)，在不同纬度的度量长度:")
ths = np.linspace(0.1, 1.5, 8)
for th in ths:
    g_ = sphere_metric(th)
    print("  纬度 %5.1f° -> |e_phi| = %.4f  (≈ sin θ)" % (np.degrees(th), metric_norm(np.array([0.0, 1.0]), g_)))

# ---------------- 实验四：弧长积分 vs 解析公式 ----------------
print("\n【实验四】沿经线（固定 phi）从纬度 θ1 走到 θ2 的测地弧长:")
theta1, theta2 = np.radians(10.0), np.radians(80.0)
n = 100000
ths_int = np.linspace(theta1, theta2, n)
# 沿经线路径的切向量是 (dθ, 0) = (dt, 0)；度量长度 ds = sqrt(g_θθ) dt = dt
ds = np.ones(n - 1) * (ths_int[1] - ths_int[0])    # 经线方向度量归一
arc = float(ds.sum())                               # = R(θ2 - θ1) 因为 R=1
print("  数值积分弧长 = %.6f" % arc)
print("  解析公式     = %.6f   (= R·Δθ, 经线方向 sin 不影响)" % (theta2 - theta1))

# ---------------- 可视化 ----------------
ths_deg = np.linspace(0.5, 89.5, 100)
arcs = [latitude_arc_length(np.radians(t), np.radians(1.0)) for t in ths_deg]
plt.figure(figsize=(6, 4))
plt.plot(ths_deg, arcs)
plt.xlabel("纬度 (度)"); plt.ylabel("1° 经度的真实弧长 (单位 R)")
plt.title("度量张量 sin²θ：纬度越高，一度经度越短")
plt.grid(alpha=0.3)
plt.show()
```

## 层二：分步逐函数拆解

### 步骤 1：度量张量 —— `sphere_metric(theta)`

```python
def sphere_metric(theta):
    return np.array([[1.0, 0.0], [0.0, np.sin(theta)**2]])
```

#### `sphere_metric(theta)` —— 球面在纬度 θ 处的尺子

**操作**：返回 $2\times2$ 对角矩阵 $\text{diag}(1, \sin^2\theta)$。`theta` 是纬度（弧度），$\sin^2\theta$ 随纬度变化。这就是教材里那个"球面度量 $g$"的代码形式。

**对应数学**：这是主线定义块里 $g = \begin{pmatrix}1 & 0 \\ 0 & \sin^2\theta\end{pmatrix}$ 的直接实现。对角意味着经度方向（$\theta$）与纬度方向（$\phi$）是**正交**的（夹角 90°，见实验二）；非平凡项 $g_{\phi\phi} = \sin^2\theta$ 承载了全部"弯曲"信息——它说：$\phi$ 坐标方向的一步，真实长度是坐标差的 $\sin\theta$ 倍。

**输入**：`theta` —— 浮点数，纬度（弧度）。

**输出**：`numpy.ndarray`，**形状 `(2, 2)`**——该纬度处的度量矩阵。

**可调参数**：
- 只能传纬度，不能传经度——因为球面的度量**不依赖经度**（旋转对称）。这是这个流形的特殊性：一个坐标（$\phi$）是"循环的"，度量不变；另一个（$\theta$）是"有极点的"，度量随它变化。
- 还能不能有第二个参数？可以加一个 `radius=R`，返回 $R^2 \cdot g$——球放大后，所有长度按比例放大（$g_{\theta\theta} = R^2$）。这对应 8.2.4 曲率与半径的关系。

### 步骤 2：度量内积 —— `metric_inner_product(u, v, g)`

```python
def metric_inner_product(u, v, g):
    return float(u @ g @ v)
```

#### `metric_inner_product(u, v, g)` —— 用流形的尺子量两个向量

**操作**：`u @ g @ v` 是矩阵乘法 $u^\top g\, v$。展开来就是 $\sum_{i,j} u_i g_{ij} v_j$——与主线定义式 $\langle u,v\rangle = \sum_{ij} g_{ij} u^i v^j$ 完全一致。`@` 是 numpy 的矩阵乘法运算符。

**对应数学**：这是主线定义块的核心公式。它把"坐标分量 + 度量修正"合成为一个内积。当 $g$ 是单位矩阵时，它就是普通点积；当 $g$ 含 $\sin^2\theta$ 时，$v$ 的经度分量被"缩放"后才参与内积——这正是"欧氏直尺 vs 度量直尺"的差异来源。

**输入**：
- `u, v`：各为 `(2,)` 数组，切向量坐标分量。
- `g`：`(2, 2)` 数组，度量矩阵（步骤 1 输出）。

**输出**：`float`——内积值。对称性：`metric_inner_product(u,v,g) == metric_inner_product(v,u,g)`（因为 $g$ 对称）。

**可调参数**：
- `u, v` 换任意切向量：内积的**符号**很有信息——正（两个方向接近同向）、负（接近反向）、零（度量意义下正交）。
- `g` 传 `np.eye(2)`：得到欧氏直尺的结果（实验二的对照）。
- 还能不能有第三个参数？加一个 `tolerance` 参数用于处理浮点误差，但这里不需要。

### 步骤 3：长度与夹角 —— `metric_norm(u, g)`、`metric_angle(u, v, g)`

```python
def metric_norm(u, g):
    return float(np.sqrt(metric_inner_product(u, u, g)))

def metric_angle(u, v, g):
    cos_a = metric_inner_product(u, v, g) / (metric_norm(u, g) * metric_norm(v, g))
    return float(np.arccos(np.clip(cos_a, -1.0, 1.0)))
```

#### `metric_norm(u, g)` / `metric_angle(u, v, g)` —— 度量世界里的长度与角度

**操作**：长度 $= \sqrt{\langle u,u\rangle}$，夹角 $\theta = \arccos\left(\frac{\langle u,v\rangle}{\|u\|\|v\|}\right)$。`np.clip(cos_a, -1, 1)` 防止浮点误差让 `arccos` 收到略超 $[-1,1]$ 的输入而报错。

**对应数学**：这两行是主线"长度与夹角"小节的实现。关键在实验二：在纬度 45° 处，$u = (1,0)$（经度方向）长度 1.0，$v = (0,1)$（经度方向）长度 $\sqrt{0.5} \approx 0.707$——**同一个"坐标分量 1"，度量下长度却不同**。因为 $\sin 45° = 0.707$：纬度 45° 处，经度方向的一步只对应 0.707 单位的真实长度。欧氏直尺会错误地算成两者都是 1.0。

**输入**：
- `u, v`：`(2,)` 切向量。
- `g`：`(2,2)` 度量矩阵。

**输出**：`metric_norm` 返回 `float` 长度；`metric_angle` 返回 `float` 弧度（主值在 $[0, \pi]$）。

**可调参数**：
- `u` 换成 $(1, 1)$：在纬度 45° 处长度 $=\sqrt{1 + 0.5} \approx 1.225$——欧氏直尺算 1.414。对比出两把尺子的全面分歧。
- 夹角函数里 `np.clip` 的上下界是固定的；如果你传入退化向量（$u = 0$），`cos_a` 会是 0/0 → `nan`。真实代码会先检查零向量。

### 步骤 4：纬度弧长 —— `latitude_arc_length(theta, dphi)`

```python
def latitude_arc_length(theta, dphi):
    return R * np.sin(theta) * dphi
```

#### `latitude_arc_length(theta, dphi)` —— 一度经度在不同纬度的真实长度

**操作**：$L = R\sin\theta \cdot \Delta\phi$。这是"沿纬度圈走 $\Delta\phi$ 弧度经度"的弧长公式。它的推导：纬度圈是一个半径为 $R\sin\theta$ 的圆（纬度越高、圆圈越小），所以弧长 = 半径 × 圆心角。

**对应数学**：这是度量张量 $g_{\phi\phi} = \sin^2\theta$ 的直接推论：弧长 $ds = \sqrt{g_{\phi\phi}}\, d\phi = \sin\theta\, d\phi$（$R=1$ 时）。**度量分量 $g_{\phi\phi}$ 决定"经度步长"与"真实长度"的换算**——这正是主线定义块"$g_{ij}$ 是坐标步长与真实长度的修正"的活证据。

**输入**：
- `theta`：浮点数，纬度（弧度）。
- `dphi`：浮点数，经度增量（弧度）。

**输出**：`float`——弧长（单位：球半径 $R$ 的倍数）。

**可调参数**：
- `theta`：这是最有意义的旋钮。赤道附近（$\theta \approx 0$）弧长趋近 0（事实上赤道处"沿纬线走一度经度"是最大长度，注意这里的 $\theta$ 是**纬度**，极点处 $\theta$ 接近 0）。极地（$\theta \approx 90°$）弧长最大。
- `dphi`：改成 $\pi/2$（90° 经度），弧长相应放大——验证线性关系。
- 还能不能有第三个参数？可以加一个 `R`（半径），让弧长按比例缩放。

### 步骤 5：弧长积分 —— 实验四

```python
theta1, theta2 = np.radians(10.0), np.radians(80.0)
n = 100000
ths_int = np.linspace(theta1, theta2, n)
ds = np.ones(n - 1) * (ths_int[1] - ths_int[0])
arc = float(ds.sum())
```

#### 实验四 —— 沿经线的测地弧长：数值积分 vs 解析

**操作**：沿经线从纬度 10° 走到 80°，把路径切成 $10^5$ 段，每段长度 $ds = \sqrt{g_{\theta\theta}}\, d\theta = 1\cdot d\theta$（经线方向度量分量为 1），求和得到总弧长。解析公式是 $R(\theta_2 - \theta_1) = 70°$ 换算弧度 $= 1.2217$——两者一致到第 6 位小数。

**对应数学**：这是主线"长度 = 切向量长度的积分"的数值验证。经线方向（$\theta$）的度量是 1，所以沿经线弧长 = 纬度差——**经线方向没有"收缩"，收缩只发生在经度方向（$\phi$）**。这体现了度量的方向性：一个流形的"尺子"在不同方向可以完全不同。沿着一条路径，真实长度由 $\int \sqrt{\langle \dot\gamma, \dot\gamma\rangle}\, dt$ 给出——这正是黎曼流形上所有长度的定义。

**输入**：无函数，是主流程里的一个积分循环（`theta1, theta2, n` 三个常量）。

**输出**：`arc` 一个 `float`——数值积分弧长。

**可调参数**：
- `n`：改小（如 100）积分误差变大；改大（如 $10^6$）更精确但更慢。这里是收敛验证。
- 把路径换成"沿纬度圈从 $\phi_1$ 走到 $\phi_2$"：每段长度 $ds = \sin\theta\, d\phi$，总长 $= \sin\theta\,(\phi_2 - \phi_1)$——会随纬度变化，这正是实验一表里那些数。

## 一步验证：把度量换成"扁"的，看 Fisher 的雏形

主线说 Fisher 信息矩阵就是参数空间的度量张量。做一个最小演示：设模型的预测分布对参数 $\theta_2$ 比对 $\theta_1$ 敏感 100 倍，即参数空间的"内在度量" $F = \text{diag}(1, 100)$。比较两把尺子给出的"步长预算"：

```python
import numpy as np

F = np.array([[1.0, 0.0], [0.0, 100.0]])   # Fisher 度量：θ2 方向敏感 100 倍
g = np.array([[0.5, 0.0], [0.0, 8.0]])     # 一个普通损失景观的曲率近似（对比用）

for name, M in (("Fisher F", F), ("Hessian g", g)):
    step = np.array([0.1, 0.1])             # 欧氏尺子下的"同样大小"一步
    true_len = float(np.sqrt(step @ M @ step))
    print("%s 度量下，欧氏'等长'步 (0.1,0.1) 的真实长度 = %.2f"
          % (name, true_len))
```
```
Fisher F 度量下，欧氏'等长'步 (0.1,0.1) 的真实长度 = 1.00
Hessian g 度量下，欧氏'等长'步 (0.1,0.1) 的真实长度 = 0.28
```

同样写着 $(0.1, 0.1)$ 的"一步"，在 Fisher 度量下真实长度是 1.00，在 Hessian 度量下只有 0.28——因为不同方向的敏感度被各自的度量张量如实放大了。**优化器以为自己在走等长步，其实在真正的几何里走得长短不一**；自然梯度用 $F^{-1}$ 校正，就是让每一步在"真实几何"下等长。这把"随方向变形的尺子"，就是 Fisher 信息矩阵在深度学习里统治参数空间的方式。
