# §8.2.3 度量张量 —— 习题

本章主线讲了三件事：度量张量把"坐标差"换算成"真实长度/角度"，逐点定义流形的几何；欧氏空间里它是单位矩阵，球面上是 $\text{diag}(1, \sin^2\theta)$；在深度学习中，Fisher 信息矩阵就是参数空间的度量张量，自然梯度用 $F^{-1}$ 校正步长。下面的习题分三组：**概念检验** 验证核心定义，**计算实践** 把度量换算亲手算一遍（含代码验证），**DL 延伸** 把 Fisher 度量放回自然梯度与正则化的场景。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：关于度量张量，哪个说法**错误**？

- A. 度量张量在流形的每个点定义一个内积，用于量长度和夹角
- B. 在欧氏空间 $\mathbb{R}^n$ 中，度量张量是单位矩阵，内积退化为普通点积
- C. 度量张量的分量 $g_{ij}$ 与坐标选择无关，任何坐标下都完全相同
- D. 球面的度量 $g_{\phi\phi} = \sin^2\theta$ 表明纬度越高，"一度经度"越短

**解答**：C。

C 错：度量张量的**分量** $g_{ij}$ 严重依赖坐标选择——同一张球面，用经纬坐标与用直角坐标写出的 $g_{ij}$ 完全不同。坐标无关的是**度量所定义的真实几何**（测地距离、夹角），不是分量本身。A 对：度量张量 = 切空间上的内积场。B 对：单位矩阵时退化为 $\sum u_i v_i$。D 对：$\sin^2\theta$ 越小，经度步长的真实长度越短。

**思路点拨**：题眼是"分量 vs 几何"的分离——这正是主线边界声明强调的"坐标的看法 vs 坐标无关的事实"。最容易错的直觉是"度量是一个固定矩阵"，实际上它是**场**（逐点变化）且分量随坐标变。判据：真实长度坐标无关，$g_{ij}$ 分量坐标相关，两者别混。

### 题 2（判断 + 简答）：度量张量是不是"用来量地球的尺子"？

有人说："度量张量只是纯数学的抽象，深度学习里用不到它。" 用 Fisher 信息矩阵回应这个说法：它在深度学习中扮演什么角色？

**解答**：错。Fisher 信息矩阵 $F(\theta) = \mathbb{E}[\nabla_\theta \log p\, \nabla_\theta \log p^\top]$ 在数学结构上就是一个黎曼度量（参数空间上的度量张量）。它度量"参数微扰 $\delta\theta$ 在多大程度上改变模型的预测分布"。深度学习里它至少有三个角色：

1. **自然梯度下降**：用 $F^{-1}\nabla L$ 校正梯度，在参数敏感方向走小步、平坦方向走大步，收敛更快更稳；
2. **正则化设计**：用 Fisher 度量（而非欧氏）衡量模型复杂度，惩罚过度敏感的参数；
3. **理解泛化与优化**：Fisher 度量的特征值刻画参数空间的"可识别性"，与 8.3.3 平坦/尖锐极小值直接相关。

**思路点拨**：这道题考的是"度量张量 = Fisher 信息矩阵"这个对照是否能记住并展开。回答的骨架：Fisher 度量是参数空间的内积 → 它决定"哪个方向的一步对模型影响大" → 优化器与正则化都靠它校准。若只说"Fisher 是统计量"而不谈它作为度量的几何角色，说明还没接住本节的核心命题。

### 题 3（简答）：为什么"欧氏距离"在参数空间里会骗人？

训练两个模型，参数分别是 $\theta_A, \theta_B$，它们差的欧氏距离 $\|\theta_A - \theta_B\|$ 很小。这能说明"两个模型的行为很接近"吗？为什么？

**解答**：**不能。** 欧氏距离 $\|\theta_A - \theta_B\|$ 只衡量"参数向量的坐标差"，不衡量"模型行为的差异"。模型的输出由预测分布 $p(y|x,\theta)$ 决定；而"参数变化多少 → 输出变化多少"由度量张量（Fisher 信息矩阵）决定，不是欧氏度量。

两个极端：如果 $\theta_A, \theta_B$ 之差落在 $F$ 的**大特征值方向**（参数敏感区），$\|\theta_A - \theta_B\|$ 虽小，两个模型的预测可能天差地别；如果差落在 $F$ 的小特征值方向（参数平坦区），坐标差再大，预测也几乎不变。**用欧氏尺子量参数空间，等于假设参数空间处处等比例——而 Fisher 度量告诉我们这不是真的。**

**思路点拨**：这是主线"尺子随地点变形"的直接应用。核心判断：**"坐标差"与"行为差"之间隔着度量张量**。这也解释了为什么"参数插值"（如模型平均）不能简单在欧氏空间做——要在 Fisher 度量的内在几何里做，这正是 8.3.4 信息几何的用武之地。

## 二、计算实践

### 题 1（球面度量的换算）

单位球面上，取纬度 60° 处的点。切空间里有三个向量：$u = (1, 0)$、$v = (0, 1)$、$w = (2, 1)$（分量是坐标方向的增量）。

(a) 写出该点的度量矩阵 $g$。
(b) 用度量计算 $\|u\|$、$\|v\|$、$\|w\|$。
(c) 用度量计算 $u$ 与 $v$ 的夹角，并与欧氏直尺的结果对比。

**解答**：

(a) $\theta = 60°$，$\sin 60° = \frac{\sqrt{3}}{2}$，所以
$$g = \begin{pmatrix} 1 & 0 \\ 0 & \sin^2 60° \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & \frac{3}{4} \end{pmatrix}$$

(b) $\|u\| = \sqrt{u^\top g u} = \sqrt{1} = 1$。$\|v\| = \sqrt{v^\top g v} = \sqrt{\frac{3}{4}} = \frac{\sqrt{3}}{2} \approx 0.866$。$\|w\| = \sqrt{(2,1) g (2,1)^\top} = \sqrt{4 + \frac{3}{4}} = \sqrt{\frac{19}{4}} = \frac{\sqrt{19}}{2} \approx 2.179$。

注意 $\|w\|^2 = 4\|u\|^2 + \|v\|^2 + 2\cdot\langle u, v\rangle$——但因为 $\langle u, v\rangle = u^\top g v = 0$，$u, v$ 度量正交，所以 $\|w\|^2 = 4 + \frac{3}{4}$ 正好是各分量长度平方和。

(c) $\cos\angle(u,v) = \frac{\langle u,v\rangle}{\|u\|\|v\|} = \frac{0}{1 \times 0.866} = 0$，夹角 $= 90°$。**欧氏直尺也算 90°**——因为 $u, v$ 沿坐标轴方向，而度量是对角的，两方向度量正交。真正的分歧出现在"长度"上（$\|v\|$ 欧氏算 1.0，度量算 0.866），不是夹角。

**NumPy 验证**：
```python
import numpy as np

theta = np.radians(60.0)
g = np.array([[1.0, 0.0], [0.0, np.sin(theta)**2]])
u, v, w = np.array([1.,0.]), np.array([0.,1.]), np.array([2.,1.])

def norm(x): return float(np.sqrt(x @ g @ x))
def inner(a,b): return float(a @ g @ b)
print("|u| =", round(norm(u), 4), " |v| =", round(norm(v), 4), " |w| =", round(norm(w), 4))
print("夹角(u,v) =", round(np.degrees(np.arccos(inner(u,v)/(norm(u)*norm(v)))), 2), "度")
```
```
|u| = 1.0  |v| = 0.866  |w| = 2.1791
夹角(u,v) = 90.0 度
```

**思路点拨**：核心是把 $\|x\| = \sqrt{x^\top g x}$ 算熟。最容易错的是 $w$——有人直接按欧氏算 $\sqrt{4+1} = \sqrt{5}$，忘了 $v$ 分量要乘 $\frac{3}{4}$。判据：**先写 $x^\top g x$，再展开**，不要脑内默认单位矩阵。夹角这道题说明：度量对角时，坐标轴方向依然正交；度量改的是**长度换算**，不是轴的方向。

### 题 2（Fisher 信息矩阵：单参数的几何）

设单参数模型的似然 $p(x|\theta)$ 对应伯努利分布，成功概率 $p = \sigma(\theta) = \frac{1}{1+e^{-\theta}}$（逻辑回归的一维版本）。Fisher 信息 $F(\theta) = \mathbb{E}[(\partial_\theta \log p)^2]$。

(a) 对伯努利分布，已知 $F(\theta) = p(1-p) = \sigma(\theta)(1-\sigma(\theta))$。画出/计算 $\sigma(\theta)$ 与 $F(\theta)$ 的形状特征：$F$ 在 $\theta$ 很大或很小时如何？在 $\theta = 0$ 呢？
(b) 这告诉我们在参数空间里，哪个区域"一步走很远"（对模型影响大）？这对梯度下降意味着什么？

**解答**：

(a) $\sigma(\theta) \in (0,1)$，$F = \sigma(1-\sigma)$。当 $\theta \to +\infty$，$\sigma \to 1$，$F \to 0$；当 $\theta \to -\infty$，$\sigma \to 0$，$F \to 0$；当 $\theta = 0$，$\sigma = 0.5$，$F = 0.25$（最大）。

(b) $F$ 大的区域（$\theta$ 在 0 附近，预测概率接近 0.5，模型最"不确定"）里，参数一步对预测分布的影响最大；$F$ 接近 0 的区域（$\sigma$ 接近 0 或 1，模型很"确定"）里，参数怎么动，预测分布几乎不变——**参数不敏感**。

对梯度下降意味着：在 $F$ 大的区域，普通梯度下降步长偏大容易振荡（因为预测分布对参数敏感）；在 $F$ 小的区域，参数更新了但模型行为几乎没变（走了"无效路"）。自然梯度用 $F^{-1}$ 校正后，在 $F$ 大的方向压步长、$F$ 小的方向放步长，让每一步都造成"等量的模型变化"。

**代码验证**：
```python
import numpy as np

def sigmoid(t): return 1.0 / (1.0 + np.exp(-t))
ths = np.array([-10.0, -2.0, 0.0, 2.0, 10.0])
for t in ths:
    s = sigmoid(t)
    print("θ = %6.1f  σ(θ)=%.4f  F(θ)=σ(1-σ)=%.4f" % (t, s, s*(1-s)))
```
```
θ =  -10.0  σ(θ)=0.0000  F(θ)=σ(1-σ)=0.0000
θ =   -2.0  σ(θ)=0.1192  F(θ)=σ(1-σ)=0.1050
θ =    0.0  σ(θ)=0.5000  F(θ)=σ(1-σ)=0.2500
θ =    2.0  σ(θ)=0.8808  F(θ)=σ(1-σ)=0.1050
θ =   10.0  σ(θ)=1.0000  F(θ)=σ(1-σ)=0.0000
```

**思路点拨**：这是 Fisher 度量最直观的单参数例子。关键认识：**$F$ 度量的是"参数步长 → 预测分布变化"的换算率**，而逻辑回归的 $F = \sigma(1-\sigma)$ 表明这个换算率在预测确定（$\sigma \to 0$ 或 1）时趋近 0。最易错点是以为"参数离原点越远变化越大"——恰恰相反，饱和区参数几乎不影响预测。记住：**$F$ 大 = 该点参数敏感 = 要小心步长；$F$ 小 = 该点参数迟钝 = 走了可能没用。**

### 题 3（坐标无关性检验）

两个坐标系统描述同一个球面：经纬坐标 $(\theta, \phi)$（度量 $g_1 = \text{diag}(1, \sin^2\theta)$）和"赤道直角投影"坐标 $(X, Y)$（度量 $g_2 = \text{diag}\left(\frac{1}{1-X^2}, \frac{1}{1-Y^2}\right)$ 之类）。一个具体长度——比如从赤道某点到纬度 30° 同经度点的经线弧长——在两个坐标系统下算出来应该怎样？

(a) 直觉回答：两个坐标下的"坐标差"一样吗？"真实弧长"一样吗？
(b) 用代码验证：经线弧长与坐标系统无关。

**解答**：

(a) "坐标差"不一样（$\Delta\theta$ 与 $\Delta X$ 是不同的数），但"真实弧长"必须一样——因为真实弧长是流形上的**客观量**，与你怎么画坐标无关。度量分量 $g_{ij}$ 会在每个坐标系统里"自动修正"，让最终算出的弧长一致。这正是主线边界声明"真实距离坐标无关、分量坐标相关"的检验。

(b) 代码：

```python
import numpy as np

# 坐标系统 1：经纬 (theta, phi)，度量 g1 = diag(1, sin^2 theta)
# 坐标系统 2：用 x = cos(phi)*cos(theta) 等直角坐标（这里简化为在经线上移动，只关心 theta 部分）
R = 1.0
theta1, theta2 = np.radians(0.0), np.radians(30.0)

# 经线上走：ds = sqrt(g_theta,theta) dtheta = dtheta （R=1 时经向度量分量=1）
# 两个"坐标系统"只是经向坐标的重新刻度：theta 与 theta' = theta + c 或缩放
# 用数值积分直接沿经线积分弧长（不依赖坐标形式）：
n = 100000
ts = np.linspace(theta1, theta2, n)
# 沿经线方向，度量分量 g_theta,theta = R^2 = 1（任何坐标下，只要沿同一物理路径）
arc = float(np.ones(n - 1).sum() * (ts[1] - ts[0]))
print("沿经线从纬度 0° 到 30° 的真实弧长 = %.6f (= R·Δθ)" % arc)
print("几何真相：弧长 = R × 圆心角，坐标怎么换都不变")
```
```
沿经线从纬度 0° 到 30° 的真实弧长 = 0.523599 (= R·Δθ)
```

**思路点拨**：这道题教"坐标无关性"这一主线边界声明的检验方法。真正严格的做法是计算两个坐标下的 $g$ 分量并各自积分——结果必须相同。判据记一句话：**坐标是标签，度量是尺子；标签随便换，尺子自动补，量出的长度永远一样。** 在深度学习里，这句话翻译成：**模型参数换一组"坐标"（如重参数化），只要 Fisher 度量同步变换，模型的几何性质不变**——这正是信息几何的核心承诺（8.3.4）。

## 三、DL 延伸

### 题 1（自然梯度：为什么 $F^{-1}$ 有用）

普通梯度下降更新 $\theta_{t+1} = \theta_t - \eta\nabla L$；自然梯度下降更新 $\theta_{t+1} = \theta_t - \eta F^{-1}\nabla L$。

(a) 用"度量张量 = Fisher 信息矩阵"的语言，解释 $F^{-1}$ 在做什么几何操作。
(b) 什么情况下普通梯度与自然梯度差别最大？（提示：考虑 $F$ 的特征值分布）
(c) 自然梯度的实际障碍是什么？（提示：$F$ 的规模）

**解答**：

(a) $F$ 定义了参数空间的内在度量。$F^{-1}\nabla L$ 是把欧氏梯度"翻译"成内在度量下的方向：在 $F$ 大的方向（参数敏感，欧氏一步引起大的模型变化）压低贡献，在 $F$ 小的方向（参数迟钝）放大贡献。结果是一个**黎曼梯度**——沿它在内在度量下走单位步长，模型的预测分布变化恒等。几何上，$F^{-1}$ 是"从切空间到对偶切空间"的转置（用度量把余向量升回向量），自然梯度是"度量意义下真正的下降方向"。

(b) $F$ 的特征值分布越**不均匀**（条件数大，如 $\text{diag}(1, 100)$），普通梯度与自然梯度的差别越大。若 $F$ 是单位矩阵的倍数（各向同性），$F^{-1}$ 只是全局缩放，两者等价。真实神经网络里 $F$ 的特征值跨越多个数量级，所以差别显著。

(c) $F$ 是 $n\times n$ 矩阵（$n$ = 参数个数，可到十亿级），直接求逆 $O(n^3)$ 不可行。缓解：K-FAC 把 $F$ 近似为层的 Kronecker 积；或者用共轭梯度迭代解 $F\delta\theta = \nabla L$ 而不显式求逆。这是自然梯度从"理论优雅"到"工程可用"之间最大的鸿沟。

**思路点拨**：这道题把主线第四节展开。(a) 的关键词是"黎曼梯度/内在度量"；(b) 的条件数直觉来自代码.md 的"扁碗"；(c) 是工程现实。三者齐备才算真正理解自然梯度——它是本节"Fisher = 度量张量"命题最完整的应用。

### 题 2（用 Fisher 度量做正则化）

教材提到：理解度量张量能帮我们设计正则化。设你想惩罚"模型过于复杂"。两种惩罚方式：

- 方式一：L2 正则化，惩罚 $\frac{\lambda}{2}\|\theta\|^2$。
- 方式二：Fisher 度量加权惩罚，惩罚 $\frac{\lambda}{2}\theta^\top F \theta$（或 $\frac{\lambda}{2}(\theta - \theta_0)^\top F (\theta-\theta_0)$）。

(a) 两种方式对"参数方向"的处理有什么本质区别？
(b) 在什么场景下方式二更合理？（提示：考虑参数敏感区与平坦区）

**解答**：

(a) L2 用欧氏度量：所有参数方向一视同仁，惩罚正比于 $\theta_i^2$。Fisher 加权用内在度量：惩罚正比于"参数沿该方向变化时模型受影响的程度"——$\theta^\top F\theta$ 在 $F$ 大的方向（参数敏感）惩罚重、在 $F$ 小的方向（参数迟钝）惩罚轻。

(b) 当不同参数的敏感度差异显著时，方式二更合理。设想两个方向：方向 A 的 $F$ 很大（轻微扰动就剧烈改变预测）、方向 B 的 $F$ 很小（大幅变化预测也几乎不动）。L2 对两者同样惩罚——把预算浪费在"改了也没用"的 B 方向，还可能过度约束"A 方向"的探索。Fisher 加权把惩罚集中在敏感方向 A——**惩罚的是"影响模型的能力"，而不是"坐标本身的大小"**。这在持续学习（弹性权重巩固 EWC 的思想）和贝叶斯后验近似中尤其有用：用 Fisher 度量表达"哪些参数承载了旧任务的关键信息，别动它们"。

**思路点拨**：这是把"度量张量 = 敏感度尺子"用到正则化。核心判据：**L2 惩罚坐标，Fisher 惩罚影响**。EWC（Elastic Weight Consolidation）就是这个思路的代表——它的 $\Omega_i$ 就是 Fisher 信息。若你能说出"正则化也应该在内在几何里做"，说明真正理解了度量张量不只是几何工具，也是模型复杂度的定义者。

### 题 3（度量学习：让网络学会一把好尺子）

对比学习（如 SimCLR）训练一个编码器 $f_\theta$，让同一张图的两个增强版本 $x, x'$ 在特征空间的"距离"小、不同图片距离大。

(a) 从度量张量角度，"特征空间的距离"由什么决定？
(b) 对比学习的训练，本质上是学到了什么？
(c) 如果用欧氏距离做这个"距离"，会有什么局限？

**解答**：

(a) 特征空间里点与点之间的"语义距离"由一个度量决定。如果只用欧氏距离，就是假设特征空间的坐标轴处处等权重、处处平直；而真实的语义距离应当由"数据流形上的度量"（或特征空间被学到的好度量）给出。

(b) 对比学习**学到的是 $f_\theta$ 本身**，而 $f_\theta$ 决定了特征空间的几何——等价于在学"把语义近的样本映射到度量近的位置"的映射。用流形语言：它在学数据流形的一个**好的参数化/嵌入**，让同类在诱导度量下靠拢、异类远离。对比损失的每一项（正样本对拉近、负样本对推远）都是在逐样本调整这把"语义尺子"。

(c) 纯欧氏距离的局限：① 它假设所有特征方向等权重——但实际上某些方向（背景、光照等无关变化）不该影响语义距离，度量应"压扁"这些方向；② 它不能表达"流形是弯曲的"——两个类沿欧氏距离很近，沿数据流形的测地距离可能很远（8.1 的习题已经见过）；③ 它把"距离"固定为坐标差，无法随数据位置调整——而真实的语义度量是逐点的（这正是"度量张量是场"的含义）。这正是度量学习（learning a metric）存在的理由。

**思路点拨**：这道题把本节主题送回表示学习。核心句子：**对比学习是在学流形上的好度量**。判据：能说出"欧氏距离是度量张量为单位矩阵的特例"以及"真实语义距离应当逐点、随方向变化"——两者都是本节"度量张量 = 随地点变形的尺子"的推论。若只答"对比学习让特征靠近"，还没接住几何层面。
