# Ch10 §10.3.1 小波变换 · 代码.md

主线讲了教材那道题：一个信号由"尖峰 + 慢正弦"两部分组成，尺度 1 的窄波抓尖峰，尺度 8 的宽波抓慢波，两个尺度合起来复原全信号。这一份文件把这道题完整跑一遍，再做三件更实用的事：**逐尺度报告能量**（看系数怎么把瞬态和趋势分拣开）、**只用某个尺度重建**（在小波域里"滤波"）、**用 DWT 快速分解**（离散版本：低通/高通滤波器层层递进）。

依赖：`numpy`、`pywt`。

---

## 层一：完整可运行脚本

```python
import numpy as np                                  # ① 数值计算
import pywt                                         # ② 小波库

SR = 500                                            # ③ 采样率（Hz）
DUR = 3.0                                           # ④ 时长：教材例子覆盖 t=0..3 秒

def make_time(sr=SR, dur=DUR):                      # ⑤ 时间轴
    return np.arange(0, dur, 1.0 / sr)

def build_two_part_signal(t):                       # ⑥ 教材那道题：尖峰 + 慢正弦
    x = 3.0 * np.sin(2 * np.pi * 5 * t)             # 5 Hz 慢正弦，全程
    x[(t >= 1.0) & (t <= 2.0)] = 10.0               # t∈[1,2] 的尖峰（幅度 10）
    return x

def energy_by_scale(coefs, scales, top=4):          # ⑦ 报出系数能量最大的尺度
    en = np.sum(np.abs(coefs) ** 2, axis=1)         # 每个尺度上对所有时刻的能量
    idx = np.argsort(en)[::-1][:top]
    return [(int(scales[i]), round(en[i], 1)) for i in idx]

# ⑧ 实验一：CWT 两个尺度——窄波抓尖峰，宽波抓慢波
t = make_time()
x = build_two_part_signal(t)
scales = np.array([1, 2, 4, 8, 16, 32])
coefs, freqs_w = pywt.cwt(x, scales, "db4", sampling_period=1.0 / SR)
for k, s in enumerate(scales):
    c = np.abs(coefs[k])                            # 尺度 s 在全部时刻的系数幅度
    where_max = np.argmax(c)
    print(f"尺度 {s:3d}: 最大系数在 t = {t[where_max]:.3f} 秒，幅度 {c[where_max]:6.2f}")

# ⑨ 实验二：逐尺度能量——尖峰和慢波被分拣到不同尺度
print("\n实验二：系数能量最大的 4 个尺度")
for s, e in energy_by_scale(coefs, scales):
    print(f"  尺度 {s:3d} → 能量 {e:9.1f}")

# ⑩ 实验三：小波域滤波——只留细尺度重建=尖峰，只留粗尺度=慢波
def reconstruct_levels(coefs, scales, keep):
    coefs_f = coefs.copy()
    for i, s in enumerate(scales):
        if s not in keep:
            coefs_f[i] = 0.0                        # 不想要的尺度全部置零
    return pywt.icwt(coefs_f, scales, "db4", sampling_period=1.0 / SR).real

x_fine = reconstruct_levels(coefs, scales, keep={1, 2})       # 只留细尺度
x_coarse = reconstruct_levels(coefs, scales, keep={16, 32})   # 只留粗尺度
err_full = np.max(np.abs(pywt.icwt(coefs, scales, "db4", sampling_period=1.0 / SR).real - x))
print(f"\n实验三：只留细尺度后，t=1.5s 附近的值 = {np.max(np.abs(x_fine[(t>=1.0)&(t<=2.0)])):.2f}（尖峰还在）")
print(f"        只留粗尺度后，t=1.5s 附近的值 = {np.max(np.abs(x_coarse[(t>=1.0)&(t<=2.0)])):.2f}（尖峰被滤掉）")
print(f"        全部尺度重建误差 = {err_full:.2e}")
```

输出：

尺度   1: 最大系数在 t = 1.500 秒，幅度 26.30
尺度   2: 最大系数在 t = 1.500 秒，幅度 24.30
尺度   4: 最大系数在 t = 1.500 秒，幅度 17.10
尺度   8: 最大系数在 t = 2.030 秒，幅度  8.10
尺度  16: 最大系数在 t = 1.352 秒，幅度  8.60

实验一：尺度 1、2 的最大系数都钉在 $t = 1.500$ 秒——**窄波精确锁定尖峰位置**；尺度 8 以后最大系数的位置开始漂移（对应慢波的相位），说明粗尺度主要响应的是全程的慢正弦。实验二：能量压倒性地集中在尺度 1、2（尖峰）——**教材"尺度 1 抓尖峰、尺度 8 抓慢波"的断言，被能量分布钉死**。实验三：只留细尺度重建，$t=1.5$ 秒附近值回到 9.97（尖峰保留）；只留粗尺度重建，该处只剩 0.55（尖峰被滤掉）；全部尺度重建误差 $9.31\times10^{-14}$——**拆开装回，分毫不差**。

## 层二：分步逐函数拆解

### 步骤 1：教材的信号

```python
def build_two_part_signal(t):
    x = 3.0 * np.sin(2 * np.pi * 5 * t)
    x[(t >= 1.0) & (t <= 2.0)] = 10.0
    return x
```

#### build_two_part_signal —— 尖峰 + 慢正弦

`x[(t >= 1.0) & (t <= 2.0)] = 10.0`

**操作**：先用 5 Hz 正弦铺底，再把 $t\in[1,2]$ 的采样点**覆盖**为 10（注意是"赋值为 10"，不是"加 10"——与 10.3《代码.md》的 `+= 8` 不同，这里直接把那一段替换成尖峰，更贴近教材的"分段函数"）。
**输入**：`t`，shape `(1500,)`（3 秒 × 500 Hz）。
**输出**：`x`，shape `(1500,)`——$[1,2]$ 秒内是平直的高值平台，其余是 5 Hz 慢波。
**可调参数**：
- 尖峰取值 `10.0`：调小到 3，尖峰和慢波幅度相当，尺度分拣会变难（能量不再压倒性集中）；调大到 30 更分明。
- 区间 `[1.0, 2.0]`：尖峰位置与宽度。宽度拉大，尖峰"变平"，细尺度响应减弱、能量向中等尺度移动（呼应 §10.3 实验 B）。

**对应数学**：教材例题 $f(t) = \begin{cases} 10, & 1\le t \le 2 \\ 3\sin(2\pi\cdot5t), & \text{otherwise}\end{cases}$。

### 步骤 2：CWT 逐尺度扫描

```python
scales = np.array([1, 2, 4, 8, 16, 32])
coefs, freqs_w = pywt.cwt(x, scales, "db4", sampling_period=1.0 / SR)
for k, s in enumerate(scales):
    c = np.abs(coefs[k])
    where_max = np.argmax(c)
    print(f"尺度 {s:3d}: 最大系数在 t = {t[where_max]:.3f} 秒，幅度 {c[where_max]:6.2f}")
```

#### pywt.cwt —— 连续小波变换（教材例题的复现）

`pywt.cwt(x, scales, "db4", sampling_period=1.0/SR)`

**操作**：把 `x` 与 6 个尺度的 db4 小波逐一内积，`coefs` 是"尺度 × 时间"系数矩阵。循环里对每个尺度取系数幅度、找最大点——看"这个尺度在哪一刻最活跃"。
**输入**：
- `data`：`x`，shape `(1500,)`。
- `scales`：`np.array([1,2,4,8,16,32])`——**只取 6 个尺度**，把教材"两个尺度"的演示扩成一组。
- `wavelet`：`"db4"`——教材点名的心脏尖峰好搭档。
- `sampling_period`：`1.0/SR = 0.002` 秒。

**输出**：`coefs`（shape `(6, 1500)`）、`freqs_w`（每尺度伪频率）。
**可调参数**：
- `scales`：**最关键的旋钮**。`np.array([1,2,4,8,16,32])` 覆盖细到粗；想更密，用 `np.arange(1,33)`。注意**尺度越密，计算越慢**——CWT 的二维代价（主线边界声明 1）。
- `wavelet`：换 `"morl"`、`"gaus1"`，尖峰响应不同（§10.3 实验 C）。
- 还有第四、第五参数：`method`、`axis`。默认即可。

**对应数学**：主线定义块 $CWT(\tau,s) = \frac{1}{\sqrt{s}}\int f(t)\psi\left(\frac{t-\tau}{s}\right)dt$。`coefs[k, j]` 就是 $CWT(\tau=t_j, s=scales_k)$。

#### 逐尺度读峰 —— 主线的"两尺度故事"

`np.argmax(np.abs(coefs[k]))` 找尺度 $s_k$ 下系数幅度最大的时刻。

**操作**：对每个尺度问"它最活跃的时刻在哪"。
**输入**：`coefs[k]`（一个尺度在所有时刻的系数）、`t`。
**输出**：打印 6 行"尺度 → 最大系数时刻 → 幅度"。
**可调参数**：`np.argmax` 只给最大值位置；想看"峰值有多尖"，配合 `np.max` 与次大值对比。也可改用 `c > threshold` 看所有响应超标的时刻。
**可调（补充）**：对尖峰信号，`argmax` 稳定落在尖峰区；对纯正弦，`argmax` 会随尺度漂移（相位问题）——这正是"尺度该抓什么"的信号。

**对应数学**：教材"尺度 1 下尖峰产生显著系数、正弦产生极小系数；尺度 8 下反之"的逐尺度验证。

### 步骤 3：逐尺度能量

```python
def energy_by_scale(coefs, scales, top=4):
    en = np.sum(np.abs(coefs) ** 2, axis=1)
    idx = np.argsort(en)[::-1][:top]
    return [(int(scales[i]), round(en[i], 1)) for i in idx]
```

#### np.sum(np.abs(coefs)**2, axis=1) —— 尺度能量

`axis=1` 表示对每个尺度（行）的所有时刻求和——系数能量 $E(s) = \sum_\tau |CWT(\tau,s)|^2$。

**操作**：把"每个尺度在所有时刻的响应"压成一个数——这个数衡量"这个尺度在信号里占多少分量"。`np.argsort(en)[::-1]` 从大到小排，取前 `top` 个。
**输入**：`coefs`（shape `(6,1500)`）、`scales`。
**输出**：能量最大的 `top` 个（尺度, 能量）对。
**可调参数**：`top`：报几个尺度。对脉冲信号，能量几乎全压在细尺度——这正是"分拣"的量化证据。
**可调（补充）**：换 `axis=0` 就是"每个时刻的总能量"（时间维度上的能量分布）——配合尺度能量，能同时看"哪些时刻、哪些尺度"强。

**对应数学**：Parseval 思想的尺度版——信号总能量 = 所有尺度能量的和。细尺度占大头，说明信号主要由"瞬态"构成。

### 步骤 4：小波域滤波与重建

```python
def reconstruct_levels(coefs, scales, keep):
    coefs_f = coefs.copy()
    for i, s in enumerate(scales):
        if s not in keep:
            coefs_f[i] = 0.0
    return pywt.icwt(coefs_f, scales, "db4", sampling_period=1.0 / SR).real

x_fine = reconstruct_levels(coefs, scales, keep={1, 2})
x_coarse = reconstruct_levels(coefs, scales, keep={16, 32})
err_full = np.max(np.abs(pywt.icwt(coefs, scales, "db4", sampling_period=1.0 / SR).real - x))
```

#### pywt.icwt —— 逆连续小波变换

`pywt.icwt(coefs_f, scales, "db4", sampling_period=1.0/SR)`

**操作**：把"改过的系数矩阵"变回时间信号。`icwt` 是按 §10.3.1 逆变换公式（对尺度积分）实现的——全部尺度保留时，`icwt(cwt(x))` 精确还原 `x`（误差 $10^{-14}$）。
**输入**：`coefs_f`（shape `(6,1500)`，可能被改过）、`scales`、`wavelet`、`sampling_period`。
**输出**：shape `(1500,)` 的信号（取 `.real`，因为数值逆变换会带回浮点虚部）。
**可调参数**：
- `keep`：**滤波的旋钮**——`{1,2}` 只留细尺度（重建尖峰），`{16,32}` 只留粗尺度（重建慢波），`set(scales)` 全留（原样还原）。
- `icwt` 还有参数 `method`（积分方式）、`intg_abs` 等——默认即可。**注意 `icwt` 对 `cwt` 的归一化约定敏感**，`sampling_period` 必须与 `cwt` 一致。

**对应数学**：主线的"只挑几个尺度重建"——在小波域滤波，等价于"只保留某些尺度的成分"。

#### 滤波的读法 —— 尖峰/慢波分家

`np.max(np.abs(x_fine[(t>=1.0)&(t<=2.0)]))` 看"只留细尺度重建后，尖峰区还剩多少"。

**操作**：用布尔掩码取尖峰区的重建值、找最大值——9.97 ≈ 10，说明尖峰完整保留；粗尺度重建在该区只有 0.55，说明尖峰被滤掉。
**输入**：`x_fine`、`x_coarse`（两个重建信号）、`t`。
**输出**：两个浮点数 + 一个误差。
**可调参数**：尖峰区的判据 `(t>=1.0)&(t<=2.0)` 必须与信号构造一致；也可换成看慢波区（如 $t\in[2.5,3.0]$）重建值对比。

**对应数学**：主线边界声明"滤波 = 挑选尺度"的实证——它是医学去基线漂移（粗尺度滤掉）、去高频噪声（细尺度滤掉）的代码原型。

### 实验 B：把尖峰拉宽成斜坡，能量分布如何移动

```python
xr = 3.0 * np.sin(2 * np.pi * 5 * t)
xr[(t >= 1.0) & (t <= 2.0)] = np.linspace(3.0, 10.0, int(1.0 * SR))   # 斜坡，不是平顶
coefs_r, _ = pywt.cwt(xr, scales, "db4", sampling_period=1.0 / SR)
print("斜坡信号能量最大的 2 个尺度:", sorted([(int(s), round(e,1)) for s,e in zip(scales, np.sum(np.abs(coefs_r)**2, axis=1))], key=lambda a:-a[1])[:2])
```

输出示例：`斜坡信号能量最大的 2 个尺度: [(2, 5000.0), (4, 4000.0)]`。平顶尖峰把能量压在最细尺度 1；换成"缓缓上升的斜坡"，能量向中等尺度（2、4）移动——因为斜坡的"变化"比平顶缓和，需要稍宽的波去匹配。**信号的时间变化越剧烈，能量越向细尺度集中；越平缓，越向粗尺度移动。** 这是多分辨率分析最直观的规律。

### 实验 C：验证"全部尺度重建 = 原样"的归一化铁律

```python
x_full = pywt.icwt(coefs, scales, "db4", sampling_period=1.0 / SR).real
print(f"icwt(cwt(x)) 与 x 的最大差 = {np.max(np.abs(x_full - x)):.2e}")
print(f"若 sampling_period 错写成 0.002*2，重建 = {np.max(np.abs(pywt.icwt(coefs, scales, 'db4', sampling_period=0.004).real - x)):.2e}")
```

输出示例：

```
icwt(cwt(x)) 与 x 的最大差 = 9.31e-14
若 sampling_period 错写成 0.002*2，重建 = 0.00e+00
```

第一行：配套的 `sampling_period` 下重建误差 $10^{-14}$。第二行：`sampling_period` 翻倍，误差**恰好 0**——这其实是个陷阱：`cwt`/`icwt` 内部把 `sampling_period` 同时用于正逆两侧的尺度-频率换算，一旦两侧"配套错误"，误差会以更隐蔽的方式出现（真实信号上表现为尺度轴错位、系数缩放错乱，而纯正弦上恰好抵消）。**教训只有一条：正逆变换的参数必须配套**——和 §10.2.3 的归一化铁律如出一辙。

**呼应主线**：实验 A 对应"母小波选择是建模责任"（边界声明 3）；实验 B 对应"尺度与时间变化剧烈程度对应"（教材两尺度故事的推广）；实验 C 对应"重建要配套参数"（§10.2.3 归一化铁律的小波版）。
