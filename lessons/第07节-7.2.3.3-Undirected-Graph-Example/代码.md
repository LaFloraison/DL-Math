# Ch07 §7.2.3.3 无向图例：Alice–Bob–Carol 社交网络 · 代码.md

主线用三人朋友网络（$V=\{A,B,C\}$，$E=\{\{A,B\},\{A,C\},\{B,C\}\}$）演示了无向图的读法，并介绍了一个新量——聚类系数。本文件把这个三人网络完整实现成 numpy：邻接矩阵、度、连通分量，再加一个手写的**聚类系数**函数——"你的朋友之间有多少比例也是朋友"。三角形（聚类系数 = 1）正是它的最小样例。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

people = ["Alice", "Bob", "Carol"]                     # ② 三人
friends = [("Alice", "Bob"), ("Alice", "Carol"), ("Bob", "Carol")]

def adjacency(nodes, edges):                           # ③ 无向邻接矩阵
    idx = {n: i for i, n in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=int)
    for u, v in edges:
        i, j = idx[u], idx[v]
        A[i, j] = 1
        A[j, i] = 1
    return A

def clustering(A):                                     # ④ 聚类系数：朋友间也是朋友的比例
    n = A.shape[0]
    cc = np.zeros(n)
    for v in range(n):
        friends_v = np.where(A[v] == 1)[0]             # v 的所有朋友
        deg = len(friends_v)
        if deg < 2:
            cc[v] = 0.0                                # 朋友不够 2 个，三角形无从谈起
            continue
        sub = A[np.ix_(friends_v, friends_v)]          # 朋友之间的"子邻接矩阵"
        triangles = sub.sum() // 2                     # 朋友内部边数（无向，数两遍）
        cc[v] = triangles / (deg * (deg - 1) / 2)      # 实际边数 / 最大可能边数
    return cc

A = adjacency(people, friends)                         # ⑤ 主流程
print("邻接矩阵：\n", A)
print("每人朋友数：", dict(zip(people, A.sum(axis=1))))
print("聚类系数：", dict(zip(people, clustering(A))))
```

输出：

```
邻接矩阵：
 [[0 1 1]
  [1 0 1]
  [1 1 0]]
每人朋友数： {'Alice': 2, 'Bob': 2, 'Carol': 2}
聚类系数： {'Alice': 1.0, 'Bob': 1.0, 'Carol': 1.0}
```

三人度全为 2、聚类系数全为 1——每个节点的两个朋友互相也是朋友，三角形闭合。这正是主线说的"三人成圈"。若把 Bob–Carol 的友谊删掉，Alice 的两个朋友 Bob 和 Carol 就不互相认识，Alice 的聚类系数会掉到 0——你可以把这个删边的实验亲手跑一遍，看聚类系数如何反映"圈子闭合程度"。

## 层二：分步逐函数拆解

### 步骤 1：定义无向邻接矩阵

```python
def adjacency(nodes, edges):
    idx = {n: i for i, n in enumerate(nodes)}
    A = np.zeros((len(nodes), len(nodes)), dtype=int)
    for u, v in edges:
        i, j = idx[u], idx[v]
        A[i, j] = 1
        A[j, i] = 1
    return A
```

#### adjacency —— 对称无向矩阵

`A[i, j] = 1` 与 `A[j, i] = 1`

**操作**：与 §7.2.3 完全相同——每条无向边 $\{u,v\}$ 在矩阵里对称地写两处。输出是 $3\times3$ 对称矩阵，主对角线 0（无自环）。

**输入**：`nodes`（3 个名字）、`edges`（3 对朋友）。

**输出**：`(3,3)` int 对称矩阵。`A[0,1]=A[1,0]=1` 表示 Alice–Bob 是朋友。

**可调参数**：加新朋友直接扩 `edges`；想建"明星结构"（一人认识所有人，其他人互不认识）就把三角形换成星形边集，聚类系数会跟着大改。

**对应数学**：§7.2.3 定义 $E\subseteq\{\{u,v\}\}$——花括号无序，代码里就是对称两处。

---

### 步骤 2：定义聚类系数函数

```python
def clustering(A):
    n = A.shape[0]
    cc = np.zeros(n)
    for v in range(n):
        friends_v = np.where(A[v] == 1)[0]
        deg = len(friends_v)
        if deg < 2:
            cc[v] = 0.0
            continue
        sub = A[np.ix_(friends_v, friends_v)]
        triangles = sub.sum() // 2
        cc[v] = triangles / (deg * (deg - 1) / 2)
    return cc
```

#### clustering —— 朋友之间也是朋友的比例

`sub.sum() // 2` 与 `triangles / (deg * (deg - 1) / 2)`

**操作**：对每个节点 $v$ 分四步：
1. `np.where(A[v] == 1)[0]`——找出 $v$ 的所有朋友（邻居）；
2. 度 $d$ 若小于 2，无法构成三角形，聚类系数记 0；
3. `A[np.ix_(friends_v, friends_v)]`——取"朋友×朋友"的子矩阵，`sub.sum()` 数朋友之间所有边，无向边被数了两次，除以 2 得真实边数 $T$；
4. $v$ 的 $d$ 个朋友两两之间最多有 $\binom{d}{2} = d(d-1)/2$ 条边，实际有 $T$ 条，比值就是聚类系数。

**输入**：`A`：`(n, n)` 无向邻接矩阵。

**输出**：`np.ndarray`，形状 `(n,)`——每个节点的聚类系数，取值 $[0,1]$。

**可调参数**：
- `np.ix_(friends_v, friends_v)` 是 numpy 的"取子矩阵"利器——传入两个下标数组，得到"行取这些、列取这些"的子块。
- `deg < 2` 时置 0 是约定（单例或双人没有三角形）；也有人约定置 0 而非 NaN，是为了求和方便。
- 全图的**平均聚类系数**就是 `clustering(A).mean()`——它是"整张图成圈程度"的标量，社区检测用它做信号。

**对应数学**：主线第二节的聚类系数。Alice 的 $d=2$，朋友 Bob、Carol 之间有 1 条边，$\binom{2}{2}=1$，系数 $= 1/1 = 1$。

---

### 步骤 3：主流程

```python
A = adjacency(people, friends)
print("邻接矩阵：\n", A)
print("每人朋友数：", dict(zip(people, A.sum(axis=1))))
print("聚类系数：", dict(zip(people, clustering(A))))
```

#### 主流程 —— 度与聚类的读数

**操作**：`A.sum(axis=1)` 数度；`clustering(A)` 算系数。

**输入**：矩阵。

**输出**：两个字典。度全 2，聚类全 1.0。

**可调参数**：`dict(zip(people, ...))` 把下标映射回人名——"表示层"的小技巧，让输出可读。

**对应数学**：§7.2.3 的度 + 主线的聚类系数。这张图也满足握手引理：$\sum d = 6 = 2\times3$。

## 改个数字试试

### 实验 A：删掉一条边，看聚类系数跌落

```python
A2 = adjacency(people, friends[:2])            # 只剩 Alice-Bob, Alice-Carol
print("删掉 Bob-Carol 后聚类系数：", dict(zip(people, clustering(A2))))
```

输出：

```
删掉 Bob-Carol 后聚类系数： {'Alice': 0.0, 'Bob': 0.0, 'Carol': 0.0}
```

一条边的消失，让三个节点的聚类系数同时归零：Alice 的两个朋友 Bob、Carol 不再互相认识，"你朋友的朋友是你的朋友"彻底失效；Bob 只有一个朋友了，同样无从成圈。**聚类系数对"圈是否闭合"极端敏感**——这正是它在社交网络里能检测"紧密社区"的原因：圈闭合的地方，系数高；缝隙连接的地方，系数低。

### 实验 B：加一个"圈外人"，看桥节点

加第四人 Dave，只和 Alice 是朋友：`friends2 = friends + [("Alice", "Dave")]`。重跑看度数：Alice 变 3，Dave 是 1。再看聚类：Dave 只有 1 个朋友，聚类 0；Alice 的两个朋友（Bob、Carol）互相认识，Alice 聚类仍是 1——**Dave 进不了圈，Alice 则同时属于"圈内人"和"圈外人"的桥**。这就是 §7.4.5 影响力节点/桥节点在无向图里的雏形：真正的桥，是那些"跨圈"的人。

**呼应主线**：Alice–Bob–Carol 的三角形是聚类系数=1 的最小单元，也是"小世界网络"（§7.2.3.3 历史）的最小砖块。理解 `clustering` 里"朋友间边数 / 最大可能边数"这一步，就理解了"圈子闭合"的数学定义——以及为什么 GNN 的社区检测、好友推荐都从数三角形开始。
