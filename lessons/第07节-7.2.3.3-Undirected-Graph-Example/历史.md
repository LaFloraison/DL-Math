# 历史：从三个朋友，到"六度"——一张小图引出的世界之小

## 1967，内布拉斯加州，一场邮递实验的起点

斯坦利·米尔格拉姆（Stanley Milgram）把一叠信交给一个叫杰弗里的股票经纪人，让他寄给一个住在波士顿的、他素未谋面的目标人物。

规矩很怪：杰弗里不能直接寄给目标（他不知道地址，也不许去查），他只能把信寄给他**认识的**、他**认为**更可能认识目标的人。收到信的人照做，再转给下一个"更可能"的人。如此接力。米尔格拉姆想知道的是：这封信要经过多少只手，才能到达那个波士顿人？

答案震惊了整个社会科学界。平均只经过 **6 只手**。从内布拉斯加的经纪人到波士顿的陌生人——隔着整个美国、几十年的生活轨迹、无数从不交集的圈子——却只用六个人，就把信送到了。米尔格拉姆称之为"小世界现象"，大众给它起了个朗朗上口的名字：**六度分隔**。

## 一张没有箭头的图

米尔格拉姆的实验，本质上是在一张巨大的**无向图**上走最短路径。

这张图的节点是美国的每个人，边是"互相认识"。注意：**认识是双向的**——杰弗里认识同事 A，A 也认识杰弗里。没有箭头，没有方向，"我认识你"与"你认识我"同时成立。这正是无向图的定义在真实世界的最大规模现身。

而米尔格拉姆的实验，就是在这张图上演算"从一个节点到另一个节点的路径有多短"。他不数节点有多少，他量的是**图上的距离**——一条消息要沿边跳多少跳，才能把两座孤岛连起来。

## 为什么世界这么小

米尔格拉姆之后的几十年，网络科学家找到了答案的线索。无向图里藏着一个反直觉的结构：**既有紧密的圈（三角形），又有连接圈与圈的桥。** 你的朋友大多是你的"圈内人"——他们彼此也认识，形成密实的三角形；但只要你认识几个"圈外人"（换个城市的同事、另一个行业的球友），你就成了连接两个世界的桥。

巧合的是，几乎在同一时代，数学家们也在捣鼓这个问题：小世界到底是怎么出现的？直到 1998 年，沃茨（Watts）和斯特罗加茨（Strogatz）发表了一篇论文，用一页纸的模型回答了这个世纪谜题：**在一个以三角形（聚类）为主的图上，只要随机加上几条"长连接"，整个图的世界就骤然变小**——从"绕远路"变成"几乎任意两点都近在咫尺"。他们的模型，恰恰是从"你和你的朋友都是朋友"（三角形，§7.2.3.3 的 Alice–Bob–Carol 结构）出发，往里掺几根"万里姻缘一线牵"的长边。

## 从三个朋友到全人类

回头再看 Alice、Bob、Carol——那个三人互相都认识的最小三角形。米尔格拉姆的美国有上亿节点，沃茨-斯特罗加茨模型有几千节点，而它们共享同一个原子：**三个人互相认识**。三角形是社交图的最小砖块；亿万人际网络，就是由无数这样的砖块砌成，再被少数"长连接"缝合起来。

米尔格拉姆没有画图，他只是在寄信。但他实际上做了一件图论的事：在这张无向图上，从起点到终点，走出了六跳。他证明的不是"世界小"，而是：**即使在一张庞大的无向图上，只要连接足够密、足够巧，任意两个节点的距离都比想象短得多。** 这是无向图给人类的最浪漫的定理。

## 留一扇门

三个朋友组成一个三角形，亿万人组成一张小世界网络——它们的数学骨骼是同一种无向结构：边不辨方向，关系双方共享，连通与聚类决定世界的形状。

但"三个朋友"要怎么变成机器能算的东西？上一节我们读了有向的例子，这一节我们读了无向的例子——两者的邻接矩阵，一个不对称、一个对称。这正是主线要做的：把 Alice–Bob–Carol 这张三人图写进矩阵，让"度、分量、聚类"从直觉，变成几行 numpy。
