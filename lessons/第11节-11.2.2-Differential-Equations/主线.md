## 第一步：Toy Model —— 一辆车，和它"此刻在怎么开"

你坐在副驾驶，导航在报路况。你给朋友打电话描述这辆车：**"它在高速上，时速 110 公里。"**

这句话有两个部分。第一部分是"在哪"——高速上。第二部分是"开得多快"——时速 110。你的朋友立刻知道了车的状态，也知道了它的**变化率**：位置每秒在变，变的速度是 110 公里/小时。

现在换一个场景。你在教一个刚学会开车的人描述路况。他说："车在高速上，位置是 45 公里处。" 你皱眉——**"位置"根本不够。** 光知道在 45 公里处，你不知道它下一秒在哪：它可能静止，可能以 110 飙车。要描述一辆**正在行驶**的车，你必然要说它的速度——它在**如何变化**。

"如何变化"，就是"变化率"，数学的名字叫**导数 (derivative)**。而一门语言如果能把"一个量是多少"和"它变化得多快"放进同一句话，它就拥有了描述世界的文法。这门语言，叫**微分方程 (differential equation)**。

你盯着眼前的车流，心里浮起一个问题：**"描述位置"和"描述变化率"，怎样写成同一个数学式子？**

## 第二步：正式数学讲解

### 一、撞墙：只知道"是多少"，永远算不出"将是多少"

先试试用"老办法"描述一辆车的运动。你说：车在 $t$ 时刻的位置是 $y(t)$。然后你问：$t=5$ 秒时它在哪？

回答不了。因为光有"位置随时间变化"这句话，信息是**不够的**——除非你再告诉我"位置是怎么随时间变化的"这一条规则。也就是说，你要的不是"位置序列"，而是"**位置的变化率，如何由位置和时间决定**"这条约定。

这条约定长这样：

$$\frac{dy}{dt} = f(t, y)$$

左边 $\frac{dy}{dt}$ 是"$y$ 对时间的变化率"——导数。右边 $f(t,y)$ 说：这个变化率，由此刻的时间 $t$ 和此刻的状态 $y$ 共同决定。整句话的意思是：**"你想要一个函数 $y(t)$，它的变化率处处遵守这条规则。"** 这就是微分方程——不是问"$y$ 等于几"，而是问"**哪个函数满足这条关于它自己的变化率的约定**"。

你恍然大悟：导数，是"变化得多快"的尺子；微分方程，是把"量的值"和"量的变化率"捆进同一句话的语法。所以教材说，微分方程是"变化的语言 (the language of change)"——它同时描述**状态**（$y$ 是多少）和**变化**（$y$ 在怎么变）。

> **微分方程 (differential equation)**
>
> $$\frac{dy}{dt} = f(t, y)$$
>
> - $y$：因变量（dependent variable）——系统的状态
> - $t$：自变量（independent variable）——通常是时间
> - $\frac{dy}{dt}$：导数——$y$ 关于 $t$ 的变化率
> - $f(t, y)$：描述"变化率依赖什么"的规则
> - 解：一个**函数** $y(t)$，满足这条关于变化率的约定
> - 初始条件 $y(t_0) = y_0$：从解族里挑出具体那一条
>
> 特例回顾：$\frac{dx}{dt} = 0.5x$ 的解是 $x(t) = x_0 e^{0.5t}$——"变化率 = 状态的二分之一"。
>
> 按自变量个数分两族：
> - **常微分方程 (ODE)**：一个自变量（通常是 $t$），如 $\frac{dy}{dt} = f(t,y)$
> - **偏微分方程 (PDE)**：多个自变量（如 $t$ 与 $x$），导数变成偏导数，如 $\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$

### 二、为什么是"方程"，不是"公式"？

这个词值得停下来闻一闻。中学的方程——$2x + 3 = 7$——问的是"**哪个数** $x$ 让等式成立"。微分方程把"数"换成了"**函数**"：$2y' + 3y = 7$ 问的是"**哪个函数** $y(t)$ 让等式成立"。

$2x + 3 = 7$ 的解是一个点（$x = 2$）；$\frac{dy}{dt} = 0.5y$ 的解是一族函数（$y = Ce^{0.5t}$）。从"解一个数"到"解一个函数"，是数学里一次从低维到高维的跃迁——而这就是"变化"必须付出的代价：因为变化本身是无穷多个瞬间的连续，描述它的方程，解的也必须是整条曲线，不是一个点。

解微分方程的"解"字，也因此有两个层次：**通解 (general solution)**——含任意常数的整个解族（如 $Ce^{0.5t}$）；**特解 (particular solution)**——用初始条件钉死常数后的那一条（如 $100e^{0.5t}$）。两者合起来，才是"完整的答案"。

### 三、这一节只立招牌，两扇门在隔壁

§11.2.2 是一扇大厅。它把"变化的语言"的招牌挂起来，然后告诉你大厅里有两扇门：

- **常微分方程 (ODE)**：自变量只有一个。你描述的东西，只随着**一个**量变化——通常是时间。秋千摆一个位置 $y(t)$，只依赖时间。§11.2.2.1。
- **偏微分方程 (PDE)**：自变量有多个。你描述的东西，同时随**几个**量变化——时间和空间。金属棒上某点的温度 $u(t,x)$，既依赖时间又依赖位置。§11.2.2.2。

判断口诀：**数一数自变量。一个 → ODE；两个以上 → PDE；出现的导数是普通导数还是偏导数，跟着走就行。**

### 四、边界声明：变化的语言，有三处口吃

1. **不是所有变化都光滑。** 微分方程用导数描述变化，而导数要求"变化是光滑的"——开关的翻转、相变的跳跃、冲击波的断裂，这些瞬间导数不存在。语言的语法只覆盖光滑的世界。
2. **能写出来 ≠ 能解出来。** 绝大多数微分方程没有解析解——摆锤的精确方程、三体、混沌系统，全都解不出闭式公式。"变化的语言"能**描述**它们，但不保证能**算尽**它们。§11.2.1.2 的欧拉法和数值积分，是这门语言请来的翻译。
3. **"变化率"依赖"状态"，这本身就是一种假设。** 微分方程假设"此刻的变化率只由此刻的状态（和此刻的时间）决定"。真实世界里，有的系统"记得"更早的历史（时滞系统）、有的受随机干扰（随机微分方程）——它们超出本章这门基本语法的范围。

## 第三步：DL 桥接

"变化的语言"在深度学习里有三句最响亮的方言。

**ODE → 连续时间 RNN 与 Neural ODE。** RNN 隐藏状态的连续化 $\frac{dh}{d\tau} = -h + \sigma(W_{hh}h + W_{xh}x(\tau))$ 是一个 ODE——普通 RNN 是它的欧拉离散化，Neural ODE 是它的精确积分。§11.2.2.1 你会亲手解这样的方程。

**ODE → 梯度流。** 训练参数 $w$ 的连续轨迹 $\frac{dw}{d\tau} = -\nabla L(w)$ 也是 ODE。你写的 `w -= lr*grad`，就是这句方言的一个欧拉词。

**PDE → 扩散模型与热方程。** 扩散模型把图像分布逐步加噪"稀释"，与热方程 $\frac{\partial u}{\partial t} = \alpha\frac{\partial^2 u}{\partial x^2}$（热量向均匀扩散）是同一族方程。§11.2.2.2 会亲手数值解热方程——那是理解扩散模型的家门钥匙。
