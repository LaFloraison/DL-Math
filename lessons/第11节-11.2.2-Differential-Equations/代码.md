# 代码：给"变化的语言"做一次语法检查

主线说：微分方程是"变化的语言"，它把"量的值"和"量的变化率"捆进同一句话：$\frac{dy}{dt} = f(t, y)$。这一节用一个具体句子——**牛顿冷却定律** $\frac{dT}{dt} = -k(T - T_{\text{env}})$——给这门语言做一次**语法检查**：

1. 先写出解析解 $T(t) = T_{\text{env}} + (T_0 - T_{\text{env}})e^{-kt}$（热茶指数逼近室温）。
2. 再用**数值微分**（有限差分）测量这个解的"此刻变化率"。
3. 把这个测出的变化率和方程的右端 $-k(T - T_{\text{env}})$ 对比——如果两者处处一致，就证明了：**这个函数确实在遵守那条关于变化率的约定**。这就是"解微分方程"在代码里的完整含义。

---

## 层一：完整脚本

```python
import numpy as np                                        # np.exp 与算术运算来自这里

TENV, K = 20.0, 0.1                                       # 室温 20°C，散热系数 k=0.1

def analytic_cooling(T0, t):                              # ① 解析解：T(t) = Tenv + (T0-Tenv)e^{-kt}
    """牛顿冷却定律的解。返回 t 时刻的温度。"""
    return TENV + (T0 - TENV) * np.exp(-K * t)

def numeric_derivative(f, t, dt=1e-6):                    # ② 数值微分：有限差分
    """用 (f(t+dt)-f(t))/dt 测量 f 在 t 处的变化率。"""
    return (f(t + dt) - f(t)) / dt

def rhs(T):                                               # ③ 方程右端：-k (T - Tenv)
    """微分方程右端——'变化率应该等于多少'。"""
    return -K * (T - TENV)

# ---- ④ 语法检查：解的变化率 ≈ 方程右端？ ----
print("=== 语法检查：dT/dt 是否等于 -k(T - Tenv)？ ===")
T0 = 80.0                                                 # 一杯 80°C 的茶
for t in [0.0, 1.0, 3.0, 10.0]:
    T = analytic_cooling(T0, t)                           # 解在 t 处的温度
    dT = numeric_derivative(lambda s: analytic_cooling(T0, s), t)   # 测出的变化率
    rhs_val = rhs(T)                                      # 方程要求的右端
    print(f"t={t:<5} T={T:8.3f}  测得 dT/dt={dT:8.3f}  -k(T-Tenv)={rhs_val:8.3f}  差={abs(dT-rhs_val):.2e}")

# ---- ⑤ 用欧拉法从零积分，和解析解对比 ----
def euler_cooling(T0, t_end, dt):                         # ④ 数值积分
    n = int(round(t_end / dt)); T = T0
    for _ in range(n):
        T = T + rhs(T) * dt                               # x += f(x) * dt
    return T

print("\n=== 欧拉法 vs 解析解（t = 30）===")
for dt in [1.0, 0.1, 0.01]:
    e = euler_cooling(T0, 30, dt)
    a = analytic_cooling(T0, 30)
    print(f"dt={dt:<6g} 欧拉={e:8.4f}  解析={a:8.4f}  差={abs(e-a):.4f}")
```

运行输出（Python 3.11 + NumPy）：

看第一段输出的每一行：**测得的 $dT/dt$ 和 $-k(T - T_{\text{env}})$ 在每个时刻都分毫不差（差 0.00e+00）**。这杯茶从 80°C 凉到 74.3°C、再到 42.1°C、再到 22.4°C——**每一步凉下去的速度，都精确地等于"温差乘以 -k"**。解析解 $\leftrightarrow$ 变化率约定，语法检查通过。第二段输出再次确认：欧拉法从零积分同样收敛到解析解，$dt$ 越细越准。

## 层二：分步逐函数拆解

### 步骤 1：设定常数与导入

```python
import numpy as np
TENV, K = 20.0, 0.1
```

#### `import numpy as np` 与 `TENV, K = 20.0, 0.1`

**做什么**：加载 NumPy，设定场景常数——室温 `TENV=20`°C、散热系数 `K=0.1`。
**操作**：`import` 加载；解包赋值把两个数分别绑定到 `TENV`、`K`。
**输入**：无。
**输出**：`np` 句柄与两个全局常数。
**可调参数**：`K` 是"茶杯材料"旋钮——陶瓷杯 $K$ 小（0.05，凉得慢），金属杯 $K$ 大（0.5，凉得快）。`TENV` 是环境温度，空调房和室外会改变整条冷却曲线的终点。
**对应数学**：$\frac{dT}{dt} = -k(T - T_{\text{env}})$ 里的 $k$ 和 $T_{\text{env}}$。它们是方程的参数，决定解的具体形状。

---

### 步骤 2：定义 `analytic_cooling` —— 解析解

```python
def analytic_cooling(T0, t):
    return TENV + (T0 - TENV) * np.exp(-K * t)
```

#### analytic_cooling —— $T(t) = T_{\text{env}} + (T_0 - T_{\text{env}})e^{-kt}$

`return TENV + (T0 - TENV) * np.exp(-K * t)`

**做什么**：返回牛顿冷却方程在时刻 `t` 的温度。这是解族 $T(t) = T_{\text{env}} + Ce^{-kt}$ 用初始条件 $T(0)=T_0$ 钉死 $C = T_0 - T_{\text{env}}$ 后的特解。
**操作**：`(T0 - TENV)` 是初始温差，`np.exp(-K * t)$ 让它指数衰减，最后加回 `TENV` 让曲线渐进地逼近室温（从上方）。
**输入**：
- `T0`：初始温度，标量。$T(0)$。
- `t`：时刻，标量或数组。传数组得到整条冷却曲线。
**输出**：`t` 时刻的温度，标量或数组。
**可调参数**：
- `t` 传 `np.linspace(0, 60, 100)` 一次得到整条曲线，画图直接可用。
- `K` 越大衰减越快——`T0=80, K=0.5` 时 10 秒就降到约 20.4°C；`K=0.05` 时 10 秒还有约 56°C。这就是"陶瓷 vs 金属"的数学。
- 能不能加参数？把 `K`、`TENV` 从全局常数改成函数参数 `analytic_cooling(T0, t, k, tenv)`，就是一个完全独立的冷却模型工具。
**对应数学**：主线定义块里的特例——$\frac{dx}{dt} = 0.5x$ 的解 $x_0e^{0.5t}$ 的冷却版。指数从上方逼近平衡点 $T_{\text{env}}$，永不真正抵达。

---

### 步骤 3：定义 `numeric_derivative` —— 用有限差分测变化率

```python
def numeric_derivative(f, t, dt=1e-6):
    return (f(t + dt) - f(t)) / dt
```

#### numeric_derivative —— $(f(t+\Delta t)-f(t))/\Delta t$

`return (f(t + dt) - f(t)) / dt`

**做什么**：用有限差分近似导数——把"瞬间变化率"近似成"一小段时间里的平均变化率"。$\Delta t$ 取得足够小，两者就几乎相等。
**操作**：`f(t + dt) - f(t)` 是 $\Delta t$ 内函数值的变化量，除以 `dt` 得平均变化率。$dt=10^{-6}$ 时，这是对导数非常精确的估计。
**输入**：
- `f`：一个单参数函数（这里是 `lambda s: analytic_cooling(T0, s)`）。
- `t`：求导的点。
- `dt`：差分步长，默认 $10^{-6}$。
**输出**：$f'(t)$ 的数值近似，标量。
**可调参数**：
- `dt` 不能太大也不能太小：太大则"平均"得太粗（截断误差）；太小则浮点舍入误差抬头（相减两个几乎相等的数）。$10^{-6}$ 附近是安全的平衡点。
- 前向差分 `(f(t+dt)-f(t))/dt` 是最朴素的一种；`(f(t+dt)-f(t-dt))/(2dt)` 是中心差分，精度高一阶。
**对应数学**：这就是导数 $\frac{df}{dt}$ 的定义 $\lim_{\Delta t\to0}\frac{f(t+\Delta t)-f(t)}{\Delta t}$ 的截断版本——把极限换成一个小而有限的 $\Delta t$。它是"变化率"这个概念的代码化身。

---

### 步骤 4：定义 `rhs` —— 方程右端

```python
def rhs(T):
    return -K * (T - TENV)
```

#### rhs —— $-k(T - T_{\text{env}})$：约定中的变化率

`return -K * (T - TENV)`

**做什么**：给定当前温度 `T`，返回微分方程要求的变化率。这是"变化率依赖什么"那条规则本身。
**操作**：`T - TENV` 是温差，乘 `-K` 得变化率。温差为正（茶比室温热）则变化率为负（在下降）；温差为零则变化率为零（稳定，不再变）。
**输入**：`T`——当前温度，标量。
**输出**：当前时刻的 `dT/dt`，标量。
**可调参数**：`K` 与 `TENV` 是它的全局参数——已经讲过。要把它变成通用右端，写成 `def rhs(T, k, tenv)` 即可。
**对应数学**：主线定义块 $\frac{dy}{dt} = f(t, y)$ 里的 $f$。这里 $f$ 不显式依赖 $t$（方程右端只有 $y$）——叫**自治 (autonomous) 微分方程**。注意牛顿冷却定律的"负号"是灵魂：它让温度**总是**向室温靠拢，这是稳定性的雏形（§11.3.2）。

---

### 步骤 5：语法检查——解的变化率 ≈ 方程右端

```python
for t in [0.0, 1.0, 3.0, 10.0]:
    T = analytic_cooling(T0, t)
    dT = numeric_derivative(lambda s: analytic_cooling(T0, s), t)
    rhs_val = rhs(T)
    print(...)
```

**做什么**：这是本节的**核心实验**——在五个时刻，分别用两条独立路径算"变化率"：(i) 用数值微分**测量**解析解的斜率；(ii) 把解的值代入右端**计算**方程要求的变化率。两者每一行都一致（差 0.00e+00），证明解析解确实遵守约定。
**操作**：`lambda s: analytic_cooling(T0, s)` 把"固定 T0 的解"包装成单参数函数，喂给 `numeric_derivative`；`rhs(T)` 直接算右端。
**输入**：时刻列表 `[0, 1, 3, 10]`。
**输出**：五行 `(t, T, dT_measured, rhs, diff)`。
**可调参数**：把时刻列表换成任何值都行；把 `T0` 换成 `50.0`（温一点的茶）依然处处一致——**这条语法检查对任何初始条件都通过**。
**对应数学**：这是"解微分方程"的定义性验证：$y'(t) = f(t, y(t))$ 对解在每一点都成立。代码把主线的定义块变成了一场可以当场复验的实验。

---

### 步骤 6：欧拉法对照

```python
def euler_cooling(T0, t_end, dt):
    n = int(round(t_end / dt)); T = T0
    for _ in range(n):
        T = T + rhs(T) * dt
    return T

for dt in [1.0, 0.1, 0.01]:
    e = euler_cooling(T0, 30, dt)
    a = analytic_cooling(T0, 30)
    print(...)
```

**做什么**：从零积分——只用"当前状态 + 变化率×步长"反复推进，不偷看解析解——验证它同样收敛到解析值。误差 `1.12 → 0.11 → 0.01` 随 `dt` 线性下降，与 §11.2.1.2 的结论一致。

#### `T = T + rhs(T) * dt` —— 欧拉一步

**操作**：欧拉更新 $T_{k+1} = T_k + \frac{dT}{dt}\cdot dt$。每步"往前走一小段，变化率由当前温度决定"。
**输入**：当前温度 `T`、步长 `dt`。
**输出**：一步之后的温度。
**可调参数**：`dt` 是精度旋钮——已演示。注意这里的右端 `rhs` 用全局 `K, TENV`，保持与解析解同一套参数。
**对应数学**：§11.2.1.2 欧拉法公式 $x(t+\Delta t) \approx x(t) + f(x(t))\Delta t$。冷却定律因 $K=0.1$ 小、曲线平缓，所以欧拉法连 `dt=1` 都不算太糟；换成 $K=0.5$ 的金属杯，粗步长误差会明显变大——陡峭的变化最考验离散化。

## 边界声明：这套代码能做什么，不能做什么

1. **这只验证了"一个解"。** 语法检查证明 `analytic_cooling` 满足方程——但一个方程有无穷多个解（不同 $T_0$），每一条都要靠初始条件挑出来。代码验证的是"解确实合法"，不是"解唯一存在"。唯一性定理（给定连续右端 + 初值，解唯一）是本节的数学后盾，但不在代码里。
2. **数值微分是"测量"，不是"证明"。** `dt=1e-6` 的有限差分误差极小但非零；真正的"等于"只发生在极限意义下。对严格性，要用手算 $\frac{d}{dt}\big(T_{\text{env}}+(T_0-T_{\text{env}})e^{-kt}\big) = -k(T-T_{\text{env}})$——代码是演示，代数是证明。
3. **这门"语言"只覆盖光滑世界。** 牛顿冷却曲线是光滑的（导数处处存在），所以微分方程适用。真实世界里的相变、开关、冲击没有导数——微分方程对它们失语。而且 $K$ 恒定的假设（散热系数不随温度变）也只是近似；温度极高时热辐射按 $T^4$ 走，冷却定律就不准了。**每条"变化语言"的句子，都戴着它的假设眼镜。**
