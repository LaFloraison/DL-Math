# §11.2.2 微分方程 —— 习题

主线把微分方程立为"变化的语言"：$\frac{dy}{dt} = f(t,y)$，解是函数、初始条件挑特解，并给出 ODE / PDE 的分界口诀。习题分三组：**概念检验** 验证"语言"的语法，**计算实践** 亲手做冷却定律的语法检查，**DL 延伸** 把微分方程放回梯度流与扩散模型。

---

## 一、概念检验

### 题 1（选择）：微分方程的"解"是什么？

$\frac{dy}{dt} = -0.5y$ 的"解"是：

- A. 一个数 $y = -0.5$
- B. 一族函数 $y(t) = C e^{-0.5t}$
- C. 一个积分 $\int -0.5y\,dt$
- D. 一条直线 $y = -0.5t$

**解答**：B。

微分方程的解是**函数族**——含任意常数 $C$ 的通解。$y(t) = Ce^{-0.5t}$ 代入方程：$y' = -0.5Ce^{-0.5t} = -0.5y$ $\checkmark$。A 是右端系数；C 是"解方程"运算的草图；D 是直线，但 $y'=-0.5 \ne -0.5y$，不满足方程。

**思路点拨**：判据永远是"代回验证"。C 是对"积分"的误解——解不是积分，是要找一个函数使等式成立。抓住"解是函数，不是数字"，这一节的地基就稳了。

### 题 2（判断 + 简答）：为什么同一个方程，答案却"很多"？

$\frac{dy}{dt} = -0.5y$ 有无穷多个解（不同 $C$）。这是否说明微分方程"没给够信息"？加上什么信息后解就唯一？

**解答**：不是"没给够信息"——是它本来就在描述**一族**系统。$\frac{dy}{dt} = -0.5y$ 说"变化率是状态的一半（反向）"，至于"从哪个状态出发"（$y(0)$ 是多少），方程不关心：那是**初始条件 (initial condition)** 的职责。加上 $y(0) = 10$，代入 $10 = Ce^{0} = C$，解得 $C=10$，特解 $y(t) = 10e^{-0.5t}$ 唯一确定。**方程定"怎么变"，初值定"从哪变"，合起来才定"变到哪"。**

**思路点拨**：这是主线"通解 vs 特解"的考点。理解"解族 + 初值 = 特解"这套组合拳，后面 §11.2.2.1 简谐振动的 $A, B$（由初位置和初速度确定）和 §11.3.2 的不动点分析都用它。

### 题 3（简答）：ODE 和 PDE，怎么一眼区分？

请分别给出一个 ODE 和一个 PDE 的例子（不用教材原例），并说明判断依据。

**解答**：例如 ODE：$\frac{dy}{dt} = 3t^2$（只依赖时间 $t$ 一个自变量）；PDE：$\frac{\partial u}{\partial t} = \frac{\partial^2 u}{\partial x^2}$（同时依赖时间 $t$ 和空间 $x$）。判断依据：**数自变量个数**。一个自变量 → 普通导数 $\frac{dy}{dt}$ → ODE；多个自变量 → 偏导数 $\frac{\partial u}{\partial t}$ → PDE。也可以数"函数名后面挂几个变量"：$y(t)$ 一个 → ODE；$u(t,x)$ 两个 → PDE。

**思路点拨**：背口诀不如数变量。$y(t)$ vs $u(t,x)$——函数括号里的变量个数，就是答案。这道题是 §11.2.2.1/11.2.2.2 的分流阀。

## 二、计算实践

### 题 1（手算：冷却定律的特解）

牛顿冷却：$\frac{dT}{dt} = -k(T - 20)$，一杯茶 $T(0) = 80$°C，$k = 0.1$。

(a) 写出解的通式与特解。
(b) 手算 $T(1)$、$T(5)$（$e^{-0.1}\approx0.905,\ e^{-0.5}\approx0.607$）。
(c) $t$ 很大时温度趋向多少？永远到得了吗？

**解答**：

(a) 通式 $T(t) = 20 + Ce^{-0.1t}$；代入 $T(0)=80$ 得 $80 = 20 + C$，$C=60$，特解 $T(t) = 20 + 60e^{-0.1t}$。

(b) $T(1) = 20 + 60e^{-0.1} \approx 20 + 60\times0.905 = 74.3$°C；$T(5) = 20 + 60e^{-0.5} \approx 20 + 60\times0.607 = 56.4$°C。

(c) $e^{-0.1t} \to 0$，$T(t) \to 20$——趋向室温，但**永远不真正抵达**（指数只渐近逼近，不穿越）。茶凉到室温是极限过程，不是事件。

**思路点拨**：(c) 是整道题的灵魂——"趋近但不抵达"是指数衰减的标志。它与 §11.2.1.2 的"指数增长永不封顶"是一对镜像：增长逼近无穷，衰减逼近平衡点，都靠 $e^{\pm kt}$ 的渐近性。

**NumPy 验证**：
```python
import numpy as np
for t in [0, 1, 5, 30]:
    print(f"T({t}) =", round(20 + 60*np.exp(-0.1*t), 3))
```
```
T(0) = 80.0
T(1) = 74.302
T(5) = 56.407
T(30) = 22.988
```

### 题 2（手算 + 代码：验证"解确实满足约定"）

对 $\frac{dy}{dt} = -0.5y$ 的解 $y(t) = 3e^{-0.5t}$：

(a) 手算 $\frac{dy}{dt}$（用求导），并代入验证 $y' = -0.5y$。
(b) 用代码做数值验证：取 $dt=10^{-5}$，比较"数值微分测出的 $y'$"与"$-0.5y$"在 $t=2$ 处的值。

**解答**：

(a) $\frac{dy}{dt} = \frac{d}{dt}(3e^{-0.5t}) = 3 \times (-0.5)e^{-0.5t} = -0.5 \times (3e^{-0.5t}) = -0.5y$ $\checkmark$。**指数滑下来变成系数**——这正是 $e$ 定义性性质的直接应用。

(b) 代码：
```python
import numpy as np

def y(t): return 3.0 * np.exp(-0.5 * t)

t, dt = 2.0, 1e-5
measured = (y(t + dt) - y(t)) / dt          # 数值微分测变化率
expected = -0.5 * y(t)                       # 方程右端
print("测得 y' =", round(measured, 6), "  -0.5y =", round(expected, 6),
      "  差 =", f"{abs(measured - expected):.2e}")
```
```
测得 y' = -0.551819   -0.5y = -0.551819   差 = 3.26e-11
```

**思路点拨**：(a) 是"推导优于宣告"——用手算证明解合法，而不是背结论。(b) 是《代码.md》语法检查的小号复刻——数值微分测出的斜率与方程右端一致到 $10^{-11}$。两把尺子（解析与数值）互相印证，你才真正"解"了一个方程。

### 题 3（手算：从具体数字到一般公式）

教材用 $x' = 0.5x$、$x(0)=100$ 讲指数增长。

(a) 把具体数字换成字母，写出 $\frac{dx}{dt} = rx$ 的通解与特解。
(b) 验证 $r$ 为正、为零、为负三种情况下轨道的三种命运。

**解答**：

(a) 通解 $x(t) = Ce^{rt}$；特解（用 $x(0)=x_0$）$x(t) = x_0e^{rt}$。

(b) $r>0$：指数增长，$t\to\infty$ 时 $x\to\infty$（复利加速）；$r=0$：$x(t)=x_0$ 恒定（静止，$x=0$ 之外处处是不动点）；$r<0$：指数衰减，$x(t)\to0$（渐近逼近 0，不抵达）。$r$ 的符号决定轨道是冲上天、钉死、还是沉向底。

**思路点拨**：这道题是"从 0.5、100 到字母"的收官——主线《代码.md》`analytic_growth(x0, r, t)` 就是这条通式的代码。$r=0$ 的情形最易漏：当 $r=0$ 时**每一个**状态都是不动点（变化率为零），这与 §11.3.2 的"连续不动点"概念直接衔接。

## 三、DL 延伸

### 题 1（梯度流：训练循环是一条离散化的河）

连续化训练是 $\frac{dw}{d\tau} = -\nabla L(w)$（梯度流）。

(a) 用"通解/特解"的语言说明：为什么"训练"通常只能得到数值近似，而非精确轨迹？
(b) SGD 更新 $w_{k+1} = w_k - \eta\nabla L(w_k)$ 与欧拉法是什么关系？

**解答**：

(a) 因为 $\nabla L(w)$ 是**非线性的**（损失函数通常高度非线性），梯度流 $\frac{dw}{d\tau} = -\nabla L(w)$ 绝大多数情况下**没有闭式解**——你写不出"解族 + 初值 = 特解"的公式。所以训练只能靠数值积分（SGD、Adam 都是数值近似）。这正呼应主线边界声明：能写出来 ≠ 能解出来；"训练收敛"只是数值轨道落在某个不动点附近。

(b) SGD 就是欧拉法：把 $\frac{dw}{d\tau} \approx \frac{w_{k+1}-w_k}{\eta}$（$\eta$ 当步长）代入梯度流，得 $w_{k+1} = w_k - \eta\nabla L(w_k)$。**每个 `w -= lr*grad` 都是一次欧拉一步**——§11.2.1.2 的欧拉法在这里以日常形态现身。所以"学习率太大训练发散"= 欧拉法步长太大 overshoot（§11.2.1.2 习题 2 的教训）。

**思路点拨**：把"训练"从工程词翻译成"数值积分微分方程"。理解 (a) 就不会再问"为什么训练没有精确解"；(b) 让你看懂学习率为什么是步长。

### 题 2（扩散模型：偏微分方程的当代亲戚）

扩散模型的确定性加噪过程与热方程 $\frac{\partial u}{\partial t} = \alpha\frac{\partial^2 u}{\partial x^2}$ 同族。请从"自变量个数"的角度说明：为什么扩散模型的核心数学是 PDE 的世界？

**解答**：因为扩散模型处理的量是**概率分布 $p(x,t)$**——它既随"扩散时间" $t$ 变化，又随"样本空间坐标" $x$ 变化，至少两个自变量，必然出现偏导数（对 $t$ 一阶、对 $x$ 二阶）。和金属棒温度 $u(t,x)$ 一样：既要描述"随时间变"，又要描述"随空间分布"。所以它的演化方程是 PDE（Fokker–Planck 方程族），而非只有一个自变量的 ODE。

**思路点拨**：回到口诀——数自变量。$p(x,t)$ 两个自变量 → PDE。这条判断法让"图像生成"和"热扩散"在同一族方程里相遇。§11.2.2.2 会亲手数值解热方程，届时你会认出扩散模型的加噪过程就是"信息被抹平"的同族方程。

**延伸预告**：§11.2.2.1 讲 ODE——摆锤与弹簧，解二阶常微分方程；§11.2.2.2 讲 PDE——金属棒的热扩散，解偏微分方程。
