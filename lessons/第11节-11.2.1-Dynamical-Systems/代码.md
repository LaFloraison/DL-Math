# 代码：一颗卫星，一个状态空间，一条轨道

主线说：动力系统三件套——状态、演化规则、轨道；状态必须充分，否则预测崩盘。本节用**一颗在二维平面里绕行星飞行的卫星**把这三件套变成可运行的代码。

卫星的状态是四维向量 $x = (x, y, v_x, v_y)$——**位置和速度，缺一不可**。演化规则是中心引力：加速度总是指向原点、大小与距离平方成反比。我们从初始条件出发，用欧拉法 (Euler method) 一步步推轨道，然后做一个**对照实验**：把速度从状态里丢掉（只跟踪位置、假设速度不变），看"不充分的状态"如何把预测带沟里去。

---

## 层一：完整脚本

```python
import numpy as np                                   # 向量运算与 sqrt 全部来自这里

def gravity_step(state, dt):                         # ① 演化规则：状态 → 下一个状态
    """中心引力的一步欧拉更新。state = (x, y, vx, vy)。"""
    x, y, vx, vy = state                             # 拆开状态向量
    r = np.sqrt(x*x + y*y)                           # 到引力中心的距离
    ax, ay = -x / r**3, -y / r**3                    # 引力加速度：指向原点，随 r 衰减
    return np.array([x + vx*dt, y + vy*dt,           # 新位置 = 旧位置 + 速度 × dt
                     vx + ax*dt, vy + ay*dt])        # 新速度 = 旧速度 + 加速度 × dt

def simulate(state0, dt, steps):                     # ② 跑轨道：反复施加规则
    """从 state0 出发，施加 steps 次规则，返回整条轨道 (list of states)。"""
    traj, s = [], state0
    for _ in range(steps):
        traj.append(s)                               # 记下当前状态
        s = gravity_step(s, dt)                      # 规则推一步
    traj.append(s)
    return np.array(traj)

# ---- ③ 初始条件：位置 (10, 0)，速度垂直方向，刚好绕圆 ----
state0 = np.array([10.0, 0.0, 0.0, 1.0])             # 圆形轨道需要 v = sqrt(GM/r) = 1
traj = simulate(state0, dt=0.01, steps=3000)         # 30 秒，dt=0.01，共 3001 个状态点

print("=== 完整状态（位置 + 速度）预测的轨道 ===")
print("起点 位置:", traj[0, :2], " 速度:", traj[0, 2:])
print("10s后 位置:", np.round(traj[1000, :2], 4), " 距原点:", round(np.hypot(*traj[1000,:2]), 4))
print("20s后 位置:", np.round(traj[2000, :2], 4), " 距原点:", round(np.hypot(*traj[2000,:2]), 4))
print("30s后 位置:", np.round(traj[3000, :2], 4), " 距原点:", round(np.hypot(*traj[3000,:2]), 4))

# ---- ④ 对照：状态不充分——丢掉速度，假设速度永远不变 ----
naive = np.array([10.0, 0.0, 0.0, 1.0])              # 同一个起点
for _ in range(1000):                                # 只推 10 秒，看偏差就够
    x, y, vx, vy = naive
    naive = np.array([x + vx*0.01, y + vy*0.01, vx, vy])   # 速度从不更新（无引力）

true_pos = traj[1000, :2]                            # 真轨道 10 秒后的位置
print("\n=== 对照：丢掉速度的'不充分状态' 10 秒后 ===")
print("真实轨道  位置:", np.round(true_pos, 4))
print("朴素预测  位置:", np.round(naive[:2], 4))
print("偏差:", round(float(np.linalg.norm(true_pos - naive[:2])), 4))
```

运行输出（Python 3.11 + NumPy）：

```text
=== 完整状态（位置 + 速度）预测的轨道 ===
起点 位置: [10. 0.]  速度: [0. 1.]
10s后 位置: [0.9951 9.9486]  距原点: 9.9981
20s后 位置: [-9.9729 0.7614]  距原点: 10.0020
30s后 位置: [0.2092 -9.9933]  距原点: 9.9955
=== 对照：丢掉速度的'不充分状态' 10 秒后 ===
真实轨道  位置: [0.9951 9.9486]
朴素预测  位置: [10. 1.]   ← 还停留在起点附近
偏差: 12.5198
```

真实轨道每 10 秒扫过四分之一圆周（10,0）→（0.995,9.95）→（-9.97,0.76）→…，距原点恒为 10——卫星在绕圈。而"丢掉速度"的朴素预测，10 秒后还停在起点附近（(10,1)），偏差 12.5——**状态不充分，预测彻底崩盘。** 这正是主线第一节那面墙的数字证据。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy —— 只要两个操作

```python
import numpy as np
```

**做什么**：加载 NumPy。脚本只用 `np.sqrt`、`np.hypot`、`np.linalg.norm` 和 `np.array` 的向量运算。

#### `import numpy as np` —— 引入数值工具箱

**操作**：加载 NumPy，绑定简写 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：无直接公式对应——它是所有数值操作的后勤。

### 步骤 2：定义 `gravity_step` —— 演化规则的一次应用

```python
def gravity_step(state, dt):
    x, y, vx, vy = state
    r = np.sqrt(x*x + y*y)
    ax, ay = -x / r**3, -y / r**3
    return np.array([x + vx*dt, y + vy*dt,
                     vx + ax*dt, vy + ay*dt])
```

#### gravity_step —— 中心引力的一步欧拉更新

`ax, ay = -x / r**3, -y / r**3` 与 `x + vx*dt, y + vy*dt`

**做什么**：给一个状态，返回规则作用后的下一个状态。这是主线定义块里演化规则 $f: X \to X$ 的**代码模板**：输入一个状态点，输出状态空间里的下一个点。
**操作**：
1. 拆包：`x, y, vx, vy` 是状态的四个分量——前两个是位置，后两个是速度。
2. 算距离：`r = np.sqrt(x*x + y*y)`，卫星到引力中心（原点）的距离。
3. 算加速度：`ax, ay = -x / r**3, -y / r**3`。这是单位质量的万有引力 $a = -\frac{GM}{r^2}\cdot\frac{\vec r}{r}$ 的简化版——方向指向原点（负号），大小随 $r^2$ 衰减。注意这行的数学里藏着"加速度"这一层：规则要先算**变化率**，才能更新速度。
4. 欧拉更新：位置 $+=$ 速度 $\times dt$；速度 $+=$ 加速度 $\times dt$。这是把"连续演化"切成小步长 $dt$ 的近似——**欧拉法 (Euler method)**，§11.2.1.2 会系统讲它。
**输入**：
- `state`：四维数组 `(x, y, vx, vy)`——卫星此刻的完整状态。
- `dt`：步长，标量。每一"格"时间多长。
**输出**：新的四维数组——规则作用后的下一个状态。
**可调参数**：
- `dt` 是精度旋钮。`dt=0.01` 时轨道近似圆；把 `dt` 改成 `1.0`（每步一大格），轨道会明显漂走——欧拉法步长太大会积累误差。试试 `dt=0.5`，10 秒后距原点会显著偏离 10。
- 引力规则 `-x/r**3` 是"平方反比定律"的化身。把它换成弹簧力 `-x`（线性恢复力），卫星轨道会变成椭圆/直线振荡——**换规则 = 换动力学**，这正是动力系统"规则决定轨道"的核心。真实系统里的"规则"（$W_{hh}$、引力常数）都是这样作为函数写死的。
- 状态向量能不能加维度？可以。加上第 5 维"质量"、第 6、7 维"三维空间的 z 坐标"，`gravity_step` 的拆分、加速度公式都要跟着改——这就是"状态空间变高维"的物理含义。RNN 的 $d_{hid}$ 同理：加维度 = 加大状态空间。
**对应数学**：主线定义块的 $x_{n+1} = f(x_n)$。`gravity_step` 就是 $f$。它是**确定性的**——同一种子永远得到同一轨道。

### 步骤 3：定义 `simulate` —— 反复施加规则，收集轨道

```python
def simulate(state0, dt, steps):
    traj, s = [], state0
    for _ in range(steps):
        traj.append(s)
        s = gravity_step(s, dt)
    traj.append(s)
    return np.array(traj)
```

#### simulate —— 从初始条件出发，跑出一条轨道

`for _ in range(steps): traj.append(s); s = gravity_step(s, dt)`

**做什么**：把演化规则反复施加 `steps` 次，从初始条件 `state0` 出发，收集途中每一个状态，返回整条轨道。这是主线"轨道 = 规则反复作用留下的足迹"的代码翻译。
**操作**：循环体内"先记录、再推进"。`traj` 列表累积每个时刻的状态；结束时转成 `np.array`，形状 `(steps+1, 4)`——每一行是一个时刻的完整状态。
**输入**：
- `state0`：初始条件，四维数组。轨道从它出发。
- `dt`：步长，标量。
- `steps`：步数，正整数。规则被施加多少次。
**输出**：形状 `(steps+1, 4)` 的数组——轨道。第 $k$ 行是时刻 $k\cdot dt$ 的状态。
**可调参数**：
- `state0` 是"命运之起点"：圆形轨道要 `v=1.0` 恰好与引力平衡。把初始速度改成 `1.5`（太快），卫星挣脱束缚、轨道变成开的双曲线；改成 `0.5`（太慢），卫星坠向原点——**同一个规则，不同初始条件 = 不同命运**，这是主线 §11.2.1 定义块里"轨道由初始条件唯一确定"的直观证据。
- `steps` × `dt` = 模拟的总时长。总时长 = 30 秒时，卫星绕了约 0.95 圈。
- 能不能加参数？可以把 `gravity_step` 作为参数传入，让 `simulate` 变成"任意动力系统的通用轨道机"——`simulate(step_fn, state0, dt, steps)`。这是把演化规则与轨道收集解耦的标准做法。
**对应数学**：轨道 $\{x_0, x_1, \dots, x_n\}$。`traj[k]` 就是 $x_k$。

### 步骤 4：打印完整状态预测的轨道

```python
traj = simulate(state0, dt=0.01, steps=3000)
print("10s后 位置:", np.round(traj[1000, :2], 4), " 距原点:", round(np.hypot(*traj[1000,:2]), 4))
```

#### `np.hypot(x, y)` —— 一步算距离

**操作**：`np.hypot(a, b)` 返回 $\sqrt{a^2 + b^2}$——比手写 `np.sqrt(a**2 + b**2)` 更稳（防溢出），也更短。
**输入**：两个标量/数组。
**输出**：$\sqrt{x^2+y^2}$，形状与输入一致。
**可调参数**：可以传第三维 `np.hypot(np.hypot(x, y), z)` 得三维距离。
**对应数学**：这就是欧氏距离——用来验证"距原点是否恒为 10"，即卫星是否在绕圆。输出里 9.998、10.002、9.995 的微小波动，是欧拉法 $dt=0.01$ 的截断误差。

#### `traj[1000, :2]` —— 取第 1000 步的状态的前两维（位置）

**操作**：NumPy 高级索引。`[1000, :2]` 取第 1000 行、前两列——即第 1000 步的位置 `(x, y)`。
**输入**：`traj`（形状 `(3001, 4)`）、行号、列切片。
**输出**：形状 `(2,)` 的数组——那一刻的位置。
**可调参数**：`[:2]` 换 `[2:]` 就是取速度分量；`1000` 换成任意 $k$ 就是取任意时刻。切片是"从状态里抽出你关心的分量"的标准操作。
**对应数学**：状态 $x_n = (x_n, y_n, v_{x,n}, v_{y,n})$，`[1000, :2]` 提取其中的位置坐标。

### 步骤 5：对照实验 —— 状态不充分，预测崩盘

```python
naive = np.array([10.0, 0.0, 0.0, 1.0])
for _ in range(1000):
    x, y, vx, vy = naive
    naive = np.array([x + vx*0.01, y + vy*0.01, vx, vy])
```

**做什么**：模拟一个"状态不充分"的朴素模型——它只把速度当成**恒定常数**，从不更新（没有引力加速度）。10 秒后比较它与真实轨道的偏差。
**操作**：循环里位置按 `x + vx*dt` 走，但速度 `vx, vy` 原样放回——没有任何力去改变它。
**输入**：与真实轨道相同的初始条件 `(10, 0, 0, 1)`。
**输出**：`naive`——朴素预测 10 秒后的状态。
**可调参数**：这里"不充分"体现在"忽略了加速度"。你也可以换个漏法：只跟踪位置、把速度估计错（把 `vx` 初值写成 `2.0`），一样会把轨道带偏。**每一种漏法，都是主线'状态必须充分'的一次实际演示。**
**对应数学**：这就是主线"撞墙"一幕——两颗卫星同一位置、不同速度，未来不同。`naive` 假装"位置就能决定未来"，于是它给出的轨道是一条直线（匀速直线运动），而真实轨道是一条弧线。输出的偏差 `12.5198` 就是"状态不充分"的代价：**预测长度 10 秒、误差 12.5 个长度单位——比轨道半径还大。**

## 边界声明：这套代码能做什么，不能做什么

1. **欧拉法只是近似。** `gravity_step` 用 $x_{n+1} = x_n + v_n dt$ 代替真实的连续运动，每步都有一点截断误差。输出里"距原点 9.998 而非 10"就是证据。想要更准，可以换更高阶的数值积分（中点法、RK4，或 `scipy.integrate.solve_ivp`——§11.2.2.1 会用到）。动力系统"解不出来"时的标准退路就是数值积分，而欧拉是最朴素的一种。
2. **这只是二维、一个引体。** 真实卫星还要考虑行星的扁率、大气阻力、其他天体的摄动；三体以上就进入混沌区（§11.2.2.2 预告）。这里的两维 + 单引力，是让你看清"状态+规则+轨道"骨架的最小舞台。
3. **确定性 ≠ 可预测。** 这个脚本是确定性的（同一种子同一条轨道），所以它能"预测"。但动力系统的边界（§11.2.1 第五节）说得很清楚：规则确定不代表长期可预测——混沌系统对初始条件敏感到天文数字般放大误差。你现在看到的这颗乖乖绕圈的卫星，是动力系统家族里最驯服的一员。
