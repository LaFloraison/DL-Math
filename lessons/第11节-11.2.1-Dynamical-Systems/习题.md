# §11.2.1 动力系统 —— 习题

主线把动力系统拆成三件套（状态空间、演化规则、轨道），并立了两条纪律：**状态必须充分（马尔可夫性）**、**对象与表示分离**。习题分三组：**概念检验** 验证三件套与纪律，**计算实践** 手推一条小轨道并做代码对照，**DL 延伸** 把状态空间视角放回 RNN。

---

## 一、概念检验

### 题 1（选择）：哪项不是动力系统的必要成分？

一个动力系统由状态空间、演化规则、初始条件共同描述。以下哪项**不是**"给定初始条件就能唯一确定轨道"所必需的？

- A. 状态空间 $X$：所有可能状态的集合
- B. 演化规则 $f: X \to X$：状态到状态的映射
- C. 状态必须充分（马尔可夫性）
- D. 必须能把轨道写成解析公式 $x_n = g(n)$

**解答**：D。

前三项都是"轨道被唯一确定"的必要条件：没有状态空间就没有点，没有规则就没有推进，状态不充分（漏信息）轨道就会错。而 D 是"解析公式"的要求——绝大多数动力系统**没有**解析解（三体问题、混沌系统），轨道照样被唯一确定，只是要靠数值方法算出来。**"有唯一轨道"不等于"写得闭式公式"。**

**思路点拨**：这道题考"确定性"与"可解析"的区分。常见错误是把"可预测"误当成"有公式"。回忆 §11.2.1 边界声明：多数系统解不出闭式解，但数值积分照样给出轨道。

### 题 2（判断 + 简答）：位置，是一个"充分"的状态吗？

一辆汽车行驶在高速公路上。你打算用"此刻的位置"作为状态来预测它 5 秒后的位置。

(a) 这个状态充分吗？为什么？
(b) 补上什么才充分？请构造一个充分的状态。

**解答**：

(a) **不充分**。同一位置，汽车可能以 30 km/h 滑行，也可能以 120 km/h 疾驰——两个状态共享同一个位置，下一秒却天差地别。只给位置，规则无法唯一决定未来。

(b) 至少补上速度：状态 $= (x, y, v_x, v_y)$（位置 + 速度）。如果还要考虑驾驶员是否踩刹车、弯道是否减速，就得更细——直到"给定此刻状态，未来不再被过去额外影响"为止。这正是 §11.2.1 的历史里哈密顿的顿悟：**位置 + 动量才是一个完整的"此刻"。**

**思路点拨**：判据是"两颗卫星同一位置、不同速度"的翻版。凡是出现"同一个状态却有两种未来"，状态就不充分。现实建模里这条纪律决定你往状态里塞多少东西——塞少了漏信息，塞多了计算爆炸。

### 题 3（简答）：状态是对象，坐标是表示——为什么这个区分重要？

有人说："换一个坐标系，卫星的轨道就变了。" 判断并解释。

**解答**：错。**轨道是对象，坐标系是表示。** 卫星绕行星飞的那条弧线（轨迹）是物理事实，不管用经纬度、直角坐标还是球坐标去编号，那条弧线都在同一个地方。换坐标系改变的只是坐标的数字写法——同时改变的是"演化规则在坐标下的样子"（比如从极坐标下的式子变成直角坐标下的式子），**轨道本身不动**。这一点对 RNN 的 $W_{hh}$ 尤其关键：给隐藏状态换一组基向量，矩阵变了个样子，但网络学到的动力学不变。

**思路点拨**：区分"物理事实"与"编号方式"。这条纪律在 §2 章线性代数里反复强调（向量 vs 向量的坐标表示），到了动力系统它以更尖锐的形式回归：轨道是坐标系无关的几何对象。

## 二、计算实践

### 题 1（手算轨道：三件套各就各位）

定义离散动力系统：状态空间 $X = \{1, 2, 3\}$，演化规则 $f(1)=2,\ f(2)=3,\ f(3)=1$，初始条件 $x_0 = 1$。

(a) 写出轨道 $x_0, x_1, x_2, x_3, x_4$。
(b) 这个系统有"不动点"吗？什么叫不动点？
(c) 如果初始条件改成 $x_0 = 2$，轨道会怎样？说明什么？

**解答**：

(a) $x_0=1,\ x_1=f(1)=2,\ x_2=f(2)=3,\ x_3=f(3)=1,\ x_4=2$。轨道是 $1 \to 2 \to 3 \to 1 \to 2 \to \dots$，一个长度为 3 的循环。

(b) 不动点 (fixed point) 是满足 $f(x^*) = x^*$ 的状态——规则作用后原样不动。这里 $f(1)=2 \ne 1$、$f(2)=3 \ne 2$、$f(3)=1 \ne 3$，**没有不动点**。整个系统永不静止，永远在 1→2→3→1 的循环里打转。这提示：不动点不是动力系统的必需品，它只是"轨道被吸住"的那类系统才有。

(c) $x_0=2$ 时：$x_1=3, x_2=1, x_3=2, x_4=3$——同样的循环，只是从另一格进入。**初始条件改变轨道的位置，不改变轨道的形状（同一个 3-循环）。** 这印证"轨道由初始条件唯一确定"——不同起点，不同的状态序列，但共享同一个循环结构。

**思路点拨**：这是最简状态空间（3 个点）上的一次手算。要点：(a) 一步一个脚印地套 $f$；(b) 不动点的定义 $f(x^*)=x^*$ 是后面 §11.3.2 的伏笔；(c) "起点不同、循环相同"是动力系统"吸引子"概念的雏形——§11.3.2 会说 RNN 的长期记忆与这个 3-循环是同一类现象。

**NumPy 验证**：
```python
import numpy as np

f = {1: 2, 2: 3, 3: 1}
for x0 in [1, 2]:
    traj, x = [], x0
    for _ in range(6):
        traj.append(x); x = f[x]
    print(f"x0={x0}:", traj)
```
```
x0=1: [1, 2, 3, 1, 2, 3]
x0=2: [2, 3, 1, 2, 3, 1]
```

### 题 2（手算 + 代码：一维动力系统的轨道）

设 $x_{n+1} = 0.5\, x_n + 1$，$x_0 = 0$。

(a) 手算 $x_1, x_2, x_3, x_4$。
(b) 求不动点 $x^*$（解 $x^* = 0.5 x^* + 1$）。
(c) 用代码跑 20 步，观察轨道是否逼近 $x^*$。

**解答**：

(a) $x_1 = 0.5\times0 + 1 = 1$；$x_2 = 0.5\times1 + 1 = 1.5$；$x_3 = 0.5\times1.5 + 1 = 1.75$；$x_4 = 0.5\times1.75 + 1 = 1.875$。数字一路逼近 2。

(b) $x^* = 0.5 x^* + 1 \Rightarrow 0.5 x^* = 1 \Rightarrow x^* = 2$。

(c) 轨道 $0, 1, 1.5, 1.75, 1.875, 1.9375, \dots$——逐次逼近 2，永不越过。**不动点 2 是稳定的：无论起点在哪，轨道都被吸向它。**

**NumPy 验证**：
```python
x, traj = 0.0, []
for _ in range(20):
    traj.append(x); x = 0.5 * x + 1
print("第20步:", round(traj[-1], 8), "  不动点 2 的偏差:", round(2 - traj[-1], 8))
```
```
第20步: 1.99999809   不动点 2 的偏差: 1.9e-06
```

**思路点拨**：(b) 的不动点方程 $x^* = f(x^*)$ 是 §11.3.2 固定点分析的主角。(c) 让你看见"稳定不动点"的实感：不是恰好落在 2，而是**无限逼近 2**。判断稳定性的判据（$|f'(x^*)| < 1$）在 §11.3.2 会给出——这里的斜率 $0.5 < 1$，正是稳定。

### 题 3（手算：把三件套装进一个小 RNN）

一个 1 维 RNN：$h_{t+1} = 0.8\, h_t + 0.2\, x_t$，输入固定为 $x_t = 1$，初始 $h_0 = 0$。

(a) 手算 $h_1, h_2, h_3$。
(b) 在"忽略输入"的意义下求它的不动点 $h^*$（解 $h^* = 0.8 h^* + 0.2$）。
(c) $h_t$ 会逼近 $h^*$ 吗？这说明了 RNN 记忆的什么性质？

**解答**：

(a) $h_1 = 0.8\times0 + 0.2 = 0.2$；$h_2 = 0.8\times0.2 + 0.2 = 0.36$；$h_3 = 0.8\times0.36 + 0.2 = 0.488$。

(b) $h^* = 0.8 h^* + 0.2 \Rightarrow 0.2 h^* = 0.2 \Rightarrow h^* = 1$。

(c) 会。$h_t = 0.2 + 0.8\times(\dots)$ 逐步逼近 1（$0.2, 0.36, 0.488, 0.5904, \dots$）。这说明**这个 RNN 在持续输入 1 时，记忆被"吸"向一个固定值**——一旦 $h_t$ 到达 1，新的输入不再改变它，历史的影响也几乎消失。这就是"记忆会饱和/被吸引"的最简形态：$0.8$ 这个系数决定了"旧记忆保留多少"（越大记得越久），§11.3.2 的稳定性分析会告诉你，$|0.8| < 1$ 意味着记忆**指数衰减**——它记不住"很久以前"。

**思路点拨**：这道题是 §11.3.2 的直通预告。$0.8$ 就是 $W_{hh}$ 在 1 维世界的化身；"$|$系数$|<1$ → 记忆衰减"正是梯度消失的雏形。你可以试：把 0.8 改成 1.0（$h_{t+1} = h_t + 0.2$），记忆会线性累积、永不饱和——那时 RNN 会不会更好？答案会在 §11.3.2 揭晓。

## 三、DL 延伸

### 题 1（语言模型：记忆的"状态空间"在哪？）

有人说："RNN 把一句话的上下文存进隐藏状态 $h_t$，所以它的'记忆'是一段可检查的编码。" 结合动力系统三件套，判断这句话的准确程度。

**解答**：方向正确，但要加三处精确化。**（1）** $h_t$ 确实是状态，它生活在 $\mathbb{R}^{d_{hid}}$ 状态空间里；上下文被压缩成这个点。**（2）** 但这个"编码"是**有损、稠密、不可直接解读**的——$h_t$ 的每个分量并不对应"主语""时态"这类语言学标签，它是整段历史被 $W_{hh}$ 非线性地搅拌后的混合体。**（3）** 状态是否"充分"（马尔可夫性）取决于 $W_{hh}$ 的谱性质：$|$特征值$|$远小于 1 时，$h_t$ 记不住太久以前——普通 RNN 的"记忆"是有保质期的。所以更准确的说法是：**记忆 = 一条轨道，它的"寿命"由状态空间的动力学（稳定性）决定，而不是由"存了什么"决定。**

**思路点拨**：这道题考"状态是点，不是仓库"。常见误解是"$h_t$ 像数据库一样存着各个词"。正确理解是：$h_t$ 是轨道上的一个点，它包含的信息取决于演化规则如何压缩历史。LSTM 的门控 = 让网络自己学"什么值得保留"，本质上是学习一个更好的状态压缩。

### 题 2（"状态充分"的工程化：从 RNN 到 Transformer）

普通 RNN 的马尔可夫性依赖 $h_t$ 足够充分；而 Transformer 根本没有逐时间步滚动的 $h_t$，它通过注意力一次性"看到"整条序列。请用本节"状态"的概念，比较两者"状态空间"的差异。

**解答**：普通 RNN 的状态是**单点** $h_t \in \mathbb{R}^{d_{hid}}$——整个上下文被压缩成一个点，马尔可夫性全靠这个点"够不够装得下历史"（不够就忘事，梯度消失）。Transformer 的"状态"不是单点，而是**整条序列的表示**（每层每个 token 都有一个向量，加上显式位置编码）——它不靠"递归压缩"，而靠"并行重看"：每步都从整条序列重新计算。代价是**状态空间大得多**（$\mathbb{R}^{T \times d}$ 而非 $\mathbb{R}^d$），换来的好处是不受"压缩有损"的困扰。**一个是"边走边压缩"，一个是"随时回看全部"——这正是本章边界声明（Transformer 不是本章意义的动力系统）的深层原因。**

**思路点拨**：把问题翻译成"状态空间大小 vs 状态充分性"的权衡。RNN 用单点状态换效率、输掉了长程记忆；Transformer 用整条序列状态换记忆、付了显存代价。这道题帮你理解为什么 2017 之后序列模型换了主流——以及为什么 RNN 的数学（本章全部内容）至今仍是理解记忆与稳定性的最锋利的刀。
