## 第一步：Toy Model —— 一个在田垄之间跳跃的农场主

你有一小块地，种两种作物：作物 A 和作物 B。每种作物都有两笔"账"要付：

- **土地**：一亩 A 和一亩 B 各占 1 单位地，你一共只有 4 单位地。于是 $x_1 + x_2 \le 4$。
- **水源**：一亩 A 耗 2 单位水，一亩 B 耗 1 单位水，你只有 6 单位水。于是 $2x_1 + x_2 \le 6$。

每收一亩 A 净赚 3 元，每收一亩 B 净赚 2 元。你的目标：$\max Z = 3x_1 + 2x_2$。

你画下这两条线，可行域是一个四边形，四个顶点。上一节（§5.3.1）你已经知道**最优解必在顶点上**。现在的问题是：**怎么聪明地从顶点走到顶点？**

你想出一个规矩：**从一个顶点出发，永远只跳到"会让利润增加"的相邻顶点，直到跳无可跳。** 你从原点 $(0,0)$（种零亩，赚 0）出发。看一眼两条边：沿 $x_1$ 轴走，每走一步赚 3；沿 $x_2$ 轴走，每走一步赚 2。**A 更值钱，先沿 $x_1$ 轴走**——走到头，被水源挡住（$2x_1 \le 6$），停在 $(3,0)$，赚 9。

到了 $(3,0)$，再想往上走（增加 $x_2$）。沿着水源这条边（$2x_1 + x_2 = 6$）往上滑——但土地在挡你：$x_1 + x_2 = 4$。两条边交于 $(2,2)$。你停在这，赚 $3\times 2 + 2\times 2 = 10$。

**跳无可跳了**——$(2,2)$ 的两条边，往哪个方向走都会让利润下降。你宣布：(2,2)，赚 10，最优。

你刚刚完整地跑了一遍**单纯形法 (simplex method)**：从原点出发，沿"利润增加最快的边"跳到相邻顶点，撞墙，再沿另一边跳，直到任何相邻顶点都不能让你更好。**不是搜遍所有顶点，而是只沿着"变好"的方向跳**——这就是它比"枚举顶点"聪明的地方。现在问一个"浅到可笑"的问题：**"哪条边会让我变好"怎么精确判断？"跳到哪"怎么精确计算？万一跳着跳着绕回了原路（死循环）怎么办？** 该请数学登场了。

## 第二步：正式数学讲解

### 一、标准形式：先把 LP 摆成统一姿势

单纯形法要求问题有一个标准姿势。教材给出线性规划的标准形式：

$$\max Z = c_1 x_1 + c_2 x_2 + \cdots + c_n x_n \quad \text{s.t.} \quad Ax \le b,\; x \ge 0$$

- $c$：目标函数系数向量（每种作物赚多少）
- $A$：约束系数矩阵（每种作物耗多少资源）
- $x$：决策变量向量（种多少亩）
- $b$：约束右端（资源上限）

（教材例：$c = (3,2)$，$A = \begin{pmatrix}1&1\\2&1\end{pmatrix}$，$b = (4,6)$。）

**一个关键技巧：把不等式变成等式——引入松弛变量 (slack variables)。** $x_1 + x_2 \le 4$ 变成 $x_1 + x_2 + s_1 = 4$，其中 $s_1 \ge 0$ 表示"没用完的土地"。$2x_1 + x_2 \le 6$ 变成 $2x_1 + x_2 + s_2 = 6$。**松弛变量把"不等式"翻译成"等式"，让数学能处理"恰好用完"的顶点。** 在 $(0,0)$ 处，$s_1 = 4, s_2 = 6$（资源全没用）；在 $(2,2)$ 处，$s_1 = s_2 = 0$（资源全部耗尽——所以它是最优，两条约束都绑定）。

### 二、单纯形法的三个动作

单纯形法是一个"顶点到顶点"的迭代：每个顶点对应一组"基本变量 (basic variables)"（取正值）和"非基本变量 (non-basic variables)"（取零）。从一个顶点到相邻顶点，就是**换出一个基本变量、换进一个非基本变量**——这个操作叫**转轴 (pivot)**。具体三步：

**动作一：选入基变量 (entering variable)——哪条边能让我变好？**
看目标函数在"非基本变量 = 0"处的表现。若某个非基本变量的系数是**正的**（在最大化问题里），把它从 0 增大能让目标变好——它就该入基。哪个"边际贡献"最大，先选它（教材用"目标行最负的约化成本"判定，符号约定：$\max$ 问题看 $-$系数，约化成本最负者入基）。农场例子：$x_1$ 每单位赚 3，$x_2$ 赚 2，先入基 $x_1$。

**动作二：选出基变量 (leaving variable)——能跳多远？**
入基变量能增大多少，由约束决定。对每条含入基变量的约束，计算"该约束能容忍入基变量增大到多少"（$\frac{\text{右端}}{\text{入基变量系数}}$），**取最小的那个**——这就是**最小比值检验 (minimum ratio test)**。它保证新点仍在可行域内。农场例子：土地说 $x_1 \le 4$，水源说 $x_1 \le 3$——取小者，$x_1$ 最多到 3，于是 $(3,0)$。

**动作三：转轴——换基底，重新表示。**
用线性代数（高斯消元）把新基本变量的方程整理好，更新整个表格（表格 = 单纯形表 tableau），回到动作一。

**收敛判据**：当目标行不再有"能变好的系数"（最大化问题的约化成本全部非负），当前顶点就是最优——**任何相邻顶点都无法再改进**，这正是 Toy Model 里"跳无可跳"的精确版。

> **单纯形法 (simplex method)**
>
> 物理含义：从可行域的一个顶点出发，沿"使目标改善"的棱跳到相邻顶点，直到任何相邻顶点都不再改善——由 LP 基本定理保证，此时停在最优顶点。
>
> **标准形式**：$\max \; c^T x \quad \text{s.t.} \quad Ax \le b,\; x \ge 0$（引入松弛变量转成等式）
>
> **单次迭代（转轴）**：
> 1. 选入基变量：目标行约化成本最负者（$\max$ 问题）
> 2. 选出基变量：最小比值检验 $\arg\min_{r:\, A_{r,e}>0} \frac{b_r}{A_{r,e}}$（$e$ 为入基变量列）
> 3. 高斯消元更新单纯形表
>
> **终止**：目标行全部 $\ge 0$ → 当前顶点最优
> - 若最优解存在，必在某个顶点取到（LP 基本定理，§5.3.1）
> - 实践中通常极快；最坏情况复杂度可能是指数的（罕见）
> - 可能"循环 (cycling)"——用 **Bland 法则**（按最小下标选入基/出基变量）避免

**每个符号的含义逐一解释：** $c^T x$ 是目标，$Ax \le b$ 是约束，松弛变量把可行域从"不等式区域"变成"高维空间里的等式面"。顶点对应"$n$ 个变量取零、其余取正"的基底。

### 三、撞墙加深：死循环、退化与 Bland 法则

单纯形法有一个理论上的尴尬：**理论上可能循环 (cycle)——在两个或多个顶点之间来回跳，目标值不变，永远不停。** 这发生在**退化 (degenerate)** 时——某个基本变量取值为 0，最小比值检验出现平局。

解决方法是教材点名的 **Bland 法则 (Bland's Rule)**：当有多个可入基/出基变量可选时，**永远选下标最小的那个**。这个看似随意的约定，保证了单纯形法**永远不会循环**。**定理：按 Bland 法则操作的单纯形法，必在有限步内终止。** 细节上是"任取一个"与"取最小下标"的区别，但数学上前者可能循环，后者保证不循环——**一个纪律，救了整个算法。**

### 四、对偶问题：每一道 LP 都有一个影子

教材点出一个深刻的结构：**每一个线性规划都有一个对应的对偶问题 (dual problem)。** 原问题叫**原始问题 (primal)**。两者的关系：

- 原始问题是"让每种作物赚最多"；对偶问题是"让每份资源的影子价格最低"。
- **强对偶定理**：若原始有最优解，则对偶也有最优解，且两者的最优值**相等**。
- 对偶变量（影子价格）告诉你"再买一单位土地值多少钱"——这在资源定价、经济分析里威力无穷。

对偶的价值不只是理论美。有时对偶比原始**更容易解**；有时对偶变量本身就是你要的东西（资源定价）。§5.3.9 的拉格朗日乘子，与对偶理论血脉相连——那里会看到更一般的形式。

### 五、单纯形法的家族与对手

单纯形法有多个变体，教材点名的两个：
- **两阶段单纯形法 (Two-Phase Simplex)**：当初始顶点不好找（约束含 $\ge$ 或等式）时，第一阶段先找一个可行顶点，第二阶段再优化。
- **修正单纯形法 (Revised Simplex)**：不在整个表格上做高斯消元，只维护关键信息，省内存、省时间，适合大规模问题。

它的对手是**内点法 (interior point methods)**（§5.3.1 提过）：不走顶点，从可行域内部直达最优。对超大规模 LP，内点法往往更快；单纯形法在稀疏、小中型问题上依然称霸。**两者互补，现代求解器（HiGHS、CPLEX、Gurobi）常常都内置，按需切换。**

**边界声明：** 单纯形法的"顶点最优"保证只属于**线性**世界。一旦目标或约束非线性，顶点直觉失效（§5.3.1 末尾讲过）。另外它的最坏情况是指数级——1957 年 Klee 与 Minty 构造的"扭立方体"能逼疯任何天真实现的单纯形法，这正是内点法存在的原因之一。

## 第三步：DL 桥接

**诚实地说：单纯形法不出现在深度学习的训练循环里**——深度学习的目标非凸，顶点定理完全不适用。但它在深度学习的"周边世界"里站岗，而且它的思想塑造了优化文化的深层结构。

**其一：线性世界的精确解，是深度学习"够好即可"的反面镜子。** 单纯形法代表了"精确保证"的极致：有限步、严格最优、可证明。深度学习告别了这一切。理解单纯形法的精确承诺，你就理解了深度学习在"放弃什么"——这是两代优化哲学的分水岭。

**其二：对偶思想渗入了深度学习的每个角落。** SVM 的对偶形式（把约束拉进目标，用对偶变量求解）、带约束训练里的拉格朗日对偶、强化学习策略约束的拉格朗日方法——**"把约束变成影子价格"这个对偶直觉**，在深度学习里以"对偶/拉格朗日"的形式反复出现（§5.3.9 会正式展开）。你在 GAN 训练里"判别器给生成器打分"的对抗结构，也常被解释成一种 min-max 对偶博弈。

**其三：顶点跳跃 vs 梯度下降——两种世界的两种舞步。** 单纯形法在离散的顶点间跳跃，梯度下降在连续的曲面上滑行。前者精确但只属于线性凸多面体，后者近似但统治非凸丘陵。**你理解了这两种舞步的区别，就理解了优化理论的全景地图**：精确派在顶点之间起跳，逼近派在坡度上滑行。

**一句话收束：** 单纯形法是线性世界加冕的国王——一个精确、优雅、有一个世纪历史的算法。深度学习不再需要它，但深度学习的每一次训练，都站在它划定的那条"精确 vs 逼近"分界线的另一侧。具体如何用一张单纯形表亲手转轴、验证 (2,2) 与 Z=10，见《代码.md》。
