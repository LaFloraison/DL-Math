# 代码：一张单纯形表——亲手转轴求解 LP

**目标**：主线里的农场问题——$\max Z = 3x_1 + 2x_2$，约束 $x_1 + x_2 \le 4$，$2x_1 + x_2 \le 6$，$x_1, x_2 \ge 0$，已知最优 $(2,2)$，$Z=10$。这里**从零实现表格单纯形法**：引入松弛变量、构造单纯形表、反复执行"选入基变量 → 最小比值检验 → 转轴"，直到目标行全非负。**没有任何优化库——每一步转轴都是你能看懂的高斯消元。**

## 层一：完整脚本

```python
import numpy as np

# ---- 1. 标准形式 ----
c = np.array([3.0, 2.0])            # 目标系数: Z = 3x1 + 2x2
A = np.array([[1.0, 1.0],           # 约束矩阵
              [2.0, 1.0]])
b = np.array([4.0, 6.0])            # 右端
m, n = A.shape                      # m=2 约束, n=2 变量

# ---- 2. 构造单纯形表: 引入松弛变量 s1, s2 ----
T = np.zeros((m + 1, n + m + 1))    # 形状 (3, 5): x1,x2,s1,s2 | b
T[:m, :n] = A                       # 原约束系数
T[:m, n:n+m] = np.eye(m)            # 松弛变量列 = 单位阵
T[:m, -1] = b                       # 右端
T[-1, :n] = -c                      # 目标行: -3, -2, 0, 0 | 0
T[-1, -1] = 0.0

# ---- 3. 转轴函数: 高斯消元 ----
def pivot(T, r, e):
    T[r] = T[r] / T[r, e]                       # 主元行归一
    for i in range(T.shape[0]):
        if i != r and abs(T[i, e]) > 1e-12:
            T[i] = T[i] - T[i, e] * T[r]        # 其余行消元

# ---- 4. 单纯形主循环 ----
steps = 0
while True:
    e = int(np.argmin(T[-1, :n+m]))             # 目标行最负 -> 入基变量
    if T[-1, e] >= -1e-12:                       # 全非负 -> 最优
        break
    ratios = []
    for r in range(m):
        ratios.append(T[r, -1] / T[r, e] if T[r, e] > 1e-12 else np.inf)
    r = int(np.argmin(ratios))                  # 最小比值 -> 出基变量
    pivot(T, r, e)                               # 转轴
    steps += 1

# ---- 5. 提取最优解 ----
x = np.zeros(n)
for j in range(n):                              # 对每个原始变量
    col = T[:m, j]                               # 它在约束行的列
    if abs(col.sum() - 1) < 1e-9 and (col >= -1e-12).all():
        r = int(np.argmax(col))                  # 找系数为1的行
        x[j] = T[r, -1]                           # 该行右端即变量值
Z = T[-1, -1]

print(f"转轴 {steps} 次后收敛")
print(f"最优解: x1 = {x[0]:.2f}, x2 = {x[1]:.2f}")
print(f"最优值 Z = {Z:.2f}  (解析答案: x1=2, x2=2, Z=10)")
```

输出：

```
转轴 2 次后收敛
最优解: x1 = 2.00, x2 = 2.00
最优值 Z = 10.00  (解析答案: x1=2, x2=2, Z=10)
```

**两步转轴，从 (0,0) 跳到 (3,0) 再跳到 (2,2)——和主线的手工推导完全一致。** 这张 3×5 的表格，就是丹齐格那本"账本"的最小版本。

## 层二：分步逐函数拆解

### 步骤 1-2：标准形式 + 构造单纯形表

```python
c = np.array([3.0, 2.0])
A = np.array([[1.0, 1.0], [2.0, 1.0]])
b = np.array([4.0, 6.0])
m, n = A.shape
T = np.zeros((m + 1, n + m + 1))
T[:m, :n] = A
T[:m, n:n+m] = np.eye(m)
T[:m, -1] = b
T[-1, :n] = -c
```

**操作**：把 LP 装进一张表格。`T` 形状 `(3, 5)`：前 2 行是两条约束（加松弛变量后变成等式），第 3 行是目标行。列布局：`[x1, x2, s1, s2 | RHS]`。
- `T[:m, :n] = A`：把原约束系数放进前两列。
- `T[:m, n:n+m] = np.eye(m)`：**松弛变量的系数是单位阵**——每条约束自己的松弛变量系数为 1，别的为 0（$x_1+x_2+s_1 = 4$，$2x_1+x_2+s_2 = 6$）。
- `T[:m, -1] = b`：右端 4、6。
- `T[-1, :n] = -c`：目标行存 $-c$（$-3,-2$），因为"目标行 $\ge 0$"是终止判据——这是记号约定。

**输入**：`c, A, b`。**输出**：初始单纯形表 `T`。
**可调参数**：换 `c/A/b` 就换了一个 LP——**算法骨架一字不改**。加一条约束就多一行、一个松弛列。

**对应数学**：主线的标准形式 $\max c^Tx$ s.t. $Ax \le b, x\ge 0$ 及其松弛变量版本。

---

### 步骤 3：转轴函数——高斯消元

```python
def pivot(T, r, e):
    T[r] = T[r] / T[r, e]
    for i in range(T.shape[0]):
        if i != r and abs(T[i, e]) > 1e-12:
            T[i] = T[i] - T[i, e] * T[r]
```

#### `pivot` —— 一次转轴

**操作**：两步高斯消元。先 `T[r] = T[r] / T[r, e]` 把主元行 $r$ 的第 $e$ 列归一成 1；再对每一行 $i \ne r$，用 `T[i] = T[i] - T[i,e] * T[r]` 把第 $e$ 列的其他元素消成 0。`1e-12` 容差跳过"几乎为零"的元素（避免除零/数值噪声）。
**输入**：`T`（表格）、`r`（主元行/出基变量所在行）、`e`（主元列/入基变量所在列）。**输出**：就地更新 `T`——入基变量的列变成单位向量，表格被"重新表达"成新顶点的坐标系。
**可调参数**：无直接参数。**数值细节**：这就是 Ch02 的高斯消元——线性代数的工具在这里直接驱动优化算法。

**对应数学**：主线的"转轴 (pivot)"——换入一个基本变量、换出一个基本变量，顶点沿棱移动。

---

### 步骤 4：主循环——三个动作

```python
while True:
    e = int(np.argmin(T[-1, :n+m]))
    if T[-1, e] >= -1e-12:
        break
    ratios = []
    for r in range(m):
        ratios.append(T[r, -1] / T[r, e] if T[r, e] > 1e-12 else np.inf)
    r = int(np.argmin(ratios))
    pivot(T, r, e)
    steps += 1
```

#### `np.argmin(T[-1, :n+m])` —— 选入基变量

**操作**：找目标行前 4 列（所有变量）里**最负**的元素下标。最大化问题里，约化成本最负的变量入基（增大它最划算）。`np.argmin` 返回下标；若最小值 $\ge -1e-12$（不再有负系数），说明无法再改善 → `break` 终止。
**输入**：目标行 `T[-1]`。**输出**：整数 `e`（入基变量列号）。
**可调参数**：无。**注意**：这里没有实现 Bland 法则（若有并列负系数，`np.argmin` 天然取最小下标——恰好近似 Bland 的行为，能避开大多数循环）。遇到退化问题时，可显式加"取最小下标"纪律。

#### 最小比值检验 + `np.argmin(ratios)` —— 选出基变量

**操作**：对每条约束 $r$，若该行入基变量系数 `T[r,e] > 0`，计算 $\frac{T[r,-1]}{T[r,e]}$（该约束能容忍入基变量增大到多少）；系数 $\le 0$ 的约束记 `np.inf`（不限制）。**取比值最小者**为出基行——它最先"撞墙"，保证新点仍在可行域内。这正是农场例子里"土地说 4、水源说 3，取 3"的机器版。
**输入**：`T` 的约束行。**输出**：整数 `r`（出基行号）。

#### `pivot(T, r, e)` —— 执行转轴

**操作**：用上面的 `pivot` 完成换基底。循环直到 `break`。

**对应数学**：主线的动作一/二/三——入基、最小比值检验、转轴。

---

### 步骤 5：提取最优解

```python
x = np.zeros(n)
for j in range(n):
    col = T[:m, j]
    if abs(col.sum() - 1) < 1e-9 and (col >= -1e-12).all():
        r = int(np.argmax(col))
        x[j] = T[r, -1]
Z = T[-1, -1]
```

**操作**：最优顶点处，**基本变量**对应单位向量列（该列在约束行恰有一个 1、其余 0）。对每个原始变量 $x_j$，检查它在约束行的列 `col` 是否"单位向量"（和接近 1 且非负）——若是，它的值等于那个 1 所在行的右端。非基本变量值为 0。
**输入**：收敛后的 `T`。**输出**：`x`（长度 2 的最优解向量）、`Z`（最优值）。
**可调参数**：无。**注意**：`Z = T[-1, -1]` 直接读目标行右下角——单纯形表把最优值"结算"在右下角，这是表格记账的经典收尾。

## 实验台：让单纯形表现原形

1. **换问题**：把 `c` 改成 `[2.0, 5.0]`（更偏爱 $x_2$），最优解变到哪？（解析：$(0,4)$，$Z=20$）——算法两次转轴后给出同一答案。
2. **加约束**：加一行 `[1.0, 0.0]`、右端 `3.0`（$x_1 \le 3$），最优解被削到哪？——**亲手看到"多一条约束，世界小一圈"**（§5.2 的哲学）。
3. **退化与循环**：构造 $x_1+x_2\le 1$、$2x_1+2x_2\le 2$ 这类退化问题，观察 `steps` 是否暴增——体会 Bland 法则存在的理由。
4. **对照 scipy**：`scipy.optimize.linprog` 解同一问题，结果应一致。黑盒库只作裁判。

**对应数学**：这些实验都在验证主线的一句话——**单纯形法只沿着"变好"的边跳，不枚举所有顶点**；而 `steps` 次数的增长方式，就是"顶点跳跃效率"的直接度量。
