# Ch07 §7.2.4 加权图 · 代码.md

主线讲了加权图的核心：边带权重、加权邻接矩阵、"最短"= 权重和最小。本文件用三座城市的交通网（教材例子：A–B 200km、A–C 150km、B–C 300km）把这些实现成 numpy + 纯 Python：加权邻接矩阵、加权度、然后手写一个**Dijkstra 最短路径算法**——不调 `networkx.shortest_path` 黑盒，把"贪心逐块确认"的每一步摊开。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy
import heapq                                           # ② 堆：Dijkstra 的优先队列

cities = ["A", "B", "C"]                               # ③ 三座城市
roads = [("A", "B", 200.0), ("A", "C", 150.0), ("B", "C", 300.0)]

def weighted_adjacency(nodes, edges):                  # ④ 加权邻接矩阵
    idx = {n: i for i, n in enumerate(nodes)}
    W = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v, w in edges:
        i, j = idx[u], idx[v]
        W[i, j] = w
        W[j, i] = w                                    # 无向：对称
    return W

def dijkstra(W, start):                                # ⑤ 最短路径：贪心逐块确认
    n = W.shape[0]
    dist = np.full(n, np.inf)
    dist[start] = 0.0
    pq = [(0.0, start)]
    while pq:
        d, v = heapq.heappop(pq)
        if d > dist[v]:
            continue                                    # 过期的旧条目，跳过
        for u in range(n):
            if W[v, u] == 0.0:
                continue                                # 无边
            nd = d + W[v, u]
            if nd < dist[u]:
                dist[u] = nd
                heapq.heappush(pq, (nd, u))
    return dist

W = weighted_adjacency(cities, roads)                  # ⑥ 主流程
print("加权邻接矩阵（公里）：\n", W)
print("加权度（城市总吞吐/连接总里程）:", dict(zip(cities, W.sum(axis=1))))
print("从 A 出发的最短距离:", dict(zip(cities, dijkstra(W, 0))))
```

输出：

```
加权邻接矩阵（公里）：
 [[  0. 200. 150.]
  [200.   0. 300.]
  [150. 300.   0.]]
加权度（城市总吞吐/连接总里程）: {'A': 350.0, 'B': 500.0, 'C': 450.0}
从 A 出发的最短距离: {'A': 0.0, 'B': 200.0, 'C': 150.0}
```

三个数字读起来很舒服：A 到 B 直接 200（A→B 直达比 A→C→B 的 150+300=450 短，所以是 200），A 到 C 直接 150。加权度给出每座城市"连接的总里程"——B 虽然只有两条路，但它的路总长 500，超过 A 的三条路里能比的 350？不——A 只有两条路（200+150=350），B 也有两条路（200+300=500），C 两条（150+300=450）。这张图每座城市恰好连两条路，加权度 = 两路之和。注意这里加权度的语义是"总连接里程"，若是流量问题它就是你设的"吞吐量"——量纲随你的 $w$ 定义而定。

## 层二：分步逐函数拆解

### 步骤 1：定义加权邻接矩阵

```python
def weighted_adjacency(nodes, edges):
    idx = {n: i for i, n in enumerate(nodes)}
    W = np.zeros((len(nodes), len(nodes)), dtype=float)
    for u, v, w in edges:
        i, j = idx[u], idx[v]
        W[i, j] = w
        W[j, i] = w
    return W
```

#### weighted_adjacency —— 边带权重

`W[i, j] = w` 与 `W[j, i] = w`

**操作**：和 §7.2.3 的 `adjacency` 几乎一样，只是把写 1 改成写权重 `w`，且边的数据现在是三元组 `(u, v, w)`。无向则对称写两处。

**输入**：`nodes`（list of str）、`edges`（list of (str, str, float)），第三项是权重。

**输出**：`np.ndarray`，形状 `(n, n)`，`dtype=float`。有边处放权重，无边处是 **0.0**。

**可调参数**：
- 想让方向（§7.2.2）也生效，删掉 `W[j, i] = w`——`(u,v,w)` 表示"u 到 v 的权重 w"，反向可以没有或不同。
- **危险区**：这里约定"无边 = 0"。如果你的问题里存在"权重恰好为 0 的边"（免费通道），这个约定会把它和无边混淆——那时应改用 `np.inf` 表示无边（因为 $\infty$ 不可能是合法权重），或另存边列表。这是主线边界声明里"0 的两重含义"的工程版本。

**对应数学**：§7.2.4 的权重函数 $w: E \to \mathbb{R}$——`w` 就是 $w(e)$，矩阵是它的表格化。

### 步骤 2：定义 Dijkstra 最短路径

```python
def dijkstra(W, start):
    n = W.shape[0]
    dist = np.full(n, np.inf)
    dist[start] = 0.0
    pq = [(0.0, start)]
    while pq:
        d, v = heapq.heappop(pq)
        if d > dist[v]:
            continue
        for u in range(n):
            if W[v, u] == 0.0:
                continue
            nd = d + W[v, u]
            if nd < dist[u]:
                dist[u] = nd
                heapq.heappush(pq, (nd, u))
    return dist
```

#### dijkstra —— 贪心逐块确认最短距离

`pq = [(0.0, start)]` 与 `nd = d + W[v, u]`

**操作**：用优先队列（小根堆）维护"待确认的候选距离"。初始化 `dist[start]=0`，其余无穷。循环：
1. 弹出堆顶——当前已知距离最小的节点 `v`（贪心：它一定是已确认最短的）；
2. 若弹出的距离 `d` 大于 `dist[v]`，说明是过期旧条目，跳过；
3. 对 `v` 的每条出边 `(v,u)`，计算"经 v 到 u"的候选距离 `nd = d + W[v,u]`；若它比当前 `dist[u]` 更小，更新并压入堆。

**输入**：`W`：`(n, n)` 非负加权邻接矩阵；`start`：int，起点下标。

**输出**：`np.ndarray`，形状 `(n,)`——`dist[i]` 是从 `start` 到节点 i 的**最短加权路径长度**（权重和）。不可达的节点保持 `np.inf`。

**可调参数**：
- 若权重含负数，Dijkstra 失效（贪心前提被破坏），要换 Bellman-Ford——**这是本算法的边界声明**：非负权是 Dijkstra 的前提。
- `heapq.heappop` 弹出的是"距离最小"的候选，这是"贪心"的机器实现；`if d > dist[v]: continue` 一行是跳过重复入堆的旧记录，去掉它程序仍对、只是更慢。
- 想同时得到路径（而非只有距离），额外记录每个节点的"前驱"，结束时回溯即可。

**对应数学**：主线第三节的最短路径问题与"最短=权重和最小"。`nd = d + W[v,u]` 里的 `+` 正是"路径长度 = 边权和"的编码——跳数最少的 A→B→C（2 跳）在这里不是最短路，因为 450 > 150。

### 步骤 3：主流程

```python
W = weighted_adjacency(cities, roads)
print("加权邻接矩阵（公里）：\n", W)
print("加权度:", dict(zip(cities, W.sum(axis=1))))
print("从 A 出发的最短距离:", dict(zip(cities, dijkstra(W, 0))))
```

#### 主流程 —— 读数与对照

**操作**：`W.sum(axis=1)` 算加权度（每行权重和）；`dijkstra(W, 0)` 算最短路。

**输入**：矩阵。

**输出**：矩阵、加权度字典、最短距离字典。

**可调参数**：`dijkstra(W, 0)` 的起点换成 1（B）、2（C）可看其他出发点的最短路。`dict(zip(cities, ...))` 仍是"表示层"的人名映射。

**对应数学**：加权度 $\sum_{u\in\mathcal{N}(v)} w(v,u)$ 与最短路。对照：A→C 直接 150，A→B 直接 200（绕 C 是 450，更长）——Dijkstra 正确地没有给出绕行方案。

## 改个数字试试

### 实验 A：把"短"从跳数改成权重，结论翻转

若三条路的权重改成 A–B=100、A–C=400、B–C=100（把"近路"换成"远路"），重跑。你会看到：从 A 到 C 的最短路不再是直达 400，而是 A→B→C 的 200（100+100）——**跳数 2 的路，权重和反而更小**。这正是主线强调的：无权图说"直达最近"，加权图说"权重和最小才最近"。Dijkstra 在两个世界里的答案可以完全不同。

### 实验 B：权重自动学习的预告

把注意力矩阵当权重，把"聚合"当加权求和：

```python
h = np.array([1.0, 2.0, 3.0])              # 三个 token 的特征
attn = np.array([0.1, 0.3, 0.6])           # 对三个来源的关注强度（softmax 后）
agg = (attn * h).sum()                     # 加权聚合
print("加权聚合结果 =", agg)                # 0.1*1 + 0.3*2 + 0.6*3 = 2.5
```

输出：

```
加权聚合结果 = 2.5
```

`attn` 就是一张"一行三列的加权邻接矩阵"，`(attn * h).sum()` 就是消息传递的加权求和——权重大的 token 贡献更多。在 Transformer/GAT 里，`attn` 不是给定的，是 `softmax(QKᵀ)` 从数据里学出来的。**这条 `(attn * h).sum()` 就是加权图走进深度学习的最小原型**，也是 §7.3 消息传递公式的种子。

**呼应主线**：加权图不是"多了个数字"那么简单——它让"最短/最省/最强"成为可优化的问题，也让"聚合强度"成为可学习的对象。Dijkstra 时代权重是印死的公里数，深度学习时代权重是长出来的注意力——同一张加权图，两种时代。
