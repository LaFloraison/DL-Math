# §7.2.4 加权图 —— 习题

主线讲了加权图的三个要点：边挂权重、加权邻接矩阵、"最短"= 权重和最小（Dijkstra）。下面三组习题检验你能否从"连不连"升级到"多贵多强"。每题附解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：无权图和加权图的本质区别是什么？

- A. 加权图节点更多
- B. 加权图能表达"关系的强度"，无权图只能表达"关系存在与否"
- C. 加权图一定有方向
- D. 无权图不能做最短路径

**解答**：B。

**思路点拨**：区别在**信息等级**：无权图回答"连不连"（定性），加权图回答"多强/多长/多贵"（定量）。C 错——加权图可以无向（教材例子的道路就是无向加权）。D 错——无权图也能做最短路径，只是"最短"指跳数最少。常见错选 D，混淆了"有权最短"与"无权最短"。

### 题 2（判断）：加权图里，"跳数最少的路径"一定是最短路径吗？

**解答**：不一定。最短路径（权重和最小）与最少跳数（边数最少）是**两个不同的目标**。当所有边权重相等时二者重合；否则一条绕远但轻量的路可能权重和更小。例：A→C 直达权重 400，A→B→C 两跳但权重各 100——跳数多的路，反而最"短"。

**思路点拨**：这是本节的灵魂判断题。答题要点是"两个目标，两套最优"。最常见错误是默认"少跳 = 近"。记忆锚点：**有权最短路看权重和，无权最短路看跳数。** 建模时必须先声明你的"代价"是什么。

### 题 3（简答）：加权邻接矩阵里，"0"可能有哪些含义？建模时要注意什么？

**解答**：两种含义：**没有边**，或**边权重恰好为 0**（如免费通道、零成本连接）。建模时必须明确约定，否则代码会混淆——Dijkstra 把 `W[v,u]==0` 当"无边"跳过，一条权重真为 0 的边就会被误杀。解决：用 `np.inf` 表示无边（∞ 不可能是合法权重），0 专给"零权重边"。

**思路点拨**：这是"0 的两重语义"陷阱。答题时给出**工程解法**（`inf` 表无边）就拿到了满分——它让 Dijkstra 的 `W[v,u]==0` 判据天然变成"跳过无边、保留零权边"。常见错误是只指出歧义、不给方案。

## 二、计算实践

### 题 1（手算 + NumPy：四城路网）

四座城市 A、B、C、D。道路及里程：A–B=100、A–C=200、B–C=50、B–D=150、C–D=80。

(a) 写加权邻接矩阵。
(b) 从 A 到 D 的最短路径是什么？总里程多少？
(c) 从 A 出发到各城的加权距离。

**解答**：

(a)
$$\begin{pmatrix} 0&100&200&0 \\ 100&0&50&150 \\ 200&50&0&80 \\ 0&150&80&0 \end{pmatrix}$$

(b) 枚举：A→B→D = 250；A→B→C→D = 100+50+80 = 230；A→C→D = 200+80 = 280；A→C→B→D = 200+50+150 = 400。最短是 **A→B→C→D = 230**。

(c) A→A=0，A→B=100，A→C=150（经 B 或直连 200 中取小），A→D=230（经 B→C→D）。

**NumPy 验证（Dijkstra）**：
```python
import numpy as np, heapq
W = np.array([[0,100,200,0],[100,0,50,150],[200,50,0,80],[0,150,80,0]], dtype=float)
def dijkstra(W, s):
    n=W.shape[0]; dist=np.full(n,np.inf); dist[s]=0; pq=[(0,s)]
    while pq:
        d,v=heapq.heappop(pq)
        if d>dist[v]: continue
        for u in range(n):
            if W[v,u]==0: continue
            if d+W[v,u]<dist[u]: dist[u]=d+W[v,u]; heapq.heappush(pq,(dist[u],u))
    return dist
print("A→各城最短距离:", dict(zip("ABCD", dijkstra(W,0))))
```
```
A→各城最短距离: {'A': 0.0, 'B': 100.0, 'C': 150.0, 'D': 230.0}
```

**思路点拨**：(b) 的技巧是**别只枚举直达**——最短路可能绕路。A→D 直达不存在（矩阵 0），必须绕；而绕行里 A→B→C→D 最短，因为它借了 B–C=50 这条"便宜"的边。常见错误：漏掉多跳候选，或把无权图的"少跳优先"直觉搬过来。Dijkstra 的核心理念"先确认近的，再用近的刷新远的"在这里完全体现。

### 题 2（手算：加权度的意义）

沿用题 1，算每座城市的加权度（连接总里程）。A 的加权度比 C 大还是小？这说明什么？

**解答**：$A{:}100{+}200=300$，$B{:}100{+}50{+}150=300$，$C{:}200{+}50{+}80=330$，$D{:}150{+}80=230$。C 的加权度最大。若把权重当"吞吐量"，C 是这张路网里"承载量最大"的枢纽；若当"总里程"，C 是连接成本最重的城市。**加权度 = 节点承载的总权重**，它的语义完全取决于你给 $w$ 定的量纲。

**思路点拨**：对比无权度：这里每个节点度都不同吗？其实 B、C 度 3，A、D 度 2——加权度（300/330/230）和无权度（3/2）给出了**不同的排序**。这就是"关系强度 vs 关系个数"的分野：一个节点连接的边少，可能每条都很重；连接的边多，可能每条都很轻。加权度把"强度"这个维度加进了重要性评估。

## 三、DL 延伸

### 题 1（场景设计）：分子图加权重

一个分子建模任务，把原子当节点、化学键当边。有人提出给每条边加权：键长（Å）或键级（单键 1.0、双键 2.0）。请说明这个权重对 GNN 预测分子性质有什么具体好处，并举一个"无权会出错"的例子。

**解答**：权重让 GNN 聚合时区分"强键"与"弱键"：聚合公式里 $h_v = \sigma(W\sum_u w_{vu} h_u)$，键级高的邻居贡献更大。例如 C=O 双键（权重 2.0）与 C–C 单键（1.0），在预测分子光谱或反应性时，双键原子对中心的电子环境影响显著更大——无权图会把两者等权相加，丢失关键差异。此外键长权重能区分"化学上接近但键数相同"的同分异构差异。

**思路点拨**：答题锚点是"**权重 = 强度调制聚合**"。加分点是同时说到"原子类型（节点特征）与键强度（边权重）是两个独立通道，应分别编码"。常见错误是只说"能表达更多信息"，没落到聚合公式的 $w_{vu}$ 上。

### 题 2（概念连线）：注意力权重为什么是"可学习的权重函数"？

§7.2.2 说注意力矩阵是有向加权图；本节说权重函数 $w:E\to\mathbb{R}$ 是"给每条边定价"。请问：Transformer 里"给边定价"的钱从哪里来？它与 Dijkstra 时代的权重有什么不同？

**解答**：Dijkstra 时代的权重是**给定的**（地图印死的公里数，$w$ 是常数）；Transformer 的权重 $A_{ij} = \mathrm{softmax}(q_i^\top k_j / \sqrt{d_k})$ 是**从数据里学出来的**——"价格"由 query 与 key 的内积决定，模型训练时反向传播会调整 q、k，从而调整每条边的权重。所以 Transformer 是"权重函数参数化 + 可训练"的加权图：$w$ 不再是常数，而是一个可微的、随输入变化的函数。

**思路点拨**：这道题是"加权图"到"深度学习"的最后一块拼图。核心对照：**常数权重 → 学习权重**。加分点：softmax 保证每行权重非负且和为 1（归一化），这恰好是"每行是一张合法概率分布"的加权邻接——与 §4.2 的分布思想一脉相承。常见错误是停留在"注意力是图"的比喻，没指出"权重可学习"这个划时代的差异。
