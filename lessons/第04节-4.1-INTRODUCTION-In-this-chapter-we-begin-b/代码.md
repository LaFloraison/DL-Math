# §4.1 概率论导论 · 代码

主线里，我们看见蒙眼射手在靶墙上钉出那团箭。这节代码，就是把那团箭——随机性的图案——请进 Python。

我们将从最离散、最简单的随机实验出发：**掷骰子**。完整走一条链：模拟随机采样 → 统计经验频率 → 对比理论概率 → 可视化 → 最后用大数定律确认"样本越多，经验频率越贴近理论概率"。

需要的环境：Python 3.8+ 与 `matplotlib`（绘图用，可以 `pip install matplotlib` 安装）。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方（`SEED = 42` 固定，所以你的结果与这里**逐位一致**）。

```python
"""
§4.1 概率论导论 · 代码.md
从最离散的随机实验——掷骰子——出发，走完一条完整的路：
模拟随机采样 -> 计算经验频率 -> 对比理论概率 -> 可视化。

运行：python 代码.py    （绘图依赖 matplotlib）
"""

import random            # 标准库：伪随机数生成器（Mersenne Twister 算法）
import matplotlib.pyplot as plt

N_FACES = 6              # 骰子面数：样本空间 Omega = {1,2,3,4,5,6}
N_ROLLS = 1000           # 掷多少次骰子（采样量 N）
SEED = 42                # 随机种子：让"随机"实验可以精确复现


def roll_once(rng):
    """掷一次骰子：把一个均匀随机数映射到 1..6 的某一个面。"""
    u = rng.random()             # u ~ U[0,1)：抽一个 [0,1) 上的均匀随机数
    return int(u * N_FACES) + 1  # k = floor(6u) + 1 ∈ {1,...,6}


def simulate_rolls(n_rolls, seed=SEED):
    """独立地掷 n_rolls 次骰子，返回一个长度为 n_rolls 的结果列表。"""
    rng = random.Random(seed)    # 用固定种子初始化发生器，结果可复现
    return [roll_once(rng) for _ in range(n_rolls)]


def empirical_frequencies(rolls, n_faces=N_FACES):
    """把结果列表统计成每个面的经验频率 Phat(k) = 出现次数 / 总次数。"""
    counts = [0] * n_faces       # 6 个计数槽，下标 0..5 对应面 1..6
    for face in rolls:
        counts[face - 1] += 1    # 面 k 落在槽 k-1
    total = len(rolls)
    return [c / total for c in counts]


def theoretical_pmf(n_faces=N_FACES):
    """理论概率质量函数：公平骰子每个面 p(k) = 1/6，均匀离散分布。"""
    return [1.0 / n_faces] * n_faces


def plot_distribution(empirical, theoretical, labels=None):
    """并排对比经验频率（柱状）与理论概率（折线），观察两者是否靠拢。"""
    x = list(range(1, len(empirical) + 1))
    plt.bar(x, empirical, width=0.5, color="steelblue", alpha=0.8,
            label="经验频率 Phat(k)")
    plt.plot(x, theoretical, "ro-", label="理论概率 p(k) = 1/6")
    plt.xlabel("骰子面数 k")
    plt.ylabel("频率 / 概率")
    plt.xticks(x, labels)
    plt.ylim(0, 0.5)
    plt.legend()
    plt.grid(axis="y", linestyle="--", alpha=0.3)
    plt.title("经验频率 vs 理论概率（N = %d 次掷骰）" % N_ROLLS)
    plt.show()


# ---------------- 主流程 ----------------
rolls = simulate_rolls(N_ROLLS)              # 1. 模拟采样
emp = empirical_frequencies(rolls)           # 2. 经验频率
th = theoretical_pmf()                       # 3. 理论概率

print("掷了 %d 次骰子，前 20 次结果为：" % N_ROLLS)
print("  ", rolls[:20])
print("经验频率 Phat(k) =", [round(f, 4) for f in emp])
print("理论概率 p(k)    =", [round(p, 4) for p in th])
plot_distribution(emp, th, labels=["1", "2", "3", "4", "5", "6"])

# 大数定律：样本量越大，经验频率越贴近理论概率（主线中「箭墙成形」）
print("\n大数定律（观察面 6 的经验概率随样本量收敛）：")
for n in (10, 100, 1000, 10000, 100000):
    r = simulate_rolls(n)
    f6 = sum(1 for v in r if v == 6) / n
    print("  N = %6d 次 -> Phat(6) = %.4f   (理论值 1/6 = 0.1667)" % (n, f6))
```

运行输出（`SEED=42`，结果完全可复现）：

## 层二：分步逐函数拆解

### 步骤 1：设置实验参数与随机源

```python
import random            # 标准库：伪随机数生成器（Mersenne Twister 算法）
import matplotlib.pyplot as plt

N_FACES = 6              # 骰子面数：样本空间 Omega = {1,2,3,4,5,6}
N_ROLLS = 1000           # 掷多少次骰子（采样量 N）
SEED = 42                # 随机种子：让"随机"实验可以精确复现
```

这一块没有函数，它是**实验的参数表**——对应主线里"样本空间 $\Omega$"和"采样量"的具身。

`import random` 引入 Python 标准库的伪随机数生成器。`import matplotlib.pyplot as plt` 引入绘图工具。

三个模块级常量：

- `N_FACES = 6` —— 骰子面数。这正是主线里的**样本空间** $\Omega = \{1,2,3,4,5,6\}$。改成 8，整台机器就变成八面骰；改成 2，就是抛硬币。**注意**：它同时被 `roll_once`、`empirical_frequencies`、`theoretical_pmf` 三个函数读取——改一个常量，全链路跟着变，这就是"样本空间决定分布的形状"。
- `N_ROLLS = 1000` —— 采样量 $N$。主线里"让他射一整天"的箭数。改成 10 会看到频率乱跳，改成 100000 会看到频率逼近理论值——这正是步骤 7 大数定律要演示的。
- `SEED = 42` —— 随机种子。伪随机不是真随机：它是一条确定性递归，种子决定这条递归从哪个状态起步。固定种子 = 每次运行得到**逐位相同**的结果。改种子（如 `SEED = 7`），骰子序列整个换一套，但统计形状不变。

**可调参数**：三个常量都可以改。它们是"实验的旋钮"——`N_FACES` 换骰子，`N_ROLLS` 换样本量，`SEED` 换随机流的起点。还能不能有第四个？当然可以：比如再加一个 `LABELS` 常量，把面值从数字换成文字（"红""黑"）。但这里为了简单，只留了三个。

### 步骤 2：掷一次骰子 —— `roll_once(rng)`

```python
def roll_once(rng):
    u = rng.random()             # u ~ U[0,1)：抽一个 [0,1) 上的均匀随机数
    return int(u * N_FACES) + 1  # k = floor(6u) + 1 ∈ {1,...,6}
```

#### `roll_once(rng)` —— 把一个均匀随机数翻译成一个骰子面

`u = rng.random()`

**操作**：`rng.random()` 调用 Mersenne Twister 算法生成一个 $[0,1)$ 上的浮点数 $u$。所谓"随机数"，实质是一个确定性递归产生的、统计上均匀分布于 $[0,1)$ 的数——它不是宇宙的噪声，而是算法的出口。这就是主线里**随机变量**的雏形：一次实验的真实结果我们不知道，但抽样机制告诉我们每个值的可能比例。

然后做两次纯数学变换，把一个连续数压成离散的面：

1. **`u * N_FACES`** —— 把 $u \in [0,1)$ 放大到 $[0, 6)$。
2. **`int(...)`** —— 截断取整（对非负数等价于 $\lfloor \cdot \rfloor$），把 $[0,6)$ 切成六段 $[0,1), [1,2), \dots, [5,6)$，得到 $0,1,2,3,4,5$。
3. **`+ 1`** —— 平移，得到 $\{1,2,3,4,5,6\}$。

合起来：$k = \lfloor 6u \rfloor + 1$。

**对应数学**：这正是主线"随机变量：把结果翻译成数字"的实现，也是离散分布 PMF 的几何来源。均匀的 $u$ 落在六段等长区间 $[0,\tfrac16), [\tfrac16,\tfrac26), \dots$ 的概率各为 $1/6$，所以每个面 $p(k) = 1/6$。区间**等长**是关键——如果区间不等长，面就不是等概率的了（见下方可调参数的陷阱）。

**输入**：`rng` —— 一个 `random.Random` 实例（一个对象，没有形状概念）。它必须拥有 `.random()` 方法。

**输出**：一个整数 $k \in \{1, 2, 3, 4, 5, 6\}$（标量）。每个输出值是"随机变量 $X$ 的一次实现 (realization)"。

**可调参数**：
- `rng`：唯一的显式参数。传入不同种子初始化出的 `rng`，掷出不同的序列；传入同一个 `rng` 则序列逐位一致。
- 隐式参数 `N_FACES`：模块级常量。改成 8，就变成 $k = \lfloor 8u \rfloor + 1$，输出 $\{1,\dots,8\}$，每面概率 $1/8$。
- 还能不能有第三个参数？可以——把面数显式传进来更好：`def roll_once(rng, n_faces)`。这样 `roll_once` 就不依赖全局常量了。但那样 `int(u * n_faces) + 1` 的写法不变。
- **陷阱**：如果把 `int()`（截断）换成 `round()`（四舍五入），会怎样？`round(6u)` 会把区间切成 $[0, 0.5) \to 0$、$[0.5, 1.5) \to 1$……首尾区间只有别的区间一半宽。于是面 1 和面 6 的概率变成 $1/12$，中间的面变成 $1/6$——骰子被悄悄做成了灌铅的。**均匀映射的第一原则：区间必须等长。**

### 步骤 3：掷 N 次 —— `simulate_rolls(n_rolls, seed)`

```python
def simulate_rolls(n_rolls, seed=SEED):
    rng = random.Random(seed)    # 用固定种子初始化发生器，结果可复现
    return [roll_once(rng) for _ in range(n_rolls)]
```

#### `simulate_rolls(n_rolls, seed)` —— 独立地掷一长串骰子

**操作**：先用种子初始化一个发生器 `rng`，再通过列表推导式把 `roll_once(rng)` 调用 `n_rolls` 次，收集结果。每一次调用 `rng.random()`，Mersenne Twister 的内部状态就前进一步——**下一次的 $u$ 与上一次无关**。这就是统计学里最珍贵的性质：**独立性 (independence)**。上一次掷出 6，不影响这一次掷出什么。

**对应数学**：独立同分布采样 (i.i.d. sampling)。$X_1, X_2, \dots, X_N$ 是 $N$ 个独立、且都服从同一个均匀离散分布的随机变量。这一串结果，就是主线里"射一整天"得到的那几千支箭——**一个样本 (sample)**。

**输入**：
- `n_rolls`：整数，掷骰次数（采样量 $N$）。
- `seed`：整数（可省略，默认 `SEED = 42`），随机种子。

**输出**：一个整数列表，**形状 `(n_rolls,)`** ——一维数组，长度 $N$，第 $i$ 个元素是第 $i$ 次掷骰的面值。

**可调参数**：
- `n_rolls`：取值范围为任意非负整数。给 0 返回空列表；给 10 得到 10 个结果，经验频率会与 $1/6$ 偏差很大；给 100000 会非常贴近 $1/6$。
- `seed`：保持默认 42 → 结果可复现；改成任意整数 → 换一套序列；传 `None` → Python 用系统熵（时间戳等）自动播种，每次运行结果都不同——适合"真随机感"的演示，但没法复现实验结果。
- 还能不能有第三个参数？可以。比如加一个 `transform=None` 参数，传入一个自定义函数来替换 `roll_once` 的面值映射逻辑，从而模拟**不公平骰子**（如面 6 概率 $1/3$）。但公平骰子不需要它。

### 步骤 4：统计经验频率 —— `empirical_frequencies(rolls, n_faces)`

```python
def empirical_frequencies(rolls, n_faces=N_FACES):
    counts = [0] * n_faces       # 6 个计数槽，下标 0..5 对应面 1..6
    for face in rolls:
        counts[face - 1] += 1    # 面 k 落在槽 k-1
    total = len(rolls)
    return [c / total for c in counts]
```

#### `empirical_frequencies(rolls, n_faces)` —— 数每张脸出现多少次，再归一化

**操作**：
1. `counts = [0] * n_faces` —— 造一个长度 6 的计数数组，下标 0..5 对应面 1..6。
2. `for face in rolls: counts[face - 1] += 1` —— 遍历每一个结果。面值 $k$ 落在下标 $k-1$（因为数组下标从 0 开始）。这一步是**纯计数**：面 1 出现几次、面 2 出现几次……
3. `total = len(rolls)` —— 总次数 $N$。
4. `[c / total for c in counts]` —— 每个计数除以 $N$，得到频率。

**对应数学**：这就是主线里"可能性的频率解释"的代码形式：

$$\hat{p}(k) = \frac{\text{面 } k \text{ 出现的次数}}{N} = \frac{N_k}{N}$$

$\hat{p}(k)$（读作 p-hat）是**经验频率 (empirical frequency)**，也叫经验概率。它是我们从有限样本里"看到"的概率——对应主线边界声明里那句"你看到的是它的影子（频率），而不是真正的 $p(k)$"。注意：$\hat{p}(k)$ 是随机量（换一批样本就变），而 $p(k) = 1/6$ 是确定的理论值。

**输入**：
- `rolls`：整数列表，**形状 `(N,)`**——步骤 3 的输出。每个元素是 $\{1,\dots,6\}$ 中的一个面值。
- `n_faces`：整数（可省略，默认 6），骰子面数。

**输出**：浮点数列表，**形状 `(n_faces,)`**。第 $k-1$ 个元素是面 $k$ 的经验频率。每个值都在 $[0,1]$ 内；**六个值之和恒为 1**（浮点误差内）——因为每个结果恰好属于一个面，这正是 Kolmogorov 公理三（互斥事件可加）与公理二（全样本空间为 1）在数据上的回响。

**可调参数**：
- `n_faces`：若你在步骤 2 把骰子换成了 8 面，这里也必须传 `n_faces=8`，否则计数数组还是 6 格，面 7、面 8 会被下标越界访问——更脆弱的是恰好不会报错却漏数。**参数一致性是这类代码最常见的 bug 来源。**
- 还能不能有第三个参数？可以加一个 `normalize=True` 开关：传 `False` 就只返回原始计数 `counts` 而不除以总数。当你想同时看"次数"和"频率"时有用。

### 步骤 5：理论概率 —— `theoretical_pmf(n_faces)`

```python
def theoretical_pmf(n_faces=N_FACES):
    return [1.0 / n_faces] * n_faces
```

#### `theoretical_pmf(n_faces)` —— 写出公平骰子的理论分布

**操作**：用列表乘法 `[1.0/6] * 6` 生成六个相同元素：`[1/6, 1/6, 1/6, 1/6, 1/6, 1/6]`。注意 `1.0 / n_faces` 用了浮点数 `1.0`——保证整除语义，不会把 `1/6` 截断成整数 0。

**对应数学**：这就是主线里概率质量函数 (PMF) 的一个具体实例——**均匀离散分布**：

$$p(k) = \frac{1}{n}, \quad k \in \{1, 2, \dots, n\}$$

它满足 PMF 的两条纪律：$p(k) \ge 0$ 且 $\sum_{k=1}^{n} p(k) = 1$。它从何而来？不是靠掷骰测出来的，而是从"公平"这个**对称性假设**推出的：六个面没有任何一个该被偏爱，于是每个面分到同样的 $1/6$。这就是理论值 vs 经验值的分野——理论值来自假设与推导，经验值来自观察与计数。

**输入**：`n_faces` —— 整数（可省略，默认 6），面数。

**输出**：浮点数列表，**形状 `(n_faces,)`**，每个元素都是 `1.0 / n_faces`，和为 1。

**可调参数**：
- `n_faces`：传 8 得到 $p(k) = 1/8$ 的均匀分布；传 2 得到抛硬币分布 $p = 1/2$。
- 还能不能有第二个参数？可以加一个 `weights` 参数传入各面权重（如 `[1, 1, 1, 1, 1, 2]`），先归一化再返回——这就把公平骰子扩展成**任意离散分布**，即主线 §4.2 里"针对特定数据定制的分布"的一个极简预览。但公平骰子用不到。

### 步骤 6：可视化 —— `plot_distribution(empirical, theoretical, labels)`

```python
def plot_distribution(empirical, theoretical, labels=None):
    x = list(range(1, len(empirical) + 1))
    plt.bar(x, empirical, width=0.5, color="steelblue", alpha=0.8,
            label="经验频率 Phat(k)")
    plt.plot(x, theoretical, "ro-", label="理论概率 p(k) = 1/6")
    plt.xlabel("骰子面数 k")
    plt.ylabel("频率 / 概率")
    plt.xticks(x, labels)
    plt.ylim(0, 0.5)
    plt.legend()
    plt.grid(axis="y", linestyle="--", alpha=0.3)
    plt.title("经验频率 vs 理论概率（N = %d 次掷骰）" % N_ROLLS)
    plt.show()
```

#### `plot_distribution(empirical, theoretical, labels)` —— 把那团箭画在墙上

**操作**：
1. `x = list(range(1, len(empirical) + 1))` —— 横轴坐标：面 1 到面 6。
2. `plt.bar(...)` —— 画经验频率的**柱状图**：柱子的高度就是 $\hat{p}(k)$。
3. `plt.plot(x, theoretical, "ro-")` —— 在同样位置叠一条理论概率的**红色折线** $p(k) = 1/6$。
4. `plt.ylim(0, 0.5)` —— 把纵轴定在 $[0, 0.5]$，让 $1/6 \approx 0.167$ 恰好在中部，柱顶高低一目了然。
5. `plt.legend()` / `plt.grid()` / `plt.title()` —— 图例、网格、标题，纯排版。

**对应数学**：这一幅图，就是主线 Toy Model 里"退后十步看靶墙"的复刻。柱顶距离那条红色理论线越近，说明经验频率越接近理论概率——即"样本里看出的疏密图案"越接近"假设的图案"。当 $N$ 变大（改 `N_ROLLS`），柱子会越来越整齐地趴在红色线上。

**输入**：
- `empirical`：浮点数列表，**形状 `(n_faces,)`**——步骤 4 的输出。
- `theoretical`：浮点数列表，**形状 `(n_faces,)`**——步骤 5 的输出。
- `labels`：字符串列表，**形状 `(n_faces,)`**，可省略（默认 `None`）。控制横轴刻度显示的文字。

**输出**：没有返回值（返回 `None`）。它把图渲染到一个窗口（或在 Jupyter 里内嵌），然后 `plt.show()` 展示。

**可调参数**：
- `empirical` / `theoretical`：两个序列必须等长，否则 `plt.plot` 与 `plt.bar` 对不上横轴。
- `labels`：传 `None` 时横轴显示数字 1..6；传 `["一","二","三","四","五","六"]` 就换成中文。
- 函数体内还有一批**样式参数**可调：`width`（柱宽，默认 0.5）、`color`（柱色）、`alpha`（透明度）、`ylim`（纵轴范围）。这些不是函数的参数，而是写死在函数体里的——想暴露它们，可以把它们升级成函数参数。
- 还能不能有第四个参数？可以加一个 `save_path`：传入一个文件路径（如 `"dice.png"`），用 `plt.savefig(save_path)` 把图存成图片而不是弹窗口——在服务器/无图形环境里非常有用。

### 步骤 7：主流程 —— 采样、统计、对比，最后验证大数定律

```python
rolls = simulate_rolls(N_ROLLS)              # 1. 模拟采样
emp = empirical_frequencies(rolls)           # 2. 经验频率
th = theoretical_pmf()                       # 3. 理论概率

print("掷了 %d 次骰子，前 20 次结果为：" % N_ROLLS)
print("  ", rolls[:20])
print("经验频率 Phat(k) =", [round(f, 4) for f in emp])
print("理论概率 p(k)    =", [round(p, 4) for p in th])
plot_distribution(emp, th, labels=["1", "2", "3", "4", "5", "6"])

# 大数定律：样本量越大，经验频率越贴近理论概率（主线中「箭墙成形」）
print("\n大数定律（观察面 6 的经验概率随样本量收敛）：")
for n in (10, 100, 1000, 10000, 100000):
    r = simulate_rolls(n)
    f6 = sum(1 for v in r if v == 6) / n
    print("  N = %6d 次 -> Phat(6) = %.4f   (理论值 1/6 = 0.1667)" % (n, f6))
```

#### 主流程 —— 把三个函数串成一条链

**操作**：这是脚本的"执行部分"（顶层代码，不是函数）。它把步骤 2–6 的三个函数按顺序串起来：

1. `rolls = simulate_rolls(N_ROLLS)` —— 掷 1000 次，得到形状 `(1000,)` 的结果列表。
2. `emp = empirical_frequencies(rolls)` —— 得到形状 `(6,)` 的经验频率。
3. `th = theoretical_pmf()` —— 得到形状 `(6,)` 的理论概率。
4. 打印三样东西，再 `plot_distribution(...)` 画图。
5. **大数定律循环**：对 $N = 10, 100, 1000, 10000, 100000$ 各掷一次，只看面 6 的经验频率 $\hat{p}(6)$。`sum(1 for v in r if v == 6)` 是"数出结果里有多少个 6"——与步骤 4 的计数是同一操作，只是只关心面 6。`/ n` 归一化成频率。

**对应数学**：最后的循环是主线全文的缩影。$\hat{p}(6)$ 是一串随机的数：$0.1000 \to 0.1600 \to 0.1780 \to 0.1624 \to 0.1663$——它在**围绕** $1/6$ 晃荡，且晃荡的幅度越来越小。这就是**大数定律 (Law of Large Numbers)**：当 $N \to \infty$，经验频率 $\hat{p}(k) \to p(k)$。单支箭是混沌，几千支箭显秩序——现在这秩序有了数学的证明。

**输入**：无显式输入，读三个模块常量。

**输出**：控制台文本 + 一张图。控制台输出的形状是"六个频率 + 五行收敛表"，图中是"六根柱子 + 一条红线"。

**可调参数**：
- 修改 `N_ROLLS`：主流程的柱状图随之变化。设成 `100`，柱子高矮会明显参差；设成 `100000`，柱子几乎齐平，趴在那条红线上。
- 修改大数定律循环里的元组 `(10, 100, 1000, 10000, 100000)`：可以换成别的样本量序列。比如加一个 `1000000`，你会看到 $\hat{p}(6)$ 更逼近 0.1667。
- 还能不能有更多参数？这层不是函数，没有"参数"——想让它更灵活，可以把打印与循环封装成一个 `run_experiment(n_rolls, trials)` 函数。但作为一节导论的演示脚本，顶层直写更透明。

## 一步验证：把脚本改成"灌铅骰子"

想亲手撞一次主线里的边界声明吗？把 `roll_once` 改成一个不诚实的骰子：

```python
def roll_once(rng):
    u = rng.random()
    if u < 1 / 3:          # 面 6 的概率被放大到 1/3
        return 6
    return int(u * 5) + 1  # 其余五面均分剩下的 2/3 -> 每面 2/15
```

跑一遍，你会发现柱子们不再趴在 $p(k) = 1/6$ 的红线上——面 6 高高突起。**经验频率忠实反映的，是生成数据的真实机制，而不是我们一厢情愿的假设。** 这正是主线里那句"概率分布是模型，地图不是地形"的现场演示：$\hat{p}(k)$ 不会说谎，但它只会告诉你骰子实际怎么掷的，不会告诉你骰子"应该"怎么掷。
