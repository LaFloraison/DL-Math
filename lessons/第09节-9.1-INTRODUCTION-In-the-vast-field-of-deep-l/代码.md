# 代码：把神经网络剥成骨架，数一数它的"桥"

主线里我们借欧拉的眼睛做了一件事：**把城市剥成点与线，忘掉距离与形状。** 本节的代码把同一件事做到神经网络上——把一份网络拓扑（几层、几个节点、怎么连）剥成一张纯粹的图 (graph)，然后用欧拉式的计数（连边数、连通分量数、环的个数）回答一个问题：**这张骨架，结构上"连得通不通"？**

脚本只依赖 Python 标准库。用邻接表 (adjacency list) 存放"谁连着谁"，用广度优先搜索 (BFS) 数连通分量——这两件工具，正是欧拉那张哥尼斯堡地图的现代化身。

---

## 层一：完整脚本

```python
from collections import deque            # deque：BFS 的队列，左右都可弹出

def build_network(layers):
    """把 [3,4,2] 这样的层宽表变成邻接表：每层节点全连到下一层节点。"""
    offsets = []                          # 每个节点全局编号的起点
    acc = 0
    for w in layers:                      # 逐层累加，得到每个节点在全局的编号
        offsets.append(acc)
        acc += w
    n_nodes = acc
    adj = {i: set() for i in range(n_nodes)}   # 每个节点一个空的邻居集合
    for L in range(len(layers) - 1):
        for u in range(layers[L]):        # 第 L 层的每个节点
            for v in range(layers[L+1]):  # 连到第 L+1 层的每个节点
                a = offsets[L] + u
                b = offsets[L+1] + v
                adj[a].add(b)             # 无向图：双向登记
                adj[b].add(a)
    return adj, n_nodes

def count_edges(adj):
    """欧拉计数法：边数 = 每个节点的度数之和 / 2（每条边被数了两次）。"""
    return sum(len(nbrs) for nbrs in adj.values()) // 2

def connected_components(adj):
    """BFS 扫全图，返回连通分量的个数（拓扑不变量 β0 的离散雏形）。"""
    seen = set()
    comps = 0
    for start in adj:
        if start in seen:
            continue
        comps += 1
        q = deque([start])
        seen.add(start)
        while q:
            u = q.popleft()
            for v in adj[u]:
                if v not in seen:
                    seen.add(v)
                    q.append(v)
    return comps

def cycles(adj, n_nodes):
    """无向图环数 = 边数 - 节点数 + 连通分量数（欧拉公式的图论版）。"""
    return count_edges(adj) - n_nodes + connected_components(adj)

# ---- 一份典型的小网络：输入 3 个特征 → 隐藏层 4 个 → 输出 2 类 ----
layers = [3, 4, 2]
adj, n = build_network(layers)
print(f"节点数     = {n}")                                  # 3+4+2 = 9
print(f"边数       = {count_edges(adj)}")                   # 3*4 + 4*2 = 20
print(f"连通分量数 = {connected_components(adj)}")          # 每层全连，必然 1
print(f"环的个数   = {cycles(adj, n)}")                     # 20 - 9 + 1 = 12
```

运行输出（Python 3.11）：

```text
节点数     = 9
边数       = 20
连通分量数 = 1
环的个数   = 12
```

一份三层的网络骨架，剥掉"长得像不像"之后，只剩这四个数。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入队列

```python
from collections import deque
```

#### `deque` —— 双端队列

**操作**：`collections.deque` 是 Python 的双端队列，头尾都能 O(1) 弹出。BFS 需要"先进先出"的队列，`deque` 比 list 快得多。
**输入**：一个可迭代对象（这里为空，得到一个空队列）。
**输出**：一个双端队列对象，支持 `.append(x)`（尾部入队）、`.popleft()`（头部出队）。
**可调参数**：`deque(maxlen=k)` 可以限制长度——满了自动丢最老的元素，本脚本用不上。
**对应数学**：排队机制对应"先发现的点先扩展"——BFS 的"广"就广在这里。

---

### 步骤 2：`build_network` —— 把层宽表变成邻接表

```python
def build_network(layers):
    offsets = []
    acc = 0
    for w in layers:
        offsets.append(acc)
        acc += w
    n_nodes = acc
    adj = {i: set() for i in range(n_nodes)}
    for L in range(len(layers) - 1):
        for u in range(layers[L]):
            for v in range(layers[L+1]):
                a = offsets[L] + u
                b = offsets[L+1] + v
                adj[a].add(b)
                adj[b].add(a)
    return adj, n_nodes
```

**做什么**：把 `[3,4,2]`（输入 3 个节点、隐藏层 4 个、输出 2 个）转成一张**无向邻接表** `adj`——一个字典，键是节点全局编号，值是该节点的邻居集合。
**操作**：
- `offsets` 记录每层第一个节点在全局里的编号。`[3,4,2]` 中：层 0 偏移 0，层 1 偏移 3，层 2 偏移 7。于是全局编号 0–2 是第一层，3–6 是第二层，7–8 是第三层。
- 双层 for 循环把第 L 层的**每个**节点与第 L+1 层的**每个**节点配对——这就是"全连接 (fully connected)"的拓扑：每一对都有一条边。
- 无向图要双向登记：`a` 的邻居加 `b`，`b` 的邻居加 `a`。
**输入**：
- `layers`：一个列表，第 i 个元素是第 i 层的节点数。`[3,4,2]` 表示三层、共 9 个节点。每层宽度 >= 1。
**输出**：`(adj, n_nodes)`。`adj` 是 `{节点编号: 邻居集合}` 的字典；`n_nodes` 是总节点数 `sum(layers)`。
**可调参数**：
- 改 `layers` 就是改**网络拓扑**本身：`[784, 50, 10]` 是窄网络，`[784, 500, 10]` 是宽网络（§9.3.1.2 的精确例子）。`[3,4]` 是两层，`[3,4,4,2]` 是三隐藏层——层数一变，下面所有计数全变。
- 能不能加参数？可以传第三个参数 `directed=False`，改成有向图（只登记 `a→b` 一条），边数会少一半，环的计数公式也随之不同。本脚本保持无向，最贴近"接线"的直觉。
**对应数学**：这就是主线里"网络拓扑 = 节点 + 层 + 连接"的代码化身。`adj` 就是那副骨架——它完全不知道节点"长什么样"，只记录"谁连着谁"，正如欧拉丢掉地图的比例尺。

---

### 步骤 3：`count_edges` —— 欧拉的计数法

```python
def count_edges(adj):
    return sum(len(nbrs) for nbrs in adj.values()) // 2
```

#### `count_edges` —— 用"度数之和除以 2"数边

**做什么**：数出网络里一共有多少条连接（边）。
**操作**：每条边都有两个端点，所以"所有节点的邻居数之和"把每条边数了两次。`sum(len(nbrs) ...)` 求和后 `// 2` 整除 2，得到真实边数。这与欧拉数哥尼斯堡的桥用的是同一个道理：每座桥连着两片陆地，数两岸的"桥头数"再除以 2。
**输入**：`adj` 邻接表。
**输出**：一个整数。对 `[3,4,2]`：第一层到第二层 `3×4=12` 条，第二层到第三层 `4×2=8` 条，共 20。
**可调参数**：无参数——工具函数。可以直接手算验证：`3×4 + 4×2 = 20`。
**对应数学**：对应主线里"欧拉的桥数"思想。在哥尼斯堡，这个数算出了 7；在这里，它算出的是网络的**连接规模**——一个决定训练开销和过拟合风险的关键量（§9.3.1.2 会把这个数放大到 39,200 与 392,000）。

---

### 步骤 4：`connected_components` —— 数一数网络"断成几截"

```python
def connected_components(adj):
    seen = set()
    comps = 0
    for start in adj:
        if start in seen:
            continue
        comps += 1
        q = deque([start])
        seen.add(start)
        while q:
            u = q.popleft()
            for v in adj[u]:
                if v not in seen:
                    seen.add(v)
                    q.append(v)
    return comps
```

#### `connected_components` —— BFS 数连通分量

**做什么**：判断整张网是不是"一体的"——返回连通分量的个数。全连接网络从任何节点出发都能走到任何节点，所以是 1。
**操作**：外层 `for start in adj` 逐个节点尝试。若 `start` 已被访问过就跳过；否则新开一个分量 (`comps += 1`)，从它出发做一次完整 BFS——内层 `while q` 把可达的所有节点都标记进 `seen`。一轮 BFS 结束，一个连通分量就被完整圈出。
**输入**：`adj` 邻接表。
**输出**：整数，连通分量的个数。
**可调参数**：无。但可以试着把 `build_network` 改成一个**断开**的网络（比如把某一条边从邻接表里删掉），这个数就会从 1 变大——网络"断线"了。这正是拓扑性质：**连不连通，与节点画多大毫无关系**。
**对应数学**：这是主线"连通性是拓扑性质"的第一次量化。它是持久同调里 $\beta_0$（§9.4.1）在离散图上的雏形——数"有几块"。

---

### 步骤 5：`cycles` —— 欧拉公式，算出环的个数

```python
def cycles(adj, n_nodes):
    return count_edges(adj) - n_nodes + connected_components(adj)
```

#### `cycles` —— 用欧拉公式数"环"

**做什么**：数出这张图里有多少个独立的"环"（闭合回路）——拓扑意义上"洞"的离散版本。
**操作**：对无向图，一条著名恒等式成立：**边数 − 节点数 + 连通分量数 = 环的个数**。这是欧拉多面体公式（顶点−边+面=2）的图论推广，也是"洞的数量"在离散世界的祖先。对 `[3,4,2]`：`20 − 9 + 1 = 12`。
**输入**：`adj` 邻接表、`n_nodes` 节点总数。
**输出**：整数，环的个数。
**可调参数**：无。注意：这里的"环"指图的回路，与 §9.4.1 的同调环（Betti 数 $\beta_1$）有关联但不等价——那些"洞"是几何点云里的，这 12 个环是接线方式里的。别混为一谈，这正是主线"两个 topology 不能混淆"的提醒在代码里的回声。
**对应数学**：$\beta_1$（环路数）的思想，这里先以最朴素的形式出现——它提醒我们，**"有没有洞"是可以用计数精确刻画的**，不需要任何距离概念。

## 边界声明：这套代码能做什么，不能做什么

1. **它算的是"接线拓扑"，不是神经网络的性能**。这里没有训练、没有权重、没有损失函数。它回答的是结构问题（连得通不通、有几个环），回答不了性能问题（学得好不好）。性能问题要等 §9.3 系列登场。
2. **无向图丢掉了方向信息**。真实前馈网络的信息流是单向的（输入→隐藏→输出），无向化之后方向信息被抹平。本脚本故意用无向来贴合"欧拉数桥"的直觉；要精确刻画信号流向，需要读入 §9.3.3 的有向视角。
3. **"环的个数"不等于"环的拓扑意义"**。这里的 12 个环是图论计数，其中多数是"嵌套接线"的副产品，而非数据里的洞。真正的洞——$\beta_1$——要等持久同调（§9.4.1）在**点云**上才算得出来。计数是第一步，读懂计数是第二步。
