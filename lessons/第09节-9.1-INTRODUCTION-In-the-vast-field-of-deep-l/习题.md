# 习题：拓扑的双重面孔

## 第一组：概念检验

**1. 判断对错并说明理由**："把一块橡皮泥从杯子捏成甜甜圈的过程，如果中间有一瞬间需要把橡皮泥切断再接上，那么这个变形仍然算'连续变形'。"

**2. 单选题**：下面哪一项**不是**拓扑性质（在连续变形下保持不变的属性）？
- (A) 空间是否连通
- (B) 空间中洞的个数
- (C) 两个点之间的距离
- (D) 空间是否只有一个整体

**3. 简答题**：数学拓扑中的 "topology" 与深度学习中的 "topology" 含义有什么不同？它们共享的深层内核是什么？

### 解答与思路点拨

**1. 错误。** 连续变形的定义是"不切断、不粘连"。一旦切了再接，就不是连续变形，那个过程不属于拓扑学承认的变形。想一想：甜甜圈和杯子之间的洞，必须靠**捏**出来而不能靠**剪**出来。很多人误以为"只要能变到就行"，忘了连续变形这条硬约束。这正是同胚（§9.2.1）的前提——在 §9.2.1 你会看到，这直接决定两个形状"算不算同一个"。

**2. (C)。** 距离是度量 (metric) 概念，一拉就变——把橡皮泥拉长，两点距离立刻改变。而连通性、洞的个数、整体性在拉伸中都不变。选错 (B) 的读者通常想的是"洞是几何特征"——不，洞恰恰是**最典型**的拓扑性质，杯子和甜甜圈靠它同胚，圆球和圆环靠它区分。这道题的陷阱在于：直觉上"洞"听起来像形状，其实它是结构。

**3.** 数学拓扑研究空间在连续变形下不变的性质；深度学习中的拓扑指网络的**结构设计**——节点数、分层、连接方式。共同内核是：**结构决定性质**——空间的结构决定空间在变形下守住什么；网络的结构决定网络能学到什么。参考主线第二步的定义块，把两条定义并排背下来，这一章你就不会迷路。

## 第二组：计算实践

**4. 手算**：一个网络拓扑是 `[4, 3, 2]`（输入 4 节点、隐藏 3 节点、输出 2 节点，全连接）。
   - (a) 总共有多少个节点？
   - (b) 总共有多少条连接（边）？
   - (c) 手算验证：边数 − 节点数 + 连通分量数 等于几？

**5. 代码验证**：用本节的 `build_network` 函数，把 `[4, 3, 2]` 喂进去，验证你的手算结果；再把网络改成 `[4, 3, 3, 2]`（多一层隐藏），观察边数如何变化。

### 解答与思路点拨

**4.** (a) `4+3+2 = 9` 个节点。(b) 输入层到隐藏层 `4×3=12` 条，隐藏层到输出层 `3×2=6` 条，共 18 条边。(c) 全连接网络连通分量为 1，所以 `18 − 9 + 1 = 10`，即 10 个环。常见错误：把节点数算成 3（那是层数）——时刻记得层宽表里每个数是**该层节点个数**。

**5.** 验证脚本：

```python
def build_network(layers):
    offsets, acc = [], 0
    for w in layers:
        offsets.append(acc); acc += w
    adj = {i: set() for i in range(acc)}
    for L in range(len(layers) - 1):
        for u in range(layers[L]):
            for v in range(layers[L+1]):
                a, b = offsets[L]+u, offsets[L+1]+v
                adj[a].add(b); adj[b].add(a)
    return adj, acc

for ls in ([4,3,2], [4,3,3,2]):
    adj, n = build_network(ls)
    edges = sum(len(s) for s in adj.values()) // 2
    print(f"{ls}: 节点={n}, 边={edges}")
```

```text
[4, 3, 2]: 节点=9, 边=18
[4, 3, 3, 2]: 节点=12, 边=33
```

思路点拨：多了一层隐藏层，边数从 18 涨到 33——注意增长不是线性的：`4×3 + 3×3 + 3×2 = 33`。每一层的宽度都在贡献乘法项。这为 §9.3.1.2 的"宽度决定连接数爆炸"埋下伏笔：`[4, 500, 2]` 的边数是 `4×500 + 500×2 = 3000`，宽度是决定连接规模的主导变量。

## 第三组：DL 延伸

**6. 场景判断**：你在设计一个图像分类器，纠结要不要给网络加一条"跳连"（把第 1 层的输出直接加到第 3 层的输入上）。你的同事说："别加，跳连会把网络的拓扑搞乱。" 请问同事的说法在**拓扑结构**上成立吗？跳连改变的是网络的哪一部分？

**7. 思考题**：§9.1 主线说"神经网络的进化史是一部网络拓扑的演化史"。请举出两个你听过的神经网络架构，说明它们分别在哪里**改变了接线方式**（而不仅仅是加深加宽）。

### 解答与思路点拨

**6.** 跳连**确实改变了拓扑**——它在原有一层接一层的链式结构上，额外开了一条跨越一层的直连路径。所以"搞乱"不是没有根据。但"搞乱"不是"搞坏"：跳连反而解决了深层网络训不动的问题（§9.3.2 会专门证明）。关键在于理解**拓扑的代价与收益**：任何拓扑改动都同时改变信息流与梯度流（§9.3.2 的 Figure 9.3 会画出梯度的变化）。判断的标准不是"改没改结构"，而是"改动后的结构能否让学习算法收敛"。

**7.** 开放题，示例答案：**ResNet** 加了恒等跳连（§9.3.2 的主角），让 152 层可以训练；**Transformer** 同样在多头注意力外并联了残差连接，并且用位置编码把"序列顺序"注入结构。两者都没有发明新数学，只是在接线图上各加了一条捷径。这个观察呼应主线第三步的桥接：深度学习的突破常是结构发明而非公式发明。
