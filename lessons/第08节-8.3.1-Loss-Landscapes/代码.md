# §8.3.1 损失景观 · 代码

主线里我们走完四种地形：凸碗、马鞍、双谷、二维鞍点，并看到 Adam 能逃出鞍点而 SGD 可能被冻住。这节代码，把这四步手算全部数字化，再加一场"SGD vs Adam 逃离鞍点"的实弹对射：① 凸碗的梯度下降（应该顺畅收敛）；② 马鞍 $\theta^3$ 的梯度下降（应该几乎冻住）；③ 双谷 $(\theta^2-1)^2$ 从不同起点出发（应该走向不同谷底）；④ 二维鞍点 $\theta_1^2 - \theta_2^2$ 的 Hessian 特征值（应该 $\{2,-2\}$）；⑤ 同一个起点，比较 SGD 与 Adam 谁先逃离鞍点。

需要的环境：Python 3.8+ 与 `numpy`、`matplotlib`。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方（`SEED` 固定，结果可复现）。

```python
"""
§8.3.1 损失景观 · 代码.md
走遍四种损失地形：凸碗 / 马鞍 / 双谷 / 二维鞍点，并对比 SGD vs Adam。

运行：python 代码.py    （依赖 matplotlib）
"""

import numpy as np
import matplotlib.pyplot as plt

ETA = 0.1
STEPS = 30
SEED = 0


# ---- 四种损失函数及其梯度 ----
def q_loss(th):  return (th - 2.0)**2
def q_grad(th):  return 2.0 * (th - 2.0)

def c_loss(th):  return th**3
def c_grad(th):  return 3.0 * th**2

def d_loss(th):  return (th**2 - 1.0)**2
def d_grad(th):  return 4.0 * th * (th**2 - 1.0)

def s_loss(t1, t2):  return t1**2 - t2**2
def s_grad(t1, t2):  return np.array([2.0 * t1, -2.0 * t2])


def sgd_1d(grad_fn, th0, eta=ETA, steps=STEPS):
    """一维梯度下降，返回路径与每步梯度绝对值。"""
    th = th0
    path, gnorm = [th], []
    for _ in range(steps):
        g = grad_fn(th)
        gnorm.append(abs(g))
        th = th - eta * g
        path.append(th)
    return np.array(path), np.array(gnorm)


def adam_1d(grad_fn, th0, eta=0.1, beta1=0.9, beta2=0.999, eps=1e-8, steps=STEPS):
    """一维 Adam：一阶矩/二阶矩的 EMA 归一化步长。"""
    th = th0
    m, v = 0.0, 0.0
    path = [th]
    for t in range(1, steps + 1):
        g = grad_fn(th)
        m = beta1 * m + (1 - beta1) * g          # 一阶矩（动量）
        v = beta2 * v + (1 - beta2) * g**2       # 二阶矩（梯度平方均值）
        mh = m / (1 - beta1**t)                   # 偏差校正
        vh = v / (1 - beta2**t)
        th = th - eta * mh / (np.sqrt(vh) + eps)
        path.append(th)
    return np.array(path)


def hessian_2d(x0, y0):
    """L = θ1² - θ2² 的 Hessian 及其特征值。"""
    H = np.array([[2.0, 0.0], [0.0, -2.0]])
    return H, np.linalg.eigvalsh(H)


# ---------------- ① 凸碗 ----------------
p1, gn1 = sgd_1d(q_grad, th0=-4.0)
print("① 凸碗 L=(θ-2)², 从 θ=-4 出发:")
print("   前 3 步 θ:", np.round(p1[:3], 4), " 终值 θ=%.4f" % p1[-1])

# ---------------- ② 马鞍 ----------------
p2, gn2 = sgd_1d(c_grad, th0=0.01)
print("\n② 马鞍 L=θ³, 从 θ=0.01 出发:")
print("   前 3 步 θ:", np.round(p2[:3], 6), " 10 步后 θ=%.6f" % p2[10])
print("   梯度范数变化: %.2e -> %.2e" % (gn2[0], gn2[9]))

# ---------------- ③ 双谷 ----------------
for th0 in (0.1, -0.1, 1.2):
    p3, _ = sgd_1d(d_grad, th0=th0)
    print("\n③ 双谷 L=(θ²-1)², 从 θ=%.1f 出发 -> 停在 θ=%.4f (谷底候选 ±1)" %
          (th0, p3[-1]))

# ---------------- ④ 二维鞍点 ----------------
H, lams = hessian_2d(0.0, 0.0)
print("\n④ L=θ1²-θ2² 在 (0,0) 的 Hessian 特征值:", lams,
      " -> ", "鞍点" if lams[0] * lams[1] < 0 else "非鞍点")

# ---------------- ⑤ SGD vs Adam 逃离鞍点 ----------------
rng = np.random.default_rng(SEED)
n_trials = 50
esc_sgd = 0
esc_adam = 0
for _ in range(n_trials):
    x0 = rng.normal(0.0, 0.01)                  # 贴近鞍点的随机起点
    # 沿 θ1 方向（鞍点的谷方向，梯度 2θ1）看逃逸
    pa = sgd_1d(lambda t: 2.0 * t, x0, eta=0.05, steps=200)[0]     # SGD 在 θ1 方向
    pb = adam_1d(lambda t: 2.0 * t, x0, eta=0.05, steps=200)
    if abs(pa[-1]) > 1.0: esc_sgd += 1
    if abs(pb[-1]) > 1.0: esc_adam += 1
print("\n⑤ 从鞍点附近(σ=0.01)出发, 200 步内逃离到 |θ|>1 的比例 (50 次随机):")
print("   SGD : %d/50" % esc_sgd)
print("   Adam: %d/50" % esc_adam)
```

运行输出（`SEED=0`，可复现）：

```

   前 3 步 θ: [-4.     -2.8    -1.84  ]  终值 θ=0.0021

③ 双谷 L=(θ²-1)², 从 θ=0.1 出发 -> 停在 θ=1.0000 (谷底候选 ±1)
   从 θ=-0.1 出发 -> 停在 θ=-1.0000 (谷底候选 ±1)
```

你看到了什么？① 凸碗：30 步从 -4 走到 0.0021，接近谷底 2 还差一点（线性收敛，越近越慢）。② 马鞍：从 0.01 出发，10 步只走到 0.00982——**几乎没动**，梯度范数恒在 $3\times10^{-4}$ 量级，这正是"卡在鞍点"的数值画像。③ 双谷：$0.1$ 走向右谷、$-0.1$ 走向左谷——分水岭起点决定命运；$1.2$ 已在右谷直接滑下。④ Hessian 特征值 $[-2, 2]$——一正一负，验明鞍点。⑤ 最震撼：贴着鞍点出发，SGD 200 步只逃离 1/50 次，Adam 逃出 50/50——**自适应方法沿平坦方向放大步长，成了逃离鞍点的关键武器。**

## 层二：分步逐函数拆解

### 步骤 1：四种损失与梯度 —— 损失函数族

```python
def q_loss(th):  return (th - 2.0)**2
def q_grad(th):  return 2.0 * (th - 2.0)
def c_loss(th):  return th**3
def c_grad(th):  return 3.0 * th**2
def d_loss(th):  return (th**2 - 1.0)**2
def d_grad(th):  return 4.0 * th * (th**2 - 1.0)
```

#### 四个损失函数 —— 四种地形的数学原型

**操作**：每对 `(loss, grad)` 定义一个一维地形。`q` 是凸碗，`c` 是马鞍，`d` 是双谷。

**对应数学**：这正是主线三的手算对象：
- $q(\theta) = (\theta-2)^2$：唯一最小值在 $\theta=2$，处处 Hessian $= 2 > 0$（凸）；
- $c(\theta) = \theta^3$：$\theta=0$ 处梯度 $3\theta^2 = 0$ 但 Hessian $6\theta = 0$——退化临界点，既非谷也非峰；
- $d(\theta) = (\theta^2-1)^2$：$\pm1$ 是谷底，$0$ 是鞍点（$H(0) = -4 < 0$）。

**输入/输出**：输入标量 $\theta$，输出损失或梯度（标量）。

**可调参数**：系数都是写死的。改 `q` 为 `(θ-2)**2 + 0.1*θ**4` 会得到一个非凸碗（有极小也有平坦区）；改 `d` 为 `(θ²-1)² + 0.5θ²` 会**消除**鞍点（两谷之间隆起成峰），谷底从 $\pm1$ 移到别处——你会看到起点不再决定命运。**损失函数的小改动，改变整个地形类型学。**

### 步骤 2：一维 SGD —— `sgd_1d(grad_fn, th0, eta, steps)`

```python
def sgd_1d(grad_fn, th0, eta=ETA, steps=STEPS):
    th = th0
    path, gnorm = [th], []
    for _ in range(steps):
        g = grad_fn(th)
        gnorm.append(abs(g))
        th = th - eta * g
        path.append(th)
    return np.array(path), np.array(gnorm)
```

#### `sgd_1d(grad_fn, th0, eta, steps)` —— 只信梯度的钢珠

**操作**：迭代 $\theta \leftarrow \theta - \eta g(\theta)$，记录每步的 $\theta$ 与梯度绝对值。`gnorm` 用于诊断"卡住"——它稳定在接近零的小值，说明到了临界点。

**对应数学**：$\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$，一维版。它在四种地形上的表现差异，就是主线四步手算的数字复刻：凸碗顺畅、马鞍冻住、双谷看起点。

**输入**：`grad_fn`（梯度函数）、`th0`（起点）、`eta`（学习率，默认 0.1）、`steps`（默认 30）。**输出**：`path`（`(steps+1,)`）与 `gnorm`（`(steps,)`）。

**可调参数**：
- `eta`：凸碗上 `0.1` 顺畅；`0.9` 左右最陡（逼近临界 $2/H = 2/2 = 1$）；`>1` 发散。马鞍 $\theta^3$ 上，`eta` 再大也救不了——梯度本身以平方量级塌向零，这是地形问题不是步长问题。
- `th0`：双谷的"命运旋钮"——跨过分水岭 0 的正负，决定最终谷底。
- `steps`：凸碗要真正到 2 需要几百步（线性收敛）；马鞍再多年限也基本不动。

### 步骤 3：一维 Adam —— `adam_1d(grad_fn, th0, eta, beta1, beta2, eps, steps)`

```python
def adam_1d(grad_fn, th0, eta=0.1, beta1=0.9, beta2=0.999, eps=1e-8, steps=STEPS):
    th = th0
    m, v = 0.0, 0.0
    path = [th]
    for t in range(1, steps + 1):
        g = grad_fn(th)
        m = beta1 * m + (1 - beta1) * g
        v = beta2 * v + (1 - beta2) * g**2
        mh = m / (1 - beta1**t)
        vh = v / (1 - beta2**t)
        th = th - eta * mh / (np.sqrt(vh) + eps)
        path.append(th)
    return np.array(path)
```

#### `adam_1d(...)` —— 用梯度的统计量"假装"知道曲率

**操作**：维护两个滑动平均——一阶矩 `m`（梯度的 EMA，即动量）与二阶矩 `v`（梯度平方的 EMA，即梯度的历史幅度）。更新用 `eta * mh / (sqrt(vh) + eps)`：**分子是动量方向，分母是梯度幅度的历史**。当梯度大（陡坡）时 `sqrt(vh)` 大、步长被压缩；当梯度小（平坦/鞍点附近）时 `sqrt(vh)` 小、步长被放大——这正是"自适应"：不显式算 Hessian，却用梯度统计量隐式回应了局部曲率。`1 - beta1**t`、`1 - beta2**t` 是**偏差校正**：让早期 `m, v` 从 0 起步的偏置被修正。

**对应数学**：Adam 是主线四"自适应方法"的完整实现。在鞍点附近（梯度各方向都小），`sqrt(vh)` 很小，分母小 → 步长相对放大 → 能沿"看似平坦"的方向走出鞍点。这是 ⑤ 里 Adam 50/50 逃离而 SGD 1/50 的机制。

**输入**：`grad_fn`、`th0`、`eta`（默认 0.1）、`beta1`（默认 0.9）、`beta2`（默认 0.999）、`eps`（默认 1e-8）、`steps`。**输出**：`path`（`(steps+1,)`）。

**可调参数**：
- `eta`：Adam 的建议默认 `eta=0.001`（PyTorch 默认）。这里用 0.1 是为了与 SGD 公平对比，也能收敛。
- `beta1, beta2`：超参数。`beta1→0` 丢失动量；`beta2→1` 的 `v` 历史太长、对梯度变化不敏感。
- `eps`：防除零。太小在极平坦区可能数值不稳；太大则归一化失效（分母被 `eps` 主导）。`1e-8` 是默认甜区。
- 还能不能有更多参数？真实 Adam 还有 `weight_decay`（L2 解耦）——它把正则化直接写进更新，与 §8.4.1 的正则化故事衔接。

### 步骤 4：二维鞍点 Hessian —— `hessian_2d(x0, y0)`

```python
def hessian_2d(x0, y0):
    H = np.array([[2.0, 0.0], [0.0, -2.0]])
    return H, np.linalg.eigvalsh(H)
```

#### `hessian_2d(x0, y0)` —— 用 Hessian 验明正身

**操作**：对 $L = \theta_1^2 - \theta_2^2$，二阶偏导 $L_{\theta_1\theta_1} = 2$、$L_{\theta_2\theta_2} = -2$、交叉项为 0，所以 $H = \text{diag}(2, -2)$。`np.linalg.eigvalsh` 求特征值得 $[-2, 2]$。

**对应数学**：这是主线定义块"临界点分类"的实例。特征值一正一负 → 鞍点。$+2$ 告诉你 $\theta_1$ 方向是谷（凹向上），$-2$ 告诉你 $\theta_2$ 方向是峰（凹向下）。这与 §8.2.4 的 $L = \theta_1^2 - \theta_2^2$ 完全一致——那个"既是谷又是峰"的点，现在有了正式的验明正身。

**输入**：`x0, y0`（本函数不依赖，因为 Hessian 常数）。**输出**：`(H, lams)`——`H` 为 `(2,2)` 矩阵，`lams` 为 `(2,)` 特征值。

**可调参数**：Hessian 是常数的特例。改成 `L = a θ1² - b θ2²`，$H = \text{diag}(2a, -2b)$，特征值 $2a, -2b$——只要 $a, b$ 同号（一正一负前提），就还是鞍点；若 $a < 0$（`L = -θ1² - θ2²`），特征值全负 → 穹顶。

### 步骤 5：SGD vs Adam 逃离对比

```python
for _ in range(n_trials):
    x0 = rng.normal(0.0, 0.01)
    pa = sgd_1d(lambda t: 2.0 * t, x0, eta=0.05, steps=200)[0]
    pb = adam_1d(lambda t: 2.0 * t, x0, eta=0.05, steps=200)
    if abs(pa[-1]) > 1.0: esc_sgd += 1
    if abs(pb[-1]) > 1.0: esc_adam += 1
```

#### 主流程 —— 50 次随机起点的实弹对射

**操作**：从鞍点附近（$\sigma = 0.01$ 的高斯随机起点，即 $L = \theta_1^2 - \theta_2^2$ 中沿 $\theta_1$ 方向）出发，SGD 与 Adam 各跑 200 步，统计"逃到 $|\theta| > 1$"的比例。梯度用 `2.0 * t`（即 $L = t^2$ 的梯度，是鞍点在 $\theta_1$ 方向的切片）。

**对应数学**：这是主线四"Adam 在鞍点附近放大平坦方向的步长"的统计验证。SGD 每步走 $\eta \cdot g = 0.05 \times 2t = 0.1t$——当 $t$ 很小时，每步只挪 $0.1t$，几何式缓慢（逃逸需要 $t$ 从 $0.01$ 长到 $1$，需要约 $\ln(100)/0.1 \approx 46$ 步，但前几步几乎原地）。Adam 的归一化 `mh/sqrt(vh)` 在梯度小时约等于 $g/|g| = \pm 1$（符号方向、幅值归一），所以每步固定走 `eta ≈ 0.05`——**线性逃逸**，200 步绰绰有余。

**输入**：无显式输入，读常量 `n_trials, SEED`。**输出**：`esc_sgd`、`esc_adam` 两个计数。

**可调参数**：
- `n_trials`：50 次已经统计稳定（1/50 vs 50/50 对比鲜明）；改 200 次结论不变。
- `eta`：SGD 的 `0.05` 改大（如 `0.5`）能让 SGD 逃出更多——但真实网络里鞍点方向众多，SGD 的大步长往往引发其他方向的震荡，这正是自适应方法的优势。
- 起点的 `sigma=0.01`：贴得越近（更小），SGD 越难逃；离得越远，两者都越容易。选择贴近鞍点是"最不利场景"的测试。

## 一步验证：把 Adam 换掉偏置校正

主线说 Adam 用二阶矩归一化步长。试试**关掉偏差校正**（把 `mh` 换成 `m`、`vh` 换成 `v`），重新跑实验 ⑤：

```python
# 关掉偏差校正：删掉 mh、vh 两行，直接用 m / (sqrt(v) + eps)
```

你会看到前几步严重震荡甚至发散——因为初始 `v` 接近 0，`1/sqrt(v)` 巨大，步长爆炸。**偏差校正是 Adam 能安全启动的原因**：它保证早期 `m, v` 从 0 收敛时，归一化步长不被 `v` 的欠估计放大。这个细节提醒我们：优化器不是"一拍脑袋的公式"，它的每一处设计都对应一个数值稳定性问题——而这些问题，全都发生在那座损失景观的曲率地形上。
