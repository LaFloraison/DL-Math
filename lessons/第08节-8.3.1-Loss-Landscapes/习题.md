# §8.3.1 损失景观 —— 习题

本章主线讲了三件事：损失景观是"几十亿维的地形"（凸谷、鞍点、多谷）；用 Hessian 特征值给临界点分类（全正=谷、全负=峰、有正有负=鞍）；优化器是与地形博弈的策略（SGD 信梯度、牛顿法用二阶、Adam 用梯度统计量）。下面的习题分三组：**概念检验** 验证分类判据，**计算实践** 把四种地形亲手算一遍（含代码验证），**DL 延伸** 把损失景观用回真实训练场景。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：以下哪个关于鞍点的说法**错误**？

- A. 鞍点处梯度为零，但既不是局部最大值也不是局部最小值
- B. 鞍点的 Hessian 特征值有正有负
- C. 高维损失景观里，鞍点比局部最小值常见得多
- D. 鞍点是最坏的障碍，梯度下降永远无法通过它

**解答**：D。

D 错：鞍点不是不可逾越的——自适应方法（Adam）、动量、加噪声扰动都能帮助逃离鞍点（代码实验⑤：Adam 50/50 逃出）。A 对：鞍点是"部分方向谷、部分方向峰"的临界点。B 对：特征值有正有负正是鞍点的 Hessian 判据。C 对：随机临界点的特征值全正概率为 $2^{-n}$，随维度指数衰减。

**思路点拨**：题眼是"鞍点是卡住而非死局"。最容易错的直觉是"梯度为零且不是极值 → 无解"——其实鞍点的负曲率方向是有出路的，问题只在于梯度太小、步长不足。判据：**鞍点是"迟缓的障碍"不是"封闭的死胡同"**，而克服它的工具正是对曲率的利用（动量/自适应/二阶）。

### 题 2（判断 + 简答）：为什么高维里梯度为零"几乎必然"是鞍点？

一个 100 万维的神经网络，在某处梯度恰好为零。为什么"它是局部最小值"的概率几乎为零？用特征值语言解释。

**解答**：梯度为零只是临界点（一阶条件）。判断它是最小值，要看 Hessian 的**所有**特征值是否都为正（二阶条件）。对"随机"的临界点，每个方向的曲率可正可负、大致各半。所有 $n$ 个特征值同时为正的概率约为 $\left(\frac12\right)^n$。当 $n = 10^6$ 时，这个概率是 $\left(\frac12\right)^{10^6}$——比宇宙中原子数分之一还小几个数量级。所以一个随机的梯度零点，几乎必然是鞍点（至少有一个负特征值）。

**思路点拨**：这是主线撞墙的核心命题。关键是把"梯度为零"与"局部最小值"分开：前者是一阶信息（切空间），后者需要二阶信息（曲率）。概率论证的锚点：特征值全正 = $2^{-n}$。若你能说出"这解释了为什么训练容易卡住"，说明理解了它的实际意义。

### 题 3（简答）：凸区域、凹区域、鞍点，梯度下降各遇到什么？

用"碗内（凸）""穹顶外（凹）""马鞍"三种地形，分别描述梯度下降的行为。

**解答**：

- **凸区域（碗内）**：梯度总指向谷底方向，无论从哪出发，下降路径平滑、收敛可靠。这是优化者最想要的地形——"闭着眼也能下山"。
- **凹区域（穹顶外）**：这是"山峰的外侧"，梯度指向远离峰顶的下降方向，其实也是在走向更低处——但峰顶本身是陷阱（局部最大值）。如果路径恰好要经过峰顶附近，会被"推离"。
- **鞍点**：梯度接近零，但离真正的低处还远。梯度下降的步长 $\eta\|\nabla L\|$ 随梯度塌向零，于是训练"卡住"——不是到了终点，是踩上了马鞍。高维里这是最常见的地形。

**思路点拨**：这道题考"地形-行为"配对。核心：凸=顺滑、凹=推离、鞍=卡住。最容易错的是把"鞍点"当"局部最小值"——判据：看特征值符号。记忆锚点：**梯度为零不意味着到谷底，可能只是踩上了马鞍的背。**

## 二、计算实践

### 题 1（凸碗的手算：教材第一步）

$L(\theta) = (\theta - 2)^2$，从 $\theta_0 = -4$ 出发，学习率 $\alpha = 0.1$。

(a) 写出梯度与 Hessian，验证处处凸。
(b) 手算前两步的 $\theta$ 与损失（教材给 $\theta_1 = -2.8$，$L_1 = 23.04$）。
(c) 这个收敛是"线性收敛"——说明 $\theta_t$ 每次按固定比例逼近 2。比例是多少？（提示：写出 $\theta_{t+1} - 2$ 与 $\theta_t - 2$ 的关系）

**解答**：

(a) $\nabla L = 2(\theta - 2)$，$H = 2 > 0$ 恒成立——处处凸，唯一最小值在 $\theta = 2$。

(b) $\theta_0 = -4$，$\nabla L(\theta_0) = 2(-4-2) = -12$。
$$\theta_1 = -4 - 0.1 \times (-12) = -4 + 1.2 = -2.8$$
$$L_1 = (-2.8 - 2)^2 = (-4.8)^2 = 23.04$$
$\theta_1 = -2.8$，$\nabla L(\theta_1) = 2(-4.8) = -9.6$。
$$\theta_2 = -2.8 - 0.1 \times (-9.6) = -2.8 + 0.96 = -1.84$$
$$L_2 = (-1.84 - 2)^2 = (-3.84)^2 = 14.7456$$

(c) 关键观察：$\theta_{t+1} - 2 = \theta_t - 2 - 0.1 \times 2(\theta_t - 2) = (\theta_t - 2)(1 - 0.2)$。所以
$$\theta_{t+1} - 2 = 0.8(\theta_t - 2)$$
**距谷底的距离每步乘 0.8**——几何级数衰减，这就是"线性收敛"（收敛阶 1）。$|\theta_t - 2| = 6 \times 0.8^t$，要逼近到 $10^{-6}$ 需要约 $\log_{0.8}(10^{-6}/6) \approx 60$ 步。

**NumPy 验证**：
```python
import numpy as np

th = -4.0
for t in range(3):
    print("t=%d θ=%.4f L=%.4f dist_to_2=%.4f" % (t, th, (th-2)**2, abs(th-2)))
    th = th - 0.1 * 2.0 * (th - 2.0)     # 一步梯度下降
print("比值 (θ_{t+1}-2)/(θ_t-2) =", 1 - 0.1 * 2.0)
```
```
t=0 θ=-4.0000 L=36.0000 dist_to_2=6.0000
t=1 θ=-2.8000 L=23.0400 dist_to_2=4.8000
t=2 θ=-1.8400 L=14.7456 dist_to_2=3.8400
比值 (θ_{t+1}-2)/(θ_t-2) = 0.8
```

**思路点拨**：核心是 (c)——把收敛写成 $|\theta_t - \theta^*|$ 的几何衰减，比例 $|1 - \alpha H|$。这直接给出 8.2.4 的 $\eta < 2/H$ 判据（$|1 - \alpha \cdot 2| < 1 \Rightarrow \alpha < 1$）。判据记一句：**凸二次的收敛速度 = $|1 - \alpha \cdot \text{曲率}|$ 的几何级数。**

### 题 2（马鞍的手算：教材第二步）

$L(\theta) = \theta^3$，从 $\theta_0 = 0.01$ 出发，学习率 $\alpha = 0.1$。

(a) 手算前两步的 $\theta$，指出每步的移动量有多小。
(b) 为什么移动量这么小？梯度在 $\theta \to 0$ 时以什么阶数塌向零？
(c) 如果从 $\theta_0 = 1$ 出发，同样 10 步会怎样？（提示：梯度不再接近零）

**解答**：

(a) $\nabla L = 3\theta^2$。$\theta_0 = 0.01$，$\nabla L(\theta_0) = 3(0.01)^2 = 0.0003$。
$$\theta_1 = 0.01 - 0.1 \times 0.0003 = 0.01 - 0.00003 = 0.00997$$
$\nabla L(\theta_1) = 3(0.00997)^2 \approx 0.0002982$。
$$\theta_2 = 0.00997 - 0.1 \times 0.0002982 \approx 0.00994018$$
每步移动量只有约 $3\times10^{-5}$——**几乎原地不动**。

(b) 梯度 $3\theta^2$ 在 $\theta \to 0$ 时以**平方阶**（$O(\theta^2)$）塌向零。梯度下降的步长 $\alpha\|\nabla L\| = 0.1 \times 3\theta^2$ 也以平方阶塌零。越接近 0，走得越慢——形成"临界慢化"。

(c) 从 $\theta_0 = 1$ 出发：$\nabla L(1) = 3$，$\theta_1 = 1 - 0.3 = 0.7$，$\nabla L(0.7) = 1.47$，$\theta_2 = 0.7 - 0.147 = 0.553$……参数快速远离原点（向 $-\infty$ 走去，因为 $\theta^3$ 在负方向无下界）。10 步会走得很远。**离鞍点足够远时梯度很大，梯度下降"能跑起来"；只有贴着鞍点时，才被平方级的小梯度冻住。**

**思路点拨**：这道题解释"为什么卡住"的机制——梯度塌陷的速度。关键量：$|\nabla L| = 3\theta^2$ 是二次塌陷。判据：**鞍点/退化点附近，梯度的塌陷阶数决定梯度下降的迟缓程度。** (c) 还暗示了优化实践的一条经验：多起点/扰动（如 warm restart、加噪声）能帮模型从鞍点附近的"冻结点"挣脱。

### 题 3（双谷与二维鞍点）

(a) $L(\theta) = (\theta^2 - 1)^2$，梯度与 Hessian 各是什么？$\theta = 0$ 处是什么类型的临界点？$\pm1$ 呢？
(b) $L(\theta_1, \theta_2) = \theta_1^2 - \theta_2^2$ 的 Hessian 特征值是什么？用 Hessian 判据分类原点。
(c) 对 (b)，梯度下降从 $(0.1, 0.1)$ 出发，$\theta_1, \theta_2$ 各自怎么动？会怎样？

**解答**：

(a) 梯度 $4\theta(\theta^2 - 1)$，Hessian $4(3\theta^2 - 1)$。$\theta = 0$：梯度 0，$H = -4 < 0$——**鞍点**（一维里它其实是局部最大，因为 $(\theta^2-1)^2$ 在 0 处达到其"中间峰"）。$\theta = \pm1$：梯度 0，$H = 4(3 - 1) = 8 > 0$——**局部最小值**（谷底）。

(b) $H = \text{diag}(2, -2)$，特征值 $2, -2$。一正一负 → **鞍点**。$\theta_1$ 方向是谷（$\lambda_1 = 2 > 0$），$\theta_2$ 方向是峰（$\lambda_2 = -2 < 0$）。

(c) 更新：$\theta_1 \to \theta_1 - 0.1 \times 2\theta_1 = 0.8\theta_1$，$\theta_2 \to \theta_2 - 0.1 \times (-2\theta_2) = 1.2\theta_2$。从 $(0.1, 0.1)$：$\theta_1$ 按 0.8 衰减趋近 0，$\theta_2$ 按 1.2 **增长**——参数沿 $\theta_2$ 方向被"推离"原点。最终 $\theta_2$ 迅速增大、损失 $-(\theta_2)^2$ 变得巨大（沿负曲率方向损失无限下降）。**梯度下降被鞍点的负曲率方向"甩出去"，看似在逃逸，其实是沿错误方向跌落。**

**NumPy 验证**：
```python
import numpy as np

t1, t2 = 0.1, 0.1
print("θ1, θ2 演化 (α=0.1):")
for t in range(8):
    print("  t=%d θ1=%.4f θ2=%.4f L=%.4f" % (t, t1, t2, t1**2 - t2**2))
    t1, t2 = 0.8 * t1, 1.2 * t2
```
```
θ1, θ2 演化 (α=0.1):
  t=0 θ1=0.1000 θ2=0.1000 L=0.0000
  t=1 θ1=0.0800 θ2=0.1200 L=-0.0080
  t=2 θ1=0.0640 θ2=0.1440 L=-0.0166
  ...
  t=7 θ1=0.0210 θ2=0.3583 L=-0.1280
```

**思路点拨**：这道题把教材第三步、第四步合成一道。(a) 练一维 Hessian 判据；(b) 练二维；(c) 揭示鞍点的行为——负曲率方向是"不稳定流形"，参数会沿它被推走。判据：**Hessian 的负特征值方向是鞍点的"逃逸方向"，但它通向损失上升还是下降取决于该方向函数形状**——$L = \theta_1^2 - \theta_2^2$ 里 $\theta_2$ 方向是"下坡的逃逸"（损失下降但永不到谷）。

## 三、DL 延伸

### 题 1（训练卡住的诊断与对策）

你的模型训练 loss 停在 0.35 不再下降，但验证 loss 一直在涨。梯度范数约为 $10^{-4}$（很小但非零）。

(a) 用损失景观的语言诊断：最可能是哪种地形？为什么不是"到了局部最小值"？
(b) 给出三条可操作的几何对策，并说明各针对什么。

**解答**：

(a) **最可能是鞍点（或退化的平坦区域）**。判据：梯度很小（$10^{-4}$）但非零，说明"一阶条件近似满足但没到谷底"；验证 loss 在涨说明模型对数据细节过度敏感（过拟合信号，往往是尖锐地形）。若真是局部最小值，梯度会更接近零且验证 loss 应稳定。梯度"小而不零" + 验证在涨 = 靠近鞍点的特征。

(b) 三条对策：
1. **换 Adam / 调大学习率**——自适应方法沿平坦方向放大步长，帮参数逃离鞍点（针对"梯度太小、步长不足"）；
2. **加动量（momentum）**——沿历史速度方向冲过平坦区（针对"鞍点附近的惯性不足"）；
3. **引入扰动或 warm restart**——周期性增大学习率或加噪声，把参数从鞍点"踢出去"（针对"退化/平坦方向的冻结"）。

**思路点拨**：这道题把"卡住"从现象变诊断。(a) 的判据："梯度小而不零 + 验证涨"是鞍点的经典签名（真最小值梯度≈0 且验证稳）。易错回答是"到了局部最小值"——但局部最小值梯度应该更接近零、且不会让验证涨。对策要落到机制：Adam 用统计量、动量用惯性、重启用扰动，各自对应地形的一种特征。

### 题 2（牛顿法 vs SGD：曲率的代价）

牛顿法更新 $\theta_{t+1} = \theta_t - \eta H^{-1}\nabla L$。

(a) 对 $L = (\theta-2)^2$，牛顿法一步到哪？（$H = 2$）
(b) 为什么大神经网络不用纯牛顿法？给出两个原因。
(c) Adam 用梯度统计量"近似曲率"，为什么这算一个合理的折中？

**解答**：

(a) $H^{-1} = 1/2$，一步：$\theta_1 = -4 - \eta \times \frac12 \times (-12) = -4 + 6\eta$。取 $\eta = 1$，$\theta_1 = 2$——**一步到达谷底**！牛顿法对凸二次函数一步收敛，因为 $H^{-1}$ 把"曲率"从更新里除掉（等价于换坐标让地形变球）。

(b) 两个原因：① **计算/存储**：$H$ 是 $n\times n$（$n$ = 参数数，可达十亿），存储 $10^{18}$ 个元素不可行，求逆 $O(n^3)$ 更不可行；② **Hessian 病态**：真实损失景观的 $H$ 含大量近零特征值（冗余方向），$H^{-1}$ 在这些方向爆炸，数值不稳定，需要正则化（如 Levenberg-Marquardt、加 $\lambda I$）。

(c) Adam 不显式求 $H$，而是用**梯度的二阶矩** $\mathbb{E}[g^2]$ 做逐方向归一化——这是对"Hessian 对角线的近似"（对二次损失，$\mathbb{E}[(\partial L/\partial\theta_i)^2]$ 与 $H_{ii}$ 相关）。它只用一个"对角 + 历史统计"的近似，代价（$O(n)$ 内存、每步 $O(n)$ 计算）与 SGD 同阶，却抓住了"哪个方向陡、哪个方向平"的关键信息。**这是"用一阶的代价换二阶的直觉"的工程折中。**

**思路点拨**：这道题把主线四的三种策略对比收紧。核心命题：牛顿法 = 精确曲率但昂贵；Adam = 近似曲率但廉价。判据一句话：**曲率信息越精确，收敛越快，代价越高——深度学习选择了"够用"而不是"最优"。** 这也是 K-FAC（块近似曲率）存在的动机。

### 题 3（架构即地形）

2018 年损失景观可视化发现：ResNet（带残差连接）的损失景观是大片平坦盆地，而浅层/无残差的网络景观崎岖破碎。

(a) 从曲率角度，平坦盆地意味着什么？（Hessian 特征值、泛化、优化稳定性）
(b) 为什么"平坦盆地"对训练有利？
(c) 如果你在调一个总卡在局部最优附近的模型，这条观察给你什么架构层面的启发？

**解答**：

(a) 平坦盆地 = Hessian 特征值普遍较小 = 曲率低。这意味着：① **优化**上，学习率可以大而不发散（$2/\lambda_{\max}$ 的临界值高），各方向步长均匀，收敛快而稳；② **泛化**上，低曲率极小值对扰动不敏感，是 8.3.3 说的"平坦极小值泛化好"；③ **鲁棒性**上，参数小幅变化预测稳定。

(b) 三个机制：① 梯度在各方向都"有点信息"，不会被鞍点的极小梯度冻住（平坦不等于零梯度）；② 大学习率安全（$\lambda_{\max}$ 小）；③ 收敛终点是低锐度区域，对新数据稳健。

(c) 架构层面的启发：**若你的模型反复卡在尖锐的局部结构里，优先考虑"让损失景观变平坦"的架构修改**——加入残差连接（skip connection）、批归一化（显式归一化激活，平滑景观）、合适的激活函数（避免饱和区）。这些技巧在直觉上是"让网络更深更稳"，在几何上是"把崎岖的损失山变成一片缓坡盆地"。**你设计的不是架构，是损失景观的地形。**

**思路点拨**：这道题把"架构技巧"重新翻译成"地形设计"。核心命题：ResNet 的残差连接不只是"缓解梯度消失"，它同时重塑了损失景观的曲率分布。判据：遇到优化/泛化问题，先问"我的模型停在了什么样的地形上"，再选工具——调参、换优化器、还是改架构。
