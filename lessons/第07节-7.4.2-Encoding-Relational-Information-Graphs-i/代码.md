# Ch07 §7.4.2 编码关系信息：链接预测 · 代码.md

主线讲了两件事：链接预测（共同邻居预测未来连接）与节点分类（同质性让标签沿边传染）。本文件把**链接预测**做成可运行的实验：用图的大部分边训练"共同邻居"打分器，隐藏一条真实边（A–D），看它能否从所有"不存在的边"里被排到最前——这是"关系信息能预测未来连接"的机器验证。全篇手写，无黑盒。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 完整图：A–B–C–D 团、D–E–F–G 链（H 孤立）
names = ["A", "B", "C", "D", "E", "F", "G", "H"]
full = [("A","B"), ("A","C"), ("A","D"), ("B","C"), ("B","D"), ("C","D"),
        ("D","E"), ("E","F"), ("E","G"), ("F","G")]
hidden = ("A", "D")                                    # ③ 故意藏起来的一条真实边
edges = [e for e in full if e != hidden]               # 训练图：不含隐藏边

def adjacency(names, edges):                           # ④ 邻接矩阵
    idx = {n: i for i, n in enumerate(names)}
    A = np.zeros((len(names), len(names)), dtype=float)
    for u, v in edges:
        A[idx[u], idx[v]] = 1.0
        A[idx[v], idx[u]] = 1.0
    return A

def common_neighbors(A, i, j):                         # ⑤ 共同邻居打分
    return int((A[i] * A[j]).sum())

def predict_all(A, names):                             # ⑥ 给所有"缺失边"打分
    n = A.shape[0]
    scores = []
    for i in range(n):
        for j in range(i + 1, n):
            if A[i, j] == 0.0:                         # 只预测"还不存在"的边
                scores.append((common_neighbors(A, i, j), names[i], names[j]))
    return sorted(scores, reverse=True)

A = adjacency(names, edges)                            # ⑦ 当前图（不含隐藏边）
hi, hj = names.index("A"), names.index("D")
print("A–D 的共同邻居数：", common_neighbors(A, hi, hj))
pred = predict_all(A, names)
rank = next(i for i, (s, u, v) in enumerate(pred) if {u, v} == {"A", "D"})
print("预测排名（前 8，按共同邻居降序）：")
for i, (s, u, v) in enumerate(pred[:8]):
    mark = "  ← 隐藏的真实边" if {u, v} == {"A", "D"} else ""
    print(f"  #{i+1}: {u}–{v}  共同邻居 {s}{mark}")
print(f"\n隐藏边 A–D 排第 {rank+1} 名（共 {len(pred)} 对候选）")
```

输出：

```
A–D 的共同邻居数： 2
预测排名（前 8，按共同邻居降序）：
  #1: A–D  共同邻居 2  ← 隐藏的真实边
  #2: D–F  共同邻居 1
  #3: D–G  共同邻居 1
  #4: A–E  共同邻居 0
  #5: A–F  共同邻居 0
  #6: A–G  共同邻居 0
  #7: A–H  共同邻居 0
  #8: B–E  共同邻居 0
  ...
隐藏边 A–D 排第 1 名（共 19 对候选）
```

隐藏的真实边 A–D 被共同邻居打分器排到了第 1 名：训练图里 A 的邻居是 {B, C}，D 的邻居是 {B, C, E}，交集 {B, C} = 2 个共同邻居——全图最高分。**用"当前"的图预测"未来"的边，猜中了。** 这正是主线那句话的机器证明：已有的连接（B、C 同时认识 A 和 D）本身就预测了"下一根线"。

## 层二：分步逐函数拆解

### 步骤 1：定义邻接矩阵与共同邻居打分

```python
def adjacency(names, edges): ...
def common_neighbors(A, i, j):
    return int((A[i] * A[j]).sum())
```

#### common_neighbors —— 共同邻居 = 两行的逐位相乘再求和

`(A[i] * A[j]).sum()`

**操作**：`A[i]` 是节点 i 的邻居指示行（1 = 是邻居），`A[j]` 同理。`A[i] * A[j]` 逐位相乘：某位置同时为 1 当且仅当"既是 i 的邻居又是 j 的邻居"——即共同邻居。求和就是共同邻居个数。

**输入**：`A`（`(n,n)`）、`i`、`j`（节点下标）。

**输出**：int，$|\mathcal{N}(i) \cap \mathcal{N}(j)|$。

**可调参数**：
- 想升级成 **Adamic/Adar**：对每个共同邻居 $k$ 加权重 $1/\log d(k)$（度越小的共同邻居越有区分力）——实现就是把 `A[i] * A[j]` 的每个非零位乘上 $1/\log d(k)$ 再求和。
- 这条公式就是主线"共同邻居启发式"的代码形态，也是 §7.2 邻接矩阵内积性质（两行内积 = 共同邻居数）的又一次运用。

**对应数学**：主线第二节的链接预测启发式。共同邻居 = 两行向量的内积，直觉来源是"三元闭包"。

---

### 步骤 2：定义全对预测

```python
def predict_all(A, names):
    n = A.shape[0]
    scores = []
    for i in range(n):
        for j in range(i + 1, n):
            if A[i, j] == 0.0:
                scores.append((common_neighbors(A, i, j), names[i], names[j]))
    return sorted(scores, reverse=True)
```

#### predict_all —— 扫描所有缺失边，按共同邻居排序

`sorted(scores, reverse=True)`

**操作**：遍历所有节点对 `(i, j)`（`j > i` 避免重复），跳过已有边（`A[i,j] != 0`），对缺失边算共同邻居分。最后按分数降序排——**分数最高的缺失边 = 最可能出现的未来边**。

**输入**：`A`、`names`。

**输出**：降序排列的 `(score, u, v)` 列表。

**可调参数**：
- 只预测缺失边（`A[i,j]==0`）是标准做法——已存在的边不用预测。
- 取前 $k$ 名作为"推荐列表"（`pred[:k]`），对应社交平台的"你可能认识的人"。

**对应数学**：链接预测的问题设定——把"预测未来边"变成"给所有缺失边打分排序"。

---

### 步骤 3：主流程

```python
A = adjacency(names, edges)
hi, hj = names.index("A"), names.index("D")
print("A–D 的共同邻居数：", common_neighbors(A, hi, hj))
pred = predict_all(A, names)
rank = next(i for i, (s, u, v) in enumerate(pred) if {u, v} == {"A", "D"})
```

#### 主流程 —— 隐藏边、打分、看名次

**操作**：`edges` 不含隐藏边 A–D，`A` 是"当前"图；给 A–D 打分，再在 `predict_all` 的全排序里找它的名次。**名次越靠前，说明"关系信息预测未来连接"越成功。**

**输入**：图与隐藏边。

**输出**：A–D 的共同邻居数、它在全候选里的排名。

**可调参数**：隐藏不同的边、或隐藏多条边，观察排名变化——这是对"预测质量"的直观检验。想严格评估，可做"留出交叉验证"：随机藏 20% 的边，看被藏边平均排名。

**对应数学**：链接预测的评估范式——用部分图打分，看能否在未见的真实边里命中高分。

## 改个数字试试

### 实验 A：共同邻居越多，预测越准

把隐藏边改成 `("B", "E")`：训练图里 B 的邻居 {A, C, D}，E 的邻居 {D, F, G}，交集 {D} = 1 个共同邻居——排名会跌到与 D–F、D–G 并列的第 2 位之后。再改成 `("E", "H")`（H 是孤立点，共同邻居 0）——直接排到倒数。**共同邻居越多，越容易被正确预测**——这就是"结构重合度 → 关系概率"的直接验证。也可以反过来加边：给训练图加一条 `("B","E")`，A–D 的共同邻居不变（仍是 B、C），但新候选的排序会随之变化。

### 实验 B：退化为随机图——信号消失

把 `edges` 换成随机配对的边（共同邻居与"未来边"无关）。重跑会看到：隐藏边的排名退化为随机位置，共同邻居打分失去预测力。这验证了主线边界声明：**关系信息有用，前提是网络真的有"三元闭包"式的结构**；随机图里"共同朋友"什么也预测不了。

### 实验 C：升级打分——Adamic/Adar 权重

```python
def adamic_adar(A, i, j, degrees):
    common = np.where(A[i] * A[j] > 0)[0]
    return sum(1.0 / np.log(degrees[k] + 1.0) for k in common)
```

对每个共同邻居按 $1/\log d(k)$ 加权：**共同朋友越多但越"滥交"，说服力越低**。这个升级版在真实数据集上往往比纯计数更准——它把"共同朋友的质量"也算进了打分。

**呼应主线**：本实验用十几行代码证明了"已有的连接携带未来连接的信息"——共同邻居这个最简单的结构量，就能把隐藏边排到候选第一。这正是链接预测的机器形态：**图本身，就是一个自洽的预测器。**
