# 习题：马尔可夫链蒙特卡洛（MCMC）

## 第一组：概念检验

**1. 写出 Metropolis-Hastings 的接受概率公式，并解释每一部分。**

**解答**：$\alpha(x\to x')=\min\left(1,\frac{p(x')q(x|x')}{p(x)q(x'|x)}\right)$。$p$ 是目标分布（只需未归一化形状），$q(x'|x)$ 是从当前 $x$ 提议走到 $x'$ 的概率。分子"$x'$ 的目标高度 × 从 $x'$ 走回 $x$ 的提议概率"，分母反之；比值 $>1$ 时必接受（$\min$ 截到 1），$<1$ 时以该概率接受——**偶尔下坡，才能翻谷探峰**。

**2. 为什么 MCMC 只需要目标分布的"未归一化形状"？贝叶斯后验为什么因此特别受益？**

**解答**：接受概率里的 $p$ 同时出现在分子分母——归一化常数 $Z$（如 $P(D)$）会约掉。贝叶斯后验 $p(w|D)=\frac{P(D|w)P(w)}{P(D)}$ 的分母 $P(D)$ 不可算，但 $p(w|D)\propto P(D|w)P(w)$ 的"形状"随时可算——**MCMC 恰好只需要这个形状**。这就是为什么"后验不可归一化"在 MCMC 面前不再是障碍。

**3. 判断题并说明理由："MCMC 的 100000 个样本就是 100000 个独立样本。"**

**解答**：错误。MCMC 的样本构成一条马尔可夫链，**相邻样本高度相关**（每步只挪一小步）——"100000 个样本"的有效信息量（有效样本量 ESS）远小于 100000 个独立样本。估计方差时要考虑自相关；这也是为什么真实 MCMC 要检查 ESS、必要时抽稀（thinning）或加长链。

## 第二组：计算实践

**4. 手算 + 代码验证。** 教材例子：Metropolis-Hastings 生成 100000 样本，前 10000 作 burn-in。（a）为什么前 10000 个要丢弃？（b）用代码实现一个目标为标准正态的 MH，复现"burn-in 后样本 ≈ N(0,1)"。（c）检查均值/标准差。

**解答**：
（a）链的起点是任意的（可能在低概率区），刚起步时链的分布还是"起点的阴影"，未达平衡——**平衡之前采的样本不服从 $p$，会扭曲后验估计**。丢弃 burn-in = 等链"忘掉起点"再记账。
（b）（c）见《代码.md》层一：burn-in 后均值 -0.011、标准差 0.981，与 $\mathcal{N}(0,1)$ 贴合；直方图贴着真实曲线（复现教材 Figure 4.5）。

代码验证：

```python
import numpy as np
np.random.seed(0)
def mh(n, x0=0.0):
    x = x0; chain = []
    for _ in range(n):
        xp = x + np.random.normal(0, 1)
        if np.log(np.random.uniform()) < -0.5*xp**2 + 0.5*x**2:
            x = xp
        chain.append(x)
    return np.array(chain)
c = mh(100000)
after = c[10000:]
print("burn-in 后均值 =", round(after.mean(), 3), " 标准差 =", round(after.std(), 3))
```

输出：

```text
burn-in 后均值 = 0.002  标准差 = 0.998
```

**思路点拨**：若有人答"burn-in 就是热身，无所谓丢不丢"，那忽略了：不平衡期的样本会系统性地偏向起点附近，均值/方差估计都被污染——**丢 burn-in 不是浪费，是防止污染**。

**5. 步长实验。** 把提议步长 $\sigma$ 从 0.1 改到 10，观察接受率与链的探索能力（burn-in 后标准差），总结"步长太大/太小的症状"。

**解答**：见《代码.md》"改个数字试试"。$\sigma=0.1$：接受率 0.97（几乎全接受）但链走得太慢（探索不足，标准差偏低）；$\sigma=10$：接受率 0.14（几乎全拒绝，原地打转）；$\sigma=1$：接受率约 0.7——**经典甜区**。**步长太小"走得慢"，太大"不肯走"**，两者都导致混合差。

## 第三组：DL 延伸

**6. SGLD 场景。** 你想给深度学习的训练过程"免费"获得后验采样。SGLD（随机梯度 Langevin 动力学）的做法是：在 SGD 更新 $w_{t+1}=w_t-\eta_t\nabla\tilde L(w_t)$ 中额外加入高斯噪声。（a）SGLD 为什么能让"训练轨迹"收敛到后验？（b）它与标准 SGD 的本质区别？（c）用 MCMC 的语言解释"为什么深度学习训练本身可以被看成采样"。

**解答**：
（a）Langevin 动力学证明：带恰当方差高斯噪声的随机游走，其长期平衡分布就是目标分布。SGLD 把 SGD 的更新 + 高斯噪声组合起来——**噪声的方差与学习率匹配时，链的平衡分布收敛到后验 $p(w|D)$**。训练不再是"找一个点"，而是"在参数空间按后验散步"。
（b）标准 SGD 的噪声来自 batch 随机性（梯度估计噪声），且被学习率调度"磨平"——最终收敛到**一个点**（MAP 附近）；SGLD **故意保留并放大噪声**，让链持续"游走"，永不"钉死"——长期足迹分布就是后验。**一个是点估计，一个是分布采样。**
（c）从 MCMC 视角看，深度学习训练的每一步权重更新就是马尔可夫链的一步；batch 的随机性给链注入了噪声。**"训练 = 在权重空间走一条马尔可夫链"**——SGD 是"用噪声找最优点"，SGLD 是"用噪声逛后验"。这也是"训练即采样"（training as inference）思想的核心。
**思路点拨**：若有人答"SGLD 就是加了噪声的 SGD，没什么区别"，他忽略了"噪声的角色"完全不同——SGD 的噪声是讨厌的干扰（要衰减掉），SGLD 的噪声是必需的能量（要保留才能逛遍分布）。若有人答"MCMC 和深度学习没关系"，SGLD 就是反例——**它证明深度学习已有的训练过程，稍加改造就是贝叶斯采样**。
