# 习题：吉布斯采样

## 第一组：概念检验

**1. 写出二维 Gibbs 采样的更新规则，并解释为什么第二步要用"新"的 X 而不是旧的。**

**解答**：$X^{(t+1)}\sim p(X|Y^{(t)})$，$Y^{(t+1)}\sim p(Y|X^{(t+1)})$。第二步必须用刚更新的 $X^{(t+1)}$，因为条件分布 $p(Y|X)$ 要"给定 $X$ 的当前值"——只有用最新状态，每步转移才精确对应条件分布，链才能朝联合分布收敛。**用旧 $X$ 会让更新失去"当前状态"的信息，破坏马尔可夫链的正确性。**

**2. Gibbs 与 Metropolis-Hastings 相比，省掉了什么、又有什么前提？**

**解答**：省掉了两件事——**提议分布的设计**（$q(x'|x)$）和**接受/拒绝**（$\alpha$，可能拒绝浪费算力）。Gibbs 每步从条件分布精确采样、无拒绝。前提是**每个坐标的条件分布都能采样**：条件分布是已知分布（正态等）时最顺，条件分布也复杂时 Gibbs 会退化得很慢。**Gibbs 是"条件分布好采"时的省心神器。**

**3. 判断题并说明理由："Gibbs 采样的每步都精确，所以它的样本比 Metropolis-Hastings 更独立。"**

**解答**：错误。每步"精确"说的是"采样的分布正确"（从正确的条件分布采样），不是"样本独立"。Gibbs 的相邻样本同样高度自相关（每步只更新一个坐标，其他坐标保持原值）——$\rho$ 大时自相关甚至接近 1。**"无拒绝"≠"独立"**，两者都要靠有效样本量（ESS）评估。

## 第二组：计算实践

**4. 手算 + 代码验证。** 目标为二元正态，均值 $(0,0)$、方差 1、$\rho=0.8$。（a）写出条件分布 $p(X|Y)$、$p(Y|X)$。（b）代码跑 10000 轮，验证样本的均值/方差/相关系数。（c）固定 $Y\approx0.8$，检查 $X$ 的均值。

**解答**：
（a）$p(X|Y)=\mathcal{N}(0.8Y,\ 0.36)$，$p(Y|X)=\mathcal{N}(0.8X,\ 0.36)$（$1-\rho^2=1-0.64=0.36$）。
（b）见《代码.md》步骤 3：均值 $(0.001,-0.002)$、方差 $(0.994,1.001)$、相关系数 0.799——全贴理论。
（c）条件切片 $Y\approx0.8$ 时 $X$ 均值 0.640，理论 $\rho\cdot0.8=0.64$——**条件结构也被重现**。

代码验证：

```python
import numpy as np
np.random.seed(0)
rho = 0.8
X, Y = 0.0, 0.0; s = []
for _ in range(10000):
    X = np.random.normal(rho*Y, np.sqrt(1-rho**2))
    Y = np.random.normal(rho*X, np.sqrt(1-rho**2))
    s.append((X, Y))
s = np.array(s[200:])
print("均值 =", s.mean(axis=0).round(3), " 相关系数 =", round(np.corrcoef(s[:,0], s[:,1])[0,1], 3))
```

输出：

```text
均值 = [0.001 -0.002]  相关系数 = 0.799
```

**思路点拨**：若有人困惑"为什么只给条件分布就能重现联合分布"，答案是：联合分布由其条件分布（切片）唯一确定。**Gibbs 的本质是"每个切片都正确，联合分布自然正确"。**

**5. ρ 扫描实验。** 把 $\rho$ 从 0 改到 0.95，观察相邻样本自相关，总结 Gibbs 收敛速度与坐标耦合的关系。

**解答**：见《代码.md》"改个数字试试"。$\rho=0$ 自相关 0.006（链几乎独立），$\rho=0.5$ 时 0.390，$\rho=0.95$ 时 0.954——**坐标越耦合，链每步挪得越少、收敛越慢**。这正是教材说 Gibbs"特别适合分量条件独立"的原因。

## 第三组：DL 延伸

**6. LDA 主题模型场景。** 你在用 LDA 做主题建模，文档里的每个词要分配一个主题 $z_i$。（a）为什么 Gibbs 是 LDA 推断的标准工具？（b）Gibbs 在这里"轮流更新"的"坐标"是什么？（c）LDA 的 Gibbs 为什么能工作——它的条件分布为何可采样？

**解答**：
（a）LDA 的后验（给定文档的词主题分配）高维复杂、无法直接采样，但"给定所有其他词的主题分配，某个词的主题的条件分布"是可计算的——这正是 Gibbs 的适用条件：**轮流更新、只用条件分布、无需提议分布**。
（b）"坐标"是每个词的**主题分配** $z_i$：每轮遍历所有词，从"给定当前所有其他词主题下，该词属于各主题的概率"采一个新主题。一轮一轮转，最终主题分配收敛到后验。
（c）LDA 的条件分布 $P(z_i=k|z_{-i},w)$ 有闭式形式——它正比于"主题 $k$ 中出现该词的比例"×"该文档属于主题 $k$ 的比例"，两个计数都能从当前分配直接数出来。**条件分布是"计数比"，能算就能采**——这是 LDA + Gibbs 能落地全部的原因。
**思路点拨**：若有人答"LDA 用 EM 或梯度下降训练"，那是混淆了"点估计"与"贝叶斯后验采样"——LDA 的贝叶斯版本要的是主题分配的分布（后验），Gibbs 采样正是为此。若有人困惑"为什么计数能当采样"，因为他看到了 Gibbs 的精髓：**条件分布只要"正比于什么"就能采样**（配合归一化），正如 MH 只需要未归一化形状。
