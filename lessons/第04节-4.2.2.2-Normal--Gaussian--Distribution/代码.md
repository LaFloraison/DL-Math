# 代码：正态分布——把一座钟写进函数，让积分和抽样共同验算

主线里我们认识了正态分布这座钟：$\mu$ 决定它在哪，$\sigma$ 决定它多胖，公式 $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ 是它唯一的身份证。本课用代码做三件事：

1. **量密度**：在教材的身高例（$\mu=170, \sigma=10$）上算出峰顶、1σ、2σ 处的具体密度。
2. **验归一化**：用梯形法则确认整座钟的面积是 1。
3. **验经验法则**：用数值积分验证 68/95/99.7 三个著名数字，再用抽样从另一个方向逼近 68%。

我们不调用现成的分布类，只用手写公式 + `np.trapz`——这样你才能看见那座钟的每一个零件。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：sqrt / pi / exp / trapz / linspace

def normal_pdf(x, mu, sigma):             # ① 密度：归一化因子 × 钟形内核
    """正态密度：以 mu 为中心、sigma 决定胖瘦的钟形。"""
    return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))

# ---- ① 教材的数字：身高 N(170, 100)，即 mu=170, sigma=10 ----
mu, sigma = 170.0, 10.0
print(f"f(170) = {normal_pdf(mu, mu, sigma):.6f}   # 峰顶密度 = 1/(σ√(2π)) ≈ 0.0399")
print(f"f(180) = {normal_pdf(180.0, mu, sigma):.6f}   # 距均值 1σ，密度降到峰顶的 e^{-1/2} 倍")
print(f"f(190) = {normal_pdf(190.0, mu, sigma):.6f}   # 距均值 2σ，密度进一步衰减")

# ---- ② 归一化裁决：∫ f(x) dx ≈ 1 ----
x = np.linspace(120.0, 220.0, 10001)      # μ±5σ，把钟的裙边都包进来
area = np.trapz(normal_pdf(x, mu, sigma), x)
print(f"∫ N(170,10) ≈ {area:.6f}   # 理论值 1")

# ---- ③ 经验法则验证：68/95/99.7 ----
x68  = np.linspace(mu - sigma, mu + sigma, 10001)
x95  = np.linspace(mu - 2*sigma, mu + 2*sigma, 10001)
x997 = np.linspace(mu - 3*sigma, mu + 3*sigma, 10001)
print(f"P(μ±σ)  = {np.trapz(normal_pdf(x68, mu, sigma), x68):.4f}   # 理论 0.6827")
print(f"P(μ±2σ) = {np.trapz(normal_pdf(x95, mu, sigma), x95):.4f}   # 理论 0.9545")
print(f"P(μ±3σ) = {np.trapz(normal_pdf(x997, mu, sigma), x997):.4f}   # 理论 0.9973")

# ---- ④ 抽样逼近：np.random.normal 抽 20 万次，数落在 μ±σ 的比例 ----
np.random.seed(0)
samples = np.random.normal(loc=mu, scale=sigma, size=200000)
empirical = np.mean(np.abs(samples - mu) <= sigma)
print(f"抽样落在 μ±σ 的比例 = {empirical:.4f}   # 理论 0.6827，大数定律把它拉回来")
```

运行输出（Python 3.11 + NumPy）：

```text
f(170) = 0.039894   # 峰顶密度 = 1/(σ√(2π)) ≈ 0.0399
f(180) = 0.024197   # 距均值 1σ，密度降到峰顶的 e^{-1/2} 倍
f(190) = 0.005399   # 距均值 2σ，密度进一步衰减
∫ N(170,10) ≈ 1.000000   # 理论值 1
P(μ±σ)  = 0.6827   # 理论 0.6827
P(μ±2σ) = 0.9545   # 理论 0.9545
P(μ±3σ) = 0.9973   # 理论 0.9973
抽样落在 μ±σ 的比例 = 0.6818   # 理论 0.6827，大数定律把它拉回来
```

公式、经验法则、抽样三个方向全部对上了。下面拆开每一行。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

#### `import numpy as np` —— 引入数值计算工具箱

**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：$\sqrt{2\pi}$ 里的 $\pi$ 从 `np.pi` 来，$e^{(\cdot)}$ 从 `np.exp` 来。

### 步骤 2：定义 `normal_pdf` —— 钟形曲线的两个因子

```python
def normal_pdf(x, mu, sigma):
    """正态密度：以 mu 为中心、sigma 决定胖瘦的钟形。"""
    return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))
```

#### normal_pdf —— 正态分布的密度：归一化因子 × 钟形内核

`return 1.0 / (sigma * np.sqrt(2.0 * np.pi)) * np.exp(-(x - mu)**2 / (2.0 * sigma**2))`

**做什么**：对每个点算出该点的正态密度——把"离均值多远"翻译成"密度多高"。
**操作**：公式分成相乘的两块。前面 $1/(\sigma\sqrt{2\pi})$ 是**归一化因子**，只管把总面积压到 1；后面 $\exp\!\big(-\frac{(x-\mu)^2}{2\sigma^2}\big)$ 是**钟形内核**，决定形状。`(x - mu)**2` 逐元素算每个点到均值的平方距离；除以 `2.0 * sigma**2` 后取 `np.exp`。
**输入**：
- `x`：标量或任意形状数组，待求密度的点。
- `mu`（均值，mean）：钟形对称中心，也是密度最高点。教材例子里是身高 $\mu=170$ cm。
- `sigma`（标准差，standard deviation）：钟形胖瘦。教材例子 $\sigma=10$ cm。
**输出**：与 `x` 同形状的数组，每个位置是该点的密度，恒为正。
**可调参数**：
- `mu`：平移整座钟。`mu` 只影响"哪里是中心"，不影响形状。
- `sigma`：决定胖瘦和峰高。峰高 $1/(\sigma\sqrt{2\pi})$ 与 $\sigma$ 成反比——$\sigma$ 越大钟越矮胖，越小越高瘦，总面积恒为 1。
- 还能不能加参数？`x, mu, sigma` 已完备。有人把 $\sigma^2$（方差）单独提出来当参数，写成 `normal_pdf(x, mu, var)`——如果这么写，记得内部要 `np.sqrt(var)` 转回 $\sigma$。教材直接给 $\mu,\sigma$，我们照教材来。

**为什么是 `np.sqrt(2.0 * np.pi)`？** 内核 $\exp(-\frac{(x-\mu)^2}{2\sigma^2})$ 不会自己归一——它在整条实数轴上积分出来是 $\sigma\sqrt{2\pi}$（高斯积分 $\int_{-\infty}^{\infty}e^{-t^2}dt=\sqrt{\pi}$ 的伸缩版）。要让总面积等于 1，唯一的办法是**除以它自己积出来的面积**——归一化因子 $1/(\sigma\sqrt{2\pi})$ 就这样被迫诞生。它是除法，不是装饰。

**`np.exp(-(x - mu)**2 / (2.0 * sigma**2))` 在说什么？** 指数里是标准化的平方距离 $\frac{(x-\mu)^2}{2\sigma^2}$。当 $x=\mu$ 时指数为 0，$e^0=1$，密度取峰顶；当 $x=\mu\pm\sigma$ 时指数为 $-1/2$，密度降到峰顶的 $e^{-1/2}\approx0.6065$——这正是输出里 180 处 0.024197 ≈ 0.039894 × 0.6065 的来源。平方把偏离放大成"偏离²"，离得越远密度掉得越狠——这是"越远离均值越不可能"的精确版本。
**对应数学**：主线里 $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ 逐符号翻译。

### 步骤 3：在特定点上量密度

```python
mu, sigma = 170.0, 10.0
print(f"f(170) = {normal_pdf(mu, mu, sigma):.6f}   # 峰顶密度 = 1/(σ√(2π)) ≈ 0.0399")
print(f"f(180) = {normal_pdf(180.0, mu, sigma):.6f}   # 距均值 1σ，密度降到峰顶的 e^{-1/2} 倍")
print(f"f(190) = {normal_pdf(190.0, mu, sigma):.6f}   # 距均值 2σ，密度进一步衰减")
```

**做什么**：在峰顶、1σ、2σ 三个"有故事"的点上把公式算成具体的数。
**操作**：f-string 把表达式求值并格式化；`normal_pdf(mu, mu, sigma)` 就是把 $x=\mu$ 代入（峰顶）。
**输入**：三个横坐标。
**输出**：三行文本。
**可调参数**：可换成任何点——比如 `normal_pdf(160.0, 170.0, 10.0)`（距均值 1σ 的另一侧，因对称应得与 180 相同的 0.024197）。
**对应数学**：密度不是概率——$f(180)=0.0242$ 是"180 cm 附近单位长度上的浓度"，概率要积分。峰的左右对称（$f(160)=f(180)$）是公式里平方项的功劳。

### 步骤 4：`np.trapz` 验证归一化与经验法则

```python
x = np.linspace(120.0, 220.0, 10001)
area = np.trapz(normal_pdf(x, mu, sigma), x)
x68  = np.linspace(mu - sigma, mu + sigma, 10001)
p68  = np.trapz(normal_pdf(x68, mu, sigma), x68)
```

#### `np.linspace(start, stop, N)` —— 生成等距网格

**操作**：在 $[start, stop]$ 上生成 $N$ 个等间距点，首尾包含。
**输入**：`start`、`stop`、`N`。
**输出**：长度 $N$ 的一维数组。`np.linspace(120.0, 220.0, 10001)` 得到 10001 个点，间距 $dx = (220-120)/10000 = 0.01$。
**可调参数**：`N` 越大越准。网格区间为什么取 $\mu\pm5\sigma$？因为 $5\sigma$ 已覆盖 99.99994% 的面积，把尾巴包得几乎完整。
**对应数学**：$\int_{-\infty}^{\infty}f(x)\,dx=1$ 的近似——"总面积恒为 1"这一合法性的数字证据。

#### `np.trapz(y, x)` —— 梯形法则数值积分

**操作**：把曲线下方切成 $N-1$ 个细长梯形，每个以相邻两点 $x_i,x_{i+1}$ 上的函数值为上下底，面积 $\frac{y_i+y_{i+1}}{2}\cdot dx$，全部相加。
**输入**：`y`（函数值数组 `(N,)`）、`x`（横坐标数组 `(N,)`）。
**输出**：标量近似值。
**可调参数**：第二参数可传标量 `dx`；网格密度是主旋钮。注意 `np.trapz` 在新版 NumPy（≥2.0）更名为 `np.trapezoid`，结果一致。
**对应数学**：归一化（对整个 $\mathbb{R}$）和经验法则（对 $\mu\pm k\sigma$ 的区间）都是同一个积分操作，只是积分限不同。$P(\mu-\sigma\le X\le\mu+\sigma)=\int_{\mu-\sigma}^{\mu+\sigma}f(x)\,dx\approx0.6827$——这就是教材里"约 68%"的精确来历。

### 步骤 5：抽样逼近经验法则

```python
np.random.seed(0)
samples = np.random.normal(loc=mu, scale=sigma, size=200000)
empirical = np.mean(np.abs(samples - mu) <= sigma)
```

#### `np.random.normal(loc, scale, size)` —— 从正态分布抽样本

**操作**：在 $[-\infty,\infty]$ 上按密度 $f(x)$ 抽取 `size` 个独立样本，均值为 `loc`、标准差为 `scale`。底层用 Box-Muller 变换：把均匀随机数对 $u_1,u_2$ 通过 $\sqrt{-2\ln u_1}\cos(2\pi u_2)$ 变成标准正态，再缩放平移。
**输入**：
- `loc`：均值 $\mu$。
- `scale`：标准差 $\sigma$。
- `size`：样本数。
**输出**：形状 `(200000,)` 的数组，近似服从 $\mathcal{N}(\mu,\sigma^2)$。
**可调参数**：`size` 可传元组返回多维数组；`scale` 决定散布。注意这里第三个参数是**标准差**不是方差——跟记号 $\mathcal{N}(\mu,\sigma^2)$ 里的第二个量刚好相反，写代码时别踩教材的那个坑。

#### `np.abs(samples - mu) <= sigma` 与 `np.mean` —— 数"离均值不超 1σ"的比例

**操作**：`np.abs(samples - mu)` 逐元素算每个样本离均值的距离；`<= sigma` 生成布尔数组；`np.mean` 求比例（`True` 当 1）。
**输入**：样本数组、$\mu$、$\sigma$。
**输出**：标量 `0.6818`。
**可调参数**：把 `<= sigma` 换成 `<= 2*sigma` 就验证 95% 法则。`size` 越大收敛越好——`size=100` 时可能在 0.65 到 0.71 之间晃，`size=200000` 时稳定在 0.682 附近。
**对应数学**：经验法则的统计视角。积分给精确值 0.6827，抽样给近似值 0.6818，两者靠大数定律握手——这是"理论 vs 频率"的再一次对照。

## 改个数字试试：把参数推向极端

### 实验 1：σ 缩到 3，钟变尖

```python
x3 = np.linspace(155.0, 185.0, 10001)
print(f"sigma=3 峰顶密度 = {normal_pdf(170.0, 170.0, 3.0):.6f}   # 原 σ=10 时是 0.039894")
print(f"sigma=3 归一化   = {np.trapz(normal_pdf(x3, 170.0, 3.0), x3):.6f}")
```

输出：

```text
sigma=3 峰顶密度 = 0.132981   # 原 σ=10 时是 0.039894
sigma=3 归一化   = 1.000000
```

σ 从 10 缩到 3，峰顶密度 0.039894 → 0.132981，涨了约 3.3 倍。因为峰高与 σ 成反比——σ 缩到 3/10，峰高涨到 10/3 倍。面积守恒逼着曲线把变矮的宽度"还"回高度：钟变尖、变瘦、变高。归一化依然是 1——**参数怎么改，面积永远守约**。你在模型里看到"方差小的预测，置信区间窄而尖"时，看到的就是这座被捏紧的钟。

### 实验 2：μ 平移到 0，形状不变

```python
print(f"N(0,1) 峰顶 = {normal_pdf(0.0, 0.0, 1.0):.6f}   # 标准正态，峰顶 1/√(2π)")
print(f"N(0,1) 在 1 = {normal_pdf(1.0, 0.0, 1.0):.6f}   # 标准正态在 1σ 处，与 f(180)/f(170) 同比例")
```

输出：

```text
N(0,1) 峰顶 = 0.398942   # 标准正态，峰顶 1/√(2π)
N(0,1) 在 1 = 0.241971   # 标准正态在 1σ 处，与 f(180)/f(170) 同比例
```

任何正态分布都是标准正态 $\mathcal{N}(0,1)$ 的平移加缩放——$\frac{x-\mu}{\sigma}\sim\mathcal{N}(0,1)$ 这个变换让"身高"问题变成"标准尺子"问题。你只需要一张标准正态的表（或一次标准抽样），就能回答所有正态分布的问题。

## 边界声明：这套代码能做什么，不能做什么

1. **打印出来的密度不是概率。** $f(180)=0.0242$ 是"180 cm 附近单位长度的浓度"，不是"恰好 180 cm 的概率"（连续分布单点概率恒为 0）。概率必须积分——`np.trapz` 干的就是这个。
2. **"长得像钟"不等于正态。** 这段代码验证的是"**如果**数据服从正态，那么……"。它不能告诉你"这些数据是不是正态"。要判断是否正态，需要用 Q-Q 图或正态性检验（如 Shapiro-Wilk），那是统计检验的领域。
3. **68/95/99.7 是正态专属。** 经验法则只对这一座钟成立。换成指数分布、均匀分布，同样的区间概率完全不同。别把"大约 68%"背成对所有分布的通用结论。
4. **这只是验算工具。** 真实建模不会手写 PDF 再数值积分——NumPy 有 `np.random.normal` 直接抽样，SciPy 有 `scipy.stats.norm` 的完整分布对象。但那些封装背后，正是这条公式和这座钟在做同一件事。
