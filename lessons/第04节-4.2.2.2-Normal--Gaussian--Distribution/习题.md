# 习题：正态分布

## 第一组：概念检验

**1. $\mathcal{N}(0, 4)$ 的标准差是多少？$\mathcal{N}(0, 1)$ 呢？这个记号藏了什么样的坑？**

**解答**：$\mathcal{N}(0,4)$ 的标准差是 2，方差是 4——记号 $\mathcal{N}(\mu,\sigma^2)$ 里括号中的第二个量是**方差**。$\mathcal{N}(0,1)$ 是标准正态，均值 0、方差 1、标准差 1。坑在于：如果误把第二个量当标准差，会以为 $\mathcal{N}(0,4)$ 的散布比实际小一半。读论文、写代码时（如 `np.random.normal(loc, scale, ...)`，其中 `scale` 是标准差）必须时刻分清"给的是方差还是标准差"。

**2. 为什么正态分布的密度函数里必须有那个 $1/(\sigma\sqrt{2\pi})$ 因子？去掉它行不行？**

**解答**：不行。内核 $e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ 在整个实数轴上积分出来是 $\sigma\sqrt{2\pi}$，不等于 1——如果直接用内核当密度，总概率就不是 1，它就不够格称为概率密度。$1/(\sigma\sqrt{2\pi})$ 是**归一化因子**：除以内核自己积出来的面积，把总面积压回 1。它不是装饰，是一场必要的除法。

**3. 一个同学说"我的数据画出来也是中间高两边低，所以它一定服从正态分布"。指出他推理中的错误。**

**解答**：错误在把"形状像钟"当成了"是正态"。中间高、两边低、左右对称的曲线有无数条——抛物线、余弦、三角形都符合这个外形描述。正态分布必须是那个精确公式 $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$。判断数据是否正态不能靠眼睛看形状，要靠 Q-Q 图或正态性检验。这正好呼应主线的边界声明："长得像钟"不等于正态。

## 第二组：计算实践

**4. 手算 + 代码验证。** 设 $X\sim\mathcal{N}(170, 100)$（身高，cm）。（a）$\mathrm{P}(160 \le X \le 180)$ 约为多少？（b）$X$ 落在 150 以下大约占多少比例？（c）$\mathrm{P}(X=170)$ 是多少？

**解答**：
（a）$\mu=170$，$\sigma=\sqrt{100}=10$。区间 $[160,180]=[\mu-\sigma,\mu+\sigma]$，由经验法则 $\approx 0.6827$（约 68%）。
（b）$150 = \mu - 2\sigma$。$\mathrm{P}(X \le \mu-2\sigma) = \frac{1-0.9545}{2} = 0.02275$（约 2.3%）。因为 $[\mu-2\sigma,\mu+2\sigma]$ 占了 95.45%，两侧尾巴平分剩下的 4.55%。
（c）$\mathrm{P}(X=170)=0$——连续分布单点概率恒为 0。身高的"恰好 170.000 cm"追不上也装不下。

代码验证（用 CDF 的积分近似）：

```python
import numpy as np
mu, sigma = 170.0, 10.0
def norm_cdf_approx(t, mu, sigma, dx=0.001):
    x = np.arange(mu - 6*sigma, t, dx)          # 从足够远处积分到 t
    pdf = 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))
    return np.sum(pdf) * dx
print("P(160<=X<=180) ≈", norm_cdf_approx(180, mu, sigma) - norm_cdf_approx(160, mu, sigma))
print("P(X<=150)      ≈", norm_cdf_approx(150, mu, sigma))
```

输出：

```text
P(160<=X<=180) ≈ 0.682689
P(X<=150)      ≈ 0.022744
```

**思路点拨**：这是连续分布 + 对称性的组合题。若有人把 (b) 答成 4.55%，那是在两端尾巴之间忘记除以 2。经验法则给的是"±2σ 之内"，而"150 以下"在**一条**尾巴上，要再除 2。

**5. 用抽样验证经验法则。** 从 $\mathcal{N}(0,1)$ 抽 50 万次，统计落在 $(-1,1)$、$(-2,2)$、$(-3,3)$ 的比例，并与 68/95/99.7 对照。

**解答**：

```python
import numpy as np
np.random.seed(0)
s = np.random.normal(0.0, 1.0, 500000)
for k in (1, 2, 3):
    print(f"P(|X|<= {k}σ) = {np.mean(np.abs(s) <= k):.4f}")
```

输出（每次略有不同）：

```text
P(|X|<= 1σ) = 0.6826
P(|X|<= 2σ) = 0.9543
P(|X|<= 3σ) = 0.9973
```

与理论 0.6827 / 0.9545 / 0.9973 高度吻合。样本多到 50 万，频率几乎贴着概率。**思路点拨**：抽样结果每次都会抖一点点（换 seed 试试），这是随机性的本质；大数定律保证抖动的幅度随样本数增大而收缩。理论给精确，抽样给验证。

## 第三组：DL 延伸

**6. VAE 场景。** 变分自编码器的编码器输出隐变量的均值 $\mu(x)$ 和方差 $\sigma^2(x)$，生成阶段要从 $\mathcal{N}(\mu(x), \sigma^2(x))$ 抽样出 $z$。但"抽样"这个操作没有梯度，梯度无法反传。请你解释重参数化技巧 $z = \mu(x) + \sigma(x)\odot\epsilon$（$\epsilon\sim\mathcal{N}(0,I)$）为什么能解决问题，以及 $\odot$ 在做什么。

**解答**：问题在于"从 $\mathcal{N}(\mu,\sigma^2)$ 抽样"是随机操作，它对 $\mu$ 和 $\sigma$ 的导数无法通过随机性传播。重参数化把随机性**外包**给一个与参数无关的固定噪声源 $\epsilon\sim\mathcal{N}(0,I)$：$z = \mu + \sigma\odot\epsilon$。此时 $z$ 对 $\mu$ 的梯度就是 1，对 $\sigma$ 的梯度就是 $\epsilon$——梯度可以畅通地流回编码器，去更新 $\mu(x)$ 和 $\sigma^2(x)$。$\odot$ 是逐元素相乘 (element-wise/Hadamard product)：$\mu$ 和 $\sigma$ 是 $d$ 维向量，$\epsilon$ 也是 $d$ 维，逐位相乘得到 $d$ 维的 $z$。因为 $\mu+\sigma\epsilon$ 的分布恰好是 $\mathcal{N}(\mu,\sigma^2)$（正态的线性变换仍是正态），"重参数化的 $z$"和"直接抽样的 $z$"分布相同，只是前者可导。
**思路点拨**：若有人回答"把抽样放到训练之后"，那是误解——生成阶段本来就要抽样，重参数化要解决的是**训练阶段的梯度流**。核心是"随机性从参数里搬出去，参数只剩可导的确定性映射"。
