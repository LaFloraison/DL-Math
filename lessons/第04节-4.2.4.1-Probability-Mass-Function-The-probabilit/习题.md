# 习题：概率质量函数（PMF）

## 第一组：概念检验

**1. 掷两枚硬币，$X$=正面个数。写出 $X$ 的 PMF，并说明三条铁律如何被满足。**

**解答**：$p(0)=\frac14,\ p(1)=\frac12,\ p(2)=\frac14$。铁律一：三个值都非负；铁律二：$\frac14+\frac12+\frac14=1$；铁律三：对 $X\notin\{0,1,2\}$（如 $p(3)$），概率为 0——抛两枚不可能出 3 个正面。

**2. 判断题并说明理由："PMF 里的每个值 $p(x)$ 都是概率，所以一定在 0 和 1 之间；PDF 里的每个值 $f(x)$ 也是概率，所以也在 0 和 1 之间。"**

**解答**：前半句对，后半句错。PMF 的 $p(x)$ 是**概率本身**，必在 $[0,1]$。PDF 的 $f(x)$ 是**密度**，不是概率——可以大于 1（如 $\text{Uniform}(0,0.5)$ 的密度是 2）。"$f(x)\le1$"是连续分布世界最常见的错误直觉之一，因为曲线高度经常"看起来像概率"。

**3. 为什么离散分布用"质量"，连续分布用"密度"？这组命名想强调什么？**

**解答**：离散的概率像**一堆堆在点上的物质**（point mass）——0 处一堆 $\frac14$，1 处两堆 $\frac14$；连续的概率像**铺开的浓度**——需要乘区间的宽度（积分）才得到概率。命名强调：离散按"点"记账（求和），连续按"面积"记账（积分）。混淆两者是初学者犯错的头号来源。

## 第二组：计算实践

**4. 手算 + 代码验证。** 掷一个公平骰子，$X$=点数。写出 PMF 并验证 $\sum p(x)=1$；再用代码算 $P(X\ge4)$ 和 $P(X \text{为偶数})$。

**解答**：$p(x)=\frac16$ 对 $x=1,\dots,6$。$\sum_{x=1}^6\frac16=1$。$P(X\ge4)=\sum_{x=4}^6\frac16=\frac12$。$P(X\text{偶数})=p(2)+p(4)+p(6)=\frac12$。

代码验证：

```python
import numpy as np
pmf = np.full(6, 1/6)                     # 每个点数概率 1/6
print("总和 =", pmf.sum())
print("P(X>=4) =", pmf[3:].sum())         # 下标 3 对应点数 4
print("P(X 偶数) =", pmf[[1, 3, 5]].sum())  # 点数 2,4,6
```

输出：

```text
总和 = 1.0
P(X>=4) = 0.5
P(X 偶数) = 0.5
```

**思路点拨**：若有人答"$P(X\ge4)=\frac36$ 但说不清为什么下标是 3"，提醒他：数组下标 0 对应点数 1，`pmf[3:]` 是点数 4、5、6。**数组下标和取值不是一回事**，这是用代码做概率时最常见的错位。

**5. 用代码验证"频率 → PMF"。** 抛 20 次硬币（或抽 20 次二项），统计出现 0..20 个正面的频率，与理论 PMF 对比——样本量从 100 涨到 100 万，误差如何收敛？

**解答**：

```python
import numpy as np
np.random.seed(0)
from math import comb
def pmf(k, n=20, p=0.5):
    return comb(n, k) * (0.5**k) * (0.5**(n-k))
for size in (100, 10000, 1000000):
    s = np.random.binomial(n=20, p=0.5, size=size)
    err = max(abs(np.mean(s == k) - pmf(k)) for k in range(21))
    print(f"size={size:>7}: 最大频率误差 = {err:.4f}")
```

输出（大致）：

```text
size=    100: 最大频率误差 = 0.0573
size=  10000: 最大频率误差 = 0.0046
size=1000000: 最大频率误差 = 0.0005
```

样本量每涨 100 倍，误差约缩 10 倍——**平方根定律**。频率是对理论 PMF 的估计，误差随 $\sqrt{\text{size}}$ 下降。**思路点拨**：这是"PMF 是理论、频率是估计"的最直观证据，也是蒙特卡洛方法（§4.3.6）的提前热身。

## 第三组：DL 延伸

**6. 分类器场景。** 一个三分类网络输出 logits $z=[2.0,\ 1.0,\ 0.1]$。（a）用 softmax 算出输出的 PMF。（b）如果真实标签是"第 0 类"（one-hot 是 $[1,0,0]$），说出交叉熵损失大致大小及含义。（c）softmax 输出的 $p_k$ 为什么必然满足 PMF 的三条铁律？

**解答**：
（a）$e^{2.0}\approx7.39$，$e^{1.0}\approx2.72$，$e^{0.1}\approx1.105$，分母 $\approx11.21$。于是 $p=[7.39/11.21,\ 2.72/11.21,\ 1.105/11.21]\approx[0.659,\ 0.243,\ 0.099]$。
（b）$\mathcal{L}=-\sum_k y_k\log p_k=-\log p_0=-\log 0.659\approx0.417$。它衡量"模型对真实类（第 0 类）的自信度"——$p_0$ 越接近 1，损失越小；模型还不完全确定，损失约 0.42。
（c）三条铁律自动成立：$p_k=\frac{e^{z_k}}{\sum_j e^{z_j}}$ 中分子指数恒正 → 非负；分母是分子之和 → 归一（$\sum_k p_k=1$）；定义域就是 K 个类别，对类别之外没有定义。**softmax 是"把任意分数变成合法 PMF"的机器。**
**思路点拨**：若有人想"把 logits 直接当概率"，那是忘了 logits 可能是负数、且不归一的——它只是分数，不是 PMF。softmax 存在的全部理由，就是把"分数"翻译成"合法概率"。若有人答 $p_1$ 是"类别 1 的概率"，提醒他 softmax 里指数和归一化已经做完——输出就是可直接读的概率。
