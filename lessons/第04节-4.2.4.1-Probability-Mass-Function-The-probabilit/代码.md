# 代码：PMF——把"每个点的质量"写进函数，让柱子总和被当场验证

主线里我们把 PMF 定义为"离散随机变量恰好取某个值的概率"，并立下三条铁律：非负、总和为 1、只对可能值有意义。教材给的最干净的例子是抛两枚硬币数正面：$P(X=0)=1/4,\ P(X=1)=1/2,\ P(X=2)=1/4$。本课用代码做三件事：

1. **手写二项 PMF**：用 $\binom{n}{k}p^k(1-p)^{n-k}$ 直接算出抛两枚硬币的三个概率。
2. **验铁律**：检查三项是否非负、是否总和为 1。
3. **对照抽样**：从二项分布抽 10 万次，看频率柱子的高度是否逼近理论 PMF——大数定律的现场。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：binom 需要 math.comb，这里用浮点对数避免溢出

def binomial_pmf(k, n, p):
    """二项 PMF：C(n,k) p^k (1-p)^(n-k)。k 是成功次数。"""
    from math import comb
    return comb(n, k) * (p**k) * ((1.0 - p)**(n - k))

# ---- ① 抛两枚硬币（n=2, p=0.5）：正面次数 0/1/2 的 PMF ----
n, p = 2, 0.5
ks = np.arange(0, n + 1)
pmf = np.array([binomial_pmf(k, n, p) for k in ks])
for k, prob in zip(ks, pmf):
    print(f"P(X={k}) = {prob:.4f}")

# ---- ② 铁律检验：非负？总和为 1？----
print(f"所有概率非负: {np.all(pmf >= 0)}")
print(f"总和 = {pmf.sum():.6f}   # 应为 1")

# ---- ③ 区间概率：P(1 <= X <= 2) ----
print(f"P(1<=X<=2) = {pmf[1:].sum():.4f}   # p(1)+p(2) = 3/4")

# ---- ④ 抽样对照：抽 10 万次，统计各成功次数的频率 ----
np.random.seed(0)
samples = np.random.binomial(n=n, p=p, size=100000)
for k in ks:
    freq = np.mean(samples == k)
    print(f"X={k}: 理论 {pmf[k]:.4f}  频率 {freq:.4f}")
```

运行输出（Python 3.11 + NumPy）：

```text
P(X=0) = 0.2500
P(X=1) = 0.5000
P(X=2) = 0.2500
所有概率非负: True
总和 = 1.000000   # 应为 1
P(1<=X<=2) = 0.7500   # p(1)+p(2) = 3/4
X=0: 理论 0.2500  频率 0.2495
X=1: 理论 0.5000  频率 0.5000
X=2: 理论 0.2500  频率 0.2505
```

教材的三个数字被复现，铁律被验证，抽样频率贴着理论 PMF。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy

```python
import numpy as np
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 `np.arange`（生成 $k$）、`np.random.binomial`（抽样）、`np.mean`（频率）提供执行者。

---

### 步骤 2：定义 `binomial_pmf` —— 二项 PMF 的直接翻译

```python
def binomial_pmf(k, n, p):
    """二项 PMF：C(n,k) p^k (1-p)^(n-k)。k 是成功次数。"""
    from math import comb
    return comb(n, k) * (p**k) * ((1.0 - p)**(n - k))
```

#### binomial_pmf —— 二项 PMF：组合数 × 成功概率 × 失败概率

**做什么**：对给定成功次数 $k$，算出 $P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}$。
**操作**：`comb(n,k)` 算组合数；`p**k` 是 $k$ 次成功的概率；`(1-p)**(n-k)` 是 $n-k$ 次失败的概率；三者相乘。
**输入**：
- `k`：成功次数。
- `n`：总试验次数。
- `p`：单次成功概率。
**输出**：该 $k$ 的概率。
**可调参数**：`p` 从 0 到 1 任意；`n` 可大可小（但注意 `comb` 和 `p**k` 对超大 $n,k$ 可能溢出——本脚本教学场景足够）。想验证不对称就换 `p=0.7`，柱子会往右侧偏。
**对应数学**：二项 PMF 公式。`comb(n,k)` 数"$k$ 次成功有几种走法"（教材里 1 个正面的两条路），`p^k(1-p)^{n-k}` 是每条路的概率。

---

### 步骤 3：生成 $k$ 网格并逐点算 PMF

```python
n, p = 2, 0.5
ks = np.arange(0, n + 1)
pmf = np.array([binomial_pmf(k, n, p) for k in ks])
for k, prob in zip(ks, pmf):
    print(f"P(X={k}) = {prob:.4f}")
```

#### `np.arange(0, n+1)` 与列表推导 —— 对每个 $k$ 求 PMF

**做什么**：$k$ 取 $0,1,\dots,n$ 共 $n+1$ 个点，逐点算概率。
**操作**：`np.arange(0, n+1)` 生成 $[0,1,2]$；列表推导对每个 $k$ 调 `binomial_pmf`；`np.array` 转数组。
**输入**：`n=2, p=0.5`。
**输出**：`[0.25, 0.5, 0.25]`。
**可调参数**：把 `n` 改成 10 就得到 11 根柱子（二项分布的正态近似会显现，教材 Figure 4.1a）；把 `p` 改成 0.1，柱子整体左偏。
**对应数学**：PMF 是一个"点 → 概率"的映射——`ks` 是定义域（可能值），`pmf` 是每个点的质量。柱子高度 $=p(k)$，正是教材"Peak at n×p"所在处。

---

### 步骤 4：铁律检验与区间概率

```python
print(f"所有概率非负: {np.all(pmf >= 0)}")
print(f"总和 = {pmf.sum():.6f}   # 应为 1")
print(f"P(1<=X<=2) = {pmf[1:].sum():.4f}   # p(1)+p(2) = 3/4")
```

#### `np.all` / `.sum()` / 切片 —— 验证铁律、算区间概率

**做什么**：检查非负与归一，再算区间概率。
**操作**：`pmf >= 0` 生成布尔数组，`np.all` 确认全为 True；`pmf.sum()` 求和；`pmf[1:]` 取下标 1 及之后（$k=1,2$）再求和。
**输入**：`pmf` 数组。
**输出**：`True`、`1.000000`、`0.7500`。
**可调参数**：换不同 $n,p$，总和恒为 1（浮点误差内）——这是 PMF 的硬性铁律，永远成立。
**对应数学**：$\sum_k p(k)=1$ 与 $\mathrm{P}(a\le X\le b)=\sum_{k=a}^{b}p(k)$。区间概率就是"把区间内的柱子加起来"。

---

### 步骤 5：抽样对照——大数定律

```python
samples = np.random.binomial(n=n, p=p, size=100000)
for k in ks:
    freq = np.mean(samples == k)
```

#### `np.random.binomial(n, p, size)` —— 从二项分布抽样

**操作**：生成 `size` 个服从二项分布的样本（内部等价于"抛 $n$ 次、成功 $p$、重复 `size` 次"）。
**输入**：`n`（试验次数）、`p`（成功概率）、`size`（样本数）。
**输出**：形状 `(size,)` 的整数数组，取值 0..n。
**可调参数**：`size` 越大频率越贴近理论 PMF；`n`、`p` 决定分布形状。
**对应数学**：`np.mean(samples == k)` 是"取到 $k$ 的频率"，大数定律保证它收敛到 $p(k)$。理论给精确，抽样给验证——频率柱子贴着理论柱子，就是教材 Figure 4.1a 的"统计版"。

## 改个数字试试：柱子如何随参数变形

### 实验：n=10, p=0.5 vs n=10, p=0.2

```python
for p in (0.5, 0.2):
    ks = np.arange(11)
    pmf = np.array([binomial_pmf(k, 10, p) for k in ks])
    peak = ks[np.argmax(pmf)]
    print(f"n=10,p={p}: 峰在 k={peak}（理论 np={10*p}） 总和={pmf.sum():.4f}")
```

输出：

```text
n=10,p=0.5: 峰在 k=5（理论 np=5.0） 总和=1.0000
n=10,p=0.2: 峰在 k=2（理论 np=2.0） 总和=1.0000
```

峰的位置正是 $np$（教材"Peak at n×p"），总和恒为 1。`p` 越小柱子越往左偏——这就是"成功概率不同，PMF 形状不同"的直接演示。

## 边界声明：这套代码能做什么，不能做什么

1. **`binomial_pmf` 只适用于离散、有限试验次数。** 对连续变量（身高、等待时间）直接套 PMF 会得"单点概率 0"的荒谬结论——那需要 PDF（§4.2.4.2）。对可数无穷的泊松，分母是 $k!$，需另写函数。
2. **大 $n$ 时朴素公式会溢出。** `comb(n,k)*p**k*(1-p)**(n-k)` 对 $n=1000$ 会因 `p**k` 极小、`comb` 极大而损失精度。真实工程用 `scipy.stats.binom.pmf`（内部对数空间计算）或对数似然。本脚本面向教学，不处理极端参数。
3. **PMF 是理论，频率是估计。** `np.random.binomial` 的频率贴着理论 PMF 但永远不会完全相等——那是大数定律的"抖动"，不是代码 bug。分清"分布本身"与"对分布的抽样"，是后续所有推断的起点。
