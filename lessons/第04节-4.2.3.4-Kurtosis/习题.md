# 习题：峰度

## 第一组：概念检验

**1. 为什么峰度用四次方而不是立方或平方？为什么公式里要"减 3"？**

**解答**：四次方抹掉符号（不像立方），但又比平方**更偏爱极端值**——偏离 4 个单位的点平方贡献 16、四次方贡献 256，极端偏离被四次方放大得更狠，于是"平均四次偏离"越大代表尾巴越肥。而正态分布的四阶矩恰好是 3（高斯积分的性质 $\mathbb{E}[Z^4]=3$），所以减 3 把正态定为原点，得到超额峰度：$>0$ 尖峰态（肥尾）、$=0$ 正态、$<0$ 低阔峰（瘦尾）。

**2. 判断题并说明理由："峰度大的分布一定更尖。"**

**解答**：不准确。超额峰度 $>0$ 的分布确实通常"中间更尖 + 尾巴更肥"（总面积守恒下尖与肥常相伴），但"尖"只是表象，"尾巴肥、极端值多"才是峰度真正度量的东西。同一个超额峰度可以由不同的"尖 + 肥"组合产生。更稳妥的说法：峰度度量的是**极端值相对正态是多还是少**。

**3. 一只基金的日收益超额峰度为 8。这句话对投资者意味着什么？**

**解答**：意味着这只基金的极端波动**比正态分布预测的频繁得多**。如果假设收益正态，模型会认为"暴跌 6σ"几亿年才一次；超额峰度 8 说明这类极端事件"隔一段时间就来"。投资者应该意识到：用均值-方差（正态假设）衡量这只基金的风险，会**系统性低估**尾部风险——这正是主线"黑天鹅"的工程含义。

## 第二组：计算实践

**4. 手算 + 代码验证。** 均匀分布 $\text{Uniform}(0,1)$ 的理论超额峰度是多少？用代码抽样验证。再验证正态分布理论超额峰度为 0。

**解答**：$\text{Uniform}(0,1)$ 的方差 $\frac{(1-0)^2}{12}=\frac1{12}$，四阶中心矩 $=\frac{1}{80}$（$\mathbb{E}[(X-\mu)^4]$ 可积分算出），峰度 $=\frac{1/80}{(1/12)^2}=\frac{1/80}{1/144}=1.8$，超额 $=1.8-3=-1.2$。所以均匀分布超额峰度为 $-\frac65=-1.2$——低阔峰。

代码验证：

```python
import numpy as np
np.random.seed(0)
def kurt(x):
    mu, sd = x.mean(), x.std()
    return np.mean(((x - mu)/sd)**4) - 3.0
u = np.random.uniform(0, 1, 200000)
n = np.random.normal(0, 1, 200000)
print("Uniform(0,1) 超额峰度 =", round(kurt(u), 3), " 理论 = -1.2")
print("Normal(0,1)  超额峰度 =", round(kurt(n), 3), " 理论 = 0")
```

输出：

```text
Uniform(0,1) 超额峰度 = -1.201  理论 = -1.2
Normal(0,1)  超额峰度 = 0.001  理论 = 0
```

**思路点拨**：若有人直觉"均匀没尾巴，峰度应该小于正态"，他的方向对，但要说清数值——减 3 后均匀是 -1.2。若有人把峰度和"平不平"画等号，注意均匀分布其实是"两端截断、无尾"，所以超额峰度为负。

**5. 用代码对比三种"同方差不同尾巴"的分布**：正态、均匀、t(5)（都缩放到方差 1），打印各自的超额峰度，并验证"标准化不改峰度"。

**解答**：

```python
import numpy as np
np.random.seed(1)
def kurt(x):
    mu, sd = x.mean(), x.std()
    return np.mean(((x - mu)/sd)**4) - 3.0
dists = {
  "正态": np.random.normal(0,1,100000),
  "均匀": np.random.uniform(-np.sqrt(3), np.sqrt(3), 100000),
  "t(5)": np.random.standard_t(5, 100000),
}
for name, d in dists.items():
    d = d / d.std()                       # 全部缩放到方差 1
    print(f"{name}: 方差={d.var():.3f} 超额峰度={kurt(d):.3f}")
```

输出（大致）：

```text
正态: 方差=1.000 超额峰度=0.001
均匀: 方差=1.000 超额峰度=-1.198
t(5): 方差=1.000 超额峰度=5.947
```

三个分布方差都是 1，峰度却从 -1.2 到 0 到 5.9——**同一把方差尺子量不出尾巴差异**。缩放只改变方差，不改变标准化后的四阶矩，所以峰度不变。**思路点拨**：这正是主线"两只股票统计数字全同，风险却不同"的代码版。若有人试图用方差解释峰度差异，他会失败——因为它们被故意设计成方差相同。

## 第三组：DL 延伸

**6. 训练稳定性场景。** 训练一个深层网络时你注意到：损失在大多数 step 平缓下降，但偶尔出现几个巨大的梯度尖峰，有时甚至导致 loss 变成 NaN。（a）用峰度的语言描述这种情况。（b）梯度裁剪和 Huber 损失分别是如何应对"肥尾梯度"的？它们背后的数学动机是什么？

**解答**：
（a）梯度的分布呈**超高峰度**——大多数梯度接近 0（样本已学好），少数样本的梯度极大（困难样本/异常标签）。与正态假设相比，极端梯度出现的频率远高于预期。这就是"梯度肥尾"。
（b）**梯度裁剪**把梯度的范数砍到阈值 $c$：$\tilde{g}=g\cdot\min(1, c/\|g\|)$——直接截断肥尾，防止单个大梯度把参数一步推出安全区。**Huber 损失**则是把误差从平方（$L_2$，对极端误差以平方放大）换成"小误差平方、大误差线性"的分段函数：$\ell(y,\hat y)=\frac12(y-\hat y)^2$（当 $|y-\hat y|\le\delta$）否则 $\delta(|y-\hat y|-\frac\delta2)$。它让大误差的梯度从"线性增长"（$L_2$）降为"常数"（$L_1$），从而不被肥尾的异常标签统治。两者共同的数学动机：**当数据的峰度远超正态，以平方为基础的损失/更新会被极端值主导，必须对尾部施加线性或硬性约束。**
**思路点拨**：若有人答"梯度裁剪是防梯度消失"，方向错了——裁剪防的是"梯度爆炸"（肥尾的大值），消失是另一回事。若有人答"Huber 的 $\delta$ 越小越好"，那忽略了 $\delta$ 太小时 Huber 退化成纯 $L_1$、对正常样本的拟合精度下降——$\delta$ 是"正常 vs 极端"的阈值旋钮，正对应主线的峰度思维。
