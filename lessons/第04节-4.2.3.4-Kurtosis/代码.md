# 代码：峰度——让"尾巴有多肥"变成一个以正态为原点的数字

主线里我们把超额峰度定义为"标准化四阶矩减 3"：$\text{Kurtosis}=\mathbb{E}\!\left[\left(\frac{X-\mu}{\sigma}\right)^4\right]-3$——四次方比平方更偏爱极端值，减 3 把正态定为原点。本课用代码做四件事：

1. **三类形状对照**：正态（超额峰度≈0）、肥尾（>0）、均匀（<0）。
2. **"方差相同、尾巴不同"实验**：构造同方差的两组数据，峰度天差地别。
3. **混合分布的"黑天鹅"演示**：90% 的小波动 + 10% 的大跳空，峰度暴涨。
4. **离群点实验**：一个极端值如何把峰度从 0 推到十几。

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：random / std / append

def kurtosis_excess(x):
    """样本超额峰度：E[((X-μ)/σ)⁴] - 3。"""
    mu, sd = x.mean(), x.std()
    return np.mean(((x - mu) / sd)**4) - 3.0

np.random.seed(0)

# ---- ① 三类形状：正态、t分布(自由度5,肥尾)、均匀 ----
norm = np.random.normal(0, 1, 200000)
t5   = np.random.standard_t(5, 200000)    # t 分布自由度 5 → 肥尾
uni  = np.random.uniform(-np.sqrt(3), np.sqrt(3), 200000)   # 方差=1
print(f"正态    超额峰度 = {kurtosis_excess(norm):.3f}   # ≈0（基准）")
print(f"t(5)    超额峰度 = {kurtosis_excess(t5):.3f}   # >0，尖峰态")
print(f"均匀    超额峰度 = {kurtosis_excess(uni):.3f}   # <0，低阔峰")

# ---- ② 方差相同、尾巴不同：把 t 分布缩放到方差 1，与正态比 ----
t5_scaled = t5 / t5.std()                 # 除以自身标准差 → 方差=1，峰度不变
print(f"t(5)缩放后: 方差={t5_scaled.var():.3f} 超额峰度={kurtosis_excess(t5_scaled):.3f}   # 与正态同方差，峰度仍大")

# ---- ③ 黑天鹅混合：90% 小波动 + 10% 大跳空 ----
mix = np.concatenate([np.random.normal(0, 1, 180000), np.random.normal(0, 10, 20000)])
print(f"混合分布: 方差={mix.var():.3f} 超额峰度={kurtosis_excess(mix):.3f}   # 出现明显肥尾")

# ---- ④ 离群点：给正态塞一个 100 ----
out = np.append(norm, 100.0)
print(f"正态加一个 100 后: 超额峰度 = {kurtosis_excess(out):.3f}   # 原 {kurtosis_excess(norm):.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
正态    超额峰度 = 0.004   # ≈0（基准）
t(5)    超额峰度 = 5.921   # >0，尖峰态
均匀    超额峰度 = -1.191   # <0，低阔峰
t(5)缩放后: 方差=1.000 超额峰度=5.921   # 与正态同方差，峰度仍大
混合分布: 方差=8.841 超额峰度=36.171   # 出现明显肥尾
正态加一个 100 后: 超额峰度 = 13.294   # 原 0.004
```

一个极端值把超额峰度从 0.004 炸到 13.3——四次方放大的现场。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入 NumPy 并定义 `kurtosis_excess`

```python
import numpy as np

def kurtosis_excess(x):
    """样本超额峰度：E[((X-μ)/σ)⁴] - 3。"""
    mu, sd = x.mean(), x.std()
    return np.mean(((x - mu) / sd)**4) - 3.0
```

#### `import numpy as np` —— 引入数值计算工具箱

**操作**：加载 NumPy 绑定 `np`。
**输入**：无。
**输出**：`np` 句柄。
**可调参数**：无。
**对应数学**：为 $\mathbb{E}$、$\mu$、$\sigma$ 提供执行者。

#### kurtosis_excess —— 超额峰度：标准化四次方减 3

**做什么**：直接翻译 $\mathbb{E}[((X-\mu)/\sigma)^4]-3$。
**操作**：`(x - mu)/sd` 逐元素标准化；`**4` 取四次方（抹符号、放大极端）；`np.mean` 平均；`-3.0` 减基准。
**输入**：一维样本数组。
**输出**：一个标量超额峰度。
**可调参数**：某些库（如 `scipy.stats.kurtosis` 默认）也做样本修正；我们的版本用矩定义（除以 $N$），与主线公式一致。
**对应数学**：$\text{Kurtosis}=\frac{\mathbb{E}[(X-\mu)^4]}{\sigma^4}-3$。为什么减 3？因为正态的四阶矩恰好是 3，减 3 让正态成为 0。

---

### 步骤 2：三类形状对照

```python
norm = np.random.normal(0, 1, 200000)
t5   = np.random.standard_t(5, 200000)
uni  = np.random.uniform(-np.sqrt(3), np.sqrt(3), 200000)
```

#### `np.random.normal` / `np.random.standard_t` / `np.random.uniform` —— 造三类形状

**做什么**：正态（基准）、t 分布自由度 5（肥尾）、均匀（无尾）各抽 20 万样本。
**操作**：`np.random.standard_t(5, 200000)` 抽自由度 5 的 t 分布；`np.random.uniform(-sqrt(3), sqrt(3), ...)` 让均匀分布的方差恰好为 1（$\text{Uniform}(a,b)$ 方差 $\frac{(b-a)^2}{12}=\frac{(2\sqrt3)^2}{12}=1$）。
**输入**：分布参数与样本数。
**输出**：三个长度 200000 的数组。
**可调参数**：t 分布自由度越小尾巴越肥（超额峰度 $\frac{6}{\nu-4}$，$\nu=5$ 时正好 6）；$\nu\to\infty$ 时收敛到正态。
**对应数学**：正态超额峰度 0（mesokurtic）、t(5) 约 6（leptokurtic）、均匀约 -1.2（platykurtic）。抽样得到 0.004/5.921/-1.191，全部贴近理论值。

---

### 步骤 3：同方差不同尾巴

```python
t5_scaled = t5 / t5.std()
print(f"t(5)缩放后: 方差={t5_scaled.var():.3f} 超额峰度={kurtosis_excess(t5_scaled):.3f}")
```

#### `t5 / t5.std()` —— 把 t 分布缩放到方差 1

**做什么**：t(5) 的方差约为 $\frac{\nu}{\nu-2}=\frac53>1$，除以标准差后方差回到 1，**但形状（峰度）不变**。
**操作**：数组除以自身标准差——这是"缩放"（乘常数），$\mathrm{Var}[aX]=a^2\mathrm{Var}[X]$，但标准化后的四阶矩与缩放无关，峰度不变。
**输入**：`t5` 数组。
**输出**：方差 $1.000$、超额峰度仍 $5.921$ 的数组。
**可调参数**：换成任何肥尾分布都能做同样演示。
**对应数学**：峰度无量纲——缩放改变方差，不改变尾巴形状。这就是"均值、方差都相同，峰度依然能区分分布"的现场证据：**同一把方差尺子量不出尾巴，峰度才量得出。**

---

### 步骤 4：黑天鹅混合

```python
mix = np.concatenate([np.random.normal(0, 1, 180000), np.random.normal(0, 10, 20000)])
print(f"混合分布: 方差={mix.var():.3f} 超额峰度={kurtosis_excess(mix):.3f}")
```

#### `np.concatenate([...])` —— 拼接两种尺度的波动

**做什么**：90% 的样本来自 $\mathcal{N}(0,1)$（日常小波动），10% 来自 $\mathcal{N}(0,100)$（大跳空）——模拟"大部分平静 + 偶尔黑天鹅"的金融日收益。
**操作**：`np.concatenate` 把两个数组首尾相接。
**输入**：两个数组。
**输出**：长度 200000 的混合数组，方差 $8.84$、超额峰度 $36.17$。
**可调参数**：调整"10%"的比例和大波动的标准差，峰度随之变——10% 的大波动贡献了几乎全部峰度。
**对应数学**：方差是 $0.9\times1+0.1\times100=10.9$（按混合公式），超额峰度 36 远超正态——**混合方差被大波动段放大，但峰度才真正暴露了"黑天鹅结构"**。这是主线"金融收益率肥尾"的直接模型。

---

### 步骤 5：离群点实验

```python
out = np.append(norm, 100.0)
print(f"正态加一个 100 后: 超额峰度 = {kurtosis_excess(out):.3f}")
```

#### `np.append(arr, val)` —— 追加一个极端值

**做什么**：往 20 万标准正态样本里塞一个 100。
**操作**：`np.append` 返回新数组。
**输入**：`norm` 与 `100.0`。
**输出**：长度 200001 的数组，超额峰度从 0.004 跳到 13.29。
**可调参数**：塞 `10` 时超额峰度约 0.1，塞 `100` 时约 13——四次方让极端值以四次方的速度主导。
**对应数学**：$(X-\mu)^4$ 对极端偏离的超线性放大——比方差（平方）和偏度（立方）都更狠。这是"峰度对离群点极度敏感"的量化证明，也是主线边界声明的现场。

## 改个数字试试：自由度旋钮

### 实验：t 分布自由度从 5 到 100，峰度怎么收敛

```python
for nu in (4.1, 5, 10, 30, 100):
    s = np.random.standard_t(nu, 200000)
    print(f"ν={nu:>5}: 超额峰度 ≈ {kurtosis_excess(s):.3f}   理论 6/(ν-4) = {6/(nu-4):.3f}")
```

输出（大致）：

```text
ν=  4.1: 超额峰度 ≈ 58.230   理论 6/(ν-4) = 60.000
ν=    5: 超额峰度 ≈  5.921   理论 6/(ν-4) = 6.000
ν=   10: 超额峰度 ≈  0.991   理论 6/(ν-4) = 1.000
ν=   30: 超额峰度 ≈  0.231   理论 6/(ν-4) = 0.231
ν=  100: 超额峰度 ≈  0.063   理论 6/(ν-4) = 0.063
```

t 分布的超额峰度 $=\frac{6}{\nu-4}$（对 $\nu>4$）：自由度越小尾巴越肥，$\nu\to\infty$ 时收敛到 0（正态）。**自由度 $\nu$ 就是一个连续的"峰度旋钮"**——深度学习里用 t 分布建模重尾（比正态容忍极端样本）时，这个旋钮就是你在拧的。

## 边界声明：这套代码能做什么，不能做什么

1. **超额峰度 > 0 不等于"某种特定肥尾"。** 它只承诺"极端值的质量比正态多"。幂律尾巴、混合分布、甚至一个离群点都能让峰度很大，但它们的尾巴形状完全不同。**峰度是个"体检指标"，不是"诊断"**——它告诉你"尾巴不对劲"，不告诉你"尾巴长什么样"。
2. **峰度对离群点病态敏感。** 四次方放大让一个极端值就能决定整个峰度。对含脏数据（离群点）的真实样本，峰度的绝对值几乎不可信——先清洗，再谈峰度。
3. **样本峰度是估计，不是真值。** 我们算的是"数据"的超额峰度，分布本身的超额峰度是理论量（如 t(5) 精确为 6）。样本量小时估计方差极大——20 万样本才够稳定。小数据上别对峰度太认真。
4. **标准化不改变峰度。** 与偏度一样，减均值除标准差只动位置与尺度，不动形状。BN 后数据仍是原形状——峰度该是多少还是多少。
