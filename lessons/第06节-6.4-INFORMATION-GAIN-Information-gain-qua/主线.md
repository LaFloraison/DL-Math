## 第一步：Toy Model —— 气象站里的一道选择题

你是气象站的预报员，每天要做一件事：**预报明天下不下雨。**

先别管云图，只看历史数据。过去一年里，40% 的日子下了雨，60% 没下——你把"明天下雨"当成一个纯概率问题：$P(\text{雨}) = 0.4$，$P(\text{晴}) = 0.6$。这时候你对"明天下不下雨"是很拿不准的：$H(Y) \approx 0.970$ bits，接近 1 bit 的天花板——五五开边缘的犹豫。

现在给你一个新工具：**看一眼天空，看今天有没有云。** 气象学常识告诉你，云和雨强相关：今天有云（50% 的日子），明天有 80% 概率下雨；今天没云（50% 的日子），明天只有 20% 概率下雨。

看一眼天，世界清晰多了：

- 今天**有云** → 明天八成下雨，你的犹豫掉到 $0.722$ bits
- 今天**没云** → 明天八成不下雨，你的犹豫也掉到 $0.722$ bits

加权平均一下，"看了天之后"你对"明天下不下雨"的总不确定：

$$H(Y \mid X) = 0.5 \times 0.722 + 0.5 \times 0.722 = 0.722 \text{ bits}$$

现在问一个"浅到可笑"的问题：**看天，到底帮了你多少忙？**

答案是一个减法：不看天时 $0.970$ bits，看了天只剩 $0.722$ bits。差：

$$0.970 - 0.722 = 0.249 \text{ bits}$$

**看天，帮你消掉了 0.249 bits 的犹豫。** 这个"消掉的犹豫"，就是信息论里分量极重的一个量：**信息增益 (information gain)**。它问的是一个朴素到极点的问题——**"多知道一件事，能少拿不准多少？"**——而它的答案，决定了决策树在哪里劈下第一刀。

## 第二步：正式数学讲解

### 一、撞墙：怎样衡量"一个变量对另一个的贡献"？

上一节我们有了两把尺子：$H(Y)$ 是"知道 $X$ 之前 $Y$ 的不确定"，$H(Y \mid X)$ 是"知道 $X$ 之后 $Y$ 的不确定"。现在我们要回答一个更"实用主义"的问题：**$X$ 到底贡献了多少？**

直觉几乎是自动浮现的：贡献 = 知道之前 − 知道之后。你从 $0.970$ bits 的拿不准出发，看了天只剩 $0.722$ bits，差值 $0.249$ bits 就是天对你的贡献。

但要让这个直觉成为定义，得先撞一下墙。这个减法有几个"理所当然"的要求：

**要求一：贡献不能为负。** 看天只会让预报更准，不可能越看越糊涂。$H(Y \mid X) \le H(Y)$ 已经由上一节保证（知道不会增加不确定），所以差 $H(Y) - H(Y \mid X) \ge 0$ 恒成立。这个非负性，让"信息增益"配得上"增益"二字。

**要求二：$X$ 完全决定 $Y$ 时，贡献达到最大。** 如果"有云必下雨、没云必不下"，看了天预报就零失误——$H(Y \mid X) = 0$，增益 $= H(Y)$，你把 $Y$ 的全部不确定都消掉了。这是贡献的天花板。

**要求三：$X$ 与 $Y$ 无关时，贡献为零。** 如果云和雨毫不相关（有云没云时下雨概率都是 0.4），看了天等于没看——$H(Y \mid X) = H(Y)$，增益 $= 0$。这对应"完全没用"的变量。

三个要求，一个减法，全部满足。于是：

> **信息增益 (information gain)** $\mathrm{IG}(Y; X)$
>
> 物理含义：知道 $X$ 之后，$Y$ 的不确定被消掉了多少——$X$ 对 $Y$ 的"信息贡献"。
>
> $$\mathrm{IG}(Y; X) = H(Y) - H(Y \mid X)$$
>
> - $H(Y)$：不知道 $X$ 时 $Y$ 的熵
> - $H(Y \mid X)$：知道 $X$ 后 $Y$ 的条件熵
> - 性质：
>   - 非负：$\mathrm{IG}(Y;X) \ge 0$，等于 0 当且仅当 $X$ 与 $Y$ 独立（$X$ 毫无帮助）
>   - 上界：$\mathrm{IG}(Y;X) \le H(Y)$，等于 $H(Y)$ 当且仅当 $X$ 完全决定 $Y$（$H(Y\mid X)=0$）
>   - 对称性：$\mathrm{IG}(Y;X) = \mathrm{IG}(X;Y)$（它就是 6.5 节要讲的**互信息**，写法的另一面）
> - 决策树视角：每次选特征，就选使 $\mathrm{IG}$ **最大**的那个——它把不确定砍得最狠

### 二、把信息增益展开：0.249 bits 的完整来路

把教材的天气预报例子完整走一遍，信息增益的每一步都落到具体数字上。

**第一步：算 $H(Y)$——不知道云时，对"下雨"的犹豫。**
$P(Y=1)=0.4$，$P(Y=0)=0.6$：

$$H(Y) = -(0.4\log_2 0.4 + 0.6\log_2 0.6) = 0.4\times1.322 + 0.6\times0.737 \approx 0.529 + 0.442 = 0.970 \text{ bits}$$

**第二步：算条件熵 $H(Y \mid X)$——知道云之后，还剩多少犹豫。**
今天有云时，条件分布 $(0.8, 0.2)$：

$$H(Y \mid X=1) = -(0.8\log_2 0.8 + 0.2\log_2 0.2) = 0.8\times0.322 + 0.2\times2.322 = 0.258 + 0.464 = 0.722 \text{ bits}$$

今天没云时，条件分布 $(0.2, 0.8)$：

$$H(Y \mid X=0) = -(0.2\log_2 0.2 + 0.8\log_2 0.8) = 0.722 \text{ bits}$$

加权（$P(X=1)=P(X=0)=0.5$）：

$$H(Y \mid X) = 0.5 \times 0.722 + 0.5 \times 0.722 = 0.722 \text{ bits}$$

**第三步：做减法。**
$$\mathrm{IG}(Y; X) = 0.970 - 0.722 = 0.249 \text{ bits}$$

**0.249 bits**——天气云量消掉了 0.249 bits 的下雨不确定。看这个数的大小：$H(Y)$ 是 0.970，被砍掉约四分之一。直观上"有云→八成下雨"听起来帮助很大，但信息增益只记了 0.249——**因为"看云"没有把下雨的不确定完全消掉**（有云时还有 20% 可能不下），它留下的条件熵 0.722 仍然很高。信息增益是个诚实的计量器：它不表扬你"感觉上很有用"，只记录你"实际削掉了多少不确定"。

### 三、边界声明：信息增益的三条底线

**第一，信息增益是"削掉的确定"，不是"帮助的价值"。** 0.249 bits 说的是"看云把下雨的不确定砍掉了 0.249"，它**不**直接衡量"这个预报对农业生产值多少钱"。一个信息增益很小的变量，可能依然很重要（因为它削掉的是最要命的那部分不确定）；一个增益很大的变量，也可能对最终决策无关痛痒。信息增益量的是"信息论意义上的贡献"，不是"实用意义上的价值"。

**第二，信息增益 = 0 不说明"没关系"，只说明"不降低不确定"。** 若 $X$ 与 $Y$ 有**非线性但完全确定**的关系——比如 $Y$ 恒等于 $X^2$ 且 $X$ 取 $\{-1, 0, 1\}$——那么 $H(Y\mid X)$ 会是 0（知道 $X$ 完全知道 $Y$），增益达到 $H(Y)$，不会误判。真正"增益为 0"的情形是独立。但反过来说：**线性相关系数为 0 的两个变量，信息增益可能远大于 0**（$Y=X^2$ 就是例子）——信息增益抓得住非线性关系，这正是它比相关系数更强大的地方（6.5 节会再强调）。

**第三，决策树里"信息增益最大"不是唯一标准，而且有偏。** 教材说决策树每步选增益最大的特征。但纯信息增益**偏爱取值多的特征**——一个把每个样本都分成独一份的特征（如身份证号）能把条件熵压到接近 0、增益接近最大，却是完全无用的过拟合。工程上用信息增益率 (gain ratio) 或基尼系数 (Gini impurity) 来修正这种偏向。教材介绍的是信息增益的**原理**，工程现实要更精细。

## 第三步：DL 桥接

**信息增益 → 决策树与特征选择，这是它最经典、也最直接的战场。** ID3 / C4.5 决策树的每次分裂，都选"信息增益（或其变体）最大"的特征：在节点上，对每个候选特征算 $\mathrm{IG}$，挑砍不确定砍得最狠的那个，把数据劈成子树，递归下去。你以后写决策树或看 sklearn 的 `DecisionTreeClassifier`，那个 `criterion='entropy'` 参数背后，就是这一节的 $H(Y) - H(Y\mid X)$。随机森林的每个特征重要性分数，本质也是信息增益的累积。

**信息增益 → 特征选择 (filter 方法)。** 训练前挑选特征时，filter 方法给每个特征算它和目标变量之间的信息增益（或互信息），按分数排序，留下分数高的。这比只看线性相关系数更可靠——因为它能捕捉"非线性却有预测力"的特征。`sklearn.feature_selection.mutual_info_classif` 就是干这个的，它返回的分数就是 $\mathrm{IG}(Y; X_i)$ 的估计。

**信息增益 → 信息瓶颈的雏形。** 下一节你会发现，信息增益其实就是互信息 $I(X;Y)$ 的另一个名字。而信息瓶颈理论 (Information Bottleneck) 说：深度网络逐层做的事情，是最大化"表示与目标的互信息"、同时最小化"表示与输入的互信息"——一场以信息增益为核心的压缩与保留的平衡。信息增益不只是决策树的工具，它是整个表示学习的底层货币。

现在，你握着信息增益这把尺子，它告诉你"一个变量对另一个贡献了多少"。下一节我们要给这把尺子换个更响亮的名字，并揭示它的全部身份：**互信息**。它将回答一个更根本的问题：$X$ 和 $Y$ **共享**多少信息？而那个答案，将打开特征选择、InfoGAN、信息瓶颈的整扇门。
