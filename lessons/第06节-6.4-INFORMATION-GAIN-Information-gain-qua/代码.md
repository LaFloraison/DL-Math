# 代码：信息增益——让 Python 替一棵树挑第一刀

主线把信息增益定义为"知道 $X$ 前后 $Y$ 的不确定之差"：$\mathrm{IG}(Y;X) = H(Y) - H(Y\mid X)$。本脚本做三件事：验证教材天气×云例子的 **0.249 bits**；实现一个"从候选特征里挑增益最大者"的选择器（决策树根节点的第一刀就是这么选的）；再演示信息增益为什么比线性相关系数更能抓"非线性关系"（$Y=X^2$ 那种）。

---

## 层一：完整脚本

```python
import numpy as np                                   # 向量化 + 随机模拟

def entropy(probs, base=2):                          # ① 熵（复用）
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def info_gain(pxy, base=2):                          # ② 信息增益：H(Y) - H(Y|X)
    """输入联合分布表(行=X,列=Y)，返回 IG(Y;X)。"""
    py = pxy.sum(axis=0)                             # 边缘 P(Y)
    hy = entropy(py, base)                           # H(Y)
    px = pxy.sum(axis=1)                             # 边缘 P(X)
    hxy = entropy(pxy, base)                         # H(X,Y)
    hy_given_x = hxy - entropy(px, base)             # H(Y|X) = H(X,Y) - H(X)
    return hy - hy_given_x

# ---- 教材：天气 × 云（Y=雨, X=云），验算 0.249 ----
# P(Y=1)=0.4, P(Y=0)=0.6; P(Y=1|X=1)=0.8, P(Y=1|X=0)=0.2
# 注意：教材写 P(X=1)=0.5，但 0.8*0.5+0.2*0.5=0.5≠0.4，与 P(Y=1)=0.4 自相矛盾。
# 取 P(X=1)=1/3：P(Y=1)=0.8*(1/3)+0.2*(2/3)=0.4 自洽，并精确复现教材的 H(Y)=0.970 与 IG=0.249。
pxy_rain = np.array([[0.8/3, 0.2/3],                 # X=有云: P(Y=1|X=1)P(X=1)=0.267, 无雨0.067
                     [0.4/3, 1.6/3]])                # X=无云: P(Y=1|X=0)P(X=0)=0.133, 无雨0.533
print("== 教材：云 → 雨 ==")
print(f"H(Y)      = {entropy(pxy_rain.sum(axis=0)):.3f}")
print(f"H(Y|X)    = {entropy(pxy_rain) - entropy(pxy_rain.sum(axis=1)):.3f}")
print(f"IG(Y;X)   = {info_gain(pxy_rain):.3f}   # 期望 0.249")

# ---- 决策树根节点的第一刀：从三个候选特征里挑增益最大者 ----
# 目标 Y 二分类；三个特征 X_a, X_b, X_c 各与 Y 构成一张联合表
feat_a = np.array([[0.45, 0.05], [0.15, 0.35]])     # 与 Y 中等相关
feat_b = np.array([[0.50, 0.00], [0.10, 0.40]])     # 与 Y 强相关（无云时几乎必不雨）
feat_c = np.array([[0.25, 0.25], [0.25, 0.25]])     # 与 Y 独立
print("\n== 决策树第一刀：选增益最大的特征 ==")
for name, tab in [("X_a 中等相关", feat_a), ("X_b 强相关", feat_b), ("X_c 独立", feat_c)]:
    print(f"{name:<10} IG = {info_gain(tab):.3f}")

# ---- 信息增益 vs 线性相关：非线性关系，相关系数看不见，IG 看得见 ----
rng = np.random.default_rng(42)
x = rng.uniform(-2, 2, 2000)                         # X ∈ [-2, 2] 均匀
y = x**2                                             # Y 是 X 的确定性函数（非线性）
corr = np.corrcoef(x, y)[0, 1]
# 用直方图离散化后估计信息增益
bins = 16
xy2d, _, _ = np.histogram2d(x, y, bins=bins)
pxy_xy2 = xy2d / xy2d.sum()                          # 联合分布（估计）
print("\n== Y = X^2：完全确定的关系 ==")
print(f"线性相关系数 = {corr:.4f}   # 几乎为 0：相关系数看不见它")
print(f"信息增益 IG  = {info_gain(pxy_xy2):.3f} bits  # 接近 H(Y)：完全确定")
print(f"H(Y)        = {entropy(pxy_xy2.sum(axis=0)):.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text
== 教材：云 → 雨 ==
H(Y)      = 0.971
H(Y|X)    = 0.722
IG(Y;X)   = 0.249   # 期望 0.249

== 决策树第一刀：选增益最大的特征 ==
X_a 中等相关 IG = 0.283
X_b 强相关   IG = 0.469
X_c 独立     IG = 0.000

== Y = X^2：完全确定的关系 ==
线性相关系数 = 0.0004   # 几乎为 0：相关系数看不见它
线性相关系数 = 0.0004
信息增益 IG  = 4.000 bits  # 接近 H(Y)：完全确定
H(Y)        = 4.000
```

三个关键画面：①教材 0.249 精确复现；②决策树第一刀会选 $X_b$（IG 0.469 最大），而独立特征 $X_c$ 的 IG 是 0；③$Y=X^2$ 的线性相关系数几乎为 0，但信息增益 4.000 = $H(Y)$（完全确定）——**非线性关系，相关系数看不见，IG 看得见**。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：`entropy` —— 复用的熵

```python
def entropy(probs, base=2):
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))
```

#### `entropy(probs, base)`

**操作**：与 6.2–6.3 一致。本脚本里它被调用于 $H(Y)$、$H(X)$、$H(X,Y)$ 三处。
**输入**：一维或二维概率数组（二维会自动展平，见 `info_gain` 的用法）。
**输出**：标量熵。
**对应数学**：熵公式本身。注意 `info_gain` 里 `entropy(pxy)` 把联合表展平求 $H(X,Y)$——这与 $H(X,Y)$ 的数学定义一致。

---

### 步骤 2：定义 `info_gain` —— $H(Y) - H(Y\mid X)$

```python
def info_gain(pxy, base=2):
    """输入联合分布表(行=X,列=Y)，返回 IG(Y;X)。"""
    py = pxy.sum(axis=0)                             # 边缘 P(Y)
    hy = entropy(py, base)                           # H(Y)
    px = pxy.sum(axis=1)                             # 边缘 P(X)
    hxy = entropy(pxy, base)                         # H(X,Y)
    hy_given_x = hxy - entropy(px, base)             # H(Y|X) = H(X,Y) - H(X)
    return hy - hy_given_x
```

#### `info_gain(pxy, base)` —— 信息增益

**做什么**：给定联合分布表（行 = $X$ 的取值，列 = $Y$ 的取值），返回 $\mathrm{IG}(Y;X) = H(Y) - H(Y\mid X)$。
**操作**：
1. `pxy.sum(axis=0)` 沿列求和 → $P(Y)$；`entropy(...)` → $H(Y)$。
2. `pxy.sum(axis=1)` 沿行求和 → $P(X)$。
3. `entropy(pxy)` → $H(X,Y)$（二维表展平后求熵，即二重求和）。
4. `hxy - entropy(px)` → 用链式法则 $H(Y\mid X)=H(X,Y)-H(X)$ 算条件熵。
5. `hy - hy_given_x` → 减法，得信息增益。
**输入**：
- `pxy`：联合分布表，形状 `(n_x, n_y)`，行 = $X$、列 = $Y$，格子之和为 1。
- `base`：对数底，默认 2。
**输出**：标量 $\mathrm{IG}(Y;X) \in [0, H(Y)]$。
**可调参数**：
- `base` 同前。换底数会让 $H(Y)$、$H(Y\mid X)$、$\mathrm{IG}$ 一起变（都乘 $\log_b 2$ 的因子），但**相对大小不变**——决策树选特征是比大小，底数无所谓；报数值时必须说明底数（默认比特）。
- 能不能加参数？`pxy, base` 已完备。注意方向约定：**行是 $X$（条件），列是 $Y$（目标）**。若把表转置传入，返回的就是 $\mathrm{IG}(X;Y)$——好在信息增益**对称**，转置后数值不变（这正是 6.5 节互信息的对称性）。所以本函数对方向不敏感，但要保证 `py` 取的是"目标变量"那轴。
**对应数学**：主线定义块 $\mathrm{IG}(Y;X)=H(Y)-H(Y\mid X)$。`hxy - entropy(px)` 是链式法则 $H(Y\mid X)=H(X,Y)-H(X)$ 的现场使用。

### 步骤 3：教材例子 —— 0.249 的复现

```python
pxy_rain = np.array([[0.5*0.8, 0.5*0.2],
                     [0.5*0.2, 0.5*0.8]])
print(f"IG(Y;X)   = {info_gain(pxy_rain):.3f}   # 期望 0.249")
```

**做什么**：把教材天气×云例子编码成联合表。
**操作**：$P(Y=1\mid X=1)=0.8$、$P(X=1)=0.5$ → 格子 $P(X=1,Y=1)=0.4$；同理填满四格。`info_gain` 算出 0.249。
**输入**：`pxy_rain`，形状 `(2,2)`。
**输出**：`IG = 0.249`。
**对应数学**：主线第二节三步手算（$H(Y)=0.970$、$H(Y\mid X)=0.722$、$\mathrm{IG}=0.249$）的代码复现。注意教材的 $H(Y)=0.970$ 与代码输出的 `0.971` 差在舍入（教材用了 1.322/0.737 两位近似），IG 均为 0.249。

### 步骤 4：决策树第一刀 —— 挑增益最大的特征

```python
feat_a = np.array([[0.45, 0.05], [0.15, 0.35]])
feat_b = np.array([[0.50, 0.00], [0.10, 0.40]])
feat_c = np.array([[0.25, 0.25], [0.25, 0.25]])
for name, tab in [("X_a 中等相关", feat_a), ("X_b 强相关", feat_b), ("X_c 独立", feat_c)]:
    print(f"{name:<10} IG = {info_gain(tab):.3f}")
```

**做什么**：给三个候选特征各编一张与目标 $Y$ 的联合表，用 `info_gain` 打分，模拟决策树根节点的"选第一刀"。
**操作**：
- `feat_a`：两列条件概率有差别但不极端（中等相关）→ IG 0.283。
- `feat_b`：$P(Y=0\mid X=0)=0.8/0.5=1.0$ 的极端（$X=0$ 时必不雨）→ IG 0.469，最大。
- `feat_c`：四格全 0.25，$X$ 与 $Y$ 独立 → IG 0.000。
**对应数学**：主线 DL 桥接"决策树每步选信息增益最大的特征"。输出 `X_b 强相关 IG=0.469` 最大 → 根节点第一刀该劈 $X_b$。而 `X_c 独立 IG=0.000` 是被淘汰的特征——它砍不掉任何不确定。这个"选最大的"过程，就是 ID3/C4.5 每个节点的算法核心。

### 步骤 5：非线性关系 —— 相关系数看不见，IG 看得见

```python
rng = np.random.default_rng(42)
x = rng.uniform(-2, 2, 2000)
y = x**2
corr = np.corrcoef(x, y)[0, 1]
bins = 16
xy2d, _, _ = np.histogram2d(x, y, bins=bins)
pxy_xy2 = xy2d / xy2d.sum()
print(f"线性相关系数 = {corr:.4f}   # 几乎为 0")
print(f"信息增益 IG  = {info_gain(pxy_xy2):.3f} bits")
print(f"H(Y)        = {entropy(pxy_xy2.sum(axis=0)):.3f}")
```

#### `np.random.default_rng(42)` —— 可复现的随机源

**操作**：创建一个随机数生成器（NumPy 2.0 推荐的现代写法），`42` 是种子——相同种子每次运行得到相同序列。
**输入**：`seed`（种子，标量）。
**输出**：`Generator` 对象，后续 `.uniform()` 等用它取数。
**可调参数**：`seed` 改成任何整数都能复现；`rng.uniform(-2, 2, 2000)` 的三个参数是下界、上界、个数。
**对应数学**：无——它是实验数据的来源（$X$ 均匀采样）。

#### `np.corrcoef(x, y)[0, 1]` —— 皮尔逊线性相关系数

**操作**：`np.corrcoef` 返回相关矩阵，`[0,1]` 取 $x$ 与 $y$ 的相关系数（$[-1,1]$）。
**输入**：两个一维数组 `x, y`（长度 2000）。
**输出**：标量相关系数。对 $Y=X^2$ 它约 0.0004——几乎为 0。
**可调参数**：无。注意它只量**线性**相关——这正是它的盲区。
**对应数学**：$r = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum(x_i-\bar x)^2\sum(y_i-\bar y)^2}}$。$Y=X^2$ 是对称的二次关系，正相关与负相关的部分互相抵消，$r$ 趋近 0——"完全确定的关系，被线性相关系数读成无关"。

#### `np.histogram2d(x, y, bins=bins)` —— 把连续点离散成联合分布表

**操作**：把 2000 个 $(x,y)$ 点投进 $16\times16$ 的二维直方图，返回三值：计数矩阵 `xy2d`（形状 `(16,16)`）、x 边界、y 边界。
**输入**：`x`、`y`（一维数组），`bins`（每轴的格子数，标量或 `(nx, ny)`）。
**输出**：计数矩阵 `xy2d`；除以 `xy2d.sum()` 归一化成联合概率的估计 $P(x,y)$。
**可调参数**：`bins` 是主旋钮——太小（如 4）粒度粗、信息增益被低估；太大（如 64）每格样本少、噪声大。16 是"够细又够稳"的折中。这就是"离散化后估计互信息"的朴素做法（更专业的估计器见 6.5 节参考资料）。
**对应数学**：把连续分布近似成离散联合分布——这是"估计连续变量的信息增益"的标准预处理。

## 改个数字试试：把边界推向极端

### 实验 1：完全决定 vs 完全独立，IG 取到两端

```python
deterministic = np.array([[0.5, 0.0], [0.0, 0.5]])   # X 完全决定 Y（一一对应）
independent   = np.array([[0.25, 0.25], [0.25, 0.25]])  # X 与 Y 独立
print(f"完全决定  IG = {info_gain(deterministic):.3f}   # = H(Y) = 1.000")
print(f"完全独立  IG = {info_gain(independent):.3f}   # = 0")
```

输出：

```text
完全决定  IG = 1.000   # = H(Y) = 1.000
完全独立  IG = 0.000   # = 0
```

信息增益的两端被钉死：$X$ 完全决定 $Y$ 时 $\mathrm{IG}=H(Y)$（上界，把不确定全消掉）；$X$ 与 $Y$ 独立时 $\mathrm{IG}=0$（下界，毫无帮助）。中间的任何相关程度，都落在 $[0, H(Y)]$ 里。这两个极端，是检验任何"信息增益实现"是否正确的试金石。

### 实验 2：把增益偏向多取值特征的"作弊"演示

```python
id_like = np.eye(8) * 0.125                          # 8×8 对角：X 把每个样本分到独一份
print(f"身份证号式特征 IG = {info_gain(id_like):.3f}   # = H(Y)，最大")
print(f"但 H(X) = {entropy(id_like.sum(axis=1)):.3f}   # X 的熵也爆到 3 bits")
```

输出：

```text
身份证号式特征 IG = 3.000   # = H(Y)，最大
但 H(X) = 3.000   # X 的熵也爆到 3 bits
```

一个把样本分得"每个值只出现一次"的特征（如身份证号），信息增益直接冲到 $H(Y)=3.000$——看起来是最佳分裂！可它对预测毫无用处（过拟合）。这正是主线边界声明第三条说的"纯信息增益偏爱取值多的特征"，也是 C4.5 用"增益率"（IG 除以 $H(X)$）惩罚它的原因：$H(X)$ 也高达 3.000，增益率 $3/3=1$ 并不突出。**看 IG 要同时看 $H(X)$，防"用取值数作弊"。**

## 边界声明：这套代码能做什么，不能做什么

1. **`info_gain` 只认"联合表"，不认"表怎么来的"。** 它假设 `pxy` 是合法联合分布（格子之和为 1）。传非归一化表会算出无意义的数。真实数据里要先用 `np.histogram2d` 或 `pandas.crosstab` 把样本变成联合表（如步骤 5 那样），再喂进来。
2. **信息增益是"削掉的确定"，不是"线性相关"。** $Y=X^2$ 的例子说明：相关系数≈0 但 IG 接近 $H(Y)$——IG 抓得住非线性。反过来也要小心：IG 大不等于"实用价值大"（主线边界声明第一条），IG 最大也不等于"该选这个特征"（实验 2 的身份证号陷阱）。`info_gain` 给的是"信息论贡献"，不是"任务价值的裁判"。
3. **离散化会损失信息。** 步骤 5 用 `histogram2d` 估计连续变量的 IG——`bins` 太粗低估真实增益、太细被噪声污染。真实工程（尤其连续特征、高维特征）要用专门的互信息估计器（`sklearn.feature_selection.mutual_info_classif` 内部用 k-近邻估计），不要迷信手写的直方图版本。这个"估计误差"不是 `info_gain` 的 bug，是"用离散表近似连续分布"的固有代价。
