# Ch07 §7.6.3 异质图 · 代码.md

主线给了异质图的两条路：异质 GNN（分类型聚合）与元路径（跨类型路径）。本文件用一个迷你学术网络（作者–论文–会议）演示两件事：(1) **元路径邻居**——沿"作者-论文-作者"（共同作者）找到"有语义的邻居"，用矩阵乘法数路径；(2) **分类型聚合**——对"论文邻居"和"共同作者邻居"分别用各自的矩阵变换，再组合。全篇手写 numpy。

---

## 层一：完整可运行脚本

```python
import numpy as np                                     # ① numpy

# ② 迷你学术网络：作者 A1,A2,A3、论文 P1,P2、会议 C1
#    边：作者-论文（写）、论文-会议（发表）
a_write_p = np.array([[1,0],                           # A1 写 P1
                      [0,1],                           # A2 写 P2
                      [1,1]])                          # A3 写 P1 和 P2
p_at_c    = np.array([[1], [1]])                       # P1、P2 都发表在 C1

# ③ 元路径 "作者-论文-作者"（共同作者）矩阵：A × (A写P) × (P写^T A)
a_coauthor = a_write_p @ a_write_p.T                   # 作者-作者：共享论文数
np.fill_diagonal(a_coauthor, 0)                        # 去掉自己
print("共同作者矩阵（A_i 与 A_j 共享几篇论文）：\n", a_coauthor)

# ④ 元路径邻居：对 A1，共同作者是共享论文的作者
a1_neighbors = np.where(a_coauthor[0] > 0)[0]
print("A1 的元路径邻居（共同作者）：", [f"A{i+1}" for i in a1_neighbors])

# ⑤ 分类型聚合：作者邻居用 W_author，论文邻居用 W_paper，再组合
H_author = np.array([[1.,0.],[0.,1.],[1.,1.]])         # 作者特征（A1,A2,A3）
H_paper  = np.eye(2)                                   # 论文特征（P1,P2 独热）
W_author = np.array([[1.0, 0.0], [0.0, 1.0]])          # 作者邻居的变换（恒等）
W_paper  = np.array([[0.5, 0.0], [0.0, 0.5]])          # 论文邻居的变换（衰减）

agg_author = (a_coauthor @ H_author) @ W_author        # 作者邻居聚合
agg_paper  = (a_write_p @ H_paper) @ W_paper           # 论文邻居聚合
h1 = agg_author[0] + agg_paper[0]                      # A1 的表示 = 两类聚合之和
print("\nA1 的作者邻居聚合：", np.round(agg_author[0], 2))
print("A1 的论文邻居聚合：", np.round(agg_paper[0], 2))
print("A1 的异质表示（两类之和）：", np.round(h1, 2))
```

输出：

```
共同作者矩阵（A_i 与 A_j 共享几篇论文）：
 [[0. 0. 1.]
  [0. 0. 1.]
  [1. 1. 0.]]
A1 的元路径邻居（共同作者）： ['A3']
A1 的作者邻居聚合： [1. 1.]
A1 的论文邻居聚合： [0.5 0. ]
A1 的异质表示（两类之和）： [1.5 1. ]
```

三个读数各说一件事。**元路径邻居**：`a_write_p @ a_write_p.T` 数出"A_i 与 A_j 共享几篇论文"——A1 与 A3 共享 1 篇（P1），所以 A1 的"共同作者邻居"是 A3（矩阵里 A1 行的非零位置）。**分类型聚合**：A1 的"作者邻居聚合"用 `W_author` 把共同作者 A3 的特征接入（得 `[1,1]`），"论文邻居聚合"用 `W_paper` 把自己写的论文 P1 的特征衰减接入（得 `[0.5,0]`）——**两类邻居走不同的变换矩阵**。**组合**：A1 的表示 = 作者邻居贡献 + 论文邻居贡献 = `[1.5,1]`——它"认识共同作者 A3"（作者段）与"写了论文 P1"（论文段）两个不同语义的信息都被保留，且分得清贡献来源。

## 层二：分步逐函数拆解

### 步骤 1：计算元路径邻居

```python
a_coauthor = a_write_p @ a_write_p.T
np.fill_diagonal(a_coauthor, 0)
```

#### 元路径邻居 —— 矩阵乘法数"跨类型路径"

`a_write_p @ a_write_p.T`

**操作**：$A_{写}$ 是"作者×论文"矩阵（$A_{写}[i,k]=1$ 表示作者 i 写论文 k）。$A_{写} \times A_{写}^\top$ 的 $(i,j)$ 元素 $= \sum_k A_{写}[i,k] A_{写}[j,k]$——即"作者 i 和作者 j 共同写的论文数"。这正是元路径"作者-论文-作者"的路径计数（§7.2 的"矩阵幂数路径"）。`fill_diagonal` 去掉"自己"。

**输入**：`a_write_p`。

**输出**：作者-作者共同写作数矩阵。

**可调参数**：
- 换元路径：`a_write_p.T @ a_write_p` 数"论文-作者-论文"（共享作者的论文对）；`a_write_p @ p_at_c` 数"作者-会议"（作者发表了哪些会议）——**不同的矩阵乘法顺序 = 不同的元路径 = 不同的语义**。
- 用 `>` 布尔化得到"是否相关"，用数值保留"相关强度"（共享论文越多越强）。

**对应数学**：主线元路径方法。`A @ A^T` 是元路径"作者-论文-作者"的矩阵实现——把"跨类型的间接关系"变成可计算的路径计数。

---

### 步骤 2：分类型聚合

```python
agg_author = a_coauthor @ H_author @ W_author
agg_paper  = (a_write_p @ H_paper) @ W_paper
h1 = agg_author[0] + agg_paper[0]
```

#### 分类型聚合 —— 每类邻居各自的变换矩阵

**操作**：`agg_author` 用共同作者矩阵聚合作者邻居、乘 `W_author`；`agg_paper` 用写作矩阵聚合论文邻居、乘 `W_paper`（衰减系数 0.5）。A1 的表示 = 两个聚合相加。

**输入**：两个邻接（元路径矩阵 + 写作矩阵）、两类特征、两类权重。

**输出**：两类聚合向量。

**可调参数**：
- `W_author`、`W_paper` 是**可学习的、类型专属的**参数——训练时各自更新，学到"作者邻居该信多少、论文邻居该信多少"。
- 组合方式除了"相加"，还可以"拼接"（`np.concatenate`）——拼接保留两类信息的"通道"，相加压缩成一个空间（§7.4.3 的分类型拼接 vs 混合）。

**对应数学**：主线异质 GNN 聚合 $h_v = \sigma(W_0 h_v + \sum_\tau W_\tau \sum_{u\in\mathcal{N}_\tau(v)} h_u)$。"作者邻居"与"论文邻居"各走各的 $W_\tau$，再组合。

---

### 步骤 3：主流程

```python
a1_neighbors = np.where(a_coauthor[0] > 0)[0]
print("A1 的元路径邻居（共同作者）：", ...)
```

#### 主流程 —— 元路径邻居的读数

**操作**：`np.where(a_coauthor[0] > 0)[0]` 取 A1 行非零列——A1 的共同作者下标。

**输入**：元路径矩阵。

**输出**：邻居列表。

**可调参数**：换 `a_coauthor[1]` 看 A2 的邻居（也是 A3）。注意 A3 与 A1、A2 都共享论文——**A3 是"跨论文的桥梁"**（§7.4.5 的结构角色，在异质图里由元路径揭示）。

**对应数学**：元路径邻居的定义——"沿元路径可达的节点"是聚合的候选邻居。它把"听谁"从"所有邻居"变成"有语义的邻居"。

## 改个数字试试

### 实验 A：换一条元路径，看到不同语义

```python
p_shared = a_write_p.T @ a_write_p          # "论文-作者-论文"：共享作者的论文对
print("论文 P1 与 P2 共享作者数：", p_shared[0,1])   # A3 都写 → 1
```

`a_write_p.T @ a_write_p` 数"两篇论文共享几个作者"——P1、P2 共享 A3（都写），所以是 1。**元路径 "作者-论文-作者" 看"合作"关系，"论文-作者-论文" 看"同人"关系**——同样的网络，不同元路径 = 不同的关系视角。元路径的选择，就是建模者声明"我要捕捉哪种语义"。

### 实验 B：把两类邻居混在一起——语义丢失

```python
# 把作者邻居和论文邻居直接相加（不区分类型）
h_mixed = (a_coauthor @ H_author)[0] + (a_write_p @ H_paper)[0]
# vs 分类型：A1 的作者段 [1,1] + 论文段 [0.5,0]——来源可辨
```

分类型聚合把两类信息放在**不同的通道**（作者段、论文段），混合聚合把它们压进同一个向量——你再也分不清"A1 认识共同作者"和"A1 写了论文"哪个是哪个。**异质模型坚持分类型的根本原因**（§7.4.3《代码.md》实验 A 的再证明）。

**呼应主线**：本实验用两个矩阵乘法和两组权重证明了异质图的两条路——元路径（`A @ A^T` 数跨类型路径）与异质 GNN（每类邻居各自的 $W_\tau$）。"类型即语义，别混"——这就是 §7.6.3 的全部核心，也是三道坎之"太杂"的解法。
