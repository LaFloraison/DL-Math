# 代码：让偏导数在三个世界里自证其身

主线里我们学会了偏导数的规则——"对谁求导，只动谁，其它当常数"——并用解析法算出了 $f(x,y) = x^2 + 2xy + y^2$ 的两个偏导数。但数学有个好习惯：**一个结论，要经得起不同的检验方式。** 这一节的脚本让偏导数同时在三套语言里现身：

1. **解析 (analytic)**：我们把求导公式直接写进代码——`2*x + 2*y`，这是教科书公式的化身；
2. **数值 (numerical)**：我们完全不背公式，只用偏导数的**定义**——让 $x$ 挪动一个微小量 $h$，量一量 $f$ 涨了多少，除以 $h$。这是从极限定义直接翻译过来的；
3. **二阶偏导**：对偏导数再求一次偏导，验证"导数的导数"。

三者互相印证的数，才是可信的数。

---

## 层一：完整脚本

```python
import numpy as np                                    # NumPy：数组与数组运算

# ---- ① 目标函数（教材例题）：f(x, y) = x^2 + 2xy + y^2 ----
def f(x, y):
    """抛物线形的二元函数：两个方向都是二次项。"""
    return x**2 + 2.0 * x * y + y**2

# ---- ② 解析偏导数：把"对谁求导、谁当常数"写死 ----
def df_dx_analytic(x, y):
    """∂f/∂x = 2x + 2y：对 x 求导，y 当常数。"""
    return 2.0 * x + 2.0 * y

def df_dy_analytic(x, y):
    """∂f/∂y = 2x + 2y：对 y 求导，x 当常数。"""
    return 2.0 * x + 2.0 * y

# ---- ③ 数值偏导数：只靠定义，不靠公式 ----
def partial_x_numeric(x, y, h=1e-5):
    """用中心差分逼近 ∂f/∂x：(f(x+h,y)-f(x-h,y)) / (2h)。"""
    return (f(x + h, y) - f(x - h, y)) / (2.0 * h)

def partial_y_numeric(x, y, h=1e-5):
    """用中心差分逼近 ∂f/∂y：冻住 x，只动 y。"""
    return (f(x, y + h) - f(x, y - h)) / (2.0 * h)

# ---- ④ 二阶偏导数（教材 3.2.2）：导数的导数 ----
def d2f_dx2_analytic(x, y):
    """∂²f/∂x² = 2：对 ∂f/∂x 再对 x 求导。"""
    return 2.0

def mixed_analytic(x, y):
    """∂²f/∂x∂y = 2：对 ∂f/∂x 再对 y 求导。"""
    return 2.0

# ---- ⑤ 逐点对照：在多个点上让解析与数值互相验算 ----
points = [(1.0, 2.0), (-1.0, 3.0), (0.5, -0.5)]
for (x, y) in points:
    a_x, a_y = df_dx_analytic(x, y), df_dy_analytic(x, y)
    n_x, n_y = partial_x_numeric(x, y), partial_y_numeric(x, y)
    print(f"点 ({x:+.1f}, {y:+.1f}) | 解析 ∂f/∂x={a_x:+.4f} 数值={n_x:+.4f} | 解析 ∂f/∂y={a_y:+.4f} 数值={n_y:+.4f}")

# ---- ⑥ 二阶偏导：对偏导数再求一次 ----
print(f"∂²f/∂x²  = {d2f_dx2_analytic(1.0, 2.0):.2f}   # 对二次函数恒为 2")
print(f"∂²f/∂x∂y = {mixed_analytic(1.0, 2.0):.2f}   # 混合偏导也是 2")
```

运行输出（Python 3.11 + NumPy）：

```text
点 (+1.0, +2.0) | 解析 ∂f/∂x=+6.0000 数值=+6.0000 | 解析 ∂f/∂y=+6.0000 数值=+6.0000
点 (-1.0, +3.0) | 解析 ∂f/∂x=+4.0000 数值=+4.0000 | 解析 ∂f/∂y=+4.0000 数值=+4.0000
点 (+0.5, -0.5) | 解析 ∂f/∂x=+0.0000 数值=+0.0000 | 解析 ∂f/∂y=+0.0000 数值=+0.0000
∂²f/∂x²  = 2.00   # 对二次函数恒为 2
∂²f/∂x∂y = 2.00   # 混合偏导也是 2
```

解析与数值在三个点上分毫不差。注意 $(0.5, -0.5)$ 这个点：解析值 $2x+2y = 1 + (-1) = 0$，数值同样算出 $0$——**这个点是函数在 $x$ 方向的"平地"，坡度恰好为零**。下面拆开每一段看。

## 层二：分步逐函数拆解

### 步骤 1：定义 `f` —— 教材里的目标函数

```python
def f(x, y):
    return x**2 + 2.0 * x * y + y**2
```

#### `f(x, y)` —— 被求导的二元函数

`return x**2 + 2.0 * x * y + y**2`

**做什么**：给定两个自变量，返回函数值。这就是主线里手算的那个教材例题 $f(x,y) = x^2 + 2xy + y^2$。
**操作**：`**` 是幂运算（`x**2` = $x^2$）；`2.0 * x * y` 是交叉项；整个表达式按标量逐项计算。函数接受 Python 标量，也能接受 NumPy 数组（运算符会逐元素广播）。
**输入**：`x`、`y`——两个标量（或两个形状相同的数组），函数的自变量。
**输出**：一个标量（或与输入同形状的数组），函数值。
**可调参数**：无——函数是固定的。但你可以把交叉项系数 `2.0` 改成任意 `a`，函数就变成 $x^2 + axy + y^2$，相应的解析偏导要改成 $2x + ay$（主线里演示过的字母替换）。改完跑一遍，看数值偏导是否依然咬合。
**对应数学**：主线第二步手算的那个 $f$。注意它在 $(0,0)$ 处的偏导是 $0$——所有二次项都消失。

---

### 步骤 2：定义解析偏导数 —— 把求导公式写进代码

```python
def df_dx_analytic(x, y):
    return 2.0 * x + 2.0 * y
```

#### `df_dx_analytic(x, y)` —— 解析版 $\partial f/\partial x$

`return 2.0 * x + 2.0 * y`

**做什么**：对 $f = x^2 + 2xy + y^2$ 做"对 $x$ 求导、$y$ 当常数"后得到 $2x + 2y$。注意 $y^2$ 那一项在代码里**根本没有出现**——因为对 $x$ 来说它是常数，导数为零，被正确地"消掉"了。
**操作**：直接计算 $2x + 2y$，是主线定义块的公式逐符号翻译。`df_dy_analytic` 因为该函数恰好对称，长得一样，但语义不同——它对应的是对 $y$ 求导。
**输入**：`x`、`y`——与 `f` 相同的自变量。
**输出**：该点处 $\partial f/\partial x$ 的值，标量。
**可调参数**：无独立参数——它被 `f` 的系数钉死。改 `f` 的交叉项系数，这里必须同步改，否则"解析"就不再解析了。这正是**手写求导的脆弱性**：公式一变，手就要跟着变。后面你会看到，数值法没有这个烦恼。
**对应数学**：主线定义块 $\frac{\partial f}{\partial x} = 2x + 2y$。"常数项求导为零"在代码里的化身，就是 $y^2$ 项缺席。

---

### 步骤 3：定义数值偏导数 —— 让定义替我们算

```python
def partial_x_numeric(x, y, h=1e-5):
    return (f(x + h, y) - f(x - h, y)) / (2.0 * h)
```

#### `partial_x_numeric(x, y, h)` —— 中心差分逼近 $\partial f/\partial x$

`return (f(x + h, y) - f(x - h, y)) / (2.0 * h)`

**做什么**：完全不碰求导公式，只按**极限定义**做事：把 $x$ 往右挪 $h$、往左挪 $h$，量 $f$ 在这两点的高度差，除以跨度 $2h$。这个方案叫**中心差分 (central difference)**。
**操作**：`f(x + h, y)` 与 `f(x - h, y)` 分别算函数在 $x$ 两侧的高度；相减后除以 `2.0 * h`。注意 `y` 在两个调用里**原封不动**——这正是"冻结另一个变量"在代码里的化身：`partial_x_numeric` 里根本没有 `y + h`，只有 `y`。
**输入**：
- `x`、`y`：求导点。
- `h`（步长）：向左右各挪多远。默认 `1e-5`。
**输出**：$\partial f/\partial x$ 的数值近似，标量。
**可调参数**：
- `h` 是精度旋钮。理论上 $h$ 越小越接近极限，但**太小会翻车**：$f$ 的前几位有效数字被 $h$ 淹没（浮点消减，cancellation），比如 `h=1e-10` 时结果开始抖动。`h≈1e-5` 在双精度浮点下通常是精度与稳定的甜蜜点——这正是真实框架做**梯度检查 (gradient check)** 时用的量级。你可以分别用 `h=1e-2`、`1e-5`、`1e-10` 跑一遍，观察误差先降后升。
- 能不能改成向前差分 `(f(x+h,y)-f(x,y))/h`？可以，误差量级从 $h^2$ 退化到 $h$，精度差一个数量级。中心差分是对称的，两边误差相互抵消，所以更好——记住这个经验，§3.6.3 的牛顿法里数值 Jacobian 也用同一招。
**对应数学**：主线里"直觉检验"那一节的数值逼近，用的是向前差分 $(f(x+h)-f(x))/h$；这里是更精确的中心差分版本，但同根同源——都在给极限定义做数值代言。

---

### 步骤 4：定义二阶偏导 —— 导数的导数

```python
def d2f_dx2_analytic(x, y):
    return 2.0
```

#### `d2f_dx2_analytic(x, y)` —— 解析版 $\partial^2 f/\partial x^2$

`return 2.0`

**做什么**：对一阶偏导 $\partial f/\partial x = 2x + 2y$ 再对 $x$ 求一次导：$2x$ 变成 $2$，$2y$（常数）消失，结果恒为 $2$。这就是二阶偏导数 $\dfrac{\partial^2 f}{\partial x^2}$。
**操作**：对二次函数，二阶偏导是常数——这是二次函数的标志性性质：一阶是直线，二阶是常数，三阶归零。`mixed_analytic` 对应 $\partial^2 f/\partial x\partial y$（先对 $x$ 再对 $y$），结果也是 $2$。
**输入**：`x`、`y`——其实结果与它们无关（恒为 2），但接口保持统一。
**输出**：标量 `2.0`。
**可调参数**：无。换成三次函数 $f = x^3$ 的话，二阶偏导就是 $6x$，不再恒定——你可以自己试试把 `f` 改成 $x^3 + y^3$ 来观察。
**对应数学**：教材 §3.2.2 的高阶偏导。值得留一句话：混合偏导 $\partial^2 f/\partial x\partial y$ 和 $\partial^2 f/\partial y\partial x$ 在函数足够平滑时**相等**——这个"混合偏导可交换"的性质（Clairaut 定理）看似平凡，却是后面 Jacobian 分析里一个安静而重要的靠山。

---

### 步骤 5：逐点对照 —— 解析与数值互相验算

```python
for (x, y) in points:
    a_x, a_y = df_dx_analytic(x, y), df_dy_analytic(x, y)
    n_x, n_y = partial_x_numeric(x, y), partial_y_numeric(x, y)
    print(...)
```

**做什么**：在三个不同点上，同时用解析法和数值法算两个偏导数，打印对照。三组输出全部一致——这就是"偏导数经得起检验"的实证。
**操作**：`for (x, y) in points` 遍历预先定义的三个点；每轮分别调用解析与数值函数；f-string 里 `:+.4f` 把结果格式化为带符号、4 位小数。数值和解析都显示 `+0.0000` 的点，是 $\partial f/\partial x = 2x+2y = 0$ 的"平地"。
**输入**：`points` 列表，三个二维点。
**输出**：三行对照记录。
**可调参数**：`points` 里的坐标可以随意增删。挑 $x = -y$ 上的点（如 $(3,-3)$），两个偏导都会是 0——因为 $2x+2y = 2(x+y)$。换一个不对称的函数（如 $f = x^2 + 3xy + y^2$），解析与数值的分量会分化，对照才真正有意义。
**对应数学**：主线里"三条路指向同一个数"的验证——在代码里，解析与数值就是其中的两条路。

## 改个数字试试：把点与函数推向极端

### 实验 1：把 $h$ 从 1e-5 推到 1e-12

```python
for h in [1e-2, 1e-5, 1e-8, 1e-12]:
    n = partial_x_numeric(1.0, 2.0, h=h)
    print(f"h={h:.0e}  数值 ∂f/∂x = {n:.10f}   |误差| = {abs(n - 6.0):.2e}")
```

输出：

```text
h=1e-02  数值 ∂f/∂x = 6.0001000000   |误差| = 1.00e-04
h=1e-05  数值 ∂f/∂x = 6.0000000000   |误差| = 5.96e-12
h=1e-08  数值 ∂f/∂x = 6.0000000001   |误差| = 1.66e-10
h=1e-12  数值 ∂f/∂x = 6.0001558562   |误差| = 1.56e-04
```

误差先随 $h$ 缩小而缩小（$h=1e-5$ 时几乎完美），之后**反弹**——$h$ 太小时浮点舍入误差占了上风。这是一条"误差 vs 步长"的 U 形曲线：太小与太大都差，中间有一片黄金地带。记住这个 U 形，它是所有数值微分（包括真实框架的 gradient check）的内在规律。

### 实验 2：换一个不对称函数

```python
def g(x, y): return x**2 + 3.0 * x * y + y**2     # 把交叉项系数改成 3
# 解析：∂g/∂x = 2x + 3y，∂g/∂y = 3x + 2y
# 数值：把 f 换成 g 后重跑对照循环
```

数值法**不用改任何求导代码**——它只调用 `f`，你把 `f` 指向 `g`，数值偏导自动跟随新函数。而解析法必须手工改写公式。这就是数值法的价值：**公式可以变，定义不变。** 深度学习的自动微分能处理任意复杂的函数，靠的正是"从定义出发、而非从公式出发"这个思路——你在这里提前体会到了它的力量。

## 边界声明：这套代码能做什么，不能做什么

1. **数值偏导是近似，不是解析解。** `partial_x_numeric` 给出的是"极限的近似"，误差约为 $h^2$ 量级（中心差分）。它永远不会像 $2x+2y$ 那样精确到任意位数。它的用途是**验证**解析结果、以及**在无法手写公式时**（比如真实神经网络的反向传播实现）做抽查——深度学习框架正是靠"解析求导 + 数值梯度检查"的对照来发现 bug 的。
2. **偏导数是局部的、单方向的。** 这套代码算出的每个值都只属于"那一个点、那一个坐标方向"。它不知道别的方向，也不知道离这个点远了之后函数变成什么样。想描述"整座山的方向"，需要把偏导数**组装成梯度**——那是 §3.4 的事。
3. **二次函数是特例，别把它的习惯当规律。** 这个函数二阶偏导恒为常数、混合偏导恒相等——这是多项式的优雅。真实神经网络的损失函数是 $10^6$ 维的非线性怪物，二阶偏导处处在变，混合偏导的交换律在"足够平滑"之外也不总是成立。本节的手算让你看清机制，不要把它当作真实损失曲面的画像。
4. **数值方法有精度天花板。** 实验 1 的 U 形曲线就是天花板本身：步长太小被浮点舍入吞掉，太大则逼近误差失控。数值微分永远"够用"，但永远不是"精确"。这正是数学上"先学会解析求导"仍然重要的原因——它给你一个准确的目标，让近似有了可比的基准。
