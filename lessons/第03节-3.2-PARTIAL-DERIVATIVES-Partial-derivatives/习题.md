# 习题：偏导数

## 一、概念检验

### 题 1.1（填空）

对二元函数 $f(x,y)$ 求 $\dfrac{\partial f}{\partial x}$ 时，我们把 ____ 视作常数，只对 ____ 求导。记号中的圆头符号 $\partial$ 读作 ____，它和一元导数的 $d$ 相区分，提醒你这只是众多方向中的____。

**解答**：$y$（其它变量）；$x$；partial（"部分"）；一个。
**思路点拨**：关键词是"partial = 部分"。偏导每次只动一个变量、冻结其余，是"部分方向"上的导数。答错的同学常把"只对 x 求导"记成"对全体求导"——那就退回一元导数的思路，偏导数的意义就丢了。

### 题 1.2（选择）

对 $f(x,y) = x^2 + 2xy + y^2$，下列**错误**的是（ ）

A. $\dfrac{\partial f}{\partial x} = 2x + 2y$
B. 求 $\partial f/\partial x$ 时，$y^2$ 项的导数为 $0$
C. $\dfrac{\partial f}{\partial x}$ 与 $\dfrac{\partial f}{\partial y}$ 在任意点都相等
D. $\dfrac{\partial f}{\partial x}$ 是 $x,y$ 的函数

**解答**：C。
**思路点拨**：A 正确（教材原题）。B 正确——$y^2$ 对 $x$ 是常数，导数为零，这正是"冻结变量"的体现。D 正确——$2x+2y$ 仍然依赖 $x$ 和 $y$，换个点值就变。C 是陷阱：对 $f = x^2 + 2xy + y^2$ 这个**特定的**函数，两个偏导恰好都等于 $2x+2y$，但它们是在两个**不同**的求导动作下得到的，只是数值巧合。改成 $f = x^2 + 3xy + y^2$，$\partial f/\partial x = 2x+3y$，$\partial f/\partial y = 3x+2y$，立刻不同。**"数值相同"不等于"同一个东西"。**

### 题 1.3（简答）

有人说"偏导数存在，说明这个函数是光滑的，所有方向都能求导"。请指出这句话哪里不严谨。

**解答**：偏导数存在只说明**沿坐标轴方向**的变化率存在，不保证**任意方向**（如东北 45°）的方向导数存在。函数可以在两个坐标轴方向都有偏导数，却在斜方向"折断"。坐标轴方向只是无穷多个方向中的两个特例。要谈"所有方向光滑"，需要更强的正则性条件（可微性），那是比"偏导数存在"更高一档的要求。
**思路点拨**：这道题考的是主线的边界声明——偏导数是局部、单方向的。能区分"偏导存在"与"可微"两个概念，就说明你没有把一维的直觉错误地搬到多元世界。

## 二、计算实践

### 题 2.1（手算）

设 $f(x,y) = x^2y + 3xy^2$。

(a) 求 $\dfrac{\partial f}{\partial x}$ 和 $\dfrac{\partial f}{\partial y}$。
(b) 求二阶偏导 $\dfrac{\partial^2 f}{\partial x^2}$ 和混合偏导 $\dfrac{\partial^2 f}{\partial x\partial y}$。
(c) 在 $(1, 1)$ 处，$\partial f/\partial x$ 的符号告诉你要往哪个方向调整 $x$ 来**增大** $f$？

**解答**：
(a) $\dfrac{\partial f}{\partial x} = 2xy + 3y^2$（把 $y$ 当常数：$x^2y \to 2xy$，$3xy^2 \to 3y^2$）。$\dfrac{\partial f}{\partial y} = x^2 + 6xy$（把 $x$ 当常数：$x^2y \to x^2$，$3xy^2 \to 6xy$）。
(b) $\dfrac{\partial^2 f}{\partial x^2} = 2y$（对 $2xy+3y^2$ 再对 $x$：$2xy \to 2y$，$3y^2$ 是常数归零）。$\dfrac{\partial^2 f}{\partial x\partial y}$：先对 $\partial f/\partial x = 2xy + 3y^2$ 再对 $y$ 求导，得 $2x + 6y$。
(c) 在 $(1,1)$：$\partial f/\partial x = 2 + 3 = 5 > 0$。偏导为正，说明增大 $x$ 会使 $f$ 增大，所以应往 $+x$ 方向调。
**思路点拨**：混合偏导可以换个顺序算（先对 $y$ 再对 $x$）来核对——Clairaut 定理保证平滑函数下两者相等。算得顺手后，用《代码.md》的数值偏导函数 `partial_x_numeric` 验证 (a)，三组数会咬合。这道题训练"对谁求导、谁当常数"的机械反应——深度学习里每个权重都享受同等待遇。

### 题 2.2（代码验证）

用 NumPy 验证题 2.1 的解析结果。写一个 `f(x,y) = x^2*y + 3*x*y**2`，用中心差分逼近 $\partial f/\partial x$ 和 $\partial f/\partial y$ 在 $(2, 3)$ 处的值，与解析式对比。

```python
import numpy as np
def f(x, y): return x**2 * y + 3.0 * x * y**2
h = 1e-5
px = (f(2+h, 3) - f(2-h, 3)) / (2*h)          # 数值 ∂f/∂x
py = (f(2, 3+h) - f(2, 3-h)) / (2*h)          # 数值 ∂f/∂y
print(f"数值 ∂f/∂x = {px:.6f}  解析 = {2*2*3 + 3*9:.6f}")
print(f"数值 ∂f/∂y = {py:.6f}  解析 = {2*2 + 6*2*3:.6f}")
```

**解答**：数值 $\partial f/\partial x = 39.000000$，解析 $2xy + 3y^2 = 12 + 27 = 39$。数值 $\partial f/\partial y = 40.000000$，解析 $x^2 + 6xy = 4 + 36 = 40$。两者一致。
**思路点拨**：注意中心差分里"冻结变量"的写法——算 $\partial f/\partial x$ 时，$y$ 在两个 `f` 调用里都保持 `3` 不变。把 `h` 改成 `1e-10` 试试，误差会因为浮点消减而反弹（见《代码.md》实验 1 的 U 形曲线）。

## 三、DL 延伸

### 题 3.1

训练一个网络，损失函数 $L$ 依赖权重 $w_1, w_2$，简化为 $L = (w_1 - 3)^2 + (w_2 + 1)^2$。梯度下降每一步要更新 $w_1, w_2$。

(a) 写出 $\partial L/\partial w_1$、$\partial L/\partial w_2$。
(b) 在 $w_1 = 5, w_2 = 1$ 处，两个偏导的符号分别指示什么行动？整体应向哪个方向移动？
(c) 为什么这里必须用偏导数 $\partial L/\partial w_i$，而不能用一个普通导数 $dL/dw$ 来描述？

**解答**：(a) $\partial L/\partial w_1 = 2(w_1 - 3)$，$\partial L/\partial w_2 = 2(w_2 + 1)$。
(b) $w_1=5$：$2(5-3)=4>0$，增大 $w_1$ 会升损失 → $w_1$ 应**减小**。$w_2=1$：$2(1+1)=4>0$，$w_2$ 应**减小**。整体朝 $(-\partial L/\partial w_1, -\partial L/\partial w_2) = (-4, -4)$ 方向移动。
(c) $L$ 同时依赖两个权重，它是二元函数。$dL/dw$ 这个记号没有意义——你没有说清对哪个 $w$、冻结哪个。偏导数 $\partial L/\partial w_i$ 明确地"只动第 $i$ 个权重、冻结其余"，这正是"每个权重各听各的指挥"的精确语言。
**思路点拨**：这道题把 §3.2 的 DL 桥接落到具体数字上。注意 (c) 的关键：**$L$ 的输入是向量 $\mathbf{w}$，所以梯度是一组偏导数组成的向量，而不是一个数。** 能说出这一点，你就已经站在 §3.4 梯度概念的门口了。

### 题 3.2

一位工程师手写了一个反向传播实现，怀疑梯度算错了。他用"数值差分"来检查：对每个权重 $w_i$，计算 $\dfrac{L(w_i+h) - L(w_i-h)}{2h}$ 与自己的解析偏导对比。请说明：这个检查利用了什么？如果数值与解析的差达到 $10^{-3}$ 量级，可能的原因是什么？

**解答**：这个检查（梯度检查，gradient check）利用的是偏导数的**定义**——极限不需要任何求导公式，只靠函数值的差值就能逼近。它和手写解析求导是两条独立的路径，两条路径互相印证才可信。差达到 $10^{-3}$ 的原因可能有：① 解析求导公式写错了（最常见的 bug）；② $h$ 选得太大（逼近误差大）或太小（浮点消减），偏离 U 形曲线的黄金地带；③ 函数在某点不可微或数值实现有近似（如 ReLU 在 0 处的"折痕"）。优先检查 $h$ 量级与解析公式。
**思路点拨**：这道题把《代码.md》实验 1 的 U 形曲线和 §3.2 的数值偏导用到真实工程场景。深度学习的框架（PyTorch 等）内部正是用这套数值对照来测试 autograd 的正确性。你能说出"两条独立路径互相印证"这个思想，就抓住了梯度检查的灵魂。
