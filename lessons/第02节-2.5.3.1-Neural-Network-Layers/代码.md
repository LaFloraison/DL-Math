# 代码：手写一个全连接层——让 z = Wx + b 在你眼前跑起来

主线里我们用选秀评委感受了"层 = 线性变换"。这一节把它变成代码——不调用 `nn.Linear`，用 NumPy 亲手实现 $\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$，加上 ReLU 激活，再堆第二层，并验证"去掉激活，两层线性 = 一层线性"的塌缩恒等式。

脚本只依赖 NumPy，约 30 行，全部输出印在下方。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 教材的例子：一位选手，两个技能维度 ----
x = np.array([1.0, 2.0])                  # 输入向量 [唱歌1, 跳舞2]，形状 (2,)
W = np.array([[0.5, 0.3],                 # 权重矩阵：2行=两位评委/神经元，2列=两个技能
              [0.7, 0.9]])                # 形状 (2, 2)
b = np.array([0.1, 0.2])                  # 偏置向量：两位评委的起评分，形状 (2,)

# ---- ② 全连接层前向：z = Wx + b ----
z = W @ x + b                             # (2,) = (2,2) @ (2,) + (2,)
print("z = Wx + b   =", z)                # 期望 [1.2 2.7]

# ---- ③ 逐神经元手算，验证 z_i = w_i·x + b_i ----
z_check = np.array([W[0] @ x + b[0],      # 评委甲：0.5*1+0.3*2+0.1
                    W[1] @ x + b[1]])     # 评委乙：0.7*1+0.9*2+0.2
print("逐神经元手算 =", z_check)

# ---- ④ 激活函数 ReLU：折断线性，引入非线性 ----
def relu(v):                              # ReLU：小于0压到0，大于0不变
    return np.maximum(v, 0.0)
a = relu(z)                               # 本层输出，形状 (2,)
print("relu(z)      =", a)

# ---- ⑤ 堆叠第二层：把第一层的输出喂给新的一层 ----
W2 = np.array([[0.4, 0.6]])               # 第二层只有1个神经元，形状 (1, 2)
b2 = np.array([0.05])                     # 第二层偏置，形状 (1,)
z2 = W2 @ a + b2                          # 复合：z2 = W2·relu(W1x+b1)+b2
print("第二层输出 z2 =", z2)

# ---- ⑥ 验证"去掉激活，两层线性 = 一层线性"的塌缩 ----
W_comp = W2 @ W                           # 复合权重矩阵 (1,2) = (1,2) @ (2,2)
b_comp = W2 @ b + b2                      # 复合偏置 (1,)
left   = W2 @ (W @ x + b) + b2            # 先过第一层、再过第二层
right  = W_comp @ x + b_comp              # 直接过一张复合表
print("复合权重 W2W1   =", W_comp)
print("复合偏置 W2b1+b2 =", b_comp)
print("两层前向==复合一层?", np.allclose(left, right))
```

运行输出（Python 3.11 + NumPy）：

```text
z = Wx + b   = [1.2 2.7]
逐神经元手算 = [1.2 2.7]
relu(z)      = [1.2 2.7]
第二层输出 z2 = [2.15]
复合权重 W2W1   = [[0.62 0.66]]
复合偏置 W2b1+b2 = [0.21]
两层前向==复合一层? True
```

## 层二：分步逐函数拆解

### 步骤 1：造输入、权重、偏置 `np.array`

```python
x = np.array([1.0, 2.0])
W = np.array([[0.5, 0.3],
              [0.7, 0.9]])
b = np.array([0.1, 0.2])
```

#### `np.array(list)` —— 把嵌套列表变成 NumPy 数组

**做什么**：把 Python 列表转成 NumPy 的 `ndarray`——这是"向量与矩阵在计算机里的存在形式"。
**操作**：`np.array` 按列表的嵌套结构推断维度（一层括号 = 一维），元素按顺序存入连续内存。
**输入**：一维列表 `[1.0, 2.0]` → 一维数组（向量）；嵌套列表 `[[0.5, 0.3], [0.7, 0.9]]` → 二维数组（矩阵）。
**输出**：`x` 形状 `(2,)`；`W` 形状 `(2, 2)`；`b` 形状 `(2,)`。
**可调参数**：
- 嵌套层数决定维度：`np.array([[[1.0], [2.0]]])` 是三维张量。深度学习里图像是三维、批量是四维，维度只增不减。
- 传 `dtype`：`np.array([1, 2], dtype=float)` 强制转浮点；真实训练里常用 `np.float32` 省显存。
- 矩阵的行列顺序：`[[0.5, 0.3], [0.7, 0.9]]` 第一层括号是"行"、第二层是"列"——必须与主线定义块的行列语义一致。
**对应数学**：主线定义块里的 $\mathbf{x} \in \mathbb{R}^2$、$\mathbf{W} \in \mathbb{R}^{2\times2}$、$\mathbf{b} \in \mathbb{R}^2$。

### 步骤 2：前向传播 `W @ x + b`

```python
z = W @ x + b
```

#### `@`（`np.matmul`）—— 矩阵-向量乘法

**做什么**：计算 $\mathbf{W}\mathbf{x}$——权重矩阵作用在输入向量上。
**操作**：矩阵 $\mathbf{W}$ 的第 $i$ 行与向量 $\mathbf{x}$ 做点积，得到输出的第 $i$ 个分量：$(\mathbf{W}\mathbf{x})_i = \sum_j w_{ij} x_j$。这里 $W @ x = [0.5\times1+0.3\times2, \; 0.7\times1+0.9\times2] = [1.1, \, 2.5]$。
**输入**：$\mathbf{W}$ 形状 `(2, 2)`，$\mathbf{x}$ 形状 `(2,)`——**内维 `2` 必须对齐**。
**输出**：形状 `(2,)` 的数组 `[1.1, 2.5]`（此时还没加偏置）。
**可调参数**：
- 内维对齐规则：`(m, n) @ (n,)` → `(m,)`；`(m, n) @ (n, k)` → `(m, k)`。内维不匹配会直接报 `ValueError`——这是最常踩的错。
- `np.matmul(W, x)` 与 `W @ x` 完全等价；`np.dot(W, x)` 对二维数组也做同样乘法，但处理三维以上数组时语义不同，建议统一用 `@`。
- **方向敏感**：`x @ W` 会因 `(2,) @ (2, 2)` 内维不匹配报错——单样本前向必须是 `W @ x`，矩阵在左。
**对应数学**：主线"每个输出 = 一行权重与输入的点积"，$\mathbf{W}\mathbf{x}$ 就是那个线性变换（还没加平移）。

#### `+ b` —— 广播加法（偏置平移）

**做什么**：把偏置向量逐分量加到 $\mathbf{W}\mathbf{x}$ 上，完成仿射变换 $\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$。
**操作**：`[1.1, 2.5] + [0.1, 0.2] = [1.2, 2.7]`——逐元素相加。
**输入**：两个形状 `(2,)` 的数组。
**输出**：`[1.2, 2.7]`。
**可调参数**：广播规则——当形状 `(B, m)` 与 `(m,)` 相加时，`(m,)` 会沿第一维"自动复制"对齐每一行。这正是批量训练时，同一个偏置能一次性加到所有样本上的原因（见步骤 5 与边界声明）。
**对应数学**：主线展开部分"$+\mathbf{b}$ 是整片空间的平移"。

### 步骤 3：逐神经元手算验证

```python
z_check = np.array([W[0] @ x + b[0],
                    W[1] @ x + b[1]])
```

#### `W[i]` —— 取矩阵第 i 行（第 i 个神经元的权重向量）

**做什么**：`W[0]` 取出第一行 `[0.5, 0.3]`，`W[1]` 取出第二行 `[0.7, 0.9]`。
**操作**：按行索引切片，再与 `x` 做点积、加偏置，得到单个神经元的输出。
**输入**：$\mathbf{W}$ 形状 `(2, 2)`，$\mathbf{x}$ 形状 `(2,)`。
**输出**：`np.array([...])` 形状 `(2,)`，值 `[1.2, 2.7]`——与第 ② 步结果一致，证明 `W @ x + b` 做的就是这条逐行公式。
**可调参数**：
- 负数索引 `W[-1]` 取最后一行；`W[:, 0]` 取第 0 列——"唱歌"这一维度被所有评委（所有神经元）如何加权；`W[0, 0]` 取单个元素 `0.5`。
- 若想一次取多行，用切片 `W[0:2]`。
**对应数学**：主线"行是神经元、列是输入维度"——亲手验证 $z_i = \mathbf{w}_i \cdot \mathbf{x} + b_i$。

### 步骤 4：激活函数 `relu`

```python
def relu(v):
    return np.maximum(v, 0.0)
a = relu(z)
```

#### `np.maximum(v, 0.0)` —— 逐元素取最大值

**做什么**：实现 ReLU：$v < 0$ 压成 $0$，$v \ge 0$ 保持不变。
**操作**：逐元素计算 $\max(v_i, \, 0)$。
**输入**：任意形状的数组（这里 `z` 形状 `(2,)`）。
**输出**：相同形状。这里 `[1.2, 2.7]` 全为正，输出不变——换成含负数的输入试试：`relu([-0.5, 3.0]) = [0.0, 3.0]`，负数被折断。
**可调参数**：
- 激活不只 ReLU：`1/(1+np.exp(-v))` 是 sigmoid（输出落在 $(0,1)$），`np.tanh(v)` 输出落在 $(-1,1)$。ReLU 因计算快、梯度好成为默认。
- `np.clip(v, 0, None)` 与 `np.maximum(v, 0.0)` 等价。
- **边界情况**：ReLU 把负半轴全部压成 $0$——若一层神经元全落在负区，它的梯度为 $0$，该神经元就"死"了（dead ReLU），实践中常用 LeakyReLU 缓解。
**对应数学**：主线边界声明——"激活函数在每一层之后折断线性"。

### 步骤 5：堆叠第二层 `W2 @ a + b2`

```python
W2 = np.array([[0.4, 0.6]])
b2 = np.array([0.05])
z2 = W2 @ a + b2
```

**做什么**：让第二层（1 个神经元）作用于第一层的激活输出 $a$。
**操作**：`W2` 形状 `(1, 2)` 与 `a` 形状 `(2,)` 做矩阵-向量乘法 → `(1,)`，再加 `b2`。$z_2 = 0.4\times1.2 + 0.6\times2.7 + 0.05 = 2.15$。
**输入**：`W2` `(1, 2)`、`a` `(2,)`、`b2` `(1,)`。
**输出**：`z2` 形状 `(1,)`，值 `[2.15]`。
**可调参数**：第二层的神经元个数就是 `W2` 的行数——把 `W2` 换成 `(8, 2)`，输出就是 8 维。层与层之间唯一的硬约束是"**前一层的输出维度 = 后一层的输入维度**"。
**对应数学**：主线第四部分——"一次前向传播，就是一串 $\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$ 的接力"。

### 步骤 6：复合验证 `W_comp` 与 `np.allclose`

```python
W_comp = W2 @ W
b_comp = W2 @ b + b2
left  = W2 @ (W @ x + b) + b2
right = W_comp @ x + b_comp
np.allclose(left, right)
```

#### `W2 @ W` —— 矩阵乘矩阵 = 线性变换的复合

**做什么**：把"先过第一层再过第二层"压成一张复合权重表。
**操作**：`(1, 2) @ (2, 2)` → `(1, 2)`，结果为 `[[0.62, 0.66]]`（$[0.4\times0.5+0.6\times0.7, \; 0.4\times0.3+0.6\times0.9]$）。
**输入**：`W2` `(1, 2)`、`W` `(2, 2)`。
**输出**：`(1, 2)`——复合矩阵 $\mathbf{W}_2\mathbf{W}_1$。
**可调参数**：矩阵乘法**不满足交换律**——`W @ W2` 会因内维不匹配报错。这正是"层有先后顺序"的代数体现。
**对应数学**：主线核心恒等式 $(\mathbf{W}_2\mathbf{W}_1)\mathbf{x}$——矩阵乘法就是线性变换的复合。

#### `np.allclose(a, b)` —— 近似比较

**做什么**：判断两个数组逐元素是否在容差内相等。
**操作**：对每个元素判断 $|a_i - b_i| \le \text{atol} + \text{rtol}\cdot|b_i|$。
**输入**：两个形状相同的数组（这里都是 `(1,)`）。
**输出**：布尔值 `True`。
**可调参数**：`rtol`（相对容差，默认 `1e-5`）、`atol`（绝对容差，默认 `1e-8`）。浮点计算有舍入误差，比较应该用 `np.allclose` 而不是 `==`。
**对应数学**：验证塌缩恒等式成立——"去掉激活，两层线性 = 一层线性"。这里 `left == right` 为 `True`，亲手确认了教材那句话说的事。

## 边界声明：这套代码能做什么，不能做什么

1. **只做前向传播，不学习。** $\mathbf{W}$、$\mathbf{b}$ 是写死的常量。如何从数据里"调"出正确的 $\mathbf{W}$、$\mathbf{b}$（训练 / 梯度 / 反向传播）是后续章节的内容。学习就是反复前向、看误差、改权重。
2. **单样本 vs 批量的方向陷阱。** 本脚本的 $\mathbf{x}$ 是单个样本，形状 `(n,)`，正确写法 `W @ x`。真实训练一次喂一批 $\mathbf{X}$ 形状 `(B, n)`——正确写法是 `X @ W.T + b`，输出 `(B, m)`。漏写 `.T` 是新手最高频的错误：`X @ W` 要么内维对不上，要么对上了但行语义从"神经元"悄悄变成了"特征"。
3. **教材笔误，亲手验。** 教材印输出为 `[1.1, 2.7]`，手算与这段代码都得 `[1.2, 2.7]`——第一个分量漏加了偏置 `0.1`。见到印刷数字，默认先算一遍。
4. **塌缩恒等式只在无激活时成立。** 一旦中间夹了 ReLU，$(\mathbf{W}_2\mathbf{W}_1)\mathbf{x}$ 的等效替换失效——这正是深度网络有价值的原因。
5. **ReLU 的代价。** 负半轴全部为 $0$，可能造成神经元"死亡"。本课不展开缓解手段，但你需要知道：激活的选择不是免费的。
