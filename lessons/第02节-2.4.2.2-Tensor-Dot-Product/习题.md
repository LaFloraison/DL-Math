# 习题：张量点积（张量收缩）

## 第一组：概念检验

**1.1（单选）** 张量 $A$ 的秩为 3，张量 $B$ 的秩为 2，它们沿 **1 条**共享轴收缩后，结果的秩是：
- A. 5
- B. 4
- C. 3
- D. 2

**1.2（判断并说明）** "张量点积就是两个张量逐元素相乘，然后把所有结果全部加起来，得到一个数。" 这句话对吗？为什么？

**1.3（填空）** 在 $C_{ij} = A_{ijk}\, B_{k}$ 中，哑指标是 ____；结果 $C$ 的形状由自由指标 ____ 决定；若 $A$ 形状是 $(2,3,4)$、$B$ 形状是 $(4,)$，则 $C$ 的形状是 ____。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 令 $A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$，$B = \begin{bmatrix} 5 & 6 \\ 7 & 8 \end{bmatrix}$。手算 $C_{ij} = \sum_k A_{ik} B_{kj}$ 的每个元素，然后用 `np.einsum('ik,kj->ij', A, B)` 和 `A @ B` 验证。

**2.2（手算 + 代码验证）** 令 $A = \begin{bmatrix} 2 & 5 \\ 3 & 7 \end{bmatrix}$。手算迹 $\mathrm{tr}(A) = A_{ii} = \sum_i A_{ii}$，并用 `np.einsum('ii->', A)` 与 `np.trace(A)` 验证。思考：为什么 $'ii\text{-}->'$ 的写法里，两个 `i` 恰好就是"对角线"？

**2.3（代码验证 + 形状）** 生成形状 `(3,4)` 的随机数组 `S`。验证 `S.sum(axis=1)` 形状是 `(3,)`，而 `S.sum(axis=1, keepdims=True)` 形状是 `(3,1)`。说明 `keepdims` 在多出一维的情况下，对后续广播（如归一化）有什么用。

## 第三组：DL 延伸

**3.1（场景判断 + 写表达式）** Attention 中，$Q$ 形状 $(batch, 4, 3)$、$K$ 形状 $(batch, 4, 3)$，其中第 3 维是 $d_k=3$。要用一次收缩算出分数矩阵（形状 $(batch, 4, 4)$，第 $i$ 行第 $k$ 列 = token $i$ 与 token $k$ 的相似度），应写出怎样的 `einsum` 表达式？哪条轴被收缩？

**3.2（场景判断）** 一个全连接层做 $y = Wx$，其中 $W$ 形状 $(128, 64)$、$x$ 形状 $(64,)$、输出 $y$ 形状 $(128,)$。这是什么数学操作？用爱因斯坦记号的写法是什么？如果 $x$ 变成一批 $(32, 64)$ 的输入，同样的操作应怎么写？

## 解答与思路点拨

### 第一组

**1.1 答案：C（秩为 3）。**
- **思路**：秩公式 $\mathrm{rank}(C) = r_A + r_B - 2m = 3 + 2 - 2\cdot1 = 3$。
- **点拨**：每条被消掉的轴在两个张量里各占一条，所以"少 2"。常见错误是只减 1（以为消掉一条轴只少一条）——但那条轴同时存在于两个张量里。

**1.2 这句话不准确。**
- **思路**：收缩要求先**指明配平的轴**——"哪条对哪条"。两个秩 3 的张量可以沿第 0 条轴配对、也可以沿第 2 条轴配对，结果形状完全不同。另外，"把结果全部加起来得到一个数"其实是**把自由指标也全部消掉**的极限情形（所有轴都成为哑指标），那是收缩的特例，不是一般情形。
- **点拨**：这道题同时戳中两个常见混淆——(1) 忘记收缩要选轴；(2) 把"张量点积"当成"元素全乘起来再全加起来"。逐元素相乘再全加是"点乘 (dot product of flattened tensors)"，通常不是我们要的张量点积。

**1.3 答案：哑指标是 $k$；自由指标是 $i, j$；$C$ 形状是 $(2,3)$。**
- **思路**：$k$ 出现两次被求和消掉；$i, j$ 各出现一次保留为结果的两条轴，长度分别是 $A$ 的轴 0（2）与轴 1（3）。$B$ 是 $(4,)$ 一维，$k=4$ 与 $A$ 的轴 2（长度 4）配平。
- **点拨**：判断"谁被消掉"只看**字母出现的次数**，不看位置。$B_k$ 的下标在下标位置，$A_{ijk}$ 的下标也在下标位置——同一个指标 $k$ 出现两次即求和，与它是上标还是下标无关。

### 第二组

**2.1**
$$C = \begin{bmatrix} 1\cdot5+2\cdot7 & 1\cdot6+2\cdot8 \\ 3\cdot5+4\cdot7 & 3\cdot6+4\cdot8 \end{bmatrix} = \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix}$$

```python
import numpy as np
A = np.array([[1., 2.], [3., 4.]])
B = np.array([[5., 6.], [7., 8.]])
print(np.einsum('ik,kj->ij', A, B))   # [[19. 22.]
print(A @ B)                          #  [43. 50.]]
```
- **思路**：$C_{00}$ 是 $A$ 的第 0 行 $[1,2]$ 与 $B$ 的第 0 列 $[5,7]$ 的点积：$1\cdot5+2\cdot7=19$；其余同理。
- **点拨**：矩阵乘法就是"把 $A$ 的每一行与 $B$ 的每一列做一次点积"——点积是收缩的一维特例，矩阵乘是收缩的二维特例，完全同一个动作。

**2.2**
$$\mathrm{tr}(A) = A_{11} + A_{22} = 2 + 7 = 9$$

```python
import numpy as np
A = np.array([[2., 5.], [3., 7.]])
print(np.einsum('ii->', A))   # 9.0
print(np.trace(A))            # 9.0
```
- **思路**：$'ii\text{-}->'$ 让同一个张量的第 0 轴与第 1 轴配对。配对意味着两个 `i` 同时取同一个值——只有当 $i$ 相等时才"对齐"，所以它恰恰遍历 $A_{00}, A_{11}, \dots$，即对角线。
- **点拨**：这是"自己收缩自己"的写法。注意 `'ii->i'`（保留一个 i）是不对的——它需要第 0 轴与第 1 轴长度相等（方阵），结果还是对角线元素组成的向量；完整求迹要写 `'ii->'` 把两个都消掉。

**2.3**
```python
import numpy as np
np.random.seed(0)
S = np.random.rand(3, 4)
print(S.sum(axis=1).shape)                       # (3,)
print(S.sum(axis=1, keepdims=True).shape)        # (3,1)
```
- **思路**：不 `keepdims` 时被消掉的轴直接消失；`keepdims=True` 把它保留为长度 1，于是 `(3,4)` 的每一行求和后仍是 `(3,1)`。
- **点拨**：`keepdims` 的价值在于广播——归一化时你常常要做 `(X - mean) / std`，若 `mean` 是 `(3,)` 而 `X` 是 `(3,4)`，广播规则会按"尾对齐"把 `(3,)` 对到最后一维（列），语义就错了；保留成 `(3,1)` 才能正确地按行对齐。这是初学者最容易踩的形状陷阱。

### 第三组

**3.1 答案：`np.einsum('bij,bkj->bik', Q, K)`，被收缩的是 `j` 轴（即 $d_k$）。**
- **思路**：给 $Q$ 标 `b, i, j`，给 $K$ 标 `b, k, j`。共享的 `b` 各出现一次（自由指标，保留批次），`j` 出现两次（哑指标，求和消掉），剩下 `i, k` 作为结果的 token 轴。所以分数 `scores[b,i,k] = Σ_j Q[b,i,j]·K[b,k,j]`，形状 `(batch, 4, 4)`。
- **点拨**：这正是主线 DL 桥接里 $QK^T$ 的代码原型。有人会写成 `'bij,bik->bjk'`——那是在算"把 Q 的 j 与 K 的 k 配对"，不对齐 $d_k$，形状也不对。判断标准：**哑指标必须是两个输入里长度相等的那一条**（这里只有 $d_k$），并且它不出现在结果里。

**3.2 答案：这是沿特征轴的一次收缩；爱因斯坦写法是 $y_i = W_{ij} x_j$（哑指标 $j$ 被消掉）。批量时写作 `np.einsum('ij,bj->bi', W, X)` 或直接 `X @ W.T`（注意转置）。**
- **思路**：$W$ 的轴 1（长度 64）与 $x$ 的轴 0（长度 64）配对求和，留下 $W$ 的轴 0（128）作为输出神经元轴。批量输入 $X$ 形状 `(32,64)` 时，把样本轴 `b` 保留为自由指标，`'ij,bj->bi'` 得到 `(32,128)`。
- **点拨**：这也是常见陷阱——批量时有人写 `W @ X`，而 `(128,64)@(32,64)` 轴对不上。要么用 `einsum` 明确写出配对，要么给 $X$ 转置成 `(64,32)` 再 `(128,64)@(64,32)`。**优先用 einsum**：它把"哪条轴配对"写在明面上，永不歧义。

## 一个"为什么有人会答错"的提醒

1.1 的 B（减 1 而不是减 2）和 1.2 的"全部加起来得到一个数"是最常见的两个误区——前者忘了哑指标同时存在于两个张量，后者把"收缩"与"展平后点乘"混为一谈。1.2 里还有一层：**同一对张量可以沿不同轴收缩，得到不同形状的结果**——"张量点积"这个词只有在指明轴之后才有意义。这正是爱因斯坦约定存在的理由。
