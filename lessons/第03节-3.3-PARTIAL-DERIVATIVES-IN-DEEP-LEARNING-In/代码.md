# 代码：让每个权重听自己的偏导数指挥

主线里我们学会了核心那句规则：**方向由 $\partial L/\partial w_i$ 的符号决定，步幅由 $\eta$ 决定。** 这一节的脚本把这句话变成一个可以观察的训练循环：

1. 教材的二次损失 $L(w) = (w-3)^2$：从 $w=4$（导数为正，应减小）和 $w=1$（导数为负，应增大）两个方向出发，看它们如何殊途同归；
2. 一个**两个权重**的损失 $L(w_1, w_2)$：演示"每个权重各听各的偏导"——同时更新两个旋钮，各自朝各自的下降方向走；
3. 打印每一步的"符号 → 方向 → 行动"，让"偏导符号决定往哪拧"肉眼可见。

---

## 层一：完整脚本

```python
import numpy as np

# ---- ① 教材二次损失：L(w) = (w-3)^2，谷底在 w=3 ----
def loss(w):
    """单个权重的损失：离 3 越远损失越大。"""
    return (w - 3.0) ** 2

def dloss_dw(w):
    """dL/dw = 2(w-3)：符号 = 该往哪边走。"""
    return 2.0 * (w - 3.0)

# ---- ② 单权重梯度下降：打印每一步 ----
def train_single(w0, eta, steps):
    """从 w0 出发，按 w <- w - eta*dL/dw 走 steps 步，逐行打印。"""
    w = w0
    for t in range(steps):
        g = dloss_dw(w)
        w = w - eta * g                       # 朝负导方向迈一步
        print(f"第{t+1:>2}步  w={w:+.6f}  dL/dw={g:+.6f}  L={loss(w):.8f}")

print("=== 从 w=4 出发（导数为正 → 减小）===")
train_single(4.0, eta=0.1, steps=5)
print("=== 从 w=1 出发（导数为负 → 增大）===")
train_single(1.0, eta=0.1, steps=5)

# ---- ③ 两个权重的损失：每个旋钮各听各的偏导 ----
def loss2(w):
    """L = (w1-3)^2 + (w2+2)^2：谷底在 (3, -2)。"""
    return (w[0] - 3.0) ** 2 + (w[1] + 2.0) ** 2

def grad2(w):
    """∂L/∂w1 = 2(w1-3)，∂L/∂w2 = 2(w2+2)。"""
    return np.array([2.0 * (w[0] - 3.0), 2.0 * (w[1] + 2.0)])

def train_two(w0, eta, steps):
    """两个权重同步更新：每个分量用自己的偏导。"""
    w = np.array(w0, dtype=float)
    for t in range(steps):
        g = grad2(w)
        w = w - eta * g
        print(f"第{t+1:>2}步  w=({w[0]:+.4f}, {w[1]:+.4f})  g=({g[0]:+.4f}, {g[1]:+.4f})  L={loss2(w):.8f}")

print("=== 两个权重同时训练：w0 = (4, 0)，谷底 (3, -2) ===")
train_two([4.0, 0.0], eta=0.1, steps=4)
```

运行输出（Python 3.11 + NumPy）：

## 层二：分步逐函数拆解

### 步骤 1：定义 `loss` 与 `dloss_dw` —— 教材二次损失

```python
def loss(w): return (w - 3.0) ** 2
def dloss_dw(w): return 2.0 * (w - 3.0)
```

#### `loss(w)` —— 单权重损失 $L = (w-3)^2$

`return (w - 3.0) ** 2`

**做什么**：教材 Figure 3.2 的 U 形损失曲线——在 $w=3$ 处取最小值 0，两侧对称上升。
**操作**：`(w-3.0)**2` 逐项计算，永远非负。
**输入**：`w`，标量权重。
**输出**：损失值，非负标量。
**可调参数**：谷底位置 `3.0` 可以换成任何目标值。真实模型里这个函数是"预测与答案的差距"，比二次复杂得多，但"谷底 = 最佳权重"的结构相同。

#### `dloss_dw(w)` —— 偏导数 $dL/dw = 2(w-3)$

`return 2.0 * (w - 3.0)`

**做什么**：算出当前权重的"坡度"。**符号**决定方向：$w>3$ 时为正（应减小），$w<3$ 时为负（应增大），$w=3$ 时为零（谷底）。
**操作**：直接代入公式 $2(w-3)$。
**输入**：`w`，标量。
**输出**：导数，标量。带符号——这正是"方向"的载体。
**可调参数**：无。它被 `loss` 唯一决定。注意它和"谷底位置 3.0"的关系：$2(w-3)=0$ 的解恰是谷底。
**对应数学**：主线第二节 $dL/dw = 2(w-3)$，符号决定方向。

---

### 步骤 2：定义 `train_single` —— 单权重训练循环

```python
def train_single(w0, eta, steps):
    w = w0
    for t in range(steps):
        g = dloss_dw(w)
        w = w - eta * g
        print(...)
```

#### `train_single(w0, eta, steps)` —— 更新规则 $w \leftarrow w - \eta \frac{dL}{dw}$

`w = w - eta * g`

**做什么**：执行主线的更新公式：算导、看符号、按 $\eta$ 迈步、重复。
**操作**：`g = dloss_dw(w)` 算当前坡度；`eta * g` 把坡度缩放到步幅；`w - eta * g` 朝负导方向走。打印行里 `dL/dw` 的符号清晰展示了"符号决定方向"。
**输入**：
- `w0`：起始权重，标量。
- `eta`（学习率）$\eta$：步幅旋钮，标量正数。
- `steps`：迭代次数，标量整数。
**输出**：控制台逐行打印每一步的 `w`、`dL/dw`、`L`。
**可调参数**：
- `eta`：主旋钮。0.1 是教材风格的稳妥值。改成 0.6：$w=4$ 出发每步 $w \leftarrow w - 0.6\cdot2(w-3)$，一步 3.4、再一步 3.16……**逼近还是收敛**；改成 1.0 以上：$w$ 会在 3 两侧来回反弹、越来越大——发散。你可以亲手验证"学习率过大"的墙。
- `w0`：起点。4（右侧）与 1（左侧）展示了两个方向的对称行为。
- `steps`：5 步看趋势，50 步看收敛（$w$ 会逼近 3.000000，损失逼近 0）。
**对应数学**：主线定义块的 $w_{t+1} = w_t - \eta \cdot \frac{\partial L}{\partial w_i}$，一字不差。

### 步骤 3：定义 `loss2` 与 `grad2` —— 两个权重，各听各的偏导

```python
def loss2(w):
    return (w[0] - 3.0) ** 2 + (w[1] + 2.0) ** 2

def grad2(w):
    return np.array([2.0 * (w[0] - 3.0), 2.0 * (w[1] + 2.0)])
```

#### `loss2(w)` —— 二元损失 $L = (w_1-3)^2 + (w_2+2)^2$

`return (w[0] - 3.0) ** 2 + (w[1] + 2.0) ** 2`

**做什么**：两个独立方向的损失之和，谷底在 $(3, -2)$。它近似一个"只有两个权重"的微型网络——每个权重各有各的目标值。
**操作**：`w[0]`、`w[1]` 取向量两个分量，各自平方求和。因为两项解耦（无交叉项），每个权重可以独立优化——这正是"每个旋钮各听各的"的理想舞台。
**输入**：`w`，形状 `(2,)` 的权重向量。
**输出**：损失标量。
**可调参数**：目标值 `3.0`、`-2.0` 可任意改。若加上交叉项（如 $w_1 w_2$），两个权重就开始"纠缠"，梯度下降会走出弧线——那才是真实损失曲面的常态。

#### `grad2(w)` —— 梯度向量，两个偏导装进一个数组

`return np.array([2.0 * (w[0] - 3.0), 2.0 * (w[1] + 2.0)])`

**做什么**：$\partial L/\partial w_1 = 2(w_1-3)$，$\partial L/\partial w_2 = 2(w_2+2)$，装进一个形状 `(2,)` 的向量。这就是"偏导数组装成梯度"的雏形——§3.4 的完整定义。
**操作**：`np.array([...])` 把两个标量偏导打包成向量；`w - eta * g` 向量减法让两个分量**同时**各自更新。输出的 `g=(+2.0, +4.0)` 表示：$w_1$ 方向导数为正应减小，$w_2$ 方向导数为正应减小——两者同时进行。
**输入**：`w`，形状 `(2,)`。
**输出**：`g`，形状 `(2,)`，每个分量是该方向的偏导。
**可调参数**：无独立参数——由 `loss2` 决定。这正是"梯度向量"的定义方式。
**对应数学**：主线定义块在 $n=2$ 时的实例化。每个分量 $g_i$ 就是"第 $i$ 个旋钮往哪边拧"的答案。

---

### 步骤 4：定义 `train_two` —— 同步更新两个权重

```python
def train_two(w0, eta, steps):
    w = np.array(w0, dtype=float)
    for t in range(steps):
        g = grad2(w)
        w = w - eta * g
        print(...)
```

**做什么**：`w = w - eta * g` 是向量版本的更新——两个分量一次性各走各的路。$w_1$ 从 4 朝 3 走，$w_2$ 从 0 朝 -2 走，互不干扰。
**操作**：`eta * g` 是标量乘向量（广播），`w - eta*g` 是向量减法。`dtype=float` 保证浮点精度。打印行同时展示位置与梯度，让你看到"每个分量的符号各自指挥方向"。
**输入**：
- `w0`：起始向量，形状 `(2,)`（列表会被 `np.array` 转换）。
- `eta`：学习率，标量。
- `steps`：迭代次数。
**输出**：逐行打印每一步的位置、梯度、损失。
**可调参数**：`w0` 换成 $(0, 0)$，$w_1$ 应增大（导数为负）、$w_2$ 应增大（导数为正）——两个分量朝不同方向，但都在下山。`eta` 改大观察震荡。
**对应数学**：真实网络训练的就是这个向量版本的更新——只是向量维度是几千亿。**一个循环，几亿个旋钮，各自听各自的偏导。**

## 改个数字试试：学习率的两极

### 实验 1：$\eta = 1.1$ —— 越过谷底，来回反弹

```python
train_single(4.0, eta=1.1, steps=4)
```

输出（节选）：

```text
第 1步  w=+1.800000  dL/dw=+2.000000  L=1.44000000
第 2步  w=+4.560000  dL/dw=-2.400000  L=2.43360000
第 3步  w=+1.128000  dL/dw=+3.120000  L=3.50553600
第 4步  w=+5.126400  dL/dw=-3.744000  L=4.52206829
```

$\eta=1.1$ 时，$w$ 在 3 两侧**来回横跳**，损失不降反升。为什么？$|\eta \cdot dL/dw| = 1.1 \times 2|w-3| > |w-3|$——每一步迈得比"到谷底的距离"还远，于是每次都在越过谷底后跳到更远的对岸。**学习率太大 = 步子比路宽。** 这是本节的边界声明第一次变成数字。

### 实验 2：$\eta = 0.01$ —— 安全但缓慢

```python
train_single(4.0, eta=0.01, steps=5)
```

输出：

```text
第 1步  w=+3.980000  dL/dw=+2.000000  L=0.96040000
第 2步  w=+3.960400  dL/dw=+1.960000  L=0.92225522
```

5 步只走了 0.04。方向永远对，但慢得让人着急——真实训练里，这就是"损失曲线下降得像个老太太"的原因之一。**学习率太小 = 步子太保守，预算（步数）不够到谷底。** 学习率的选择，是深度学习里"快与稳"的永恒权衡。

## 边界声明：这套代码能做什么，不能做什么

1. **这是单步局部规则，不是全局保证。** 更新公式保证的是"这一步损失下降"，不是"一定到达全局最优"。对 $L=(w-3)^2$ 这种单谷函数，从任何起点都会收敛；但真实损失曲面多谷多鞍，同样的规则可能把你带进浅洼。方向对，不等于终点对。
2. **$\eta$ 的悬崖。** 代码实验 1 展示了 $\eta=1.1$ 的发散：学习率没有"绝对正确"的值，只有"对当前地形合适"的值。工程师用学习率衰减、动量、自适应学习率（Adam）来绕过这个悬崖——那是第 5 章优化论的正式战场。
3. **偏导数由谁算？** 这里 `dloss_dw`、`grad2` 都是**手写解析**的。真实网络的损失是几十亿变量的复合函数，没有人能手写全部偏导。实际由**反向传播 + 自动微分**计算（§3.5.2、§3.6）。这个脚本的价值是让你看清"方向+大小+$\eta$"的机制，而不是教你手写真实梯度。
4. **解耦是玩具特性。** `loss2` 两项无交叉，所以 $w_1$、$w_2$ 各走各的直线。真实损失函数交叉纠缠（一个权重的调整会影响其它权重的梯度），轨迹是弯曲的。别把"独立下山"的直觉当作真实网络的普遍形态——那只是这个概念最小舞台的布景。
