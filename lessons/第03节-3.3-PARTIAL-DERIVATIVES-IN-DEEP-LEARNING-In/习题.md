# 习题：深度学习中的偏导数

## 一、概念检验

### 题 1.1（填空）

梯度下降更新规则是 $w_{t+1} = w_t - \eta \cdot \dfrac{\partial L}{\partial w_i}$。其中偏导数 $\dfrac{\partial L}{\partial w_i}$ 的**符号**决定____，**大小**决定____；$\eta$（学习率）控制____。

**解答**：调整方向（增大还是减小 $w_i$）；陡峭程度（坡多陡）；每次迈步的力度（步幅）。
**思路点拨**：三个信息各司其职——方向（符号）、陡峭度（大小）、力度（$\eta$）。答"大小决定步幅"不算错但不完整：步幅其实是 $|\eta \cdot \partial L/\partial w_i|$，大小参与其中但 $\eta$ 才是总力度。能把"方向/大小/力度"拆开，才算真正读懂更新公式。

### 题 1.2（选择）

设 $L(w) = (w-3)^2$。当 $w = 5$ 时，下列说法**正确**的是（ ）

A. $\dfrac{dL}{dw} = 4 > 0$，应增大 $w$ 来降低损失
B. $\dfrac{dL}{dw} = 4 > 0$，应减小 $w$ 来降低损失
C. $\dfrac{dL}{dw} = -4 < 0$，应增大 $w$
D. $\dfrac{dL}{dw} = -4 < 0$，应减小 $w$

**解答**：B。
**思路点拨**：$dL/dw = 2(5-3) = 4 > 0$。符号为正 = 增大 $w$ 会使损失上升，所以要**减小** $w$。选 A 的同学把"导数为正"直接当成"应该增大"——但增大的是损失，权重要朝**反**方向调。**导数的符号告诉你的是"增大会怎样"，行动永远取反方向。** $w=5$ 在谷底 3 的右边，往左（减小）正是下山。

### 题 1.3（简答）

教材说偏导数（梯度）有"方向"和"大小"两个特征。请分别说明它们在更新公式 $w_{t+1} = w_t - \eta \cdot \partial L/\partial w_i$ 中扮演什么角色，并解释：为什么"方向"是第一位的？

**解答**：方向由 $\partial L/\partial w_i$ 的符号给出，它决定往哪边调——调错了方向，损失必涨，一切努力白费；大小（绝对值）给出陡峭程度，它与 $\eta$ 相乘共同决定步幅——坡越陡，这一步走得越远。方向是第一位的，因为方向错 = 南辕北辙；大小错了只是步幅不合适（可以靠调 $\eta$ 补救），方向错则每一步都在远离目标。
**思路点拨**：这个"方向第一位"的论断是理解优化的钥匙。想想真实场景：如果梯度符号算错（比如反向传播 bug），学习率再小也没用——每一步都在把权重往错误方向推。深度学习框架的数值梯度检查，本质上就是在验证"方向对不对"。

## 二、计算实践

### 题 2.1（手算）

设 $L(w) = (w-3)^2 + 2$（教材 Figure 3.2 的版本，加了常数项 2）。$\eta = 0.5$，从 $w = 4$ 出发，手算前三步的 $w$ 和损失。

**解答**：$dL/dw = 2(w-3)$（常数 2 的导数为 0）。
- 第 1 步：$w=4$，$dL/dw = 2$，$w = 4 - 0.5 \cdot 2 = 3$，$L = (3-3)^2+2 = 2$。
- 第 2 步：$w=3$，$dL/dw = 0$，$w = 3 - 0.5 \cdot 0 = 3$，$L = 2$。
- 第 3 步：$w=3$，$dL/dw = 0$，$w$ 停在 3，$L = 2$。

$\eta=0.5$ 恰好一步跳到谷底，此后梯度为零、不再移动。
**思路点拨**：注意常数项 2 在求导时消失——它只是把整条 U 形曲线**抬高**了 2，不改变谷底位置和形状，所以不改变下降路径。这是"常数平移不影响优化"的直接证据。手算一遍你就理解为什么 $\eta=0.5$ 一步到位、而 $\eta=1.1$ 会来回震荡（见《代码.md》实验 1）。

### 题 2.2（代码验证）

用 NumPy 验证题 2.1，并检验 $\eta = 1.5$ 时的发散行为。

```python
import numpy as np
def loss(w): return (w-3.0)**2 + 2.0
def dloss(w): return 2.0*(w-3.0)
def run(w, eta, n):
    for _ in range(n):
        w = w - eta * dloss(w)
    return w, loss(w)
for eta in [0.5, 1.5]:
    w, L = run(4.0, eta, 6)
    print(f"eta={eta}: w={w:.4f}  L={L:.4f}")
```

**解答**：`eta=0.5`：$w=3.0000$，$L=2.0000$（一步到位，原地不动）。`eta=1.5`：$w$ 在 3 两侧交替横跳，6 步后损失越来越大（如 $w=2.4375, L=3.3164$ 之类，取决于步数）。
**思路点拨**：$\eta=1.5$ 时 $|\eta\cdot dL/dw| = 1.5\cdot2|w-3| > |w-3|$，每步都越过谷底跳到对岸更远处——发散。这个"步幅与距离的比值"正是判断收敛/发散的分界线：$\eta \cdot |\text{斜率}| < 1$ 才可能收敛。可以试试恰好 $\eta=1$ 的边缘情形（在 3 两侧等距反弹，损失不降）。

## 三、DL 延伸

### 题 3.1

你训练一个模型，损失卡在 0.42 不动了。你检查梯度，发现某个权重 $w_i$ 的 $\partial L/\partial w_i \approx 0$。请从本节知识出发，列出"卡住"的可能解释，以及每种解释对应的排查方向。

**解答**：① $w_i$ 真的到了该方向的"平地"——它可能已到局部极小（该权重维度的优化已完成），也可能停在**鞍点**或**平坦区**（plateau），此时梯度处处接近 0，靠梯度下降无法继续推进。排查：看海森矩阵（二阶信息）判断是极小还是鞍点；对鞍点/平坦区，改用带动量的优化器（Adam、momentum）或随机重启。② 计算问题：手写梯度有 bug（如链式法则算错），导致这个权重方向的梯度被错误地归零——排查：用数值差分做梯度检查（§3.2 的 `partial_x_numeric` 思路），对照解析与数值梯度。③ 学习率太小：梯度本身不为 0 但被 $\eta$ 压得太小，每步几乎不动——排查：看训练曲线是否"极缓慢下降"，调大 $\eta$ 或改用自适应学习率。
**思路点拨**：这道题把本节"符号+大小+$\eta$"三个旋钮翻译成真实的训练卡顿诊断。能列出三条，说明你把更新公式的每个部件都接到了工程问题上。"梯度为零 ≠ 到谷底"（§3.2.1 的鞍点警告）在这里直接兑现。

### 题 3.2

一个 3 层网络有 10 万个权重。训练时你只观察到：某一步 $\partial L/\partial w_{17} = +0.03$，$\partial L/\partial w_{98888} = -0.05$。请解释：这两个数字对 $w_{17}$ 和 $w_{98888}$ 各自的调整方向是什么？如果 $\eta = 0.1$，两个权重的实际改变量是多少？为什么说"每个权重听自己的偏导"是可行的——即使网络有 10 万个权重？

**解答**：$w_{17}$ 的偏导为正 → 应减小 $w_{17}$，改变量 $-0.1 \times 0.03 = -0.003$。$w_{98888}$ 的偏导为负 → 应增大，改变量 $+0.1 \times 0.05 = +0.005$。可行是因为偏导数是**逐分量**定义和逐分量计算的：每个 $\partial L/\partial w_i$ 只回答"只动第 $i$ 个、冻结其余"时损失怎么变，因此 10 万个权重的调整是**并行独立**的——一次向量运算 $w \leftarrow w - \eta \nabla L$ 同时完成 10 万个更新，不需要"协同规划"。这正是梯度向量的意义（§3.4）：把 10 万个偏导装进一个向量，一次更新全部。
**思路点拨**：两个权重方向相反、各自行动，正是"逐分量独立性"的体现。能说出"并行独立"和"向量化一次完成"，就抓住了本节通往 §3.4 的关键一步——偏导数逐个处理，梯度向量一次搬运。
