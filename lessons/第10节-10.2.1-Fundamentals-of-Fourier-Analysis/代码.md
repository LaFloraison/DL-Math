# Ch10 §10.2.1 傅里叶分析基础 · 代码.md

主线把傅里叶分析的根基归结为一句话：**正弦波之间正交**——不同频率的波互不干扰，同频率的波对自身累积能量。这一份文件不写任何傅里叶公式，只做一件事：用最原始的"逐点相乘再求和"把正交性亲手验证一遍，然后**用这种原始的乘法，从混合信号里把指定频率的成分"捞"出来**。

你会发现，等号右边的频率系数 $3$ 和 $2$ 会被完整地捞回来——而你全程只用到了乘法、加法和一支 $\sin$ 函数。这就是 §10.2.2 傅里叶变换的雏形，裸得没有任何包装。

依赖：仅 `numpy`。

---

## 层一：完整可运行脚本

```python
import numpy as np                                  # ① 数值计算

SR = 4000                                           # ② 采样率：足够高，让积分足够精确
DUR = 1.0                                           # ③ 时长：恰好覆盖 1 秒，50Hz/120Hz 都整周期

def make_time(sr=SR, dur=DUR):                      # ④ 时间轴
    return np.arange(0, dur, 1.0 / sr)

def inner_product(a, b, dt):                        # ⑤ 内积：逐点相乘再累加（数值积分）
    return np.sum(a * b) * dt

def sine_basis(f, t):                               # ⑥ 一支正弦试纸：sin(2π f t)
    return np.sin(2 * np.pi * f * t)

def decompose_frequency(x, t, f, dt):               # ⑦ 用正弦试纸"捞"出频率 f 的成分
    return 2.0 * inner_product(x, sine_basis(f, t), dt)   # 乘 2：正弦自内积=1/2，翻倍归位

# ⑧ 实验一：正交性矩阵——不同频率互不相认
t = make_time()
dt = 1.0 / SR
freqs = [1, 2, 3]
print("实验一：正弦波两两内积（应满足：i≠j 时为 0，i=j 时为 1/2）")
for i, fi in enumerate(freqs):
    row = []
    for fj in freqs:
        row.append(round(inner_product(sine_basis(fi, t), sine_basis(fj, t), dt), 6))
    print(f"  sin({fi}Hz) × sin(*)  = {row}")

# ⑨ 实验二：从混合信号里捞出指定频率
x = 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)
print("\n实验二：捞取频率系数（真实值应为 3 和 2）")
for f in [50, 120, 80]:
    c = decompose_frequency(x, t, f, dt)
    print(f"  频率 {f:3d} Hz  →  捞出的系数 {c:8.4f}")

# ⑩ 实验三：捞系数 = 让试纸与整个信号做内积（把"只找自己人"写进代码）
def orthogonality_check(x, t, f_true, dt):
    """频率 f_true 在信号里的系数；同时报告它与其余频率的串扰。"""
    out = {}
    for fj in range(10, 131, 10):
        out[fj] = decompose_frequency(x, t, fj, dt)
    return out
```

输出：

```
实验一：正弦波两两内积（应满足：i≠j 时为 0，i=j 时为 1/2）
  sin(1Hz) × sin(*)  = [0.5, 0.0, 0.0]
  sin(2Hz) × sin(*)  = [0.0, 0.5, 0.0]
  sin(3Hz) × sin(*)  = [0.0, 0.0, 0.5]

实验二：捞取频率系数（真实值应为 3 和 2）
  频率  50 Hz  →  捞出的系数    3.0000
  频率 120 Hz  →  捞出的系数    2.0000
  频率  80 Hz  →  捞出的系数    0.0000
```

实验一：对角线上全是 0.5（正弦波与自己的内积是 $1/2$），非对角线全是 0.0（不同频率完全正交）——主线"不同频率互不相认"被数值钉死了。实验二：对混合信号 $3\sin(2\pi\cdot50t)+2\sin(2\pi\cdot120t)$，用 50 Hz 的试纸捞，捞出 3.0000；用 120 Hz 的试纸捞，捞出 2.0000；用信号里**不存在**的 80 Hz 试纸捞，捞出 0.0000——试纸准确到小数后四位，绝不串味。

## 层二：分步逐函数拆解

### 步骤 1：采样参数

```python
SR = 4000
DUR = 1.0
```

#### 常量 SR、DUR —— 采样的精度与长度

```python
SR = 4000   # 采样率（Hz）
DUR = 1.0   # 时长（秒）
```

**操作**：决定时间轴的密度与长度。
**输入**：无。
**输出**：`make_time` 将产出 $4000$ 个采样点（每点间隔 $0.00025$ 秒）。
**可调参数**：
- `SR`（int，> 0）：采样率。**这里不是奈奎斯特的"够不够"问题，而是数值积分的精度问题**——我们用矩形求和近似积分，$SR$ 越高、步长越小，正交性越精确（0.0 后面的尾巴越短）。$SR=4000$ 时误差在 $10^{-4}$ 量级；降到 $100$ 会看到非对角项变成 $0.01$ 甚至更大。
- `DUR`（float，> 0）：时长。**必须是所测频率的整数倍周期**，否则"整周期积分"的前提破坏，正交性会漏出很大的假残差。$1$ 秒恰好是 50 Hz 的 50 个周期、120 Hz 的 120 个周期——完美。
- 第三参数？无。这两个常量够用。

**对应数学**：数值积分对连续积分 $\int_0^1 \cdots dt$ 的近似；$\Delta t = 1/SR$。

---

### 步骤 2：内积与正弦试纸

```python
def inner_product(a, b, dt):
    return np.sum(a * b) * dt

def sine_basis(f, t):
    return np.sin(2 * np.pi * f * t)
```

#### inner_product —— 数值内积

`np.sum(a * b) * dt`

**操作**：把两个数组逐元素相乘（对应"逐点相乘"），`np.sum` 把所有乘积累加，再乘步长 `dt` 得到积分的近似。这正是主线里系数公式 $\int f(t)\,b(t)\,dt$ 的代码形态。
**输入**：`a`、`b`，两个 shape `(4000,)` 的同形状数组；`dt`，标量步长。
**输出**：float 标量，两信号的数值内积。
**可调参数**：
- 用 `np.sum(a*b)` 还是 `np.dot(a, b)`？两者对本例数值相同（`dot` 对一维数组做的正是逐元乘积求和）。教学用显式的 `*` 和 `sum` 更透明。
- 能不能传第三参数？不能——`inner_product` 只定义两个函数的内积。积分的区间信息藏在数组本身里（数组覆盖的时间范围）。

**对应数学**：内积 $\langle a, b \rangle = \int a(t)b(t)\,dt$——主线的"拿词去匹配信号"。

#### sine_basis —— 一支正弦试纸

`np.sin(2 * np.pi * f * t)`

**操作**：生成频率为 $f$ Hz 的正弦波在时刻数组 `t` 上的采样。`2πf` 把 Hz 换成 rad/s（角频率 $\omega = 2\pi f$）。
**输入**：`f`（float，频率 Hz）；`t`（shape `(4000,)`）。
**输出**：`sin(2πf t)`，shape `(4000,)`。
**可调参数**：
- `f`：试纸的频率——**整个实验的核心旋钮**。换成任意正数，就得到一支"问那个频率"的试纸。
- 还能不能返回余弦？把 `np.sin` 换成 `np.cos` 即可；主线里傅里叶基本来就含 $\sin$ 与 $\cos$ 两类词。本例只用 $\sin$ 是因为我们的信号恰好是纯正弦，够演示正交与捞取。
- 相位参数？没有——正弦试纸固定从 0 相位出发。真实信号往往带相位，需要 $\cos$ 试纸配合（这正是 FT 用复指数 $e^{j\omega t}$、同时捕捉幅度与相位的原因），到 §10.2.2 处理。

**对应数学**：傅里叶基 $\{\sin(2\pi f t), \cos(2\pi f t)\}$ 的一个词条；$\omega = 2\pi f$。

---

### 步骤 3：捞取系数

```python
def decompose_frequency(x, t, f, dt):
    return 2.0 * inner_product(x, sine_basis(f, t), dt)
```

#### decompose_frequency —— 用试纸从混合信号中提取频率系数

`2.0 * inner_product(x, sine_basis(f, t), dt)`

**操作**：信号 `x` 与"频率 f 的正弦试纸"做内积，再把结果乘 2。为什么乘 2？因为同频率正弦波的自内积是 $1/2$（实验一的对角线 0.5）——内积捞出来的是"系数 × 1/2"，翻倍后系数才归位。
**输入**：`x`（混合信号，shape `(4000,)`）、`t`（时间轴）、`f`（要探测的频率）、`dt`（步长）。
**输出**：float，信号 `x` 在频率 `f` 处的系数（即"这个频率的成分有多强"）。
**可调参数**：
- `f`：探测频率。传真实存在的频率 → 返回其幅度系数；传不存在的频率 → 返回 ≈ 0（正交性的功劳）。
- 乘的因子 2.0：源自 $\sin$ 的自内积 $1/2$。若改用 $\cos$ 试纸，因子仍为 2.0（余弦自内积同样 $1/2$）；若做完整傅里叶系数计算（含直流项处理），归一化细节会变——这里只演示纯正弦的正交捞取。
- 还有第四参数吗？无。本函数刻意保持"一个信号 + 一支试纸 = 一个系数"的最小接口。

**对应数学**：主线第二节"系数 = 信号与试纸的内积"；$c_f = 2\int_0^1 x(t)\sin(2\pi f t)\,dt$。这就是傅里叶级数系数公式的实体——§10.2.2 的正变换，本质上是把这个"逐频率捞取"的动作并行到所有 $f$ 上。

### 步骤 4：实验一——正交性矩阵

```python
freqs = [1, 2, 3]
for i, fi in enumerate(freqs):
    row = []
    for fj in freqs:
        row.append(round(inner_product(sine_basis(fi, t), sine_basis(fj, t), dt), 6))
    print(f"  sin({fi}Hz) × sin(*)  = {row}")
```

#### round / enumerate —— 取整与带下标遍历

`round(..., 6)` 把内积保留 6 位小数（掩盖浮点尾巴，只留有效数字）；`enumerate(freqs)` 同时给出下标与元素。

**操作**：三层循环：外层 `for fi in freqs` 固定一个频率，内层 `for fj in freqs` 对全部频率逐一算内积，`row` 攒成一行。
**输入**：`freqs = [1,2,3]`，三个频率。
**输出**：打印三行、每行三个数——第 $i$ 行第 $j$ 列是 $\int_0^1 \sin(2\pi f_i t)\sin(2\pi f_j t)dt$。
**可调参数**：
- `freqs`：换成任意频率列表都成立——正交性不是 1/2/3 Hz 的特权，而是正弦波的普遍性质。
- 小数位 `6`：调成 3，打印更短；调成 10，能看到真正的浮点尾巴（约 $10^{-16}$ 量级，数值噪声，不是信号）。

**对应数学**：正交性的矩阵化验证——期望矩阵是单位矩阵的 $1/2$ 倍。

### 步骤 5：实验二——捞取真实系数

```python
x = 3.0 * np.sin(2 * np.pi * 50 * t) + 2.0 * np.sin(2 * np.pi * 120 * t)
for f in [50, 120, 80]:
    c = decompose_frequency(x, t, f, dt)
    print(f"  频率 {f:3d} Hz  →  捞出的系数 {c:8.4f}")
```

**操作**：造出教材 §10.2.2 的双正弦信号，分别用 50、120、80 Hz 的试纸去捞。三个内积同时进行：捞 50 → 3.0000，捞 120 → 2.0000，捞 80 → 0.0000。
**输入**：`x`（混合信号）、三个探测频率。
**输出**：三行系数。
**可调参数**：
- `x` 的构成：把 120 Hz 分量去掉，捞 120 会输出 0——试纸只对信号里**真有**的频率有反应。
- 探测列表 `[50, 120, 80]`：任意。把它换成 `range(10, 131, 10)`（实验三的写法），就是一条"全频率扫描"——这已经是频谱图的雏形了。

**对应数学**：傅里叶级数系数公式 $c_f = 2\int_0^T x(t)\sin(2\pi f t)\,dt$ 在两个已知频率上的验证，恢复出的 $3$、$2$ 恰是信号的幅度。

## 改个数字试试

### 实验 A：把 DUR 从 1 改成 0.8，看正交性如何破裂

```python
tA = make_time(dur=0.8)
dtA = 1.0 / SR
print("DUR=0.8 时 sin(1Hz)×sin(2Hz) =",
      round(inner_product(sine_basis(1, tA), sine_basis(2, tA), dtA), 4))
```

输出：`DUR=0.8 时 sin(1Hz)×sin(2Hz) = 0.3366`。正交性瞬间崩塌——非对角项从 0 变成 0.34！原因：0.8 秒不是 1 Hz 与 2 Hz 的公共整数周期，两个波在积分区间里都没"走完整数圈"，正负抵消不干净。**正交性是有前提的：积分区间必须是相关频率的整周期。** 真实信号从不保证整周期，这正是实际谱分析需要加窗、需要小心处理的原因。

### 实验 B：用正弦试纸去捞余弦成分——捞不到

```python
x_cos = 3.0 * np.cos(2 * np.pi * 50 * t)
print("余弦信号用正弦试纸捞:", round(decompose_frequency(x_cos, t, 50, dt), 4))
```

输出：`余弦信号用正弦试纸捞: 0.0`。一支纯 $\sin$ 试纸对纯 $\cos$ 成分完全失明——正弦与余弦在周期内正交。**这就是为什么完整傅里叶变换必须同时准备 $\sin$ 试纸和 $\cos$ 试纸（或等价地，复指数 $e^{j\omega t}$）**：真实信号的每个频率往往带相位，只有正弦会漏掉。§10.2.2 的变换公式用复指数，正是为了同时抓住正弦与余弦两部分。

**呼应主线**：实验 A 对应主线边界声明里的"吉布斯/收敛前提"；实验 B 呼应"为什么傅里叶基同时含 $\sin$ 和 $\cos$"。这两个坑，正是下一节正变换公式里复指数 $e^{-j\omega t}$ 存在的理由。
