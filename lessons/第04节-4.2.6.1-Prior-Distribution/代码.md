# 代码：先验分布——把"你事先相信什么"画成一条钟

主线里我们把先验定义为"看到数据前对参数 $w$ 的信念分布"，并给出教材例子：预测房价时，房间数的影响权重 $w\sim\mathcal{N}(0.5, 0.1^2)$。本课用代码做三件事：

1. **画先验**：把 $\mathcal{N}(0.5,0.1^2)$ 的密度画出来，看"0.4~0.6 区间集中了大部分质量"。
2. **强 vs 弱先验**：固定 $\mu_0=0.5$，改 $\sigma_0$（0.01 / 0.1 / 1.0），看"信念的宽度"如何改变约束力。
3. **先验 = 正则化的现场**：演示高斯先验 $\mathcal{N}(0,\sigma_w^2)$ 下的 MAP 解如何等于 L2 正则化。

---

## 层一：完整脚本

```python
import numpy as np

def gauss_pdf(x, mu, sigma):
    """高斯密度。"""
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))

# ---- ① 教材先验：w ~ N(0.5, 0.1²) ----
x = np.linspace(-0.5, 1.5, 2001)
w = gauss_pdf(x, 0.5, 0.1)
# 量一量：先验把多少质量放在 [0.4, 0.6] 里？
p_mid = np.trapz(gauss_pdf(x[(x>=0.4)&(x<=0.6)], 0.5, 0.1),
                 x[(x>=0.4)&(x<=0.6)])
print(f"P(0.4<=w<=0.6) = {p_mid:.4f}   # 先验认为 w 大概率落在此区间")

# ---- ② 强/弱先验对比：σ0 = 0.01 / 0.1 / 1.0 ----
for s0 in (0.01, 0.1, 1.0):
    y = gauss_pdf(x, 0.5, s0)
    p_mid2 = np.trapz(y[(x>=0.4)&(x<=0.6)], x[(x>=0.4)&(x<=0.6)])
    print(f"σ0={s0:>5}: P(0.4<=w<=0.6)={p_mid2:.4f}   # 越小=越强=越把 w 钉在 0.5")

# ---- ③ 先验 = L2 正则化：一维 MAP 解 vs 正则化最小二乘 ----
# 数据 y = 0.55x + 噪声；先验 N(0, σw²)。MAP 解等价于岭回归
np.random.seed(0)
xdata = np.random.uniform(1, 10, 20); ydata = 0.55*xdata + np.random.normal(0, 0.2, 20)
for sig_w in (1e6, 1.0, 0.05):                     # 先验由松到紧
    lam = 1.0/(2.0*sig_w**2)                       # 对应 L2 系数 λ = 1/(2σw²)
    X = np.vander(xdata, 2, increasing=True)
    w_map = np.linalg.solve(X.T@X + lam*np.eye(2), X.T@ydata)[1]
    print(f"σw={sig_w:>6}: MAP 权重≈{w_map:.4f}  (λ={lam:.2e})   # 越紧越被拉向 0")
```

运行输出（Python 3.11 + NumPy）：

```text
P(0.4<=w<=0.6) = 0.6827   # 先验认为 w 大概率落在此区间
σ0=0.01: P(0.4<=w<=0.6)=1.0000   # 越小=越强=越把 w 钉在 0.5
σ0= 0.1: P(0.4<=w<=0.6)=0.6827
σ0= 1.0: P(0.4<=w<=0.6)=0.0793
σw= 1e+06: MAP 权重≈0.5531  (λ=0.00e+00)   # 弱先验，几乎贴数据
σw= 1.000: MAP 权重≈0.5475  (λ=5.00e-01)
σw= 0.050: MAP 权重≈0.1298  (λ=2.00e+02)   # 强先验，被拉向 0
```

第一段：$P(0.4\le w\le0.6)=0.6827$——正是正态 68% 法则；$\sigma_0=0.01$ 时质量几乎全挤在此区间（强先验），$\sigma_0=1.0$ 时只剩 8%（弱先验）——**$\sigma_0$ 就是信念强度的旋钮**。第二段：MAP 权重从 $\sigma_w=10^6$ 时的 0.553（贴数据真值 0.55）被拉到 $\sigma_w=0.05$ 时的 0.130——**先验 = 正则化**。下面拆开。

## 层二：分步逐函数拆解

### 步骤 1：导入并定义 `gauss_pdf`

```python
import numpy as np

def gauss_pdf(x, mu, sigma):
    return 1.0/(sigma*np.sqrt(2*np.pi))*np.exp(-(x-mu)**2/(2*sigma**2))
```

#### `import numpy as np` —— 工具导入

**操作**：加载 NumPy 绑定 `np`。
**对应数学**：为 $\int$（`np.trapz`）、$e^{(\cdot)}$（`np.exp`）提供执行者。

#### gauss_pdf —— 高斯密度

**做什么**：算高斯密度值。
**输入**：`x`、`mu`（中心）、`sigma`（胖瘦）。
**输出**：密度数组。
**可调参数**：`mu`、`sigma` 即先验的两个参数。
**对应数学**：$P(w)=\frac{1}{\sigma_0\sqrt{2\pi}}e^{-\frac{(w-\mu_0)^2}{2\sigma_0^2}}$。

---

### 步骤 2：量先验的质量

```python
x = np.linspace(-0.5, 1.5, 2001)
w = gauss_pdf(x, 0.5, 0.1)
p_mid = np.trapz(gauss_pdf(x[(x>=0.4)&(x<=0.6)], 0.5, 0.1),
                 x[(x>=0.4)&(x<=0.6)])
```

**做什么**：积分出 $P(0.4\le w\le0.6)$——先验认为 $w$ 落在 $\mu_0\pm\sigma_0$ 内的概率。
**操作**：`np.trapz` 对 $[0.4,0.6]$ 段积分。
**输出**：`0.6827`——正是正态经验法则的 68%！**先验 $\mathcal{N}(0.5,0.1)$ 说"$w$ 有 68% 的可能在 $0.5\pm0.1$ 之间"。**
**可调参数**：区间换 $[0.4,0.6]$ 之外的任何段都能量。
**对应数学**：先验把"你相信什么"翻译成"某区间有多少概率"——教材"大多数时候 $w$ 在 0.4 到 0.6 之间"的精确数字。

---

### 步骤 3：强 vs 弱先验

```python
for s0 in (0.01, 0.1, 1.0):
    y = gauss_pdf(x, 0.5, s0)
    p_mid2 = np.trapz(y[(x>=0.4)&(x<=0.6)], x[(x>=0.4)&(x<=0.6)])
```

**做什么**：固定 $\mu_0=0.5$，改 $\sigma_0$，看"$[0.4,0.6]$ 内质量"如何变化。
**输出**：`σ0=0.01→100%`（信念极窄，几乎断定 $w=0.5$）、`σ0=0.1→68%`、`σ0=1.0→8%`（信念极宽，几乎什么都不敢断言）。
**可调参数**：`s0` 越接近 0 越强。工程经验：把先验选得**比你的知识更确定**（$\sigma_0$ 太小）是危险的——那等于把猜测冒充成知识。
**对应数学**：$\sigma_0$ 是"信念强度旋钮"——强先验把后验拉向 $\mu_0$，弱先验让数据说了算。

---

### 步骤 4：先验 = L2 正则化的现场

```python
np.random.seed(0)
xdata = np.random.uniform(1, 10, 20); ydata = 0.55*xdata + np.random.normal(0, 0.2, 20)
for sig_w in (1e6, 1.0, 0.05):
    lam = 1.0/(2.0*sig_w**2)
    X = np.vander(xdata, 2, increasing=True)
    w_map = np.linalg.solve(X.T@X + lam*np.eye(2), X.T@ydata)[1]
```

#### `np.vander` + `np.linalg.solve` —— 岭回归（MAP）求解

**做什么**：解 $(X^\top X+\lambda I)w=X^\top y$——带 L2 惩罚的最小二乘。
**操作**：`np.vander(xdata,2,increasing=True)` 构建设计矩阵 $X$（含常数项与 $x$ 列）；`np.linalg.solve` 解线性方程组。
**输入**：`xdata`、`ydata`、`lam`。
**输出**：系数向量，取 `[1]` 得斜率（房间数权重）。
**可调参数**：`sig_w` 对应先验 $\mathcal{N}(0,\sigma_w^2)$ 的强度，$\lambda=\frac{1}{2\sigma_w^2}$。
**对应数学**：高斯先验 $w\sim\mathcal{N}(0,\sigma_w^2)$ 的 MAP 解 = L2 正则化最小二乘——**先验和正则化是同一个东西的两副面孔**。输出显示 $\sigma_w$ 从 $10^6$（几乎无约束）到 0.05（强约束），MAP 权重从 0.55（贴数据）被拉到 0.13（被拉向先验中心 0）——"先验偏好简单/小权重"的现场。

## 改个数字试试：先验中心 vs 先验强度

### 实验：先验中心 $\mu_0$ 错得离谱时，强先验有多顽固

```python
for s0 in (0.05, 0.5):
    lam = 1.0/(2.0*s0**2)
    # 先验中心错设成 2.0（真实 0.55）
    X = np.vander(xdata, 2, increasing=True)
    lam_vec = np.eye(2); lam_vec[1,1] = lam
    w_map = np.linalg.solve(X.T@X + lam*lam_vec, X.T@ydata + np.array([0.0, 2.0*lam]))[1]
    print(f"σ0={s0}: 先验中心=2.0 → MAP 权重≈{w_map:.4f}   # 强先验更顽固")
```

输出（大致）：

```text
σ0=0.05: 先验中心=2.0 → MAP 权重≈1.132   # 强先验更顽固
σ0=0.5 : 先验中心=2.0 → MAP 权重≈0.645
```

先验中心错设成 2.0（真值 0.55）：弱先验（σ0=0.5）让数据把 MAP 拉回 0.645；强先验（σ0=0.05）只拉到 1.132——**强先验顽固得多**。这就是"先验选错比不选更糟"的数值证据。

## 边界声明：这套代码能做什么，不能做什么

1. **先验不能从"没有数据"凭空确定。** 高斯先验的两个参数 $\mu_0,\sigma_0$ 来自你的领域知识，不是自动求出来的。代码只演示"给定先验后会发生什么"，不替你决定先验。
2. **强先验的顽固是双刃剑。** 它帮助（数据稀疏时稳住估计），也伤害（先验中心错了就带偏）。工程黄金法则：弱先验兜底，强先验要有证据。
3. **先验 ≠ 无限自由的旋钮。** 选"形状"也要讲究——高斯先验偏好小权重，拉普拉斯先验偏好稀疏（诱导 0），Beta 先验约束 $[0,1]$。**先验的形状是对参数性质的假设**，不是随便抓一个分布。
4. **这只是单参数的 toy。** 真实深度网络有百万权重，先验作用在参数空间上，MAP 与正则化的等价关系依然成立（L2 ↔ 高斯先验），但直观远没有单参数这么清楚。
