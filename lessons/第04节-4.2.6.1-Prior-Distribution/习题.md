# 习题：先验分布

## 第一组：概念检验

**1. 什么是先验分布？教材的房价例子里，先验 $\mathcal{N}(0.5,0.1^2)$ 的每个参数代表什么？**

**解答**：先验是"看到任何数据之前，对参数已有的信念分布"。$P(w)\sim\mathcal{N}(\mu_0,\sigma_0^2)$ 里 $\mu_0=0.5$ 是你认为"房间数对房价的影响大概在哪"，$\sigma_0=0.1$（方差 $0.1^2=0.01$）是"这个大概有多不确定"。$\sigma_0$ 越小信念越强越窄，越大越弱越宽。先验是贝叶斯旅程的起点——它编码你的领域知识或常识。

**2. 判断题并说明理由："先验一定来自主观臆断，所以应该尽量避免使用。"**

**解答**：错误，而且方向反了。即使你"拒绝"先验，均匀分布（弱先验）也在暗中扮演先验——"没有先验"在贝叶斯里不存在。先验可以来自领域知识（合理）、无信息先验（尽力中立）、或错误偏见（有害）——它的好坏取决于"是否正确"，而不是"是否用了"。数据充足时先验影响趋近于零；数据稀缺时先验是稳住估计的垫脚石。**关键不是"要不要先验"，而是"先验多强、对不对"。**

**3. 为什么"高斯先验 $\mathcal{N}(0,\sigma_w^2)$ 下的 MAP 等价于 L2 正则化"？这条等价关系在深度学习里意味着什么？**

**解答**：MAP 最大化 $\log P(w|D)\propto\log P(D|w)+\log P(w)$。高斯先验的 $\log P(w)=-\frac{w^2}{2\sigma_w^2}+$常数——加进去正好是往损失上加 $\lambda w^2$（$\lambda=1/2\sigma_w^2$），即 L2 正则化。同理 L1 对应拉普拉斯先验。**意味着 weight_decay 不只是工程技巧，它是贝叶斯"偏好小权重"的信念**——你调 `weight_decay=λ`，就是在设定高斯先验的强度。

## 第二组：计算实践

**4. 手算 + 代码验证。** 先验 $w\sim\mathcal{N}(0.5,0.1^2)$。（a）$w$ 落在 $[0.4,0.6]$ 的概率是多少？（b）若把 $\sigma_0$ 改为 $0.01$，这个概率变多少？改到 $1.0$ 呢？（c）这三个数字说明 $\sigma_0$ 控制什么？

**解答**：
（a）$[0.4,0.6]=[0.5-0.1,0.5+0.1]=\mu_0\pm\sigma_0$，正态经验法则给约 68.3%。
（b）$\sigma_0=0.01$：区间 $[0.4,0.6]=\mu_0\pm10\sigma_0$，概率几乎为 100%；$\sigma_0=1.0$：区间是 $\mu_0\pm0.1\sigma_0$，概率约 $0.08$。
（c）$\sigma_0$ 控制**信念强度**：越小越强（把 $w$ 钉在 $\mu_0$ 附近），越大越弱（几乎不约束）。

代码验证：

```python
import numpy as np
def P(a, b, mu, s):
    from math import erf
    Phi = lambda z: 0.5*(1+erf(z/np.sqrt(2)))
    return Phi((b-mu)/s) - Phi((a-mu)/s)
for s in (0.01, 0.1, 1.0):
    print(f"σ0={s:>4}: P(0.4<=w<=0.6) = {P(0.4,0.6,0.5,s):.4f}")
```

输出：

```text
σ0=0.01: P(0.4<=w<=0.6) = 1.0000
σ0= 0.1: P(0.4<=w<=0.6) = 0.6827
σ0= 1.0: P(0.4<=w<=0.6) = 0.0793
```

**思路点拨**：若有人把 (b) 的 $1.0000$ 记成"概率为 1 所以 $w$ 一定在区间内"——不，它只是"$\mu_0\pm10\sigma_0$ 覆盖了几乎所有质量"；$w$ 仍可能落在区间外，只是概率小到浮点显示为 1。**区分"概率几乎为 1"与"必然"。**

**5. 先验强度实验。** 对同一批数据，把先验强度从弱到强（$\sigma_w=10^6, 1, 0.05$）跑 MAP（岭回归），打印 MAP 权重如何被拉向先验中心 0，并解释哪个对应"几乎不管数据"、哪个对应"几乎不听数据"。

**解答**：见《代码.md》步骤 4。典型输出：$\sigma_w=10^6$ 时 MAP≈0.553（弱先验，贴数据真值 0.55）；$\sigma_w=1$ 时≈0.548（轻微拉向 0）；$\sigma_w=0.05$ 时≈0.130（强先验，被拉向先验中心 0）。**$\sigma_w$ 巨大 = 几乎不管数据（先验近似无信息）；$\sigma_w$ 很小 = 几乎不听数据（先验主导）。** 若有人答"$\sigma_w=10^6$ 时 MAP 最准"，那只是这个 toy 里数据恰好充足；真实场景中数据越少，弱先验越容易过拟合，强先验越显价值。

## 第三组：DL 延伸

**6. 迁移学习场景。** 你想用预训练模型微调到新任务。把预训练权重 $w_{pt}$ 当作"先验中心 $\mu_0$"。（a）如何用先验的语言描述迁移学习？（b）微调时通常设一个小的学习率，这和"先验强度"有什么关系？（c）如果新任务的数据极多，先验（预训练权重）还有用吗？

**解答**：
（a）预训练权重 $w_{pt}$ 是强先验的中心：$w\sim\mathcal{N}(w_{pt},\sigma_0^2)$（$\sigma_0$ 小）。贝叶斯更新从"预训练学到的表示"出发，新任务数据只做小范围修正——**迁移学习 = 从好的先验开始，而不是从零开始**。这解释了为什么微调总是比从头训练更快、更稳。
（b）小学习率让参数只做微小移动——对应"强先验"：你相信预训练权重大致正确，只允许数据轻微扰动它。大学习率则会快速逃离先验中心（相当于弱先验）。**学习率，某种意义上也是先验强度的旋钮。**
（c）数据极多时，先验被数据覆盖——后验趋近于"只用新数据"的估计（§4.2.6.2）。此时预训练先验的影响趋近于零，微调甚至可能破坏预训练学到的泛化表示。**先验在数据稀缺时是救命稻草，数据充足时让位给数据。**
**思路点拨**：若有人答"迁移学习就是初始化，跟先验无关"，那是只看到工程表象——贝叶斯视角把它上升为"强先验 + 小步修正"的结构。若有人答"先验永远有用"，提醒他数据充足时先验会被数据主导；**先验的价值与数据量成反比**。
