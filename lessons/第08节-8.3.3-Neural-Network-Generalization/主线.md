# §8.3.3 神经网络的泛化 —— 平坦处扎营，别在尖峰上过夜

## 第一步：Toy Model —— 两个学生的两种复习方式

期末考试前，班里有两个学生。

**学生 A** 复习的时候，不是去背每一道题，而是反复琢磨"这类题的套路是什么"——题目再怎么变花样，只要套路对，他就能解。考试时，他遇到没见过的题目，虽然不能满分，但能答对大部分。

**学生 B** 复习的时候，把练习册的每一道原题连同答案都背得滚瓜烂熟。考试时，凡是他背过的原题，他一字不差；但凡是稍微变了一点的题目，他就懵了——他甚至会把"变了数字的旧题"当成另一道题。

发卷那天，两人在**练习册上的题目**（训练数据）上都得了高分——B 甚至比 A 更高。但**没见过的题目**（测试数据）上，A 远胜 B。

现在问你一个"浅到可笑"的问题：**A 和 B，谁真正"学会"了？**

答案显而易见：A。因为"学会"的定义不是"记住见过的题目"，而是"对没见过的题目也能答好"——这，就是**泛化 (generalization)**。而 A 和 B 的差别，恰恰对应损失景观上的两种落点：A 落在了**平坦的极小值**（记住的是宽泛的规律，参数稍微变一点，答案也稳），B 落在了**尖锐的极小值**（记住的是具体的题目，参数钉死在训练数据的细节上，一碰就错）。

直觉已经到位：**泛化的好坏，写在模型停在损失景观的那个"落点"的形状里——平坦的落点对扰动稳健，尖锐的落点对扰动脆弱。** 但"平坦"和"尖锐"要怎样精确成能测量的量？我们凭什么说 B 会过拟合？该请数学登场了。

## 第二步：正式数学讲解

### 一、撞墙：训练误差低，不等于学得好

先撞一面所有初学者都会撞的墙。

你训练一个模型，训练集上准确率 99%。你很满意。然后拿到测试集上一测——60%。你的第一反应是"测试集太难了"或者"我的模型还不够好"。但真相往往更残酷：**你的模型没有学"什么是猫"，它学的是"训练集里那 10000 张图片长什么样"。** 它把训练样本背下来了，而背下来的东西，在没见过的新图片上派不上用场。

这就是**过拟合 (overfitting)**：训练误差极低，但泛化误差（测试误差）很高。模型"记住"了训练集的细节，而不是"理解"了数据的规律。

现在问：这个"记住细节" vs "理解规律"的差别，怎么从几何上看出来？答案藏在极小值的形状里。**如果你看训练结束时损失景观上的那个落点——如果那里"又尖又窄"，说明模型对参数极其敏感：参数稍微一动，损失就剧烈变化，预测就大幅改变——这样的模型，本质上是把预测"钉死"在训练样本的精确位置上。如果那里"又平又宽"，说明参数在很大范围内变化，损失和预测几乎不动——这样的模型，预测对扰动稳健，抓住了"宽泛的规律"。**

### 二、定义：用 Hessian 特征值度量"平坦 vs 尖锐"

把"平坦/尖锐"精确化，工具还是上一节那个老朋友——Hessian。

> **泛化与极小值的形状**
>
> 物理含义：模型停在损失景观的极小值处；该极小值越平坦（曲率越低），参数对扰动越不敏感，泛化越好；越尖锐（曲率越高），对训练细节越敏感，越容易过拟合。
>
> **平坦 vs 尖锐判据**（设 $\lambda_{\max}(H)$ 为 Hessian 最大特征值）：
> $$\text{平坦极小值}:\ \lambda_{\max}(H) \approx 0 \qquad \text{尖锐极小值}:\ \lambda_{\max}(H) \gg 0$$
>
> - $H = \partial^2 L / \partial \theta^2$ 是损失对参数的二阶导（§8.2.4 的曲率）
> - 特征值小 → 该方向曲率低 → 参数小幅移动损失几乎不变（平坦）
> - 特征值大 → 该方向曲率高 → 参数小幅移动损失剧变（尖锐）
> - 平坦极小值对应：对输入/参数扰动稳健、泛化好
> - 尖锐极小值对应：对训练细节过拟合、泛化差

每个符号逐一解释。$H$ 的特征值就是各个方向的曲率（§8.2.4）。$\lambda_{\max}(H)$ 是**最尖方向**的曲率——它决定"最坏情况下，参数动一点损失会怎样"。如果 $\lambda_{\max}$ 很小（≈0），说明即使沿最尖方向，损失也几乎不随参数变化——这是平坦极小值；如果 $\lambda_{\max}$ 很大，说明存在一个方向，参数微扰就引发损失剧变——这是尖锐极小值。

直觉检验：想象把一个球放在两种碗底。平坦极小值 = 一个浅而大的碟子——把球拨到任何位置，它都回到中心附近，损失几乎不变；尖锐极小值 = 一个又深又尖的漏斗——把球稍微拨偏一点，它就掉到完全不同的地方，损失剧烈变化。**碟子里能容错，漏斗里不容错。**

边界声明：**平坦 vs 尖锐不是二值对立，是连续谱；而且"平坦"是泛化好的强信号，不是保证。** 现实中有平坦但泛化差的边界情形（平坦也可能因其他原因失败），也有尖锐却泛化好的例外。$\lambda_{\max}(H)$ 是一个**启发式指标**——它捕捉了"参数敏感度"这一核心机制，但不能代替在测试集上的直接验证。把它当"快速体检"，不要当"终极裁决"。

### 三、展开：奇偶分类的手算——同一个任务，两种落点

用教材的例子，把"平坦 vs 尖锐"走一遍完整的数字计算。任务：用 1 个神经元 + sigmoid 的网络（$\hat y = \sigma(wx + b)$）判断"数字是奇数还是偶数"。训练数据：$x = 1,2,3,4$，标签 $y$ = 奇数 1 / 偶数 0。损失 MSE。

**模型 A（平坦落点）**：加 L2 正则化训练，收敛到 $w = 0.5, b = 0$。

$$\text{训练：}\ x=1 \to \sigma(0.5) \approx 0.622,\quad x=2 \to \sigma(1.0) \approx 0.731$$
$$\text{验证：}\ x=5 \to \sigma(2.5) \approx 0.924,\quad x=6 \to \sigma(3.0) \approx 0.953$$

A 的预测都在 0.6–0.95 之间——不完美（奇数应该接近 1、偶数应该接近 0），但**方向合理**：奇数得分高、偶数得分低。对没见过的 $x = 5$（奇数）、$x = 6$（偶数），它给出的判断方向正确。

**模型 B（尖锐落点）**：无正则化训练，收敛到 $w = 10, b = -25$。

$$\text{训练：}\ x=1 \to \sigma(10-25) = \sigma(-15) \approx 3\times10^{-7},\quad x=2 \to \sigma(-5) \approx 0.0067$$
$$\text{验证：}\ x=5 \to \sigma(50-25) = \sigma(25) \approx 1.0,\quad x=6 \to \sigma(60-25) = \sigma(35) \approx 1.0$$

B 在训练集上"完美"：$x=1$ 输出近 0（实际该判奇数 1！）、$x=2$ 输出近 0（判偶数正确）……等一下，$x=1$ 应该是奇数（标签 1），B 却输出 $\approx 0$——B 在训练集上的表现并不好？让我们重新看：$w=10, b=-25$，$\sigma(-15) \approx 3\times10^{-7}$——这被判成"偶数"（0）。但 $x=1$ 是奇数，标签是 1。所以 B 连 $x=1$ 都判错了！

这暴露了 B 的本质：$w = 10, b = -25$ 的决策边界是 $\sigma(10x - 25) = 0.5 \Rightarrow x = 2.5$——**"大于 2.5 就是奇数"**。它在训练集上的"好成绩"其实是假的（教材的例子里 B 声称训练完美，但仔细算，$x=1$ 它判成偶数）。无论如何，更致命的是验证集：$x = 6$（偶数）输出 $\sigma(35) \approx 1.0$——**判成奇数，错了**。B 用一个脆弱的阈值 $x = 2.5$ 硬切，训练里没见过的数字 $x = 6$ 被它"推理"错了。

**两种落点的对比**：A 的 $w = 0.5$ 很小，权重对参数的微小变化不敏感——把 $w$ 从 0.5 改成 0.6，预测几乎不变（平坦）；B 的 $w = 10$ 很大，$\lambda_{\max}$ 大——把 $w$ 从 10 改成 11，$\sigma(10x-25)$ 的边界剧烈移动，预测大变（尖锐）。A 损失"背下训练集"的机会，换来了"对未见过数字也合理"的稳健；B 精准拟合（或看似精准），却在边界外崩溃。

### 四、展开：为什么"平坦"带来"稳健"

把机制再挖深一层。平坦极小值为什么泛化好？核心是**参数敏感度**：

- **平坦极小值**：$\lambda_{\max}(H)$ 小 → 损失在极小值附近的大范围内变化缓慢 → 参数 $\theta$ 在这个范围内怎么挪，预测都几乎不变。于是：① 对输入的小扰动（噪声、光照、角度）不敏感——输出稳定；② 对训练数据的"巧合"不敏感——没有把预测钉死在具体样本上，学到的是"宽泛的模式"。
- **尖锐极小值**：$\lambda_{\max}(H)$ 大 → 损失对参数极度敏感 → 模型把预测"锚定"在精确的参数值上，而这些精确值只对训练样本有意义。输入一变、参数一动，输出就大幅震荡——这是过拟合的几何签名。

教材给出一个精炼的判据：$\lambda_{\max}(H) \approx 0$（平坦）vs $\lambda_{\max}(H)$ 很大（尖锐）。**泛化的好坏，被一个数字——Hessian 最大特征值——高度概括。** 这个数字，正是我们在 §8.3.1 里为损失景观分类时用过的那把尺子，现在它多了一个用途：预测泛化。

## 第三步：DL 桥接

"平坦极小值泛化好"在真实深度学习里催生了大量实践，最著名的三个：

- **正则化把模型推向平坦**（§8.4.1 的入口）：L2 正则化、权重衰减、dropout，都在惩罚"对参数过度敏感"的解——几何上，它们引导优化走向曲率更低、更平坦的极小值。教材的 Model A 用了 L2，所以落在平坦处。
- **Sharpness-Aware Minimization (SAM)**：直接把"找平坦极小值"写进优化目标——最小化"以当前点为中心的小球内的最坏损失"（$\max_{\|\epsilon\| \le \rho} L(\theta + \epsilon)$）。它显式地把 $\lambda_{\max}(H)$ 当敌人打，实证大幅提升泛化。
- **平坦性作为评估信号**：训练完成后，算 $\lambda_{\max}(H)$ 或做"扰动-稳定测试"（§8.2.4 习题），在跑测试集之前快速预判泛化。

一句话串起整节：**泛化不是玄学，它是几何——模型停得越平，对世界越宽容；停得越尖，只对训练集忠诚。** 下一节，我们把几何从"损失景观"推到"概率分布的空间"，认识 Fisher 度量与信息几何。
