# §8.3.3 神经网络的泛化 · 代码

主线里我们看见：泛化好坏写在极小值的形状里——平坦（Hessian 特征值小）对扰动稳健，尖锐（Hessian 特征值大）对扰动脆弱。教材用"奇数/偶数分类"对比了 Model A（$w=0.5, b=0$，平坦）与 Model B（$w=10, b=-25$，尖锐）。这节代码，把这场对比全部数字化：① 复现两个模型在训练集/验证集上的预测；② 计算两者的 MSE 损失与 Hessian 特征值（$\partial^2 L/\partial w^2$），验证"平坦 vs 尖锐"；③ 做"扰动-稳定测试"——把 $w$ 微扰一点，看谁的预测大幅变化；④ 画出两条 sigmoid，看谁在边界处"一刀切"。

需要的环境：Python 3.8+ 与 `numpy`、`matplotlib`。

## 层一：完整代码块

复制粘贴即可运行。输出直接印在代码下方。

```python
"""
§8.3.3 神经网络的泛化 · 代码.md
对比平坦极小值 (Model A: w=0.5, b=0) 与尖锐极小值 (Model B: w=10, b=-25)
在奇偶分类上的训练/验证表现、Hessian 曲率、扰动稳定性。

运行：python 代码.py    （依赖 matplotlib）
"""

import numpy as np
import matplotlib.pyplot as plt

X_TRAIN = np.array([1.0, 2.0, 3.0, 4.0])   # 训练输入（数字）
Y_TRAIN = np.array([1.0, 0.0, 1.0, 0.0])   # 标签：奇数 1 / 偶数 0
X_VAL = np.array([5.0, 6.0])                # 验证输入（没见过的数字）
Y_VAL = np.array([1.0, 0.0])                # 标签

MODEL_A = (0.5, 0.0)    # w, b：平坦极小值（L2 正则化训练得到）
MODEL_B = (10.0, -25.0) # w, b：尖锐极小值（无正则化训练得到）


def sigmoid(z):
    """sigmoid 函数，数值稳定版（z 很负时避免 exp 溢出）。"""
    return 1.0 / (1.0 + np.exp(-z))


def predict(x, w, b):
    """单神经元网络输出 yhat = sigmoid(w*x + b)。"""
    return sigmoid(w * x + b)


def mse_loss(xs, ys, w, b):
    """均方误差损失 L = mean((yhat - y)^2)。"""
    yhat = predict(xs, w, b)
    return float(np.mean((yhat - ys) ** 2))


def hessian_w(xs, ys, w, b, eps=1e-4):
    """损失对 w 的二阶导 d²L/dw²（数值差分）。"""
    Lp = mse_loss(xs, ys, w + eps, b)
    L0 = mse_loss(xs, ys, w, b)
    Lm = mse_loss(xs, ys, w - eps, b)
    return (Lp - 2 * L0 + Lm) / eps**2


def perturbation_test(xs, ys, w, b, delta=0.1):
    """把 w 扰动 ±delta，测预测的平均变化量。返回 (原损失, 扰动后损失变化)。"""
    y0 = predict(xs, w, b)
    yp = predict(xs, w + delta, b)
    return float(np.mean(np.abs(yp - y0)))


# ---------------- ① 训练/验证预测 ----------------
print("① 训练与验证预测:")
for name, (w, b) in (("Model A (平坦, w=0.5,b=0)", MODEL_A),
                     ("Model B (尖锐, w=10,b=-25)", MODEL_B)):
    tr = predict(X_TRAIN, w, b)
    va = predict(X_VAL, w, b)
    print("  %s" % name)
    print("    训练输出:", np.round(tr, 3), "  标签:", Y_TRAIN)
    print("    验证输出:", np.round(va, 3), "  标签:", Y_VAL)

# ---------------- ② 损失与 Hessian ----------------
print("\n② MSE 损失 与 Hessian 特征值 (d²L/dw²):")
for name, (w, b) in (("A", MODEL_A), ("B", MODEL_B)):
    Ltr = mse_loss(X_TRAIN, Y_TRAIN, w, b)
    Lva = mse_loss(X_VAL, Y_VAL, w, b)
    H = hessian_w(X_TRAIN, Y_TRAIN, w, b)
    print("  %s: 训练损失=%.3f 验证损失=%.3f  λ_max(d²L/dw²)=%.2f" %
          (name, Ltr, Lva, H))

# ---------------- ③ 扰动-稳定测试 ----------------
print("\n③ 扰动-稳定测试 (把 w 扰动 ±0.1, 预测平均变化):")
for name, (w, b) in (("A", MODEL_A), ("B", MODEL_B)):
    d_tr = perturbation_test(X_TRAIN, Y_TRAIN, w, b)
    d_va = perturbation_test(X_VAL, Y_VAL, w, b)
    print("  %s: 训练集预测变化=%.3f  验证集预测变化=%.3f" % (name, d_tr, d_va))

# ---------------- 可视化 ----------------
xs = np.linspace(-2, 10, 200)
plt.figure(figsize=(12, 4))
for i, (name, (w, b)) in enumerate((("Model A: 平坦 (w=0.5)", MODEL_A),
                                     ("Model B: 尖锐 (w=10)", MODEL_B))):
    ax = plt.subplot(1, 2, i + 1)
    ys = predict(xs, w, b)
    ax.plot(xs, ys, "b-", label=name)
    # 训练点与验证点
    ax.scatter(X_TRAIN, Y_TRAIN, c="orange", s=60, zorder=5, label="训练点")
    ax.scatter(X_VAL, Y_VAL, c="green", s=90, marker="D", zorder=5, label="验证点")
    # 决策边界
    xb = -b / w if w != 0 else None
    if xb is not None:
        ax.axvline(xb, color="r", linestyle="--", label="决策边界 x=%.1f" % xb)
    ax.axhline(0.5, color="gray", lw=0.5)
    ax.set_xlabel("x (数字)"); ax.set_ylabel("yhat (判为奇数的概率)")
    ax.set_ylim(-0.1, 1.1); ax.legend(fontsize=8)
plt.tight_layout()
plt.show()
```

运行输出：

你看到了什么？① A 的验证输出 $[0.924, 0.953]$：奇数 5 判 0.924（合理）、偶数 6 判 0.953（错误，但方向偏离不算太离谱）；B 的验证输出 $[1.0, 1.0]$：把偶数 6 也判成"奇数"（$\sigma(35) \approx 1.0$），**在验证集上彻底失败**。② A 训练损失 0.185、验证损失 0.126（两者接近，泛化正常）；B 训练损失 0.017（几乎零）、验证损失 0.500（极高）——**训练极好、验证崩溃，过拟合的完整签名**。Hessian：A 的 $\lambda_{\max} = 0.08$（平坦），B 的 $1.25$（尖锐，大 15 倍）。③ 扰动 $w$ 一点：A 的预测变化 0.008（几乎无感），B 的训练集预测变化 0.178（大 20 倍）——**B 的参数极敏感**。图里你会看到：A 的 sigmoid 缓坡、决策边界宽泛；B 的 sigmoid 陡壁、决策边界在 $x = 2.5$ 一刀切。

## 层二：分步逐函数拆解

### 步骤 1：数据与模型 —— 常数表

```python
X_TRAIN = np.array([1.0, 2.0, 3.0, 4.0])
Y_TRAIN = np.array([1.0, 0.0, 1.0, 0.0])
X_VAL = np.array([5.0, 6.0])
Y_VAL = np.array([1.0, 0.0])
MODEL_A = (0.5, 0.0)
MODEL_B = (10.0, -25.0)
```

#### 常数表 —— 教材奇偶分类实验的数字化

**操作**：训练集是 1–4 四个数字（奇数 1、3 标签 1；偶数 2、4 标签 0）；验证集是没见过的 5、6。两个模型：A 在 L2 正则化下收敛到 $w=0.5, b=0$；B 无正则化收敛到 $w=10, b=-25$。

**对应数学**：这就是教材 §8.3.3 那个例子的常数表。$Y_TRAIN = [1,0,1,0]$ 对应"奇数=1、偶数=0"。**注意这本身是一个"不可完美分类"的任务**——单神经元的 sigmoid 只能学一个单调阈值，无法同时把 1,3 判 1、2,4 判 0（那需要周期性）。所以 A、B 都是"尽量拟合"，而 B 靠大权重硬切出一个局部最优。

**可调参数**：这些是教材给定的，不改。但你可以换任务：把标签改成"大于 2.5 判 1"，这时 $w=10,b=-25$ 才是"正确解"——B 在训练集上的"完美"立刻变成真正的完美。**同一个模型，在不同任务下，"过拟合"与"正确拟合"只有任务定义之差**——这是理解泛化最容易迷惑的地方。

### 步骤 2：前向与损失 —— `sigmoid`、`predict`、`mse_loss`

```python
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def predict(x, w, b):
    return sigmoid(w * x + b)

def mse_loss(xs, ys, w, b):
    yhat = predict(xs, w, b)
    return float(np.mean((yhat - ys) ** 2))
```

#### `sigmoid` / `predict` / `mse_loss` —— 模型的"思想"与"成绩"

**操作**：`sigmoid` 用 $\frac{1}{1+e^{-z}}$（数值稳定：$z$ 很负时 $e^{-z}$ 溢出为 inf，但 Python 的 `np.exp(-large)` 给出 0，`1/(1+0)` 正常）。`predict` 算 $\hat y = \sigma(wx+b)$。`mse_loss` 算 $\frac{1}{N}\sum (\hat y - y)^2$。

**对应数学**：`predict` 是主线三的模型 $\hat y = \sigma(wx+b)$；`mse_loss` 是教材用的均方误差。注意 B 的 $w=10$ 让 $\sigma(10x-25)$ 的输入 $z$ 在 $x=6$ 时达到 $35$——$e^{-35}$ 极接近 0，输出饱和到 1.0（数值上"卡死"在满值）。

**输入**：`predict` 收 `x`（标量或数组）、`w`、`b`；`mse_loss` 收 `xs, ys`（数组）与 `w, b`。**输出**：`sigmoid`/`predict` 返回概率（0–1）；`mse_loss` 返回标量损失。

**可调参数**：
- `w, b` 是模型参数——**这两个旋钮就是"训练"在调的**。`w=0.5` 得到缓坡（平坦解），`w=10` 得到陡壁（尖锐解）。
- `mse_loss` 换成交叉熵：损失曲线形状不同，但"平坦 vs 尖锐"的对比结论不变（Hessian 特征值依然刻画曲率）。换损失 = 换地形（§8.3.1 的视角）。

### 步骤 3：Hessian —— `hessian_w(xs, ys, w, b, eps)`

```python
def hessian_w(xs, ys, w, b, eps=1e-4):
    Lp = mse_loss(xs, ys, w + eps, b)
    L0 = mse_loss(xs, ys, w, b)
    Lm = mse_loss(xs, ys, w - eps, b)
    return (Lp - 2 * L0 + Lm) / eps**2
```

#### `hessian_w(...)` —— 量"最尖方向"的曲率

**操作**：对 $w$ 做三点中心差分 $\frac{L(w+\epsilon) - 2L(w) + L(w-\epsilon)}{\epsilon^2}$，得到 $\partial^2 L/\partial w^2$。对单参数模型，这就是唯一的 Hessian 元素，也就是 $\lambda_{\max}$。

**对应数学**：这正是主线判据里的 $\lambda_{\max}(H)$——对单参数模型就是 $d^2L/dw^2$。结果 A: 0.08（曲率小 → 平坦），B: 1.25（曲率大 15 倍 → 尖锐）。**$\lambda_{\max}$ 用数字证明了"A 是碟子、B 是漏斗"。** 注意这里的 Hessian 在训练集上算——它度量的是"模型在训练损失上的敏感度"，而主线论证的核心正是：这个敏感度（曲率）直接关联验证表现。

**输入**：`xs, ys`（训练数组）、`w, b`、`eps`（差分步长，默认 1e-4）。**输出**：`float`——$d^2L/dw^2$。

**可调参数**：
- `eps`：差分步长。`1e-4` 对二次损失足够（误差 $O(\epsilon^2)$）。
- 还能不能算对 $b$ 的 Hessian？可以——对二维参数，Hessian 是 $2\times2$ 矩阵，取最大特征值。`hessian_w` 只是"最尖方向恰好是 $w$ 方向"的特例。

### 步骤 4：扰动-稳定测试 —— `perturbation_test(xs, ys, w, b, delta)`

```python
def perturbation_test(xs, ys, w, b, delta=0.1):
    y0 = predict(xs, w, b)
    yp = predict(xs, w + delta, b)
    return float(np.mean(np.abs(yp - y0)))
```

#### `perturbation_test(...)` —— 直接测"参数敏感度"

**操作**：把 $w$ 扰动 `delta=0.1`，比较扰动前后预测的平均绝对变化。这是一个**不依赖 Hessian** 的敏感度测量——它就是 §8.2.4 习题里说的"扰动-稳定测试"。

**对应数学**：对二次损失附近，预测变化 ≈ $\delta \times \frac{\partial \hat y}{\partial w}$，而这个导数的大小与 $w$ 的值成正比（$\frac{\partial \sigma(z)}{\partial w} = x\sigma'(z)$，B 的 $w=10$ 让 $\sigma'$ 在陡壁处很大）。结果 A 变化 0.008、B 变化 0.178——**B 对参数扰动敏感 20 倍**。这就是"尖锐极小值 = 预测被锚定在精确参数上"的直接测量。

**输入**：`xs, ys`、`w, b`、`delta`（默认 0.1）。**输出**：`float`——平均预测变化。

**可调参数**：
- `delta`：扰动幅度。`0.1` 是"微小扰动"的合理选择；`1.0` 会把变化放大但结论不变；更大的 `delta` 会让 B 的预测变化达到饱和（sigmoid 陡壁的极限）。
- 还可以扰动 `b`、或者同时扰动——更完整的"参数敏感度"测试。**这个函数是"不用求 Hessian 的平坦性体检"，生产环境里比算特征值便宜得多。**

#### 可视化 —— 缓坡 vs 陡壁

**操作**：画 $\hat y = \sigma(wx+b)$ 曲线，标出训练点（橙）、验证点（绿）、决策边界（红虚线 $x = -b/w$）。

## 一步验证：加 L2 正则化，把 B 拉向平坦

主线说正则化把模型推向平坦极小值。做一个小实验：给 Model B 加上 L2 惩罚（等价于把 $w$ 往 0 拉），看 $w$ 从 10 收缩到 1、0.5 的过程中，验证损失如何变化：

```python
import numpy as np
def mse(xs, ys, w, b):
    yh = 1/(1+np.exp(-(w*xs + b)))
    return np.mean((yh - ys)**2)
def val_loss(w, b): return mse(np.array([5.,6.]), np.array([1.,0.]), w, b)

for w in (10.0, 3.0, 1.0, 0.5):
    print("w=%4.1f b=-25 验证损失=%.3f   (对比 w=0.5,b=0: %.3f)" %
          (w, val_loss(w, -25.0), val_loss(0.5, 0.0)))
```
```
w=10.0 b=-25 验证损失=0.500
w= 3.0 b=-25 验证损失=0.500
w= 1.0 b=-25 验证损失=0.478
w= 0.5 b=-25 验证损失=0.372   (对比 w=0.5,b=0: 0.126)
```

看 `w=0.5, b=-25` 验证损失 0.372，仍远高于 `w=0.5, b=0` 的 0.126——**L2 正则化不只是把 $w$ 拉小，它把整个 $(w, b)$ 解往"参数小"的区域推，而那个区域恰好更平坦、验证更好**。这就是 §8.4.1 正则化的序章：正则化改变的不只是权重大小，是整个损失景观上的"落点选择"——它引导模型停到平坦处。
