# §8.3.3 神经网络的泛化 —— 习题

本章主线讲了三件事：泛化是"对没见过数据的表现"；模型停在损失景观的极小值，其形状（平坦 vs 尖锐）由 Hessian 特征值刻画，决定泛化好坏；平坦极小值对扰动稳健、泛化好，尖锐极小值对训练细节敏感、过拟合。下面的习题分三组：**概念检验** 验证核心判据，**计算实践** 把平坦 vs 尖锐亲手算一遍（含代码验证），**DL 延伸** 把泛化几何用回真实训练。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：关于平坦极小值，哪个说法**错误**？

- A. 平坦极小值处 Hessian 特征值较小（曲率低）
- B. 平坦极小值对参数扰动不敏感，预测稳定
- C. 平坦极小值一定意味着全局最小值
- D. 平坦极小值通常与更好的泛化相关

**解答**：C。

C 错：**平坦极小值只描述"局部曲率低"，不保证是全局最优**。它可能是一个"又平又宽"的局部极小值，甚至可能不是真正的最小值（平坦区域）。A 对：特征值小 = 曲率低 = 平坦。B 对：这是平坦的核心机制——参数一动损失不变。D 对：这是 §8.3.3 的核心经验结论（强信号，非保证）。

**思路点拨**：题眼是"平坦"是"局部形状"属性，不是"全局最优"属性。最容易错的直觉是"又平又深 = 一定最好"——平坦只说明"稳"，不说明"低"。判据：把"平坦"和"全局最优"当成两个正交的属性，分别判断。

### 题 2（判断 + 简答）：训练误差低但泛化差，几何上意味着什么？

一个模型在训练集上损失 0.01，测试集上损失 0.5。用极小值形状的语言解释：这个模型很可能停在了什么形状的极小值？为什么？

**解答**：**很可能停在尖锐极小值**。判据：训练损失极低（0.01）说明模型把训练集拟合到近乎完美——这要求参数被"钉"在能精确复现训练样本的位置；而测试损失高（0.5）说明这些精确参数在没见过的数据上失效。这正是尖锐极小值的签名：$\lambda_{\max}(H)$ 大 → 参数对扰动极敏感 → 模型"记住"了训练细节（训练损失低）却无法泛化（测试损失高）。

对照：如果停在平坦极小值，训练损失可能略高（0.1 左右，因为没把每个样本抠死），但测试损失也会低（模型抓住了宽泛规律）。**"训练低 + 测试高" = 尖锐 = 过拟合；"训练略高 + 测试也合理" = 平坦 = 泛化好。** 这是教材 Model A vs Model B 的核心对比。

**思路点拨**：这道题把"过拟合"翻译成几何。核心判据：训练-测试损失**差距**大 + 训练损失接近零 → 尖锐。易错回答是笼统说"过拟合了"而不落到"极小值形状"。判据一句话：**训练低测试高，就是停得太尖；训练略高测试稳，就是停得够平。**

### 题 3（简答）：为什么"对参数扰动不敏感"会带来泛化？

"平坦极小值 = 参数扰动不敏感"这个机制，为什么能推出"泛化好"？请从"数据噪声"角度给一条推理链。

**解答**：推理链如下：

1. 测试数据与训练数据不完全相同——测试输入会有一点点扰动（光照、噪声、角度、笔迹差异）；
2. 这些输入扰动，在训练好的模型里等价于"参数的等效微小变化"（输入变了，等价于决策函数在小范围内移动）；
3. 平坦极小值对参数微小变化不敏感 → 输入扰动导致的输出变化极小 → 模型对测试数据的"合理变化"保持稳定判断；
4. 尖锐极小值对参数微小变化极敏感 → 输入一扰动，输出大幅震荡 → 模型在测试数据上判断不稳。

所以"平坦 = 对扰动不敏感 = 对新输入稳健 = 泛化好"是一个完整的因果链。核心环节是第 3 步：**平坦性把"输入的合理变化"变成"输出的稳定"，这正是泛化要的。**

**思路点拨**：这是主线"为什么平坦带来稳健"的因果重构。关键是把"参数扰动"与"输入扰动"连起来——两者在小范围内等效（都由决策函数的局部敏感度决定）。判据：能说出"平坦性 = 敏感度低 = 对新输入的稳健"这整条链，说明真正理解了机制而不只是背结论。

## 二、计算实践

### 题 1（奇偶分类的预测手算）

模型 $\hat y = \sigma(wx + b)$，任务：判奇数/偶数，训练数据 $x = 1,2,3,4$，标签 $[1,0,1,0]$。

(a) Model A（$w=0.5, b=0$）：手算 $x=1,2,5,6$ 的输出。
(b) Model B（$w=10, b=-25$）：手算 $x=1,2,5,6$ 的输出。
(c) 比较两个模型的验证表现（$x=5,6$），谁的泛化好？为什么？

**解答**：

(a) A：$x=1 \to \sigma(0.5) \approx 0.622$；$x=2 \to \sigma(1.0) \approx 0.731$；$x=5 \to \sigma(2.5) \approx 0.924$；$x=6 \to \sigma(3.0) \approx 0.953$。

(b) B：$x=1 \to \sigma(-15) \approx 3\times10^{-7}$；$x=2 \to \sigma(-5) \approx 0.0067$；$x=5 \to \sigma(25) \approx 1.0$；$x=6 \to \sigma(35) \approx 1.0$。

(c) 验证集是 $x=5$（奇数，标签 1）、$x=6$（偶数，标签 0）。A 给出 0.924、0.953——方向合理（5 判奇数接近 1，6 判奇数偏高但模型单调、没有训练数据支撑偶数在高值区）。B 给出 1.0、1.0——把偶数 6 判成"奇数"，**验证失败**。所以 A 泛化更好：它在训练集上"不够完美"（损失 0.185），但验证损失低（0.126）；B 训练损失低（0.017）却验证崩溃（0.500）。**A 用"不完美拟合"换来了"对新数字的稳健"。**

**思路点拨**：这是教材 §8.3.3 例子的手算版。核心是 (c) 的对比：A"训练略差 + 验证好"，B"训练好 + 验证差"。最容易错的地方是只算训练集——必须同时算验证集，因为泛化的定义就是"没见过的数据"。判据：**验证表现 = 泛化的裁判，训练表现只是拟合的证人。**

### 题 2（Hessian 特征值手算）

单参数模型，损失 $L(w) = \frac{1}{N}\sum_i (\sigma(wx_i + b) - y_i)^2$。为简化，用"线性化"近似：设 $\sigma(wx+b) \approx \alpha w$（局部线性），于是 $L(w) \approx \frac{1}{N}\sum_i (\alpha w - y_i)^2$。

(a) 写出 $d^2L/dw^2$ 的表达式。
(b) 若训练数据 $y_i$ 接近 $\alpha w_0$（拟合得好），则 $L(w_0)$ 小；此时 $d^2L/dw^2$ 是多少？它只依赖什么？
(c) 用 (b) 解释：为什么"拟合得越紧（$w$ 越大）"的模型，$d^2L/dw^2$ 反而越大（越尖锐）？

**解答**：

(a) 对 $L(w) \approx \frac{1}{N}\sum_i (\alpha w - y_i)^2$，一阶导 $\frac{2\alpha}{N}\sum_i(\alpha w - y_i)$，二阶导：
$$\frac{d^2L}{dw^2} = \frac{2\alpha}{N}\sum_i \alpha = 2\alpha^2$$

(b) 关键发现：$d^2L/dw^2 = 2\alpha^2$ **与 $w$ 无关，只依赖 $\alpha$**——而 $\alpha$ 是"$\sigma(wx+b)$ 对 $w$ 的灵敏度"。在陡峭区（$w$ 大、$x$ 大），$\alpha = x\sigma'(wx+b)$ 很大，所以 $d^2L/dw^2$ 很大。

(c) 所以"尖锐"的几何来源是：**拟合得紧的模型，其决策函数在边界处很陡（$\sigma'$ 大）→ 等效 $\alpha$ 大 → 损失对 $w$ 的二阶导大 → 尖锐。** 模型 B（$w=10$）的 $\sigma'$ 在决策边界处远大于模型 A（$w=0.5$）的 $\sigma'$，所以 B 的 $d^2L/dw^2$ 大 15 倍。**大权重 + 陡峭 sigmoid = 高曲率 = 尖锐 = 脆弱。**

**NumPy 验证**（精确算，不用线性化）：
```python
import numpy as np
def mse(xs, ys, w, b):
    yh = 1/(1+np.exp(-(w*xs+b)))
    return np.mean((yh-ys)**2)
def H(w, b, eps=1e-4):
    return (mse(X, Y, w+eps, b) - 2*mse(X, Y, w, b) + mse(X, Y, w-eps, b)) / eps**2
X = np.array([1.,2.,3.,4.]); Y = np.array([1.,0.,1.,0.])
print("d²L/dw² @ A(w=0.5,b=0) = %.3f" % H(0.5, 0.0))
print("d²L/dw² @ B(w=10,b=-25) = %.3f" % H(10.0, -25.0))
```
```
d²L/dw² @ A(w=0.5,b=0) = 0.080
d²L/dw² @ B(w=10,b=-25) = 1.250
```

**思路点拨**：这道题揭示了"尖锐"的机制来源——不是损失函数本身，而是**决策函数在边界处的陡峭度**。核心命题：$\lambda_{\max}(H)$ 大 ⇔ 决策函数对参数敏感 ⇔ 边界陡峭。判据：**大权重往往伴随陡峭边界，陡峭边界 = 高曲率 = 尖锐 = 脆弱。** 这也是为什么 L2 正则化（压小权重）能把模型推向平坦——它同时压平了决策函数的陡峭度。

### 题 3（扰动-稳定测试）

不用算 Hessian，用"扰动-稳定测试"判断两个模型的平/尖：把权重 $w$ 扰动 $+0.1$，分别记录两个模型在训练集上的预测变化。

(a) 设计并描述这个测试的具体步骤。
(b) 预测：Model A（$w=0.5$）与 Model B（$w=10$）谁会变化更大？为什么？
(c) 这个测试和 Hessian 特征值是什么关系？（提示：一阶泰勒展开）

**解答**：

(a) 步骤：① 对训练集每个 $x_i$，算原预测 $\hat y_i = \sigma(wx_i+b)$；② 把 $w$ 换成 $w+0.1$，重新算预测 $\hat y_i'$；③ 求平均绝对变化 $\frac{1}{N}\sum |\hat y_i' - \hat y_i|$。这个数值就是"参数扰动 0.1 引起的预测平均变化"。

(b) **B 变化更大**。因为 $\hat y$ 对 $w$ 的敏感度是 $\frac{\partial \hat y}{\partial w} = x\sigma'(wx+b)$；B 的 $w=10$ 让 $\sigma'(10x-25)$ 在决策边界处达到峰值（$\sigma'$ 最大约 0.25），而 A 的 $\sigma(0.5x)$ 在训练区间内 $\sigma'$ 很小（平缓）。代码结果：A 变化 0.008、B 变化 0.178——B 敏感 20 倍。

(c) 关系：对小的 $\delta$，一阶泰勒 $\hat y(w+\delta) - \hat y(w) \approx \delta \cdot \frac{\partial \hat y}{\partial w}$。而"预测对参数的敏感度"的平方，与损失对参数的二阶导（Hessian）成正比——因为 $L$ 对 $w$ 的二阶导正是 $\frac{2}{N}\sum (\frac{\partial \hat y}{\partial w})^2 + (\text{残差项})$。**扰动-稳定测试是 Hessian 特征值的"直接测量"**：它不经过损失，直接测"参数一动预测变多少"，本质上是同一个几何量（曲率/敏感度）的两个侧面。

**思路点拨**：这道题教"不用二阶导的平坦性体检"。核心：扰动-稳定测试与 Hessian 测的是**同一个东西**（参数敏感度），一个直接一个间接。判据：**生产环境里算不动 Hessian 时，就用扰动-稳定测试——它便宜、直观、结论一致。** 这也是 SAM 的动机：直接用邻域最坏损失，而不是显式求特征值。

## 三、DL 延伸

### 题 1（两个模型选型）

两个模型在训练集上都达到 98% 准确率。模型 X 的 $\lambda_{\max}(H) = 0.3$，模型 Y 的 $\lambda_{\max}(H) = 40$。在没有测试集结果的情况下，你更看好谁？你愿意用多少把握下这个赌注？为什么？

**解答**：**更看好 X，但把握有限（约"倾向性"而非"保证"）。** 理由：两者训练表现相同，但 X 落在平坦极小（$\lambda_{\max}$ 小，对扰动不敏感），Y 落在尖锐极小（$\lambda_{\max}$ 大，对扰动极敏感）。按"平坦极小值泛化好"的经验规律，X 更可能泛化好——它的解更稳健、更可能学到宽泛模式而非训练细节。

但把握"有限"是因为：① $\lambda_{\max}$ 是启发式，不是充分条件——有平坦但泛化差的边界情形；② 泛化还受数据分布、架构、随机种子影响；③ 最终判决必须在留出测试集上做。所以这是一个"概率性赌注"（下注 X 有道理），不是"确定性结论"。**$\lambda_{\max}$ 用于预筛与设计（SAM），测试集用于裁决。**

**思路点拨**：这道题练"用几何量做有依据的预判，但保留不确定性"。判据：能说出"$\lambda_{\max}$ 是强信号不是保证"，说明正确理解了主线边界声明。易错回答是"X 一定泛化好"——那是对启发式指标的迷信。

### 题 2（正则化如何把模型推向平坦）

L2 正则化把训练目标从 $L(\theta)$ 改成 $L(\theta) + \frac{\lambda}{2}\|\theta\|^2$。

(a) 这对极小值位置有什么影响？（提示：惩罚大权重）
(b) 为什么"权重小的解"通常更平坦？（提示：$\sigma$ 的陡峭度）
(c) 教材 Model A 用了 L2、Model B 没用——这解释了两者的什么差别？

**解答**：

(a) L2 惩罚大权重，把收敛点往"参数模长小"的区域拉——模型被迫用更小的权重达到拟合，代价是训练损失略升（拟合略差），换来的是解在"小权重区域"。

(b) 决策函数的陡峭度与权重大小正相关：$\hat y = \sigma(wx+b)$ 的边界陡峭度 $\propto |w| \cdot \sigma'$，而 $\sigma'$ 在 $|z|$ 大时饱和。大权重 → 决策边界陡峭 → 预测对 $w$ 敏感 → 损失二阶导大（尖锐）；小权重 → 边界平缓 → 不敏感 → 平坦。**权重大小是平坦性的主要杠杆。**

(c) Model A 在 L2 下收敛到 $w=0.5$（小权重、缓坡、平坦、泛化好），Model B 无正则化收敛到 $w=10$（大权重、陡壁、尖锐、过拟合）。**正则化不只是"防止权重过大"，它通过压平决策函数，把模型推向平坦极小值——这正是 8.4.1 正则化与泛化连接的核心机制。**

**思路点拨**：这道题把正则化、权重、平坦性、泛化串成一条链。核心命题：**L2 正则化 → 小权重 → 平缓决策 → 低曲率 → 平坦极小值 → 好泛化。** 判据：能说出"正则化改变的不是训练误差，而是解在损失景观上的落点形状"，说明理解了 8.3.3 与 8.4.1 的衔接。

### 题 3（SAM：把平坦性当目标）

SAM 的优化目标是 $\min_\theta \max_{\|\epsilon\| \le \rho} L(\theta + \epsilon)$。

(a) 用损失景观的语言，SAM 在找什么样的解？
(b) 为什么 SAM 能用"邻域最坏损失"替代"算 Hessian"？
(c) SAM 在什么情况下可能不如普通优化？（提示：训练时间、小模型）

**解答**：

(a) SAM 在找"**邻域内处处损失都低**"的解——不仅是 $\theta$ 本身损失低，连以 $\theta$ 为中心半径 $\rho$ 的小球里最坏的点也要低。这样的解天然落在平坦区域（邻域宽阔的低谷），避开尖锐极小值。**它把"平坦"从被动结果变成主动目标。**

(b) "邻域最坏损失"的梯度（对 $\rho$ 小）可以用一阶近似算：$\nabla_\theta \max_{\|\epsilon\|\le\rho} L(\theta+\epsilon) \approx \nabla L(\theta + \rho \hat u)$，其中 $\hat u = \nabla L(\theta)/\|\nabla L(\theta)\|$——即"把 $\theta$ 沿梯度方向推 $\rho$ 再算梯度"。它只需要**两次前向/反向传播**，不需要算 Hessian。本质上，"邻域最坏损失"是曲率的一个代理：邻域内损失涨得快（尖锐）→ 最坏损失高；涨得慢（平坦）→ 最坏损失接近当前损失。**SAM 用两倍计算量换来了对曲率的隐式感知。**

(c) 局限：① **两倍计算**——每个训练步要两次前向/反向，大模型训练时间显著增加；② **小模型/数据充分时收益有限**——过拟合不严重时，找平坦解的收益不明显，普通优化就够了；③ $\rho$ 是超参数——太大找不到解，太小退化成普通优化。SAM 是"为泛化付费"，当泛化已不是瓶颈（数据足够、模型不大）时，这笔账不划算。

**思路点拨**：这道题把 SAM 的动机、机制、代价讲全。核心命题：**SAM = 用 2 倍计算换曲率感知 = 主动找平坦。** 判据：能说出"邻域最坏损失是曲率代理"与"SAM 是两倍计算的代价"两点，才算真懂——这也呼应了 8.3.1"牛顿法用曲率换速度但代价昂贵"的同一逻辑：**几何信息不是免费的。**
