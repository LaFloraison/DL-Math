# Ch04 §4.2.1 离散概率分布 · 代码.md

主线里我们讲清楚了四个离散分布的形状和公式，但公式放在纸面上是死的。这一份文件把它们变成能跑的四行函数——你输入参数，它吐出一个概率。更关键的是最后一步：我们把四个 PMF 各自的全部取值概率加起来，看它们是不是真的等于 1。这是概率论的宪法第一条：**总概率必须是 1**。如果哪一步加出来不是 1，说明要么函数写错了，要么我们对"这个分布覆盖了哪些取值"的理解错了。

四个函数全部用 `math` 标准库的透明函数手写——`math.comb`、`math.exp`、`math.factorial`——不依赖任何统计库。每一个 `k`、每一个 `p`、每一个 `λ` 是怎么进入式子的，都摊开在代码里。

---

## 层一：完整可运行脚本

复制粘贴即可运行（Python 3.8+）。输出直接印在代码块下方。

```python
import math                                   # ① 导入标准库 math：comb / exp / factorial 全在这里

def binomial_pmf(k, n, p):                    # ② 二项分布：n 次独立试验中恰好成功 k 次
    return math.comb(n, k) * (p ** k) * ((1 - p) ** (n - k))

def poisson_pmf(k, lam):                      # ③ 泊松分布：固定区间内恰好发生 k 次事件
    return math.exp(-lam) * (lam ** k) / math.factorial(k)

def geometric_pmf(k, p):                      # ④ 几何分布：首次成功恰好落在第 k 次试验
    return ((1 - p) ** (k - 1)) * p

def uniform_pmf(k, n):                        # ⑤ 离散均匀分布：n 个等可能结果中恰好取到 k
    return 1 / n

# ⑥ 手算验证：用教材 §4.2.1 的数值例子逐一核对
print("二项分布  P(X=10), n=20, p=0.5 :", binomial_pmf(10, 20, 0.5))   # 教材 ≈ 0.176
print("泊松分布  P(X=3),  λ=2         :", poisson_pmf(3, 2))           # 教材 ≈ 0.18
print("几何分布  P(X=5),  p=0.5       :", geometric_pmf(5, 0.5))       # 教材 = 0.03125
print("离散均匀  P(X=3),  n=6         :", uniform_pmf(3, 6))           # 教材 ≈ 0.1667

# ⑦ 归一化验证：把全部取值 k 的概率加起来，必须等于 1
print("\n归一化验证：Σ P(X=k) 应约等于 1")
print("  二项分布   k = 0..20    Σ =", sum(binomial_pmf(k, 20, 0.5) for k in range(21)))
print("  泊松分布   k = 0..30    Σ =", sum(poisson_pmf(k, 2) for k in range(31)))
print("  几何分布   k = 1..200   Σ =", sum(geometric_pmf(k, 0.5) for k in range(1, 201)))
print("  离散均匀   k = 1..6     Σ =", sum(uniform_pmf(k, 6) for k in range(1, 7)))
```

输出：

```
二项分布  P(X=10), n=20, p=0.5 : 0.17619705200195312
泊松分布  P(X=3),  λ=2         : 0.1804470443154836
几何分布  P(X=5),  p=0.5       : 0.03125
离散均匀  P(X=3),  n=6         : 0.16666666666666666

归一化验证：Σ P(X=k) 应约等于 1
  二项分布   k = 0..20    Σ = 1.0
  泊松分布   k = 0..30    Σ = 1.0
  几何分布   k = 1..200   Σ = 1.0
  离散均匀   k = 1..6     Σ = 1.0
```

第一行 0.176、第二行 0.18、第三行 0.03125、第四行 0.1667——与教材 §4.2.1 里手算的三个例子（和那个骰子）完全吻合。更重要的在后面：**四个 Σ 全部精确等于 1.0**。每块概率质量各就各位，谁也没多吃、谁也没漏掉。

## 层二：分步逐函数拆解

### 步骤 1：导入标准库 math

```python
import math
```

#### import math —— 导入标准库，拿到三个透明数学函数

`import math`

**操作**：`import` 语句把 Python 标准库 `math` 载入当前命名空间。之后所有数学函数都要通过 `math.` 前缀调用。

**输入**：无。

**输出**：无直接输出；向命名空间注册 `math` 模块，其中我们只用到三个函数——`math.comb(n, k)`（组合数 $C(n,k)$）、`math.exp(x)`（自然指数 $e^x$）、`math.factorial(k)`（阶乘 $k!$）。

**可调参数**：无。也可以改成 `from math import comb, exp, factorial`，之后就能直接写 `comb(n, k)` 少打前缀——但那样会污染命名空间，且丢失"每个函数来自哪个模块"的线索。教学上保留 `math.` 前缀更诚实。

**对应数学**：无直接对应。这是计算工具，不是概率概念。

### 步骤 2：定义二项分布 PMF

```python
def binomial_pmf(k, n, p):
    return math.comb(n, k) * (p ** k) * ((1 - p) ** (n - k))
```

#### binomial_pmf —— 二项分布概率质量函数

`return math.comb(n, k) * (p ** k) * ((1 - p) ** (n - k))`

**操作**：三个因子相乘，每个因子对应公式里的一块语义：
- `math.comb(n, k)` —— 从 $n$ 次试验中选出 $k$ 个"成功的位置"有多少种选法（组合数）。这一项回答的是"**哪些**试验成功"——因为 20 次里哪 10 次是正面，有 $C(20,10) = 184756$ 种可能；
- `p ** k` —— $k$ 次成功的概率乘积，$p \times p \times \cdots \times p$；
- `(1 - p) ** (n - k)` —— 剩下 $n-k$ 次失败的联合概率。

三者相乘：$\binom{n}{k} p^k (1-p)^{n-k}$，就是恰好成功 $k$ 次的总概率。

**输入**：三个标量（shape：`()`），`k`、`n` 是整数，`p` 是浮点数：
- `k`：int，成功的次数；
- `n`：int，试验总次数；
- `p`：float，单次试验的成功概率。

**输出**：float 标量，事件 $X = k$ 的概率，取值在 $[0, 1]$。

**可调参数**：
- `n`（int ≥ 0）：试验次数。它是分布的"宽度"参数。固定 $p$，$n$ 越大方差 $np(1-p)$ 越大，但概率质量在 $k = np$ 附近反而相对更集中（大数定律的影子）。
- `p`（float，$0 \le p \le 1$）：单次成功率。$p = 0.5$ 时分布对称；$p < 0.5$ 时右偏（成功少见，$k$ 小的地方概率高）；$p > 0.5$ 时左偏。
- `k`（int，$0 \le k \le n$）：取值点。**注意边界**：$k$ 超出 $[0, n]$ 时 `math.comb` 返回 0，且 `(1-p)**(n-k)` 会变成负数次幂——公式会给出无意义结果。合法性检查留给调用者。
- 还有第四、第五个参数吗？——没有。二项分布只需要 $n$ 和 $p$ 两个参数，这是数学上决定的，不是代码上的偷懒。

**对应数学**：主线中二项分布的定义块 $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$，$k \in \{0, 1, \ldots, n\}$。

### 步骤 3：定义泊松分布 PMF

```python
def poisson_pmf(k, lam):
    return math.exp(-lam) * (lam ** k) / math.factorial(k)
```

#### poisson_pmf —— 泊松分布概率质量函数

`return math.exp(-lam) * (lam ** k) / math.factorial(k)`

**操作**：三块拼成 $\dfrac{\lambda^k e^{-\lambda}}{k!}$：
- `math.exp(-lam)` —— 计算 $e^{-\lambda}$，这是"区间内一次事件也不发生"的基准概率；
- `lam ** k` —— $\lambda^k$，事件密度随次数增长的幂部分；
- `math.factorial(k)` —— $k!$，作为分母压住增长。

三者按 `分子除以 k!` 的关系连起来：`exp(-lam) * (lam ** k) / factorial(k)`。除法和乘法的先后顺序不影响结果（都是浮点乘法/除法），读作 $\lambda^k \cdot e^{-\lambda} \div k!$。

**输入**：两个标量（shape：`()`）：
- `k`：int ≥ 0，区间内发生的事件次数；
- `lam`：float > 0，平均发生率（教材里记为 $\lambda$）。Python 变量名避开希腊字母，写成 `lam`。

**输出**：float 标量，事件 $X = k$ 的概率。

**可调参数**：
- `lam`：float > 0，**泊松分布唯一的参数**。它同时是均值又是方差——$\mathbb{E}[X] = \mathrm{Var}(X) = \lambda$，这是泊松最特别的身份：一个参数管两件事。$\lambda$ 小分布尖而右偏，$\lambda$ 大分布趋于对称。把 `lam` 从 2 改成 8 会看到峰位右移，见下文"改个数字试试"。
- `k`：int ≥ 0。原则上 $k$ 可以取任意非负整数（泊松的支撑集无限），但 $k$ 一旦明显超过 $\lambda$，$\lambda^k/k!$ 指数级坍缩，概率在机器精度下迅速变成 0——所以求和时可以安全截断。

**对应数学**：主线中泊松分布的定义块 $P(X=k) = \dfrac{\lambda^k e^{-\lambda}}{k!}$，$k \in \{0, 1, 2, \ldots\}$。

---

### 步骤 4：定义几何分布 PMF

```python
def geometric_pmf(k, p):
    return ((1 - p) ** (k - 1)) * p
```

#### geometric_pmf —— 几何分布概率质量函数

`return ((1 - p) ** (k - 1)) * p`

**操作**：两个因子相乘：
- `(1 - p) ** (k - 1)` —— 前 $k-1$ 次**全部失败**的概率乘积，每次失败概率都是 $1-p$，连续 $k-1$ 次就是 $(1-p)^{k-1}$；
- `* p` —— 第 $k$ 次终于成功的概率。

先失败 $k-1$ 次、再成功一次，两者相乘，就是首次成功恰好落在第 $k$ 次的概率。注意指数是 `k - 1` 不是 `k`——因为成功的**那一次**不乘失败概率，它乘的是 $p$。

**输入**：两个标量（shape：`()`）：
- `k`：int ≥ 1，首次成功所在的试验编号；
- `p`：float（$0 < p \le 1$），单次试验的成功概率。

**输出**：float 标量，事件 $X = k$ 的概率。

**可调参数**：
- `p`：float（$0 < p \le 1$）。$p$ 是控制**尾巴长度**的关键旋钮：$p$ 越小，$(1-p)^{k-1}$ 衰减越慢，概率质量拖得越远。$p$ 从 0.5 降到 0.1，尾巴会明显变长，见下文"改个数字试试"。
- `k`：int ≥ 1。$k = 1$ 时 $(1-p)^{0} = 1$，$P = p$——"第一次就成功"。
- 第三个参数：无。几何分布只有一个参数 $p$，$\mathbb{E}[X] = 1/p$，均值随着 $p$ 减小而变大——这恰好呼应"尾巴变长"。

**对应数学**：主线中几何分布的定义块 $P(X=k) = (1-p)^{k-1} \cdot p$，$k \in \{1, 2, \ldots\}$。注意它的支撑集从 $1$ 开始，**没有 $k=0$ 这一项**——首次成功不可能发生在第 0 次试验。

---

### 步骤 5：定义离散均匀分布 PMF

```python
def uniform_pmf(k, n):
    return 1 / n
```

#### uniform_pmf —— 离散均匀分布概率质量函数

`return 1 / n`

**操作**：直接返回 `1 / n`。$n$ 个等可能结果，每个结果分到 $\dfrac{1}{n}$ 的概率——掷骰子，$n=6$，每个面 $\frac{1}{6} \approx 0.1667$。整个函数体只有一行，因为它没有任何参数化逻辑：均匀就是"人人有份，各得一瓢"。

**输入**：两个标量（shape：`()`）：
- `k`：int，具体某个结果；
- `n`：int ≥ 1，结果总数。

**输出**：float 标量，概率 $1/n$。

**可调参数**：
- `n`：int ≥ 1，结果个数。$n=6$ 是公平骰子，$n=2$ 是公平硬币，$n=52$ 是洗匀的扑克牌抽一张。
- `k`：int。**注意一个诚实的细节**：$k$ 在这里不参与任何计算——它只作为占位符，保证四个 PMF 的接口统一（都吃 `(k, 参数)` 两个入参）。它的合法性（$k$ 是否真的落在 $1..n$ 之间）这里不检查，由调用者保证。函数只负责"这一瓢是多少"，不负责"你是不是该拿这一瓢"。

**对应数学**：主线中离散均匀分布的定义块 $P(X=k) = \dfrac{1}{n}$，$k \in \{1, 2, \ldots, n\}$。

#### print —— 标准输出函数

`print("二项分布  P(X=10), n=20, p=0.5 :", binomial_pmf(10, 20, 0.5))`

**操作**：把逗号分隔的各个参数依次转成字符串，用空格连接，打印到控制台，末尾换行。

**输入**：一个字符串标签（告诉读者这一行在算什么）+ 一个 float 概率值。都是标量。

**输出**：打印到标准输出，返回值是 `None`（print 不产出任何可继续计算的数）。

**可调参数**：`print` 还有三个常用参数——`sep=` 控制多个值之间的分隔符（默认一个空格），`end=` 控制行尾字符（默认换行 `\n`），`file=` 指定写到哪个流（默认 `sys.stdout`）。这里全部用默认值即可。想更精细对齐时，可以像"改个数字试试"里那样改用 `f-string`。

**对应数学**：无。这一步是把概率**暴露到我们眼前**，让手算与机器结果面对面。

这四行验证了什么：$n=20, p=0.5, k=10$ 得 $0.176$（教材例一）；$\lambda=2, k=3$ 得 $0.1804$（教材例二）；$p=0.5, k=5$ 得 $0.03125$（教材例三）；$n=6, k=3$ 得 $0.1667$（骰子）。四个数字与教材手算完全一致——公式写对了。

### 步骤 7：归一化验证 Σ P(X=k) ≈ 1

```python
print("  二项分布   k = 0..20    Σ =", sum(binomial_pmf(k, 20, 0.5) for k in range(21)))
print("  泊松分布   k = 0..30    Σ =", sum(poisson_pmf(k, 2) for k in range(31)))
print("  几何分布   k = 1..200   Σ =", sum(geometric_pmf(k, 0.5) for k in range(1, 201)))
print("  离散均匀   k = 1..6     Σ =", sum(uniform_pmf(k, 6) for k in range(1, 7)))
```

#### sum —— 求和内建函数

`sum(binomial_pmf(k, 20, 0.5) for k in range(21))`

**操作**：`range(21)` 生成整数 $0, 1, \ldots, 20$；生成器表达式 `binomial_pmf(k, 20, 0.5) for k in range(21)` 惰性地依次算出这 21 个取值各自的概率；`sum(...)` 把这串数从头到尾累加，得到 $\sum_{k=0}^{n} P(X=k)$。

**输入**：一个生成器（一串标量）。`range` 的上下界决定了对哪些取值求和——**这是归一化验证最容易被改错的地方**，上界漏一项，总和就缺一块质量。

**输出**：float 标量，全部取值概率的总和。

**可调参数**（这里的"参数"是 `range` 的上下界）：
- `range(21)`：二项的求和区间。上界 21 = $n+1$，恰好覆盖 $k = 0..20$ 全部合法取值。写成 `range(20)` 会漏掉 $k=20$，总和变成 $1 - p^{20}$，不再是 1。
- `range(31)`：泊松的支撑集是无限集，但 $\lambda = 2$ 时 $k \ge 10$ 的概率已经小于 $10^{-7}$，$k = 30$ 之后在浮点精度下直接归零——截断到 30 完全够用。**这就是为什么泊松的"无穷求和"在机器里可以安全地截断**。
- `range(1, 201)`：几何从 $k=1$ 开始（没有 $k=0$ 项）。截断到 200 时尾项 $(1-p)^{200} = 0.5^{200} \approx 6 \times 10^{-61}$，小到加进去也不改变任何一位小数。
- `range(1, 7)`：均匀只有 6 个结果，$6 \times \frac{1}{6}$ 精确等于 1.0。

**对应数学**：概率公理第二条 $\mathrm{P}(\Omega) = 1$。一个函数要配得上"概率"二字，所有取值的概率加起来必须恰好为 1——这就是 PMF 的**归一化条件**，也是我们在主线中撞墙撞出来的那堵墙的落脚点。四个 Σ 都等于 1.0，说明四个函数各自吃干净了自己的整块质量，没有丢，没有多。

## 改个数字试试

函数的意义在于可以被拨弄。下面两组实验，把同一个函数的参数拧一下，看形状怎么变。

### 实验 A：λ 从 2 升到 8，泊松的峰向右移

```python
for k in range(0, 10):
    print(f"  k={k}  λ=2: {poisson_pmf(k, 2):.4f}   λ=8: {poisson_pmf(k, 8):.4f}")
```

输出：

```
  k=0  λ=2: 0.1353   λ=8: 0.0003
  k=1  λ=2: 0.2707   λ=8: 0.0027
  k=2  λ=2: 0.2707   λ=8: 0.0107
  k=3  λ=2: 0.1804   λ=8: 0.0286
  k=4  λ=2: 0.0902   λ=8: 0.0573
  k=5  λ=2: 0.0361   λ=8: 0.0916
  k=6  λ=2: 0.0120   λ=8: 0.1221
  k=7  λ=2: 0.0034   λ=8: 0.1396
  k=8  λ=2: 0.0002   λ=8: 0.1396
  k=9  λ=2: 0.0002   λ=8: 0.1241
```

看到了什么？$\lambda = 2$ 时概率集中在 $k=1,2$（峰值 $0.2707$），$k=4$ 之后几乎为零；$\lambda = 8$ 时峰值挪到 $k=7,8$（各 $0.1396$），$k=0,1$ 反而几乎为零。**峰位跟着 $\lambda$ 向右走**——因为 $\mathbb{E}[X] = \lambda$，平均发生 8 次事件的地方，最可能发生的次数就是 7 或 8。同时注意峰值本身从 $0.2707$ 降到了 $0.1396$：$\lambda$ 越大，同样 $1$ 的概率质量要摊到更多取值上，峰必然变矮。这解释了为什么"稀有事件"（小 $\lambda$，如每年两次地震）分布尖，而"高频事件"（大 $\lambda$，如每分钟 8 个请求）分布平。

```
  k=7  p=0.5: 0.0078   p=0.1: 0.0531
```

$p = 0.5$ 时，$k=1$ 就有 $0.5$ 的概率，之后每步减半，$k=6$ 只剩 $0.0156$——**质量紧紧压在开头**。$p = 0.1$ 时，$k=1$ 只有 $0.1$，而且每步只乘 $0.9$，衰减极慢：$k=6$ 还有 $0.0590$。算一算尾巴：$p=0.5$ 时 $P(X \ge 6) = 0.5^5 = 0.03125$，只有约 3% 的概率要等到第 6 次之后；$p=0.1$ 时 $P(X \ge 6) = 0.9^5 \approx 0.59049$——**超过一半的质量落在第 6 次之后**。成功概率越低，前 $k-1$ 次连续失败的乘积 $(1-p)^{k-1}$ 衰减越慢，你要等的那场"第一次成功"就越可能姗姗来迟。$\mathbb{E}[X] = 1/p$：$p=0.5$ 时平均第 2 次成功，$p=0.1$ 时平均第 10 次才成功。

**呼应主线**：几何分布的这个"长尾等待"，正是深度学习里模拟"稀有事件发生前的等待时长"（如模型何时首次收敛到某个精度）的天然工具——详见主线第三步的桥接。
