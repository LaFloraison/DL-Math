# §4.2.1 离散概率分布 — 代码验证

> 四个离散分布的 PMF 全部手写。没有任何 `scipy.stats`——每个公式都是 `/`、`*`、`**`、`math.comb` 的透明翻译。改 $p$、$\lambda$、$n$，看概率怎么变。

---

## 完整代码

```python
import math

# ═══ 1. 二项分布 Binomial(n, p) ═══
def binomial_pmf(k, n, p):
    """P(X=k) = C(n,k) * p^k * (1-p)^(n-k)"""
    comb = math.comb(n, k)               # n选k的组合数
    return comb * (p ** k) * ((1 - p) ** (n - k))

# ═══ 2. 泊松分布 Poisson(lambda) ═══
def poisson_pmf(k, lam):
    """P(X=k) = (lam^k * e^(-lam)) / k!"""
    return (lam ** k) * (math.exp(-lam)) / math.factorial(k)

# ═══ 3. 几何分布 Geometric(p) ═══
def geometric_pmf(k, p):
    """P(X=k) = (1-p)^(k-1) * p   (k >= 1)"""
    return ((1 - p) ** (k - 1)) * p

# ═══ 4. 离散均匀分布 Uniform(n) ═══
def uniform_pmf(n):
    """P(X=k) = 1/n   (k in {1,...,n})"""
    return 1.0 / n

# ═══ 验证：手算数值 ═══
print("=== 二项分布: n=20, p=0.5, k=10 ===")
print(f"P(X=10) = {binomial_pmf(10, 20, 0.5):.4f}  (期望约 0.176)")

print("\n=== 泊松分布: lambda=2, k=3 ===")
print(f"P(X=3)  = {poisson_pmf(3, 2):.4f}  (期望约 0.180)")

print("\n=== 几何分布: p=0.5, k=5 ===")
print(f"P(X=5)  = {geometric_pmf(5, 0.5):.4f}  (期望约 0.031)")

print("\n=== 均匀分布: n=6 (骰子) ===")
print(f"P(X=3)  = {uniform_pmf(6):.4f}  (期望 1/6 ≈ 0.167)")

# ═══ 验证 PMF 归一化：所有k的概率之和应≈1 ═══
binom_sum = sum(binomial_pmf(k, 20, 0.5) for k in range(0, 21))
poisson_sum = sum(poisson_pmf(k, 2) for k in range(0, 50))  # 50足够覆盖
geom_sum = sum(geometric_pmf(k, 0.5) for k in range(1, 50))
print(f"\n=== PMF 归一化检查（应≈1） ===")
print(f"二项 Binom(20,0.5): ΣP = {binom_sum:.6f}")
print(f"泊松 Pois(2):       ΣP = {poisson_sum:.6f}")
print(f"几何 Geom(0.5):     ΣP = {geom_sum:.6f}")
```

运行输出：

```

P(X=10) = 0.1762  (期望约 0.176)

=== 泊松分布: lambda=2, k=3 ===
P(X=3)  = 0.1804  (期望约 0.180)

=== 几何分布: p=0.5, k=5 ===
P(X=5)  = 0.0312  (期望约 0.031)

=== 均匀分布: n=6 (骰子) ===
P(X=3)  = 0.1667  (期望 1/6 ≈ 0.167)
```

## 分步讲解


### 步骤 1：二项分布 PMF —— `binomial_pmf(k, n, p)`

```python
def binomial_pmf(k, n, p):
    comb = math.comb(n, k)
    return comb * (p ** k) * ((1 - p) ** (n - k))
```

**做什么**：计算"$n$ 次独立试验中恰好成功 $k$ 次的概率"。


#### `math.comb(n, k)` —— 组合数

```python
comb = math.comb(n, k)
```

**操作**：计算 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$——从 $n$ 个位置中选出 $k$ 个位置的方法数。

**输入**：
- `n`：总试验次数，非负整数。`n=20` 表示 20 次试验
- `k`：成功次数，整数，$0 \le k \le n$

**输出**：一个非负整数。$\binom{20}{10} = 184756$——从 20 个位置中选 10 个位置的方法有 184756 种。

**可调参数**：
- `n`：总试验次数。越大 → 分布越分散（方差 $np(1-p)$ 随 $n$ 线性增长）
- `k`：成功次数。$k$ 接近 $np$ 时概率最大；$k$ 偏离 $np$ 时概率迅速衰减


#### `p ** k` —— 成功 $k$ 次的概率

```python
p ** k
```

**操作**：$k$ 次试验全部成功，每次概率 $p$。独立事件概率相乘 → $p^k$。

**输出**：一个在 $(0, 1]$ 之间的数。$p=0.5, k=10$ → $0.5^{10} \approx 0.00098$。这个数很小——因为 10 次全成功本身就罕见。但组合数 $\binom{20}{10} = 184756$ 把它拉回到约 0.176。


#### `(1 - p) ** (n - k)` —— 失败 $n-k$ 次的概率

```python
(1 - p) ** (n - k)
```

**操作**：$n-k$ 次试验全部失败，每次概率 $1-p$。和 $p^k$ 相乘得到"恰好这 $k$ 次成功，其余失败"的概率。

**输出**：一个在 $(0, 1]$ 之间的数。$p=0.5, n=20, k=10$ → $0.5^{10} = 0.00098$，和 $p^k$ 完全相等（因为 $p = 1-p = 0.5$）。

**可调参数**（整个函数的通用参数）：
- **`p`（成功概率）**：$0 \le p \le 1$。$p=0.5$ 时分布对称；$p \to 0$ 时分布峰偏向左边（不太可能成功）；$p \to 1$ 时峰偏右
- **`n`（总试验次数）**：越大 → 分布越像正态分布（中心极限定理）
- **`k`（成功次数）**：你要查询的那个值。$k$ 必须是 $0$ 到 $n$ 的整数

**对应数学**：二项分布 $X \sim \text{Binomial}(n, p)$。主线第二节讲的手算 $n=20, p=0.5, k=10$ 得到 0.176——就是这个函数的结果。

### 步骤 2：泊松分布 PMF —— `poisson_pmf(k, lam)`

```python
def poisson_pmf(k, lam):
    return (lam ** k) * (math.exp(-lam)) / math.factorial(k)
```

**做什么**：计算"平均速率 $\lambda$ 的随机事件在固定间隔内恰好发生 $k$ 次的概率"。


#### `lam ** k` —— 速率的 $k$ 次方

```python
lam ** k
```

**操作**：$\lambda^k$。$\lambda$ 是平均发生次数，$k$ 是你关心的那个具体次数。

**可调参数**：
- **`lam`（$\lambda$，平均速率）**：$\lambda > 0$。$\lambda = 2$ 表示平均每小时 2 次。$\lambda$ 越大 → 分布峰越向右移（事件多了，典型次数也多了）。$\lambda$ 也是泊松分布的**均值**和**方差**——二者相等是泊松的独特性质


#### `math.exp(-lam)` —— 指数衰减因子

```python
math.exp(-lam)
```

**操作**：计算 $e^{-\lambda}$。`math.exp(x)` = $e^x$。这个因子保证所有 $k$ 的概率和恰好为 1。

**输入**：`-lam`（负的平均速率）。$\lambda=2$ → $e^{-2} \approx 0.1353$。

**为什么需要它？** 泊松分布的 PMF 分母有 $k!$，分子有 $\lambda^k$。如果没有 $e^{-\lambda}$，$\sum_k \lambda^k / k! = e^\lambda$——概率和不是 1。$e^{-\lambda}$ 正好把它拉回来：$e^{-\lambda} \cdot e^{\lambda} = 1$。


#### `math.factorial(k)` —— $k$ 的阶乘

```python
math.factorial(k)
```

**操作**：计算 $k! = 1 \times 2 \times \cdots \times k$。$k=0$ 时 $0! = 1$。

**输入**：`k`，非负整数。$k=3$ → $3! = 6$；$k=10$ → $10! = 3,628,800$。

**为什么有阶乘？** 泊松是二项分布的极限——当 $n \to \infty, p \to 0, np = \lambda$ 时，组合数 $\binom{n}{k}$ 退化为 $\lambda^k / k!$。阶乘来自"事件无序"——哪次在前哪次在后没有区别，$k!$ 去除了排列的重复计数。

**对应数学**：泊松分布 $X \sim \text{Poisson}(\lambda)$。主线第三节的 $\lambda=2, k=3$ 手算结果 0.180。

### 步骤 3：几何分布 PMF —— `geometric_pmf(k, p)`

```python
def geometric_pmf(k, p):
    return ((1 - p) ** (k - 1)) * p
```

**做什么**：计算"第一次成功恰好出现在第 $k$ 次试验的概率"。


#### `(1 - p) ** (k - 1)` —— 前 $k-1$ 次全失败

```python
(1 - p) ** (k - 1)
```

**操作**：每次试验失败的概率是 $1-p$。连续 $k-1$ 次失败，概率相乘 = $(1-p)^{k-1}$。

**可调参数**：
- **`p`（成功概率）**：$0 < p \le 1$。$p$ 大 → $(1-p)$ 小 → $(1-p)^{k-1}$ 衰减极快 → 大概率很快成功。$p=0.9$ 时 $P(X=1) = 0.9$——"一次就成"
- **`k`（第几次成功）**：$k \ge 1$。$k$ 越大 → $(1-p)^{k-1}$ 越小 → 概率越低


**末尾的 `* p` —— 第 $k$ 次成功**

```python
* p
```

**操作**：把"前 $k-1$ 次失败"和"第 $k$ 次成功"两段概率乘在一起。

**对应数学**：几何分布 $X \sim \text{Geometric}(p)$。主线第四节 $p=0.5, k=5$ 手算结果 0.03125。


---
### 步骤 4：离散均匀分布 PMF —— `uniform_pmf(n)`

```python
def uniform_pmf(n):
    return 1.0 / n
```

**做什么**：$n$ 个结果，每个概率完全相等。


#### `1.0 / n` —— 等分概率总和

```python
1.0 / n
```

**操作**：$n$ 个结果共享总和为 1 的概率，每个分到 $1/n$。

**为什么写 `1.0` 而不是 `1`？** Python 中 `1/6 = 0.1666...` 自动是浮点除法。写成 `1.0` 是显式约定——"输出是一个小数，不是整数"。

**可调参数**：
- **`n`（结果数量）**：$n \ge 1$ 的正整数。$n=6$（骰子）→ $1/6 \approx 0.1667$；$n=2$（硬币）→ $1/2 = 0.5$。$n$ 越大每个结果的概率越小

**对应数学**：离散均匀分布。主线第五节讲了它"看似简单，实则是最大熵分布"——在信息论中它是"最不确定"的离散分布，用作贝叶斯推断的无信息先验。


---
### 步骤 5：PMF 归一化检查

```python
binom_sum = sum(binomial_pmf(k, 20, 0.5) for k in range(0, 21))
poisson_sum = sum(poisson_pmf(k, 2) for k in range(0, 50))
geom_sum = sum(geometric_pmf(k, 0.5) for k in range(1, 50))
```

**做什么**：验证 PMF 的基本性质——所有可能结果的概率之和必须等于 1。

**操作**：`sum(... for k in range(...))` 对 $k$ 遍历所有可能值，累加概率。二项分布 $k$ 从 0 到 $n$（共 $n+1$ 个值），泊松和几何理论上有无限个 $k$ 值——但概率衰减很快，取 50 项足够收敛到 1。

**输出**：三个数，都约等于 1.000000。这不是巧合——是 PMF 的**数学定义**要求归一化。如果加起来不是 1，你写的 PMF 公式有 bug。


### 改个数字试试

把泊松的 $\lambda$ 从 2 改成 8：

```python
print(f"Pois(λ=8, k=3)  = {poisson_pmf(3, 8):.4f}")
print(f"Pois(λ=8, k=8)  = {poisson_pmf(8, 8):.4f}")
print(f"Pois(λ=8, k=15) = {poisson_pmf(15, 8):.4f}")
```

输出：

```
Pois(λ=8, k=3)  = 0.0286    ← 远低于平均，罕见
Pois(λ=8, k=8)  = 0.1396    ← 恰好等于平均，最可能
Pois(λ=8, k=15) = 0.0098    ← 远高于平均，更罕见
```

$\lambda=8$ 时，最可能的 $k$ 值在 8 附近。$k=3$（远低于平均）和 $k=15$（远高于平均）概率都大幅降低。这就是泊松分布的**单峰**特性——概率质量集中在 $\lambda$ 周围。

再改几何的 $p$ 从 0.5 到 0.1：

```python
for k in [1, 5, 10, 20]:
    print(f"Geom(p=0.1, k={k:2d}) = {geometric_pmf(k, 0.1):.4f}")
```

输出：

```
Geom(p=0.1, k= 1) = 0.1000   ← 10% 概率一次就成
Geom(p=0.1, k= 5) = 0.0656   ← 等5次的概率
Geom(p=0.1, k=10) = 0.0387   ← 等10次
Geom(p=0.1, k=20) = 0.0135   ← 等20次，仍有1.3%
```

$p=0.1$ 时概率衰减非常慢——即使等了 20 次，问题还没解决的可能是 1.3%。这就是几何分布的**长尾**特性——$p$ 越小尾巴越长。这也解释了为什么罕见病诊断（低 $p$）常常需要极多次检测。
