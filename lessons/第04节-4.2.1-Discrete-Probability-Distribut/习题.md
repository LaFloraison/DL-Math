# 习题：离散概率分布

## 第一组：概念检验

**1. 二项分布公式里为什么必须乘上组合数 $\binom{n}{k}$？有人这样说："一批 20 个零件，次品率 $p=0.1$，恰好 3 个次品的概率，直接算 $0.1^{3}\times 0.9^{17}$ 就够了。"这个说法漏掉了什么？**

**解答**：$0.1^3 \times 0.9^{17}$ 是"**指定**某三个具体位置（比如第 1、5、17 号零件）恰好是次品、其余全好"的概率。"恰好 3 个次品"并没有指定位置——次品落在第 1、5、17 号，和落在第 2、9、13 号，是两种**互斥**的不同情形，都要算进去。这些情形一共有 $\binom{20}{3}=1140$ 种，每种概率都是 $0.1^3\times 0.9^{17}$，所以总概率是 $1140 \times 0.1^3 \times 0.9^{17}\approx 0.190$。组合数 $\binom{n}{k}$ 数的正是"哪 $k$ 个位置恰好成功"的挑选方式——它是"位置的选择"在公式里的化身。

**思路点拨**：若有人回答 $0.1^3 \times 0.9^{17}$（漏掉组合数），他是把"恰好 $k$ 个"和"指定的某 $k$ 个"混为一谈——"恰好"两个字里藏着"不指定位置"。这正是《主线.md》撞墙那一步的墙：直觉只给一个模糊的"两三个吧"，数学要求把位置的选择数清楚。对应《代码.md》步骤 2 `binomial_pmf` 里 `math.comb(n, k)` 那一项——没有它，二项就退化成"指定位置"的概率。

**2. 判断正误并解释："连抛 4 次硬币都是反面，第 5 次出正面的概率比 $0.5$ 大——运气总该轮到了吧。"**

**解答**：错误。每次抛掷独立，硬币没有记忆，第 5 次出正面的概率仍然是 $0.5$。几何分布 $P(X=k)=(1-p)^{k-1}p$ 恰好点破这一点："第 5 次才首次成功"的概率只有 $(0.5)^4\times 0.5=0.03125$，确实很小——但那个"小"来自"前 4 次全失败"这个无条件事件，它**不等于**"已经等了 4 次之后，第 5 次成功的条件概率"。后者仍是 $0.5$：已经等了 $j$ 次而一无所获，剩下的等待与从零开始等待一模一样——这是几何分布的无记忆性 (memoryless property)：$P(X=k+j \mid X>j)=P(X=k)$。

**思路点拨**：要区分两个量——无条件概率 $P(X=5)$（小，$0.03125$）与条件概率 $P(X=5\mid X>4)$（就是 $0.5$）。有人把"等得越久"当作"越接近成功"，这是赌徒谬误 (gambler's fallacy)；独立随机过程从不补偿。对应《代码.md》步骤 4 `geometric_pmf` 的 `((1-p)**(k-1)) * p`——注意指数是 $k-1$ 不是 $k$，首次成功**那一次**乘的是 $p$，不是 $(1-p)$。

**3. 泊松分布只有一个参数 $\lambda$，为什么它能同时决定均值（位置）和方差（离散程度）？如果事件不是独立发生、而是会"传染"（一次爆发诱发下一次），泊松还适用吗？**

**解答**：泊松是"罕见事件在固定区间内独立发生次数"的极限（二项 $n\to\infty,\ p\to 0$、$np=\lambda$ 固定）。独立性保证事件像"在区间上均匀撒点"，撒点的浓密程度唯一由 $\lambda$ 决定——所以 $\mathbb{E}[X]=\mathrm{Var}(X)=\lambda$，一个参数同时携带位置与波动的全部信息。若事件会传染，方差会被撑大、超过均值（"扎堆"），泊松立刻失效，需要负二项等能容纳超离散的分布。

**思路点拨**：有人误以为"一个分布至少要两个参数才能定位置和离散度"。泊松是反例：它结构特殊（稀有 + 独立），一个参数就锁死了整个分布。这正是《主线.md》泊松定义块后"均值等于方差"那句伏笔的来由，也呼应《代码.md》步骤 3 对 `lam` 的解说——"一个参数管两件事：它同时是均值又是方差"。

## 第二组：计算实践

**4. 手算 + 代码验证。**
（a）手算：一批 20 个零件、次品率 $p=0.1$，恰好 3 个次品的概率（老周的表一）；
（b）手算：几何分布 $p=0.5$，"首次成功恰好落在第 5 次"的概率；
（c）用《代码.md》步骤 2–5 的四个函数，验证教材 §4.2.1 的四个数字（$n=20,p=0.5,k=10$；$\lambda=2,k=3$；$p=0.5,k=5$；$n=6,k=3$）。

**解答**：
（a）$\mathrm{P}(X=3)=\binom{20}{3}(0.1)^3(0.9)^{17}=1140\times 0.001\times 0.1668\approx 0.190$。
（b）$\mathrm{P}(X=5)=(1-0.5)^{4}\times 0.5=(0.5)^4\times 0.5=\dfrac{1}{32}=0.03125$。
（c）代码（就是《代码.md》步骤 2–5 的函数）：

```python
import math
def binomial_pmf(k, n, p):
    return math.comb(n, k) * (p ** k) * ((1 - p) ** (n - k))
def poisson_pmf(k, lam):
    return math.exp(-lam) * (lam ** k) / math.factorial(k)
def geometric_pmf(k, p):
    return ((1 - p) ** (k - 1)) * p
def uniform_pmf(k, n):
    return 1 / n

print("二项分布  P(X=10), n=20, p=0.5 :", binomial_pmf(10, 20, 0.5))
print("泊松分布  P(X=3),  λ=2         :", poisson_pmf(3, 2))
print("几何分布  P(X=5),  p=0.5       :", geometric_pmf(5, 0.5))
print("离散均匀  P(X=3),  n=6         :", uniform_pmf(3, 6))
```

输出（与《代码.md》步骤 6 完全一致）：

```
二项分布  P(X=10), n=20, p=0.5 : 0.17619705200195312
泊松分布  P(X=3),  λ=2         : 0.1804470443154836
几何分布  P(X=5),  p=0.5       : 0.03125
离散均匀  P(X=3),  n=6         : 0.16666666666666666
```

**思路点拨**：（a）里若有人写 $0.1^3\times 0.9^{17}$（约 $1.7\times10^{-4}$）而少了 $\binom{20}{3}=1140$ 这一项，会得到比正确值 $0.190$ 小约三个数量级的答案——"恰好 3 个"和"指定某 3 个"相差 1140 倍。（b）的手算要盯住指数是 $k-1=4$，不是 $5$——首次成功那一次乘的是 $p$。四个输出与教材逐一吻合，说明公式写对了。

**5. 泊松的峰位实验。** 用代码把 $\lambda$ 从 2 改成 8，观察 $P(X=k)$ 的峰值位置和峰值高度怎么变，并解释规律。这验证了泊松的哪条性质？

**解答**：峰值大约跟着 $\lambda$ 向右移动，且峰变矮。代码（用 NumPy 向量化验证）：

```python
import numpy as np
from math import exp, factorial
def poisson_pmf(k, lam):
    return exp(-lam) * lam**k / factorial(k)
ks = np.arange(0, 10)
for lam in (2, 8):
    ps = np.array([poisson_pmf(int(k), lam) for k in ks])
    pk = int(np.argmax(ps))
    print(f"λ={lam}: 峰值出现在 k={pk}, P(X={pk})={ps[pk]:.4f}   E[X]=λ={lam}")
```

输出：

```
λ=2: 峰值出现在 k=1, P(X=1)=0.2707   E[X]=λ=2
λ=8: 峰值出现在 k=7, P(X=7)=0.1396   E[X]=λ=8
```

（与《代码.md》"实验 A"逐行一致。）规律：因为 $\mathbb{E}[X]=\lambda$，"平均发生 $\lambda$ 次"的地方最可能发生 $\lambda$ 次，所以峰位跟着 $\lambda$ 走（$\lambda=8$ 时峰落在 $k=7,8$）；同时 $\lambda$ 越大，同样的概率质量 1 要摊到更多取值上，峰必然变矮（$0.2707\to 0.1396$）。这验证了泊松"均值决定中心、概率质量总量恒为 1"的性质。

**思路点拨**：有人会预期"$\lambda=8$ 时峰值恰好在 $k=8$"——注意峰在 $k=7$ 或 $8$ 都有 $0.1396$，泊松的峰不需要精确落在 $\lambda$ 上：均值是"加权平均"，不是"最可能点"。若有人答"峰值高度不变"，那是忘了总面积恒为 1——摊得越开，峰必须越矮。这道题也是对《主线.md》"泊松的均值等于方差"一句的数值确认。

**6. 归一化陷阱。** 验证二项分布 $n=20,\ p=0.5$ 的 $\sum_{k} P(X=k)$ 等于 1，然后故意把求和上界从 $21$ 改成 $20$（漏掉 $k=20$），看总和差多少。这个差值是什么？

**解答**：代码：

```python
import math
def binomial_pmf(k, n, p):
    return math.comb(n, k) * (p ** k) * ((1 - p) ** (n - k))
full = sum(binomial_pmf(k, 20, 0.5) for k in range(21))
trunc = sum(binomial_pmf(k, 20, 0.5) for k in range(20))
print(f"k = 0..20 : {full:.10f}")
print(f"k = 0..19 : {trunc:.10f}")
print(f"差值       = 漏掉的 k=20 项 = p^20 = {0.5**20:.6e}")
```

输出：

```
k = 0..20 : 1.0000000000
k = 0..19 : 0.9999990463
差值       = 漏掉的 k=20 项 = p^20 = 9.536743e-07
```

$k=0..20$ 全部取值概率之和精确等于 1.0——这是 PMF 的**归一化条件**，也是概率公理 $\mathrm{P}(\Omega)=1$。漏掉 $k=20$（全部 20 次都是正面），总和就少了那一项 $\binom{20}{20}(0.5)^{20}=p^{20}=9.536743\times10^{-7}$：质量缺了一块，总和不再是 1。

**思路点拨**：这正是《代码.md》步骤 7 强调的"上界漏一项，总和就缺一块质量"。$p=0.5$ 时 $p^{20}$ 太小，肉眼几乎看不出差别——换成 $p=0.9$，漏掉 $k=20$ 会让总和少 $0.9^{20}\approx 0.12$，立刻穿帮。归一化验证是检验"我对分布覆盖了哪些取值"理解错了没有的照妖镜：如果加出来不是 1，要么函数写错了，要么支撑集搞错了。

## 第三组：DL 延伸

**7. 分类与计数的输出层。** 一个 3 分类网络，softmax 输出的类别概率是 $(0.7, 0.2, 0.1)$。（a）这是哪种离散分布？训练它的交叉熵损失在数学上做了什么？（b）若换一个任务：预测"一段文本里的错别字个数"，输出层应该配哪种分布/损失？为什么不能用二项分布？

**解答**：
（a）softmax 保证 $p_j\ge 0$ 且 $\sum_j p_j=1$——这是定义在有限类别集 $\{1,2,3\}$ 上的离散分布（多项分布 / categorical distribution，单次分类就是从它抽一个类别）。交叉熵 $\mathcal{L}=-\log p_y$ 做的，是拿模型输出的这条离散分布，去对齐真实标签这一个"点分布"（§4.2.1 主线第三步桥接）。
（b）配**泊松损失 (Poisson loss)**：模型预测平均率 $\hat{\lambda}$，损失用 $-\log \mathrm{P}(k\mid \hat{\lambda})$。不能配二项，因为二项需要一个**真实、有限、天然分立**的试验次数 $n$——"全文里有多少个可能出错的位置"是人为且含糊的（每个字符？每个词？），这正是《主线.md》泊松那面"$n$ 在哪？$p$ 在哪？"的墙。泊松只需要你认得平均发生几次。

**思路点拨**：若有人给计数任务配二项损失，他是被"错别字 = 是/否二分类"的表面迷惑了——二项需要固定的试验次数 $n$，而"错别字机会"无法数清；泊松正是为"不知道试验次数、只知平均率"的稀有事件而生的。选错分布，模型不是"算不准"，而是"根本说不出答案"。

**8. 生成模型的终止信号。** 一个语言模型要预测"还要生成多少个 token 才会遇到 end-of-sequence 终止符"。假设每一步终止的概率恒定且彼此独立，剩余步数服从哪个离散分布？如果实际数据显示"等得越久越不容易终止"（长尾巴特别肥），几何模型的哪条假设被破坏了？

**解答**：每一步终止概率恒定、独立，则"首次终止的等待时间"服从**几何分布 (geometric distribution)** $\mathrm{Geom}(p)$——它数的正是"首次成功的等待时间"（主线第三步桥接：语言模型预测 end-of-sequence token 何时出现）。如果长尾巴比几何更肥——极长的序列比公式预测的更常出现——说明"每步终止概率恒定"这条假设被破坏了：越到后面 $p$ 越小（模型越"舍不得"终止）。几何要求每次试验独立同分布；一旦概率在漂移，公式就失效，这正落在《主线.md》第五节"一张共同的底牌：独立"的边界声明上。

**思路点拨**：有人直接套 $P(X=k)=(1-p)^{k-1}p$ 而不检查前提。几何的美——只用一个 $p$ 就刻画等待——同时也是它的脆弱：$p$ 必须恒定、试验必须独立。真实生成模型里终止概率往往随上下文变化，所以工程上通常用可学习的分类头而非固定几何模型。这与赌徒谬误同源：把"等待"误当成"累积"，是本节留给你的最后一面镜子。
