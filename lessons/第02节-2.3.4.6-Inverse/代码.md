# 代码：算逆、验证"乘回单位阵"、并撞一次"奇异矩阵"的报错

主线里我们算了 $A^{-1}$ 并验证 $AA^{-1}=I$。这一节用 NumPy 做四件事：**① `np.linalg.inv` 一步求逆；② 手算伴随公式对照；③ 验证 $AA^{-1}=I$；④ 撞奇异矩阵报错，学会诊断。**

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：linalg

# ---- ① 教材矩阵 ----
A = np.array([[1.0, 2.0], [3.0, 4.0]])

# ---- ② 手算 2x2 逆矩阵公式 ----
a, b, c, d = A[0,0], A[0,1], A[1,0], A[1,1]
det = a*d - b*c                         # 行列式 = -2
Ainv_manual = (1/det) * np.array([[d, -b], [-c, a]])
print("det =", det)
print("手算 A⁻¹ =\n", Ainv_manual)       # [[-2.   1. ] [ 1.5 -0.5]]

# ---- ③ np.linalg.inv 一步求逆 ----
Ainv = np.linalg.inv(A)
print("np.linalg.inv =\n", Ainv)

# ---- ④ 验证 A @ A⁻¹ = I ----
I_check = A @ Ainv
print("A @ A⁻¹ =\n", I_check)
print("是否等于单位阵:", np.allclose(I_check, np.eye(2)))   # True

# ---- ⑤ 奇异矩阵：det=0，求逆报错 ----
S = np.array([[1.0, 2.0], [2.0, 4.0]])   # 第 2 行 = 2×第 1 行
print("det(S) =", np.linalg.det(S))      # ≈ 0
try:
    np.linalg.inv(S)
except np.linalg.LinAlgError as e:
    print("奇异矩阵求逆报错:", e)
```

运行输出（Python 3.11 + NumPy）：

```text

 [ 0.0000000e+00  1.0000000e+00]]
是否等于单位阵: True

奇异矩阵求逆报错: Singular matrix
```

## 层二：分步逐函数拆解

### 步骤 1–2：手算 2×2 逆

```python
a, b, c, d = A[0,0], A[0,1], A[1,0], A[1,1]
det = a*d - b*c
Ainv_manual = (1/det) * np.array([[d, -b], [-c, a]])
```

**做什么**：按伴随公式 $\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$ 手算。$\det = 1\cdot4-2\cdot3 = -2$，$A^{-1} = \frac{1}{-2}\begin{bmatrix}4&-2\\-3&1\end{bmatrix} = \begin{bmatrix}-2&1\\1.5&-0.5\end{bmatrix}$。
**操作**：`a*d - b*c` 是 2×2 行列式；`np.array([[d,-b],[-c,a]])` 是伴随矩阵；`1/det` 缩放。
**可调参数**：公式只对 2×2 成立（更高阶用手算伴随矩阵极痛苦——这正是 `np.linalg.inv` 存在的理由）。
**对应数学**：主线 2×2 逆矩阵公式。

### 步骤 3：`np.linalg.inv(A)`

#### `np.linalg.inv(A)` —— 数值求逆

**操作**：用高斯-约当消元等数值算法求 $A^{-1}$。结果与手算完全一致。
**输入**：方阵 `A`（`(2,2)`）。
**输出**：`Ainv`（`(2,2)`）。
**可调参数**：接受任意方阵；对非方阵报 `LinAlgError`。**注意：`np.linalg.inv` 是"最后的手段"——求解方程组用 `np.linalg.solve` 更快更稳。**
**对应数学**：主线"$A^{-1}$ 存在当且仅当 $\det\neq0$"。

### 步骤 4：验证 `A @ Ainv` ≈ I

```python
I_check = A @ Ainv
np.allclose(I_check, np.eye(2))
```

**操作**：$AA^{-1}$ 应精确等于单位阵。数值上舍入误差给 $10^{-16}$ 量级的小数，`allclose` 判定为 `True`。
**可调参数**：用 `np.eye(2)` 作对照。**这是"是否真的是逆"的唯一判据**——写代码验证求逆，永远乘回去看看。
**对应数学**：主线 $AA^{-1}=I$ 的定义。**"求逆"的验证，就是"乘回去得单位阵"。**

### 步骤 5：奇异矩阵

```python
S = np.array([[1., 2.], [2., 4.]])   # 第二行是第一行的 2 倍
np.linalg.det(S)                     # 0.0
np.linalg.inv(S)                     # LinAlgError: Singular matrix
```

#### `np.linalg.det(S)` —— 行列式

**操作**：$\det(S) = 1\cdot4-2\cdot2 = 0$。
**可调参数**：对高维矩阵同样可算；接近 0 意味着"病态"（数值上危险，即使不严格为 0）。
**对应数学**：主线"$\det=0$ 不可逆"。**行列式是"可逆性"的探照灯。**

#### `np.linalg.LinAlgError` —— 奇异矩阵报错

**操作**：`np.linalg.inv` 遇到 $\det=0$ 的矩阵抛 `LinAlgError: Singular matrix`——"机器压扁了空间，无法撤销"。
**可调参数**：`try/except` 捕获；训练中若遇到此报错，多半是数据冗余/特征相关导致的奇异。
**对应数学**：主线"$\det=0$ 的矩阵把空间压扁（降秩），不可逆"。第二行是第 1 行的 2 倍 → 秩为 1 → 不可逆。

## 边界声明：这套代码能做什么，不能做什么

1. **"能算出逆" ≠ "数值上安全"**。$\det$ 接近 0（病态）时，`np.linalg.inv` 能算但结果极不稳定——输入误差被放大成天文数字。**看 `np.linalg.cond(A)`（条件数）比看 $\det$ 更靠谱**；条件数巨大 = 病态 = 别信求逆结果。
2. **不要用 `np.linalg.inv` 解方程组**。`Ax = b` 应该用 `np.linalg.solve(A, b)`（LU 分解，§2.6.1）——更快、更稳、不显式求逆。**逆矩阵是理论概念，求解是工程实践，两者分开。**
3. **非方阵没有逆**，但可以用伪逆 `np.linalg.pinv`（§2.6.3 SVD 实现）。遇到"矩阵不可逆但又要'解'"，先想伪逆。
4. **`np.linalg.inv` 只能对方阵**。训练中权重矩阵常是非方阵（如 `(256,512)`）——它们没有"逆"，但可以有伪逆或转置。别对着非方阵调 `inv`。
