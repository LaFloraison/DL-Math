# 历史：当图像"学会"变成数字表——像素矩阵的诞生与登基

## 1920 年代，横跨大西洋的电报照片：图像的第一次"数字化"

1920 年代，人们开始用"传真电报"（wirephoto）跨越大陆传送照片。原理朴素得惊人：**把照片分成细密的小格子，每个格子量出明暗，变成一串数字，通过电报线传过去，接收端再重新画出来。**

这就是图像的第一次"矩阵化"——每个格子（像素）的亮度是一个数，整张照片是一张数字表。报业巨头靠它传照片，整个世界第一次意识到：**"图片"和"数字"可以互相翻译。** 早期的"像素矩阵"粗糙（格子大、灰度少），但方向已定。

## 1965 年，哈特菲尔德与 NASA：数字图像处理学科诞生

1965 年，美国喷气推进实验室（JPL）的工程师迈克尔·哈特菲尔德（Michael Hatfield）和同事们在处理"月球照片"。探测器（徘徊者 7 号）传回的月球表面照片需要增强——但它们是模拟信号，难以精确处理。

哈特菲尔德做了一个在今天看来理所当然的决定：**把照片扫描成数字矩阵，用计算机逐像素处理。** 于是"数字图像处理"作为一门学科诞生。模糊的照片被增强，噪点被去除——一切都发生在那个"像素矩阵"上。**"图像 = 矩阵，矩阵 = 可计算"从此成为工程界的共识。**

## 1998 年，LeNet：像素矩阵第一次被"深度"处理

1998 年，Yann LeCun 的 LeNet-5 在 MNIST 上工作——MNIST 正是把 $28\times28$ 的手写数字存成矩阵。LeNet 不展平矩阵，而是让卷积核在矩阵上滑动（§2.2.3.7）——**它直接"利用"了图像的矩阵结构。** 像素的上下左右，成了卷积能用的空间关系。

**"保持矩阵喂模型"第一次成为主流**——因为矩阵的"局部性"是卷积的燃料。从 1998 到 2012（AlexNet），"图像 = 矩阵"成了视觉深度学习的默认世界观。

## 2012 年至今：批量 + 矩阵 = 张量

2012 年后，训练规模化，一次处理"一批图像"成为刚需。3 张 $2\times2$ 的图，堆成 $(3,2,2)$ 的张量——**"矩阵的批"变成了张量。** 此后，一切深度学习数据都走向张量：$(B,C,H,W)$ 的图像、$(B,T,d)$ 的文本、$(B,T,F)$ 的音频。

图像的矩阵表示，从电报时代的一串数字，变成了 GPU 上轰鸣的四维张量——**同一个思想（图像 = 数字表），走了整整一百年，从"传照片"走到了"训练 ChatGPT 的视觉模块"。**

## 留一扇门

从 1920 年代的电报像素，到 LeNet 的 $28\times28$ 矩阵，再到 $(B,C,H,W)$ 的四维张量——"图像 = 数字表"从未改变，变的是这张表被堆叠得越来越高、被处理得越来越快。

而"矩阵的矩阵"——张量——即将在 §2.4 正式登场。你会看到，从向量到矩阵到张量，只是一条"不断加维"的路。
