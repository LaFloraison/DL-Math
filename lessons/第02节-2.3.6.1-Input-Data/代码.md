# 代码：把一张图变成矩阵，把一批图堆成张量

主线里我们把图像当矩阵、把一批图像当张量。这一节用 NumPy 做四件事：**① 手写一个 3×3 图像矩阵；② 3 张 2×2 图堆成 (3,2,2) 张量；③ 批处理对"矩阵"的语义；④ 瞥一眼 MNIST 批量张量的形状。**

---

## 层一：完整脚本

```python
import numpy as np                        # NumPy：矩阵与张量

# ---- ① 单张 3x3 灰度图（教材例子）----
I = np.array([[100, 150, 200],
              [ 50, 100, 150],
              [  0,  50, 100]])
print("单张图形状:", I.shape)              # (3, 3)
print("左上像素 I[0,0] =", I[0, 0])        # 100

# ---- ② 3 张 2x2 图（教材例子）----
I1 = np.array([[100, 150], [50, 100]])
I2 = np.array([[200, 250], [150, 200]])
I3 = np.array([[50, 75],  [25, 50]])
batch = np.stack([I1, I2, I3])            # 沿新轴 0 堆叠
print("批量张量形状:", batch.shape)        # (3, 2, 2)
print("第 0 张图 =\n", batch[0])

# ---- ③ 访问张量元素：第 b 张、第 i 行、第 j 列 ----
print("batch[1,0,1] =", batch[1, 0, 1])   # I2 的第 0 行第 1 列 = 250

# ---- ④ MNIST 批量：模拟 5 张 28x28 图 ----
mnist_batch = np.random.randint(0, 256, (5, 28, 28))
print("MNIST 批量形状:", mnist_batch.shape)   # (5, 28, 28)
print("5 张、每张 28×28，共", mnist_batch.size, "个像素")

# ---- ⑤ 保持矩阵结构 vs 展平 ----
flat = batch.reshape(3, -1)               # (3, 2, 2) -> (3, 4)
print("展平后形状:", flat.shape, "（丢掉了空间结构，只留样本×像素）")
```

运行输出（Python 3.11 + NumPy）：

```text

展平后形状: (3, 4)（丢掉了空间结构，只留样本×像素）
```

## 层二：分步逐函数拆解

### 步骤 1：单张图 = 矩阵

```python
I = np.array([[100, 150, 200], [50, 100, 150], [0, 50, 100]])
I.shape    # (3, 3)
```

**做什么**：一张 3×3 灰度图，每个元素 = 像素亮度。
**操作**：`np.array` 嵌套列表 → `(3,3)` 矩阵。`I[0,0]=100` 是左上角像素。
**可调参数**：像素值 0–255；`dtype=np.uint8` 是真实图像的标准类型（省内存）。归一化时转 float 再除 255。
**对应数学**：主线"灰度图 = 矩阵 $I\in\mathbb{R}^{H\times W}$"。

### 步骤 2：`np.stack` 把 3 张图堆成张量

```python
batch = np.stack([I1, I2, I3])
batch.shape    # (3, 2, 2)
```

#### `np.stack([...])` —— 沿新轴堆叠

**操作**：三张 `(2,2)` 图沿**新**第 0 维堆叠 → `(3,2,2)`。第 0 维 = "第几张图"。
**输入**：三个形状相同的数组。
**输出**：`(3,2,2)` 三维张量。
**可调参数**：`axis` 控制新轴位置（`axis=-1` 得 `(2,2,3)`——通道最后）。**默认 `axis=0` 把"样本"放最前，是深度学习惯例。**
**对应数学**：主线"批量张量 $X\in\mathbb{R}^{B\times H\times W}$"。**"矩阵的矩阵"首次出现——三维数组。**

### 步骤 3：三维下标

```python
batch[1, 0, 1]    # 250
```

**操作**：`batch[b, i, j]` = 第 $b$ 张图的第 $i$ 行第 $j$ 列像素。`batch[1,0,1]` = 第 1 张图（$I_2$）的第 0 行第 1 列 = 250。
**可调参数**：三个下标分别对应（样本, 行, 列）。
**对应数学**：主线"第 0 维样本、后两维空间"。**三维下标是读张量代码的基本功。**

### 步骤 4：MNIST 批量

```python
mnist_batch = np.random.randint(0, 256, (5, 28, 28))
```

**操作**：模拟 5 张 28×28 的图，形状 `(5,28,28)`，共 3920 像素。
**可调参数**：真实 MNIST 用 `torchvision.datasets.MNIST` 返回 `(B, 1, 28, 28)`（多了通道维）。`randint` 只是模拟形状。
**对应数学**：主线"5 张 MNIST 图 → $(5,28,28)$"。**张量的形状即数据的地图。**

### 步骤 5：`reshape(3, -1)` —— 展平

```python
batch.reshape(3, -1)    # (3, 2, 2) -> (3, 4)
```

**操作**：`-1` 自动推断：$2\times2=4$。每张图的 4 个像素摊成一维，得到 `(3,4)`——"3 样本 × 4 像素"的矩阵。
**可调参数**：这就是"卷积层 → 全连接层"之间的展平（§2.3.2 习题 3.2）。全连接吃 `(B, d)`，卷积吃 `(B, H, W)`——展平是两者的桥梁。
**对应数学**：主线"展平 vs 保持矩阵"。**展平丢空间结构（全连接用），保持矩阵留空间结构（卷积用）——同一批数据，两种吃法。**

## 边界声明：这套代码能做什么，不能做什么

1. **灰度图没有通道维**。彩色图是 `(H, W, 3)` 或 `(3, H, W)`，批后 `(B, H, W, 3)` 或 `(B, 3, H, W)`。PyTorch 用 `(B, C, H, W)`（NCHW），TensorFlow 常用 `(B, H, W, C)`（NHWC）——**通道维位置是框架约定，读代码先确认。**
2. **`np.stack` 与 `np.concatenate` 不同**。`stack` 加新轴（3 张 2×2 → (3,2,2)），`concatenate` 沿已有轴拼接（3 张 2×2 → (6,2)，会污染图的边界）。造"图像批"必须用 `stack` 或 `np.array([...])`。
3. **像素值 0–255 是"原生"，通常要归一化**。除以 255 到 [0,1]，或标准化——直接喂 0–255 会让权重初始值不匹配、训练不稳（§2.3.6.8 BatchNorm 相关）。
4. **这个例子只有灰度单通道**。真实 CNN 输入常是 `(B, 3, 224, 224)`（RGB 三通道）。"图像 = 矩阵"是基础，"图像 = 多通道张量"是现实——§2.4 会系统处理。
