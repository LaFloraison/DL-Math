# 代码：联合熵——让 Python 摊开整张配对概率表

主线把联合熵定义成"整张配对概率表的平均惊讶"：$H(X,Y) = -\sum_x\sum_y P(x,y)\log_2 P(x,y)$。本脚本围绕联合熵做三件事：验证教材硬币×骰子手算的 **3.585 bits**；构造一个"骰子被硬币操控"的相关场景，亲眼看 $H(X,Y) < H(X)+H(Y)$；再验证联合熵的两个不等式（$\ge$ 各分量的熵，$\le$ 熵之和）。最后用一个"相关强度旋钮"实验，看联合熵如何被关系一点点压缩到极限。

---

## 层一：完整脚本

```python
import numpy as np                                   # 二维数组 = 联合分布表

def entropy(probs, base=2):                          # ① 一维熵（6.2 节复用）
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def marginal(pxy, axis):                             # ② 边缘化：P(x) 或 P(y)
    return pxy.sum(axis=axis)

def joint_entropy(pxy, base=2):                      # ③ 联合熵：摊平整张表
    return entropy(pxy, base)

# ---- 场景 A：硬币 × 骰子，独立（教材 6.3.1 手算的例子） ----
px = np.array([0.5, 0.5])                            # 硬币：正/反
py = np.full(6, 1/6)                                 # 骰子：1..6 各 1/6
pxy_A = np.outer(px, py)                             # 独立 → 外积，12 格每格 1/12
print("== 场景 A：硬币 × 骰子（独立）==")
print(f"H(X)       = {entropy(px):.3f}")
print(f"H(Y)       = {entropy(py):.3f}")
print(f"H(X)+H(Y)  = {entropy(px) + entropy(py):.3f}")
print(f"H(X,Y)     = {joint_entropy(pxy_A):.3f}   # 期望 log2(12)=3.585")
print(f"不等式验证: H(X,Y)>=H(X)? {joint_entropy(pxy_A) >= entropy(px)};  H(X,Y)<=H(X)+H(Y)? {joint_entropy(pxy_A) <= entropy(px)+entropy(py)}")

# ---- 场景 B：骰子被硬币操控，相关 ----
# corr=0 独立；corr 越大，硬币正面时骰子越偏向掷出 1、反面时越偏向掷出 6
def rigged_die(corr):
    """corr∈[0,1]：0=独立；1=硬币完全决定骰子（正面→1、反面→6）。返回联合表 (2,6)。"""
    row_head = np.array([(1-corr)/6 + corr] + [(1-corr)/6]*5)   # 正面行：掷 1 的概率被 corr 拉高
    row_tail = np.array([(1-corr)/6]*5 + [(1-corr)/6 + corr])   # 反面行：掷 6 的概率被 corr 拉高
    return 0.5 * np.vstack([row_head, row_tail])                # 硬币各 0.5 → 联合概率

pxy_B = rigged_die(corr=0.8)
print("\n== 场景 B：骰子被硬币操控（corr=0.8）==")
print(f"H(X)       = {entropy(marginal(pxy_B, axis=1)):.3f}")
print(f"H(Y)       = {entropy(marginal(pxy_B, axis=0)):.3f}")
print(f"H(X)+H(Y)  = {entropy(marginal(pxy_B, axis=1)) + entropy(marginal(pxy_B, axis=0)):.3f}")
print(f"H(X,Y)     = {joint_entropy(pxy_B):.3f}   # 应小于 H(X)+H(Y)")
print(f"关系压掉的不确定 = {entropy(marginal(pxy_B,axis=1)) + entropy(marginal(pxy_B,axis=0)) - joint_entropy(pxy_B):.3f} bits")

# ---- 实验：相关强度从 0 拧到 1，联合熵单调下降 ----
print("\n-- 相关强度旋钮：corr 从 0 到 1 --")
for corr in [0.0, 0.25, 0.5, 0.75, 1.0]:
    tab = rigged_die(corr)
    hx, hy = entropy(marginal(tab, axis=1)), entropy(marginal(tab, axis=0))
    print(f"corr={corr:<4} H(X,Y)={joint_entropy(tab):.3f}   H(X)+H(Y)={hx+hy:.3f}   压掉={hx+hy-joint_entropy(tab):.3f}")
```

运行输出（Python 3.11 + NumPy）：

```text

H(X)       = 1.000
H(Y)       = 2.585
H(X)+H(Y)  = 3.585
H(X,Y)     = 3.585   # 期望 log2(12)=3.585
不等式验证: H(X,Y)>=H(X)? True;  H(X,Y)<=H(X)+H(Y)? True

== 场景 B：骰子被硬币操控（corr=0.8）==

H(Y)       = 1.700

H(X,Y)     = 2.037   # 应小于 H(X)+H(Y)
```

关键画面：**场景 A 独立，$H(X,Y)=3.585=H(X)+H(Y)$；corr 越大，$H(X,Y)$ 被关系压得越低**（corr=1.0 时只剩 1.000——骰子被硬币完全决定）。"压掉的不确定"从 0 一路涨到 1.000 bits，与"关系强度"完美单调。下面逐行拆开。

## 层二：分步逐函数拆解

### 步骤 1：`entropy` 与 `marginal` —— 复用单变量的零件

```python
def entropy(probs, base=2):
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log(probs) / np.log(base))

def marginal(pxy, axis):
    return pxy.sum(axis=axis)
```

#### `entropy(probs, base)` —— 一维熵

**操作**：与 6.2 节完全一致——规范化、过滤零概率、$-\sum p\log p/\log b$。
**输入**：一维分布 `probs`（形状 `(n,)`）。
**输出**：标量熵。
**可调参数**：`base`。注意它只吃一维——传二维表会被展平（布尔索引返回一维），语义错误；联合熵由 `joint_entropy` 单独处理。
**对应数学**：$H(X)$、$H(Y)$ 都是用它算的。

#### `marginal(pxy, axis)` —— 边缘化

**操作**：`pxy.sum(axis=axis)`。`axis=1` 沿列求和 → $P(x)$（形状 `(n_x,)`）；`axis=0` 沿行求和 → $P(y)$（形状 `(n_y,)`）。
**输入**：联合表 `pxy`（形状 `(n_x, n_y)`）；`axis`。
**输出**：一维边缘分布。
**可调参数**：`axis` 决定压出谁。这是从联合表回收单变量熵的唯一途径。
**对应数学**：$P(x) = \sum_y P(x,y)$。

---

### 步骤 2：定义 `joint_entropy` —— 摊平整张表

```python
def joint_entropy(pxy, base=2):
    """联合熵：摊平整张表"""
    return entropy(pxy, base)
```

#### `joint_entropy(pxy, base)` —— $H(X,Y) = -\sum_x\sum_y P(x,y)\log_b P(x,y)$

**做什么**：联合熵——整张配对概率表的平均惊讶。
**操作**：直接调 `entropy(pxy)`。`entropy` 里的 `probs[probs>0]` 会**自动把二维表展平成一维**（NumPy 布尔索引返回一维数组），于是二重求和 $\sum_x\sum_y$ 变成对展平后所有配对的一次求和——数学上完全等价（求和顺序不影响结果）。核心就是：**联合熵不在乎配对怎么排，只在乎每格概率被按自己的概率加权**。
**输入**：二维数组 `pxy`（形状 `(n_x, n_y)`），联合分布表，格子之和为 1。
**输出**：标量，联合熵。非负；均匀时 = $\log_b(n_x \cdot n_y)$。
**可调参数**：`base` 同上。想显式写二重循环也可以，但向量化更快、更接近"整张表一起算"的直觉。
**对应数学**：主线定义块 $H(X,Y)$。这一行就是定义本身。

### 步骤 3：场景 A —— 独立时联合熵 = 熵之和

```python
px = np.array([0.5, 0.5])
py = np.full(6, 1/6)
pxy_A = np.outer(px, py)
```

#### `np.outer(px, py)` —— 外积 = 独立联合分布

**操作**：`np.outer(a, b)[i][j] = a[i]*b[j]`。这里 `pxy_A` 是形状 `(2,6)` 的表，12 格每格 $0.5\times\frac{1}{6}=\frac{1}{12}$。
**输入**：`px`（硬币，`(2,)`）、`py`（骰子，`(6,)`）。
**输出**：`(2,6)` 联合表。
**可调参数**：`np.outer` 无参数。它构造的是**独立**联合分布——相关场景必须手动填行（场景 B 的 `rigged_die`）。
**对应数学**：独立性 $P(x,y)=P(x)P(y)$。

#### 打印与解读

```python
print(f"H(X,Y)     = {joint_entropy(pxy_A):.3f}   # 期望 log2(12)=3.585")
print(f"不等式验证: H(X,Y)>=H(X)? {joint_entropy(pxy_A) >= entropy(px)};  H(X,Y)<=H(X)+H(Y)? {joint_entropy(pxy_A) <= entropy(px)+entropy(py)}")
```

**做什么**：验证教材手算的 3.585 bits，并当场验证两条不等式。
**操作**：`joint_entropy(pxy_A)` 对 12 个等概率格子求平均惊讶；两个布尔比较打印 `True`。
**对应数学**：$H(X,Y)=\log_2 12=3.585=H(X)+H(Y)$（独立取等号）；$H(X,Y)\ge H(X)$、$\le H(X)+H(Y)$ 两条不等式同时满足。教材 §6.3.1 的 3.585 bits 被代码精确复现。

### 步骤 4：定义 `rigged_die` —— 用"相关强度"造一张被操控的表

```python
def rigged_die(corr):
    """corr∈[0,1]：0=独立；1=硬币完全决定骰子（正面→1、反面→6）。返回联合表 (2,6)。"""
    row_head = np.array([(1-corr)/6 + corr] + [(1-corr)/6]*5)
    row_tail = np.array([(1-corr)/6]*5 + [(1-corr)/6 + corr])
    return 0.5 * np.vstack([row_head, row_tail])
```

#### `rigged_die(corr)` —— 骰子被硬币操控的联合表

**做什么**：构造一个可控的**相关**联合分布。硬币（正面/反面各 0.5）决定骰子的偏向：`corr=0` 时骰子均匀（独立）；`corr` 越大，硬币正面时骰子越偏向掷出 1、反面时越偏向掷出 6；`corr=1` 时硬币**完全决定**骰子（正面必掷 1、反面必掷 6）。
**操作**：
- `row_head`：硬币正面时骰子的条件分布。第一格（掷 1）概率 $= \frac{1-corr}{6} + corr$，其余 5 格各 $\frac{1-corr}{6}$。`corr=0` 时全为 $\frac{1}{6}$（均匀）；`corr=1` 时掷 1 概率为 1（其余 0）。
- `row_tail`：硬币反面时对称地偏向掷 6。
- `0.5 * np.vstack([...])`：`np.vstack` 把两行竖着拼成 `(2,6)`，再乘 0.5 得联合概率 $P(x,y)=\frac{1}{2}P(y\mid x)$。**每行内部概率和为 1**（$corr$ 项只把"掷 1"和"其他 5 面"之间的分量搬来搬去），两行各乘 0.5 后整表之和恒为 1——**无论 `corr` 取多少，这张表始终是合法联合分布**。
**输入**：`corr`，标量 $\in [0,1]$——相关强度旋钮。
**输出**：形状 `(2,6)` 的联合分布表，格子之和恒为 1。
**可调参数**：`corr` 是唯一的旋钮。`corr=0` → 完全独立；`corr=1` → 硬币完全决定骰子。想让"正面偏向掷 1、反面仍均匀"（单侧操控），把 `row_tail` 换回 `np.full(6, 1/6)` 即可。
**对应数学**：相关联合分布 $P(x,y)=P(x)P(y\mid x)$。条件概率 $P(y\mid x)$ **依赖** $x$（正面行与反面行不同）——这正是"相关"的全部含义，也是与外积（独立）的本质区别。这个实现的关键是**保证每行都归一化**：联合分布表必须每行、整表和为 1，否则算出的熵没有意义。

### 步骤 5：场景 B —— 相关时联合熵被关系压缩

```python
pxy_B = rigged_die(corr=0.8)
print(f"H(X)+H(Y)  = {entropy(marginal(pxy_B, axis=1)) + entropy(marginal(pxy_B, axis=0)):.3f}")
print(f"H(X,Y)     = {joint_entropy(pxy_B):.3f}   # 应小于 H(X)+H(Y)")
print(f"关系压掉的不确定 = {entropy(marginal(pxy_B,axis=1)) + entropy(marginal(pxy_B,axis=0)) - joint_entropy(pxy_B):.3f} bits")
```

**做什么**：构造 corr=0.8 的相关场景，对比 $H(X)+H(Y)$ 与 $H(X,Y)$。
**操作**：`marginal(pxy_B, axis=1)` 得 $P(x)=(0.5,0.5)$（$H(X)=1.000$）；`marginal(pxy_B, axis=0)` 得 $P(y)$（因骰子被操控，$H(Y)$ 从 2.585 降到 1.700——操控让骰子不再均匀）。两者之和 2.700，而 `joint_entropy(pxy_B) = 2.037`。
**对应数学**：**$H(X,Y) = 2.037 < H(X)+H(Y) = 2.700$**。这就是主线"相关时严格小于"的现场证据。差 0.663 bits 是"关系压掉的不确定"——它是互信息的雏形（6.5 节正式命名）。

### 步骤 6：相关强度旋钮 —— 联合熵随 corr 单调下降

```python
for corr in [0.0, 0.25, 0.5, 0.75, 1.0]:
    tab = rigged_die(corr)
    hx, hy = entropy(marginal(tab, axis=1)), entropy(marginal(tab, axis=0))
    print(f"corr={corr:<4} H(X,Y)={joint_entropy(tab):.3f}   H(X)+H(Y)={hx+hy:.3f}   压掉={hx+hy-joint_entropy(tab):.3f}")
```

**做什么**：把 `corr` 从 0 拧到 1，观察联合熵的变化。
**操作**：循环里每次构造新的 `rigged_die(corr)`，算 $H(X,Y)$ 与 $H(X)+H(Y)$。
**输出**：五行——$H(X,Y)$ 从 3.585 单调降到 1.000；"压掉的不确定"从 0.000 涨到 1.000。
**对应数学**：主线"关系越强，联合熵离 $H(X)+H(Y)$ 越远"。corr=1.0 时硬币完全决定骰子，$H(Y\mid X)=0$、$H(X,Y)=H(X)=1.000$、"压掉"=1.000——骰子的全部不确定都被关系"归并"进硬币。这条单调曲线就是"联合熵作为相关强度的函数"的完整画像：**从"完全独立"（3.585）到"完全决定"（1.000），中间每一格都是关系强度的一个刻度。**

## 改个数字试试：把边界推向极限

### 实验 1：完全决定 vs 单向决定

```python
# 双向完全决定：corr=1.0（正面→1，反面→6）—— X 完全决定 Y，且 Y 完全决定 X
tab = rigged_die(1.0)
print(f"双向完全决定: H(X,Y)={joint_entropy(tab):.3f}   H(Y|X)={entropy(tab)-entropy(marginal(tab,axis=1)):.3f}   H(X|Y)={entropy(tab)-entropy(marginal(tab,axis=0)):.3f}")

# 单向决定：X 取三个值 {X1,X2,X3}，Y 由 X 决定但非一一对应
# X1→Y1、X2→Y1、X3→Y2（非单射：Y1 对应两个 X）—— X 决定 Y，但 Y 不能完全决定 X
tab1 = np.array([[1/3, 0.0], [1/3, 0.0], [0.0, 1/3]])   # 行=X, 列=Y
print(f"单向决定:     H(X,Y)={joint_entropy(tab1):.3f}   H(Y|X)={entropy(tab1)-entropy(marginal(tab1,axis=1)):.3f}   H(X|Y)={entropy(tab1)-entropy(marginal(tab1,axis=0)):.3f}")
```

输出：

```text
双向完全决定: H(X,Y)=1.000   H(Y|X)=0.000   H(X|Y)=0.000
单向决定:     H(X,Y)=1.585   H(Y|X)=0.000   H(X|Y)=0.667
```

`rigged_die(1.0)`：正面必掷 1、反面必掷 6——$X$ 与 $Y$ **互相**完全决定，$H(Y\mid X)=0$ 且 $H(X\mid Y)=0$，联合熵塌缩到 $H(X)=1.000$。而"单向决定"表（X1、X2 都映到 Y1，X3 映到 Y2，**非单射**）：知道 $X$ 就完全知道 $Y$（$H(Y\mid X)=0$），但知道 $Y=Y1$ 时仍分不清是 X1 还是 X2（$H(X\mid Y)=0.667>0$）——**"完全决定"是单向的**：$H(Y\mid X)=0$ 只说明"$Y$ 是 $X$ 的函数"，不说明"$X$ 是 $Y$ 的函数"。这正是 6.3.2 节"条件熵不对称"的极限形态。

### 实验 2：换一对"互不相干但各自复杂"的变量

```python
pxy = np.outer(np.full(10, 0.1), np.full(10, 0.1))
print(f"H(X,Y) = {joint_entropy(pxy):.3f}   H(X)+H(Y) = {entropy(np.full(10,0.1)) + entropy(np.full(10,0.1)):.3f}")
```

输出：

```text
H(X,Y) = 6.644   H(X)+H(Y) = 6.644
```

两个各 10 等可能的变量，完全独立：联合熵 6.644 = 6.644。**联合熵很大，可它们毫无关系**——这正是主线边界声明第一条：联合熵不量关系。6.644 bits 只说明"系统复杂"，要量"关系"得看 $H(X)+H(Y)-H(X,Y)=0$。联合熵大 ≠ 相关，联合熵小 ≠ 无关——它是"总面积"，不是"交叠区"。

## 边界声明：这套代码能做什么，不能做什么

1. **`joint_entropy` 不能用来判断"有没有关系"。** 联合熵只量"系统总不确定"。场景 B 的 2.037 和独立场景的 3.585，单独看都只是"总不确定"的数字；要判断相关，必须同时算 $H(X)+H(Y)$ 看差。差的那个量（互信息）才是关系尺度。只报 `H(X,Y)` 就像只报"面积"不报"重叠了多少"。
2. **二维表必须归一化。** `joint_entropy` 假设格子之和为 1。`rigged_die` 内部通过"每行先归一化、再乘 0.5"保证整表恒为 1（这是它比"随手填数"更可靠的原因）；手填表时务必检查 `pxy.sum() == 1.0`。**非归一化的表会让 `entropy` 算出一个看似正常、实则无意义的数**——这是本节最常见的隐蔽错误。
3. **展平丢失了"配对顺序"，但保留"配对本身"。** `entropy(pxy)` 把二维表展平后求和，数学上等价于二重求和——因为联合熵只关心每格概率，不关心格子排在哪。但这意味着：**两张"同样的格子、不同的摆放"的联合表会得到相同的联合熵**（边缘相同、关系相同、只是行列标签换了）——这正确；但若"摆放"改变了格子里的概率分布，联合熵也会变。联合熵对"概率怎么摊"敏感，对"标签叫什么"不敏感。
