# §6.3.1 联合熵 —— 习题

本节主线把熵推向"一对变量"：$H(X,Y) = -\sum_x\sum_y P(x,y)\log_2 P(x,y)$，并确立"独立时等于熵之和、相关时小于熵之和"的性格。习题分三组：**概念检验** 验证联合熵的性质与边界，**计算实践** 手算独立/相关场景并代码复核，**DL 延伸** 把联合熵放回生成模型的联合建模。每题附完整解答与思路点拨。

---

## 一、概念检验

### 题 1（选择）：哪个说法正确？

$X, Y$ 为任意离散随机变量。以下说法**正确**的是（ ）。

- A. $H(X,Y)$ 一定等于 $H(X)+H(Y)$
- B. $H(X,Y)$ 一定小于 $H(X)+H(Y)$
- C. $H(X,Y) \le H(X)+H(Y)$，且 $H(X,Y) \ge H(X)$、$H(X,Y) \ge H(Y)$ 恒成立
- D. $H(X,Y) < H(X)$ 是有可能的

**解答**：C。

C 的两端都是铁的：$H(X,Y) \le H(X)+H(Y)$（等号当且仅当独立），且联合不会比单个更确定（$\ge H(X)$、$\ge H(Y)$）。A 只在独立时成立；B 只在相关时成立；D 永远不可能——多一个变量只会让系统更不确定。

**思路点拨**：这题考的是"恒成立"的边界。A 和 B 各披一件"常见情形"的外衣，但都不是恒成立。判别方法：**联合熵与熵之和的差，正是相关性的度量**——所以"等于"（独立）和"小于"（相关）都是特定情形，只有"≤ 恒成立"和"≥ 单个分量"是铁的。最危险的错误是 D：以为"关系能让联合熵降到单个之下"——不可能，联合熵只增不减。

### 题 2（判断 + 简答）：联合熵能判断"相关"吗？

有人测量了 $X, Y$ 两个变量，算出 $H(X,Y) = 5.0$ bits，然后宣称："这个数很大，说明 $X$ 和 $Y$ 关系密切。" 判断并解释。

**解答**：错。**联合熵大 ≠ 相关。** $H(X,Y)$ 量的是"整个系统的总不确定"，它同时被两个因素撑大：①每个变量自己的复杂程度；②两变量间的独立程度。如果 $X$、$Y$ 各自取值很多、但完全独立，联合熵照样很大（如 6.3.1《代码.md》实验 2：两个 10 等可能的独立变量，$H(X,Y)=6.644$ bits，可它们毫无关系）。要判断"关系密切"，必须看 $H(X)+H(Y)-H(X,Y)$ 这个差——差越大关系越强，独立时差为零。5.0 bits 的联合熵本身不携带任何"关系"信息。

**思路点拨**：这是联合熵最容易被误用的一点。记忆锚点：**联合熵 = 总面积；关系 = 交叠区。** 两个独立但复杂的变量有巨大的"总面积"却没有交叠。判断关系的正确操作永远是"算差"，而不是"看联合熵的大小"。这个差正是 6.5 节互信息的定义雏形。

### 题 3（简答）：$H(X,Y)=H(X)$ 意味着什么？

已知 $H(X,Y) = H(X)$。据此能推出关于 $X, Y$ 的什么结论？

**解答**：能推出 **$H(Y\mid X) = 0$**——给定 $X$，$Y$ 被完全确定。由链式法则 $H(X,Y) = H(X) + H(Y\mid X)$，$H(X,Y)=H(X)$ 立即给出 $H(Y\mid X)=0$。这说的是：$Y$ 是 $X$ 的（确定性）函数，知道 $X$ 就完全知道 $Y$。注意反过来不一定：$Y$ 完全由 $X$ 决定，但 $X$ 未必由 $Y$ 决定（比如 $X$ 是任意整数、$Y$ 恒等于 0——知道 $X$ 完全知道 $Y$，知道 $Y$ 却对 $X$ 一无所知）。

**思路点拨**：这道题把链式法则变成推理工具。$H(X,Y)=H(X)$ 不是"Y 多余"——它是"Y 的信息全部来自 X，没有独立的部分"。识别这类题的方法：**联合熵等于哪个分量，就把哪个分量当作"信息源头"**。这也预告了条件熵的直觉：$H(Y\mid X)=0$ 正是"条件熵下界"，对应"完全依赖"的极端。

## 二、计算实践

### 题 1（硬币 × 骰子：复现教材的 3.585）

$X$：公平硬币（正/反）。$Y$：公平骰子。$X, Y$ 独立。

(a) 写出联合分布表（12 格）。
(b) 手算 $H(X,Y)$。
(c) 验证 $H(X,Y)=H(X)+H(Y)$ 并解释为什么取等号。

**解答**：

(a) 独立时 $P(x,y)=P(x)P(y)$，每格 $0.5\times\frac{1}{6}=\frac{1}{12}$。表是 $2\times6$ 的全 $\frac{1}{12}$ 矩阵。

(b) 12 个等概率配对：
$$H(X,Y) = -\sum_{i=1}^{12}\frac{1}{12}\log_2\frac{1}{12} = \log_2 12 \approx 3.585 \text{ bits}$$

(c) $H(X)=1$ bit，$H(Y)=\log_2 6\approx 2.585$ bits，$H(X)+H(Y)=3.585=H(X,Y)$。取等号因为 $X,Y$ **独立**——联合分布是外积，$\log P(x,y)=\log P(x)+\log P(y)$ 把二重求和拆成两个独立的求和，于是联合熵退化为熵之和。**独立性是"联合熵=熵之和"的充分必要条件。**

**思路点拨**：(b) 的核心是"12 个等概率配对 → $\log_2 12$"；别把 12 当成概率。最容易错的是把 $H(X,Y)$ 算成 $H(X)\times H(Y)$——熵是相加的，配对概率才是相乘的。判别句：**"配对"的概率相乘（$\frac{1}{12}$），"配对"的熵相加（1+2.585）。**

**代码验证**：
```python
import numpy as np
def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -np.sum(p * np.log(p) / np.log(2))
pxy = np.full((2, 6), 0.5 * 1/6)
print(entropy(pxy))            # 3.584962500721156 = log2(12)
```

### 题 2（被操控的骰子：相关让联合熵变小）

改一下规则：硬币**反面**时骰子均匀；硬币**正面**时骰子掷出 1 的概率是 $\frac{1}{2}$、其余 5 面各 $\frac{1}{10}$。

(a) 填出联合分布表（8 个非零格？不——是 12 格，其中正面行不均匀）。
(b) 手算 $H(Y)$ 与 $H(X,Y)$（可用代码），并计算 $H(X)+H(Y)-H(X,Y)$（这个差预示着什么？）。

**解答**：

(a) 正面行：$P(H,1)=0.5\times0.5=0.25$，$P(H,j)=0.5\times0.1=0.05$（$j=2..6$）。反面行：$P(T,j)=0.5\times\frac{1}{6}\approx0.0833$（$j=1..6$）。

(b) $P(Y=1)=0.25+0.0833=0.333$，$P(Y=j)=0.05+0.0833=0.133$（$j=2..6$）。$H(Y)=-(0.333\log_2 0.333 + 5\times0.133\log_2 0.133)\approx 0.333\times1.585 + 5\times0.133\times2.910 \approx 0.528+1.935 = 2.463$ bits。$H(X)=1$ bit，所以 $H(X)+H(Y)=3.463$ bits。
联合熵（代码）：`entropy(pxy)` 得约 **3.373** bits。差 $= 3.463 - 3.373 = 0.090$ bits。

**0.090 bits 正是"硬币对骰子关系的贡献"**——骰子的不确定中，有 0.090 bits 被"知道硬币"消掉了。这个差就是 6.5 节互信息 $I(X;Y)$ 的预演。注意它**很小**：因为"正面时骰子偏向掷 1、反面仍均匀"这条规则对骰子整体的约束很弱（反面时毫无约束，正面时也只把掷 1 提到 0.5），所以关系能消掉的不确定有限——**别期待关系强，差就一定大，先算出来再说**。

**思路点拨**：(b) 的关键是"先算边缘，再算联合，然后做差"。容易错的地方：①$P(Y=j)$（$j\ge2$）要**同时**加正面行和反面行（$0.05+0.0833$），别只加一边；②联合熵不能用"每个格子等概率"来算——只有独立时才等概率；③**联合熵要对着整张表算**（这里 12 个格子），$H(X,Y)=3.373$ 比 $H(Y)=2.463$ 大是必然的（联合不会比单个更确定）。这个"差"请记住它的名字（互信息），它是信息论里"关系"的正式度量：**$H(X)+H(Y)-H(X,Y)$ 越大，两个变量纠缠越深。**

**代码验证**：
```python
import numpy as np
def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -np.sum(p * np.log(p) / np.log(2))
row_h = np.array([0.5] + [0.1]*5) * 0.5
row_t = np.full(6, 1/6) * 0.5
pxy = np.vstack([row_h, row_t])
print(entropy(pxy))              # 约 3.373
print(entropy([0.5,0.5]) + entropy(pxy.sum(axis=0)) - entropy(pxy))  # 约 0.090
```

### 题 3（同边缘、不同联合：关系的指纹）

两个联合分布表 $A$ 与 $B$：$A$ 是独立的外积（$P(x,y)=P(x)P(y)$），$B$ 是相关表。已知两者**边缘分布完全相同**（$P_A(x)=P_B(x)$、$P_A(y)=P_B(y)$），但 $H(X,Y)_A > H(X,Y)_B$。这个不等式告诉你什么？从"边缘一样、联合不同"这个事实你能推出什么？

**解答**：边缘分布完全相同 → $H(X)_A = H(X)_B$、$H(Y)_A = H(Y)_B$，于是 $H(X)+H(Y)$ 两个表相等。既然 $H(X,Y)_A > H(X,Y)_B$，那么差 $[H(X)+H(Y)] - H(X,Y)$ 在 $A$ 更小、在 $B$ 更大——**$B$ 里两个变量关系更强**。这证明了主线核心：**同样的边缘，不同的摆放，联合熵不同**——联合熵（以及它的差）能"看到"关系，而单变量熵看不到。$A$ 是独立（差为 0），$B$ 是相关（差 > 0）。

**思路点拨**：这道题是全节最重要的思维实验。它回答"为什么我们需要联合熵"：因为 $H(X)$ 和 $H(Y)$ 加起来**丢掉了关系**——两张表边缘一样，单变量熵完全一样，看不出任何差别；只有把"配对"放回表里算联合熵，关系才现形。这就是戈耳顿甜豌豆的历史直觉：分别看两代种子什么都看不出，画在一起才看见遗传。6.5 节会把"差"命名为互信息——它就是"边缘看漏了的那部分"。

## 三、DL 延伸

### 题 1（GAN 与 VAE：两个"联合分布"的哲学）

生成对抗网络 (GAN) 训练时让生成器学真实数据分布，判别器区分真伪；变分自编码器 (VAE) 建模数据 $x$ 与隐变量 $z$ 的联合分布 $p(x,z)$。

(a) GAN 学的"分布"和 VAE 学的"分布"在变量个数上有什么不同？
(b) VAE 的 ELBO 里有 $\mathrm{D}_{\mathrm{KL}}(q(z\mid x)\|p(z))$。用联合熵/条件熵的语言，这一项在约束什么？

**解答**：

(a) GAN 的生成器学的是**数据 $x$ 自己的边缘分布** $p_{\text{gen}}(x)$（目标逼近真实数据的 $p_{\text{data}}(x)$）；VAE 学的是**数据 + 隐变量**的联合分布 $p(x,z)$，再边缘化出 $p(x)=\int p(x,z)\,dz$。所以 GAN 只接触 $x$ 一个变量，VAE 要处理 $(x,z)$ 一对变量——后者天然是联合熵/条件熵的领域。

(b) KL 项 $\mathrm{D}_{\mathrm{KL}}(q(z\mid x)\|p(z))$ 约束的是"给定 $x$ 后 $z$ 的条件分布 $q(z\mid x)$"别离先验 $p(z)$ 太远。翻译成信息论：它把 $H(Z\mid X)$ 控制在一个范围——既不能太大（$z$ 与 $x$ 无关、编码器在瞎猜），又不能太小到塌缩（$z$ 退化成 $x$ 的确定性压缩，丢失多样性）。VAE 的整个训练，是在"重建 $x$ 需要多少关于 $z$ 的信息"（压低 $H(X\mid Z)$）与"别让 $z$ 完全泄露 $x$"（约束 $H(Z\mid X)$）之间找平衡——这正是联合熵框架里的资源分配博弈。

**思路点拨**：这道题让联合熵"走出表格"进入高维生成模型。要点：**GAN 管一个变量的分布，VAE 管两个变量（数据×隐码）的联合分布**。当读到 "VAE 拟合 $p(x,z)$"时，你脑子里应该浮现一张"数据-隐码"的配对表——只是格子从 12 个变成连续无穷个。ELBO 里每个项，都能对应回熵家族的一个成员（条件熵、KL 散度）。理解联合分布这个"对象"，是理解现代生成模型的第一步。

### 题 2（表示学习：$H(X,Z)$ 为什么是设计的核心）

一个自编码器把高维输入 $x$ 编码成低维潜码 $z$。设计者希望：$z$ 尽量"压缩"（低维、信息浓密）。从联合熵 $H(X,Z)$ 的角度，为什么"$z$ 与 $x$ 纠缠得越紧越好"，但又不能"$z$ 干脆等于 $x$"？

**解答**：联合熵 $H(X,Z)$ 是"数据 × 潜码"系统的总不确定。设计者想要的平衡是：
- **$z$ 尽量决定 $x$**（压低 $H(X\mid Z)$）：给定 $z$ 能还原 $x$，潜码才算"抓到了信息"——这对应自编码器的重建损失。
- **$z$ 的熵别太小**（别塌缩）：如果 $z$ 对每张图都输出几乎相同的向量，$H(Z)\to0$，潜码就没在"区分"数据——所有图共享一个编码，等于没编码。
- **但 $z$ 不能等于 $x$**：如果 $z=x$（恒等编码），$H(X\mid Z)=0$ 且 $I(X;Z)=H(X)$ 最大，可完全没有"压缩"——潜码维度没降，冗余没去掉。

联合熵的视角：$H(X,Z)=H(Z)+H(X\mid Z)$。设计者想要"$H(Z)$ 小（低维压缩）但 $H(X\mid Z)$ 也小（能重建）"——两者同时小很困难，这正是在最小化它们之和，即最小化联合熵，同时保持重建能力。**表示学习 = 让联合熵 $H(X,Z)$ 尽量小，但不让任何一边的信息被白白丢掉。**

**思路点拨**：这道题把联合熵变成"设计目标"。关键转译：$H(X,Z)=H(Z)+H(X\mid Z)$——低维压缩压低 $H(Z)$，重建能力压低 $H(X\mid Z)$。两个目标共同挤压的是**联合熵**。当一个表示"好"时，它其实是让"数据×潜码"这个联合系统的总不确定尽可能小、又没塌缩。这也呼应信息瓶颈理论（6.5 节参考资料）：深度网络在逐层压缩 $I(X;Z)$，本质上都在调这个联合系统的熵。
