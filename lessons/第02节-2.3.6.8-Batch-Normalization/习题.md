# 习题：批归一化

## 第一组：概念检验

**1.1（单选）** 一批数据 $X$（形状 `(m, d)`），BatchNorm 的均值与方差是按哪个轴统计的？
- A. 沿特征轴（`axis=-1`）
- B. 沿批轴（`axis=0`）
- C. 对每个样本单独算
- D. 不按轴，算全体一个数

**1.2（判断并说明）** "BatchNorm 归一化后，网络学到的原始分布信息就永久丢失了，无法恢复。" 这句话对吗？$\gamma$、$\beta$ 的作用是什么？

**1.3（填空）** BatchNorm 三步：算批____与____、归一化 $\hat{X} = \frac{X-\mu}{\sqrt{\sigma^2+\epsilon}}$、用可学习参数 $\_\_\_$（缩放）与 $\_\_\_$（平移）变换。测试时用____统计量（滑动平均）。

## 第二组：计算实践

**2.1（手算 + 代码验证）** 对 $X = \begin{bmatrix} 1 & 10 \\ 3 & 20 \\ 5 & 30 \end{bmatrix}$（3 样本、2 特征），手算每特征均值/方差、归一化后 $X$，用 NumPy 验证每列均值≈0、方差≈1。

**2.2（代码验证）** 验证"$\gamma=\sqrt{\sigma^2+\epsilon}$、$\beta=\mu$ 时 BatchNorm 还原原数据"：用随机数据跑一遍，`np.allclose` 确认。

**2.3（动手理解）** 用 `np.random.randn(1000, 5)` 生成数据，做一次完整 BatchNorm（γ=1,β=0），统计输出每列的均值/方差，观察是否≈0/≈1。

## 第三组：DL 延伸

**3.1（场景判断）** PyTorch 里 `nn.BatchNorm2d(64)` 的 `64` 是什么？它的 `weight`/`bias` 对应 BatchNorm 的哪个参数？`model.eval()` 时统计量来自哪里？

**3.2（场景分析）** 为什么 Transformer 用 LayerNorm（沿特征维）而不用 BatchNorm（沿批维）？从"批大小稳定性"与"序列独立性"两方面回答。

---

## 解答与思路点拨

### 第一组

**1.1 答案：B（沿批轴 `axis=0`）。**
- **思路**：BatchNorm 对每个特征，在这一批样本上算均值/方差——沿 `axis=0`（样本维）。得 $d$ 组 $(\mu_j,\sigma_j^2)$。
- **点拨**：**"沿批轴统计"是 BatchNorm 名字里"Batch"的来源**。LayerNorm 才沿特征轴（`axis=-1`）。B vs A 正是 BatchNorm vs LayerNorm 的分水岭。

**1.2 不对。**
- **思路**：归一化后还有一步"$\gamma, \beta$ 缩放平移"——若 $\gamma=\sqrt{\sigma^2+\epsilon}$、$\beta=\mu$，输出完全还原原始激活。所以"归一化"不是强制，而是"给网络一个选项"：$\gamma, \beta$ 可学习，网络自己决定"归一化多少、保留原分布多少"。
- **点拨**：**"归一化 + 可学习恢复"是 BatchNorm 的精髓**。它不是"洗掉信息"，是"让信息处于可调节的稳定形态"。

**1.3 答案：均值；方差；$\gamma$；$\beta$；滑动平均（running）统计量。**
- **思路**：三步公式 + 测试期滑动平均。
- **点拨**：三个空 + 一个行为，就是 BatchNorm 的完整骨架。

### 第二组

**2.1**
$\mu = [3, 20]$、$\sigma^2 = [\frac{(1-3)^2+(3-3)^2+(5-3)^2}{3}, \frac{(10-20)^2+(20-20)^2+(30-20)^2}{3}] = [\frac{8}{3}, \frac{200}{3}] \approx [2.667, 66.67]$。
```python
import numpy as np
X = np.array([[1.,10.],[3.,20.],[5.,30.]])
mu = X.mean(axis=0); var = X.var(axis=0)
Xh = (X-mu)/np.sqrt(var+1e-5)
print(np.round(Xh.mean(axis=0),6), np.round(Xh.var(axis=0),6))   # ≈0 ≈1
```
- **思路**：按列统计、按列归一化。$X$ 的第 1 列 `[1,3,5]` 归一化后约 `[-1.22, 0, 1.22]`。
- **点拨**：**"每列归一化"让不同量纲的特征可比**——这正是"称重站"的数学版本。

**2.2**
```python
X = np.random.randn(8, 4)
mu = X.mean(axis=0); var = X.var(axis=0)
Xh = (X - mu)/np.sqrt(var + 1e-5)
back = np.sqrt(var+1e-5)*Xh + mu
print(np.allclose(back, X))    # True
```
- **思路**：$\gamma=\sqrt{\sigma^2+\epsilon}$、$\beta=\mu$ 精确还原 $X$。
- **点拨**：**"能还原"说明归一化不是损失，是"可逆变换"**——$\gamma,\beta$ 是那个"逆旋钮"。

**2.3**
```python
X = np.random.randn(1000, 5)
Xh = (X - X.mean(axis=0)) / np.sqrt(X.var(axis=0) + 1e-5)
print(np.round(Xh.mean(axis=0), 6))   # ≈0
print(np.round(Xh.var(axis=0), 6))    # ≈1
```
- **思路**：大批量下归一化效果更稳定——统计量估计更准。
- **点拨**：**批越大，统计量越接近真实分布，归一化越"标准"**。这也是批大小影响 BatchNorm 的实证。

### 第三组

**3.1 答案：`64` 是通道数 $C$（对 `(B,C,H,W)` 的每个通道分别归一化）；`weight` 对应 $\gamma$、`bias` 对应 $\beta$；`model.eval()` 时用 `running_mean`/`running_var`（训练时累积的滑动平均）。**
- **思路**：BatchNorm2d 对每个通道算一组 $\mu,\sigma^2,\gamma,\beta$（沿 `(B,H,W)` 统计）。训练用批统计、测试用滑动平均。
- **点拨**：**`nn.BatchNorm2d(64)` = "64 个称重站，每通道一个"**。`running_*` 是测试期稳定性的关键。

**3.2 思路**
- **批大小不稳定**：Transformer 处理变长序列、大模型批量常受限，BatchNorm 的批统计噪声大甚至失效（$m$ 小）。LayerNorm 沿特征维、不依赖批——对任意批量/序列长度都稳定。
- **序列独立性**：Transformer 每个 token 应被独立处理；BatchNorm 混入"同批其他样本"的统计信息，破坏序列间的独立性。LayerNorm 对每个 token 单独归一化，保持独立。
- **此外**：推理时 BatchNorm 依赖训练时的 running 统计（部署复杂），LayerNorm 无此负担——大模型部署更简洁。
- **点拨**：**"归一化沿哪个轴"是架构设计哲学**：BatchNorm 适合"批大且稳定"（CNN），LayerNorm 适合"批多变、需序列独立"（Transformer）。
