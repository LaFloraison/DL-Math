## 第一步：Toy Model —— 一个"统一尺度"的称重站

一队运动员来体检，教练要比较他们的体能数据。可数据五花八门：身高的单位是"厘米"（160–190），体重的单位是"公斤"（50–100），跑步速度是"米/秒"（4–8），而血糖是"毫摩尔/升"（4–6）——**量纲不同，数值大小不可比。**

教练做了一件关键的事：**把每个指标标准化**——减去这批人的均值，除以标准差。于是每个指标都变成"均值 0、方差 1"的标准化分数。身高的 175 与体重的 70 终于可以放在同一把尺子上比较了。

**批归一化 (Batch Normalization, BatchNorm)** 在神经网络里做同样的事：**每层激活进来，先在这一批样本上算均值与方差，归一化到均值 0、方差 1，再用两个可学习参数 $\gamma, \beta$ 做一次"缩放和平移"。** 它让每一层的输入分布保持稳定——训练更稳、更快。

但注意最后一步的巧妙：**为什么要 $\gamma, \beta$ 再缩放平移回来？** 因为"归一化"会抹掉网络好不容易学到的"分布信息"——$\gamma, \beta$ 允许网络**按需恢复**归一化前的能力。这是"标准化"与"可学习"的平衡。

## 第二步：正式数学讲解

### 一、撞墙：归一化会不会把"表示能力"洗掉？

你也许觉得：归一化到 0-1 均值，那网络学到的"某些激活本来就该很大"的信息不就丢了吗？**这正是 $\gamma$、$\beta$ 存在的意义。**

如果 $\gamma = \sqrt{\sigma_B^2 + \epsilon}$、$\beta = \mu_B$，那么 $Y = \gamma\hat{X} + \beta$ 就完全还原成原始激活——**网络可以选择"不归一化"**。而 $\gamma, \beta$ 是可学习的，网络在训练中自己决定"这层要多归一化、还是多保留原分布"。**你撞的墙是："归一化"和"保留表达能力"是一对矛盾，而 BatchNorm 用两个可学习参数让网络自己找平衡。**

### 二、定义块：三步走

> **批归一化（对单个特征维 $j$，在一个批量上）**
>
> **第 1 步：算批统计量**
> $$\mu_B = \frac{1}{m}\sum_{i=1}^{m} X_i, \qquad \sigma_B^2 = \frac{1}{m}\sum_{i=1}^{m}(X_i - \mu_B)^2$$
> （$m$ = 批大小；对每个特征维各算一组 $\mu_B, \sigma_B^2$）
>
> **第 2 步：归一化**
> $$\hat{X}_i = \frac{X_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$
> （$\epsilon$ 小常数，防除零）
>
> **第 3 步：缩放 + 平移（可学习）**
> $$Y_i = \gamma \hat{X}_i + \beta$$
> （$\gamma$：缩放参数；$\beta$：平移参数——均随训练学习）

### 三、展开：为什么 BatchNorm 让训练又快又稳？

三个作用机制：

1. **稳定内部协变量偏移**。深层网络中，每层输入分布随前层权重更新而漂移（内部协变量偏移，internal covariate shift）。BatchNorm 把每层输入拉回"均值 0、方差 1"，让网络各层"对着稳定的输入训练"，收敛更快。

2. **允许更大的学习率**。归一化让激活的尺度可控——梯度不会因激活过大而爆炸，因此可以放心用更大的学习率（§2.3.6.5 说过学习率是双刃剑）。

3. **自带轻微正则化**。批统计量是"随机样本"的估计，有噪声——这个噪声给训练加了轻微的扰动，效果类似正则化（§2.3.6.6），让模型更鲁棒（对较小批量时尤其明显）。

直觉检验：为什么"逐特征维"归一化？一个 `(m, d)` 的批量，有 $d$ 个特征——对**每个特征 $j$**，在这批的 $m$ 个样本上算均值方差（`axis=0`），得 $d$ 组 $(\mu_j, \sigma_j^2)$、$d$ 个 $\gamma_j$、$d$ 个 $\beta_j$。**归一化是"沿批维、对每个特征分别做"。**

边界声明：**BatchNorm 依赖"批"——批太小统计量噪声大、甚至失效**（batch size=1 时方差为 0，无法归一化）。这引出它的替代品：**LayerNorm**（沿特征维归一化，不依赖批——Transformer 用它）、**InstanceNorm、GroupNorm**（GAN/风格迁移常用）。另外，**BatchNorm 在训练与测试时行为不同**：训练用"当前批"的统计量，测试用"训练时累积的滑动平均"统计量（固定 $\mu, \sigma^2$）——所以 `model.eval()` 会切换统计量来源。还有：**"归一化 + 可学习 γ,β"** 的模式是通用范式，不只 BatchNorm 用。

## 第三步：DL 桥接

**BatchNorm 是 2015 年后几乎所有 CNN 的标准部件**，三处落点：

1. **`nn.BatchNorm2d(C)` / `nn.BatchNorm1d(d)`**：PyTorch 实现。它的 `weight`（$\gamma$）与 `bias`（$\beta$）是可学习参数；`running_mean`/`running_var` 是测试期用的滑动平均统计量。**模型里"卷积 → BN → ReLU"是 CNN 的黄金三连。**

2. **训练/测试切换**：`model.train()` 用批统计量，`model.eval()` 用滑动平均统计量——**忘切 eval 会让 BatchNorm 在推理时行为错误**（这是常见 bug）。

3. **与 Transformer 的分野**：Transformer 用 **LayerNorm**（沿特征维，不依赖批）而非 BatchNorm——因为注意力/大模型的批大小不稳定、且需序列间独立。**理解 BatchNorm 的"依赖批"，才能理解 LayerNorm 为何存在。**

一句话：**BatchNorm 把每层激活"拉回稳定分布"，再用可学习的 $\gamma, \beta$ 保留表达能力**——它让深层网络训练又快又稳，是 CNN 时代的"稳定器"。你在每个 `nn.BatchNorm2d` 里看到的，就是这三步公式。
