# 代码：手写 BatchNorm 三步走——批统计、归一化、γ/β 缩放平移

主线里我们给了 BatchNorm 的三步公式。这一节用 NumPy 完整实现（训练模式），并用一个具体例子验证"每个特征维沿批维归一化"。

---

## 层一：完整脚本

```python
import numpy as np                       # NumPy：均值与方差

# ---- ① 一个批次：m=4 个样本、d=3 个特征 ----
X = np.array([
    [1.0, 10.0, 0.5],
    [3.0, 20.0, 0.7],
    [2.0, 15.0, 0.6],
    [4.0, 30.0, 0.8],
])                                        # 形状 (4, 3)
print("批量 X 形状:", X.shape)

eps = 1e-5

# ---- ② 第 1 步：沿批维（axis=0）算每个特征的均值、方差 ----
mu  = X.mean(axis=0)                      # 每个特征一个均值，形状 (3,)
var = X.var(axis=0)                       # 每个特征一个方差，形状 (3,)
print("均值 μ  =", mu)
print("方差 σ² =", var)

# ---- ③ 第 2 步：归一化 X̂ = (X - μ)/√(σ² + ε) ----
X_hat = (X - mu) / np.sqrt(var + eps)
print("归一化 X̂（每列均值≈0、方差≈1）:")
print(np.round(X_hat, 3))
print("X̂ 每列均值 ≈ 0:", np.round(X_hat.mean(axis=0), 6))
print("X̂ 每列方差 ≈ 1:", np.round(X_hat.var(axis=0), 6))

# ---- ④ 第 3 步：可学习 γ、β 缩放平移 ----
gamma = np.array([1.0, 2.0, 0.5])         # 可学习缩放参数（初始值）
beta  = np.array([0.0, 1.0, -0.2])        # 可学习平移参数（初始值）
Y = gamma * X_hat + beta
print("输出 Y = γX̂ + β:")
print(np.round(Y, 3))

# ---- ⑤ 验证：γ=√(σ²+ε)、β=μ 时能还原原 X ----
gamma_restore = np.sqrt(var + eps)
beta_restore  = mu
X_back = gamma_restore * X_hat + beta_restore
print("还原原 X:", np.allclose(X_back, X))    # True
```

## 层二：分步逐函数拆解

### 步骤 1：批量数据

```python
X = np.array([[...], ...])    # (4, 3)
```

**做什么**：4 个样本、3 个特征的一批数据。三个特征量纲差很大（$0.5$ vs $30$）——正是归一化要处理的"称重站"场景。
**可调参数**：形状 `(m, d)`。真实 CNN 里是 `(B, C, H, W)`，BN 沿 `(B, H, W)` 统计、对每个通道 $C$ 各算一组。
**对应数学**：主线"对单个特征维、在一个批量上"。

### 步骤 2：批统计量

```python
mu  = X.mean(axis=0)      # 每个特征一个均值
var = X.var(axis=0)       # 每个特征一个方差
```

#### `X.mean(axis=0)` / `X.var(axis=0)` —— 沿批维统计

**操作**：`axis=0` 沿"样本维"求均值/方差——对每个特征，在 4 个样本上统计。得形状 `(3,)` 的 $\mu$、$\sigma^2$。
**可调参数**：`axis` 是"归一化沿哪个轴"的关键——BatchNorm 用 `axis=0`（沿批），LayerNorm 用 `axis=-1`（沿特征）。**轴的选择，就是 BatchNorm 与 LayerNorm 的本质区别。**
**对应数学**：主线第 1 步公式。**注意：`X.var` 默认是"总体方差"（除 $m$），BN 用总体方差（不是样本方差 $m-1$）。**

### 步骤 3：归一化

```python
X_hat = (X - mu) / np.sqrt(var + eps)
```

**操作**：每个元素减去对应特征均值、除以对应特征标准差。**广播**：`(4,3) - (3,)` 沿行广播。
**可调参数**：`eps` 防除零；特征方差为 0（常数特征）时，没有 `eps` 会除零。
**对应数学**：主线第 2 步公式。输出每列均值 ≈ 0、方差 ≈ 1——**归一化成功。**
**验证**：`X_hat.mean(axis=0)` 全为 0、`X_hat.var(axis=0)` 全为 1。

### 步骤 4：γ、β 缩放平移

```python
Y = gamma * X_hat + beta
```

**操作**：`gamma * X_hat` 逐特征缩放，`+ beta` 逐特征平移。$\gamma, \beta$ 初始值可任意设，训练中学习。
**可调参数**：$\gamma$ 初始常为 1、$\beta$ 初始常为 0（先"纯归一化"再学）。PyTorch `nn.BatchNorm` 的默认初始值正是 $\gamma=1,\beta=0$。
**对应数学**：主线第 3 步公式。**$\gamma, \beta$ 让网络"按需恢复"表达力。**

### 步骤 5：可还原性验证

```python
gamma_restore = np.sqrt(var + eps)
beta_restore  = mu
X_back = gamma_restore * X_hat + beta_restore
np.allclose(X_back, X)    # True
```

**操作**：若 $\gamma=\sqrt{\sigma^2+\epsilon}$、$\beta=\mu$，则 $Y = \sqrt{\sigma^2}\cdot\frac{X-\mu}{\sqrt{\sigma^2}} + \mu = X$——**完全还原**。
**可调参数**：这说明 $\gamma, \beta$ 的参数空间里"包含不归一化"这一点——网络可以选择任何介于"完全归一化"与"完全不归一化"之间的行为。
**对应数学**：主线"$\gamma,\beta$ 允许网络恢复归一化前的能力"。**这是 BatchNorm"可学习"的关键性质：归一化不是强制，是给网络的选项。**

## 边界声明：这套代码能做什么，不能做什么

1. **本课是"训练模式"的 BatchNorm**。测试模式用"滑动平均统计量"（`running_mean`/`running_var`），不依赖当前批。`model.eval()` 切换统计量来源——**忘了切，推理结果出错**。
2. **批量太小会失效**。$m=1$ 时方差为 0、统计量噪声大。这正是 LayerNorm（不依赖批）在 Transformer 里取代 BatchNorm 的原因。
3. **`X.var` 用总体方差（$m$）**，与"样本方差"（$m-1$）不同。BatchNorm 论文用总体方差。这个细节在实现一致性上重要。
4. **本课只实现"前向"**。反向传播中 BatchNorm 也要对 $\mu, \sigma^2$ 求导（链式法则），PyTorch 自动处理。手写版看"前向三步"即可。
